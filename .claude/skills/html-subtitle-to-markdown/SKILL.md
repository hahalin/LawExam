# 字幕 HTML 轉 Markdown

## 取得字幕 HTML：Claude 用 Chrome 自動抓（2026/10/18 起，憲法 17 講用這個方法）

使用者不必再右鍵、F12 複製。需要：電腦上的 Chrome 開著、Claude 擴充功能已登入同一帳號、志光網站已登入；Claude 有 `D:\repo\LawExam` 與「下載」資料夾（`C:\Users\AIC\Downloads`）的存取權。

1. 使用者給課程清單網址（例：憲法 `https://ai.highstudy.com.tw/zh/program/b8c727a3-684e-48e2-8697-279b194f8994`）。用 Claude in Chrome 開新分頁，`get_page_text` 讀清單，確認每講名稱（例 `115律師-憲法A(陸伯言)-01`）與講數。
2. **跳過測驗**：清單裡影片與「-測驗」是分開的項目，只點影片項目即可進播放頁，不用做測驗（憲法 01、02、17 講實測可直接進）。
3. 用 `javascript_tool` 貼上 `scripts/grab_subtitles.js` 全文定義 `window.__grab`，再**一講一呼叫**：`JSON.stringify(await window.__grab('憲法', '115律師-憲法A(陸伯言)-', '04'))`。它會點該講、開「字幕」分頁、等字幕載完（整講一次全載，不是虛擬捲動）、只留時間與字幕，下載 `{科目}{NN}.html`。強制執行法這類不加前綴的科目，第一個參數給 `''`。
4. 回傳的句數（約 3000～3700 句）與最後時間（約 2:20～2:35）要合理；`err` 或 0 句就重抓那一講。
5. 用 `device_stage_files` 從「下載」資料夾取檔，確認檔內註解的課名編號對得上（`grep "-NN；"`），在雲端跑 `convert_subtitle.py` 轉 md，再用 `device_commit_files` 寫進 `課程字幕/{科目}/`（html 與 md 都寫；html 在 .gitignore，只留本機）。

踩過的坑：
- **Chrome 擋多檔下載**：第一個檔之後會被擋。請使用者點網址列右邊的下載圖示，選「一律允許 ai.highstudy.com.tw 自動下載多個檔案」。被擋時排隊的檔案，允許後會一起冒出來，可能變成空檔或「(1)」「(2)」重複檔，以檔案大小與檔內課名挑對的。
- **不要連抓**：一次呼叫抓多講曾超過 45 秒逾時，網站還進了「服務即將恢復」維護頁。一講一呼叫、中間隔幾秒。
- **進度百分比**：點進播放頁影片會播一兩秒，志光的觀看進度可能多 1% 左右；腳本會暫停影片。
- 字幕內容不要經過對話傳（一講 13 萬字），一律走下載檔。
- 抓完關掉自己開的分頁。「下載」資料夾裡的 `{科目}NN.html` 殘檔 Claude 刪不掉，提醒使用者自行清。

## 流程

1. 使用者把網頁字幕區塊存成 `課程字幕/{科目}/{科目}{編號}.html`（例：`課程字幕/民法/民法16.html`）。
   - 一堂課 HTML 約 1～2 MB，**不要**貼進對話，一律存檔。
2. 執行腳本（在專案根目錄）：
   ```bash
   python3 .claude/skills/html-subtitle-to-markdown/convert_subtitle.py "課程字幕/民法/民法16.html"
   ```
   - 傳**專案根目錄起算的相對路徑或絕對路徑**皆可；腳本會自行處理。
3. 輸出 `課程字幕/民法/民法16.md`，格式：
   ```markdown
   # 課程名稱：民法民法16

   HH:MM:SS - HH:MM:SS  
   字幕內容
   ```
4. 回報行數，並確認開頭／結尾幾句是否像完整一堂課（網頁有時只載入部分字幕）。

## 跳過規則（必須遵守）

- 對應的 `.md` 已存在 → **不處理、不覆蓋**，告知使用者。

## 腳本認得的 HTML 結構

```html
<div class="css-10s8ss9">
  <p>00:00:00 - 00:01:23</p>
  <p>字幕內容</p>
</div>
```
備用：連續的 `<p>時間</p><p>內容</p>`。若兩種都抓不到（補習班改版），讀 HTML 前 200 行找新的 class 名稱，修改腳本的選擇器，不要手動轉。

## 環境

- Claude 的執行環境是 Linux，用 `python3`；需要 `beautifulsoup4`（已安裝；缺少時 `pip install beautifulsoup4`）。

## 轉完之後

接著用 `subtitle-note-organizer` 做筆記。字幕檔 7000～8000 行，整理時分批讀（每批約 500～800 行）。
