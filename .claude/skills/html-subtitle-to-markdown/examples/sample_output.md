# 課程名稱：刑法01

00:00:00 - 00:00:15  
各位同學大家好，歡迎來到刑法總則的課程。

00:00:15 - 00:00:45  
今天我們要介紹的是刑法的基本原則，包括罪刑法定原則、法律明確性原則等重要概念。

00:00:45 - 00:01:30  
首先，罪刑法定原則是刑法最重要的基本原則之一，其意義在於「無法律即無犯罪，無法律即無刑罰」。

00:01:30 - 00:02:15  
這個原則的目的是為了保障人權，避免國家濫用刑罰權，讓人民能夠預見自己的行為是否會受到處罰。

00:02:15 - 00:03:00  
罪刑法定原則包含幾個重要的派生原則：第一是習慣法禁止原則，第二是類推適用禁止原則，第三是溯及既往禁止原則。
