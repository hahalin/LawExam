# 偵查 — 主題式考古題整理

> 涵蓋範圍：偵查主體、偵查不公開、傳喚與通知、拘提（逕行拘提）、逮捕（現行犯／通緝犯）、通訊監察、強制採集（採血／採尿）、不起訴處分與緩起訴  
> 資料來源：108～114年司律一試刑事訴訟法考古題（不含113年）

---

## 壹、偵查主體與偵查不公開

### 1、112年第18題（原第53題）

> 某直播主甲因涉嫌詐騙，經警局通知到場接受詢問。結束後，甲自認很冤枉，當晚遂將警察提問關於其自己涉案之內容透過臉書直播說出來，藉以澄清自己並未涉及不法。下列關於甲是否違反刑事訴訟法第245條第3項偵查不公開原則之敘述，何者最為正確？

**(A)** 違反。因案件既然進入偵查階段，任何人皆不得公開任何偵查相關資訊  
**(B)** 不違反。因被告就其本身涉案部分並非刑事訴訟法第245條第3項偵查不公開原則之規範對象  
**(C)** 違反。因被告須事先取得偵查機關同意始得公開  
**(D)** 不違反。因被告僅於個人臉書發表，尚未達公開之程度

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 偵查不公開原則（刑訴§245 III）之規範對象為「偵查中因執行職務知悉偵查有關事項之人」，主要拘束偵查機關人員，並非拘束所有人。被告非屬該條規範對象。 |
| (B) | ✓ | 刑訴§245 III 偵查不公開之規範對象為檢察官、檢察事務官、司法警察（官）及辯護人等因執行職務知悉偵查事項之人。**被告（犯罪嫌疑人）就其本身涉案部分，非屬該條規範對象**，故甲公開自己涉案內容不違反偵查不公開原則。 |
| (C) | ✗ | 被告非偵查不公開之規範對象，無須取得偵查機關同意。 |
| (D) | ✗ | 臉書直播已具有公開性，但本題關鍵不在是否達公開程度，而在被告根本非偵查不公開之規範對象。 |

> [!NOTE]
> **重點整理**
> - 偵查不公開原則（刑訴§245 III）規範對象：檢察官、檢察事務官、司法警察（官）、辯護人等「因執行職務知悉偵查有關事項之人」。
> - **被告（犯罪嫌疑人）不受偵查不公開原則拘束**，得就自身涉案事項對外說明。
> - 偵查不公開作業辦法進一步細化規範對象與例外情形。

### 2、112年第2題（原第37題）

> 甲警為查緝走私毒品裝置衛星定位追蹤器（Global Positioning System）於A使用貨車下方底盤，用以接收其行車於公有道路之所在位置經緯度、地址及停留時間等行蹤數據（下稱「GPS偵查」）。依據我國最高法院實務判決，有關「GPS偵查」之證據蒐集，下列敘述何者正確？

**(A)** 「GPS偵查」該當現行法之搜索處分  
**(B)** 「GPS偵查」該當現行法之勘驗處分  
**(C)** 「GPS偵查」違反強制處分法定原則  
**(D)** 「GPS偵查」符合偵查任意性原則

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | GPS偵查涉及長期、全面監控行蹤，與傳統搜索（對人身、物件、住居所之搜查）性質不同，最高法院認為不能直接歸類為現行法之搜索處分。 |
| (B) | ✗ | 勘驗係法官或檢察官就特定物體或場所之狀態進行五官觀察，GPS追蹤非屬勘驗範疇。 |
| (C) | ✓ | 最高法院認為GPS偵查屬於對人民隱私權之重大干預，具有**強制處分**之性質，但現行刑事訴訟法並無明文授權此種偵查手段，故違反**強制處分法定原則**（刑訴§228 IV 參照）。依法律保留原則，干預人民基本權之強制處分須有法律明文依據。 |
| (D) | ✗ | GPS偵查非屬任意偵查。其長期、持續追蹤個人行蹤，已逾越任意偵查之界限，侵害隱私權及資訊自主權。 |

> [!NOTE]
> **重點整理**
> - GPS追蹤偵查屬**強制處分**，因現行法欠缺明文授權，違反強制處分法定原則。
> - 強制處分法定原則：限制人民基本權之強制處分，須有法律明確授權依據。
> - 任意偵查 vs 強制處分之區分：是否干預人民基本權（人身自由、隱私權等）。
> - GPS偵查取得之證據，因程序違法，其證據能力須依刑訴§158-4 權衡判斷。

### 3、107年第22題（原第57題）

> 被害人甲向檢察官提起強盜案件的告訴。下列敘述，何者正確？

**(A)** 若甲並未指明犯罪之人，檢察官並無開始偵查之義務，因犯罪情事尚未明確  
**(B)** 檢察官不得命檢察事務官進行偵查，因其並非司法警察官員  
**(C)** 若犯罪嫌疑人自行到案，未經拘提，警察不得解送犯罪嫌疑人至檢察官處  
**(D)** 司法警察官員應取得檢察官之同意後，始得封鎖犯罪現場，並為即時之勘察  

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依**§228 I**，檢察官因**告訴**而知有犯罪嫌疑者，**應即開始偵查**。無論告訴人有無指明犯罪之人，檢察官均有偵查義務。 |
| (B) | ✗ | 依**§231-1**，檢察官得命**檢察事務官**進行偵查。檢察事務官係依法令協助檢察官執行職務之人員，屬於法定輔助偵查人員，非限於司法警察官員。 |
| (C) | ✓ | 依**§92 I**、**§87**等規定，警察**解送**犯罪嫌疑人至檢察官處，須有合法之強制處分依據（如拘提、逮捕、通緝）。若犯罪嫌疑人**自行到案且未經拘提**，並無法律上之留置（強制）根據，警察不得強制**解送**之（僅能通知到場或由當事人自願前往）。 |
| (D) | ✗ | 依**§218**（及相關規定），**司法警察官員**於遇有突發犯罪事件時，得**不待**檢察官之命令，自行即時封鎖犯罪現場，並進行相關查察工作，無須先取得檢察官同意。 |

> [!NOTE]
> **重點整理**
> - **§228 I**：有告訴→檢察官**應即開始偵查**，不論告訴人是否指明嫌疑人。
> - **§231-1**：檢察官得命**檢察事務官**偵查，不限於司法警察官員。
> - **解送犯罪嫌疑人**：需有合法強制處分基礎（拘提/逮捕/通緝）；**自行到案**之嫌疑人，警察不得強制解送。
> - **§218**（現場封鎖）：司法警察官員遇突發犯罪，**不需**等待檢察官命令，可自行即時封鎖現場。

## 貳、傳喚與通知

### 4、108年第12題（原第47題）

> 司法警察官欲通知犯罪嫌疑人甲到場接受詢問。下列敘述何者正確？

**(A)** 通知甲到場，依法得以言詞或通知書為之  
**(B)** 通知甲到場所使用的通知書，應由檢察官簽名  
**(C)** 通知書上應記載受通知人無正當理由不到場時，得命拘提  
**(D)** 合法通知甲後，無正當理由不到場者，得報請檢察官核發拘票

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依刑訴§71-1，司法警察官通知犯罪嫌疑人應使用**通知書**，不得僅以言詞通知。通知書為要式文書。 |
| (B) | ✗ | 通知書由**司法警察官**簽名即可（刑訴§71-1 II），無須檢察官簽名。傳票才須由法官或檢察官簽名。 |
| (C) | ✗ | 通知書不得記載「得命拘提」之內容。此為**傳票**之法定記載事項（刑訴§71 IV）。通知書之效力弱於傳票，不得以拘提相威脅。 |
| (D) | ✓ | 依刑訴§71-1 IV，經合法通知，無正當理由不到場者，得**報請檢察官核發拘票**。司法警察官本身不得核發拘票，須報請檢察官為之。 |

> [!NOTE]
> **重點整理**
> - 司法警察官通知犯罪嫌疑人到場，應使用**通知書**（刑訴§71-1），不得以言詞為之。
> - 通知書由司法警察官簽名；傳票由法官或檢察官簽名。
> - 經合法通知不到場→報請檢察官核發拘票；經合法傳喚不到場→得逕行拘提。
> - 通知書 ≠ 傳票：效力、簽發權限、不到場之法律效果均不同。

### 5、109年第13題（原第48題）

> 甲、乙二人共同謀議犯強盜罪，經司法警察官調查後，移送檢察官偵查。下列敘述何者最為正確？

**(A)** 傳票僅須合法送達於甲，其效力仍及於乙  
**(B)** 傳票僅能由法官簽發  
**(C)** 傳喚屬強制處分，被告無正當理由不到場，得命拘提  
**(D)** 司法警察官不得用通知書約談甲、乙到場協助調查

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 傳票具有**一身專屬性**，僅對被傳喚人發生效力，不及於共犯。甲、乙應分別傳喚，傳票對甲之效力不及於乙。 |
| (B) | ✗ | 傳票非僅由法官簽發。偵查中**檢察官**亦得簽發傳票傳喚被告（刑訴§71 II）。 |
| (C) | ✓ | 傳喚屬於強制處分之一種。依刑訴§75，被告經合法傳喚，無正當理由不到場者，**得命拘提**。 |
| (D) | ✗ | 司法警察官依刑訴§71-1，得使用通知書通知犯罪嫌疑人到場詢問，此為法律明文授權。 |

> [!NOTE]
> **重點整理**
> - 傳喚屬強制處分，傳票具一身專屬性，不及於共犯。
> - 偵查中傳票由檢察官簽發；審判中傳票由法官簽發。
> - 經合法傳喚無正當理由不到場→得命拘提（刑訴§75）。
> - 司法警察官得以通知書通知犯罪嫌疑人到場（刑訴§71-1）。

### 6、111年第2題（原第37題）

> 檢察官受理告訴人告訴被告甲涉嫌詐欺，檢察官依法發動偵查。下列作為何者不符合刑事訴訟法之規定？

**(A)** 檢察官依法傳喚被告甲到檢察署接受訊問，甲無正當理由不到，檢察官簽發拘票，拘提甲  
**(B)** 檢察官將案件發交轄區之司法警察官先行調查蒐證，受發交之司法警察官遂對甲發出傳票，傳喚甲至警察局接受調查  
**(C)** 檢察官傳喚被告甲到檢察署接受訊問後，認甲涉嫌詐欺犯罪嫌疑重大，有逃亡之虞但無聲請羈押之必要，檢察官可逕命具保  
**(D)** 被告甲自行到檢察署說明案情，檢察官訊問後，如認甲涉嫌詐欺犯罪嫌疑重大，且有反覆實施詐欺犯罪之虞，需先踐行逮捕程序，才能向法院聲請羈押

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 檢察官依刑訴§71傳喚被告，甲無正當理由不到場，依刑訴§75得拘提之。檢察官有簽發拘票之權限（刑訴§77 II），合法。 |
| (B) | ✗ | **司法警察官無權簽發傳票**。傳票僅得由法官或檢察官簽發（刑訴§71 II）。司法警察官僅得以**通知書**通知犯罪嫌疑人到場（刑訴§71-1）。受發交調查之司法警察官對甲「發出傳票」違法。 |
| (C) | ✓ | 依刑訴§93 III，檢察官認無羈押必要時，得逕命具保、責付或限制住居。合法。 |
| (D) | ✓ | 詐欺罪屬刑訴§101-1 I 列舉之預防性羈押罪名，檢察官聲請羈押前須先踐行逮捕程序（刑訴§228 IV），始得向法院聲請羈押。甲自行到場非經逮捕或拘提，需另行踐行逮捕程序。 |

> [!NOTE]
> **重點整理**
> - **傳票**僅得由法官或檢察官簽發（刑訴§71 II）；**通知書**由司法警察官簽發（刑訴§71-1）。
> - 檢察官「發交」司法警察官調查，司法警察官僅得以通知書通知到場，不得以傳票傳喚。
> - 偵查中聲請羈押前，須先踐行逮捕或拘提程序。

### 7、112年第1題（原第36題）

> 甲發現其菜園內的高麗菜100顆被人盜採一空而報警，經警察調閱菜園旁道路的監視器，發現駕駛小貨車之乙涉有重嫌，關於警察請乙出面說明的文書，下列敘述何者最為正確？

**(A)** 警察請乙出面說明的文書，稱為傳票，警察可直接以此文書強制乙到場說明  
**(B)** 警察請乙出面說明的文書，稱為傳票，警察不可直接強制乙到場說明  
**(C)** 警察請乙出面說明的文書，稱為通知書，警察不可直接強制乙到場說明  
**(D)** 警察請乙出面說明的文書，稱為通知書，警察可以直接強制乙到場說明

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 警察（司法警察官或司法警察）無權簽發傳票。傳票由法官或檢察官簽發。且即使是傳票，警察也不能直接以傳票強制到場（傳票不到場之效果為拘提，須另行核發拘票）。 |
| (B) | ✗ | 前半段錯誤，該文書非傳票而是通知書。 |
| (C) | ✓ | 警察通知犯罪嫌疑人到場使用**通知書**（刑訴§71-1）。通知書不具直接強制力，犯罪嫌疑人不到場時，警察不可直接強制到場，須**報請檢察官核發拘票**。 |
| (D) | ✗ | 文書名稱正確為通知書，但警察不得直接強制到場。 |

> [!NOTE]
> **重點整理**
> - 警察請犯罪嫌疑人到場說明，使用**通知書**，非傳票。
> - 通知書無直接強制力，不到場者須報請檢察官核發拘票。
> - 傳票 vs 通知書：簽發權限、法律效果均不同，為常考區辨點。

## 參、拘提（逕行拘提）

### 8、108年第11題（原第46題）

> 警察乙於巡邏時，經過某地，經通報該處正發生強盜案件，立即前往並逮捕強盜中之犯罪行為人甲。依實務見解，下列敘述何者正確？

**(A)** 不論情況是否急迫，乙均得因現行犯甲之供述，對共謀共同正犯丙，不經傳喚逕行拘提  
**(B)** 乙因現行犯甲之供述，對有事實足認為共犯嫌疑重大者且情況急迫時，得依法逕行拘提之  
**(C)** 乙經現行犯甲同意至甲宅搜索，搜索完畢後乙應於3日內向該管檢察官報告  
**(D)** 乙得立即搜索現行犯甲使用之交通工具，並應於3日內報告該管檢察官

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 逕行拘提須具備**情況急迫**之要件（刑訴§88-1 I②）。「不論情況是否急迫」之說法錯誤，非任何情形均得逕行拘提共犯。 |
| (B) | ✓ | 依刑訴§88-1 I②，因現行犯之供述，且有事實足認為共犯嫌疑重大，且**情況急迫**者，檢察官、司法警察官或司法警察得逕行拘提之。三要件須同時具備：(1)現行犯供述、(2)共犯嫌疑重大、(3)情況急迫。 |
| (C) | ✗ | 同意搜索之報告期限非3日。且搜索甲宅若係同意搜索，應由執行人員持搜索同意書，事後無須向檢察官報告。 |
| (D) | ✗ | 逮捕現行犯時得為附帶搜索（刑訴§130），搜索其身體、隨身攜帶物件、所使用之交通工具及立即可觸及之處所，無須另行報告。附帶搜索無須事後報告檢察官。 |

> [!NOTE]
> **重點整理**
> - 逕行拘提共犯之要件（刑訴§88-1 I②）：(1)因現行犯之供述、(2)有事實足認共犯嫌疑重大、(3)**情況急迫**。三者缺一不可。
> - 逕行拘提後應即報請檢察官核發拘票（刑訴§88-1 II）；逮捕現行犯之附帶搜索無須事後報告。

### 9、109年第14題（原第49題）

> 檢察官擬拘提被告甲。下列敘述何者最為正確？

**(A)** 非經合法傳喚甲，檢察官不得拘提  
**(B)** 檢察官應向法院聲請拘票，方得拘提甲，以保護其人身自由  
**(C)** 拘提如由司法警察（官）執行，為有效執行，拘票得作數通，分別交由數人各別執行  
**(D)** 為遵循管轄區域之規定，司法警察（官）不得於管轄區域外執行拘提

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 刑訴§76規定，有法定情形者（如逃亡之虞等），得**不經傳喚逕行拘提**，並非一律須先傳喚。 |
| (B) | ✗ | 偵查中拘票由**檢察官**核發（刑訴§77 II），無須向法院聲請。審判中拘票由法官簽名。 |
| (C) | ✗ | 拘票雖得作數通，但依刑訴§79 II但書，不得分別交由數人各別執行，應由執行人員一同持票執行。 |
| (D) | ✓ | 依刑訴§81，司法警察官或司法警察不得於管轄區域外執行拘提。但有急迫情形者，得報請該管檢察官許可後執行。 |

> [!NOTE]
> **重點整理**
> - 偵查中拘票由**檢察官**核發，審判中由**法官**核發。
> - 有法定事由（刑訴§76）得不經傳喚逕行拘提。
> - 司法警察（官）**不得於管轄區域外**執行拘提（刑訴§81），但有急迫情形者例外。
> - 拘票不得分別交由數人各別執行（刑訴§79 II但書）。

### 10、111年第8題（原第43題）

> 無一定住居所之甲涉犯詐欺罪嫌，經司法警察調查後，認犯罪嫌疑重大。下列敘述何者最為正確？

**(A)** 因甲犯罪嫌疑重大且無一定住居所，故必要時，得不使用拘票予以拘提  
**(B)** 因甲犯罪嫌疑重大且無一定住居所，故必要時，得不經傳喚且不持拘票予以逮捕  
**(C)** 因甲犯罪嫌疑重大且無一定住居所，但仍應經傳喚後，無正當理由不到場，且須持拘票始得予以拘提  
**(D)** 因甲犯罪嫌疑重大且無一定住居所，故必要時，得不經傳喚，但仍應持拘票予以拘提

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 拘提必須使用拘票（刑訴§77），拘票為拘提之令狀依據，不得省略。 |
| (B) | ✗ | 無一定住居所之逕行拘提仍屬「拘提」，非「逮捕」。逮捕僅適用於現行犯或通緝犯。且拘提須持拘票。 |
| (C) | ✗ | 依刑訴§76①，被告犯罪嫌疑重大且**無一定住居所**者，得**不經傳喚**逕行拘提，無須先傳喚不到場。 |
| (D) | ✓ | 依刑訴§76①，被告犯罪嫌疑重大且無一定住居所者，得**不經傳喚**逕行拘提。但逕行拘提仍須持拘票（刑訴§77），拘票為拘提之必要令狀。 |

> [!NOTE]
> **重點整理**
> - 逕行拘提（刑訴§76）之法定事由：①無一定住居所、②逃亡或有逃亡之虞、③有湮滅證據之虞、④犯重罪有相當理由。
> - 逕行拘提＝不經傳喚即拘提，但仍**須持拘票**。
> - 拘提 vs 逮捕：拘提須令狀（拘票），逮捕（現行犯、通緝犯）為無令狀處分。

### 11、114年第7題（原第42題）

> 司法警察調查犯罪，因嫌疑重大，情況急迫而得為逕行拘提之情形，下列敘述何者錯誤？

**(A)** 犯罪嫌疑人在公共場所賭博財物，經警盤查而逃逸者  
**(B)** 因現行犯之供述，且有事實足認為共犯嫌疑重大者  
**(C)** 犯罪嫌疑人因犯強盜罪而故意殺人，有事實足認有逃亡之虞者  
**(D)** 發覺犯罪嫌疑人是另案通緝中之被告

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗（本選項為錯誤敘述，即本題答案） | 刑訴§88-1 I③規定，逕行拘提之罪名列舉中**不包含賭博罪**。在公共場所賭博財物為刑法§266公然賭博罪，屬輕罪，不在逕行拘提之法定列舉罪名範圍內。故不得以此為由逕行拘提。 |
| (B) | ✓ | 符合刑訴§88-1 I②之規定，因現行犯之供述，有事實足認為共犯嫌疑重大且情況急迫者，得逕行拘提。 |
| (C) | ✓ | 強盜殺人屬最輕本刑5年以上有期徒刑之重罪，有事實足認有逃亡之虞，符合刑訴§88-1 I④之逕行拘提要件。 |
| (D) | ✓ | 通緝犯依刑訴§87 I，利害關係人得逕行逮捕。而司法警察發覺犯罪嫌疑人為另案通緝被告，亦屬刑訴§88-1 I①之情形，得逕行拘提。 |

> [!NOTE]
> **重點整理**
> - 逕行拘提（刑訴§88-1 I）之法定情形：①為通緝犯、②因現行犯供述共犯嫌疑重大、③犯特定罪名逃逸者（不含賭博罪）、④犯重罪有逃亡之虞。
> - 刑訴§88-1 I③列舉之罪名：放火、強制性交、搶奪、強盜、恐嚇取財、擄人勒贖等，**賭博罪不在列舉範圍**。
> - 逕行拘提後應即報請檢察官核發拘票。

### 12、114年第13題（原第48題）

> 強盜案件的犯罪嫌疑人甲在被以現行犯逮捕後，當場供稱乙為共犯。警察掌握其他事實，認乙確共犯嫌疑重大且情況急迫。下列敘述何者正確？

**(A)** 檢察官應先傳喚乙，乙經合法傳喚，無正當理由不到場者，得拘提之  
**(B)** 為掌握犯罪偵查效率，警察得先行拘提乙，再報請檢察官核發拘票  
**(C)** 因乙涉嫌觸犯的是最輕本刑5年有期徒刑以上之罪，僅能由檢察官逕行拘提之  
**(D)** 警察應取得檢察官簽發之拘票後，始得拘提乙

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 本案情況急迫，依刑訴§88-1 I②，因現行犯供述，有事實足認共犯嫌疑重大且情況急迫者，得**不經傳喚逕行拘提**，無須先傳喚。 |
| (B) | ✓ | 依刑訴§88-1 I②，因現行犯甲之供述，有事實足認乙為共犯嫌疑重大且情況急迫，**司法警察得逕行拘提乙**，再於拘提後**即報請檢察官核發拘票**（刑訴§88-1 II）。此即「先拘提、後補票」之程序。 |
| (C) | ✗ | 逕行拘提非僅檢察官得為之，**司法警察官或司法警察**亦得依刑訴§88-1為逕行拘提，非僅限檢察官。 |
| (D) | ✗ | 逕行拘提之特色即在於不需事先取得拘票，事後再補行報請核發拘票即可（刑訴§88-1 II）。 |

> [!NOTE]
> **重點整理**
> - 逕行拘提共犯（刑訴§88-1 I②）：因現行犯供述＋共犯嫌疑重大＋情況急迫→得逕行拘提。
> - 逕行拘提後之補正程序：應即報請檢察官核發拘票（刑訴§88-1 II）。
> - 逕行拘提非檢察官專屬權限，司法警察（官）亦得為之。
> - 與108年第11題（原第46題）同一考點，反覆出現。

### 13、107年第13題（原第48題）

> 甲因涉嫌竊盜罪羈押於看守所，又因另案涉嫌與乙共犯傷害致死罪，偵查中經檢察官向看守所提訊甲，訊問甲有無與乙共犯傷害致死事實，並認為有再傳乙與甲訊問之必要，遂當場告知甲：「下次訊問之時間為當年2月23日上午10時再開庭」並記明筆錄。5日後，甲因上述竊盜罪具保釋放，惟檢察官不知其已經具保釋放，而甲並未於上開指定期日到庭，亦未具狀說明不到庭之原因。試問檢察官能否於2月23日上午10時之後，簽發拘票拘提甲？

**(A)** 可。因檢察官已對甲當面告知下次應到之期日，甲未到庭亦未具狀說明不到庭之原因  
**(B)** 可。雖檢察官未同時告知「如不到場得命拘提」的意旨，惟因甲當時在押，且經告以應行到庭之意旨  
**(C)** 不可。因檢察官對甲當面告知下次應到之期日時，未同時告知「如不到場得命拘提」的意旨  
**(D)** 不可。除逕行拘提外，一定要在庭期前先送達傳票給甲  

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 僅口頭告知下次到場日期，**不符合合法傳喚的要件**。合法傳喚須以傳票為之，且傳票應記載「如不到場得命拘提」（§71 IV）。無合法傳喚即無拘提之前提。 |
| (B) | ✗ | 雖甲當時在押（有強制處分），但偵查中對另案嫌疑人的「再次告知到場日期」，**並非合法傳票**。傳票需載明「如不到場得命拘提」之意旨（§71 IV），口頭或筆錄告知日期並不等同合法傳票。在押≠已被合法傳喚。 |
| (C) | ✓ | 依**§71 IV**，傳票應記載「如不到場得命拘提」的意旨，此為傳喚之**必要記載事項**。檢察官雖告知甲下次庭期，但未**同時告知「如不到場得命拘提」**，不符合合法傳喚之要件。無合法傳喚→**不得依§75簽發拘票**拘提。 |
| (D) | ✗ | 逕行拘提（§76、§88-1）情形下，不需先傳票通知。問題在於本案情況是否符合逕行拘提要件，而非一律須先傳票。(D)說「一定要先送達傳票」過於絕對，因逕行拘提不需傳票。 |

> [!NOTE]
> **重點整理**
> - **§71 IV**：傳票應記載應到場之**時日、場所**及「**如不到場得命拘提**」的意旨。
> - 僅口頭告知庭期但未告知「得命拘提」→**不構成合法傳喚**→不得依§75發拘票。
> - 合法傳喚後無正當理由不到場→始得依§75簽發拘票拘提。
> - 逕行拘提（§76）：無須先傳票，但須符合法定事由（逃亡或藏匿、無固定住所等）。

> - 抗拒逮捕者得用強制力，但不得逾必要程度（刑訴§90）。

### 15、109年第11題（原第46題）

> 甲涉犯強盜罪嫌重大，經司法警察持檢察官所簽發之拘票仍拘提無著，且發現甲已潛逃。下列敘述何者正確？

**(A)** 甲犯罪嫌疑重大且已潛逃，檢察長得簽發通緝書通緝  
**(B)** 路人乙發現通緝犯甲時，得逕行逮捕  
**(C)** 通緝書僅得由法院院長簽發，偵查中檢察長不得簽發  
**(D)** 告訴人發現通緝犯甲時，不得逕行逮捕

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 通緝須以「被告經合法傳喚無正當理由不到場」或「拘提無著」為前提（刑訴§84）。偵查中通緝書由**檢察官**簽發（非檢察長），但此選項敘述檢察長得簽發，並不正確。 |
| (B) | ✓ | 依刑訴§87 I，通緝經通知或公告後，**檢察官、司法警察官得拘提被告或逕行逮捕之**。同條第2項規定，**利害關係人**亦得逕行逮捕通緝之被告。路人乙屬一般人民，依此規定，**任何人**發現通緝犯均得逕行逮捕（準用現行犯之逮捕規定）。 |
| (C) | ✗ | 通緝書非僅由法院院長簽發。偵查中得由檢察官簽發（刑訴§85 II）。 |
| (D) | ✗ | 告訴人亦得逮捕通緝犯。通緝犯之逮捕，任何利害關係人均得為之（刑訴§87 II）。 |

> [!NOTE]
> **重點整理**
> - 通緝之前提：被告經合法傳喚不到場，或拘提無著（刑訴§84）。
> - 通緝犯之逮捕：檢察官、司法警察官得拘提或逮捕；**利害關係人（含一般人民）**亦得逕行逮捕（刑訴§87）。
> - 通緝書：偵查中由檢察官簽發，審判中由法官簽發。

### 16、109年第18題（原第53題）

> 某超商所有價值約新臺幣 2400 元之洋酒失竊，警察調取該店之監視器錄影光碟查閱，顯示甲涉嫌重大，警察發通知書通知甲詢問。甲依通知到場說明，但否認犯行，則警察能否違反甲之意願逕行解送檢察官訊問？

**(A)** 可，甲確實涉嫌重大，有必要儘速偵查終結該案  
**(B)** 不可，因甲涉嫌者僅為竊盜罪，若為最輕本刑5年以上有期徒刑之罪則可  
**(C)** 不可，因甲非經拘提或逮捕，係依警察通知到場，不得解送  
**(D)** 可，因甲否認犯行，有必要儘速偵查終結該案

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 犯竊盜罪非最輕本刑5年以上之罪，不符合解送要件。不能僅因涉嫌重大即逕行解送。 |

| (D) | ✗ | 否認犯行非得逕行解送之法律依據。 |

> [!NOTE]
> **重點整理**
> - 經通知到場之犯罪嫌疑人，非經拘提或逮捕，不得逕行解送檢察官。
> - 解送原則：拘提或逮捕後始得解送（刑訴§91、§92）。
> - 通知到場後不到場之效果：報請檢察官核發拘票（刑訴§71-1 IV）。

### 20、110年第12題（原第47題）

> 通訊保障及監察法（下稱通保法）第18條之1第1項規定：「依第5條、第6條或第7條規定執行通訊監察，取得其他案件之內容者，不得作為證據。但於發現後7日內補行陳報法院，並經法院審查認可該案件與實施通訊監察之案件具有關連性或為第 5 條第 1 項所列各款之罪者，不在此限」。關於本項規定另案監聽之證據能力有無，依實務見解，下列敘述何者錯誤？

**(B)** 另案監聽得作為證據的要件之一，是另案罪名屬「重罪列舉原則」（通保法第5條第1項所列各款之罪），或非屬重罪但「與本案具有關連性之犯罪」

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 通保法§18-1 I 採「原則排除、例外容許」的立法體例：另案監聽取得之內容原則上不得作為證據，例外於7日內陳報法院並經審查認可者，始得作為證據。 |
| (B) | ✓ | 另案監聽得為證據之要件：(1)7日內陳報法院，且(2)法院認可該另案「與本案具有關連性」或「屬通保法§5 I 列舉之重罪」。 |
| (C) | ✗（本選項為錯誤敘述，即本題答案） | 依實務見解（最高法院判決），未於7日內補行陳報法院者，並非絕對排除。受訴法院**仍得適用刑訴§158-4**之權衡法則，審酌人權保障與公共利益之均衡維護，決定該另案監聽內容有無證據能力。 |
| (D) | ✓ | 若執行機關自始以虛偽罪名聲請通訊監察書，意圖規避法律規範，實質上已違反正當法律程序，該監聽內容應予絕對排除，不具證據能力。 |

> [!NOTE]
> **重點整理**
> - 另案監聽之證據能力：原則排除、例外容許（通保法§18-1 I）。
> - 例外要件：7日內陳報法院＋法院認可（關連性或重罪）。
> - **未於7日內陳報，仍得依刑訴§158-4權衡**，非絕對排除。
> - 自始偽以罪名聲請監聽→**絕對排除**證據能力。

(D)

|------|--------|------|
| (A) | ✗ | 另案監聽非違法取得。本案通訊監察書合法核發，於監聽過程中意外發現另案內容，屬通保法§18-1所定之「另案監聽」，有法定處理程序，非絕對排除。 |

**(D)** B之抗辯沒有理由，因檢察事務官認有相當理由認為採取吐氣或血液得作為犯罪之證據時，得採取之

(A)

#### 解析

### 23、109年第7題（原第42題）

**(D)** 勘驗筆錄所載告訴人之指訴、說明，有證據能力

(B)

#### 解析

### 24、110年第16題（原第51題）

> 甲施用海洛因被警察逮捕，經警察初步調查後，移送至地檢署繼續偵辦。檢察官發現甲雖在警詢中自白，但警局卻未採集甲之尿液。關於檢察官處理之敘述，下列何者最為正確？

**(A)** 檢察官為偵查主體，應自行對甲採集尿液  
**(B)** 被告既已自白，已無採集尿液之必要，檢察官對此無須再為任何處理  
**(C)** 檢察官得將卷證發回原警局，請其補行採尿液並送驗後再行移送  
**(D)** 檢察官應交由其他警局協助採集

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 檢察官雖為偵查主體，但採集尿液為技術性之蒐證行為，通常由司法警察執行。且實務上檢察官通常指揮司法警察為之，非親自採集。 |
| (B) | ✗ | 被告自白不得作為有罪判決之唯一證據（刑訴§156 II），仍須有補強證據。尿液檢驗結果為施用毒品之重要補強證據，不可省略。 |
| (C) | ✓ | 依刑訴§231 IV，檢察官得將案件發交或發回司法警察官補行調查。本題檢察官得將卷證發回原警局，請其補行採集尿液並送驗。此為偵查實務中常見之「發回補正」程序。 |
| (D) | ✗ | 應發回「原承辦」之警局補行採集，以維持偵查程序之連貫性。交由其他警局在實務上並非正常作法。 |

> [!NOTE]
> **重點整理**
> - 偵查中補行採尿：檢察官得將案件**發回原警局**補行採集（刑訴§231 IV）。
> - 被告自白不得為有罪判決之唯一證據（刑訴§156 II），尿液檢驗為施用毒品案之重要補強證據。
> - 檢察官為偵查主體，得指揮司法警察進行蒐證。

### 26、104年第5題（原第40題）

> 被告甲對於臺北地方法院檢察署檢察官逕為之鑑定留置處分不服，下列關於救濟途徑之敘述，何者正確？

**(A)** 甲得依刑事訴訟法第256條以下的再議規定，經原檢察官向臺灣高等法院檢察署檢察長聲請再議  
**(B)** 甲得依刑事訴訟法第403條、第404條以下的抗告規定，向臺灣高等法院提起抗告救濟  
**(C)** 甲得依刑事訴訟法第416條之準抗告規定，聲請臺北地方法院撤銷之  
**(D)** 甲對系爭處分，依法並無單獨不服途徑，應隨同本案判決一併上訴救濟之  

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | **再議（§256）**係針對**檢察官之不起訴處分**的救濟途徑，僅得由告訴人向上級檢察官聲請。鑑定留置係偵查中之強制處分，非不起訴處分，不得以再議救濟。 |
| (B) | ✗ | **抗告（§403、§404）**係針對**法院裁定**之救濟途徑。鑑定留置係**檢察官**所為之處分，非法院裁定，不得以一般抗告救濟。 |
| (C) | ✓ | 依**§416 I①**，受訴法院以外之法官（含檢察官）就搜索、扣押、鑑定留置等所為之**強制處分**，當事人得聲請**準抗告**，由**受處分地之地方法院**裁定之。甲應向**臺北地方法院**聲請準抗告，請求撤銷鑑定留置處分。 |
| (D) | ✗ | 法律設有§416準抗告規定作為即時救濟途徑，被告不需等到判決確定後才救濟。不及時救濟，等待本案判決後上訴，無法回復鑑定留置期間之人身自由。 |

> [!NOTE]
> **重點整理**
> - **§416 I①（準抗告）**：對檢察官所為之**搜索、扣押、鑑定留置**等強制處分不服，得聲請**受處分地之地方法院**撤銷之。
> - 準抗告 vs 抗告：準抗告針對「法院以外之人（法官、檢察官）」所為之強制處分；抗告針對「法院之裁定」。
> - 再議（§256）：僅針對**不起訴處分**，非強制處分之救濟途徑。
> - 鑑定留置（§203）：性質為限制人身自由之強制處分，不服者得依§416準抗告救濟。

## 柒、不起訴處分與緩起訴

### 27、108年第19題（原第54題）

> 甲涉犯過失傷害罪嫌，經檢察官偵查終結後，參酌刑法第57條所列事項及公共利益之維護，對甲處以緩起訴處分，緩起訴期間 2 年。下列敘述何種情形，檢察官得依職權或依告訴人之聲請撤銷緩起訴？

**(A)** 緩起訴前，因犯過失傷害罪，而在緩起訴期間內受有期徒刑以上刑之宣告  
**(B)** 緩起訴前，因故意犯侵占脫離他人持有物罪，而在緩起訴期間內受科罰金之宣告  
**(C)** 未履行向被害人支付相當數額損害賠償之緩起訴條件  
**(D)** 於緩起訴期間內過失更犯有期徒刑以上刑之罪，經檢察官提起公訴

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依刑訴§253-3 I①，撤銷緩起訴之事由為「緩起訴前，因**故意犯**他罪，而在緩起訴期間內受有期徒刑以上刑之宣告者」。本選項所犯為**過失**傷害罪，非故意犯罪，不符合撤銷事由。 |
| (B) | ✗ | 依刑訴§253-3 I①，須「受**有期徒刑以上刑**之宣告」。本選項雖為故意犯罪，但僅受科**罰金**之宣告，未達有期徒刑以上刑，不符合撤銷事由。 |
| (C) | ✓ | 依刑訴§253-3 I③，被告**未履行**檢察官命其遵守或履行之事項（如§253-2 I④向被害人支付相當數額之損害賠償）者，檢察官得依職權或依告訴人之聲請，**撤銷緩起訴處分**。 |
| (D) | ✗ | 依刑訴§253-3 I②，撤銷事由為「緩起訴期間內**故意**更犯有期徒刑以上刑之罪，經檢察官提起公訴者」。本選項所犯為**過失**罪，不符合此要件。 |

> [!NOTE]
> **重點整理**
> - 撤銷緩起訴處分之事由（刑訴§253-3 I）：
>   1. 緩起訴前因**故意犯他罪**，於緩起訴期間內受**有期徒刑以上刑**之宣告。
>   2. 緩起訴期間內**故意更犯**有期徒刑以上刑之罪，經檢察官提起公訴。
>   3. **未履行**§253-2 I 各款所定應遵守或履行之事項。
> - 注意：撤銷事由限於「**故意犯罪**」，過失犯罪不構成撤銷事由。
> - 注意：須受「**有期徒刑以上刑**」之宣告，僅科罰金者不符合。

### 28、109年第8題（原第43題）

> 下列何種犯罪之被害人，對於檢察官所為之不起訴處分不得提出再議？

**(A)** 違法搜索罪  
**(B)** 妨害投票正確罪  
**(C)** 誣告罪  
**(D)** 放火燒燬房屋罪

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 違法搜索罪（刑法§307）之被害人為被搜索對象，屬**直接被害人**，得依刑訴§256 I對不起訴處分提出再議。 |
| (B) | ✗ | 妨害投票正確罪之被害人為投票權受侵害之個人，仍屬直接被害人，得提出再議。 |
| (C) | ✗ | 誣告罪（刑法§169）之被害人為被誣告之人，屬直接被害人，得提出再議。 |
| (D) | ✓ | 放火燒燬房屋罪（刑法§173、§174）為**公共危險罪**，所保護之法益為**公共安全**（社會法益），個別住戶非刑法直接保護之個人法益被害人。依實務見解，公共危險罪之被害人非屬刑訴§232之**犯罪被害人**（即直接被害人），**不得**對不起訴處分提出再議。 |

> [!NOTE]
> **重點整理**
> - 得對不起訴處分提出再議者：**告訴人**（刑訴§256 I）。
> - 告訴人須為**犯罪之直接被害人**（刑訴§232）或其他法定告訴權人。
> - **公共危險罪**（如放火罪）保護之法益為社會法益（公共安全），個別被害人非犯罪之直接被害人，不具告訴人地位，不得提出再議。
> - 區辨：個人法益犯罪（如違法搜索、誣告）→ 有直接被害人 → 得再議；社會法益犯罪（如放火）→ 無直接被害人 → 不得再議。

### 29、112年第20題（原第55題）

> 關於檢察官的作法，下列敘述何者最為正確？

**(A)** 被告涉犯殺人罪，但偵查期間自殺身亡，檢察官以被告死亡為不起訴處分，但因被告所犯為最輕本刑3年以上有期徒刑之罪，檢察官應將本案送職權再議  
**(B)** 檢察官因認被告僅意圖販賣而持有毒品提起公訴，就警察移送之販賣毒品部分說明不另為不起訴處分，檢察官就不另為不起訴部分毋庸送職權再議  
**(C)** 被告所犯最輕本刑為 3 年以上有期徒刑之罪，如檢察官認其犯罪情狀顯可憫恕，有刑法第 59 條之適用，即得逕為緩起訴處分  
**(D)** 檢察官為使被告甲可以指證乙販毒，當庭將甲轉成證人要求具結作證，並告知甲如無正當理由拒絕作證，得由檢察官依法裁處罰鍰

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 被告死亡為不起訴處分之法定事由（刑訴§252 #6）。然而依刑訴§256 III，須送**職權再議**者，限於「**告訴乃論之罪**，而被告所犯為最輕本刑3年以上有期徒刑之罪之不起訴處分」。被告死亡之不起訴處分係基於訴訟條件消滅，且殺人罪為非告訴乃論之罪，不需依§256 III送職權再議。 |
| (B) | ✓ | 檢察官認定被告僅成立「意圖販賣而持有」，就移送之「販賣」部分不另為不起訴處分。依實務見解，**不另為不起訴處分**係附隨於起訴部分之說明，並非獨立之不起訴處分書，**毋庸依§256 III送職權再議**。 |
| (C) | ✗ | 依刑訴§253-1 I，緩起訴處分之適用範圍限於「被告所犯為**死刑、無期徒刑或最輕本刑3年以上有期徒刑以外之罪**」。最輕本刑3年以上有期徒刑之罪**不得**為緩起訴處分，即使有刑法§59情狀顯可憫恕之適用，亦不得逕為緩起訴。 |
| (D) | ✗ | 依刑訴§187 II，證人無正當理由拒絕具結或證言者，得處以罰鍰，但此**裁處罰鍰權限屬於法院**，檢察官不得自行裁處。偵查中檢察官僅得聲請法院處之。 |

> [!NOTE]
> **重點整理**
> - **職權再議**（刑訴§256 III）之適用範圍：告訴乃論之罪且最輕本刑3年以上有期徒刑之不起訴處分。被告死亡之不起訴處分不在此限。
> - **不另為不起訴處分**：附隨於起訴書之說明，非獨立不起訴處分，毋庸送職權再議。
> - **緩起訴**之適用範圍限制（§253-1 I）：死刑、無期徒刑或最輕本刑3年以上有期徒刑之罪，**不得**緩起訴。
> - 偵查中證人拒絕作證之罰鍰，應由**法院**裁處，檢察官無裁處權限。

### 30、104年第2題（原第37題）

> 甲因涉犯竊盜罪，檢察官經偵查後，認應以緩起訴處分為適當，乃命甲向某基金會提供義務勞務，緩起訴處分期間為2年。下列何者非撤銷緩起訴處分之原因？

**(A)** 甲在緩起訴處分期間內，因酒後駕車觸犯公共危險罪，經檢察官偵查後，聲請簡易判決處刑  
**(B)** 甲在緩起訴前，因犯賭博罪，經檢察官聲請簡易判決處刑，在緩起訴處分期間，經法院判處罰金新臺幣1萬元，惟甲上訴，經地方法院合議庭於緩起訴處分期滿後，駁回上訴確定  
**(C)** 甲在緩起訴前，因犯竊盜罪，經檢察官起訴，在緩起訴處分期間，經法院判處有期徒刑 2 月，緩刑 3 年確定  
**(D)** 甲未於檢察官指定之期限內履行義務勞務  

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗（非答案，即屬撤銷原因） | 依**§253-3 I③**，被告在緩起訴期間內**故意犯他罪，檢察官提起公訴或聲請簡易判決處刑者**，得撤銷緩起訴。甲在緩起訴期間故意犯公共危險罪，檢察官聲請簡易判決處刑→屬撤銷原因。 |
| (B) | ✓（即本題答案：非撤銷原因） | 依**§253-3 I②**，撤銷緩起訴之原因之一是被告在「**緩起訴前**因故意犯他罪，**受有期徒刑以上刑之宣告確定**」。甲在緩起訴前犯賭博罪，受**罰金宣告**（非有期徒刑以上），故不符合§253-3 I②「有期徒刑以上刑之宣告確定」之要件。且法院判決雖確定，但因甲上訴，**在緩起訴期間屆滿後**才確定，不在緩起訴期間內確定→**非撤銷原因**。 |
| (C) | ✗（屬撤銷原因） | 依**§253-3 I②**，甲緩起訴前因犯竊盜罪起訴，在緩起訴期間受**有期徒刑2月（緩刑3年）確定**。有期徒刑2月仍屬「有期徒刑以上刑之宣告確定」（縱附緩刑），符合§253-3 I②→屬撤銷原因。 |
| (D) | ✗（屬撤銷原因） | 依**§253-3 I①**，「**未履行緩起訴條件**」（義務勞務未履行）為撤銷緩起訴之法定原因→屬撤銷原因。 |

> [!NOTE]
> **重點整理**
> - **§253-3 I**：撤銷緩起訴之三種原因：
>   - ①**未履行**緩起訴條件（§253-2命令事項）
>   - ②緩起訴**前**故意犯罪，在緩起訴期間受**有期徒刑以上**宣告確定
>   - ③緩起訴**期間**故意犯他罪，檢察官提起公訴或聲請簡易判決處刑
> - ②之要件：①**緩起訴前**犯罪；②**有期徒刑以上**（罰金不算）；③**在緩起訴期間內確定**（期滿後確定不算）。
> - 緩刑+有期徒刑：附緩刑之有期徒刑仍屬「有期徒刑以上刑之宣告」。

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 再議期間**屬於**得聲請回復原狀之期間。依§67（準用§318），因非可歸責於己之事由而遲誤期間，得聲請回復原狀。再議之7日期間屬得聲請回復原狀之期間，(A)稱「不屬於」有誤。 |
| (B) | ✓ | 依**§67 II**（告訴人聲請再議之情形），代理人（律師丙）之過失，依法**視為本人（甲）之過失**。丙律師的遺忘屬可歸責於代理人之過失，被視為甲之過失，因此甲不符合「非可歸責於己之事由」的要件，**不得聲請回復原狀**。 |
| (C) | ✗ | 再議聲請之回復原狀，**不是**向法院聲請。再議係向原作出不起訴處分之**檢察官**聲請，回復原狀亦應向**原檢察官**聲請，而非向法院聲請。 |
| (D) | ✗ | 雖然程序方向（向原檢察官聲請）較接近正確，但答案前提是「可以聲請回復原狀」，而依(B)的說明，因代理人過失視為本人過失，甲根本無法聲請回復原狀。故(D)的程序說明雖部分正確（向原檢察官），但整體前提錯誤。 |

> [!NOTE]
> **重點整理**
> - **§67 II**：代理人之過失，視為本人之過失（回復原狀之代理人過失歸責）。
> - 律師（代理人）遺忘提再議→視為甲的過失→不得依§67聲請回復原狀（因可歸責於己）。
> - 再議期間：收到不起訴處分書後**7日內**（§256 I）。
> - 回復原狀之聲請：向**原作出處分之機關**（即原檢察官，非法院）聲請。

### 32、107年第23題（原第58題）

> 甲因犯公共危險罪，經檢察官為緩起訴處分（下稱前案），緩起訴處分期間再犯竊盜罪，前案經檢察官撤銷緩起訴處分，並向法院聲請簡易判決處刑，法院審理後認定前案之罪證明確，但檢察官係於緩起訴期間屆滿後始撤銷緩起訴。法院應如何審判？

**(A)** 依簡易程序，依刑事訴訟法第303條第1款之規定判決公訴不受理。因檢察官聲請簡易判決處刑之程序違背規定  
**(B)** 改依通常程序，依刑事訴訟法第303條第1款之規定判決公訴不受理。因檢察官聲請簡易判決處刑之程序違背規定  
**(C)** 依簡易程序，判決有罪。因檢察官撤銷緩起訴處分之程序固有瑕疵，但聲請簡易判決處刑之程序並無瑕疵  
**(D)** 改依通常程序，依刑事訴訟法第303條第4款之規定判決公訴不受理。因緩起訴期滿未經撤銷，而有違背刑事訴訟法第260條之規定再行起訴之違法  

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 程序確有違法，應為不受理判決，但正確的是以「通常程序」諭知，且依§303 IV而非§303 I。(A)程序和條文均錯。 |
| (B) | ✗ | 程序改依通常程序是對的，但條文引用錯誤。應為**§303 IV**（起訴違反§260再行起訴之規定）而非§303 I（起訴程序違背規定之一般情形）。此外，問題根源在於緩起訴期滿後撤銷緩起訴無效→相當於緩起訴處分確定後再行起訴，違反§260。 |
| (C) | ✗ | 緩起訴期間屆滿後撤銷緩起訴**不發生撤銷效力**（因撤銷已逾期），緩起訴等同已期滿確定，依**§260**不得再行起訴或聲請簡易判決處刑，法院不得為有罪實體判決。 |
| (D) | ✓ | 緩起訴期間屆滿→緩起訴處分確定（等同不起訴確定）→檢察官在期滿後撤銷緩起訴，撤銷不生效力→再行聲請簡易判決處刑，違反**§260**（不起訴或緩起訴確定後不得再行起訴之限制）→法院應**改依通常程序**，依**§303 IV**諭知**公訴不受理**判決。 |

> [!NOTE]
> **重點整理**
> - **緩起訴期滿後撤銷緩起訴**：不發生撤銷效力；緩起訴相當於**確定**。
> - **§260**：不起訴處分或緩起訴期滿（確定）後，不得就同一案件再行起訴（例外：有新事實、新證據）。
> - 違反§260再行起訴（含聲請簡易判決處刑）→法院**改依通常程序**→**§303 IV**不受理判決。
> - §303 I（起訴程序不合法）vs §303 IV（違反§260限制）：此題適用§303 IV，非§303 I。

### 二、高頻考點摘要

| 考點 | 核心觀念 |
|------|----------|
| 逕行拘提共犯（§88-1 I②） | 現行犯供述＋共犯嫌疑重大＋情況急迫 → 得逕行拘提，事後補票 |
| 通知書 vs 傳票 | 通知書由司法警察官簽發、傳票由法官或檢察官簽發；法律效果不同 |
| 現行犯逮捕 | 不問何人、不限故意犯、無需令狀 |
| 另案監聽證據能力 | 7日內陳報法院＋法院審查認可 → 例外得為證據 |
| 強制採血/採尿許可 | 違反意願強制採取血液或尿液，須經法官或檢察官許可 |
| 偵查不公開之規範對象 | 拘束偵查機關人員及辯護人，不拘束被告自身 |
| 通緝犯之逮捕 | 任何利害關係人均得逮捕，為無令狀處分 |
| 撤銷緩起訴事由（§253-3） | 限故意犯罪＋有期徒刑以上刑之宣告，或未履行附負擔條件 |

### 三、關鍵區辨整理

| 概念A | 概念B | 區辨重點 |
|-------|-------|----------|
| 傳票 | 通知書 | 傳票由法官/檢察官簽發，不到場得拘提；通知書由司法警察官簽發，不到場報請檢察官核發拘票 |
| 拘提 | 逮捕 | 拘提須令狀（拘票）；逮捕（現行犯/通緝犯）為無令狀處分 |
| 逕行拘提 | 一般拘提 | 逕行拘提不經傳喚，先拘提後補票（§88-1）；一般拘提須經傳喚不到場，或有§76法定事由 |
| 本案監聽 | 另案監聽 | 本案監聽依通訊監察書合法取得；另案監聽須7日內陳報法院審查認可始有證據能力 |
| 現行犯逮捕 | 通緝犯逮捕 | 現行犯逮捕：不問何人均得逮捕；通緝犯逮捕：檢察官/司法警察官得拘提或逮捕，利害關係人亦得逮捕 |
| 強制採血 | 一般身體檢查 | 強制採血須經法官或檢察官許可（§205-2）；一般身體檢查之限制較寬，但檢查婦女須命醫師或婦女行之（§215） |
| GPS偵查 | 搜索/勘驗 | GPS偵查非搜索亦非勘驗，因欠缺法律授權，違反強制處分法定原則 |
| 不起訴處分 | 緩起訴處分 | 不起訴：終局不追訴；緩起訴：附條件暫緩起訴，期滿未撤銷→不起訴確定 |
| 不另為不起訴 | 獨立不起訴處分 | 不另為不起訴附隨於起訴書說明，毋庸送職權再議；獨立不起訴處分須依法送再議 |
| 個人法益犯罪 | 社會法益犯罪 | 個人法益犯罪有直接被害人、可提告訴再議；社會法益犯罪（如放火）無直接被害人 |
