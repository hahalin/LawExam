> 涵蓋範圍：國民參與審判之特殊程序規定、國民法官選任程序  
> 資料來源：108～114年司律一試刑事訴訟法考古題

---

## 壹、國民參與審判之特殊程序規定

### 1、114年第54題（原第54題）

> 行國民參與審判之案件與行一般通常審判程序之案件，關於訴訟程序之規定，下列敘述何者錯誤？

**(A)** 行國民參與審判之案件，檢察官起訴時，應向管轄法院提出起訴書，並不得將卷宗及證物一併送交法院；一般通常審判程序之案件，檢察官提起公訴，應由檢察官向管轄法院提出起訴書，且起訴時，應將卷宗及證物一併送交法院  
**(B)** 行國民參與審判及一般通常審判程序之案件，第一次準備程序期日之傳票或通知，至遲均應於 14 日前送達  
**(C)** 證物及書證之調查，行國民參與審判之案件，原則上由聲請調查之當事人向國民法官法庭提示或宣讀；一般通常審判程序之案件，則由審判長行之  
**(D)** 關於有罪判決書認定犯罪事實理由之記載，行國民參與審判之案件，得僅記載證據名稱及對重要爭點判斷之理由；一般通常審判程序之案件，則應詳細記載認定犯罪事實所憑之證據及其認定之理由、對於被告有利之證據不採納之理由等事項

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 行國民參與審判之案件，為落實**起訴狀一本主義**，檢察官起訴時應向法院提出起訴書，**不得將卷宗及證物一併送交法院**（國民法官法§43 I）。一般通常程序則依刑訴§264 III，起訴時應將卷宗及證物一併送交法院。兩者制度設計不同。 |
| (B) | ✗（本題正確答案 — 錯誤選項） | 一般通常程序之準備程序傳票至遲應於7日前送達（刑訴§272）。但國民參與審判案件之第一次準備程序期日之傳票或通知，至遲應於**21日前**送達（國民法官法§47 II），而非14日。兩者均非14日，此選項**錯誤**。 |
| (C) | ✓ | 國民參與審判案件之證物及書證調查，原則上由**聲請調查之當事人**向國民法官法庭提示或宣讀（國民法官法§73），以落實當事人進行主義。一般通常程序則由**審判長**行之（刑訴§164、§165）。 |
| (D) | ✓ | 國民參與審判案件之有罪判決書，得僅記載**證據名稱**及**對重要爭點判斷之理由**（國民法官法§86），以簡化判決書之製作。一般通常程序則應詳細記載認定犯罪事實所憑之證據及理由、不採納有利證據之理由等（刑訴§310）。 |

> [!NOTE]
> **重點整理**
> - 國民參與審判案件採**起訴狀一本主義**：檢察官不得將卷宗及證物隨起訴書送交法院（國民法官法§43 I）。
> - 國民參與審判案件之**準備程序傳票至遲應於21日前送達**（國民法官法§47 II），比一般通常程序之7日更為提前。
> - 證物及書證調查由**當事人**提示或宣讀（當事人進行主義），不同於一般通常程序由審判長行之。
> - 有罪判決書得**簡化記載**，僅記載證據名稱及重要爭點判斷理由（國民法官法§86）。

### 3、113年第53題（原第53題）

> 法院依據國民法官法完成審判程序後，進入評議階段，經職業法官與國民法官針對案情進行討論後，經評議有罪者五票（含一票職業法官），無罪者四票（含兩票職業法官）。此時合議庭應如何處理？

**(A)** 應為無罪判決  
**(B)** 適用國民法官法之案件均為重大刑事案件，合議庭應為一致決  
**(C)** 審判長應向國民法官提示審理過程中之特定重要證據，請國民法官重新審酌  
**(D)** 因有罪認定已取得多數票，且包括一名職業法官，因此審判長可以結束評議程序，並由合議庭作成有罪判決  

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 國民法官法庭由**3 名職業法官＋6 名國民法官＝9 人**組成。依**國民法官法§83 I**，有罪之認定應以**包含國民法官及法官雙方意見在內達「三分之二以上」之同意**決定之（即9人取三分之二＝6票以上）。本案有罪僅**五票**（未達 6 票門檻），不得為有罪認定；依**§83 IV**未達有罪必要同意人數時，應為**無罪之諭知**或為被告有利之認定。 |
| (B) | ✗ | 國民法官法採**特別多數決（三分之二）**（§83），**非一致決**。本選項錯誤。 |
| (C) | ✗ | 評議以審理所得心證之證據為依據，並無「審判長提示特定重要證據請重新審酌」之法定評議機制，且審判長不得以其意見不當影響國民法官（§82）。 |
| (D) | ✗ | 有罪五票雖含一職業法官，但**未達 6 票（2/3）門檻**，不得作成有罪判決。需注意：非僅看多數，而須達特別多數且雙方意見均含在內。 |

> [!NOTE]
> **重點整理**
> - **有罪認定門檻（國民法官法§83 I）**：需達**2/3 以上（6票／9人）**，且須**同時包含國民法官與職業法官各至少一人**之意見。
> - 未達有罪必要同意人數→**諭知無罪**或為被告有利認定（§83 IV）。
> - 量刑（未必要同意）：**過半數**且含雙方各至少一人；死刑：**2/3 以上**（§83 II、III）。
> - 陷阱：「一致決」、「只看多數決」、「含一職業法官即可定罪」均為錯誤。

## 貳、國民法官選任程序

### 2、114年第56題（原第56題）

> 有關國民法官之選任程序，下列何者錯誤？

**(A)** 國民法官選任程序不公開  
**(B)** 兩造均有不附理由之拒卻權，得行使之次數與被告被起訴之法條有關，起訴法條罪名越重，不附理由拒卻權次數越多，至多可達6次  
**(C)** 兩造附理由之拒卻權，無行使次數之限制  
**(D)** 無足夠候選國民法官可受抽選為國民法官或備位國民法官時，法院不得逕行抽選部分國民法官或備位國民法官，應重新踐行選任程序

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依國民法官法§27 I，國民法官之**選任程序不公開**，以保護候選國民法官之隱私並確保選任過程之公正性。 |
| (B) | ✗（本題正確答案 — 錯誤選項） | 兩造均有不附理由之拒卻權（國民法官法§29），但其行使次數**與被告被起訴之法條無關**。依法規定，檢察官與被告各得行使不附理由拒卻權之次數為固定數（各**4次**），並非依起訴罪名輕重而異。本選項關於「起訴法條罪名越重，次數越多，至多6次」之敘述錯誤。 |
| (C) | ✓ | 依國民法官法§28，兩造**附理由**之拒卻權（有因拒卻），**無行使次數之限制**，只要有法定事由即得行使。此與不附理由拒卻權之次數限制不同。 |
| (D) | ✓ | 依國民法官法§30，候選國民法官人數不足以抽選國民法官及備位國民法官時，法院**不得逕行抽選部分名額**，應**重新踐行選任程序**，以確保國民法官法庭之組成完整性。 |

> [!NOTE]
> **重點整理**
> - 國民法官選任程序**不公開**（國民法官法§27 I）。
> - **不附理由拒卻權**：檢察官與被告各得行使固定次數（各4次），與起訴法條無關（國民法官法§29）。
> - **附理由拒卻權**（有因拒卻）：無行使次數限制，只要有法定事由即可（國民法官法§28）。
> - 候選國民法官人數不足時，不得逕行部分抽選，應**重新踐行選任程序**（國民法官法§30）。

## 綜合整理

### 一、出題趨勢分析

| 年度 | 題號 | 考點 |
|------|------|------|
| 113 | 第53題 | 國民法官評議（特別多數決 2/3） |
| 114 | 第54題 | 國民參與審判與通常程序比較 |
| 114 | 第56題 | 國民法官選任程序 |

### 二、核心觀念速查

| 概念 | 要點 |
|------|------|
| 起訴狀一本主義 | 國民參與審判案件適用，檢察官不得將卷證隨起訴書送交法院 |
| 準備程序傳票送達期限 | 國民參與審判：21日前；一般通常程序：7日前 |
| 證據調查主體 | 國民參與審判：由當事人提示；一般通常程序：由審判長行之 |
| 判決書簡化記載 | 國民參與審判案件得僅記載證據名稱及重要爭點判斷理由 |
| 選任程序公開性 | 不公開 |
| 不附理由拒卻權 | 各方各4次，與起訴法條無關 |
| 附理由拒卻權 | 無次數限制 |

### 三、國民參與審判 vs 一般通常程序 對照表

| 項目 | 國民參與審判 | 一般通常程序 |
|------|-------------|-------------|
| 起訴方式 | 起訴狀一本主義（卷證不隨送） | 卷宗及證物一併送交法院 |
| 準備程序傳票送達 | 至遲21日前 | 至遲7日前 |
| 證據調查方式 | 當事人提示或宣讀 | 審判長行之 |
| 判決書記載 | 得簡化記載 | 應詳細記載 |
| 交互詰問 | 適用（§455-17 之例外適用於沒收程序，非本程序） | 適用 |
| 不附理由拒卻 | 各方各4次 | 無此制度 |
| 附理由拒卻 | 無次數限制 | 無此制度 |
| 選任程序 | 不公開 | 無此制度 |
