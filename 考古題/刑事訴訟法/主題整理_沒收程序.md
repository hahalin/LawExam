# 沒收程序 — 主題式考古題整理

> 涵蓋範圍：沒收之聲請與程序（緩起訴後沒收）、第三人參與沒收程序  
> 資料來源：108～114年司律一試刑事訴訟法考古題（不含113年）

---

## 壹、沒收之聲請與程序

### 1、109年第44題（原第44題）

> 甲因缺錢花用，竟持其所有之美工刀割破某戲院門口之海報，打算在網路上販售，而犯刑法第321條第1項第3款之攜帶兇器竊盜罪，經巡邏員警發覺而當場逮捕，嗣經檢察官偵查後，認應以緩起訴處分為適當，而依職權為緩起訴處分確定，甲所有供本件犯罪所用之美工刀，應如何處理？

**(A)** 由於檢察官已依職權為緩起訴處分，故已不得再向法院聲請沒收，惟依法得列為緩起訴之條件，命被告將該美工刀以沒收物處理  
**(B)** 檢察官既然已為緩起訴處分，表示本件事證明確，且甲亦未聲請再議，可認定甲亦承認該美工刀應沒收，故檢察官得逕自為沒收之處分，惟依法應通知甲  
**(C)** 沒收與否乃檢察官之職權，該物既然已為偵查機關所扣得，檢察官得自行決定是否予以沒收，惟甲若不服該沒收處分，得依刑事訴訟法第416條第1項之規定，聲請所屬法院撤銷或變更之  
**(D)** 由於檢察官已依職權為緩起訴處分，並未經起訴審判程序，故法院無法在有罪判決中一併宣告沒收，惟檢察官依法得另行聲請法院宣告沒收

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 緩起訴確定後，未經起訴審判程序，法院無法在有罪判決中宣告沒收。依刑訴§253-2 I 第6款，檢察官得將供犯罪所用之物列為**緩起訴條件**，命被告向指定機構繳交或交付沒收物處理。此為緩起訴案件中處理應沒收之物之適切方式。 |
| (B) | ✗ | **沒收係法院之權限**，檢察官不得逕自為沒收處分。即使被告未聲請再議，亦不得推定被告同意沒收。 |
| (C) | ✗ | 沒收並非檢察官之職權，須由法院宣告。檢察官不得自行決定沒收，此選項混淆了處分權限之歸屬。 |
| (D) | ✗ | 前半段正確（緩起訴確定後法院無法在有罪判決中宣告沒收）。但本題之最適切處理方式為依§253-2 I 第6款列為緩起訴條件，而非另行聲請法院宣告沒收。 |

> [!NOTE]
> **重點整理**
> - 緩起訴確定後，未經起訴審判程序，法院無法在有罪判決中一併宣告沒收。
> - **緩起訴附帶沒收之處理**：依刑訴§253-2 I 第6款，檢察官得將應沒收之物列為緩起訴條件，命被告交付沒收物處理。
> - 沒收係**法院之權限**，檢察官不得逕自為沒收處分。
> - 緩起訴條件包括：向公庫支付一定金額、向被害人道歉或賠償、提供義務勞務、交付沒收物等（§253-2 I）。

## 貳、第三人參與沒收程序

### 2、110年第57題（原第57題）

> 被告因違反證券交易法案件，經檢察官起訴。法院審理時，認第三人名下之證券交易帳戶財產與本案犯罪所得有關，財產可能被沒收，惟檢察官未聲請沒收第三人財產。依最高法院刑事大法庭裁定見解，法院應如何處理？

**(A)** 依控訴原則，法院不得命該第三人參與沒收程序  
**(B)** 法院得命該第三人參與沒收程序，但依控訴原則，不得為第三人財產沒收之宣告  
**(C)** 縱第三人聲請參與沒收程序，法院仍不得為第三人財產沒收之宣告  
**(D)** 法院得依職權裁定命第三人參與沒收程序，並諭知沒收

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 沒收具有**獨立之法律效果**，非控訴原則之範疇。依刑訴§455-12 I，法院認應沒收第三人財產者，得依職權裁定命第三人參與沒收程序，不以檢察官聲請為前提。 |
| (B) | ✗ | 法院不僅得命第三人參與沒收程序，且依最高法院刑事大法庭裁定見解，法院亦**得為第三人財產沒收之宣告**，不受控訴原則之限制。 |
| (C) | ✗ | 第三人聲請參與沒收程序後，法院自得依調查結果為沒收之宣告。此選項之見解不符實務立場。 |
| (D) | ✓ | 依最高法院刑事大法庭裁定見解，沒收為**刑罰及保安處分以外之獨立法律效果**，法院**得依職權裁定命第三人參與沒收程序，並諭知沒收**，不受檢察官是否聲請之限制。此見解突破傳統控訴原則，確立沒收之職權調查原則。 |

> [!NOTE]
> **重點整理**
> - 沒收為刑罰及保安處分以外之**獨立法律效果**，不受控訴原則拘束。
> - 法院得**依職權**裁定命第三人參與沒收程序（刑訴§455-12 I），不以檢察官聲請為前提。
> - 最高法院108年度台上大字第3594號刑事大法庭裁定確立：法院得依職權命第三人參與沒收程序並諭知沒收。
> - 第三人參與沒收程序應踐行正當法律程序，保障第三人之聽審權。

### 3、114年第38題（原第38題）

> 關於財產可能被沒收的第三人參與沒收程序之敘述，下列何者正確？

**(A)** 參與沒收程序之證據調查，不適用交互詰問規定  
**(B)** 第三人參與沒收程序之規定，亦適用於簡易程序及協商程序  
**(C)** 檢察官須於起訴時一併主張有無應沒收第三人財產之事實，若於審理中始認為應沒收第三人財產者，不得再為主張或聲請  
**(D)** 參與人經合法傳喚或通知而不到庭者，不得逕行判決

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依刑訴§455-17，參與沒收程序之審理，**不適用交互詰問之規定**。蓋第三人參與沒收程序之目的在確認財產之歸屬與沒收之合法性，其程序構造與一般刑事審判有別，故排除交互詰問之適用。 |
| (B) | ✗ | 依刑訴§455-12 III，第三人參與沒收程序之規定，於**簡易程序及協商程序不適用之**。因簡易程序及協商程序之審理方式較為簡化，不適合進行第三人參與沒收之複雜程序。 |
| (C) | ✗ | 檢察官不限於起訴時主張。法院於審理中發現應沒收第三人財產者，亦得依職權裁定命第三人參與（刑訴§455-12 I），檢察官於審理中亦得聲請。 |
| (D) | ✗ | 依刑訴§455-16，參與人經合法傳喚或通知而不到庭者，**得不待其陳述逕行判決**。此為確保訴訟程序不因參與人缺席而停滯之規定。 |

> [!NOTE]
> **重點整理**
> - 第三人參與沒收程序之證據調查，**不適用交互詰問**（刑訴§455-17）。
> - 第三人參與沒收程序**不適用於簡易程序及協商程序**（刑訴§455-12 III）。
> - 參與人經合法傳喚而不到庭，得**逕行判決**（刑訴§455-16）。
> - 法院於審理中發現應沒收第三人財產者，得**依職權**裁定命第三人參與。

## 綜合整理

### 一、出題趨勢分析

| 年度 | 題號 | 考點 |
|------|------|------|
| 109 | 第44題 | 緩起訴確定後之沒收程序 |
| 110 | 第57題 | 第三人參與沒收（法院職權） |
| 114 | 第38題 | 第三人參與沒收之程序規定 |

### 二、核心觀念速查

| 概念 | 要點 |
|------|------|
| 沒收之法律性質 | 刑罰及保安處分以外之獨立法律效果 |
| 緩起訴後沒收處理 | 依§253-2 I 第6款列為緩起訴條件，命被告交付沒收物 |
| 第三人參與沒收之發動 | 法院得依職權裁定，不以檢察官聲請為前提 |
| 沒收程序之證據調查 | 不適用交互詰問（§455-17） |
| 適用範圍例外 | 簡易程序及協商程序不適用第三人參與沒收規定 |

### 三、關鍵區辨整理

| 概念A | 概念B | 區辨重點 |
|-------|-------|----------|
| 有罪判決中沒收 | 緩起訴後沒收 | 有罪判決中法院得於判決主文一併宣告沒收；緩起訴後須透過緩起訴條件處理 |
| 法院職權沒收 | 檢察官聲請沒收 | 法院得依職權命第三人參與沒收並諭知沒收，不受檢察官是否聲請拘束 |
| 第三人沒收之通常程序 | 簡易程序／協商程序 | 通常程序適用第三人參與沒收；簡易程序及協商程序不適用 |
| 參與人到庭 | 參與人缺席 | 參與人到庭時得陳述意見；經合法傳喚不到庭者得逕行判決 |
