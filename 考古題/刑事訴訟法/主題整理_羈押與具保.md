# 羈押與具保 — 主題式考古題整理

> 涵蓋範圍：羈押之要件、羈押審查程序與辯護、具保與停止羈押、限制出境出海  
> 資料來源：108～114年司律一試刑事訴訟法考古題（不含113年）

---

## 壹、羈押之要件

### 1、109年第3題（原第38題）

> 甲為17歲高二男生，精力旺盛，喜看A片，與同校高一未滿16歲女生乙、丙、丁、戊於1個月內先後各發生性行為1次，嗣以再與乙性交時，為乙之導師發覺報警移送檢察官偵查，乙、丙、丁、戊及其他有告訴權之人均未提出告訴。下列敘述何者正確？

**(A)** 甲反覆觸犯刑法第227條之罪，法院得依刑事訴訟法第101條之1之規定羈押之  
**(B)** 甲觸犯刑法第227條之罪，因不屬於預防性羈押之罪名，法院不得依刑事訴訟法第101條之1之規定羈押之  
**(C)** 甲已觸犯刑法第227條之罪4次，有反覆實施之虞，法院得依刑事訴訟法第101條之1之規定羈押之  
**(D)** 甲所犯之罪，係告訴乃論之罪，未經告訴，法院不得依刑事訴訟法第101條之1之規定羈押之

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | §101-1第1項並未列入「反覆觸犯特定罪名」之一般性要件。本選項之表述方式未正確引述法條要件。 |
| (B) | ✗ | 依§101-1 I④，刑法第227條之罪（對未滿16歲之人為性交）**屬於預防性羈押之列舉罪名**，法院得予羈押。 |
| (C) | ✓ | 依**§101-1 I④**，被告犯刑法§227之罪，其犯罪嫌疑重大，有事實足認為有**反覆實施同一犯罪之虞**者，法院得命羈押之（預防性羈押）。甲已對4名未滿16歲女生各為性交1次，顯有反覆實施之虞。**預防性羈押不以告訴為前提**。 |
| (D) | ✗ | 預防性羈押（§101-1）為強制處分，其目的在**預防再犯**，與案件是否告訴乃論無關。未經告訴僅影響訴追程序，不影響羈押之法定要件。 |

> [!NOTE]
> **重點整理**
> - **預防性羈押（§101-1）**：列舉特定罪名 ＋ 犯罪嫌疑重大 ＋ 有事實足認有反覆實施之虞。
> - 刑法§227（與未滿16歲之人為性交）屬預防性羈押之列舉罪名（§101-1 I④）。
> - 預防性羈押**不以告訴為前提**，告訴乃論之犯罪仍得予以預防性羈押。
> - 「反覆實施之虞」須有**事實基礎**（如已多次犯同一罪名）。

### 2、112年第3題（原第38題）

> 甲某夜因殺人罪之現行犯，為警方逮捕，翌日中午經檢察官偵辦後，認有逃亡之疑慮，向管轄法院聲請羈押，並經乙法官訊問。下列敘述何者最為正確？

**(A)** 乙法官審核該羈押案件，日後仍得辦理同一案件之審判事務  
**(B)** 乙法官審核該羈押案件，使用之證據應具有證據能力且經過法定程序調查  
**(C)** 乙法官訊問後，認甲犯罪嫌疑重大且有羈押原因，即可裁定羈押  
**(D)** 甲被警方逮捕至羈押前期間，得折算裁判確定前之羈押日數

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依實務見解，偵查中審核羈押之法官，不當然應迴避日後同一案件之審判。但此為爭議問題。依§26-1，偵查中審核羈押聲請之法官，**得**辦理同一案件之審判事務（現行法未要求應迴避）。然而本選項敘述方式未精確。 |
| (B) | ✗ | 羈押審查屬**令狀審查程序**，採**自由證明**即可，不要求所有證據均須具有嚴格之證據能力，亦不須經法定之嚴格證據調查程序。 |
| (C) | ✗ | 依§101，羈押須具備：①犯罪嫌疑重大；②有法定羈押原因（逃亡之虞、滅證之虞等）；③有**羈押之必要性**。僅有犯罪嫌疑重大及羈押原因，若無羈押必要性，不得裁定羈押。 |
| (D) | ✓ | 依**§108 IV**準用§37-2，逮捕後至羈押前之拘束人身自由期間，**得折算裁判確定前之羈押日數**。此為保障被告權益之規定。 |

> [!NOTE]
> **重點整理**
> - 羈押三要件：①犯罪嫌疑重大；②有法定羈押原因（§101 I各款）；③有**羈押必要性**（比例原則）。
> - 羈押審查採**自由證明**，不適用嚴格證明法則。
> - 逮捕至羈押前之拘束期間 → **得折算羈押日數**。
> - 偵查中審核羈押之法官，現行法未規定應迴避日後之審判事務（§26-1）。

### 3、114年第10題（原第45題）

> 甲涉嫌殺人未遂，經檢察官傳喚到庭，檢察官訊問後。下列處置何者違法？

**(A)** 認甲涉嫌尚非重大，逕予釋放  
**(B)** 認甲無羈押必要，諭知具保、責付或限制住居  
**(C)** 認甲有羈押原因與必要，逕行聲請法院羈押之  
**(D)** 認甲有羈押原因與必要，應予逮捕並告知逮捕所依據之事實後，再聲請法院羈押之

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 檢察官訊問後認涉嫌尚非重大，得逕予釋放，此為檢察官之職權判斷，合法。 |
| (B) | ✓ | 依§93 III，檢察官訊問後認被告犯罪嫌疑重大但無羈押必要者，得逕命**具保、責付或限制住居**。此為羈押之替代處分，合法。 |
| (C) | ✗ | 依**§228 IV**、**§93**，檢察官認有羈押原因及必要時，須先**逮捕被告**並告知其逮捕事由，再聲請法院羈押。不得在未逮捕被告之情形下逕行聲請羈押。聲請羈押前須踐行逮捕程序，以保障被告之人身自由。本選項「逕行聲請法院羈押」缺少逮捕程序，**程序違法**。 |
| (D) | ✓ | 依§228 IV、§93，檢察官認有羈押原因與必要時，應先**逮捕被告並告知逮捕事由**，再聲請法院羈押。此為正當法律程序之要求，合法。 |

> [!NOTE]
> **重點整理**
> - 檢察官聲請羈押之前提：須先**逮捕被告**並告知逮捕所依據之事實（§228 IV、§93）。
> - 不得在未逮捕之情形下逕行聲請羈押。
> - 偵查中聲請羈押之程序：逮捕 → 告知逮捕事由 → 聲請法院羈押 → 法院訊問 → 裁定。
> - 替代處分：犯罪嫌疑重大但無羈押必要 → 具保、責付或限制住居。

## 貳、羈押審查程序與辯護

### 4、108年第10題（原第45題）

> 甲因涉嫌持槍擄人勒贖，經依法通緝期間，檢察官訊問證人乙供稱曾無意中窺知甲持有制式手槍；訊問證人丙曾目擊甲夥同其幫派5人涉嫌擄丁勒贖；丁趁機脫身後，再訊問丁遭受甲挾持傷害經過，並調得案發現場路口監視器錄影。乙、丙因恐被甲報復，請求不要揭露其身分。其後緝獲甲，檢察官以甲有脅迫乙、丙、丁串證之虞，有羈押之必要，向法官聲請羈押甲。關於相關偵查卷證資料之閱覽，下列敘述何者正確？

**(A)** 法院須命提出所有原卷證給甲及其辯護人知悉  
**(B)** 僅命檢察官說明應羈押理由，不須提出任何證據給甲及其辯護人知悉  
**(C)** 檢察官應提出丁偵訊筆錄及路口監視器錄影帶給甲及其辯護人知悉。但對乙、丙之偵訊筆錄，則另分卷敘明理由，適當限制甲及其辯護人獲知  
**(D)** 可禁止甲及其辯護人獲知乙、丙、丁筆錄

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依§33-1，偵查中羈押審查程序，檢察官得向法院請求以適當方式**限制或禁止**被告及辯護人獲知部分卷證資料（如涉及證人安全者）。無須一律提出所有原卷證。 |
| (B) | ✗ | 依§33-1，羈押審查時辯護人原則上有**卷證獲知權**。完全不提出任何證據將侵害被告之防禦權，違反正當法律程序。 |
| (C) | ✓ | 依**§33-1**，辯護人原則上得獲知羈押審查之卷證資料。惟乙、丙因恐被甲報復而請求不揭露身分，檢察官得向法院請求將乙、丙之偵訊筆錄**另分卷敘明理由**，適當限制甲及其辯護人獲知。丁之筆錄及監視器錄影則應提出供被告及辯護人知悉。此為**卷證獲知權之例外限制**。 |
| (D) | ✗ | 不得全面禁止甲及其辯護人獲知所有筆錄。限制卷證獲知權須有正當理由（如證人安全），且應以適當方式為之，不得全面禁止。丁之筆錄無特別限制理由，不應禁止獲知。 |

> [!NOTE]
> **重點整理**
> - **羈押審查之卷證獲知權（§33-1）**：辯護人原則上得檢閱羈押聲請書及相關卷證。
> - **例外限制**：檢察官得向法院請求適當限制或禁止被告及辯護人獲知部分卷證（如涉及證人安全、有串證之虞等），須另分卷敘明理由。
> - 限制須具**正當理由**且應以適當方式為之，不得全面禁止所有卷證之獲知。
> - 此為平衡被告防禦權與證人安全之制度設計。

### 5、109年第15題（原第50題）

> 檢察官向法院聲請羈押被告，地方法院法官在決定是否羈押被告時，關於羈押程序之調查，下列敘述何者最為正確？

**(A)** 法官在所有令狀審查程序，都是自由證明即可，不必經嚴格證明，故法官認為沒有訊問被告之必要，只要審查檢察官檢送之書面資料及筆錄即可  
**(B)** 羈押被告是嚴重侵犯人身自由的強制處分，不只要訊問被告，所有證據都應經嚴格證明  
**(C)** 羈押審查程序都必須有檢察官、被告及辯護人在場，由雙方於審查程序加以攻防、辯論  
**(D)** 法官依法必須訊問被告，但羈押審查之決定只要自由證明即可

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 雖然令狀審查一般採自由證明，但法官**依法必須訊問被告**（§101 I），不得僅審查書面資料即為羈押裁定。訊問被告為強制規定，不得省略。 |
| (B) | ✗ | 羈押審查採**自由證明**，不要求所有證據均經嚴格證明。但法官必須訊問被告，此為程序上之強制要求。 |
| (C) | ✓ | 依**§101 I、§31-1**，偵查中羈押審查程序須有**檢察官到場陳述聲請羈押之理由及事實**，被告及辯護人亦應在場（強制辯護案件應有辯護人到場），使雙方得於審查程序**進行攻防辯論**，以保障被告之防禦權與聽審權。 |
| (D) | ✗ | 法官依法必須訊問被告為正確。羈押審查採自由證明亦為正確。但本選項之組合不如選項(C)完整，(C)更精確描述了羈押審查程序之完整要求（包含檢察官、被告、辯護人三方到場及攻防辯論）。 |

> [!NOTE]
> **重點整理**
> - 羈押審查程序三大要求：①**法官必須訊問被告**；②**檢察官到場陳述理由**；③**辯護人在場**（強制辯護）。
> - 羈押審查之證明程度：**自由證明**即可，不適用嚴格證明法則。
> - 羈押審查採**對審架構**：檢察官與被告（辯護人）雙方攻防辯論。
> - 自由證明 ≠ 不訊問被告：訊問被告為法定程序義務。

### 6、110年第3題（原第38題）

> 甲、乙、丙三人商量好，由丙提供帳戶及提款卡、密碼給乙以領款朋分，甲以電話行騙被害人，果然使被害人匯款到丙帳戶，因被害人之家人察覺有異報警，乙於領款時為警當場查獲，並扣得提款卡及聯繫的行動電話。乙於偵查中委任辯護人丁，並辯稱是不詳之人要他領款，經檢察官聲請羈押。法官在審理檢察官之羈押聲請時，丁得否向法院請求閱覽檢察官提出之羈押聲請卷宗及證物？

**(A)** 可以，但檢察官得向法院請求以適當之方式限制或禁止丁獲知部分羈押聲請卷宗及證物  
**(B)** 可以，且法院依法不得予以限制閱覽  
**(C)** 不可以，僅乙有卷證獲知權  
**(D)** 不可以，因法院尚未決定羈押

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依**§33-1**，偵查中辯護人得向法院請求閱覽檢察官提出之羈押聲請卷宗及證物，此為辯護人之**卷證獲知權**。惟檢察官得向法院請求以適當方式**限制或禁止**辯護人獲知部分卷證（如有串證之虞或涉及證人安全），須另分卷敘明理由。 |
| (B) | ✗ | 辯護人雖有卷證獲知權，但**非不得限制**。§33-1明定檢察官得請求法院適當限制或禁止辯護人獲知部分卷證。 |
| (C) | ✗ | 辯護人為被告行使防禦權之重要輔助者，**辯護人亦有卷證獲知權**（§33-1），非僅被告本人始得獲知。 |
| (D) | ✗ | 卷證獲知權之行使時點為**羈押審查程序中**，法院尚未決定是否羈押前，辯護人即得請求閱覽卷宗，以利為被告進行有效辯護。 |

> [!NOTE]
> **重點整理**
> - 偵查中羈押審查之**辯護人卷證獲知權（§33-1）**：辯護人得請求閱覽羈押聲請卷宗及證物。
> - 卷證獲知權之**例外限制**：檢察官得請求法院以適當方式限制或禁止辯護人獲知部分卷證，須另分卷敘明理由。
> - 卷證獲知權在**羈押審查前**即得行使，非待法院裁定後始可。
> - 辯護人與被告均有卷證獲知權，但辯護人之獲知範圍可能受限制。

### 7、110年第4題（原第39題）

> 關於偵查中羈押審查程序，依現行規定，下列敘述何者錯誤？

**(A)** 被告未選任辯護人者，審判長應指定公設辯護人或律師為被告辯護。但等候指定辯護人逾 4 小時未到場，經被告主動請求訊問者，不在此限  
**(B)** 選任辯護人無正當理由而不到庭者，審判長得指定公設辯護人或律師  
**(C)** 除法律另有規定外，辯護人得檢閱卷宗及證物並得抄錄或攝影  
**(D)** 有辯護人之被告經法院許可者，被告得在確保卷宗及證物安全之前提下檢閱之

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依**§31-1**，偵查中羈押審查屬**強制辯護**案件，未選任辯護人者，審判長應指定公設辯護人或律師。但等候指定辯護人逾**4小時**未到場，經**被告主動請求訊問**者，得例外進行（§31 V）。 |
| (B) | ✓ | 依§31 IV，選任辯護人無正當理由不到庭者，審判長得**另行指定**公設辯護人或律師，以確保被告之辯護權不因辯護人缺席而受損害。 |
| (C) | ✓ | 依§33-1，偵查中羈押審查程序，辯護人得檢閱卷宗及證物，並得抄錄或攝影，此為辯護人之卷證獲知權。 |
| (D) | ✗ | 依§33-1，偵查中羈押審查程序之卷證獲知權**限於辯護人**行使。被告**本人不得自行檢閱卷宗及證物**，僅辯護人得為之。本選項稱「被告得在確保安全之前提下檢閱」，與現行法規定不符。（此規定見於審判中§33，偵查中羈押審查則無。） |

> [!NOTE]
> **重點整理**
> - 偵查中羈押審查程序屬**強制辯護**（§31-1）：未選任辯護人 → 審判長應指定。
> - 等候指定辯護人逾**4小時**＋被告主動請求訊問 → 得例外進行。
> - 偵查中羈押審查之卷證獲知權**限辯護人行使**，被告本人不得自行檢閱。
> - 區分偵查中與審判中之卷證閱覽權：審判中被告亦得閱卷（§33），偵查中羈押審查限辯護人。

### 8、111年第1題（原第36題）

> 甲涉嫌殺人未遂，經法院以有逃亡及串供之虞裁定羈押，茲因所有共犯及證人均已傳喚訊問完畢，甲之辯護人乙律師聲請法院撤銷羈押，下列敘述何者最為正確？

**(A)** 甲之所有共犯及證人均已傳訊完畢無勾串之虞，羈押原因已消滅，法院應撤銷羈押  
**(B)** 所有共犯及證人雖已傳訊完畢，但仍有可能再行勾串，法院不應撤銷羈押  
**(C)** 甲羈押之原因有二，縱已無勾串之虞，仍需依事實認定是否無逃亡之虞，然後才審酌是否撤銷羈押  
**(D)** 甲僅係未遂犯應無逃亡之虞，應撤銷羈押

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 甲之羈押原因有**二**：逃亡之虞＋串供之虞。僅因串供之虞消滅，不代表所有羈押原因均已消滅。若逃亡之虞仍存在，羈押原因未完全消滅，法院不當然應撤銷羈押。 |
| (B) | ✗ | 所有共犯及證人均已傳訊完畢，客觀上串供之虞已相當程度降低。僅憑抽象可能性主張「仍有可能勾串」而拒絕審酌，不符合比例原則。 |
| (C) | ✓ | 依**§107**，羈押之原因消滅者，法院應撤銷羈押。本案羈押原因有二（逃亡之虞＋串供之虞），縱串供之虞因共犯及證人傳訊完畢而消滅，法院仍須**逐一審酌**其餘羈押原因（逃亡之虞）是否仍存在，始能決定是否撤銷羈押。須**全部**羈押原因消滅，方應撤銷。 |
| (D) | ✗ | 未遂犯與有無逃亡之虞無必然關聯。逃亡之虞應依**具體事實**（如有無固定住居所、犯罪嚴重程度、人際關係等）判斷，不得僅以犯罪為未遂而當然認定無逃亡之虞。 |

> [!NOTE]
> **重點整理**
> - 撤銷羈押（§107）：**全部**羈押原因消滅 → 法院**應**撤銷羈押。
> - 羈押原因有數個時，須**逐一審酌**每一原因是否仍存在，非僅單一原因消滅即應撤銷。
> - 逃亡之虞：依具體事實判斷，與犯罪既遂或未遂無必然關聯。
> - 辯護人得聲請法院撤銷羈押（§107）。

## 參、具保與停止羈押

### 9、108年第18題（原第53題）

> 甲因販賣毒品罪嫌，經法院予以羈押，臺灣高等法院判決後，甲上訴於最高法院，並聲請具保停止羈押，此項聲請，應由何法院裁定？

**(A)** 案件已上訴於最高法院，應由最高法院裁定  
**(B)** 如卷宗及證物已送交最高法院，由最高法院裁定；尚未送交者，由臺灣高等法院裁定  
**(C)** 不論卷宗及證物是否已送交最高法院，均由臺灣高等法院裁定  
**(D)** 甲提出上訴書狀前，由臺灣高等法院裁定；提出上訴書狀後，由最高法院裁定

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 最高法院為**法律審**，不進行事實調查，且實務上不處理具保停止羈押之聲請。應由**事實審法院**（即二審高等法院）裁定。 |
| (B) | ✗ | 具保停止羈押之管轄法院不以卷宗及證物之所在為區分標準。依實務見解，一律由原判決之事實審法院裁定。 |
| (C) | ✓ | 依**§121 I**但書及實務見解，案件上訴於最高法院後，具保停止羈押之聲請，**不論卷宗及證物是否已送交最高法院**，均由原判決之事實審法院（即**臺灣高等法院**）裁定。因最高法院為法律審，不宜審酌具保之必要性。 |
| (D) | ✗ | 管轄法院之判斷不以上訴書狀之提出時點為標準，而係依事實審與法律審之功能區分。 |

> [!NOTE]
> **重點整理**
> - 案件上訴**最高法院**後，具保停止羈押之聲請 → 由**原判決之事實審法院**裁定（§121 I但書）。
> - 最高法院為法律審，不處理具保停止羈押之聲請。
> - **不論卷宗是否已送交**最高法院，均由高等法院裁定。
> - 具保停止羈押涉及事實審酌（如有無逃亡之虞等），由事實審法院處理較為適當。

### 10、111年第9題（原第44題）

> 關於羈押被告之敘述，下列何者正確？

**(A)** 甲因涉犯最輕本刑為10年以上有期徒刑之重罪嫌疑重大，又因另案通緝中，有逃亡之虞，經檢察官訊問後，檢察官得命令將甲羈押  
**(B)** 乙涉犯最重本刑為 3 年以下有期徒刑之罪嫌疑重大，檢察官不得向法院聲請羈押乙，若檢察官向法院聲請羈押，法院應裁定駁回其聲請  
**(C)** 丙女涉嫌販賣毒品，經法院裁定羈押，嗣丙女向法院提出其懷孕6月之醫院診斷證明書，聲請具保停止羈押，若法院調查屬實，應准予具保停止羈押  
**(D)** 法院於審判中裁定羈押丁，不得逾 3 月，如認需延長羈押，每次不得逾 3 月，且最多以延長 3 次為限

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依**§101 I**，羈押須由**法院裁定**，檢察官不得自行命令羈押。檢察官僅得**聲請**法院裁定羈押。不論犯罪多嚴重，羈押權限均屬法院，此為法官保留原則之體現。 |
| (B) | ✗ | 現行法並無以「最重本刑」限制羈押聲請之規定。§101 I③重罪羈押原因以「最輕本刑5年以上有期徒刑」為要件，但其他羈押原因（逃亡之虞§101 I①、滅證之虞§101 I②）不以重罪為限。乙若有逃亡或滅證之虞，仍得聲請羈押。 |
| (C) | ✓ | 依**§114③**，被告**懷胎5月以上**者，法院**應命具保、責付或限制住居停止羈押**，為強制停止羈押之法定事由。丙女懷孕6月，已逾5月之門檻，法院調查屬實後**應准予具保停止羈押**。 |
| (D) | ✗ | 依§108，審判中羈押期間每次不得逾**3月**，延長次數之限制視罪名輕重而定。重罪案件（如最重本刑10年以上）之延長次數限制較寬，並非一律以延長3次為限。 |

> [!NOTE]
> **重點整理**
> - **強制停止羈押（§114）**之法定事由：①所犯最重本刑3年以下有期徒刑、拘役或專科罰金之罪；②**懷胎5月以上**或生產後2月未滿；③現罹疾病非保外治療不能維持生命者。
> - 羈押為**法官保留**，檢察官僅得聲請，不得命令羈押。
> - 羈押原因（逃亡之虞、滅證之虞）不以重罪為限。
> - 懷胎5月以上 → 法院**應准**停止羈押（強制規定）。

## 肆、限制出境出海

### 11、110年第9題（原第44題）

> 關於限制出境、出海之敘述，下列何者錯誤？

**(A)** 偵查中檢察官認為有必要且具備法定事由者，得逕行限制被告出境、出海，無須向法院聲請  
**(B)** 被告雖經法院限制出境、出海，但法院一旦為無罪判決，即視為撤銷  
**(C)** 經法院限制出境、出海者，法院僅得依職權為變更，但不得逕行撤銷  
**(D)** 被告如果符合命具保之法定事由者，依法亦得命限制出境、出海

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依**§93-2**，偵查中檢察官認有必要且具備法定事由者，得**逕行限制**被告出境、出海，無須向法院聲請。但限制期間不得逾**8月**，如需延長應向法院聲請。 |
| (B) | ✓ | 依§93-6，法院為**無罪**、免訴、不受理、管轄錯誤、駁回起訴判決者，限制出境出海之處分即**視為撤銷**。無罪判決使限制之基礎喪失，故當然撤銷。 |
| (C) | ✗ | 依**§93-4**，經法院限制出境出海者，法院得依職權或依當事人聲請為**變更或撤銷**。本選項稱「僅得依職權為變更，但不得逕行撤銷」，為**錯誤**。法院得變更亦得撤銷；且聲請並不限於職權，當事人亦得聲請。 |
| (D) | ✓ | 依§93-2，被告若符合命具保之法定事由（§101 I各款），依法亦得命限制出境出海。限制出境出海為具保之替代或附加處分。 |

> [!NOTE]
> **重點整理**
> - **限制出境出海（§93-2～§93-6）**為109年增訂之新制度。
> - 偵查中：檢察官得**逕行限制**，期間不逾8月；延長應聲請法院裁定。
> - 法院得依職權或依當事人聲請**變更或撤銷**限制出境出海（§93-4）。
> - 法院為無罪等判決 → 限制出境出海**視為撤銷**（§93-6）。
> - 限制出境出海之法定事由準用具保之要件（§93-2）。
