## 壹、上訴期間與程式要件（送達、期間計算、合法上訴）

### 1、111年第42題（原第42題）

> 甲因竊盜案經法院審理後判處有期徒刑一年，法院宣判後，甲因另案於 3 月 1 日入獄服刑，法院知悉後將判決書分別於： 3 月 5 日送達甲之住所，由甲之同居父親簽收； 3 月 6 日囑託甲服刑之監獄長官送達甲簽收； 3 月 7 日送達甲指定之送達代收人律師乙簽收。如甲不服判決，至遲須在何日前提起上訴？

**(A)** 3月25日  
**(B)** 3月26日  
**(C)** 3月27日  
**(D)** 3月29日

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 若以3月5日住所送達起算20日，期滿日為3月25日。惟甲已入獄服刑，住所送達由同居父親簽收雖屬補充送達，但法院知悉甲在監，依法應囑託監獄長官送達本人，以3月5日起算並不正確。 |
| (B) | ✓ | 甲已在監服刑，法院知悉後依刑訴§56準用民訴送達規定，應囑託監獄長官送達。**3月6日囑託監獄長官送達甲本人簽收**，為對甲本人之合法送達。上訴期間為**20日**（刑訴§349 I），自3月6日之翌日（3月7日）起算20日，期滿日為**3月26日**。甲至遲須於3月26日前提起上訴。 |
| (C) | ✗ | 若以3月7日送達代收人律師乙起算20日，為3月27日。惟送達效力以最先合法送達為準，3月6日囑託送達已先生效。 |
| (D) | ✗ | 計算錯誤。無論以何日起算，均不會得出3月29日之結果。 |

> [!NOTE]
> **重點整理**
> - 在監被告之送達，法院知悉後應**囑託監獄長官送達本人**（刑訴§56準用民訴規定）。
> - 上訴期間為判決送達後**20日**內（刑訴§349 I）。
> - 有多次送達時，以**最先合法送達**之日起算上訴期間。
> - 期間之計算：始日不算入（刑訴§65 I），自送達翌日起算。

### 2、112年第50題（原第50題）

> 被告之住居所因不在法院所在地，乃向法院陳明以律師甲為送達代收人，法院嗣向甲送達判決書。被告提起上訴之期間，應自何時起算及是否應扣除在途期間？

**(A)** 自該判決書送達予甲後起算，不用扣除在途期間  
**(B)** 自該判決書送達予甲後起算，應扣除在途期間  
**(C)** 自甲實際轉交該判決書予被告之日起算，不用扣除在途期間  
**(D)** 自甲實際轉交該判決書予被告之日起算，應扣除在途期間

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 送達予送達代收人時即生送達效力，此部分正確。但被告住居所不在法院所在地，依刑訴§66，**應扣除在途期間**。 |
| (B) | ✓ | 依刑訴§62準用民訴§137，向送達代收人為送達者，**於送達予代收人時即生送達效力**，無須待代收人實際轉交被告。上訴期間自送達予甲之翌日起算。又被告住居所不在法院所在地，依刑訴§66規定，**應扣除在途期間**，以保障被告之上訴權。 |
| (C) | ✗ | 送達效力自送達代收人時即生，不以實際轉交為生效時點。 |
| (D) | ✗ | 起算日錯誤，同(C)之說明。 |

> [!NOTE]
> **重點整理**
> - 送達代收人收受送達時，即生**送達效力**，不以實際轉交當事人為生效要件。
> - 被告住居所不在法院所在地者，上訴期間應**扣除在途期間**（刑訴§66）。
> - 在途期間依司法院所定標準計算，目的在保障遠地當事人之訴訟權。

### 3、109年第58題（原第58題）

> 有關不服地方法院第一審判決提起上訴，其上訴理由記載是否合法，依實務見解，下列敘述何者正確？

**(A)** 不服第一審通常程序判決，上訴第二審時，上訴書狀僅記載「量刑過重」，為合法上訴  
**(B)** 第一審判處死刑，被告上訴第二審時，其上訴書狀僅記載「量刑過重」，為合法上訴  
**(C)** 不服第一審通常程序判決，上訴第二審時，如上訴書狀未敘述上訴理由，法院得直接判決駁回  
**(D)** 不服第一審簡易判決，上訴第二審時，上訴書狀應記載具體理由，否則上訴不合法

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 不服第一審通常程序判決上訴第二審，依刑訴§361 II，上訴書狀應敘述**具體理由**。僅記載「量刑過重」而未具體說明原審量刑如何違法或不當，屬不具體之上訴理由，上訴不合法。 |
| (B) | ✗ | 依刑訴§344 V，宣告死刑之案件，法院應依職權逕送上訴，無待被告提起。但若被告自行上訴，仍應符合上訴書狀敘述具體理由之要求。僅記載「量刑過重」仍非具體理由。 |
| (C) | ✗ | 上訴書狀未敘述上訴理由，法院應先定期間命補正（刑訴§361 III），**不得直接判決駁回**。經定期補正逾期未補正者，始得以裁定駁回上訴。 |
| (D) | ✓ | 依刑訴§455-1 III，不服簡易判決上訴第二審（管轄之地方法院合議庭），**準用第三審上訴之規定**（刑訴§382 I），上訴書狀應記載**具體理由**並指摘原判決違背法令之處。未記載具體理由者，上訴不合法。 |

> [!NOTE]
> **重點整理**
> - 通常程序上訴二審：須敘述**具體理由**（刑訴§361 II）；未敘述者，法院應先命**補正**（§361 III）。
> - 簡易判決上訴二審：準用第三審上訴規定（刑訴§455-1 III），須記載具體理由，否則上訴不合法。
> - 宣告死刑或無期徒刑之案件，法院應**依職權逕送上訴**（刑訴§344 V）。

### 4、111年第50題（原第50題）

> 原審之辯護人收受判決正本，與被告討論後，經被告授意提起上訴。該辯護人應以何人之名義提起上訴，始為合法？

**(A)** 以被告之名義提起上訴。因原審辯護人之上訴，性質上為代理上訴  
**(B)** 以辯護人之名義提起上訴。因原審之辯護人得為被告之利益而上訴  
**(C)** 以被告之名義提起上訴。因原審之辯護人得為被告之利益而獨立上訴  
**(D)** 以辯護人或被告之名義提起上訴均可。因原審之辯護人得為被告之利益而上訴，被告則為有上訴權之當事人

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依刑訴§346，原審之**代理人或辯護人**得為被告之利益而上訴，但**非獨立上訴權**。辯護人為被告之利益上訴，係**代理上訴**，應以**被告名義**提起上訴。辯護人經被告授意提起上訴，更顯示代理性質，應以被告名義為之。 |
| (B) | ✗ | 辯護人雖依§346得為被告利益上訴，但此非獨立上訴權，不得以辯護人自己名義提起。以辯護人名義提起上訴，不合法。 |
| (C) | ✗ | 以被告名義上訴為正確，但理由有誤。辯護人之上訴並非「獨立上訴」，而係**代理上訴**。獨立上訴係指被告之法定代理人或配偶等依§345規定所為之上訴，不待被告授意。 |
| (D) | ✗ | 不得以辯護人名義提起上訴。辯護人上訴之性質為代理被告上訴，須以被告名義為之。 |

> [!NOTE]
> **重點整理**
> - 辯護人依刑訴§346得為被告利益上訴，性質為**代理上訴**，應以**被告名義**提起。
> - **獨立上訴**（刑訴§345）：被告之法定代理人或配偶得**獨立**為被告利益上訴，不待被告授意。
> - 代理上訴 vs 獨立上訴之區分：辯護人→代理上訴（被告名義）；法定代理人、配偶→獨立上訴（得以自己名義）。

### 5、111年第60題（原第60題）

> 下列關於第二審上訴之敘述，何者正確？

**(A)** 提起第二審上訴，應由第一審法院先為審查。第一審法院如認上訴已逾上訴期間，應以判決駁回  
**(B)** 提起第二審上訴，應由第一審法院先為審查。第一審法院如認上訴書狀未敘述具體理由，應逕以裁定駁回  
**(C)** 原審之辯護人得為被告之利益提起上訴，故上訴狀得以辯護人自己之名義提起上訴  
**(D)** 被告於第一審判決後死亡，配偶已失其獨立上訴權，不得再以自己之名義提起上訴

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 第一審法院如認上訴逾期，應以**裁定**駁回（刑訴§362），非以判決駁回。判決與裁定之區分為重要程序概念。 |
| (B) | ✗ | 上訴書狀未敘述具體理由，第一審法院應先**定期間命補正**（刑訴§361 III），不得逕以裁定駁回。經定期補正逾期仍未補正者，始得裁定駁回。 |
| (C) | ✗ | 辯護人依§346為被告利益上訴，係代理上訴，應以**被告名義**提起，不得以辯護人自己名義提起。 |
| (D) | ✓ | 依刑訴§345，配偶之獨立上訴權係為被告之利益而設。被告於第一審判決後**死亡**，依刑訴§303④應諭知不受理判決，訴訟程序因被告死亡而終結。配偶已**失其獨立上訴權**，不得再以自己名義提起上訴。被告死亡後，刑罰權已無行使之對象，上訴已無實益。 |

> [!NOTE]
> **重點整理**
> - 第一審法院審查上訴逾期→以**裁定**駁回（刑訴§362），非以判決駁回。
> - 上訴書狀未敘述具體理由→先命**補正**，逾期未補正始得裁定駁回。
> - 辯護人上訴→以被告名義（代理上訴）；配偶/法定代理人→獨立上訴（以自己名義）。
> - 被告死亡→配偶失獨立上訴權。

### 22、107年第25題（原第60題）

> 第一審判決後，判決正本於民國107年3月1日送達於被告之辯護人，同年月2日送達於被告，被告之辯護人並為被告之利益提起上訴。其上訴期間起算，下列敘述，何者正確？

**(A)** 自民國107年3月1日起算。因上訴期間應自被告之辯護人收受判決正本之日起算  
**(B)** 自民國107年3月2日起算。因上訴期間應自被告之辯護人收受判決正本之翌日起算  
**(C)** 自民國107年3月2日起算。因上訴期間應自被告收受判決正本之日起算  
**(D)** 自民國107年3月3日起算。因上訴期間應自被告收受判決正本之翌日起算  

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 上訴期間之起算，依刑訴§349 I，應自**被告**收受判決正本之日起算，非以辯護人收受之日為準。且依§349，期間起算係自收受之**翌日**起算，非收受當日。 |
| (B) | ✗ | 辯護人依§346代理被告提起上訴，其上訴期間仍應以**被告**收受判決正本之日為基準，非以辯護人收受之翌日起算。 |
| (C) | ✗ | 被告收受判決正本之日為3月2日，期間起算應為其**翌日**（3月3日），非收受當日（3月2日）。 |
| (D) | ✓ | 依刑訴§349 I，上訴期間自**收受判決後起算**，實務解釋為自**收受翌日**起算（不計入收受當日）。辯護人雖先於3月1日收受，但依§349，上訴期間應以**被告**收受判決之日為準；被告於3月2日收受，故上訴期間自3月3日（翌日）起算。 |

> [!NOTE]
> **重點整理**
> - 上訴期間起算基準：以**被告**收受判決正本之翌日起算（刑訴§349 I）。
> - 辯護人雖代被告上訴，仍以被告收受日為準，非辯護人收受日。
> - 辯護人先收受、被告後收受時，**以較遲之被告收受日之翌日**起算。
> - 上訴期間為**20日**（刑訴§349 I）。

### 28、113年第59題（原第59題）

> 甲因偽造文書等案件，經第二審法院判處相關罪刑後，甲於法定上訴期間內提起第三審上訴，然其上訴書狀並未敘述上訴理由，僅記載「理由後補」。第二審法院收受甲提出之上訴書狀後，應如何處理，最為正確？

**(A)** 以裁定定期命甲補提上訴理由，逾期不補正，則以裁定駁回上訴  
**(B)** 以裁定定期命甲補提上訴理由，逾期不補正，則以判決駁回上訴  
**(C)** 毋庸以裁定定期命甲補提上訴理由，直接以判決駁回上訴  
**(D)** 毋庸以裁定定期命甲補提上訴理由，直接送最高法院審判  

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依實務見解，第三審上訴未敘述理由僅記載「理由後補」者，**第二審法院毋庸裁定命補提**，亦不由第二審以裁定駁回，本選項錯誤。 |
| (B) | ✗ | 第二審法院無庸命補提，且駁回第三審上訴之權在**第三審法院**，非第二審以判決駁回，本選項錯誤。 |
| (C) | ✗ | 第二審法院之職責僅在收受並轉送卷宗，**不得逕以判決駁回**第三審上訴（駁回權屬最高法院§395），本選項錯誤。 |
| (D) | ✓ | 依**§382**及實務見解，上訴書狀未敘述理由者，第二審法院**毋庸命補提**，應逕將卷宗送交第三審（最高法院）審判；有無補提理由由第三審審查，未補提者由第三審依**§395前段**以上訴違背法律上之程式判決駁回。本選項正確。 |

> [!NOTE]
> **重點整理**
> - 第三審上訴書狀應敘述上訴理由（§382 I）；未敘述僅記「理由後補」者，**第二審法院毋庸命補提**。
> - 第二審法院職責：收受並**轉送卷宗至最高法院**，不自行命補正或駁回。
> - 未補提理由→**第三審（最高法院）**依§395前段以上訴違背法律上之程式**判決駁回**。
> - 對照：合法要件之審查與駁回權，第三審上訴屬**最高法院**。

## 貳、上訴審級與範圍（二審、三審審查範圍、想像競合上訴）

### 6、111年第51題（原第51題）

> 檢察官以被告犯過失重傷害罪提起公訴，第一審法院以告訴人告訴逾越告訴期間為由，諭知公訴不受理，在上訴期間，被害人因同一原因事由死亡。檢察官於上訴期間屆滿前提起上訴，第二審法院審理後之處理，下列敘述何者最為正確？

**(A)** 自為判決。過失重傷害與過失致死係同一案件，第二審法院係事實審，自得變更罪名而為判決  
**(B)** 自為判決。過失重傷害雖屬告訴乃論之罪，但過失致死係非告訴乃論之罪，無告訴逾期之問題  
**(C)** 撤銷發回原審。過失重傷害與過失致死事實不同，非同一案件，第二審法院顯就未受請求事項而予判決  
**(D)** 撤銷發回原審。因係同一案件，得撤銷第一審判決，將案件發回原審法院，以維被告審級利益

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 過失重傷害與過失致死雖屬同一案件（基本社會事實同一），但第一審僅為程序判決（公訴不受理），未進入實體審理。第二審若自為實體判決，將剝奪被告於第一審之**審級利益**，與審級制度之保障不符。 |
| (B) | ✗ | 結論方向正確（過失致死為非告訴乃論之罪，無告訴逾期問題），但處理方式錯誤。第二審不應自為判決，應發回第一審。 |
| (C) | ✗ | 過失重傷害與過失致死之基本社會事實同一（同一過失行為、同一被害人），屬同一案件，非不同事實。 |

### 24、106年第6題（原第41題）

> 第一審以甲犯刑法第201條第2項行使偽造有價證券罪，處有期徒刑1年6月。檢察官未對第一審判決提起上訴，甲提起上訴，第二審變更檢察官起訴法條，改論甲以刑法第216條、第210條第1項之行使偽造私文書罪，處有期徒刑2年，緩刑2年。關於第二審判決之量刑，依實務見解，下列敘述，何者錯誤？

**(A)** 適用法條不同，屬第二審法院職權行使之事項，沒有違背不利益變更禁止原則，第二審之科刑判決為合法  
**(B)** 雖然刑度較重，但已諭知緩刑，於甲並無不利，未違反不利益變更禁止原則，第二審之科刑判決為合法  
**(C)** 刑度較重，違反不利益變更禁止原則，第二審之科刑判決為違法  
**(D)** 依第一審、第二審判決所臚列量刑審酌事項多寡，綜合判斷有無違反不利益變更禁止原則以及罪刑相當原則  

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 雖然變更法條屬法院職權，但**不利益變更禁止原則（§370）之效力及於量刑**。縱使罪名不同，若刑度較重，仍違反該原則。本選項謂「沒有違背」係屬錯誤。 |
| (B) | ✗ | 依實務見解，**不利益變更禁止原則之判斷以宣告刑為準**，不得以已諭知緩刑而謂「整體無不利」。諭知緩刑不能抵消刑度加重之不利益，本選項見解有誤。 |
| (C) | ✓ | 依刑訴§370，被告上訴（不含檢察官為被告不利益上訴），第二審**不得諭知較重之刑**。第一審判處有期徒刑1年6月，第二審改判2年，**刑度較重**，違反不利益變更禁止原則，**第二審科刑判決為違法**。 |
| (D) | ✗ | 依實務見解，不利益變更禁止原則之判斷基準係比較**宣告刑之輕重**，不以量刑理由多寡作為綜合判斷標準。本選項所述並非正確之判斷方式。 |

> [!NOTE]
> **重點整理**
> - **不利益變更禁止原則**（刑訴§370）：被告上訴或為被告利益上訴→第二審**不得諭知較重之刑**。
> - 判斷標準：以**宣告刑**之輕重為準，非以執行刑或是否緩刑為準。
> - 縱使**變更罪名**，若宣告刑較重，仍違反不利益變更禁止原則。
> - 諭知緩刑≠抵消刑度加重之不利→**仍違反§370**。

### 29、113年第58題（原第58題）

> 檢察官起訴被告於民國109年間同時持有A、B二把改造手槍，涉想像競合犯非法持有手槍1罪嫌。第一審法院判決被告持有 A 槍有罪，持有 B 槍部分則於理由內說明不另為無罪之諭知。第二審法院駁回檢察官及被告之上訴，維持第一審法院判決。下列敘述何者正確？

**(A)** 非法持有手槍罪係得上訴第三審之案件，檢察官就第二審判決全部都可以提起第三審上訴，不受任何限制  
**(B)** 被告僅對第二審有罪部分上訴，檢察官未上訴，上訴範圍不及於不另為無罪諭知部分  
**(C)** 被告僅對第二審有罪部分上訴，檢察官未上訴。第三審如認被告上訴有理由，基於審判不可分原則，應將不另為無罪諭知部分併同發回第二審更為審理  
**(D)** 僅檢察官對第二審有罪部分上訴，依上訴不可分原則，及於不另為無罪諭知部分，第三審法院應全部審理  

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 檢察官既未上訴（題示為被告上訴），自無「全部都可提起第三審上訴」可言；且上訴範圍受§348之限制，本選項錯誤。 |
| (B) | ✓ | 想像競合案件一審判A槍有罪、B槍不另為無罪。依**§348 II但書**（111年修法），有罪部分之上訴，其有關係之部分為**無罪、免訴或不受理性質者不在上訴不可分之列**。被告僅對有罪部分上訴、檢察官未上訴，**上訴範圍不及於不另為無罪（實質無罪）部分**。本選項正確。 |
| (C) | ✗ | 不另為無罪部分未在上訴範圍內（§348 II但書），第三審無從併同發回，本選項錯誤。 |
| (D) | ✗ | 題示係被告上訴、檢察官未上訴；且不另為無罪部分依§348 II但書不生上訴不可分，第三審不應全部審理，本選項錯誤。 |

> [!NOTE]
> **重點整理**
> - **§348 II（上訴不可分）**：對判決一部上訴者，有關係之部分視為亦已上訴。
> - **§348 II但書（111年修法）**：有關係之部分為**無罪、免訴或不受理**者，**不在此限**（可分）。
> - 想像競合之「不另為無罪」部分屬實質無罪性質→被告僅對有罪上訴時，**上訴範圍不及於不另為無罪部分**。
> - 判斷關鍵：先辨明「誰上訴」（被告／檢察官）＋「有關係部分之性質」（有罪或無罪免訴不受理）。

## 參、抗告與再抗告

### 13、108年第60題（原第60題）

> 某甲提起自訴，經第一審法院裁定駁回自訴，甲不服提出抗告，經抗告法院駁回後，提出再抗告。關於再抗告合法性之敘述，何者正確？

**(A)** 合法。為保障訴訟權，刑事訴訟法規定原則上皆應容許被告提出再抗告  
**(B)** 合法。甲之抗告遭駁回後，性質上等同於駁回上訴之裁定，應容許提出再抗告  
**(C)** 不合法。針對駁回自訴之裁定，不得提出抗告，亦不得提出再抗告  
**(D)** 不合法。再抗告以法律有明文規定者為限，甲之情況非屬法律列舉得再抗告事由

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 再抗告並非原則上均得提出。依刑訴§415 I，再抗告**以法律有明文規定者為限**，非原則上容許。且本題甲為自訴人，非被告。 |
| (B) | ✗ | 抗告法院駁回抗告之裁定，不等同於駁回上訴之裁定，兩者性質不同。再抗告之容許性須依法律明文，不得類推。 |
| (C) | ✗ | 駁回自訴之裁定**得提出抗告**（刑訴§403），故前半段錯誤。駁回自訴係影響當事人訴訟權之重要裁定，依法得抗告。 |
| (D) | ✓ | 依刑訴§415 I，再抗告**以法律有特別規定者為限**。駁回自訴之裁定經抗告駁回後，法律並無明文規定得再抗告，故甲之再抗告不合法。再抗告之容許性採**法定主義**，僅於法律明文列舉之事由始得為之。 |

> [!NOTE]
> **重點整理**
> - **抗告**：對法院之裁定不服，原則上得抗告（刑訴§403），但有不得抗告之例外。
> - **再抗告**：以**法律有特別規定者為限**（刑訴§415 I），採法定主義，非一般性容許。
> - 駁回自訴之裁定→得抗告→抗告被駁回→無法律明文容許再抗告→再抗告不合法。

### 14、109年第59題（原第59題）

> 當事人不服法院駁回其關於調查證據之聲請，應如何請求救濟，下列敘述何者正確？

**(A)** 向直接上級法院提起抗告。因法院駁回調查證據之聲請，必須作成裁定，當事人不服法院之裁定，得抗告於直接上級法院  
**(B)** 向原審法院聲明異議。因法院駁回調查證據之聲請，屬於審判長或受命法官有關調查證據之處分，當事人不服，得向原審法院聲明異議  
**(C)** 向直接上級法院提起抗告或上訴均可。因法院駁回調查證據之聲請，必須作成裁定，當事人不服法院之裁定，得抗告於直接上級法院；如當事人未提起抗告，則得於提起上訴時主張  
**(D)** 法院駁回調查證據之聲請，屬於判決前關於訴訟程序之裁定，當事人不得聲明不服，僅能於上訴時主張

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 駁回調查證據之聲請雖以裁定為之，但依刑訴§404但書，**判決前關於訴訟程序之裁定，不得抗告**。當事人不得逕向上級法院提起抗告。 |
| (B) | ✗ | 聲明異議（刑訴§288-3）係針對審判長或受命法官關於**證據調查或訴訟指揮**之處分。但法院以裁定駁回調查證據之聲請，並非審判長個人之訴訟指揮處分，而係法院（合議庭）之裁定，不得以聲明異議救濟。 |
| (C) | ✗ | 如前述，不得抗告。「得於上訴時主張」部分正確，但選項整體錯誤。 |
| (D) | ✓ | 法院駁回調查證據之聲請，屬**判決前關於訴訟程序之裁定**（刑訴§404但書），當事人**不得聲明不服**。救濟途徑為：於不服判決而**提起上訴時**，以法院未調查有利證據為上訴理由，主張原審判決有「應調查之證據未予調查」之違法（刑訴§379⑩）。 |

> [!NOTE]
> **重點整理**
> - 駁回調查證據聲請之裁定 = **判決前關於訴訟程序之裁定**→**不得抗告**（刑訴§404但書）。
> - 救濟方式：於**上訴時**主張原審有「應調查之證據未予調查」之違法。
> - 聲明異議（§288-3）對象為審判長/受命法官之訴訟指揮處分，非法院之裁定。
> - 不得抗告 ≠ 不得救濟，仍可透過上訴主張。

## 肆、再審

### 15、111年第58題（原第58題）

> 檢察官有客觀注意義務，不僅指通常審判程序中有之，即便在開始再審後之審判程序亦然，故當二審檢察官為在監的死刑犯受刑人之利益聲請再審，下列敘述何者最為正確？

**(A)** 檢察官將聲請書遞交法院後，就可以直接釋放在監受刑人  
**(B)** 法官裁定開始再審後，檢察官為節省訴訟程序可以直接撤回本件之起訴  
**(C)** 法官裁定開始再審後，檢察官不得請求法院為無罪判決，只能請求從輕判決  
**(D)** 法官裁定開始再審後，得裁定停止刑罰之執行

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 聲請再審並不當然停止刑罰之執行（刑訴§430）。檢察官遞交聲請書後，法院尚未裁定是否開始再審，不得直接釋放在監受刑人。 |
| (B) | ✗ | 再審開始後，案件回復至判決前之程序狀態（刑訴§436），應**依判決前之程序更為審判**。檢察官不得直接撤回起訴，因再審程序之目的在重新審理案件。 |
| (C) | ✗ | 檢察官有**客觀注意義務**（刑訴§2 I），應就有利不利被告之情形一律注意。再審開始後，檢察官若認被告確屬無辜，自得請求法院為**無罪判決**，不限於請求從輕判決。 |
| (D) | ✓ | 依刑訴§435 II，法院為**開始再審之裁定**後，**得以裁定停止刑罰之執行**。此規定之目的在於避免受刑人於再審程序進行中仍持續執行可能錯誤之刑罰，尤其對死刑犯更為重要。 |

> [!NOTE]
> **重點整理**
> - 聲請再審**不停止刑罰之執行**（刑訴§430）；但法院裁定**開始再審**後，**得裁定停止刑罰之執行**（§435 II）。
> - 再審開始後，回復至判決前程序狀態，**依判決前之程序更為審判**（§436）。
> - 檢察官之**客觀注意義務**貫穿通常程序與再審程序，得請求無罪判決。

### 16、114年第59題（原第59題）

> 甲涉犯普通竊盜及強制罪嫌之裁判上一罪，經檢察官向臺灣臺北地方法院提起公訴。臺灣臺北地方法院審理結果，就甲被訴強制罪嫌部分判決有罪，被訴普通竊盜罪嫌部分，則於判決理由內說明不另為無罪之諭知。檢察官及甲均不服提起上訴，臺灣高等法院審理結果，認定檢察官之上訴有理由，甲之上訴則無理由，因而撤銷第一審判決，改依想像競合犯之規定，從一重論處甲犯普通竊盜罪刑確定。甲不服欲向法院聲請再審，關於聲請再審程序之敘述，依實務見解，下列何者正確？

(D)

### 17、109年第60題（原第60題）

> 檢察官起訴被告涉犯傷害罪嫌，第一審判決被告無罪，檢察官提起上訴，第二審法院誤檢察官上訴逾期，以不合法程序駁回上訴判決確定，依現行實務見解，下列敘述何者正確？

**(A)** 此為程序判決，不生實質確定力，第二審可逕對合法上訴進行審判  
**(B)** 此為程序判決，僅生形式確定力，不得提起非常上訴  
**(C)** 應依再審程序將該確定判決撤銷後，始能就合法上訴部分進行審判  
**(D)** 應依非常上訴程序將該確定判決撤銷後，始能就合法上訴部分進行審判

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 雖為程序判決（駁回上訴），但判決一旦確定，即生確定力。第二審法院不得逕行重新審理，須先透過救濟程序撤銷確定判決。 |
| (B) | ✗ | 該判決生形式確定力，但並非不得救濟。依實務見解，得以**再審**程序救濟。另非常上訴以判決確定後發現違背法令為要件，是否得提起非常上訴，與本題所問之救濟途徑不同。 |
| (C) | ✓ | 依實務見解（最高法院相關判例），第二審法院**誤認上訴逾期而駁回上訴**之確定判決，屬**事實認定錯誤**（誤認送達日、上訴期間等事實），得依**再審程序**撤銷。透過再審撤銷該確定判決後，始能就原來之合法上訴重新進行審判。此與非常上訴（針對法律適用錯誤）不同。 |
| (D) | ✗ | 非常上訴係針對判決**違背法令**之救濟（刑訴§441）。本件第二審法院係因**事實認定錯誤**（誤認上訴是否逾期），而非法律適用錯誤。依實務見解，應以**再審**而非非常上訴為救濟途徑。 |

> [!NOTE]
> **重點整理**
> - 二審誤認上訴逾期而駁回 = **事實認定錯誤**→以**再審**救濟。
> - 非常上訴 = 判決確定後發現**違背法令**→由**檢察總長**向最高法院提起。
> - 再審 vs 非常上訴之區分：事實錯誤→再審；法令違背→非常上訴。
> - 確定判決一旦生確定力，須透過法定救濟程序撤銷，不得逕行重新審判。

## 伍、簡易判決之上訴救濟

### 18、111年第49題（原第49題）

> 檢察官依通常程序起訴被告搶奪罪，經法院訊問後被告自白犯罪，法院認為宜以簡易判決處刑，最終處有期徒刑兩年，緩刑五年。檢察官不服，上訴至管轄之第二審地方法院合議庭，地方法院合議庭認為上訴無理由，駁回上訴。依實務見解，檢察官此時得否再對第二審判決上訴？

**(A)** 可以。搶奪罪非屬刑事訴訟法第376條之案件，檢察官自得針對二審判決上訴第三審，此時應向高等法院提起第三審上訴  
**(B)** 可以。搶奪罪非屬刑事訴訟法第376條之案件，檢察官自得針對二審判決上訴第三審，此時應向最高法院提起第三審上訴  
**(C)** 不可以。簡易處刑判決，僅被告得上訴第三審，不容許檢察官上訴第三審  
**(D)** 不可以。簡易程序僅有一次救濟機會，此時檢察官不得上訴第三審

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 簡易判決之上訴體系有別於通常程序。簡易判決不服→上訴至地方法院合議庭（第二審）。地方法院合議庭之判決，僅有**一次救濟機會**，不得再上訴第三審。此與通常程序可由地方法院→高等法院→最高法院之三級三審不同。 |
| (B) | ✗ | 同(A)之說明，簡易程序之第二審為地方法院合議庭，其判決即為終審，不得上訴最高法院。 |
| (C) | ✗ | 簡易程序之上訴限制，並非只限被告不得上訴，而是**任何人均不得**對地方法院合議庭之簡易判決第二審判決上訴第三審。 |
| (D) | ✓ | 簡易判決處刑之審級制度為**二級二審**：簡易庭（第一審）→地方法院合議庭（第二審）。地方法院合議庭之判決即為**終審判決**，不得再上訴第三審。依實務見解及刑訴§455-1之規定，簡易程序**僅有一次救濟機會**，檢察官不得上訴第三審。 |

> [!NOTE]
> **重點整理**
> - 簡易判決處刑之審級：**二級二審**（簡易庭→地方法院合議庭），合議庭判決即為終審。
> - 簡易程序不得上訴**第三審**，無論當事人為何人。
> - 通常程序之搶奪罪雖非§376案件，得上訴第三審；但以簡易程序審理時，受簡易程序之審級限制。
> - 簡易程序之適用前提：被告自白犯罪、法院認為宜以簡易判決處刑，且科刑以有期徒刑上限為限制。

## 陸、其他救濟程序（回復原狀等）

### 19、112年第49題（原第49題）

> 關於聲請回復原狀之敘述，下列何者最為正確？

**(A)** 非因過失，遲誤上訴期間者，於其原因消滅後20日內，得聲請回復原狀  
**(B)** 非因過失，遲誤抗告期間者，於其原因消滅後10日內，得聲請回復原狀  
**(C)** 非因過失，遲誤聲請撤銷檢察官命令之期間者，於其原因消滅後15日內，得聲請回復原狀  
**(D)** 非因過失，遲誤告訴期間者，於其原因消滅後5日內，得聲請回復原狀

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依刑訴§67 I，非因過失遲誤上訴期間者，於原因消滅後**5日內**得聲請回復原狀，非20日內。期限嚴格，以維護法的安定性。 |
| (B) | ✓ | 依刑訴§67 I，非因過失遲誤**上訴或抗告期間**者，得聲請回復原狀。依同條第2項，遲誤**抗告期間**之回復原狀聲請，應自原因消滅後**10日內**為之。 |
| (C) | ✗ | 回復原狀之對象限於**上訴及抗告期間**之遲誤（刑訴§67 I），不及於聲請撤銷檢察官命令之期間。15日亦非法定期限。 |
| (D) | ✗ | 回復原狀之適用範圍不及於**告訴期間**之遲誤。告訴期間為實體法上之期間限制，逾期不得告訴，無回復原狀之適用。 |

> [!NOTE]
> **重點整理**
> - **回復原狀**（刑訴§67）：非因過失遲誤**上訴或抗告期間**者，得聲請回復原狀。
> - 遲誤上訴期間→原因消滅後**5日內**聲請；遲誤抗告期間→原因消滅後**10日內**聲請。
> - 回復原狀之適用範圍僅限上訴及抗告期間，**不及於告訴期間**或其他聲請期間。
> - 須為**非因過失**遲誤，因過失遲誤者不得聲請回復原狀。

### 20、110年第60題（原第60題）

> 甲經高等法院判決論處強盜罪刑，甲不服提起上訴，最高法院因認甲並非依據卷內證據具體指摘原判決有何違背法令，而以上訴不合法定程式為由，判決駁回上訴確定。甲主張原確定判決不傳喚其聲請之有利證人乙到庭作證，且未敘明理由，致事實認定錯誤而影響判決結果。關於甲得請求救濟之途徑，下列敘述何者最為正確？

**(A)** 甲得向最高法院聲請再審  
**(B)** 甲得向高等法院聲請停止刑罰之執行  
**(C)** 甲得請求檢察總長提起非常上訴  
**(D)** 甲得向高等法院聲明疑義

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 最高法院以上訴不合法定程式駁回上訴，為**程序判決**，並未為實體判斷。再審須向**為實體確定判決之法院**聲請（刑訴§426 I）。最高法院係以程序理由駁回，非實體判決法院。實體確定判決為高等法院之判決，但甲所主張之事由（未傳喚證人、事實認定錯誤）屬原判決違背法令問題，非再審事由。 |
| (B) | ✗ | 停止刑罰之執行須有法定事由（如再審開始之裁定等），甲僅主張原判決違法，無停止執行之法定依據。 |
| (C) | ✓ | 甲主張原確定判決**未傳喚有利證人且未敘明理由**，此屬「應於審判期日調查之證據而未予調查」及「判決不載理由」之判決違背法令情形（刑訴§379⑩、⑭）。判決確定後發現**違背法令**，救濟途徑為**非常上訴**（刑訴§441），應由**檢察總長**向最高法院提起。甲本人不得逕行提起非常上訴，但得**請求檢察總長**提起。 |
| (D) | ✗ | 聲明疑義（刑訴§483）係就**判決確定後之執行有疑義**者，向諭知該裁判之法院聲明之。本件非執行上之疑義，而係判決本身違背法令，不得以聲明疑義救濟。 |

> [!NOTE]
> **重點整理**
> - **非常上訴**（刑訴§441）：判決確定後發現**違背法令**，由**檢察總長**向最高法院提起。
> - 當事人不得自行提起非常上訴，但得**請求檢察總長**提起。
> - 「應調查之證據未予調查」（§379⑩）及「判決不載理由」（§379⑭）屬判決違背法令。
> - 最高法院以程序理由駁回上訴（非實體判決），實體確定判決為下級審之判決。

### 21、114年第51題（原第51題）

> 甲與被害人發生衝突，因而與乙共同持棍毆傷被害人，被害人因不知乙之姓名，僅先對甲提起傷害罪之告訴，甲經檢察官起訴後，第一審審理中，檢察官另案查出乙之姓名，被害人於另案偵查中與乙達成和解，並撤回對乙之告訴後，甲始經法院判處傷害罪刑確定，甲知悉上情後，主張應依非常救濟程序，改諭知不受理判決。依實務見解，其主張有無理由？

**(A)** 無理由，因甲是正犯，且被害人未對甲撤回告訴，本應對甲論罪判刑  
**(B)** 無理由，已經判刑確定，不可救濟  
**(C)** 有理由，法院本應諭知公訴不受理，但應由甲聲請再審救濟  
**(D)** 有理由，法院本應諭知公訴不受理，且應以非常上訴救濟

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 傷害罪為**告訴乃論之罪**（刑法§287），告訴之撤回依刑訴§239，對**共犯之一人**撤回告訴者，其效力**及於其他共犯**（告訴不可分原則）。被害人對乙撤回告訴，效力及於甲。法院本應對甲諭知公訴不受理。 |
| (B) | ✗ | 判刑確定後並非不可救濟。有非常上訴及再審等非常救濟程序。 |
| (C) | ✗ | 結論正確（法院本應諭知不受理），但救濟途徑有誤。本件為法院適用法律之錯誤（未適用告訴不可分原則而為不受理判決），屬判決**違背法令**，應以**非常上訴**救濟，而非再審。再審係針對事實認定之錯誤。 |
| (D) | ✓ | 依刑訴§239（告訴不可分原則），被害人對共犯乙撤回告訴，效力**及於共犯甲**。法院本應依刑訴§303②諭知**公訴不受理**判決。法院未適用告訴不可分原則而逕為有罪判決，屬**判決違背法令**，應以**非常上訴**救濟（刑訴§441），由檢察總長向最高法院提起。 |

> [!NOTE]
> **重點整理**
> - **告訴不可分原則**（刑訴§239）：告訴乃論之罪，對**共犯之一人**告訴或撤回告訴，效力**及於其他共犯**。
> - 撤回告訴效力及於共犯→法院應諭知**公訴不受理**（刑訴§303②）。
> - 法院未適用告訴不可分原則而逕為有罪判決→**判決違背法令**→以**非常上訴**救濟。
> - 非常上訴 vs 再審之區分：違背法令→非常上訴；事實認定錯誤→再審。

### 26、104年第10題（原第45題）

> 下列敘述，何者錯誤？

**(A)** 再議聲請，提出於原檢察官之後，原檢察官認為聲請有理由者，應撤銷其處分  
**(B)** 上訴書狀，提出於原審法院之後，原審法院認為上訴有理由者，應更正其判決  
**(C)** 抗告書狀，提出於原審法院之後，原審法院認為抗告有理由者，應更正其裁定  
**(D)** 抗告書狀，提出於原審法院之後，原審法院認為抗告一部有理由、一部無理由者，不應更正其裁定，而應送交抗告法院  

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依刑訴§258，聲請再議後，原檢察官認再議有理由者，**應撤銷原處分**（不起訴或緩起訴），重行偵查或起訴。本選項正確。 |
| (B) | ✗ | 刑事訴訟法中**並無「原審法院得自行更正判決」**之規定。上訴書狀提出後，原審法院只能審查是否逾期（§362）或命補正（§361 III），**無法自行更正判決**（判決一旦宣示即已確定由上級審審查，非原審更正）。本選項**錯誤**，為本題應選答案。 |
| (C) | ✓ | 依刑訴§408，抗告書狀提出後，原審法院認抗告有理由者，**應更正其裁定**，如認無理由，應送交抗告法院。本選項正確。 |
| (D) | ✓ | 依刑訴§408，抗告一部有理由、一部無理由時，原審法院不得分拆自行更正有理由部分，應**整體送交抗告法院**處理，以維審查一貫性。本選項正確。 |

> [!NOTE]
> **重點整理**
> - **再議書狀**→原檢察官認有理由→**撤銷原處分**（§258）。
> - **抗告書狀**→原審法院認有理由→**得更正裁定**（§408）；認無理由→送抗告法院。
> - **上訴書狀**→原審法院**無**自行更正判決之權限；只能審查逾期裁定駁回（§362）或命補正（§361 III）。
> - 抗告一部有理由一部無理由→**整體送交**抗告法院，不得分割處理。

### 28、105年第8題（原第36題）

> 甲因竊盜案經法院判處有期徒刑八個月，於收受判決翌日狂颱橫掃臺灣，甲居住的山區因大片土石流沖刷並且對外橋樑沖毀，道路無法通行，亦無法與外界聯絡，於第15日始搶通對外往來通道。下列敘述，何者正確？

**(A)** 甲應在搶通對外往來通道的5日內，以書狀向原審法院聲請回復原狀，同時於書狀中表明提出上訴  
**(B)** 甲應在搶通對外往來通道的5日內，向原審法院聲請回復原狀。待法院准予回復原狀後，再於5日內向原審法院提出上訴書狀  
**(C)** 甲應在搶通對外往來通道的5日內，向原審法院聲請回復原狀。待法院准予回復原狀後，再於10日內向原審法院提出上訴書狀  
**(D)** 甲應在搶通對外往來通道的10日內，向原審法院聲請回復原狀。待法院准予回復原狀後，再於10日內向原審法院提出上訴書狀  

#### 答案

(A)

#### 解析

甲因天災（土石流、橋樑沖毀）致無法於上訴期間（§349，10日）內上訴，係**非因過失**遲誤上訴期間，得聲請**回復原狀**。關鍵在§67、§68之程序：期間為「原因消滅後**5日內**」，且應**同時補行**應為之訴訟行為（即同時提起上訴）。

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依**§67 I**，非因過失遲誤上訴期間，得於原因消滅（搶通通道）後**5日內**聲請回復原狀；依**§68 II**，因遲誤上訴期間聲請回復原狀者，應與聲請**同時補行期間內應為之訴訟行為**（即同時表明提起上訴）。本選項完全符合。 |
| (B) | ✗ | 回復原狀之聲請與上訴**應同時為之**（§68 II），並非「待法院准予回復原狀後再另行上訴」。且期間亦非「准許後再5日」。 |
| (C) | ✗ | 同(B)之錯誤，須與聲請同時補行上訴，不能分兩階段；「10日」之期間亦無依據。 |
| (D) | ✗ | 聲請回復原狀之期間為原因消滅後**5日內**（§67 I），非10日；且須同時補行上訴。本選項期間與程序均錯誤。 |

> [!NOTE]
> **重點整理**
> - **§67 I**：非因過失遲誤上訴、抗告或聲請再審等期間者，於**原因消滅後5日內**得聲請回復原狀。
> - **§68 I**：聲請回復原狀，應以**書狀向原審法院**為之。
> - **§68 II**：因遲誤上訴或抗告期間聲請回復原狀者，應**同時補行**期間內應為之訴訟行為（即同時提起上訴）。
> - 記憶：回復原狀＝「原因消滅後5日內」＋「同時補行上訴」，一步到位，非分兩階段。

### 30、113年第60題（原第60題）

> A 因使用 GPS追蹤器調查他人行蹤，一審法院判決 A 有罪，二審法院認原審判決適用法條有誤，撤銷後亦改判有罪。A上訴第三審，第三審法院以上訴違背法律上之程式，判決駁回。關於本件之非常上訴，下列敘述何者正確？

**(A)** 檢察總長為被告利益，應以第三審程序判決為對象提起非常上訴  
**(B)** 檢察總長應以第二審實體判決為對象提起非常上訴  
**(C)** 檢察總長得以最高法院法律見解已有變更作為非常上訴理由  
**(D)** 非常上訴採強制辯護制度，A未選任辯護人者，應由審判長為其指定公設辯護人或律師  

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 第三審係以「上訴違背法律上之程式」為**程序判決駁回**，未進入實體；使案件實體確定者為第二審實體判決，非常上訴之對象應為該確定之實體判決，本選項錯誤。 |
| (B) | ✓ | 第三審上訴不合法經程序判決駁回，**第二審實體有罪判決因而確定**。非常上訴（§441）係對確定判決之審判違背法令而設，其對象應為**第二審實體判決**。本選項正確。 |
| (C) | ✗ | 非常上訴之理由為「該案件之審判係違背法令」（§441），**最高法院法律見解變更並非非常上訴之法定事由**，本選項錯誤。 |
| (D) | ✗ | 非常上訴由**最高檢察署檢察總長**向最高法院提起，**不經言詞辯論**，並無強制辯護制度之適用，本選項錯誤。 |

> [!NOTE]
> **重點整理**
> - **非常上訴（§441）**：判決確定後發現**審判違背法令**，由**檢察總長**向最高法院提起。
> - **對象**：使案件確定之**違背法令判決**。三審以程序駁回時，實體確定者為**第二審判決**→以第二審實體判決為對象。
> - 非常上訴**不經言詞辯論**、**無強制辯護**；理由限「審判違背法令」，非「法律見解變更」。
> - 對照：非常上訴（違背法令，統一法律適用）vs 再審（事實錯誤，發現新事實新證據）。

### 二、高頻考點摘要

| 考點 | 核心觀念 |
|------|----------|
| 上訴期間起算（判決送達） | 在監被告應囑託監獄長官送達本人；多次送達以最先合法送達為準 |
| 送達代收人與在途期間 | 送達予代收人時即生效；住居所不在法院所在地應扣除在途期間 |
| 上訴書狀具體理由 | 通常程序上訴二審須具體理由；簡易判決上訴二審準用三審規定 |
| 辯護人代理上訴 | 辯護人為代理上訴，應以被告名義提起；配偶/法定代理人為獨立上訴 |
| 想像競合犯上訴三審 | 各罪名分別判斷是否得上訴三審；§376但書：一審無罪→二審改有罪得上訴 |
| 依職權逕送上訴 | 宣告死刑或無期徒刑者，法院應依職權逕送上訴（§344 V） |
| 再抗告法定主義 | 再抗告以法律有特別規定者為限（§415 I） |
| 再審管轄與停止執行 | 向原確定判決法院聲請；開始再審後得裁定停止刑罰執行 |
| 回復原狀 | 限於上訴及抗告期間之遲誤；上訴→5日內、抗告→10日內 |
| 非常上訴 | 判決確定後違背法令；由檢察總長向最高法院提起 |

### 三、關鍵區辨整理

| 概念A | 概念B | 區辨重點 |
|-------|-------|----------|
| 代理上訴（辯護人） | 獨立上訴（配偶/法定代理人） | 代理上訴以被告名義提起；獨立上訴以自己名義提起 |
| 再審 | 非常上訴 | 再審→事實認定錯誤或新事證；非常上訴→判決違背法令 |
| 抗告 | 再抗告 | 抗告原則上得為之；再抗告以法律有明文規定者為限 |
| 通常程序上訴二審 | 簡易判決上訴二審 | 通常程序→上訴高等法院，得續上訴三審；簡易判決→上訴地方法院合議庭，不得上訴三審 |
| 上訴期間（上訴） | 抗告期間（抗告） | 上訴期間20日（§349）；抗告期間5日或10日 |
| 回復原狀（上訴遲誤） | 回復原狀（抗告遲誤） | 上訴→原因消滅後5日內聲請；抗告→原因消滅後10日內聲請 |
| §376案件一二審均有罪 | §376案件一審無罪二審改有罪 | 均有罪→不得上訴三審；一審無罪→二審改有罪→得上訴三審（但書例外） |
| 沒收之從屬性 | 沒收之獨立性 | §376本案不得上訴三審者，沒收部分亦不得獨立上訴三審 |
