# 搜索與扣押 — 主題式考古題整理

> 涵蓋範圍：搜索票之聲請與範圍、附帶搜索、同意搜索、緊急搜索與無令狀搜索、扣押與保全扣押  
> 資料來源：108～114年司律一試刑事訴訟法考古題（不含113年）

---

## 壹、搜索票之聲請與範圍

### 1、108年第9題（原第44題）

> 員警據報A與友人於KTV唱歌狂歡，有使用毒品助興，經前往調查發現A等人於某包廂飲酒作樂，且有塑膠「燒焦」氣味，但未見到可疑物品。員警依辦案經驗研判現場情況，認有搜索 A 所攜行李之必要，惟A不同意。下列敘述何者正確？

**(A)** 依刑事訴訟法第128條之1取得搜索票實施搜索  
**(B)** 依刑事訴訟法第130條附帶搜索  
**(C)** 依刑事訴訟法第131條第1項第3款逕行搜索  
**(D)** 逕依刑事訴訟法第131條第2項緊急搜索

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 本案員警雖有合理懷疑（塑膠燒焦氣味），但**未發現可疑物品**，A亦不同意搜索，且A非現行犯、未經逮捕或拘提，不符無令狀搜索之要件。應依**刑訴§128-1**向法院聲請搜索票後實施搜索。有令狀搜索為原則，無令狀搜索為例外。 |
| (B) | ✗ | 附帶搜索（§130）須以「逮捕或拘提」為前提。本案A未遭逮捕或拘提，不得實施附帶搜索。 |
| (C) | ✗ | 逕行搜索（§131 I③）須有「被告或犯罪嫌疑人有事實足認為在內」等法定事由。本案僅有「塑膠燒焦氣味」之間接跡象，尚未達逕行搜索之門檻，且本條主要適用於搜索住宅或其他處所，而非搜索人身行李。 |
| (D) | ✗ | 緊急搜索（§131 II）須以「逮捕被告、犯罪嫌疑人或執行拘提、羈押」為前提，於有事實足認情況急迫時始得為之。本案A未被逮捕或拘提，不符合緊急搜索之要件。 |

> [!NOTE]
> **重點整理**
> - **有令狀搜索為原則**，無令狀搜索（附帶搜索、逕行搜索、緊急搜索、同意搜索）為例外。
> - 附帶搜索（§130）→ 前提：逮捕或拘提。
> - 逕行搜索（§131 I）→ 法定事由（如被告在內、追蹤現行犯等）。
> - 緊急搜索（§131 II）→ 前提：先有逮捕或拘提 ＋ 情況急迫。
> - 僅有懷疑（如氣味）而無現行犯或逮捕事實者，應循搜索票程序。

### 2、112年第4題（原第39題）

> 某縣府之政風人員得知長官涉犯收受賄賂罪嫌，向法務部調查局舉發，經調查後，認為有搜索之必要。下列敘述何者正確？

**(A)** 該政風人員得逕自向該管法院聲請搜索票  
**(B)** 該政風人員須得檢察官許可後，始得向法院聲請搜索票  
**(C)** 調查局調查站主任得逕自向法院聲請搜索票  
**(D)** 調查局調查站主任須得檢察官許可後，始得向法院聲請搜索票

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 政風人員為行政機關公務員，**非司法警察（官）**，無搜索票聲請權限，不得向法院聲請搜索票。 |
| (B) | ✗ | 政風人員縱得檢察官許可，亦非聲請搜索票之適格主體。搜索票聲請權限僅限於檢察官及司法警察官。 |
| (C) | ✗ | 調查局調查站主任為司法警察官，但依**刑訴§128-1 II**，須先報請**檢察官許可**後，始得向法院聲請搜索票，不得逕自聲請。 |
| (D) | ✓ | 依刑訴§128-1 II，司法警察官（如調查站主任）因調查犯罪嫌疑人犯罪情形及蒐集證據，認有搜索之必要時，得**報請檢察官許可後**，向該管法院聲請核發搜索票。 |

> [!NOTE]
> **重點整理**
> - 搜索票聲請權限兩軌制：①**檢察官**得直接向法院聲請；②**司法警察官**須報請檢察官許可後始得向法院聲請（§128-1 II）。
> - 政風人員非司法警察（官），無搜索票聲請權。
> - 調查局人員（如調查官、調查站主任）具司法警察官身分，但須經檢察官許可方得聲請搜索票。

### 3、114年第22題（原第57題）

> 甲係立法院行政科室之公務員，因涉嫌索取回扣，經檢察官偵辦後發現甲涉嫌貪污罪嫌重大，認有搜索之必要，下列敘述何者錯誤？

**(A)** 如無急迫情形，檢察官應以書面，檢附理由，向該管法院聲請核發搜索票，於法院核發搜索票後，可交由司法警察執行搜索  
**(B)** 檢察官可向法院聲請對甲位於立法院院內之辦公室核發搜索票  
**(C)** 甲之妻乙係某大學教授，雖係第三人，但如有理由認甲將索取回扣資料存放於乙於學校之教授研究室內，檢察官亦可向法院聲請對乙於大學內之教授研究室核發搜索票  
**(D)** 檢察官可向法院聲請對甲之身體核發搜索票，但不得聲請搜索第三人乙之身體

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依刑訴§128，搜索應用搜索票，由檢察官向法院聲請核發。搜索票得交由司法警察執行（§128 III），程序合法。 |
| (B) | ✓ | 甲為立法院**行政科室公務員**，非立法委員，不享有憲法上國會議員之免搜索特權（憲法§74僅保障立法委員）。故得對其辦公室聲請搜索票。 |
| (C) | ✓ | 依**§122 II**，對於第三人之住宅或其他處所，以**有相當理由可信為應扣押之物存在**時得搜索之。乙之研究室若有理由認為藏有回扣相關資料，檢察官得向法院聲請搜索票。 |
| (D) | ✗ | 依§122 II，對於**第三人之身體**亦得搜索，只要有相當理由可信為應扣押之物存在。本選項稱「不得搜索第三人乙之身體」，與法律規定不符，故為錯誤。 |

> [!NOTE]
> **重點整理**
> - **搜索對象範圍**：被告之身體、物件、住宅等（§122 I）；**第三人**之身體、物件、住宅等（§122 II），須有相當理由。
> - 立法院行政人員 ≠ 立法委員，不享國會自律與免搜索之保障。
> - 第三人之**身體**亦得為搜索對象，此為常見考點陷阱。

## 貳、附帶搜索

### 4、109年第12題（原第47題）

> 甲因涉嫌縱火燒住宅案，有證人指認被焚現場監視器內潑汽油者影像為甲，甲偵查中經檢察官傳訊，無理由不到庭應訊，警察遂持檢察官核發之拘票前往拘提甲，在甲住處庭院門口拘提甲時，經甲反抗。拘提後，警察能否同時入內搜索甲之住處？

**(A)** 可。甲涉嫌重大，且傳訊不到，故可入內搜索  
**(B)** 不可，其住處並非立即可觸及之處所  
**(C)** 不可，且不得逕行搜索其身體、隨身攜帶之物件、所使用之交通工具及其立即可觸及之處所  
**(D)** 可。甲拘提時反抗，故可入內搜索

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 涉嫌重大或傳訊不到並非擴大搜索範圍之法定事由。附帶搜索之範圍有嚴格法定限制，不得僅以犯罪嫌疑重大正當化入宅搜索。 |
| (B) | ✗ | 此選項僅指出住處非立即可觸及之處所，雖有部分正確，但未完整說明附帶搜索之法定範圍限制。 |
| (C) | ✓ | 依**§130**，附帶搜索之範圍限於被告之**身體、隨身攜帶之物件、所使用之交通工具及其立即可觸及之處所**。甲於住處庭院門口被拘提，住處內部顯然超出附帶搜索之法定範圍，不得入內搜索。本選項完整列出附帶搜索之法定範圍限制，說明搜索不得逾越此範圍而及於住處內部。 |
| (D) | ✗ | 甲拘提時反抗並不能擴大附帶搜索之範圍。反抗僅涉及得否使用強制力之問題，與搜索範圍無關。 |

> [!NOTE]
> **重點整理**
> - 附帶搜索（§130）之範圍：**身體、隨身攜帶之物件、所使用之交通工具、立即可觸及之處所**。
> - 「立即可觸及之處所」係指與逮捕或拘提地點緊密相連、被告伸手可及之範圍。
> - 住處內部若非拘提現場之立即可觸及處所，不得以附帶搜索名義入內搜索。
> - 犯罪嫌疑重大或反抗逮捕均非擴大搜索範圍之正當事由。

### 5、110年第5題（原第40題）

> 某甲開車因車燈不亮、形跡可疑而遭司法警察攔停後，發現車上載有毒品，甲遂開車衝撞警察試圖逃逸，下列敘述何者錯誤？

**(A)** 因甲是現行犯，所以司法警察毋需拘票，得逕行逮捕之  
**(B)** 司法警察逮捕後，得無令狀搜索甲之身體及車輛  
**(C)** 司法警察合法逮捕甲，因此亦得無令狀緊急搜索甲之住所  
**(D)** 附帶搜索的範圍僅限於甲正在使用之車輛，甲若有其他車輛則不在搜索範圍內

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 甲車上載有毒品且衝撞警察逃逸，屬**現行犯**（§88 I），不問何人均得逕行逮捕，無需令狀。 |
| (B) | ✓ | 依§130，逮捕時得附帶搜索被告之**身體及所使用之交通工具**。甲正在使用之車輛屬附帶搜索範圍，合法。 |
| (C) | ✗ | **緊急搜索（§131 II）**之要件為「逮捕犯罪嫌疑人或執行拘提、羈押，有事實足認有另外應扣押之物存在且情況急迫」時，始得為之，且搜索範圍為「住宅或其他處所」。本案僅因合法逮捕甲，**不當然**取得搜索其住所之權限，仍須符合§131 II之法定要件（如情況急迫、有事實足認住所有應扣押之物等）。 |
| (D) | ✓ | 附帶搜索之「所使用之交通工具」限於逮捕當時**甲正在使用**之車輛，其他未在使用之車輛不在附帶搜索範圍內。 |

> [!NOTE]
> **重點整理**
> - **附帶搜索（§130）**：逮捕或拘提時，得搜索身體、隨身物件、正在使用之交通工具、立即可觸及之處所。
> - **緊急搜索（§131 II）**：須另行符合法定要件（情況急迫 ＋ 有事實足認有應扣押之物），非逮捕後當然取得。
> - 附帶搜索 ≠ 緊急搜索：前者為逮捕之附隨權限，後者須額外要件。
> - 「所使用之交通工具」限於逮捕時正在使用者，不及於被告名下其他車輛。

### 6、111年第20題（原第55題）

> 通緝犯甲於KTV包廂內遇警察臨檢而遭逮捕，員警當場對甲之身體及隨身包實施搜索，發現有疑似海洛因粉末，隨即帶回警局。甲到警局後表示其機車停在KTV地下室停車場，員警通知巡邏警網前往搜索該機車，經撬開置物箱，發現 1 把改造手槍。下列關於警察所為附帶搜索之敘述，何者最為正確？

**(A)** 合法。因附帶搜索之範圍及於「所使用之交通工具」，故得對甲之機車實施附帶搜索  
**(B)** 不合法。因附帶搜索之範圍須限縮於「立即可觸及之處所」，該機車顯然已逾越此一範圍  
**(C)** 合法。因附帶搜索具有保全證據之作用，若非立即對該機車實施附帶搜索，證據有滅失之虞  
**(D)** 不合法。因附帶搜索限於原實施逮捕之執法人員，其他人員不得實施附帶搜索

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 雖§130規定附帶搜索範圍包含「所使用之交通工具」，但須限於逮捕當場被告正在使用且在**立即可觸及範圍**內者。甲之機車停在KTV地下室停車場，與逮捕地之KTV包廂有空間距離，甲於逮捕時無法立即觸及該機車。 |
| (B) | ✓ | 附帶搜索（§130）之範圍須限縮於「**立即可觸及之處所**」。甲於KTV包廂內被逮捕並帶回警局後，其機車停於KTV地下室停車場，**時間與空間上均已脫離逮捕現場**，顯非立即可觸及之處所，故該搜索不合法。 |
| (C) | ✗ | 附帶搜索之正當化事由並非保全證據，而係基於**防止被告湮滅或取用武器**之立即危險。即使有保全證據之需要，仍須符合附帶搜索之法定範圍限制。如需保全證據，應另行聲請搜索票。 |
| (D) | ✗ | 附帶搜索並無限於原逮捕人員始得實施之規定。本題違法原因在於範圍逾越，而非執行人員錯誤。 |

> [!NOTE]
> **重點整理**
> - 附帶搜索之「立即可觸及之處所」須符合**時間與空間上之緊密關聯**。
> - 逮捕後帶回警局，再派員搜索遠離逮捕地之交通工具，已**逾越附帶搜索之法定範圍**。
> - 附帶搜索之理論基礎：①防止被告取用武器危害安全；②防止被告湮滅隨身證據。離開逮捕現場後，此二目的已不存在。
> - 若需搜索逮捕現場以外之處所或交通工具，應另行聲請**搜索票**或符合**緊急搜索**要件。

## 參、同意搜索

### 7、108年第14題（原第49題）

> 警員甲深夜於臺北火車站著制服執行巡邏勤務，發現乙走路搖晃、神智不清，可能涉嫌施用毒品，遂對乙攔檢盤查，並要求乙將其所攜帶上鎖之行李箱打開，甲遂向乙出示證件並表示檢查後若無違禁品即可離去，乙同意打開行李箱，警員甲在乙之行李箱查獲一包重約 500 公克之海洛因，隨即將乙以現行犯當場逮捕，帶回警察局製作筆錄後，始讓乙在警局內簽署自願同意搜索筆錄。下列敘述，何者最為正確？

**(A)** 甲搜索違法，查獲之毒品絕對不得作為證據  
**(B)** 甲之搜索符合同意搜索之規定，查獲之毒品可為證據  
**(C)** 甲搜索違法，但查獲之毒品，法院仍可審酌人權保障及公共利益，決定是否具有證據能力  
**(D)** 甲之搜索，因係在火車站之公共場所執行，雖無搜索票，仍屬合法，查獲之毒品可為證據

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 我國對於違法搜索取得之證據採**相對排除法則**（§158-4），並非一律排除。法院應審酌人權保障及公共利益之均衡維護，決定有無證據能力。 |
| (B) | ✗ | 依**§131-1**，同意搜索須於**搜索前**取得被搜索人之書面同意。本案乙之自願同意搜索筆錄係於搜索後、帶回警局才簽署，**程序上不合法**。事前口頭同意不足以取代法定之書面同意程序。 |
| (C) | ✓ | 同意搜索未依法於搜索前取得書面同意，搜索程序**違法**。但依§158-4，違背法定程序取得之證據，法院應審酌**人權保障**及**公共利益**之均衡維護，決定有無證據能力，非當然排除。 |
| (D) | ✗ | 公共場所並非合法無令狀搜索之事由。搜索之合法性不因場所為公共或私人而有不同，仍須有法律授權依據。 |

> [!NOTE]
> **重點整理**
> - 同意搜索（§131-1）之法定要件：①搜索**前**取得書面同意；②出於被搜索人**自願**。
> - 事後補簽同意書 → 搜索程序違法。
> - 違法搜索取得之證據 → **相對排除法則**（§158-4）：審酌人權保障與公共利益之均衡。
> - 口頭同意搜索不符同意搜索之法定程式。

### 8、114年第4題（原第39題）

> 甲涉犯擄人勒贖罪嫌，警察人員未經檢察官之指揮及未持搜索票下，逕赴甲宅並得甲同意後搜索。依實務見解，下列敘述何者正確？

**(B)** 警察人員經甲同意後所為之搜索，應向法院陳報，始為合法  
**(C)** 甲主張同意搜索程序不合法，審理法官如認搜索程序不合法，所扣得之物得宣告不得作為證據  
**(D)** 甲於搜索中反悔，不再同意搜索，警察仍得續行搜索

#### 答案

(C)

#### 解析

|------|--------|------|
| (A) | ✗ | 同意搜索（§131-1）並未要求須有辯護律師陪同。只要被搜索人出於**自由意思**，以**書面同意**即可。是否有律師陪同非法定要件。 |
| (B) | ✗ | 同意搜索（§131-1）**無須向法院陳報**。須向法院陳報者為緊急搜索（§131 III），同意搜索與緊急搜索之程序要求不同。 |

> - 被搜索人得**隨時撤回同意**，撤回後不得續行搜索。

## 肆、緊急搜索與無令狀搜索

### 9、110年第7題（原第42題）

> 有關刑事訴訟法偵查階段無令狀搜索，下列敘述何者最為正確？

**(A)** 無令狀搜索，僅限於執行拘提、逮捕時始可實施  
**(B)** 為逮捕現行犯，於必要時可進入其所在住居所進行搜索  
**(C)** 實施緊急拘提，縱事後未核發拘票，無令狀搜索取得之物品無須返還  
**(D)** 無令狀搜索僅限於受搜索人同意，方得實施

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 無令狀搜索不限於拘提、逮捕之附帶搜索。尚包括**逕行搜索**（§131 I，如追蹤現行犯進入住宅）、**緊急搜索**（§131 II）、**同意搜索**（§131-1）等。 |
| (B) | ✓ | 依**§131 I②**，為逮捕現行犯，有事實足認其在內者，得不用搜索票，**進入住宅或其他處所搜索**之。此為逕行搜索之法定事由。 |
| (C) | ✗ | 若緊急拘提事後未獲檢察官核發拘票，該拘提即屬違法，附隨之無令狀搜索亦喪失正當性基礎。依法，違法搜索取得之物品應返還或依§158-4權衡其證據能力。 |
| (D) | ✗ | 同意搜索僅為無令狀搜索之一種類型。無令狀搜索尚包括附帶搜索、逕行搜索、緊急搜索等，均不以受搜索人同意為必要。 |

> [!NOTE]
> **重點整理**
> - 無令狀搜索之類型：①附帶搜索（§130）②逕行搜索（§131 I）③緊急搜索（§131 II）④同意搜索（§131-1）。
> - 逕行搜索（§131 I②）：為逮捕現行犯，有事實足認其在內者，得進入住宅搜索。
> - 逕行搜索後應陳報法院（§131 III），法院認為不應准許者，應於5日內撤銷之。

### 10、110年第8題（原第43題）

> 司法警察巡邏時行經一住戶之窗外，聽到屋子內有人辱罵髒話，且一名女子大喊救命，遂破門而入，下列敘述何者最為正確？

**(B)** 司法警察搜索違法，此種破門而入之情形應僅限於24小時內證據有偽造、變造、湮滅或隱匿之虞者，方得無令狀搜索  
**(C)** 司法警察搜索合法，只要破門後取得該名女子之同意，即屬合法之無令狀搜索  
**(D)** 司法警察搜索合法，因就客觀情形已可合理相信有人在內犯罪而情形急迫

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 有人大喊救命，情形急迫，可能有人正在犯罪或有生命身體危險，若要求先取得搜索票將緩不濟急。此種情形得依**§131 I**逕行搜索。 |
| (B) | ✗ | §131 I所列逕行搜索之事由，並不限於「24小時內證據有湮滅之虞」。尚包括「有事實足認有人在內犯罪而情形急迫」（§131 I①）。本案情形屬後者。 |
| (C) | ✗ | 同意搜索（§131-1）須於搜索前取得書面同意。事後取得同意不能回溯使搜索合法。且破門進入之合法性應依逕行搜索規定判斷。 |
| (D) | ✓ | 依**§131 I①**，有事實足認有人在內犯罪而**情形急迫**者，得不用搜索票逕行搜索。聽到辱罵及女子喊救命，客觀上可合理相信有人正在內犯罪（可能涉及傷害、妨害自由等），且情形急迫，符合逕行搜索之要件。 |

> **重點整理**
> - **逕行搜索（§131 I①）**：有事實足認有人在內犯罪而情形急迫 → 得不用搜索票逕行搜索。
> - 聽到喊救命聲即屬「情形急迫」之典型情形。
> - 逕行搜索後應於24小時內陳報法院（§131 III）。
> - 急迫情形下，要求先取得搜索票將無法及時保護被害人。

### 11、111年第12題（原第47題）

> 警察發現犯罪嫌疑人甲正強盜他人財物，於追捕過程中，甲逃至乙房屋內。下列敘述何者正確？

**(A)** 警察為逮捕甲，得進入到乙的房屋內  
**(B)** 警察應得檢察官之許可後，始得進入到乙的房屋內  
**(C)** 警察不得進入乙的屋內，因其為乙享有隱私權的處所  
**(D)** 警察進入乙的房屋後三日內，應報告檢察官，檢察官認為不應准許者，應於五日內撤銷之

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 甲正在強盜，屬**現行犯**（§88 I）。依**§131 I②**，為逮捕現行犯，有事實足認現行犯在內者，得不用搜索票進入住宅或其他處所搜索之。甲逃入乙房屋，警察有事實足認甲在內，得進入乙之房屋逮捕現行犯。 |
| (B) | ✗ | 逕行搜索（§131 I）以情況急迫為前提，**不須事先取得檢察官許可**。追捕現行犯時，若需等待檢察官許可，將使現行犯脫逃。搜索後依§131 III陳報法院即可。 |
| (C) | ✗ | 乙之隱私權雖應保障，但追捕現行犯之公共利益優先。§131 I②明文授權為逮捕現行犯得進入第三人之住宅或處所，已就隱私權與公共安全進行利益衡量。 |
| (D) | ✗ | 逕行搜索後之陳報程序為向**法院**陳報（§131 III），非向檢察官報告。且期限為**24小時內**陳報，法院認為不應准許者，應於**5日內撤銷**之。本選項誤載「3日」及「檢察官」。 |

> [!NOTE]
> **重點整理**
> - 逕行搜索（§131 I②）：為追捕現行犯，有事實足認其在內 → 得進入**第三人**之住宅搜索。
> - 追捕現行犯入第三人住宅：**無須檢察官許可**，事後24小時內**陳報法院**。
> - 逕行搜索後陳報對象：**法院**（非檢察官）；法院不准許 → 5日內撤銷。
> - 第三人住宅之隱私權在追捕現行犯之急迫情形中須讓步。

## 伍、扣押與保全扣押

### 12、109年第16題（原第51題）

> 甲涉嫌於民國105年組織詐騙集團，經檢察官偵查後發現甲詐騙所得達新臺幣（下同）5億元，並發現甲名下有於民國 98 年購入市值 3 億元之別墅一棟及於民國 106 年以詐騙所得購入藍寶堅尼跑車一部，並登記在其妻乙之名下。下列敘述何者最為正確？

**(A)** 甲所有之別墅，係甲犯罪前所購置，與甲涉嫌之犯罪無關，不得扣押  
**(B)** 乙名下之藍寶堅尼跑車，非甲名下之財產，不得扣押  
**(C)** 檢察官為確保沒收甲之犯罪所得，避免甲脫產規避追徵之執行，可向法院聲請裁定酌量扣押甲所有之別墅  
**(D)** 乙名下之藍寶堅尼跑車，非甲名下之財產，得扣押，但法院不得於判決中諭知沒收

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依**§133 II**，為保全追徵，必要時得**酌量扣押**犯罪嫌疑人、被告或第三人之財產。別墅雖於犯罪前購入，但若用以保全將來追徵之需要（犯罪所得5億之追徵），仍得扣押之。保全扣押之目的在確保將來沒收或追徵之執行，不以該財產與犯罪直接相關為限。 |
| (B) | ✗ | 依刑法§38-1 II，犯罪所得轉讓予第三人者，仍得沒收之。跑車以詐騙所得購入而登記在乙名下，屬**第三人持有之犯罪所得**，依法得扣押以保全沒收。 |
| (C) | ✓ | 依§133 II，為保全追徵，得**酌量扣押**犯罪嫌疑人之財產。檢察官於偵查中向法院聲請裁定扣押甲之不動產（別墅），以擔保將來追徵犯罪所得之執行，**程序合法**。 |
| (D) | ✗ | 依刑法§38-1 II，犯罪行為人以外之自然人或法人取得犯罪所得者，得沒收之。跑車以詐騙所得購入，登記在乙名下，法院得於判決中對乙名下之跑車**諭知沒收**。 |

> [!NOTE]
> **重點整理**
> - **保全扣押（§133 II）**：為保全追徵，得酌量扣押犯罪嫌疑人、被告或第三人之財產。
> - 保全扣押之對象不以犯罪所得本身為限，得及於犯罪嫌疑人之**其他財產**，以擔保將來追徵。
> - 犯罪所得轉讓第三人 → 仍得沒收（刑法§38-1 II），故亦得扣押以保全。
> - 檢察官聲請扣押不動產 → 須向**法院**聲請裁定。

### 13、110年第6題（原第41題）

> 警察甲巡邏夜市時，見有 3 人付錢後拿取一小包粉狀物品點燃吸食，懷疑該 3 人涉嫌販毒及吸毒而上前盤查，該3人發現後迅即騎車離開。甲撿獲其等留下之智慧型手機，無人承認持有該手機，該手機外殼有毒品反應。關於甲能否直接打開該手機查看其內訊息、通話紀錄，作為查辦販毒等案件之證據，依實務見解，下列敘述何者最為正確？

**(A)** 可以打開手機查看其內之訊息、通話紀錄  
**(B)** 甲應報請檢察官於其認有扣押必要時，聲請法官許可裁定後，方可查看手機內之訊息、通話紀錄

**(D)** 雖無緊急情況，甲以電話報請檢察官同意後，即可打開手機查看其內之訊息、通話紀錄

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 手機內之訊息、通話紀錄涉及**隱私權**與**通訊自由**，不得未經令狀程序逕行查看。智慧型手機之資料量龐大，隱私干預程度高，自須受嚴格之令狀原則保障。 |
| (B) | ✓ | 依實務見解，手機內之**電磁紀錄**（訊息、通話紀錄等）具有高度隱私敏感性，**不得逕行檢視**。應報請檢察官聲請法院許可後，始得查看手機內之資料。此涉及搜索扣押之程序保障（§133等）。 |
| (C) | ✗ | 警察局長非法律授權之許可主體。查看手機內容涉及人民隱私權之干預，須經**法院**許可（法官保留原則），不得由警察局長同意取代。 |

> [!NOTE]
> **重點整理**
> - 智慧型手機之內容（訊息、通話紀錄等）屬**電磁紀錄**，具高度隱私敏感性。
> - 查看手機內容須依**令狀原則**，聲請法院許可後始得為之。
> - 「法官保留原則」：干預人民基本權之強制處分，原則上須經法院許可。
> - 檢察官或警察局長之同意不能取代法官保留。

> 甲涉嫌經營地下匯兌而違反銀行法，因而有不法利得。檢察官在偵查中向法院聲請扣押甲名下之數筆不動產。關於檢察官之聲請扣押，下列敘述何者錯誤？

### 15、112年第16題（原第51題）

> 司法警察丙聲請得對甲人身實施搜索甲涉嫌販賣毒品之搜索票，執行搜索當時，甲駕駛其所有之小客車停在某便利商店旁，甲下車倚著駕駛座旁車門，販賣海洛因毒品2小包給有施用毒品的乙，丙當場逮捕甲，丙在搜索甲之身體時，發現甲另外持有偽造的警官證件（證物 A）及 10 張甲講不出來源、分屬不同人的提款卡及密碼條（證物 B），丙能否以甲可能另外涉嫌偽造文書、詐欺等罪嫌而查扣證物A、B？

**(A)** 不可以查扣。因證物A、B不屬於販毒搜索票記載之應扣押範圍  
**(B)** 可以同時查扣證物A、B。因只要依法實施搜索時發現另案應扣押之物，亦得扣押  
**(C)** 不可以查扣證物A、B。因非同一案件  
**(D)** 可以查扣證物A，因涉及假造警官、公權力證件，但不可查扣證物B，因非同一案件

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依**§152**（另案扣押），實施搜索或扣押時，**發現另案應扣押之物**亦得扣押之，不以搜索票記載之範圍為限。 |
| (B) | ✓ | 依**§152**，實施搜索時發現本案以外之另案應扣押之物，亦得扣押之。丙依法實施搜索（持有搜索票＋附帶搜索），在搜索甲身體時發現偽造警官證件及來源不明之提款卡，屬另案應扣押之物，**均得合法扣押**。另案扣押後應分別報告該管檢察官及法院。 |
| (C) | ✗ | §152另案扣押之規定，正是處理搜索中發現**非同一案件**應扣押之物的情形。非同一案件並非不得扣押之理由，反而是§152適用之前提。 |
| (D) | ✗ | 另案扣押（§152）不區分犯罪類型或嚴重性。只要依法實施搜索時發現應扣押之物，不論是偽造文書或詐欺犯罪之證據，均得扣押。 |

> [!NOTE]
> **重點整理**
> - **另案扣押（§152）**：依法實施搜索或扣押時，發現另案應扣押之物，亦得扣押之。
> - 另案扣押不以搜索票記載範圍為限，亦不以同一案件為必要。
> - 另案扣押後，應**分別報告該管檢察官及法院**。
> - 另案扣押之物如用作證據，其證據能力不因係另案發現而受影響。

### 二、高頻考點摘要

| 考點 | 核心觀念 |
|------|----------|
| 附帶搜索範圍（§130） | 限於身體、隨身物件、正在使用之交通工具、立即可觸及之處所 |
| 同意搜索程序（§131-1） | 須於搜索前取得書面同意，事後補簽不合法 |
| 逕行搜索進入住宅（§131 I） | 追捕現行犯得進入第三人住宅，事後24小時內陳報法院 |
| 保全扣押（§133 II） | 為保全追徵，得酌量扣押犯罪嫌疑人或第三人之財產 |
| 搜索票聲請權限（§128-1） | 司法警察官須報請檢察官許可後始得向法院聲請 |
| 另案扣押（§152） | 搜索時發現另案應扣押之物，亦得扣押 |
| 手機電磁紀錄之搜索 | 涉及高度隱私，須經法院許可（法官保留原則） |

### 三、關鍵區辨整理

| 概念A | 概念B | 區辨重點 |
|-------|-------|----------|
| 附帶搜索（§130） | 緊急搜索（§131 II） | 附帶搜索為逮捕/拘提之附隨權限，範圍限於立即可觸及；緊急搜索須有另行之急迫事由，範圍得及於住宅 |
| 逕行搜索（§131 I） | 緊急搜索（§131 II） | 逕行搜索有3款法定事由（如追捕現行犯入宅），24小時內陳報法院；緊急搜索以逮捕/拘提為前提，情況急迫，3日內陳報法院 |
| 同意搜索（§131-1） | 有令狀搜索（§128） | 同意搜索無須搜索票但須書面同意，無須陳報法院；有令狀搜索須向法院聲請搜索票 |
| 搜索票搜索 | 附帶搜索 | 搜索票搜索依票載範圍為之；附帶搜索範圍限於法定項目（身體、物件、車輛、立即可觸及處所） |
| 保全扣押（§133 II） | 一般扣押（§133 I） | 保全扣押以確保追徵為目的，對象得及於犯罪嫌疑人之其他財產；一般扣押對象為可為證據或得沒收之物 |
| 本案扣押 | 另案扣押（§152） | 本案扣押依搜索票記載範圍；另案扣押為搜索中發現本案以外應扣押之物 |
