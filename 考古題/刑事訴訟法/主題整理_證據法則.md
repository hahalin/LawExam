## 壹、嚴格證明與自由證明

### 1、108年第1題（原第36題）

> 甲向友人乙恐嚇取財多次，經檢察官以甲有恐嚇取財之習慣，依法提起公訴，除指明甲不顧朋友道義，向乙恐嚇取財，應量處重刑外，並請求宣告強制工作。法院審理中，甲坦承未經同意而拿走財物，但否認有不法所有之意圖，亦否認有竊盜之惡習，且堅稱：「乙並非其好友，平日常藉故予以羞辱」等語。下列敘述何者錯誤？

**(A)** 甲就被訴恐嚇取財之事實，不負證明其不存在之舉證責任  
**(B)** 甲與乙究竟是否好友，涉及科刑情狀之輕重，屬嚴格證明之對象  
**(C)** 甲有無不法所有之意圖，屬於犯罪事實之內容，須經嚴格證明  
**(D)** 甲有無恐嚇取財之習慣，係強制工作之基礎，並非以自由證明為已足

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 刑事訴訟採**無罪推定原則**（刑訴§154 II），被告不負自證無罪之責，舉證責任在檢察官。 |
| (B) | ✗ | 甲與乙是否好友，僅涉及**科刑情狀**（量刑因子），屬**自由證明**之事項，非嚴格證明之對象。嚴格證明限於犯罪事實之認定。 |
| (C) | ✓ | 不法所有意圖屬**主觀構成要件要素**，為犯罪事實之內容，須經嚴格證明（須以有證據能力之證據，經法定調查程序）。 |
| (D) | ✓ | 甲有無恐嚇取財之習慣，為宣告**強制工作（保安處分）**之前提事實，依實務見解屬嚴格證明之對象，不得僅以自由證明為已足。 |

> [!NOTE]
> **重點整理**
> - **嚴格證明**：犯罪事實（構成要件事實）及保安處分之基礎事實，須以有證據能力之證據，經法定調查程序證明之。
> - **自由證明**：訴訟法上事實（如管轄、上訴是否逾期）、科刑情狀等，證據能力及調查程序不受嚴格限制。
> - 保安處分（如強制工作）之基礎事實，因涉及人身自由之限制，屬嚴格證明之範疇。

### 2、108年第15題（原第50題）

> 第一審判決甲犯強盜罪，甲提起上訴，第二審認定甲上訴逾期，駁回上訴。甲不服，上訴第三審主張：第二審調查上訴是否逾期時，僅傳訊其住所地的大樓管理員乙，卻未讓其進行交互詰問，侵害其詰問權。甲之主張有無理由？

**(A)** 有理由。送達是否合法，關乎甲上訴期間是否屆滿之計算，對甲之權利影響甚巨，應採嚴格的證明，以進行交互詰問為必要  
**(B)** 無理由。送達是否合法，係屬自由的證明之事項，其證據調查之方式不以進行交互詰問為必要  
**(C)** 有理由。依據司法院釋字第582號解釋，刑事被告詰問證人之權利係屬憲法第8條第1項規定「非由法院依法定程序不得審問處罰」之正當法律程序所保障之權利，二審既然傳訊證人乙，自應進行交互詰問程序，方才符合憲法保障詰問權之意旨  
**(D)** 無理由。甲所涉案件屬於不得上訴三審之案件，故甲上訴三審之主張仍屬無理由

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 送達是否合法、上訴是否逾期，屬**訴訟法上之事實**，為**自由證明**事項，不以嚴格證明為必要，亦不以交互詰問為必要。 |
| (B) | ✓ | 送達之合法性為**訴訟程序事項**，屬自由證明範疇。自由證明之證據調查方式不受嚴格限制，**不以進行交互詰問為必要**。 |
| (C) | ✗ | 釋字第582號解釋保障之詰問權，係針對**犯罪事實之認定**（嚴格證明範圍），不及於訴訟程序事項之調查。上訴是否逾期屬程序事項，不在詰問權保障範圍內。 |
| (D) | ✗ | 強盜罪非刑訴§376所列不得上訴三審之案件，甲得上訴第三審。本選項前提錯誤。 |

> [!NOTE]
> **重點整理**
> - 訴訟程序事項（如送達合法性、上訴是否逾期）→**自由證明**，證據調查方式不以交互詰問為必要。
> - 犯罪事實之認定→**嚴格證明**，證人原則上應經交互詰問。
> - 釋字第582號保障之詰問權，適用範圍限於犯罪事實之認定。

### 3、111年第22題（原第57題）

> 所謂自由證明，係指使用之證據，其證據能力或證據調查程序不受嚴格限制而已，然仍必須為適法之證據始足當之。下列事項之調查，依近期實務見解，何者不適用自由證明？

**(A)** 被告科刑資料中，與犯罪事實有密切關連之犯罪動機、目的、所生危害、違反義務程度之調查  
**(B)** 共同正犯各人，就與構成要件事實無涉之犯罪利得若干、對犯罪利得有無處分權之認定  
**(C)** 被告限制出境、出海之事由是否具備、有無限制必要性之審酌  
**(D)** 證人於審判外之陳述，是否符合滯留國外或所在不明而無法傳喚或傳喚不到之要件

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 最高法院近期見解認為，科刑資料中**與犯罪事實有密切關連**之犯罪動機、目的、所生危害、違反義務程度等，因與犯罪事實密切相關，應採**嚴格證明**，不適用自由證明。此為對傳統見解之修正。 |
| (B) | ✗ | 共同正犯各人之犯罪利得若干、有無處分權，與構成要件事實無涉，屬沒收相關之附隨事項，得以自由證明為之。 |
| (C) | ✗ | 限制出境、出海之事由是否具備，屬**強制處分之程序事項**，以自由證明為已足。 |
| (D) | ✗ | 證人審判外陳述是否符合傳聞例外之要件（如滯留國外、所在不明），屬**傳聞法則適用之程序前提**，為訴訟法上事項，以自由證明為已足。 |

> [!NOTE]
> **重點整理**
> - 最高法院近期見解擴大嚴格證明之範圍：科刑資料中**與犯罪事實密切關連者**（犯罪動機、目的、所生危害、違反義務程度），應以嚴格證明為之。
> - 傳統上僅犯罪事實須嚴格證明，量刑因子一律自由證明；新見解對此有所修正。
> - 仍屬自由證明之事項：強制處分程序事項、傳聞例外之程序前提、沒收相關之附隨事項。

## 貳、自白法則

### 4、109年第4題（原第39題）

> 司法警察拘提犯罪嫌疑人甲到警局接受詢問，警察為使甲解除心防，佯稱只是聊聊，不必選任律師到場，並稱事實交待清楚之後，即可返家，甲為免被解送檢察官，表示願意配合，警察隨即開始製作筆錄，甲坦承犯行。關於甲自白警詢筆錄證據能力之敘述，下列何者最為正確？

**(A)** 警察並未使用強暴、脅迫之手段，甲之自白係出於自由意志，警詢筆錄有證據能力  
**(B)** 甲於警察詢問時之自白，並非於法官面前作成，屬審判外之陳述，自不得作為證據  
**(C)** 警察誘導使甲放棄辯護權，只要出於惡意，警詢筆錄中甲之自白，即不得作為證據  
**(D)** 警察誘導使甲放棄緘默權而自白，未必屬惡意，法院就該自白之證據能力仍可權衡

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 自白任意性之判斷，不以使用強暴脅迫為限。警察以詐術誘導被告放棄緘默權或辯護權，亦可能影響自白之任意性。惟本題情形，法院仍得權衡判斷。 |
| (B) | ✗ | 審判外之自白並非一律不得作為證據。依刑訴§156 I，被告之自白須出於任意性始有證據能力，並非以是否於法官面前作成為判斷標準。 |
| (C) | ✗ | 並非「只要出於惡意」即無證據能力。警察未告知辯護權之程序違反，應依刑訴§158-4權衡判斷證據能力，非一概排除。 |
| (D) | ✓ | 警察以詐術誘導被告放棄緘默權而自白，未必出於惡意，法院就該自白之證據能力，仍得依**刑訴§158-4**審酌人權保障與公共利益之均衡維護，**權衡判斷**有無證據能力。 |

> [!NOTE]
> **重點整理**
> - 被告自白之證據能力要件：**出於任意性**（刑訴§156 I），不得出於強暴、脅迫、利誘、詐欺、疲勞訊問或其他不正方法。
> - 警察未依法告知權利（緘默權、辯護權），其取得之自白，依§158-4**權衡法則**判斷證據能力。
> - 權衡因素：違背法定程序之程度、主觀意圖、侵害被告權益之輕重、犯罪所生危害、禁止使用證據對預防將來違法之效果、偵審人員如依法定程序有無發現該證據之必然性、證據取得違法對被告訴訟防禦不利益之程度等。

### 5、110年第11題（原第46題）

> 檢察官偵辦殺人案件，認甲涉嫌重大，惟為免打草驚蛇，仍以證人身分傳喚甲到庭，並以證人身分訊問，隨後即將甲列為被告起訴其涉犯殺人罪，法院就使用甲於偵訊中不利於己之陳述作為證據一事，依實務見解，下列敘述何者最為正確？

**(A)** 檢察官非屬詐欺取得自白，僅偵查手段不當，法院應依刑事訴訟法第158條之4審酌有無證據能力  
**(B)** 檢察官非屬詐欺取得自白，供述者之自白如出於自由意志且與事實相符，法院應認有證據能力  
**(C)** 檢察官構成詐欺取得自白，法院應依刑事訴訟法第158條之4審酌有無證據能力  
**(D)** 檢察官構成詐欺取得自白，法院應依刑事訴訟法第156條第1項認無證據能力

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 實務見解認為，檢察官明知甲為被告卻以證人身分傳喚訊問，已構成**詐欺取得自白**，非僅偵查手段不當。 |
| (B) | ✗ | 以詐欺方法取得之自白，不問是否出於自由意志或與事實相符，均無證據能力。 |
| (C) | ✗ | 以詐欺方法取得之自白，應適用§156 I 排除，非依§158-4 權衡。§156 I 為**絕對排除**規定。 |
| (D) | ✓ | 檢察官以證人身分傳喚實際上之被告，使其具結作證而為不利於己之陳述，構成**詐欺取得自白**，依**刑訴§156 I**，該自白**無證據能力**，不得作為證據。 |

> [!NOTE]
> **重點整理**
> - 檢察官以證人身分傳喚實質被告 → 構成**詐欺取得自白**（刑訴§156 I）。
> - §156 I 列舉之不正方法（強暴、脅迫、利誘、**詐欺**、疲勞訊問等）→ **絕對排除**，無證據能力。
> - §158-4 為**相對排除**（權衡法則），適用於其他違背法定程序取得之證據，不適用於§156 I 之情形。

### 6、110年第23題（原第58題）

> 被告甲於法院行準備程序時，主張其於警詢中之自白，係受警方威脅、利誘，而非出於任意性。有關法院自白任意性之調查，依實務見解，下列敘述何者正確？

**(A)** 關於自白任意性之有無，得由受命法官以裁定認定之  
**(B)** 關於自白任意性之調查，應於審判期日進行，不得於準備程序期日為之  
**(C)** 關於自白任意性之調查，得於其他事證調查後緊接調查  
**(D)** 關於自白任意性之調查，屬於訴訟法上之事實，以自由證明為已足

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 自白任意性之調查，法院應於審理中依調查證據之結果判斷之，非以裁定認定。受命法官得於準備程序進行調查，但最終認定由合議庭於判決中為之。 |
| (B) | ✗ | 自白任意性之調查，得於準備程序中先行調查（刑訴§273 I⑤），不以審判期日為限。準備程序本有篩選證據之功能。 |
| (C) | ✗ | 依刑訴§156 III，被告陳述其自白係出於不正方法者，應**先於其他事證而為調查**，不得於其他事證調查後才為之。此為**優先調查**原則。 |
| (D) | ✓ | 自白任意性之有無，屬**訴訟法上之事實**（非犯罪事實本身），依實務見解以**自由證明**為已足，其證據不限於有證據能力之證據，調查方式亦不受嚴格限制。 |

> [!NOTE]
> **重點整理**
> - 自白任意性之調查：屬**訴訟法上事實**，以**自由證明**為已足。
> - **優先調查原則**（刑訴§156 III）：被告抗辯自白出於不正方法，應**先於其他事證**而為調查。
> - 準備程序得先行調查自白任意性（刑訴§273 I⑤）。
> - 自白任意性 vs 自白之真實性：前者為證據能力問題（自由證明），後者為證明力問題（自由心證）。

### 7、111年第3題（原第38題）

> 甲涉嫌竊車，警方通知甲到案接受詢問，於詢問甲涉案情況時，警員因疏忽未告知甲有權保持緘默，甲在不知有此權利的情況下自白犯罪。依實務見解，該自白證據能力之判斷，下列敘述何者正確？

**(A)** 警員詢問犯罪嫌疑人時未依法告知享有緘默權，為重大之程序違法，甲之自白不得作為證據  
**(B)** 該自白原則上不得作為證據，但如經證明警員違背程序非出於惡意，且該自白係出於自由意志者，仍得作為證據  
**(C)** 如檢察官可證明甲之自白係出於任意，仍具有證據能力  
**(D)** 由法官審酌人權保障以及公共利益之均衡維護後，決定該自白有無證據能力

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 未告知緘默權雖屬程序違法，但並非一律排除證據能力。依實務見解，應依§158-4 權衡判斷，非絕對排除。 |
| (B) | ✗ | 非採「原則排除、例外容許」之判斷方式。實務採§158-4 之權衡法則，非以「非出於惡意」為唯一判斷標準。 |
| (C) | ✗ | 即使自白出於任意，程序違法之問題仍須處理。未告知緘默權屬§158-4 之程序違法問題，非僅以任意性判斷。 |
| (D) | ✓ | 未告知緘默權屬**違背法定程序**取得之證據，依**刑訴§158-4**，由法官**審酌人權保障及公共利益之均衡維護**後，決定該自白有無證據能力。 |

> [!NOTE]
> **重點整理**
> - 未告知緘默權（刑訴§95 I②）→ 違背法定程序 → 依**§158-4 權衡法則**判斷證據能力。
> - 區分：§156 I 之不正方法（強暴、脅迫、詐欺等）→ 絕對排除；§158-4 之違背法定程序 → 相對排除（權衡）。
> - 未告知緘默權 ≠ 脅迫取得自白，故不適用§156 I 絕對排除，而適用§158-4 權衡。

### 8、112年第6題（原第41題）

> 甲涉嫌殺人未遂，在員警恫嚇之下坦承行兇，並交代兇刀藏匿處。當天警方前往該處搜出兇刀，並將甲移送至地檢署。檢察官依法偵訊，甲僅言「警詢時所述皆屬實在」，檢察官據以起訴。審判中，甲抗辯警方對其脅迫，前後兩次自白和兇刀皆無證據能力。依據現行法及實務見解，下列敘述何者錯誤？

**(A)** 法院應優先調查甲之警詢自白是否出於脅迫  
**(B)** 檢察官應提出警詢錄音或證人等，證明甲之自白係出於自由意志，否則甲之警詢自白無證據能力  
**(C)** 因檢察官依法偵訊甲，其證據能力完全不受警詢脅迫甲之影響  
**(D)** 法院若是確定警方取得自白和脅迫手段有因果關係，則甲之警詢自白無證據能力

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依刑訴§156 III，被告抗辯自白出於不正方法，法院應**先於其他事證而為調查**（優先調查原則）。 |
| (B) | ✓ | 自白任意性之舉證責任在**檢察官**。檢察官應提出證據證明自白係出於任意性（如提出錄音、傳喚製作筆錄之員警），否則該自白不得作為證據。 |
| (C) | ✗ | 甲於偵訊中僅稱「警詢時所述皆屬實在」，若警詢自白係受脅迫而為，則偵訊自白受**前階段不正方法之影響**（「毒樹果實理論」之延伸），其證據能力亦**可能受影響**，並非完全不受影響。 |
| (D) | ✓ | 若脅迫手段與自白間具有**因果關係**，該自白即屬出於不正方法而為，依刑訴§156 I 無證據能力。 |

> [!NOTE]
> **重點整理**
> - **自白優先調查原則**（刑訴§156 III）：被告抗辯自白出於不正方法，應先於其他事證調查。
> - **自白任意性舉證責任**：由**檢察官**負擔，應提出證據證明自白出於任意。
> - **前後自白之連鎖效應**：前一次自白因不正方法而無證據能力時，後一次自白若僅援引前次自白內容，其證據能力亦受影響。
> - 兇刀作為衍生證據（毒樹果實），其證據能力另依§158-4 權衡判斷。

### 9、114年第9題（原第44題）

> 甲因涉嫌竊盜遭警方以現行犯逮捕。下列何種狀況取得甲之自白，原則上不得作為證據？

**(A)** 甲於夜間移送檢察署，經檢察官夜間訊問時，甲自白犯罪之筆錄  
**(B)** 甲同意警方夜間詢問，於警方夜間詢問時所製作甲自白犯罪之筆錄  
**(C)** 移送檢察署，經檢察官訊問後，命被告甲具保，甲於等候具保四小時後，無法具保，甲於檢察官訊問時自白犯罪之筆錄  
**(D)** 警詢時甲要求選任辯護人到場，於等候辯護人到場前之四小時內，甲於警詢時自白犯罪之筆錄

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 甲係現行犯遭逮捕後移送，屬刑訴§100-3 I但書②「經檢察官或法官許可」或③「經逮捕、拘提到場」之例外情形，得於夜間訊問，自白筆錄有證據能力。 |
| (B) | ✓ | 依刑訴§100-3 I但書①，經受詢問人**明示同意**者，得於夜間詢問，自白筆錄有證據能力。 |
| (C) | ✓ | 經檢察官命具保後等候具保，嗣後檢察官再行訊問，程序上合法，且非違法取得自白之情形。 |
| (D) | ✗ | 依刑訴§34-1，被告或犯罪嫌疑人請求選任辯護人到場，應即停止詢問。但等候辯護人逾**4小時**未到場者，始得開始或繼續詢問。本題甲要求辯護人到場，警方於**等候辯護人到場前之4小時內**即進行詢問，違反§34-1之等候義務，該自白**原則上不得作為證據**。 |

> [!NOTE]
> **重點整理**
> - 被告請求辯護人到場 → 應停止詢問，等候辯護人到場（刑訴§34-1）。
> - 等候辯護人到場之上限：**4小時**，逾4小時未到場，始得開始或繼續詢問。
> - 夜間訊問之例外（刑訴§100-3 I但書）：①受詢問人明示同意、②經檢察官或法官許可、③經逮捕拘提到場等。
> - 違反辯護人在場權之等候義務 → 取得之自白原則上不得作為證據。

## 參、補強證據

### 10、108年第3題（原第38題）

> 被告甲妨害性自主案件，法院依檢察官之聲請，傳喚曾為被害人乙進行心理治療之精神科醫師丙到庭，就乙於事發後心理治療過程中，被害人有無出現創傷後壓力症候群之跡象而為陳述。下列敘述，依實務見解，何者最為正確？

**(A)** 丙係學理上所稱鑑定證人，法院應適用刑事訴訟法第 202 條有關鑑定人具結之規定，由丙於陳述前具結，其結文內應記載必為公正誠實之鑑定等語  
**(B)** 由檢察官行主詰問時，於丙就待證事實為陳述前，檢察官針對有關丙之身分、學歷、經歷等事項，詰以「你是精神科專科醫師？」、「你是台大醫學系畢業？」、「你在台大醫院擔任精神科醫師已有20年之久？」係屬不當詰問，甲之辯護人因此聲明異議，審判長應認異議為有理由  
**(C)** 丙經合法傳喚，無正當理由而不到場者，法院得科以罰鍰，但不得拘提  
**(D)** 丙於法院就待證事實所為陳述，與乙關於被害事實之陳述，不具有同一性，得作為判斷乙所為不利於甲之陳述係屬真實之補強證據

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 丙雖為鑑定證人，但本質上仍為**證人**，應適用**證人具結**之規定（刑訴§186），而非鑑定人具結（§202）。鑑定證人之具結方式同證人。 |
| (B) | ✗ | 主詰問前就證人之身分、學歷、經歷等事項之詢問，屬**證人適格性之調查**，為交互詰問程序中合法之詰問方式，非屬不當詰問。辯護人之異議無理由。 |
| (C) | ✗ | 鑑定證人本質為證人，經合法傳喚無正當理由不到場者，法院得科以罰鍰，**亦得拘提**（刑訴§178）。 |
| (D) | ✓ | 丙就乙心理治療過程中是否出現創傷後壓力症候群之陳述，與乙關於被害事實之陳述**不具同一性**，係獨立之證據，得作為判斷乙陳述真實性之**補強證據**。 |

> [!NOTE]
> **重點整理**
> - **鑑定證人**：憑藉自身特別知識經驗，就過去親身體驗之事實為陳述者。本質為**證人**，適用證人之規定。
> - **補強證據**之要件：①與被告自白或被害人陳述不具同一性、②足以補強待證事實之真實性。
> - 精神科醫師就被害人心理治療過程之陳述，屬獨立證據，得為補強證據。

### 11、111年第4題（原第39題）

> 就告訴人之陳述作為論罪之依據而言，依實務見解，下列敘述何者錯誤？

**(A)** 告訴人之告訴，係以使被告受刑事訴追為目的，其經以證人身分具結之陳述是否與事實相符，法院仍應調查其他證據以資審認  
**(B)** 告訴人如係被害人之法定代理人，其將私人訪查目擊者之見聞，於審判中到庭具結，經交互詰問之後，法院原則上仍不得將該見聞之陳述採為認定被告犯罪之依據  
**(C)** 告訴人仍屬被告以外之人，其於檢察官偵查中具結陳明被害事實經過，該偵查筆錄與告訴人在審判中具結證述之內容不符，只要該偵查筆錄未於審判中經提示、朗讀或告以要旨，法院即不得將偵查筆錄採為認定被告犯罪之依據  
**(D)** 告訴人如未滿十六歲，其於審判中經傳喚到庭為證人，法院誤命其具結，行交互詰問，其證詞即不得採為認定被告犯罪之依據

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 告訴人之告訴以使被告受刑事追訴為目的，其陳述有偏頗之虞，法院仍應調查其他證據以資審認（**補強法則**之運用）。 |
| (B) | ✓ | 告訴人（法定代理人）轉述私人訪查目擊者之見聞，屬**傳聞證據**，原則上不得作為認定犯罪之依據，縱經具結及交互詰問亦然。 |
| (C) | ✓ | 偵查筆錄未於審判中經**提示、朗讀或告以要旨**，即未經法定調查程序，法院不得採為裁判基礎（刑訴§165、§155 II）。 |
| (D) | ✗ | 未滿16歲之人，依法**不得令其具結**（刑訴§186 I），法院誤命其具結，該具結無效，但其**證言本身仍有證據能力**（實務見解）。誤命具結不影響證言之證據能力，僅該具結無效。 |

> [!NOTE]
> **重點整理**
> - **告訴人陳述之補強**：告訴人以使被告受追訴為目的，其陳述須有**補強證據**佐證，法院始得採為論罪依據。
> - 未滿16歲之人**不得具結**（刑訴§186 I），誤命具結→具結無效，但**證言仍有證據能力**。
> - 偵查筆錄須經**法定調查程序**（提示、朗讀或告以要旨）始得作為裁判基礎。

### 12、112年第7題（原第42題）

> 我國實務認為，特定類型之證言虛偽可能性高，應有補強證據始得作為有罪判決的根據，被稱為超法規補強法則。依實務見解，此一法則不適用於下述何種證詞？

**(A)** 竊盜案件之被害人  
**(B)** 強盜案件之被告配偶  
**(C)** 組織犯罪案件之秘密證人  
**(D)** 殺人案件之目擊幼童

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 被害人之陳述，因其與被告立場對立，虛偽可能性較高，實務認為應有補強證據，屬超法規補強法則之適用對象。 |
| (B) | ✓ | 被告配偶之證詞，並非實務上超法規補強法則之適用對象。超法規補強法則主要針對**被害人**、**共犯（共同被告）**、**秘密證人**、**幼童證人**等虛偽可能性較高之證言。被告配偶得依法**拒絕證言**（刑訴§180），但若選擇作證，其證詞之證明力由法院自由心證判斷，非屬超法規補強法則之範疇。 |
| (C) | ✗ | 組織犯罪防制條例之秘密證人，因身分保密而無法由被告詰問，虛偽可能性高，實務認為應有補強證據。 |
| (D) | ✗ | 幼童證人因心智發展未臻成熟，記憶、認知及表達能力有限，虛偽或錯誤可能性較高，實務認為應有補強證據。 |

> [!NOTE]
> **重點整理**
> - **超法規補強法則**：法律未明文規定，但實務基於特定證言虛偽可能性高，要求應有補強證據。
> - 適用對象：①**被害人**陳述、②**共犯（共同被告）**陳述、③**秘密證人**、④**幼童證人**。
> - **不適用**：被告配偶。配偶有拒絕證言權（§180），但選擇作證時，其證明力由法院自由心證判斷。
> - 法定補強法則：被告自白（刑訴§156 II）須有補強證據。

## 肆、證人與具結

### 13、108年第16題（原第51題）

> 15 歲之甲目擊乙搶奪丙皮包，偵查中檢察官命甲具結後證稱：「當日夜間確實看到乙當街對丙搶奪皮包」等語。審判中被告乙主張：「甲年僅15歲，檢察官逕命具結，其證詞不具證據能力」等語，被告乙之辯護人另抗辯：「證人甲有深度近視，卻僅配帶不足度數之眼鏡，於夜間應該看不清楚搶奪行為人是否為被告乙，其證詞不能證明被告有罪」等語，依實務見解，下列敘述何者正確？

**(A)** 檢察官誤命未滿16歲之證人甲具結作證，其所為證言乃無具結能力者之證言，仍有證據能力  
**(B)** 檢察官誤命未滿16歲之證人甲具結作證，其作證之法定程序於法有違，其證言自無證據能力  
**(C)** 被告乙之辯護人所為之抗辯係屬證據能力有無的問題，與證詞之證據價值無關  
**(D)** 檢察官誤命未滿16歲之證人甲具結作證，已生具結之效力，如有虛偽陳述，應以偽證罪處罰

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依實務見解，未滿16歲之人為**不得具結**之人（刑訴§186 I），檢察官誤命具結，該具結無效，但其**證言仍有證據能力**。蓋具結與否不影響證言之證據能力，僅具結無效而已。 |
| (B) | ✗ | 誤命具結僅使該具結無效，不影響證言之證據能力。證言本身仍為合法取得之供述證據。 |
| (C) | ✗ | 辯護人主張甲因深度近視於夜間看不清楚，屬**證明力（證據價值）**之爭執，非證據能力問題。選項(C)將兩者混淆。 |
| (D) | ✗ | 不得具結之人經誤命具結，**具結不生效力**，縱有虛偽陳述亦**不成立偽證罪**。偽證罪以合法具結為前提。 |

> [!NOTE]
> **重點整理**
> - 不得具結之人（刑訴§186 I）：未滿16歲、因精神障礙不解具結意義者。
> - 誤命不得具結之人具結 → **具結無效**，但**證言仍有證據能力**。
> - 具結無效 → 不成立偽證罪（偽證罪以合法具結為前提）。
> - **證據能力** vs **證明力**：前者為法律判斷（是否得為證據），後者為事實判斷（證據之價值、可信度）。

### 14、109年第6題（原第41題）

> 甲、乙共同毆打丙致死，被提起公訴。因甲遲未到案，法院乃依法將甲通緝，並就乙部分判決有罪確定。嗣甲通緝到案，審理中，法院依檢察官之聲請，傳喚證人乙及當時在場、年僅 14 歲之丁作證；另傳喚鑑定人戊說明其如何判斷丙係為尖銳之刀器所殺。下列敘述何者正確？

**(A)** 乙恐因陳述而受有「偽證罪」追訴、處罰，自得拒絕證言  
**(B)** 甲之反對詰問權，雖屬憲法保障之基本訴訟權，不得任意剝奪；但甲非不得予以放棄  
**(C)** 丁年僅14歲，其所為證言乃無具結能力之人之證言，並無證據能力  
**(D)** 戊倘經合法傳喚，無正當理由不到庭，法院得予拘提，以查明事實真相

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 刑訴§181規定證人恐因陳述致**自己或與其有一定關係之人**受刑事追訴或處罰者，得拒絕證言。但乙恐受「偽證罪」追訴，係因作證本身可能虛偽而生之風險，非因陳述內容致受刑事追訴，**不得據此拒絕證言**。 |
| (B) | ✓ | 反對詰問權（對質詰問權）為憲法保障之基本訴訟權（釋字第582號），不得任意剝奪，但被告得**自行放棄**。惟本選項雖正確，但非最佳答案。 |
| (C) | ✗ | 丁年僅14歲，屬**不得具結**之人（刑訴§186 I），但其仍有**證人適格**，所為證言**仍有證據能力**，僅不得令其具結。 |
| (D) | ✓ | 鑑定人經合法傳喚，無正當理由不到庭者，依刑訴§197準用§178，法院得**科以罰鍰**並得**拘提**。 |

> [!NOTE]
> **重點整理**
> - 拒絕證言權（刑訴§181）：恐因陳述致自己或特定關係人受刑事追訴者得拒絕證言，但**恐受偽證罪追訴**不在此限。
> - 未滿16歲→不得具結，但**仍有證人適格**，證言有證據能力。
> - 鑑定人準用證人規定（§197），經合法傳喚不到場→得科罰鍰、得拘提。
> - 反對詰問權為憲法保障之權利，但被告得自行放棄。

> 刑事訴訟法第197條規定，鑑定另有特別規定外，準用關於人證之規定。有關鑑定人之義務，下列敘述何者錯誤？

**(C)** 應受選任之義務  
**(D)** 公正誠實義務

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 鑑定人準用證人之到場義務（刑訴§197準用§178），經合法傳喚應到場，無正當理由不到場者得科罰鍰或拘提。 |
| (B) | ✓ | 鑑定人應於鑑定前具結（刑訴§202），具結義務為鑑定人之法定義務。 |
| (C) | ✗ | 鑑定人由法院或檢察官**選任**（刑訴§198），受選任後有到場及鑑定之義務，但**不負有「應受選任」之義務**。換言之，鑑定人之產生係由法院或檢察官主動選任，非鑑定人有義務接受選任。此與證人之不可替代性不同。 |
| (D) | ✓ | 鑑定人具結時應記載「必為公正誠實之鑑定」（刑訴§202），公正誠實義務為鑑定人之核心義務。 |

> [!NOTE]
> **重點整理**
> - 鑑定人之義務：①到場義務、②具結義務、③公正誠實義務、④鑑定義務。
> - 鑑定人**無「應受選任」之義務**。鑑定人由法院/檢察官選任（§198），具有**可替代性**。
> - 證人 vs 鑑定人：證人具**不可替代性**（因親身經歷之事實無法替代）；鑑定人具**可替代性**（專業知識可由其他專家替代）。

(D)

#### 解析

| 選項 | 正確？ | 說明 |

> - 法官不得於辦公室私自勘驗關鍵證據，應於審判中或通知當事人到場後實施。

### 18、108年第2題（原第37題）

> 被告甲將其殺人計畫、步驟詳細記載於「記事（紙）本」中，而於犯罪偵查過程經依法扣押。對於得為證據之本項甲之「記事（紙）本」，法院應如何進行證據調查？下列敘述，何者最為正確？

**(A)** 應依刑事訴訟法第164條第1項物證之調查程序進行證據調查  
**(B)** 應依刑事訴訟法第165條書證之調查程序進行證據調查  
**(C)** 應依刑事訴訟法第165條之1準用書證之調查程序進行證據調查  
**(D)** 應依刑事訴訟法第166條對人證之調查程序進行證據調查

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 刑訴§164 I 規定之物證調查程序，係對**物品**本身（如凶器、毒品等）提示當事人辨認。記事本之證據價值在於其**記載內容**，非物品本身之外觀形狀，故應以書證調查程序為之。 |
| (B) | ✓ | 記事本記載殺人計畫與步驟，其證據價值在於**文書之記載內容**，應依刑訴§165書證之調查程序，宣讀或告以要旨。 |
| (C) | ✗ | §165-1 係關於「錄音、錄影、電磁紀錄等」準用書證之調查程序，記事本為紙本文書，應直接適用§165，非準用§165-1。 |
| (D) | ✗ | §166 係證人交互詰問之規定，記事本非人證，不適用人證調查程序。 |

> [!NOTE]
> **重點整理**
> - **物證**（§164）：以物品本身之存在、外觀、形狀為證據 → 提示辨認。
> - **書證**（§165）：以文書之記載內容為證據 → 宣讀或告以要旨。
> - 同一文件可能兼具物證與書證性質，應依其**待證事實**決定調查程序。
> - 記事本記載犯罪計畫 → 以記載內容為證據 → 書證調查程序。

### 20、110年第15題（原第50題）

> 有關證據性質之敘述，下列何者錯誤？

**(A)** 鑑定為人的證據方法，鑑定人到庭應具結，並接受詰問  
**(B)** 警察製作之刑事現場勘察報告，其證據性質為書證，以提示作為調查方式  
**(C)** 鑑定證人本質上是證人，具有不可代替性，應適用證人之調查程序  
**(D)** 共同被告本質上為證人，得為程序分離，並依人證之方式為調查

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 鑑定人為**人的證據方法**，到庭應依§202具結，並得接受當事人之詰問（§208 II準用§166以下）。 |
| (B) | ✗ | 警察製作之刑事現場勘察報告，實務見解認為其性質為**勘驗之性質**，並非單純書證。勘驗應依§212以下之規定為之，以提示調查方式處理有所不足。且依實務見解，此類報告含有製作者之判斷，應傳喚製作者到庭接受詰問。 |
| (C) | ✓ | 鑑定證人本質上為**證人**，係憑藉特別知識經驗就過去親身體驗之事實為陳述，具有**不可替代性**，應適用證人之調查程序（具結、交互詰問）。 |
| (D) | ✓ | 共同被告對其他共同被告而言，本質上為**證人**（釋字第582號），得為程序分離後，依人證之方式調查（具結、交互詰問）。 |

> [!NOTE]
> **重點整理**
> - **鑑定人**：人的證據方法，具可替代性，應具結，得接受詰問。
> - **鑑定證人**：本質為證人，具不可替代性，適用證人調查程序。
> - **共同被告**：對其他共同被告為證人（釋字第582號），得程序分離後依人證方式調查。
> - 警察刑事現場勘察報告：非單純書證，含有勘驗性質，應傳喚製作者到庭詰問。

### 21、112年第24題（原第59題）

> 甲涉嫌竊盜乙所有之貴重手錶1只，審判長於調查證據時，僅向當事人提示手錶之扣押筆錄及照片，而未提示手錶使當事人辨認。依實務見解，下列關於法院踐行調查程序之敘述，何者錯誤？

**(A)** 手錶之同一性雖無爭議，法院亦得提示手錶  
**(B)** 手錶之同一性無爭議時，審判長得僅向當事人提示手錶之扣押筆錄及照片  
**(C)** 手錶之同一性有爭議時，法院應僅就扣押筆錄及照片，以書證調查程序行之  
**(D)** 手錶之同一性有爭議時，法院應提示手錶

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 即使手錶同一性無爭議，法院仍**得**提示手錶供當事人辨認，此為法院之裁量。 |
| (B) | ✓ | 手錶同一性無爭議時，依實務見解，審判長得僅提示扣押筆錄及照片即可，無須逐一提示物證。 |
| (C) | ✗ | 手錶同一性**有爭議**時，法院**應提示手錶本身**（物證調查程序，§164），不得僅以扣押筆錄及照片代替。以書證程序調查無法確認物證之同一性。 |
| (D) | ✓ | 手錶同一性有爭議時，法院**應提示手錶**使當事人辨認（§164 I），以確認該扣案物即為系爭標的物。 |

> [!NOTE]
> **重點整理**
> - **物證調查程序**（§164）：提示當事人辨認，適用於物品之同一性有爭議時。
> - **書證調查程序**（§165）：宣讀或告以要旨，適用於文書記載內容之調查。
> - 物證同一性**無爭議** → 得以扣押筆錄及照片替代提示；**有爭議** → 應提示物證本身。
> - 法院調查證據應依證據性質選擇正確之調查程序。

## 柒、傳聞法則與傳聞例外

### 22、110年第14題（原第49題）

> 有關性侵害案件被害人「警詢筆錄」，作為被告有罪證據之法律爭議，司法院釋字第 789 號解釋認為：「應兼顧性侵害案件發現真實與有效保護性侵害犯罪被害人之正當目的。」下列敘述何者錯誤？

**(A)** 一律應利用聲音、影像傳送而為隔離詰問  
**(B)** 應強化被告對被害人以外之其他證人對質、詰問權  
**(C)** 對於被告之防禦權，應採取訴訟上之有效補償措施  
**(D)** 被害人警詢筆錄不得作為有罪唯一證據

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 釋字第789號解釋並未要求「**一律**」應以隔離詰問方式為之。性侵害案件被害人之詰問方式應依個案情況而定，得採取隔離詰問等保護措施，但非強制一律適用。「一律」二字過於絕對，為錯誤敘述。 |
| (B) | ✓ | 釋字第789號認為，為補償被告未能直接詰問被害人之不利益，應**強化被告對被害人以外之其他證人**之對質、詰問權。 |
| (C) | ✓ | 釋字第789號明確指出，對於被告之防禦權，應採取**訴訟上之有效補償措施**，例如強化其他證人之詰問機會、補強證據之要求等。 |
| (D) | ✓ | 釋字第789號認為被害人警詢筆錄雖得作為證據，但**不得作為有罪之唯一證據**，仍應有其他補強證據以增強法院確信。 |

> [!NOTE]
> **重點整理**
> - **釋字第789號**：性侵害案件被害人警詢筆錄得依刑訴§159-2作為證據，但應兼顧被告防禦權保障。
> - 補償措施：① 強化對其他證人之對質詰問權；② 不得作為有罪唯一證據；③ 得採隔離詰問但非強制一律適用。
> - 性侵害被害人保護與被告防禦權之平衡：核心在於「有效補償」而非「一律排除」。

### 23、114年第11題（原第46題）

> 檢察官偵辦候選人甲的賄選案件，傳喚證人乙證明甲的樁腳行賄，偵訊時進行錄音，並依法命其具結後製作偵訊筆錄。審判中，甲的辯護人主張乙之偵訊筆錄無證據能力。其所提出之下列主張，何者為最高法院實務見解所採認？

**(A)** 檢察官偵訊乙時，依法不得錄音，故偵訊程序違法  
**(B)** 偵訊筆錄之記載與偵訊錄音之重要內容不一致  
**(C)** 偵訊筆錄係由訊問之檢察官自行製作，非由書記官製作  
**(D)** 偵訊筆錄未逐字記錄，即屬於顯有不可信情況之傳聞證據

#### 答案

(B)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 刑訴§100-1 I規定訊問被告應全程連續錄音，對證人之偵訊雖無明文強制錄音，但檢察官偵訊證人時進行錄音並不違法，反而有助於程序透明。 |
| (B) | ✓ | 依最高法院實務見解，偵訊筆錄之記載如與偵訊錄音之**重要內容不一致**，將影響該偵訊筆錄之可信性，可認定為刑訴§159-1 II「**顯有不可信之情況**」，而否定其證據能力。 |
| (C) | ✗ | 偵訊筆錄由檢察官自行製作或由書記官製作，均不影響其證據能力。實務上檢察官自行操作電腦製作筆錄並非罕見，此不構成程序違法之事由。 |
| (D) | ✗ | 偵訊筆錄未逐字記錄並不當然屬於「顯有不可信」之情況。筆錄採摘要記載並經證人閱覽無訟後簽名者，仍具證據能力，僅於筆錄與錄音內容有**重要歧異**時始生影響。 |

> [!NOTE]
> **重點整理**
> - **偵訊筆錄證據能力之判斷**（刑訴§159-1 II）：原則上有證據能力，但「顯有不可信之情況」時例外無證據能力。
> - 「顯有不可信」之典型情形：筆錄記載與偵訊錄音之**重要內容不一致**。
> - 筆錄未逐字記錄≠顯有不可信；筆錄由檢察官自行製作≠程序違法。
> - 偵訊證人時進行錄音非違法行為，不影響程序合法性。

### 24、114年第14題（原第49題）

> 甲、乙為警當場查獲涉嫌共同販賣毒品予丙，甲、乙於警詢時，一致指稱與丁有販賣毒品予丙之犯意聯絡及行為分擔等情，並經依法調取甲與乙、丁共同販賣毒品予丙過程之行動電話通信（聯）紀錄，甲、乙、丁均經提起公訴。於審判中，甲、乙以證人身分作證時，均否認其等於警詢中所為不利於丁之證述係屬實在，丁則抗辯甲、乙於警詢之陳述，不具證據能力。下列敘述何者正確？

**(A)** 甲、乙於警詢中所為陳述，與審判中不符，如為證明犯罪事實所必要者，即得依刑事訴訟法第159條之2之規定，均具有證據能力  
**(B)** 刑事訴訟法第155條第1項前段之規定，證據之證明力，由法院本於確信自由判斷。故法院不違背經驗法則及論理法則，依憑甲、乙所為不利於丁之證述，即據以認定丁共同販賣毒品予丙之犯罪事實，採證合法  
**(C)** 證人即甲之友人戊於審判中具結後證述，甲曾向戊表示其係與乙、丁共同販賣毒品予丙等情，具有證據能力，且可作為判斷甲於警詢中所為不利於丁之陳述係屬真實之補強證據  
**(D)** 甲與乙、丁共同販賣毒品予丙過程之行動電話通信（聯）紀錄，具有證據能力，且可作為判斷甲於警詢中所為不利於丁之陳述係屬真實之補強證據

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依刑訴§159-2，被告以外之人於警詢之陳述，與審判中不符，須具備「為證明犯罪事實所必要」且「具有較可信之特別情況」二要件，不能僅因「為證明犯罪事實所必要」即認有證據能力。 |
| (B) | ✗ | 共同被告之證述屬**共犯自白**性質，依實務見解，共犯之自白不得作為有罪判決之唯一證據，應有**補強證據**。僅憑甲、乙不利於丁之證述，尚不足認定丁之犯罪事實。 |
| (C) | ✗ | 戊係轉述甲之陳述內容，屬於**傳聞證據**（轉述他人審判外陳述），雖得具有證據能力（經具結），但不得作為判斷甲警詢陳述係屬真實之**補強證據**。補強證據須為獨立於待證證據之別一證據，戊僅轉述甲之話，不具獨立性。 |
| (D) | ✓ | 行動電話通信（聯）紀錄為**非供述證據**（非傳聞證據），具有證據能力。且通聯紀錄可證明甲、乙、丁間確有聯繫，能獨立於甲、乙之證述之外，作為判斷甲於警詢中所為不利於丁之陳述係屬真實之**補強證據**。 |

> [!NOTE]
> **重點整理**
> - **共同被告警詢陳述翻供**時，其警詢陳述之證據能力須依刑訴§159-2判斷，需具備「必要性」及「較可信之特別情況」。
> - 共犯自白不得為有罪判決之唯一證據，應有**補強證據**。
> - **補強證據**須具獨立性，轉述他人陳述之傳聞證據不具獨立性，不得為補強證據。
> - 通信（聯）紀錄為**非供述證據**，具獨立性，得作為補強證據。

## 捌、違法取得證據排除

### 25、110年第13題（原第48題）

> 被告甲涉嫌殺害妻乙，甲於命案發生前曾書寫遺書表示：因乙結交男友，故以殺害自己女兒性命要脅乙不能離去云云。檢察官提出該遺書證明被告有殺人動機。依實務見解，該遺書有無證據能力？

**(A)** 與證明犯罪事實有關，有證據能力  
**(B)** 與犯罪事實無關，無證據能力  
**(C)** 屬證明被告品格之證據，無證據能力  
**(D)** 被告提出時有證據能力，檢察官提出則無證據能力

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 遺書記載甲以殺害女兒要脅乙不得離去，顯示甲對乙有強烈之控制慾望與敵意，得用以證明甲具有**殺人動機**。殺人動機與犯罪事實有關，遺書**有證據能力**。且遺書為被告親自書寫之文書，非傳聞證據。 |
| (B) | ✗ | 殺人動機係犯罪事實認定之重要輔助證據，遺書內容與犯罪事實具有關聯性。 |
| (C) | ✗ | 遺書係用以證明被告之**殺人動機**，非僅用於證明被告品格。動機證據不等於品格證據，得作為犯罪事實認定之輔助。 |
| (D) | ✗ | 證據能力之有無不因提出者為被告或檢察官而異。合法取得之證據，無論何方提出均有證據能力。 |

> [!NOTE]
> **重點整理**
> - **動機證據**：用以證明被告犯罪動機之證據，與犯罪事實具有關聯性，有證據能力。
> - 被告親自書寫之遺書，屬**非供述證據**（文書證據），非傳聞證據，有證據能力。
> - 動機證據 ≠ 品格證據：動機證據用以說明犯罪行為之原因，與品格證據（用以證明被告性格傾向）性質不同。
> - 證據能力不因提出者身分而異。

### 26、114年第15題（原第50題）

> 關於證據法則之敘述，下列何者錯誤？

**(A)** 法院於第一次審判期日前，認為檢察官指出之證明方法顯不足認定被告有成立犯罪之可能時，得視情況通知檢察官補正，或直接以裁定駁回起訴  
**(B)** 當事人、代理人、辯護人或輔佐人應就調查證據之範圍、次序及方法提出意見  
**(C)** 法院為發見真實，得依職權調查證據。但於公平正義之維護或對被告之利益有重大關係事項，法院應依職權調查之  
**(D)** 當事人、代理人、辯護人或輔佐人聲請調查之證據，法院認為不必要者，得以裁定駁回之

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依刑訴§161 II，法院於第一次審判期日前，認檢察官指出之證明方法顯不足認定被告有成立犯罪之可能時，應以**裁定**定期通知檢察官補正，逾期未補正者，得以裁定駁回起訴。法院**不得直接以裁定駁回起訴**，須先通知補正。選項稱「得視情況通知檢察官補正，**或直接以裁定駁回起訴**」，後半段錯誤。 |
| (B) | ✓ | 依刑訴§163 III，當事人、代理人、辯護人或輔佐人應就調查證據之範圍、次序及方法提出意見。此為當事人進行主義之體現。 |
| (C) | ✓ | 依刑訴§163 II，法院為發見真實，**得**依職權調查證據；但於公平正義之維護或對被告之利益有重大關係事項，法院**應**依職權調查之。 |
| (D) | ✓ | 依刑訴§163-2 I，當事人等聲請調查之證據，法院認為不必要者，得以裁定駁回之。§163-2 II 列舉不必要之情形。 |

> [!NOTE]
> **重點整理**
> - **起訴審查**（§161 II）：法院認檢察官舉證不足 → 應先**裁定命補正** → 逾期未補正 → 始得裁定駁回起訴。不得直接駁回。
> - 法院職權調查（§163 II）：原則上「得」職權調查；例外於公平正義之維護或被告利益有重大關係時「應」職權調查。
> - 駁回調查證據之聲請（§163-2）：法院認為不必要者得裁定駁回，但當事人得於上訴時主張。

### 二、高頻考點摘要

| 考點 | 核心觀念 |
|------|----------|
| 自白任意性（§156 I） | 以強暴、脅迫、利誘、詐欺等不正方法取得之自白 → 絕對排除 |
| 權衡法則（§158-4） | 違背法定程序取得之證據 → 審酌人權保障與公共利益均衡維護 → 相對排除 |
| 自白優先調查（§156 III） | 被告抗辯自白出於不正方法 → 應先於其他事證調查 |
| 嚴格證明 vs 自由證明 | 犯罪事實→嚴格證明；訴訟法上事實→自由證明；科刑密切關連事項→近期擴大嚴格證明 |
| 超法規補強法則 | 被害人、共犯、秘密證人、幼童證人之證言 → 應有補強證據 |
| 不得具結之人（§186 I） | 未滿16歲、精神障礙不解具結意義 → 誤命具結無效，但證言仍有證據能力 |
| 鑑定選任權限 | 偵查中→檢察官；審判中→法院；概括選任→合法 |
| 物證 vs 書證調查程序 | 物證→提示辨認（§164）；書證→宣讀或告以要旨（§165） |
| 性侵被害人警詢筆錄（釋字789號） | 得作證據但不得為唯一證據，應強化對其他證人詰問權，非強制一律隔離詰問 |
| 偵訊筆錄與錄音不一致 | 筆錄與錄音重要內容不一致→屬§159-1 II「顯有不可信」→無證據能力 |
| 共犯警詢陳述翻供與補強 | 共犯警詢陳述須依§159-2判斷，且需獨立補強證據（如通聯紀錄），傳聞證據不具獨立性 |

### 三、關鍵區辨整理

| 概念A | 概念B | 區辨重點 |
|-------|-------|----------|
| 嚴格證明 | 自由證明 | 嚴格證明：犯罪事實，須以有證據能力之證據經法定程序調查；自由證明：訴訟法上事實，證據能力及調查程序不受嚴格限制 |
| §156 I 絕對排除 | §158-4 相對排除 | §156 I：不正方法取得自白（強暴、脅迫、詐欺等）一律排除；§158-4：其他違背法定程序（未告知權利等）權衡排除 |
| 證據能力 | 證明力 | 證據能力為法律判斷（得否為證據）；證明力為事實判斷（證據之價值可信度），由法院自由心證 |
| 法定補強法則 | 超法規補強法則 | 法定：被告自白（§156 II）；超法規：被害人、共犯、秘密證人、幼童證人陳述（實務創設） |
| 鑑定人 | 鑑定證人 | 鑑定人：由法院選任，具可替代性，依§202具結；鑑定證人：本質為證人，不可替代，適用證人程序 |
| 物證 vs 書證調查程序 | 物證→提示辨認（§164）；書證→宣讀或告以要旨（§165）；同一文件依待證事實決定 |
| 自白任意性調查 | 犯罪事實調查 | 自白任意性：訴訟法上事實，自由證明即可，應優先調查；犯罪事實：嚴格證明 |
| 概括選任鑑定 | 個案囑託鑑定 | 概括選任：檢察長事前選任鑑定機關，員警得依此送鑑；個案囑託：由檢察官或法院就個案囑託 |
| 偵訊筆錄證據能力 | 警詢筆錄證據能力 | 偵訊（§159-1 II）：原則有證據能力，例外「顯有不可信」時無；警詢（§159-2）：原則無證據能力，例外「必要性＋較可信」時有 |
| 補強證據之獨立性 | 傳聞證據之轉述 | 補強證據須具獨立性，僅轉述他人陳述不具獨立性，不得為補強證據 |
