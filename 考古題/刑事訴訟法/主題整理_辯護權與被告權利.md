> 涵蓋範圍：辯護人之選任與強制辯護、辯護人之權利（接見、閱卷）、輔佐人  
> 資料來源：108～114年司律一試刑事訴訟法考古題（不含113年）

## 壹、辯護人之選任與強制辯護

### 1、112年第44題（原第44題）

> 公務員甲承辦工程招標，涉嫌受廠商乙請託洩漏底價，乙因此得標。甲、乙在偵查中未選任辯護人，甲矢口否認洩漏底價，乙則坦承不諱，檢察官遂以二人共犯主管職務圖利罪（貪污治罪條例第 6條第1項第4款最輕法定本刑有期徒刑5年以上）起訴。有關本案之辯護人選任或指定，下列敘述何者正確？

**(A)** 本案係偵查中強制辯護案件，檢察官未為甲、乙指定辯護人係屬違法  
**(B)** 本案係審判中任意辯護案件，甲、乙得隨時決定是否選任辯護人  
**(C)** 本案係審判中強制辯護案件，甲、乙因利害相反，審判長不得為其二人指定共同辯護人  
**(D)** 本案係審判中任意辯護案件，甲、乙因利害相反，刑事訴訟法明定不得選任共同辯護人

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 強制辯護之規定（刑訴§31 I）僅適用於**審判中**，偵查中並無強制辯護之明文規定。偵查中檢察官未指定辯護人並不違法。 |
| (B) | ✗ | 本案所犯為最輕本刑5年以上有期徒刑之罪，屬**審判中強制辯護案件**（刑訴§31 I 第1款），並非任意辯護案件。 |
| (C) | ✓ | 本案最輕本刑5年以上有期徒刑，屬審判中強制辯護案件（刑訴§31 I 第1款）。甲否認犯行、乙坦承不諱，二人利害相反，審判長**不得為其二人指定共同辯護人**（刑訴§31 IV），以避免利益衝突。 |
| (D) | ✗ | 前段錯誤，本案係強制辯護案件而非任意辯護案件。且刑訴§31 IV 係規範「指定」辯護人不得共同，並非針對「選任」辯護人之限制。 |

> [!NOTE]
> **重點整理**
> - **強制辯護僅適用於審判中**（刑訴§31 I）：①最輕本刑3年以上有期徒刑之案件；②高等法院管轄第一審案件；③被告因智能障礙無法為完全陳述等。
> - 偵查中無強制辯護規定，但被告仍得自行選任辯護人。
> - 共同被告**利害相反**時，審判長不得為其指定共同辯護人（刑訴§31 IV），以確保辯護之實質有效性。

### 2、106年第2題（原第37題）

> 甲因涉嫌犯偽造貨幣罪，經刑警依法拘提到場。於詢問前，刑警僅對甲說：「你現在是因涉嫌犯有偽造貨幣罪而接受詢問，你可以保持緘默，也可以請求調查對你有利之證據。」就開始詢問。詢問後，甲坦承多次偽造千元鈔票。關於甲之陳述，依現行法，下列敘述，何者正確？

**(A)** 甲的陳述原則上無證據能力。但甲之陳述出於任意，以及警察詢問非出於惡意者，不在此限  
**(B)** 甲之陳述可作為認定甲的犯罪事實之用，因為警察在詢問前已盡到告知義務，已足以保障甲的程序權益不會受到不當之侵害  
**(C)** 甲之陳述有無證據能力不可一概而論，需視警察詢問時是否有使用強暴或脅迫等不正方法，以及甲之陳述是否與事實相符而定  
**(D)** 甲之陳述不具有證據能力，因為警察未告知甲得選任辯護人已等同於係以詐欺之方式騙取甲之自白，故應排除甲之陳述的證據能力，以嚇阻執法機關之不法行為  

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓ | 依**§95 I ②**，詢問前應告知「得選任辯護人」。本案警察未告知→違反法定告知義務→自白**原則無證據能力**（§100-1）。但若陳述出於任意且警察非出於惡意，依例外規定不排除。此選項正確呈現原則與例外。 |
| (B) | ✗ | §95 I 之告知義務**包含**「得選任辯護人」（§95 I ②），警察僅告知緘默權和調查有利證據，**未告知辯護人選任**→告知義務未盡→不得謂已盡告知義務。 |
| (C) | ✗ | 本題重點在**程序違法**（未盡告知義務，§95 I ②），並非強暴脅迫或陳述真實性問題。程序瑕疵獨立構成排除自白之事由，與任意性及真實性判斷分屬不同層次。 |
| (D) | ✗ | 「等同詐欺」的理由過於誇大，不符合法律規定。排除自白之法律依據為「違反法定告知義務」（§95、§100-1），非「詐欺」；且嚇阻理論為美國法上的排除法則理論，我國刑訴並未採用此理論。 |

> [!NOTE]
> **重點整理**
> - **§95 I 告知義務**（詢問前應告知）：①罪名；②得保持緘默；③**得選任辯護人**；④得請求調查有利證據。
> - 違反§95 I ②未告知得選任辯護人→ 自白**原則無證據能力**（§100-1 I）。
> - 例外（§100-1 II）：陳述出於任意性，且非出於惡意者，不在排除之列。

### 3、106年第5題（原第40題）

> 甲涉犯違背職務受賄罪嫌而被起訴。第一審法院審理中甲沒有選任辯護人，法院亦未指定公設辯護人為甲辯護，判決後，甲提起第二審上訴，第二審法院為甲指定公設辯護人乙，辯論終結後，依現行法，法院為何種判決最為正確？

**(A)** 撤銷第一審判決並發回。因為在第一審，辯護人缺席的瑕疵判決當然違背法令  
**(B)** 撤銷第一審判決並發回。因為在第一審，辯護人缺席的判決侵害到甲的審級利益  
**(C)** 撤銷第一審判決並自為判決。因為在第一審，辯護人缺席的瑕疵判決當然違背法令  
**(D)** 撤銷第一審判決並自為判決。因為在第一審，儘管辯護人缺席，判決仍然合法  

#### 答案

(C)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 原因正確（一審辯護人缺席→§379 VII當然違背法令），但結論**錯誤**。二審已補正（指定辯護人乙並辯論終結），瑕疵已治癒，應「**自為判決**」而非「發回」。 |
| (B) | ✗ | 「審級利益受侵害」不是「發回」的充分理由。且既然二審已補正辯護，直接自為判決更為正當。 |
| (C) | ✓ | 違背職務受賄罪（§122）最輕本刑7年→屬**強制辯護案件**（§31 I ①最輕本刑3年以上）。一審無辯護人→**§379 VII判決當然違背法令**。二審已為甲指定辯護人乙，已補正一審缺陷，得「撤銷一審判決並**自為判決**」（§369 I但書）。 |
| (D) | ✗ | 辯護人缺席於強制辯護案件中**絕非合法**，此選項事實認定根本錯誤。 |

> [!NOTE]
> **重點整理**
> - **強制辯護案件**（§31 I）：最輕本刑3年以上、或高等法院管轄第一審等情形。
> - 強制辯護案件無辯護人→ **§379 VII判決當然違背法令**（為二審撤銷原因）。
> - 二審若補正辯護（指定辯護人並辯論終結）→ 得**自為判決**（§369 I但書「除顯有必要者外」）。
> - 「發回」 vs 「自為」：發回用於一審有重大程序瑕疵且二審無法補正時；補正後得自為。

### 4、107年第16題（原第51題）

> 警察逮捕犯罪嫌疑人甲後，擬進行詢問。下列敘述，何者最為正確？

**(A)** 甲若表示已選任辯護人，應即停止詢問，但有急迫情形且記明筆錄者，不在此限  
**(B)** 詢問甲時，應告知其得選任辯護人、輔佐人及代理人  
**(C)** 甲不得請求對質  
**(D)** 詢問時，應全程連續錄音；必要時，並應全程連續錄影。但有急迫情況且經記明筆錄者，不在此限  

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 依**§245 II**，甲已**選任**辯護人時，應**即停止**詢問，**無急迫例外**之適用。本選項加入「急迫情形且記明筆錄者不在此限」乃錯誤──§100-2 I 的「急迫例外」僅適用於**等候**辯護人的情形，非已選任時。 |
| (B) | ✗ | §95 I ③告知義務為「得**選任辯護人**」，並無「輔佐人及代理人」。本選項所稱範圍超出法律規定。 |
| (C) | ✗ | **§97**明定被告得請求對質，此為被告之訴訟權利，不得剝奪。本選項敘述與法律規定相反。 |
| (D) | ✓ | **§100-3 I**：詢問被告或犯罪嫌疑人時，「應全程連續錄音；必要時，並應全程連續錄影。但有**急迫情況且經記明筆錄**者，不在此限。」選項(D)與法條文字完全相符。 |

> [!NOTE]
> **重點整理**
> - **§100-3**（全程錄音/錄影）：詢問時應全程連續錄音；有急迫情況且記明筆錄→ 例外免錄音。
> - **§95 I** 告知義務（共4項）：罪名、緘默權、**選任辯護人**、請求調查有利證據。無「輔佐人、代理人」。
> - 已選任辯護人→ 應**即停止詢問**（§245 II），無急迫例外；等候辯護人→ 急迫例外見§100-2。

## 貳、辯護人之權利（接見、閱卷）

### 5、108年第55題（原第55題）

> 強盜案件之被告甲經法院裁定羈押，乙為其辯護人。下列敘述何者正確？

**(A)** 經法院同意後，乙始得接見甲，並互通書信  
**(B)** 限制乙及甲的接見通信，應用限制書。限制書，偵查中由檢察官簽名，審判中由法官簽名  
**(C)** 限制乙及甲間的接見，應用限制書，至於乙及甲間的通信，則不得限制之  
**(D)** 偵查中檢察官認有限制乙及甲間接見通信，且情形急迫者，得先為必要處分，但應於24小時內聲請法院補發限制書

#### 答案

(D)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✗ | 辯護人接見羈押被告為辯護權之核心內涵。依刑訴§34，辯護人得接見犯罪嫌疑人或被告，並互通書信，**無須經法院同意**始得為之。 |
| (B) | ✗ | 限制辯護人與被告之接見通信，依刑訴§34-1，限制書**無論偵查中或審判中，均應由法院核發**。偵查中檢察官不得自行簽發限制書。 |
| (C) | ✗ | 依刑訴§34-1，辯護人與被告間之**接見及通信均得受限制**，非僅限於接見。通信亦在得限制之範圍。 |
| (D) | ✓ | 依刑訴§34-1 III，偵查中檢察官認有限制辯護人與被告接見通信之必要，且**情形急迫**者，得先為必要處分，但應於**24小時內聲請法院補發限制書**。此為急迫情形之例外規定。 |

> [!NOTE]
> **重點整理**
> - 辯護人接見被告之權利為辯護權之核心，**無須法院同意**即得接見（刑訴§34）。
> - 限制辯護人接見通信須用**限制書**，由**法院核發**（刑訴§34-1 I），不論偵查中或審判中。
> - 偵查中急迫情形之例外：檢察官得先為必要處分，但應於**24小時內**聲請法院補發限制書（刑訴§34-1 III）。
> - 接見與通信均得限制，非僅限於接見。

### 6、104年第4題（原第39題）

> 甲係被拘提之被告，甲的妻子隨即委任律師丙為甲的辯護人，丙趕至地檢署要求與甲接見。下列敘述，何者**錯誤**？

**(A)** 甲係被拘提之被告，在拘提後24小時內，檢察官有權拘束其人身自由，並得禁止其與任何人接見，以利偵查之進行  
**(B)** 除有急迫情形且具正當理由外，檢察官不得暫緩辯護人丙與被拘提之被告甲接見，且辯護人丙得在偵訊甲時在場及陳述意見  
**(C)** 甲係被拘提之被告，除有例外情形外，辯護人丙得與被拘提之被告甲接見，但以接見一次為限，且接見時間不得逾1小時  
**(D)** 檢察官若要聲請羈押，應在拘提甲後24小時內向法院聲請之。但甲與辯護人丙接見時間應不得計算在24小時之內  

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓（本題正確答案＝錯誤陳述） | 「得禁止其與任何人接見」→ **錯誤**。依**§34**，辯護人接見被告為辯護權之核心，不得完全禁止。即使被拘提前，檢察官僅能在急迫且具正當理由時**暫緩**（非禁止）辯護人接見，且不得超越必要範圍。「禁止與任何人接見」明顯逾越法律許可範圍。 |
| (B) | ✗（正確陳述） | 依**§34 II**，除有急迫情形且具正當理由外，不得暫緩辯護人接見；依**§245 II**，辯護人得在偵訊時在場及陳述意見。本選項正確。 |
| (C) | ✗（本題另一錯誤陳述） | 「以接見一次為限，且接見時間不得逾1小時」→ 無任何法律依據，屬錯誤。但(A)所稱「完全禁止接見」更為根本性的違反辯護權，故答案選(A)。 |
| (D) | ✗（正確陳述） | 依**§93 I 但書**，辯護人與被告之接見時間，不計入24小時之計算。聲請羈押應在拘提後24小時內（§93）。本選項正確。 |

> [!NOTE]
> **重點整理**
> - **§34**：辯護人接見被告之基本權利→ 不得完全禁止；急迫情形下可「暫緩」但非「禁止」。
> - **§34-1**：限制接見通信需**法院核發限制書**（偵查中急迫例外：檢察官得先處分，24小時內補發限制書）。
> - 接見時間**不計入** 24小時（§93 I 但書）→ 延長聲請羈押之時間。
> - 辯護人得在偵訊時**在場及陳述意見**（§245 II），無須被告特別聲請。

## 參、輔佐人

### 7、111年第54題（原第54題）

> 下列何者並非審判中輔佐人在法律上之權限？

**(A)** 詰問證人  
**(B)** 聲請撤銷被告之羈押  
**(C)** 辯論證據之證明力  
**(D)** 聲請調查證據

#### 答案

(A)

#### 解析

| 選項 | 正確？ | 說明 |
|------|--------|------|
| (A) | ✓（本題正確答案 — 非輔佐人權限） | 輔佐人不得行使**詰問權**。交互詰問權專屬於當事人（含被告）及辯護人，輔佐人並不在詰問權之主體範圍內。 |
| (B) | ✗ | 輔佐人得為被告之利益聲請撤銷羈押，此屬輔佐人依法得行使之權限（刑訴§35 III 準用相關規定）。 |
| (C) | ✗ | 輔佐人得於審判中陳述意見，包括辯論證據之證明力，此屬輔佐人陳述意見之權限範疇（刑訴§35 II）。 |
| (D) | ✗ | 聲請調查證據為輔佐人明文規定之權限（刑訴§35 II），輔佐人得為被告之利益聲請調查證據。 |

> [!NOTE]
> **重點整理**
> - **輔佐人之權限**（刑訴§35 II）：陳述事實、提出意見、聲請調查證據、辯論證據證明力等。
> - 輔佐人**不得行使詰問權**（交互詰問），此為辯護人與當事人之專屬權限。
> - **辯護人 vs 輔佐人之權限區辨**：辯護人得行使詰問權、閱卷權等完整訴訟權限；輔佐人僅得為被告之利益陳述、聲請，不具詰問權及閱卷權。

| 概念 | 要點 |
|------|------|
| 辯護人接見權 | 無須法院同意即得接見被告；限制須法院核發限制書 |
| 強制辯護適用範圍 | 僅審判中適用（§31 I）；偵查中無強制辯護規定 |
| 利害相反之共同被告 | 審判長不得為其指定共同辯護人（§31 IV） |
| 輔佐人之權限界限 | 得陳述、聲請調查證據，但不得行使詰問權 |
| 急迫限制接見通信 | 檢察官得先處分，24小時內聲請法院補發限制書 |
| §95告知義務（4項） | 罪名、緘默權、**選任辯護人**、調查有利證據（無輔佐人、代理人） |
| 未告知辯護人之自白 | 原則無證據能力；例外：任意性且非出於惡意（§100-1 II） |
| 強制辯護案件辯護人缺席 | §379 VII當然違背法令；二審已補正→自為判決 |
| 已選任辯護人時之詢問 | 應即停止詢問（§245 II），無急迫例外 |
| 全程錄音（§100-3） | 應全程連續錄音；急迫情形記明筆錄→例外免錄音 |

### 三、關鍵區辨整理

| 概念A | 概念B | 區辨重點 |
|-------|-------|----------|
| 辯護人 | 輔佐人 | 辯護人得詰問、閱卷、獨立上訴；輔佐人僅得陳述意見、聲請調查證據，不得詰問 |
| 強制辯護 | 任意辯護 | 強制辯護限於審判中法定情形（§31 I），法院應指定辯護人；任意辯護由被告自行決定 |
| 偵查中辯護 | 審判中辯護 | 偵查中無強制辯護，被告得自行選任；審判中有強制辯護規定 |
| 指定辯護人 | 選任辯護人 | 指定辯護人受利害相反限制（§31 IV）；選任辯護人由被告自主選擇 |
