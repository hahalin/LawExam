## 檔名
- 年次碼：民國年＋考試碼，例 `104110`、`106120`、`115110`
- PDF：`{年次}_{卷別碼}_{科目簡稱}.pdf`；答案前加 `ANS`、更正答案前加 `MOD`
  - 例：`115110_0301_綜合法學(一)(刑法.pdf`、`115110_ANS0301_綜合法學(一)(刑法.pdf`
- 逐年題目 md：`{年次}_{試題代號}.md`，例 `刑法/115110_1301.md`

## 各科題號（115 年）
- 1301：刑法 1–35、刑事訴訟法 36–60、法律倫理 61–75
- 2301：憲法 1–20、行政法 21–55、國際公法 56–65、國際私法 66–75
- 3301：民法 1–50、民事訴訟法 51–80（77–80 為家事事件）
- 4301：公司法 1–15、保險法 16–25、票據法 26–35、證券交易法 36–45、強制執行法 46–55、法學英文 56–70

## 逐年題目 md 格式
- 檔頭：`# {年}年司法官律師考試 - {科目}（{試題代號}）`，引言列考試名稱、科目、題號範圍
- 每題：`## 第N題（原第M題）`、題幹、`(A)`～`(D)` 選項、`### 答案：(X)`、`---`
- 4301 不拆科，題號直接寫 `## 第N題`
- 換行 CRLF、UTF-8

## 備註
- 逐年 md 的代號照當年考題 PDF 的編碼：刑法、刑事訴訟法、法律倫理的 105、109 年是 `0301`（`105110_0301.md`、`109120_0301.md`），其他年份是 `1301`
