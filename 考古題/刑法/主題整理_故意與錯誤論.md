# 刑法主題整理：故意與錯誤論

> 涵蓋 108-114 年司律一試刑法考題  
> 主題：故意類型、客體錯誤、打擊錯誤、因果歷程偏離、客觀歸責、容許構成要件錯誤、禁止錯誤、包攝錯誤、過失犯與信賴原則、原因自由行為

---

## 壹、客體錯誤與打擊錯誤

### 一、109年 第4題

甲因女友乙移情別戀，計畫至乙家縱火洩憤，但缺乏勇氣，遂猛灌一瓶烈酒壯膽後，於深夜拿自製汽油彈至乙住處。因酒醉加上天色昏暗，甲看錯門牌號碼，將丙宅誤認為乙宅而丟擲汽油彈，造成丙宅客廳大部分焚燬，甲當場被逮捕。經鑑定後確認，甲縱火時血液中酒精濃度達 3.4‰，無責任能力。下列敘述何者錯誤？

(A) 甲欲燒燬乙宅，行為時卻將丙宅誤認為乙住處，屬等價的客體錯誤，不影響甲之縱火故意  
(B) 甲縱火時已無責任能力，依罪責原則，行為與罪責需同時存在，故甲無罪  
(C) 甲故意飲酒自陷於無責任能力狀態，且於此狀態下縱火，應屬故意自招的原因自由行為  
(D) 甲自陷無責任能力狀態時，雖無法操控犯罪的因果歷程，其縱火客體與清醒時想侵害的客體不一致，非屬因果歷程重大偏離  

### 答案：(B)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ✅ | 甲欲燒乙宅卻將丙宅誤認為乙宅，丙宅與乙宅在刑法評價上等價（均為他人之住宅），屬**等價客體錯誤**，不影響縱火故意 |
| (B) | ❌（本題問「何者錯誤」） | 甲縱火時雖已無責任能力，但甲係**故意飲酒**使自己陷入無責任能力狀態後實行犯罪，屬**原因自由行為**（§19 III），不得因行為時無責任能力而主張無罪 |
| (C) | ✅ | 甲於自由意志狀態下故意飲酒（原因行為），使自己陷入無責任能力狀態後縱火（結果行為），符合**故意型原因自由行為**之要件 |
| (D) | ✅ | 甲因等價客體錯誤而燒錯房屋，此偏離不影響故意認定。縱火客體雖與清醒時預想不同，但屬等價客體錯誤問題，非重大因果偏離 |

> [!NOTE]
> **重點整理**
> - **客體錯誤 + 原因自由行為的綜合考題**：本題同時考兩個概念
> - 等價客體錯誤不影響故意；原因自由行為排除§19 I 的免責
> - **原因自由行為**（§19 III）：行為人故意或過失自行招致無責任能力／限制責任能力狀態，仍應負刑事責任
> - 行為與罪責同時原則的例外：原因自由行為將罪責判斷前移至原因行為時點

### 二、111年 第3題

關於故意與錯誤，下列敘述何者正確？

(A) 甲舉槍射擊眼前之人，認為該人係仇人乙，殊不知該人乃路人丙，甲成立打擊錯誤，對丙構成過失致死罪  
(B) 甲計畫殺害仇人乙，開車至乙住處途中不慎撞死人，甲下車察看後，發現係仇人乙，內心十分高興，甲不成立殺人罪  
(C) 甲欲開槍射死乙，但打死旁邊之丙，屬於打擊錯誤，依通說見解得阻卻或減免罪責  
(D) 甲舉槍射擊仇人乙，想像乙心臟中彈立即死亡，然而乙心臟先天偏右，並未立即死亡，而係死於失血過多無人救援，甲對乙構成過失致死罪

### 答案：(B)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | 甲誤認眼前之人為仇人乙，實際上是路人丙，此為**等價客體錯誤**（error in persona），非打擊錯誤。等價客體錯誤不影響故意，甲對丙仍成立**故意殺人罪** |
| (B) | ✅ | 甲計畫殺乙但開車途中「不慎」撞死乙，撞死行為出於**過失**而非殺人故意之實行行為，甲僅成立**過失致死罪**，不成立故意殺人罪。事後發現被害人恰為仇人乙，不影響行為時之主觀故意判斷 |
| (C) | ❌ | 甲對乙開槍卻打死旁邊之丙，確為**打擊錯誤**（aberratio ictus），但依通說（具體符合說），打擊錯誤並**不阻卻或減免罪責**，甲對乙成立殺人未遂，對丙成立過失致死 |
| (D) | ❌ | 甲以殺人故意射擊乙，乙雖非因心臟中彈死亡而是失血過多死亡，屬**因果歷程偏離**，但偏離幅度在常態經驗範圍內（槍傷失血致死屬可預見），不影響殺人故意，甲仍成立**故意殺人罪** |

> [!NOTE]
> **重點整理**
> - **等價客體錯誤**：行為人誤認 A 為 B 而攻擊，A、B 在刑法評價上等價，不影響故意（法定符合說）
> - **打擊錯誤**：行為人對預定客體A攻擊，卻命中非預定客體B，依通說（具體符合說）：對A成立未遂、對B成立過失
> - **因果歷程偏離**：結果發生方式與行為人想像不同，但若偏離在常態可預見範圍內，不影響故意之成立

### 三、110年 第10題

甲計劃持衝鋒槍至乙家掃射殺害乙，並依計劃前往乙家，但甲看錯乙家地址，竟以為離乙家約10公尺的丙家是乙家，甲爬上丙家圍牆開槍對丙家內部掃射，造成在家中的丙受傷，丙的妻子丁也被子彈擊中而成為植物人，丙家的愛犬 A 當場死亡。沒想到乙跟丙是舊識，乙當天正好前往丙家拜訪，在丙家的乙也被甲掃射的子彈擊中而死亡。下列敘述何者錯誤？

(A) 甲對乙之死亡，構成打擊錯誤而成立過失致死罪  
(B) 甲對丙之受傷，構成故意殺人未遂罪  
(C) 甲對丁之重傷，構成故意殺人未遂罪  
(D) 甲對A之死亡，構成故意毀損一般財物罪

### 答案：(A)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌（本題問「何者錯誤」） | 甲看錯地址將丙家誤認為乙家，此為**客體錯誤**（等價客體錯誤），非打擊錯誤。甲以殺人故意對丙家掃射，丙家中的乙也被擊中死亡，甲以殺人故意射擊丙家中的人（包括乙），對乙之死亡應成立**故意殺人罪**，而非僅過失致死罪 |
| (B) | ✅ | 甲以殺人故意對丙家掃射，丙受傷但未死亡，甲對丙成立**故意殺人未遂罪** |
| (C) | ✅ | 甲以殺人故意掃射，丁被子彈擊中成為植物人（重傷），甲對丁成立**故意殺人未遂罪** |
| (D) | ✅ | 甲以殺人故意掃射，丙家愛犬A死亡。動物在刑法上為「物」，甲對A成立**故意毀損罪**（甲有毀損之未必故意，掃射時對屋內物品之毀損結果有預見且不違背其本意） |

> [!NOTE]
> **重點整理**
> - **客體錯誤 vs 打擊錯誤的區別**：甲看錯地址→誤認丙家為乙家→將丙家的人當作乙→屬**客體錯誤**（行為人認知目標與實際目標不同）。若甲對準乙射擊但子彈偏向旁邊的丙→才是**打擊錯誤**（行為方向偏差）
> - 客體錯誤（等價）：不影響故意→仍成立故意犯
> - 打擊錯誤（具體符合說）：對預定客體成立未遂、對實際被害客體成立過失犯

### 四、114年 第6題

村長時常炫耀家中財富，引起村民甲的厭惡。某日，甲得知村長買入新的高檔豪車後，決定深夜前去村長家，以鐵棍破壞村長的車，給村長一個教訓。甲持鐵棍到了村長家，卻發現村長開車外出，只好作罷。沒想到，甲於返家途中，巧遇村長停車在對街的便利商店門口，便順手撿起路邊石塊，擲向村長的車；沒想到石塊卻反彈砸中剛好路過的村民乙之車，使得乙車的車窗玻璃破碎。下列敘述何者正確？

(A) 村長開車外出，出乎甲意料之外，甲成立毀損罪的障礙未遂犯  
(B) 村長開車外出，使得甲無法損壞村長的車，甲成立毀損罪的不能未遂犯  
(C) 甲朝村長的車丟擲石塊，但未能砸中，故甲成立毀損罪的普通未遂犯  
(D) 甲朝村長的車丟擲石塊，卻砸中乙車，但毀損罪不罰過失，故甲不成立犯罪

### 答案：(D)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | 題目分兩段行為。第一段甲到村長家發現車不在→放棄（自行中止）。第二段甲在便利商店門口另起犯意丟石頭→此為新的行為。甲到村長家後作罷，並非致力實行未遂後因障礙而停止 |
| (B) | ❌ | 不能未遂係指行為人之行為不能發生犯罪結果且無危險（§26）。甲在便利商店丟石頭砸車的行為客觀上有可能產生毀損結果，並非不能未遂 |
| (C) | ❌ | 毀損罪（§354）**不處罰未遂犯**，因此甲對村長車的毀損未遂不成立犯罪。可參刑法第354條，未設未遂犯處罰規定 |
| (D) | ✅ | 甲以毀損故意對村長車丟石頭→對村長車毀損未遂（不罰）；石頭反彈砸中乙車→**打擊錯誤**，對乙車僅有過失→**毀損罪不罰過失**。綜上，甲不成立犯罪 |

> [!NOTE]
> **重點整理**
> - **打擊錯誤 + 不罰過失的犯罪**：當打擊錯誤發生時，對實際被害客體僅成立過失犯，若該罪不處罰過失（如毀損罪），則不成立犯罪
> - 毀損罪（§354）既**不罰未遂**也**不罰過失**，故本題甲無論對村長車或乙車均不成立犯罪
> - 打擊錯誤的實際效果，取決於該罪是否處罰過失犯

## 貳、因果歷程偏離、客觀歸責與概括故意

### 五、109年 第28題

甲在乙所獨居的小木屋放火，欲藉此殺害乙。放火時，甲不知乙正好在外地出差，屋內其實空無一人。約 20 分鐘後，消防隊獲報後前往救火，消防員丙身著齊全的消防裝備進入火場，但還是被突然坍塌的樑柱壓死。乙的友人丁聽聞乙宅失火，以為乙仍在屋內，便奮不顧身衝進火場救乙。丁進入火場，雖然自知屋內已經充滿濃煙，但僅使用一般棉質口罩罩住口鼻。丁因吸入過多濃煙而死亡。關於甲之行為的犯罪評價，下列敘述何者正確？

(A) 針對丙衝入火場後，被樑柱壓死，為「打擊失誤」  
(B) 針對丁衝入火場，被濃煙嗆死，為「等價客體錯誤」  
(C) 丁使用一般棉質口罩進入火場，因吸入過多濃煙而死亡，係屬結果無法避免之情形，甲可據此排除死亡結果之客觀歸責  
(D) 丙衝入火場後，不是因為火勢致死，而是遭坍塌的樑柱壓死，此屬於重大之因果偏離，甲可據此排除死亡結果之客觀歸責  

### 答案：(C)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | 丙為消防員因執行救火任務進入火場而死亡，非甲攻擊乙卻命中丙之情形，**非打擊錯誤**。打擊錯誤須行為人攻擊特定目標卻擊中他人，本題丙係因第三人介入行為（救火）而死 |
| (B) | ❌ | 丁衝入火場死亡亦非等價客體錯誤。客體錯誤係行為人**誤認攻擊對象**，甲根本不知丁的存在，非對丁有任何誤認 |
| (C) | ✅ | 丁**明知**火場已充滿濃煙卻僅以一般棉質口罩進入，屬於**被害人自我危險的實現**（Eigenverantwortliche Selbstgefährdung）。丁自主決定以顯然不足的防護措施冒險進入火場，其死亡結果應歸責於丁自己的冒險行為，甲可據此**排除客觀歸責** |
| (D) | ❌ | 消防員進入火場救火是放火行為的**可預見後果**，消防員因火場坍塌而死亡仍在甲放火行為所創造的危險範圍內，**非重大因果偏離**，甲對丙的死亡結果原則上仍可成立客觀歸責 |

> [!NOTE]
> **重點整理**
> - **客觀歸責理論**的排除事由：
>   1. 被害人自我危險的實現：被害人自主決定冒險，且完全認知風險→結果歸責於被害人
>   2. 第三人介入：專業救助人員（消防員）進入火場屬可預見，不當然排除歸責
> - 丁的死亡：丁明知濃煙危險卻以不足防護進入→自我答責→排除甲之客觀歸責
> - 丙的死亡：消防員進入火場為可預見介入→因果偏離不重大→甲仍可能被歸責
> - 區分：打擊錯誤 vs 第三人介入（救火者傷亡） vs 客體錯誤 → 本題考的是**客觀歸責**

### 六、114年 第1題

有關刑法上錯誤論敘述，下列何者正確？

(A) 甲把乙從橋上推到河中，希望乙溺斃，但乙最後頭部撞到橋墩而死，此時應否定甲的殺人故意  
(B) 甲以殺人之意思緊勒乙，導致乙昏迷，但甲誤認乙已死，故將其埋入土中，最後乙因被土覆蓋口鼻而窒息死亡，此時依實務見解甲仍應負擔殺人罪責  
(C) 甲想要殺乙，所以看準了乙和丙、丁同在一間房間時，用一顆炸彈丟進三人所在的房間，導致在爆炸範圍的乙、丙、丁均因爆炸而死，此時僅能肯定甲對乙有殺人故意，對於丙、丁只能成立過失犯  
(D) 甲以殺人的意思，在公眾使用道路放地雷想要炸死乙，偶然經過的丙踏到地雷被炸死，此時應否定甲殺人的故意

### 答案：(B)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | 甲以殺人故意將乙推入河中，乙雖非溺斃而是撞橋墩死亡，屬**因果歷程偏離**，但偏離幅度在社會經驗範圍內（推人落橋→撞到橋墩屬可預見），不影響殺人故意，**不應否定甲之殺人故意** |
| (B) | ✅ | 此為經典的**「韋伯概括故意」**（Weber'sche Überhaupt-Vorsatz）案例：前行為（勒乙）未致死→誤認已死→後行為（埋土）致死。依實務見解，將前後行為**視為一個整體**的殺人行為，因果歷程偏離屬不重要偏離，甲仍負**殺人既遂**罪責 |
| (C) | ❌ | 甲明知丙、丁與乙同處一室仍丟擲炸彈，對丙、丁之死亡至少具有**未必故意**（間接故意）：甲預見丙、丁可能因爆炸死亡且不違背其本意。甲對丙、丁亦成立**故意殺人罪** |
| (D) | ❌ | 甲在公路放地雷欲炸乙，丙路過踏雷身亡，屬**打擊錯誤**。然甲在公眾使用道路放地雷，對不特定人踩到地雷至少有**未必故意**，**不應否定殺人故意**。甲對丙仍可能成立故意殺人罪 |

> [!NOTE]
> **重點整理**
> - **因果歷程偏離**：結果發生方式與行為人預想不同，判斷標準為偏離是否在「一般生活經驗範圍內可預見」。若可預見→不影響故意
> - **韋伯概括故意**（兩階段因果偏離）：前行為未完成犯罪→誤認已完成→後行為完成犯罪。實務將全部過程視為一體，不影響故意殺人既遂之認定
> - **未必故意**（間接故意）§13 II：行為人預見其行為可能發生犯罪結果，且其發生不違背其本意→仍屬故意

## 參、容許構成要件錯誤（誤想防衛）

### 七、110年 第7題

甲在登山時，看見乙正在持小刀割丙的小腿，誤以為乙在傷害丙，故立即持登山杖擊傷乙。實際上，乙正在為遭毒蛇咬傷的丙緊急治療傷口。依實務見解，下列有關甲刑責之敘述何者正確？

(A) 甲之行為係誤想防衛，屬於包攝錯誤，得依刑法第16條減輕刑責  
(B) 甲之行為係誤想防衛，不成立故意傷害罪，仍可能成立過失傷害罪  
(C) 甲之行為係誤想避難，不成立故意傷害罪，仍可能成立過失傷害罪  
(D) 甲之行為係誤想避難，仍可阻卻違法，不成立犯罪

### 答案：(B)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | 甲誤認乙在傷害丙而出手防衛，此為**誤想防衛**（容許構成要件錯誤），非包攝錯誤。誤想防衛係行為人誤認「阻卻違法事由的前提事實」存在，第16條適用於**禁止錯誤**（不知行為違法），二者不同 |
| (B) | ✅ | **誤想防衛**依實務見解：甲誤認現在不法侵害存在而實施防衛行為，**阻卻故意**（類推構成要件錯誤之法律效果），不成立故意傷害罪；但若甲之誤認有過失（未善盡查證義務），仍可能成立**過失傷害罪** |
| (C) | ❌ | 本題甲係誤認「乙正在侵害丙」而自認「為丙防衛」，屬**誤想防衛**，非誤想避難。避難係針對危難狀況，防衛係針對不法侵害 |
| (D) | ❌ | 即使是誤想避難，依實務通說亦僅阻卻故意而非阻卻違法，仍可能成立過失犯 |

> [!NOTE]
> **重點整理**
> - **誤想防衛**：行為人誤認現在不法侵害存在而為防衛行為。實際上不法侵害不存在
> - 法律效果：依實務見解，**阻卻故意**（類推構成要件錯誤），不成立故意犯；但有過失者，成立過失犯
> - 區別：誤想防衛 ≠ 包攝錯誤 ≠ 禁止錯誤

### 八、111年 第4題

甲誤以為乙在追殺丙，立即拾起地上的石塊朝乙丟去，欲砸傷乙以阻止其行兇，結果致乙受輕傷。事後發現乙、丙是在拍攝兇殺片電影的演員。關於甲的刑事責任，下列敘述何者錯誤？

(A) 若依照嚴格罪責理論，容許構成要件錯誤與禁止錯誤應為相同處理，故甲不具備傷害故意，僅能成立過失傷害罪，除非其誤認係不可避免，始可免責  
(B) 若依照負面構成要件要素理論，誤認阻卻違法事由情狀的存在，即屬欠缺對整體不法構成要件的認識，故甲不具備傷害罪之主觀不法，若有過失則另行成立過失傷害罪  
(C) 若依照限制罪責理論，容許構成要件錯誤與構成要件錯誤有相似性，應為相同處理，故甲不具備傷害故意，最多僅能成立過失傷害罪  
(D) 若依照限制法律效果的罪責理論，容許構成要件錯誤與構成要件錯誤不同，不應相同處理。甲仍具備傷害故意，但得以阻卻故意罪責，最多僅能成立過失傷害罪

### 答案：(A)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌（本題問「何者錯誤」） | **嚴格罪責理論**：容許構成要件錯誤等同「禁止錯誤」處理。禁止錯誤**不影響故意**，甲仍具備傷害故意。若不可避免→免責；若可避免→減輕罪責。選項稱「甲不具備傷害故意」錯誤 |
| (B) | ✅ | **負面構成要件要素理論**：將阻卻違法事由視為構成要件的「負面要素」，整體不法構成要件（=構成要件+無阻卻違法事由）。誤認阻卻違法事由存在→欠缺對整體不法構成要件之認識→阻卻故意→可能成立過失犯 |
| (C) | ✅ | **限制罪責理論**：容許構成要件錯誤與構成要件錯誤「相似」，應**類推適用**§12 I阻卻故意。甲不具備傷害故意，最多成立過失傷害罪 |
| (D) | ✅ | **限制法律效果的罪責理論**：容許構成要件錯誤雖與構成要件錯誤不同（甲仍具傷害故意），但法律效果上得**阻卻故意罪責**，最多成立過失犯。此為我國通說所採理論 |

> [!NOTE]
> **重點整理 — 容許構成要件錯誤四大學說比較**
>
> | 學說 | 對故意的影響 | 法律效果 |
> |------|-------------|---------|
> | 嚴格罪責理論 | 故意「存在」 | 等同禁止錯誤，可避免→減輕；不可避免→免責 |
> | 負面構成要件要素理論 | 故意「不存在」 | 阻卻故意→成立過失犯 |
> | 限制罪責理論 | 故意「不存在」 | 類推構成要件錯誤→阻卻故意→成立過失犯 |
> | 限制法律效果罪責理論（通說） | 故意「存在」但阻卻故意罪責 | 最多成立過失犯 |

## 肆、禁止錯誤（違法性錯誤 §16）

### 九、111年 第6題

甲經營資源回收事業數十年，被同業檢舉無照經營。案經檢察官偵查終結，以違反廢棄物清理法之罪將甲起訴；甲辯稱，自己中學畢業後，就從事資源回收事業，完全不知道有許可文件方得經營之。有關甲之刑責，下列敘述何者正確？

(A) 甲有罪，因甲從事廢棄物清理數十年，有保證人地位  
(B) 甲有罪，難謂甲有正當理由而無法避免不知法律  
(C) 甲無罪，因甲從事廢棄物清理數十年，得主張信賴原則  
(D) 甲無罪，因甲僅中學畢業，故得因不知法律而免除刑責

### 答案：(B)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | 保證人地位係不純正不作為犯的要件，與本題甲不知法規的問題無關。本題爭點為**禁止錯誤**（§16），非不作為犯 |
| (B) | ✅ | 依§16規定：不得因不知法律而免除刑事責任，但按其情節得減輕其刑；若**有正當理由而無法避免**者，免除其刑。甲經營資源回收數十年，有充分時間與機會瞭解相關法規，**難謂有正當理由而無法避免**，故甲仍有罪 |
| (C) | ❌ | **信賴原則**係過失犯的歸責限制理論（用於交通事故等），與不知法律的禁止錯誤無關 |
| (D) | ❌ | 是否免除刑責取決於**不知法律是否有正當理由且無法避免**，而非學歷高低。甲長期從事該行業，應有注意法規之義務 |

> [!NOTE]
> **重點整理**
> - **§16 禁止錯誤**的法律效果：
>   - 原則：不得因不知法律而免除刑事責任
>   - 例外：按其情節**得減輕其刑**
>   - 再例外：有正當理由而**無法避免**者→**免除其刑**
> - 判斷「無法避免」的關鍵：行為人是否有查詢法律的義務與機會

### 十、113年 第9題

有關刑法第16條規定，依實務見解，下列敘述何者正確？

(A) 第16條之規定係專指行為人自認其行為存在與阻卻違法事由相關之事實，故其行為合法而言  
(B) 若行為人對行為是否涉及不法有所懷疑，必要時有向具有專業能力之人或機構等查詢之義務  
(C) 第16條之規定，是對於行為人不知法律之情形，區分不同法律效果，僅有行為人對於違法性錯誤無正當理由而屬可避免者，始應免除其刑事責任  
(D) 誤想犯有第16條規定之適用

### 答案：(B)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | §16係**禁止錯誤**（不知法律禁止），而非容許構成要件錯誤（誤認阻卻違法事由的前提事實存在）。選項描述的情形是「容許構成要件錯誤」，非§16的適用範圍 |
| (B) | ✅ | 依實務見解，行為人若對行為是否涉及不法**有所懷疑**時，**有向專業人士或機構查詢的義務**。未盡此查詢義務者，即非有正當理由而無法避免，不得主張§16免除其刑 |
| (C) | ❌ | 顛倒了法律效果。§16規定：有正當理由而**無法避免**者→**免除其刑**；**可避免**者→**得減輕其刑**。選項稱「可避免者始應免除刑事責任」，恰好相反 |
| (D) | ❌ | **誤想犯**（幻覺犯）係行為人誤以為其行為構成犯罪，實際上不構成犯罪。因不具構成要件該當性，根本不成立犯罪，**無§16適用之餘地** |

> [!NOTE]
> **重點整理**
> - §16 的適用範圍：行為人**不知其行為為法律所禁止**（禁止錯誤）
> - 區分：容許構成要件錯誤（誤認阻卻違法事由的前提事實）→適用§12 I 類推 ≠ §16
> - 區分：誤想犯（以為犯罪但實際合法）→不成立犯罪 ≠ §16
> - 查詢義務：有懷疑→應查詢→未查詢→屬可避免→得減輕其刑

## 伍、包攝錯誤

### 十一、112年 第5題

甲因鄰居乙時常隨便違規停車而有糾紛，欲刮傷乙車以教訓乙，但知道損壞他人財物是犯罪行為而不敢下手。某日，甲忽聞乙飼養的鸚鵡啼叫，心想乙平日愛鳥成痴，若將寵物鳥毒死，因動物非財物，非損壞乙財物的行為，於是趁乙不在家的時候，打開鳥籠，毒死鸚鵡。下列敘述何者正確？

(A) 甲毒死鸚鵡，並非毀損行為，故不成立毀損罪，僅有民事責任  
(B) 甲毒死鸚鵡，雖是毀損行為，但甲因不知法律，法院必須免除其刑事責任  
(C) 甲知道法律禁止毀損他人財物，但認為毒死乙的鸚鵡，並不該當毀損罪構成要件，故屬於構成要件錯誤，阻卻故意  
(D) 甲知道法律禁止毀損他人財物，但誤以為毒死乙的鸚鵡，並非毀損罪構成要件包攝的範圍，故屬於包攝錯誤

### 答案：(D)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | 動物（鸚鵡）在刑法上為「物」（**他人之物**），毒死他人鸚鵡為**毀損行為**，成立毀損罪 |
| (B) | ❌ | 甲**知道**法律禁止毀損他人財物，並非「不知法律」。甲只是誤認動物不屬於「財物」，無§16適用。且即使適用§16，也非「必須免除」，而是「得減輕」或「有正當理由無法避免時」方免除 |
| (C) | ❌ | 甲知道鸚鵡是乙的動物，只是誤認「動物不屬於刑法上的財物」，此為**法律評價層面的錯誤**，非對事實的誤認。構成要件錯誤係對「事實」的誤認（如把人看成稻草人），本題不屬之 |
| (D) | ✅ | 甲知道毀損他人財物違法，但誤以為「動物不是刑法上的物」→此為**包攝錯誤**（Subsumtionsirrtum）：行為人知悉法律禁止，但對構成要件要素的**法律涵攝範圍**有錯誤認識。包攝錯誤屬**禁止錯誤**的一種，不阻卻故意 |

> [!NOTE]
> **重點整理**
> - **包攝錯誤**：行為人知道法律規範存在，但對構成要件要素的**法律涵攝範圍**有誤解
> - 包攝錯誤屬**禁止錯誤**的一種（非構成要件錯誤），不阻卻故意
> - 法律效果：依§16處理（不得免除刑事責任，得減輕其刑；有正當理由無法避免者免除其刑）
> - 區分三種錯誤：
>   - **構成要件錯誤**：對事實的誤認→阻卻故意
>   - **禁止錯誤**：不知行為違法→§16
>   - **包攝錯誤**：知法律禁止但誤解涵攝範圍→§16（禁止錯誤之一種）

## 陸、過失犯與信賴原則

### 十二、110年 第5題

依實務見解，下列何者得主張刑法上「信賴原則」之適用？

(A) 甲依速限駕車直行，早就看見前方一少年違規穿越馬路，本有時間閃避該少年，但卻仍繼續依速限直行，直到撞上該少年始停止  
(B) 乙一路超速直行於馬路上，突有一兒童從路邊人行道衝出撿拾玩具，乙不及閃避而撞上該兒童  
(C) 丙駕車在山路上行駛，為了超越前方車輛，謹慎小心地跨越雙黃線至對向車道試圖超車，卻在跨越雙黃線當時，撞上對向車道內超速行駛之機車騎士  
(D) 丁依速限駕車直行至有號誌之交岔路口時，見號誌為綠燈，乃注意兩側是否有來車後繼續依速限直行，卻撞上從慢車道超速駛出、違規左轉之機車騎士

### 答案：(D)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | 甲**已看見**少年違規穿越馬路且**有時間閃避**卻未閃避，甲已發現危險卻未採取避險措施，不得主張信賴原則。信賴原則的前提是行為人自身已遵守交通規則且**無法預見他人違規** |
| (B) | ❌ | 乙**超速**行駛，自身已違反交通規則，不得主張信賴原則。只有自身遵守交通規則之人，方得信賴他人亦會遵守規則 |
| (C) | ❌ | 丙**跨越雙黃線**違規超車，自身已違反交通規則，不得主張信賴原則 |
| (D) | ✅ | 丁依速限駕車、綠燈直行、且已注意兩側來車，完全遵守交通規則。對方從慢車道**超速駛出、違規左轉**，丁得主張**信賴原則**：已盡注意義務之駕駛人，得信賴其他用路人亦會遵守交通規則 |

> [!NOTE]
> **重點整理**
> - **信賴原則**的適用要件：
>   1. 行為人**自身遵守交通規則**
>   2. 他人之違規行為**非行為人所能預見**
>   3. 行為人於發現危險時**已無迴避可能性**
> - 不得主張信賴原則的情形：
>   - 自身違規（超速、跨越雙黃線等）
>   - 已發現對方違規卻仍有閃避可能而未閃避
>   - 對方為兒童、老人等不具自主能力之人（依部分實務見解）

### 十三、113年 第6題

有關過失犯敘述，依實務見解，下列何者錯誤？

(A) 在判斷醫療過失時，不得一律以醫學中心之醫療水準為判斷標準  
(B) 他人之交通違規事實已極為明顯，且行為人有充足時間可避免發生交通事故時，行為人即不能主張信賴原則免責  
(C) 由於醫師在進行手術前，可信賴護理師已先正確確認患者人別，故即使主刀醫師開刀前未再核對患者之身分，而對錯誤之患者開刀時，醫師也不用負過失傷害之責任  
(D) 在過失不作為犯的情形，依實務見解，過失犯的注意義務和不作為犯的作為義務屬於不同層次問題，不得混為一談

### 答案：(C)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ✅ | 醫療過失的注意義務標準應依**該醫療機構之等級與所在地區的醫療水準**判斷，不得一律以醫學中心為標準（醫療法§82參照） |
| (B) | ✅ | 他人違規已**極為明顯**，且行為人**有充足時間可避免**事故發生→行為人已能預見危險且有迴避可能→不得再主張信賴原則。此為信賴原則之**限制** |
| (C) | ❌（本題問「何者錯誤」） | 主刀醫師對患者身分之確認屬**其自身應盡之注意義務**，不得完全以信賴護理師為由免責。醫師有**親自核對患者身分**的義務，開錯刀仍應負過失傷害之責 |
| (D) | ✅ | 過失犯的**注意義務**（行為人是否違反客觀注意義務）與不作為犯的**作為義務**（保證人地位）為不同層次的法律問題，不得混為一談 |

> [!NOTE]
> **重點整理**
> - **醫療過失**判斷標準：依該醫療機構等級與地區之醫療水準，非一律以醫學中心為準
> - **信賴原則的限制**：已發現對方違規且有充足避險時間→不得主張信賴原則
> - **信賴原則在醫療領域的適用**：團隊醫療中各成員有各自注意義務，不得全然依賴他人
> - 過失犯之**注意義務** ≠ 不作為犯之**作為義務**：前者為行為規範層面，後者為保證人地位層面

## 柒、原因自由行為

### 十四、112年 第7題

某甲有睡眠困擾，按醫師處方，服用安眠藥；未料，服用安眠藥後，竟然於昏睡時夢遊。夢遊中，甲毆打同居人乙，直到乙報警，警察趕到現場壓制甲，甲才從睡夢中醒來。下列敘述何者正確？

(A) 依原因自由行為，甲成立故意傷害罪  
(B) 依原因自由行為，甲成立過失致傷罪  
(C) 依容許構成要件錯誤，甲成立過失致傷罪  
(D) 甲無罪

### 答案：(D)

| 選項 | 正確/錯誤 | 說明 |
|:---:|:---:|------|
| (A) | ❌ | **原因自由行為**（§19 III）之適用前提：行為人在**自由意志**狀態下（原因行為時），對**後續無責任能力狀態下的犯罪行為**有故意或過失。甲按醫師處方服用安眠藥，並非故意使自己陷入無責任能力狀態以傷人 |
| (B) | ❌ | 原因自由行為之過失型態：行為人雖無故意使自己陷入無責任能力狀態，但對該結果有**預見可能性**。甲依醫師處方正常服藥，**無法預見**會夢遊毆人，不符合過失之原因自由行為 |
| (C) | ❌ | **容許構成要件錯誤**係行為人誤認阻卻違法事由的前提事實存在，與本題無關。甲在夢遊中毆打乙，並未誤認任何防衛或避難情狀 |
| (D) | ✅ | 甲在夢遊狀態下毆打乙：(1) 夢遊中的行為不具**行為支配能力**，欠缺刑法上之「行為」；(2) 即使認為有行為，甲在夢遊中**完全喪失辨識及控制能力**（§19 I），且無原因自由行為之適用（正常服藥無預見可能性）。**甲無罪** |

> [!NOTE]
> **重點整理**
> - **原因自由行為**（§19 III）的適用要件：
>   1. 行為人在自由意志狀態下（原因行為）使自己陷入無責任能力/限制責任能力狀態
>   2. 對原因行為有**故意**或**過失**
>   3. 在該狀態下實行犯罪行為（結果行為）
> - 不適用原因自由行為的情形：依醫師處方正常服藥→無預見夢遊暴力行為之可能→無故意或過失
> - 夢遊行為：可能欠缺刑法上之「行為」（無意識支配），或構成§19 I 完全無責任能力

## 體系歸納

### 一、錯誤論體系圖

```
┌─ 故意與錯誤論 ─────────────────────────────────────────┐
│                                                         │
│  一、構成要件層次之錯誤                                   │
│    ├─ 客體錯誤（等價）→ 不影響故意（法定符合說）            │
│    │     例：看錯門牌（109§4）、誤認仇人（111§3A、110§10）  │
│    ├─ 打擊錯誤 → 對預定客體：未遂；實際客體：過失          │
│    │     例：射乙打中丙（111§3C）、石頭反彈（114§6）       │
│    ├─ 因果歷程偏離 → 可預見範圍內：不影響故意              │
│    │     例：推入河中撞橋墩（114§1A）、失血死（111§3D）     │
│    ├─ 概括故意（韋伯案例）→ 整體觀察，不影響故意           │
│    │     例：勒昏後埋土（114§1B）                          │
│    └─ 客觀歸責 → 被害人自我危險可排除歸責                  │
│          例：自行衝入火場（109§28C）                       │
│                                                         │
│  二、違法性層次之錯誤                                     │
│    ├─ 容許構成要件錯誤（誤想防衛）                         │
│    │   → 阻卻故意，可能成立過失犯                          │
│    │     例：誤認傷害而防衛（110§7）、拍電影（111§4）       │
│    ├─ 禁止錯誤（§16）                                     │
│    │   → 不免除刑責；可避免→得減輕；不可避免→免除          │
│    │     例：無照經營回收（111§6）、不知法律（113§9）       │
│    └─ 包攝錯誤                                            │
│        → 屬禁止錯誤之一種，依§16處理                      │
│          例：誤認動物非財物（112§5）                       │
│                                                         │
│  三、過失犯（故意之對面概念）                              │
│    ├─ 注意義務之判斷標準                                  │
│    ├─ 信賴原則（限制過失歸責）                             │
│    │     例：依規則駕車（110§5）、醫療過失（113§6）        │
│    └─ 原因自由行為                                        │
│          例：酒後縱火（109§4）、夢遊毆人（112§7）          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
