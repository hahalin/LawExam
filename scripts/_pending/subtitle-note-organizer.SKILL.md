# 課程字幕筆記整理技能

## 功能說明

此技能用於將課程字幕 Markdown 檔案（由 `html-subtitle-to-markdown` 技能產出），整理為**主題式結構化學習筆記**。每個主題產出一份獨立的筆記檔案，包含法條原文速查、一試重點提示、體系分析、案例解析等，方便複習備考。

### 核心特色

1. **📖 法條原文速查**：筆記開頭直接附上所有引用法條的原文，免開六法即可對照
2. **🎯 一試重點提示**：針對選擇題的考法，標出常見題型與答題關鍵
3. **主題分類**：依講課脈絡將字幕拆分成多個主題，每個主題一份筆記
4. **體系圖表**：使用 ASCII 體系圖、比較表格、邏輯推導圖整理複雜概念
5. **案例分析**：還原老師講解的案例，以結構化步驟呈現分析過程
6. **實務見解速查**：附上大法官解釋、判例、決議的要旨摘錄

## 適用情境

- 聽完一堂課後，將字幕整理成可複習的結構化筆記
- 字幕中法條和釋字飛太快，需要放慢整理
- 需要以一試選擇題為目標的重點提煉
- 搭配板書照片補強筆記內容

## 指令格式

### 整理整份字幕

```
整理{字幕檔路徑}筆記
```

範例：
```
整理課程字幕/民法/民法12.md筆記
```

### 整理字幕的特定範圍

```
{字幕檔路徑}到{行數}整理筆記
```

範例：
```
課程字幕/民法/民法12.md到1012行整理筆記
```

### 搭配板書照片

使用者可能會附上板書照片，要求對照更新筆記：

```
板書圖片我放在同資料夾如附件，你查看後適度調整更新筆記
```

## 資料來源

### 字幕 Markdown 檔案位置

所有來源檔案位於 `課程字幕/{科目}/` 資料夾，命名格式：
- `{科目}{編號}.md`
- 例如：`民法12.md`、`刑法06.md`

### 字幕檔案格式

字幕檔案的內容格式為時間戳記 + 文字：

```markdown
HH:MM:SS - HH:MM:SS  
字幕內容

HH:MM:SS - HH:MM:SS  
字幕內容
```

## 執行步驟

### 步驟 1：確認範圍

1. 讀取指定的字幕 Markdown 檔案
2. 若使用者指定了行數範圍，僅讀取該範圍
3. 若未指定，讀取整份檔案（注意：字幕檔案可能很長，數千行，建議分批讀取）

### 步驟 2：通讀字幕，辨識主題

逐段閱讀字幕內容，記錄：
- 老師講解的**法律概念**（如消滅時效、物上請求權）
- 引用的**法條**（如 §767、§125）
- 引用的**大法官解釋/憲法判決**（如釋字 107、憲判字第 20 號）
- 講解的**案例**（如通謀虛偽、浮覆地）
- 強調的**考試技巧**

### 步驟 3：主題分類

將內容依法律概念拆分成主題。分類原則：

1. **一個核心概念一個主題**：例如「§767 與消滅時效」、「釋字 771」各自獨立
2. **體系性的總論可獨立**：例如「消滅時效的客體分類」
3. **考試技巧獨立成篇**：老師強調的答題方法論獨立出來
4. **每份筆記聚焦且完整**：不要太碎（少於一個完整論點），也不要太雜（混入不相關概念）

### 步驟 4：為每個主題建立筆記檔案

依照下方「Markdown 結構範本」逐一建立筆記檔案。

### 步驟 5：品質檢查

- 確認法條原文正確（若不確定，標註「建議查閱最新條文」）
- 確認釋字/判例要旨與課堂講述一致
- 確認一試重點與筆記內容對應
- 確認體系圖的邏輯正確
- 確認案例分析步驟完整

### 步驟 6（可選）：搭配板書更新

若使用者提供板書照片：
1. 辨識板書中的法條、體系圖、案例標記
2. 對照現有筆記，補充遺漏的分類項目
3. 對齊板書的體系架構（如板書有更完整的分支）
4. 將板書特有的標記/簡寫轉化為筆記中的說明

## 輸出路徑

```
課程字幕/{科目}/{科目}{編號}-筆記-{序號}-{主題名稱}.md
```
序號兩位數、依講課（字幕時間）順序，讓檔案總管排序＝上課順序＝ELI5 卡片順序。

範例：
```
課程字幕/民法/民法12-筆記-01-消滅時效客體.md
課程字幕/民法/民法12-筆記-02-§767與消滅時效.md
課程字幕/民法/民法12-筆記-03-考試論述技巧.md
課程字幕/民法/民法12-筆記-04-釋字771與繼承回復請求權.md
課程字幕/民法/民法12-筆記-05-浮覆地與大法庭裁定.md
```
**建檔時就直接帶序號**：步驟 2 列出主題清單時同時定序，之後寫檔、ELI5 卡片底部都用同一個檔名，不需要事後改名。（`scripts/rename_notes_seq.py` 僅供補救舊檔。）

## Markdown 結構範本

每份筆記應包含以下結構（依序）：

### 1. 標題與來源

```markdown
# {科目}{編號} 筆記：{主題名稱}

> 來源：{科目}{編號} 課程字幕 HH:MM:SS ~ HH:MM:SS
```

### 2. 📖 法條原文速查

將本筆記中引用到的所有法條原文列出。格式：

```markdown
## 📖 法條原文速查

> **§767**（所有人之物上請求權）
> I 前段：所有人對於無權占有或侵奪其所有物者，得**請求返還**之。→ 對應**釋字 107**
> I 中段：對於妨害其所有權者，得**請求除去**之。→ 對應**釋字 164**
> I 後段：有妨害其所有權之虞者，得**請求防止**之。

> **§125**（一般消滅時效）
> 請求權，因**十五年**間不行使而消滅。但法律所定期間較短者，依其規定。
```

**撰寫原則**：
- 每條法條標註**條號**、**括號內簡稱**、**原文**
- 關鍵字詞用 `**粗體**` 標記
- 若該條文與釋字/判例有對應，用 `→` 附註
- 若法條太長，可摘錄與本筆記最相關的項或款即可
- 若不確定原文，加註「→ 建議查閱最新六法原文」

### 3. 📋 釋字/實務見解原文速查（視需要）

若本筆記涉及大法官解釋、憲法判決、判例、決議，列出要旨：

```markdown
## 📋 釋字原文速查

> **釋字 107 號**：已登記不動產所有人之回復請求權（§767 I 前段），無民法第 125 條消滅時效之適用。

> **69 台上 277 判例**：釋字 107 號所謂「已登記不動產所有人」，指依土地法辦理登記之不動產**真正所有人**，非指登記名義人。
```

### 4. 🎯 一試重點提示

以「常見考法→答題關鍵」表格形式，針對**選擇題**提煉重點：

```markdown
## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產之 §767 有無消滅時效？」 | **有**，§125（15 年） |
| 「已登記不動產之 §767 有無消滅時效？」 | **原則無**（釋字 107、164）；**例外有**（釋字 771） |
```

**撰寫原則**：
- 「常見考法」用**選擇題題幹的口吻**（引號包覆）
- 「答題關鍵」用**最精簡的結論**，粗體標記核心答案
- 標出**陷阱題型**（如一字之差結論相反的情形）
- 數量以 3~8 個為宜，聚焦該主題最可能出的題型

### 5. 正文內容

正文依主題性質靈活安排，常用元素包括：

#### 體系圖（用 ASCII art）

```markdown
```
§767 物上請求權
│
├── 動產 → 有消滅時效，適用 §125（15 年）
│
└── 不動產
    ├── 已登記 → 原則無時效（釋字 107、164）
    └── 未登記 → 原則有時效（§125，15 年）
```
```

#### 比較表格

```markdown
| 比較項目 | 概念 A | 概念 B |
|---------|--------|--------|
| 性質 | ... | ... |
| 時效 | ... | ... |
```

#### 案例分析

```markdown
### 案例：{案例名稱}

#### 事實
1. ...
2. ...

#### 分析

##### （一）請求權基礎：§___
1. 構成要件：...
2. 時效問題：...

##### （二）結論
- ...
```

#### 邏輯推導圖

```markdown
```
A 條件成立
     ↓
B 結論 → 但受 C 限制
     ↓
最終結論
```
```

### 6. 法條/實務見解速查表（正文末尾）

最後附上本筆記所有引用的法條與實務見解的快速對照表：

```markdown
## 關鍵法條速查表

| 法條 | 內容 | 與本主題關聯 |
|------|------|------------|
| **§767** | 所有人之物上請求權 | 本筆記核心 |
| **§125** | 一般消滅時效 15 年 | 時效期間 |

## 關鍵實務見解速查表

| 實務見解 | 要旨 |
|---------|------|
| **釋字 107** | 已登記不動產 §767 I 前段無時效 |
```

## 法條原文的取得方式

1. **優先從字幕內容推斷**：老師通常會唸出法條要旨
2. **可信度高的法條直接寫上**：核心法條（如 §767、§125、§144、§148）的內容已廣為人知
3. **不確定時標註**：加上「→ 建議查閱最新六法原文」
4. **不要捏造法條內容**：寧可只寫簡稱，不要寫錯原文

## 一試重點提示的撰寫要點

1. **以選擇題思維撰寫**：一試是選擇題，重點不是申論架構，而是「判斷力」
2. **標記陷阱**：容易搞混的概念、一字之差的區別、看似相同實則不同的選項
3. **結論導向**：選擇題需要明確的「是/否」判斷，不需要推導過程
4. **援引正確釋字號碼**：一試常考釋字對應的條文段落（如釋字 107 對應 §767 I 前段）

## 搭配板書更新的原則

當使用者提供板書照片時：

1. **辨識體系架構**：板書通常有清楚的分支圖，對齊筆記的體系圖
2. **補充遺漏分類**：板書可能涵蓋字幕未充分展開的分支
3. **標記板書簡寫**：將板書中的簡寫（如「83.7th」→「83年第七次民事庭決議」）轉為完整說明
4. **對齊案例步驟**：板書的案例解題步驟通常很精簡，確保筆記步驟與板書吻合
5. **注意板書特有內容**：板書可能有字幕中沒有明確提到的結論或標記

## 🧒 ELI5 頁（每堂課一份 HTML）

主題筆記是查表用；ELI5 頁是**入口**，先消化再去翻主題筆記。

### 輸出路徑與共用檔

```
課程字幕/{科目}/{科目}{編號}-ELI5.html     ← 只放內容
課程字幕/_eli5/style.css                   ← 共用樣式（卡片、流程框、分叉、分類樹、兩欄比較、時間軸 SVG）
課程字幕/_eli5/app.js                      ← 全部展開/收合、「我懂了」存 localStorage、進度條
```
不吃 CDN，離線能開。範本：`課程字幕/民法/民法01-ELI5.html`。

### 卡片結構（與主題筆記一對一，同順序）

```html
<section class="card" id="c5">
  <h2><span class="n">5</span>情境式標題（白話但用法律用語）</h2>
  <div class="scene">
    <p>具體情境：甲乙丙 + 金額/日期，像在講一件事，不先講法條。</p>
    <p class="q">一句問題，讓他先想。</p>
  </div>
  <!-- 圖：擇一或組合 -->
  <div class="flow">…</div>       <!-- 線性流程：.b 框、.a 箭頭、.a.lbl 帶字箭頭、.br 換行；.b.ok/.no/.q/.dim -->
  <div class="fork">…</div>       <!-- 條件 → 兩個結果：.cond、.out>.tag+.b -->
  <div class="tree">…</div>       <!-- 分類樹：巢狀 ul；li.hit 強調、li.off 淡化 -->
  <div class="vs">…</div>         <!-- 兩欄比較：div.rule-c / div.trap-c -->
  <svg class="tl">…</svg>         <!-- 時間軸，照民法01 卡 6 的寫法 -->
  <details class="rule"><summary>規則</summary><div class="body">2～3 句，條號用 <span class="s">§7</span></div></details>
  <details class="trap"><summary>陷阱</summary><div class="body">1～2 句，一試最常錯的點</div></details>
  <div class="card-foot"><label><input type="checkbox">我懂了</label><span class="src">對應的主題筆記檔名（含序號）.md</span></div>
</section>
```

### 寫法

- 標題用情境或結論（「要慰撫金時，人格權分兩種門檻」），**不用需要轉一下才懂的比喻**（✗「分兩種票價」✗「預先發的會員卡」）。Frank 要在讀寫中適應法律界的習慣用語，二試輸入輸出都是這套，ELI5 是入口不是翻譯。
- 情境 → 問題 → 圖 → 規則 → 陷阱，順序固定；規則永遠在情境後面。
- 規則、陷阱的語氣是講給剛開始學法律的人聽：句子可以白話，但**法律概念一律用正式用語**（除去侵害、防止侵害、效力未定、不得對抗、情節重大），第一次出現可在括號裡用情境白話解釋一次（「除去侵害（這題就是刪文）」），之後不再另造口語代稱。條號放括號或 `.s` 小標，不進句子主幹。
- 卡片間互相引用要寫對卡號；口語代稱（刪文）只在它自己的情境那張卡用。
- 每卡 150～250 字（不含圖）；一堂 6～12 卡。
- 不列法條原文、不放速查表——那些在主題筆記。
- 老師說「超愛考」的一定進陷阱。

### 檢查

寫完用無頭瀏覽器（Playwright，桌機 900px 與手機 390px）截圖看：流程框換行是否正常、時間軸文字有無重疊、分叉在手機上是否堆疊。

### 產出順序

一堂課的順序固定：**先主題筆記 → 再 ELI5 頁**（卡片底部的檔名要對到實際存在的筆記）。

## 一堂課的完整流程（CLAUDE.md 也會引用）

0. 先把字幕壓縮成純文字（去時間戳與空行、每 25 句留一個時間標記）再讀，省一半篇幅。
1. 分批讀字幕（每批 500～800 行），邊讀邊列主題邊界與時間戳。**字幕檔內若有使用者自加的 `##`／`###` 標題（如「### 請求權基礎為何?」、「#### 367 買受人之義務」），那是他上課時的板書標記，直接當主題邊界與條號線索用。**
2. 列出主題清單（檔名）給使用者看一眼，**不等回覆**，直接開始寫。
3. 逐一產出主題筆記；每寫完一份回報一行。
4. 寫 ELI5 頁，截圖檢查。
5. 最後附一行這堂課的檔案清單。

## 注意事項

1. **字幕檔案可能很長**：一堂課的字幕可能數千行，建議分批讀取（每次約 500 行），先粗讀辨識主題邊界，再細讀各主題內容
2. **字幕有口語雜訊**：老師的口語會有重複、停頓、離題等，需要提煉核心內容，不是逐字搬運
3. **法條原文要正確**：這是讓使用者建立法條印象的關鍵，不確定寧可標註也不要寫錯
4. **一試重點要實用**：以「看完這張表就能答對選擇題」為目標
5. **不覆蓋既有筆記**：若同一主題的筆記已存在，應以更新方式處理，不可覆蓋
6. **來源標記**：每份筆記標明字幕的時間範圍，方便使用者回頭聽原始課程對照
