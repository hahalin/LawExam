# 4 大 Notion 國考筆記整理術
### 1. 爭點地圖資料庫（最核心的無價之寶）
司律二試的本質是「爭點的排列組合」。上榜生通常會建立一個「全科目爭點資料庫」，利用 Notion 的標籤功能進行跨學科的管理：
- 欄位設計：
  - 名稱：爭點題目（例如：民法 §184 第1項前段「權利」是否包含純粹經濟損失？）。
  - 科目標籤：民法 / 刑法 / 民訴 / 刑訴。
  - 學說見解：用 Toggle（折疊清單）收納各學派看法，保持頁面乾淨。
  - 實務見解：直接複製貼上相關的最高法院判例、大法庭裁定字號。
  - 上榜金句：直接把要在考卷上寫出來的 100-200 字「百搭帥氣帥話」寫在最顯眼處，考前衝刺純背這個。
- 強大優勢：你可以利用「Relation（關聯）」功能，把民法與民訴有交集的爭點（如：訴訟標的相對化）串聯在一起，打破學科壁壘。
### 2. 進度與複習週期追蹤表（滾動式複習）
國考最忌諱「讀到後面，忘了前面」。上榜生會利用 Notion 來管理補習班進度或參考書的複習進度：
- 狀態標籤：未開始、進行中、已聽完錄音、已做完章節筆記。
- 複習進度計數：紀錄這個章節已經讀了第幾遍（一讀、二讀、三讀）。
- 串聯「艾賓浩斯記憶法」：利用 Notion 的 Formula（公式）功能，設定讀完某一章後，系統會自動在「第 1 天、第 7 天、第 30 天」跳出提醒，通知你該用 iPad mini 點開法律人 App 複習該章節的重點法條。
### 3. 考古題錯題與答題模組庫
當你進入二試衝刺期（約考前 3-4 個月），Notion 會轉變為你的「武器庫」：
- 錯題紀錄：寫一試選擇題時，只要錯了，就把題目截圖貼進 Notion，並在一旁標註「錯題原因（例如：沒看清是『得』還是『應』）」，以及超連結對應的法律人 App 法條。
- 答題解題大綱：不需要每次都完整寫完一整篇申論題，那太耗時間。上榜生會將各類經典題型（如：共犯與身分、行政處分之定性）的「開標結構」與「解題層次」打字在 Notion 中。考前只要快速掃視這些大綱，就能在大腦中演練輸出。
### 4. 實務見解與最新修法追蹤牆
修法與最新憲判字是司律考試的必考地帶：
- 表格化管理：左邊放「舊法／舊實務」，右邊放「新法／新實務（如最新憲法法庭判決）」，中間欄位寫「修法理由與影響」。
- 網頁擷取工具（Notion Web Clipper）：在電腦瀏覽器或手機上看到學者發表的最新時事法律評論、或是司法院公布的大法庭裁定，一鍵直接抓取存入 Notion 的「待讀清單」，後續再利用零碎時間消化。

# 跨學科爭點資料庫標籤分類範例
> 在 Notion 中，準備司律（律師／司法官）考試的核心心法是「用同一個資料庫（Database）管理所有爭點，再透過標籤（Select/Multi-Select）來自由切換視窗」。
> 這樣才能應付一、二試常見的跨科綜合題（例如：民法與民事訴訟法交織、刑法與刑事訴訟法綜合考題）。
> 以下為你規劃一套專為司律國考設計的「跨學科爭點資料庫標籤分類範例」，你可以直接照著在 Notion 中建立欄位：

## 🏗️ 第一步：建立核心資料庫欄位 (Properties)
在 Notion 建立一個名為「司律國考爭點地圖」的資料庫，並設定以下 5 個關鍵欄位：
1. 爭點名稱 (Name)：主標題，用一句話點出問題。
2. 實體／程序跨科標籤 (Multi-select)：這是最關鍵的跨科橋樑。
3. 科目分類 (Select)：傳統的大學科分類。
4. 考試重要度 (Select)：標記星等（★★★ 必背、★★ 重要、★ 偏門）。
5. 備考狀態 (Status)：未讀、已理解、考前衝刺必看。

## 🏷️ 第二步：跨學科標籤 (Multi-select) 具體分類範例
請在 「實體／程序跨科標籤」 這個欄位中，建立以下這些「跨學科/跨領域標籤」。這些標籤能幫你把散落在不同科目、卻有相同法理或會一起考的爭點串聯起來：
### 1. ⚖️ 標籤：【民法✕民訴】
- 適用時機：實體法上的權利，在訴訟法上如何主張或定性？二試綜合題的最愛。
- 爭點範例：
  - 「訴訟標的相對化」（民法不當得利/侵權行為 ✕ 民訴訴訟標的理論）
  - 「連帶債務之訴訟拘束力」（民法 §272 ✕ 民訴 §56 共同訴訟）
  - 「代位權之既判力擴張」（民法 §242 ✕ 民訴 §401 判決效力）
### 2. ⛓️ 標籤：【刑法✕刑訴】
- 適用時機：實體法的犯罪成立與否，會直接影響程序法上的強制處分或證據能力。
- 爭點範例：
  - 「相牽連案件之沒收程序」（刑法沒收新制 ✕ 刑訴沒收特別程序）
  - 「告訴乃論之罪與告訴權人」（刑法個別罪名如傷害罪 ✕ 刑訴 §232 告訴權）
  - 「違法搜索與犯罪故意之認定」（刑法實體犯罪 ✕ 刑訴 §131 緊急搜索與證據排除）
### 3. 🏛️ 標籤：【憲法✕行政法】（公法大帝國）
- 適用時機：行政機關的行為是否違反憲法原則？或是憲法法庭判決如何影響行政處分的效力。
- 爭點範例：
  - 「法律保留原則與授權明確性」（憲法基本權限制 ✕ 行政程序法 §150 法規命令）
  - 「違憲法規適用之救濟」（憲法法庭裁判效力 ✕ 行政訴訟法 §273 再審事由）
  - 「比例原則於警察裁量之適用」（憲法 §23 ✕ 警職法/行政罰法裁量）
### 4. 💼 標籤：【民法✕商事法】
- 適用時機：商事法是民法的特別法，兩者互動極為頻繁。
- 爭點範例：
  - 「董事違反忠實義務之損害賠償」（公司法 §23 ✕ 民法 §184 侵權行為）
  - 「表見代理於支票簽名之適用」（票據法 §5 ✕ 民法 §169 表見代理）
### 5. 🎯 標籤：【一試專用】 / 【二試爭點】
- 適用時機：有些概念只會考一試選擇題，有些則是二試申論題的大熱門。
- 用途：考前一個月，你可以直接篩選【一試專用】，拿著 iPad mini 狂刷這些純法條細節的爭點。
## 👁️ 第三步：如何利用 Notion 「檢視功能 (Views)」展現跨科威力？
設定好上述標籤後，你可以在 Notion 同一個頁面上創造多個「標籤分頁（Views）」，達到神級的複習效果：
- 設定「民刑事綜合題檢視」
  建立一個 Filter（篩選器），設定「標籤包含【民法✕民訴】或【刑法✕刑訴】」。在寫大綜合題時，點開這個分頁，你就能一眼看出哪些實體法權利會牽動訴訟法程序。
- 設定「考前一週帥話牆」
  篩選「狀態為：考前衝刺必看」＋「重要度：★★★」。Notion 會把所有跨科最核心的爭點、以及你從法律人 App 複製過來的最新大法庭裁定精華集中在一起。考前在考場休息區，你只需要用 iPad mini 滑這個清單，就能完成最有效率的總複習。   
透過這種「以爭點為核心、標籤為橋樑」的 Notion 整理術，搭配 iPad mini 上的法律人 App 隨時查閱法條，你的數位大腦就能在司律考試中發揮最大威力！

# Notion MCP
## 1. Claude Code ✕ Notion MCP（上榜生最強推崇）
如果你有一定的資訊基礎或願意嘗試，Anthropic 官方推出的命令列工具 Claude Code 搭配 Notion MCP (Model Context Protocol) 協議，是目前最黑科技的組合。
### 💡 它能做到什麼？
你可以在終端機直接對 Claude 說白話文：
> 「把這篇最新大法庭裁定的法理摘要下來，直接在我的 Notion『司律爭點地圖』資料庫裡新增一筆資料。科目設定為【民訴】，跨科標籤勾選【民法✕民訴】，並在內頁建立學說與實務對照表。」
Claude 收到後，會自動透過 API 讀取你資料庫的欄位格式（Schema），並完美地幫你把資料填入正確的格子裡，連複製貼上都省了！
### 🔧 如何串接設定？
Notion 官方有提供完整的 [Notion MCP 串接指南](https://developers.notion.com/guides/mcp/get-started-with-mcp)：
1. 在電腦的終端機執行指令安裝 Notion 插件：
   ```
   bash
   claude mcp add --transport http notion https://mcp.notion.com/mcp
   ```
2. 輸入 /mcp 啟動認證流程，網頁會自動跳出 Notion 的 OAuth 授權畫面。
3. 關鍵步驟：勾選並允許 Claude 存取你用來備考的那個「司律筆記工作區」即可。
