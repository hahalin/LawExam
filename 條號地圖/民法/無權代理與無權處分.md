# 條號地圖：無權代理 vs 無權處分

> 主題：民法總則／物權－代理外觀保護 與 公示外觀保護  
> 適用：2026 司律一試民法、綜合法學（二）  
> 來源：2026-05-03 對話整理（無權代理與條號地圖）  
> 性質：條號地圖試作版本，用於驗證 `condition-map` skill 規格

---

## 0. 一句話總結

> 自己名義 → 走無權處分（§118）→ 第三人信「物的公示外觀」→ 善意取得（§801、§948、§759-1）。  
> 他人名義 → 走無權代理（§170）→ 第三人信「代理權外觀」→ 表見代理（§107、§169）。  
> **兩條路徑不互通，不能混用。**

---

## 1. 最短一行筆記（功能標籤，不抄全文）

### 無權代理組

| 條號 | 一行功能標籤 |
| --- | --- |
| §103 | 代理行為的效力歸屬本人（代理的基本條） |
| §107 | 代理權「事後限制或撤回」不得對抗善意無過失第三人 |
| §169 | 本人「自己製造授權外觀」或「知情不反對」→ 負授權人責任（表見代理） |
| §170 I | 無權代理對本人不生效，等本人承認 |
| §170 II | 相對人可催告本人表態，逾期視為拒絕承認 |
| §171 | 善意相對人在本人承認前可撤回 |
| §110 | 無權代理人對善意相對人的損害賠償責任 |

### 無權處分組

| 條號 | 一行功能標籤 |
| --- | --- |
| §118 I | 無權處分原則上效力未定，須權利人承認 |
| §118 II | 無權處分人事後取得權利，處分自始有效 |
| §801 | 動產善意取得的「效果條」：受讓人取得所有權 |
| §948 | 動產善意取得的「要件條」：善意 + 無重大過失 + 占有移轉 |
| §949 | 盜贓、遺失物例外：原權利人 2 年內得回復 |
| §759-1 I | 不動產登記的權利推定 |
| §759-1 II | 信賴登記善意取得：登記公信力 |

              【170 I】無權代理 → 對本人不生效
                       │
        ┌──────────────┼──────────────┐
        ▼                              ▼
   有外觀（本人有歸責）          沒有外觀
        │                              │
        ├─【107】事後限制/撤回         ├─【170 II】相對人催告
        └─【169】授權外觀/知情不反對   ├─【171】善意相對人撤回

                       │
        ┌──────────────┼──────────────┐

### 兩組並列（一試最愛考的對應）

| 比較項目 | 無權處分 | 無權代理 |
| --- | --- | --- |
| 起手條 | §118 | §170 |
| 名義 | 自己 | 本人 |
| 缺什麼 | 處分權 | 代理權 |
| 第三人信什麼 | 物的公示外觀 | 代理權外觀 |
| 第三人保護 | §801、§948、§759-1 | §107、§169 |
| 是否要求本人/權利人有過失 | 不要求 | 要求（§169 須有可歸責性） |
| 救濟條 | §949（限制） | §110、§170 II、§171 |
| 取得內容 | 物權（所有權） | 債權（契約對本人生效） |

## 3. 起手判斷流程（5 步驟）

1. **看名義**：行為人用「自己」名義 → 進 §118；用「本人」名義 → 進 §170。
2. **問效力**：原則上都是「效力未定」，等真正權利人/本人承認。
3. **找外觀**：
   - 自己名義 → 第三人是不是相信「物在他手上 / 登記在他名下」？
   - 本人名義 → 第三人是不是相信「他有代理權」？
4. **套保護條**：
   - 動產公示外觀 → §801 +§948
   - 不動產登記公信 → §759-1 II
   - 代理權外觀 → §107 或 §169
5. **不能保護就走救濟**：
   - 無權處分側：§949 限制是否適用
   - 無權代理側：§170 II 催告、§171 撤回、§110 求償

## 4. 高頻混淆點（一試陷阱對照）

### 陷阱 1：張冠李戴（最常見）

> 題幹用「自己名義」賣，選項卻寫「§170 無權代理」→ 直接刪。  
> 題幹用「本人名義」簽約，選項卻寫「§801 善意取得」→ 直接刪。

**口訣**：看名義先刪一半選項。

### 陷阱 2：占有改定不適用善意取得

> §948 II：以「占有改定」方式受讓動產者，須現實受讓占有後，才適用善意取得。  
> 題幹若出現「畫先借我兩天」「先寄放在賣方」→ 不能主張 §801。

### 陷阱 3：盜贓遺失物的 2 年回復期

> §949：縱使第三人善意取得，原權利人於遺失或被盜之 2 年內仍得請求回復。  
> 例外：第三人於公開市場、拍賣、販賣同種物之商人處買得 → 須償還價金（§950）。

### 陷阱 4：§107 vs §169 的差別

| 條文 | 情境 | 關鍵字 |
| --- | --- | --- |
| §107 | 本人「曾經授權」，後來限制或撤回 | 「事後」變動 |
| §169 | 本人「從未授權」，但製造外觀或知情不反對 | 「自始」無權但有外觀 |

### 陷阱 5：§169 須本人有可歸責性

> 善意取得（§948）不問原所有人有無過失。  
> 表見代理（§169）須本人「製造外觀」或「知而不反對」，本人無可歸責則不成立。

### 陷阱 6：相對人保護條的順序

> §171 撤回權：必須在「本人承認前」、「相對人為善意」。  
> §170 II 催告：本人逾期不答覆 → 視為「拒絕承認」（不是視為承認，題目常顛倒）。  
> §110 求償：要件是「無權代理人」對「善意相對人」，且本人不承認時才有適用。

## 6. 實戰自我測驗（30 秒內回答）

1. 甲將乙的相機，「以甲自己名義」賣給善意的丙並交付 → 適用？  
   → §118 + §801、§948（無權處分 + 善意取得）

2. 甲冒稱是乙的代理人，以「乙的名義」與丙簽約 → 適用？  
   → §170（待乙承認）；若乙曾交付印章造成外觀 → §169 表見代理

3. 乙之前授權甲，事後撤回授權但未收回委任狀，甲又以乙名義簽約 → 適用？  
   → §107（代理權限制不得對抗善意無過失第三人）

4. 丙從乙處買畫，但畫仍寄放在乙處（占有改定） → 能否善意取得？  
   → 不能。§948 II 須現實受讓占有。

5. 本人逾期不答覆催告 → 視為承認 or 拒絕？  
   → 拒絕承認（§170 II）。

## 7. 本主題最短可保留版本（如果只剩 30 秒複習）

> 1. **看名義**：自己 → 118；本人 → 170。  
> 2. **看外觀**：物的外觀 → 801、948、759-1；代理的外觀 → 107、169。  
> 3. **看救濟**：無權處分例外看 949；無權代理救濟看 110、170 II、171。  
> 4. **核心差異**：善意取得不問本人過失；表見代理（169）要本人可歸責。
