# 強制執行法02 筆記：對合夥之執行

## 合夥團體與合夥人：
- 合夥是**非法人團體**，有當事人能力（民訴 §40 III），可為原告、被告
- 合夥團體的財產與各合夥人自己的財產**分開**

## 執行順序（補充連帶責任）：
- 執行名義命**合夥**給付 → 第一步先執行**合夥財產**
- **不足清償**時 → 第二步才執行**各合夥人**財產（民 §681）
- 這也是**主觀範圍擴張**：執行名義只寫合夥，卻可執行合夥人；但不能一開始就找合夥人

## 合夥人有爭執：
- 否認自己是合夥人（如主張早已退夥）→ 實體爭執，執行處不處理
- 無確認其為合夥人之確定判決 → **不得**對之強制執行
- 救濟：**§14-1 I** 異議之訴（§4-2 與 §14-1 是一組）

## 📖 法條原文速查

> **民 §681**　合夥財產**不足清償**合夥之債務時，各合夥人對於不足之額，**連帶**負其責任。
> **民訴 §40 III**　非法人之團體，設有代表人或管理人者，有當事人能力。
> **強制執行事件辦理注意事項 2**　確定判決命合夥履行債務者，應先對**合夥財產**為執行，如不足清償時，得對**合夥人之財產**執行。但其人**否認為合夥人**，而無確認其為合夥人之確定判決者，不得對之強制執行。（項次、原文請對講義）
> **強執 §14-1 I**　債務人對於債權人依第四條之二規定聲請強制執行，如主張非執行名義效力所及者，得於強制執行程序終結前，向執行法院對債權人提起異議之訴。（原文請對六法）

## 📋 實務見解速查

> **22 年院字 918 號解釋**（年度、字號依字幕，請對講義）：原確定判決雖僅令合夥團體履行債務，但合夥財產不足清償時，自得對合夥人執行；合夥人如有爭執，應令其起訴。
> **66 年第九次民事庭會議決議**（老師請自行閱讀，內容請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「以合夥為債務人之執行名義，得直接執行合夥人財產？」 | **不得直接**；先執行合夥財產，**不足**時始得執行合夥人 |
| 「乙餐廳（合夥）財產不足清償，債權人得持對餐廳之判決執行合夥人？」 | **得**（民 §681，主觀範圍擴張） |
| 「合夥人主張早已退夥，執行處應審理？」 | **否**，實體爭執；無確認其為合夥人之確定判決不得執行 |
| 「主張已退夥之人，循何程序避免個人財產被執行？」 | **§14-1 I** 異議之訴 |
| 「合夥人對合夥債務之責任性質？」 | **補充**連帶責任（有先後順序） |

## 一、雞排店例（老師板書）

```
甲廠商 ──貨款 100 萬給付之訴──→ A 合夥（雞排店）  ← 判決確定，執行名義寫 A 合夥
                                     │
                              合夥人：乙、丙、丁（各有自己的財產）

步驟 ①  先執行 A 合夥財產
        │ 不足清償
步驟 ②  再執行乙、丙、丁個人財產（就不足額連帶，民 §681）
        │ 有人否認是合夥人（退夥）
        └→ 須有確認其為合夥人之確定判決，否則不得執行；當事人提 §14-1 訴訟
```

## 二、練習

```
甲對乙餐廳請求買賣價金勝訴確定，持判決對乙餐廳聲請執行
(1) 餐廳財產不足清償，得否對合夥人聲請執行？ → 得
(2) 某人爭執早已退夥、非合夥人，循何程序？ → §14-1 I 異議之訴（民事訴訟，實體救濟）
```

- 老師：§14-1 搭配 §4-2，對主觀範圍有爭執就用 §14-1 起訴；細節在救濟章節再講。不要隨便合夥，合夥人要負連帶責任。
