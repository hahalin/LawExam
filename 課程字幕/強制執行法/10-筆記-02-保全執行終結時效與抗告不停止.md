# 強制執行法10 筆記：保全執行終結時效與抗告不停止

## 債務人於裁定後死亡：
- 致未能送達 → **不影響**假扣押之執行
- 執行後由法定繼承人**聲明承受**，對**承受人**（繼承人）送達；對一般繼受人續行執行（§4-2、民訴 §401），除非拋棄繼承

## 保全執行的終結：
- 假扣押之執行，以假扣押標的**脫離假扣押之處置**為終結
- 兩例：① 標的**交付（本案）終局執行**；② **撤銷假扣押**
- 已轉本案執行 → 第三人只能對**本案執行程序**提 §15 第三人異議之訴；已終結的假扣押程序無從再排除

## 時效中斷何時終止（103 年第 2 次決議）：
- 因假扣押強制執行而中斷者，於假扣押**執行行為完成時**（查封、查封登記、強制管理、緊急換價提存、提存收取之金錢）中斷事由終止，時效**重行起算**
- **不是**等到標的脫離假扣押處置才重算 → 債權人要趕快起訴本案

## 抗告不停止執行：
- 對假扣押、假處分裁定抗告，除有停止執行之裁定外，**無停止執行效力**（民訴 §491）
- 抗告歸抗告、執行歸執行

## 📖 法條原文速查

> **強執 §4-2 I ①**　執行名義為確定終局判決者，除當事人外，對於**訴訟繫屬後為當事人之繼受人**……亦有效力。（原文請對六法）
> **民訴 §168**　當事人死亡者，訴訟程序在有繼承人……**承受其訴訟**以前當然停止。（原文請對六法）
> **民訴 §491 I**　抗告，除別有規定外，**無停止執行之效力**。
> **強執 §15**　第三人就執行標的物有足以排除強制執行之權利者，得於強制執行程序**終結前**，向執行法院對債權人提起異議之訴。

---

## 📋 實務見解

> **保全執行終結之判例**（字號請對講義）：假扣押之執行，以假扣押之標的**脫離假扣押之處置**，例如將假扣押標的交付執行或撤銷假扣押，為執行程序之終結。在將假扣押標的交付執行之情形，於本案執行程序終結前，第三人就執行標的物如有足以排除強制執行之權利，**僅得提起請求排除本案執行程序之異議之訴**；對於已終結之假扣押程序，無提起異議之訴再請求排除之餘地。
> **103 年第 2 次決議**（字幕所唸，年度與會議別請對講義）：消滅時效因假扣押強制執行而中斷者，於法院實施假扣押之執行程序，例如查封、通知登記機關為查封登記、強制管理、對於假扣押之動產實施緊急換價提存價金、提存執行假扣押所收取之金錢等**行為完成時**，其中斷事由終止，時效**重行起算**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人於假扣押裁定後死亡致未能送達，應撤銷執行？」 | **不撤銷**；執行後對聲明承受之**繼承人**送達 |
| 「假扣押執行程序何時終結？」 | 標的**脫離假扣押處置**：交付終局執行、撤銷假扣押 |
| 「假扣押已轉本案執行，第三人應對哪個程序提 §15？」 | **本案執行程序**；已終結之假扣押程序不得再訴請排除 |
| 「假扣押執行中斷時效，於假扣押撤銷或標的脫離時才重行起算？」 | **錯**。執行行為（如查封）**完成時**即重行起算 |
| 「債務人對假扣押裁定抗告，執行應停止？」 | **不停止**（抗告不停止執行原則），除另有停止執行裁定 |

## 一、時效中斷：一下子就結束

```
聲請假扣押執行 → 時效中斷
      ↓
查封行為完成（動產：置於執行人員實力支配下，一瞬間）
      ↓
中斷事由終止 → 時效重行起算 ✔
✕ 不是「查封狀態持續中」都算中斷
✕ 不是「脫離假扣押處置」才重算
→ 債權人：趕快起訴本案（也是避免被命限期起訴後撤銷裁定）
```

## 二、終結的兩種情形

| 情形 | 後續 |
|---|---|
| ① 交付本案終局執行 | 改用本案案號；第三人異議對**本案程序** |
| ② 撤銷假扣押 | 程序終結，無後續 |

## 三、抗告與執行是兩條線

```
民事庭：假扣押裁定 → 債務人收受送達 → 10 日內抗告（抗告期間仍從送達起算）
執行處：先執行（查封）————————— 繼續有效，不因抗告而停止
抗告成功且確定 → 持裁定到執行處聲請撤銷執行處分（§132-1，筆記 05）
```
