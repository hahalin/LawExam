# 強制執行法04 筆記：第三人異議之訴 §15——第三人就執行標的物有**足以排除強制執行之權利**（實體；錯誤執行：執行到非債務人的財產）→ 於該標的物（**個別**）執行程序終結前，向執行處所屬地院**民事庭**對債權人起訴（債務人亦否認其權利時並得列債務人為被告）；形成之訴；「足以排除強制執行之權利」：44 台上 721 例示所有權、典權、留置權、質權，**非以此為限**；單純占有（民法 §940 事實上管領力）**不行**；共有：僅執行債務人之**應有部分**→ 其他共有人不得提（無影響）；執行**全部**或**公同共有**→ 得提；土地法 §34-1 多數決是共有人**主動**處分，不適用被執行，執行名義未及之共有人仍得提

> 來源：強制執行法04 課程字幕 01:56:00 ~ 02:10:30（講義 157～159 頁）

---

## 📖 法條原文速查

> **強執 §15**　第三人就執行標的物有足以排除強制執行之權利者，得於強制執行程序終結前，向執行法院對債權人提起異議之訴。如債務人亦否認其權利時，並得以債務人為被告。
> **土地法 §34-1 I**　共有土地或建築改良物，其處分、變更及設定地上權、農育權、不動產役權或典權，應以共有人過半數及其應有部分合計過半數之同意行之。但其應有部分合計逾三分之二者，其人數不予計算。
> **民法 §940**　對於物有事實上管領之力者，為占有人。

---

## 📋 實務見解速查

> **44 年台上字第 721 號判例**（講義 158 頁）要旨：§15 的「足以排除強制執行之權利」指對執行標的物有所有權、典權、留置權、質權之一者；占有依民法 §940 只是事實上管領力，不包含在內。→ 講義註明此為**例示**，不以這四種為限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§15 之結構？」 | 原告**第三人**、被告**債權人**（債務人否認其權利時並列）、向執行處所屬地院**民事庭**、**形成之訴**（訴之聲明：某執行事件就某標的物之執行程序應予撤銷）、得併 §18 II 停止執行 |
| 「§15『終結前』指？」 | **個別**（該執行標的物之執行程序終結前）。§14 是整個（否定執行名義）、§15 是個別（針對客體瑕疵） |
| 「何謂足以排除強制執行之權利？」 | 第三人就標的物有一定權利，因執行受侵害而**法律上無忍受義務**。44 台上 721 例示：所有權、典權、留置權、質權——**不以此為限**（用益物權、擔保物權、孳息收取權等視情形，筆記 08） |
| 「單純占有人得否提 §15？」 | **不得**。沒有物權等級的權利，占有只是事實上管領力 |
| 「甲持對乙1、乙2 之執行名義，執行三人（乙1、乙2、乙3）共有之 A 地」 | ① 僅執行乙1 之**應有部分**→ 乙3 無影響 → **不得**提（持分可賣）② 執行 A 地**全部**→ 侵害乙3 的三分之一 → **得**提 ③ **公同共有**→ 同樣影響 → 得提 ④ 乙1＋乙2 的應有部分已達土地法 §34-1 多數決 → 仍**得**提：§34-1 是共有人間**主動行使同意權處分**土地的規定，不是被執行；不得據此否定共有人提第三人異議之訴的權利，債權人不得為實現債權侵害債務人以外第三人之權利 |

## 一、§15 vs §14

| | §14 債務人異議之訴 | §15 第三人異議之訴 |
|---|---|---|
| 瑕疵 | 執行名義（實體請求權） | 執行客體（標的物不是債務人的） |
| 原告 | 債務人 | 第三人 |
| 被告 | 債權人 | 債權人（＋否認之債務人） |
| 終結前 | **整個** | **個別**（該標的物） |
| 異議事由時期限制（既判力） | 有（有確定判決效力時） | 無 |

- 實務訴狀例：原告為既存建物共有人之一，執行名義只對其他人，「你欠缺對我的執行名義，不能對我執行」→ 典型第三人異議之訴。

## 二、共有的四種情形

```
A 地：乙1、乙2、乙3 各 1/3；執行名義只對乙1、乙2
① 只執行乙1 應有部分 → 乙3 ✗（持分可單獨拍賣，不影響他）
② 執行全部 → 乙3 ✓
③ 公同共有 → 乙3 ✓
④ 乙1＋乙2 ＝ 2/3，看似符合 §34-1 多數決 → 乙3 仍 ✓
   §34-1：共有人主動處分、變更、設定負擔時的同意權規定，不是強制執行的規定
```
