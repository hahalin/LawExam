# 強制執行法07 筆記：投標程序與投標瑕疵（§85～§90）

## 投標的性質：
- 只有**不動產**才有投標；應買人把金額寫在投標書，**書面、秘密**投入標匭，執行法官當眾開標朗讀
- 不動產可口頭競價或投標（§85「得」），實務多用投標
- 只有投標會出現**出價相同**；口頭競價後出更高價者，前一出價即失拘束力

## 投標的要件：
- 未繳保證金 → 投標**無效**（§89），不能補繳
- 代理投標須**及時**提出授權證明，否則代理權欠缺、投標無效，不準用定期補正
- 投標書投入標匭後**不得撤回**（民法 §95 到達生效；撤回通知須同時或先時到達）

## 出價相同（§90）：
- ① **當場增加金額**最高者得標 → ② 無人增加才**抽籤**
- 得標人未繳足價金 → 同條件再行拍賣；但未中籤者仍願依原條件承買者，由其承買

## 合併拍賣的投標瑕疵（注意事項 50）：
- 未記載每宗價額／每宗合計與總價不符 → 以**總價**為準
- 只記每宗、漏記總價 → 執行法院**代為合計**
- 總價最高且達最低總價，但某宗未達該宗底價 → 執行法院**按比例調整**

## 廢標的救濟：
- 原則：執行程序終結前 **§12 聲明異議**
- 曾經宣告**得標**後又被認為廢標 → 得另提**確認買賣成立之訴**

## 📖 法條原文速查

> **強執 §85**　拍賣不動產，執行法院**得**因債權人或債務人之聲請或依職權，以**投標**之方法行之。
> **強執 §87**　I 投標人應以書件**密封**，投入執行法院所設之標匭。II 前項書件，應載明左列事項：一、投標人之姓名、年齡及住址。二、願買之不動產。三、願出之價額。
> **強執 §88**　開標應由執行法官**當眾開示**，並朗讀之。
> **強執 §89**　投標應繳納保證金而**未照納**者，其投標**無效**。
> **強執 §90**　I 投標人願出之最高價額相同者，以**當場增加之金額最高者**為得標人；無人增加價額者，以**抽籤**定其得標人。II 前項得標人未於公告所定期限內繳足價金者，再行拍賣。但未中籤之投標人仍願按原定投標條件依法承買者，不在此限。
> **民法 §95 I**　非對話而為意思表示者，其意思表示，以通知**達到**相對人時，發生效力。但撤回之通知，**同時或先時**到達者，不在此限。
> **辦理強制執行事件應行注意事項 50**　（一）數宗不動產合併拍賣，投標人未記載每宗之價額或其記載每宗價額合計與其記載總價不符者，以其所載**總價額**為準；……投標人僅記載每宗之價額而漏記總價額者，執行法院得**代為合計**……（二）土地與建物合併拍賣，……總價額最高且達拍賣最低總價額，但土地或建物所出價額未達拍賣最低價額，而投標人不知自行調整者，執行法院得按總價額及拍賣最低價額**比例調整**之。
（注意事項 50 為摘要，原文請對六法）

## 📋 實務見解

> **代理投標**（實務見解，字號請對講義）：應買人得委任他人代理應買，但應**及時**提出證明書以證明合法授權；未提出者代理權有欠缺，投標無效，性質上不得準用定期命補正之規定——開標於利害關係對立之不特定多數人注視下公開進行，程序有**極端急切**之必要。

> **廢標之救濟**（決議，字號請對講義）：應買人之投標經執行法院認為廢標，得於強制執行程序終結前聲明異議；應買人所投之標經決定其得標後，又經認為廢標者，得另提起**確認買賣成立之訴**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產得否以投標方式拍賣？」 | **不得**，投標只有不動產 |
| 「投標未附保證金，開標後補繳？」 | **不得**，投標**無效**（§89） |
| 「標匭尚未封、時間未到，應買人請求撤回投標？」 | **不生撤回效力**——投入即到達生效（民法 §95） |
| 「最高出價相同，直接抽籤？」 | **錯**。先**當場加價**，無人加價才抽籤（§90 I） |
| 「代理人投標未當場提出委任書，得命補正？」 | **不得**，投標無效 |
| 「合併拍賣，每宗合計與總價不符？」 | 以**總價**為準 |
| 「只寫每宗價額、漏寫總價？」 | 執行法院**代為合計** |
| 「總價最高但房屋出價未達房屋底價？」 | 執行法院得**比例調整**，仍可得標 |
| 「被認為廢標，如何救濟？」 | §12 聲明異議；**曾宣告得標**後才廢標 → 另得提確認買賣成立之訴 |

## 一、口頭競價 vs 投標

| | 口頭競價 | 投標 |
|---|---|---|
| 適用 | 動產、不動產 | **只有不動產** |
| 方式 | 公開喊價 | 書面、秘密，當眾開標 |
| 出價相同 | 不會發生 | 會發生 → §90 |
| 拘束力 | 有人出更高價即喪失 | 開標決定得標人後確定 |

## 二、合併拍賣四名投標人例題（底價：土地 500＋房屋 400＝900）

| 投標人 | 瑕疵 | 處理（注意事項 50） | 認定總價 |
|---|---|---|---|
| 甲 | 600＋450，總價誤寫 1,150 | 以**總價**為準 | 1,150 |
| 乙 | 只寫分別出價，漏寫總價 | **代為合計** | 1,100 |
| 丙 | 只寫總價，未寫每宗 | 以**總價**為準 | 1,100 |
| 丁 | 房屋只出 200，未達房屋底價 | **比例調整** | 老師結論：丁總價最高，得標（丁土地出價字幕未唸，請對講義） |

- 共同邏輯：最後比的都是**總價**——賣得越高，對債權人、債務人都有利。

## 三、廢標救濟

```
投標被認為廢標
├─ 從未宣告得標 → §12 聲明異議（應買人也是利害關係人）
└─ 已宣告得標（＝拍定、買賣成立）後又被廢標 → 另得提確認買賣成立之訴
```
