# 強制執行法05 筆記：**準債務人**（§25 II，講義 190 頁）——不是欠錢的人，但債務人之拘提、管收、限制住居、報告及其他應負義務之規定對其**亦適用**：①債務人為無行為能力或限制行為能力人 → **法定代理人** ②債務人失蹤 → **財產管理人** ③債務人死亡 → **繼承人、遺產管理人、遺囑執行人或特別代理人** ④法人或非法人團體 → **負責人**；獨資商號 → **經理人**（都是管理人、代理人、負責人）；**§25 III**：前項之人於**喪失資格或解任前**已具有報告義務或拘提管收限制住居之原因者，喪失資格或解任**後**，於執行必要範圍內**仍得**命其履行義務或予以拘提、管收、限制住居。**具保證書人**（§23，講義 191 頁）：債務人依法應供之擔保，執行法院得許由**該管區域內有資產之人**具保證書代之（如台中執行 → 找台中市內有資產者）；保證書**載明**債務人逃亡或不履行義務時由其負責清償或賠償一定金額者（99.9% 都會寫）→ 執行法院得因債權人聲請**逕向具保證書人為強制執行**（老師：任何情況都不要當保人）

> 來源：強制執行法05 課程字幕 01:15:00 ~ 01:18:30（講義 190～191 頁）

## 📖 法條原文速查

> **強執 §25 II**　關於債務人拘提、管收、限制住居、報告及其他應負義務之規定，於下列各款之人亦適用之：一、債務人為無行為能力人或限制行為能力人者，其法定代理人。二、債務人失蹤者，其財產管理人。三、債務人死亡者，其繼承人、遺產管理人、遺囑執行人或特別代理人。四、法人或非法人團體之負責人、獨資商號之經理人。
> **強執 §25 III**　前項各款之人，於喪失資格或解任前，具有報告及其他應負義務或拘提、管收、限制住居之原因者，在喪失資格或解任後，於執行必要範圍內，仍得命其履行義務或予以拘提、管收、限制住居。
> **強執 §23 I**　債務人依本法應供擔保者，執行法院得許由該管區域內有資產之人具保證書代之。
> **強執 §23 II**　前項具保證書人，如於保證書載明債務人逃亡或不履行義務時，由其負責清償或賠償一定之金額者，執行法院得因債權人之聲請，逕向具保證書人為強制執行。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人為未成年人，得否對其法定代理人拘提管收？」 | **得**。§25 II ① 準債務人：法定代理人適用債務人之拘提、管收、限制住居、報告義務規定 |
| 「準債務人有哪些？」 | 法定代理人／財產管理人／繼承人、遺產管理人、遺囑執行人、特別代理人／法人與非法人團體之負責人、獨資商號之經理人 |
| 「公司負責人已解任，得否再對其管收？」 | 於**解任前**已具管收原因者，解任後於執行必要範圍內**仍得**（§25 III） |
| 「具保證書人之資格？」 | **該管區域內有資產之人**；以保證書代替債務人應供之擔保 |
| 「對具保證書人得否直接執行？」 | 保證書**載明**債務人逃亡或不履行時由其負責清償或賠償一定金額者 → 執行法院得因債權人聲請**逕向具保證書人強制執行**（§23 II），不必另取執行名義 |

## 一、準債務人表

| 債務人狀態 | 準債務人 |
|---|---|
| 無行為能力／限制行為能力 | 法定代理人 |
| 失蹤 | 財產管理人 |
| 死亡 | 繼承人、遺產管理人、遺囑執行人、特別代理人 |
| 法人、非法人團體 | 負責人 |
| 獨資商號 | 經理人 |

- §25 III：資格喪失或解任**前**已有原因 → 之後仍得處分（「已經不當了還是可以被抓」）。

## 二、具保證書人

```
債務人應供擔保 → 執行法院得許由「該管區域內有資產之人」具保證書代之（§23 I）
保證書載明「債務人逃亡或不履行由其負責清償／賠償一定金額」
→ 債權人聲請 → 執行法院逕向具保證書人強制執行（§23 II）
```
