# 強制執行法05 筆記：違建執行選擇題（複習講義 160 頁，考的是 §15 原告適格）——甲持假扣押裁定及付款確定判決，查封乙占用之未辦保存登記 A 屋：**A** 丙出資興建（形式所有人）、未出售 → 丙**得**提 §15 ✓；**B** 丙出資興建並**出售於乙**（執行債務人）→ 丙**不得**（50 台上 1236：賣掉拿錢了，只剩形式所有權空殼，對買受人之債權人有忍受義務）→ **錯誤選項、本題答案**；**C** 丙出資興建並出售於**丁**（第三人）→ 丁無所有權（違建不能移轉所有權，只取得事實上處分權）不能直接提，實務讓丁**代位**丙提 §15（48 台上 209）✓；**D** 丙售予乙、乙再售予丁 → 丁**不得**代位丙，因**丙丁間無債權債務關係**（代位權以債權存在為前提，民法 §242）→ 考的是民法不是執行法 ✓；提醒：題目表面考執行法、實際考民法或民訴的情形不少，先把違建前提拿掉想一遍，再加回去

## 📖 法條原文速查

> **民法 §242**　債務人怠於行使其權利時，債權人因保全債權，得以自己之名義，行使其權利。但專屬於債務人本身者，不在此限。
> **強執 §15**　第三人就執行標的物有足以排除強制執行之權利者……

---

## 📋 實務見解速查

> **50 年台上字第 1236 號**：違建原始建築人已將建築物出賣，負有交付之義務；買受人之債權人將之查封，原建築人負有忍受之義務，不得提第三人異議之訴。
> **48 年台上字第 209 號**：違建真正買受人因不能登記不能主張所有權提第三人異議之訴，但得**代位**原所有人提起。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「違建原始建築人丙（未出售），債務人乙占用被執行，丙得否提 §15？」 | **得**。丙有所有權（違建出資興建者原始取得），乙未取得所有權 |
| 「丙出售於執行債務人乙？」 | **不得**（50 台上 1236）。丙只剩形式上所有權，錢已拿、負交付義務，對乙之債權人有忍受義務 |
| 「丙出售於第三人丁，執行乙占用之 A 屋（錯誤執行）？」 | 丁只有事實上處分權、無所有權 → 不能直接提；實務讓丁**代位丙**提 §15（48 台上 209）。丁花錢買的（天龍國違建上千萬）需要救濟 |
| 「丙售予乙、乙再售予丁，丁得否代位丙？」 | **不得**。代位須有債權債務關係（民法 §242），丙丁間沒有（丁的債權是對乙）。這是民法問題 |
| 「解題技巧？」 | 先把「違建」拿掉：一般已登記不動產，所有權人非債務人被執行 → 當然 §15；再加回違建：買受人無所有權 → 想辦法（代位）讓他救濟 |

## 一、四個選項一張圖

```
A  丙（出資興建、未售）─── 乙占用 ←執行   丙 §15 ✓
B  丙 ─售→ 乙（債務人）←執行            丙 ✗（50 台上 1236）→ 答案
C  丙 ─售→ 丁；乙占用 ←執行（錯誤執行）  丁代位丙 ✓（48 台上 209）
D  丙 ─售→ 乙 ─售→ 丁                    丁不得代位丙（丙丁無債權關係）✓
```

## 二、違建三句話

- 出資興建者原始取得所有權；不能辦保存登記；不能以法律行為移轉所有權，交易移轉的是**事實上處分權**。
- 有財產價值，可作執行標的。
- §15 須有所有權、典權、留置權、質權等物權地位 → 違建買受人沒有 → 代位。
