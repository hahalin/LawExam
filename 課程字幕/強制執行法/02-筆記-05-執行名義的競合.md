# 強制執行法02 筆記：執行名義的競合

## 什麼是競合：
- **同一**金錢債權，有**複數**執行名義
- 例：先有公證書（§4 I ④），又取得給付判決（§4 I ①）；銀行手上常同時有借款契約、本票、抵押 → 本票裁定、拍賣抵押物裁定

## 效力：
- 採**第二說**：新舊執行名義**均有效**，都可以拿來聲請強制執行
- 但給付請求權是**同一個**：一筆債只能還一次

## 重複執行怎麼辦：
- 債權人以其中一個執行名義受償後，又拿另一個執行同一筆錢 → **程序上沒有瑕疵**（有執行名義）
- 背後請求權已因清償**消滅** → 實體瑕疵 → 債務人提**債務人異議之訴**（§14）排除強制執行
- 這是**分離原則**的展現：執行處只看執行名義，不審背後債權

## 📖 法條原文速查

> **強執 §4 I ①④**　一、確定之終局判決。……四、依公證法規定得為強制執行之公證書。
> **強執 §14 I**　執行名義成立後，如有**消滅或妨礙債權人請求之事由**發生，債務人得於強制執行程序終結前，向執行法院對債權人提起**異議之訴**。如以裁判為執行名義時，其為異議原因之事實發生在前訴訟言詞辯論終結後者，亦得主張之。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「同一金錢債權先有公證書、後有給付判決，各執行名義效力？」 | **新舊均有效**（第二說） |
| 「債權人以公證書受償後，再以判決聲請執行同一債權，執行處應駁回？」 | **否**，程序上合法；請求權消滅屬**實體**問題 |
| 「上述情形債務人如何救濟？」 | **債務人異議之訴**（§14），實體瑕疵救濟 |
| 「執行處審查時看執行名義還是看背後債權？」 | 看**執行名義**（形式審查、分離原則） |

## 一、圖解

```
            同一筆借款 100 萬
         ┌──────┴──────┐
   執行名義一          執行名義二
   公證書 §4 I ④      給付判決 §4 I ①
         │                  │
         ▼                  │
   執行受償 100 萬           │
   → 實體請求權因清償消滅     │
                            ▼
                  又以判決聲請執行
                  程序：有執行名義 → 合法，執行處照收
                  實體：請求權已消滅 → 債務人 §14 異議之訴
```

## 二、程序 vs 實體

| | 程序面 | 實體面 |
|---|---|---|
| 重複執行 | 有執行名義，無瑕疵 | 債已清償，請求權消滅 |
| 誰處理 | 執行處（只做形式審查） | 民事庭 |
| 救濟 | —— | §14 債務人異議之訴 |

- 老師：同學會擔心債務人沒保障，實務上執行處會跟債權人溝通，不要做這種事。

## 三、實務常見的競合來源

```
銀行放款 1,000 萬（同一筆債權債務）
├── 借款契約 → 起訴取得給付判決            §4 I ①
├── 要求簽本票 → 本票裁定                  §4 I ⑥
└── 設定抵押權 → 許可拍賣抵押物裁定        §4 I ⑤
→ 手上可能有 2～3 個執行名義，全部有效；但總共只能受償一次
```

## 四、同一邏輯：執行名義背後的請求權出問題，都走實體救濟

| 情形 | 執行處 | 債務人救濟 |
|---|---|---|
| 以另一執行名義重複執行已清償債權 | 照常執行 | §14 |
| 解除條件成就（筆記 06） | 執行名義不失效 | §14 |
| 請求權罹於時效（筆記 07） | 照常執行 | §14 |
