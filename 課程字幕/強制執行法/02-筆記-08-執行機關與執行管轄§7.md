# 強制執行法02 筆記：執行機關與執行管轄（§7）

## 執行機關：
- **民事執行處**；條文、題目寫「執行法院」原則指執行處（例外指民事庭，遇到再講）
- 原則由**司法事務官**辦理，命書記官督同執達員實施；**拘提、管收**涉人身自由 → **法官保留**
- 執行處對實體爭執（如條件是否成就）**無審究之權**，只做形式審查（102 年裁定）
- 職務確保：比例原則（§1 II）、遇抗拒得用強制力但不得逾必要程度（§3-1）；請警察、移民機關等協助；登記機關（地政）辦查封登記（§11 I）

## 管轄（§7，與民訴分開）：
- 民訴之**合意管轄不及於**強制執行
- I 標的物所在地或執行行為地 → II 不明時才到債務人住居所、事務所、營業所
- **商標專用權** → 債務人住所地（公司看營業所）（考過）；**薪資** → 第三人（雇主公司）所在地
- III **選擇管轄**：數法院有管轄權 → 債權人擇一聲請；**不得**以同一執行名義同時繫屬多數法院
- IV 轄區外執行行為 → **囑託**他法院

## 管轄錯誤：
- 執行處先**查明**（甚至先代查財產，轄區內有財產就有管轄權），確無管轄才**裁定移送**（§30-1 準用民訴 §28 I）
- 無管轄權法院之執行行為**非當然無效**，屬程序瑕疵 → §12 聲明異議；程序終結後瑕疵治癒
- 移送裁定送達債務人：**實際為執行行為之同時或之後**（避免打草驚蛇）

## 📖 法條原文速查

> **強執 §7**　I 強制執行由應執行之**標的物所在地**或應為**執行行為地**之法院管轄。II 應執行之標的物所在地或應為執行行為地**不明**者，由**債務人**之住、居所、公務所、事務所、營業所所在地之法院管轄。III 同一強制執行，數法院有管轄權者，債權人得向其中**一**法院聲請。IV 受理強制執行事件之法院，須在他法院管轄區內為執行行為時，應**囑託**該他法院為之。
> **強執 §1 II**　強制執行應依公平合理之原則，兼顧債權人、債務人及其他利害關係人權益，以適當之方法為之，**不得逾達成執行目的之必要限度**。
> **強執 §3-1 I**　執行人員於執行職務時，遇有抗拒者，得用強制力實施之。但不得逾必要之程度。（原文請對六法）
> **強執 §11 I**　供強制執行之財產權，其取得、設定、喪失或變更，依法應登記者，為強制執行時，執行法院應即通知該管登記機關登記其事由。
> **強執 §30-1**　強制執行程序，除本法有規定外，準用民事訴訟法之規定。
> **民訴 §28 I**　訴訟之全部或一部，法院認為無管轄權者，依原告聲請或依職權以**裁定移送**於其管轄法院。

## 📋 實務見解速查

> **102 年裁定**（字號請對講義）：公證書附有條件者雖得為執行名義，債權人聲請時應就條件成就提出證明文件；當事人對條件成就與否有爭執時，執行法院對此**實體問題無審究之權**，應由債權人另行起訴取得執行名義。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「民事訴訟之合意管轄效力及於強制執行？」 | **不及於** |
| 「執行商標專用權之管轄法院？」 | **債務人住所地**（公司：營業所所在地） |
| 「執行債務人對第三人之薪資債權，債務人住高雄、公司在臺南？」 | **臺南**（第三人所在地為標的物所在地） |
| 「債務人財產分散數地，債權人得同時向各地法院聲請？」 | **不得**；擇一聲請（§7 III），他地**囑託**（§7 IV） |
| 「無管轄權法院所為執行行為之效力？」 | **非當然無效**，程序瑕疵 → §12；程序終結後治癒 |
| 「執行法院發現無管轄權，應裁定駁回？」 | **否**，**裁定移送**（§30-1 準用民訴 §28 I） |
| 「金錢債權執行之移送裁定何時送達債務人？」 | **實際為執行行為同時或之後** |
| 「拘提、管收得由司法事務官為之？」 | **不得**，法官保留 |

## 一、管轄判斷流程

```
要執行什麼？
├── 有體物（土地、車）→ 標的物所在地（§7 I）
├── 行為（演唱會在高雄）→ 執行行為地（§7 I）
├── 薪資債權 → 第三人（雇主公司登記地）所在地
├── 商標等抽象權利 → 債務人住所地（公司：營業所）
└── 上述不明 → 債務人住居所、公務所、事務所、營業所（§7 II）
數地都有 → 擇一（§7 III）＋轄區外囑託（§7 IV）
```

## 二、囑託執行 vs 移送管轄

| | 囑託他法院執行 | 移送他法院管轄 |
|---|---|---|
| 前提 | 本院**有**管轄（選擇管轄） | 本院**無**管轄（管轄錯誤） |
| 依據 | §7 IV | §30-1 準用民訴 §28 I |
| 案件歸屬 | 仍由本院主辦，只委託轄區外行為 | 整件移出 |

## 三、練習

```
(1) 丙持 200 萬確定支付命令執行丁，丁僅 C 車停在高雄，丙向臺中聲請
    → 臺中無管轄權 → 裁定移送高雄地院民事執行處

(2) 甲對乙 500 萬確定判決，乙有基隆、高雄土地各一筆
    → 兩地皆有管轄（§7 I），擇一聲請（§7 III）
    → 選基隆：高雄土地囑託高雄執行處查封拍賣（§7 IV）

(3) 講義 64 頁：甲向臺北地院聲請查封拍賣乙公司商標專用權，乙公司登記於臺中
    → 應由臺中管轄；臺北拍定移轉後，乙主張當然無效 → 錯
    → 非當然無效，程序瑕疵，§12 聲明異議 → 裁定移送
```

## 四、為何不能同時多處聲請

- 統一權責、避免重複執行；同時多案易造成**超額查封**，使債務人承受超過義務的負擔。
