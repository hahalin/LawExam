1§15 適用於所有執行（含假扣押），執行處查封錯人時還可以同時聲明異議

甲聲請假扣押乙的財產，執行處沒看謄本，把登記在丙名下的 A 地也查封了。丙很火。

假扣押執行中丙能提 §15 嗎？除了 §15 還能做什麼？要去哪個法院？

§15 適用範圍：所有財產執行，含保全執行（任何執行都可能執行到非債務人的財產）
對照 §14：不適用保全執行（假扣押必有本案訴訟，實體爭執去本案解決）
執行處違背責任財產外觀認定原則（不動產看登記、動產看占有）
程序瑕疵 → §12 聲明異議（執行處）
並行
實體瑕疵 → §15 第三人異議之訴（民事庭）
規則

§15 骨架：原告第三人；被告債權人（債務人亦否認其權利時並列為共同被告）；向執行處所屬法院之民事庭起訴——條文寫「執行法院」，在 §14、§15 都指民事庭，是民訴 §1 以原就被的例外，執行在台中地院就在台中地院民事庭告，不用另找管轄。

不動產違反外觀認定較少（謄本很清楚），動產（債務人沒占有卻被執行）較常見。

陷阱

選擇題常問「得否並行」——可以，甚至同時：在執行處聲明異議，又去隔壁民事庭起訴。

2§15 要在「那個標的物」執行完之前告；拍定後只能要價金，不能撤銷拍賣

執行乙的 A 地和 B 車。A 地已拍定給小明、價金還沒分；B 車還在查封中。丙說 A 地是他的。

丙現在提 §15 來得及嗎？來得及的話能拿回 A 地嗎？

規則

院 2776：執行標的物經拍賣終結而未將賣得價金交付債權人時，該標的物之執行程序尚未終結，第三人仍得提 §15；但已終結之拍賣不能撤銷 → 僅得請求交付賣得價金，不得請求撤銷拍賣程序。保護拍定人：動產善意受讓、不動產土地法 §43 登記絕對效力，第三人已喪失所有權。

個別程序終結後 → 不能提 §15（形成之訴沒有排除對象了）→ 另訴（§179、§184、國賠）。

訴訟標的價額：債權額與標的物價值取低者（91 年第 5 次決議）。有理由判決：不許對該特定財產執行（§14 是全面否定執行名義）；判決不當然使執行處分失效，原告要把判決正本提出於執行法院，執行處才會撤銷執行處分——民事庭和執行處是兩個單位。

陷阱

「個別終結前」考過 N＋1 次。這題 A 地的 deadline 是 A 地做完，跟 B 車無關。拍定後能提不代表能拿回土地。

3違建四選項：賣掉就不能告，買的人要代位，代位要有債權關係

甲執行乙占用的未辦保存登記 A 屋。四種情況：丙蓋的沒賣；丙賣給乙；丙賣給丁；丙賣給乙、乙再賣給丁。

哪一個選項是錯的？

  • A　丙出資興建、未出售 → 丙是所有權人，乙未取得所有權 → 丙得提 §15 ✓
  • B　丙出售於乙（債務人） → 丙不得（50 台上 1236：錢拿了、只剩形式所有權空殼，對乙的債權人有忍受義務）→ 選項說「得」→ 錯，答案 B
  • C　丙出售於丁（第三人），執行乙占用的 A 屋＝錯誤執行 → 丁無所有權（違建只能移轉事實上處分權）不能直接提 → 代位丙提 §15（48 台上 209）✓
  • D　丙→乙→丁 → 丁不得代位丙：丙丁間無債權債務關係（民法 §242 代位以債權為前提）→ 這是民法題 ✓
規則

解法：先把「違建」拿掉——一般已登記不動產，非債務人的所有權人被執行當然 §15；再加回違建：買受人沒有所有權，實務想辦法讓他救濟 → 代位。

陷阱

表面考執行法、實際考民法（代位權）或民訴的題目不少。D 選項的關鍵不在違建，在「丙丁之間有沒有債權」。

4申論題：拍賣抵押物裁定不畫圖，改成確定判決就要畫圖——時效在起訴前完成會被遮斷

甲把爸爸丙送的台南土地設定最高限額抵押給乙、簽本票，到期 90/6/1 沒還。乙拿拍賣抵押物裁定執行。甲說債權罹於時效；丙說兒子不孝、我已撤銷贈與。第二小題把執行名義改成本票債權的確定判決，乙是 93/7/1 才起訴的。

甲、丙各怎麼救濟？第二小題甲還能告嗎？

執行三要素：乙→甲／§4 I ⑤ 拍賣抵押物裁定（對物，只能執行該地）／台南土地
甲：時效＝實體
§14 ＋ §18 II；裁定無既判力 → 不畫圖
另有：對裁定抗告；釋字 182 確認抵押權不存在之訴（亦得停止執行）
丙：撤銷贈與、地是我的
§15 ＋ §18 II
第二小題：確定判決（§4 I ①）→ 有既判力 → 畫圖
本票對發票人時效 3 年：90/6/1 → 93/6/1 完成；乙 93/7/1 起訴 → 時效在基準時前完成、甲本案未抗辯 → 遮斷 → 不得 §14，另訴
規則

要畫基準時圖的只有三種執行名義：確定判決、訴訟上和解、訴訟上調解。拍賣抵押物裁定、支付命令、本票裁定都不畫。

講義 152 頁概念解析：時效以完成時為異議事由發生時點，完成在基準時前又沒抗辯 → 被遮斷，不能把時效抗辯「憋到執行階段當大招」。對照：抵銷以行使時為準（上堂卡 6）。

陷阱

讀題先抓三要素，再把不同角色的主張切開（債務人→§14、第三人→§15）。原告被告、甲乙不要寫反，電腦作答打完整體檢查一次。

5§14-1：人找錯了——債務人用第一項，債權人被打槍用第二項，跟 §4-2 綁在一起

債務人死了，債權人對他兒子執行，兒子說「我早就拋棄繼承」。另一邊，資產管理公司買了銀行的債權去聲請執行，執行處說「你不是判決書上的債權人」裁定駁回。

兒子怎麼救濟？資產管理公司怎麼救濟？同名同姓被執行的人呢？

  • 三種實體瑕疵一蘿蔔一坑（講義 131 頁）
    • 執行名義瑕疵 → §14
    • 執行主體瑕疵（人找錯）→ §14-1，對應 §4-2（執行力主觀範圍＝民訴 §401 既判力主觀範圍）
      • I　原告債務人（拋棄繼承、否認債務承擔）→ 對債權人 → 民事庭 → 整個終結前 → 得 §18 II 停止執行
      • II　原告債權人（依 §4-2 聲請被裁定駁回：債權受讓人）→ 對債務人 → 民事庭 → 駁回裁定送達後 10 日不變期間 → 許可執行之訴，無停止問題
    • 執行客體瑕疵（財產執行錯）→ §15
    • 同名同姓躺著中槍＝同一性爭執 → 程序瑕疵 → §12 聲明異議，不是 §14-1
規則

懂 §4-2 就知道何時用 §14-1：繼承人、占有人（債務人的員工、保全、清潔人員都算，可施強制力）、為他人而為當事人之該他人、繼受人（債權讓與、債務承擔）都是執行力所及。不在 §4-2 範圍卻被執行 → §14-1 I；在範圍卻被執行處拒絕 → §14-1 II。

條文倒著規定：債務人在前（I）、債權人在後（II）。I 項廣義上還是債務人異議之訴，時點跟 §14 一起記＝整個終結前。

陷阱

停止執行是向民事庭聲請、拿裁定到執行處；執行處自己不能決定停止。「要告都去隔壁」。

6支付命令題：從未欠款走 §14（＋民訴 §521 III）；沒收到支付命令 → 它根本不是執行名義

甲持 A 法院核發、已附確定證明書的支付命令，執行乙的動產和土地。乙說一：我從來沒欠你錢。乙說二：我根本沒收到支付命令。

兩種主張各用什麼救濟？執行處要不要審查支付命令有沒有合法送達？

支付命令＋確定證明書＝§4 I ② 執行名義（民訴 §521：104 年後只有執行力、無既判力）
「從未欠款」＝實體
§14 債務人異議之訴（無既判力不畫圖）
＋民訴 §521 III 確認債權不存在之訴（亦得停止執行）
「沒收到」→ 支付命令不得公示送達、不得於國外送達；未合法送達 → 20 日異議期間不起算、三個月內未送達即失效
未確定 → 不是執行名義 → 執行法院應審查（81 台抗 114：執行名義是否成立，執行法院得審查，不受確定證明書拘束）
規則

邏輯鏈：沒合法送達 → 不會確定 → 不是執行名義 → 執行處不能發動。執行名義是執行處「最重要的文件」，成立要件執行處有獨立審查權。

支付命令條號（民訴 §515、§516、§521）等民訴上到再回看；老師說這種題考出來是送分題。

陷阱

81 台抗 114 上堂（卡 2）出現過，這堂又考一次——「號碼可以不記，內容一定要會」。

7強制處分：拘提三事由、管收五事由；管收不是抵債，是逼有錢人把錢吐出來

債務人明明有錢卻裝窮，叫他報告財產他不報、調查不動產他亂講。另一位是演唱會歌手，判決命他履行卻一直不唱。

執行處能把人關起來嗎？關了可以抵債嗎？要誰簽字？

拘提（強制到場）

①合法通知無正當理由不到場 ②有事實足認顯有逃匿之虞 ③違反限制住居命令
①②另須有必要性

管收（類似羈押）五事由

①命報告財產狀況而不報告或虛偽報告 ②顯有履行可能而故不履行 ③就應執行之財產有隱匿、處分之情事 ④不動產現況調查無正當理由拒絕陳述或虛偽陳述 ⑤不可代替行為、不作為義務（§128、§129：處怠金或管收）

限制住居

事由＝管收②③（故不履行、隱匿處分財產）
規則

程序：都是人身自由限制 → 法官保留（事務官要報請法院）＋令狀主義（拘票、管收票，法官簽名）→ 執達員執行；未規定者準用刑訴。

管收期間不得逾 3 個月；有新管收原因得再行管收，以一次為限。不得管收／停止管收：一家生計難以維持、懷胎五月以上或生產後二月未滿、罹病恐因管收不能治療。釋放：原因消滅、提供擔保、期限屆滿、執行完畢。

§25 I：債務人履行債務之義務不因被管收而免除——管收不能抵債。前四個事由背後都是「你有錢但藏起來／不配合」，所以被管收的通常不是窮人；新聞上多半是行政執行（欠稅大老闆），「關一個禮拜家人就拿錢來救」。

陷阱

選擇題幾乎沒考過強制處分，申論、執達員考試會考（112 年執達員：拘提要件）。至少記第⑤個：不可代替行為 → 怠金或管收。流程圖在講義 395 頁。

8準債務人與具保證書人：沒欠錢也可能被拘提管收，當保人會被直接執行

債務人是未成年人，執行處要管收他的法定代理人。另一位朋友幫債務人出具保證書代替供擔保，保證書上寫「債務人不履行時由我負責」。

法定代理人沒欠錢，可以對他拘提管收嗎？保證人會怎樣？

  • §25 II 準債務人：關於債務人拘提、管收、限制住居、報告及其他應負義務之規定，於下列之人亦適用
    • ① 債務人為無行為能力或限制行為能力人 → 法定代理人
    • ② 債務人失蹤 → 財產管理人
    • ③ 債務人死亡 → 繼承人、遺產管理人、遺囑執行人、特別代理人
    • ④ 法人或非法人團體 → 負責人；獨資商號 → 經理人
    • §25 III：喪失資格或解任前有事由者，解任後於執行必要範圍內仍得命其履行或拘提管收限制住居
  • §23 具保證書人
    • I 債務人應供之擔保，執行法院得許由該管區域內有資產之人具保證書代之
    • II 保證書載明債務人逃亡或不履行時由其負責清償或賠償一定金額者 → 執行法院得因債權人聲請逕向具保證書人強制執行
規則

準債務人都是「管理人、代理人、負責人」這類替債務人掌握財產的人，所以債務人的義務（報告財產、到場、受管收）他們也要負。

陷阱

99.9% 的保證書都會寫「債務人不履行由我負責」，所以當保人等於直接變成被執行人。「任何情況都不要去當保人。」

9參與分配入門：錢都變現金之後怎麼分——§31 分配表、§32 三個時間點、要有執行名義

甲一聲請執行乙的財產。甲二、甲三看到了也想分一杯羹。甲二只有一張借據和 LINE 對話；甲三拿著一個還沒到期的將來給付勝訴判決。

甲二、甲三能來參與分配嗎？要用什麼方式、什麼時候前來？

  • 金錢債權執行：查封 → 換價 → 滿足。第 2～6 節依財產種類只規定查封換價；滿足統一規定在第 1 節參與分配（都變錢了沒差別）；只有金錢債權才有分配問題
  • §31 多數債權人 → 執行法院作成分配表（次序：稅捐 → 執行費 → 實行抵押費用 → 抵押權等優先 → 普通債權；講義 399 頁）、指定分配期日（匯款）、期日 5 日前繕本交付並任其閱覽
  • 參與分配五要件
    • ①金錢債權 ②終局執行 ③同一債務人
    • ④債權已屆清償期：§4 II 將來給付判決期限未屆至不得聲請執行，也不得據以參與分配 → 甲三 ✗
    • ⑤有執行名義（§34 I）：借據、合約、LINE 都不行 → 甲二 ✗（例外：抵押權人，卡 10）
  • §32 I 三個時間點（＝基準時）：拍賣變賣終結、交債權人承受、不經拍賣者分配表作成，各「之日一日前」，以書狀聲明（口頭 ✗）
  • §32 II 逾基準時 → 僅得就前項債權人受償餘額受清償（群團二）；就債務人其他財產執行時按債權額比例平均受償
規則

基準時 ≠ 最晚時點：逾基準時還是能參與分配（只是列群團二、分剩的）；真正的最晚是整個執行程序終結前——已分配完的部分不重來，只能分還沒分完的。

程序：書狀、證明文件、執行費千分之八（§28-2 II，參與分配不打折）。

陷阱

「平均受償」是按債權額比例，不是除以人數。「口頭聲明參與分配」考過，錯。

10抵押權人是天選之人：不用執行名義、不管到期沒、不來也強制列入——因為抵押權會被塗銷

執行處要拍乙的房子，調謄本發現銀行有第一順位抵押，貸款要到 130 年才到期。銀行說「我不想來」。

銀行沒有執行名義、債權沒到期、人不想來，執行處怎麼處理？為什麼？

§98 III 塗銷主義：不動產上抵押權及其他優先受償權因拍賣而消滅（拍定人買到乾淨的房子）
抵押權要被塗銷 → 怎麼保護抵押權人？
把他抓進來先分錢＝強制列入參與分配（§34 II、III）
§34 II：不須執行名義，提出權利證明文件即可；不問債權是否屆清償期
§34 III：知有抵押權人應通知（不知住所則公告）；經通知未聲明 → 執行法院就已知債權及金額列入分配；執行費從執行所得扣繳
§34 IV：不聲明又金額非法院所知 → 優先受償權因拍賣消滅；已列入而未受償部分亦同
§34 V 通知各債權人及債務人；§34-1 政府機關公法上金錢債權（欠稅、健保費、罰單）得檢附證明參與分配，依特別法定優先次序
規則

一般債權人要先去拿到確定判決、確定支付命令、本票裁定之類的執行名義才能來分錢；抵押權人（講義：擔保物權或優先受償權人，含質權、留置權、船舶優先權）連拍賣抵押物裁定都不用拿。

原因只有一個：§98 III 抵押權會因拍賣而消滅。既然要塗銷，就一定要讓他先分到錢。

陷阱

選擇題「99.9% 考抵押權人」。不用執行名義 ≠ 什麼都不用：還是要提出權利證明文件（設定抵押的文件）。

11分錢的次序：找基準時（拍定日前一天）、分群團、同群團按比例；每個財產重新分一次

甲一（債權 100 萬）3/1 聲請執行；甲二（300 萬）3/2、甲三（100 萬）3/11 聲明參與分配。A 車 3/10 拍定得 200 萬，B 車 4/1 拍定得 120 萬。

A 車的 200 萬誰先拿？B 車呢？

A 車（基準時 3/9）

甲一 50 萬（餘 50）／甲二 150 萬（餘 150）／甲三 0（餘 100）

B 車（基準時 3/31，重新認定）

三人都在 3/31 前 → 全是群團一 → 按餘額比例 50：150：100＝1：3：2 → 20、60、40 萬（餘 30、90、60）
規則

立法例：平等主義（不分先後按比例）vs 優先主義（早起的鳥兒有蟲吃）；我國採折衷主義（群團優先）：基準時前加入＝群團一，優先於群團二；同群團內按債權額比例。

三個基準時（§32 I）：①拍賣或變賣終結之日前一日＝拍定日前一天（九成題目用這個；當天太忙所以往前一天）②依法交債權人承受之日前一日（賣不掉以底價作價抵債）③不經拍賣變賣者，分配表作成之日前一日。

拍賣終結（槌子敲下、買賣契約成立）≠ 拍賣程序終結（拍定人繳足價金取得所有權、換價階段整個結束）。基準時用前者；§15 個別程序終結（卡 2）看後者。

群團零：抵押權人等優先受償權人實體法上本來就優先，不受基準時影響，姍姍來遲也排最前面。

陷阱

基準時跟著標的物，每個財產認定一次 → 群團會重組：A 車的群團二到 B 車可能變群團一。第二輪用受償餘額算比例，所以第一輪要把每個人剩多少算出來。

12參與分配 vs 併案執行：查封只查一次，先程序停了後程序照跑；行政執行也是後案併前案

甲執行乙的房屋（A 事件），第三人丙提 §15 並供擔保，法院裁定停止執行。停止期間丁也來聲請執行同一房屋（B 事件），併入 A。丁說：我要繼續執行。

執行處要不要再查封一次？丁能續行嗎？

§33 立法意旨：禁止雙重查封——已實施執行行為之效力於聲請時及於後聲請之他債權人 → 合併程序、依 §31、§32 分配（後案併前案，§56）
後執行程序於聲請時生潛在查封效力
先程序撤回或撤銷 → 潛在效力顯現（甲一撤回不能啟封，甲二還在）
座談會：丁得續行——後執行程序獨立、與先執行債權人地位相同；停止裁定效力僅及於兩造（丙、甲）與 A 事件，不及於丁；丁的執行名義是什麼都一樣
行政執行競合 §33-1、§33-2：行政先查封 → 民事卷宗函送行政執行機關合併；民事先查封 → 行政函送執行法院；先者不續行時卷宗送回後者續行

§32 參與分配

附隨於執行債權人之程序（理論上失所附麗）；優先受償權人不須執行名義（但不能單獨聲請執行）；書狀寫「聲明參與分配」

§33 併案執行

獨立程序（本有單獨查封效力 → 潛在效力顯現）；聲請人一律須有執行名義；書狀寫「聲請強制執行」。執行費同、最後都做分配表分群團
規則

注意事項 §16 I：執行債權人撤回時，依 §34 I 聲明參與分配之他債權人得聲請繼續執行——補一個聲請就好，不必另案重來。所以參與分配跟併案執行實際上幾乎沒差。注意事項 §18 III：撤回時原執行處分對再聲請執行之他債權人繼續有效（§33 本有）。

陷阱

停止裁定「停的是裁定上寫的那兩造、那個事件」，不是整棟房子不能動。下堂從「國字五 分配程序」（分配表異議）開始。
