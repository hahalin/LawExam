# 強制執行法07 筆記：拍定後之點交與再行點交（§99）

## 點交是什麼：
- 執行法院以**公權力**解除債務人或第三人占有，使買受人或承受人取得**現實占有**
- §99 是**拍定後**點交給**拍定人／承受人**；之後講的不動產物之交付執行（§124）才是點交給債權人
- 性質：點交程序與拍賣程序**分離**、各自獨立；通說認為**點交命令也是執行名義**，本質上是不動產物之交付的執行

## 得點交的四種情形：
- ① 現為**債務人**占有（§99 I）
- ② **查封後**為第三人占有（§99 I）
- ③ 第三人對其在查封前**無權占有不爭執**（§99 II）
- ④ 占有為 §98 II **但書**情形——用益權或租賃**經執行法院除去**後拍賣（§99 II）

## 點交的相對人：
- 債務人採**廣義**：含一般繼受人、**占有輔助人**（家屬、受僱人）
- 例：債務人在自有房屋設公司自任負責人，職員都是家屬並住在屋內 → **可以點交**
- 租約訂於查封前、但**交付前**就被查封 → 承租人不得以查封前訂約為由阻止點交（注意事項，項次請對講義）
- 查封前已訂約**且已交付**的承租人 → 有權占有，**不點交**；拍賣公告會載明不點交原因、租期、租金

## 再行點交（§99 III、IV）：
- 點交後，**原占有人**「**復即**」占有 → 依聲請再解除其占有後點交
- 要件：同一原占有人＋時間接續（多短個案認定）
- **應徵執行費**；好處是拍定人不必另訴取得執行名義，維持執行效果、避免訟累

## 📖 法條原文速查

> **強執 §99**　I 債務人應交出之不動產，**現為債務人占有**或於**查封後為第三人占有**者，執行法院應解除其占有，點交於買受人或承受人；如有拒絕交出或其他情事時，得請**警察**協助。
> II 第三人對其在**查封前無權占有不爭執**或其占有為**前條第二項但書**之情形者，前項規定亦適用之。
> III 依前二項規定點交後，**原占有人復即占有**該不動產者，執行法院得依聲請再解除其占有後點交之。
> IV 前項執行程序，**應徵執行費**。
> **強執 §98 II**　前項不動產原有之地上權、永佃權、地役權、典權及租賃關係隨同移轉。但發生於設定抵押權之後，並對抵押權有影響，經執行法院**除去後拍賣**者，不在此限。
（條文原文請對六法）

## 📋 實務見解

> **債務人之占有輔助人**（實務見解，字號請對講義）：以對債務人個人之執行名義查封債務人所有房屋，查封前債務人在屋內設公司並自任法定代理人，職員均為家屬並居住屋內 → 拍賣後**仍得點交**；家屬為債務人之占有輔助人，與債務人占有無異。

> **注意事項**（項次請對講義）：出租人與承租人訂立租賃契約後，將租賃物**交付承租人占有前**，經執行法院查封者，承租人不得主張查封前訂立租約而阻止點交。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§99 點交的對象？」 | **買受人或承受人**（非債權人） |
| 「查封後借住之第三人，得點交？」 | **得**（查封後為第三人占有） |
| 「查封前借住，對無權占有不爭執？」 | **得**點交 |
| 「查封前已訂約並交付之承租人？」 | **不得**點交（有權占有，買賣不破租賃） |
| 「查封前訂約、查封後才搬入？」 | **得**點交，承租人不得以訂約在先阻止 |
| 「債務人家屬、員工占有，得點交？」 | **得**，占有輔助人屬廣義債務人 |
| 「點交後原占有人隔天又搬回，拍定人須另訴？」 | **不必**，聲請**再行點交**，但應徵執行費 |
| 「點交後由**另一人**占有，得再行點交？」 | **不得**，須「原占有人」 |

## 一、四種得點交情形

```
誰在占有？
├─ 債務人（含家屬、受僱人等占有輔助人）────────────── 點交 ①
└─ 第三人
   ├─ 查封後才占有 ──────────────────────────────── 點交 ②（查封效力 §51 II）
   └─ 查封前就占有
      ├─ 無權占有且不爭執 ──────────────────────── 點交 ③
      ├─ 用益權／租賃在抵押權後成立，經除去後拍賣 ── 點交 ④（§98 II 但書）
      └─ 有權占有（查封前租約已交付）──────────── 不點交，公告載明
```

## 二、再行點交要件

| 要件 | 內容 |
|---|---|
| 前提 | 已依 §99 I、II 點交 |
| 主體 | **原占有人** |
| 時間 | **復即**占有——時間接續、未隔太久 |
| 程序 | 拍定人聲請；**應徵執行費** |
| 好處 | 不必另訴取得執行名義 |

## 三、§99 點交 vs 不動產交付執行

| | §99 點交 | 不動產物之交付執行 |
|---|---|---|
| 程序來源 | 金錢債權執行的拍賣後 | 交付不動產的執行名義 |
| 點交給誰 | 拍定人、承受人 | 債權人 |
| 執行名義 | 點交命令（通說） | 原執行名義 |
