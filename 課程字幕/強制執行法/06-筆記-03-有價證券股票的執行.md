# 強制執行法06 筆記：有價證券（股票）的執行

## 二分法：
- **無實體發行**（證券戶、集保帳戶裡的股份）→ **其他財產權**執行（§117 準用 §115）：對券商發**扣押命令** → 轉入法院集保帳戶 → 集中市場賣出
- **有實體發行**（有一張股票）→ **動產**執行：查封**占有**股票 → 拍賣；轉讓要背書，所以要剝奪債務人對股票的占有

## 配套規定：
- 有價證券**不得**交債務人保管（§59 II）
- 須於期限內行使或保全權利 → 執行法院**代債務人**為之（§59-1）
- 認為適當時得不經拍賣，準用其他財產權規定（§60-1）
- 拍賣後執行法院得**代債務人背書**或變更名義（§68-1）

## 📖 法條原文速查

> **強執 §59 II**　查封物除**貴重物品及有價證券**外，經債權人同意或認為適當時，得使債務人保管之。
> **強執 §59-1**　查封之有價證券，須於其所定之期限內為權利之行使或保全行為者，執行法院應於期限之始期屆至時，**代債務人為該行為**。
> **強執 §60-1**　查封之有價證券，執行法院認為適當時，得**不經拍賣程序**，準用第一百十五條至第一百十七條之規定處理之。
> **強執 §68-1**　執行法院於有價證券拍賣後，得**代債務人為背書或變更名義**與買受人之必要行為，並載明其意旨。
> **強執 §115 I**　就債務人對於第三人之金錢債權為執行時，執行法院應發**扣押命令**禁止債務人收取或為其他處分，並禁止第三人向債務人清償。
> **強執 §117**　對於前三節及第一百十五條至前條所定以外之財產權執行時，準用第一百十五條至第一百十六條之規定……
（§115、§117 原文請對六法）

## 📋 實務見解速查

> **最高法院 112 年判決**（講義 218 頁，字號請對講義）：第三人公司已發行股份並**發行股票**，執行法院本應依**動產**執行方式查封占有系爭股票，再依動產執行拍賣換價（未拍定時作價交債權人承受）；誤依其他財產權程序執行，執行程序有瑕疵，**不生轉讓系爭股票之效力**，縱執行法院發執行命令，亦無從替代**背書轉讓**之方式。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「執行債務人證券戶內之 B 股票 10 萬股，如何為之？」 | 無實體發行 → **其他財產權**執行（§117 準用 §115）：對證券商發**扣押命令**（＝查封）→ 再函請轉入**法院集保帳戶** → 集中市場賣出 → 分配 |
| 「執行已發行**實體股票**之股份？」 | **動產**執行：執行人員**實施占有**股票（剝奪債務人占有，阻止其背書轉讓）→ 拍賣 |
| 「題目出現『未占有股票』？」 | 線索：有**股票**（那張紙）＝實體發行 → 用其他財產權程序**不妥適** |
| 「有價證券得否交債務人保管？」 | **原則不得**（§59 II 反面；變現太快風險高）。貴重物品亦同 |
| 「查封之有價證券須於期限內提示、中斷時效？」 | 執行法院**代債務人**為之（§59-1） |
| 「有價證券拍賣後，背書由誰為之？」 | 執行法院**代債務人**背書或變更名義（§68-1） |

## 一、判斷流程

```
要執行的是股份／股票
   ├─ 有發行實體股票？
   │    ├─ 有 → 動產執行：占有股票 → 拍賣（未拍定 → 作價交債權人承受）→ 代背書（§68-1）
   │    └─ 無（集保帳戶）→ 其他財產權：扣押命令給券商（凍結）→ 轉入法院集保帳戶 → 市場賣出
   └─ 結論錯用 → 程序瑕疵，不生轉讓效力（112 年判決）
```

## 二、112 年考題（司法事務官申論，講義 217 頁）

- 事實：甲持台中地院債權憑證（§27，得為執行名義），聲請執行債務人持有之丙公司股份 10 萬股；執行法院依 **§117 準用 §115 I** 以其他財產權辦理拍賣、**未占有股票**，未拍定後作價交債權人。
- 問：執行程序是否妥適？
- 答：「未占有股票」→ 丙公司已**發行股票** → 應依**動產**執行查封占有股票、拍賣；誤用其他財產權程序 → **不妥適**，不生股票轉讓效力，執行命令不能替代背書。
- 老師：申論題這樣問，通常答案就是有問題。
