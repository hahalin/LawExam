# 強制執行法05 筆記：各論導論＋參與分配 §31、§32——金錢債權執行三階段**查封→換價→滿足**；條文依財產種類設計（第 2～6 節：動產、不動產、船舶航空器、其他財產權、公法人財產，只規定**查封與換價**），**滿足階段統一規定在第 1 節「參與分配」**（變成錢之後沒有差別）；只有**金錢債權**執行才有分配問題（物之交付、行為不行為無）。**§31**：多數債權人參與分配時，執行法院作成**分配表**（講義 399 頁；次序：土增稅等稅捐 → 執行費用 → 實行抵押費用 → 抵押權等優先債權 → 普通債權）、指定**分配期日**（以匯款為之），分配期日 **5 日前**以繕本交付債務人及各債權人並置於執行處任其閱覽（分配表只是方案，兩造得表示意見 → 分配表異議，下堂）。**§32 I**：他債權人參與分配，應於①標的物**拍賣、變賣終結**②依法交債權人**承受**之日 **一日前**；③不經拍賣變賣者，於當次**分配表作成之日一日前**，以**書狀**聲明（要式，口頭 ✗）。**§32 II**：逾前項期間者（群團二）**僅得就前項債權人受償餘額**受清償；如再就債務人**其他財產**執行，其債權額與前項債權餘額除有優先權外按**債權額比例**平均受償（非按人數）。**參與分配要件**：①金錢債權 ②終局執行（保全執行無） ③同一債務人 ④債權**已屆清償期**（§4 II：將來給付判決於期限屆至前不得聲請執行，亦不得據以參與分配）⑤有**執行名義**（例外：對執行標的物有擔保物權或優先受償權者，筆記 10）。程序：書狀、證明文件、執行費千分之八（§28-2 II，不打折）。**最晚**聲明時點：**整個執行程序終結前**（已分配完畢之部分不重來）——與 §32 I 基準時是**兩個概念**：逾基準時仍可參與，只是列群團二

> 來源：強制執行法05 課程字幕 01:18:30 ~ 01:36:50、01:51:20 ~ 01:55:05（講義 192～196、399 頁）

## 📖 法條原文速查

> **強執 §31**　因強制執行所得之金額，如有多數債權人參與分配時，執行法院應作成分配表，並指定分配期日，於分配期日五日前以繕本交付債務人及各債權人，並置於民事執行處，任其閱覽。
> **強執 §32 I**　他債權人參與分配者，應於標的物拍賣、變賣終結或依法交債權人承受之日一日前，其不經拍賣或變賣者，應於當次分配表作成之日一日前，以書狀聲明之。
> **強執 §32 II**　逾前項期間聲明參與分配者，僅得就前項債權人受償餘額而受清償；如尚應就債務人其他財產執行時，其債權額與前項債權餘額，除有優先權者外，應按其數額平均受償。
> **強執 §4 II**　執行名義附有條件、期限或須債權人提供擔保者，於條件成就、期限屆至或供擔保後，始得開始強制執行。
> **強執 §28-2 II**　前項規定（執行費千分之八），於聲明參與分配者適用之。（項次請對原文）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「強執法為何第 1 節先規定參與分配（滿足），第 2～6 節才規定查封換價？」 | 查封、換價因財產種類（動產、不動產、船舶航空器、其他財產權、公法人財產）而異，分節規定；滿足階段全部變成錢、無差別 → 統一放第 1 節 |
| 「哪種執行有參與分配？」 | 只有**金錢債權**執行。物之交付、行為不行為是特定義務，無分配問題 |
| 「分配表、分配期日？」 | §31：多數債權人參與分配 → 作分配表、指定分配期日；期日 **5 日前**繕本交付兩造並置執行處閱覽；分配以匯款為之 |
| 「參與分配之方式？」 | **書狀**（要式）。選項寫「以言詞聲明參與分配」→ 錯 |
| 「§32 I 三個時點？」 | ①拍賣、變賣終結之日**一日前** ②交債權人承受之日**一日前** ③不經拍賣變賣者：當次分配表作成之日**一日前**（每個都是「之日一日前」）→ 這三個時點叫**基準時**，決定群團一／二（筆記 11） |
| 「逾基準時聲明參與分配之效果？」 | **仍得**參與，但列**群團二**：僅就群團一受償後之**餘額**受償；就債務人其他財產執行時，再與群團一按**債權額比例**平均受償（§32 II） |
| 「參與分配五要件？」 | ①金錢債權 ②終局執行 ③同一債務人 ④債權已屆清償期 ⑤有執行名義（例外：擔保物權、優先受償權人） |
| 「持將來給付之訴勝訴確定判決、債權尚未到期，得否參與分配受分配款？」 | **不得**。§4 II 期限屆至始得開始執行 → 期限屆至前不得以之聲請執行，亦不得據以聲明參與分配（講義 194 頁概念解析） |
| 「參與分配要不要繳執行費？」 | 要，與聲請執行同標準（千分之八，§28-2 II），不打折 |
| 「最晚何時可聲明參與分配？」 | **執行程序終結前**（整個；已分配完的財產不重來，只能分尚未分配的部分）。≠ §32 I 基準時：基準時影響**順位**，終結前才是**最後期限** |
| 「平均受償怎麼算？」 | 按**債權額比例**（甲一 1000 萬、甲二 50 萬、甲三 200 萬 → 20:1:4），不是除以人數 |

## 一、體系圖

```
金錢債權執行：查封 → 換價 → 滿足
  第 2～6 節（動產／不動產／船舶航空器／其他財產權／公法人財產）：查封、換價
  第 1 節 參與分配：滿足（§31 分配表、§32 參與分配、§33 併案、§34 執行名義與優先權人、§38～ 分配表異議…）
執行債權人（甲一，開第一槍）vs 聲明參與分配之債權人（甲二、甲三，搭便車來分錢）
```

## 二、基準時 vs 最晚時點

| | §32 I 基準時 | 最晚聲明時點 |
|---|---|---|
| 內容 | 拍定日前一日／承受日前一日／分配表作成日前一日 | 整個執行程序終結前 |
| 效果 | 之前＝群團一（先分）；之後＝群團二（分餘額） | 之後不能再分 |
| 關係 | 逾基準時**還是可以來**，只是分得少 | — |

## 三、分配表（講義 399 頁）次序示意

```
土地增值稅等稅捐 → 執行費用 → 實行抵押權費用 → 第一順位抵押權 → 第二順位… → 普通債權（依群團、債權額比例）
→ 普通債權常常一場空
```
