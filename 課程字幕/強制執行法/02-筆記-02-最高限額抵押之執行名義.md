# 強制執行法02 筆記：最高限額抵押之執行名義

## 案例：
- 甲為最高限額抵押權人，以**本票**為債權證明（此處本票只是證明文件，不是執行名義）
- 執行名義＝**拍賣抵押物裁定**（§4 I ⑤，不分一般或最高限額）
- 取得裁定所憑之 A 債權，後經民事庭判決**確認不存在確定**；同判決肯認尚有 B 債權
- 乙依 **§12 聲明異議**（主張欠缺執行名義＝程序瑕疵），請求駁回強制執行聲請

## 大法庭結論：
- 執行法院就其他債權證明文件**形式審查**，足認尚有其他已屆清償期之擔保債權（B）存在 → **不得**依聲明異議**駁回**強制執行聲請
- 一句話：可以拿 B 債權撐住原執行名義

## 理由：
- **執行機關與權利判定機關分離原則**：拍賣抵押物裁定由非訟法院（事務官）作成，執行處受其拘束
- 裁定主文以**抵押物**為對象；理由所載個別擔保債權存否，不影響主文執行效力
- 執行處依其他債權證明形式審查，不生取代非訟法院職權之問題

## 📖 法條原文速查

> **強執 §4 I ⑤**　抵押權人或質權人，為拍賣抵押物或質物之聲請，經法院為許可強制執行之裁定者。
> **強執 §12**　當事人或利害關係人，對於執行法院強制執行之命令，或對於執行法官、書記官、執達員實施強制執行之方法，強制執行時應遵守之程序，或其他侵害利益之情事，得於強制執行程序終結前，為聲請或聲明異議。（節錄，原文請對六法）

## 📋 實務見解速查

> **最高法院民事大法庭裁定**（最高限額抵押，字號請對講義）：最高限額抵押權人持拍賣抵押物裁定為執行名義聲請強制執行，其取得執行名義所憑之債權經法院判決確認不存在確定，倘執行法院就其所提出之其他債權證明文件，**形式審查**結果，足認尚有其他已屆清償期之擔保債權存在時，即**不得依債務人之聲明異議駁回**強制執行之聲請。
> **79 年台抗字裁定**（講義 28 頁，字號請對講義）：抵押權所擔保之債權不存在 → 等於持白紙聲請執行，欠缺執行名義（實體＋程序**雙重瑕疵**）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「最高限額抵押權人實行抵押之執行名義？」 | **拍賣抵押物裁定**（§4 I ⑤）；題目裡的本票可能只是債權證明 |
| 「取得裁定所憑債權經判決確認不存在確定，執行法院應駁回聲請？」 | **不一定**：形式審查認尚有**其他已屆清償期擔保債權** → **不得駁回** |
| 「債務人主張欠缺從屬債權，循何程序？」 | §12 **聲明異議**（執行名義要件屬程序，執行處可審查） |
| 「執行處依他債權續行，是否取代非訟法院職權？」 | **否**，主文以抵押物為對象，個別債權不影響主文執行效力 |
| 「本題背後的原則？」 | **執行機關與權利判定機關分離原則** |

## 一、事實圖

```
甲（最高限額抵押權人）── 抵押 ──→ 乙的不動產
   │
   ├─ 非訟法院：拍賣抵押物裁定（所憑：A 債權）＝執行名義
   │
   ├─ 民事庭：確認 A 債權不存在確定（判決理由提到尚有 B 債權）
   │
   └─ 執行處：乙 §12 聲明異議「A 沒了，執行名義失所附麗」
              甲提出 B 債權證明 → 形式審查 B 存在
              → 不駁回，續行執行
```

## 二、三個部門各司其職

| 部門 | 做什麼 | 本案 |
|---|---|---|
| 非訟中心（事務官） | 判斷可否拍賣抵押物、作成裁定 | 主文：抵押物准予拍賣 |
| 民事庭 | 實體權利存否 | 確認 A 債權不存在 |
| 民事執行處 | 依執行名義執行、形式審查 | 依 B 債權證明續行 |

## 三、瑕疵救濟兩大類（講義 28 頁表格）

```
執行瑕疵
├── 程序瑕疵 → 在執行處 §12 聲請或聲明異議
└── 實體瑕疵 → 到民事庭提訴訟（§14、§15 等）  ← 分離原則
欠缺從屬債權：實體有問題，且不具開始執行要件 → 雙重瑕疵
```

- 老師：選擇題記結論「**可以拿 B 債權**」就好；申論細節在講義後段。
