# 強制執行法09 筆記：行為請求權體系與可代替行為（§127）

## 體系：
- 金錢債權（查封、換價、滿足）與物之交付（取交、解除占有）都是**直接強制**
- 行為不行為的關鍵是區分**可否代替**：可代替 → **代替執行**（§127）；不可代替、不作為 → **間接強制**（處怠金、管收）
- 不作為一定不可代替（叫你不要滑手機，別人無從代你不滑）

## 可代替行為：
- 定義：由第三人代為履行與債務人自己為之，對債權人有**相同經濟上、法律上效果**
- 執行：以**債務人費用**命第三人代為履行；費用由執行法院酌定，命債務人預付或命債權人代為預納，必要時鑑定（§127）
- 本質轉化為**金錢給付義務** → 債務人不付就走金錢債權執行
- 例：修漏水、修繕、拆屋、清除土地上廢棄物

## 可否代替要看個案：
- 駐唱演出：知名歌手有票房 → 不可代替；餐廳背景音樂只要有人唱 → 可代替。畫素描同理
- 刪除臉書網頁：平台後台能刪 → 可代替；**台灣臉書公司**無從代為刪除 → 不能用 §127，改依 **§128**

## 強制道歉已不能執行：
- **111 年憲判字第 2 號**：回復名譽之適當處分不包括法院判決命加害人道歉
- 憲判生效時尚未執行或執行未完畢者 → **不得再予執行**，聲請一律駁回
- 舊考點：登報道歉＝可代替；親自道歉＝不可代替。現在可考「判決主文登報」＝可代替

## 📖 法條原文速查

> **強執 §127**　I 依執行名義，債務人應為一定行為而不為者，執行法院得**以債務人之費用，命第三人代為履行**。II 前項費用，由執行法院**酌定數額**，命債務人**預行支付**或命債權人**代為預納**，必要時，並得命鑑定人鑑定其數額。
> **民法 §195 I 後段**　其名譽被侵害者，並得請求**回復名譽之適當處分**。（字幕老師唸成「民法第 193 條第一項後段」，應為 §195 I 後段，請對六法）
（條文原文請對六法）

## 📋 實務見解

> **111 年憲判字第 2 號**：民法 §195 I 後段所稱回復名譽之適當處分，**不包括**法院以判決命加害人公開道歉之情形（侵害不表意自由）。

> **憲判後之執行**：在憲法法庭判決生效前已取得命道歉之確定判決，生效後尚未執行或執行未完畢者，**不得再予執行**。（字號請對講義 338 頁後）

> **臉書網頁刪除案**：台灣臉書公司為個別法人，總公司在愛爾蘭，其經營活動僅限於公共關係諮詢等，無從依執行命令代為刪除 → 不能依 §127 代為履行，改依 §128 不可代替行為執行。（字號請對講義 338 頁後）

> **修漏水**：執行法院命債務人修復浴室樓板漏水工程，得命債權人僱請第三人代為修復；實務多由債權人先墊付，再向債務人求償（金錢債權執行）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「命清除土地上廢棄物，如何執行？」 | **可代替行為**（§127）：以債務人費用命第三人代為履行 |
| 「可代替行為之費用如何處理？」 | 執行法院酌定數額，命債務人**預行支付**或命債權人**代為預納**，必要時鑑定 |
| 「不作為義務可否由第三人代為履行？」 | **不能**。不作為**一律不可代替** → 間接強制 |
| 「命刪除臉書個人網頁？」 | 平台無從代刪 → **§128** 不可代替（處怠金、管收） |
| 「持 111 年憲判字第 2 號前確定之登報道歉判決聲請執行？」 | 尚未執行或執行未完畢者，**不得再予執行**，駁回 |
| 「命將判決主文刊登報紙？」 | **可代替行為**，得聲請執行 |
| 「強制執行中的直接強制有哪些？」 | 金錢債權執行、動產取交、不動產解除占有；行為不行為才分代替執行與間接強制 |

## 一、執行方法總圖

```
強制執行
├─ 金錢債權 ──────── 查封 → 換價 → 滿足（直接強制）
├─ 物之交付 ──────── 動產取交 §123／不動產解除占有 §124（直接強制）
└─ 行為不行為
    ├─ 可代替行為 ── 代替執行 §127 → 轉化為金錢債權
    ├─ 不可代替行為 ─ 間接強制 §128：定期 → 怠金 → 再怠金或管收
    ├─ 不作為 ────── 間接強制 §129（一律不可代替）
    └─ 意思表示 ──── 擬制 §130（不必執行）
```

## 二、同一行為，可否代替看情境

| 行為 | 可代替 | 不可代替 |
|---|---|---|
| 演唱 | 餐廳背景駐唱，找得到人代唱 | 有票房、粉絲的知名歌手 |
| 畫畫 | 路邊素描（AI 也畫得出來） | 指定藝術家的創作 |
| 刪文 | 平台後台可刪 | 只有債務人能刪（台灣臉書案） |
| 道歉（已不得執行） | 登報道歉（以前） | 親自道歉（以前） |

- 申論題無法判斷就兩種都假設；選擇題用刪去法。
- 老師：非金錢執行在選擇題約出現在第 6～8 題，題目簡單，一定要拿分。
