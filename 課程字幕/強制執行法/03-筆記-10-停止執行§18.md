# 強制執行法03 筆記：停止執行（§18）

## 原則與事由：
- 執行開始後，除法律另有規定外，**不停止執行**（§18 I）
- §18 II 六種事由：回復原狀、再審、**異議之訴**（考試頻率第一名）、和解繼續審判、宣告調解無效／撤銷調解之訴、對許可強制執行裁定抗告
- 效果是「**得**」停止，不是當然停止：須有**停止必要**，願供擔保**不能取代**必要性

## 誰裁定：
- 停止裁定由**受訴法院**（再審、異議之訴、抗告之繫屬法院）為之；**執行法院無權酌定**
- 當事人須把裁定**提出於執行處**才停（兩部門不連線）

## 停止的範圍：
- **主觀**：僅及於裁定所列之債權人與債務人；其他併案、後執行之債權人得繼續執行（105 年研討結果）
- **客觀**：被停止之債權人**不得**再扣押債務人其他財產、追加標的或**聲明參與分配**

> 來源：強制執行法03 課程字幕 01:52:13 ~ 02:11:40（講義 117～120 頁）

## 📖 法條原文速查

> **強執 §18 I**　強制執行程序開始後，除法律另有規定外，**不停止執行**。
> **強執 §18 II**　有回復原狀之聲請，或提起再審或異議之訴，或對於和解為繼續審判之請求，或提起宣告調解無效之訴、撤銷調解之訴，或對於許可強制執行之裁定提起抗告時，法院因必要情形或依聲請定相當並確實之擔保，**得**為停止強制執行之裁定。

## 📋 實務見解速查

> **第三人異議之訴與停止**（實務見解，字號請對講義）：審判未確定前應否停止執行，由**受訴法院**斟酌情形定之，**執行法院並無酌定之權**。
> **105 年法律座談會研討結果**（講義，字號請對講義）：停止裁定效力僅及於裁定所列兩造之先執行程序，**不及於**受裁定人以外之後執行程序；後執行者得聲請繼續執行，不因係債務人或第三人異議之訴而異。
> **座談會研討結果**（講義 120 頁，字號請對講義）：債務人供擔保停止執行後，該被停止之債權人不得再聲請追加執行標的或併案、參與分配。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人提起異議之訴，執行程序當然停止？」 | **錯**，僅「**得**」停止，須受訴法院裁定 |
| 「只要聲明願供擔保，法院即應裁定停止？」 | **錯**，仍須有**停止之必要** |
| 「停止執行之裁定由執行法院為之？」 | **錯**，由**受訴法院**；執行法院無酌定權 |
| 「對假扣押、假處分裁定抗告，得聲請停止執行？」 | **不得**，抗告不停止執行（§18 II 抗告之例外） |
| 「對本票裁定、拍賣抵押物裁定抗告？」 | 屬許可強制執行之裁定 → **得**停止 |
| 「回復原狀適用於哪些執行名義？」 | **全部**（老師更正講義）；再審限**確定判決** |
| 「停止裁定效力及於後來併案之其他債權人？」 | **不及於**，僅及於裁定所列當事人 |
| 「被停止之債權人得對債務人其他財產聲明參與分配？」 | **不得** |

## 一、§18 II 停止事由表（講義填空）

| # | 事由 | 適用之執行名義 |
|---|---|---|
| 1 | 回復原狀之聲請（民訴 §164） | 全部 |
| 2 | 提起再審（民訴 §496） | 確定判決（§4 I ①） |
| 3 | 提起**異議之訴**（§14、§15 等） | 全部（實務最常用） |
| 4 | 和解繼續審判之請求 | 訴訟上和解 |
| 5 | 宣告調解無效、撤銷調解之訴 | 調解 |
| 6 | 對許可強制執行之裁定抗告 | 拍賣抵押物裁定、本票裁定等；**假扣押、假處分以外** |

## 二、停止的運作

```
債務人在民事庭提再審／異議之訴 ＋ 聲請停止
        ↓ 受訴法院審酌必要性、命供擔保
取得停止裁定
        ↓ 自行提出於執行處
執行處停止（只停裁定所列之債權人）
        ↓ 本案結果
├── 債務人勝訴確定 → 提出判決 → 撤銷全部執行處分
└── 債務人敗訴 → 續行執行
```

## 三、主觀與客觀範圍

```
債務人乙 ← 甲1（停止裁定所列）、甲2、甲3（併案）
停止裁定只列甲1 vs 乙
├── 甲1：停；且不得對乙其他財產追加、併案、參與分配
└── 甲2、甲3：照常執行（潛在查封效力顯現）
→ 債務人想全部停下，要對每一個執行名義各取得停止裁定
```
