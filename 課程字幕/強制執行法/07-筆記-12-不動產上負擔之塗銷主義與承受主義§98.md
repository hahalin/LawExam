# 強制執行法07 筆記：不動產上負擔之塗銷主義與承受主義（§98）

## 擔保物權：原則塗銷主義（§98 III）：
- 不動產上的**抵押權及其他優先受償權**，因拍賣而**消滅**（拍定人買到的是乾淨的不動產）
- 例外承受：抵押債權未定清償期或清償期未屆至，**拍定人（或承受之債權人）聲明願在價額範圍內清償**，並經**抵押權人同意** → 抵押權留下來
- 例外的實際動機：銀行想繼續收利息、不想被提前清償，拍定人另外跟銀行談

## 用益物權與租賃：原則承受主義（§98 II）：
- 地上權等用益物權、典權及**租賃關係**，**隨同移轉**給拍定人（呼應民 §425 買賣不破租賃）
- 例外**除租拍賣**：用益權或租賃**發生於抵押權設定後**，且**對抵押權有影響**，經執行法院**除去**後拍賣 → 不隨同移轉

## 「對抵押權有影響」的判斷：
- 注意事項：因設定用益權或出租致**價值減少**，使抵押擔保債權**不能受滿足之清償**（須有因果關係）
- 法條用「**得**」除去：先抵押後出租不當然除去，個案評估
- 聲請權人：老師強調**只有抵押權人**；其他普通債權人不得以此為由聲請；執行法院亦得依職權

## 例題：先抵押後出租、價金不足：
- 執行法院處理：依 §98 II 但書（民 §866 II）**除去租賃後拍賣**
- 丁拍定後可否解除丙之占有點交 → **可以**，§99 II 後段（占有係 §98 II 但書情形）

## 📖 法條原文速查

> **強執 §98 II**　前項不動產原有之地上權、（其他用益物權）、典權及**租賃關係隨同移轉**。但發生於設定抵押權之後，並**對抵押權有影響**，經執行法院**除去後拍賣**者，不在此限。（用益物權名稱原文請對六法）
> **強執 §98 III**　存於不動產上之**抵押權及其他優先受償權，因拍賣而消滅**。但書要旨：抵押債權未定清償期或清償期尚未屆至，拍定人或承受之債權人聲明願在價額範圍內清償債務，**經抵押權人同意**者，不在此限。（原文請對六法）
> **強執 §99 II**　第三人對其在查封前無權占有不爭執或其占有為**前條第二項但書**之情形者，前項規定亦適用之。（原文請對六法）
> **民 §425 I**　出租人於租賃物交付後，承租人占有中，縱將其所有權讓與第三人，其租賃契約，對於受讓人仍繼續存在。
> **民 §866**　要旨：I 抵押權設定後，所有人仍得設定用益物權或成立租賃，但**抵押權不因此受影響**。II 前項情形，抵押權人實行抵押權受有影響者，法院得除去該權利或終止該租賃關係後拍賣之。（原文請對六法）
> **辦理強制執行事件應行注意事項 57**　要旨：抵押後設定其他權利或出租，**因而價值減少，致抵押債權不能受滿足之清償**者，執行法院得依聲請或依職權除去後拍賣之。（字幕聽成「第57條第四項」，點次請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「拍賣後不動產上之抵押權？」 | 原則**消滅**（塗銷主義，§98 III） |
| 「抵押權例外不消滅的要件？」 | 未定清償期／清償期未屆至＋拍定人聲明願清償＋**抵押權人同意** |
| 「查封前已存在之租賃，拍定後？」 | **隨同移轉**（承受主義，§98 II；民 §425） |
| 「先出租後設定抵押，得除去租賃？」 | **不得**，除租限於**抵押後**才發生的租賃 |
| 「先抵押後出租，執行法院即應除去租賃？」 | **錯**，須**對抵押權有影響**（價值減少致不能足額受償），且法條為「得」 |
| 「普通債權人得聲請除去租賃？」 | **不得**（老師：只有抵押權人） |
| 「租賃經除去後拍定，得點交？」 | **得**，§99 II 後段 |

## 一、負擔處理總表

```
不動產上負擔
├─ 擔保物權（抵押權、優先受償權）
│   ├ 原則：因拍賣而消滅 → 塗銷主義（§98 III 本文）
│   └ 例外：清償期未到＋拍定人願清償＋抵押權人同意 → 承受（§98 III 但書）
└─ 用益物權、典權、租賃
    ├ 原則：隨同移轉 → 承受主義（§98 II 本文；民 §425）
    └ 例外：抵押後才發生＋對抵押有影響 → 除去後拍賣（§98 II 但書；民 §866 II）
```

## 二、除租拍賣的三個要件

| 要件 | 內容 |
|---|---|
| 時間 | 租賃（用益權）**發生於抵押權設定之後** |
| 影響 | 因而**價值減少**，致抵押債權**不能足額清償**（有因果關係） |
| 程序 | 抵押權人聲請（或執行法院職權），由執行法院**除去**後拍賣 |

- 數字感：抵押擔保 1,000 萬，帶租約只能賣 800 萬、不帶租約能賣 1,100 萬 → 有影響，得除租。

## 三、例題兩小題對應

| 小題 | 答案 | 依據 |
|---|---|---|
| ① 執行法院應如何處理 | 除去租賃後拍賣 | §98 II 但書；民 §866 II |
| ② 丁拍定後可否解除丙占有點交 | 可以 | §99 II 後段（§99 第四種點交情形） |

- §99 四種可點交情形（07-筆記-10）：債務人占有、查封後第三人占有、查封前無權占有不爭執、占有經 §98 II 但書除去。
