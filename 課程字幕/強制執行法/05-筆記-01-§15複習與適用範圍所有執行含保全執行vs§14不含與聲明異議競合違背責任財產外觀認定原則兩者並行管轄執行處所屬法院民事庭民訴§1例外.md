# 強制執行法05 筆記：第三人異議之訴 §15 複習與適用範圍——原告第三人、被告債權人（債務人亦否認其權利時並列為共同被告）、向執行處所屬法院**民事庭**提起（條文「執行法院」在 §14、§15 指民事庭，是民訴 §1 以原就被的**例外**：執行在哪個地院，異議之訴就在該地院民事庭）、**個別**執行程序終結前；**適用範圍：所有財產之強制執行，含保全執行**（§14 債務人異議之訴則**排除保全執行**——假扣押假處分必有本案訴訟，實體爭執應在本案解決；§15 是錯誤執行到非債務人財產，終局、保全皆可能發生）；**與聲明異議 §12 競合**：執行機關違背**責任財產外觀認定原則**（不動產看**登記**名義、動產看**占有**外觀）而查封第三人財產 → 程序瑕疵（§12 聲明異議）＋實體瑕疵（§15）**兩者得並行**，選擇題常考

> 來源：強制執行法05 課程字幕 00:00:02 ~ 00:07:00（講義 157、166 頁）

## 📖 法條原文速查

> **強執 §15**　第三人就執行標的物有足以排除強制執行之權利者，得於強制執行程序終結前，向執行法院對債權人提起異議之訴。如債務人亦否認其權利時，並得以債務人為被告。
> **民訴 §1 I**　訴訟，由被告住所地之法院管轄。……（以原就被；§14、§15 之「執行法院」為其例外）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§15 之當事人？」 | 原告：**第三人**；被告：**債權人**；債務人亦否認第三人權利時，**並得**以債務人為被告（共同被告）→ 看誰否認你的權利 |
| 「§15 之管轄？」 | 條文「執行法院」＝**執行處所屬法院之民事庭**（與 §14 同解）；不用再依民訴 §1 找管轄，執行在台中地院執行處 → 就在台中地院民事庭起訴 |
| 「假扣押執行程序中，第三人得否提 §15？」 | **得**。§15 適用於**所有**財產執行，含保全執行（錯誤執行到非債務人財產，任何執行都可能發生）。對照：§14 不適用於保全執行（實體爭執應於本案訴訟解決） |
| 「執行處未依登記名義查封第三人之不動產，第三人如何救濟？」 | **兩者並行**：違背責任財產外觀認定原則＝程序瑕疵 → §12 聲明異議；第三人無忍受執行義務＝實體瑕疵 → §15 → 可同時在執行處聲明異議＋到民事庭起訴 |
| 「責任財產外觀認定原則？」 | 不動產：**登記**；動產：**占有**。執行處依外觀認定財產歸屬；不動產違反較少（謄本很清楚），動產（債務人未占有卻被執行）較可能 |

## 一、§15 骨架

```
原告：第三人（就執行標的物有足以排除強制執行之權利）
被告：債權人（＋否認其權利之債務人）
法院：執行處所屬地院民事庭（民訴 §1 之例外）
時點：該標的物（個別）執行程序終結前 → 筆記 02
性質：形成之訴；有理由 → 不許對該特定財產執行
```

## 二、§14 vs §15 適用範圍

| | §14 債務人異議之訴 | §15 第三人異議之訴 |
|---|---|---|
| 瑕疵 | 執行名義（實體請求權） | 執行客體（財產不是債務人的） |
| 保全執行 | **✗**（有本案訴訟） | **✓**（所有執行） |

## 三、與 §12 競合（並行）

```
執行處違背外觀認定原則查封第三人財產
├ 程序瑕疵 → §12 聲明異議（執行處）
└ 實體瑕疵 → §15 第三人異議之訴（民事庭）
→ 可同時提
```
