# 強制執行法03 筆記：薪資執行與生活所必需（§122）

## 先扣（§115-1）：
- 對薪資等繼續性給付債權，**扣押一次**，效力及於扣押後**應受**（以後每月）及**增加**（加薪）之給付
- 扣押範圍**不得逾各期給付數額三分之一**（「扣薪不超過三分之一」的依據）

## 後算（§122）：
- 社會保險給付、對第三人債權（考試 99.9% 是**薪資**）屬生活所必需者 → **不得強制執行**
- 生活所必需＝當地**每人每月最低生活費 × 1.2**；共同生活親屬依扶養義務比例同樣加計
- 算出來的數字是「**不能執行**」的金額，不是可執行金額；顯失公平時可個案調整（§122 V）

## 救濟：
- 違反 §122 屬**程序瑕疵（違法執行）** → **§12 聲明異議**

## 📖 法條原文速查

> **強執 §115-1 I**　對於薪資或其他繼續性給付之債權所為強制執行，於債權人之債權額及強制執行費用額之範圍內，其效力及於扣押後**應受及增加之給付**。
> **強執 §115-1 II**　對於下列債權發扣押命令之範圍，**不得逾各期給付數額三分之一**：①自然人因提供勞務而獲得之繼續性報酬債權 ②（第二款請對六法）
> **強執 §122 II**　債務人依法領取之社會保險給付或其對於第三人之債權，係維持債務人及其共同生活之親屬**生活所必需**者，**不得強制執行**。
> **強執 §122 III**　債務人生活所必需，以最近一年衛生福利部或直轄市政府所公告當地區每人每月**最低生活費一點二倍**計算其數額，並應斟酌債務人之其他財產。
> **強執 §122 IV**　債務人共同生活親屬生活所必需，準用前項計算基準，並按債務人依法應負擔**扶養義務之比例**定其數額。
> **強執 §122 V**　執行法院斟酌債務人與債權人生活狀況及其他情事，認有失公平者，不受前三項規定之限制。但應酌留債務人及其扶養之共同生活親屬生活費用。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「執行薪資，每月須重新核發扣押命令？」 | **不須**，效力及於扣押後應受及增加之給付（§115-1 I） |
| 「扣押薪資之上限？」 | 各期給付數額 **1/3**（§115-1 II） |
| 「債務人生活所必需如何計算？」 | 當地最低生活費 **× 1.2**；**別忘了乘 1.2** |
| 「共同生活親屬之生活所必需是否加計？」 | **加計**，依債務人應負擔扶養義務比例（§122 IV） |
| 「§115-1 與 §122 適用順序？」 | **§115-1 先**（扣押階段先扣 1/3）→ **§122 後**（決定最後能執行多少） |
| 「扣薪致生活困頓，債務人如何救濟？」 | 違反 §122 屬程序瑕疵 → **§12 聲明異議** |

## 一、兩條文的先後

```
扣押階段（先）               實際執行階段（後）
§115-1：先扣 1/3      →      §122：扣除生活所必需後才能執行
（財產狀況還不明朗）          （債務人＋親屬 × 1.2）
                                   ↓
                     剩下 2/3 仍不夠生活所必需 → 撤銷先扣的部分（起封）
```

## 二、實例計算（老師板書）

```
甲住臺南市（生活中心地），月薪 28,590 元，獨力扶養未成年子女 1 人
每月被扣 1/3 ＝ 9,530 元 → 實領 19,060 元，生活困頓

臺南市 114 年最低生活費 15,515 × 1.2 ＝ 18,618（甲本人）
子女 1 人，扶養義務全部 → 再加 18,618
合計不得執行 ＝ 37,236 元 ＞ 月薪 28,590 元
→ 薪資全部不得執行
→ 救濟：§12 聲明異議（違法執行＝程序瑕疵）
```

- 臺北市 114 年：20,379 × 1.2 ≈ 24,455
- 扶養義務若兩兄弟分擔 → 該親屬那一份再乘 **1/2**
- 司法院網站有已乘好 1.2 的對照表（講義附錄一）；題目只給最低生活費時要自己乘

## 三、比較：程序瑕疵 vs 實體瑕疵

| | 程序瑕疵 | 實體瑕疵 |
|---|---|---|
| 判斷 | 執行**合不合法** | 執行**有無理由** |
| 本題 | 違反 §122 ✓ | — |
| 救濟 | §12 聲明異議（向執行處） | 異議之訴（向民事庭） |
