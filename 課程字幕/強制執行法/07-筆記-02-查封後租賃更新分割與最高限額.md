# 強制執行法07 筆記：查封後租賃更新分割與最高限額

## 查封前已存在的租約：
- 不受查封影響，繼續存續；拍定後隨同移轉給拍定人（買賣不破租賃）
- 查封**後**新訂租約 → 違反 §51 II，不生效力

## 查封後租約的更新、讓與、轉租：
- **法定（默示）更新**：查封後租期屆滿，承租人繼續使用、出租人未反對 → **不適用民法 §451**（67 年決議）
- **任意更新**（出租人查封後與承租人續約）→ 當然**不行**
- **讓與、轉租**：原則不行；但只換承租人、租金期限等**內容不變**、未增加負擔 → 可以

## 應有部分（持分）查封後的分割：
- **裁判分割**：可以——法院會通盤考量（形式形成之訴、非訟性質）
- **協議分割**：可能不行——若故意讓被查封者分得較少，有礙執行效果，個案判斷

## 最高限額抵押物遭他債權人查封：
- 擔保債權**確定**（民法 §881-12 I ⑥）：查封而為最高限額抵押權人所**知悉**，或經執行法院**通知**時

## 📖 法條原文速查

> **強執 §51 II**　實施查封後，債務人就查封物所為移轉、設定負擔或其他有礙執行效果之行為，對於債權人不生效力。
> **民法 §451**　租賃期限屆滿後，承租人仍為租賃物之使用收益，而出租人不即表示反對之意思者，視為以**不定期限繼續契約**。
> **民法 §425 I**　出租人於租賃物交付後，承租人占有中，縱將其所有權讓與第三人，其租賃契約，對於受讓人仍繼續存在。
> **民法 §881-12 I ⑥**　最高限額抵押權所擔保之原債權，除本節另有規定外，因下列事由之一而確定：……六、抵押物因他債權人聲請強制執行經法院查封，而為最高限額抵押權人所**知悉**，或經執行法院**通知**最高限額抵押權人者。
（§881-12 原文請對六法）

## 📋 實務見解

> **67 年決議**（字號請對講義，約 251 頁）：甲將房屋出租乙後房屋被查封，甲對房屋喪失處分及設定負擔之權，對是否續租更漠不關心；租期於查封後屆滿，乙仍繼續使用，甲雖未即表示反對，**難認有默示同意繼續出租**之意思，不適用民法 §451。

> **租賃權讓與、轉租**（實務見解，出處請對講義）：僅承租人變更、原契約內容不變者，不違反查封效力。

> **應有部分查封後之分割**（實務見解，出處請對講義）：裁判分割可；協議分割視有無妨礙執行效果。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「查封前已出租並交付，查封後租約效力？」 | **繼續存在**，拍定後隨同移轉 |
| 「查封後租期屆滿，承租人繼續使用、出租人未反對，得主張 §451 不定期租賃？」 | **不得**（67 年決議）；租約到期就是到期 |
| 「查封後出租人與承租人合意續約？」 | 違反 §51 II，對債權人**不生效力** |
| 「查封後承租人將租約讓給學弟，租金期限不變？」 | **可以**，只是換人、未增加負擔 |
| 「應有部分被查封後，共有人訴請**裁判分割**？」 | **可以**，法院會考量查封情形 |
| 「應有部分被查封後**協議分割**？」 | 個案判斷；故意讓被查封人少分 → 有礙執行效果，不行 |
| 「最高限額抵押物被他債權人查封，擔保債權何時確定？」 | 抵押權人**知悉**查封或受執行法院**通知**時（§881-12 I ⑥） |

## 一、查封前租約的四種變動

| 情形 | 可否對抗執行債權人 | 理由 |
|---|---|---|
| 查封前租約繼續履行 | 可 | 查封前已存在 |
| 查封後期滿默示更新 | **不可** | 不適用 §451（67 年決議） |
| 查封後任意更新 | **不可** | 等於查封後新設負擔 |
| 讓與、轉租 | 原則不可；內容不變的換人可 | 看是否增加負擔、有礙執行效果 |

## 二、最高限額抵押為何要「確定」

```
最高限額抵押：擔保債權陸續發生，金額要到確定時才算得出來
   ↓
同一擔保物被其他債權人（如假扣押債權人）聲請執行查封
   ↓
抵押權人知悉查封 或 受執行法院通知 → 原債權確定（金額定下來）
```

- 老師提醒：這也是在考民法；一試強執只有十題，碰到不會的用民法推。
