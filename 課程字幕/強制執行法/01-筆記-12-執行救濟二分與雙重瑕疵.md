# 強制執行法01 筆記：執行救濟二分與雙重瑕疵

## 兩條路：
- **程序瑕疵**＝執行處違反強執法＝**違法執行** → 向執行處**聲明異議**（§12）
- **實體瑕疵**＝清償、時效、抵銷等實體抗辯＝**不當執行** → 到**民事庭**提**異議之訴**等，可同時聲請**停止執行**（「得」停止）
- 呼應分離原則：違法是程序、不當是實體，用語不同

## 雙重瑕疵：
- 拍賣抵押物裁定成立後，債務人提**確認債權不存在之訴**獲勝訴確定 → 抵押權因**從屬性**而失所附麗
- 債權人仍持該裁定聲請執行 → 既是實體瑕疵，也是程序瑕疵（**欠缺執行名義**，等於拿白紙執行）
- 79 年判例：原執行名義之執行力已可確定其不存在，尚在執行中者，債務人**可依 §12 聲明異議**（考過好幾次）

> 來源：強制執行法01 課程字幕 02:37:55 ~ 02:45:37（講義 28 頁起）

## 📖 法條原文速查

> **強執 §12 I**　當事人或利害關係人，對於執行法院強制執行之命令，或對於執行法官、書記官、執達員實施強制執行之方法，強制執行時應遵守之程序，或其他侵害利益之情事，得於強制執行程序終結前，為聲請或**聲明異議**。但強制執行**不因而停止**。
> **強執 §14 I**　執行名義成立後，如有消滅或妨礙債權人請求之事由發生，債務人得於強制執行程序終結前，向執行法院對債權人提起**異議之訴**……
> **強執 §18 II**　……提起異議之訴……時，法院因必要情形或依聲請定相當並確實之擔保，**得**為停止強制執行之裁定。（原文請對六法）

---

## 📋 實務見解速查

> **最高法院 79 年判例**（講義 28 頁附近，字號請對講義）：非訟事件之強制執行名義成立後，如債務人提起確認該債權不存在之訴，而獲得勝訴確定判決時，應認原執行名義之**執行力已可確定其不存在**，其尚在執行中，債務人可依強執 **§12 聲明異議**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「執行處夜間查封有人居住之住宅（或法拍未公告），救濟方式？」 | 程序瑕疵 → **§12 聲明異議** |
| 「債務人主張執行名義成立後已清償，救濟方式？」 | 實體瑕疵 → 民事庭**異議之訴**（§14） |
| 「提起異議之訴，執行程序當然停止？」 | **錯**。須聲請，法院**得**裁定停止（§18 II） |
| 「許可拍賣抵押物裁定後，債務人確認擔保債權不存在勝訴確定，債權人仍聲請執行，債務人如何救濟？」 | **雙重瑕疵**：可提訴訟，也可依 **§12 聲明異議**（79 年判例，考過好幾次） |
| 「聲明異議之對象？」 | 直接向**執行處**（執行法院） |

## 一、救濟二分

```
執行中發現瑕疵
   │
   ├─ 程序瑕疵（違法執行：執行處沒照強執法做）
   │    例：夜間查封、法拍未公告、查封方式錯誤
   │    → §12 聲明異議 → 向執行處
   │
   └─ 實體瑕疵（不當執行：實體權利有爭執）
        例：清償、時效、抵銷
        → 民事庭起訴（異議之訴等）
        → 同時聲請停止執行：得停止，非應停止
          （亂告的不會准；勝訴可能性高才給停止裁定）
```

## 二、雙重瑕疵案例

```
甲持許可拍賣抵押物裁定（§4 I ⑤）聲請執行乙之房地
乙提起確認擔保債權不存在之訴 → 勝訴確定
  │ 抵押權從屬於被擔保債權 → 債權不存在，抵押權也不存在
  ▼
甲仍持原裁定聲請執行
  ├─ 實體瑕疵：債權不存在 → 可起訴救濟
  └─ 程序瑕疵：執行力已確定不存在＝欠缺執行名義（拿白紙執行）
              → §12 聲明異議（79 年判例）
```

- 下堂預告：持拍賣抵押物裁定聲請執行，應備文件除抵押權證明外還要**債權證明文件**；形式上無法證明債權存在，就等於沒有執行名義。

## 三、用語對照

| 用語 | 瑕疵 | 救濟 |
|---|---|---|
| 違法執行（不合法） | 程序 | §12 聲明異議 |
| 不當執行（無理由） | 實體 | 民事庭訴訟＋§18 II 停止 |
