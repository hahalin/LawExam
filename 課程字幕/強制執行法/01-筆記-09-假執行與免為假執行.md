# 強制執行法01 筆記：假執行與免為假執行

## 假執行的性質：
- 「假」＝暫時；一審（未確定）判決**提早實現**，屬**終局執行**：查封、換價、滿足整套做完，不足時也**發債權憑證**
- **暫定的執行名義**：本案判決或假執行宣告於上訴審被**廢棄或變更**，於該範圍內**向後失效**（民訴 §395 I）
- 實務少用：通常是**附條件**假執行，原告須供**全額**擔保（保全執行擔保約 1/3 左右）

## 失效後執行處怎麼辦：
- 執行程序**終結前** → 撤銷已為之執行處分
- 已終結 → 來不及撤銷；債務人另依民訴 §395 II 請求**回復原狀、損害賠償**

## 免為假執行（反擔保）：
- 被告供擔保或提存標的物而免為假執行（民訴 §392 II）
- 最晚時點（§392 III）：**拍定、變賣**（買賣契約成立，槌子敲下）或**物之交付前**
- 行為不行為：條文未規定，依法理在**執行終結前**

## 📖 法條原文速查

> **民訴 §392**　I 法院得宣告非經原告預供擔保，不得為假執行。II 法院得依聲請或依職權，宣告**被告預供擔保**，或將請求標的物**提存**而**免為假執行**。III 依前項規定預供擔保或提存而免為假執行，應於執行標的物**拍定、變賣或物之交付前**為之。
> **民訴 §395**　I 假執行之宣告，因就**本案判決或該宣告**有廢棄或變更之判決，自該判決宣示時起，於其廢棄或變更之範圍內，**失其效力**。II 法院廢棄或變更宣告假執行之本案判決者，應依被告之聲明，將其因假執行或因免假執行所為給付及所受損害，於判決內命原告**返還及賠償**……（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「假執行屬保全執行，只能查封不能換價？」 | **錯**。假執行是**終局執行**，可到滿足 |
| 「假執行之債權人執行不足時，得發債權憑證？」 | **得** |
| 「第二審僅廢棄本案判決而未廢棄假執行宣告，假執行仍有效？」 | **錯**。本案**或**宣告被廢棄變更，於該範圍內均失效（依附本案） |
| 「假執行失效之效力？」 | 自廢棄判決宣示時起**向後**失效 |
| 「假執行宣告失效時，執行程序已終結？」 | 不能撤銷執行處分；債務人依民訴 §395 II 請求返還、賠償 |
| 「被告供反擔保免為假執行，最遲何時？」 | 執行標的物**拍定、變賣或物之交付前**（民訴 §392 III） |
| 「行為不行為請求權之免為假執行時點？」 | 條文未規定，依法理於**執行終結前** |

## 一、假執行的位置

```
一審：原告勝訴＋假執行宣告（附條件：原告供擔保）
        ├── 被告上訴 → 二審審理中（案件未確定）
        └── 原告持一審判決先聲請執行（終局執行：查封→換價→滿足）
二審改判（廢棄原判、駁回原告之訴）
        → 假執行於廢棄範圍內向後失效（民訴 §395 I）
        ├─ 執行還在進行 → 執行處趕快停，撤銷已為之執行處分
        └─ 執行已終結 → 來不及；民訴 §395 II 回復原狀、損害賠償
```

## 二、四種執行名義比一比（講義 21 頁表）

| 比較 | 假扣押 | 假處分 | 假執行 | 確定判決 |
|---|---|---|---|---|
| 性質 | 保全 | 保全 | **終局** | 終局 |
| 做到哪 | 凍結 | 凍結 | 滿足 | 滿足 |
| 供擔保 | 原則要，約 1/3 | 原則要 | 原則要，**全額** | **不用** |
| 穩定度 | — | — | **暫定**，可能失效 | 穩定（除非再審） |

## 三、免為假執行的時點

```
查封 ─────────► 換價 ───────────────► 滿足
                  │拍定／變賣＝買賣契約成立
                  │（出賣人＝債務人，買受人＝拍定人「小明」）
  ◄── 可供反擔保 ──┤ 截止
```

| 執行類型 | 最晚時點 | 依據 |
|---|---|---|
| 金錢債權 | 拍定、變賣前 | 民訴 §392 III |
| 物之交付 | 完成交付前 | 民訴 §392 III |
| 行為不行為 | 執行終結前 | 法理 |

- 為什麼停在拍定：拍定後涉及買受人（小明）的權益，執行程序最保護他。
- 拍賣＝價格競爭（一元起標）；變賣＝直接談價（這瓶水 10 元）。
