# 強制執行法07 筆記：特別變賣與第四拍（§95）

## 特別變賣：
- 三拍（第二次減價拍賣）未拍定，債權人不願或不得承受 → 執行法院**應**於三拍期日終結後 **10 日內公告**（§95 I）
- 願買受者得於公告之日起**三個月內**，依**原定拍賣條件**（實務上即三拍條件）為應買之表示
- 不做價格競爭，是**變賣**不是拍賣；詢問債權人、債務人意見後許其買受
- 債權人於期間內仍得**承受**——任何一拍、特別變賣中，只要未賣出，債權人都可承受

## 第四拍：
- 三個月內、無人應買前，債權人得**聲請**停止特別變賣，另行**估價或減價拍賣**（§95 II）
- 用「聲請」的，**不一定會有**

## 視為撤回：
- 第四拍仍未拍定、債權人亦不承受；或債權人未於三個月內聲請另行估價或減價拍賣 → **視為撤回該不動產之執行**
- 該不動產的個別執行程序終結；立法者不希望無止境打折、讓財產被賤賣

## 例題：第四拍承受後不補繳差額：
- 第四拍由債權人承受，但逾期未補繳差額 → 實務多數說：**不再拍賣**
- 理由：依法已不得繼續減價拍賣；承受人不繳，主觀上已拋棄承受、無續行執行之意；以原價再拍**恐無實益**

> 來源：強制執行法07 課程字幕 01:19:15 ~ 01:26:11（多數說審查意見在講義 270 頁）

## 📖 法條原文速查

> **強執 §95**　I 經**二次減價拍賣**而未拍定之不動產，債權人不願承受或依法不得承受時，執行法院應於第二次減價拍賣期日終結後**十日內公告**願買受該不動產者，得於公告之日起**三個月內**依**原定拍賣條件**為應買之表示，執行法院得於詢問債權人及債務人意見後，許其買受。債權人復願為承受者，亦同。
> II 前項三個月期限內，無人應買前，債權人亦得**聲請停止**前項拍賣，而**另行估價或減價拍賣**，如仍未拍定或由債權人承受，或債權人未於該期限內聲請另行估價或減價拍賣者，**視為撤回**該不動產之執行。
（條文原文請對六法；字幕念成「如未拍定」，II 後段文字以六法為準）

## 📋 實務見解

> **第四拍承受人未補繳差額**（座談會，字號請對講義 270 頁）：不動產經二次減價拍賣未拍定，於特別變賣程序中另行估價或減價拍賣仍無結果，依法已不得繼續減價拍賣，以免損害債務人權益。債權人於 §95 II 減價拍賣聲明承受後不依限繳納差額，主觀上已拋棄承受而無繼續執行之意；該不動產既不得繼續減價拍賣，僅以原價再行拍賣恐無實益 → 多數說：**不再行拍賣**（甲說／乙說代號請對講義，字幕聽不清）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「經兩次減價拍賣未拍定，是第幾拍？」 | **三拍**（一拍不減價，二拍起才減） |
| 「三拍未拍定，執行法院應如何？」 | 期日終結後 **10 日內公告**，三個月內依原條件應買＝特別變賣 |
| 「特別變賣是拍賣程序？」 | **否**，是**變賣**，無價格競爭 |
| 「特別變賣期間，債權人得否承受？」 | **得**（§95 I 後段） |
| 「第四拍是否必經程序？」 | **否**，須債權人於三個月內**聲請** |
| 「三個月內未聲請，亦無人應買？」 | **視為撤回**該不動產之執行 |
| 「第四拍債權人承受後未補繳差額，應同條件再拍？」 | 實務多數說：**不再拍賣**（恐無實益） |

## 一、§95 流程

```
三拍未拍定 + 債權人不承受
        │ 期日終結後 10 日內
        ▼
公告特別變賣：三個月內依原定拍賣條件應買（得詢問債權人、債務人意見後許其買受）
        │                     │
        │ 有人應買 / 債權人承受 → 結束換價
        │
        ├─ 三個月內債權人聲請 → 停止特別變賣 → 另行估價或減價拍賣（第四拍）
        │                              ├ 拍定或承受 → 結束換價
        │                              └ 仍未拍定且無人承受 → 視為撤回
        │
        └─ 三個月屆滿，無人應買、未聲請 → 視為撤回該不動產之執行
```

## 二、例題：第四拍承受後不補繳差額

| 步驟 | 內容 |
|---|---|
| 事實 | 一拍、二拍、三拍均未拍定 → 特別變賣 → 債權人聲請減價拍賣（第四拍）仍無人應買 → 債權人承受 → 執行法院限期命補繳差額，逾期未繳 |
| 爭點 | 依 §94 II 應同條件再行拍賣嗎？ |
| 一般情形 | 承受人不補繳 → 同條件再行拍賣（上一份筆記） |
| 本題 | 程序已走到最後，再減價不合法，原價再賣也賣不掉 → **不再拍賣** |
| 性質 | 法無明文，屬實務見解 |
