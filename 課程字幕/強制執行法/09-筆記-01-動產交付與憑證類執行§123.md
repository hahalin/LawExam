# 強制執行法09 筆記：動產交付與憑證類執行（§123）

## 一般動產（§123 I）：
- 執行方法只有一種：**取交**（執行法院將動產取來交債權人）＝移轉占有＝**直接強制**
- 一般動產（車、鑽戒、電視、花瓶、字畫）**不得**處怠金或管收——座談會否定說；§123 I 未準用 §128
- 債務人有隱匿情事 → 可依總則規定命限期履行或管收（字幕聽成「122 條」，推測為總則 §22，請對講義 324～326 頁）

## 書據、印章或其他相類憑證（§123 II）：
- 三種執行方法：① 取交 → 無效果 → ② 準用 §121 公告宣示未交出之憑證**無效**、另作證明書 ③ 準用 §128 I 定期履行、**處怠金或管收**
- 實務例：股東會議紀錄、資產負債表、原始憑證、記帳憑證、所有權狀 → 都是憑證類

## 合夥帳冊交付查閱：
- 重點在「解除占有、移轉支配」→ 動產交付；重點在「提供查閱、看內容」→ **不可代替行為**（§128）
- 題目看著重點；選擇題用刪去法

## 物之交付優先於行為請求權：
- 物之交付本質上也是行為，但強執法把它獨立成一章，解釋上**優先適用**（§123 是特別規定）

> 來源：強制執行法09 課程字幕 00:00:02 ~ 00:11:59（講義 324～326 頁）；所有權狀練習題 00:54:54 ~ 00:58:18（講義 336 頁）

## 📖 法條原文速查

> **強執 §121**　債務人應交出之書據、印章或其他相類之憑證而不交出者，執行法院得以公告宣示未交出之書據、印章或其他相類之憑證為**無效**，另作證明書發給債權人。
> **強執 §123**　I 執行名義係命債務人交付一定之動產而不交付者，執行法院得將該動產**取交**債權人。II 債務人應交付之物為**書據、印章或其他相類之憑證**而依前項規定執行**無效果**者，得準用第一百二十一條、第一百二十八條第一項之規定強制執行之。
> **強執 §128 I**　依執行名義，債務人應為一定之行為，而其行為非他人所能代為履行者，債務人不為履行時，執行法院得定債務人履行之期間。債務人不履行時，得處新臺幣三萬元以上三十萬元以下之**怠金**。其續經定期履行而仍不履行者，得再處怠金或**管收**之。
（條文原文請對六法；字幕老師唸 §123 II 為「準用 121 條第一項」，請對六法確認準用範圍）

## 📋 實務見解

> **座談會（否定說）**：一般動產（非書據印章類）債務人不交付，**不得**依 §128 處怠金或管收。強執法將物之交付請求權獨立於行為請求權另設一章，解釋上應優先適用；§123 I 未準用 §128。（座談會年度、字號請對講義 324～326 頁）

> **106 年實務見解**：執行名義命交付公司股東會議紀錄、資產負債表、原始憑證、記帳憑證 → 屬書據等相類憑證；執行法院發自動履行命令，債務人不履行，得準用 §128 處怠金。（字號請對講義 326 頁）

> **座談會（合夥帳冊查閱）**：判決主文並非著重於解除債務人對帳冊的占有，而是著重於債務人**提供債權人查閱** → 不可代替行為，依 §128 執行。（字號請對講義 324 頁）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「交付一般動產（汽車）之執行方法？」 | **取交**（§123 I），直接強制 |
| 「債務人不交付汽車，執行法院得處怠金？」 | **不得**。處怠金、管收**只限**書據、印章等憑證類 |
| 「命交付土地所有權狀，取交無效果，得公告宣示無效並另作證明書？」 | **得**（§123 II 準用 §121） |
| 「取交無效果，**不得**定期命交出並處怠金或管收？」 | **錯**。憑證類**得**準用 §128 I（考題陷阱就在「不得」） |
| 「交付物之執行，原則上第一步？」 | 實務先發**自動履行命令**（物之交付、行為不行為皆同） |
| 「命交付合夥帳冊供查閱，如何執行？」 | 看著重點：著重查閱內容 → **不可代替行為**（§128） |

## 一、§123 體系

```
執行名義命交付動產
├─ 一般動產（車、戒指、字畫）
│   └─ 只有「取交」；執行無效果 → 執行程序終結，不得改處怠金
└─ 書據、印章、其他相類憑證（§123 II）
    ├─ ① 取交（原則，仍是動產）
    ├─ ② 無效果 → 準用 §121：公告宣示未交出者無效、另作證明書
    └─ ③ 無效果 → 準用 §128 I：定期履行 → 處怠金 → 再處怠金或管收
```

- 為何憑證類可以用間接強制：特定的那一張憑證，別人無從代為交出，性質接近**不可代替行為**。
- 老師：題目選項看到股東會議紀錄、報表、會計憑證、記帳憑證、所有權狀 → 直接想到「三種方法」。

## 二、練習：命交付 A 地所有權狀（講義 336 頁，選錯誤者）

| 選項 | 判斷 | 理由 |
|---|---|---|
| A 先發自動履行命令命交出 | 正確 | 實務第一步 |
| B 拒絕交出 → 直接強制取交 | 正確 | 動產交付原則 |
| C 無效果 → 公告宣示無效、另作證明書 | 正確 | §123 II 準用 §121 |
| D 無效果 → **不得**定期命交出並處怠金管收 | **錯誤（答案）** | 應為「得」，§123 II 準用 §128 I |
