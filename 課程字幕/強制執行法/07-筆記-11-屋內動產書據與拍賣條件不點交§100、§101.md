# 強制執行法07 筆記：屋內動產書據與拍賣條件不點交（§100、§101）

## 屋內動產的處理（§100）：
- 房屋內、土地上的家具、生活用品不在執行範圍（除非與不動產**同時強制執行**）
- 步驟：① **取去點交**給債務人或其代理人、家屬、受僱人 → ② 無人接受 → **暫付保管**（實務常交拍定人保管）→ ③ 通知債務人**限期領取** → ④ 逾期不領 → **拍賣提存價金**或其他適當處置
- §99 的第三人（如被點交的承租人）留下的動產，同樣適用（§100 III）
- 實務上拍定人常要自找倉庫、搬家公司，是買法拍屋的成本

## 書據的處理（§101）：
- 債務人應交出書據而拒絕 → ① **取交**債權人或買受人（直接強制）② **公告宣示**未交出之書據**無效**，另作證明書
- 書據主要是證明功能，不一定要原本；較重要的是之後非金錢執行的 §123

## 例題：拍賣條件為不點交，拍定後主張租約是假的：
- 丁依「不點交」條件拍定，繳尾款前取得切結書稱租約為假，聲明異議請求改為點交
- 聲明異議**合法**：A 地個別執行程序尚在換價階段（拍定後還有繳價金、發證書、點交），**未終結**
- 但**無理由**：不點交是拍賣公告的條件，拍定後**不得為相反主張**；執行法院也無權判斷切結書真偽（不審查實體）
- 結論：執行法院應**駁回**異議，不得撤銷拍定、不得更正拍賣條件

## 📖 法條原文速查

> **強執 §100**　I 房屋內或土地上之動產，除應與不動產同時強制執行外，應**取去點交**債務人或其代理人、家屬或受僱人。
> II 無前項之人接受點交時，應將動產**暫付保管**，向債務人為**限期領取**之通知，債務人逾限不領取時，得**拍賣之而提存其價金**，或為其他適當之處置。
> III 前二項規定，於前條之第三人適用之。
> **強執 §101**　債務人應交出之書據而拒絕交出時，執行法院得將書據**取交**債權人或買受人，並得以**公告宣示未交出之書據無效**，另作證明書發給債權人或買受人。
> **強執 §12 I**　當事人或利害關係人，對於執行法院強制執行之命令，或對於執行法官、書記官、執達員實施強制執行之方法，強制執行時應遵守之程序，或其他侵害利益之情事，得於強制執行程序**終結前**，為聲請或聲明異議。……
（條文原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「屋內家具債務人不搬，執行法院即得拍賣？」 | **錯**，先取去點交 → 暫付保管 → 限期領取 → 逾期才拍賣提存 |
| 「承租人被點交後留下的動產？」 | 同樣適用 §100（III） |
| 「債務人拒交書據，法院得如何？」 | **取交**；並得**公告宣示無效**、另作證明書 |
| 「拍定後聲明異議，因拍賣程序已終結不合法？」 | **錯**，個別執行程序未終結，異議**合法** |
| 「以不點交為條件拍定，拍定人事後證明租約虛偽，請求改為點交？」 | **無理由**，應駁回；不得撤銷拍定或更正條件 |

## 一、§100 四步驟

```
屋內動產（不在執行範圍）
  │
  ▼ ① 取去點交 → 債務人／代理人／家屬／受僱人
  │      └ 有人接受 → 結束
  ▼ ② 無人接受 → 暫付保管（常交拍定人）
  ▼ ③ 通知債務人限期領取
  ▼ ④ 逾期不領 → 拍賣、提存價金，或其他適當處置
（§99 的第三人亦同）
```

## 二、假租約例題逐項判斷

| 選項 | 判斷 | 理由 |
|---|---|---|
| A 拍賣程序已拍定終結，異議不合法 | ✗ | A 地個別執行程序仍在換價階段，未終結 → 合法 |
| B 撤銷原拍定、重為拍賣 | ✗ | 異議無理由 |
| C 依丁之異議更正拍賣條件為點交 | ✗ | 拍定後不得為相反主張 |
| D 不點交為拍賣條件，拍定後不得為相反主張，應駁回 | ✓ | 合法但無理由 |

- 拍賣法律關係：拍賣公告＝要約之引誘（條件寫在公告上）、投標＝要約、拍定＝承諾。條件是買賣內容的一部分，拍定後不能單方改。
- 為什麼債務人要做假租約：有租約就不點交，想藉此讓房子不好賣。
