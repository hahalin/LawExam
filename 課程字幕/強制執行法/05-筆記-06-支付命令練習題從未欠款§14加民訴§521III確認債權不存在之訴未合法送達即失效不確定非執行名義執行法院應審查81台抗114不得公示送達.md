# 強制執行法05 筆記：練習題——甲持 A 法院核發「乙應給付甲 100 萬」之**支付命令＋確定證明書**（§4 I ②「其他依民事訴訟法得為強制執行名義者」；104 年民訴修法後支付命令確定**僅有執行力、無既判力**，民訴 §521 I），向乙住所地 A 法院聲請執行乙之動產與土地。①乙主張**從未欠款** → 實體瑕疵 → **債務人異議之訴 §14**（二選一題：不是聲明異議）；另有民訴 **§521 III**：得提**確認債權不存在之訴**，亦為停止執行事由。②乙具狀向執行處聲明**從未收到支付命令** → 民訴：支付命令 3 個月內未合法送達即**失其效力**（§515）、未送達不起算 20 日異議期間、不會確定 → **不是執行名義**；支付命令**不得公示送達、不得於外國送達**（§509）→ 執行法院**應審查**是否合法送達（執行名義成立之合法要件，執行處有獨立審查權，**81 台抗 114**：不受確定證明書拘束）

> 來源：強制執行法05 課程字幕 00:58:40 ~ 01:03:40（講義 175～176 頁）

## 📖 法條原文速查

> **民訴 §521 I**　債務人對於支付命令未於法定期間合法提出異議者，支付命令得為執行名義。
> **民訴 §521 III**　債務人主張支付命令上所載債權不存在而提起確認之訴者，法院依債務人聲請，得許其提供相當並確實之擔保，停止強制執行。（項次請對原文）
> **民訴 §515 I**　發支付命令後，三個月內不能送達於債務人者，其命令失其效力。
> **民訴 §509**　督促程序，如聲請人應為對待給付尚未履行，或支付命令之送達應於外國為之，或依公示送達為之者，不得行之。
> **民訴 §516 I**　債務人對於支付命令之全部或一部，得於送達後二十日之不變期間內，不附理由向發命令之法院提出異議。
> **強執 §4 I ②**　依民事訴訟法成立之和解或調解；（§4 I 各款款次請對原文，支付命令屬「其他依民事訴訟法得為強制執行名義者」）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「確定之支付命令為執行名義，債務人主張從未欠款，聲明異議或異議之訴？」 | **債務人異議之訴 §14**（實體瑕疵）。支付命令無既判力 → 債權不存在（成立前事由）亦得主張（§14 II） |
| 「除 §14 外還有什麼救濟？」 | 民訴 **§521 III 確認債權不存在之訴**，並得聲請停止執行（民訴那邊的規定，別忘） |
| 「債務人稱從未收到支付命令，執行法院應否審查？」 | **應審查**。未合法送達 → 不起算 20 日異議期間 → 不會確定（3 個月未送達即失效）→ 不是執行名義 → 執行名義成立之合法要件執行處得審查，不受確定證明書拘束（81 台抗 114） |
| 「支付命令得否公示送達？」 | **不得**（亦不得於外國送達，民訴 §509）。支付命令必須實際送達 |
| 「支付命令現在有無既判力？」 | **無**，僅執行力（104 年修法前與確定判決同一效力，現已刪除）。所以 §14 不畫基準時圖 |

## 一、兩小題邏輯鏈

```
①從未欠款 → 實體 → §14（＋民訴 §521 III 確認之訴，皆得停止執行）
②從未收到 → 未合法送達 → 不起算異議期間 → 不確定（3 月內未送達失效）
   → 非執行名義 → 執行處應審查（81 台抗 114）
```
