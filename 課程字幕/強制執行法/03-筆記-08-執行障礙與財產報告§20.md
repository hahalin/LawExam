# 強制執行法03 筆記：執行障礙與財產報告（§20）

## 執行障礙：
- 妨礙執行**開始或續行**之事由＝強制執行開始之**消極要件**，執行法院**依職權調查**
- 多為**一般執行**（對總財產之總清算）優先於個別執行：**破產**、破產法上**和解**、公司**重整**、消債條例**更生、清算**

## 執行調查：
- 無庸傳訊當事人（§9）；事項範圍有疑義**應調閱卷宗**（§8）
- 命債權人查報或職權調查（§19，詳筆記 03）

## 命債務人報告財產（§20）：
- 已發現財產**不足抵償**，或**不能發現**應交付之財產 → **得**命債務人報告**期間屆滿前一年內**之財產狀況
- 不報告或虛偽報告 → **得**命提供擔保或限期履行 → 仍不遵守 → **得管收**（須先訊問、認非不能報告）
- **假扣押**等保全執行名義**不得**聲請（國考考過，答案 C）

## 執行登記（§11）：
- 財產權變動依法應登記者，執行法院**應**通知登記機關登記執行事由（查封登記）；得交債權人逕持送
- 因繼承等登記前已取得不動產 → 得以**債務人費用**代辦登記後執行（詳筆記 02-10）

## 📖 法條原文速查

> **強執 §20 I**　已發見之債務人財產**不足抵償**聲請強制執行之債權或**不能發現**債務人應交付之財產時，執行法院得依債權人聲請或依職權，定期間命債務人據實報告該期間屆滿前**一年內**應供強制執行之財產狀況。
> **強執 §20 II**　債務人違反前項規定，不為報告或為虛偽之報告，執行法院得依債權人聲請或依職權，命其**提供擔保或限期履行**執行債務。
> **強執 §20 III**　債務人未依前項命令提供相當擔保或遵期履行者，執行法院得依債權人聲請或依職權**管收**債務人。但未經訊問債務人，並認其非不能報告財產狀況者，不得為之。
> **強執 §8 I**　關於強制執行事項及範圍發生疑義時，執行法院**應調閱卷宗**。
> **強執 §11 I**　供強制執行之財產權，其取得、設定、喪失或變更，依法應登記者，為強制執行時，執行法院**應即通知**該管登記機關登記其事由。
> **消債條例 §48 II**　法院裁定開始更生程序後，對於債務人**不得開始或繼續**訴訟及強制執行程序（但書請對六法）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人受破產宣告、公司重整、更生清算中，強制執行？」 | 屬**執行障礙**，總清算程序優先，個別執行不得開始或繼續 |
| 「執行障礙由當事人主張始審查？」 | **錯**，執行法院**依職權調查** |
| 「持**假扣押裁定**聲請命債務人報告財產狀況，應准許？」 | **不應准許**（考過）。§20 之「抵償」含**滿足**之意，限**終局執行**名義 |
| 「債務人拒絕報告財產，執行法院應即管收？」 | **錯**。先命供擔保或限期履行；仍不遵守才「**得**」管收，且須先**訊問** |
| 「§20 命報告之期間範圍？」 | 期間屆滿前 **一年內** 之財產狀況 |
| 「財產權依法應登記者，執行法院得通知登記？」 | 「**應**」即通知（§11 I）；得交債權人逕行持送（§11 II） |

## 一、執行障礙體系

```
一般執行（總財產總清算）＞ 個別執行（強制執行）
├── 破產程序
├── 破產法上和解
├── 公司法上公司重整
└── 消債條例更生、清算（§48 II）
→ 發生時：強制執行不得開始或續行（依職權調查）
```

## 二、§20 三階段

```
① 財產不足抵償／找不到應交付之物（例：解除婚約應返還之鑽戒）
       ↓ 得命報告（前一年內財產狀況）
② 不報告或虛偽報告
       ↓ 得命提供擔保或限期履行
③ 仍不提供、不履行
       ↓ 得管收（人身自由限制 → 先訊問＋管收必要性）
全部都是「得」，沒有「應管收」
```

## 三、國考題：假扣押能否用 §20

```
甲持假扣押裁定 → 執行乙財產 → 發現不足且乙有隱匿
→ 聲請命乙報告前一年內財產狀況
→ 答案 C：應駁回
理由：「不足抵償」指為清償（滿足）而為之終局執行；假扣押債權尚未確定，只到保全
```

## 四、§11 執行登記

| 項 | 內容 |
|---|---|
| I | 依法應登記之財產權 → 應通知登記機關登記執行事由（如查封登記，謄本可查） |
| II | 得交債權人逕行持送 |
| III | 繼承、強制執行、徵收、判決於登記前已取得 → 得以債務人費用登記後執行 |
| IV | §5 III 續行執行須辦繼承登記者準用；不影響拋棄、限定繼承 |
| 行政管理登記 | 如汽機車監理登記，與權利得喪無關，**宜**通知 |
