# 強制執行法08 筆記：特殊移轉命令（§115-1 IV）

## 意義：
- 對**繼續性給付債權**（薪資、租金）核發的移轉命令
- 形式上結案（案件得報結、執行名義正本註記後發還債權人）；但**未到期部分**尚未發生債權讓與 → **實質上未終結**

## 失效與復活（§115-1 IV）：
- 債務人**喪失其權利**（離職）或第三人**喪失支付能力**（公司倒閉）→ 未受清償部分移轉命令**失效**
- 得聲請**繼續執行**，**免徵執行費**——唯一「移轉命令結案後還能復活」的情形

## 其他債權人加入（注意事項 62 之 1 第 5 項）：
- 他債權人就同一債務人同一繼續性給付債權聲請**併案執行（§33）或參與分配（§32）**→ 可以
- 執行法院**撤銷未到期部分**之移轉命令，**改發按債權額比例之移轉命令**；已到期部分不動

## 債權人陳明已清償或撤回：
- 執行法院應**撤銷未到期部分**之移轉命令（未到期薪資債權尚未移轉）

## 📖 法條原文速查

> **強執 §115-1 IV**　第一項債務人於扣押後應受及增加之給付，執行法院得以命令**移轉**於債權人。但**債務人喪失其權利或第三人喪失支付能力**時，債權人債權未受清償部分，移轉命令**失其效力**，得聲請**繼續執行**。並**免徵執行費**。
> **強執注意事項 62 之 1**（點次請對講義）
> III 對繼續性給付債權核發移轉命令後，案件得報結，並於執行名義正本註記執行案號、執行費用及第三人名稱等字句，……後將之發還債權人。
> V 執行法院對繼續性給付債權核發移轉命令後，經其他債權人就同一債務人之同一繼續性給付債權聲請併案執行或參與分配者，執行法院應**撤銷未到期部分之移轉命令**，改發按各該參與分配或併案執行債權額**比例之移轉命令**。
（注意事項原文請對講義；字幕把「繼續性給付」聽成「金錢給付／幾付／機遇給付」）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「特殊移轉命令是什麼？」 | 對**繼續性給付債權**所核發之移轉命令 |
| 「發移轉命令後債務人離職，債權人未受償部分？」 | 移轉命令**失效**，得聲請**繼續執行**，**免徵**執行費 |
| 「一般移轉命令也可因第三人無資力而失效、繼續執行？」 | **不可**，只有 §115-1 IV |
| 「對薪資發移轉命令後，丁聲請參與分配，應否准許？」 | **應准許**：撤銷**未到期**部分，改發**比例**移轉命令 |
| 「已到期而移轉給甲的薪資，丁也能分？」 | **不能**，已到期部分真正終結 |
| 「債務人清償後債權人具狀撤回，請求撤銷移轉命令？」 | **應撤銷**（未到期部分），否則每月繼續扣薪 |

---

## 一、為什麼會有特殊移轉命令

- 對薪資發移轉命令本來不太合理（將來薪資沒有確切面額），實務為了**案件報結**（未結案量的行政管考）而核發。
- 結果債務人一被執行就離職、被解僱、留職停薪，債權人落空 → 發展出「失效可復活」的規定。

## 二、時間軸

```
          特殊移轉命令生效
                 │
 已到期（已逐月債權讓與）│ 未到期（每月到期時才債權讓與）
 ────────────────────────┼──────────────────────────▶
 真正終結，他人不能分      實質未終結
                          ├ 丁參與分配 → 撤銷未到期部分＋改發比例移轉命令
                          ├ 債權人撤回 → 撤銷未到期部分
                          └ 乙離職／丙倒閉 → 失效 → 繼續執行、免徵執行費
```

## 三、一般移轉命令 vs 特殊移轉命令（講義 304 頁）

| | 一般移轉命令 | 特殊移轉命令 |
|---|---|---|
| 對象 | 有確切面額之金錢債權 | 繼續性給付債權 |
| 債權讓與 | 送達第三人生效即讓與 | 每期到期時才讓與 |
| 程序終結 | 生效即終結 | 形式終結、未到期部分**實質未終結** |
| 他債權人加入 | 不可（已終結） | 可：撤銷未到期部分＋比例移轉命令 |
| 債權落空 | 甲自行另訴 | 失效、繼續執行、免徵執行費（§115-1 IV） |

## 四、練習

1. 甲對乙任職丙公司之每月薪資，依 §115-1 IV 核發移轉命令；乙之另一債權人丁聲請參與分配 → **應准許**，撤銷未到期部分移轉命令，改發比例移轉命令。
2. 扣押乙薪資並核發移轉命令後，因債務協商或乙聲請清算，甲具狀陳明已受清償或撤回 → 未到期部分**應予撤銷**。
