# 強制執行法01 筆記：強制執行的種類

## 依效果：
- **終局執行**：可做到**滿足**（查封、換價、滿足整套）；確定判決、**假執行**
- **保全執行**：原則只做到**查封**；假扣押、假處分（例外：定暫時狀態處分可到滿足，見筆記 08）

## 依財產範圍：
- 強制執行＝**個別執行**（依聲請、就個別財產）
- 破產、消債條例更生清算＝**一般執行**（總財產總清算）
- 兩者互斥；競合時**一般執行優先**，強制執行停下來

## 依對象與請求權：
- 對物執行為原則；對人執行很少（**拘提、管收**）
- 金錢請求權（第二章，條文最多、最常考）vs 非金錢：**物之交付**（第三章）、**行為不行為**（第四章）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「假執行屬保全執行？」 | **錯**。假執行是**終局執行**，可做到滿足 |
| 「假扣押之執行得將扣押之金錢交付債權人？」 | **不得**。保全執行原則只到**查封**，不換價、不分配 |
| 「強制執行程序中債務人受破產宣告？」 | 一般執行**優先**於個別執行，強制執行停止，由破產管理人主導 |
| 「強制執行法之對人執行方法？」 | **拘提、管收** |
| 「非金錢請求權之執行包括？」 | **物之交付**請求權、**行為不行為**請求權 |
| 「強制執行法各章中考試頻率最高者？」 | 第二章**金錢請求權**之執行 |

## 一、條文體系（講義 3 頁，全法共 142 條）

```
第一章 總則（基本觀念、當事人、管轄……）
┌ 第二章 關於金錢請求權之執行   ← 條文最多、考最多
│ 第三章 關於物之交付請求權之執行  （交還車、房、土地）
└ 第四章 關於行為及不行為請求權之執行（開演唱會、修漏水、夜間不彈琴）
第五章 假扣押假處分之執行（保全執行）
第六章 附則（不考）
```

## 二、分類總表

| 區分標準 | 種類 | 重點 |
|---|---|---|
| 執行效果 | 終局執行 / 保全執行 | 能否做到「滿足」 |
| 被執行財產範圍 | 個別執行 / 一般執行 | 一般執行優先 |
| 執行對象 | 對物執行 / 對人執行 | 對人＝拘提、管收 |
| 實現之請求權 | 金錢 / 非金錢 | 非金錢＝物之交付＋行為不行為 |
| 執行方法 | 直接強制 / 代替執行 / 間接強制 | 見筆記 05 |

## 三、終局 vs 保全

```
終局執行：查封 ──► 換價 ──► 滿足   （確定判決、假執行）
保全執行：查封 ─┤停                 （假扣押、假處分）
                 └ 例外：定暫時狀態處分（滿足性處分）可能到滿足
```

- 假扣押例：起訴前聲請假扣押裁定 → 到執行處執行 → 在 100 萬範圍內凍結債務人財產，防止訴訟中脫產；錢先扣在法院，債權人還拿不到。

## 四、個別 vs 一般執行

| 比較 | 個別執行 | 一般執行 |
|---|---|---|
| 例 | 強制執行 | 破產、更生、清算 |
| 對象 | 個別財產，依聲請 | 總財產總清算 |
| 競合 | 停止 | **優先** |

## 五、金錢 vs 非金錢

- 物之交付與行為義務有時重疊（例：拆屋還地，一個執行程序混用多種方法）。
- 金錢債權與另兩者完全不同（查封、換價、滿足三階段）。
