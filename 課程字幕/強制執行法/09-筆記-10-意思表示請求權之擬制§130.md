# 強制執行法09 筆記：意思表示請求權之擬制（§130）

## 擬制，不是執行：
- 命債務人為一定意思表示，本質是不可代替行為；但債權人要的只是法律效果 → 法律直接**擬制**債務人已為意思表示
- 聲請執行是多此一舉 → 執行法院**駁回**（選擇題考很多次）
- 例：協同辦理不動產所有權移轉登記、塗銷抵押權 → 單獨持判決或和解筆錄向地政機關辦理（土地登記規則 §27 ④）

## 限確定判決或同一效力之執行名義：
- 確定判決、訴訟上和解、民訴調解、鄉鎮市調解經法院核定、確定之仲裁判斷 → 有擬制效力
- 公證書等其他執行名義 → **沒有**
- **不得宣告假執行**：假執行判決尚未確定，若生擬制效力等於讓效力提前發生；誤宣告者，執行法院駁回聲請

## 擬制時點：
- 判決 → **確定時**；和解、調解 → **成立時**
- 有對待給付者：債權人須**先給付**，以 ① 提存 ② 執行法院給予證明書 ③ 公證人公證，三擇一證明後才擬制（無同時履行抗辯可言）

## 擬制的界限：
- 只擬制「意思表示」，不及於其他要件：所有權移轉仍要**辦完登記**才生物權效力
- 票據背書：除意思表示外還要事實行為 → 不可代替，依 §128
- 股票過戶：公司須承認股東並記載股東名簿 → 不可代替，依 §128 執行（執行法院仍受理）
- **公法上意思表示**（撤回起訴、撤回假扣押執行聲請、撤回告訴）不包括 → 不能執行
- 擬制沒有執行程序 → 不能依 §18 聲請停止執行

## 📖 法條原文速查

> **強執 §130**　I 命債務人為一定之意思表示之判決**確定**或其他與確定判決有同一效力之執行名義**成立**者，**視為**自其確定或成立時，債務人已為意思表示。II 前項意思表示有待於**對待給付**者，於債權人已為**提存**或執行法院就債權人已為對待給付給予**證明書**時，視為債務人已為意思表示。**公證人**就債權人已為對待給付予以公證時，亦同。
> **土地登記規則 §27 ④**　下列登記由權利人或登記名義人**單獨申請**之：……四、因法院、行政執行分署或公正第三人拍定、**法院判決確定**之登記。
> **公司法（股東名簿）**　股份轉讓非將受讓人姓名、住所記載於股東名簿，不得對抗公司。（字幕老師唸 §169；對抗要件應在 §165，請對六法）
（條文原文請對六法）

## 📋 實務見解

> **股票過戶登記**：確定判決命辦理股票過戶登記，非僅由債務人為一定意思表示即可達執行目的；債務人除承認債權人為股東外，並應將其姓名等記載於股東名簿，始生對抗公司效力，該行為具**不可代替性** → 依 §128 執行，非 §130。（字號請對講義 352 頁）

> **意思表示判決誤宣告假執行（專利移轉登記）**：命債務人為一定意思表示之判決，於判決確定時始視為已為意思表示，無待於執行，更無於判決確定前為假執行之餘地；原法院認不得據以強制執行、駁回聲請，並無違誤。（字號請對講義 354 頁）

> **和解筆錄「同意撤回假扣押執行聲請」**：訴訟權之實施與否屬公法上權利，除有例外規定或承認訴訟契約外，不得以和解筆錄代之，不生撤回效力，執行法院不得啟封（否定說；教科書同採否定說，學者姓名字幕為「張登科」，請對講義 354～356 頁）。源頭：公法上撤回之意思表示本不得為民事訴訟標的。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「持命協同辦理所有權移轉登記之確定判決聲請執行？」 | **駁回**——§130 擬制，單獨持判決辦登記 |
| 「和解筆錄載明塗銷抵押權？」 | 同上，和解與確定判決同一效力 → 擬制，駁回執行 |
| 「命為意思表示之判決得宣告假執行？」 | **不得** |
| 「擬制時點？」 | 判決**確定時**；和解、調解**成立時** |
| 「意思表示有待對待給付？」 | 債權人先為對待給付：**提存／執行法院證明書／公證** |
| 「判決確定即視為所有權移轉登記完畢？」 | **錯**。只擬制意思表示，仍須辦理登記 |
| 「命辦理股票過戶登記？」 | **§128** 不可代替（非 §130），執行法院應受理 |
| 「和解約定撤回假扣押執行聲請，得據以聲請執行？」 | **不得**（公法上意思表示） |
| 「§130 擬制得依 §18 聲請停止執行？」 | **不得**，無執行程序可停 |

## 一、356 頁選擇題：何者須聲請執行始得實現？

| 選項 | 內容 | 歸類 |
|---|---|---|
| A | 命將土地所有權移轉登記 | §130 擬制，不必執行 |
| B | 命就 A 地以 350 萬元同一條件與甲訂立買賣契約 | §130 擬制（訂約的意思表示） |
| **C** | **命在某報刊登啟事向甲道歉** | **§127 可代替 → 須聲請執行（當年答案）** |
| D | 命協同甲向監理機關辦理 B 車過戶 | §130 擬制（行政管理登記也可） |

- 111 年憲判字第 2 號後已不能強制道歉，C 現在是「歷史遺跡」；改考「判決主文登報」仍是 §127 可代替。

## 二、擬制的射程

```
§130 擬制「債務人已為意思表示」
├─ 及於：移轉所有權、訂立契約、塗銷抵押權、車輛過戶之意思表示
└─ 不及於：
    ├─ 登記本身（仍要去地政辦）
    ├─ 事實行為（票據背書）→ §128
    ├─ 第三人行為（公司記載股東名簿）→ §128
    └─ 公法上意思表示（撤回起訴、撤回執行聲請）→ 不能執行
```
