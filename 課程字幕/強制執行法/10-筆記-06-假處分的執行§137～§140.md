# 強制執行法10 筆記：假處分的執行（§137～§140）

## 假處分的特色：
- 保全**金錢請求以外**之請求（民訴 §532）→ 內容五花八門，但概念仍是**凍結、不准動**
- 「不得移轉、讓與、設定他項權利及其他一切處分行為」＝實質上就是**查封**（不動產：現場查封＋查封登記）
- 股票、支票「不得讓與、提示、付款」→ 準用其他財產權，發**扣押命令**

## 30 日與不作為：
- 聲請執行期間同為收受裁定後 **30 日**
- **單純不作為**之假處分（禁止夜間彈琴、禁止執行職務）→ 債務人未違反就**沒有執行問題**，**不適用 30 日**；違反時才依 §129 聲請處怠金（法無明文，依性質推論）

## 執行方法（§140 準用）：
- 準用假扣押、金錢請求權、行為不行為請求權執行之規定 → 依裁定內容挑最適合的程序
- §137 選任**管理人** → 使管理人**占有**其物
- §138 命令或禁止債務人為一定行為 → 執行法院應將裁定**送達**債務人（選擇題很愛考）
- §139 禁止設定、移轉、變更**不動產上權利** → 應將裁定**揭示**

## 生效與效力：
- 禁止移轉土地：準用 §76，查封登記通知**到達**地政即生**執行（查封）效力**，不待裁定送達債務人；但民訴**抗告期間**仍從送達起算
- 停止執行職務：送達後喪失權限，所為行為無效
- 禁止處分、禁止移轉占有：違反行為**相對無效**（準用 §51 II，對債權人不生效力）
- 移本案執行：無庸重複程序

## 📖 法條原文速查

> **強執 §137**　假處分裁定，應選任**管理人**管理系爭物者，於執行時，執行法院應使管理人**占有其物**。
> **強執 §138**　假處分裁定，係**命令或禁止債務人為一定行為**者，執行法院應將該裁定**送達**於債務人。
> **強執 §139**　假處分裁定，係禁止債務人設定、移轉或變更**不動產上權利**者，執行法院應將該裁定**揭示**。
> **強執 §140**　假處分之執行，除前三條規定外，**準用**關於假扣押、金錢請求權及行為、不行為請求權執行之規定。
> **強執 §51 II**　實施查封後，債務人就查封物所為移轉、設定負擔或其他有礙執行效果之行為，**對於債權人不生效力**。
> **民訴 §532 I**　債權人就**金錢請求以外之請求**，欲保全強制執行者，得聲請假處分。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「假處分命令或禁止債務人為一定行為，執行法院應如何？」 | **送達**裁定於債務人（§138）——選擇題常考 |
| 「假處分禁止移轉不動產權利？」 | 應將裁定**揭示**（§139）＋查封登記 |
| 「假處分選任管理人？」 | 使管理人**占有**其物（§137） |
| 「禁止夜間彈琴之假處分，收受裁定 40 日後債務人才違反，得聲請執行？」 | **得**。單純不作為假處分不受 30 日限制，依 §129 處怠金 |
| 「土地禁止移轉假處分，何時發生查封效力？」 | 查封登記通知**到達**地政時；不待送達債務人 |
| 「違反禁止處分假處分所為之移轉，絕對無效？」 | **錯**，**相對無效**，對債權人不生效力（準用 §51 II） |
| 「支票禁止提示付款之假處分，用何程序？」 | 準用**其他財產權**執行，發扣押命令 |

## 一、看裁定內容挑準用對象（§140）

```
假處分裁定內容
├─ 禁止移轉、處分不動產 → 查封（§76）＋揭示（§139）
├─ 禁止讓與股票、提示支票 → 其他財產權：扣押命令（§115、§117）
├─ 選任管理人 → 管理人占有（§137）
├─ 命令／禁止一定行為（停止執行職務）→ 送達債務人（§138）；違反 → §129 怠金
└─ 單純不作為（禁止彈琴）→ 未違反無執行；違反 → §129
```

## 二、兩種「生效」不要混

| | 執行（查封）效力 | 民訴抗告期間 |
|---|---|---|
| 起點 | 現場查封或查封登記到達（以先者為準） | 裁定**送達**時 |
| 未送達債務人時 | 已生效 | 尚未起算 |

## 三、效力整理

| 假處分類型 | 違反時 |
|---|---|
| 停止執行職務 | 送達後喪失權限，行為**無效** |
| 禁止處分 | **相對無效**（對債權人不生效力） |
| 禁止移轉占有 | 移轉對債權人不生效力，債權人得起訴主張 |
