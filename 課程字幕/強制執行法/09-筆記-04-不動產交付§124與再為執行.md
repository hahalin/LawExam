# 強制執行法09 筆記：不動產交付（§124）與再為執行

## 執行方法：
- **解除債務人之占有，使歸債權人占有**（§124 I 前段）＝移轉占有＝直接強制（不動產搬不走，所以是把人請走）
- 船舶、航空器、建造中船舶 → 準用前二項（§124 III）

## 廣義債務人：
- §124 的債務人包括受僱人、學徒、與債務人**同居一家**共同生活者、其他受債務人指示而有管領力之人（占有輔助人、家屬）
- 例：妻單獨與房東簽租約、夫妻同住不搬 → 夫雖非執行名義當事人，也可一併排除占有，**不必另取執行名義**（肯定說）

## 屋內動產（§125 準用 §100）：
- ① 取去點交債務人或其家屬 → ② 無人接受 → 暫付保管、限期領取通知 → ③ 逾期不領 → 拍賣提存價金或其他適當處置
- 第三人的動產同樣處理；債權人不能把東西亂丟

## 再為執行（§124 I 後段、II）：
- 解除占有後債務人**復即占有** → 依聲請**再為執行**，用原執行名義，但應**再徵執行費**
- 「復即」：與前次執行時間要有相當密接性，個案判斷
- **動產交付沒有**再為執行；強執法三處有：§99（再行點交）、§124（不動產交付）、§129 III（不作為）

## 📖 法條原文速查

> **強執 §124**　I 執行名義係命債務人交出不動產而不交出者，執行法院得**解除債務人之占有，使歸債權人占有**。如債務人於解除占有後，**復即占有**該不動產者，執行法院得依聲請**再為執行**。II 前項再為執行，**應徵執行費**。III 執行名義係命債務人交出船舶、航空器或在建造中之船舶而不交出者，準用前二項規定。
> **強執 §125**　關於動產、不動產執行之規定，於前二條情形準用之。
> **強執 §100**　I 房屋內或土地上之動產，除應與不動產同時強制執行外，應**取去點交**債務人或其代理人、家屬或受僱人。II 無前項之人接受點交時，應將動產**暫付保管**，向債務人為限期領取之通知，債務人逾限不領取時，得**拍賣之而提存其價金**，或為其他適當之處置。III 前二項規定，於前條之第三人適用之。
（條文原文請對六法）

## 📋 實務見解

> **夫妻承租案（肯定說）**：§124 所指債務人，包括債務人之受僱人、學徒或與債務人共同生活而同居一家，或基於其他類似關係，受債務人指示而對之有管領力者在內。夫妻同戶居住共同生活，非租約當事人之夫亦得一併執行。（出處請對講義 330 頁後）

> **再為執行之意旨**：明文「復即占有」係為維持執行效果、防止債務人取巧、避免債權人訟累；復即占有與前次執行相隔時間不宜過長，個案判斷。（出處請對講義 330 頁後）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「交付不動產之執行方法？」 | **解除債務人占有，使歸債權人占有**（直接強制） |
| 「執行名義僅對妻，同住之夫不搬？」 | 夫屬**廣義債務人**（同居一家），得一併排除，不必另取執行名義 |
| 「債務人解除占有後隔兩三天又搬回？」 | 得依聲請**再為執行**，用原執行名義，**應再繳執行費** |
| 「交付汽車後債務人又偷開回去，得再為執行？」 | **不得**。動產交付**無**再為執行規定，須另訴 |
| 「屋內有債務人的家具？」 | §125 準用 §100：取去點交 → 暫付保管、限期領取 → 拍賣提存價金 |
| 「交付船舶、航空器？」 | 準用不動產交付（§124 III） |

## 一、§124 執行流程

```
執行名義命交出不動產
   ↓（實務先發自動履行命令）
解除債務人（含家屬、受僱人、占有輔助人）之占有
   ↓
使歸債權人占有 ── 屋內動產：§125 → §100 取去點交／暫付保管／拍賣提存
   ↓
債務人「復即占有」
   ↓
債權人聲請再為執行（原執行名義＋再繳執行費）
```

## 二、再為執行三處比較

| 條文 | 情形 | 共通點 |
|---|---|---|
| §99 | 拍定人聲請點交後，債務人等又占有 → 再行點交 | 不必另取執行名義 |
| **§124 I 後段** | 不動產交付後債務人復即占有 | 但都要**再繳執行費** |
| §129 III | 不作為執行除去行為結果後，債務人復行違反 | （使用者付費） |

- 動產交付（§123）沒有 → 選項寫「交付動產後債務人復占有，得再為執行」是錯的。
- 字幕中老師一度把三處講成「127、125」，隨即更正為 §99、§124、§129（01:40:03 前後）。
