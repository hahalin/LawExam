# 強制執行法05 筆記：參與分配的「天選之人」——對執行標的物有**擔保物權或優先受償權**之債權人（99.9% 考**抵押權人**；另質權、留置權、海商法船舶優先權等）：**§34 I** 一般債權人參與分配應提出**執行名義**證明文件；**§34 II** 擔保物權／優先受償權人**不問其債權已否屆清償期**，應提出**權利證明文件**（設定文件即可，**不須執行名義**，連拍賣抵押物裁定都不用）聲明參與分配 → 學說稱**強制列入參與分配**（II、III 一組）；**原因＝§98 III 塗銷主義**：存於不動產上之抵押權及其他優先受償權**因拍賣而消滅**（拍定人買到乾淨的物、法律關係不複雜化）→ 抵押權要被塗銷，所以必須把抵押權人拉進來分錢保護他、且逼他提前受償；**§34 III** 執行法院知有前項債權人者**應通知**，不知住居所或不知孰為債權人者以適當方法通知或公告；經通知或公告**仍不聲明者，執行法院仍就已知債權及金額列入分配**（不來也強制列入）；其應徵收之執行費**於執行所得金額扣繳**（被動加入，不先繳）；**§34 IV** 第二項債權人不聲明參與分配、其債權金額又非執行法院所知者 → 該債權對執行標的物之**優先受償權因拍賣而消滅**，已列入分配而未受清償部分亦同（呼應 §98 III；例外 §98 III 但書拍定人與抵押權人另有約定，以後講）；**§34 V** 執行法院於 I、II 情形應通知各債權人及債務人；**§34-1** 政府機關對義務人有**公法上金錢債權**、依行政執行法得移送執行者，得檢附證明文件聲明參與分配（欠稅、健保費、罰單；次序依特別法，稅捐多優先）

## 📖 法條原文速查

> **強執 §34 I**　有執行名義之債權人聲明參與分配時，應提出該執行名義之證明文件。
> **強執 §34 II**　依法對於執行標的物有擔保物權或優先受償權之債權人，不問其債權已否屆清償期，應提出其權利證明文件，聲明參與分配。
> **強執 §34 III**　執行法院知有前項債權人者，應通知之。知有債權人而不知其住居所或知有前項債權而不知孰為債權人者，應依其他適當方法通知或公告之。經通知或公告仍不聲明參與分配者，執行法院僅就已知債權及其金額列入分配。其應徵收之執行費，於執行所得金額扣繳之。
> **強執 §34 IV**　第二項之債權人不聲明參與分配，其債權金額又非執行法院所知者，該債權對於執行標的物之優先受償權，因拍賣而消滅，其已列入分配而未受清償部分，亦同。
> **強執 §34 V**　執行法院於有第一項或第二項之情形時，應通知各債權人及債務人。
> **強執 §34-1**　政府機關依法令或本於法令之處分，對義務人有公法上金錢債權，依行政執行法得移送執行者，得檢具證明文件，聲明參與分配。
> **強執 §98 III**　存於不動產上之抵押權及其他優先受償權，因拍賣而消滅。但抵押權所擔保之債權未定清償期或其清償期尚未屆至，而拍定人或承受抵押物之債權人聲明願在拍定或承受之抵押物價額範圍內清償債務，經抵押權人同意者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「抵押權人參與分配須否提出執行名義？」 | **不須**（§34 II）。提出**權利證明文件**（抵押權設定文件）即可，連拍賣抵押物裁定都不用。其他債權人要（§34 I） |
| 「抵押權所擔保之債權清償期 130 年才到，現在得否參與分配？」 | **得**，§34 II「不問其債權已否屆清償期」。被強迫提前受償 |
| 「為什麼抵押權人這麼特別？」 | **§98 III 塗銷主義**：抵押權因拍賣而消滅（讓拍定人買到乾淨的物）→ 抵押權要被塗掉，就必須把抵押權人拉進來分錢保護他 → 所以不要求執行名義、不管清償期、**強制列入** |
| 「抵押權人經通知仍不聲明參與分配？」 | 執行法院仍就**已知債權及金額列入分配**（§34 III）——由不得你；執行費從執行所得**扣繳** |
| 「抵押權人不聲明、金額執行法院又不知道？」 | 其對執行標的物之優先受償權**因拍賣而消滅**（§34 IV）；已列入分配而未受清償部分亦消滅 |
| 「執行法院知有抵押權人之義務？」 | **應通知**（§34 III）；不知住居所或不知孰為債權人 → 其他適當方法通知或公告；有 I、II 情形應通知各債權人及債務人（§34 V） |
| 「債務人另欠稅、健保費、罰單，政府機關得否參與分配？」 | **得**，§34-1 公法上金錢債權依行政執行法得移送執行者，檢具證明文件聲明參與分配；受償次序依特別法（稅捐多優先） |
| 「字幕缺漏之練習題（02:18:37～02:19:19）結論」 | 題幹沒收到；結論：抵押權人**要列入分配**（強制列入，縱無執行名義）、就賣得 500 萬**優先受償**（不受基準時影響，筆記 11） |

## 一、§34 五項圖

```
§34 I  一般債權人：執行名義證明文件 ─┐
§34 II 擔保物權／優先受償權人：權利證明文件即可、不問清償期 ─┤→ 聲明參與分配
§34 III 執行法院知有 II 之人 → 應通知／公告；不來也就已知債權列入；執行費扣繳   ┐ 強制列入
§34 IV  II 之人不聲明 + 金額不知 → 優先受償權因拍賣而消滅                         ┘（原因：§98 III）
§34 V   I、II 情形通知各債權人及債務人
§34-1  政府機關公法上金錢債權 → 檢具證明文件參與分配
```

## 二、抵押權人 vs 一般債權人

| | 一般債權人（甲二） | 抵押權人 |
|---|---|---|
| 執行名義 | 要（§34 I） | **不要**（§34 II） |
| 清償期 | 須已屆（§4 II） | **不問** |
| 執行費 | 聲明時繳 | 執行所得**扣繳** |
| 不來 | 不分 | **仍列入**（已知債權） |
| 受償順位 | 群團一／二（筆記 11） | **最優先**（群團零），不受基準時影響 |
