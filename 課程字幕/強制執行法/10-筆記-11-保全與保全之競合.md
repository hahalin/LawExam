# 強制執行法10 筆記：保全與保全之競合

## 假扣押 vs 假扣押：
- **得並存**：有金額者都**提存**；無金額者只做查封
- 其中一案取得終局名義、開始終局執行 → 他案（仍是假扣押）應受分配之金額**提存**（§133）

## 假處分 vs 假處分、假扣押 vs 假處分：
- **看情況**：假處分內容各不相同；兩個都只是「禁止處分＝查封」→ 可並存；內容抵觸 → 依聲請先後
- 申論題也出過

## 先假處分、後假扣押（實務見解，年度請對講義）：
- 我國兼採**查封優越**（＝時間先後）與**終局執行優越**（＝終局優先）原則
- 假扣押債權人**先取得終局執行名義**並為終局執行 → 假處分不排除法院強制執行 → **終局優先**
- 假處分債權人**先取得執行名義**（例：所有權移轉登記確定判決）→ 依 §130 **擬制**債務人已為意思表示，**不必聲請執行**，直接持判決辦登記 → 假扣押與之不相容部分效力**歸於消滅**
- 關鍵：保全一旦「轉成終局」，誰先拿到終局、誰先完成，誰就贏

## 不要背的那一句：
- 該見解末句「假扣押在先、假處分在後，假處分債權人先取得之名義有礙假扣押查封效果者，對假扣押債權人不生效力」→ 已被 **103 年座談會**（終局一律優先）取代，**不採**
- 現在不分假扣押或假處分：**遇到終局，就終局優先**

> 來源：強制執行法10 課程字幕 02:06:34 ~ 02:14:00（講義 389～390 頁）

## 📖 法條原文速查

> **強執 §130 I**　命債務人為一定之**意思表示**之判決確定或其他與確定判決有同一效力之執行名義成立者，**視為自其確定或成立時，債務人已為意思表示**。（原文請對六法；講義 351 頁）
> **強執 §133**　因執行假扣押收取之金錢，及依分配程序應分配於假扣押債權人之金額，應提存之。

## 📋 實務見解

> **假處分與假扣押執行之競合**（字幕先唸「74 年」、後又稱「79 年那個判決」，字號請對講義 389～390 頁）：關於假處分與假扣押執行之競合，我國係採**查封優越及終局執行優越**之原則。就債務人所有執行標的物**實施假處分在先、執行假扣押在後**，而假扣押債權人就假扣押所保全之請求**先取得執行名義**並就該標的為**終局執行**者，該假處分之效力並不能排除法院之強制執行；如**假處分之債權人**就其保全請求**先取得執行名義**，則可進行請求實現該執行名義所載內容，包括依確定判決聲請地政機關辦理不動產所有權移轉登記，該假扣押執行與之不相容部分之效力即歸於消滅。
> 末句（假扣押在先、假處分在後之反面情形）→ 老師：早期判決、非判例，已被 103 年座談會推翻，不要理。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「兩個假扣押對同一標的？」 | **得並存**，金額提存 |
| 「兩個假扣押，其中一個轉終局執行，另一個應受分配金額？」 | **提存**（§133） |
| 「兩個假處分對同一土地，一定不能並存？」 | **不一定**，都只是查封即可並存——看情況 |
| 「先假處分、後假扣押，假扣押債權人先取得終局名義並聲請拍賣？」 | **准許**，終局優先 |
| 「假處分債權人先取得所有權移轉登記確定判決，須聲請強制執行？」 | **不必**，§130 擬制意思表示，逕持判決辦登記；假扣押不相容部分效力消滅 |
| 「保全遇到終局，要區分假扣押或假處分？」 | **不用分**，一律終局優先 |

## 一、先假處分、後假扣押：誰先轉終局

```
① 甲：假處分（禁止處分 A 地）── 查封
② 乙：假扣押（A 地）─────────── 查封（短暫並存）
        │
        ├─ 乙先拿到清償判決 → 終局執行 → 終局優先 → 拍賣 A 地
        │
        └─ 甲先拿到移轉登記確定判決 → §130 擬制 → 逕辦登記
                                    → 乙假扣押不相容部分效力消滅
```

## 二、保全 vs 保全 一覽

| 組合 | 處理 |
|---|---|
| 假扣押＋假扣押 | 並存，提存 |
| 假處分＋假處分 | 看情況（都查封 → 並存；抵觸 → 時間先後） |
| 假扣押＋假處分（任一順序） | 看情況；任一方轉終局 → 終局優先 |

- 老師：以前要分「假扣押 vs 終局」「假處分 vs 終局」背口訣，現在一律終局優先，比較簡單。
