# 強制執行法07 筆記：金錢債權之扣押命令與四種換價命令（§115）

## 三角關係（先畫圖）：
- 甲（債權人）→ 乙（債務人）→ 丙（第三人，如銀行、雇主）
- 丙本身沒欠甲錢，但會收到執行法院公文，必須配合——這是 §115 的特色
- 老師建議：條文的「債務人」旁寫乙、「第三人」旁寫丙

## 查封階段＝扣押命令（§115 I）：
- 抽象權利不用揭示、占有，改以**發命令**（公文）查封，**乙、丙各送一份**
- 效力一：禁止**債務人乙收取**或為其他處分（薪水被扣押，不能去找人資要）
- 效力二：禁止**第三人丙向乙清償**

## 換價階段＝四種命令（§115 II、III）：
- ① **收取命令**：甲**代位**乙向丙收取（類似民 §242）——單一債權人
- ② **移轉命令**：債權**讓與**給甲，甲成為丙的新債權人——債權明確可計算、無多數債權人
- ③ **支付轉給命令**：丙先付給**執行法院**，再轉給債權人——**間接收取**，多數債權人
- ④ **拍賣或變賣**：債權附條件、期限、對待給付等難以前三種辦理 → 準用動產執行
- 滿足階段由參與分配統一規定，§115 只講查封與換價

## 誰承擔丙無資力的風險（打星號）：
- 收取命令、支付轉給：**債務人乙**承擔——債權在**實際收取範圍內**才消滅
- 移轉命令：**債權人甲**承擔——移轉命令**生效時**即清償、程序**終結**，換價與滿足**同時**發生
- 三種裡**移轉命令最愛考**，實務見解多與它有關（下堂續講）

## 📖 法條原文速查

> **強執 §115 I**　就債務人對於第三人之金錢債權為執行時，執行法院應發**扣押命令**禁止**債務人收取**或為其他處分，並禁止**第三人向債務人清償**。
> **強執 §115 II**　前項情形，執行法院得詢問債權人意見，以命令許債權人**收取**，或將該債權**移轉**於債權人。如認為適當時，得命第三人向執行法院**支付轉給**債權人。
> **強執 §115 III**　金錢債權因附條件、期限、對待給付或其他事由，致難依前項之規定辦理者，執行法院得依聲請，準用對於動產執行之規定**拍賣或變賣**之。
（條文原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「扣押命令的兩個效力？」 | 禁止**債務人收取**或處分＋禁止**第三人向債務人清償** |
| 「扣押命令屬查封、換價或滿足階段？」 | **查封**階段 |
| 「金錢債權的換價方法？」 | 收取、移轉、支付轉給、拍賣或變賣（四種） |
| 「收取命令之性質？」 | **代位收取** |
| 「移轉命令之性質？」 | **債權讓與**（換價與滿足同時發生） |
| 「移轉命令後第三人無資力，風險誰負擔？」 | **債權人**（甲） |
| 「收取命令後第三人無資力，風險誰負擔？」 | **債務人**（乙），以實際收取範圍清償 |
| 「移轉命令生效後，他債權人得參與分配？」 | **不得**，程序已終結 |
| 「多數債權人時宜發何命令？」 | **支付轉給命令**（間接收取） |

## 一、三角圖

```
      甲（執行債權人）
       │ 金錢債權
       ▼
      乙（執行債務人）
       │ 金錢債權（存款、薪資）
       ▼
      丙（第三人：銀行、雇主）

扣押命令：乙 不得收取／處分；丙 不得向乙清償
```

## 二、三種換價命令比較

| 比較 | 收取命令 | 移轉命令 | 支付轉給命令 |
|---|---|---|---|
| 性質 | 代位收取 | **債權讓與** | 間接收取（經法院） |
| 適用 | 單一債權人 | 債權明確可計算、無多數債權人 | **多數債權人** |
| 丙無資力風險 | 乙（債務人） | **甲（債權人）** | 乙（債務人） |
| 執行債權何時消滅 | 實際收取範圍內 | **命令生效時** | 實際收取範圍內 |
| 程序終結 | 收取時 | **命令生效時** | 收取時 |

- 數字感：乙在丙銀行存款 10 萬。發收取命令，甲實際只收到 5 萬 → 只清償 5 萬，其餘仍可向乙執行。發移轉命令 → 生效時 10 萬全額視為清償，丙付不出來是甲自己的事，甲自行起訴丙。
- 收取命令與支付轉給本質相同，差在中間有沒有經過法院（單一 vs 多數債權人）。
