# 強制執行法07 筆記：共有物應有部分之拍賣（§102）與強制管理

## 應有部分（持分）拍賣的通知（§102 I）：
- 共有物應有部分**第一次**拍賣，執行法院應**通知他共有人**
- 目的：實體法上他共有人有**優先承購權**，要讓他們知道
- 只限第一次拍賣，**不必每次**通知；無法通知時不在此限

## 底價怎麼定（§102 II）：
- **共有物全部估價**，再按債務人**應有部分比例**定最低拍賣價額

## 強制管理（不動產第二種換價方式）：
- 拍賣：以**交換價值**為對象，一次取得較高價金
- 強制管理：以**使用收益價值**為對象，選任管理人出租收租，細水長流
- **只有不動產**才有，動產沒有
- 適用：依法不能移轉而無法拍賣、或有高額抵押拍賣恐無實益時的變通方法
- 老師：本身不太會考，內容多為管理人選任、監督、撤換

## 強制管理時抵押權人是否強制列入分配（講義 280 頁）：
- **不必**
- 理由：§34 II 強制列入，是配合 §98 III 拍賣**塗銷**抵押權；強制管理只就使用收益變現，**不塗銷**抵押權，抵押權也不妨礙用益
- 抵押權人自己聲請執行或參與分配仍可以，只是不強拉進來
- 法條沒寫，但老師認為很可能考

## 📖 法條原文速查

> **強執 §102**　I 共有物應有部分第一次之拍賣，執行法院應**通知他共有人**。但無法通知時，不在此限。II 最低拍賣價額，就**共有物全部估價**，按債務人**應有部分比例**定之。（原文請對六法）
> **強執 §75 I**　不動產之強制執行，以查封、**拍賣、強制管理**之方法行之。
> **強執 §34 II**　依法對於執行標的物有擔保物權或優先受償權之債權人，不問其債權已否屆清償期，應提出其權利證明文件，聲明參與分配。（原文請對六法）
> **強執 §98 III 本文**　存於不動產上之抵押權及其他優先受償權，因拍賣而消滅。
> **土地法 §34-1 IV**　要旨：共有人出賣其應有部分時，他共有人得以同一價格共同或單獨優先承購。（老師只說「優先購買權」，條號原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「應有部分每次拍賣均應通知他共有人？」 | **錯**，僅**第一次**拍賣；無法通知者不在此限 |
| 「應有部分最低拍賣價額如何定？」 | **共有物全部估價**，按應有部分比例定之 |
| 「動產得強制管理？」 | **不得**，強制管理只有不動產 |
| 「拍賣與強制管理的換價對象？」 | 拍賣＝交換價值；強制管理＝**使用收益價值** |
| 「強制管理時，抵押權人應依 §34 II 強制列入分配？」 | **不必**，強制管理不塗銷抵押權 |

## 一、底價計算

| 項目 | 數字 |
|---|---|
| 共有物全部估價 | 3,000 萬 |
| 債務人應有部分 | 1/3 |
| 最低拍賣價額 | 3,000 萬 × 1/3 ＝ **1,000 萬** |

## 二、拍賣 vs 強制管理

| 比較 | 拍賣 | 強制管理 |
|---|---|---|
| 換價對象 | 交換價值 | 使用收益價值 |
| 清償方式 | 一次取得較高價金 | 分期收取租金 |
| 適用標的 | 動產、不動產 | **僅不動產** |
| 抵押權 | 因拍賣消滅（§98 III） | 不消滅 |
| 抵押權人強制列入分配（§34 II） | **要** | **不必** |

## 三、§34 II 與 §98 III 的配套

```
§98 III 拍賣 → 抵押權塗銷
        ↓ 為保障被塗銷的抵押權人
§34 II  不問是否屆期，強制列入分配
──────────────────────────────
強制管理 → 抵押權不塗銷 → 沒有強制列入的理由
```
