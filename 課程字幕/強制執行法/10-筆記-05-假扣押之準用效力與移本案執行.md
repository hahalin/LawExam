# 強制執行法10 筆記：假扣押之準用效力與移本案執行

## 執行方法（準用）：
- 不動產假扣押：現場查封＋通知地政辦理查封登記（準用 §76）
- **§136**：除本章規定外，準用動產、不動產、船舶、航空器執行之規定 → 表面考假扣押，實際考前面的**查封**規定
- **§135**：對債權或其他財產權 → 發**禁止處分或清償之命令**，準用其他財產權執行（效果同 §115 I 扣押命令）

## 對人的保全執行（§132-2）：
- 債權人依民法 §151 **自助行為**拘束債務人自由並聲請法院處理，經法院命假扣押或假處分 → 執行法院得依**管收**規定管收債務人或為其他限制自由之處分

## 假扣押執行的效力：
- 就是**查封**：債務人仍為所有權人，只是**處分權受限制**；債權則不得收取

## 裁定被廢棄（§132-1）：
- 假扣押、假處分或定暫時狀態處分裁定**經廢棄或變更已確定** → 執行法院得**依聲請**撤銷已實施之執行處分
- 抗告成功的債務人要把確定裁定拿到執行處聲請撤銷

## 保全移本案執行：
- 取得終局執行名義後**接續**執行，不必重複保全程序已為的程序（不再查封）
- 本案執行被撤銷時：保全執行名義仍**獨立存在**（潛在地位），原則可恢復；除非撤銷原因是債務人本案勝訴確定，可認同時撤銷保全執行

## 📖 法條原文速查

> **強執 §132-1**　假扣押、假處分或定暫時狀態之處分裁定經**廢棄或變更已確定**者，於其廢棄或變更之範圍內，執行法院得**依聲請**撤銷其已實施之執行處分。
> **強執 §132-2**　債權人依民法第一百五十一條規定拘束債務人自由，並聲請法院處理，經法院命為假扣押或假處分者，執行法院得依本法有關**管收**之規定，管收債務人或為其他限制自由之處分。
> **強執 §135**　對於債權或其他財產權執行假扣押者，執行法院應分別發**禁止處分或清償之命令**，並準用對於其他財產權執行之規定。
> **強執 §136**　假扣押之執行，除本章有規定外，**準用**關於動產、不動產、船舶及航空器執行之規定。
> **民法 §151**　為保護自己權利，對於他人之自由或財產施以拘束、押收或毀損者，不負損害賠償之責。但以不及受法院或其他有關機關援助，並非於其時為之，則請求權不得實行或其實行顯有困難者為限。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「對債權假扣押，執行法院應發何命令？」 | **禁止處分或清償之命令**（§135），準用其他財產權執行 |
| 「假扣押不動產如何執行？」 | 準用不動產查封（§136）：揭示、封閉、追繳契據＋查封登記 |
| 「自助行為拘束債務人後，執行法院得管收債務人？」 | **得**，經法院命假扣押或假處分者（§132-2） |
| 「假扣押執行後，債務人喪失所有權？」 | **否**，只喪失**處分權** |
| 「假扣押裁定經抗告廢棄確定，執行處應依職權撤銷執行處分？」 | 條文是「得**依聲請**」撤銷（§132-1） |
| 「假扣押移本案執行，須重新查封？」 | **不必**，接續換價、分配 |

## 一、假扣押執行方法對照

| 標的 | 方法 | 依據 |
|---|---|---|
| 動產 | 實施占有、交付保管 | §136 準用 §47 以下 |
| 不動產 | 揭示、封閉、追繳契據＋查封登記 | §136 準用 §76 |
| 債權、其他財產權 | 禁止處分或清償之命令 | §135（＝扣押命令） |
| 人（自助行為後） | 管收或其他限制自由 | §132-2 |

## 二、兩個部門、兩個程序

```
民事庭：假扣押裁定 → 抗告 → 抗告法院廢棄確定
                                   ↓ 債務人持確定裁定
執行處：已實施之查封 ─────────→ 依聲請撤銷執行處分（§132-1）→ 程序終結
```

## 三、移本案後本案被撤銷

```
假扣押（獨立執行名義）──→ 移本案執行（被涵蓋）
                              ↓ 本案執行被撤銷
            保全執行名義仍在？ ├ 是 → 保全執行恢復獨立存在
                              └ 債務人本案勝訴確定／保全裁定也被廢棄 → 撤銷已實施之執行處分
```
