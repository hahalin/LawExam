# 強制執行法03 筆記：延緩執行（§10）

## 性質與要件：
- 延緩執行＝**合意停止**的概念：執行原則自動進行，但**債權人同意**時，執行法院**得**延緩
- 須同意之債權人：本案債權人、**併案**（§33 雙重聲請）債權人；**參與分配**債權人**不包括**（附隨地位）

## 期間限制：
- 每次延緩**不得逾三個月**；續行後再同意延緩**以一次為限** → 最多兩次、共六個月
- 每次期滿，經通知而**十日內**不聲請續行 → **視為撤回**執行聲請

## 併案時續行：
- 多數併案債權人同意延緩，期滿只有**一人**聲請續行 → 續行效力**及於全體**，其他人**不發生擬制撤回**（實務見解，字號請對講義）

## 變更或延展期日（§10 III）：
- 有特別情事繼續執行顯非適當（如家中喪事、寒流強制遷出）→ 執行法院**得**變更或延展執行期日，避免苛酷執行

## 📖 法條原文速查

> **強執 §10 I**　實施強制執行時，經**債權人同意**者，執行法院**得延緩**執行。
> **強執 §10 II**　前項延緩執行之期限**不得逾三個月**。債權人聲請續行執行而再同意延緩執行者，**以一次為限**。每次延緩期間屆滿後，債權人經執行法院通知而不於**十日內**聲請續行執行者，**視為撤回**其強制執行之聲請。
> **強執 §10 III**　實施強制執行時，如有**特別情事**繼續執行顯非適當者，執行法院得**變更或延展**執行期日。

## 📋 實務見解速查

> **併案延緩後部分續行**（實務見解，字號請對講義）：甲乙丙分持不同執行名義對同一債務人聲請執行而合併執行，經全體同意延緩；期滿後僅甲聲請續行，乙丙應利用該執行程序，**不因未另行聲請續行而發生擬制撤回**之效果。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「延緩執行須經何人同意？」 | **債權人**同意（條文不要求債務人） |
| 「延緩執行期限？」 | 每次**不得逾三個月** |
| 「再同意延緩之次數？」 | **以一次為限**（最多兩次） |
| 「期滿經通知未於十日內聲請續行？」 | **視為撤回**強制執行之聲請 |
| 「併案債權人之同意是否必要？」 | **必要**（有獨立聲請地位） |
| 「參與分配債權人之同意是否必要？」 | **不必要**（附隨性質） |
| 「併案延緩期滿，僅一債權人聲請續行，其餘視為撤回？」 | **錯**，續行效力**及於全體** |

## 一、三種「停」的比較

| | 延緩執行（§10） | 停止執行（§18 II） | 執行障礙 |
|---|---|---|---|
| 類比民訴 | **合意停止** | **裁定停止** | — |
| 發動 | 債權人同意 | 受訴法院裁定 | 依職權調查 |
| 期限 | 3 個月 × 最多 2 次 | 至本案確定 | 至總清算結束 |
| 筆記 | 本筆記 | 筆記 10 | 筆記 08 |

## 二、時間軸

```
同意延緩 ─(≤3 月)─ 期滿通知 ─(10 日)─ 聲請續行？
                                    ├── 有 → 續行；可再同意延緩一次（≤3 月）
                                    └── 無 → 視為撤回（結案）
```

## 三、併案 vs 參與分配（甲1 先聲請，甲2 後加入）

```
甲2 加入方式
├── 獨立聲請強制執行 → 併案（§33）→ 延緩須甲2 同意
└── 僅聲明參與分配（§32 以下）→ 附隨 → 延緩不須甲2 同意
外觀都是「多個債權人對同一債務人」，差在加入方式
```
