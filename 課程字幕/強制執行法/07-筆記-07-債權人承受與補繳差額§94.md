# 強制執行法07 筆記：債權人承受與補繳差額（§94）

## 數債權人都願承受：
- **直接抽籤**（§94 I），不先加價
- 理由：承受一律以**底價**承受，本來就沒有價格競爭的意思
- 對照 §90：投標**出價相同** → 先當場加價，無人加價才抽籤

## 承受人應補繳差額：
- 承受人應繳價金 **超過** 其應受分配額 → 執行法院**限期命補繳差額**，繳足後才發權利移轉證書（§94 II）
- 例：債權 100 萬，承受的不動產底價 200 萬 → 要補繳差額
- 逾期不繳 → **再行拍賣**；但未中籤的債權人仍願按原定條件承受者，由其承受

## 不繳差額的再行拍賣：
- 是**同一條件**再賣，**不是減價拍賣**——只是那個人沒繳錢，不代表東西賣不掉
- **準用 §68-2**（§94 III）：原承受人不得應買；再拍賣價金低於原價金及費用 → 原承受人負擔差額，法院依職權裁定，得據以強制執行

## 📖 法條原文速查

> **強執 §94**　I 債權人有二人以上願承受者，以**抽籤**定之。
> II 承受不動產之債權人，其應繳之價金**超過其應受分配額**者，執行法院應**限期命其補繳差額**後，發給權利移轉證書；逾期不繳者，**再行拍賣**。但有未中籤之債權人仍願按原定拍賣條件依法承受者，不在此限。
> III 第六十八條之二之規定，於前項再行拍賣**準用**之。
> **強執 §68-2**　I 拍定人未繳足價金者，執行法院應再拍賣。再拍賣時原拍定人**不得應買**。如再拍賣之價金低於原拍賣價金及因再拍賣所生之費用者，原拍定人應**負擔其差額**。II 前項差額，執行法院應依職權以**裁定**確定之。III 原拍定人繳納之保證金不足抵償差額時，得依前項裁定對原拍定人**強制執行**。
> **強執 §90 I**　投標人願出之最高價額相同者，以**當場增加之金額最高者**為得標人；無人增加價額者，以抽籤定其得標人。
（條文原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲、乙兩債權人均願承受，應先命當場加價？」 | **錯**，承受直接**抽籤**（§94 I） |
| 「投標出價相同，直接抽籤？」 | **錯**，先當場加價（§90） → 與 §94 對照的陷阱 |
| 「承受人債權不足抵價金，如何處理？」 | 限期命**補繳差額**，繳足才發權利移轉證書 |
| 「承受人逾期不補繳，執行法院應減價拍賣？」 | **錯**，以**同一條件**再行拍賣 |
| 「承受人逾期不補繳，未中籤債權人願依原條件承受？」 | 由其承受，不必再賣 |
| 「再拍價金較低，差額誰負擔？」 | **原承受人**（準用 §68-2），法院依職權裁定後得強制執行 |

## 一、§90 與 §94 對照

| | 投標出價相同（§90） | 數債權人願承受（§94 I） |
|---|---|---|
| 價格 | 各自出價，剛好相同 | 一律**底價** |
| 第一步 | 當場增加金額，最高者得 | **直接抽籤** |
| 第二步 | 無人加價 → 抽籤 | — |
| 得標／中籤者不繳錢 | 再行拍賣；未中籤者願依原條件承買者不在此限 | 再行拍賣；未中籤債權人願依原條件承受者不在此限 |

## 二、補繳差額數字練習

```
承受價（底價）     200 萬
承受人應受分配額   100 萬
────────────────
應補繳差額         100 萬 → 限期補繳 → 發權利移轉證書
                     │
                     └ 逾期不繳
                         ├ 未中籤債權人願依原條件承受 → 由其承受
                         └ 無 → 同條件再行拍賣（準用 §68-2）
                                  再拍只賣 180 萬 + 費用 5 萬
                                  → 原承受人負擔 25 萬（裁定確定 → 得強制執行）
```

## 三、為什麼不是減價拍賣

- 減價拍賣（§91、§92）的前提是「賣不掉」。
- 承受後不繳錢，是「有人要、但他沒付錢」，標的物本身的市場沒有問題 → 用同一條件再賣，概念與拍定人未繳足價金（§68-2）相同。
