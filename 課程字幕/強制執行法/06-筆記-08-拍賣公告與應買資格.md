# 強制執行法06 筆記：拍賣公告與應買資格

## 拍賣公告：
- 應先期公告；載明物之種類數量品質、拍賣原因日時場所、閱覽處所、交付期限、應買資格、保證金（§64）——**不載底價**（不動產則要載）
- 揭示處所：**執行法院**＋**鄉鎮市區公所或拍賣場所**＝一定要；**法院網站、公報新聞紙＝得**（§65）
- 公告**五日後**才拍賣（§66）
- 未遵守公告程序 → §12 聲明異議

## 誰能買：
- 債權人：可
- **債務人：不得應買**（§70 VI）——出賣人不能當買受人；避免循環執行（105 台抗 381）
- 保證人、連帶債務人：可（不同人）
- 限定繼承人、物上保證人（抵押物所有人）：可（只負物的有限責任，不會循環執行）
- 執行法官、書記官、執達員：不得，亦不得使他人（人頭）應買（民法 §392）
- 院長及其他職員：應買有效，只生懲戒問題

## 📖 法條原文速查

> **強執 §64**　I 拍賣動產，應由執行法院**先期公告**。II 前項公告，應載明左列事項：一、拍賣物之種類、數量、品質及其他應記明之事項。二、拍賣之原因、日時及場所。三、閱覽拍賣物及查封筆錄之處所及日時。四、定有拍賣價金之交付期限者，其期限。五、定有應買之資格或條件者，其資格或條件。六、定有保證金者，其金額。
> **強執 §65**　拍賣公告，應揭示於**執行法院**及動產所在地之**鄉鎮市（區）公所或拍賣場所**，如認為必要或因債權人或債務人之聲請，並**得**公告於法院網站；法院認為必要時，**得**命登載於公報或新聞紙。
> **強執 §66**　拍賣，應於公告**五日後**行之。但因物之性質須迅速拍賣者，不在此限。
> **強執 §70 VI**　**債務人不得應買**。
> **民法 §392**　拍賣人對於其所經管之拍賣，不得應買，亦不得使他人為其應買。
（§64 各款原文請對六法）

## 📋 實務見解速查

> **最高法院 105 年台抗字第 381 號裁定**：不動產執行依 §113 準用 §70 VI，債務人不得應買。此係基於通說認強制執行法上拍賣屬買賣之一種、以債務人為出賣人，**出賣人不得為買受人**之觀點；且債務人如有資力並欲保有名下財產，應盡力向債權人清償，而非許其應買自己財產，否則債權未獲全額清償時將再聲請拍賣同一財產，產生**冗長之執行程序**。至於**限定繼承**或**第三人提供抵押物**之強制執行，繼承人、抵押物所有人僅負**物的有限責任**，許其應買既不生上述疑慮，對債權人亦無不利，**無禁止之必要**。
> **實務見解**（講義 238 頁）：執行法院之**院長及其他職員**均非民法 §392 之拍賣人，縱司法行政監督長官曾有禁止應買之命令，其應買僅生**是否懲戒**之問題，**不得認拍賣為無效**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產拍賣公告應載明底價？」 | **否**，§64 沒有底價；縱定有底價也不放公告。**不動產**底價要載於公告（§81） |
| 「動產拍賣公告未登法院網站，程序違法？」 | **否**。網站、公報新聞紙都是**得**；一定要的是執行法院＋公所**或**拍賣場所。（不動產一定要上網站） |
| 「公告後隔天即拍賣？」 | 原則**不得**，公告**五日後**；須迅速拍賣者例外 |
| 「拍賣未遵守公告程序之救濟？」 | **§12** 聲明異議 |
| 「債務人得否應買自己被拍賣之財產？」 | **不得**（§70 VI；不動產 §113 準用）。理由：出賣人不得為買受人；避免循環執行 |
| 「執行債務人之**連帶債務人**、**保證人**得否應買？」 | **得**，非執行債務人 |
| 「**物上保證人**（抵押物所有人）、限定繼承人得否應買？」 | **得**（105 台抗 381）：僅負物的有限責任，一次性執行，不會循環 |
| 「執達員以妻名義應買？」 | **不得**，民法 §392 亦不得使他人為其應買 |
| 「法院院長應買？」 | **有效**，僅生懲戒問題 |

## 一、公告揭示處所

```
一定要（應）：執行法院 ＋ 動產所在地之鄉鎮市區公所 或 拍賣場所（二選一）
可以（得）  ：法院網站（認為必要或兩造聲請）
              公報、新聞紙（法院認為必要）
```

- 附錄 396 頁實例（車輛）：拍賣場所在動產所在地（地下二樓）、當場付款、記載欠稅罰款與「拍定人就拍賣物無物之瑕疵擔保請求權」、**沒有底價**。附錄 48 頁不動產公告：土地底價 6,523 萬、房屋 744 萬。

## 二、應買資格

| 人 | 可否 | 理由 |
|---|---|---|
| 債權人 | 可 | |
| **債務人** | **不可** | §70 VI；出賣人≠買受人；循環執行 |
| 保證人、連帶債務人 | 可 | 不同人 |
| 限定繼承人、物上保證人 | 可 | 物的有限責任，一次性（105 台抗 381） |
| 經管該拍賣之執行法官、書記官、執達員（含人頭） | 不可 | 民法 §392 |
| 院長、其他職員 | 應買有效 | 非 §392 拍賣人，僅懲戒問題 |

- 老師：債務人想買就叫他**提出現款**撤銷查封（§58），不是去應買。
