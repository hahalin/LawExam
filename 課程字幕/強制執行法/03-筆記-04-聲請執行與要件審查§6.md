# 強制執行法03 筆記：聲請執行與要件審查（§6）

## 聲請方式：
- 全部依**債權人聲請**開始；應以**書狀**（要式，無言詞聲請）表明當事人、請求實現之權利（§5 I）
- 宜記載執行標的物、應為之執行行為等（§5 II）

## 應備文件（§6，對應 §4 I 六款）：
- 一律提出**正本**（與民事訴訟附副本不同）
- 確定判決、支付命令 → 須**確定證明書**；假扣押、假處分、假執行 → 裁判正本即可，不必確定
- 拍賣抵押物裁定 → 裁定＋**抵押權證明**＋**債權證明**；本票裁定 → **本票原本**＋裁定＋合法送達證明（實務多附確定證明書）
- 未提出：受聲請法院即原第一審法院 → **應調卷**；不是 → **定期命補正**，不補正駁回（可再聲請）

## 要件審查（81 台抗 114）：
- 執行法院對**執行名義是否有效成立**應自行審查
- 民事庭**誤發確定證明書**，裁判仍不因此確定；執行法院**不受拘束**（考過很多次）

## 📖 法條原文速查

> **強執 §5 I**　債權人聲請強制執行，應以**書狀**表明左列各款事項，提出於執行法院為之：一、當事人及法定代理人。二、請求實現之權利。
> **強執 §6 I**　債權人聲請強制執行，應依左列規定，提出證明文件：①確定終局判決 → 判決正本並判決確定證明書或各審級判決正本 ②假扣押、假處分、假執行之裁判 → 裁判正本 … ⑤抵押權／質權之拍賣裁定 → 裁定正本及**權利證明文件** ⑥其他依法得為執行名義者 → 證明文件（要旨，原文請對六法）
> **強執 §6 II**　前項證明文件，未經提出者，執行法院**應調閱卷宗**。但受聲請之法院**非係原第一審法院**時，不在此限。
> **民訴 §521 II**　（支付命令得為執行名義之）情形，為裁定之法院應付與**裁定確定證明書**。

## 📋 實務見解速查

> **81 年台抗字第 114 號**（老師：申論要背字號）：強制執行應依執行名義為之，執行法院對於執行名義是否有效成立，自應加以審查。未確定之支付命令，不備執行名義之要件，執行法院不得據以強制執行；法院誤認未確定之裁判為確定而付與確定證明書，仍不生該裁判已確定之效力，執行法院就該裁判是否確定，仍得審查，**不受確定證明書之拘束**。（要旨，原文請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「得以言詞聲請強制執行？」 | **不得**，應以**書狀**（§5 I） |
| 「以假扣押裁定聲請執行，須附確定證明書？」 | **不須**，保全裁判不待確定 |
| 「以支付命令聲請執行應附？」 | 支付命令正本＋**確定證明書** |
| 「拍賣抵押物裁定聲請執行應附？」 | 裁定＋抵押權設定證明＋**債權證明文件**（借據、借款契約等） |
| 「本票裁定聲請執行應附？」 | **本票原本**＋本票裁定＋合法送達證明（或確定證明書） |
| 「未附證明文件，執行法院應即駁回？」 | **錯**。同一第一審法院應**調卷**；非同一法院**命補正**，逾期不補才駁回 |
| 「民事庭已付與確定證明書，執行法院即應執行？」 | **錯**（81 台抗 114）。執行法院**仍得審查**是否確定，不受拘束 |

## 一、§6 應備文件表

| §4 I | 執行名義 | 應備文件 | 須確定證明？ |
|---|---|---|---|
| ① | 確定終局判決 | 判決正本＋確定證明書（或各審判決） | ✓ |
| ② | 假扣押、假處分、假執行 | 裁判正本 | ✗ |
| ② | 支付命令 | 正本＋確定證明書 | ✓ |
| ③ | 和解、調解 | 筆錄正本 | — |
| ④ | 公證書 | 公證書正本 | — |
| ⑤ | 拍賣抵押物／質物裁定 | 裁定＋抵押權證明＋債權證明 | ✗（不待確定） |
| ⑥ | 本票裁定 | 本票原本＋裁定＋合法送達證明 | ✗（附確定證明書是為證明已送達） |

## 二、未提出文件的處理

```
證明文件不全
├── 受聲請法院＝原第一審法院 → 應調閱卷宗（§6 II 本文）
└── 非原第一審法院 → 定期命補正 → 不補正 → 裁定駁回
                                         └→ 文件齊備後可再聲請（無重複執行禁止）
```

## 三、81 台抗 114 圖解

```
民事庭（非訟中心）：支付命令未合法送達 → 誤發確定證明書
            ↓ 不生確定效力
執行處：獨立審查執行要件（與民事庭平行，不受其認定拘束）
            ↓
未確定 → 執行名義未成立 → 不得執行
```
