# 強制執行法10 筆記：假扣押之提存與緊急換價（§133～§134）

## §133 兩種金錢要提存：
- ① 因執行假扣押**收取之金錢**（例：扣到的租金、報酬）
- ② 依**分配程序**應分配於假扣押債權人之金額 → 他債權人終局執行換價後，假扣押債權人那份**照算**，但**提存**、不交付（§32 參與分配、§33 併案）
- 原理不變：錢卡住不動，等本案結果

## 注意事項 70：徵收補償金也提存：
- 假扣押、假處分中的財產被政府**強制收購或徵收** → 價金或補償金**提存**，查封效力延續，債務人不得領走

## §134 緊急換價：
- 限**動產**；要件：**價格減少之虞**（生鮮、季節物品、3C 跌價）或**保管需費過多**（冷凍冷藏、倉儲）
- 發動：債權人聲請、債務人聲請、**依職權**皆可
- 定期拍賣，**提存賣得金**

## 緊急換價無人應買，假扣押債權人得否承受：
- **原則不得**：承受＝作價抵債＝滿足，違反保全本質、對他債權人不公平
- 實務折衷：要承受就**提出現款**繳納價金，價金**提存**，不得以債權抵繳

## 對第三人金錢債權假扣押：
- 發扣押命令（禁止收取、禁止清償）即可，第三人**不必提存**（練習題 B 錯在這裡）

## 📖 法條原文速查

> **強執 §133**　因執行假扣押**收取之金錢**，及依**分配程序**應分配於假扣押債權人之金額，應**提存**之。
> **強執 §134**　假扣押之**動產**，如有**價格減少之虞**或**保管需費過多**時，執行法院得因債權人或債務人之聲請或**依職權**，定期拍賣，**提存其賣得金**。
> **強執注意事項 70**　在假扣押或假處分中之財產，如經政府機關依法**強制採購或徵收**者，執行法院應將其價金或補償金額**提存**之。（原文請對六法）
> **強執 §115 I**　就債務人對於第三人之金錢債權為執行時，執行法院應發扣押命令禁止債務人收取或為其他處分，並禁止第三人向債務人清償。

## 📋 實務見解

> **緊急換價之承受**（出處請對講義 372 頁附近）：假扣押債權人原則不得聲明承受；如欲承受，應同其他拍定人**提出現款繳納價金**，並將價金**提存**。法條無規定，為實務折衷見解。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「他債權人執行換價後，假扣押債權人應受分配之金額如何處理？」 | **提存**（§133）；照算一份，但不交付 |
| 「假扣押土地被徵收，補償金？」 | **提存**（注意事項 70）——考過 |
| 「緊急換價限依債權人聲請？」 | **錯**。債權人、債務人聲請或**依職權**皆可 |
| 「緊急換價之客體？」 | **動產**，價格減少之虞或保管需費過多 |
| 「緊急換價賣得價金交付假扣押債權人？」 | **錯**，**提存** |
| 「緊急換價無人應買，假扣押債權人得以債權額承受？」 | **不得**；要承受須提出現款繳價金並提存 |
| 「對第三人金錢債權假扣押，命第三人交付之金額應提存？」 | **錯**。發扣押命令即可，第三人不必提存 |

## 一、§133 的分配情形

```
甲1：確定判決（終局、金錢）─┐
                            ├→ 同一債務人乙的車子：查封 → 換價 → 分配表（按債權比例）
甲2：假扣押（保全、金錢）───┘
                                    ├ 甲1 那份 → 匯入甲1 帳戶
                                    └ 甲2 那份 → 提存（§133）
```

## 二、練習題（假扣押提存，選錯的）

| 選項 | 判斷 | 依據 |
|---|---|---|
| A 動產價格減少之虞，依職權拍賣所得價金應提存 | 正確 | **§134**（老師先說 133，後更正為 134） |
| B 對第三人金錢債權假扣押，命第三人交付之金額應提存 | **錯誤（答案）** | 準用 §115 I 扣押命令即可，不須提存 |
| C 假扣押土地被徵收，補償金應提存 | 正確 | 注意事項 70 |
| D 他案債權人執行，依分配程序應分配於假扣押債權人之金額應提存 | 正確 | **§133** |

## 三、緊急換價 vs 承受

```
§134 緊急換價（動產）→ 拍賣 → 有人買 → 價金提存
                          └ 無人應買 → 假扣押債權人承受？
                                         ✕ 以債權抵價（＝滿足）
                                         ✔ 提出現款 → 價金提存
```
