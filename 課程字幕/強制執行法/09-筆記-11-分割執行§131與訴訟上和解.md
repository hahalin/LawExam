# 強制執行法09 筆記：分割執行（§131）與訴訟上和解

## §131 兩項的分工：
- **I 項限「裁判」**：① 原物分割 → 分得部分**點交**（移轉占有）② 金錢補償 → 對補償義務人財產執行
- **II 項不限執行名義**：③ 變價分割 → 拍賣並分配價金，拍賣程序準用動產、不動產規定（走金錢債權執行）
- 民法分割方法正好三種：原物分割、金錢補償、變價分割
- 實務常用：分割之訴中成立**和解、調解** → 依 II 項聲請拍賣

## 分割執行的三個特色（條文沒寫，實務認同）：
- ① 原告、被告**都可以**聲請執行（形式形成訴訟，雙方非對立）
- ② 排除「債務人不得應買」（§70 VI）：目的是分割不是還錢，不會循環執行
- ③ 不適用**無益執行禁止**（§80-1）：即使有高額抵押權仍可變價

## 和解筆錄約定原物分割：
- 訴訟上和解只有**協議分割**效力，**沒有形成判決效力**（民訴：和解不生形成力）→ 不能依 §131 I 聲請點交
- 例外：和解內容**約定互為交付義務** → 依 §124 不動產交付執行
- 對照：裁判分割確定時各共有人已取得分得部分所有權（尚須登記才能處分），§131 I 點交只是讓他取得現實占有

## 📖 法條原文速查

> **強執 §131**　I 關於繼承財產或共有物分割之**裁判**，執行法院得將各繼承人或共有人**分得部分點交**之；其應以**金錢補償**者，並得對於補償義務人之財產執行。II 執行名義係**變賣**繼承財產或共有物，以價金分配於各繼承人或各共有人者，執行法院得予以**拍賣**，並分配其價金，其拍賣程序，準用關於動產或不動產之規定。
> **強執 §70 VI**　債務人不得應買。
> **強執 §80-1 I 前段**　不動產之拍定或依前條第一項規定承受之價額，如不足清償優先債權及強制執行費用者，執行法院應將其事由通知債權人（無益執行禁止）。（原文請對六法）
（條文原文請對六法）

## 📋 實務見解

> **研討會（§131 II 不限裁判）**：繼承人或共有人於訴訟上就繼承財產或共有物協議**變賣**分配價金而調解成立者，非不得作為執行名義；觀 §131 II 所謂「執行名義」與 I 項明定「裁判」不同可知。（字號請對講義 356～361 頁間）

> **和解約定原物分割（司法業務座談會）**：分割共有物之訴成立訴訟上和解約定原物分割，但和解內容**未約定互為交付**者，該和解僅有協議分割效力，無形成判決效力；除和解內容已約定交付義務外，不得依 §131 I 聲請點交。（字號請對講義 356～361 頁間）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「得依 §131 I 聲請點交分得部分之執行名義？」 | **限裁判**（判決） |
| 「分割之訴成立和解，約定變價分割，得聲請拍賣？」 | **得**（§131 II 不限執行名義） |
| 「和解約定原物分割，未約定互為交付，得聲請點交？」 | **不得**——和解無形成力 |
| 「和解約定原物分割並約定交付義務？」 | 得依 **§124** 不動產交付執行 |
| 「分割執行，被告得聲請執行？」 | **得**，原告被告皆可 |
| 「變價分割拍賣，共有人（形式上債務人）得應買？」 | **得**，排除 §70 VI |
| 「共有物上有高額抵押權，變價分割有無益執行問題？」 | **沒有**，目的在分割 |

## 一、§131 架構

```
分割執行
├─ §131 I（限「裁判」）
│   ├─ 原物分割 → 分得部分點交（移轉占有）
│   └─ 金錢補償 → 對補償義務人財產執行（金錢債權）
└─ §131 II（不限：判決、和解、調解都可）
    └─ 變價分割 → 拍賣、分配價金（準用動產、不動產拍賣）
```

## 二、經典題：甲乙共有建地，分割之訴成立和解，約定原物分割

| 步驟 | 判斷 |
|---|---|
| 執行名義 | 訴訟上**和解**，不是裁判 |
| 分割方法 | **原物分割** → 要點交須依 §131 I |
| §131 I 限裁判 | 和解不符 |
| 和解有無約定互為交付 | 未約定 → **不得**聲請拆卸車庫、交付土地 |
| 若有約定 | 依 §124 交付不動產 |

## 三、裁判分割 vs 和解分割

| | 裁判分割（形成判決） | 訴訟上和解 |
|---|---|---|
| 所有權 | 判決確定時取得分得部分（處分前須登記） | 只有協議分割效力，未取得 |
| 原物分割點交 | §131 I 可 | 不可（除非約定交付義務 → §124） |
| 金錢補償 | §131 I 可 | 依約定內容 |
| 變價分割拍賣 | §131 II 可 | §131 II 可 |
