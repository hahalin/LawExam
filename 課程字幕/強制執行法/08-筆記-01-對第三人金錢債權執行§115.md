# 強制執行法08 筆記：對第三人金錢債權執行（§115）

## 定位：
- 其他財產權執行三類之一：債務人（乙）對第三人（丙）的**金錢債權**（存款、薪資、租金、貨款）
- 老師：§115「幾乎每年都會考」一題

## 查封階段（§115 I）：
- 執行法院**應**發**扣押命令**：禁止乙收取或為其他處分＋禁止丙向乙清償

## 換價階段（§115 II、III）：
- 收取命令、**移轉命令**（最愛考）、支付轉給命令；難以核發時 → 拍賣或變賣（第四種）
- 收取與支付轉給同類（代位收取，實際收到才算清償）；移轉命令＝**債權讓與**，換價與滿足同時發生、程序立即終結

> 來源：強制執行法08 課程字幕 00:00:01 ~ 00:05:09（講義 294～295 頁）

---

## 📖 法條原文速查

> **強執 §115**　I 就債務人對於第三人之金錢債權為執行時，執行法院應發**扣押命令**禁止債務人收取或為其他處分，並禁止第三人向債務人清償。II 前項情形，執行法院得詢問債權人意見，以命令許債權人**收取**，或將該債權**移轉**於債權人。如認為適當時，得命第三人向執行法院**支付轉給**債權人。III 金錢債權因附條件、期限、對待給付或其他事由，致難依前項之規定辦理者，執行法院得依聲請，準用對於動產執行之規定**拍賣或變賣**之。
（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「對債務人之存款債權執行，查封方法？」 | 發**扣押命令**（§115 I），不是實施占有 |
| 「扣押命令的效力？」 | **禁止債務人收取或處分**＋**禁止第三人向債務人清償**——兩個禁止 |
| 「換價命令有哪幾種？」 | 收取、移轉、支付轉給（§115 II）；難以辦理時拍賣或變賣（§115 III） |
| 「哪一種命令一生效執行程序就終結？」 | **移轉命令**（債權讓與，換價＋滿足同時完成） |
| 「收取命令核發後，執行債權何時消滅？」 | 債權人**實際收取**的範圍內才消滅 |
| 「第三人無資力的風險，移轉命令由誰承擔？」 | **執行債權人**（甲）；收取、支付轉給原則上仍由債務人承擔（甲可繼續執行乙其他財產） |

## 一、三方關係

```
甲（執行債權人）──執行名義──▶ 乙（債務人）
                                 │ 乙對丙之金錢債權（存款、薪資、貨款…）
                                 ▼
                               丙（第三人／第三債務人）

查封：扣押命令 → 乙不得收取、丙不得清償給乙
換價：收取／移轉／支付轉給（／拍賣變賣）
```

## 二、換價命令比較表（講義 295 頁表格）

| | 收取命令 | 移轉命令 | 支付轉給命令 |
|---|---|---|---|
| 性質 | 代位收取 | **債權讓與** | 間接收取（丙付法院→法院轉給） |
| 何時清償 | 甲實際收取範圍內 | 命令生效時，於移轉範圍內 | 法院轉給的金額限度內 |
| 丙無資力風險 | 債務人乙 | **債權人甲** | 債務人乙 |
| 執行程序終結 | 收取完畢 | **命令生效即終結** | 轉給債權人時 |
| 得否 §119 II 逕向第三人執行 | 得 | **不得**（筆記 10） | 得 |

- 移轉命令後丙不付錢：甲以新債權人地位**另訴**、另取得對丙之執行名義；執行處已結案，不再管。
- 好處：執行處可以快速結案。
