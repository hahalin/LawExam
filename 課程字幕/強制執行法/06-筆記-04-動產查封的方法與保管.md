# 強制執行法06 筆記：動產查封的方法與保管

## 查封是什麼：
- 剝奪債務人對特定財產的**處分權**；**不喪失所有權**，東西還是債務人的

## 怎麼查封（§47）：
- 查封＝**執行人員實施占有**（車開走、鋼琴載走）
- 標封、烙印、火漆印＝**交付保管時的公示方法**，不是查封行為本身（選項寫「貼封條查封」是錯的）

## 現場與保管：
- 書記官督同執達員（§46）；得檢查、**啟視**住居所、倉庫、箱櫃（§48 I）
- 債務人不在場 → 命家屬或鄰居有辨別事理能力者到場，必要時請警察（§48 II；違反多數說只能 §12 聲明異議）
- 保管：法院貯藏所、保管人、常見**債權人**保管（§59 I）；**貴重物品、有價證券**原則不交債務人（§59 II）
- 債務人保管 → 得於**無損查封物價值範圍內**使用（§59 V）
- 書記官作**查封筆錄**及查封物品清單，在場者簽名（§54）

## 📖 法條原文速查

> **強執 §46**　查封動產，由執行法官命**書記官督同執達員**為之。於必要時得請有關機關、自治團體、商業團體、工業團體或其他團體，或對於查封物有專門知識經驗之人協助。
> **強執 §47**　I 查封動產，由執行人員**實施占有**。其將查封物**交付保管**者，並應依左列方法行之：一、標封。二、烙印或火漆印。三、其他足以公示查封之適當方法。II 前項方法，於必要時得併用之。
> **強執 §48**　I 查封時，得檢查、**啟視**債務人居住所、事務所、倉庫、箱櫃及其他藏置物品之處所。II 查封時，如債務人不在場，應命其**家屬或鄰居之有辨別事理能力者**到場，於必要時，得請**警察**到場。
> **強執 §59**　I 查封之動產，應移置於該管法院所指定之貯藏所或委託妥適之保管人保管之。認為適當時，亦得以**債權人**為保管人。II 查封物除**貴重物品及有價證券**外，經債權人同意或認為適當時，得使債務人保管之。III 查封物交保管人時，應告知刑法所定損壞、除去或污穢查封標示或為違背其效力之行為之處罰。IV 查封物交保管人時，應命保管人出具收據。V 查封物以債務人為保管人時，得許其於**無損查封物之價值範圍內**，使用之。
> **強執 §54**　I 查封時，書記官應作成**查封筆錄**及查封物品清單。II 查封筆錄應載明：一、為查封原因之權利。二、動產之所在地、種類、數量、品質及其他應記明之事項。三、債權人及債務人。四、查封開始之日時及終了之日時。五、查封之動產保管人。六、保管方法。III 查封人員，應於前項筆錄簽名，如有保管人及依第四十八條第二項規定之人員到場者，亦應簽名。
（條文原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產經查封，債務人喪失所有權？」 | **否**。只喪失**處分權** |
| 「動產查封之方法？」 | **執行人員實施占有**（§47 I）。「以貼封條為查封」→ **錯** |
| 「標封、烙印、火漆印的定位？」 | **交付保管**時之**公示方法**，讓第三人知悉已查封、避免善意受讓；必要時得併用 |
| 「執行人員得否打開債務人之箱櫃、大門？」 | **得**，§48 I「啟視」＝阻卻違法依據 |
| 「債務人不在場時查封？」 | 應命家屬或鄰居有辨別事理能力者到場，必要時請警察；違反之效力有爭議，多數認僅得依 **§12** 聲明異議 |
| 「得否以債權人為保管人？」 | **得**（§59 I），實務常見 |
| 「金飾、有價證券得否交債務人保管？」 | **原則不得**；經債權人同意或認為適當時例外（§59 II） |
| 「債務人保管之查封電視得否繼續使用？」 | **得**，於**無損查封物價值範圍內**（§59 V） |

## 一、查封三步

```
① 查封行為：執行人員實施占有（剝奪債務人占有）
② 交付保管：貯藏所／保管人／債權人／（例外）債務人 —— §59
③ 公示方法：標封、烙印、火漆印、貼公文（寫案號、法院）—— §47 I 後段
→ 書記官作查封筆錄＋物品清單，在場者簽名 —— §54
```

## 二、保管人比較

| 保管人 | 可否 | 備註 |
|---|---|---|
| 法院指定貯藏所 | 可 | 法院空間通常不夠 |
| 妥適之保管人 | 可 | |
| 債權人 | 可（常見） | 債權人自己租倉庫、叫搬家公司 |
| 債務人 | 可，但**貴重物品、有價證券原則不可** | 債權人同意或認為適當時例外；可在無損價值範圍內使用 |

- 交保管人時應告知刑法毀損查封標示之處罰（§59 III）、命出具收據（§59 IV）。
