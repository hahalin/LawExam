# 強制執行法08 筆記：物之交付與行為執行之區分

## 非金錢債權執行兩大類：
- **物之交付**（§123 動產、§124 不動產）vs **行為、不行為**（§127 可代替、§128 不可代替、§129 不行為）
- 同一件事兩者可能重疊 → 看**執行名義怎麼寫、重視的是什麼**決定執行方法

## 三組教科書例：
- 電力：命交付**已裝入容器**的電力 → 物之交付（§123）；命裝設電線桿、埋設導管後供電 → 行為（再分可否代替）
- 帳簿、文書：命**交付**帳本（移轉占有）→ 物之交付；命提供**閱覽**、不得妨礙閱覽 → 行為，原則**不可代替**（§128）
- 複合：命製造加工物或發行股票後**交付** → 行為＋物之交付並用

## 動產交付（§123，下堂細講）：
- 一般動產 → **取交**（直接強制）
- 書據、印章或其他相類憑證，取交無效果 → 準用 **§121**（公告宣示無效、另作證明書）或 **§128 I**（處怠金、再處怠金或管收）
- 「另作證明書」**不是**重刻印章、重印權狀

## 📖 法條原文速查

> **強執 §123**　I 執行名義係命債務人交付一定之動產而不交付者，執行法院得將該動產**取交**債權人。II 債務人應交付之物為**書據、印章或其他相類之憑證**，而依前項規定執行無效果者，得準用第一百二十一條、第一百二十八條第一項之規定強制執行之。
> **強執 §128 I**　要旨：行為非他人所能代為履行者，債務人不為履行時，執行法院得定履行期間；屆期不履行，處新臺幣 3 萬元以上 30 萬元以下**怠金**；續經定期仍不履行者，得**再處怠金或管收**之。
> **強執 §121**　要旨：書據拒不交出 → 取出，並得公告宣示未交出之書據**無效**，另作**證明書**。
（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「物之交付與行為執行如何區分？」 | 看**執行名義**記載與重視之點 |
| 「命交付帳簿 vs 命容許閱覽帳簿？」 | 交付 → §123 物之交付；閱覽 → **不可代替行為**（§128） |
| 「命製造後交付？」 | 行為＋物之交付**並用** |
| 「一般動產的執行方法？」 | **取交**（直接強制） |
| 「印章拒不交出，取交無效果？」 | 準用 §121 公告無效另作證明書，或 §128 I 處怠金、管收 |
| 「債務人不交印章，執行處刻新印章交債權人？」 | **錯**，只宣示原印章無效、另作證明書 |

## 一、同一給付、不同執行方法

| 例 | 執行名義寫法 | 重點 | 執行方法 |
|---|---|---|---|
| 電力 | 交付已裝入容器之電力 | 容器的交付 | 物之交付 §123 |
| 電力 | 裝設設備後供電 | 裝設行為 | 行為（可代替 §127／不可代替 §128） |
| 帳簿 | 將帳本交給債權人 | 移轉占有 | 物之交付 §123 |
| 帳簿 | 在債務人占有下供閱覽、不得妨礙 | 看內容 | 不可代替行為 §128 |
| 加工物、股票 | 製造或發行後交付 | 兩段 | 行為＋物之交付並用 |

- 老師：這些都是教科書上的例子；合夥人、股東查帳常考

## 二、憑證類動產三種執行方法（下堂再講一次）

```
書據、印章、相類憑證
  ① 取交（§123 I）—— 直接強制
        ↓ 無效果
  ② 準用 §121：公告宣示未交出者無效、另作證明書
  ③ 準用 §128 I：定期履行 → 怠金 3～30 萬 → 再處怠金或管收 —— 間接強制
```

| 方法 | 性質 |
|---|---|
| 取交 | 直接強制 |
| 公告無效、另作證明書 | 證明原物無效，**不另製新物** |
| 怠金、管收 | 間接強制 |
