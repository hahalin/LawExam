# 強制執行法02 筆記：本票裁定與其他法律之執行名義（§4 I ⑥）

## 本票裁定：
- 票據法 §123：執票人向本票發票人行使追索權，得聲請法院裁定後強制執行
- **不必確定**即可聲請強制執行，只要**合法送達生效**
- 同樣不必確定：假扣押、假處分裁定、許可拍賣抵押物裁定；**要確定**：判決、支付命令
- 實務要求附確定證明書，其實是要證明已合法送達（已生效）

## 其他法律規定之執行名義：
- 鄉鎮市調解條例之調解書：須經**法院核定**
- 國家賠償法之**協議書**
- 檢察官**緩起訴**處分命被告給付金錢（給付被害人部分）
- 家事事件法之和解、調解、本案裁判

## 外國確定判決：
- 須經我國法院**許可執行**，不能直接拿來執行（詳筆記 04）

## 📖 法條原文速查

> **強執 §4 I ⑥**　其他依法律之規定，得為強制執行名義者。
> **票據法 §123**　執票人向本票發票人行使追索權時，得聲請法院**裁定後強制執行**。
> **鄉鎮市調解條例 §27**　調解經法院核定後，當事人就該事件不得再行起訴、告訴或自訴。經法院核定之民事調解，與民事確定判決有同一之效力；……（條號、原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「本票裁定須確定後始得聲請強制執行？」 | **不須**，合法送達生效即可 |
| 「下列何者須確定始得為執行名義？」 | **判決、支付命令**；本票裁定、假扣押假處分裁定、拍賣抵押物裁定**不必** |
| 「鄉鎮市調解書得為執行名義之要件？」 | 須經**法院核定** |
| 「國家賠償協議書得為執行名義？」 | **得**（§4 I ⑥ 其他法律） |
| 「緩起訴處分命被告給付金錢，得為民事執行名義？」 | **得** |
| 「債務人對本票裁定提抗告，執行程序？」 | 不影響聲請執行（裁定不必確定） |

## 一、§4 I 六款總覽（本堂位置）

```
§4 I
├── ① 確定終局判決（限給付判決）           ← 筆記 04 末段
├── ② 假扣押、假處分、假執行之裁判等
├── ③ 民訴和解、調解
├── ④ 公證書（逕受強制執行）
├── ⑤ 拍賣抵押物、質物裁定                ← 筆記 01、02
└── ⑥ 其他法律規定                       ← 本筆記
     ├── 本票裁定（票據法 §123）★最重要
     ├── 鄉鎮市調解書（法院核定）
     ├── 國賠協議書
     ├── 緩起訴命被告給付金錢
```

## 二、要不要等確定

| 執行名義 | 須確定？ |
|---|---|
| 確定終局判決 | ✓ |
| 支付命令 | ✓ |
| 本票裁定 | ✗（生效即可） |
| 假扣押、假處分裁定 | ✗ |
| 許可拍賣抵押物裁定 | ✗ |

- 老師實務補充：書記官要看確定證明書，是因為有確定證明書就代表已合法送達；理論上不用等確定。

## 三、本票裁定在本堂其他考點

| 考點 | 結論 | 詳見 |
|---|---|---|
| 題目出現本票，一定是執行名義？ | 不一定；最高限額抵押案中本票只是**債權證明** | 筆記 02 |
| 本票時效 3 年，中斷後重行起算延長為 5 年？ | **不延長**，本票裁定無確定判決同一效力 | 筆記 07 |
| 發票人收受本票裁定後、確定前死亡，可否對繼承人執行？ | **可**，裁定已生效；繼承人為一般繼受人，但限遺產 | 筆記 10 |
| 本票裁定的主觀範圍與判決相同？ | **相同**，§4-2 II 準用 | 筆記 09 |
