# 強制執行法06 筆記：查封的限制（時間、超額、無益、生活必需）

## 時間（§55）：
- 星期日、休息日、日出前、日沒後 → 不得進入**有人居住之住宅**查封（工廠、空屋不受限）
- 例外：急迫情事＋執行法官許可（許可命令應提示債務人）；日沒前已開始者得繼續

## 範圍：
- 超額查封禁止（§50）：以債權額＋執行費用為限；實務折衷——**除極端超額外**不違法，賣到夠就停（§72）
- 無益執行禁止（§50-1）：清償（優先債權＋）執行費後無賸餘 → 不得查封／應撤銷查封

## 債務人生活：
- 酌留 **2 個月**食物、燃料、金錢，含共同生活親屬；得伸縮 **1～3 個月**（§52）
- 禁止查封物七款（§53 I）；顯失公平或**債務人同意** → 仍得查封（§53 II）

## 📖 法條原文速查

> **強執 §55**　I **星期日或其他休息日及日出前、日沒後**，不得進入**有人居住之住宅**實施關於查封之行為。但有急迫情事，經執行法官許可者，不在此限。II 日沒前已開始為查封行為者，得繼續至日沒後。III 第一項許可之命令，應於查封時**提示債務人**。
> **強執 §50**　查封動產，以其價格足清償強制執行之**債權額**及債務人應負擔之**費用**者為限。
> **強執 §50-1**　I 應查封動產之賣得價金，清償強制執行費用後，無賸餘之可能者，執行法院**不得查封**。II 查封物賣得價金，於清償**優先債權及強制執行費用**後，無賸餘之可能者，執行法院應**撤銷查封**，將查封物返還債務人。III 前二項情形，應先詢問債權人之意見，如債權人聲明於查封物賣得價金不超過優先債權及強制執行費用時，願負擔其費用者，不適用之。
> **強執 §52**　I 查封時，應酌留債務人及其共同生活之親屬**二個月**間生活所必需之食物、燃料及金錢。II 前項期間，執行法官審核債務人家庭狀況，得伸縮之。但不得短於**一個月**或超過**三個月**。
> **強執 §53**　I 左列之物不得查封：一、債務人及其共同生活之親屬所必需之衣服、寢具及其他物品。二、職業上或教育上所必需之器具、物品。三、債務人所受或繼承之勳章及其他表彰榮譽之物品。四、遺像、牌位、墓碑及其他祭祀、禮拜所用之物。五、未與土地分離之天然孳息**不能於一個月內收穫**者。六、**尚未發表**之發明或著作。七、附於建築物或其他工作物，而為防止災害或確保安全，依法令規定應設備之機械或器具、避難器具及其他物品。II 前項規定斟酌債權人及債務人狀況，有**顯失公平**情形，仍以查封為適當者，執行法院得依聲請查封其全部或一部。其經**債務人同意**者，亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「星期六晚上得否進入債務人無人居住之倉庫查封？」 | **得**。§55 只限**有人居住之住宅** |
| 「夜間進入住宅查封之例外？」 | ①急迫情事＋**執行法官許可**（許可命令應**提示債務人**）②**日沒前已開始**者得繼續至日沒後 |
| 「債務人欠 50 萬，查封其房屋是否當然違法？」 | **不當然**。實務折衷：查封時無法預知他債權人參與分配，容許適度超額，**除極端超額外**不違法；換價階段賣到足額即停（§72） |
| 「優先債權＋執行費用後無賸餘可能？」 | **無益執行**：未查封 → 不得查封；已查封 → **應撤銷查封**（§50-1 I、II）；債權人願負擔費用者例外（III） |
| 「酌留生活費期間？」 | 原則 **2 個月**，得伸縮 **1～3 個月**；含**共同生活之親屬** |
| 「果樹上一個月內可收穫之橘子得否查封？」 | **得**。不得查封的是**不能**於一個月內收穫者 |
| 「禁止查封物何時仍得查封？」 | **顯失公平**（依聲請）或**債務人同意**（§53 II） |

## 一、四種限制

```
查封的限制
├─ 時間：§55（休息日、夜間、有人居住之住宅）
├─ 範圍：§50 超額查封禁止（天花板＝債權額＋執行費）
│        §50-1 無益執行禁止（剩餘主義：前面有高額優先債權，執行了也輪不到你）
└─ 客體：§52 酌留生活所需、§53 禁止查封物
```

## 二、超額查封：為何容許「稍微超額」

- 參與分配採優先主義的國家必採超額禁止；我國第一個查封的債權人**無法預知**後來會有多少人參與分配、併案（分母會變大）。
- 嚴格貫徹 → 不可能也不合理 → 折衷：**除極端超額外**，查封多一點不違法；拍賣時已足清償債權額及費用者不再拍賣（§72），多出的撤銷查封還給債務人。

## 三、§55 判斷

| 地點 | 休息日／夜間 |
|---|---|
| 有人居住之住宅 | 原則不得；急迫＋法官許可、或日沒前已開始 → 得 |
| 工廠、空屋、非住宅 | 不受限 |
