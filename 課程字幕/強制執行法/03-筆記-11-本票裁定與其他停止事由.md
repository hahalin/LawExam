# 強制執行法03 筆記：本票裁定與其他停止事由

## 強執以外的停止規定：
- 民訴 §491 II：抗告法院等得於抗告裁定前**停止原裁定之執行**
- 公證法 §13 III：得裁定停止公證書之執行
- 民訴 §521 III：支付命令確定後，債務人提**確認債權不存在之訴**，法院**得**命供擔保停止執行
- 非訟 §195：本票裁定之停止（下表）

## 本票裁定三種停止方式：
- **抗告**（§18 II）→ 得停止
- **20 日內**提確認本票**偽造、變造**之訴 → 執行法院**應**停止（唯一「應停止」）
- 逾 20 日或以偽造變造以外原因提確認之訴 → **得**供擔保停止

## 不能停止的情形：
- 聲請**假處分**以停止執行 → **不准**（70 年第 10 次決議等）：假處分只拘束債務人處分，不排除法院執行
- **訴訟外和解** → 非法定停止事由；應提**債務人異議之訴**

## 拍賣抵押物裁定的救濟（均可為停止事由）：
- 抗告、債務人異議之訴（§14）、確認抵押權不存在之訴（實務，舉輕以明重）

## 📖 法條原文速查

> **非訟 §195 I**　發票人主張本票係**偽造、變造**者，於前條裁定送達後**二十日內**，得對執票人向為裁定之法院提起確認之訴。
> **非訟 §195 II**　發票人證明已依前項規定提起訴訟時，執行法院**應停止**強制執行。但得依執票人聲請，許其提供相當擔保，繼續強制執行，亦得依發票人聲請，許其提供相當擔保，停止強制執行。
> **非訟 §195 III**　發票人主張本票債權不存在而提起確認之訴不合於第一項之規定者，法院依發票人聲請，**得**許其提供相當並確實之擔保，停止強制執行。
> **民訴 §521 III**　債務人主張支付命令上所載債權不存在而提起確認之訴者，法院依債務人聲請，**得**許其提供相當並確實之擔保，停止強制執行。

## 📋 實務見解速查

> **最高法院 70 年度第 10 次民事庭會議決議**（考過多次）：禁止債務人就特定財產為處分行為之假處分，其效力**僅在禁止債務人**自由處分，**並不排除法院之強制執行**；其他債權人對該財產聲請執行，非法所不許。（要旨）
> **65 年實務見解**（字號請對講義）：執行名義成立後，除法律別有規定外，不得阻卻其執行力；債務人或第三人**不得依一般假處分程序**聲請停止執行。
> **拍賣抵押物裁定與確認之訴**（字號請對講義）：債務人提起確認抵押權不存在之訴，得聲請受訴法院裁定停止執行。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「發票人於本票裁定送達後 20 日內提確認本票偽造之訴並證明？」 | 執行法院「**應**」停止（非訟 §195 II） |
| 「逾 20 日始提確認偽造之訴？」 | 不當然停止，須供擔保聲請，法院「**得**」停止 |
| 「以本票債權不存在（非偽造變造）提確認之訴？」 | 「**得**」供擔保停止（§195 III） |
| 「執票人對抗 §195 II 停止？」 | 得聲請供擔保**繼續執行** |
| 「債務人得聲請假處分禁止法院執行？」 | **不得**（70 年第 10 次決議） |
| 「支付命令確定後之救濟及停止？」 | 提**確認債權不存在之訴**，**得**供擔保停止（民訴 §521 III） |
| 「訴訟外和解後撤回上訴，債權人仍執行一審判決？」 | 可執行；債務人以和解為由聲請停止**不應准許** → 提**債務人異議之訴** |
| 「拍賣抵押物裁定，債務人提確認抵押權不存在之訴，得聲請停止？」 | **得**（實務） |

## 一、本票裁定停止方式比較

| 方式 | 依據 | 期限 | 效果 |
|---|---|---|---|
| 對本票裁定抗告 | 強執 §18 II | 抗告期間 | 得停止 |
| 確認**偽造變造**之訴 | 非訟 §195 I、II | 送達後 **20 日內** | **應**停止（執票人得供擔保續行） |
| 逾期或其他原因之確認之訴 | 非訟 §195 III | — | 得供擔保停止 |

## 二、拍賣抵押物裁定（§4 I ⑤）的三條救濟

```
許可拍賣抵押物裁定
├── 抗告 → §18 II 第 6 種事由
├── 債務人異議之訴 → §14，§18 II 第 3 種事由
└── 確認抵押權不存在之訴 → 實務肯定（抗告都能停，訴訟更應能停）
→ 三者都可作為停止事由
```

## 三、訴訟外和解案例

```
甲訴乙給付價金 500 萬 → 一審甲全勝 → 乙上訴
二審中甲乙「訴訟外」和解 → 乙撤回上訴 → 一審判決確定
乙不履行和解 → 甲持一審判決聲請執行：可以
乙以有和解為由聲請停止：不應准許（停止事由法定，無訴訟外和解）
乙正確救濟：債務人異議之訴（實體瑕疵）
老師：應成立「訴訟上和解」（有確定判決效力）
```
