# 強制執行法07 筆記：權利移轉證書與危險負擔（§97、§98 I）

## 拍定的效果：
- 拍定（得標）＝買賣契約成立；拍定人負**價金支付義務**，付清後取得標的物所有權
- **先繳足價金，再發權利移轉證書**（§97）——特別規定，沒有同時履行的問題

## 所有權取得時點（§98 I）：
- 買受人自**領得權利移轉證書之日**起取得所有權；債權人承受者亦同
- 不是辦完地政登記時——屬民法 §758 的例外（非依法律行為取得），登記只是事後處分前要辦

## 危險負擔：
- 與民法相同，以**所有權移轉**為分界；執行法上的分界點＝**領得權利移轉證書**
- 移轉前 → 出賣人（＝**債務人**）負擔；移轉後 → 拍定人負擔
- **點交只是移轉現實占有**，不是危險移轉的時點

## 兩則對照：
- 921 地震：已領權利移轉證書、尚未點交，房屋全倒 → 拍定人負擔，**不得撤銷拍賣**
- 92 年座談會：拍定後、未發證書前，債務人**嚴重破壞**致不堪使用 → 非 §69 物之瑕疵可比，依誠信原則**准許撤銷拍賣**

## 📖 法條原文速查

> **強執 §97**　拍賣之不動產，買受人**繳足價金後**，執行法院應發給**權利移轉證書**及其他書據。
> **強執 §98 I**　拍賣之不動產，買受人自**領得**執行法院所發給權利移轉證書**之日起**，取得該不動產所有權，債權人承受債務人之不動產者亦同。
> **強執 §69**　拍賣物買受人就物之瑕疵**無擔保請求權**。（§113 準用於不動產）
> **民法 §373**　買賣標的物之利益及危險，自**交付時**起，均由買受人承受負擔。但契約另有訂定者，不在此限。
（條文原文請對六法；老師課堂說法為「民法上以所有權移轉為危險負擔分界」，與 §373「交付時」的文字不同，考試以執行法 §98 I 時點作答，民法部分請對講義）

## 📋 實務見解

> **921 地震例**（實務見解，字號請對講義）：拍定人已領得權利移轉證書而取得所有權，點交前房屋因地震全倒，屬不可抗力，危險由拍定人負擔，不得聲請撤銷拍賣。

> **92 年座談會**（字號請對講義）：執行法院拍賣債務人房屋拍定後、尚未核發權利移轉證書以前，房屋遭債務人嚴重破壞達不堪使用程度，非 §69 物之瑕疵可比，依誠信原則，應准許拍定人撤銷拍賣程序。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「拍定人何時取得不動產所有權？」 | **領得權利移轉證書之日**（§98 I），非登記完畢時 |
| 「債權人承受者，何時取得所有權？」 | 同上（§98 I 後段） |
| 「拍定人得主張同時履行，要求先發證書？」 | **不得**，先繳足價金才發證書（§97） |
| 「已領證書未點交，房屋因地震倒塌，得撤銷拍賣？」 | **不得**，危險已移轉於拍定人 |
| 「未發證書前，債務人故意毀損房屋，拍定人得撤銷拍賣？」 | **得**（92 年座談會），不受 §69 限制 |
| 「危險負擔移轉時點是點交時？」 | **錯**，點交只是現實占有 |

## 一、時間軸

```
拍定（買賣成立）── 繳足價金 ── 領得權利移轉證書 ──────── 點交
                                │                         │
     危險：債務人（出賣人）負擔  │  危險：拍定人負擔        │ 取得現實占有
                                ▼
                         取得所有權（§98 I）
```

## 二、兩則案例對照

| | 921 地震 | 92 年座談會 |
|---|---|---|
| 發生時點 | **領證後**、點交前 | 拍定後、**領證前** |
| 原因 | 不可抗力（地震全倒） | 債務人**故意嚴重破壞** |
| 所有權人 | 拍定人 | 仍是債務人 |
| 結論 | 拍定人負擔，**不得撤銷拍賣** | **准許撤銷拍賣** |
| 理由 | 所有權已移轉 → 危險移轉 | 非 §69 物之瑕疵可比；誠信原則 |

- 記法：先看「證書領了沒」，再看損害原因。
