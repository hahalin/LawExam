# 強制執行法03 筆記：責任財產的調查與認定

## 範圍：
- 特別法禁止執行（公務人員退休、軍人保險等）→ 現行多設**專戶**，存入專戶仍不得執行
- **未登記、無法登記**之不動產（頂樓加蓋、違建）**可以**作為執行標的
- 以**執行開始時**債務人之財產為準

## 調查：
- 原則**債權人查報**（§19 I 雖寫「得命債權人查報或依職權調查」，實際以查報為主）
- 執行法院**得**向稅捐機關等調查，受調查之機關團體**不得拒絕**；個人有正當理由可拒（§19 II）
- 執行無效果 → 執行法院**應命債權人一個月內查報**（§27 I）
- 開始執行前原則**無庸傳訊當事人**（§9）——避免打草驚蛇

## 認定：
- **外觀調查原則**：動產看**占有**、不動產看**登記**、未登記看公文書、其他財產權看陳報＋發函確認
- 實體歸屬有爭執 → 執行處不認定，由當事人**另訴**（異議之訴）

## 📖 法條原文速查

> **強執 §19 I**　執行法院對於強制執行事件，認有調查之必要時，**得命債權人查報，或依職權調查**之。
> **強執 §19 II**　執行法院得向稅捐及其他有關機關、團體或知悉債務人財產之人調查債務人財產狀況，受調查者**不得拒絕**。但受調查者為個人時，如有正當理由，不在此限。
> **強執 §27 I（前段）**　債務人無財產可供強制執行，或雖有財產經強制執行後所得之數額仍不足清償債務時，執行法院應命債權人於**一個月內查報**債務人財產。
> **強執 §9**　開始強制執行前，除因調查關於強制執行之法定要件或執行之標的物認為必要者外，**無庸傳訊當事人**。
> **民 §1148 II**　繼承人對於被繼承人之債務，以因繼承所得**遺產為限**，負清償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人財產原則由執行法院依職權調查？」 | **錯**，民事執行以**債權人查報**為主 |
| 「受執行法院調查之機關得拒絕？」 | **不得**；僅**個人**有正當理由可拒（§19 II） |
| 「執行法院開始執行前應先傳訊債務人？」 | **無庸**（§9），避免脫產 |
| 「未辦保存登記之違建可否執行？」 | **可以**，依房屋稅單、水電帳單等公文書外觀認定 |
| 「動產、不動產之歸屬如何認定？」 | 動產依**占有**、不動產依**登記**（外觀調查原則） |
| 「查報之動產第三人主張為其所有？」 | 實體爭執，執行處不終局認定 → 命**起訴**（異議之訴） |
| 「執行到繼承人固有財產之救濟？」 | 一般執行名義 → **§15 第三人異議之訴**；保留判決 → 另得 **§12**（詳筆記 02-10） |

## 一、外觀調查原則

```
責任財產認定（執行處只做形式判斷）
├── 動產　　　→ 債務人占有
├── 不動產　　→ 登記名義
│   └── 未登記 → 房屋稅單、水電瓦斯帳單等公文書
├── 其他財產權 → 債權人陳報 → 發函公司／銀行確認
└── 有實體爭執 → 不貿然執行，當事人另向民事庭起訴
```

## 二、查報錯誤怎麼辦（講義概念解析）

| 情形 | 處理 |
|---|---|
| 明顯非債務人所有，尚未執行 | 命債權人另行查報 |
| 明顯非債務人所有，已開始執行 | 停止執行、撤銷已為之處分 |
| 歸屬不明（多為動產） | 命當事人起訴，由民事庭解決 |

## 三、有限責任（簡述，詳筆記 02-10）

```
繼承人對被繼承人債務 → 以遺產為限（民 §1148 II）
執行到固有財產
├── 一般執行名義 → 繼承人就固有財產立於第三人地位 → §15 第三人異議之訴（實體瑕疵）
└── 執行名義載明「以遺產為限」 → 超出執行名義範圍＝程序瑕疵 → 另得 §12 聲明異議（雙重瑕疵）
```
