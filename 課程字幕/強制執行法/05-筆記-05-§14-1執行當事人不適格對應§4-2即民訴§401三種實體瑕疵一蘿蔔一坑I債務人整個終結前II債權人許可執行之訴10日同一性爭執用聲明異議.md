# 強制執行法05 筆記：§14-1 執行當事人不適格之救濟——三種實體瑕疵「一蘿蔔一坑」（講義 131 頁）：執行**名義**瑕疵 → §14；執行**主體**瑕疵（人找錯）→ **§14-1**；執行**客體**瑕疵（財產執行錯）→ §15；§14-1 與 **§4-2**（執行力主觀範圍＝民訴 **§401** 既判力主觀範圍：形式當事人、繼受人、占有人、為他人而為當事人之該他人）**綁定**——違反 §4-2 的執行，救濟就是 §14-1；**I 項（債務人不適格之異議之訴）**：原告**債務人**（被執行的人主張非執行名義效力所及，如已**拋棄繼承**、否認**債務承擔**）、被告債權人、民事庭、**整個**執行程序終結前（與 §14 一起記）、得為 §18 II 停止執行事由；**II 項（許可執行之訴）**：原告**債權人**（依 §4-2 聲請執行遭執行法院**裁定駁回**，如主張為確定判決債權之受讓人——資產管理公司持債權讓與契約、通知債務人文件、執行名義依 §6 聲請）、被告債務人、民事庭、**駁回裁定送達後 10 日不變期間**內、無停止執行問題（本來就沒在執行）；條文「倒著規定」：債務人在前（I）、債權人在後（II）；**同一性爭執**（同名同姓躺著中槍）→ 不是 §14-1，是**程序瑕疵 → §12 聲明異議**（執行名義所載當事人是誰就只能執行誰）

> 來源：強制執行法05 課程字幕 00:42:22 ~ 00:58:40（講義 131、173～175 頁）

## 📖 法條原文速查

> **強執 §14-1 I**　債務人對於債權人依第四條之二規定聲請強制執行，如主張非執行名義效力所及者，得於強制執行程序終結前，向執行法院對債權人提起異議之訴。
> **強執 §14-1 II**　債權人依第四條之二規定聲請強制執行經執行法院裁定駁回者，得於裁定送達後十日之不變期間內，向執行法院對債務人提起許可執行之訴。
> **強執 §4-2 I**　執行名義為確定終局判決者，除當事人外，對於下列之人亦有效力：一、訴訟繫屬後為當事人之繼受人及為當事人或其繼受人占有請求之標的物者。二、為他人而為原告或被告者之該他人及訴訟繫屬後為該他人之繼受人，及為該他人或其繼受人占有請求之標的物者。
> **民訴 §401 I**　確定判決，除當事人外，對於訴訟繫屬後為當事人之繼受人者，及為當事人或其繼受人占有請求之標的物者，亦有效力。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「三種實體瑕疵各用什麼救濟？」 | 執行**名義**（實體請求權）→ §14；執行**主體**（當事人不適格）→ §14-1；執行**客體**（錯誤執行財產）→ §15。一蘿蔔一坑 |
| 「§14-1 對應哪一條？」 | **§4-2**（執行力主觀範圍，解釋與民訴 §401 一模一樣）。違反 §4-2 的執行 → §14-1。懂 §4-2 就知道何時用 §14-1 |
| 「債權人對債務人之繼承人執行，繼承人主張已拋棄繼承？」 | **§14-1 I**：原告繼承人（被執行之債務人）、被告債權人、民事庭、**整個**終結前；得為 §18 II 停止執行事由 |
| 「債權人主張丙承擔確定判決被告乙之債務而對丙執行，丙否認？」 | **§14-1 I**（否認債務承擔＝非 §4-2 繼受人） |
| 「資產管理公司主張為確定判決債權之受讓人聲請執行，執行處裁定駁回？」 | **§14-1 II 許可執行之訴**：原告債權人、被告債務人、民事庭、**裁定送達後 10 日不變期間**。無停止執行問題（根本還沒執行） |
| 「債務人主張只是同名同姓，不是判決書上的人？」 | **§12 聲明異議**（程序瑕疵：未依執行名義所載當事人執行），不是 §14-1 |
| 「對債務人之員工、保全、清潔人員施以強制力？」 | 可。他們是 §4-2 之**占有人**，執行力所及 |
| 「債務人死亡，對繼承人執行？」 | 可（繼受人，執行力擴張所及）；繼承人主張有限責任是另一問題 |

## 一、§14-1 兩項對照

| | I 不適格之異議之訴 | II 許可執行之訴 |
|---|---|---|
| 原告 | **債務人**（被執行者） | **債權人** |
| 被告 | 債權人 | 債務人 |
| 要件 | 主張非執行名義效力所及（§4-2 爭議） | 依 §4-2 聲請執行遭裁定駁回（§4-2 爭議） |
| 法院 | 民事庭 | 民事庭 |
| 時點 | **整個**執行程序終結前 | **駁回裁定送達後 10 日**不變期間 |
| 停止執行 | 得（§18 II） | 無（本未執行） |
| 例 | 拋棄繼承、否認債務承擔 | 債權受讓人（資產管理公司）被執行處打槍 |

## 二、三種瑕疵圖

```
執行名義瑕疵 → §14（整個終結前）
執行主體瑕疵 → §14-1（I 債務人／II 債權人）→ 對應 §4-2 ＝ 民訴 §401
執行客體瑕疵 → §15（個別終結前）
同一性爭執（同名同姓）→ 程序瑕疵 → §12
```

- 記法：§14-1 I 廣義上還是一種債務人異議之訴（原告都是債務人），時點跟 §14 一起記＝整個終結前。
- 停止執行要向**受訴法院（民事庭）**聲請，拿裁定到執行處；執行處無法自己決定停止。
