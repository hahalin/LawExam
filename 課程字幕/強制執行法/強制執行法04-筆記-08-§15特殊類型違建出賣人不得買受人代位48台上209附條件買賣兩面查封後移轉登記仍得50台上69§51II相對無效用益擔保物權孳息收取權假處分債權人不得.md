# 強制執行法04 筆記：第三人異議之訴的特殊類型——違建（原始建築人已出賣、形式上仍為所有人 → **不得**提，50 台上 1236；非債務人之真正買受人僅有事實上處分權 → 不得直接提，得**代位**原所有人提，48 台上 209）；附條件買賣（買受人之債權人執行 → **出賣人得**提；出賣人之債權人執行 → **買受人得**提）；查封後移轉登記之受讓人仍**得**提（50 台上 69：登記有絕對真實公信力；§51 II 相對無效，債權人應另訴塗銷登記）；用益物權人視占有使用是否受侵害（不點交 → 不得；點交、強制管理 → 得）；擔保物權：質權、留置權喪失占有 → 得；權利質權扣押命令不得、換價命令得；抵押權原則**不得**（§98 III 拍賣消滅、§34 II 強制參與分配優先受償），張登科例外；天然孳息收取權人 → **得**（§53 I ⑤ 一個月內收穫可執行）；假處分債權人 → **不得**（70 年第 10 次決議：僅禁止債務人處分，不排除法院強制執行）

## 📖 法條原文速查

> **強執 §51 II**　實施查封後，債務人就查封物所為移轉、設定負擔或其他有礙執行效果之行為，對於債權人不生效力。→ **相對無效**
> **強執 §98 III**　存於不動產上之抵押權及其他優先受償權，因拍賣而消滅。……（原文請對六法）
> **強執 §34 II**　依法對於執行標的物有擔保物權或優先受償權之債權人，不問其債權已否屆清償期，應提出其權利證明文件，聲明參與分配。（強制參與分配，原文請對六法）
> **強執 §53 I ⑤**　未與土地分離之天然孳息不能於一個月內收穫者（不得查封）。→ 反面：一個月內可收穫者得執行
> **強執 §115**　就債務人對第三人之金錢債權為執行：禁止命令（扣押）→ 收取、支付轉給、移轉命令（換價）。（條項請對六法）

## 📋 實務見解速查

> **50 年台上字第 1236 號**（違建出賣人）：原始建築人既已將建築物出賣，即負有交付之義務；買受人之債權人將之查封，原建築人負有忍受之義務，不得提第三人異議之訴。
> **48 年台上字第 209 號**（違建真正買受人）：真正買受人因不能登記，不能主張所有權提第三人異議之訴，但得**代位**原所有人提起。
> **50 年台上字第 69 號**（查封後移轉登記）：依土地法所為之登記有絕對真實之公信力，縱債務人之處分有無效原因，債權人未提起**塗銷登記之訴**並得勝訴確定判決前，登記不失效力；第三人仍有足以排除強制執行之權利。
> **70 年第 10 次民庭決議**（假處分債權人）：禁止處分之假處分僅禁止債務人自由處分，不排除法院之強制執行；假處分債權人對其他債權人之執行無優越地位，不得提第三人異議之訴。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「丙出資興建違建後出賣予乙（事實上處分權移轉，乙占有使用），乙之債權人甲執行該違建，丙以形式上所有人提 §15？」 | **不得**（50 台上 1236）。賣掉錢也拿了，負有交付義務，對買受人之債權人查封有忍受義務 |
| 「債務人乙非違建買受人，真正買受人是丁（事實上處分權），執行該違建？」 | 錯誤執行。丁無所有權**不得直接**提 §15（§15 須物權等級之權利），但得**代位**原所有人丙提起（48 台上 209） |
| 「附條件買賣（分期付款），買受人未繳清前，**買受人之債權人**執行該物，出賣人得否提 §15？」 | **得**（肯定說）。價金未清償前所有權保留於出賣人，用以擔保價金債權 |
| 「反過來，**出賣人之債權人**執行該物，買受人得否提？」 | **得**（實務，較特別）。買受人依契約有占有標的物、使用收益並繼續繳款以取得所有權之權利，無忍受理由 |
| 「乙之 A 地經查封後，乙仍移轉登記予丙，丙得否提 §15？」 | **得**（50 台上 69）。登記有絕對真實公信力；§51 II 查封效力是**相對無效**（對債權人不生效力，非絕對無效）→ 債權人應另提**塗銷登記之訴** |
| 「地上權人、典權人得否提？」 | 視執行結果是否侵害其**占有使用收益**：拍賣條件不點交 → 不受影響 → 不得；拍賣點交、強制管理、物之交付執行 → 剝奪占有 → 得 |
| 「質權人、留置權人？」 | 以占有為成立存續要件 → 執行致其喪失占有 → **得** |
| 「權利質權人？」 | 僅扣押命令（禁止處分）→ 不得；收取、支付轉給、移轉等**換價命令**（債權可能因清償而消滅）→ 得 |
| 「抵押權人？」 | 原則**不得**：抵押權因拍賣而消滅（§98 III）但就價金優先受償、強制參與分配（§34 II），權益不受影響。張登科例外：抵押物一部執行致整體擔保價值大幅下降（廠房與機器共同抵押，僅執行機器）→ 應許提 |
| 「承租土地種菜之天然孳息收取權人，地主之債權人查封該孳息？」 | **得**提（無忍受義務）。前提：一個月內可收穫之天然孳息得執行（§53 I ⑤ 反面） |
| 「假處分之債權人，其他債權人對同一標的物執行？」 | **不得**提（70 年第 10 次決議）。假處分只禁止**債務人**處分，不排除法院強制執行；假處分債權人無優先地位，不能藉假處分變成優先受償 |

## 一、違建兩題（圖）

```
題一：丙（出資興建、形式所有人）─出賣違建→ 乙（買受人、占有）←甲執行
      丙提 §15？✗（已出賣、負交付義務、對乙之債權人有忍受義務）
題二：丙 ─出賣→ 丁（真正買受人、事實上處分權）；乙只是借住，甲（乙之債權人）執行 → 錯誤執行
      丁直接提 §15？✗（無所有權）→ 丁代位丙提 §15 ✓
```

- 違建複習：出資興建者原始取得所有權；不能登記；可交易，移轉的是**事實上處分權**；可作為執行標的（未辦保存登記但有財產價值）。

## 二、附條件買賣：兩面都保護

| 誰的債權人執行 | 誰得提 §15 | 理由 |
|---|---|---|
| 買受人（消費者）的債權人 | 出賣人（店家） | 所有權保留，擔保價金 |
| 出賣人（店家）的債權人 | 買受人（消費者） | 占有使用、繼續繳款取得所有權之契約上權利 |

## 三、查封後移轉登記

```
查封 → 乙違反 §51 II 將 A 地移轉登記予丙（相對無效）
丙：登記名義人、非執行債務人 → 提 §15 ✓（50 台上 69：登記絕對真實公信力）
債權人反制：另訴塗銷登記之訴
```

## 四、各種權利人一覽

| 權利 | 得否提 §15 | 關鍵 |
|---|---|---|
| 所有權 | ✓ | 典型 |
| 違建原始建築人（已出賣） | ✗ | 50 台上 1236 |
| 違建真正買受人 | 代位 ✓ | 48 台上 209 |
| 附條件買賣出賣人／買受人 | ✓／✓ | 看誰的債權人執行 |
| 查封後受讓登記人 | ✓ | 50 台上 69 |
| 用益物權人 | 視占有是否受侵害 | 不點交 ✗；點交、強制管理 ✓ |
| 質權、留置權人 | ✓（喪失占有） | 以占有為要件 |
| 權利質權人 | 扣押命令 ✗／換價命令 ✓ | §115 |
| 抵押權人 | 原則 ✗ | §98 III、§34 II；張登科例外 |
| 天然孳息收取權人 | ✓ | §53 I ⑤ |
| 單純占有人 | ✗ | 44 台上 721 |
| 假處分債權人 | ✗ | 70 年第 10 次決議 |
