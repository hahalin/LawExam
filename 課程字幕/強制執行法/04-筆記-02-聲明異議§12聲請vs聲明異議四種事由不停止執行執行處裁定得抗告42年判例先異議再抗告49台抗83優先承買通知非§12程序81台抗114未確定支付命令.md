# 強制執行法04 筆記：聲明異議 §12——「聲請」（執行機關怠於作為，請求其作為）vs「聲明異議」（作為有錯）；四種事由（命令、方法、程序、其他侵害利益情事）選擇題不用分，都是程序瑕疵；**不停止執行**；由執行處裁定，不服得抗告（§12 III）；執行處以裁定形式為之者仍應先聲明異議再抗告（42 年判例：變更拍賣期日）；實體法上之通知義務（土地法 §104、三七五減租條例 §15 優先承買通知）非 §12「應遵守之程序」，只能以訴救濟（49 台抗 83）；無執行名義＝拿白紙執行：未確定之支付命令不得據以執行，執行法院獨立審查、不受確定證明書拘束（81 台抗 114）；當事人及利害關係人皆得提、不要式、向實施執行之受託法院為之、可反覆提起

## 📖 法條原文速查

> **強執 §12**　I 當事人或利害關係人，對於執行法院強制執行之命令，或對於執行法官、書記官、執達員實施強制執行之方法，強制執行時應遵守之程序，或其他侵害利益之情事，得於強制執行程序終結前，為聲請或聲明異議。但強制執行不因而停止。II 前項聲請及聲明異議，由執行法院裁定之。III 不服前項裁定者，得為抗告。
> **強執 §4 I**　強制執行，依左列執行名義為之：一、確定之終局判決。二、假扣押、假處分、假執行之裁判及其他依民事訴訟法得為強制執行之裁判。三、依民事訴訟法成立之和解或調解。四、依公證法規定得為強制執行之公證書。五、抵押權人或質權人，為拍賣抵押物或質物之聲請，經法院為許可強制執行之裁定者。六、其他依法律之規定，得為強制執行名義者。
> **強執 §47、§76**　動產查封方法（實施占有、標封、烙印火漆印）／不動產查封方法（揭示、封閉、追繳契據，並為查封登記）→ 未依法為之即程序瑕疵（原文請對六法）

## 📋 實務見解速查

> **42 年台抗字判例**（字號請對講義 135 頁）：變更拍賣不動產期日屬實施強制執行之方法，對此裁定僅得依 §12 I 向執行法院聲明異議；對聲明異議之裁定不服，始得依同條 III 抗告。
> **49 年台抗字第 83 號**（講義 136 頁）：三七五減租條例 §15 之優先承買通知，無妨由拍賣機關踐行，但非 §12 所謂執行時應遵守之程序；執行法院未踐行或踐行不當，承租人只能以訴救濟，不得引為聲請或聲明異議之依據。
> **81 年台抗字第 114 號**（講義 136 頁，考過 N 次）：執行法院對執行名義是否有效成立應自行審查；未確定之支付命令不具執行名義要件，不得據以執行。法院誤認未確定裁判為確定而發給確定證明書，不生確定之效力，執行法院不受該確定證明書拘束。
> **院字第 2776 號解釋 ④**：聲明異議經裁定駁回確定後，復以同一理由聲明異議而認有理由者，法院得為相反之裁判 → 可反覆提起。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「聲請與聲明異議？」 | 聲請：執行機關**不做**（怠惰）→ 請求為作為或不作為。聲明異議：做了但**做錯**。口頭上統稱聲明異議 |
| 「§12 I 四種事由？」 | ① 執行法院強制執行之命令 ② 執行法官、書記官、執達員實施強制執行之方法 ③ 強制執行時應遵守之程序 ④ 其他侵害利益之情事。選擇題不須區分，全是程序瑕疵 |
| 「聲明異議是否停止執行？」 | **不停止**（§12 I 但書）。與異議之訴最大差別 |
| 「由誰裁定？不服？」 | **執行處**裁定（§12 II）；不服得**抗告**（§12 III） |
| 「執行處以裁定形式為執行處分（變更拍賣期日），救濟用抗告還是聲明異議？」 | 實務：§12 是特別規定優先適用 → **先聲明異議**，對異議裁定不服再抗告（42 年判例）。沒有剝奪抗告權，只是多一道讓執行處自我反省 |
| 「執行法院未通知優先承買權人（土地法 §104、三七五減租 §15），承租人得否聲明異議？」 | **不得**（49 台抗 83）。實體法上之通知義務非 §12「應遵守之程序」→ 只能以訴救濟 |
| 「債權人持未確定之支付命令聲請執行，債務人如何救濟？」 | **聲明異議**（81 台抗 114）。無執行名義（執行名義未有效成立、欠缺執行力）＝拿白紙執行＝程序瑕疵。執行法院獨立審查，不受民事庭誤發的確定證明書拘束 |
| 「誰可以聲明異議？要式？向誰？」 | 當事人（債權人、債務人）及利害關係人（第三人）皆可；不一定有相對人；口頭或書面皆可（查封現場舉手講）；向**執行處**；囑託他法院執行者向實際實施執行之**受託法院** |
| 「聲明異議駁回確定後可否以同一理由再提？」 | **可**。不是訴訟，無重複提起限制（院 2776 ④） |

## 一、§12 的結構

```
主體：當事人、利害關係人
事由：命令／方法／程序／其他侵害利益情事（＝任何違反執行法之處）
時點：強制執行程序終結前（整個 or 個別 → 筆記 03）
效果：不停止執行
程序：執行處裁定 → 抗告
```

## 二、程序瑕疵的例子

| 類型 | 例 |
|---|---|
| 命令 | 無夜間、星期日執行之必要卻許可 |
| 方法 | 動產查封未依 §47 實施占有、標封、烙印、火漆印；不動產查封未依 §76 揭示、封閉、追繳契據、查封登記 |
| 其他情事 | **無執行名義**：支付命令未確定、判決未確定、公證書不具公證法 §13 要件 |

## 三、三個實務見解各管一件事

| 判解 | 問題 | 結論 |
|---|---|---|
| 42 年判例 | 裁定形式的執行處分，抗告還是聲明異議？ | 先聲明異議，再抗告 |
| 49 台抗 83 | 實體法通知義務是不是 §12 程序？ | 不是，只能以訴救濟 |
| 81 台抗 114 | 未確定支付命令可否執行？ | 不可；執行法院獨立審查 → 聲明異議 |

- 實務：收到支付命令還不能執行，要等**確定證明書**；拿裁定本身去聲請執行會被打回票。

## 四、105 年考題

- 甲以確定支付命令為執行名義聲請執行，但支付命令未合法送達（異議期間無從起算，三個月未送達失效）→ 不確定 → 救濟方式 **C 聲明異議**。同一見解換各種方式考。
