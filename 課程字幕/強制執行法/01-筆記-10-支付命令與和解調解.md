# 強制執行法01 筆記：支付命令與和解調解

## 確定支付命令（§4 I ②後段）：
- 債務人於送達後 **20 日**不變期間內未合法**異議** → 支付命令得為執行名義（民訴 §516、§521 I）
- 聲請執行要附：支付命令＋**確定證明書**（民訴 §521 II）
- 確定後**無既判力**（104 年修法前可再審）；債務人可提**確認債權不存在之訴**，並聲請供擔保**停止執行**（§521 III，「得」停止，同強執 §18 II 意旨）

## 民訴和解、調解（§4 I ③）：
- 訴訟上和解、調解成立 → **與確定判決同一效力**（既判力＋執行力）（民訴 §380 I、§416 I）
- **第三人參加**和解、或就**未聲明事項**成立和解，也**得為執行名義**（民訴 §377 II、§380-1）

## 陷阱：
- 民法上和解、**執行程序中和解** → 只有民法效力，**不是**執行名義
- 鄉鎮市調解經**法院核定** → 也與確定判決同一效力（第 6 款）

## 📖 法條原文速查

> **民訴 §516 I**　債務人對於支付命令之全部或一部，得於送達後**二十日**之不變期間內，**不附理由**向發命令之法院提出異議。
> **民訴 §521**　I 債務人對於支付命令**未於法定期間合法提出異議**者，支付命令**得為執行名義**。II 前項支付命令，於確定後，法院應付與**裁定確定證明書**。III 債務人主張支付命令上所載債權不存在而提起**確認之訴**者，法院依債務人聲請，**得**許其提供相當並確實之擔保，**停止強制執行**。
> **民訴 §380 I**　和解成立者，與**確定判決有同一之效力**。
> **民訴 §416 I**　調解經當事人合意而成立；調解成立者，與**訴訟上和解有同一之效力**。（原文請對六法）
> **民訴 §377 II**　第三人經法院之許可，得**參加和解**。法院認為必要時，亦得通知第三人參加。
> **民訴 §380-1**　當事人就**未聲明之事項**或**第三人參加和解**成立者，得為執行名義。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「支付命令送達後即得為執行名義？」 | **錯**。須 20 日內**未合法異議**（確定）後 |
| 「確定之支付命令有既判力？」 | **無**（現行法） |
| 「債務人提起確認支付命令債權不存在之訴，法院應停止執行？」 | **得**停止（供擔保），非「應」 |
| 「訴訟上和解成立之效力？」 | 與確定判決同一效力：**既判力＋執行力** |
| 「第三人參加訴訟上和解，得否對該第三人強制執行？」 | **得**（民訴 §380-1） |
| 「就起訴未聲明之事項成立和解，得為執行名義？」 | **得**（民訴 §380-1） |
| 「債權人與債務人於強制執行程序中達成和解，該和解書得為執行名義？」 | **不得**，只有民法效力 |

## 一、支付命令流程

```
債權人向法院（非訟，司法事務官）聲請支付命令（裁判費 500 元）
   ▼ 送達債務人
20 日不變期間（民訴 §516）
   ├─ 合法異議 → 支付命令失效（轉訴訟程序）
   └─ 未異議 → 確定 → 法院發確定證明書（§521 II）
             → 支付命令＋確定證明書＝執行名義
             → 債務人事後救濟：確認債權不存在之訴＋得聲請停止執行（§521 III）
```

- 常見情節：債務人把法院寄的支付命令當詐騙丟掉，等存款被扣才來問律師 → 提確認債權不存在之訴。
- 老師：§521 III 本質是執行規定，類似強執 §18 II。

## 二、各種「和解／調解」能不能執行

| 類型 | 執行名義？ | 依據 |
|---|---|---|
| 訴訟上和解（法院內） | **可** | §4 I ③、民訴 §380 |
| 法院調解 | **可** | §4 I ③、民訴 §416 |
| 鄉鎮市調解經法院核定 | **可** | §4 I ⑥、鄉鎮市調解條例 §27 |
| 民法上和解契約 | ✗ | 只有實體效力 |
| 執行程序中和解 | ✗ | 只有民法效力；債務人用 §14 救濟 |

## 三、和解擴張

```
甲訴乙請求 100 萬 → 和解時乙之親人丙加入當保證人（第三人參加）
  → 丙之給付義務也有執行力（民訴 §380-1）
  → 立法目的：擴大和解解決紛爭的功能
```
