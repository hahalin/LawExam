# 強制執行法01 筆記：執行方法（直接代替間接強制）

## 直接強制：
- **金錢請求權**（查封、換價、滿足）與**物之交付**（直接移轉占有）都走直接強制
- 物之交付的術語＝**點交**＝**占有移轉**（動產、不動產皆同）

## 行為：先分可代替／不可代替：
- **可代替行為**（拆屋、多數修漏水）→ **代替執行**：命第三人或債權人代為，費用由債務人負擔 → 最後變成金錢義務（§127）
- **不可代替行為**（請特定歌手開演唱會、依債之本質須本人履行）→ **間接強制**：**怠金**或**管收**（§128）
- 判斷看**債之本質**與判決主文著重的是結果還是本人

## 不行為：
- 不作為性質上就是**不可代替** → 也用間接強制（怠金、管收）（§129）
- 實務幾乎不管收，主要處怠金

## 📖 法條原文速查

> **強執 §127 I**　依執行名義，債務人應為一定行為而不為者，執行法院得以**債務人之費用**，命**第三人代為履行**。（原文請對六法）
> **強執 §128 I**　依執行名義，債務人應為一定之行為，而其行為**非他人所能代履行**者，債務人不為履行時，執行法院得定債務人履行之期間。債務人不履行時，得處新臺幣三萬元以上三十萬元以下之**怠金**。其續經定期履行而仍不履行者，得再處怠金或**管收**之。（原文請對六法）
> **強執 §129 I**　執行名義係命債務人容忍他人之行為，或禁止債務人為一定之行為者，債務人不履行時，執行法院得處新臺幣三萬元以上三十萬元以下之怠金。其仍不履行時，得再處怠金或管收之。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「命債務人拆除地上房屋之判決，執行方法？」 | 可代替行為 → **代替執行**，費用由債務人負擔 |
| 「命債務人修繕漏水之判決，執行方法？」 | 多數認為**可代替**（重在修好）→ 代替執行（**國考考過**）；仍看判決主文 |
| 「命特定歌手履行演出之判決，執行方法？」 | **不可代替** → 間接強制：**怠金、管收** |
| 「命債務人夜間 10 點後不得彈鋼琴，違反時？」 | 不行為＝性質上不可代替 → **處怠金**（§129） |
| 「拆屋還地中的『還地』屬何種執行？」 | **物之交付**（不動產交付），方法為直接強制＝點交 |
| 「點交之意義？」 | **占有移轉**（自債務人或第三人移轉給債權人） |
| 「代替執行屬間接強制？」 | **錯**。間接強制只有**怠金、管收**（給心理壓力） |

## 一、執行方法總圖（講義重點圖）

```
金錢請求權 ─────────────── 直接強制（查封→換價→滿足）
物之交付請求權 ─────────── 直接強制（點交＝占有移轉）
                              ├ 動產交付
                              └ 不動產交付
行為不行為請求權
  ├─ 行為
  │   ├─ 可代替 ───────── 代替執行（第三人代履行，債務人出錢）§127
  │   └─ 不可代替 ─────── 間接強制（怠金／管收）§128
  └─ 不行為 ＝性質上不可代替 ─ 間接強制（怠金／管收）§129
```

## 二、三種方法定義

| 方法 | 定義 | 例 |
|---|---|---|
| 直接強制 | 執行機關的行為直接實現執行名義內容 | 法拍房子、取走鑽戒 |
| 代替執行 | 授權第三人或債權人代履行，費用由債務人負擔 | 找拆除師傅拆屋、找師傅修漏水 |
| 間接強制 | 以間接方法對債務人心理施壓，促其自動履行 | 怠金（罰錢）、管收（關起來） |

## 三、可代替 vs 不可代替判斷

```
判決要求的行為
   │ 由債務人做 vs 由第三人做，法律上、經濟上效果相同？
   ├─ 相同 → 可代替：拆屋、多數修繕（債務人可能根本不會修）
   └─ 不同 → 不可代替：特定明星開演唱會（找別的歌手不行）
             蓋房子 → 看債之本質與約定內容，可能兩種都有
```

## 四、案例：拆屋還地

```
甲訴請乙（無權占有）拆屋還地勝訴（民法 §767 I）
  ├─ 拆屋：可代替行為 → 代替執行，拆除費由乙負擔
  └─ 還地：物之交付（不動產）→ 點交給甲
→ 一個執行程序混用多種方法，常見
```
