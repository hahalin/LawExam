# 強制執行法03 筆記：執行程序終結與債權憑證

## 整個 vs 個別：
- **整個**執行程序＝同一執行名義對債務人全部標的（A 車＋B 地）之程序；終結＝**結案** → §14 債務人異議之訴所稱終結
- **個別**（各個）執行程序＝單一標的物之查封、換價、滿足；到滿足即終結 → §15 第三人異議之訴所稱終結

## 整個終結四事由：
- 請求權與執行費**完全滿足**
- 執行無效果，**發給債權憑證**（最常見）
- 債權人**撤回**聲請（不退費；得再以同一執行名義聲請）
- 提出文書（再審、異議之訴勝訴確定判決等）→ 撤銷執行處分

## 債權憑證：
- 限**金錢債權之終局執行**；保全執行、非金錢執行不發
- 效力：①程序終結 ②時效**重行起算** ③本身是**執行名義**
- 「俟發見有財產時再予執行」只是提醒，**不是**限制

## 📖 法條原文速查

> **強執 §27 I**　債務人無財產可供強制執行，或雖有財產經強制執行後所得之數額仍不足清償債務時，執行法院應命債權人於一個月內查報債務人財產。債權人到期不為報告或查報無財產者，應**發給憑證**，交債權人收執，載明**俟發見有財產時，再予強制執行**。
> **強執 §27 II**　債權人聲請執行，而陳明債務人現無財產可供執行者，執行法院得**逕行發給憑證**。
> **民 §137 I**　時效中斷者，自中斷之事由終止時，**重行起算**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§14 債務人異議之訴之『執行程序終結』指？」 | **整個**執行程序終結 |
| 「§15 第三人異議之訴之『執行程序終結』指？」 | **個別**（該標的物）執行程序終結 |
| 「假扣押執行無效果，發給債權憑證？」 | **不發**，限**金錢債權終局執行** |
| 「債權憑證可否作為執行名義？」 | **可以** |
| 「未發現債務人新財產，得否持債權憑證聲請執行？」 | **可以**；「俟發見有財產」非限制規定。債務人有無財產從來不是執行要件 |
| 「發給債權憑證後時效？」 | 程序終結，**重行起算** |
| 「撤回執行後得否再依同一執行名義聲請？」 | **可以**，撤回只是拋棄該程序利益 |
| 「§12 聲明異議有停止執行效力？」 | **沒有**；異議之訴才是停止事由（§18 II） |

## 一、整個與個別（老師板書）

```
債權人甲（一份執行名義）→ 債務人乙
├── A 車：查封 → 換價 → 滿足 ┐ 各個（個別）執行程序
├── B 地：查封 → 換價 → 滿足 ┘ → §15 第三人異議之訴的終結點
└── 全部合起來＝整個執行程序 → §14 債務人異議之訴的終結點（結案）
```

## 二、整個執行程序終結事由

| # | 事由 | 備註 |
|---|---|---|
| 1 | 請求權及執行費全部滿足 | 少見 |
| 2 | 執行無效果，發債權憑證 | 最常見 |
| 3 | 債權人撤回 | 不退費（不準用民訴 §83）；可再聲請 |
| 4 | 提出廢棄執行名義或宣告不許執行之確定裁判 | 執行處撤銷執行處分 |

## 三、債權憑證與執行費（複習筆記 06）

```
原執行名義已繳足 → 日後持憑證再聲請 → 不重複繳
逕行發給（只繳 1,000）→ 日後實際執行財產 → 補千分之八差額
```

## 四、下堂預告：救濟二分

| | 程序瑕疵 | 實體瑕疵 |
|---|---|---|
| 救濟 | §12 **聲明異議**（向執行處） | **異議之訴**（向民事庭） |
| 停止執行 | **不停止** | 是 §18 II 停止事由 |
