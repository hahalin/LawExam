# 強制執行法04 筆記：債務人異議之訴最難的地方——異議事由發生時期的限制：執行名義**有確定判決同一效力**時，異議事由須發生於**既判力基準時以後**（新事由）；基準時：確定判決＝最後事實審言詞辯論終結時，和解調解＝成立時；既判力之遮斷效＝失權效，遮的是攻擊防禦方法（基準時前能提未提者，之後不得再以 §14 主張）；**無既判力**之執行名義（支付命令、公證書、本票裁定、拍賣抵押物裁定、大陸裁判經認可）不畫圖，事由在前在後皆可提（只是條項不同）；**抵銷**以實際行使時為準（不能強迫債務人抵銷 → 基準時前得抵銷、之後才行使仍可提）；**撤銷、解除、時效完成**須於本案訴訟主張，否則被遮斷（否定說：請求權本身有瑕疵，無效都被遮斷，較輕的撤銷反得主張失衡）；執行開始前不得預先提起（20 年判例）；敗訴後另訴侵權或不當得利可

> 來源：強制執行法04 課程字幕 01:08:00 ~ 01:21:00、01:31:50 ~ 01:41:00、01:46:00 ~ 01:56:00（講義 148～151、154～156 頁）

## 📖 法條原文速查

> **強執 §14 I 後段**　如以裁判為執行名義時，其為異議原因之事實發生在**前訴訟言詞辯論終結後**者，亦得主張之。→ 新的事由
> **民訴 §400 I**　除別有規定外，確定之終局判決就經裁判之訴訟標的，有既判力。
> **民法 §334 I、§335 I**　抵銷之要件；抵銷應以意思表示向他方為之。（原文請對六法）

## 📋 實務見解速查

> 有既判力之執行名義，其請求權於既判力基準時確定存在，為既判力所確定之事實，不許債務人事後另藉異議之訴否定，以免與既判力牴觸 → 與既判力相牴觸之事項不得為異議事由。
> **抵銷（肯定說，實務）**：抵銷非於債務適於抵銷時當然發生效力，須一方對他方為抵銷之意思表示始生效力；是否抵銷為債務人之自由 → 以**實際行使時**認定異議事由發生時點 → 言詞辯論終結前雖具抵銷適狀未主張，確定後仍得主張。
> **撤銷（否定說為大宗，實務）**：撤銷權係因請求權本身具有瑕疵，此瑕疵於言詞辯論終結前已存在而未主張，即為既判力所遮斷；否則無效之事由既受既判力阻卻，瑕疵較輕之撤銷反得主張，有失均衡。
> **20 年判例**（講義 154 頁，字號請對講義）：異議之訴於實施執行時始得提起；未及執行、僅因某項財產有被執行之虞而預先起訴，其目的仍為確認，無所謂異議之訴。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「何時要畫『基準時』的圖？」 | 兩要件都滿足：① 考的是**債務人異議之訴**（§14，實體瑕疵）② 執行名義**有確定判決同一效力**（確定判決、訴訟上和解調解、仲裁判斷）。聲明異議、§15 第三人異議之訴沒有這個問題 |
| 「基準時在哪？」 | 確定判決：**最後事實審言詞辯論終結時**；和解、調解等無言詞辯論者：**成立時** |
| 「遮斷效遮什麼？」 | 遮**攻擊防禦方法**，不是訴訟標的。基準時前能提出的攻防方法（清償、抵銷、時效…）全部要在本案提出，沒提就**失權** |
| 「債務人於第二審審理中已清償，判決確定後被執行，得否提 §14？」 | **不得**。清償發生在基準時前＝舊事由 → 被遮斷 |
| 「債務人於判決確定後清償，仍被執行？」 | **得**（§14 I 後段「發生在前訴訟言詞辯論終結後」＝新事由） |
| 「執行名義是支付命令／公證書／本票裁定／拍賣抵押物裁定／大陸裁判經裁定認可？」 | **無既判力**，不畫圖、不遮斷；異議事由發生在成立前（§14 II）或成立後（§14 I）皆可提 |
| 「基準時前已具抵銷適狀，當時未主張，執行中始行使抵銷，得否提 §14？」 | **得**（肯定說）。抵銷以**實際行使時**為異議事由發生時點；民法不能強迫債務人抵銷 |
| 「基準時前已有得撤銷原因未行使，執行中始撤銷？」 | **不得**（否定說）。撤銷權是請求權本身的瑕疵，本案就該主張，未主張即遮斷；解除權、時效完成（基準時前已完成未為抗辯）同此結論 |
| 「尚未開始執行，債務人擔心某財產被執行而預先提 §14？」 | **不得**（超前部署 ✗，20 年判例）。沒有執行程序就沒有異議之訴 |
| 「異議之訴敗訴確定後，得否另依侵權行為或不當得利對債權人起訴？」 | **得**，訴訟標的不同，不違反重複起訴禁止 |

## 一、圖（考試遇到有確定判決效力的 §14 題就畫）

```
                    基準時（最後事實審言詞辯論終結／和解調解成立）
 ───────────────────────┼─────────────────────────
   A 事由（舊）：被遮斷 ✗ │  B 事由（新）：得提 §14 ✓
   §14 II（成立前）      │  §14 I（成立後）
```

- 題目給抵銷、清償、時效等事由 → 標在圖上的相對位置：第二審中 → 左邊（✗）；執行程序中 → 右邊（✓）。
- 無既判力的執行名義：同一張圖但**不畫斜線**（不遮斷），只是左邊用第二項、右邊用第一項。

## 二、跨越基準時的形成權：抵銷 vs 撤銷／解除／時效

| | 抵銷 | 撤銷、解除、時效完成 |
|---|---|---|
| 性質 | 兩個獨立成立的債權互抵，不是請求權的瑕疵 | 請求權本身有瑕疵 |
| 要不要在本案主張 | 不用（抵銷與否是債務人自由） | 要（本案能主張未主張 → 失權） |
| 異議事由時點 | **實際行使時** | 瑕疵存在時（基準時前）→ 被遮斷 |
| 結論 | 執行中行使 → 得提 §14 | 執行中始行使 → 不得 |

- 記法：**抵銷特別**，其他三個（撤銷、解除、時效）結論一樣。

## 三、已終結部分不得撤銷（§14 也一樣）

- 院 2776：個別標的物執行程序雖已終結，整個程序未終結前仍得提 §14；但有理由之判決僅就執行名義所載債權**未達目的之部分**排除執行力，不能撤銷已終結之執行處分（買受人已取得所有權）→ 只能就後續分配價金主張。

## 四、考題

### 講義 155 頁
```
甲以金錢債權確定判決執行乙之房屋，丙拍定繳足價金、領得權利移轉證書（丙取得所有權 §98 I）
乙於價金分配前主張「確定判決後」已清償 → 實體 → 有確定判決效力要畫圖 → 清償在基準時後＝新事由 → §14 ✓
答案 B 債務人異議之訴（但已終結之拍賣不能撤銷，只能就價金主張）
```

### 講義 156 頁（許可拍賣抵押物裁定，選錯誤）
```
A 裁定送達後不待確定即得執行 ✓
B 聲請執行除裁定正本外應提出債權及抵押權證明文件 ✓（§6；從屬性）
C 僅得就裁定所載抵押物 A 地執行，不及於共同擔保之 B 地 ✓（對物的執行名義，記載什麼執行什麼）
D 抵押人主張抵押債權不存在，得聲明異議並聲請停止執行 ✗ → 聲明異議可以，但聲明異議不能停止執行
   救濟四種（講義 123 頁）：對裁定抗告；聲明異議（欠缺債權不符從屬性＝執行名義不成立）；§14 異議之訴；確認抵押權不存在之訴（釋字 182：舉輕以明重，得停止執行）→ 後兩者才能停止執行
```
