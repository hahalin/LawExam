# 強制執行法03 筆記：執行費的特別規定（§28-3）

## 逕行發給憑證：
- 債權人陳明債務人無財產、只求**中斷時效** → §27 II **逕行發給憑證**，執行費 **1,000 元**（依千分之八算更低者從低）
- 持該憑證再聲請且仍逕行發給 → **免徵**
- 持憑證**實際執行**債務人財產 → **補徵**千分之八與已繳 1,000 元之**差額**

## 不退費、例外免預納：
- 撤回執行聲請 → **不準用**民訴 §83 退還三分之二，執行費不退
- **擔保物權人、優先受償權人**（考試幾乎都是**抵押權人**）：強制列入分配，未預納不必命補正、不駁回，執行費**由執行所得扣繳**

## 保全與本案：
- 假扣押、假處分之執行**照樣**徵收千分之八，不打折
- 本案終局執行時**扣除**已繳部分，不重複徵收；本案金額擴張者補差額

## 📖 法條原文速查

> **強執 §28-3 I**　債權人聲請執行，依第二十七條第二項**逕行發給憑證**者，徵收執行費新臺幣**一千元**。但依前條第一項規定計算應徵收之執行費低於一千元者，依該規定計算徵收之。
> **強執 §28-3 II**　債權人依前項憑證聲請執行，而依第二十七條第二項逕行發給憑證者，**免徵**執行費。
> **強執 §28-3 III**　債權人依前二項憑證聲請強制執行債務人財產者，應**補徵收**按前條第一項規定計算執行費之**差額**。
> **強執 §27 II**　債權人聲請執行，而陳明債務人現無財產可供執行者，執行法院得**逕行發給憑證**。
> 抵押權人等未預納執行費由執行所得扣繳之依據（條號請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「聲請逕行發給債權憑證之執行費？」 | **1,000 元**，不依千分之八（但依千分之八算更低者從低） |
| 「持憑證再聲請逕行發給憑證？」 | **免徵** |
| 「持憑證聲請實際執行財產？」 | 補徵千分之八之**差額**（扣掉已繳 1,000） |
| 「撤回執行聲請得否請求退還執行費 2/3？」 | **不得**，不準用民訴 §83 |
| 「抵押權人未預納執行費，執行法院應駁回其參與分配？」 | **錯**。不必命補正、不駁回，**由執行所得扣繳** |
| 「普通債權人聲明參與分配未預納，經命補正逾期不補？」 | 得**裁定駁回**其參與分配 |
| 「假扣押執行費得減免？」 | **不得**，同樣千分之八；本案執行時**扣除**，不重複徵收 |
| 「不動產查封後債權人不預納**必要鑑定費**，法院僅得不為該行為、不得駁回？」 | **錯**（選擇題答案 B）。致程序不能進行 → 依 §28-1 **得裁定駁回** |

## 一、債權憑證與執行費

```
第一次：陳明債務人無財產 → 逕行發給憑證（§27 II） → 1,000 元
   ↓（約五年後再來中斷時效）
第二次：持憑證聲請、仍逕行發給 → 免徵
   ↓（債務人中樂透、發現財產）
實際執行：千分之八 − 1,000 ＝ 補繳差額（§28-3 III）
```

## 二、抵押權人為何免預納

```
強執對擔保物權採「塗銷主義」：抵押權因拍賣而消滅
        ↓ 為保護抵押權人
已知抵押權所擔保之債權 → 強制列入分配（§34，日後詳述）
        ↓ 抵押權人可能根本沒來繳錢
執行費 → 不命補正、不駁回 → 從執行所得扣繳
```

## 三、保全執行與本案執行

```
假扣押執行（只到查封）── 繳千分之八 ─┐
                                      ├→ 同一債權只收一次
本案終局執行（接續換價、滿足）── 扣除已繳 ─┘
例：假扣押 1,000 萬、本案擴張為 1,100 萬 → 多出的 100 萬補千分之八
```

## 四、選擇題（何者錯誤）

| 選項 | 判斷 |
|---|---|
| A 不預納執行費，法院得裁定駁回 | ✓（§28-1） |
| B 不預納必要鑑定費，法院僅得不為該行為，不得駁回 | **✗ 答案**：不動產必須鑑價，不預納致不能進行 → 得駁回 |
| C 普通債權人參與分配應預繳，逾期不補得駁回 | ✓ |
| D 保全執行亦徵收，本案執行時扣除 | ✓ |
