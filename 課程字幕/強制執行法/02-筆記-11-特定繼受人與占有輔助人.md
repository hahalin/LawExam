# 強制執行法02 筆記：特定繼受人與占有輔助人

## 訴訟標的之繼受（債權讓與）：
- 確定判決之債權受讓人（如資產管理公司）為**特定繼受人**，得依**原執行名義**聲請
- 須提出：①**債權讓與契約書** ②**通知債務人之證明**（通常是存證信函，對應民 §297 I）（考好幾遍）

## 訴訟標的物之受讓（61 台上 186）：
- **債權物權區分說**：看原訴訟標的法律關係有無**物權**效力
- 基於**物上請求權**（§767）→ 執行力**及於**受讓標的物之第三人
- 基於**債權**（租賃物返還）→ 債之相對性，**不及於**
- 但第三人符合**善意受讓**（民 §801、§948）→ 實體法優先，仍可阻卻執行

## 占有人與實質當事人：
- 占有人＝**為當事人占有**（占有輔助）：保管人、受寄人、受任人、受僱人、同居家屬、保全人員 → 可直接執行
- **承租人、質權人、典權人**為自己利益占有 → **不是**占有輔助人（次承租人改用 61 台上 186 判斷）
- 實質當事人：遺產訴訟 → 繼承人；破產財團訴訟 → 破產人；選定當事人 → 選定人
- 所有執行名義都準用（§4-2 II），聲請時要附戶政等資料證明繼受關係

## 📖 法條原文速查

> **民 §297 I**　債權之讓與，非經讓與人或受讓人**通知債務人**，對於債務人**不生效力**。但法律另有規定者，不在此限。
> **民 §767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。
> **強執 §123 I**　執行名義係命債務人**交付一定之動產**而不交付者，執行法院得將該動產**取交**債權人。
> **強制執行事件辦理注意事項 57**　本法所稱債務人，包括債務人之受僱人、學徒、與債務人共同生活而同居一家之人，或基於其他類似關係，受債務人指示而對之有管領力者在內。（項次、原文請對講義）

## 📋 實務見解速查

> **61 台上 186 判例**：訴訟標的物於繫屬後移轉於第三人，確定判決效力是否及於該第三人，視訴訟標的法律關係之性質而定：為**物權**關係者，及於受讓之第三人；為**債權**關係者，不及之。（老師以「債權物權區分說」講解，原文請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債權受讓人得持原執行名義聲請強制執行？」 | **得**，為特定繼受人；須附**讓與契約**＋**通知債務人之證明** |
| 「出租人本於**租賃關係**訴請遷讓勝訴，乙於繫屬後轉租丙，得對丙執行？」 | **不得**，債權性質，執行力不及於丙（61 台上 186） |
| 「同上，但本於**所有權（§767）**訴請遷讓？」 | **得**，丙為特定繼受人 |
| 「繫屬後被告將動產賣給善意第三人？」 | 第三人符合**善意受讓**者仍得阻卻執行 |
| 「執行名義對公司命返還房屋，現場保全人員得一併排除？」 | **得**，占有輔助人 |
| 「執行名義對妻，同住之夫占有房屋？」 | **得**對夫執行（同居家屬＝占有輔助人） |
| 「承租人是 §4-2 之『占有人』？」 | **不是**，為自己利益占有 |
| 「遺產管理人為原告之判決，實質當事人為？」 | **繼承人** |

## 一、61 台上 186 判斷圖

```
甲 ─訴請返還 A 物─→ 乙        繫屬後乙把 A 物交給丙（出借、出租、出賣皆同）
執行名義只寫甲、乙 → 甲能否用它對丙執行？
         │
   看原訴訟標的（傳統訴訟標的理論）
   ├── 物上請求權（§767）→ 有對世效 → 及於丙 → 可執行
   └── 債權（租賃物返還）→ 債之相對性 → 不及丙 → 須另取執行名義
   ＊丙若符合善意受讓 → 實體優先，仍可阻卻
```

- 老師：房子題考過 N 次，就看當初是**債權還是物權**。執行處看執行名義不只看主文，這種情形要看整份判決。

## 二、繼受型態比較

| | 受讓訴訟標的 | 受讓訴訟標的物 |
|---|---|---|
| 例 | 債權讓與、債務承擔 | 標的物移轉、出借、出租 |
| 是否繼受權利義務 | 是 | 否，只是東西換人拿 |
| 執行力 | 及於（附讓與及通知證明） | 依 61 台上 186 區分 |

## 三、實質當事人（講義填空）

| 形式當事人 | 實質當事人（該他人） |
|---|---|
| 遺產管理人、遺囑執行人（遺產訴訟） | 繼承人 |
| 破產管理人（破產財團訴訟） | 受破產宣告之人 |
| 被選定人（選定當事人） | 選定人 |

## 四、立體演練

```
(1) 甲將 A 轎車出借乙，約三個月後返還，作成公證書；期滿未返還
    公證書要件：公證人作成、載明逕受強制執行、特定動產（不限租借；
    不動產才限租、借）、已屆履行期
    執行方法：物之交付請求權之執行 → §123 取交
    A 車由同居之妻丙占有 → 占有輔助人 → 不必另取執行名義

(2) 甲出租 A 屋予乙，租期屆滿乙未返還；甲本於租賃關係起訴勝訴確定
    丙具狀聲明異議：繫屬後才向乙承租（次承租人）
    → 丙為訴訟標的物特定繼受人，但甲主張債權 → 不受確定判決效力所及
    → 執行法院不得強制丙遷讓交還
```
