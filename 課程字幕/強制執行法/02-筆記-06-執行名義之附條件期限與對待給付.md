# 強制執行法02 筆記：執行名義之附條件期限與對待給付

## 開始執行要件（§4 II、III）：
- 附**停止條件** → 條件成就；附**期限** → 期限屆至；須**供擔保** → 供擔保後；有**對待給付** → 債權人已為給付或已提出給付後
- 條文都寫「始得**開始**強制執行」→ 是**開始要件**，不是執行名義成立要件（我國採第二說）
- 所以要件未備仍可先**聲請**（可中斷時效），執行處會命補正；真正查封前要補齊

## 個別問題：
- **解除條件**成就 → 執行名義**不失效**，屬消滅請求之實體事由 → 債務人提 **§14 異議之訴**
- **過怠條款**（遲付一期視為全部到期）→ 是否已履行由**債務人**舉證
- 期限包括不確定期限（如「父親死亡後」）；民訴 §246 可提將來給付之訴，但執行一定要**屆期**（考過）
- 供擔保：執行處看**提存書**

## 對待給付：
- 判決中被告抗辯之對待給付**無既判力、無執行力** → 被告要執行須**反訴**
- **和解筆錄**中約定之對待給付 → **有**執行力
- 已為對待給付之證明（參 §130 II）：**提存**、**執行法院證明書**、**公證**

## 📖 法條原文速查

> **強執 §4 II**　執行名義附有**條件、期限**或須債權人**提供擔保**者，於條件成就、期限屆至或供擔保後，始得**開始**強制執行。
> **強執 §4 III**　執行名義有**對待給付**者，以債權人已為給付或已提出給付後，始得**開始**強制執行。
> **強執 §130 II**　前項意思表示有待於對待給付者，於債權人已為**提存**或執行法院就債權人已為對待給付給予**證明書**時，視為債務人已為意思表示。**公證人**就債權人已為對待給付予以公證時，亦同。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「執行名義所附期限未屆至，執行法院得開始執行？」 | **不得**，期限屆至始得開始（§4 II）；將來給付判決也一樣 |
| 「執行名義附解除條件，條件成就時執行名義當然失效？」 | **否**，屬實體事由，債務人提 **§14 異議之訴** |
| 「過怠條款，債務人有無遲延由誰舉證？」 | **債務人**舉證已按期履行 |
| 「債權人未為對待給付前，得否聲請強制執行？」 | **得聲請**；對待給付是**開始**要件，開始執行前完成即可 |
| 「對待給付判決，被告得就對待給付部分聲請執行？」 | **不得**，無既判力、執行力；應提**反訴** |
| 「訴訟上和解約定之對待給付，有無執行力？」 | **有**（和解筆錄約定之給付義務均有執行力） |
| 「債權人如何證明已為對待給付？」 | 提存、執行法院證明書、公證（參 §130 II） |

## 一、條件：開始條件 vs 解除條件

```
停止（開始）條件
例：債務人應於債權人給付搬遷費 X 元後，交還房屋
    搬遷費＝條件 → 先付 → 才能開始執行點交（§4 II）

解除條件
例：債務人於交還土地前，按月給付 3 萬元
    交還土地＝解除條件 → 成就後
    執行名義不失效 → 債務人 §14 債務人異議之訴（實體救濟）
```

## 二、申請執行 ≠ 開始執行

```
聲請強制執行 ──────── 補正（提存書、對待給付證明）──────── 開始執行（查封）
   ↑ 可以先來，中斷時效                                    ↑ 此前要件須具備
```

| 學說 | 對待給付性質 | 聲請前須先給付？ |
|---|---|---|
| 第一說（外國立法例） | 執行名義**成立**要件 | 須 |
| **第二說（我國）** | 開始執行要件（§4 II、III「開始」） | 不須 |

- 理由：若列為成立要件，等於債權人先給付，與同時履行抗辯制度有違、對債權人不公平。

## 三、對待給付的兩種來源

| 來源 | 對待給付部分有無執行力 | 理由 |
|---|---|---|
| 判決（被告抗辯） | ✗ | 只是攻防方法，非訴訟標的；要有執行力須反訴 |
| 訴訟上和解筆錄 | ✓ | 約定之給付義務，不問原告或被告負擔 |
