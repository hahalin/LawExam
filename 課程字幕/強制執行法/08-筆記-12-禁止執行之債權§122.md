# 強制執行法08 筆記：禁止執行之債權§122

## 絕對禁止（§122 I）：
- 債務人依法領取之**社會福利津貼、社會救助或補助** → 任何金額都**不得**強制執行
- 福利津貼例：中低收入老人生活津貼、身障者生活補助、老農津貼、農民救濟給付
- 救助、補助例：急難救助、災害救助（地震、颱風災民）、勞工職災補助

## 相對禁止（§122 II～V）：
- **社會保險給付**（公保、勞保、軍保、農保等強制保險）及**對第三人之債權**（如薪資）→ 限維持債務人及共同生活親屬**生活所必需**部分不得執行
- 計算：當地每人每月**最低生活費 × 1.2**；共同生活親屬準用，並按債務人**扶養義務比例**定數額
- 執行法院斟酌雙方生活狀況，認有失公平者，**不受前三項限制**（V）

## 退休金存入專戶：
- 早期實務：存入銀行即變成對銀行的存款債權，可執行
- 現行：特別法（公務人員退撫法、勞保條例等）明定**專戶內存款不得扣押、強制執行** → 絕對不能執行，不用算生活所必需

## 📖 法條原文速查

> **強執 §122 I**　債務人依法領取之**社會福利津貼、社會救助或補助**，不得為強制執行。
> **強執 §122 II**　債務人依法領取之**社會保險給付**或其對於第三人之債權，係維持債務人及其共同生活之親屬**生活所必需**者，不得為強制執行。
> **強執 §122 III～V**　要旨：III 生活所必需以最近一年衛福部或直轄市政府公告當地區每人每月**最低生活費 1.2 倍**計算；IV 共同生活親屬準用並按**扶養義務比例**；V 執行法院斟酌雙方生活狀況，認**有失公平**者不受前三項限制（但書請對六法）。
> **公務人員退休資遣撫卹法**　要旨：請領退撫給與之權利不得讓與、抵銷、扣押或供擔保；領受人得開立**專戶**，專戶內存款不得作為抵銷、扣押、供擔保或強制執行之標的。（條號與原文請對六法）
（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「社會救助金、急難救助金得否執行？」 | **絕對不得**（§122 I），不論金額 |
| 「勞保給付得否執行？」 | **相對**：生活所必需部分不得，其餘得執行（§122 II） |
| 「勞保給付與老農津貼一樣絕對禁止？」 | **錯**：社會保險給付屬 II，津貼救助補助屬 I |
| 「生活所必需如何計算？」 | 最低生活費 **× 1.2**；親屬部分再乘**扶養義務比例** |
| 「算出生活所必需後，必定不得執行？」 | **否**，有失公平者法院得不受限制（V） |
| 「公務員退休金存入專戶後得否執行？」 | **不得**，特別法明定專戶內存款不得扣押、強制執行 |

## 一、§122 體系

```
§122 禁止執行之債權
├─ I 絕對禁止：社會福利津貼、社會救助、補助
│      → 全部給債務人，不計算
└─ II 相對禁止：社會保險給付、對第三人之債權（薪資等）
       → 生活所必需部分不得執行
       ├─ III 計算：最低生活費 × 1.2
       ├─ IV 親屬：準用 × 扶養義務比例
       └─ V 有失公平 → 不受前三項限制
```

## 二、算一次（數字為示意）

| 項目 | 數字 |
|---|---|
| 當地最低生活費 | 每月 2 萬 |
| 債務人本人 | 2 萬 × 1.2 ＝ 2.4 萬 |
| 未成年子女 1 人（與配偶共同扶養，比例 1/2） | 2 萬 × 1.2 × 1/2 ＝ 1.2 萬 |
| 生活所必需合計（不得執行） | **3.6 萬** |

- 老師說計算題前面堂次已算過（03-筆記-02），「記得乘 1.2 就對了」

## 三、退休金存入銀行（講義 318 頁）

| 時期 | 見解 | 問題 |
|---|---|---|
| 早期實務 | 存入後性質改變，成為對銀行之請求權 → 可執行 | 失去保障退休生活的立法意旨 |
| 現行（年改後） | 特別法明定**專戶**內存款不得扣押、強制執行 | 選擇題知道結論即可 |

- 字幕 02:11:31 老師唸第五項為「顯失公平」，條文用語為「**有失公平**」，以六法為準
