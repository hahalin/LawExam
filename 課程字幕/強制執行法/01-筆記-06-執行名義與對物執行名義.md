# 強制執行法01 筆記：執行名義與對物執行名義

## 意義：
- 執行名義＝表示私法上給付請求權**存在及範圍**的**公文書**；是開啟執行程序的鑰匙，**必備**
- 範圍：寫 100 萬就不能執行 101 萬；只寫開演唱會就不能要求簽名
- 私人借據、切結書、私下和解書都**不是**；要變成公文書（公證、鄉鎮市調解經法院核定）

## 形式審查：
- 執行名義成立過程（民訴）已保障債務人程序參與 → 執行法院只做**形式審查**
- 提出公文書即足認實體權利存在有高度可能性

## 對人 vs 對物執行名義：
- **對人**：以債務人**一般財產**為對象（確定判決、本票裁定等，多數）
- **對物**：§4 I ⑤ 許可**拍賣抵押物（質物）裁定**，只能執行**擔保物**
- 對物三特色：① 只限特定擔保物 ② 債權人對債務人財產**無選擇權** ③ 不足清償**不得**續執行其他財產、**不發債權憑證**
- 例外：債權人**另有**其他執行名義（確定判決、本票裁定）→ 可續對其他財產執行

## 📖 法條原文速查

> **強執 §4 I ⑤**　抵押權人或質權人，為**拍賣抵押物或質物**之聲請，經法院為**許可強制執行之裁定**者。
> **強執 §27**　不足清償時發給憑證（對人執行名義才有；對物執行名義不發）。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債權人持債務人簽立之切結書（借據），得聲請強制執行？」 | **不得**。非公文書、非法定執行名義 |
| 「債權人持拍賣抵押物裁定，得否執行債務人之存款、薪資、汽車？」 | **不得**，只能執行**抵押物** |
| 「拍賣抵押物後價金不足，債權人聲請發債權憑證？」 | **駁回**。對物執行名義不發債權憑證（講義練習第五題） |
| 「拍賣抵押物後不足受償，債權人可否續對其他財產執行？」 | **原執行名義不行**；**另取得**其他執行名義（判決、本票裁定）則可 |
| 「執行法院對執行名義所載請求權是否存在，應實質審查？」 | **錯**，只做**形式審查** |
| 「確定判決得執行債務人之一切財產？」 | **對**（對人執行名義；法律另有禁止者除外） |

## 一、對人 vs 對物執行名義

| 比較 | 對人執行名義 | 對物執行名義（§4 I ⑤） |
|---|---|---|
| 例 | 確定判決、本票裁定、和解調解…… | 許可拍賣抵押物／質物裁定 |
| 執行對象 | 債務人**一般財產** | **特定擔保物** |
| 選擇權 | 債權人可挑 | **無** |
| 不足清償 | 發**債權憑證** | 程序終結，**不發** |
| 實務比重 | 多數 | 考試 99.9% 考抵押，不太考質權 |

## 二、實行抵押流程

```
借款人房貸違約（如寬限期後繳不出）
   ▼
銀行向法院（非訟）聲請拍賣抵押物裁定
   ▼
持裁定到執行處聲請強制執行（§4 I ⑤）
   ▼
只能拍賣抵押之房地
   ├─ 足額 → 結束
   └─ 不足 → 程序終結，不發債權憑證
            └ 銀行另持本票裁定／清償判決 → 可再執行其他財產
```

- 銀行為什麼又要你設抵押、又簽本票、又簽契約：**多重擔保**，一個債權人可以有多個執行名義。

## 三、講義練習（實例題）

```
事實：債權人持法院許可拍賣抵押物裁定聲請執行，拍賣抵押物後價金不足清償
問：可否就不足額續對債務人其他財產執行？
步驟：抓三要素 → 執行名義＝§4 I ⑤（對物）→ 客體＝抵押物（正確）
答：原執行名義不可；另取得其他執行名義者，可續對其他財產執行
```

## 四、怎麼讓私人約定變成執行名義（律師建議）

| 私下做法（不能執行） | 改成（可以執行） |
|---|---|
| 切結書、借據 | 公證（符合公證法 §13，筆記 11） |
| 私下和解書 | 鄉鎮市調解委員會調解，經**法院核定**（免費） |
