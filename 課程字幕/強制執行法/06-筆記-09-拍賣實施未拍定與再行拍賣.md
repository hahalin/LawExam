# 強制執行法06 筆記：拍賣實施、未拍定與再行拍賣

## 拍賣實施：
- 口頭公開競價（不動產才有書面投標）；最高價**高呼三次**後拍定（§70 III）

## 一拍未拍定（§70 IV）：
- 出價低於底價，或未定底價而債權人／債務人認為不足而反對 → 不拍定
- 先問**債權人願否依底價承受**；不承受 → 定期**再行拍賣**（二拍）

## 二拍（§70 V）：
- 拍歸出價最高者；但不足底價 **50%**、或未定底價而**顯不相當** → 作價交債權人承受
- 債權人不願或不能承受 → **撤銷查封**、返還債務人 → 動產最多賣兩次

## 無人應買（§71）：
- 作價交債權人承受；不承受 → 撤銷查封返還（原則一拍就終結）
- 例外：**顯有賣得相當價金之可能** → 準用 §70 V 再行拍賣
- 承受一律不強迫，條文的「應」不是強制

## 📖 法條原文速查

> **強執 §70**　III 拍定，應就應買人所出之最高價，**高呼三次**後為之。
> IV 應買人所出之最高價，如**低於底價**，或雖未定底價，而債權人或債務人對於應買人所出之最高價，**認為不足而為反對之表示**時，執行拍賣人應不為拍定，由執行法院定期**再行拍賣**。但債權人願依所定底價承受者，執行法院應交債權人承受。
> V 拍賣物依前項規定，再行拍賣時，應拍歸出價最高之應買人。但其最高價**不足底價百分之五十**；或雖未定底價，而其最高價**顯不相當**者，執行法院應作價交債權人承受；債權人不願承受或依法不能承受者，應由執行法院**撤銷查封**，將拍賣物返還債務人。
> **強執 §71**　拍賣物**無人應買**時，執行法院應作價交債權人承受，債權人不願承受或依法不能承受者，應由執行法院撤銷查封，將拍賣物返還債務人。但拍賣物**顯有賣得相當價金之可能**者，準用前條第五項之規定。
（條文原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產拍賣方式？」 | **口頭**公開競價；投標（書面）是不動產（§86） |
| 「何時拍定？」 | 最高價**高呼三次**後 |
| 「未定底價，出價一元即可拍定？」 | **否**。債權人或債務人認為不足而反對 → 不拍定；二拍顯不相當亦不拍定 |
| 「一拍未拍定之後？」 | 先問債權人願否**依底價承受**；不承受 → 定期再行拍賣（二拍） |
| 「二拍之拍定門檻？」 | 達底價 **50%** 即可拍定（打對折）；不足 50% 或未定底價而顯不相當 → 作價交債權人承受 |
| 「二拍仍未拍定、債權人不承受？」 | **撤銷查封**，返還債務人。動產**最多拍兩次** |
| 「第一次拍賣**無人應買**，當然進入二拍？」 | **否**（§71）。原則：作價交債權人承受，不承受 → 撤銷查封返還；例外**顯有賣得相當價金之可能** → 準用 §70 V 再行拍賣 |
| 「債權人有義務承受？」 | **無**。條文寫「應作價交債權人承受」，但債權人可以不願承受 |

## 一、流程（§70 有人出價 vs §71 無人應買）

```
一拍
├─ 有人出價（§70）
│   ├─ 最高價 ≥ 底價、無人反對 → 高呼三次 → 拍定
│   └─ 低於底價／未定底價而兩造反對 → 未拍定
│        → 債權人依底價承受？ 是 → 承受
│                            否 → 二拍
└─ 無人應買（§71）
    → 作價交債權人承受？ 是 → 承受
                        否 → 原則：撤銷查封、返還債務人（終結）
                             例外：顯有賣得相當價金可能 → 準用 §70 V（二拍）

二拍（§70 V）
├─ 最高價 ≥ 底價 50%（或未定底價而相當）→ 拍定
└─ 不足 50%／顯不相當／無人 → 作價交債權人承受？ 否 → 撤銷查封、返還（終結）
```

## 二、§70 vs §71

| | §70 未拍定（有人出價） | §71 無人應買 |
|---|---|---|
| 現場 | 有人出價但太低或被反對 | 完全沒人 |
| 先做什麼 | 問債權人承受 | 作價交債權人承受 |
| 債權人不承受 | **當然**進入二拍 | 原則**終結**（撤銷查封） |
| 二拍 | 有 | 例外：顯有賣得相當價金之可能 |

- 老師：無人應買不一定是東西差（例如疫情期間沒人出門），才有 §71 但書。講義右邊「概念解析」是早期見解，選擇題依 §70 條文作答。
