# 強制執行法06 筆記：不動產查封（§75～§78）

## 換價方式（§75）：
- 查封後以**拍賣、強制管理**（出租收租）換價，得並行
- 建物及基地同屬債務人 → 得併予查封拍賣；動產不動產合併拍賣 → 動產適用不動產規定
- 本節沒規定的準用動產（§113）：§69、§68-2、§51 III、§70 VI 等

## 查封兩個動作（§76）：
- **查封行為**（現場查封）：揭示、封閉、追繳契據
- **查封登記**：通知登記機關，通知**到達**即生查封效力（不待登記完成）
- 兩者**以先者為準**；實務通常先發查封登記函

## 筆錄與現況調查：
- 查封筆錄記載實際狀況、使用情形，及海砂屋、輻射屋、漏水、非自然死亡等影響交易之情事（§77）——現場得知者記載，執行處非偵探
- 調查方法：開鎖進入、訊問債務人或占有第三人、命提出文書；向警察等機關調查（§77-1 I）
- 債務人拒絕或虛偽陳述 → 得**管收債務人**；第三人 → **罰鍰 1.5 萬元以下**（§77-1 II、III）

## 保管：
- 債務人保管 → 仍得為從來之管理或使用（照住，不能搞破壞）（§78）

## 📖 法條原文速查

> **強執 §75**　I 不動產之強制執行，以查封、**拍賣、強制管理**之方法行之。II 前項拍賣及強制管理之方法，於性質上許可並認為適當時，得併行之。III 建築物及其基地同屬於債務人所有者，得併予查封、拍賣。IV 應拍賣之財產有動產及不動產者，執行法院得合併拍賣之。V 前項合併拍賣之動產，**適用關於不動產拍賣之規定**。
> **強執 §76**　I 查封不動產，由執行法官命書記官督同執達員依左列方法行之：一、**揭示**。二、**封閉**。三、**追繳契據**。II 前項方法，於必要時得併用之。III 已登記之不動產，執行法院並應先通知登記機關為**查封登記**，其通知於第一項執行行為實施前**到達**登記機關時，亦發生查封之效力。
> **強執 §77 I ②**　不動產之所在地、種類、實際狀況、使用情形、現場調查所得之海砂屋、輻射屋、地震受創、嚴重漏水、火災受損、建物內有非自然死亡或其他足以影響交易之特殊情事及其應記明之事項。
> **強執 §77-1**　I 執行法官或書記官，為調查前條第一項第二款情事或其他權利關係，得依下列方式行之：一、開啟門鎖進入不動產或訊問債務人或占有之第三人，並得命其提出有關文書。二、向警察及其他有關機關、團體調查，受調查者不得拒絕。II 前項情形，**債務人**無正當理由拒絕陳述或提出文書，或為虛偽陳述或提出虛偽之文書者，執行法院得依債權人聲請或依職權**管收**債務人。但未經訊問債務人，並認非予管收，顯難查明不動產狀況者，不得為之。III **第三人**有前項情形或拒絕到場者，執行法院得以裁定處新臺幣一萬五千元以下之**罰鍰**。
> **強執 §78**　已查封之不動產，以債務人為保管人者，債務人仍得為**從來之管理或使用**。由債務人以外之人保管者，執行法院得許債務人於必要範圍內管理或使用之。
> **土地法 §75-1**　前條之登記尚未完畢前，登記機關接獲法院查封、假扣押、假處分或破產登記之囑託時，應即改辦查封、假扣押、假處分或破產登記，並通知登記聲請人。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「不動產換價方式？」 | **拍賣、強制管理**（§75 I）；動產才是拍賣、變賣 |
| 「動產與不動產合併拍賣？」 | 動產**適用不動產拍賣規定**（較嚴謹）（§75 V） |
| 「不動產查封方法？」 | 揭示、封閉、追繳契據（得併用）＋已登記者**查封登記** |
| 「查封登記何時生查封效力？」 | 通知**到達**登記機關時，**不待**登記完成 |
| 「先發查封登記函、一個月後才現場揭示，查封效力何時發生？」 | **以先者為準** → 函到地政時 |
| 「辦理過戶中接獲查封囑託？」 | 登記機關應即**改辦查封登記**（土地法 §75-1） |
| 「債務人拒絕陳述或虛偽陳述不動產狀況？」 | 得**管收債務人**（須先訊問，且非管收顯難查明）——管收五事由之一 |
| 「承租人（第三人）拒絕到場或虛偽陳述？」 | **罰鍰**（新臺幣 1.5 萬元以下），**不得管收** |
| 「查封後債務人得否繼續居住？」 | **得**，債務人保管時仍得為從來之管理或使用（§78） |

## 一、查封行為 vs 查封登記

```
已登記之不動產
├─ 查封行為（§76 I、II）：現場揭示、封閉、追繳契據 —— 要約時間派車，較慢
└─ 查封登記（§76 III）：通知地政，到達即生效 —— 通常先做
→ 查封效力發生時點：兩者「以先者為準」
→ 越早生效，債權人越早受 §51 II 保護（108 年題：5/1 函到即生效，5/15 現場查封無關）
```

## 二、現況調查的配合義務

| 對象 | 不配合（拒絕、虛偽） | 理由 |
|---|---|---|
| 債務人 | **管收**（§77-1 II） | 不動產價值高，債務人配合義務較高 |
| 第三人（如承租人） | **罰鍰**（§77-1 III） | 第三人不得管收 |
