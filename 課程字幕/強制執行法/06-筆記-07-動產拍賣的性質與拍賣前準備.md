# 強制執行法06 筆記：動產拍賣的性質與拍賣前準備

## 換價方式：
- 動產：**拍賣**、**變賣**（筆記 11）；不動產：拍賣、強制管理（筆記 12）

## 拍賣的性質：
- 私法上**買賣**（49 台上 83）：**債務人＝出賣人**、拍定人＝買受人；執行法院**代替債務人**立於出賣人地位
- 拍賣公告＝要約之引誘；應買（出價）＝要約；拍定（槌子敲下）＝承諾，契約成立

## 拍賣前準備：
- 查封日至拍賣期日至少 **7 日**、不得多於 **1 個月**（§57）
- 地點：執行法院或**動產所在地**；得委託拍賣行（§61）
- 鑑價：**貴重物品且價格不易確定**才鑑價 → 反面：動產原則**不鑑價**（§62）
- 通知**債權人及債務人**；無法通知或不到場，拍賣不停止（§63）
- 底價：條文寫「應」，實為「**得**」——動產原則**不定底價**；得酌定保證金（§70 I）
- 拍定人就物之瑕疵**無擔保請求權**（§69，不動產準用）

## 📖 法條原文速查

> **強執 §57**　I 查封後，執行法官應速定拍賣期日。II 查封日至拍賣期間，至少應留**七日**之期間。但經債權人及債務人之同意或因查封物之性質，須迅速拍賣者，不在此限。III 前項拍賣期日不得多於**一個月**。但因查封物之性質或有不得已之事由者，不在此限。
> **強執 §61**　I 拍賣動產，由執行法官命書記官督同執達員於**執行法院或動產所在地**行之。II 前項拍賣，執行法院認為必要時，得**委託拍賣行**或適當之人行之。但應派員監督。
> **強執 §62**　查封物為**貴重物品**而其價格**不易確定**者，執行法院應命鑑定人鑑定之。
> **強執 §63**　執行法院應通知**債權人及債務人**於拍賣期日到場，無法通知或屆期不到場者，拍賣不因而停止。
> **強執 §69**　拍賣物買受人就物之瑕疵無擔保請求權。
> **強執 §70**　I 執行法院因債權人或債務人之聲請或認為必要時，應依職權於拍賣前預定拍賣物之**底價**，並得酌定**保證金**額，命應買人於應買前繳納之。未照納者，其應買無效。II 執行法院定底價時，應詢問債權人及債務人之意見，但無法通知或屆期不到場者，不在此限。
（§57 II 但書、§70 原文請對六法）

## 📋 實務見解速查

> **49 台上 83 判例**：強制執行法上之拍賣，應解釋為**買賣之一種**，即**債務人為出賣人**，拍定人為買受人，而以**拍賣機關代替債務人立於出賣人之地位**。
> **57 年實務見解**（講義 234 頁）：執行法院**應通知而不通知**，或通知**未經合法送達**，始屬程序違法，得依 §12 聲明異議。
> **54 年實務見解**（講義 234 頁）：不動產拍賣依 §113 準用 §63，務必通知；「無法通知」指遷移、隱匿或因故他往等；立法意旨在促使執行法院踐行通知手續，**苟已通知**，縱發生上列情事，仍難謂違背法定程序。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「強制執行拍賣之出賣人？」 | **債務人**（執行法院代替其立於出賣人地位，49 台上 83）；不是法院 |
| 「拍賣公告是要約？」 | **否**，是要約之**引誘**；應買＝要約，拍定＝承諾 |
| 「查封後隔天即拍賣？」 | 原則**不得**，至少留 **7 日**；拍賣期日不得多於 1 個月 |
| 「動產拍賣原則須鑑價？」 | **否**。§62 反面解釋：僅貴重物品且價格不易確定（古董、字畫）才鑑價 |
| 「債權人、債務人未到場，拍賣應停止？」 | **否**（§63）。但**應通知而未通知**或未合法送達 → 程序違法 → §12 |
| 「優先承買權人未通知？」 | 屬**得**通知，不通知非程序違法 |
| 「動產拍賣須預定底價？」 | **否**，原則不定（因聲請或認為必要時才定）。**不動產一定要定底價**（§80、§81） |
| 「動產、不動產拍賣何者正確？①拍定人無物之瑕疵擔保請求權②底價須載於公告③皆以投標為之④皆須預定底價」 | **①**（§69，不動產準用）。②③④只有不動產（§81、§86、§80） |

## 一、拍賣＝買賣契約

```
執行法院（代替債務人）── 拍賣公告（要約之引誘）
                          ↓
小明舉手出價 ── 應買（要約）
                          ↓
高呼三次、槌子敲下 ── 拍定（承諾）→ 買賣契約成立
出賣人：債務人　　買受人：拍定人
```

## 二、動產 vs 不動產（本堂先記動產，下堂補不動產）

| | 動產 | 不動產 |
|---|---|---|
| 鑑價 | 原則不用（§62） | 要（估價師） |
| 底價 | 原則不定（§70 I 得） | **必定**（§80） |
| 底價載於公告 | 不載 | **載**（§81） |
| 方式 | 口頭喊價 | 得**投標**（書面，§86） |
| 物之瑕疵擔保 | 無（§69） | 無（§113 準用 §69） |
