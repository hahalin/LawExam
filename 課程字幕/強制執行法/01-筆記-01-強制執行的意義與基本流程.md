# 強制執行法01 筆記：強制執行的意義與基本流程

## 定位：
- 主體是**國家**（地方法院**民事執行處**），以國家強制力為債權人強制債務人履行，**實現私權**
- 民法＝實體法（應然面）；民訴＝程序法，重在**解決紛爭**、取得執行名義；強制執行法＝程序法，重在**實現**
- 私法上債權走強制執行法；欠稅、健保費、罰鍰等公法上債權走**行政執行法**（內容大同小異）

## 金錢債權執行流程：
- **依聲請開始**，沒有依職權（當事人主義）
- 三要素先抓：**執行名義**（§4 I）、**主體**（管轄、當事人＝債權人／債務人）、**客體**（責任財產）
- 三階段：**查封 → 換價 → 滿足**；查封＝扣押，只剝奪**處分權**，所有權還在
- 不足清償 → 發**債權憑證**（§27），程序先終結；日後發現財產可再聲請（沒有重複起訴禁止）

## 考試比重：
- 一試強執 10 題，**金錢債權執行**約占 5～7 題，法條也最多

## 📖 法條原文速查

> **強執 §1 I**　民事強制執行事務，於地方法院及其分院設**民事執行處**辦理之。
> **強執 §4 I**　強制執行，依左列**執行名義**為之：……（六款，見筆記 07）
> **強執 §27**　I 債務人無財產可供強制執行，或雖有財產經強制執行後所得之數額仍不足清償債務時，執行法院應命債權人於一個月內查報債務人財產。債權人到期不為報告或查報無財產者，應發給**憑證**，交債權人收執，載明俟發見有財產時，**再予強制執行**。II 債權人聲請執行，而陳明債務人現無財產可供執行者，執行法院得逕行發給憑證。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債權人取得勝訴確定判決後，執行法院應依職權開始強制執行？」 | **錯**。強制執行一律**依聲請**開始，沒有依職權 |
| 「強制執行之主體為債權人？」 | **錯**。主體是**國家**（民事執行處），債權人是聲請人 |
| 「欠繳稅款、罰鍰依強制執行法執行？」 | **錯**。公法上金錢給付義務走**行政執行法** |
| 「查封後債務人喪失所有權？」 | **錯**。只喪失**處分權**，所有權仍在 |
| 「執行後不足清償，執行程序如何？」 | 發**債權憑證**（§27），程序終結；日後可持憑證再聲請 |
| 「強制執行事件之管轄，依本案訴訟之管轄定之？」 | **錯**。執行管轄與民訴**脫鉤**，重新認定（老師：考過好幾次，第 2 堂講） |

## 一、三部法律的分工

```
民法（實體法，應然面：買東西要付錢、租房要付租金）
   │ 現實有糾紛
   ▼
民事訴訟法（解決紛爭）── 取得「執行名義」（如確定給付判決）
   │
   ▼
強制執行法（實現）── 民事執行處查封、法拍、分錢
```

- 律師笑話：當事人拿著勝訴判決，以為對方就會還錢——判決本身不會把錢放進口袋，要靠強制執行。

## 二、金錢債權執行的基本流程（講義 1 頁圖）

```
債權人聲請（依聲請，無依職權）
   │  先抓三要素
   │  ├─ 執行名義（§4 I）：有沒有、內容是什麼、確定了沒
   │  ├─ 主體：管轄、當事人（債權人／債務人，沒有原告被告）
   │  └─ 客體：責任財產（房地、存款、薪資……）
   ▼
① 查封（＝扣押）：凍結財產，剝奪處分權
   ▼
② 換價（俗稱法拍）：拍賣；另有變賣、強制管理
   ▼
③ 滿足：分配。多數債權人時依優先順位（如抵押權人優先受償）
   ▼
足額清償 → 執行完畢
不足清償 → 發債權憑證（§27）→ 程序終結 → 日後發現財產可再聲請
```

## 三、民事執行 vs 行政執行

| 項目 | 強制執行法 | 行政執行法 |
|---|---|---|
| 實現之債權 | **私法上**債權（借款、價金、承攬報酬） | **公法上**債權（欠稅、健保費、罰單） |
| 內容 | 原型 | 大同小異 |

## 四、讀題方法

- 實例題（含考古題選擇題）先抓**執行名義、主體、客體**，停下來看懂，再往下分析；同民訴先抓當事人、訴訟標的、聲明。
- 動產、不動產的執行程序不同，客體一定要先確認。
