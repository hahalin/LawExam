# 強制執行法06 筆記：動產變賣

## 是什麼：
- **任意出賣**：不做價格競爭的換價，一律叫變賣（洽特定人、標價陳列販賣）
- 拍賣＝公開競價；變賣＝直接標價或個別交涉

## 何時可以變賣（§60 I）：
- 兩造聲請或對價格已協議／易腐壞／有減少價值之虞／金銀物品或有市價之物品／保管困難或需費過鉅
- 共通點：要**迅速**換價，或個別交涉反而易得高價

## 賣不掉：
- 準用 §71：問債權人承受，不承受 → 撤銷查封返還（§60 II）
- **不動產不得變賣**（不動產換價＝拍賣、強制管理）

## 📖 法條原文速查

> **強執 §60**　I 查封物應**公開拍賣**之。但有左列情形之一者，執行法院得不經拍賣程序，將查封物**變賣**之：一、債權人及債務人聲請或對於查封物之價格為協議者。二、有易於腐壞之性質者。三、有減少價值之虞者。四、為金銀物品或有市價之物品者。五、保管困難或需費過鉅者。II 第七十一條之規定，於前項變賣準用之。
（條文原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產換價方式？」 | **拍賣**、**變賣**兩種 |
| 「執行處將查封之蔬菜標價每包 50 元出售？」 | **變賣**（易腐壞，§60 I ②） |
| 「變賣須公告、定底價？」 | **否**，沒有拍賣那些法定期間、公告、底價程序 |
| 「變賣不成？」 | 準用 **§71**：作價交債權人承受，不承受 → 撤銷查封返還 |
| 「不動產得否變賣？」 | **不得**。不動產換價＝**拍賣、強制管理**（§75 I），仍須價格競爭 |

## 一、拍賣 vs 變賣（講義右下表）

| | 拍賣 | 變賣 |
|---|---|---|
| 方式 | 公開競價（價格競爭） | 任意出賣（洽特定人、標價販賣） |
| 法定期間 | 有（§57、§66） | 無，較快 |
| 鑑價、底價 | 得 | 無此問題（直接標價） |
| 事前公告、通知 | 要（通知**債權人及債務人**） | 不需繁瑣程序 |
| 處所 | 法院或動產所在地 | 幾無限制 |
| 不動產 | 可（含投標） | **不可** |
| 賣不掉 | §70、§71 | 準用 §71 |

## 二、換價方式總表

```
動產   → 拍賣、變賣
不動產 → 拍賣、強制管理（出租收租）
共通   → 拍賣
```
