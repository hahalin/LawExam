# 強制執行法07 筆記：不動產拍賣準備與拍賣公告（§80～§84）

## 拍賣前準備流程：
- 鑑定價格 → 核定**拍賣最低價額**（底價）→ 定拍賣期日、場所 → 定保證金 → 拍賣公告（上網）
- 不動產**應**鑑價、**應**定底價（§80）；動產原則不鑑價、不定底價
- 拍賣期日距公告日**不得少於 14 日**（§82）
- 保證金：投標時**開標前**繳納，不能補繳（§86、§89）；實務約底價 10%～30%

## 拍賣公告：
- **應**先期公告（§81 I），應載明八款事項（§81 II）：含現況與海砂屋等特殊情事、**底價**、交付價金期限、**不點交之原因**
- 揭示處所：**應**揭示於執行法院＋不動產所在地或鄉鎮市區公所；**應**公告於法院網站；公報、新聞紙只是**得**（§84）
- 拍賣通知：§113 準用 §63，通知債權人及債務人，不到場不停止拍賣

## 未依命登報：
- 法院命債權人登報而債權人未登，仍照常拍賣 → 拍賣**有效**；§84 II 後段為**訓示規定**
- 應公告的（如網站）漏了 → 走 §12 聲明異議；沒人異議，程序就終結

## 📖 法條原文速查

> **強執 §80**　拍賣不動產，執行法院**應**命鑑定人就該不動產估定價格，經核定後，為**拍賣最低價額**。
> **強執 §81**　I 拍賣不動產，**應**由執行法院先期公告。II 前項公告，應載明下列事項：一、不動產之所在地、種類、實際狀況、占有使用情形、調查所得之海砂屋、輻射屋、地震受創、嚴重漏水、火災受損、建物內有非自然死亡或其他足以影響交易之特殊情事及其應記明之事項。二、拍賣之原因、日期及場所。如以投標方法拍賣者，其開標之日時及場所，定有保證金額者，其金額。三、**拍賣最低價額**。四、交付價金之期限。五、閱覽查封筆錄之處所及日、時。六、定有應買資格或條件者，其資格或條件。七、拍賣後**不點交者，其原因**。八、定有應買人察看拍賣物之日、時者，其日、時。
> **強執 §82**　拍賣期日距公告之日，不得少於**十四日**。
> **強執 §83**　拍賣不動產，由執行法官命書記官督同執達員於執行法院或其他場所為之。
> **強執 §84**　I 拍賣公告，**應**揭示於執行法院及不動產所在地或其所在地之鄉鎮市（區）公所。II 拍賣公告，**應**公告於法院網站；法院認為必要時，**得**命登載於公報或新聞紙。
> **強執 §86**　以投標方法拍賣不動產時，執行法院得酌定保證金額，命投標人於**開標前**繳納之。
（條文原文請對六法）

## 📋 實務見解

> **未依命登報之拍賣**（實務見解，出處請對講義 256 頁附近）：債權人收受應登載報紙之通知而未登載，執行法院仍依期拍賣、第三人得標——§84 II 後段為**訓示規定**，拍賣程序仍有效。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「不動產拍賣是否一定要鑑價、定底價？」 | **是**，§80 用「應」；動產原則不用 |
| 「拍賣期日距公告日至少幾日？」 | 首次 **14 日**（§82）；再行拍賣 10～30 日（§93） |
| 「底價是否載於公告？」 | **是**（§81 II ③）；動產公告不載底價 |
| 「拍賣後不點交，公告要寫嗎？」 | **要寫原因**（§81 II ⑦） |
| 「不動產拍賣公告一定要登報？」 | **不用**；揭示＋網站是「應」，公報新聞紙是「得」 |
| 「法院命登報，債權人未登，拍定效力？」 | **有效**（§84 II 後段訓示規定） |
| 「動產與不動產拍賣共通的規定？」 | 拍定人**無物之瑕疵擔保請求權**（§69，不動產經 §113 準用） |
| 「保證金開標後補繳？」 | **不行**；未繳者投標無效（§89） |

## 一、拍賣前準備（講義流程圖）

```
鑑定價格（應，§80）
   ↓
核定拍賣最低價額＝底價（應）
   ↓
定拍賣期日、場所（§83；距公告 ≥ 14 日，§82）
   ↓
定保證金（得，§86；開標前繳）
   ↓
拍賣公告（應，§81）→ 揭示法院＋所在地或公所、上網（應）／登報（得）（§84）
```

## 二、公告範例（講義 400～402 頁）怎麼讀

- 投標時間、開標時間：下午 2:30 前投入標匭、3:00 開標。
- 得標規定：須達底價、出價最高者得標；**出價相同 → 先當場加價，無人加價才抽籤**（§90，詳筆記 05）。
- 交付價金期限：得標後 7 日內繳足，逾期再拍賣，原得標人負擔差額（§113 準用 §68-2）。
- 合併拍賣：土地、房屋**分別出價且均達底價**，以總價最高者得標（詳筆記 05）。
- 免責：增建面積增減不得請求增減價金或撤銷拍定（§113 準用 §69）。
- 附表：土地、房屋各有底價；點交情形（債務人及家屬自住 → 拍定後點交，§99）；使用情形（囑託警察查明、現場履勘結果）。

## 三、動產 vs 不動產拍賣公告

| | 動產 | 不動產 |
|---|---|---|
| 鑑價 | 貴重且價格不易確定才鑑價 | **應**鑑價 |
| 底價 | 原則不定、公告不載 | **應**定、公告**應**載 |
| 公告距拍賣 | 5 日 | **14 日** |
| 網站 | 得 | **應** |
| 投標 | 無 | 得以投標行之 |
