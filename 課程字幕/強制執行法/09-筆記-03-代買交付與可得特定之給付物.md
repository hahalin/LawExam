# 強制執行法09 筆記：代買交付與可得特定之給付物

## 代買交付是什麼：
- 應交付之物是**代替物**（一包米、一公斤麵粉、一罐不限廠牌的牛奶）→ 債務人不交，由第三人代為購買交付，費用由債務人負擔
- 交付義務**轉化為金錢給付義務**：執行法院裁定命債務人預付費用 → 依此裁定對債務人一切財產執行（又回到查封、換價、滿足）
- 條文沒有，規定在**強制執行法注意事項**（字幕唸「67」，請對講義 328 頁）

## 原則與例外：
- 原則：執行名義只命交付一定種類數量之動產、未載明不交付時應給付金錢 → 不得因無該動產而改執行債務人其他財產
- 例外：交付物為一定數量之**代替物** → 代買交付，執行方式等同**可代替行為**（§127）

## 實務例：
- 返還日月光公司股票若干股（未記載股票特徵、無特定之意）→ 代替物 → 到市場買進，費用由債務人負擔
- 返還四錢金飾：先認定債務人是否占有；未占有且外面買得到一樣的 → 裁定命預付採買金額，依 §127 辦理；全世界只有那一件 → 回到 §123 取交，取不到也不能處怠金
- 離婚後一年購買價值 3,500 萬元房屋給原告：房屋未特定、僅**可得特定** → 依 §127 行為請求權方式執行

## 📖 法條原文速查

> **強執 §127**　I 依執行名義，債務人應為一定行為而不為者，執行法院得**以債務人之費用，命第三人代為履行**。II 前項費用，由執行法院酌定數額，命債務人預行支付或命債權人代為預納，必要時，並得命鑑定人鑑定其數額。
> **強執法注意事項（代買交付）**　執行名義僅命債務人交付一定種類數量之動產，而未載明不交付時應給付金錢者，執行法院不得因無該動產可供交付而對債務人其他財產執行；但交付之動產為一定數量種類之**代替物**者，債務人不為交付時，執行法院得以債務人之費用，命第三人**代為購買交付**，其費用由執行法院定其數額，以裁定命債務人預行支付，基此裁定得就債務人一切財產而為執行。（字幕老師唸為第 67 點，原文與點次請對講義 328 頁）
> **民法 §200 II**　前項情形，債務人交付其物之必要行為完結後，或經債權人之同意指定其應交付之物時，其物即為特定給付物。（原文請對六法）

## 📋 實務見解

> **日月光股票案**：執行名義未詳細記載股票特徵，顯非命返還特定某張；綜合理由欄以股數及公司名稱定應交付之物，足見當事人無特定之意 → 代替物，債務人得以同種同值同量之物代替之。（字號請對講義 328 頁；老師：國考尚未考過）

> **四錢金飾案**：執行法院應先認定債務人是否占有該金飾；如未占有，得裁定命債務人預付採買此金飾之金額，依 §127 規定辦理。（字號請對講義 328 頁後）

> **3,500 萬元房屋案**：房屋所在地號、門牌、面積均未特定，給付範圍雖已特定但房屋未具體指定；嗣後雙方合意指定或依民法 §200 II 後段經原告同意指定時，該房屋始為特定給付物 → 屬**可得特定**，依 §127 關於行為請求權之方式執行。（字號請對講義 328 頁後）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「命交付一定數量之代替物，債務人不交付？」 | **代買交付**：以債務人費用命第三人代為購買交付；裁定命預付費用 → 執行一切財產 |
| 「代買交付規定在哪？」 | **強制執行法注意事項**，條文沒有 |
| 「代買交付的執行方式比照哪一條？」 | **§127 可代替行為** |
| 「命交付一定種類數量動產（非代替物），無物可交，得改執行債務人其他財產？」 | **不得**（未載明不交付應給付金錢） |
| 「命返還上市公司股票若干股？」 | 未特定某張 → 代替物 → 代買交付 |
| 「命購買價值 3,500 萬元房屋給原告，房屋未特定？」 | 可得特定 → 依 **§127** 執行，不是 §124 不動產交付 |

## 一、判斷流程

```
執行名義命交付某物，債務人不交
   │
   ├─ 是特定物（刻名鑽戒、特定 A 地）
   │     → 物之交付：動產 §123 取交／不動產 §124 解除占有
   │     → 取不到：一般動產不得處怠金，執行無效果
   │
   └─ 是代替物或只是可得特定（股票若干股、金飾、某價位房屋）
         → 代買交付：第三人代購，費用由債務人負擔（比照 §127）
         → 裁定命預付費用 → 金錢債權執行（查封 → 換價 → 滿足）
```

## 二、為什麼代買交付會變成金錢債權

| 步驟 | 內容 |
|---|---|
| 1 | 債務人不交付代替物 |
| 2 | 執行法院以債務人費用命第三人代購 |
| 3 | 費用由執行法院酌定，**裁定**命債務人預付 |
| 4 | 該裁定得就債務人一切財產執行 → 回到金錢債權執行 |

- 老師：可代替行為「簡化到最後就是叫債務人出錢」；修漏水也是同一個邏輯（筆記 06）。
- 金飾、黃金題的資訊常常不夠，要先判斷「外面買不買得到一樣的」。
