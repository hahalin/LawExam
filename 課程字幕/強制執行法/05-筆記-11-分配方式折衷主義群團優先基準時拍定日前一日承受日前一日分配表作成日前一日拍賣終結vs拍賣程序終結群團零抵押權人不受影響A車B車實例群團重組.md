# 強制執行法05 筆記：多數債權人之分配方式——立法例：**平等主義**（不分早晚，皆按債權額比例）／**優先主義**（早起的鳥兒有蟲吃，獎勵努力行使權利者）／我國採**折衷主義＝群團優先主義**：以 **§32 I 基準時**切分，基準時前加入者＝**群團一**、之後＝**群團二**，群團一**優先於**群團二受償（優先主義），同一群團內按**債權額比例**（平等主義），群團一分完有剩才輪群團二；**群團零＝抵押權人**（擔保物權、優先受償權人）：實體法上本就優先，**不受基準時影響**，再晚來也最先分（§34 II 債權人不受 §32 II 限制）。三個基準時（講義 199～200 頁）：①**拍定日前一日**（拍賣終結＝槌子敲下、**買賣契約成立**；變賣終結＝變賣契約成立；當天太忙故取前一日；九成考題用這個）②**債權人承受之日前一日**（賣不掉時債權人依底價**作價抵債**）③不經拍賣變賣者：**分配表作成之日前一日**；注意「**拍賣終結**」≠「**拍賣程序終結**」（後者＝拍定人繳足價金、取得所有權／領得權利移轉證書，換價階段整個結束，較晚）。**基準時跟著標的物走**，每個財產各認定一次 → **群團會重組**。實例（講義 198 頁）：甲一 100 萬 3/1 聲請執行、甲二 300 萬 3/2、甲三 100 萬 3/11 參與分配；A 車 3/10 拍賣終結得 200 萬 → 基準時 3/9 → 甲一、甲二群團一（1:3 分 50／150 萬），甲三群團二分 0；餘額甲一 50、甲二 150、甲三 100；B 車 4/1 拍賣終結得 120 萬 → 基準時 3/31 → 三人皆群團一 → 以**餘額** 1:3:2 分 20／60／40 萬；最終未受償甲一 30、甲二 90、甲三 60 萬

## 📖 法條原文速查

> **強執 §32 I**　他債權人參與分配者，應於標的物拍賣、變賣終結或依法交債權人承受之日一日前，其不經拍賣或變賣者，應於當次分配表作成之日一日前，以書狀聲明之。
> **強執 §32 II**　逾前項期間聲明參與分配者，僅得就前項債權人受償餘額而受清償；如尚應就債務人其他財產執行時，其債權額與前項債權餘額，除有優先權者外，應按其數額平均受償。
> **強執 §38**　參與分配之債權人，除依法優先受償者外，應按其債權額數平均分配。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「我國參與分配採何主義？」 | **折衷主義（群團優先主義）**：群團間採優先主義（群團一先於群團二），群團內採平等主義（債權額比例） |
| 「基準時怎麼算？」 | ①拍賣／變賣終結之日**前一日**＝**拍定日前一天**（6/15 拍定 → 基準時 6/14）②債權人承受日前一日 ③不經拍賣變賣：分配表作成日前一日。至少記第一個 |
| 「拍賣終結 vs 拍賣程序終結？」 | **拍賣終結**＝拍定、買賣契約成立（槌子敲下）；**拍賣程序終結**＝拍定人繳足價金取得所有權（不動產領權利移轉證書）、換價階段整個結束。基準時用前者；§15 個別程序終結（筆記 02）看後者 |
| 「債權人承受？」 | 賣不掉時拍賣官問債權人要不要以**底價**承受＝作價抵債 |
| 「同一債權人在 A 財產是群團二，在 B 財產會不會是群團一？」 | **會**。基準時跟著標的物，每個財產各認定一次 → **群團重組** |
| 「群團二分什麼？」 | 群團一按比例分完後之**餘額**（§32 II 前段）；對債務人**其他財產**執行時，以各自**餘額**再按比例（§32 II 後段）→ 所以第一輪要算每人剩多少 |
| 「抵押權人要不要管基準時？」 | **不用**（群團零）。實體法上優先受償，再晚來也先分，不受 §32 II 限制 |
| 「實例題解題步驟」 | ①找每個財產的基準時（拍定日前一日）②把各債權人加入時間放上去分群團 ③群團一按債權額比例分、群團二分餘額 ④算每人未受償餘額 ⑤下一個財產重新認定基準時、以餘額比例再分 |

## 一、群團圖

```
            基準時（§32 I：拍定日前一日）
 ─────────────────┼─────────────────
  群團一（之前加入）   │   群團二（之後加入）
  甲一、甲二           │   甲三
  按債權額比例先分     │   分餘額
群團零：抵押權人 > 群團一 > 群團二
```

## 三、三種主義

| 主義 | 內容 | 我國採否 |
|---|---|---|
| 平等主義 | 不分早晚，一律債權額比例 | 群團內採 |
| 優先主義 | 先來先分（獎勵努力行使權利） | 群團間採 |
| 折衷（群團優先） | 以基準時分群，群間優先、群內平等 | **現行法** |
