# 強制執行法08 筆記：繼續性給付債權扣押（§115-1）

## 原則與例外（司法院函釋）：
- 原則：扣押命令只及於**生效時已存在**的債權；將來債權不及（存款就是如此）
- 例外：與原扣押債權基於**同一繼續之法律關係**而發生的將來債權，於執行債權範圍內得繼續扣押 → 即 §115-1

## §115-1 I 向後效力：
- 薪資（例示）或其他繼續性給付債權（考試幾乎只考**薪資、租金**）
- 效力及於扣押後**應受**（未到期部分）及**增加**（加薪部分）之給付
- 立法理由：不必每月重發扣押命令；公司收到命令後，之後每月的薪水都先不能發給債務人

## §115-1 IV 預告：
- 對這類債權可發移轉命令（**特殊移轉命令**），債務人離職或第三人喪失支付能力 → 移轉命令失效、得聲請繼續執行、免徵執行費（筆記 06）

## 📖 法條原文速查

> **強執 §115-1**　I 對於**薪資或其他繼續性給付之債權**所為強制執行，於債權人之債權額及強制執行費用額之範圍內，其效力及於**扣押後應受及增加之給付**。II 對於下列債權發扣押命令之範圍，不得逾各期給付數額**三分之一**：一、自然人因提供勞務而獲得之繼續性報酬債權。二、以維持債務人或其共同生活親屬生活所必需為目的之繼續性給付債權。……IV 第一項債務人於扣押後應受及增加之給付，執行法院得以命令**移轉**於債權人。但債務人喪失其權利或第三人喪失支付能力時，債權人債權未受清償部分，移轉命令**失其效力**，得聲請**繼續執行**。並**免徵執行費**。
（原文請對六法；II、III 三分之一與失公平調整見 03 堂筆記 02）

## 📋 實務見解

> **司法院函釋**（字號請對講義）：依 §115 I 所發扣押命令，效力不及於扣押命令生效時尚未存在之將來債權；除該債權與原扣押債權係基於**同一、繼續之法律關係**而發生，為扣押命令效力所及，於執行債權範圍內得繼續扣押者外，非原扣押命令效力所及。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「對薪資之扣押命令，效力不及於扣押後加薪部分？」 | **錯**。及於扣押後**應受及增加**之給付（§115-1 I）（104 年考題 A 選項） |
| 「每月薪資須逐月核發扣押命令？」 | **不用**，一次扣押即有向後效力 |
| 「存款扣押也有向後效力？」 | **沒有**——只有繼續性給付債權才有（對照筆記 02） |
| 「扣押薪資的上限？」 | 原則不得逾各期給付**三分之一**（§115-1 II） |
| 「向後效力的範圍？」 | 以**債權額＋執行費用額**為限 |
| 「特殊移轉命令的『特殊』在哪？」 | 對**繼續性給付債權**核發；失效後可復活、免徵執行費（§115-1 IV） |

## 一、時間軸

```
          扣押命令生效
               │
 已到期（1 月）│  未到期（2 月、3 月、4 月…）＋加薪部分
 ──────────────┼──────────────────────────────▶
 §115 I 本來就及之   §115-1 I 向後效力及之（不用再發命令）
```

## 二、一般金錢債權 vs 繼續性給付債權

| | 一般（存款、貨款） | 繼續性給付（薪資、租金） |
|---|---|---|
| 給付型態 | 一次性 | 每期發生，同一法律關係 |
| 扣押效力 | 到達時存在的債權 | ＋扣押後應受及增加之給付 |
| 新增部分 | 另發扣押命令 | 當然及之 |
| 發移轉命令後債權落空 | 程序已終結，不能復活 | 失效、繼續執行、免徵執行費 |

- 老師提醒：條文第一項以「薪資」為例示，選擇題九成九考薪資或租金。
