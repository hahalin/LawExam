# 強制執行法09 筆記：不作為請求權之執行（§129）

## 不作為的種類：
- 一次不為（某天音樂會不得演出）、反覆不為（10 點後不得發出噪音）、繼續不為（工廠不得排放廢水）
- 條文分兩型：① **容忍**他人之行為（容忍通行、容忍進入）② **禁止**債務人為一定行為

## 執行方法：
- 不作為一律不可代替 → **間接強制**：處 3 萬～30 萬元怠金 → 仍不履行，再處怠金或管收（§129 I）
- §129 **沒有**「先定履行期間」：違反了才需要執行，所以直接處怠金；§128 則先定期履行（先禮後兵）

## 除去行為結果（§129 II）：
- 違反不作為義務留下殘留物（圍牆、路障、柵欄）→ 依債權人聲請、以**債務人費用**除去（01:53 前後老師說成「128 第二項」，應為 §129 II）
- 除去本身是**可代替**行為 → 轉化為金錢債權執行
- 結果發生在執行名義成立**前或後**都可除去（注意事項，字幕唸「68 第二項」，請對講義 350 頁）
- 除去後債務人**復行違反** → 依聲請**再為執行**，應徵執行費（§129 III、IV）

## 執行名義要寫成給付：
- **確認**通行權存在之判決**沒有執行力**（§4 I ① 限確定**給付**判決）→ 鄰居亂停車擋路也不能聲請執行
- 「應容忍債權人通行並設置道路」→ 可執行；債權人請求鋪柏油或水泥，在通行安全必要、一般道路樣態內 → **准許**

## 📖 法條原文速查

> **強執 §129**　I 執行名義係命債務人**容忍**他人之行為，或**禁止**債務人為一定之行為者，債務人不履行時，執行法院得處新臺幣三萬元以上三十萬元以下之**怠金**。其仍不履行時，得再處怠金或管收之。II 前項情形，於必要時，並得因債權人之聲請，**以債務人之費用，除去其行為之結果**。III 依前項規定執行後，債務人**復行違反**時，執行法院得依聲請**再為執行**。IV 前項再為執行，應徵執行費。
> **強執 §4 I ①**　強制執行，依左列執行名義為之：一、確定之終局判決。（實務：限**給付**判決始有執行力）
> **強執法注意事項（§129 II）**　本法第一百二十九條第二項所稱除去行為之結果，係指禁止債務人為一定行為之執行名義成立後，存在之行為結果而言；執行名義成立前發生者，**亦包括在內**。（點次請對講義 350 頁）
（條文原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「命債務人容忍通行，債務人築牆阻擋？」 | 處怠金（§129 I）＋聲請**除去行為結果**拆牆（§129 II，債務人費用） |
| 「圍牆在執行名義成立**前**就蓋了，可否除去？」 | **可**，前後都包括（注意事項） |
| 「拆牆後債務人又蓋回？」 | **再為執行**，原執行名義，應再徵執行費（§129 III、IV） |
| 「持確認通行權存在之確定判決聲請排除妨礙？」 | **不得**——確認判決無執行力 |
| 「命容忍通行並設置道路，債權人請求鋪柏油？」 | **准許**（通行安全必要、一般道路樣態） |
| 「命容忍進入屋內修漏水，債務人拒絕進入？」 | 容忍進入 → **§129** 處怠金；修漏水 → **§127** 代替執行 |
| 「§129 與 §128 都要先定履行期間？」 | **否**。§128 先定期；§129 違反即處怠金 |

## 一、容忍進入修漏水：一個執行名義切兩段

```
「債務人應容忍債權人進入系爭房屋內施作天花板漏水修繕工程」
├─ 前段：容忍進入 ── 不作為 §129 → 拒絕就處怠金、再處怠金或管收
└─ 後段：修漏水 ──── 可代替 §127 → 找師傅修，債務人負擔費用
```

- 執行名義較長時，拆開看每段要債務人做什麼，再各自歸類。

## 二、§128 vs §129

| | §128 不可代替行為 | §129 不作為 |
|---|---|---|
| 第一步 | **定履行期間**（希望自動履行） | 違反即**處怠金**（有懲罰色彩） |
| 怠金 | 3 萬～30 萬元 | 3 萬～30 萬元 |
| 後續 | 續經定期仍不履行 → 再處怠金或管收 | 仍不履行 → 再處怠金或管收 |
| 除去結果 | — | §129 II（可代替，債務人費用） |
| 再為執行 | — | §129 III |

- 不作為拿到執行名義不一定要執行：債務人沒違反就沒事；要執行就表示他違反了。

## 三、執行名義寫法（給未來的律師）

| 判決主文 | 能否執行 |
|---|---|
| 確認甲就乙所有 A 地有通行權存在 | 不能（確認判決） |
| 乙應容忍甲於 A 地通行並設置道路 | 能（給付判決，不作為） |
