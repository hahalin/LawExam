# 強制執行法01 筆記：分離原則（不審查實體）

## 原則：
- **執行機關**（民事執行處）與**權利判定機關**（民事庭）分離＝分離原則
- 執行法院**不得審查實體法律關係**，只依**執行名義之外觀**（判決主文、理由）執行，只做**形式審查**
- 判決寫 100 萬就執行 100 萬；判決沒寫遲延利息就不執行利息

## 實體爭執怎麼辦：
- 清償、抵銷、時效、執行中和解等**實體抗辯** → 到**民事庭**起訴（如 §14 債務人異議之訴）
- 起訴後可依 **§18 II** 聲請停止執行（「**得**」停止，非「應」）
- 88 年裁定：執行中和解，執行法院**仍得繼續執行**；債務人只能依 §14 起訴（考過）

## 理由與準用：
- 迅速為最高指導原則；紛爭應在取得執行名義階段吵完，執行處不是第四審
- 強制執行程序，除本法有規定外，**準用民訴**（§30-1）

> 來源：強制執行法01 課程字幕 00:18:34 ~ 00:33:07（講義 2～3 頁；法院編制圖在 52 頁）

## 📖 法條原文速查

> **強執 §14 I**　執行名義成立後，如有**消滅或妨礙債權人請求之事由**發生，債務人得於強制執行程序終結前，向執行法院對債權人提起**異議之訴**。如以裁判為執行名義時，其為異議原因之事實發生在前訴訟言詞辯論終結後者，亦得主張之。
> **強執 §18**　I 強制執行程序開始後，除法律另有規定外，**不停止執行**。II 有回復原狀之聲請，或提起再審或**異議之訴**……時，法院因必要情形或依聲請定相當並確實之擔保，**得**為停止強制執行之裁定。（第 II 項列舉較長，原文請對六法）
> **強執 §30-1**　強制執行程序，除本法有規定外，**準用民事訴訟法**之規定。

## 📋 實務見解速查

> **63 年實務見解**（講義 2 頁，字號請對講義）：強制執行之當事人**依執行名義之記載定之**；執行事件債權人有無執行名義所載請求權，執行法院**無審認判斷之權**。
> **88 年裁定**（講義 2 頁，字號請對講義）：執行法院並無實體審查權限，債權人縱已與債務人於強制執行程序中**和解**，亦非不得繼續強制執行；和解為消滅或妨礙債權人請求之事由，債務人僅得依 **§14** 提起異議之訴，不得謂其和解有阻止確定判決執行之效力。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人向執行處主張已清償／時效完成，執行處應審查？」 | **不得審查**實體。請債務人到**民事庭**起訴（§14） |
| 「債權人與債務人於執行程序中和解，執行法院即應停止執行？」 | **錯**。仍得繼續執行；和解屬實體事由 → §14 異議之訴（88 年裁定，**考過**） |
| 「債務人提起異議之訴，執行程序當然停止？」 | **錯**。§18 I 不停止為原則；II 法院**得**裁定停止（通常命供擔保） |
| 「執行法院審查執行名義，採實質審查？」 | **錯**。只做**形式審查**，依執行名義外觀 |
| 「判決主文未命給付遲延利息，執行時得一併執行利息？」 | **不得**，執行名義寫什麼才執行什麼 |
| 「強制執行法未規定事項，準用何法？」 | **民事訴訟法**（§30-1） |

## 一、分離原則體系

```
                法院（同一棟建築，不同部門）
        ┌───────────────┴───────────────┐
   民事庭＝權利判定機關                 民事執行處＝執行機關
   言詞辯論、調查證據                   辦公室、拍賣開標室，不開庭
   審查實體權利存否                     只看執行名義外觀（形式審查）
        ▲                                   │
        └──── 實體爭執：請你「去隔壁起訴」 ◄──┘
                 （§14 異議之訴等）
                 起訴後 → §18 II 得聲請停止執行
```

## 二、案例：執行中和解（88 年裁定）

```
甲持確定判決（乙應給付 100 萬）聲請執行乙的存款
執行中甲乙私下和解：乙付 50 萬，甲不再執行
甲「不講武德」，照樣聲請續行執行
  │
  ├─ 執行處：和解是實體事項，執行名義上沒寫 → 不審查 → 得繼續執行
  └─ 乙救濟：到民事庭提 §14 債務人異議之訴（百分之百的民事訴訟）
            ＋ 依 §18 II 聲請停止執行 → 等判決確定再決定是否續行
```

## 三、為何不審查實體

| 理由 | 說明 |
|---|---|
| 迅速 | 迅速為最高指導原則 |
| 程序保障已給過 | 民訴有直接、言詞審理；該提的抗辯應在前階段提出（既判力失權效） |
| 避免逃避執行 | 防止債務人以爭執請求權存否拖延 |
| 不是第四審 | 執行處不重審判決 |
