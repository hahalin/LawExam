# 強制執行法03 筆記：民訴費用修正與執行費

## 112 年 12 月 1 日民訴修正：
- §77-2 II 加入「**起訴後**」三字：只有起訴後之孳息、損賠、違約金、費用不併算 → 反面解釋：**起訴前要併算**
- 執行依 §30-1 準用 → 孳息等附帶請求應計算至**聲請強制執行之前一日**（當天不算），併入標的金額再算千分之八

## 新舊法過渡：
- 舊法時已**繳足**執行費，拍賣無著換發憑證，新法後持憑證再聲請 → **不必補繳**附帶請求部分
- 舊法時只繳 **1,000 元**（逕行發給）或只繳**部分**執行費，新法後聲請執行全部 → 屬新事實，**依新法計算**

## 異議要不要繳 1,000 元：
- 民訴 §77-19 對**司法事務官處分**提出異議，徵收裁判費 1,000 元
- 強執 §12、§39、§119 之異議**不是**民訴上的異議 → **不必繳裁判費**

## 📖 法條原文速查

> **民訴 §77-2 I**　以一訴主張數項標的者，其價額**合併計算**之。但所主張之數項標的互相競合或應為選擇者，其訴訟標的價額，應依其中價額最高者定之。
> **民訴 §77-2 II**　以一訴附帶請求其**起訴後**之孳息、損害賠償、違約金或費用者，**不併算**其價額。
> **民訴 §77-19**　（下列聲請或提出異議，徵收裁判費新臺幣一千元：…）對於**司法事務官處分**提出異議（款次請對六法）
> **強執 §30-1**　強制執行程序，除本法有規定外，準用民事訴訟法之規定。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「執行標的金額之利息應計算至何時？」 | **聲請強制執行之前一日**（當天不算） |
| 「起訴前之利息是否併算訴訟標的價額？」 | **併算**（§77-2 II 反面解釋） |
| 「舊法時已繳足執行費，新法後持債權憑證再聲請，應補繳利息部分？」 | **不必** |
| 「舊法時僅繳 1,000 元逕行發給憑證，新法後聲請執行全部？」 | **依新法**計算（利息算至前一日）再套千分之八 |
| 「依強執 §12 聲明異議須繳裁判費 1,000 元？」 | **不必**，強執之異議非民訴所定異議 |
| 「對司法事務官確定訴訟費用額之處分不服？」 | 10 日內書狀**異議**，繳 **1,000 元** |

## 一、修正前後對照

| | 修正前 | 修正後（112.12.1 施行） |
|---|---|---|
| 附帶請求 | 全部不併算 | 只有**起訴後**不併算 |
| 起訴前孳息 | 不算 | **併算** |
| 立法理由 | — | 起訴前有確定日期，算得出來；起訴後終期不明 |
| 執行準用 | — | 孳息算至**聲請執行前一日** |

## 二、計算例

```
本金 100 萬，利息自 113/1/1 起算
115/7/15 遞狀聲請強制執行
標的金額 ＝ 本金 100 萬 ＋ 利息（113/1/1 ～ 115/7/14）
執行費 ＝ 標的金額 × 千分之八
```

## 三、新舊法過渡判斷

```
舊法時代（112.12.1 前）怎麼繳的？
├── 繳足 → 換發憑證後再聲請 → 不補繳附帶請求部分
└── 未繳足（只繳 1,000 逕行發給，或只執行一部分）
        → 新法後聲請執行全部 → 新事實，依新法計算
口訣：繳足的不補；沒繳足通通依新法
```

## 四、哪些「異議」要繳錢

```
民訴上的異議（司法事務官處分，例：確定訴訟費用額）→ 1,000 元
強執上的異議
├── §12  聲明異議（程序瑕疵）
├── §39  分配表聲明異議
└── §119 第三人對扣押命令之異議
→ 均不必繳裁判費
```
