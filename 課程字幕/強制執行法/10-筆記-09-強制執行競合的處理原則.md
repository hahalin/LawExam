# 強制執行法10 筆記：強制執行競合的處理原則

## 什麼是執行競合：
- **數個債權人**各持**執行名義**，對**同一債務人**之**同一標的物**，同時或先後聲請執行
- 考題幾乎都是**兩個**執行程序；每年必考一題

## 先判斷能否並存：
- **得並存**：目的相同、不相抵觸 → 通常是**金錢對金錢**（大家都要錢）
- **不得並存**：目的不同、互相抵觸 → 物之交付、行為不行為具**特定性、排他性**
- 金錢與非金錢也可能並存，**看題目**用常理判斷

## 得並存 → §33＋§133：
- §33 併案：已實施執行行為之效力及於後聲請之債權人，合併程序，依分配程序辦理（禁止雙重查封）
- 其中有**假扣押** → 其應受分配之金額**提存**（§133）
- 前程序撤回或撤銷而終結 → 後程序潛在效力顯現，得**繼續執行**

## 不得並存 → 兩個標準（二選一）：
- ① **終局 vs 保全** → **終局優先**
- ② **終局 vs 終局**、**保全 vs 保全** → 依**聲請時間先後**（先聲請者優先）
- 先用①；①用不上（兩者同級）才用②；劣後者聲請被**駁回**

## 📖 法條原文速查

> **強執 §33**　對於已開始實施強制執行之債務人財產，他債權人再聲請強制執行者，**已實施執行行為之效力，於為聲請時及於該他債權人**，應**合併其執行程序**，並依前二條之規定辦理。
> **強執 §133**　因執行假扣押收取之金錢，及依分配程序應分配於假扣押債權人之金額，應**提存**之。
> **強執 §4 I ①**　確定之終局判決。（終局執行名義之典型）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「終局金錢執行與假扣押競合？」 | **得並存**：§33 合併程序＋假扣押那份**提存**（§133） |
| 「終局金錢執行與禁止處分之假處分競合？」 | **不得並存** → **終局優先**；假處分之聲請駁回 |
| 「兩個終局執行、內容互相抵觸？」 | 依**聲請先後**決定 |
| 「兩個保全執行、內容互相抵觸？」 | 依**聲請先後**決定 |
| 「併案執行後前案撤回，後案？」 | 潛在效力顯現，**得繼續執行** |
| 「金錢與非金錢執行一定不能並存？」 | **不一定**，看題目內容 |

## 一、黑板圖：兩種典型

```
例一（得並存）                       例二（不得並存）
甲1：確定判決（金錢）─┐              甲1：確定判決（金錢，§4 I ①）─┐
甲2：假扣押（金錢）───┼→ 乙的車      甲2：假處分「禁止處分 A 地」────┼→ 乙的 A 地
                     │                                             │
  查封 → 換價 → 分配表                甲1 要換價 ←→ 甲2 要不准動
  甲2 那份提存（§133）                → 終局優先：甲1 拍賣；甲2 聲請駁回
```

## 二、判斷流程

```
兩個執行程序同時對同一標的
        ↓
內容是否相抵觸？
├─ 否 → 並存：§33 合併、分配；有假扣押 → §133 提存
└─ 是 → 一個終局、一個保全？
         ├─ 是 → 終局優先
         └─ 否（同級）→ 時間先後（先聲請者優先）
```

- 講義「依時間先後」那一行老師說有誤植，更正為「終局 vs 終局、**保全 vs 保全**」（01:52 附近）。
