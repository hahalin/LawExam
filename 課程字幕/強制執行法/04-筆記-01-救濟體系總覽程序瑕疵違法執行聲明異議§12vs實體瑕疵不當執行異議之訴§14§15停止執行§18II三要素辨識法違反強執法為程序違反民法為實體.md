# 強制執行法04 筆記：強制執行救濟的體系

## 先問程序瑕疵還是實體瑕疵：
- 程序瑕疵（違法執行）→ 向執行處**聲明異議**（§12，不停止執行）
- 實體瑕疵（不當執行）→ 向民事庭提**異議之訴**（§14 債務人、§15 第三人，得併依 §18 II 聲請停止執行）

## 辨識法：
- 違反的是強制執行法 → 程序
- 違反的是民法 → 實體
- 執行三要素（執行名義、主體、客體）各有對應的異議之訴

## 📖 法條原文速查

> **強執 §12 I**　當事人或利害關係人，對於執行法院強制執行之命令，或對於執行法官、書記官、執達員實施強制執行之方法，強制執行時應遵守之程序，或其他侵害利益之情事，得於強制執行程序終結前，為聲請或聲明異議。但強制執行不因而停止。
> **強執 §14 I**（債務人異議之訴）執行名義成立後，如有消滅或妨礙債權人請求之事由發生，債務人得於強制執行程序終結前，向執行法院對債權人提起異議之訴。……
> **強執 §15**（第三人異議之訴）第三人就執行標的物有足以排除強制執行之權利者，得於強制執行程序終結前，向執行法院對債權人提起異議之訴。如債務人亦否認其權利時，並得以債務人為被告。
> **強執 §18 II**　有回復原狀之聲請，或提起再審或異議之訴，或對於和解為繼續審判之請求，或提起宣告調解無效之訴、撤銷調解之訴，或對於許可強制執行之裁定提起抗告時，法院因必要情形或依聲請定相當並確實之擔保，得為停止強制執行之裁定。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「看到救濟題第一步？」 | 先辨識是**程序**上還是**實體**上的不服。程序瑕疵＝**違法執行**→ 聲明異議（§12）；實體瑕疵＝**不當執行**→ 異議之訴（§14／§15） |
| 「怎麼分程序／實體？」 | 違反的是**強制執行法**（查封方式、夜間執行、禁止查封物、無執行名義）→ 程序；違反的是**民法**（清償、抵銷、時效、所有權歸屬）→ 實體 |
| 「兩種救濟最大差別？」 | 聲明異議：向**執行處**，**不停止執行**（§12 I 但書）。異議之訴：向**民事庭**起訴，是一般民事訴訟，得併依 **§18 II** 聲請停止執行 |
| 「甲持 500 萬確定判決執行乙之 A 屋 B 地；乙主張甲積欠其買賣價金 800 萬抵銷？」 | 抵銷＝債之消滅事由＝實體 → **§14 債務人異議之訴**＋§18 II 聲請停止執行 |
| 「第三人丙主張 A 屋為其出資興建所有？」 | 所有權歸屬＝實體 → **§15 第三人異議之訴**＋§18 II |
| 「異議之訴依執行要素分幾類？」 | 執行**名義**有瑕疵（§14、§14-1）、執行**主體**有瑕疵（§14-1）、執行**客體**有瑕疵（§15）；特殊：§41 分配表、§119 第三人聲明異議 |

## 一、兩條路

| | 程序瑕疵（違法執行） | 實體瑕疵（不當執行） |
|---|---|---|
| 違反什麼 | 強制執行法 | 民法（實體權利義務） |
| 救濟 | **聲明異議** §12 | **異議之訴** §14、§15（§14-1、§41、§119） |
| 向誰 | 執行處（自己做錯自己改） | 民事庭（一般民事訴訟） |
| 停止執行 | **不停止**（§12 I 但書） | 得依 §18 II 聲請停止 |
| 審查對象 | 執行程序合不合法 | 實體權利存不存在、歸屬誰 |

## 二、審題三要素

```
誰對誰執行（債權人甲 → 債務人乙）
執行名義是什麼（確定判決、支付命令、本票裁定、公證書…）
執行對象是什麼（A 屋、B 地、醫療設備…）
```

- 三要素各自有實體爭執的管道：名義 → §14；主體 → §14-1；客體 → §15。執行法「很整齊」。

## 三、講義 132 頁例題（幼幼班）

```
甲持 500 萬確定判決，執行乙之 A 屋、B 地
① 乙：甲欠我 800 萬買賣價金，主張抵銷 → 實體（債之消滅）→ §14 ＋ §18 II
② 丙：A 屋是我出資興建、我所有 → 實體（所有權歸屬）→ §15 ＋ §18 II
（虛線框：若執行名義有確定判決效力，提 §14 還要看異議事由發生時點 → 筆記 06）
```

- 老師：出題老師知道很多人放棄執行法，稍微聽過課選擇題就能猜對。
