# 強制執行法08 筆記：收取命令與移轉命令

## 收取命令：
- **代位收取**：甲直接向丙收取；丙向甲清償 → 對乙生清償效力
- 丙得以對乙之抗辯對抗甲；丙未依 §119 異議 → 得逕為執行；有異議 → 另行起訴（筆記 09、10）

## 移轉命令＝債權讓與：
- 性質同民法債權讓與（答案沒寫「債權讓與」老師說基本上就是錯）
- 適合：有**確切面額**、能即時明確結算的債權（例：扣押生效當日存款餘額 10 萬）
- 效力：被移轉債權連同從權利移轉給甲；丙對乙之實體事由仍得對抗甲
- 清償效力：生效時被移轉債權存在者，於移轉額度內發生清償債權及執行費用之效力 → **執行程序終結**

## 對移轉命令的救濟：
- 執行程序雖因核發移轉命令而終結，但對**移轉命令本身是否合法**聲明異議時，執行法院**不得**以程序已終結為由駁回

> 來源：強制執行法08 課程字幕 00:34:09 ~ 00:41:39（講義 300 頁起）

## 📖 法條原文速查

> **強執 §115 II**　前項情形，執行法院得詢問債權人意見，以命令許債權人**收取**，或將該債權**移轉**於債權人。如認為適當時，得命第三人向執行法院支付轉給債權人。
> **強執 §12 I**　當事人或利害關係人，對於執行法院強制執行之命令，或對於執行法官、書記官、執達員實施強制執行之方法，強制執行時應遵守之程序，或其他侵害利益之情事，得於強制執行程序**終結前**，為聲請或聲明異議。……
（原文請對六法）

## 📋 實務見解

> **最高法院 106 年判決**（字號請對講義）：移轉命令係執行法院以命令將扣押之金錢債權，依**確切面額**移轉於債權人，以代替金錢之支付，為扣押債權之**代物清償**，性質與民法之債權讓與同。移轉命令生效後，債務人喪失其債權人地位，執行債權在移轉範圍內**因清償而消滅**，該部分執行程序即告終結。

> **院字 2776 號（33 年）**：§12 所稱程序終結，視聲明異議內容分別定之——針對整個執行名義者為整個程序終結前，針對個別執行處分者為個別程序終結前（04 堂筆記 03）。

> **移轉命令之聲明異議**（出處請對講義）：執行程序因核發移轉命令而終結者，當事人或利害關係人就執行法院核發移轉命令是否合法有爭執，執行法院**不得**以執行程序業已終結為由駁回其聲明異議。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「移轉命令的性質？」 | **債權讓與**（代物清償） |
| 「移轉命令生效後丙不付款，甲得聲請執行處逕向丙執行？」 | **不得**；甲以新債權人地位另訴取得執行名義 |
| 「收取命令核發後，執行債權即全部消滅？」 | **錯**。實際收取的範圍內才消滅 |
| 「適合核發移轉命令的債權？」 | 有**確切面額**、可即時明確結算者 |
| 「移轉命令核發後程序終結，對移轉命令聲明異議應駁回？」 | **錯**。不得以程序終結為由駁回（考過） |
| 「丙已依收取命令向甲清償，對乙？」 | 生清償效力 |

## 一、收取 vs 移轉

| | 收取命令 | 移轉命令 |
|---|---|---|
| 乙的債權人地位 | 仍是乙 | **移轉給甲**，乙喪失 |
| 清償時點 | 甲實際收取時、收取範圍內 | 命令**生效時**，移轉範圍內 |
| 執行程序 | 收取後才終結 | 生效即終結 |
| 丙不付款 | §119 II 逕向丙執行（未異議時） | 甲另訴、另取執行名義 |
| 丙無資力風險 | 乙（甲可續行執行其他財產） | 甲 |

## 二、移轉命令「兩個願望同時滿足」

```
移轉命令生效（送達丙）
   ↓
換價（債權讓與給甲）＋滿足（移轉範圍內清償）同時完成
   ↓
執行程序終結 → 執行處結案
   ↓ 例外
對「移轉命令本身」聲明異議 → 不得以終結為由駁回（否則永遠無法救濟）
```
