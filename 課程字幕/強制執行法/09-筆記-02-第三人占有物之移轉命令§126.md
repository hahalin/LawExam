# 強制執行法09 筆記：第三人占有物之移轉命令（§126）

## 前提：
- 應交付之動產、不動產、船舶、航空器在**第三人**手上（例：乙把應交給甲的車借給丙開）
- 第三人為執行名義效力所及（§4-2，等於民訴 §401 主觀範圍）→ **直接對第三人執行**，不必用 §126
- 第三人非效力所及，債務人對第三人有交付請求權 → 執行法院以命令將該請求權**移轉於債權人**（§126）

## 兩種「移轉命令」同名不同義：
- 金錢債權執行 §115 II 的移轉命令＝**債權讓與**、以券面額抵償，執行程序**終結**
- 物之交付 §126 的移轉命令＝只給債權人**收取權**；第三人不交 → 債權人須**另行起訴取得執行名義**，不得逕對第三人執行（也沒有 §119 那種逕對第三人執行）

## 不用先發扣押命令：
- §126 只規定移轉，物之交付章也未準用 §115、§116 → **否定說**：直接發移轉命令
- 「查封 → 換價 → 滿足」只用在金錢債權執行；物之交付、行為不行為都不適用

## 📖 法條原文速查

> **強執 §126**　第一百二十三條及第一百二十四條應交付之動產、不動產或船舶及航空器為**第三人占有**者，執行法院應以命令將債務人對於第三人得請求交付之權利**移轉於債權人**。
> **強執 §4-2 I**　執行名義為確定終局判決者，除當事人外，對於下列之人亦有效力：一、訴訟繫屬後為當事人之繼受人及為當事人或其繼受人占有請求之標的物者。二、為他人而為原告或被告者之該他人及訴訟繫屬後為該他人之繼受人，及為該他人或其繼受人占有請求之標的物者。
> **強執 §115 II**　（金錢債權執行）執行法院得詢問債權人意見，以命令許債權人收取，或將該債權移轉於債權人。
（條文原文請對六法；§126 字幕老師要求把「應」字畫起來）

## 📋 實務見解

> **§126 移轉命令之性質**：僅給予債權人**收取權**，與 §115 II 之移轉命令有別。債權人得依此命令直接請求第三人交付；第三人不履行時，債權人須另行提起交付之訴，取得執行名義後方得對第三人強制執行，未取得前不得逕予強制執行。（出處請對講義 326 頁後）

> **核發前是否須先發扣押命令**：採**否定說**。物之交付章未設規定，亦未準用 §115、§116，執行法院直接核發移轉命令即可。（字幕聽成「才否定說」＝採否定說；座談會字號請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「應交付之動產由**非**執行名義效力所及之第三人占有，執行法院應如何？」 | 依 §126 核發**移轉命令**，將債務人對第三人之交付請求權移轉於債權人 |
| 「第三人為執行名義效力所及（如訴訟繫屬後之繼受人）？」 | 直接對第三人執行（§4-2），不必用 §126 |
| 「核發 §126 移轉命令前，應先發扣押命令？」 | **否**（否定說）——物之交付不走查封換價 |
| 「§126 移轉命令與 §115 II 移轉命令性質相同？」 | **不同**。§126 只給**收取權**；§115 II 是債權讓與、程序終結 |
| 「第三人收到 §126 移轉命令仍不交付，執行法院得逕對第三人執行？」 | **不得**。債權人須另訴取得執行名義 |
| 「題目是金錢、物之交付、還是行為不行為？」 | 先分類；一試非金錢執行約佔 2～3 題，看錯類型就全錯 |

## 一、三角關係圖

```
      執行名義（交付 B 車）
  甲 ─────────────────────▶ 乙（債務人，車不在手上）
  ▲                          │ 使用借貸，借用物返還請求權
  │  §126 移轉命令            ▼
  └──────────────────────── 丙（第三人，實際占有 B 車）
     甲取得「向丙請求交付」的權利（收取權）
     丙不交 → 甲另訴取得對丙的執行名義
```

## 二、兩種移轉命令比較

| | §115 II（金錢債權執行） | §126（物之交付） |
|---|---|---|
| 目的 | 拿錢 | 拿到那個物 |
| 前一步 | 先發**扣押命令** | **不用**扣押 |
| 性質 | 債權讓與，以券面額抵償 | 只給**收取權** |
| 程序 | 移轉後執行程序終結 | 第三人不交 → 另訴取得執行名義 |
| 第三人不理 | 有 §119 逕對第三人執行 | **無** |

- 老師：考卷上九成以上的「移轉命令」指的是 §115 II 那一種；§126 是「同名同姓」的另一個人，出題時看標的是錢還是物就分得出來。
