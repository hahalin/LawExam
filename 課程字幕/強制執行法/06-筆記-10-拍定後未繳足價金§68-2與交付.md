# 強制執行法06 筆記：拍定後——未繳足價金（§68-2）與交付

## 拍定人未繳足價金（§68-2）：
- 執行法院**再拍賣**：**同一條件**，不打折（不是東西差，是拍定人害的；與二拍不同）
- 原拍定人**不得應買**
- 再拍賣價金較低＋再拍賣費用 → 原拍定人**負擔差額**；執行法院依職權**裁定**確定，裁定＝執行名義
- 保證金先抵差額，不足再對原拍定人強制執行；有剩發還（注意事項 37 II）
- 性質：損害賠償兼制裁；不動產依 §113 準用

## 債權人承受後反悔：
- §68-2 條文只講拍定人 → 對承受之債權人**類推適用**（座談會多數說）

## 交付與其他：
- 先**繳足價金**才交付；動產移轉占有取得所有權
- 拍定人就物之瑕疵**無擔保請求權**（§69）
- 賣得價金足清償債權額及費用 → 應即停止拍賣（§72，超額拍賣禁止）；拍賣作筆錄（§73）

## 📖 法條原文速查

> **強執 §68-2**　I 拍定人未繳足價金者，執行法院應**再拍賣**。再拍賣時**原拍定人不得應買**。如再拍賣之價金低於原拍賣價金及因再拍賣所生之費用者，原拍定人應**負擔其差額**。II 前項差額，執行法院應依職權以**裁定**確定之。III 原拍定人繳納之**保證金**不足抵償差額時，得依前項裁定對原拍定人強制執行。
> **辦理強制執行事件應行注意事項 37 II**　動產拍賣拍定人預納保證金者，如因拍定人不繳足價金而再行拍賣時，原拍定人所繳納之保證金，應於清償再拍賣程序之費用及拍定價額低於前次拍定價額所生差額後，予以**發還**。（原文請對講義）
> **強執 §69**　拍賣物買受人就物之瑕疵無擔保請求權。
> **強執 §72**　拍賣於賣得價金足以清償強制執行之債權額及債務人應負擔之費用時，應即停止。
> **強執 §113**　不動產之強制執行，除本節有規定外，準用關於動產執行之規定。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「拍定人未繳足價金，再拍賣條件？」 | **同一條件**（不打折）；與二拍打五折不同 |
| 「原拍定人得否參加再拍賣？」 | **不得應買** |
| 「再拍賣價金較低？」 | 差額＋再拍賣費用由**原拍定人負擔**；執行法院**依職權裁定**確定，該裁定即**執行名義** |
| 「保證金如何處理？」 | 先抵償差額及費用；不足 → 依裁定對原拍定人強制執行；有剩 → 發還（不必然全部沒收） |
| 「債權人表示承受後反悔不補繳？」 | **類推適用 §68-2**（§68-2 文義只及於拍定人；座談會多數說） |
| 「不動產拍定人未繳價金？」 | **§113 準用 §68-2** |
| 「拍定人回家發現電視壞了，請求退貨或減價？」 | **不得**（§69），不動產亦準用 |
| 「拍賣到何時應停止？」 | 賣得價金足清償債權額及執行費用時（§72） |

## 一、§68-2 的再拍賣 vs §70 V 的再行拍賣

| | §68-2 再拍賣 | §70 V 再行拍賣（二拍） |
|---|---|---|
| 原因 | 拍定人**未繳足**價金 | 一拍**未拍定** |
| 條件 | **同一條件** | 底價 50% 即可拍定 |
| 原拍定人 | 不得應買 | — |
| 差額 | 原拍定人負擔（裁定＝執行名義） | — |

## 二、例題（講義 242 頁）

```
甲銀行聲請拍賣債務人乙之房屋
丙繳保證金 20 萬，投標 250 萬拍定，未於期限繳價金
→ 再拍賣以 240 萬賣出
→ 依據：§113 準用 §68-2
   差額 10 萬＋再拍賣費用由丙負擔；保證金先抵，有剩發還
```

## 三、國考題：債權人承受後反悔

```
拍賣 A 動產定有底價而無人應買（§71）
→ 債權人甲表示願承受 → 後悔、拒絕補繳差額
→ A 動產顯有賣得相當價金之可能 → 再行拍賣（§71 但書準用 §70 V）
→ 甲：類推適用 §68-2（負擔差額，裁定得為執行名義）
```
