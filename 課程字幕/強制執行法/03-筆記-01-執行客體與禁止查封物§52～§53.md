# 強制執行法03 筆記：執行客體與禁止查封物（§52～§53）

## 執行客體：
- 金錢債權 → 債務人的**責任財產**（存款、房地、汽車…），範圍最廣，本章主要討論對象
- 物之交付 → 執行名義所載**特定物**；行為不行為 → 以該作為／不作為為對象
- **選擇權在債權人**：債務人不得指定「先執行某財產」（實務見解，字號請對講義）

## 不能執行的財產：
- 不能換價者、一身專屬者（依實體法）、人格權身分權、法律禁止查封者
- §52：查封時酌留債務人**及共同生活親屬** 2 個月生活必需（得伸縮，**1～3 個月**）
- §53 I 七款禁止查封物；但 §53 II：**顯失公平**（依聲請）或**債務人同意** → 仍可查封

## 📖 法條原文速查

> **強執 §52**　I 查封時，應酌留債務人及其**共同生活之親屬二個月間**生活所必需之食物、燃料及金錢。II 前項期間，執行法官審核債務人家庭狀況，得伸縮之。但不得**短於一個月或超過三個月**。
> **強執 §53 I**　左列之物不得查封：①生活必需之食物、衣服、寢具等 ②**職業上或教育上所必需之器具、物品** ③勳章、表彰榮譽之物 ④遺像、牌位、墓碑等祭祀禮拜用物 ⑤未與土地分離之天然孳息**不能於一個月內收穫者** ⑥尚未發表之發明或著作 ⑦依法令應設備之防災、安全器具（要旨，原文請對六法）
> **強執 §53 II**　前項規定斟酌債權人及債務人狀況，有**顯失公平**情形，仍以查封為適當者，執行法院得依聲請查封其全部或一部。其經**債務人同意**者，亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人得請求執行法院先執行其指定之財產？」 | **不得**，選擇權在**債權人** |
| 「§52 酌留生活費之對象僅限債務人本人？」 | **錯**，含**共同生活之親屬** |
| 「§52 酌留期間？」 | 原則 **2 個月**，法官得伸縮，**不短於 1 個月、不超過 3 個月** |
| 「職業上所必需之物**絕對**不得查封？」 | **錯**（考過）。顯失公平或債務人同意仍可查封（§53 II） |
| 「即將收成之橘子可否查封？」 | **可以**。§53 I ⑤ 只禁止「**不能**於一個月內收穫」者，要反面解釋 |
| 「百萬名牌床墊屬寢具，一律不得查封？」 | **錯**，個案顯失公平得依聲請查封 |

## 一、執行客體體系

```
執行客體
├── 金錢請求權 → 債務人責任財產（總財產）
│     └── 例外不能執行：
│         ├── 不能換價
│         ├── 一身專屬（實體法）
│         ├── 人格權、身分權
│         └── 法律禁止：§52 酌留、§53 禁止查封物、§122（筆記 02）、特別法（筆記 03）
├── 物之交付請求權 → 執行名義所示特定物
└── 行為不行為請求權 → 該行為本身
```

## 二、§53 I 七款速記

| 款 | 內容 | 例 |
|---|---|---|
| ① | 生活必需 | 衣服、棉被、床 |
| ② | **職業上、教育上**必需（常考） | 工作電腦、計程車、音樂家樂器、書包書桌 |
| ③ | 榮譽 | 勳章、獎盃 |
| ④ | 祭祀 | 牌位、墓碑 |
| ⑤ | 天然孳息**不能一個月內**收穫 | 剛種下的苗 ✗；快採收的橘子 ✓ 可查封 |
| ⑥ | 未發表發明、著作 | 寫到一半的書稿 |
| ⑦ | 依法令應設置之防災安全設備 | 大樓消防設施、避難器具 |

## 三、§53 II 例外

```
屬 §53 I 禁止查封物
        ↓
├── 顯失公平（如千萬小提琴、百萬床墊）＋以查封為適當 → 依聲請查封全部或一部
└── 債務人同意 → 可查封
→ 選擇題看到「絕對不得」「一律」＝極端字眼，通常是錯的
```
