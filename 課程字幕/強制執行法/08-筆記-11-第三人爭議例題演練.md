# 強制執行法08 筆記：第三人爭議例題演練

## 申論例題（甲、乙、丙、丁）：
- 乙對丙銀行 50 萬存款 → 扣押後發**移轉命令**；乙對丁 30 萬貨款 → 扣押後發**收取命令**
- 丙、丁扣押階段都沒異議；丙對移轉命令沒異議但拒不付款；丁在收取命令後 10 日內書狀異議
- 逕向執行：丙 ✗（移轉命令已終結）；丁 ✗（換價階段異議**合法**，已有異議）
- 起訴：丙 → 甲以新債權人地位提一般**給付之訴**；丁 → 甲依 **§120 II** 10 日內提收取訴訟，或不起訴

## 選擇題三題：
- 扣薪題（老師稱 104 年）：加薪部分亦為扣押效力所及；違反扣押付款對債權人不生效力；離職應先**聲明異議**；答案 **D**
- 置之不理題：收取、支付轉給得逕向第三人執行，移轉命令不得；「無論何種命令均不得」錯；答案 **D**
- 存款扣押題：次日匯入的錢**不**為扣押效力所及；答案 **B**

## 📖 法條原文速查

> **強執 §115-1 I**　要旨：對薪資或其他繼續性給付之債權所為強制執行，扣押效力及於扣押後應受及**增加之給付**。（原文請對六法）
> **強執 §51 II**　實施查封後，債務人就查封物所為移轉、設定負擔或其他有礙執行效果之行為，對於債權人**不生效力**。→ 扣押命令類推適用
> **民法 §340**　受債權扣押命令之第三債務人，於扣押後，始對其債權人取得債權者，不得以其所取得之債權與受扣押之債權為抵銷。→ 反面：扣押**前**已取得之債權仍得抵銷

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「扣押薪資後公司加薪，加薪部分不受扣押？」 | **錯**，及於扣押後增加之給付（§115-1 I） |
| 「扣押命令送達後，公司仍將全薪付給債務人，債權人不得主張無效？」 | **錯**，類推 §51 II，對債權人不生效力 |
| 「債務人收到扣押後離職，公司應 10 日內起訴？」 | **錯**，應 10 日內**聲明異議**（§119 I） |
| 「執行債權人受破產宣告，法院得許破產管理人收取？」 | **對**（破產管理人取得管理處分權） |
| 「無論何種命令，第三人置之不理，債權人僅得另取執行名義？」 | **錯**，收取、支付轉給仍得逕向第三人執行 |
| 「扣押 50 萬，帳戶只有 20 萬，次日匯入 30 萬亦受扣押？」 | **錯**，存款非繼續性給付，扣押無向後效力 |
| 「帳戶 100 萬、扣押 50 萬，另 50 萬債務人仍得處分？」 | **對**，客觀範圍以命令記載金額為準，不凍結整個帳戶 |
| 「銀行於扣押前已對乙有 30 萬借款債權，扣押後得抵銷？」 | **得**（扣押前取得之債權） |

## 一、申論例題分析

```
確定判決：乙應給付甲 100 萬
甲 ─→ 乙 ─┬─ 丙銀行：存款 50 萬 ── 扣押 → 移轉命令（債權讓與，終結）
           └─ 丁：貨款 30 萬 ───── 扣押 → 收取命令（代位收取）
```

| | 丙（移轉命令） | 丁（收取命令） |
|---|---|---|
| 異議情形 | 扣押、移轉都沒異議，拒不付款 | 扣押沒異議；收取命令後 10 日內書狀異議 |
| 異議合法？ | — | **合法**（命令包括換價命令） |
| 甲得否逕向執行？ | **否**：移轉命令已終結（注意事項 64 II） | **否**：要件①不符（已異議） |
| 甲得否起訴？ | 以受讓人地位提一般給付之訴，與執行程序無關 | §120 I 通知後，10 日內提**收取訴訟**（§120 II）；不起訴 → 丁得聲請撤銷命令 |

## 二、選擇題一：扣薪三分之一（老師稱 104 年）

- 事實：甲欠乙 100 萬，乙對甲在 K 公司的薪資聲請執行，法院就薪資三分之一發扣押命令
- A 加薪不受扣押 ✗（§115-1 I）
- B 公司全薪付甲、乙不得主張無效 ✗（類推 §51 II）
- C 甲離職，公司應 10 日內起訴 ✗（先聲明異議）
- D 乙受破產宣告，法院得許其破產管理人收取 ✓ → **答案 D**
- 字幕人名多誤聽（「假」「以」），依題意整理為甲債務人、乙債權人；B 選項原文請對講義

## 三、選擇題二：第三人置之不理（選錯的）

| 選項 | 判斷 |
|---|---|
| A 收取命令 → 得聲請對丙執行 | ✓ |
| B 移轉命令 → 不得聲請逕向執行 | ✓ |
| C 支付轉給命令 → 得逕向執行 | ✓ |
| D 無論何種命令都不得，只能另取執行名義 | **✗ → 答案 D** |

## 四、選擇題三：存款扣押 50 萬（選錯的）

| 選項 | 判斷 | 理由 |
|---|---|---|
| A 存款不足 50 萬，得具狀聲明異議 | ✓ | 數額有爭議（§119 I） |
| B 存款 20 萬，次日匯入 30 萬亦受扣押 | **✗ → 答案 B** | 非繼續性給付，扣押無向後效力，須另行聲請 |
| C 存款 100 萬，另 50 萬乙仍得處分 | ✓ | 以命令記載金額為準 |
| D 扣押前已有 30 萬借款，得抵銷 | ✓ | 扣押前已存在之抵銷權不受影響 |
