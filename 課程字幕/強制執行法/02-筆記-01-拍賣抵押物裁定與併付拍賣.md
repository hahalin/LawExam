# 強制執行法02 筆記：拍賣抵押物裁定與併付拍賣

## 執行名義種類開場題：
- 形成判決不能當執行名義，**給付判決**才有執行力
- 假執行判決被上級審**廢棄** → 假執行失效（民訴 §395），不是假執行本身不能當執行名義
- 公證書約定**一定數額**違約金、載明逕受強制執行 → 可為執行名義（正解）
- 外國確定判決須經我國法院**判決許可**，不得「逕為」執行名義（筆記 04）

## 拍賣抵押物裁定（§4 I ⑤）：
- **對物**的執行名義：只能執行擔保物；拍賣不足清償 → 債務人其他財產須**另取執行名義**
- 一般抵押、最高限額抵押、動產質權都用第五款

## 併付拍賣：
- 民 §877：土地設定抵押**後**才蓋的房屋，抵押權人得於執行程序中**聲請**併付拍賣；建物部分**不必另取裁定**，但建物價金**無優先受償權**
- 聲請不一定准，由執行處個案判斷
- 另有 §877-1（建物抵押 → 必要之土地使用權）、§862 III 但書（抵押後附加之獨立物）；要和 §876 **法定地上權**區分

## 📖 法條原文速查

> **強執 §4 I ⑤**　抵押權人或質權人，為拍賣抵押物或質物之聲請，經法院為**許可強制執行之裁定**者。
> **民 §877 I**　土地所有人於設定抵押權**後**，在抵押之土地上營造建築物者，抵押權人於必要時，得於強制執行程序中**聲請**法院將其建築物與土地**併付拍賣**。但對於建築物之價金，**無優先受清償之權**。
> **民 §877-1**　以建築物設定抵押權者，於法院拍賣抵押物時，其抵押物存在所必要之權利得讓與者，應併付拍賣。但抵押權人對於該權利賣得之價金，無優先受清償之權。
> **民 §876 I**　設定抵押權時，土地及其土地上之建築物，**同屬於一人所有**，而僅以土地或僅以建築物為抵押者，於抵押物拍賣時，**視為已有地上權之設定**……（後段請對六法）
> **強執 §99 I**　債務人應交出之不動產，現為債務人占有或於查封後為第三人占有者，執行法院應解除其占有，**點交**於買受人或承受人；如有拒絕交出或其他情事時，得請警察協助。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法院撤銷某法律行為之判決確定，得為執行名義？」 | **不得**，形成判決無執行力；限**給付判決** |
| 「宣告假執行之給付判決遭上級審廢棄，仍得執行？」 | **不得**，假執行宣告因廢棄而**失效**（民訴 §395） |
| 「日本法院確定給付判決得逕為執行名義？」 | **錯**，須經我國法院判決許可（§4-1） |
| 「拍賣抵押物不足清償，得就債務人其他財產續行執行？」 | **不得**，§4 I ⑤ 是對物執行名義，須另取執行名義 |
| 「依 §877 併付拍賣之建物，須另取許可拍賣裁定？」 | **不須**，併付拍賣由執行處直接處理 |
| 「併付拍賣之建物價金，抵押權人得優先受償？」 | **不得**，抵押權只設定在土地 |
| 「土地拍定後能否點交？」 | 看查封時占有人：**債務人占有** → 可點交（§99），會載於拍賣公告 |

## 一、併付拍賣三種（民法）

```
抵押標的        可併付拍賣的東西              價金優先受償？
─────────────────────────────────────────────────────
土地（§877）    抵押後營造的建築物             ✗
建築物（§877-1）建物存在所必要之權利（地上權等）✗
建築物（§862 III 但書）抵押後附加的獨立物      ✗
```

- 對照 §876：設定抵押時**土地與房屋同屬一人** → 拍賣時**視為有地上權**（房子不能浮在空中，要有占有權源）。

## 二、講義 34 頁 立體演練

```
100 年  債務人以 A 地設定抵押 → 之後才蓋 B 屋
        債權人持許可拍賣抵押物裁定（§4 I ⑤）聲請拍賣 A 地

(1) A 地拍定後可否點交？
    點交＝移轉占有，執行處派人排除占有、交付買受人
    查封時 A 地由債務人占有 → 可點交（§99）

(2) A 地因有 B 屋，價格低落無人應買 → 聲請併付拍賣 B 屋？
    可以：符合 §877（抵押後營造）
    B 屋價金：無優先受償權
```
