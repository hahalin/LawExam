# 強制執行法06 筆記：分配次序與分配表聲明異議（§39）

## 分配次序：
- 稅（土增稅、地價稅、房屋稅）→ 執行費及共益費用（§29 II）→ 實體法上優先受償債權（擔保物權、勞工工資、關稅…）→ 普通債權
- 執行費通常排在稅後面

## 分配表聲明異議（§39）：
- 對象：分配表所載各債權人之**債權**或**分配金額**＝**實體**事項
- 時點：**分配期日一日前**（期日 3/2 → 最晚 3/1）
- 方式：**書狀**（口頭一定錯），記載原分配表之不當及應如何變更之聲明
- 向執行處提出；分配程序中的**程序**瑕疵仍走 §12（雙軌並行）

## 異議之後：
- 異議正當、到場者不反對或同意 → 更正分配表分配（§40 I）；未終結 → 無異議部分先分配（§40 II）
- 更正分配表送達未到場者，**三日內**不反對陳述 → 視為同意（§40-1 II）；有反對 → 通知異議人 → 接 §41（筆記 02）
- 不走 §39 也可以另訴不當得利（§179）

## 📖 法條原文速查

> **強執 §29 II**　前項費用及其他為債權人共同利益而支出之費用，得求償於債務人者，得就強制執行之財產**先受清償**。
> **強執 §31**　因強制執行所得之金額，如有多數債權人參與分配時，執行法院應作成**分配表**，並指定分配期日，於分配期日**五日前**以繕本交付債務人及各債權人，並置於民事執行處，任其閱覽。
> **強執 §39**　I 債權人或債務人對於分配表所載各債權人之**債權或分配金額**有不同意者，應於分配期日**一日前**，向執行法院提出**書狀**，聲明異議。II 前項書狀，應記載異議人所認原分配表之不當及應如何變更之聲明。
> **強執 §40**　I 執行法院對於前條之異議認為正當，而到場之債務人及有利害關係之他債權人不為反對之陳述或同意者，應即更正分配表而為分配。II 異議未依前項規定終結者，應就**無異議之部分先為分配**。
> **強執 §40-1**　I 依前條第一項更正之分配表，應送達於未到場之債務人及有利害關係之他債權人。II 前項債務人及債權人於受送達後**三日內**不為反對之陳述者，**視為同意**依更正分配表實行分配。其有為反對陳述者，應通知聲明異議人。
（§40、§40-1 原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「分配時誰先拿？」 | **稅** → 執行費及共益費用（§29 II）→ 實體法優先受償債權（抵押權、勞工工資等）→ 普通債權 |
| 「對分配表所載**債權金額過高、分配次序**有爭執，用什麼救濟？」 | **§39 分配表聲明異議**（實體瑕疵）；後續異議未終結 → **§41 分配表異議之訴** |
| 「對分配程序之**程序**瑕疵？」 | 仍是 **§12** 聲明異議——§39 與 §12 **雙軌並行**，不因在分配程序就排除 §12 |
| 「聲明異議都是程序瑕疵？」 | **錯**。聲明異議只代表「向執行處提出」；§39 是針對**實體**瑕疵的聲明異議 |
| 「得否於分配期日當天以**口頭**聲明異議？」 | **不得**。須於分配期日**一日前**、以**書狀**為之，並記載不當之處及如何變更 |
| 「未到場之債權人收到更正分配表後未表示意見？」 | 受送達後**三日內**不為反對陳述 → **視為同意**（§40-1 II） |
| 「異議未能終結，執行處怎麼分？」 | **無異議部分先分配**（§40 II）；有爭議部分走 §41 |
| 「債權人未依 §39 異議，得否另訴不當得利？」 | **得**。執行法救濟不排斥另訴；假債權受領＝無法律上原因受利益（§179） |

## 一、分配次序（講義 206 頁虛線框）

```
① 稅（土增稅、地價稅、房屋稅…）—— 通常最優先
② 執行費（千分之八）及其他共益費用（鑑價費等）—— §29 II
③ 實體法上優先受償之債權（擔保物權、勞基法工資優先權、關稅…）
④ 無優先權之普通債權
```

## 二、§39 vs §12

| | §39 分配表聲明異議 | §12 聲明異議 |
|---|---|---|
| 瑕疵 | **實體**（債權金額、分配次序） | 程序 |
| 向誰 | 執行處 | 執行處 |
| 時點 | 分配期日**一日前** | 執行程序終結前 |
| 方式 | **書狀**，載明不當及變更聲明 | 書狀或言詞 |
| 後續 | 未終結 → §41 民事庭 | 執行處裁定 → 抗告 |

- 老師：分配表只是書記官作的「暫定版本」，只有形式確定力；聲明異議可**阻止分配表確定**。

## 三、流程

```
執行處作分配表（期日 5 日前送達兩造，§31）
   ↓
有人不同意 → 期日 1 日前書狀聲明異議（§39）
   ↓
分配期日：異議正當、到場者不反對 → 更正分配表分配（§40 I）
         ├ 未到場者：更正表送達，3 日內不反對 → 視為同意（§40-1 II）
         └ 有反對陳述 → 異議未終結 → 無異議部分先分（§40 II）
                                   有爭議部分 → §41 分配表異議之訴（筆記 02）
```

- 分配期日不必到場（錢是匯款），但有異議的人最好去，才知道異議終結了沒。
