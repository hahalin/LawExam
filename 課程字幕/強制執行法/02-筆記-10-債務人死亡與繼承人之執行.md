# 強制執行法02 筆記：債務人死亡與繼承人之執行

## 實體前提：
- 民 §1148：繼承人概括承受權利義務，但對被繼承人債務以**所得遺產為限**負清償責任（98 年後全面有限責任）
- 遺產清算前，**遺產與固有財產分離**：被繼承人的債權人只能找遺產，繼承人的債權人只能找固有財產
- 可列繼承人為執行債務人，但執行標的**限於遺產**；**拋棄繼承**者不是繼承人，不得列為債務人

## 執行法配套：
- §5 III：執行開始後債務人死亡 → **得續行**（責任財產換名叫遺產，東西一樣）
- §5 IV：繼承人有無不明、所在不明、是否承認不明、因故不能管理遺產 → 得選任**特別代理人**
- §11 III、IV：債權人得聲請以**債務人費用**通知地政辦**繼承登記**後執行；不影響拋棄或限定繼承

## 萬年考古題：執行到繼承人固有財產：
- 實體瑕疵（違反民 §1148）→ 繼承人提 **第三人異議之訴**（§15），不是債務人異議之訴
- 理由：就遺產立於債務人地位；就**固有財產**立於**第三人**地位
- 執行名義若為「**於繼承財產限度內**」給付之保留判決 → 另得 **§12 聲明異議**（逾執行名義範圍＝程序瑕疵）
- 限定繼承公示催告期間（民 §1158）：限制的是繼承人清償，**不禁止**債權人聲請強制執行

## 📖 法條原文速查

> **民 §1148**　I 繼承人自繼承開始時，除本法另有規定外，承受被繼承人財產上之一切權利、義務。但權利、義務專屬於被繼承人本身者，不在此限。II 繼承人對於被繼承人之債務，**以因繼承所得遺產為限**，負清償責任。
> **民 §1158**　繼承人在前條所定之一定期限內，**不得對於被繼承人之任何債權人償還債務**。
> **強執 §5**　III 強制執行開始後，債務人死亡者，**得續行**強制執行。IV 債務人死亡，有左列情形之一者，執行法院得依債權人或利害關係人聲請，選任**特別代理人**……：一、繼承人有無不明者。二、繼承人所在不明者。三、繼承人是否承認繼承不明者。四、繼承人因故不能管理遺產者。（但書請對六法）
> **強執 §11**　III 債務人因繼承、強制執行、徵收或法院之判決，於登記前已取得不動產物權者，執行法院得因債權人之聲請，以**債務人費用**，通知登記機關登記為債務人所有後而為執行。IV 前項規定，於第五條第三項之續行強制執行而有辦理繼承登記之必要者，準用之。但**不影響繼承人拋棄繼承或限定繼承之權利**。（原文請對六法）

## 📋 實務見解速查

> **最高法院 75 年決議**（字號請對講義）：負有限責任之繼承人，對被繼承人債務僅負以遺產為限度之物的有限責任，僅就遺產之執行居於債務人地位；債權人就繼承人**固有財產**聲請強制執行，應認繼承人為強制執行法之**第三人**，得提**第三人異議之訴**。
> **最高法院判決**（字號請對講義）：遺產完成清算前，遺產與繼承人固有財產分離，被繼承人之債權人與繼承人之債權人，分別僅得就遺產或固有財產行使權利。
> **民 §1158 實務（第二說）**：該條僅規定債務人（繼承人）不得清償，**非規定法院不得強制執行**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「執行開始後債務人死亡，執行程序？」 | **得續行**（§5 III） |
| 「執行法院執行法定繼承人之固有財產，繼承人如何救濟？」 | **第三人異議之訴**（§15）；**非**債務人異議之訴 |
| 「上述情形繼承人得否聲請停止執行？」 | **得**（§18，異議之訴均得為停止事由） |
| 「執行名義為『於繼承財產限度內』給付，卻執行固有財產？」 | 另得 **§12 聲明異議**（逾執行名義範圍） |
| 「繼承人中一人已拋棄繼承，得列為執行債務人？」 | **不得** |
| 「遺產未辦繼承登記，執行法院如何執行？」 | 依聲請以**債務人費用**通知地政辦繼承登記後執行（§11 III、IV） |
| 「限定繼承公示催告申報期間內，債權人得聲請強制執行遺產？」 | **得**（§1158 只限制繼承人清償） |

## 一、選擇題（講義 70 頁後）

```
甲對 A 有 500 萬勝訴判決，聲請查封 A 之土地一筆
A 死亡，繼承人丙、丁、戊：丙依法拋棄繼承；丁、戊未表示（法定繼承）
下列何者錯誤？
A 執行開始後債務人死亡，執行程序仍得續行          ✓ §5 III
B 執行債務人應改列為丙、丁、戊                    ✗ ★答案：丙已拋棄
C 依甲聲請以債務人費用通知地政登記為丁戊公同共有後執行 ✓ §11 III、IV
D 執行丁之固有財產，丁得提第三人異議之訴並聲請停止執行 ✓ §15＋§18
```

## 二、本票題

```
甲持乙簽發 1,000 萬本票，取得本票裁定；乙收受後、確定前死亡
唯一繼承人丙：自有 A 地；繼承 B 地（500 萬，未辦繼承登記）
(1) 執行名義成立？丙有被執行適格？ → 均是（本票裁定生效即可；丙為一般繼受人）
(2) 執行 A 地？ → 不可（固有財產）
(3) 執行 B 地？ → 可；未登記者以債務人費用通知地政辦繼承登記後執行
```

## 三、繼承人的雙重身分

| 標的 | 繼承人地位 | 被違法執行時之救濟 |
|---|---|---|
| 遺產 | 債務人 | —— |
| 固有財產 | **第三人** | §15 第三人異議之訴（＋保留判決時 §12） |

- 早期實務曾認應提債務人異議之訴，**現已不採**。
