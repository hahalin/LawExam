# 強制執行法02 筆記：執行當事人與主觀範圍（§4-2）

## 執行當事人：
- 聲請人＝**債權人**，被請求人＝**債務人**，不問實體法上是否真為債權人、債務人
- 誰是當事人、執行範圍，都**依執行名義之記載**
- 當事人能力：準用民訴 §40（有權利能力即有；胎兒以利益為限；非法人團體、機關符合要件亦有）
- 執行行為能力：準用訴訟能力 → 須**成年**（18 歲）；未成年由法定代理人代理

## 主觀範圍（§4-2＝民訴 §401）：
- 執行力主觀範圍與既判力主觀範圍**一模一樣**
- 考點是**擴張**：執行名義上**沒寫名字**的人，能否拿它執行、能否被執行
- 四類：形式當事人、**繼受人**、**占有人**（占有輔助）、**實質當事人**（該他人）＋該他人之繼受人、占有人

## 準用：
- §4-2 II：第二至六款執行名義**準用** → 所有執行名義主觀範圍都一樣（本票裁定也有）
- 對主觀範圍有爭執 → **§14-1** 異議之訴（§4-2 與 §14-1 是一組）

## 📖 法條原文速查

> **強執 §4-2**　I 執行名義為確定終局判決者，除當事人外，對於左列之人亦有效力：
> 一、訴訟繫屬後為當事人之**繼受人**及為當事人或其繼受人**占有請求之標的物**者。
> 二、**為他人而為原告或被告者之該他人**及訴訟繫屬後為該他人之繼受人，及為該他人或其繼受人占有請求之標的物者。
> II 前項規定，於第四條第一項**第二款至第六款**規定之執行名義，**準用**之。
> **民訴 §401 I**　確定判決，除當事人外，對於訴訟繫屬後為當事人之繼受人者，及為當事人或其繼受人占有請求之標的物者，亦有效力。
> **強執 §14-1 I**　債務人對於債權人依第四條之二規定聲請強制執行，如主張**非執行名義效力所及**者，得於強制執行程序終結前，向執行法院對債權人提起異議之訴。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「執行當事人如何確定？」 | 依**執行名義之記載** |
| 「未成年人為執行債務人，如何進行？」 | 由**法定代理人**代理（準用訴訟能力） |
| 「執行力主觀範圍與既判力主觀範圍？」 | **相同**（§4-2＝民訴 §401） |
| 「本票裁定之執行力及於債務人之繼承人？」 | **及於**，§4-2 II 準用，各款執行名義皆同 |
| 「債權人死亡，其繼承人得持原執行名義聲請？」 | **得**，債權人方、債務人方都有繼受人之擴張 |
| 「債務人主張非執行名義效力所及，應如何救濟？」 | **§14-1** 異議之訴（實體救濟，民事訴訟） |

## 一、主觀範圍四類

```
§4-2 主觀範圍
├── ① 形式當事人：執行名義上記載之人（自不待言）
├── ② 繼受人（訴訟繫屬後）
│     ├── 一般繼受：死亡 → 繼承人（債權人死亡／債務人死亡）   ← 筆記 10
│     └── 特定繼受
│           ├── 訴訟標的：債權讓與、債務承擔                ← 筆記 11
│           └── 訴訟標的物：61 台上 186 債權物權區分         ← 筆記 11
├── ③ 占有人：為當事人或其繼受人占有標的物（占有輔助人）    ← 筆記 11
└── ④ 實質當事人：為他人起訴、被訴之「該他人」＋其繼受人、占有人 ← 筆記 11
```

## 二、黑板例

```
執行名義：甲（債權人）對乙（債務人）100 萬，判決確定
判決確定後乙死亡，繼承人丙
         ┌── 遺產（乙留下）
丙 ───────┤
         └── 固有財產（丙自己的）
問：甲能否持「甲對乙」的執行名義對丙執行？
→ 可以（一般繼受人，主觀範圍擴張）
→ 但執行標的以遺產為限，不能動丙的固有財產（民 §1148 II）
```

- 老師：繼承是最常考的，執行到一半死亡、繼承人來聲請或被執行。
