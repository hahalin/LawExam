# 強制執行法01 筆記：公證書（公證法§13）

## 四個要件：
- ① **公證人**依公證法作成（法院公證人、民間公證人效力相同）
- ② 限**四種法律行為**（公證法 §13 I 四款）
- ③ 載明**逕受強制執行**之意旨（執行承諾、執行約款）；欠缺即不能執行
- ④ 隱藏要件：債務人**給付遲延**（期限屆至未履行）

## 四款（兩兩一組）：
- 動產組：① 金錢、代替物、有價證券之**一定數量** ② **特定動產** → 不限契約類型（買賣、贈與、借貸皆可）
- 不動產組：③ 建築物／工作物 ④ 土地 → 只限**租用或借用**，須約定**期限屆滿應交還**（只寫「租到 12/31 止。」不夠）
- 土地另限使用目的：約定**非供耕作或建築**（保護農民；房子不能隨便拆）→ 夜市、停車場可以
- 使用目的以**約定**為準，不問實際使用狀況

## 附條件公證書：
- 102 年最高法院裁定：附條件者得為執行名義，但債權人應就**條件成就**提出證明文件（§4 II）

## 📖 法條原文速查

> **公證法 §13 I**　當事人請求公證人就下列各款法律行為作成之公證書，載明應**逕受強制執行**者，得依該證書執行之：
> 一、以給付金錢或其他代替物或有價證券之**一定數量**為標的者。
> 二、以給付**特定之動產**為標的者。
> 三、**租用或借用建築物**或其他工作物，定有期限並應於期限屆滿時**交還**者。
> 四、**租用或借用土地**，約定**非供耕作或建築**為目的，而於期限屆滿時應**交還土地**者。
> （原文請對六法）
> **強執 §4 II**　執行名義附有**條件**、期限或須債權人提供擔保者，於**條件成就**、期限屆至或供擔保後，始得開始強制執行。

---

## 📋 實務見解速查

> **最高法院 102 年裁定**（講義 30 頁，字號請對講義）：依公證法規定得為強制執行之公證書附有條件者，固得為執行名義，但債權人執此公證書請求執行時，對於**條件成就之事實應提出證明文件**，此觀強執 §4 II 規定自明。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「買賣房屋經公證並載明逕受強制執行，得依公證書請求交屋？」 | **不得**。不動產只限**租用、借用** |
| 「租用土地約定供耕作（或建築），期滿交還，經公證？」 | **不得**為執行名義（須**非**供耕作或建築） |
| 「租用土地約定作停車場，實際搭建鐵皮屋？」 | 以**約定**為準 → **得**執行 |
| 「租用土地約定建築房屋，實際作停車場？」 | 以約定為準 → **不得** |
| 「公證書載承攬契約解除時應返還已受領之價金？」 | **不得**，未載**一定數量**（須調查結算） |
| 「公證書載應給付以引擎號碼特定之卡車一輛？」 | **得**（特定動產） |
| 「公證書未載逕受強制執行之意旨？」 | **不得**執行 |
| 「附條件之公證書，誰證明條件成就？」 | **債權人**提出證明文件（§4 II；102 年裁定） |

老師：這節「考出來就一定會死一片」。

## 一、記憶表

```
            標的              契約類型          其他要求
動產 ┬ ① 金錢等一定數量  ──  不限            數量要明確
     └ ② 特定動產        ──  不限            要特定
不動 ┬ ③ 建築物／工作物  ──  限租、借        期滿交還（不限用途）
產   └ ④ 土地            ──  限租、借        期滿交還＋非供耕作或建築
```

- 口訣：**夜市、停車場可以**；種菜種田、蓋房子不行。
- 房屋不管用途（自住、商用、工廠都可）；土地才管用途。

## 二、講義練習：四份公證書（皆載逕受強制執行、期滿交還條款）

| 公證書內容 | 款 | 結論 |
|---|---|---|
| 承攬契約解除時，債務人應返還解除時已受領之價金 | ① | ✗ 未載一定數量，須核算 |
| 給付某廠生產、以引擎號碼特定之卡車一輛 | ② | ✓ 已特定 |
| 租用土地，約定停車場，實際搭鐵皮屋（建築） | ④ | ✓ 依約定 |
| 租用土地，約定建築房屋，實際作停車場 | ④ | ✗ 依約定，約定建築 |

## 三、加油站題（附條件公證書）

```
甲出租加油站（建築物）給乙，經公證；另約定乙交 600 萬履約保證金：
「契約期滿、乙無未履行事項時，甲無息返還」，並載逕受強制執行
租期屆滿，乙持公證書聲請執行甲之財產，請求返還 600 萬
甲抗辯：乙尚未返還加油站
  │
  ├─ 600 萬屬 ① 金錢一定數量 → 不限契約類型
  ├─ 返還附條件：期滿＋無未履行事項
  └─ 乙須就條件成就（已返還加油站、無未履行事項）提出證明文件（§4 II）
     → 執行處就此做形式審查
```
