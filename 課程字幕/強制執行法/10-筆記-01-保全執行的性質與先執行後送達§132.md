# 強制執行法10 筆記：保全執行的性質與先執行後送達（§132）

## 保全執行的定位：
- 保全執行（假扣押、假處分）**不是終局執行**：原則只做到**查封**，不換價、不滿足
- 例外得**換價**（緊急換價，§134），但價金一律**提存**，**滿足萬萬不可**——要等本案確定判決
- 民訴拿到的只是假扣押**裁定**；要拿到執行處聲請執行，財產才真正被凍結
- 本案勝訴後持確定判決聲請執行 → 不再重複查封，直接進入換價、分配

## 先執行、再送達（§132 I、II）：
- 執行應於裁定**送達同時或送達前**為之 → 目的：避免打草驚蛇、債務人脫產
- 先執行後**不能送達**，債權人又未聲請公示送達 → **應撤銷執行**；公示送達聲請被駁回確定者亦同

## 30 日（§132 III）：
- 債權人**收受裁定後逾 30 日**，不得聲請執行 → 執行名義本身有期限的唯一例外
- 逾期 → 再聲請一個新的假扣押裁定即可

## 注意事項的 7 日：
- 執行同時或執行完畢後 **7 日內**送達裁定 → 實務認為是**訓示規定**，逾期不影響執行效力、不撤銷

## 📖 法條原文速查

> **強執 §132**　I 假扣押或假處分之執行，應於假扣押或假處分之裁定**送達同時或送達前**為之。II 前項送達前之執行，於執行後**不能送達**，債權人又未聲請**公示送達**者，應**撤銷其執行**。其公示送達之聲請被駁回確定者亦同。III 債權人收受假扣押或假處分裁定後已逾**三十日**者，**不得聲請執行**。
> **強執注意事項（§132 部分）**　執行法院應於執行同時或執行完畢後**七日內**，將假扣押或假處分裁定送達債務人。（點次字幕聽成「第六的九條」，請對講義；原文請對六法）
> **民訴 §522 以下**　假扣押程序（取得執行名義的流程，民訴範圍）。

## 📋 實務見解

> **注意事項 7 日之性質**：執行法院未於執行同時或執行完畢後 7 日內送達裁定，**不應撤銷**假扣押執行——該期間為**訓示規定**，僅提醒執行人員勿拖延，不影響執行效力。（出處請對講義 368 頁附近）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「假扣押之執行應於裁定送達後為之？」 | **錯**。應於送達**同時或送達前**——先執行、再送達 |
| 「先執行後不能送達，債權人也沒聲請公示送達？」 | **應撤銷執行**（§132 II） |
| 「債權人收受假扣押裁定 35 日後才聲請執行？」 | **不得聲請**（§132 III，30 日）；可重新聲請裁定 |
| 「執行名義都沒有期間限制？」 | 原則上執行名義本身無時效，**假扣押、假處分裁定是例外**（30 日） |
| 「執行完畢後第 10 日才送達裁定，應撤銷假扣押執行？」 | **不應**。注意事項 7 日是**訓示規定** |
| 「保全執行可以把賣得價金交給債權人？」 | **不可**。最多到換價，價金**提存**；滿足要等本案 |

## 一、保全執行走到哪裡

```
終局執行（金錢）：查封 ──→ 換價 ──→ 滿足（分配、交付價金）
保全執行（假扣押）：查封 ──→ △換價（例外：緊急換價，價金提存）──✕ 滿足
                                   ↑ 本案勝訴確定後，持確定判決接續換價、分配（不再查封）
```

- 老師畫「△」：以前說保全不能換價，但特殊情形（易腐壞、保管費過高）可以換價。

## 二、一般執行 vs 保全執行的送達順序

| | 一般執行（確定判決） | 保全執行（假扣押、假處分裁定） |
|---|---|---|
| 順序 | 先送達兩造 → 再聲請執行 | **先執行 → 再送達**（或同時） |
| 理由 | 判決送達才確定 | 避免債務人知情後處分、隱匿財產 |
| 不能送達 | — | 未聲請公示送達 → 撤銷執行 |
| 聲請期間 | 無（看請求權時效） | 收受裁定後 **30 日** |

## 三、時點整理

```
債權人收受裁定 ──(30 日內聲請執行)──→ 執行（查封）──(同時或 7 日內)──→ 送達債務人
                                                       └ 不能送達且未聲請公示送達 → 撤銷執行
                                                       └ 逾 7 日才送達 → 訓示規定，執行仍有效
```
