# 強制執行法10 筆記：強制執行競合實例演練

## 解題步驟：
- 畫圖：同一債務人、同一標的、兩個債權人、兩個執行名義
- 把裁定內容「翻譯」：禁止移轉、禁止處分＝**查封**
- 判斷：能否並存 → 不能 → 終局 vs 保全？終局優先：同級？時間先後

## 選擇題一（本票裁定＋確定判決）：
- 兩個都是**金錢**終局執行 → **得並存** → §33 **合併執行程序**（答案 B）

## 選擇題二（假處分在先＋金錢確定判決在後，選錯的）：
- A 地仍是乙的責任財產，丙**得**聲請拍賣（查封只剝奪處分權）
- 甲得基於**所有權**（不是基於假處分債權人地位）提 §15 第三人異議之訴，並依 §18 II 聲請停止執行
- 甲以「保全在先」對准許丙執行**聲明異議** → **錯（答案 D）**：終局優先，程序無瑕疵

## 申論一（拆屋還地＋假扣押轉終局；事務官考題）：
- 甲拆屋還地確定判決在先 → 執行中丙假扣押房屋 → 丙後取得清償借款確定判決 → 房屋已拆除完畢
- 兩個都是終局 → 時間先後 → 甲先，拆除合法
- 剩餘鋼筋木材可否依丙聲請**直接拍賣**？多數（乙說）**否**：動產、不動產查封方法不同，房屋查封效力不能變成動產查封效力；房屋拆除 → 標的物**失其存在**，建材是新的動產 → 丙須**重新聲請**依動產方法查封

## 申論二（假處分＋金錢終局）：
- 假處分禁止甲處分 A 屋並查封完畢；丙持金錢確定判決聲請拍賣 → **准許**（70 年第 10 次，終局優先）
- 假處分債權人只能另以金錢請求取得名義參與分配；拍賣後**塗銷**假處分查封登記

## 📖 法條原文速查

> **強執 §15**　第三人就執行標的物有**足以排除強制執行之權利**者，得於強制執行程序終結前，向執行法院對債權人提起異議之訴。
> **強執 §18 II**　有回復原狀之聲請，或提起再審或異議之訴……法院因必要情形或依聲請定相當並確實之擔保，得為**停止強制執行**之裁定。（原文請對六法）
> **強執 §47 I**　查封動產，由執行人員實施**占有**。（原文請對六法）
> **強執 §76 I、III**　查封不動產：揭示、封閉、追繳契據；已登記者通知登記機關為查封登記。
> **強執 §12 I**　當事人或利害關係人，對於執行法院強制執行之命令，或對於執行法官、書記官、執達員實施強制執行之方法、強制執行時應遵守之程序，或其他侵害利益之情事，得於強制執行程序終結前，為**聲請或聲明異議**。（原文請對六法）

## 📋 實務見解

> **拆除後建材之執行（法律座談會，請對講義 392 頁）**：乙說（多數）——查封動產與不動產之方法既有不同，查封不動產之效力當然不能變成查封動產之效力；假扣押查封之房屋既經強制執行拆除，標的物**失其存在**，殘餘鋼筋木材已屬**動產**，假扣押債權人如欲就之強制執行，應依**動產查封**方式查封。甲說（肯定得直接拍賣）不採。
> **70 年第 10 次決議**：假處分之效力僅禁止債務人自由處分，不排除法院之強制執行。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「本票裁定查封 A 地後，另一債權人持金錢確定判決聲請執行 A 地？」 | **合併執行程序**（§33） |
| 「A 地已受禁止移轉之假處分，仍屬債務人責任財產？」 | **是**，終局執行得拍賣 |
| 「假處分債權人得以**假處分債權人地位**提第三人異議之訴？」 | **不得**；須主張**所有權**等足以排除強制執行之權利 |
| 「假處分債權人以保全在先為由，對准許終局執行聲明異議？」 | **無理由**，終局優先、程序無瑕疵 |
| 「假扣押之房屋被拆除，殘餘建材得依原查封直接拍賣？」 | **不得**（多數說），須依動產方法**重新查封** |
| 「假處分查封之房屋經他債權人終局拍賣後，假處分查封登記？」 | 應**塗銷** |

## 一、選擇題二的圖

```
債務人乙：A 地
① 甲：假處分「禁止移轉 A 地所有權」＝查封（在先）
② 丙：金錢勝訴確定判決，聲請拍賣 A 地（在後）
      → 查封階段短暫並存，換價時終局優先
甲想阻止丙：
  ✕ §12 聲明異議（程序無瑕疵）
  ✔ 主張 A 地所有權 → §15 第三人異議之訴＋§18 II 停止執行
```

## 二、申論一：房屋 → 建材

```
不動產查封（§76）：房屋 ──拆除──→ 標的物失其存在
                                       ↓
                       鋼筋、木材＝新的動產 → 須重新聲請、依 §47 實施占有查封
                       換價：動產＝拍賣、變賣（不動產＝拍賣、強制管理）
```

- 這題與「假扣押移本案接續執行、不必再查封」相反：標的物已經換了，不能接續。老師：遲早會出選擇題。
