# 強制執行法06 筆記：查封的效力（§51）

## 及於什麼：
- **天然孳息**當然及於（雞蛋、小牛）（§51 I）
- 法定孳息（租金、利息）**不當然**及於 → 屬其他財產權，另對第三人發扣押命令

## 相對無效（§51 II）：
- 查封後債務人之移轉、設定負擔、**其他有礙執行效果之行為**（含出租、物理破壞）→ **對債權人不生效力**
- 債務人與相對人之間**仍有效**
- 能主張的債權人：**個別執行程序終結前**加入者都可以（參與分配、併案皆可，不問在處分行為前後）＝程序相對無效說

## 其他：
- 第三人未經允許占有查封物 → 執行法院得依職權或聲請**排除**（§51 III，不動產準用）
- 查封後第三人**不得主張善意受讓**（執行法多數見解）
- 債務人自救：**拍定前提出現款**，聲請撤銷查封（§58 I）

## 📖 法條原文速查

> **強執 §51**　I 查封之效力及於查封物之**天然孳息**。II 實施查封後，債務人就查封物所為**移轉、設定負擔或其他有礙執行效果之行為**，對於債權人**不生效力**。III 實施查封後，第三人未經執行法院允許，占有查封物或為其他有礙執行效果之行為者，執行法院得**依職權或依聲請排除**之。
> **強執 §58 I**　查封後，債務人得於**拍定前**提出**現款**，聲請撤銷查封。
> **強執 §76 III**　已登記之不動產，執行法院並應先通知登記機關為查封登記，其通知於第一項執行行為實施前**到達**登記機關時，亦發生查封之效力。（筆記 12）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「查封母牛後生下小牛，須另行查封？」 | **不須**，天然孳息當然及之（§51 I） |
| 「查封效力及於法定孳息？」 | **不當然**。租金、利息屬**其他財產權**，另對支付之第三人發扣押命令 |
| 「查封後債務人出租查封之房屋？」 | 有礙執行效果（降低交換價值）→ **對債權人不生效力**（§51 II）；不限處分行為，負擔行為、事實行為均屬之 |
| 「§51 II 之不生效力是絕對或相對？」 | **相對無效**：對執行債權人不生效力；債務人與相對人間**仍有效** |
| 「得主張 §51 II 之債權人範圍？」 | **個別執行程序終結前**聲明參與分配或併案執行者均得主張，**不問**在處分行為前後（程序相對無效說） |
| 「查封後不知情之第三人買受查封動產，得否主張善意受讓？」 | **不得**（執行法多數見解，加強查封效力） |
| 「查封之空屋遭他人占住？」 | 執行法院得**依職權或聲請排除**（§51 III），不必另訴 |
| 「查封後債務人何時前可清償撤銷查封？」 | **拍定前**提出現款（§58 I） |

## 一、108 年考題（講義 227 頁）

```
甲（持對丙金錢確定判決）→ 聲請執行丙之 A 房地
107/5/1 下午  囑託查封登記函送達地政 → 查封效力發生（函到即生效，不待登記完成）
107/5/1 晚上  丙丁簽租期三年租約 → 查封後之有礙執行效果行為
107/5/15     現場查封完成 → 與效力發生無關（以先者為準）
之後         乙（另一金錢債權人）聲請執行同一房地 → §33 併案
併案三個月後 甲乙聲請定拍賣條件，主張丙丁租約違反查封效力
→ 答案 C：甲、乙均得主張租約對其不生效力；丙丁間租約仍有效
→ 拍賣時以「無租約」狀態定拍賣條件
```

## 二、A 車題（講義 229 頁）

```
9/15 上午 10 時  執行人員查封 A 車（實施占有）→ 查封效力發生
               經債權人同意交債務人乙保管
9/15 下午       乙將 A 車賣給不知情之丙，約定翌日過戶
9/16           法院始發函監理機關禁止過戶
```

| 選項 | 判斷 |
|---|---|
| A 禁止過戶函送達監理機關時始生查封效力 | ✗ 查封行為完成即生效；監理登記只是行政作業 |
| B 甲應先訴請丙交還 A 車始能續行執行 | ✗ 無此要求 |
| C 丙受讓 A 車所有權之行為對甲不生效力 | **✓ 答案**（§51 II） |
| D 丙善意受讓取得所有權，不得執行 | ✗ 查封後不得主張善意受讓 |

## 三、§51 II「有礙執行效果之行為」

| 類型 | 例 |
|---|---|
| 處分行為 | 移轉所有權、設定抵押 |
| 負擔行為 | 出租（使用收益沒了，交換價值降低） |
| 事實行為 | 物理破壞（拿鐵鎚敲電視） |
