# 強制執行法09 筆記：分割執行的實務問題與練習

## 分割裁判為何有執行力：
- 分割判決是**形成判決**，原則上形成判決沒有執行力；§131 I 是法律**例外賦予**分割裁判執行力，擴大其實效性（除了取得所有權，還保障取得占有）
- 變價分割判決：變賣**完成後**共有關係才消滅，變賣前尚未消滅

## 點交與拆屋：
- §131 I 分得部分點交＝不動產交付 → 同樣適用 44 台抗 6：地上物可拆（筆記 05）

## 變價分割的特殊處理：
- 應有部分設定抵押權 → **無**拍賣無實益問題，賣一塊錢也照分
- 共有人甲的債權人想執行甲將來分得的價金 → 可請求權以變價分割為條件 → 先核發**附條件扣押命令**，變價後再續行收取等程序
- 拍賣**可拍至拍定為止**：沒有四拍未拍定發債權憑證的問題，所以實務有第六、七拍；怕賤賣，共有人可聲明承受
- 共有人皆有**應買權**（形式上列為債務人，但各共有人地位相同、非對立）
- 第三人拍定後，共有人仍得主張**優先承買權**；二人以上願優先承買 → **抽籤**定之（民法 §824 VII）

## 📖 法條原文速查

> **強執 §131**　I 關於繼承財產或共有物分割之裁判，執行法院得將各繼承人或共有人分得部分點交之；其應以金錢補償者，並得對於補償義務人之財產執行。II 執行名義係變賣繼承財產或共有物，以價金分配於各繼承人或各共有人者，執行法院得予以拍賣，並分配其價金，其拍賣程序，準用關於動產或不動產之規定。
> **民法 §824 VII**　變價分配之執行，共有人有依相同條件**優先承買**之權，有二人以上願優先承買者，以**抽籤**定之。
> **強執 §127 I**　依執行名義，債務人應為一定行為而不為者，執行法院得以債務人之費用，命第三人代為履行。
（條文原文請對六法）

## 📋 實務見解

> **分割裁判之執行力**：§131 規定執行法院得將分得部分點交，係法律規定賦予分割裁判執行力，以擴大分割裁判之實效性。（出處請對講義 361 頁）

> **將來分得價金之執行**：甲之債權人於變價分割未拍定前聲請執行甲將來分得之價金，其請求權內容及數額以系爭共有物變價分割為條件，執行法院只能先核發**附條件之扣押命令**，待變價完畢再視情形續行。（出處請對講義 362～364 頁）

> **拍賣次數**：變價分割執行，四拍未拍定無發債權憑證問題，故可減價拍賣至賣出為止；共有人認有賤賣之虞，可依法聲明承受。（出處請對講義 364 頁）

> **共有人應買權**：變價分割判決賦予各共有人變賣共有物分配價金之權利，各共有人地位相同、非互相對立；聲請人以外之共有人雖於執行法上列為債務人，僅屬形式，各共有人均有應買權；第三人拍定後，共有人仍得主張優先承買。（出處請對講義 364 頁後）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「分割共有物判決為形成判決，有無執行力？」 | **有**，§131 例外賦予 |
| 「變價分割判決確定，共有關係即消滅？」 | **否**，變賣完成後才消滅 |
| 「變價分割得拍賣幾次？」 | **至拍定為止**，無四拍限制 |
| 「共有人之債權人執行其將來分得價金？」 | 核發**附條件扣押命令** |
| 「二共有人均願優先承買，按應有部分比例取得？」 | **錯**，以**抽籤**定之（民法 §824 VII） |
| 「判決原物分割，他共有人不配合分割登記，得聲請執行協同登記？」 | **不必**，單獨持判決辦理登記 |
| 「判決原物分割，分得部分由他共有人占有？」 | 得以判決聲請**點交**，排除其占有（§131 I 前段） |
| 「訴請拆除鄰人招牌勝訴，如何執行？」 | **可代替行為**（§127） |

## 一、練習：甲乙丙共有 A 地各 1/3，甲乙訴請裁判分割（講義 364 頁後）

| 選項 | 判斷 | 理由 |
|---|---|---|
| A 變價分割確定，僅甲得聲請執行 | 錯 | 甲乙丙**都可以** |
| B 甲乙均願優先承買，按應有部分比例承買 | 錯 | 二人以上 → **抽籤** |
| C 原物分割確定，乙丙不配合登記，甲得聲請執行協同登記 | 錯 | 單獨持判決登記，不必執行 |
| **D 原物分割確定，甲分得部分為丙占有，甲得聲請排除丙之占有** | **正確** | §131 I 點交 |

- 登記不用執行；點交是要拿到現實占有。占有人很配合就不必聲請點交，有需要再來。變價分割則一定要聲請拍賣。

## 二、練習：兄弟比鄰而居（甲乙）

```
① 甲訴請排除侵害，判決命乙拆除屋外招牌
   → 拆招牌＝可代替行為 → §127（台北地院：以債務人費用命第三人代為履行）
② 另案請求分割遺產，判決甲分得 A 地特定部分（原物分割），由高雄地院執行
   → 得聲請點交 → §131 I 前段
   → 辦登記則單獨持判決向地政機關申請；執行法院不是地政機關，只管點交
```

## 三、變價分割 vs 一般金錢債權拍賣

| | 一般金錢債權執行 | 變價分割執行 |
|---|---|---|
| 聲請人 | 債權人 | 任一共有人 |
| 債務人應買 | 不得（§70 VI） | 共有人皆得應買 |
| 無益執行 | 禁止（§80-1） | 不適用 |
| 拍賣次數 | 三拍、特別變賣、四拍後發債權憑證 | 拍至拍定為止 |
| 優先承買 | — | 共有人有，二人以上抽籤 |
