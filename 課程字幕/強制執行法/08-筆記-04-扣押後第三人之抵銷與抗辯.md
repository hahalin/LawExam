# 強制執行法08 筆記：扣押後第三人之抵銷與抗辯

## 契約終止、解除權：
- 扣押命令生效後，第三人依契約原本可行使的權利**不受影響**
- 例：扣押保單價值準備金，債務人欠繳數期保費 → 保險公司仍得依約**終止**保險契約

## 扣押前已簽發的支票：
- 扣押命令生效**前**，第三人為清償被扣押債權已簽發支票（未經提示）→ 扣押效力**不及**於該支票
- 理由：保障未禁止背書轉讓支票之交易安全；第三人於命令送達後仍應清償票據債務

## 抵銷：
- 第三人於扣押**前**已取得對債務人之債權（得抵銷狀態但尚未主張）→ 扣押後**仍得抵銷**（衡平原則）
- 扣押**後**才取得之債權 → **不得**抵銷（防止創造新債權規避扣押）

## 其他抗辯：
- 扣押時第三人得對抗債務人的一切實體抗辯（時效抗辯等），均得對抗執行債權人

## 📖 法條原文速查

> **強執 §115 I**　……執行法院應發扣押命令禁止債務人收取或為其他處分，並禁止第三人向債務人清償。
> **民法 §340**　受債權扣押命令之第三債務人，於扣押後，始對其債權人取得債權者，不得以其所取得之債權與受扣押之債權為抵銷。
（民法 §340 字幕未唸條號，請對六法）

## 📋 實務見解

> **最高法院 100 年判決**（字號請對講義）：第三人於收受扣押命令時，所簽發支票未經提示，債務人對第三人尚有買賣價金債權存在；為保障**無禁止背書轉讓支票**之交易安全，第三人讓支票兌現，非 §115 扣押命令效力所及，第三人於扣押命令送達後，應就所負票據債務為清償。

> **抵銷之實務見解**（出處請對講義）：基於衡平原則，受扣押命令之第三債務人於**扣押前**對其債權人取得債權者，其得行使之抵銷權不宜因此受影響；**扣押後**始取得債權者，不得主張抵銷，以防止第三人隨時創造新債權尋求抵銷途徑，使扣押效力歸於消滅。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「扣押保單價值準備金後，保險公司不得再以欠繳保費終止契約？」 | **錯**。第三人契約上的終止、解除權不受扣押拘束 |
| 「扣押前已開立、未兌現的支票，扣押效力及之？」 | **不及**，第三人仍應兌現（保障票據交易安全） |
| 「銀行於扣押前已對乙有 30 萬貸款債權，收到扣押命令後得抵銷？」 | **得**（考過，筆記 11 第三題 D 選項） |
| 「第三人於扣押**後**才取得對債務人之債權，得抵銷？」 | **不得**（民法 §340 意旨） |
| 「第三人得以對債務人之抗辯對抗執行債權人？」 | **得**，扣押不改變乙丙間實體法律關係 |

## 一、判斷順序：看「扣押前」或「扣押後」

```
第三人（丙）可主張的事由
├─ 扣押前已存在
│   ├─ 契約終止、解除權 → 仍得行使
│   ├─ 已簽發之支票 → 扣押效力不及，照常兌現
│   ├─ 已取得之反對債權 → 仍得抵銷
│   └─ 時效等實體抗辯 → 得對抗執行債權人
└─ 扣押後才取得之債權 → 不得抵銷（先來後到；否則等於取得優先受償地位）
```

## 二、抵銷的實例

```
乙在丙銀行存款（乙對丙之存款債權）＝被動債權，被甲扣押
丙銀行對乙有貸款債權（扣押前已取得、已屆清償期、尚未主張抵銷）＝主動債權
→ 甲聲請扣押後，丙仍得以貸款債權抵銷存款債權
→ 理由：丙是無辜的第三人，本來就處於得抵銷狀態
```

- 若丙已在扣押前主張抵銷，存款債權早已消滅，根本沒有東西可扣。
- 字幕把「抵銷權」誤聽成「抵押權」（00:31:08 附近），依文意更正。
