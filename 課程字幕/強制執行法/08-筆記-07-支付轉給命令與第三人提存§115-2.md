# 強制執行法08 筆記：支付轉給命令與第三人提存（§115-2）

## 支付轉給命令：
- **間接收取**：丙先把錢付給執行法院，由法院計算後轉給債權人；性質與收取命令同
- 多用於**債權人多數**、需要統籌分配的情形
- 清償效力：於執行法院**轉給**的債權金額限度內；執行程序於轉給債權人時終結
- 拍賣、變賣（§115 III）：直接把債權賣掉，考試少考

## 第三人提存（§115-2 I）：
- 執行法院發換價命令（§115 II）**前**，第三人得將全額或扣押部分**提存**於清償地提存所
- 性質：**清償提存**；目的：免除第三人遲延責任

## 第三人收到兩份扣押命令（§115-2 II）：
- 換價命令辦理前又收受扣押命令，扣押金額超過未受扣押部分 → 應將債權**全額**支付**扣押在先**之執行法院（之後由法院作分配表）
- 提存或支付後，應向執行法院陳明事由（§115-2 III）

## 📖 法條原文速查

> **強執 §115 II 後段**　如認為適當時，得命第三人向執行法院**支付轉給**債權人。
> **強執 §115-2**　I 第三人於執行法院發第一百十五條第二項命令**前**，得將對債務人之金錢債權全額或扣押部分**提存**於清償地之提存所。II 第三人於依執行法院許債權人收取或向執行法院支付轉給債權人之命令辦理前，又收受扣押命令，而其扣押之金額超過債務人之金錢債權未受扣押部分者，應即將該債權之**全額**支付**扣押在先之執行法院**。III 第三人已為提存或支付時，應向執行法院陳明其事由。
（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「支付轉給命令，執行程序何時終結？」 | 執行法院**轉給債權人**時；轉給金額限度內債權消滅 |
| 「支付轉給命令的性質？」 | 間接收取，與收取命令**同類**（非債權讓與） |
| 「支付轉給命令核發後第三人不付款，得逕向第三人執行？」 | **得**（未聲明異議時，§119 II） |
| 「第三人何時得提存？」 | 執行法院發 **§115 II 換價命令前** |
| 「§115-2 提存的性質與目的？」 | **清償提存**，免除第三人遲延責任 |
| 「第三人收到兩個扣押命令且不足清償？」 | 全額支付**扣押在先**之執行法院 |

## 一、三種換價命令定位

```
§115 II
├─ 收取命令 ── 甲直接向丙收 ─────────┐ 代位收取類
├─ 支付轉給 ── 丙 → 法院 → 甲（多數債權人）┘ 實際拿到才清償
└─ 移轉命令 ── 債權讓與，生效即清償、程序終結
§115 III 拍賣／變賣（難以依 II 辦理時）
```

## 二、§115-2 的兩種情境

| 情境 | 第三人怎麼做 | 理由 |
|---|---|---|
| 被扣押、但換價命令還沒來，債務已屆期 | 得**提存**全額或扣押部分（I） | 不能付給乙又不能付給甲，避免遲延責任 |
| 換價命令辦理前又收到第二份扣押命令，金額不夠 | 應**全額**支付扣押在先之法院（II） | 程序上先集中，再由法院作分配表 |
