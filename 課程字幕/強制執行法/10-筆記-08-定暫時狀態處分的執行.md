# 強制執行法10 筆記：定暫時狀態處分的執行

## 執行方式依內容而定：
- 命金錢給付（扶養費、薪資）→ 金錢請求權執行；容忍、禁止 → 行為不行為執行（§140 準用）
- 保全執行這一章是前面各種執行方法的「集大成」

## 櫃位案（行為不行為）：
- 承租人取得「得繼續經營使用櫃位」之定暫時狀態處分，出租人另設木板門封櫃
- 執行法院依 §140 準用 §129，核發**自動履行命令**，命債務人 **3 日內**拆除木板門、回復原狀

## 禁止行使董事職權（94 年實務）：
- 屬命令或禁止債務人為一定行為 → 依 **§138 送達**債務人
- 效力始於債務人**收受裁定時**；一經生效即發生禁止之**形成效果**，**無**其他強制執行問題
- 學說補充：債務人**違反**仍行使職權 → 債權人得聲請**處怠金**；與實務不衝突，兩者並行

## 暫定受僱人地位（確認性假處分）：
- 本案確認僱傭關係存在；處分內容只是暫定受僱人地位、無給付內容
- 仍須**聲請執行**，由**執行處**依 §138 送達裁定，裁定才發生效力；送達後執行程序即**終結**

## 抗告廢棄後返還給付：
- 由**抗告法院**依抗告人聲請，同時命聲請人返還所受領之給付（民訴 §538-2）——**不是執行法院**

> 來源：強制執行法10 課程字幕 01:19:29 ~ 01:40:33（講義 382～384 頁）

## 📖 法條原文速查

> **強執 §129**　I 執行名義係命債務人**容忍**他人之行為，或**禁止**債務人為一定之行為者，債務人不履行時，執行法院得拘提、管收之或處新臺幣三萬元以上三十萬元以下之**怠金**。其仍不履行者，得再處怠金或管收之。II 前項情形，於必要時，並得因債權人之聲請，以債務人之費用，**除去其行為之結果**。（原文請對六法）
> **強執 §138**　假處分裁定，係命令或禁止債務人為一定行為者，執行法院應將該裁定**送達**於債務人。
> **強執 §140**　假處分之執行，除前三條規定外，準用關於假扣押、金錢請求權及行為、不行為請求權執行之規定。
> **民訴 §538-2 I**　**抗告法院**廢棄或變更第五百三十八條第三項之裁定時，應依抗告人之聲請，在廢棄或變更範圍內，同時命聲請人**返還其所受領之給付**。其給付為金錢者，並應依聲請附加自受領時起之利息。（原文請對六法）

## 📋 實務見解

> **櫃位案**（字號請對講義 382 頁附近）：債務人另設木板門阻礙債權人經營使用系爭櫃位，執行法院依 §140 準用 §129 I（字幕所唸，除去行為結果規定在 §129 II，請對講義），核發自動履行命令，命債務人於 3 日內拆除並回復原狀。
> **94 年禁止行使董事職權**（字號請對講義 383 頁附近）：假處分裁定係命令或禁止債務人為一定行為者，執行法院應將該裁定送達債務人，目的在使債務人知悉而能自動履行；該處分效力始於債務人收受裁定之時，一旦發生效力即發生命令或禁止之形成效果，自無強制執行之問題。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「禁止行使董事職權之定暫時狀態處分，如何執行？」 | 執行法院**送達**裁定（§138），收受時生效 |
| 「該處分生效後債務人仍行使職權？」 | 得聲請**處怠金**（學說補充，與實務並行） |
| 「暫定受僱人地位之處分，無給付內容，不必聲請執行？」 | **錯**。仍須聲請，由執行處送達裁定才生效；送達後程序終結 |
| 「§138 的裁定由誰送達？」 | **執行處（執行法院）** |
| 「定暫時狀態處分經抗告廢棄確定，**執行法院**依聲請命返還所受領給付？」 | **錯**。是**抗告法院**（民訴 §538-2） |
| 「容忍通行之處分，債務人設圍牆妨礙？」 | 得聲請除去行為結果（準用 §129） |

## 一、練習題：容忍甲通行 A 地（選錯的）

| 選項 | 判斷 | 理由 |
|---|---|---|
| A 執行法院應將系爭處分送達於乙 | 正確 | §138 |
| B 乙收受處分 30 日後才開始妨礙，甲仍得聲請執行 | 正確 | 「容忍」＝不作為，未違反無執行問題，不受 30 日限制（筆記 06） |
| C 乙設圍牆妨礙通行，甲得聲請除去 | 正確 | 準用 §129 除去行為結果 |
| D 處分經乙抗告廢棄確定，**執行法院**依乙聲請命甲返還通行利益 | **錯誤（答案）** | 應為**抗告法院**（民訴 §538-2）；執行處不審判、不作執行名義 |

- 老師：A、B、C 很明顯，D 很細，用刪去法。

## 二、執行處的角色

```
執行名義有效 → 依內容執行（送達、怠金、除去、金錢執行）
執行名義被廢棄 → 撤銷執行處分（§132-1）、終結程序
要對方「返還」什麼 → 不是執行處的事 → 抗告法院、訴訟法院、非訟法院
```
