# 強制執行法05 筆記：§15 的時點與裁判——最晚於**該標的物（個別）執行程序終結前**起訴（考過 N＋1 次）：A 地、B 車各有自己的查封→換價→滿足，第三人主張 A 地是他的，就要在 A 地做完之前告；**院 2776**：執行標的物經**拍賣終結而未將賣得價金交付債權人**（＝滿足階段）時，該標的物之執行程序尚未終結，第三人**仍得**提 §15，**但**已終結之拍賣程序不能以異議之訴有理由之判決撤銷 → 第三人**僅得請求交付賣得價金，不得請求撤銷拍賣程序**（保護拍定人：動產善意受讓、不動產土地法 §43 登記絕對效力，第三人已喪失所有權）；個別程序終結後 → 不能提 §15（形成之訴已無排除對象），另訴救濟（§179、§184、國賠）；**訴訟標的價額**（91 年第 5 次決議）：標的物價值低於執行名義債權額時，以**標的物價值**為準 → 兩者取**低者**；**裁判**：不合法裁定駁回、無理由判決駁回、有理由判決**不許對該特定財產**為強制執行（鎖定標的物，與 §14 全面否定執行名義不同）；判決**非當然使執行處分失效**，原告應將判決正本**提出於執行法院**，執行處始停止執行、撤銷已為之執行處分

> 來源：強制執行法05 課程字幕 00:07:00 ~ 00:21:45（講義 167～169 頁；院 2776 倒數第四行起）

## 📖 法條原文速查

> **強執 §15**　……得於強制執行程序終結前……（指個別標的物之執行程序）
> **土地法 §43**　依本法所為之登記，有絕對效力。
> **強執 §98 I**　拍賣之不動產，買受人自領得執行法院所發給權利移轉證書之日起，取得該不動產所有權……

## 📋 實務見解速查

> **司法院院字第 2776 號解釋**（講義 167 頁；字幕「33 年雲字」應為「院字」）：……故執行標的物經拍賣終結而未將其賣得價金交付債權人時，對於該執行標的物之強制執行程序不得謂已終結，第三人仍得提起異議之訴，但已終結之拍賣程序不能依異議之訴有理由之判決予以撤銷，故該第三人僅得請求交付賣得價金，不得請求撤銷拍賣程序。
> **91 年第 5 次民事庭決議**（講義 168 頁）：第三人異議之訴訴訟標的價額……執行標的物之價值若低於執行名義所載債權額時，因其訴訟標的所有之利益僅為標的物不受強制執行，訴訟標的價額應以標的物價值為準。（字號請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§15 最晚何時提起？」 | 該**標的物**（個別）執行程序終結前，不是整個。A 地、B 車各自有查封換價滿足，主張 A 地是我的就要在 A 地做完前告 |
| 「A 地已拍定、價金尚未分配，第三人得否提 §15？結果？」 | **得**（院 2776：賣得價金未交付債權人，該標的物之執行程序未終結）。但不能撤銷已終結之拍賣（保護拍定人），**僅得請求交付賣得價金**，不得請求返還原物 |
| 「為何不能撤銷拍賣？」 | 拍定人信賴法院拍賣程序；動產善意受讓、不動產土地法 §43 登記絕對效力 → 第三人已喪失所有權，不得再主張拍賣無效請求回復 |
| 「該標的物執行程序已終結（價金分完）？」 | **不得**提 §15（形成之訴已無執行程序可排除）→ 另訴：§179 不當得利、§184 侵權行為、國家賠償 |
| 「§15 訴訟標的價額如何核定？」 | 債權額與執行標的物價值**取低者**（91 年第 5 次決議）。利益僅在標的物不受執行，不會多收裁判費 |
| 「§15 有理由之判決效果？」 | 判決**不許對該特定財產**強制執行（鎖定標的物；§14 是全面否定執行名義）；**非當然**使執行處分失效，原告應將判決正本**提出於執行法院**（民事庭和執行處是兩個單位，執行處不知道民事庭判了什麼）→ 執行處才停止執行、撤銷執行處分 |

## 一、時間軸

```
A 地：查封 ──→ 換價（拍定）──→ 滿足（價金分配）──→ 終結
      ✓ 可提 §15      ✓ 仍可提，但只能要價金、不能撤銷拍賣   ✗ 另訴
```

- 執行處各財產的程序可能時間重疊、快慢不一；圖示只是概念。

## 二、聲明異議 vs 異議之訴（講義 169 頁比較表）

| | §12 聲明異議 | §14／§15 異議之訴 |
|---|---|---|
| 性質 | **程序**瑕疵（對執行程序不服） | **實體**瑕疵 |
| 管轄 | 執行處（內部處理） | 民事庭（起訴） |
| 停止執行 | **不停止** | **得**為 §18 II 停止執行事由（法院裁量，不是起訴就當然停止） |
| 時點 | 看異議內容：針對標的物 → 標的物終結前；針對整個執行名義 → 整個終結前 | §14 整個終結前；§15 個別終結前 |

- 選項寫「起訴就一定停止執行」→ 錯。
