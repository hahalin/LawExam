# 強制執行法04 筆記：聲明異議的最晚時點——「執行程序終結前」是整個還是個別，看異議內容（院字 2776）：針對執行名義本身（拿白紙執行）→ **整個**執行程序終結前；針對個別執行標的物（牙醫設備為禁止查封物）→ 該**標的物**之執行程序終結前；已終結之執行處分**無從撤銷**：拍賣程序終結＝買賣契約履行完畢（動產交付買受人／不動產領得權利移轉證書 §98 I）→ 保護善意買受人，之後只能就分配程序（價金）異議；「執行程序跑得快」：聲明異議雖在終結前提起，執行法院或抗告法院裁判時執行程序已終結者，應駁回

## 📖 法條原文速查

> **強執 §12 I**　……得於**強制執行程序終結前**，為聲請或聲明異議。但強制執行不因而停止。
> **強執 §53 I ⑤**（禁止查封之動產）債務人職業上或教育上所必需之器具、物品。（款次請對六法）
> **強執 §98 I**　拍賣之不動產，買受人自領得執行法院所發給權利移轉證書之日起，取得該不動產所有權。
> **強執 §124 I**（不動產之物之交付執行）執行名義係命債務人交出不動產而不交出者，執行法院得解除債務人之占有，使歸債權人占有。（原文請對六法）

## 📋 實務見解速查

> **司法院院字第 2776 號解釋**（執行法第一有名）要旨：§12 I 的「執行程序終結」要依聲請或聲明異議的**內容**分別認定。動產已終結、不動產未終結時，債務人主張拍賣之動產為禁止查封物而異議者，終結指該**標的物**的執行程序終結；債務人主張執行名義（公證書）不具要件者，終結指**執行名義**的執行程序終結。但後者即使異議有理由，也只能撤銷對不動產的執行處分，動產部分既已終結即無從撤銷。另：聲明異議雖在終結前提起，執行法院或抗告法院裁判時執行程序已終結者，撤銷更正之裁定已無從執行，得以此駁回。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§12『執行程序終結前』指整個還是個別？」 | **看異議內容**：異議針對**執行名義本身**（未確定支付命令、公證書不具要件＝白紙）→ 整個執行程序終結前；針對**個別標的物**（某動產為禁止查封物）→ 該標的物之執行程序終結前 |
| 「牙醫題：甲查封乙之醫療設備及房屋，設備已拍賣、價金已由甲受償，房屋拍賣中；乙主張設備為職業上所必需（§53）拍賣違法，得否聲明異議？」 | 主張正確（職業上必需＝禁止查封＝程序瑕疵），但設備之執行程序（查封→換價→滿足）**已終結** → 無救濟對象 → **不得**（答案 D）。只能另訴 |
| 「拍賣程序何時終結？」 | 動產：執行法院將拍賣物**交付買受人**時；不動產：買受人**領得權利移轉證書**時（§98 I，取得所有權，非登記時）。記法：**買賣契約履行完畢**——拍定＝契約成立，買受人繳足價金、法院交付標的物或發給證書＝履約完畢 |
| 「拍賣程序已終結但價金尚未交付債權人，債務人聲明異議？」 | 標的物執行程序尚未終結（還在滿足／分配階段），但**不得對已終結之拍賣程序聲明異議**，僅得對**分配程序**（價金）異議——買受人已取得所有權，不得再撤銷拍賣以保護**善意買受人** |
| 「聲明異議後抗告中，執行程序先終結，抗告法院如何處理？」 | **駁回**（院 2776）。聲明異議與抗告都不停止執行，執行程序跑得快，裁判時已無執行程序可撤銷更正 |
| 「遷讓房屋確定判決執行，債務人對執行命令聲明異議遭駁回後抗告；高院裁定前執行處已解除債務人占有使歸債權人占有？」 | 解除占有＝§124 不動產物之交付執行程序**終結** → 抗告法院只能**駁回** |
| 「違法執行行為未經救濟？」 | 程序**有效**。有意見要提出來 |

## 一、整個 vs 個別（院 2776 的表格）

| 異議事由內容 | 「終結前」指 | 例 |
|---|---|---|
| 針對執行名義本身（連根拔起） | 執行名義之執行程序＝**整個** | 未確定支付命令、公證書不具要件 |
| 針對個別執行標的物 | 該標的物之執行程序＝**個別** | 牙醫設備為禁止查封物 |

## 二、金錢債權執行三階段與終結

```
查封 → 換價（拍賣）→ 滿足（分配價金）
拍賣程序終結 ＝ 換價階段做完 ＝ 買受人繳錢、法院交付（動產）／發權利移轉證書（不動產 §98 I）
→ 善意買受人取得所有權，永遠最受保護，不得再撤銷拍賣
→ 之後債務人只能就分配程序（價金）主張
```

- 執行處不會讓買受人欠錢：一定先收錢再交東西。
- 不動產拍定人取得所有權的時點是**領得權利移轉證書**，是民法物權編登記生效的特別規定。

## 三、兩個「已終結就沒救」

| 情形 | 結論 |
|---|---|
| 已終結之執行處分 | 無從撤銷或更正（§12 有理由也只能撤銷未終結部分） |
| 執行程序跑得快：裁判時已終結 | 執行法院或抗告法院駁回聲明異議 |

```
聲明異議 ──→ 裁定 ──→ 抗告 ──→（審理中）
執行程序 查封 → 換價 → 滿足 ──→ 終結 ← 比抗告審完更早
→ 救濟對象消失 → 駁回。因為聲明異議、抗告都不停止執行（異議之訴才能 §18 II）
```

## 四、牙醫題拆解

```
甲查封乙（牙醫）的 ① 醫療設備 ② 房屋
① 已拍賣、價金由甲受償 → 查封換價滿足都做完 → 設備之執行程序終結
② 拍賣中 → 整個程序未終結
乙：設備為職業上所必需（§53 禁止查封）→ 程序瑕疵，救濟方式聲明異議 ✓
但針對個別標的物 → 時點是設備之執行程序終結前 → 已終結 → 不得救濟 → 答案 D
```
