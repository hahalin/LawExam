# 強制執行法07 筆記：查封效力範圍與增建併付拍賣

## 不動產查封的效力：
- 不動產本節沒規定 → §113 準用動產 → **§51 II**：查封後債務人之移轉、設定負擔或其他有礙執行效果之行為，對債權人**不生效力**
- 查封後不能出租、不能處分、也不能做減少價值的事實行為；是否「有礙執行效果」個案認定
- 債務人只喪失**處分權**，所有權仍屬債務人

## 查封效力的客觀範圍（實行抵押權時）：
- 強執法沒有明文 → **查封效力所及＝抵押權效力所及**，完全用民法判斷
- 抵押權及於從物、從權利（民法 §862 I）；建築物上**附加而不具獨立性**之部分亦及之（§862 III）
- 判斷關鍵：構造上、使用上有無**獨立性**（有沒有獨立出入口）

## 併付拍賣：
- 抵押**設定後**在抵押土地上營造的建物 → 抵押權人得聲請併付拍賣（民法 §877）
- 抵押**設定前**已存在的建物 → **不得**併付拍賣

## 📖 法條原文速查

> **強執 §51 II**　實施查封後，債務人就查封物所為**移轉、設定負擔或其他有礙執行效果**之行為，對於債權人**不生效力**。
> **強執 §113**　不動產之強制執行，除本節有規定外，**準用關於動產執行之規定**。
> **民法 §862**　I 抵押權之效力，及於抵押物之**從物與從權利**。……III 以建築物為抵押者，其附加於該建築物而**不具獨立性**之部分，亦為抵押權效力所及。但其附加部分為獨立之物，如係於抵押權設定後附加者，準用第八百七十七條之規定。
> **民法 §877 I**　土地所有人於設定抵押權**後**，在抵押之土地上營造建築物者，抵押權人於必要時，得於強制執行程序中聲請法院將其建築物與土地**併付拍賣**。但對於建築物之價金，無優先受償之權。
> **民法 §68**　I 非主物之成分，常助主物之效用，而同屬於一人者，為從物。……II 主物之處分，及於從物。
（§862 III 但書、§877 原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「查封後債務人將房屋出租，效力？」 | 對債權人**不生效力**（§113 準用 §51 II）；債務人仍是所有人，只是喪失處分權 |
| 「實行抵押權查封 A 屋，效力是否及於增建？」 | 看**抵押權效力所及範圍**——強執法沒規定，回民法 §862 |
| 「頂樓加蓋須經 A 屋大門出入？」 | 不具獨立性 → **及於**（§862 III） |
| 「廚房外推、打掉原牆向外延伸？」 | 不具獨立性 → **及於** |
| 「抵押設定後在空地另蓋、有獨立出入口的建物？」 | 有獨立性 → **不及於**（是否併付拍賣另依 §877 判斷） |
| 「抵押設定**前**已蓋好的未保存登記建物，得否併付拍賣？」 | **不得**；§877 限設定**後**營造者 |

## 一、103 年選擇題（講義 250 頁）

```
債務人以 A 屋＋B 地設定抵押（共同擔保）→ 拍賣抵押物裁定（§4 I ⑤）→ 查封 A 屋
問：查封 A 屋之效力是否及於 C、D、E？F 得否併付拍賣？

C 頂樓增建閣樓，須經 A 屋大門出入   → 無獨立性 → 及於
D 廚房敲牆向外搭建（外推）         → 無獨立性 → 及於
E 設定抵押後在 B 空地另建，有獨立出入口 → 有獨立性 → 不及於
F 設定抵押前在 B 地已建之二層房屋    → 非設定後營造 → 不得併付拍賣（§877）
```

- 審題時把「設定抵押**後**／**前**」圈起來——時間點決定 §877 能不能用。
- 老師提醒：強執法選擇題常常是在考民法，物權篇的規則直接拿來用。

## 二、判斷流程

```
查封標的上有附加物
   ↓
構造上、使用上有獨立性嗎？（獨立出入口？）
   ├─ 無 → 附屬於原建物 → 抵押權（＝查封）效力所及
   └─ 有 → 獨立之物 → 不及於
            └─ 是抵押設定後在抵押土地上蓋的？
                 ├─ 是 → 得聲請併付拍賣（§877），但對建物價金無優先受償權
                 └─ 否 → 不得併付拍賣
```
