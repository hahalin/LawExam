# 強制執行法02 筆記：外國確定判決（§4-1）

## 三要件：
- 外國法院**確定**判決（且須為**給付**判決，有命給付內容）
- 無民訴 **§402 I 各款**情形（無管轄權、敗訴被告未應訴、違背公序良俗、無相互承認）
- 經我國法院（**民事庭**）以**判決宣示許可執行**，該許可判決也要確定

## 執行名義是什麼：
- **結合說**：外國確定判決＋我國許可執行判決，兩者都要，任一失效即不能執行

## 最常考 §402 I ②：
- 敗訴被告**未應訴** → 原則不承認（保護多半是臺灣人的被告）
- 但書：開始訴訟之通知或命令（開庭通知）已於相當時期在該國**合法送達**，或依我國法律上**協助送達** → 仍承認、可執行
- 債務人在我國**有無財產**，從來不是考慮因素
- 外國仲裁判斷：同樣須經我國法院裁定承認

## 📖 法條原文速查

> **強執 §4-1 I**　依外國法院確定判決聲請強制執行者，以該判決無**民事訴訟法第四百零二條**各款情形之一，並經中華民國法院以**判決宣示許可其執行**者為限，得為強制執行。（原文請對六法）
> **民訴 §402 I**　外國法院之確定判決，有下列各款情形之一者，**不認其效力**：
> 一、依中華民國之法律，外國法院無管轄權者。
> 二、**敗訴之被告未應訴者**。但開始訴訟之通知或命令已於相當時期在該國**合法送達**，或依中華民國法律上之**協助送達**者，不在此限。
> 三、判決之內容或訴訟程序，有背中華民國之公共秩序或善良風俗者。
> 四、無相互之承認者。
> **強執 §128 II**　（命履行夫妻同居義務之判決不得強制執行）（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「外國確定判決得逕為執行名義？」 | **不得**，須我國法院**判決宣示許可執行** |
| 「依外國判決聲請執行，執行名義為何？」 | **結合說**：外國確定判決＋我國許可執行判決 |
| 「臺灣被告未出庭被判敗訴，我國一律不承認？」 | **否**：開庭通知已合法送達或經我國協助送達 → 仍承認、可執行 |
| 「准否許可執行，下列何者**不需**考慮？」 | **債務人在我國有無財產**（果凍題答案 B） |
| 「互惠原則（無相互承認）實務寬嚴？」 | 從**寬**，對方不明顯否認即可 |
| 「§4 I ① 之確定終局判決指？」 | **給付判決**；確認、形成判決不能執行（分割判決另論） |
| 「命履行夫妻同居義務之判決得強制執行？」 | **不得**（§128 II，性質上不適於強制執行） |

## 一、外國判決執行流程

```
外國確定給付判決
      │
      ▼
我國民事庭：許可執行之訴（審 §402 I 四款地雷）
      │ 判決宣示許可執行 → 確定
      ▼
執行處：外國判決＋許可判決（結合說）→ 開始強制執行
```

## 二、§402 I ② 判斷

```
敗訴被告有無應訴（出庭）？
├── 有 → 不涉本款
└── 未應訴
     ├── 開庭通知於相當時期在該國合法送達 ──┐
     ├── 或依我國法律上協助送達 ────────────┤→ 不在此限：承認、可執行（自己不去，自負後果）
     └── 都沒有 → 不承認、不可執行（欠缺程序保障）
```

## 三、果凍題（考古題）

```
我國甲公司出口果凍至美國，標示不明致美國籍幼童受害
美國法院判甲公司賠償 5,000 萬美元（甲公司未出庭應訊），確定
債權人來臺請求承認並執行 → 應考慮的因素中「不包含」何者？
A 判決內容與訴訟程序是否有背公序良俗        → 要考慮（③）
B 甲公司在我國境內是否有財產可供執行        → 不考慮 ★答案
C 我國與美國有無相互承認                    → 要考慮（④）
D 開始訴訟之通知是否合法送達或經協助送達    → 要考慮（②但書）
```

- 老師：債務人有沒有錢從來不是執行要件；沒錢也會聲請執行來**中斷時效**。

## 四、同頁立體演練：§4 I ①

| 判決種類 | 可否為執行名義 |
|---|---|
| 給付判決 | ✓ |
| 確認判決、形成判決 | ✗（分割判決例外可執行，有限制） |
| 命履行夫妻同居義務 | ✗（雖是給付，§128 II 不適於執行） |
