# 強制執行法08 筆記：扣押命令生效與客觀範圍（§118）

## 生效時點（§118）：
- 執行命令**應送達債務人及第三人**（乙丙都寄），送達後通知債權人
- **送達第三人時**生效；無第三人者送達債務人時生效
- 送達前已為扣押登記（商標、專利等）→ **登記時**生效；與送達以先者為準（同 §76 不動產查封）

## 客觀範圍（存款）：
- 以扣押命令**到達第三人當時**的存款為準，於命令所載金額範圍內扣押
- **扣押後才存入的款項不及**（存款不是繼續性給付債權，沒有向後效力）→ 只能聲請另發扣押命令
- 到達時帳戶內的本金＋已入帳利息全部及之；扣押後才產生的**法定孳息（利息）不及**
- 存款不足命令所載金額 → 銀行 **10 日內**書狀聲明異議，陳報實際扣押金額（§119 I）

## 📖 法條原文速查

> **強執 §118**　I 第一百十五條、第一百十五條之一、第一百十六條、第一百十六條之一及前條之執行命令，應**送達於債務人及第三人**，已為送達後，應通知債權人。II 前項命令，**送達於第三人時發生效力**，無第三人者，送達於債務人時發生效力。但送達前已為扣押登記者，於**登記時**發生效力。
> **強執 §51 I**　查封之效力及於查封物之**天然孳息**。
（原文請對六法）

## 📋 實務見解

> **銀行公會函**（字號請對講義 296 頁）：金錢寄託為要物契約，存款人須現實存入金錢才取得返還請求權；扣押時存款不足債權金額者，**扣押後繼續存入之款項非扣押效力所及**，銀行對之不予繼續扣押；扣押時存款不足者，銀行應於收受命令後十日內具狀聲明異議，陳報實際扣押金額。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「扣押命令何時發生效力？」 | **送達第三人時**（§118 II），不是送達債務人時 |
| 「扣押命令要送達給誰？」 | 債務人**及**第三人都要送達，送達後通知債權人 |
| 「已辦扣押登記之權利？」 | 送達前已登記者，**登記時**生效——以先者為準 |
| 「存款 20 萬，次日他人匯入 30 萬，30 萬為扣押效力所及？」 | **錯**。存款無向後效力，須另發扣押命令（考過，筆記 11 第三題） |
| 「扣押命令所載 50 萬、帳戶有 100 萬？」 | 50 萬禁止領取，其餘 50 萬債務人仍有處分權——**不是凍結整個帳戶** |
| 「扣押後該存款所生利息是否及之？」 | **不及**（§51 I 只及天然孳息，反面解釋不及法定孳息）；到達時已入帳的利息則及之 |

## 一、生效時點

```
執行處發命令 ──寄──▶ 乙（債務人）
              └─寄──▶ 丙（第三人） ← 送達丙時生效（§118 II 本文）
有登記制度的權利：送達前已辦扣押登記 → 登記時生效（但書）
→ 執行就是搶時間，一律「以先者為準」
```

## 二、客觀範圍——存款的例子

| 情形 | 扣押效力 |
|---|---|
| 命令載 500 萬，到達時存款 300 萬 | 300 萬全部及之 |
| 之後又存入 200 萬 | **不及**，另聲請扣押命令 |
| 到達時存款本金 100 萬＋已生利息 1,000 元 | 100 萬 1,000 元**全部**及之（都是消費寄託返還請求權） |
| 年底再入帳的利息 | **不及**（扣押後之法定孳息） |

- 扣押命令一定載明「在多少元範圍內扣押」，通常是執行名義上的債權額。
- 對照：薪資、租金等**繼續性給付債權**有向後效力（§115-1，筆記 03）。
