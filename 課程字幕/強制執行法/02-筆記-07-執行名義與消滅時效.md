# 強制執行法02 筆記：執行名義與消滅時效

## 誰有時效：
- 執行名義（判決書、和解筆錄）本身**沒有時效**，是背後的**請求權**有時效，依實體法判斷
- 唯一例外：**假扣押、假處分裁定**，債權人收受後逾 **30 日**不得聲請執行（§132 III）；逾期可再聲請一個新的保全裁定

## 中斷與重行起算：
- **聲請強制執行**中斷時效（民 §129 II ⑤）；條文「開始執行行為」已是贅文（現行全依聲請）
- 執行程序終結（執行完畢、核發**債權憑證**）→ 重行起算（民 §137 I）
- 撤回聲請或聲請被駁回 → **視為不中斷**（民 §136 II）

## 延長為五年（民 §137 III）：
- 兩要件：原時效**不滿五年**＋經**確定判決或與確定判決同一效力**之執行名義確定
- 原時效五年以上 → 仍依原期間，**不會縮短**
- **本票裁定不適用**：沒有確定判決效力，永遠三年、三年（考生常錯）

## 時效完成後：
- 權利**不當然消滅**，執行處照樣執行（分離原則）→ 債務人提 **§14 異議之訴**（考過）

## 📖 法條原文速查

> **民 §129 II ⑤**　左列事項，與起訴有同一效力：……五、**開始執行行為或聲請強制執行**。
> **民 §136 II**　時效因聲請強制執行而中斷者，若**撤回**其聲請，或其聲請**被駁回**時，視為不中斷。
> **民 §137**　I 時效中斷者，自中斷之事由終止時，重行起算。II 因起訴而中斷之時效，自受確定判決，或因其他方法訴訟終結時，重行起算。III 經**確定判決或其他與確定判決有同一效力之執行名義**所確定之請求權，其原有消滅時效期間**不滿五年**者，因中斷而重行起算之時效期間為**五年**。
> **強執 §132 III**　債權人收受假扣押或假處分裁定後已逾**三十日**者，不得聲請執行。
> **票據法 §22 I**　票據上之權利，對匯票承兌人及本票發票人，自到期日起算；見票即付之本票，自發票日起算；**三年**間不行使，因時效而消滅。對支票發票人自發票日起算，**一年**間不行使，因時效而消滅。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「確定判決之時效為幾年？」 | 問法錯誤：執行名義無時效，看**背後請求權** |
| 「唯一有期限的執行名義？」 | **假扣押、假處分裁定**：收受後 30 日內聲請（§132 III） |
| 「聲請強制執行後撤回，時效？」 | **視為不中斷**（民 §136 II） |
| 「核發債權憑證後時效？」 | 執行程序終結 → **重行起算** |
| 「侵權行為（2 年）經判決確定，中斷後重行起算？」 | 延長為 **5 年**（民 §137 III） |
| 「本票裁定（3 年）聲請執行中斷後重行起算？」 | 仍 **3 年**，本票裁定無確定判決同一效力，**不延長** |
| 「15 年之請求權經判決確定後重行起算？」 | 仍 **15 年**，不縮短 |
| 「持 20 年前確定判決聲請執行，執行處應駁回？」 | **否**，照常執行；時效抗辯屬實體 → 債務人 **§14** |

## 一、時效流程圖（講義 51 頁板書）

```
請求權發生 ──時效進行──→ 起訴（中斷，民 §129 I ③）
                              │ 審理中
                         判決確定 → 重行起算（民 §137 II）
                              │ 若原時效 < 5 年 → 延長為 5 年（§137 III）
                         聲請強制執行 → 再中斷（民 §129 II ⑤）
                              │ 執行中
                         執行程序終結（執行完畢／債權憑證）→ 重行起算（§137 I）
                              │
                         5 年內再拿債權憑證聲請 → 再中斷 …（循環）
```

## 二、延長時效的判斷

| 執行名義 | 有確定判決同一效力？ | 原時效 < 5 年時延長？ |
|---|---|---|
| 確定判決 | ✓ | ✓ 延為 5 年 |
| 民訴和解、調解 | ✓ | ✓ |
| 經法院核定之鄉鎮市調解書 | ✓ | ✓ |
| 本票裁定 | ✗ | ✗ 永遠 3 年 |
| 拍賣抵押物裁定、假扣押裁定、支付命令 | ✗ | ✗ |

- 立法理由：短時效是要你趕快行使；已有確定判決效力，權利義務塵埃落定，就不必再用短時效。

## 三、為什麼「每五年換一次債權憑證」

- 借款本金時效 15 年，但執行名義通常含**利息**，利息時效 **5 年**（民 §126）→ 每 5 年聲請一次以中斷時效。
