# 強制執行法05 筆記：參與分配（§32）vs 雙重聲請執行／併案執行（§33）——外觀相同（數債權人對同一債務人之同一財產），差在書狀寫法：寫「聲明參與分配」或「聲請強制執行」；§33 立法意旨＝**禁止雙重查封**（查封一次就夠，效力及於後聲請者，不必再勞師動眾）：對已開始執行之債務人財產，他債權人再聲請執行者，**以前已實施之執行行為之效力，於為聲請時及於該他債權人**，應合併其執行程序並依 §31、§32 辦理（最後一樣做分配表、一樣依基準時分群團）；**後案併前案**（§56：書記官執達員查封時發現已因案受查封，報告執行法官併案）；併案之效力：後執行程序於聲請時生**潛在查封效力**合併於先程序，先程序**撤回或撤銷**時潛在效力**顯現**（甲一撤回不能啟封，甲二還在）；先程序續行時後程序不得進行；**座談會**（講義 203 頁）：A 事件因第三人異議之訴依 §18 II 裁定停止執行，B 事件（丁）併入後**得續行**——§33 僅禁止雙重查封，後執行程序是獨立程序、與先執行債權人地位相同；停止裁定之效力僅及於**裁定兩造（丙、甲）與主文所示之 A 事件**，不及於丁，不論丁之執行名義為一般金錢債權或拍賣抵押物裁定（多數說）；**法理差異**：參與分配**附隨**於執行債權人之程序（先程序消滅理論上失所附麗），且**優先受償權人不須執行名義**；併案執行是**獨立**程序（本有單獨查封效力）、聲請人**須有執行名義**；但**注意事項 §16 I**：債權人撤回時，依 §34 I 聲明參與分配之他債權人**得聲請繼續執行**（補一個聲請即可，不必重新聲請）→ 兩者實際上幾乎無差；注意事項 §18 III：撤回時原執行處分對再聲請執行之他債權人繼續有效（§33 本有）；**行政執行競合**（§33-1、§33-2）：同樣禁止雙重查封、後案併前案——行政先查封 → 民事執行連同卷宗函送行政執行機關合併辦理；民事先查封 → 行政執行機關函送執行法院；先者不再繼續執行時卷宗送回由後者續行

## 📖 法條原文速查

> **強執 §33**　對於已開始實施強制執行之債務人財產，他債權人再聲請強制執行者，已實施執行行為之效力，於為聲請時及於該他債權人，應合併其執行程序，並依前二條之規定辦理。
> **強執 §33-1**　I 執行人員於實施強制執行時，發現債務人之財產業經行政執行機關查封者，不得再行查封。II 前項情形，執行法院應將執行事件連同卷宗函送行政執行機關合併辦理，並通知債權人。III 行政執行機關就已查封之財產不再繼續執行時，應將有關卷宗送請執行法院繼續執行。
> **強執 §33-2**　I 執行法院已查封之財產，行政執行機關不得再行查封。II 前項情形，行政執行機關應將執行事件連同卷宗函送執行法院合併辦理，並通知移送機關。III 執行法院就已查封之財產不再繼續執行時，應將有關卷宗送請行政執行機關繼續執行。
> **強執 §56**　書記官、執達員於查封時，發現債務人之財產業經因案受查封者，應速將其查封原因，報告執行法官。（條文原文請對六法）
> **辦理強制執行事件應行注意事項 §16 I**　債權人撤回強制執行之聲請時，如他債權人依本法第三十四條第一項規定聲明參與分配者，得聲請繼續執行。
> **注意事項 §18 III**　聲請強制執行之債權人撤回執行時，原實施之執行處分對於再聲請執行之他債權人繼續有效。（原文請對講義 204 頁）

## 📋 實務見解速查

> **座談會**（講義 203 頁，字號字幕未唸，請對講義）：甲持確定判決對乙之房屋聲請執行（A 事件），第三人丙主張已撤銷乙丙間物權行為、其為所有權人，提第三人異議之訴，法院裁定於丙供擔保後停止執行（§18 II）；停止期間另一債權人丁對同一房屋聲請執行（B 事件），執行法院併入 A 事件，丁聲請續行——**肯定說（多數）**：①§33 僅規定不得為雙重查封，後執行程序係**獨立之執行程序**，與先執行債權人有相同地位，僅於先執行債權人繼續執行時後執行之地位潛在，一旦先執行撤回，後執行之效力即告顯現；②先執行程序因 §18 II 事由經裁定停止時，該裁定係以異議之訴之**兩造（丙、甲）**為當事人、主文所諭知停止者亦為**先執行程序（A 事件）**，其效力**不及於**後執行債權人丁 → 丁得聲請續行，不論其執行名義為一般金錢債權或拍賣抵押物裁定。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§33 之立法意旨？」 | **禁止雙重查封**：查封一次即可，已實施執行行為之效力於聲請時及於後聲請之他債權人；合併執行程序，依 §31、§32 分配。後案併前案 |
| 「甲一聲請執行查封 A 地後，甲二再聲請執行同一 A 地，執行處應否再查封？」 | **否**。§33 查封效力及於甲二，合併程序（§56 發現已因案受查封應報告執行法官併案） |
| 「甲一撤回執行，A 地應否啟封？」 | **否**（只要甲二還在）。後執行程序於聲請時生**潛在查封效力**，先程序撤回或撤銷時**顯現**（注意事項 §18 III 同旨） |
| 「先執行程序因第三人異議之訴裁定停止執行，併入之後執行債權人得否聲請續行？」 | **得**（座談會多數說）。後執行程序獨立、地位相同；停止裁定之效力僅及於裁定兩造與該先執行事件，不及於後執行債權人；執行名義種類不影響結論 |
| 「參與分配 vs 併案執行有何不同？」 | ①性質：參與分配**附隨**於執行債權人程序（先程序消滅理論上失所附麗）；併案執行是**獨立**程序（有單獨查封效力 → 潛在效力顯現）②資格：參與分配**優先受償權人不須執行名義**（但不能單獨聲請執行）；併案執行聲請人**一律須有執行名義** ③書狀寫法不同；執行費同（千分之八）；效力最後都合併做分配表、依基準時分群團 |
| 「執行債權人撤回，參與分配之他債權人怎麼辦？」 | 注意事項 §16 I：**得聲請繼續執行**（補一個聲請，不必另案重新聲請）→ 參與分配與併案執行實際上幾乎無差 |
| 「債務人財產已經行政執行機關查封，民事執行處得否再查封？」 | **不得**（§33-1 I）。執行法院應將執行事件連同卷宗函送行政執行機關合併辦理（後案併前案）；行政執行機關不再繼續執行時，卷宗送回執行法院續行 |
| 「反之，執行法院已查封，行政執行機關？」 | **不得**再查封（§33-2），函送執行法院合併辦理；執行法院不再執行時送回行政執行機關續行 |

## 一、§32 vs §33 對照

| | §32 參與分配 | §33 雙重聲請執行（併案） |
|---|---|---|
| 書狀 | 聲明參與分配 | 聲請強制執行 |
| 性質 | 附隨、附屬於執行債權人之程序 | 獨立執行程序，為程序便利合併於先程序 |
| 先程序撤回 | 理論上失所附麗 → 但注意事項 §16 I 得聲請繼續執行 | 潛在查封效力顯現，當然繼續（注意事項 §18 III） |
| 資格 | 原則須執行名義；**優先受償權人不須** | **一律**須執行名義 |
| 執行費 | 千分之八 | 千分之八 |
| 效力 | 合併分配表、依基準時分群團 | 同 |

## 二、座談會案圖

```
甲（確定判決）→ 執行乙之房屋（A 事件）
丙：我才是所有權人 → §15 ＋ §18 II → 法院裁定停止執行（兩造：丙、甲；客體：A 事件）
丁（另一債權人）→ 聲請執行同一房屋（B 事件）→ §33 併入 A → 丁聲請續行
→ 得續行：停止裁定不及於丁；後執行程序獨立、地位相同（不論丁之執行名義種類）
```

## 三、行政執行競合

```
行政先查封 → 民事不得再查封（§33-1 I）→ 民事卷宗函送行政執行機關合併（II）→ 行政不續行時送回民事（III）
民事先查封 → 行政不得再查封（§33-2 I）→ 行政卷宗函送執行法院合併（II）→ 民事不續行時送回行政（III）
原則一樣：禁止雙重查封、後案併前案、先者退場後者潛在效力顯現
```

- 公法上金錢債權（欠稅、健保費、罰單）亦得參與分配（§34-1，筆記 10）；稅捐依特別法常有優先次序。
