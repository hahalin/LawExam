# 強制執行法01 筆記：強制執行請求權（院字2776）

## 兩個名詞：
- **強制執行請求權**：主體是**債權人**，請求國家（執行處）發動強制執行，屬**公法上請求權**
- **強制執行權**：主體是**國家**，執行處查封、法拍的權力；強執法主要是寫給執行處看的公法

## 不得拋棄：
- **33 年院字 2776 號解釋**（老師：執行法最重要的實務見解，沒有之一）
- 債權人與債務人所定**拋棄**強制執行請求權之特約，在執行法上**不生**請求權喪失之效力
- 可以不行使，但不能約定拋棄

## 學說：
- 通說採**抽象請求權說**：只要有**執行名義**即可請求執行，不問實體法上請求權是否存在
- 具體請求權說（不採）：須執行名義＋實體法上請求權兩者兼備
- 抽象說呼應分離原則

## 📋 實務見解速查

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「強制執行請求權之主體為國家？」 | **錯**。請求權主體＝**債權人**；執行權主體＝**國家** |
| 「強制執行請求權性質為私法上請求權？」 | **錯**。是請求國家發動執行權的**公法上**請求權 |
| 「債權人與債務人約定拋棄強制執行請求權，嗣債權人聲請執行，應駁回？」 | **不應駁回**。拋棄特約在執行法上不生喪失效力（院字 2776） |
| 「通說認為聲請強制執行須有執行名義及實體法上請求權？」 | **錯**，那是具體請求權說。通說**抽象請求權說**：有執行名義即可 |
| 「強制執行程序之性質？」 | **非訟程序**（不開庭），但當事人利害對立，略帶訴訟性質 |

## 一、三面關係圖（講義 4 頁）

```
                 民事執行處（國家）
                 ▲      強制執行權（主體：國家）
   強制執行請求權  │        │
  （主體：債權人） │        ▼  合法侵害（依執行名義）
              債權人 ─────── 債務人
               聲請人           被執行人
```

- 稱「債權人／債務人」，沒有原告被告；實際上誰真正有債權不是重點，只是程序上的名稱。
- 執行處對債務人的侵害是**依執行名義**的合法侵害；強執法同時是對債務人的**最低限度保障**。

## 二、兩說比較

| 比較 | 具體請求權說（不採） | 抽象請求權說（通說） |
|---|---|---|
| 要件 | ① 執行名義 ② 實體法上請求權 | **只要執行名義** |
| 執行處要看實體權利？ | 要 | 不用，看判決就好 |
| 與分離原則 | 衝突 | **呼應** |

```
債權人聲請執行
   │
   ├─ 有執行名義？ ── 否 → 駁回
   │        是
   ▼
   開始執行（抽象說：不問實體權利）
   │
   └─ 債務人主張實體上已無請求權 → 去民事庭起訴（分離原則）
```

## 三、院字 2776 的記法

- 「請求權可以**不用**，不能**約定丟掉**」。
- 申論班要背字號；一試至少要認得「院字 2776 → 拋棄執行請求權之特約不生效力」。
