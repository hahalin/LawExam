# 強制執行法05 筆記：強制處分（講義 176～189 頁、395 頁流程圖；選擇題幾乎沒考過，申論、執達員考試會考）——**拘提**（強制債務人到場）：三事由①經合法通知無正當理由不到場 ②有事實足認顯有逃匿之虞 ③違反限制住居命令，前二者另須有強制到場之**必要性**；**管收**（類似羈押，拘束於管收所）：五事由①命報告財產狀況而不為報告或為虛偽報告 ②有事實足認顯有履行義務之可能而**故不履行** ③就應供強制執行之財產有**隱匿或處分**之情事 ④於調查不動產現況時無正當理由拒絕陳述或為虛偽陳述、提出虛偽文書 ⑤**不可代替行為、不行為義務**（§128、§129）之間接強制「處怠金或管收」；背後道理：**管收不能抵債**（§25 I：履行義務不因被管收而免除）→ 關的是**藏錢的有錢人**，逼其吐錢（實務上多見於行政執行欠稅）；程序：對人身自由之強制處分 → **法官保留**（事務官報請法官）＋**令狀主義**（拘票／管收票，載法定事由、法官簽名）→ 執達員執行；未規定者**準用刑訴**；管收期限**不得逾 3 個月**，有新原因得**再行管收一次**；不得／停止管收：一家生計難以維持、懷胎五月以上或生產後二月未滿、罹疾病恐因管收不能治療；釋放：原因消滅、提供擔保、期限屆滿、執行完畢；**限制住居**：二事由＝管收事由②③（故不履行、隱匿處分財產）

> 來源：強制執行法05 課程字幕 01:03:40 ~ 01:15:00（講義 176～189 頁；流程圖 395 頁；112 年執達員考題在 178 頁）

## 📖 法條原文速查

> **強執 §21**（拘提事由：經合法通知無正當理由不到場／有事實足認顯有逃匿之虞／違反限制住居命令，前二款以有強制其到場之必要者為限）（條號、款次請對六法）
> **強執 §22**（管收事由五款、限制住居）（條號請對六法）
> **強執 §24**　管收期限，不得逾三個月。有管收新原因發生時，對於債務人仍得再行管收，但以一次為限。（項次請對原文）
> **強執 §25 I**　債務人履行債務之義務，不因債務人或依本法得管收之人被管收而免除。
> **強執 §128 I**　依執行名義，債務人應為一定之行為，而其行為非他人所能代為履行者，債務人不為履行時，執行法院得定債務人履行之期間。債務人不履行時，得處新臺幣三萬元以上三十萬元以下之怠金。其續經定期履行而仍不履行者，得再處怠金或管收之。
> **強執 §129 I**（不行為義務：處怠金或管收）
> **不得管收／停止管收、釋放事由、拘票與管收票之記載、準用刑訴之條號請對講義 178～188 頁**

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「拘提之要件？」（112 年執達員第二小題） | 三事由：①合法通知無正當理由不到場 ②有事實足認顯有逃匿之虞 ③違反限制住居命令；①②另須**有強制到場之必要** |
| 「管收之事由？」 | 五個：①不為財產報告或虛偽報告 ②顯有履行可能而**故不履行** ③財產**隱匿或處分** ④不動產現況調查拒絕陳述、虛偽陳述或提出虛偽文書 ⑤不可代替行為／不行為之間接強制（§128、§129 處怠金**或管收**） |
| 「管收可否抵債？」 | **不能**（§25 I）。管收是逼有錢卻藏錢的債務人把錢拿出來的心理強制，不是以關代償 |
| 「拘提、管收之程序？」 | 人身自由限制 → **法官保留**（司法事務官不能自行決定，須報請法官）＋**令狀主義**（拘票／管收票，載法定事由、法官簽名）→ 由執達員執行；管收所所長驗收後於管收票附記送到時間並簽名。未規定者**準用刑訴** |
| 「管收期限？」 | 不得逾 **3 個月**；有新原因得再行管收，**以一次為限** |
| 「不得管收／應停止管收之情形？」 | ①因管收致一家生計難以維持 ②懷胎五月以上或生產後二月未滿 ③現罹疾病恐因管收不能治療 |
| 「釋放事由？」 | ①管收原因消滅 ②提供擔保 ③期限屆滿 ④執行完畢（執行程序終結） |
| 「限制住居之事由？」 | 二個＝管收事由②③：故不履行、隱匿或處分財產（與管收重疊） |
| 「不可代替行為舉例？」 | 歌手開演唱會（換人唱不一樣）；拆房子可代替（找別人拆）→ 不是 |

## 一、三種強制處分對照

| | 拘提 | 管收 | 限制住居 |
|---|---|---|---|
| 性質 | 強制到場（≈刑訴拘提） | 拘束身體自由於管收所（≈羈押） | 限制居住、出境 |
| 事由 | 3（＋必要性） | 5 | 2（＝管收②③） |
| 令狀 | 拘票 | 管收票 | — |
| 決定 | 法官（法官保留） | 法官 | — |
| 期限 | — | ≤3 月，再行管收 1 次 | — |

## 二、管收五事由的共同邏輯

```
①不報告財產 ②故不履行 ③隱匿處分財產 ④不配合不動產調查 → 都是「有錢卻藏錢、不配合」
⑤不可代替行為／不行為 → 間接強制（怠金 → 管收）逼其履行
→ 窮人不會被管收；被管收的是有資力者（新聞上多為行政執行欠稅大戶）
```
