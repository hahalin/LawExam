# 強制執行法07 筆記：無益執行禁止（§80-1）與超額禁止（§96）

## 無益執行禁止（剩餘主義、無剩餘換價禁止）：
- 典型：一般債權人聲請拍賣，不動產上有抵押權；賣完先付稅、執行費、抵押債權，一般債權人分不到
- 判斷基準：**底價**（拍賣最低價額）不足清償「**優先債權＋執行費用**」
- 執行法院**通知債權人** → 債權人**七日內**選擇：
  - 聲請拍賣：證明有剩餘可能，或指定較高底價，**並聲明未拍定願負擔費用**
  - 不聲請：逾期 → **撤銷查封**，返還債務人
- 聲請拍賣仍未拍定、債權人不承受 → 公告**三個月**（特別變賣）→ 仍無人應買或承受 → 撤銷查封
- 順位在先之抵押權人、優先受償權人聲請拍賣 → **不適用**
- 已併付或認為適當另付**強制管理** → 不撤銷查封返還

## 超額禁止（§96）：
- 數宗不動產，其中一宗或數宗賣得價金**已足清償** → 其他部分**停止拍賣**
- 債務人得指定拍賣部分；但**建物與基地不得指定單獨拍賣**
- 不要求精準，避免極端超額即可

## 📖 法條原文速查

> **強執 §80-1**　I 不動產之**拍賣最低價額**不足清償**優先債權及強制執行之費用**者，執行法院應將其事由**通知債權人**。債權人於受通知後**七日內**，得證明該不動產賣得價金有賸餘可能或指定超過該項債權及費用總額之拍賣最低價額，並聲明如未拍定**願負擔其費用**而聲請拍賣。逾期未聲請者，執行法院應**撤銷查封**，將不動產返還債務人。
> II 依債權人前項之聲請為拍賣而未拍定，債權人亦不承受時，執行法院應公告願買受該不動產者，得於**三個月**內依原定拍賣條件為應買之表示，執行法院於詢問債權人及債務人意見後，許其買受。債權人復願承受者亦同。逾期無人應買或承受者，執行法院應撤銷查封，將不動產返還債務人。
> III 不動產由**順位在先之抵押權或其他優先受償權人**聲請拍賣者，**不適用**前二項之規定。
> IV 第一項、第二項關於撤銷查封將不動產返還債務人之規定，於該不動產已併付**強制管理**之情形；或債權人已聲請另付強制管理而執行法院認為適當者，不適用之。
> **強執 §96**　I 供拍賣之數宗不動產，其中一宗或數宗之賣得價金，已足清償強制執行之債權額及債務人應負擔之費用時，其他部分應**停止拍賣**。II 前項情形，債務人得指定其應拍賣不動產之部分。但**建築物及其基地，不得指定單獨拍賣**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「是否無益執行，以什麼價格判斷？」 | **拍賣最低價額（底價）**，不是鑑定價或市價 |
| 「底價要跟什麼比？」 | **優先債權＋執行費用** |
| 「執行法院發現無益，第一步？」 | **通知債權人**（不是直接撤銷查封） |
| 「債權人受通知後幾日內聲請拍賣？」 | **七日**；須證明有賸餘可能或指定較高底價，並聲明**未拍定願負擔費用** |
| 「債權人逾期未聲請？」 | 執行法院**應撤銷查封**，返還債務人 |
| 「聲請拍賣後未拍定，債權人不承受？」 | 公告 **3 個月**應買（特別變賣）→ 仍無 → 撤銷查封 |
| 「第一順位抵押權人聲請拍賣，有 §80-1 適用？」 | **無**（§80-1 III） |
| 「數宗不動產，債務人指定只拍房屋、不拍基地？」 | **不得**（§96 II 但書） |

## 一、§80-1 流程

```
底價 ＜ 優先債權＋執行費用
   ↓
① 執行法院通知（聲請執行的一般）債權人
   ↓
② 受通知後 7 日內
   ├─ 不聲請 → 撤銷查封，返還債務人（§80-1 I 後段）
   └─ 聲請拍賣：證明有賸餘可能／指定較高底價＋聲明未拍定願負擔費用
          ↓
       拍賣未拍定、債權人不承受
          ↓
       ③ 公告 3 個月，依原條件應買（特別變賣）；債權人亦得承受
          ↓
       逾期無人應買或承受 → 撤銷查封返還（§80-1 II）
   ※ 已併付強制管理等 → 不撤銷返還，接續強制管理（§80-1 IV）
```

## 二、為何以「底價」判斷

- 底價是估價師估價後由執行處核定的**預估值**，最後拍定價可能更高（房市熱時搶標）。
- 拍賣還沒發生，只能用底價先衡量；債權人不服，可另找估價、自行指定較高底價，但**後果自負**（費用自己吸收）。

## 三、無益執行在強執法各階段

| 階段 | 條文（講義概念解析） |
|---|---|
| 查封 | §50-1（無益查封） |
| 換價 | **§80-1**（考試頻率最高） |
| 強制管理 | 亦有相應規定（條次請對講義） |

- 為何重點在換價：查封時可能只有一個債權人，到拍賣階段陸續有人參與分配、併案，無益與否到換價才見真章。

## 四、超額 vs 無益

| | 超額禁止 §96 | 無益執行 §80-1 |
|---|---|---|
| 問題 | 賣太多 | 賣了一般債權人分不到 |
| 處理 | 已足清償 → 其他停止拍賣 | 通知 → 7 日內聲請拍賣或撤銷查封 |
| 嚴格度 | 寬鬆，避免極端超額即可 | 有固定程序，要記流程 |
