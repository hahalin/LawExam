# 強制執行法08 筆記：對公法人之執行§122-1～§122-4

## 公法人得為執行債務人：
- 早期有否定見解；現行**肯定**：履約能力、履行意願不是執行要件，國庫不一定有錢，機關從事採購等私經濟行為也會欠錢

## 適用對象（§122-1 I）：
- **中央或地方機關**（部會、局處、市政府）＋**依法為公法人者**
- 但書：**金融機構**或其他無關人民生活必需之公用事業 → 「不在此限」＝**不適用本節特別規定**，照一般程序執行，**不是**不得執行（例：中央銀行）
- 已民營化（中華郵政、中華電信股份有限公司）→ 非機關、非公法人，一般程序

## 特別規定：
- **不適用 §20～§25**（§122-1 II）：無拘提、管收、限制住居、財產報告等
- **先發執行命令**：促其 **30 日內**自動履行或將金錢支付執行法院轉給債權人（§122-2 I）
- 應給付之金錢**列有預算項目**而不辦理 → 得適用 §115 I、II **逕向該管公庫執行**（§122-2 II）
- **公用財產**為推行公務所必需或移轉違反公共利益 → 不得執行（§122-3 I）；有疑問時應詢問債務人意見或為必要調查（II）
- 非公用財產、不屬前述之公用財產 → **仍得執行**，不受國有財產法、土地法等處分限制（§122-4）

## 📖 法條原文速查

> **強執 §122-1**　I 關於金錢請求權之強制執行，債務人為**中央或地方機關**或依法為**公法人**者，適用本節之規定。但債務人為**金融機構**或其他無關人民生活必需之公用事業者，不在此限。II 第二十條至第二十五條之規定，於前項執行**不適用**之。
> **強執 §122-2**　I 執行法院應對前條債務人先發執行命令，促其於**三十日內**依照執行名義自動履行或將金錢支付執行法院轉給債權人。II 債務人應給付之金錢，**列有預算項目**而不依前項規定辦理者，執行法院得適用第一百十五條第一項、第二項規定，逕向該管**公庫**執行之。
> **強執 §122-3 I**　債務人管有之**公用財產**，為其**推行公務所必需**或其移轉**違反公共利益**者，債權人不得為強制執行。
> **強執 §122-4**　要旨：債務人管有之非公用財產及不屬前條第一項之公用財產，仍得為強制執行，不受國有財產法、土地法及其他法令有關處分規定之限制。
（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「政府機關得否為執行債務人？」 | **得**；履行能力、意願非執行要件 |
| 「對中央銀行執行，適用 §122-1 以下？」 | **不適用**（金融機構），但仍**得**依一般程序執行 |
| 「對中華電信股份有限公司執行？」 | 已民營化，非機關非公法人 → 一般程序 |
| 「對機關得拘提管收其首長？」 | **不得**，§20～§25 不適用 |
| 「對機關執行第一步？」 | 先發執行命令，促其 **30 日內**自動履行 |
| 「機關不履行，且該筆金錢列有預算？」 | 得逕向**該管公庫**執行（適用 §115 I、II） |
| 「機關的公用財產一律不得執行？」 | **錯**：須推行公務所必需或移轉違反公益；閒置的仍得執行 |

## 一、適用範圍判斷

```
債務人是誰？
├─ 中央／地方機關、公法人 ……… 適用本節（§122-1 I 本文）
├─ 但金融機構、無關人民生活必需之公用事業
│     → 不適用本節，照一般程序（仍得執行）
└─ 已民營化之公司（中華郵政、中華電信）
      → 本來就不是機關，一般程序
```

## 二、執行流程

```
執行名義（例：廠商對市政府的採購價金）
      ↓
先發執行命令：30 日內自動履行或付給執行法院轉給（§122-2 I）
      ↓ 不履行
列有預算項目？ ── 是 → 適用 §115 I、II 逕向該管公庫執行（§122-2 II）
      │
      否 → 查封財產
             ├─ 公用財產＋公務所必需或移轉違反公益 → ✗（§122-3）
             └─ 非公用財產、閒置公用財產 → ✓（§122-4）
```

## 三、不得執行之財產兩要件

| 要件 | 例 |
|---|---|
| ① 債務人管有之**公用財產** | 辦公廳舍、設備、圖書館藏書 |
| ② **推行公務所必需**或**移轉違反公共利益** | 公務員使用中的電腦桌椅 ✗；多出來閒置的 ✓ |
