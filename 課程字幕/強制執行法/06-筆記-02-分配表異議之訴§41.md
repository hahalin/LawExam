# 強制執行法06 筆記：分配表異議之訴（§41）

## 兩階段：
- 第一階段：§39 向執行處聲明異議（期日一日前、書狀）
- 第二階段：異議未終結 → §41 向**民事庭**提分配表異議之訴（實體事項要實體解決）

## 當事人與期限：
- 原告＝聲明異議之人；被告＝為反對陳述之人
- 分配期日起**十日內**：**起訴＋向執行處提出起訴證明**，兩件都要
- 做到 → 該債權應受分配之金額**提存**；沒做到 → **視為撤回異議**，照原分配表分
- 110 年大法庭：**不因異議人是否於分配期日到場**而延後起算，十天就十天

## 其他：
- 債務人對有執行名義之債權人異議 → 只能以 **§14** 事由（有既判力者受遮斷效）
- 已依同一事由就爭執債權另提他訴 → 毋庸再起訴，依該確定判決分配
- 性質：形成之訴（形成新分配表）；判決效力採**按分說**——未起訴之其他債權人也一起受益（團體分配主義）

## 📖 法條原文速查

> **強執 §41**　I 異議未終結者，為異議之債權人或債務人，得向執行法院對為反對陳述之債權人或債務人提起**分配表異議之訴**。但異議人已依同一事由就有爭執之債權先行提起其他訴訟者，毋庸再行起訴，執行法院應依該確定判決實行分配。
> II 債務人對於有執行名義而參與分配之債權人為異議者，**僅得以第十四條規定之事由**，提起分配表異議之訴。
> III 聲明異議人未於分配期日起**十日內**向執行法院為前二項**起訴之證明**者，**視為撤回其異議之聲明**；經證明者，該債權應受分配之金額，應行**提存**。
> IV 前項期間，於第四十條之一有反對陳述之情形，自聲明異議人**受通知之日**起算。
（條文原文請對六法）

## 📋 實務見解速查

> **最高法院 110 年民事大法庭裁定**（講義 212 頁，字號請對講義）：§41 III 之十日期間，自分配期日起算，**不因異議人是否於分配期日到場而有異**；未到場者不得主張延後起算。
> **最高法院 106 年裁定**（講義 213 頁，字號請對講義）：強制執行法對多數債權人採**團體分配主義**，債權人提起分配表異議之訴之勝訴利益，因更正分配表而剔除之部分，執行法院將之分配與**各債權人**（含未起訴者），原審認不得由上訴人一人取得，並無違法。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「分配表異議之訴向哪裡起訴？」 | 執行法院之**民事庭**（條文「執行法院」與 §14、§15 同，指民事庭，不是執行處） |
| 「原告、被告？」 | 原告：**聲明異議**之債權人或債務人；被告：**為反對陳述**之債權人或債務人 |
| 「異議人於分配期日起十日內起訴，但未向執行處提出起訴證明？」 | **視為撤回異議**（§41 III），執行處照原分配表分配。十日內要**起訴＋證明** |
| 「十日內起訴並證明之效果？」 | 該債權應受分配之金額**提存**，待判決確定 |
| 「異議人未於分配期日到場，十日期間得否延後起算？」 | **不得**（110 年大法庭）。唯一的另行起算是 §41 IV：§40-1 有反對陳述時，自**受通知之日**起算 |
| 「債務人對**有執行名義**參與分配之債權人提起分配表異議之訴，得主張之事由？」 | **僅得以 §14 事由**（§41 II）；執行名義有既判力者，受**遮斷效**限制（基準時後事由） |
| 「已就該債權另提確認之訴，還要提 §41 嗎？」 | **毋庸**，執行法院依該確定判決分配（§41 I 但書） |
| 「勝訴後剔除部分歸誰？」 | **按分說**（實務）：原告與**未起訴之其餘債權人**按債權額比例分——團體分配主義 |

## 一、時間軸（老師板書）

```
收到分配表 ─── 期日前 1 日（§39 異議最後一天）─── 分配期日 ─────── 期日起 10 日
                                                    │                │
                                       異議未終結 → 有爭議部分不分   │
                                                    └─ 起訴＋證明 ──┘ → 提存
                                                       未做到 → 視為撤回異議 → 照原表分配
```

## 二、§41 要件整理

| 項目 | 內容 |
|---|---|
| 前提 | §39 異議**未終結**（沒有共識） |
| 原告／被告 | 異議人／反對陳述人 |
| 事由 | 實體事項；債務人對有執行名義者限 §14 事由（受遮斷效） |
| 期限 | 分配期日起 10 日內起訴＋證明（§40-1 情形自受通知日起算） |
| 管轄 | 執行法院所屬**民事庭** |
| 性質 | **形成之訴**（請求形成新分配表） |
| 判決後 | 確定判決拿到執行處 → 依判決作新分配表 |

## 三、判決效力：按分說

```
分配表：甲 100（假債權）、乙 50、丙 50 → 乙起訴剔除甲之假債權勝訴
→ 剔除之金額不是乙一人獨得
→ 由原告乙與未起訴之丙，按債權額比例算出應分配額（團體分配主義）
```

- 老師：選擇題採實務的按分說，名字不用記，記「沒告的人也沾光」。
