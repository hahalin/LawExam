# 強制執行法09 筆記：不可代替行為（§128）

## 執行方法（§128 I）：
- 行為**非他人所能代為履行**（反推 §127＝可代替）
- 三步驟：① 定債務人**履行期間**（先禮後兵，發執行命令）→ ② 不履行，處新臺幣 **3 萬元以上 30 萬元以下怠金** → ③ 續經定期仍不履行，**再處怠金或管收**
- 實務很少管收，多半反覆處怠金、金額逐次提高
- 執行法院得通知**有關機關**適當協助（§129-1）；限政府機關，不含個人、企業、團體

## 不適用間接強制的不可代替行為：
- 學者整理五種（姓名字幕為「張登科」，請對講義）：
  - ① 夫妻同居判決（§128 II 明文）
  - ② 壓制債務人意思使為行為，難以實現債務本質（藝術家作畫）
  - ③ 僅依債務人意思無法實現，尚需第三人協力而無協力之預期
  - ④ 債務人非有特別設備不能履行
  - ⑤ 仰賴債務人之力執行其行為，需負擔顯不相當之巨額費用
- 效果：不得處怠金或管收；債權人只能依**債務不履行請求損害賠償**
- 國考考過的是 ②

## 交出子女或被誘人（§128 III）：
- 本質是不可代替 → 本來只能間接強制；§128 III 多給一個**直接強制**：將子女或被誘人**取交**債權人
- 實務上直接強制限於年紀很小、無意思能力的子女（襁褓中、一兩歲）；國小、國中生不太可能
- 詳細規範在家事事件法（筆記 08）

## 📖 法條原文速查

> **強執 §128**　I 依執行名義，債務人應為一定之行為，而其行為**非他人所能代為履行**者，債務人不為履行時，執行法院得**定債務人履行之期間**。債務人不履行時，得處新臺幣**三萬元以上三十萬元以下之怠金**。其續經定期履行而仍不履行者，得**再處怠金或管收**之。II 前項規定，於**夫妻同居**之判決不適用之。III 執行名義，係命債務人**交出子女或被誘人**者，除適用第一項規定外，得用**直接強制**方式，將該子女或被誘人取交債權人。
> **強執 §129-1**　債務人應為第一百二十八條第一項及前條第一項之行為或不行為者，執行法院得通知**有關機關**為適當之協助。
（條文原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「不可代替行為之執行步驟？」 | ① 定履行期間 → ② 處 **3～30 萬元**怠金 → ③ 再處怠金或管收 |
| 「夫妻同居判決得強制執行？」 | **不得**（§128 II） |
| 「命畫家完成肖像油畫，畫家拒絕？」 | 壓制意思難以實現債務本質 → **不適用間接強制**，只能請求損害賠償 |
| 「命交出子女，得用直接強制？」 | **得**（§128 III），取交債權人；並得同時用 §128 I 間接強制 |
| 「§129-1 之有關機關包括私人托育機構？」 | **不包括**，限政府機關 |
| 「§128 怠金一次處完就結束？」 | 否。可定期 → 怠金 → 再定期 → 再怠金或管收，循環 |

## 一、§128 流程

```
執行名義命為不可代替之行為（實務先發自動履行命令）
   ↓
① 執行法院定履行期間
   ↓ 期滿未履行
② 處怠金（新臺幣 3 萬～30 萬元）
   ↓ 再定期仍不履行
③ 再處怠金或管收（實務多再處怠金、金額提高）
   ＋ §129-1 得通知有關機關協助（警察、境管單位）
```

## 二、不可代替但不能間接強制

| 類型 | 例 | 理由 |
|---|---|---|
| 夫妻同居 | §128 II | 強迫意思違反現代文化觀念 |
| 壓制意思難實現本質 | 藝術創作 | 給壓力就畫不出來 |
| 需第三人協力 | 無協力之預期 | 債務人一人做不到 |
| 需特別設備 | 債務人沒有設備 | 事實上不能 |
| 費用顯不相當 | 巨額費用 | 比例原則 |

- 老師：勝訴判決不等於一定實現，「理想很美好、現實很骨感」。

## 三、§128 III 交出子女的特殊性

| | 一般不可代替行為 | 交出子女、被誘人 |
|---|---|---|
| 間接強制 | 有 | 有（§128 I） |
| 直接強制 | 無 | **有**：取交債權人 |
| 限制 | — | 實務限無意思能力之幼兒；家事法另有審酌因素 |
