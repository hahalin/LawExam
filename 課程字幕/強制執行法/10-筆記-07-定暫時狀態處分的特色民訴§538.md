# 強制執行法10 筆記：定暫時狀態處分的特色（民訴§538）

## 要件與特色：
- 於**爭執之法律關係**，為防止重大損害、避免急迫危險或其他相類情形而有必要時（民訴 §538 I）
- 本案**不限給付**之訴：給付、確認、形成都可以；但須本案訴訟能確定該法律關係（§538 II）
- 有**公益性**：保護受扶養人、勞工、家暴被害配偶、未成年子女
- 多出現在**繼續性法律關係**：租賃、僱傭、婚姻、黨員資格、通行

## 最大不同：可以做到滿足：
- 得命**先為一定之給付**（§538 III）→ 扶養費、薪資可先拿 → **滿足性假處分**
- 給付金錢者準用第二章**金錢請求權執行**：查封、換價、滿足都能走完
- 所以裁定前原則**應使兩造陳述意見**（§538 IV）——與假扣押、假處分的秘密性相反

## 本案與處分內容可以不一致：
- 本案離婚（形成）→ 定暫時狀態：給付扶養費（給付）
- 本案確認僱傭關係存在（確認）→ 定暫時狀態：每月給付薪資
- 國賠法 §11 II：命賠償義務機關**暫先支付**醫療費或喪葬費 → 性質也是定暫時狀態處分

## 課堂案例：
- 健身房承租人被提前終止 → 確認租賃關係存在之訴 → 裁定：本案確定前不得要求遷讓、不得干擾使用收益
- 黨員被撤銷黨籍 → 確認黨籍存在之訴 → 裁定：本案確定前得繼續行使黨員權利

## 📖 法條原文速查

> **民訴 §538**　I 於**爭執之法律關係**，為防止發生**重大之損害**或避免**急迫之危險**或有其他相類之情形而有必要時，得聲請為定暫時狀態之處分。II 前項裁定，以其**本案訴訟能確定**該爭執之法律關係者為限。III 第一項處分，得命**先為一定之給付**。IV 法院為第一項及前項裁定前，應使**兩造當事人有陳述之機會**。但法院認為不適當者，不在此限。（字幕聽成「增值／真實之法律關係」，條文為「爭執之法律關係」；原文請對六法）
> **國家賠償法 §11 II**　依本法請求損害賠償時，法院得依聲請為假處分，命賠償義務機關**暫先支付**醫療費或喪葬費。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「定暫時狀態處分以本案為給付之訴者為限？」 | **錯**。確認、形成之訴亦可 |
| 「定暫時狀態處分僅能凍結現狀，不能命給付？」 | **錯**。得命**先為一定給付**（§538 III），可達**滿足** |
| 「法院為定暫時狀態處分前，應先使兩造陳述意見？」 | **原則應**，例外法院認不適當者不在此限 |
| 「本案為離婚之訴，得聲請定暫時狀態命給付扶養費？」 | **得**，本案類型與處分內容不必一致 |
| 「國賠法命機關暫先支付醫療費之假處分，性質？」 | **定暫時狀態處分**（滿足性），準用金錢請求權執行 |
| 「定暫時狀態處分執行，只能到查封階段？」 | **錯**。命金錢給付者可查封、換價、滿足 |

## 一、三種保全名義比較

| | 假扣押 | 假處分 | 定暫時狀態處分 |
|---|---|---|---|
| 保全對象 | 金錢請求 | 金錢以外之請求 | 爭執之法律關係 |
| 本案類型 | 給付 | 給付 | 給付、確認、形成 |
| 執行到哪 | 查封（例外換價） | 查封、凍結 | **可到滿足** |
| 債務人事前知情 | 否（秘密性） | 否 | 原則**應**使陳述意見 |
| 性質 | 私益 | 私益 | 帶公益色彩 |

## 二、本案 vs 處分內容

```
本案：離婚（形成）            → 定暫時狀態：給付扶養費（給付）
本案：確認僱傭關係存在（確認）→ 定暫時狀態：每月給付薪資（給付）＝滿足性假處分
本案：確認租賃關係存在（確認）→ 定暫時狀態：不得要求遷讓、不得干擾（不作為）
本案：撤銷股東會決議（形成）  → 定暫時狀態：禁止或准許行使董事職權
```

- 老師：分類方式各教科書不同，記內容就好。家事案件常用來安排訴訟期間子女的照顧與居住。
