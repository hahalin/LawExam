# 強制執行法04 筆記：§14 第一項 vs 第二項（條文是「倒著規定」）——I：異議事由發生於執行名義**成立後**、事由為**消滅或妨礙**、所有執行名義皆適用；II：發生於執行名義**成立前**、事由為**不成立、消滅或妨礙**（多送一個「不成立」，因未經審判程序）、限**無確定判決同一效力**之執行名義；III：數異議原因事實應**一併主張**（通說同一訴訟說），未一併主張不得再提異議之訴（另提給付之訴可）；異議事由例；執行契約（不利債務人之約定無效；不利債權人之約定僅有實體法上拘束力 → 用 §14 不用 §12）；§16 執行處遇實體抗辯指示另行起訴；終結＝整個；管轄＝執行處所屬地院民事庭

## 📖 法條原文速查

> **強執 §14 I**　執行名義**成立後**，如有**消滅或妨礙**債權人請求之事由發生，債務人得於強制執行程序終結前，向執行法院對債權人提起異議之訴。……
> **強執 §14 II**　執行名義**無**確定判決同一之效力者，於執行名義**成立前**，如有債權**不成立或消滅或妨礙**債權人請求之事由發生，債務人亦得於強制執行程序終結前提起異議之訴。
> **強執 §14 III**　依前二項規定起訴，如有多數得主張之異議原因事實，應一併主張之。其未一併主張者，不得再行提起異議之訴。
> **強執 §16**　債務人或第三人就強制執行事件得提起異議之訴時，執行法院得指示其另行起訴，或諭知債權人，經其同意後，即由執行法院撤銷強制執行。
> **強執 §10**（延緩執行）經債權人同意者，執行法院得延緩執行；期限不得逾三個月，再同意延緩以一次為限。（原文請對六法）
> **強執 §27**（債權憑證）債務人無財產或執行所得不足清償時，執行法院命債權人查報財產；到期不為報告或查報無財產者，發給憑證。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人於執行名義成立後清償，債權人仍執行，依第幾項？」 | **§14 I**（成立後 → 第一項） |
| 「債務人於支付命令確定前即已清償，依第幾項？」 | **§14 II**（成立前 → 第二項；支付命令無確定判決效力） |
| 「兩項三個不同？」 | ① 事由發生**時點**：I 成立後／II 成立前 ② 適用**執行名義**：I 全部／II 限無確定判決同一效力者 ③ **事由用語**：I 消滅、妨礙／II 不成立、消滅、妨礙 |
| 「為何 II 多送一個『不成立』？」 | 無確定判決效力之執行名義（公證書、本票裁定、支付命令）未經審判或類似程序，債務人無抗辯機會、較易有瑕疵 → 成立前的實體爭執也許其提異議之訴 |
| 「以抵銷為由提異議之訴遭駁回確定，得再以債權不成立為由另提異議之訴？」 | **不得**（§14 III）。數異議原因事實應於**同一訴訟**言詞辯論終結前一併主張（通說）；§14 只讓你告一次。另提給付之訴、損害賠償之訴可 |
| 「異議事由例？」 | 消滅：清償、提存、抵銷、免除、混同、消滅時效完成、解除條件成就、訴訟外和解、解除契約、意思表示撤銷、請求權人死亡。妨礙：延期清償之同意、同時履行抗辯。不成立：通謀虛偽無效、無權代理 |
| 「執行契約？」 | 法定：§10 延緩執行（合意停止）。意定：約定**不利於債務人**（比強執法更差）→ **無效**（強執法是債務人最低限度保障）；約定**不利於債權人**（分期、延期）→ 有效但僅有**實體法上拘束力**，執行處違反之不違法 → 不得 §12，應以 §14 主張 |
| 「債務人在執行處說『我已清償』，執行處怎麼辦？」 | **§16** 指示其另行起訴（去隔壁民事庭）；或諭知債權人同意後撤銷執行 |
| 「§14 之『終結前』？管轄？」 | **整個**執行程序終結前（否定執行名義本身）；向執行處所屬地院**民事庭** |

## 一、§14 I vs II 比較表

| | §14 I | §14 II |
|---|---|---|
| 異議事由發生時點 | 執行名義**成立後** | 執行名義**成立前** |
| 適用執行名義 | 全部 | 限**無**確定判決同一效力者 |
| 事由 | 消滅、妨礙 | **不成立**、消滅、妨礙 |
| 例 | 判決確定後才清償 | 支付命令確定前即清償 |

```
────執行名義成立────
   §14 II（前）  │  §14 I（後）    ← 條文倒著規定：第二項管前面、第一項管後面
```

## 二、§14 III 一併主張（通說：同一訴訟說）

- 同一訴訟程序言詞辯論終結前可自由追加其他異議原因事實；未一併主張者不得再提**異議之訴**（其他訴訟不受限）。

## 三、執行契約

| 約定 | 效力 | 救濟 |
|---|---|---|
| 不利債務人（比執行法更差） | 無效 | — |
| 不利債權人（同意延期、分期） | 有效，僅實體法上拘束力 | 執行處不受拘束、不違法 → **§14**（執行限制契約抗辯），非 §12 |

## 四、考題

### 112 年（支付命令執行，選錯誤）
```
A 乙以未居住於戶籍地、支付命令未合法送達而失效 → 聲明異議 ✓（81 台抗 114）
B 甲未交付借款、債權不成立 → 異議之訴 ✓（§14 II）
C 執行開始後清償、債權消滅 → 異議之訴 ✓（§14 I）
D 以抵銷為由之異議之訴遭駁回確定後，再以無借貸合意為由提異議之訴 ✗（§14 III）→ 答案 D
```

### 113 年（支票支付命令執行，選正確）
```
A 債權未獲足額清償，得依 §27 聲請核發債權憑證 ✓ → 答案 A
B 支票款於聲請支付命令「前」已罹於時效，得依 §14「第一項」提異議之訴 ✗ → 成立前應為第二項（支付命令無既判力，前後皆可提，只是條項不同）
C 提起異議之訴後受訴法院「依職權」裁定「不須供擔保」停止執行 ✗ → 停止執行由債務人聲請，供擔保與否由法院裁量（實務幾乎都供擔保）
D 支付命令送達後即得執行不須確定 ✗ → 須確定證明書（民訴 §521）
```
