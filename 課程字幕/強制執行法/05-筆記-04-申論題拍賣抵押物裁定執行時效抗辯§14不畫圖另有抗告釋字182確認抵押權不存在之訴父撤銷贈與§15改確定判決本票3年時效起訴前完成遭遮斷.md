# 強制執行法05 筆記：早期申論題（講義 170～172 頁）——甲（債務人）將父丙贈與之台南土地設定最高限額抵押予乙（債權人）並簽發本票，本票到期（90/6/1）未償，乙取得**許可拍賣抵押物裁定**（§4 I ⑤，對物之執行名義，只能執行該抵押物）聲請執行；**甲**主張債權**罹於時效**＝實體瑕疵 → **§14 債務人異議之訴**（得為 §18 II 停止執行事由）；執行名義是拍賣抵押物裁定，**無確定判決同一效力 → 不畫基準時圖**，時效在前在後皆可提；另有兩種救濟：對裁定**抗告**、**釋字 182** 提**確認抵押權不存在之訴**（亦得停止執行）；**丙**主張甲不給付扶養費、未盡孝道而**撤銷贈與**，土地回歸丙 → 錯誤執行 → **§15 第三人異議之訴**＋§18 II；**第二小題**：執行名義改為乙持本票訴請清償之**勝訴確定判決**（§4 I ①）→ 有既判力 → **畫圖**：本票對發票人時效 **3 年**，90/6/1 到期 → 93/6/1 完成，乙 93/7/1 才起訴 → 時效在**起訴前（基準時前）已完成**，甲於本案未為時效抗辯 → **被遮斷**，不得提 §14，另訴救濟（講義 152 頁概念解析否定說：時效以完成時為準，完成在基準時前即遮斷，不能把時效抗辯「憋到執行階段當大招」）

> 來源：強制執行法05 課程字幕 00:28:17 ~ 00:42:22（講義 170～172 頁；152 頁概念解析）

## 📖 法條原文速查

> **強執 §4 I ⑤**　抵押權人或質權人，為拍賣抵押物或質物之聲請，經法院為許可強制執行之裁定者。
> **強執 §4 I ①**　確定之終局判決。
> **票據法 §22 I**　票據上之權利，對匯票承兌人及本票發票人，自到期日起算；見票即付之本票，自發票日起算；三年間不行使，因時效而消滅。
> **釋字 182**：強制執行程序開始後，除法律另有規定外，不停止執行……惟債務人對於抵押權之存在有爭執而提起確認之訴者，法院得依聲請裁定停止執行（要旨依老師講解，原文請對講義）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人於拍賣抵押物裁定執行中主張債權罹於時效，如何救濟？」 | **§14 債務人異議之訴**（時效＝實體抗辯，不是 §12）；得併 §18 II 聲請停止執行。另：對裁定**抗告**；釋字 182 **確認抵押權不存在之訴**（亦得停止執行） |
| 「此時要不要畫既判力基準時圖？」 | **不用**。拍賣抵押物裁定無確定判決同一效力。要畫圖的只有：確定判決、訴訟上和解、訴訟上調解（有既判力者） |
| 「第三人丙主張已撤銷贈與、土地是他的？」 | **§15 第三人異議之訴**＋§18 II。兒子欠錢不能執行爸爸的地 |
| 「執行名義改為本票債權之勝訴確定判決，債務人主張時效？」 | **畫圖**。本票對發票人時效 3 年（票據法 §22 I），到期 90/6/1 → 93/6/1 完成；乙 93/7/1 起訴 → 時效**基準時前**已完成，甲本案未抗辯 → 遮斷 → **不得**提 §14 → 另訴 |
| 「基準時前已時效完成但未抗辯，判決確定後得否以時效為由提 §14？」 | **不得**（講義 152 頁概念解析否定說）。時效以**完成時**為異議事由發生時點；完成在基準時前 → 遮斷。對照：抵銷以**行使時**為準（強執法04 筆記 06） |
| 「對物執行名義？」 | 許可拍賣抵押物裁定只能執行該抵押物（台南土地），不能執行債務人其他財產 |

## 一、讀題法（老師）

```
① 先抓執行三要素：當事人（債權人乙／債務人甲）、執行名義（§4 I ⑤ 拍賣抵押物裁定）、標的（台南土地）
② 把不同角色的主張切開：甲（債務人）→ 時效 → 實體 → §14
                          丙（第三人）→ 撤銷贈與 → 錯誤執行 → §15
③ 問執行名義有沒有既判力 → 決定要不要畫圖
```

## 二、第一小題 vs 第二小題

| | 第一小題 | 第二小題 |
|---|---|---|
| 執行名義 | 拍賣抵押物裁定（§4 I ⑤） | 本票債權勝訴確定判決（§4 I ①） |
| 既判力 | 無 → 不畫圖 | 有 → 畫圖 |
| 時效完成時點 | 不論前後皆可 §14 | 93/6/1 完成 < 93/7/1 起訴 → 基準時前 → 遮斷 |
| 甲之救濟 | §14（＋抗告、確認抵押權不存在之訴） | 不得 §14 → 另訴 |
