# 強制執行法07 筆記：船舶及航空器之執行（§114～§114-4）

## 哪些船準用不動產執行（§114 I）：
- **海商法所定之船舶**（大船、海船、商船）→ 準用**不動產**執行；**建造中船舶**亦同
- 非海商法船舶（小船、軍艦、公務船、內陸湖泊的船）→ 適用**動產**執行（注意事項）
- 小船（船舶法）：總噸位未滿 **50** 之**非動力**船，或未滿 **20** 之**動力**船
- 建造中船舶：自**安放龍骨**（或相當時期）起，至成為海商法船舶止（注意事項 61 I）

## 航行中也能執行（§114 II、III）：
- 自**發航準備完成時**起至**航行完成時**止，仍得強制執行
- 但**保全程序**（假扣押等）之執行名義**不適用**——除海商法 §4 I 但書或船舶碰撞損害賠償

## 查封後停泊與撤銷查封（§114-1）：
- 查封後**取去國籍證書**、停泊指定處所、通知航政機關
- 經**債權人同意**，得因當事人或**利害關係人**聲請准許航行（俗稱「帶封航行」）
- 債務人或**利害關係人**提供擔保 → 得聲請**撤銷船舶查封**（考過）

## 航空器（§114-4）：
- 民用航空法所定航空器，準用**船舶**執行 → 等於也準用不動產執行；沒考過，知道即可

## 考古題（申論，講義 288 頁）：
- 甲之遠洋漁船遭查封：① 查封後出租 → **不可**（§113 準用 §51 II）② 甲投標 → **不可**（§113 準用 §70 VI，債務人不得應買）③ 委託作業之乙公司提供擔保聲請撤銷查封 → **應准許**（§114-1 II，乙為利害關係人）

## 📖 法條原文速查

> **強執 §114 I**　海商法所定之船舶，其強制執行，除本法另有規定外，準用關於**不動產執行**之規定；**建造中之船舶**亦同。
> **強執 §114 II、III**　要旨：II 對船舶之強制執行，自運送人或船長**發航準備完成時起，以迄航行完成時止**，仍得為之。III 前項強制執行，除海商法 §4 I 但書或船舶碰撞之損害賠償外，於**保全程序之執行名義，不適用**之。（原文請對六法）
> **強執 §114-1**　要旨：I 船舶查封後，應**取去證明船舶國籍之文書**，使其停泊於指定處所，並通知航政主管機關；但經**債權人同意**，得因當事人或利害關係人之聲請准許航行。II 債務人或**利害關係人**，得以債權額及執行費用額或船舶之價額，**提供擔保**，聲請**撤銷船舶之查封**。（原文請對六法）
> **強執 §114-4 I**　民用航空法所定航空器之強制執行，除本法另有規定外，準用關於**船舶**之強制執行之規定。
> **海商法 §1**　本法稱船舶者，謂在**海上航行**，或在**與海相通**之水面或水中航行之船舶。
> **海商法 §3**　下列船舶除因碰撞外，不適用本法之規定：一、船舶法所稱之**小船**。二、軍事建制之艦艇。三、專用於公務之船舶。四、第一條規定以外之其他船舶。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「海商法所定船舶之強制執行？」 | 準用**不動產**執行（§114 I），建造中亦同 |
| 「湖泊遊憩用小船之強制執行？」 | 非海商法船舶 → **動產**執行 |
| 「小船的標準？」 | 非動力未滿 **50** 噸、動力未滿 **20** 噸 |
| 「航行中之船舶不得強制執行？」 | **錯**，發航準備完成至航行完成仍得為之 |
| 「以假扣押裁定對航行中船舶執行？」 | 原則**不適用**（保全程序），例外：海商法 §4 I 但書、碰撞損害賠償 |
| 「船舶查封後得航行？」 | 原則停泊；經**債權人同意**得准許航行 |
| 「誰得提供擔保聲請撤銷船舶查封？」 | 債務人**或利害關係人**（如託運人、委託作業人） |
| 「民航法所定航空器之執行？」 | 準用**船舶** → 實質上準用不動產 |

## 一、船舶分流

```
船舶
├─ 海商法所定船舶（海船、大船、商船）＋建造中船舶
│    → 準用不動產執行（§114 I）
└─ 非海商法船舶
     ├ 小船（非動力 <50 噸、動力 <20 噸）
     ├ 軍艦、公務船
     └ 非海船（內陸湖泊）
     → 動產執行
航空器（民航法所定）→ 準用船舶（§114-4）→ 不動產
```

## 二、考古題解題路徑

| 小題 | 轉換成不動產問題 | 結論 | 依據 |
|---|---|---|---|
| ① 查封後出租 | 不動產查封後得否出租 | 不可 | §113 準用 §51 II |
| ② 債務人甲投標 | 債務人得否應買 | 不可 | §113 準用 §70 VI |
| ③ 乙公司供擔保撤銷查封 | 船舶特別規定 | 應准許 | §114-1 II |

- 老師提醒：看到「船」不要慌，海商法船舶骨子裡是**不動產執行**；①② 用不動產規則就能答，③ 才是船舶特別規定。
