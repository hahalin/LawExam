審題先認三要素：誰對誰執行、執行名義是什麼、執行對象是什麼。三要素各有實體爭執的管道：執行名義 → §14；執行主體 → §14-1；執行客體 → §15。

陷阱

這張卡是幼幼班。若執行名義有確定判決效力，提 §14 還要看異議事由發生的時點（卡 6）。

2聲明異議 §12：執行處做錯就跟執行處講；拿未確定的支付命令來執行等於拿白紙

執行處變更了拍賣期日（裁定），債務人想抗告。承租人說執行法院沒有通知他優先承買。債權人拿到支付命令就急著聲請執行，確定證明書還沒下來。

三個情形各怎麼救濟？裁定形式的執行處分要抗告還是聲明異議？

  • §12 I 四種事由（選擇題不用分，全是程序瑕疵）：執行命令／執行方法／應遵守之程序／其他侵害利益情事
  • 程序：執行處裁定（§12 II）→ 不服得抗告（§12 III）；不停止執行（I 但書）
    • 裁定形式的執行處分（變更拍賣期日）→ §12 是特別規定 → 先聲明異議，對異議裁定不服再抗告（42 年判例）。沒剝奪抗告權，多一道讓執行處自我反省
    • 土地法 §104、三七五減租 §15 優先承買通知 → 實體法上義務，非 §12「應遵守之程序」→ 不得聲明異議，只能以訴救濟（49 台抗 83）
    • 未確定支付命令、未確定判決、不具公證法 §13 要件之公證書 → 無執行名義＝白紙 → 聲明異議；執行法院獨立審查，不受誤發的確定證明書拘束（81 台抗 114，考 N 次）
規則

「聲請」是執行機關不做（怠惰）叫他做；「聲明異議」是做了但做錯。口頭上統稱聲明異議。當事人和利害關係人都可以提、口頭書面皆可（查封現場舉手講）、向執行處或實際實施執行的受託法院；駁回確定後以同一理由再提也可以（不是訴訟）。

陷阱

105 年題：確定支付命令未合法送達 → 異議期間無從起算、不確定 → 救濟是 C 聲明異議。同一個 81 台抗 114 換各種方式出。

4債務人異議之訴 §14 的骨架：形成之訴、告債權人、去民事庭；假扣押假處分不能用

債務人被執行，說請求權已罹於時效，到民事庭起訴：「被告不得執某執行名義對原告為強制執行」。另一人被假扣押，也想提 §14。

§14 的訴訟標的是什麼？敗訴後還能告不當得利嗎？哪種執行名義不能提 §14？

  • 結構：原告債務人、被告債權人、向執行處所屬地院民事庭（不用再依民訴找管轄）、形成之訴（訴訟標的＝§14 的異議權，效果＝排除執行名義之執行力）
  • 既判力不及於實體法律關係 → 敗訴確定後仍得依不當得利另訴
  • 適用範圍
    • 假扣押、假處分（保全執行）→ 不得提 §14（實務；條文看不出來要記）→ 實體爭執走本案訴訟
    • 假執行判決 → 得提（86 年判決：有 §18 II 停止執行的實益；學說反對）
  • 與確定判決同一效力的執行名義：確定判決、訴訟上和解、訴訟上調解、鄉鎮市調解經核定、仲裁判斷。公證書、支付命令、本票裁定、拍賣抵押物裁定、大陸裁判經認可 → 沒有
規則

結論只記一句：只有假扣押、假處分不能用 §14。「有無確定判決同一效力」這個分類接下來兩張卡都要用：決定 §14 用第一項還是第二項，也決定要不要畫既判力基準時的圖。

陷阱

§14 的「執行法院」是民事庭不是執行處。執行處不開庭；當事人在執行處說「我已清償」，執行處依 §16 指示其另行起訴。

6有確定判決效力的執行名義：異議事由要發生在既判力基準時之後；抵銷例外以行使時為準

甲持確定判決執行乙。乙說早就清償了——問他什麼時候還的：「第二審審理中」。另一位乙在第二審時就有可以抵銷的債權，當時沒主張，執行中才行使抵銷。還有一位基準時前就有得撤銷的原因，執行中才撤銷。

三個人各能不能提 §14？為什麼抵銷和撤銷結論相反？

抵銷：以實際行使時為準 → 得提

抵銷不是請求權的瑕疵，是兩個獨立債權互抵；要不要抵銷是債務人的自由，民法不能強迫抵銷 → 基準時前有抵銷適狀未主張，執行中才行使 → 事由發生在行使時＝新 → §14 ✓（肯定說）

撤銷、解除、時效完成：須在本案主張 → 不得

撤銷權是請求權本身的瑕疵，基準時前已存在未主張就被遮斷；無效都被既判力阻卻，較輕的撤銷反而能主張 → 失衡（否定說為大宗）。解除權、基準時前已完成的時效同此
規則

畫這張圖的兩個前提都要滿足：① 考 §14 債務人異議之訴 ② 執行名義有確定判決同一效力。既判力遮斷的是攻擊防禦方法（基準時前能提的全部要提，沒提就失權），不是訴訟標的。

執行名義是支付命令、公證書、本票裁定、拍賣抵押物裁定、大陸裁判經認可 → 沒有既判力 → 同一張圖但不畫斜線，事由在前（§14 II）在後（§14 I）都能提。

執行還沒開始就擔心被執行而預先提 §14 → 不行（20 年判例，沒有執行程序就沒有異議之訴）。

陷阱

講義 155 頁：確定判決執行，丙拍定領得權利移轉證書，乙於分配前主張「確定判決後」清償 → 新事由 → §14 ✓（答案 B），但拍賣已終結不能撤銷，只能就價金主張。156 頁拍賣抵押物裁定題 D 錯在「聲明異議並停止執行」——聲明異議不能停止執行；§14 或確認抵押權不存在之訴（釋字 182）才能。

§15 救濟的是「錯誤執行」——執行到非債務人的財產，第三人躺著也中槍。訴之聲明：某執行事件就某標的物之執行程序應予撤銷。

  • 假處分債權人 → ✗（70 年第 10 次決議：只禁止債務人處分，不排除法院強制執行；不能藉假處分變成優先受償）
規則

判斷原則一句話：第三人就標的物有物權等級的權利、因執行受侵害而法律上無忍受義務 → 得提。違建買賣移轉的是事實上處分權（不能登記），所以買受人要代位；附條件買賣兩面都保護是實務較特別的地方。

陷阱

109 年考題（講義 171 頁）就是違建代位這個最難的點，下堂複習。下堂從國家財產（講義「國資產」）開始。
