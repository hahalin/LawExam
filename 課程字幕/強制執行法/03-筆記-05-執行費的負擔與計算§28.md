# 強制執行法03 筆記：執行費的負擔與計算（§28）

## 誰負擔、誰先付：
- 執行費用以必要部分為限，由**債務人負擔**，與執行債權**同時收取**（分配表中與稅捐同列最前面）（§28 I）
- 執行法院**得命債權人代為預納**（§28 II）
- 不預納必要費用致程序不能進行 → **裁定駁回**聲請，確定後撤銷已為之執行處分（§28-1）

## 執行費用三塊：
- **執行費**（規費）：標的金額 **千分之八**，不分級累退；未滿 **5,000 元免徵**；非財產案件每件 **3,000 元**
- **參與分配費**：計算方式與聲請執行**相同**（千分之八），晚來不打折（§28-2 II）
- **必要費用**：鑑價費、保管費、登報費等，依實支

## 標的金額：
- 指債權人**請求實現**之債權額（可只執行一部分，但不得超過執行名義）
- 變價分割之執行：準用民訴 §77-11，以**聲請人因分割所受利益**計算

## 📖 法條原文速查

> **強執 §28**　I 強制執行之費用，以必要部分為限，由**債務人負擔**，並應與強制執行之債權同時收取。II 前項費用，執行法院得命**債權人代為預納**。
> **強執 §28-1 ②**　執行法院命債權人於相當期限內**預納必要之執行費用而不預納**者，致不能進行時，執行法院得以裁定駁回其強制執行之聲請，並於裁定確定後，撤銷已為之執行處分。
> **強執 §28-2 I**　執行標的金額或價額**未滿新臺幣五千元者，免徵**執行費；五千元以上者，每百元收七角（現依提高徵收標準為**八角**），不滿百元以百元計。II 前項規定，於**聲明參與分配**者，適用之。III 執行**非財產案件**，徵收執行費新臺幣**三千元**。VI 執行人員之食、宿、舟、車費，**不另徵收**。（原文請對六法）
> **強執 §30-1**　強制執行程序，除本法有規定外，**準用民事訴訟法**之規定。
> **民訴 §77-11**　分割共有物涉訟，以原告因分割所受利益之價額為準。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「強制執行費用最終由誰負擔？」 | **債務人**（§28 I），但得命**債權人預納** |
| 「執行費率？」 | 標的金額 **千分之八**（每百元八角），無分級累退 |
| 「執行標的 4,999 元，執行費？」 | **免徵**（未滿 5,000 元） |
| 「後來聲明參與分配之債權人須繳執行費？」 | **須**，與聲請執行者計算方式**相同**（§28-2 II） |
| 「非財產案件（如會面交往）執行費？」 | 每件 **3,000 元** |
| 「書記官、警察到場，須另付車馬費？」 | **不另徵收**（§28-2 VI） |
| 「確定判決 1,000 萬，只執行 100 萬，執行費以何計？」 | 以**請求實現之金額**（100 萬）計 |
| 「變價分割判決之執行費以何計？」 | 準用民訴 §77-11，以**聲請人因分割所受價額**計（持分小者聲請較省） |

## 一、執行費用體系

```
強制執行費用（§28：債務人負擔，債權人預納）
├── 執行費（規費，§28-2）
│   ├── 財產案件：千分之八；未滿 5,000 免徵
│   ├── 參與分配：同上
│   ├── 非財產案件：每件 3,000
│   ├── 罰鍰、怠金之執行：免徵（左手換右手）
│   └── 執行人員食宿舟車：不另收
└── 必要費用：鑑價、保管、登報…（實支）
```

## 二、不預納的後果

```
命債權人預納 → 期限內不預納 → 程序無從進行 → §28-1 裁定駁回
                                             → 確定後撤銷查封（起封）
未繳執行費 → 命補正 → 逾期不補 → 駁回聲請
```

## 三、變價分割執行費案例（講義實務問題）

```
甲、乙共有 A 地，甲持分大、乙持分小（持分數字請對講義）
乙以變價分割確定判決為執行名義聲請執行（走拍賣程序）
執行費如何核定？
→ §30-1 準用民訴 §77-11：以聲請人乙「因分割所受之價額」核定
→ 不以全部拍賣價金計算
→ 有反對意見認為取巧，多數意見：法律允許範圍內
```

- 建議：能執行全部就全部，避免剩餘部分日後時效問題（老師實務建議）
