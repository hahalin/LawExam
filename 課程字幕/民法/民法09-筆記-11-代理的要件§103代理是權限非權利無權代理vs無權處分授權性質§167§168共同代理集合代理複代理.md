# 民法09 筆記：代理的要件 §103——代理是權限不是權利；無權代理 vs 無權處分（本人名義 vs 自己名義）；代理權來源與授權的性質（§167 有相對人之單獨行為、中性行為、內部／外部授權）；限於法律行為（身分行為除外 §1076-2）；共同代理 §168 vs 集合代理；複代理

> 來源：民法09 課程字幕 02:01:00 ~ 02:28:01

## 📖 法條原文速查

> **§103**（代理行為之要件及效力）
> I 代理人於**代理權限內**，以**本人名義**所為之意思表示，直接對本人發生效力。
> II 前項規定，於應向本人為意思表示，而向其代理人為之者，準用之。
> **§104**　代理人所為或所受意思表示之效力，不因其為限制行為能力人而受影響。→ 反面：無行為能力人不得為代理人（下堂）
> **§167**　代理權係以法律行為授與者，其授與應向代理人或向代理人對之為代理行為之第三人，以意思表示為之。
> **§168**　代理人有數人者，其代理行為應**共同**為之。但法律另有規定或本人另有意思表示者，不在此限。
> **§1086 I、§1098 I、§1003 I**　父母、監護人、夫妻日常家務之法定代理
> **§1076-2 I**　被收養者未滿七歲時，應由其法定代理人代為並代受意思表示。→ 身分行為可代理的例外

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「代理之要件？」 | ① 有**代理權限**（法定或意定）② 以**本人名義**為意思表示 ③ 代理人**非無行為能力人**（§104 反面）→ 效果直接及於本人 |
| 「代理是權利？」 | **不是**。§103 用「權限」：資格、地位。不要寫「有代理的權利」 |
| 「無權代理 vs 無權處分？」 | 關鍵字：以**本人**名義（宣稱代理甲）→ 無權代理，債權、物權行為都效力未定，法律關係在甲丙間；以**自己**名義處分甲的物 → 無權處分，法律關係在乙丙間，債權行為有效、物權行為效力未定 |
| 「授與代理權之性質？」 | ① **有相對人之單獨行為**（不需相對人同意；被授權人不因此有權利義務）② **無損益之中性行為**（對限制行為能力人授權不須法代同意，類推 §77 但書）|
| 「授權方法？」 | **內部授權**（向代理人）或**外部授權**（向第三人），§167 兩者皆可 |
| 「侵權行為、事實行為得否代理？」 | **不得**，代理限於**法律行為、準法律行為**（須意思表示）|
| 「身分行為得否代理？」 | 原則**不得**（特重真意、無交易安全）；例外 **§1076-2 I** 未滿七歲被收養由法代代為代受 |
| 「本人授權 A、B、C 三人，A 單獨為之？」 | 原則**共同代理**（§168 本文）→ A 單獨＝無權代理；本人另有意思表示（三個房仲各管一區）→ **集合代理**（但書），須特約 |
| 「乙受甲授權後轉授權丙（複代理）？」 | 原則**無權代理、效力未定**（授權乙 ≠ 授權丙，代理著重信賴）；例外：經本人**同意**（律師衝庭代理條款）、或**無利害關係**（買杯飲料誰買都一樣） |

## 一、代理的結構與定位
```
甲（本人）──授權或法律規定──→ 乙（代理人）──以甲的名義向丙為意思表示──→ 效果直接及於甲
己願他力：我要效果，叫別人幫我做意思表示
代理是法律事實，「代理權」是權限（資格、地位），不是權利
```

## 二、無權代理 vs 無權處分：看用誰的名義
| | 無權處分 | 無權代理 |
|---|---|---|
| 乙用誰的名義 | **自己** | **本人（甲）**：宣稱代理甲 |
| 法律關係 | 乙丙間 | 甲丙間 |
| 效力 | 債權行為有效、物權行為 §118 效力未定 | 債權、物權行為**都**效力未定（§170）|
| 「本人」 | 權利義務歸屬對象（東西是誰的） | 同 |

## 三、代理權的來源
| 法定代理 | 意定代理 |
|------|------|
| §1086（父母）、§1098（監護人）、§1003（夫妻日常家務）；董事對法人是代表權，可類推 | 授權：以意思表示為之（§167）|

### 授權的性質（考試愛考）
```
① 有相對人的單獨行為：不需被授權人同意；他只取得資格，不取得權利義務（不幫你做也沒責任，除非另有委任、僱傭契約）
② 無損益的中性行為：對 10 歲小孩授權 → 不須法代同意（類推 §77 但書）→ 效果都在本人身上
③ 方法：內部授權（甲對乙說）／外部授權（甲對丙說）都可以
```

## 四、以本人名義「為意思表示」：限法律行為
- 法律行為、準法律行為可代理；侵權行為、事實行為不需意思表示 → 不能代理。
- 身分行為（結婚、離婚、收養、認領）特重真意、無交易安全 → 須親自為之；例外 §1076-2 I：未滿七歲被收養，由法代代為代受（收養是契約，一定要有意思表示，小孩自己做不了）。

## 五、代理人有數人
| | 共同代理（原則，§168 本文） | 集合代理（例外，§168 但書） |
|---|---|---|
| 方式 | 數人**共同**為之 | 各自**個別**為之 |
| 例 | 授權律師團、會計團、公關團一起談判 → 公關團單獨出手＝無權代理 | 三個房仲各管中正、萬華、大安區 |
| 要件 | 沒特別說就是這個 | 須本人**特約** |

## 六、複代理（多層代理）
```
甲授權乙，乙轉授權丙 → 丙代理甲？
原則：無權代理、效力未定——授權是信賴關係，我信賴你 ≠ 信賴別人；須甲承認
例外 ①：經甲同意 → 律師衝庭找同事代理，委任契約先寫同意條款
例外 ②：無利害關係 → 幫忙買 50 嵐四季春，誰買都一樣
考題：甲委託乙買土地，乙轉委託丙 → 乙是專家丙不是，價格可能差 100 萬 → 有利害 → 效力未定
```
