# 民法18 筆記：§191工作物所有人責任與§189之競合

## 三個推定：
- 設置或保管**並無欠缺** → 推定**不法**；損害**非因**欠缺所致 → 推定**因果**；已盡相當注意 → 推定**過失**
- 被告證明其中一項即可免責；設置＝興建時，保管＝蓋好後（電梯、水塔、管線定期保養；颱風前貼窗）

## 保護客體：
- 用語是「所致他人**權利**之損害」→ 限權利受侵害；王澤鑑認 §190、§191 都不保護過失造成的純粹經濟上損失，故意者回 §184 I 後段

## 必須是建築物本身：
- 含建築物之成分（天花板、樓梯、門窗、水電管線），**不含獨立設備**
- 火鍋店冷凍櫃起火延燒 → 冷凍櫃可移動、非工作物 → **無 §191**；電線走火要查是**管線**（有）還是**電器**（無）

## 負責人是所有人：
- §190 看占有、§191 看**所有**：持有房屋＝持有危險源，屬交易安全義務之具體化
- 房屋出租，承租人裝修致窗戶掉落砸傷丙 → 丙對承租人主張 §184（不是 §191），對屋主主張 §191；**出租不排除 §191**
- §191 II 求償權爭點同 §190 II（故意過失要件、時效）

## 與 §189 衝突：
- 屋主交承攬人施工，承攬人侵害丙：依 §191 屋主負責、依 §189 定作人不負責
- 95 台上 2550：§189 優先；109 年 1438 號：定作或指示**有過失**（§189 但書）仍可依 §191 負責
- 申論只考過一次，實務上很常用（工地、火災，原告免舉證三要件）

## 📖 法條原文速查

> **§191**　I 土地上之建築物或其他工作物所致他人**權利**之損害，由工作物之**所有人**負賠償責任。但其對於設置或保管**並無欠缺**，或損害**非因**設置或保管有欠缺，或於防止損害之發生，**已盡相當之注意**者，不在此限。II 前項損害之發生，如別有應負責任之人時，賠償損害之所有人，對於該應負責者，有求償權。

> **§189**　承攬人因執行承攬事項，不法侵害他人之權利者，定作人不負損害賠償責任。但定作人於**定作或指示有過失**者，不在此限。

## 📋 實務見解

> **107 年第 1611 號判決**（講義 178 頁註 277）：土地上工作物指以人工作成之設施；建築物內部設備如天花板、樓梯、門窗、水電管線，屬建築物成分應包括在內；機器或設備未安裝於土地而易於移動者，非土地上之工作物（冷凍櫃案）。（字幕未唸「台上」，字號請對講義）

> **95 年第 310 號判決**（註 278）：電線走火案，須區分電器或房屋管線起火。（字號請對講義）

> **93 年第 1175 號判決**（講義 180 頁）：所有人將建築物出租第三人，對其所致他人權利之損害，除證明但書情形外，所有人仍應負賠償責任。（字號請對講義）

> **95 台上 2550**（講義 181 頁）：承攬人執行承攬事項有獨立自主地位，定作人無監督權限；工作物雖屬定作人所有，因承攬人執行承攬事項不法侵害他人權利者，應**優先適用 §189**，不適用 §191。

> **109 年第 1438 號判決**（註 282）：非一有承攬關係即排除 §191，關鍵在屋主定作或指示有無過失。（字號請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§191 推定哪些要件？」 | **不法、過失、因果關係**三者（§190 只推定過失、因果） |
| 「§191 之責任主體？」 | 工作物**所有人**；承租人、占有人回 §184 |
| 「房屋出租後，所有人是否仍負 §191 責任？」 | **是**，出租不排除 §191 |
| 「店內冷凍櫃起火延燒鄰屋，得否依 §191 請求？」 | **否**，獨立可移動設備非工作物 |
| 「屋主交承攬人施工致第三人受損，屋主負 §191？」 | 95 台上 2550：**§189 優先**，定作無過失則不負；定作或指示有過失仍可能負責 |
| 「§191 保護純粹經濟上損失？」 | **否**，條文明文「權利」 |

## 一、§190 與 §191 比較

| | §190 | §191 |
|---|---|---|
| 責任主體 | 動物**占有人**（事實管領力） | 工作物**所有人**（危險源持有） |
| 推定 | 過失、因果 | **不法**、過失、因果 |
| 用語 | 加損害於他人 | 所致他人**權利**之損害 |
| 純粹經濟上損失 | 王澤鑑目的性限縮排除 | 文義即排除 |
| 第二項求償 | 有 | 有，爭點相同 |

## 二、三個推定與免責

```
被告證明任一項 → 不負 §191
├─ 設置或保管並無欠缺 ─────── 阻卻不法
├─ 損害非因設置保管欠缺所致 ── 因果不存在
└─ 防止損害已盡相當注意 ────── 無過失
```

## 三、出租案（窗戶掉落）

| 請求對象 | 請求權基礎 | 理由 |
|---|---|---|
| 承租人乙 | §184 I 前段 | 只是占有人，非所有人 |
| 所有人甲 | §191 I | 持有危險源；出租不免責 |

## 四、承攬案：§189 vs §191

```
甲（屋主、定作人）把 A 屋交乙承攬施工 → 乙侵害丙
├─ §191：甲是所有人 → 要負責
└─ §189：甲是定作人 → 原則不負責
   ├─ 定作指示無過失 → §189 優先，甲不負（95 台上 2550）
   └─ 定作指示有過失 → §189 但書，仍得令甲負責（109 年 1438 號）
```
- 兩判決不衝突：前者處理無過失、後者處理有過失
