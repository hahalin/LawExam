# 民法13 筆記：時效完成之效力——§144 I 抗辯發生主義（債務人得拒絕給付，請求權與債之關係不消滅）；§144 II 時效完成後仍為給付、以契約承認或提出擔保者，不得以不知時效為由請求返還（債務協商、重簽清償協議、再提供抵押或保證人＝拋棄時效抗辯）；「無請求權」≠「無效」：罹於時效之債仍是給付的法律上原因，不成立不當得利（§179）；§145 抵押權擔保之債權雖罹於時效仍得就抵押物取償，§880 五年除斥期間

> 來源：民法13 課程字幕 00:46:30 ~ 00:56:00

## 📖 法條原文速查

> **§144**　I 時效完成後，債務人得拒絕給付。II 請求權已經時效消滅，債務人仍為履行之給付者，不得以不知時效為理由，請求返還；其以契約承認該債務或提出擔保者亦同。
> **§145 I**　以抵押權、質權或留置權擔保之請求權，雖經時效消滅，債權人仍得就其抵押物、質物或留置物取償。
> **§880**　以抵押權擔保之債權，其請求權已因時效而消滅，如抵押權人，於消滅時效完成後，五年間不實行其抵押權者，其抵押權消滅。
> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。……

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「時效完成之效力？」 | **抗辯發生主義**：請求權不真的消滅，債務人取得拒絕給付之抗辯（§144 I）；與除斥期間（形成權真正消滅）不同 |
| 「債務人不知時效已完成而清償，得否依不當得利請求返還？」 | **不得**（§144 II）。罹於時效的債**沒有消滅**，買賣契約等債之關係仍在 → 受領有法律上原因 → §179 要件不備。「不知」是債務人自己的問題 |
| 「債務人不知時效完成，與債權人重簽清償協議（分 100 期）、或再提供土地設定抵押、再找保證人？」 | 以契約承認該債務、提出擔保 → **亦同**，不得再主張時效抗辯。所以債權人最愛罹於時效的債務人來協商；有時效抗辯的人要**積極主張** |
| 「無請求權 vs 無效？」 | 契約**無效** → 給付無法律上原因 → 不當得利 ✓。請求權**罹於時效** → 契約仍有效 → 有法律上原因 → 不當得利 ✗ |
| 「乙對甲之債權罹於時效，乙就甲之 A 地有抵押權，得否實行？」 | **得**（§145 I）。抵押權擔保的是甲乙間的債權，債權不因請求權罹於時效而消滅 → 抵押權仍在；但 §880：時效完成後**五年**不實行，抵押權消滅（除斥期間） |

## 一、§144 兩項

```
I  時效完成 → 債務人得拒絕給付（抗辯發生主義；不主張就沒有）
II 時效完成後 ① 仍為給付 ② 以契約承認該債務 ③ 提出擔保 → 不得以不知時效為由請求返還
```

- 實務現象：債務人不知有時效抗辯跑去談，債權人什麼條件都說好——一談就被當成拋棄時效抗辯。

## 二、無請求權 ≠ 無效（不當得利的「法律上原因」）

| | 契約無效 | 請求權罹於時效 |
|---|---|---|
| 債之關係 | 不存在 | **仍存在** |
| 給付之法律上原因 | 無 | 有 |
| §179 | ✓ 得請求返還 | ✗（§144 II 就是這個意思） |

- 例：乙對甲之價金請求權逾 §127 ⑧ 二年，甲不知仍付款 → 買賣契約還在 → 乙受領有法律上原因 → 甲不得請求返還。不當得利不問受損人有無故意過失，縱不知時效亦同。

## 三、§145 擔保物權不受影響，§880 另設除斥

```
乙對甲債權罹於時效 → 甲只是多了一個時效抗辯，債權本身還在
抵押權擔保的是這個債權 → 債權在、抵押權在 → §145 仍得就抵押物取償
§880：時效完成後五年內不實行 → 抵押權消滅（除斥期間，物權再講）
```
