# 民法01 筆記：民法體系鳥瞰與法源（§1、§2）

> 來源：民法01 課程字幕 00:03:00 ~ 00:08:50、00:27:30 ~ 00:32:57

---

## 📖 法條原文速查

> **§1**（法源）
> 民事，法律所未規定者，依**習慣**；無習慣者，依**法理**。

> **§2**（習慣之限制）
> 民事所適用之習慣，以**不背於公共秩序或善良風俗**者為限。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「民事事件法律無明文，法院得否以無法律規定為由不予裁判？」 | **不得**。§1：無法律→習慣→法理，一定要處理（與刑法罪刑法定相反） |
| 「民間『賣祖產應先問近親』習慣，可否作為優先購買權依據？」 | **不可**。該習慣妨礙物的流通→背於**公共秩序**→§2 不得適用 |
| 「§2 的習慣限制，是公序還是良俗？」 | 兩者都是限制；賣產先問近親是**公共秩序**（經濟秩序），與善良風俗無關 |
| 「民法五大編 / 民總各章的條號範圍？」 | 見下方體系圖 |

## 一、民法的位置：私法

```
法律
├── 公法：國家 ↔ 人民（上下關係）
└── 私法：人民 ↔ 人民（平行關係）← 民法在這裡
```

## 二、五大編

```
民法
├── 財產法
│   ├── 總則    ：原理原則的統一規定
│   ├── 債編    ：人 ↔ 人的債權債務關係
│   └── 物權編  ：人 ↔ 物的支配關係
└── 身分法
    ├── 親屬編  ：身分關係的發生與權利義務（結婚、認領、收養）
    └── 繼承編  ：人死後法律關係的變動
```

## 三、民法總則的章節與條號

| 單元 | 條號 | 一句話 |
|------|------|--------|
| 法例 | §1～§5 | 法源順序、習慣限制、數量記載 |
| 權利主體：自然人 | §6～§24 | 權利能力、行為能力、死亡宣告、住所 |
| 權利主體：法人 | §25～§65 | 社團、財團 |
| 權利客體：物 | §66～§70 | 動產不動產、主物從物、孳息 |
| **法律行為** | §71～§118 | **民總核心**：生效要件、意思表示、條件期限、代理、無效撤銷 |
| 期日期間 | §119～§124 | 期間計算 |
| 消滅時效 | §125～§147 | 時效期間、中斷、完成效果 |
| 權利之行使 | §148～§152 | 誠信原則、正當防衛、緊急避難、自助行為 |

> 老師會提前用到後面的概念：§184 侵權行為、§179 不當得利、§118 無權處分、§801/§948 善意取得、§767 物上請求權。第一次卡住先空著，之後補回來。

## 四、§1 法源順序：民法沒有「無法可管」

```
遇到民事糾紛
    │
    ├── 法律有規定 → 依法律
    │
    └── 法律沒規定 → 依習慣
                       │
                       └── 沒習慣 → 依法理
```

| 比較 | 刑法 | 民法 |
|------|------|------|
| 法律沒規定時 | 無罪（罪刑法定） | **仍須處理**，找習慣、法理 |
| 思考方向 | 不該當構成要件就結束 | 一定要給當事人一個答案 |

## 五、§2 習慣的限制：案例「賣產應先問近親」

### 事實
1. 丙死亡，遺產 A 地由甲、乙共同繼承。
2. 甲乙**分割**為 A1、A2（分割後已非共有）。
3. 甲欲將 A1 賣給丁。乙主張依民間習慣有優先購買權。

### 分析

**（一）法律有沒有規定優先購買權？**
- §426-2：租用基地建築房屋的優先購買權 → 本件無租賃，不適用。
- 土地法 §34-1 IV：共有人優先購買權 → 本件已分割，非共有，不適用。
- → 法律無規定，進入 §1 第二順位：習慣。

**（二）習慣存在嗎？**
- 台灣民間確有「賣產應先問近親」的習慣。

**（三）§2 檢驗：是否背於公共秩序或善良風俗？**
```
賣產先問近親
    → 要賣自己的土地得先問完親戚才能賣外人
    → 阻礙物的流通 → 阻礙經濟發展
    → 妨害「公共秩序」（經濟秩序）
    → §2：不得作為民法上的習慣
```
- 注意：與**善良風俗**無關，是**公共秩序**的問題。

**（四）結論**
- 無法律、無（合法）習慣、亦無法理可據 → 乙**無**優先購買權，主張無理由。
