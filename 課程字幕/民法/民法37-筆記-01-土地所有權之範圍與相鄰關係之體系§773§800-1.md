# 民法37 筆記：土地所有權之範圍與相鄰關係之體系（§773、§800-1）

## 銜接前講：
- 民法36 結束在取得時效之中斷（§771，見民法36-筆記-12）；本講從**不動產所有權**（§773～§800-1）開始

## 土地所有權的範圍（§773）：
- 不動產分土地與定著物；定著物有固定形體，範圍好認，土地是平面，所以要定範圍
- §773：除法令限制外，於行使有利益之範圍內，**及於土地之上下**（立體的、3D 的）
- 但他人干涉**無礙**所有權行使者，**不得排除**
  - 飛機從上空飛過、高鐵捷運從地下穿過、管線埋在地下 → 不能收過路費
  - 理由：一條管線可能通過上百筆土地，每筆都要談，成本太高；互利共生、物盡其用

## 相鄰關係的共同原則：
- 土地彼此緊密相鄰，一方使用必然影響他方
- 基本公式：**容忍＋補償**
  - 對方有正當事由（排水、通行、管線通過）→ 你要容忍
  - 對你造成損害 → 可請求償金

## 規範對象擴及利用人（§800-1）：
- 條文主詞都是「土地所有人」，但承租人、地上權人一樣有通行、排水的需要
- §800-1：§774 至 §800 的規定，於**地上權人、農育權人、不動產役權人、典權人、承租人**及其他土地、建築物或工作物利用人**準用**
- 例：袋地的承租人也可主張袋地通行權；越界建築規定也可由承租人主張

## 不動產所有權的體系：
```
不動產所有權（§773～§800-1）
├── 土地所有權範圍：§773
├── 相鄰關係：§774～§798
│     ├── 袋地通行權：§787～§789（常考）
│     ├── 越界建築：§796～§796-2（選擇題幾乎每年一題）
│     └── 其他：鄰地損害、水流、枝根越界等（看法條即可）
├── 建築物區分所有：§799～§800（與共有重疊，講完共有再回來）
└── 用益權人等準用：§800-1
```

## 📖 法條原文速查

> **§773**（土地所有權之範圍）
> 土地所有權，除法令有限制外，於其行使有利益之範圍內，**及於土地之上下**。如他人之干涉，**無礙其所有權之行使者，不得排除之**。

> **§800-1**（相鄰關係之準用）
> 第七百七十四條至前條規定，於**地上權人、農育權人、不動產役權人、典權人、承租人**、其他土地、建築物或其他工作物利用人**準用**之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「土地所有權之範圍是否及於土地上下？」 | **是**，限於行使有利益之範圍（§773） |
| 「捷運從地下通過，地主得否排除？」 | 無礙所有權行使者，**不得排除** |
| 「土地承租人得否主張袋地通行權？」 | **得**，§800-1 準用 |
| 「相鄰關係規定僅適用於土地所有人？」 | **錯**，地上權人、農育權人、不動產役權人、典權人、承租人等準用 |
