# 民法17 筆記：執行職務之客觀說與內在關聯說

## 判斷順序：
- ①是不是**職務本體**（與職務內容直接相關）→ 是就屬執行職務
- ②不是職務本體 → 是否**利用職務機會**、與職務有**客觀關聯** → 完全無關就不是執行職務（例：員工下班開自己的車撞人）
- ③有客觀關聯 → 兩說分歧

## 兩說：
- **客觀說（實務多數）**：有客觀關聯就過關，不另考慮僱用人能否預見
- **內在關聯說（王澤鑑）**：客觀關聯之外，還要**為僱用人所能預見**；僱用人預見得到才能事先分散風險，才有令其負責的必要
- 實務兩說慢慢都有出現，但大多仍以客觀說判斷

## 區分兩說的典型案例：
- 貨運司機下班開公司的車去買宵夜、把公司車開回家停 → 非職務本體，但有客觀關聯
- 貨車司機送完貨，回程順路去接小孩 → 非職務本體；利用送貨回程的機會 → 客觀說即過關；內在關聯說要再問：老闆知不知道他常順路接小孩

## 📖 法條原文速查

> **§188 I 前段**　受僱人因**執行職務**，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「受僱人下班後駕駛自用車肇事，僱用人應否負 §188？」 | **否**，與職務完全無關 |
| 「貨運司機下班駕公司貨車買宵夜肇事？」 | 非職務本體，但**利用職務機會**、有客觀關聯 → 客觀說肯定 |
| 「實務判斷執行職務多採何說？」 | **客觀說**（不問僱用人能否預見） |
| 「內在關聯說比客觀說多了什麼要件？」 | **僱用人預見可能性**（王澤鑑） |
| 「利用職務機會為之的行為是否屬執行職務？」 | 客觀說：**是**（有客觀關聯） |

## 一、判斷流程

```
受僱人的行為
│
├─ 職務本體？──────────── 是 → 執行職務 ✓
│      │否
├─ 利用職務機會／客觀關聯？─ 否 → 非執行職務 ✗（下班開自用車）
│      │是
├─ 客觀說（實務）──────── → 執行職務 ✓
└─ 內在關聯說（王澤鑑）── 僱用人能預見？
                          ├─ 能 → ✓
                          └─ 不能 → ✗
```

## 二、兩說比較

| | 客觀說 | 內在關聯說 |
|---|---|---|
| 客觀關聯 | 需要 | 需要 |
| 僱用人預見可能性 | 不需要 | **需要** |
| 理由 | 保護被害人 | 僱用人預見得到，才能事先分散風險 |
| 採用者 | 實務多數 | 王澤鑑 |

## 三、案例：送貨回程接小孩

| 審查 | 結果 |
|---|---|
| 職務本體 | ✗（接小孩不是工作） |
| 客觀關聯 | ✓（利用送貨回程） |
| 客觀說 | 執行職務 ✓ |
| 內在關聯說 | 看老闆知不知道他常順路接小孩 |
