# 民法39 筆記：抵押物之範圍從物從權利與附加物（§862§877-1）

## 從物（§862 I）：
- 主物之處分及於從物（§68 II）→ 抵押權效力也及於從物，維持利用一體

## 從權利（§862 I）——要分三種：
- **非坐落所需**的從權利（例：不動產役權）→ §862 I，直接為抵押權**效力所及**，可優先受償
- **坐落所需**的權利（例：房屋坐落土地的**租賃權**）→ 依特別規定 **§877-1 併付拍賣**：不是效力所及，可以一起賣，但就該部分價金**不得優先受償**
- 坐落所需的權利是**地上權** → **§838 III**：地上權與建物不得分離設定權利，須**一併設定**抵押權（99 年修法後；之前是併付拍賣）
- 「併付拍賣」與「效力所及」的差別：前者只是一起賣，後者連價金都能優先受償

## 附加物（§862 III）：
- 限於「**以建築物為抵押**」；土地上新蓋房屋是 §877 的問題，不是本項
- 情境：透天厝設定抵押後，往後推出廚房、旁邊加蓋廁所、頂樓加蓋鐵皮屋
- **不具獨立性**（使用上與構造上都不獨立：沿牆增建、無獨立出入口、無獨立功能）→ 建物的一部分，**效力所及**
- **具獨立性**（頂樓鐵皮屋有外牆樓梯直通一樓、獨立車庫或倉庫）
  - 抵押權設定**前**就存在 → 不及、也不能併拍
  - 設定**後**才附加 → **準用 §877 併付拍賣**，價金不得優先受償（讓房屋與車庫一起賣，買受人不必再向他人租車庫）

## 思考順序：
1. 有無**使用上、構造上獨立性**？無 → 建物一部分，效力所及
2. 有 → 是不是**從物**（§68）？是 → §862 I 效力所及
3. 不是從物 → 獨立附加物，依 §862 III 看設定前後

## 從物四要件（§68）：
- 非主物之成分、常助主物之效用、與主物同屬一人、交易上無特別習慣
- 房屋後面的養魚池、養豬場 → 不助房屋之效用，**非從物**
- 兒子在父親房屋旁蓋車庫 → 不同屬一人，**非從物**，只是獨立附加物

## 考題：加油站
- 就加油站旁的房屋設定抵押，後來擴建為加油站，底下管線、油槽連接
- 實務：與房屋無法分離，使用上構造上一體 → **不具獨立性**，整座加油站為效力所及，一起拍賣並優先受償

## 📖 法條原文速查

> **§862**（抵押權效力及於標的物之範圍）
> I 抵押權之效力，及於抵押物之**從物與從權利**。
> II 第三人於抵押權設定前，就從物取得之權利，不受前項規定之影響。
> III 以**建築物**為抵押者，其附加於該建築物而**不具獨立性**之部分，亦為抵押權效力所及。但其附加部分為獨立之物，如係於抵押權**設定後**附加者，準用第 877 條之規定。

> **§877-1**（建物存在必要權利之併付拍賣）以建築物設定抵押權者，於法院拍賣抵押物時，其抵押物存在所必要之權利得讓與者，應**併付拍賣**。但抵押權人對於該權利賣得之價金，**無優先受償之權**。

> **§877 I**（營造建物之併付拍賣）土地所有人於設定抵押權後，在抵押之土地上營造建築物者，抵押權人於必要時，得於強制執行程序中聲請法院將其建築物與土地併付拍賣。但對於建築物之價金，無優先受償之權。

> **§838 III**　地上權與其建築物或其他工作物，**不得分離**而為讓與或設定其他權利。

> **§68**（主物與從物）I 非主物之成分，常助主物之效用，而同屬於一人者，為從物。但交易上有特別習慣者，依其習慣。II 主物之處分，及於從物。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「房屋抵押，坐落土地之租賃權？」 | **併付拍賣**，價金不得優先受償（§877-1） |
| 「房屋抵押，坐落之地上權？」 | 須**一併設定**（§838 III） |
| 「抵押後沿牆增建之廚房？」 | 不具獨立性，**效力所及** |
| 「抵押後另建獨立車庫？」 | 準用 §877 **併付拍賣**，不得優先受償 |
| 「抵押前已存在之獨立倉庫？」 | **不及**，也不併拍 |
| 「§862 III 適用於土地抵押？」 | **否**，限以建築物為抵押 |
| 「子於父屋旁蓋車庫是否從物？」 | **否**，不同屬一人 |
