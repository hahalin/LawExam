# 民法03 筆記：無權代表——§27 III 與 §31 怎麼分、「得對抗」是什麼

> 來源：民法03 課程字幕 00:00:01 ~ 00:11:41

---

## 📖 法條原文速查

> **§27 III**（代表權之限制）
> 對於董事**代表權所加之限制**，不得對抗**善意**第三人。

> **§31**（登記之效力）
> 法人登記後，有**應登記之事項而不登記**，或已登記之事項有變更而不為變更之登記者，**不得以其事項對抗第三人**。
> → 沒有「善意」兩個字

> **§48 I ④⑧、§61 I ⑥⑦**（應登記事項）
> 董事之姓名及住所；定有代表法人之董事者，其姓名。→ 建議查閱最新六法原文

> **§170 I**（無權代理）
> 無代理權人以代理人之名義所為之法律行為，非經本人承認，對於本人不生效力。

> **§87 I 但書**（對照：另一個「不得對抗」）
> 通謀虛偽意思表示無效，但不得以其無效對抗善意第三人。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「無代表權之董事代表法人為法律行為，不得對抗善意第三人？」 | **錯**。那是 **§31**：有登記就可對抗、沒登記就不可對抗，**與善惡意無關** |
| 「董事代表權受限制，法人得否以該限制對抗第三人？」 | **§27 III**：第三人善意 → 不得對抗；惡意 → 得對抗 |
| 「§27 III 與 §31 的判斷標準各是什麼？」 | §27 III 看**善惡意**；§31 看**有無登記** |
| 「法人得對抗第三人時，該行為效力？」 | 行為人成**無權代表** → **類推 §170** → 效力未定，看法人承不承認 |
| 「法人不得對抗第三人時？」 | 第三人說了算 → 視為有權代表 → 契約有效，第三人得請求法人履約 |

---

## 一、先判斷「甲是誰」

```
甲「代表」A 法人與 B 締約
│
├── 甲是董事 ＋ 有代表權 ＋ 無限制 → 有權代表 → 效力直接及於 A（董事＝法人手足）
│
├── 甲是董事 ＋ 有代表權 ＋ 代表權受限制（例：不得為不動產交易）→ 【§27 III】看 B 善惡意
│
├── 甲是董事但無代表權（代表權被剝奪）        ┐
└── 甲不是董事（董事的弟弟、好友、已卸任董事） ┘→ 【§31】看有無登記
```

- 為什麼後兩種走 §31？「誰是董事」「哪個董事有代表權」都是**應登記事項**（§48 I ④⑧、§61 I ⑥⑦）。
- 為什麼第二種不走 §31？代表權的「限制」不是應登記事項，所以不管登記，直接看 §27 III。

### 考試最愛的交叉陷阱
```
§27 III：有善惡意 → 「不得對抗善意第三人」
§31    ：無善惡意 → 「非經登記不得對抗第三人」
→ 題目把兩條混寫：「無代表權董事……不得對抗善意第三人」→ 錯
```

## 二、「得對抗／不得對抗」到底在講什麼

- **對抗是抗辯權的概念**：一定先有對方的主張，才有「對抗」可言。看到「不得對抗 XXX」，先問 XXX 想幹嘛。
- 第三人 B 想幹嘛？B 只在乎一件事：**契約有效、A 要履約** → B 會主張「甲有權代表」。
- A 能不能用「甲代表權受限制／甲沒登記為董事」這件事去擋 B 的主張，就是「對抗」。

### 以 §27 III 為例

```
B 主張：甲有權代表 → 契約有效 → A 履約
    │
    ├── B 善意 → A【不得對抗】→ B 說了算
    │              → 甲視為有權代表 → 買賣契約有效 → B 得請求 A 履行
    │
    └── B 惡意 → A【得對抗】→ A 說了算
                   → 甲是無權代表（逾越限制＝無代表權）
                   → 民法對代表沒規定 → 類推最像的「無權代理」§170
                   → 效力未定 → A 承認 → 有效；A 拒絕 → 不生效力
```

- §31 的操作一樣：有登記 → A 得對抗 → 走下面那條；沒登記 → A 不得對抗 → 走上面那條。

## 三、答題順序

```
① 甲是誰？（董事？有代表權？受限制？）
② 用哪條？（限制 → §27 III；不是董事／無代表權 → §31）
③ 那條的判斷標準？（善惡意／有無登記）
④ 得對抗 → 類推 §170 效力未定；不得對抗 → 契約有效
```
