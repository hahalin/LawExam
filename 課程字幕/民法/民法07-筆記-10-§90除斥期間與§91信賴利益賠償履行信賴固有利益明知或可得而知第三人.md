# 民法07 筆記：§90 一年除斥期間與 §91 信賴利益賠償——履行利益／信賴利益／固有利益的區分、「明知或可得而知」＝善意且無過失、§91 的「第三人」是誰

> 來源：民法07 課程字幕 01:27:16 ~ 01:50:39

---

## 📖 法條原文速查

> **§90**　前二條之撤銷權，自意思表示後，經過**一年**而消滅。
> **§91**　依第八十八條及第八十九條之規定撤銷意思表示時，表意人對於**信**其意思表示為有效而受損害之**相對人或第三人**，應負賠償責任。但其撤銷之原因，受害人**明知或可得而知**者，不在此限。

> 信賴利益的四個條文：**§91**（錯誤撤銷）、**§110**（無權代理人責任，通說接近信賴利益）、**§245-1**（締約上過失）、**§247**（自始客觀不能）
> 履行利益的條文：**§226、§227**（給付不能、不完全給付）、債各 **§360**（物之瑕疵）、**§495**（承攬瑕疵）等
> **§179**　不當得利　　**§767 I 前段**　所有物返還

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§88 撤銷權之除斥期間？」 | 自**意思表示後一年**（§90），不是自知悉時起 |
| 「§91 損害賠償之性質？」 | **信賴利益**（為締約所支出的成本，因契約無效而成為損害），**不包含履行利益** |
| 「信賴利益 vs 履行利益？」 | 契約**無效或不成立** → 信賴利益（§91、§110、§245-1、§247）；契約**有效而不履行** → 履行利益（債務不履行 §226、§227 等） |
| 「固有利益？」 | 與契約無關、本來就有的利益 → 侵權行為或加害給付處理 |
| 「§91 但書『明知或可得而知』？」 | 排除惡意（明知）與善意有過失（可得而知）→ 受害人須**善意且無過失**始得請求 |
| 「乙花 3 萬鑑定後以 20 萬買畫，甲撤銷，乙得請求多少？」 | **3 萬**締約成本（信賴利益）；80 萬履約獲利是履行利益，契約無效不存在 |
| 「乙轉賣善意丙，丙善意取得，丙得否依 §91 向甲請求鑑定費？」 | **不得**。丙已善意取得標的物，**無損害** |
| 「§91 之『第三人』指？」 | 王澤鑑：用於**無相對人之法律行為**（如拋棄→先占人），有相對人者看相對人 |

## 一、§90：撤銷要在一年內
- 從意思表示時起算一年，不是從發現錯誤起算。撤銷後依 §114 自始無效 → 衍生無權處分、善意受讓等問題。

## 二、三種利益

```
利益來自契約？
├── 是
│    ├── 信賴利益：為締約付出的成本（鑑定費、車馬費）
│    │    契約有效 → 成本自己吸收，不是損害
│    │    契約無效／不成立 → 白花了 → 損害 → §91、§110、§245-1、§247
│    └── 履行利益：契約履行後能得到的獲利
│         契約有效對方不履行 → 損害 → 債務不履行 §226、§227、§360、§495……
│         契約無效 → 對方本來就不用履行 → 不存在履約獲利 → 不是損害
└── 否 → 固有利益（本來就有的）→ 侵權行為／加害給付
```

| | 信賴利益 | 履行利益 |
|---|---|---|
| 前提 | 契約**無效、不成立** | 契約**有效** |
| 內容 | 締約成本 | 履約獲利 |
| 條文 | §91、§110、§245-1、§247 | §226、§227、§360、§495…… |
| 關鍵字 | §91 的「**信**其意思表示為有效」 | 債務不履行 |

### 案例一
```
乙花 3 萬請專家鑑定 → 專家說高度可能是真跡 → 乙 20 萬向甲買（若為真跡可獲利 80 萬）
甲發現畫是真的 → §88 II 物的性質視為內容錯誤 → 撤銷
乙對甲 §91：只能要 3 萬（信賴利益），不能要 80 萬（履行利益——契約無效，履約獲利不存在）
```

## 三、§91 但書：明知或可得而知 → 善意且無過失
```
§88 要表意人無過失才能撤 → 衡平：§91 要受害人也無過失才能請求
明知 ＝ 惡意（故意）
可得而知 ＝ 不知道，但有過失
排除這兩種 → 剩下【善意且無過失】才能依 §91 請求
→ 法條有時正面寫「善意且無過失」，有時反面寫「明知或可得而知者不在此限」，意思一樣
```

## 四、案例二：畫轉了兩手，錢怎麼算
```
A 畫市價 100 萬（真跡）。甲誤以為仿作，30 萬賣乙（乙花 3 萬鑑定）；乙 100 萬賣善意丙（丙也花 3 萬鑑定）
① 甲→丙 §767？甲依 §88 II 撤銷（假設無過失）→ 甲乙買賣、物權行為無效 → 乙未取得
   乙丙買賣有效、物權行為無權處分 → 丙善意 → §801＋§948 善意取得 → 甲非所有人 → §767 ✗
② 甲→乙：乙賣掉甲的畫得 100 萬 → 權益歸屬說，畫從未屬於乙 → 100 萬是畫的代替利益 → §179 返還 100 萬
③ 乙→甲：價金 30 萬 §179 返還 ＋ 鑑定費 3 萬 §91 信賴利益 ＝ 33 萬；70 萬差價是履行利益 ✗
④ 丙→甲 §91 要 3 萬？文義上丙是「第三人」、善意無過失、有信賴……但丙**沒有損害**——他善意取得畫了 → ✗
```

### 那 §91 的「第三人」是誰
- 王澤鑑：§91 寫「相對人**或**第三人」→ 有相對人的法律行為看相對人；**無相對人的法律行為**（單獨行為）看第三人。
- 例：甲把 A 車丟路邊（拋棄），乙以為無主物先占；甲說拋棄的意思表示有錯誤要撤銷 → 乙不是相對人（拋棄沒有相對人），但因撤銷受損 → 乙就是 §91 的第三人。
