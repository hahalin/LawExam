# 民法37 筆記：共有物之處分與土地法第34條之1（§819）

## 應有部分 vs 共有物：
- 應有部分是自己的 → 自由處分（見本講筆記-11）
- 共有物是大家的 → §819 II：處分、變更、設定負擔須**全體同意**
- 但共有**土地或建築改良物**有**土地法 §34-1 I** 的多數決特別規定，優先適用
- 老師：土地法 §34-1 **每年都考**，當民法念

## 土地法 §34-1 I 的多數決：
- 共有人**過半數**及應有部分合計**過半數**同意
- 應有部分合計**逾 2/3** → 人數不計
- 計算以**登記簿**記載的人數與應有部分為準；共有人死亡，計入繼承人及其應繼分（執行要點第 7 點）

## 射程：哪些可以多數決？
| 行為 | 適用 | 依據 |
|---|---|---|
| **動產**的任何處分 | 民法 §819 II 全體同意 | 土地法只管土地、建物 |
| **有償**移轉（買賣） | 土地法 §34-1 I 多數決 | 執行要點第 3 點：處分以有償讓與為限 |
| **有償**設定地上權、農育權、不動產役權、典權 | 多數決 | 同上 |
| 變更（如地目變更） | 多數決 | 以有償或不影響他共有人利益為限 |
| **無償**移轉（贈與）、無償設定用益物權 | §819 II 全體同意 | 不在「有償」範圍 |
| 設定**抵押權** | §819 II 全體同意 | 條文只列四種用益物權，沒有抵押權 |
| 信託、交換所有權（互易） | §819 II 全體同意 | 執行要點排除；互易可能達到類似分割的結果 |
| **分割** | §823 以下 | 分割既非管理也非處分，是消滅共有關係的獨立制度 |

- 為什麼抵押權不能多數決：設定擔保對不同意的人只有不利；5 人共有、4 人同意就拿去抵押，等於多數暴力
- 分割不能偷渡：不能說「分割也是處分，所以多數決」

## 爭點：多數決把土地賣給共有人之一
- 甲乙丙丁共有 A 地，各 1/4；甲乙丙依多數決把 A 地賣給丙
- 問題：丙本應透過分割（協議須全體同意、不成則裁判分割）才能取得全部；改用多數決，丁的 1/4 被強迫賣給丙，結果與分割無異
- **修法前**：法無限制，最高法院 **103 台上 2333** 在計算上動手腳
  - 同意處分的共有人**兼為承受人**時，其人數與應有部分**不計入**
  - 本例只剩甲乙 2/4，人數與應有部分都未過半 → 不能多數決
- **修法後**：執行要點第 3 點第 2 項明定，共有人除依法優先購買外，**不得為受讓人**（老師說 112 年修正，建議查證）
  - → 直接不能賣給共有人
- 答題：先寫現行規定直接禁止；若題目時點在修法前，用 103 台上 2333 的計算方式

## 違反同意門檻的處分效力：
- 動產較常發生（不動產登記時地政機關會審同意書，除非偽造同意書）
- 兩說：
  - **無效說**：第三人**不能**善意取得
  - **無權處分說**（通說）：**效力未定**，其他共有人承認即生效；第三人可主張**善意取得**
- 通說理由：**保護交易安全**
  - 例：甲乙丙共有一輛車，甲未經全體同意賣給丁並交付 → 丁善意且無重大過失可善意取得
  - 土地：偽造同意書辦妥登記，第三人信賴登記，可依 §759-1 II 取得

## 解題流程：
```
共有物要處分
├─ 動產 → §819 II 全體同意
└─ 土地、建物
     ├─ 有償移轉、有償設定用益物權、變更 → 土地法 §34-1 I 多數決
     │     └─ 受讓人是共有人？→ 現行執行要點：不得
     ├─ 無償、設定抵押權、信託、互易 → §819 II 全體同意
     └─ 分割 → §823 以下
違反門檻 → 無權處分（效力未定）→ 善意第三人可善意取得
```

## 📖 法條原文速查

> **§819 II**　共有物之**處分、變更、及設定負擔**，應得**共有人全體之同意**。

> **土地法 §34-1 I**
> 共有土地或建築改良物，其處分、變更及設定**地上權、農育權、不動產役權或典權**，應以共有人**過半數**及其應有部分合計**過半數**之同意行之。但其應有部分合計**逾三分之二**者，其人數不予計算。

> **土地法第三十四條之一執行要點第 3 點**（講義註釋 236，要旨）
> 本法條第一項所定處分，以**有償讓與**為限，不包括**信託行為**及**共有物分割**；變更以有償或不影響不同意共有人之利益為限；設定地上權、農育權、不動產役權或典權，以**有償**為限。第 2 項：共有人除依本法條規定**優先購買**外，**不得為受讓人**。

## 📋 實務見解速查

> **最高法院 103 年台上字第 2333 號判決**（講義註釋 234）：部分共有人依土地法 §34-1 I 處分共有土地，其處分不包括分割；承受人雖不以共有人以外之人為限，惟同意處分之共有人兼為承受人時，有利害衝突、顯失公平，其人數及應有部分均不得計入同意處分之共有人數及應有部分。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「共有動產之出賣得否多數決？」 | **不得**，§819 II 全體同意 |
| 「共有土地設定抵押權，得否依土地法 §34-1 多數決？」 | **不得**，回歸 §819 II 全體同意 |
| 「共有土地贈與他人？」 | 無償，須**全體同意** |
| 「共有土地分割得否依土地法 §34-1？」 | **不得**，依 §823 以下 |
| 「應有部分合計逾 2/3 但人數未過半？」 | **可以**，人數不計 |
| 「多數決將共有土地賣給共有人之一？」 | 現行執行要點：**不得**為受讓人；修法前實務：該共有人不計入 |
| 「未經全體同意處分共有動產之效力？」 | 通說**無權處分**，效力未定，第三人得善意取得 |
