# 民法40 筆記：抵押土地上建物之併付拍賣基本型（§866§877§877-1）

## 共同原則
- 抵押權設定後，所有人怎麼利用都可以，但**不能影響抵押權**
- 最極端是叫人拆屋，但蓋 300 萬、拆再 300 萬，社會成本浪費 → 改用**併付拍賣**

## 類型一：設定抵押後，土地所有人自己蓋房（§877 I）
- 甲以空地 A 設定抵押給乙，之後甲在 A 地蓋 B 屋
- 乙於必要時，得於強制執行程序中**聲請**法院將 A、B **併付拍賣**
- 價金分配：A 地價金乙優先受償；**B 屋價金乙無優先受償權**，歸蓋屋的甲
- 好處：房屋不拆；土地附現成房屋較好賣

## 類型二：設定抵押後，承租人蓋房（§877 II＋§866）
- 甲以 A 地設定抵押給乙 → 甲把 A 地租給丙 → 丙蓋 B 屋
- 兩步驟：
  1. 依 **§866 II** 除去（終止）租賃關係——否則買賣不破租賃，地價下跌
  2. 依 **§877 II** 準用 I，將 A、B 併付拍賣；B 屋價金還給丙
- 「受有影響」是隱藏要件：債權 500 萬、地價 1,000 萬、帶租約可賣 800 萬 → 仍足額，**沒有影響**，不能除去

## 選擇題細節：誰發動
- **§866 II**：「**法院得**除去該權利或終止租賃關係」→ 法院**職權**即可
- **§877 I**：抵押權人「得……**聲請**法院」併付拍賣 → 須抵押權人聲請，法院不能職權併拍

## 類型三：承租人蓋房後以房屋設定抵押（§877-1）
- 甲把 A 地租給丙 → 丙蓋 B 屋 → 丙以 B 屋設定抵押給乙（租賃在抵押之前）
- 乙實行抵押權時，房屋存在所必要且**得讓與**的權利（租賃權）**應**併付拍賣
- B 屋價金乙優先受償；租賃權價金乙無優先權，歸丙
- 對照用語：§877 I「**得**聲請」可併可不併；§877-1「**應**併付拍賣」一定要併，否則拍定人買到沒有坐落權源的房屋

> 來源：民法40 課程字幕 00:59:09 ~ 01:13:53；字幕「因併付拍賣」為「應併付拍賣」、「867」為「877」之口誤

## 📖 法條原文速查

> **§866 II**（除去用益權利）前項情形，抵押權人實行抵押權受有影響者，法院得除去該權利或終止該租賃關係後拍賣之。

> **§877 I、II、§877-1** → 建議查閱最新六法原文（要點：§877 I 抵押權人於必要時得聲請併付拍賣，建物價金無優先受償權；II §866 II、III 之情形準用；§877-1 房屋存在所必要之權利得讓與者應併付拍賣）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 抵押後所有人蓋屋，抵押權人可否併付拍賣 | 可，§877 I，須**聲請** |
| 房屋價金是否優先受償 | **否** |
| 抵押後出租、承租人蓋屋 | 先 §866 II 除去租賃，再 §877 II 併拍 |
| §866 除去是否須聲請 | **不必**，法院職權 |
| 以房屋抵押，租賃權如何處理 | §877-1 **應**併付拍賣 |
| 租賃妨礙但地價仍足清償 | 未受影響，不得除去 |

## 三種基本型比較

| 類型 | 時間順序 | 處理 | 依據 |
|---|---|---|---|
| 一 | 地抵押 → 所有人蓋屋 | 地屋併拍（聲請） | §877 I |
| 二 | 地抵押 → 出租 → 承租人蓋屋 | 除去租賃（職權）＋併拍 | §866 II、§877 II |
| 三 | 出租 → 承租人蓋屋 → 屋抵押 | 屋＋租賃權併拍（應） | §877-1 |

## 解題第一步

```
先找「抵押權設定時點」
  ├─ 在它之後發生的負擔 → 不得影響抵押權（除去／併拍）
  └─ 在它之前就存在的 → 抵押權人設定時已可預見，原則尊重
```
