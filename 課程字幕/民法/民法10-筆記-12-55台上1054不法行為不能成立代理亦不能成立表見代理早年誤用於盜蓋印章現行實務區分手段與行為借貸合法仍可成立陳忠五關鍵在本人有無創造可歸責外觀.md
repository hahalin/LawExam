# 民法10 筆記：55 台上 1054「不法行為不能成立代理，亦不能成立表見代理」——判例本身沒錯，錯在被誤用：早年實務以「盜蓋、偽刻印章是不法行為」否定表見代理；現行實務區分**手段**（盜蓋印章）與**行為**（借貸）——借貸合法，仍可成立表見代理；陳忠五：合法不法根本不是重點，重點是本人有無創造可歸責的授權外觀

> 來源：民法10 課程字幕 01:58:00 ~ 02:06:39（講義 270 頁）

---

## 📋 實務見解速查

> **最高法院 55 年台上字第 1054 號判例**（字號照字幕，建議查閱）：表見代理云者，即代理人雖無代理權，而因有可信其有代理權之正當理由，遂由法律課以授權人責任之謂；而代理權僅限於意思表示範圍以內，不得為意思表示以外之行為，故**不法行為及事實行為不僅不得成立代理，且亦不得成立表見代理**。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲將身分證、印章交乙保管，乙盜蓋印章以甲名義向丙借款後逃逸；丙得否依 §169 要甲為借款契約負責？」 | **可能成立**表見代理（現行實務）。盜蓋、偽刻印章是**手段**（有刑責），借貸才是**法律行為**本身——借貸合法 → 可成立代理，也可成立表見代理 |
| 「55 台上 1054 判例錯了嗎？」 | 判例本身**沒錯**：行為本身若是不法行為（詐騙、侵權）或事實行為，本來就不能代理、也不能表見代理。錯在六七十年代實務望文生義，把「手段不法」當「行為不法」 |
| 「陳忠五對此爭議的看法？」 | 最高法院前後見解都沒抓到表見代理的本質：能不能要甲負責，與行為合法不法**無關**；關鍵是**甲有沒有創造讓丙相信乙有代理權的可歸責外觀**。甲把身分證印章交乙保管 → 有創造外觀 → 不管乙是合法蓋章還是盜蓋，只要造成丙的信賴就有 §169 適用 |

## 一、判例的正確理解

```
代理只能用在意思表示（法律行為、準法律行為）
→ 不法行為（侵權）、事實行為本身不能代理 → 當然也不能表見代理 ✓ 這段沒問題
```

## 二、誤用：手段 vs 行為

```
甲 ─交身分證、印章保管─→ 乙 ─盜蓋印章，以甲名義向丙借錢─→ 丙交付借款 → 乙捲款跑
早年實務：盜蓋、偽刻印章＝不法行為 → 不法行為不能成立代理 → 不能成立表見代理 → 甲不負責
現行實務：盜蓋印章是「手段」，法律行為是「借貸」→ 借貸本身不具不法性 → 仍可成立代理、可成立表見代理
```

| | 手段 | 行為 |
|---|---|---|
| 本案 | 盜蓋／偽刻印章（有刑責） | 消費借貸（合法） |
| 判例適用對象 | — | 行為本身不法（詐騙、侵權）才排除 |

- 50 幾年的判例出來後，民國六七十年代很多法官光看判例就這樣論述；後來最高法院意識到手段與行為是不同概念，做了判決以正視聽。

## 三、陳忠五：回到表見代理的本質

```
問題不是「合法蓋章 or 盜蓋」
問題是「甲有沒有創造一個讓丙相信乙有代理權的可歸責外觀」
甲主動把身分證印章交給乙 → 有 → 只要造成丙的信賴 → 有 §169 適用
（對照筆記 10：鎖保險櫃被偷 → 沒有創造外觀 → 無 §169）
```
