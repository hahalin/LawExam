# 民法05 筆記：純獲法律上利益的三個特殊案例——附抵押權土地、贈與稅、附負擔贈與 §412

> 來源：民法05 課程字幕 00:48:39 ~ 01:00:15

---

## 📖 法條原文速查

> **§77 但書**　純獲法律上利益者，不須允許。

> **§867**（抵押權之追及效力）
> 不動產所有人設定抵押權後，得將不動產讓與他人。但其抵押權不因此而受影響。
> → 受贈人成為抵押人（物上保證人），但不是債務人、不是保證人

> **§412 I**（附負擔之贈與）
> 贈與附有負擔者，如贈與人已為給付而受贈人不履行其負擔時，贈與人得**請求受贈人履行其負擔**，或**撤銷贈與**。
> → 負擔不履行：只能命履行或撤銷，**沒有損害賠償**

> **§406**（贈與之定義）
> 稱贈與者，謂當事人約定，一方以自己之財產無償給與他方，他方允受之契約。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「祖父瞞著父母將設有抵押權之土地贈與並移轉登記予限制行為能力之孫，物權行為效力？」 | **有效**（王澤鑑）。成為抵押人不負任何義務，只是土地價值較低 → 仍純獲法律上利益 |
| 「受贈土地須繳贈與稅，是否仍純獲法律上利益？」 | **是**（王澤鑑）。稅捐是**公法上義務**，不是贈與契約的效果；純獲法律上利益從**民法**角度判斷 |
| 「附負擔之贈與對限制行為能力人是否純獲法律上利益？」 | **否**（王澤鑑）。負擔不履行時贈與人得**命其履行** → 非單純享受權利 → §79 效力未定 |
| 「負擔與債務之別？」 | 債務不履行 → **損害賠償**；負擔不履行 → 只能**命履行或撤銷贈與**（§412），無賠償 |
| 「抵押人與保證人之別？」 | 抵押人最多**土地被拍賣**（不足不補、有剩歸還）；保證人要**以全部財產負責** |

## 一、案例一：附抵押權的土地

#### 事實
祖父十年前將 A 地設定抵押權給銀行。祖父想把地留給孫子甲（限制行為能力人），瞞著甲的父母找代書辦贈與並移轉登記。

#### 分析
```
未經允許 → 先看例外：純獲法律上利益？
甲取得 A 地 → 依 §867 抵押權不受影響 → 甲變成【抵押人】（第三人抵押／物上保證）
    甲有義務嗎？
    ✗ 甲不是債務人（不用還錢）
    ✗ 甲不是保證人（不用以全部財產負責）
    → 銀行最多把 A 地拍賣，優先受償；有剩還給甲，不足也不用補
→ 王澤鑑：附抵押權只影響【土地的價值】，不使甲負擔義務 → 仍純獲法律上利益 → 物權行為有效
```

## 二、案例二：要繳贈與稅

```
甲受贈 A 地 → 要繳贈與稅 → 有「純」嗎？
王澤鑑：繳稅是【稅法／公法上】的義務，不是贈與契約的效果
    純獲法律上利益是在【民法】這個法律關係裡問有沒有義務
    贈與無償，甲在民法上沒有任何義務
→ 仍純獲法律上利益 → 贈與契約有效
```

## 三、案例三：附負擔的贈與（§412）

#### 事實
乙送甲（高中生）一台 6 萬元筆電，但要甲幫忙管理乙的社群帳號。

#### 負擔 vs 債務

| | 債務 | 負擔 |
|---|---|---|
| 不履行的效果 | 債務不履行 → **損害賠償** | 贈與人得**命履行**或**撤銷贈與**（§412），**無賠償** |
| 強度 | 強 | 弱 |

#### 分析
```
負擔不是債務，但乙仍可【命甲履行】
→ 王澤鑑：甲並非單純享受權利 → 不是純獲法律上利益
→ 贈與契約 §79 效力未定
```

## 四、四個爭點一覽

| 爭點 | 結論 | 關鍵 |
|------|------|------|
| 物權行為獨立判斷 | 移轉標的物給限制行為能力人的物權行為有效 | 義務來自債權行為不是物權行為（上一份筆記） |
| 附抵押權土地 | 純獲法律上利益 | 抵押人無義務，只是土地價值低 |
| 附稅捐 | 純獲法律上利益 | 公法義務不算 |
| 附負擔贈與 | **不**純獲法律上利益 | 可被命履行 |
