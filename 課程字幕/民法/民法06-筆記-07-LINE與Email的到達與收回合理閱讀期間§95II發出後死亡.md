# 民法06 筆記：用 LINE／Email 為意思表示的「到達」與「收回」——合理閱讀期間；§95 II 發出後死亡

> 來源：民法06 課程字幕 01:00:26 ~ 01:08:15

---

## 📖 法條原文速查

> **§95**
> I 非對話而為意思表示者，其意思表示，以通知達到相對人時，發生效力。但撤回之通知，同時或先時到達者，不在此限。
> II 表意人於**發出通知後**死亡或喪失行為能力或其行為能力受限制者，其意思表示，**不因之失其效力**。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲 9:00 以 LINE 傳要約予乙，9:05 收回，乙尚未已讀，要約效力？」 | 傳統解釋：9:00 已到達手機 → 收回無效。**陳聰富**：以相對人**合理閱讀期間**（實際閱讀或可合理預期閱讀之時）為生效時點 → 已讀前收回 → **撤回有效** |
| 「乙已讀後甲才收回？」 | 已生效 → 收回無效 → 要約仍有效 |
| 「§95 I 但書在電子通訊時代的問題？」 | 傳到即到達 → 永遠無法先時或同時到達 → 但書變**具文** → 須重新解釋「到達」 |
| 「此種解釋方法？」 | 老師：社會學解釋——讓法律解釋符合社會現狀與科技發展 |
| 「表意人發出要約後死亡／受監護宣告，要約效力？」 | **不受影響**（§95 II）。以**發出時**有行為能力為準；後續由繼承人／監護人處理 |

---

## 一、問題：網路沒有時間差

```
9:00 甲 LINE 傳要約 → 同一秒到達乙的手機
9:05 甲「收回」訊息
傳統解釋：9:00 已置於乙隨時可瞭解之地位 → 已到達、已生效 → 9:05 收回無意義
→ §95 I 但書「同時或先時到達」在 LINE／Email 永遠做不到 → 條文變具文
```

## 二、解法：重新定義電子意思表示的「到達」

```
民國 19 年制定民法時：寄信十幾二十天、坐輪船半年 → 時間差明顯
現在：瞬間到達 → 但人不是瞬間看
    → 把「時間差」往後拉，用【已讀】當比較基準
    → 收回在已讀之前 → 撤回有效（A 要約不生效）
    → 收回在已讀之後 → 撤回無效（A 要約有效）
```
- 陳聰富（講義 153 頁、註 70 文章）：應以**收件人實際閱讀**，或**寄件者可合理預期收件人閱讀**的時間，作為生效時點；不以一般的到達時點比較。
- 老師：這是「社會學解釋」——法律不是現在制定的，透過解釋讓它跟上時代，在修法或特別法制定前，民法仍可處理。

| | 傳統信件 | LINE／Email |
|---|---|---|
| 到達 | 進信箱 | 相對人合理閱讀期間（實際已讀或可合理預期閱讀時） |
| 撤回成功 | 撤回通知先時或同時進信箱 | 收回在已讀之前 |

## 三、§95 II：發出後死亡或喪失行為能力

```
甲發出要約 → 到達乙之前，甲死亡／受監護宣告
→ 意思表示不受影響（以發出時有行為能力為準）
→ 甲死亡：法律關係由繼承人承受；甲受監護：由監護人處理
```
- 以前坐輪船寄信半年才到，中間什麼都可能發生；現在機率低，但條文沒爭議，考試會設計這種案例。
