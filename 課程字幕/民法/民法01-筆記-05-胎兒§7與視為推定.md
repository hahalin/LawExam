# 民法01 筆記：胎兒 §7 與「視為／推定」

> 來源：民法01 課程字幕 00:45:30 ~ 01:13:44

---

## 📖 法條原文速查

> **§7**（胎兒之權利能力）
> 胎兒以**將來非死產者為限**，關於其**個人利益之保護**，**視為既已出生**。
> → 要件 2 個 + 效果 1 個

> **§99**（條件）
> I 附**停止條件**之法律行為，於條件成就時，**發生**效力。→ 先無後有
> II 附**解除條件**之法律行為，於條件成就時，**失其**效力。→ 先有後無

> **§1166 I**（胎兒應繼分之保留）
> 胎兒為繼承人時，非保留其應繼分，他繼承人不得分割遺產。

> **§1063 I**（婚生推定）
> 妻之受胎，係在婚姻關係存續中者，**推定**其所生子女為婚生子女。

> **§1065 I 前段**（認領之效力）
> 非婚生子女經生父認領者，**視為**婚生子女。

> **§192、§194**（侵害生命權之賠償）→ 見「權利能力」筆記
> **§184 I、§195 I**（侵害身體健康之賠償）
> §195 I 前段：不法侵害他人之身體、健康……得請求賠償相當之金額。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§7『將來非死產』通說採何說？」 | **法定解除條件說**：先給權利能力，死產才溯及消滅 |
| 「胎兒父被撞死，胎兒可否於出生前即依 §192、§194 請求？」 | **可**（解除條件說，先視為既已出生） |
| 「父死留債務千萬，胎兒是否視為既已出生而繼承債務？」 | **否**。§7 限於「個人利益之保護」，純負擔義務不適用 |
| 「胎兒提告後死產，尚未賠償？」 | 權利能力溯及消滅 → 無權利受侵害 → **原告之訴駁回** |
| 「胎兒提告後死產，已賠償 300 萬給母親代收？」 | 加害人依 **§179** 向母親請求返還（法律上原因已不存在） |
| 「孕婦被撞致胎兒死產，母親可否以胎兒生命權受侵害依 §192、§194 請求？」 | **不可**。死產→胎兒非人→無生命權。母親僅能以**自己**身體健康權受侵害依 **§184 + §195** 請求 |
| 「『視為』與『推定』之別？」 | 視為：與事實相反的法律擬制，**不得舉反證推翻**；推定：預設事實，**得舉反證推翻** |
| 「題目沒說死產，胎兒權利能力？」 | 直接當作**有**（視為既已出生），不要自己加死產假設 |

## 一、§7 的結構

```
要件 1：將來非死產
要件 2：關於其個人利益之保護
效果  ：視為既已出生
```

## 二、要件 1「將來非死產者為限」怎麼解？——借 §99 條件的概念

### 停止條件 vs 解除條件

```
停止條件（§99 I）：成立 ─✗停住─→ 條件成就 → 生效        【先無後有】
解除條件（§99 II）：成立 ─✓生效─→ 條件成就 → 失效        【先有後無】
```

### 套到胎兒

| | 法定停止條件說 | 法定解除條件說（通說） |
|---|---|---|
| 現在（還是胎兒） | **沒有**權利能力 | **有**權利能力（視為既已出生） |
| 將來順產 | 這時才給 | 維持 |
| 將來死產 | 本來就沒有 | **溯及消滅** |
| 能否現在提告 | 不能，等出生 | **能** |

### 為什麼通說採解除條件說？
- 文義上兩說都通，要靠**目的解釋**。
- §7 的目的：**保護胎兒**（不然 §6 已經說出生才有，幹嘛再訂 §7）。
- 哪一說更能提早保護？先給、死產再收回 → **解除條件說**。

## 三、要件 2「關於其個人利益之保護」——胎兒是雙標仔

```
對胎兒有利 → 視為既已出生 → 出來主張
對胎兒不利（純負擔義務）→ §7 不適用 → 不出來
```

| 情形 | 胎兒視為既已出生？ |
|------|------|
| 父死留遺產 100 萬 | **是**，可繼承；§1166 他繼承人須保留應繼分才能分割 |
| 父死只留債務千萬 | **否**，不繼承債務 |
| 有遺產也有債務 | 加減後有剩餘才算有利益（概括繼承有限責任，§1148 II） |

## 四、效果「視為既已出生」——視為 vs 推定

| | 視為 | 推定 |
|---|---|---|
| 本質 | 立法者為達某目的**擬制**一個與事實相反的狀態 | 立法者**預設**一個事實狀態 |
| 可否舉反證推翻 | **不可** | **可** |
| 態度 | 「我說的算」 | 「我先假設，錯了你舉證」 |
| 例 | §7 視為既已出生；§1065 認領視為婚生 | §9 推定死亡；§1063 婚生推定 |

- §1065：父母根本沒結婚，但一認領就「視為」婚生 → 不能舉「他們沒結婚」推翻。
- §1063：立法者也不確定孩子是不是丈夫的，只敢「推定」→ 可舉反證（DNA）推翻。

## 五、§7 的兩種考法

### 考法一：胎兒的父（或母）被侵害

#### 事實
甲懷胎 10 週，甲的配偶乙被丙開車撞死。胎兒 A 可否對丙依 §192、§194 請求？

#### 分析
```
A 現為胎兒 → §7：關於個人利益之保護（身分權：對父的扶養、慰撫金）
    → 視為既已出生（解除條件說：先給）
    → A 有權利能力 → 得依 §192 II、§194 請求
```
→ **可以現在就告**。

#### 後續：如果 A 死產了？（題目常寫「母傷心過度流產」）

| 情形 | 處理 |
|------|------|
| 尚未判決／尚未賠償 | 權利能力溯及消滅 → A 無權利 → 無權利受侵害 → **原告之訴駁回** |
| 丙已和解賠償 300 萬（由母甲代理受領） | 丙依 **§179** 向甲請求返還 300 萬 |

§179 涵攝（已賠償的情形）：
```
甲受有利益      ：代收 300 萬 ✓
無法律上原因    ：原因是「侵權行為損害賠償」；A 死產 → 無權利能力 → 不構成侵權行為
                 → 法律上原因不存在 ✓
致丙受損害      ：丙付了 300 萬 ✓
```

### 考法二：胎兒本身受傷

#### 事實
丙撞孕婦甲，超音波顯示胎兒 A 腦部損傷。

#### 分析
- A 在母體內、尚未死產 → §7 視為既已出生 → 有身體健康權 → 得依 **§184** 請求。
- 將來死產 → 同上：未賠償則駁回、已賠償則 §179 返還。

#### 考試真正要你注意的：母親甲能主張什麼？

```
胎兒 A 死產
    → §7 要件「將來非死產」不成立
    → 不再視為既已出生 → A 從未出生 → 無權利能力
    → 無生命權 → 不會有「生命權受侵害」→ 沒有「致死」這個結果
    → §192、§194（要件：不法侵害他人致死）不該當
```
→ 甲**不能**以 A 的生命權受侵害請求 §192、§194。
→ 甲只能以**自己的身體健康權**受侵害，依 **§184 + §195** 請求。

> 實務新聞：台南孕婦 36 週遇車禍胎死腹中，家屬想告過失致死，檢察官認為不成立「致死」——同一個邏輯。
> 美國「心跳法案」思維（有心跳即為人）與我國民法衝突：人工流產必然死產 → 依 §7 根本未取得權利能力 → 無侵害胎兒生命權可言。

## 六、答題口訣

```
題目沒寫死產 → 胎兒就有權利能力，直接用 §7 視為既已出生
題目後面寫死產 → 權利能力溯及消滅
    ├── 沒賠 → 原告之訴駁回
    └── 賠了 → §179 拿回來
母親自己的損害 → §184 + §195（身體健康權），不是 §192、§194
```
