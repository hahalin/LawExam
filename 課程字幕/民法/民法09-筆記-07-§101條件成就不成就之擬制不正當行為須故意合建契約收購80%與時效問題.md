## 📖 法條原文速查

> **§101**（條件成就或不成就之擬制）
> I 因條件成就而受不利益之當事人，如以**不正當行為**阻其條件之成就者，**視為條件已成就**。
> II 因條件成就而受利益之當事人，如以不正當行為促其條件之成就者，**視為條件不成就**。
> **§127 ⑦**　技師、承攬人之報酬及其墊款 → 二年短期時效
> **§128**　消滅時效，自請求權**可行使時**起算。……

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§101 之『不正當行為』須故意或過失？」 | **以故意為限**，過失不構成 |
| 「甲允諾乙考上即贈車，考前在乙的水中下瀉藥使其無法應試？」 | 受不利益之當事人以不正當行為阻止條件成就 → **視為條件已成就** |
| 「合建契約約定『周邊土地收購達 80% 時付款』，定作人故意不收購？」 | 以不正當行為阻其條件成就 → 視為成就 → 承攬人得請求付款 |
| 「同上，完工於 100 年，103 年起訴，定作人主張承攬報酬 §127 ⑦ 二年時效？」 | 視為成就後請求權「可行使」時點如何認定（§128 主觀說／客觀說）→ 解套：**時效停止**或**誠信原則**；時效章再講 |
| 「地主買賣農地約定建照申請失敗即解約，地主拒絕配合下鄉耕種一年，是否不正當行為？」 | 老師經辦案件：法院認地主無此義務 → 非不正當行為 → 單純解除條件成就 → §179 互相返還 |

## 一、條文邏輯
```
會因條件成就而吃虧的人，故意阻止它成就 → 當作已經成就（§101 I）
會因條件成就而得利的人，故意促成它成就 → 當作沒有成就（§101 II）
「不正當行為」＝故意；過失不算
```

## 二、案例：合建契約擺爛（台大法研所約 100～102 年考題）
```
甲（開發商）與乙（建商）約定：周邊土地收購達 80% 時甲開始付款
乙蓋到一定程度，甲都不收購、一直拖延（「地主很難配合」）→ 擺爛
第一小題：乙能否請求付款？
→ 甲是條件成就受不利益之人，故意不收購＝不正當行為阻止成就 → §101 I 視為成就 → 乙可請求
```

### 第二小題：時效（進階，時效章再講）
```
乙 100 年完工，忍到 103 年起訴
甲抗辯 ①條件未成就 ②若視為成就 → 承攬報酬 §127 ⑦ 二年時效已過
→ 甲立於不敗之地？
問題 ①：§128「可行使時」採主觀說還是客觀說
問題 ②：採客觀說時如何解套 → 時效停止制度／誠信原則
```

## 三、老師的農地案：什麼不算不正當
- 農地買賣附解除條件「建照申請被駁回則契約作廢」。買方主張地主「不配合」（要地主到光復鄉下耕種一年才能申請）＝不正當方法。法院：地主無此義務，不算不正當 → 單純解除條件成就 → 契約失效 → §179 互相返還。
