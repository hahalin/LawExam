# 民法10 筆記：無權代理體系——廣義（§107 越權代理、§169 表見代理、§170 狹義無權代理）vs 狹義（§170）；大原則：本人不承擔被無權代理的風險（本人沒有創造公示外觀，與無權處分不同），善意相對人靠 §110 求償；例外：本人可歸責創造授權外觀＋相對人善意且無過失 → 本人負授權人責任（權利外觀理論／法外觀理論）；王澤鑑認 §107 亦為表見代理，考試仍稱越權代理

> 來源：民法10 課程字幕 01:06:00 ~ 01:18:21

---

## 📖 法條原文速查

> **§107**　代理權之限制及撤回，不得以之對抗善意第三人。但第三人因過失而不知其事實者，不在此限。
> **§169**　由自己之行為表示以代理權授與他人，或知他人表示為其代理人而不為反對之表示者，對於第三人應負授權人之責任。但第三人明知其無代理權或可得而知者，不在此限。
> **§170 I**　無代理權人以代理人之名義所為之法律行為，非經本人承認，對於本人不生效力。
> **§110**　無代理權人，以他人之代理人名義所為之法律行為，對於善意之相對人，負損害賠償之責。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「狹義無權代理？廣義無權代理？」 | 狹義＝**§170**；廣義＝§107 越權代理＋§169 表見代理＋§170。選擇題出現過這組用語 |
| 「乙無代理權，以甲名義與丙為法律行為，乙丙間效力？」 | **乙丙間不生任何法律效果**：乙用甲的名義，丙沒有要跟乙做法律行為的意思 |
| 「無權代理為何原則上本人不負責，與無權處分不同？」 | 無權處分：本人把物交給乙（借、被騙、通謀），**創造了占有的公示外觀**，要為外觀負責 → 善意第三人可善意受讓。無權代理：本人**什麼都沒做**，誰都可能被人在外面宣稱是其代理人 → 本人不承擔風險，§170 效力未定由本人決定，善意相對人改向乙依 §110 求償 |
| 「何時例外要本人負責？」 | ① 本人有**創造授權外觀的可歸責事由**（交付身分證印章、不反對他人宣稱代理、授權後撤回卻沒人知道）＋ ② 相對人**善意且無過失**（信賴值得保護）→ 依 §107 或 §169 負**授權人責任** |
| 「權利外觀理論（法外觀理論）？」 | 本人可歸責＋相對人信賴值得保護 → 縱行為效力有瑕疵，本人仍負授權人責任。信賴保護原則推出來的，票據法也用。§107、§169 都是這個模型的具體化 |
| 「§107 與 §169 之異同？」 | 同：相對人皆須善意且無過失、效果皆為本人負授權人責任。異：**歸責事由不同**（§107 授權後限制／撤回；§169 行為表示授權／明知不反對）。王澤鑑：§107 也是表見代理；但實務稱 §107 **越權代理**、§169 **表見代理**，考試照實務用語 |

## 一、體系

```
無權代理（廣義）
├ §107 越權代理（代理權之限制或撤回）─┐ 本人可歸責＋相對人善意無過失
├ §169 表見代理                        ─┘ → 本人負授權人責任（例外）
└ §170 狹義無權代理 → 效力未定，本人承認／拒絕；善意相對人 §110 向無權代理人求償（原則）
```

## 二、大原則：為什麼本人不用為無權代理負責

| | 無權處分 | 無權代理 |
|---|---|---|
| 本人做了什麼 | 把車借給乙、被騙交付、通謀交付 → 乙占有 | 什麼都沒做 |
| 公示外觀 | 有（占有／登記）→ 本人要為自己創造的外觀負責 | 無（我在這裡上課，外面有人宣稱是我的代理人，我渾然不知） |
| 善意第三人保護 | 善意受讓（§801、§948、§759-1） | 不能善意受讓（筆記 13）；改向無權代理人 §110 求償 |
| 本人 | 失去權利 | §170 效力未定，自己決定承認或拒絕 |

- 乙丙間：乙以甲名義為之，丙無與乙締約之意 → 乙丙間不發生直接法律效果。

## 三、例外：權利外觀理論（法外觀理論）

```
要件 ① 本人有「創造權利外觀」的可歸責事由
     ② 相對人信賴值得保護 ＝ 善意且無過失
效果   縱行為效力有瑕疵，本人仍負授權人責任（＝當作有權代理，不是損害賠償）
```

- 例：把身分證、印章、印鑑交乙保管；乙對外宣稱是我的代理人而我不反對；曾授權後撤回但沒人知道。
- 票據法的權利外觀理論（老師那年代念李欽賢老師學說；字幕音譯「李清賢」，建議查閱）不是獨門暗器，就是信賴保護原則在民事法的具體表現。

## 四、§107 vs §169：同一個模型，只差歸責事由

| | §107 越權代理 | §169 表見代理 |
|---|---|---|
| 歸責事由 | 授權後**限制或撤回**，外觀殘留 | **行為表示**授權（無授權意思）；**明知他人表示為代理人而不反對** |
| 相對人 | 善意且無過失（但書「因過失而不知」排除） | 善意且無過失（但書「明知或可得而知」排除） |
| 效果 | 「不得對抗善意第三人」＝第三人可要求本人負授權人責任，本人不得以限制撤回抗辯 | 直接寫「負授權人責任」 |

- 王澤鑑：兩者法理相同，§107 亦為表見代理。考試不建議這樣寫——實務用語 §107 越權代理、§169 表見代理。
