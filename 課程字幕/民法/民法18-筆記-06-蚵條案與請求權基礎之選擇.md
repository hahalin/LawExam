# 民法18 筆記：蚵條案與請求權基礎之選擇

## 事實（講義 193 頁）：
- 榮民工程公司（榮工處）在雲林離島工業區附近海域抽砂，未做好環境評估，漂砂污染海域
- 蚵苗無法順利附著於蚵農放置的蚵條，或長成後含砂量高乏人問津 → 蚵農無法收成

## 第一步：有無權利受侵害（§184 I 前段）：
- 陳忠五：肯定，蚵條**物之功能性減損**＝侵害所有權之使用收益權能（§765）
- 多數說：否定，蚵條**未毀損滅失** → 屬純粹經濟上損失

## 第二步：§184 I 後段：
- 陳聰富：肯定，其對故意與背俗一向從寬——**重大輕率**可視為故意，未做環評違反社會共同生活準則
- 多數說：否定，抽砂不以損害蚵農為目的，無故意

## 第三步：§191-3：
- 實務：肯定，§191-3 含純粹經濟上損失；抽砂具環境污染之**非日常危險**，榮工處藉此獲利
- 王澤鑑：否定，§184 不成立就不能「躲回」§191-3，兩者只差舉證責任、保護法益相同

## 請求權基礎怎麼選（老師作答習慣）：
- 先判斷有無**絕對權**受侵害 → 有就用 §184 I 前段；純粹經濟上損失再看 §184 I 後段、II、§190～§191-3
- 單純車禍：涵攝 §184 I 前段，§184 II、§191-2 用「或可依…並此敘明」帶過
- 題目暗示**無法證明過失** → §191-2 必寫；給出**違規事實**（超速、邊開車邊滑手機）→ §184 II 必寫
- 多數人、法代、僱用人、動物、工作物 → 直接以特殊侵權行為涵攝；§184 只在 §185、§187、§188 需要行為人成立侵權時才展開

## 📖 法條原文速查

> **§184 I**　因故意或過失，不法侵害他人之**權利**者，負損害賠償責任。故意以**背於善良風俗**之方法，加損害於他人者亦同。

> **§765**　所有人，於法令限制之範圍內，得自由**使用、收益、處分**其所有物，並排除他人之干涉。

> **§191-3**（要旨）　經營事業或從事活動之人，其活動或工具方法有生損害於他人之危險者，對他人之損害應負賠償責任；推定因果與過失。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「蚵條案依陳忠五見解，蚵農得否依 §184 I 前段請求？」 | **得**，物之功能性減損＝所有權侵害 |
| 「依多數說，蚵條案屬何種損害？」 | **純粹經濟上損失**（蚵條未毀損滅失） |
| 「蚵條案依實務得否依 §191-3 請求？」 | **得**，§191-3 含純粹經濟上損失 |
| 「依王澤鑑，§184 I 後段不成立時得否改依 §191-3？」 | **否** |
| 「陳聰富如何處理重大輕率？」 | 可視為**故意**，從寬適用 §184 I 後段 |

## 一、蚵條案思考流程

```
蚵農受損
   ↓
有無權利受侵害？
├─ 有（陳忠五：物之功能性減損）→ §184 I 前段 ✓
└─ 無（多數：蚵條未毀損）→ 純粹經濟上損失
      ↓
   §184 I 後段？
   ├─ 陳聰富：重大輕率＝故意，未環評＝背俗 → ✓
   └─ 多數：不以損害為目的，無故意 → ✗
      ↓
   §191-3？
   ├─ 實務：含純粹經濟上損失，抽砂屬環境污染危險 → ✓
   └─ 王澤鑑：§184 不成立不能躲回 §191-3 → ✗
```
