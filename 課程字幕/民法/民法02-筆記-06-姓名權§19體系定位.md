# 民法02 筆記：姓名權 §19 的體系定位

> 來源：民法02 課程字幕 01:08:00 ~ 01:17:14

---

## 📖 法條原文速查

> **§19**（姓名權之保護）
> 姓名權受侵害者，得請求法院**除去**其侵害，並得請求**損害賠償**。

> **§18 II**
> 前項情形，以法律有特別規定者為限，得請求**損害賠償或慰撫金**。

> **§184 I 前段**
> 因**故意或過失**，不法侵害他人之權利者，負損害賠償責任。

> **§195 I 前段**
> 不法侵害他人之身體、健康、名譽、自由、信用、隱私、貞操，或不法侵害**其他人格法益而情節重大**者，被害人雖非財產上之損害，亦得請求賠償相當之金額。
> → 注意：**§195 沒有「姓名」**

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§19 之除去請求，須加害人有故意過失？」 | **不須**，與 §18 I 同解釋 |
| 「§19 之損害賠償，須加害人有故意過失？」 | 學者認為**須**，受 §184 限制（體系解釋，侵權行為以過失責任為原則） |
| 「姓名權受侵害請求慰撫金，是否須情節重大？」 | **有爭議**：王澤鑑 → 走 §195「其他人格法益」須情節重大；陳聰富 → §19 損害賠償含慰撫金，不須情節重大 |
| 「§18 II 的『損害賠償』是否包含慰撫金？」 | **不含**（文義：「損害賠償**或**慰撫金」並列）→ 王澤鑑據此認為 §19 的損害賠償也不含慰撫金 |
| 「考試姓名權受侵害，請求權基礎寫什麼？」 | **直接寫 §184**，不會錯；§19 頂多當確認性規範 |

---

## 一、姓名權是什麼

- 姓名是人的外在象徵，「見名如見人」。名字被濫用 → 姓名權受侵害。
- §19 給兩個效果：**除去** ＋ **損害賠償**。問題是這條在體系裡到底算什麼？

## 二、除去：跟 §18 一樣，不要故意過失

- §19 前段與 §18 I 前段作用相同，無爭議。

## 三、損害賠償：要不要故意過失？

```
§19 文義：「姓名權受侵害者」七個字，沒有故意過失
    → 直接當請求權基礎 → 無過失也要賠？
    ✗ 與侵權行為法「過失責任原則」不合
    → 體系解釋：§19 的損害賠償受 §184 限制，仍以故意過失為必要
```
- 同一句「姓名權受侵害者」，解釋會分岔：
  - 除去 → 與 §18 同（不要故意過失）
  - 損害賠償 → 與 §184 同（要故意過失）
- 另一說：§19 只是**確認性規範**（確認姓名權是人格權、可請求賠償），不是請求權基礎，損害賠償直接用 §184。

### 老師的考試建議
- 題目明顯有故意過失 → **直接拿 §184** 當請求權基礎，可補一句「§19 縱得適用亦受 §184 限制」。
- 題目故意寫「key 錯名字、電腦自動選字、無過失」→ 這時才把 §19 文義 vs §184 的爭點拿出來寫。

## 四、慰撫金：走 §195 還是走 §19？（核心爭點）

### 問題
姓名權不在 §195 I 列舉中 → 若走 §195，就是「其他人格法益」→ 要**情節重大**。
若把 §19 的「損害賠償」解釋成包含慰撫金 → §19 本身就是 §18 II 的「法律特別規定」→ **不用**情節重大。

### 兩說

| | 王澤鑑（否定說） | 陳聰富（肯定說） |
|---|---|---|
| §19 損害賠償含慰撫金？ | **不含** | **含** |
| 解釋方法 | **文義解釋**：§18 II 寫「損害賠償**或**慰撫金」，兩者並列 → §18 II 的「損害賠償」不含慰撫金 → §19 的「損害賠償」同解 | **目的解釋**：若不含慰撫金，§19 全部可被取代（除去→§18；財產上→§184；慰撫金→§195），§19 變具文；讓它含慰撫金才有存在價值 |
| 姓名權慰撫金的路 | 回到 §195 I「其他人格法益」→ **須情節重大** | §19 直接請求 → **不須情節重大** |
| §19 的價值 | 僅確認姓名權是人格權 | 作為慰撫金的「法律特別規定」 |

### 推導圖（王澤鑑）
```
§18 II：「……得請求 損害賠償 或 慰撫金」
    → 若損害賠償已含慰撫金，何必再寫「或慰撫金」？
    → §18 II 的「損害賠償」＝財產上損害賠償
    → §19 緊接 §18，用語相同 → §19 的「損害賠償」亦不含慰撫金
    → 慰撫金另找依據 → §195 I → 姓名非列舉 → 情節重大
```

### 推導圖（陳聰富）
```
§19 若不含慰撫金：
    除去      ← §18 I 可取代
    財產上損害 ← §184 + §216 可取代
    慰撫金    ← §195 可取代
    → §19 留著幹嘛？→ 具文
→ 讓 §19 的損害賠償及於慰撫金 → 姓名權慰撫金不須情節重大 → §19 別具意義
```

- 老師：不要背「王老師否定、陳老師肯定」，要懂為什麼——一個看文義，一個看目的。
