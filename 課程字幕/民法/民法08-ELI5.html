2除斥期間 §90 vs §93：一段式與兩段式，起算點才是考點

甲意思表示後九年半才發現被詐欺。另一題：甲做了錯誤的意思表示，兩年後才發現錯了。

被詐欺的甲還剩多久可以撤？錯誤的甲還能撤嗎？

§90 錯誤：一段式

自意思表示起一年。不管你有沒有發現。兩年後才發現 → 已逾期 → 不能撤

§93 詐欺／脅迫：兩段式

自發見詐欺（脅迫終止）起一年 ＋ 自意思表示起不逾十年，兩個門檻都要過。九年半才發現 → 只剩六個月
規則

為什麼不一樣？§88 是自己的錯，撤銷又破壞交易安全，所以側重法安定性，從意思表示起算死線。§93 要保護被騙的人，發現才起算；但「發現」這個起算點不固定（隔天、五年、一輩子不會），法律關係不能永遠懸著，所以加十年上限。侵權行為 §197 也是同樣結構（知有損害二年、侵權行為十年）。

陷阱

大家都背「一年、十年」，選擇題考的是從哪一天算。§56 撤銷總會決議的三個月從決議作成之日起算，不是知道有瑕疵時。

6被脅迫的要件：惡害要對表意人、不法性有三種

兒子要爸爸當保證人，爸爸不肯，兒子當場咬舌昏倒，爸爸嚇到答應了。另一題：「你不便宜把地賣我，我就去舉發你逃漏稅。」第三題：承攬人說「不把報酬從 1,000 萬調到 1,800 萬我就停工」。

三個都讓人害怕，哪些是 §92 的脅迫？

  • 脅迫＝故意告以惡害（詐欺是告知不實資訊）
    • 惡害須是對表意人的不利益：兒子傷的是自己 → 最高法院：非脅迫
    • 不法性 ①目的不法 ②手段不法（不賣畫就燒你家）③目的手段都合法但欠缺合理關聯（賣地 vs 舉發逃漏稅）→ 都是脅迫
    • 停工漲價：看關聯合理性——原物料上漲不得不漲 → 有關聯 → 非脅迫（葉啟洲：停止供貨要求漲價不違交易習慣）；坐地喊價 → 仍可能構成
    • 因果關係：被脅迫 → 心生畏怖 → 為意思表示。不害怕就不是
規則

目的、手段都合法而且有合理關聯，才不是脅迫；都合法但沒有關聯，還是脅迫。「不小心脅迫到你」殊難想像，所以故意是當然要件。

陷阱

考點集中在第三種「關聯不法」。舉發逃漏稅本身合法，拿來換便宜賣地就不行。

10§72 公序良俗：看目的正當、手段適當，而且會隨時代變

非律師甲跟乙約定「我幫你打車禍官司，贏了分我三成」，贏了乙不付。航空公司約定機師離職賠培訓費 300 萬；醫院約定護理師離職賠高額違約金。媽媽出錢讓兩個牙醫兒子開診所，約定每月淨利 60% 給媽媽。

哪些違反公序良俗？

  • §72：私法自治的紅線。判斷＝目的正當性 ＋ 手段適當性，個案認定
    • 非律師包攬訴訟分成 → 違反公共秩序（法治國原則：國家有義務提供經認證的律師）→ 無效 → 乙得拒付（103 台上 41）
    • 父健在時子女預立遺產分割、夫妻預立離婚契約 → 判例：違反善良風俗無效。老師：民國 46 年和 114 年的善良風俗可以不同，申論可質疑；選擇題照判例
    • 機師離職賠培訓費：目的正當（確保培訓成本）、手段適當（賠的就是成本）→ 不違反。護理師：幾無培訓成本、只為防人力短缺 → 可能違反
    • 離職後競業禁止：目的正當（保密），要給合理補償才適當；現依勞基法 §9-1。藝人禁止私接演出：最高法院不違反
    • 牙醫兒子孝親費（103 台上 2036）：二審違反善良風俗；最高法院攤開全貌（母出資、扣成本、不同住、財產終歸兄弟）→ 不違反
規則

公共秩序是國家想創造的秩序（法治國、民主國原則），善良風俗是人與人相處的道德界線，兩個都浮動。善良風俗題難寫，因為素材不只是法律，是你對社會、人性、當事人關係的觀察。

陷阱

選擇題黏著判例：生前分產、預立離婚選「無效」。申論題才寫自己的想法。

12§71 強行規定的四種分類：法條寫「得」不一定是任意規定

僱傭契約特約「受僱人離職須經主管核准才生效」。買賣土地特約「土地增值稅由買受人負擔」。賭場老闆讓欠賭債的甲改簽借據，再依消費借貸請求。

§488 II 寫「得隨時終止」，特約排除可以嗎？土地法 §182 說向出賣人徵收，約定由買受人繳可以嗎？賭債變借據就能告贏嗎？

  • 法律規定的四種
    • 任意規定：無拘束力。土地法 §182 增值稅——國家只要有人繳，誰繳都一樣 → 約定由買受人負擔有效
    • 訓示規定：建議性質，違反仍有效。土地法 §102 二個月內登記地上權（§422-1 請求權時效其實 15 年）
    • 取締規定：違反受罰但行為有效（§71 但書）。證券商違反證交法借錢給客戶 → 借貸有效、證券商受罰
    • 效力規定：違反無效（§71 本文）。§488 II 的「得」是給受僱人的權利，本質是不得限制 → 特約須主管核准 → 無效（註 163）

最高法院：脫法行為

賭債非債；改簽借據、本票是用合法掩護非法 → 脫法行為 → 新債務也無效（44 年判例）

王澤鑑：法律解釋就夠

賭債變票據債務是債務性質更改，著重同一性，原本無效的債務不因更改而有效。不必另造理論，「最高法院不要偷懶」
規則

結論相同，差在方法：王澤鑑認為能用法律解釋得出的結論，就不要直接丟一個「脫法行為」。實務的進化：賭場現在不把賭債換借據，而是先借你錢再讓你賭，單純消費借貸，借錢去玩是你家的事——澳門賭場來台告的就是這種。

陷阱

看法條不能只看「得」「應」「不得」，要看立法目的：土地法 §182 沒有任何這些字，從目的（順利課稅）判斷是任意規定。

13原住民保留地借名登記：大法庭全部 §71 無效，學說說解釋太粗暴

非原住民乙想買原住民甲的保留地做露營區，法律規定所有權移轉以原住民為限。乙找原住民丙當人頭：乙丙借名登記、丙與甲買賣、甲為乙設定地上權、甲移轉所有權給丙。另外甲還偽造共同繼承人丁的同意書，先把地單獨登記在自己名下。

四個行為各自效力如何？丁怎麼把地要回公同共有？

108 台上大 1636
結論
借名登記、買賣、設定地上權、移轉登記 → 都是為了讓非原住民取得 → 全部 §71 無效
甲偽造丁同意書的分割登記無效
丁
§828 II 準用 §821、§767 I 中段請求甲乙丙塗銷 → 回復甲丁公同共有
  • 學說（陳榮傳、吳從周、林誠二）：結論可接受，法律解釋太粗暴——條文射程只有「所有權移轉」
    • 丙甲買賣契約：不在射程，不是 §71；但實質當事人乙非原住民 → 甲不可能移轉 → 給付不能 §246 無效
    • 設定地上權、抵押權：條文沒說以原住民為限；原住民要融資只能抵押給原住民？→ 文義過度擴張，規範密度不足應修法
    • 借名登記契約：以規避法律為目的 → §71 或 §72 無效，可接受
    • 甲→丙所有權移轉：實質是非原住民取得 → §71 無效，可接受
規則

大家都同意不該讓乙拿到實質控制力。差在：法條管的是所有權移轉，其他行為一律丟 §71，是「拿明朝的劍斬清朝的官」。公同共有登記任一繼承人可辦，分割登記才要全體同意，所以甲偽造丁同意書那一步無效。

陷阱

答題分四個行為逐一寫，每個行為的無效依據可能不同（§71／§246／§72），不要一句話全包。
