# 民法04 筆記：法律行為的定義與分類

> 來源：民法04 課程字幕 00:59:45 ~ 01:12:00

---

## 📖 法條原文速查

> **§71**（違反強行規定之效力）
> 法律行為，違反強制或禁止之規定者，無效。但其規定並不以之為無效者，不在此限。
> → 民法第一次出現「法律行為」四個字

> **§78**（限制行為能力人之單獨行為）
> 限制行為能力人未得法定代理人之允許，所為之**單獨行為**，無效。

> **§79**（限制行為能力人之契約行為）
> 限制行為能力人未得法定代理人之允許，所訂立之**契約**，須經法定代理人之承認，始生效力。
> → 單獨行為／契約行為的區分實益（下堂講）

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律行為之定義？」 | 以**意思表示**為要素，對外發生一定**法律效果**之法律事實 |
| 「買賣契約是債權行為或物權行為？」 | **債權行為**（負擔行為）：只發生債權債務，不發生權利變動 |
| 「債權讓與、債務免除是何種行為？」 | **準物權行為**（處分行為；標的是權利不是物） |
| 「所有權移轉、設定抵押權？」 | **物權行為**（處分行為；標的是物） |
| 「物權行為必為契約？」 | **否**。拋棄所有權是物權行為＋單獨行為；移轉所有權是物權行為＋契約（讓與合意） |
| 「債權行為必為契約？」 | **否**。捐助（財團設立）通說是債權行為＋單獨行為 |
| 「社團總會決議是何種行為？」 | **合同行為**（多數人意思表示相同、同一方向） |
| 「一個故事裡有幾個單獨行為／契約／債權行為／準物權行為？」 | 一試典型題型，要能逐一定性 |

## 一、法律行為在法律事實中的位置

```
生活事實
├── 非法律事實（不生權利義務：刷牙、加入學生會）
└── 法律事實
      ├── 非行為（事件：出生、死亡、繼承、時效）
      └── 行為
            ├── 非表示行為（事實行為：§802 先占、§811 添附、§814 加工）
            └── 表示行為
                  ├── 法律行為 ← 本筆記
                  └── 準法律行為 ← 下一份筆記
```

- **定義**：以意思表示為要素，對外發生一定法律效果的法律事實。白話：人透過自己的意思創造法律效果。

## 二、分類一：依效果

```
法律行為
├── 身分行為（結婚、離婚、認領、收養）→ 民總不討論
└── 財產行為
      ├── 負擔行為＝債權行為：以【發生債權債務】為目的（買賣、租賃、贈與）
      │     → 不會產生權利變動
      └── 處分行為：以【產生權利變動】為目的
            ├── 物權行為：標的是【物】（移轉所有權、設定抵押權、拋棄）
            └── 準物權行為：標的是【權利】（債權讓與、債務免除）
```

| 行為 | 目的 | 標的 | 例 |
|------|------|------|-----|
| 債權行為 | 發生債權債務 | — | 買賣契約（只是約定，東西還沒變成你的） |
| 物權行為 | 權利變動 | 物 | 把汽車所有權移轉給你 |
| 準物權行為 | 權利變動 | 權利 | 把對丙的 100 萬債權讓與給你 |

- 有因／無因、獨立性／無因性 → 講到物權行為時再談，這裡先有分類架構。

## 三、分類二：依作成方式

| 類型 | 要幾個意思表示 | 例 |
|------|------|-----|
| 單獨行為 | 一方意思表示即生效 | 拋棄（飲料喝完丟垃圾桶）、撤銷、解除、捐助 |
| 契約行為 | 雙方意思表示**合致**（方向相對） | 買賣、租賃、贈與、**物權契約**（讓與合意） |
| 合同行為 | 多數人意思表示**相同**（方向一致） | 總會決議、多數決處分 |

- 台灣：契約是契約、合同是合同，意義不同；對岸「合同」＝契約。考卷不要寫「買賣合同」。

## 四、兩種分類是不同角度貼標籤，不是對立

```
同一個人可以同時是「超過 50 歲」「男性」「碩士」
同一個行為可以同時是「物權行為」「契約行為」
```
| 行為 | 依效果 | 依方式 |
|------|------|------|
| 買賣契約 | 債權行為 | 契約 |
| 所有權移轉（讓與合意） | 物權行為 | 契約（一個巴掌拍不響：我要移轉、你要收） |
| 拋棄所有權 | 物權行為 | 單獨行為 |
| 捐助（財團設立） | 債權行為（通說） | 單獨行為 |
| 總會決議 | — | 合同行為 |
