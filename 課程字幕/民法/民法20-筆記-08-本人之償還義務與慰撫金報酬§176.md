# 民法20 筆記：本人之償還義務與慰撫金、報酬（§176）

## 本人的義務（§176 I 明定三項，報酬另有爭議）：
- **清償債務**：管理人為本人負擔的債務（幫你修漏水，欠水電行的錢由你結清）
- **償還費用**：必要或有益費用＋自支出時起之利息（已付水電行 30 萬，向你請求）
- **賠償損害**：管理人因管理受損害 → 爭點：含不含慰撫金
- **報酬**：條文未規定 → 爭點

## 損害賠償不含慰撫金：
- 通說、實務：只限**財產上損害**
- 理由：§18 II 人格權受侵害，以**法律有特別規定**者為限，始得請求損害賠償或慰撫金（見民法19-筆記-02）；§176 不是這種特別規定
- 對照：侵權走 §184 → §195；債務不履行走 §227 → §227-1 準用 §195；無因管理到不了 §195

## 高壓電灼傷案（講義 272 頁註 428）：
- 甲自 A 公司離職、已申請復職，預定 8 月 1 日上班；7 月 15 日颱風，A 公司高壓變電箱毀損
- 警衛乙打電話請甲回來看；甲修理時變電箱爆炸，全身 **78% 灼傷**
- 侵權 ✗：A 公司無侵害行為；債務不履行 ✗：甲尚未復職，無僱傭契約
- 承攬契約 ✗：警衛沒有找人修高壓電的代理權 → **無權代理**，A 公司拒絕承認
- 只剩 §176 I → 只能請求財產上損害，**不能請求慰撫金**
- 陳忠五評析（註 429）可能出路：
  - A 公司事後仍為甲投保勞保 → 能否認定已**承認**無權代理 → 有契約 → §227-1 準用 §195
  - 變電箱不安全 → 違反**交易往來安全義務**之不作為侵權 → §184 → §195

## 報酬請求權：
- 原則**沒有**：否則無因管理會變成敲詐工具（失業的人主動幫人做事就能領錢）
- 王澤鑑：管理涉及**專業**者，例外可請求
- 老師：重點不在專業，而在是否因專業**節省了費用**；依據為**類推 §176** 費用償還
- 例：甲在公園昏倒。乙是律師 → 只能叫救護車、代墊醫院費用 → 請求償還費用；乙是醫生 → 帶回自己醫院救治、沒有支出費用 → 例外可請求報酬

## 📖 法條原文速查

> **§176 I**　管理事務，利於本人，並不違反本人明示或可得推知之意思者，管理人為本人支出**必要或有益之費用**，或**負擔債務**，或**受損害**時，得請求本人償還其費用及自支出時起之利息，或清償其所負擔之債務，或賠償其損害。

> **§18 II**　前項情形，以**法律有特別規定者為限**，得請求損害賠償或慰撫金。

> **§227-1**　債務人因債務不履行，致債權人之人格權受侵害者，準用第一百九十二條至第一百九十五條及第一百九十七條之規定，負損害賠償責任。

## 📋 實務見解速查

> **講義 272 頁註 428**：管理人為公司修繕高壓配電線路，成立正當（適法）無因管理；民法未就無因管理人管理事務致人格權受侵害者，特別規定得請求損害賠償或慰撫金，其請求賠償非財產上損害即屬無據。（字號字幕未唸，請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「適法無因管理人受傷，得依 §176 請求慰撫金？」 | **否**，§18 II 無特別規定 |
| 「債務不履行侵害人格權，得否請求慰撫金？」 | **得**，§227-1 準用 §195 |
| 「無因管理人原則上有報酬請求權？」 | **否** |
| 「醫師救治路倒病患，得否請求報酬？」 | 學說：例外**得**（專業／節省費用），類推 §176 |
| 「§176 費用償還之利息自何時起算？」 | **自支出時起** |

## 一、慰撫金三條路

| 請求權基礎 | 通往 §195 | 慰撫金 |
|---|---|---|
| §184 侵權行為 | 直接 §195 | ✓ |
| §227 債務不履行 | §227-1 準用 | ✓ |
| §176 I 無因管理 | 無特別規定 | ✗ |

