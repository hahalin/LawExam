# 民法19 筆記：§217法院職權減免與§218§218-1

## §217 的法律效果：
- 條文主詞是**法院**：「法院得減輕賠償金額，或免除之」→ 不待當事人主張，法院得**依職權**斟酌
- 選擇題陷阱：「與有過失是抗辯，當事人未提出法院不得斟酌」→ **錯**
- 規定在損害賠償之債，所有損害賠償都能用

## §218 生計酌減（求情用）：
- 要件：① 損害**非因故意或重大過失**所致 ② 賠償致賠償義務人**生計有重大影響**
- 效果：法院得**減輕**，**不能免除**（對照 §217「或免除之」）
- 老師：很少用、考試不太考

## §218-1 讓與請求權：
- 適用：同一損害有數個賠償義務人
- 例：甲的 A 車停在乙停車場被丙偷走；乙監視器有死角有過失 → 甲可依**債務不履行**向乙、依 **§184** 向丙請求
- 乙、丙非共同侵權行為，無 §280、§281 內部求償 → 乙賠完甲後，甲不會再找丙，終局責任人丙就沒事
- §218-1：乙得請求甲讓與甲對丙之 §184 請求權 → 由乙向丙求償
- 隱藏要件：請求讓與者須為**非終局**賠償義務人；丙賠了不能反過來要甲對乙之請求權
- II 準用 **§264** 同時履行抗辯：乙不必先賠，賠償與讓與同時履行

## 死牛案：類推 §218-1
- 甲撞死乙的牛，甲賠償後能否請求乙交付牛屍（還能賣牛肉、做飼料）？
- 條文讀法：讓與「基於其物之所有權**對於第三人之請求權**」或「基於其權利**對於第三人之請求權**」→ 客體一定是**對第三人之請求權**
- 本案沒有對第三人之請求權 → 不能直接適用；學者認為**類推 §218-1**，甲得請求讓與牛屍

## 下一講：
- 侵權行為剩**消滅時效**（§197）；§218-1 之後在不真正連帶債務、非給付型不當得利還會用到

## 📖 法條原文速查

> **§217 I**　損害之發生或擴大，被害人與有過失者，**法院**得減輕賠償金額，**或免除之**。

> **§218**　損害非因**故意或重大過失**所致者，如其賠償致賠償義務人之**生計有重大影響**時，法院得**減輕**其賠償金額。

> **§218-1**　I 關於物或權利之喪失或損害，負賠償責任之人，得向損害賠償請求權人，請求讓與基於其物之所有權或基於其權利**對於第三人之請求權**。II 第二百六十四條之規定，於前項情形準用之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「當事人未主張與有過失，法院不得依職權減輕？」 | **錯**，法院得依職權斟酌 |
| 「§218 法院得減輕或免除？」 | **只能減輕**（§217 才有免除） |
| 「加害人故意或重大過失，得否主張 §218？」 | **否** |
| 「終局責任人得否依 §218-1 請求讓與對他人之請求權？」 | **否**，限非終局賠償義務人 |
| 「§218-1 請求讓與與賠償有無先後？」 | 準用 **§264**，同時履行 |

## 一、§217 與 §218 對照

| | §217 | §218 |
|---|---|---|
| 原因 | 被害人與有過失 | 賠償義務人生計困難 |
| 主觀限制 | 無 | 非故意或重大過失 |
| 效果 | 減輕或**免除** | 只能**減輕** |

## 二、停車場案

```
甲（A 車被偷）
├─ 對乙（停車場）：債務不履行 ← 非終局
└─ 對丙（竊賊）：§184 ← 終局
乙賠償甲 ⇄（§264 同時履行）甲讓與對丙之 §184 請求權
        ↓
乙向丙求償 ✓　　丙不得反向請求 ✗
```
