# 民法04 筆記：法律行為的成立要件——三要素、要式 §73 §166、要物 §474

> 來源：民法04 課程字幕 01:24:47 ~ 01:46:07

---

## 📖 法條原文速查

> **§73**（不依法定方式之效力）
> 法律行為，不依法定方式者，**無效**。但法律另有規定者，不在此限。
> → 用語是「無效」；學說認為方式是成立要件，應為「不成立」

> **§166**（約定方式）
> 契約當事人約定其契約須用一定方式者，在該方式未完成前，**推定其契約不成立**。
> → 用語是「不成立」

> **§474 I**（消費借貸之定義）
> 稱消費借貸者，謂當事人一方**移轉金錢或其他代替物之所有權於他方**，**而約定**他方以種類、品質、數量相同之物返還之契約。
> → 「而約定」之前＝成立要件（交付）；之後＝義務（返還）

> **§464**（使用借貸之定義）
> 稱使用借貸者，謂當事人一方以物交付他方，而約定他方於無償使用後返還其物之契約。

> **§465-1**（使用借貸之預約）、**§475-1**（消費借貸之預約）→ 民國 89 年修法增訂，建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律行為之一般成立要件？」 | **當事人、意思表示、標的** |
| 「兩個五歲小孩訂立之買賣契約，是法律行為嗎？」 | **是**（成立），但**無效**（生效要件欠缺）。不成立 ≠ 無效 |
| 「人與狗之約定是法律行為？」 | **不是**，欠缺當事人 |
| 「『我送你一個東西』是贈與契約？」 | **不是**，標的無法特定 |
| 「法律行為不依法定方式，效力？」 | 一試選法條：**無效**（§73）；學說（邱聰智、林誠二）：應為不成立 |
| 「當事人約定須用一定方式而未完成？」 | **推定不成立**（§166） |
| 「消費借貸是單務或雙務契約？」 | **單務**。交付是成立要件，返還是唯一義務 |
| 「單務契約必為無償？」 | **錯**。有利息之消費借貸＝單務有償 |
| 「雙務契約必為有償？」 | **對**（完全雙務契約）。無償雙務不存在；無償委任為不完全雙務契約 |
| 「答應借錢但尚未交付，發生何效力？」 | 消費借貸**預約**（§475-1） |

## 一、成立 vs 生效：兩個層次

```
成立要件：這「是不是」一個法律行為？
生效要件：這個法律行為「有沒有效」？
→ 先是法律行為，才談有沒有效
```
- 王澤鑑：區分實益不大（都是不生效果）；一般仍分開看，邏輯上有價值。
- 例：兩個五歲小孩訂買賣契約 → 是法律行為（有人、有意思表示、有標的）→ 但無效（無行為能力）。不會說「不是買賣契約」。

## 二、一般成立要件：人、意思表示、標的

| 要素 | 缺了會怎樣 | 例 |
|------|------|-----|
| **當事人** | 不是法律行為 | 跟狗約定晚上散步，牠不能告你債務不履行 |
| **意思表示**（想發生法律效果、受拘束的意思） | 不是法律行為 | 朋友說順路載你、沒來 → 不會告他；約機場接送沒來 → 違約。差別在有無法效意思 |
| **標的**（物、權利、勞務皆可，但要能特定） | 不是法律行為 | 「我送你一個東西」「送你一個驚喜」→ 無從履行 |

## 三、特別成立要件 ①：要式行為

| | 法定要式 | 約定要式 |
|---|---|---|
| 來源 | 法律要求（終身定期金須書面） | 當事人自己約定（租約本不要式，雙方約定要白紙黑字） |
| 違反效果 | **§73 無效** | **§166 推定不成立** |
| 體系評價 | 方式是成立要件，寫「無效」體系不合（邱聰智、林誠二：應修為不成立）；王澤鑑：不必分那麼細 | 用語正確，看得出立法者知道成立≠生效 |
| 考試 | **一試選法條，答無效**；研究所可帶學說批評 | — |

## 四、特別成立要件 ②：要物行為

### 看法條的「而約定」在哪裡
```
§474：當事人一方【移轉金錢…所有權於他方】，而約定【他方以同種類…之物返還】
                ↑ 成立要件（交付）                    ↑ 義務（返還）
```
```
甲向乙借 100 萬
  乙把錢交給甲 → 不是義務，是【成立要件】→ 交付時契約才成立
  甲還錢給乙   → 契約裡【唯一的義務】
→ 消費借貸是【單務契約】（§464 使用借貸同理）
```

### 單務／雙務 × 有償／無償
```
雙務 → 必為有償（完全雙務契約，雙方義務有對價）
單務 → 通常無償，但【有利息的消費借貸】＝單務有償 ← 最常考錯
無償雙務 → 不存在（無償委任是「不完全雙務契約」：費用償還義務與勞務無對價關係）
```
- 老師：高普考常出，司律還沒看過，但只是觀念。

### 要物行為的立法檢討
- 要物的「警告功能」：答應借錢 ≠ 一定要借，交付了契約才成立，保護貸與人。
- 但與當事人意思不符（已經答應了卻說契約沒成立）→ 德國修法盡量刪除要物債權契約。
- 我國 89 年修法沒刪，改加**預約**：答應借錢 → 成立借貸預約（§465-1、§475-1）→ 交付 → 本約成立。
