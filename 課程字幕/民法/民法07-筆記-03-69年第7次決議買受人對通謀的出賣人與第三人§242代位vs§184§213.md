# 民法07 筆記：69 年第 7 次民事庭決議——買受人甲面對「出賣人乙與丙通謀移轉標的物」：§242 代位 §767 vs §184＋§213 塗銷，能不能把乙列為被告

> 來源：民法07 課程字幕 00:17:38 ~ 00:27:14（講義 165 頁）

---

## 📖 法條原文速查

> **§242**（債權人代位權）債務人怠於行使其權利時，債權人因保全債權，得以自己之名義，行使其權利。……
> **§348 I**　物之出賣人，負交付其物於買受人，並使其取得該物所有權之義務。
> **§767 I 中段**　對於妨害其所有權者，得請求除去之。
> **§184 I**　因故意或過失，不法侵害他人之權利者，負損害賠償責任（**前段**）。故意以背於善良風俗之方法，加損害於他人者亦同（**後段**）。
> **§185 I**　數人共同不法侵害他人之權利者，連帶負損害賠償責任。
> **§213 I**　負損害賠償責任者，除法律另有規定或契約另有訂定外，應**回復他方損害發生前之原狀**。

## 📋 實務見解速查

> **最高法院 69 年度第 7 次民事庭會議決議**（講義 165 頁；年度、次別請對講義）
> 債務人與第三人通謀移轉財產，目的雖在使債權無法實現而應負債務不履行責任，惟債務人將自己之財產予以處分，**原可自由為之**，難謂係故意不法侵害債權人之權利，故與侵害債權之第三人**不能構成共同侵權行為**。債權人如本於侵權行為請求塗銷登記，**只能向第三人為之**，債務人既非侵權行為人，自不得對其一併為請求。
> → 至今仍有最高法院判決引用，學者多所批評

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲向乙買 A 地，乙與丙通謀虛偽將 A 地移轉登記予丙，甲如何使 A 地回到乙名下？」 | **§242 代位乙**行使 **§767 I 中段**請求丙塗銷登記（無爭議）→ 再依 §348 請求乙移轉 |
| 「甲得否直接請求丙移轉予自己？」 | **不得**。甲丙間無任何法律關係 |
| 「甲得否依侵權行為請求乙、丙塗銷登記？」 | 實務（69 年第 7 次決議）：**只能告丙**，乙處分自己財產不構成侵權。王澤鑑：乙丙**都可以**告，依 **§184 I 後段**（債權非權利，不能用前段）＋ **§213 回復原狀** |
| 「侵權行為如何帶出『塗銷登記』的效果？」 | 損害賠償方法＝**回復原狀**（§213）→ 回復原狀即塗銷 |

## 一、事實
```
甲 ──買賣 A 地（§348 債權）──→ 乙
                               乙 ──通謀虛偽移轉登記──→ 丙
登記簿：甲（原）? 不是——A 地原本是乙的，登記在乙名下 → 現在登記在丙名下
甲要的是：A 地回到乙名下，再由乙移轉給甲
```

## 二、路 ①：§242 代位（沒有爭議）
```
乙丙物權行為通謀無效 → 丙未取得所有權卻登記為所有人 → 對真正所有人乙構成【法律上妨害】
→ 乙對丙有 §767 I 中段塗銷登記請求權
→ 乙當然不會行使（怠於行使）→ 甲有保全債權（§348 以 A 地為標的）的必要
→ 甲依 §242 以自己名義代位乙行使 → 丙塗銷 → A 地回乙名下 → 甲依 §348 請求乙移轉
```
- 老師：土地登記題畫一張登記簿流向圖給自己看。

## 三、路 ②：侵權行為（有爭議）
```
乙丙的通謀侵害了甲的債權 → §184 損害賠償 → 損害賠償方法是回復原狀（§213）→ 回復原狀＝塗銷登記
→ 甲可否依 §184＋§213 直接請求乙丙塗銷？
```

| | 實務：69 年第 7 次決議 | 王澤鑑 |
|---|---|---|
| 被告 | **只能告丙**。土地是乙的，乙要給誰是他的自由，即使通謀也不構成侵權；乙非侵權行為人，與丙不成立共同侵權 | **乙丙都可以告** |
| 條文 | — | **§184 I 後段**（故意背於善良風俗）。債權不是 §184 I 前段的「權利」 |

### 答題三個注意
1. 一定要**配 §213**：靠回復原狀帶出塗銷登記的效果。
2. 能不能對**乙**提告：實務 ✗、學說 ✓。
3. 條文是 **§184 I 後段**，不是前段。
