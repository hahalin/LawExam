# 民法03 筆記：財團法人——捐助的撤回時點、§64 宣告無效

> 來源：民法03 課程字幕 01:16:00 ~ 01:32:37

---

## 📖 法條原文速查

> **§59**（財團之設立許可）
> 財團於登記前，應得主管機關之許可。

> **§62**（財團之組織及管理方法）
> 財團之組織及其管理方法，由捐助人以**捐助章程**或遺囑定之。→ 建議查閱最新六法原文

> **§64**（財團董事行為無效之宣告）
> 財團董事，有**違反捐助章程**之行為時，法院得因主管機關、檢察官或利害關係人之聲請，**宣告其行為為無效**。
> → 民法只有這裡用「宣告無效」四個字

> **§30**（登記）
> 法人非經向主管機關登記，不得成立。

---

## 📋 實務見解速查

> **最高法院 105 年、109 年判決**（講義 79 頁註 93）：董事違反捐助章程之行為，**並非當然無效**，必須經法院宣告後**始溯及失效**。（＝宣告前有效，撤銷訴訟說）
> → 字號請查講義

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「財團法人之意思決定機關？」 | **捐助章程**，不是信徒大會、不是董事會 |
| 「捐助與捐贈之別？」 | 捐贈：把錢送給別人；**捐助**：把錢變成一個法人 |
| 「捐助人於財團**登記後**死亡，繼承人得否撤回？」 | **不得**，已成立 |
| 「捐助人於**許可後、登記前**死亡？」 | **實務：得撤回**（登記前都可）；王澤鑑：**不得**（許可後即不可） |
| 「捐助人於**申請後、許可前**死亡？」 | 實務、王澤鑑：得撤回；林誠二：**不得**（尊重捐助人意思） |
| 「§64 宣告前，董事違反章程之行為效力？」 | **實務：有效**（撤銷訴訟說，宣告後溯及無效）；吳從周、姚瑞光：**自始無效**（確認訴訟說） |
| 「選擇題怎麼選？」 | 以實務為準：登記前可撤回；§64 宣告前有效 |

## 一、財團的結構與外部監督

```
捐助人 ──捐助（法律行為）──→ 一筆錢擬人化 ＝ 財團法人（基金會）
    意思決定機關：捐助章程（錢怎麼用、目的為何都寫在裡面）
    行為機關    ：董事（＋監察人）
    外部監督    ：法院（§64 宣告無效、甚至宣告解散）
```
- 社團由社員自己出錢、自己監督（內部自律），不需法院介入；財團是一個人把錢捐出去之後就沒人盯，所以設計成**法院監督**。
- 財團只能以公益為目的。

## 二、捐助的撤回：三個時點、三種見解

```
捐助意思表示 ──① 申請許可──→ ② 主管機關許可 ──→ ③ 登記（成立）
```

| 捐助人死亡時點 | 實務 | 王澤鑑 | 林誠二（字幕音譯） |
|------|------|------|------|
| 申請後、許可前 | 得撤回 | 得撤回 | **不得**（已提出申請，尊重捐助人意思，繼承人無撤回餘地） |
| 許可後、登記前 | **得撤回**（登記前都可） | **不得**（許可後即不可） | 不得 |
| 登記後 | 不得 | 不得 | 不得 |

- 老師：早年爭點（民國 8、90 年考過），選擇題以實務為準——**登記後不能撤回，登記前都還有救**。

## 三、§64「宣告無效」：是撤銷還是確認？

### 問題
民法通常「無效就無效、得撤銷就得撤銷」，只有 §64 寫「宣告無效」。宣告**後**無爭議（自始無效）；爭的是宣告**前**。

| | 撤銷訴訟說（實務、王澤鑑） | 確認訴訟說（吳從周、姚瑞光） |
|---|---|---|
| 「宣告」的意思 | 本質是**撤銷** | 本質是**確認** |
| 宣告前 | **有效**，沒人聲請就一直有效 | **自始無效**，法院只是 double check |
| 理由 | 105、109 年判決：非當然無效，經宣告後始溯及失效 | 若是撤銷，用語應是「請求法院撤銷」；寫「宣告無效」就是確認它本來無效 |

### 考題：111 年檢事官（講義 79 頁）
#### 事實
甲**宗教財團法人**信徒大會決議「逾期未繳常年會費者自動喪失信徒資格」，經董監事審議通過，乙等 8 名信徒被除名。甲之捐助章程**未規定除名事由**。

#### 分析
```
① 甲是財團法人 → 意思決定看捐助章程；信徒大會不是意思機關（財團沒有總會概念）
② 章程未規定除名事由 → 董事依信徒大會決議除名 ＝ 董事行為違反捐助章程
③ 依 §64 得聲請法院宣告無效
④ 宣告前效力？
    實務（撤銷訴訟說）→ 法院未宣告前，除名【仍有效】
    吳從周（確認訴訟說）→ 除名【自始無效】，乙等仍具信徒資格
```
- 老師：檢事官、司法事務官特別愛考法人；律師司法官二試幾乎不考。
