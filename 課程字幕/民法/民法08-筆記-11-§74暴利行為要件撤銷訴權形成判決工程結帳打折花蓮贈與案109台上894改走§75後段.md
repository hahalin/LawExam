# 民法08 筆記：§74 暴利行為——趁人急迫輕率無經驗、財產上給付、顯失公平；撤銷訴權須形成判決（不能當攻擊防禦方法）；工程結帳打折判例、花蓮智能障礙贈與案 109 台上 894 改走 §75 後段

> 來源：民法08 課程字幕 01:37:51 ~ 01:53:00（講義 209 頁；註 153）

---

## 📖 法條原文速查

> **§74**（暴利行為）
> I 法律行為，係**乘**他人之**急迫、輕率或無經驗**，使其為**財產上之給付或為給付之約定**，依當時情形**顯失公平**者，**法院**得因利害關係人之**聲請**，撤銷其法律行為或減輕其給付。
> II 前項聲請，應於法律行為後**一年內**為之。

> **§75 後段**　雖非無行為能力人，而其意思表示，係在無意識或精神錯亂中所為者亦同（無效）。
> **§114 I**　法律行為經撤銷者，視為自始無效。　**§179**　不當得利　**§767 I**　所有物返還

## 📋 實務見解速查

> 註 153 判例（字號請對講義）：某甲於工程竣工時負債累累，如不能領取價款即無以應付債主迫索；某乙利用某甲經濟困難之急迫機會，以低於工程價額數十萬元結帳，顯失公平，自得聲請撤銷。
> **最高法院 109 年度台上字第 894 號判決**（講義 209 頁）：§74 I 所定撤銷權，須以**訴**之方式向法院請求為撤銷行為之**形成判決**，始能發生撤銷效果；如僅於**給付訴訟中主張**此項撤銷權作為**攻擊方法**，尚不生撤銷之效力，其法律行為不因此失其效力。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§74 之要件？」 | ① **乘**人急迫、輕率、無經驗（趁人之危的故意）② 使其為**財產上**給付或給付之約定（身分行為不適用）③ 依當時情形**顯失公平** |
| 「效果？」 | 法院得因聲請**撤銷或減輕給付**；一年內聲請 |
| 「§74 之撤銷與 §88、§92 之撤銷有何不同？」 | §88、§92 以**意思表示**撤銷（訴訟中記明筆錄即生效）；§74 是**撤銷訴權**（形成訴權），須**形成判決確定**才無效，判決確定前法律行為仍有效 |
| 「於不當得利給付之訴中主張依 §74 撤銷？」 | **不生撤銷效力**（109 台上 894）。須另提撤銷之訴或先取得形成判決（中間判決），再往下打 §179 |
| 「定作人趁承攬人竣工後負債累累急需用錢，要求 1,500 萬打折為 800 萬結帳？」 | 乘急迫、使為給付之約定、顯失公平 → 一年內聲請法院撤銷或減輕 |
| 「中度智能障礙者（未受監護／輔助宣告）將房屋贈與配偶，家屬如何救濟？」 | §74 須另訴（二審誤用）；§92 詐欺難證明；發回後改用 **§75 後段**（無意識或精神錯亂）→ 無效 → §179 返還 |

## 一、要件
```
① 乘人急迫、輕率、無經驗 → 「趁」＝趁人之危的故意
② 使其為財產上之給付或給付之約定 → 標的是財產給付；身分上約定與 §74 無關
③ 依當時情形顯失公平
→ 效果：法院得因利害關係人聲請，撤銷或減輕給付；法律行為後一年內聲請
```

## 二、最常見：工程結帳打折（趁你病要你命）
```
A（定作人）──承攬 1,500 萬──→ 甲（承攬人）──→ 乙丙丁小包商 ──→ 乙一、乙二……
小包商做完就要錢；甲要等 A 付款才有錢給下面
過年前 A：打個折，800 萬現在給你；不然你告我，打到最高法院三年，你早破產了
甲為了讓下面的人好過年只好答應 → 甲很悶
→ A 乘甲急迫，使甲為減少報酬之約定，無減少理由顯失公平 → §74 一年內聲請撤銷
```

## 三、§74 的撤銷是「訴權」：109 台上 894
### 事實
甲中度智能障礙、領身障手冊、五六十歲未婚，未受監護或輔助宣告。父母生前把花蓮一間透天過戶給甲。甲與外籍女子乙結婚（兄弟姊妹事後才知），並以贈與為原因將 A 屋移轉登記給乙。甲：「他說喜歡我、要跟我結婚，我就說好。」兄弟姊妹丙丁想幫甲把房子要回來（先聲請輔助宣告）。

### 歷審
| | 見解 |
|---|---|
| 二審 | 援引 §74：乙乘甲無經驗 → 撤銷 → 後續行為無效 → §179／§767 要回 |
| 最高法院 | 論述有大錯：§74 須**以訴請求形成判決**；僅在給付訴訟中主張作為攻擊方法，**不生撤銷效力**。§74 不像 §88、§92 可在訴訟中以意思表示撤銷、記明筆錄即生效 |
| 發回後 | 改走 **§75 後段**：調就醫紀錄，甲行為時根本無法認識移轉所有權的結果（無意識、精神錯亂）→ 贈與無效 → §179 返還 |

### 為什麼不走 §92
- 詐欺難證明：夫妻間贈與財產並不罕見。
- 且 §74、§92 都以**有效的法律行為**為前提（本來就無效幹嘛撤）；最高法院暗示：有行為能力的人所為不一定有效，§75 後段無效更直接。

### 操作上
```
§74 不能單純當攻擊防禦方法
→ 另提撤銷之訴，或至少先取得 §74 的中間判決確認撤銷
→ 再往下打不當得利
```
