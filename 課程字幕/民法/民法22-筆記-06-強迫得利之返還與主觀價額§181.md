# 民法22 筆記：強迫得利之返還與主觀價額（§181）

## 案例：
- 甲擅自花 3 萬元替乙修好房屋漏水
- 乙：房子下個月就要改建、現在沒人住，漏水就讓它漏，我不要
- 違反乙明示或可得推知的意思 → 不適法無因管理

## 先看無因管理：
- 乙願意享受管理利益 → 依 §177 I，甲仍得在乙所得利益範圍內依 §176 請求（見民法20-筆記-10）
- 乙不願享受 → 回到不當得利

## 成立 §179：
- 乙客觀上受有漏水修好的利益
- 屬非給付型中的**支出費用型**；費用是甲支出的，利益歸屬於甲 → 乙受有屬於甲的利益 → 成立
- 強迫得利**不是在 §179 否定**，客觀上仍是得利

## 在 §181 處理（王澤鑑）：
- **原形能還就還原形**：替人裝冷氣對方不要 → 拆下來還；便當多加一顆滷蛋 → 夾出來還，誰都不虧
- 與其說不成立不當得利，結果還是逼對方吞下滷蛋，沒有意義
- **原形不能還 → 償還價額**：漏水已修好，總不能拆掉
- 價額原則採**客觀說**；強迫得利例外採**主觀說**，依受領人主觀上對他的價值認定

## 主觀價額不一定是零：
- 對乙毫無意義 → 返還 0 元
- 乙因為漏水修好，決定在改建前再住一個月 → 這一個月的利益仍有主觀價值，要返還這部分
- 考試不要寫「強迫得利就不用還」：先分能不能還原形，再談價額

## §181 最愛考兩點：
- 交易溢價（見民法22-筆記-01）
- 強迫得利

## 📖 法條原文速查

> **§181**　不當得利之受領人，除返還其所受之利益外，如本於該利益更有所取得者，並應返還。但依其利益之性質或其他情形不能返還者，應**償還其價額**。

> **§177 I**　管理事務不合於前條之規定時，本人仍得享有因管理所得之利益，而本人所負前條第一項對於管理人之義務，以其所得之利益為限。

> **§176 I**　管理事務，利於本人，並不違反本人明示或可得推知之意思者，管理人為本人支出必要或有益之費用，或負擔債務，或受損害時，得請求本人償還其費用及自支出時起之利息，或清償其所負擔之債務，或賠償其損害。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「強迫得利不成立不當得利？」 | **錯**，仍成立 §179，在 §181 處理 |
| 「強迫得利之原形可返還時？」 | **返還原形**（拆下冷氣） |
| 「強迫得利不能返還原形，價額如何認定？」 | 例外採**主觀說** |
| 「一般不當得利之價額如何認定？」 | 原則**客觀說** |
| 「本人願享受不適法管理之利益？」 | 依 §177 I 適用 §176，以所得利益為限 |

---

## 一、解題流程

```
甲擅自為乙支出費用
        ↓
適法無因管理？── 是 → §176
        ↓ 否
乙願享受利益？── 是 → §177 I（以所得利益為限）
        ↓ 否
§179 支出費用型 → 成立（強迫得利仍是得利）
        ↓
§181 返還什麼？
├─ 原形能還 → 返還原形（冷氣拆回、滷蛋夾出）
└─ 不能還 → 償還價額，採主觀說（0 元或再住一個月的價值）
```

## 二、價額認定對照

| | 一般不當得利 | 強迫得利 |
|---|---|---|
| 標準 | 客觀市價 | 受領人主觀價值 |
| 理由 | — | 利益非受領人所欲，對他未必有意義 |
| 本例 | 3 萬元 | 0 元或一個月使用價值 |
