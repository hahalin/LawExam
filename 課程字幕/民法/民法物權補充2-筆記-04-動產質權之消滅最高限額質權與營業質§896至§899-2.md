# 民法物權補充2 筆記：動產質權之消滅、最高限額質權與營業質（§896至§899-2）

## 消滅原因
| 原因 | 內容 | 條文 |
|---|---|---|
| 債權消滅 | 消滅上的從屬性；質權人應**返還質物** | §896 |
| **返還質物** | 質權人將質物返還出質人或交付債務人 → 質權消滅；為質權繼續存在之**保留無效** | §897 |
| 喪失占有 | 喪失質物占有，**2 年內**未請求返還 → 消滅 | §898 |
| 質物滅失 | 原則消滅；出質人因滅失得受賠償或其他利益者，質權存於該請求權（物上代位） | §899 |

- §897 是選擇題陷阱：甲把鑽戒質給乙，甲說晚宴借戴一下，乙借了 → 質權**當場消滅**，就算約定保留也無效
- 物上代位例：質物賓士車被第三人縱火 → 質權轉存於車主對第三人的損害賠償請求權（權利質權），結構同 §881

## 最高限額質權（§899-1）
- 以動產為一定範圍內不特定債權設定最高限額的質權（例：以勞力士手錶、鑽戒擔保反覆往來的債權）
- 設定要件：除交付外，**還要書面**
- 準用最高限額抵押權規定，及動產質權規定（性質不抵觸者）

## 營業質（§899-2）：當鋪
- 經許可以受質為營業者，**僅得**就質物行使權利
  - 「**僅**」＝不能請求債務人清償；當鋪不是地下錢莊
- 出質人於取贖期間屆滿後 **5 日**內未取贖 → 質權人**取得質物所有權**，所擔保債權**同時消滅**
  - 例：手錶約定 4/30 取贖，5/1～5/5 再給 5 天；5/5 一過，手錶歸當鋪，借款也不用還
- **不適用**：§889～§895（孳息、轉質、預行拍賣、實行等權利）、§899（物上代位）、§899-1（最高限額質權）

## 📖 法條原文速查

> **§897 I**（返還質物）動產質權，因質權人將質物返還於出質人或交付於債務人而消滅。返還或交付質物時，為質權繼續存在之保留者，其保留無效。

> **§899-2 I** → 建議查閱最新六法原文（要點：營業質僅得就質物行使權利；取贖期間屆滿後五日內未取贖，質權人取得所有權，債權同時消滅）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 質權人將質物借還出質人並約定保留質權 | 質權**消滅**，保留無效 |
| 喪失占有多久未請求返還而消滅 | **2 年** |
| 質物滅失有賠償請求權 | 物上代位 |
| 最高限額質權設定要件 | 交付＋**書面** |
| 當鋪可否請求債務人清償 | **不可**，僅得就質物 |
| 當鋪取得所有權時點 | 取贖期間屆滿後 **5 日** |

---

## 一般動產質權 vs. 營業質

| 項目 | 一般動產質權 | 營業質 |
|---|---|---|
| 請求債務人清償 | 可 | **不可** |
| 實行 | 拍賣、流質、其他方法 | 期滿 5 日未贖即取得所有權 |
| 債權 | 未受償部分仍存在 | 同時消滅 |
| 轉質、變賣 | 可 | 不適用 |
