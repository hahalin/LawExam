# 民法17 筆記：§189 定作人責任之確認性規定

## 體系位置：
- 特殊侵權行為體系圖裡沒有 §189：§185 共同侵權、§186 公務員、§187、§188 為他人負責、§190、§191 為物負責、§191-1～§191-3 舉證責任調整
- §189 有跟沒有一樣，是**確認性規定**；同類：§18 II、陳聰富眼中的 §188 III、林誠二眼中的 §100（原文請對六法）

## 案例：
- 甲請乙裝冷氣（承攬），乙不慎讓冷氣掉落，砸破樓下陽臺或砸到等公車的路人丙
- 丙能否依 §188 找甲？**不能**：承攬著重工作完成，定作人**沒有指揮監督權限**；僱傭再怎麼放寬也不會變成承攬

## 但書的意思：
- 「定作人於定作或指示有過失者，不在此限」≠ 回去負 §188
- 是要定作人為**自己的過失**負責 → 依 **§184** 請求
- 丙對乙 §184、對甲 §184；甲乙頂多依 **§185** 連帶，不是依 §188 連帶

## 答題提醒：
- 不要寫「依 §189 請求損害賠償」：§189 **不是請求權基礎**
- 刪掉 §189 結論一樣；保留是為了避免爭執承攬時有無僱用人責任，直接把答案寫出來

> 來源：民法17 課程字幕 02:21:05 ~ 02:26:00（講義 175 頁；字幕「僱傭再怎麼寬都不會變成懶」＝變成承攬）

## 📖 法條原文速查

> **§189**　承攬人因執行承攬事項，不法侵害他人之權利者，定作人不負損害賠償責任。但定作人於**定作或指示有過失**者，不在此限。

> **§188 I 前段**　受僱人因執行職務，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。

> **§184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。

> **§18 II**　前項情形，以法律有特別規定者為限，得請求損害賠償或慰撫金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「承攬人執行承攬事項侵權，被害人得否依 §188 向定作人請求？」 | **否**，承攬無指揮監督關係 |
| 「定作人於定作或指示有過失，被害人之請求權基礎？」 | **§184**（不是 §189，也不是 §188） |
| 「承上，定作人與承攬人如何連帶？」 | **§185**，不是 §188 |
| 「§189 是否為請求權基礎？」 | **否**，確認性規定 |

## 一、法律構造

```
丙（被害人）
├── 對乙（承攬人）：§184
└── 對甲（定作人）
      ├─ §188 ✗（承攬無指揮監督）← §189 本文確認
      └─ 定作或指示有過失 → §184 ✓ ← §189 但書確認
            └─ 甲乙連帶：§185
```

## 二、僱傭與承攬

| | 僱傭 | 承攬 |
|---|---|---|
| 著重 | 服勞務 | 工作完成 |
| 指揮監督 | 有 | 無 |
| 對他人侵權 | §188 連帶 | §189：原則不負責；定作或指示有過失依 §184 |

## 三、確認性規定一覽

| 條文 | 確認了什麼 | 實際依據 |
|---|---|---|
| §18 II | 人格權受侵害，以法律有規定為限可請求 | §184、§195 等 |
| §188 III（陳聰富） | 僱用人有求償權 | §280、§281 |
| §189 | 承攬不適用 §188；有過失回 §184 | §184、§185 |
