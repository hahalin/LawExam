# 民法12 筆記：消滅時效起算點（§128）

> 來源：民法12 課程字幕 01:24:00 ~ 01:46:00

---

## 📖 法條原文速查

> **§128**（消滅時效起算）
> 消滅時效，自請求權可行使時起算。以不行為為目的之請求權，自為行為時起算。
> → 「可行使」= 客觀上無法律障礙（通說）

> **§229**（給付遲延）
> 給付有確定期限者，債務人自期限屆滿時起，負遲延責任。
> 給付無確定期限者，債務人於債權人得請求給付時，經其催告而未為給付，自受催告時起，負遲延責任。其經債權人起訴而送達訴狀，或依督促程序送達支付命令，或為其他相類之行為者，與催告有同一之效力。
> → 未定期限 = 催告後才負遲延責任

> **§315**（清償期——未定期限）
> 清償期，除法律另有規定或契約另有訂定，或得依債之性質或其他情形決定者外，債權人得隨時請求清償，債務人亦得隨時為清償。
> → 未定期限 = 隨時可請求 → 契約成立即可請求

> **§478**（消費借貸——未定期限之返還）
> 借用人應於約定期限內，返還與借用物種類、品質、數量相同之物。未定返還期限者，借用人得隨時返還，貸與人亦得定一個月以上之相當期限，催告返還。
> → 爭點：「定一個月以上催告」= 清償期？還是遲延責任起算？

## 📋 實務見解速查

| 實務見解 | 要旨 |
|---------|------|
| **99 年第 7 次民事庭決議** | 未定期限消費借貸，§478 催告屆滿時才可行使返還請求權 → 時效**自催告期滿起算** |

---

## 🎯 一試重點提示

1. **§128 起算**：客觀上無法律障礙即起算 → 主觀不知、事實障礙（對方跑了）都不影響
2. **99 年決議（一試標準答案）**：未定期限消費借貸 → 時效自**催告期滿**起算（= 實務見解）
3. **學說不同見解**：時效自**契約成立時**起算 → 但一試選實務就對了
4. **題目出現「不知有權利」**→ 不影響時效起算（客觀說）
5. **題目出現「對方跑了找不到」**→ 事實障礙，不影響時效起算
6. **題目出現「票據被扣押」**→ **法律障礙** → 時效暫不起算

---

## 一、§128 起算的基本規則

### 核心公式

```
消滅時效起算 = 請求權「可行使」時
    │
    ├── ✓ 客觀上無「法律」障礙 → 唯一要件
    │
    ├── ✗ 主觀是否知悉 → 不問
    │
    └── ✗ 事實上障礙 → 不問
```

### 三個排除情境

| 情境 | 影響時效起算？ |
|------|-------------|
| 權利人**不知道**有權利可以行使 | ✗ 不影響 |
| **對方跑了**找不到人 | ✗ 不影響（事實障礙） |
| **票據被檢察官扣押**，無法行使票據債權 | ✓ 影響（**法律障礙** → 暫不起算） |

> ⚠️ 考試陷阱：題目常故意說「甲不知道有權利可以行使」→ 客觀上有權利就開始算了！

## 二、99 年第 7 次民事庭決議（經典考題）

### 案例事實

```
民國 90 年：甲乙消費借貸，未定期限
    │
    ↓（8 年後）
民國 98 年：乙催告甲「一年內還錢」
    │
    ↓（催告屆滿 1 年後）
民國 99 年：催告期滿，甲仍未還
    │
    ↓（又過 14 年）
民國 113 年：乙請求甲返還借款

❓ 甲能否主張時效抗辯？
```

### 爭點：15 年從何時起算？

#### 實務見解（99 年第 7 次決議）

```
§478：未定期限 → 貸與人須「定一個月以上期間催告返還」
    │
    └── 催告期滿 → 請求權「可行使」→ §128 起算
         │
         時效起算點：民國 99 年（催告期滿）
         時效完成點：民國 114 年（99 + 15）
         │
         民國 113 年起訴 → 未逾時效 → 甲不能主張時效抗辯
```

> **實務邏輯**：§478 是 §315 的特別規定 → 不催告就不能請求 → 時效不會起算 → 113 年未逾時效

#### 學說多數見解（詹森林、陳聰富等）

```
§315：未定期限 → 隨時可請求
    │
    └── 契約成立即可請求 → §128 起算
         │
         時效起算點：民國 90 年（契約成立）
         時效完成點：民國 105 年（90 + 15）
         │
         民國 113 年起訴 → 已逾時效 → 甲可以主張時效抗辯
```

### 學說的三層論證

#### （一）體系解釋：§478 是 §229 的特別規定，不是 §315 的

| 法條 | 功能 | 規範對象 |
|------|------|---------|
| **§315** | 清償期（何時可以請求） | 未定期限 → 隨時可請求 |
| **§229** | 遲延責任起算（何時算遲延） | 未定期限 → 催告後遲延 |
| **§478** | 一個月以上催告返還 | 消費借貸的**恩惠期間** |

> §478 的「定一個月以上期間」= §229 遲延責任的特別規定
> 不是說不能請求（§315 隨時可以），而是遲延利息要等一個月才能算

#### （二）恩惠期間的意涵

```
甲向乙借 100 萬（未定期限）

如果沒有 §478：
  乙早上借，下午催告 → 甲立刻遲延 → 跳利息（§229）
  → 對借用人太不利！

有了 §478（恩惠期間）：
  乙催告後 → 給甲至少 1 個月準備 → 1 個月後不還才算遲延
  → 保護借用人的立法善意
```

> **§478 = 遲延利息什麼時候開始算，不是你什麼時候可以叫他還錢**

#### （三）目的解釋：法安定性

```
實務見解的問題：

  時效起算 = 催告期滿
  → 不催告 = 時效永遠不起算
  → 民國 90 年借款，110 年才催告 → 時效從 111 年起算
  → 一筆借款可能 30 年都不罹於時效 → 嚴重害及法安定性

學說見解：

  時效起算 = 契約成立（民國 90 年）
  → 起算點固定 → 不影響法安定性
  → 時效從 90 年跑 15 年 = 105 年就完成
```

### 一試答題策略

> **選擇題問「依最高法院見解」→ 選 99 年第 7 次決議 = 催告期滿起算**
> 申論題 → 寫實務見解＋批評（體系解釋、目的解釋）＋學說

## 三、立法論的反思：主觀說 vs 客觀說

### 比較法趨勢

| | 客觀說（我國現行） | 主觀說（德國 2000 年修法後） |
|--|-------------------|---------------------------|
| 起算點 | 請求權「可行使」時 | 權利人「知悉」時 |
| 時效長度 | 長（15 年） | 短（3 年） |
| 法安定性 | 靠長時效保護 | 靠知悉才起算保護 |
| 不知情風險 | 可能默默罹於時效 | 不知道就不會起算 |

### 我國修法方向（尚未通過）
- 民國 104 年：法務部啟動民總、債編修正草案計畫
- 民國 109 年：完成草案 → 送立法院 → **至今未通過**
- 方向：改採「主觀說為主、客觀說為輔」+ 縮短時效

### 現行法解套：誠信原則（詹森林老師）

> 在主觀說尚未立法之前，若債務人**故意妨礙**權利人知悉（如做假帳），事後主張時效抗辯 → 可能**違反誠信原則**

兩種可能構成違反誠信的情形：
1. 義務人以**不當手段**致使權利人不知可行使權利
2. 權利的行使需義務人**告知或協力**，而義務人不為告知或協力
