# 民法05 筆記：物權行為獨立判斷——一手交錢一手交貨的三個法律行為

> 來源：民法05 課程字幕 00:37:50 ~ 00:48:39

---

## 📖 法條原文速查

> **§77 但書**　純獲法律上利益者，不須允許。
> **§78**　限制行為能力人未得法定代理人之允許，所為之**單獨行為**，無效。
> **§79**　限制行為能力人未得法定代理人之允許，所訂立之**契約**，須經法定代理人之承認，始生效力。

> **§761 I**（動產物權之讓與）
> 動產物權之讓與，非將動產交付，不生效力。→ 讓與合意 ＋ 交付；讓與合意是**契約**

> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。→ 要件：請求人是**所有人**
> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「16 歲甲向乙買腳踏車、一手交錢一手交貨，共幾個法律行為？」 | **三個**：買賣契約（債權行為）＋ 乙移轉車之物權行為 ＋ 甲移轉價金之物權行為 |
| 「買賣契約效力？」 | 甲負價金義務 → 不純 → **§79 效力未定** |
| 「乙移轉車給甲之物權行為效力？」 | 甲只取得所有權、無義務 → **純獲法律上利益** → **有效** |
| 「甲付錢給乙之物權行為效力？」 | 甲喪失金錢所有權、無所得 → 不純 → 是**契約**（讓與合意）→ **§79 效力未定**（不是 §78 無效） |
| 「法代全部拒絕承認，乙如何取回車？」 | **§179 不當得利**。不能用 §767（移轉車的物權行為有效，乙已非所有人） |
| 「物權行為之獨立性與無因性？」 | 獨立性：每個物權行為**獨立判斷**效力；無因性：**不受債權行為影響** |

## 一、一個交易，三個法律行為

```
16 歲甲 ⇄ 乙：買 A 腳踏車，一手交錢一手交貨

① 買賣契約（債權行為）：甲乙意思表示合致
② 乙把 A 車所有權移轉給甲（物權行為＝讓與合意＋交付）
③ 甲把價金所有權移轉給乙（物權行為＝讓與合意＋交付）
→ 雙方總共六個意思表示：甲（買、受領 A、移轉錢）、乙（賣、移轉 A、受領錢）
```

## 二、逐一判斷：問「這個行為若有效，甲會怎樣」

| 行為 | 若有效，甲…… | 純獲法律上利益？ | 效力 |
|------|------|------|------|
| ① 買賣契約 | 負 §367 價金義務 | ✗ | **§79 效力未定** |
| ② 乙移轉 A 車 | 取得 A 車所有權，**無任何義務**（義務來自買賣契約，不是來自這個物權行為） | ✓ | **有效** |
| ③ 甲移轉價金 | 喪失金錢所有權，**什麼都沒得到**（得到 A 車是因為 ②，不是因為 ③） | ✗ | **§79 效力未定** |

### 行為 ③ 為什麼是 §79 不是 §78
- 很多人卡在這：付錢不是單獨行為嗎？**不是**。移轉金錢所有權要雙方「讓與合意」——我要給、你要收 → 是**物權契約** → 契約走 §79 效力未定，不是 §78 無效。
- 老師：這種題目大概每兩年考一次。

## 三、物權行為的兩個特性

```
獨立性：每個物權行為有沒有效，獨立判斷
    → 不能說「買賣效力未定，所以兩個物權行為跟著效力未定」
無因性：物權行為不受債權行為（原因行為）的影響
    → ② 有效與 ① 效力未定並存
```

## 四、法代全部拒絕承認之後：乙怎麼把車要回來

```
① 買賣契約 → 不生效力
② 乙→甲 移轉 A 車 → 有效 → 甲已是 A 車所有人 → 一物一權 → 乙不是所有人
③ 甲→乙 移轉價金 → 不生效力

乙對甲
├── §767 I 前段請求返還 A 車？✗ 乙不是所有人（第一句話就是「所有人」）
└── §179 不當得利？✓ 甲受有利益（A 車）、無法律上原因（買賣不生效力）、乙受損害
甲對乙
└── 要回價金 → §179（金錢是利益，不要求原物返還；還不同張鈔票也可以）
```
- 選擇題：「乙得依 §767 請求甲返還 A」→ **錯**。
