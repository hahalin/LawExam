# 民法04 筆記：主物與從物 §68、「處分」的範圍

> 來源：民法04 課程字幕 00:12:35 ~ 00:23:10

---

## 📖 法條原文速查

> **§68**（主物與從物）
> I 非主物之成分，常助主物之效用，而同屬於一人者，為從物。但交易上有特別習慣者，依其習慣。
> II 主物之**處分**，及於從物。

> **§362**（解除契約與從物）
> I 因主物有瑕疵而解除契約者，其效力及於從物。
> II 從物有瑕疵者，買受人僅得就從物之部分為解除。

> **§862 I**（抵押權效力及於從物從權利）
> 抵押權之效力，及於抵押物之從物與從權利。

> **§765**（對照：所有權之內容）
> 所有人，於法令限制之範圍內，得自由使用、收益、處分其所有物，並排除他人之干涉。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「從物之要件？」 | ① 非主物之成分（獨立物）② 常助主物之效用 ③ 與主物同屬一人 ④ 交易習慣（§68 I 但書） |
| 「甲乙就 A 訂立買賣契約，乙得否請求交付 B？」 | 看 B 是否為 A 之從物（四要件）→ 是 → 主物之處分及於從物（§68 II）→ 得請求 |
| 「汽車方向盤是汽車之從物？」 | **不是**，它是汽車的**成分**（第一要件不符） |
| 「主物有瑕疵解除契約，效力及於從物？」 | **及於**（§362 I）；僅從物有瑕疵 → 僅得就從物部分解除（§362 II） |
| 「抵押權效力及於從物？」 | **及於**（§862 I） |
| 「§68 II 之『處分』指什麼？」 | **法律上處分**（債權行為、物權行為）；事實上處分（洗車、烤漆）不及於從物 |

---

## 一、為什麼民總要定義主物從物：界定交易的範圍

```
我們通常只針對「主物」訂約，從物不會特別講
    買冷氣 → 附遙控器？買車 → 附補胎劑？買薯條 → 附番茄醬？
    → 靠 §68 和交易習慣，決定就 A 的法律行為效力可以自動擴張到 B
```
- 呼應物的第三要件「滿足人類社會生活」：每個物都切開看，生活無法被滿足。
- 老師：§68 就是「買薯條要附番茄醬」的法律依據。

## 二、從物四要件

| 要件 | 說明 | 例 |
|------|------|-----|
| ① 非主物之成分 | 必須是**獨立物**；是主物一部分的就是主物本身 | 方向盤 ✗、珍奶的珍珠 ✗；遙控器 ✓ |
| ② 常助主物之效用 | 幫主物發揮功能 | 遙控器方便操控冷氣 |
| ③ 同屬一人 | 主物從物同一所有人 | 便當和筷子都是便當店的 |
| ④ 交易習慣 | §68 I 但書；習慣會變 | 便當附筷子（現在要加一元）、iPhone 附耳機／豆腐頭（現在只剩線） |

- 交易習慣會隨法令、時代改變：前三要件都符合，第四個才是關鍵。

## 三、考法：不會直接問「B 是不是從物」

```
甲乙就 A 訂立買賣契約 → 乙得否請求交付 B？
    → A 契約效力是否及於 B？
    → B 須為 A 之從物（四要件檢驗）
    → 是 → §68 II 主物之處分及於從物 → 得請求
```
- 延伸條文：§362（解約及於從物）、§862（抵押權及於從物）——選擇題愛考。

## 四、§68 II 的「處分」＝法律上處分

```
法律上處分：債權行為、物權行為（買賣、移轉所有權、設定抵押）→ 效力及於從物
事實上處分：汽車烤漆、洗冷氣 → 效力只在標的物本身，與從物無關（遙控器不會自動變乾淨）
```
- 民法裡「處分」出現很多次（§68、§84、§118、§765），意義不盡相同（最廣義／廣義／狹義），後面再整理比較。
