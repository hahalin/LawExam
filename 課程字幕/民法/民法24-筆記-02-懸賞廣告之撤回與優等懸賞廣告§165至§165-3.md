# 民法24 筆記：懸賞廣告之撤回與優等懸賞廣告（§165至§165-3）

## 懸賞廣告的撤回（§165 I）：
- 行為完成前，相對人尚未承諾、契約未生效 → 廣告人**可以撤回**
- 撤回後的責任：對行為人因廣告**善意所受之損害**負賠償責任
  - 例：為找狗印傳單、做準備的支出
  - 上限：**不超過預定報酬額**
- 免責：廣告人**證明行為人不能完成**其行為
  - 例：狗自己回家了 → 再怎麼找也找不到，不必賠

## 定有完成期間（§165 II）：
- 廣告定有完成行為之期間 → **推定**廣告人拋棄撤回權

## 優等懸賞廣告（§165-1～§165-3）：
- 意義：完成一定行為、在一定期間內通知，並經**評定為優等**者才給報酬
  - 例：徵文比賽、繪畫比賽、攝影比賽
- 廣告人於**評定完成時**負給付報酬義務（§165-1）
- 評定人：廣告中指定之人；未指定 → 廣告人決定方法評定（§165-2 I）
- 評定對**廣告人及應徵人**有拘束力（§165-2 II）
- 數人同等優等：除廣告另有聲明外，**共同取得**報酬請求權（§165-3）
  - 例：第一名 3 萬、第二名 2 萬，兩人並列第一 → 共同取得 3 萬，一人只分到 1.5 萬，反而比第二名少
  - 老師：主辦方通常會另行聲明；這段看看有印象即可，很選擇題

## 📖 法條原文速查

> **§165**（懸賞廣告之撤回）
> I 預定報酬之廣告，如於行為完成前撤回時，除廣告人證明行為人不能完成其行為外，對於行為人因該廣告**善意所受之損害**，應負賠償之責。但以**不超過預定報酬額**為限。
> II 廣告定有完成行為之期間者，**推定**廣告人拋棄其撤回權。

> **§165-1**（優等懸賞廣告）　以廣告聲明對完成一定行為，於一定期間內為通知，而經評定為優等之人給與報酬者，為優等懸賞廣告。廣告人於**評定完成時**，負給付報酬之義務。

> **§165-2**（評定）　I 前條優等之評定，由廣告中指定之人為之。廣告中未指定者，由廣告人決定方法評定之。II 依前項規定所為之評定，對於廣告人及應徵人有拘束力。

> **§165-3**（共同取得）　被評定為優等之人有數人同等時，除廣告另有聲明外，**共同取得**報酬請求權。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「行為完成前，廣告人可否撤回？」 | **可以**（契約尚未成立） |
| 「撤回後行為人得請求賠償之範圍？」 | **善意所受之損害**，以**預定報酬額**為上限 |
| 「廣告人如何免責？」 | 證明行為人**不能完成**其行為 |
| 「定有完成期間的懸賞廣告？」 | **推定**拋棄撤回權（非「視為」） |
| 「優等懸賞廣告何時負給付報酬義務？」 | **評定完成時** |
| 「兩人同列優等？」 | 除另有聲明，**共同取得**報酬請求權 |

## 找狗案

| 情形 | 結論 |
|------|------|
| 乙印傳單找狗中，甲撤回廣告 | 甲賠乙善意支出，最多 1 萬元（預定報酬額） |
| 狗已自己回家，甲撤回 | 甲證明乙不能完成 → 不必賠 |
| 廣告寫「一個月內找到」 | 推定甲拋棄撤回權 |

## 一般懸賞 vs 優等懸賞

| | 一般懸賞廣告 | 優等懸賞廣告 |
|---|---|---|
| 取得報酬的要件 | 完成行為 | 完成行為＋期間內通知＋評定優等 |
| 數人時 | 最先完成者；同時則共同 | 同等優等者共同 |
| 報酬義務發生 | 完成時 | 評定完成時 |
