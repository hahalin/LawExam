# 民法36 筆記：債權占有權源與占有連鎖（§767、§373、§443）

## 占有權源的兩種：
- **物權**的占有權源（如地上權）：可以對抗任何人，包括土地所有人
- **債權**的占有權源（如租賃）：基於債之相對性，原則上只能對抗契約相對人
- 例外突破債之相對性：**占有連鎖**、誠信原則（使用借貸的情形，前面債之相對性已講過，知道即可）

## 占有連鎖的三個要件：
1. 現占有人對中間人有合法占有權源（丙→乙）
2. 中間人對所有人有合法占有權源（乙→甲）
3. 中間人有**移轉占有的權限**（最容易漏）
- 只有兩段租賃還不夠，第三個要件是關鍵
- 實務已廣泛承認，不再只是學說（最高法院 104 台上 40 等，字號建議查證）

## 情形一：轉租（最常考）：
- 甲把 A 地租給乙，乙轉租給丙；甲能否對丙依 §767 I 前段請求返還
- 先確認丙**占有**（有）→ 再看是否**無權**
- 丙的權源是乙丙租賃，原則不能對抗甲 → 看能否占有連鎖
  - **合法轉租**：乙有移轉占有權限 → 構成占有連鎖 → 丙是有權占有
  - **違法轉租**：乙沒有權限 → 不構成
- 違法轉租時，實務要求甲先依 **§443 II 終止**甲乙租約，再對丙主張 §767
  - 理由：不先終止，甲向丙取回後，乙又可依租約請求甲交付，來回折騰

## 情形二：買賣交付後、移轉登記前出租：
- 甲把 A 地賣給乙並先點交，尚未移轉登記；乙把 A 地出租給丙並交付
- 甲仍是所有人，能否對丙主張 §767 I 前段
- 乙對甲的占有權源**不是買賣契約本身**（買賣只生給付請求權），而是 **§373**：交付後買受人享受利益
- 享受利益 → 可使用收益 → 可以出租 → 乙有移轉占有的權限
- 三要件具備 → 丙不是無權占有，甲不能請求返還
- 提醒：只背轉租，考到買賣就卡住；占有連鎖兩種情形都要會

## 📖 法條原文速查

> **§373**　買賣標的物之**利益**及危險，除契約另有訂定外，自**交付**時起，均由買受人承受負擔。

> **§443**
> I　承租人非經出租人承諾，不得將租賃物轉租於他人。但租賃物為房屋者，除有反對之約定外，承租人得將其一部分轉租於他人。
> II　承租人違反前項規定，將租賃物轉租於他人者，出租人得**終止**契約。

> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。

## 📋 實務見解速查

> **104 台上 40（講義註 95）**：物之占有人如本於債之關係而占有，該債之關係存在於占有人與相對人間，占有人欲主張其為有權占有，須該相對人對所有人亦有占有之正當權源，**且得基於該權源而移轉占有**於現占有人為前提。→ 字號依字幕，建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「次承租人得以其與承租人之租約對抗出租人？」 | 原則**不得**；合法轉租可依占有連鎖 |
| 「占有連鎖只要兩段占有權源即可？」 | **否**，中間人須有移轉占有之權限 |
| 「違法轉租，出租人得逕對次承租人請求返還？」 | 實務：先依 §443 II 終止租約 |
| 「買受人受交付未登記即出租，出賣人得對承租人請求返還？」 | **不得**，§373 使買受人有出租權限 |
| 「買受人對出賣人之占有權源為買賣契約本身？」 | **否**，是交付後的 §373 |

## 占有連鎖判斷流程

```
所有人甲 → §767 I 前段 告現占有人丙
   │
   ├─ 丙有占有事實？ 否 → 告錯人
   └─ 是 → 丙的權源是債權？
            ├─ 物權 → 有權占有
            └─ 債權 → 占有連鎖三要件
                      ├─ 丙→乙 權源 ✓
                      ├─ 乙→甲 權源 ✓（租賃／§373）
                      └─ 乙有移轉占有權限？
                           ├─ 有（合法轉租、買受人出租）→ 丙有權占有
                           └─ 無（違法轉租）→ 先終止甲乙租約，再請求返還
```
