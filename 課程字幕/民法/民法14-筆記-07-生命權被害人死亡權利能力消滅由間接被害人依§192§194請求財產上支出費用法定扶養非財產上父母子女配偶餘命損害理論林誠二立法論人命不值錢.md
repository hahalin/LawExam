# 民法14 筆記：生命權：由間接被害人依 §192、§194 請求

## 被害人死亡，誰能請求：
- 被害人之權利能力**終於死亡**（§6），本人無從依 §184 請求 → 由**間接被害人**請求
- **財產上**（§192）：為被害人支出醫藥費、增加生活上需要費用、殯葬費之人；被害人對之負**法定扶養義務**之人
- **非財產上**（§194）：被害人之父母、子女、配偶之慰撫金
- **73 台再 182** 判例：§192 I 殯葬費係間接被害人得請求之特例；間接被害人須承擔直接被害人之**與有過失**（§217）

## 餘命損害：
- 英美法概念：承認被害人本人對加害人有請求權，由**繼承人**主張（**林誠二**倡議修法引進）
- **立法論**：現行法下被害人死亡瞬間已非權利主體、無權利可繼承（多數說王澤鑑否定），**考試不能直接寫**
- 背景「人命不值錢」：撞成植物人賠 §193 動輒數千萬，撞死只賠喪葬費、扶養費、慰撫金一兩百萬

> 來源：民法14 課程字幕 01:13:30 ~ 01:23:30（講義 57 頁註 100）

## 📖 法條原文速查

> **民法 §6**　人之權利能力，始於出生，終於死亡。
> **民法 §192 I**　不法侵害他人致死者，對於支出醫療及增加生活上需要之費用或殯葬費之人，亦應負損害賠償責任。
> **民法 §192 II**　被害人對於第三人負有法定扶養義務者，加害人對於該第三人亦應負損害賠償責任。
> **民法 §194**　不法侵害他人致死者，被害人之父、母、子、女及配偶，雖非財產上之損害，亦得請求賠償相當之金額。
> **民法 §193 I**　不法侵害他人之身體或健康者，對於被害人因此喪失或減少勞動能力或增加生活上之需要時，應負損害賠償責任。

## 📋 實務見解速查

> **最高法院 73 年台再字第 182 號判例**（講義 57 頁註 100，已核對）：民法第一百九十二條第一項規定不法侵害他人致死者，對於支出殯葬費之人，亦應負損害賠償責任，係**間接被害人**得請求賠償之特例。此項請求權，自理論言，雖係固有之權利，然其權利係基於侵權行為之規定而發生，自不能不負擔直接被害人之過失，倘直接被害人於損害之發生或擴大與有過失時，依公平之原則，亦應有民法第二百十七條**過失相抵**規定之適用。
> **最高法院 66 年台上字第 2759 號判例**（講義 58 頁，老師未講）：不法侵害他人致死者，被害人之子女得請求賠償相當數額之慰撫金，又胎兒以將來非死產者為限，關於其個人利益之保護，視為既已出生（§194、§7），慰撫金之數額應酌量一切情形定之，**但不得以子女為胎兒或年幼為不予賠償或減低賠償之依據**。
> 講義 57 頁註 99：比較法上「餘命損害」係以「假設直接被害人未死亡，其可能獲得之經濟利益」作為**繼承標的**，使直接被害人之繼承人得向加害人求償；我國**多數說**（王澤鑑，人格權法 115、469 頁）認依現行民法架構無法為相同解釋，否定之；**林誠二**（債法總論新解（上）456 頁）認現行法雖無法作此解釋，但為貫徹生命權保障，將來修法應引進。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「乙不法侵害甲致死，甲得否依 §184 對乙請求？」 | **不得**。權利能力終於死亡（§6），甲已非權利主體，原告不會是被害人 |
| 「誰可以請求？」 | **間接被害人**：財產上——§192 I 支出醫療、增加生活需要、殯葬費之人；§192 II 甲負法定扶養義務之人；非財產上——§194 父母、子女、配偶之慰撫金 |
| 「直接被害人 vs 間接被害人？」 | 直接被害人＝發生死亡結果的甲；間接被害人＝因甲死亡而受損害之人 |
| 「餘命損害理論？考試怎麼寫？」 | 英美法概念：承認甲本人生命權受侵害之請求權，因甲死亡無法行使，由繼承人主張，使損害回歸生命權本身。我國林誠二倡議。**立法論**，現行法下甲死亡即非權利主體、無權利可繼承 → 考試寫法：「間接被害人依 §192、§194 請求是現行機制，但無法正確反映生命之價值，故有學者提出餘命損害之概念，認應由繼承人就被害人生命權受侵害之損失請求賠償」，**不能**直接以餘命損害作為請求權基礎 |
| 「間接被害人之請求，直接被害人與有過失時如何處理？」 | 間接被害人之權利衍生自直接被害人之損害 → **須承擔直接被害人之與有過失**，有 §217 過失相抵之適用（73 台再 182） |
| 「胎兒被侵害致死？胎兒為 §194 之子女？」 | 胎兒被侵害致死（死產）→ 不符 §7「非死產者為限」→ 無權利能力，父母無法就胎兒死亡主張 §192、§194（至於母親身體健康權受侵害另論，講義 57～58 頁）。反之，被害人死亡時其子女尚為胎兒 → 視為既已出生，得請求 §194 慰撫金，不得因胎兒或年幼而不賠或減賠（66 台上 2759） |
| 「為何說人命不值錢？」 | 撞成植物人：§193 勞動能力減損（30→65 歲 35 年收入）＋增加生活需要（至平均餘命 50 年照護）＋慰撫金 → 數千萬；撞死：喪葬費、醫藥費、扶養費＋§194 慰撫金 → 一兩百萬 |

## 一、體系圖

```
乙 ──不法侵害致死──→ 甲（直接被害人，權利能力消滅，不能告）
                       │
                       ├ 財產上間接被害人：§192 I 支出醫療、生活需要、殯葬費之人
                       │                   §192 II 甲負法定扶養義務之人
                       └ 非財產上間接被害人：§194 父母、子女、配偶（慰撫金）
學者反思：甲自己的損害呢？→ 餘命損害（繼承人主張）→ 立法論
```

## 二、餘命損害：立法論 vs 解釋論

| | 現行法 | 餘命損害理論 |
|---|---|---|
| 誰的損害 | 間接被害人的 | 甲本人生命權的 |
| 原告 | §192、§194 之人 | 甲之繼承人 |
| 可否解釋出來 | — | **不行**：§6 權利能力終於死亡，死亡瞬間無請求權發生，無從繼承 |
| 老師評價 | 立法上的選擇 | 有討論空間，但行車記錄器普及後「輾死比撞傷便宜」的誘因已少，實際需求不大 |
| 學者歸屬（註 99） | 多數說否定：王澤鑑 | 林誠二：將來修法引進 |
