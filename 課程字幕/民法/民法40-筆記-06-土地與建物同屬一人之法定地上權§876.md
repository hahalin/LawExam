# 民法40 筆記：土地與建物同屬一人之法定地上權（§876）

## 要件：設定抵押權時，土地與建物同屬一人
- 甲有 A 地及地上 B 屋；自己的地上蓋自己的房子，本來不需要任何權利
- 甲只以 A 地設定抵押權給乙，乙實行後由丙拍定 → A 地屬丙、B 屋仍屬甲
- 同樣適用：只抵押 B 屋；或地、屋一起抵押但由不同人拍定（§876 II）
- 判斷時點是**設定抵押權時**（與 §425-1、§838-1 不同，見筆記-10）

## 效果：視為已有地上權之設定
- 地租、期間、範圍由當事人協議，不能協議由法院判決定之
- 目的：讓**原本就存在**的 B 屋不被拆，不是讓甲在丙的地上重新蓋房子
- 最高法院判例：法定地上權**存續至建物不堪使用為止**（老師未唸字號，建議查證）

## 經典考點：建物滅失後能否重建
| | 意定地上權（§841） | 法定地上權（§876、§838-1） |
|---|---|---|
| 建物滅失 | 地上權**不消滅**，可以再蓋 | 地上權**隨之消滅** |
| 理由 | 地上權本是蓋房子的權利 | 只為保護既存建物 |

- 題型：地震房屋倒塌，可否在土地上重建？法定地上權 → **不能**；意定地上權 → **可以**

## 📖 法條原文速查

> **§876**（法定地上權）
> I **設定抵押權時**，土地及其土地上之建築物，**同屬於一人所有**，而僅以土地或僅以建築物為抵押者，於抵押物拍賣時，**視為已有地上權之設定**，其地租、期間及範圍由當事人協議定之。不能協議者，得聲請法院以判決定之。
> II 設定抵押權時，土地及其土地上之建築物，同屬於一人所有，而以土地及建築物為抵押者，如經拍賣，其土地與建築物之**拍定人各異**時，適用前項之規定。

> **§838-1 II**（強制執行之法定地上權）前項地上權，因**建築物之滅失而消滅**。

> **§841**（地上權之永續性）地上權**不因建築物或其他工作物之滅失而消滅**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§876 判斷土地房屋同屬一人之時點？」 | **設定抵押權時** |
| 「地屋一併抵押，由不同人拍定？」 | 亦有法定地上權（§876 II） |
| 「法定地上權之存續期間？」 | 至**建物不堪使用**為止 |
| 「法定地上權之建物因地震倒塌，得否重建？」 | **否**，地上權消滅 |
| 「意定地上權之建物滅失？」 | 地上權**不消滅**（§841） |

## 圖示

```
設定抵押時：A 地（甲）＋ B 屋（甲）  ← 同屬一人
     │ 只抵押 A 地給乙
     ▼
實行抵押權，丙拍定 A 地
     ▼
A 地（丙）／B 屋（甲）  → B 屋視為有地上權（§876 I）
                          地租協議，不成由法院定
                          B 屋不堪使用或滅失 → 地上權消滅
```
