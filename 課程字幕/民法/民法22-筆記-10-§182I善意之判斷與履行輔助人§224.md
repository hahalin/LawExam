# 民法22 筆記：§182I善意之判斷與履行輔助人（§224）

## 案例（113 台上 1223 裁定，講義 344 頁、註 538）：
- Y 為了幫小孩 A 買房，委託在 X 農會任職的妹妹 S 代辦貸款，只授權借 **216 萬**
- Y 把身分證、存摺、提款卡密碼全交給 S 保管，帳戶由 S 管理
- S 卻以 Y 名義向 X 借了 **800 萬**，撥入 Y 帳戶；S 依 Y 指示匯 216 萬給建商，其餘 **584 萬**盜領一空
- Y 完全不知情；X 想找有不動產可供執行的 Y、A，不想找沒錢的 S

## 第一訴：表見代理敗訴
- 216 萬內有權代理 → 消費借貸有效，Y 應清償
- 584 萬是無權代理，Y 拒絕承認 → 不生效力
- 表見代理要相對人善意無過失；S 是 X 自己的職員，S 的過失就是 X 的過失 → 不成立

## 第二訴：不當得利，法院駁回
- 584 萬匯入 Y 帳戶 → Y 受利益、兩造無消費借貸 → 成立 §179
- 錢已被提領 → 償還價額
- Y 自始不知情 → **善意**，所受利益已不存在 → 依 §182 I **免返還**
- 最高法院維持二審：X 應去找 S

## 詹森林第一層：S 的惡意算 Y 的惡意
- §224 放在「債之效力」，所有的債都適用，**包括不當得利之債**
- 584 萬匯入時，Y 即負不當得利返還義務
- Y 委託 S 管理帳戶，S 就是替 Y 處理帳戶款項（含返還不當得利）的**履行輔助人**
- S 是惡意（盜領者）→ 依 §224 Y 應負同一責任 → Y 為惡意 → 不能用 §182 I
- 理由：事情由 Y 委託 S 惹起，不能完美切割、把風險全推給 S

## 詹森林第二層：善意也要無過失
- 退一步，委託管帳戶未必等於委託返還不當得利，§224 未必能用
- 但 Y 把帳戶全交給人、不聞不問，至少**善意有過失**
- §182 I 立法理由說「不問有無過失」，卻沒說為什麼 → 只是僅供參考
- 依**過失責任原則**，§182 I 的善意應**限於無過失** → Y 仍不能免返還

## 📖 法條原文速查

> **§224**　債務人之代理人或使用人，**關於債之履行**有故意或過失時，債務人應與自己之故意或過失負同一責任。但當事人另有訂定者，不在此限。

> **§182 I**　不當得利之受領人，不知無法律上之原因，而其所受之利益已不存在者，免負返還或償還價額之責任。

> **§169**　由自己之行為表示以代理權授與他人，或知他人表示為其代理人而不為反對之表示者，對於第三人應負授權人之責任。但第三人明知其無代理權或可得而知者，不在此限。

## 📋 實務見解速查

> **113 台上 1223 裁定**（講義註 538，要旨）：584 萬元部分兩造間無消費借貸關係，被上訴人無法律上原因而受利益；惟該款項經第三人陸續提領匯出而不存在，帳戶於該期間均由該第三人保管，被上訴人無從得知上訴人匯入款項，依 §182 I 免負返還責任，上訴人依 §179、§182 II 請求為無理由。（要旨改寫，建議查證）

> **詹森林教授評釋**（月旦裁判時報，講義註 537）：§224 適用於不當得利之債；受領人之善意應限於無過失。（出處依字幕，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§224 是否適用於不當得利之債？」 | 詹森林：**是**，§224 位於債之效力 |
| 「帳戶管理人之惡意，得否歸由帳戶名義人承擔？」 | 詹森林：依 **§224** 可以 |
| 「§182 I 之善意是否須無過失？」 | 立法理由：**不問過失**；詹森林：應**限於無過失** |
| 「本案實務結論？」 | 名義人善意、利益不存在，**免返還** |
| 「相對人之職員即為無權代理人，得主張表見代理？」 | **否**，相對人非善意無過失 |

## 一、兩個訴訟

```
X 農會 → Y 請求 584 萬
├─ 第一訴：表見代理（§169）✗ X 非善意無過失
└─ 第二訴：§179
    ├─ 成立：584 萬匯入、無消費借貸
    ├─ §181：償還價額
    └─ §182 I：Y 善意、利益不存在 → 免返還（實務）
        ├─ 詹一：S 是履行輔助人，§224 → Y 惡意 → 須還
        └─ 詹二：善意有過失不得免責 → 須還
```

## 二、實務與學說

| | 113 台上 1223 | 詹森林 |
|---|---|---|
| 善惡意判斷對象 | Y 本人 | 可依 §224 及於 S |
| 是否要求無過失 | 不問（立法理由） | 限於無過失 |
| 結論 | 免返還 | 仍須返還 |
