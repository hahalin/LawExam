# 民法二試02 筆記：營業員詐取客戶財物之僱用人責任（§188）

## 案例（講義 120 頁）：
- 甲證券公司業務經理丙，上班時間用公司設備列印試算表，勸客戶乙賣 A 股買 B 股
- 乙信賴丙，把存摺、印章交丙代操作；丙賣出 A 股後把錢據為己有
- 乙依 §188 I 請求甲、丙連帶賠償 → 甲抗辯：①非執行職務 ②乙與有過失

## 「執行職務」怎麼認定：
- 傳統：**客觀說**（客觀上與職務有關聯、利用職務機會）或**內在關聯說**（與職務有關且僱用人可預見）→ 都會認定丙在執行職務（從寬，保護被害人）
- **陳忠五：信賴說**——被害人與受僱人有**個別特殊往來**（交付存摺印章）時，以被害人的信賴判斷；乙明知這不是營業員職務 → 無保護必要 → 限縮，非執行職務 → 不成立 §188
- **另一位學者（字幕作王一平／王澤鑑，請對講義）**：執行職務照樣從寬（內在關聯說）；重點放在僱用人有無**違反組織義務**（監督營業員、宣導勿交存摺印章）→ 決定甲有無過失

## 📖 法條原文速查

> **民法 §188 I**　受僱人因**執行職務**，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。但選任受僱人及監督其職務之執行，已盡相當之注意或縱加以相當之注意而仍不免發生損害者，僱用人不負賠償責任。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「乙得否依 §188 I 向證券公司求償？」 | 要件：僱傭關係 ✓、**執行職務**（爭點）、不法侵害、僱用人無免責事由 |
| 「客觀說、內在關聯說結論？」 | 丙利用職務機會、公司可預見 → 執行職務 |
| 「陳忠五為何限縮？」 | §188 目的在保護被害人；有個別特殊往來、明知非職務範圍者，無值得保護之信賴 → 信賴說 → 非執行職務 |
| 「另一路徑？」 | 不限縮執行職務，改審查甲有無違反組織義務（監督、宣導）→ 有違反即有過失、成立 §188 |
| 「甲成立 §188 後能主張乙與有過失嗎？」 | 甲僅有過失 → 可以（§217 I）；乙改向故意的丙請求時才有爭議（筆記 07） |

## 一、執行職務的同心圓

```
┌ 第三圈：與職務完全無關 → 不成立 §188
│ ┌ 第二圈：與職務有關聯（客觀說、內在關聯說）→ 從寬認定成立
│ │ ┌ 核心：真正的執行職務 → 成立
陳忠五：被害人與受僱人有個別特殊往來、明知非職務 → 第二圈不擴張（信賴說）
```

## 二、兩條路徑

| | 陳忠五（信賴說） | 組織義務路徑 |
|---|---|---|
| 調整點 | 「執行職務」限縮 | 僱用人過失（組織義務） |
| 本件 | 非執行職務 → 不成立 | 看甲有無監督、宣導 → 可能成立 |
