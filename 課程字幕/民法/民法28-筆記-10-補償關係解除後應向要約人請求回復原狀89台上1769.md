# 民法28 筆記：補償關係解除後應向要約人請求回復原狀（89台上1769）

## 案例：
- 甲乙訂土地買賣契約，含第三人約款：甲應向丙給付
- 丙已表示享受，甲也已把土地移轉登記給丙
- 乙一直不付價金，甲催告後依 §254 解約
- 解約後，甲要向誰請求回復原狀？

## 前提爭點：甲能不能解約？
- 丙已表示享受並取得利益
- 採**實務與多數說**：法定解除權不受 §269 II 限制 → 可以解約（見民法28-筆記-08）
- 若採林誠二說，題目根本解不下去

## 甲 → 丙：向第三人請求說（少數實務）
- **95 台上 2610**：補償關係依法解除或溯及消滅時，**第三人約款隨之失其存在**
- 第三人約款是丙取得土地的**法律上原因** → 約款消滅 → 丙無法律上原因 → 甲對丙依 **§179** 請求返還
- 問題：這個推論以解除採**溯及消滅說**為前提
  - 依學者多數的**清算說**，契約不溯及消滅，導不出第三人約款跟著消滅
  - 所以這說更站不住

## 甲 → 乙：向要約人請求說（多數說、王澤鑑）
- **89 台上 1769**：第三人雖得直接請求給付，但**不因此成為契約當事人**；應負回復原狀義務者是**要約人**，不是第三人
- 補償關係是甲乙間的法律關係，解除後回復原狀義務人是乙
- 土地不在乙手上 → 乙依 **§259 ⑥ 償還價額**
- 丙本來就**沒有對待給付義務**；乙不付錢，關丙什麼事

## 考試寫法：
1. 先處理丙已表示享受後甲可否解約（實務、多數說可以）
2. 再處理回復原狀對象：採多數說，向乙請求 §259 ⑥ 價額
3. 可補一句：向第三人請求說以溯及消滅說為前提，與清算說不合

## 📖 法條原文速查

> **§259 ⑥**　契約解除時……應返還之物有毀損、滅失或因其他事由，致不能返還者，應**償還其價額**。

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

> **§269 I**　以契約訂定向第三人為給付者，要約人得請求債務人向第三人為給付，其第三人對於債務人，亦有直接請求給付之權。

---

## 📋 實務見解速查

> **95 台上 2610**（講義 550 頁；少數說）：為補償關係之契約，苟經依法解除或溯及消滅，**第三人約款即隨之失其存在**。

> **89 台上 1769**（多數說）：附第三人利益約款之契約，涉及債務人與要約人、要約人與第三人及債務人與第三人間之三面關係；第三人雖得直接向債務人請求給付，但並不因此成為契約當事人。契約解除時，應負回復原狀義務者，為**要約人而非第三人**。→ 判決原文建議查證

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「第三人已受領給付，債務人解約後向誰請求回復原狀？」 | 多數說：**要約人**（89 台上 1769） |
| 「要約人無法返還標的物？」 | **§259 ⑥ 償還價額** |
| 「利益第三人是否為契約當事人？」 | **不是** |
| 「向第三人依 §179 請求的見解採何種解除效力？」 | **溯及消滅說**（95 台上 2610） |

## 兩說對照

| | 向第三人請求說 | 向要約人請求說 |
|---|---|---|
| 地位 | 少數實務 | 多數說、王澤鑑 |
| 實務見解 | 95 台上 2610 | 89 台上 1769 |
| 請求對象 | 丙 | 乙 |
| 依據 | §179 | §259（⑥ 價額） |
| 解除效力前提 | 溯及消滅說 | 與清算說相容 |

```
甲 ──解約（§254）──→ 乙
│                     │
│  ✗ 少數：§179 向丙  │ ✓ 多數：§259 ⑥ 向乙請求價額
↓                     │
丙（已受領土地，非當事人）
```
