# 民法41 筆記：同一人兼為保證人與抵押人之分擔額（群團主義與單一雙重責任說）

## 題目設定：
- 甲向乙借 **1,500 萬**
- 丙提供 A 地、丁提供 B 地、戊提供 C 地，都設定抵押權給乙；A、B、C 價值都超過 1,500（計算時以債權額 1,500 為準）
- **丙另外又擔任保證人**，保證全額 1,500
- 乙拍賣 A 地拿足 1,500 → 丙可以向丁、戊各求償多少？
- 關鍵：丙同時是人保與物保，分擔額怎麼算決定求償額

## 第一說：群團主義（少數說）：
- 出處：一位高院法官最早處理這個問題（臺灣高等法院 98 上 331 判決為代表）
- 理由：§879 II 文字是「保證人」對「抵押物」→ 分成兩組
- 保證人組（丙）：抵押物組（A＋B＋C）＝1,500：1,500＝**1：1**
- 丙保證分擔 750；抵押物組 750 再三分，每筆 **250**
- 丙自己共負擔 750＋250＝1,000 → 向丁、戊各求償 **250**
- 老師：考試可以忽略

## 第二說：個別主義（通說，最高法院與學者）：
- 法條沒有要分組，每一個保證人、每一個抵押物各自按比例算
- 個別主義底下又分兩種算法：

| | 單一責任說（實務） | 雙重責任說（學說） |
|---|---|---|
| 想法 | 保證人以全部財產負責，A 地本來就在裡面 → 被保證責任吸收 | 願意當保證人又提供抵押物，就是給了兩份擔保 |
| 計算單位 | 丙（含 A）一份、B 一份、C 一份 → **3 份** | A、B、C、丙保證 → **4 份** |
| 每份 | 1,500÷3＝**500** | 1,500÷4＝**375** |
| 丙向丁、戊各求償 | **500** | **375** |
| 代表 | 最高法院 99 台上 1204（字幕作「991204號」，建議查證） | 杜怡靜文章等 |

- 雙重責任說的另一理由：丁、戊設定時看到的就是「A 地＋丙保證」兩個擔保，沒料到會被算成一個 → 保護其他擔保人的信賴

## 學者文章（講義 302 頁）：
- 杜怡靜：解釋論採**雙重責任說**（我國民法導不出單一責任）
- 立法論贊成改採日本法的單一責任，避免保證人負全額保證又多負一份物上責任

## 📖 法條原文速查

> **§879 II** 債務人如有保證人時，保證人應分擔之部分，依保證人應負之履行責任與抵押物之價值或限定之金額比例定之。抵押物之擔保債權額少於抵押物之價值者，應以該債權額為準。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「同一人兼保證人與抵押人，實務見解？」 | 個別主義＋**單一責任**（只算一份） |
| 「學說多數？」 | 個別主義＋**雙重責任**（算兩份） |
| 「群團主義怎麼分？」 | 保證人一組、抵押物一組，先 1：1 再組內平分 |
| 「三說求償額比較（本例）？」 | 群團 250、單一 500、雙重 375 |

## 三說計算總表（單位：萬元）

| 擔保 | 群團主義 | 單一責任 | 雙重責任 |
|---|---|---|---|
| 丙保證 | 750 | 500（含 A） | 375 |
| A 地（丙） | 250 | ↑ | 375 |
| B 地（丁） | 250 | 500 | 375 |
| C 地（戊） | 250 | 500 | 375 |
| 丙合計負擔 | 1,000 | 500 | 750 |
| 丙向丁、戊各求償 | 250 | 500 | 375 |

## 判斷順序

```
有人同時是保證人＋抵押人
   │
   ├─ 分不分組？ 分 → 群團主義（少數）
   └─ 不分組（個別主義，通說）
          ├─ 算一份 → 單一責任說（實務）
          └─ 算兩份 → 雙重責任說（學說）
```
