# 民法07 筆記：意思表示「不成立」vs「有瑕疵」——陳忠五的四要素分析與媽媽簽名案

> 來源：民法07 課程字幕 00:30:47 ~ 00:41:16（講義 180～182 頁，陳忠五兩篇文章）

---

## 📖 法條原文速查

> **§88 I**　意思表示錯誤 → 得撤銷　　**§90**　撤銷權自意思表示後經過**一年**而消滅
> **§92 I**　被詐欺或被脅迫 → 得撤銷　　**§93**　自發見詐欺或脅迫終止後**一年**內為之；自意思表示後經過十年不得撤銷
> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。
> **§184 I**、**§179**　侵權行為、不當得利

---

## 📋 實務見解速查

> 媽媽簽名案（講義 180 頁，字號請對講義）：母親將所有權狀交兒子保管，兒子持買賣契約書請母親簽名，土地遭移轉；母親主張不知所簽為何。二審：意思表示之瑕疵（§88、§92），未撤銷前請求無理由。最高法院：本件涉及**意思表示是否成立／是否合致**，非意思表示瑕疵。
> → 陳忠五：二審較正確，最高法院有待商榷；但可理解最高法院是為了讓表意人不受除斥期間限制

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「意思表示之四要素？」 | 客觀：**表示行為**；主觀：**行為意思、表示意思、效果意思** |
| 「欠缺何者意思表示不成立？」 | 欠缺**表示行為**或**行為意思**（不知道自己在簽名）→ **不成立** |
| 「欠缺效果意思或表示意思？」 | 意思表示**成立但有瑕疵** → §88、§92 撤銷（陳忠五） |
| 「不成立與得撤銷之實益？」 | 不成立 → 無除斥期間，隨時確認之訴＋§767；得撤銷 → 受 §90 一年／§93 一年十年限制，未撤銷前不能回復 |
| 「媽媽知道自己在簽名，但不知道簽的是買賣契約？」 | 有表示行為、有行為意思 → 意思表示**成立**；不知效果 → **瑕疵**（錯誤或被詐欺） |

## 一、兩個概念的差別

```
意思表示 ＝ 表示行為（外部）＋ 意思（內部：行為意思、表示意思、效果意思）
            ↑ 客觀要素             ↑ 主觀要素

陳忠五：
  表示行為 欠缺 → 沒有意思表示可言 → 不成立
  行為意思 欠缺 → 不是基於自己的意思而表示（連自己在簽名都不知道）→ 不成立
  表示意思／效果意思 欠缺 → 只是誤認效果、不知行為會發生什麼效果 → 成立但有瑕疵 → §88、§92
```

| 階段出錯 | 結果 | 處理 |
|------|------|------|
| 根本不知道自己在做什麼（無行為意思）、沒有表示行為 | 意思表示**不成立** → 契約不成立 | 確認之訴、§767、§179、§184，**無除斥期間** |
| 知道自己在簽名，但誤買賣為贈與、不知簽了會過戶 | 意思表示**成立但有瑕疵** | §88 錯誤／§92 詐欺 → 撤銷 → §114 自始無效，**受 §90、§93 限制** |

## 二、媽媽簽名案
```
兒子：媽，幫我簽一下 → 媽媽什麼都沒問就簽 → 土地被過戶
媽媽抗辯：我不知道我在簽什麼
    她知道自己在【簽名】嗎？知道 → 有行為意思、有表示行為 → 意思表示成立
    她不知道簽名會發生什麼效果 → 那是效果意思／表示意思的問題 → 瑕疵
→ 二審（瑕疵）較正確；最高法院（不成立）有待商榷
```

### 最高法院為什麼硬要說「不成立」
```
若是瑕疵 → §88 要在意思表示後一年內撤銷（§90）、§92 發現後一年內（§93）
    → 老母親 10 年、20 年後才發現 → 來不及 → 回復不了
若是不成立 → 自始沒有意思表示 → 對方從未取得土地 → 隨時 §767 要回
→ 從個案保護看，「不成立」對表意人保護較足
```
- 陳忠五第二篇文章（講義 182 頁）：可理解最高法院的考量，但應透過締約上過失、侵權行為、§92 較長的除斥期間（一年／十年）從寬保護，而不是把得撤銷說成不成立。
- 考試第一步：先判斷**到底在哪一個要素出錯** → 決定走不成立還是走瑕疵。
