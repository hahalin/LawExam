# 民法02 筆記：輔助宣告 §15-1 §15-2 與監護宣告比較

> 來源：民法02 課程字幕 00:18:29 ~ 00:30:56

---

## 📖 法條原文速查

> **§15-1**（輔助之宣告）
> I 對於因精神障礙或其他心智缺陷，致其為意思表示或受意思表示，或辨識其意思表示效果之能力，**顯有不足**者，法院得因**本人、配偶、四親等內之親屬、最近一年有同居事實之其他親屬、檢察官、主管機關或社會福利機構**之聲請，為輔助之宣告。
> II 受輔助之原因消滅時，法院**應**依前項聲請權人之聲請，**撤銷**其宣告。
> III 受輔助宣告之人**有受監護之必要**者，法院得依第十四條第一項規定，**變更**為監護之宣告。

> **§15-2**（受輔助宣告人之能力）
> I 受輔助宣告之人為下列行為時，**應經輔助人同意**。但純獲法律上利益，或依其年齡及身分、日常生活所必需者，不在此限：
> 一、為獨資、合夥營業或為法人之負責人。
> 二、為消費借貸、消費寄託、保證、贈與或信託。
> 三、為訴訟行為。
> 四、為和解、調解、調處或簽署仲裁契約。
> 五、為**不動產、船舶、航空器、汽車或其他重要財產**之處分、設定負擔、買賣、租賃或借貸。
> 六、為遺產分割、遺贈、拋棄繼承權或其他相關權利。
> 七、法院依前條聲請權人或輔助人之聲請，所指定之其他行為。
> II 第 78 條至第 83 條規定，於未依前項規定得輔助人同意之情形，**準用**之。
> → 建議查閱最新六法原文（第 III、IV 項略）

> **家事事件法 §179 I**
> 法院對於輔助宣告之聲請，認有監護宣告之必要者，得依聲請或依職權以裁定為監護之宣告。
> → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「受輔助宣告之人為限制行為能力人？」 | **錯**。仍是**完全行為能力人**，只在 §15-2 I 特定事項需輔助人同意 |
| 「受輔助宣告之人買一台腳踏車，效力？」 | **有效**，不需同意。腳踏車不是 §15-2 I ⑤ 的「重要財產」 |
| 「意定監護受任人／輔助人／利害關係人可否聲請輔助宣告？」 | **不可**。輔助宣告聲請權人只有基本款那一組 |
| 「聲請輔助宣告，法院認已達不能程度，可否直接為監護宣告？」 | **可**，依據是**家事事件法 §179**，不是 §15-1 III（那是「變更」，前提是已受輔助宣告） |
| 「受輔助宣告人狀況惡化？」 | 法院得**變更為監護宣告**（§15-1 III） |
| 「可否對 15 歲國中生為輔助宣告？」 | **不可**（無實益）。對限制行為能力人只能做監護宣告 |

---

## 一、要件：顯有不足 ＋ 聲請（只有基本款）＋ 法院宣告

### 聲請權人為什麼沒有第二組
- 意定監護受任人：意定監護是監護制度的配套，與輔助無關。
- 輔助人：還沒被輔助宣告的人，根本沒有輔助人。
- 其他利害關係人：還沒到「不能」，沒有聲請實益。

### 法院的三種結果

```
聲請輔助宣告 → 法院審查
    ├── 不足   → 輔助宣告（§15-1 I）
    ├── 不能   → 直接監護宣告【依據：家事事件法 §179，§15-1 沒規定這種情形】
    └── 正常   → 駁回
```

- 為什麼不是 §15-1 III？該項是「受輔助宣告之人……**變更**為監護」，前提是已經受輔助宣告。現在連輔助宣告都還沒做，無從「變更」。

## 二、撤銷：三種結果

```
聲請撤銷輔助宣告 → 法院重新判斷
    ├── 更糟（不能）→ 職權變更為監護宣告（§15-1 III）
    ├── 仍不足      → 駁回撤銷
    └── 恢復正常    → 撤銷（§15-1 II）
```

## 三、效果：仍有完全行為能力，只在特定事項需輔助

```
15 歲甲 向乙買 A 腳踏車
    → 限制行為能力人；非日常所需、非純獲利益 → §77、§79 效力未定

受輔助宣告之甲 向乙買 A 腳踏車
    → 檢查 §15-2 I 七款：
         ⑤ 不動產、船舶、航空器、汽車、其他重要財產 ← 腳踏車幾百幾千塊，不是
    → 不在七款內 → 不受限制 → 直接買，有效
```

- 立法者**沒有要剝奪或限制**受輔助宣告人的行為能力，只是在有必要時旁邊有人輔助。
- 選擇題陷阱：「受輔助宣告之人＝限制行為能力人」很多人打勾，因為 §15-2 II 準用 §78～§83 看起來很像。**不對**。
- 進階（後面講）：受輔助宣告之人可否立遺囑？涉及 §1186 與 §15-2 的解釋。

## 四、監護宣告 vs 輔助宣告 總表

| 比較項目 | 監護宣告 | 輔助宣告 |
|---------|---------|---------|
| 條號 | §14、§15 | §15-1、§15-2 |
| 主觀要件用語 | **不能** | **顯有不足** |
| 聲請權人 | 基本款 ＋ 108 年新增三種 | **只有基本款** |
| 法院可改判？ | 未達 → 改輔助（§14 III） | 已達不能 → 改監護（**家事事件法 §179**） |
| 效果 | **無行為能力**（§15）→ 行為無效（§75） | **仍有行為能力**，§15-2 I 七款需同意 |
| 撤銷時中間結果 | 變更為輔助（§14 IV） | 變更為監護（§15-1 III） |
| 對象 | 完全＋限制行為能力人 | **只有**完全行為能力人 |
| 目的 | 剝奪 | 限制 |
