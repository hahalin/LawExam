# 民法41 筆記：流抵契約與抵押物之其他處分方法（§873-1§878）

## 抵押權實行方法總覽：
- **拍賣**：一般情形；涉及建築物時另有 §876、§877、§877-1 與強制執行法 §98 II（上一講）
- **多數擔保**：共同抵押 §875～§875-4、人保物保 §879、§879-1（本講前段）
- **其他方法**：流抵契約 §873-1、清償期後之契約 §878

## 流抵契約為什麼以前無效：
- 情境：甲向乙借 **500 萬**，A 地（市價 **800 萬**）設定抵押，約定「到期不還，A 地歸乙」
- 缺點一：通常只是債權約定，登記簿只看得到抵押權 → **欠缺公示**，害及交易安全
- 缺點二：**沒有找補**，A 地 800 萬全歸乙抵 500 萬，甲白損 300 萬
- 缺點三：到期就直接移轉，甲**沒有緩衝**，失去以清償消滅抵押權的機會
- 名稱：流抵、流押契約／約款都可以

## §873-1 一個缺點對一項修正：

| 缺點 | 修正 | 項次 |
|---|---|---|
| 欠缺公示 | **非經登記不得對抗第三人** | I |
| 沒有找補 | 價值超過擔保債權**返還**抵押人；不足仍可請求債務人清償（**多退少補**） | II |
| 沒有緩衝 | 所有權移轉前，抵押人**得清償**以消滅抵押權 | III |

- 數字：借 500、A 值 800 → 乙要找 **300**；借 1,000、A 值 800 → 甲還要補 **200**
- 性質：流抵約款只有**債權效力**，乙到期只取得**移轉登記請求權**，不是自動取得所有權（第 III 項「移轉於抵押權人前」可佐證）

## §878 和 §873-1 差在訂約時點：
- §878：清償期屆滿後**未受清償**，可訂約取得抵押物所有權，或用拍賣以外方法處分（如出租）；但不得有害其他抵押權人
- 看起來都是「不還錢，抵押物歸債權人」，差在**什麼時候約定**：

| | §873-1 流抵 | §878 |
|---|---|---|
| 約定時點 | **設定抵押權時**（借錢時） | **清償期屆滿後** |
| 雙方地位 | 債務人有求於人，容易接受不公平條款 | 已經還不出來，換債權人有求於人，地位對等 |
| 找補 | **要**（§873-1 II） | **不用** |
| 例 | 借 500、地值 800 → 找 300 | 借 1,000、地值 600 → 雙方合意以地抵償、一筆勾銷，債權人賭地價上漲 |

## 📖 法條原文速查

> **§873-1** I 約定於債權已屆清償期而未為清償時，抵押物之所有權移屬於抵押權人者，非經登記，不得對抗第三人。
> II 抵押權人請求抵押人為抵押物所有權之移轉時，抵押物價值超過擔保債權部分，應返還抵押人；不足清償擔保債權者，仍得請求債務人清償。
> III 抵押人在抵押物所有權移轉於抵押權人前，得清償抵押權擔保之債權，以消滅該抵押權。

> **§878** 抵押權人於債權清償期屆滿後，為受清償，得訂立契約，取得抵押物之所有權，或用拍賣以外之方法，處分抵押物。但有害於其他抵押權人之利益者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「流抵約款現行法有效嗎？」 | **有效**，未登記不得對抗第三人 |
| 「流抵約款到期後抵押權人當然取得所有權？」 | **否**，只有移轉請求權（債權效力） |
| 「抵押物價值超過債權？」 | 超過部分返還抵押人（§873-1 II） |
| 「移轉前抵押人可否清償？」 | 可以，清償後抵押權消滅（§873-1 III） |
| 「§878 須找補嗎？」 | 條文未規定；老師：地位對等，不需找補 |
| 「§878 限制？」 | 不得害及其他抵押權人 |

## 流抵約款的時間軸

```
設定抵押＋流抵約款（登記）
   ↓
清償期屆至，未清償
   ↓
乙取得「移轉登記請求權」 ←── 這段期間甲仍可清償 → 塗銷抵押權
   ↓
移轉登記完成 → 計算差額，多退少補
```
