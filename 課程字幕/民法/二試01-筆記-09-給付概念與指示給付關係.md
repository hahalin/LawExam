# 民法二試01 筆記：給付概念與指示給付關係

## 給付是什麼：
- 通說：**有意識、有目的**地增加他人財產
- 給付的**指向性**：看給付人心裡要清償誰的債 → 決定不當得利的當事人

## 指示給付（三角關係）：
- 乙指示甲直接交付給丙：甲乙＝補償關係、乙丙＝對價關係、甲丙＝履行關係（只有履行，沒有給付）
- 補償關係（甲乙）無效 → 甲應向**乙**主張給付型不當得利，不是向丙
- **給付型不當得利優先原則**（非給付型補充原則）：同一受利益客體，經由他人給付而取得者，不再成立非給付型不當得利

## 第三人利益契約（§269）：
- 第三人丙對甲有直接請求權 → 給付關係可能同時存在於甲乙、甲丙
- 王澤鑑、多數實務：仍向**乙**請求（甲給付丙是為了滿足與乙的補償關係）；少數實務：可向丙

## 📖 法條原文速查

> **民法 §179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。……
> **民法 §269 I**　以契約訂定向第三人為給付者，要約人得請求債務人向第三人為給付，其第三人對於債務人，亦有直接請求給付之權。

---

## 📋 實務見解速查

> **最高法院 106 年度台上字第 239 號判決**（講義註 85，台電案）：給付不當得利之給付，係指有意識地基於一定目的而增加他人財產，以給付目的指向決定給付關係當事人；指示給付關係中，給付關係存在於指示人與被指示人、指示人與領取人之間，被指示人與領取人間僅有履行關係；受領人之利益經由他人給付而來者，就同一受利益客體不能同時成立非給付型不當得利。
> **最高法院 113 年判決**（講義註 84，字號請對講義）：明確承認給付型不當得利優先原則。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「乙向甲買車再轉賣丙，指示甲直接交車給丙；甲乙買賣無效，甲向誰請求？」 | 向**乙**。甲交車時心裡要清償的是對乙的債 → 給付指向乙 |
| 「丙確實拿到車，甲能否改對丙主張非給付型不當得利？」 | 不能。給付型不當得利優先，同一客體不再成立非給付型 |
| 「台電案？」 | 林水火依與台電之契約要求台電供電給太美公司；契約無效 → 台電向林水火請求，不向太美公司（106 台上 239） |
| 「第三人利益契約有何不同？」 | 丙有直接請求權（§269），給付關係可能兩邊都有；多數仍認給付在甲乙之間 → 向乙請求 |

## 一、三角關係圖

```
          乙（指示人）
     補償關係 ／   ＼ 對價關係
           ／       ＼
   甲（被指示人）——→ 丙（領取人）
          履行關係（只有交付，無給付關係）

補償關係無效 → 甲 → 乙：給付型不當得利
               甲 → 丙：✗（給付型優先，非給付型補充）
```
