# 民法二試01 筆記：強制道歉與回復名譽之適當處分（§195 I 後段）

## 爭點在哪個要件：
- 乙侵害甲名譽 → 甲依 §184 I 前段請求損害賠償：財產上損害（§216）、非財產上損害（§195 I 前段）
- 甲能否請求乙**道歉**？依據是 §195 I 後段「回復名譽之**適當處分**」
- 強制道歉能否涵攝進「回復名譽」＋「適當處分」

## 各說：
- **釋字 656**：命加害人公開道歉，未涉自我羞辱等損及人性尊嚴者，不違比例原則 → 適當
- **111 年憲判字第 2 號**：強制道歉侵害不表意自由 → 「適當處分」**不包括**法院判決命道歉
- **陳忠五**：連「回復名譽」都難該當（道歉不能澄清事實）；且不適當 → 改採**刊登判決重要內容**

## 📖 法條原文速查

> **民法 §195 I**　不法侵害他人之身體、健康、名譽、自由、信用、隱私、貞操，或不法侵害其他人格法益而情節重大者，被害人雖非財產上之損害，亦得請求賠償相當之金額。其名譽被侵害者，並得請求**回復名譽之適當處分**。

---

## 📋 實務見解速查

> **釋字 656**（講義註 5）：§195 I 後段所謂回復名譽之適當處分，如屬以判決命加害人公開道歉，而未涉及加害人自我羞辱等損及人性尊嚴之情事者，即未違背憲法 §23 比例原則，不牴觸憲法對不表意自由之保障。
> **111 年憲判字第 2 號**（講義註 6）：§195 I 後段所稱之適當處分，應不包括法院以判決命加害人道歉之情形，始符憲法保障人民言論自由及思想自由之意旨。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「甲得否請求乙登報道歉？」 | 依據 §195 I 後段 → 拆成「回復名譽」（目的）＋「適當處分」（手段） |
| 「釋字 656 與 111 憲判 2 差在哪？」 | 都糾結在「**適當**」：656 原則適當（除自我羞辱）；111 憲判 2 侵害不表意自由，不適當 |
| 「學說更進一步？」 | 陳忠五：道歉不能澄清事實，**連目的（回復名譽）都達不到**；改採刊登判決重要內容 |
| 「結論怎麼寫？」 | 依 111 憲判 2，強制道歉非適當處分；得請求刊登判決重要內容（目的上能澄清事實、手段上判決本即公開） |

## 一、要件拆解

```
§195 I 後段：名譽被侵害 → 得請求「回復名譽」之「適當處分」
                              目的          手段
強制道歉：
  目的 → 名譽＝社會評價；回復要靠澄清事實；道歉不能澄清 → ✗（陳忠五）

刊登判決重要內容：
  目的 → 判決事實經法院調查，可澄清事實 → ✓
  手段 → 判決本來就公開 → ✓
```
