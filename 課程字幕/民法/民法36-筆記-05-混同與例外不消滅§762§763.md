# 民法36 筆記：混同與例外不消滅（§762、§763）

## 原則與例外：
- 原則：同一物的所有權與其他物權歸於一人 → 其他物權因混同消滅（在自己的地上設地上權是多此一舉）
- 例外：其他物權的存續，對**所有人或第三人有法律上利益** → 不消滅
- 一句話：要消滅可以，但不要影響到別人
- §762 但書、§763 II、§764 II 法理相通（§764 II 見本講筆記-04），選擇題超愛考

## 例一：地上權上有權利抵押權（§762 但書保護第三人）：
```
① 甲把 A 地設定地上權給乙
② 乙以地上權設定權利抵押權給丙（擔保乙丙借款）
③ 甲把 A 地賣給乙並移轉登記
```
- 乙同時有所有權與地上權 → 原則上地上權消滅
- 但地上權消滅 → 丙的權利抵押權失去標的一起消滅 → 影響丙
- 結論：地上權**例外不消滅**

## 例二：第一順位抵押權人取得所有權（§762 但書保護所有人）：
- 數字例：A 地值 800 萬元
  - 第一順位抵押權給乙，擔保 600 萬元
  - 第二順位抵押權給丙，擔保 400 萬元
- 正常拍賣：乙 600 萬、丙 200 萬
- 甲把 A 地移轉給乙，若乙的抵押權因混同消滅：
  - 丙升為第一順位，先拿 400 萬，剩下 400 萬才歸乙
  - 乙平白少了 200 萬 → 對**所有人乙**不利
- 結論：乙的抵押權**例外不消滅**，拍賣時乙仍優先受償 600 萬、丙 200 萬

## 例三：§763 連鎖效應：
```
① 甲把 A 地設定地上權給乙
② 乙向丙借錢，以地上權設定權利抵押權給丙
③ 丙向丁借錢，以「丙對乙的債權」設定權利質權給丁
④ 乙把地上權讓與丙
```
- 地上權（所有權以外之物權）與以其為標的之權利抵押權都歸丙 → §763 I：**權利抵押權**消滅（「其權利」指後者）
- 連鎖效應：丙對乙的債權變成**無擔保債權** → 丁的權利質權擔保價值大減
  - 原本：丙不還錢 → 丁拍賣丙對乙的債權；乙不還錢 → 還能拍賣乙的地上權
  - 權利抵押權沒了 → 乙不還就沒救
- 結論：依 §763 II 準用 §762 但書，權利抵押權**例外不消滅**

## 答題判斷法：
- 問「會不會消滅」→ 先套原則，再問：**消滅後誰受不利影響**
- 只要有人（所有人或第三人）受影響 → 例外不消滅

## 📖 法條原文速查

> **§762**　同一物之所有權及其他物權，歸屬於一人者，其他物權因**混同**而消滅。但其他物權之存續，於**所有人或第三人有法律上之利益**者，不在此限。

> **§763**
> I　所有權以外之物權，及以該物權為標的物之權利，歸屬於一人者，**其權利**因混同而消滅。
> II　前條但書之規定，於前項情形**準用**之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「地上權人買受土地，其上有權利抵押權，地上權因混同消滅？」 | **不消滅**，第三人有法律上利益 |
| 「第一順位抵押權人取得抵押物所有權，有後順位抵押權，抵押權消滅？」 | **不消滅**，對所有人有法律上利益 |
| 「§762 但書保護的對象只有第三人？」 | **否**，包括**所有人** |
| 「§763 I 因混同消滅者為哪一權利？」 | **以該物權為標的物之權利**（如權利抵押權） |
| 「§763 是否有例外不消滅？」 | **有**，II 準用 §762 但書 |
