# 民法16 筆記：§185I前段共同加害行為與連帶責任

## 特殊侵權行為總覽：
- 範圍 §185～§191-3；**§185、§187、§188 最常考**（連帶責任）；§190～§191-3 要記各條**推定**了什麼
- 讀每條都問：它「特殊」在哪、處理一般 §184 處理不了的什麼問題

## 共同加害行為要件：
- ①**數人各自成立 §184**（I 前段、I 後段、II 皆可）
- ②**共同**：先問主觀**意思聯絡**（字幕作意識聯絡）→ 有即共同；無 → 再問客觀**行為關聯**
  - 只有客觀行為關聯：**實務肯定**（司法院例變字第 1 號）；**游進發否定**（字幕作遊進發／由進發，請對講義）

## 連帶責任的兩個好處（對被害人）：
- ①**無資力風險**轉由其他共同行為人承擔（§273 對一人請求全部，再由其依 §281 內部求償）
- ②**訴訟成本**降低：不必對每個加害人各打一場官司

## 實務與學說的理由：
- 實務從寬：連帶對被害人太有利，為貫徹保護被害人，擴大 §185 範圍
- 游進發從嚴：連帶使行為人互相承擔對方無資力風險，偶然在巷口相撞波及路人者被綁在一起不合理 → 限**主觀意思聯絡**（講義註 213 文章）
- 考試：選擇題選**實務**；申論可在後面補充少數說

## 時間密接性：
- 乙偷甲車，交丙拆解變賣零件 → 最高法院 100 台上 2217：故買、牙保贓物發生在竊盜損害之後，是**另一個侵權行為**，非共同
- 王澤鑑：最高法院跳過第一步；應先審有無分工的意思聯絡（竊盜集團「我偷你賣」即共同），沒有才審客觀關聯

## 📖 法條原文速查

> **民法 §185 I 前段**　數人**共同**不法侵害他人之權利者，**連帶**負損害賠償責任。

> **民法 §273 I**　連帶債務之債權人，得對於債務人中之**一人或數人或其全體**，同時或先後請求**全部或一部**之給付。

> **民法 §281 I**（要旨）　連帶債務人中之一人清償致他債務人同免責任者，得向他債務人請求償還其**各自分擔之部分**。（原文請對六法）

## 📋 實務見解速查

> **司法院例變字第 1 號**（講義 138 頁；一般引作 66 年例變字第 1 號，年份請對講義）：民事共同侵權行為與刑事共同正犯之構成要件不完全相同，共同行為人間**不以有意思聯絡為必要**；數人因過失不法侵害他人權利，各人過失均為損害之共同原因者（**行為關聯共同**），即足成立共同侵權行為；早期相反判例應予變更。

> **最高法院 100 年度台上字第 2217 號判決**（講義 139 頁）：僅知情而故買或牙保贓物者，係在被害人因竊盜受損害之後，另行成立侵權行為；原審逕認與竊盜者成立共同侵權行為，未盡允洽。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「數人因過失不法侵害他人權利，無意思聯絡，是否成立共同侵權行為？」 | 實務**肯定**：**行為關聯共同**即足（司法院例變字第 1 號）；游進發否定 |
| 「§185 I 前段之共同行為人，每人應成立 §184 何款？」 | I 前段、I 後段或 II **皆可** |
| 「共同侵權行為之連帶責任對被害人之實益？」 | ①不必承擔個別加害人**無資力**風險 ②**訴訟成本**降低 |
| 「竊盜後由他人故買或牙保贓物，竊盜者與故買者是否成立共同侵權行為？」 | **否**（100 台上 2217）：故買在竊盜損害發生**後**，另成立侵權行為 |
| 「共同之審查順序（王澤鑑）？」 | 先審**主觀意思聯絡**；無，再審**客觀行為關聯**（含時間密接性） |

## 一、「共同」的審查流程

```
數人各成立 §184
   ↓
① 主觀意思聯絡？ ── 有 → 共同 ✓
   ↓ 無
② 客觀行為關聯？（行為之關係＋時間密接性）
   ├─ 有 → 實務：共同 ✓／游進發：✗
   └─ 無 → 不共同 ✗
```

## 二、無資力風險的移轉

| | 一般侵權（§184） | 共同侵權（§185＋§273） |
|---|---|---|
| 加害人甲無資力 | 被害人自己承擔 | 被害人找有資力的丙請求全部 |
| 之後 | — | 丙依 §281 向甲內部求償；要不到是丙的事 |
| 訴訟 | 加害人幾個就告幾次 | 一次解決 |

## 三、案例：偷車與處理贓物

| 層次 | 最高法院 | 王澤鑑 |
|---|---|---|
| 第一步 | 未審 | 乙丙有無事先分工之意思聯絡 |
| 第二步 | 偷車與處理贓物是兩件可明確劃分的事，無時間密接 → 非共同 | 無意思聯絡時，認無客觀關聯可以接受 |
