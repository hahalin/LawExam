# 民法02 筆記：法人董事 §27 與代表權

> 來源：民法02 課程字幕 02:21:36 ~ 02:33:34（本堂結尾，§31 登記效力下堂續）

---

## 📖 法條原文速查

> **§27**（法人之機關）
> I 法人**應**設董事。董事有數人者，法人事務之執行，除章程另有規定外，取決於**全體董事過半數之同意**。
> II 董事就法人一切事務，**對外代表法人**。董事有數人者，除章程另有規定外，**各董事均得代表法人**。
> III 對於董事**代表權所加之限制**，**不得對抗善意第三人**。
> IV 法人**得**設監察人，監察法人事務之執行。監察人有數人者，除章程另有規定外，監察權之行使，各得單獨為之。

> **§31**（登記之效力）
> 法人登記後，有應登記之事項而不登記，或已登記之事項有變更而不為變更之登記者，**不得以其事項對抗第三人**。

> **§48 I**（社團設立登記事項，節錄）
> 四、董事之姓名及住所。……八、定有代表法人之董事者，其姓名。

> **§61 I**（財團設立登記事項，節錄）
> 六、董事之姓名及住所。……七、定有代表法人之董事者，其姓名。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人應設監察人？」 | **錯**。董事「**應**」設，監察人「**得**」設（§27 I、IV） |
| 「董事有數人，法人事務之執行（對內）如何決定？」 | 除章程另有規定外，**全體董事過半數同意** |
| 「董事有數人，對外代表權如何行使？」 | 除章程另有規定外，**各董事均得單獨代表**，不須共同 |
| 「對董事代表權所加限制之效力？」 | **不得對抗善意第三人**（§27 III） |
| 「§27 III 適用前提？」 | 行為人必須是**董事**且**有代表權**，只是代表權「受限制」 |
| 「非董事、或無代表權之董事代表法人簽約？」 | 不適用 §27 III，看 **§31 登記效力**（下堂續） |
| 「董事是否一定有代表權？」 | **不一定**。可在章程／登記簿上定「代表法人之董事」（§48 I ⑧、§61 I ⑦） |

## 一、董事＝法人的手足

```
社團法人：社員總會（決定大方向）→ 董事（決定細節、對外執行）
財團法人：捐助章程（決定方向）  → 董事（執行）
```

## 二、§27 四項拆開看

| 項 | 內容 | 關鍵字 |
|----|------|------|
| I | **應**設董事；對內執行：章程另有規定外，**過半數**同意 | 應、過半 |
| II | 對外：各董事**均得**單獨代表 | 獨立代表權 |
| III | 代表權之**限制**不得對抗**善意**第三人 | 限制、善意 |
| IV | **得**設監察人 | 得（可有可無） |

### 對內 vs 對外
```
對內（§27 I）：總會決議「投資風電概念股」→ 哪一支、多少錢、錢從哪來 → 董事開會過半數決定
對外（§27 II）：A 法人已決定向乙買地 → 甲董事一人就可代表 A 簽約，不需全體董事一起
    （章程可另訂「三名董事共同代表」）
```

## 三、考題結構：行為人甲到底是誰？

```
甲「代表」A 法人與 B 簽約 → 契約效力？A 要不要買單？
│
├── 甲是董事 ＋ 有代表權 ＋ 代表權無限制
│       → 有權代表 → 甲的行為＝A 的行為 → A 概括承受，虧損也含淚吞 → 契約有效
│
└── 其他三種（考試在考的）
      ① 甲不是董事（例：任期到去年 12/31，今年已卸任）
      ② 甲是董事但無代表權（登記簿寫明只有爸媽董事有代表權，小孩董事沒有）
      ③ 甲是董事、有代表權，但代表權受限制
```

### 哪一條管哪一種

| 類型 | 適用條文 | 說明 |
|------|---------|------|
| ③ 代表權受限制 | **§27 III** | 限制不得對抗善意第三人。前提：是董事＋有代表權，才有「限制」可言 |
| ① 非董事 | **§31** 登記效力 | 董事是誰＝應登記事項（§48 I ④、§61 I ⑥） |
| ② 無代表權之董事 | **§31** 登記效力 | 誰有代表權＝應登記事項（§48 I ⑧、§61 I ⑦） |

- 沒有的東西無從「限制」→ ①② 不走 §27 III。
- §31 的效果（有登記／沒登記各產生什麼效力、與 §27 III 的差異）→ **下堂課續**。

## 四、代表權可以被剝奪嗎

- 可以。家族企業董事可能是全家人，不想讓小孩有代表權 → 章程／登記簿寫清楚「有代表權之董事為○○」即可。
