# 民法18 筆記：§190動物占有人責任

## 構成要件：
- 原告只要證明兩件事：**動物加損害於他人**、被告是**動物占有人**；過失與因果關係由法律**推定**，由占有人舉證推翻
- 加損害包括**直接與間接**侵害：被狗追而跌倒也算

## 純粹經濟上損失：
- 用語「加損害」與 §184 I 後段相同，文義上似可包括純粹經濟上損失
- 王澤鑑：**目的性限縮**，§190 只是推定過失的規定，仍以**絕對權受侵害**為限；純粹經濟上損失回到 §184 I 後段（須故意以背於善良風俗之方法）
- 例：德國牛瘟案、非洲豬瘟——牧場疏失讓病牛跑出，全國禁宰禁售，業者的營業損失屬**過失**造成的純粹經濟上損失，不能求償

## 誰是動物占有人：
- 指對動物有**事實上管領力**、當場拉得住的人＝**直接占有人、占有輔助人**；**不含間接占有人**
- 甲把狗交給弟弟帶去散步，狗咬人 → 弟弟是直接占有人負 §190；甲是間接占有人（§941），不負 §190
- 選擇題常見陷阱：「主人」往往不是答案

## §190 II 求償權：
- A 犬被乙的 B 犬追逐、受驚撞傷丙 → 丙對甲主張 §190 I（外部）；甲再依 §190 II 向乙求償（內部）
- 爭點一：是否以故意過失為要件——否定說（林誠二、孫森焱，文義）／肯定說（王澤鑑）
- 爭點二：時效——§197 說／§125 十五年說（**多數**：求償權不是單純的損害賠償請求權）

## 📖 法條原文速查

> **§190**　I 動物加損害於他人者，由其**占有人**負損害賠償責任。但依動物之種類及性質已為相當注意之管束，或縱為相當注意之管束而仍不免發生損害者，不在此限。II 動物係由第三人或他動物之挑動，致加損害於他人者，其占有人對於該第三人或該他動物之占有人，有**求償權**。

> **§941**（要旨）　地上權人、質權人、承租人、受寄人或基於其他類似法律關係，對於他人之物為占有者，該他人為**間接占有人**。（原文請對六法）

> **§197 I**（要旨）　侵權行為損害賠償請求權，自知有損害及賠償義務人起 **2 年**、自侵權行為時起 **10 年**不行使而消滅。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲將愛犬交弟弟遛狗，狗咬傷乙，乙得否依 §190 向甲請求？」 | **否**。甲為間接占有人；負 §190 者為**直接占有人**（弟弟） |
| 「§190 之動物占有人是否包括間接占有人？」 | **不包括**；限直接占有人與占有輔助人 |
| 「被狗追逐跌倒受傷，是否屬動物加損害於他人？」 | **是**，含間接侵害 |
| 「§190 推定了哪些要件？」 | **過失**與**因果關係**（但書：已為相當注意之管束／縱為管束仍不免發生） |
| 「動物致他人純粹經濟上損失，得否依 §190 請求？」 | 王澤鑑：**否**（目的性限縮）；故意背俗者回 §184 I 後段 |
| 「§190 II 求償權之時效？」 | 多數：**§125 十五年** |

## 一、§190 的審查架構

```
§190 I
├─ 原告舉證：① 動物加損害於他人（直接／間接侵害）
│            ② 被告為動物占有人（直接占有人、占有輔助人）
├─ 法律推定：過失、因果關係 → 被告依但書舉證免責
└─ 保護客體：絕對權（王澤鑑目的性限縮）
              └─ 純粹經濟上損失 → §184 I 後段
```

## 二、占有人範圍

| 類型 | 是否為 §190 占有人 | 理由 |
|---|---|---|
| 直接占有人 | ✓ | 對動物有事實上管領力 |
| 占有輔助人 | ✓ | 當場控制動物之人 |
| 間接占有人 | ✗ | 無事實上管領力（例：把狗交給弟弟的主人） |

## 三、§190 II 內外部關係（狗追狗案）

```
乙的 B 犬追逐 → 甲的 A 犬受驚 → 撞傷丙
外部：丙 ──§190 I──> 甲（A 犬占有人）
內部：甲 ──§190 II──> 乙（挑動之他動物占有人）
```

| 爭點 | 見解 |
|---|---|
| 求償是否以故意過失為要件 | 否定：林誠二、孫森焱（條文未提）／肯定：王澤鑑（要人負責就要有可歸責） |
| 求償權時效 | §197 說／**§125 十五年說（多數）** |

## 四、老師列的常考點

1. 動物占有人是否含間接占有人
2. 加損害是否含純粹經濟上損失
3. 加損害是否含間接侵害
4. 推定了哪些要件
5. §190 II 求償權的要件與時效
