# 民法25 筆記：雙方不可歸責之危險負擔（§266、§373）

## §225 I 不是請求權基礎：
- 乙依 **§348** 請求甲交付 A，是基於買賣契約的**第一次給付**請求權
- 甲給付不能時，以 §225 I 主張免給付義務，是用來**對抗**履行請求的抗辯
- 甲反過來請求價金：看乙可否歸責——不可歸責依 §266 免對待給付；可歸責依 §267 仍須付

## §266 就是在分配「價金危險」：
- 雙方都沒有錯，但標的物沒了，總要有人承擔損失
- 依 §266：甲**東西沒了、也收不到錢**；乙沒買到，但錢還在口袋，不虧
- 所以雙方不可歸責時，原則上由**出賣人（債務人）**承擔危險
- §373 所稱「危險」＝**價金危險**：能否請求對待給付的危險

## §373 以「交付」為移轉點：
- 地震題：甲賣 A 屋給乙，因地震或第三人行為倒塌，甲乙都不可歸責
  - 乙依 §348 請求交屋 → 敗訴（§225 I）
  - 甲請求價金：
    - 倒在**交付前** → 危險仍在甲，依 §266 不得請求
    - 倒在**交付後**（已點交、未過戶）→ §373 危險移轉給乙，甲**仍可請求價金**
- 關鍵是**交付**（點交），不是移轉登記（過戶）
- 理由：**利益與危險一體兩面**，買受人已享有使用收益，就要承擔毀損滅失

## 有一方可歸責時，不談 §373：
- 可歸責於誰就由誰負責：甲可歸責 → 乙對甲請求損害賠償；乙可歸責 → 甲對乙請求對待給付
- 只有雙方都不可歸責，才需要法律出面分配風險
- 老師：地震、颱風、第三人縱火這類題目以前很愛考，現在申論少了，選擇題仍常見

## 📖 法條原文速查

> **§348 I**　物之出賣人，負交付其物於買受人，並使其取得該物所有權之義務。

> **§373**　買賣標的物之**利益及危險**，除契約另有訂定外，自**交付**時起，均由買受人承受負擔。

> **§266**　I 因不可歸責於雙方當事人之事由，致一方之給付全部不能者，他方**免為對待給付**之義務；如僅一部不能者，應按其比例減少對待給付。II 前項情形，已為全部或一部之對待給付者，得依關於不當得利之規定，請求返還。

> **§225 I**　因不可歸責於債務人之事由，致給付不能者，債務人免給付義務。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§225 I 是否為請求權基礎？」 | **否**，是對抗履行請求的抗辯 |
| 「§373 之危險指什麼？」 | **價金危險**（對待給付之危險） |
| 「房屋已點交未過戶，因地震倒塌，出賣人可否請求價金？」 | **可以**，§373 自**交付**時危險移轉 |
| 「房屋未交付即因地震倒塌？」 | **不可**，§266 買受人免對待給付 |
| 「可歸責於一方之給付不能，適用 §373？」 | **否**，可歸責者負責 |
| 「§266 情形已付價金？」 | 依**不當得利**請求返還（§266 II） |

## 案例：點交後地震倒塌

### 事實
- 甲以 1,000 萬元出賣 A 屋給乙
- 7/1 點交，預定 8/1 過戶；7/15 地震，A 屋全倒，甲乙均不可歸責

### 分析
| 請求 | 依據 | 結論 |
|---|---|---|
| 乙 → 甲：交屋過戶 | §348 | ✗ §225 I 免給付義務 |
| 甲 → 乙：1,000 萬價金 | §367 | ✓ 已交付，§373 危險由乙負擔 |
| 若地震發生在 6/20（交付前） | §266 | ✗ 乙免對待給付 |

```
雙方不可歸責之給付不能
├── 交付前 → §266：出賣人承擔價金危險
└── 交付後 → §373：買受人承擔價金危險（仍須付款）
```
