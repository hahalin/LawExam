# 民法物權補充2 筆記：占有之類型、推定效力與占有保護（§940至§966）

## 定義與類型
- 占有＝對物有**事實上管領力**的狀態（§940）；是**事實**，不是權利（否則不會有「無權占有」）
- 類型：
  - 直接占有／間接占有／占有輔助人（§941、§942；動物侵權、占有改定時已講）
  - 有權／無權：有無合法占有權源
  - **自主**（以所有之意思）／**他主**（以地上權、承租等意思）
  - **善意**（誤以為有權）／**惡意**（明知無權）

## 推定效力
- §943：占有人於占有物上行使的權利，推定其適法有此權利（例：以租賃意思占有，推定有租賃權）
- §944：推定以所有之意思，善意、和平、公然、繼續占有（時效取得時已講）

## 占有狀態的變更
- 他主 → 自主：須向使其占有之人**表示**所有之意思；已知所有人是誰，應向所有人表示（§945）
- 善意 → 惡意：本權訴訟敗訴時，自**訴狀送達之日**起視為惡意占有人（§959）——訴訟上常用

## 移轉與合併
- 移轉：準用 §761（現實、簡易、占有改定、指示交付）（§946）
- 前後占有合併計算（§947）；善意取得 §948～§951-1

## 回復關係
| 項目 | 善意占有人 | 惡意占有人 |
|---|---|---|
| 使用收益 | 推定適法可使用收益，排除不當得利（§952） | 須返還孳息，並負賠償責任（§958） |
| 滅失毀損 | 善意**自主**占有人僅於所受利益限度內負責（§953） | 負損害賠償責任（§956；他主占有人亦同） |
| 必要費用 | 得請求償還（§954） | 依無因管理規定請求（§957） |
| 有益費用 | 現存增加價值限度內請求（§955） | 條文未規定：王澤鑑肯定可依不當得利；邱聰智認為立法者有意排除 |

## 占有保護
| 項目 | 自力救濟（§960、§961） | 占有物上請求權（§962） |
|---|---|---|
| 性質 | 現實上直接取回、防禦 | 法律上請求，須透過訴訟 |
| 要件 | 侵奪或妨害 | 侵奪、妨害或有妨害之虞 |
| 權利人 | 直接占有人、**占有輔助人**；間接占有人**不行** | 直接、**間接**占有人；占有輔助人**不行** |
| 時間 | 無時效問題 | **1 年**間不行使而消滅（§963） |

- 與 §767 的差別：§962 須有「**侵奪**」，不是單純無權占有
  - 例：租約屆滿承租人不搬 → 無權占有，但房子是自己交出去的，**不是侵奪**
- 有權、無權、自主、他主、善意、惡意占有人都受保護
- 共同占有：各占有人得為全體行使 §962（§963-1，類似 §821）

## 消滅、共同占有、準占有
- 喪失事實上管領力 → 占有消滅（§964）
- 數人共同占有一物，各占有人就使用範圍**不得互相**請求占有保護（§965）
- 行使財產權而不以占有為要件者，為準占有人（§966；§310 已講）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 占有是權利嗎 | **否**，事實 |
| 善意占有人何時轉惡意 | 本權訴訟敗訴，自**訴狀送達**日起 |
| 自力救濟權利人 | 直接占有人、占有輔助人 |
| §962 請求權人 | 直接、間接占有人；不含輔助人 |
| §962 消滅時效 | **1 年** |
| 租約屆滿不搬可否依 §962 | 否，非侵奪；改依 §767 |
| 共同占有人間互相請求保護 | **不得** |
