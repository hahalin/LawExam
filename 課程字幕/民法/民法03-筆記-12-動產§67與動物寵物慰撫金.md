# 民法03 筆記：動產 §67 與動物的法律地位、寵物慰撫金

> 來源：民法03 課程字幕 02:25:54 ~ 02:36:30（本堂結尾；人體分離部分、屍體下堂續）

---

## 📖 法條原文速查

> **§67**（動產）
> 稱動產者，為前條所稱不動產以外之物。

> **§18 II**　前項情形，以法律有特別規定者為限，得請求損害賠償或慰撫金。→ 要有人格權或身分權受侵害才有慰撫金

> **§194**　不法侵害他人致死者，被害人之**父、母、子、女及配偶**，雖非財產上之損害，亦得請求賠償相當之金額。→ 沒有祖父母、孫子女

> **§195 I**　不法侵害他人之身體、健康、名譽、自由、信用、隱私、貞操，或不法侵害**其他人格法益而情節重大**者，被害人雖非財產上之損害，亦得請求賠償相當之金額。

> **§184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。

## 📋 實務見解速查

> **臺灣高等法院 106 年判決**（講義 52 頁註 59，愛犬於寵物醫院高壓氧艙火災燒死案）：寵物與飼主間有**類似伴侶之關係**，寵物非以經濟目的存在，為介於人與物之間之特殊生命體；法律未規定屬漏洞，**類推適用**侵權行為法規定，飼主得請求慰撫金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產之檢驗順序？」 | 是物嗎？→ 是土地或定著物嗎？→ 都不是 → 動產 |
| 「土地上的石頭、土地上的樹，何者為動產？」 | 石頭是**動產**（物、非土地）；未分離的樹是**土地的成分**，不是動產 |
| 「動物在民法上之性質？」 | **動產**，人的財產，可買賣（野生動物另有特別法） |
| 「寵物被不法侵害致死，飼主得否請求慰撫金？」 | 早期**否**（財產權受侵害無慰撫金）；106 年高院判決**肯定**（類推侵權行為法） |
| 「高院見解的體系問題？」 | 孫子被殺，阿公依 §194 **無**慰撫金；狗被殺，主人**有** → 體系失衡 |
| 「學說替代路徑？」 | 人與寵物的關係＝人格權的延伸 → §195 I「**其他人格法益而情節重大**」 |

## 一、動產的檢驗：二分法

```
是物嗎？（四要件）
  └── 是 → 是土地或定著物嗎？
            ├── 是 → 不動產
            └── 否 → 動產（§67）
樹（未分離）→ 土地的成分 → 它就是土地 → 不是動產
土地上的石頭 → 是物、不是土地 → 動產
```

## 二、§67 的三個爭點（本堂只講第一個）

1. **動物**的法律性質 ← 本筆記
2. 與人體分離之部分 → 下堂
3. 屍體 → 下堂

## 三、動物＝動產

- 民法未承認動物的特殊性；動保法、野生動物保育法另有保護，但在民法體系內動物就是**一般動產、人的財產**，可以買賣。
- 特殊議題上動物才顯出特殊性；回到最一般的判斷，動物還是動產。

## 四、案例：愛犬燒死於寵物醫院

#### 事實
甲的愛犬術後住進寵物醫院高壓氧艙，當晚艙內電線走火，愛犬燒死。甲請求慰撫金。

#### 分析

| | 早期見解 | 106 年高院判決 |
|---|---|---|
| 狗的定位 | 動產 → 財產權受侵害 | 寵物＝類似伴侶、非經濟目的、介於人與物之間的特殊生命體 |
| 慰撫金 | **無理由**：§18 II 要人格權／身分權受侵害；甲無人格權受侵害，甲與狗之間也無身分權；財產損失可用金錢衡量 | **有理由**：法律就寵物保護無規定＝漏洞 → 類推侵權行為法 |
| 可請求 | 財產上損害：狗的市價（名犬高、土狗低）、醫藥費 | 財產上損害 ＋ 慰撫金 |

### 老師對高院論理的批評
```
孫子（人）過世 → 阿公依 §194 → 不在父母子女配偶之列 → 無慰撫金
狗過世        → 主人 → 有慰撫金
→ 阿公與孫子的感情比不上人與狗？孫子不也陪伴阿公？→ 體系失衡，「伴侶關係」不能一概而論
```
- 結論大家心態上可以接受，論理有問題。

### 學說的替代路徑：§195 I 概括條款
```
人與寵物的關係 → 人格權的延伸（現代人藉寵物滿足生活、貫徹存在價值）
    → 一般人格權 →「其他人格法益」
    → 用「情節重大」當濾網：隨便養 vs 比養兒子還認真、人與寵物互動程度 → 個案衡量
```
- 老師觀察：電梯裡三台娃娃車兩台是狗；寵物醫院比兒童醫院多。
