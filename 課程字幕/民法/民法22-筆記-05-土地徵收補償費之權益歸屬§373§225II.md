# 民法22 筆記：土地徵收補償費之權益歸屬（§373、§225 II）

## 案例（81 年第 19 次民事庭會議決議）：
- 甲把 A 地賣給乙，**已交付、未移轉登記**
- A 地被政府徵收，徵收補償費（例：1,000 萬）發給甲
- 這個決議會講兩次：這裡講不當得利，債務不履行（代償請求權）再講一次

## 甲還能向乙請求價金：
- §373：標的物的利益及危險，自**交付**時起由買受人承受負擔
- 已交付 → 被徵收的危險由乙負擔 → 乙仍須付價金
- 「危險」就是：標的物出事，你還是得付錢

## 乙不能請求交付土地：
- 土地已被徵收，甲給付不能且不可歸責 → 乙依 §348 請求必敗訴
- 乙想改要徵收補償費，先試 §179

## 乙依 §179 請求補償費：不成立
- 甲受有補償費的利益；補償費來自政府，非乙給付 → 非給付型 → 權益歸屬說
- 補償費能否依 §373 歸乙？**不能**：§373 的「利益」指**使用收益**，不含標的物滅失或被徵收的**代替利益**
- 乙承擔被徵收的危險，卻不能享受徵收的利益（老師：§373 對乙有點不公平）
- 補償費依土地徵收條例歸**土地所有人**；未移轉登記前所有人仍是甲 → 甲受領屬於自己的利益 → 不成立不當得利

## 出路：類推 §225 II 代償請求權
- §225 II 處理的是損害賠償；徵收補償費是**損失補償**，不能直接適用
- 但同樣是不可歸責於債務人的給付不能、債務人從第三人取得代償利益 → **類推適用**
- 乙付了價金，得請求甲讓與補償費
- 考試多考類推 §225 II；老師認為決議前段用 §373 推論權益歸屬，是不當得利的漂亮案例

## 📖 法條原文速查

> **§373**　買賣標的物之**利益及危險**，自**交付**時起，均由買受人承受負擔，但契約另有訂定者，不在此限。

> **§225**　I 因不可歸責於債務人之事由，致給付不能者，債務人免給付義務。II 債務人因前項給付不能之事由，對第三人有損害賠償請求權者，債權人得向債務人請求**讓與**其損害賠償請求權，或交付其所受領之賠償物。

> **§348 I**　物之出賣人，負交付其物於買受人，並使其取得該物所有權之義務。

## 📋 實務見解速查

> **最高法院 81 年度第 19 次民事庭會議決議**（講義 324 頁，要旨）：買受人向出賣人買受之土地，於辦妥所有權移轉登記前經政府徵收，補償地價由出賣人領取。縱該土地早已交付，惟 §373 所指利益，係指物之收益而言，並不包括買賣標的物滅失或被徵收之代替利益；且買受人自始未取得所有權，出賣人於辦畢移轉登記前仍為所有人，補償地價本應歸出賣人取得，出賣人本於所有人地位領取，不成立不當得利。惟買受人非不得**類推適用 §225 II**，請求出賣人讓與該補償地價。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「已交付未登記之土地被徵收，買受人仍須付價金？」 | **是**，危險自交付時移轉（§373） |
| 「§373 之利益包含徵收補償費？」 | **否**，只指使用收益 |
| 「出賣人領取補償費，對買受人成立不當得利？」 | **否**，補償費歸屬所有人（出賣人） |
| 「買受人請求補償費之依據？」 | **類推適用 §225 II** |
| 「為何類推而非直接適用 §225 II？」 | 補償費是**損失補償**，非損害賠償 |

## 一、法律關係圖

```
甲（出賣人、登記所有人）── 買賣、已交付 ──→ 乙（買受人）
   ↑ 徵收補償費
  政府
甲 → 乙：價金請求權 ✓（§373 危險已移轉）
乙 → 甲：§348 交付土地 ✗（給付不能）
乙 → 甲：§179 補償費 ✗（權益歸屬於所有人甲）
乙 → 甲：類推 §225 II 讓與補償費 ✓
```

## 二、§373 的利益與危險

| | 包含 | 不包含 |
|---|---|---|
| 危險 | 毀損滅失、**被徵收** | — |
| 利益 | 使用、收益 | **徵收補償等代替利益** |
