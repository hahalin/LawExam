# 民法06 筆記：意思表示的解釋 §98——送報生「承攬契約書」其實是僱傭、三種勞務契約的分法

> 來源：民法06 課程字幕 00:08:02 ~ 00:18:07

---

## 📖 法條原文速查

> **§98**（意思表示之解釋）
> 解釋意思表示，應**探求當事人之真意**，不得拘泥於所用之辭句。

> **§482**（僱傭）稱僱傭者，謂當事人約定，一方於一定或不定之期限內為他方服勞務，他方給付報酬之契約。
> **§490 I**（承攬）稱承攬者，謂當事人約定，一方為他方完成一定之工作，他方俟工作完成，給付報酬之契約。
> **§528**（委任）稱委任者，謂當事人約定，一方委託他方處理事務，他方允為處理之契約。

> **§188 I**（僱用人責任）受僱人因執行職務，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。……
> **§189**（定作人責任）承攬人因執行承攬事項，不法侵害他人之權利者，定作人不負損害賠償責任。但定作人於定作或指示有過失者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「契約名為『承攬契約書』，內容充滿指揮監督（上下班時間、路線調度、收款回報），性質？」 | **僱傭**。§98 探求真意，不拘泥名稱 |
| 「僱傭、委任、承攬如何區分？」 | 有**指揮監督** → 僱傭；無指揮監督：重**過程** → 委任、重**結果** → 承攬 |
| 「律師打輸官司是否債務不履行？」 | **否**。委任重過程不重結果；過程有過失才是 |
| 「外送員撞傷人，被害人得否對平台主張 §188？」 | 看契約性質：僱傭 → §188 連帶；承攬 → §189 定作人原則不負責 |
| 「送報生工作 30 年，退休時報社以『承攬契約』拒給退休金？」 | 最高法院依 §98 認定本質為**僱傭**，有勞基法適用 |

## 一、§98：不是每個人都懂法律，字句不精準很正常

```
解釋意思表示 → 探求真意，不拘泥文字
→ 法官看的是契約【內容】，不是契約【名稱】
```

## 二、案例：送報生的「承攬契約書」

#### 事實
甲在報社送報 20～30 年，兼向訂戶收費。65 歲申請退休，依勞基法請求退休金。報社拿出 20 多年前的「承攬契約書」：我們是承攬，每月完成工作給承攬報酬，無勞健保、無勞基法。

#### 分析
```
名稱：承攬
內容：幾點到公司、幾點前送完幾份、送報時要收錢並回報、接受調班（中和調去永和）
→ 滿滿的指揮監督 → 本質是以指揮監督為核心的【僱傭契約】
→ §98 探求真意 → 僱傭 → 勞基法 → 有退休金
```

## 三、三種勞務契約

| | 僱傭 §482 | 委任 §528 | 承攬 §490 |
|---|---|---|---|
| 指揮監督 | **有**（一個口令一個動作） | 無（尊重專業：律師、醫生） | 無（找水電工通水管） |
| 重點 | 服勞務 | **過程**有沒有好好做 | **結果**有沒有完成 |
| 債務不履行 | — | 過程有過失才算；輸官司、病人死亡不算 | 沒修好才算；怎麼修不管 |

```
判斷順序：有指揮監督？→ 有 → 僱傭
                     → 無 → 重過程 → 委任；重結果 → 承攬
```

## 四、現代版：外送員、車隊司機

- UberEats、foodpanda 的契約都叫「承攬契約書」；勞動部曾表示應為僱傭。
- 差別在哪：外送員在路上撞到人 → 僱傭 → 平台依 **§188** 連帶；承攬 → **§189** 定作人原則不負責。
- 實務傾向：為保護外送員（勞基法）與被害人（§188），契約中有指揮監督要素就偏向解釋為僱傭。
- 老師：平台也在請律師改寫「真正的承攬契約」（拿掉所有監督條款）；考試不會問「Uber 外送員是什麼契約」（沒看契約無法判斷），申論會給契約內容要你判斷有無指揮監督。
