# 民法06 筆記：意思表示瑕疵的體系與 §86 心中保留（單獨虛偽意思表示）——表示說／意思說、相對人明知只讓「表意人的」意思表示無效

> 來源：民法06 課程字幕 01:15:00 ~ 01:27:23

---

## 📖 法條原文速查

> **§86**（單獨虛偽意思表示／心中保留／真意保留）
> 表意人無欲為其意思表示所拘束之意，而為意思表示者，其意思表示，**不因之無效**。但其情形為相對人所**明知**者，不在此限。

> **§87 I**（通謀虛偽意思表示）表意人與相對人通謀而為虛偽意思表示者，其意思表示無效。……
> **§88～§91**　錯誤、傳達錯誤、撤銷之損害賠償、除斥期間
> **§92、§93**　詐欺、脅迫

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「意思表示瑕疵之體系？」 | **不一致**（故意：§86 單獨虛偽、§87 通謀虛偽；偶然：§88～§91 錯誤）＋**不自由**（§92、§93 詐欺脅迫） |
| 「偶然不一致為何不叫過失不一致？」 | §88 I 但書：表意人**無過失**才能撤銷，用「過失」會矛盾 |
| 「§86 之別名？」 | **心中保留、真意保留**（一試會用這些名詞） |
| 「§86 之要件？」 | 表意人**無受拘束之意**（內心沒有效果意思）而**故意**為意思表示 |
| 「§86 原則效力？」 | **不因之無效**（表示說：以外部表示為準）→ 不等於一定有效，仍可能因其他原因（§71、§72、§75）無效 |
| 「相對人明知表意人無受拘束之意？」 | 表意人之意思表示**無效**（意思說：以內心意思為準） |
| 「甲真意保留為贈與要約，乙明知仍承諾，乙之意思表示效力？」 | 乙的意思表示**有效**（乙沒有虛偽）。乙的「明知」使**甲的**意思表示無效，不是使乙的無效 |
| 「甲乙都虛偽？」 | 那是 **§87 通謀**，不是 §86 |

## 一、體系圖

```
意思表示的瑕疵（§86～§93）
├── 意思與表示【不一致】（內心想的 ≠ 表現出來的）
│     ├── 故意不一致
│     │     ├── 單獨虛偽意思表示（心中保留）§86
│     │     └── 通謀虛偽意思表示 §87
│     └── 偶然不一致（不叫「過失」不一致，因 §88 要求無過失）
│           └── 錯誤 §88～§91
└── 意思表示【不自由】（不一致是被迫的）
      └── 被詐欺、被脅迫 §92、§93
```

## 二、§86 心中保留

### 要件
```
表意人內心根本沒有要做這個意思表示（無欲受拘束）
卻故意做了 → 「明明不想你還做」
```

### 效果：原則表示說、例外意思說
| | 標準 | 結果 |
|---|---|---|
| 原則 | **表示說**：以外部表示為準 | 「不因之無效」——不受單獨虛偽影響；但可能因違反強行規定、公序良俗、無行為能力等**其他原因**無效（題目沒給線索就當有效） |
| 例外：相對人**明知** | **意思說**：以內心意思為準 | 表意人的意思表示**無效** |

- 立法目的：保護**相對人的交易安全**——相對人不知情，就讓它有效；相對人明知你在開玩笑，就不需要保護他。

## 三、案例：病床前的贈與

#### 事實
媽媽臨終叫甲（有錢的哥哥）、乙（好吃懶做的弟弟）到床前，要甲把一間房子送給乙。甲根本不想送，被情勒只好說「好，我願意」；乙說「好，我接受」。

#### 分析
```
兩個意思表示：甲的要約（虛偽）、乙的承諾（真心）
討論的只有【甲的】意思表示：
    乙不知甲不想送 → 甲的意思表示有效 → 贈與契約有效
    乙明知甲不想送 → 甲的意思表示無效 → 贈與契約無效（因為甲那邊缺了）
乙的意思表示：乙內心有效果意思、表現出來也一致 → 【永遠有效】，跟 §86 無關
```

### 選擇題陷阱
- ✗「因乙明知甲為虛偽意思表示，故乙之意思表示亦無效」→ **錯**。乙是認真的；乙的「知」影響的是**對方（甲）**的意思表示。
- 題目問「贈與契約效力如何？」→ 不能只答無效，要說理：是**甲的**意思表示因乙明知而無效，所以契約不成立；乙的沒問題。
- 除非甲乙都虛偽 → 那是 §87 通謀。

### 老師：德國式思維
- 把每個動作切開（甲的意思表示、乙的意思表示、債權行為、物權行為），一格一格找瑕疵、對症下藥。
