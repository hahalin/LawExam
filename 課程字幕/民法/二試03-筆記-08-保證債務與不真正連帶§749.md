# 民法二試03 筆記：保證債務與不真正連帶（§749）

## 案例（管靜怡法官文章，講義 214 頁；字幕一處作管敬一，請對講義）：
- 甲向乙借 1,000 萬；**B（未經認許之外國法人）**與 **C** 共同擔任保證人
- A 以 B 代表人身分簽保證契約 → 依**民總施行法 §15**，A 就該法律行為與 B 負連帶責任
- 甲還不出來，C 清償 1,000 萬 → C 能否請求 A、B 連帶負責？
- 老師：考題出現「外國法人」，八九不離十是考這個；民總施行法考試可能不附，§15 要記

## 兩組法定連帶，缺一條線：
- B–C：§748 共同保證 → 真正連帶 → C 對 B 有 §281 I 內部求償權
- A–B：民總施行法 §15 → 連帶
- **A–C：沒有任何條文綁在一起** → 依實務屬**不真正連帶**（數人偶然就同一給付負責）→ 無內部求償權，C 對 A 本來沒有權利

## 各審見解：
- 一審：民總施行法 §15 有規定 A、B 連帶 → 肯定（但忽略 §15 的連帶是對債權人乙，不是對 C）
- **二審、最高法院**：繞道 **§749**——C 清償後**承受乙的債權**，連同乙依民總施行法 §15 對 A 的權利 → C 可請求 A、B 連帶負責

## 管靜怡：
- 問題根源是實務把「法條明文＝真正連帶、無明文＝不真正連帶」切得太窄
- 從規範目的看，A 為 B 負責、B 與 C 共同保證同一債務 → 不妨把 **A、B、C 從寬認定為一組真正連帶** → C 直接依 §281 I 向 A 求償，不必繞道 §749
- 內部分擔：A 是替 B 負責，A、B 視為一體 → C 可向 A、B 請求 **500 萬**

## 📖 法條原文速查

> **民總施行法 §15**　未經認許其成立之外國法人，以其名義與他人為法律行為者，其行為人就該法律行為應與該外國法人**負連帶責任**。
> **民法 §748**　數人保證同一債務者，除契約另有訂定外，應**連帶**負保證責任。
> **民法 §749**　保證人向債權人為清償後，於其清償之限度內，**承受債權人對於主債務人之債權**。但不得有害於債權人之利益。
> **民法 §281 I**（要旨）：連帶債務人中之一人因清償等致他債務人同免責任者，得向他債務人請求償還其各自分擔之部分。（原文請對六法）

---

## 📋 實務見解速查

> **最高法院判決**（字幕未唸字號，請對講義，要旨）：保證人清償後依 §749 承受債權人之債權，得請求未經認許外國法人及其行為人連帶負責。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「C 對 B 之請求權基礎？」 | §748 共同保證連帶 → §281 I 內部求償 |
| 「C 對 A 呢？」 | A 非保證人，A–C 無法定連帶 → 不真正連帶 → 無 §281 求償權 |
| 「實務如何解套？」 | §749 承受乙之債權（含乙依民總施行法 §15 對 A 之權利） |
| 「管靜怡？」 | 依目的從寬認定 ABC 為真正連帶 → C 直接依 §281 I 求償；AB 一體，各半分擔 |
