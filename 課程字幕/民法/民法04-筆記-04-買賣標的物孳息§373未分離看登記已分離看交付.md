# 民法04 筆記：買賣標的物的孳息 §373——未分離看登記、已分離看交付

> 來源：民法04 課程字幕 00:30:16 ~ 00:38:00

---

## 📖 法條原文速查

> **§373**（標的物利益與危險之承受負擔）★ 民法財產法「神出鬼沒」的條文
> 買賣標的物之**利益及危險**，自**交付**時起，均由買受人承受負擔。但契約另有訂定者，不在此限。
> → 利益＝使用收益 → 買受人自交付起有收取權

> **§758 I**（不動產物權登記生效）
> 不動產物權，依法律行為而取得、設定、喪失及變更者，非經**登記**，不生效力。

> **§66 II**　未分離之出產物為不動產之部分。
> **§70 I**　有收取天然孳息權利之人取得分離之孳息。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「A 地買賣，B 果實**未分離**，歸誰？」 | 看**登記**：已移轉登記 → 乙（買受人）；未登記 → 甲。交付與否不管 |
| 「A 地買賣，B 果實**已分離**，歸誰？」 | 看**交付**：已交付 → 乙有收取權（§373）；未交付 → 甲。登記與否不管 |
| 「已交付未登記、果實已分離？」 | **乙的**（交付了） |
| 「已登記未交付、果實已分離？」 | **甲的**（還沒交付） |
| 「已登記未交付、果實未分離？」 | **乙的**（乙已是土地所有人） |
| 「§373 的『利益』指什麼？」 | **使用收益**，不是所有權 |

---

## 一、不動產買賣有兩個動作

```
甲賣 A 地給乙
├── 移轉登記（過戶）→ 所有權移轉（§758）→ 法律上「拿到」
└── 交付（點交）    → 占有移轉          → 現實上「拿到」
→ 四種排列組合：已登記已交付／已登記未交付／未登記已交付／未登記未交付
```

## 二、兩個判斷標準

| 果實狀態 | 問什麼 | 看什麼 | 理由 |
|---------|-------|-------|------|
| **未分離** | 誰是原物（土地）所有人？ | **登記** | 未分離是土地一部分（§66 II）→ 土地所有人的 → 所有權看登記（§758） |
| **已分離** | 誰有收取權？ | **交付** | §373：利益（使用收益）自交付時起歸買受人 → 收取權看交付 |

```
果實未分離 → 看登記了沒
    已登記 → 乙　｜　未登記 → 甲　（不管交付）
果實已分離 → 看交付了沒
    已交付 → 乙　｜　未交付 → 甲　（不管登記）
```

## 三、完整表格

| 登記 | 交付 | 未分離果實 | 已分離果實 |
|------|------|-----------|-----------|
| ✓ | ✓ | 乙 | 乙 |
| ✓ | ✗ | **乙** | **甲** |
| ✗ | ✓ | **甲** | **乙** |
| ✗ | ✗ | 甲 | 甲 |

- 陷阱在中間兩列：一個看登記、一個看交付，答案相反。
- 老師：不要背，要會推——未分離就是土地，土地是誰的看登記；分離後問收取權，收取權看 §373 交付。

## 四、§373 為什麼重要

- 民總（孳息）、債總（給付不能的危險負擔）、債各（買賣）、物權都會看到它。
- 這裡只用「利益」那半；「危險」那半到債編再講。
