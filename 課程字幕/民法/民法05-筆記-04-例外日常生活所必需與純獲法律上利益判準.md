# 民法05 筆記：§77 但書的例外——日常生活所必需、純獲法律上利益的基本判準

> 來源：民法05 課程字幕 00:30:33 ~ 00:37:50

---

## 📖 法條原文速查

> **§77 但書**
> ……但**純獲法律上利益**，或**依其年齡及身分、日常生活所必需**者，不在此限。

> **§367**（買受人之義務）
> 買受人對於出賣人，有交付約定價金及受領標的物之義務。
> → 買賣對買受人必有價金義務 → 不可能「純」獲法律上利益

> **§805 II**（拾得人之報酬請求權）
> 有受領權之人認領遺失物時，拾得人得請求報酬。但不得超過其物財產上價值十分之一；其不具有財產上價值者，拾得人亦得請求相當之報酬。
> （§805 III 給付報酬顯失公平者得請求法院減少或免除；IV 報酬請求權六個月不行使而消滅）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「日常生活所必需如何認定？」 | **個案、從寬**（王澤鑑）：同年齡同身分的小孩通常需要的即可 |
| 「16 歲限制行為能力人以 500 元買市價 3,000 元腳踏車，是否純獲法律上利益？」 | **否**。有經濟上利益，但仍負 §367 價金義務 → 不「純」 |
| 「法律上利益 vs 經濟上利益？」 | 條文講**法律上**：單純享受權利、**不負任何義務**；划不划算不管 |
| 「無償贈與是否純獲法律上利益？」 | **是**（受贈人無義務） |
| 「國中生買 500 元二手腳踏車？」 | 日常生活所必需 ✓ |
| 「17 歲無駕照買機車？」 | ✗ 無駕照 → 非日常生活所必需 |
| 「未經允許、未符合例外，再回原則」 | 檢驗順序：先例外，再原則 |

## 一、檢驗順序：先例外、再原則

```
未經法代允許
  ├── 符合例外（純獲法律上利益／日常生活所必需／中性行為／§83 詐術）→ 不受行為能力影響，結束
  └── 都不符合 → 回原則：§78 單獨行為無效、§79 契約效力未定
```
- 符合例外就代表「沒得到允許也沒關係」，不用再討論沒允許會怎樣。

## 二、日常生活所必需：個案、從寬

- 王澤鑑：依每個小孩的狀況個案認定，而且**從寬**——同年齡、同身分的小孩通常需要的事就算。
- 娛樂也是生活所需之一，不能不讓小孩從事任何娛樂；重點是**不要超過**。

| 情形 | 老師的判斷 |
|------|-----------|
| 國中生買 500 元二手腳踏車 | ✓ |
| 舊法時期 19 歲、有駕照、能力負擔範圍內買機車 | 可能 ✓（現在 18 歲已成年，問題消失） |
| 17 歲無駕照買機車 | ✗ |
| 用零用錢買幾百元偶像周邊 | ✓ |
| 一次買好幾萬偶像周邊 | ✗（題目通常給誇張數字） |
| 高中生撿到錢包獲 1 萬元報酬（§805），拿去報名數學補習班 | 老師認為 ✓ 補數學很日常；拿去奢侈消費則不見得 |

- 日常生活所必需要論述 → 考申論；司律二試幾乎沒考過。純獲法律上利益才是老師特別愛考的。

## 三、純獲法律上利益的基本判準：有沒有「義務」

```
純 ＝ 單純享受權利、不負擔任何義務
法律上利益 ≠ 經濟上利益（划不划算不是重點）
```

#### 事實
16 歲甲向乙買 A 腳踏車，市價 3,000 元，乙只賣 500 元。

#### 分析
```
經濟上：甲賺 2,500 → 有利益
法律上：買賣契約若有效，甲依 §367 負給付價金義務 → 有義務 → 不「純」
→ 不是純獲法律上利益 → §79 效力未定
```
- 無償贈與（受贈人沒有義務）才是典型的純獲法律上利益。
- 純獲法律上利益的四個進階爭點：**物權行為獨立判斷**、附抵押權土地之贈與、附稅捐之贈與、附負擔贈與 → 見下兩份筆記。
