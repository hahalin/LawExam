# 民法二試01 筆記：出借帳戶之侵權責任與不當得利責任

## 案例（講義 71 頁）：
- 丙為 A 公司負責人，長期把公司帳戶借甲從事**非法匯兌**（不是詐騙）
- 丁詐騙乙，指示匯款入 A 帳戶；丙以為是貨款，已轉付上游廠商
- 乙對丙請求 ①§184 損害賠償 ②§179 返還不當得利

## 最高法院：
- §184：丙無詐欺（或幫助）故意，與甲丁無聯絡 → 不成立
- §179：可成立（非給付型）；但丙**善意**、錢已轉出 → §182 I 免返還 → 丙全身而退

## 詹森林：
- §184 I 後段（被害人受的是純粹經濟損失）：故意含**未必故意**；把帳戶借人做非法匯兌，對帳戶被用來詐騙有認識且不違本意 → 可能構成
- §179：本件是指示給付 → 應向詐騙者丁請求，不向丙
- 退步言之成立不當得利：①對不法有認識（出借帳戶本身不正當）→ 非善意 ②錢拿去付貨款 → 受有**債務消滅利益**，利益仍存在 → 無 §182 I
- 授課老師：不完全贊同「出借做非法匯兌即可預見詐騙」的事實推論

## 📖 法條原文速查

> **民法 §184 I**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。**故意以背於善良風俗之方法，加損害於他人者亦同。**
> **民法 §182 I**　不當得利之受領人，不知無法律上之原因，而其所受之利益已不存在者，免負返還或償還價額之責任。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「被詐騙者對出借帳戶之丙請求侵權賠償，依據？」 | 純粹經濟損失 → **§184 I 後段**；爭點在「故意」 |
| 「丙只想做非法匯兌，算故意嗎？」 | 故意含未必故意（預見其發生而不違本意）；詹森林：出借帳戶做不正使用，對其他不正使用（詐騙）亦有預見 → 可能構成；實務：無故意 |
| 「§179 向丙請求？」 | 先處理對象：指示給付說（向丁）vs 非給付型說（向丙，筆記 11） |
| 「丙主張 §182 I？」 | 善意：知出借帳戶不正當＝對不法有認識 → 非善意；利益不存在：用來清償貨款 → 有債務消滅利益 → 利益仍存在 |

## 一、論述骨架

```
乙 → 丙
① §184 I 後段（純粹經濟損失）
   故意？ 直接故意 ✗；未必故意？
     實務：✗（與詐騙者無聯絡、無詐欺意圖）
     詹森林：出借帳戶做非法匯兌 → 預見被用於詐騙且不違本意 → 可能 ✓
② §179
   對象？ 指示給付 → 向丁（詹森林）；非給付型 → 向丙（實務本件、筆記 11）
   §182 I？
     善意：實務 ✓；詹森林 ✗（對不法有認識）
     利益不存在：實務 ✓（已轉出）；詹森林 ✗（清償貨款＝債務消滅利益）
```
