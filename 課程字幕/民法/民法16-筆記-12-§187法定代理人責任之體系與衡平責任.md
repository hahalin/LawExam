# 民法16 筆記：§187法定代理人責任之體系與衡平責任

## 考試定位：
- 老師：§187 很愛考，選擇、申論都有機會

## 體系定位：為他人負責 vs 為自己負責：
- **傳統見解**（國考寫這個就夠）：法代不是行為人，本不必負責，因為是你的小孩才被拉進來 → **為他人負責**；目的是找有資力者、擴大求償
- **新見解**（字幕作陳聰富／陳沖富、游進發，請對講義）：法代依 §1084 II 有保護教養義務，監督疏懈＝**不作為侵權行為**，自己就成立 §184；§187 只是像 §185 一樣把甲乙**連帶**起來 → **為自己負責**
- 兩說差別主要在**內部求償**（§188 III 時才明顯，下堂講）

## 四種組合（前提：行為人是無／限制行為能力人且成立 §184）：
- **有識別能力**：被害人對行為人 §184；對法代 **§187 I 前段連帶**；法代可依 §187 II 舉證免責
- **無識別能力**：對行為人 ✗；對法代 **§187 I 後段單獨負責**；法代依 §187 II 免責 → 沒有人負責
- 兩條線拿不到賠償時，都進 **§187 III 衡平責任**

## §187 II：
- 被害人不必證明法代監督疏懈；**推定過失＋推定因果關係**，由法代舉證監督未疏懈或縱加相當監督仍不免發生損害

## §187 III 衡平責任：
- 法院依被害人**聲請**，斟酌行為人、法代與被害人的**經濟狀況**（不是行為輕重），令其為全部或一部賠償
- 源自普魯士民法的**富人原則**：大家都沒錯時，有錢的多扛一點
- 實務少用：法代要證明監督毫無疏懈幾乎不可能；考試常見的反而是 **§187 IV 準用 III**

## §187 IV：
- 「其他之人」＝有行為能力人（含**受輔助宣告人**，其輔助人不是法代）
- **無意識** → 欠缺「行為」；**精神錯亂** → 欠缺識別能力 → 都不成立 §184 → 準用 III
- 例：便利商店門口擦撞，對方突然發病持雙截棍打人；失智者拿高爾夫球桿打破鄰車車窗

## 📖 法條原文速查

> **民法 §187**
> I　無行為能力人或限制行為能力人，不法侵害他人之權利者，以行為時有**識別能力**為限，與其法定代理人**連帶**負損害賠償責任。行為時無識別能力者，由其法定代理人負損害賠償責任。
> II　前項情形，法定代理人如其**監督並未疏懈**，或縱加以相當之監督，而仍不免發生損害者，不負賠償責任。
> III　如不能依前二項規定受損害賠償時，法院因被害人之聲請，得斟酌行為人及其法定代理人與被害人之**經濟狀況**，令行為人或其法定代理人為全部或一部之損害賠償。
> IV　前項規定，於其他之人，在**無意識或精神錯亂**中所為之行為致第三人受損害時，準用之。

> **民法 §1084 II**　父母對於未成年之子女，有保護及教養之權利義務。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有識別能力之未成年人侵權，被害人得對法代主張？」 | **§187 I 前段**與行為人連帶；不必證明法代監督疏懈 |
| 「無識別能力之未成年人侵權，誰負責？」 | 行為人不負責；法代依 **§187 I 後段單獨**負責 |
| 「§187 II 之性質？」 | **推定過失＋推定因果關係**；法代舉證免責 |
| 「§187 III 法院斟酌之因素？」 | 行為人、法代與被害人之**經濟狀況**（非行為輕重）；須被害人**聲請** |
| 「成年人在精神錯亂中毀損他人之物，被害人得依何請求？」 | 不成立 §184（無識別能力）→ **§187 IV 準用 III** 衡平責任 |
| 「受輔助宣告人侵權，其輔助人應否依 §187 I 連帶負責？」 | **否**。受輔助宣告人有行為能力，輔助人非法代；無意識或精神錯亂時適用 §187 IV |
| 「§187 為他人負責或為自己負責？」 | 傳統：**為他人**；新見解：為自己監督疏懈負責（§1084 II 不作為） |

## 一、四種組合圖

```
行為人（無／限制行為能力人）成立 §184
├── 有識別能力
│     ├─ 被害人 → 行為人：§184 ✓
│     └─ 被害人 → 法代：§187 I 前段 連帶 ✓
│                 └─ 法代證明監督無疏懈／無因果（§187 II）→ 免責
│                       └─ 行為人無資力拿不到錢 → §187 III
└── 無識別能力
      ├─ 被害人 → 行為人：✗
      └─ 被害人 → 法代：§187 I 後段 單獨 ✓
                  └─ 法代依 §187 II 免責 → 無人負責 → §187 III
```

## 二、傳統 vs 新見解的構造

| | 傳統（為他人負責） | 新見解（為自己負責） |
|---|---|---|
| 法代有無侵權行為 | 無，只是被拉進來 | 有：監督疏懈＝不作為侵權 |
| 丙對甲的依據 | §187 本身 | §184 ＋ §187（連帶） |
| §187 地位 | 請求權基礎 | 與 §185 相同，是連帶規定 |

## 三、特殊侵權行為之「特殊」

| 條文 | 特殊之處 |
|---|---|
| §185 | 複數行為人 → 連帶 |
| §186 | 保護公務員勇於任事 |
| §187、§188 | 為他人（未成年人、受僱人）負責 |
| §190、§191 | 為物（動物、建築物）負責 |

## 四、10 歲小孩踢球案

- 10 歲已有識別能力，告他 §184 會贏，但小孩名下沒有財產，執行無實益 → 才需要告法代（§187 I 前段）；法代若舉證免責 → §187 III
