# 民法17 筆記：行員盜領存款與陳忠五信賴說

## 案例：
- 客戶乙信任 A 銀行行員甲，把存摺、印章、身分證交甲保管，授權「有賺錢的直接幫我買」
- 甲先挪 10 萬、20 萬投資再補回，最後挪 200 萬血本無歸被抓；甲沒錢，乙對 A 銀行主張 §188

## 依傳統標準涵攝：
- 僱傭關係 ✓
- 執行職務：盜領不是職務本體；但利用行員身分建立的信賴、要客戶交付存摺印章 → 利用職務機會 ✓；銀行一向告誡客戶不要把存摺印章交給行員 → 僱用人可預見 ✓
- 不論客觀說或內在關聯說，都是執行職務 → 銀行應負 §188

## 最高法院與陳忠五：反而否定：
- §188 為保護被害人才把要件從寬；但被害人若**沒有被保護的價值**，就該從嚴
- 陳忠五：客戶「**行為異常、動機可疑**」（正常人不會把存摺印章交給行員保管）
- 提出**信賴說**：看被害人有沒有值得保護的信賴 → 有，就放寬（客觀說、內在關聯說）；沒有，就從嚴解釋執行職務，僱用人不被無端拖下水

## 信賴說的論理（講義 163 頁圈五）：
- 早年實務以「是否構成犯罪」判斷是否執行職務，不可採：兩者無必然關係；現在看有無利用職務機會的關聯
- 客觀說由被害人主觀說衍生：一個人的主觀叫主觀，所有人一致的主觀就是客觀
- 一般交易 → 以**一般被害人**的信賴判斷；特殊情形 → 以**個別被害人**的信賴判斷（只有你會把存摺印章交出去）

## 陳聰富的進階觀點：
- 被害人行為異常、動機可疑，即使能請求，也有**與有過失**（§217）的適用 → 乙對甲依 §184 請求時，甲可主張乙與有過失（簡單知道即可）

## 📖 法條原文速查

> **§188 I 前段**　受僱人因**執行職務**，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。

> **§217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

---

## 📋 實務見解

> **被害人信賴之法院判決**（講義 159 頁底下括弧五，字號請對講義）：類似案件中，最高法院開始強調應考慮被害人有無值得保護的信賴。

> **陳忠五文章**（講義 158 頁圈二；161 頁括弧六「證券公司業務經理詐騙客戶金錢的僱傭人責任」）：信賴說之出處。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「行員利用客戶交付之存摺印章盜領存款，依客觀說是否屬執行職務？」 | **是**（利用職務機會、有客觀關聯） |
| 「承上，最高法院及陳忠五結論？」 | **否定**銀行 §188：被害人行為異常、動機可疑，無值得保護的信賴 |
| 「受僱人行為構成犯罪即非執行職務？」 | **錯**，犯罪與否與執行職務無必然關係 |
| 「信賴說以誰的信賴為判斷基準？」 | 一般交易：一般被害人；特殊情形：**個別被害人** |
| 「被害人行為異常、動機可疑，對受僱人請求時有無 §217？」 | 陳聰富：**有**與有過失之適用 |

## 一、結論為何翻轉

```
§188 目的：保護被害人
        ↓
要件從寬（僱傭關係、執行職務都放寬）
        ↓
但：被害人沒有值得保護的信賴？（行為異常、動機可疑）
        ↓
執行職務從嚴解釋 → 不成立 §188（最高法院、陳忠五）
```

## 二、三說比較

| | 客觀說 | 內在關聯說 | 信賴說（陳忠五） |
|---|---|---|---|
| 看什麼 | 有無客觀關聯 | ＋僱用人預見可能性 | 被害人有無正當信賴 |
| 行員盜領案 | 執行職務 ✓ | 執行職務 ✓ | 無值得保護的信賴 → ✗ |

## 三、案例涵攝順序

1. 僱傭關係：銀行與行員 ✓
2. 執行職務：傳統標準 ✓
3. 但被害人把存摺印章交行員保管 → 行為異常、動機可疑 → 依信賴說從嚴 → ✗
4. 乙對甲 §184 仍成立；甲可主張乙與有過失（陳聰富）
