# 民法31 筆記：減價解約之除斥期間與損害賠償之時效（§365）

## §365 只管 §359：
- 條文：「因物有瑕疵，而得**解除契約**或請求**減少價金**者」
- 沒有提到損害賠償（§360）與另行交付（§364）→ §365 只針對 §359
- 通說：§365 是**除斥期間**，不是消滅時效
  - 因為解除權、減少價金請求權本質上都是**形成權**（單方意思表示即生效力）

## 形成權要搭配請求權基礎：
- 減少價金 → 只形成價金減少的結果 → 返還多付的錢要依 **§179**
- 解除契約 → 只讓契約進入解除狀態 → 回復原狀要依 **§259**
- 只寫「依 §359 請求返還價金」是錯的：§359 沒有返還的效果
- **110 年律師司法官考題**：買車、音響有瑕疵，問可否依不當得利主張
  - 考點：先依 §359 行使減價形成權，再依 §179 請求返還多付的價金

## 兩段期間（§365 I、II）：
- ① 依 §356 **通知後六個月**不行使 → 消滅
- ② 自**物之交付時起五年** → 消滅
- 一般情形兩段都要審查，**任一**超過就不能主張
- 出賣人**故意不告知**瑕疵 → 不適用六個月，只審查交付後五年

## 爭點：§360、§364 請求權的時效？
- 這兩者是**請求權**，§365 沒有規定
- **實務**：法無規定 → 回到 **§125，15 年**
- **詹森林老師**（字幕作「張森林」，建議查證）：
  - 同一個瑕疵，走減價、解約要在通知後六個月內處理，走損害賠償卻能拖 15 年，體系失衡
  - 立法者有意讓買賣糾紛盡速確定，卻漏未規定 → 應**類推 §365**（通知後六個月、交付後五年）
- 老師舉例：今天買的手機，15 年後才主張瑕疵損害賠償，沒有必要讓紛爭拖這麼久

## 銜接下一個爭點：
- 考題常設計「交屋後第六年才發現結構歪斜、嚴重漏水」→ §365 已過，來不及解約
- 還能不能改依 §227 不完全給付解約？→ 見民法31-筆記-06

## 📖 法條原文速查

> **§365**
> I　買受人因物有瑕疵，而得**解除契約**或請求**減少價金**者，其解除權或請求權，於買受人依第三百五十六條規定為**通知後六個月**間不行使或自**物之交付時起經過五年**而消滅。
> II　前項關於六個月期間之規定，於出賣人**故意不告知**瑕疵者，不適用之。

> **§259**（解除後回復原狀）契約解除時，當事人雙方回復原狀之義務，除法律另有規定或契約另有訂定外，依下列之規定：……（各款 → 建議查閱最新六法原文）

> **§125**　請求權，因十五年間不行使而消滅。但法律所定期間較短者，依其規定。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§365 期間性質？」 | **除斥期間**（解除權、減價權是形成權） |
| 「§365 適用於 §360 損害賠償？」 | **否**，條文只及於解約、減價 |
| 「出賣人故意不告知瑕疵，§365 如何適用？」 | 不受六個月限制，只看**交付後五年** |
| 「依 §359 可直接請求返還價金？」 | **否**，須搭配 §179（減價）或 §259（解約） |
| 「§360、§364 的時效？」 | 實務：§125 **15 年**；學說：類推 §365 |

## §359 vs. §360、§364

| 項目 | §359 減價、解約 | §360 損害賠償、§364 另行交付 |
|------|-------------|------------------------|
| 性質 | 形成權 | 請求權 |
| 期間 | §365 除斥期間（6 個月／5 年） | 實務 §125；學說類推 §365 |
| 取回金錢 | 另依 §179、§259 | 本身即請求權 |
