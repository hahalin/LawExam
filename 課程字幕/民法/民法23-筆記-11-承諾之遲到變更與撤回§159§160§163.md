# 民法23 筆記：承諾之遲到變更與撤回（§159、§160、§163）

## 原則：
- 要約有拘束力，相對人在適當時期內承諾、且**不變更內容** → 契約成立

## 承諾遲到（§159）：構造與 §162 幾乎一樣
- 承諾通知按傳達方法**通常可在相當時期內到達**而遲到
- 要約人**可得而知**（有郵戳為證）
- 要約人有沒有**即發遲到之通知**：
  - 有發 → 真的遲到 → 依 §160 I 視為新要約
  - 怠於通知 → 承諾**視為未遲到** → 契約成立

## 視為新要約（§160）：
- **遲到之承諾**（§159 情形以外）→ 視為新要約
- 將要約**擴張、限制或為其他變更**而承諾 → 視為**拒絕原要約**而為新要約
  - 限制＝殺價（1,000 萬賣地，回 900 萬）
  - 擴張＝抬價；變更＝改買別的標的
- 效果：決定權換到對方手上

## 議價過程就是 §160：
- 夜市芭樂標「一斤 100」→ 標價陳列，視為要約
- 你說「一斤 80」→ 限制原要約 → 新要約
- 老闆拒絕 → 契約不成立；老闆接受 → 以老闆的承諾成立
- 老闆說「一斤 90」→ 又是變更 → 新要約，換你決定

## 承諾的撤回（§163）：
- 準用 §162：撤回通知準時到 → 承諾撤回，契約不成立
- 撤回通知遲到 → 一樣走三步驟：通常會遲到嗎？對方可得而知嗎？有發遲到通知嗎？

## 三條長一樣：
- **§159**（承諾遲到）、**§162**（撤回要約遲到）、**§163**（撤回承諾遲到）
- 共同結構：本來不會遲到卻遲到 → 對方看得出來 → 有通知才算遲到，沒通知就視為未遲到

## 📖 法條原文速查

> **§159**　I 承諾之通知，按其傳達方法，通常在相當時期內可達到而遲到，其情形為要約人可得而知者，應向相對人即發**遲到之通知**。II 要約人怠於為前項通知者，其承諾**視為未遲到**。

> **§160**　I 遲到之承諾，除前條情形外，**視為新要約**。II 將要約**擴張、限制或為其他變更**而承諾者，視為**拒絕原要約而為新要約**。

> **§163**　前條之規定，於**承諾之撤回**準用之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「承諾遲到，要約人可得而知卻未發遲到通知？」 | **視為未遲到**，契約成立 |
| 「承諾遲到，要約人已發遲到通知？」 | 視為**新要約**（§160 I） |
| 「對 1,000 萬要約回覆 900 萬？」 | 拒絕原要約＋**新要約**（§160 II） |
| 「承諾的撤回適用哪條？」 | §163 準用 **§162** |
| 「哪三條結構相同？」 | **§159、§162、§163** |

## 三條對照

| | 遲到的是 | 該發遲到通知的人 | 未通知的效果 |
|---|---|---|---|
| §159 | 承諾 | 要約人 | 承諾視為未遲到 → 契約成立 |
| §162 | 撤回要約之通知 | 相對人 | 撤回視為未遲到 → 要約失效 |
| §163 | 撤回承諾之通知 | 要約人（準用） | 撤回視為未遲到 → 承諾失效 |

## 承諾的去向

```
承諾
├── 準時、不變更內容 ───────────→ 契約成立
├── 遲到
│   ├── §159：通常可達＋可得而知＋未通知 → 視為未遲到 → 成立
│   └── 其他 ─────────────────→ 新要約（§160 I）
└── 擴張／限制／變更 ────────────→ 拒絕原要約＋新要約（§160 II）
```
