# 民法15 筆記：寵物被侵害致死之慰撫金

## 問題：
- 甲的 A 犬被乙不法侵害致死，甲得否向乙請求**慰撫金**

## 多數見解：否定：
- 犬是**物**，屬甲之財產權；財產權受侵害只能請求財產上損害，**無慰撫金**

## 少數實務：類推適用侵權行為規定：
- 臺灣高等法院 106 年判決（講義註 166）：寵物是介於人與物之間的**獨立生命體**，具伴侶關係者更應受保障 → 類推侵權行為規定請求賠償，**包括慰撫金**
- 理由：經濟動物（養豬、養雞）無情感連結，按財產權處理即可；伴侶寵物與人的關係已類似人與人 → 法律未保護 → **法律漏洞**，以類推填補
- 類推哪一條沒講清楚；老師從字裡行間推知，應是類推 §184 I 前段搭配 §194
- 案例：養十幾年的老狗術後住寵物醫院高壓氧艙，當晚電線走火爆炸，犬被燒死；飼主堅持要法院「把狗當人看」

## 學說肯定說（林誠二）：結論同、方法不同：
- 不贊成類推：類推等於把犬的地位提升、擬人化；但**動物不會是請求權主體**，不保護動物是立法者的價值取捨，**不是法律漏洞**；法官只能解釋法律、不能創造法律
- 要保護的是**甲（人）**與寵物之間的陪伴關係 → 屬 §195 I **其他人格法益**（維護人性尊嚴所必要）→ §184 I 前段＋§195 I，**情節重大**即可請求
- 情節重大的判斷：寵物性質（貓狗 vs 蟑螂、獨角仙等無互動者）、飼養期間、陪伴關係、飼養目的（陪伴 vs 獲取經濟價值）

## 多數說難以突破的理由：體系解釋：
- 車禍同時撞死甲的 A 犬與孫子 B：B 孫部分**不得**請求慰撫金——§194 限父母、子女、配偶，立法理由明言為避免範圍過大而限縮，祖父母不在內
- 若狗可以、孫子不行 → 狗比孫子重要，**體系失衡**；人至少比物重要是民法基本原則

> 來源：民法15 課程字幕 00:53:45 ~ 01:04:00（講義註 166）

## 📖 法條原文速查

> **民法 §194**　不法侵害他人致死者，被害人之**父母、子女及配偶**，雖非財產上之損害，亦得請求賠償相當之金額。

> **民法 §195 I**　……或不法侵害**其他人格法益而情節重大者**，被害人雖非財產上之損害，亦得請求賠償相當之金額。……

> **民法 §184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「寵物被不法侵害致死，飼主得否請求慰撫金？」 | **多數見解：否**（寵物為物，財產權受侵害無慰撫金）；少數實務與林誠二：**得** |
| 「少數實務肯定之方法？」 | 寵物為介於人與物之間之獨立生命體 → 法律漏洞 → **類推適用侵權行為規定**（老師推知為 §184 I 前段＋§194） |
| 「林誠二肯定說之方法？」 | 不類推（**非法律漏洞**、動物非權利主體）；保護人與寵物之陪伴關係 → §195 I **其他人格法益**，**情節重大**可請求 |
| 「林誠二如何判斷情節重大？」 | 寵物性質、飼養期間、陪伴關係、飼養目的（陪伴 vs 經濟） |
| 「孫子被撞死，祖父母得否依 §194 請求慰撫金？」 | **否**。§194 限父母、子女、配偶，立法理由刻意限縮 |
| 「多數說維持否定之核心理由？」 | **體系解釋**：狗可請求、孫子不可 → 體系失衡 |

## 一、三種見解

```
A 犬被乙不法侵害致死，甲請求慰撫金？
│
├── 多數見解：✗ 犬＝物，財產權無慰撫金
│
├── 少數實務（高院 106 年）：✓
│     伴侶寵物＝介於人與物之間 → 法律漏洞
│     → 類推侵權行為規定（推知：§184 I 前段＋§194）
│
└── 林誠二：✓ 但不類推
      保護「人與寵物之陪伴關係」
      → §184 I 前段＋§195 I 其他人格法益（情節重大）
```

## 二、比較表

| | 少數實務 | 林誠二 |
|---|---|---|
| 保護對象 | 寵物（擬人化） | 甲與寵物之關係 |
| 有無法律漏洞 | 有 | 無（立法者價值取捨） |
| 方法 | 類推適用 | 解釋 §195 I 其他人格法益 |
| 控制 | 未明 | 情節重大（性質、期間、陪伴、目的） |

## 三、體系解釋的例子

| 車禍被撞死者 | 甲（祖父）得否請求慰撫金 | 依據 |
|---|---|---|
| A 犬 | 多數說 ✗／少數說 ✓ | 財產權 vs 其他人格法益 |
| B 孫 | **✗** | §194 限父母子女配偶 |

- 若對 A 犬肯定、對 B 孫否定，一般人無法接受；此為多數說目前最難突破之處。
