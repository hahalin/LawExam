# 民法17 筆記：獨立履行輔助人與車隊外送平臺

## 計程車乘客：
- 甲搭乙的計程車（背後是 A 車隊），乙開太快撞傷丙
- 丙對乘客甲主張 §188 ✗：乘客只指定目的地，對司機**沒有指揮監督權限**，客觀上也不像僱傭（司機叫你「老闆」不算）→ 司機是**獨立的履行輔助人**
- 王澤鑑：乘客指示司機超速闖紅燈 → 乘客是 **§185 II 造意人**，用 §185 連帶，不必硬套 §188

## 計程車車隊：
- 早期學說：車隊與司機是**居間**（平臺媒合，每趟抽成），報酬方向與僱傭相反（司機付錢給車隊），司機可隨時不出車 → 不像僱傭，車隊不負 §188
- 現況：很多司機向車隊**租車**，受高度管制（每月出車天數、制服、車內整潔、被申訴罰關機三天）→ 越管越像僱傭
- 實務漸傾向：不問法律上有無僱傭契約、實質為誰服勞務，**客觀上**已可認有僱傭關係 → 車隊負 §188；並援用靠行的法理：收錢營運就要承擔風險
- 相關實務見解：講義註釋 238（107 年判決，老師新補一則 111 年判決；字號請對講義）

## Uber 與外送平臺：
- 勞動部曾認定為僱傭；Uber 主張**承攬**（承攬依 §189 定作人原則不負責）
- 平臺對外送員幾乎沒有指揮監督：不要求單量、天數，隨時上下線，只要求使用外送箱
- 老師：屬新時代的難題，沒有標準答案；若涵攝認為無僱傭關係，結論就寫無理由，但可以反思：平臺利潤高、風險低，把風險轉嫁給消費者與路人是否失衡、是否需立特別法、有無提供保險

## 旅行社與遊覽車公司：
- 旅行社 A 辦畢業旅行，請 B 遊覽車公司出車，司機甲過失翻車
- 學生對甲 §184、對 B §188 ✓；對旅行社 A §188 ✗：B 不受 A 指揮監督，也不是為 A 服勞務，較類似承攬 → **獨立的履行輔助人**

## 📖 法條原文速查

> **§188 I 前段**　受僱人因執行職務，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。

> **§185 II**　造意人及幫助人，視為共同行為人。

> **§189**　承攬人因執行承攬事項，不法侵害他人之權利者，定作人不負損害賠償責任。但定作人於定作或指示有過失者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「計程車司機肇事，被害人得否對乘客主張 §188？」 | **否**：乘客無指揮監督權限，司機是獨立履行輔助人 |
| 「乘客指示司機超速致肇事，乘客責任依據？」 | **§185 II 造意人**，連帶負責（王澤鑑） |
| 「計程車司機肇事，車隊應否負 §188？」 | 實務漸採**肯定**：客觀上有僱傭關係（車隊管制多、收費營運） |
| 「遊覽車公司司機肇事，委託出車之旅行社應否負 §188？」 | **否**：遊覽車公司是獨立履行輔助人，不受監督 |
| 「定作人對承攬人執行承攬事項之侵權，是否負 §188？」 | **否**（§189），定作或指示有過失才依 §184 負責 |

## 一、判斷核心：有沒有指揮監督

```
協助他人完成事務的人
├── 受指揮監督（或客觀上看起來受）→ 受僱人 → §188
└── 不受指揮監督 → 獨立的履行輔助人 → 無 §188
      ├─ 計程車司機（對乘客）
      ├─ 遊覽車公司（對旅行社）
      └─ 承攬人（對定作人，§189）
```

## 二、四種關係比較

| 關係 | 指揮監督 | 金錢流向 | §188 |
|---|---|---|---|
| 乘客—司機 | 無（只指定目的地） | 乘客付車資 | ✗（指示超速 → §185 II） |
| 車隊—司機 | 越來越多（租車、制服、罰關機） | 司機付抽成／租金 | 實務漸傾向 ✓ |
| Uber—外送員 | 極微弱（只要求外送箱） | 外送員付抽成 | 有爭議，涵攝不出可寫無理由＋反思 |
| 旅行社—遊覽車公司 | 無（類似承攬） | 旅行社付費 | ✗ |
