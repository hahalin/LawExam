# 民法30 筆記：買賣契約之義務體系與§353之準用爭議（§345、§348、§349、§353）

## 債各的上課方式：
- 債總講完，進入債各；債各、物權改為**重點式**
- 債各完整講**買賣、租賃、承攬**，其他契約只帶重要條文
- 老師對出題的觀察：
  - 二試民法兩題，債編一定有一題，且幾乎都考**債總**；債各多半只是小題中的一個爭點
  - 物權在二試出現的機率不高，但仍要念
  - 民總在一試約 10～13 題（民法 50 題），基本觀念、大法庭裁定、學者文章、傳統判例都要會
- 債各的思考三層次：① **定性**（成立什麼契約）→ ② 債權債務**內容** → ③ **債務不履行**的效果

## 買賣契約的義務體系：
- 定性（§345）：一方移轉**財產權**、他方支付**價金**；標的可以是物，也可以是權利
- 出賣人：
  - 給付義務（§348）：物 → 交付並移轉所有權；權利 → 使買受人取得權利
  - **瑕疵擔保**義務：
    - 權利瑕疵：§349（權利無缺）、§350（權利存在），效果依 §353
    - 物之瑕疵：§354～§365
    - 特約免除或限制：§366
- 買受人（§367）：支付價金、受領標的物
- 違反 §348 → 一般**債務不履行**（給付不能 §226、給付遲延 §229～§232、不完全給付 §227）

## 權利瑕疵擔保的例子（買賣贓車）：
- 乙偷了甲的 A 車，賣給善意的丙並交付
  - 乙丙買賣契約**有效**；乙無權處分，丙原可依 §801、§948 善意取得
  - 但盜贓物有 §949：甲自喪失占有起**兩年內**，得向善意的現占有人丙請求回復，再依 §767 請求返還
- 丙對乙：乙應擔保第三人不得對丙主張權利（§349），甲卻來主張 → 依 §353 請求損害賠償或解除契約

## 瑕疵擔保是無過失責任：
- §349、§350、§353 都**沒有**「故意過失」「可歸責於出賣人」等用語
- 債務不履行是**過失責任**，以可歸責於債務人為要件

## §353「得依關於債務不履行之規定」怎麼準用？
- **構成要件準用**：連債務不履行的要件（可歸責）一起準用 → 變成過失責任
- **法律效果準用**：要件已由「違反 §349～§351」自己具備，只借用效果（損害賠償、解除契約）→ 維持無過失責任
- 違反 §349～§351 → **法律效果準用**，維持瑕疵擔保的無過失性質
- 違反 §348（條文也列在 §353 內）→ 爭議：
  - 通說（林誠二、邱聰智）：**構成要件準用**，仍以可歸責為要件，與債務不履行體系一致
  - 少數說：法律效果準用，是立法者要出賣人對「給付」也負無過失責任的特別規定
  - 邱聰智主張修法：把 §353 的「348」改成「349」，違反 §348 直接回到債務不履行
- 考法：甲乙買賣 A，因**不可歸責於甲**的事由給付不能
  - 乙不能依 §226 請求（須可歸責）
  - 通說：§353 對 §348 採構成要件準用，乙也**不能**依 §353 請求
  - 少數說：乙仍可依 §353 請求

## 📖 法條原文速查

> **§345 I**　稱買賣者，謂當事人約定一方**移轉財產權**於他方，他方**支付價金**之契約。

> **§348**
> I　物之出賣人，負**交付其物**於買受人，並使其**取得該物所有權**之義務。
> II　權利之出賣人，負使買受人**取得其權利**之義務，如因其權利而得占有一定之物者，並負交付其物之義務。

> **§349**　出賣人應擔保**第三人**就買賣之標的物，對於買受人**不得主張任何權利**。

> **§353**　出賣人不履行**第三百四十八條至第三百五十一條**所定之義務者，買受人得依關於**債務不履行**之規定，行使其權利。

> **§367**　買受人對於出賣人，有交付約定價金及受領標的物之義務。

> **§949 I**　占有物如係**盜贓、遺失物**或其他非基於原占有人之意思而喪失其占有者，原占有人自喪失占有之時起**二年**以內，得向善意受讓之現占有人請求回復其物。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「買賣標的限於物？」 | **不限**，財產權皆可（§345） |
| 「瑕疵擔保責任以可歸責為要件？」 | **否**，無過失責任 |
| 「違反 §349 依 §353，是要件準用還是效果準用？」 | **法律效果準用** |
| 「違反 §348，通說如何解釋 §353？」 | **構成要件準用**，仍須可歸責 |
| 「不可歸責於出賣人之給付不能，買受人可依 §353 請求？」 | 通說**不可** |
| 「買受人善意買受盜贓物，原所有人何時可請求回復？」 | 喪失占有起**兩年內**（§949） |

## §353 準用體系

```
§353「得依關於債務不履行之規定」
├── 違反 §349～§351（權利瑕疵）
│     └── 法律效果準用 → 無過失責任
└── 違反 §348（給付義務）
      ├── 通說：構成要件準用 → 須可歸責（同債務不履行）
      └── 少數說：法律效果準用 → 無過失責任
```

| 比較項目 | 構成要件準用 | 法律效果準用 |
|---------|------------|------------|
| 借用內容 | 要件＋效果 | 只借效果 |
| 責任性質 | 過失責任 | 無過失責任 |
| 適用 | §348（通說） | §349～§351 |
