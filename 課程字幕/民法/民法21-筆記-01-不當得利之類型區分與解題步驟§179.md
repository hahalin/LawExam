# 民法21 筆記：不當得利之類型區分與解題步驟（§179）

## 統一說與非統一說：
- 統一說：我國只有 §179 一條，不必學德國分類
- 非統一說：發生原因與法律構造不同，條文雖只一條，仍應分**給付型**與**非給付型**分別解釋 → **目前通說，最高法院亦採**
- 分類的實益：四要件（無法律上原因、受利益、受損害、因果關係）在兩種類型的解釋方法完全不同

## 解題三步（老師：「超級重要」）：
- 第一步：**被告受有什麼利益**（有得利才有不當得利；教科書從法律上原因講起，但涵攝時先找利益）
- 第二步：**利益從哪裡來** → 來自受損人**有意識、有目的之給予** → 給付型；其他原因 → 非給付型
- 第三步：依類型套判準
  - 給付型：**給付目的說**，任務是**矯正利益流動**
  - 非給付型：**權益歸屬說**，任務是**決定利益應歸屬於誰**

## 數字例：
- 給付型：甲賣 A 給乙並交付，買賣因意思表示撤銷而無效 → 乙得 A；A 來自甲有意識之給付；給付目的（買賣）不存在 → 無法律上原因
- 非給付型：甲把 A 車借給乙，乙轉賣丙得價金 → 乙的利益不是 A 車占有（有使用借貸），是**價金**；價金來自丙不是甲 → 非給付型；價金是 A 車的**代替利益**，依權益歸屬應屬所有人甲 → 甲得對乙請求

## 不當得利的體系：
- 與侵權行為同結構：責任成立（§179、§180）→ 返還客體（§181）→ 返還範圍（§182、§183）

## 📖 法條原文速查

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

> **§181**（要旨）　受領人除返還所受利益外，本於該利益更有所取得者，並應返還；依其性質或其他情形不能返還者，償還其價額。→ 建議查閱最新六法原文

> **§182**（要旨）　I 善意受領人所受利益已不存在者，免負返還或償還價額之責任；II 惡意受領人應返還受領時所得利益或知悉時現存利益，附加利息，如有損害並應賠償。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **101 台上 1722**（講義 279 頁）：不當得利可分為給付型與非給付型；前者係基於受損人**有目的及有意識之給付**而發生之不當得利。（要旨改寫；字號依字幕「1011722」，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「我國通說對不當得利採統一說？」 | **錯**，採非統一說，分給付型、非給付型 |
| 「給付型不當得利之『給付』意義？」 | 受損人**有意識、有目的**增加他人財產 |
| 「給付型之無法律上原因採何說？」 | **給付目的說** |
| 「非給付型之無法律上原因採何說？」 | **權益歸屬說** |
| 「乙擅賣甲借給他的車，甲對乙之不當得利屬何類型？」 | **非給付型**（價金來自丙，不是甲） |
| 「不當得利之責任成立規定於？」 | **§179、§180**；返還客體 §181；範圍 §182、§183 |

## 一、解題流程

```
被告受有什麼利益？
   ↓
利益是否來自原告有意識、有目的之給予？
├─ 是 → 給付型：給付目的是否存在（給付目的說）
│        ↓ 再檢驗 §180 例外
└─ 否 → 非給付型：利益依法應歸屬誰（權益歸屬說）
```

## 二、兩種類型對照

| | 給付型 | 非給付型 |
|---|---|---|
| 利益來源 | 受損人有意識之給予 | 給付以外之行為或法律規定 |
| 功能 | 矯正利益流動 | 決定權益歸屬 |
| 法律上原因判準 | 給付目的說 | 權益歸屬說（行為）、法規目的說（法律規定） |
| §180 | 適用 | 不適用（見民法21-筆記-11） |

## 三、借車擅賣：為什麼不能用給付目的說

- 甲乙間有使用借貸、乙丙間有買賣 → 用給付目的說看，乙怎麼看都有法律上原因
- 改問「這筆價金在法律上屬於誰」→ A 車處分之代價屬所有人 → 甲得請求
