# 民法38 筆記：共有人間約定對應有部分受讓人之效力（§826-1釋字349）

## 問題
- 甲乙丙共有 A 地各 1/3，訂有分管契約；甲把 1/3 賣給丁並移轉登記
- 原分管契約拘束丁嗎？
- 拉扯：**團體法理**（加入團體就受團體規範拘束）vs. **債之相對性**（契約只拘束當事人）

## 三個階段
1. **早期實務（48 台上 1065 判例）**：肯定說，採團體法理，受讓人一律受拘束
2. **釋字349**：受讓人**明知或可得而知**才受拘束；不知者不受拘束——不能以團體法理強迫人接受完全不知情的法律關係
3. **98 年增訂 §826-1**：參考釋字349 精神，但依不動產／動產重新設計

## §826-1 的結構
- **不動產（I）**：約定或決定**經登記**後，對應有部分受讓人或取得物權之人具有效力
- **動產（II）**：受讓或取得時**知悉或可得而知**者，才有效力
- **連帶責任（III）**：應有部分讓與時，受讓人對讓與人因使用、管理等所生的負擔，負連帶清償責任

## 適用的四種情形
- 條文區分「約定」與「決定」：
  - 約定（契約，全體同意）：**分管契約、分割協議、不分割協議**
  - 決定（多數決）：依 §820 I 的**分管決定**
- 推論：分割與不分割只能用契約，不能多數決；分管則兩者皆可

## 爭點：不動產未登記（默示分管契約）
- 默示分管：無書面、長年相互容忍形成的默契，事實上不可能登記
- §826-1 I 只講登記後有效，**未登記怎麼辦條文沒說**
  - 甲說：回到釋字349，看受讓人是否明知或可得而知
  - 乙說：對 §826-1 I 作**反面解釋**，未登記即無拘束力
- 老師觀察：近來最高法院偏向乙說，以督促共有人去登記（老師自承是推測）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 不動產分管契約對受讓人效力 | **經登記**後有效（§826-1 I） |
| 動產分管約定對受讓人效力 | 受讓時**知悉或可得而知**（§826-1 II） |
| §826-1 適用對象 | 分管契約、分管決定、分割協議、不分割協議 |
| 分割協議可否多數決 | **不可**，須全體同意 |
| 受讓人對讓與人使用管理負擔 | **連帶**清償責任（§826-1 III） |
| 釋字349 判準 | 明知或可得而知 |

## 演變對照

| 時期 | 判準 | 丁不知情時 |
|---|---|---|
| 48 台上 1065 | 團體法理 | 仍受拘束 |
| 釋字349 | 明知或可得而知 | 不受拘束 |
| §826-1（不動產） | 登記 | 已登記即受拘束；未登記有爭議 |
| §826-1（動產） | 知悉或可得而知 | 不受拘束 |

## 判斷流程

```
共有人間約定／決定，受讓人丁受拘束？
   ├─ 不動產 ── 已登記？ ─ 是 → 受拘束
   │               └─ 否 → 甲說：回釋字349（明知／可得而知）
   │                       乙說：反面解釋，不受拘束（近期實務傾向）
   └─ 動產 ──── 丁知悉或可得而知？ ─ 是 → 受拘束；否 → 不受拘束
```
