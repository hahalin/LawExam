# 民法13 筆記：時效中斷的效力及於誰——§138 相對效力（當事人、繼承人、受讓人）；不及於其他**連帶債務人**（§279；73 台上 2128：僅對被起訴者中斷，兩年後追加其他連帶債務人可為時效抗辯 → 要告就一次全部告）；**保證人** §747：「（債權人）向主債務人請求履行及為其他中斷時效之行為」對保證人亦生效力——限於債權人之行為（§129 I ①③、II）；主債務人之**承認**（§129 I ②）不及於保證人：實務以 §747 反面解釋，陳榮傳認反面解釋推不出結論，應類推 §742 II（主債務人拋棄之抗辯保證人仍得主張）

> 來源：民法13 課程字幕 00:06:10 ~ 00:17:25（講義註 95-2；105 台上 1144、107 台上 85 涉抵押權，物權再講）

## 📖 法條原文速查

> **§138**　時效中斷，以當事人、繼承人、受讓人之間為限，始有效力。
> **§279**　就連帶債務人中之一人所生之事項，除前五條規定或契約另有訂定者外，其利益或不利益，對他債務人不生效力。
> **§747**　向主債務人請求履行，及為其他中斷時效之行為，對於保證人亦生效力。
> **§742 II**　主債務人拋棄其抗辯者，保證人仍得主張之。
> **§185 I**　數人共同不法侵害他人之權利者，連帶負損害賠償責任。
> **§273 I**　連帶債務之債權人，得對於債務人中之一人或數人或其全體，同時或先後請求全部或一部之給付。

## 📋 實務見解速查

> **最高法院 73 年台上字第 2128 號判決**（講義註 95-2，字號照字幕）：我國民法對於消滅時效中斷，係採相對效力，即時效中斷僅限於當事人、繼承人、受讓人之間始有效力；所謂當事人，係關於致時效中斷行為之人。故連帶債務人中之一人發生時效中斷之事由，除該債務人應分擔之部分外，對其他債務人並不生效力……被上訴人於二年時效期間內對上訴人起訴請求損害賠償，其對上訴人之請求權消滅時效固因而中斷，但其對於另一連帶債務人之請求權消滅時效，並不中斷。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲乙丙共同侵權（§185 連帶），A 僅對甲起訴；兩年後發現甲無資力，追加乙丙為被告，乙丙得否時效抗辯？」 | **得**。§138 相對效力＋§279：對甲起訴只對甲中斷（§129 I ③），乙丙的請求權時效獨立進行、不受影響 → 遇連帶債務，**要告就一次全部告** |
| 「§747 之主語？」 | 省略了「債權人」：**債權人**向主債務人請求履行及其他中斷時效之行為（§129 I ①請求、③起訴、II 類似起訴）→ 及於保證人 |
| 「主債務人向債權人承認債務（§129 I ②），對保證人之時效是否中斷？」 | **不中斷**（實務、學說一致，理由不同）。實務：§747 只列債權人之行為，**反面解釋**承認不在內。陳榮傳：法條沒講不等於沒有（也可能是忘記規定、可類推），反面解釋推不出結論；應從保證法理——**債務人之不利益保證人不應承擔**——類推 **§742 II**（主債務人拋棄的抗辯保證人仍得主張）得出不及於保證人 |
| 「為何是類推 §742 II 而非直接適用？」 | 時效完成**後**的承認＝拋棄時效抗辯（§742 II 直接適用）；時效進行**中**的承認只是重行起算、不是拋棄 → 性質類似（都是對保證人不利）→ 類推 |

## 一、§138 相對效力：及於誰

```
致時效中斷行為之當事人 → 其繼承人（死亡）→ 債權受讓人（債權讓與）
＝ 具有同一性的人，不會擴張出去
```

## 二、連帶債務人：不及

```
A 受害 100 萬，甲乙丙 §185 連帶 → A 得依 §273 對一人請求全部
A 只告甲 → §129 I ③ 對甲中斷
兩年後追加乙丙 → 乙丙的時效獨立進行、早已完成 → 得時效抗辯（§138、§279、73 台上 2128）
司機／雇主例：先告司機，快兩年才想追加老闆 → 對老闆的請求權可能已罹於時效
→ 實務建議：連帶債務要告就一次全告，不要先告一個試水溫
```

## 三、保證人：§747 只及於債權人的行為

| 中斷事由 | 行為人 | 及於保證人？ | 依據 |
|---|---|---|---|
| 請求（§129 I ①）、起訴（③）、類似起訴（II） | 債權人 | ✓ | §747 |
| 承認（§129 I ②） | 主債務人 | ✗ | 實務：§747 反面解釋／陳榮傳：類推 §742 II |

- 陳榮傳對實務的批評：最高法院最愛對沒規定的東西類推，這裡卻說沒講就沒有——法律沒規定有兩種可能（故意不規定／忘記規定），反面解釋不能當然成立。結論相同、理由要嚴謹。
- 字幕先作「陳龍傳」後作「陳榮傳」，筆記取陳榮傳，建議查閱講義；陳聰富另有文章，債各保證契約再看。
