# 民法37 筆記：有償袋地通行權與任意行為所生之袋地（§787、§788）

## 兩種袋地通行權：
- **有償**：§787（一般情形，容忍＋補償）
- **無償**：§789（一部讓與、分割等造成的袋地，見本講筆記-03）

## §787 的構成要件：
1. **袋地或準袋地**
   - 袋地：與公路完全沒有聯絡
   - 準袋地：與公路**無適宜之聯絡**，致不能為通常使用
   - 例：聯外道路寬不到 2 公尺，一般汽車勉強、砂石車與挖土機進不去 → 無法開發，仍屬準袋地
2. **非因土地所有人之任意行為所生**
   - 地震、土石流沖毀道路、聯外橋樑被拆除，非你造成 → 可主張
   - 自己把原有出路封閉、自己築牆擋住 → 自己承擔風險，不得轉嫁給鄰地

## 法律效果：
- 得通行周圍地以至公路
- 須擇**損害最少之處所及方法**（§787 II）；不能硬要從人家房子正中間過
- 對損害最少的處所有爭議 → 準用 §779 IV，**請求法院以判決定之**（§787 III）
- 必要時得**開設道路**（§788 I）
- 須**支付償金**：鄰地依法有容忍義務，但容忍要補償

## 爭點：終止租約、縮減租地造成的袋地，算任意行為嗎？
- 事實：甲地本是袋地，甲向乙承租乙地一部分作為通往公路的通道；後來甲與乙約定**縮減承租面積**（或終止租約），甲地又與公路無適宜聯絡
- 問題：甲能否對鄰地主張 §787？
- **103 台上 505**：屬任意行為，**不得主張**通行權
  - 甲本可請求第三人除去無權占有通道之妨害，卻自行縮減租地、排除對公路的適宜聯絡，應自行承受後果
- 結論：「自己行為所致」包括
  - 物理上：封路、拆橋、築牆
  - 法律上：自行終止租約、縮減租賃範圍

## 解題流程：
```
甲地與公路無適宜聯絡
   ↓
是否因甲之任意行為所生？
   ├─ 是（封路、終止租約、縮減租地）→ 不得主張 §787
   └─ 否（天災、橋樑被拆）
         ↓
   是否因一部讓與、分割、同屬一人分別讓與？
   ├─ 是 → §789 無償，只能走原地（筆記-03）
   └─ 否 → §787 有償，擇損害最少處所，付償金
```

## 📖 法條原文速查

> **§787**（袋地通行權）
> I　土地因與公路**無適宜之聯絡**，致不能為通常使用時，除因土地所有人之**任意行為**所生者外，土地所有人得通行周圍地以至公路。
> II　前項情形，有通行權人應於通行必要之範圍內，擇其周圍地**損害最少之處所及方法**為之；對於通行地因此所受之損害，並應**支付償金**。
> III　第七百七十九條第四項規定，於前項情形準用之。

> **§788 I**（開路通行權）
> 有通行權人於必要時，得**開設道路**。但對於通行地因此所受之損害，應支付償金。
> → II 項（通行地損害過鉅時得請求購買）建議查閱最新六法原文

> **§779 IV**　第一項但書之情形，鄰地所有人有異議時，有通過權之人或異議人得**請求法院以判決定之**。

## 📋 實務見解速查

> **最高法院 103 年台上字第 505 號判決**（講義註釋 123）：承租人與出租人約定減縮承租土地面積，致承租土地成為袋地而與公路無適宜之聯絡，屬以任意行為自行排除對公路之適宜聯絡，應自行承受其後果，不得主張 §787 通行權。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「路寬不足、車輛無法通行之土地得否主張通行權？」 | **得**，屬無適宜之聯絡（準袋地） |
| 「土地所有人自行封閉出路致成袋地？」 | 任意行為所生，**不得**主張 §787 |
| 「承租人縮減租地面積致成袋地？」 | **任意行為**，不得主張（103 台上 505） |
| 「§787 通行權人應否支付償金？」 | **應支付**（有償） |
| 「通行處所有爭議如何處理？」 | 準用 §779 IV，請求法院判決定之 |
