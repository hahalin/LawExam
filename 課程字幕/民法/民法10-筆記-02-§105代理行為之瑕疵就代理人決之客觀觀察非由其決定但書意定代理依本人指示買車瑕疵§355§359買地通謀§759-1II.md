# 民法10 筆記：§105 代理行為之瑕疵——意思欠缺、被詐欺脅迫、明知或可得而知，原則「就代理人決之」（客觀上從代理人角度觀察，不是由代理人決定）；但書：意定代理＋依本人指示 → 就本人決之；買車瑕疵 §355／§359 案、買地通謀虛偽 §759-1 II 案

> 來源：民法10 課程字幕 00:14:00 ~ 00:28:53

---

## 📖 法條原文速查

> **§105**　代理人之意思表示，因其意思欠缺、被詐欺、被脅迫，或明知其事情或可得而知其事情，致其效力受影響時，其事實之有無，應**就代理人決之**。但代理人之代理權係以法律行為授與者，其意思表示，如依照本人所指示之意思而為時，其事實之有無，應**就本人決之**。
> **§355 I**　買受人於契約成立時，知其物有前條第一項所稱之瑕疵者，出賣人不負擔保之責。
> **§359**　買賣因物有瑕疵，而出賣人依前五條之規定，應負擔保之責者，買受人得解除其契約或請求減少其價金。……
> **§759-1 II**　因信賴不動產登記之善意第三人，已依法律行為為物權變動之登記者，其變動之效力，不因原登記物權之不實而受影響。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§105 在處理什麼？」 | 只處理一件事：代理行為的**瑕疵**（§86～§88 意思欠缺、§92 詐欺脅迫、善惡意有無過失）要從**本人**還是**代理人**的角度判斷。原則就**代理人**決之；例外（意定代理＋依本人指示）就**本人**決之 |
| 「『就代理人決之』＝由代理人決定？」 | **不是**。「就」＝客觀上從代理人的角度觀察（法官看他有沒有被騙），不是問他、也不是讓他決定 |
| 「甲知 A 車有瑕疵，授權乙『去買車』，乙不知瑕疵買了 A 車，甲得否依 §359 主張？」 | **可以**。買哪台車是乙決定的 → 就乙決之 → 乙不知情 → 視同甲不知情 → §355 不排除 → 甲得減少價金或解除契約 |
| 「同上，但甲授權乙『去買 A 車』？」 | **不可以**。意定代理＋依本人指示 → §105 但書就甲決之 → 甲知情 → §355 I 出賣人不負擔保責任 |
| 「丙丁通謀虛偽將地登記給丙，甲知情；甲授權乙『買地』，乙善意，代理甲向丙買 A 地並完成登記，地歸誰？」 | **甲**善意取得（§759-1 II）。丙丁 §87 無效、丙非所有人 → 物權行為無權處分；但買 A 地是乙決定的 → 善惡意就乙決之 → 乙善意 → 甲雖惡意仍受保護 |
| 「考題外觀？」 | 一定是本人與代理人狀態**不一致**（一個被詐欺一個沒有、一個善意一個惡意），先用 §105 定角度，再往下解 |

## 一、讀 §105 的技巧：把「因其……可得而知其事情」括起來

```
代理人之意思表示，因【意思欠缺（§86 §87 §88）、被詐欺被脅迫（§92）、明知或可得而知（善惡意、有無過失）】
致其效力受影響時，其事實（＝括號裡那些事）之有無 → 應「就」代理人決之
但：意定代理（「代理權係以法律行為授與」）＋ 依本人所指示之意思而為 → 就本人決之
```

- 「就 X 決之」vs「由 X 決之」：法條用「就」，是客觀上從 X 的角度觀察有沒有那個事實，由法官判斷，不是讓 X 自己說了算。問代理人「你有沒有被騙」他說沒有，不代表沒有。
- 法定代理不需要授權，所以但書「以法律行為授與」一出現就是意定代理。

## 二、判斷公式：誰做的決定，瑕疵就從誰的角度看

| 授權內容 | 誰決定買 A | 就誰決之 |
|---|---|---|
| 「幫我買車」 | 乙（買哪台由乙決定） | 乙（原則） |
| 「幫我買 A 車」（乙去談價錢、付款條件等細節） | 甲 | 甲（但書：意定代理＋指示） |

## 三、案例一：買車瑕疵（§355／§359）

```
甲曾看過 A 車，知道有瑕疵沒買
甲授權乙買車 → 乙不知瑕疵 → 買了 A 車
甲要依 §359 減價或解約 → §355 I：買受人契約成立時知瑕疵，出賣人不負擔保責任
→ 甲知情嗎？題目說知情。但決定買 A 的是乙 → §105 本文就乙決之 → 乙不知 → 等同甲不知 → 甲可主張 §359
變化：甲授權乙「買 A 車」→ 但書就甲決之 → 甲知情 → 不能主張
```

## 四、案例二：買地遇通謀虛偽（§87、§759-1 II）

```
丁 ─通謀虛偽移轉登記─→ 丙（§87 I 無效，丙未取得所有權）；甲知道這件事（惡意）
甲授權乙「買地」→ 乙善意 → 乙代理甲向丙買 A 地並完成移轉登記
→ 買賣契約有效；物權行為：丙無所有權 → 無權處分效力未定
→ 甲能否善意取得？很多人看到「甲惡意」就答不能 → 錯
→ 決定買 A 地的是乙 → 善惡意就乙決之 → 乙善意 → 甲依 §759-1 II 善意取得
理由：甲只授權買地，萬中選一選到 A 地的是乙，風險不該由甲承擔
```

## 五、§105 的功用

- 考試一定給你本人和代理人**不一樣**的狀態（一個被詐欺一個沒有、一個錯誤一個沒有、一個通謀一個沒有、一個善意一個惡意）。
- 先用 §105 決定從誰的角度看 → 再用觀察結果往下解題。§105 本身不給結論，是判斷工具。
