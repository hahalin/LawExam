# 民法39 筆記：抵押權擔保債權之範圍與利息五年限制（§861§145）

## 擔保範圍五項（§861 I）：
- 原債權、利息、遲延利息、違約金、實行抵押權之費用；契約另有約定者從其約定

## 爭點一：哪些要登記才在擔保範圍內？
- 舊爭議：應登記說（抵押權是不動產物權，非經登記不生效力）vs 不須登記說（法律已規定）
- 現行主流：**區分說**（字幕：102 年第 13 次民事庭決議補充 73 台抗 239 判例；陳榮傳同說）
- 判準：**約定才有的 → 要登記；法律規定一定有的 → 不必登記**

| 項目 | 法定或約定 | 須否登記 |
|---|---|---|
| 原債權 | — | **一定要**（否則欠缺發生上從屬性；最高限額抵押權除外） |
| 約定利息 | 約定 | 要 |
| 法定遲延利息（§233） | 法定 | 不必 |
| 違約金 | 只有約定（台灣無法定違約金） | 要 |
| 實行抵押權費用（執行費千分之八） | 法定 | 不必 |

- 理由是交易安全：法律規定的，後手看法條就知道；約定的，不登記後手無從得知

## 爭點二：登記的方法
- **附件**：登記簿寫不下，抵押權設定契約書可視為登記簿附件，所載擔保債權為抵押權效力所及（字幕：101 年 1031 號判決）
- **寫「無」vs 留白**
  - 寫「無」→ 明示排除，約定、法定都不在範圍內
  - 留白 → 要登記的項目＝未登記＝不在範圍；不必登記的項目仍在範圍
  - 例：違約金留白 → 不擔保；實行費用留白 → 仍擔保

## 爭點三：利息只擔保實行前五年（§861 II）
- 甲 100/12/10 向乙借款並設定抵押權，分文未付，乙 113/12/10 聲請實行
- 本金未罹時效 → 可受償
- 利息短期時效 **5 年**（§126）→ 只有 108/12/10～113/12/10 這段未罹時效
- 108/12/10 以前的利息：§145 I 說罹於時效仍可就抵押物取償，但 **§145 II 排除利息及其他定期給付** → 不能取償
- 所以 §861 II 限於**聲請強制執行前五年內**及**執行程序中**發生者
- 實務上司法事務官製作分配表時常見，選擇題也常考

## 📖 法條原文速查

> **§861**（擔保債權之範圍）
> I 抵押權所擔保者為**原債權、利息、遲延利息、違約金及實行抵押權之費用**。但契約另有約定者，不在此限。
> II 得優先受償之利息、遲延利息、一年或不及一年定期給付之違約金債權，以於抵押權人實行抵押權聲請強制執行**前五年內**發生及於強制執行程序中發生者為限。

> **§145**（附有擔保之請求權時效完成之效力）
> I 以抵押權、質權或留置權擔保之請求權，雖經時效消滅，債權人**仍得**就其抵押物、質物或留置物取償。
> II 前項規定，於**利息及其他定期給付**之各期給付請求權，經時效消滅者，**不適用之**。

> **§126**（短期時效）利息、紅利、租金、贍養費、退職金及其他一年或不及一年之定期給付債權，其各期給付請求權，因**五年**間不行使而消滅。

## 📋 實務見解速查

> **73 台抗 239 判例**（經決議補充）：抵押權所擔保之債權，其範圍包括遲延利息在內，且不以登記為必要；所稱遲延利息，指**法定**遲延利息。（要旨改寫；補充之決議字幕唸「102年第13次」，年度次數建議查證）

> **最高法院 101 年度台上字第 1031 號判決**（字幕唸「101年的1031」，字號建議查證）：抵押權所擔保之債權未於登記簿逐一記載者，申請登記時提出之抵押權設定契約書得視為登記簿之**附件**，其上記載之擔保債權為抵押權效力所及。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「約定利息未登記，是否為抵押權擔保範圍？」 | **否**，約定者須登記 |
| 「法定遲延利息未登記？」 | **仍擔保**（73 台抗 239） |
| 「設定契約書違約金欄留白？」 | **不擔保**（違約金須登記） |
| 「實行抵押權費用欄留白？」 | **仍擔保**（法定） |
| 「欄位寫『無』？」 | 明示排除 |
| 「罹於時效之本金可否就抵押物取償？」 | **可以**（§145 I） |
| 「罹於時效之利息可否就抵押物取償？」 | **不可**（§145 II）→ §861 II 限前五年 |

---

## 判斷流程

```
某項目是否在擔保範圍？
├─ 寫「無」 → 排除
├─ 有登記 → 在範圍
└─ 未登記／留白
     ├─ 法定（遲延利息、執行費） → 仍在範圍
     └─ 約定（利息、違約金） → 不在範圍
再檢查：利息、遲延利息、定期違約金 → 只算聲請執行前五年＋執行中
```
