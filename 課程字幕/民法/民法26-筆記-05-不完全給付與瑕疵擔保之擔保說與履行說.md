# 民法26 筆記：不完全給付與瑕疵擔保之擔保說與履行說

## 先審查可不可歸責：
- 瑕疵擔保是**無過失責任**；不完全給付（§227）以**可歸責**為要件
- 不可歸責 → 不能走 §227，只剩瑕疵擔保（§359 等）
- 可歸責 → 可能同時構成 §227 與瑕疵擔保 → 再看瑕疵發生的時點

## 77 年第 7 次民庭決議的關鍵句：
- 出賣人交付的標的物有應負擔保責任之瑕疵，**瑕疵於契約成立後始發生**，且因可歸責於出賣人之事由所致 → 除物之瑕疵擔保責任外，**同時構成不完全給付**
- 事後瑕疵（締約後才發生）＋可歸責 → 兩者都構成，爭議不大
- 爭點在**自始瑕疵**（締約前就存在）＋可歸責

## 自始瑕疵是否構成不完全給付：
- **擔保說**：不構成，純粹瑕疵擔保問題
- **履行說**：構成，同時有瑕疵擔保與不完全給付
- 為什麼要分：只構成瑕疵擔保就處理到這裡；兩者都構成就要往下處理**競合**（請求權競合或規範競合，留到買賣契約再講）

## 核心：出賣人有沒有「給付無瑕疵之物」的義務？
- 例：A 車滿分 100 分，因泡水瑕疵只有 60 分；雙方以 A 車為買賣標的，出賣人交付這台 60 分的車
- **擔保說**：買賣標的就是這台 60 分的車，現況交付就符合債之本旨 → 無不完全給付；瑕疵另依瑕疵擔保處理
  - 理由：以往認為出賣人沒有排除瑕疵的能力，不能期待他給付無瑕疵之物
- **履行說**：出賣人有給付無瑕疵之物的義務；除非明確約定現況交付或已告知瑕疵，買受人期待的是至少中等品質的 A 車 → 交付 60 分的車不合債之本旨 → 同時構成不完全給付
  - 理由：現代交易中出賣人大多有提供無瑕疵物的能力，至少也應告知瑕疵

## 📖 法條原文速查

> **§227 I**　因**可歸責**於債務人之事由，致為不完全給付者，債權人得依關於給付遲延或給付不能之規定行使其權利。

> **§354 I**　物之出賣人對於買受人，應擔保其物依第三百七十三條之規定**危險移轉於買受人時無**滅失或減少其價值之瑕疵，亦無滅失或減少其通常效用或契約預定效用之瑕疵。但減少之程度，無關重要者，不得視為瑕疵。

> **§359**　買賣因物有瑕疵，而出賣人依前五條之規定，應負擔保之責者，買受人得解除其契約或請求減少其價金。但依情形，解除契約顯失公平者，買受人僅得請求減少價金。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **最高法院 77 年第 7 次民事庭會議決議**：出賣人就其交付之買賣標的物有應負擔保責任之瑕疵，而其瑕疵係於**契約成立後始發生**，且因可歸責於出賣人之事由所致者，則出賣人除負物之瑕疵擔保責任外，同時構成不完全給付之債務不履行責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「瑕疵擔保是否以可歸責為要件？」 | **否**，無過失責任 |
| 「出賣人不可歸責，買受人可否依 §227 請求？」 | **不可**，只能走瑕疵擔保 |
| 「77 年第 7 次決議處理的是哪種瑕疵？」 | 契約成立後始發生（**事後瑕疵**）＋可歸責 |
| 「可歸責之自始瑕疵，擔保說的結論？」 | 只構成瑕疵擔保，**不構成**不完全給付 |
| 「履行說的核心理由？」 | 出賣人有**給付無瑕疵之物**的義務 |

## 判斷流程

```
標的物有瑕疵
├── 不可歸責 → 只有瑕疵擔保（§354、§359）
└── 可歸責
    ├── 事後瑕疵 → 瑕疵擔保＋不完全給付（77 年第 7 次決議）→ 處理競合
    └── 自始瑕疵
        ├── 擔保說 → 只有瑕疵擔保
        └── 履行說 → 瑕疵擔保＋不完全給付 → 處理競合
```

## 兩說對照

| | 擔保說 | 履行說 |
|---|---|---|
| 出賣人義務 | 現況交付即可 | 給付無瑕疵之物 |
| 交付 60 分的 A 車 | 合於債之本旨 | 不合債之本旨 |
| 可歸責自始瑕疵 | 只有瑕疵擔保 | 另構成 §227 |
| 背景 | 出賣人無排除瑕疵能力 | 現代出賣人多有此能力 |
