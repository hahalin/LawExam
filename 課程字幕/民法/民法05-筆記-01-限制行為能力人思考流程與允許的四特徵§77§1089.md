# 民法05 筆記：限制行為能力人的思考流程與「允許」的四個特徵 §77 §1089

> 來源：民法05 課程字幕 00:00:01 ~ 00:13:37

---

## 📖 法條原文速查

> **§77**（限制行為能力人之意思表示）
> 限制行為能力人為意思表示及受意思表示，應得法定代理人之**允許**。但純獲法律上利益，或依其年齡及身分、日常生活所必需者，不在此限。

> **§79**（未得允許之契約）
> 限制行為能力人未得法定代理人之允許，所訂立之契約，須經法定代理人之**承認**，始生效力。
> → 事前叫允許、事後叫承認，通稱同意

> **§1089 I**（父母共同行使親權）
> 對於未成年子女之權利義務，除法律另有規定外，由父母**共同**行使或負擔之。父母之一方不能行使權利時，由他方行使之。……
> → 法定代理權是親權的內涵之一 → 允許原則上父母共同為之（民國 74 年修法前由父行使、母補充）

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「允許與承認之別？」 | 允許＝**事前**同意（§77）；承認＝**事後**同意（§79） |
| 「父同意、母反對，小孩買機車？」 | §1089 父母**共同**行使 → 一人反對即**未得允許** |
| 「允許須以書面為之？」 | **不須**，不要式 |
| 「允許應向誰為之？」 | 向**限制行為能力人**或**相對人**皆可，做一次就夠 |
| 「父母對 16 歲子女說『以後所有事都同意，不用再問』？」 | **概括允許無效**。允許可就「一定範圍」為之（畢業旅行），不能概括 |
| 「法代允許承租房屋，子女嗣後自行終止租約？」 | 終止**不在允許範圍內**（父母預見可能性）；水電費、網路費在範圍內 |
| 「經法代允許之行為必有效？」 | 不精確。只是**不受行為能力影響**（過第一關），仍須其他要件 |

## 一、整張思考流程圖

```
限制行為能力人（滿 7 歲未成年、未受監護宣告）
│
├── 法定代理人代為並代受意思表示 → OK（除非濫用代理權，見民法04 筆記 12）
│
└── 自己做法律行為
      ├── 經法代允許（§77 一般允許、§84 財產處分、§85 營業）→ 不受行為能力影響
      └── 未經允許
            ├── 先看例外（符合 → 不受影響，不用再往下）
            │     ├── §77 但書：純獲法律上利益
            │     ├── §77 但書：依年齡身分日常生活所必需
            │     ├── 中性行為（類推 §77 但書）
            │     └── §83 詐術
            └── 不符合例外 → 回到原則
                  ├── 單獨行為 → §78 無效
                  └── 契約 → §79 效力未定 → §80 催告、§81 成年承認、§82 撤回
```

- 老師：題目沒講到的要件就當它符合；但學習時每個要件都想一遍，才不會漏爭點。
- 「經允許就有效」推太快：允許只是行為能力這關過了（一試過了不等於考上），意思表示、標的、處分權、代理都還要看。

## 二、「允許」的四個特徵

| # | 特徵 | 說明 |
|---|------|------|
| ① | 由**法定代理人**為之；數人時**共同** | §1089 父母共同行使親權。考題寫「經法定代理人同意」就當都同意；寫「父可母不可」→ 未得允許 |
| ② | **不要式** | 口頭即可 |
| ③ | 向限制行為能力人**或**相對人為之皆可 | 15 歲甲與乙締約，法代丙對甲或對乙表示允許都算，一次即可 |
| ④ | 須有**一定範圍可界定**，**不得概括** | 「畢業旅行相關的事都同意」OK；「從今以後你的事我都同意」✗ |

### 範圍怎麼認定：父母的預見可能性

#### 事實（醫師國考選擇題）
17 歲甲向乙承租房屋，法代同意。後甲想搬去跟朋友住，私下向乙表示終止租約。

#### 分析
```
法代同意「承租」≠ 同意「終止」
    父母預見：我知道這個房東、這間房子，所以同意他住這裡
    他不住了要去住哪？跟朋友住？→ 不在預見範圍 → 終止不在允許範圍內
但：水電費、網路費 → 租房當然會有 → 在範圍內
```
- 沒有法定標準，個案從父母的預見去判斷。
