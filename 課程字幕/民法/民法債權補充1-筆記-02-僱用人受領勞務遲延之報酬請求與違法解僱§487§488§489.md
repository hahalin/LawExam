# 民法債權補充1 筆記：僱用人受領勞務遲延之報酬請求與違法解僱（§487§488§489）

## §487 的效果
- 僱用人**受領勞務遲延**者，受僱人**無補服勞務**之義務，**仍得請求報酬**
- 條文但書另可扣除受僱人因此減省的費用、轉向他處服勞務所得等（→ 建議查閱最新六法原文）

## 什麼是受領遲延（§234、§235）
- 債務人已**提出給付**，債權人拒絕受領或不能受領
- 提出的方式：
  - **現實提出**：真的去上班
  - **言詞提出**：債權人**預示拒絕**受領，或給付**兼需債權人之行為**者，以準備給付之事情通知債權人即可

## 套用一：僱主不改善工作環境（接筆記-01）
- 在安全環境上班＝給付兼需債權人（僱主改善）的行為
- 受僱人以言詞表示「準備好隨時上班」→ 已提出；僱主不改善 → 受領遲延
- → 受僱人不用上班、不用補服勞務，仍可請求薪水（林誠二）

## 套用二：違法解僱期間的薪水
- 違法解僱 → 解僱無效，**僱傭關係仍存在**
- 受僱人提起確認僱傭關係存在之訴或調解，中間這段時間能否向公司請求薪水？→ 實務用 **§487**
  - 前提：受僱人已**言詞提出**（例：寄存證信函表示隨時可回去上班，請指定時間地點），僱主拒絕受領
  - 若是**合法**解僱，僱傭關係已消滅，沒有給付義務，也就沒有受領遲延
- 爭點：勞工常常沒寄存證信函
  - 最高法院：沒有言詞提出，就不構成受領遲延，不能主張 §487
  - **徐婉寧**：不必那麼嚴格；客觀上讓僱主知道受僱人有積極回去上班的意思即可——**提起確認解僱違法之訴**本身就可認為已言詞提出

## 僱傭關係的消滅（§488、§489）
- 定有期限：期限屆滿時消滅（§488 I）
- 未定期限且不能依勞務性質或目的定期限：各當事人得**隨時終止**；但有利於受僱人的習慣從其習慣（§488 II，例：過年前不解僱）
- 有**重大事由**：縱定有期限，也可在期限屆滿前終止；事由因一方過失而生，他方得請求損害賠償（§489）
- 勞動基準法有特別規定者優先適用

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 僱用人受領遲延之效果 | 無補服勞務義務，**仍得請求報酬** |
| 言詞提出之情形 | 債權人預示拒絕、給付兼需債權人行為 |
| 違法解僱期間請求薪水之依據 | §487 |
| 違法解僱未寄存證信函（徐婉寧） | 提起確認訴訟可認為已言詞提出 |
| 合法解僱後可否主張 §487 | **否**，僱傭關係已消滅 |
| 未定期限僱傭 | 隨時終止，有利受僱人之習慣從其習慣 |

## 推論流程

```
請求違法解僱期間的薪水
  1. 解僱違法？ → 僱傭關係仍存在
  2. 受僱人有無提出給付？ → 言詞提出（§235 但書）
       實務：須明確通知；徐婉寧：起訴即可
  3. 僱主拒絕受領 → 受領遲延（§234）
  4. §487 → 不補服勞務，仍得請求報酬
```
