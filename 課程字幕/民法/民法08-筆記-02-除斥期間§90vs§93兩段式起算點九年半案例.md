# 民法08 筆記：撤銷權的除斥期間 §90 vs §93——一段式 vs 兩段式、起算點才是考點、九年半才發現怎麼辦

> 來源：民法08 課程字幕 00:07:30 ~ 00:14:51

---

## 📖 法條原文速查

> **§90**　前二條（§88 錯誤、§89 傳達錯誤）之撤銷權，自**意思表示後**，經過**一年**而消滅。
> **§93**　前條（§92）之撤銷，應於**發見詐欺或脅迫終止後**，**一年內**為之。但自**意思表示後**，經過**十年**，不得撤銷。
> **§197 I**（對照）因侵權行為所生之損害賠償請求權，自請求權人**知有損害及賠償義務人時**起，二年間不行使而消滅；自有**侵權行為時**起，逾十年者亦同。
> **§56 I**（對照）總會之召集程序或決議方法違反法令或章程時，社員得於**決議後三個月內**請求法院撤銷其決議。……

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§88 錯誤撤銷權之除斥期間起算？」 | **意思表示時**起一年，**不是**發現錯誤時 |
| 「§92 詐欺撤銷權之除斥期間？」 | **兩段式**：發見詐欺後一年內 ＋ 意思表示後不逾十年，**兩個都要符合** |
| 「意思表示後九年半才發現被詐欺，還有多久可撤？」 | **六個月**（十年上限先到） |
| 「為何 §90 一段式、§93 兩段式？」 | §88 是**自己的錯**且撤銷破壞交易安全 → 側重法安定性，固定從意思表示起算；§93 要保護**被詐欺的表意人**，發現才起算，但為法安定性加十年上限 |
| 「兩段式時效的共同特色？」 | 第一段起算點**不固定**（發現、知悉）→ 需要第二段固定上限（§197 亦同） |
| 「§56 撤銷總會決議三個月自何時起算？」 | **決議作成之日**，不是知悉時 |

## 一、兩條對照

| | §90（錯誤） | §93（詐欺／脅迫） |
|---|---|---|
| 起算 | 意思表示時 | 發見詐欺／脅迫終止時 |
| 期間 | 一年 | 一年 |
| 上限 | — | 意思表示後十年 |
| 結構 | 一段式 | 兩段式（兩門檻都要過） |
| 價值 | 法安定性（自己的錯，又會破壞交易安全） | 保護表意人（讓他發現後才算），再用十年守住法安定性 |

## 二、九年半的案例
```
甲 ──意思表示──→ 9 年半後發現被詐欺
發現後一年？→ 但意思表示後十年是上限 → 只剩 6 個月
超過一年【或】超過十年 → 都不能撤
```

## 三、為什麼會有兩段式
```
第一段的起算點不固定：你什麼時候「發現」被騙？隔天、兩年後、一輩子不會
→ 發現才有辦法行使權利 → 從發現起算對表意人才公平
→ 但法律關係不能永遠懸著 → 第二段給一個從意思表示起算的固定上限
§197 侵權同理：知有損害及賠償義務人起二年 ＋ 侵權行為時起十年
```

## 四、老師提醒：背期間不如背起算點
- 大家都背「一年、三年、十年」，但選擇題愛考**從哪一天起算**：§56 從決議作成之日（不是知道有瑕疵時）；§88 從意思表示；§92 從發現、但不逾意思表示後十年。
