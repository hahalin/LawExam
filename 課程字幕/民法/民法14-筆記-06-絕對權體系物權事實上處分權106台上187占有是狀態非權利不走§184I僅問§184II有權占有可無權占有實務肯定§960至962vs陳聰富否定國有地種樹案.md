# 民法14 筆記：§184 I 前段「權利」＝絕對權的體系整理——①**物權**（所有權、其他物權）：具典型公開性，無爭議 ②違章建築之**事實上處分權**：**106 台上 187** 後實務、通說肯定為絕對權（物權法再講，涉 §758、§759）③**占有**：是**狀態**不是權利（事實上管領力）→ **不走 §184 I 前段／後段**，只問是否「違反保護他人之法律」而構成 **§184 II**——**有權占有**被侵害：無爭議 ✓；**無權占有**被侵害：實務**肯定**（§960～962 占有保護不分有權無權，無權占有亦受法律保護之狀態，侵害之即違反保護他人之法律）vs **陳聰富否定**（無權占有僅有 §960～962 之消極保障，無使用收益權能，不應再以侵權行為積極保護其使用收益）；經典案例：甲無權占用國有地種樹、乙偷砍——樹依 §66 II、§766 屬國家，甲無樹之所有權損害；最高法院認甲之（無權）占有受侵害，得依侵權行為（§184 II）請求；學者：無權占有不值得保護，且乙砍樹並未排除甲繼續使用，甲**根本沒有損害**

> 來源：民法14 課程字幕 01:00:00 ~ 01:13:30（講義註 94～96；106 台上 187 待物權法）

## 📖 法條原文速查

> **民法 §66 II**　不動產之出產物，尚未分離者，為該不動產之部分。
> **民法 §766**　物之成分及其天然孳息，於分離後，除法律另有規定外，仍屬於其物之所有人。
> **民法 §940**　對於物有事實上管領之力者，為占有人。
> **民法 §960 I**　占有人，對於侵奪或妨害其占有之行為，得以己力防禦之。
> **民法 §962**　占有人，其占有被侵奪者，得請求返還其占有物；占有被妨害者，得請求除去其妨害；占有有被妨害之虞者，得請求防止其妨害。
> **民法 §952、§953**（善意占有人之使用收益、賠償責任，老師提及，條文請對原文）

## 📋 實務見解速查

> **106 年度台上字第 187 號判決**（講義 57 頁，已核對）：按民法第一百八十四條第一項前段所稱之權利，係指**既存法律體系所明認之權利**。所謂既存法律體系，應兼指法典（包括委任立法之規章）、習慣法、習慣、法理及判例。受讓未辦理所有權第一次登記之建物，受讓人雖因該建物不能為所有權移轉登記，而僅能取得事實上處分權，但該事實上處分權，具**占有、使用、收益、事實上處分及交易等支配權能**，長久以來為司法實務所肯認，亦為社會交易之通念，自屬民法第一百八十四條第一項前段所稱之權利。
> **講義註 94 判決**：民法有關占有規定之保護，於無權源之占有亦有其適用。
> **講義註 96 判決**（國有地種樹案）：無權占有他人土地使用收益者，僅該他人得依法排除侵害，第三人仍無權對其使用收益妄加干涉。例如無權占有他人土地建屋，第三人如將其拆除或遷入居住，乃非法之所許。本件國有土地雖未經管理機關核准上訴人住用，但地上林木係由上訴人種植成長，竟遭被上訴人砍伐出售，上訴人非不得基於侵權行為請求損害賠償。（字號請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§184 I 前段之權利包含哪些？」 | 絕對權：物權（所有權及其他物權）、違建之事實上處分權（106 台上 187 後肯定）、人格權、身分權。**占有不是**（狀態） |
| 「侵害他人占有，得否依 §184 I 前段？」 | **不得**。占有是事實上管領力之**狀態**，非權利 → 不構成 §184 I；只能問是否違反保護他人之法律（§960～962）→ **§184 II** |
| 「有權占有（如承租人之土地占有）被第三人侵害？」 | **得依 §184 II**，無爭議 |
| 「無權占有被侵害，得否依 §184 II？」 | **實務肯定**：§960～962 不分有權無權，無權占有亦受法律保護之狀態，侵害之即違反保護他人之法律。**陳聰富否定**：法律對無權占有只給消極保障（被拿走可以拿回來），無積極保護其使用收益之理；無權占有本無使用收益權能，保護之反破壞占有保護機制 |
| 「甲無權占用國有地種樹，乙偷砍，甲得否對乙請求？」 | 第一步：樹是誰的？§66 II 未分離出產物為土地之部分、§766 分離後仍屬土地所有人（甲、乙皆無收取權）→ 樹是**國家的**，甲無樹之所有權損害。第二步：甲之**占有**被侵害？最高法院：是，無權占有亦受保護 → 依侵權行為（對照前後文應為 §184 II）請求。學者（**陳聰富**，物之損害賠償，月旦法學雜誌 257 期，講義 57 頁註 97）：①無權占有不應受保護 ②乙砍樹並未妨礙甲繼續使用土地（還可以再種）→ 甲**根本無損害**，無請求賠償之必要 |

## 一、絕對權體系圖

```
§184 I 前段「權利」＝絕對權
├ 物權：所有權、其他物權 ✓（典型公開性）
├ 事實上處分權（違建）：106 台上 187 後 ✓（物權法：§758、§759）
├ 人格權 ✓（筆記 07～13）
├ 身分權 ✓
└ 占有 ✗ → 是狀態不是權利 → 只問 §184 II
      ├ 有權占有被侵害 → §184 II ✓
      └ 無權占有被侵害 → 實務 ✓／陳聰富 ✗
```

## 二、國有地種樹案三步

| 步驟 | 內容 |
|---|---|
| ① 甲的損害是什麼？ | 不是樹（樹屬國家：§66 II、§766；甲無權占用、乙偷砍，兩人都無收取權） |
| ② 占有被侵害？ | 最高法院：甲對土地之無權占有受侵害，可依侵權行為（§184 II）請求 |
| ③ 學者批評（陳聰富，註 97） | 無權占有怎會受保護？且本件真的有占有被侵害嗎？沒有不讓甲用、沒有排除甲再種 → 甲沒損害 |
