# 民法21 筆記：非給付型不當得利之類型與§180之排除

## 定義與分類：
- 利益**不是**來自受損人有意識的給予 → 非給付型（講義 309 頁）
- 依發生原因：基於**行為**、基於**法律規定**
- 依類型：**權益侵害型**、**支出費用型**、**求償型**；考試討論以權益侵害型為主

## 支出費用型：多被無因管理吸收：
- 例：甲找工人修好乙家漏水，錢付給工人，乙得到房屋修好的利益 → 甲不是對乙給付 → 非給付型
- 先檢驗無因管理：適法無因管理本身就是**法律上原因**，不成立不當得利
- 無因管理不成立（不適法、不真正無因管理）時，才回到不當得利（見民法20-筆記-10）

## 求償型：先找其他規定：
- 例：甲替乙清償銀行卡債 10 萬，錢付給銀行，乙的債務消滅 → 非給付型
- 優先檢驗：委任（§546）、適法無因管理（§176）、利害關係第三人清償之承受（§312）
- 都不該當才用不當得利，且要記得它屬於**非給付型**

## 非給付型不適用 §180（講義 303 頁判決）：
- 乙無權占有甲的 A 屋並支出裝潢費，之後依 §179 向甲請求
- 甲抗辯：「你無權占有是不法，屬不法原因給付（§180④）」→ **不成立**
- 理由：§180 開頭是「給付」，只適用於給付型；為他人房屋支出費用屬支出費用型，是非給付型

## 非給付型的判斷標準：
- 基於**行為**所生 → **權益歸屬說**：這個利益在法律上應歸屬於誰
- 基於**法律規定**所生 → **法規目的說**：該規定是否要讓當事人**終局保有**利益
- 受利益、受損害、因果關係、無法律上原因，都用同一個標準一併判斷

## 📖 法條原文速查

> **§180**　**給付**，有左列情形之一者，不得請求返還：……四、因不法之原因而為給付者。但不法之原因僅於受領人一方存在時，不在此限。

> **§312**　就債之履行有利害關係之第三人為清償者，於其清償之限度內承受債權人之權利，但不得有害於債權人之利益。

> **§546 I**　受任人因處理委任事務，支出之必要費用，委任人應償還之，並付自支出時起之利息。

> **§176 I**　管理事務，利於本人，並不違反本人明示或可得推知之意思者，管理人為本人支出必要或有益之費用，或負擔債務，或受損害時，得請求本人償還其費用及自支出時起之利息，或清償其所負擔之債務，或賠償其損害。

## 📋 實務見解速查

> **最高法院判決**（講義 303 頁）：不當得利有給付型與非給付型之分，前者係基於受損人有目的、有意識之給付而發生，後者係由於給付以外之行為或法律規定所成立。§180 規定給付有該條各款情形之一者不得請求返還，乃適用於**給付型**不當得利，**不包括非給付型**。本案為無權占有人支出房屋裝潢費用。（字號字幕未唸，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「無權占有人支出裝潢費請求返還，所有人得以 §180④ 拒絕？」 | **否**，§180 不適用於非給付型 |
| 「為他人修繕房屋支出費用，屬何類型？」 | **非給付型**（支出費用型） |
| 「代他人清償債務之求償，應先檢驗？」 | 委任、無因管理、§312 |
| 「適法無因管理之本人受利益，成立不當得利？」 | **否**，無因管理為法律上原因 |
| 「基於法律規定之非給付型不當得利，判斷標準？」 | **法規目的說** |

## 一、非給付型的分類

```
非給付型不當得利
├─ 權益侵害型（討論重點，下一講續）
├─ 支出費用型 → 先看無因管理
└─ 求償型     → 先看委任、無因管理、§312
判準：行為 → 權益歸屬說；法律規定 → 法規目的說
```

## 二、檢驗順序（支出費用、求償）

| 步驟 | 支出費用型 | 求償型 |
|---|---|---|
| 1 | 無因管理（適法即有法律上原因） | 委任 §546、無因管理 §176 |
| 2 | — | §312 承受債權 |
| 3 | 都不成立才用 §179 | 都不成立才用 §179 |
| §180 | 不適用 | 不適用 |
