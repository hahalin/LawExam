# 民法15 筆記：臺北地院否定外遇損害賠償判決

## 判決背景：
- 109 年臺北地院判決在外遇案件採**否定說**：外遇不能請求損害賠償（講義 88 頁起收錄重要段落）
- 時空背景：釋字 **791** 通姦除罪化之後

## 論證三步：
- ①**否定配偶權**：權利＝一方得對他方支配；承認配偶權等於結婚後受另一半支配、把人當權利客體 → **違反人性尊嚴**，不是憲法上的權利；釋字 791 顯示**性自主**之保護大於婚姻忠誠之保障（講義 93～98 頁）
- ②**否定家庭圓滿幸福利益**：幸福抽象、難以定義，每個人對幸福婚姻的圖像不同，不是法官能界定、法律能保護的；若承認，配偶沉迷手遊、社群，也能告遊戲公司、社群媒體公司，荒謬（講義 102 頁）
- ③**指出正確路徑**：不是不讓你告，是告錯條文；婚姻出問題回到婚姻法——依 **§1052** 訴請離婚，搭配 **§1056** 請求損害賠償

## 老師評價：
- 與通說及傳統「保護家庭圓滿」的想像完全不同，但推論縝密、不是沒有道理
- **國考尚未考過**，可能出現在研究所或國考；已有零星地院判決跟進
- 實務現況：以往找徵信社取得證據「百分之百會贏」，現在不敢這樣講

## 📖 法條原文速查

> **民法 §1052**　裁判離婚之事由（I 列舉重婚、與配偶以外之人合意性交等各款；II 有前項以外之重大事由，難以維持婚姻者）。（原文請對六法）

> **民法 §1056 I**　夫妻之一方，因判決離婚而受有損害者，得向有過失之他方，請求賠償。
> **II**　前項情形，雖非財產上之損害，受害人亦得請求賠償相當之金額。但以受害人無過失者為限。

> **民法 §195 III**　前二項規定，於不法侵害他人基於父母、子女或配偶關係之身分法益而情節重大者，準用之。

## 📋 實務見解速查

> **臺灣臺北地方法院 109 年判決**（字號字幕未唸，請對講義 88 頁以下）：要旨依老師整理——①配偶權違反人性尊嚴，非憲法上之權利 ②婚姻共同生活之圓滿、安全及幸福本即抽象且難以定義，如肯認為法律上利益，極為抽象空洞 ③婚姻有問題者應循離婚（§1052）及離婚損害賠償（§1056）途徑。

> **釋字第 791 號**：刑法通姦罪規定違憲而失效（通姦除罪化）。判決援引：性自主之保護大於婚姻忠誠之保障。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「外遇之損害賠償，現行實務是否一致肯定？」 | **否**。通說與多數實務肯定；109 年臺北地院採**否定說**，零星地院跟進 |
| 「否定說如何否定配偶權？」 | 權利含支配性，承認配偶權等於將人當作權利客體 → **違反人性尊嚴**；釋字 791 肯認性自主優先於婚姻忠誠 |
| 「否定說如何否定家庭圓滿幸福之利益？」 | 幸福**抽象難以定義**，非法律所能界定；肯認將導致配偶沉迷電玩也可告遊戲公司之荒謬結果 |
| 「否定說認為受害配偶應如何救濟？」 | 依 **§1052** 訴請離婚，並依 **§1056** 請求損害賠償（含非財產上損害，以受害人無過失為限） |
| 「本判決論證順序？」 | 先否定**配偶權** → 再否定**家庭圓滿幸福利益** → 最後指出**離婚**路徑 |

## 一、論證流程圖

```
乙主張 §184 I 前段（配偶權）
   ✗ 配偶權＝支配他方 → 違反人性尊嚴；釋字 791：性自主 > 婚姻忠誠
        ↓
乙退而主張 §184 I 後段（家庭圓滿安全幸福之利益）
   ✗ 幸福抽象難定義；肯認則手遊、社群公司皆可被告
        ↓
正確路徑：§1052 離婚 ＋ §1056 損害賠償
   「不離婚又說不幸福、還要求償」→ 判決認為矛盾
```

## 二、肯定說與否定說

| | 通說／多數實務 | 109 年臺北地院 |
|---|---|---|
| 配偶權 | 承認（§195 III 身分法益） | 違反人性尊嚴，不承認 |
| 家庭圓滿幸福利益 | 承認（55 年判例） | 抽象空洞，不承認 |
| 外遇第三人 | 負共同侵權責任 | 不負侵權責任 |
| 受害配偶救濟 | §184＋§195 | §1052＋§1056 |
| 核心價值 | 保護婚姻家庭 | 侵權行為沒那麼好用；幸福要自己追求 |

## 三、寫題提示

- 若題目問外遇求償，先寫通說（配偶權或家庭完整法益），再以「另有地院判決採否定說」補充其三步論證，最後表明立場。
- 判決的離婚路徑論點最好用：§1056 II 已提供非財產上損害之救濟，不必透過侵權行為擴張保護。
