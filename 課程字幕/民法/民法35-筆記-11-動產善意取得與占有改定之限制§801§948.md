# 民法35 筆記：動產善意取得與占有改定之限制（§801、§948）

## 為什麼 §801 要配 §948：
- §801 沒把話講完：「受讓人占有動產，**而受關於占有規定之保護**者」→ 取得所有權
- 什麼樣的占有受保護？要進 **§948 I** 看
```
§801：受讓人占有動產 ＋ 其占有受保護 ──→ 縱前手無讓與權利，仍取得所有權
                         ↑
§948 I：①以移轉或設定為目的（法律行為）
        ②善意且無重大過失受讓占有   ──→ 其占有受法律保護
```

## 要件一：依法律行為（法條沒寫，但讀得出來）：
- §948 沒有「法律行為」四個字，不像 §759-1 II 明文
- 但開頭「以動產所有權，或其他物權之**移轉**或**設定**為目的」
  - 抽詞換面：動產所有權接「移轉」，其他物權接「設定」
  - 移轉、設定都需要意思表示 → 就是法律行為
- 801、948 常被當咒語背，要仔細讀條文用語

## 要件二：善意且無重大過失：
- §948 I 但書：受讓人**明知或因重大過失而不知**讓與人無讓與權利 → 不受保護
| | 不動產（§759-1 II） | 動產（§801＋§948） |
|---|---|---|
| 信賴的外觀 | 登記 | 占有 |
| 主觀要件 | 善意（通說：**不問**有無重大過失） | 善意**且無重大過失** |
| 理由 | 登記經地政機關審查，可信度高 | 占有外觀容易取得；水壺上寫別人名字還誤信，不值得保護 |
| 外觀完成 | 完成登記 | 受讓占有 |

## §948 II：以占有改定受讓者（選擇題很愛考）：
- 數字例：
  - 甲把 A 畫借給乙；乙於 **1/8** 將 A 畫賣給善意且無重大過失的丙
  - 畫正在展覽，乙丙以**占有改定**代交付（乙繼續占有，丙取得間接占有）
  - 展覽 **1/31** 結束，乙才把畫現實交付給丙
- 乙不是所有人 → 買賣有效，物權行為是**無權處分**（效力未定）
- 依 §948 II：以占有改定受讓者，須**受現實交付**且**交付時善意**，才受保護
```
1/8 占有改定 ─────── 1/20 ─────── 1/31 現實交付
   ✗ 尚不能善意取得      若此時得知真相 → 惡意      交付時仍善意 → ✓ 取得
                         → 1/31 也不能取得
```
- 常見錯誤選項：
  - 「丙於 1/8 即可主張善意取得」→ **錯**，尚未現實交付
  - 「丙於 1/31 受現實交付，無論如何均取得」→ **錯**，須交付時**仍善意**

## 下一講：

## 📖 法條原文速查

> **§801**　動產之受讓人占有動產，而受**關於占有規定之保護**者，縱讓與人無移轉所有權之權利，受讓人仍取得其所有權。

> **§948**
> I　以動產所有權，或其他物權之**移轉或設定**為目的，而**善意**受讓該動產之占有者，縱其讓與人無讓與之權利，其占有仍受法律之保護。但受讓人明知或因**重大過失**而不知讓與人無讓與之權利者，不在此限。
> II　動產占有之受讓，係依第七百六十一條第二項規定為之者，以受讓人受**現實交付**且**交付時善意**者為限，始受前項規定之保護。

> **§761 II**　讓與動產物權，而讓與人仍繼續占有動產者，讓與人與受讓人間，得訂立契約，使受讓人因此取得間接占有，以代交付。

> **§949 I**　占有物如係**盜贓、遺失物或其他非基於原占有人之意思而喪失其占有**者，原占有人自喪失占有之時起**二年**以內，得向善意受讓之現占有人請求回復其物。→ 下一講，建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§801 所稱受關於占有規定之保護，指何條？」 | **§948 I** |
| 「動產善意取得須受讓人無重大過失？」 | **須**（§948 I 但書）；不動產不須 |
| 「以占有改定受讓，受讓人於占有改定時即善意取得？」 | **否**，須受**現實交付**（§948 II） |
| 「占有改定後、現實交付前得知真相，交付後可善意取得？」 | **不可**，須交付時仍善意 |
| 「§948 雖無『法律行為』文字，仍以法律行為為要件？」 | **是**，「移轉或設定」為目的 |
