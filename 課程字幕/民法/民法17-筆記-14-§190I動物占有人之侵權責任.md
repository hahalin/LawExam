# 民法17 筆記：§190 I 動物占有人之侵權責任

## 舉證責任拆解：
- 原告證明：**動物加損害於他人**（動物侵害行為、權利受侵害、損害、兩者因果關係）＋**被告是動物占有人**
- 被告證明（但書）：已為**相當注意之管束**（推翻過失推定），或縱為相當注意之管束**仍不免發生損害**（推翻因果推定）

## 侵害行為：
- 包含**直接**侵害與**間接**侵害：狗咬傷人是直接；狗追人致摔車受傷是間接
- 實務上嚴重案件多是被狗追而受傷，例：河濱公園野狗追騎機車的老婦人，摔車致腦傷死亡

## 責任主體是「占有人」：
- §190 是動物**占有人**，§191 是工作物**所有人** → 考試把「占有」「所有」圈起來
- 老師講述：§190 的占有人指**直接占有人**與**占有輔助人**，**不含間接占有人**
- 理由：看誰對動物有**事實上管領力**、最可能制止；主人把狗交出去後「天高皇帝遠」，管不到

## 餵養流浪狗：
- 實務傾向：**單純餵養不構成占有**
- 要有進一步互動，例如繫牽繩、關在固定處所，才可能被認定為占有人

## 下堂：
- §190 II 留到下次（禮拜四）講；預計下堂講完侵權行為，接著進無因管理、不當得利

## 📖 法條原文速查

> **§190 I**　動物加損害於他人者，由其**占有人**負損害賠償責任。但依動物之種類及性質已為**相當注意之管束**，或縱為相當注意之管束而**仍不免發生損害**者，不在此限。

> **§191 I 前段**　土地上之建築物或其他工作物所致他人權利之損害，由工作物之**所有人**負賠償責任。

> **§941**（要旨）地上權人、典權人、承租人等，基於類似法律關係對他人之物為占有者，**該他人為間接占有人**。（原文請對六法）

> **§942**（要旨）受僱人、學徒等受他人指示而對物有管領力者，**僅該他人為占有人**。（原文請對六法；老師未唸此條，補列供對照占有輔助人）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§190 責任主體為動物之所有人？」 | **錯**，是**占有人**（§191 才是所有人） |
| 「被狗追逐摔車受傷，是否屬動物加損害於他人？」 | **是**，侵害行為含**間接**侵害 |
| 「寵物交美容店時，主人是否為 §190 占有人？」 | 主人是**間接占有人**，依老師講述**不在** §190 範圍 |
| 「§190 推定什麼？」 | **過失＋因果關係**（但書由占有人證明） |
| 「單純餵養流浪狗者是否為動物占有人？」 | 實務傾向**否**；須有進一步管領（牽繩、圈養） |

## 一、案例：寵物美容店的狗咬傷他犬

#### 事實
1. 甲是 A 犬所有人，把 A 犬送到寵物美容店保養
2. 美容店員工乙替 A 犬洗澡剪指甲時弄痛 A 犬，A 犬失控咬傷顧客丁的 B 犬
3. 不論契約責任，只問丁能依 §190 向誰請求

#### 占有關係（§941、§942）
```
甲（所有人）
 └─ 透過美容店占有 A 犬 → 甲＝間接占有人
      美容店＝直接占有人
        └─ 透過員工乙實現占有 → 乙＝占有輔助人
```

#### 分析
| 對象 | 地位 | §190 |
|---|---|---|
| 甲 | 所有人、間接占有人 | ✗（管不到，不含間接占有） |
| 美容店 | 直接占有人 | ✓ |
| 員工乙 | 占有輔助人 | ✓（老師講述；見下方待確認） |

- 理由：當下實際能制止 A 犬的是美容店與員工，責任應落在有事實上管領力的人

## 二、§190 I 的舉證分配

```
動物加損害於他人  ＋  被告為占有人    →  負損害賠償責任
└────── 原告證明 ──────────────┘       └─ 法律效果 ─┘
但書：已為相當注意之管束 ／ 縱為相當注意仍不免發生
└──────────── 被告（占有人）證明 ─────────────┘
```

| 原告證明 | 被告證明 |
|---|---|
| 動物有侵害行為（直接或間接） | 依動物種類性質已為相當注意之管束（無過失） |
| 權利受侵害、有損害 | 縱為相當注意之管束仍不免發生損害（無因果） |
| 動物侵害行為與損害間之因果 | |
| 被告是動物占有人 | |

## 三、§190 與 §191 對照

| | §190 | §191 |
|---|---|---|
| 客體 | 動物 | 土地上建築物或其他工作物 |
| 責任主體 | **占有人** | **所有人** |
| 推定 | 過失、因果 | 不法（欠缺）、過失、因果 |
