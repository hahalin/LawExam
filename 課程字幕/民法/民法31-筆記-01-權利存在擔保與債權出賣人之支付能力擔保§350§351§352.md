# 民法31 筆記：權利存在擔保與債權出賣人之支付能力擔保（§350、§351、§352）

## 複習：瑕疵擔保的位置：
- 出賣人的給付義務是 §348；違反 → 一般債務不履行
- 瑕疵擔保 §349～§366：權利瑕疵 §349～§353、物之瑕疵 §354 以下
- 兩種瑕疵擔保都是**無過失責任**，不問出賣人有無故意過失
- 權利瑕疵兩型：權利無缺擔保（§349，見民法30-筆記-12）、權利存在擔保（§350）

## 買賣不存在的物 vs. 買賣不存在的權利：
- 邏輯前提：先有**債之關係** → 才有**債務** → 才有**債務不履行**
- 買賣不存在的**物**：
  - 以不能之給付為標的，契約**無效**（§246）
  - 沒有債務，就沒有債務不履行；只剩 §247 **信賴利益**賠償
- 買賣不存在的**權利**：
  - §350 要出賣人擔保權利確係存在，§353 又給債務不履行的效果
  - 若解為契約無效，就會出現「契約無效卻有債務不履行」的矛盾
  - 所以解為契約**有效**，§350 是 §246 的特別規定 → 依 §350、§353 請求債務不履行賠償

## 買受人知情（§351）：
- 買受人**契約成立時知道**權利有瑕疵還買 → 出賣人不負擔保責任，風險自負
- 但書：當事人特約「即使你知道我也負責」（例如保證會除去瑕疵、保證第三人不會來找麻煩）→ 仍要負責
- 老師定位為誠信原則的展現

## 債權出賣人不擔保債務人的支付能力（§352）（選擇題很愛考）：
- 例：甲對乙有 A 債權，甲把 A 債權賣給丙並讓與；後來乙不付錢
  - 債權**不存在** → §350、§353
  - 債權**存在但收不到** → 原則上甲**不負責**（支付能力不是出賣人能控制的）
- 例外：契約另有訂定 → 甲才負責
  - 即使有特約，也只**推定**擔保「**債權移轉時**」乙的支付能力
  - 想擔保未來三年、十年，要明白約定

## §353 再整理（詳見民法30-筆記-11）：
- §353 列「§348 至 §351」，其中 §351 指的是**但書**（特約仍負責）的情形
- 違反 §349、§350 → **法律效果準用**（只借損害賠償、解除契約的效果，維持無過失責任），無爭議
- 違反 §348 → 通說**構成要件準用**（仍須可歸責），否則會架空債務不履行的過失責任設計
- 邱聰智建議修法把 §353 的「348」改成「349」

## 📖 法條原文速查

> **§350**　債權或其他權利之出賣人，應擔保其權利**確係存在**。有價證券之出賣人，並應擔保其證券未因公示催告而宣示無效。

> **§351**　買受人於契約成立時，**知有權利之瑕疵**者，出賣人不負擔保之責。但契約另有訂定者，不在此限。

> **§352**　債權之出賣人，對於債務人之**支付能力**，除契約另有訂定外，**不負擔保責任**。出賣人就債務人之支付能力，負擔保責任者，**推定**其擔保**債權移轉時**債務人之支付能力。

> **§353**　出賣人不履行第三百四十八條至第三百五十一條所定之義務者，買受人得依關於債務不履行之規定，行使其權利。

> **§246 I 本文**　以不能之給付為契約標的者，其契約為**無效**。

> **§247 I**　契約因以不能之給付為標的而無效者，當事人於訂約時知其不能或可得而知者，對於非因過失而信契約為有效致受損害之他方當事人，負賠償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「買賣不存在的物，契約效力？」 | **無效**（§246），只有 §247 信賴利益賠償 |
| 「買賣不存在的債權，契約效力？」 | **有效**，依 §350、§353 負債務不履行責任 |
| 「買受人明知權利瑕疵仍買，出賣人負責？」 | 原則**不負**（§351）；有特約者仍負 |
| 「債權出賣人應否擔保債務人支付能力？」 | 原則**不負**；特約才負（§352） |
| 「有特約擔保支付能力，擔保到何時？」 | **推定**擔保**債權移轉時**的支付能力 |
| 「§353 對違反 §349、§350 如何準用？」 | **法律效果準用**，維持無過失責任 |

## 物與權利的對照

| 比較項目 | 買賣不存在的物 | 買賣不存在的權利 |
|---------|-------------|---------------|
| 契約效力 | 無效（§246） | 有效（§350 為特別規定） |
| 有無債務 | 無 | 有 |
| 責任 | §247 信賴利益 | §350、§353 債務不履行 |
