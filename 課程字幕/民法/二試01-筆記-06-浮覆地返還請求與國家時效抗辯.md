# 民法二試01 筆記：浮覆地返還請求與國家時效抗辯

## 案例（講義 34 頁）：
- 日據時期已登記之土地成為河川，經塗銷登記；79 年浮覆，96 年辦第一次所有權登記為國有
- 原所有人之繼承人依 §828 II、§821、§767 I 中段請求塗銷 → 國家主張時效抗辯

## 爭點：
- 釋字 107、164：**已登記不動產**所有人之 §767 無時效 → 日據時期的登記算不算「已登記」？

## 兩條路徑：
- **最高法院大法庭裁定**：「已登記」須**依我國法**登記；日據登記不算 → 未登記不動產，有時效 → 國家原則得抗辯；但須審查有無**違反誠信原則**（公告、通知等正當程序有無踐行）
- **憲法判決**：論述不在「已登記」解釋，而在 ①國家財產權**無受保障必要**（憲法 §15 保障人民）②本件國家主張時效抗辯**欠缺正當性**（政權更替、資訊不足、遊戲規則國家定、等同未補償徵收）→ 不得主張時效抗辯

## 📖 法條原文速查

> **民法 §767 I**　所有人對於無權占有或侵奪其所有物者，得請求返還之。對於妨害其所有權者，得請求除去之。有妨害其所有權之虞者，得請求防止之。
> **民法 §125**　請求權，因十五年間不行使而消滅。……
> **憲法 §15**　人民之生存權、工作權及財產權，應予保障。

---

## 📋 實務見解速查

> **釋字 107、164**：已登記不動產所有人之回復請求權、除去妨害請求權，無 §125 消滅時效之適用。
> **最高法院民事大法庭裁定**（字號請對講義）：釋字 107、164 所稱已登記不動產，指依我國法登記者；日據時期登記之浮覆地未依我國法登記，其 §767 請求權有時效適用；國家主張時效抗辯有無違反誠信原則，應審酌登記為國有時有無踐行公告、通知等程序。
> **憲法法庭判決**（字號請對講義）：國家就本件浮覆地主張時效抗辯，欠缺正當性，不得為之。
- 民法12 筆記「浮覆地與大法庭裁定」有同一議題的一試整理，可對照。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「繼承人請求塗銷國有登記，國家得否主張時效？」 | 先問有無時效適用 → 釋字 107、164「已登記不動產」之解釋 |
| 「大法庭怎麼解釋？」 | 須依**我國法**登記；日據登記不算 → 有時效 → 但國家抗辯受**誠信原則**審查（公告、通知是否確實） |
| 「憲法判決的理由？」 | 不碰「已登記」；①國家財產權不受憲法 §15 保障 ②本件國家欠缺時效抗辯正當性（政權更替、人民無從得知、國家自訂規則後又抗辯、形同未補償徵收） |
| 「兩條路徑結論差在哪？」 | 大法庭：原則可抗辯，個案以誠信原則調整；憲法判決：本件直接不得抗辯（僅限本件事實） |

## 一、事實時間軸

```
日據時期  A 地已登記（日本法）
          → 成為河川，塗銷登記
38 年後   國民政府；60～88 年間辦理全國土地總登記
79 年     A 地浮覆（處於未登記狀態）
          → 公告、通知；無人補正 → 登記為國有（本件 96 年）
其後      繼承人發現 → §828 II＋§821＋§767 I 中段 請求塗銷
          國家：已逾 15 年，時效抗辯
```

## 二、路徑比較

| | 大法庭裁定（＋最高法院） | 憲法判決 |
|---|---|---|
| 論述重心 | 「已登記不動產」之解釋 | 國家有無主張時效抗辯之正當性 |
| 日據登記 | 不算已登記 → 有時效 | 不處理 |
| 時效抗辯 | 原則可以，誠信原則把關 | 本件不可以 |
