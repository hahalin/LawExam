# 民法物權補充2 筆記：最高限額抵押權之讓與、確定、結算與不準用（§881-4至§881-17）

## 抵押權人的兩個特別權利
- **債權讓與、債務承擔**：原債權確定前，離開範圍就不受擔保（§881-6）
- **抵押權可單獨讓與**：與普通抵押權 §870 不得分離讓與相反
  - 例：甲以 A 地為乙設定最高限額 1,000 萬；乙可切 300 萬讓給丙（乙 700、丙 300 按比例受償），或讓丙成為共有人
  - 甲丙之間沒有「一定法律關係」？由甲丙依 §881-3 **變更擔保範圍**即可
  - 老師說是 §881-7；依條文順序，讓與應為 **§881-8**，且條文要求**經抵押人同意**（建議查證）

## 當事人死亡（§881-11）
- 抵押權人、抵押人或債務人**死亡**，最高限額抵押權**不受影響**
- 但經約定為原債權確定事由者，不在此限

## 先確定，再結算，才實行
- 最高限額抵押權擔保的是一段期間的法律關係，必須先**確定**把範圍固定下來，才能結算、實行
- **約定確定**：
  - 約定確定期日，**不得逾 30 年**（§881-4）
  - 未約定期日，抵押人或抵押權人得**隨時請求確定**（§881-5）
- **法定確定事由**：§881-12（例：約定期日屆至、聲請裁定拍賣抵押物等）

## 確定後的結算規則
- 可請求結算並變更登記為普通抵押權，但不得逾原最高限額（§881-13）
- 確定後發生的債權**不再受擔保**（§881-14）
- 擔保債權的請求權罹於時效後，**5 年**不實行 → 該債權**脫離**擔保範圍（§881-15）；不是整個抵押權消滅
- 第三人塗銷（§881-16）：實際債權額**超過**最高限額時，為債務人設定抵押權的第三人或利害關係人，清償**最高限額**即可請求塗銷；債權額較低就清償債權額
  - 例：最高限額 1,000 萬、債權 1,300 萬 → 清償 1,000 萬即可

## 不準用普通抵押權的規定（§881-17）
| 不準用 | 理由 |
|---|---|
| §861 II（利息限扣押前 5 年） | 已有債權最高限額控制 |
| §869 I（從屬性） | §881-6 特別規定 |
| §870（不得分離讓與） | 最高限額抵押權可讓與 |
| §870-1、§870-2（次序調整） | 避免法律關係過於複雜（立法理由） |
| §880（時效後 5 年抵押權消滅） | §881-15 改為債權脫離 |

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 確定期日上限 | **30 年** |
| 未約定確定期日 | 隨時請求確定 |
| 當事人死亡 | 原則**不影響** |
| 確定後發生之債權 | **不受擔保** |
| 債權罹於時效後 5 年未實行 | 該債權**脫離**擔保範圍 |
| 第三人清償多少可塗銷 | 最高限額或債權額，取低者 |
| 可否為次序讓與、拋棄 | **不準用** §870-1 |

## 流程

```
設定（一定範圍、最高限額）
  ↓ 期日屆至／請求確定／法定事由（§881-4、5、12）
確定 → 之後發生的債權不算（§881-14）
  ↓
結算 → 可變更為普通抵押權（§881-13）
  ↓
實行
```
