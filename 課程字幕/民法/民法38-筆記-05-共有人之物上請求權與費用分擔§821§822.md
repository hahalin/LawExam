# 民法38 筆記：共有人之物上請求權與費用分擔（§821§822）

## §821 的兩個關鍵字：
- 「**各**」：每一個共有人都可以單獨對第三人就共有物**全部**為本於所有權之請求
- 「**僅**」：回復共有物的請求，**僅得為共有人全體之利益**為之

## 請求權基礎怎麼寫：
- 甲乙丙共有 A 地各 1/3，被丁無權占有，甲要丁返還
- 只寫 §767 不對：§767 I 前段是「所有人」，甲只是 1/3 的共有人
- 只寫 §821 也不對：§821 **不是請求權基礎**，而是讓甲取得單獨行使 §767 的**資格**
- 正確：**§767 I 前段＋§821**

## 訴之聲明：
- ✗「丁應返還 A 地予甲」
- ✓「丁應返還 A 地予**全體共有人**」

## 什麼是「本於所有權之請求」：
| 請求 | 能否依 §821 為全體單獨請求 |
|---|---|
| §767 所有物返還、除去、防止妨害 | **可以**，典型 |
| 相鄰關係所生權利（袋地通行、越界建築之請求購買、償金） | 王澤鑑：**可以**，不限於 §767 |
| 債權請求權（如 §179 不當得利） | **不在內**，本於債之關係 |

## 不當得利各自請求：
- 甲向丁請求相當於租金之不當得利 → 依 **§179** 單獨請求**自己 1/3** 即可
- 不能用 §179 搭配 §821 要求丁把全部不當得利返還全體
- 理由：不當得利是錢，大家各自請求，沒有合一確定的必要

## §822 費用分擔（選擇題偶爾出）：
- 管理費及其他負擔：除契約另有約定外，按**應有部分**分擔
- 一人支付超過自己應分擔部分 → 得按其他共有人應分擔部分**請求償還**

```
甲（1/3 共有人）對無權占有人丁
├─ 返還 A 地 → §767 I 前段＋§821 → 返還予全體共有人
└─ 相當於租金之利益 → §179 → 只請求自己 1/3
```

## 📖 法條原文速查

> **§821**（共有人對第三人之權利）
> 各共有人對於第三人，得就共有物之**全部**為**本於所有權之請求**。但回復共有物之請求，**僅得為共有人全體之利益**為之。

> **§767 I**　所有人對於無權占有或侵奪其所有物者，得請求返還之。對於妨害其所有權者，得請求除去之。有妨害其所有權之虞者，得請求防止之。

> **§822**（共有物費用之分擔）
> I 共有物之管理費及其他負擔，除契約另有約定外，應由各共有人按其應有部分分擔之。
> II 共有人中之一人，就共有物之負擔為支付，而逾其所應分擔之部分者，對於其他共有人得按其各應分擔之部分，請求償還。

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「共有人得否單獨請求無權占有人返還共有物？」 | **得**，§767 I 前段＋§821 |
| 「§821 是否為請求權基礎？」 | **否**，是賦予單獨行使 §767 之資格 |
| 「共有人單獨請求返還，應請求返還予誰？」 | **全體共有人** |
| 「本於所有權之請求是否包括債權請求權？」 | **不包括** |
| 「共有人請求相當於租金之不當得利？」 | §179 單獨請求**自己應有部分**範圍 |
| 「共有物管理費如何分擔？」 | 按**應有部分**；溢付者得請求償還（§822） |
