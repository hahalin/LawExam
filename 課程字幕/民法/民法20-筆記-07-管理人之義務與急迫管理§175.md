# 民法20 筆記：管理人之義務與急迫管理（§175）

## 管理人的義務：
- **善良管理人之注意**：無因管理是介入他人事務，要取得正當性就必須好好管；不能「可以介入、又可以隨便處理」
- 違反善管注意致本人受損害 → 適法無因管理是法定之債 → 負**債務不履行**損害賠償責任
- **通知義務**（§173 I）：開始管理時，能通知者應即通知本人；無急迫情事，應俟本人指示
- 準用委任 **§540～§542**（§173 II）：報告管理狀況、交付收取之金錢物品、為自己使用本人金錢應付利息

## 管理過程中造成本人損害：兩條路
- **債務不履行**：看有無違反善良管理人注意義務；破窗救火是善良管理人也會做的事 → 不負責
- **侵權行為**：適法無因管理是**阻卻違法事由**；損害是**管理所必然發生**者（破窗入屋救火）→ 阻卻不法，不成立侵權
- 非管理必然發生的損害 → 不能阻卻，仍可能成立侵權行為（幫人管事不等於可以破壞他人財產）

## §175 急迫管理：
- 要件：為免除本人**生命、身體或財產上之急迫危險**而管理
- 效果：對因管理所生之損害，除有**惡意或重大過失**外，不負賠償責任
- 性質：**不是請求權基礎**，是對上述債務不履行、侵權責任的**特別免責事由**
- 選擇題陷阱：條文寫**惡意**不是**故意** → 急迫下的**故意**行為仍可能免責
- 不適法無因管理也可適用 §175（通說，見民法20-筆記-10）

## 火場砍手案：
- 甲家失火，甲被壓在櫃子下；消防隊未到，乙手邊只有斧頭，砍斷甲的手把甲救出
- ①成立適法無因管理：出發點救人 → 利於本人；甲縱表示不要救，求死意思違反善良風俗
- ②責任：若能先破壞櫃子，砍手可能違反善管注意，也不是管理必然發生之損害 → 原本可能成立 §184、§227
- ③免責：火勢急迫、樑柱掉落，難期待審慎思考 → 乙無惡意，除非有**重大過失**（一般人都想得到其他方法、只有你想不到），依 §175 不負責

## 📖 法條原文速查

> **§173**　I 管理人開始管理時，以能通知為限，應即**通知本人**。如無急迫之情事，應**俟本人之指示**。II 第五百四十條至第五百四十二條關於委任之規定，於無因管理準用之。

> **§175**　管理人為免除本人之生命、身體或財產上之**急迫危險**，而為事務之管理者，對於因其管理所生之損害，除有**惡意或重大過失**者外，不負賠償之責。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「無因管理人之注意義務程度？」 | **善良管理人**之注意 |
| 「破窗入屋救火，本人得依侵權行為請求窗戶損害？」 | **否**，管理必然發生之損害，阻卻違法 |
| 「§175 急迫管理，除故意或重大過失外不負責？」 | **錯**，條文是**惡意**或重大過失 |
| 「§175 得作為請求權基礎？」 | **否**，是免責事由 |
| 「無急迫情事，管理人通知後應？」 | **俟本人之指示**（§173 I） |

## 一、責任檢驗流程

```
管理人造成本人損害
├─ 債務不履行：違反善管注意？ ── 否 → 不負責
│                              └ 是 ↓
├─ 侵權行為：管理必然發生之損害？ ── 是 → 阻卻違法
│                                 └ 否 ↓
└─ 急迫危險？ ── 是 → §175：無惡意或重大過失 → 免責
              └ 否 → 負責
```

## 二、惡意與故意

| | 一般侵權 | 急迫管理 §175 |
|---|---|---|
| 歸責 | 有過失即負責 | 只就惡意、重大過失負責 |
| 故意砍手救人 | 故意 → 負責 | 無惡意 → 可免責 |
