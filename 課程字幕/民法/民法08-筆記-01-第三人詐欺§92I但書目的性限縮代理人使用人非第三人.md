# 民法08 筆記：第三人詐欺 §92 I 但書——表意自由 vs 相對人交易安全；目的性限縮：相對人的代理人、使用人不是「第三人」

> 來源：民法08 課程字幕 00:00:07 ~ 00:07:30

---

## 📖 法條原文速查

> **§92 I**　因被詐欺或被脅迫而為意思表示者，表意人得撤銷其意思表示。但詐欺係由**第三人**所為者，以相對人**明知或可得而知**其事實者為限，始得撤銷之。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「丙詐欺甲，甲因此與乙締約，乙完全不知情，甲得否撤銷？」 | **不得**（§92 I 但書）。相對人乙善意無過失 → 天平倒向乙的交易安全 |
| 「乙明知或可得而知丙之詐欺？」 | **得**撤銷。乙惡意或有過失 → 無保護必要 → 天平倒向甲的表意自由 |
| 「丙是乙車商的**銷售業務**，向甲隱瞞 A 車為事故車，乙本人不知情，甲得否撤銷？」 | **得**。通說對 §92 I 但書**目的性限縮**：相對人用以締約的**代理人、使用人（履行輔助人）**不是「第三人」→ 回到 §92 I 本文 → 不問乙知情與否 |
| 「理由？」 | 乙藉由丙擴大活動範圍並獲利 → 丙是乙派來的 → 丙詐欺的風險由乙承擔比由甲承擔合理 → 乙無保護必要 |
| 「相對人自己詐欺？」 | §92 I 本文，隨時可撤，相對人無保護必要 |

---

## 一、§92 I 但書在衡量什麼
```
丙（第三人）詐欺甲 → 甲與乙締約
甲：表意自由要保護　　乙：什麼都沒做、不是詐欺行為人 → 交易安全要保護
→ 乙不知情 → 倒向乙 → 甲不能撤
→ 乙明知或可得而知（惡意，或善意但有過失）→ 倒向甲 → 甲可以撤
```

## 二、最常考的案例：業務員詐欺
```
乙＝車商，丙＝乙的銷售業務
丙對甲說 A 車是原廠件、無事故（其實是事故車修過）→ 甲向乙買
乙本人完全不知情
文義：丙是第三人、乙不知 → 甲不能撤？
```

### 目的性限縮
```
但書的目的：乙有被保護必要時，限制甲的撤銷權
丙是乙的業務 → 乙藉由丙擴大活動範圍、獲取利益 → 「那是你派來的人」
→ 讓乙承擔丙詐欺的風險，比讓甲承擔更合理 → 乙沒有被保護的必要
→ 「第三人」在解釋上不包括相對人用以締約的代理人、使用人（履行輔助人）
→ 排除但書，回歸 §92 I 本文 → 甲可以撤，不管乙知不知情
```
- 老師：這題選擇題大約每兩年出現一次，看到「第三人詐欺」先確認那個第三人跟相對人是什麼關係。
