# 民法07 筆記：誤載無害真意——單純寫錯不是意思表示錯誤，更正即可，不必依 §88 撤銷

> 來源：民法07 課程字幕 00:27:14 ~ 00:30:47
> 字幕聽寫為「物權無害爭議」「誤載無害爭議」，正確用語是「**誤載無害真意**」（falsa demonstratio non nocet）

---

## 📖 法條原文速查

> **§88 I**　意思表示之內容有錯誤，或表意人若知其事情即不為意思表示者，表意人得將其意思表示撤銷之。但以其錯誤或不知事情，非由表意人自己之過失者為限。
> **§98**　解釋意思表示，應探求當事人之真意，不得拘泥於所用之辭句。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲乙口頭約定蛋黃酥 50 顆共 5,000 元，乙開立之收據誤載為 500 元，價金為何？」 | **5,000 元**。雙方意思表示合致於 5,000，收據只是誤載 → **誤載無害真意** → 更正即可，**不是 §88 的問題** |
| 「表示行為錯誤須無過失始得撤銷，乙寫錯有過失，故價金為 500 元？」 | **錯**。意思表示在締約時就完成且無錯誤，收據不是意思表示 |
| 「誤載無害真意之定位？」 | 意思表示**根本沒有錯誤**，§88 以下（意思表示瑕疵）無從適用；屬 §98 解釋真意的範疇 |

---

## 一、案例
```
甲向乙訂蛋黃酥 50 顆，一顆 100 元，講好總價 5,000，兩週後取貨
乙事後開的收據寫「蛋黃酥 50 顆，總價 500 元」（少一個零）
```

## 二、常見的錯誤推論
```
✗「這是表示行為錯誤 → 須無過失才能撤銷 → 乙寫錯有過失 → 不能撤銷 → 價金變 500」
問題：意思表示在哪裡？
    → 在雙方【締約】那一刻：甲說 5,000 買、乙說 5,000 賣 → 意思表示合致、沒有任何錯誤
    → 收據不是意思表示，只是事後的記載
```

## 三、正解
```
意思表示沒有錯誤 → 根本不進 §86～§93 瑕疵體系 → 不需要撤銷
單純誤載、不影響意思表示的真意 → 更正即可（§98 探求真意）
```
- 一試超愛考：看到「寫錯」就想撤銷，先問**意思表示本身有沒有錯**。
