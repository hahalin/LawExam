# 民法11 筆記：§110 的消滅時效——56 年判例（講義 273 頁註 24）一次講三件事：無權代理人負無過失責任（原因責任／結果責任）、時效依 §125 十五年而非 §197、相對人善意即足；學說：§110 不寫時效是「故意留白」，應依原權利之時效定之（租金 §126 五年、價金 §125 十五年）

> 來源：民法11 課程字幕 00:00:02 ~ 00:09:25（接民法10 筆記 14 的爭點 ④）

---

## 📖 法條原文速查

> **§110**　無代理權人，以他人之代理人名義所為之法律行為，對於善意之相對人，負損害賠償之責。
> **§125**　請求權，因十五年間不行使而消滅。但法律所定期間較短者，依其規定。
> **§126**　利息、紅利、租金、贍養費、退職金及其他一年或不及一年之定期給付債權，其各期給付請求權，因五年間不行使而消滅。
> **§197 I**　因侵權行為所生之損害賠償請求權，自請求權人知有損害及賠償義務人時起，二年間不行使而消滅；自有侵權行為時起，逾十年者亦同。

---

## 📋 實務見解速查

> **最高法院 56 年台上字判例**（講義 273 頁註 24，字號請對講義）：無權代理人之責任，其法律上根據如何，見解不一，而通說係直接基於民法之規定而發生之特別責任，並不以無權代理人有故意或過失為其要件，係屬於所謂原因責任、結果責任或無過失責任之一種，而非基於侵權行為之損害賠償。故無權代理人縱使證明其無故意或過失，亦無從免責。是項請求權之消滅時效，在民法既無特別規定，則以民法第 125 條所定十五年期間內應得行使，要無民法第 197 條短期時效之適用。……上訴人既未能證明被上訴人知其實無代理權，則被上訴人縱因過失而不知，仍得請求損害賠償。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§110 之責任性質？」 | 直接依民法規定發生之**特別責任**，不以故意過失為要件（原因責任、結果責任、無過失責任），**非侵權行為**責任 |
| 「無權代理人證明自己無過失，得否免責？」 | **不得** |
| 「§110 之時效？」 | 實務：民法無特別規定 → **§125 十五年**；非侵權行為 → **無 §197 二年／十年**之適用 |
| 「相對人因過失而不知乙無代理權，得否依 §110 求償？」 | **得**。善意即足，不以無過失為要件 |
| 「學說對十五年的批評？」 | §110 是**類似契約的補充責任**，只填補「因無權代理而無法享受法律行為效果」的損失，效力不應超過原契約 → 時效應**依原權利而定**：租金請求權 §126 五年 → 損害賠償也五年；價金請求權 §367 十五年 → 十五年。§110 不寫時效是立法者**故意留白**，不是忘記寫 |

## 一、56 年判例講的三件事

| 爭點 | 判例立場 |
|---|---|
| 無權代理人故意過失 | 不要。無過失責任，縱證明無過失亦不免責 |
| 時效 | §125 十五年；不是侵權，無 §197 |
| 相對人主觀 | 善意即足，有過失仍可求償 |

## 二、時效的學說批評：補充包不能比原本那包大

```
乙無權代理甲向丙承租 A 屋（甲說我只是心裡規劃，根本沒要租）
甲拒絕承認 → §170 不生效力 → 丙對乙 §110
若租約有效：丙對甲的租金請求權 §126 五年
租約不生效：丙對乙的損害賠償 §125 十五年？
→ 契約有效只有五年、契約無效反而十五年 → 不合理
→ §110 是補充責任，填補原本沒享受到的契約利益，不會讓你拿得更多（備胎不會比原胎大）
→ 依原權利定：買賣價金 §367 十五年；租金、承攬報酬等短期時效 → 回歸短期
```

- 「法律沒寫」有兩種：真的沒寫（回 §125）、故意不寫（另有概念可用）。學者認為 §110 是後者。
