# 民法11 筆記：無權代理 vs 無權處分比較表（選擇題最愛）——當事人（甲丙 vs 乙丙）、效力（債權物權皆效力未定 vs 僅物權行為效力未定）、保護機制（§107／§169／§170／§110 vs §801＋§948／§759-1 II）、主觀要件門檻（§107 §169 善意無過失／§801 §948 善意無重大過失／§759-1 II §110 善意即可）；信賴對象不同：代理外觀 vs 公示外觀 → 無權代理不能善意取得

> 來源：民法11 課程字幕 01:18:00 ~ 01:25:40（與民法10 筆記 13 第四段合看）

---

## 📖 法條原文速查

> **§103 I**　代理人於代理權限內，以本人名義所為之意思表示，直接對本人發生效力。
> **§118 I**　無權利人就權利標的物所為之處分，經有權利人之承認始生效力。
> **§170 I**　無代理權人以代理人之名義所為之法律行為，非經本人承認，對於本人不生效力。
> **§943 I**　占有人於占有物上行使之權利，推定其適法有此權利。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「乙用誰的名義？」 | 無權代理：**本人甲**之名義。無權處分：**自己**名義 |
| 「法律行為當事人？」 | 無權代理：**甲丙**（效力直接及於本人）。無權處分：**乙丙** |
| 「效力？」 | 無權代理：債權行為、物權行為**都**效力未定（§170）。無權處分：買賣契約**不受影響**，只有物權行為（動產、不動產皆同）效力未定（§118） |
| 「善意第三人保護機制？」 | 無權處分：善意取得（§801＋§948；§759-1 II）。無權代理：§107／§169（授權人責任）、§170（催告撤回）、§110（損害賠償）|
| 「主觀門檻？」 | §801＋§948：善意且無**重大**過失。§759-1 II：善意即可（信賴登記外觀就保護）。§107／§169：善意且**無過失**（一點過失都不行）。§110：善意即可 |
| 「無權代理，善意無過失之相對人得依善意取得規定取得權利？」 | **錯**（最常出現的錯誤選項）。善意取得保護的是對**公示外觀**（占有、登記）的信賴；無權代理中乙說「這是甲的車」，丙信賴的是**代理外觀** → 保護機制是 §107／§169，不是善意取得 |

## 一、比較表

| | 無權代理 | 無權處分 |
|---|---|---|
| 乙的名義 | 本人甲 | 自己 |
| 法律行為當事人 | 甲丙 | 乙丙 |
| 債權行為 | 效力未定 | 有效 |
| 物權行為 | 效力未定 | 效力未定 |
| 本人之權利 | 承認／拒絕（§170） | 承認／拒絕（§118） |
| 善意第三人保護 | §107、§169 授權人責任；§170 II 催告、§171 撤回；§110 損害賠償 | §801＋§948、§759-1 II 善意取得 |
| 丙信賴的是 | 乙有**代理權**（代理外觀） | 乙有**處分權**（占有 §943、登記的公示外觀） |

## 二、主觀要件門檻一覽

| 條文 | 門檻 |
|---|---|
| §107、§169 | 善意且無過失 |
| §801＋§948 | 善意且無重大過失 |
| §759-1 II | 善意 |
| §110 | 善意 |

## 三、為什麼無權代理不能善意取得

```
無權處分：乙占有 A 車、以自己名義賣 → 丙相信「乙是所有人」→ 公示原則保護這種信賴 → 善意受讓
無權代理：乙占有 A 車，但說「這是甲的車，我是甲的代理人」→ 丙不會相信車是乙的，最多相信乙有代理權
         → 沒有信賴公示外觀 → 信賴的是代理外觀 → 保護機制是 §107／§169（甲創造外觀就負授權人責任）
         → 甲無可歸責事由時，退而求其次 §110 向乙求償
```

- 選擇題標準錯誤選項：「無權代理時，善意無過失之相對人得依善意取得之規定取得權利」——講得很順，觀念完全錯。
