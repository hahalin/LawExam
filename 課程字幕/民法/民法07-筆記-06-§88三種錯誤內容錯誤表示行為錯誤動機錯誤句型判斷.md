# 民法07 筆記：§88 的三種錯誤——內容錯誤、表示行為錯誤可撤銷，動機錯誤不可；用句型判斷

> 來源：民法07 課程字幕 00:41:16 ~ 00:51:20

---

## 📖 法條原文速查

> **§88**（錯誤之意思表示）
> I 意思表示之**內容有錯誤**，或表意人**若知其事情即不為意思表示**者，表意人得將其意思表示撤銷之。但以其錯誤或不知事情，非由表意人自己之過失者為限。
> II 當事人之資格或物之性質，若交易上認為重要者，其錯誤，視為意思表示內容之錯誤。

> **§89**（傳達錯誤）意思表示，因傳達人或傳達機關傳達不實者，得比照前條之規定撤銷之。
> **§90**　前二條之撤銷權，自意思表示後，經過一年而消滅。
> **§91**　依第八十八條及第八十九條之規定撤銷意思表示時，表意人對於信其意思表示為有效而受損害之相對人或第三人，應負賠償責任。但其撤銷之原因，受害人明知或可得而知者，不在此限。

---

## 📋 實務見解速查

> 最高法院 51 年台上字、43 年台上字判例（講義 167 頁註 83，字號請對講義）：§88 所謂錯誤，指**意思表示之內容或表示行為**有錯誤者而言，與為意思表示之**動機有錯誤**之情形有別。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§88 I 前段『內容有錯誤』？」 | **內容錯誤**：腦子裡就搞錯——誤甲為乙（當事人）、誤 A 車為 B 車（標的）、誤買賣為贈與（法律行為性質）。句型「**誤 A 為 B**」 |
| 「§88 I 前段『若知其事情即不為意思表示』？」 | **表示行為錯誤**：腦子裡沒錯，做的時候出錯——寫錯、拿錯、說錯。句型「**誤＋動詞**」 |
| 「為求婚購買鑽戒，始知女友已婚，得否撤銷？」 | **動機錯誤**，§88 無此類型 → **不得撤銷**（最高法院判例）。句型「**誤以為**」 |
| 「§88 的要件？」 | ① 意思表示錯誤（屬可撤銷的類型）② 重要（有爭議）③ 表意人無過失 ④ 未逾一年除斥期間（§90）→ 效果：撤銷＋ §91 信賴利益賠償 |

## 一、體系

```
§88 I 第一句：內容錯誤
§88 I 第二句：表示行為錯誤          } 可撤銷
§88 II：重要的動機錯誤（視為內容錯誤）
§89：傳達錯誤                        }
──────────────────────────
一般動機錯誤：§88 沒有這個類型 → 不可撤銷
```

## 二、三種錯誤怎麼分：看它錯在哪個階段

```
動機 ──→ 意思（腦子裡的內容）──→ 表示（表現出來）
  ↑              ↑                    ↑
動機錯誤      內容錯誤            表示行為錯誤
```

| 類型 | 錯在哪 | 例 | 題目句型 | §88？ |
|------|------|-----|------|------|
| 內容錯誤 | 腦子裡的內容就是錯的 | 想買 A 卻以為 B 就是 A；誤某甲為某乙；誤買賣為贈與 | 「誤 A 為 B」 | ✓ 可撤銷 |
| 表示行為錯誤 | 腦子沒錯，動作出錯 | 想買 A 顯示卡，拿貨時拿成 B；想寫 5,000 寫成 500 | 「誤＋動詞」（寫錯、拿錯、說錯） | ✓ 可撤銷 |
| 動機錯誤 | 形成意思之前的理由錯了 | 誤以為土地會漲而買；為求婚買鑽戒 | 「誤以為……」 | ✗（§88 II 重要者例外） |

- 句型只是粗略判斷，有的老師會寫「誤以為 A 車為 B 車」，那還是內容錯誤。看劇情：是搞錯了、拿錯了、還是出發點的理由錯了。
- 內容錯誤涵蓋法律行為三要素（當事人、標的、內容）在意思形成過程中的任何一個出錯。

## 三、為什麼動機錯誤不能撤銷
```
動機藏在內心深處，不是交易的要素
    買鹹酥雞不用跟老闆說為什麼（「肚子餓」「我爽」）
    只要把標的講清楚就好：100 元、切、不要辣
→ 不重要的東西出錯 → 不能影響契約效力 → §88 沒有列這個類型
→ 最高法院判例：動機錯誤與 §88 之錯誤有別
```
- 鑽戒例：為求婚買鑽戒，求婚時才發現女友早已結婚 → 不能退（除非店家有「求婚失敗條款」約定九折收回——那是契約，不是 §88）。
