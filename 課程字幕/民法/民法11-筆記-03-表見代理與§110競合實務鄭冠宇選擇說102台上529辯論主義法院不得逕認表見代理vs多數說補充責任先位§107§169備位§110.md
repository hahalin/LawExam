# 民法11 筆記：表見代理要件該當時，相對人得否跳過 §107／§169 直接依 §110 向無權代理人求償——實務與鄭冠宇：選擇說（二選一由丙決定；102 台上 529：辯論主義，丙未主張表見代理，法院不得逕將授權人責任效果歸於丙）vs 多數學說：§110 是補充責任，先位 §107／§169 無理由才備位 §110

> 來源：民法11 課程字幕 00:27:04 ~ 00:35:07（講義 277 頁底下）

---

## 📋 實務見解速查

> **最高法院 102 年度台上字第 529 號判決**（講義 277 頁，字號照字幕）：民事訴訟採辯論主義，除法律別有規定外，不得斟酌當事人所未提出之事實，此為辯論主義之當然結果；法院如就當事人未主張之事實依職權斟酌，即有擅作主張之違法。又由自己之行為表示以代理權授與他人，對於第三人因而負授權人責任者，必須本人有表見之事實，使第三人相信該他人有代理權之情形存在，且必須第三人基於此項表見之事實，**主張**本人應負授權人之責任；如第三人不為此項主張，法院不得逕將法律上之效果歸屬於第三人。關於民法第 169 條前段表見代理之事實，須待當事人主張後，法院始得斟酌，非得由法院任意為當事人主張其效果。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲將身分證印章交乙保管，乙無權代理甲與善意無過失之丙訂約；甲未承認。丙不欲維持契約，得否直接依 §110 向乙請求損害賠償？」 | **實務、鄭冠宇：得**（選擇說）。§107／§169 與 §110 是**二選一**，由丙選擇要甲負責還是要乙賠償，表見代理也是廣義無權代理，符合要件即可。**多數學說：不得**（補充責任說）。§110 補充的是契約無效之損失；契約若能依表見代理對甲生效，丙就沒有損害 → 應先主張 §107／§169，無理由再依 §110 |
| 「法院得否依職權認定表見代理而駁回丙對乙之 §110 請求？」 | **不得**（102 台上 529）。二審認丙可對甲主張 §107／§169 故無損害，判丙對乙請求無理由 → 最高法院：要不要主張表見代理是丙的自由，丙未主張法院不得斟酌，應當作無權代理處理 |
| 「鄭冠宇對多數說之批評？」 | ① 強迫丙多打一次訴訟、承擔多餘訴訟成本（誰知道主張 §107／§169 一定會贏）② 從 §110 要件看不出必須先主張 §107／§169 |

## 一、題型

```
乙無權代理甲與丙訂約（買 A 畫）
甲有可歸責事由（身分證印章交乙保管）、丙善意且無過失 → 表見代理要件該當
甲還沒承認；丙發現畫是傳家之寶，不想要了
丙：我不要甲負責（那會讓契約有效），我直接撤回（§171）然後對乙 §110 求償，可以嗎？
```

## 二、兩說

| | 選擇說 | 補充責任說 |
|---|---|---|
| 採者 | 實務（102 台上 529）、鄭冠宇 | 多數學者 |
| 理由 | §107／§169 與 §110 二選一，由丙選；廣義無權代理也是無權代理，符合要件即可 | §110 補充「契約無效而無法享受契約利益」的損失；甲若能負責，丙就沒有損害，乙的賠償責任以甲不負責為前提 → 先位 §107／§169，備位 §110 |
| 批評 | — | 強迫丙多一次訴訟成本；法條要件看不出先後 |

## 三、102 台上 529 的審級脈絡

```
二審：丙明明可以對甲主張 §107／§169 → 丙沒有損害 → 丙對乙 §110 無理由
最高法院：辯論主義；表見代理須當事人主張，法院不得職權斟酌 → 丙沒主張就當無權代理，讓丙對乙求償
```

- 與民法10 筆記 09（102 台上 1778 前段「表見代理須當事人主張」）同一思路。
