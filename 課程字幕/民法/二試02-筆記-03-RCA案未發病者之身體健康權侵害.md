# 民法二試02 筆記：RCA 案未發病者之身體健康權侵害

## 案例（講義 93 頁）：
- 美商 RCA 70～92 年在桃園廠區使用有毒溶劑（三氯乙烯）並排放地下，污染土壤與地下水
- A 類（死亡）、B 類（罹病）請求沒問題；**C 類：有接觸、未發病** → 能否請求？
- 爭點：§184 I 前段「權利」——身體權、健康權的內涵

## 訴訟經過：
- 二審：**微觀損害**（細胞層次已受影響，如無症狀帶原）＋心理健康 → 肯定
- 最高法院：微觀損害無法證明 → 發回
- 更一審：無微觀損害，心理健康多屬臆測 → 否定
- **110 年度台上字第 50 號**：不用微觀損害；擴大身體權、健康權內涵 → 肯定

## 110 台上 50 的兩個擴張：
- 身體權＝身體**完整性**＋身體**自主性**：未經同意＋有害物質進入人體＋逾越客觀容忍程度 → 侵害身體自主性，不以發病為必要
- 健康權含**心理健康**：精神安寧、情緒；衡量發生場所、頻率、範圍、客觀嚴重性，排除日常輕微侵害

## 📖 法條原文速查

> **民法 §184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。
> **民法 §195 I**　不法侵害他人之身體、健康……被害人雖非財產上之損害，亦得請求賠償相當之金額。

---

## 📋 實務見解速查

> **最高法院 110 年度台上字第 50 號判決**（講義 96 頁畫線處）：所稱身體，指人體之完整，為人格之基礎；為維護主體性及人格自由發展，身體之完整性除身軀器官之完整外，尚包括身體之自主性，以未得他人同意之方法，使有害人體之物質進入人體內，逾越一般人客觀上所能容忍之程度，自屬對身體自主性之侵害；健康權以保持內部機能完全為內容，包含生理及心理，精神安寧或情緒等影響心理健康之因素亦應納入保護，惟須衡量損害事故發生場所、頻率、影響範圍及客觀嚴重性等，排除社會通念上日常生活常見之輕微侵害。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「接觸有毒溶劑但未發病之員工得否請求賠償？」 | §184 I 前段；爭點在身體權、健康權是否以發病為必要 |
| 「微觀損害說的問題？」 | 被害人難以證明細胞受多少影響（最高法院因此發回） |
| 「110 台上 50 的解釋？」 | 身體權含**自主性**（三要件：未同意、有害物質入體、逾越容忍）；健康權含**心理健康**（情節重大） |
| 「肯否兩說都有理，怎麼收尾？」 | 陳忠五三面向：①加害人行為自由有無保護必要 ②被害人權益保障 ③社會公益（勞動安全） |

---

## 一、陳忠五的三面向收尾法（侵權題通用）

| 面向 | 本題 |
|---|---|
| 加害人 | 否定說等於鼓勵：劑量抓準、不發病就不用賠 → 使用有毒溶劑的行為自由無保護必要 |
| 被害人 | 疾病有潛伏期；提前取得賠償可用於將來治療與精神慰撫 |
| 社會 | 勞動安全：先賠再說，可遏止業者使用有害物質 |

→ 採肯定說（不論以微觀損害或身體自主權肯定都可以）。
