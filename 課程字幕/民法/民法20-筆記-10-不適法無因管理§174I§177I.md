# 民法20 筆記：不適法無因管理（§174I、§177I）

## 要件：只差一點：
- 未受委任、並無義務、為他人管理事務 → 與適法無因管理相同
- 差在：管理事務之**承擔**不利於本人，或**違反本人明示或可得推知之意思**
- 效果上最大差別：**不發生法定之債** → 沒有善良管理人注意義務 → 沒有債務不履行

## 本人受損害：
- **§174 I**：違反本人意思而管理，對因管理所生之損害，**雖無過失**亦應負賠償責任 → 比侵權行為好用
- **§184**：不適法無因管理沒有阻卻違法效果，管理人有過失即可主張，與 §174 I 不互斥
- **§175 能否適用？** 通說**肯定**：急迫時根本無從判斷本人意思（火是本人自己放的，你看到火災只會想到救火），適法與否都只就惡意或重大過失負責

## 本人受利益：
- 客觀上仍可能有好處（你幫我修好漏水，但我不要）
- **本人願享受利益**（§177 I）：
  - 享受因管理所得之利益 → 不生不當得利
  - 但負 §176 I 之義務（償還費用、清償債務、賠償損害），**以所得利益為限**
- **本人不願享受利益**：
  - 不負 §176 I 義務
  - 仍可能成立不當得利 → 以**強迫得利**緩和：能原樣返還就返還；不能返還，對本人而言價值為**零元**
  - 例：便當被硬加一顆滷蛋 → 夾起來還你；漏水被修好 → 無法原樣返還 → 返還 0 元
  - 強迫得利細節在不當得利再講

## 📖 法條原文速查

> **§174 I**　管理人違反本人明示或可得推知之意思，而為事務之管理者，對於因其管理所生之損害，**雖無過失，亦應負賠償之責**。

> **§177 I**　管理事務不合於前條之規定時，本人仍得**享有因管理所得之利益**，而本人所負前條第一項對於管理人之義務，**以其所得之利益為限**。

> **§175**　管理人為免除本人之生命、身體或財產上之急迫危險，而為事務之管理者，對於因其管理所生之損害，除有惡意或重大過失者外，不負賠償之責。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「不適法無因管理之管理人，本人得依債務不履行請求？」 | **否**，無法定之債 |
| 「違反本人意思管理，須有過失始負賠償責任？」 | **錯**，§174 I **無過失**責任 |
| 「不適法無因管理得否適用 §175？」 | 通說**肯定** |
| 「本人主張享受利益，對管理人之償還義務範圍？」 | **以所得利益為限**（§177 I） |
| 「本人不願享受且無法原物返還之利益？」 | 強迫得利：價值為**零** |

## 一、適法與不適法對照

| | 適法 | 不適法 |
|---|---|---|
| 法定之債 | ✓ | ✗ |
| 本人受損 | §227（善管注意）、§184（必然損害阻卻違法） | §174 I 無過失責任、§184 |
| §175 | ✓ | ✓（通說） |
| 管理人請求 | §176 I 全部 | 本人享受利益時，以利益為限 |
| 不當得利 | ✗（有法律上原因） | 可能成立 → 強迫得利 |

## 二、本人受利益時

```
不適法無因管理，本人得利
├─ 願享受（§177 I）
│   └─ 負 §176 I 義務，以所得利益為限；無不當得利
└─ 不願享受
    └─ 不當得利 → 強迫得利
        ├─ 能原樣返還 → 返還（滷蛋）
        └─ 不能返還 → 價值 0 元（修漏水）
```
