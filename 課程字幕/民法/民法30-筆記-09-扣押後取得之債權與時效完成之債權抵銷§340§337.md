# 民法30 筆記：扣押後取得之債權與時效完成之債權抵銷（§340、§337）

## 扣押後取得之債權不得抵銷（§340）：
- 要用強制執行的角度看：例如對薪資債權的扣押（老師稱支付轉給命令，薪水每月扣一部分給債權人）
- 案例：
  - 甲對乙有 A 債權 100 萬元
  - 乙在丙公司上班，乙對丙有 B 債權（薪資，月薪 6 萬元）
  - 甲聲請扣押 B 債權，丙是「受債權扣押命令之第三債務人」
  - 丙對乙另有 C 債權
- 丙能否以 C 抵銷被扣押的 B？
  - C 在**扣押前**已存在 → **可以**抵銷
  - C 在**扣押後**才取得 → **不可以**抵銷
- 理由：避免第三債務人在扣押後才取得債權，架空扣押效力
- 選擇題比較常考，申論題較少

## 時效完成之債權仍得抵銷（§337）：
- 罹於時效的債權**沒有消滅**，只是不能請求（債務人取得拒絕給付的抗辯）
- 只要在**時效完成前已適於抵銷**，時效完成後**仍得抵銷**
- 時效完成前就不具備抵銷要件 → 時效完成後不能抵銷

## 老師處理過的案例（車禍與保險代位）：
- 110 年 5 月 10 日甲乙車禍：甲（汽車，保險較多）車損；乙（機車）車損與輕傷
- 雙方在警察局做完筆錄後口頭說好互不求償，但**沒有簽和解契約**
- 甲向保險公司申請理賠；保險公司依保險法 §53 **保險代位**，在 112 年 5 月 8 日起訴乙（兩年時效將屆）
- 乙收到訴狀時已是 112 年 5 月 20 日，乙對甲的 §184 請求權已罹於時效（兩年，§197 I）
- 處理方式：
  - 主張和解：口頭、無證人，舉證失敗
  - 主張**抵銷**：乙對甲的請求權在時效完成前已適於抵銷 → 依 §337 仍可抵銷；整理修車單據、醫藥費計算
  - 未起訴的慰撫金依現行實務也可抵銷（見民法30-筆記-07）
- 結果：保險公司原本請求約 30 萬元，最後以 3 萬元調解成立
- 提醒：罹於時效的債權仍然存在，**抵銷抗辯**還很好用

## 📖 法條原文速查

> **§340**　受債權扣押命令之第三債務人，於**扣押後**，始對其債權人取得債權者，**不得**以其所取得之債權與受扣押之債權為抵銷。

> **§337**　債之請求權雖經時效而消滅，如在**時效未完成前**，其債務已**適於抵銷**者，亦得為抵銷。

> **§197 I**　因侵權行為所生之損害賠償請求權，自請求權人知有損害及賠償義務人時起，**二年**間不行使而消滅。自有侵權行為時起，逾十年者亦同。

> **保險法 §53 I**　被保險人因保險人應負保險責任之損失發生，而對於第三人有損失賠償請求權者，保險人得於給付賠償金額後，代位行使被保險人對於第三人之請求權；但其所請求之數額，以不逾賠償金額為限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「第三債務人於扣押前已取得之債權，可否抵銷？」 | **可以** |
| 「第三債務人於扣押後始取得之債權，可否抵銷？」 | **不可以**（§340） |
| 「罹於時效之債權可否作為主動債權抵銷？」 | 時效完成前已適於抵銷者，**可以**（§337） |
| 「時效完成前尚未適於抵銷？」 | 時效完成後**不得**抵銷 |
| 「罹於時效之債權是否消滅？」 | **不消滅**，債務人只取得抗辯權 |

## §340 判斷圖

```
甲 ──A 債權──→ 乙 ──B 債權（薪資）──→ 丙公司
                ↑                    │
                └──── C 債權 ─────────┘
甲扣押 B，丙是第三債務人
├── C 在扣押前已存在 → 丙得以 C 抵銷 B
└── C 在扣押後才取得 → 丙不得抵銷（§340）
```

## §337 時間軸

```
110/5/10 車禍 ── 乙對甲 §184 請求權發生，已適於抵銷
112/5/8  保險公司代位起訴乙
112/5/10 乙之請求權時效完成
112/5/20 乙收到訴狀 → 不能請求，但依 §337 仍得抵銷
```
