# 民法09 筆記：§118 II、III——占有改定下不能善意取得（§948 II）；無權處分人事後取得權利，處分自始有效、數處分牴觸以最初為有效（惡意的丙反而拿到）；II 但書：原權利人已取得之利益不受影響

> 來源：民法09 課程字幕 01:46:33 ~ 02:01:00（約 100 年律師一試考題）

---

## 📖 法條原文速查

> **§118 II**　無權利人就權利標的物為處分後，取得其權利者，其處分**自始有效**。但原權利人或第三人已取得之利益，不因此而受影響。
> **§118 III**　前項情形，若數處分相牴觸時，以其**最初之處分**為有效。
> **§761 II**（占有改定）讓與動產物權，而讓與人仍繼續占有動產者，讓與人與受讓人間，得訂立契約，使受讓人因此取得間接占有，以代交付。
> **§948 II**　動產占有之受讓，係依第七百六十一條第二項規定為之者，以受讓人受**現實交付**且交付時善意為限，始受前項規定之保護。
> **§1148 I**　繼承人承受被繼承人財產上之一切權利義務。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「占有改定之意義？」 | 讓與人仍占有，以契約使受讓人取得**間接占有**以代交付（賣出去再借回來、租回來；畫展結束才取畫）。也是物權行為 |
| 「以占有改定受讓他人之物，得否善意取得？」 | **不得**（§948 II）：須受**現實交付**且交付時善意，始受保護 |
| 「1/1 乙無權以占有改定將甲之 A 車賣予惡意丙；2/2 同法賣予善意丁；3/3 甲死亡、乙為唯一繼承人。A 車屬誰？」 | **丙**。1/1、2/2 兩個物權行為皆效力未定，丙惡意、丁未受現實交付皆不能善意取得；3/3 乙繼承取得所有權（§1148）→ §118 II 兩處分**自始有效** → 一物二主相牴觸 → §118 III **最初之處分有效** → 丙 |
| 「同上，3/3 乙繼承後立即將 A 車現實交付給丁？」 | **丁**（善意且受現實交付 → 善意取得） |
| 「乙於 1/1 以占有改定無權處分甲之 A 給丙，3/3 甲將 A 贈與乙，丙得否向甲請求 1/1～3/3 期間相當於租金之不當得利？」 | **不得**。§118 II 但書：原權利人已取得之利益不受影響，該期間利益仍歸屬甲 |

## 一、占有改定：賣出去再借回來
- 「我把畫賣你，但展覽結束才能拿」「車賣你，再借我一個月」→ 訂立契約讓受讓人取得間接占有，代替交付（§761 II）。
- 無處分權人用占有改定處分 → 一樣是無權處分效力未定。
- **§948 II**：占有改定的受讓人**沒有現實占有**，占有還不值得保護 → 受現實交付且當時善意，才能善意取得。超容易錯。

## 二、經典案例：一台車兩次占有改定，然後繼承
```
1/1：乙（無權）以占有改定把甲的 A 車賣給【惡意】丙
2/2：乙以占有改定把 A 車賣給【善意】丁
3/3：甲意外死亡，乙是唯一繼承人
A 車是誰的？
```

| 時點 | 分析 | 所有人 |
|------|------|------|
| 1/1 | 買賣有效；物權行為無權處分效力未定；丙惡意 → 不能善意取得 | 甲 |
| 2/2 | 買賣有效；物權行為效力未定；丁善意**但占有改定未受現實交付** → §948 II 不能善意取得 | 甲 |
| 3/3 | 乙依 §1148 繼承取得 A 車所有權 → **§118 II**：無權利人取得權利 → 1/1、2/2 兩處分**自始有效**（溯及改寫過去）→ 丙 1/1 取得、丁 2/2 取得 → 一物一權衝突 → **§118 III 最初之處分有效** | **丙** |

- 惡意的丙最後拿到車——因為丁在 §948 II 下沒拿到現實交付，無法善意取得，只好讓最初處分有效。
- 變化：3/3 乙繼承後立刻把車**現實交付**給丁 → 丁善意取得 → 丁。題目有沒有這一句，答案完全不同。

## 三、§118 II 但書：溯及有效不改變權益歸屬
```
1/1 乙以占有改定無權處分 A 給丙（不能善意取得）
3/3 甲把 A 送給乙 → §118 II → 丙自 1/1 起取得 A
丙：1/1～3/3 是甲在用我的車 → 向甲主張相當於租金的不當得利？
→ §118 II 但書：原權利人已取得之利益不受影響 → 這段期間的使用利益仍歸甲 → 甲無不當得利
```
- 選擇題：「丙自 1/1 起取得所有權」✓；「丙得對甲主張不當得利」✗。
