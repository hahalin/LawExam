# 民法10 筆記：§106 但書「專」為履行債務——高普考案：銀行乙受甲財產管理授權，代理甲向自己支付利息，有清償效果、但**不生承認效果**（承認會中斷時效 §129 I ②、重新起算 §137，對甲不利、對乙有利 → 有利益衝突 → 不「專」）→ 時效仍於 105/1/1 完成，甲得為時效抗辯

> 來源：民法10 課程字幕 00:56:12 ~ 01:04:00（老師評為出得很棒的高普考題）

---

## 📖 法條原文速查

> **§106 但書**　但其法律行為，係專履行債務者，不在此限。
> **§129 I**　消滅時效，因左列事由而中斷：一、請求。二、**承認**。三、起訴。
> **§137 I**　時效中斷者，自中斷之事由終止時，重行起算。
> **§125**　請求權，因十五年間不行使而消滅。但法律所定期間較短者，依其規定。
> **§144 I**　時效完成後，債務人得拒絕給付。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人支付利息之效果？」 | 實務：支付利息＝**承認債務**（不承認幹嘛付利息）→ §129 I ② 時效中斷 → §137 重行起算。打定主意要主張時效抗辯的人千萬不能付利息 |
| 「甲欠乙 100 萬，清償期 90/1/1，分文未付；103/1/10 甲授與乙財產管理權，乙代理甲向自己支付利息；105/5 乙請求返還借款，甲得否時效抗辯？」 | **可以**。乙代理甲付利息是**履行債務**（§106 但書允許，有清償效果）；但承認債務會破壞甲的時效利益、對乙有利 → **有利益衝突** → 不是「專」為履行債務 → 代理付利息**不發生承認效果** → 時效自 90/1/1 起算，**105/1/1 完成** → 甲得拒絕給付 |
| 「若承認有效，時效何時完成？」 | 自 103/1/10 重行起算 15 年 → 118/1/10。原本再熬兩年就完成，一個承認變成再等 15 年 → 這就是利益衝突 |
| 「財產管理權是否包含承認債務？」 | **不包含**。授權管理財產 ≠ 授權承認債務；你可以幫我還，不能幫我承認 |

## 一、題目結構

```
90/1/1   甲向乙（銀行／資產管理公司）借 100 萬，清償期屆至，分文未付（本金利息都沒付）
103/1/10 甲年紀大／出國，授與乙財產管理權（意定代理）
         乙拿到代理權第一件事：代理甲支付利息給乙自己（10 萬、20 萬）；本金沒還
105/5    乙請求甲返還借款 → 甲主張時效抗辯？
```

## 二、兩層前提先確認

| 前提 | 內容 |
|---|---|
| 支付利息 ＝ 承認 | 實務見解：願意付利息就是承認這筆債務存在 → §129 I ② 中斷 → §137 重行起算 |
| 自己代理 | 乙代理甲、向乙自己為給付 → §106 本文原則禁止 → 但書：專為履行債務則可 |

## 三、關鍵：清償效果 vs 承認效果分開看

```
乙代理甲支付利息
├ 清償債務的效果？ 有。履行債務本身無利益衝突 → §106 但書允許 → 利息債務消滅
└ 承認債務的效果？ 無。
   承認 → 時效中斷重新起算 → 甲原本 105/1/1 可主張時效抗辯的利益被破壞；乙的債權卻多活 15 年
   → 對甲不利、對乙有利 → 有利益衝突 → 「專」字擋下來：有利益衝突就不是專為履行債務
   → 承認部分乙無代理權 → 不生承認效果
結論：時效於 105/1/1 完成 → 105/5 乙請求 → 甲依 §144 I 拒絕給付 ✓
```

- 「我授權你管理財產，不等於你可以幫我承認債務。承認債務跟履行債務是不一樣的事。」
- 若承認有效：103/1/10 重行起算 → 118/1/10 才完成。

## 四、這題在考什麼（為什麼很多人說「完蛋」）

1. 要先知道「支付利息會有承認效果」（時效）。
2. 再想：代理本人履行債務，是不是也會發生代理本人承認的效果？→ **不會**，因為 §106 但書的「專」排除了有利益衝突的部分。
3. 兩個制度（§106、§129）疊在一起，表面是時效題，核心是 §106 但書的解釋。
