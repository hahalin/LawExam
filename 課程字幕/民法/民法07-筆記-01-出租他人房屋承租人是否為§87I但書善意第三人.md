# 民法07 筆記：出租他人房屋——承租人是不是 §87 I 但書的「善意第三人」（王澤鑑 vs 多數說）

> 來源：民法07 課程字幕 00:00:04 ~ 00:12:00（接民法06 結尾）；01:00:48 ~ 01:05:30 補充買受人的兩條路

---

## 📖 法條原文速查

> **§87 I**　表意人與相對人通謀而為虛偽意思表示者，其意思表示無效。但不得以其無效對抗善意第三人。
> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。
> **§118 I**　無權利人就權利標的物所為之處分，經有權利人之承認始生效力。
> **§435 I**（租賃物一部滅失之減租）／**§436**（權利瑕疵準用）　前條規定，於承租人因第三人就租賃物主張權利，致不能為約定之使用、收益者準用之。
> **§227**（不完全給付）　→ 承租人對出租人債務不履行的依據

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲與乙通謀虛偽將 A 地登記予乙，乙出租予善意丙並交付，丙得否善意取得 A 地？」 | **不得**。租賃＋交付是債權契約之履行，**沒有處分行為** → 無無權處分 → 無善意取得（租房子不會租成地主） |
| 「丙如何阻止甲依 §767 I 前段請求返還？」 | 不是主張自己是所有人，而是**否認甲是所有人**：主張甲乙行為有效、乙才是所有人 → 甲能否以通謀無效對抗丙 → 丙是否 §87 I 但書之「善意第三人」 |
| 「王澤鑑：承租人是否善意第三人？」 | **否**。善意第三人須「**法律行為之效力**因通謀而受影響」；乙丙租賃契約效力不受影響 → 非第三人 → 甲得對抗 → §767 有理由 → 丙只能對乙主張 §436 準用 §435、§227 |
| 「多數說（林誠二、陳聰富）？」 | **是**。只要「**受影響**」即可，不必到效力受影響：① 丙原可使用收益變成只能請求賠償，實質受影響 ② 甲是通謀當事人、丙是善意人，無保護惡意犧牲善意之理 → 甲不得對抗 → 對丙而言乙是地主 → 甲非所有人 → §767 無理由 |
| 「乙將 A **賣**給善意丙？」 | 有物權行為 → 無權處分 → 丙有兩條路：§87 I 但書主張甲乙有效（乙有權處分 §758/§761）或 §801＋§948／§759-1 II 善意受讓 |

## 一、先把錯誤示範拿掉

```
✗ 甲乙通謀無效 → 乙未取得所有權 → 乙出租給丙＝無權處分效力未定 → 丙善意 → 善意取得 A 地
   → 承租人租一租變地主，荒謬
正解：乙丙之間只有租賃契約（債權行為）＋為履行而交付 → 沒有物權行為 → 沒有無權處分 → 沒有善意取得
```

## 二、丙的策略：不是「我是所有人」，是「你不是所有人」

```
甲 →丙 §767 I 前段，要件 ① 甲是 A 地所有人
    甲乙物權行為通謀無效 → 乙未取得 → 甲仍是所有人？
丙在訴訟中主張：甲乙的行為【有效】→ 乙才是所有人 → 甲不是 → 甲告不了我
    → 甲能否以「通謀虛偽無效」對抗丙？→ 看丙是不是 §87 I 但書的善意第三人
    是 → 甲不得對抗 → 丙說了算 → 乙是地主 → 甲 §767 無理由，丙依乙丙租約繼續用
    不是 → 甲得對抗 → 甲是所有人、乙丙租約基於債權相對性不能對抗甲 → 丙無權占有 → §767 有理由
```

## 三、兩說

| | 王澤鑑（少數說） | 多數說：林誠二、陳聰富 |
|---|---|---|
| 善意第三人的定義 | 須「**法律行為之效力**」因通謀虛偽意思表示而受影響 | 只要**受影響**即可，不必到效力受影響 |
| 套用 | 乙丙租賃契約的效力不受通謀影響（會受影響的是物權行為）→ 丙**不是**第三人 | ① 若採否定說甲可主張 §767，丙原本「對 A 地使用收益」變成「只能請求損害賠償」，契約內容已不同 → 實質受影響 ② 甲是通謀的當事人、丙是善意第三人，法律沒有保護惡意、犧牲善意的道理 → 丙**是**第三人 |
| 結果 | 甲得對抗丙 → §767 有理由 → 丙對乙：§436 準用 §435 權利瑕疵、§227 債務不履行 | 甲不得對抗丙 → 對丙而言乙才是地主 → 甲 §767 無理由 → 丙繼續承租 |

- 老師：王澤鑑在民法絕大多數爭點都是多數說，這裡是少數的例外。

## 四、補充：乙把 A 賣給善意丙（下課同學問）
```
乙丙買賣有效；物權行為無權處分效力未定
丙兩條路：
  ① §87 I 但書：主張甲乙有效 → 乙是所有人、有權處分（動產 §761／不動產 §758）→ 丙取得
  ② 善意受讓：§801＋§948／§759-1 II
在民總階段兩條路結果相同（都保護交易安全）；到 §92 II 才會有差異（後述）
```
- §87 I 但書的第三人討論三種人：繼承人（不受保護，民法06）、買受人（兩條路）、承租人（本筆記）。
