# 民法債權補充2 筆記：寄託、消費寄託與場所主人責任（§589至§611）

## 一般寄託
- 一方以物交付他方，他方允為保管的契約；老師認為是**要物**契約
- 報酬可有可無；注意義務隨之不同（§590）：
  - **無償**：與處理自己事務同一之注意（具體輕過失）
  - **有償**：善良管理人之注意（抽象輕過失）
- 返還期限雖經約定，寄託人仍得**隨時請求返還**（§597）——東西是自己的
  - 例：約定保管車子半年，3 個月就可要回
- 寄託的報酬、費用償還、損害賠償請求權：自寄託關係終止時起 **1 年**（§601-2）

## 消費寄託（§602、§603）
- 寄託物為**代替物**，約定**所有權移轉**於受寄人，由受寄人以種類、品質、數量相同之物返還（§602）
- 例：存 10 萬到銀行，銀行取得所有權，存款人取得債權；領回的不必是同一批鈔票
- 寄託物為**金錢**時，**推定**為消費寄託（§603）
  - 是「推定」不是「視為」：存古幣、連號鈔票等特定物，可舉反證推翻，認定為一般寄託

## 場所主人責任：未交付保管也要負責
- 一般寄託要把東西交給受寄人；場所主人責任是客人把東西**帶進**旅館、餐廳、浴場等消費場所而生的責任

| 條文 | 場所 | 標的 | 責任型態 |
|---|---|---|---|
| §606 | 旅店等住宿場所 | 旅客攜帶物品 | **通常事變責任** |
| §607 | 飲食店、浴場等 | 客人攜帶的**通常物品** | 通常事變責任 |
| §608 | 上列場所 | 金錢、有價證券、珠寶等**貴重物品** | 見下 |

- **通常事變責任**（§606）：毀損喪失即負責，不必主人有過失；但因**不可抗力**、物之性質、或客人自己（或其伴侶、隨從、來賓）的故意過失所致者，免責
- §607 限「通常物品」：去餐廳吃飯戴 20 克拉鑽戒、去三溫暖帶 300 萬本票，不是通常物品
- **貴重物品**（§608）：
  - 未**報明性質及數量**並**交付保管** → 主人不負責
  - 主人無正當理由**拒絕保管** → 對毀損喪失負責
  - 因主人或其使用人的**故意或過失**致毀損喪失 → 亦負責
- 以**揭示**限制或免除 §606～§608 責任者，**無效**（§609）
- 客人知悉毀損喪失應**即通知**主人，怠於通知者**喪失**損害賠償請求權（§610）
- §606～§608 請求權：自發現喪失或毀損時起 **6 個月**；或自客人離去場所後 **6 個月**（§611）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 有償寄託注意義務 | 善良管理人 |
| 約定期限前可否請求返還 | **可**，隨時 |
| 金錢寄託 | **推定**消費寄託 |
| 旅店對旅客攜帶物品 | 通常事變責任 |
| 餐廳、浴場之責任範圍 | 限**通常物品** |
| 貴重物品未報明交付保管 | 主人不負責 |
| 門口告示「遺失不負責」 | **無效** |
| 怠於通知 | 失權 |
| 場所主人責任時效 | **6 個月** |
| 一般寄託請求權時效 | **1 年** |
