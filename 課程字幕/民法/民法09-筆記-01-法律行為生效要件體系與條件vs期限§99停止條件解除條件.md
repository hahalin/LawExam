# 民法09 筆記：法律行為生效要件體系總覽；條件 vs 期限的區別；真正條件——§99 停止條件與解除條件

> 來源：民法09 課程字幕 00:00:00 ~ 00:10:00

---

## 📖 法條原文速查

> **§99**（條件之效力）
> I 附停止條件之法律行為，於條件**成就時**，發生效力。
> II 附解除條件之法律行為，於條件**成就時**，失其效力。
> III 依當事人之特約，使條件成就之效果，不於條件成就之時發生者，依其特約。

> **§102**（期限之效力）
> I 附始期之法律行為，於期限**屆至時**，發生效力。
> II 附終期之法律行為，於期限**屆滿時**，失其效力。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律行為之一般生效要件與特別生效要件？」 | 一般：行為能力、意思表示健全無瑕疵、標的可能妥當確定適法。特別：**條件、期限、處分權**（§99～§102、§118）、代理（§103～§111） |
| 「法律行為之效力有幾種？」 | **有效、無效、得撤銷、效力未定**（§111～§117 處理無效與撤銷的效果） |
| 「條件與期限之別？」 | 條件＝**不確定是否發生**之事實（考上律師）；期限＝**確定會發生**之事實（聖誕節、光復節） |
| 「停止條件 vs 解除條件？」 | 停止：成立但效力**停下來**，成就時**生效**（§99 I）；解除：成立即生效，成就時**失效**（§99 II） |
| 「預售屋約定『一個月內未貸得八成，契約不生效力／自動失效』？」 | 前者停止條件、後者解除條件，兩種寫法都常見 |
| 「分期付款買車，約定價金付清始取得所有權？」 | **附條件買賣**：買賣契約有效，**物權行為**附停止條件（動產擔保交易法 §26，筆記 04） |

## 一、體系：這張圖是審查工具
```
法律行為效力的審查
├── 一般生效要件
│     ├── 當事人行為能力（題目給 17 歲、監護宣告、輔助宣告才審）
│     ├── 意思表示健全無瑕疵（詐欺、脅迫、錯誤、通謀、心中保留）
│     └── 標的可能、妥當、確定、適法（原保地、預立離婚）
├── 特別生效要件
│     ├── 條件、期限 §99～§102
│     ├── 處分權 §118
│     └── 代理 §103～§111（含 §167～§171）
└── 效力：有效／無效／得撤銷／效力未定 → §111～§117 處理後果
```
- 老師：題目沒給的要件就跳過，給了線索才審；體系是用來一步一步檢查的，不是畫好看的。

## 二、條件 vs 期限：會不會發生
| | 條件 | 期限 |
|---|---|---|
| 附款內容 | **不確定是否發生** | **確定會發生** |
| 例 | 下禮拜三若下雨、考上律師 | 光復節、聖誕節 |
| 效力 | §99 | §102 |

## 三、真正條件：停止 vs 解除
```
法律行為兩階段：成立 → 生效（一般同時）
停止條件：成立，效力先停住 ──條件成就──→ 生效
解除條件：成立即生效 ──條件成就──→ 失效
```

### 實務最常見
| 情境 | 條件 |
|------|------|
| 預售屋：給一個月申請貸款，未貸到一定成數契約**不生效力** | 停止條件 |
| 預售屋：未貸到七成／八成，契約**自動作廢** | 解除條件 |
| 分期 60 期零利率，價金付清才取得所有權 | 附條件買賣：買賣契約無條件，**物權行為**附停止條件 |

- 真正條件 → 條件成就時發生（或失去）效力；不真正條件（法定、既成、不能、不法）見下一份筆記。
