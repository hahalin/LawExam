# 民法41 筆記：讓與擔保之法律構造與所有權移轉構造說

## 為什麼民間要用讓與擔保：
- 甲向乙借錢，正規做法是 A 地設定抵押權給乙
- 缺點：A 地有第一順位抵押權後，再向銀行借款時銀行只能排第二順位，可借額大減
- 民間做法：把 A 地**所有權移轉**給乙，但以**擔保為目的** → 登記簿上沒有抵押權，日後還能拿去向銀行設定第一順位，融資價值最大
- 民法沒有明文，是實務發展出的非典型擔保；考試約 103 或 104 年考過一次（建議查證）
- 近年謝在全、王澤鑑、陳榮傳、游進發等多位學者撰文，講義第五節整合各家見解（講義 338 頁以下）

## 三個法律行為（王澤鑑：兩個債、一個物）：

| 層次 | 內容 | 性質 |
|---|---|---|
| ① 原因關係 | 甲乙借款等債權債務 | 債權契約；無效時依 §111 法理，讓與擔保隨之失效（類似從屬性） |
| ② 讓與擔保契約 | 約定 A 地移轉是為擔保、雙方權利義務 | 債權契約 |
| ③ 移轉 A 地所有權 | 甲移轉登記給乙 | 物權契約 |

- 稱呼：乙＝擔保權人；甲＝擔保義務人

## 讓與擔保契約的權利義務（債的關係）：
- **清償前**：通常甲繼續占有、使用收益；甲不能處分（所有權已在乙）；乙雖是所有人，但負**不得處分**的義務
- 乙違約處分：負債務不履行責任；常見約款如「處分所得範圍內債務消滅」或懲罰性違約金，依契約自由
- **清償期屆至、已清償**：甲請求乙返還 A 地；乙已賣掉或設定負擔而無法原狀返還 → 損害賠償
- **清償期屆至、未清償**，依約定擇一：
  - 乙自行出賣（不是法院拍賣），價金清償後**多退少補**
  - 乙請求甲**交付** A 地；通說要清算，類推 **§873-1 II**
- 違反這些義務 → 往**債務不履行**找答案，不是物權問題

## 物權考點：甲移轉 A 地給乙，乙取得什麼？

| | 所有權移轉構造說（通說） | 擔保物權構造說（少數） |
|---|---|---|
| 乙取得 | **所有權** | 只有擔保權，所有權仍在甲 |
| 理由 | 物權公示原則，登記就是所有權移轉；當事人本就以移轉所有權的意思設定擔保 | 重視當事人內心真意 |
| 學者 | 王澤鑑、謝在全、陳榮傳 | — |

- 陳榮傳：乙取得的是**定限所有權**——有所有權的殼，但不能使用收益（在甲）、也不能處分（特約限制）；甲到期不清償時束縛解開，成為完全所有權。本質仍是所有權，所以仍屬所有權移轉構造說

## 兩說的差別（延伸考點）：

| 問題 | 所有權移轉構造說 | 擔保物權構造說 |
|---|---|---|
| A 地被第三人無權占有，誰主張 §767？ | **乙**；乙不主張，甲依 §242 代位 | 甲直接主張 |
| 乙的債權人查封 A 地，誰提異議？ | **乙** | 甲 |

## 公示與立法論：
- 登記實務沒有「讓與擔保」選項，大多勾「買賣」
- 有學者主張增設讓與擔保登記；老師認為一公示就破壞制度初衷（銀行看到就不肯多借）
- 比較法：日本考慮立特別法（條文很少），法國完全交由契約自由；我國目前靠實務判決形成框架

## 📖 法條原文速查

> **§873-1 II**（類推）抵押權人請求抵押人為抵押物所有權之移轉時，抵押物價值超過擔保債權部分，應返還抵押人；不足清償擔保債權者，仍得請求債務人清償。

> **§767 I**（所有物返還請求權）、**§242**（代位權）、**§111**（一部無效）→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「讓與擔保是民法明文的擔保物權？」 | **否**，非典型擔保 |
| 「讓與擔保包含幾個法律行為？」 | 原因關係、讓與擔保契約（債）、移轉所有權（物） |
| 「擔保權人取得什麼權利？」 | 通說：**所有權**（所有權移轉構造說） |
| 「到期未清償，擔保權人請求交付須否清算？」 | 須清算，類推 §873-1 II |
| 「擔保權人違約處分？」 | 債務不履行責任 |

## 流程圖

```
甲乙借款（原因關係）
   ↓
讓與擔保契約（債）＋ 移轉 A 地所有權（物）
   ↓ 清償前：甲占有使用、乙不得處分
清償期屆至
   ├─ 甲清償 → 乙返還 A 地（不能返還 → 損害賠償）
   └─ 甲未清償 → 乙自行出賣或請求交付 → 清算，多退少補
```
