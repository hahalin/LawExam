# 民法17 筆記：§187 II 委託照顧與未行使親權一方

## 舉證責任：
- §187 II 監督疏懈是**推定**的：被害人不必證明法代沒把小孩教好，由法代證明自己監督未疏懈
- 本段兩個爭點：①小孩不在身邊（學校、補習班、安親班、阿公阿嬤家）時，法代能否主張監督未疏懈；②父母離婚，未行使親權的一方要不要負 §187

## 爭點一：子女委由他人照顧：
- 肯定說（少數，52 台上 2771）：小孩在學校爸媽管不到 → 無從監督 → 無監督疏懈 → 可依 §187 II 免責
- **否定說（通說，王澤鑑）**：把小孩交給別人照顧，等於把自己的保護監督義務交給他人代為履行 → **類推 §224**，父母就直接監督者（老師、阿公阿嬤）的故意過失負同一責任 → 不能依 §187 II 免責
- 為什麼是類推：§224 管的是**債之履行**；父母的保護教養義務不是債

## 爭點二：離婚後未行使親權之一方：
- 依 §1055 由一方行使親權時，他方親權不消滅，只是**暫時停止**
- 暫停期間無從保護教養 → 不會有監督疏懈 → 不負 §187（100 台上 1123）
- 用語：父母對子女的是**親權**（權利義務之行使負擔），**監護權**是無父母或父母不能行使親權時才設置的監護人的權利；舊判決混用，答題要寫「親權」

## 📖 法條原文速查

> **§187 II**　前項情形，法定代理人如其監督並未疏懈，或縱加以相當之監督，而仍不免發生損害者，不負賠償責任。

> **§224**　債務人之代理人或使用人，關於債之履行有故意或過失時，債務人應與自己之故意或過失負同一責任。但當事人另有訂定者，不在此限。→ 本段**類推**

> **§1084 II**　父母對於未成年之子女，有保護及教養之權利義務。

> **§1055 I**（要旨）　夫妻離婚者，對於未成年子女權利義務之行使或負擔，依協議由一方或雙方共同任之。（原文請對六法）

## 📋 實務見解

> **52 台上 2771**（少數說；字幕先唸「2771」又唸「277」，字號請對講義 149 頁）：學生應邀在學校教室內摔角遊戲，非法令所不許，父親對子女之監督並無鬆懈可言，不負賠償責任。

> **100 台上 1123**（講義 149 頁最下方，字號請對講義）：父母對未成年子女之保護教養權利義務（§1084 II）不得拋棄；但協議離婚約定由一方監護時，他方之權利行使暫時停止，既無從對子女為監督，自不能就子女之侵權行為連帶負責。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「子女在學校侵害他人，父母得否以『管不到』依 §187 II 免責？」 | 通說**否**：類推 **§224**，老師的過失視為父母的過失 |
| 「為何是類推 §224 而非適用？」 | §224 限於**債之履行**；保護教養義務不是債 |
| 「離婚後未行使親權之一方，應否負 §187 連帶責任？」 | **否**：親權暫時停止，無從監督即無監督疏懈（100 台上 1123） |
| 「離婚後他方之親權是否消滅？」 | **不消滅**，僅暫時停止 |
| 「父母對未成年子女之權利稱為監護權？」 | **錯**，稱**親權**；監護權是監護人的權利 |

## 一、體系圖

```
被害人乙
├── 對行為人甲（限制行為能力、有識別能力）：§184
└── 對法代：§187 I 前段連帶
      └── 法代可否依 §187 II 舉證免責？
            ├── 小孩交給學校／阿公阿嬤照顧
            │     ├─ 少數說（52 台上 2771）：管不到 → 免責
            │     └─ 通說（王澤鑑）：類推 §224 → 不得免責 ★
            └── 離婚，未行使親權之一方
                  └─ 親權暫停 → 無從監督 → 不負責（100 台上 1123）★
```

## 二、兩個爭點比較

| | 委託他人照顧 | 離婚未行使親權 |
|---|---|---|
| 父母的監督義務 | 仍存在，只是交給別人代為履行 | 暫時停止 |
| 他人的過失 | 類推 §224 算在父母身上 | 不涉及 |
| 結論 | 仍負 §187 連帶責任 | 不負 §187 |

## 三、案例

- 甲（限制行為能力、有識別能力）在學校侵害乙；老師丙，父母丁
- 乙對甲 §184 ✓；乙對丁 §187 I 前段，要件都具備
- 丁主張「小孩在學校，我管不到」→ 通說：丙的監督過失類推 §224 算在丁身上，丁不能依 §187 II 免責
- 離婚案例：甲乙離婚約定由甲行使親權，子丙侵害丁 → 丁對甲 §187 ✓；丁對乙 ✗（乙得依 §187 II 免責）
