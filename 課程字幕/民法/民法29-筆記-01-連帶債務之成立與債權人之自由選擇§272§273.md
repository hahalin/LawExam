# 民法29 筆記：連帶債務之成立與債權人之自由選擇（§272、§273）

## 接續上一講：
- 民法28 結束在 §271 可分之債與多數債權人債務人的體系（見民法28-筆記-12）
- 本講從**連帶債務**開始，順帶比較**真正連帶**與**不真正連帶**

## 真正連帶的成立（§272）：
- 數人負同一債務，對債權人**各負全部給付之責任**
- 兩條路，至少要有一條：
  - **契約明示**（§272 I）：不能用默示或暗示；銀行要保證人簽的就是寫明「連帶保證」的契約書
  - **法律明文**（§272 II）：條文裡出現「連帶」兩字才算，例如 §185、§187、§188
- 沒有明示、也沒有法律明文，卻**偶然**為同一債務負責 → **不真正連帶**（見本講筆記-06）

## 效力的分類：
- **外部效力**：債權人與連帶債務人之間 → 債權人怎麼請求、對一人發生的事會不會影響其他人
- **內部效力**：債務人彼此之間 → 分擔與求償（§280～§282，見本講筆記-05）
- 外部效力再分：
  - **自由選擇**：§273
  - **絕對效力事項**：效力及於其他債務人
    - 完全絕對效力：及於**全部債務**（§274、§275、§278）
    - 限制絕對效力：只及於該債務人的**應分擔部分**（§276、§277）
  - **相對效力事項**：不及於其他債務人（§279）

## §273 自由選擇：
- 請求**對象**、**順序**、**數額**都不受限制：一人、數人或全體，同時或先後，全部或一部
- 連帶債務**未全部履行前**，全體仍負連帶責任（§273 II）：不是誰付了錢誰就離開

## 案例（本講基本事實）：
- 甲乙丙共同侵害 A（§185），A 損害 **100 萬元**；內部分擔 甲 30%、乙 60%、丙 10%
- A 查到只有丙名下有房屋 → 可以只告丙請求 100 萬元，拍賣丙的房屋受償，丙再向甲乙內部求償
- 丙只付了 60 萬元 → 剩下 40 萬元，甲乙丙**繼續連帶**，直到 A 全部受償

## 📖 法條原文速查

> **§272**（連帶債務之成立）
> I 數人負同一債務，**明示**對於債權人各負全部給付之責任者，為連帶債務。
> II 無前項之明示時，連帶債務之成立，以**法律有規定者**為限。

> **§273**（債權人之權利）
> I 連帶債務之債權人，得對於債務人中之一人或數人或其全體，同時或先後請求全部或一部之給付。
> II 連帶債務未全部履行前，全體債務人仍負連帶責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「當事人默示負連帶責任，是否成立連帶債務？」 | **否**，契約須**明示**（§272 I） |
| 「無明示時，連帶債務如何成立？」 | 以**法律有規定**者為限（§272 II） |
| 「債權人得否只對分擔額最低之債務人請求全部？」 | **得**，對象、順序、數額均不限（§273 I） |
| 「一債務人清償一部後，其餘部分？」 | 全體**仍負連帶責任**（§273 II） |
| 「無明示也無法律規定，偶然為同一債務負責？」 | **不真正連帶** |

## 體系圖

```
連帶債務 §272～§282
├── 成立 §272：契約明示 或 法律明文
├── 外部效力（債權人 ↔ 債務人）
│   ├── 自由選擇 §273
│   ├── 完全絕對效力 §274、§275、§278 → 及於全部債務
│   ├── 限制絕對效力 §276、§277 → 及於應分擔部分
│   └── 相對效力 §279 → 不及於他人
└── 內部效力（債務人 ↔ 債務人）
    └── 分擔、求償、承受、無資力分擔 §280～§282
```

| 比較 | 真正連帶 | 不真正連帶 |
|---|---|---|
| 成立依據 | 契約明示或法律明文 | 都沒有，偶然為同一債務負責 |
| 例 | §185、§187、§188 | 法定代理人與他人之受僱人 |
