# 民法13 筆記：侵權行為體系——責任成立（§184 一般侵權、§185～§191-3 特殊侵權）與法律效果（§192～§198 損害賠償，含 §197、§198 時效）；§213～§218-1 是債之標的中的「損害賠償之債」，所有損害賠償（侵權、債務不履行）通用；思考三層次：要不要賠（§184、§185～§191-3）→ 賠什麼（§213～§215 賠償方法）→ 賠多少（§193、§195、§216 範圍）；§213、§216、§195 不是請求權基礎（§192、§194 例外）；三小條款（§184 I 前段、I 後段、II）各自獨立，考試要寫清楚，不要只寫「侵權行為法則」

> 來源：民法13 課程字幕 01:15:00 ~ 01:25:00（債編開始；老師授課順序：侵權→不當得利→無因管理→契約＋債總後半→債各買賣租賃承攬）

## 📖 法條原文速查

> **§184**　I 因故意或過失，不法侵害他人之權利者，負損害賠償責任。故意以背於善良風俗之方法，加損害於他人者亦同。II 違反保護他人之法律，致生損害於他人者，負賠償責任。但能證明其行為無過失者，不在此限。
> **§213 I**　負損害賠償責任者，除法律另有規定或契約另有訂定外，應回復他方損害發生前之原狀。
> **§216 I**　損害賠償，除法律另有規定或契約另有訂定外，應以填補債權人所受損害及所失利益為限。
> **§192 I**　不法侵害他人致死者，對於支出醫療及增加生活上需要之費用或殯葬費之人，亦應負損害賠償責任。
> **§194**　不法侵害他人致死者，被害人之父、母、子、女及配偶，雖非財產上之損害，亦得請求賠償相當之金額。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「侵權行為體系？」 | **責任成立**：§184 一般侵權（三小條款）＋§185～§191-3 特殊侵權；**效果**：§192～§198（賠償範圍、慰撫金、時效）。§213～§218-1 不在侵權行為章，是**損害賠償之債**的通則，債務不履行也用 |
| 「侵權行為思考三層次？」 | ① **要不要賠**（責任成立：§184、§191-2 等涵攝）② **賠什麼**（賠償方法：§213～§215，回復原狀或金錢）③ **賠多少**（範圍：§193 勞動能力減損與增加生活需要、§195 慰撫金、§216 所受損害所失利益） |
| 「§213、§216、§195 可否作為請求權基礎？」 | **不可**。它們只決定責任成立後的方法與範圍，不是獨立的成立要件；要讓責任成立仍須回到 §184、§185～§191-3 等完全法條。例外：**§192、§194**（致死時特定第三人之請求權）可獨立作為請求權基礎 |
| 「考試引用 §184 要怎麼寫？」 | 寫清楚是 **§184 I 前段、I 後段或 II**（三小條款，對應德民 §823、§826），各自是獨立請求權基礎、要件不同；不要只寫「§184」或「依侵權行為法則」——學者很討厭，標的不明確就無法涵攝 |

## 一、體系圖

```
侵權行為
├ 責任成立
│  ├ 一般侵權 §184：I 前段／I 後段／II（三小條款）
│  └ 特殊侵權 §185～§191-3
└ 法律效果：損害賠償
   ├ 方法 §213～§215（債之標的，通用）
   ├ 範圍 §216～§218-1（通用）；§192～§195（侵權特則）
   └ 時效 §197、§198
```

## 二、三層次操作（乙被甲開車撞到）

| 層次 | 問題 | 條文 |
|---|---|---|
| ① | 甲要不要賠？ | §184 I 前段、§191-2 涵攝 |
| ② | 賠什麼？ | §213～§215：回復原狀／金錢賠償 |
| ③ | 賠多少？ | §193 勞動能力減損、增加生活上需要；§195 慰撫金；§216 |

- 90% 的考題考 §213～§218-1 都以侵權行為為前提，但這些規定不是只給侵權用。

## 三、債編授課順序（老師預告）

- 侵權行為 → 不當得利 → 無因管理（三者獨立成題）→ 契約 ＋ 債總後半（債權保全、債之移轉多搭契約考）→ 債各：買賣、租賃、承攬為主，其他契約帶看法條（選擇題愛考運送契約貨損一年、人傷二年之類細節）→ 物權約八堂。
