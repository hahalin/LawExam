# 民法36 筆記：妨害之不法性與必要容忍程度（§767）

## 什麼是「妨害」（§767 I 中段）：
- ① 破壞所有權的**圓滿狀態**：影響所有人的使用、收益、處分
- ② 具**不法性**：**逾越必要容忍程度**
- 沒有標準答案，要個案涵攝：所有人對物的支配，界線在哪裡

## 典型妨害：
- 傾倒廢土、垃圾
- 在他人土地掩埋有毒物質
- 這些沒有爭議，直接構成妨害

## 難題：土地已有一定公共功能時，容忍範圍怎麼劃：
- 先找出所有人**本來就要容忍的範圍**，再看行為有沒有超過
- 超過 → 構成妨害，可主張 §767 I 中段（必要時加 I 後段防止將來）、§179

## 案例一：農業用水池塘排入工業用水（近年國考考過）：
- 甲的 A 池塘數十年來供周圍農地排放**農業用水**，已形成**公用地役關係**；甲在池塘養魚，與農民互蒙其利
- 乙開工廠，把**無害的工業用水**排進池塘（題目沒有觸及相鄰關係條文）
- 甲的容忍範圍 = 農業用水
- 工業用水超出容忍範圍 → 影響甲的使用收益，也影響甲決定讓誰排水 → **構成妨害**
- 甲可依 §767 I 中段請求乙停止排放

## 案例二：既成道路上開夜市（研究所考過，真實案例）：
- 甲的土地是既成道路，乙在上面經營夜市
- 甲的容忍範圍 = **供公眾通行**
- 一般人通行 → 不構成妨害
- 開夜市 → 逾越通行範圍 → 構成妨害，甲可主張 §767、§179

## 答題步驟：
```
1. 是否影響所有人之使用、收益、處分（圓滿狀態）？
2. 所有人原本應容忍之範圍為何？（農業排水／公眾通行／無）
3. 行為是否逾越該範圍？
   ├─ 是 → 具不法性，構成妨害 → §767 I 中段（＋後段）
   └─ 否 → 不構成妨害
```

## 📖 法條原文速查

> **§767 I 中段、後段**　（所有人）對於**妨害**其所有權者，得請求**除去**之。有妨害其所有權之虞者，得請求**防止**之。

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「妨害之不法性如何判斷？」 | 是否**逾越必要容忍程度** |
| 「既成道路所有人得禁止公眾通行？」 | 原則**不得**，通行在容忍範圍內 |
| 「既成道路上擺攤經營夜市，所有人得請求除去？」 | **得**，逾越通行範圍 |
| 「供排放農業用水之池塘，他人排入工業用水？」 | 逾越容忍範圍，構成妨害 |
