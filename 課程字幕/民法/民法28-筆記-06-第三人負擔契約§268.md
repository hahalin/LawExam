# 民法28 筆記：第三人負擔契約（§268）

## 涉他契約的兩種：
- 原本契約只有甲（債務人）、乙（債權人）；涉他契約多了一個**第三人**
- 第三人**替債務人給付** → 第三人負擔契約（§268）
- 第三人**替債權人享受權利** → 第三人利益契約（§269、§270）
- §268～§270 是債總「契約」一節的最後一個主題

## §268 的構造：
- 甲乙約定由**丙**對乙給付；丙**沒有同意**，只是被扯進來
- 丙**不是契約當事人**
- 若丙也同意加入 → 丙就是契約當事人，不是這裡的涉他契約

## 生活例：
- 乙向甲商店買東西，甲說本店沒貨，請乙去乙分店（丙）拿
- 丙分店給了 → 事情結束
- 丙說「甲沒跟我講，我沒庫存」→ 法律關係如何？

## 丙不給付時：
- **乙對丙**：不能請求債務不履行
  - 丙不是當事人、沒有債務，自然沒有債務不履行
- **乙對甲**：甲負**損害賠償**責任
  - 即使甲已查好庫存、通知保留，**沒有過失**也要賠
  - 理由：債務人本應親自履行；把履行丟給第三人，就要為第三人的結果負**無過失的擔保責任**
- **乙能否請求甲給付？** 原則**不行**
  - §268 的效果只有「應負損害賠償責任」，沒有寫「應為給付」
  - 締約時已講明東西不在甲手上
- **甲主動給付時**：通說認為乙**不能拒絕**
  - 乙受領後即無損害，也就沒有損害賠償問題

- §268 也可能藏在第三人利益契約裡（見民法28-筆記-09）

## 📖 法條原文速查

> **§268**　契約當事人之一方，約定由**第三人**對於他方為給付者，於第三人不為給付時，應負**損害賠償**責任。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「第三人不給付，債權人得對第三人請求債務不履行？」 | **不得**，第三人非契約當事人 |
| 「債務人無過失，仍須對債權人負責？」 | **須**，無過失的擔保責任 |
| 「債權人得請求債務人自為給付？」 | 原則**不得**，§268 只有損害賠償 |
| 「債務人主動給付，債權人得拒絕？」 | 通說**不得拒絕** |
| 「第三人同意加入契約，仍是 §268？」 | **否**，第三人成為當事人 |

## 法律關係圖

```
甲（債務人）══契約══ 乙（債權人）
   │                   │
   │ 約定由丙給付       │ 丙不給付時
   ↓                   ↓
丙（未同意）        乙→丙：無請求權
                    乙→甲：§268 損害賠償（無過失亦負責）
                    乙→甲：原則不能請求給付
                    甲主動給付：乙不得拒絕
```

| 請求方向 | 結論 | 理由 |
|---|---|---|
| 乙→丙 給付或賠償 | 否 | 丙非當事人 |
| 乙→甲 損害賠償 | 是 | §268，擔保責任 |
| 乙→甲 給付 | 原則否 | 條文只有賠償 |
