# 民法物權補充2 筆記：動產質權之設定、擔保範圍與質權人之權利義務（§884至§895）

## 定義與取得
- 債權人對債務人或第三人**移轉占有**而供擔保的動產，得就其賣得價金優先受償之權（§884）
- **設定**：須**交付**（移轉占有）才生效力；質權人不得使出質人或債務人**代自己占有**（§885）
- **善意取得**：拿他人的動產設定質權，質權人善意且無重大過失仍取得質權（§886 準用 §948）

## 擔保範圍（§887）比抵押權多兩項
- 與抵押權相同：原債權、利息、遲延利息、違約金、實行質權費用
- 多出：**保存質物之費用**、因質物**隱有瑕疵**所生之損害賠償

## 質權人的義務
- 以**善良管理人**注意保管質物（§888）→ 抽象輕過失
- 不得出租；原則上不得使用，但為保存必要範圍內可使用（例：機器需運轉保養）

## 質權人的權利
### 1. 收取孳息（§889、§890）
- 原則有收取權，契約另有約定者從之（§889）
- 收取注意義務：**與處理自己財產同一之注意**（§890 I）→ 具體輕過失；與保管的善管注意不同
- 孳息利益歸出質人：依序抵充 **收取費用 → 原債權利息 → 原債權**（§890 II）
- 計算例：甲以 1 萬隻雞設定質權給乙，擔保本金 **100 萬**、已生利息 **8 萬**；雞蛋賣得 **25 萬**、收取費用 **3 萬**
  - 25 − 3 ＝ 22；22 − 8（利息）＝ 14；100 − 14 ＝ 甲還欠 **86 萬**

### 2. 轉質（§891）
- 質權存續中，得以自己責任將質物轉質於第三人
- 轉質所受**不可抗力**的損失也要負責

### 3. 預行拍賣（§892）
- 質物有**腐壞之虞**或價值顯有減少、足以害及質權人權利 → 得拍賣，以價金**代充質物**
- 出質人得請求將價金提存；拍賣前應通知（§894）

### 4. 實行質權
- **拍賣**：債權屆期未受清償，得拍賣質物（§893 I），不必聲請法院
- **流質契約**：準用 §873-1（§893 II）
- **其他方法**：準用 §878（§895）

## 📖 法條原文速查

> **§887 I**（擔保範圍）質權所擔保者為原債權、利息、遲延利息、違約金、保存質物之費用、實行質權之費用及因質物隱有瑕疵而生之損害賠償。但契約另有約定者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 動產質權設定要件 | **交付**；不得由出質人代占有 |
| 擔保範圍比抵押權多 | 保存費用、隱有瑕疵之損害賠償 |
| 保管質物注意義務 | **善良管理人**（抽象輕過失） |
| 收取孳息注意義務 | **與處理自己財產同一**（具體輕過失） |
| 孳息抵充順序 | 收取費用 → 利息 → 原債權 |
| 轉質之責任 | 含不可抗力 |
| 拍賣質物是否須聲請法院 | **不必** |
