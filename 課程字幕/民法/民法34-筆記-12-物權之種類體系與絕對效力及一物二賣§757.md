# 民法34 筆記：物權之種類體系與絕對效力及一物二賣（§757）

## 債與物權：
- 債：**人與人**之間的法律關係（契約、侵權行為、無因管理、不當得利）
- 物權：**人對物**的支配關係
- 同一塊地上可能同時有所有權、銀行抵押權、甲的地上權、乙的租賃權……物權法處理這些支配關係怎麼調和

## 物權法定主義（§757）：
- 物權除依**法律**或**習慣**外，不得創設
- 「習慣」是後來增訂（字幕作民國 96 年；物權編通則修正公布為 98 年，建議查證）
- 常見習慣物權：
  - **事實上處分權**：買受未辦保存登記的違章建築，主流見解解為習慣物權；王澤鑑稱「事實上所有權」
  - **讓與擔保**：老師猜很多年，至今未考，後面會講

## 法定物權體系：
```
物權
├── 所有權（完全物權）
└── 定限物權
    ├── 擔保物權（重交換價值）
    │   ├── 抵押權 —— 不動產
    │   ├── 質權 —— 動產（與權利）
    │   └── 留置權 —— 動產；唯一依法律要件自然發生，不用設定
    └── 用益物權（重利用價值，全部以不動產為標的）
        ├── 地上權 —— 蓋房子
        ├── 農育權 —— 種東西
        ├── 不動產役權 —— 消極：不讓你用（怕蓋太高擋採光）
        └── 典權 —— 錢給我、地借你，期滿原價互還，不計利息租金
```
- 唯一不能當抵押權標的的用益物權：**不動產役權**（§882 只列地上權、農育權、典權）
  - 理由：須與需役地綁在一起才有價值，單獨沒有經濟價值

## 占有不是物權：
- 物權編十章：通則、所有權、七種定限物權、**占有**
- 占有是對物有**事實上管領力**的**狀態**（§940）
- 若占有是權利，就不會有「無權占有」；有權無權要看背後有無**占有權源**
- 答題不要寫成「占有權」

## 考試火力：
- **通則**（§758、§759、§759-1、§762～§764 等物權變動）、**所有權**（尤其共有、時效取得、相鄰關係）、**抵押權**
- 其他（留置權、典權、農育權）留到最後看法條

## 物權之絕對效力 vs. 債之相對性：一物二賣
- 甲先將 A 地賣給乙並**交付**，又賣給丙並**移轉登記**
- 乙 → 丙依 §348 請求移轉登記？**不行**，丙不是買賣契約當事人
- 丙 → 乙依 §767 I 前段請求返還：
  - 丙登記為所有人，物權可對抗任何人
  - 乙主張依 §373 受交付後可使用收益 → 這是**債權**占有權源，不能對抗丙 → 乙**無權占有**
- 乙的救濟：對甲依 **§226** 請求損害賠償
- 結論：債權與物權衝突時，物權因有絕對效力而優先

## 無因性與獨立性：
| | 無因性 | 獨立性 |
|---|---|---|
| 情境 | **債權行為有瑕疵** | 債權行為**沒有瑕疵** |
| 問題 | 瑕疵會不會影響物權行為 | 物權行為本身是否有效 |
| 例 | 買賣 A 車卻交付 B 車，B 車物權行為在撤銷前仍可能有效 | 訂約時有行為能力，移轉登記時已受監護宣告 → 買賣有效、物權行為無效 |
- 不確定時兩個一起寫也可以；共同瑕疵說、條件關聯說民總已講

## 公示原則：
- 物權要對抗全世界，須有讓人看得到的**公示外觀**：不動產＝**登記**，動產＝**占有**
- 債權你知我知就好，不必公示
- 公信原則留到**善意取得**再講

## 下一講：
- 從 **§758 以下物權變動**開始（不動產、動產物權變動、善意受讓）

## 📖 法條原文速查

> **§757**　物權除依**法律**或**習慣**外，不得創設。

> **§882**　**地上權、農育權及典權**，均得為抵押權之標的物。

> **§940**　對於物有**事實上管領之力**者，為占有人。

> **§758 I**　不動產物權，依法律行為而取得、設定、喪失及變更者，非經**登記**，不生效力。

> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「物權得依習慣創設？」 | **得**（§757） |
| 「下列何者不得為抵押權標的？」 | **不動產役權**（§882） |
| 「哪一種擔保物權不須設定？」 | **留置權** |
| 「用益物權的標的？」 | 全部是**不動產** |
| 「占有是物權？」 | **不是**，是事實狀態 |
| 「一物二賣，先受交付之買受人可對抗已登記之後買受人？」 | **不可**，債權占有權源無法對抗所有人 |
