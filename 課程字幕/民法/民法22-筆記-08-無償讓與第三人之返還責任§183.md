# 民法22 筆記：無償讓與第三人之返還責任（§183）

## 無償有權處分（案例一之一，乙善意）：
- 甲把 A 車賣給乙並交付，乙轉贈丙並交付
- 甲因錯誤只撤銷**買賣契約**，物權行為有效 → 乙曾取得所有權，再有權處分給丙
- 甲對乙 §179：給付型、契約撤銷無法律上原因 → 成立；§181：車不在 → 償還價額
- §182 I：贈與是諾成契約，乙沒有因此得到對價，總體財產只減少 → 利益不存在 → **免返還**
- 結果：甲失去 A 車又無 §179 可用；乙不賺不賠；丙無償取得
- **§183**：受領人無償讓與第三人、因此（§182 I）免返還 → 第三人在受領人免返還的限度內負返還責任 → 甲得**直接適用 §183** 向丙請求

## 無償無權處分：類推 §183
- 同案，但甲把買賣契約與**物權行為**都撤銷
- 乙從未取得所有權，贈與又是無償 → 乙**根本沒有得利**，連 §179 都不成立（不是走到 §182 才免責）
- §183 要件卡住：乙不是「不當得利之受領人」，也不是「因 §182 I」免返還
- 王澤鑑：利益狀態相同（甲失去 A 而無 §179 可用，丙無償得到 A），只是理由不同 → **類推適用 §183**

## 林誠二（楊芳賢亦有批評）：§183 是錯誤立法
- 乙用 A 車履行對丙的贈與債務 → 受有**債務消滅**的利益，且這個利益一直存在
- 乙既有利益，就不會因 §182 I 免返還 → 甲直接向乙請求償還價額即可，根本不必找丙
- 有權、無權處分都一樣用不到 §183
- 考試以**通說**為主軸（法條就寫無償讓與會免返還），再補「另有學者認為」

## 乙惡意時（案例一之二）：
- 乙不能用 §182 I，依 §182 II 不問利益存否都要還 → 甲對乙有 §179 可用
- 甲不要錢、只要原物（例：獨一無二的畢卡索畫作），可否仍依 §183 找丙？
- **多數說：不行**。§183 是在甲無不當得利可主張時才給的路
- 少數說（黃茂榮，高院判決曾採）：舉輕以明重，善意都能找丙，惡意更應可以 → 類推 §183
- **102 台上 1591** 廢棄該高院判決：能對受領人主張不當得利時，不得類推 §183

## 📖 法條原文速查

> **§183**　不當得利之受領人，以其所受者，**無償讓與第三人**，而受領人因此**免返還義務**者，第三人於其所免返還義務之限度內，負返還責任。

> **§182 I**　不當得利之受領人，不知無法律上之原因，而其所受之利益已不存在者，免負返還或償還價額之責任。

> **§88 I**　意思表示之內容有錯誤，或表意人若知其事情即不為意思表示者，表意人得將其意思表示撤銷之。但以其錯誤或不知事情，非由表意人自己之過失者為限。

---

## 📋 實務見解速查

> **102 台上 1591**（講義註 528 之上訴審，要旨）：§183 以受領人因無償讓與而免返還義務為要件；受損人得對受領人主張不當得利時，不得類推適用 §183 向第三人請求。（要旨依課堂講述，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「善意受領人將所受之物贈與第三人，原權利人得向誰請求？」 | 第三人，**直接適用 §183** |
| 「無償**無權**處分，§183 如何適用？」 | **類推適用**（受領人連 §179 都不成立） |
| 「受贈之第三人負返還責任之範圍？」 | 受領人**所免返還義務之限度內** |
| 「受領人惡意時，得否類推 §183 向第三人請求？」 | 多數說、102 台上 1591：**否** |
| 「林誠二對 §183 之看法？」 | 受領人有債務消滅利益，§183 為錯誤立法 |

## 一、三種情形

| | 無償有權處分（乙善意） | 無償無權處分 | 無償有權處分（乙惡意） |
|---|---|---|---|
| 撤銷 | 只撤銷債權行為 | 債權、物權都撤銷 | 只撤銷債權行為 |
| 甲對乙 §179 | 成立，§182 I 免還 | 不成立（未得利） | 成立，§182 II 須還 |
| 甲對丙 | **適用** §183 | **類推** §183 | 多數說：不得類推 |

## 二、為什麼要 §183

```
甲：失去 A，對乙無 §179 可用 ── 虧
乙：失去 A，也不用還 ────────── 不賺不賠
丙：無償得到 A ──────────────── 賺
        ↓
§183：讓甲直接向無償受讓的丙請求
```
