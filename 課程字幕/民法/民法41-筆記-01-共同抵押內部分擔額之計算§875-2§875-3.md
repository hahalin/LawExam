# 民法41 筆記：共同抵押內部分擔額之計算（§875-2§875-3）

## 外部關係回顧（上一講）：
- 一個債權有數個抵押物擔保 → 共同抵押（§875 以下）
- 抵押權人**自由選擇**實行哪一個抵押物；同時拍賣時，有**債務人所有**的抵押物先受償（§875-1），其餘按比例

## 內部分擔額：按「價值比例」，但價值要先調整
- 依據：§875-2；同時拍賣且價金超過債權額時，§875-3 準用 §875-2
- 核心觀念：每個抵押物的計算值＝**抵押權人從這個抵押物最多能拿到的金額**
- 不是直接拿市價比，要一格一格檢查：

| 情形 | 計算值 | 依據 |
|---|---|---|
| 未限定金額 | 市價 | §875-2 I ① |
| 未限定，但**市價 > 債權額** | **債權額** | 學說類推 §879 II 後段（鄭冠宇）；有爭議，見筆記-02 |
| 已限定金額 | 限定額 | §875-2 I ②③ |
| 限定額 > 市價（高估） | **市價** | §875-2 II |
| 該抵押物上是**後次序** | 市價扣除先次序債權後的**剩餘** | 同一法理 |

## 考過的題目（二試）：
- 甲向乙借 **400 萬**，A 地（市價 **600 萬**）設第一順位抵押給乙
- 甲再向丙借 **300 萬**，A 地設第二順位給丙，另以 B 地（市價 **200 萬**）設第一順位給丙
- 丙的債權先到期，實行抵押權，**同時拍賣 A、B**，如何分配？
- 陷阱：不是 600：200（3：1）
- A 地對丙的價值＝600－400＝**200**；B 地對丙＝**200** → **1：1**
- 丙的 300 萬由 A、B 各負擔 **150 萬**

> 來源：民法41 課程字幕 00:00:01 ~ 00:11:57、00:13:56 ~ 00:16:16（講義 297～299 頁以下有計算題）；字幕「187條之2」為「875條之2」之誤，「餅」為「丙」、「AD／BD」為「A地／B地」

## 📖 法條原文速查

> **§875-2**（共同抵押各抵押物之分擔額）
> I 為同一債權之擔保，於數不動產上設定抵押權者，各抵押物對債權分擔之金額，依下列規定計算之：
> 一、未限定各個不動產所負擔之金額時，依各抵押物**價值之比例**。
> 二、已限定各個不動產所負擔之金額時，依各抵押物所**限定負擔金額之比例**。
> 三、僅限定部分不動產所負擔之金額時，依各抵押物所限定負擔金額與未限定負擔金額之各抵押物價值之比例。
> II 計算前項第二款、第三款分擔金額時，各抵押物所限定負擔金額**較抵押物價值為高者，以抵押物之價值為準**。

> **§875-3**（同時拍賣之準用）為同一債權之擔保，於數不動產上設定抵押權者，在抵押物全部或部分**同時拍賣**，而其賣得價金**超過所擔保之債權額**時，經拍賣之各抵押物對債權分擔金額之計算，**準用前條**之規定。

> **§879 II 後段**（類推依據）抵押物之擔保債權額**少於抵押物之價值者，應以該債權額為準**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「共同抵押之抵押權人須先就債務人之抵押物實行？」 | **否**，自由選擇；同時拍賣時才先就債務人之物受償（§875-1） |
| 「限定負擔金額高於抵押物價值，如何計算？」 | 以**抵押物價值**為準（§875-2 II） |
| 「未限定金額、市價高於債權額？」 | 學說類推 §879 II 後段以**債權額**為準；條文未明定 |
| 「同時拍賣數抵押物，分擔額如何計算？」 | §875-3 **準用** §875-2 |
| 「抵押權人在某抵押物為第二順位？」 | 以扣除前順位後之**剩餘價值**計算比例 |

## 計算檢查流程

```
某抵押物的計算值
   │
   ├─ 有限定金額？
   │    ├─ 是 → 限定額；限定額 > 市價 → 改用市價（§875-2 II）
   │    └─ 否 → 市價；市價 > 債權額 → 改用債權額（類推 §879 II）
   │
   └─ 抵押權人在此物是後次序？
        └─ 是 → 再扣掉前次序債權，取剩餘
   ↓
各抵押物計算值相比 → 得出分擔比例 → 乘上債權額
```

## 數字對照：考題的分配表

| 拍賣標的 | 賣得 | 乙（A 一順位） | 丙 | 還給所有人 |
|---|---|---|---|---|
| A 地 | 600 | 400 | 150（二順位） | 50 |
| B 地 | 200 | — | 150（一順位） | 50 |

- 丙在 A、B 各只能拿到自己的分擔額，多出的各 50 萬丙沒有優先受償權，返還抵押物所有人
- 換個角度驗證：丙就算只拍賣 A，最多也只拿得到 200 → A 對丙的價值就是 200

## 限定金額的小例

| 抵押物 | 市價 | 限定額 | 計算值 |
|---|---|---|---|
| 甲地 | 1,000 萬 | 700 萬 | 700 萬（限定額） |
| 乙地 | 500 萬 | 700 萬 | **500 萬**（高估，以市價為準） |
