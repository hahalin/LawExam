# 民法05 筆記：完全行為能力人、§75 後段與意思表示三要素入門

> 來源：民法05 課程字幕 02:25:18 ~ 02:37:12（本堂結尾；意思表示的方法、解釋、生效、瑕疵下堂續）

## 📖 法條原文速查

> **§75**（無行為能力人及無意識能力人之意思表示）
> 無行為能力人之意思表示，無效；**雖非無行為能力人**，而其意思表示，係在**無意識或精神錯亂**中所為者亦同。
> → 後段適用於限制行為能力人、受輔助宣告人、完全行為能力人

> **§1190**（自書遺囑）
> 自書遺囑者，應自書遺囑全文，記明年、月、日，並親自簽名；如有增減、塗改，應註明增減、塗改之處所及字數，另行簽名。

> **§86～§98**（意思表示）體系：
> §86～§93 有瑕疵的意思表示（心中保留、通謀虛偽、錯誤、詐欺脅迫）
> §94～§97 意思表示的生效（對話、非對話、對限制行為能力人、相對人不明）
> §98 意思表示的解釋

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有行為能力人所為之法律行為必有效？」 | **不必然**。§75 後段：行為時無意識或精神錯亂 → 無效 |
| 「§75 後段適用對象？」 | 「雖非無行為能力人」→ 限制行為能力人、受輔助宣告人、完全行為能力人**都適用** |
| 「80 歲老人自書遺囑形式要件俱全，醫療紀錄顯示當日精神狀況極差？」 | §75 後段 → **無效**（人死後靠就醫紀錄舉證） |
| 「10 歲兒童購買文具（日常生活所必需），但當時精神錯亂？」 | 仍 §75 後段**無效** |
| 「意思表示之三要素？」 | **行為意思**（知道自己在做什麼）、**表示意思**（知道行為會產生法律效果）、**效果意思**（知道想要什麼效果） |
| 「路上舉手向朋友打招呼，計程車停下？」 | 有行為意思，無表示意思、無效果意思 → **不是完整的意思表示** |

## 一、完全行為能力人：原則不受影響，但看精神狀態

```
行為能力四級
├── 無行為能力人      → §75 前段、§76
├── 限制行為能力人    → §77～§85
├── 受輔助宣告人      → §15-2
└── 完全行為能力人    → 原則不受行為能力影響
      ↑ 以上後三者都要再檢查 §75 後段：行為時無意識或精神錯亂 → 無效
```

### 考試審查順序（老師建議）
```
① 客觀上是哪一種行為能力人？
② 依其規定，行為原則上效力如何？
③ 行為時有無無意識或精神錯亂？有 → §75 後段無效
（其實先審 ③ 也可以，思考上更流暢：有 → 直接無效；沒有 → 再走 ①②）
```

### 案例：80 歲老人的遺囑（身分法考題）
- 形式要件都有：親自書寫全文、記明年月日、簽名。
- 問題在：醫生說他當天精神狀況很差。
- 遺囑有沒有效通常在人死後才爭執，死無對證 → 調**就醫紀錄**看有無無意識或精神錯亂 → 有 → §75 後段無效。
- 10 歲小孩買文具，日常生活所必需本來不受影響，但當下精神錯亂 → 一樣無效。

## 二、意思表示入門：腦子想的 ＋ 表現出來

```
意思表示 ＝ 意思（腦子裡想的，漫畫的雲朵框）＋ 表示（表現於外，漫畫的對話框）
「意思」要有三個認知：
    行為意思：我知道我在做什麼（我知道我在舉手）
    表示意思：我知道這個行為會產生法律效果（舉手會叫到計程車）
    效果意思：我知道我要的效果是什麼（我要搭計程車）
三個都有 → 完整的意思
```

| 情境 | 行為意思 | 表示意思 | 效果意思 | 完整的意思表示？ |
|------|------|------|------|------|
| 路邊舉手叫計程車 | ✓ | ✓ | ✓ | ✓ |
| 路邊舉手跟朋友打招呼，計程車停下 | ✓ | ✗ | ✗ | ✗ |

- 欠缺表示意思或效果意思會怎樣？是意思表示錯誤（撤銷就好）還是根本不成立？→ 講完意思表示錯誤後，用陳忠五老師的文章（講義 180 頁）再談。
