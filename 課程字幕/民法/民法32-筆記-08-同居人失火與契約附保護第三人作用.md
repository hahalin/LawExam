# 民法32 筆記：同居人失火與契約附保護第三人作用

## 問題：出租人直接找同居人
- 承租人有 §434 保護（重大過失才賠），出租人改對**同居人**依 §184 請求
- 同居人能不能也用 §434 影響 §184？
- 實務：**不能**
  - 同居人不是契約當事人，§434 是保護**承租人**的契約規定
  - 同居人仍以**抽象輕過失**負 §184 責任

## 實務結論的不合理：
- 新婚夫妻甲乙一起租屋，只派甲出面跟丙簽約
- 甲是契約當事人 → 失火只就重大過失負責
- 乙不是當事人 → 失火要就輕過失負責
- 同一個屋簷下，只因為**誰去簽約**這個偶然事實，責任就不同

## 契約附保護第三人作用（德國法理論）：
- 又稱「契約對第三人之保護效力」，兩個名稱同義
- 要件：
  - ① 第三人與契約當事人**關係親密**：同居、父母子女、配偶；交往很久、已接近同居程度的男女朋友
  - ② 為**相對人（出租人）可預見**
- 效果：第三人**受契約保護**，可援用 §434
- 注意：第三人**不因此成為契約當事人**，沒有契約上的權利義務，不必付租金
- 只有學說承認，實務尚未承認（突破債之相對性的範圍太廣）
- 老師提醒：考試**不要亂用**，只用在這類特殊情形

## 學說的操作（兩個理論串起來）：
- 第一步：契約附保護第三人作用 → 同居人可援用 §434
- 第二步：規範競合說（請求權相互影響說）→ §434 影響 §184，過失解為**重大過失**
- 結論：同居人只就重大過失失火負責

## 考題型：
- 事實：
  - 甲乙婚後租屋，由甲出面與丙簽租約
  - 乙**輕過失**失火，A 屋付之一炬
  - 問丙對甲、對乙如何主張
- 丙對甲（§433）：
  - 受 §434 影響，乙須有**重大過失**，甲才負責
  - 乙只有輕過失 → 丙**不能**請求
- 丙對乙（§184）：
  - 實務：乙非契約當事人，不適用 §434 → 輕過失即須負責 → 丙**可以**請求
  - 學說：契約附保護第三人作用 ＋ 規範競合 → 須重大過失 → 丙**不能**請求

## 📖 法條原文速查

> **§433**　因承租人之**同居人**或因承租人允許為租賃物之使用、收益之第三人應負責之事由，致租賃物毀損、滅失者，承租人負損害賠償責任。

> **§434**　租賃物因承租人之**重大過失**，致失火而毀損、滅失者，承租人對於出租人負損害賠償責任。

> **§184 I**（前段）因故意或過失，不法侵害他人之權利者，負損害賠償責任。

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「同居人輕過失失火，出租人依 §184 請求同居人？」 | 實務：**可以**（同居人不適用 §434） |
| 「同居人輕過失失火，出租人依 §433 請求承租人？」 | **不可以**，須同居人重大過失 |
| 「契約附保護第三人作用的要件？」 | **關係親密** ＋ **相對人可預見** |
| 「受保護的第三人須付租金？」 | **不用**，不是契約當事人 |
| 「實務承認契約附保護第三人作用？」 | **未承認**，僅學說 |
