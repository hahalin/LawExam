# 民法15 筆記：其他人格法益之定性與居住安寧權

## 本段定位：
- 接續民法14：§195 I 列舉之身體、健康、名譽、自由、信用、隱私、貞操講完，進入**法條未列舉**、但實務學說多承認或有高度爭議的「其他人格法益」（講義 77 頁起）
- 本堂依序講：居住安寧 → 死者人格權 → 家庭完整人格法益（配偶權）→ §195 III 身分法益 → 寵物

## 「其他人格法益」是權利還是利益：
- 爭點意識：是權利 → §184 I **前段**；是利益 → 只能走 §184 I **後段**
- **多數學說：權利**。是前面列舉人格權的延伸，前面是權利、後面也是權利；且有「**情節重大**」可控制範圍，不致氾濫
- **少數實務：利益**（文義解釋，法條用「法益」）→ 只能依後段

## 居住安寧權：
- **92 台上 164 判例**（老師：蠻常考）：於他人居住區域發出超越一般人社會生活所能容忍之噪音，屬不法侵害他人居住安寧之**人格利益**，情節重大者得依 §195 I 請求相當金額
- 判例用語是「利益」→ 依其文義要走後段＋§195；依通說仍可當權利走前段
- 不只聲音：**光、氣味**（樓下陽臺長期抽菸、油煙）逾越一般人可容忍程度皆屬之；現行判決以**菸味**案件最多

## 📖 法條原文速查

> **民法 §195 I**　不法侵害他人之身體、健康、名譽、自由、信用、隱私、貞操，或不法侵害**其他人格法益而情節重大者**，被害人雖非財產上之損害，亦得請求賠償相當之金額。……

> **民法 §184 I**　因故意或過失，不法侵害他人之**權利**者，負損害賠償責任。故意以背於善良風俗之方法，加損害於他人者亦同。

---

## 📋 實務見解速查

> **最高法院 92 年台上字第 164 號判例**（講義 79 頁上方，字幕作「92164」）：於他人居住區域發出超越一般人社會生活所能容忍之噪音，應屬不法侵害他人**居住安寧之人格利益**，如其情節重大，被害人非不得依 §195 I 請求賠償相當之金額。（要旨依老師唸讀整理，原文請對講義）
> 講義 78 頁另有兩則相關判例，老師說「知道一下就好」，字幕未唸字號。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§195 I『其他人格法益』屬權利或利益？」 | **多數說：權利**（列舉人格權之延伸＋情節重大可控範圍）→ 得依 §184 I 前段；少數實務依文義認係**利益** → 僅得依後段 |
| 「製造噪音侵害鄰居，被害人得否請求慰撫金？」 | 得。92 台上 164：侵害**居住安寧之人格利益**，**情節重大**者依 §195 I 請求 |
| 「居住安寧之侵害限於噪音？」 | **否**。光線、氣味（菸味、油煙）逾越一般人社會生活所能容忍程度者亦屬之 |
| 「依 92 台上 164 之用語，請求權基礎為何？」 | 判例用「人格**利益**」→ 文義上應為 §184 I **後段**＋§195 I；通說則認為權利 → **前段**＋§195 I |
| 「§195 I 列舉者與其他人格法益之差別？」 | 列舉者（身體、健康、名譽、自由、信用、隱私、貞操）直接請求；其他人格法益須**情節重大** |

## 一、§195 I 的兩層構造

```
§195 I
├── 列舉：身體、健康、名譽、自由、信用、隱私、貞操
│        → 皆屬權利，§184 I 前段 ✓，不須情節重大
│
└── 其他人格法益而情節重大者
         ├── 多數學說：權利（延伸＋情節重大把關）→ 前段 ✓
         └── 少數實務：利益（文義「法益」）→ 只能後段
```

## 二、居住安寧侵害的判斷

| 項目 | 內容 |
|---|---|
| 侵害型態 | 噪音、光、氣味（菸味、油煙）等影響居住環境者 |
| 門檻 | 超越一般人社會生活所能容忍之程度 |
| 判斷因素（老師舉例） | 抽菸的時間、頻率是否遠高於一般人能容忍者 |
| 慰撫金 | 須**情節重大**（§195 I） |
| 請求權基礎 | 通說：§184 I 前段＋§195 I；依判例用語：§184 I 後段＋§195 I |

## 三、案例：公寓陽臺抽菸

#### 事實
- 乙住二樓，長期在陽臺抽菸，菸味飄進樓上甲家，頻率與時間遠高於一般人可容忍程度。

#### 分析
1. 甲有無權利受侵害：居住安寧屬 §195 I「其他人格法益」；不限聲音，氣味亦屬之。
2. 前段或後段：採多數說（權利）→ §184 I 前段；採文義（利益）→ 須證明乙故意以背於善良風俗之方法，難度較高。
3. 慰撫金：須情節重大。

#### 結論
- 逾越容忍程度且情節重大者，甲得請求非財產上損害賠償；寫題時先點出「權利或利益」之定性爭議。
