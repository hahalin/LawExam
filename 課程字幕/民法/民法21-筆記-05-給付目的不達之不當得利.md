# 民法21 筆記：給付目的不達之不當得利

## 要件（講義 288 頁，王澤鑑文章）：
- 受有利益
- 為達成某種事實上或法律上的結果而為給付，該結果是**無拘束力的目的約定**（不是法律上的債務）
- 給付目的不達
- 關鍵：若是有拘束力的約定 → 那是**債務不履行**；只有道德、事實層次的期待，才可能走給付目的不達

## 德國例：
- 甲無償照顧鄰居乙 20 年（收信、打掃、載去看醫生、買晚餐），目的是乙口頭說過會把部分遺產給甲
- 乙沒立遺囑、也沒有遺贈；乙死後繼承人不認帳
- 甲當初給付的目的（取得遺產）是事實上的目標，未達成 → 可依給付目的不達之不當得利請求

## 我國實務的濫用（老師：考試要會批評）：
- 105 年最高法院判決：甲付乙 100 萬請乙清運廢土，乙把廢土倒到河川、山上 → 最高法院認給付目的（清運廢土）不達，依不當得利返還
- **王澤鑑批評**：甲乙間有**承攬契約**，100 萬是承攬報酬；乙未完成工作是**債務不履行**，應依債務不履行處理
- 若把給付目的不達放寬到所有情形，所有債務不履行都變成不當得利，契約法就沒有存在必要

## 審查順序（講義 288 頁末段）：
1. 是否為給付障礙（債務不履行）？→ 是 → 走債務不履行
2. 是否給付目的**自始不存在**？→ 是 → 一般給付型不當得利
3. 兩者皆否，給付目的存在但**無法達成** → 才討論給付目的不達

> 來源：民法21 課程字幕 00:44:16 ~ 00:51:48（講義 288 頁、註 453）

## 📖 法條原文速查

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

---

## 📋 實務見解速查

> **105 年最高法院判決**（講義註 453）：§179 所謂無法律上原因而受利益，就受損人之給付情形而言，係指欠缺給付目的；給付目的自始欠缺、嗣後不存在或**不能達到**，均屬給付型不當得利之無法律上原因。本案為廢土清運報酬之返還。（字號字幕未唸，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「給付目的不達之目的約定須有法律上拘束力？」 | **錯**，須為**無拘束力**之目的約定 |
| 「承攬人收報酬未完成工作，定作人應依給付目的不達請求返還？」 | 學說：**否**，應依**債務不履行** |
| 「審查給付目的不達前應先排除？」 | 債務不履行、給付目的自始不存在 |
| 「口頭承諾遺產而無償照顧多年，未獲遺產？」 | 給付目的不達之典型（德國例） |

---

## 一、三種情形的分流

```
當事人為給付，結果不如預期
├─ 有拘束力的債之關係，對方不履行 → 債務不履行
├─ 給付目的自始不存在          → 給付型不當得利
└─ 無拘束力目的約定，目的不能達成 → 給付目的不達之不當得利
```

## 二、兩案對照

| | 照顧鄰居 20 年 | 廢土清運 |
|---|---|---|
| 約定性質 | 口頭期待遺產，無拘束力 | 承攬契約，有拘束力 |
| 未達成時 | 給付目的不達 | 債務不履行 |
| 最高法院 | — | 給付目的不達（被批評） |
