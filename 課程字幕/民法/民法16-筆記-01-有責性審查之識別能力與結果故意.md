# 民法16 筆記：有責性審查之識別能力與結果故意

## 審查位置與順序：
- §184 I 前段的最後一關＝**有責性**，包含兩件事：責任能力、故意過失
- 實際審查順序**先責任能力、後故意過失**：沒有識別能力的人，既無從「明知並有意」，也欠缺「能注意」的能力，不可能有故意過失

## 識別能力：
- 責任能力以**識別能力**判斷＝能認識自己行為**可能造成損害**
- 王澤鑑**從寬**：只要知道「可能會受傷」即足，不必認識到具體損害內容（不必知道會骨折）

## 故意：
- 知＋欲，含**直接故意**（明知並有意使其發生）與**未必故意**（預見其發生，而發生不違背本意）
- 故意是針對**結果**，不是針對**行為**；否則開車上路也是「有意為之」，人人都是故意

## 申論技巧：
- 題目沒給線索的要件，當作符合，不必逐一涵攝；出題者想看你討論的才會給素材

## 📖 法條原文速查

> **民法 §184 I 前段**　因**故意或過失**，不法侵害他人之權利者，負損害賠償責任。

> **民法 §187 I**（要旨）　無行為能力人或限制行為能力人不法侵害他人權利，以**行為時有識別能力**為限，與法定代理人連帶負責。→ 識別能力作為侵權責任能力標準之明文依據（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲故意闖紅燈，撞傷行人乙，甲對乙身體權之侵害係出於故意或過失？」 | 通常是**過失**。故意以**結果**為對象；闖紅燈的故意不等於撞人的故意（通常是賭一把、並不想撞人） |
| 「侵權行為之責任能力以何為判斷標準？」 | **識別能力**＝能認識其行為可能造成損害之能力 |
| 「識別能力須認識到何種程度？」 | 認識「**可能造成損害**」即足，不須認識損害之具體內容（王澤鑑從寬） |
| 「無識別能力者得否成立過失侵權？」 | **否**。過失以「能注意」為前提，無識別能力即無注意能力，故先審責任能力 |
| 「未必故意之意義？」 | 預見結果之發生，且其發生**不違背本意**；與直接故意同屬故意 |

## 一、§184 I 前段審查流程

```
行為 → 權利受侵害 → 損害 → 因果關係 → 不法性 → 有責性
                                                  ├─ ① 責任能力（識別能力）← 先審
                                                  └─ ② 故意／過失
```

## 二、故意與過失的區分

| | 對結果的認識 | 對結果的意欲 |
|---|---|---|
| 直接故意 | 認識 | 有意使其發生 |
| 未必故意 | 認識（預見） | 發生不違背本意 |
| 過失 | 應注意、能注意而不注意 | 無意使其發生 |

## 三、案例：故意闖紅燈撞到人

1. 對「闖紅燈」這個**行為**：有故意
2. 對「撞到人」這個**結果**：一般是心存僥倖，既不想撞人，撞人也違背本意 → **過失**
3. 結論：侵權法上的故意過失，一律看**結果**，不看行為

## 四、答題提醒

- §184 I 前段要件多（行為、權利、損害、因果、不法、責任能力、故意過失），申論只寫**有爭議**的
- 題目沒提識別能力 → 當作具備，不要糾結
