# 民法21 筆記：詐騙匯入人頭帳戶之不當得利

## 案例：
- 丙把帳戶（存摺、印章、提款卡）交給詐騙集團成員甲；甲詐騙乙，要乙把錢匯入丙的帳戶
- 乙報案，帳戶凍結，乙剛匯入的 300 萬還在帳戶裡
- 問：乙得否依 §179 向**丙**（帳戶提供者）請求返還？

## 先問丙有沒有得利：
- 帳戶已全部交給詐騙集團 → 帳戶裡的錢實際由甲支配，可能認為丙**沒有得利**
- 就算承認丙有利益，還要問：利益是否來自乙有意識之給予、乙是對誰給付

## 三說（高院座談會）：
- **甲說（否定）**：給付型。乙被騙時想付錢的對象是**甲**，丙只是甲指定的一串帳號 → 給付關係在甲乙間，乙丙間僅有財產移動、不發生給付關係 → 乙只能向甲請求
- **乙說（肯定，研討結果採之）**：被詐騙而匯款，欠缺健全的給付意識 → **非給付型**；依權益歸屬說，錢應歸屬乙 → 乙得向丙請求
- **丙說（肯定）**：給付型，但從**受領人丙的客觀立場**判斷，匯款是乙有目的、有意識增加丙的財產 → 乙是對**丙**給付 → 乙得向丙請求（講義 283 頁）

## 老師的評價：
- 甲說在法律上比較正確：被詐欺而付錢，仍是有意識的給予，不是錢被搶走
- 乙說是解套：若「意思表示有瑕疵就是非給付」，會與給付／非給付的分類衝突
- 老師個人**較支持丙說**；採乙說或丙說都能讓被害人拿回看得到的錢

## 📖 法條原文速查

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

---

## 📋 實務見解速查

> **113 年法律座談會民事類提案第 4 號**（講義 280 頁）：丙將帳戶提供詐騙集團成員甲使用，甲詐騙乙將款項匯入該帳戶，乙得否依不當得利向丙請求返還？甲說否定（被指示人與領取人間不發生給付關係）；乙說肯定（受詐騙匯款之受領屬非給付型不當得利）；研討結果採**乙說**。（會議名稱、年度依字幕，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「被害人受騙匯入人頭帳戶，得否向帳戶提供者請求不當得利？」 | 座談會研討結果：**得**（乙說，非給付型） |
| 「否定說之理由？」 | 給付關係在被害人與**詐騙集團**之間 |
| 「丙說如何肯定？」 | 給付型，從**受領人客觀立場**認定被害人是對帳戶提供者給付 |
| 「解題第一步？」 | 先判斷帳戶提供者**是否受有利益** |

## 一、三說比較

| | 類型 | 乙是對誰給付 | 乙→丙 §179 |
|---|---|---|---|
| 甲說 | 給付型 | 甲（詐騙集團） | ✗ |
| 乙說（研討結果） | 非給付型 | 欠缺給付意識 | ✓ 權益歸屬於乙 |
| 丙說（老師支持） | 給付型 | 丙（受領人視角） | ✓ |

## 二、流程

```
丙有無受利益？（帳戶交出，可能否定）
   ↓ 假設有
利益是否來自乙有意識之給予？
├─ 是，對甲給付 → 甲說：向甲請求
├─ 是，對丙給付 → 丙說：向丙請求
└─ 否（受詐欺）  → 乙說：非給付型，向丙請求
```

## 三、為什麼這題值得記

- 事實很單純，卻正好測試「給付」的定義：有意識的給予，是看給付者的意識，還是受領人的客觀視角
- 這個「想著誰」的判斷方式，在三角關係（見民法21-筆記-10）會再用到
