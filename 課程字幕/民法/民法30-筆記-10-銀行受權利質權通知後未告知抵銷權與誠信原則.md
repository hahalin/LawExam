# 民法30 筆記：銀行受權利質權通知後未告知抵銷權與誠信原則

## 文章與考題背景：
- 陳忠五教授文章（講義 618 頁，字幕作「陳中武」「陳重物」）：金融機構受債權質權通知時，有無告知質權人其得行使抵銷權的義務
- 老師說去年考過；當時考生以為在考冷門的權利質權，其實核心是**誠信原則的操作**

## 事實：
- 甲在乙銀行有定存 → 甲對乙有 **A 債權**（存款返還）
- 乙銀行貸款給甲 → 乙對甲有 **B 債權**（貸款）
- 甲做工程積欠丙一筆錢 → 丙對甲有 **C 債權**
- 甲以 A 債權設定**權利質權**給丙，擔保 C 債權
- 丙通知乙銀行：A 債權已設定質權給我，甲要解約領錢時請阻止
- 乙銀行只回「知道了」，**沒有提到**自己對甲有 B 債權、將來可能抵銷 A
- 後來 C 債權不履行，丙要對 A 債權行使質權；乙主張以 B 抵銷 A

## 第一層：不告知而主張抵銷，是否違反誠信原則（§148 II）？
- 抵銷要件本身具備：甲乙互負債務、種類相同、均屆清償期
- 二審：銀行未告知，就不能主張抵銷（理由沒說清楚）→ 最高法院發回
- 陳忠五用兩個標準判斷：
  1. **信賴保護**：
     - 銀行只是沒說，沒有製造「不會抵銷」的假象
     - 若銀行明白表示「有 B 債權但不會抵銷」，事後又抵銷，才違反信賴
  2. **利益衡量**：
     - 對乙：抵銷可滿足 B 債權，好處大
     - 對丙：C 債權本身不消滅，只是從有擔保變無擔保，影響較小
- 結論：**不違反誠信原則，乙得主張抵銷**

## 第二層：銀行有沒有告知義務？
- 實務曾有行政指導要求銀行告知，但**沒有拘束力**
- 陳忠五認為可從誠信原則導出**告知義務**：
  - 對乙：告知成本很低
  - 對丙：資訊很重要，會影響要不要要求甲提供其他擔保
- 延伸爭點：銀行違反告知義務，是否構成**不作為侵權行為**？丙受的是**純粹經濟損失**，能否請求賠償？
- 文章兩層要分開：不告知**不影響抵銷**；但可能另外**負賠償責任**

## 📖 法條原文速查

> **§148 II**　行使權利，履行義務，應依**誠實及信用方法**。

> **§334 I**　二人互負債務，而其給付種類相同，並均屆清償期者，各得以其債務，與他方之債務，互為抵銷。（但書略）

> **§900**　稱權利質權者，謂以可讓與之債權或其他權利為標的物之質權。

> **§184 I**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。故意以背於善良風俗之方法，加損害於他人者亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「判斷權利行使是否違反誠信原則的方法？」 | **信賴保護**與**利益衡量** |
| 「單純沉默是否製造不抵銷的信賴？」 | 原則**否**；須有明示不抵銷之表示 |
| 「抵銷後質權人丙的 C 債權？」 | **不消滅**，只是喪失擔保 |

## 爭點層次表

| 層次 | 問題 | 陳忠五見解 |
|------|------|-----------|
| 一 | 不告知 B 債權，事後抵銷違反誠信？ | 不違反：未製造信賴；利益衡量乙大丙小 |
| 二 | 銀行有無告知義務？ | 有：告知成本低、資訊對質權人重要 |
| 延伸 | 違反告知義務的效果？ | 不作為侵權、純粹經濟損失能否請求 |

## 關係圖

```
甲 ──A 債權（定存）──→ 乙銀行
乙銀行 ──B 債權（貸款）──→ 甲
丙 ──C 債權──→ 甲，甲以 A 設權利質權給丙
丙通知乙 → 乙只說「知道了」
C 不履行 → 丙行使 A 之質權 → 乙以 B 抵銷 A？
```
