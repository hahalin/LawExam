# 民法06 筆記：透過第三人轉達的意思表示——實務看「有無轉達」vs 學說看「有無告知受領權」

> 來源：民法06 課程字幕 00:41:00 ~ 00:50:00

---

## 📖 法條原文速查

> **§94**　對話人為意思表示者，其意思表示，以相對人瞭解時，發生效力。
> **§95 I 前段**　非對話而為意思表示者，其意思表示，以通知達到相對人時，發生效力。

> **§1003**（日常家務代理權）
> I 夫妻於**日常家務**，互為代理人。
> II 夫妻之一方濫用前項代理權時，他方得限制之。但不得對抗善意第三人。

> **§103 I**（代理行為之效力）
> 代理人於代理權限內，以本人名義所為之意思表示，直接對本人發生效力。
> **§103 II**　前項規定，於應向本人為意思表示，而向其代理人為之者，準用之。→ 代受意思表示

---

## 📋 實務見解速查

> **最高法院 86 年台上字第 3742 號判決**（講義 151 頁註 65；字幕聽寫「86 年 37442 號」，字號請對講義）
> 上訴人限期給付欠租之催告，係向被上訴人之妻徐女為之，而非向被上訴人本人為之；徐女**未將該催告情事轉達**被上訴人，被上訴人無從獲知 → 催告**不生效力**。
> → 實務標準：有轉達才生效、沒轉達不生效

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「房東對承租人之妻口頭為終止租約／催告之意思表示，妻忘記轉達？」 | **實務**：未轉達 → 不生效力。**學說**：妻依 §1003 於日常家務有代理權 → 有**告知受領權** → 向妻為之即如向本人為之，妻瞭解時生效（§94），**轉達與否非所問** |
| 「學說的區分標準？」 | 受領者有無**告知受領權**：有 → §94 於其瞭解時生效；無 → 其為傳達人 → §95 非對話，看有無轉達（到達本人） |
| 「向公司警衛轉告股東建議？」 | 警衛無告知受領權；實務亦無轉達 → 兩說都**不生效** |
| 「向董事長秘書為意思表示？」 | 實務：看有無轉達。學說：秘書有告知受領權 → 瞭解即生效 |
| 「秘書休假時、半夜 LINE 秘書？」 | 王澤鑑：告知受領權**非永久**，非上班狀態即無受領權 → 等其轉達才生效 |

## 一、案例

#### 事實
甲（房東）要賣房出國，想提前終止與乙的不定期租約。乙上班不在，甲向乙的配偶丙說明並請她轉達。丙忘記了。甲事後問乙何時搬，乙說沒聽說。

#### 問題
甲對丙說 ＝ 對乙說嗎？終止的意思表示生效了嗎？

## 二、實務：只看有沒有轉達

```
丙有轉達 → 意思表示到達乙 → 生效
丙沒轉達 → 不生效（86 台上 3742）
```
- 老師：實務沒去探討丙的角色，直接以轉達與否為標準，學者認為不當。

## 三、學說（王澤鑑）：先問丙是誰

```
丙有「告知受領權」嗎？（能不能代替乙受領意思表示）
├── 有（代理人、秘書、特助……）
│     → 對丙為意思表示 ＝ 對乙為意思表示（§103 II 代受）
│     → 對話：丙瞭解時生效（§94）→ 有沒有轉達不重要
└── 無（警衛、路人）
      → 丙只是「傳達人」→ 等於非對話的意思表示（§95）
      → 看丙有沒有把話帶到（到達乙）
```

### 套回案例
- 夫妻於日常家務互為代理人（§1003）。給付欠租、終止租約是日常家務？老師：應認丙有代理權 → 有告知受領權 → 丙瞭解即生效，忘記轉達不影響。

### 對照：HTC 老股東
| 對象 | 實務 | 學說 |
|------|------|------|
| 對**警衛**說「轉告王雪紅」 | 沒轉達 → 不生效 | 警衛無告知受領權 → 看轉達 → 不生效 |
| 對**王雪紅的秘書**說 | 沒轉達 → 不生效 | 秘書有告知受領權 → 秘書瞭解即生效 |

### 王澤鑑的人性化補充：告知受領權不是永久的
- 秘書要上下班。休假中、下班後、半夜被 LINE → 此時他只是一般人，**無告知受領權** → 等他上班轉達才生效。
- 上班時間對秘書說 → 直接生效。
