# 民法27 筆記：解除權之行使與不得撤銷及催告消滅（§258、§257）

## 解除契約的體系：
- 解除事由：法定解除（§254～§256 給付遲延、給付不能；各論另有規定）、**合意解除**
- 合意解除是一個新的契約（解除契約的契約）
- 行使方法：§258
- 解除權消滅：§257、§262（§262 下講搭配 §259 與吳從周文章講）
- 效果：§259 回復原狀、§260 不妨礙損害賠償、§261 準用同時履行抗辯（效果與事由前面已講過，見民法25-筆記-05、06）

## §258 I、II：意思表示，且**全體對全體**
- 案例：乙丙丁三兄弟姊妹**共同共有**繼承來的土地，賣給甲；後來甲想解約
- 甲只寄存證信函給負責對外聯絡的大哥乙
- 除非丙丁曾授權乙代為受領，否則解除的意思表示**不生效力** → 要對乙丙丁**都**寄
- 買方若有甲、戊兩人，也要甲戊**一起**發
- 實務提醒：對方有五人就寄五份，不要省

## §258 III「不得撤銷」是什麼意思？
- 解為不得**任意撤銷**：法律本來就沒有任意撤銷權 → 這樣解等於沒寫
- 能否行使**法定撤銷權**（被詐欺、脅迫、錯誤，§88、§92）？
  - 否定說：文義寫不得撤銷 → 被詐欺也不能撤 → 違反表意自由
  - **肯定說（多數）**：仍可依法定撤銷權撤銷
- 學者：§258 III 是**立法錯誤**，應是「不得**撤回**」
  - 依 §95 I 但書，撤回通知同時或先時到達可以撤回
  - §258 III 要表達的是：解除的意思表示發出後，不能隨便反悔撤回

## §257：解除權因催告而消滅
- §254～§256 的解除權都**沒有期間**限制；解除權是**形成權**，不適用消滅時效
- 給付不能時隨時可解約，30 年後也行？→ 法安定性有問題
- §257 的控制方式：不限制解除權人，而是讓**他方**催告
  - 解除權未定期間 → 他方定相當期限，催告解除權人確答是否解除
  - 逾期未受解除通知 → 解除權**消滅**

## 📖 法條原文速查

> **§258**　I 解除權之行使，應向他方當事人以**意思表示**為之。II 契約當事人之一方有數人者，前項意思表示，應由其**全體**或向其**全體**為之。III 解除契約之意思表示，**不得撤銷**。

> **§257**　解除權之行使，未定有期間者，他方當事人得定相當期限，**催告**解除權人於期限內確答是否解除；如逾期未受解除之通知，解除權即**消滅**。

> **§95 I**　非對話而為意思表示者，其意思表示，以通知達到相對人時，發生效力。但**撤回**之通知，同時或先時到達者，不在此限。

> **§256**　債權人於有第二百二十六條之情形時，得解除其契約。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「出賣人為三位共同共有人，買受人僅對其中一人解約？」 | **不生效力**（全體對全體，§258 II） |
| 「解除契約的意思表示被詐欺，可否撤銷？」 | 多數說**可以**（法定撤銷權不受影響） |
| 「學者認 §258 III 應解為？」 | 不得**撤回** |
| 「解除權有無消滅時效？」 | **無**，形成權不適用時效 |
| 「解除權未定期間，他方如何使其消滅？」 | §257 **催告**確答，逾期未通知即消滅 |
| 「合意解除的性質？」 | 一個新的**契約** |

## 解除權之行使與消滅

```
解除契約
├── 事由：法定（§254～§256、各論）／合意（新契約）
├── 行使：§258 意思表示，全體對全體；不得撤銷（應為不得撤回）
├── 消滅：§257 催告；§262（下講）
└── 效果：§259 回復原狀、§260 損害賠償、§261 同時履行
```

| §258 III「不得撤銷」 | 結論 |
|---|---|
| 任意撤銷 | 本來就沒有，解釋無意義 |
| 法定撤銷（詐欺、脅迫） | 多數說仍可 |
| 撤回 | 學者：條文真正要禁止的是這個 |
