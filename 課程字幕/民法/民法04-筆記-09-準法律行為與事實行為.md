# 民法04 筆記：準法律行為與事實行為

> 來源：民法04 課程字幕 01:12:00 ~ 01:24:47

## 📖 法條原文速查

> **§229**（給付遲延）
> II 給付無確定期限者，債務人於債權人得請求給付時，經其**催告**而未為給付，自受催告時起，負遲延責任。→ 催告＝意思通知，效果（遲延）法律規定

> **§129 I ①**（時效中斷事由：請求）→ 請求＝意思通知，效果（中斷）法律規定

> **§426-2 II**（優先承買權之通知）
> 出賣人應將出賣條件以書面通知優先承買權人。優先承買權人於通知達到後**十日內**未以書面表示承買者，**視為放棄**。→ 觀念通知
> → 建議查閱最新六法原文

> **§1053**（裁判離婚之限制）
> 對於前條第一款、第二款之情事，有請求權之一方，於事前同意或事後**宥恕**，或知悉後已逾六個月，或自其情事發生後已逾二年者，不得請求離婚。

> **§1145 II**（繼承權喪失之宥恕）
> 前項第二款至第四款之規定，如經被繼承人**宥恕**者，其繼承權不喪失。

> **§802**（無主物先占）、**§811**（動產附合於不動產）、**§814**（加工）→ 事實行為；**§75**（無行為能力人之意思表示無效）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律行為與準法律行為之別？」 | 都靠意思表示觸發；**法律行為效果由當事人決定**，**準法律行為效果由法律決定** |
| 「催告之性質？」 | **意思通知**（準法律行為） |
| 「優先承買權之通知、股東會開會通知？」 | **觀念通知**（準法律行為） |
| 「宥恕之性質？」 | **情感表示**（準法律行為）；民法唯一有效果的情感是原諒 |
| 「準法律行為與事實行為之別？」 | 準法律行為要**主觀有意思**；事實行為**只要客觀行為**，做了就有效果 |
| 「無行為能力人得否為無主物先占取得所有權？」 | **得**。事實行為不需意思表示，不受 §75 影響 |
| 「配偶外遇，另一方宥恕後得否訴請離婚？」 | **不得**（§1053）。原諒觸發法律效果 |

## 一、法律行為 vs 準法律行為：效果誰決定

```
法律行為  ：意思表示 ──直接──→ 法律效果（當事人自己決定）
             把手錶交到你手上：賣？送？借？租？設質？寄託？→ 看我內心的意思
準法律行為：意思表示 ──觸發法律規定──→ 法律效果（法律事先決定好）
             我只負責表達，後面的效果法律幫我準備好
```

## 二、準法律行為三種

| 類型 | 內容 | 例 | 法律準備好的效果 |
|------|------|-----|------|
| **意思通知** | 表達一定的請求 | 催告 | §229 遲延責任；§129 時效中斷 |
| **觀念通知** | 告知一定的事實 | 優先承買權通知（§426-2 II）、股東會開會通知 | 十日內不回覆視為放棄 |
| **情感表示** | 告知一定的情緒 | **宥恕**（§1053、§1145 II） | 不得請求離婚；繼承權不喪失 |

### 情感表示：民法裡唯一有效果的情感是「原諒」
```
開心、生氣、難過 → 無效果
原諒（宥恕）
├── §1053：配偶外遇，你原諒了 → 不能再以此訴請離婚（律師要先問：你原諒過他嗎？）
└── §1145 II：繼承人隱匿遺囑喪失繼承權，被繼承人原諒 → 繼承權復活
→ 不是你決定「原諒但還是要離婚」，是原諒觸發法條，效果法律定
```
- 老師補充：宥恕是身分行為的例子，身分行為看意思能力；財產法上的例子（催告）更適合拿來理解無行為能力人的問題。

## 三、準法律行為 vs 事實行為：要不要「意思」

```
準法律行為：主觀要有意思 ＋ 效果法律定
事實行為  ：只要客觀行為，做了就有效果，不問你在想什麼
    §814 加工：甲把乙的石頭刻成雕像，價值高於石頭 → 甲取得所有權，不需「取得所有權的意思表示」
    §811 添附、§802 無主物先占 同理
```

### 分類的實益：無行為能力人能做什麼
```
需要意思表示的（法律行為、準法律行為）→ §75 無效 → 無行為能力人不能做
不需要意思表示的（事實行為）→ 無行為能力人可以做，照樣發生效果（先占取得所有權）
```

## 四、整張圖

```
表示行為（需要意思）
├── 法律行為：效果自己決定
└── 準法律行為：效果法律決定
      ├── 意思通知（催告）
      ├── 觀念通知（事實告知）
      └── 情感表示（宥恕）
非表示行為＝事實行為（不需意思，做就有效）：加工、添附、先占
```
