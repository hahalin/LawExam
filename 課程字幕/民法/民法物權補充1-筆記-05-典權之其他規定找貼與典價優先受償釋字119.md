# 民法物權補充1 筆記：典權之其他規定、找貼與典價優先受償（釋字119）

## 典權人的責任與處分
- **§916**：典權人對典物因**轉典或出租**所受損害，負賠償責任——不以故意過失為要件（無過失責任）
- **§917**：典權人得將典權**讓與**或**設定抵押權**；典物為土地、典權人在其上有建物者，不得分離處分
- 權利抵押三種：地上權、農育權、**典權**；不動產役權不行（§882）

## 典物滅失後的重建（§921、§922-1）
- 典物因**不可抗力**全部或一部滅失：除經出典人同意外，典權人只能在**滅失時滅失部分的價值限度內**重建或修繕
- 原典權對重建之物**視為繼續存在**（類似代位性）
- 例：房屋地震毀損，出典人想「反正不回贖了」，典權人想蓋得更好；未經同意只能回到原狀程度

## 找貼（§926）
- 典權存續中，**出典人**表示要把典物所有權讓與典權人 → 典權人得按**時價找貼**取得所有權
- 找貼**以一次為限**；之後地價再漲也不能再找
- 例：典價 1,200 萬，時價 1,300 萬 → 典權人再貼 **100 萬**取得所有權
- 只限出典人發動；典權人自己表示要買，不適用 §926，雙方重新議價

## 地屋同一人只典其一：推定租賃（§924-2）
- 土地及其上建物同屬一人，僅以土地或建物出典 → 典權人與建物所有人間，推定在典權或建物存續中有**租賃關係**
- 結構與 §425-1、§838-1、§876 相同（土地與房屋同屬一人）

## 抵押在先、典權在後：釋字119
- 甲 A 地（拍得 **500 萬**）：先設定第一順位抵押給乙 **300 萬** → 再出典給丙，典價 **200 萬** → 再設定第二順位抵押給丁 **100 萬**
- 乙實行抵押權，典權致無人應買或出價不足 → 執行法院得**除去典權**（§866）
- 價金分配：
  1. 乙 **300 萬**
  2. 丙的**典價 200 萬**，對登記在後的權利人**優先受償**
  3. 丁 **0**
- 執行法院發權利移轉證書時，依職權通知地政機關塗銷典權登記

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 典權人對轉典、出租所生損害 | 無過失**賠償責任**（§916） |
| 典權可否設定抵押 | **可以**（§882、§917） |
| 不可抗力滅失之重建範圍 | 滅失部分價值限度內，除經同意 |
| 找貼次數 | **一次** |
| 誰發動找貼 | **出典人**表示讓與 |
| 只出典地或屋 | 推定**租賃**（§924-2） |
| 典權被除去，典價受償順位 | 優先於**登記在後**之權利人（釋字119） |
