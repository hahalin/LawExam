# 民法23 筆記：債編總論之體系與章節標題之適用範圍

## 考試比重：
- 侵權行為、無因管理、不當得利約占債總考題一半，另一半是契約法
- 契約法條文瑣碎，課堂只講常考重點，不逐條講

## 債總後半段的地圖：
- **債之發生—契約**（§153～§166-1）：契約成立，快速帶過法條，選擇題考「契約有沒有成立」
- **債之標的**（§199～§218-1）：給付；種類之債、貨幣之債、利息之債、選擇之債、損害賠償之債（損害賠償已講過，跳過）
- **債之效力**（§220～§241）：債務不履行（給付不能、給付遲延、不完全給付），受領遲延、情事變更也放在這裡
- **債之保全**（§242～§245）：代位權、撤銷權，條文只有四條但**考試超級重要**，近年大法庭裁定集中在撤銷權
- **契約**（§245-1～§270）：解除、終止、雙務契約、射倖契約、第三人利益契約、第三人負擔契約
- **多數債務人及債權人**（§271～§293）：可分、連帶、不可分之債；條文像把數學公式寫成中文，選擇題會考計算
- **債之移轉**（§294～§306）：債權讓與（§294～§299）、債務承擔（§300～§306）
- **債之消滅**（§307～§344）：重點在清償、抵銷；提存（§326）、免除（§343）、混同（§344）帶過條文

## 章節名稱決定射程：
- 以「債」為名的章節，**所有的債都能用**，不限契約之債
- 只有「契約」那一款是專給契約用
- 讀法條時往上看章節標題，就知道這條的適用範圍

## 例子：
- 車禍後加害人應賠 100 萬卻遲遲不付 → 侵權行為之債也會**給付遲延**，可請求 §233 遲延利息
- 與有過失（§217）規定在債之標的的損害賠償之債 → 不只侵權行為，**債務不履行**（§226 損害賠償）也能減免
- 不當得利返還金錢 → 屬貨幣之債，§201、§202 可能適用
- 不當得利債權也能讓與第三人 → 適用債之移轉規定
- 考題多用契約設計，課堂也用契約舉例，但不要誤以為只限契約

## 📖 法條原文速查

> **§233 I**　遲延之債務，以支付金錢為標的者，債權人得請求依法定利率計算之**遲延利息**。但約定利率較高者，仍從其約定利率。

> **§217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

> **§226 I**　因可歸責於債務人之事由，致給付不能者，債權人得請求賠償損害。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「侵權行為損害賠償之債能否發生給付遲延？」 | **能**，債之效力規定適用於所有的債 |
| 「債務不履行之損害賠償可否適用 §217？」 | **可以**，與有過失規定在損害賠償之債 |
| 「債總中專為契約設的是哪一部分？」 | 債之效力第四款「契約」（§245-1～§270） |
| 「不當得利債權可否讓與？」 | **可以**，債之移轉適用於所有的債 |

## 體系圖

```
債編總論
├── 債之發生 ─ 契約 §153～§166-1（另有無因管理、不當得利、侵權行為）
├── 債之標的 §199～§218-1 ─ 種類／貨幣／利息／選擇／損害賠償之債
├── 債之效力
│   ├── 給付、遲延 §220～§241 ─ 債務不履行、受領遲延
│   ├── 保全 §242～§245 ─ 代位、撤銷 ★
│   └── 契約 §245-1～§270 ←── 唯一只給契約用
├── 多數債務人及債權人 §271～§293 ─ 會考計算
├── 債之移轉 §294～§306
└── 債之消滅 §307～§344 ─ 清償、抵銷為主
```
