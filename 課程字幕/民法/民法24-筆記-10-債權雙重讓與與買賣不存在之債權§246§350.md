# 民法24 筆記：債權雙重讓與與買賣不存在之債權（§246、§350）

## 爭點一：債權雙重讓與
- 事實：甲對乙有 A 債權；甲先賣給丙並**讓與**給丙，又賣給丁並讓與給丁
- 甲丙：買賣有效、債權讓與有效 → 丙成為 A 債權的債權人
- 甲丁：買賣契約**有效**（債權行為不以有處分權為必要）
- 問題：甲已失去處分權，第二次**債權讓與**（準物權行為）效力如何？

### 實務：類推 §246，無效
- §246 直接適用於債權契約；債權讓與是準物權契約，性質不同但同樣「以不能之給付為標的」→ **類推**
- **102 台上 1825**（講義 422 頁）：債權讓與為準物權行為，讓與時債權即移轉，讓與人喪失收取權與處分權；雙重讓與時，第二受讓人係受讓**不存在之債權**，原屬標的不能，類推 §246，第二次讓與**無效**

### 老師的批評：
- 「不存在」三個字錯了——A 債權好好地在丙身上，是**他人之債權**，不是不存在的債權
- 判決把「他人債權」與「不存在的債權」搞混
- 老師本講未展開正確解法；依其批評應從處分他人權利的角度思考（→ 建議查證）

### 民總複習：準物權行為
- 債權行為（負擔行為）：發生債權債務關係
- 處分行為：**物權行為**（物權得喪變更）、**準物權行為**（物以外的權利得喪變更，如債權、股票、票據）
- 債權讓與使債權變動 → 準物權行為

## 爭點二：買賣不存在之債權（110 年考過）
- 買賣不存在的**物**（燒掉的房子、不存在的車）→ §246 無效 → §247 信賴利益
- 買賣不存在的**債權**（虛構對某人有 20 萬債權，以 1 萬元讓給你）→ **契約有效**
  - 理由：§350 權利出賣人應**擔保權利確係存在**，違反依 §353 負債務不履行責任
  - 這些效果都以**契約有效**為前提；若依 §246 認為無效又要依契約負責，邏輯矛盾
  - 通說：§350、§353 為**特別規定**，排除 §246
- 老師：買賣的權利瑕疵擔保會再講一次

## 📖 法條原文速查

> **§246 I**　以不能之給付為契約標的者，其契約為無效。但其不能情形可以除去，而當事人訂約時並預期於不能之情形除去後為給付者，其契約仍為有效。

> **§294 I**（債權讓與）　債權人得將債權讓與於第三人。但左列債權，不在此限：……→ 建議查閱最新六法原文

> **§350**　債權或其他權利之出賣人，應擔保其權利**確係存在**。有價證券之出賣人，並應擔保其證券未因公示催告而宣示無效。

> **§353**　出賣人不履行第三百四十八條至第三百五十一條所定之義務者，買受人得依關於**債務不履行**之規定，行使其權利。

## 📋 實務見解速查

> **102 台上 1825**：第二受讓人係受讓不存在之債權，原屬標的不能，類推適用 §246，第二次債權讓與契約無效。→ 老師批評：應是他人之債權，非不存在之債權

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債權雙重讓與，第二次買賣契約效力？」 | **有效**（債權行為不以有處分權為必要） |
| 「第二次債權讓與，實務見解？」 | 類推 §246，**無效**（102 台上 1825） |
| 「債權讓與屬何種行為？」 | **準物權行為** |
| 「買賣不存在之物？」 | §246 **無效** → §247 信賴利益 |
| 「買賣不存在之債權？」 | **有效**，§350、§353 為特別規定 → 債務不履行 |

## 不存在之物 vs 不存在之債權

| | 不存在之物 | 不存在之債權 |
|---|---|---|
| 契約效力 | **無效**（§246） | **有效**（§350 特別規定） |
| 請求權基礎 | §247 | §353 → 債務不履行 |
| 賠償範圍 | 信賴利益 | 依債務不履行規定 |

```
債權雙重讓與
甲 ──賣＋讓與──→ 丙（取得 A 債權）
 └──賣＋讓與──→ 丁
       買賣：有效
       讓與：實務類推 §246 無效
             老師：債權在丙身上，是「他人」債權，不是「不存在」
```
