# 民法20 筆記：無因管理與無權代理及管理人死亡

## 無權代理修漏水案：
- 甲家漏水；乙未受託，以**甲的名義**與丙訂承攬契約，丙把漏水修好
- 丙能否向甲請求承攬報酬？ → 乙構成**無權代理**，契約效力未定
- **甲承認**：承攬契約在甲丙間生效 → 丙直接向甲請求報酬，與無因管理無關
- **甲拒絕承認**：契約不生效，丙不能向甲請求報酬 → 丙依 **§110** 向乙請求損害賠償

## 乙賠完丙，能否找甲？
- 乙主張：我是為甲好，找人修漏水才負擔這筆賠償 → 屬 §176 I 之「負擔債務」？
- 王澤鑑**肯定**：§176 I 的負擔債務，不只包括乙以自己名義訂約所負的報酬債務，也包括乙以甲名義**無權代理所負之賠償債務**
- 前提：仍須構成**適法無因管理**（乙出發點須為甲好、不違反甲之意思）

## 管理人死亡（進階）：
- 甲溺水，乙無義務下水救人；甲獲救，乙溺斃。乙的家人能向甲主張什麼？
- **§176 I** ✗：請求權是乙的權利；人的權利能力終於死亡，乙無從取得，繼承人也無從繼承（老師說明）
- **§192、§194** ✗：屬侵權行為規定，甲沒有不法侵害乙（見民法18-筆記-12）
- 楊芳賢：現行法下**無法求償**，屬法律漏洞，只能在**立法論**上調整
- 另說：**類推 §192**，讓間接被害人請求財產上損害（殯葬費、扶養費）；**不類推 §194**，因無因管理本來就沒有慰撫金
- 楊芳賢不採類推：此非侵權行為，兩者欠缺類似性

## 下一講：
- 進入**不當得利**（老師預計 3～4 堂），之後契約法；強迫得利在不當得利細講

## 📖 法條原文速查

> **§110**　無代理權人，以他人之代理人名義所為之法律行為，對於**善意之相對人**，負損害賠償之責。

> **§170 I**　無代理權人以代理人之名義所為之法律行為，非經本人**承認**，對於本人不生效力。

> **§176 I**　管理事務，利於本人，並不違反本人明示或可得推知之意思者，管理人為本人支出必要或有益之費用，或**負擔債務**，或受損害時，得請求本人償還其費用及自支出時起之利息，或**清償其所負擔之債務**，或賠償其損害。

> **§192 I**　不法侵害他人致死者，對於支出醫療及增加生活上需要之費用或殯葬費之人，亦應負損害賠償責任。→ II 法定扶養權利人之扶養費；§194 慰撫金

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「本人承認無權代理所訂承攬契約，承攬人如何請求？」 | 直接依**承攬契約**向本人請求，非無因管理 |
| 「本人拒絕承認，承攬人得向誰請求？」 | 依 **§110** 向無權代理人 |
| 「無權代理人之 §110 賠償債務，屬 §176 I 之負擔債務？」 | 王澤鑑：**肯定**，但須適法無因管理 |
| 「救人溺斃，其遺屬得依 §192、§194 向獲救者請求？」 | **否**，非侵權行為 |
| 「類推 §192 說是否包含慰撫金？」 | **否**，不類推 §194 |

## 一、無權代理修漏水

```
乙以甲名義 → 丙修漏水
├─ 甲承認（§170）→ 甲丙承攬契約 → 丙向甲請求報酬
└─ 甲拒絕承認
    ├─ 丙 → 乙：§110 損害賠償
    └─ 乙 → 甲：§176 I 負擔債務（王澤鑑肯定；須適法）
```

## 二、管理人死亡

| 主張 | 結論 | 理由 |
|---|---|---|
| 繼承 §176 I | ✗ | 乙死亡未取得權利 |
| §192、§194 | ✗ | 非侵權行為 |
| 類推 §192 | 部分學說 ✓ | 只限財產上損害 |
| 楊芳賢 | 無法求償 | 欠缺類似性，待修法 |
