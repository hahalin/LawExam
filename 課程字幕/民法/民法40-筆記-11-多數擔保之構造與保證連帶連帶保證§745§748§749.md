# 民法40 筆記：多數擔保之構造與保證連帶連帶保證（§745§748§749）

## 多數擔保的共同構造
- 一個債權有複數擔保：兩個保證人、兩個抵押物、或一個保證人一個抵押物
- **外部關係**（債權人乙的角度）：如何實現債權
- **內部關係**（債務人甲與各擔保人之間）：
  1. 內部**分擔**
  2. 內部**求償**（求償權、承受權）
- 這個架構套到共同抵押（§875 以下）、人保物保（§879）都一樣

## 保證連帶（§748）
- 甲向乙借 300 萬，乙分別與丙、丁訂保證契約
- 數人保證同一債務，除契約另有約定，**丙丁之間**連帶負保證責任；甲不在連帶之內
- 外部：
  - 未拋棄先訴抗辯權：乙須先對甲**強制執行而無效果**，才能找丙丁（§745）
  - 已拋棄（§746 ①）：只要甲**屆期不履行**即可找丙丁，不必先強制執行
- 丙丁之間，乙可自由選擇找誰、請求全部或一部（§273）

## 連帶保證（實務常見，須明示特約）
- 民法保證章沒有「連帶保證」類型；契約寫「本人願任連帶保證人」
- 甲丙丁**三人連帶**，丙丁與甲負同一責任
- 外部：清償期屆至，乙可**直接**找甲、丙或丁（§273），不必先向甲請求
- 實務愛用：少發存證信函、少一道執行程序

## 易錯：拋棄先訴抗辯權 ≠ 連帶保證
| 類型 | 乙何時可找保證人 |
|---|---|
| 一般保證（未拋棄） | 對甲**執行無效果**後 |
| 拋棄先訴抗辯權的保證 | 甲**屆期不履行**後（仍有補充性） |
| 連帶保證 | 清償期屆至即可**直接**找 |

## 內部關係（兩者相同）
- **分擔**：丙丁之間依 §280，有約定依約定，無約定**平均**（300 萬 → 各 150 萬）；甲負終局責任，不參與分擔
- **保證人對保證人**：求償權 §281 I、承受權 §281 II
- **保證人對債務人**：
  - 承受權：**§749**（清償限度內承受債權人對主債務人的債權）
  - 求償權：不在保證章，看有無委任 → 委任 **§546**；無委任 → 無因管理 **§176**
- 最高法院：連帶保證外部與甲負同一責任，內部本質仍是為甲擔保，甲負終局責任

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 數人保證同一債務，未約定 | 保證人間**連帶**（§748） |
| 連帶保證之成立 | 須**明示**約定 |
| 拋棄先訴抗辯權是否即為連帶保證 | **否**，仍有補充性 |
| 保證人對債務人之承受權 | §749 |
| 保證人對債務人之求償權 | 委任 §546／無因管理 §176 |
| 共同保證人內部分擔，未約定 | 平均（§280） |

## 圖解

```
保證連帶（§748）           連帶保證（特約）
   乙                          乙
   │ 先找甲（執行無效果／屆期）  │ 直接找任一人
   甲                     ┌───┼───┐
   │                      甲   丙   丁   ← 三人連帶
 ┌─┴─┐
 丙 ═ 丁  ← 只有保證人間連帶
```
