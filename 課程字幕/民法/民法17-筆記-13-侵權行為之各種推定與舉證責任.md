# 民法17 筆記：侵權行為之各種推定與舉證責任

## 為什麼要整理：
- 舉證責任通常被當成民事訴訟法的問題，但民事實體法的條文裡也藏著舉證責任分配
- 選擇題很愛考：「§191-1 推定了什麼？」「下列何者不受 §188 推定？」「下列何者不受 §187 推定？」

## 讀條文的方法：
- 找到條文中的**法律效果**（「負損害賠償責任」）
- 法律效果**之前**的構成要件 → **原告（被害人）**證明
- 法律效果**之後**（但書）的要件 → **被告**證明自己不需負責，也就是被推定的要件

## 推定一覽：
- 過失最基本：除 §185 I 後段外，各條至少都推定過失
- 有的多推定**因果關係**，有的多推定**不法**（欠缺），各條不同

## 📖 法條原文速查

> **§184 II**　違反保護他人之法律，致生損害於他人者，負賠償責任。但能證明其行為**無過失**者，不在此限。

> **§185 I 後段**　不能知其中孰為加害人者，亦同。

> **§187 II**（要旨）法定代理人如其**監督並未疏懈**，或縱加以相當之監督而**仍不免發生損害**者，不負賠償責任。

> **§188 I 但書**（要旨）僱用人**選任受僱人及監督其職務之執行已盡相當之注意**，或縱加以相當之注意而**仍不免發生損害**者，不負賠償責任。

> **§190 I 但書**（要旨）依動物之種類及性質已為**相當注意之管束**，或縱為相當注意之管束而**仍不免發生損害**者，不在此限。

> **§191 I 但書**（要旨）對於設置或保管**並無欠缺**、或損害**非因**設置或保管有欠缺、或於防止損害之發生**已盡相當之注意**者，不在此限。（原文請對六法）

> **§191-1 I 但書**（要旨）商品之生產、製造、加工、設計**並無欠缺**、或損害**非因該項欠缺所致**、或於防止損害之發生**已盡相當之注意**者，不在此限。（原文請對六法）

> **§191-2 但書**（要旨）於防止損害之發生，**已盡相當之注意**者，不在此限。（原文請對六法）

> **§191-3 但書**（要旨）損害**非由於**其工作、活動或使用之工具方法**所致**，或於防止損害之發生**已盡相當之注意**者，不在此限。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§185 I 後段共同危險行為推定什麼？」 | **只推定因果關係**（唯一不推定過失的） |
| 「§184 II 推定什麼？」 | **只推定過失** |
| 「§187、§188 推定什麼？」 | **過失＋因果關係**（監督疏懈、與損害間的因果） |
| 「§190 推定什麼？」 | **過失＋因果關係** |
| 「§191、§191-1 推定什麼？」 | **不法（欠缺）＋過失＋因果關係**，三者全推定 |
| 「§191-2 推定什麼？」 | **只推定過失** |
| 「§191-3 推定什麼？」 | **過失＋因果關係**（不推定不法） |
| 「下列何者不推定過失？」 | **§185 I 後段** |

```

```

## 二、從條文切出舉證責任（以 §187 為例）

```
§187 I：無行為能力人或限制行為能力人，不法侵害他人之權利，
        以行為時有識別能力為限，與法代連帶負損害賠償責任
        └─────────── 原告證明 ───────────┘└── 法律效果 ──┘
§187 II：監督並未疏懈／縱加相當監督仍不免發生損害 → 不負責
        └──────────── 被告（法代）證明 ────────────┘
```

| 原告（被害人）證明 | 被告（法代）證明 |
|---|---|
| 行為人是無行為能力人或限制行為能力人 | 監督並未疏懈（推翻過失推定） |
| 行為人不法侵害他人權利 | 縱加相當監督仍不免發生損害（推翻因果推定） |
| 行為人有識別能力 | |
| 被告是行為人的法定代理人 | |

- **§188 同理**：被害人證明受僱人因執行職務不法侵害他人權利；選任監督無過失、縱注意仍不免發生損害，由僱用人證明

---

## 三、注意區分兩種因果關係

- §187、§188、§190 推定的「因果」，是**監督（管束）疏懈**與損害之間的因果
- **行為（動物加害）與損害之間**的因果，仍屬原告要證明的構成要件（詳見筆記 14 §190 的拆解）
