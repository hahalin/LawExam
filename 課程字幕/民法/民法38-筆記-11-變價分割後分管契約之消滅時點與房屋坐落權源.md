# 民法38 筆記：變價分割後分管契約之消滅時點與房屋坐落權源

## 前提：分管契約的暫時性
- 分管契約或分管決定以**共有關係存在**為前提；共有關係消滅，分管隨之消滅（陳榮傳文章，講義 164 頁）
- **原物分配**：分割判決確定 → 共有關係消滅 → 分管同時消滅，沒有爭議
- **變價分割**：判決確定時還沒賣，共有關係延續到**變賣完成**才消滅 → 分管何時消滅？

## 爭點一：變價分割時，分管契約何時消滅
- **實務**（107 台上 879、107 台上 2074）：不論分割方法，**判決確定即終止**分管契約
  - 變價分割只是讓共有關係延續到變賣完成，分管不跟著延續
  - 之後除另有協議或決定，共有人不得繼續占用特定部分
- **陳榮傳**：分管跟著共有走，**變賣完成**、共有關係消滅時才消滅
- 差別在「判決確定 → 變賣完成」這段期間：
  - 實務：繼續占用 → 構成相當於租金的**不當得利**
  - 學說：仍有分管權源 → 不構成

## 案例
- 甲乙丙共有 A 地，依分管契約由丙在其上蓋房屋
- 法院判決**變價分割**確定；房屋仍坐落 A 地
- 依實務，丙自判決確定時起須返還相當於租金之不當得利；依陳榮傳，至變賣完成時才開始

## 爭點二：丁拍定後，丙的房屋能否主張坐落權源
- 丁拍定取得 A 地所有權，依 §767 I 前段、中段請求丙拆屋還地
- 分管契約此時已消滅（兩說都同意），丙無從以分管對抗
- 丙能否**類推 §425-1（推定租賃）或 §838-1（法定地上權）**？
  - **少數說（肯定）**：「土地及房屋同屬一人所有」包括土地共有人除房屋所有人外**尚有其他共有人**（土地甲乙丙、房屋丙）（最高法院 107 台上 797，字號建議查證；講義註 242）
  - **多數說、陳榮傳（否定）**：§425-1、§838-1 的前提是「**無中生有**」——同一人自己的地與屋之間本無任何約定，分開後才由法律補一個權源；共有人間本來就有分管約定，房屋能否坐落應依分管契約決定，分管消滅就欠缺權源，不屬相同事物，不能類推

> 來源：民法38 課程字幕 02:18:10 ~ 02:31:34；字幕「陳龍泉／陳龍傳」為「陳榮傳」、「七分管契約」為「其分管契約」之誤（建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 原物分配判決確定，分管契約 | 同時消滅 |
| 變價分割，分管契約消滅時點（實務） | **判決確定時** |
| 變價分割，分管契約消滅時點（陳榮傳） | **變賣完成**、共有關係消滅時 |
| 判決確定後續占用之效果（實務） | 相當於租金之不當得利 |
| 共有人依分管蓋屋，拍定後可否類推 §425-1、§838-1 | 多數說**否定**（有分管約定，非無中生有） |

## 時間軸

```
訂分管 ── 判決變價分割確定 ──────── 變賣完成（丁拍定）
           │                          │
  實務：   分管消滅 ← 這段使用＝不當得利 │
  學說：   分管仍在 ← 這段不構成       分管消滅
                                      │
                         丁 §767 請求丙拆屋還地
                         丙類推 §425-1／§838-1？多數說否定
```

## 兩說對照

| 項目 | 實務 | 陳榮傳 |
|---|---|---|
| 分管消滅 | 判決確定 | 變賣完成 |
| 理由 | 分割判決之形成力 | 分管依附共有關係 |
| 中間期間占用 | 不當得利 | 有權源 |
