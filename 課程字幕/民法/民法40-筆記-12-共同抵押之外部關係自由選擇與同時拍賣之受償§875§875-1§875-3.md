# 民法40 筆記：共同抵押之外部關係（自由選擇與同時拍賣之受償§875§875-1§875-3）

## 架構（內部關係在民法41 筆記-01 接續）
- **外部**：抵押權人怎麼選、怎麼受償 → §875、§875-1、§875-3
- **內部**：分擔 §875-2；抵押人間求償與承受 §875-4 ①；抵押人對債務人：委任 §546／無因管理 §176、承受 §879 I

## 自由選擇（§875）
- 為同一債權在數不動產上設定抵押權，未限定各不動產負擔金額 → 抵押權人得就**各個**不動產賣得價金，受債權**全部或一部**清償
- 不必先賣債務人的抵押物；選一塊、兩塊、全部都可以

## 同時拍賣時的受償順序
- 拍賣的抵押物中有**債務人所有**者 → 先就該抵押物價金受償（§875-1）
- 其餘抵押物、或都不是債務人的 → 價金超過債權額時，依 **§875-3 準用 §875-2**，按**價值比例**分擔

## 計算例（講義有多題可練）
- 甲向乙借 **900 萬**
- A 地（甲，債務人）市價 **300**；B 地（丙）市價 **600**；C 地（丁）市價 **900**

| 乙選擇拍賣 | 計算 | 乙受償 | 退還 |
|---|---|---|---|
| 只賣 C | 900 足額 | C 900 | — |
| A＋C | A 先受償 300（§875-1），C 補 600 | A 300、C 600 | C 300 → 丁 |
| B＋C | 無債務人之物；B：C＝600：900＝2：3 → 900×2/5、900×3/5 | B 360、C 540 | B 240 → 丙；C 360 → 丁 |
| A＋B＋C | A 先 300；剩 600 按 2：3 → 240、360 | A 300、B 240、C 360 | B 360 → 丙；C 540 → 丁 |

- 選擇題陷阱：「乙選擇賣 ABC，可就 C 受償 540 萬」→ **錯**，是 360 萬；只賣 BC 時才是 540 萬

## 📖 法條原文速查

> **§875-1**（債務人之物先受償）為同一債權之擔保，於數不動產上設定抵押權者，抵押物全部或部分同時拍賣時，拍賣之抵押物中有為債務人所有者，抵押權人應先就該抵押物賣得之價金受償。

> **§875、§875-3** → 建議查閱最新六法原文（§875-3 原文見民法41 筆記-01）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 共同抵押權人須先賣債務人之物？ | **否**，自由選擇（§875） |
| 同時拍賣，有債務人之物 | 先就該物受償（§875-1） |
| 同時拍賣，價金超過債權 | §875-3 準用 §875-2，按價值比例 |
| ABC 同賣，C 分擔多少 | 先扣債務人 A，再按比例分剩餘 |

---

## 計算步驟

```
1. 有沒有拍到債務人的抵押物？
     有 → 該物價金先受償（§875-1）
2. 剩多少債權？
3. 剩下的抵押物 → 價值比例（§875-3 準用 §875-2）
4. 各物分擔額 ＝ 剩餘債權 × 比例；價金超過分擔額的部分退還該物所有人
```
