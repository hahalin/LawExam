# 民法13 筆記：時效不完成 §139～§143——同一張圖：時效**即將完成時**遇到障礙無法行使權利中斷時效 → 障礙消滅後給一段延長時間（時效暫緩完成）；五條只差「障礙」與「延長多久」：§139 天災事變一個月、§140 繼承財產（繼承人不明）六個月、§141 無行為能力人／限制行為能力人**無**法定代理人六個月、§142 對**法定代理人**之權利一年（小孩告父母：性侵、家暴）、§143 夫妻間權利於婚姻關係消滅後一年（30 年前借先生的錢）

> 來源：民法13 課程字幕 00:17:25 ~ 00:30:00

---

## 📖 法條原文速查

> **§139**　時效之期間終止時，因天災或其他不可避之事變，致不能中斷其時效者，自其妨礙事由消滅時起，一個月內，其時效不完成。
> **§140**　屬於繼承財產之權利或對於繼承財產之權利，自繼承人確定或管理人選定或破產宣告時起，六個月內，其時效不完成。
> **§141**　無行為能力人或限制行為能力人之權利，於時效期間終止前六個月內，若無法定代理人者，自其成為行為能力人或其法定代理人就職時起，六個月內，其時效不完成。
> **§142**　無行為能力人或限制行為能力人，對於其法定代理人之權利，於代理關係消滅後一年內，其時效不完成。
> **§143**　夫對於妻或妻對於夫之權利，於婚姻關係消滅後一年內，其時效不完成。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「時效不完成之意義？」 | 時效**即將完成**時遇到障礙，無法請求或起訴以中斷時效 → 不能怪權利人 → 障礙消滅後給一段時間，時效暫緩完成。與中斷（重行起算）不同，只是延長末日 |
| 「疫情停班停課、法院關門，當天本要遞狀？」 | §139 天災或其他不可避之事變 → 妨礙事由消滅起**一個月**內不完成 |
| 「債務人死亡，繼承人有無不明，無從請求？」 | §140 → 繼承人確定、管理人選定或破產宣告起**六個月** |
| 「7 歲孩童之侵權行為損害賠償請求權將罹於時效，父母雙亡、新法代尚未就職？」 | §141（**無**法定代理人）→ 成為行為能力人或法代就職起**六個月** |
| 「國中生被養父性侵，成年後始提告，對方時效抗辯？」 | §142（對**法定代理人**之權利；不能期待法代幫他告自己）→ 代理關係消滅後**一年**內不完成 |
| 「妻 30 年前借先生 100 多萬開工廠，離婚後請求，先生主張逾 15 年？」 | §143 → 婚姻關係消滅後**一年**內不完成 → 離婚後一年內都可以要（還沒離婚更不用急） |
| 「§141 與 §142 之區別？」 | §141：**沒有**法代 → 六個月；§142：要告的對象**就是**法代 → 一年 |

## 一、一張圖懂五條

```
──────時效進行──────┤即將完成│ 遇障礙，不能請求／起訴 │障礙消滅│──延長期間──┤ 才完成
§139 天災事變           一個月
§140 繼承人不明         六個月（自繼承人確定／管理人選定／破產宣告）
§141 無法代             六個月（自成為行為能力人／法代就職）
§142 對法代之權利       一年（自代理關係消滅）
§143 夫妻間權利         一年（自婚姻關係消滅）
```

## 二、各條的故事

| 條 | 障礙 | 老師的例子 |
|---|---|---|
| §139 | 事實上障礙：天災、不可避事變 | 疫情全國停班停課、法院關門、律師等候通知 |
| §140 | 債務人死亡，對死人為法律行為無意義；繼承人是誰不知道（有無私生子、在哪、活著嗎） | 找到繼承人再給六個月 |
| §141 | 小孩沒有法代幫他主張（父母雙亡、新法代未就職） | 車禍小孩的賠償請求權 |
| §142 | 要告的人就是法代，不可能期待法代幫他告自己 | 13 歲被性侵，兩年時效 15 歲就完成 → 不合理 → 成年（代理關係消滅）後一年內都可告；家暴亦同 |
| §143 | 婚姻關係存續中不會對配偶提告 | 民國 70 幾年借先生 100 多萬，30 幾年後離婚才要，四個律師都說沒救 → 老師：還沒離婚，離婚後一年內都可以；證據留著就試 |

- §143 的教訓（老師自嘲）：知道答案也要留一手，不然當事人問完就不委任了。

## 三、後面接著講：§139 的「障礙」限事實上障礙 → 法律上障礙（撤銷仲裁訴訟進行中）只能**類推** §139（筆記 04）。
