# 民法36 筆記：盜贓遺失物回復之相對人與溯及效力（§949）

## 典型案例：先回復，再請求返還：
- 甲的 A 車被乙偷走，乙無權處分賣給善意的丙，丙依 §801＋§948 善意取得
- 甲直接對丙主張 §767 或 §179 → **敗訴**：甲已不是所有人，善意取得是丙受利益的法律上原因
- 正確做法分兩步：
```
① 甲對丙主張 §949（四要件都具備）→ 甲的所有權自喪失占有時起復活
② 甲再依 §767 I 前段 或 §179 請求丙返還 A 車
```
- §949 **不是請求權基礎**：條文只有「回復」，沒有「返還」，是法律狀態的復舊；答題不要寫「依 §949 請求返還」
- 延伸考點：丙被追回後，回頭向乙主張**權利瑕疵擔保**（§349＋§353）；要先把 §949 帶進去，才會有「第三人對標的物主張權利」

## 承租人主張 §949：回復的是「善意受讓前的狀態」：
- 甲把 A 車租給乙，被丙偷走賣給善意的丁
- 丁善意取得 → 甲的所有權、乙的租賃權都消滅
- 乙主張 §949 → 不是乙變成所有人，而是「按上一步」：**甲的所有權＋乙的租賃權**一起回復
- 之後乙依 §962 請求返還占有物，或甲依 §767、§179 請求

## 相對人：轉得人是否包括在內：
- 例：甲車被乙偷 → 善意的丙取得 → 丙再有權處分給丁，甲能否對丁主張 §949
| | 否定說 | 肯定說 |
|---|---|---|
| 代表 | 實務（法務部解釋偏此說）、鄭冠宇 | 王澤鑑、謝在全 |
| 方法 | **文義解釋**：須「善意受讓」**且**「現占有人」 | **目的性擴張**：及於自善意受讓人轉得之人 |
| 結果 | 丙已非現占有人、丁不是靠善意受讓取得 → 都不能主張 | 可對丁主張 |
| 理由 | 條文用語 | 法諺「**一時盜贓物，永遠盜贓物**」；贓物轉手機率極高，否則 §949 形同虛設（怪手被賣了六手的案例） |
- 老師個人從文義較支持否定說，但認為肯定說從立法目的看也說得通

## 二年是除斥期間：
- §949 是**形成權**：回復法律狀態不需對方同意或作為
- 條文雖有「請求」二字，仍不是請求權 → 二年是**除斥期間**，不是消滅時效（通說）
- 同類陷阱：§359「請求減少價金」也是形成權

## 法律效果：主張前、主張後分開看：
| 時段 | 爭議 | 通說 |
|---|---|---|
| 善意受讓時 → 主張 §949 前 | 原所有人歸屬說 vs **善意受讓人歸屬說** | 善意受讓人歸屬說：所有權與利益都歸受讓人，不是暫緩 2 年才取得 |
| 主張 §949 後 | 溯及說（從未失去）vs 不溯及說（失而復得） | **溯及說**：§949 II「自喪失其占有時起，回復其原來之權利」 |
- 溯及回復後，中間的使用利益原則上可依不當得利請求，但要注意 **§952** 善意占有人有使用收益權

## 📖 法條原文速查

> **§949 II**　依前項規定回復其物者，自喪失其占有時起，**回復其原來之權利**。

> **§349**　出賣人應擔保第三人就買賣之標的物，對於買受人不得主張任何權利。

> **§353**　出賣人不履行第三百四十八條至第三百五十一條所定之義務者，買受人得依關於債務不履行之規定，行使其權利。

> **§962**　占有人，其占有被侵奪者，得請求**返還其占有物**；占有被妨害者，得請求除去其妨害；占有有被妨害之虞者，得請求防止其妨害。

> **§952**　善意占有人於推定其為適法所有之權利範圍內，得為占有物之使用、收益。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「原占有人得逕依 §949 請求善意受讓人返還？」 | **否**，§949 只回復權利，再依 §767／§179／§962 請求 |
| 「§949 之二年為消滅時效？」 | **否**，除斥期間（形成權） |
| 「主張 §949 前，標的物所有權屬於誰？」 | 善意受讓人（善意受讓人歸屬說） |
| 「§949 回復之效力是否溯及？」 | **是**，自喪失占有時起（§949 II） |
| 「承租人主張 §949，承租人取得所有權？」 | **否**，回復出租人所有權與承租人租賃權 |
| 「依文義，§949 之相對人包括轉得人？」 | 否定說；王澤鑑、謝在全採肯定說 |
