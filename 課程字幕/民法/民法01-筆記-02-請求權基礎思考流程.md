# 民法01 筆記：請求權基礎思考流程（15 歲買車案）

> 來源：民法01 課程字幕 00:08:51 ~ 00:21:30

---

## 📖 法條原文速查

> **§367**（買受人之義務）
> 買受人對於出賣人，有**交付約定價金**及受領標的物之義務。

> **§13 II**（限制行為能力）
> 滿七歲以上之未成年人，有限制行為能力。

> **§77**（限制行為能力人之意思表示）
> 限制行為能力人為意思表示及受意思表示，應得法定代理人之允許。但**純獲法律上利益**，或依其年齡及身分、日常生活所必需者，不在此限。

> **§79**（未得允許之契約）
> 限制行為能力人未得法定代理人之允許，所訂立之契約，須經法定代理人之**承認**，始生效力。→ 效力未定

> **§767 I 前段**（所有物返還請求權）
> 所有人對於無權占有或侵奪其所有物者，得請求返還之。

> **§179**（不當得利）
> 無法律上之原因而受利益，致他人受損害者，應返還其利益。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「15 歲甲未得法代允許與乙訂買賣契約，效力？」 | **效力未定**（§77、§79），法代承認才生效 |
| 「乙交付 A 車給 15 歲甲，物權行為效力？」 | **有效**。對甲是純獲法律上利益（§77 但書）；物權行為獨立於買賣契約判斷 |
| 「買賣契約效力未定、物權行為有效，乙可依 §767 請求返還 A 車？」 | **不可**。所有權已移轉，乙非所有人 |
| 「同上，乙可依 §179 請求返還？」 | **可**。甲取得所有權（受利益）、買賣契約不生效（無法律上原因）、乙喪失所有權（受損害） |
| 「物權行為的效力是否受債權行為影響？」 | **否**，物權行為獨立性（無因性） |

## 一、思考流程（老師整堂課反覆唸的那句話）

```
誰告誰？（原告／被告）
    ↓
訴之聲明：原告要什麼？（民訴用語；實體法 = 訴求）
    ↓
請求權基礎為何？（依哪一條達到訴求）
    ↓
逐一涵攝：這條的每個要件，事實有沒有該當？
    ↓
該當 → 請求成立；不該當 → 換下一個請求權基礎
```

法官問話的順序就是這個：**人別訊問 → 訴之聲明 → 請求權基礎**。

## 二、案例：15 歲甲買車

### 事實
1. 甲 15 歲（限制行為能力人，§13 II），與乙訂立 A 車買賣契約，未得法代允許。
2. 乙已交付 A 車給甲。
3. 甲尚未付款。
4. 問：當事人法律關係如何？

### 第一步：誰會告誰？
- 甲拿到車了，不會告。**乙會告甲。**

### 第二步：乙要什麼？→ 兩個訴求輪流試

---

### 訴求一：請求買賣價金

| 項目 | 內容 |
|------|------|
| 請求權基礎 | §367 |
| 要件 1 | 買賣契約**有效** |
| 要件 2 | 買受人有給付價金義務 |

**涵攝要件 1**：
```
甲 15 歲 → 限制行為能力人（§13 II）
    → 訂立契約應得法代允許（§77 本文）
    → 未得允許 → 須經法代承認始生效力（§79）
    → 法代拒絕承認 → 契約不生效力
```
→ 要件 1 不該當 → **§367 請求失敗**。

---

### 訴求二：請求返還 A 車

#### 路徑 A：§767 I 前段（物上請求權）

| 要件 | 涵攝 |
|------|------|
| 乙是 A 車**所有人** | ？→ 要看物權變動軌跡 |
| 甲**無權占有** | ？ |

**物權變動軌跡**：
```
t1：乙是 A 車所有人
t2：乙交付 A 車給甲（物權行為：讓與合意 + 交付）
    → 這個物權行為有效嗎？甲是限制行為能力人……
```

**關鍵：§77 但書「純獲法律上利益」**
- 定義：**單純享受權利、不負擔義務**。
- 乙把 A 車所有權移轉給甲，甲只是取得所有權，**不因這個物權行為負任何義務**。
- 「甲要付價金」是**買賣契約**（債權行為）產生的義務，不是物權行為產生的 → **物權行為獨立性**，分開判斷。
- → 物權行為對甲是純獲法律上利益 → 不需法代允許 → **有效**。

```
買賣契約（債權行為）：效力未定 ✗
物權行為（移轉所有權）：有效 ✓ → 甲取得 A 車所有權 → 乙不再是所有人
```
→ §767 要件「乙是所有人」不該當 → **§767 走不通**。

#### 路徑 B：§179（不當得利）

| 要件 | 涵攝 | 結果 |
|------|------|------|
| 甲受有利益 | 取得 A 車所有權 | ✓ |
| 無法律上之原因 | 買賣契約不生效力，取得所有權沒有合法原因 | ✓ |
| 致他人受損害 | 乙喪失 A 車所有權 | ✓ |

→ 要件全部該當 → **乙得依 §179 請求甲返還 A 車**。

### 結論
- 乙 → 甲：§367 ✗、§767 ✗、**§179 ✓**。

## 三、這個案例要學會的兩件事

1. **解題不是判斷「有沒有效」就結束**。契約效力未定、物權行為有效——然後呢？重點永遠是「當事人要什麼、依哪條拿得到」。
2. **論述 = 法條解釋 + 事實放進去**。「純獲法律上利益」四個字要先解釋（單純享受權利不負擔義務），再把「乙移轉所有權給甲」放進去，才叫涵攝。不能寫「因為法條這樣規定所以結果這樣」。

```
法律解釋 → 要件的意義
    ↓
涵攝 → 事實放進要件
    ↓
解釋角度不同 → 結論不同 → 這就是「爭點」的來源
（文義、體系、目的、歷史、比較法、合憲性）
```

> 爭點不是背的，是理解「法條哪個字有模糊空間」。
