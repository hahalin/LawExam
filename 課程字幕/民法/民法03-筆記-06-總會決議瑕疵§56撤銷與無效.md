# 民法03 筆記：總會決議的瑕疵 §56——撤銷 vs 無效

> 來源：民法03 課程字幕 01:03:22 ~ 01:16:00

---

## 📖 法條原文速查

> **§56**（總會決議之撤銷與無效）
> I 總會之**召集程序或決議方法**，違反法令或章程時，社員得於**決議後三個月內**請求**法院撤銷**其決議。但**出席社員**，對召集程序或決議方法，**未當場表示異議**者，不在此限。
> II 總會決議之**內容**違反法令或章程者，**無效**。

> **§88、§92**（對照：以意思表示撤銷）
> 錯誤、被詐欺或被脅迫之意思表示，表意人得撤銷之。→ 意思表示到達即生效，不用打官司

> **公司法 §189-1**
> 法院對於前條撤銷決議之訴，認為其違反之事實**非屬重大且於決議無影響**者，得駁回其請求。→ 建議查閱最新條文

---

## 📋 實務見解速查

> **最高法院 107 年度台上字第 1957 號判決**（講義 73 頁註 86）：社團總會決議之程序瑕疵，若非屬重大且於決議無影響，得**類推適用公司法 §189-1**，由法院駁回撤銷之請求。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「召集程序或決議方法違法，效力？」 | **得撤銷**（§56 I），原則有效，撤銷後才無效 |
| 「決議內容違反法令或章程，效力？」 | **無效**（§56 II），自始、當然、確定無效，無待撤銷 |
| 「§56 I 之除斥期間自何時起算？」 | **決議之日**起三個月，**不是**知悉時起 |
| 「出席社員未當場異議，得否事後請求撤銷？」 | **不得**（§56 I 但書） |
| 「未出席之社員有無撤銷權？」 | **有**（通說），否則無從救濟 |
| 「§56 I 之撤銷如何行使？」 | **請求法院撤銷**（撤銷訴權），不能以意思表示撤銷；**判決確定**時始生效 |
| 「程序瑕疵非重大且於決議無影響？」 | 類推公司法 §189-1，法院得**駁回**（107 台上 1957） |
| 「主張決議無效，提何種訴訟？」 | **確認之訴**，不是撤銷之訴 |

## 一、兩種瑕疵、兩種處理

```
決議做成後有瑕疵
├── 程序瑕疵：召集程序（例：漏發開會通知）、決議方法（例：章程規定記名投票卻用舉手）
│     → §56 I 得撤銷：原則有效 → 經法院撤銷 → 變無效
└── 實體瑕疵：決議內容違反法令或章程
      → §56 II 無效：自始無效，無待撤銷 → 要打的是確認之訴
```

| | 得撤銷（§56 I） | 無效（§56 II） |
|---|---|---|
| 撤銷／宣告前 | **有效** | 本來就無效 |
| 怎麼主張 | 撤銷訴訟，判決確定才生效 | 確認訴訟（確認無效） |
| 典型例 | 漏發通知、表決方式違反章程 | 內容違法 |

## 二、§56 I 的四個重點

### 1. 誰有撤銷權
```
有出席 ＋ 當場異議   → 有
有出席 ＋ 未當場異議 → 無（§56 I 但書）：現場有機會處理卻沒處理，事後再翻有害決議安定
未出席               → 有（通說）：沒機會現場表達，再剝奪事後撤銷就無從救濟
```

### 2. 除斥期間：決議日起三個月
- 撤銷權是形成權 → 除斥期間。
- **從決議之日起算**，不是從知悉起算。決議後一個月才知道 → 只剩兩個月。
- 考題最愛寫「自社員知悉有瑕疵起三個月內」→ **錯**。

### 3. 方式：請求法院撤銷（撤銷訴權）

```
民法的撤銷有兩種
├── 用意思表示撤：§88 錯誤、§92 詐欺脅迫 → 撤銷之意思表示【到達】即生效
└── 用訴訟撤（條文寫「請求法院撤銷」）：§56 I、§244 → 要打撤銷訴訟，【判決確定】才生效
      → 用意思表示撤不掉；起訴還不夠、一審判決還不夠，要確定
```

### 4. 瑕疵非重大且於決議無影響 → 類推公司法 §189-1 駁回

#### 事實
100 人社團，10 人漏未收到通知。收到通知的 90 人中 70 人出席、50 人同意，通過議案。10 人請求撤銷。

#### 分析
```
要件全部符合：召集程序違法 ✓、未出席者有撤銷權 ✓、三個月內 ✓、請求法院 ✓
但：就算 10 人都來、都反對 → 80 出席、50 同意 → 一樣過
→ 瑕疵對決議結果無影響
→ 決議成本高（召集、場地、討論、投票），不踩紅線就尊重 → 類推公司法 §189-1，法院得駁回（107 台上 1957）
例外：你能說服法官「我到場就能把同意票拉到 10 票以下」→ 有影響 → 可撤銷
```
