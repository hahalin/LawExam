# 民法13 筆記：違約金與時效——107 年第 3 次民庭決議三個結論：① 按日計算之違約金**不是** §146 的從權利（利息因本金而生，違約金因**違約**而生，不違約就沒有）→ 價金罹於時效不使違約金跟著罹於時效；② 違約金時效 **§125 十五年**（不是每天違約一次，違約金債權於首日違約即發生、之後只是範圍每日增加，非 §126 定期給付）；③ 違約金計算至債務人**就價金為時效抗辯之前一日**為止（抗辯後得拒絕給付，不再違約）；數額驚人 → 酌減

> 來源：民法13 課程字幕 01:06:30 ~ 01:15:00（民法總則結束；權利之行使章節併入債編、物權講）

---

## 📖 法條原文速查

> **§146**　主權利因時效消滅者，其效力及於從權利。但法律有特別規定者，不在此限。
> **§127 ⑧**　商人、製造人、手工業人所供給之商品及產物之代價（二年）。
> **§125**　請求權，因十五年間不行使而消滅。……
> **§126**　利息、紅利、租金……及其他一年或不及一年之定期給付債權，其各期給付請求權，因五年間不行使而消滅。
> **§252**　約定之違約金額過高者，法院得減至相當之數額。

---

## 📋 實務見解速查

> **最高法院 107 年度第 3 次民事庭會議決議**（字號照字幕，建議查閱）：甲向乙公司購買商品，約定 97/12/31 清償，逾期按日給付價金千分之一違約金；乙 103/6/1 起訴請求價金及違約金，甲為時效抗辯。決議：價金請求權 §127 ⑧ 二年已罹於時效；違約金非價金之從權利，無 §146 之適用；違約金請求權時效為 §125 十五年；違約金計算至甲就價金為時效抗辯之前一日止。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「價金 97/12/31 清償期，§127 ⑧ 二年；103/6/1 起訴，價金部分？」 | 99/12/31 完成 → 甲得時效抗辯 |
| 「價金罹於時效，按日計算之違約金是否依 §146 隨同罹於時效？」 | **否**。利息是本金生出來的（有本金就有利息、不違約也有）→ 典型從權利；違約金是**違約**生出來的（乖乖付款就沒有）→ 發生原因不同 → 不是從權利 |
| 「違約金請求權時效？」 | **§125 十五年**。雖按日計算，但不是每天違約一次：97/12/31 不付，98/1/1 起違約，違約金債權**那天就發生**，之後每天只是**增加範圍**，不是每天發生一筆 1000 元的獨立債權 → 非 §126 定期給付 |
| 「違約金算到哪一天？」 | 自 98/1/1（清償期翌日）起，算到甲**就價金為時效抗辯之前一日**（103/5/31）。理由：甲一抗辯就可以拒絕給付價金，不再違約，就沒有違約金 |
| 「數額？」 | 100 萬 × 千分之一 ＝ 1000／日，一年 36.5 萬，近五年比價金還高 → 下一步 §252 酌減 |

## 一、利息 vs 違約金

| | 利息 | 違約金 |
|---|---|---|
| 發生原因 | 有本金就發生，與違約無關 | 違約才發生 |
| §146 從權利？ | 是（筆記 06） | **不是** |
| 時效 | §126 五年 | §125 十五年 |

## 二、時間軸

```
97/12/31 價金清償期 → §127 ⑧ 二年 → 99/12/31 完成
98/1/1   開始違約 → 違約金債權發生（之後每日 +1000 擴大範圍）
103/6/1  乙起訴；甲就價金為時效抗辯
         → 價金：甲得拒絕
         → 違約金：§125 十五年未完成；計算 98/1/1 ～ 103/5/31（抗辯前一日）→ 約 36.5 萬 × 5 年 → 酌減
```

## 三、三結論背下來

1. 違約金**不是** §146 的從權利。
2. 違約金時效 **§125 十五年**。
3. 違約金算到就價金為**時效抗辯之前一日**。
