# 民法11 筆記：無效的法律行為可否撤銷——一個法律行為兩種瑕疵（甲為限制行為能力人＋被乙詐欺），第三人丙「一半善意一半惡意」（知詐欺、不知甲未成年）；甲走行為能力（§77、§79 法代拒絕 → 無效）→ 丙就這個瑕疵是善意 → §801＋§948 善意取得 → §767 不通；甲改走 §92 撤銷 → 傳統實務：已無效之行為不得撤銷 → 王澤鑑：能不能撤銷與有無實益是兩回事，有撤銷實益即可撤銷 → 丙就詐欺是惡意 → 不能善意取得 → §767 I 前段返還

> 來源：民法11 課程字幕 01:44:10 ~ 01:52:40（講義 289 頁；104、105 年公證人、檢察官考試常考）

---

## 📖 法條原文速查

> **§79**　限制行為能力人未得法定代理人之允許，所訂立之契約，須經法定代理人之承認，始生效力。
> **§92 I**　因被詐欺或被脅迫而為意思表示者，表意人得撤銷其意思表示。……
> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。
> **§801、§948**　動產善意受讓。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「題型特徵？」 | 一個法律行為同時有**兩種瑕疵**（限制行為能力＋詐欺），第三人**知道一半**（知乙詐欺、不知甲未成年），法定代理人拒絕承認。問甲得否依 §767 向丙請求返還 A |
| 「甲主張限制行為能力，結果？」 | 甲乙法律行為（債權、物權）依 §77、§79 經法代拒絕 → 不生效力 → 乙未取得 A；乙丙買賣有效、物權行為無權處分效力未定；丙就「甲未成年」這個瑕疵是**善意** → §801＋§948 善意取得 → 甲 §767 **不通** |
| 「甲改主張被詐欺（§92 撤銷），實務？」 | **傳統實務：不得**。法律行為已因法代拒絕而無效，撤銷是讓有效變無效，無效之行為無從撤銷（87／244 判例脈絡：通謀虛偽無效者不得再依 §244 撤銷） |
| 「王澤鑑？」 | **得撤銷**。「能不能撤銷」與「有無撤銷實益」是兩件事；無效行為通常只是沒有撤銷實益，不是不能。本件**有實益**：甲撤銷 → 甲乙行為因撤銷而無效 → 乙未取得 A → 乙丙物權行為無權處分效力未定 → 丙就詐欺是**惡意** → 不能善意取得 → 甲 §767 I 前段請求返還 ✓ |
| 「學理淵源？」 | 18、19 世紀德國法學大辯論「無效之行為可否撤銷」，當時設想的正是一善意一惡意的案例 |

## 一、題目結構

```
甲（限制行為能力人）─被乙詐欺─ 將 A 賣給乙並交付
乙 → 將 A 轉賣丙並交付
丙：知道乙詐欺甲；不知道甲是限制行為能力人（一半善意一半惡意）
法定代理人知悉後拒絕承認
問：甲得否依 §767 I 前段向丙請求返還 A？
```

## 二、兩條路

| | 走限制行為能力 | 走 §92 詐欺撤銷 |
|---|---|---|
| 甲乙行為 | §77、§79 法代拒絕 → 不生效力 → 乙未取得 A | 傳統實務：已無效不得撤銷 ✗／王澤鑑：有實益得撤銷 → 撤銷而無效 → 乙未取得 A |
| 乙丙行為 | 買賣有效；物權行為無權處分效力未定 | 同 |
| 丙善惡意（就甲主張的瑕疵看） | 甲主張「我未成年」→ 丙對此**善意** | 甲主張「我被騙」→ 丙對此**惡意** |
| 善意取得 | ✓ 丙取得 → §767 不通 | ✗ → 甲 §767 ✓ |

- 最容易錯的地方：丙是善意還是惡意，要看**甲主張的是哪一個瑕疵**。甲從頭到尾講「我未成年」，就與詐欺無關。

## 三、王澤鑑的論點

- 無效行為「頂多沒有撤銷實益」，不等於「不能撤銷」。同時具備無效事由與撤銷事由時，能撤銷，只是通常沒必要。
- 本件撤銷有實益（讓丙變惡意），所以可以撤銷——這正是當年德國辯論設想的情形。
- 最高法院那則判例是針對 §87 通謀虛偽與 §244，不是針對這個情形。
