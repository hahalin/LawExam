# 民法09 筆記：§100 期待權的保護——當事人侵害期待權：實務（條件成就後 §100／§226）vs 王澤鑑（成就前即為獨立請求權；老師：信賴利益）vs 林誠二（君子條款、確認性規範）

> 來源：民法09 課程字幕 00:58:30 ~ 01:07:39

---

## 📖 法條原文速查

> **§100**（附條件法律行為當事人之責任）
> 附條件之法律行為**當事人**，於條件成否未定前，若有損害相對人因條件成就所應得利益之行為者，負賠償損害之責任。
> **§226 I**　因可歸責於債務人之事由，致給付不能者，債權人得請求賠償損害。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲以『乙考上律師』為停止條件贈與 A 車，條件成否未定前甲將 A 車賣予丙並交付，乙得否依 §100 請求賠償？」 | **實務**：條件未成就前契約未生效、無損害 → 不得；須待**條件成就後**依 §100 或 §226 請求。**王澤鑑**：§100 是期待權的特別保護，將期待**權利化** → 條件成就前即可依 §100 請求（否則 §100 成具文）；成就後依 §226 |
| 「§100 之損害性質？」 | 王澤鑑未明說；老師推論：契約未生效不可能有履行利益 → 應為**信賴利益**（為考試支出的補習、函授費用）；成就後 §226 才是履行利益 |
| 「林誠二對 §100 之定位？」 | **君子條款／確認性規範**：成就前無損害不能是請求權基礎，成就後與 §226 疊床架屋 → §100 只是**警告**當事人將來有賠償責任，不是請求權 |
| 「§100 適用對象？」 | 僅限附條件法律行為之**當事人**，第三人侵害不適用（筆記 06） |

## 一、案例
```
甲 ──附停止條件贈與 A 車（乙考上律師司法官）──→ 乙
條件成否未定前，甲把 A 車賣給丙並交付
乙在條件成就前、成就後，各有什麼權利？
```

## 二、三說

| | 實務 | 王澤鑑 | 林誠二 |
|---|---|---|---|
| 條件成就前 | **無權利**：契約未生效 → 無損害 → 無賠償 | **§100 獨立請求權**：期待權權利化，期待被破壞即可請求 | 無損害 → 不能是請求權基礎 |
| 條件成就後 | §100 或 §226 皆可（重疊） | §226 履行利益 | §226（§100 再用就疊床架屋） |
| §100 的定位 | 請求權，與 §226 重疊 | 條件成就前的信賴利益請求權（老師推論） | **確認性規範**：只是警告「你一言既出駟馬難追，將來拿不到就要賠」 |
| 批評 | 若只能等成就後，§100 變具文 | 損害是什麼？書上沒明說 | — |

### 老師補充：§100 的損害應是信賴利益
```
契約沒生效 → 沒有履行利益可言 → 若用履行利益想，會跟實務一樣找不到損害
乙為了考試報補習班、買函授 → 為「契約將來有效」所做的準備 → 典型信賴利益
→ 成就前 §100 信賴利益、成就後 §226 履行利益 → 兩邊都顧到
```
