# 民法37 筆記：添附之類型與所有權歸屬（§811～§815）

## 添附的目的：
- 物的狀態改變後（磚頭砌成牆壁），**重新分配物權秩序**
- 兩個原則：**物盡其用**（不要拆回來破壞價值）＋**有犧牲就補償**（補償見本講筆記-09）
- 只會發生在動產與動產、動產與不動產之間；土地與土地不會附合

## 三種類型：
| 類型 | 特徵 | 例 |
|---|---|---|
| **附合** | 結合後**不能分離**，或分離需費過鉅 | 磁磚貼上牆、鑽石鑲進戒指 |
| **混合** | 混在一起**不能識別**（可以分離但分不出來） | 甲的羊跑進乙的羊群 |
| **加工** | 產生**形態變更**，成為新物 | 石頭雕成石雕、白紙畫成畫 |
- 修復不是加工：椅子修好還是椅子
- 可輕易分離的不是附合：畫掛在牆上、電視鎖在牆上，拿下來就好

## 各類型的效果：
### 動產與不動產附合（§811）
- 動產成為不動產的**重要成分**（非經毀損不能分離或分離需費過鉅）
- **不動產所有人**取得動產所有權
- 例：甲的磁磚貼進乙的房屋 → 全歸乙

### 動產與動產附合（§812）
- 原則：各動產所有人按**附合時之價值**共有合成物
  - 例：牛奶倒進咖啡成拿鐵，兩人共有
- 例外：有**可視為主物**者 → 主物所有人取得全部
  - 例：鑽戒，鑽石價值高是主物 → 鑽石所有人取得整個鑽戒

### 混合（§813）
- **準用 §812**：原則共有，有可視為主物者歸主物所有人
- 主物怎麼認定：**以量取勝**
  - 例：甲的 1 隻羊跑進乙的 100 隻羊裡 → 101 隻都歸乙

### 加工（§814）
- 原則：屬**材料所有人**
- 例外：加工所增之價值**顯逾**材料之價值 → 屬**加工人**
- 數字例：市價 10 萬元的石頭雕成佛像，市價 30 萬元 → 增值 20 萬顯逾材料 10 萬，歸加工人
- 考題訊號：看到「**藝術家**」就想到 §814

### 其他權利隨同消滅（§815）
- 動產所有權因添附消滅 → 該動產上的**其他權利**（如動產質權）也消滅
- 字幕老師口誤將此條說成 §814，依條文校正為 §815

## 兩個細節：
1. **事實行為**：不需要有添附或取得所有權的意思 → 無行為能力人也能添附
   - 考題：受監護宣告、「發瘋的藝術家」在他人木頭上雕出高價作品 → 仍可因加工取得所有權
2. **不問故意過失**：故意、過失、無過失都一樣
   - 考題：甲想買乙門口的木頭被拒，連夜偷走雕成木雕 → 仍因加工取得所有權
   - 理由：制度目的是物權秩序重新分配，不管行為人主觀；被犧牲的人另循 §816、§184 救濟

## 📖 法條原文速查

> **§811**　動產因附合而為不動產之**重要成分**者，**不動產所有人**，取得動產所有權。

> **§812**
> I　動產與他人之動產附合，非毀損不能分離，或分離需費過鉅者，各動產所有人，按其動產**附合時之價值，共有**合成物。
> II　前項附合之動產，有**可視為主物**者，該**主物所有人**，取得合成物之所有權。

> **§813**　動產與他人之動產混合，**不能識別**，或識別需費過鉅者，**準用**前條之規定。

> **§814**　加工於他人之動產者，其加工物之所有權，屬於**材料所有人**。但因加工所增之價值**顯逾材料之價值**者，其加工物之所有權屬於**加工人**。

> **§815**　依前四條之規定，動產之所有權消滅者，該動產上之**其他權利，亦同消滅**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「磁磚貼於他人房屋，所有權歸誰？」 | **不動產所有人**（§811） |
| 「兩人之動產附合，無主物可言？」 | 按附合時價值**共有** |
| 「鑽石鑲入他人戒指？」 | 鑽石為主物，鑽石所有人取得全部 |
| 「混合之效果？」 | **準用 §812** |
| 「加工物原則歸誰？」 | **材料所有人**；增值顯逾材料價值歸加工人 |
| 「無行為能力人加工，得否取得所有權？」 | **得**，事實行為 |
| 「竊取他人木材雕刻，得否因加工取得所有權？」 | **得**，不問故意過失 |
| 「動產附合後其上之質權？」 | **隨同消滅**（§815） |
