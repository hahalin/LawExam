# 民法22 筆記：指示給付受領人之類推適用（§183）

## 案例（107 年最高法院判決，講義 340 頁、註 532）：
- 乙向甲買 A 地；乙年事已高，怕買賣拖到自己過世，土地增值稅變成遺產稅
- 乙指示甲：直接把 A 地移轉登記給我兒子丙
- 甲先移轉給丙，兩人再談價金，結果談不攏，**買賣契約不成立**
- 丙：土地是我爸送我的，你去找我爸
- 判決書當事人為真名，本筆記改稱甲乙丙

## 給付關係：
- 甲＝被指示人（債務人）、乙＝指示人（債權人）、丙＝領取人
- 給付關係看給付者**想給誰**，不是實際交給誰：甲想履行對乙的買賣義務 → 給付關係在**甲乙**、**乙丙**之間（見民法21-筆記-10）
- 甲丙間沒有給付關係 → 甲對丙不成立給付型不當得利

## 甲對乙 §179：不成立
- 利益已轉到丙身上，不在乙
- 乙丙是贈與，乙沒有因贈與受有任何利益 → 乙未得利

## 法院：類推 §183，甲得向丙請求返還
- 利益狀態與 §183 相同：甲失去 A 地又無 §179 可用；丙無償取得 A 地
- 高雄分院 106 重上更一 10（最高法院 107 年判決維持）：涉及三人間給付關係，指示人無從返還利益，而指示人與領取人間為**無償行為**，且由財產損益變動觀之，領取人係直接由被指示人取得利益 → 參考 §183 立法精神，被指示人得直接向領取人請求返還，較符公平
- 與無償無權處分類推 §183 同一邏輯（見民法22-筆記-08）

## 林誠二的批評：
- 乙丙有贈與契約，乙用甲的土地履行贈與債務 → 乙受有**債務消滅**的利益
- 甲向乙請求償還 A 地價額即可；丙受贈並已登記，土地就是丙的，不必動到丙

> 來源：民法22 課程字幕 01:35:58 ~ 01:46:10（講義 340 頁、註 532）；最高法院判決字號字幕僅作「107 年 14 號」，建議查證

## 📖 法條原文速查

> **§183**　不當得利之受領人，以其所受者，無償讓與第三人，而受領人因此免返還義務者，第三人於其所免返還義務之限度內，負返還責任。

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

---

## 📋 實務見解速查

> **臺灣高等法院高雄分院 106 年度重上更一字第 10 號判決**（講義註 532，最高法院 107 年判決維持，要旨）：被指示人依指示人之指示對領取人為給予行為，領取人與被指示人間並無給付關係，無從成立不當得利。惟參考 §183 之立法精神及不當得利之法制建構，於涉及三人間給付關係，如指示人無從返還其利益，而指示人與領取人間之法律關係為無償行為，且由財產損益變動觀之，領取人係直接由被指示人處取得利益，雖兩者間無給付關係，仍應認被指示人得直接向領取人請求返還利益，較符公平。（要旨改寫，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「指示給付之給付關係存在於何人之間？」 | **被指示人－指示人**、**指示人－領取人** |
| 「被指示人得否對領取人主張給付型不當得利？」 | **否**，兩者間無給付關係 |
| 「指示人無償轉贈領取人，被指示人對指示人 §179？」 | 實務：指示人**未得利**，不成立 |
| 「被指示人如何向無償領取人請求？」 | 實務：**類推適用 §183** |
| 「林誠二見解？」 | 指示人受有債務消滅利益，向指示人請求價額 |

## 一、三角關係圖

```
        乙（指示人、父）
       ↗ 買賣（不成立）  ↘ 贈與（無償）
甲（被指示人）── 移轉 A 地 ──→ 丙（領取人、子）
甲→乙 §179：乙未得利 ✗
甲→丙 給付型 §179：無給付關係 ✗
甲→丙 類推 §183：✓（107 年判決）
```

## 二、兩種處理

| | 實務（類推 §183） | 林誠二 |
|---|---|---|
| 乙是否得利 | 否 | 是（債務消滅） |
| 甲請求對象 | 丙 | 乙 |
| 甲請求內容 | 返還 A 地 | 償還 A 地價額 |
