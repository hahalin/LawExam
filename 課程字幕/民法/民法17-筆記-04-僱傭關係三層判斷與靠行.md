# 民法17 筆記：僱傭關係三層判斷與靠行

## 三層判斷（不是三說，是思考順序）：
- ①**法律上**僱傭關係：有僱傭契約就過關，不用再往下
- ②**事實上**僱傭關係：法律上沒有，但真的在為他人服勞務；用在僱傭契約有瑕疵時（例：未成年人未得允許打工，依 §77、§79 效力未定，法代拒絕承認即確定不生效力；字幕老師說「無效」）
- ③**客觀上**僱傭關係：法律上、事實上都沒有，最後才看「看起來像不像」

## 寫作提醒：
- 「甲是乙的員工，所以客觀上有僱傭關係」是錯誤論述：真的是員工就不必看起來像
- 不要每題都把客觀說拿進來，字裡行間會暴露邏輯謬誤

## §188 的立法目的：
- **可以告不等於拿得到錢**：贏了判決、拿判決確定證明書去執行，結果受僱人名下沒有財產
- 僱用人利用受僱人賺錢，出事卻躲在後面不合理 → §188 把僱用人拉進來，多一個求償對象
- 目的在**保護被害人** → 要件盡量從寬解釋；若只認法律上僱傭關係，公司與員工串通說「他是自己來幫忙的」就逃掉了

## 靠行：
- 甲買遊覽車靠行 A 交通公司，車身漆 A 公司名稱；甲自僱司機乙，乙撞傷丙
- 丙對乙 §184、對甲 §188 都沒問題；但丙想告資力較好的 **A 公司**
- A 與乙：無僱傭契約（契約在甲乙間），乙也不是為 A 服勞務 → 法律上、事實上都沒有
- 乙開著有 A 公司名稱的車 → **客觀上**足使人認為是 A 的司機 → A 負 §188
- 理由：交通公司收取靠行費獲利，就要承擔被告 §188 的風險（**風險分配**）
- 反思：公司對靠行司機其實沒有管制能力，責任是否過寬，可以思考

## 📖 法條原文速查

> **§188 I 前段**　受僱人因執行職務，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。

> **§77**（要旨）　限制行為能力人為意思表示及受意思表示，應得法定代理人之允許；**§79**（要旨）　未得允許所訂立之契約，須經法定代理人之承認，始生效力。（原文請對六法）

## 📋 實務見解

> **靠行判決**（字幕唸「92779 號」，講義 154 頁，字號請對講義）：靠行車輛外觀標示交通公司名稱，客觀上足使人認為司機係為該公司服勞務，交通公司應負 §188 責任。→ 老師：109 年律師、司法人員考過，「考出來不能不會」

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§188 僱傭關係如何判斷？」 | 依序：**法律上 → 事實上 → 客觀上**，前一層過關就不必往下 |
| 「未成年人未得允許打工，法代拒絕承認，雇主是否負 §188？」 | 仍有**事實上**僱傭關係 → 是 |
| 「靠行車司機肇事，靠行之交通公司應否負 §188？」 | **應負**：客觀上足認為其受僱人（實務） |
| 「§188 要件為何從寬解釋？」 | 立法目的在**保護被害人**，增加求償對象 |
| 「交通公司對靠行司機無指揮監督，為何仍負責？」 | 收取靠行費獲利 → **風險分配** |

## 一、三層判斷流程

```
法律上有僱傭契約？── 有 ──→ 僱傭關係 ✓（停）
        │無
事實上為其服勞務？── 有 ──→ 僱傭關係 ✓（例：未成年人打工契約不生效力）
        │無
客觀上看起來像？──── 像 ──→ 僱傭關係 ✓（例：靠行）
        │不像
        ✗ 不成立 §188
```

## 二、靠行案例的當事人

| 關係 | 法律上 | 事實上 | 客觀上 |
|---|---|---|---|
| 甲（車主）— 乙（司機） | 僱傭契約 ✓ | — | — |
| A 公司 — 乙 | ✗ | ✗（為甲服勞務） | ✓（車身 A 公司名稱） |

## 三、為什麼丙要告 A

- 告甲、告乙也可以，但拿到錢的機率不如告公司：有資產、有規模、受政府管制
- 多一個被告，就多一份拿到錢的機會
