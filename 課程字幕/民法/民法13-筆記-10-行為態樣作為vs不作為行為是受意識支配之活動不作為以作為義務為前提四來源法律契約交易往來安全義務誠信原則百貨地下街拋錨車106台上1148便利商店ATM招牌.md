# 民法13 筆記：行為的態樣——行為＝受意識所支配的活動（夢遊、癲癇踩油門不是行為）；作為（積極）vs 不作為（消極）；不作為原則不成立侵權，須以**作為義務**為前提；作為義務四來源：① 法律（消防員、父母對子女）② 契約（救生員、船長）③ **交易往來安全義務**（開啟危險者應防範危險：百貨地下街滑倒、拋錨車未放三角錐、106 台上 1148 便利商店 ATM 招牌）④ 誠信原則／公序良俗（筆記 11）

> 來源：民法13 課程字幕 01:31:30 ~ 01:47:00（講義 18 頁）

---

## 📋 實務見解速查

> **最高法院 106 年度台上字第 1148 號判決**（講義 18 頁，字號照字幕）：侵權行為之成立須有加害行為，所謂行為包括作為與不作為；其以不作為侵害他人權益而成立侵權行為者，以作為義務之存在為前提。在毫無關係之當事人間，原則上固無防範損害發生之作為義務；惟基於法令規定、當事人契約、服務關係，以及自己危險前行為等，亦可成立不作為之侵權行為。**經營商店者開啟往來交易**，引起正當信賴，基於侵權行為法旨在防範危險之原則，對於其管理能力範圍內之營業場所及周遭場地之相關設施，當然有注意義務；該等設施遭破壞時，即應採取適當措施，以降低或避免危險發生之可能性。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「行為？」 | **受意識所支配的活動**。吃安眠藥夢遊、癲癇發作踩油門 → 無意識 → 不是行為 |
| 「不作為得否成立侵權行為？」 | 原則**不得**（人與人之間原則上沒有作為義務：路人昏倒、泳池有人溺水，我可以走開）。例外：有**作為義務**時，不作為構成侵權 |
| 「作為義務之來源？」 | ① **法律**：消防員救火、父母帶發燒的小孩就醫（鄰居沒有這個義務）② **契約**：救生員、船長對遇難者（韓國沉船船長落跑被判刑）③ **交易往來安全義務**：開啟危險者應防範危險 ④ **誠信原則／公序良俗** |
| 「交易往來安全義務？」 | 無形的作為義務，沒有明確法律或契約，來自你在社會上**開啟了危險**就應防範危險發生。百貨公司地下街蹭冷氣（無契約）滑倒 → 百貨公司開啟供人往來的環境，就算湯是別的顧客打翻的也要負責 → 所以美食街滿滿清潔人員；車子拋錨未打雙黃燈、未放三角錐 → 後車追撞 → 違反安全義務 |
| 「便利商店外 ATM 招牌掉落，路人撿起放在公共電話上；店長僅電話報修未收進倉庫；乙打電話時招牌掉落砸傷？」 | 店長：我什麼都沒做（招牌不是我弄掉、不是我放的、我有報修）。最高法院：不是問你做了什麼，是問你**沒做什麼**——經營商店者開啟往來交易，對管理能力範圍內之營業場所及周遭設施有注意義務，知道招牌有掉落危險卻不收進倉庫 → 違反交易往來安全義務 → **不作為侵權**（乙對店長 §184、對公司 §188） |

## 一、行為的兩個面向

```
態樣：作為（意識支配下積極為之）／不作為（意識告訴我不要做）
主體：自然人／法人（筆記 12）
```

## 二、不作為侵權的結構

```
原則：人與人之間無作為義務 → 不作為不成立侵權
例外：有作為義務 → 應作為而不作為 → 不作為侵權
作為義務來源：法律 → 契約 → 交易往來安全義務 → 誠信原則／公序良俗（依序檢討）
```

| 來源 | 例 | 反例（無義務） |
|---|---|---|
| 法律 | 消防員救火；父母帶發燒子女就醫（保護教養義務） | 鄰居不救火；隔壁小孩發燒不關你的事 |
| 契約 | 救生員對泳客；船長對遇難旅客 | — |
| 交易往來安全義務 | 百貨地下街地板濕滑；拋錨車未警示；便利商店招牌 | 毫無關係的路人 |
| 誠信原則 | 山谷喊救命只有你能打電話（筆記 11） | — |

## 三、106 台上 1148 的論述順序（對著體系看）

1. 侵權行為之成立須有加害行為 → 要件①行為。
2. 行為包括作為與不作為 → 態樣。
3. 不作為以作為義務為前提 → 原則無。
4. 作為義務來源：法令、契約、服務關係、**自己危險前行為**（並排停車、地板濕滑、招牌）。
5. 經營商店者**開啟往來交易**→ 對營業場所及周遭設施有注意義務 → 設施遭破壞應採適當措施。

## 四、思考起點：先契約再侵權

- 地下街案若有點餐／消費 → 環境維護是契約**附隨義務**，往契約找就好；完全沒消費（蹭冷氣、借廁所）才需要交易往來安全義務。
