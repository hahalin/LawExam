# 民法15 筆記：考題解析詐欺訂約與意思決定自由

## 題目要旨：
- 補充講義為今年國考民法考題；老師講第一題第（一）小題，第（二）小題考**表見代理**（民總上過，自行看），第一題第（三）小題與第二大題留待物權、身分法時自看（講義附有老師寫的答案與實務註釋）
- 事實：甲謊稱 A 地已劃入市地重劃範圍並出示不實文件，丙以市價四倍（4,000 萬）購買，事後發現只值 1,000 萬
- 問：丙以被詐欺為由，依 **§184 I 前段**請求甲賠償 3,000 萬，有無理由

## 審題方法：
- 題目已指定請求權基礎，就照前提解；寫 §92、§179 不會是主軸，頂多補在後面
- 構成要件展開後先「檢查」：無爭議的要件一句帶過，有爭議的才停下來論述
- 本題無爭議：謊稱＝侵害行為、詐欺必為**故意**、差額說下損害 3,000 萬、因果關係、無阻卻違法事由、有責任能力
- 唯一爭點：**意思決定自由（表意自由）是不是「權利」**

## 老師解法：
- 四段式：①法條＋「權利」定義，帶出爭點 ②抽象見解（肯否二說理由）③依兩說各自涵攝 ④提出己見
- 老師採**否定說**（多數說、王澤鑑現說）；肯定說也可以，重點在說理與涵攝

## 考試趨勢：
- 近年題目「反璞歸真」，暗器題變少，回歸基本爭點；法條要熟、要建立自己的民法思考邏輯，不能只背爭點

## 📖 法條原文速查

> **民法 §184 I**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。故意以背於善良風俗之方法，加損害於他人者亦同。

> **民法 §92 I 前段**　因被詐欺或被脅迫而為意思表示者，表意人得撤銷其意思表示。

> **民法 §179 前段**　無法律上之原因而受利益，致他人受損害者，應返還其利益。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「被詐欺而訂約，得否依 §184 I 前段請求損害賠償？」 | 關鍵在**意思決定自由是否屬權利**：肯定說 → 前段 ✓；否定說 → 前段 ✗，改走**後段**（詐欺＝故意背俗）或 §92 撤銷＋§179 |
| 「意思決定自由屬於 §184 I 前段之權利？」 | **肯定說**：早期王澤鑑、陳聰富（自由權含意思自由）、陳忠五；**否定說**：王澤鑑現說、**多數說**（意思自由空泛，保護範圍無法界定，過度限制行為自由） |
| 「否定說下，被詐欺人如何救濟？」 | §184 I **後段**（故意以背於善良風俗之方法）；或依 **§92** 撤銷後依 **§179** 請求返還。過失侵害意思自由則**不負**侵權責任 |
| 「詐欺可能出於過失？」 | **不可能**。詐欺必為故意；不小心講錯、過失遺漏資訊是過失，不叫詐欺 |
| 「本題丙之損害如何認定？」 | 差額說：付 4,000 萬、取得市價 1,000 萬之土地 → 總財產減少 **3,000 萬** |

| 要件 | 本題 | 處理 |

| 侵害行為 | 謊稱、出示不實文件 | 帶過 |

## 二、肯否二說

```
意思決定自由是不是 §184 I 前段之「權利」？
│
├── 肯定說（早期王澤鑑、陳聰富、陳忠五）
│     自由權不只身體自由，也包含意思自由
│     → §184 I 前段成立，丙得請求 3,000 萬
│     （陳忠五另有權利與利益無區別必要之看法）
│
└── 否定說（王澤鑑現說、多數說；老師採）
      意思自由概念空泛，保護範圍無法界定
      權利保護越大，行為自由限縮越大
      → 過失侵害意思自由不負責
      → 故意者走 §184 I 後段；另有 §92＋§179
```

- 老師提醒：王澤鑑見解**有改變**，是本題爭點來源；講義 72 頁的案例與考題事實幾乎相同，係改編自陳忠五（字幕作陳中武，請對講義）之文章。

## 三、四段式答題架構（老師示範）

1. **法條與定義**：§184 I 前段之權利，通說指絕對權，包括物權、人格權；人格權含身體、健康、名譽、自由等，自由是否包含意思自由則有爭議 → 爭點由定義帶出。
2. **抽象見解**：先列肯否二說及理由，不急著涵攝；先從抽象的法條解釋開始，再進入具體案例。
3. **依兩說涵攝**：肯定說結論為何、否定說結論為何，找出兩說結論的差異。
4. **己見**：侵權行為之規範目的在尋求權利保護與行為自由之適當界限；承認意思自由為權利，過失侵害亦須負責，過於嚴苛。丙仍可依後段或撤銷後依不當得利受保護，無必要擴大前段適用範圍 → 採否定說。

- 題目中的線索（謊稱、出示不實文件取信於人）都要寫進涵攝。
- 若審題發現兩個爭點就開兩段；不同請求權基礎下的不同爭點，分段處理。
