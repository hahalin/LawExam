# 民法債權補充2 筆記：保證契約補充與人事保證（§739-1至§756-3）

## 保證人權利不得預先拋棄（§739-1）
- 本節所定保證人之權利，除法律另有規定外，**不得預先拋棄**
- 「法律另有規定」例：先訴抗辯權可拋棄（§746）

## 契約結構提醒
- 保證契約在**債權人與保證人**之間
- 債務人與保證人之間是**委任**（拜託你作保）或**無因管理**（主動作保），不是保證契約

## 主張主債務人的抗辯（§742、§742-1）
- 主債務人所有的抗辯，保證人**得主張**；主債務人拋棄抗辯，保證人仍得主張（§742）
- 保證人得以**主債務人對債權人之債權**主張**抵銷**（§742-1）
  - 例：甲欠乙 10 萬，丙為保證人；甲對乙另有 10 萬債權 → 乙向丙請求時，丙可用甲的債權抵銷

## 明知行為能力欠缺仍作保（§743）
- 保證有從屬性：主債務無效，保證原則也無效
- 例外：保證人對因**行為能力欠缺**而無效的債務，**知其情事而為保證**者，保證仍有效
- 例：甲受監護宣告，向銀行借 100 萬，丙明知仍作保 → 借貸無效，但丙要對甲應返還的不當得利負保證責任；不知情則保證隨之無效

## 董監事保證（§753-1）
- 因擔任法人**董事、監察人**或其他有代表權之人而為該法人保證者，**僅就任職期間**所生債務負責

## 人事保證
- 為他方的受僱人將來因職務上行為應負的損害賠償責任作保（為受僱人的誠實擔保）（§756-1 I）
- 應以**書面**為之（§756-1 II）
- 期間**不得逾 3 年**，逾者縮短為 3 年（§756-3）——人會變，不能保證十年後仍誠實
- **爭點**：保證機師等受僱人「服務滿一定年限、未滿離職應付違約金」，是一般保證還是人事保證？
  - 若是人事保證 → 3 年期限
  - 最高法院 108 年民事庭決議：屬**一般保證**（決議字號建議查證；講義有收錄）

## 📖 法條原文速查

> **§743**（無效債務之保證）保證人對於因行為能力之欠缺而無效之債務，如知其情事而為保證者，其保證仍為有效。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 保證人權利可否預先拋棄 | 原則**不可**；先訴抗辯權例外 |
| 保證人可否以主債務人之債權抵銷 | **可**（§742-1） |
| 明知主債務人無行為能力仍作保 | 保證**有效** |
| 董監事為法人保證之範圍 | **任職期間**所生債務 |
| 人事保證方式 | **書面** |
| 人事保證期間 | 不得逾 **3 年** |
| 保證服務年限違約金 | 實務：一般保證 |
