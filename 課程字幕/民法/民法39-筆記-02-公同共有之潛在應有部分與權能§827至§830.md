# 民法39 筆記：公同共有之潛在應有部分與權能（§827至§830）

## 定義：
- 數人基於**公同關係**而共有一物（§827）；進入公同關係就是公同共有人，離開就不是（定義見民法37-筆記-10）
- 對物**沒有應有部分**；但對公同關係有一定權利，稱**潛在應有部分**：祭祀公業的派下權比例、繼承的應繼分、合夥的股份比例
- 需要多數決時，用潛在應有部分換算

## 權能：
- **使用收益**：依公同關係定之（§828 I），看合夥契約、祭祀公業規約；不像 §818 按應有部分
- **管理**：§828 II 準用 §820 → 可多數決作分管決定、全體作分管契約（見民法38-筆記-04）
- **物上請求權**：§828 II 準用 §821 → 各人可起訴，但為全體利益（見民法38-筆記-05）

## 處分：
- **應有部分的處分不存在**：沒有 §819 I 那種自由處分；要轉讓的是合夥股份、派下權、應繼分，各依其法律關係（例：合夥股份轉讓原則須全體同意）
- **公同共有物的處分**：
  - 動產 → §828 III 全體同意
  - 不動產有償讓與、有償設定用益物權 → 土地法 §34-1 **V 準用 I～IV** → 可多數決，不同意者也有優先承買權
  - 無償處分、設定擔保物權 → 回到 §828 III 全體同意
  - 分割、信託、互易不在土地法 §34-1 範圍（與分別共有相同，見民法37-筆記-12）
- 引用時**不能直接引土地法 §34-1 I**，要寫「V 準用 I」

## 分割：
- 公同關係存續中**不得請求分割**（§829）：分割等於消滅公同關係；而且後加入的人本來也應該分得這些財產
- 公同關係終止後，分割**依共有物分割之規定**（§830 II）

> 來源：民法39 課程字幕 00:08:16 ~ 00:19:11；字幕 00:16:50 前後老師口誤說成「無償才能多數決、有償要全體決」，依土地法 §34-1 I 文義校正為**有償**可多數決

## 📖 法條原文速查

> **§827 I**（公同共有人）依法律規定、習慣或法律行為，成一公同關係之數人，基於其公同關係，而共有一物者，為公同共有人。

> **§828**（公同共有人之權利義務）
> I 公同共有人之權利義務，依其**公同關係**所由成立之法律、法律行為或習慣定之。
> II 第 820 條、第 821 條及第 826 條之 1 規定，於公同共有準用之。
> III 公同共有物之**處分**，及**其他之權利行使**，除法律另有規定外，應得公同共有人**全體之同意**。

> **§829**（公同共有物分割之限制）公同關係存續中，各公同共有人，**不得請求分割**其公同共有物。

> **§830**（公同共有之消滅與分割方法）
> I 公同共有之關係，自公同關係終止，或因公同共有物之讓與而消滅。
> II 公同共有物分割之方法，除法律另有規定外，應依關於共有物分割之規定。

> **土地法 §34-1 V**（要旨）前四項規定，於公同共有準用之。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公同共有人得否自由處分其應有部分？」 | **不得**，公同共有對物無應有部分 |
| 「公同共有物之使用收益依何定之？」 | 依**公同關係**（§828 I） |
| 「公同共有土地有償出賣，可否多數決？」 | **可以**，土地法 §34-1 **V 準用 I** |
| 「公同共有土地設定抵押權？」 | §828 III **全體同意** |
| 「公同關係存續中可否請求分割？」 | **不得**（§829） |
| 「公同共有多數決以何計算？」 | **潛在應有部分**（應繼分、派下權、股份） |

## 體系圖

```
公同共有（§827）
├─ 使用收益：依公同關係（§828 I）
├─ 管理：§828 II → §820 多數決
├─ 物上請求：§828 II → §821 各人為全體
├─ 處分
│   ├─ 應有部分 → 不存在
│   └─ 公同共有物
│        ├─ 不動產有償讓與、有償設定用益物權 → 土地法 §34-1 V 準用 I（多數決）
│        └─ 其他（動產、無償、擔保物權）→ §828 III 全體同意
└─ 分割：存續中不得（§829）；終止後依共有物分割（§830 II）
```

## 與分別共有對照

| 項目 | 分別共有 | 公同共有 |
|---|---|---|
| 應有部分 | 有，可自由處分（§819 I） | 無，只有潛在應有部分 |
| 使用收益 | 按應有部分（§818） | 依公同關係（§828 I） |
| 有償處分不動產 | 土地法 §34-1 I | 土地法 §34-1 V 準用 I |
| 分割 | 隨時（§823） | 公同關係終止後（§829、§830） |
