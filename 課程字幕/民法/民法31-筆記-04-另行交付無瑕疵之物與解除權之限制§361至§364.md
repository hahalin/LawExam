# 民法31 筆記：另行交付無瑕疵之物與解除權之限制（§361至§364）

## 另行交付無瑕疵之物（§364）：就是「換貨」：
- 限**種類之債**（「僅指定種類者」）；**特定物**沒有換貨的空間
- 要「**即時**」請求，沒有即時就沒有這個權利 → 只能回到 §359、§360
- 例：買包包回家發現拉鍊壞了，可要求換新
- 老師舉例：買水果回家才發現有幾顆爛了，回去換還算「即時」嗎？界線難定，總之要從速行使
- 出賣人對另行交付的物，**仍負擔保責任**（§364 II）

## 解除權的細節（選擇題偶爾考）：
- 解約除了 §359 的「非顯失公平」，還有 §361～§363

### §361 催告後喪失解除權：
- 買受人主張物有瑕疵 → 出賣人得定相當期限，催告買受人是否解約
- 期限內不解約 → **喪失解除權**
- 理由：避免買受人有解除權卻不行使，出賣人卡在僵局，無法另行處分

### §362 主物與從物（選擇題最愛考，打勾）：
- 主物有瑕疵而解約 → 效力**及於從物**
- 從物有瑕疵 → **只能就從物**解約，主物不受影響
- 例：冷氣附遙控器；冷氣壞了解約，遙控器要一起退；只有遙控器壞，換遙控器就好
- 常與民總 §68（主物、從物）合併出題

### §363 數物買賣：
- 數物中一物有瑕疵 → 原則只能就該物解約（例：100 箱水果有 3 箱臭掉）
- 以總價金將數物同時賣出 → 並得請求減少與瑕疵物相當的價額
- 有瑕疵之物與他物分離而**顯受損害** → **任何一方**都可以解除全部契約
  - 例：金木水火土五件石雕成套才有意義，兩件有瑕疵 → 可全部解約

## 📖 法條原文速查

> **§364**
> I　買賣之物，**僅指定種類**者，如其物有瑕疵，買受人得不解除契約或請求減少價金，而**即時**請求另行交付無瑕疵之物。
> II　出賣人就前項另行交付之物，**仍負擔保責任**。

> **§361**
> I　買受人主張物有瑕疵者，出賣人得定相當期限，**催告**買受人於其期限內是否解除契約。
> II　買受人於前項期限內不解除契約者，**喪失其解除權**。

> **§362**
> I　因**主物**有瑕疵而解除契約者，其效力**及於從物**。
> II　**從物**有瑕疵者，買受人**僅得就從物**之部分為解除。

> **§363**
> I　為買賣標的之數物中，一物有瑕疵者，買受人僅得就有瑕疵之物為解除。其以**總價金**將數物同時賣出者，買受人並得請求減少與瑕疵物相當之價額。
> II　前項情形，當事人之**任何一方**，如因有瑕疵之物，與他物分離而**顯受損害**者，得解除**全部**契約。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「特定物有瑕疵，可請求另行交付？」 | **不可**，§364 限種類之債 |
| 「另行交付請求有無時間限制？」 | 須**即時**請求 |
| 「出賣人催告後買受人未於期限內解約？」 | **喪失解除權**（§361） |
| 「主物有瑕疵解約，效力及於從物？」 | **及於**（§362 I） |
| 「從物有瑕疵，可解除全部契約？」 | **不可**，僅就從物解約（§362 II） |
| 「數物中一物瑕疵，分離顯受損害？」 | **任何一方**得解除全部契約（§363 II） |
