# 民法12 筆記：消滅時效中斷（§129-§137）

> 來源：民法12 課程字幕 01:46:37 ~ 02:31:31

---

## 📖 法條原文速查

> **§129**（消滅時效中斷事由）
> I 消滅時效，因左列事由而中斷：
> 一、請求。
> 二、承認。
> 三、起訴。
> II 左列事項，與起訴有同一效力：
> 一、依督促程序，聲請發支付命令。
> 二、聲請調解或提付仲裁。
> 三、申報和解債權或破產債權。
> 四、告知訴訟。
> **五、開始執行行為或聲請強制執行。**
> → 爭點：「聲請強制執行」是否包含假扣押？

> **§130**（視為不中斷）
> 時效因請求而中斷者，若於請求後六個月內不起訴，視為不中斷。
> → 「視為」= 跟事實相反（明明有請求，但法律當你沒有）

> **§137**（重新起算）
> I 時效中斷者，自中斷之事由終止時，重新起算。
> II 因起訴而中斷之時效，自受確定判決，或因其他方法訴訟終結時，重新起算。
> III 經確定判決或其他與確定判決有同一效力之執行名義所確定之請求權，其原有消滅時效期間不滿五年者，因中斷而重新起算之時效期間為五年。
> → 不滿五年 → 延為五年（保障權利人積極行使的獎勵）

> **§147**（時效利益之預先拋棄禁止）
> 時效期間，不得以法律行為加長或減短之，並不得預先拋棄時效之利益。
> → 反面解釋：不能「預先」拋棄 → 可以「事後」拋棄

## 📋 實務見解速查

| 實務見解 | 要旨 |
|---------|------|
| **103 年第 2 次民事庭決議** | 假扣押強制執行 → §129 II §5 中斷時效 → 執行程序終了時重新起算 |
| （吳明軒/林誠二反對） | 假扣押 ≠ §129 II §5 → 最多只有「請求」效力（六個月內要起訴） |

---

## 🎯 一試重點提示

1. **「請求」後六個月內不起訴** → §130 視為不中斷（當作沒請求過）
2. **「承認」不適用 §130** → 承認即中斷，直接重新起算，不用六個月內起訴
3. **§137 III**：經確定判決的請求權，原有時效不滿 5 年 → 延為 5 年重新起算
4. **時效進行中承認 = §129 中斷** vs **時效完成後承認 = §147 反面拋棄時效利益**（超級愛考！）
5. **刑事告訴 ≠ 民事請求**、**檢察官起訴 ≠ 民事起訴**、**刑事認罪 ≠ 民事承認**
6. **換發債權憑證** → 中斷 → 重新起算 → 再執行 → 再中斷 → **永不消滅**
7. **假扣押中斷時效**：一試選實務（103 年決議 = 有中斷）

## 一、時效中斷的基本架構

### 核心概念

> 時效中斷 = 砍掉重練
> 時效進行中，因特定事由，將已進行的時效歸零，重新起算

### §129 事由總覽

```
§129 時效中斷事由
│
├── §129 I（三大事由）
│   ├── 一、請求 ──→ §130（六個月內不起訴 → 視為不中斷）
│   ├── 二、承認 ──→ 直接重新起算（不適用 §130）
│   └── 三、起訴 ──→ §137 II（判決確定/其他終結 → 重新起算）
│
└── §129 II（類似起訴事由）
    ├── 一、聲請支付命令
    ├── 二、聲請調解/仲裁
    ├── 三、申報和解債權/破產債權
    ├── 四、告知訴訟
    └── 五、開始執行行為/聲請強制執行 ← 爭點：含假扣押？
```

---

## 二、§130 請求與視為不中斷

### 請求的特殊性

```
請求（意思表示）→ 沒有如起訴般的正式程序
    │
    ├── 六個月內起訴 ──→ 時效中斷（直到判決確定才重新起算）
    │
    └── 六個月內未起訴 ──→ §130 視為不中斷
                              = 當作你沒請求過
                              = 時效按原始方式繼續計算
```

> **「視為」**的意思 = 法律認定跟事實相反
> 你明明有請求，但法律說「你沒有」→ 不可推翻的法律擬制

## 三、§137 重新起算規則

| 情形 | 重新起算時點 | 時效期間 | 法條依據 |
|------|------------|---------|---------|
| 承認 | 中斷事由終止時（= 承認時） | **原有時效** | §137 I |
| 起訴 → 判決確定 | **判決確定時** | 原有時效，**不滿 5 年延為 5 年** | §137 II + III |
| 起訴 → 其他終結（和解等） | 訴訟終結時 | 同上 | §137 II + III |
| 強制執行 | 執行終了時 | 原有時效 | §137 I |

### 經典案例：車禍起訴

```
民國 110 年：甲開車撞乙（§184 侵權行為，§197 時效 2 年）
    │
    ↓ 原本 112 年時效完成
    │
民國 111 年：乙起訴甲 → 時效中斷（砍掉重練！）
    │
    ↓ 訴訟進行中……
    │
民國 113 年：判決確定 → 重新起算
    │
    ├── 原有時效 = 2 年（§197）
    ├── 不滿 5 年 → §137 III 延為 5 年
    │
    └── 時效完成：113 + 5 = 民國 118 年 ✓
```

### 強制執行與換發債權憑證

```
判決確定 → 5年內聲請強制執行
  │
  ├── 執行成功 → 拿錢 ✓
  │
  └── 執行失敗 → 拿到「債權憑證」
       │
       ├── 時效因強制執行而中斷（§129 II §5）
       ├── 執行終了 → 重新起算 5 年
       │
       └── 5年內再執行 → 再拿債權憑證 → 再重新起算
            │
            └── 循環往復 → 🔄 實質上永不消滅
```

> 銀行債權為何幾十年不消滅？每年去強制執行一次 → 換發債權憑證 → 時效不斷砍掉重練
> **已取得確定判決 → 對法安定性無影響 → 讓權利人一直延長是合理的**

## 四、承認的方式與重要區辨

### 承認 = 明示 + 默示

| 承認方式 | 說明 | 實例 |
|---------|------|------|
| **明示** | 直接表示承認債務 | 「我確實欠你 100 萬」 |
| **默示：支付利息** | 付利息 = 承認債務存在 | 房貸每月繳息 → 時效重新起算 15 年 |
| **默示：請求緩期清償** | 要求寬限 = 承認債務存在 | 「拜託再給我兩個月」 |

> **房貸案例**：借房貸 30 年，每月付利息 →  每付一次利息 = 承認一次 = 時效重新起算 15 年 → 銀行永遠不用擔心時效問題

### ⚠️ §129 承認 vs §147 承認（超級考點！）

```
┌─────────────────────────┬─────────────────────────┐
│  時效「進行中」承認        │  時效「完成後」承認        │
├─────────────────────────┼─────────────────────────┤
│  §129 I §2               │  §147 反面解釋            │
│  效果：時效「中斷」        │  效果：「拋棄時效利益」     │
│  → 砍掉重練              │  → 不得再主張時效抗辯      │
│  → 重新起算原有時效       │  → 債務復活               │
├─────────────────────────┼─────────────────────────┤
│  理由：時效在跑 → 可以斷  │  理由：時效已完成 → 無從中斷│
│                          │  §147 只禁止「預先」拋棄   │
│                          │  → 「事後」拋棄可以        │
└─────────────────────────┴─────────────────────────┘
```

> **考試陷阱**：看到「承認」就選「中斷」→ 錯！
> 要先判斷承認發生在時效**進行中**還是**完成後**！

### §147 的文字遊戲

> 「不得**預先**拋棄時效利益」
> → 只說不能預先，沒說不能事後
> → 反面解釋：**事後**可以拋棄時效利益
> → 時效完成後承認 = 事後拋棄時效利益

```
銀行借款契約要求「聲明拋棄時效抗辯權」
  → §147 → 預先拋棄 → 無效（違反強行規定）→ 簽了也沒關係

但時效完成後，債務人自己說「我確實欠你錢」
  → §147 反面 → 事後拋棄 → 有效 → 不能再主張時效抗辯
```

## 五、起訴：刑事 ≠ 民事（車禍實務重點）

### 案例：以刑逼民的時效陷阱

```
民國 110 年 3 月：甲撞乙（車禍）
    │ → §197 時效 2 年（112 年 3 月完成）
    │
    ↓（5 個月後）
110 年 8 月：乙向地檢署「提出告訴」（刑事）
    │
    ↓（疫情拖延，1.5 年後）
112 年 3 月：檢察官起訴（刑事）
    │
112 年 4 月：乙附帶民事訴訟
    │
    ↓
刑事審理中：乙認罪 → 緩刑

❓ 甲對乙的民事 §184 請求權，是否已罹於時效？
```

### 三個常見誤解

| 誤解 | 正確理解 |
|------|---------|
| ❌ 刑事「告訴」= 民事「請求」→ 中斷時效 | ✓ 告訴 = 叫檢察官起訴，不是向對方請求賠償 |
| ❌ 檢察官「起訴」= 民事「起訴」→ 中斷時效 | ✓ 刑事起訴 ≠ 民事起訴，不發生 §129 效力 |
| ❌ 刑事「認罪」= 民事「承認」→ 中斷/拋棄 | ✓ 認罪是刑事考量（換緩刑），不等於承認民事賠償責任 |

> **核心原則**：民事歸民事，刑事歸刑事 →  刑事程序中的任何行為，都不影響民事時效

### 實務建議

```
車禍 110 年 3 月 → §197 時效 2 年 → 112 年 3 月前必須起訴

律師 SOP：
  1. 先提刑事告訴（保護告訴期間）
  2. 自己盯緊 112 年 3 月這個死線
  3. 如果檢察官在 112 年 3 月前還沒起訴
     → 自己先提民事訴訟（寧可繳裁判費，也不要讓對方有時效抗辯）
  4. 不要傻等檢察官！
```

> 疫情期間很多案件就是因為律師沒注意時間，等檢察官等到超過兩年 → 對方直接主張時效抗辯 → 民事部分歸零

## 六、假扣押與時效中斷（103 年第 2 次決議）

### 假扣押程序流程

```
乙對甲有侵權行為債權
    │
    ├── ① 向法院聲請假扣押（費用 1000 元）
    │      → 法院裁定准許 → 提供 1/3 擔保金
    │
    ├── ② 執行假扣押（查封、登記、緊急換價等）
    │
    └── ③ 起訴（附帶或獨立提起民事訴訟）
```

### 爭點：假扣押執行 → 是否中斷時效？

#### 實務見解（103 年第 2 次決議）

```
假扣押執行 → §129 II §5「聲請強制執行」→ 中斷時效
    │
    └── 執行程序終了（查封登記完成等）→ 重新起算（§137 I）
```

#### 學說見解（吳明軒 + 林誠二）

```
假扣押執行 ≠ §129 II §5
    │
    ├── 吳明軒三點質疑：
    │   ① 先起訴再假扣押 → 時效已因起訴中斷 → 假扣押中斷無意義
    │   ② 先假扣押再起訴 → 時效會因起訴中斷 → 假扣押中斷無意義
    │   ③ 假扣押後不起訴 → 對方可命起訴 → 不起訴 → 假扣押被撤銷
    │      → 視為不中斷 → 所以讓假扣押中斷時效根本沒有實益
    │
    └── 林誠二觀點：
        §129 II = 「與起訴有同一效力」
        假扣押 = 暫時性保全處分 ≠ 類似起訴
        假扣押最多 = 「請求」的效力 → 六個月內要起訴（§130）
```

### 一試要怎麼選？

> 問「依實務見解」→ 選 103 年決議（假扣押 = §129 II §5 → 中斷時效）
> 問「依學說」→ 選假扣押不發生 §129 II §5 效力 / 最多等同請求

## 七、時效停止（立法論——目前我國沒有！）

### 案例：承攬協商

```
110 年 2 月：甲完工（§127 第 7 款 → 承攬報酬時效 2 年）
    │        → 112 年 2 月時效完成
    ↓（半年催款無果）
110 年 8 月：開啟正式協商程序
    │
    ↓（協商進行中……）
    │
112 年 4 月：協商破裂

❓ 乙可否主張時效抗辯？
```

### 比較法：德國 Hemmung（時效停止 / 暫停）

```
┌── 我國（無時效停止制度）──────────────────┐
│                                          │
│  110/2      110/8         112/2  112/4   │
│  ├──────────┼──────────────┤───┤          │
│  完工        協商開始      時效完成  協商破裂 │
│  ← 時效 2 年一路跑完 →                     │
│  → 112/2 已完成 → 甲告了也被時效抗辯       │
│                                          │
└──────────────────────────────────────────┘

┌── 德國（有時效停止 Hemmung）──────────────┐
│                                          │
│  110/2      110/8         112/4  113/10  │
│  ├──6個月──┤  ⏸暫停⏸     ├─1.5年─┤      │
│  完工        協商開始      協商破裂 時效完成  │
│  ← 6個月 →  ← 停止 →     ← 剩1.5年 →     │
│                                          │
│  → 協商期間時效暫停 → 破裂後繼續跑剩餘時間  │
│  → 甲有充足時間提告                        │
└──────────────────────────────────────────┘
```

> 時效停止 ≠ 時效中斷
> 中斷 = **砍掉重練**（歸零重算全部）
> 停止 = **按暫停鍵**（只跑剩餘時間）

### 我國現行法的解套：誠信原則

```
乙在協商中 → 創造甲的「信賴」（讓甲覺得有機會和解）
    │
    └── 甲因信賴而不積極起訴
         │
         └── 乙事後主張時效抗辯 → 可能違反 §148 誠信原則
```

> ⚠️ **創造信賴 ≠ 承認**
> 承認 → 協商成立 → 時效因承認而中斷（沒有問題）
> 創造信賴 → 只是讓對方**以為**會承認 → 沒有中斷效果 → 只能靠誠信原則

適用場景不限於承攬，**保險金請求**的協商也常見同樣問題。
