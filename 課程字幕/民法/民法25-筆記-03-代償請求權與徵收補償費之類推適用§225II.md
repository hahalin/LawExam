# 民法25 筆記：代償請求權與徵收補償費之類推適用（§225 II）

## 代償請求權的基本構造：
- 甲以 **100 萬**元出賣市價 **200 萬**的 A 車給乙；A 車被丙毀損，甲乙都不可歸責
  - 乙 → 甲 §348：✗ §225 I
  - 甲 → 乙 價金：✗ §266
  - 但甲對丙有 **§184** 損害賠償請求權
- 「代償」＝拿 A 取代 B：乙改「買」甲對丙的 §184 請求權
- 乙若能向丙求償 200 萬，付 100 萬給甲仍然划算

## 選擇權在債權人乙：
- 路線一：不要代償，也不付錢（§266）
- 路線二：請求代償（§225 II），但要付價金
- 兩者**擇一**，由乙決定；甲處於被動地位

## 保險金能不能代償？（老爭點，現在少考）
- §225 II 用語是「損害賠償」；保險金是保險契約的給付，不是損害賠償
- **多數說**：保險金非典型損害賠償 → **類推適用** §225 II
- 少數說：保險法 §1 把保險定義為「賠償」→ 從寬解釋，**直接適用**

## 81 年第 19 次民事庭決議：徵收補償費（第二次講）：
- 甲出賣 A 地給乙，已交付未移轉登記，A 地被政府徵收，甲領到補償費
  1. 乙 → 甲 §348：✗ 徵收不可歸責雙方，§225 I
  2. 甲 → 乙 價金：✓ 已交付，§373 危險在乙
  3. 乙 → 甲 §179 補償費：✗ 依權益歸屬說，補償費歸屬於所有人甲（見民法22-筆記-05）
  4. 乙 → 甲：**類推適用** §225 II 請求讓與補償費 ✓
- 為何是類推，不是直接適用？
  - **補償**針對**合法**侵害，**賠償**針對**不法**侵害，性質不同
  - 徵收補償費是合法徵收後的補償，不是 §225 II 所稱的損害賠償
- 老師：決議可考兩處——**為何不成立 §179**、**類推 §225 II 的操作**；一試出現機率很高，也可能變成二試小題

## 📖 法條原文速查

> **§225 II**　債務人因前項給付不能之事由，對第三人有**損害賠償請求權**者，債權人得向債務人請求**讓與其損害賠償請求權**，或**交付其所受領之賠償物**。

> **保險法 §1 I**　本法所稱保險，謂當事人約定，一方交付保險費於他方，他方對於因不可預料，或不可抗力之事故所致之損害，負擔**賠償**財物之行為。

---

## 📋 實務見解速查

> **最高法院 81 年度第 19 次民事庭會議決議**（要旨改寫）：買賣土地於移轉登記前被徵收，補償地價由出賣人領取，出賣人本於所有人地位受領，不成立不當得利；惟買受人得**類推適用 §225 II**，請求出賣人讓與補償地價。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「代償請求權由誰選擇是否行使？」 | **債權人** |
| 「債權人可否免對待給付又請求代償？」 | **不可**，擇一 |
| 「土地被徵收，買受人請求補償費之依據？」 | **類推適用** §225 II（81 年第 19 次民庭決議） |
| 「買受人可否依 §179 請求補償費？」 | **否**，補償費歸屬於所有人（出賣人） |
| 「為何類推而非直接適用？」 | 補償針對**合法**侵害，非損害賠償 |
| 「保險金請求代償？」 | 多數說**類推適用** |

## 案例：A 車被丙撞毀

```
甲 ──買賣 100 萬──→ 乙
│
└─ A 車（市價 200 萬）被丙毀損 → 甲對丙 §184
          │
          ├─ 乙選路線一：不付 100 萬，也不要 §184（§266）
          └─ 乙選路線二：付 100 萬，取得 §184 請求權（§225 II）→ 淨賺 100 萬
```

| | 損害賠償 | 補償 |
|---|---|---|
| 針對 | 不法侵害 | 合法侵害 |
| 例 | §184 | 徵收補償費 |
| §225 II | 直接適用 | 類推適用 |
