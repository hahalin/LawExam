# 民法07 筆記：網拍標錯價的三個爭點——§154 標價是要約還是要約之引誘、§88 能否撤銷、§148 請求履約是否違反誠信（戴爾案）

> 來源：民法07 課程字幕 01:50:39 ~ 02:02:17

---

## 📖 法條原文速查

> **§154**（要約之拘束力、要約引誘）
> I 契約之要約人，因要約而受拘束。但要約當時預先聲明不受拘束，或依其情形或事件之性質，可認當事人無受其拘束之意思者，不在此限。
> II **貨物標定賣價陳列者，視為要約**。但**價目表之寄送，不視為要約**。

> **§88 I**　表示行為錯誤得撤銷，但以非由表意人之過失者為限。
> **§348 I**　出賣人負交付並移轉所有權之義務。
> **§148**　I 權利之行使，不得違反公共利益，或**以損害他人為主要目的**。II 行使權利，履行義務，應依**誠實及信用方法**。
> 消保法定型化契約相關規定（「本公司保有最終決定權」條款之效力）→ 建議查閱

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「網拍標價之性質？」 | 多數說：**要約**（如貨物標定賣價陳列，§154 II 本文）；少數說：**要約之引誘**（如價目表寄送，§154 II 但書）。採要約說 → 下標即承諾 → 契約成立 |
| 「業者標錯價（5 萬標成 5 千），得否依 §88 撤銷？」 | 屬**表示行為錯誤**，但 key 錯單**難謂無過失**（連採重大過失說的林誠二都救不了）→ 原則**不得撤銷**；例外：**系統當機**自動改價 → 無過失 → 可撤銷 |
| 「契約有效且不能撤銷，買受人必能請求出貨？」 | 不一定。買受人**明知**標錯價仍**故意**大量下標、呼朋引伴 → 以損害他人為主要目的 → 違反 **§148** → 不得依 §348 請求履行；不知情、只買一台 → 可請求 |
| 「『本公司保有最終決定權』條款效力？」 | 通說**有效**：約定標價為要約之引誘，消費者頂多沒買到，無不利益，非顯失公平，為企業控制風險之方式 |

## 一、三層次的思考順序
```
① 契約成立了沒？ → 標價是要約還是要約之引誘（§154）
       不成立 → 沒有契約請求權 → 原告之訴駁回，結束
       成立 ↓
② 能不能撤銷？ → §88 表示行為錯誤，但有無過失
       能撤 → 自始無效，結束
       不能撤 ↓
③ 請求履約有沒有違反誠信原則？ → §148
```

## 二、爭點 ①：§154 II 的兩種情形

| | 貨物標定賣價陳列 | 價目表之寄送 |
|---|---|---|
| 性質 | **視為要約** → 客人說要買＝承諾 → 不能不賣 | **不視為要約**（要約之引誘）→ 客人說要買才是要約 → 老闆說賣完了＝拒絕 → 契約不成立，不能告債務不履行 |
| 為什麼 | 東西擺在店裡、價格寫清楚 | 傳單上的東西不一定還有 |
| 網拍像哪個？ | 多數說：跟商店一樣有商品有標價 → **要約** | 少數說：類似價目表 → 要約引誘 |

- 民國 19 年立法時只有這兩種賣法，沒有網拍，所以條文對不上。
- 現在業者幾乎都加「本公司保有最終決定權」→ 特約把標價變成要約之引誘 → 爭議大減，但考試可能「復古」。

## 三、爭點 ②：§88 撤銷——卡在無過失
```
標錯價 ＝ 表示行為錯誤（腦子想 5 萬、手 key 成 5 千）→ 是可撤銷的類型
但無過失？key 錯單悖於一般人的注意義務 → 連重大過失說都過不了 → 原則不得撤銷
例外：系統當機自動把 5 萬顯示成 5 千 → 跟當事人無關 → 無過失 → 可撤銷
→ 契約有效 → 買受人原則可依 §348 請求履約 → 戰場移到 ③
```

## 四、爭點 ③：§148 誠信原則——戴爾案
```
戴爾電腦網路標價出錯（3 萬多元標成 3 千多，約民國 98～100 年間，請查）→ 大家瘋狂下單
成大兩位學生：不知道標錯，以為在辦活動，一人買一台 → 法院：標價是要約、契約成立；標錯有過失不能撤；學生未違反誠信 → 戴爾應出貨 → 勝訴
台北地院另案：一次買 10 台、20 台、呼朋引伴 → 明知標錯還故意大量買來轉賣 → 以損害他人為主要目的 → 違反 §148 → 戴爾不必出貨
```
- 判斷點：買受人**知不知道**標錯價、有沒有**故意**利用（數量、呼朋引伴）。
