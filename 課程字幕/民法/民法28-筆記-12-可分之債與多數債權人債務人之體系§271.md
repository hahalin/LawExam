# 民法28 筆記：可分之債與多數債權人債務人之體系（§271）

## 多數債權人、債務人的章節架構：
- **可分之債**：§271
- **連帶之債**：
  - 連帶債務：§272～§282
  - 連帶債權：§283～§291
- **不可分之債**：§292、§293

## 考試重要性：
- **連帶債務**最重要，下一講的主題
- 連帶債權、不可分債務出現機率很低
- **不可分債權**也重要，但留到物權 §831 **共同共有債權**時再講
  - 屆時搭配 **104 年第 3 次民事庭決議**，討論 §293 體系解釋與該決議的衝突
  - 共同共有債權本質上是一種不可分債權

## §271 可分之債：
- 要件：數人負同一債務或有同一債權，且**給付可分**
- 效果：除法律另有規定或契約另有訂定外，**平均**分擔或分受
- 給付本不可分而變為可分者，亦同
- 重點在「分」：每人**分別**享有權利、負擔義務

## 案例：
- 甲乙丙三人向丁買 **120 公斤**茶葉（可分；土地、房屋則不可分）
- 沒有特別約定 → 甲、乙、丙各可向丁請求 **40 公斤**
- 誰沒拿到，就**個別**對丁主張債務不履行
- 反過來，丁也是個別向甲乙丙請求各自的價金
- 本質：把多數當事人關係**切割開來**，各自為自己的部分負責、享受自己的權利
- 和下一講的**連帶債務**不同

## 下一講：
- 從**連帶債務**開始，預計把債總講完，接著進債各
- 老師提醒：每年考題一半以上和債總有關，重要實務見解都在債總，投資報酬率高

## 📖 法條原文速查

> **§271**　數人負同一債務或有同一債權，而其給付**可分**者，除法律另有規定或契約另有訂定外，應各**平均**分擔或分受之；其給付本不可分而變為可分者亦同。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「三人共同買受可分之物，未約定比例？」 | **平均**分受（§271） |
| 「可分之債中一人未受給付？」 | 該人**個別**主張債務不履行 |
| 「給付本不可分而變為可分？」 | 亦適用 §271 |
| 「共同共有債權的性質？」 | 本質上是**不可分債權** |

## 體系圖

```
多數債權人債務人
├── 可分之債 §271 → 平均分擔、分受（切割）
├── 連帶之債
│   ├── 連帶債務 §272～§282（最重要，下一講）
│   └── 連帶債權 §283～§291
└── 不可分之債
    ├── 不可分債權 §293（搭配 §831、104 年第 3 次民事庭決議）
    └── 不可分債務 §292
```

| 類型 | 法條 | 考試重要性 |
|---|---|---|
| 可分之債 | §271 | 基礎 |
| 連帶債務 | §272～§282 | 最高 |
| 連帶債權 | §283～§291 | 低 |
| 不可分債務 | §292 | 低 |
| 不可分債權 | §293 | 中（共同共有債權） |
