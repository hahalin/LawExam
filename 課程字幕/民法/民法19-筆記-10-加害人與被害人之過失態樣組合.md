# 民法19 筆記：加害人與被害人之過失態樣組合

## 前提：
- 「與有過失」＝被害人**也有**過失；被害人一定要有過失，加害人是什麼態樣再分類

## 四種組合：
- 加害人**無過失**＋被害人過失 → **有** §217（無過失責任不妨礙與有過失；講義註 368 判例）
- 加害人**過失**＋被害人過失 → **有**，典型情形
- 加害人**故意**＋被害人**故意**（互毆）→ **有爭議**
  - 實務：雙方互毆乃互為侵權行為，與雙方行為為損害之**共同原因**有別 → 無 §217
  - 詹森林：互毆是「與有故意」，雙方行為仍是損害之共同原因、有原因力 → 可**類推** §217
- 加害人**故意**＋被害人只有**過失** → **無** §217（近年學說討論重點）

## 故意侵權：被害人沒有迴避義務
- 例：A 銀行理專 Y 假稱幫老人 X 買基金、慫恿 X 申辦網路銀行，設定時記下密碼後盜領 **150 萬**；X 依 §184、§188 及 §224、§227 請求 Y、A，Y、A 主張 X 輕信行員、與有過失
- 最高法院：事實認定不清，**發回**二審
- 林誠二：與有過失看被害人是否採取有效防止或迴避措施，前提是有**防止或迴避義務**；法律未課人民對不法侵害負此義務 → 縱未防止，亦非與有過失
- 王怡蘋（參考德國法）：加害人利用被害人人性弱點或環境便利故意加害，難苛責被害人
  - **直接故意** → 不論被害人有無迴避，都不適用
  - **未必故意** → 被害人有**重大過失**才適用
- 本案：行員基於專業負說明義務，X 信賴其專業交由操作，不能認為 X 有過失
- 法理：故意侵權的風險應由故意行為人**完全承擔**，不能轉嫁給沒迴避的被害人

> 來源：民法19 課程字幕 01:58:40 ~ 02:08:40（講義 241～246 頁，註 368、369）；「凌晨二」為林誠二、「王一平」依語音推定為王怡蘋，建議查證；互毆之判例字幕未唸字號，常見引用為 68 台上 967，建議查證

## 📖 法條原文速查

> **§217 I**　損害之發生或擴大，被害人**與有過失**者，法院得減輕賠償金額，或免除之。

> **§188 I**（要旨）　受僱人因執行職務，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。（但書免責規定請對六法）

---

## 📋 實務見解速查

> **互毆判例**（講義註 369）：雙方互毆乃雙方互為侵權行為，與雙方行為為損害之共同原因者有別，無 §217 過失相抵原則之適用。（字號建議查證）

> **註 368 判例**：§217 被害人與有過失之規定，於債務人應負無過失責任者，亦有其適用。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「加害人負無過失責任，被害人有過失，有無 §217？」 | **有** |
| 「雙方互毆，得否主張過失相抵？」 | 實務：**否**；詹森林：可類推 |
| 「加害人故意、被害人僅有過失，有無 §217？」 | 學說：**否**，被害人無迴避義務 |
| 「德國法見解：加害人直接故意時？」 | 一律**不適用**；未必故意＋被害人重大過失才適用 |

## 一、排列組合表

| 加害人 | 被害人 | §217 |
|---|---|---|
| 無過失 | 過失 | ✓ |
| 過失 | 過失 | ✓（典型） |
| 故意 | 故意（互毆） | 實務 ✗／詹森林類推 ✓ |
| 故意 | 過失 | ✗ |

## 二、故意侵權的細分（王怡蘋）

```
加害人故意
├─ 直接故意 → 被害人怎樣都不適用 §217
└─ 未必故意
    ├─ 被害人重大過失 → 適用
    └─ 被害人輕過失 → 不適用
```
