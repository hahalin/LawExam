# 民法17 筆記：§188 構成要件與為他人或為自己負責

## 考試定位：
- §188 在國考出現機率一直特別高；車禍、工商案件幾乎都會用到
- §187 的內部求償要等 §188 III 講完再回頭講（見筆記 10）

## 構成要件：
- ①**僱傭關係**（僱用人與受僱人）②受僱人**執行職務** ③受僱人**成立侵權行為**

## 法律效果：
- 外部（被害人求償）：對受僱人 §184；對僱用人 §188 I 前段**連帶**
- 僱用人可依 §188 I 但書舉反證免責：推定**選任監督過失＋因果關係**，結構同 §187 II
- 免責後被害人可聲請 §188 II **衡平責任**，結構同 §187 III
- 內部：僱用人賠償後，依 §188 III 對受僱人求償（爭議多，見筆記 08、09、11）

## 性質：兩種法律構造：
- **為他人負責**（傳統通說、最高法院；林誠二、孫森焱）：公司沒有行為，本無責任，為保護被害人才被 §188 I 拖下水 → 賠完可依 §188 III **全額**求償
- **為自己負責**（游進發、陳聰富）：選任監督過失本身就是**不作為侵權**，公司自己成立 §184；§188 I 只是像 §185 一樣把兩人**連帶**起來
- 陳聰富：§188 III 是**確認性規定**，確認有求償權，實際依據回到 §280、§281（如同 §18 II 只確認、不是請求權基礎）
- 上課先以傳統通說為主，遇爭點再補為自己負責說

## 📖 法條原文速查

> **§188 I**　受僱人因執行職務，不法侵害他人之權利者，由僱用人與行為人**連帶**負損害賠償責任。但選任受僱人及監督其職務之執行，已盡相當之注意或縱加以相當之注意而仍不免發生損害者，僱用人不負賠償責任。
> **§188 II**　如被害人依前項但書之規定，不能受損害賠償時，法院因其聲請，得斟酌僱用人與被害人之經濟狀況，令僱用人為全部或一部之損害賠償。
> **§188 III**　僱用人賠償損害時，對於為侵權行為之受僱人，**有求償權**。

> **§18 II**　前項情形，以法律有特別規定者為限，得請求損害賠償或慰撫金。→ 確認性規定的例子

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§188 I 但書推定何事？」 | 推定僱用人**選任監督過失**及**因果關係** |
| 「§188 各項與 §187 各項如何對應？」 | §188 I 但書 ≒ §187 II；§188 II ≒ §187 III |
| 「受僱人未成立侵權行為，僱用人是否負 §188？」 | **否**，受僱人成立侵權是要件 |
| 「實務認為 §188 之性質？」 | **為他人負責**，僱用人得依 §188 III 全額求償 |
| 「為自己負責說如何看 §188 III？」 | 陳聰富：**確認性規定**，求償依 §280、§281 |

## 一、外部與內部關係

```
                受僱人甲 ──§184──┐
被害人乙 ─────                    ├─ 連帶（§188 I 前段）
                僱用人 A ──§188──┘
                   │ 但書：舉反證推翻過失＋因果 → 免責
                   │        └→ §188 II 衡平責任
                   └── 內部：A 賠償後 → §188 III 對甲求償
```

## 二、兩種構造比較

| | 為他人負責（傳統） | 為自己負責（新見解） |
|---|---|---|
| 公司有無自己的侵權行為 | 無，被拖下水 | 有，選任監督過失＝不作為 |
| §188 I 的功能 | 公司負責的請求權基礎 | 把公司與員工連帶起來（像 §185） |
| §188 III 的性質 | 獨立的全額求償權 | 確認性規定，回到 §280、§281 |
| 代表 | 最高法院、林誠二、孫森焱 | 游進發、陳聰富 |

## 三、確認性規定的意思

- 只告訴你「有」，不告訴你「依哪一條」
- §18 II：人格權受侵害，以法律有特別規定者為限得請求 → 要另找 §184、§195
- §188 III（陳聰富）：有求償權 → 要回到 §281 找
