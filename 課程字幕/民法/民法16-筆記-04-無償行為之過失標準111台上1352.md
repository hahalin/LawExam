# 民法16 筆記：無償行為之過失標準111台上1352

## 案情：
- 甲住戶屋頂漏水，頂樓屬公設，要求管委會 A 修繕；A 認為維修責任歸屬不明，不修、要甲去告
- 第一訴訟：甲訴請修繕，**104.11.27 判決確定**；A 收判後不到一個月即雇工（104.12.20），**105.1.28 修好**
- 第二訴訟：甲請求 **103.3.24 通知修繕起至 105.1.28 修好止**，將近兩年**不能使用房屋**的損害

## 爭點（本堂只看過失要件）：
- 管委會處理社區事務**無報酬**＝無償關係 → 過失標準要不要降低？

## 二審 vs 最高法院：
- **二審**：無償 → 負**具體輕過失**即可 → 判決確定後立刻修 → **無過失**
- **最高法院 111 台上 1352**：侵權行為之過失**不因無償而降低**，仍採**抽象輕過失** → 善良管理人應一接獲通知就主動修，拖到判決確定才修 → 可能**有過失**
- 損害是否存在是另一個爭點，本堂姑且不論；本判決被選為值得參考之裁判，論述詳見講義

## 📖 法條原文速查

> **民法 §184 I 前段**　因故意或**過失**，不法侵害他人之權利者，負損害賠償責任。

---

## 📋 實務見解速查

> **最高法院 111 年度台上字第 1352 號判決**（講義 129 頁註 199；字幕作「111年1352號」，字號請對講義）：要旨依課堂講述——侵權行為之過失，不因行為人係無償為之而降低注意標準，仍應以**抽象輕過失**（善良管理人注意）判斷。（原文請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「無償為他人處理事務者，其侵權行為之過失應以何標準認定？」 | 最高法院 111 台上 1352：**抽象輕過失**，不因無償而降低 |
| 「管委會於判決確定後一個月內即修繕，是否當然無過失？」 | 依**抽象輕過失**：善良管理人一經通知即應主動修繕；等到判決確定才修，期間不能使用房屋之損害可能歸責於管委會 |
| 「本案二審為何認定管委會無過失？」 | 二審以無償為由採**具體輕過失**；判決確定後立即修繕 → 無過失（遭最高法院否定） |
| 「本案請求之損害為何？」 | 不是漏水本身（第一訴訟已處理），而是**漏水期間不能使用房屋**之損害 |

## 一、時間軸

```
103.03.24  甲通知 A 修繕 ── A 不修，要甲去告
    │
104.11.27  第一訴訟判決確定（A 應修繕）
    │
104.12.20  A 雇工修繕
    │
105.01.28  修繕完成
    │
第二訴訟：請求 103.03.24 ~ 105.01.28 不能使用房屋之損害
```

## 二、標準不同，結論不同

| | 具體輕過失（二審） | 抽象輕過失（最高法院） |
|---|---|---|
| 理由 | 管委會無償，與處理自己事務同一注意即足 | 侵權行為之過失不因無償降低 |
| 應修時點 | 判決確定後 | 一經通知即應主動修繕 |
| 本件 | 判決後一個月內即修 → 無過失 | 拖延將近兩年 → 可能有過失 |

## 三、老師的評語

- 單看案例事實讀不出爭點：「我一拿到判決就修，哪來的過失？」——答案取決於過失標準
- 本案也說明「過失標準」決定「何時開始有過失」：以修繕時點判斷過失有無
