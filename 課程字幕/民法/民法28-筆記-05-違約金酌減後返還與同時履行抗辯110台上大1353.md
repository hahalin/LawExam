# 民法28 筆記：違約金酌減後返還與同時履行抗辯（110台上大1353）

## 案例（講義 533 頁，數字簡化）：
- 甲向乙買土地，價金 **6,000 萬元**，分三期付
- 雙方**並約定**：可歸責於甲而解約時，乙得把甲已付價金**沒收充作違約金**
  - 「並約定」要畫起來：後面的效果來自**契約**，不是法律；不違反強行規定、善良風俗就有效
- 甲已付兩期 **4,000 萬元**（原裁定為 3,746 萬元），乙已移轉登記土地
- 甲付不出最後 2,000 萬元

## 雙方主張：
- 乙：① §254 催告後解約 ② §259 ① 請求返還土地 ③ 依特約沒收 4,000 萬元作違約金
- 甲：① 違約金過高，依 §252 酌減 ② 假設法院認 **600 萬元**適當，請求返還過高的 **3,400 萬元** ③ 乙不還 3,400 萬元，我就不還土地（同時履行抗辯）

## 爭點一：過高的 3,400 萬元是什麼性質？
- **價金說**：過高部分根本沒有被轉換，仍是價金
  - 返還依據：§259 ② → 與返還土地都是**因解約**互負 → §261 準用 §264
- **違約金說**：已全部轉換，只是被酌減
  - 過高部分失去法律上原因 → 依 **§179** 返還
  - 問題：這筆債務不是因契約、不是因解約、也不是因契約無效而生 → 還能同時履行嗎？

## 大法庭：違約金說＋類推 §264
- 過高違約金不會轉回價金，返還屬**不當得利**
- 返還土地與返還 3,400 萬元雖非同一法律關係所生，但**具牽連性與對立性**，發生於同一紛爭
- 本於誠信及公平原則，**類推 §264**

## 爭點二：甲有沒有先給付義務？
- 鄭雅萍法官不同意見書：乙先解約、甲才主張酌減，有時間先後 → 甲有先返還義務 → 不能抗辯
- 大法庭回應：
  - 先給付義務是**同一雙務契約**內，依合意、法律或交易習慣決定的給付順序
  - 偶然發生、只是具牽連性的兩個對立債務，本來就**沒有誰先誰後**
  - 誰先解約、誰先主張權利，和先給付義務沒有必然關係
- 不同意見書援引日本法；劉姿汝撰文指出其誤解日本法，日本法下仍可主張 → 老師認大法庭值得贊同

## 學說：
- 顏佑紘：**價金說**。甲心中只有在合理範圍（600 萬元）內轉換的意思，其餘未轉換 → 直接 §261 準用 §264，不用繞
- 吳從周：**違約金說**。既已全部轉換，直接生不當得利即可
- 老師：準備國考，把**多數意見與不同意見書**弄懂就夠

## 📖 法條原文速查

> **§252**　約定之違約金額**過高**者，法院得減至相當之數額。

> **§264 I**　因契約互負債務者，於他方當事人未為對待給付前，得拒絕自己之給付。但自己有**先為給付之義務**者，不在此限。

> **§261**　當事人因契約解除而生之相互義務，準用第二百六十四條至第二百六十七條之規定。

> **§259 ①②**　契約解除時：一、由他方所受領之給付物，應返還之。二、受領之給付為金錢者，應附加自受領時起之利息償還之。

## 📋 實務見解速查

> **110 台上大 1353 裁定**（主文，講義 533 頁）：出賣人依買賣契約約定將買受人給付之價金沒收充作違約金，經法院依 §252 酌減至相當數額後，就出賣人應返還之金額，屬**不當得利**性質；買受人得**類推 §264**，以自己因買賣契約解除後之回復原狀義務，為同時履行之抗辯。

> **同裁定理由（講義 534 頁 (D)）**：§264 I 但書之先為給付義務，係就雙務契約當事人互負之對待給付而言，因合意、法律規定或交易習慣而生；非基於同一雙務契約、僅具牽連性之對立債務，本於誠信及公平原則類推同時履行抗辯，原無何人有先為給付義務之問題。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「沒收價金充作違約金經酌減，過高部分返還依據？」 | 大法庭：**§179 不當得利**（違約金說） |
| 「買受人得否以返還土地與之同時履行？」 | **得**，**類推 §264** |
| 「不同意見書的理由？」 | 買受人有**先返還義務** |
| 「大法庭如何回應？」 | 非同一雙務契約所生，**無先後**問題 |
| 「若採價金說，同時履行抗辯的依據？」 | §259 ② → **§261 準用 §264** |
