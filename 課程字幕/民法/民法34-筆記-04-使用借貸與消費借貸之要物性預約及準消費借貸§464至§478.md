# 民法34 筆記：使用借貸與消費借貸之要物性、預約及準消費借貸（§464～§478）

## 債各後半段的讀法：
- 申論最愛考買賣、租賃、承攬（另加贈與）；其餘契約看法條，抓選擇題常考點
- 讀債各法條看到「**死亡**」就圈起來：誰死了會怎樣，一試 CP 值很高

## 使用借貸的構造（§464）：
- 「而約定」**之前**＝成立要件：貸與人**交付**借用物（**要物契約**）
- 「而約定」**之後**＝契約義務：借用人**返還**
- 貸與人交付不是義務 → 只有借用人有義務 → **單務**契約
- 用別人的東西要付錢是租賃，不用付錢是借貸 → **無償**契約

## 使用借貸預約（§465-1）：
- 只有口頭約定「車借我」「明天來拿」→ 尚未交付，借貸不成立，成立**預約**
- 預約貸與人**得撤銷**；但預約借用人已請求履行而貸與人**未即時撤銷**，就不能再撤銷
- 背景：89 年修法曾考慮廢除要物性（德國債法修正已改諾成），改動太大，增訂預約規定緩和

## 其他使用借貸規定：
- 保管義務、不得允許第三人使用、違反時之終止與損害賠償 → 自己看
- **§472 ④：借用人死亡 → 貸與人得終止**
  - 對照租賃 §452：承租人死亡 → **承租人之繼承人**得終止（見民法32-筆記-11）
  - 貸與人死亡、出租人死亡 → 對契約都沒有影響
- §473 短期時效 **6 個月**（租賃 §456 是 2 年，見民法33-筆記-01）；注意起算點

## 消費借貸（§474 I）：
- 標的是**代替物**（金錢、可樂），返還種類、品質、數量相同之物即可
- 不只交付，而是**移轉所有權**
- 只有借用人負返還義務 → **單務**
- 約定利息 → **有償**；未約定 → 無償

## 單務有償的經典題：
| 命題 | 對錯 |
|---|---|
| 單務契約必為無償 | **錯**（付息消費借貸） |
| 有償契約必為雙務 | **錯**（同上） |
| 雙務契約必為有償 | 對 |
| 無償契約必為單務 | 對 |

## 消費借貸預約（§475-1）：
- 有利息或其他報償 → 預約成立後一方成為**無支付能力**，預約貸與人才得撤銷（I）
- 無報償 → 準用 §465-1，隨時可撤銷（II）

## §478 與時效起算：
- 未定返還期限 → 貸與人得定**一個月以上**相當期限催告返還
- 請求權時效從何時起算有爭議，連結 **99 年第 7 次民事庭決議**（民總 §128 消滅時效起算點已講）

## 準消費借貸（§474 II）：
- 一方對他方原負金錢或代替物給付義務，約定以之作為消費借貸標的 → 亦成立消費借貸
- 數字例：建商以 6,000 萬賣屋給甲，甲沒錢付價金，雙方約定把 6,000 萬價金債務**轉為借款**
- 不必先撥款再付價金，法律明定可以這樣做；選擇題考過一次

## 📖 法條原文速查

> **§464**　稱使用借貸者，謂當事人一方以物**交付**他方，而約定他方於**無償**使用後返還其物之契約。

> **§465-1**　使用借貸預約成立後，預約貸與人得**撤銷**其約定。但預約借用人已請求履行預約而預約貸與人**未即時撤銷**者，不在此限。

> **§472 ④**　借用人死亡者，**貸與人**得終止契約。

> **§473**（要旨）　貸與人就借用物所受損害之賠償請求權、借用人之有益費用償還請求權及工作物取回權等，均因**六個月**間不行使而消滅；於貸與人自受借用物返還時起算，於借用人自借貸關係終止時起算。→ 建議查閱最新六法原文

> **§474**
> I　稱消費借貸者，謂當事人一方**移轉**金錢或其他代替物之**所有權**於他方，而約定他方以種類、品質、數量相同之物返還之契約。
> II　當事人之一方對他方負金錢或其他代替物之給付義務，而約定以之作為消費借貸之標的者，亦成立消費借貸。

> **§475-1**
> I　消費借貸之預約，其約定之消費借貸有利息或其他報償，當事人之一方於預約成立後，成為**無支付能力**者，預約貸與人得撤銷其預約。
> II　消費借貸之預約，其約定之消費借貸為無報償者，準用第四百六十五條之一之規定。

> **§478**　借用人應於約定期限內，返還與借用物種類、品質、數量相同之物。未定返還期限者，借用人得隨時返還，貸與人亦得定**一個月以上**之相當期限，催告返還。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「使用借貸之貸與人有交付義務？」 | **無**，交付是成立要件（要物、單務） |
| 「借用人死亡，誰得終止？」 | **貸與人**（§472 ④）；租賃是承租人之繼承人（§452） |
| 「使用借貸預約可否撤銷？」 | 原則可；借用人已請求履行而未即時撤銷則不可 |
| 「單務契約必為無償？」 | **錯**，付息消費借貸是單務有償 |
| 「有償消費借貸預約何時得撤銷？」 | 一方成為**無支付能力**時（§475-1 I） |
| 「以買賣價金債務轉為借款？」 | **準消費借貸**，有效（§474 II） |
