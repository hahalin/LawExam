# 民法39 筆記：公同共有債權之行使與繼承後之不當得利（104年第3次民事庭決議）

## 基本題：
- 甲對乙有 500 萬借款返還請求權，甲死亡，繼承人丙丁戊；遺產分割前對該債權**公同共有**（§1151）
- 問：丙能否**單獨**起訴請求乙向**全體繼承人**返還？還是須全體起訴，當事人適格始無欠缺？
- 老師：近年二試已考過兩三次，**一定要會**

## 實務（104年第3次民事庭決議）：文義解釋
- §831：共有規定於所有權以外之財產權準用 → 「權利」**包括債權**，所以到物權編找答案
- §828 II 準用的三條都不通：§820 是管理，不是行使權利；§821 是本於**所有權**之請求，債權不適用；§826-1 是內部約定拘束後手，無關
- 只剩 §828 III「其他之權利行使」→ 須**全體同意或全體起訴**

## 學說多數：體系解釋
- 債權怎麼行使，應先看**債編**：公同共有債權是法律上**不可分之債權**，§293 I：**各**債權人得請求向債權人**全體**為給付
- 實務走 §828 III 會和 §293 得出不同答案 → **評價矛盾**
- 物權編也有不矛盾的路：§831 → §828 II → **§821**（把「所有權」換成債權）→ 各人可單獨起訴，命債務人向全體給付，與 §293 一致

## 延伸題：繼承房屋被無權占有
- 甲的 A 屋自 108 年起被乙無權占有到 113 年，甲於 110 年死亡，繼承人丙丁戊
- **返還房屋**：丙可單獨請求，§828 II 準用 §821 ＋ §767 I 前段，請求返還全體（這是物上請求權，不是債權）
- **相當於租金之不當得利**，要切兩段：

| 期間 | 性質 | 丙能否單獨請求 |
|---|---|---|
| 108～110（甲生前） | 甲的不當得利債權，被繼承 → 公同共有債權 | 實務：全體；學說：可單獨為全體 |
| 110～113（甲死後） | 實務：基於公同共有物所生之債權，仍是公同共有債權 | 實務：全體 |
| 同上 | 陳榮傳：直接對繼承人各自發生，非繼承而來 | 各自行使 |

## 📖 法條原文速查

> **§831**（準共有）本節規定，於所有權以外之財產權，由數人共有或公同共有者準用之。

> **§293 I**（不可分債權）數人有同一債權，而其給付不可分者，**各**債權人僅得請求向債權人**全體**為給付，債務人亦僅得向債權人全體為給付。

> **§821**（共有人對第三人之權利）各共有人對於第三人，得就共有物之全部為本於所有權之請求。但回復共有物之請求，僅得為共有人**全體之利益**為之。

> **§828 III**　公同共有物之處分，及其他之權利行使，除法律另有規定外，應得公同共有人全體之同意。

> **§1151**（遺產之公同共有）繼承人有數人時，在分割遺產前，各繼承人對於遺產全部為公同共有。

## 📋 實務見解速查

> **最高法院 104 年度第 3 次民事庭會議決議**：公同共有債權人起訴請求債務人履行債務，係公同共有債權之**權利行使**，非屬回復公同共有債權之請求，無 §821 之準用，應依 §831 準用 §828 III，除法律另有規定外，須得其他公同共有人**全體同意**，或由**全體為原告**，當事人適格始無欠缺。（要旨改寫）

> **最高法院 108 年度台上字第 789 號判決**（字幕唸「108789號」，字號建議查證）：繼承人因繼承取得之財產受侵害時，所生損害賠償或不當得利請求權，為公同共有債權。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公同共有債權，一人可否單獨起訴？」 | 實務：**否**，全體同意或全體起訴（104-3 決議） |
| 「104-3 決議走的條文路徑？」 | §831 → §828 **III** |
| 「學說批評實務的理由？」 | 與 **§293** 不可分債權矛盾；應走 §831 → §828 II → **§821** |
| 「§831 的『財產權』包括債權嗎？」 | **包括** |
| 「繼承房屋被占，一人可否單獨請求返還房屋？」 | **可以**，§828 II → §821 ＋ §767 I 前段 |
| 「繼承後才發生的相當租金不當得利」 | 實務：仍為公同共有債權；陳榮傳：各自之債權 |

## 三條路徑比較

```
公同共有債權如何行使？
├─ 實務（文義）：§831 → §828 III → 全體
├─ 學說（體系）：§831 → §828 II → §821 → 各人為全體
└─ 債編：§293 I → 各人請求向全體給付
          ↑ 學說：物權編的答案應與債編一致
```
