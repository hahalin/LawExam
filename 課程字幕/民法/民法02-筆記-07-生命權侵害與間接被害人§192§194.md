# 民法02 筆記：生命權侵害與間接被害人 §192 §194

> 來源：民法02 課程字幕 01:17:14 ~ 01:24:31

---

## 📖 法條原文速查

> **§6**（自然人之權利能力）
> 人之權利能力，始於出生，**終於死亡**。

> **§192**（侵害生命權之財產上損害賠償）
> I 不法侵害他人致死者，對於**支出醫療及增加生活上需要之費用或殯葬費之人**，亦應負損害賠償責任。
> II 被害人對於第三人負有**法定扶養義務**者，加害人對於該第三人亦應負損害賠償責任。

> **§194**（侵害生命權之非財產上損害賠償）
> 不法侵害他人致死者，被害人之**父、母、子、女及配偶**，雖非財產上之損害，亦得請求賠償相當之金額。

> **§184 I 前段**
> 因**故意或過失**，不法侵害他人之權利者，負損害賠償責任。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲被乙撞死，甲得否依 §184 向乙請求？」 | **否**。§6 權利能力終於死亡，死人不能當原告；**我國不承認餘命損害** |
| 「甲之繼承人得否繼承甲對乙之損害賠償請求權（餘命損害）？」 | **否**。甲死亡即無損害可言，無請求權可繼承 |
| 「里長為被撞死之甲支出喪葬費，得否向加害人請求？」 | **可**，§192 I。**不以**與甲有親屬關係為必要 |
| 「§192、§194 之請求權人是誰？」 | **間接被害人**（因甲死亡而間接受損之人），不是甲 |
| 「§194 慰撫金請求權人？」 | 限**父、母、子、女、配偶** |
| 「依 §192、§194 請求，要不要先成立 §184？」 | 論述上**搭 §184**：§192、§194 條文只寫「不法侵害他人致死」，沒有故意過失，要靠 §184 涵攝 |

---

## 一、死人不能當原告

```
甲被乙開車撞死 → 甲可否對乙主張 §184？
    §6：權利能力終於死亡
    → 甲已非權利主體 → 無權利 → 無權利受侵害 → 無損害
    → 甲不能告
```

## 二、餘命損害：美國有些州有，台灣沒有

```
餘命損害：平均壽命 80 歲，60 歲死於非命 → 剩 20 年生命價值的損害
    → 損害歸屬：甲（直接被害人）
    → 甲死不能告 → 由繼承人代為請求

台灣：不承認。甲沒有損害，繼承人無從繼承。
```

## 三、所以要找間接被害人出來：§192、§194 是特例

```
甲（直接被害人）死亡 → 無損害
    ↓ 乙難道不用賠？不合理
    ↓
找出因甲死亡而「間接」受損害之人 → 讓他們直接請求

§192 I  支出醫療費、增加生活需要費用、殯葬費之人   → 財產上損害
        （不限親屬：里長幫窮困的甲辦後事也算）
§192 II 甲對其負法定扶養義務之人（父母、子女、配偶）→ 失去扶養的財產上損害
§194    甲之父、母、子、女、配偶                     → 慰撫金
```
- 這些人不是「人格權或身分權受侵害」，而是因甲生命權受侵害而間接受損；因為不承認餘命損害，只好讓間接被害人跳出來。

## 四、論述要搭 §184

```
§192、§194 條文：「不法侵害他人致死者」← 沒有「故意過失」
    → 單用 §192、§194 無法涵攝故意過失
    → 論述時先用 §184 I 前段處理責任成立（故意過失、不法、因果關係）
    → 再接 §192、§194 決定誰可以請求、請求什麼
```

## 五、答題口訣

```
不法侵害他人致死 → 不要讓甲當原告
    ✗ 甲依 §184 向乙請求 → 一定錯
    ✓ 間接被害人（支出費用之人／法定扶養權利人／父母子女配偶）
      依 §184 ＋ §192、§194 向乙請求
```
