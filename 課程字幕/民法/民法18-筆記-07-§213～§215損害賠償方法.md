# 民法18 筆記：§213～§215損害賠償方法

## 先分能否回復原狀：
- **不能**回復原狀或回復**顯有重大困難** → §215 只能請求金錢賠償（打破的玻璃盤要黏回去顯有困難）
- **能**回復原狀 → §213 I 原則回復原狀；例外改請求金錢：① §213 III 債權人**得**請求回復原狀之**必要費用**；② §214 定相當期限催告**逾期不為回復** → 金錢賠償
- 「回復原狀為原則、金錢賠償為例外」只在能回復時（§213）成立

## 回復原狀＝回復應有狀態：
- 不是回到原有狀態，而是「**如果沒有發生侵權行為，現在應有的狀態**」，事故後的變動（折舊）要算進去（講義 195 頁註 306 決議，字號請對講義）
- 十年車一年後求償，就回復到十一年車的狀態；可以用**二手零件**修
- 數字：車禍時市價 100 萬、損後 30 萬；若無事故一年後應值 80 萬 → 回復原狀必要費用是 **80－30＝50 萬**，不是 70 萬

## 三種「金錢」不一樣：
- §213 III、§214：**回復原狀之必要費用**（能回復體系下的代替）
- §215：無法回復時之金錢賠償，以**買價**計（買回同樣東西要花的錢），不是賣價
- 二手車商收購 30 萬、隔天賣 50 萬 → 被撞爛的 A 車應賠 **50 萬**；陳聰富：金錢賠償目的在讓被害人立刻買到替代物

> 來源：民法18 課程字幕 01:27:08 ~ 01:41:43（講義 195 頁）；01:28:18 時間標記重複出現，可能有剪接；01:31:24 老師說講義寫錯，§213 III 應為「得請求」回復原狀必要費用；01:35:28 字幕為「賠償的其實是 30 萬」，依應有狀態計算應為 80－30＝50 萬，筆記採 50 萬（請對講義或板書）

## 📖 法條原文速查

> **§213**　I 負損害賠償責任者，除法律另有規定或契約另有訂定外，應**回復他方損害發生前之原狀**。III 第一項情形，債權人**得**請求支付**回復原狀所必要之費用**，以代回復原狀。

> **§214**　應回復原狀者，如經債權人**定相當期限催告**後，逾期不為回復時，債權人得請求以金錢賠償其損害。

> **§215**　**不能回復原狀**或回復**顯有重大困難**者，應以金錢賠償其損害。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「所謂回復原狀，係回復至損害發生前之原有狀態？」 | **錯**，回復**應有狀態**（考量折舊等事後變動） |
| 「舊車被撞，加害人得否以二手零件修復？」 | **得**，應有狀態本是舊車 |
| 「§214 之金錢與 §215 之金錢意義相同？」 | **不同**：§214＝回復原狀必要費用；§215＝買價 |
| 「物滅失時 §215 金錢賠償以何價格計？」 | **買價**（重新購得同等物之價格），非賣價 |
| 「債權人可否不待催告逕請求回復原狀必要費用？」 | **可**，§213 III「得」請求 |
| 「回復原狀顯有重大困難時，債權人得否堅持回復原狀？」 | **否**，§215 應以金錢賠償 |

## 一、損害賠償方法體系

```
損害賠償方法
├─ 能回復原狀（§213、§214）
│   ├─ 原則：回復原狀（§213 I）→ 應有狀態
│   ├─ 例外一：債權人得請求必要費用（§213 III）
│   └─ 例外二：催告逾期不回復 → 金錢（§214）＝必要費用
│
└─ 不能回復或顯有重大困難（§215）
    └─ 只能金錢賠償 → 以買價計
```

## 二、應有狀態：算一次

| 項目 | 金額 |
|---|---|
| 事故當時市價 | 100 萬 |
| 事故後（受損）市價 | 30 萬 |
| 若無事故，一年後求償時應值 | 80 萬 |
| ✗ 錯誤算法：100－30 | 70 萬（等於這一年都不折舊） |
| ✓ 回復原狀必要費用：80－30 | **50 萬** |

## 三、三種「金錢」對照

| 條文 | 前提 | 金錢內容 |
|---|---|---|
| §213 III | 能回復，債權人選擇 | 回復原狀必要費用 |
| §214 | 能回復，催告逾期 | 同 §213 III（必要費用） |
| §215 | 不能回復／顯有重大困難 | 標的物**買價** |

## 四、買價與賣價（§215）

| | 賣價（收購價） | 買價（市場售價） |
|---|---|---|
| A 車例 | 30 萬 | 50 萬 |
| 誰會主張 | 加害人（乙） | 被害人（甲） |
| 採用 | ✗ | ✓ 陳聰富：被害人本無出售意思，要能立刻買回同樣的車 |
