# 民法25 筆記：給付不能之效果體系與查封登記是否構成給付不能

## 給付、對待給付是相對概念：
- 甲乙買賣 A 車：討論 A 車 → A 車是**給付**，甲是債務人、乙是債權人，價金是**對待給付**
- 題目問乙不付錢 → 價金變成給付，乙變債務人，A 車變對待給付
- 先看題目討論哪一個標的，再定誰是債務人

## 債務不履行的給付不能＝自始主觀不能＋嗣後不能：
- 自始主觀不能：典型是**買賣他人之物**，債務人自己拿不出來，但不是任何人都做不到
- 嗣後不能：訂約後才不能，不再區分主觀或客觀
- 自始客觀不能 → §246 契約無效，不屬債務不履行（見民法24-筆記-09）

## 解題兩步：先問能不能提出，再問誰可歸責：
- 債務人**不可歸責** → §225 I 免給付義務；§225 II 代償請求權（兩效果可並存）
  - 債權人也不可歸責 → §266 免對待給付
  - 可歸責於債權人 → §267 仍須對待給付
- 債務人**可歸責** → §226 損害賠償、§256 解除契約（→ §259 回復原狀）
- 兩個「擇一還是並存」的爭點：
  - 代償請求權與 §266 免對待給付：**擇一**——要代償就要付錢，不付錢就沒有代償
  - §226 損害賠償與 §256 解約：有爭議（見本講筆記-05、06）

## 查封登記是不是給付不能（詹森林文章，講義 430 頁）：
- 案情簡化：甲答應把 A 屋移轉給兒子乙；甲欠護理之家費用，甲死後 A 屋被查封；乙向其他繼承人丙等請求移轉登記
- **第一訴訟**：查封登記未塗銷前不能辦理移轉登記，丙等**給付不能**，乙不得請求
- 繼承人清償欠款、塗銷查封後，丙又因自己欠債被丁查封，乙再起訴
- **第二訴訟**：最高法院提出疑問——**何以公法上之登記障礙會構成私法上之給付不能？**（未給答案）
- 詹森林認同第二訴訟的質疑：
  - 給付不能應指**永久不能**；**一時不能**只是暫時有障礙，屬**給付遲延**
  - 早年 **70 年第 18 次民事庭決議**（講義註 696）認暫時不能即構成給付不能，論理有待商榷（決議內容依老師轉述，建議查證）
  - 查封只要塗銷就能移轉 → 一時不能 → 給付遲延

## 📖 法條原文速查

> **§225**　I 因**不可歸責**於債務人之事由，致給付不能者，債務人**免給付義務**。II 債務人因前項給付不能之事由，對第三人有損害賠償請求權者，債權人得向債務人請求讓與其損害賠償請求權，或交付其所受領之賠償物。

> **§226 I**　因**可歸責**於債務人之事由，致給付不能者，債權人得請求賠償損害。

> **§266 I**　因不可歸責於雙方當事人之事由，致一方之給付全部不能者，他方免為對待給付之義務；如僅一部不能者，應按其比例減少對待給付。

> **§267**　當事人之一方因可歸責於他方之事由，致不能給付者，得請求對待給付。但其因免給付義務所得之利益或應得之利益，均應由其所得請求之對待給付中扣除之。

> **§256**　債權人於有第二百二十六條之情形時，得解除其契約。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務不履行所稱給付不能包括？」 | **自始主觀不能**＋**嗣後不能** |
| 「買賣他人之物屬何種不能？」 | **自始主觀不能**，契約有效 |
| 「雙方不可歸責之給付不能，債權人可否同時免對待給付又請求代償？」 | **不可**，兩者擇一 |
| 「可歸責於債權人之給付不能，債務人可否請求對待給付？」 | **可以**（§267），扣除免給付所得利益 |
| 「一時不能是否即為給付不能？」 | 詹森林：**否**，屬給付遲延；給付不能指永久不能 |

## 體系圖

```
無法提出給付？
├── 否 → 命債務人履行（或給付遲延）
└── 是：給付不能
    ├── 不可歸責於債務人 → §225 I 免給付＋§225 II 代償
    │   ├── 債權人亦不可歸責 → §266 免對待給付（與代償擇一）
    │   └── 可歸責於債權人 → §267 仍須對待給付
    └── 可歸責於債務人 → §226 損賠＋§256 解約（並存或擇一有爭議）
```

| | 第一訴訟 | 第二訴訟 |
|---|---|---|
| 查封中請求移轉 | 給付不能，駁回 | 質疑公法障礙何以構成私法給付不能 |
| 詹森林 | ✗ | ✓（一時不能屬給付遲延） |
