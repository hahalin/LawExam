# 民法30 筆記：代物清償新債清償與債之更改（§319、§320）

## 問題：原定給付能不能換成別的？
- 例：向車商訂 2025 年式 A 車，A 車缺貨，車商提議改給現貨 2026 年式 A+、不加價
- 把 A 換成 A+ 有三種做法：代物清償、新債清償、債之更改

## 代物清償（§319）：
- 性質：**要物行為**，車商須真的**提出** A+，買受人也**受領**
- 效果：受領他種給付以代原定給付 → **債之關係全部消滅**

## 新債清償（§320，又稱間接給付）：
- 性質：**諾成**的約定，只是口頭約定以 A+ 取代 A，A+ 還沒交付
- 新債務**履行** → 新舊債務**同時消滅**
- 新債務**不履行** → **舊債務不消滅**，新舊債務**並存**
- 並存時要先請求哪一個？
  - 早期實務（**88 台上 2384**）：新舊債務並存，債權人得**擇一行使**，一個獲得清償，另一個隨之消滅
  - 現行實務（**101 台上 1410**）：新債務清償期屆至前，債權人**不得行使舊債權** → 先請求新債務，新債務不履行才請求舊債務
  - 另有學說認為成立選擇之債

## 債之更改：
- 法條**沒有規定**，基於契約自由由當事人約定
- 效果：**舊債務消滅，只剩新債務**
- 常見例子：**換訂單**（例：戰爭導致零件缺貨，車商建議改訂現貨車款）
- 與 §320 的關係：§320「除當事人另有意思表示外」，最常見的另有意思表示就是債之更改

## 📖 法條原文速查

> **§319**　債權人**受領他種給付**以代原定之給付者，其債之關係消滅。

> **§320**　因清償債務而對於債權人負擔新債務者，除當事人另有意思表示外，若**新債務不履行**時，其**舊債務仍不消滅**。

---

## 📋 實務見解速查

> **88 台上 2384**（早期）：§320 所稱新債清償，當事人無特別約定時，新舊債務並存，債權人得擇一行使；其中一債權獲得清償，另一債權即歸於消滅。

> **101 台上 1410**（現行）：因清償債務而對於債權人負擔新債務者，除當事人另有意思表示外，新債務不履行時，舊債務固不消滅；惟在新債務之清償期屆至前，債權人**不得行使舊債權**，此觀 §320 規定自明。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「代物清償的性質？」 | **要物行為**，須受領他種給付 |
| 「代物清償的效果？」 | 債之關係**消滅**（§319） |
| 「新債清償，新債務未履行，舊債務？」 | **不消滅**，新舊並存（§320） |
| 「新債清償，新債務清償期屆至前可請求舊債務？」 | **不可**（101 台上 1410） |
| 「債之更改有無明文？效果？」 | **無明文**；舊債務消滅，只剩新債務 |
| 「換訂單屬於哪一種？」 | **債之更改** |

## 三種做法比較

| 比較項目 | 代物清償 §319 | 新債清償 §320 | 債之更改 |
|---------|-------------|-------------|---------|
| 性質 | 要物 | 諾成 | 諾成（契約自由） |
| 何時消滅舊債 | 受領他種給付時 | 新債務履行時 | 約定時 |
| 新債不履行 | （不會發生） | 新舊並存 | 只能請求新債 |
| 法條 | 有 | 有 | 無 |

```
以 A+ 代替 A
├── 當場交付並受領 A+ → 代物清償 → 債之關係消滅
├── 約定將來給 A+，A 先留著 → 新債清償
│     ├── 給了 A+ → A、A+ 都消滅
│     └── 沒給 A+ → A、A+ 並存（先請求 A+）
└── 約定 A 直接改成 A+ → 債之更改 → 只剩 A+
```
