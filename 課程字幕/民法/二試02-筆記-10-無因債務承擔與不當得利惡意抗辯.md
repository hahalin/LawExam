# 民法二試02 筆記：無因債務承擔與不當得利惡意抗辯

## 爭點（承筆記 09）：
- 甲約定「無條件代繳乙之 B 屋貸款至繳清」，事後不繳 → 甲能否依 §408 I 撤銷？
- 定性：**贈與**（可撤銷，最高法院）vs **無因債務承擔**／無因債務承認／無因債務拘束（二審：不能撤銷）

## 定性為無因債務承擔時，法律效果：
- **實務**：無因債務承擔契約本身就是請求權基礎、就是法律上原因 → 乙可直接請求，甲無從抗辯
- **學說（陳聰富，講義 127 頁；呂教授同旨）**：無因只是**舉證責任轉換**
  - 乙請求時**不必**證明原因關係
  - 甲可以舉證**原因關係不存在**（例如沒有贈與之意、已依 §408 I 撤銷贈與之意思）
  - 甲若給付，乙即構成不當得利 → 依誠信原則，甲得主張**不當得利之惡意抗辯**，拒絕給付（參考票據無因性理論）

## 📖 法條原文速查

> **民法 §179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。……
> **民法 §148 II**　行使權利，履行義務，應依誠實及信用方法。
> **民法 §408 I**　贈與物之權利未移轉前，贈與人得撤銷其贈與。……

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「甲得否撤銷代繳貸款之約定？」 | 先定性：贈與 → §408 I 可撤銷；無因債務承擔 → 不能依 §408 撤銷 |
| 「定性為無因債務承擔，甲就一定要繳？」 | 實務：是；學說：無因只是舉證責任轉換，甲證明原因不存在 → 不當得利惡意抗辯 |
| 「什麼是不當得利之惡意抗辯？」 | 原因關係不存在，甲給付後乙即須返還（§179）→ 依誠信原則，與其給了再要回，不如現在就拒絕給付 |
| 「誰負舉證？」 | 乙不必證明原因；甲須證明原因不存在 |

---

## 一、實務 vs 學說

```
乙依「代繳協議」請求甲履行
  實務：無因債務承擔＝請求權基礎＝法律上原因 → 甲只能繳
  學說：乙不必證明原因
        甲 → 舉證原因關係不存在（無贈與意思／已撤銷）
           → 給付即構成乙之不當得利（§179）
           → 依誠信原則（§148 II）主張不當得利之惡意抗辯 → 拒絕給付
```
