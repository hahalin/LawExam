# 民法33 筆記：合建契約之定性與買賣承攬混合契約

## 合建的三種類型：
| 類型 | 內容 | 考試 |
|---|---|---|
| 互易型 | 地主以土地所有權換建商蓋好的房屋所有權（俗稱地主保留戶） | 少考 |
| 合夥型 | 地主、建商訂合夥契約，房地共同共有，一起出售獲利 | 少考 |
| **買賣混合承攬型** | 土地部分買賣、房屋部分承攬，價金與報酬互相抵銷 | **最常考** |

## 為什麼會有混合型：雙方互不信任
- 地主怕：土地先過戶給建商，房子最後沒蓋起來
- 建商怕：土地沒先給我，房子蓋好後地主把土地賣給第三人，第三人請求拆屋還地

## 混合型的構造（甲地主、乙建商）：
```
土地 A（建商分得部分）：甲乙買賣
  甲 ──移轉 A 地所有權──▶ 乙
  乙 ──給付價金─────────▶ 甲
                              } 價金與報酬互相抵銷
房屋 B（地主分得那一戶）：甲乙承攬
  乙 ──蓋好 B 屋（直接歸甲）──▶ 甲
  甲 ──給付報酬（後付）────────▶ 乙
```
- 承攬：乙蓋好的房屋直接歸甲，甲不怕乙蓋完轉賣
- 報酬**後付**：房屋沒蓋完，甲不用付錢
- 土地依買賣規定處理，房屋依承攬規定處理

## 考試操作：
- 題目只說「地主與建商簽合建契約」，沒說互易或合夥 → 定性為**買賣混合承攬**
- 房屋有瑕疵 → 走承攬（§492 以下）
- 土地有權利瑕疵 → 走買賣（§349 以下）
- 好處：可以寫的考點最多，定性也多一段可寫
- 實務個案仍要看當事人約定

## 📖 法條原文速查

> **§398**　當事人雙方約定互相移轉金錢以外之財產權者，準用關於買賣之規定。

> **§490 I**　稱承攬者，謂當事人約定，一方為他方完成一定之工作，他方俟工作完成，給付報酬之契約。

> **§345 I**　稱買賣者，謂當事人約定一方移轉財產權於他方，他方支付價金之契約。

## 📋 實務見解速查

> **91 台上 1559**（要旨，字幕「911559」，字號建議查證）：地主提供土地、建商出資合作建屋，按土地價款與建築費比例分配房屋之約定，其性質應依契約內容探求當事人真意決定，非可一概而論。約定房屋完成後，以分歸地主之房屋與分歸建商之基地**互易**所有權者，屬互易契約；約定建商向地主承攬完成一定工作，而以地主應給付之報酬充作建商買受分歸建商之房屋部分基地價款者，屬**買賣與承攬之混合契約**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「合建契約一律為承攬？」 | **否**，依約定內容探求真意 |
| 「以房屋換土地所有權的合建？」 | **互易**（§398 準用買賣） |
| 「建商承攬蓋屋、報酬充作買受基地價款？」 | **買賣與承攬混合契約** |
| 「混合型合建，房屋有瑕疵依何規定？」 | **承攬**瑕疵擔保 |
