# 民法二試02 筆記：承租人自殺成凶宅之保證人責任與契約解釋

## 案例（講義 126 頁）：
- 乙向甲租屋，丙為保證人
- 租約 §11：乙應以善良管理人注意使用房屋，因過失致房屋毀損應賠償
- 租約 §13：乙違約或**損害租賃房屋**時，丙連帶負賠償責任
- 乙在屋內自殺，房屋成為凶宅 → 甲依**契約**向丙請求 600 萬

## 爭點：
- 請求權基礎是契約約定 → 租約 §13「損害房屋」是否包括成為凶宅的價值減損

## 最高法院（109 台上 2112）：
- **以法律解釋契約**：§432 II「毀損、滅失」指物理上毀損；§184 I 前段限絕對權；凶宅只是價值減損（純粹經濟上損失）→ 法律上不能請求 → 契約也不能

## 陳忠五：
- 契約解釋應探求**當事人真意**（§98），法律只是輔助（不違強行規定、善良風俗即可）
- 約款寫「損害房屋」，沒有限於物理毀損 → 依一般租屋交易習慣，應包括成為凶宅之價值減損 → 甲得向丙請求

> 來源：民法二試02 課程字幕 01:54:50 ~ 02:05:33（講義 126 頁，註 200）

## 📖 法條原文速查

> **民法 §98**　解釋意思表示，應探求當事人之真意，不得拘泥於所用之辭句。
> **民法 §432**　I 承租人應以善良管理人之注意，保管租賃物……II 承租人違反前項義務，致租賃物**毀損、滅失**者，負損害賠償責任。但依約定之方法或依物之性質而定之方法為使用、收益，致有變更或毀損者，不在此限。
（原文請對六法）

---

## 📋 實務見解速查

> **最高法院 109 年度台上字第 2112 號判決**（講義註 200）：承租人在房屋自殺致成凶宅，該自殺行為未造成房屋外觀形體之毀損或實體破壞，或使用功能之減損或喪失，是否構成「毀損」「損害」，非無斟酌餘地。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「出租人依租約向保證人請求凶宅損害？」 | 請求權基礎是契約 → 爭點在約款「損害房屋」之**契約解釋** |
| 「最高法院的思路？」 | 用 §432 II、§184 I 前段解釋契約 → 凶宅非物理毀損、屬純粹經濟損失 → 否定 |
| 「陳忠五的批評？」 | 契約應依當事人真意解釋（§98），法律只是輔助；約款未限物理毀損 → 依交易習慣包括凶宅 |
| 「最容易寫錯的地方？」 | 直覺拿法律解釋契約。題目若給約款文字，先解釋約款 |

## 一、兩種解釋路徑

```
請求權基礎：租約 §13（保證人連帶責任）
「損害房屋」包括凶宅？
  ├ 最高法院：以法律解釋契約
  │    §432 II 毀損滅失＝物理毀損；§184 I 前段＝絕對權 → 凶宅 ✗
  └ 陳忠五：以當事人真意解釋契約（§98）
       約款未限縮 → 依租屋交易習慣 → 凶宅 ✓
```
