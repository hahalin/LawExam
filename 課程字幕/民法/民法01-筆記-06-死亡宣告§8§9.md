# 民法01 筆記：死亡宣告（§8、§9）與推定死亡時點的計算

> 來源：民法01 課程字幕 01:13:44 ~ 01:33:50

---

## 📖 法條原文速查

> **§8**（死亡宣告）
> I 失蹤人**失蹤滿七年**後，法院得因**利害關係人或檢察官**之聲請，為死亡之宣告。
> II 失蹤人為**八十歲以上**者，得於失蹤滿**三年**後，為死亡之宣告。
> III 失蹤人為遭遇**特別災難**者，得於特別災難終了滿**一年**後，為死亡之宣告。

> **民用航空法 §98**（航空器失事）
> 因航空器失事致所載人員失蹤，於失蹤滿**六個月**後，法院得因利害關係人或檢察官之聲請，為死亡之宣告。→ 建議查閱最新條文

> **§9**（死亡時間之推定）
> I 受死亡宣告者，以判決內所確定死亡之時，**推定**其為死亡。
> II 前項死亡之時，應為前條各項所定期間**最後日終止之時**。但有反證者，不在此限。

> **§120 II**（始日不算入）
> 以日、星期、月或年定期間者，其**始日不算入**。

> **§121**（期間之終止）
> I 以日、星期、月或年定期間者，以期間末日之終止，為期間之終止。
> II 期間不以星期、月或年之始日起算者，以最後之星期、月或年與**起算日相當日之前一日**，為期間之末日。

> **§1147**（繼承之開始）
> 繼承，因被繼承人死亡而開始。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「失蹤之意義？」 | **生死不明**，非僅所在不明（知道他活著只是找不到人 ≠ 失蹤） |
| 「79 歲失蹤，等幾年？」 | 實務：以**失蹤時年齡**為準 → 未滿 80 → **7 年**（少數說：滿 80 時起算 3 年） |
| 「失足落海、登山失足是否為特別災難？」 | **不是**。特別災難須為任何人在當下均無法倖免的不可抗力（海嘯、地震、空難） |
| 「檢察官聲請死亡宣告是否須經家屬同意？」 | **不須**。檢察官有**獨立**聲請權（法安定性涉公益） |
| 「鄰長、好友可否聲請？」 | **不可**，非利害關係人 |
| 「推定死亡時點 = 判決時？聲請時？」 | 都不是。= **§8 期間最後日終止之時**（24:00） |
| 「90/9/10 失蹤，7 年，推定何時死亡？」 | 始日不算入 → 90/9/11 起算 → 相當日 97/9/11 的前一日 → **97/9/10 24:00** |
| 「受死亡宣告者實際仍生存，其在現生活地所為侵權行為是否負責？」 | **要**。死亡宣告僅有**範圍效力**（原生活地依繼承處理），不影響其實際權利能力、行為能力 |
| 「§9 是視為還是推定？」 | **推定**，得舉反證推翻 |

## 一、為什麼需要死亡宣告

```
人活著 → 自己處理法律關係
人死了 → 繼承人處理（§1147）
生死不明 → ？？？ ← 薛丁格的活著
    債權人要告他還是告繼承人？不知道
    → 法律關係懸而未決 → 有害法安定性
    → 用法律「先假裝他死了」→ 依繼承法則處理
```

> 死亡宣告 ≠ 死亡筆記本。宣告不會讓人真的死，只是讓**原生活地**的法律關係可以結算。

## 二、§8 要件

### 要件 1：失蹤達一定期間

**失蹤 = 生死不明**（不是所在不明）。

| 失蹤人 | 期間 | 依據 |
|------|------|------|
| 一般（未滿 80） | **7 年** | §8 I |
| 80 歲以上 | **3 年** | §8 II |
| 遭遇特別災難 | 災難終了後 **1 年** | §8 III |
| 航空器失事 | **6 個月** | 民用航空法 §98 |

#### 解釋問題 A：79 歲失蹤，等多久？
```
實務（文義）：看「失蹤時」幾歲 → 79 歲未滿 80 → 等 7 年（86 歲可宣告）
少數說（孫森焱）：失蹤中滿 80 歲時起算 3 年（83 歲可宣告）
```
→ 一試選**實務：以失蹤時年齡為準**。

#### 解釋問題 B：特別災難要多特別？
- 標準：**不可抗力、任何人在當下都無法倖免**（海嘯、地震、颶風、雪崩）。
- 與個人行為有關的不算：失足落海、登山跌落山谷（最高法院見解）。

### 要件 2：利害關係人或檢察官聲請

| 聲請人 | 可否 | 說明 |
|------|------|------|
| 利害關係人（配偶、繼承人、債權人……） | ✓ | 他的死活影響到你的法律關係 |
| 檢察官 | ✓ **獨立聲請權** | 法安定性有公益性質，不需家屬同意 |
| 鄰里長、好友 | ✗ | 無利害關係 |

- 法院**不得依職權**宣告，一定要有人聲請。

### 要件 3：法院裁定

三要件齊備 → 法院為死亡宣告之裁定 → 進入 §9。

## 三、§9 效果：推定死亡 + 死亡時點

### 推定死亡的時點 = §8 期間「最後日終止之時」

#### 計算案例（一試會考）

```
90/9/10   甲最後音訊日（失蹤日）
100/7/5   家屬聲請死亡宣告        ← 與死亡時點無關
101/3/8   法院裁定                ← 與死亡時點無關

問：甲被推定於何時死亡？
```

```
Step 1  §120 II 始日不算入 → 90/9/10 不算，從 90/9/11 00:00 起算
Step 2  7 年 → 相當日 = 97/9/11
Step 3  §121 II 相當日之前一日為末日 → 97/9/10
Step 4  §121 I 末日之終止 → 97/9/10 24:00
```
→ 裁定記載：**甲推定於民國 97 年 9 月 10 日 24 時死亡**。
→ 從這個時點起，甲的法律關係依繼承處理；債權人要告的是繼承人。

- 為何始日不算入？第一天幾點失蹤不知道，乾脆整天不算，從隔天 0:00 開始，期間才明確。
- 97/9/10 24:00 = 97/9/11 00:00，同一瞬間；但 **24:00 表示結束、00:00 表示開始**，法律意義不同（跨年倒數的概念）。

#### 法院怎麼找「最後音訊日」
手機訊號、信用卡／提款卡消費、健保卡紀錄、管區、目擊者……窮盡調查後，某日之後再無人見過他 → 那天就是失蹤日。

### 推定 ≠ 真的死：範圍效力

```
死亡宣告
├── 原生活地（失蹤前留下的法律關係）→ 依繼承法則結算
└── 現生活地（他其實還活著的地方）→ 完全不受影響
        → 仍有權利能力、行為能力
        → 所為法律行為有效、侵權行為仍須負責
```

#### 考題
甲受死亡宣告後其實躲在山上，某日酒駕撞死人。甲要負賠償責任嗎？
→ **要**。§9 推定死亡僅有範圍效力，甲活著就有權利能力，§184 照常成立。
