# 民法09 筆記：不法條件與 §111 一部無效——65 台上 2436「分手就還地」案（實務：約定無效 vs 王澤鑑：解除條件無效→贈與無效→§179 但 §180 ④）；懷孕離職條款用 §111 但書

> 來源：民法09 課程字幕 00:21:21 ~ 00:35:00（講義 205 頁註 143）

---

## 📖 法條原文速查

> **§71**　違反強制或禁止規定者無效。　**§72**　背於公序良俗者無效。
> **§111**（一部無效）法律行為之一部分無效者，**全部皆為無效**。但除去該部分亦可成立者，則其他部分，仍為有效。
> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。……
> **§180 ④**　給付，有左列情形之一者，不得請求返還：……四、因**不法之原因**而為給付者。但不法之原因僅於受領人一方存在時，不在此限。

---

## 📋 實務見解速查

> **最高法院 65 年台上字第 2436 號判例**（講義 205 頁註 143；一試考過多次）：上訴人為有婦之夫，因貪戀被上訴人姿色，誘使同居，將土地贈與並約定「如分手則返還」。系爭約定違反善良風俗無效 → 請求返還無理由。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「條件違反公序良俗（不法條件），效力？」 | 條件無效（§71、§72）；法律行為是否跟著無效看 **§111**：條件是法律行為的主要要素 → 全部無效（本文）；除去仍可成立 → 其餘有效（但書） |
| 「有婦之夫贈與小三土地並約定分手即返還，分手後請求返還？」 | **無理由**。實務：系爭約定違反善良風俗無效。王澤鑑：該約定是贈與的**解除條件**，不是請求權基礎；條件不法無效 → 依 §111 贈與全部無效（附款是主要要素）→ §179 要件雖具備，但 **§180 ④ 不法原因給付不得請求返還** |
| 「一般男女朋友贈與約定分手返還？」 | 老師：判例以**維持外遇關係**為前提，一般交往是否悖於善良風俗有待商榷 |
| 「勞動契約約定『懷孕即離職』？」 | 解除條件違反強行規定無效；但除去該條款不影響僱傭契約（服勞務給付報酬）→ **§111 但書**，契約其餘有效 |

## 一、分析順序
```
條件違反公序良俗／強行規定 → 條件無效（§71、§72）
→ 法律行為整個無效嗎？→ §111
    條件是法律行為的主要要素（沒這附款當事人就不會做）→ 本文：全部無效
    除去條件其他部分仍可成立 → 但書：其餘有效
```

## 二、65 台上 2436：結論相同，論理完全不同

| | 實務 | 王澤鑑 |
|---|---|---|
| 「如分手則返還 A 地」是什麼 | **請求權基礎** | 贈與契約的**解除條件**（契約有效時怎麼可能請求返還？這句話一定是要讓贈與失效） |
| 推論 | 系爭約定違反善良風俗無效 → 請求返還無理由 | ① 解除條件以違反善良風俗之事由為內容 → 條件無效 ② §111 本文：附款是贈與的主要要素（富商就是要用土地牽制對方）→ 贈與全部無效 ③ 乙受有利益、無法律上原因、致甲受損 → §179 要件具備 ④ 但 **§180 ④**：為維持外遇而給付＝不法原因給付 → 不得請求返還（拒絕保護說：不當得利不保護惡意之人） |
| 結論 | 不能請求返還 | 不能請求返還 |

- 選擇題只問「能不能請求返還／約定有無悖於善良風俗」，答無效即可；申論要小心別被判例牽著把約定當請求權基礎。
- 老師法律諮詢經驗：百萬鑽戒要不要還 → 先問是不是外遇關係。

## 三、懷孕離職條款：§111 但書
```
僱傭契約以「懷孕即離職」為解除條件 → 違反強行規定（性別工作平等法等）→ 條件無效
除去這一條，僱傭契約（服勞務、給付報酬）仍可成立 → §111 但書 → 契約其餘有效
→ 不是「條件無效，法律行為一定無效」
```
