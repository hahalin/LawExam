# 民法14 筆記：人格權②身體健康權——身體（外）／健康（內）現已不區分、合用；**RCA 案**（美國無線電公司 1970 年代在台設廠，三氯乙烯倒入地下水，廠區員工多年後死亡或罹癌）：被害人分三類——A 死亡（生命權）、B 罹病（身體健康權）皆獲賠無爭議；**C 類：目前無外顯病徵**，有無權利受侵害？四個判決：①高院 **104 重上 505**（第一次二審）：承認**微觀損害**（細胞層次病變，看不見不代表不存在）＋**心理健康**（同事死亡罹癌之恐懼）→ 可請求 ②最高 **107 台上 267**：質疑微觀損害如何證明、未回應心理健康 → 發回（陳忠五批評：舉證責任分配該說清楚就自為判決，不該找小尾巴發回）③高院更審（字幕「107 重上更一 134」）：全盤否定——微觀損害只是醫學觀察、未成疾病不算；心理健康須有憂鬱症等明確疾病，單純緊張害怕失眠不算 ④最高 **110 台上 50**（經典，選為值得參考判決）：不再談微觀損害，直接**擴張內涵**——**身體權**除身體完整外含**身體自主性**（三要件：未徵得同意／使有害人體物質進入體內／超過一般人客觀上能忍受程度），**健康權**除生理健康外含**心理健康** → C 類該當 §184 侵權；陳忠五兩篇文章：第一篇贊同原二審（三角形：行為人／被害人／政策），第二篇高度認同 110 台上 50

## 📖 法條原文速查

> **民法 §184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。
> **民法 §195 I 前段**　不法侵害他人之身體、健康、名譽、自由、信用、隱私、貞操，或不法侵害其他人格法益而情節重大者，被害人雖非財產上之損害，亦得請求賠償相當之金額。

## 📋 實務見解速查

> **最高法院 110 年度台上字第 50 號判決**（講義 62 頁註 109，**已核對**）：按釋字 372（維護人格尊嚴與確保人身安全為憲法保障人民自由權利之基本理念）、釋字 689 理由書（免於身心傷害之身體權雖非憲法明文列舉，基於人性尊嚴理念、維護個人主體性及人格自由發展，亦屬憲法 §22 保障之基本權利）、釋字 785 理由書（人民之健康權為憲法 §22 保障之基本權利，旨在保障人民生理及心理機能之完整性），身體權、健康權均與個人主體性及人性尊嚴密不可分，法院適用私法上關於人格權之規定時，亦應作**符合憲法價值體系之解釋**。所稱身體，指人體之完整，乃人格之基礎；所謂身體之完整性，除身軀、器官等之完整外，尚應包括**身體之自主性**，每個人有權支配自己身體不受不法侵犯。因此，以**未徵得他人同意之方法**，使**有害人體之物質進入人體內**，**超過一般人客觀上能忍受之程度**，自屬對於身體自主性之侵害。而健康，指身心功能的狀態，故健康權是以保持內部機能完全為其內容，**包含生理與心理之健康**；心神的安寧或情緒等影響心理健康的因素，亦應納入健康權予以保護。僅在具體個案上，為調和被害人權益與加害人行為自由之保障，尚須考量損害事故之**發生場所、發生頻率、影響範圍及客觀嚴重性**等因素，**排除社會通念上認為係日常生活中常見而輕微之侵害**。準此，被害人受化學毒物長期之侵入，因而對罹病風險之提高，及未來可能罹病的恐懼、擔憂，倘已非被害人個人主觀上的恣意、臆測或想像，而係**一般人客觀上正常的合理懷疑或心理反應**，此一罹病風險之提高，致心理傷害或情緒痛苦，應已構成心理層面之健康權受損，**不以形成醫學上認定之「疾病」或具有治療必要性為限**。而飲用或吸入化學毒物，未達損及生理、心理健康之人，亦可能構成**身體自主權**受侵害。
> 講義 62 頁整理三點：①基於憲法保障身體健康權之意旨，解釋 §195 應符合憲法精神（**合憲性解釋**）②§195 I 之身體健康權除保護身體健康之完整性外，尚應包括**身體自主性**以及**心理健康** ③日常生活中**輕微**之損害被害人應予容忍，不得請求；然若**情節重大**，**不以構成疾病或有治療必要性為限**，仍構成身體健康權之侵害。
> 四判決時序（講義 59～62 頁註 105～107，**已核對**）：臺灣高等法院 **104 年度重上字第 505 號**（二審，肯定）→ 最高法院 **107 年度台上字第 267 號**（發回）→ 臺灣高等法院 **107 年度重上更(一)字第 134 號**（更審，否定）→ 最高法院 **110 年度台上字第 50 號**。
> **104 重上 505**（註 105）：§184 II 之「損害」，隨現代醫學、分子生物學之進步及對人身法益之重視，已不只侷限於肢體殘缺或器官衰竭之「**巨觀**」損傷，而逐漸包含細胞機能受阻、次細胞層級之染色體甚至 DNA 序列完整性遭破壞之「**微觀**」損害；環境或毒物侵權之被害人體內損害經常潛伏於細胞內、短時間不易顯現；為減緩此類被害人舉證傳統損害之困難，實務已漸承認細胞或次細胞層級之損害概念，不能以臨床上目前與常人相同或未出現症狀即謂健康未受傷害；如被害人致癌或產生其他疾病之機率效應高於常人，造成被害人心理揮之不去之沉重負擔，亦屬對**心理健康**之傷害。
> **107 台上 267**（註 106）：原審既謂選定人須因身體、健康受有如上開內容之破壞始該當損害而得請求慰撫金，然其既認定 C 類選定人未因系爭污染而罹患疾病，乃未具體審認說明該部分選定人有何細胞機能受阻、染色體、DNA 序列完整性有何遭破壞……遽命 RCA 等四公司賠償慰撫金，已有理由不備之違法；所謂體內存有導致健康異常因子究何所指？健康究竟受有何種損害？尚待釐清。（講義本文整理：①有無身體健康權受侵害應依**醫學予以客觀判斷** ②原審未具體說明 C 類受有何種微觀損害）
> **107 重上更(一) 134**（註 107）：§195 I 前段所定「身體權」係指保障身體**完整性**之權利；「健康權」係指保持身體**機能**為內容之權利，包括對肉體及精神之侵害，破壞身體機能即構成健康權之損害。惟均以權利人**受有實際損害為前提**。「對人體有致癌或其餘健康風險存在」僅係對未來可能罹病之「**假設**」或「**可能性**」，目前身體完整性、機能性在未罹癌、罹病前俱未受有改變，難認已構成身體、健康侵害；罹病風險提高之損害**無法量化**，受害人現時擔心將來致癌之恐懼係情緒痛苦，尚非現時之身體健康已受實際損害，具有**投機性及不確定性**，不得預先請求賠償。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「身體權與健康權如何區分？」 | 講義 58 頁：身體權＝保持身體**完整性**；健康權＝保持身體**機能**；內涵不同但通常重疊（車禍骨折＝身體權、臟器破裂＝健康權）。老師：現已不區分、合用 |
| 「更審法院否定 C 類之理由？」 | 身體權、健康權之侵害均以**受有實際損害為前提**；致癌風險只是未來罹病之假設或可能性；風險提高無法量化、恐懼只是情緒痛苦 → 具投機性及不確定性，**不得預先請求**（107 重上更(一) 134） |
| 「最高法院第一次發回的理由？」 | ①有無身體健康權受侵害應依**醫學客觀判斷** ②原審未具體說明 C 類受有何種微觀損害（細胞、染色體、DNA 究竟如何被破壞）→ 理由不備（107 台上 267） |
| 「長期接觸有毒物質但尚未發病之人，得否主張身體健康權受侵害？」 | **得**（110 台上 50）。身體權含**身體自主性**：未經同意使有害物質進入體內、逾一般人客觀忍受程度，即屬侵害，**不須造成受傷生病之結果**；健康權含**心理健康**（同事相繼死亡罹癌之恐懼） |
| 「身體自主性侵害三要件？」 | ①**未徵得他人同意**之方法 ②使**有害人體之物質進入體內** ③**逾越一般人客觀上所能忍受之程度**（老師例：被迫在噴白煙老爺車後面聞一個紅燈 → 要件②③未必該當；連續十年二十年 → 該當） |
| 「微觀損害、心理健康是哪個法院提出？結局？」 | 第一次二審（104 重上 505）提出；最高（107 台上 267）質疑舉證、發回；更審否定兩者；110 台上 50 **不再談微觀損害**，改以擴張身體權、健康權內涵處理 |
| 「陳忠五第一篇文章怎麼說（講義 61～62 頁）？」 | **贊同原二審**：自 89 年 §195 I 增訂「其他人格法益」後實務創設許多人格法益（如居住安寧權）值得肯定，但本件**無須另創「勞動人格權」**，擴大解釋身體健康權即可。擴大解釋（含微觀損害＋心理健康）可發揮三功能：①**損害預防**——被害人無須等損害實際發生，即可依 **§18 I** 預先請求除去或防止侵害，降低巨觀損害發生機率 ②**損害填補**——加害人已具備侵害行為、過失、不法、因果關係，若限縮解釋被害人仍不易獲賠；寬鬆認定可提早救濟、**減少請求權罹於時效之風險** ③**精神慰撫**——長期處於「發病率高於常人」之壓力，寬鬆認定有助慰撫 |
| 「陳忠五批評最高法院（107 台上 267）？」 | ①若認身體健康權應**從嚴**解釋 → 應**自為判決**，無須廢棄發回 ②若認得**從寬**解釋 → 舉證責任亦應從寬，不應要求被害人就微觀損害負高度舉證責任 ③原審以「心理健康」為損害並肯定慰撫金，最高法院若否定亦應於理由中交待 |
| 「陳忠五批評更審法院（107 重上更(一) 134）？」 | ①微觀損害係「**現在存在**」之損害（身體發生病變之機率提升），並非對未來損害之假設；更審混淆現在損害與未來損害 ②未來可能罹病之恐懼，若非被害人主觀臆測想像、而係**客觀上正常之心理反應**，則此精神層面之情緒痛苦已是具體、實際的損害，並非投機、不確定 ③雇主對員工之勞動安全及健康有**保護義務**，員工基於對雇主提供安全勞動環境之信賴而長期曝露於危險；雇主資力雄厚、勞工經濟能力有限，寬鬆認定有助勞工安全健康之保護 |
| 「110 台上 50 如何排除過度擴張？」 | 考量損害事故之**發生場所、頻率、影響範圍、客觀嚴重性**，排除社會通念上日常生活常見而**輕微**之侵害；恐懼須是一般人客觀上正常的合理懷疑，非個人主觀恣意臆測 |
| 「為何本案法律解釋偏向被害人？」 | 高度公害＋勞動權益事件，小蝦米對國際企業；陳忠五三角形：①行為人：若「沒出事就不用賠」等於鼓勵企業偷用有毒溶劑 ②被害人：提前獲賠使保護更完整（否則十年後發病企業資產早已移轉）③政策：宣示在台使用有毒物質「不用等員工生病，被抓到就賠」之嚇阻效果。一般車禍、私人間事件不見得如此傾斜 |

## 一之二、講義補充（老師未講，58～59 頁）

- **與身體分離之部分**（德國儲存精子滅失案）：多數說認係**財產權**之侵害，不得請求慰撫金（陳聰富例：甲捐肝給乙，摘出後植入前肝臟屬甲所有，醫護毀損＝侵害甲之所有權而非身體權；對乙不構成所有權侵害）；亦有認為仍可能透過結合復成身體之一部（精卵結合植入母體）→ 應認係**身體權**之侵害，得請求慰撫金（王澤鑑）。
- **存活機會喪失**：病人死亡時，存活機會係生命之延續 → 剝奪生存機會應認**生命權**受侵害；尚未死亡者，疾病因醫療疏失惡化致存活機會喪失，通常伴隨身體內外組織破壞或內部機能減損 → 於最終死亡前應認**身體權或健康權**受侵害（陳聰富）。
- 胎兒出生前受身體健康侵害，亦得本於侵權行為求償（§7）。

## 二、身體自主性三要件圖

```
①未徵得同意 ＋ ②有害人體物質進入體內 ＋ ③逾一般人客觀忍受程度
   → 身體權（自主性）受侵害 → §184 I 前段 ✓（不須有受傷、生病結果）
```

- 老師評價：若被最高法院廣泛承認，是權利保護的巨大里程碑；日常生活中造成的污染（噴白煙機車）行為自由會受更嚴重限縮。
