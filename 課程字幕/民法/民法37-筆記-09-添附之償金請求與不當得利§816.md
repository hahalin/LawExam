# 民法37 筆記：添附之償金請求與不當得利（§816）

## 案例：
- 乙在自己土地上蓋房子，工人到了、乙訂的磚頭還沒到
- 乙看到隔壁工地剛運來甲的 A 磚頭，就叫工人拿來砌牆
- A 磚頭成為房屋的重要成分 → 依 §811 **乙取得所有權**，甲的所有權消滅
- 問：甲對乙能主張什麼？

## 請求權一：侵權行為（§184）
- 乙故意或過失使甲喪失磚頭所有權 → 可依 §184 請求損害賠償
- 添附制度**沒有排除**侵權行為

## 請求權二：不當得利——三個層次
### （一）乙受利益、甲受損害
- 乙取得 A 磚頭所有權；甲喪失所有權 → 沒有問題

### （二）無法律上原因：§811 能不能當乙的法律上原因？
- 乙取得利益不是基於甲的給付 → **非給付型**不當得利
- 而且是基於**法律規定**（§811），不是當事人的行為
- 依法律規定而生的非給付型不當得利 → 採**法規目的說**
  - 規定目的若在讓受益人**終局保有**利益 → 是法律上原因
  - 規定另有目的 → 不是法律上原因
- 通說：§811 的目的在**物盡其用**、維護物的經濟價值（不要把磚頭從牆裡拆出來），不是為了保護乙
  - → §811 **不能作為法律上原因**
- 結論：不當得利要件具備

### （三）返還範圍：只能請求償還價額
- 依 §181 本應返還**利益原形**，但那等於要把磚頭拆出來，破壞添附的目的
- §816 的用語是「依關於不當得利之規定，**請求償還價額**」
  - 不是「請求返還其所受之利益」
  - 目的：**排除原形返還**，只剩價額
- 關鍵就是最後兩個字：**價額**

## §816 與不當得利的關係：
- 通說：**構成要件準用說**
  - §816 仍要符合不當得利的**全部要件**才會發生
  - 不是「不成立不當得利」，而是「成立不當得利，但只能請求價額」的特別規定
- 對照：若只準用法律效果，就不用審查無法律上原因；通說不採

## 解題架構：
```
甲的磚頭被乙附合於房屋（§811 乙取得）
   │
   ├─ §184：乙有故意過失 → 損害賠償
   │
   └─ §816 準用 §179
        ├─ 受利益／受損害 ✓
        ├─ 無法律上原因：非給付型、依法律規定 → 法規目的說
        │     §811 目的在物盡其用 → 非法律上原因 ✓
        └─ 效果：只能請求償還價額（排除原形返還）
```

## 📖 法條原文速查

> **§816**　因前五條之規定而受損害者，得依關於不當得利之規定，**請求償還價額**。

> **§811**　動產因附合而為不動產之重要成分者，不動產所有人，取得動產所有權。

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

> **§181**　不當得利之受領人，除返還其所受之利益外，如本於該利益更有所取得者，並應返還。但依其利益之性質或其他情形不能返還者，應償還其價額。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「因添附喪失所有權者，得否請求回復原物？」 | **不得**，只能請求**償還價額** |
| 「§811 是否為受益人保有利益之法律上原因？」 | **否**（法規目的說：目的在物盡其用） |
| 「§816 之性質？」 | 通說：**構成要件準用說**，仍須具備不當得利要件 |
| 「添附是否排除侵權行為損害賠償？」 | **不排除**，得併依 §184 請求 |
