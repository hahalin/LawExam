# 民法二試01 筆記：人頭帳戶詐騙之不當得利對象

## 案例（講義 70 頁）：
- 丙把帳戶借給詐騙集團甲；甲詐騙乙，指示乙把錢匯入丙的帳戶
- 乙對丙的侵權行為請求權常已罹於 2 年時效（例如等刑事附帶民事）→ 改依 §179 向丙請求？
- 爭點：丙是否「受有利益」——不當得利的對象是甲還是丙

## 兩種見解：
- **指示給付說**（最高法院、詹森林）：乙匯款時心裡要給的是甲（或以為丙就是甲）→ 給付指向甲 → 向**甲**請求，不能向丙
- **非給付型說**（葉啟洲、113 年高院座談會乙說）：指示給付以甲丙間有**債之關係**（對價關係）為前提；甲只是借用丙的帳戶，甲丙間無任何關係 → 不成立指示給付 → 乙丙間成立**非給付型不當得利** → 可直接向丙請求

## 📖 法條原文速查

> **民法 §179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。……
> **民法 §197 I**　因侵權行為所生之損害賠償請求權，自請求權人知有損害及賠償義務人時起，二年間不行使而消滅。自有侵權行為時起，逾十年者亦同。

---

## 📋 實務見解速查

> **113 年高等法院座談會乙說**（講義註 96，字號請對講義）：受詐欺者與詐欺者間未必有契約關係；詐欺者指示受詐欺者匯款至 A 帳戶，目的在遂行詐騙，並非有意透過受詐欺者之交付履行其與帳戶所有人間之對價關係；甲乙丙三人無從成立指示給付關係，不得以指示給付關係中之履行關係為由，否定受詐欺者對帳戶所有人之不當得利請求。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「被害人侵權請求權罹於時效，得否依 §179 向帳戶提供者請求？」 | 爭點在帳戶提供者是否「受有利益」→ 是否構成指示給付關係 |
| 「指示給付說的理由？」 | 給付是有意識、有目的的給予；乙要給的是詐騙者甲 → 給付指向甲，丙非受領人；給付型優先原則 |
| 「非給付型說的理由？」 | 指示給付須甲丙間有債之關係，才會有「乙給甲、甲給丙」縮短為乙直接給丙；詐騙者只是借帳戶，甲丙無關係 → 無給付指向性問題 → 乙丙間非給付型不當得利 |
| 「目前誰採哪說？」 | 葉啟洲、113 年高院座談會：可直接向丙請求；最高法院、詹森林：向甲請求 |

---

## 一、兩種結構

```
指示給付說：
  乙 ──給付（指向）──→ 甲（詐騙者）  → 乙向甲 §179
   └─履行（匯入帳戶）─→ 丙             丙不是受領人

非給付型說：
  甲丙間無債之關係 → 不成立指示給付
  乙 ──匯款──→ 丙帳戶 → 乙丙間非給付型不當得利 → 乙向丙 §179
```
