# 民法二試03 筆記：建物承租人之土地占有與不當得利（§952）

## 案例（大法庭裁定，講義 271～276 頁；字幕未唸字號，請對講義）：
- A 的土地上，B 無權蓋了 B 屋；A 對 B 已勝訴確定（拆屋還地＋每月 2 萬相當於租金之不當得利）
- B 把 B 屋全部出租給 C；105～106 年間土地使用利益鑑定 199 萬，扣除 B 同期已付 20 萬 → A 向 C 請求 **179 萬**
- 請求權基礎：§179 → 卡在兩個要件：C 有無**受利益**？有無**無法律上原因**？

## 要件一：占有房屋＝占有土地？（受利益）
- 過去最高法院兩說：C 占有 B 屋、B 屋占有 A 地，C 與 A 無關 vs 房屋與土地不能分離，占有房屋必然占有基地
- **大法庭採肯定**：非建物所有人或事實上處分權人之建物占有人，**也是土地占有人**
  - §940：對物有事實上管領力即為占有人；C 支配房屋、房屋坐落土地，C 也對土地有認識 → 客觀、主觀均具備
  - 理論一貫：各說都承認地主拆屋還地時可依 §767 I 請求建物占有人**遷出**——C 若不是占有人，這個請求根本無從成立
- 陳忠五（字幕作陳忠武，講義 59 頁）就本案前身 109 年判決已撰文持相同看法，並反對原判決「C 已付租金給 B 即無不當得利」的說法

## 要件二：無法律上原因（非給付型 → 權益歸屬說）
- **不能用 B、C 間租約判斷**：租約只規範 B、C 之間
- §943：C 以承租意思占有 → **推定**其適法有租賃權；兩個例外都不成立（C 行使的是債權而非物權；A 不是使 C 占有之人）
- §952：**善意**占有人在推定範圍內得使用收益 → 善意期間的使用利益歸屬 C，不構成不當得利
- A 起訴請求後，C 自訴狀送達起視為惡意（§959）→ 此後構成不當得利；C 一開始就惡意，則無此保護

## 不同意見書（講義 276 頁）：
- 占有應依**社會通念**評價，不只看物理狀態
- 一般承租人認知自己只使用房屋空間，基地是屋主與地主之間的事 → C 不是土地占有人
- 不同意見書並未挑戰「房屋不能脫離土地」的物理事實，而是把物理與社會評價切開

## 📖 法條原文速查

> **民法 §940**　對於物有**事實上管領之力**者，為占有人。
> **民法 §943 I**　占有人於占有物上行使之權利，**推定其適法有此權利**。（II 之例外：占有已登記不動產而行使物權；行使所有權以外之權利者，對使其占有之人——原文請對六法）
> **民法 §952**　**善意占有人**於推定其為適法所有之權利範圍內，得為占有物之使用、收益。
> **民法 §959**（要旨）：善意占有人於本權訴訟敗訴時，自訴狀送達之日起，視為惡意占有人。（原文請對六法）

---

## 📋 實務見解速查

> **最高法院大法庭裁定**（講義 271 頁主文，字號請對講義，要旨）：單一建物無權占有他人土地，非建物所有權人或事實上處分權人之建物占有人，亦為土地占有人；除善意占有之情形外，應依不當得利規定返還使用土地之利益於土地所有人。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「地主得否向房屋承租人請求相當於租金之不當得利？」 | §179：爭點在「受利益」（占有土地？）與「無法律上原因」 |
| 「承租房屋＝占有基地？」 | 大法庭：§940 事實上管領力＋§767 遷出請求之理論一貫 → 肯定 |
| 「C 已付租金給 B，還算得利嗎？」 | 不以 BC 租約判斷；依權益歸屬說＋§943、§952 |
| 「善意 C 何時起要返還？」 | 起訴後訴狀送達起視為惡意（§959）；之前受 §952 保護 |
| 「不同意見？」 | 依社會通念，承租人只占有房屋空間 → 非土地占有人 |

## 一、論述骨架

```
A 對 C：§179 返還相當於租金之利益（179 萬）
  ① 受利益：C 占有 B 屋是否占有 A 地？
     ├─ 不同意見：社會通念 → 否
     └─ 大法庭：§940＋理論一貫 → 是
  ② 無法律上原因（非給付型，權益歸屬說）
     ├─ C 善意 → §943 推定有租賃權 → §952 得使用收益 → 起訴前不返還
     └─ C 惡意／訴狀送達後 → 應返還
  ③ 結論：依 C 善惡意與起訴時點計算
```
