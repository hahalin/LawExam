# 民法04 筆記：生效要件體系（§71～§118）與無行為能力人

> 來源：民法04 課程字幕 01:46:07 ~ 02:00:04

---

## 📖 法條原文速查

> **§75**（無行為能力人之意思表示）
> 無行為能力人之意思表示，無效；雖非無行為能力人，而其意思表示，係在無意識或精神錯亂中所為者亦同。

> **§76**（無行為能力人之代理）
> 無行為能力人由法定代理人代為意思表示，並代受意思表示。

> **§980**（結婚年齡）
> 男女未滿十八歲者，不得結婚。（112 年起男女同為 18 歲）

> **郵政法 §12**
> 無行為能力人或限制行為能力人，關於郵政事務對中華郵政公司所為之行為，**視為有行為能力人之行為**。
> **電信法 §9**（老師所引；電信法已由電信管理法取代，條號請查最新法規）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律行為之一般生效要件？」 | ① 當事人有**行為能力**（§75～§85）② 意思表示**健全無瑕疵**（§86～§98）③ 標的**可能、妥當、確定、適法**（§71～§74） |
| 「特別生效要件？」 | 條件期限（§99～§102）、代理（§103～§110）、處分行為須有**處分權**（§118） |
| 「法律行為效力有幾種？」 | **有效、無效（§111～§113）、得撤銷（§114、§116）、效力未定（§115～§117）** |
| 「17 歲高中生當選畢聯會會長，父母反對，效力？」 | **不是法律行為**（無權利義務）→ 根本不討論行為能力，§77 用不上 |
| 「無行為能力人得否繼承？」 | **得**。繼承是事件，不是行為，與行為能力無關 |
| 「受監護宣告之 18 歲人得否結婚？」 | **得**。身分行為看**意思能力**，不受行為能力影響 |
| 「三歲小孩寄信、五歲小孩打電話？」 | 郵政、電信行為**視為有行為能力人之行為**，不受影響（但信裡的要約仍受影響） |
| 「無行為能力人如何為法律行為？」 | 由**法定代理人代為並代受意思表示**（§76） |

## 一、生效要件體系：§71～§118 的地圖

```
一般生效要件（對應成立要件三要素）
├── 當事人 → 要有【行為能力】        §75～§85
├── 意思表示 → 要【健全無瑕疵、生效】 §86～§98
└── 標的 → 要【可能、妥當、確定、適法】§71～§74（§73 是方式，例外）

特別生效要件（特定法律行為才需要）
├── 附條件、期限 §99～§102
├── 代理 §103～§110
└── 處分行為須有處分權 §118

效力四種（一試選項 ABCD 就是這四個）
├── 有效
├── 無效 §111～§113
├── 得撤銷 §114、§116
└── 效力未定 §115～§117
```
- 老師：民法選擇題好出——寫一個故事，問法律行為效力如何，四個選項就是這四種。

## 二、行為能力四級

```
無行為能力人 → 幾乎不能做任何法律行為
限制行為能力人 → 可以做一點
受輔助宣告之人 → 比限制多一點（仍是完全行為能力人，只在 §15-2 事項需同意）
完全行為能力人 → 幾乎不受限制
```

## 三、先確認「這是不是法律行為」，再談行為能力

```
題目：17 歲甲當選畢業聯誼會會長，父母反對，效力？
    ✗ 錯誤反應：§77 但書「日常生活所必需」→ 有效
    ✓ 正確：當選會長不生任何法律上權利義務 → 不是法律行為 → 行為能力根本不介入
```
| 不是法律行為的 | 性質 | 行為能力 |
|------|------|------|
| 繼承 | 事件（非行為） | 無關 → 植物人也能當繼承人，只要有權利能力 |
| 添附、無主物先占 | 事實行為 | 無關 |
| 當選會長、約打球 | 非法律事實 | 無關 |

## 四、無行為能力人自己做法律行為：原則無效，例外「不受影響」

- 用語：老師要求寫「例外**不受行為能力影響**」，不要寫「例外有效」——可能仍因其他原因（公序良俗、通謀虛偽）無效。

| 例外 | 內容 |
|------|------|
| **身分行為** | 結婚、離婚、認領、收養：只看**意思能力**＋客觀要件（§980 滿 18 歲）。受監護宣告之 18 歲人意識清楚即可結婚 |
| **郵政行為** | 郵政法 §12：視為有行為能力人之行為。三歲小孩投信，郵局照寄 |
| **電信行為** | 電信法 §9（條號請查最新法規）：五歲小孩打電話照樣接通 |

- 郵政、電信行為不受影響，但**後續的法律行為仍受影響**：無行為能力人寄信提出要約，寄信有效、要約無效。

## 五、無行為能力人的法律行為由誰做：法定代理人（§76）

- 無行為能力人兩種：未滿 7 歲、受監護宣告之人。
- 法定代理人代為並代受意思表示 → 真正的考點是**法代濫權**（下一份筆記）。
