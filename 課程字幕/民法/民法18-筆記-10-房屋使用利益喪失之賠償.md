# 民法18 筆記：房屋使用利益喪失之賠償

## 先問兩件事：
- 是否**自住**房屋：投資或出租用的房屋只有出租、投資利益損失，不會有「無法居住」的損害
- 有無**支出費用**：另租房、住飯店 → 財產減少＝所受損害，依 §216 請求，**無爭議**
- 爭點在**沒有支出費用**：另有房屋可住、借住親友（德國例：在露營車窩半年）

## 否定說（王澤鑑）：
- 未支出費用就沒有財產上損害；生活不便屬**非財產上損害**，法無明文不得請求
- 被害人不支出費用而維持使用，是自願承擔生活不便

## 肯定說一：實務（107 年 402 號判決，講義 203 頁註 322）：
- 以憲法**適足住房權**（經社文公約承認）為出發點，對民法作**合憲性解釋**
- §213：回復應有狀態＝房屋完整**且可使用**
- §216：依自住計畫本可享有之使用利益未享有＝**所失利益**
- 被害人以可支配其他住處換得免付租金，**不能加惠加害人**；於合理必要範圍內得請求
- 計算：**相當於租金**

## 肯定說二：向明恩（姓名請對講義）：
- 不必拉到居住權，否則汽車等其他物的使用利益保護不到；重點是**物之使用利益**
- 標準：**可感性**（有使用意思，非收藏）＋**重要性**（生活不可或缺、無法替代）
- 汽車例：台北市區有捷運公車 → 可替代 → 無使用利益損害；偏鄉公車一天兩班 → 不可或缺 → 有
- 計算：不用租金（含收益成分），改以**持有成本與維護費**換算

## 📖 法條原文速查

> **§213 I**　負損害賠償責任者，除法律另有規定或契約另有訂定外，應**回復他方損害發生前之原狀**。

> **§216 I**　損害賠償，除法律另有規定或契約另有訂定外，應以填補債權人**所受損害及所失利益**為限。

---

## 📋 實務見解

> **最高法院 107 年第 402 號判決**（講義 203 頁註 322；字號照字幕，請對講義）：被毀損之房屋原係被害人為滿足其本人及共同生活之人基本住房權之需求，且確為其生活上所依賴者，縱被害人因另有居住處所可用而未實際支出租金，該本應支出而未支出之使用對價，係以其可支配其他處所之利益換得，不能加惠於加害人；被害人就房屋使用利益之損害，於合理且必要之範圍內，得請求加害人賠償，以回復應有狀態。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「自住房屋毀損，屋主另租房居住，租金得否請求？」 | **得**，所受損害（§216），無爭議 |
| 「屋主借住親友家未支出費用，依王澤鑑得否請求使用利益損害？」 | **否**，屬非財產上損害，法無明文 |
| 「同上，依實務？」 | **得**，適足住房權合憲性解釋；以**相當於租金**計 |
| 「出租用房屋毀損，得否請求無法居住之損害？」 | **否**，只有租金收益損失（須有出租計畫） |
| 「向明恩判斷物之使用利益應否保護之標準？」 | **可感性＋重要性** |
| 「向明恩如何計算使用利益？」 | **持有成本與維護費**，非租金 |

## 一、判斷流程

```
房屋毀損，不能居住
   ↓
自住房屋？
├─ 否（投資、出租）→ 只論出租或投資利益損失
└─ 是 → 有無支出費用？
         ├─ 有（另租、住飯店）→ §216 所受損害 ✓
         └─ 無（另有房、借住）
              ├─ 王澤鑑：非財產上損害，法無明文 → ✗
              ├─ 實務：適足住房權＋§213＋§216 → ✓（租金）
              └─ 向明恩：可感性＋重要性 → ✓（持有成本）
```

## 二、肯定說兩見解比較

| | 實務（107 年 402 號） | 向明恩 |
|---|---|---|
| 切入點 | 憲法適足住房權 → 合憲性解釋 | 物之使用利益本身 |
| 保護範圍 | 自住房屋 | 房屋、汽車等一切有使用利益之物 |
| 要件 | 為滿足基本住房需求、生活所依賴 | 可感性＋重要性（不可替代） |
| 計算 | 相當於租金 | 持有成本＋維護費 |
| 對實務的批評 | — | 租金含收益（房東要賺），高於純使用價值 |

## 三、持有成本法：算一次

| 項目 | 數字 |
|---|---|
| 持有期間成本（房貸、稅金、維護費加總） | 5,000 萬 |
| 持有年數 | 50 年 |
| 每年使用價值 | 100 萬 |
| 每月使用價值 | 約 8.3 萬 |

- 對照租金法：房貸每月 2 萬，出租通常收超過 2 萬 → 租金多出的是收益，不是使用價值
