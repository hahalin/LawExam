# 民法債權補充2 筆記：特種買賣之買回、試驗買賣與拍賣（§379至§395）

## 這堂課的定位
- 二試債各以買賣、租賃、承攬、保證為主（正課已講）；本堂補選擇題偶爾出的冷門條文
- 老師估計正課已涵蓋八到九成選擇題考點，本堂是剩下的一成

## 買回（§379、§380）
- 出賣人於買賣契約**保留買回權**，得返還所受領價金而買回標的物（§379 I）
  - 訂約時已約定，行使時**不必再經買受人同意**
  - **要物性**：須**返還價金**，買回才有效
- 買回價金另有特約者從其特約（§379 II）
- 原價金的**利息**與買受人就標的物所得的**利益**，**視為**互相抵銷（§379 III）
  - 選擇題陷阱：是「**視為**」，不是「推定」，不得舉反證推翻
- 買回期限**不得超過 5 年**，約定較長者縮短為 5 年（§380）

## 試驗買賣（§384、§386、§387）
- 以買受人**承認標的物**為**停止條件**而訂立的買賣契約（§384）
- 意思表示合致 → **成立**；買受人承認（條件成就）→ **生效**
- 試驗後不表示意見：
  | 情形 | 效果 | 條文 |
  |---|---|---|
  | 標的物**已交付**買受人試驗（帶回家試），不交還、或期限內不拒絕 | **視為承認** | §386 |
  | 標的物**未交付**（在店裡試），期限內不承認 | **視為拒絕** | §387 |

## 拍賣（§391～§395）
- 結構：拍賣表示＝**要約之引誘**；應買＝**要約**；拍定＝**承諾**
- 拍賣因拍賣人**拍板**或其他慣用方法為賣定之表示而**成立**（§391）
- 拍賣人對其所經營的拍賣**不得應買**，也不得使他人為其應買（§392）
- 原則拍歸**出價最高**者；拍賣委任人有反對表示者不在此限（§393）
- 拍賣人認最高價不足，得不為賣定而**撤回**其物（§394）——契約尚未成立，所以用「撤回」不是「撤銷」
- 應買表示，於有出價較高之應買或拍賣物經撤回時，**失其拘束力**（§395）——有人喊 60 萬，先前 50 萬的要約失效

## 附帶：消費借貸移轉所有權（§474）
- 使用借貸：借車，**所有權不移轉**，仍屬貸與人
- 消費借貸：移轉金錢或其他代替物之**所有權**於他方 → 借 100 萬，借用人取得所有權
- 其他借貸問題（要物性、預約、99 年第 7 次民事庭決議的時效起算）見民總、正課

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 買回之性質 | 要物，須返還價金 |
| 價金利息與標的物利益 | **視為**互相抵銷 |
| 買回期限 | **5 年**，逾者縮短 |
| 試驗買賣何時生效 | 買受人**承認**時（停止條件） |
| 帶回家試、不表示 | **視為承認** |
| 店裡試、不表示 | **視為拒絕** |
| 拍賣何時成立 | **拍板**（拍定）時 |
| 拍賣人可否自己應買 | **不可** |
| 消費借貸所有權 | 移轉於借用人 |
