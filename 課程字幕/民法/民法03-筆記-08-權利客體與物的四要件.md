# 民法03 筆記：權利客體與「物」的四要件

> 來源：民法03 課程字幕 01:32:37 ~ 01:42:35

---

## 📖 法條原文速查

> **§66**（不動產）
> I 稱不動產者，謂**土地及其定著物**。
> II 不動產之**出產物**，尚未分離者，為該不動產之**部分**。

> **§67**（動產）
> 稱動產者，為**前條所稱不動產以外之物**。

> **§68**（主物與從物）
> I 非主物之成分，常助主物之效用，而同屬於一人者，為從物。但交易上有特別習慣者，依其習慣。
> II 主物之處分，及於從物。

> **§69**（天然孳息與法定孳息）
> I 稱天然孳息者，謂果實、動物之產物及其他依物之用法所收穫之出產物。
> II 稱法定孳息者，謂利息、租金及其他因法律關係所得之收益。

> **§70**（孳息之歸屬）
> I 有收取天然孳息權利之人，其權利存續期間內，取得與原物分離之孳息。
> II 有收取法定孳息權利之人，按其權利存續期間內之日數，取得其孳息。

> **§246 I**（給付不能之契約）
> 以**不能之給付**為契約標的者，其契約為**無效**。

> **§16**（對照）權利能力及行為能力，不得拋棄。→ 人不是物

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債權是否為權利客體？是否為物？」 | 是**權利客體**（可被支配、可讓與）；**不是物** |
| 「法律上『物』的要件？」 | ① 非人體之成分 ② 人力所能支配 ③ 能獨立滿足人類社會生活 ④ 有體無體均可 |
| 「日月星辰之買賣效力？」 | 非人力所能支配 → 不是物 → 以不能之給付為標的 → **無效**（§246） |
| 「風力、電力、核能是物嗎？」 | **是**，無體物也可以；風力是**動產** |
| 「所有權是權利客體嗎？」 | **不是**。權利是法律創造的抽象概念，不是現實存在的東西 |
| 「地上一粒灰塵是法律上的物嗎？」 | **不是**，無法獨立滿足人類社會生活 |
| 「民總 §66～§70 處理什麼？」 | 只處理**物**；債權讓與、債務承擔等「其他權利客體」是準物權行為，後面講 |

## 一、權利客體在體系中的位置

```
民法總則
├── 權利主體 §6～§65（自然人 §6～§24、法人 §25～§65）← 講完
└── 權利客體：受權利主體所支配的對象
      ├── 物 ← §66～§70 只處理這個
      └── 其他（例：債權。可以買賣、讓與 → 也是被支配的對象）
            → 債權讓與、債務承擔、債務免除 ＝ 準物權行為（後面講）
```

## 二、物的四要件

```
① 非人體之成分
    人是權利主體，不受他人支配（§16 反奴隸的延伸）→ 人體的一部分不會是權利客體
② 人力所能支配
    日月星辰 → 不能支配 → 不是物 → 買賣以不能給付為標的 → §246 無效
    科技進步 → 核能、風力、電力雖無形，可支配 → 是物
③ 能獨立滿足人類社會生活（有被支配的價值）
    地上的灰塵、海邊一粒沙 → 生活上是東西，但無法獨立滿足社會生活 → 不是法律上的物
④ 有體、無體皆可，但不含抽象的權利
    風力、核能 → OK
    所有權、債權 → 法律創造的概念，不是現實存在 → 不是物
```

## 三、民總的三個分類

| 分類 | 條號 |
|------|------|
| 動產／不動產 | §66、§67 |
| 主物／從物 | §68 |
| 孳息（天然／法定） | §69、§70 |

- 物權法還有融通物／不融通物、集合物等，民總先不管。

## 四、檢驗順序：先是物，才分動產不動產

```
這是物嗎？（四要件）
  ├── 不是 → 不會是動產也不會是不動產（「你男朋友是動產還是不動產？」→ 他不是物）
  └── 是  → 是土地或定著物嗎？
              ├── 是 → 不動產（§66）
              └── 否 → 動產（§67：不動產以外之物）→ 風力是動產
```
