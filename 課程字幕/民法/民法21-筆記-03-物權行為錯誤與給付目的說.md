# 民法21 筆記：物權行為錯誤與給付目的說

## 案例型態「買 A 給 B」：
- 甲乙訂立買賣，標的物是 A（電腦），甲包裹時寄錯，把 B（手機）交給乙
- 第一小題常問：甲得否依 §88 撤銷錯誤之意思表示？→ **不得**，錯誤是甲自己的過失
- 第二小題：不能撤銷，甲得否依 §179 請求乙返還 B？

## 早年實務（錯誤示範，考試要跟著批評）：
- 移轉 B 的物權行為**有效且無法撤銷** → 乙受領 B 有物權行為作為法律上原因 → 不成立不當得利

## 通說（學說與現在實務）：
- 早年見解把**給付手段**與**給付目的**搞混
- 物權行為只是移轉所有權的**手段**；法律上原因要找的是背後的**給付目的**（原因關係）
- 甲乙只有買 A 的契約，沒有買 B 的契約 → 給付 B 的目的不存在 → **無法律上原因**，成立不當得利

## 多付價金的變形：
- 104 年律師二試：約定價金 80 萬，買受人匯了 100 萬，**4 年後**才發現
- 錯誤撤銷須在意思表示後 1 年內（§90）→ 已不能撤銷
- 法律上原因若看匯款的物權行為 → 不能請求；看買賣契約 → 只有 80 萬有原因，多付的 20 萬可依 §179 請求
- 更早的考法：買雷射印表機交付噴墨印表機

## 📖 法條原文速查

> **§88 I**　意思表示之內容有錯誤，或表意人若知其事情即不為意思表示者，表意人得將其意思表示撤銷之。但以其錯誤或不知事情，**非由表意人自己之過失**者為限。

> **§90**　前二條之撤銷權，自意思表示後，經過**一年**而消滅。

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

## 📋 實務見解速查

> **74 台上 1378**（講義註 445）：早年見解，認物權行為有效時受領人即有法律上原因。學說批評混淆給付手段與給付目的。（字號依字幕「74年的1378號」，判決內容字幕未唸，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「出賣人因自己過失寄錯物品，得依 §88 撤銷？」 | **不得**（須非由表意人自己之過失） |
| 「物權行為有效，受領人即有法律上原因？」 | **錯**，法律上原因指**給付目的**，不是給付手段 |
| 「買 A 交付 B，出賣人得否依 §179 請求返還 B？」 | **得**，欠缺買 B 的原因關係 |
| 「多付價金逾 1 年不能撤銷，得否請求返還差額？」 | **得**，差額欠缺買賣契約之給付目的 |

---

## 一、手段與目的

```
甲 ──交付 B（物權行為：給付手段）──→ 乙
          背後的給付目的？
          ├─ 買賣 A 的契約 → 不涵蓋 B
          └─ 買賣 B 的契約 → 不存在
                ↓
         無法律上原因 → §179 返還 B
```

## 二、兩種見解對照

| | 早年實務 | 通說 |
|---|---|---|
| 法律上原因看什麼 | 物權行為 | 給付目的（原因關係） |
| 物權行為不能撤銷時 | 有原因，不成立 | 仍無原因，成立 |
| 評價 | 被批評 | 考試採此說 |

## 三、答題順序

1. 先處理撤銷：§88 有過失不能撤銷，或 §90 已逾 1 年
2. 引早年見解並指出混淆手段與目的
3. 以給付目的說認定無法律上原因，成立 §179
