# 民法物權補充2 筆記：留置權之發生要件與對善意留置權人之優先（§928至§937）

## 性質
- 債權人占有他人動產，債權與該動產有牽連關係，債權屆期未受清償時，得留置該動產之權（§928 I）
- **法定**擔保物權：依法律規定發生，沒有「設定留置權」這回事

## 發生要件
1. **占有他人動產**
   - 不得因侵權行為或其他不法原因而占有（§928 II 前段）
   - 債務人的動產：可以
   - 第三人的動產：占有之始**善意且無重大過失**不知非債務人所有，才可以（§928 II 後段反面）
   - 例：甲把 A 車借乙，乙交丙修理；丙善意無重大過失不知車是甲的 → 丙仍取得留置權
2. **債權與動產有牽連關係**
   - 基於動產本身所生（例：為狗支出的飼料費）
   - 基於同一法律關係（例：承攬修車的報酬）
   - 基於同一事實關係（例：被狗咬的侵權賠償）
   - 商人間因營業關係占有動產與其債權，**視為**有牽連關係（§929）
3. **債權已屆清償期**未受清償；債務人**無支付能力**時，清償期前也可留置（§931）
4. **不違反**公序良俗、債權人所負義務或債務人交付時的指示（§930）
   - 例：留置計程車司機的計程車，個案判斷是否違反善良風俗

## 效力範圍（§932）
- 原則就留置物**全部**行使（修理費 20 萬，車值 300 萬，仍可留置整台車）
- 留置物**可分**者，依債權與留置物價值的比例行使

## 對其他物權：善意留置權人優先（§932-1）
- 留置物存有所有權以外之物權者，該物權人**不得對抗善意**留置權人
- 例：甲 A 車先質押給乙（100 萬），乙交丙修車，丙留置權 30 萬；A 車拍得 **105 萬**

| 丙 | 丙 | 乙 |
|---|---|---|
| 善意 | **30** | 75 |
| 惡意 | 5 | **100** |

## 保管、實行與消滅
- 保管：準用 §888～§890、§892（善管注意、孳息、預行拍賣）；**不準用 §891 轉質**（§933）
- 保管必要費用得請求償還（§934）
- 實行（§936）：
  - 定 **1 個月以上**期限通知債務人，期滿不清償 → 準用質權實行規定，就賣得價金優先受償或取得所有權
  - **不能通知**者，清償期屆至後經 **6 個月**仍未受清償，亦得行使
- 消滅（§937）：債務人提出**相當擔保**；並準用 §897～§899（返還、喪失占有、滅失）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 留置權如何發生 | **法定**，非設定 |
| 留置第三人之動產 | 占有之始善意且無重大過失 |
| 商人間營業關係 | **視為**有牽連關係 |
| 清償期前可否留置 | 債務人無支付能力時可以 |
| 可否轉留置 | **不可**（不準用 §891） |
| 留置權與先成立之質權 | 善意留置權人**優先** |
| 實行前通知期限 | **1 個月**以上；不能通知 **6 個月** |
