# 民法16 筆記：未成年人無過失時法定代理人之責任

## 問題：
- 講義 148 頁註 224：行為人**有識別能力**，但因**無過失**而不成立侵權行為，法代要不要負責？

## 案例：
- 7 歲的甲（有識別能力）在公園玩球，球滾走、追不到；乙在公園騎腳踏車撞到球摔傷
- 行為、權利、損害、因果、不法、識別能力都有；卡在**過失**：未成年人以**同齡之人**為標準，一般 7 歲小孩追不到滾走的球，不算過失

## 依條文文義：
- §187 I 以行為人**成立 §184** 為前提 → 甲不成立 → 法代不負 §187 I → 也進不了 §187 III → 被害人自己承擔

## 王澤鑑（參考德國法）：
- 小孩不必負責的原因有兩種：無識別能力（條文已處理），或因**過失標準放寬**而無過失（條文漏未處理）
- 若法代監督有疏懈（例：小孩玩球時法代在滑手機），讓法代免責不合理
- → **類推 §187 I**（後段）令法代**單獨**負責；法代也可**類推 §187 II**，證明監督未疏懈而免責

## 下堂預告：
- 從講義 149 頁「監督疏懈之判斷」等其他要件續講，再進 §188；侵權行為講完後是不當得利、無因管理

> 來源：民法16 課程字幕 02:24:35 ~ 02:30:32（講義 148 頁註 224；字幕至「謝謝各位」完整結束）

## 📖 法條原文速查

> **民法 §187 I**　無行為能力人或限制行為能力人，**不法侵害他人之權利者**，以行為時有識別能力為限，與其法定代理人連帶負損害賠償責任。**行為時無識別能力者，由其法定代理人負損害賠償責任。**
> **民法 §187 II**　前項情形，法定代理人如其監督並未疏懈，或縱加以相當之監督，而仍不免發生損害者，不負賠償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有識別能力之未成年人因無過失而不成立侵權行為，法代是否依 §187 I 負責？」 | 依文義**否**（以行為人成立侵權行為為前提）；王澤鑑：**類推 §187 I** 令法代單獨負責 |
| 「承上，法代得否主張免責？」 | 得**類推 §187 II**，證明監督未疏懈而免責 |
| 「7 歲小孩玩球滾走未追回致他人受傷，是否有過失？」 | 以**同齡之人**為準，通常**無過失** |
| 「此種情形得否適用 §187 III 衡平責任？」 | 依文義**不能**（未成立 §187 I 即無「不能依前二項受賠償」可言），故王澤鑑改走類推 |

## 一、小孩不負責的兩種原因

```
未成年人致他人受損，自己不負 §184
├── 無識別能力 ──────── §187 I 後段：法代單獨負責（條文有規定）
└── 有識別能力但無過失（同齡標準放寬）
      ├─ 文義：§187 不適用 → 被害人自擔
      └─ 王澤鑑：類推 §187 I → 法代單獨負責
                  └─ 類推 §187 II → 法代證明監督無疏懈即免責
```

## 二、案例涵攝（公園玩球）

| 要件 | 甲（7 歲） |
|---|---|
| 行為、權利、損害、因果 | ✓ |
| 不法性 | ✓（無阻卻違法事由） |
| 識別能力 | ✓（知道球滾到路上可能讓人摔傷） |
| 過失 | ✗（同齡標準：一般 7 歲小孩追不到） |
| 結論 | 甲不成立 §184 → 能否向法代請求？→ 類推 §187 I、II |

## 三、類推的理由

- 甲不負責，是因為法律對未成年人的過失「放水」；放水的風險不該全由無辜被害人承擔
- 法代若確有監督疏懈（滑手機沒看小孩），應負責；確實無疏懈，則可免責，與 §187 II 的利益衡量一致
