# 民法06 筆記：撤回 §95 I 後段與 §162 §163「遲到通知」——郵戳為憑的邏輯

> 來源：民法06 課程字幕 00:50:00 ~ 00:59:25

---

## 📖 法條原文速查

> **§95 I 但書**　但**撤回之通知**，同時或先時到達者，不在此限。

> **§162**（撤回要約通知之遲到）
> I 撤回要約之通知，其到達在要約到達之後，而按其傳達方法，**通常在相當時期內應先時或同時到達**，其情形為相對人**可得而知**者，相對人應向要約人即發**遲到之通知**。
> II 相對人怠於為前項通知者，其要約撤回之通知，**視為未遲到**。

> **§163**（撤回承諾通知之遲到）
> 前條之規定，於承諾之撤回準用之。

> **§159**（承諾通知之遲到）→ 結構相同，承諾遲到時要約人應發遲到通知，否則視為未遲到。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「非對話意思表示得否撤回？」 | 得，但撤回通知須**同時或先時**到達（§95 I 但書） |
| 「撤回通知晚於原意思表示到達，撤回必然失敗？」 | **不一定**。符合 §162：方法通常不遲到 ＋ 相對人可得而知 ＋ 相對人**未發遲到通知** → **視為未遲到** → 撤回成功 |
| 「相對人發了遲到通知？」 | 遲到效果確定 → 撤回失敗 → 原意思表示有效 |
| 「平信寄撤回通知，無郵戳可辨？」 | 相對人**無法得知**是否通常應先到 → 無 §162 適用 → 遲到 → 撤回失敗 |
| 「撤回 vs 撤銷？」 | 未生效 → 撤回；已生效 → 撤銷 |
| 「§162 適用於承諾之撤回？」 | 是，§163 準用 |

## 一、§95 I 但書：追回那封信

```
9/10 甲平信寄出 A 意思表示（預計 9/13 到）
9/11 甲反悔 → 用限時掛號寄「撤回通知」
    撤回通知 ≤ 9/13 到（同時或先時）→ 撤回成功 → A 不生效
    撤回通知 > 9/13 到（後時）      → 撤回失敗 → A 生效
```
- 立法理由：寄出到到達有時間差，能在時間差內追回，就當作沒發出。

## 二、§162：「通常不會遲到」的卻遲到了

```
甲 9/11 寄限時掛號撤回，郵局說 9/12 到、最慢 9/13
→ 郵局作業疏失（台北公館分到苗栗公館）→ 9/15 才到，晚於 A
→ 撤回一定失敗嗎？看 §162
```

### 判斷層次
```
① 傳達方法通常會遲到嗎？
   會（本來就慢）→ 遲到正常 → 無 §162 → 撤回失敗
   不會（限時掛號、快捷）→ 進入 ②
② 相對人可得而知嗎？（能從外觀看出這封信通常應先到）
   無法得知（沒郵戳、看不出是平信還是快捷）→ 當作遲到 → 撤回失敗
   可得而知（郵戳為憑）→ 進入 ③
③ 相對人有無即發「遲到通知」？
   有 → 遲到確定 → 撤回失敗，原意思表示有效
   無（怠於通知）→ §162 II 視為未遲到 → 撤回成功 → 原意思表示失效
```

### 郵戳為憑：考選部的例子
- 報名截止 9/15，你 9/13 寄出，考選部 9/20 才收到 → 郵戳 9/13 → 考選部**可得而知**這封信通常不會遲到 → 考選部沒發遲到通知 → 視為未遲到 → 報名有效。
- 郵差疏失的風險不該由表意人承擔，這就是 §162 的精神。

## 三、整理

| 撤回通知到達時點 | 結果 |
|------|------|
| 先時或同時 | 撤回成功（§95 I 但書） |
| 後時，方法本來就慢 | 撤回失敗 |
| 後時，方法通常不慢、相對人可得而知、相對人**發**遲到通知 | 撤回失敗 |
| 後時，方法通常不慢、相對人可得而知、相對人**未發**遲到通知 | **視為未遲到 → 撤回成功**（§162 II） |

- 要約的撤回看 §162，承諾的撤回 §163 準用，兩條一起看。
