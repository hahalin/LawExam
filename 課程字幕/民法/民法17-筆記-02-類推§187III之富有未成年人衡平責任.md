# 民法17 筆記：類推 §187 III 之富有未成年人衡平責任

## 問題背景：
- 未成年人的過失從寬認定（以同齡人為準）；對加害人保護越多，對被害人保護就越少
- 德國討論的典型：歐洲貴族家的小孩侵權，被害人是窮人
- 兩個案例的共同點：**有錢的小孩依法不必負責**（或不必被打折），但他之所以不必負責，是法律放水的結果

## 案例一：有識別能力、因無過失不成立侵權：
- 6 歲甲（很有錢）侵害乙，但依同齡標準甲**無過失** → 乙對甲 §184 ✗
- 乙對甲之法代：類推 §187 I 後段請求（講義 148 頁註 224，上堂講過）；但法代若能類推 §187 II 證明監督未疏懈 → 也落空
- 被害人求償無門 → 德國通說：乙得對甲**類推 §187 III**，由法院斟酌雙方經濟狀況，命甲為全部或一部賠償（扶弱原則）

## 案例二：被害人無識別能力，不成立與有過失：
- 乙侵害 6 歲甲（無識別能力）；甲在路邊玩球沒注意來車
- 乙想主張 §217 與有過失 → 甲無識別能力即無過失，**§217 要件不合**，乙須全部賠償
- 甲有錢、乙是騎機車送外送的人 → 德國通說：**類推 §187 III**，由法院斟酌經濟狀況**減輕或免除**乙的賠償

## 考試提醒：
- 屬研究所程度考題；寫法：先用一般規定涵攝（§187 I、III、§217 都不合）→ 指出被害人求償無門的不合理 → 類推 §187 III 另闢路徑

## 📖 法條原文速查

> **§187 III**　如不能依前二項規定受損害賠償時，法院因被害人之聲請，得斟酌行為人及其法定代理人與被害人之**經濟狀況**，令行為人或其法定代理人為全部或一部之損害賠償。

> **§217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有識別能力之未成年人因無過失不成立侵權，法代又證明監督未疏懈，被害人得否請求？」 | 依文義求償無門；德國通說：對未成年人**類推 §187 III** |
| 「無識別能力之被害人得否成立與有過失？」 | **否**，無識別能力即無過失，§217 要件不合 |
| 「承上，加害人能否請求減輕賠償？」 | 德國通說：**類推 §187 III**，斟酌經濟狀況減免 |
| 「§187 III 衡平責任斟酌的是什麼？」 | 雙方**經濟狀況**，不是行為輕重 |

## 一、兩個案例並排

| | 案例一 | 案例二 |
|---|---|---|
| 有錢的小孩是 | 加害人 | 被害人 |
| 法律放水在哪裡 | 過失以同齡人為準 → 無過失 | 無識別能力 → 無與有過失 |
| 依一般規定 | 被害人求償無門 | 加害人全額賠償 |
| 德國通說 | 類推 §187 III，命小孩賠償 | 類推 §187 III，減免加害人賠償 |
| 講義 | 151 頁第一段 | 151 頁第二段 |

## 二、案例一的求償路徑

```
乙（被害人）
├── 對甲（6 歲、有識別能力、無過失）
│     ├─ §184 ✗（同齡標準 → 無過失）
│     └─ 類推 §187 III ← 德國通說，最後一條路
└── 對甲之法代
      ├─ 類推 §187 I 後段（筆記：民法16-13）
      └─ 法代類推 §187 II 舉證免責 → 落空
```

## 三、為什麼可以類推

- 有錢人在這兩個案例裡都**享受到法律的好處**：一個因過失標準放寬而免責，一個因欠缺識別能力而不被打折
- 但有錢人沒有完全享受這些好處的必要：案例一的小孩若用一般標準可能有過失；案例二的小孩在路邊玩球，對損害發生也有原因力
- 交給法院斟酌經濟狀況，與 §187 III 衡平責任背後的**扶弱原則**一致
