# 民法20 筆記：適法無因管理之互相求償與解題步驟

## 考題長相：
- 無因管理平安無事就沒得吵；考題都是管理過程中**本人受損**、**管理人受損或有支出**，問雙方怎麼互相請求
- 第一步永遠是：先判斷**適法或不適法**，再分別檢驗各請求權

## 本人 → 管理人（本人受損）：
- **§184**：適法無因管理可阻卻違法，但限**管理必然發生**之損害
- **§227**（法定之債的債務不履行）：看有無違反**善良管理人注意**
- 責任成立後，再看能否依 **§175** 急迫管理免責（見民法20-筆記-07）

## 管理人 → 本人（管理人受損或支出）：
- **§176 I**：適法 → 一定可以；只有財產上損害，沒有慰撫金（見民法20-筆記-08）
- 本人對管理人通常無侵害行為 → 沒有 §184
- **§179**：適法無因管理本身就是**法律上原因** → 本人受利益**不成立不當得利**

## 跳河自殺案：
- 甲在碧潭跳河，死意甚堅；乙下水施救，拉扯中把甲的手折斷，甲的手錶也脫落；乙自己嗆傷
- 先判斷：未受委任並無義務、為甲管理事務；救人在承擔上利於甲；甲求死意思違反善良風俗 → 違反也屬適法（§174 II）→ **適法無因管理**
- 甲對乙（手折斷）：
  - §184：拉扯中折斷是否為救援必然發生 → 是則阻卻違法
  - §227：善良管理人在施救中也可能折斷 → 未違反注意義務即不負責（個案判斷）
- 乙對甲（嗆傷）：甲沒有侵害乙 → 依 §176 I 請求**財產上**損害賠償

## 符水案再走一次（本人方面）：
- 乙對丙：適法 → §176 I 請求 100 元費用
- 甲喝符水後又拉肚子，丙對乙：
  - §184：拉肚子不是管理必然發生之損害 → 不阻卻違法 → 可主張
  - §227：帶去宮廟不是正常就醫管道 → 違反善良管理人注意 → 可主張
- 同一事件：乙可請求費用，丙也可請求損害賠償，兩者並存

## 📖 法條原文速查

> **§176 I**　管理事務，利於本人，並不違反本人明示或可得推知之意思者，管理人為本人支出必要或有益之費用，或負擔債務，或受損害時，得請求本人償還其費用及自支出時起之利息，或清償其所負擔之債務，或**賠償其損害**。

> **§179**　無**法律上之原因**而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

> **§227 I**　因可歸責於債務人之事由，致為不完全給付者，債權人得依關於給付遲延或給付不能之規定行使其權利。→ 加害給付另見 §227 II

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「因適法無因管理而受利益，構成不當得利？」 | **否**，適法無因管理為法律上原因 |
| 「救助自殺者時造成之必然損害，自殺者得依侵權行為請求？」 | **否**，阻卻違法 |
| 「救人者自己受傷，得向被救者請求？」 | 依 **§176 I**，僅財產上損害 |
| 「管理人因手段不當造成本人損害？」 | 本人得依 **§227** 或 §184 請求，再審 §175 |

---

## 一、解題步驟

```
① 適法或不適法無因管理？
② 本人受損 → 管理人
    §184：必然發生之損害？→ 阻卻違法
    §227：違反善管注意？
    → 成立後：§175 急迫免責？
③ 管理人受損／支出 → 本人
    §176 I（適法）；無慰撫金
    §179：適法 → 不成立
```

## 二、兩案對照

| | 跳河自殺案 | 符水案 |
|---|---|---|
| 適法？ | ✓（§174 II） | ✓ |
| 本人損害 | 手折斷：可能必然發生 | 拉肚子：非必然發生 |
| 管理人責任 | 視個案，可能不負 | §184、§227 負責 |
| 管理人請求 | 嗆傷：§176 I 財產上 | 100 元：§176 I |
