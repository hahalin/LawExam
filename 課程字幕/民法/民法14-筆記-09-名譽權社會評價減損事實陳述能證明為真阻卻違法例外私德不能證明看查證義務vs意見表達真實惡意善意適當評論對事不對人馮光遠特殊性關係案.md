# 民法14 筆記：人格權③名譽權——名譽＝**社會上的評價**，侵害＝減損他人社會評價；兩種類型、兩套標準：**事實陳述**（某人有沒有做某事，可驗證真偽）：第一階段能否**證明為真**——能 → 原則**阻卻違法**（社會評價未因真話減損），例外**涉及私德**（非公眾人物之外遇等，與公共討論無關）縱屬實仍可能構成；不能 → 第二階段有無盡**查證義務**——有（客觀證據足以合理相信為真）→ 無過失不成立；無 → 成立。**意見表達**（餐廳好不好吃、某人是否卑劣，個人感受）：看有無**真實惡意**——**善意且適當之評論**（對事不對人、可受公評之事）→ 不構成；為詆毀而發（對人不對事）→ 構成；背景：名譽權保護 vs **言論自由**之衝突，我國高度保障言論自由，被害人須忍受一定界限；馮光遠「特殊性關係」案：一審認對事不對人勝訴，二審認對人不對事判賠（字幕：50 萬）→ 界線在法官一念之間，考試不用追標準答案，寫出判斷標準即可

## 📖 法條原文速查

> **民法 §195 I**　不法侵害他人之身體、健康、**名譽**、自由、信用、隱私、貞操，或不法侵害其他人格法益而情節重大者，被害人雖非財產上之損害，亦得請求賠償相當之金額。其名譽被侵害者，並得請求回復名譽之適當處分。
> **刑法 §310 III**　對於所誹謗之事，能證明其為真實者，不罰。但涉於私德而與公共利益無關者，不在此限。（事實陳述「能證明為真／私德例外」之對照條文）
> **刑法 §311 ③**　以善意發表言論，對於可受公評之事，而為適當之評論者，不罰。（意見表達「善意適當評論」之對照條文）
> **釋字 509**（講義 65 頁，已核對）：行為人雖不能證明言論內容為真實，但依其所提證據資料，認為行為人有**相當理由確信其為真實**者，即不能以誹謗罪之刑責相繩；亦不得以此項規定而免除檢察官或自訴人於訴訟程序中，依法應負行為人故意毀損他人名譽之舉證責任，或法院發現其為真實之義務。刑法 §310 III 與憲法保障言論自由之旨趣並無牴觸。
> **釋字 656**（講義 65 頁註 118）：§195 I 後段「回復名譽之適當處分」，如屬以判決命加害人公開道歉，而未涉及加害人自我羞辱等損及人性尊嚴之情事者，即未違背憲法 §23 比例原則，不牴觸不表意自由之保障。

## 📋 實務見解速查

> **最高法院 102 年台上字第 1293 號判決**（講義 65 頁註 117）：刑法（誹謗罪）與民法（侵權行為）所規範者均為人格權保護與言論自由，釋字 509 就刑法誹謗罪所創設之**合理查證基準（真實相當性）**，對民法侵權行為亦應同為適用，始能維護法秩序之無矛盾性。合理查證因攸關侵害名譽權「違法性之阻卻」，在民事侵權行為上，自應由**行為人（加害人）負舉證責任**；行為人是否已盡其舉證責任，為顧及言論自由，不能一概作嚴格之認定，應就個案事實分別斟酌——依「**行為人及被害人究係私人、媒體或公眾人物**」「**名譽侵害之程度**」「**與公共利益之關係**」「**資料來源之可信度**」「**查證對象之人、事、物**」等因素，定其合理查證義務之高低。（本件：上訴人為政治人物，時值領導反貪腐政治運動，被上訴人依消息來源、取得之證據及上訴人之澄清難以盡除疑慮，可認已盡合理查證、有相當理由確信為真實，且係就具重大公共利益之政治運動為適當評論，不具違法性）
> **釋字 656 林子儀大法官不同意見書**（講義 65～66 頁）：民事上應**類推適用刑法 §310 III 前段**。行為人**明知**所言不實仍率意為之 → 除有其他阻卻違法事由外構成侵權；能證明為真 → 不構成；無法證明為真時，應視**言論對象之身分與言論內容之性質**設定不同程度之注意義務（見下表）；是否已踐行查證與合理判斷，法院應依個案斟酌行為人與被害人之身分、名譽侵害之程度、所涉言論內容之公共利益大小、時效性與來源之可信度、查證成本及查證對象等綜合判斷。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「名譽權之侵害如何認定？」 | 名譽＝社會評價；侵害＝使社會評價減損。先區分**事實陳述**／**意見表達** |
| 「事實陳述型判斷順序？」 | ①能否**證明為真**：能 → 原則阻卻違法（說他酒駕他真的酒駕，社會評價未減損），例外：**涉及私德**、非公眾人物、與公共討論無關（如外遇）→ 縱屬實仍可能構成 ②不能證明為真：有無盡**查證義務**：有（有客觀證據可合理相信為真）→ 無過失，不成立；無 → 成立 |
| 「媒體報導不實但已盡查證，是否成立？」 | **不成立**（無過失）。這是言論自由與名譽權的平衡：被害人須忍受 |
| 「意見表達型判斷？」 | 有無**真實惡意**：**善意且適當**之表達（對事不對人，如據實分享餐廳難吃、對總統用人等可受公評之事為評價）→ 不構成；為詆毀該人而發（對人不對事）→ 構成 |
| 「事實陳述 vs 意見表達例？」 | 餐廳是否用美國豬＝事實陳述；餐廳好不好吃＝意見表達。公眾人物有無請狗仔拍照＝事實；公眾人物是否臭不可聞＝意見 |
| 「無法證明為真時，注意義務的高低怎麼分？（林子儀，講義 66 頁註 119）」 | 看**對象**×**內容**：①對**公眾人物**（公職人員、對公共事務討論有實質影響力之政治人物）且涉**公益** → 違反善良管理人注意義務**且情節重大**（極端違反一般負責任且對他人名譽權有適當尊重之人所應為之查證與合理判斷）始負責 ②對公眾人物但明顯僅涉**私德** → 違反善良管理人注意義務即負責 ③對**一般私人**但內容與**公益**有關 → 違反善良管理人注意義務即負責 ④對一般私人且僅涉**私德** → 無法證明為真、又無其他阻卻違法事由即負責（門檻最低） |
| 「查證義務由誰舉證？」 | 合理查證攸關違法性之阻卻 → 由**行為人（加害人）**負舉證責任，但為顧及言論自由不能一概嚴格認定（102 台上 1293） |
| 「馮光遠案？」 | 評論馬英九與金溥聰「特殊性關係」：讀作「特殊**性關係**」→ 對人不對事（二審，判賠）；讀作「特殊的**性關係**」→ 對事不對人（一審，勝訴）→ 真實惡意有無在法官一念之間 |

## 一、判斷流程圖

```
名譽受損（社會評價減損）
├ 事實陳述
│   ├ 能證明為真 → 原則不構成（阻卻違法）
│   │               例外：涉私德、與公共利益無關 → 仍可能構成
│   └ 不能證明為真
│        ├ 已盡查證義務（合理相信為真）→ 無過失 → 不構成
│        └ 未盡查證義務 → 構成
└ 意見表達
    ├ 善意、適當、對事不對人（可受公評之事）→ 不構成
    └ 真實惡意、為詆毀而發（對人不對事）→ 構成
```

## 一之二、講義 66 頁註 119 整理表（林子儀）

| | 內容涉公益 | 內容僅涉私德 |
|---|---|---|
| **能證明為真** | 不罰（阻卻違法） | 仍構成名譽權侵害，應負賠償責任 |
| **無法證明為真／對公眾人物** | 違反善良管理人注意義務**且情節重大**＝須負責 | 違反善良管理人注意義務＝須負責 |
| **無法證明為真／對一般私人** | 違反善良管理人注意義務＝須負責 | 無法證明為真且無阻卻違法事由＝須負責 |
| **意見表達**（刑法 §311） | 善意且適當評論＋可受公評之事 → 不罰；非可受公評之事 → 不阻卻違法 | 惡意或不適當評論 → 不阻卻違法 |

- 老師上課講的「能證明為真→阻卻違法／私德例外／不能證明→查證義務／意見表達→真實惡意」就是這張表的簡化版；二試題目若給了身分（政治人物／私人）與內容（公益／私德）線索，要套這張表分級。

## 二、為什麼言論自由優先

- 言論自由是國家進步的動力；不同意見不能提出，社會失去生命力。
- 「言論自由最大的敵人就是名譽權」——講錯話一定減損他人評價，但**講錯話不一定要罰**，界線由上述標準劃。
- 網路評價（餐廳心得）有資訊揭露價值，受保護；不合口味者可另發文平衡。
