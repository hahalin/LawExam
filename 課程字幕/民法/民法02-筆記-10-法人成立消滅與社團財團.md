# 民法02 筆記：法人的成立、消滅與社團／財團

> 來源：民法02 課程字幕 01:48:47 ~ 02:04:54

---

## 📖 法條原文速查

> **§25**（法人成立法定原則）
> 法人非依本法或其他法律之規定，不得成立。

> **§30**（法人設立登記）
> 法人非經向主管機關**登記**，不得成立。

> **民法總則施行法 §10 I**
> 依民法總則規定法人之登記，其主管機關為該法人**事務所所在地之法院**。
> → 建議查閱最新六法原文

> **§45**（營利社團之設立）
> 以**營利**為目的之社團，其取得法人資格，依特別法之規定。

> **§46**（公益社團之設立）
> 以**公益**為目的之社團，於登記前，應得主管機關之**許可**。

> **§59**（財團之設立）
> 財團於登記前，應得主管機關之**許可**。

> **§40 II**（清算中法人之存續）
> 解散之法人，於**清算之必要範圍內，視為存續**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人成立之要件？」 | ① 法律依據（§25）② 登記（§30）③ 公益法人另須**許可**（§46、§59） |
| 「民法上一般法人向何機關登記？」 | **法人事務所所在地之法院**（民總施行法 §10）；公司才是經濟部 |
| 「營利社團法人須經許可？」 | **不須**（準則制，§45 依特別法如公司法） |
| 「可否設立營利之財團法人？」 | **不可**。財團法人只有公益；基金會一定是公益 |
| 「社團法人可以是營利或公益？」 | **都可以**（§45 營利、§46 公益） |
| 「法人解散即消滅？」 | **否**。須至**清算終結**；清算必要範圍內視為存續（§40 II） |
| 「財團法人之意思決定機關？」 | **捐助章程**（沒有總會）；社團是**社員總會**；兩者行為機關都是**董事** |

## 一、為什麼需要法人

```
人
├── 自然人：自然孕育的人類
└── 法人：法律創造的權利主體

起源：大航海時代 → 一個人航海風險太高 → 1000 人組團，一人損失 1 萬
    → 出了糾紛要告誰？1000 個人？帶頭的？團隊？
    → 給組織法律上的地位（擬制說 → 目的財產說 → 實在說）
    → 直接把組織當一個人：單獨享受權利、負擔義務，不再牽扯背後成員
```

## 二、社團 vs 財團

| 比較項目 | 社團法人 | 財團法人 |
|---------|---------|---------|
| 組織基礎 | **人**（社員） | **財產**（捐助人捐出的錢；俗稱基金會） |
| 意思決定機關 | **社員總會** | **捐助章程**（沒有總會） |
| 行為機關 | 董事（法人的手足） | 董事 |
| 目的 | 營利或公益皆可 | **只能公益** |
| 設立 | 營利：§45 準則制；公益：§46 許可制 | §59 許可制 |
| 條文範圍 | §45～§58 | §59～§65 |

- 「財團法人」不是「財團」，是把一筆錢擬人化。
- 通則 §25～§44：社團、財團都適用。

```
                  有法律依據（§25）＋ 登記（§30）
營利社團 §45  →  依特別法（公司法等）即可      → 準則制
公益社團 §46  →  ＋ 主管機關許可                → 許可制
公益財團 §59  →  ＋ 主管機關許可                → 許可制
營利財團      →  法律沒規定 → 不存在
```

## 三、成立：法律依據 ＋ 登記（＋ 許可）

1. **法律依據（§25）**：法律創造的人，一定要有法律為本（銀行→銀行法、保險公司→保險業法）。
2. **登記（§30）**：
   - 公司 → 經濟部（商業司）
   - 民法上一般法人 → **法人所在地之法院**（民總施行法 §10；老師：超級冷知識，選擇題考過）
3. **許可**：只有公益法人要（§46 社團、§59 財團）。

## 四、消滅：解散 → 清算完成

```
自然人：出生 ─────────── 死亡（有繼承人處理財產、債務）
法人  ：成立 ─── 解散 ─── 清算終結 ＝ 消滅
                   ↑ 營業停下來，但不能死：財產、債務沒人處理
                   → §40 II 清算必要範圍內「視為存續」（被強迫活著）
```
