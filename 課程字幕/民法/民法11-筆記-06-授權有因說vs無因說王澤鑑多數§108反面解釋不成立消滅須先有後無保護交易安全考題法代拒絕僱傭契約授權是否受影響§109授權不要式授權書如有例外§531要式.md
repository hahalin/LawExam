# 民法11 筆記：沒有原因關係（或原因關係無效、不成立）還能不能授權——有因說（事出必有因、§108 反面推論）vs 無因說（王澤鑑，多數：沒有法條禁止單獨授權；§108「消滅」先有後無，推不出沒有原因就不能授權；保護交易安全）；考題：法代拒絕承認僱傭契約，授權是否受影響；§109 授權書：授權不要式，§109 讀作「如有授權書」；例外 §531 委任事務之法律行為為要式者，授權亦應要式（§758 抵押權設定）

> 來源：民法11 課程字幕 00:46:20 ~ 00:58:20

---

## 📖 法條原文速查

> **§108 I**　代理權之消滅，依其所由授與之法律關係定之。
> **§109**　代理權消滅或撤回時，代理人須將授權書交還於授權者，不得留置。
> **§531**　為委任事務之處理，須為法律行為，而該法律行為，依法應以文字為之者，其處理權之授與，亦應以文字為之。其授與代理權者，代理權之授與亦同。
> **§758 II**　前項行為（不動產物權依法律行為而取得設定喪失變更），應以書面為之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有因說之理由？」 | ① 事出必有因：社會上不會有人無緣無故單純授權，一定是為了僱傭、委任等勞務契約 ② §108 I 代理權隨原因關係消滅 → 授權與原因是生命共同體 → 沒有原因就不能授權（反面推論） |
| 「無因說（王澤鑑，多數說）之理由？」 | ① 不常見不代表不可能，**沒有任何法條說不能單獨授權**；純粹授權，被授權人取得資格、對我無義務，哪裡不行 ② §108 的用語是「**消滅**」——先有後無才叫消滅（要先有體脂肪才能消滅體脂肪）→ §108 的前提是一個有效的授權，它只處理「有效授權因原因消滅而消滅」，**不處理原因無效能不能授權** → 反面推論不成立 ③ 隱藏版好處：**保護交易安全** |
| 「甲與限制行為能力人乙訂僱傭契約並授與代理權，法定代理人拒絕承認僱傭契約；乙代理甲與丙締約效力？」 | 僱傭契約 §79 經拒絕不生效力。授權：(a) 受僱傭契約無效影響？**無因說：不受**；有因說：受 → 不能授權 → 無權代理 §170 效力未定 (b) 受乙是限制行為能力人影響？**不受**（無損益中性行為，類推 §77 但書）→ 無因說下：有權代理，甲丙契約有效 |
| 「無因說與交易安全？」 | 店長派 16、17 歲的小毛頭接洽，你敢買嗎？無因說下就算僱傭契約無效，授權仍有效，契約仍有效 → 降低契約無效的風險；勞動法 15 歲就能打工，沒必要解釋得那麼嚴 |
| 「授權是否為要式行為？§109 之『授權書』？」 | **不要式**。§109 讀作「代理權消滅或撤回時，**如有**授權書，應交還不得留置」，有無授權書皆可。考點不在交還，在「授權一定要有授權書嗎」→ 不一定 |
| 「要式之例外？」 | **§531**：委任事務須為法律行為，且該法律行為依法應以文字為之（如 §758 抵押權設定要書面）→ 處理權與代理權之授與亦應以文字為之 |

## 一、兩說

| | 有因說 | 無因說（王澤鑑、多數） |
|---|---|---|
| 社會現象 | 單純授權不存在，一定伴隨勞務契約 | 不常見 ≠ 不可能，法無禁止 |
| §108 解讀 | 代理權隨原因消滅 → 授權依附原因 → 無原因不能授權 | 「消滅」以有效授權存在為前提，§108 只管「因原因消滅而消滅」，管不到「無原因能否授權」 |
| 效果 | 原因無效 → 不能授權 → 無權代理 | 原因無效 → 授權仍有效 → 有權代理 |
| 政策 | — | 保護交易安全（王澤鑑最愛的法理） |

## 二、考題永遠長這樣

```
甲（店長）─僱傭契約─ 乙（限制行為能力人）；甲授與乙代理權；法代拒絕承認僱傭契約
乙代理甲與丙締約 → 效力？
① 僱傭契約：§79 → 法代拒絕 → 不生效力
② 授權受不受影響？
   (a) 受僱傭契約無效影響？ 無因說：否／有因說：是 → 無權代理 §170
   (b) 受乙是限制行為能力人影響？ 否（中性行為，類推 §77 但書，不須法代同意）
③ 無因說 → 有權代理 → 代理行為 §104 → 甲丙契約有效
```

- 與民法10 筆記 01 的三階段同一個題型，這裡把「授權無因」的爭議補完。

## 三、§109 與授權的方式

```
原則：授權不要式（口頭即可）→ §109「授權書」＝ if 有授權書才交還
例外：§531 → 委任 ＋ 所託之法律行為依法要式（§758 II 書面）→ 代理權之授與也要以文字為之
```
