# 民法06 筆記：§96 對無／限制行為能力人為意思表示（到達法代才生效）與 §75 §77 的關係；§97 公示送達

> 來源：民法06 課程字幕 01:08:15 ~ 01:15:00

---

## 📖 法條原文速查

> **§96**（向無行為能力人或限制行為能力人為意思表示）
> 向無行為能力人或限制行為能力人為意思表示者，以其通知**達到其法定代理人時**，發生效力。
> → 用語「達到」→ 針對**非對話**設計；對話意思表示通說**類推**（於法代瞭解時生效）

> **§97**（公示送達）
> 表意人**非因自己之過失**，不知相對人之姓名、居所者，得依民事訴訟法公示送達之規定，以**公示送達**為意思表示之通知。

> **§75 前段**　無行為能力人之意思表示，無效。
> **§76**　無行為能力人由法定代理人代為意思表示，並代受意思表示。
> **§77**　限制行為能力人為意思表示及受意思表示，應得法定代理人之允許。但純獲法律上利益，或依其年齡及身分、日常生活所必需者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「向限制行為能力人以非對話為意思表示，何時生效？」 | 通知**達到其法定代理人時**（§96） |
| 「向無行為能力人以對話為意思表示？」 | **類推 §96**，於法代**瞭解**時生效（§96「達到」只寫非對話） |
| 「§96 與 §75、§77 是否矛盾？」 | **否**。§96 是「建議你跟法代做」；你硬要跟本人做 → 無行為能力人 → §75 無效；限制行為能力人 → §77～§85（允許？例外？效力未定） |
| 「向限制行為能力人為意思表示，該行為屬純獲法律上利益／日常生活所必需／§83 詐術？」 | 他自己可以受領 → **直接對本人為之即可**，不需到達法代 |
| 「承租人人間蒸發，出租人不知其姓名居所，如何終止租約？」 | **§97 公示送達**（非因自己過失不知相對人姓名居所） |

---

## 一、§96 的定位：法律給你的建議

```
甲要對 乙（無行為能力）／丙（限制行為能力）為意思表示，法代都是丁

非對話：寄給乙／丙 → 原則不生效 → 要到達丁 → §96 直接適用，到達丁時生效
對 話：對乙／丙說 → 原則不生效 → 要對丁說 → 類推 §96，丁瞭解時生效
```

### 與 §75、§77 的關係：兩條路，不矛盾
| 你的選擇 | 適用 |
|------|------|
| 聽建議：跟法代丁做 | §96（非對話到達丁／對話類推於丁瞭解時）→ 沒事 |
| 不聽建議：硬跟乙（無行為能力）做 | §75 無效（乙無受意思表示的能力；§76 由法代代受） |
| 不聽建議：硬跟丙（限制行為能力）做 | 先看是不是丙自己能做的（§77 但書純獲法律上利益、日常生活所必需；§83 詐術）→ 能 → 直接對丙即可；不能 → 回 §77～§85：有允許？沒有 → 單獨行為 §78 無效、契約 §79 效力未定 |

- 老師：§96 是在告訴你「跟他的法代做就好，不要去找他」；找他就有無效／效力未定的風險。

## 二、§97 公示送達：找不到人怎麼辦（冷知識，考過一次）

#### 事實
套房月租 8,000 租給「阿呆」，從未補訂租約、不知其本名、身分證、地址、電話。某日阿呆人間蒸發，欠租兩個月。

#### 分析
```
終止租約要對相對人為意思表示（對話或非對話都要有相對人）
→ 表意人非因自己過失不知相對人姓名居所 → §97 → 依民訴公示送達規定
→ 法院公告欄張貼，期間屆滿即生送達效力 → 可終止租約、另租他人
```
- 「非因自己之過失」：老師案例中房東從沒要資料，是否算無過失？考試通常直接給「非因過失」的條件。民訴公示送達的生效期間請查民訴相關條文。
