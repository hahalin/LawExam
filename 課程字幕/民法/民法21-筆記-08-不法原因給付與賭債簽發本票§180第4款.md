# 民法21 筆記：不法原因給付與賭債簽發本票（§180第4款）

## 本文：拒絕保護：
- 賭博、毒品買賣、性交易 → 違反強行規定或善良風俗，依 §71、§72 **無效**
- 依 §179 本來可請求返還（無法律上原因），但 §180④ 不准
- 理由（**拒絕保護說**）：當事人把自己置於法律秩序之外；若允許事後要回，等於鼓勵大家從事不法行為

## 但書：不法原因僅存在於受領人一方：
- 例：甲擄走乙的鴿子要求贖金，乙怕鴿子被滅口而付款 → 不法只在甲 → 乙**得**請求返還

## 經典題：賭債簽發本票：
- 甲是莊家，乙賭輸 500 萬；甲要乙「留小指頭或留本票」，乙簽發 500 萬本票
- 乙得否依 §179 請求甲返還本票？
- 三步：§179 成立？→ §180③？→ §180④？
- **§179**：甲取得本票（受利益）；賭債依 §72 無效，無法律上原因；乙負擔票據債務（受損害）→ 成立
- **§180③**：甲抗辯「乙明知沒有欠我錢還簽本票」→ 不適用：第一句要件是「**因清償債務**而為給付」，**賭債非債**，根本沒有可清償的債務
- **§180④**：不法原因存在雙方，也沒有但書問題，為何仍不適用？→ 簽發本票**不是給付**：只是把賭債換成票據債務，甲的財產一塊錢都沒增加；§180④ 的給付須使受領人**終局保有**該財產
- 結論：兩款都擋不住 → 乙得請求返還本票

## 📖 法條原文速查

> **§180**　給付，有左列情形之一者，不得請求返還：
> 三、**因清償債務而為給付**，於給付時明知無給付之義務者。
> 四、**因不法之原因而為給付者**。但不法之原因僅於受領人一方存在時，不在此限。

> **§71**　法律行為，違反強制或禁止之規定者，無效。但其規定並不以之為無效者，不在此限。

> **§72**　法律行為，有背於公共秩序或善良風俗者，無效。

---

## 📋 實務見解速查

> **最高法院 101 年判決**（講義 297～298 頁）：賭債非債，本不生債之關係；為賭債簽發本票，舊債務為賭債、新債務為本票，自無給付義務可言，**不適用 §180③**。§180④ 之規範目的在於當事人從事不法行為而置身法律秩序之外，無保護必要；所稱給付，係指本於受損人之意思所為財產之給予，且給付目的在使受領人**終局保有**該財產，簽發本票不屬之。（要旨改寫；字號字幕未唸，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「因賭博所為給付，得否請求返還？」 | 原則**否**（§180④） |
| 「被擄人勒贖所付贖金，得否請求返還？」 | **得**，不法原因僅存在於受領人（但書） |
| 「為賭債簽發本票，有 §180③ 之適用？」 | **否**，賭債非債，非「因清償債務」 |
| 「為賭債簽發本票，有 §180④ 之適用？」 | **否**，簽發本票非給付（未使受領人終局保有） |
| 「賭輸簽發本票，得否依不當得利請求返還本票？」 | **得** |

## 一、賭債本票的檢驗順序

```
§179：甲取得本票、賭債無效、乙負票據債務 → 成立
   ↓
§180③：「因清償債務而為給付」？ 賭債非債 → ✗
   ↓
§180④：「給付」？ 簽本票未使甲終局保有財產 → ✗
   ↓
乙得請求返還本票
```

## 二、§180④ 本文與但書

| | 不法在誰 | 結論 | 例 |
|---|---|---|---|
| 本文 | 雙方或給付人 | 不得請求 | 賭博、毒品、性交易 |
| 但書 | 僅受領人 | 得請求 | 擄人（鴿）勒贖 |
