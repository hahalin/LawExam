# 民法16 筆記：§185I後段共同危險行為與天燈案

## 讀條文的關鍵：
- 「不能知其中孰為加害人者，亦同」不能單獨讀，要接在「數人共同不法侵害他人之權利」後面一起讀

## 要件與效果：
- **每個人都要有 §184 的行為**，只是不知道結果是誰造成的
- 立法只**推定因果關係**，其他要件（每人皆有侵權行為）仍須具備
- 被害人證明：每人都有行為＋自己受有損害 → 全體連帶負責；誰說「不是我」，由他自己證明

## 為什麼需要這條：
- 若個別依 §184 起訴，會卡在**事實上因果關係**：條件理論「若無甲之行為，丁不會受傷」不成立，因為還有乙丙 → 告誰都輸
- 例：甲乙丙從山上推石頭，一顆砸到人；少年在公園打群架，每人都說只打地板、打椅子

## 天燈案（講義 140 頁註 215）：
- 多人參加放天燈活動，**只有一盞**釋放失敗引發火災
- 最高法院：只有一個侵權行為，與「數人均有不法侵害行為」不同 → **不得**要求全體負共同危險行為之連帶責任
- 典型適用：全部或數盞都釋放失敗，每人都有侵權行為，只是不知哪一盞燒的

## 楊芳賢（字幕作楊方賢）：
- 甲乙同車，超速撞人後立刻下車，無證據顯示誰駕駛，兩人都否認
- 只有一人駕駛＝只有一個侵權行為 → 不能直接適用；但為降低被害人舉證負擔，可**類推** §185 I 後段

## 📖 法條原文速查

> **民法 §185 I**　數人共同不法侵害他人之權利者，連帶負損害賠償責任。**不能知其中孰為加害人者，亦同。**

---

## 📋 實務見解速查

> **最高法院 95 年度台上字第 2388 號判決**（講義 140 頁註 215；字幕僅唸「95年的2388號」，字號請對講義）：參加天燈活動之釋放者係個別釋放，僅因**一盞**天燈釋放失敗引發火災，顯係個別釋放者所致，與數人均有不法侵害他人權利之情形有別，無令全體釋放者同負共同危險行為連帶責任之理。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§185 I 後段推定何種要件？」 | 只推定**因果關係**；每人仍須有侵權行為 |
| 「多人放天燈，僅一盞釋放失敗致火災，能否令全體連帶負責？」 | **否**（95 台上 2388）：只有一個侵權行為，不構成共同危險行為 |
| 「共同危險行為中，主張非由其造成損害者，由誰舉證？」 | **行為人**自證；被害人不必證明誰造成損害 |
| 「甲乙同車，不知何人駕駛肇事，被害人得否請求連帶賠償？」 | 不能直接適用（只有一個侵權行為）；楊芳賢：可**類推** §185 I 後段 |
| 「若無 §185 I 後段，被害人個別依 §184 請求會卡在何要件？」 | **事實上因果關係**（條件理論不成立） |

## 一、共同危險行為的推定結構

```
被害人證明：甲乙丙皆有危險行為 ＋ 損害
        ↓（§185 I 後段推定因果關係）
甲乙丙連帶負責
        ↓
個人若證明損害非其所致 → 免責
```

## 二、為何個別起訴會輸

| 被告 | 條件理論檢驗 | 結果 |
|---|---|---|
| 甲 | 若無甲推石頭，丁仍可能被乙或丙的石頭砸到 | 事實上因果關係 ✗ |
| 乙、丙 | 同上 | ✗ |

## 三、天燈案：一盞 vs 多盞

| | 只有一盞失敗 | 全部（數盞）失敗 |
|---|---|---|
| 侵權行為數 | 一個（其他人順利升空，無侵權行為） | 數個 |
| §185 I 後段 | ✗ | ✓（不知哪盞燒的 → 推定因果） |

## 四、一個侵權行為、數個可能行為人

| 案例 | 直接適用 | 楊芳賢 |
|---|---|---|
| 天燈只有一盞失敗 | ✗ | 可考慮類推 |
| 同車不知誰駕駛 | ✗ | **類推** §185 I 後段 |

- 類推理由：§185 I 後段立法目的在**降低被害人舉證責任**
