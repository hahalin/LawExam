# 民法13 筆記：作為義務來源之三與四——③ 網路平台：109 台上 1015：平台開啟網路使用環境，對有相當理由足認侵害名譽之言論有採取防止措施之作為義務，未審核或未防止令其繼續存在 → 不作為侵權（老師保留：平台沒有、也不需要法官判斷名譽侵害的能力，刪也不是不刪也不是；應提供發文者身分讓被害人去告本人）；④ 誠信原則／公序良俗：法律、契約、安全義務都不該當時，若**成本遠小於損害**且**你是唯一能防止者**，不作為仍可非難（山谷喊救命只打一通電話；應召女見男客暈倒於浴室逕自離去未通知櫃檯——性交易契約無效不生附隨義務、亦非開啟危險，只能從誠信原則論）

## 📋 實務見解速查

> **最高法院 109 年度台上字第 1015 號判決**（講義 20 頁，字號照字幕）：網路平臺服務提供者，如有相當理由足認確屬侵害名譽之言論，更有採取防止措施之作為義務；倘未為任何審核，或已有相當理由足認屬侵害名譽之言論而未為任何防止措施，令該侵害行為之言論繼續存在，自屬違反作為義務，亦可成立不作為侵權行為。（婚紗討論區匿名惡評案）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「匿名用戶在討論區發文詆毀甲，甲要求平台刪文，平台以無權限拒絕；甲得否對平台主張不作為侵權？」 | **實務（109 台上 1015）：得**。平台開啟網路上供人自由使用的環境 → 交易往來安全義務的延伸 → 對有相當理由足認侵害名譽之言論有防止措施之作為義務 → 未審核、未防止令其繼續存在 → 不作為侵權 |
| 「老師對此判決的保留？」 | 要求太高：「有相當理由足認確屬侵害名譽」是**法官**的工作，名譽權侵害要件很多，平台沒有也不需要這種能力；刪了被說侵害言論自由（作為侵權），不刪是不作為侵權 → 兩難。較合理：平台提供發文者身分，被害人去告本人、叫本人刪。可繼續觀察 |
| 「誠信原則作為作為義務來源的判斷？」 | 兩要素：① 你的**成本遠小於**可防止的損害 ② 你不做**真的會造成損害**（你是唯一能防止的人）。爬山見人跌落山谷喊救命，荒山野嶺下一個人可能明天才來 → 不要你下去拉（會死），但打個電話很難嗎？不打 → 違反誠信原則、公序良俗 |
| 「應召女見買春男客在浴室暈倒，收拾離去、未告知櫃檯，男客心肌梗塞死亡？」 | 刑事判決以契約附隨義務論（遺棄）。老師：民法上**性交易契約違反善良風俗無效**，無契約義務；也沒有開啟危險，無安全義務 → 只能走**誠信原則**：跟櫃檯講一聲成本極低（可不留資料），且退房前不會有第二個人進房、她是唯一救命稻草 → 違反作為義務 → 不作為侵權 |

## 一、109 台上 1015：平台的作為義務

```
平台開啟網路使用環境（開啟危險）→ 環境發生危險應防範
→ 經審查認確屬侵害名譽之文章 → 有維護（刪除）義務 → 不作為 → 不作為侵權
```

| 老師的疑慮 | 說明 |
|---|---|
| 能力 | 名譽侵害要件多，判斷是法官的事，平台不會、也不需要會 |
| 兩難 | 刪 → 侵害言論自由（作為侵權）；不刪 → 不作為侵權 |
| 替代 | 平台提供發文者身分，被害人對本人請求刪文、求償 |
| 秩序 | 開一個討論區還要逐句審查髒話是否構成名譽侵害 → 矯枉過正 |

## 二、誠信原則／公序良俗（最後一個來源）

```
檢討順序：法律 ✗ → 契約 ✗ → 交易往來安全義務 ✗ → 誠信原則？
要件 ① 成本 ≪ 損害（打一通電話 vs 一條命）
     ② 不做可能真的造成損害（只有你能救、沒有別人）
```

| 案例 | 法律 | 契約 | 安全義務 | 誠信原則 |
|---|---|---|---|---|
| 山谷喊救命 | ✗ | ✗ | ✗ | ✓ 打電話 |
| 應召女案 | ✗ | ✗（性交易契約無效，刑事判決用附隨義務論，老師認為不正確） | ✗（沒開啟危險） | ✓ 跟櫃檯講一聲 |

- 判決用語：作為義務來源包含法令、契約、危險前行為、**公序良俗**——學說上強調的就是誠信原則。
