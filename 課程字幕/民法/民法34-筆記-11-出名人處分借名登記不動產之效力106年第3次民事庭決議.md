# 民法34 筆記：出名人處分借名登記不動產之效力（106年第3次民事庭決議）

## 問題：
- 甲將 A 屋借名登記在乙名下
- 乙未經甲同意，把 A 屋賣給丙並移轉登記
- 甲乙借名契約約定使用、收益、管理、處分權都在甲
- 乙丙**買賣契約**本來就有效，爭點在**移轉 A 屋給丙的物權行為**

## 三說：
| | 無權處分說 | 有權處分說 | 區分說 |
|---|---|---|---|
| 代表 | 早年實務 | 吳從周；**106 年第 3 次民事庭決議** | 詹森林 |
| 理由 | 借名是通謀虛偽，乙沒取得所有權 | 甲依借名意思移轉，乙**真的取得所有權**；甲乙債權約定不能決定物權歸屬 | 原則有權處分；丙**惡意**時改採無權處分 |
| 丙 | 須**善意受讓**才取得 | 不論善惡意都取得 | 善意取得；惡意不取得 |

- 有權處分說的類比：甲乙訂車子買賣，乙不會因買賣契約就取得車的所有權，還要交付；同理，甲乙內部約定「處分權在甲」也不影響物權歸屬
- 區分說的理由：**惡意不受保護**；否則明知借名的丙也能取得，風險全落在甲

## 決議要旨：
- 借名登記契約是借名人與出名人間的**債權契約**
- 出名人依約通常沒有管理、使用、收益、處分權，但只是**內部約定**，效力不及於第三人
- 出名人既登記為所有人，將不動產移轉登記給第三人，屬**有權處分**

## 老師的看法：
- 登記在自己名下是常態，登記在別人名下是**變態**
- 有權處分說讓借名人承擔被處分的風險 → 可以**遏止借名登記**
- 過去主張無權處分就不怕，現在只剩向乙求償一條路

## 甲的救濟：
- 乙已處分 → 對甲陷於**返還給付不能**
- 依 **§226** 請求損害賠償
- 或類推 **§544**（逾越權限）請求賠償

## 借名登記的其他連結：
- 原住民保留地借名登記（民總已講）
- 出名人把財產贈與他人，借名人可否依 **§244** 撤銷並請求返還（大法庭裁定已講）
- 講義另有決議後的文章可延伸閱讀

## 📖 法條原文速查

> **§226 I**　因可歸責於債務人之事由，致給付不能者，債權人得請求賠償損害。

> **§544**　受任人因處理委任事務有過失，或因**逾越權限**之行為所生之損害，對於委任人應負賠償之責。

> **§759-1 II**（要旨，連結善意受讓）　因信賴不動產登記之善意第三人，已依法律行為為物權變動之登記者，其變動之效力，不因原登記物權之不實而受影響。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **106 年第 3 次民事庭決議**（講義 780 頁）：不動產借名登記契約為借名人與出名人間之債權契約，出名人依其與借名人間借名登記契約之約定，通常固無管理、使用、收益、處分借名財產之權利，然此僅為出名人與借名人間之內部約定，其效力不及於第三人。出名人既登記為該不動產之所有權人，其將該不動產處分移轉登記予第三人，自屬**有權處分**。（要旨，原文建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「出名人擅自處分借名不動產，效力？」 | **有權處分**（106 年第 3 次決議） |
| 「第三人須善意才取得？」 | 決議：**不問善惡意**；區分說（詹森林）惡意不取得 |
| 「借名人可向第三人請求塗銷？」 | **不可**，只能向出名人求償 |
| 「借名人對出名人之請求權基礎？」 | §226 給付不能、類推 §544 |
| 「無權處分說的立論基礎？」 | 早年認借名係**通謀虛偽**而無效 |
