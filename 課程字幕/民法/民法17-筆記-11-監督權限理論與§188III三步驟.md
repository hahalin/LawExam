# 民法17 筆記：監督權限理論與 §188 III 三步驟

## 往上一層問：
- 前面各說（實務、類推 §217、§281）爭的都是「**怎麼**求償才公平」，前提都是僱用人**可以**求償
- 陳忠五問的是：僱用人**憑什麼**對受僱人求償？

## 監督權限理論（陳忠五）：
- 老闆可以監督員工，藉員工執行職務獲利 → 員工造成的風險，由老闆承擔有正當性（能力越大，責任越大）
- 與 §188 保護被害人的目的不衝突：被害人只要能依 §188 向僱用人請求就受保護；僱用人能否向員工求償，與保護被害人無關
- → **原則：僱用人不得向受僱人求償**

## 例外（逾越監督權限，風險不該由老闆扛）：
- ①受僱人**不是在執行職務本體**，只是利用職務機會做自己的事（例：送貨回程順路接小孩）→ 對外仍須負 §188，但可轉嫁
- ②受僱人有**故意或重大過失**
- 例外可求償時，陳忠五仍採傳統構造：依 §188 III 求償，再**類推 §217** 調整

## 答題三步驟（老師統整）：
- **第一步：可否求償？** 多數說：可以；陳忠五：原則不行，例外兩種情形才可以
- **第二步：如何求償？** 多數說：§188 III（全額）；陳聰富：§281 I（按內部分擔，§188 III 只是確認性規定）
- **第三步：有無與有過失？**（只有走 §188 III 全額才需要）實務：不適用；多數學者、陳忠五：類推 §217

## 📖 法條原文速查

> **§188 III**　僱用人賠償損害時，對於為侵權行為之受僱人，有求償權。

> **§281 I**　連帶債務人中之一人，因清償、代物清償、提存、抵銷或混同，致他債務人同免責任者，得向他債務人請求償還**各自分擔之部分**，並自免責時起之利息。

> **§217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「監督權限理論下，僱用人得否向受僱人求償？」 | **原則否**；例外：非執行職務本體、故意或重大過失 |
| 「監督權限理論是否與 §188 保護被害人目的衝突？」 | **不衝突**：被害人已可向僱用人請求 |
| 「依多數說，僱用人求償之依據與額度？」 | **§188 III**，全額；再看有無類推 §217 |
| 「陳聰富之求償依據？」 | **§281 I**，按內部分擔 |
| 「受僱人送貨回程順路接小孩肇事，依陳忠五見解僱用人賠償後得否求償？」 | **得**：非職務本體，僅利用職務機會 |

## 一、三步驟流程

```
甲（A 公司司機）撞傷乙；甲 70%、A 30%；A 依 §188 賠償乙
│
├─ 第一步：A 可否向甲求償？
│     ├─ 多數說：可以
│     └─ 陳忠五：原則不行 ── 例外：①非執行職務本體 ②故意或重大過失
│
├─ 第二步：如何求償？
│     ├─ 多數說：§188 III → 全額 100%
│     └─ 陳聰富：§281 I → 直接按分擔 70%（結束）
│
└─ 第三步：（走 §188 III 者）有無與有過失？
      ├─ 實務：無（71 年判決，筆記 09）
      └─ 多數學者、陳忠五：類推 §217 → 減 30%
```

## 二、各家立場一覽

| | §188 性質 | 可否求償 | 依據 | 與有過失 |
|---|---|---|---|---|
| 實務 | 為他人負責 | 可 | §188 III | 不適用 |
| 王澤鑑、詹森林 | 為他人負責 | 可 | §188 III | 類推 §217 |
| 陳聰富 | 為自己負責 | 可 | §281 I | 不需要 |
| 陳忠五 | 為他人負責 | 原則不可 | §188 III | 類推 §217 |

## 三、例外情形的理由

| 例外 | 為何轉嫁合理 |
|---|---|
| 非執行職務本體（利用職務機會） | 不是在幫老闆做事，老闆沒有為他負責的必要；對外負責只是為了保護被害人 |
| 故意或重大過失 | 已逾越老闆的監督權限 |
