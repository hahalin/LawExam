# 民法21 筆記：個別財產觀察法與因果關係之判斷

## 受利益、受損害：個別財產觀察法：
- 只看**個別**財產的增減，不看總體財產是否增加或減少
- 數字例：買賣無效，乙付 100 萬，甲交付市價 120 萬的 A 車 → 乙受有 A 車之利益；甲受有 100 萬之利益（雖然甲整體虧 20 萬，仍有得利）
- 109 年律師考題：無權占用他人土地經營停車場，原預計月賺 1 萬，反而月虧 3 萬 → 仍受有**占有使用土地之利益**，盈虧不問

## 因果關係：舊爭議的來源：
- 早年實務尚未區分給付型、非給付型，爭點集中在因果關係
- 經典案例：乙詐騙甲取得一筆錢，再拿去清償乙以為還欠丙的工程款（其實早已結清，屬非債清償）→ 甲得否對丙請求？
- **直接因果關係說**：受利益與受損害須出於**同一原因事實**；丙得利來自乙的清償、甲受損來自乙的詐騙 → 不同事實 → 否定
- **非直接因果關係說（社會觀念說）**：日本法少數說，孫森焱書介紹較多；同一筆錢、同一人所致，依社會觀念有關聯 → 肯定，省去甲→乙、乙→丙兩段請求

## 分類後的處理（王澤鑑）：
- 給付型：以**給付關係**認定因果關係；利益來自原告之給付，因果關係即具備
- 非給付型：以**權益歸屬**認定
- 回到詐騙案：丙的利益來自乙的清償，不是甲的給付 → 甲丙間無給付關係；該筆利益依法不屬於甲 → 甲不得對丙請求；應由乙對丙（非債清償）、甲對乙請求
- 問題在權益歸屬階段就處理掉，根本不會進到因果關係

## 考試寫法：
- 遇到「以詐騙或脅迫取得他人財產，再對第三人清償」的故事 → 先寫直接、非直接因果關係兩說，再帶出王澤鑑的給付關係說，論述較完整

## 📖 法條原文速查

> **§179**　無法律上之原因而受利益，**致**他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。→「致」即因果關係要件

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「不當得利之受利益，採總體財產觀察？」 | **錯**，採**個別財產觀察法** |
| 「無權占地經營停車場虧損，仍受有利益？」 | **是**，占有使用利益 |
| 「直接因果關係說之內容？」 | 受利益與受損害須基於**同一原因事實** |
| 「乙詐騙甲財產對丙非債清償，依直接因果關係說甲得對丙請求？」 | **否** |
| 「社會觀念說之結論？」 | 肯定甲得直接對丙請求（少數說） |
| 「區分類型後，給付型之因果關係如何認定？」 | 以**給付關係**認定 |

## 一、個別 vs 總體

| | 乙 | 甲 |
|---|---|---|
| 個別觀察（採） | 得 A 車 | 得 100 萬 |
| 總體觀察（不採） | +120 −100 = +20 | +100 −120 = −20 |

## 二、詐騙後非債清償

```
甲 ──被詐騙交付金錢──→ 乙 ──非債清償──→ 丙
   直接因果說：兩個原因事實 → 甲不得向丙請求
   社會觀念說：同一筆錢、同一人 → 甲得向丙請求
   給付關係說：丙的利益來自乙之給付 → 甲向乙、乙向丙
```

## 三、各說對照

| 學說 | 判準 | 甲→丙 |
|---|---|---|
| 直接因果關係說 | 同一原因事實 | ✗ |
| 非直接因果關係說（社會觀念說） | 社會觀念上之關聯 | ✓ |
| 給付關係說（王澤鑑） | 給付關係／權益歸屬 | ✗ |
