# 民法10 筆記：法定代理與代表無 §169 適用——79 台上 2012 判例：表見代理於意定代理有適用，法定代理無適用餘地（法定代理不需授權 → 沒有授權外觀 → 沒有創造外觀的可歸責、也沒有信賴外觀）；乙宣稱為 15 歲甲之父案；董事代表權是法律規定（§27），非法人授權 → 無權代表不適用 §169，應回歸 §31 登記對抗；原審類推 §169 被最高法院廢棄

> 來源：民法10 課程字幕 01:48:42 ~ 01:58:00（講義註 21）

---

## 📖 法條原文速查

> **§1086 I**　父母為其未成年子女之法定代理人。
> **§27 II**　董事就法人一切事務，對外代表法人。董事有數人者，除章程另有規定外，各董事均得代表法人。
> **§31**　法人登記後，有應登記之事項而不登記，或已登記之事項有變更而不為變更之登記者，不得以其事項對抗第三人。

---

## 📋 實務見解速查

> **最高法院 79 年台上字第 2012 號判例**（字號照字幕，建議查閱）：民法第 169 條關於表見代理之規定，於意定代理時有其適用；若法定代理，則無適用該規定之餘地。
> **講義註 21 判決**（字號建議查閱）：法定代理係依法律規定而發生代理權，既非因授權而發生，即使有授權事實之表示，亦與法定代理之發生無關。民法第 169 條關於表見代理之規定，惟意定代理始有適用；若為**代表**或法定代理，則無適用該規定之餘地。原審認上訴人之法定代理人無權代表上訴人簽訂系爭買賣契約，**類推適用**民法第 169 條，令上訴人負授權人責任，所持法律見解顯有錯誤 → 廢棄。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「乙宣稱為 15 歲甲之父（法定代理人），甲不反對；乙代理甲向丙買機車，丙得否依 §169 要甲負授權人責任？」 | **不得**。文義上像「明知他人表示為代理人而不反對」，但法定代理人資格靠**法律規定**（§1086）不靠授權 → 根本沒有「授權外觀」可創造 → 沒有可歸責、也沒有信賴外觀 → 表見代理與法定代理在概念上矛盾、不會同時存在 |
| 「乙對外宣稱為 A 公司董事多年，A 明知不反對；乙代表 A 與善意無過失之丙簽數億投資案，乙實非董事？」 | 丙**不得**依 §169 要 A 負責。董事代表權是 §27 **法律賦予**，不是法人授權 → 無授權外觀 → 無 §169（也無類推）。這是一般的**無權代表**，應回歸 **§31**：有無登記決定能否對抗第三人（這種人通常沒登記，§31 走不通才想類推 §169） |
| 「法院得否類推 §169 處理無權代表？」 | 最高法院：**不得**，見解顯有錯誤，廢棄 |

## 一、法定代理為什麼沒有 §169

```
§169 的法理：本人創造「授權外觀」的可歸責事由 ＋ 相對人信賴該外觀
→ 前提：這是一個「需要授權」的代理，才有外觀可言
法定代理：§1086 父母為未成年子女之法定代理人 → 依法律規定，不需授權
→ 沒有授權外觀 → 沒有創造外觀的問題 → 沒有可歸責性、也沒有信賴外觀
→ 表見代理與法定代理不會同時存在
```

- 乙宣稱是甲爸爸、甲不反對：能不能當法定代理人靠法律不靠甲授權，甲不反對也不會造成丙的信賴。

## 二、代表同理：董事代表權是法定的

```
乙（董事長特助、總裁兒子、空降部隊）對外宣稱「我是 A 公司董事，有代表權」好幾年
A 公司明知、不反對（默認他在外面招搖撞騙）
乙代表 A 與善意無過失之丙談成三億投資案 → A：他不是我們董事，無權代表
丙：§169 表見代理／表見代表？
最高法院：代表權依 §27 法律規定而來，不是法人授權 → 無授權外觀 → 無 §169 適用餘地
→ 一般無權代表 → 回歸 §31：登記了可對抗、沒登記不能對抗
→ 這類人一定沒登記為董事（登記就會被噴下去）→ §31 失敗 → 原審才想類推 §169 → 被廢棄
```

## 三、結構圖

| | 權限來源 | 有無授權外觀 | §169 |
|---|---|---|---|
| 意定代理 | 本人授權 | 有 | ✓ |
| 法定代理 | 法律規定（§1086） | 無 | ✗ |
| 代表 | 法律規定（§27） | 無 | ✗（回歸 §31） |
