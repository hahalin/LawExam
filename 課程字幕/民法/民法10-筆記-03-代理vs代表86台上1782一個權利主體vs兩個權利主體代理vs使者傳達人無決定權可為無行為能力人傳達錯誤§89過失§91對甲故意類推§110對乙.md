# 民法10 筆記：代理 vs 代表（86 台上 1782：代表是一個權利主體的關係、法人之手足，事實行為侵權行為亦可；代理是兩個權利主體、限法律行為）；代理 vs 使者／傳達人（無決定權、可為無行為能力人）；傳達錯誤 §89：過失 → 丙依 §91 向甲求償；故意 → 丙類推 §110 向乙求償

> 來源：民法10 課程字幕 00:28:53 ~ 00:43:48（講義 259 頁註 8、171 頁）

---

## 📖 法條原文速查

> **§103 I**　代理人於代理權限內，以本人名義所為之意思表示，直接對本人發生效力。
> **§27 II**　董事就法人一切事務，對外代表法人。
> **§89**　意思表示，因傳達人或傳達機關傳達不實者，得比照前條之規定撤銷之。
> **§91**　依第八十八條及第八十九條之規定撤銷意思表示時，表意人對於信其意思表示為有效而受損害之相對人或第三人，應負賠償責任。但其撤銷之原因，受害人明知或可得而知者，不在此限。
> **§110**　無代理權人，以他人之代理人名義所為之法律行為，對於善意之相對人，負損害賠償之責。

---

## 📋 實務見解速查

> **最高法院 86 年台上字第 1782 號判決**（講義 259 頁註 8，字號照字幕，建議查閱）：代理與代表之法律性質及效果均不相同。代表在法人組織法上不可或缺，代表人與法人係**一個權利主體**間之關係，代表人所為之行為，不論法律行為、事實行為或侵權行為，均為法人之行為；代理人與本人則係**兩個權利主體**間之關係，代理人之行為並非本人之行為，僅效力歸於本人，且代理人僅得代為法律行為及準法律行為。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「代理與代表之區別？」 | 代表：**法人獨有**，代表人＝法人之手足，**一個權利主體**，執行職務範圍內之法律行為、準法律行為、事實行為、侵權行為都是法人的行為。代理：**兩個權利主體**，代理人的行為不是本人的行為，只是效力歸屬本人；限法律行為、準法律行為 |
| 「自然人間有無代表？」 | **無**。自然人有自己的意思決定機關與手足，不需要別人「就是我」；只能授權他人為意思表示而效果及於己 |
| 「代表人得否代表法人為侵權行為、無因管理、無權占有？」 | **可以**（執行職務範圍內）。郭台銘吃滷肉飯不代表鴻海，簽約就是鴻海簽約 |
| 「代理與使者（傳達人）之區別？」 | 代理人**自己為意思表示**、有一定決定權；使者只**傳達本人已作成的意思表示**、無任何決定權 |
| 「使者得否為無行為能力人？」 | **可以**（飛鴿傳書連鴿子都行）。代理人則不得為無行為能力人（§104 反面） |
| 「§105 但書『指示』與傳達的差別？」 | 指示：細節（付款期限、過戶時間、貸款條件）仍由代理人決定；傳達：純傳話，細節本人另談 |
| 「乙過失傳達錯誤（100 萬傳成 130 萬），丙承諾？」 | 甲依 **§89** 比照 §88 撤銷；丙依 **§91** 向**甲**請求信賴利益賠償 |
| 「乙故意傳達錯誤？」 | 甲仍得依 §89 撤銷；但損害是乙造成的，通說：丙**類推 §110** 向**乙**請求損害賠償（風險由故意者自負） |

## 一、代理 vs 代表：圖上多畫一條線變等號

```
代理：甲（本人）        乙（代理人）─以甲名義為意思表示─ 丙
      兩個獨立權利主體；本人單純享受法律效果，不參與意思表示作成；效力歸屬本人
代表：法人 ＝ 代表人 ───────────────────────────── 相對人
      一個權利主體；代表人是法人的手足，代表人做什麼＝法人做什麼（執行職務範圍內）
```

| | 代理 | 代表 |
|---|---|---|
| 存在於 | 自然人、法人皆可 | **法人獨有**（法人是抽象組織，沒有手足，需要人當手足） |
| 權利主體 | 兩個 | 一個 |
| 可為之行為 | 法律行為、準法律行為 | 法律行為、準法律行為、**事實行為、侵權行為**皆可 |
| 權限來源 | 授權（意定）或法律規定（法定） | 法律規定（§27 II），不是法人授權 |

- 代表在法律上沒有特別規定 → 類推代理的規定（下一筆記 §106 自己代表即是）。

## 二、代理 vs 使者（機關、傳達人）

| | 代理人 | 使者／傳達人 |
|---|---|---|
| 意思表示誰做的 | 代理人 | 本人（使者只轉達） |
| 決定權 | 有一定決定權（§105 但書「指示」仍含細節決定權） | 無 |
| 行為能力 | 不得為無行為能力人 | 可為無行為能力人 |
| 錯誤的處理 | §88 | §89 |

## 三、傳達錯誤 §89（講義 171 頁，當時跳過，因涉及無權代理概念）

```
甲託乙傳達「願以 100 萬買 A 車」給丙
① 乙過失傳成 130 萬 → 丙承諾
   甲：§89 比照 §88 撤銷
   丙：§91 向甲請求信賴利益賠償（表意人撤銷，自己承擔用錯傳達人的風險）
② 乙故意傳成 130 萬
   甲：仍得 §89 撤銷
   丙：損害明顯是乙造成的，不該由甲賠 → 通說：類推 §110 向乙請求損害賠償
```

- 為什麼先講完代理再回頭講傳達：直接講會覺得傳達跟代理差在哪，講完代理才會感受到兩者是完全不同的制度。
