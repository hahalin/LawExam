# 民法16 筆記：未成年人與好意施惠之過失標準

## 特殊個案的過失標準（老師列三種）：
- ①未成年人 ②好意施惠（字幕誤作「惡意滋擾」）③無償行為（見筆記 04）

## 未成年人：
- 以**同年齡之人**的注意能力、預見可能性為判斷標準
- 不把成年人的抽象輕過失（善良管理人注意）套在未成年人身上——法律不能強人所難
- 講義 129 頁：臺灣高等法院 95 年判決（字幕作「95年跟上易字第六號」，字號請對講義）採同齡人標準

## 好意施惠：
- 無委任、無契約、無報酬的單純互助：幫忙搬家摔壞東西、順路載人出事
- **王澤鑑**：仍負**抽象輕過失**責任；不能因好意就架空侵權法保護被害人的目的
- **林誠二**：改採**具體輕過失**（與處理自己事務同一注意）；理由是鼓勵社會互助、沒收錢
- 學說兩說並存

> 來源：民法16 課程字幕 00:14:28 ~ 00:17:21（講義 129 頁）

---

## 📖 法條原文速查

> **民法 §535**　受任人處理委任事務，應依委任人之指示，並**與處理自己事務為同一之注意**，其受有報酬者，應以**善良管理人之注意**為之。→ 老師未唸；供對照「具體輕過失」與「抽象輕過失」兩種注意程度的立法用語

---

## 📋 實務見解速查

> **臺灣高等法院 95 年判決**（講義 129 頁；字號字幕未唸清楚，請對講義）：未成年人之過失，應以**同年齡之人**為判斷標準。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「國中生騎腳踏車撞傷他人，其過失應以何標準判斷？」 | 以**同年齡之人**的注意義務、預見可能性判斷，**不**以成年人之善良管理人注意為準 |
| 「甲好意順路載乙，途中過失肇事致乙受傷，甲之注意義務是否降低？」 | **學說兩說**：王澤鑑——仍負抽象輕過失；林誠二——具體輕過失即可 |
| 「王澤鑑認為好意施惠不降低注意義務之理由？」 | 不能因好意而架空侵權行為**保護被害人**之目的 |
| 「林誠二主張具體輕過失之理由？」 | **鼓勵社會互助**；施惠者未收報酬，以處理自己事務同一注意即足 |

## 一、過失三級對照

| 過失類型 | 注意程度 | 本堂出現位置 |
|---|---|---|
| 抽象輕過失 | 善良管理人之注意 | 侵權行為之原則標準；王澤鑑（好意施惠） |
| 具體輕過失 | 與處理自己事務同一之注意 | 林誠二（好意施惠）；111 台上 1352 二審（無償） |
| 重大過失 | 顯然欠缺普通人之注意 | 本段未涉及 |

## 二、標準往下調的兩條路

```
侵權行為過失原則：抽象輕過失（善良管理人）
├── 未成年人 → 改以同齡之人為準（標準降低，無爭議）
└── 好意施惠 → 是否降低？
      ├─ 王澤鑑：不降低（抽象輕過失）
      └─ 林誠二：降低（具體輕過失）
```

## 三、好意施惠 vs 無償行為

| | 好意施惠 | 無償行為 |
|---|---|---|
| 重點 | 「施惠」：互相幫忙的過程 | 單純沒有對價，不一定是幫忙 |
| 例 | 幫搬家、順路載人 | 管委會無報酬處理社區事務 |
| 爭點 | 學說：抽象 vs 具體輕過失 | 實務：111 台上 1352（筆記 04） |
