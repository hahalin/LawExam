# 民法03 筆記：社團總會決議方法 §52 §53 §57 與出席數爭議

> 來源：民法03 課程字幕 00:44:39 ~ 01:03:22

---

## 📖 法條原文速查

> **§50 I**（社團之最高機關）
> 社團以總會為最高機關。

> **§52**（總會之決議）
> I 總會決議，除本法有特別規定外，以**出席社員過半數**決之。
> II 社員有**平等之表決權**。
> → 第 I 項**沒有**出席數的要求

> **§53 I**（變更章程之決議）
> 社團變更章程之決議，應有**全體社員過半數之出席，出席社員四分之三以上之同意**，或有**全體社員三分之二以上書面之同意**。

> **§57**（社團之解散）
> 社團得隨時以**全體社員三分之二以上之可決**解散之。

> **§46**（對照：公益社團須許可；§53 II 受設立許可之社團變更章程並應得許可）→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「社員表決權依出資額比例？」 | **錯**。社員有**平等**表決權（§52 II），一人一票；跟公司法股份有限公司不同 |
| 「變更章程之決議方法？」 | 全體**過半出席** ＋ 出席 **3/4 以上**同意；或全體 **2/3 以上書面**同意（§53 I） |
| 「解散之決議方法？」 | 全體 **2/3 以上可決**（§57），須開會，不是書面 |
| 「120 人社團，60 人出席、50 人同意變更章程？」 | **未通過**。60 人＝剛好一半，不是「過半」出席 |
| 「120 人社團，80 人出席、60 人同意變更章程？」 | **通過**。80 過半；60/80＝3/4，「以上」含本數 |
| 「普通決議有無出席數要求？」 | **實務：無**（文義＋體系）；**學說（陳忠五）：有**，章程未定者類推 §53 過半出席 |
| 「出席數不足之決議效力？」 | **決議不成立**（不是無效、不是得撤銷） |

## 一、社團法人的擬人化

```
社員總會 ＝ 頭腦（意思決定機關，§50 最高機關）
董事     ＝ 手足（行為機關）
```
- 老師：一試超愛考名詞與法條結構，這一塊一試會錯；二試幾乎不考。

## 二、表決權：一人一票（§52 II）

| | 民法社團 | 公司法股份有限公司 |
|---|---|---|
| 表決權 | **平等**，一人一票 | 一股一票，出資多票多 |
| 出資 100 萬 vs 10 萬 | 票數一樣 | 票數不一樣 |

## 三、決議方法：普通 vs 特別

```
普通決議 §52 I：出席社員過半數 ← 沒寫出席數
特別決議（只有兩個）
├── 變更章程 §53：全體過半出席 ＋ 出席 3/4 以上同意   ｜或 全體 2/3 以上書面同意
└── 解散     §57：全體 2/3 以上可決（開會，不是書面；隱含至少 2/3 出席）
```

### 「以上」「過半」的算術

| 用語 | 意思 | 剛好等於可不可以 |
|------|------|------|
| 過半（過半數） | **＞** 1/2 | ✗ |
| 3/4 以上、2/3 以上 | **≧** | ✓（「以上」含本數） |

```
120 人社團變更章程
  60 出席、50 同意 → 60 不是「過半」→ 第一關就刷掉 → 不通過
  80 出席、60 同意 → 80 過半 ✓；60/80 ＝ 3/4，以上含本數 ✓ → 通過
90 人社團解散
  至少 60 人同意 → 至少 60 人到場；50 人來 → 不可能通過
```
- 老師：司律沒看過這麼雕琢的，高普考有。

## 四、爭點：普通決議到底要不要出席數

### 案例（陳忠五老師文章，講義 73～74 頁註 87、88）
#### 事實
某寺廟（非法人團體，**類推適用**法人規定）有 31 名信徒。某次信徒大會只有 **7 人出席、5 人同意**，就完成改選。其他信徒不服。

#### 兩說

| | 實務（最高法院） | 陳忠五 |
|---|---|---|
| 結論 | 決議**通過** | 決議**不成立** |
| 解釋方法 | 文義：§52 I 只寫「出席社員過半數」，沒寫出席數。體系：§53、§57 都明文寫了出席數，§52 故意不寫＝沒要求 | 目的：總會是意思決定機關，決議至少要**體現多數社員意志**；5 人代表 31 人、極端到 3 人出席 2 人同意也過，欠缺**民主正當性** |
| §52 I 為何不寫出席數 | 因為不需要 | 立法者**故意留白**，原則交給**章程**自訂（1000 人社團硬要 500 人到場，場地都難找）；章程沒訂 → 法律介入 → **類推 §53 過半出席** |

### 效力：不成立，不是無效

```
出席數 → 決定它「是不是一個決議」      → 不足 → 決議【不成立】（連決議的資格都沒有）
內容違法／章程 → 決定決議「有沒有效」  → 【無效】（§56 II）
程序瑕疵 → 決議成立且有效，但有瑕疵    → 【得撤銷】（§56 I）
```
- 先有「決議」的資格，才往下談有效無效。出席數不足連資格都沒有 → 不成立。
