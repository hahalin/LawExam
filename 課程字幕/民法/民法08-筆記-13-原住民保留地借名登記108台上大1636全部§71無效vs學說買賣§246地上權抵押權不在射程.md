# 民法08 筆記：原住民保留地借名登記案——大法庭 108 台上大 1636 全部依 §71 無效 vs 學說：買賣是 §246、地上權抵押權不在條文射程、借名登記才是 §71／§72

> 來源：民法08 課程字幕 02:14:00 ~ 02:30:05（講義 218～222 頁，註 192、193）

---

## 📖 法條原文速查

> **山坡地保育利用條例 §37 II**　原住民取得原住民保留地所有權，如有移轉，以原住民為限。
> **原住民保留地開發管理辦法 §18 I**　原住民取得原住民保留地所有權後，除政府指定之特定用途外，其移轉之承受人以原住民為限。
> → 兩條都只規範「**所有權移轉**」；建議查閱最新條文
> **§71**　違反強制或禁止規定者無效。　**§72**　背於公序良俗者無效。
> **§246 I**　以不能之給付為契約標的者，其契約為無效。
> **§828 II** 準用 **§821**、**§767 I 中段**　公同共有人對第三人之物上請求權（塗銷登記）
> **§1151**　繼承人有數人時，在分割遺產前，各繼承人對於遺產全部為公同共有。

---

## 📋 實務見解速查

> **最高法院 108 年度台上大字第 1636 號裁定**：非原住民乙欲購買原住民甲之原住民保留地經營民宿（露營），為規避山坡地保育利用條例 §37、原住民保留地開發管理辦法 §18，與原住民丙成立**借名登記契約**，以丙名義與甲訂立**買賣契約**，甲以該地為乙**設定地上權**後將**所有權移轉登記**予丙。乙丙借名登記契約、丙甲買賣契約、甲為乙設定地上權及移轉所有權登記予丙之行為，均係為實現非原住民乙取得原住民保留地所有權之效果，**違反上開規定，依 §71 全部無效**。
> 學說批評：陳榮傳、吳從周、林誠二等（講義 222 頁）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「大法庭結論？」 | 借名登記、買賣、設定地上權、移轉登記**全部依 §71 無效** |
| 「學說對買賣契約的看法？」 | 兩條規定只管**所有權移轉**，買賣契約不在射程 → 不是 §71；但實質當事人乙非原住民，甲無法移轉 → **給付不能 → §246 無效** |
| 「學說對設定地上權、抵押權？」 | 條文**沒說**地上權、抵押權以原住民為限；原住民融資需要設定抵押給銀行 → 最高法院**過度擴張文義**，規範密度不足應**修法**而非解釋 |
| 「學說對借名登記契約？」 | 以規避法律為目的 → **§71 或 §72 無效**可以接受 |
| 「學說對甲→丙所有權移轉？」 | 實質為非原住民取得 → 違反規定之虞 → §71 無效可以接受 |
| 「甲偽造丁同意書辦理分割登記單獨取得 A 地？」 | 分割登記須全體繼承人同意 → 無效；公同共有登記則任一繼承人可辦。丁依 §828 II 準用 §821、§767 I 中段請求甲、乙、丙塗銷，回復甲丁公同共有 |

## 一、事實（登記簿流向）
```
X（原住民）死亡 → A 地（原住民保留地）由甲、丁共同繼承（公同共有）
甲偽造丁同意書 → 辦繼承登記＋分割登記 → A 地單獨登記甲名下
乙（非原住民）想買 A 地做露營區 → 甲：你不是原住民我不能賣你
乙找原住民丙當人頭：乙丙【借名登記契約】→ 丙與甲訂【買賣契約】→ 甲為乙【設定地上權】（有的版本還有抵押權）→ 甲將【所有權移轉登記】給丙
乙的目的：繞過「所有權移轉以原住民為限」，取得實質控制力（地上權可使用收益、抵押權可拍賣優先受償、借名登記控制丙）
丁事後發現 → 起訴
```

## 二、大法庭：全部 §71 無效
- 兩條規定的目的是保護原住民固有文化與財產，限制移轉對象；乙透過借名、地上權間接達到類似取得所有權的效果，無保護價值 → 四個行為通通無效。
- 加上甲的分割登記偽造同意書無效 → 丁依 §828 II 準用 §821＋§767 I 中段請求甲、乙、丙塗銷，回到甲丁公同共有。

## 三、學說：結論可以接受，法律解釋太粗暴

| 行為 | 大法庭 | 學說 |
|------|------|------|
| 丙甲買賣契約 | §71 無效 | 條文只管所有權移轉，買賣**不在射程**（「不能拿明朝的劍斬清朝的官」）。但實質當事人是乙，甲不可能移轉給非原住民 → **給付不能 → §246 無效** |
| 甲為乙設定地上權（抵押權） | §71 無效 | 條文**沒有**說地上權、抵押權以原住民為限；原住民要融資只能設定抵押給原住民？→ 無法保護財產 → 文義**過度擴張**；規範密度不足應**修法** |
| 乙丙借名登記契約 | §71 無效 | 以規避法律為目的 → **§71 或 §72** 無效，可接受 |
| 甲→丙所有權移轉 | §71 無效 | 實質是非原住民取得 → 有違反之虞 → §71 無效，可接受 |

```
學說共識：不想讓乙拿到實質控制力，這個理念大家接受
問題：法條射程只有「所有權移轉」，其他行為一律丟 §71，是法律解釋過於簡單粗暴
```
