# 民法10 筆記：§106 自己代理、雙方代理——核心是防止利益衝突；違反效果：無權代理效力未定（早年無效說已被最高法院推翻）；三個例外：① 本人許諾（房仲雙方代理條款）② 專為履行債務（董事代表法人移轉已出賣之地給自己：自己代表類推 §106）③ 父母為未成年子女利益之自己代理（目的性限縮）

> 來源：民法10 課程字幕 00:43:48 ~ 00:56:12、01:04:00 ~ 01:06:00

---

## 📖 法條原文速查

> **§106**　代理人非經本人之許諾，不得為本人與自己之法律行為，亦不得既為第三人之代理人，而為本人與第三人之法律行為。但其法律行為，係**專履行債務**者，不在此限。
> **§71**　法律行為，違反強制或禁止之規定者，無效。但其規定並不以之為無效者，不在此限。
> **§170 I**　無代理權人以代理人之名義所為之法律行為，非經本人承認，對於本人不生效力。
> **§348 I**　物之出賣人，負交付其物於買受人，並使其取得該物所有權之義務。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「自己代理？雙方代理？」 | 自己代理：乙代理甲**與自己**為法律行為。雙方代理：乙**同時**代理甲與丙為法律行為。§106 原則不得為之 |
| 「§106 之立法目的？」 | **防止利益衝突**。乙代理甲買乙自己的地，價格不會低於市價；乙同時代理買方賣方，只會為自己的獎金著想 |
| 「違反 §106 之效果？」 | **無權代理，效力未定**（§170）。早年少數實務以「不得」＝強行規定 → §71 無效，已被最高法院改掉：不得代理只表示就這件事**沒有代理權** |
| 「§106 之例外？」 | ① **本人許諾**（願意接受利益衝突就讓他做；房仲要雙方簽同意雙方代理條款）② **專**為履行債務（不會有利益衝突）③ 法無明文：**父母為未成年子女利益**之自己代理（爸爸把自己的地送給未成年兒子）→ 目的性限縮，不受 §106 限制 |
| 「A 法人將 V 地賣給甲，甲後當選 A 之董事，代表 A 將 V 移轉登記給自己？」 | **有效**。代表無特別規定，類推 §106（自己代表）；甲對 A 本有 §348 債權，移轉是**履行買賣契約義務**，對 A 無任何不利益、誰來做都一樣 → 專為履行債務 |

## 一、為什麼要有 §106：代理伴隨信賴，利益衝突時信賴動搖

```
意定代理：我相信你的專業和能力才授權你 → 希望你為我的利益考慮
自己代理：甲授權乙買地，乙剛好有地要賣 → 乙代理甲向乙買 → 乙身兼賣方，價格只會高不會低
雙方代理：甲託乙買地（買低於 1000 萬，價差抽 20%）、丙託乙賣地（賣高於 1000 萬，超額抽 50%）
          → 乙不為甲也不為丙，只為自己的獎金 → 人性
→ 為防止利益衝突，原則不得為之
```

## 二、違反 §106 的效果（小考點，已少考）

| 說法 | 理由 | 現況 |
|---|---|---|
| 無效說（早年少數實務） | 「不得」＝強行規定 → §71 無效 | 學者批評，最高法院已改 |
| **效力未定說（現行）** | 不得為此種代理 ＝ 就這部分**沒有代理權** → 無權代理 §170 → 效力未定，看本人要不要承認 | ✓ |

## 三、三個例外

| 例外 | 說明 | 例 |
|---|---|---|
| ① 本人許諾 | 制度為防止利益衝突而存在，本人願意接受就讓他做 | 房仲同時受買方賣方委託，一定要雙方簽「同意雙方代理」條款（配對、話術、優惠都是在讓甲丙承認這個利潤存在） |
| ② **專**為履行債務 | 「專」畫底線：只能就履行債務這件事做，因為履行債務**不會有利益衝突**；履行以外可能發生利益衝突的事就不行（下一筆記：代理支付利息不生承認效果） | 自己代表移轉已出賣之地 |
| ③ 父母為未成年子女利益 | 爸爸是未成年兒子的法定代理人，代理兒子受贈自己的地 → 典型自己代理，但為子女利益、無利益衝突 → **目的性限縮**，不受 §106 限制 | 父贈地予子 |

## 四、自己代表類推 §106：董事移轉土地案（考過）

```
A 法人 ─買賣 V 地─→ 甲（甲對 A 取得 §348 I 債權）
甲當選 A 之董事（有代表權）
甲代表 A 將 V 移轉登記給甲自己 → 自己代表
代表無特別規定 → 類推 §106
→ 甲本來就有權請求 A 移轉，A 本來就要給，由甲代表 A 來給，對 A 無不利益、無利益衝突、誰來做都一樣
→ 專為履行債務 → §106 但書 → 有效
```

## 五、解題核心一句話

- 抓住「防止利益衝突」：**有利益衝突就不能做，沒有利益衝突就放寬讓它做**。例外①②③都是這句話的具體化。
