# 民法二試02 筆記：故意侵權行為與被害人與有過失（§217）

## 爭點：
- 承筆記 06：乙向**僱用人甲**（過失）求償 → 甲主張乙與有過失（交出存摺印章）沒問題
- 乙改向**故意盜領的丙**求償 → 丙能不能主張乙與有過失？
- 詐騙集團案件同樣常見：被害人輕信而交付財物，有沒有與有過失？

## 學說（林誠二、王志誠）：
- §217 的「過失」不是對損害發生的過失，而是**迴避義務＋迴避可能性**：有義務迴避、能迴避卻沒迴避 → 才是與有過失
- 加害人**直接故意**：法律不要求被害人閃避故意加害 → 無迴避義務 → **無**與有過失適用
- 加害人**未必故意**：原則無；例外被害人有**重大過失**（一般人都能迴避卻沒迴避）
- 加害人**過失**：當然適用

> 來源：民法二試02 課程字幕 01:48:17 ~ 01:54:50（講義 113 頁「四、與有過失之適用」）

---

## 📖 法條原文速查

> **民法 §217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「營業員故意盜領，得否主張客戶交出存摺印章與有過失？」 | §217「過失」＝迴避義務＋迴避可能；對直接故意之侵害，被害人無迴避義務 → 不適用 |
| 「詐騙集團主張被害人輕信？」 | 同上，直接故意 → 原則不減免 |
| 「未必故意呢？」 | 原則不適用；被害人有重大過失時例外適用 |
| 「答題層次？」 | ①§188 成立（執行職務、組織義務）②甲（過失）主張與有過失 ✓ ③丙（故意）主張與有過失 → 依加害人主觀區分 |
