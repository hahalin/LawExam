# 民法04 筆記：孳息 §69 §70 §766——分離前看原物所有人、分離後看收取權人

> 來源：民法04 課程字幕 00:23:10 ~ 00:30:16

---

## 📖 法條原文速查

> **§69**（天然孳息與法定孳息）
> I 稱天然孳息者，謂果實、動物之產物及其他依物之用法所收穫之出產物。
> II 稱法定孳息者，謂利息、租金及其他因法律關係所得之收益。

> **§70**（孳息之歸屬）
> I 有收取天然孳息權利之人，其權利存續期間內，取得與原物分離之孳息。
> II 有收取法定孳息權利之人，按其權利存續期間內之日數，取得其孳息。
> → 老師：§70 I「有說跟沒說一樣」，誰是收取權人要看 §766 和其他條文

> **§766**（物之成分及天然孳息之歸屬）
> 物之成分及其天然孳息，於分離後，除法律另有規定外，仍屬於其物之所有人。
> → 原物主義：原則歸原物所有人

> **§66 II**　不動產之出產物，尚未分離者，為該不動產之部分。

> **§421 I**（租賃）承租人得使用收益；**§850-1**（農育權）；**§911**（典權）→ 條文有「**收益**」二字者為收取權人。建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「土地上未分離之果實歸誰？」 | **原物（土地）所有人**，不管誰種、不管租給誰、不管誰無權占有 |
| 「果實分離後歸誰？」 | **有收取權之人**（§70 I）；沒有其他收取權人 → 回到原則**原物所有人**（§766） |
| 「承租人、農育權人、典權人是否為收取權人？」 | **是**（法條有「收益」二字） |
| 「無權占有人是否為收取權人？」 | **否**，找不到依據 |
| 「天然孳息 vs 法定孳息？」 | 天然：雞生蛋、羊毛、果實（依物之用法）；法定：租金、利息、股利（依法律關係） |

## 一、孳息是什麼：大 A 生出小 A

```
主物／從物：A 和 B 是兩個不同的物，問 B 跟不跟著 A
孳息      ：小 A 是大 A 生出來的，問小 A 歸誰
    天然孳息：雞 → 蛋；羊 → 羊毛；樹 → 果實（§69 I）
    法定孳息：房子 → 租金；錢 → 利息；股票 → 股利（§69 II）
```

## 二、兩步驟判斷法（天然孳息）

```
第一步：分離了沒有？
├── 未分離 → 原物的一部分（§66 II）→ 歸【原物所有人】
│            不管誰種的、租給誰、誰無權占有，通通不管 → 只問地主是誰
└── 已分離 → 變成獨立的動產 → 歸【有收取權之人】（§70 I）
             ├── 有其他收取權人（法律或契約）→ 歸他
             └── 沒有 → 原則：原物所有人（§766 原物主義）
```

### 原物主義的理由
- 舉證方便：證明「蘋果種在誰的地上」比證明「蘋果是誰種的」容易。

### 例題
甲把土地租給乙，乙種水果；丙無權占有同一塊地也種水果。
- 未分離：乙種的、丙種的都是**甲的**（土地的一部分）。
- 題目再怎麼轉（土地又賣、又租），未分離就看地主。

## 三、誰是收取權人：找「收益」兩個字

| 收取權人 | 依據 | 爭議 |
|---------|------|------|
| 承租人 | 租賃契約（§421 使用收益） | 無 |
| 農育權人、典權人 | 物權（條文有「收益」） | 無 |
| 買受人 | §373 | 見「買賣標的物孳息」筆記 |
| 質權人 | §889、§890 | 見「質權人收取孳息」筆記：收與益分家 |
| 善意占有人 | §952 ＋ §943 | 見「善意占有人」筆記：容易被忽略 |
| 未成年人之父母 | §1088 | 見「未成年人特有財產」筆記 |
