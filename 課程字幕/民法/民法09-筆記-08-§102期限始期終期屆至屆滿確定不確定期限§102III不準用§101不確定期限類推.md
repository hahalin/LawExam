# 民法09 筆記：§102 期限——始期／終期、屆至／屆滿、確定／不確定期限（死因贈與）；§102 III 準用 §100 但不準用 §101 → 不確定期限有類推 §101 的實益（驗收、保險公司不核保）

> 來源：民法09 課程字幕 01:23:00 ~ 01:33:12

---

## 📖 法條原文速查

> **§102**（期限之效力）
> I 附始期之法律行為，於期限**屆至**時，發生效力。
> II 附終期之法律行為，於期限**屆滿**時，失其效力。
> III 第一百條之規定，於前二項情形準用之。→ 準用 §100（期待權保護），**不準用 §101**

> **§101**　條件成就／不成就之擬制
> **§1200**（對照）遺囑所定遺贈，附有停止條件者，自條件成就時，發生效力。／死因贈與以死亡為不確定期限

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「始期與終期之效力？」 | 始期**屆至**生效；終期**屆滿**失效（用語：到了才開始叫屆至，到了就結束叫屆滿） |
| 「期限既然確定會發生，何來『不確定期限』？」 | 確定的是「**會不會**發生」，不確定的是「**何時**發生」。死亡必然發生但不知何時 → **不確定期限**（死因贈與：我死了車就是你的） |
| 「§102 III 準用何條？」 | 準用 **§100**，**不準用 §101**（立法理由：期限必然到來，無法用不正當方法阻止） |
| 「受贈人殺害以死亡為期限之贈與人，贈與是否生效？」 | 不確定期限可被**積極促成**提前屆至 → 學說、實務**類推 §101 II** 視為期限不屆至（另有撤銷贈與規定） |
| 「定作人以『驗收合格』為付款期限卻故意不驗收？」 | 不確定期限被故意延緩 → **類推 §101 I** 視為屆至 → 得請求付款 |
| 「保險公司收保費後故意不核保以免溯及理賠？」 | 早期實務類推 §101：被保險人若為合格保險體，視為核保、契約生效（保險法後有無修法請查） |
| 「確定期限（聖誕節）有無類推 §101 的必要？」 | **無**。無法讓聖誕節提前或不來 |

## 一、分類與用語
| 分類 | 內容 |
|------|------|
| 始期／終期 | 租約 113/1/1～115/12/31：始期屆至生效，終期屆滿失效 |
| 確定期限 | 確定發生、且知何時：放榜日、聖誕節 |
| 不確定期限 | 確定發生、但不知何時：**死亡**（死因贈與） |

- 寫合約時可以把用語改成貼近法條：屆至＝開始，屆滿＝結束。

## 二、§102 III 的準用與漏洞
```
§102 III 準用 §100 → 期限屆至前侵害相對人期待 → 賠償
不準用 §101 → 立法者想：期限必然到來，怎麼可能用不正當方法阻止？
但不確定期限可以：
    積極促成提前 → 殺掉贈與人（人必會死，但你讓他提早死）
    故意延緩 → 「驗收合格才付尾款」卻一直不驗收（驗收必會完成，但你故意不去）
→ 不確定期限有類推 §101 的實益；確定期限沒有（聖誕節不可能提前或不來）
```

## 三、例子
| 情境 | 期限 | 不正當行為 | 處理 |
|------|------|------|------|
| 「我死了車就送你」，受贈人殺贈與人 | 不確定始期 | 積極促成 | 類推 §101 II 視為不屆至（贈與法另有撤銷規定） |
| 承攬「驗收合格付尾款」，定作人故意不驗收 | 不確定期限 | 故意延緩 | 實務類推 §101 I 視為屆至 → 可請求 |
| 意外險剛繳保費即出車禍，保險公司故意不核保（核保會溯及生效要理賠） | — | 不正當不核保 | 早期實務類推 §101：合格保險體視為核保；保險法後續規定請查 |
