# 民法38 筆記：共有物管理之分管契約與分管決定（§820）

## 體系位置：
- 分別共有的權能：積極權能（使用收益 §818、處分 §819＋土地法 §34-1、**管理 §820**）、消極權能（§821）

## 分管契約 vs 分管決定：
- 98 年修法前只有「分管契約」（全體同意）；修法後 §820 I 分成兩種
  - **分管契約**：「除契約另有約定外」→ 意思表示合致，一定是**全體同意**
  - **分管決定**：**多數決**，門檻與土地法 §34-1 I 相同：人數過半＋應有部分過半，或應有部分逾 2/3 不計人數
- 不同意的人不能被叫做「契約」拘束，所以多數人做的叫「決定」
- 修法理由：處分都能多數決了，程度較輕的管理還要全體同意，管理效率太低

## 少數人的保護（II～IV 只在分管決定才有意義）：
- 例：甲乙合計 2/3，決定臨大馬路那一側由甲乙管理，後段畸零地留給丙
- **II 顯失公平**：不同意的共有人得聲請法院**裁定變更**
- **III 情事變更**：法院得因任何共有人聲請裁定變更；§227-2 是給契約用的，決定另設本項
- **IV 損害賠償**：多數人為決定有故意或重大過失，致共有人受損害 → 對不同意的共有人**連帶**負賠償責任
- 分管契約是全體同意，沒有「不同意之人顯失公平」的問題；情事變更依 §227-2（老師見解；III 條文用語是「前二項所定之管理」，建議查證）
- **V 簡易修繕、保存行為**：各共有人**單獨**為之

## 細節一：法院不能替共有人定分管方法
- 66 年第 7 次民事庭決議：共有物如何分別管理應由共有人自行約定；與分割不同，**不能由法院判決**，訴請分管於法無據（講義註釋 238）
- 現行法：契約、多數決都做不成 → 法院也幫不了；喬不攏只能請求**分割**

## 細節二：多數決不能終止全體訂立的分管契約
- 甲乙丙在 98 年修法前訂分管契約，各管一塊；修法後乙丙認為甲分到臨大馬路那塊不公平，想以 2/3 多數決終止
- **108 台上 1278**：全體訂立的分管契約，終止**僅得經全體同意**；不能以多數決變更
- 理由：民主正當性較弱的多數決，不能推翻全體共識

## 細節三：可以分區各自管理
- 113 年高等法院座談會：分管決定約定 A、B 分用右側、中間各 1/3，左側由 C 使用收益，可否？
- 研討與審查意見採**肯定**：共有人得依分管決定占有使用特定位置，分管方法不限
- 吳從周文章（講義 166 頁）討論公寓大廈分管契約如何締結（建商擬定同意型、媒介型），有興趣自行閱讀

```
共有物之管理（§820）
├─ 分管契約（全體）── 情事變更 → §227-2；終止須全體同意（108 台上 1278）
├─ 分管決定（多數決）── 顯失公平 II／情事變更 III／連帶賠償 IV
├─ 簡易修繕、保存 → 各共有人單獨（V）
└─ 都做不成 → 法院不得代定（66 年第 7 次決議）→ 只能分割
```

## 📖 法條原文速查

> **§820**（共有物之管理）
> I 共有物之管理，**除契約另有約定外**，應以共有人**過半數**及其應有部分合計**過半數**之同意行之。但其應有部分合計**逾三分之二**者，其人數不予計算。
> II 依前項規定之管理**顯失公平**者，不同意之共有人得聲請法院以**裁定變更**之。
> III 前二項所定之管理，因**情事變更**難以繼續時，法院得因任何共有人之聲請，以裁定變更之。
> IV 共有人依第一項規定為管理之決定，有**故意或重大過失**，致共有人受損害者，對不同意之共有人**連帶**負賠償責任。
> V 共有物之**簡易修繕及其他保存行為**，得由各共有人**單獨**為之。

## 📋 實務見解速查

> **最高法院 66 年第 7 次民事庭決議**：共有土地如何分別管理，應由全體共有人以契約定之，與共有物之分割不同，不能由法院判決，共有人訴請分管於法無據。（要旨改寫；當時尚無多數決）

> **最高法院 108 年台上字第 1278 號判決**：共有人間經全體訂立之分管契約，約定各自占有共有物特定部分而為管理者，其終止僅得經全體共有人同意為之，不得以多數決終止。（要旨改寫）

> **113 年高等法院法律座談會**：共有人得依分管決定占有使用共有物之特定位置。（要旨改寫，建議查證座談會出處）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「共有物管理得否多數決？」 | **得**（分管決定），門檻同土地法 §34-1 I |
| 「分管決定顯失公平，不同意者如何救濟？」 | 聲請法院**裁定變更**（§820 II） |
| 「多數決管理致少數受損？」 | 故意或重大過失 → **連帶**賠償（§820 IV） |
| 「共有物簡易修繕須多數決？」 | **不須**，各共有人單獨為之（§820 V） |
| 「協議與多數決都不成，得否訴請法院定分管方法？」 | **不得**，於法無據 |
| 「全體訂立之分管契約，得否多數決終止？」 | **不得**（108 台上 1278） |
