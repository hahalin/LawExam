# 民法37 筆記：鄰地損害防免、水流關係與枝根越界（§774～§798）

## 老師提醒：
- 這些規定考出來機率不高，偶爾出現；看法條、記要件即可
- 相鄰關係規定多可作為 **§184 II 保護他人之法律**

## 鄰地損害之防免：
- **§774**：經營事業或行使所有權，應注意防免鄰地損害
  - 只是**注意規定**，不是請求權基礎；違反時回到侵權行為請求賠償
- **§794**：開掘土地或建築時，不得使鄰地地基動搖、發生危險，或使鄰地建物受損
  - 例：蓋大樓連續壁滲水，導致鄰屋傾斜坍塌 → 違反保護他人之法律，依 §184 II 請求賠償
- **§795**：建物或工作物有傾倒危險，致鄰地有受損害之虞 → 鄰地所有人得請求**必要之預防**

## 水流關係（選擇題較愛考水）：
| 條號 | 內容 | 重點 |
|---|---|---|
| §775 I | 不得妨阻由鄰地**自然流至之水** | 人工引導的水不適用；工廠挖管排廢水可阻止 |
| §775 II | 自然流至之水為鄰地所必需，不得妨阻其全部 | 上游養魚也不能把水全擋住 |
| §776 | 蓄水、排水、引水工作物破潰阻塞 → 所有人以**自己費用**修繕疏通預防 | 費用另有習慣從其習慣 |
| §777 | 不得設屋簷、工作物使雨水或液體**直注**相鄰不動產 | 冷氣滴水、工廠排水 |
| §778 | 水流因事變在鄰地阻塞 → 得以自己費用疏通；鄰地受益者按受益程度分擔 | 土石流堵住 A 地河道，B 地主可進去挖 |
| §779 | 為使浸水地乾涸或排洩家用、其他用水，得使水**通過**鄰地**以至河渠或溝道** | 擇損害最少處所、付償金、爭議由法院判決 |

## 結合民法36 的池塘案（見民法36-筆記-09）：
- 事實：甲的池塘向來供周圍農地排農業用水；乙蓋工廠，挖排水道把廢水直接排進甲的池塘
- §767 I 中段的「妨害」須具**不法性**；乙若能找到相鄰關係的依據，不法性即被阻卻
- 乙可能的主張都不成立：
  - §775：工廠廢水**不是自然流至**之水
  - §779：「其他用水」雖可涵蓋工業用水，但 §779 是讓水**通過鄰地到河渠或溝道**，不是直接**排到鄰地上**
- 結論：乙構成妨害，甲得請求除去

## 枝根越界與果實自落：
- **§797**：鄰地植物的**枝根**越界
  - 先請求植物所有人於相當期間內刈除 → 不刈除可自行刈取並請求償還費用
  - 不妨害土地利用者（參天大樹）不適用
- **§798**：果實**自落**於鄰地 → **視為**屬於鄰地所有人（不能舉反證推翻）；鄰地為公用地者不在此限
  - 目的：杜絕糾紛，掉在誰的地就是誰的

## 考古題：竹筍
- 題目：下列何者非 §797 所稱植物之枝根？桑樹、木瓜樹、牽牛花藤蔓、**竹筍**
- 竹子走**地下莖**，A 地種竹，竹筍從 B 地冒出
  - 不是枝根越界，而是 **B 地的出產物**（§66 II，未分離前是土地的一部分）
  - 分離後依 §766 歸原物所有人（B 地主）
  - 也不是 §798「自落」的果實
- A 地主不能主張「那是我家竹子長的」

## 📖 法條原文速查

> **§774**　土地所有人經營事業或行使其所有權，應注意**防免鄰地之損害**。

> **§775**
> I　土地所有人不得妨阻由鄰地**自然流至之水**。
> II　自然流至之水為鄰地所必需者，土地所有人縱因其土地利用之必要，**不得妨阻其全部**。

> **§777**　土地所有人不得設置屋簷、工作物或其他設備，使雨水或其他液體**直注**於相鄰之不動產。

> **§779 I**　土地所有人因使浸水之地乾涸，或排洩家用或其他用水，**以至河渠或溝道**，得使其水**通過鄰地**。但應擇於鄰地損害最少之處所及方法為之。
> → II～IV 項（償金、習慣、法院判決）建議查閱最新六法原文

> **§794**　土地所有人開掘土地或為建築時，不得因此使鄰地之地基動搖或發生危險，或使鄰地之建築物或其他工作物受其損害。

> **§797**
> I　土地所有人遇鄰地植物之**枝根**有逾越地界者，得向植物所有人，請求於相當期間內刈除之。
> II　植物所有人不於前項期間內刈除者，土地所有人得刈取越界之枝根，並得請求償還因此所生之費用。
> III　越界植物之枝根，如於土地之利用**無妨害**者，不適用前二項之規定。

> **§798**　果實**自落**於鄰地者，**視為**屬於鄰地所有人。但鄰地為公用地者，不在此限。

> §776、§778、§795 原文 → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§774 是否為獨立請求權基礎？」 | **否**，注意規定，回到侵權行為 |
| 「工廠以管線排放廢水至鄰地，鄰地得否阻止？」 | **得**，非自然流至之水 |
| 「得否依 §779 將廢水直接排入鄰地池塘？」 | **不得**，§779 是通過鄰地至河渠溝道 |
| 「竹筍自鄰地冒出，是否為 §797 之枝根？」 | **否**，是鄰地之出產物，屬鄰地所有人 |
| 「果實自落鄰地，屬誰所有？」 | **視為**鄰地所有人；公用地除外 |
| 「枝根越界但不妨害土地利用？」 | 不得請求刈除（§797 III） |
