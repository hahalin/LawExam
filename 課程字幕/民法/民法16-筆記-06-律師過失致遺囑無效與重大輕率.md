# 民法16 筆記：律師過失致遺囑無效與重大輕率

## 案情（法研所考過）：
- 乙委任甲律師寫遺囑，內容是遺贈丙一筆錢
- 甲**重大輕率**，未依法定方式（例：應簽名卻叫人蓋章），遺囑**無效**
- 乙死亡後，丙向乙之繼承人請求遺贈被拒，受有損害 → 丙能否向甲請求？

## 四條路逐一檢驗：
- **契約**：委任在甲乙之間，丙非當事人 → 債之相對性，丙不能主張甲債務不履行
- **契約對第三人保護效力**：第三人與債權人關係密切、債務人可預見 → 契約保護效力擴及丙；理論可行，但突破債之相對性又無明文，我國實務**未承認**（僅學說與少數德國判決）
- **§184 I 前段**：遺贈只有**債權效力**，丙無絕對權受侵害 → 純粹經濟上損失 → ✗
- **§184 I 後段**：關鍵在「故意」「背俗」的解釋寬嚴

## 從嚴 vs 從寬：
- 從嚴：律師辦錯事是契約上可非難，不是踩到社會道德底線；甲也不是以損害丙為目的 → ✗
- 從寬（字幕作陳聰富／陳松富，請對講義）：**故意包含重大輕率**；背俗只要違背社會共同生活準則、為一般大眾所不能接受即可 → ✓
- 理由：前段（權利＋過失）與後段（利益＋故意背俗）之間有**保護漏洞**；不法性趨近背俗、過失趨近故意者，例外納入後段

## 📖 法條原文速查

> **民法 §184 I**　因故意或過失，不法侵害他人之**權利**者，負損害賠償責任。**故意以背於善良風俗之方法**，加損害於他人者亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「律師過失致遺囑無效，受遺贈人得否依委任契約向律師請求？」 | **否**。受遺贈人非契約當事人（債之相對性） |
| 「契約對第三人保護效力理論於我國實務之地位？」 | **未承認**；突破債之相對性且無明文，僅存於學說與少數德國判決 |
| 「受遺贈人得否依 §184 I 前段向律師請求？」 | **否**。遺贈僅有**債權效力**，非絕對權 → 純粹經濟上損失 |
| 「主張律師依 §184 I 後段負責之學說如何解釋要件？」 | **從寬**：故意含**重大輕率**；背俗只須為一般社會大眾所不能接受 |
| 「從寬解釋之目的？」 | 填補前段（權利）與後段（利益＋故意背俗）間之**保護漏洞** |

## 一、請求權檢驗圖

```
丙 → 甲律師
├── 契約（委任）✗ 丙非當事人，債之相對性
│     └── 契約對第三人保護效力 → 理論可，實務不承認
├── §184 I 前段 ✗ 遺贈＝債權，非絕對權 → 純粹經濟損失
└── §184 I 後段 ？
      ├─ 從嚴：非故意、非踩道德底線 → ✗
      └─ 從寬：重大輕率＝故意；大眾不能接受＝背俗 → ✓
```

## 二、保護漏洞示意

| 行為人主觀 | 行為之不法程度 | 侵害客體 | 結果 |
|---|---|---|---|
| 過失 | 一般不法 | 權利 | §184 I 前段 ✓ |
| 故意 | 背於善良風俗 | 利益 | §184 I 後段 ✓ |
| 過失 | 一般不法 | 利益（純粹經濟損失） | 原則不保護（維持契約與侵權界線、利益欠缺典型公開性） |
| **重大輕率**（趨近故意） | **趨近背俗** | 利益 | 從寬說：例外適用後段 |

## 三、德國參考案例：監護宣告資料錯誤

1. 法院為監護宣告（舊稱禁治產宣告）時，囑託醫師提供醫療資料
2. 醫師誤交他人的資料，法院認當事人正常而未為宣告
3. 當事人此後任意處分財產受損 → 經濟損失
4. 德國法對此種接近背俗、接近重大輕率的情形擴大侵權保護範圍；課堂所述學者參考此見解

## 四、答題提醒

- 寫從寬時要先鋪「從嚴 → 丙無從求償 → 甲毫無責任不妥」，再改採從寬
- 實務是否承認此從寬解釋，字幕未說明；考試寫「學說有認為」較穩
