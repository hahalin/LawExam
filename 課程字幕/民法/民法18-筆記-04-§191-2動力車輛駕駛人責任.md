# 民法18 筆記：§191-2動力車輛駕駛人責任

## 適用範圍：
- 汽車、機車或其他**非依軌道**行駛之**動力**車輛；動力指機械動力
- **不含**：腳踏車（人力）、牛車馬車（獸力）、火車（依軌道）——選擇題真的會考「被哪種車撞到不能主張 §191-2」

## 使用中加損害於他人：
- 須車輛**使用中**：駕駛中或人在車上使用
- 違規停車、人已離開，機車撞上受傷 → 停車人負 §184，**無 §191-2**
- 純粹經濟上損失：用語雖是「加損害」，王澤鑑與多數學說均認**不包含**，這裡反而少爭議（車禍回堵致誤機改票之損失不能請求）

## 責任主體是駕駛人：
- 條文只規定**駕駛人**；所有人把車借人開，依我國條文**不負** §191-2
- 日本法、德國法採肯定：持有汽車如同持有房屋，屬持有危險源 → 修法可思考擴大

## 只推定過失：
- 不推定不法與因果；與 §184 II 類似，但更好用——§184 II 還要證明違反保護他人之法律，§191-2 只要證明對方是駕駛人、車輛使用中加損害

## 📖 法條原文速查

> **§191-2**　汽車、機車或其他**非依軌道行駛之動力車輛**，在**使用中**加損害於他人者，**駕駛人**應賠償因此所生之損害。但於防止損害之發生，已盡相當之注意者，不在此限。

> **§184 II**（要旨）　違反保護他人之法律，致生損害於他人者，負賠償責任；但能證明其行為無過失者，不在此限。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「被下列何者撞傷，不得依 §191-2 請求？A 火車 B 腳踏車 C 大卡車」 | **火車**（依軌道）、**腳踏車**（非動力）；大卡車可 |
| 「被牛車撞傷得否主張 §191-2？」 | **否**，非機械動力 |
| 「違規停車、駕駛已離開，第三人撞上受傷，車主負 §191-2？」 | **否**，非使用中；回 §184 |
| 「車主將車借友人駕駛肇事，車主負 §191-2？」 | **否**，責任主體限駕駛人 |
| 「§191-2 推定哪些要件？」 | 只推定**過失** |
| 「車禍致後方回堵，他車誤機之損失得依 §191-2 請求？」 | **否**，純粹經濟上損失不在保護範圍 |

## 一、構成要件與法律效果

```
§191-2
├─ 機動車輛：汽車、機車、其他非依軌道之動力車輛
│    ✗ 腳踏車　✗ 牛車馬車　✗ 火車
├─ 使用中：駕駛中／人在車上使用
│    ✗ 已停妥下車
├─ 加損害於他人：限權利受侵害（多數說）
├─ 責任主體：駕駛人（不含出借之所有人）
└─ 但書：已盡相當注意 → 只推定過失
```

## 三、§184 II 與 §191-2 舉證比較（車禍原告）

| | §184 II | §191-2 |
|---|---|---|
| 原告要證明 | 違反保護他人之法律（超速、未注意車前狀況） | 對方是駕駛人、車輛使用中加損害 |
| 推定 | 過失 | 過失 |
| 實務 | 題目給違規事實時用 | 車禍案件最常被拿出來用，舉證最輕鬆 |

## 四、比較法：所有人應否負責

| | 我國 §191-2 | 日本法、德國法 |
|---|---|---|
| 責任主體 | 駕駛人 | 所有人、持有人亦負責 |
| 理由 | 文義 | 持有危險源，應妥善保管、不隨意出借 |
| 啟示 | 修法時可考慮擴大至所有人或占有人 | |
