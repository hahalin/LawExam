# 民法36 筆記：有償回復與不得回復（§950、§951）

## 兩個例外的差別：
- **§950 有償回復**：原占有人要先償還現占有人支出的價金，才能回復
- **§951 不得回復**：金錢、未記載權利人之有價證券，無論如何都不能回復
- 兩條都是 §949 的例外，交易安全被保護的程度比一般善意取得更高

## §950 的要件：
- 標的物是盜贓、遺失物或其他非基於原占有人之意思而喪失占有之物
- 現占有人是從下列管道**以善意買得**：
  - **公開交易場所**，或
  - **販賣與其物同種之物之商人**
- 理由：在店裡用正常價格買到東西，買受人更難想像是贓物
- 數字例：
  - 甲在二手錶店看中一支原價 30 萬元的錶，店家開價 18 萬元，甲認為六折合理就買下
  - 事後發現是贓物，錶主要回復，**須先償還甲 18 萬元**
- 不適用的情形：在火車上偷了當場賣掉、在補習班偷了在補習班轉賣 → 不是公開交易場所，也不是同種之物的商人

## 爭點：網路拍賣算不算：
- 教科書有援引早年德國見解，認為網拍既非公開交易場所、也非商人 → 一律不適用
- 老師見解：**視賣場性質而定**
  - 私人賣場、什麼都賣（手錶、文具、電腦）→ 跟私下買賣沒兩樣 → 不適用
  - 購物平台上的專業商家、專賣同類商品 → 可認為是「販賣與其物同種之物之商人」→ 可適用 §950

## §951 不得回復：
- 對象：**金錢**、**未記載權利人之有價證券**
- 理由：
  - 很難證明是誰的（被偷的 100 元拿去買早餐，怎麼向早餐店證明那張是你的）
  - 若可回復，大家都不敢收錢，**流通性**喪失
- 老師的反思：現在演唱會票、車票都有手機購買紀錄，已非「難以證明」；可考慮**限縮解釋**為真的無法證明歸屬者（例：撿到一張不知誰買的車票）

## 📖 法條原文速查

> **§950**　盜贓、遺失物或其他非基於原占有人之意思而喪失其占有之物，如現占有人由**公開交易場所**，或由**販賣與其物同種之物之商人**，以**善意買得**者，**非償還其支出之價金，不得回復其物**。

> **§951**　盜贓、遺失物或其他非基於原占有人之意思而喪失其占有之物，如係**金錢**或**未記載權利人之有價證券**，**不得**向其善意受讓之現占有人請求回復。

> **§951-1**　第九百四十九條及第九百五十條規定，於原占有人為惡意占有者，不適用之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「於二手商店善意買得贓物，原所有人得無償回復？」 | **否**，須償還支出之價金（§950） |
| 「於火車上向竊賊善意買得贓物，有 §950 適用？」 | **無**，非公開交易場所、非同種商人 → 回到 §949 無償回復 |
| 「被竊之現金，得向善意受讓人請求回復？」 | **不得**（§951） |
| 「被竊之無記名有價證券，得請求回復？」 | **不得**（§951） |
| 「§950 須以『善意買得』為要件？」 | **是**，受贈不適用 |

---

## §949～§951-1 體系

```
盜贓、遺失物、非因己意喪失占有之物，被善意受讓
│
├─ 原占有人惡意 → 不能主張（§951-1）
├─ 金錢、無記名有價證券 → 不得回復（§951）
├─ 公開交易場所或同種商人處善意買得 → 償還價金才能回復（§950）
└─ 其他 → 2 年內無償回復（§949）
```
