# 民法二試03 筆記：不動產查封登記與給付不能（§226）

## 案例（詹森林文章，講義 147～148 頁）：
- 甲將 A 屋賣給乙；A 屋正被甲的債權人丙**查封**中
- 乙可以依 §348 請求甲移轉登記嗎？還是只能依 §226 請求損害賠償？

## 早期實務（70 年第 18 次民事庭決議，註 256）：
- 土地登記規則 §141 I：查封登記未塗銷前，登記機關應**停止**與其權利有關之新登記
- 查封撤銷前不能辦移轉 → **給付不能** → 法院不得命移轉登記，乙只能依 §226 請求賠償

## 詹森林：
- 給付不能分**一時不能**與**永久不能**；§226 的給付不能應指**永久不能**
- 查封是暫時的（甲清償後即可撤銷查封）→ 一時不能 → 乙仍得依 §348 請求給付，甲不能履行時依 §231 I 請求遲延損害
- 早期決議等於剝奪買受人請求給付標的物的權利，不符憲法保障財產權意旨
- 最高法院前後訴訟見解不一（前訴訟 110 年 2555 號裁定〔註 255〕循舊決議，後訴訟採詹說）→ 應提**大法庭**統一見解

> 來源：民法二試03 課程字幕 00:11:56 ~ 00:18:52（講義 147～148 頁，註 254～256）

---

## 📖 法條原文速查

> **民法 §348 I**　物之出賣人，負交付其物於買受人，並使其取得該物所有權之義務。
> **民法 §226 I**　因可歸責於債務人之事由，致**給付不能**者，債權人得請求賠償損害。
> **民法 §231 I**　債務人遲延者，債權人得請求其賠償因遲延而生之損害。
> **土地登記規則 §141 I**（要旨）：土地經查封、假扣押、假處分、暫時處分、破產登記或因法院裁定而為清算登記後，未為塗銷前，登記機關應停止與其權利有關之新登記。（原文請對六法）

---

## 📋 實務見解速查

> **最高法院 70 年第 18 次民事庭會議決議**（講義註 256，要旨）：不動產既經查封，依土地登記規則（當時為 §128，即現行 §141）在法院撤銷查封前，登記機關不得准許移轉登記，出賣人辦理移轉登記之給付處於給付不能狀態，法院不能命為移轉登記。

> **前訴訟：110 年 2555 號裁定**（講義註 255；字幕未唸全稱，請對講義）：延續上開決議。後訴訟改採詹森林見解（字號請對講義）。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「標的不動產遭查封，買受人得否請求移轉登記？」 | 爭點在查封是否構成 §226「給付不能」 |
| 「早期實務？」 | 70 年第 18 次決議：登記機關須停止新登記 → 給付不能，只能請求損害賠償 |
| 「詹森林？」 | §226 限永久不能；查封是一時不能 → 仍得依 §348 請求給付，遲延依 §231 I |
| 「為何不採早期實務？」 | 剝奪買受人請求給付之權利，與財產權保障不符 |
| 「實務見解分歧怎麼辦？」 | 應提大法庭統一見解（詹森林主張） |

## 一、比較表

| | 早期實務（70-18 決議） | 詹森林 |
|---|---|---|
| 查封之性質 | 給付不能 | 一時不能 |
| 乙得否請求移轉登記 | ✗ | ✓（§348） |
| 乙之救濟 | §226 損害賠償 | 請求給付＋§231 I 遲延損害 |
| 評價 | 剝奪買受人之給付請求權 | 符合給付障礙體系 |

## 二、論述骨架

```
乙對甲：§348 I 請求移轉 A 屋所有權
  ↓ 甲抗辯：A 屋被查封，登記機關停止登記 → 給付不能
  ↓ 爭點：§226「給付不能」是否包括一時不能？
  ├─ 早期實務：包括 → 不得命移轉，只能 §226
  └─ 詹森林：限永久不能；查封可因清償而撤銷 → 一時不能
  ↓ 結論（採詹說）：法院仍得命甲移轉；
     甲屆期不能給付 → 乙另依 §231 I 請求遲延損害
```
