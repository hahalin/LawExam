# 民法24 筆記：債務不履行之體系與自始客觀不能（§246、§247）

## 第一次給付與第二次給付：
- **第一次給付**：依契約命債務人履行（買車就是要車）
- **第二次給付**：不履行時改請求損害賠償，屬替代性
- 思考順序：先試著命他履行，真的不行才走債務不履行

## 債之效力的條文地圖：
- §219（履行應依誠信）88、89 年修法刪除：與 §148 重疊，本意不變
- **§220～§224**：什麼叫可歸責（見民法24-筆記-11、12）
- 給付不能：§225、§226
- 不完全給付：§227、§227-1
- 給付遲延：§229～§233
- 受領遲延：§234～§241
- 雙務契約的對待給付與解除：§266、§267、§256

## 給付不能的分類：
- 時點：締約當下就不能（**自始**）vs 締約後才不能（**嗣後**）
- 範圍：任何人都做不到（**客觀**）vs 只有債務人做不到（**主觀**）
- **自始客觀不能**：§246 契約**無效** → 沒有債 → 不是債務不履行
- 債務不履行的給付不能 = **自始主觀不能**＋**嗣後不能**

## §246 但書：例外有效
- 兩要件：不能情形**可以除去**＋當事人訂約時**預期**於除去後為給付
- **105 台上 1254**（講義註 670，字號建議查證）：早年非自耕農不得買農地，契約自始客觀不能而無效；後來修法開放，買受人能否請求履行？
  - **不行**：訂約時沒有預見會修法，不符合「並預期」

## §247：信賴利益的賠償
- 要件：一方訂約時**知其不能或可得而知**；他方**非因過失**而信契約有效致受損害
- 範圍：**信賴利益**（消極的契約利益）：締約費用、準備費用、**喪失締約機會**的損害
- **不包括履行利益**——契約無效就不用履行，哪來的履行利益
- 51 台上 2101 判例（講義 421 頁）

## 📖 法條原文速查

> **§246**　I 以**不能之給付**為契約標的者，其契約為**無效**。但其不能情形**可以除去**，而當事人訂約時並**預期**於不能之情形除去後為給付者，其契約仍為有效。II 附停止條件或始期之契約，於條件成就或期限屆至前，不能之情形已除去者，其契約為有效。

> **§247 I**　契約因以不能之給付為標的而無效者，當事人於訂約時**知其不能或可得而知**者，對於**非因過失**而信契約為有效致受損害之他方當事人，負賠償責任。

---

## 📋 實務見解速查

> **51 台上 2101 判例**：契約因出賣人以不能之給付為標的而無效者，買受人所得請求賠償之範圍，依 §247 I 自以因信賴契約有效所受之損害為限，即**消極的契約利益（信賴利益）**，例如訂約費用、準備履行所需費用或另失訂約機會之損害；至積極的契約利益（履行利益），不得請求。

> **105 台上 1254**：不能情形縱事後因修法而除去，訂約時未預期者，不符 §246 I 但書。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「自始客觀不能是否屬債務不履行？」 | **否**，§246 契約無效 |
| 「債務不履行的給付不能包括？」 | **自始主觀不能**、**嗣後不能** |
| 「§246 但書有效的要件？」 | 可以除去＋訂約時**預期**除去後給付 |
| 「事後修法使不能除去，契約即有效？」 | **否**，須訂約時有預期 |
| 「§247 賠償範圍？」 | **信賴利益**，含喪失締約機會；不含履行利益 |

## 案例：燒掉的小木屋

### 事實
- 甲的 A 屋上個月已燒毀，甲長住國外不知情
- A 屋市價 **500 萬**，甲以 **400 萬**賣給乙
- 丙同時以 **400 萬**要賣乙 B 屋（市價 **450 萬**），乙選 A 屋、拒絕丙

### 分析
| | 計算 | 可否依 §247 請求 |
|---|---|---|
| 履行利益 | 500 − 400 = **100 萬** | ✗ 契約無效，無履行利益 |
| 信賴利益（喪失締約機會） | 450 − 400 = **50 萬** | ✓ |

```
給付不能
├── 自始客觀不能 → §246 無效 → §247 信賴利益（不是債務不履行）
└── 債務不履行
    ├── 自始主觀不能
    └── 嗣後不能 → §225、§226（下一講）
```
