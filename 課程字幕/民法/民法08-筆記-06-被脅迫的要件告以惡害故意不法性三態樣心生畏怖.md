# 民法08 筆記：被脅迫的要件——告以惡害、故意、不法性三種態樣（目的／手段／關聯）、心生畏怖的因果關係

> 來源：民法08 課程字幕 00:35:00 ~ 00:43:31（講義 197 頁葉啟洲停工漲價）

---

## 📖 法條原文速查

> **§92 I 前段**　因被詐欺或**被脅迫**而為意思表示者，表意人得撤銷其意思表示。
> **§148 I**　權利之行使，不得違反公共利益，或以損害他人為主要目的。

---

## 📋 實務見解速查

> 最高法院（字號請對講義）：兒子為使父親擔任保證人，當場咬舌自殘昏厥，父親驚嚇後同意作保 → 最高法院認為**不構成脅迫**（惡害須是對表意人的惡害）。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「脅迫之意義？」 | **故意告以惡害**，使表意人心生畏怖而為意思表示。詐欺是告知不實資訊，脅迫是告知惡害 |
| 「子以自殺相逼使父作保？」 | 最高法院：**非脅迫**（惡害須是對表意人之不利益） |
| 「不法性之態樣？」 | ① **目的不法** ② **手段不法**（不賣畫就放火燒你家）③ **目的與手段均合法但欠缺合理關聯**（不便宜賣地就舉發你逃漏稅） |
| 「承攬人以停工要脅定作人調高報酬，是否脅迫？」 | 看**關聯合理性**：原物料上漲等正當理由 → 停工與漲價有合理關聯 → 非脅迫（葉啟洲：停止供貨要求漲價不違交易習慣，除非獨占寡占）；單純坐地喊價 → 可能構成 |
| 「因果關係？」 | 因被脅迫而**心生畏怖**，因畏怖而為意思表示；不害怕就不是被脅迫 |

---

## 一、要件體系
```
① 脅迫行為：故意告以惡害（對表意人的不利益）
② 不法性：目的不法／手段不法／目的手段關聯不法
③ 因果關係：被脅迫 → 心生畏怖 → 為意思表示
④ 第三人脅迫（下一份筆記）
⑤ 除斥期間 §93（脅迫終止後一年；意思表示後十年）
```

## 二、惡害要對表意人
- 兒子咬舌案：兒子傷害的是自己，不是對父親的惡害 → 最高法院不認為是脅迫。
- 故意：從文義推知；「不小心脅迫到你」殊難想像。

## 三、不法性三態樣

| 態樣 | 目的 | 手段 | 關聯 | 例 | 脅迫？ |
|------|------|------|------|-----|------|
| 手段不法 | 合法（訂買賣） | 不法（放火） | — | 不把畫賣我就燒你家 | ✓ |
| 關聯不法 | 合法（訂買賣） | 合法（舉發逃漏稅） | **無合理關聯** | 不便宜賣地就舉發你 | ✓ |
| 都合法且有關聯 | 合法 | 合法 | 有 | 原物料漲 → 不調報酬就停工 | ✗ |

### 停工漲價（葉啟洲，講義 197 頁）
```
承攬報酬 1,000 萬 → 承攬人：不漲到 1,800 萬就停工
葉啟洲：以停止供貨、斷貨要求漲價，不違交易習慣，手段目的不違法，也有關聯 → 非脅迫（除非獨占、寡占）
老師：看漲價有無正當理由
    原物料上漲不得不漲 → 關聯合理 → 不構成
    報酬本來夠、只想賺更多、坐地喊價 → 仍可能構成 → 個案認定
```

## 四、因果關係：心生畏怖
- 被脅迫 → 害怕 → 因害怕而為意思表示。沒有害怕就不是被脅迫的意思表示。
