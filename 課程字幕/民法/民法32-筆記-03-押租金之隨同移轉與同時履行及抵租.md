# 民法32 筆記：押租金之隨同移轉與同時履行及抵租

## 定位：
- 押租金**沒有法條**，是當事人約定的給付，爭點都靠實務見解整理
- 租賃成立的三塊：意定（§421、§422）→ 法定（§425、§425-1、§426）→ 押租金

## 爭點一：買賣不破租賃時，押租金會不會隨同移轉？
- 事實：乙承租甲的房屋並交付押租金，甲把房屋賣給丙，租約依 §425 移到乙丙之間；租約終止後，乙要找誰拿回押租金？
- 早年實務：押租金契約是租約的**從契約**，主契約法定移轉，從契約隨同移轉 → 乙向**丙**請求返還
  - 問題：甲賣屋時沒把押租金交給丙，丙卻要還錢，不合理
- 現行實務：押租金契約是**要物契約**，以金錢交付為成立要件
  - 甲**有把押租金轉交**丙 → 隨同移轉 → 乙向**丙**請求返還
  - 甲**沒有轉交** → 不隨同移轉 → 乙只能向**甲**依 **§179** 請求返還（押租金擔保的租賃關係已不在甲乙之間，甲無保有權源）
- 考試出現過

## 爭點二：返還租賃物與返還押租金可否同時履行？
- 事實：租約終止，甲依 §455 請求乙返還房屋；乙說「押租金不還，鑰匙就不還」
- 實務：**否定**
  - 押租金擔保租賃物的返還，乙有**先返還租賃物**的義務
  - §264 要件是「自己無先為給付之義務」→ 要件不合
- 王澤鑑教授：**類推 §264** 肯定
  - 承認要件不合，但兩者時間非常緊密（交鑰匙的一瞬間就該還錢）
  - 鑰匙是承租人最後的武器，交出去後房東可能開始挑毛病扣錢

## 爭點三：押租金可否抵充租金？（§440 II 的計算）
- 事實：乙付了兩個月押租金，已欠租兩個月；甲可否依 §440 II 終止？
- 押租金當然擔保的只有兩件事：
  - ① 擔保**租賃物之返還**
  - ② 擔保**租賃物之完整**（毀損的修繕費從押租金扣）
- 是否擔保**租金支付**，要看**特約**：
  - 有「押租金得抵租金」特約 → 欠 2 個月先以押租金抵充 → 要再欠 2 個月才達 §440 II 門檻（2＋2）
  - 無特約 → 不得抵充，欠滿 2 個月即可依法催告後終止
- 理由：若無特約也能抵，承租人就能用欠租的方式強迫房東返還押租金，押租金的擔保功能落空

## 📖 法條原文速查

> **§264 I**　因契約互負債務者，於他方當事人未為對待給付前，得拒絕自己之給付。但**自己有先為給付之義務者，不在此限**。

> **§440 II**　租賃物為房屋者，遲付租金之總額，非達**二個月之租額**，不得依前項之規定，終止契約。其租金約定於每期開始時支付者，並應於遲延給付逾二個月時，始得終止契約。

> **§455**（前段）承租人於租賃關係終止後，應返還租賃物。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「押租金契約的性質？」 | **要物契約**，以金錢交付為成立要件 |
| 「出租人賣屋未轉交押租金，承租人向誰請求返還？」 | 向**原出租人**依 §179 請求，不能向受讓人請求 |
| 「出租人已轉交押租金給受讓人？」 | 隨同移轉，向**受讓人**請求 |
| 「承租人可否以押租金未返還為由拒絕返還房屋？」 | 實務**否定**（先返還租賃物）；王澤鑑類推 §264 肯定 |
| 「押租金當然可抵充欠租？」 | **否**，須有特約才能 2＋2 |
