# 民法09 筆記：§118 處分權——狹義處分（物權、準物權行為）、債權行為不以有處分權為必要；有權處分的來源 §765、§1088 II 但書、授權處分；善意取得不會「治癒」物權行為

> 來源：民法09 課程字幕 01:33:12 ~ 01:46:33

---

## 📖 法條原文速查

> **§118**（無權處分）
> I 無權利人就權利標的物所為之處分，經有權利人之承認始生效力。
> II 無權利人就權利標的物為處分後，取得其權利者，其處分自始有效。但原權利人或第三人已取得之利益，不因此而受影響。
> III 前項情形，若數處分相牴觸時，以其**最初之處分**為有效。

> **§765**　所有人，於法令限制之範圍內，得自由使用、收益、**處分**其所有物，並排除他人之干涉。
> **§1088 II**　父母對於未成年子女之特有財產，有使用、收益之權。但非為子女之利益，不得處分之。
> **§801、§948**　善意受讓

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§118 之『處分』？」 | **狹義**：物權行為、**準物權行為**（債權讓與也適用 §118）；債權行為不在內 |
| 「無權處分人所訂買賣契約效力？」 | **有效**。債權行為以發生債權債務為目的、不以有處分權為必要；無法移轉頂多債務不履行。若認無效，買受人連債務不履行都不能主張，更不利 |
| 「誰有處分權？」 | ① 所有人（**§765**）② 父母對未成年子女之特有財產，**為子女利益**時（**§1088 II 但書**，如賣地供子女留學）③ **授權處分**（王澤鑑：本人授權他人以**他人自己名義**處分，基於私法自治可承認） |
| 「承租人、借名登記出名人、讓與擔保權人有無處分權？」 | **無** |
| 「授權處分 vs 授與代理權？」 | 授與代理權：乙以**甲**名義為之，效果在甲丙間。授權處分：乙以**自己**名義處分甲的物並交付（甲不想出名） |
| 「甲將車借乙，乙賣予善意丙並交付，甲拒絕承認；乙丙物權行為效力？」 | **不生效力**（甲拒絕承認）。丙依 §801＋§948 善意取得。**善意取得不會治癒物權行為**——物權行為若有效就不需要善意取得，兩者矛盾 |

## 一、§118 只管狹義處分
```
債權行為（買賣）：目的是發生債權債務 → 有沒有處分權不影響 → 有效；移轉不了 → 債務不履行
物權行為／準物權行為：目的是權利變動 → 要有處分權 → 無權處分 → §118 效力未定
→ 反過來想：若無權處分使買賣無效，乙丙間連債的關係都沒有，丙連債務不履行都不能主張 → 更可怕
```

## 二、有權處分的三種來源
| 來源 | 依據 | 說明 |
|------|------|------|
| 所有人 | §765 | 使用、收益、處分 |
| 父母對子女特有財產 | §1088 II 但書 | 須**為子女利益**：阿公送的地賣掉供子女讀美國名校 ✓ |
| 授權處分 | 法無明文，王澤鑑 | 甲授予乙處分權，乙以**自己名義**把 A 車賣給丙並交付（明星不想出名）；私法自治、契約自由下可承認 |

- 沒有處分權的典型：承租人、借名登記的出名人、讓與擔保的擔保權人。

## 三、無權處分的基本處理
```
債權行為有效
處分行為（物權／準物權）效力未定 → 本人承認 → 有效；拒絕 → 不生效力
→ 第三人靠善意受讓取得
```

## 四、選擇題陷阱：善意取得會不會讓物權行為變有效
```
甲借車給乙，乙賣給善意丙並交付，甲拒絕承認
✓ 買賣有效；物權行為因甲拒絕而不生效力；丙善意取得 A 車
✗「丙善意取得，故乙丙物權行為之瑕疵被治癒而有效」
→ 矛盾：物權行為若有效，丙直接從乙取得，根本不需要善意取得
→ 善意取得是「無中生有」，前提就是前手無權處分；它只讓丙拿到 A，沒有治癒的效果
```
