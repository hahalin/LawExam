# 民法03 筆記：代表與代理的區別

> 來源：民法03 課程字幕 00:11:41 ~ 00:20:23

---

## 📖 法條原文速查

> **§103 I**（代理行為之要件及效力）
> 代理人於代理權限內，以**本人名義**所為之**意思表示**，直接對本人發生效力。

> **§27 II**（董事之代表權）
> 董事就法人一切事務，對外代表法人。

> **§1**（法源）
> 民事，法律所未規定者，依習慣；無習慣者，依法理。→ 代表無明文 → 類推代理

---

## 📋 實務見解速查

> **最高法院 86 年台上字第 1782 號判決**：代理與代表之制度，法律性質及效果均不相同。代表為法人組織法上所不可或缺，代表人與法人係**一個權利主體間之關係**，代表人所為之行為，不論**法律行為、事實行為或侵權行為**，均為法人之行為；代理人與本人則係**兩個權利主體間之關係**，代理僅限於**法律行為及準法律行為**。
> → 建議查閱判決原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「代理人得代理本人為侵權行為？」 | **不可**。代理只限法律行為、準法律行為（需要意思表示的場合） |
| 「法人代表人之侵權行為，是否為法人之行為？」 | **是**。代表人是法人手足，法律行為、事實行為、侵權行為都算 |
| 「代表人與法人／代理人與本人，是幾個權利主體？」 | 代表：**一個**；代理：**兩個** |
| 「A 法人之甲董事無權占有 B 之土地，B 依 §767 應以誰為被告？」 | **A 法人**。以甲為被告會敗訴（甲無無權占有之事實，是 A 在占有） |
| 「無權代表之效力？」 | 民法無明文 → **類推** §170 效力未定（相同事物相同處理） |

## 一、結構上的差別

```
代理（§103）
    本人 ──授與代理權──→ 代理人 ──以本人名義為意思表示──→ 相對人
    效力直接及於本人；但代理人不是本人，本人不是代理人 →【兩個權利主體】

代表（§27 II）
    法人 ＝ 代表人（在職務範圍內）──行為──→ 相對人
    代表人就是法人的手足，代表人的行為＝法人的行為 →【一個權利主體】
```

| 比較項目 | 代理 | 代表 |
|---------|------|------|
| 主體 | 本人、代理人是**兩個**人 | 代表人與法人是**同一個**主體 |
| 做什麼 | 代為、代受**意思表示** | **任何行為** |
| 範圍 | 僅法律行為、準法律行為 | 法律行為、準法律行為、事實行為、**侵權行為** |
| 能否「代」侵權行為 | **不能**（那是教唆、幫助的問題） | 代表人的侵權行為就是法人的侵權行為 |
| 民法規定 | 很多（§103～§110、§167～§171） | 只有定義性規定（應設董事、董事為代表人） |

## 二、「手足」的比喻

- 你的手打了人一巴掌，不能說「不是我打的，是我的手打的」。手受你支配、是你身體的一部分。
- 董事是法人的手，不能把董事跟法人切開 → 董事做什麼＝法人做什麼。

### 考法：告誰
```
A 法人的甲董事（代表 A）無權占有 B 的土地
B 依 §767 I 前段請求返還 → 被告是誰？

把甲和 A 畫上等號 → 是 A 在無權占有 → 以 A 為被告
以甲為被告 → 法院：甲沒有無權占有的事實（他是代表 A 占有）→ 敗訴
```

## 三、為什麼無權代表要「類推」代理

- 代理和代表結構不同，不能直接用代理規定。
- 但概念很像（一個人做、另一個人承受效果）→ 相同事物相同處理。
- 民法對代表的定義、效力完全沒規定 → §1 法律未規定依法理 → 找最類似的條文來類推 → 無權代理 §170。
