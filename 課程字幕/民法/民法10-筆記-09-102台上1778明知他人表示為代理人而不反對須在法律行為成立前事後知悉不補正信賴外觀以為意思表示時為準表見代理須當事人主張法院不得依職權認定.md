# 民法10 筆記：102 台上 1778——「知他人表示為其代理人而不為反對」有時點限制：須在法律行為**成立前**（相對人為意思表示時要有信賴外觀存在）；事後才知悉而未反對，對已成立之法律行為不生影響、不能補正；表見代理須經**當事人主張**，法院不得依職權認定

> 來源：民法10 課程字幕 01:35:00 ~ 01:42:28（講義 267 頁底下）

---

## 📋 實務見解速查

> **最高法院 102 年度台上字第 1778 號判決**（字號照字幕，建議查閱）：
> 按由自己之行為表示以代理權授與他人者，對於第三人應負授權人之責任，固為民法第 169 條所明定；惟必須該第三人**主張**表見代理行為應對本人發生效力，法院始得審酌，非得由法院任意為之。
> 次按所謂知他人表示為其代理人而不為反對之表示者，係指知他人表示為其代理人**而與相對人為法律行為時**，應即時為反對之表示，使其代理行為無從成立，以保護善意第三人而言；倘於**法律行為成立後**，始知其情事而未為反對之表示者，對業已成立之法律行為**不生影響**，自難令其負授權人責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「① 乙對外宣稱為甲之代理人 → ② 乙代理甲與丙締約 → ③ 丙事後起疑問甲，甲笑而不答、不反對。丙得否依 §169 請求甲負授權人責任？」 | **不得**。丙為意思表示（②）時，甲還沒有任何「明知不反對」的行為 → 當時**沒有信賴外觀**、甲無可歸責事由、丙的信賴也不值得保護 → 無 §169 適用；甲事後明知不反對**不能補正** |
| 「若順序是 ① → ③（丙先問甲，甲不反對）→ ②（丙才締約）？」 | **有** §169 適用。丙是因為信賴甲不反對所創造的外觀才為意思表示 |
| 「法院得否依職權認定表見代理？」 | **不得**。須當事人主張。因為當事人可能寧願主張狹義無權代理（§170）而不主張表見代理——表見代理也是廣義無權代理的一種（下堂 §110 與 §169 關係） |
| 「判斷信賴外觀的時點？」 | 相對人**為意思表示的當下**。那時才有「因信賴外觀而為意思表示」、信賴值得保護的問題 |

## 一、案例時序圖（看這題要畫 ①②③）

```
① 乙對外宣稱「我是甲的代理人」
② 乙代理甲與丙為意思表示（締約）
③ 丙起疑，問甲「乙對你有代理權嗎？」→ 甲笑笑說「你猜」→ 不反對、也不承認
丙：依 §169「明知他人表示為代理人而不反對」要甲負責？
```

| 順序 | 丙為意思表示時有無信賴外觀 | §169 |
|---|---|---|
| ① → ② → ③ | ② 時甲什麼都沒做，外觀在 ③ 才出現 → **無** | ✗ 事後不反對不能補正 |
| ① → ③ → ② | ③ 甲不反對先創造外觀，丙因此於 ② 為意思表示 → **有** | ✓ |

## 二、為什麼：回到權利外觀理論推

```
§107／§169 共同法理：本人可歸責創造外觀 ＋ 相對人因信賴該外觀而為意思表示、信賴值得保護
→ 「因信賴外觀而為意思表示」：外觀必須在意思表示之前就存在
→ 連外觀都沒有就先締約，事後再說「我需要被保護」→ 不通
→ 跟學說反對「自始限制」適用 §107 是同一個思路（筆記 07）
```

## 三、判決前段（沒畫黑線但重要）：表見代理須當事人主張

- §169 是**當事人主張才有法律效果**的事項，法院不能職權認定「本件構成表見代理所以本人要負責」。
- 原因：當事人可能選擇直接主張 §170 無權代理（例如想對無權代理人依 §110 求償），表見代理也是廣義無權代理 → 下堂講 §107／§169 與 §110 的適用關係。
