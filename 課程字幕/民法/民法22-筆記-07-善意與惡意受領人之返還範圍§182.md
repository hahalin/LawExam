# 民法22 筆記：善意與惡意受領人之返還範圍（§182）

## 返還範圍兩層：
- §181 決定**還什麼**（原形或價額）；§182 決定**還多少**
- 善意受領人（§182 I）：所受利益**已不存在** → 免返還或償還價額
- 惡意受領人（§182 II）：不問利益存否，返還全部所受利益，**附加利息**，有損害並應賠償

## 惡意分兩種：
- **自始惡意**（受領時知無法律上原因）→ 受領時所得利益全部返還
- **嗣後惡意**（其後知之）→ 知悉時**現存**的利益全部返還；知悉前已不存在的部分仍免返還（那段時間還是善意）

## 善意不問有無過失：
- §182 I 立法理由：受領人受領時不知無法律上原因，其後利益因不可抗力滅失或因善意而消費，**不問其有無過失**，均免返還
- 有過失拿錯，只要以為是自己的，仍是善意受領人
- 詹森林教授另有見解，見民法22-筆記-10

## 「利益不存在」採總體財產觀察法：
- 與 §179「受利益」採個別財產觀察法不同
- 利益只是轉換形態、總體財產沒減少 → 仍存在（不當得利的車賣掉，換成價金，仍存在）

## 水果題：善意誤取乙的草莓吃掉
- §179：草莓權益歸屬於乙 → 成立
- §181：原形已吃下肚 → 償還價額
- §182 I：看甲有沒有**消費計畫**
  - 沒有吃草莓的計畫 → 沒有節省任何費用 → 利益不存在 → 免返還
  - 本來就要去買草莓 → 省下費用、總體財產沒減少 → 利益存在 → 仍須償還

## 附加利息算幾年（§182 II）：
- 例：甲詐騙乙 100 萬，10 年後乙依 §179 請求（純詐欺、不涉 §92 撤銷）
- 甲是惡意受領人 → 100 萬原形＋利息；未約定依 §203 年息 5%，每年 5 萬
- 早年實務：§125，15 年內利息都可請求 → 10 年共 50 萬
- **95 年第 17 次民事庭決議**：附加利息性質雖屬不當得利，既以利息為計算標準，時效依 **§126** 為 5 年 → 只能請求最近 5 年共 25 萬

## 📖 法條原文速查

> **§182**　I 不當得利之受領人，**不知**無法律上之原因，而其所受之利益**已不存在**者，免負返還或償還價額之責任。II 受領人於受領時，**知**無法律上之原因或其後知之者，應將受領時所得之利益，或知無法律上之原因時所現存之利益，**附加利息**，一併償還；如有損害，並應賠償。

> **§203**　應付利息之債務，其利率未經約定，亦無法律可據者，週年利率為**百分之五**。

> **§126**　利息、紅利、租金、贍養費、退職金及其他一年或不及一年之定期給付債權，其各期給付請求權，因**五年**間不行使而消滅。

## 📋 實務見解速查

> **最高法院 95 年度第 17 次民事庭會議決議**（講義 343 頁、註 535，要旨）：利息、紅利、租金等 §126 定有明文；§182 II 所定附加之利息，性質上雖屬不當得利，惟既明定以利息為計算標準，參照 49 年判例意旨，其請求權時效仍應依 §126 規定為 **5 年**。（字號依字幕，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「善意受領人有過失，得適用 §182 I？」 | **得**，立法理由：不問有無過失 |
| 「§182 I 利益是否存在，採何觀察法？」 | **總體財產觀察法** |
| 「善意誤食他人草莓，須否償還？」 | 看有無**消費計畫**：有 → 須還；無 → 免還 |
| 「嗣後惡意之受領人，返還範圍？」 | **知悉時現存**之利益＋利息＋損害 |
| 「§182 II 附加利息之時效？」 | **5 年**（§126，95 年第 17 次決議） |
| 「未約定利率之附加利息？」 | 週年 **5%**（§203） |

## 一、§182 構造

```
不當得利受領人
├─ 善意（不問過失）→ §182 I
│   ├─ 利益存在（總體財產觀察）→ 返還現存部分
│   └─ 利益不存在 → 免返還
└─ 惡意 → §182 II
    ├─ 自始惡意 → 受領時全部利益
    └─ 嗣後惡意 → 知悉時現存利益
    ＋ 附加利息（§126，5 年）＋ 損害賠償
```

## 二、兩個觀察法不要混

| | §179 受利益 | §182 I 利益是否存在 |
|---|---|---|
| 觀察法 | 個別財產 | 總體財產 |
| 目的 | 有沒有得利 | 返還後會不會讓善意者虧損 |
