# 民法38 筆記：共有物分割之方法（協議分割與裁判分割§824）

## 兩條路：先協議，不成才裁判
- **協議分割**（§824 I）：性質是**債權契約**，只產生履行請求權；不動產要完成分割登記、動產要互相交付應有部分，才發生分割效力
- **裁判分割**（§824 II）：兩種前提擇一
  - 分割方法**不能協議決定**
  - 已有協議，但履行請求權**罹於時效**（§125，15 年），其他共有人主張時效抗辯拒絕履行

## 實務常見：老協議過了 15 年
- 長輩民國 60 年訂過分割協議，當時沒去辦分割登記
- 協議只是契約，請求權 15 年不行使即罹於時效；有人拒絕履行 → 只能訴請裁判分割

## 裁判分割的順序：原物分配為原則，變價為最後手段
- 法院要用盡原物分配的可能，才能變賣；沒試過就變價，常被最高法院廢棄發回
- 由優先到最後：
  1. 原物全部分配給**全體**共有人
  2. 原物全部分配給**部分**共有人，其他人金錢補償（§824 II①但書、III）
  3. 一部分分配，**其餘維持共有**（§824 IV）
  4. 一部分分配，**其餘變賣**（§824 II②後段）
  5. **全部變賣**，價金分配（§824 II②前段，須原物分配「顯有困難」）
- 老師舉例：小塊土地有 136 個共有人，切 136 份每份都沒價值 → 分給其中 3 人，其他人受金錢補償

## 變賣時的優先承買權（§824 VII）
- 變賣共有物，共有人得依相同條件優先承買
- 二人以上願承買 → **抽籤**，只能一人**單獨**承買；不能共同承買（否則又回到共有）
- 對照土地法 §34-1 IV：共有人出賣應有部分，他共有人可「單獨或共同」優先承購

## 合併分割（選擇題常考）
- **共有人全部相同**的數不動產：可請求合併分割（§824 V）
- **共有人部分相同**：三要件（§824 VI）
  1. 數筆不動產須**相鄰**
  2. 由**各筆都有應有部分**的共有人請求
  3. 經**各筆不動產應有部分過半數**共有人同意
- 法院認為不適當，仍分別分割（§824 VI 但書）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 分割協議的性質 | **債權契約**；登記（不動產）或交付（動產）才生分割效力 |
| 何時可訴請裁判分割 | 不能協議，或協議罹於時效經拒絕履行 |
| 法院可否逕行變價分割 | 不可；原物分配顯有困難才變賣 |
| §824 VII 多人願優先承買 | **抽籤**，單獨承買；不得共同承買 |
| 土地法 §34-1 IV 可否共同優先承購 | **可以**「單獨或共同」 |
| 部分相同共有人之合併分割要件 | 相鄰、各筆均有應有部分之人請求、各筆應有部分過半同意 |

## 合併分割計算例

| 土地 | 共有人 |
|---|---|
| A 地 | 甲、乙、丙 |
| B 地 | 乙、丙、丁 |
| C 地 | 丙、丁、戊 |

- 誰能請求合併分割 A、B、C？只有**丙**（三筆都有應有部分）
- 假設應有部分均等。乙、丙、丁三人同意夠不夠？
  - A 地：乙、丙 → 2/3 過半
  - B 地：乙、丙、丁 → 3/3
  - C 地：丙、丁 → 2/3 過半
  - **夠**

## 分割方法流程

```
能協議？ ──是──→ 協議分割（債權契約）→ 登記／交付才生效
   │                    │
   否                   └─ 罹於時效＋拒絕履行 ─┐
   ↓                                          ↓
            裁判分割（§824 II）
   原物全部分配（全體 → 部分＋補償）
     → 一部分配＋其餘共有
     → 一部分配＋其餘變賣
     → 全部變賣（最後手段，§824 VII 優先承買）
```
