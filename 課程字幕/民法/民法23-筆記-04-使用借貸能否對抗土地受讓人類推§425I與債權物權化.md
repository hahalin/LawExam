# 民法23 筆記：使用借貸能否對抗土地受讓人（類推§425I與債權物權化）

## 案例：幼兒園保衛戰（98 台上 1319）
- 甲繼承祖產 A 地，借給弟弟乙蓋幼兒園（甲乙**使用借貸**）
- 甲的兒子丙要在 A 地蓋工廠；甲先依 §767 訴請乙拆屋還地 → **敗訴**：使用借貸以經營幼兒園為目的，目的未完成、建物仍堪用，乙非無權占有（§470）
- 甲於是把 A 地**贈與並移轉登記給丙**，由丙再依 §767 起訴
- 老師：當年臺大法研所只要題目出現「蓋幼兒園」，就是考這個案子

## 要件檢查：
- 丙是 A 地所有人：沒有問題
- 乙是否無權占有：關鍵在甲乙的使用借貸**能否對抗丙**，學理有三說

## 三說：
- **多數說（肯定無權占有）**：使用借貸只有債之相對性，不能對抗丙
  - 債之相對性是原則，§425 買賣不破租賃是例外 → **原則從寬、例外從嚴**，不宜任意類推
  - 租賃有償、使用借貸**無償**；民法對付錢的保護較多，借用人沒有特別保護的必要
  - 實務及王澤鑑、陳忠五等學者（字幕作「王子建」「陳沖富」，建議查證）
- **詹森林（否定）**：類推適用 **§425 I**
  - 買賣不破租賃在保護已交付的**使用收益狀態**，不論基於租賃或借貸都值得保護
- **吳從周（否定）**：**債權物權化**
  - 物權化要有公示外觀；乙在 A 地上蓋幼兒園，這個事實創造了公示外觀，使人信賴乙有合法的占有權源 → 可對抗丙

## 結論（多數說）：
- 乙對丙為無權占有，§767 要件具備
- 接著才討論丙行使 §767 有無違反誠信原則（見民法23-筆記-05）

## §425 的構造：
- 要件：租賃物**已交付**、承租人**占有中**、所有權讓與第三人
- 法條強調「承租人占有中」：保護的是占有狀態，承租人已不占有就沒有保護必要
- 不限買賣，只要所有權讓與即可 → 嚴格來說是「所有權移轉不破租賃」
- 效果：租賃契約對受讓人繼續存在 → **法定的契約承擔**（把出租人地位移到受讓人）
- 所以有學者認為 §425 **不是債權物權化**：債權物權化是讓甲乙契約拘束第三人；§425 是把第三人拉進來成為契約當事人

## 📖 法條原文速查

> **§425 I**　出租人於租賃物交付後，**承租人占有中**，縱將其所有權讓與第三人，其租賃契約，對於受讓人仍繼續存在。

> **§464**　稱使用借貸者，謂當事人一方以物交付他方，而約定他方於**無償**使用後返還其物之契約。

> **§470**　I 借用人應於契約所定期限屆滿時，返還借用物；未定期限者，應於**依借貸之目的使用完畢時**返還之。但經過相當時期，可推定借用人已使用完畢者，貸與人亦得為返還之請求。II 借貸未定期限，亦不能依借貸之目的而定其期限者，貸與人得隨時請求返還借用物。

> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「使用借貸之貸與人移轉所有權，受讓人得否對借用人主張 §767？」 | 多數說：**得**，借用人對受讓人為無權占有 |
| 「使用借貸可否類推 §425 I？」 | 多數說**否**：例外從嚴、使用借貸無償；詹森林肯定 |
| 「§425 適用要件？」 | 已交付＋**承租人占有中**＋所有權讓與 |
| 「§425 是否限於買賣？」 | **否**，所有權讓與即可 |
| 「§425 是債權物權化嗎？」 | 有學者認為**不是**，是法定契約承擔 |

| 乙對丙 | 無權占有 | 有權占有 | 有權占有 |
| 理由 | 債之相對性、例外從嚴 | 類推 §425 I | 債權物權化＋公示外觀 |
