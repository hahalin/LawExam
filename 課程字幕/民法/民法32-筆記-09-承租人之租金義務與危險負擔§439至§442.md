# 民法32 筆記：承租人之租金義務與危險負擔（§439至§442）

## 條文分工：
- §439 支付時期、§440 遲延效果 → §441 危險負擔 → §442 情事變更（與 §227-2 比較，考過）

## 支付時期（§439）：
- 依約定 → 依習慣 → 都沒有：**租賃期滿時**支付
- 分期支付：每期屆滿時；收益有季節性（例：租地種西瓜）：收益季節終了時
- 實務上幾乎都有約定，有印象即可

## 欠租終止（§440）：
- 租金是金錢之債，不會給付不能，只有**遲延** → 定期**催告**後終止
- 房屋：遲付總額須達**二個月租額**（§440 II）；租地建屋：達**二年租額**（§440 III）
- 二個月怎麼算：
  - **期滿付**（1 月租金 1/31 付）：1/31、2/28 都沒付 → 欠滿兩個月，可催告終止
  - **期初付**（每月 28 日付下個月）：12/28 已付 1 月份；1/28、2/28 沒付 → 雖欠兩期，2/28 當天 3 月一天都還沒住，實際只多住一個月 → **還不能終止**
  - 期初付須遲延給付**逾**二個月（§440 II 後段），實際上是欠到第三期

## 情事變更（§442 vs. §227-2）：
- §442 要件：**不動產**、**未定期限**、因**租賃物價值昇降**
- 定有期限，或因**其他原因**（不是價值昇降），§442 用不上
  - 例一：COVID-19 期間房價上漲，但店面封城無法營業，租金 10 萬元照燒
  - 例二：西門町店面 20 年前租 8 萬元，周邊已漲到 20 萬元，但房屋本身價值沒漲
- 否定說：§442 是租賃的特別規定，明示其一、排除其他
- 最高法院：其他原因仍可回到 **§227-2** 請求法院調整，否則太不公平

## 危險負擔（§441）：
- 可歸責於**承租人**：
  - 例：乙承租 A 屋，因乙的事由毀損，修復三個月不能住
  - 甲可依 §432 請求損害賠償；三個月租金**照付**（§441）
  - 也不能依 §435 減租（§435 要件是不可歸責於承租人）
- **不可歸責**於承租人：
  - 一部滅失 → §435；第三人主張權利 → §436；瑕疵 → §347 準用買賣
  - 單純不能使用收益 → **§441 反面解釋**，按不能使用的程度**免付租金**
  - 例：房東修漏水兩週，漏水不是承租人造成的 → 兩週租金可免付
- 出租人可不可歸責，**不影響**危險負擔，只影響出租人要不要負債務不履行責任
- 考試看到「租賃物不能使用，承租人要不要付錢」→ 先問**承租人有無可歸責事由**

## 106 年律師考題：
- 丙承租房屋經營民宿，標榜看星星看海；隔壁蓋大樓，景觀全沒了，民宿做不下去
- 房屋沒有滅失、沒有瑕疵，只是不能達使用收益目的，丙也不可歸責
- 免付租金：§441 反面解釋
- 終止契約：**類推 §435 II**（不能使用收益與一部滅失致目的不達類似）
- 法條要件有不相符 → 試著類推，這是法律解釋的方法

## 📖 法條原文速查

> **§439**　承租人應依約定日期，支付租金；無約定者，依習慣；無約定亦無習慣者，應於**租賃期滿時**支付之。如租金分期支付者，於每期屆滿時支付之。如租賃物之收益有季節者，於收益季節終了時支付之。

> **§440**
> I　承租人租金支付有遲延者，出租人得定相當期限，**催告**承租人支付租金，如承租人於其期限內不為支付，出租人得終止契約。
> II　租賃物為房屋者，遲付租金之總額，非達**二個月**之租額，不得依前項之規定，終止契約。其租金約定於每期開始時支付者，並應於遲延給付**逾二個月**時，始得終止契約。
> III　租用建築房屋之基地，遲付租金之總額，達**二年**之租額時，適用前項之規定。

> **§441**　承租人因**自己之事由**，致不能為租賃物全部或一部之使用、收益者，**不得免其支付租金之義務**。

> **§442**　租賃物為**不動產**者，因其**價值之昇降**，當事人得聲請法院增減其租金。但其租賃**定有期限者，不在此限**。

> **§227-2 I**　契約成立後，情事變更，非當時所得預料，而依其原有效果顯失公平者，當事人得聲請法院增、減其給付或變更其他原有之效果。

## 📋 實務見解速查

> **最高法院 92 年度判決（講義註 1078）**：出租人未盡保持義務時，依 §441 反面解釋，承租人於不能依約定使用收益期間，得按其不能使用之程度，免其支付租金之義務。→ 字號建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「房屋租金期初付，欠滿兩期即可終止？」 | **不行**，須遲延**逾**二個月 |
| 「租地建屋欠租多少才能終止？」 | 達**二年**租額 |
| 「定期租約可依 §442 調整租金？」 | **不行**；其他原因可回 §227-2 |
| 「因承租人事由修繕三個月，租金要付？」 | **要付**（§441） |
| 「不可歸責於承租人，修繕期間租金？」 | §441 反面解釋，**免付** |
| 「隔壁蓋大樓致民宿目的不達，可否終止？」 | **類推 §435 II** |
