# 民法27 筆記：總額性違約金與懲罰性違約金（§250）

## 違約金一定要特約：
- 法律只規定損害賠償，沒有法定違約金
- 違約金只出現在契約 → 侵權行為、不當得利不會有懲罰性違約金

## 兩次特約，位置不同：
- 第一次（**§250 I**）：約定債務不履行時要付違約金 → 有違約金
- 第二次（**§250 II 前段「除當事人另有訂定外」**）：再約定它是懲罰性 → 才是懲罰性違約金
- 只約定違約金、沒說是懲罰性 → **總額性違約金**

## 總額性違約金：
- 視為因不履行而生損害之**賠償總額**
- 違約時二選一：依違約金條款請求，或依債務不履行請求
- 但不論走哪一條，金額都**依約定**（例：約定 100 萬元，就是 100 萬元），不看實際損害多少

## §250 II 後段在講什麼：
- 先畫出債務不履行體系：
  - 給付不能 → §226
  - 給付遲延：給付仍有實益 → 請求給付＋§231 I 遲延損害；已無實益 → §232
  - 不完全給付：不能補正 → 依給付不能；能補正且有實益 → 請求補正＋§231 I；補正無實益 → §232
- 「不於適當時期」＝給付遲延、「不依適當方法」＝不完全給付，且都是**給付仍有實益**的位置
- 「債權人除得請求履行債務外」→ 違約金**不取代給付**，只取代那筆額外的損害賠償
- 結論：總額性違約金可以取代所有債務不履行的損害賠償，但**不能取代給付**；能請求給付時，給付與違約金並存

## 懲罰性違約金：
- 違約時，**實際損害的賠償**＋**另一筆懲罰性違約金**，兩者並存
- 例：實際損害 100 萬元，另約定懲罰三分之一 → 合計約 133 萬元
- 民法本來只有填補損害、沒有懲罰；要懲罰只能靠特約

## 📖 法條原文速查

> **§250**　I 當事人得**約定**債務人於債務不履行時，應支付違約金。II 違約金，**除當事人另有訂定外**，視為因不履行而生損害之**賠償總額**。其約定如債務人**不於適當時期**或**不依適當方法**履行債務時，即須支付違約金者，債權人**除得請求履行債務外**，違約金視為因不於適當時期或不依適當方法履行債務所生損害之賠償總額。

> **§231 I**　債務人遲延者，債權人得請求其賠償因遲延而生之損害。

> **§232**　遲延後之給付，於債權人無利益者，債權人得拒絕其給付，並得請求賠償因不履行而生之損害。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「契約只約定違約金，未說明性質？」 | **總額性**（§250 II 前段） |
| 「懲罰性違約金的成立？」 | 須**再特約**其為懲罰性 |
| 「總額性違約金能否與債務不履行損害賠償並請求？」 | **不能**，二選一，金額依約定 |
| 「懲罰性違約金能否與損害賠償並請求？」 | **可以並存** |
| 「遲延違約金能否與履行請求並存？」 | **可以**，§250 II 後段「除得請求履行債務外」 |
| 「侵權行為可否有懲罰性違約金？」 | **不會**，違約金以契約為前提 |

## 總額性違約金能取代什麼

```
債務不履行
├── 給付不能 ─────────────── §226 損害賠償  ← 違約金取代
├── 給付遲延
│   ├── 有實益：請求給付＋§231 I ← 違約金只取代 §231 I（§250 II 後段）
│   └── 無實益：§232           ← 違約金取代
└── 不完全給付
    ├── 不能補正：依給付不能   ← 違約金取代
    └── 能補正
        ├── 有實益：補正＋§231 I ← 違約金只取代 §231 I（§250 II 後段）
        └── 無實益：§232         ← 違約金取代
```

| | 總額性違約金 | 懲罰性違約金 |
|---|---|---|
| 成立 | 約定違約金即可 | 須再特約懲罰性 |
| 與損害賠償 | 擇一，金額依約定 | 並存 |
| 性質 | 損害賠償總額預定 | 損害賠償以外的懲罰 |
