# 民法40 筆記：抵押人事後取得土地之租賃混同與§876之特別規定性（§762§877-1）

## 案例十（老師說 103 年考過的「加油站」題，年份建議查證）
- 丙有 A 地，租給甲 → 甲在 A 地蓋 B 屋 → 甲以 **B 屋**設定抵押給乙 → 甲資金充裕，**買下 A 地**
- 乙實行抵押權，B 屋由他人拍定（字幕稱丙，以下稱丁）
- 甲（A 地所有人）能否請求丁拆屋還地？丁的坐落權源是什麼？

## 直覺解：類推 §876 → 有陷阱
- §876 要「**設定抵押權時**」土地與房屋同屬一人；本件設定時土地還是丙的，**實行時**才同屬甲 → 不能直接適用
- 但在討論類推 §876 之前，要先問：**甲的租賃權去哪了？**

## 先處理混同（類推 §762）
- 甲同時是土地所有人與土地承租人 → 債權與所有權混同，情況類似物權與所有權混同 → **類推 §762**
- 原則：自己向自己租地沒有意義 → 租賃消滅
- **但書**：其他權利的存續，對所有人或第三人有**法律上利益**者，不消滅

## 比較兩種結果，看租賃存續對甲是否有利
| 項目 | 租賃消滅 | 租賃存續 |
|---|---|---|
| 房屋坐落依據 | 類推 §876 法定地上權 | **§877-1** 屋與租賃權併付拍賣 |
| 甲能拿到什麼 | 地上權是法律送的，沒有一筆價金，只能慢慢收地租 | 租賃權併拍的**價金**歸甲 |
| 房屋 | 不拆 | 不拆 |

- 租賃存續對甲較有利 → 依 §762 但書**不消滅** → 直接適用 §877-1 併拍，不必類推 §876
- 結論：甲不得對拍定人主張 §767（謝在全教科書見解）

## 為什麼不直接用 §838-1 或 §425-1（謝在全）
- 三條結構相同：土地與房屋同屬一人 → 因處分、強制執行或抵押權實行分屬不同人 → 推定租賃或法定地上權
- 判斷時點不同：
  - §425-1：**讓與時**同屬一人
  - §838-1：**強制執行時**同屬一人
  - §876：**設定抵押權時**同屬一人
- §425-1、§838-1 只為避免拆屋還地；§876 另外保護**抵押權人設定時的預見**——設定時看到地屋同一人，才可預見將來會有法定地上權
- 所以 §876 是 §838-1、§425-1 的**特別規定**；抵押權實行的案件不能改用 §838-1、§425-1 強迫抵押權人或拍定人接受
- 同理，§877-1 限「得讓與」才併拍，也是讓抵押權人能預見

## 十個案例的總原則
- 先抓**抵押權設定時點**
- 之前存在的：原則尊重（除非像使用借貸這種不值得保護的）
- 之後發生的：不得影響抵押權

## 📖 法條原文速查

> **§762**（混同）同一物之所有權及其他物權，歸屬於一人者，其他物權因混同而消滅。但其他物權之存續，於所有人或第三人有法律上之利益者，不在此限。

> **§876、§838-1、§425-1** → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| §876 判斷同屬一人之時點 | **設定抵押權時** |
| §838-1 判斷時點 | 強制執行時 |
| §425-1 判斷時點 | 讓與時 |
| 承租人以屋抵押後買下土地，租賃是否混同消滅 | 類推 §762 **但書**，存續對甲有利 → 不消滅 |
| 之後如何處理 | §877-1 屋與租賃權併付拍賣 |
| §876 與 §838-1 之關係（謝在全） | §876 為**特別規定** |

## 解題流程

```
丙地租給甲 → 甲蓋屋 → 屋抵押給乙 → 甲買地 → 乙實行
   ↓
甲＝土地所有人＋承租人 → 類推 §762
   ├─ 租賃消滅？ → 只能類推 §876（設定時非同一人，有疑問），甲無價金
   └─ 但書：存續對甲有利 → 不消滅
          ↓
      §877-1：B 屋＋租賃權併付拍賣
          ├─ B 屋價金 → 乙優先受償
          └─ 租賃權價金 → 甲
      拍定人基於租賃坐落 → 甲不得請求拆屋還地
```
