# 民法07 筆記：§88 I 要不要「交易上重要」、「無過失」是哪一種過失——王澤鑑／林誠二／實務三說；過失＝及格標準

> 來源：民法07 課程字幕 01:11:01 ~ 01:27:16

---

## 📖 法條原文速查

> **§88 I 但書**　但以其錯誤或不知事情，**非由表意人自己之過失**者為限。
> **§88 II**　……若**交易上認為重要**者……（「重要」只出現在第二項）
> **§91**　撤銷意思表示時，表意人對於信其意思表示為有效而受損害之相對人或第三人，應負賠償責任。……
> **§114 I**　法律行為經撤銷者，視為自始無效。

> 過失的三種標準（整理）
> 抽象輕過失＝欠缺**善良管理人**之注意（跟專家比）
> 具體輕過失＝欠缺**與處理自己事務同一**之注意（跟自己比）
> 重大過失＝欠缺**一般人**之注意（跟一般人比）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§88 I 之內容錯誤、表示行為錯誤，是否須交易上重要始得撤銷？」 | 文義只有 §88 II 有「重要」。**王澤鑑：要**（類推 II，法律漏洞，保護交易安全）；**林誠二：不要**（I 沒寫，交易安全交給 §91 賠償） |
| 「§88 I 但書『無過失』之標準？」 | **王澤鑑：抽象輕過失**（最嚴，要跟專家一樣好）；**實務：具體輕過失**；**林誠二：重大過失**（最寬，跟一般人一樣就行） |
| 「丙買古董誤以為真品，專家看得出、一般人看不出，丙得否撤銷？」 | 王澤鑑（抽象輕過失）：專家看得出 → 丙有過失 → **不得**。林誠二（重大過失）：一般人看不出 → 無過失 → **得**撤銷，但依 §91 賠償 |
| 「§88 衡量的兩個價值？」 | 表意人的**意思自主（真意）** vs 相對人的**交易安全**。王偏交易安全、林偏意思自主 |

## 一、§88 的天平
```
甲撤銷 → §114 自始無效 → 甲的真意被保護 ↔ 乙信賴契約有效的交易安全被破壞
王澤鑑：往【交易安全】偏 → 要件嚴格解釋 → 能不撤就不撤
林誠二：往【意思自主】偏 → 要件寬鬆 → 要撤就撤，交易安全有 §91 賠償在後面等著
→ 這個價值取向決定了下面兩個爭點的答案
```

## 二、爭點 ①：§88 I 要不要「重要」

| | 王澤鑑 | 林誠二 |
|---|---|---|
| 文義 | 承認 I 沒寫 | I 沒寫就不用 |
| 主張 | I 漏了重要性是**法律漏洞** → **類推 II** → 內容錯誤、表示行為錯誤交易上不重要者仍不得撤銷 | 依文義只有 II 要判斷重要性 |
| 理由 | 交易安全比意思真正重要 | 讓他撤，撤完 §91 賠償就保護到交易安全了 |

## 三、爭點 ②：「無過失」是沒有哪一種過失

### 先懂「過失」怎麼判斷：考幾分 × 及格線
```
一個人有沒有過失 ＝ 他做到什麼程度（考幾分）× 法律要求的標準（及格線）
只知道考 60 分沒意義，要知道及格線是 70 還是 60
```

| 標準 | 比較對象 | 及格線（比喻） | 犯錯空間 | 誰採 |
|------|------|------|------|------|
| 抽象輕過失 | **專家**（專業、謹慎、有經驗的善良管理人） | 90 分 | 很小：專家不會犯的錯你就不能犯 | **王澤鑑** |
| 具體輕過失 | **自己**（與處理自己事務同一注意） | 60 分 | 不大：你窮盡努力仍無法避免才算無過失 | **實務** |
| 重大過失 | **一般人** | 50 分 | 大：一般人會犯的錯就算了 | **林誠二** |

- 「無過失」＝沒有那一種過失。採抽象輕過失說 → 要做到跟專家一樣好才叫無過失。
- 例：地政機關資料有誤，連代書都看不出 → 一般人看不出很正常 → 即使抽象輕過失標準也無過失。

### 古董案
```
甲有 A 古董，曾送專家乙鑑定，乙看出是假的（專家看得出）
丙誤以為是真品向甲購買，一般人肉眼看不出；甲沒有詐欺、什麼都沒說
① 古董真假＝物的性質、交易上重要 → §88 II 視為內容錯誤
② 丙無過失？
    王澤鑑（抽象輕過失）：專家看得出 → 丙沒做到專家程度 → 有過失 → 不得撤銷
    林誠二（重大過失）：一般人看不出 → 丙無過失 → 得撤銷 → 但依 §91 賠甲
```
- 林誠二對王澤鑑的批評：每個人都要做到專家程度才能撤，§88 根本變**具文**；明明有 §91 在後面，讓他撤、撤完賠償，兩邊都顧到。
- 老師：沒有對錯，是價值觀不同；要知道為什麼會有不同的解釋脈絡。
