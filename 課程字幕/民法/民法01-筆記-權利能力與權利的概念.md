# 民法01 筆記：權利能力與權利的概念（§6）

> 來源：民法01 課程字幕 00:32:57 ~ 00:45:30

---

## 📖 法條原文速查

> **§6**（自然人之權利能力）
> 人之權利能力，**始於出生，終於死亡**。

> **§184 I 前段**（一般侵權行為）
> 因故意或過失，不法侵害他人之權利者，負損害賠償責任。

> **§192 I**（侵害生命權之財產上損害賠償）
> 不法侵害他人致死者，對於支出醫療及增加生活上需要之費用或殯葬費之人，亦應負損害賠償責任。

> **§194**（侵害生命權之非財產上損害賠償）
> 不法侵害他人致死者，被害人之父、母、子、女及配偶，雖非財產上之損害，亦得請求賠償相當之金額。

> **§767 I**（物上請求權）
> 所有人對於無權占有或侵奪其所有物者，得請求返還之。對於妨害其所有權者，得請求除去之。有妨害其所有權之虞者，得請求防止之。

> **§802**（無主物先占）
> 以所有之意思，占有無主之動產者，除法令另有規定外，取得其所有權。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「出生的認定標準？」 | 通說**獨立呼吸說**：脫離母體能獨立呼吸即出生，活一秒也是權利主體 |
| 「植物人有無權利能力？」 | **有**。活著就有，與意識狀態無關 |
| 「死亡的認定？」 | 一般：**心跳停止說**；器官移植：**腦死說**。兩說非對立，適用情形不同 |
| 「甲被流浪狗咬，可否以狗為被告請求 §184？」 | **不可**。狗非權利主體，無負擔義務之資格 |
| 「遺囑遺贈愛犬 100 萬，效力？」 | **無效**。狗無權利能力，不能受遺贈 |
| 「權利能力 vs 行為能力？」 | 權利能力 = 享受權利負擔義務的**資格**（活著就有）；行為能力 = 做法律行為的資格（看年齡與宣告） |

---

## 一、權利能力 = 享受權利、負擔義務的資格

```
沒有法律的世界：你是你、石頭是石頭、狗是狗，彼此無關
    ↓ 有了法律
你撿一顆石頭 → §802 取得所有權 → 受保護
你被打 → 身體健康權受侵害 → §184 請求賠償
你被殺 → 家人依 §192、§194 請求賠償
```
→ 因為你是「人」，法律就給你這套保護力。這個資格叫**權利能力**。

> 老師的話：**民法這個遊戲是人在玩的。** 不是人，不受民法保護，也不負民法義務。

## 二、權利 = 法律之力

### 權利的內容（法律保護什麼）

```
權利
├── 非財產權
│   ├── 人格權：維護人性尊嚴、貫徹人的存在價值（生命、身體、健康、名譽……）
│   └── 身分權：人 ↔ 人的關係（親子、配偶）
└── 財產權
    ├── 債權：人 ↔ 人的請求關係
    └── 物權：人 ↔ 物的支配關係
```

### 權利的作用（怎麼實現內容）

| 作用 | 意思 | 例 |
|------|------|-----|
| **請求權** | 要求他人為一定行為 | §184 損害賠償請求權、§767 返還請求權 |
| **形成權** | 單方意思表示就改變法律關係 | 撤銷權、解除權、終止權 |
| **支配權** | 直接支配客體 | 所有權 |
| **抗辯權** | 對抗他人請求 | 時效抗辯、同時履行抗辯 |

> 作用是工具，目的是實現內容。先有這個概念就夠，各個權利的性質之後逐條講。

## 三、出生：獨立呼吸說

```
在母體內 → 胎兒（§7 另有規定）
    │
    ↓ 脫離母體 + 能獨立呼吸 ← 出生
    │
活著（不管活多久、有無意識）→ 有權利能力
```
- 只活一秒 → 那一秒是權利主體（會影響繼承！）。
- 植物人 → 活著 → 有權利能力。

## 四、死亡：兩說並用

| 情形 | 標準 |
|------|------|
| 一般 | **心跳鼓動停止說** |
| 器官移植（以人工方式維持心跳） | **腦死說** |

- 判斷死亡時點的目的：人死 → 不再是權利主體 → 財產債務依繼承處理（§1147）、身分關係消滅。要「處理後事」就要知道哪一刻死的。

## 五、「不是人」就不能玩

### 案例一：流浪狗咬人
- 甲被無主的 A 犬咬傷。甲可否以 A 犬為被告，依 §184 請求賠償？
- **不可**。A 犬非人，無權利能力，無負擔義務的資格。反過來甲咬 A 犬，A 犬也不能當原告。

### 案例二：遺贈給狗（一試考過）
- 富翁立遺囑遺贈愛犬 100 萬。
- **無效**。狗不是權利主體，無法受遺贈（受遺贈人須有權利能力）。
