# 民法36 筆記：時效取得地上權（§772）

## 依據與要件：
- 法條沒有直接規定，是 **§772 準用 §769、§770**；考試最常出現的就是這個
| 要件 | 內容 |
|---|---|
| 主觀 | 以**行使地上權之意思**（不是所有之意思） |
| 客觀 | 和平、公然、繼續占有**他人之土地** |
| 期間 | 20 年；占有之始善意並無過失 → 10 年 |
| 登記 | 土地**已登記、未登記都可以**（§772 後段「於已登記之不動產，亦同」） |
| 效果 | 得請求登記為**地上權人** |

## 地上權之意思不受推定：
- §944 只推定「所有之意思」，**沒有推定行使地上權之意思** → 主張者**自己舉證**
- 在別人地上蓋房子，可能是租賃、所有或地上權的意思，很難證明
- 實際能用到的典型情形：
  - 數十年前地主口頭或書面答應設定地上權，但沒去登記
  - 指界錯誤：設定人說整塊地都是他的，其實只有一半是他的，地上權人誤以為全部都有地上權

## 三個大法官解釋（選擇題真的喜歡考）：
| 爭點 | 解釋 | 結論 |
|---|---|---|
| 以**違建**占有可否 | **釋字 291** | **可以**；內政部要點要求合法建物證明，是增加法律所無之限制 |
| 「他人」包括**共有人**？ | **釋字 451** | **包括**；共有人可在共有土地上時效取得地上權 |
| **耕地（農地）**可否 | **釋字 408** | **不可以**；耕地不能設定地上權（只能設定農育權） |

## 四個時點：地主何時還能請求拆屋還地：
```
① 要件具備 → ② 提出申請 → ③ 地政機關受理 → ④ 完成登記
```
| 時點 | 地主依 §767 請求拆屋還地 |
|---|---|
| ① 要件具備，未申請 | **可以**：未登記就沒有地上權，是無權占有 |
| ② 已申請，未受理 | **可以**：同上 |
| ③ 已受理，未登記 | **由法院實體認定**（80 年第 2 次民事庭會議決議） |
| ④ 已登記 | **不可以**：已有地上權，物權可對抗任何人 |
- 受理：書面與佐證資料經形式審查才會受理；之後進入實質審查，可能要幾個月
- 時點③：法院認定符合要件 → 駁回地主之訴；不符合（例如無法證明地上權之意思）→ 地主勝訴

## 📖 法條原文速查

> **§772**　前五條之規定，於所有權以外財產權之取得，**準用**之。**於已登記之不動產，亦同**。

> **§769**　以所有之意思，二十年間和平、公然、繼續占有他人未登記之不動產者，得請求登記為所有人。

> **§770**　以所有之意思，十年間和平、公然、繼續占有他人未登記之不動產，而其占有之始為善意並無過失者，得請求登記為所有人。

> **§944 I**　占有人推定其為以**所有之意思**，善意、和平、公然及無過失占有。

## 📋 實務見解速查

> **釋字 291**：時效取得地上權之登記，不以占有之建物為合法建物為要件；行政命令要求檢附合法建物證明，增加法律所無之限制，違憲。

> **釋字 451**：共有人得就共有物時效取得地上權。

> **釋字 408**：耕地不得設定地上權，故占有耕地者不得主張時效取得地上權。

> **80 年第 2 次民事庭會議決議**：占有人申請時效取得地上權登記，經地政機關受理後，土地所有人訴請拆屋還地，法院應就占有人是否具備時效取得地上權之要件為實體審查。→ 要旨依課堂內容整理，建議查證原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「以違章建築占有他人土地，得時效取得地上權？」 | **得**（釋字 291） |
| 「共有人得於共有土地時效取得地上權？」 | **得**（釋字 451） |
| 「占有耕地得時效取得地上權？」 | **不得**（釋字 408） |
| 「已登記土地得時效取得地上權？」 | **得**（§772 後段） |
| 「行使地上權之意思受 §944 推定？」 | **否**，須自行舉證 |
| 「地政機關受理後、登記前，地主訴請拆屋還地？」 | 法院**實體審查**要件（80 年第 2 次民事庭會議決議） |
| 「僅具備要件尚未申請，得拒絕拆屋還地？」 | **不得**，未登記即無地上權 |
