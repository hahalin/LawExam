## 📖 法條原文速查

> **§87 I 但書**　但不得以其無效對抗善意第三人。

> **§767 I**　所有人對於無權占有或侵奪其所有物者，得請求返還之。對於妨害其所有權者，得請求除去之。有妨害其所有權之虞者，得請求防止之。
> **§118 I**　無權利人就權利標的物所為之處分，經有權利人之承認始生效力。
> **§761 I 前段**　動產物權之讓與，非將動產交付，不生效力。

> **§801**（善意受讓）動產之受讓人占有動產，而受關於占有規定之保護者，縱讓與人無讓與之權利，受讓人仍取得其所有權。
> **§948 I**　以動產所有權，或其他物權之移轉或設定為目的，而**善意**受讓該動產之占有者，縱其讓與人無讓與之權利，其占有仍受法律之保護。但受讓人明知或因**重大過失**而不知讓與人無讓與之權利者，不在此限。
> **§943 I**　占有人於占有物上行使之權利，**推定**其適法有此權利。
> **§886**　動產之受質人占有動產，而受關於占有規定之保護者，縱出質人無處分其質物之權利，受質人仍取得其質權。
> **§928 II**　債權人因侵權行為或其他不法之原因而占有動產者，不適用前項之規定。其占有之始明知或因重大過失而不知該動產非為債務人所有者，亦同。→ 反面解釋：善意無重大過失得善意取得留置權

> **§759-1**
> I 不動產物權經登記者，**推定**登記權利人適法有此權利。
> II 因信賴不動產登記之善意第三人，已依法律行為為物權變動之登記者，其變動效力，不因原登記物權之不實而受影響。

> **§92 II**　被**詐欺**而為之意思表示，其撤銷不得以之對抗善意第三人。→ 沒寫脅迫 → 脅迫之撤銷**得**對抗善意第三人

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲與乙通謀虛偽買賣 A 車並交付，乙轉賣善意丙並交付，甲得否依 §767 向丙請求返還？」 | **不得**。甲乙債權、物權行為均無效 → 乙未取得所有權；乙丙買賣有效（債權行為不以有處分權為必要）、物權行為 §118 效力未定 → 甲拒絕承認 → 丙依 **§801＋§948 善意受讓**或 **§87 I 但書**取得所有權 → 甲非所有人 |
| 「債權行為不以有處分權為必要之意義？」 | 債權行為只發生債權債務，不生物權變動；無處分權頂多**債務不履行**，契約不因此無效 |
| 「§801 為何須配 §948？」 | §801「占有受關於占有規定之保護」沒說什麼叫受保護 → **§948** 補充：依法律行為（移轉／設定）善意且無重大過失受讓占有 |
| 「繼承人得否主張善意受讓？」 | **不得**。繼承非法律行為（無移轉、設定），無交易安全保護必要 |
| 「動產所有權／質權／留置權／不動產物權之善意取得條文？」 | §801＋§948／§886＋§948／§928 II 反面解釋／**§759-1 II**（所有不動產物權一條搞定；土地法 §43） |
| 「不動產善意取得是否須無重大過失？」 | **不須**，通說單純善意即可（登記公信力較強） |
| 「丙善意但有重大過失，不能善意受讓，得否改主張 §87 I 但書？」 | **王澤鑑**：善意受讓為物權法特別規定，**優先適用** → 不得再用但書。**林誠二**：兩者**並存**由當事人自選；且 §87 I 但書只管通謀，比管所有無權處分的善意受讓更「特別」 |
| 「債權讓與之無權處分（一債二賣），第二受讓人如何受保護？」 | 債權非物，**不能善意受讓** → 只能用 **§87 I 但書**（105 年律師） |
| 「§92 II 與善意取得之衝突？」 | 脅迫之撤銷得對抗善意第三人 vs 善意受讓。王澤鑑：善意取得優先。林誠二、鄭冠宇：§92 II 優先（後述） |

## 一、基本題：A 車案的解題路徑

#### 事實
甲（A 車所有人）與乙通謀虛偽買賣並交付；乙把 A 車賣給善意的丙並交付。

#### 第一步：誰告誰、請求權基礎是什麼
```
原告一定是甲（車跑到丙那裡了）→ 甲對丙：§767 I 前段請求返還
要件 ① 甲是 A 車所有人 ② 丙無權占有 → 逐一檢驗，① 不過就不用看 ②
```

#### 第二步：用「時間順序」討論甲是否仍為所有人
```
【甲乙間】通謀虛偽 → 買賣契約、物權契約都無效（§87 I）→ 乙沒拿到所有權
【乙丙間】
    債權行為（買賣）→ 有效：債權行為不以有處分權為必要
        （買賣的目的只是讓乙丙間發生債權債務，不是讓丙取得所有權；乙給不出來 → 債務不履行，不是無效）
    物權行為（讓與合意＋交付）→ 乙無處分權 → 無權處分 → §118 效力未定
        甲承認 → 生效 → 乙丙間物權行為有效（但甲要告丙就不會承認；邏輯不能自打嘴巴）
        甲拒絕 → 不生效力 → 丙靠不了乙，靠自己：善意受讓
【丙】§801＋§948 善意受讓 → 取得 A 車所有權 → 甲非所有人 → §767 ✗
【甲→乙】不當得利 §179、侵權 §184 算帳
```
- 兩套解題法：**請求權基礎**（原告、被告、訴求、請求權基礎、要件）＋**時間順序**（故事脈絡）。王澤鑑《法律思維與案例研習——請求權基礎理論體系》（綠皮書）值得念。
- 補充：本人承認無權處分後，對無權處分人的損害賠償請求權不受影響（本人可能為商譽不得不承認）。

## 二、善意受讓制度的背景：公示與公信

```
物權是絕對權，可對抗任何人 → 要讓人看得到 → 【公示原則】
    動產：占有　　不動產：登記
但外觀不一定是真的（手上的筆可能是借的）→ 外觀只有【推定力】
    動產 §943 I　　不動產 §759-1 I
相信外觀的人要不要保護？若不保護 → 每筆交易都要追查前手是否有權 → 查證成本高 → 經濟落後
→ 民法選擇保護 → 【公信原則】：信賴外觀者，縱外觀不實仍受保護 → 善意受讓
```

## 三、§801＋§948 的要件（為什麼一定要兩條一起引）

```
§801：① 受讓人占有動產（先創造外觀）② 其占有受關於占有規定之保護 ③ 縱讓與人無讓與之權利 → 取得所有權
      「受保護」是什麼？§801 沒說 → 看 §948
§948：② 的內容 ＝ ⓐ 以所有權移轉或其他物權設定為目的 → 【法律行為】（繼承不算）
                   ⓑ 善意且無重大過失
```

| 要善意取得的是 | 條文 |
|------|------|
| 動產所有權 | §801＋§948 |
| 動產質權 | §886＋§948 |
| 動產留置權 | §928 II 反面解釋 |
| **不動產物權**（所有權、地上權、抵押權……） | **§759-1 II**（土地法 §43）；要件：善意（**不要求無重大過失**）＋依法律行為＋完成變動登記 |

## 四、丙的另一條路：§87 I 但書

```
「不得對抗」＝抗辯權的限制 → 前面一定先有主張
丙主張：甲乙的行為【有效】→ 乙是所有人 → 乙有權處分 → 丙經乙移轉取得所有權
甲乙不得以「我們是通謀無效」對抗善意的丙
```

### 兩條路並存時怎麼選：有落差才需要討論

| 情境 | §801＋§948 | §87 I 但書 | 需要討論嗎 |
|------|------|------|------|
| 丙善意且無重大過失 | ✓ | ✓ | 擇一即可，不用討論 |
| 丙善意但**有重大過失** | ✗ | ✓？ | **要討論** |
| **債權讓與**的無權處分 | ✗（債權非物） | ✓ | 只能用但書（105 律師） |
| §92 II **脅迫** | ✓？ | — | 要討論（後述） |

| | 王澤鑑 | 林誠二 |
|---|---|---|
| 關係 | 善意受讓是物權法對民總的**特別規定**，**優先適用**；§87 I 但書於債權讓與時「別具意義」 | **並存**，由當事人自選 |
| 理由 | 尊重物權法的特別秩序（德國只有善意受讓） | 誰比較「特別」？§87 I 但書**只管通謀**，善意受讓管**所有無權處分** → 但書才特別；立法時兩種模式都抄進來（小孩子才選擇），不必硬套德國 |
| 有重大過失的丙 | 不能善意受讓 → **也不能**用但書 | 可改用但書 |

- 老師：考試上兩者適用沒落差就擇一；有落差（重大過失、債權讓與、脅迫）才把爭議拿出來寫。

### §92 II 的衝突（預告）
- §92 I 詐欺、脅迫都可撤銷；§92 II 只說**詐欺**之撤銷不得對抗善意第三人 → 脅迫之撤銷**可以**對抗善意第三人 → 與善意受讓衝突。王澤鑑：善意取得優先；林誠二、鄭冠宇：§92 II 優先（脅迫的特殊性），之後再講。
