> 稱動產者，為前條所稱不動產以外之物。

> **§72**（違背公序良俗之效力）

## 📋 實務見解速查

> **最高法院 109 年度台上字第 2627 號判決**（講義 109 頁註 110）：被繼承人之屍體為物，構成遺產，為繼承人所**公同共有**；惟其所有權之內涵與其他財產權不同，僅得以屍體之埋葬、管理、祭祀等為目的，不能自由使用收益處分。屍體因殘存死者之人格權，屬**具人格性之物**，基於對人性尊嚴之尊重，其處分不得違反公序良俗；繼承人取得其所有權後，因慎終追遠之傳統禮俗而**不得拋棄**，故繼承人拋棄繼承之效力**不及於被繼承人之遺體**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「剪下之頭髮、抽出之血液，法律性質？」 | **動產**（已非人體成分、又非不動產） |
| 「以血液、頭髮為標的之買賣契約效力？」 | 學說：**有效**（可買賣），但**不得強制執行**（人性尊嚴） |
| 「與人體分離部分被侵害，得否請求慰撫金？」 | 多數：**不得**（動產→財產上損害）；少數說：有**再結合可能性**者（精液、待移植器官）視為人體延伸，得請求 |
| 「屍體之法律性質？」 | **物**（動產），但為具人格性之物，僅得以埋葬、祭祀等目的處分 |
| 「屍體歸誰？」 | 全體繼承人**公同共有** |
| 「拋棄繼承後，是否仍為遺體處分權人？」 | **是**。拋棄繼承效力不及於遺體（109 台上 2627） |
| 「四名子女中一人拋棄繼承，其餘三人中兩人決定火葬？」 | 拋棄者仍算 → 四人中兩人同意 → **未過半** → 不合法（§828 II 準用 §820） |

## 一、動產的三個爭點

```
動產（§67）：是物、不是不動產 → 動產
① 動物       → 上堂：動產；寵物慰撫金實務肯定，學說建議走 §195 I 概括條款
② 人體分離部分 → 本筆記
③ 屍體        → 本筆記
```

## 二、與人體分離之部分：動產，可買賣，不可強制執行

```
物的要件 ①「非人體之成分」
    → 剪下的指甲、頭髮、抽出的血液、取出的器官 → 已分離 → 不是人體成分
    → 不是土地或定著物 → 動產
```
- 可以買賣（賣血、賣頭髮，學說認為契約有效）。
- **不能強制執行**：答應賣 500cc 血後反悔，不能把人綁去抽——人性尊嚴。
- 被侵害 → 動產 → 只有財產上損害賠償，**無慰撫金**。

### 例外爭議：德國精液滅失案
#### 事實
丈夫為人工生殖提供精液（精子活動度差，培育多次才成功），醫院保存的精液滅失。丈夫請求慰撫金。

#### 分析
| | 多數說 | 少數說（德國） |
|---|---|---|
| 性質 | 動產 | 與人體有**再結合可能性** → 人體的延伸 → 身體健康權範疇 |
| 慰撫金 | ✗ | ✓ |
- 考試：一般分離部分 → 動產、無慰撫金；題目強調「再結合可能性」→ 帶出少數說。

## 三、屍體：具人格性的物

```
人死亡 → 屍體 → 物（動產）→ 遺產之一部 → 全體繼承人【公同共有】
但：不能自由使用收益處分 → 只能以埋葬、供奉、祭祀、研究等符合公序良俗之目的處分
```

### 案例：拋棄繼承後的火葬決定（109 台上 2627）
#### 事實
甲死亡，子女乙丙丁戊四人。乙拋棄繼承。丁戊不顧乙丙反對，決定將甲火葬。

#### 分析
```
① 屍體為全體繼承人公同共有；處分（火葬）依 §828 II 準用 §820 → 須人數過半同意
② 乙拋棄繼承 → 自始非繼承人 → 遺體處分權是否一併喪失？
    若喪失 → 丙丁戊三人，丁戊兩票 → 過半 → 合法
    若不喪失 → 乙丙丁戊四人，丁戊兩票 → 未過半 → 不合法
③ 最高法院：埋葬祭祀是子孫本於身分的責任，基於公序良俗、慎終追遠，遺體所有權【不得拋棄】
    → 拋棄繼承效力【不及於遺體】→ 乙仍是處分權人 → 四人中兩票 → 不合法
```
- 反面想：全家都拋棄繼承，遺體變無主物看誰先占？不可能 → 所以不能拋。

### 這個判決跨三個領域
| 領域 | 爭點 |
|------|------|
| 民法總則 | 遺體的性質（具人格性之物） |
| 繼承法 | 拋棄繼承的效力範圍 |
| 物權法 | 公同共有物之處分（§828 II 準用 §820 過半） |
