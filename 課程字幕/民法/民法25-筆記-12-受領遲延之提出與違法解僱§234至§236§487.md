# 民法25 筆記：受領遲延之提出與違法解僱（§234至§236、§487）

## 受領遲延的性質：
- 受領是債權人的**權利**，受領遲延必然是權利不行使，這點沒有爭議
- 是否同時構成**債務不履行**：有肯定說、否定說
- 比較確定的是**買受人**：§367 明定買受人有**受領標的物之義務** → 兼具權利不行使與債務不履行

## 為什麼要分：出賣人能不能直接解約？
- 網拍：賣家依約寄到超商，買家放一週不取件，包裹被退回
- 受領遲延的條文串（§234～§241）**沒有解除權**；解約要回到 **§254**，而 §254 是給付遲延的規定
- 實務：買受人的受領遲延同時是**給付遲延**（受領也是一種給付）→ 出賣人得依 **§254** 解除契約
  - 老師更正：講義引文誤植為「245」，應為 **254**（§245 是撤銷權除斥期間，與解約無關）
  - 講義所引判決字號未見於字幕；常見引用者為 64 台上 2367 判例，建議查證

## 要件（§234）：債務人提出＋債權人拒絕或不能受領
- **§235 本文**：須**依債務本旨**提出（字幕作「債之本質」），包括人、事、時、地、物
  - 約定在辦公室交付卻送到家裡 → 不生提出效力 → 債權人拒收**不構成**受領遲延
  - 送來有瑕疵的 A：可以拒收，不構成受領遲延；收下 → 轉為**不完全給付**問題
- 合於本旨的提出：
  - 債權人受領 → **§309** 清償，債之關係消滅
  - 債權人拒絕或不能受領 → **受領遲延**

## 現實提出與言詞提出：
- **現實提出**：依債務本旨實際提出給付
- **言詞提出**（§235 但書）：債權人**預示拒絕受領**，或給付**兼需債權人之行為** → 債務人以**準備給付之事情通知**債權人，代替提出
  - 例：打電話向書店訂書說要**自取**，書到後老闆通知「書到了」→ 發生提出效力，不去拿就是受領遲延
  - 通知形式不拘：簡訊、存證信函、口頭都可以，但債務人須已準備好

## §236 一時不能受領（法條看看就好）：
- 給付無確定期限或債務人可提前清償時，債務人突然送來，債權人一時不能受領 → 不負遲延責任
- 但由債權人催告而提出，或債務人已在相當期間前預告 → 不在此限

## §487 違法解僱（常與受領遲延合考）：
- 雇主甲違法解僱乙，乙要回去上班：訴請**確認僱傭關係存在**，並就訴訟期間（A 期間）**不補服勞務、仍請求報酬**
- 要件「僱用人**受領勞務遲延**」的操作：
  - 解僱當天就發**存證信函**，請甲指定服勞務的時間、地點與內容
  - 甲已**預示拒絕** → 乙以準備給付之事情通知 ＝ **言詞提出**
  - 甲拒絕 → 受領勞務遲延 → §487 效果發生
- 但書扣除減省費用或轉職所得（之後再講）

## 📖 法條原文速查

> **§234**　債權人對於已提出之給付，**拒絕受領或不能受領**者，自提出時起，負遲延責任。

> **§235**　債務人非依**債務本旨**實行提出給付者，不生提出之效力。但債權人**預示拒絕受領**之意思，或給付**兼需債權人之行為**者，債務人得以**準備給付之事情，通知**債權人，以代提出。

> **§236**　給付無確定期限，或債務人於清償期前得為給付者，債權人就**一時不能受領**之情事，不負遲延責任。但其提出給付，由於債權人之催告，或債務人已於相當期間前預告債權人者，不在此限。

> **§367**　買受人對於出賣人，有交付約定價金及**受領標的物之義務**。

> **§487**　僱用人受領勞務遲延者，受僱人**無補服勞務之義務，仍得請求報酬**。但受僱人因不服勞務所減省之費用，或轉向他處服勞務所取得，或故意怠於取得之利益，僱用人得由報酬額內扣除之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「買受人受領遲延，出賣人可否依 §254 解約？」 | **可以**，§367 受領為買受人義務 |
| 「未依債務本旨提出，債權人拒收？」 | **不構成**受領遲延 |
| 「言詞提出之前提？」 | 債權人**預示拒絕**或給付**兼需債權人行為** |
| 「債務人突然送達，債權人一時不能受領？」 | 不負遲延責任（§236） |
| 「違法解僱期間，受僱人可否不服勞務仍請求報酬？」 | **可以**（§487），須先使雇主受領遲延 |

## 判斷流程

```
債務人提出給付
├── 不合債務本旨 → 不生提出效力
│   ├── 債權人拒收 → 非受領遲延
│   └── 債權人收下 → 不完全給付問題
└── 合於債務本旨（現實提出／言詞提出）
    ├── 債權人受領 → §309 清償
    └── 債權人拒絕或不能受領 → 受領遲延（§234）
```
