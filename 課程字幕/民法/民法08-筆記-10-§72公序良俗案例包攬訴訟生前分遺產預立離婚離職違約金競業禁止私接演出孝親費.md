## 📖 法條原文速查

> **§72**　法律行為，有背於公共秩序或善良風俗者，無效。
> **勞動基準法 §9-1**（離職後競業禁止之要件：雇主有應受保護之正當營業利益、勞工職務能接觸或使用營業秘密、期間區域職業活動範圍及就業對象未逾合理範疇、雇主對勞工因不從事競業所受損失有合理補償；違反者無效；期間最長二年）→ 建議查閱原文
> **§1114～§1117**（扶養）受扶養權利者以不能維持生活而無謀生能力者為限（直系血親尊親屬不以無謀生能力為限）→ 建議查閱

## 📋 實務見解速查（字號請對講義）

> **最高法院 103 年台上字第 41 號**（講義 204 頁；字幕「103 年註字 41 號」）：訴訟權為人民司法上受益權，不容他人從中牟利。未取得律師資格、意圖營利，對可能涉訟之人允諾提供服務並負擔全部費用，約定勝訴後給付訴訟標的一部價額或比例為報酬 → 有違公序良俗，依 §72 無效。
> **註 140**（養父母健在時預立分產契約）：於養父母健在時預立分管合約瓜分財產，約定百年後生效；不待其父贈與或身故後協議，於生父膝下爭產、預定契約剝奪母之應繼分，「衡諸我國崇尚孝悌之善良風俗」有違 → 無效。
> **註 141**（預立離婚契約）：夫妻為恐一方日後有虐待侮辱他方情事而預立離婚契約者，與善良風俗有悖，依 §72 無效。
> **最高法院 103 年台上字第 2036 號**（註 150，牙醫兒子案）：母出資為兩名成年牙醫兒子開設診所，約定每月淨利 60% 給母，百年後財產由兄弟對分。二審：以契約強迫子女給付孝親費違反善良風俗無效。最高法院：綜觀全部情節（母出資、扣成本、不與子女同住、財產終歸子女）**不違反善良風俗**。
> 藝人私接演出違約金：最高法院認目的正當（維護整體形象規劃）、手段適當（未剝奪工作機會）→ 不悖於善良風俗。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「非律師與當事人約定代辦訴訟，勝訴後分得標的物一定比例，勝訴後請求報酬，當事人得否拒絕？」 | **得**。契約違反公序良俗（**法治國原則**：國家有義務提供經國家認證的律師）→ §72 無效 |
| 「被繼承人健在時繼承人預立遺產分割協議？」 | 判例：違反**善良風俗**（孝悌）無效。選擇題照判例；申論可討論現代觀點（有共識、經被繼承人同意、附始期） |
| 「夫妻預立離婚契約？」 | 判例：違反善良風俗無效。老師：現代離婚是自由（憲法法庭肯認），申論可質疑 |
| 「公序良俗的判斷方法？」 | **目的正當性 ＋ 手段適當性**，從個案判斷 |
| 「航空公司與機師約定離職賠償培訓費 300 萬？」 | 目的正當（確保培訓成本）、手段適當（賠的就是培訓成本）→ **不違反** |
| 「醫院與護理師約定離職賠償高額違約金？」 | 護理師幾無培訓成本，只為防人力短缺 → 可能**違反** |
| 「離職後競業禁止？」 | 目的正當（保密），手段須給**合理補償**；現已有**勞基法 §9-1**，不再用 §72 處理 |
| 「母與成年子女約定每月淨利 60% 給母？」 | 103 台上 2036：**不違反**善良風俗（二審認為違反，最高法院翻盤） |
| 「選擇題怎麼答？」 | **黏著判例**；申論題可有自己的想法 |

## 一、公共秩序 vs 善良風俗
```
§72 是私法自治、契約自由的界線：法律原則不介入，但踩到紅線就不承認效力
公共秩序：國家想創造的秩序（民主國、法治國原則……）
善良風俗：人與人相處的道德界線，隨時代浮動
判斷：行為的目的、手段、手段與目的的關聯 → 綜合判斷 → 個案認定，沒有標準答案
```

## 二、案例一：非律師包攬訴訟（公共秩序）
```
甲非律師，對乙說：我幫你處理車禍訴訟（寫狀、教你開庭怎麼講、陪調解），不先收錢，贏了分我
→ 便宜、吸引人，錯在哪？
→ 法治國原則：國家提供法律制度解決紛爭，就有義務提供經認證的法律專業人士（律師考試）
   非律師亂處理致敗訴 → 破壞人民對法治的信賴 → 違反公共秩序 → §72 無效
→ 甲勝訴後依約請求報酬 → 乙得拒絕
```

## 三、案例二、三：善良風俗會變
| 案例 | 判例 | 老師的現代觀點 |
|------|------|------|
| 父健在，子女預立遺產分割（百年後生效） | 違反孝悌之善良風俗 → 無效（判決書「很像國文老師寫的」） | 民國 46 年與 114 年的善良風俗可以不一樣；兄弟姐妹有共識、甚至經被繼承人同意、附始期 → 能事先解決糾紛，未必踩紅線 |
| 預立離婚契約（事由、財產、子女） | 違反善良風俗 → 無效 | 離婚率高、離婚是憲法保障的自由 → 事先規劃為何不行 |
| 考試 | 選擇題照判例 | 申論可從寬 |

## 四、案例四：離職違約金、競業禁止、私接演出——目的＋手段
| 約定 | 目的 | 手段 | 結論 |
|------|------|------|------|
| 機師離職賠培訓費 300 萬 | 正當：送國外受訓一兩年、吃住薪水都給，確保培訓成本 | 適當：賠的就是培訓成本 | 不違反 |
| 護理師離職賠高額違約金 | 幾無培訓成本，只為防人力短缺（那是醫院的問題） | 把不利加諸護理師 | 可能違反 |
| 離職後競業禁止（台積電三年不得從事相關行業） | 正當：保密 | 須**合理補償**才適當；高額違約金綁住、無補償 → 不適當 | 現依勞基法 §9-1 |
| 藝人禁止私接演出違約金 | 正當：人設、整體形象規劃 | 適當：未剝奪工作機會，仍介紹工作 | 最高法院：不違反 |

## 五、案例五：牙醫兒子的孝親費（103 台上 2036）
```
媽媽離婚、女強人、一手拉拔兩個牙醫兒子（已成年）
媽媽出錢讓兩人開診所（各約 1,000 萬）→ 約定每月淨利（扣成本）60% 給媽媽 → 百年後財產兄弟對分
乙結婚後太太：你媽超有錢、會謀生，法律上不能請求扶養（§1117），幹嘛給？→ 不給 → 媽媽告
二審：子女扶養父母除法定義務外出於孝心，不能用契約強迫給「孝親費」→ 違反善良風俗無效
最高法院：攤開整個故事——媽媽出資、讓扣成本、不想跟兒子同住（避婆媳問題）、財產終歸兄弟
          → 獨立自主的媽媽，哪裡違反善良風俗？→ 不違反 → 有效
```
- 老師：善良風俗題難寫，因為素材不只是法律，是你對社會、人性、當事人關係的觀察。
