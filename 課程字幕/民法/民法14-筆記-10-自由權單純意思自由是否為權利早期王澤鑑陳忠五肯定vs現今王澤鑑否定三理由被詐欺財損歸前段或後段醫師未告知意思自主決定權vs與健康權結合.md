# 民法14 筆記：自由權：單純意思自由是不是權利

## §195 I 的「自由」：
- 自由權受侵害之財產上損害得依侵權行為請求，無疑問；問題在**慰撫金**
- **第一種：身體自由**（如被拘禁）→ 通說得請求慰撫金，無爭議
- **第二種：單純意思自由**（被詐欺、被脅迫，未與其他權利結合）→ 有爭議

## 兩說：
- **肯定說**（講義稱通說：王澤鑑舊說、陳聰富；老師另舉陳忠五）：單純意思自由亦為自由權 → §184 I 前段，財損為其所受損害
- **否定說**（王澤鑑新說，月旦 318 期）：①比較法上多指身體自由 ②詐欺已有 **§92** 撤銷＋不當得利處理 ③過失侵害即負責對行為自由限制過重 ④被詐欺本可依 §184 I 後段求償

## 否定說下要與其他權益結合：
- 被詐欺財損 → 純粹經濟損失 → §184 I 後段
- 醫師未充分告知致手術後遺症：肯定說以**意思自主決定權**走前段；否定說與**健康權**結合走前段
- 最高法院對「以詐術使投資數百萬」兩說並存

> 來源：民法14 課程字幕 01:56:01 ~ 02:09:30（講義 67 頁；休息前 01:55:20～01:56:01 之「第一種：身體自由」內容字幕缺漏，已依講義 67 頁補）

## 📖 法條原文速查

> **民法 §92 I**　因被詐欺或被脅迫而為意思表示者，表意人得撤銷其意思表示。但詐欺係由第三人所為者，以相對人明知其事實或可得而知者為限，始得撤銷之。
> **民法 §195 I**　不法侵害他人之身體、健康、名譽、**自由**、信用、隱私、貞操……
> **民法 §184 I 後段**　故意以背於善良風俗之方法，加損害於他人者亦同。

## 📋 實務見解速查

> 講義 67 頁註 121（王澤鑑新文引述）：甲以詐術使乙投資數百萬元或將房屋賤賣——最高法院有認屬**財產損失、純粹經濟損失**，被害人僅得依 §184 I 後段或 II 求償者；亦有認構成對**意思決定自由權**之侵害，得依 §184 I 前段求償者。→ 最高法院自己也有不同看法。
> 遷葬案（筆記 12）：實務採肯定說，承認遷葬自由決定權為權利。
> wrongful birth（筆記 11）：實務承認生育自主決定權。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲被乙詐欺而受財產損失，依 §184 I 前段或後段？」 | 爭點＝**意思自由是不是權利**。肯定說：意思（決定）自由權受侵害 → **前段**，財損是其所受損害／所失利益。否定說：意思自由非權利 → 無權利受侵害 → 財損是純粹經濟損失 → **後段**（詐欺＝故意背俗，仍可求償） |
| 「自由權受侵害，財產上損害 vs 慰撫金？」 | 財產上損害依侵權行為請求無疑問；慰撫金要問 §195 I「自由」所指：**身體自由**（被拘禁）→ 通說可；**單純意思自由** → 有爭議 |
| 「被持刀控制但無財損，得否請求慰撫金？」 | 肯定說（講義稱通說：王澤鑑舊說、陳聰富；老師另舉陳忠五）：單純意思自由被侵害亦為自由權受侵害 → §195 慰撫金可。否定說（王澤鑑新說）：須同時構成其他權利（貞操權、身體自由等）之侵害始可 |
| 「王澤鑑否定說三理由？」 | ①比較法：侵權法保護之自由指**身體自由** ②詐欺已有 **§92** 撤銷＋不當得利回復，意思自由已有保護機制，不必權利化再丟給侵權法（各法律有其制度目的） ③過失侵害意思決定自由即負責（過失提供錯誤資訊致對方誤判）→ **行為自由限制過重**；且被詐欺本可依 §184 I 後段求償 → 無創設意思自由權之必要 |
| 「告知後同意法則（informed consent）？」 | 講義 67 頁：醫師於得病人同意後進行手術，若發生醫療之**固有風險**（非醫療疏失所生）→ 得以病人同意作為**阻卻違法事由**；未經病人（充分告知後之）同意即進行 → 無阻卻違法（講義 68 頁續，本堂未講） |
| 「醫師未據實充分說明，病人同意手術後生後遺症，權利為何？」 | 肯定說：**意思自主決定權**受侵害 → 前段；後遺症損失為延伸損害。否定說：意思自由須與其他權利結合 → 後遺症＝**健康權**受侵害 → 以健康權走前段 |
| 「否定說的結論是不能救濟？」 | **不是**。否定說只是不承認「單純意思自由」為權利；須與**其他權益**結合——財產損失 → PEL → §184 I 後段；身體後遺症 → 健康權 → 前段；遺體被火化 → 遺族追思權（筆記 12） |
| 「兩說實益？」 | **過失**侵害意思自由：肯定說要賠（前段過失即可）；否定說不賠（後段須故意；無其他權益可結合即無救濟）。老師較認同王澤鑑 |

## 一、體系圖

```
自由權受侵害
├ 財產上損害 → 侵權行為請求，無疑問
└ 慰撫金（§195 I「自由」）
   ├ 第一種：身體自由（被拘禁）→ 通說 ✓
   └ 第二種：單純意思自由 ↓
意思自由被侵害
├ 肯定說（講義稱通說：王澤鑑舊說、陳聰富；陳忠五）：意思自由＝自由權 → §184 I 前段
│     財損＝所受損害／所失利益；無財損亦得請求慰撫金
└ 否定說（現今王澤鑑）：不是權利 → 須與其他權益結合
      ├ 結合財產損失 → 純粹經濟損失 → §184 I 後段（故意）
      ├ 結合健康權（手術後遺症）→ §184 I 前段
      └ 結合遺族追思權（遷葬案）→ §195 其他人格法益
```

## 二、「早年王澤鑑 vs 現在王澤鑑」

| | 早年 | 現在（講義 67 頁註 121） |
|---|---|---|
| 單純意思自由 | 是自由權，可請求慰撫金 | 不是權利 |
| 被詐欺財損 | 前段 | 純粹經濟損失，後段 |
