# 民法19 筆記：無識別能力人與未成年人之與有過失

## 無識別能力之被害人：
- 例：乙 3 歲，在路上玩球沒看車，被甲撞傷；乙依 §184 求償，甲能否主張 §217？
- 王澤鑑早年：類推 §217；與有過失在合理分配風險，乙雖無過失，但**自己製造風險**
- 通說（王澤鑑後改採）：**無 §217 適用**；過失是「能注意而不注意」，無識別能力人沒有注意能力 → 無過失 → 無與有過失，文義不該當
- 但甲負全部責任也不公平 → **類推 §187 III**，由法院斟酌雙方經濟狀況調整
- §187 III 的精神：有損害卻依法沒人負責時，給法院介入衡平的管道

## 無過失責任也有 §217：
- 例：8 歲甲把學校沒固定好的足球門當單槓玩，球門倒下致甲骨折；甲依國賠法向學校 A 請求
- A 負**無過失責任**，仍有 §217 適用：「與有過失」只要求**被害人**有過失，不以加害人有過失為要件

## 未成年人識別能力的判斷（陳忠五）：
- 識別能力是個案主觀判斷，不像行為能力看年齡（8 歲依 §13 為限制行為能力人）
- 未成年人是**加害人** → 識別能力**從寬**認定（保護被害人）
- 未成年人是**被害人** → 保護被害人與保護未成年人兩目的一致 → **從嚴**認定，避免輕易減少賠償
- 足球門案：實務以同齡同學都知道不能這樣玩、學校有宣導 → 甲有識別能力 → 賠償打**六折**（兩三百萬變一百多萬）；陳忠五質疑此結果

> 來源：民法19 課程字幕 01:12:40 ~ 01:26:30；足球門案老師說甲主張「國賠法第二條」，但公有公共設施設置管理欠缺之無過失責任規定於國賠法 §3，建議查證

## 📖 法條原文速查

> **§217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

> **§187 III**　如不能依前二項規定受損害賠償時，法院因被害人之聲請，得斟酌行為人及其法定代理人與被害人之**經濟狀況**，令行為人或其法定代理人為全部或一部之損害賠償。

> **國賠法 §3 I**（要旨）　公共設施因設置或管理有欠缺，致人民生命、身體、人身自由或財產受損害者，國家應負損害賠償責任。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「無識別能力之被害人得否適用 §217？」 | 通說：**否**，無過失即無與有過失；改類推 **§187 III** |
| 「加害人負無過失責任時，有無 §217 之適用？」 | **有**，只須被害人有過失 |
| 「8 歲兒童必定無識別能力？」 | **否**，識別能力個案判斷，與行為能力不同 |
| 「未成年人為被害人時，識別能力宜如何認定？」 | 陳忠五：**從嚴**（為加害人時從寬） |

## 一、無識別能力被害人的處理

```
乙（3 歲，無識別能力）被甲撞傷
├─ 王澤鑑早年：類推 §217（自己製造風險）
└─ 通說／王澤鑑後說
    ├─ §217 ✗：不能注意 → 無過失
    └─ 類推 §187 III：法院斟酌經濟狀況衡平
```

## 二、識別能力認定的雙重標準

| 未成年人的角色 | 衝突的保護目的 | 識別能力 |
|---|---|---|
| 加害人 | 保護被害人 vs 保護未成年人 | 從寬（易負責） |
| 被害人 | 兩者一致 | 從嚴（不易被減賠） |

## 三、足球門案

| 爭點 | 結論 |
|---|---|
| 學校負無過失責任，有無 §217 | 有 |
| 甲（8 歲）有無識別能力 | 實務：有（同學都知道）→ 打六折 |
| 陳忠五 | 被害人應從嚴認定，質疑打折結果 |
