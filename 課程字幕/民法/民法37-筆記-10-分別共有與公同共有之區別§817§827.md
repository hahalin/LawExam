# 民法37 筆記：分別共有與公同共有之區別（§817、§827）

## 共有的重要性：
- 物權考試三大重點：**通則**（§758、§759、善意取得、違章建築）、**共有**、**抵押權**

## 共有的條文體系（§817～§831）：
```
共有
├── 分別共有：§817～§826-1
│     ├── 定義：§817
│     ├── 積極權能
│     │     ├── 使用收益：§818
│     │     ├── 處分：§819（筆記-11、12）
│     │     └── 管理：§820
│     ├── 消極權能（排除侵害）：§821
│     ├── 費用分擔：§822（自己看條文）
│     ├── 分割：§823～§824-1（§825 擔保責任、§826 證書保管看過即可）
│     └── 協議對受讓人之效力：§826-1
├── 公同共有：§827～§830
└── 準共有：§831（所有權以外之財產權）
      └── 例：繼承人公同共有債權 → 104 年第 3 次民事庭會議決議（之後介紹）
```
- 字幕的「共同共有」「共同關係」為語音辨識或口語，條文用語是**公同共有**、**公同關係**

## 分別共有（§817）：
- 數人**按應有部分**對一物有所有權
- 只有**一個所有權**，切成幾份，不是三個所有權
- 數字例：甲乙丙共有 A 地，應有部分各 1/3
  - 應有部分**抽象**存在於共有物的**每一點**上
  - 不是「左邊 1/3 是甲的」，而是每一點上都有甲的 1/3
- 應有部分是自己的：三人吵翻了，甲的 1/3 還是甲的，可以帶走

## 公同共有（§827）：
- 依法律規定、習慣或法律行為成立**公同關係**的數人，基於公同關係而共有一物
- 共有人是跟**公同關係**連結，再透過公同關係共有物；**沒有應有部分**的概念
- 加入公同關係 → 成為共有人；離開 → 什麼都沒有
- 典型例：
  - **合夥**：退夥後與合夥財產無關
  - **祭祀公業**：派下員才有份；女性派下員出嫁後是否喪失派下權，有大法官解釋處理（老師未記字號，應為釋字 728，建議查證）
  - **繼承人**：甲乙丙三人公同共有遺產，應繼分各 1/3；丙拋棄繼承就離開公同關係，1/3 不能帶走，遺產由甲乙兩人共有

## 比較：
| | 分別共有 | 公同共有 |
|---|---|---|
| 成立 | 按應有部分 | 基於公同關係 |
| 應有部分 | 有，抽象存在於每一點 | 無（潛在的份額） |
| 與物的連結 | 共有人直接連結物 | 透過公同關係連結 |
| 離開 | 應有部分帶走 | 離開公同關係即無權利 |
| 例 | 三人合買一塊地 | 合夥、祭祀公業、共同繼承 |

## 使用收益（§818）：
- 各共有人除契約另有約定外，按應有部分對共有物**全部**有使用收益之權
- 使用收益的**方法**屬於**管理**問題，回到 §820 處理

## 📖 法條原文速查

> **§817**
> I　數人**按其應有部分**，對於一物有所有權者，為共有人。
> II　各共有人之應有部分不明者，**推定其為均等**。

> **§818**　各共有人，除契約另有約定外，按其應有部分，對於共有物之**全部**，有使用收益之權。

> **§827**
> I　依法律規定、習慣或法律行為，成一**公同關係**之數人，基於其公同關係，而共有一物者，為公同共有人。
> II　前項依法律行為成立之公同關係，以有法律規定或習慣者為限。
> III　各公同共有人之權利，及於公同共有物之全部。

> **§831**（準共有）→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「分別共有人之應有部分存在於共有物之特定部分？」 | **錯**，抽象存在於每一點上 |
| 「應有部分不明者？」 | **推定均等**（§817 II） |
| 「共有人得就共有物全部使用收益？」 | **得**，按應有部分（§818） |
| 「公同共有人有無應有部分？」 | **無**，權利及於公同共有物之全部 |
| 「繼承人拋棄繼承後，應繼分如何？」 | 離開公同關係，由其他繼承人共有 |
| 「債權得否公同共有？」 | 得，§831 準共有 |
