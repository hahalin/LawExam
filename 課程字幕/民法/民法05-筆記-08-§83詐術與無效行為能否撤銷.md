# 民法05 筆記：§83 詐術與「無效的法律行為能否撤銷」

> 來源：民法05 課程字幕 01:24:28 ~ 01:34:17

---

## 📖 法條原文速查

> **§83**（限制行為能力人之詐術）
> 限制行為能力人用詐術使人信其為**有行為能力人**或**已得法定代理人之允許**者，其法律行為為有效。
> → 「有效」＝不受行為能力影響；詐術**僅限**這兩種

> **§92 I**（詐欺脅迫之撤銷）
> 因被詐欺或被脅迫而為意思表示者，表意人得撤銷其意思表示。……

> **§114 I**（撤銷之效力）
> 法律行為經撤銷者，視為自始無效。

> **§82 但書**（對照：撤回權的善意要件）
> ……但訂立契約時，知其未得有允許者，不在此限。→ 老師上課一度把善意要件講到 §83，隨即更正：善意要件在 §82

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「17 歲甲持 20 歲兄之身分證向乙購買機車？」 | 詐術使人信其有行為能力 → **§83 不受行為能力影響** |
| 「甲偽造父母同意書並盜蓋印章？」 | 詐術使人信已得允許 → **§83** |
| 「限制行為能力人甲以詐術使乙相信盜版包為真品，有無 §83 適用？」 | **無**。§83 的詐術限於行為能力／允許的詐欺；標的詐欺走 **§92** 撤銷（陳聰富） |
| 「§83 之『有效』意義？」 | 不是真的一定有效，是**不受行為能力影響** |
| 「法代拒絕承認致契約不生效力後，被詐欺之乙仍得撤銷？」 | 最高法院：**不能**（已無效無從撤銷）；王澤鑑：**能**但**無實益**（法律行為多面向，各面向分別觀察） |

---

## 一、§83 的範圍：只騙兩件事

```
§83 的詐術 ＝ 騙你「我成年了」或「我爸媽同意了」
    例：17 歲弟拿 20 歲哥的身分證買機車；手寫同意書偷蓋父母印章
    → 法律行為不受行為能力影響（不是保證有效）

不是 §83 的詐術 ＝ 騙你標的物是真的、品質是好的
    例：限制行為能力人賣盜版名牌包，騙乙是真品
    → 這是 §92 詐欺 → 乙撤銷意思表示即可（陳聰富）→ 與 §83 無關
```

## 二、衍生爭點：無效的法律行為還能撤銷嗎

#### 事實
限制行為能力人甲賣盜版包給乙，騙乙是真品。無 §83 適用 → 買賣契約 §79 效力未定 → 法代拒絕承認 → 不生效力。乙被詐欺，還能依 §92 撤銷嗎？

#### 兩說

| | 最高法院 | 王澤鑑 |
|---|---|---|
| 結論 | **不能撤銷** | **能撤銷，但無實益** |
| 理由 | 撤銷的目的是使法律行為無效（§114）；已經無效的行為無從再使之無效。「你不能殺一個死人」 | 問題分兩層：能不能／有沒有實益。法律行為不像人只有一條命，它有**多個面向**（行為能力、意思表示、標的），每個面向各有瑕疵與對應效力 |
| 例 | — | 脅迫無行為能力人賣毒：行為能力面 §75 無效、標的面 §71 無效、意思表示面 §92 得撤銷——同一行為三種評價並存 |

```
王澤鑑：從行為能力的角度它無效，轉個角度它是被詐欺的法律行為，仍可撤銷
    → 不能說「不能撤」，只能說「撤銷無實益」
    → 例外有撤銷實益的情形 → 講到得撤銷的法律行為時再談
```
