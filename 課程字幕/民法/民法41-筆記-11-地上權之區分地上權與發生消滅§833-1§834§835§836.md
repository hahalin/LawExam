# 民法41 筆記：地上權之區分地上權與發生消滅（§833-1§834§835§836）

## 區分地上權（§841-1 以下）：
- 土地所有權及於土地上下（§773）→ 可以**分層**設定地上權
- 例：丙的 A 地，地下 0～10 公尺給甲、地上 0～10 公尺給乙、10～15 公尺再給另一人走管線
- **§841-2**：區分地上權人可與土地上下有使用收益權的人約定相互限制；約定**未經土地所有人同意**者，使用收益權消滅時，所有人不受拘束；約定須**登記**才能對抗第三人
- **§841-3**：法院定區分地上權期間足以影響第三人權利時，應併斟酌第三人利益
- 立法理由（選擇題考過，課本 233 頁註釋）：後設定的區分地上權若經**先存在的物權人同意**而設定，後物權得優先於先物權行使，先物權人應受限制

## 普通地上權的發生：
- **意定**：設定是法律行為，須**登記**（§758）
- **法定**：§876（設定抵押時土地房屋同一人所有，拍賣後分屬不同人）、§838-1（強制執行致土地房屋分屬不同人）
- 兩者都為避免拆屋還地；§876 另有保護抵押權人目的 → 有抵押權時**優先適用 §876**（謝在全）

## 消滅原因一：存續期間：
- 地上權期限**沒有上限**，50 年、99 年、100 年都可以
- **§833-1**：未定期限，存續**逾 20 年**或成立目的已不存在 → 法院得依請求，斟酌目的、建物種類性質與利用狀況，**定存續期間或終止**
- **§833-2**：以公共建設為目的、未定期限 → 建設使用目的完畢時視為存續期限

## 消滅原因二：拋棄（§834、§835，選擇題考過）：

| 情形 | 拋棄條件 |
|---|---|
| **無償** | 隨時拋棄（§834） |
| 有償＋**定期** | 支付未到期 **3 年分**地租 |
| 有償＋**未定期** | **1 年前通知**，或支付未到期 **1 年分**地租 |
| 不可歸責於地上權人致不能達原使用目的 | 前兩項地租 **1/2**（打五折） |
| 可歸責於土地所有人 | **免付**地租 |

- 例：地層下陷蓋不了房 → 打五折；若是地主超抽地下水造成 → 免付

## 消滅原因三：終止（與義務連動）：
- 地租相關：
  - §835-1：土地價值昇降致原地租顯失公平 → 請求法院增減
  - **§836 I**：積欠地租達 **2 年**總額 → 定期催告，逾期不付得終止
  - **§836 II**：地租約定**經登記**者，地上權讓與時前手積欠地租併同計算，受讓人與讓與人**連帶**負責（未登記就不用承受）
  - **§836 III**：終止以**意思表示**向地上權人為之即生效，之後再請求塗銷
- 使用相關：§836-2 依設定目的及約定方法使用（約定方法非經登記不得對抗第三人）；§836-3 違反經阻止仍繼續 → 得終止
- **§837**：縱因**不可抗力**妨礙使用，也**不得請求免除或減少地租** ← 與租賃 §435 相反
- §838：地上權可讓與，但須與建物一併；禁止讓與的特約須登記才能對抗第三人
- 消滅效果：§839（工作物取回）、§840（建物補償、延長期間），有印象即可

## 消滅原因四：建築物滅失：
- **意定**地上權：不因建物滅失而消滅（§841）
- **法定**地上權：因建物滅失而消滅（§838-1 II）

## 📖 法條原文速查

> **§834** 地上權無支付地租之約定者，地上權人得隨時拋棄其權利。

> **§835** I 地上權定有期限，而有支付地租之約定者，地上權人得支付未到期之三年分地租後，拋棄其權利。
> II 地上權未定有期限，而有支付地租之約定者，地上權人拋棄權利時，應於一年前通知土地所有人，或支付未到期之一年分地租。
> III 因不可歸責於地上權人之事由，致土地不能達原來使用之目的時，地上權人於支付前二項地租二分之一後，得拋棄其權利；其因可歸責於土地所有人之事由，致土地不能達原來使用之目的時，地上權人亦得拋棄其權利，並免支付地租。

> **§837** 地上權人，縱因不可抗力，妨礙其土地之使用，不得請求免除或減少租金。

> **§833-1、§836、§841-2** → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「地上權期限上限？」 | **無**上限 |
| 「未定期限地上權逾 20 年？」 | 法院得定期間或終止（§833-1） |
| 「有償定期地上權拋棄？」 | 付 3 年分地租；未定期 1 年 |
| 「積欠地租多久得終止？」 | **2 年**總額＋催告 |
| 「受讓人要否承受前手欠租？」 | 地租約定**經登記**才要，且連帶 |
| 「不可抗力妨礙使用，可否減租？」 | **不可**（§837），租賃則可（§435） |
| 「建物滅失地上權消滅？」 | 意定否（§841）、法定是（§838-1 II） |
| 「法定地上權競合？」 | 有抵押權時優先適用 §876 |

## 地上權 vs 租賃

| | 地上權 | 租賃 |
|---|---|---|
| 不可抗力不能使用 | 不得減免地租（§837） | 不可歸責承租人得減租（§435） |
| 欠租終止 | 2 年總額＋催告（§836） | 依 §440 |
| 讓與 | 可，建物一併（§838） | 原則不得轉租（§443） |
