# 民法二試03 筆記：承租人無益裝修費用之賠償（§227）

## 案例（詹森林文章，講義 145～146 頁）：
- 甲向乙承租 A 建物 5 年，作高爾夫球培訓場；A 是違建，乙訂約時謊稱合法
- 甲花了兩三百萬裝修；A 屋後來被政府拆除，乙詐欺罪確定
- 甲不想主張履行利益（5 年營業利潤，難證明），只想拿回裝修費 → 請求權基礎怎麼寫？

## 實務（112 台上 2911，註 250）：
- 乙違反 §423 租賃物保持義務＋未盡告知之附隨義務 → 不完全給付
- 裝修支出＝甲之**固有利益**受損 → **加害給付**，依 §227 II 請求

## 詹森林：
- 裝修已因**附合**（§811）成為乙屋之重要成分，所有權屬乙；拆除侵害的是乙的所有權，甲沒有具體固有利益受侵害 → **不是加害給付**
- 定性為**徒勞無益費用**：為履約或為獲取契約利益而支出、因契約無法履行而落空的成本（德國法 §284 有明文，我國無）
- 請求權基礎：**§227 I 準用 §226**（已不能補正）；效果**類推 §213 III**，以金錢回復到「如同未締約」的狀態

## 📖 法條原文速查

> **民法 §227**　I 因可歸責於債務人之事由，致為不完全給付者，債權人得依關於**給付遲延或給付不能**之規定行使其權利。II 因不完全給付而生前項以外之損害者，債權人並得請求賠償。
> **民法 §423**　出租人應以合於所約定使用收益之租賃物，交付承租人，並應於租賃關係存續中，**保持**其合於約定使用、收益之狀態。
> **民法 §811**　動產因附合而為不動產之重要成分者，不動產所有人，取得動產所有權。
> **民法 §213 III**　債權人得請求支付回復原狀所必要之費用，以代回復原狀。（原文請對六法）

---

## 📋 實務見解速查

> **最高法院 112 年度台上字第 2911 號判決**（講義註 250，要旨）：出租人之租賃物保持義務於租期內繼續存在；出租人明知增建屋為違建仍表示合法，未盡告知保護等附隨義務，致承租人出資裝修而該屋遭拆除，裝修支出屬加害給付所生損害，承租人得依不完全給付規定請求賠償。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「承租人得否請求裝修費用？依據？」 | 先認定乙違反 §423 保持義務、可歸責 → 不完全給付（§227） |
| 「實務怎麼定性？」 | 裝修費＝固有利益 → 加害給付，§227 II |
| 「詹森林反對理由？」 | 裝修已附合於乙屋（§811），所有權屬乙，甲無固有利益受侵害 |
| 「那甲依什麼請求？」 | 徒勞無益費用：§227 I 準用 §226（不能補正）＋類推 §213 III，以金錢回復未締約狀態 |
| 「§227 I 為何要搭 §226？」 | §227 I 本身沒有完整效果，須看能否補正決定準用給付不能或給付遲延 |

## 一、§227 I 的效果分流

```
§227 I 不完全給付（瑕疵給付）
│
├── 不能補正 → 準用給付不能 → §226（本件：房子已拆）
│
└── 能補正
    ├── 補正有實益 → 請求補正 ＋ 遲延損害 §231 I
    └── 補正無實益 → §232 拒絕補正，請求不履行之損害
```

## 二、三種利益比較

| | 履行利益 | 固有利益 | 徒勞無益費用（信賴型） |
|---|---|---|---|
| 意義 | 契約如期履行可得之利益 | 履約前原本就有的權益 | 為履約支出、因不履行而落空的成本 |
| 本件數字 | 5 年營業淨利（難證明） | 實務：裝修費 | 詹森林：裝修費 200～300 萬 |
| 依據 | §227 I | §227 II | §227 I＋§226，類推 §213 III |

- 詹森林的回復方向是「如同沒有締約」，所以不是真正回復原狀，只能**類推** §213 III。
