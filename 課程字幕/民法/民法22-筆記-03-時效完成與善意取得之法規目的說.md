# 民法22 筆記：時效完成與善意取得之法規目的說

## 法規目的說：
- 適用於**基於法律規定**而發生的非給付型不當得利
- 問題不是利益歸屬於誰，而是：該規定的目的是否要讓受領人**終局保有**利益
- 有此目的 → 該規定本身就是法律上原因 → 不成立不當得利；沒有 → 仍構成不當得利

## 時效完成：打人後不用賠（司法特考考過）
- 甲毆打乙致傷，兩年後侵權損害賠償請求權罹於時效（§197 I），乙改依 §179 向甲請求
- 甲受有利益：**免賠償的利益**（可拒絕給付）
- 這個利益不是乙給的，也沒有債務免除 → 用法規目的說
- 時效制度目的在**維護法安定性** → 有讓甲終局保有的意思 → 時效可作為法律上原因 → **不成立**不當得利
- 否則時效抗辯毫無意義：§184 罹於時效就改打 §179，永無結束之日

## 不是 §197 II 的問題：
- §197 II 要件是「**因侵權行為受利益**」
- 毆打沒有讓甲得到財產利益 → 不適用 §197 II
- 搶劫才有：侵權罹於時效後，被害人仍得依不當得利要回被搶的錢

## 善意取得：
- 甲把 A 車借給乙，乙無權處分給善意的丙，丙善意取得
- 甲不能對丙主張 §767，民總通常就停在這裡；那 §179 呢？
- 丙受有 A 車所有權的利益，但善意取得制度目的在**保護交易安全** → 必須讓丙終局保有 → 法律上原因 → 甲對丙**不成立**不當得利
- 甲只能轉向乙主張其他權利

> 來源：民法22 課程字幕 00:25:26 ~ 00:34:00（講義 320 頁）

## 📖 法條原文速查

> **§197**　I 因侵權行為所生之損害賠償請求權，自請求權人知有損害及賠償義務人時起，**二年**間不行使而消滅，自有侵權行為時起，逾**十年**者亦同。II 損害賠償之義務人，**因侵權行為受利益**，致被害人受損害者，於前項時效完成後，仍應依關於不當得利之規定，返還其所受之利益於被害人。

> **§948 I**　以動產所有權，或其他物權之移轉或設定為目的，而善意受讓該動產之占有者，縱其讓與人無讓與之權利，其占有仍受法律之保護。但受讓人明知或因重大過失而不知讓與人無讓與之權利者，不在此限。

> **§801**　動產之受讓人占有動產，而受關於占有規定之保護者，縱讓與人無移轉所有權之權利，受讓人仍取得其所有權。

## 📋 實務見解速查

> **51 台上 2881**（講義 320 頁）：因時效而免負義務，雖得認為受利益，但法律規定時效制度，其目的即在使受益人取得其利益，故除另有不當得利請求權與之競合外，不能謂無法律上之原因而受利益。本件上訴人受被上訴人毆傷，僅有侵權行為，並無不當得利與之競合，侵權行為損害賠償請求權罹於時效後，即無行使不當得利請求權可言。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「毆打致傷之侵權賠償罹於時效，被害人得依 §179 請求？」 | **否**，時效制度是法律上原因（51 台上 2881） |
| 「上題得適用 §197 II？」 | **否**，毆打未因侵權行為受利益 |
| 「搶劫之侵權賠償罹於時效，被害人得依不當得利請求？」 | **得**（§197 II） |
| 「動產遭善意取得，原所有人得對受讓人依 §179 請求？」 | **否**，善意取得保護交易安全，為法律上原因 |
| 「基於法律規定之非給付型不當得利，判準？」 | **法規目的說**：是否讓受領人終局保有 |

## 一、法規目的說的操作

```
某法律規定使財產變動
        ↓
該規定目的是否讓受領人「終局保有」利益？
├─ 是 → 法律上原因 → 不成立 §179
│        例：時效（法安定性）、善意取得（交易安全）
└─ 否 → 無法律上原因 → 成立 §179
         例：添附（維護物的經濟價值，見民法22-筆記-04）
```

## 二、時效案的兩條路

| | 毆打 | 搶劫 |
|---|---|---|
| 加害人受利益 | 免賠償的利益 | 搶得的財物 |
| §197 II | 不適用 | 適用 |
| §179 | 時效制度為法律上原因 → 不成立 | 與侵權競合 → 得請求 |
