# 民法11 筆記：無權處分與繼承——① 本人死亡、無權處分人為繼承人（兒子賣爸爸的畫）：§118 II 直接適用，處分自始有效，惡意丙亦取得；② 無權處分人死亡、本人為繼承人（爸爸賣兒子的畫）：早年實務（民國 20 幾年判例）以「有處分權人繼承債務」類推 §118 II 自始有效——概括繼承時代合理；98 年修法後概括繼承有限責任（§1148 II），林秀雄：不應再類推，否則剝奪有限責任抗辯、對其他債權人不公，改看本人承認與否，拒絕則乙給付不能，§226 賠償責任由本人在遺產範圍內負擔

## 📖 法條原文速查

> **§118 II**　無權利人就權利標的物為處分後，取得其權利者，其處分自始有效。……
> **§1148**　I 繼承人自繼承開始時，除本法另有規定外，承受被繼承人財產上之一切權利、義務。……
> II 繼承人對於被繼承人之債務，以因繼承所得遺產為限，負清償責任。（98 年修法：概括繼承有限責任）
> **§226 I**　因可歸責於債務人之事由，致給付不能者，債權人得請求賠償損害。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「乙無權處分甲之 A 畫予惡意丙，甲死亡、乙為唯一繼承人，A 畫歸誰？」 | **丙**。乙依 §1148 取得 A 所有權 → 無權利人事後取得權利 → **§118 II 直接適用**，處分自始有效 → 丙雖惡意亦取得。沒有爭議（參民法09 筆記 10） |
| 「反過來：賭徒父乙無權處分藝術家子甲之 A 畫予惡意丙，乙死亡、甲為唯一繼承人。甲要履約嗎？」 | 甲繼承乙丙間買賣契約（債務）。**早年實務**：「有處分權人繼承債務」與「無處分權人取得權利」相似 → **類推 §118 II** 處分自始有效 → 丙取得。**林秀雄（98 年修法後）**：**不應類推**。看甲要不要承認：承認＝願以自己財產清償乙的債務，丙取得；拒絕 → 乙給付不能 → 丙對乙之 §226 賠償債權由甲繼承，甲只在**所得遺產範圍內**（§1148 II）負責 |
| 「為何修法後不再類推？」 | ① **剝奪甲的有限責任抗辯**：乙遺產若為零，甲本不須清償任何債務，類推 §118 II 等於強迫甲拿自己的畫還債 ② **對其他債權人不公**：乙財產 100 萬、債務 1000 萬，各債權人只能按比例分到十分之一，丙卻因此 100% 滿足 |
| 「早年判例為何沒錯？」 | 98 年前繼承三軌制：概括繼承、限定繼承、拋棄繼承；未主張限定或拋棄即概括繼承、概括承受一切債務 → 本來就要還，類推 §118 II 讓丙取得以清償，符合當時精神 |

## 一、兩種類型（圖一樣，狀況相反）

| | 類型一：本人死亡 | 類型二：無權處分人死亡 |
|---|---|---|
| 考題外觀 | 兒子（無權處分人）賣爸爸的畫，爸爸死 | 爸爸（無權處分人）賣兒子的畫，爸爸死 |
| 繼承人 | 無權處分人乙 → 取得 A 所有權 | 本人甲 → 繼承乙丙買賣契約（債務） |
| 處理 | §118 II **直接適用**：自始有效 → 丙取得（惡意亦同） | 早年：類推 §118 II；修法後：林秀雄不類推（下） |

## 二、類型二的新舊法分水嶺（98 年繼承編修正）

```
修法前：概括繼承（未主張限定／拋棄）→ 概括承受一切債務 → 本來就要還 → 類推 §118 II 讓丙取得 ✓ 合理
修法後：概括繼承有限責任（§1148 II）→ 只在所得遺產範圍內清償
       類推 §118 II 會：
       ① 剝奪甲的有限責任抗辯（乙遺產 0、負債一堆，甲本不用還，卻被迫拿畫還）
       ② 獨厚丙（其他債權人按比例，丙 100% 滿足）
→ 林秀雄：不類推。甲承認 → 丙取得；甲拒絕 → 乙給付不能 → §226 損害賠償債務由甲繼承，在遺產範圍內賠（損害 200 萬、遺產只夠十分之一 → 賠 20 萬）
```
