# 民法32 筆記：租賃物之滅失瑕疵與出租人之擔保責任（§435、§436、§347）

## 租賃物的狀態分類：
- **滅失**：無法回復（例：附屬倉庫整個燒掉）
- **毀損**：還可以回復
- **瑕疵**：物的瑕疵、權利瑕疵

## 一部滅失（§435）：
- 要件：**不可歸責於承租人**；出租人可不可歸責，**不問**
- 效果：
  - 先就滅失部分**請求減少租金**（§435 I）
  - 存餘部分不能達租賃目的 → **終止契約**（§435 II）

## 全部滅失：
- 租賃物不存在，無法使用收益 → 租賃關係**當然消滅**
- 之後依各自可否歸責，走債務不履行處理賠償

## 物之瑕疵：修繕之外的路（§347 準用買賣）
- 租賃章沒有物之瑕疵擔保規定，預設可修就走 §429、§430
- 但若瑕疵**修不好**、又沒到滅失程度：
  - 例：房屋漏水，房東一直修不好，承租人自己也修不好
  - §430 只給終止或修繕費用，承租人還想住、想減租
  - §435 是一部滅失，漏水不是滅失 → 用不上
- 解法：**§347 準用買賣**
  - 準用 **§359** 請求**減少租金**
  - 準用 **§360** 請求損害賠償（例：出租人保證不會漏水，欠缺保證品質）
  - 準用 **§364** 請求另行交付無瑕疵之物：例如租車，試開發現頓挫，承租人現在就要用、不想等修 → 種類物可替換，請求換一台
- 依當事人想要的效果決定路徑
- 對照：勞務契約法無規定者，準用委任（§529）

## 權利瑕疵（§436）：
- 第三人就租賃物主張權利，致不能為約定之使用收益 → **準用 §435**
- 一部 → 減少租金；不能達目的 → 終止契約

## 實務：瑕疵擔保不以交付時存在為必要
- 最高法院 110 年度判決（講義註 1058）：出租人依 §423 負保持義務，就租賃物應與出賣人負相同之擔保責任，瑕疵於**交付後才發生**，出租人也要負責 → 字號建議查證
- 判決未寫法條依據，實質上是 §347 準用

## 📖 法條原文速查

> **§435**
> I　租賃關係存續中，因**不可歸責於承租人**之事由，致租賃物之**一部滅失**者，承租人得按滅失之部分，請求**減少租金**。
> II　前項情形，承租人就其存餘部分不能達租賃之目的者，得**終止契約**。

> **§436**　前條規定，於承租人因**第三人就租賃物主張權利**，致不能為約定之使用、收益者準用之。

> **§347**　本節規定，於買賣契約以外之**有償契約準用**之。但為其契約性質所不許者，不在此限。

> **§529**　關於勞務給付之契約，不屬於法律所定其他契約之種類者，適用關於委任之規定。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§435 減租須出租人可歸責？」 | **不問**出租人，只要承租人不可歸責 |
| 「租賃物一部滅失，可直接終止？」 | 先減租；存餘部分**不能達目的**才終止 |
| 「租賃物全部滅失？」 | 租賃關係**當然消滅** |
| 「房屋漏水修不好，想續住並減租？」 | **§347 準用 §359** |
| 「第三人就租賃物主張權利？」 | **§436 準用 §435** |
| 「交付後才發生瑕疵，出租人要負擔保責任？」 | **要**，不以交付時存在為必要 |
