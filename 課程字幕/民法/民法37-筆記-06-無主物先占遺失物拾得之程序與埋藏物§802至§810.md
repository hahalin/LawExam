# 民法37 筆記：無主物先占、遺失物拾得之程序與埋藏物（§802～§810）

## 動產所有權（§801 以下）的定位：
- 動產可移動，不會黏在一起，所以**沒有相鄰關係**
- 兩大塊：**動產所有權之取得**、**添附**（添附見本講筆記-08、09）
- 區分所有建築物（§799）暫跳過，講完共有再回來

## 動產所有權取得的途徑：
| 途徑 | 條號 | 性質 |
|---|---|---|
| 依法律行為 | §761（讓與合意＋交付） | 法律行為 |
| 善意取得 | §801、§948（見民法35-筆記-11） | — |
| 無主物先占 | §802 | **事實行為** |
| 遺失物拾得 | §803～§807-1 | 事實行為 |
| 埋藏物發見 | §808、§809 | 事實行為 |
| 漂流物、沈沒物 | §810 | 準用遺失物 |
| 添附 | §811～§816 | 事實行為 |
- 事實行為 → **不以行為能力為必要**，無行為能力人也會發生效果

## 無主物先占（§802）：
- 要件：以所有之意思，占有**無主之動產**
- 「以所有之意思」**不是意思表示**，只是想據為己有的事實
  - 要和「占有無主之動產」合起來看：把無主動產據為己有
- 通說：**事實行為**
- 考法：5 歲小孩撿到別人丟棄的東西 → **取得所有權**

## 遺失物拾得的流程：
```
第一步：通知或報告並交存（§803）
  通知遺失人、所有人、有受領權人，或報告警察、自治機關並交存
  公共場所拾得者，亦得交該場所管理人
  受報告者公告、廣播招領；未認領交警察（§804）
        ↓
第二步：自通知或最後招領之日起等 6 個月
  ├─ 有人認領 → 受償費用後返還（§805 I），並可請求報酬（筆記-07）
  └─ 無人認領 → 拾得人取得所有權（§807）
```
- **500 元以下**的遺失物：等 **15 日**即可（§807-1）
- 易腐壞或保管費用過鉅：可拍賣或變賣，保管價金（§806）
  - 例：撿到一罐一個月後就過期的醬料，等 6 個月就成垃圾

## 公務員拾得：
- 警察巡邏時撿到手機 → 是**代表國家**拾得，拾得人是**國家**
- 6 個月無人認領 → 依 §807 歸國家，不是警察個人
- 對照：警察沒有報酬請求權，但國家仍可依 §807 取得所有權

## 埋藏物、漂流物：
- §808：發見埋藏物而占有者取得所有權
  - 在**他人所有**之動產或不動產中發見 → 該物所有人與發見人**各取得一半**
- §809：足供學術、藝術、考古、歷史資料者 → 依特別法
- §810：漂流物、沈沒物等 → 準用遺失物拾得
- 老師：§808 很冷門，但選擇題考過兩次

## 📖 法條原文速查

> **§802**（無主物先占）
> 以**所有之意思**，占有**無主之動產**者，除法令另有規定外，取得其所有權。

> **§803 I**（拾得人之義務）
> 拾得遺失物者應**從速通知**遺失人、所有人、其他有受領權之人或**報告警察、自治機關**。報告時，應將其物一併**交存**。但於機關、學校、團體或其他公共場所拾得者，亦得報告於各該場所之管理機關、團體或其負責人、管理人，並將其物交存。

> **§807 I**（逾期未認領）
> 遺失物自通知或最後招領之日起逾**六個月**，未經有受領權之人認領者，由**拾得人取得其所有權**。……
> → 後段及 II 項（3 個月未領取歸地方自治團體）建議查閱最新六法原文

> **§807-1**　遺失物價值在新臺幣**五百元以下**者 ……自通知或招領之日起逾**十五日**未經認領，由拾得人取得其所有權或變賣之價金。（摘要）→ 建議查閱最新六法原文

> **§808**　發見埋藏物而占有者，取得其所有權。但埋藏物係在他人所有之動產或不動產中發見者，該動產或不動產之所有人與發見人，**各取得埋藏物之半**。

> **§810**　拾得漂流物、沈沒物或其他因自然力而脫離他人占有之物者，**準用**關於拾得遺失物之規定。

> §804、§806、§809 原文 → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「無主物先占之性質？」 | 通說：**事實行為** |
| 「無行為能力人得否因先占取得所有權？」 | **得** |
| 「遺失物招領後多久無人認領，拾得人取得所有權？」 | **6 個月**（§807） |
| 「價值 500 元以下之遺失物？」 | **15 日**（§807-1） |
| 「警察執勤時拾得遺失物，無人認領歸誰？」 | 歸**國家**（代表國家拾得） |
| 「在他人土地發見埋藏物？」 | 土地所有人與發見人**各取得一半** |
