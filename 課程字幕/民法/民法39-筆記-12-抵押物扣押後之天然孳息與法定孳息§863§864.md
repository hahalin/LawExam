# 民法39 筆記：抵押物扣押後之天然孳息與法定孳息（§863§864）

## 天然孳息（§863）——選擇題常考，常和 §766、§70 一起考
- 甲以 A 地設定抵押權給乙，A 地上長出農作物，乙實行抵押權時能否一起拍賣？
- **未分離** → 是土地的一部分，當然為效力所及
- **已分離** → 看兩件事：
  1. 何時分離：**扣押前**分離 → 脫離抵押權；**扣押後**分離 → 往下看
  2. 誰有收取權：**抵押人**有收取權 → 效力所及；**第三人**有收取權 → 不及
- 扣押：抵押權人向執行法院聲請，法院囑託地政機關辦**查封（扣押）登記**；之後抵押物不能動
- 例：丙在甲的 A 地種紅蘿蔔，扣押後採收
  - 丙是承租人 → 丙有收取權（§70）→ **不及**
  - 丙是亂種的路人 → 無收取權，依原物主義歸土地所有人甲（§766）→ **及於**
- 收取權歸屬要回想 §766 以下：善意占有人、買賣契約、未成年子女特有財產等情形

## 法定孳息（§864）
- 甲設定抵押後把 A 地出租給丙，甲對丙的**租金債權**是法定孳息
- 要件：**扣押後**、抵押人**得收取**
- 對抗要件：抵押權人須把扣押的事**通知**應付租金的丙，否則不得對抗丙

## 爭點：抵押權人可否直接向承租人收租？
- 甲欠乙 100 萬，丙每期應付租金 5 萬；乙能否要丙直接付給自己，甲的債務剩 95 萬？
- **實務（100 台上 877）**：**否**。§864 指抵押權人就扣押後之法定孳息有**優先受償權**，不是有**收取權**；要實行只能拍賣該租金債權
- **謝在全**：**可以**。孳息通常以債權形態存在，最簡便的變價方式就是請求債務人向抵押權人給付；§878 也承認拍賣以外的實行方法，不必限於拍賣

## 📖 法條原文速查

> **§863**（天然孳息）抵押權之效力，及於抵押物**扣押後**自抵押物分離，而得由**抵押人收取**之天然孳息。

> **§864**（法定孳息）抵押權之效力，及於抵押物**扣押後**抵押人就抵押物得收取之法定孳息。但抵押權人，非以扣押抵押物之事情，**通知**應清償法定孳息之義務人，不得與之對抗。

> **§70 I**（孳息之歸屬）有收取天然孳息權利之人，其權利存續期間內，取得與原物分離之孳息。

> **§766**（物之成分及孳息之歸屬）物之成分及其天然孳息，於分離後，除法律另有規定外，仍屬於其物之所有人。

> **§878**（拍賣以外之實行方法）抵押權人於債權清償期屆滿後，為受清償，得訂立契約，取得抵押物之所有權，或用拍賣以外之方法，處分抵押物。但有害於其他抵押權人之利益者，不在此限。

## 📋 實務見解速查

> **最高法院 100 年度台上字第 877 號判決**（講義 267 頁；字幕唸「100年877號」，字號建議查證）：§864 所定抵押權之效力及於抵押物扣押後抵押人得收取之法定孳息，係指抵押權人對該法定孳息有**優先受償之權**，非謂抵押權人就該法定孳息有**收取權**。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「扣押前已分離之天然孳息？」 | **不及** |
| 「扣押後分離，承租人種植之作物？」 | **不及**（承租人有收取權） |
| 「扣押後分離，無權種植者之作物？」 | **及於**（歸土地所有人，抵押人得收取） |
| 「扣押後之租金債權？」 | 及於，但**須通知**承租人始得對抗 |
| 「抵押權人得否直接向承租人收取租金？」 | 實務：**否**（100 台上 877）；謝在全：可 |

## 判斷流程

```
孳息是否為抵押權效力所及？
├─ 天然孳息（§863）
│    ├─ 未分離 → 及於
│    └─ 已分離
│         ├─ 扣押前 → 不及
│         └─ 扣押後 → 抵押人有收取權？ 是 → 及於／否 → 不及
└─ 法定孳息（§864）
     └─ 扣押後＋抵押人得收取 → 及於；通知義務人始得對抗
```
