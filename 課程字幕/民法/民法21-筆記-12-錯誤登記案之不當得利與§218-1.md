# 民法21 筆記：錯誤登記案之不當得利與§218-1

## 案例（旗山地政事務所案，講義 311 頁）：
- 甲（地政事務所）把乙所有的 A 地，錯誤登記到丙名下
- 丙死亡，丁不知情，以為是丙的遺產，辦理繼承登記
- 丁把 A 地賣給善意的戊並移轉登記，取得價金
- 乙發現時已無法回復，依土地法 §68 向甲請求損害賠償，甲賠償
- 問：甲賠償後，得否依 §179 向丁請求返還價金？

## 為什麼無法更正：
- 錯誤登記 → 丙沒有取得所有權，可更正
- 丁繼承 → 繼承不能取得不屬於丙的東西，仍可更正
- 丁出賣移轉（無權處分）→ 戊善意信賴登記，依 **§759-1 II** 取得所有權 → 不能更正 → 乙受損害，轉為賠償

## 最高法院（99 台上 2006）：肯定
- 丁受有出售土地之**價金利益**；甲受有賠償之**損害**
- 兩者出於同一原因事實（丁的出賣移轉行為）→ 要件具備，甲得對丁請求
- 老師評：沒有區分給付、非給付，思考方式與學說不同

## 學說與二審附論：否定直接請求
- 先找利益：丁得到價金
- 利益來源：價金來自戊，不是甲的給付 → **非給付型**
- 權益歸屬：價金是 A 地的對價，在法律上應歸屬**乙**（原所有人），不是甲 → 甲不能直接對丁主張
- 甲會說「我已經賠給乙，損害在我身上」→ 學說：少了一步，應依 **§218-1** 請求乙**讓與**其對丁的 §179，再以乙的請求權向丁請求
- 實務操作：賠償時請被害人簽讓與同意書

## 老師的看法：
- 最高法院不是不懂：二審已在附論點出 §218-1；若要求另行起訴，最後結果相同卻再耗數年 → 為審判效率從寬解釋
- 但考生要寫的是**正確的法律論述**，仍應以權益歸屬說＋§218-1 作答

## 下一講：
- 從**非給付型不當得利（權益歸屬說）的相關爭議**續講：各種無權占有他人土地、無權處分他人之物的案例類型
- 老師提醒：不當得利條文少、考出機率高，投資報酬率很高

## 📖 法條原文速查

> **§218-1 I**　關於物或權利之喪失或損害，負賠償責任之人，得向損害賠償請求權人，**請求讓與**基於其物之所有權或基於其權利對於第三人之請求權。

> **§759-1 II**　因信賴不動產登記之善意第三人，已依法律行為為物權變動之登記者，其變動之效力，不因原登記物權之不實而受影響。

> **土地法 §68 I**（要旨）　因登記錯誤、遺漏或虛偽致受損害者，由該地政機關負損害賠償責任；但地政機關證明其原因應歸責於受害人時，不在此限。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **99 台上 2006**（講義 312 頁、註 562）：系爭土地本非繼承人應繼承之標的，其取得繼承登記係因地政機關錯誤所致，乃無法律上原因；繼承人於地政機關得依職權更正前搶先移轉，致地政機關無法更正而須負賠償責任，同時受有土地出售對價之利益，成立不當得利。（要旨改寫，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「錯誤登記之土地經繼承登記，真正所有人得否更正？」 | **得**，繼承不取得所有權 |
| 「善意第三人信賴登記受讓，得否取得？」 | **得**（§759-1 II） |
| 「地政機關賠償後，得否直接依 §179 向出賣人請求價金？」 | 99 台上 2006：**得**；學說：**否**，價金權益歸屬於原所有人 |
| 「學說認地政機關應如何求償？」 | 依 **§218-1** 請求被害人讓與其對第三人之 §179 |

## 一、時間軸

```
錯誤登記給丙 → 丁繼承登記 → 丁賣給善意戊並移轉
   可更正         可更正         §759-1 II，不能更正
                                    ↓
                    乙依土地法 §68 向甲請求賠償
```

## 二、兩種見解

| | 最高法院 99 台上 2006 | 學說、二審附論 |
|---|---|---|
| 思考方式 | 利益、損害出於同一原因事實 | 先分類，非給付型看權益歸屬 |
| 價金歸屬 | — | 原所有人乙 |
| 甲之路徑 | 直接 §179 向丁 | §218-1 受讓乙對丁之 §179 |
| 考試 | 介紹並評析 | 採此說作答 |
