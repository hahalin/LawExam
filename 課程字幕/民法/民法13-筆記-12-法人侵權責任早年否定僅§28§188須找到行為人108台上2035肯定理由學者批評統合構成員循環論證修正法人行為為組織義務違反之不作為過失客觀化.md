# 民法13 筆記：法人得否為 §184 的責任主體——早年否定（行為＝受意識支配之活動，法人無意識；只能找到行為人後依 §28 董事／§188 受僱人連帶，找不到行為人就告不了）；108 台上 2035 肯定，理由：① 法人實在說 ② §184 文義未排除法人 ③ 統合其構成員之行為與意識作為法人之行為與過失 ④ 保護被害人 ⑤ 風險分配；學者批評：①②無實益（早年亦採實在說仍否定；§28 體系解釋可反推）、③循環論證（找不到行為人才告法人，卻又要統合「構成員」）；修正：法人之行為＝**組織義務違反之不作為**（該做的 SOP 沒做到：汙水處理、管線保養），過失**客觀化**（陳聰富）

> 來源：民法13 課程字幕 01:57:40 ~ 02:15:00（講義 8 頁）

---

## 📖 法條原文速查

> **§26**　法人於法令限制內，有享受權利負擔義務之能力。……
> **§28**　法人對於其董事或其他有代表權之人因執行職務所加於他人之損害，與該行為人連帶負賠償之責任。
> **§188 I**　受僱人因執行職務，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。……

---

## 📋 實務見解速查

> **最高法院 108 年度台上字第 2035 號判決**（講義 8 頁，字號照字幕）：依法人實在說，法人為權利主體，有責任能力，自有侵權行為能力；§184 文義並未排除法人；法人之行為與過失，得**統合其成員之行為與意識**認定之；為保護被害人及合理分配風險，法人得為 §184 之責任主體。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人得否直接依 §184 負侵權責任？」 | **得**（108 台上 2035 後實務與通說一致，已非考點）。考點在**理由**與學說批評 |
| 「早年為何否定？被害人怎麼辦？」 | 行為是受意識支配之活動，法人是抽象組織無意識 → 無行為 → 不構成侵權。被害人須**找到行為人**：董事 → §28、受僱人 → §188 連帶；找不到行為人（組織龐大）→ 告不了 → 保護不足 |
| 「108 台上 2035 的理由？」 | ① 法人實在說 ② §184 文義未限自然人 ③ 統合構成員之行為與意識 ④ 保護被害人（不必再找行為人）⑤ 風險分配（在社會上活動獲利就該承擔風險；刑法上企業刑責亦同趨勢） |
| 「學者對理由①②的批評？」 | ① 我國向來採法人實在說，早年仍否定法人侵權能力 → 實在說與此問題**無關**，不是理由 ② 法律解釋不只文義：§28 明定法人就董事行為負連帶責任，體系上可反推 §184 未含法人；「法條沒說不能用」不等於「可以用」→ 文義解釋不充分 |
| 「對理由③的批評（最重要）？」 | **循環論證**：被害人因找不到行為人才對法人主張 §184，結果法人的行為要「統合構成員」認定 → 構成員是誰？要怎麼統合？→ 又回到找行為人 → 與目的④衝突。最高法院解決一個問題又創造一個問題 |
| 「學說的修正？」 | 從法人角度重新定義行為與過失：法人之行為＝**組織義務違反之不作為**——不問誰排放廢水，問法人**汙水處理環節哪裡沒做到**；過失**客觀化**（陳聰富）——法人應注意的客觀標準（管線每兩年保養）沒做到就是過失。被害人只須證明法人客觀上該做沒做，不必找人、不必證明意識；舉證困難另由民訴舉證責任轉換處理 |

## 一、否定說時代的救濟路徑

```
知道行為人是董事 → §28 法人連帶
知道行為人是受僱人 → §188 僱用人連帶
不知道行為人是誰 → 無法用 §28／§188；§184 法人無行為 → 告不了
```

## 二、108 台上 2035 五個理由與學者評價

| 理由 | 學者評價 |
|---|---|
| ① 法人實在說 | 無實益：早年也採實在說仍否定，與本問題無關 |
| ② §184 文義未排除法人 | 不充分：§28 體系解釋可反推；沒規定 ≠ 可以用 |
| ③ 統合構成員之行為與意識 | **循環論證**：構成員是誰、怎麼統合沒講清楚；找不到行為人才告法人，又要我找構成員 |
| ④ 保護被害人 | ✓ |
| ⑤ 風險分配 | ✓ |

## 三、學說的重新定義

```
法人的行為 ＝ 不作為 ＝ 組織義務的違反（該做的沒做到）
   工廠排放廢水汙染農田 → 不找是誰按下排放鈕 → 問為什麼有廢水 → 汙水處理沒做到 → 這就是法人的行為
法人的過失 ＝ 客觀化（陳聰富）
   自然人過失：主觀預見可能性（因注意能注意而不注意）；法人無主觀
   → 改問法人客觀上應注意什麼（地下管線兩年保養一次、何種情況應更換）→ 沒做到 → 過失
→ 涵攝時不再卡在「意識」與「行為人是誰」
```
