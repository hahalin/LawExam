# 民法39 筆記：抵押權發生上之從屬性與形式認定

## 三種特性：
- **從屬性**：發生上、移轉上、消滅上
- **不可分性**：§868、§869
- **代位性**：§881（與 §862-1 一起看，見本講筆記-11）
- 這些是觀察出來的特色，條文散在各處

## 發生上從屬性：
- 抵押權為擔保特定債權而存在 → 沒有債權，不能設定抵押權

## 爭點一：先設定抵押、後撥款，抵押權有效嗎？
- 甲向乙借 500 萬，乙要求甲先設定抵押權才撥款
- 釣人的第一小題：消費借貸是**要物契約**，撥款（移轉金錢所有權）才成立 → 設定抵押時債權還不存在
- 實務學說共識：被擔保債權包括**將來可預期發生的特定債權**；實行抵押權時，登記的債權確實存在即可
- 須「可預期」：只是說說而已、沒有確定會借，不算
- 111 年座談會（講義註釋 376）：4/1 訂約、4/2 設定抵押、4/3 才匯款 → 普通抵押權與最高限額抵押權都可以將來債權為被擔保債權，**有效**

## 爭點二：登記的債權與實際債權不符？
- 甲向乙借 300 萬，乙已撥款；甲的好友丙提供 A 地設定抵押權給乙
- 設定契約書上卻把擔保債權寫成「丙對乙的借款」，丙乙之間根本沒有借款
- 實務採**形式認定**：抵押權人只能依**登記內容**行使權利；登記的債權不存在 → 欠缺發生上從屬性，抵押權**無效**，不能以「實際上另有債權」補救
- 理由：物權有絕對效力，公示外觀要讓第三人看得出擔保的是哪筆債權
- 效果：抵押人得訴請**塗銷**；抵押權人不能實行

## 📖 法條原文速查

> **§860**　稱普通抵押權者，謂債權人對於債務人或第三人不移轉占有而**供其債權擔保**之不動產，得就該不動產賣得價金優先受償之權。

> **§474 I**（消費借貸）稱消費借貸者，謂當事人一方移轉金錢或其他代替物之所有權於他方，而約定他方以種類、品質、數量相同之物返還之契約。

> **§861 I 但書**　但契約另有約定者，不在此限。→ 47 台上 535 判例據此認擔保債權可由當事人自行約定

## 📋 實務見解速查

> **47 台上 535 判例**：抵押權所擔保之債權，原可由契約當事人自行訂定，此觀 §861 但書規定自明；故契約當事人如訂定以**將來可發生之債權**為被擔保債權，自非法所不許。（要旨改寫）

> **111 年法律座談會**（講義註釋 376，會議名稱字幕未唸，建議查證）：普通抵押權或最高限額抵押權，均得以將來可能發生之債權為被擔保債權；先設定抵押權、翌日始撥款者，抵押權仍有效。（要旨改寫）

> **最高法院 70 年度第 18 次民事庭會議決議**（字幕唸「70年第18次」，建議查證）：抵押權為不動產物權，非經登記不生效力，抵押權人僅得依**登記之內容**行使權利；登記之債務人與抵押權人間無債權債務關係者，抵押人得訴請塗銷，抵押權人不得實行。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「消費借貸契約何時成立？」 | **交付金錢時**（要物契約） |
| 「先設定抵押、後撥款，抵押權效力？」 | **有效**，可擔保將來可預期之債權 |
| 「普通抵押權可否擔保將來債權？」 | **可以**（不限最高限額抵押權） |
| 「登記之債權不存在，但實際另有債權？」 | 採**形式認定**，抵押權無效，得訴請塗銷 |
| 「抵押權人得依實際債權主張權利？」 | **不得**，僅能依登記內容 |

## 判斷流程

```
被擔保債權是否存在？
├─ 設定時尚未發生
│    ├─ 將來可預期之特定債權 → 有效
│    └─ 只是空談 → 欠缺從屬性
└─ 登記內容與實際不符
     └─ 形式認定：看登記的債權 → 不存在即無效
```
