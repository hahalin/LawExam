# 民法06 筆記：掛號信「招領通知單」算不算到達——109 台上大 908 大法庭裁定 vs 吳從周的批評

> 來源：民法06 課程字幕 00:30:00 ~ 00:41:00

## 📖 法條原文速查

> **§95 I 前段**　非對話而為意思表示者，其意思表示，以通知達到相對人時，發生效力。

> **§254**（給付遲延之解除）
> 契約當事人之一方遲延給付者，他方當事人得定相當期限**催告**其履行，如於期限內不履行時，得解除其契約。

> **§426-2 II**　優先承買權人於通知達到後十日內未以書面表示承買者，視為放棄。

> 郵政相關規定：掛號郵件不獲會晤，郵局招領保管 **15 日**，逾期退回原寄件人。→ 建議查閱郵政法規原文

## 📋 實務見解速查

> **最高法院 109 年度台上大字第 908 號民事大法庭裁定**（講義 149 頁）
> 表意人將其意思表示以書面郵寄**掛號**至相對人之住所地，郵務機關因不獲會晤相對人而製作**招領通知單**通知相對人領取者，除相對人能證明其客觀上有**不能領取之正當事由**外，應認相對人**受招領通知時**，表意人之意思表示已到達相對人而發生效力，**不以實際領取為必要**。
> → 字號、日期請對講義 149 頁

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲以掛號寄催告函，乙不在家，郵差貼招領通知，乙 15 日內未領致退回，催告是否到達？」 | 大法庭：**已到達**（受招領通知時即到達），除非乙證明有不能領取之正當事由 |
| 「到達時點？」 | **招領通知貼上時**，不是 15 天後、不是領取時 |
| 「正當事由之例？」 | 教召、寄錯地址（寄到三五年前租屋處） |
| 「學說批評？」 | 吳從周：招領通知 ≠ **隨時**可瞭解（郵局非 24 小時、只有 15 天、不知寄件人與內容）→ 原則**不到達**，相對人違反誠信故意不領才例外擬制到達 |
| 「此裁定如何結合考點？」 | 任何需要「通知／催告到達」的題目：§254 催告解除、§80 催告法代、§426-2 優先承買通知、§440 催告繳租 |

## 一、事實與問題

```
甲 ──掛號信──→ 乙家，乙不在（不獲會晤）
郵差貼招領通知單：15 天內持身分證印章到某某郵局領
乙 15 天都沒去領 → 信退回甲
→ 甲的意思表示到達了沒有？
```

### 考法：不會單獨考，會包裝在別的考點裡
- §254：乙給付遲延，甲掛號寄催告，退回；再寄解約通知 → 解除有效？前提是**催告到達**。
- §426-2：掛號通知其他共有人優先承買，退回 → 10 日沉默**視為拒絕**的效果發生嗎？
- 老師：這個裁定「超級萬用」，所有用到意思表示的題目都能套。

## 二、大法庭裁定（109 台上大 908）：貼了就到達

```
招領通知單 → 已置於相對人隨時可瞭解之地位（看到通知就能去領）
→ 原則：受招領通知時【即到達】，不以實際領取為必要
→ 例外：相對人證明客觀上有【不能領取之正當事由】→ 不到達
    例：當天被教召兩週；信寄到三五年前的租屋處、現住人撕掉
邏輯：貫徹 §95 的風險分配——表意人只要寄到你家門口就完成任務，15 天不去領被退回是你的事
```

## 三、吳從周的批評：招領通知 ≠「隨時」可瞭解

| | 一般信件在信箱 | 招領通知單 |
|---|---|---|
| 可瞭解的時間 | **24 小時**，隨時拿出來看；一個月才收一次信也看得到 | 郵局不是超商，早 8 晚 7 上班族、週末**去不了** |
| 期限 | 無 | 只有 **15 天** |
| 資訊 | 打開就知道誰寄的、內容是什麼 | 只知道「有一封掛號」，**不知寄件人、不知內容** |

```
吳從周：到達的定義重點在「隨時」兩個字 → 招領通知不符
→ 原則：不發生到達效力
→ 例外：相對人違反誠信原則、明知有信故意不理 → 擬制到達（回到陳聰富「輔以誠信原則」）
→ 大法庭把原則例外顛倒了
```

### 兩說對照

| | 大法庭 | 吳從周 |
|---|---|---|
| 原則 | 受招領通知即到達 | 不到達 |
| 例外 | 相對人證明不能領取之正當事由 → 不到達 | 相對人違反誠信故意不領 → 擬制到達 |
| 舉證 | 相對人證明正當事由 | 表意人證明相對人惡意 |
