# 民法01 筆記：法律解釋與 §4、§5 數量記載

> 來源：民法01 課程字幕 00:19:47 ~ 00:27:30

---

## 📖 法條原文速查

> **§4**（文字與號碼不符）
> 關於一定之數量，**同時以文字及號碼**表示者，其文字與號碼有不符合時，如法院不能決定何者為當事人之原意，應以**文字**為準。

> **§5**（數次表示不符）
> 關於一定之數量，以文字或號碼為**數次之表示**者，其表示有不符合時，如法院不能決定何者為當事人之原意，應以**最低額**為準。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「契約寫 180 萬，又寫壹佰伍拾萬元，法院無法探求真意，以何者為準？」 | **文字**（§4）→ 150 萬 |
| 「契約同為號碼，寫 180 萬又寫 200 萬，以何者為準？」 | **最低額**（§5）→ 180 萬 |
| 「§4、§5 適用的前提？」 | **法院不能決定何者為當事人原意**。能探求真意就依真意 |
| 「文字號碼混雜、數次表示均不符時？」 | 有爭議：全部最低額說（只看 §5）vs 文字最低額說（先 §4 留文字，再 §5 取最低）。一試少考，知道兩說即可 |

## 一、法律是一門「解釋」的學問

```
找到請求權基礎
    ↓
拆出構成要件
    ↓
每個要件的每個字都要解釋 ← 法學方法
    ↓
解釋角度：文義／體系／目的／歷史／比較法／合憲性
    ↓
角度不同 → 結論不同 → 爭點
```

- 爭點不是用背的。先找「這條哪個字有模糊空間」，再用方法去想，就能自己推出各說。
- 遇到沒讀過的條文，至少要能從文義、目的、體系給出一條合乎方法的解釋路徑；最忌「我覺得可以／不可以」。

## 二、§4、§5 的基本操作

| 情形 | 條文 | 結果 |
|------|------|------|
| 文字 ≠ 號碼（各一次） | §4 | 以**文字**為準 |
| 同為號碼（或同為文字），數次不符 | §5 | 以**最低額**為準 |
| 共同前提 | — | 法院**不能決定**當事人原意 |

為什麼文字優先？文字（壹佰伍拾萬）比號碼（1,500,000）更難寫錯、更難改。

## 三、爭點：文字、號碼混雜且數次表示

### 事實
同一份買賣契約，針對同一筆價金，前後出現：
`150 萬`（號碼）、`壹佰捌拾萬元`（文字）、`200 萬`（號碼）、`貳佰貳拾萬元`（文字），談判過程全寫進去了，法院無法探求真意。

### 兩說

```
┌─ 全部最低額說（只用 §5）──────────────────────┐
│ §5 文義：「以文字或號碼為數次之表示」          │
│ → 本件就是文字加號碼、數次表示、互不相符       │
│ → 每句都該當 → 直接取最低額                   │
│ → 150 萬                                       │
└───────────────────────────────────────────────┘

┌─ 文字最低額說（§4 + §5 體系解釋）──────────────┐
│ 本件同時有文字與號碼並存 → 先用 §4              │
│ → 文字優先，把號碼刪掉，剩 180 萬、220 萬       │
│ → 剩下的仍不一致 → 再用 §5 取最低額             │
│ → 180 萬                                       │
└───────────────────────────────────────────────┘
```

| 比較 | 全部最低額說 | 文字最低額說 |
|------|------------|------------|
| 解釋方法 | 文義解釋（單看 §5） | 體系解釋（§4、§5 合看） |
| 結果 | 150 萬 | 180 萬 |

### 這題要學的
同一事實、同一法條，切入角度不同就有不同結論——這就是爭點的長相。方法在，爭點就能自己推出來。
