# 民法20 筆記：利於本人與不違反本人意思（§174II、§176II）

## 利於本人：看「承擔」不看「實施」：
- 判斷對象是**管理事務之承擔**（為什麼要管、出發點），不是**管理事務之實施**（怎麼管、手段）
- 標準很寬：出發點有利於本人就夠，手段不必也有利
- 手段好不好，是成立後**有無違反善良管理人注意義務**、要不要負債務不履行責任的問題 → 兩個不同層次

## 符水案：
- 鄰居小孩甲發燒拉肚子，父母都去上班；乙帶甲去宮廟喝符水，支出 100 元
- 乙能否依 §176 I 向甲之母丙請求 100 元？
- 承擔：乙出發點是要治好甲 → 利於本人；丙未曾明示反對 → 不違反意思 → 王澤鑑：**構成適法無因管理**，乙得請求
- 實施：喝符水不是正常治療管道 → 未盡善良管理人注意 → 甲若病情加重，乙負**債務不履行**責任（見民法20-筆記-09）

## 不違反本人明示或可得推知之意思：
- 個案認定，看本人有無明示或其他可推知的意思
- 常考：甲的房屋嚴重漏水，預計下個月拆除重建；乙不知情把漏水修好 → 違反甲**可得推知**之意思 → 不構成適法無因管理

## 例外：違反本人意思仍屬適法（§174 II、§176 II）：
- 三種情形：①為本人盡**公益上之義務** ②為本人履行**法定扶養義務** ③本人之意思**違反公共秩序善良風俗**
- 本人意思有問題，違反它反而對他好（負負得正）
- 最常考：救助**死意甚堅**的自殺者 → 違反其明示意思，仍屬適法
- 本人不想繳稅、不想繳罰單，你幫他繳 → 公益上義務，仍屬適法
- 效果：§176 II 使管理人仍有 §176 I 請求權；§174 II 使管理人不負 §174 I 無過失責任

## 📖 法條原文速查

> **§174**　I 管理人違反本人明示或可得推知之意思，而為事務之管理者，對於因其管理所生之損害，雖無過失，亦應負賠償之責。II 前項之規定，如其管理係為本人盡**公益上之義務**，或為其履行**法定扶養義務**，或本人之意思**違反公共秩序善良風俗**者，不適用之。

> **§176 II**　第一百七十四條第二項規定之情形，管理人管理事務，雖違反本人之意思，仍有前項之請求權。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「利於本人係指管理事務之實施？」 | **錯**，指管理事務之**承擔** |
| 「帶病童喝符水，不成立適法無因管理？」 | 通說（王澤鑑）：**成立**；手段問題另論債務不履行 |
| 「房屋將拆除重建，他人修繕漏水？」 | 違反**可得推知**之意思 → 不適法 |
| 「救助自殺者違反其明示意思，仍屬適法？」 | **是**，本人意思違反善良風俗 |
| 「本人不願繳罰單，他人代繳？」 | **公益上義務**，仍屬適法 |
| 「§174 II 三種情形？」 | 公益上義務、法定扶養義務、違反公序良俗 |

## 一、兩個層次

```
乙帶甲喝符水
├─ 層次一：成立適法無因管理？（看承擔）
│   出發點要治病 → 利於本人 ✓；丙未反對 ✓ → 成立
│   → 乙對丙：§176 I 請求 100 元
└─ 層次二：管理得好不好？（看實施）
    喝符水 → 未盡善良管理人注意
    → 甲病情加重：乙負債務不履行（§227）
```

## 二、違反本人意思時

| 情形 | 本人意思 | 結論 |
|---|---|---|
| 房屋將拆除，乙修漏水 | 正常（不必修） | 不適法 |
| 救死意甚堅之自殺者 | 違反善良風俗 | 適法（§174 II） |
| 代繳罰單、稅 | 拒盡公益上義務 | 適法（§174 II） |
| 代為支付扶養費 | 拒盡法定扶養義務 | 適法（§174 II） |
