# 民法14 筆記：公墓遷葬案——甲母土葬於公營公墓，政府欲移作他用，僅**公告**限一年內自行遷出、逾期火化移入納骨塔，未依殯葬管理條例對登記名冊之人**逐一通知**（有過失）→ 甲不知情，隔年清明掃墓始知母已被火化；甲依 §184 I 前段請求：損害＝難過（非財產上）✓；權利＝「**遷葬自由決定權**」（意思自由之內涵：剝奪甲自行選擇遷葬地點之機會）→ 回到「意思自由是不是權利」：**實務採肯定說**，承認為權利 → 前段 ✓（五名繼承人各判賠一兩萬元）；**否定說下**須與其他權利結合：**阮富枝**法官：與**遺族追思權**結合——§195 I「**其他人格法益**」包含遺族追思權（慎終追遠之善良風俗、固有傳統下之權利），未通知即火化侵害遺族追思之情 → 得請求；**黃松茂**研究員：亦採否定說，但本件**不能**與遺族追思權結合——遺體火化移入納骨塔並未使甲不能祭拜（骨灰亦可追思，不以全屍為必要），且政府全程請道士誦經、符合禮俗 → 未達侵害追思權程度 → 不得請求；兩篇文章脈絡相同（先否定意思自由為權利、再問能否與追思權結合），結論相反

## 📖 法條原文速查

> **民法 §195 I**　不法侵害他人之身體、健康、名譽、自由、信用、隱私、貞操，或不法侵害**其他人格法益而情節重大者**，被害人雖非財產上之損害，亦得請求賠償相當之金額。
> **殯葬管理條例**（公墓遷葬應通知墓主之規定；條號請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「政府遷葬公墓未個別通知即火化遺體，遺族得否依 §184 I 前段請求慰撫金？權利為何？」 | 實務**肯定**：**遷葬自由決定權**（意思自由內涵）為權利 → 前段 ✓ |
| 「若採意思自由非權利之否定說？」 | 須與其他權利結合。阮富枝：**遺族追思權**（§195 I 其他人格法益，慎終追遠之傳統良俗）→ 得請求。黃松茂：本件未侵害追思權（仍可祭拜、骨灰亦可追思、全程符合禮俗）→ 不得請求 |
| 「遺族追思權的法律依據？」 | §195 I「其他人格法益」；來源為我國固有傳統、善良風俗下慎終追遠之精神 |
| 「阮富枝 vs 黃松茂異同？」 | 同：都否定意思自由為權利、都問能否與遺族追思權結合。異：阮肯定本件可結合，黃否定（未達侵害程度） |

## 一、涵攝

```
甲 → 政府（§184 I 前段）
  ① 損害：難過（非財產上）✓
  ② 權利？
     ├ 肯定說（本件實務）：遷葬自由決定權＝權利 → ✓ → 判賠
     └ 否定說：意思自由非權利 → 找其他權利
          ├ 阮富枝：遺族追思權（§195 其他人格法益）✓
          └ 黃松茂：追思權未受侵害（還是能拜、有誦經）✗
  ③ 過失：殯葬管理條例要求通知登記之人，政府只公告 ✓
```

## 二、與筆記 10 的連結

- 這題是「意思自由是否為權利」體系的套用：肯定說直接走前段；否定說要看能不能跟其他權益結合，結合得上才有救濟。
