# 民法16 筆記：§184I後段之故意背於善良風俗

## 構成要件：
- 客觀：行為、損害、因果關係；**不問有無權利受侵害**（利益亦受保護，含純粹經濟上損失）
- 不法性的位置改由「**背於善良風俗之方法**」承擔
- 主觀：只剩**故意**，過失不成立；仍須有責任能力

## 背於善良風俗＝加重的不法性：
- 先具備一般不法性（結果不法說：有損害結果、無阻卻違法事由）
- 再加上**違背社會共同生活準則**（社會共同的道德標準），為一般社會大眾所不能認同
- 判斷時把自己當成一般鄉民：有沒有踩到社會的道德底線

## 挖角案：
- 房仲業務跳槽，連客戶一起帶走，原公司業績受影響
- 最高法院**從寬**：此種惡性競爭已違背社會共同生活準則，行為人主觀上可預見結果 → 依 §184 I 後段負責（字號字幕未唸，請對講義）

## 寫從寬解釋的順序：
- 先寫「若從嚴 → 原告無法求償 → 保護被害人目的落空」，再導出從寬；不要一開始就把「故意」直接涵攝成「重大輕率」，論述會跳躍

## 📖 法條原文速查

> **民法 §184 I 後段**　**故意**以**背於善良風俗之方法**，加損害於他人者亦同。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§184 I 後段是否以權利受侵害為要件？」 | **否**。只要行為、損害、因果關係；**利益**（含純粹經濟上損失）亦受保護 |
| 「§184 I 後段之主觀要件？」 | 限**故意**；過失不成立 |
| 「背於善良風俗之意義？」 | **加重的不法性**：具備不法性之外，另違背社會共同生活準則、為一般社會大眾所不能接受 |
| 「業務員跳槽並帶走原公司客戶，原公司得否依侵權行為請求？」 | 最高法院**從寬**：惡性競爭違背社會共同生活準則，主觀可預見 → **§184 I 後段** ✓ |
| 「§184 I 前段與後段之保護客體？」 | 前段：**權利**（絕對權），故意過失皆可；後段：**利益**，限故意＋背俗 |

## 一、三款比較

| | §184 I 前段 | §184 I 後段 | §184 II |
|---|---|---|---|
| 保護客體 | 權利（絕對權） | 利益（含純粹經濟損失） | 利益（依保護法律範圍） |
| 不法性 | 一般不法（結果不法） | 加重不法：背於善良風俗 | 違反保護他人之法律 |
| 主觀 | 故意或過失 | 限故意 | 推定過失 |

## 二、加重不法性的判斷

```
一般不法性：有損害結果 ＋ 無阻卻違法事由
        ＋
違背社會共同生活準則（社會道德底線）
        ＝
背於善良風俗
```

- 多數人可以接受、或雖不太能接受但未到道德底線 → 通常**不**構成背俗
- 解釋從嚴或從寬，結論截然不同（下一份筆記：律師無效遺囑案）

## 三、案例：挖角案

| 步驟 | 內容 |
|---|---|
| 損害 | 原公司業績下滑 ✓ |
| 權利 | 無絕對權受侵害 → 前段 ✗ |
| 背俗 | 一般競爭手段 vs 惡性競爭？最高法院：**惡性競爭**，違背社會共同生活準則 ✓ |
| 故意 | 行為人主觀上可預見結果 ✓ |
| 結論 | §184 I 後段 ✓ |

## 四、從寬解釋的答題模板

```
若從嚴解釋 → 原告不能請求
   ↓
不能請求 → 無法達成侵權法保護被害人之目的
   ↓
故應從寬解釋 → 擴大保護範圍 → 原告得請求
```
