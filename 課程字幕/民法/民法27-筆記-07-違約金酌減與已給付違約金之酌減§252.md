# 民法27 筆記：違約金酌減與已給付違約金之酌減（§252）

## §252 的基本問題：
- **適用範圍**：總額性、懲罰性違約金**都可以**酌減；總額性反而更常發生過高
- **職權判斷**：主詞是「法院」，由法院認定有無過高、要不要酌減

## 主要爭點：違約金已經付了，還能酌減嗎？
- 甲（承攬人）違約，乙（定作人）實際損害 **100 萬元**，約定違約金 **500 萬元**（五倍）
- 方法一：甲先不付，請求法院酌減，減完再付
- 方法二（乙的做法）：甲還有工程尾款 **700 萬元**，乙直接扣 500 萬元，只付 200 萬元
- 這種被扣款的情形叫**非任意給付**
- 老師提到 112 年律師考試曾觸及這個問題（建議查證）

## 爭議來源：德國法
- 我國 §252 條文沒說「付了就不能減」
- 德國民法 §343 I 第 3 句：違約金**給付後不得酌減**（講義 543 頁）

## 各說：
- **否定說**：參考德國民法 §343 → 已付就不能酌減
- **實務**：
  - **非任意給付**（如以扣工程款逼付）→ 仍可主張酌減
  - 任意給付 → 不得酌減
- **黃茂榮：絕對肯定說**，不區分任意與否，一律可以酌減
  - 很多人先付是為了**避免利息**或不確定是否過高，先付再請法院判斷（停損）
  - 先付反而喪失酌減機會 → 等於逼大家不要付，結果違約金若不過高反而要付更多
  - 我國沒有德國法那一句
- **顏佑紘**（字幕作「嚴幼紅」，建議查證姓名）：看當事人有無**拋棄酌減權**的意思
  - 付款時表示「付了就算了，不再主張酌減」→ 不得再酌減
  - 沒有拋棄的意思（先付再減）→ 縱屬任意給付，仍得酌減

## 酌減後的效果：
- 多付的部分依**不當得利**請求返還

## 📖 法條原文速查

> **§252**　約定之違約金額**過高**者，**法院**得減至相當之數額。

> **德國民法 §343 I 第 3 句**（講義 543 頁）：違約金**給付後**，不得酌減。→ 我國無此規定

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§252 酌減只適用於懲罰性違約金？」 | **錯**，總額性也適用 |
| 「違約金是否過高由誰判斷？」 | **法院**職權判斷 |
| 「定作人扣尾款抵充違約金，承攬人可否請求酌減？」 | **可以**，非任意給付（實務） |
| 「已任意給付違約金，可否酌減？」 | 實務：原則否；黃茂榮：可；顏佑紘：看有無**拋棄酌減權** |
| 「否定說的依據？」 | 德國民法 **§343** |
| 「酌減後如何拿回多付的錢？」 | **不當得利** |

## 已付違約金能否酌減

| 見解 | 任意給付 | 非任意給付 |
|---|---|---|
| 否定說（德國法） | 不可 | 不可 |
| 實務 | 不可 | **可** |
| 黃茂榮 | **可** | **可** |
| 顏佑紘 | 未拋棄酌減權即可 | 未拋棄酌減權即可 |

```
工程款 700 萬 ── 乙扣違約金 500 萬 ──→ 甲只拿到 200 萬
                                        │
                        法院酌減至 100 萬 → 甲依 §179 請求返還 400 萬
```
