# 民法39 筆記：承攬人抵押權（§513）

## 從法定到強制性意定：
- 承攬採**報酬後付**，承攬人做完才拿錢，所以需要擔保
- **89 年修法前**：條文寫「有抵押權」→ 法定抵押權，不須登記
- 問題：沒有登記外觀，後來的銀行以為自己是第一順位，其實前面躲著一個法定抵押權 → **有害交易安全**
- **修法後**：承攬人「得**請求定作人為抵押權之登記**」→ 只有請求權，**登記後才有抵押權**，稱**強制性意定抵押權**
- 和一般意定不同：定作人不一定願意，但承攬人可以請求、可以起訴

## 四項重點：
- I：建築物、土地上工作物或其**重大修繕**；就報酬額請求登記；將來完成的不動產可請求**預為抵押權登記**
- II：**開始工作前**也可以請求
- III：承攬契約**經公證** → 承攬人可**單獨申請**登記；未公證就要起訴、判決確定後才去登記
- IV：**修繕**報酬的抵押權，在**修繕增加的價值限度內**，優先於成立在先的抵押權

## 實務提醒：
- 很多人以為還是「有抵押權」；老師辦過安養中心承攬案，契約已公證卻沒去登記，請求報酬時只剩普通債權

## 算一次（IV 項後來居上）：
- A 屋市價 1,000 萬，已設定第一順位抵押權給乙，擔保 800 萬
- 地震後 A 屋剩 600 萬；甲找丙修繕，報酬 250 萬，修完回到 900 萬 → **增值 300 萬**
- 丙依 §513 登記抵押權；A 屋拍得 900 萬

| 價值區塊 | 金額 | 分配 |
|---|---|---|
| 修繕增加部分 | 300 萬 | 丙優先 250 萬，餘 50 萬給乙 |
| 原有價值 | 600 萬 | 乙 600 萬 |
| 合計 | 900 萬 | 乙 650 萬、丙 250 萬 |

- 若沒有 IV 項：乙先拿 800 萬，丙只剩 100 萬
- 新建工程不需要 IV 項：房子蓋好前沒人能設抵押，承攬人預為登記本來就是第一順位

## 小爭點：「定作人之不動產」
- 甲把大樓拉皮工程包給乙，乙再分包水電給丙（次承攬人）
- 乙對 A 屋有 §513 請求權；丙的定作人是**乙**，A 屋不是乙的 → 丙**沒有** §513 抵押權
- 房子蓋一半被法拍給第三人，新的承攬人與新所有人間無承攬契約 → 不能就該屋請求設定

## 📖 法條原文速查

> **§513**（承攬人之抵押權）
> I 承攬之工作為建築物或其他土地上之工作物，或為此等工作物之**重大修繕**者，承攬人得就承攬關係報酬額，對於其工作所附之**定作人之不動產**，**請求**定作人為抵押權之登記；或對於將來完成之定作人之不動產，請求**預為**抵押權之登記。
> II 前項請求，承攬人於**開始工作前**亦得為之。
> III 前二項之抵押權登記，如承攬契約已經**公證**者，承攬人得**單獨申請**之。
> IV 第一項及第二項就**修繕報酬**所登記之抵押權，於工作物因修繕所**增加之價值限度內**，優先於成立在先之抵押權。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「承攬人抵押權不登記即發生？」 | **否**，現行法為請求登記，登記始生效 |
| 「開工前可否請求登記？」 | **可以**（II） |
| 「承攬契約經公證之效果？」 | 承攬人得**單獨申請**登記（III） |
| 「修繕報酬抵押權優先於先成立之抵押權？」 | 僅在**修繕增加價值限度內**（IV） |
| 「次承攬人可否就業主房屋請求 §513 登記？」 | **不可**，非其定作人之不動產 |
| 「新建工程報酬可否後來居上？」 | IV 只規定**修繕**；新建本來就是第一順位 |

## 體系圖

```
承攬人報酬擔保
├─ 舊法：法定抵押權（無登記外觀，害交易安全）
└─ 現行 §513：請求定作人登記（強制性意定抵押權）
     ├─ 客體：定作人之不動產（含將來完成者，預為登記）
     ├─ 時點：開工前即可
     ├─ 程序：公證 → 單獨申請；未公證 → 訴請協同登記
     └─ 次序：修繕增值限度內優先於先成立之抵押權
```
