# 民法08 筆記：愛情保險單（葉啟洲）——假交友騙人買保險，是單純動機錯誤，§88 不行、§92 也不行（通說可）

> 來源：民法08 課程字幕 00:27:30 ~ 00:35:00（講義 193 頁〈愛情保險單與愛情靈骨塔〉；侵權、不當得利部分債編再講）

---

## 📖 法條原文速查

> **§88 I、II**　內容錯誤、表示行為錯誤得撤銷；人之資格、物之性質交易上重要者視為內容錯誤。
> **§92 I**　**因**被詐欺**而**為意思表示者，表意人得撤銷其意思表示。
> **§184**、**§179**　侵權行為、不當得利（後續救濟，債編再談）

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「保險業務員以虛擬帳號在交友軟體與甲交往，誘使甲向其購買 200 萬保單，甲得否依 §88 撤銷？」 | **不得**。甲要買保險、也買了保險，沒有內容錯誤或表示行為錯誤；「為了跟對方發展」是**單純動機錯誤**，非人的資格、物的性質 |
| 「得否依 §92 撤銷？」 | **通說：得**（§92 的錯誤含動機錯誤，騙人者無保護必要）。**葉啟洲：不得**——§92 的「錯誤」與 §88 同，不含單純動機錯誤；單純動機上的詐騙不能認為是被詐欺的意思表示，否則過度保護表意自由、影響交易安全 |
| 「不能撤銷時如何救濟？」 | 侵權行為、不當得利（葉啟洲文章的後半，債編再講） |

## 一、故事
```
兩個保險業務員在交友軟體創虛擬男性角色「林○廷」→ 物色中年婦女 → 戀愛腦後說服
「你要好好規劃人生、買個保險，我朋友是很厲害的業務」→ 朋友就是他自己
→ 甲一次繳清 200 多萬保費 → 之後「林○廷」避不見面 → 發現受騙
```

## 二、這是哪一種錯誤
```
甲知道自己在買保險、也買了保險 → 不是內容錯誤（不是要買意外險買成壽險）、不是表示行為錯誤
甲錯在：以為買了保險對方會繼續交往 → 動機
這個動機交易上重要嗎？不是人的資格、不是物的性質 → 單純動機錯誤
→ §88 一定不行
```

## 三、§92 可不可以：通說 vs 葉啟洲

| | 通說 | 葉啟洲 |
|---|---|---|
| §92「因被詐欺而陷於錯誤」的錯誤 | 含一般動機錯誤。只要影響你的動機也是詐欺 → 可撤 | 與 §88 同，**不含單純動機錯誤** |
| 理由 | 騙人的相對人無保護必要 | 單純動機上的詐騙若可隨便撤，影響交易安全、過度保護表意自由；「你知道你要買這個，你也買了這個」 |
| 本案 | 撤銷 → 不當得利要回保費，結束 | 不能撤 → 文章才有後半：侵權行為、不當得利怎麼走 |
