# 民法18 筆記：§196物之毀損與交易性貶值

## §192～§196 的體系：
- 依被侵害客體分：**生命權**（§192、§194）、**身體健康權**（§193、§195）、**其他人格權**（§195）、**物之毀損**（§196）
- 可否當請求權基礎：王澤鑑認為只是損害賠償**範圍**規定，不能單獨作請求權基礎；老師認為 §192 有直接主張的空間（見下一份）

## §196 只管毀損、不管滅失：
- 條文用語只有「毀損」→ 車子撞壞**可修** → 有 §196；撞成廢鐵（**滅失**）→ 無 §196
- 滅失：依 §215 請求**買價**，範圍依 §216

## 因毀損所減少之價額：
- 就算修好也回復不了的價值減少，立法者明文讓被害人請求
- **交易性貶值**：出過事故就是事故車，修得再好，市價仍只有一般車的八、九折
- **技術性貶值**：未回原廠修、改用副廠零件，品質未必較差，但市場評價仍會下跌

## 毀損案件的三段思考：
- ① §184 確定要賠 → ② §213 選回復原狀或必要費用（兩者沒差）→ ③ 範圍：§216 所受損害、所失利益，加上 §196 的貶值

> 來源：民法18 課程字幕 02:16:25 ~ 02:27:54；02:24:53 老師先說貶值是「所失利益」，隨即改口為「所受損害」（財產價值減少），筆記依改口；02:22:02～02:22:56 老師當場改寫板書，字幕片段較零碎

## 📖 法條原文速查

> **§196**　不法**毀損**他人之物者，被害人得請求賠償其物因毀損所**減少之價額**。

> **§215**　不能回復原狀或回復顯有重大困難者，應以金錢賠償其損害。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「車輛遭撞毀成廢鐵，被害人得否依 §196 請求減少之價額？」 | **否**，§196 限**毀損**；滅失依 §215 請求買價 |
| 「車輛修復後仍屬事故車、市價下跌，得否請求？」 | **得**，§196 交易性貶值 |
| 「以副廠零件修復致市價下跌，得否請求？」 | **得**，技術性貶值 |
| 「§192～§196 適用於何種損害賠償？」 | **侵權行為**；債務不履行須準用（§227-1） |
| 「依王澤鑑，§192～§196 得否單獨作為請求權基礎？」 | **否**，屬範圍規定 |

## 一、§192～§196 體系

```
侵權行為損害賠償範圍之特別規定
├─ 生命權受侵害（致死）
│   ├─ 財產上：§192（支出費用之人、法定扶養權利人）
│   └─ 非財產上：§194（父母子女配偶）
├─ 身體健康權受侵害
│   ├─ 財產上：§193（勞動能力、增加生活上需要）
│   └─ 非財產上：§195 I
├─ 其他人格權受侵害：§195
└─ 物之毀損：§196（減少之價額）
```

## 二、毀損與滅失

| | 毀損 | 滅失 |
|---|---|---|
| 能否回復 | 能（可修） | 不能 |
| 方法 | §213 回復原狀／必要費用 | §215 金錢（買價） |
| 範圍 | §216＋**§196 貶值** | §216 |
| §196 | ✓ | ✗（不再交易，無貶值可言） |

## 三、兩種貶值

| | 交易性貶值 | 技術性貶值 |
|---|---|---|
| 原因 | 事故紀錄本身 | 修復技術差異（副廠零件） |
| 例 | 100 萬的車，修好仍只值八、九折 | 非原廠修復，市場評價下跌 |
| 能否靠修理回復 | 不能 | 不能 |
| 依據 | §196 減少之價額 | 同左 |

## 四、毀損案件三段思考

```
① 責任成立：§184 → 對方要賠
        ↓
② 方法：§213 回復原狀 或 必要費用（擇一，沒差）
        ↓
③ 範圍：§216 所受損害＋所失利益
         ＋ §196 交易性貶值、技術性貶值（修好也回不來的部分）
```
