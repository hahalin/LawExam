# 民法02 筆記：監護宣告 §14 §15

> 來源：民法02 課程字幕 00:00:04 ~ 00:18:29

---

## 📖 法條原文速查

> **§14**（監護之宣告）
> I 對於因**精神障礙或其他心智缺陷**，致**不能**為意思表示或受意思表示，或**不能辨識**其意思表示之效果者，法院得因**本人、配偶、四親等內之親屬、最近一年有同居事實之其他親屬、檢察官、主管機關、社會福利機構、輔助人、意定監護受任人或其他利害關係人**之聲請，為監護之宣告。
> II 受監護之原因消滅時，法院**應**依前項聲請權人之聲請，**撤銷**其宣告。
> III 法院對於監護之聲請，認為**未達第一項之程度**者，得依第十五條之一第一項規定，為**輔助之宣告**。
> IV 受監護之原因消滅，而**仍有輔助之必要**者，法院得依第十五條之一第一項規定，**變更為輔助之宣告**。

> **§15**（受監護宣告人之能力）
> 受監護宣告之人，**無行為能力**。

> **§75**（無行為能力人及無意識能力人之意思表示）
> 無行為能力人之意思表示，**無效**；雖非無行為能力人，而其意思表示，係在**無意識或精神錯亂中**所為者亦同。

> **§1111 I**（監護人之選定）→ 由法院選定監護人（身分法再細講）
> → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「監護宣告之主觀要件？」 | 精神障礙／心智缺陷 → **不能**為、受、辨識意思表示（§14 I）。只是「顯有不足」→ 做輔助宣告 |
| 「聲請監護宣告，法院認未達不能程度？」 | **得依職權改為輔助宣告**（§14 III），不受聲明拘束；認為正常 → **駁回** |
| 「受監護宣告後精神恢復，但未撤銷，所為買賣？」 | 仍是**無行為能力人**，法律行為**無效**（§15、§75）。要先撤銷，行為能力才回來 |
| 「聲請撤銷監護宣告，法院認仍有輔助必要？」 | **得變更為輔助宣告**（§14 IV）；認仍不能 → 駁回撤銷；認正常 → 撤銷 |
| 「15 歲限制行為能力人可否受監護宣告？」 | **可**。對象＝完全＋限制行為能力人；**無行為能力人**（未滿 7 歲）無實益、不是對象 |
| 「意定監護受任人／輔助人／其他利害關係人可否聲請監護宣告？」 | **可**（108 年新增）。但這三種人**不能**聲請輔助宣告 |
| 「受監護宣告之人意識清楚時可否結婚？」 | **可**。身分行為看意思能力，不套行為能力制度 |

## 一、為什麼要有這個制度

```
行為能力採【客觀年齡標準】
    7 歲天才   → 仍無行為能力
    失智成年人 → 仍完全行為能力  ← 財產被騙走怎麼辦？
         ↓
民國 97 年前：禁治產宣告（只有一刀：100 分 → 0 分，欠缺彈性）
民國 97 年後：雙軌制
    監護宣告 → 0 分（剝奪）        §14 用語「不能」
    輔助宣告 → 中間（限制）        §15-1 用語「顯有不足」
```

## 二、要件三個：不能 ＋ 聲請 ＋ 法院宣告

### （一）主觀要件：到達「不能」
- 不能為意思表示／不能受意思表示／不能辨識意思表示之效果。
- 判斷方式：法院指定醫院的醫生鑑定（有時社工、療養院人員）。
- 還會「去巷口買麵、一手交錢一手交貨」→ 沒到「不能」→ 法院多半只做輔助宣告（行為能力與生俱來，國家不能任意剝奪）。

### （二）經聲請：聲請權人兩組

| 組別 | 聲請權人 | 備註 |
|------|---------|------|
| 基本款（舊法即有） | 本人、配偶、四親等內親屬、最近一年有同居事實之其他親屬、檢察官、主管機關、社會福利機構 | **輔助宣告只有這一組** |
| 108 年新增 | ① 意定監護受任人 ② 輔助人 ③ 其他利害關係人 | **只有監護宣告有** |

- **意定監護受任人**：配合 108 年意定監護修法。一般監護人由法院依 §1111 選；意定監護是本人意識清楚時先選好，法院受拘束。既然是自己選的人，當然給他聲請權。
- **輔助人**：原本只做輔助宣告，輔助一段時間發現「連走到巷口都迷路、買麵忘記付錢」→ 輔助人可聲請改為監護宣告。
- **其他利害關係人**（老師說沒考過但可能考）：
  ```
  甲、乙訂 A 地買賣契約，約半年後過戶（等貸款）
  半年內甲車禍成植物人 → 不能為意思表示、又沒被監護宣告 → 沒有監護人替他履行
  → 乙是利害關係人 → 聲請對甲為監護宣告 → 法院選監護人 → 監護人代為、代受意思表示履約
  ```
  考點：**契約訂立後、履行前**當事人喪失辨識能力 → 相對人透過聲請監護宣告解套。

### （三）法院宣告：三種可能結果

```
聲請監護宣告 → 法院審查
    ├── 不能        → 監護宣告（§14 I）
    ├── 顯有不足    → 職權改為輔助宣告（§14 III）【聲明不拘束法院】
    └── 正常／裝瘋  → 駁回聲請
```

## 三、效果：無行為能力（§15）→ 法律行為無效（§75）

- 先分類（這個人是誰）→ 再看他做的行為效力如何（第二階段）。
- **例外：身分行為**。結婚只看有無意思能力；受監護宣告人意識恢復（即使尚未撤銷）仍有結婚能力。
  - 理由：行為能力制度是為交易安全；身分行為多不涉交易安全，身分法有自己一套規則。

## 四、撤銷：法院重新判斷一遍

```
聲請撤銷監護宣告 → 法院重新鑑定
    ├── 仍不能        → 駁回撤銷（維持監護宣告）
    ├── 變成不足      → 變更為輔助宣告（§14 IV）
    └── 恢復正常      → 撤銷（§14 II）→ 回復原本行為能力
```

- 考試裡「積極治療、按時服藥、狀況好轉」= 暗示撤銷議題。
- **未撤銷前仍是無行為能力人**，不因事實上恢復而自動變回來。

## 五、對象：誰可以被監護宣告

| 原本身分 | 監護宣告 | 輔助宣告 |
|---------|---------|---------|
| 完全行為能力人 | ✓ | ✓ |
| 限制行為能力人（7～18 歲） | ✓（如 15 歲國中生心智不能辨識） | ✗（他能做的本來就比受輔助宣告人少，無實益） |
| 無行為能力人（未滿 7 歲） | ✗（本來就 0 分，再剝奪沒意義） | ✗ |

- 依據：§15-1 立法理由第七點（講義 35 頁註 42）：輔助宣告適用對象為有行為能力人；限制／無行為能力人無受輔助宣告之實益。
