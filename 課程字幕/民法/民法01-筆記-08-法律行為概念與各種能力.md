# 民法01 筆記：法律行為的概念與各種「能力」（§12、§13）

> 來源：民法01 課程字幕 02:02:00 ~ 02:31:00

---

## 📖 法條原文速查

> **§12**（成年）
> 滿**十八歲**為成年。（112/1/1 施行，舊法 20 歲）

> **§13**（行為能力）
> I **未滿七歲**之未成年人，**無**行為能力。
> II **滿七歲以上**之未成年人，有**限制**行為能力。
> （舊 III「未成年人已結婚者有行為能力」已刪除）

> **§71**（違反強制禁止規定）
> 法律行為，違反強制或禁止之規定者，無效。→ 條文有「法律行為」四字但沒定義

> **§77**（限制行為能力人之意思表示）→ 見「請求權基礎」筆記

> **§187 I**（無行為能力人／限制行為能力人之侵權責任）
> 無行為能力人或限制行為能力人，不法侵害他人之權利者，以行為時有**識別能力**為限，與其法定代理人連帶負損害賠償責任。

> **§802**（無主物先占）
> 以所有之意思，占有無主之動產者，除法令另有規定外，取得其所有權。

> **§811**（動產附合於不動產）
> 動產因附合而為不動產之重要成分者，不動產所有人，取得動產所有權。

> **§1147、§1148 I**
> 繼承，因被繼承人死亡而開始。繼承人自繼承開始時，承受被繼承人財產上之一切權利、義務。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律行為之定義？」 | 以**意思表示**為要素，對外發生一定法律效果之法律事實 |
| 「繼承是事實行為？」 | **否**。繼承**不是行為**（人死自然發生的狀態），不可能是事實行為 |
| 「無主物先占、添附是？」 | **事實行為**：有行為即生效果，不需意思表示 |
| 「15 歲甲未經父母同意加入學生會，效力？」 | 加入學生會**不生法律上權利義務**→連法律事實都不是→**不適用 §77**，有效與否根本不是問題 |
| 「80 歲完全失智老人，未受監護宣告，有無行為能力？」 | **有**（滿 18 歲、未受宣告）。行為能力採**客觀**標準：年齡 + 有無宣告 |
| 「30 歲精神正常但受監護宣告？」 | **無行為能力**。只看客觀的宣告，不看主觀狀態 |
| 「有行為能力但無識別能力，可能嗎？」 | **可能**。識別能力（§187）、意識能力（身分行為）採**主觀**個案認定 |
| 「『未滿 18 歲』vs『18 歲以下』？」 | 以上、以下**含本數**；未滿**不含**。未滿 18 ≠ 18 以下 |
| 「對限制行為能力人可否為監護宣告？」 | **可**；對無行為能力人則無意義 |

## 一、生活事實的分類樹（法律行為在哪裡）

```
生活事實（刷牙、上課、吃飯、買車、死亡……）
│
├── 非法律事實：不產生權利義務 → 法律不管（刷牙、參加運動會、加入學生會）
│
└── 法律事實：會產生／變動權利義務
    │
    ├── 非行為：「自然而然」發生的事件或狀態
    │     例：繼承（人死即生，§1147）、時效完成、出生、死亡
    │
    └── 行為：需藉人的行為才發生
          │
          ├── 非表示行為 = 事實行為：不需意思表示，做了就生效
          │     例：§802 無主物先占、§811 以下添附
          │
          └── 表示行為：以意思表示為要素
                ├── 法律行為：效果由當事人意思決定（買賣、贈與、結婚、移轉所有權）
                └── 準法律行為：效果由法律直接規定（催告、通知、觀念通知）
```

### 法律行為的定義
> 以**意思表示**為要素，對外發生一定法律效果的**法律事實**。

- 意思表示 = 意思（內心想發生的法律效果）+ 表示（表現於外）。
- 把手錶交到你手上，這個動作本身**空洞**；加上「移轉所有權的讓與合意」才變成物權行為，加上「借你用」就是借貸，加上「送你」就是贈與。→ 行為 + 意思表示 = 法律行為。

### 事實行為 vs 非行為（老師特別提醒會混）

| | 事實行為 | 非行為 |
|---|---|---|
| 是行為嗎 | **是** | **不是** |
| 需意思表示 | 不需 | — |
| 例 | 先占、添附 | **繼承**、時效 |

> 「繼承是一個事實」→ 很多人接著說「所以是事實行為」→ **錯**。繼承連行為都不是。

### 案例：加入學生會（一試考過）
- 15 歲甲未經父母同意加入學生會，效力？
- 錯誤思路：§77 但書「日常生活所必需」→ 有效。
- 正確思路：**先定性**。加入學生會在法律上有權利義務嗎？沒有 → 非法律事實 → 根本不是法律行為 → **§77 無從適用**，想做就做。
- 同理：5 歲小孩參加幼稚園 20 公尺賽跑不需父母同意，因為不是法律行為。

## 二、四種「能力」

| 能力 | 意思 | 判斷標準 | 條文 |
|------|------|------|------|
| **權利能力** | 享受權利負擔義務的資格 | 活著就有 | §6 |
| **行為能力** | 做**法律行為**的資格 | **客觀**：年齡 + 有無監護／輔助宣告 | §12、§13～§15-2 |
| **識別能力**（責任能力） | 認識自己行為可能發生損害結果的能力 | **主觀**：個案認定 | §187 |
| **意識能力** | 認識身分行為意義的能力（知道結婚、離婚、認領是什麼） | **主觀**：個案認定 | 無明文 |

### 為什麼行為能力採客觀標準？——交易安全 = 降低查證成本

```
如果行為能力看主觀（這個人懂不懂）
    → 每筆交易都要個案查對方腦袋 → 查證成本極高 → 沒人想交易
    → 法律變成經濟的絆腳石

所以立法者說：只看兩件事
    ① 幾歲   ② 有沒有受宣告
    → 身分證上都有 → 一看就知道 → 查證成本低 → 交易安全
```
> 銀行開戶、買保險、補習班報名都要看身分證，就是在查這兩件事。

### 為什麼識別能力、意識能力採主觀標準？
- 侵權行為、身分行為**與交易安全無關**，純粹是個人要不要負責、要不要發生身分關係 → 可以要求個案查證（你要跟他結婚，查他懂不懂結婚不難）。

### 結果：行為能力與識別能力可以脫鉤

| 題目 | 行為能力 | 識別能力 |
|------|------|------|
| 30 歲，精神分裂無法認識行為結果，未受宣告 | **有**（客觀：滿 18、無宣告） | **無**（主觀） |
| 30 歲，精神正常，受監護宣告 | **無**（客觀：有宣告） | 有 |
| 80 歲完全失智，家人未聲請宣告 | **有** | （視個案） |

> 有行為能力 ≠ 法律行為一定有效，仍要逐一看各要件。這裡只在學「分類標準」。

## 三、行為能力的分類標準（§12、§13）

```
未成年（未滿 18，§12 反面）
├── 未滿 7 歲 ──────────────→ 無行為能力（§13 I）
└── 滿 7 歲 ────────────────→ 限制行為能力（§13 II）
        └── 可受監護宣告 → 變無行為能力

成年（滿 18，§12）────────────→ 有（完全）行為能力
        ├── 受監護宣告 → 無行為能力（§14、§15）
        └── 受輔助宣告 → 特定行為須輔助人同意（§15-1、§15-2）
```

### 民總把行為能力拆在兩處

| 區塊 | 條文 | 在教什麼 |
|------|------|------|
| 前段 | §13～§15-2 | **人的分類標準**：這個人是哪一種能力的人 |
| 後段 | §75～§85 | **各種人做法律行為的效果** |

→ 第一階段只需判斷「他是哪種人」，先不管行為有沒有效。

### 用語陷阱：未滿 vs 以下

| 用語 | 含本數？ | 例 |
|------|------|-----|
| 以上 / 滿 | **含** | 「滿 7 歲」= 「7 歲以上」 |
| 以下 | **含** | 「18 歲以下」含 18 歲 |
| 未滿 | **不含** | 「未滿 7 歲」≠ 「7 歲以下」 |

- §13 I 是「**未滿**七歲」，寫成「七歲以下」意思就錯了。
- 「以上、以下俱連本數計算」：刑法 §10 I 有明文；老師提及中央法規標準法亦同此理 → 建議查閱。
