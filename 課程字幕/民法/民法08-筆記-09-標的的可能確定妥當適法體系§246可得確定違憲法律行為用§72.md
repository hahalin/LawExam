# 民法08 筆記：標的的四要件——可能（§246）、確定（可得確定即可）、妥當（§72 §74）、適法（§71）；違憲的法律行為用 §72 不用 §71

> 來源：民法08 課程字幕 01:01:00 ~ 01:13:00（講義 211 頁註 158）

---

## 📖 法條原文速查

> **§246 I**　以不能之給付為契約標的者，其契約為無效。但其不能情形可以除去，而當事人訂約時並預期於不能之情形除去後為給付者，其契約仍為有效。
> **§71**　法律行為，違反強制或禁止之規定者，無效。但其規定並不以之為無效者，不在此限。
> **§72**　法律行為，有背於公共秩序或善良風俗者，無效。
> **§74 I**　法律行為，係乘他人之急迫、輕率或無經驗，使其為財產上之給付或為給付之約定，依當時情形顯失公平者，法院得因利害關係人之聲請，撤銷其法律行為或減輕其給付。

---

## 📋 實務見解速查

> 最高法院（講義 211 頁註 158，字號請查）：法律行為之標的於成立時須確定，始能發生效力；若未確定，內容無從具體實現。於成立時**可得確定**者（由雙方另行確定、一方或第三人確定、依法律、習慣或其他特別情事確定）雖非無效；倘盡各種可得確定之方法仍無從確定，仍因標的無從確定而無效。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律行為標的之一般生效要件？」 | **可能、確定、妥當、適法** |
| 「可能、確定在民總有無規定？」 | **無**。可能看債編 **§246**（自始客觀不能無效）；確定依解釋，**可得確定**即可 |
| 「抽獎單只寫外號『大熊』，無任何聯絡資料？」 | 得獎人**無從確定** → 不生效力 → 重抽 |
| 「約定買『一支手機』？」 | 無法確定 → 不生效力；「你手上那支二手手機」→ 可得確定 → 有效 |
| 「契約內容侵害憲法基本權（言論自由、遷徙自由），依何條無效？」 | **§72**。憲法不是 §71 的「法律」層次的強制禁止規定；但憲法精神是公序良俗的具象化 → 違憲＝違反公序良俗 |

## 一、體系
```
法律行為一體多面：行為能力、意思表示、標的，各自檢驗（無行為能力人被脅迫賣毒品：§75 無效／§92 可撤／§71 無效 → 撤銷無實益）
標的四要件：
  可能 → §246（債編）：事實上與法律上都做得到。例外：不存在權利之買賣（債編再講）
  確定 → 可得確定即可（註 158）
  妥當 → §72 公序良俗、§74 暴利行為
  適法 → §71 強行規定
```

## 二、可能
- 標的須是可以實現的作為、不作為、財產給付或身分關係；事實上不能或法律上不能 → 無效。
- §246 細節（含不能情形可除去之例外）在債編。

## 三、確定：可得確定就好，不必特定
| 情形 | 可得確定？ |
|------|------|
| 抽獎單只寫外號「大熊」，沒電話沒資料 | ✗ → 重抽 |
| 「我要跟你買一支手機」 | ✗（世界上手機這麼多） |
| 「我要買你手上那支二手手機」 | ✓ |
| 「叫一批貨」但品項可依習慣、約定方式確定 | ✓ |

## 四、違憲的法律行為：§71 還是 §72
```
憲法只說保障你什麼權利，沒有「法律行為違憲者無效」這條
§71 的「強制或禁止之規定」是【法律】層次，憲法層次更高、不在其中 → 不能用 §71
憲法精神＝公共秩序善良風俗的具象化 → 違憲的法律行為違反公序良俗 → 用 §72 無效
```
- 老師：很小的爭點，但要知道「把基本權當公序良俗，不能把憲法當一般法律規定」。
