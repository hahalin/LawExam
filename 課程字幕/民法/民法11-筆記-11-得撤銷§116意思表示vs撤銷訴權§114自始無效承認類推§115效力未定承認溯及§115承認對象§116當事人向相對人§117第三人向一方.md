# 民法11 筆記：§114～§117 得撤銷與效力未定——撤銷方法：以意思表示為之（§116，依 §94／§95 生效時發生撤銷效果）vs 撤銷訴權（§56、§74、§244「聲請法院撤銷之」，判決確定始生效）；撤銷效力 §114 視為自始無效、準用 §113；得撤銷之法律行為經承認，類推 §115 自始有效（王澤鑑）；效力未定：承認溯及法律行為時生效（§115：9/5 締約、10/5 承認 → 9/5 生效）；承認對象：當事人為之向相對人（§116），第三人為之得向當事人之一方（§117）——無權代理本人甲是當事人，承認應向丙不是向乙

> 來源：民法11 課程字幕 01:34:40 ~ 01:44:10

## 📖 法條原文速查

> **§114**　I 法律行為經撤銷者，視為自始無效。II 當事人知其得撤銷或可得而知者，其法律行為撤銷時，準用前條之規定。
> **§115**　經承認之法律行為，如無特別訂定，溯及為法律行為時發生效力。
> **§116**　I 撤銷及承認，應以意思表示為之。II 如相對人確定者，前項意思表示，應向相對人為之。
> **§117**　法律行為須得第三人之同意始生效力者，其同意或拒絕，得向當事人之一方為之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§88、§92 之撤銷如何為之？何時生效？」 | 以**意思表示**為之（§116 I）；對話了解時、非對話到達時生效（§94、§95）→ 撤銷效果即發生 |
| 「§56、§74、§244 之撤銷？」 | 條文寫「**聲請法院撤銷之**」→ **撤銷訴權**，須提起撤銷訴訟，**判決確定**時始生撤銷效果 |
| 「撤銷之效力？」 | §114 I **視為自始無效**；§114 II 準用 §113（損害賠償、回復原狀，性質爭議同筆記 10） |
| 「被詐欺人承認該法律行為，效力？」 | 承認＝**拋棄撤銷權** → 類推 **§115** → 法律行為自始有效，不得再撤銷（王澤鑑等）。承認不只用在效力未定，也可用在得撤銷 |
| 「限制行為能力人甲與乙於 9/5 訂約，法定代理人 10/5 承認，契約何時生效？」 | **9/5**（§115 溯及為法律行為時生效），不是 10/5 |
| 「效力未定之承認或拒絕向誰為之？」 | 由**當事人**為之（本人自己）→ **§116 II 應向相對人**。由**第三人**為之（法定代理人、無權處分之權利人）→ **§117 得向當事人之一方** |
| 「乙無權代理甲與丙締約，甲行使承認權得向乙為之？」 | **錯**。甲是法律行為當事人 → §116 II **應向相對人丙**為之；向乙承認沒有意義 |

## 一、得撤銷的法律行為

| | 以意思表示撤銷 | 撤銷訴權 |
|---|---|---|
| 條文 | §88、§92 等（§116） | §56、§74、§244 等「聲請法院撤銷之」 |
| 生效 | 意思表示生效時（§94 了解、§95 到達） | 撤銷判決確定時 |
| 效力 | §114 視為自始無效；準用 §113 | 同 |

- 得撤銷的法律行為可否承認？可。承認＝拋棄撤銷權 → 類推 §115 → 自始有效。

## 二、效力未定的法律行為

```
承認 → 發生效力，溯及法律行為時（§115）→ 9/5 締約、10/5 承認 → 9/5 生效（選擇題考時間點）
拒絕 → 確定不生效力
```

### 承認向誰為之

| 情形 | 承認人身分 | 條文 | 對象 |
|---|---|---|---|
| §79 限制行為能力人契約 | 法定代理人（第三人） | §117 | 甲或乙任一方 |
| §118 無權處分 | 權利人（第三人） | §117 | 乙或丙任一方 |
| §170 無權代理 | 本人甲（**當事人**） | §116 II | **應向相對人丙** |

- §117 寫「當事人之**一方**」：一個人就可以。§116 II 寫「**應**向相對人」：相對人確定時只能向他。
