# 民法36 筆記：法人占有與雙重無權占有（§767）

## 無權占有的兩個要件：
- ① **占有的事實**：對方要先占有，才談得上無權占有
- ② **欠缺占有權源**
- 先確認占有，再討論有權無權；東西不在被告手上，就不能請求他返還
- 老師的旁聽經驗：兩造都沒請律師打「返還本票」，被告只抗辯「本票不在我這裡」—— 前提錯了，請求就落空
- 答題時自己判斷東西現在在誰手上，再決定告誰
- 侵奪：以外力破壞占有、把東西拿走，是一種事實

## 爭議一：董事替法人占用土地，要告誰：
- 甲的 A 地荒廢多年，B 法人在旁邊蓋工廠，董事乙把 A 地圈起來給員工停車
- 董事是法人的**代表人**，董事的行為就是法人的行為
- 對 A 地有事實上管領力的是 **B 法人** → 甲應對 B 法人主張 §767 I 前段，不是對董事乙
- 司法官考試考過類似題（年度約 100 年，建議查證）

## 爭議二：雙重無權占有：
- 甲的 A 地被乙無權占有蓋了 B 屋，B 屋又被丙無權占有
- 問題：占有 B 屋的丙，是否同時占有 A 地？甲可否對丙主張 §767（還地）、§179（相當於租金之不當得利）
| | 肯定說 | 否定說 |
|---|---|---|
| 判決 | 103 台上 2578 | 102 台上 232（字號建議查證） |
| 起手式 | 建築物不能脫離土地而存在 | 建築物不能脫離土地而存在 |
| 推論 | 占有房屋者必然使用基地 → 同時是土地占有人 | 使用基地的是**房屋所有人**，房屋使用人只占有房屋 |
| 甲對丙 | 可請求遷出、返還相當租金之利益 | 不可；甲應找乙，乙再找丙 |
- 注意：就算採肯定說，也只能請求丙**還地（遷出）**，**不能請求丙拆屋**
  - 拆屋要找對房屋有**事實上處分權**的人（乙），法院不能命丙去拆乙的房子

## 大法庭程序：提案裁定不等於最終見解：
- 最高法院 110 年度台上字第 932 號提案裁定（字號建議查證）：問題一，非建物所有人或事實上處分權人的建物占有人，是否同時是土地占有人；問題二，是否構成不當得利
- 大法庭三階段：**徵詢** → 意見一致就結束；不一致才**提案** → **大法庭裁定**
- 提案庭「本庭擬採之法律見解」是**肯定說**，但只是提案法官的見解
- 前例：法人能否請求非財產上損害，提案擬採否定說，大法庭最後採肯定說

## 📖 法條原文速查

> **§767 I 前段**　所有人對於**無權占有或侵奪**其所有物者，得請求返還之。

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

> **§27 II**　董事就法人一切事務，對外代表法人。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **103 台上 2578（肯定說）**：建築物不能脫離土地而存在，建築物之占有人當然使用其坐落之土地，應認為土地之占有人。

> **102 台上 232（否定說）**：使用房屋必須使用基地，但占有基地者為房屋所有人而非使用人；無權占有土地建屋而獲利益者為建物所有人（受害人為土地所有人），無權占有房屋而獲利益者為房屋占有人（受害人為房屋所有人）。→ 字號依字幕「102 年度 232 號」，建議查證

> **110 台上 932 提案裁定**：提案擬採肯定說，大法庭尚未裁定。→ 建議查證最新進度

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事為法人無權占用他人土地，土地所有人應對誰請求返還？」 | **法人** |
| 「請求返還之前提？」 | 被告須**現在占有**標的物 |
| 「雙重無權占有，土地所有人得請求房屋占有人拆屋？」 | **不得**，拆屋須對有事實上處分權人 |
| 「雙重無權占有，肯定說下得請求房屋占有人？」 | 還地（遷出）、不當得利 |
| 「提案裁定之擬採見解即為大法庭見解？」 | **否** |
