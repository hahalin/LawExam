# 民法二試03 筆記：回復名譽之適當處分與刊登判決（§195 I 後段）

## 背景（補充二試01 講義第 3 頁強制道歉案）：
- 甲侵害乙名譽 → 乙依 §184 I 前段＋§195 I 後段請求「回復名譽之**適當處分**」
- 釋字 656：命登報道歉合憲 → **111 年憲判字第 2 號**：強制道歉違憲，不得再以此為適當處分
- 現行實務改以**刊登判決**為之；單純把判決刊在報紙上，原則沒有問題（判決本來就公開）

## 進階爭點：刊登判決的方式
- **具名刊登**（啟事加註「刊登人某某某」）：
  - 疑慮：加上本人名義，像是被迫以刊登判決的方式認錯
  - **高等法院 114 年法律座談會第 2 號**（字幕作「高院座談會 114 年第二號」，請對講義）：具名只是讓大眾知道判決當事人是誰，尚未達侵害**不表意自由**或等同強制道歉的程度 → **可以**
- **在個人臉書刊登並置頂 30 天**：
  - **最高法院**（字幕未唸字號，請對講義）：社群帳號與個人緊密連結、以個人名義發表，命其刊登並置頂，等於逼他做不想做的表態 → 有侵害不表意自由之嫌 → **不行**
- 老師：道歉的「方法」仍在討論中，不是只要刊登判決就一定沒問題；考試可多注意

> 來源：民法二試03 課程字幕 01:30:20 ~ 01:35:29（補充二試01 講義第 3 頁）

## 📖 法條原文速查

> **民法 §195 I 後段**　其名譽被侵害者，並得請求**回復名譽之適當處分**。
> **民法 §184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。

---

## 📋 實務見解速查

> **111 年憲判字第 2 號**（要旨）：法院以判決命加害人公開道歉，侵害其不表意自由，違憲；釋字 656 不再援用。（細節請對講義）

> **高等法院 114 年法律座談會第 2 號**（字號請對講義，要旨）：命加害人刊登判決啟事並具名，僅在使公眾知悉判決當事人，尚未等同強制道歉。

> **最高法院判決**（字號請對講義，要旨）：命加害人於個人臉書刊登判決並置頂，因社群帳號與個人緊密連結，有侵害不表意自由之嫌。

---

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「乙得否請求甲登報道歉？」 | 111 憲判 2：強制道歉侵害不表意自由 → 不得 |
| 「改請求刊登判決？」 | 判決本即公開，刊登於報紙原則可以 |
| 「要求刊登時具名？」 | 高院座談會：只是表明當事人，未達強制道歉程度 → 可 |
| 「要求在臉書刊登並置頂？」 | 最高法院：以個人名義表態，近似強制道歉 → 不行 |

## 一、判斷軸：離「強迫表態」多近

```
刊登方式                         以個人名義表態的程度      結論
───────────────────────────────────────────────────────────
登報道歉                          最高（直接認錯）          ✗（111 憲判 2）
個人臉書刊登＋置頂 30 天           高（個人帳號發表）        ✗（最高法院）
報紙刊登判決＋具名「刊登人某某某」  中（表明當事人）          ✓（高院座談會）
報紙刊登判決（不具名）              低（判決本即公開）        ✓
```
