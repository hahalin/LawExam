# 民法06 筆記：§87 通謀虛偽意思表示——要件、§87 II 隱藏行為、與 §244 的分工（50 台上 547）、債權人丙的兩條路

> 來源：民法06 課程字幕 01:27:23 ~ 01:41:00

---

## 📖 法條原文速查

> **§87**（通謀虛偽意思表示）
> I 表意人與相對人**通謀**而為虛偽意思表示者，其意思表示**無效**。但不得以其無效對抗善意第三人。
> II 虛偽意思表示，**隱藏他項法律行為**者，適用關於該項法律行為之規定。

> **§244**（詐害債權之撤銷）
> I 債務人所為之**無償行為**，有害及債權者，債權人得聲請法院撤銷之。
> II 債務人所為之有償行為，於行為時明知有損害於債權人之權利者，以受益人於受益時亦知其情事者為限，債權人得聲請法院撤銷之。
> IV 債權人依第一項或第二項之規定聲請法院撤銷時，得並聲請命受益人或轉得人**回復原狀**。但轉得人係善意者，不在此限。

> **§242**（債權人代位權）
> 債務人怠於行使其權利時，債權人因保全債權，得以自己之名義，行使其權利。……
> **§767 I 中段**　所有人……對於**妨害**其所有權者，得請求除去之。
> **§114 I**　法律行為經撤銷者，視為自始無效。

## 📋 實務見解速查

> **最高法院 50 年台上字第 547 號判例**（講義 289 頁）
> 虛偽買賣乃雙方通謀而為虛偽意思表示，依 §87 I 規定，其買賣**當然無效**，與得撤銷之法律行為經撤銷始視為自始無效者有別。故虛偽買賣雖屬意圖避免強制執行，但**非 §244 所謂債權人得聲請法院撤銷之法律行為**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§87 I 之要件？」 | 表意人與相對人**雙方都故意**虛偽，且**互相知情（通謀）** |
| 「效果？」 | **無效**；但不得以無效對抗善意第三人（I 但書） |
| 「假買賣真贈與（為節稅），效力？」 | 買賣依 §87 I 無效；**贈與依 §87 II 隱藏行為有效** |
| 「甲為避強制執行，與乙通謀虛偽移轉房屋，債權人丙得否聲請法院撤銷（§244）？」 | **不得**。通謀虛偽**本來就無效**，無從撤銷（50 台上 547）。撤銷是把有效變無效 |
| 「同上，丙如何救濟？」 | 確認甲乙行為無效 → 依 **§242 代位甲行使 §767 I 中段**請求乙塗銷登記 → 房屋回甲名下 → 強制執行 |
| 「甲乙是真心脫產（非虛偽）？」 | §87 不適用 → 丙依 **§244** 聲請撤銷 → §114 視為自始無效 → 依 **§244 IV 自己**請求回復原狀（塗銷），不必代位 |

## 一、要件與效果

```
要件：表意人 與 相對人 都故意虛偽，而且是「通謀」（互相知道對方也是假的）
     → 跟 §86 的圖不同：§86 只有一邊內心是空的；§87 兩邊都是空的
效果：原則 無效（§87 I）
     但書 不得以其無效對抗善意第三人（→ 下一份筆記）
     例外 隱藏行為（§87 II）
```

## 二、§87 II 隱藏行為：掛羊頭賣狗肉

```
甲乙為了節稅：
    送地要繳 300 萬贈與稅、賣地只繳 100 萬 → 假買賣真贈與（做金流再慢慢還回去）
    家人間贈與有免稅額 → 假贈與真買賣
效果：
    表面的買賣 → §87 I 無效
    隱藏的贈與 → §87 II 適用贈與的規定 → 甲乙間有贈與契約
```
- 最常用這條的是**國稅局**：登記時勾「買賣／贈與」先照勾的課稅；事後查金流發現不對，依真正原因補稅。

## 三、§87 與 §244 的分工：虛偽脫產 vs 認真脫產

#### 事實
甲欠丙錢，為避免強制執行，把名下唯一的 A 屋過戶給乙。

#### 分析：先問「甲乙是假的還是真的」

| | 甲乙**虛偽**（通謀） | 甲乙**真心**脫產（有效的贈與／買賣） |
|---|---|---|
| 甲乙行為效力 | §87 I **當然無效** | 有效 |
| 丙能用 §244？ | **不能**（50 台上 547）：撤銷是讓有效變無效，本來就無效無從撤銷 | **能**：§244 I（無償）／II（有償且雙方惡意）聲請撤銷 → §114 視為自始無效 |
| 丙怎麼讓房子回來 | 確認甲乙無效 → 乙未取得所有權、甲仍是所有人 → 甲怠於行使 → 丙依 **§242 代位甲**行使 **§767 I 中段**請求乙塗銷登記 | 撤銷後依 **§244 IV** 丙**以自己名義**請求乙回復原狀（塗銷），不必代位 |
| 然後 | 房子回甲名下 → 丙強制執行 | 同 |

```
為什麼虛偽時要「代位」？因為甲才是屋主，塗銷登記請求權是甲的（§767），丙只是債權人，只能代位
為什麼真心時不用代位？因為 §244 IV 直接給丙「命受益人回復原狀」的請求權
```

### 實務：先備位
- 丙起訴先位主張通謀虛偽無效，備位主張 §244 撤銷。考試不需先備位，題目會明講是虛偽還是真的。

### 回到王澤鑑的「能不能撤 vs 有無實益」
- 嚴格說，通謀虛偽的行為是「撤銷**無實益**」（本來就無效），實務直接簡稱「不能撤銷」。選擇題「甲乙通謀虛偽意思表示，丙得聲請法院撤銷之」→ **錯**。
