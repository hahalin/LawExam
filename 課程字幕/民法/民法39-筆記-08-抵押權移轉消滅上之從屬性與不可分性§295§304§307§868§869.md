# 民法39 筆記：抵押權移轉消滅上之從屬性與不可分性（§295§304§307§868§869）

## 記憶法：
- 295、304、307 三條都和從屬性有關（老師：像台北車站前三路公車）

## 移轉上從屬性一：債權讓與（§295）
- 甲向乙借款，以 A 地設定抵押權給乙；乙把債權讓與丙
- 抵押權**隨同移轉**給丙 → 依**法律規定**取得，不是法律行為移轉抵押權
- 所以不適用 §758，丙**不須登記即取得**；實行前去辦變更抵押權人登記（§759 意義的登記），**次序不變**
- 選擇題愛考：「丙未辦移轉登記，不得取得抵押權」是錯的

## 移轉上從屬性二：債務承擔（§304）——兩種情形要分清
- **I 項：債務人自己提供擔保**
  - 甲以自己 A 地設定抵押權給乙，丙承擔甲的債務
  - 抵押權**不受影響**；甲從「債務人兼抵押人」變成單純的**物上保證人**，丙成為債務人
- **II 項：第三人提供擔保**
  - 甲向乙借錢，由好友丁提供 B 地設定抵押權；後來丙承擔甲的債務
  - 丁是看在甲的面子才擔保，不認識丙 → 除非丁**承認**債務承擔，抵押權**因承擔而消滅**
- II 項最容易被忽略，選擇題考過

## 消滅上從屬性（§307）
- 甲清償債務 → 債權消滅 → 抵押權**依法律規定當然消滅**，不須塗銷登記
- 對照：乙**拋棄**抵押權是意思表示（法律行為），依 §758 **塗銷登記後**才消滅
- 實務上債權人會出具「抵押權塗銷同意書」，勾選債務已清償，債務人可單獨辦塗銷
- 乙不肯出具 → 甲依 **§767 I 中段**訴請塗銷：抵押權已消滅卻仍登記為權利人，就是妨害所有權
- 順序要清楚：不是塗銷後才消滅，而是**早已消滅所以可以請求塗銷**

## 不可分性（§868、§869）
- 甲以 A 地擔保乙的 B 債權 500 萬
- A 地分割為 A1、A2，或讓與一部；B 債權分割讓與（300 萬給丙、200 萬給丁）、債務一部承擔
- 結果**不受影響**：B1、B2 各自仍受 A1＋A2 全部擔保，直到清償或消滅

> 來源：民法39 課程字幕 01:33:00 ~ 01:50:10；§304 例中老師人物代號前後混用，本筆記統一為「乙債權人、丙承擔人、丁第三擔保人」

## 📖 法條原文速查

> **§295 I**（從權利之隨同移轉）讓與債權時，該債權之擔保及其他從屬之權利，**隨同移轉**於受讓人。但與讓與人有不可分離之關係者，不在此限。

> **§304**（從權利之存續）
> I 從屬於債權之權利，**不因債務人之變更而妨礙其存在**。但與債務人有不可分離之關係者，不在此限。
> II 由**第三人**就債權所為之擔保，除該第三人對於債務之承擔**已為承認**外，因債務之承擔而**消滅**。

> **§307**（從權利之隨同消滅）債之關係消滅者，其債權之擔保及其他從屬之權利亦同時消滅。

> **§868**（不可分性—抵押物分割）抵押之不動產如經分割，或讓與其一部，或擔保一債權之數不動產而以其一讓與他人者，其抵押權**不因此而受影響**。

> **§869**（不可分性—債權分割）
> I 以抵押權擔保之債權，如經分割或讓與其一部者，其抵押權不因此而受影響。
> II 前項規定，於債務分割或承擔其一部時適用之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債權讓與，受讓人須辦登記始取得抵押權？」 | **否**，依 §295 法定隨同移轉 |
| 「債務人自己提供抵押，第三人承擔債務？」 | 抵押權**不受影響**（§304 I） |
| 「第三人提供抵押，債務由他人承擔，未經該第三人承認？」 | 抵押權**消滅**（§304 II） |
| 「債務清償後，抵押權須塗銷才消滅？」 | **否**，§307 當然消滅 |
| 「抵押權人拋棄抵押權何時消滅？」 | **塗銷登記時**（§758） |
| 「債權人拒不塗銷，抵押人依何請求？」 | **§767 I 中段**除去妨害 |
| 「抵押土地分割後，抵押權範圍？」 | **不受影響**，仍及於分割後各筆（§868） |

## 對照表：何時「登記才變動」、何時「變動後再登記」

| 情形 | 性質 | 登記 |
|---|---|---|
| 設定抵押權 | 法律行為 | 登記才生效（§758） |
| 債權讓與，抵押權隨同移轉 | 法律規定（§295） | 先取得，事後變更登記 |
| 清償，抵押權消滅 | 法律規定（§307） | 當然消滅，塗銷只是整理外觀 |
| 拋棄抵押權 | 法律行為 | 塗銷登記才消滅（§758） |
