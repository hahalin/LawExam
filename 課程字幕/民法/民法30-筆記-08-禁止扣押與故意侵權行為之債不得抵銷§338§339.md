# 民法30 筆記：禁止扣押與故意侵權行為之債不得抵銷（§338、§339）

## 禁止扣押之債（§338）：
- 禁止扣押之債，其債務人不得主張抵銷
- 對照強制執行法 §122：依法領取的社會福利津貼、社會救助或補助等，不得強制執行
- 理由：這些錢是維持基本生活所需，抵銷掉會影響生存
- 例：某人每月領 8,000 元急難救助金，又因闖紅燈被罰 3,600 元
  - 形式上互負債務、種類相同、均屆清償期
  - 但救助金是禁止扣押之債 → 政府不得以罰單抵銷救助金

## 故意侵權行為之債（§339）：
- 因**故意侵權行為**而負擔之債，**其債務人**（加害人）不得主張抵銷
- 關鍵：看是誰發動抵銷
- 案例：甲借錢給乙，乙不還；甲找人暴力討債毆打乙
  - 甲對乙：消費借貸返還請求權（字幕作 §474）
  - 乙對甲：故意侵權行為損害賠償請求權（§184）
- 甲請求乙還錢 → **乙可以**拿 §184 的賠償債權抵銷
  - 乙是侵權行為的**債權人**（被害人），不受 §339 限制
- 乙請求甲賠償 → **甲不可以**拿借款債權抵銷
  - 甲是故意侵權行為的**債務人**（加害人）

## §339 的延伸爭點（向明恩文章，講義 617 頁）：
- 規範目的：保護**被害人**，不是預防侵權行為
- **互毆**：雙方互為故意侵權行為的加害人與被害人
  - 雙方都有被害人的身分 → **得主張抵銷**
- 與故意侵權行為**競合的其他請求權**（如故意的不當得利、故意的債務不履行）能否類推 §339，也在文章中討論（結論建議查閱原文）
- 申論題考過一次 §339，考的是單純的法條操作；本段主要是選擇題考點

## 📖 法條原文速查

> **§338**　**禁止扣押**之債，其債務人不得主張抵銷。

> **§339**　因**故意侵權行為**而負擔之債，**其債務人**不得主張抵銷。

> **強制執行法 §122 I**　債務人依法領取之社會福利津貼、社會救助或補助，不得為強制執行。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「禁止扣押之債，債務人可否抵銷？」 | **不可**（§338） |
| 「故意侵權行為之加害人，可否以其債權抵銷被害人之賠償債權？」 | **不可**（§339） |
| 「故意侵權行為之被害人，可否以賠償債權抵銷？」 | **可以**，§339 只限制「其債務人」 |
| 「過失侵權行為之債可否抵銷？」 | §339 限**故意**，過失不受限制 |
| 「互毆之雙方可否主張抵銷？」 | 學說（向明恩）認為**可以**，雙方都是被害人 |

## §339 誰能抵銷

```
甲（暴力討債）←→ 乙（被毆打）
甲對乙：借款債權　　乙對甲：§184 故意侵權賠償債權

甲請求還錢 → 乙主張抵銷 → 可（乙是被害人）
乙請求賠償 → 甲主張抵銷 → 不可（甲是故意侵權之債務人，§339）
```
