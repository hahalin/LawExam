# 民法二試02 筆記：違約金之從屬性與贈與撤銷

## 案例（「好聚不好散」，講義 130～131 頁）：
- 107/4/10 婚前協議：甲願於婚後一個月內將 A 屋贈與並移轉登記給乙；未履行賠違約金（約定 5,000 萬，起訴 1,000 萬，法院酌減為 400 萬）
- 107/4/20 結婚，同日約定：甲無條件代繳乙名下 B 屋貸款至繳清
- 甲都沒做 → 乙請求違約金、請求繼續代繳；甲主張違反善良風俗，並依 **§408 I 撤銷贈與**

## 爭點：
- 贈與撤銷後（視為自始無效，§114 I），違約金約定是否隨同消滅？

## 二審 vs 最高法院：
- 二審：違約金約定**獨立**，不受影響
- 最高法院：贈與視為自始無效，**附隨**之違約金約定隨同消滅

## 學說（呂教授，字幕作呂燕平／呂燕兵，請對講義）：
- **真正違約金**：繫於有效契約下之**債務不履行** → 從屬性，契約無效就跟著消滅
- **不真正違約金**：繫於當事人**不願履約**（撤銷、解除、不締約）→ 督促履約，具**獨立性**
- 本件約定針對的是「甲不願把房子送出去」→ 不真正違約金 → 不受撤銷影響 → 乙請求有理由（是否過高另依 §252 酌減）

## 📖 法條原文速查

> **民法 §408 I**　贈與物之權利未移轉前，贈與人得撤銷其贈與。其一部已移轉者，得就其未移轉之部分撤銷之。
> **民法 §114 I**　法律行為經撤銷者，視為自始無效。
> **民法 §252**　約定之違約金額過高者，法院得減至相當之數額。

---

## 📋 實務見解速查

> **最高法院判決**（講義註 217，字號請對講義）：法律行為經撤銷者，視為自始無效（§114 I）；贈與人合法撤銷其贈與者，贈與契約既視為自始無效，附隨之違約金約定亦隨同消滅。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「甲依 §408 I 撤銷贈與後，乙得否請求違約金？」 | 爭點在違約金之從屬性：撤銷→自始無效（§114 I）→ 違約金是否隨同消滅 |
| 「實務分歧？」 | 二審：獨立；最高法院：附隨，隨同消滅 |
| 「學說怎麼切？」 | 真正違約金（債務不履行，從屬）vs 不真正違約金（不願履約，獨立） |
| 「本件屬哪種？」 | 約定的是「不把房子送出去就賠錢」＝不願履約 → 不真正違約金 → 不受撤銷影響 |
| 「金額過高？」 | 另依 §252 酌減，與成立與否是兩回事 |

---

## 一、分類

| | 真正違約金 | 不真正違約金 |
|---|---|---|
| 發生原因 | 有效契約下之債務不履行 | 不願履約（撤銷、解除、拒絕締約） |
| 性質 | 從屬於主契約 | 獨立 |
| 主契約無效／撤銷 | 跟著消滅 | 不受影響 |

- 代繳 B 屋貸款的約定 → 筆記 10（無因債務承擔）。
