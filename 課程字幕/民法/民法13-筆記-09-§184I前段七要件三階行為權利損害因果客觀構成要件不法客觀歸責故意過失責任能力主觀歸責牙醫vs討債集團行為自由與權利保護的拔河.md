# 民法13 筆記：§184 I 前段的七個要件、三個層次——客觀構成要件：行為、權利（受侵害）、損害、因果關係；違法性：不法（客觀歸責）；有責性：故意或過失、責任能力（識別能力）（主觀歸責）；與刑法三階理論同源；牙醫拔牙 vs 討債集團拔牙——構成要件都該當，差在阻卻違法事由（被害人承諾）；侵權行為法的本質是**行為自由與權利保護的拔河**，每個要件的解釋都在找界線

> 來源：民法13 課程字幕 01:25:00 ~ 01:31:30

---

## 📖 法條原文速查

> **§184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。
> **§187 I**　無行為能力人或限制行為能力人，不法侵害他人之權利者，以行為時有識別能力為限，與其法定代理人連帶負損害賠償責任。……（責任能力）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§184 I 前段之要件？」 | 七個：① 行為 ② 權利受侵害 ③ 損害 ④ 因果關係（以上客觀構成要件）⑤ 不法（違法性／客觀歸責）⑥ 故意或過失 ⑦ 責任能力（識別能力）（以上有責性／主觀歸責） |
| 「為何分三階？」 | 與刑法三階理論（構成要件該當性、違法性、有責性）同源——早期法律不分民刑，判斷一個人要不要負責的邏輯相同：先看客觀上滿足要件，再看有無可非難性（客觀不法＋主觀故意過失） |
| 「牙醫拔牙與討債集團拔牙，差別？」 | 客觀上都有拔牙行為、牙齒被拔的結果、因果關係 → 構成要件都該當；牙醫有**被害人承諾**（阻卻違法事由）→ 無不法 → 不賠；討債集團 → 不法 → 賠 |
| 「無過失要不要負責？」 | 原則**不要**，除非法律特別規定無過失責任。一個人不須為自己無過失的行為負責 |
| 「侵權行為法的核心張力？」 | **行為自由 vs 權利保護**。絕對的權利保護＝絕對的行為不自由（牙醫拔牙也要賠）；行為自由過度保護＝權利保護不足。每個要件怎麼詮釋、涵攝，就是在畫這條界線 |

## 一、七要件三層次

```
一、客觀構成要件（要件該當）
   ① 行為（作為／不作為，筆記 10、11）
   ② 權利受侵害（限絕對權，筆記 13）
   ③ 損害
   ④ 因果關係
二、違法性（客觀歸責）
   ⑤ 不法 —— 有無阻卻違法事由（被害人承諾、正當防衛、緊急避難、自助行為）
三、有責性（主觀歸責）
   ⑥ 故意或過失
   ⑦ 責任能力（識別能力）
```

## 二、牙醫 vs 討債集團

| | 牙醫 | 討債集團 |
|---|---|---|
| 拔牙行為、牙齒被拔、因果 | ✓ | ✓ |
| 不法 | ✗（被害人承諾，病人還求他拔） | ✓ |
| 結果 | 不賠 | 賠 |

## 三、為什麼侵權行為篇幅最大

- 每個要件都有故事：王澤鑑、陳聰富的侵權行為法各是一本五六百頁的書；判決查 §184 I 前段幾千幾萬則。
- 人與人之間有權利被侵害就是侵權行為問題 → 最基本的民事糾紛來源 → 如何保護權利又不過度限制行為自由，是整部侵權行為法在處理的事。
