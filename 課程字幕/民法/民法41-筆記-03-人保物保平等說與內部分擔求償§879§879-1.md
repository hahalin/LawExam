# 民法41 筆記：人保物保平等說與內部分擔求償（§879§879-1）

## 外部關係：舊法物保優先，現行法平等：
- 情形：乙對甲有債權，同時有**抵押權**（A 地）與**保證人**丙兩個擔保
- 舊法只有 **§751**：債權人拋棄擔保物權，保證人在拋棄限度內免責；反過來拋棄保證並不會減輕抵押物負擔 → 先找保證人等於放掉物保，形成**物保優先說**
- 96 年修法增訂 **§879-1**（與 §751 對稱）：債權人免除保證人責任，抵押權在保證人應分擔部分的限度內消滅
- 兩邊拋棄任一個，另一個都跟著減輕 → **人保物保平等說**：乙可自由選擇先拍 A 地、先找丙，或兩個一起

## 內部分擔額：§879 II 比例計算：
- 比例＝**保證人應負的履行責任** ： **抵押物價值或限定金額**
- 保證額度：有特約依約定；**沒有特約＝債權額**
- 抵押物價值：原則市價；**擔保債權額少於抵押物價值時，以債權額為準**（§879 II 後段明文）
- 對照：共同抵押的 §875-2 沒有這句，才有筆記-02 的類推爭議

## 計算例（考試典型問法）：
- 甲向乙借 **1,000 萬**；丙提供 A 地（市價 **1,200 萬**）設定抵押權；丁擔任保證人，保證額度限定 **600 萬**
- 陷阱：不是 1,200：600＝2：1
- A 地以債權額 **1,000** 計 → 1,000：600＝**5：3**
- 丙（A 地）分擔 1,000×5/8＝**625 萬**；丁分擔 1,000×3/8＝**375 萬**
- 乙拍賣 A 地拿足 1,000 → 丙超出分擔額 375 → 丙可向丁請求 **375 萬**

## 內部求償的請求權基礎：

| 誰向誰 | 求償權 | 承受權 |
|---|---|---|
| 抵押人 → 債務人 | 委任 §546／無因管理 §176 | §879 I |
| 抵押人 → 保證人 | **§879 III**（法律直接給） | §879 I 承受債權，保證隨同移轉 |
| 保證人 → 債務人 | 委任／無因管理 | §749 |
| 保證人 → 抵押人 | **類推 §281 I**（立法理由自承漏洞） | §749 承受債權，抵押權隨同移轉 |

- 抵押人與保證人之間通常沒有委任、也不成立無因管理，所以要靠法律另外給求償權
- §879 III 只寫抵押人；保證人這邊的漏洞，當年修的是物權編，不想在物權編寫保證人的權利，留待債編修法，目前類推 §281 I

## 📖 法條原文速查

> **§879** I 為債務人設定抵押權之第三人，代為清償債務，或因抵押權人實行抵押權致失抵押物之所有權時，該第三人於其清償之限度內，承受債權人對於債務人之債權。但不得有害於債權人之利益。
> II 債務人如有保證人時，保證人應分擔之部分，依保證人應負之履行責任與抵押物之價值或限定之金額比例定之。抵押物之擔保債權額少於抵押物之價值者，應以該債權額為準。
> III 前項情形，抵押人就超過其分擔額之範圍，得請求保證人償還其應分擔部分。

> **§879-1** 第三人為債務人設定抵押權時，如債權人免除保證人之保證責任者，於前條第二項保證人應分擔部分之限度內，該部分抵押權消滅。

> **§751** 債權人拋棄為其債權擔保之物權者，保證人就債權人所拋棄權利之限度內，免其責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債權人須先實行抵押權，不足才找保證人？」 | **錯**，現行法採人保物保平等說，自由選擇 |
| 「抵押物價值高於債權額，分擔比例怎麼算？」 | 以**債權額**為準（§879 II 後段） |
| 「保證未約定額度？」 | 以**債權額**為保證責任 |
| 「債權人免除保證人責任，抵押權如何？」 | 保證人應分擔部分限度內抵押權消滅（§879-1） |
| 「抵押人向保證人求償依據？」 | §879 III |
| 「保證人向抵押人求償依據？」 | 法無明文，**類推 §281 I** |

## 為什麼舊法是物保優先

```
舊法：只有 §751
  拋棄抵押權 → 保證人減責   ✔
  免除保證人 → 抵押物減責   ✘（沒規定）
  → 債權人不能隨便動物保 → 物保優先

現行法：§751 ＋ §879-1
  兩邊互相連動 → 地位平等 → 自由選擇
```

## 計算檢查流程

```
① 保證額度：有約定用約定，沒有用債權額
② 抵押物：市價；市價 > 債權額 → 用債權額
③ 兩者相比 → 約分 → 各自分擔額
④ 實際清償 − 自己分擔額 ＝ 可求償額
```
