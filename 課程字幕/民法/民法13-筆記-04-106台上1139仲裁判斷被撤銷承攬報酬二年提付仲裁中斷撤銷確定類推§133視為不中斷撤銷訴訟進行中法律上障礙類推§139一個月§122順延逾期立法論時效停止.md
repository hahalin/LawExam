# 民法13 筆記：106 台上 1139 仲裁判斷被撤銷案——承攬報酬 §127 ⑦ 二年；提付仲裁 §129 II ② 中斷、仲裁判斷後重行起算；撤銷仲裁判斷之訴確定 → 仲裁自始不存在，**類推 §133** 視為不中斷 → 時效回到原本的 99/10/14 完成；但該日撤銷仲裁訴訟進行中（一事不再理）無法起訴 → **法律上障礙**（非 §139 之事實上障礙）→ **類推 §139** 自判決確定起一個月不完成 → 100/10/29 週六，§122 順延至 10/31；乙 11/2 請求、11/17 起訴 → 逾期，甲時效抗辯有理由；老師：解釋論正確但結果不合理，立法論應引進**時效停止**制度

> 來源：民法13 課程字幕 00:30:00 ~ 00:46:30（講義 339 頁）

---

## 📖 法條原文速查

> **§127 ⑦**　技師、承攬人之報酬及其墊款（二年）。
> **§129 II**　左列事項，與起訴有同一效力：一、依督促程序，聲請發支付命令。二、聲請調解或提付仲裁。……
> **§133**　時效因聲請調解或提付仲裁而中斷者，若調解之聲請經撤回、被駁回、調解不成立或仲裁之請求經撤回、仲裁不能達成判斷時，視為不中斷。
> **§137 I**　時效中斷者，自中斷之事由終止時，重行起算。
> **§139**　時效之期間終止時，因天災或其他不可避之事變，致不能中斷其時效者，自其妨礙事由消滅時起，一個月內，其時效不完成。
> **§122**　期間之末日為星期日、紀念日或其他休息日時，以其休息日之次日代之。

---

## 📋 實務見解速查

> **最高法院 106 年度台上字第 1139 號判決**（講義 339 頁，字號照字幕）：仲裁判斷經法院判決撤銷確定者，類推適用 §133，時效視為不中斷；惟撤銷仲裁判斷之訴進行中，債權人因一事不再理無從另行起訴，屬法律上障礙，類推適用 §139，自撤銷判決確定時起一個月內時效不完成。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「乙 97/10/14 完工，請求報酬未果，98/8/21 提付仲裁，99/4/30 仲裁判斷，甲提撤銷仲裁判斷之訴，100/9/29 撤銷確定；乙 100/11/2 請求、11/17 起訴。甲時效抗辯有無理由？」 | **有理由**（最高法院）。分段看：① 97/10/14 完工生報酬請求權，§127 ⑦ 二年 → 99/10/14 完成 ② 98/8/21 提付仲裁 §129 II ② 中斷，99/4/30 仲裁判斷後 §137 重行起算二年 → 101/4/30 ③ 撤銷確定 → 仲裁自始不存在 → 中斷、重行起算都不算數 → **類推 §133** 視為不中斷 → 回到 99/10/14 完成 ④ 但 99/10/14 當天撤銷仲裁訴訟進行中，一事不再理不能另訴 → 法律上障礙 → **類推 §139** 自 100/9/29 確定起一個月 → 10/29 週六、30 週日 → **§122 順延至 10/31** ⑤ 11/2 請求、11/17 起訴皆逾期 |
| 「為何是類推 §133 而非直接適用？」 | §133 列舉：調解撤回、駁回、不成立；仲裁撤回、不能達成判斷。仲裁已達成判斷**事後被撤銷**不在其中 → 類似「不能達成判斷」→ 類推 |
| 「為何是類推 §139 而非直接適用？」 | §139 的障礙是天災等**事實上**障礙；本件是一事不再理的**法律上**障礙 → 類推 |
| 「結果合理嗎？」 | 老師：乙超積極（仲裁、抗辯、確定後一個多月就請求），仲裁被撤是仲裁人的問題，卻要乙承受不利益；解釋論（類推 §133、§139）都對，問題出在我國沒有**時效停止**制度——提付仲裁到撤銷仲裁確定這段期間應按暫停鍵，之後把剩下的 14 個月走完，而不是只送一個月 |

## 一、時間軸

```
97/10/14 完工 → 報酬請求權發生，§127 ⑦ 二年 → 原本 99/10/14 完成
98/8/21  提付仲裁 → §129 II ② 中斷
99/4/30  仲裁判斷 → §137 重行起算 → 101/4/30
         甲提撤銷仲裁判斷之訴
99/10/14 （原完成日）撤銷仲裁訴訟進行中 → 一事不再理 → 乙無法請求／起訴
100/9/29 撤銷確定 → 類推 §133 視為不中斷 → 時效於 99/10/14 已完成
         → 當日有法律上障礙 → 類推 §139 → 自 9/29 起一個月 → 10/29（六）→ §122 → 10/31（一）
100/11/2 乙請求 ✗ 逾期；11/17 起訴 ✗ → 甲時效抗辯 ✓
```

## 二、兩次類推

| 類推 | 為什麼不能直接用 | 效果 |
|---|---|---|
| §133 | 仲裁判斷被撤銷不是列舉的五種 | 視為不中斷 → 回到原完成日 |
| §139 | §139 限事實上障礙，本件是法律上障礙（一事不再理） | 障礙消滅（撤銷確定）起一個月不完成 |

## 三、申論寫法（老師建議）

1. 解釋論：類推 §133 → 完成日 99/10/14；類推 §139 → 期限 100/10/31（§122）；乙逾期 → 抗辯有理由。
2. 指出結果不合理：乙並非「權利睡眠者」，仲裁被撤非可歸責於乙，一個月太短（乙原本從提付仲裁起還有約 14 個月可用）。
3. 立法論收尾：引進時效**停止**制度——仲裁到撤銷確定期間時效不進行，之後續算剩餘期間。
