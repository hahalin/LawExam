# 民法24 筆記：選擇之債之選擇權歸屬與行使（§208至§212）

## 選擇之債：
- 數宗給付中選定其一，例：甲乙買賣，標的是 A、B、C 三選一
- 要處理：**誰來選**、**怎麼選**、**不選怎麼辦**

## 誰來選（§208）：
- 原則：**債務人**
- 例外：法律另有規定或契約另有訂定 → 可以是債權人或第三人

## 怎麼選（§209）：
- 債權人或債務人選 → 向**他方當事人**以意思表示為之
- **第三人**選 → 應向**債權人及債務人**以意思表示為之（「及」＝兩個都要）
- 對照 §117：法定代理人承認限制行為能力人的契約，向**當事人之一方**為之即可
  - 同樣是第三人決定效力，表示方法不同：§117 存證信函寄一張；§209 II 要寄兩張
  - 老師：選擇題很細、很愛考；看法條要一個字一個字看（如 §153 非必要之點、§202 給付額）

## 不選怎麼辦——選擇權移轉（§210）：
- 當事人有選擇權、**定有期間**，期間內不行使 → 移屬**他方當事人**
- 當事人有選擇權、**未定期間** → 債權至清償期時，他方得定相當期限**催告**；仍不行使 → 移屬**為催告之當事人**
- **第三人**不能或不欲選擇 → 選擇權屬於**債務人**，**不須催告**

## 其他：
- §211（數宗給付中有不能者）：老師留到給付不能講完再回頭講
- §212：選擇之效力**溯及於債之發生時**，知道就好

## 📖 法條原文速查

> **§208**　於數宗給付中得選定其一者，其選擇權屬於**債務人**。但法律另有規定或契約另有訂定者，不在此限。

> **§209**　I 債權人或債務人有選擇權者，應向他方當事人以意思表示為之。II 由第三人為選擇者，應向**債權人及債務人**以意思表示為之。

> **§210**　I 選擇權定有行使期間者，如於該期間內不行使時，其選擇權移屬於他方當事人。II 選擇權未定有行使期間者，債權至清償期時，無選擇權之當事人，得定相當期限催告他方當事人行使其選擇權，如他方當事人不於所定期限內行使選擇權者，其選擇權移屬於為催告之當事人。III 由第三人為選擇者，如第三人不能或不欲選擇時，選擇權屬於**債務人**。

> **§212**　選擇之效力，溯及於債之發生時。

> **§117**　法律行為須得第三人之同意始生效力者，其同意或拒絕，得向**當事人之一方**為之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「選擇權原則上屬於誰？」 | **債務人**（§208） |
| 「第三人行使選擇權，向誰表示？」 | **債權人及債務人**（兩方都要） |
| 「法定代理人承認，向誰表示？」 | **當事人之一方**即可（§117） |
| 「第三人不選擇，選擇權歸誰？須否催告？」 | 歸**債務人**，**不須催告** |
| 「當事人未定期間不選？」 | 清償期屆至後**催告**，仍不選 → 移屬**催告之人** |
| 「選擇之效力？」 | **溯及**於債之發生時 |

## 選擇權移轉

```
誰有選擇權？
├── 當事人（債務人／債權人）
│     ├── 定有期間 → 期間內不選 → 移屬他方
│     └── 未定期間 → 清償期後催告 → 仍不選 → 移屬催告之人
└── 第三人 → 不能或不欲選 → 屬於債務人（不須催告）
```

| | 選擇之債第三人選擇（§209 II） | 法定代理人承認（§117） |
|---|---|---|
| 向誰 | 債權人**及**債務人 | 當事人**之一方** |
| 存證信函 | 兩張 | 一張 |
