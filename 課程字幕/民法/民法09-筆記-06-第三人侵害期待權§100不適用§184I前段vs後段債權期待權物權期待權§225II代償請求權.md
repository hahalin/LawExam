# 民法09 筆記：第三人侵害期待權——§100 不適用；王澤鑑 §184 I 前段 vs 老師：債權期待權走後段、物權期待權才走前段；條件成就後依 §225 II 代償請求權取得甲對丙的 §184

> 來源：民法09 課程字幕 01:07:39 ~ 01:15:59

---

## 📖 法條原文速查

> **§100**　附條件之法律行為**當事人**……負賠償損害之責任。→ 限當事人
> **§184 I**　前段：因故意或過失不法侵害他人之**權利**者。後段：故意以背於善良風俗之方法加損害於他人者。
> **§225**　I 因不可歸責於債務人之事由，致給付不能者，債務人免給付義務。II 債務人因前項給付不能之事由，對第三人有損害賠償請求權者，債權人得向債務人請求讓與其損害賠償請求權，或交付其所受領之賠償物。→ **代償請求權**

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲以停止條件贈與 A 車予乙，條件未定前第三人丙毀損 A 車，乙得否依 §100 向丙請求？」 | **不得**。§100 要件是「當事人」，丙是第三人，要件不該當 |
| 「乙得否依 §184 向丙請求？」 | **王澤鑑**：期待權權利化 → §184 I **前段**。**老師**：債權的期待權充其量將來取得債權，債權非絕對權 → 應為 §184 I **後段**（須故意背於善良風俗）；只有**物權期待權**（附條件買賣已占有）才適合前段 |
| 「條件成就後乙對丙？」 | 仍不能 §100（非當事人）；取得債權 → §184 I 後段；取得物權 → 前段 |
| 「後段門檻太高，乙怎麼辦？」 | 等條件成就、契約生效、甲確定給付不能 → 依 **§225 II 代償請求權**請求甲**讓與其對丙之 §184 I 前段請求權** → 乙再向丙請求。契約的事交給契約處理，侵權不是萬能 |

## 一、結構
```
甲 ──附停止條件贈與 A──→ 乙
丙（第三人）毀損 A
乙對丙：
  §100？✗ 「附條件法律行為之當事人」→ 丙不是當事人
  §184？看期待權是什麼
```

## 二、§184 I 前段還是後段

| | 王澤鑑 | 老師 |
|---|---|---|
| 主張 | 期待權權利化 → 是 §184 I 前段的「權利」 | 債權的期待權將來頂多拿到一個**債權**，債權不是絕對權（王澤鑑在侵權法講了一百遍）→ 若契約已生效乙對甲是債權，被丙侵害走後段；契約還沒生效反而變絕對權走前段？更奇怪 |
| 結論 | 前段 | **債權期待權 → 後段**；**物權期待權**（附條件買賣、乙已占有 A 車）→ 前段可接受 |

## 三、真正合適的路：§225 II 代償請求權
```
後段要故意背於善良風俗，過失毀損的丙根本不用對乙負責 → 乙沒被保護到？
→ 侵權法本來就沒打算保護過失侵害債權的被害人
→ 等條件成就 → 契約生效 → 甲對乙的給付（A 車）因丙毀損而確定不能
→ 甲對丙有 §184 I 前段請求權（A 車是甲的所有權）
→ 乙依 §225 II 請求甲讓與該請求權（以甲對丙的 §184 代替 A 車作為給付）
→ 乙再向丙請求 → 符合契約法的秩序
```
