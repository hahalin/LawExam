# 民法10 筆記：70 台上 657「比比皆是」——「由自己之行為表示授權」的外觀要依乙想代理的行為個案認定（持名片比比皆是不足；貸款要印章＋雙證件；設定抵押要印章＋權狀＋印鑑證明）；陳忠五：**外觀**（客觀上足以使人相信）與**可歸責**（外觀是本人創造的）是兩個要件——文件鎖保險櫃被竊不成立；§169 是無過失責任，可歸責 ≠ 有過失；本人責任是履行責任不是損害賠償

> 來源：民法10 課程字幕 01:42:28 ~ 01:48:42

---

## 📋 實務見解速查

> **最高法院 70 年台上字第 657 號判例**（「比比皆是」判例，字號照字幕，建議查閱）：我國人民將印章交付他人，委託該他人辦理特定事項者，比比皆是，倘持有印章之該他人，除受託辦理之特定事項外，其他以本人名義所為之任何法律行為，均須由本人負表見代理之授權人責任，未免過苛。→ 要就乙想代理的行為，看本人交付之物客觀上足不足以構成該行為的授權外觀。
> **§169 無過失責任判例**（老師僅口述內容，字號建議查閱；內容近似 44 年台上字第 1424 號判例）：民法第 169 條係為保護善意第三人而設，故本人有使第三人信以為有代理權授與他人之行為而與之交易，即應使本人負其責任；又此本人責任係指**履行責任**而言，並非損害賠償責任，故本人**有無過失在所不問**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「交付印章、名片即構成 §169 之授權外觀？」 | **不一定**，要看乙想代理的是什麼行為、做那件事需要什麼。只有名片：拿名片的人比比皆是 → 無外觀。貸款：印章＋雙證件。設定抵押、移轉不動產：印章＋所有權狀＋**印鑑證明**（本人親赴戶政機關申請，載明用途） |
| 「考試上怎麼判斷？」 | 題目給的東西**越多越容易構成**（公司大小章、印鑑章、董事長章全在身上 → 一般人會相信）；東西少少的就要想「這一點點足以讓人相信有代理權嗎」 |
| 「§169 第一句的兩個要件（陳忠五）？」 | ① **外觀**：客觀上足以使人相信有代理權 ② **可歸責**：該外觀是**本人創造**的。兩者皆備才是「由自己之行為表示以代理權授與他人」 |
| 「甲之身分證、印章、權狀、印鑑證明鎖在家中保險櫃，被乙竊取使用，丙善意無過失？」 | **不成立** §169。外觀可能有，但不是甲交付的 → 不是「由自己之行為」→ 無可歸責事由 |
| 「§169 本人須有故意過失？」 | **不須**（無過失責任）。可歸責＝有沒有創造權限外觀，不是有沒有故意過失。為託領掛號信交付身分證印章 → 有創造外觀、可歸責，但不一定有過失 |
| 「§169 之本人責任性質？」 | **履行責任**（當作有權代理，契約對本人生效），**非損害賠償責任** |

## 一、外觀要個案認定：乙想代理你做什麼？做那件事需要什麼？

| 乙想代理的行為 | 需要的外觀 | 只給名片／一顆印章 |
|---|---|---|
| 向銀行貸款 | 印章＋雙證件（證明本人或經授權，銀行據以徵信） | 不足 |
| 設定抵押權、移轉不動產 | 印章＋土地所有權狀＋**印鑑證明**（本人到戶政機關申請，載明用途） | 不足 |
| 考題常見 | 公司大小章、印鑑章、董事長章全在乙身上 → 一般人會相信 | — |

- 判例語境：交印章託辦特定事項的人比比皆是，不能因為交了印章就什麼行為都要負表見代理責任。

## 二、陳忠五：外觀與可歸責是兩件事

```
外觀    ＝ 客觀上會不會讓人相信乙有代理權（看交付之物與所代理行為的對應）
可歸責  ＝ 這個外觀是不是本人創造的（本人主動交付 ✓；被偷 ✗）
兩者皆備 → 「由自己之行為表示以代理權授與他人」
保險櫃被竊案：第三人可能善意無過失、外觀也夠，但甲沒有主動交付 → 不可歸責 → 無 §169
```

## 三、本人要不要有故意過失：不要（無過失責任）

| 層次 | 問的是 |
|---|---|
| 可歸責 | 有沒有**創造權限外觀** |
| 故意過失 | 主觀上有無注意義務違反 |

- 託領掛號信交付身分證印章：有創造外觀（可歸責），但不一定有過失 → 仍負 §169 責任。
- 本人責任是**履行責任**：第三人可要求本人履行契約，不是請求損害賠償。
