# 民法02 筆記：住所 §20～§24

> 來源：民法02 課程字幕 01:37:04 ~ 01:48:47

---

## 📖 法條原文速查

> **§20**（住所之設定）
> I 依一定事實，足認以**久住之意思**，住於一定之地域者，即為設定其住所於該地。
> II 一人同時**不得有兩住所**。

> **§21**（無行為能力人及限制行為能力人之住所）
> 無行為能力人及限制行為能力人，以其**法定代理人之住所**為住所。

> **§22**（擬制住所）
> 遇有下列情形之一，其**居所視為住所**：
> 一、住所無可考者。
> 二、在我國無住所者。但**依法須依住所地法者，不在此限**。

> **§23**（選定居所）
> 因特定行為選定居所者，關於其行為，**視為住所**。

> **§24**（住所之廢止）
> 依一定事實，足認以**廢止之意思**離去其住所者，即為廢止其住所。

> **§314**（清償地）
> 清償地，除法律另有規定或契約另有訂定，或另有習慣，或得依債之性質或其他情形決定者外，依左列各款之規定：
> 一、以給付特定物為標的者，於訂約時，其物所在地為之。
> 二、其他之債，於**債權人之住所地**為之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「住所之設定要件？」 | 主觀**久住之意思** ＋ 客觀**久住之事實**（§20 I）；不靠登記 |
| 「戶籍地即為住所？」 | **否**，僅得**推定**（100 台上 1373）；遷戶籍常為學區、投票 |
| 「一人可否有兩住所？」 | **不可**（§20 II） |
| 「未成年人之住所？」 | 以**法定代理人之住所**為住所（§21） |
| 「住所無可考者？」 | **居所視為住所**（§22 ①）→ 視為，不得舉反證 |
| 「在臺日本人在臺無住所，離婚訴訟管轄與準據法？」 | 管轄：臺灣居所視為住所（§22 ②本文）；準據法：依涉外民事法律適用法須依住所地法 → 用**真正住所**東京（§22 ②但書） |
| 「契約載明聯絡地址？」 | 關於該行為**視為住所**（§23） |
| 「廢止住所之要件？」 | 主觀廢止意思 ＋ 客觀離去事實（§24）；廢止後未設新住所 → 住所無可考 → §22 ① |
| 「清償地？」 | 特定物之債：物之所在地；其他之債：**債權人住所地**（§314） |

## 一、住所＝法律上的地址，不是事實上的地址

```
民總體系：權利主體（自然人 §6～§24）
    §6～§11    權利能力
    §12～§15-2 行為能力
    §16～§19   人格權
    §20～§24   住所 ← 法律關係發生的「地」
```
- 用途：監護宣告向住所地法院聲請、收養、契約約定「以當事人住所地法院管轄」、清償地。

## 二、設定（§20）：兩個要件

```
主觀：久住之意思
客觀：久住之事實
→ 兩者具備即設定住所；不透過登記
```
- 戶籍地 ≠ 住所地，只能**推定**（可舉反證推翻），不能視為。
- 個案判斷：這個人有沒有離開這裡的意思？

## 三、§21 法定代理人住所、§22 擬制住所

```
§21：無／限制行為能力人 → 法代的法律上地址就是他的法律上地址
§22：自己沒有住所 → 法律幫你找 → 居所（現實生活地址）「視為」住所（不得舉反證）
    ① 住所無可考（居無定所）
    ② 在我國無住所 → 臺灣居所視為住所
         但書：依法須依「住所地法」者 → 不在此限（回到真正住所）
```

### §22 ② 但書案例（涉外民事法律適用法才會用到）

#### 事實
甲（臺灣人）、乙（日本人）在臺灣打離婚訴訟。乙在臺灣無住所、居所在臺南；在日本有住所（東京）。

#### 分析
| 問題 | 乙的住所認定 | 依據 |
|------|------|------|
| 向哪個法院起訴（管轄） | 臺南居所**視為**住所 → 臺南地院 | §22 ② 本文 |
| 用哪國法律審理（準據法） | 依涉外民事法律適用法須依住所地法 → **真正住所**東京 → 日本法 | §22 ② 但書 |

- 若準據法也用臺灣擬制住所 → 涉外法的住所地法原則被架空 → 所以有但書。

## 四、§23 選定居所、§24 廢止

- §23：簽約時指定的通訊地址 → 關於該契約，**視為**住所。
- §24：廢止要件與設定對稱——主觀廢止意思 ＋ 客觀離去事實。廢止後沒設新住所 → 住所無可考 → §22 ① 居所視為住所。

## 五、實體法上唯一常用：§314 清償地

```
特定物之債 → 訂約時物之所在地
其他之債   → 債權人之住所地（赴償債務）
```
