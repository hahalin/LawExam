# 民法09 筆記：真正條件的效力——事後確定不發生；債權行為附條件 vs 物權行為附條件：不動產靠預告登記（土地法 §79-1）、動產靠附條件買賣（動產擔保交易法 §26）

## 📖 法條原文速查

> **土地法 §79-1**（預告登記）
> I 聲請保全左列請求權之預告登記，應由請求權人檢附登記名義人之同意書為之：一、關於土地權利移轉或使其消滅之請求權。二、土地權利內容或次序變更之請求權。三、**附條件或期限之請求權**。
> II 前項預告登記未塗銷前，登記名義人就其土地所為之處分，**對於所登記之請求權有妨礙者無效**。
> III 預告登記，對於因徵收、法院判決或強制執行而為之新登記，無排除之效力。

> **動產擔保交易法 §26**　稱附條件買賣者，謂買受人**先占有**動產之標的物，約定至支付一部或全部價金，或完成特定條件時，始取得標的物所有權之交易。
> → 動產擔保交易法有三種擔保：動產抵押、附條件買賣、信託占有；可向縣市政府動產擔保交易科登記。建議查閱原文

> **§242**　債權人代位權　**§767 I 中段**　除去妨害　**§348**　出賣人移轉義務　**§179**　不當得利
> **§101**　條件成就之擬制（筆記 07）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「真正條件事後確定不發生？」 | 與既成條件「確定不發生」同處理：停止條件 → 法律行為**無效**；解除條件 → **視為無條件**（26 歲約定考上調查局送重機，過 30 歲仍未考上） |
| 「停止條件成就後，債權行為？」 | 生效 → 取得債權請求權 → 請求履約 |
| 「解除條件成就後？」 | 失效 → 繼續性契約不再履行；一時性契約依 §179 回復原狀 |
| 「約定『價金付清土地即歸買受人』，有無物權效力？」 | 無登記即無物權效力。要讓**不動產物權行為附條件**須辦**預告登記**（土地法 §79-1 I ③） |
| 「甲賣地給乙約定付款達 50% 即移轉，已辦預告登記；乙付 30% 時甲將地移轉登記給丙，乙付到 50% 後如何？」 | 甲丙移轉登記對乙之請求權有妨礙 → **無效**（§79-1 II）→ 丙未取得 → 乙依 **§242 代位甲行使 §767 I 中段**請求丙塗銷 → 再依 §348 請求甲移轉 |
| 「動產物權行為附條件？」 | **附條件買賣**（動擔法 §26）：買受人先占有，價金付清始取得所有權；買賣契約本身無條件，物權行為效力先停 |

## 一、事後確定不發生 vs 既成條件
```
26 歲甲：你考上調查局（30 歲前可考）就送你重機 → 約定時不確定 → 真正條件
過了 30 歲還沒考上 → 事後確定不發生 → 比照既成條件：停止條件 → 無效；解除條件 → 視為無條件
既成條件：約定時就已確定（乙早就超過 30 歲）
```

## 二、條件成就後：債權行為簡單，物權行為要搭特別法
```
停止條件成就
├── 債權行為（考上送你車＝贈與附條件）→ 生效 → 取得債權請求權 → 請求給付
└── 物權行為（考上車就是你的）→ 物權要公示外觀 → 沒有登記／交付不會有物權效力
      不動產 → 預告登記（土地法 §79-1）
      動產 → 附條件買賣（動擔法 §26）
解除條件成就 → 失效 → 一時性契約 §179 返還（老師的農地案：建照申請失敗 → 解除條件成就 → 互相返還）
```

## 三、預告登記（100 年司法官二試考過；把土地法 §79-1 寫在六法 §99 旁）
```
甲 ──賣 A 地──→ 乙，約定乙付款達 50% 時甲移轉登記 → 辦預告登記（附條件之請求權）
好處 ①：條件成就後乙可單獨申請把預告登記轉為本登記，不用甲配合
好處 ②：甲中途把地賣給丙並移轉登記 → §79-1 II 對乙的請求權有妨礙 → 甲丙移轉登記無效 → 丙未取得
         → 甲仍是地主但不會告丙（是他賣的）→ 乙依 §242 代位甲行使 §767 I 中段 → 丙塗銷
         → 地回甲名下 → 乙依 §348 請求甲移轉
```
- 為什麼要代位：土地移轉給乙之前，甲還是地主，對丙的塗銷請求權是甲的，乙對丙沒有直接請求權。
- 不透過銀行履約擔保的買賣才會這樣約定，考試比較多這種。

## 四、附條件買賣（動擔法 §26）
```
老師買訂製床架：契約寫「附條件買賣，繳足全部價金始取得所有權」
買賣契約：成立且生效，沒有附條件
物權行為：床先交付（買受人先占有＝公示外觀先做出來），所有權移轉的效力先停，價金付清才發生
→ 可向縣市政府動產擔保交易科登記（買車辦車貸則多用動產抵押）
```
