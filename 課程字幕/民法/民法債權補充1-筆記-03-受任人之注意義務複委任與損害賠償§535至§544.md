# 民法債權補充1 筆記：受任人之注意義務、複委任與損害賠償（§535至§544）

## 注意義務（§535）
- **有償**委任：**善良管理人**之注意（抽象輕過失）
- **無償**委任：與處理**自己事務**同一之注意（具體輕過失）

## 親自處理與複委任（§537～§539）
- 原則：受任人應**自己**處理事務（§537 本文）
- 例外：經委任人**同意**、另有**習慣**、或有**不得已**事由，得使第三人代為處理（§537 但書）

| 項目 | 合法複委任 | 違法複委任 |
|---|---|---|
| 依據 | 符合 §537 但書 | 不符合 |
| 受任人責任 | **僅就選任及指示**負責（§538 II） | 就第三人行為與**自己行為負同一責任**（§538 I） |
| 委任人對第三人 | 有**直接請求權**（§539） | 通說**無**（委任人已反對，§539 限縮解釋） |

- 例：甲委任乙買車，乙經同意再委任丙去買 → 丙有過失，乙只就選任、指示丙有無過失負責

## 附隨義務
- **報告**：事務進行狀況要報告；委任關係終止時明確報告顛末（§540）
- **交付**：收取的金錢、物品、孳息交付委任人；以自己名義取得的權利移轉給委任人（§541）
  - 交付請求權消滅時效何時起算？實務：可行使時；陳聰富：受任人履行**報告**義務後（消滅時效單元講過）
- **不得挪用**：為自己利益使用應交付委任人的金錢 → 自使用日起付利息，有損害並應賠償（§542）
  - 例：甲交乙 100 萬買車，乙拿去投資 → 付利息；投資虧損另負賠償

## 處理事務的損害賠償（§544）
- 受任人因處理委任事務**有過失**，或因**逾越權限**的行為所生損害，對委任人負賠償責任
- **逾越權限是否須有過失？** 王澤鑑：須有**可非難性**；無過失逾越權限不必賠 → 限縮解釋
- **根本沒處理**能否用 §544？多數說**否**
  - §544 前提是「處理事務」時有過失；沒處理就談不上處理的過失 → 回到一般**債務不履行**
  - 游進發：§544 是「**小損害賠償**」（有做但做得有瑕疵）；根本不作為是「大損害賠償」，走一般規定

## 📖 法條原文速查

> **§535**（注意義務）受任人處理委任事務，應依委任人之指示，並與處理自己事務為同一之注意，其受有報酬者，應以善良管理人之注意為之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 無償委任注意義務 | 與處理自己事務同一（具體輕過失） |
| 合法複委任，受任人責任 | **僅就選任及指示** |
| 違法複委任，受任人責任 | 與自己行為負**同一**責任 |
| 違法複委任，委任人對第三人有無直接請求權 | 通說**無** |
| 挪用應交付之金錢 | 自使用日起付利息＋損害賠償 |
| 無過失逾越權限是否依 §544 負責 | 王澤鑑：**否** |
| 根本未處理事務 | 不適用 §544，走一般債務不履行 |
