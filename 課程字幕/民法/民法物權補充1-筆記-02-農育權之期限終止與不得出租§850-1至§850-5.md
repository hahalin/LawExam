# 民法物權補充1 筆記：農育權之期限終止與不得出租（§850-1至§850-5）

## 定義與功能（§850-1 I）
- 在他人土地為**農作、森林、養殖、畜牧、種植竹木或保育**之權
- 對照：要蓋建物 → 地上權；要種東西、養東西 → 農育權
- **釋字408**：農地、耕地不能蓋建物 → 不能時效取得**地上權**；但時效取得**農育權**目的相符，可能成立

## 期限
- 不得逾 **20 年**，逾者縮短為 20 年；但以**造林、保育**為目的或法令另有規定者，不受限制（§850-1 II）
- **未定期限**：除以造林、保育為目的者外，當事人得**隨時終止**，應於 **6 個月前**通知他方（§850-2 I、II）
- 以造林、保育為目的而未定期限：**準用 §833-1**，存續逾 20 年或目的不存在時，法院得因請求定期間或終止（§850-2 III）

## 讓與與一體性（§850-3）
- 農育權人得讓與或設定抵押權；契約另有約定或習慣者不在此限，約定**非經登記不得對抗**第三人
- 農育權與**農育工作物**不得分離而為讓與或設定其他權利
- 結構同地上權 §838

## 不可抗力致收益減少（§850-4）
- 有支付地租之約定，農育權人因**不可抗力**致收益減少或全無 → 得請求**減免地租**或**變更使用目的**（I，請求權人只有農育權人）
- 不能依原約定目的使用 → **當事人**得終止（II，包括地主）
- 無支付地租之約定 → 準用 II 關於土地所有人得終止的規定（III）

## 不得出租（§850-5）
- 農育權人**不得**將土地或農育工作物**出租**他人；農育工作物出租另有習慣者從其習慣
- 違反 → 土地所有人得**終止**農育權
- 對照：地上權法無禁止，地上權人原則上可以出租土地

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 農育權期限上限 | **20 年**；造林、保育不受限 |
| 未定期限農育權之終止 | 隨時終止，**6 個月前**通知；造林保育除外 |
| 可否在農地時效取得地上權 | **否**（釋字408） |
| 不可抗力致收益減少 | 減免地租或變更目的 |
| 農育權人可否出租土地 | **不可**；違反地主得終止 |
| 地上權人可否出租土地 | 法無禁止，原則可以 |

---

## 地上權 vs. 農育權

| 項目 | 地上權 | 農育權 |
|---|---|---|
| 目的 | 建築物、工作物 | 農作、畜牧、造林等 |
| 期限 | 無上限 | 20 年（造林保育除外） |
| 出租 | 法無禁止 | 禁止（§850-5） |
| 不可抗力減租 | 不得請求（§837） | 得請求減免（§850-4） |
