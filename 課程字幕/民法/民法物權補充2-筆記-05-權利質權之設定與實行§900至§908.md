# 民法物權補充2 筆記：權利質權之設定與實行（§900至§908）

## 定義（§900）
- 以**可讓與的債權或其他權利**為標的物的質權（例：債權、股票）
- 對照：不動產擔保 → 抵押權；動產擔保 → 動產質權；權利擔保 → 權利質權

## 設定方式
### 以債權為標的（§904）
- 設定應以**書面**為之 → **要件**
- 債權有證書者，出質人有**交付義務** → 只是**義務**，不是要件
- 選擇題陷阱：沒交付債權證書，權利質權仍**有效**，只是質權人可請求交付（講義把交付列在要件，老師更正為義務）

### 以有價證券為標的（§908）
- **無記名**證券：交付證券即生設定效力
- 其他（記名）證券：並應依**背書**方法為之
- 邏輯同票據法：無記名交付、記名背書

## 實行方式：看質權標的債權的內容
| 標的債權的內容 | 質權人怎麼做 | 條文 |
|---|---|---|
| **金錢** | 直接收取或請求提存（民法41、§881 物上代位時已講） | §905 |
| **金錢以外的動產** | 清償期屆至，請求債務人給付該動產，對給付物取得**質權** | §906 |
| **不動產物權**設定或移轉 | 請求債務人將不動產物權設定或移轉給出質人，對該不動產取得**抵押權** | §906-1 |
| 其他 | 亦得依 §893 I 拍賣，或依 §895 準用 §878 | §906-2 |

## 例：以動產給付請求權設質
- 甲向乙買 A 車，甲對乙有 §348 交付 A 車的債權
- 甲向丙借錢，以這個債權設定權利質權給丙
- 清償期屆至，丙可請求乙交付 A 車，並對 A 車有**動產質權**
- 若標的是 A 地 → 丙可請求乙移轉登記給甲，並對 A 地有**抵押權**

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 以債權設質之要件 | **書面** |
| 交付債權證書是要件嗎 | **否**，只是義務 |
| 無記名證券設質 | 交付 |
| 記名證券設質 | 背書（＋交付） |
| 標的債權為動產給付，實行後 | 對該動產取得**質權** |
| 標的債權為不動產物權移轉，實行後 | 對該不動產取得**抵押權** |
