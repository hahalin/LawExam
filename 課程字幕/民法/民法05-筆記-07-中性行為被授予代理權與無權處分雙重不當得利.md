# 民法05 筆記：中性行為——被授予代理權、無權處分 §118（含善意取得與雙重不當得利）

> 來源：民法05 課程字幕 01:00:15 ~ 01:24:28

---

## 📖 法條原文速查

> **§77 但書**（類推適用於中性行為）

> **§118 I**（無權處分）
> 無權利人就權利標的物所為之處分，經有權利人之承認始生效力。

> **§167**（代理權之授與）
> 代理權係以法律行為授與者，其授與應向代理人或向代理人對之為代理行為之第三人，以意思表示為之。
> → 有相對人之**單獨行為**

> **§801**（善意受讓）
> 動產之受讓人占有動產，而受關於占有規定之保護者，縱讓與人無讓與之權利，受讓人仍取得其所有權。
> **§948 I**　以動產所有權，或其他物權之移轉或設定為目的，而**善意受讓**該動產之占有者，縱其讓與人無讓與之權利，其占有仍受法律之保護。但受讓人明知或因重大過失而不知讓與人無讓與之權利者，不在此限。
> → 要件是依（有效的）物權行為受讓占有＋善意無重大過失；**不問債權行為效力**

> **§179**　不當得利。　**§264**　同時履行抗辯（固有抗辯）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「中性行為（無損益行為）之意義？」 | 對限制行為能力人**不生權利也不生義務** → 類推 §77 但書，不須允許 |
| 「乙授與代理權予限制行為能力人甲，效力？」 | **有效**（中性行為）。甲代理乙締約，效果在乙丙間，甲不是當事人 |
| 「限制行為能力人甲授與代理權予乙，效力？」 | 不是中性行為（效果及於甲）；授權是**有相對人之單獨行為** → 未經允許 **§78 無效**（不是 §79） |
| 「限制行為能力人甲將乙借他的車賣給善意丙並交付，物權行為效力？」 | 對甲無損益 → 中性行為 → 不受行為能力影響；但甲**無處分權** → **§118 效力未定**（不是 §79） |
| 「甲丙買賣契約被法代拒絕承認，丙仍得善意取得？」 | **得**（王澤鑑）。善意取得只看物權行為＋善意，與債權行為無關（無因性） |
| 「乙如何向丙取回車？」 | 丙已善意取得 → 乙非所有人 → §767 ✗；直接對丙 §179 ✗（害丙的同時履行抗辯）→ **雙重不當得利** |

## 一、中性行為是什麼

```
純獲法律上利益：有好處、沒壞處 → §77 但書
中性行為（無損益行為）：沒好處、也沒壞處 → 一樣沒有禁止的必要 → 類推 §77 但書
民法上兩種：① 被授予代理權 ② 無權處分
```

## 二、被授予代理權

```
乙授權給限制行為能力人甲 → 甲取得「代理權」
    代理權的「權」不是權利，是資格、地位、權限
    甲代理乙與丙締約 → 法律效果發生在乙丙之間 → 甲不是當事人、無權利無義務
→ 中性行為 → 類推 §77 但書 → 授權有效
```

### 方向反過來：限制行為能力人授權給別人
```
甲（限制）授權給乙 → 乙代理甲締約 → 效果及於甲 → 甲可能負義務 → 不純、也非中性
    日常生活所必需？看甲叫乙做什麼：幫忙買鹹酥雞 ✓；幫忙辦手機 ✗
不符合例外 → 授與代理權是【有相對人的單獨行為】（§167，不需被授權人同意）
    → §78 無效（不是 §79 效力未定）
```
- 只是授權不需要對方同意；若另訂委任、僱傭契約，另當別論。

## 三、無權處分（最難的中性行為）

#### 事實
乙把 A 車借給限制行為能力人甲。甲缺錢，把 A 車賣給善意的丙並交付。甲的法代全部拒絕承認。

#### 分析
```
① 甲丙買賣契約：甲負 §348 交付義務 → 不純 → §79 效力未定 → 法代拒絕 → 不生效力

② 甲丙移轉 A 車的物權行為：
    若有效會怎樣？丙得到 A 車、乙失去 A 車 → 都不關甲的事 → 甲無權利無義務
    → 中性行為 → 類推 §77 但書 → 【不受行為能力影響】
    但其他要件呢？甲沒有處分權 → 無權處分 → 【§118 效力未定】
    → 效力未定的原因是「無處分權」，要乙承認，不是法代承認
```
- 老師強調：不受行為能力影響 ≠ 一定有效，其他要件照看。

### 丙能不能善意取得？
```
買賣契約無效，丙還能善意取得嗎？
通說（王澤鑑）：可以。§801、§948 只要求「依物權行為受讓占有＋善意無重大過失」
    → 善意取得與債權行為無關（物權行為無因性）
→ 丙取得 A 車所有權 → 乙不是所有人 → 乙對丙 §767 ✗
```

### 乙怎麼把車要回來：直接不當得利 vs 雙重不當得利

| | 直接不當得利請求權說 | 雙重不當得利請求權說（通說） |
|---|---|---|
| 作法 | 乙直接對丙 §179 | 乙對甲 §179，請求甲讓與「甲對丙的不當得利請求權」；乙再以該請求權向丙請求返還 A 車 |
| 問題 | 甲丙買賣無效，丙本可對甲主張「你不還價金、我不還車」（§264 同時履行抗辯）；乙直接告丙，丙的**固有抗辯用不上** | 乙用的是甲的請求權 → 丙對甲的抗辯**不受影響** |
| 採否 | 德國通說、王澤鑑：**不採**（三人關係不當得利） | **採** |

```
雙重不當得利的結構
乙 ──§179──→ 甲：你多了一個「對丙的不當得利請求權」（車不是你的，你卻能叫丙還）→ 這個利益歸我
乙 ──行使甲對丙的 §179──→ 丙：還車（丙可對甲主張的同時履行抗辯仍保留）
```
- 老師：這是德國式的論證——不跳過既有法律直接創造結果，而是在現有條文裡找到一條走得通的路；德國教科書執著「把畫拿回來」而不是賠錢，與二戰藝術品流失有關。
- 這題後續在不當得利法會再講第二遍。
