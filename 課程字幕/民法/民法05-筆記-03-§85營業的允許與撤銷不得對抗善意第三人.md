# 民法05 筆記：§85 營業的允許與「撤銷不得對抗善意第三人」

> 來源：民法05 課程字幕 00:21:40 ~ 00:30:33

---

## 📖 法條原文速查

> **§85**（獨立營業之允許）
> I 法定代理人允許限制行為能力人**獨立營業**者，限制行為能力人，**關於其營業**，有行為能力。
> II 限制行為能力人，就其營業有**不勝任**之情形時，法定代理人得將其允許**撤銷或限制**之。但**不得對抗善意第三人**。

> **§1087**（特有財產）
> 未成年子女，因繼承、贈與或其他**無償**取得之財產，為其特有財產。
> → 打工所得是有償取得 → 不是特有財產 → 不適用 §1088 → 回歸民總 §85 判斷

> **§348 I**（出賣人之義務）→ 善意第三人主張契約有效後據以請求履行

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「父母允許子女到超商打工，子女參加員工團保、買制服、參加員工旅遊，須再經允許？」 | **不須**，關於其營業範圍內有行為能力 |
| 「子女以打工所得 4 萬元購買二手機車？」 | 買機車**與營業無關** → 不在 §85 範圍 → 須另得允許（二試考過） |
| 「法代撤銷營業允許後，子女仍與善意乙締約？」 | **不得對抗善意乙** → 乙得主張契約有效（亦得主張無效） |
| 「§85 II 用『撤銷』而非『撤回』？」 | 允許已生效 → 用**撤銷**；未生效才叫撤回 |
| 「打工所得是否為特有財產？」 | **否**（有償取得），無 §1088 適用，回民總處理 |

---

## 一、§85 的兩個重點

```
① 範圍：關於其營業 → 跟營業有關的才算
② 撤銷或限制 → 不得對抗善意第三人
```

## 二、範圍：跟營業有關才算

| 行為 | 在「關於其營業」內？ |
|------|------|
| 父母允許到超商打工 → 參加員工團體保險、購買制服、參加員工旅遊 | ✓ 不用再經同意 |
| 打工兩個月賺 4 萬，買一台二手機車 | ✗ 與工作無關 → 要重新得到允許 |

- §85 只是讓小孩在營業範圍內不受父母干涉；其他與營業無關的行為不在內。

### 延伸：打工所得怎麼處理（身分法愛考）
```
特有財產（§1087）＝ 繼承、贈與、其他無償取得 → 使用收益管理處分依 §1088
打工所得 ＝ 有償取得（勞力所得）→ 不是特有財產 → 無 §1088 → 回歸民總
    → 看這筆錢的用途有沒有在 §85「關於其營業」範圍內
```

## 三、撤銷不得對抗善意第三人

#### 事實
16 歲甲經法代允許經營二手網拍。甲收 50 元賣 60 元，扣運費虧本。法代認為甲不勝任，**撤銷**允許。甲仍與乙成立買賣契約。

#### 分析
```
「對抗」是抗辯 → 前面一定先有主張
    乙主張：甲經法代允許 → 買賣契約有效 → 依 §348 請求履行
乙善意 → 法代不得以「允許已撤銷」對抗乙 → 乙說了算 → 契約有效
乙惡意 → 法代得對抗 → 回到未經允許 → §79 效力未定 → 只能催告確定效力
```
- 教科書的說法：不得對抗善意第三人，第三人**既得主張該行為有效，亦得主張無效**——主張權在第三人手上。
- 用語：允許已經發生效力 → 針對已生效的意思表示用「撤銷」；還沒生效的才用「撤回」。
