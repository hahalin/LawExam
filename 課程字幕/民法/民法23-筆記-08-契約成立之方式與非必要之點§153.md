# 民法23 筆記：契約成立之方式與非必要之點（§153）

## 先跳過給付義務群：
- 講義 365 頁給付義務群（主給付、從給付、附隨義務、先契約與後契約義務）延到債務不履行再講
- 理由：現在講不到違反後的法律效果

## 契約成立的四種方式（講義 379 頁起）：
- **要約＋承諾**（§153 以下）
- **交錯要約**（無明文）
- **意思實現**（§161）
- **強制締約**（特別法）
- 交錯要約、意思實現、強制締約見民法23-筆記-12

## §153 I：
- 當事人互相表示意思一致，**明示或默示**皆可，契約即成立

## §153 II 的關鍵字：「該」
- 必要之點一致，而非必要之點**未經表示意思** → **推定**契約成立
- 「關於**該**非必要之點」意思不一致時 → 法院依事件性質定之
- 「該」指的是**前面那個未經表示的非必要之點**，兩處講的是同一件事

## 三種情形：
- 全部的點都一致 → 契約成立
- 必要之點一致、非必要之點**一開始沒表示** → 推定成立；事後才吵 → **法院定之**（已推定成立，不再讓它不成立）
- 必要之點一致、非必要之點**一開始就不一致** → 契約**不成立**，不是交給法院

## 例：清償地
- 買賣時雙方對清償地沒表示意見 → 推定成立；事後一方說臺北、一方說臺南 → 法院依事件性質定之
- 締約時就為了臺北或臺南交付吵不攏 → 契約根本不成立

## 常見誤解：
- ✗「非必要之點不一致，一律由法院定之」
- ✓ 要分「一開始沒表示、後來不一致」與「一開始就不一致」

## 📖 法條原文速查

> **§153**　I 當事人互相表示意思一致者，無論其為**明示或默示**，契約即為成立。II 當事人對於**必要之點**，意思一致，而對於非必要之點，**未經表示意思**者，**推定**其契約為成立，關於**該**非必要之點，當事人意思不一致時，法院應依其事件之性質定之。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「必要之點一致、非必要之點未表示，契約？」 | **推定**成立 |
| 「非必要之點自始意思不一致，契約？」 | **不成立** |
| 「非必要之點未表示、嗣後爭執，如何處理？」 | 法院依事件性質定之 |
| 「契約成立可否默示？」 | **可以**，明示或默示均可 |
| 「§153 II 是視為還是推定？」 | **推定**（可舉反證推翻） |

---

## 判斷流程

```
必要之點一致？
 ├─ 否 → 契約不成立
 └─ 是 → 非必要之點？
          ├─ 全部一致 ────────────→ 成立
          ├─ 一開始沒表示 ────────→ 推定成立
          │      └─ 事後吵 → 法院依事件性質定之
          └─ 一開始就不一致 ──────→ 不成立
```
