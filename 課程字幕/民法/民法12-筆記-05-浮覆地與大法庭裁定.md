# 民法12 筆記：浮覆地問題——大法庭裁定 vs 憲判字第 20 號

> 來源：民法12 課程字幕 00:31:14 ~ 00:43:29（板書 P.307）

---

## 📖 法條原文速查

> **§125**（一般消滅時效）
> 請求權，因**十五年**間不行使而消滅。但法律所定期間較短者，依其規定。

> **§144**（時效完成之效力）
> I：時效完成後，債務人得**拒絕給付**。
> → 本筆記核心爭點：國家能不能用這條擋人民？

> **§148**（誠信原則）
> II：行使權利，履行義務，應依**誠實及信用**方法。
> → 大法庭觀點：即使國家可主張 §144，也必須通過 §148 的檢驗。

> **§767**（所有人之物上請求權）
> I 中段：對於妨害其所有權者，得**請求除去**之。
> → 人民用這條請求國家**塗銷**國有登記。

> **憲法 §15**（財產權保障）
> 人民之生存權、工作權及**財產權**，應予保障。
> → 憲判字第 20 號觀點：這條保障的是**人民**，國家不享有財產權的基本權保障。

---

## 📋 實務見解速查

> **釋字 107 號**：已登記不動產所有人之 §767 I 前段，無 §125 消滅時效之適用。

> **釋字 164 號**：已登記不動產所有人之 §767 I 中段，無 §125 消滅時效之適用。

> **大法庭裁定**：「已登記」限縮解釋為**依我國法登記**。日據時期依日本法登記 ≠ 已登記。國家可主張 §144，但受 §148 限制。

> **112 年憲判字第 20 號**：國家不受憲法 §15 財產權保障，不得對浮覆地原所有人主張 §144 時效抗辯。容許國家主張時效 ≈ 變相徵收，違反正當法律程序。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「日據時期辦理之登記，是否為釋字 107 之『已登記』？」 | **大法庭：否**（限縮為依我國法登記） |
| 「對浮覆地，國家得否主張消滅時效抗辯？」 | **大法庭：得**（但受 §148 限制）；**憲判字第20號：不得** |
| 「國家有無受憲法 §15 財產權保障？」 | **無**。國家為人民存在，不享有基本權（憲判字第 20 號） |
| 「大法庭與憲法法庭見解有何不同？」 | 大法庭＝法律層次（限縮解釋＋誠信原則）；憲法法庭＝憲法層次（直接否定國家的時效抗辯） |
| 注意：兩見解在**同一個案**中產生，考試可能要你比較 | 記住結論差異：大法庭「可以但有但書」vs 憲判「不可以」 |

## 一、浮覆地的故事背景

### 時間線（板書 P.307）

```
日據時期          光復          民國60~80年代          15年後
    │              │              │                    │
 甲＝A地        A 沉沒         A 浮覆               甲的繼承人
 （已登記）     （河水覆蓋）    （重新浮出）          發現此事
                               ↓                       │
                          甲繼承人未辦登記          向國家主張
                               ↓                   §767 I 中
                          國家地籍總登記             塗銷國有登記
                          → A 登記為國有                │
                                                  國 §144？
```

### 事實要素
1. **日據時期**：甲登記為 A 地所有人（依日本法登記）
2. **土地沉沒**：A 地被河水覆蓋（浮覆地的「沉沒」階段）
3. **臺灣光復後**：A 地浮出（浮覆），但甲的繼承人不知此事，未辦登記
4. **民國 60~80 年代**：國民政府進行全國地籍總登記，A 地公告無人認領→登記為**國有**
5. **超過 15 年後**：甲的繼承人因緣際會發現，想依 §767 I 中段塗銷國有登記

### 核心爭點
> 國家能否主張 §144 時效抗辯，拒絕塗銷？

---

## 二、大法庭裁定——限縮解釋「已登記不動產所有人」

### 解釋路徑

大法庭對釋字 107、164 號中的「**已登記**」三個字做文義解釋：

| 登記類型 | 是否為「已登記不動產」 | §767 時效 |
|---------|---------------------|-----------|
| **依我國法登記** ✓ | **是** → 釋字 107、164 適用 | 原則**無**消滅時效 |
| **依日本法登記** ✗ | **否** → 不在釋字 107、164 承認之列 | **有**消滅時效（§125，15 年） |

### 推導結論

```
甲在日據時期依日本法登記
     ↓
不算「已登記不動產所有人」
     ↓
§767 有消滅時效適用（§125，15 年）
     ↓
國家可主張 §144 時效抗辯 ✓
     ↓
 但是......是否違反 §148 誠信原則？
```

### §148 誠信原則的補充審查

大法庭進一步指出，國家主張時效抗辯時，仍須檢視**是否違反誠信原則**：

| 審查要素 | 說明 |
|---------|------|
| 公告是否依法為之？ | 土地浮覆後，國家有無依法公告 |
| 公告時間是否充足？ | 是否給予人民合理的知悉期間 |
| 有無依法通知？ | 是否盡到告知義務 |

> 如國家未盡公告/通知義務而逕行登記為國有，再主張時效抗辯 → 有違反誠信原則之虞

---

## 三、憲判字第 20 號（112 年）——國家不得主張時效抗辯

### 結論（板書標記：憲 → 國 144 ✗）

> **國家在此情形不能主張 §144 時效抗辯**

### 三大理由

| 項次 | 論點 |
|------|------|
| **① 國家無財產權** | 國家不受憲法 §15 財產權保障。國家為人民而存在，不能如人民般追求私益，只能追求公益 |
| **② 制度正當性** | 登記制度的變動（日治→光復→地籍總登記）非人民合意，而是國家單方行使統治權的結果 |
| **③ 不得變相徵收** | 容許國家透過「土地總登記 + 時效抗辯」剝奪人民財產 ≈ 無需踐行徵收程序即可取得土地，違反正當法律程序 |

### 核心邏輯

```
登記制度變動 ≠ 人民合意
     │
     ↓
人民在政權更替之際不知、也難以知悉法律變動
     │
     ↓
不能苛責人民未及時辦理登記
     │
     ↓
國家無受財產權保護之必要
     │
     ↓
國家不得主張時效抗辯（§144）
     │
     ↓
人民主張 §767 I 中段塗銷登記 → 國家應塗銷
```

## 四、大法庭 vs 憲判字第 20 號 對照

| | **大法庭裁定** | **憲判字第 20 號** |
|--|---------------|-------------------|
| **對「已登記」的解釋** | 限縮：僅指依我國法登記 | （不以此為爭點） |
| **國家 §144 時效抗辯** | **可以**（但受 §148 誠信原則限制） | **不可以** |
| **處理方式** | 法律解釋層次：限縮 + 誠信原則補充 | 憲法層次：直接否定國家的時效抗辯權利 |
| **理論依據** | 文義解釋 + 誠信原則 | 國家無財產權 + 禁止變相徵收 |
| **實質結論** | 國家主張時效若違反誠信 → 駁回 | 國家一律不得主張時效 |

### 兩者差異的制度層次

```
憲法法庭（憲判字第 20 號）
  → 討論的是：既有規範是否違憲？人民基本權如何保護？
  → 結論：國家不得主張時效抗辯

大法庭（最高法院）
  → 討論的是：在現有法律框架內如何解釋？
  → 結論：可以主張，但受誠信原則限制
  → 受法律及大法官解釋拘束，只能在既有規範內做解釋
```
