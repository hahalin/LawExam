# 民法10 筆記：§169 表見代理的兩種歸責事由——「由自己之行為表示以代理權授與他人」：重點在「行為表示」（有行為、無授權的意思表示；交身分證印章託領掛號信）；「知他人表示為其代理人而不為反對之表示」（離職保險業務員）；效果直接寫「負授權人責任」；但書明知或可得而知者不在此限 → 只有善意且無過失才保護；四種創造外觀的情形

> 來源：民法10 課程字幕 01:28:01 ~ 01:35:00（§169 一試二試都常考，實務見解很多）

---

## 📖 法條原文速查

> **§169**　由自己之行為表示以代理權授與他人，或知他人表示為其代理人而不為反對之表示者，對於第三人應負授權人之責任。但第三人明知其無代理權或可得而知者，不在此限。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§169 第一種情形是授權嗎？」 | **不是**。關鍵不在「授權」兩字而在「**行為**表示」：授權是法律行為、需要**意思**表示；行為表示只是有一個行為讓人覺得你授權了，但你沒有授權的意思 |
| 「表見？」 | 「看起來好像」。手牽手看起來像情侶、看起來像孕婦——不一定是。表見代理＝看起來好像有授權 |
| 「甲將身分證、印章交乙保管，託其代領掛號信；乙持以向丙借款？」 | 甲內心無授權借款之意，但交付身分證印章的**行為**在外觀上像授權 → 「由自己之行為表示以代理權授與他人」→ 第三人善意無過失 → 甲負授權人責任（可歸責≠有過失，筆記 10） |
| 「保險業務員離職後仍持名片以公司名義招攬保單，公司知情不反對；業務員私吞保費？」 | 「知他人表示為其代理人而不為反對之表示」→ 保戶善意無過失 → 保險公司負授權人責任 |
| 「§169 與 §107 之效果用語？」 | §107「不得對抗善意第三人」（第三人可要求本人負責、本人不得抗辯）；§169 直接寫「應負**授權人之責任**」，意思相同 |
| 「§169 但書？」 | 第三人**明知**（惡意）或**可得而知**（善意但有過失）→ 本人不負責 → 只有**善意且無過失**才受保護，與 §107 後半段完全相同 |
| 「創造授權外觀的四種情形？」 | §107：① 代理權之限制 ② 代理權之撤回；§169：③ 由自己之行為表示授權 ④ 明知他人表示為代理人而不反對 |

## 一、§169 的結構

```
歸責事由 ①「由自己之行為表示以代理權授與他人」—— 積極：有行為、無授權意思
         ②「知他人表示為其代理人而不為反對之表示」—— 消極：知道他在外面招搖撞騙卻不反對
相對人   善意且無過失（但書排除明知、可得而知）
效果     本人對第三人負授權人責任（＝當有權代理處理，是履行責任不是損害賠償）
```

## 二、第一種：行為表示 ≠ 意思表示

| | 授權（§167） | §169 第一種 |
|---|---|---|
| 性質 | 法律行為，需**意思表示** | 只是一個**行為**，沒有授權的意思 |
| 例 | 「我授權你幫我賣車」 | 把身分證、印章交給你保管（我只是要你幫我領掛號信） |
| 外觀 | 真的有代理權 | **看起來好像**有代理權 → 表見 |

- 很多人問「這不就是授權嗎？」→ 再看一遍法條：重點在前面的「由自己之**行為**表示」。授權是外觀，不是真的授權。

## 三、第二種：明知而不反對（消極）

```
離職保險業務員：離職時不會跟客戶講，手上還有名片，繼續打著公司名號招攬
公司明知 → 不反對（業績有一張是一張，收得到保費）→ 默認
有一天業務員私吞保費、保單沒轉給公司 → 保戶能否要公司負責？
→ 公司過去明知不反對所創造的外觀 → 保戶善意無過失 → 公司負授權人責任
```

## 四、§107 與 §169 用語對照

| | 用語 | 意思 |
|---|---|---|
| §107 | 不得對抗善意第三人 | 第三人主張本人要負責時，本人不能提出「已限制／撤回」的抗辯 |
| §169 | 應負授權人之責任 | 直接講：本人要負責 |
| 兩條但書 | 因過失而不知／明知或可得而知 | 都是只留下**善意且無過失** |

## 五、本筆記之後的 §169 爭點（各自成一筆記）

- 明知不反對的時點：102 台上 1778（筆記 09）
- 外觀如何認定、可歸責與外觀分開、本人不以有過失為必要：70 台上 657（筆記 10）
- 法定代理、代表無 §169 適用：79 台上 2012（筆記 11）
