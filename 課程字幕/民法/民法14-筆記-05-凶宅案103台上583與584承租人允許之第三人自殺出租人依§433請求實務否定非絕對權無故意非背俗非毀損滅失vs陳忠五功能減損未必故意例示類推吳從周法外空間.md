# 民法14 筆記：自殺致房屋成為凶宅案（**103 台上 583、103 台上 584**；講義 37 頁）——甲出租房屋予乙，乙允許丙居住（583：姑姑為剛考上大學的侄子租屋，侄子燒炭；584：萊爾富承租店面，店員在倉庫上吊），甲依 **§433** 對乙請求：三要件①丙是同居人或經承租人允許使用之第三人 ✓ ②丙有**應負責之事由**（甲丙無契約 → 問丙有無侵權行為）③致租賃物**毀損滅失**；**實務否定**：凶宅只是抽象價值減損、未破壞所有權 → 無絕對權受侵害 → §184 I 前段 ✗；自殺目的多端、無使房屋成為凶宅之**故意**，自殺亦未達**背於善良風俗**→ 後段 ✗；非物理上毀損滅失 → 要件③ ✗。**陳忠五**（少數說）：①**物之功能性減損**（§765 使用收益處分權能受減損即所有權侵害，不須完全喪失）→ 前段可 ②退步採否定說，仍有**未必故意**（預見成為凶宅仍執意為之，不違本意）＋背俗重點在「致他人房屋成為凶宅」而非自殺本身 → 後段可 ③「毀損滅失」是**保管義務違反**之例示，或**類推 §433** → 甲得請求；結論三角度（加害人行為自由／被害人權利保護／公共政策威嚇預防）；**吳從周**：**法外空間理論**（自殺非法律所能評價 → 無從認定不法 → 無應負責事由）；下級審多採肯定，由繼承人於遺產範圍內負責

> 來源：民法14 課程字幕 00:37:05 ~ 00:59:30（講義 37～43 頁；陳忠五結論在 43 頁）

## 📖 法條原文速查

> **民法 §433**　因承租人之同居人或因承租人允許為租賃物之使用、收益之第三人應負責之事由，致租賃物毀損、滅失者，承租人負損害賠償責任。
> **民法 §765**　所有人，於法令限制之範圍內，得自由使用、收益、處分其所有物，並排除他人之干涉。
> **民法 §1148 II**　繼承人對於被繼承人之債務，以因繼承所得遺產為限，負清償責任。

---

## 📋 實務見解速查

> **103 年台上字第 583 號、第 584 號判決**（講義 37 頁）：房屋成為凶宅不當然致房屋物理上毀損滅失，僅生抽象之價值減損，係純粹經濟損失，未侵害所有權；自殺者目的不一而足，難認有使房屋成為凶宅之故意，自殺亦難謂背於善良風俗；§433「毀損滅失」指物理上之毀損滅失 → 出租人不得依 §433 向承租人請求。（要旨依老師講解整理，原文請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§433 之三要件？」 | ①承租人之同居人或經承租人允許使用收益之第三人 ②該第三人**應負責之事由** ③致租賃物毀損滅失 |
| 「第三人在租屋內自殺致凶宅，出租人得否依 §433 向承租人請求？實務？」 | **否定**。要件②：丙對甲無契約，問侵權——凶宅只是價值減損、非絕對權侵害（§184 I 前段 ✗）；自殺無致凶宅之故意、亦非背俗（後段 ✗）；要件③：非物理上毀損滅失 |
| 「陳忠五怎麼說？」 | ①**物之功能性減損**說：§765 使用收益處分權能受減損（無法安心居住、無法以正常價格出租出售）即所有權侵害，不須權能完全喪失 → 前段 ✓ ②縱採否定說，自殺者對成為凶宅若有預見仍執意 → **未必故意**；背俗之重點在「使他人房屋成為凶宅」（跳河、深山上吊不影響他人即不背俗）→ 後段 ✓ ③§433 毀損滅失是保管義務違反之**例示**，凶宅價值減損亦在內；或**類推** §433 |
| 「多數說 vs 陳忠五對『所有權侵害』的差別？」 | 多數說：須使用收益處分權能**完全喪失**（不能住、不能租、不能賣）；陳忠五：權能**受影響、有所減損**即可 |
| 「吳從周的法外空間理論？」 | 自殺涉宗教、社會、感情因素，非法律所能評價 → 無法認定合法或不法 → 不構成民事責任 → 無「應負責事由」→ 無 §433。老師：國考可寫「另有學者認為」，不建議作答題主軸（研究所可） |
| 「下級審實務？」 | 蠻多地院、高院採肯定，判自殺者之**繼承人於所得遺產範圍內**負賠償責任（§1148 II 概括繼承有限責任） |
| 「侵權行為規範功能三角度（陳忠五結論，寫考卷好用）」 | ①加害人：以賠償責任限制行為自由——自殺致他人房屋成凶宅，有無必要以免責保護其行為自由？②被害人：房屋權利全無保護價值？③公共政策：賠償責任之威嚇可預防損害，縱成效有限亦不應放棄 |

## 一、涵攝流程

```
§433 要件①：丙＝經乙允許使用之人 ✓（侄子／店員皆是）
§433 要件②：丙應負責之事由 → 甲丙無契約 → 丙有無侵權行為？
   有損害 ✓（房價減損）
   有權利受侵害？ 實務 ✗（抽象價值減損，純粹的）／陳忠五 ✓（功能性減損）
   §184 I 後段？ 實務 ✗（無故意、非背俗）／陳忠五 ✓（未必故意＋致凶宅背俗）
§433 要件③：毀損滅失？ 實務 ✗（限物理）／陳忠五 例示或類推 ✓
```

## 二、兩種論述脈絡

| | 實務（103 台上 583/584） | 陳忠五 |
|---|---|---|
| 權利侵害 | 無（所有權未被破壞） | 有（§765 權能減損＝功能性減損） |
| 故意 | 無（自殺目的非為凶宅） | 未必故意可該當 |
| 背於善良風俗 | 自殺雖不被接受但未達背俗 | 重點不在自殺，在使他人房屋成凶宅 |
| 毀損滅失 | 限物理上 | 例示規定／類推適用 |
| 結論 | 甲不得依 §433 請求 | 甲得請求 |

## 三、吳從周：把問題拉到最上層

- 大家都卡在「凶宅損害是權利還是利益」→ 前段或後段 → 後段有無故意背俗。
- 吳從周問的是：自殺**是不是法律可以評價的事**？不能評價 → 不能說你不法 → 無民事責任 → 無應負責事由 → 無 §433。
- 老師保留：自殺作為法外空間可接受，但**自殺造成的房屋價值減損**難道沒有保護價值？在自殺自由與房屋所有權保護之間，老師較支持陳忠五。
