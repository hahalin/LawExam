# 民法07 筆記：動機錯誤的兩種特殊情形——相對人明知／故意利用（仍不得撤銷，走 §148）；雙方動機錯誤（誠信原則或類推 §227-2 調整）

> 來源：民法07 課程字幕 00:51:20 ~ 01:00:48

---

## 📖 法條原文速查

> **§88 I**　內容錯誤、表示行為錯誤得撤銷（動機錯誤不在內）
> **§148**　I 權利之行使，不得違反公共利益，或以損害他人為主要目的。II 行使權利，履行義務，應依誠實及信用方法。
> **§367**　買受人對於出賣人，有交付約定價金及受領標的物之義務。
> **§227-2 I**（情事變更原則）契約成立後，情事變更，非當時所得預料，而依其原有效果顯失公平者，當事人得聲請法院增、減其給付或變更其他原有之效果。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲誤以為 A 畫很值錢而向乙購買，乙**明知**甲有此動機錯誤，甲得否依 §88 撤銷？」 | **不得**（王澤鑑）。相對人不須承擔表意人動機錯誤的風險；買東西要自己做功課，老闆沒有說破的義務 |
| 「乙不僅明知，更**故意利用**甲的動機錯誤與之締約？」 | 仍**不得依 §88 撤銷**（動機錯誤不是 §88 類型）。但乙取得債權不依誠信方法 → 乙依 §367 請求履行屬**權利濫用**，依 **§148** 限制 → 法院判乙之請求無理由 |
| 「甲乙**雙方**都誤以為土地將重劃為建地（雙方動機錯誤）？」 | 不是撤銷讓契約全部無效，而是**調整契約內容**：王澤鑑用**誠信原則**；陳聰富**類推 §227-2 情事變更** |

## 一、單方動機錯誤 ＋ 相對人的主觀狀態

```
甲：誤以為 A 車／A 畫很值錢（動機錯誤）→ 向乙購買
乙：
  層次 ① 明知甲有動機錯誤，沒阻止
  層次 ② 明知，而且故意利用這個錯誤誘使甲締約
```

| 乙的狀態 | 甲能否依 §88 撤銷 | 理由 | 救濟 |
|------|------|------|------|
| 明知 | ✗ | 相對人不需承擔表意人動機錯誤的風險；甲自己沒做查證、沒蒐集資訊 → 自己吞 | 無 |
| 明知＋故意利用 | ✗（動機錯誤就不是 §88 的類型，找不到撤銷依據） | 「這樣很壞」→ 用誠信原則處罰 | 乙依 **§367** 請求甲付價金、受領 → **權利濫用** → **§148** 限制 → 無理由 |

```
處理位置：不在「意思表示瑕疵」，退到「誠信原則」
王澤鑑的邏輯：動機不是交易要素，不能讓它影響契約效力 → 無論如何不能撤
            但不能撤 ≠ 沒救 → 從權利行使那端擋
```

## 二、雙方動機錯誤
```
甲乙都誤判情勢：都以為這塊地要重劃成建地 → 結果變道路用地／喪葬用地
英國法例：甲向乙租閣樓看女王登基大典，兩人一起記錯日期
```

| | 王澤鑑 | 陳聰富 |
|---|---|---|
| 工具 | **誠信原則**調整契約內容 | **類推 §227-2 情事變更**，聲請法院調整 |
| 共同點 | 雙方要的不是契約無效，是把契約調整到符合雙方真意的狀態 → 找**調整機制**，不是撤銷 | |

- 為什麼不乾脆讓雙方都依 §88 撤銷？撤銷的結果是契約全部無效，但雙方都有錯誤時，要的是調整不是消滅。

## 關鍵法條速查表

| 法條 | 內容 | 與本主題關聯 |
|------|------|------------|
| §88 I | 錯誤撤銷 | 動機錯誤**不適用**，三種情形都不能撤 |
| **§148** | 誠信原則、權利濫用禁止 | 相對人故意利用時限制其請求 |
| §367 | 買受人義務 | 乙被限制的請求權 |
| **§227-2** | 情事變更 | 雙方動機錯誤（陳聰富類推） |
