# 民法15 筆記：精神上驚嚇之旁觀者求償

## 問題：
- 又稱情緒悲痛、精神上驚嚇（nervous shock）；考的是**旁觀者**能否請求
- 例：在超市目睹搶匪開槍射殺店主，留下 PTSD 等陰影；丙能否向行兇者乙請求

## 要件檢查：
- **損害**：精神上驚嚇、痛苦
- **權利受侵害**：須與**身體健康權**連結——要「嚇出病來」，如憂鬱症、精神官能症、PTSD
- **因果關係**：事實上 ✓；法律上很難 ✓——不是每個目睹者都會發病，常與個人體質有關

## 學者提出之限制要件（講義 121 頁）：
- ①丙與直接被害人甲**關係親密**（不限配偶，同居人、好友也可能）；路人被殺與你無關
- ②是否須**在現場以感官目睹**：英美法有判決要求在現場；**王澤鑑**認為事後被轉告、間接得知亦可；英國法甚至認為事後看到而精神崩潰亦可
- ③須有**重大精神痛苦**，即發生疾病而有身體健康權之侵害
- 學者認屬**身體健康權**侵害，上列要件是為避免責任無限擴大

## 陳聰富：重點只有一個：
- 上述要件的目的都在判斷：加害人對旁觀者之結果有無**客觀上合理可預見性**
- 乙殺甲時可預見丙目睹會受精神痛苦 → 就應負責

## 國考考過：高雄氣爆案：
- 妻在路邊等先生騎車來接，目睹先生因氣爆被炸上高空、摔落死於眼前，之後罹患憂鬱症；問能否請求慰撫金
- 妻非直接被害人，但因目睹而身體健康權受侵害；以關係親密、在場目睹、重大驚嚇綜合判斷，最重要者為**客觀可預見性**

## 📖 法條原文速查

> **民法 §184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。

> **民法 §195 I 前段**　不法侵害他人之身體、健康……被害人雖非財產上之損害，亦得請求賠償相當之金額。

> **民法 §194**　不法侵害他人致死者，被害人之父母、子女及配偶，雖非財產上之損害，亦得請求賠償相當之金額。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「目睹親人遇害而罹患精神疾病，旁觀者得否請求？」 | 得，屬旁觀者自身**身體健康權**受侵害；須符合關係親密、重大精神痛苦（發病）等要件 |
| 「單純驚嚇、未發病者？」 | 原則不足；須與身體健康權連結（**嚇出病來**） |
| 「是否以在現場親眼目睹為必要？」 | **有爭議**：英美法有判決要求；**王澤鑑**認間接得知亦可 |
| 「陳聰富認為判斷重點？」 | 加害人之**客觀合理可預見性** |
| 「為何旁觀者求償因果關係不易成立？」 | 不是每個目睹者通常都會發病（常與個人體質有關）→ 相當性難 |
| 「高雄氣爆案妻子目睹丈夫死亡而罹憂鬱症？」 | 國考考過；以親密關係、在場目睹、重大驚嚇綜合判斷，核心為客觀可預見性 → 得請求 |

## 一、要件圖

```
旁觀者丙目睹甲被乙侵害
   ↓
損害：精神驚嚇 ✓
權利：須「嚇出病來」→ 身體健康權受侵害
因果：條件 ✓／相當性難 → 學者設限制要件：
   ├── ① 丙與甲關係親密
   ├── ② 在場以感官得知（有爭議：王澤鑑認間接得知亦可）
   └── ③ 重大精神痛苦（發生疾病）
        ↓
陳聰富：以上皆在判斷乙之「客觀合理可預見性」
```

## 三、案例：高雄氣爆案（國考題）

#### 事實
- 丙在路邊等丈夫甲騎車來接，氣爆將甲炸上空中、摔落死亡；丙其後罹患憂鬱症。

#### 分析
1. 丙之身體健康權受侵害（罹患憂鬱症）；精神痛苦屬損害。
2. 因果關係：丙與甲為配偶（關係親密）、在現場親眼目睹、受重大驚嚇而發病。
3. 加害人對於配偶在旁目睹而受重大精神打擊，客觀上可預見。

#### 結論
- 丙得就自身健康權受侵害請求賠償（含慰撫金）。
- 補充：丙另可依 §194 以配偶身分就甲之死亡請求慰撫金，兩者性質不同（一為自身健康權，一為間接被害人之請求）。
