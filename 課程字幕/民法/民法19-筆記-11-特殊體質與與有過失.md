# 民法19 筆記：特殊體質與與有過失

## 承接蛋殼頭蓋骨理論：
- 特殊體質案件先在因果關係層次**擬制因果關係成立**，讓被害人可以求償
- 再以被害人未盡保護義務為由，用 §217 減輕 → 平衡雙方
- 問題：是不是所有特殊體質都有 §217？

## 與有過失的「過失」是對己義務之違反：
- 不是防範他人受害的注意義務，而是**避免自己受害**的注意義務
- 判斷：被害人有無**迴避可能**、有無**迴避義務**、是否違反

## 陳聰富：特殊體質分三類
- **身體特徵**（非疾病，如骨頭特別脆）→ 無從知道、無迴避可能 → **無** §217
- 疾病但在**個體差異容許範圍內**（如老人骨質疏鬆）→ 不具特殊性、根本不是特殊體質 → **無** §217
- 具**重大個體差異**之疾病 → 才賦予注意義務，未迴避 → **有** §217

## 一般體質與醫療過失：
- 例：麻醉劑量稍多，一般人不會死，病人因肝功能太差而死亡；胎兒因自身體質，在醫師輕微過失下死亡
- 肯定說：損害合理分配，體質有**原因力** → 類推 §217（**105 台上 136**）
- 否定說：體質不是過失 → 不能類推（**105 台上 358**、孫森焱）
- 向明恩：體質本身不是過失，否則特殊體質者不敢出門；應看被害人有無**積極治療、維護體質**
  - 有病不就醫、不照醫囑服藥、肝不好還喝酒 → 本身就是過失 → **直接適用** §217
  - 已就醫、按時服藥仍惡化 → 非過失 → 不適用

## 兩篇文章接起來：
- 先用陳聰富的分類判斷是不是特殊體質；是具重大個體差異之疾病，再用向明恩的標準看被害人有無盡到照顧自己的義務

## 📖 法條原文速查

> **§217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

> **§217 II**　重大之損害原因，為債務人所不及知，而被害人不預促其注意或怠於避免或減少損害者，為與有過失。

---

## 📋 實務見解速查

> **105 台上 358**（講義 241 頁註 374）：先天因子之存在非屬被害人之過失，類推 §217 將不利益歸由被害人負擔，於法有未合。（要旨改寫）

> **105 台上 136**（講義註 375）：應類推適用被害人與有過失之規定減輕賠償責任，以維當事人之公平。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「與有過失之過失性質？」 | **對己義務**之違反，重在迴避可能與迴避義務 |
| 「老人骨質疏鬆被撞成重傷，得主張特殊體質與有過失？」 | **否**，在個體差異範圍內，非特殊體質 |
| 「單純身體特徵（非疾病），有無 §217？」 | **無**，無迴避可能 |
| 「病人體質為損害原因之一，得否類推 §217？」 | 實務分歧：105 台上 136 **肯定**、105 台上 358 **否定** |
| 「肝病病人不遵醫囑仍飲酒，致損害擴大？」 | 向明恩：本身即過失，**直接適用** §217 |

## 一、判斷流程

```
被害人體質是損害原因之一
        ↓
是身體特徵？ ── 是 → 無迴避可能 → ✗
        ↓ 否（疾病）
在個體差異範圍內？ ── 是 → 不是特殊體質 → ✗
        ↓ 否（重大個體差異之疾病）
被害人有無積極治療、照顧自己？（向明恩）
├─ 未就醫、不遵醫囑 → ✓ §217
└─ 已盡力仍惡化 → ✗
```

## 二、醫療案件兩說

| | 肯定說 | 否定說 |
|---|---|---|
| 理由 | 體質有原因力，損害合理分配 | 體質不是過失 |
| 方法 | 類推 §217 | 不類推 |
| 實務 | 105 台上 136 | 105 台上 358、孫森焱 |
