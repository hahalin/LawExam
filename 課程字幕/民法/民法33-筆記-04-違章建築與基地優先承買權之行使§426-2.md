# 民法33 筆記：違章建築與基地優先承買權之行使（§426-2）

## 問題：
- 甲把 A 地租給乙，乙蓋的 B 屋是**違章建築**
- 甲未通知就把 A 地賣給丙並移轉登記
- 乙能不能像民法33-筆記-03 一樣請求丙塗銷、甲移轉？違建事後被拆會不會影響？
- 老師說高考二級考過，司律、司特還沒考

## 學說爭議：違建可否主張 §426-2
| | 少數說（吳從周） | 多數說（實務、多數學者） |
|---|---|---|
| 結論 | **不適用** | **適用** |
| 理由 | 目的性限縮：立法目的是避免拆屋還地、讓房地同歸一人；違建本來就要拆，沒有保護必要 | 違建在公法上有瑕疵要拆是一回事；**拆除前**在私法上仍是人民的財產，可為交易標的 |

## 實務：看違建有沒有拆、什麼時候拆
```
B 屋是違建
│
├── 尚未拆除 → 可以行使優先承買權
│
└── 已經拆除
    ├── 行使權利「之後」才拆 → 不受影響，仍可行使（103 台上 2188）
    └── 行使權利「之前」就拆 → 不能行使（沒有房屋了）
```

## 實務上真的有人這樣攻防：
- 違建承租人起訴確認優先承買權存在
- 出租人一看，立刻找主管機關來拆違建，主張「房子都沒了你憑什麼」
- 最高法院：已經行使的權利不因事後拆除受影響
- 結果：土地上已經沒有房子，承租人仍有優先承買權

## 📖 法條原文速查

> **§426-2 I**　租用基地建築房屋，出租人出賣基地時，承租人有依同樣條件優先承買之權。承租人出賣房屋時，基地所有人有依同樣條件優先承買之權。

> **土地法 §104**（要旨）　基地出賣時，地上權人、典權人或承租人有依同樣條件優先購買之權；房屋出賣時，基地所有權人亦同。→ 建議查閱最新六法原文

---

## 📋 實務見解速查

> **103 台上 2188**（要旨，字幕「1032188」，字號建議查證）：房屋縱為違章建築，且於起訴後因未能補正手續遭主管機關拆除，亦然。違建只是因行政管理規定不能辦理第一次所有權登記，非不得為交易標的而讓與事實上處分權；基地出售時房屋具一定經濟價值，且租約以在土地上有房屋為目的，不應因房屋事後被拆除而影響已取得之優先購買權，以貫徹使基地與房屋同歸一人所有之意旨。

> **108 台上 2350**（要旨，講義註 1114，字幕「1082350」，字號建議查證）：雖針對土地法 §104，但與 §426-2 相同。違章建築於主管機關**依法拆除前**，既實際存在且供居住使用，與合法建物無異，不排除優先購買權之適用。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「租地所建房屋為違建，承租人有優先承買權？」 | 實務**肯定**（拆除前） |
| 「行使優先承買權後違建遭拆除，權利消滅？」 | **否**，不受影響 |
| 「違建在行使前已拆除，仍可行使？」 | **否** |
| 「否定違建適用 §426-2 的方法？」 | **目的性限縮**（少數說） |
