# 民法二試03 筆記：撤銷拋棄繼承與遺產分割協議（§244 III）

## 案例（講義 184 頁括弧 2）：
- 甲死亡，遺產 1,000 萬，繼承人乙、丙；丙欠 A 銀行 500 萬
- 丙若照常繼承可分得 500 萬，A 可以強制執行；丙卻放棄 → A 能否依 §244 撤銷？
- 老師：還沒考過、可考性高、容易和其他觀念混考；**拋棄繼承**與**拋棄遺產**一定要分清楚

## 情形一：丙拋棄繼承 → 多數否定
- **§244 III**：非以財產為標的之行為不得撤銷；拋棄繼承是拋棄繼承人**資格**，屬**身分行為**（73 年第 2 次民事庭決議同此結論）
- **林秀雄（目的解釋）**：§244 保護的是債權人**可預見**的範圍；銀行放款看的是借款人現有資力，將來能繼承多少不在審查範圍 → 丙拋棄不算侵害 A 的債權

## 情形一的肯定說（字幕作陳聰健／陳聰陽，老師先口誤為陳聰富後更正，請對講義）：
- 舊制「概括繼承」可能帶來不利益，所以要給拋棄的自由
- §1148 II 修法改採**概括繼承有限責任** → 繼承已不會帶來不利益
- 此時拋棄繼承動機不純、以損害債權人為主要目的 → 依**誠信原則**例外允許 A 撤銷

## 情形二：丙與乙訂遺產分割協議，全部歸乙 → 得撤銷
- 最高法院 106 年判決（字號請對講義）：分割協議是**財產行為**，符合 §244 的撤銷標的 → A 得撤銷

## 📖 法條原文速查

> **民法 §244 I**　債務人所為之**無償行為**，有害及債權者，債權人得聲請法院撤銷之。
> **民法 §244 III**　債務人之行為**非以財產為標的**，或僅有害於以給付特定物為標的之債權者，不適用前二項之規定。
> **民法 §1148 II**　繼承人對於被繼承人之債務，以因繼承所得遺產為限，負清償責任。
> **民法 §148 II**　行使權利，履行義務，應依誠實及信用方法。

---

## 📋 實務見解速查

> **最高法院 73 年第 2 次民事庭會議決議**（要旨，原文請對講義）：拋棄繼承為身分行為，非 §244 得撤銷之標的。

> **最高法院 106 年判決**（字幕未唸字號，請對講義，要旨）：繼承人間之遺產分割協議為財產行為，債權人得依 §244 撤銷。

## 🎯 二試爭點提示

| 考法 | 論述關鍵 |
|---------|---------|
| 「丙拋棄繼承，A 得否依 §244 撤銷？」 | 爭點在 §244 III「非以財產為標的」：拋棄繼承是身分行為 → 多數否定 |
| 「否定說的目的解釋？」 | 林秀雄：將來繼承不在債權人可預見範圍，無保護必要 |
| 「肯定說理由？」 | §1148 II 有限責任後繼承無不利益，拋棄以損害他人為主要目的 → 誠信原則例外得撤銷 |
| 「丙改簽分割協議，全歸乙？」 | 財產行為 → 得撤銷（106 年判決） |
| 「題目陷阱？」 | 先看撤銷的是身分（拋棄繼承）還是財產（拋棄遺產）行為 |

## 二、論述骨架

```
A 對丙、乙：§244 I 撤銷（無償行為）
  ↓ 要件：無償 ✓、有害及債權 ✓（丙已無資力）
  ↓ 消極要件 §244 III：非以財產為標的？
  ├─ 拋棄繼承 → 身分行為 → 原則不得撤銷
  │     └─ 少數：§1148 II 修法 + 誠信原則 → 例外得撤銷
  └─ 分割協議 → 財產行為 → 得撤銷
```
