# 民法21 筆記：三角關係之給付型不當得利

## 三種型態（第四種利益第三人契約留到該處再講）：
- **給付連鎖**：甲賣 A 給乙並交付，乙再賣給丙並交付
- **縮短給付**：甲賣 A 給乙、乙賣 A 給丙，乙請甲直接把 A 交給丙（網購書請書商直接寄給朋友）
- **指示給付**：甲欠乙錢，乙欠丙承攬報酬，乙指示甲直接把錢匯給丙（多為金錢或不動產）
- 共同問題：甲乙、乙丙的原因關係**都無效**時，甲得否直接對丙請求？

## 給付連鎖的兩說：
- **直接不當得利請求權說**：甲直接向丙請求，省去兩段返還
  - 缺點：丙對乙**固有的抗辯**（例如同時履行抗辯）無法對甲行使，丙受不利益
- **雙重不當得利請求權說（通說）**：
  1. 甲對乙主張 §179，請求返還的標的是**乙對丙的不當得利返還請求權**
  2. 甲再以取得的乙之請求權，向丙請求返還 A
  - 結果一樣是直接從丙拿回 A，但用的是乙的權利 → 丙對乙的抗辯可對甲主張
- 背景：德國人重視物歸原主（兩次大戰後流落各處的藝術品），要原物不要錢

## 縮短給付、指示給付：同樣處理：
- 有人認為甲把東西直接交給丙，甲丙有直接給付關係 → 通說**否定**
- 「給付」是**有意識的給予**：不是看手把東西交給誰，而是看**心裡想著誰**
- 甲寄給丙時，想的是清償對乙的債務 → 給付關係在甲乙、乙丙**兩兩之間**
- 給付路徑只是物理上縮短，法律上的給付關係沒有縮短 → 一樣用雙重不當得利
- 三種型態結論相同：都用雙重不當得利請求權說，保障丙固有的抗辯

## 📖 法條原文速查

> **§179**　無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

---

## 📋 實務見解速查

> **105 年最高法院判決**（講義 306 頁註 489）：指示給付關係中，被指示人係為履行其與指示人間之約定而向領取人給付，對領取人原無給付目的；被指示人與指示人間之關係不存在時，被指示人僅得向**指示人**請求返還；領取人所受利益係本於指示人之給付，被指示人與領取人間無給付關係，**無從成立不當得利**。（要旨改寫；字號字幕未唸，建議查證）
> 對照本例：被指示人＝甲，指示人＝乙，領取人＝丙

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「給付連鎖兩契約皆無效，通說甲得直接依 §179 向丙請求？」 | **否**，採**雙重不當得利請求權說** |
| 「雙重不當得利說中，甲對乙請求返還之標的？」 | **乙對丙之不當得利返還請求權** |
| 「直接請求權說之缺點？」 | 丙對乙之**固有抗辯**被犧牲 |
| 「縮短給付中，甲直接交付丙，甲丙間有給付關係？」 | **否**，給付關係在甲乙、乙丙之間 |
| 「指示給付中，被指示人得向領取人請求返還？」 | **否**，應向指示人請求 |

## 一、三種型態

```
給付連鎖：甲 ──A──→ 乙 ──A──→ 丙
縮短給付：甲 ────A（乙請甲直接交付）────→ 丙
指示給付：甲 ────$（乙指示甲直接匯款）────→ 丙
給付關係（三種都一樣）：甲—乙、乙—丙
```

## 二、雙重不當得利請求權說

```
甲 ──§179──→ 乙：請求讓與「乙對丙之 §179」
   ↓
甲 持乙之 §179 ──→ 丙：返還 A
   └ 丙得以對乙之抗辯對抗甲
```

## 三、兩說對照

| | 直接請求權說 | 雙重不當得利說（通說） |
|---|---|---|
| 甲能否從丙取回 A | ✓ | ✓ |
| 丙對乙之抗辯 | 不能對甲主張 | 可對甲主張 |
| 與給付關係是否一致 | 否 | 是 |
