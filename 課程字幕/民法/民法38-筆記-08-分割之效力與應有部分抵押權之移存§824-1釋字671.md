# 民法38 筆記：分割之效力與應有部分抵押權之移存（§824-1釋字671）

## 分割效力何時發生（§824-1 I）
- **協議分割**：依法律行為的物權變動
  - 不動產 → 完成分割**登記**時（§758）
  - 動產 → 互相**交付**應有部分時
- **裁判分割**：形成判決，**判決確定時**即生效力；之後辦的登記只是宣示登記（§759）
- 記法：協議是「登記了才完成」；裁判是「先完成，再去登記」

## 先分清楚：共有物抵押 vs. 應有部分抵押
- 甲乙丙**全體同意**以整筆共有物設定抵押 → 分割後抵押權**不受影響**（§868）
- 甲**單獨**以自己的 1/3 應有部分設定抵押（§819 I，不需他人同意）→ 才是 §824-1 II 處理的問題

## 原則：客體不變說（§824-1 II 本文）
- 應有部分存在於土地的每一個抽象點上 → 丁的抵押權在土地每一點的 1/3 上
- 分割成 A1（甲）、A2（乙）、A3（丙）後，丁的抵押權**仍在 A1、A2、A3 各 1/3 上**

## 例外：移存於抵押人分得部分（§824-1 II 但書，客體集中說）
- 三種情形擇一，抵押權移到甲分得的 **A1 全部**：
  1. 抵押權人**同意**分割
  2. 抵押權人**已參加**分割訴訟
  3. 抵押權人經共有人**告知訴訟而未參加**
- 理由：A1 和原本的 1/3 哪個值錢，只有抵押權人自己在意；給他程序上表示意見的機會，有機會而不用就要承受結果

## 不受影響時如何實行：釋字671
- 丁實行抵押權，執行標的是分割後**各筆土地上轉載的應有部分**（A1、A2、A3 各 1/3）
- 拍定後：拍定人戊取得應有部分，**全部回復共有關係**——戊與乙、丙共有，各 1/3；乙丙回復分割前的應有部分
- 原分割等於不再存在，要的話重新分割
- 「不受影響」不只是抵押權人丁不受影響，**其他共有人乙丙也不受影響**

## 📖 法條原文速查

> **§824-1 II**（應有部分上之抵押權）應有部分有抵押權或質權者，其權利不因共有物之分割而受影響。但有下列情形之一者，其權利移存於抵押人或出質人所分得之部分：一、權利人同意分割。二、權利人已參加共有物分割訴訟。三、權利人經共有人告知訴訟而未參加。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 協議分割之不動產何時取得單獨所有權 | 完成分割**登記**時 |
| 裁判分割何時生效 | **判決確定時**，登記僅宣示性質 |
| 全體以共有物設定抵押後分割 | 不受影響（§868） |
| 應有部分抵押後分割，原則 | **不受影響**，仍存於各分得部分之應有部分上 |
| 移存於抵押人分得部分之情形 | 同意分割、參加訴訟、告知訴訟未參加 |
| 釋字671：拍定後效果 | 拍定人與其他共有人**回復分割前共有**關係 |

## 圖解：甲以 1/3 抵押給丁，之後分割

```
分割前：A 地（甲乙丙各 1/3）
        丁的抵押權 → 甲的 1/3（每一點上）

分割後  ┌ A1（甲） ┐
        │ A2（乙） │
        └ A3（丙） ┘
   ├─ 原則（不受影響）：丁 → A1、A2、A3 各 1/3
   │     └ 丁實行、戊拍定 → 戊、乙、丙 共有 A 地各 1/3（釋字671）
   └─ 例外（同意／參加／告知未參加）：丁 → A1 全部
```

## 對照表

| 項目 | 客體不變（原則） | 客體集中（例外） |
|---|---|---|
| 抵押權所在 | 各分得部分上轉載的 1/3 | 甲分得的 A1 全部 |
| 拍賣標的 | A1、A2、A3 各 1/3 | A1 |
| 對乙丙影響 | 拍定後回復共有，乙丙仍各 1/3 | 無 |
