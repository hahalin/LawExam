# 民法18 筆記：§191-3危險製造人責任

## 兩個推定：
- 但書：損害**非由於**工作活動或其工具方法所致（因果）、已盡**相當注意**（過失）→ 推定因果與過失，**不推定不法**

## 危險須為非日常之特殊危險：
- 公車行駛、醫療行為雖有危險，但屬**日常**危險，**不適用**
- 立法理由例示（講義 192 頁註 298）：工廠排放廢水廢氣、桶裝瓦斯填裝廠、爆竹廠、燃放煙火、變電所、高壓電線、瓦斯油料輸送管線；經營遊覽車事業**不包括**
- 註 299 最高法院判決：醫療行為非製造危險來源之事業，也非以危險獲利為主要目的 → 無 §191-3
- 八仙塵爆、高雄氣爆：典型特殊危險

## 責任主體是經營者：
- 條文雖有「從事」二字，但員工以勞力換報酬，**不是藉危險獲利**，不負 §191-3
- 負責者＝藉危險活動獲利之**危險事業經營者**

## 純粹經濟上損失：
- 王澤鑑：否定，§191-1～§191-3 只是調整舉證責任，保護法益同 §184
- 孫森焱、林誠二、**實務**：肯定，條文沒有「權利」二字
- 老師觀察：實務肯定的判決多是**損害很大、行為人有過失**，不讓其負責顯不合理 → 回到行為自由與權利保護之界限

## 📖 法條原文速查

> **§191-3**　經營一定事業或從事其他工作或活動之人，其工作或活動之性質或其使用之工具或方法有**生損害於他人之危險**者，對**他人之損害**應負賠償責任。但損害**非由於**其工作或活動或其使用之工具或方法所致，或於防止損害之發生**已盡相當之注意**者，不在此限。

---

## 📋 實務見解

> **註 299 最高法院判決**（講義 192 頁）：醫療行為並非從事製造危險來源之危險事業或活動，亦非以從事危險事業或活動而獲取利益為主要目的，與 §191-3 立法理由所例示之工廠排放廢水廢氣等不同，無本條之適用。（字號請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「病人因手術併發症受損，得否依 §191-3 請求醫院？」 | **否**，醫療非 §191-3 之危險（實務） |
| 「被遊覽車、公車撞傷，得否主張 §191-3？」 | **否**，日常危險；改用 §191-2 |
| 「爆竹工廠爆炸波及鄰居，得否主張 §191-3？」 | **得**，立法理由例示 |
| 「危險工廠之員工應否負 §191-3 責任？」 | **否**，限藉危險獲利之經營者 |
| 「§191-3 推定哪些要件？」 | **因果、過失**，不推定不法 |
| 「§191-3 是否保護純粹經濟上損失？」 | **有爭議**：王澤鑑否定；實務、孫森焱、林誠二肯定 |

## 一、構成要件

```
§191-3
├─ 主體：經營一定事業或從事工作活動之人
│    → 限藉危險獲利之經營者（不含員工）
├─ 危險：工作活動性質或工具方法有生損害於他人之危險
│    → 非日常之特殊危險
│      ✓ 廢水廢氣、瓦斯填裝、爆竹、煙火、變電所、高壓電、輸送管線、塵爆、氣爆
│      ✗ 公車、遊覽車、醫療
├─ 他人之損害（純粹經濟上損失有爭議）
└─ 但書：因果、過失之推定
```

## 二、為何員工不負責

| | 經營者 | 員工 |
|---|---|---|
| 與危險之關係 | 藉危險活動獲利 | 在危險環境中工作 |
| 對價 | 營業利益 | 勞力報酬 |
| 應否為危險負責 | 是（報償理論） | 否，否則顯不合理 |

## 三、§191-1～§191-3 純粹經濟上損失總整理

| 條文 | 用語 | 王澤鑑 | 其他見解 |
|---|---|---|---|
| §191-1 商品 | 所致他人之損害 | 否 | 林誠二、孫森焱肯定 |
| §191-2 車輛 | 加損害於他人 | 否 | **多數亦否**（少爭議） |
| §191-3 危險 | 他人之損害 | 否 | 林誠二、孫森焱、**實務**肯定 |

- 王澤鑑的一貫立場：特殊侵權行為只調整舉證責任，不得突破 §184 絕對權與純粹經濟上損失之劃分；過失之純粹經濟上損失不賠，故意者回 §184 I 後段
- 實務肯定的典型：下一份筆記的蚵條案
