# 民法03 筆記：繼續性・經濟性・固定性——輕便軌道、封頂、電線桿

> 來源：民法03 課程字幕 01:51:54 ~ 02:10:01

---

## 📖 法條原文速查

> **§66 I**　稱不動產者，謂土地及其定著物。

> **§126**（五年短期時效）
> 利息、紅利、**租金**、贍養費、退職金及其他一年或不及一年之定期給付債權，其各期給付請求權，因**五年**間不行使而消滅。

> **§127 ③**（二年短期時效）
> 左列各款請求權，因**二年**間不行使而消滅：……三、以**租賃動產**為營業者之租價。

> **§758 I**（對照：不動產物權變動）
> 不動產物權，依法律行為而取得、設定、喪失及變更者，非經**登記**，不生效力。
> **§761 I**（對照：動產物權變動）
> 動產物權之讓與，非將動產**交付**，不生效力。

## 📋 實務見解速查

> **釋字第 93 號**：輕便軌道除係**臨時敷設**者外，凡**繼續附著於土地**而達其**一定經濟上之目的**者，應認為不動產。
> → 金世鼎大法官不同意見書（講義 86 頁註 104）：未論及**固定性**；若可輕易拆卸仍認不動產，則電線桿等莫不為不動產，歷來學說將破毀無餘。

> **63 年第 6 次民庭決議**（後半段）：凡**屋頂尚未完全完工之房屋，其已足避風雨，可達經濟上使用之目的者**，即屬土地之定著物。

> **最高法院 106 年度台上字第 1882 號判決**（講義 87 頁註 105）：電線桿**不易移動其所在**，具固定性，為**不動產**；其租金請求權時效適用 §126 五年，非 §127 ③ 二年。
> → 建議查閱判決原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「輕便軌道之法律性質？」 | 釋字 93：除臨時敷設者外為**不動產**（選擇題選這個） |
| 「釋字 93 遺漏了哪個要件？」 | **固定性**（不易移動其所在）——金世鼎不同意見書 |
| 「演唱會舞台、災後臨時鐵皮屋、貨櫃屋是定著物嗎？」 | **不是**，欠缺**繼續性**（任務完成即拆） |
| 「興建中房屋何時成為定著物？」 | **封頂**、足以遮風避雨時（63 年第 6 次決議後半） |
| 「未封頂房屋之買賣，所有權如何移轉？」 | 是**動產** → **交付**即可（§761）；封頂後 → 須**登記**（§758） |
| 「電線桿是動產或不動產？」 | 早期：動產（可拆移）；**106 台上 1882：不動產**（現代電線桿牽一髮動全身，不易移動） |
| 「承租電線桿之租金請求權時效？」 | 電線桿為不動產 → 非「租賃動產」→ **§126 五年**，不是 §127 ③ 二年 |

## 一、四要件的簡化版

```
① 獨立性（非土地成分）  ← 上一份筆記
② 繼續性（繼續附著）
③ 經濟性（一定經濟目的）
④ 固定性（不易移動）
```

## 二、要件 ②：繼續性——輕便軌道（釋字 93）

- 輕便軌道：阿里山運木材、金瓜石運礦的簡易台車軌道。買賣要不要登記？擔保要設抵押權還是動產質權？→ 取決於動產或不動產。
- **臨時敷設** → 沒有繼續性 → 不是定著物。同理：演唱會舞台、花蓮震災臨時鐵皮屋、貨櫃屋。

### 釋字 93 的問題
```
釋字 93 文字：「除臨時敷設者外」→ 講了繼續性
            「繼續附著於土地而達一定經濟上目的」→ 講了繼續性、經濟性
            固定性？ → 沒講
→ 非臨時的輕便軌道：獨立 ✓、繼續 ✓、經濟 ✓、但「輕便」＝鐵或木頭搭的、隨時可拆 → 不易移動？✗
→ 金世鼎不同意見書：沒有固定性就不該是不動產（遊樂園小火車軌道、雲霄飛車軌道同理）
```
- 選擇題：選釋字 93 的結論。

## 三、要件 ③：經濟性——房屋何時變不動產（63 年第 6 次決議後半）

```
挖地基         → 土地的成分（不獨立）
插幾根鋼筋     → 獨立但無經濟價值 → 頂多是動產
蓋到【封頂】、足以遮風避雨 → 定著物 ＝ 不動產（牆壁、水電、門窗完工與否不問）
```

| 買賣興建中房屋 | 性質 | 所有權移轉方法 |
|------|------|------|
| 未封頂 | 動產 | **交付**（點交）即可 |
| 已封頂 | 不動產 | **移轉登記** |

- 簡陋茅房、簡易養豬養雞棚 → 經濟價值不足 → 個案可能解為動產。
- 南投兩層樓豪華狗舍（有水電、人能住）→ 已非一般狗舍 → 定著物 → 才會有違章建築的問題（動產不會是違建）。→ 個案認定。

## 四、要件 ④：固定性——電線桿（106 台上 1882）

#### 事實
甲向台電承租電線桿（傳輸第四台／手機訊號），租金每年 100 萬。台電作業疏失三年未收款，三年後請求 300 萬。甲主張時效抗辯。

#### 分析
```
爭點：電線桿租金請求權的時效是幾年？
    §126 租金 → 五年 → 三年未逾 → 300 萬全付
    §127 ③ 「以租賃動產為營業者之租價」→ 二年 → 第一年 100 萬罹於時效 → 只付 200 萬
    → 關鍵：電線桿是動產還是不動產？

四要件檢驗：獨立 ✓、繼續 ✓（沒拆就一直在）、經濟 ✓（傳電、傳訊號）、固定性？
    早期實務：否定 → 台電想拆就拆、颱風折斷就換 → 可移動 → 動產 → §127 ③ 二年 → 付 200 萬
    106 台上 1882：肯定 → 現代電線桿要移動須層層評估、牽動區域供電 → 不易移動 → 不動產 → §126 五年 → 付 300 萬
```
- 老師：不是見解歧異，是**時代在變**。金世鼎不同意見書當年就把電線桿當動產的代表例。
