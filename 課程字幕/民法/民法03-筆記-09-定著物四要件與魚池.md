# 民法03 筆記：定著物的四要件與魚池（63 年第 6 次民庭決議）

> 來源：民法03 課程字幕 01:42:35 ~ 01:51:54

## 📖 法條原文速查

> **§66**（不動產）
> I 稱不動產者，謂土地及其**定著物**。
> II 不動產之出產物，尚未分離者，為該不動產之部分。

> **§425-1 I**（土地與房屋異其所有人之推定租賃）
> 土地及其土地上之房屋同屬一人所有，而僅將土地或僅將房屋所有權讓與他人……推定在房屋得使用期限內，有租賃關係。
> → 建議查閱最新六法原文

## 📋 實務見解速查

> **最高法院 63 年度第 6 次民事庭庭推總會決議**（前半段）：§66 I 所謂定著物，係指**非土地之構成部分**，**繼續附著於土地**，而達**一定經濟上目的**，**不易移動其所在**之物而言。
> → 後半段（房屋封頂）見「輕便軌道・封頂・電線桿」筆記；物權法會再看第二遍

> **91 年台上字第 8115 號判決**（講義 85 頁註 102）：有鋼筋混凝土等**獨立結構**之魚池，未與土地結為一體，為獨立之定著物（獨立不動產）。
> → 字號依字幕，建議查閱講義

> **103 年度台上字第 280 號判決**（講義 85 頁註 103）：於土地上**挖洞貼石**而成之魚池，與土地合為一體，屬**土地之成分**，非獨立之不動產。
> → 建議查閱判決原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「定著物之要件？」 | ① 非土地之成分 ② 繼續附著於土地 ③ 一定經濟上目的 ④ 不易移動其所在（63 年第 6 次決議） |
| 「土地上未分離之樹木、地下礦產，法律性質？」 | **土地之成分**（§66 II），不是獨立之物；土地抵押權效力及之 |
| 「柏油路是定著物嗎？」 | **不是**，與土地結為一體 → 土地之成分 |
| 「魚池是不是定著物？」 | **個案判斷**：有獨立結構（鋼筋混凝土魚塭）→ 獨立不動產；挖洞貼石 → 土地成分 |
| 「土地出賣、保留有獨立結構之魚池？」 | 魚池是獨立不動產，比照房屋 → **§425-1 推定租賃** |
| 「土地設定抵押，效力是否及於挖洞貼石的魚池？」 | **及於**，它是土地的一部分 |

## 一、定著物四要件（63 年第 6 次決議）

```
① 非土地之成分   → 獨立性
② 繼續附著於土地 → 繼續性
③ 一定經濟上目的 → 經濟性
④ 不易移動其所在 → 固定性
```
- 本筆記講 ①；②③④ 見下一份筆記。

## 二、要件 ①：非土地之成分（獨立性）

```
土地的範圍不只是 2D 平面
    長出來的（樹木花草）、埋在下面的（礦產）→ 未分離前都是土地的成分（§66 II）
    人造設施與土地結為一體（柏油路）→ 也是土地的成分
→ 土地的成分不是獨立的物 → 不會是定著物，也不會是動產，它就是「土地」
```

### 為什麼要吵這個
- 土地設定抵押給銀行 → 銀行實行抵押權能不能連樹、連礦產一起賣？→ 能，它們是土地的一部分。
- 所以民法直接講清楚：未分離的出產物就是土地的一部分，杜絕糾紛。

## 三、案例：兩種魚池

#### 事實
甲將土地賣給乙（或設定抵押給乙），土地上有魚池。魚池是誰的？抵押權效力及不及於魚池？

#### 分析
| | 魚池 A：鋼筋混凝土魚塭 | 魚池 B：挖洞、周圍貼石頭、灌水 |
|---|---|---|
| 與土地結為一體？ | 否，有獨立結構 | 是 |
| 性質 | **獨立定著物 ＝ 獨立不動產**（91 台上 8115） | **土地之成分**（103 台上 280） |
| 土地賣掉、魚池沒賣 | 土地與魚池異其所有人 → 比照房屋，**§425-1 推定租賃** | 不會發生：魚池隨土地一起移轉 |
| 土地設定抵押 | 效力**不及於**魚池（另一個物） | 效力**及於**魚池 |

- 老師：這兩個判決不是「肯定說／否定說」，是魚池長得不一樣——**個案判斷**，看那個魚池長什麼樣子。

```
要成為定著物的第一關：具有獨立性（不是土地的成分）
    是土地的成分 → 沒有獨立性 → 不是定著物，它就是土地
    有獨立性     → 才有資格進下一關（繼續性、經濟性、固定性）
```
