# 民法27 筆記：先契約義務與締約上過失之「契約未成立時」（§245-1）

## 債編通則的位置：
- §153～§198 債之發生（契約、無因管理、不當得利、侵權行為）
- §199～§218-1 債之標的（種類之債、貨幣之債、選擇之債、利息之債、損害賠償之債）
- §220～§241 債之效力（給付不能、給付遲延、受領遲延、不完全給付、情事變更）
- §242～§245 債之保全（代位、撤銷）
- **契約**一節：§245-1 締約上過失 → §246、§247 自始客觀不能 → §247-1 定型化契約 → §248～§253 定金、違約金 → §254～§262 解除 → §263 終止 → §264～§267 雙務契約 → §268～§270 涉他契約
- 這一節都以契約為前提（所以侵權行為、不當得利不會有違約金）

## 依時間分的契約義務（講義 371 頁）：
- **先契約義務**：訂約前或訂約時 → §245-1
- **契約義務**：主給付、從給付、附隨義務，不履行即債務不履行
- **後契約義務**：契約結束後仍延續，例如律師、醫院的**保密義務**

## 為什麼需要締約上過失：
- 締約階段造成的多半是**純粹經濟損失**，沒有絕對權受侵害 → 侵權行為處理不了
- 還沒締約 → 也不能用契約處理
- 先契約義務（締約上過失）就是填補這段空白；耶林被稱為「法學上的發現」

## §245-1 要件：
1. **契約未成立時**
2. 一方為準備或商議訂約而有第 1～3 款情事
3. 他方**非因過失**而信契約能成立，致受損害
- 效果：損害賠償；時效 **2 年**（§245-1 II）

## 爭點：契約後來成立了，還能用 §245-1 嗎？
- 甲在訂約時就重要事項**惡意隱匿**（第 1 款），乙不知情，仍與甲訂約，契約成立
- **多數說／實務：不行**
  - 「契約未成立時」是**結果**：因這些事由導致契約不成立才賠
  - 契約已成立就進入下一階段，應走**債務不履行**
  - 講義 372 頁註 588：101 年最高法院判決認締約過失責任於契約未成立時始有適用
- **王澤鑑：可以**（少數說）
  - 「契約未成立時」是第 1～3 款行為發生的**時間**，事後契約有無成立在所不問
  - 惡意隱匿、不實說明不會因為契約成立就免責

## 老師提示：
- 學法律就是學解釋：同六個字，解為「結果」或「時間」就是兩說的分界；背兩說不如懂理由

## 時效修法預告：
- 消滅時效可能大修（例如 §197 規定可能刪除、增訂時效停止制度），與民總講義陳聰富文章的立法建議很像
- 老師會請補習班印草案；未來一兩年時效的部分要特別注意

## 📖 法條原文速查

> **§245-1**　I **契約未成立時**，當事人為準備或商議訂立契約而有左列情形之一者，對於**非因過失**而信契約能成立致受損害之他方當事人，負賠償責任：
> 一、就訂約有重要關係之事項，對他方之詢問，**惡意隱匿或為不實之說明**者。
> 二、知悉或持有他方之秘密，經他方明示應予保密，而因**故意或重大過失**洩漏之者。
> 三、其他顯然違反**誠實及信用方法**者。
> II 前項損害賠償請求權，因**二年**間不行使而消滅。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§245-1 損害賠償請求權時效？」 | **2 年** |
| 「契約已成立，可否依 §245-1 請求？」 | 實務、多數說：**不可**，走債務不履行；王澤鑑：可 |
| 「多數說如何解釋『契約未成立時』？」 | **結果**（契約因此不成立） |
| 「王澤鑑如何解釋？」 | 各款行為發生的**時間** |
| 「保密義務在契約終了後仍存在，屬於？」 | **後契約義務** |
| 「締約上過失為何不能靠侵權行為處理？」 | 損害多為**純粹經濟損失**，無絕對權受侵害 |

```
 先契約義務        契約義務          後契約義務
 §245-1           主給付／從給付／   保密義務等
                   附隨義務
```

| | 多數說（實務） | 王澤鑑 |

| 「契約未成立時」 | 結果 | 時間 |
