# 民法債權補充2 筆記：合夥與隱名合夥（§667至§708）

## 合夥的性質
- 甲乙丙訂合夥契約，成立的 A 合夥是**非法人團體**，沒有權利能力
- 合夥財產（出資及其他財產）為**全體合夥人公同共有**（§668），不屬於合夥本身
- **人合性**強：重視合夥人間的信任 → 換人、轉讓股份有特別限制

## 決議與執行
- **決議**（§670）：
  - 原則**全體同意**
  - 合夥契約約定得由全體或一部之過半數決定者，從其約定
  - 但變更**合夥契約或事業種類**，須合夥人全體 **2/3 以上**同意——不能用約定降低
- **表決權**（§673）：不論出資多寡，**推定**每人一表決權（可舉反證）
- **執行**（§671）：原則由合夥人全體執行；契約或決議可由一人或數人執行
- **注意義務**（§672）：與處理自己事務同一之注意；受有報酬者，善良管理人之注意
- **辭任與解任**（§674）：依約定或決議執行事務者，非有正當事由不得辭任；解任須**其他合夥人全體同意**

## 對外責任（§681）
- 合夥財產**不足**清償合夥債務時，各合夥人對不足之額負**連帶**責任（補充性連帶責任）

## 股份轉讓（§683）
- 非經他合夥人**全體同意**，不得將股份轉讓於**第三人**
- 轉讓給**其他合夥人**者不在此限——沒有新人加入，不破壞人合性

## 退夥
- **債權人扣押股份**（§685）：扣押後 **2 個月**內合夥人未清償或提供擔保 → 自扣押時起對該合夥人發生**退夥**效力；債權人改對其結算請求權執行，避免外人加入
- **聲明退夥**（§686）：未定存續期間或以一人終身為期 → 得聲明退夥，應於 **2 個月前**通知，不得於不利合夥事務之時期為之；有非可歸責於自己的重大事由者，縱定有期間亦得退夥
- **法定退夥**（§687）：合夥人**死亡**（契約訂明繼承人得繼承者除外）、受**破產或監護宣告**、經**開除**

## 隱名合夥
- 甲乙丙**出錢不出名**，丁為**出名營業人**（獨資外觀）對外營業
- 定義：一方對他方所經營事業出資，分受營業利益及分擔損失的契約（§700）
- 出資的**財產權移屬出名營業人**（§702）——與一般合夥公同共有不同
- 隱名合夥人僅於**出資限度內**分擔損失（§703）——**有限責任**，不同於 §681 連帶
- 終止事由（§708）注意：
  - **出名營業人**死亡或受監護宣告 → 終止
  - **隱名合夥人**死亡或受監護宣告 → **不**終止（只是出資分紅，由繼承人、法定代理人承受）
  - 出名營業人**或**隱名合夥人受**破產**宣告 → 終止

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 合夥財產歸屬 | 全體合夥人**公同共有** |
| 合夥決議原則 | **全體同意** |
| 變更事業種類 | 全體 **2/3** 以上 |
| 表決權 | **推定**每人一票 |
| 解任執行合夥人 | 其他合夥人**全體同意** |
| 轉讓股份給第三人 | 須全體同意；轉給合夥人不必 |
| 股份被扣押未清償 | **2 個月**後退夥 |
| 隱名合夥出資歸屬 | **出名營業人** |
| 隱名合夥人責任 | 出資限度內 |
| 隱名合夥人死亡 | **不**終止 |

---

## 合夥 vs. 隱名合夥

| 項目 | 合夥 | 隱名合夥 |
|---|---|---|
| 財產 | 公同共有 | 屬出名營業人 |
| 對外 | 合夥人連帶（補充） | 只有出名營業人 |
| 出資人責任 | 不足額連帶 | 出資限度內 |
| 出資人死亡 | 法定退夥 | 不終止 |
