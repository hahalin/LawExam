# 民法10 筆記：§104 代理人之行為能力——限制行為能力人授權他人（§78 無效，不是 §79）；對限制行為能力人授權（授權無因＋無損益中性行為類推 §77 但書 → 有效）；代理行為本身 §104；三階段三法條；受輔助宣告人類推 §15-2 I 但書

> 來源：民法10 課程字幕 00:00:01 ~ 00:14:00

---

## 📖 法條原文速查

> **§104**　代理人所為或所受意思表示之效力，不因其為限制行為能力人而受影響。→ 反面：無行為能力人不得為代理人
> **§77**　限制行為能力人為意思表示及受意思表示，應得法定代理人之允許。但純獲法律上利益，或依其年齡及身份、日常生活所必需者，不在此限。
> **§78**　限制行為能力人未得法定代理人之允許，所為之**單獨行為**，無效。
> **§79**　限制行為能力人未得法定代理人之允許，所訂立之**契約**，須經法定代理人之承認，始生效力。
> **§15-2 I 但書**　受輔助宣告之人……但純獲法律上利益，或依其年齡及身分、日常生活所必需者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「代理之要件？」 | ① 有代理權限（法定／意定）② 以本人名義為意思表示 ③ 代理人**非無行為能力人**（§104 反面）。限制行為能力人、受輔助宣告人皆可為代理人 |
| 「限制行為能力人甲未得法代允許，授與代理權給乙？」 | 授權是**有相對人之單獨行為** → **§78 無效**。很多人選效力未定（§79），是把授權誤當契約。例外：得允許、或 §77 但書、§83 等情形 → 甲自己能做的事就能授權別人做 |
| 「商店老闆甲僱 15 歲乙打工（法代未同意），並授與代理權；乙代理甲賣貨給丙，買賣效力？」 | **有效**。三階段：① 僱傭契約 §79 效力未定 ② 授權不受影響——授權是**無因行為**（不受原因關係影響），且是**無損益中性行為**（類推 §77 但書，不受乙是限制行為能力人影響）→ 有權代理 ③ 乙的代理行為依 **§104** 有效 |
| 「§104 用在哪個階段？」 | 只用在**代理人的意思表示**階段。§104 跟「對限制行為能力人授權有沒有效」一點關係都沒有，寫在授權階段就是法條用錯地方 |
| 「受輔助宣告人得否為代理人？」 | 可以。類推 **§15-2 I 但書**（無損益中性行為）；其代理行為不受輔助宣告影響。受輔助宣告人要授權他人，一樣看他自己能不能做那件事 |

## 一、代理人要不要有行為能力：分三種情況

```
① 限制行為能力人授權他人   → 看「他自己能不能做這件事」→ 不能 → §78 單獨行為無效（非 §79）
② 對限制行為能力人授權     → 無因＋中性 → 有效（類推 §77 但書）
③ 限制行為能力人為代理行為 → §104 有效
無行為能力人：意思表示無效（§75），做不出意思表示 → 不能當代理人
```

## 二、經典案例：15 歲打工仔（國考出現過）

```
甲（店老闆）─僱傭契約（法代未同意）─ 乙（15 歲）
甲 ─授與代理權─ 乙
乙 代理甲 ─買賣─ 丙
問：甲丙買賣契約效力？
```

| 階段 | 問題 | 依據 | 結論 |
|------|------|------|------|
| 1 僱傭契約 | 限制行為能力人未得允許訂契約 | §79（打工非日常生活所必需、非純獲法律上利益） | 效力未定 |
| 2 授權 | (a) 受僱傭契約效力未定影響？ | 通說：授權是**無因行為** | 不受影響 |
| | (b) 受乙是限制行為能力人影響？ | 授權對被授權人只是取得資格、地位，不享權利不負義務（乙幫甲賣車，失去車的是甲、拿到錢的也是甲）→ **無損益中性行為** → 類推 §77 但書 | 不受影響 → **有效授權 → 有權代理** |
| 3 代理行為 | 乙做的意思表示受其行為能力影響？ | **§104** | 有效 |
| 結論 | | | 甲丙買賣契約**有效** |

- 三個階段用三個不同的法條：無因性、類推 §77 但書、§104。老師改集訓班考卷最常見的錯：把 §104 寫到授權階段。
- 「授權無因」：原因關係無效、效力未定、不成立，授權原則上不受影響；原因關係被撤銷的情形有爭議，後面會談。

## 三、限制行為能力人授權他人：§78 而非 §79

```
授權的性質 = 有相對人的單獨行為（民法09 筆記 11）
→ 限制行為能力人未得允許所為單獨行為 → §78 無效
→ 不是效力未定！選擇題陷阱
例外：得法代允許／§77 但書（純獲法律上利益、日常生活所必需）／§83（使用詐術）等
邏輯：他自己能做 → 能授權別人做；他自己不能做 → 不能授權別人做
```

## 四、受輔助宣告人：與限制行為能力人同解

- 要授權別人 → 看是不是 §15-2 I 列舉應經輔助人同意的行為。
- 當代理人 → 類推 §15-2 I 但書（中性行為），可以；代理行為不受輔助宣告影響。

## 關鍵法條速查表

| 法條 | 內容 | 與本主題關聯 |
|------|------|------------|
| **§104** | 代理人為限制行為能力人不影響其意思表示效力 | 只用在代理行為階段 |
| **§78** | 限制行為能力人未得允許之單獨行為無效 | 限制行為能力人授權他人 |
| §79 | 未得允許之契約效力未定 | 僱傭契約；授權**不是**用這條 |
| **§77 但書** | 純獲法律上利益、日常生活所必需 | 對限制行為能力人授權：類推（中性行為） |
| §15-2 I 但書 | 受輔助宣告人之例外 | 受輔助宣告人為代理人：類推 |
