# 民法16 筆記：§186公務員侵權責任

## 考試定位：
- 一般國考可略過；高考二級「民法與民事特別法」會和國賠法合考；選擇題偶爾出現

## 適用範圍：
- 限公務員**違背對第三人應執行之職務**；下班開車撞人是一般侵權行為，與 §186 無關
- 例：違法行政處分致人民受損、過失審查錯誤使人民未領到救助金

## 處理順序：
- 第一步：能否以**法律上救濟方法除去損害**（訴願、行政訴訟撤銷處分）？能除去 → 除去後即無損害
- 能除去而**因故意或過失不為** → §186 II：公務員不負責
- 第二步：無法除去（誤拆房屋）才談賠償
  - 公務員**故意** → 人民可直接告公務員
  - 公務員**過失** → 以「不能依他項方法受賠償」為限 → 先走**國家賠償**，國賠不成才告公務員

## 實務與立法目的：
- 過失直接告公務員的案例實際上沒有，多在行政救濟或國賠就處理掉
- 故意直接告公務員也很少（老師查到約 7、8 件，多是索賄不成而刁難廠商）
- 目的：**鼓勵公務員勇於任事**——出包國家扛，除非故意；與一般侵權保護被害人的方向**相反**
- 國家對公務員有內部求償（字幕作國賠法第 8 條；求償權規定在國賠法 §2 III，請對六法）

## 📖 法條原文速查

> **民法 §186**
> I　公務員因**故意**違背對於第三人應執行之職務，致第三人受損害者，負賠償責任。其因**過失**者，以被害人**不能依他項方法受賠償**時為限，負其責任。
> II　前項情形，如被害人得依法律上之救濟方法，**除去其損害**，而因故意或過失不為之者，公務員不負賠償責任。

> **國家賠償法 §2 II 前段**（要旨）　公務員於執行職務行使公權力時，因故意或過失不法侵害人民自由或權利者，國家應負損害賠償責任。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公務員**過失**違背對第三人之職務致生損害，被害人得否直接向公務員請求？」 | 以**不能依他項方法受賠償**為限（補充性）→ 先請求國賠 |
| 「公務員**故意**違背職務致生損害？」 | 被害人得**直接**向公務員請求 |
| 「被害人得以行政救濟除去損害而因過失未為，得否向公務員請求？」 | **不得**（§186 II） |
| 「公務員下班駕車撞傷路人，適用 §186？」 | **否**，屬一般侵權行為（§184） |
| 「§186 之立法目的？」 | **鼓勵公務員勇於任事**，與一般侵權保護被害人之方向相反 |

## 一、救濟順序圖

```
公務員違背對第三人之職務 → 人民受損
   │
① 能否以法律上救濟方法除去損害？（訴願、行政訴訟）
   ├─ 能 → 請求除去 → 無損害，不談賠償
   │        └─ 能而因故意過失不為 → §186 II 公務員不負責
   └─ 不能（例：房屋已誤拆）
         ↓
② 損害賠償
   ├─ 公務員故意 → 直接告公務員（§186 I 前段）
   └─ 公務員過失 → 先國賠（國賠法 §2、§3）
                     └─ 不能依國賠受償 → 才告公務員（§186 I 後段）
```

## 二、§186 I 與 II 的差別

| | I | II |
|---|---|---|
| 關鍵字 | 「受賠償」 | 「除去損害」 |
| 意思 | 過失時須先找其他賠償管道 | 能除去損害卻不去除，公務員免責 |

## 三、特殊侵權行為之「特殊」

- §185：複數行為人 → 連帶
- **§186：保護公務員**，告訴被害人「能用行政救濟、國賠解決時，不要找公務員」
