# 民法33 筆記：租地建屋之特別規定與地上權登記請求權（§422-1）

## 租地建屋的特別規定一覽：
| 規定 | 內容 |
|---|---|
| §422-1 | 承租人得請求出租人為**地上權登記** |
| §426-1 | 承租人移轉房屋，基地租約對受讓人繼續存在 → 見民法33-筆記-03 |
| §426-2 | 雙向**優先承買權** → 見民法33-筆記-03、04 |
| §440 III | 欠租總額達 **二年租額** 才適用催告終止（一般房屋是二個月） |
| §449 III | 不受 **20 年** 上限 |
| 實務 | 未定期限 → 解為「至房屋不堪使用為止」 |

## 爭點一：地上權登記請求權的時效
- 土地法 §102 要求契約訂立後 **二個月內** 聲請地上權登記
- 若把二個月當時效：太短，房子還沒開始蓋請求權就消滅，§422-1 讓房屋穩定坐落的目的落空
- 通說、實務：二個月是**訓示規定**（提醒要快辦，沒有強制力）
- 請求權時效依 **§125，15 年**（講義註 1108）

## 爭點二：默示更新是否及於地上權
- 例：甲乙租地建屋 50 年，同時登記 50 年地上權；50 年到期，房屋仍在、甲未表示反對
- 租賃權：可依 §451 默示更新，變成不定期限
- 地上權：**不會**默示更新，登記 50 年，期間一到就消滅
  - 理由：物權有絕對效力，須有**公示外觀**；默示更新外界看不見
- 依據：64 年第 5 次民事庭決議、當年物權編修正草案（講義 711 頁，決議字號建議查證）

## 複習：未定期限與改建（見民法32-筆記-12）
- 30 年渝上字 311 號（講義註 1084，字幕「30年於上智的」，字號建議查證）：租地自建房屋，非有相當期限不能達目的，依契約目的探求真意，解為定有**至房屋不堪使用時為止**之期限
- 一直改建房屋就一直堪用 → 要看改建**是否經出租人同意**：
  - 同意 → 以改建後房屋判斷
  - 未同意 → 以**原房屋**判斷
- 本講版本（108 年左右書記官考題，建議查證）：民國 50 年訂約、木造；98 年繼承人未經同意改磚造；108 年請求拆屋還地 → 以木造判斷，約民國 100 年前後已不堪使用 → 甲請求有理由

## 📖 法條原文速查

> **§422-1**　租用基地建築房屋者，承租人於契約成立後，得請求出租人為**地上權之登記**。

> **土地法 §102**（要旨）　租用基地建築房屋，應由出租人與承租人於契約訂立後**二個月內**，聲請該管地政機關為地上權之登記。→ 建議查閱最新六法原文

> **§440 III**　租用建築房屋之基地，遲付租金之總額，達**二年**之租額時，適用前項之規定。

> **§449 III**　租用基地建築房屋者，不適用第一項之規定。

> **§125**　請求權，因十五年間不行使而消滅。但法律所定期間較短者，依其規定。

## 📋 實務見解速查

> **64 年第 5 次民事庭決議**（要旨，依課堂講述）：租地建屋併為地上權登記者，租約可默示更新，地上權不隨同默示更新。→ 建議查證決議原文

> **30 年渝上 311**（要旨）：以承租人自行建築房屋而使用為目的之土地租賃，雖未明定期限，應解為定有租至房屋不堪使用時為止之期限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「租地建屋地上權登記請求權，二個月不行使而消滅？」 | **錯**，二個月是訓示規定，時效 **15 年** |
| 「租約默示更新，地上權也隨同更新？」 | **否**，物權須公示外觀 |
| 「租用基地建屋，欠租多少才可催告終止？」 | 達 **二年**租額 |
| 「租地建屋約定 60 年有效？」 | **有效**（§449 III） |
| 「未經同意改建，期限以何屋判斷？」 | **原房屋** |
