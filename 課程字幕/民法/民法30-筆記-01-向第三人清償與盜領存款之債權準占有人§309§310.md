# 民法30 筆記：向第三人清償與盜領存款之債權準占有人（§309、§310）

## 清償的體系：
- 債之消滅五種原因（清償、提存、抵銷、免除、混同），提存、免除、混同已講過（見民法29-筆記-12），本講講**清償**與**抵銷**
- 清償（§309）：債務人**依債務本旨**提出給付，向債權人或其他有受領權人為之，經其**受領**，債之關係消滅（字幕「債之本質」應為「債之本旨」）
- 條文分布：
  - 債務人**向第三人**清償 → §310
  - **由第三人**清償 → §311～§313
  - 債之本旨（清償地、清償期、費用、方法）→ §314 以下

## 向第三人清償（§310）：
- 原則：不生清償效力（清償須向債權人或有受領權人為之）
- 例外三款：
  1. 經債權人**承認**，或受領人事後**取得債權**
  2. 受領人是**債權之準占有人**，且債務人**不知其非債權人**（善意）→ 考試考這款
  3. 其他情形，於債權人**因而受利益之限度內**有效（例：甲把欠乙的錢交給乙的哥哥丙，丙因此免除乙欠他的債務）
- 準占有人（§966）：財產權不因物之占有而成立者，**行使其財產權之人**
  - 實務限縮：須具備**行使權利的外觀要件**，提款至少要有**真正的存摺＋真正的印章**

## 盜領存款案：
- 前提：存款是**消費寄託**（§602、§603 金錢推定為消費寄託），錢的所有權已移轉給銀行，存戶甲只有返還請求權（債權）
- 情形一：乙撿到甲的存摺，偽刻印章（肉眼無法辨識）去提領 100 萬元
  - 乙持偽刻印章，**不是準占有人** → 不符 §310②，銀行清償無效
  - 甲的債權不受影響 → 受損害的是**銀行**，由銀行對乙主張 §179
- 情形二：乙同時撿到存摺與**真正印章**
  - 乙是準占有人；銀行行員只核對印鑑，原則上**善意** → 依 §310② 清償有效
  - 甲的存款債權消滅 → 受損害的是**甲**，由甲對乙主張 §179
- 銀行對印章真偽負辨識義務，肉眼無法辨識仍由銀行承擔損失
- 結論（詹老師文章，建議查證作者）：**存摺與印章分開放**
- 同樣的考點：**真正的提款卡＋真正的密碼**被盜領，受影響的是存戶

## 📖 法條原文速查

> **§309 I**　依債務本旨，向債權人或其他有受領權人為清償，經其**受領**者，債之關係消滅。

> **§310**　向第三人為清償，經其受領者，其效力依左列各款之規定：
> 一、經債權人**承認**或受領人於受領後**取得其債權**者，有清償之效力。
> 二、受領人係**債權之準占有人**者，以債務人**不知其非債權人**者為限，有清償之效力。
> 三、除前二款情形外，於債權人**因而受利益之限度內**，有清償之效力。

> **§966 I**　財產權，不因物之占有而成立者，**行使其財產權之人**，為準占有人。

> **§602 I**　寄託物為代替物時，如約定寄託物之**所有權移轉於受寄人**，並由受寄人以種類、品質、數量相同之物返還者，為消費寄託。（後段準用消費借貸 → 建議查閱最新六法原文）

> **§603**　寄託物為金錢時，推定其為消費寄託。

## 📋 實務見解速查

> **68 年第 6 次民事庭決議**：§310② 之適用，須受領人為債權之準占有人，並以債務人不知其非債權人為要件。持真正存摺，但取款條印文與存留印鑑不符（肉眼無法辨識），依判例**不能認為是準占有人**，銀行之給付不生清償效力。（字幕提到所引為「57 年判例」，字號建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人向第三人清償，效力？」 | 原則**不生效力**；例外 §310 三款 |
| 「持真正存摺＋偽刻印章盜領，誰受損害？」 | 非準占有人，清償無效 → **銀行**受損害，銀行對盜領人主張 §179 |
| 「持真正存摺＋真正印章盜領？」 | 準占有人＋銀行善意 → 清償有效 → **存戶**受損害 |
| 「偽刻印章肉眼無法辨識，銀行可免責？」 | **不可以**，銀行負辨識義務（68 年第 6 次民庭決議） |
| 「存款的所有權人？」 | **銀行**（消費寄託，§602、§603） |
| 「§310③ 的清償效力範圍？」 | 以債權人**因而受利益之限度**內為限 |

## 盜領存款判斷圖

```
乙持存摺去提款，銀行付款
├── 印章偽刻 → 非準占有人 → §310② 不符 → 清償無效
│        └── 甲債權仍在 → 銀行受損 → 銀行對乙 §179
└── 印章真正 → 準占有人 ＋ 銀行善意 → §310② 清償有效
         └── 甲債權消滅 → 甲受損 → 甲對乙 §179
```
