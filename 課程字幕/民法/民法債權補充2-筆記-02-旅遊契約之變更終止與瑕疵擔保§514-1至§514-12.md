# 民法債權補充2 筆記：旅遊契約之變更、終止與瑕疵擔保（§514-1至§514-12）

## 定義與書面（§514-1、§514-2）
- 旅遊營業人：以提供旅客旅遊服務為營業而收取旅遊費用之人；旅遊服務指安排旅程及提供交通、膳宿、導遊等（§514-1）
- 旅遊營業人因**旅客請求**，應以書面記載法定事項交付旅客（§514-2）→ 非要式契約

## 旅客的協力義務（§514-3）
- 旅遊需旅客行為始能完成（例：辦護照），旅客不為 → 營業人得定期催告
- 期限內不為 → 營業人得**終止**契約並請求**損害賠償**
- 旅遊**開始後**終止：旅客得請求營業人**墊付**費用送回原出發地，到達後由旅客**附加利息償還**

## 旅客變更參加人（§514-4）
- 旅遊開始**前**，旅客得變更由第三人參加；營業人非有正當理由不得拒絕
- 費用：增加者營業人得請求給付；減少者旅客**不得**請求退還 → **多要補、少不退**

## 營業人變更旅遊內容（§514-5）
- 非有**不得已**事由，不得變更；任意變更 → 債務不履行
- 有不得已事由變更：
  - 費用：減少者應退還，增加者不得收取 → **少要退、多不補**（與 §514-4 相反）
  - 旅客不同意 → 旅客得**終止**；得請求營業人墊付送回，到達後**附加利息償還**

## 瑕疵擔保（§514-6、§514-7）
- 旅遊服務應具備通常之價值及約定之品質（§514-6）
- 不具備時（§514-7）：
  1. 先請求**改善**
  2. 不為或不能改善 → 請求**減少費用**；難達預期目的 → **終止**契約
  3. **可歸責**於營業人 → 另得請求**損害賠償**
  4. 依本條終止 → 營業人應送回原出發地，費用由**營業人負擔**

## 時間浪費（§514-8）
- 因可歸責於營業人的事由，旅遊未依約定旅程進行 → 旅客就**時間浪費**得**按日**請求賠償相當金額
- 法律把時間浪費**擬制為損害**；每日上限＝旅遊費用總額的每日平均數
- 例：30 天團費 18 萬 → 每日上限 6,000 元

## 旅客任意終止（§514-9）
- 旅遊未完成前，旅客得**隨時終止**；應賠償營業人因終止所生損害
- 準用 §514-5 IV：可請求墊付送回，旅客仍須償還

## 其他
- 旅客身體財產發生事故，營業人應為必要協助；非可歸責於營業人者，費用由旅客負擔（§514-10）
- 營業人**安排**旅客在特定場所購物，物品有瑕疵 → 旅客得於受領後 **1 個月**內請求營業人協助處理（§514-11）
- 本節增減退費、損害賠償、墊付費用償還請求權：自旅遊終了或應終了時起 **1 年**（§514-12）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 旅客變更參加人之費用 | 多要補、**少不退** |
| 營業人不得已變更之費用 | **少要退**、多不補 |
| 四種終止，誰負擔送回費用 | 只有 §514-7（瑕疵）由**營業人**負擔；其餘旅客償還 |
| 時間浪費之賠償 | 按日、上限為每日平均旅費 |
| 旅客可否隨時終止 | **可**，須賠償 |
| 安排購物瑕疵協助期間 | **1 個月** |
| 旅遊契約請求權時效 | **1 年** |

## 四種終止比較

| 條文 | 誰終止 | 原因 | 送回費用 |
|---|---|---|---|
| §514-3 | 營業人 | 旅客不協力 | 旅客償還 |
| §514-5 | 旅客 | 不同意不得已變更 | 旅客償還 |
| §514-7 | 旅客 | 瑕疵、目的難達 | **營業人負擔** |
| §514-9 | 旅客 | 任意終止 | 旅客償還 |
