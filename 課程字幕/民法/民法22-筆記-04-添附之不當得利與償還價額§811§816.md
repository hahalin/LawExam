# 民法22 筆記：添附之不當得利與償還價額（§811、§816）

## 案例：
- 甲的房屋圍牆被震垮，重砌到一半磚頭不夠，搬走鄰居乙門口的 B 磚頭砌進自己的牆
- 乙能要回磚頭嗎？

## §767 不行：
- 動產與不動產附合，成為不動產重要成分 → 不動產所有人取得動產所有權（§811）
- 磚頭已是甲房屋的一部分，乙不能請求拆下返還

## §179 可以：添附不是法律上原因
- 甲受有利益：依 §811 取得磚頭所有權
- 法規目的說：§811 的目的是**維護物的經濟價值**（物盡其用，拆下來磚頭就碎了），不是保護甲
- 不保護甲 → 不讓甲終局保有 → 添附不能作為法律上原因 → 成立不當得利
- 對照：時效、善意取得可以作為法律上原因（見民法22-筆記-03）

## 返還什麼：只能償還價額
- 若適用 §181 本文返還原形，等於又要拆磚頭，添附制度被架空
- §816：因添附受損害者，得依關於不當得利之規定，請求**償還價額**
- §816 不是 §179 的特別規定，而是 **§181 的特別規定**：排除返還原形，只能適用 §181 但書

## 「依關於不當得利之規定」：構成要件準用
- 修正理由：①宣示財產損益依法變動，仍可能無法律上原因；②本質上是不當得利，§179～§183 均在準用之列，只排除 §181 本文
- **通說（修正理由）：構成要件準用** → 仍須具備不當得利的要件
- 林誠二：法律效果準用說
- 講義 321 頁修正理由那段的「構成要件準用／法律效果準用」寫反了，老師要求手動對調

## 📖 法條原文速查

> **§811**　動產因附合而為不動產之**重要成分**者，不動產所有人，取得動產所有權。

> **§816**　因前五條之規定而受損害者，得依**關於不當得利之規定**，請求**償還價額**。

> **§181**　不當得利之受領人，除返還其所受之利益外，如本於該利益更有所取得者，並應返還。但依其利益之性質或其他情形不能返還者，應償還其價額。

---

## 📋 實務見解速查

> **§816 修正理由**（講義 321 頁，要旨）：本條規範意義有二：一為宣示不當得利請求權，縱使財產損益變動係依法發生，仍可能構成無法律上原因；二為指明本質上係不當得利，故 §179～§183 均在準用之列，僅特別排除 §181 關於原物返還之適用。因添附受損害者，僅得適用 §181 但書請求償還價額，不能適用同條本文請求返還原物，以貫徹添附制度重新分配添附物所有權歸屬之立法目的。所稱「關於不當得利之規定」，係**構成要件準用**。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產附合於不動產，原動產所有人得依 §767 請求返還？」 | **否**，§811 所有權歸不動產所有人 |
| 「添附得否作為法律上原因？」 | **否**，§811 目的在維護物的經濟價值 |
| 「依 §816 得請求返還原物？」 | **否**，只能**償還價額** |
| 「§816 是何條之特別規定？」 | **§181**（排除返還原形） |
| 「§816『依關於不當得利之規定』，通說為何？」 | **構成要件準用** |

## 一、四種添附

```
添附（§811～§815）
├─ 動產與不動產附合（§811）← 本例：磚頭砌牆
├─ 動產與動產附合（§812）
├─ 混合（§813）
└─ 加工（§814）
        ↓
受損害者 → §816 依不當得利規定請求償還價額
```

## 二、法律上原因對照

| 法律規定 | 制度目的 | 可為法律上原因？ |
|---|---|---|
| 消滅時效 | 法安定性 | 可 |
| 善意取得 | 交易安全 | 可 |
| 添附 | 物的經濟價值 | **不可** |

## 三、解題順序

1. §767：所有權已依 §811 移轉 → 不成立
2. §179：甲受利益；§811 不是法律上原因 → 成立
3. §181＋§816：不能返還磚頭，只能償還價額
