# 民法15 筆記：死者人格權遺族追思與肖像繼承

## 出發點：
- 權利能力**終於死亡**（§6）→ 死者不再有人格權；分「名譽」與「肖像」兩種情況討論，皆有實務判決

## 死者名譽：
- 死者無名譽權；辱罵死者侵害的是**遺族追思權**（慎終追遠之情感）
- 遺族追思權屬 §195 I 之**其他人格法益**，情節重大得請求慰撫金
- 例：陳水扁於 228 晚會稱蔣中正為殺人魔，蔣家子孫請求一元象徵性賠償（臺北地院判決，講義 80～87 頁）
- 地院將追思權當作**權利**，涵攝 §184 I **前段**；但以**不法性與過失**否定責任

## 地院打掉不法與過失的理由：
- 屬**事實陳述** → 看能否證明為真、對事不對人（無真實惡意）、有無盡**查證義務**
- 陳水扁提出英國、日本、臺灣本土研究與歷史文件 → 有追思權侵害，但無過失、無不法 → 不負責

## 死者肖像：
- 死者亦無肖像權；但肖像權具**經濟價值**（可授權代言獲利）→ 例外得為**繼承標的**
- §1148 I 限於「財產上」權利義務、專屬權不繼承 → 一般人格權不繼承；肖像權因兼具財產性質而可繼承
- **白花油案**（字幕作「核心白花油」）：商標使用老太太肖像，老太太死後公司續用，繼承人不滿；最高法院採**可繼承說** → 未經繼承人同意使用構成侵害

## 📖 法條原文速查

> **民法 §6**　人之權利能力，始於出生，終於死亡。

> **民法 §1148 I**　繼承人自繼承開始時，除本法另有規定外，承受被繼承人**財產上**之一切權利、義務。但權利、義務**專屬於被繼承人本身者，不在此限**。

> **民法 §195 I**　……或不法侵害其他人格法益而情節重大者，被害人雖非財產上之損害，亦得請求賠償相當之金額。……

---

## 📋 實務見解速查

> **最高法院 104 年度台上字第 1407 號判決**（字幕作「104 的 1407 號」，講義 79 頁；字號請對講義）：白花油案。老師整理之要旨：肖像權具經濟價值，得為繼承標的；未得繼承人同意擅自使用死者肖像，構成侵害，由繼承人請求。（判決原文請對講義）

> **臺灣臺北地方法院判決**（講義 80～87 頁節錄，字號字幕未唸，請對講義）：蔣家遺族告陳水扁案。侵害遺族追思權（其他人格法益），涵攝 §184 I 前段；因已盡查證義務、對事不對人，**無過失、無不法** → 不負侵權責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「死者之名譽被毀損，死者有無名譽權受侵害？」 | **無**。權利能力終於死亡（§6）；受侵害者為**遺族追思權**（其他人格法益），情節重大得請求慰撫金 |
| 「遺族追思權之性質？」 | §195 I **其他人格法益**；地院判決將其視為權利，走 §184 I 前段 |
| 「蔣家告陳水扁案，法院以何要件否定責任？」 | 追思權有受侵害，但事實陳述已盡**查證義務**、對事不對人 → **無過失、無不法** |
| 「肖像權得否繼承？」 | 人格權原則一身專屬、不得繼承（§1148 I 但書）；**肖像權具經濟價值** → 最高法院肯定**得繼承**（白花油案） |
| 「公司於肖像人死後續用其肖像，誰得請求？」 | 依可繼承說，未得**繼承人**同意即構成侵害，由繼承人請求賠償 |

## 一、體系圖

```
死者人格權？→ 權利能力終於死亡（§6），死者本身皆無
│
├── 名譽：轉換為「遺族追思權」
│     §195 I 其他人格法益（情節重大）
│     → 再檢驗不法性（真實性、真實惡意、查證義務）與過失
│
└── 肖像：肖像權具經濟價值 → 得繼承（§1148 I 限縮理解）
      → 繼承人對擅用者請求
```

## 二、比較表

| | 死者名譽 | 死者肖像 |
|---|---|---|
| 死者本身有無權利 | 無 | 無 |
| 受保護者 | 遺族之追思權（自身人格法益） | 繼承人繼承之肖像權 |
| 根據 | §195 I 其他人格法益 | 肖像權之財產性質，§1148 I |
| 代表案件 | 蔣家告陳水扁（臺北地院） | 白花油案（104 台上 1407，請對講義） |
| 結果 | 有侵害但無過失無不法 → 不賠 | 可繼承 → 擅用構成侵害 |

## 三、案例分析的兩個層次（蔣家案）

1. **侵害什麼**：不是死者名譽權，是遺族追思權。
2. **過失與不法如何認定**：名譽事件的常見重心——事實陳述能否證明為真、對事或對人、有無盡查證義務（呼應民法14 名譽權之判斷）。
