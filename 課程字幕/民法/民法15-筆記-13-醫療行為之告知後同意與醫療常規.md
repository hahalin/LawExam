# 民法15 筆記：醫療行為之告知後同意與醫療常規

## 醫療行為放在哪一層討論：
- **多數說**：手術劃開身體＝侵害行為，要件層具備；是否負責放在**不法性**（被害人承諾）與**過失**判斷
- 游進發（字幕作「遊進發」「由老師」，請對講義）臉書見解：醫療目的是治療而非侵害，正常的醫療行為（含侵入式治療）連**侵害行為**要件都不成立，根本不用談不法與過失
- 老師：思考層次完全不同，作為補充；考試仍以多數說為準

## 告知後同意：
- 病人無法知道手術所有風險 → 醫師須**告知**風險後取得同意，才是**有效同意**而阻卻不法
- 簽了手術同意書不等於同意；未盡告知義務所取得之同意是**無效**同意
- 告知義務的前提：**有選擇餘地**。只有一種方式（不做就等死）時不必詳細說明；有兩種以上手術方式，須具體告知各自優劣

## 假設性病人同意：
- 例：全身麻醉做大腸鏡，看到疑似異常增生組織，不可能叫醒病人告知再取得同意
- 客觀上可假設病人通常會同意（正常人都會說好）→ 未告知也視為取得承諾

## 醫療常規：
- 符合醫療常規一般也可作為阻卻違法之事由
- 醫療行為的考題在二試常與**民事訴訟法舉證責任**合考

## 104 年判決（講義 125 頁、註 193）：
- 醫療行為是**可容許的危險行為**；積極侵入性治療必伴隨潛在風險（消極醫療如安寧照護則風險低、對治療幫助也小）
- 醫療過失判斷重在**過程而非結果**：醫師須恪遵醫療常規且善盡注意義務；符合常規且被害人無法證明醫師有疏失者，難認有不法侵權行為
- 老師：細讀會困惑——醫療常規到底是**不法**還是**過失**的問題

## 陳忠五見解（字幕作陳中吳／陳中五，請對講義）：
- 醫療常規是**客觀**標準，應只放在**不法性**層次
- 符合常規 → 不具不法性 → 侵權不成立，**不必再談過失**
- 不符常規 → 只是具備不法性，**仍要檢驗過失**；無過失仍不用負責
- 批評實務：符合常規還要證明無過失才免責；不符常規則等於不法且有過失 → 常規同時被當成不法與過失標準，混淆兩者

## 📖 法條原文速查

> **民法 §184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。→ 故意過失（主觀）與不法（客觀）分列

## 📋 實務見解速查

> **最高法院 104 年判決**（字幕作「104 年的 700 號」，講義註 193；字號請對講義）要旨（依老師唸讀整理）：醫療行為屬可容許之危險行為，受限於醫療之有限性、疾病多樣性與人體變化，積極侵入性醫療常伴隨潛在風險；醫療過失之判斷重在醫療過程而非結果，著眼於醫師是否恪遵醫療規則並善盡注意義務；醫師實施醫療行為如符合醫療常規，而被害人未能證明其有何疏失，難認有不法侵權行為。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「病人簽署手術同意書，即可阻卻違法？」 | **不一定**。醫師須盡**告知義務**，所得同意始為有效同意 |
| 「醫師告知義務之前提？」 | 病人**有選擇餘地**（有兩種以上方式時須具體告知優劣） |
| 「麻醉中發現異常組織即行切除，未取得同意？」 | **假設性病人同意**：客觀上病人通常會同意 → 視為取得承諾 |
| 「醫療過失之判斷重在結果？」 | **否**。重在醫療**過程**（是否恪遵醫療常規、善盡注意義務）（104 年判決） |
| 「依陳忠五，符合醫療常規之效果？」 | **不具不法性** → 侵權不成立，不必再論過失 |
| 「依陳忠五，違反醫療常規之效果？」 | 只具備不法性，**仍須有過失**才負責 |
| 「實務對醫療常規之定位，學者如何批評？」 | 實務將常規同時作為不法與過失標準，符合常規仍須證明無過失 → 混淆不法（客觀）與過失（主觀） |

## 一、醫療行為的三種定位

```
醫師手術致病人不良結果
│
├── 游進發：正常醫療≠侵害行為 → 要件層即不成立
│
└── 多數說：要件層具備 → 檢驗不法與過失
      ├── 不法：被害人承諾（告知後同意／假設性同意）、醫療常規
      └── 過失：注意義務之違反
```

## 二、醫療常規：實務 vs 陳忠五

| 情形 | 實務（104 年判決） | 陳忠五 |
|---|---|---|
| 符合常規 | 尚須被害人無法證明疏失（實質上要無過失）才不負責 | **無不法** → 不成立，不談過失 |
| 違反常規 | 傾向認定不法且有過失 → 負責 | 有不法，**另檢驗過失** |
| 常規的位置 | 混入不法與過失 | 只在**不法性** |

## 三、承諾有效性的檢查順序

1. 有無同意（同意書）
2. 有無盡告知義務（前提：有選擇餘地）
3. 無法告知時，可否假設病人同意
4. 是否符合醫療常規
