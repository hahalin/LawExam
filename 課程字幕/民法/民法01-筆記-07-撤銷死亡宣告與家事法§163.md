# 民法01 筆記：撤銷死亡宣告後的法律關係（家事事件法 §163）

> 來源：民法01 課程字幕 01:33:50 ~ 02:02:00

---

## 📖 法條原文速查

> **家事事件法 §163**（撤銷死亡宣告之效力）
> I 撤銷或變更宣告死亡裁定之裁定，**不問對於何人均有效力**。但裁定確定前之**善意行為**，不受影響。
> II 因宣告死亡取得財產者，如因前項裁定失其權利，僅於**現受利益之限度**內，負歸還財產之責。

> **家事事件法 §155**（聲請人）
> 宣告死亡、撤銷或變更宣告死亡之裁定，利害關係人或檢察官得聲請之。→ 建議查閱條文確認條號

> **§767 I 中段**（妨害除去請求權）
> 對於妨害其所有權者，得請求除去之。→ 請求塗銷登記的依據

> **§118 I**（無權處分）
> 無權利人就權利標的物所為之處分，經有權利人之承認始生效力。

> **§759-1 II**（不動產登記之公信力／善意取得）
> 因信賴不動產登記之善意第三人，已依法律行為為物權變動之登記者，其變動之效力，不因原登記物權之不實而受影響。

> **§179**（不當得利）
> 無法律上之原因而受利益，致他人受損害者，應返還其利益。雖有法律上之原因，而其後已不存在者，亦同。

> **§988 第 3 款**（結婚無效：重婚）
> 違反第 985 條規定。但重婚之雙方當事人因**善意且無過失**信賴一方前婚姻消滅之**兩願離婚登記或離婚確定判決**而結婚者，不在此限。

> **§988-1 I**
> 前條第三款但書之情形，**前婚姻自後婚姻成立之日起視為消滅**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「受死亡宣告者返家，法律關係是否自動回復？」 | **否**。須聲請**撤銷**死亡宣告裁定，撤銷後才回復 |
| 「§163 I 但書『善意行為』的意義？」 | **雙方善意**（不知其仍生存）之**法律行為** |
| 「甲受宣告→乙繼承 A 地→乙賣給丙並登記，乙丙均善意，甲撤銷後可否請求丙塗銷？」 | **不可**。善意法律行為不受影響，丙仍為所有人 |
| 「同上，乙丙均惡意？」 | **可**。甲回復所有人地位 → 乙為無權處分 → 丙惡意無善意取得 → §767 請求塗銷 |
| 「同上，乙惡意、丙善意？」 | **不可**，但理由不同：乙無 §163 但書 → 無權處分 → 丙依 **§759-1 II 善意取得** |
| 「乙丙均善意，甲可否向乙請求返還賣得之 600 萬？」 | **可**，但以**現存利益**為限（§163 II）。理由：**繼承不是法律行為** → 乙無 §163 I 但書保護 |
| 「甲受宣告後，配偶乙與丙再婚（均善意），甲撤銷後乙丙婚姻？」 | **有效**，不受影響（§163 I 但書）。注意**不是** §988 第 3 款但書（那是信賴離婚登記／判決） |
| 「同上，甲乙前婚？」 | 有爭議：類推 §988-1 I 前婚例外不回復（老師）vs 回復並存、依 §1052 訴請離婚（楊、釋 552） |

## 一、回來第一步：撤銷死亡宣告

```
甲活著回來
    ↓ 死亡宣告效力仍存在（不會因人回來自動消滅）
    ↓
依家事事件法聲請撤銷死亡宣告裁定
    ↓
§163 I 本文：不問對於何人均有效力 → 原則：法律關係回復到宣告前
§163 I 但書：裁定確定前之善意行為不受影響 → 例外：不回復
```

### 但書「善意行為」怎麼解釋

| 要素 | 解釋 |
|------|------|
| 善意 | 不知甲仍生存；通說須**雙方**善意 |
| 行為 | 須為**法律行為**（含身分行為），因為只有法律行為才有交易安全要保護 |

→ **繼承不是法律行為，甚至不是行為**（人死就自然發生的狀態）→ 繼承人不受但書保護。

## 二、案例一：A 地被繼承後賣掉

### 事實
1. 甲受死亡宣告，A 地由乙繼承。
2. 乙將 A 地以 600 萬賣給丙，並移轉登記。
3. 乙已花掉 400 萬，剩 200 萬。
4. 甲回來，撤銷死亡宣告。問法律關係。

### 甲 → 丙：依 §767 I 中段請求塗銷登記？

要件：甲仍為 A 地所有人。→ 看物權變動軌跡 + 乙丙善惡意。

```
t1  甲是 A 地所有人
t2  甲受死亡宣告 → 乙繼承取得 A 地所有權
t3  乙丙買賣 + 移轉登記 → 丙取得所有權（當時乙有權處分，有效）
t4  甲撤銷死亡宣告 → §163 I：原則回復，但善意法律行為不受影響
```

| 乙 | 丙 | 丙是否保有所有權 | 理由 | 甲可否 §767 塗銷 |
|----|----|------|------|------|
| 善 | 善 | ✓ | §163 I 但書，乙丙買賣與物權行為不受影響 | ✗ |
| 惡 | 惡 | ✗ | 無但書保護 → 甲回復所有人 → 乙成無權處分（§118 效力未定）→ 丙惡意不能善意取得 | **✓** |
| 善 | 惡 | ✗ | 須雙方善意；丙惡意 → 同上 | **✓** |
| 惡 | 善 | ✓ | 無但書保護 → 甲回復所有人 → 乙無權處分 → 但丙善意，依 **§759-1 II 善意取得** | ✗（理由是善意取得，不是 §163） |

> 考試通常設定乙丙均善意，往下接不當得利。

### 甲 → 乙：依 §179 請求返還 600 萬？（乙丙均善意）

| 要件 | 涵攝 |
|------|------|
| 乙受有利益 | 收到 600 萬 ✓ |
| 無法律上原因 | 非給付型不當得利 → **權益歸屬說**：這 600 萬是 A 地的**代替利益**，A 地的利益該歸誰？ |
| 致甲受損害 | 甲失去 A 地及其代替利益 ✓ |

**爭點：乙能否主張 §163 I 但書「我是善意繼承人」？**
```
乙取得 A 地的原因 = 繼承
繼承 ≠ 法律行為（連行為都不是，是人死後自然發生的狀態）
    → 不是「善意行為」→ 無但書保護 → 回到本文：回復
    → A 地的利益歸甲 → 乙保有 600 萬為無法律上原因
```
→ 甲得依 §179 請求。

**返還範圍：§163 II 現存利益**
- 600 萬只剩 200 萬 → 乙只須返還 **200 萬**。

### 乙 vs 丙 為何不同

| | 丙 | 乙 |
|---|---|---|
| 取得 A 地的方式 | **法律行為**（買賣 + 移轉登記） | **繼承**（非法律行為） |
| §163 I 但書 | 適用（善意時） | 不適用 |
| 結果 | 保有所有權 | 須返還現存利益 |

## 三、案例二：配偶再婚

### 事實
甲受死亡宣告，配偶乙與丙再婚，甲乙丙均善意。甲撤銷死亡宣告。問婚姻關係。

### 乙丙後婚
- 結婚是法律行為（身分行為），雙方善意 → **§163 I 但書，不受影響，有效**。
- ⚠️ 不要用 §988 第 3 款但書：那條保護的是信賴**離婚登記／離婚判決**的重婚，本件信賴的是**死亡宣告裁定**，法條對不上。

### 甲乙前婚要不要回復？

| 見解 | 內容 | 依據 |
|------|------|------|
| 前婚例外不回復（老師建議） | 避免重婚、維護一夫一妻 | **類推 §988-1 I**（前婚自後婚成立之日起視為消滅） |
| 前婚回復、前後婚並存（字幕音譯「楊成和」老師之書，待確認） | §163 I 本文「不問對於何人均有效力」→ 撤銷即回復 | 釋字 552：後婚雙方善意則不受影響，前後婚並存時當事人得依 **§1052** 訴請離婚 |

> 一試大多只考**乙丙後婚效力**（有效）。前婚爭議知道兩說即可。

## 四、總整理

```
撤銷死亡宣告後
├── 財產
│   ├── 善意法律行為取得 → 不用還（丙）
│   └── 繼承取得 → 要還，但只還現存利益（乙，§163 II）
└── 身分
    ├── 原則回復
    └── 雙方善意之再婚 → 有效
        └── 前婚：類推 §988-1 不回復 vs 回復並存＋§1052 離婚
```

## 關鍵法條速查表

| 法條 | 內容 | 與本主題關聯 |
|------|------|------------|
| **家事 §163 I** | 撤銷對任何人有效；善意行為不受影響 | 本筆記核心 |
| **家事 §163 II** | 因宣告取得財產者返還現存利益 | 乙還 200 萬 |
| §767 I 中段 | 妨害除去請求權 | 請求塗銷登記 |
| §118 | 無權處分效力未定 | 甲回復所有人後乙的處分 |
| §759-1 II | 不動產善意取得 | 乙惡丙善 |
| §179 | 不當得利（權益歸屬說） | 600 萬的歸屬 |
| §988 ③ 但書 | 信賴離婚登記／判決之重婚 | **本件不適用**，常見陷阱 |
| §988-1 I | 前婚視為消滅 | 類推的依據 |
| §1052 | 裁判離婚 | 前後婚並存時的出口 |

## 關鍵實務見解速查表

| 實務見解 | 要旨 |
|---------|------|
| **釋字 552** | 重婚之後婚雙方善意且無過失者，後婚不受影響；前後婚並存時得依 §1052 訴請離婚（§988-1 即順此解釋新增） |
| 釋字 362 | 重婚相關前解釋，552 補充之 |
