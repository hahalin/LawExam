# 民法14 筆記：商品自傷（字幕作「商品智財」，應為**商品自傷**：瑕疵商品因自身瑕疵毀損）——A 車商過失未排除煞車瑕疵，車賣給甲、甲轉賣乙，乙駕駛中因無法煞車致**車損**，乙得否直接對 A 車商依侵權行為請求？**肯定說**（少數說：陳忠五；部分實務）：重點在**車損**＝車輛所有權（絕對權）受侵害 → §184 I 前段 ✓；**否定說**（多數說：王澤鑑、陳聰富）：重點在**車有瑕疵**＝出賣人瑕疵擔保（§354）問題、乙的**債權未獲滿足**，債權非絕對權 → 純粹經濟損失 → 不得依 §184 I 前段；A 僅過失，後段、II 亦不該當 → 乙對 A 無侵權請求權，應依 §359 向甲（出賣人）主張瑕疵擔保，維護契約與侵權之分際；實務約五五開，有從寬認定所有權侵害者（讓乙直接找有資力的車商，避免一件訴訟變兩件）；本題目前**無定論**

## 📖 法條原文速查

> **民法 §354 I**　物之出賣人對於買受人，應擔保其物依第三百七十三條之規定危險移轉於買受人時，無滅失或減少其價值之瑕疵，亦無滅失或減少其通常效用或契約預定效用之瑕疵。……
> **民法 §359**　買賣因物有瑕疵，而出賣人依前五條之規定，應負擔保之責者，買受人得解除其契約或請求減少其價金。但依情形，解除契約顯失公平者，買受人僅得請求減少價金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「車商 A 過失致煞車瑕疵未排除，A→甲→乙轉賣，乙因瑕疵車損，乙得否依 §184 I 前段向 A 請求？」 | **有爭議，寫兩說**。肯定說：車損＝所有權（絕對權）受侵害 → 前段 ✓。否定說（**多數說**）：這是物有瑕疵、債權未獲滿足（§354 瑕疵擔保範圍）→ 純粹經濟損失 → 前段 ✗；A 僅過失 → 後段、II ✗ → 乙對 A 無侵權請求權，應依 §359 對甲主張 |
| 「兩說觀察角度差在哪？」 | 肯定說看**毀損滅失結果**（所有權被破壞）；否定說看**瑕疵**（買到的東西本來就有瑕疵，是契約法益沒被滿足） |
| 「否定說理由？」 | 契約的事回歸契約，侵權責任不要無限擴大（「侵權行為不要管到海邊去」）；維護契約與侵權應有的分際 |
| 「肯定說／部分實務從寬的理由？」 | 乙找甲（§359）不一定拿得到錢（甲未必有資力）、問題根源在車商、甲也無辜、乙告甲再甲告 A 是一件訴訟變兩件 → 讓乙直接向車商求償使問題迅速圓滿解決 |
| 「學者歸屬？」 | 多數說（否定）：王澤鑑、陳聰富；少數說（肯定）：陳忠五。實務「大概五五開」 |

## 一、兩說對照

| | 肯定說 | 否定說（多數） |
|---|---|---|
| 觀察重點 | 車**毀損**了 | 車有**瑕疵** |
| 受侵害者 | 所有權（絕對權） | 債權（瑕疵擔保請求權未獲滿足） |
| 損失性質 | 絕對權侵害 | 純粹經濟損失 |
| §184 I 前段 | ✓ | ✗（後段、II 亦因 A 僅過失而 ✗） |
| 乙的救濟 | 直接對 A 車商侵權 | 對甲 §359 瑕疵擔保（甲再對 A 求償） |
| 支持者 | 陳忠五；部分實務 | 王澤鑑、陳聰富；部分實務 |

## 二、與前面案例的連結

- 一樣是「有損害 → 有沒有權利受侵害」的第二步判斷；差別在這題**兩個角度都說得通**（從瑕疵看是債權，從毀損看是所有權），所以無定論。
