# 民法27 筆記：定金之種類與效力（§248、§249）

## 五種定金：
- **證約定金**、**違約定金** → 民法直接規定（§248、§249）
- **成約定金**、**解約定金**、**立約定金** → 須當事人特約
- 沒有特約時，定金同時具有**證約＋違約**兩種功能

## 證約定金（§248）：
- 收受定金 → **推定**契約成立，不是視為
- 可舉反證推翻；例：看中某物先付一筆錢訂下來，但價金、清償方法都還沒合意
- 效果只是舉證責任轉換，契約是否成立仍看意思表示有無合致

## 成約定金（§166）：
- 當事人約定「付了定金契約才成立」→ 把定金當成**成立要件**（約定要式）
- 沒付定金 → 依 §166 **推定**不成立，也不是視為

## 違約定金（§249）：擔保契約履行
- 履行了 → 返還或**作為給付之一部**（例：車價 100 萬元，定金 10 萬元，交車時補 90 萬元）
- 不能履行，看誰可歸責：
  - **付定金**的一方 → 定金**不得請求返還**（被沒收）
  - **受定金**的一方 → **加倍返還**
  - 雙方都不可歸責 → 返還

## 解約定金（特約，類推 §249）：
- 付一筆錢「買一個反悔的權利」＝保留**任意解除權**（雙方都可行使）
- 一般契約只有合意解除與法定解除，任意解約原則上做不到
- 效果直接類推 §249：
  - 沒解約、履行了 → 返還或抵充價金
  - 付定金方解約 → 定金歸對方
  - 收定金方解約 → 加倍返還
  - 合意解約或法定解約 → 返還

## 立約定金（猶豫定金，特約，類推 §249）：
- 「買一個考慮的機會」，保留**締約**的機會
- 例：看中一支錶，付 100 元定金
  - 之後買了 → 返還或抵充價金
  - 自己不買 → 店家留下 100 元
  - 店家賣給別人 → 加倍返還 200 元
  - 雙方合意作罷 → 返還

## 📖 法條原文速查

> **§248**　訂約當事人之一方，由他方受有定金時，**推定**其契約成立。

> **§249**　定金，除當事人另有訂定外，適用左列之規定：
> 一、契約履行時，定金應返還或作為給付之一部。
> 二、契約因可歸責於**付定金**當事人之事由，致不能履行時，定金**不得請求返還**。
> 三、契約因可歸責於**受定金**當事人之事由，致不能履行時，該當事人應**加倍返還**其所受之定金。
> 四、契約因不可歸責於雙方當事人之事由，致不能履行時，定金應返還之。

> **§166**　契約當事人約定其契約須用一定方式者，在該方式未完成前，**推定**其契約不成立。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「收受定金，契約視為成立？」 | **錯**，是**推定**成立（§248） |
| 「約定付定金契約才成立，未付時契約視為不成立？」 | **錯**，§166 **推定**不成立 |
| 「無特約時定金的性質？」 | **證約＋違約** |
| 「可歸責於付定金一方致不能履行？」 | 定金**不得請求返還** |
| 「可歸責於受定金一方致不能履行？」 | **加倍返還** |
| 「解約定金、立約定金的效果依據？」 | 法無明文，**類推 §249** |

## 定金類型總表

| 類型 | 依據 | 功能 |
|---|---|---|
| 證約定金 | §248 | 推定契約成立 |
| 成約定金 | 特約（§166） | 定金為成立要件 |
| 違約定金 | §249 | 擔保履行 |
| 解約定金 | 特約，類推 §249 | 保留任意解除權 |
| 立約定金 | 特約，類推 §249 | 保留締約機會 |

```
§249 違約定金
├── 履行 → 返還或作為給付之一部
└── 不能履行
    ├── 可歸責付定金方 → 不得請求返還
    ├── 可歸責受定金方 → 加倍返還
    └── 雙方不可歸責 → 返還
```
