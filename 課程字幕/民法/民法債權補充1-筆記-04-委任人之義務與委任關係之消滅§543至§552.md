# 民法債權補充1 筆記：委任人之義務與委任關係之消滅（§543至§552）

## 委任人的義務
- **報酬**：有償委任才有；報酬給付時期等見 §547、§548
- **處理委任事務請求權不得讓與**：非經受任人同意，委任人不得將處理委任事務之請求權讓與第三人（§543）——例：請律師打官司，不能把「請律師打官司」的權利轉給別人
- **預付必要費用**：委任人因受任人請求，應預付處理委任事務的**必要**費用（§545）；有益、奢侈費用不能請求預付

## 處理事務後的償還與賠償（§546）
| 項 | 內容 |
|---|---|
| I | 受任人支出的**必要費用**，委任人應償還，並付自支出時起的**利息** |
| II | 受任人因處理事務負擔**必要債務**，得請求委任人代為清償；未到期者得請求提出相當擔保 |
| III | 受任人處理事務，因**非可歸責於自己**的事由受損害，得向委任人請求**賠償** |
| IV | 損害發生別有應負責之人時，委任人對其有**求償權** |

- 有益、奢侈費用：不在 §546 I，回到**無因管理**或**不當得利**處理
- §546 III、IV 結構與僱傭 §487-1 幾乎一樣（委任人負無過失責任，再向應負責之人求償）

## 委任關係的消滅
- **任意終止**（§549）：
  - 當事人任何一方得**隨時終止**
  - 於**不利於他方之時期**終止者，應負損害賠償責任；但因非可歸責於該當事人之事由，不得不終止者，不在此限
- **死亡、破產、喪失行為能力**（§550）：委任關係消滅；但契約另有訂定，或依委任事務性質不能消滅者除外
- **繼續處理義務**（§551）：§550 消滅有害於委任人利益之虞時，受任人或其繼承人、法定代理人，在委任人方能接受前，應繼續處理
- **視為存續**（§552）：消滅事由由一方發生，在他方**知悉或可得而知**前，委任關係視為存續
  - 例：律師受甲委任打官司，甲死亡但律師不知，繼續處理 → 視為委任存續
- §550、§551 在**借名登記**常見，之後專題再談

## 📖 法條原文速查

> **§549**（任意終止）當事人之任何一方，得隨時終止委任契約。當事人之一方，於不利於他方之時期終止契約者，應負損害賠償責任。但因非可歸責於該當事人之事由，致不得不終止契約者，不負賠償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 可請求預付之費用 | 限**必要**費用 |
| 支出必要費用之償還 | 含自支出時起之**利息** |
| 受任人無過失受損害 | 得向委任人請求賠償（§546 III） |
| 委任可否隨時終止 | **可**；不利時期終止須賠償 |
| 當事人死亡 | 原則消滅；另有約定或性質不能消滅者除外 |
| 不知消滅事由前之處理 | 視為存續（§552） |
