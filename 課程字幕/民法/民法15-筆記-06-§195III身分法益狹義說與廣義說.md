# 民法15 筆記：§195III身分法益狹義說與廣義說

## 問題：
- §195 III：不法侵害基於父母、子女、配偶關係之**身分法益**而情節重大者，準用 I、II 請求慰撫金
- 「身分法益」是什麼？必須是父母子女配偶間的**權利**被侵害，還是**情感利益**受侵害即可

## 案例（法警案）：
- 法警丙在法院對來做勞動服務的成年男子甲為性侵害；甲之配偶乙、母親丁能否向丙請求
- 乙、丁本身沒有被侵害，唯一可思考的是 §195 III
- （字幕 00:42:13～00:45:52 有缺漏，事實細節請對講義）

## 立法理由（講義註 161）：
- 父母子女配偶與本人關係最親密，其身分法益被侵害時所受精神痛苦最深
- 舉兩例：①未成年子女被擄略，父母**監護權**被侵害 ②配偶一方被強姦，他方身分法益被侵害

## 狹義說（葉啟洲）：
- 身分法益＝父母子女配偶間之**權利義務關係**受侵害；無權利即無身分法益之侵害
- 立法理由例①正確（監護權＝親權）；例②**舉錯**：夫妻間無身體上之權利義務
- 母親丁：父母對**成年子女**無保護教養權利（§1084 II 限未成年）→ **不得**請求
- 配偶乙：夫妻間無此權利 → 不得請求；且本件是被強姦，非外遇，無破壞家庭完整之問題

## 廣義說（陳忠五）：
- 身分法益＝父母子女配偶間之**情感利益**；理由在立法理由例②：配偶被強暴無權利受侵害，痛苦本身即屬之
- 控制閥在後段：**情節重大**。先把情感利益全放進來，只有情節重大者可請求
- 本件：被強姦是一輩子無法回復的傷痕 → 情節重大 → 母親丁、配偶乙**皆得**請求

## 📖 法條原文速查

> **民法 §195 III**　前二項規定，於不法侵害他人基於父母、子女或配偶關係之身分法益而情節重大者，準用之。

> **民法 §1084 II**　父母對於**未成年**之子女，有保護及教養之權利義務。

---

## 📋 實務見解速查

> **§195 III 立法理由**（講義註 161，依老師唸讀整理，原文請對講義）：鑑於父母或子女或配偶與本人之關係最為親密，基於此種親密關係所生之身分法益被侵害時，其所受精神上之痛苦最深，故明定「不法侵害他人基於父母、子女或配偶關係之身分法益而情節重大者」準用之。例：未成年子女被人擄略時，父母監護權被侵害所受精神上之痛苦；配偶之一方被強姦，他方身分法益被侵害所致精神上之痛苦。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§195 III 身分法益之範圍？」 | **狹義說**（葉啟洲）：限父母子女配偶間之**權利**受侵害；**廣義說**（陳忠五）：含**情感利益**，以「情節重大」控制 |
| 「成年子女被性侵，母親得否依 §195 III 請求慰撫金？」 | 狹義說：**否**（父母對成年子女無保護教養權利，§1084 II）；廣義說：**得**（情感利益受侵害且情節重大） |
| 「配偶一方被強姦，他方得否請求？」 | 立法理由舉為例子 → 廣義說肯定；狹義說認立法理由**舉錯**（夫妻間無身體上之權利義務） |
| 「葉啟洲對立法理由兩例之評價？」 | 例①（擄略未成年子女、監護權）**正確**；例②（配偶被強姦）**錯誤** |
| 「廣義說如何避免範圍過大？」 | 靠「**情節重大**」作為控制開關 |
| 「兩說的重點擺在哪？」 | 狹義說重在**前段**（先找出被侵害之權利）；廣義說重在**後段**（情節重大之判斷） |

## 一、兩說比較

| | 狹義說（葉啟洲） | 廣義說（陳忠五） |
|---|---|---|
| 身分法益之內涵 | 父母子女配偶間之權利義務 | 父母子女配偶間之情感利益 |
| 論證依據 | 立法理由例①（監護權） | 立法理由例②（配偶被強姦） |
| 對立法理由 | 例②舉錯 | 例②正是依據 |
| 控制方式 | 須先找出權利 | 情節重大 |
| 母親丁（子女已成年） | ✗ | ✓ |
| 配偶乙 | ✗ | ✓ |

## 二、案例：法警性侵案

#### 事實
1. 法警丙對來法院勞動服務之成年男子甲為性侵害。
2. 甲之配偶乙、母親丁欲向丙請求慰撫金。（字幕有缺漏，細節請對講義）

#### 分析
1. 乙、丁自身之身體健康等權利未受侵害 → 只能檢驗 §195 III。
2. 「配偶」「父母」之身分要件具備；問題在「身分法益」之內涵。
3. 狹義說：父母對成年子女無保護教養權利；夫妻間無身體上權利 → 無身分法益受侵害。
4. 廣義說：父母、配偶之情感利益受侵害；性侵害造成無法回復之傷痕 → 情節重大。

#### 結論
- 狹義說：乙、丁皆不得請求；廣義說：乙、丁皆得請求慰撫金。寫題時兩說並陳再表態。

## 三、與第 04 篇的分別

- 外遇是配偶**主動**破壞，才有「家庭完整」問題；本件被強姦**不是**外遇，葉啟洲特別指出無從以家庭完整論之。
