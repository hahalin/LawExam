# 民法40 筆記：使用借貸建屋於抵押權實行後之拆屋還地與誠信原則

## 案例八：借地在先，抵押在後，土地被拍賣
- 甲把 A 地**借**給丙 → 甲以 A 地設定抵押給乙 → 丙蓋 B 屋 → 乙實行，丁拍定 A 地
- 丁依 §767 I 請求丙拆屋還地？
  - 丁取得所有權：無爭議
  - 丙能否主張隨同移轉？**不能**。強執 §98 II 只列用益物權與租賃；租賃能並列是因 §425 買賣不破租賃，使用借貸沒有
  - 使用借貸能否類推 §425？通說**否定**（王澤鑑、陳聰富、最高法院；詹森林早期肯定）
    - 理由：債之相對性；使用借貸無償、租賃有償，差別保護有正當性
  - → 丙**無權占有**

## 戰場轉移：如何救丙的房屋
- **少數實務**：類推 **§425-1**，丙丁間推定租賃關係（丁有租金可收，不是無償忍受）
  - 謝哲勝寫了多篇文章支持類推 §425-1
- **多數實務**：情形不同（一個是自己的地屋，一個是借人蓋屋），類推基礎不足 → 回到**誠信原則**（§148 II）
  - 判斷：利益衡量、信賴保護
  - 例：50 年的小學校舍，具公益性；或拍定時已表示會讓房屋繼續坐落，事後反悔 → 違反誠信原則

## 不能拆屋時，能否請求不當得利
- **實務**：可以。誠信原則阻止的是 §767，不阻止 **§179** 相當於租金的不當得利
- **吳從周**：既然不能拆，表示房屋坐落有正當性，就沒有不當得利；應依**情事變更**請求法院核定租金

## 案例九：借地蓋屋，以**房屋**設定抵押
- 甲把 A 地借給丙 → 丙蓋 B 屋 → 丙以 B 屋設定抵押給乙 → 乙實行，丁拍定 B 屋
- 能否依 §877-1 把坐落權利併拍？§877-1 限「**得讓與**」的權利；使用借貸具專屬性，**不得讓與** → 不能併拍
- 甲對丁依 §767 請求拆屋還地：
  - **謝在全**：沒有坐落權源就拆。設定抵押時已知是使用借貸，這是抵押權人與拍定人應承擔的風險，不能叫地主忍受
  - **少數實務**：類推 §425-1 推定租賃（謝在全批評：架空 §877-1「得讓與」的限制）
  - **多數實務**：誠信原則，再搭配 §179 的爭議，同案例八
- 老師提醒：法拍屋 40 萬很便宜，常是沒有坐落權源，買了等著被拆

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 使用借貸可否隨同移轉（強執 §98 II） | **否** |
| 使用借貸可否類推 §425 | 通說**否** |
| 借地蓋屋，以屋抵押，可否依 §877-1 併拍 | **否**，使用借貸不得讓與 |
| 多數實務救濟途徑 | **誠信原則** |
| 違反誠信不能拆屋，可否請求不當得利 | 實務**可**；吳從周主張情事變更 |

## 判斷流程（拍定人或地主請求拆屋還地）

```
房屋坐落依據是使用借貸
  ├─ 強執 §98 II 隨同移轉？ → 否
  ├─ §877-1 併拍？ → 否（不得讓與）
  └─ 無權占有 →
       ├─ 謝在全：拆
       ├─ 少數實務：類推 §425-1 推定租賃
       └─ 多數實務：誠信原則
             ├─ 不違反 → §767 有理由
             └─ 違反 → 不能拆；§179 實務可請求／吳從周：情事變更定租金
```
