# 民法03 筆記：法人侵權責任體系與 §184 肯定說（108 台上 2035）

> 來源：民法03 課程字幕 00:20:23 ~ 00:36:25

---

## 📖 法條原文速查

> **§184 I**（一般侵權行為）
> 前段：因**故意或過失**，不法侵害他人之權利者，負損害賠償責任。
> 後段：故意以背於善良風俗之方法，加損害於他人者亦同。
> → 條文開頭沒有「法人」，也沒排除法人

> **§28**（法人侵權責任）
> **法人**對於其董事或其他有代表權之人因執行職務所加於他人之損害，與該行為人連帶負賠償之責任。
> → 條文開頭就是「法人」

> **§188 I 本文**（僱用人責任）
> 受僱人因執行職務，不法侵害他人之權利者，由僱用人與行為人連帶負損害賠償責任。

---

## 📋 實務見解速查

> **最高法院 80 年判決**（講義 70 頁註 80）：§184 I 兩種侵權行為類型均適用於**自然人**之侵權行為，法人無適用之餘地。（早期否定說）
> → 字號請查講義

> **最高法院 108 年度台上字第 2035 號判決**（講義 71 頁註 83）：正式承認法人得為 §184 之侵權行為主體（肯定說），揚棄早年見解。理由五點：法人實在說、文義解釋、統合構成員之行為、保護被害人、風險分配。
> → 建議查閱判決原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人有無契約責任？」 | **有**，法人能訂約就要負債務不履行責任，無爭議 |
| 「董事執行職務侵害他人，被害人對法人之請求權基礎？」 | **§28**（對行為人 §184） |
| 「受僱人執行職務侵害他人，被害人對法人之請求權基礎？」 | **§188**（對行為人 §184） |
| 「得否直接對法人主張 §184？」 | 早期**否**（法人無行為、無故意過失）；**108 台上 2035 改採肯定** |
| 「法人直接負 §184 責任，實益何在？」 | **行為人不明**時仍可求償；有行為人時舉證也較輕（不必證明行為人、指揮監督關係） |
| 「學說如何建構法人的行為與過失？」 | 行為＝**組織義務之違反**（不作為）；過失＝**客觀化**（陳聰富） |

---

## 一、法人責任體系

```
法人的責任
├── 契約責任：有，債務不履行（無爭議）
└── 侵權責任
      ├── 有行為人、知道是誰
      │     ├── 行為人是董事／其他有代表權之人 → 對行為人 §184；對法人 §28
      │     └── 行為人是受僱人                 → 對行為人 §184；對法人 §188
      └── 行為人不明（或不想走 §28／§188）
            → 可否直接對法人主張 §184？ ← 本筆記爭點
```
- §28、§188 結構一樣：都是法人（僱主）與行為人**連帶**負責。

## 二、早期否定說：法人沒有「行為」也沒有「故意過失」

§184 的三層構成要件：
```
① 行為層次：侵害行為、權利侵害、損害、因果關係
② 客觀歸責：不法性
③ 主觀歸責：故意過失、責任能力
```
- **行為**＝受意識支配的活動 → 法人不是自然人、沒有意識 → 沒有行為。
- **故意過失**＝注意義務之違反，注意是主觀認識 → 法人沒有主觀狀態。
- → 法人不能構成 §184，只能依 §28／§188 連帶負責。

## 三、108 台上 2035 肯定說：五個理由與學者評價

| # | 最高法院的理由 | 學者怎麼看 |
|---|---|---|
| 1 | **法人實在說**：法人是真正的權利主體 → 可負侵權責任 | ✗ 以前也採實在說，80 年判決照樣否定。實在說只說法人有權利能力，「專屬自然人者除外」，推不出侵權能力 |
| 2 | **文義解釋**：§184 沒排除法人 | ✗ 那怎麼不做體系解釋？§28 開頭是「法人」，§184 沒有，也可以解成不想給法人用 |
| 3 | **統合構成員的行為與過失**作為法人的行為與過失 | ✗ 沒解決問題：找得到構成員就直接用 §28／§188 了；找不到才要 §184，但找不到要怎麼「統合」？怎麼統、怎麼合都沒說 |
| 4 | **保護被害人** | ✓ 行為人不明時被害人多一條路；有行為人時舉證也輕 |
| 5 | **風險分配** | ✓ 法人從活動獲利，就該承擔自己製造的風險 |

- 前兩個理由「有寫跟沒寫一樣」；第三個沒正面回答；後兩個最站得住。

## 四、學說的建構方式（侵權行為法再細講）

```
法人的「行為」：不問法人做了什麼，問法人「什麼沒做到」
    → 法人作為社會組織，有防範危險的【組織義務】（上位概念：交易往來安全義務）
    → 違反組織義務 ＝ 不作為 ＝ 法人的行為
    → 不必再管構成員是誰、要不要統合

法人的「過失」：【過失客觀化】（陳聰富）
    → 不看主觀認識，看客觀上法人有哪些應注意、能注意而不注意
```
- 真正的問題是：站在法人的角度，「行為」「過失」要怎麼重新詮釋。實務的「統合說」沒回答這個。
