# 民法38 筆記：共有人優先承買權之目的與債權效力（土地法第34條之1第4項）

## 制度目的：簡化共有關係
- 甲乙丙共有 A 地，應有部分各 1/3；甲要把 1/3 賣給丁 → 乙或丙可以**同一價格**優先承購
- 賣給丁：仍是乙丙丁 3 人共有；由乙買走：乙 2/3、丙 1/3，只剩 2 人
- 共有人越少，處分、管理越有效率（動產處分要全體同意，不動產至少要多數決），越能物盡其用
- 前提承接民法37-筆記-12（共有物之處分與土地法第34條之1）

## 效力：通說只有債權效力
- 比較三個優先承買權的條文：
  - **§426-2 III**、**土地法 §104 II 後段**：有「**不得對抗**優先承買權人」→ 相對的物權效力
  - **土地法 §34-1 IV**：只有一句，**沒有**不得對抗的特別規定 → 只有**債權效力**
- 結果：乙已行使優先承買權，甲不理會，仍把 1/3 移轉登記給丁
  - 丁**確定取得** 1/3，乙不能請求丁塗銷
  - 乙只能對甲依 **§226** 請求債務不履行損害賠償（行使後甲乙間已成立買賣契約）

## 對照：有物權效力的優先承買權怎麼運作（§426-2）
- 甲把 A 地租給乙建屋，甲把 A 地賣給丙並移轉登記，未通知乙
- 乙對甲行使優先承買權 → 甲乙間成立買賣契約
- 移轉登記不得對抗乙 → 對乙而言 A 地仍屬甲 → 乙依 **§242 代位**甲依 **§767 I 中段**請求丙塗銷 → 再依 **§348** 請求甲移轉
- 「相對」的意思：不是當然無效，而是**乙主張後**，才可否認該移轉的效力

## 爭點：甲依法改賣給乙，原買受人丁可否對甲依 §226 請求？
- **否定說**（85 台上 1009）：甲是基於法律規定被迫移轉給乙 → **不可歸責** → 丁不得請求
- **肯定說**（103 台上 2392；謝在全）：出賣應有部分前本應先詢問其他共有人是否購買，這個風險出賣人可以**事先排除** → 仍可歸責 → 丁得請求
- 出處：講義註釋 228（153 頁）

```
甲出賣應有部分給丁 → 乙行使優先承買權（甲乙成立買賣）
├─ 甲仍移轉給丁 → 丁確定取得（債權效力）→ 乙對甲 §226
└─ 甲改移轉給乙 → 丁對甲 §226？ 否定說：不可歸責／肯定說：可歸責
```

## 📖 法條原文速查

> **土地法 §34-1 IV**　共有人出賣其應有部分時，他共有人得以**同一價格共同或單獨**優先承購。

> **§426-2 III**　出賣人未以書面通知優先承買權人而為所有權之移轉登記者，**不得對抗**優先承買權人。

> **土地法 §104 II**　前項優先購買權人，於接到出賣通知後**十日**內不表示者，其優先權視為放棄。出賣人未通知優先購買權人而與第三人訂立買賣契約者，其契約**不得對抗**優先購買權人。

> **§226 I**　因**可歸責於債務人**之事由，致給付不能者，債權人得請求賠償損害。

## 📋 實務見解速查

> **最高法院 85 年台上字第 1009 號判決**：出賣人因他共有人行使優先承買權而移轉給該共有人，屬不可歸責，原買受人不得依 §226 請求賠償。（要旨改寫，講義註釋 228）

> **最高法院 103 年台上字第 2392 號判決**：因他共有人行使優先承買權，致無法使買受人取得標的，係可歸責於出賣人之事由。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「土地法 §34-1 IV 優先承買權之效力？」 | 通說**債權效力** |
| 「為何不具物權效力？」 | 欠缺 §426-2 III、土地法 §104 II「**不得對抗**」之規定 |
| 「共有人已行使優先承買權，出賣人仍移轉給第三人，得否請求第三人塗銷？」 | **不得**，只能對出賣人依 **§226** 請求 |
| 「基地承租人優先承買權被違反，得否請求買受人塗銷？」 | **得**，§242 代位 §767 I 中段，再依 §348 |
| 「因他共有人優先承買，原買受人得否請求出賣人賠償？」 | 否定說（85 台上 1009）不可歸責；肯定說（103 台上 2392、謝在全）可歸責 |
