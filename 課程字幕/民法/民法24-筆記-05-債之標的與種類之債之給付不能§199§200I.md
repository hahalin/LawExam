# 民法24 筆記：債之標的與種類之債之給付不能（§199、§200 I）

## 債法的三個層次：
- **債之發生**（§152～§198）：契約、無因管理、不當得利、侵權行為
- **債之標的**（§199～§218-1）：債務的內容，統稱「**給付**」
- **債務不履行**：不給付會怎樣
- 先有債，才有債務，才有債務不履行

## §199：債的定義
- I：債權人基於債之關係，得向債務人請求給付——套用到所有的債（侵權、不當得利、買賣）
- 不會直接考，但有宣示意義；II、III（非財產價格、不作為）較不重要
- 特殊類型：**種類之債**（§200）、**貨幣之債**（§201～§202）、**利息之債**（§203～§207）、**選擇之債**（§208～§212）、損害賠償之債（§213～§218-1，已講過）

## 特定物之債 vs 種類之債：
- 到展間指定「這台展示機」→ **特定物之債**，只有這一台是給付內容
- 只約定型號、款式 → **種類之債**，給哪一台都可以
- 品質不能確定 → 給**中等品質**之物即已履行（§200 I）
- 網購幾乎都是種類之債：寄來的東西型號相符、中等品質 → 已履行，沒有債務不履行

## 種類之債原則上不會給付不能：
- 種類是抽象的，市場上還找得到就永遠可能給付
- 考法：甲向乙網購某型號筆電，乙出貨途中超速車禍，筆電滅失
  - 甲依 §226 請求賠償？第一個要件「給付不能」就不成立（倉庫還有、還能進貨）
  - 甲應依 **§348** 請求乙**再給一台**
- **37 年判例**（講義 413 頁，字號建議查證）：松材債務僅以種類指示，縱存放的松材於杭州淪陷時被毀，也不生給付不能

## 例外一：庫存之債（限制種類之債）
- 種類之外還有**一定範圍**界定 → 範圍內沒了就給付不能
- 104 年司法人員考過：**清倉大拍賣**，結束營業不再進貨 → 最後一台滅失 = 給付不能

## 📖 法條原文速查

> **§199**（債權人之權利）　I 債權人基於債之關係，得向債務人請求給付。II 給付，不以有財產價格者為限。III 不作為亦得為給付。

> **§200 I**（種類之債）　給付物僅以種類指示者，依法律行為之性質或當事人之意思不能定其品質時，債務人應給以**中等品質**之物。

> **§226 I**（可歸責之給付不能）　因可歸責於債務人之事由，致給付不能者，債權人得請求賠償損害。

> **§348 I**（出賣人之義務）　物之出賣人，負交付其物於買受人，並使其取得該物所有權之義務。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「種類之債未約定品質，應給付何種品質？」 | **中等品質**（§200 I） |
| 「種類之債特定前，標的物運送途中滅失，買受人得否依 §226 請求？」 | **不得**，種類之債特定前**無給付不能** |
| 「此時買受人應如何主張？」 | 依 §348 請求**另行給付** |
| 「清倉拍賣最後一台滅失？」 | **庫存之債** → 可能給付不能 |
| 「種類之債何時可能給付不能？」 | **庫存之債**、**標的已特定** |

## 種類之債與給付不能

```
種類之債
├── 原則：無給付不能（市場上找得到就能給）
│        └─ 運送途中滅失 → §348 再給一台
└── 例外
    ├── 庫存之債：範圍內全沒了 → 給付不能
    └── 標的特定（§200 II）→ 這一台滅失 → 給付不能
```

| | 一般網路商城 | 清倉大拍賣 |
|---|---|---|
| 債的類型 | 種類之債 | 庫存之債 |
| 運送途中滅失 | 再給一台 | 最後一台 → 給付不能 |
