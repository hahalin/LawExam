# 民法39 筆記：公同共有股票之管理人選任與表決權行使

## 案例：
- 甲持有 A 公司股票 120 張，死亡後由乙丙丁繼承，尚未分割遺產 → 股票**公同共有**
- 股東會要表決：乙贊成，丙丁反對，怎麼投？
- 民法與公司法交界，國考尚未考出；老師認為很適合二試，可切成**三層爭點**

## 第一層：可否多數決選任管理人？
- **實務（104 台上 2414）**：可以。選任管理人是管理行為 → §831 → §828 II → **§820** 多數決
- **林秀雄**：不可以
  - §1152 用「**互推**」：你推我、我推你 → 全體同意
  - 選任管理人是**授權他人管理**，與共有人自己管理不同；授權要有正當性，須全體同意

## 第二層：管理人可否行使表決權？
- 實務學說**一致否定**：表決權行使是**權利之行使**，超出管理範疇
- 領股東會紀念品之類還在管理範圍內

## 第三層：表決權如何行使？
- **可否割裂行使**（40 張贊成、80 張反對）
  - 早期經濟部函（69 年，講義註釋 312）、多數民法學者：**不可**，公同關係下要一致；要各自投票就先分割遺產
  - **邵慶平**：可以，按各自潛在應有部分行使，公司法未禁止
- **共同行使時要全體還是多數決**
  - **多數說**：表決權是 §828 III「**其他之權利行使**」→ §831 → §828 III **全體同意**
  - **游進發**：「其他權利行使」應以權利變動為前提，與處分類似；投票不會讓股票增減，較像**管理** → §831 → §828 II → §820 **多數決**
- 對多數說的批評：一人反對，120 張全成廢票；林秀雄等回應：**鼓勵分割遺產**
- 背後是思考方向不同：公司法學者重**公司治理**順暢；民法學者認為公同共有是一台車，只能朝一個方向

> 來源：民法39 課程字幕 00:40:20 ~ 00:54:24（講義 210～213 頁）；學者姓名字幕多處誤寫（林秀瓊→林秀雄、遊進發／劉進發→游進發），另一位「蔡軒廷／蔡宣廷」老師姓名建議查證

## 📖 法條原文速查

> **§1152**（遺產管理）前條公同共有之遺產，得由繼承人中**互推一人**管理之。

> **§820 I**（共有物之管理）共有物之管理，除契約另有約定外，應以共有人過半數及其應有部分合計過半數之同意行之。但其應有部分合計逾三分之二者，其人數不予計算。

> **§828 II、III**　第 820 條、第 821 條及第 826 條之 1 規定，於公同共有準用之。／公同共有物之處分，及**其他之權利行使**，除法律另有規定外，應得公同共有人全體之同意。

> **§831**　本節規定，於所有權以外之財產權，由數人共有或公同共有者準用之。

## 📋 實務見解速查

> **最高法院 104 年度台上字第 2414 號判決**（講義 210 頁；字幕唸「104年的2414號」，字號建議查證）：繼承人公同共有之股票，推選管理人屬管理行為，得依 §831 準用 §828 II、§820 以多數決為之。（要旨改寫，依課堂講述）

> **經濟部 69 年函釋**（講義註釋 312，字號字幕未唸）：公同共有股份之表決權應一致行使，不得割裂。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「繼承人可否多數決推選股票管理人？」 | 實務：**可**（§820）；林秀雄：否（§1152 互推＝全體） |
| 「管理人可否代為行使表決權？」 | **不可**，表決權行使非管理行為 |
| 「公同共有股票可否割裂行使表決權？」 | 經濟部函、多數民法學者：**不可**；邵慶平：可 |
| 「共同行使表決權須全體同意？」 | 多數說：**全體**（§828 III 其他權利行使）；游進發：多數決 |

## 三層爭點圖

```
公同共有股票 120 張
├─ ① 選任管理人
│    ├─ 實務：管理行為 → §820 多數決
│    └─ 林秀雄：§1152 互推 → 全體同意
├─ ② 管理人能否投票 → 否（權利行使≠管理）
└─ ③ 怎麼投
     ├─ 割裂行使？ 多數：否／邵慶平：可
     └─ 共同行使
          ├─ 多數說：§828 III → 全體同意
          └─ 游進發：類似管理 → §820 多數決
```
