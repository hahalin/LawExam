# 民法15 筆記：蛋殼頭蓋骨理論與比例因果關係

## 特殊理論的定位：
- 一般因果關係理論可處理 99% 的問題；剩下 1% 結果不合理，才提出特殊理論**補充修正**
- 涵攝順序：先用事實上＋法律上因果關係，結果合理就不必再談特殊理論；結果不合理才拿出來

## 蛋殼頭蓋骨理論（特殊體質）：
- 甲頭殼薄如蛋殼，乙拍一下，甲頭破血流
- 相當性：一般人被拍只會痛不會破 → 不是通常結果 → 法律上因果關係過不去 → 乙不用賠，**不合理**
- 理論：**擬制因果關係具備**，侵權行為成立；再以 **§217 與有過失**調整——甲明知自己特殊體質，有無採取必要保護措施（如戴安全帽）
- 名稱固定叫「**蛋殼頭蓋骨理論**」，不要自創名稱

## 比例因果關係：
- 適用領域：**公害、食安、醫療**等舉證特別困難之案件
- 例：甲工廠排廢水，乙農田污染，廢水原因占 40%、其他原因 60%
- 傳統理論：事實上因果都過不去（沒有甲，仍可能因其他原因受相同損害）；機率低於 50% 也無相當性 → 一毛都拿不到
- 比例因果：按比例請求——損失 100 萬、機率 40% → 請求 **40 萬**

## 全有或全無原則：
- 相當性判斷只有兩種結果：超過一半 → 全賠；低於一半 → 一毛都沒有
- 比例因果是英美法為修正此問題而生，讓被害人依其證明出的比例求償

## 兩個使用限制：
- ①只用於**舉證困難**之公害、食安、醫療案件，不是所有案件
- ②是為**保護被害人**而設，被害人證明度**低於 50%**、過不了相當性門檻時才用；**加害人不得**拿來抗辯（被害人已證明 80%，加害人不能主張只賠八成）

## 考試：
- 老師提到民國 **98 年**考過**蛋殼頭蓋骨＋§217 與有過失**（老師講完蛋殼頭蓋骨搭配 §217 後即說「當年就考成」，之後才轉入比例因果關係）

## 📖 法條原文速查

> **民法 §217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

> **民法 §184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「特殊體質之被害人，依相當因果關係結論為何？」 | 非通常結果 → 相當性 **✗**，結論不合理 → 用**蛋殼頭蓋骨理論**修正 |
| 「蛋殼頭蓋骨理論之法律效果？」 | **擬制因果關係具備**、侵權成立；再依 **§217 與有過失**減輕（被害人是否對自身體質盡必要注意） |
| 「比例因果關係適用於何種案件？」 | 舉證困難之**公害、食安、醫療**案件 |
| 「比例因果關係之計算？」 | 損害額 × 致害機率（100 萬 × 40% ＝ 40 萬） |
| 「加害人得否主張比例因果關係減輕責任？」 | **不得**。理論為保護被害人而設，僅於被害人證明度**未達 50%** 時使用 |
| 「全有或全無原則指？」 | 相當性判斷只有有或無：過半全賠、未過半全無 |
| 「何時應提出特殊因果理論？」 | 一般理論涵攝結果**不合理**時才補充使用 |

## 一、兩理論對照

| | 蛋殼頭蓋骨理論 | 比例因果關係 |
|---|---|---|
| 問題 | 被害人特殊體質 | 損害原因眾多、機率低於 50% |
| 傳統理論卡在 | 法律上因果（相當性） | 事實上因果（條件）即過不去 |
| 處理 | 擬制因果具備 | 按機率比例賠償 |
| 調整工具 | §217 與有過失 | 比例本身 |
| 適用範圍 | 特殊體質 | 公害、食安、醫療 |
| 誰可主張 | 被害人 | 只有被害人 |

## 二、判斷流程

```
一般因果關係涵攝（條件 → 相當性）
   ├── 結果合理 → 結束，不談特殊理論
   └── 結果不合理
        ├── 特殊體質 → 蛋殼頭蓋骨：擬制因果 → §217 調整
        └── 舉證困難、機率 < 50%（公害／食安／醫療）
             → 比例因果：按比例請求
             （≥ 50% 已過相當性 → 全有，不必使用）
```

## 三、案例：工廠排放廢水

#### 事實
- 甲工廠排放廢水，乙農田受污染損失 100 萬；鑑定只能說廢水造成之可能性為 40%。

#### 分析
1. 條件理論：其他原因占 60%，沒有甲仍可能受相同損害 → 事實上因果難以成立。
2. 相當性：低於 50% → 不具相當性。
3. 全有全無下乙一毛都拿不到；本件屬舉證困難之公害案件，被害人證明度未達 50% → 適用比例因果關係。

#### 結論
- 乙得請求 40 萬。
