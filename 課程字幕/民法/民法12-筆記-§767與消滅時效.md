# 民法12 筆記：§767 物上請求權與消滅時效

> 來源：民法12 課程字幕 00:03:27 ~ 00:22:33

---

## 📖 法條原文速查

> **§87**（通謀虛偽意思表示）
> I：表意人與相對人通謀而為虛偽意思表示者，其意思表示**無效**。但不得以其無效對抗善意第三人。

> **§125**（一般消滅時效）
> 請求權，因**十五年**間不行使而消滅。但法律所定期間較短者，依其規定。

> **§144**（時效完成之效力）
> I：時效完成後，債務人得**拒絕給付**。

> **§148**（誠信原則）
> II：行使權利，履行義務，應依**誠實及信用**方法。

> **§759-1**（不動產物權善意取得）
> II：因信賴不動產登記之善意第三人，已依法律行為為物權變動之登記者，其變動之效力，不因原登記物權之不實而受影響。
> → 重點：**須為「法律行為」**，繼承非法律行為，故不適用。

> **§758**（不動產物權登記生效要件）
> I：不動產物權，依法律行為而取得、設定、喪失及變更者，非經登記，不生效力。
> → 重點：登記是生效要件，但若基礎的**物權合意無效**（如 §87 通謀虛偽），即使已辦登記也不生效。

> **§767**（所有人之物上請求權）★★★★★ 核心條文
> I 前段：所有人對於無權占有或侵奪其所有物者，得**請求返還**之。→ 對應**釋字 107**
> I 中段：對於妨害其所有權者，得**請求除去**之。→ 對應**釋字 164**
> I 後段：有妨害其所有權之虞者，得**請求防止**之。

> **§1146**（繼承回復請求權）
> I：繼承權被侵害者，被害人或其法定代理人得請求回復之。
> II：前項請求權，自知悉被侵害之時起，**二年**間不行使而消滅；自繼承開始時起逾**十年**者亦同。

> **§1148**（繼承之效力——概括承受）
> I：繼承人自繼承開始時，除本法另有規定外，承受被繼承人財產上之**一切權利、義務**。
> → 重點：繼承是「概括承受」，被繼承人有什麼就承受什麼。被繼承人**沒有的權利**，繼承人也無從承受。

## 📋 釋字原文速查

> **釋字 107 號**：已登記不動產所有人之**回復請求權**（§767 I 前段），無民法第 125 條消滅時效之適用。

> **釋字 164 號**：已登記不動產所有人之**除去妨害請求權**（§767 I 中段），不在同法第 125 條所定消滅時效之列。

> **69 台上 277 判例**：釋字 107 號所謂「已登記不動產所有人」，指依土地法辦理登記之不動產**真正所有人**，非指登記名義人。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「動產之 §767 有無消滅時效？」 | **有**，§125（15 年） |
| 「已登記不動產之 §767 有無消滅時效？」 | **原則無**（釋字 107、164）；**例外有**（釋字 771：§1146 競合時） |
| 「未登記不動產之 §767 有無消滅時效？」 | **原則有**（§125）；**例外無**（依法無須登記者，如水源地） |
| 「『已登記不動產所有人』如何解讀？」 | 「已登記不動產」＋「所有人」（前六後三），指**真正所有人**，非登記名義人 |
| 「釋字 107 對應 §767 哪一段？」 | **前段**（返還請求權） |
| 「釋字 164 對應 §767 哪一段？」 | **中段**（除去妨害請求權） |
| 「通謀虛偽→繼承登記→20年後能否 §767？」| **能**。真正所有人的 §767 不受時效限制，丙不得主張 §144 |
| 「已登記土地上的未登記房屋被占用」 | 土地可請求返還（無時效）→ 房屋坐落其上不可分離 → 一併返還（83年第7次決議） |

## 一、§767 消滅時效體系總覽

```
§767 物上請求權
│
├── 動產 → 有消滅時效，適用 §125（15 年）
│
└── 不動產
    ├── 已登記不動產
    │   ├── 【原則】無消滅時效適用（釋字 107、164）
    │   └── 【例外】§767 與 §1146 競合時 → 有消滅時效（釋字 771）
    │
    └── 未登記不動產
        ├── 【原則】有消滅時效，適用 §125（15 年）
        └── 【例外】依法無須登記的不動產（ex. 水源地、當然國有地）→ 無消滅時效
```

## 二、已登記不動產——釋字 107、164 號

### 基本規則
- **已登記不動產的物上請求權，原則上無消滅時效適用**
- 釋字 107 → 針對 §767 第 1 項**前段**（所有物返還請求權）
- 釋字 164 → 針對 §767 第 1 項**中段**（妨害除去請求權）

### 理由
> 消滅時效的目的 → 維護法安定性（避免法律關係長久處於不確定狀態）
>
> 不動產物權的登記制度本身已足以維護法安定性 → 不需要再用消滅時效來限制權利人

### 考試援用提醒
| 當事人主張 | 援用的大法官解釋 |
|-----------|----------------|
| §767 I **前段**（返還請求） | **釋字 107** |
| §767 I **中段**（除去妨害） | **釋字 164** |

## 三、「已登記不動產所有人」九字解釋

### 爭點：這九個字怎麼斷句？

| 解讀方式 | 斷句 | 意涵 |
|---------|------|------|
| ✗ 錯誤解讀 | 「已登記」＋「不動產所有人」 | 你必須**登記為**該不動產所有人，§767 才不受時效限制 |
| ✓ 正確解讀 | 「已登記不動產」＋「所有人」 | 只要你是一個**已辦理登記的不動產**的**真正所有人**即可 |

### 實務見解
- **69 年台上字第 277 號判例**：
  > 「司法院大法官會議釋字第 107 號解釋所謂已登記不動產所有人，乃指**依土地法辦理登記之不動產真正所有人**而言，並非指以登記為其名義的不動產所有人而言。」
- 關鍵：**不動產有沒有登記在你名下不是重點，重點是你是不是真正所有人**

## 四、案例一：通謀虛偽意思表示與時效抗辯

### 事實

```
甲 ───§87（通謀虛偽）──→ 乙 ✗（未取得所有權）
│（A地所有人）    §758（登記移轉）     │
│                                     │ 死亡
│                                     ↓
│                              丙（乙之子，善意）
│                              繼承登記 A 地
│                                     │
│←─── 20 年後想拿回 A 地 ────────┘
│
§767 I 中段？

               ┌────┐
          A 地 │ 甲 │← 真正所有人（§87 → 物權行為無效）
         登記：│ 乙 │✗（從未取得）
               │(丙)│← 繼承登記（繼承 = 概括承受，乙無權 → 丙亦無權）
               └────┘
```

1. 甲通謀虛偽意思表示（§87），將 A 地登記移轉在乙名下（§758）
2. 乙過世後，善意的丙（乙之子）繼承登記 A 地到自己名下
3. 20 年後，甲想把 A 地拿回來

### 甲 → 丙 §767 I 中段？——三點層級式分析（對照板書）

#### **1. 甲 ＝ A 地所有人 ✓**

> 目標：證明甲至今仍為 A 地的真正所有人

**(1) 甲乙間 §87 → §758 ✗**
- 甲乙通謀虛偽意思表示（§87 I）→ 意思表示**無效**
- 物權行為亦無效 → 登記移轉不生效力（§758 的登記雖已辦理，但基礎的物權合意無效）
- **結論：乙從未取得 A 地所有權**

**(2) 乙 ≠ A（乙不是 A 地所有人）→ 丙也無法經由乙取得**
- ① **丙 §1148 ✗**：繼承是概括承受被繼承人一切權利義務（§1148），但乙根本沒有 A 地所有權可供丙繼承 → 「無中生有」不可能
- ② **丙 §759-1 II ✗**：不動產善意取得（§759-1 II）須以「**法律行為**」為前提，繼承是**事實行為**（非法律行為）→ 丙不能主張善意取得

**(3) 丙 ≠ A（丙也不是 A 地所有人）**
- 乙無所有權 + 繼承無法創造所有權 + 善意取得不適用
- **結論：丙雖然登記為所有人，但並非真正所有人**

> **甲從未喪失 A 地所有權 → 甲仍為 A 地所有人 ✓**

#### **2. 丙構成妨害 ✓**

- 丙非所有人卻登記為所有人 → 登記名義與真實權利不符
- 構成對甲真正所有權的**妨害**
- 甲得依 §767 I 中段請求丙**塗銷**登記

#### **3. 丙 §144 時效抗辯？ → ✗ 不能**

- 爭點：A 地登記在丙名下，甲算不算「已登記不動產所有人」？
- 依正確解讀（**前六後三**）：
  - 「已登記不動產」→ A 地是有辦理登記的不動產 ✓
  - 「所有人」→ 甲是真正所有人 ✓
- 援用：**釋字 164** → §767 I 中段**無消滅時效**適用 ✓
- **結論：甲的 §767 不受消滅時效限制，丙不能主張 §144 時效抗辯**

### 完整推導流程圖

```
甲 → 丙 §767 I 中段（塗銷登記）？

1. 甲 = A地所有人？ ✓
   ├── (1) 甲乙 §87 → 無效 → §758 登記不生效力 → 乙未取得
   ├── (2) 乙 ≠ A → 丙能否取得？
   │       ├── ① §1148 繼承？✗（無中生有不可能）
   │       └── ② §759-1 II 善意取得？✗（繼承非法律行為）
   └── (3) 丙 ≠ A → 甲仍為所有人 ✓

2. 妨害？ ✓
   └── 丙非所有人卻登記為所有人 = 妨害

3. 丙 §144 時效抗辯？ ✗
   └── 釋字 164 ✓ →「已登記不動產」+「所有人」→ 無消滅時效

結論：甲勝，丙應塗銷登記
```

### 一試選擇題怎麼考？

> **模擬題**：甲將其已登記之 A 地，以通謀虛偽意思表示移轉登記予乙。乙死亡後，其善意之子丙辦理繼承登記。20 年後甲欲主張權利。下列敘述何者**正確**？
>
> (A) 甲乙間之物權行為有效，乙已取得 A 地所有權
> (B) 丙因善意繼承登記，依民法第 759 條之 1 第 2 項善意取得 A 地所有權
> (C) 甲得依民法第 767 條第 1 項中段請求丙塗銷登記，且不受消滅時效限制
> (D) 丙得依民法第 144 條主張時效抗辯，拒絕甲之請求

**答案：(C)**

| 選項 | 對/錯 | 考你哪個觀念 |
|------|-------|-------------|
| (A) | ✗ | §87 通謀虛偽 → 無效，物權行為也無效 |
| (B) | ✗ | §759-1 II 善意取得須以「法律行為」為前提，繼承是事實行為，不適用 |
| (C) | ✓ | 釋字 164 → 已登記不動產所有人的 §767 I 中段不受消滅時效限制 |
| (D) | ✗ | 承 (C)，既然無消滅時效，§144 抗辯無從主張 |

| 條號 | 一句話記憶 | 選項怎麼考 |
|------|-----------|-----------|

| **§758** | 不動產物權要**登記**才生效 | 反面：基礎行為無效 → 登記也無效 |
| **§759-1 II** | 善意取得須**法律行為** | 選項會說「丙善意繼承→取得所有權」來騙你 |

## 五、案例二：已登記土地 + 未登記房屋（83 年第七次民事庭決議）

### 事實
1. 甲擁有已登記的 A 地，在 A 地上建了未登記的 B 房屋（違章建築）
2. 乙無權佔用 B 房屋及 A 地達 20 年
3. 甲回國後發現，想主張權利

### 分析

#### （一）請求返還 A 地（已登記土地）
- §767 I 前段 → 構成要件該當
- 時效：已登記不動產 → 依釋字 107，**無消滅時效適用**
- **結論：✓ 可以請求返還 A 地**

#### （二）請求返還 B 房屋（未登記房屋）
- §767 I 前段 → 構成要件該當
- 時效問題：
  - B 是未登記不動產 → 原則有消滅時效（§125，15 年）
  - 已超過 20 年 → 原則上可主張時效抗辯

#### （三）83 年第七次民事庭決議的處理（板書標記：83.7th）

> **問題**：如果只需返還土地不需返還房屋 → 房屋不可能脫離土地 → 執行不能

**決議要旨**：
- 無權佔有人佔有建物的時效利益，**不能擴張及於基地的佔有**
- 即使對建物的回復請求權罹於時效，佔有人**僅取得拒絕交還建物的抗辯權**，並非變成有權佔有
- 基地所有人得主張無權佔用基地的法律關係，請求佔有人**遷出房屋並交還基地**

**結論（板書：返 A / 必返 B）**：
- 甲可一併請求返還 A 地（已登記）及 B 房屋（未登記）
- 因為 A 與 B 不可分離，返還 A 必然一併返還 B
- 乙對 B 的時效抗辯（§144）在此情形下實質上受到限制

### 邏輯圖解
```
A 地（已登記）──→ 無消滅時效 ──→ 甲可請求返還 A
                                         │
B 房屋（未登記）──→ 原則有消滅時效   │
    但：B 坐落於 A 之上，不可分離 ──→ 返還 A 必然一併返還 B
                                         │
結論：乙必須一併交還 A 地及 B 房屋 ◄──┘
```

## 六、未登記不動產的例外：依法無須登記

- 某些土地本質上當然為國有地，無法私有、無法移轉、也無法辦理登記
- 這種依法無須登記的不動產，即使未登記，§767 也**不受消滅時效限制**
