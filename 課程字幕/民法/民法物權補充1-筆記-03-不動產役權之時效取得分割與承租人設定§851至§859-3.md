# 民法物權補充1 筆記：不動產役權之時效取得分割與承租人設定（§851至§859-3）

## 性質：消極支配（§851）
- 以他人不動產供自己不動產**通行、汲水、採光、眺望、電信**或其他特定便宜之用
- 地上權、農育權是**積極**使用他人土地；不動產役權是**消極**限制他人使用（例：不准鄰地蓋高樓擋光）
- 用語：有需要的一方＝**需役不動產**；提供的一方＝**供役不動產**
- 舊法叫「地役權」只能對土地設定；現行法對房屋也可設定，改稱不動產役權

## 與用益物權並存：先來後到（§851-1）
- 同一不動產上不動產役權與以使用收益為目的的物權同時存在，**後設定者不得妨害先設定者**

## 時效取得（§852，選擇題常客）
- 一般時效取得以占有為外觀；不動產役權是消極支配，沒有占有外觀
- → 限**繼續並表見**者（例：長年可見的通行道路、引水設施）
- 需役不動產為**共有**：共有人中一人的行為，或對共有人中一人的行為，為他共有人利益亦生效力
  - 例：甲乙丙共有 A 地，甲長年表見通行丁的 B 地 → 乙丙一起受益
- 向行使取得時效的各共有人為**中斷**時效行為 → 對全體共有人生效（例：丁只向乙表示不准走，全體中斷）

## 從屬性（§853）與不得設定抵押（§882）
- 不得由需役不動產**分離**而為讓與，或為其他權利的標的物
- 需役地賣了，役權隨同移轉；不能單獨處分
- 對需役地以外的人沒有價值 → **不得設定權利抵押**；§882 只列地上權、農育權、典權

## 分割後存續於哪一部分（§856、§857）
- **需役**不動產分割：原則為各部分利益仍存續；依性質只關於一部分者，**僅就該部分**存續（§856）
- **供役**不動產分割：原則存續；依性質只關於一部分者，僅對該部分存續（§857）
- 例：A 地（需役）分成 A1、A2，B 地（供役）分成 B1、B2，道路只連 A2 與 B2 → 只剩 **A2 對 B2** 有役權

## 用益權人、承租人也能設定（§859-3）
- 基於使用收益物權或**租賃**關係使用不動產者，亦得為該不動產設定不動產役權
- 該役權因原用益物權或租賃關係**消滅而消滅**

## 📖 法條原文速查

> **§852 I**（時效取得）不動產役權因時效而取得者，以繼續並表見者為限。

> **§882**（權利抵押）地上權、農育權及典權，均得為抵押權之標的物。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 不動產役權時效取得之要件 | **繼續並表見** |
| 需役地共有，一人通行 | 為全體共有人利益生效 |
| 對一共有人中斷時效 | 對**全體**生效 |
| 可否單獨讓與不動產役權 | **否**（§853） |
| 下列何者不得為抵押權標的 | **不動產役權** |
| 承租人可否設定不動產役權 | **可**，租賃消滅即消滅（§859-3） |

## 分割示意

```
A1 ┐                  ┌ B1
   ├ A 地（需役）       │ B 地（供役）
A2 ┘ ── 道路 ─────────── B2
結果：只有 A2 → B2 存續（§856、§857 但書）
```
