2合約上寫「承攬」，不代表你就是承攬

甲在報社送報三十年，65 歲退休要退休金。報社拿出三十年前的「承攬契約書」說：我們是承攬，沒有勞基法。但契約裡寫著幾點到公司、幾點前送完、要收款回報、要接受調班。

名稱說承攬，內容像什麼？法官看哪一個？

  • §98：探求真意，不拘泥文字 → 看內容不看名稱
    • 有指揮監督（一個口令一個動作、調班、回報）→ 僱傭 §482 → 勞基法、退休金
    • 無指揮監督、重過程（律師、醫生：輸官司、病人過世不算違約）→ 委任 §528
    • 無指揮監督、重結果（水電工：怎麼修不管，通了就好）→ 承攬 §490
規則

不是每個人都懂法律，寫出來的字句常不精準，所以 §98 叫法官去找當事人真正的意思。送報生案最高法院就是這樣判：滿滿的指揮監督，本質是僱傭。

現代版是外送員、車隊司機——契約都叫承攬，勞動部說是僱傭。差別在外送員撞到人：僱傭 → 平台依 §188 連帶賠；承攬 → §189 定作人原則不負責。實務為了保護外送員和被害人，有指揮監督要素就偏向僱傭。

陷阱

考試不會問「Uber 外送員是什麼契約」（沒看契約無法判斷），申論會給你契約內容，要你自己找有沒有指揮監督。

3信送到你家門口就算數，你家狗咬爛是你的事

房東在路上遇到剛來台灣、聽不懂中文的韓國房客，口頭說「該繳房租了」。另一題：人事主管不好意思當面解僱老員工，把解僱通知偷塞進他桌上的文件夾。第三題：對方律師說 3 點前沒收到和解條件就破局，你傳真過去，他故意不放紙。

三個意思表示各自生效了嗎？

對話 §94：瞭解時生效

即時、不留紀錄（面對面、電話）
韓國房客聽不懂 → 沒瞭解 → 催告不生效 → 不能依 §440 終止

非對話 §95：到達時生效

有時間差、留紀錄（信、Email、LINE 文字、LINE 語音）
到達＝置於相對人隨時可瞭解之地位，不以看到為必要
寄出 → 到達前：寄不到的風險歸表意人
到達（進信箱）→ 打開前：沒看到的風險歸相對人
規則

為什麼非對話不用「瞭解」而用「到達」切？風險分配：表意人只要把看得懂的內容送到你家門口就完成任務；之後家人丟掉、狗咬爛、沒開信箱，都是相對人的風險。前提是內容相對人看得懂——寄中文信給看不懂中文的人，到了也沒用。

但「到達」要輔以誠信原則（陳聰富）：解僱通知塞文件夾，形式上「打開就看到」，但方式顯然不誠信 → 不算到達；傳真故意不放紙，客觀沒到，但相對人故意阻撓 → 擬制到達。

陷阱

LINE 語音訊息是用嘴巴講，卻是非對話——它留在對方手機裡隨時能點開。判準是即時性和有沒有紀錄，不是用嘴還是用手。

4掛號信沒去領被退回，算送到了嗎

乙一直遲延交貨，甲用掛號寄催告函。郵差到乙家時乙不在，貼了招領通知「15 天內到郵局領」。乙沒去領，信被退回。甲接著寄解約通知。

催告有到達嗎？解約有效嗎？你是上班族，週一到五早八晚七，週末郵局沒開，你怎麼領？

大法庭 109 台上大 908

原則：受招領通知時即到達，不以領取為必要
例外：相對人證明有不能領取的正當事由（被教召、寄到五年前的租屋處）

吳從周

招領通知 ≠「隨時」可瞭解：郵局不是超商、只有 15 天、不知誰寄的也不知內容
原則：不到達；例外：相對人違反誠信故意不領 → 擬制到達
規則

大法庭貫徹 §95 的風險分配：我寄到你家門口就完成任務，15 天不去領被退回關我什麼事。學說說這誤會了「到達」的定義——一般信件 24 小時躺在信箱裡，一個月收一次信也看得到；招領通知只給你 15 天上班時間，不是「隨時」。

兩說的原則例外剛好顛倒，舉證責任也跟著反過來：大法庭要相對人證明正當事由，吳從周要表意人證明相對人惡意。

陷阱

這個裁定不會單獨出 25 分，但「超級萬用」：§254 催告解除、§80 催告法代、§426-2 優先承買通知、§440 催告繳租——只要題目裡有一封掛號信被退回，就是在考它。

5跟老婆說等於跟老公說？跟警衛說呢？

房東甲要終止租約，房客乙不在，甲跟乙的太太丙講了，丙忘記轉達。另一題：老股東跑到 HTC 總部跟警衛說「幫我轉告王雪紅」；另一個股東找上王雪紅的秘書講了一堆。

終止生效了嗎？警衛和秘書有什麼不同？

實務（86 台上 3742）

只看有沒有轉達：丙沒轉達 → 不生效。警衛、秘書都一樣

學說（王澤鑑）

先問受領的人有沒有「告知受領權」
有（代理人、秘書）→ 對他說＝對本人說 → 他瞭解即生效（§94），轉不轉達不重要
無（警衛）→ 只是傳達人 → 看有沒有帶到（§95）
規則

夫妻於日常家務互為代理人（§1003）。催繳房租、終止租約算日常家務 → 丙有代理權、有告知受領權 → 甲對丙說完就生效，丙忘記是乙家的事。實務沒去問丙是誰，直接看轉達，學者認為不當。

王澤鑑很人性化的補充：告知受領權不是永久的。秘書休假、下班後、半夜被 LINE，那時候他只是一般人，沒有受領權 → 等他上班轉達才生效。

陷阱

兩說結論常常一樣（警衛案：都不生效），差別只在「有告知受領權但沒轉達」這一格——秘書案、老婆案。考題就會設計這一格。

9:00 已生效 → 收回永遠來不及 → §95 I 但書在網路時代變具文
陳聰富：合理閱讀期間

9病床前被情勒答應送房子：誰的意思表示出了問題

媽媽臨終前叫有錢的哥哥甲把一間房送給好吃懶做的弟弟乙。甲根本不想送，但只好說「好」；乙真心說「我接受」。

贈與契約有效嗎？關鍵在誰知道什麼？乙的意思表示會不會也跟著無效？

  • 意思表示的瑕疵 §86～§93
    • 不一致（想的 ≠ 說的）：故意 → §86 心中保留、§87 通謀；偶然 → §88～91 錯誤（不叫「過失」不一致，因 §88 要無過失）
    • 不自由（不一致是被迫的）：§92 §93 詐欺脅迫

乙不知

乙明知

規則

§86 心中保留（一試叫真意保留、單獨虛偽意思表示）：明明不想卻故意做。原則以外部表示為準（保護不知情的相對人），相對人明知就以內心為準。「不因之無效」不等於一定有效——還可能因違反強行規定、公序良俗、無行為能力而無效，題目沒給線索就當有效。

§86 只處理表意人那一條意思表示。乙是真心的，乙的「知道」影響的是甲的意思表示，不是乙自己的。

陷阱

選擇題：「因乙明知甲為虛偽意思表示，故乙之意思表示亦無效」→ 錯。除非甲乙都虛偽，那是 §87 通謀。問「贈與契約效力」要說理：是甲那條缺了。

王澤鑑

善意受讓是物權法特別規定，優先適用 → 有重大過失不能善意受讓，也不能用但書

林誠二

兩條路並存自選。誰才特別？但書只管通謀，善意受讓管所有無權處分 → 但書才特別
規則

解題兩招：請求權基礎（誰告誰、憑哪條、要件逐一檢驗）＋時間順序（先甲乙、再乙丙、最後丙）。§767 第一個要件「甲是所有人」不過，後面都不用看。

善意受讓的背景：物權是絕對權要讓人看得到（公示：動產占有、不動產登記），但外觀只有推定力（§943、§759-1 I），相信外觀的人要保護，不然每筆交易都要追查前手（公信）。§801 說「占有受保護」卻沒說什麼叫受保護，所以一定要配 §948：依法律行為（繼承不算）＋善意無重大過失。

兩條路沒落差就擇一；有落差才寫爭議：重大過失、債權讓與（債權不是物，不能善意受讓，只剩但書——105 律師考過）、§92 II 脅迫可對抗善意第三人（下堂）。

陷阱

寫「甲承認無權處分」就自打嘴巴——承認了乙丙有效，甲還告丙幹嘛。甲要告丙就一定是拒絕。

不動產善意取得不要求無重大過失，單純善意就夠（登記公信力強）；動產要善意且無重大過失。

12繼承到假登記的地，和租到假屋主的房

變形一：甲與乙通謀虛偽把 A 地登記在乙名下，乙過世，善意的兒子丙辦了繼承登記；地一直是甲在用。變形二：甲與乙通謀虛偽過戶並交付 A 屋，乙把房子租給善意的丙並交付。甲都想要回來。

丙繼承到地了嗎？甲用 §767 哪一段？租房子的丙能不能「善意取得」房子？

  • 變形一：繼承人丙（不要寫「乙丙間法律行為」——繼承是法律事實，倒扣）
    • §1148 繼承？乙沒有 A → 繼承不到
    • §759-1 II 善意取得？須「依法律行為」→ 繼承 ✗
    • §87 I 但書？目的性限縮：第三人限於因法律行為交易安全受影響者 → 繼承人 ✗
    • 甲仍是所有人 → 丙沒占有（地是甲在用）→ 不用前段 → 丙「不是所有人卻登記為所有人」＝法律上妨害 → §767 I 中段請求塗銷
變形二 ✗ 寫法：乙交屋給丙＝無權處分 → 丙善意取得 → 丙變屋主
租房子租一租變屋主？交易安全不會保護到送你房子
錯在第一句：乙丙只有租賃（債權契約）＋履行的交付 → 根本沒有處分行為 → 沒有無權處分 → 沒有善意取得
規則

繼承人取得了登記外觀，卻享受不到任何跟「善意」有關的保護——因為他沒有交易安全要被保護。這是 §87 裡很特別的存在。

變形二丙真正要做的是抗辯甲不是屋主：主張甲乙行為有效、乙才是所有人，乙來告我我用租約擋。於是問題變成：甲能不能用「通謀無效」對抗善意的承租人丙？丙沒取得物權，算不算但書的「善意第三人」？王澤鑑、陳聰富、林誠二看法不同——下堂從這裡接。

陷阱

§767 I 三段分清楚：前段返還占有、中段除去妨害（含法律上妨害＝塗銷登記）、後段防止妨害之虞。地是自己在用、只是登記錯人 → 用中段。
