# 民法26 筆記：不完全給付之體系與瑕疵給付之效果（§227 I）

## 體系：兩條條文，兩種類型
- **瑕疵給付**（§227 I）＝**瑕疵損害**：給付本身有問題
- **加害給付**（§227 II）＝**瑕疵結果損害**：給付以外的其他損害（見筆記-06）
- 選擇題可能用「瑕疵損害／瑕疵結果損害」的用語，是同一組概念，一個從給付看、一個從損害看

## 要件（§227 I）：
- **可歸責於債務人**
- **不完全給付**：有提出給付，但不合債之本旨（字幕作「債之本質」）
  - 給付不能、給付遲延：債權人**什麼都沒拿到**（一個是不能提出，一個是能提出還沒提出）
  - 不完全給付：債權人**拿到了一部分或有瑕疵的東西**
  - 不完全給付 ≠ 完全不給付

## 效果：條文只說「依給付遲延或給付不能之規定」
- §227 I 沒有寫損害賠償或解除契約，依立法理由分兩條路：
- **能補正** → 準用**給付遲延**
  - 補正**有實益**：命其補正＋請求補正遲延的損害（§231 I）
    - 命補正、經催告仍不補正 → 依 **§254** 解除契約
  - 補正**無實益**：拒絕補正＋請求不履行之損害賠償（§232）；也可以直接解約，不必再催告（§255 的概念）
- **不能補正** → 準用**給付不能**：§226 損害賠償、§256 解除契約

## 解約的隱藏限制：須契約目的不達
- 不完全給付時債權人已拿到一部分，解約要符合**誠信原則**（§148 II）
- 須欠缺部分導致**契約目的不達**才能解約，否則以損害賠償為主，硬要解約是解除權濫用
  - 例：約定 100 公斤茶葉，已交 60 公斤
  - 例：買屋漏水，催告修繕，修了幾次仍未修好，可否直接解約 → 老師引最高法院判決說明（此段字幕 00:38:17～00:40:00 斷續缺漏，判決字號未錄到）
- 可解約的情形：無法補正致契約目的不達；命補正而不補正致目的不達；補正已無實益

## 寫考卷的提醒：
- 不要寫「依 §227 I 請求損害賠償」「依 §227 I 解除契約」→ 論證跳躍
- 要寫「依 §227 I，準用給付遲延（或不能）之規定，依 §2XX 請求……」
- 先交代**可否補正、補正有無實益**，再決定接哪一條
- 也要說清楚「不合債之本旨」是哪一種義務違反（見筆記-04）

## 📖 法條原文速查

> **§227**　I 因可歸責於債務人之事由，致為**不完全給付**者，債權人得**依關於給付遲延或給付不能之規定**行使其權利。II 因不完全給付而生**前項以外之損害**者，債權人並得請求賠償。

> **§231 I**　債務人遲延者，債權人得請求其賠償因遲延而生之損害。

> **§232**　遲延後之給付，於債權人無利益者，債權人得拒絕其給付，並得請求賠償因不履行而生之損害。

> **§254**　契約當事人之一方遲延給付者，他方當事人得定相當期限催告其履行，如於期限內不履行時，得解除其契約。

> **§256**　債權人於有第二百二十六條之情形時，得解除其契約。

> **§148 II**　行使權利，履行義務，應依**誠實及信用**方法。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§227 I 是否以可歸責為要件？」 | **是**，不可歸責只能走瑕疵擔保 |
| 「不完全給付能補正時，準用何種規定？」 | **給付遲延** |
| 「不完全給付不能補正時？」 | 準用**給付不能**（§226、§256） |
| 「補正有實益，經催告仍不補正？」 | 得依 §254 解約 |
| 「已受領部分給付，可否隨時解約？」 | 須**契約目的不達**，否則違反誠信原則 |
| 「瑕疵結果損害指的是？」 | 加害給付（§227 II） |

## 效果流程

```
可歸責之不完全給付（§227 I）
├── 能補正 → 準用遲延
│   ├── 補正有實益 → 命補正＋§231 I 遲延損害
│   │                └── 催告仍不補正 → §254 解約
│   └── 補正無實益 → 拒絕補正＋§232 不履行損害／直接解約
└── 不能補正 → 準用不能 → §226 損害賠償、§256 解約
※ 解約一律須達契約目的不達（誠信原則）
```
