# 民法28 筆記：解除權因不能返還而消滅與解除契約之效果（§262、§259至§263）

## 體系定位：
- 解除權的消滅有兩條：**§257 催告**（見民法27-筆記-12）、**§262 不能返還**
- §262 要和 **§259 ⑥** 一起看，兩條處理的都是「不能回復原狀」
- 判斷順序：先問不能回復原狀發生在**解約前**還是**解約後**

## 解約前就不能返還：
- **可歸責於解除權人** → §262 解除權**消滅**，根本不能解約
  - 「解除權消滅」的意思就是還沒行使就沒了
  - 加工、改造使給付物變更種類，也一樣消滅
- **不可歸責於解除權人** → 無 §262 適用，仍可解約；效果依 **§259 ⑥ 償還價額**

## 解約後才不能返還：
- 例：甲賣乙瑕疵車，乙解約後，車被第三人放火燒毀
- 解約後依 §259 ① 雙方負回復原狀義務，這也是一種給付 → 不能返還＝**回復原狀義務的給付不能**
- 依給付不能法則處理（**89 台上 539**）：
  - 雙方不可歸責 → §225 I 免返還；他方依 §266 也免返還價金
  - 可歸責於他方 → §225 I ＋ §267
  - 可歸責於返還義務人 → §226 損害賠償
- **考試陷阱**：§259 序文寫「契約解除**時**」，⑥ 只管解除時已不能返還；解約**後**才不能返還與 §259 ⑥ 無關

## 解除契約之效果（§259～§261）：
- 案例：甲賣乙 A 車，市價 80 萬元、價金 70 萬元，乙已付款；因可歸責於甲致給付不能
  - 乙依 §226 請求履行利益（差額說）**10 萬元**
  - 乙依 §256 解約，依 §259 ② 請求返還 **70 萬元**（車未交付，沒有 ① 的問題）
  - §260：解除不妨礙損害賠償 → 採**清算說**，契約不溯及消滅，§226 的 10 萬元仍可請求（見民法25-筆記-05、06）
- 提醒：**不是每個契約都有履行利益**，對甲而言這是虧本契約
- §261：因解約互負的回復原狀義務，**準用 §264～§267**（同時履行抗辯、不安抗辯、危險負擔）
  - 例：瑕疵車依 §359 解約，乙依 §259 ② 請求返還價金、甲依 §259 ① 請求返還車 → 可主張同時履行抗辯
  - 為何要準用：§264 是「因契約」互負，這裡是「因**解約**」互負，性質類似

## §263 終止的準用：
- §263 準用 **§258 及 §260**，是「及」不是「至」→ **§259 不在準用之列**
- 理由：終止使契約**向後**失效，終止前的法律關係仍有效，沒有回復原狀的問題

## 📖 法條原文速查

> **§262**　有解除權人，因**可歸責於自己之事由**，致其所受領之給付物有毀損、滅失或其他情形不能返還者，**解除權消滅**；因加工或改造，將所受領之給付物變其種類者亦同。

> **§259**　**契約解除時**，當事人雙方回復原狀之義務，除法律另有規定或契約另有訂定外，依左列之規定：一、由他方所受領之給付物，應返還之。二、受領之給付為金錢者，應附加自受領時起之利息償還之。……六、應返還之物有毀損、滅失或因其他事由，致不能返還者，應**償還其價額**。

> **§260**　解除權之行使，不妨礙損害賠償之請求。

> **§261**　當事人因契約解除而生之相互義務，準用第二百六十四條至第二百六十七條之規定。

> **§263**　第二百五十八條**及**第二百六十條之規定，於當事人依法律之規定終止契約者準用之。

## 📋 實務見解速查

> **89 台上 539**（講義 521 頁註 831）：契約解除後始發生不能返還之情形，應適用給付不能之規定：不可歸責於雙方 → §225、§266；可歸責於他方 → §225 I、§267；可歸責於受領人 → §226。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「解除權人解約前因過失毀損受領物，仍可解約？」 | **不可**，§262 解除權消滅 |
| 「解約前不可歸責於解除權人而滅失？」 | 仍可解約，依 **§259 ⑥ 償還價額** |
| 「解約後標的物才滅失，適用 §259 ⑥？」 | **否**，依給付不能法則（89 台上 539） |
| 「解除契約後仍得請求 §226 損害賠償的理論？」 | **清算說**（§260） |
| 「§263 終止準用哪些條文？」 | §258 **及** §260，**不含 §259** |
| 「因解約互負返還義務可否同時履行抗辯？」 | 可以，§261 準用 §264 |

## 不能回復原狀的處理

```
不能回復原狀
├── 解約前
│   ├── 可歸責解除權人 → §262 解除權消滅
│   └── 不可歸責解除權人 → 可解約 → §259 ⑥ 償還價額
└── 解約後（§259 ① 義務之給付不能，89 台上 539）
    ├── 雙方不可歸責 → §225 I ＋ §266
    ├── 可歸責他方 → §225 I ＋ §267
    └── 可歸責返還義務人 → §226
```
