# 民法16 筆記：§184II違反保護他人之法律

## 推定過失：
- 被害人只要證明：行為、損害、因果關係、**違反保護他人之法律**
- 過失由立法者推定，行為人（**被告**）須自行證明無過失才能免責
- 選擇題常問「某要件由誰舉證」；後面 §187、§188、§190、§191、§191-1～§191-3 也有推定

## 「保護他人之法律」三個重點：
- ①須以**保護私益**為目的，不能純保護公益
- ②是否須該法律**本身沒有損害賠償規定**？兩說
- ③請求之人須是**該法律所保護的「他人」**（條文兩個「他人」指同一人）

## 違建案（重點①）：
- 甲未請領建照蓋違建，施工毀損隔壁乙屋 → 乙能否依 §184 II 請求？
- 肯定說：建築法規除行政管制外，也保護鄰屋與人民安全 → 有私益目的 ✓
- 否定說：請領建照純屬**行政管制**，與私益無關 → ✗；實務兩說都有

## 110 年律師考題（重點③）：
- 乙違反交通法規撞傷甲；甲是 A 公司負責人，住院期間 A 公司無法如期發表專利而受損
- A 公司之損失是純粹經濟上損失 → 前段 ✗
- 交通法規保護**用路人**的生命、身體、健康、財產；A 公司不是用路人 → 非受保護之他人 → §184 II ✗

## 📖 法條原文速查

> **民法 §184 II**　**違反保護他人之法律**，致生損害於他人者，負賠償責任。但能證明其行為**無過失**者，不在此限。
> （字幕中老師口述為「加損害於他人者，亦同」，與現行條文用語不同，以六法為準）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「依 §184 II 請求時，行為人之過失由何人舉證？」 | **行為人（被告）** 證明自己無過失；條文採**推定過失** |
| 「純粹以保護公益為目的之法律，是否屬保護他人之法律？」 | **否**，須以**保護私益**為目的 |
| 「未請領建照施工致鄰屋受損，得否依 §184 II 請求？」 | 實務**肯否兩說**：建築法規兼保護他人安全（肯）／純行政管制（否） |
| 「違反交通法規撞傷公司負責人，致公司營業受損，公司得否依 §184 II 請求？」 | **否**。交通法規保護**用路人**，公司非該法律所保護之他人（110 年律師考過） |
| 「特別法已有損害賠償規定（如公平交易法），是否仍得依 §184 II 請求？」 | 兩說：**橋樑說**認應依特別規定；反對說認條文未要求「無其他賠償依據」 |

## 一、§184 II 的定位：從違反法律到損害賠償的橋樑

```
某法律要求行為人做什麼（例：道路交通管理法規）
   │ 但只規定行政罰，沒有民事賠償規定
   ↓
§184 II（橋樑）
   ↓
損害賠償
```

## 二、重點②：法律本身已有賠償規定時

| | 須無其他賠償依據（橋樑說） | 不須（文義說） |
|---|---|---|
| 理由 | §184 II 是違反法律與損害賠償間的橋樑；已有直達路徑就不必走橋 | 條文只要求「違反保護他人之法律」，沒有這個要件 |
| 例 | 公平交易法（字幕作 §29、§30）、律師法已有賠償規定 → 依特別規定 | 仍可依 §184 II |

## 三、110 年律師考題涵攝

| 要點 | 涵攝 |
|---|---|
| ①保護私益？ | 交通法規以保護私益為目的 ✓ |
| ②無其他賠償依據？ | 交通法規無民事賠償規定 ✓ |
| ③A 公司是受保護之他人？ | 交通法規保護用路人之生命身體健康財產；A 公司非用路人 ✗ |
| 結論 | A 公司不得依 §184 II 向乙請求 |
