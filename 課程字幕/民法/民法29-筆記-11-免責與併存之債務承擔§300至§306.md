# 民法29 筆記：免責與併存之債務承擔（§300至§306）

## 重點範圍：
- 條文 §300～§306；要看懂的是 **§300、§301**（選擇題超愛考，只差一個字）
- §304（債務承擔對擔保的影響）與 §295 一樣，留到**抵押權**再講

## §300 第三人與「債權人」訂約：
- 甲對乙有 A 債權；**甲（債權人）與丙**約定由丙承擔乙的債務
- **不需要乙同意**：有人願意替債務人還錢，債務人同不同意沒有差別
- 債務於**契約成立時**移轉於丙

## §301 第三人與「債務人」訂約：
- **乙（債務人）與丙**約定由丙承擔
- 須經**債權人甲承認**，否則對甲不生效力
- 理由：債權人要確認新債務人有沒有資力
  - 不然債務人隨便找一個無資力的人、請他吃個便當就把債務轉出去，世上就沒人欠錢了

## 甲不承認時：
- 對甲不生效力 → 對甲而言，債務人**仍是乙**，甲照樣向乙請求
- 乙丙之間：債務承擔不生效力，但轉為**履行承擔**，契約本身仍有效
  - 乙仍可請求丙**向甲清償**
- §302 的佐證：
  - I 乙或丙可定相當期限**催告**甲確答，逾期不確答，**視為拒絕**承認
  - II 甲拒絕承認時，乙或丙**得撤銷**承擔契約
  - 能撤銷，代表契約**有效**（無效就不必撤銷）
  - 丙不願在甲已拒絕後還被乙要求代為清償，可以撤銷脫身

## 免責與併存：
| | 免責的債務承擔 | 併存的債務承擔 |
|---|---|---|
| 條文 | §300～§304 | §305、§306 |
| 原債務人 | **脫離**，只剩丙是債務人 | **不脫離**，乙丙都是債務人 |
| 典型 | 第三人承擔 | 概括承受資產負債、企業合併 |

## §305、§306：
- §305 I：概括承受他人財產或營業的資產及負債，對債權人**通知或公告**後發生承擔效力
- §305 II：原債務人在**兩年內**與承擔人**連帶**負責
  - 到期債權：自通知或公告時起算
  - 未到期債權：自到期時起算
- §306：營業合併互相承受資產負債，與概括承受相同；合併後的新營業對各營業的債務負責

## 📖 法條原文速查

> **§300**　第三人與**債權人**訂立契約承擔債務人之債務者，其債務於**契約成立時**，移轉於該第三人。

> **§301**　第三人與**債務人**訂立契約承擔其債務者，非經**債權人承認**，對於債權人不生效力。

> **§302**
> I 前條債務人或承擔人，得定相當期限，催告債權人於該期限內確答是否承認，如逾期不為確答者，**視為拒絕承認**。
> II 債權人拒絕承認時，債務人或承擔人得**撤銷**其承擔之契約。

> **§305**
> I 就他人之財產或營業，概括承受其資產及負債者，因對於債權人為承受之**通知或公告**，而生承擔債務之效力。
> II 前項情形，債務人關於到期之債權，自通知或公告時起，未到期之債權，自到期時起，**二年以內**，與承擔人**連帶**負其責任。

> **§306**　營業與他營業合併，而互相承受其資產及負債者，與前條之概括承受同；其合併之新營業，對於各營業之債務，負其責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「第三人與債權人訂約承擔債務，須否債務人同意？」 | **不須**；契約成立時移轉（§300） |
| 「第三人與債務人訂約承擔債務？」 | 須**債權人承認**（§301） |
| 「催告債權人確答，逾期未答？」 | **視為拒絕**承認（§302 I） |
| 「債權人拒絕承認後，乙丙間契約？」 | 仍有效（履行承擔），乙或丙**得撤銷** |
| 「概括承受資產負債後，原債務人責任？」 | **兩年內**與承擔人連帶負責（§305 II） |
| 「§305、§306 屬於何種債務承擔？」 | **併存**的債務承擔 |

## 結構圖

```
甲（債權人）──A 債權──→ 乙（債務人）

§300：甲 ＋ 丙 訂約 → 成立時移轉，乙同意與否無關
§301：乙 ＋ 丙 訂約 → 甲承認才對甲生效
        └ 甲不承認 → 對甲：債務人仍是乙
                     乙丙間：履行承擔有效，丙應向甲清償
                     §302 II：乙或丙得撤銷
```
