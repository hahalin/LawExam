# 民法04 筆記：法定代理人與代理權／同意權的濫用（53 年第 1 次民庭決議）

> 來源：民法04 課程字幕 02:00:04 ~ 02:31:07（本堂結尾；限制行為能力人 §77～§85 下堂續）

---

## 📖 法條原文速查

> **§1086 I**（父母為法定代理人）
> 父母為其未成年子女之法定代理人。

> **§1098 I**（監護人為法定代理人）
> 監護人於監護權限內，為受監護人之法定代理人。
> **§1113**　成年人之監護，除本節有規定者外，準用關於未成年人監護之規定。→ 受監護宣告人之監護人為法代

> **§1088 II**（特有財產之使用收益與處分）
> 父母對於未成年子女之特有財產，有使用、收益之權。但**非為子女之利益，不得處分**之。
> → 文義只管「特有財產的處分」；代理權、同意權、承認權的濫用都**類推**這條

> **§71**（違反強行規定無效）→ 無效說的依據
> **§170 I**（無權代理效力未定）→ 效力未定說的依據
> **§77**（限制行為能力人應得允許）、**§79**（未得允許之契約效力未定）、**§81 I**（限制原因消滅後自己承認，與法代承認同一效力）

## 📋 實務見解速查

> **最高法院 53 年度第 1 次民事庭會議決議**：父母以其未成年子女之名義承擔債務，或以其未成年子女之財產提供擔保，若非為子女之利益，而以子女之名義承擔他人債務或為他人提供擔保，依 §1088、限定繼承之立法意旨及公平誠實原則，**除子女於成年後自願承認外，不能對其子女生效**。但子女之財產如係由父母以其子女之名義購置，則應**推定**父母係提出財產為子女作長期經營，父母以子女名義置業後，在**該價額限度內**，以子女名義承擔債務或提供擔保，**不能概為無效**。
> → 建議查閱決議全文

> **最高法院 104 年度台上字第 839 號判決**（講義註 30）：將 53 年決議的「價額限度內」擴張到父母代理子女**訂立保證契約**。

> **臺灣高等法院 105 年法律座談會民事類第 15 號**（講義 123 頁註 31）：法定代理人**同意**（允許）子女為不利行為，類推 §1088 II 但書，該允許無效；契約類推 §170 效力未定，待子女成年後自行承認。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「未成年人之法定代理人是誰？」 | 有父母且得行使親權 → **父母**（§1086）；無父母或不能行使親權 → **監護人**（§1098 I）；受監護宣告之人 → 監護人（§1113 準用） |
| 「父母代理 5 歲子女與銀行訂保證契約，效力？」 | 類推 §1088 II 但書：**多數說無效**（§71 強行規定）；少數說／53 年決議：**效力未定**（無權代理），子女成年後得承認 |
| 「無效說與效力未定說的實益？」 | 子女成年後**自願承認**能否使之生效：無效說 ✗（須重新訂約）；效力未定說 ✓ |
| 「父母先將 800 萬股票置於子女名下，再以子女為 1000 萬債務之保證人？」 | 實務：**800 萬範圍內不概為無效**；超過部分回到原則 |
| 「父母不代理，改『同意』16 歲子女自己與銀行訂保證契約？」 | 同意顯不利於子女 → 類推 §1088 II 但書 → **同意無效** → 契約未經允許 → 效力未定；實務類推 §170 待子女成年自己承認（老師：用 §81 I 即可） |

## 一、法定代理人是誰

```
未成年人
├── 有父母、父母得行使親權 → 父母（§1086 I）
└── 無父母／父母不能行使親權 → 法院選定監護人 → 監護人（§1098 I）
受監護宣告之人 → 監護人（§1113 準用 §1098 I）
```

## 二、代理權濫用：類推 §1088 II 但書

#### 事實
乙是 5 歲甲的法定代理人。乙向丙銀行借 500 萬，找不到保證人，銀行說「你小孩五歲也是人」。乙代理甲與丙訂立保證契約。

#### 為什麼是「類推」
- §1088 II 但書文義只管「特有財產的**處分**」，沒寫代理。
- 但 §1086～§1088 設法定代理人制度的目的就是**保護未成年人**；代理權濫用使子女受不利益，目的相同 → 類推。

#### 類推之後效果如何：兩說

| | 無效說（多數） | 效力未定說（53 年決議、林秀雄） |
|---|---|---|
| §1088 II 但書的性質 | **強行規定** → 違反依 §71 無效 | 代理權／處分權的**內部限制** → 對外回歸民總：無權代理（§170）或無權處分，效力未定 |
| 子女成年後自願承認 | **沒用**，自始無效，要重新訂約 | **有用**，承認即生效 |
| 林秀雄的理由 | — | 這條是內部限制，不必當強行規定；對外直接用無權代理／無權處分處理即可 |

## 三、例外：父母為子女置產，在價額範圍內不概為無效

#### 事實
甲 10 歲，乙先把名下市價 800 萬的股票放到甲名下，再向丙借 1000 萬，由甲擔任保證人。

#### 實務（53 年決議）
```
父母以子女名義購置財產 → 推定是為子女長期經營
→ 在該財產價額（800 萬）範圍內，以子女名義承擔債務／提供擔保 → 不概為無效
→ 超過 800 萬的部分 → 回到原則（無效說 vs 效力未定說）
→ 乙不還錢時，甲最多幫還 800 萬
```
- 理由：那筆錢本來就是爸媽的，範圍內讓小孩出來扛對小孩沒真的不利。

#### 學說批評（講義 122～123 頁；字幕音譯「李林林老師」，姓名請查講義）
1. 「父母把財產放子女名下＝為子女長期經營」這個**推定沒有根據**——可能是單純贈與、為出國讀書準備。用推定的動機再推出「不概為無效」，推論不嚴謹。
2. 目的若是**避免詐害債權人**，要件應更嚴謹（例如父母有詐害故意），而非一律推定。
3. 53 年決議講的是「以子女**財產**提供擔保」（拿 800 萬股票設質）；104 台上 839 擴張到「代理子女訂**保證契約**」，超出決議射程，保證對子女顯然不利，應回歸無權代理效力未定。

## 四、同意權濫用：山不轉路轉

#### 事實
甲 16 歲。母親乙帶甲到丙銀行，銀行攤開保證契約書，乙說「我同意你自己決定」。甲簽名擔任乙的保證人。

#### 分析
```
這不是代理（乙沒代理甲），是 §77 的「允許」→ 53 年決議管不到？
學者（字幕音譯「黃師存老師」，姓名請查講義）：未成年人判斷能力低、礙於父母壓力不可能不簽
    → 法定代理制度目的在保護未成年人 → 允許顯不利於子女時應受限制（目的性限縮）
    → 類推 §1088 II 但書 → 【允許無效】
允許無效 → 契約等於未經允許 → §79 效力未定
    → 誰承認？乙承認不利於甲，不行
    → 實務（高院 105 年座談會第 15 號）：類推 §170，等甲成年後自己承認或拒絕
    → 老師：不必類推，§81 I 本來就規定限制原因消滅後子女得自己承認，沒有法律漏洞
```

## 五、總結：§1088 II 但書管三件事

```
父母的 代理權 ／ 同意權（允許）／ 承認權
→ 只要顯不利於子女，都類推 §1088 II 但書加以限制
→ 目的只有一個：保護未成年人
```
