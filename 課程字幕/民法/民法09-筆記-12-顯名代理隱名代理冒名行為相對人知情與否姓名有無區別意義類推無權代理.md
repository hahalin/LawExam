# 民法09 筆記：顯名代理、隱名代理、冒名行為——隱名看相對人知不知情，冒名看姓名有無區別意義（重不重人的資格）

> 來源：民法09 課程字幕 02:28:01 ~ 02:40:54（本堂結尾；下堂 §104 代理人須非無行為能力人）

---

## 📖 法條原文速查

> **§103 I**　代理人於代理權限內，以**本人名義**所為之意思表示，直接對本人發生效力。
> **§170 I**（無權代理）無代理權人以代理人之名義所為之法律行為，非經本人承認，對於本人不生效力。→ 冒名行為著重人的資格時**類推**

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「顯名代理？」 | 乙有代理權，以**甲的名義**（契約寫甲、註明代理人乙）為意思表示 → 效果直接及於甲 → **直接代理** |
| 「隱名代理？」 | 乙**有代理權**、也有代理甲的意思，但用**自己的名義** → 看相對人丙知不知情 |
| 「隱名代理，丙不知情？」 | 法律關係在**乙丙間**，間接對甲發生效力（**間接代理**）；甲乙間依內部關係（委任）處理 |
| 「隱名代理，丙知情？」 | 丙知道乙在代理甲、只是寫錯名字 → 法律關係在**甲丙間**（幼兒園報名表爸爸寫自己名字，老師知道是幫兒子報 → 去遠足的是兒子） |
| 「冒名行為？」 | 乙**無代理權**、冒用甲的名字 → 看該法律行為**重不重人的資格**（姓名有無區別意義） |
| 「冒名買飲料（不重資格）？」 | 姓名只是代稱 → 法律關係在**乙丙間** |
| 「冒名向銀行貸款（重資格）？」 | 丙沒有借給乙的意思、甲也沒有借錢的意思 → 法律無規定 → **類推無權代理** → 在甲丙間**效力未定** |
| 「隱名代理與冒名行為的判斷標準？」 | 隱名：**相對人知不知情**；冒名：**姓名有無區別意義**。選擇題會混在一起 |
| 「甲委託乙代購預售屋，乙以自己名義買下自住，房價暴漲？」 | 乙沒有代理甲的意思、用自己名義 → 不是代理，房子是乙的；乙對甲頂多債務不履行 |

---

## 一、三種情形
```
乙以「本人名義」為意思表示 → 顯名代理（原則）：合約寫甲方＝甲，括弧代理人乙 → 效果直接及於甲（直接代理）
乙有代理權但用自己名義 → 隱名代理
乙沒有代理權卻用甲的名字 → 冒名行為
```

## 二、隱名代理：前提是有代理權＋有代理的意思
```
甲授權乙（或法定代理），乙有代理甲的意思，但把甲的名字藏起來、用自己名義締約
丙不知情 → 對丙而言契約當事人是乙 → 法律關係乙丙間，間接對甲發生效力（間接代理）
             甲乙間依委任等內部關係處理
丙知情   → 丙知道乙在代理甲，只是名字寫錯 → 法律關係甲丙間
```
- 幼兒園課外教學報名表，爸爸在姓名欄寫自己名字 → 老師打電話「請問是星佑寶貝的媽媽嗎」→ 老師若知道是爸爸幫兒子報名 → 直接對兒子生效，去遠足的是兒子不是爸爸。
- 對照：甲人在美國拜託乙代購預售屋，乙發現很讚、剩最後一間，**用自己名義自己買**，房價從七八百萬漲到一千六七百萬 → 乙沒有代理甲的意思 → 不是隱名代理，房子是乙的；乙對甲頂多債務不履行。

## 三、冒名行為：看法律行為重不重人的資格
| | 不重人的資格（姓名無區別意義） | 重人的資格（姓名有區別意義） |
|---|---|---|
| 例 | 去 50 嵐買飲料說「我是金城武」 | 冒郭台銘之名向銀行貸款 30 億 |
| 法律關係 | **乙丙間**：姓名只是代稱，不影響效果 | 不能在乙丙間（丙沒有借給乙的意思）、也不能直接在甲丙間（甲沒有借錢的意思）→ 法無規定 → **類推無權代理 §170** → 甲丙間效力未定 |

## 四、兩個判斷標準不要混
| | 判斷標準 | 法律關係 |
|---|---|---|
| 隱名代理（有代理權） | 相對人**知不知情** | 不知 → 乙丙；知 → 甲丙 |
| 冒名行為（無代理權） | 姓名**有無區別意義** | 無 → 乙丙；有 → 類推無權代理，甲丙效力未定 |

- 選擇題陷阱：「隱名代理重人的資格時直接對甲發生效力」→ 錯，隱名代理看的是知不知情。
