# 民法16 筆記：過失判斷標準與漢德公式

## 過失的句型：
- 應注意、能注意而不注意（與刑法同）

## 兩種切入：
- **注意義務違反說**（過失客觀化）：先找客觀上的注意義務，違反即有過失；例：未注意車前狀況、未與前車保持安全距離
  - 優點：具體、方便論證；批評：過失本是**主觀**要件，應回歸行為人主觀
- **預見可能性說**：行為人對損害發生有預見可能，卻未採取迴避、避免或降低發生機率的措施 → 有過失
- 老師：兩者不是對立，而是**相輔相成**，可從客觀注意義務＋主觀預見可能性綜合論述；考試多屬事實認定，很少考

## 漢德公式（法律經濟學）：
- 以防範成本 B、損害發生機率 P、損害大小 L 判斷
- **B ＞ P×L** → 不防範**無過失**；**B ＜ P×L** → 不防範**有過失**
- 像是經濟學版的期待可能性：不能期待理性的人花巨額成本防範極少的損害
- Hand 是法官的名字（Learned Hand），有書直譯成「手的公式」
- 研究所考過（臺大法研所 98 或 99 年，年份字幕不確定）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「以行為人是否違反客觀注意義務認定過失，此稱為何？」 | **過失客觀化**（注意義務違反說）；批評：過失為主觀要件 |
| 「依漢德公式，防範成本大於損害乘以發生機率時，行為人未防範者？」 | **無過失**（B ＞ P×L） |
| 「依漢德公式，防範成本小於損害乘以發生機率而未防範者？」 | **有過失**（B ＜ P×L） |
| 「罕見疾病發生率極低、不影響生命、檢出需高成本精密檢查，醫師未檢查是否有過失？」 | 損害小、機率低、成本高 → B ＞ P×L → **無過失** |
| 「注意義務違反說與預見可能性說之關係？」 | 老師：可**相輔相成**、綜合判斷，非互斥 |

## 一、過失判斷三工具

```
過失（應注意、能注意而不注意）
├── 注意義務違反說：客觀有無注意義務 → 有無違反
├── 預見可能性說：能否預見 → 有無迴避／降低損害
└── 漢德公式：B（防範成本） vs P（機率）× L（損害）
      ├─ B ＞ PL → 不做無過失
      └─ B ＜ PL → 不做有過失
```

## 二、案例：顏面神經瘤案（臺大法研所考題）

#### 事實
1. 某人罹患罕見疾病（字幕作「顏面神經瘤」），全球發生率極低
2. 該病對生命沒有影響
3. 要發現此病必須做許多精密檢查，成本很高
4. 醫師先前未做精密檢查，直到某次開刀才發現；病人主張多挨一刀，請求賠償

#### 分析
- 用注意義務說、預見可能性說都很難找到涵攝的著力點
- 題目其實已給齊漢德公式三要素：
  - B 成本：須多項精密檢查 → **高**
  - P 機率：極低
  - L 損害：不影響生命 → **小**
- B ＞ P×L → 未檢查**不構成過失**

#### 類例
- 工廠是否設置污水淨化設備、廢棄物處理設備：比較設置成本與可防止的損害，決定不設置是否構成過失

## 三、答題提醒

- 題目出現「成本」「機率」「損害大小」三種線索時，就是在提示用漢德公式
- 一般題目只寫「甲因過失撞乙」或給「開車打手機、超速」，直接涵攝即可
