# 民法10 筆記：§110 無權代理人之責任——四個爭點：① 前提：本人**未承認**（承認就無損害）② 無權代理人負**無過失責任**（類似契約的補充責任；受監護宣告人授權案）；相對人**通說只須善意**（文義＋體系解釋，有過失以 §217 減輕），少數說須善意無過失（避免有過失者向無過失者求償）③ 無權代理人須有**行為能力**（隱藏要件）④ 時效：實務 §125 十五年；學說依原法律行為個案認定（租金 §126 五年例）。下堂：損害賠償範圍、與 §107／§169 之適用關係

> 來源：民法10 課程字幕 02:17:55 ~ 02:32:58（講義 273 頁①②、274 頁③④、277 頁⑤⑥；本堂結尾）

## 📖 法條原文速查

> **§110**　無代理權人，以他人之代理人名義所為之法律行為，對於**善意**之相對人，負損害賠償之責。
> **§107 但書**　但第三人因過失而不知其事實者，不在此限。／**§169 但書**　但第三人明知其無代理權或可得而知者，不在此限。
> **§217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。
> **§125**　請求權，因十五年間不行使而消滅。但法律所定期間較短者，依其規定。
> **§126**　利息、紅利、租金、贍養費、退職金及其他一年或不及一年之定期給付債權，其各期給付請求權，因五年間不行使而消滅。
> **§75**　無行為能力人之意思表示，無效；雖非無行為能力人，而其意思表示，係在無意識或精神錯亂中所為者亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「本人已承認，相對人得否依 §110 向無權代理人求償？」 | **不得**。法條沒寫，但效果是「損害賠償」：本人承認 → 契約生效 → 無損害 → 無賠償。大陷阱：先確認本人**未承認**（拒絕或未確答） |
| 「無權代理人須有故意過失？」 | **不須**（無過失責任）。文義：§110 看一百遍都沒有「過失」兩字。法理：這不是侵權行為的損害賠償，是**類似契約**的**補充責任**——契約因你無權代理而不生效，你就要負責 |
| 「受監護宣告人甲（看起來正常）授權乙，乙不知而代理，事後發現授權無效（§75）→ 乙成為無權代理人，要不要賠？」 | **要**。只看有無無權代理，不看有無過失 |
| 「相對人須善意無過失？」 | **通說：善意即可**。文義：沒寫過失；體系解釋：§107、§169 都明文排除有過失者，§110 沒寫 → 立法者有意不要求；有過失 → §217 與有過失減輕即可。**少數說**（字幕音譯「楊家源」老師，建議查閱）：應限縮為善意**無過失**，否則有過失的丙可向無過失的乙求償，體系失衡 |
| 「未成年人為無權代理人，相對人得否依 §110 求償？」 | **不得**。類似契約責任以有締約能力為前提；且民法對未成年人保護優於交易安全 → 無權代理人須有**行為能力**（隱藏構成要件） |
| 「§110 之消滅時效？」 | **實務：§125 十五年**（法無特別規定）。**學說：依原法律行為個案認定**——§110 是補充責任，補充包不能比原本那包大：乙無權代理甲向丙承租房屋，租約有效時租金請求權 §126 五年，不生效後對乙求償反而 15 年 → 不合理；立法者是故意不規定 |

## 一、§110 的定位

```
本人拒絕承認 → 甲丙契約不生效力 → 善意丙的損失 ＝ 原本契約能享受的利益
→ §110 讓無權代理人乙填補這個損失 → 類似契約的「補充責任」（補充本人不承認的情況）
→ 不是侵權責任
```

## 二、爭點 ①：前提是本人未承認

- 承認 → 契約有效 → 沒有損害 → 沒有賠償。考試先看本人有沒有承認。

## 三、爭點 ②：故意過失

| 誰 | 要不要過失 | 理由 |
|---|---|---|
| 無權代理人乙 | **不要**（無過失責任） | 文義無「過失」；類似契約的補充責任，只問有沒有無權代理。例：受監護宣告人授權，乙好人當到底，事後才知授權無效 → 仍要賠 |
| 相對人丙（通說） | **善意即可**，不須無過失 | 文義；體系解釋（§107、§169 明文要無過失，§110 沒寫）；有過失 → §217 減輕 |
| 相對人丙（少數說） | 善意**且無過失** | 乙無過失責任＋丙有過失仍可求償 → 「你沒錯我有錯但我可以告你」→ 體系失衡 → 限縮解釋 |

```
少數說的例：甲授權時無意識精神錯亂（§75 後段）→ 授權無效 → 乙（看不出來、無過失）變無權代理
            丙善意但有過失 → 多數說：丙可對乙求償 → 有過失者告無過失者
```

## 四、爭點 ③：無權代理人須有行為能力

- 類似契約的損害賠償 → 前提是有締結契約的能力 → 無行為能力人、限制行為能力人不負 §110 責任。
- 法理：§110 保護交易安全，但民法對未成年人的保護**優於**交易安全。

## 五、爭點 ④：時效

| | 見解 | 理由 |
|---|---|---|
| 實務 | §125 十五年 | §110 未規定 → 回歸一般時效 |
| 學說 | 依**原法律行為**的時效個案認定 | 補充責任只填補原契約利益，補充包不能比原包大。租屋例：租約有效 → 租金請求權 §126 五年；不生效後對乙求償 15 年 → 無權代理反而讓丙得到更多，不合理。立法者故意不規定 |
