# 民法23 筆記：要約與要約之引誘及要約之拘束力（§154）

## 要約 vs 要約之引誘：
- **要約之引誘**具高度不確定性：只告訴你有這個機會，不代表一定賣你
  - §154 II 但書：**價目表之寄送**不視為要約
  - 例：傳單寫「雞腿便當特價 50 元」，到店說要買，老闆說賣完了 → 不能告債務不履行，契約未成立
- **貨物標定賣價陳列**視為要約（§154 II 本文）
  - 例：超商架上牛奶標 30 元，拿去結帳就是承諾，契約成立，店員不能說不賣

## 要約的拘束力（§154 I 本文）：
- **形式拘束力**：要約發出後，不能任意更改內容（不能說 50 元賣你又改成 60 元）
- **實質拘束力**：對方承諾、契約成立後，要受契約拘束，不能否認契約存在

## 例外：要約不受拘束（§154 I 但書）
- **預先聲明不受拘束**：例如賣地時說「我可能明天就不想賣，要買要快」
- **依其情形或事件性質可認無受拘束之意思**：
  - 例：門口貼紅紙「急屋出租」→ 房東會挑房客，不能認為只要你說要租，契約就成立
  - 租賃著重當事人資格，個案認定

## 爭點：預先聲明不受拘束，承諾後還能反悔嗎？
- 承諾**前**：要約人可以任意更改、撤銷，沒有爭議
- 承諾**後**：
  - **鄭玉波**（早期）：只排除**形式拘束力**；承諾後仍受拘束
  - **孫森焱、邱聰智、林誠二**（多數）：形式、實質拘束力**都排除**；承諾後仍可反悔
- 老師：這是老考點；契約成立這章現在很少考，選擇題可能給幾個要約、承諾讓你判斷契約是否成立，二試機率不高

## 📖 法條原文速查

> **§154**　I 契約之要約人，因要約而受拘束。但要約當時**預先聲明不受拘束**，或依其情形或事件之性質，可認當事人**無受其拘束之意思**者，不在此限。II **貨物標定賣價陳列者，視為要約**。但**價目表之寄送，不視為要約**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「商店標價陳列商品，性質？」 | **視為要約** |
| 「寄送價目表、廣告傳單，性質？」 | **要約之引誘** |
| 「要約發出後能否任意更改內容？」 | **否**，形式拘束力 |
| 「預先聲明不受拘束，承諾後可否反悔？」 | 多數說：**可以**；鄭玉波：不可 |
| 「貼紅紙招租，有人表示承租，契約成立？」 | **未必**，租賃著重人的資格 |

## 比較表

| | 要約 | 要約之引誘 |
|---|---|---|
| 性質 | 意思表示，一經承諾契約成立 | 引誘他人向自己要約 |
| 拘束力 | 有 | 無 |
| 例 | 標價陳列商品 | 價目表、傳單 |
| 對方表示要買 | 承諾 → 契約成立 | 要約 → 待我方承諾 |

## 拘束力圖

```
要約發出 ──── 形式拘束力：不得任意更改 ────→ 承諾、契約成立 ── 實質拘束力：受契約拘束
預先聲明不受拘束：
  鄭玉波：只排除 ←形式→
  多數說：←形式→ 與 ←實質→ 都排除
```
