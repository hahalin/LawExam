# 民法16 筆記：§185II造意幫助與過失造意爭議

## 「視為」：
- 與事實相反的**法律擬制**，立法者為特定目的而設，**不得舉反證推翻**
- 對照：§7 胎兒視為既已出生、§1065 I 非婚生子女經認領視為婚生

## 造意的法律構造：
- 造意≈刑法教唆：製造他人實施侵權行為的意圖
- 丙對乙（行為人）§184 ✓；丙對甲（造意人）：造意不是侵害行為 → 甲不成立 §184 → 也無從 §185 I 前段
- §185 II 把甲**視為共同行為人**，一次補足「行為」與「共同」→ 依 **§185 I 前段**與乙連帶
- 涵攝順序：丙對乙 §184 → 帶出 §185 II → §185 I 前段；**不要**寫甲個別成立 §184

## 過失造意（考點）：
- 最高法院 98 年判決（講義 142 頁，字號請對講義）**肯定**：民事侵權在填補損害，與刑法不同，造意不以故意為必要
- 學說多數**否定**（陳聰富、王澤鑑、游進發、林誠二）：視為效果很強，須有高度非難性 → 限**故意**；否則隨口給意見都可能被拉進連帶

## 幫助：
- 同一爭點：實務承認**過失幫助**，學說不承認
- 為何幫助也要擬制：行為人本已決意，沒借鐵鎚也會自己買 → 幫助與損害之間**因果關係**難證

## 借機車案：
- 甲借機車給 15 歲無照的乙，乙撞傷丙
- 實務：過失幫助 → §185 II → §185 I 前段連帶
- 王澤鑑：借車給無照者本身違反交通管理法規（保護他人之法律）→ 甲自己成立 **§184 II**，甲乙有客觀關聯 → 直接 **§185 I 前段**，不必承認過失幫助

## 📖 法條原文速查

> **民法 §185 II**　造意人及幫助人，**視為**共同行為人。

> **民法 §7**　胎兒以將來非死產者為限，關於其個人利益之保護，**視為**既已出生。

## 📋 實務見解速查

> **最高法院 98 年判決**（講義 142 頁；字號字幕未唸，請對講義）：要旨依課堂講述——民事侵權行為重在填補被害人損害，§185 之造意與刑法不同，**不以故意為必要**，亦得有**過失**之造意；過失造意與第三人之過失侵權相結合，應連帶負責。（原文請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§185 II『視為』共同行為人，得否舉反證推翻？」 | **不得**；視為＝法律擬制 |
| 「造意人應依何條與行為人連帶負責？」 | **§185 II ＋ §185 I 前段**（造意人本身不成立 §184） |
| 「民法上是否承認過失造意？」 | 實務**肯定**（98 年判決）；學說多數**否定**（限故意） |
| 「民法上是否承認過失幫助？」 | 同上：實務肯定、學說否定 |
| 「借機車給無照者肇事，借車人之責任？」 | 實務：過失幫助 → §185 II；王澤鑑：借車人違反保護他人之法律自成立 §184 II → 直接 §185 I 前段 |
| 「單純幫助人為何難以直接依 §184 負責？」 | **因果關係**難證：行為人本已決意，無幫助仍會實施 |

## 一、造意人責任的構造

```
丙 → 乙：§184 ✓
丙 → 甲（造意）：§184 ✗（無侵害行為）
        ↓
§185 II：甲視為共同行為人（補足「行為」＋「共同」）
        ↓
§185 I 前段：甲乙連帶負責
```

## 二、石棉屋頂案（過失造意）

| 步驟 | 內容 |
|---|---|
| 事實 | 乙承攬修繕丙之屋頂，發現嚴重漏水，打電話問甲；甲未看現場，建議用焊接；屋頂為石棉材質（依字幕），焊接致屋頂燒毀 |
| 最高法院 | 甲提供意見未充分求證 → **過失造意** → 與乙連帶 |
| 學說 | 單純給錯意見不具高度非難性；行為自由與權利保護須平衡 → 不應視為共同行為人 |

## 三、學說的處理

| | 故意造意／幫助 | 過失造意／幫助 |
|---|---|---|
| §185 II | ✓ 視為共同行為人 | ✗ |
| 仍可負責嗎 | — | 回到 §185 I 前段：看該行為能否**獨立**成立侵權行為（如 §184 II） |

## 四、法研所考題：父親放任無照女兒開車

- 女兒 21 歲（當時滿 20 歲成年）→ 已成年，**無 §187** 可用
- 爭點：父親借車給無照女兒，要用 §185 II（過失幫助）處理，還是父親本身即為行為人、直接 §185 I 前段
