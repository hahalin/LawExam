# 民法35 筆記：違章建築之原始取得、繼承與拍賣（78年司法院研討結果）

## 什麼是違章建築：
- 無法取得**建築執照** → 完工後無法辦**保存登記** → 也無法辦**移轉登記**
- 常見：山坡地、水源地、頂樓加蓋；不符農舍興建辦法的豪華農舍
| | 實質違建 | 程序違建 |
|---|---|---|
| 意義 | 無法補正，永遠拿不到建照（如蓋在山坡地） | 先蓋後補，符合要件可補辦建照 |
| 討論重點 | **是** | 否，補正後就是合法建物 |

## 核心觀念：起造人取得的是「所有權」：
- 原始取得不以登記為要件（§759 先有效果再登記）
- 起造人完工時取得的是**違建的所有權**，**不是**事實上處分權
- 不能登記只是**不能處分**，不影響已取得的所有權
- 推論：凡是**跟登記無關**的變動方式，違建都一樣發生效果
  - 原始取得 ✓
  - 繼承 ✓
  - 強制執行 ✓

## 繼承違建：
- 甲為 A 違建所有人，甲死亡，乙繼承
- 依 §1148，乙繼承的是 A 違建的**所有權**，不是「只能繼承事實上處分權」
- 乙無法辦繼承登記，所以之後也無法辦移轉登記，但不能因此否認乙繼承所有權

## 拍賣違建（78 年司法院研討結果）：
- 數字例：甲為 A 違建起造人；債權人一聲請拍賣，乙拍定並繳足價金，執行法院發給權利移轉證書
- 依強制執行法 §98 I，乙領得權利移轉證書時即取得 A 違建**所有權**，不用登記
- 甲因此不再是所有人 → 甲的另一債權人（債權人二）**不能**主張違建仍屬甲所有而再聲請查封拍賣
- 執行法院可命該債權人另行查報其他財產
- 注意研討結果用語是「**所有權人**」，不是「事實上處分權人」

## 小結：
```
違建所有權的取得
├── 非因法律行為（原始取得、繼承、強制執行）→ 取得「所有權」，只是不能處分
└── 依法律行為（買賣）→ 無法移轉登記 → 買受人取得什麼？→ 見民法35-筆記-06
```

## 📖 法條原文速查

> **§759**　因繼承、強制執行、徵收、法院之判決或其他非因法律行為，於登記前已取得不動產物權者，應經登記，始得**處分**其物權。

> **§1148 I 本文**　繼承人自繼承開始時，除本法另有規定外，承受被繼承人財產上之一切權利、義務。

> **強制執行法 §98 I**　拍賣之不動產，買受人自領得執行法院所發給權利移轉證書之日起，取得該不動產所有權。→ 建議查閱最新條文

## 📋 實務見解速查

> **78 年司法院研討結果**（出處建議查證）：債務人甲之違章建築，既經法院拍賣由乙承買並取得權利移轉證書，應認乙為該違章建築之**所有權人**，縱不能依法登記，依 §759 亦僅不能處分；甲之另一債權人不得指該違建為甲所有而請求再為查封拍賣，執行法院得命其另行查報。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「違建起造人僅取得事實上處分權？」 | **錯**，原始取得**所有權** |
| 「違建因不能登記，繼承人無法繼承其所有權？」 | **錯**，繼承所有權，只是不能辦繼承登記 |
| 「拍定人取得權利移轉證書後，債務人之其他債權人得再查封該違建？」 | **不得**，已屬拍定人所有 |
| 「違建不能登記，影響其所有權之取得？」 | 非因法律行為不影響，只影響**處分** |
