# 民法05 筆記：原則 §78 §79 與效力未定的三條出路——§80 催告、§82 撤回、§81 成年後承認

> 來源：民法05 課程字幕 01:34:17 ~ 01:56:22

---

## 📖 法條原文速查

> **§78**　限制行為能力人未得法定代理人之允許，所為之**單獨行為**，無效。
> **§79**　限制行為能力人未得法定代理人之允許，所訂立之**契約**，須經法定代理人之承認，始生效力。

> **§80**（相對人之催告權）
> I 前條契約相對人，得定**一個月以上**期限，催告法定代理人，確答是否承認。
> II 於前項期限內，法定代理人不為確答者，**視為拒絕承認**。

> **§81**（限制原因消滅後之承認）
> I 限制行為能力人於**限制原因消滅後**，承認其所訂立之契約者，其承認與法定代理人之承認，有同一效力。
> II 前條規定，於前項情形準用之。

> **§82**（相對人之撤回權）
> 限制行為能力人所訂立之契約，未經承認前，相對人得**撤回**之。但訂立契約時，**知其未得有允許者**，不在此限。

> **§1086 I**　父母為其未成年子女之法定代理人。→ 子女成年，父母就不是法代
> **民法總則施行法 §3-1**
> I 中華民國一百零九年十二月二十五日修正之民法第十二條及第十三條，自一百十二年一月一日施行。
> II 於中華民國一百十二年一月一日前滿十八歲而於同日未滿二十歲者，自同日起為成年。
> III 於中華民國一百十二年一月一日未滿二十歲者，於同日前依法令、行政處分、法院裁判或契約已得享有至二十歲或成年之權利或利益，自同日起，除法律另有規定外，仍得繼續享有該權利或利益至二十歲。
> → III 是緩衝規定：甲乙 100 年離婚時約定給付 5 歲丙扶養費「至成年」，依當時 §13 即至 20 歲；112/1/1 後 18 歲成年，甲仍應給付至丙 20 歲

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「限制行為能力人未經允許之解除、終止、撤銷、拋棄、債務免除、拋棄繼承、授與代理權？」 | **單獨行為 → §78 無效**（但仍先看例外：拋棄全是負債的繼承可能純獲法律上利益） |
| 「未經允許之買賣、贈與、設定抵押權、移轉所有權？」 | **契約（含物權契約）→ §79 效力未定** |
| 「相對人催告，法代逾期不確答？」 | **視為拒絕承認**（§80 II） |
| 「相對人只給法代三天考慮？」 | 王澤鑑：催告仍有效，**自動延為一個月** |
| 「相對人何時得撤回？」 | 未經承認前；且訂約時**不知**未得允許（**善意**）。惡意者只能催告 |
| 「撤回 vs 撤銷？」 | 契約未生效 → **撤回**；已生效 → 撤銷 |
| 「子女成年後自己承認，父母反對？」 | 成年即**限制原因消滅** → §81 子女承認與法代同一效力；父母已非法代，反對**無意義** |
| 「111/11/30 締約時 18 歲（舊法未成年），112/1/1 成年當天承認？」 | 施行法 §3-1 II 當日成年 → §81 承認有效 |

## 一、原則：單獨行為無效、契約效力未定

| 類型 | 定義 | 例 | 效力 |
|------|------|-----|------|
| 單獨行為 | 單方意思表示即生效 | 解除、終止、撤銷、拋棄所有權、拋棄繼承、債務免除、**授與代理權**（有相對人之單獨行為） | **§78 無效** |
| 契約 | 雙方意思表示合致 | 買賣、租賃、贈與（對方要收）、**物權契約**（移轉所有權、設定抵押權——對方要願意當抵押權人） | **§79 效力未定** |

- 回到原則前仍先檢驗例外：拋棄繼承若被繼承人只有負債 → 可能是純獲法律上利益。
- 被授予代理權不是行為（是事實）；授與代理權才是限制行為能力人的單獨行為。

## 二、效力未定怎麼確定：三個角度

```
甲（限制行為能力人）⇄ 乙（相對人）締約；丙＝法代

丙的角度：承認 → 生效；拒絕 → 不生效力
乙的角度：丙不表態怎麼辦？
    ├── §80 催告：定一個月以上期限 → 逾期不確答 → 視為拒絕（準法律行為）
    └── §82 撤回：未經承認前，善意的乙可直接撤回，不用等
甲的角度：未成年 → 無權利；成年後（限制原因消滅）→ §81 自己承認／拒絕，§80、§82 準用
```

### §80 催告期間未滿一個月
- 不是每個人都知道要一個月；老闆說「給你三天考慮」。
- 王澤鑑：**仍為有效催告，自動延為一個月**。理由（目的解釋）：§80 的目的是讓法律關係盡早確定，若解為無效催告就要重新催告，反而讓效力未定狀態拖更久。
- 效果：給三天，法代第 20 天才說要 → 仍在一個月內 → 契約生效。

### §82 撤回的善意要件
- 「訂立契約時知其未得允許者，不在此限」→ 惡意相對人沒有撤回權，只能催告。
- 用語：契約尚未生效 → 撤回；已生效 → 撤銷。

## 三、§81：成年的那一刻，父母功成身退

#### 事實
甲 111/11/30 締約買 8 萬元機車（舊法 20 歲成年，甲 18 歲仍為限制行為能力人，§79 效力未定）。112/1/1 新法施行，甲當天打電話承認；父母反對。

#### 分析
```
112/1/1：民總施行法 §3-1 II → 當日未滿 20 歲者自同日起成年 → 甲瞬間成年
→ 限制原因消滅 → §81 I 甲的承認與法代承認同一效力 → 契約生效
父母反對？→ §1086 父母是「未成年」子女的法代 → 甲成年後父母已非法代 → 無承認權、無代理權 → 反對無意義
（若父母在 111/11/30 反對 → 當時還是法代 → 有效拒絕）
```
- 「限制原因消滅」條文不寫「成年」，因為舊法 §13 III 未成年人已結婚者有行為能力（結婚也是限制原因消滅）；112 年後成年與結婚年齡同為 18，只剩成年一種。
- 老師：行為能力制度是保護；18 歲成年後法律不再保護，要為自己的行為負責。新聞「我兒子才 18 你怎麼賣他重機」→ 法律上 18 就成年了。
