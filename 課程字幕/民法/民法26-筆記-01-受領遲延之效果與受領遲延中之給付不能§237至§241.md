# 民法26 筆記：受領遲延之效果與受領遲延中之給付不能（§237至§241）

## 考題型態：種類之債＋受領遲延＋給付不能
- 甲乙就 A（種類之債）訂買賣契約；甲在約定時間派員工丙把 A 送到乙家門口
- 乙因急性腸胃炎住院（或被教育召集）不能受領，丙只好載回
- 回程因**丙的輕過失**，A 滅失 → 問當事人間法律關係
- 題目只問「法律關係」時，先想**誰會當原告**：先乙告甲，再甲告乙
- 本題延續民法24 的水晶燈案（見民法24-筆記-06）；受領遲延的要件見民法25-筆記-12

## 乙對甲：§348 請求給付 → 甲依 §225 I 免給付義務
- 老師的習慣：先涵攝**給付不能**，再談可不可歸責（先有不能的事實，才問就這件事可否歸責）
- 種類之債原則上沒有給付不能，須先**特定**（§200 II）
  - 經債權人同意指定：乙沒有受領，不成立
  - **交付必要行為完結**：赴償之債，現實提出即完結，乙受不受領在所不問 → A 已特定
- 特定物滅失 → 給付不能 → 甲免給付義務
- §225 I 不必討論可不可歸責：可歸責時一樣免給付義務，只是轉為 §226 損害賠償
  - 講義註 738 所引 40 年判例（字幕作「40台上599」，出租人將租賃物租與他人並交付 → 承租人只能依 §226 請求賠償）、89 年判決，字號建議查證；王千維亦同此見解

## 乙對甲：§226 損害賠償 → 甲不可歸責
- 可歸責看兩件事：**歸責標準**（§220 以下）與**過失程度**
- 丙是甲的**履行輔助人**（§224）→ 丙的輕過失視同甲的輕過失
- 但輕過失是否可歸責，看本件的歸責標準：
  - 乙已構成**受領遲延**（§234）：甲依約提出，乙不能受領
  - 受領遲延**不以可歸責為要件**：教召、住院等不可歸責的不能受領，一樣成立
  - 效果：**§237** 債權人遲延中，債務人**僅就故意或重大過失負責**
- 甲只有輕過失 → 不可歸責 → §226 請求無理由
- 結論：乙請求給付敗訴（不能）、請求賠償也敗訴（不可歸責）
- 接著甲轉向乙請求價金（§367），核心爭點見民法26-筆記-02

## 受領遲延的其他效果（法條瞄過即可，選擇題用）：
- §238：遲延中債務人**無須支付利息**
- §239：應返還孳息者，以**已收取**之孳息為限
- §240：可請求**提出及保管**給付物的必要費用
- §241：**限不動產**，債務人得拋棄占有
  - 腳踏車（動產）受領遲延：不能放在對方門口了事，要載回保管，再依 §240 請求保管費
- 一直不受領：§326 **提存**；提存後 **10 年**不領取，提存物歸屬國庫（§330）→ 提存所的拍賣會就是這樣來的

## 📖 法條原文速查

> **§225 I**　因不可歸責於債務人之事由，致給付不能者，債務人**免給付義務**。

> **§226 I**　因**可歸責**於債務人之事由，致給付不能者，債權人得請求賠償損害。

> **§224**　債務人之代理人或使用人，關於債之履行有故意或過失時，債務人應與自己之故意或過失負同一責任。但當事人另有訂定者，不在此限。

> **§237**　在債權人遲延中，債務人僅就**故意或重大過失**，負其責任。

> **§238**　在債權人遲延中，債務人無須支付利息。

> **§239**　債務人應返還由標的物所生之孳息或償還其價金者，在債權人遲延中，以**已收取之孳息**為限，負返還責任。

> **§240**　債權人遲延者，債務人得請求其賠償**提出及保管**給付物之必要費用。

> **§241**　I 有交付**不動產**義務之債務人，於債權人遲延後，得**拋棄其占有**。II 前項拋棄，應預先通知債權人。但不能通知者，不在此限。

> **§326**　債權人受領遲延，或不能確知孰為債權人而難為給付者，清償人得將其給付物，為債權人**提存**之。

> **§330**　債權人關於提存物之權利，應於提存後**十年**內行使之，逾期其提存物**歸屬國庫**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「受領遲延是否以債權人可歸責為要件？」 | **否**，客觀上提出＋拒絕或不能受領即成立 |
| 「受領遲延中，債務人輕過失致給付物滅失？」 | **不負責**，僅就故意或重大過失負責（§237） |
| 「赴償之債，送到債權人住所但其不在？」 | 現實提出 → 交付必要行為完結 → 特定 |
| 「動產買賣受領遲延，債務人得否拋棄占有？」 | **不得**，§241 限不動產 |
| 「受領遲延中，金錢債務人仍須付利息？」 | **無須**（§238） |
| 「提存後多久不領取歸屬國庫？」 | **10 年**（§330） |

## 解題流程

```
乙 → 甲
├── §348 請求交付 A
│   └── 特定（§200 II）後滅失 → 給付不能 → §225 I 免給付義務
└── §226 請求賠償
    └── 丙輕過失（§224）＋ 乙受領遲延 → §237 只負故意重大過失
        → 不可歸責 → 無理由
甲 → 乙
└── §367 請求價金 → §266 或 §267？（見筆記-02）
```
