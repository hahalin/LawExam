# 民法22 筆記：無權出租他人土地與既成道路之權益歸屬（§952、§943）

## 案例：
- 乙無權占有甲的 A 地，出租給丙，丙占有使用
- 分丙**惡意**、丙**善意**兩種情形；考試愛考丙善意

## 甲對丙主張 §767 I 前段：善惡意都可以
- 乙丙租約基於債之相對性，不能對抗甲
- 土地在誰手上就告誰：A 地已交付丙，告乙返還會敗訴

## 丙受有什麼利益：
- 丙受有 **A 地占有的利益**；不當得利的「利益」範圍比侵權行為的「權利」寬，包含占有
- 早年少數實務採**總體財產觀察法**：丙付了租金，總體財產沒增加 → 無得利（83 台上 1139；109 台上 1938 又採此說）
- 通說採**個別財產觀察法**：取得個別利益就是得利，有無付租金不問；考試可寫出少數說後批評

## 丙惡意：
- 非給付型 → 權益歸屬說：占有利益歸屬於所有人甲，乙丙租約不能對抗甲
- 甲得向丙請求**相當於租金的不當得利**

## 丙善意：§952 配 §943
- §952：善意占有人在「推定其為適法所有之權利範圍內」得使用收益；這個推定就是 **§943 占有推定力**
- §943 I：占有人於占有物上行使的權利，推定其適法有此權利
- §943 II 兩個例外：①已登記不動產上行使**物權**（看登記推定力，§759-1 I）；②行使所有權以外之權利，對**使其占有之人**（雙方有原因關係，不必推定）
- 本案丙行使的是**租賃權**（債權），甲也不是使丙占有之人 → 兩個例外都不該當 → 丙受推定保護
- 結論：依 §952，占有利益在法律上歸屬於善意的丙 → 甲不能依 §179 請求
- 保護到甲舉反證推翻為止；實務上依 §959 II，本權訴訟敗訴者自**訴狀送達之日**起視為惡意，此後才有不當得利

## 老師的看法：
- 最高法院常說 §952 是 §179 的**特別規定**（77 台上 1208）
- 老師認為 §952 只是決定權益歸屬的規定，是構成要件解釋的當然結果，不是「原則成立、例外免還」

## 延伸：占用既成道路
- A 地已成既成道路，所有人甲只負**容忍公眾通行**的義務
- 以**通行**為目的使用 → 利益屬全體用路人，不成立不當得利
- 通行以外的用途（路旁擺攤形成夜市）→ 利益仍歸屬甲，得請求相當於租金的不當得利

## 📖 法條原文速查

> **§952**　**善意占有人**於推定其為適法所有之權利範圍內，得為占有物之**使用、收益**。

> **§943**　I 占有人於占有物上行使之權利，**推定其適法有此權利**。II 前項推定，於下列情形不適用之：一、占有已登記之不動產而行使物權。二、行使所有權以外之權利者，對使其占有之人。

> **§959**　I 善意占有人自確知其無占有本權時起，為惡意占有人。II 善意占有人於本權訴訟敗訴時，自**訴狀送達之日起**，視為惡意占有人。

> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。

## 📋 實務見解速查

> **61 台上 1695 判例**：無權占有他人土地，可能獲得相當於租金之利益，為社會通常之觀念。（相當於租金不當得利的基本概念）

> **77 台上 1208**（講義 318 頁）：善意占有人依 §952、§943 使用收益所獲利益，對所有人不負返還義務，此為不當得利之特別規定。

> **83 台上 1139**（講義 322 頁）：承租人有依約支付租金之義務，未受有相當於租金之利益，不得對承租人請求返還。→ 總體財產觀察法；109 台上 1938 亦同，陳忠五教授為文批評（姓名依字幕校正，建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「乙無權出租甲地給丙，甲依 §767 應向誰請求？」 | **丙**（現占有人） |
| 「丙已付租金給乙，是否受有利益？」 | 通說個別財產觀察法：**有** |
| 「善意承租人丙，甲得否請求相當於租金之不當得利？」 | **否**，§952 使利益歸屬於丙 |
| 「善意占有人自何時起負返還責任？」 | 本權訴訟敗訴，自**訴狀送達日**（§959 II） |
| 「§943 推定之例外？」 | 已登記不動產行使**物權**；對使其占有之人 |
| 「在既成道路旁擺攤，所有人得請求不當得利？」 | **得**，所有人只負容忍通行義務 |

## 一、判斷流程

```
甲對丙 §179
├─ 受利益：A 地占有（個別財產觀察法）
└─ 無法律上原因（權益歸屬說）
    ├─ 丙惡意 → 利益歸甲 → 成立
    └─ 丙善意 → §943 推定租賃權（無例外）→ §952 利益歸丙 → 不成立
                 └─ 訴狀送達後視為惡意（§959 II）→ 成立
```

## 二、§943 II 例外對照

| 例外 | 舉例 | 本案 |
|---|---|---|
| 已登記不動產行使物權 | 自稱地上權人但未登記 | 丙行使租賃權（債權）→ 不該當 |
| 對使其占有之人 | 甲自己把地租給丙 | 使丙占有的是乙 → 不該當 |
