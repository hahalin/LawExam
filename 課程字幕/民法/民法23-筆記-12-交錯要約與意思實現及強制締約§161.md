# 民法23 筆記：交錯要約與意思實現及強制締約（§161）

## 交錯要約：
- 民法沒有明文；雙方互為要約而意思表示合致，契約也成立
- 林誠二：在臺灣典型只有一種——**股票交易**（我掛 60 元賣、你掛 60 元買，兩個要約合致）
- 「我剛好要賣、你剛好要買」的例子其實就是一般的要約與承諾

## 意思實現（§161）：
- 結構：**要約＋事實**（不是要約＋承諾）
- 適用：依習慣或事件性質承諾無須通知（I），或要約人**預先聲明承諾無須通知**（II）
- 在相當時期內有**可認為承諾之事實** → 契約成立
- 事實不是意思表示，要找的是「那個事件」→ 與**默示意思表示**區別

## 考過的題型：甲向乙要約買 A 畫，乙寄出 A 畫
- **承諾無須通知**（意思實現）：乙**一寄出**契約就成立
  - 甲沒收到 → 契約已成立 → 乙**債務不履行**
- **承諾仍須通知**：寄畫是非對話的**默示承諾**，依 §95 **到達甲**時契約才成立
  - 甲沒收到 → 契約**不成立** → 甲若已付款，只能依不當得利請求返還

## 自動販賣機被吃錢：債務不履行還是不當得利？
- **販賣機是要約**：投幣＝承諾，契約成立；飲料沒出來是**債務不履行** → 應請求給付飲料，不是退錢
- **販賣機是要約之引誘**：看不出存貨、只貼照片 → 投幣是要約，飲料掉出來是**意思實現**；沒掉出來 → 契約不成立 → **不當得利**請求退錢
- 現在多看機器外觀：看得到商品與存貨（如高鐵站新型機台）接近**標價陳列**，視為要約；只貼照片的舊機台是要約之引誘
- 老師：早年教科書必談，現在少考

## 強制締約：
- 原則上有契約自由，可以選擇締約對象
- 基於公益要求一定要締約，例：醫院不得拒收急危病人（醫療法，條號建議查證）

## 下一講與講義延伸：
- 下一講：**懸賞廣告**，之後進入債之效力
- 講義中陳忠五（字幕「陳沖富」，建議查證）〈論契約的要約〉〈論契約的承諾〉較深入，有興趣自行閱讀
- 391 頁意思表示不成立與有瑕疵之區別：民總意思表示錯誤已講過

## 📖 法條原文速查

> **§161**　I 依習慣或依其事件之性質，**承諾無須通知**者，在相當時期內，有**可認為承諾之事實**時，其契約為成立。II 前項規定，於要約人要約當時**預先聲明承諾無須通知**者準用之。

> **§95 I**　非對話而為意思表示者，其意思表示，以通知**達到**相對人時，發生效力。但撤回之通知，同時或先時到達者，不在此限。

> **§154 II**　貨物標定賣價陳列者，視為要約。但價目表之寄送，不視為要約。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「意思實現的構造？」 | **要約＋可認為承諾之事實** |
| 「預先聲明承諾無須通知，乙寄出貨物，契約何時成立？」 | **寄出時** |
| 「承諾須通知，乙寄出貨物，契約何時成立？」 | **到達甲時**（默示承諾、§95） |
| 「意思實現契約成立後貨物遺失？」 | 契約已成立 → **債務不履行** |
| 「交錯要約有無明文？」 | **無**，典型例為股票交易 |
| 「販賣機吃錢，採要約之引誘說？」 | 意思未實現、契約不成立 → **不當得利** |

## 寄畫案對照

| | 承諾無須通知（§161） | 承諾須通知 |
|---|---|---|
| 乙寄出 A 畫是 | 可認為承諾之事實 | 非對話之默示承諾 |
| 契約成立時點 | **寄出時** | **到達甲時** |
| 甲沒收到 | 債務不履行 | 契約不成立 → 不當得利 |

## 販賣機兩說

```
販賣機
├── 要約（看得到商品存貨）→ 投幣＝承諾 → 契約成立
│        └─ 飲料沒出來 → 債務不履行 → 請求給付飲料
└── 要約之引誘（只貼照片）→ 投幣＝要約 → 飲料掉出＝意思實現
         └─ 飲料沒出來 → 契約不成立 → 不當得利退錢
```
