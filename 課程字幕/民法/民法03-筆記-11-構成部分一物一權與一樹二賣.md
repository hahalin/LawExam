# 民法03 筆記：構成部分、一物一權與一樹二賣（32 年上字第 6232 號判例）

> 來源：民法03 課程字幕 02:10:01 ~ 02:25:54

---

## 📖 法條原文速查

> **§66 II**　不動產之**出產物**，尚未分離者，為該不動產之**部分**。

> **§70 I**（天然孳息之歸屬）
> 有**收取天然孳息權利之人**，其權利存續期間內，**取得與原物分離之孳息**。
> → 老師口頭說「§70 II」，天然孳息是第 I 項；第 II 項是法定孳息

> **§766**（物之成分及天然孳息之歸屬）
> 物之成分及其天然孳息，於分離後，除法律另有規定外，仍屬於其物之所有人。

> **§348 I**（出賣人之義務）
> 物之出賣人，負交付其物於買受人，並使其取得該物所有權之義務。→ 契約請求，只能對契約相對人

> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。

> **§226 I**（給付不能之損害賠償）
> 因可歸責於債務人之事由，致給付不能者，債權人得請求賠償損害。

> **§799**（區分所有建築物）→ 「法律另有規定」使構成部分得獨立為物權標的之例。建議查閱最新六法原文

## 📋 實務見解速查

> **最高法院 32 年上字第 6232 號判例**（講義註 107）：物之構成部分，除法律有特別規定外，不得單獨為物權之標的物。未與土地分離之樹木，依 §66 II 為土地之構成部分，與同條 I 項所稱之定著物為獨立之不動產者不同。購買未與土地分離之樹木，**僅對於出賣人有砍伐樹木之權利**，在未砍伐前並未取得該樹木之所有權，不得對於其他購買該樹木而砍伐之第三人主張所有權。
> → 建議查閱判例全文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「一物一權主義？」 | 一個物只受**一個所有權**支配（所有權背後幾個人共有不管） |
| 「汽車之引擎、方向盤是獨立之動產？」 | **不是**，合成物之成分，未分離前不能獨立為交易客體 |
| 「駕訓班、一間教室是一個物？」 | **不是**，是**集合物**＝數個物，須分別為物權變動 |
| 「購買未分離之樹木，買到什麼？」 | **砍伐權（收取權）**，是**債權**；未砍伐前無所有權 |
| 「甲將同一棵樹先賣乙、後賣丙，丙砍伐之，樹歸誰？」 | **丙**。丙為有收取權之人，分離時取得所有權（§70 I）；誰砍誰的，不因先買而有別 |
| 「乙得否依 §348 向丙請求交付？」 | **不得**，債之相對性，丙非契約當事人 |
| 「乙得否依 §767 向丙請求？」 | **不得**，乙非所有人 |
| 「乙如何救濟？」 | 向**甲**依 **§226** 請求債務不履行（給付不能）之損害賠償 |
| 「構成部分得獨立為物權標的之例外？」 | 法律另有規定：**§799 區分所有建築物之專有部分** |

## 一、構成部分 ＝ 物的要素，不是獨立的物

- 「構成部分」「成分」「部分」三個詞一樣。
- 例：§66 II 不動產之出產物（樹木、礦產）；合成物的成分（汽車的引擎、輪胎）。
- 未分離前不能獨立成為交易客體；土地買賣效力當然及於未分離的樹，不用另外約定。

## 二、一物一權主義與三種「物」

```
一物一權：一個物只受一個所有權支配
「一個物」是什麼？
├── 獨立物：實體上就是一個東西，無法切割
│     一塊土地（上面的樹是成分，還是同一個物）；土地上的房屋具獨立性 → 另一個物
│     → 土地買賣效力及於樹木、不及於房屋
├── 合成物：數個東西合而為一 → 法律上是一個物 → 一個物權行為搞定
│     汽車（引擎、輪胎、方向盤都是成分）
└── 集合物：數個物集合在一起 → 不是一個物 → 可以訂一個買賣契約，但要分別為物權變動
      駕訓班（場地、車輛、設備各自是獨立的物）、一間教室
```

## 三、案例：一樹二賣（32 年上 6232）

#### 事實
1. 甲在 A 地上有 B 樹（未分離）。甲先將 B 樹賣給乙。
2. 甲又將同一棵 B 樹賣給丙。
3. 丙把樹砍下來。乙對丙請求交付 B 樹。

#### 分析
```
原告乙、被告丙、聲明：交付 B 樹 → 請求權基礎？

① §348？
    契約請求 → 債之相對性 → 只能對契約當事人（甲）→ 丙不是 → ✗

② §767 I 前段？
    要件：乙是 B 樹所有人？→ 按時間順序看三件事
    (1) 甲乙買賣：B 樹未分離 → 土地的成分（§66 II）→ 不是獨立的物 → 不能當獨立買賣標的
        → 乙買到的只是「砍伐權／收取權」＝ 對甲的【債權】
        → 乙沒砍 → 只有砍伐權，沒有所有權
    (2) 甲丙買賣：丙同樣買到砍伐權
        → 債權平等原則：對同一標的訂數個債權，互不干涉、地位平等，乙的債權對丙無效力
    (3) 丙砍伐：丙是有收取權之人 → 分離時取得 B 樹所有權（§70 I、§766）
    → 乙不是所有人 → §767 ✗

③ 結論：乙對丙無理由。乙只能對甲依 §226 請求給付不能之損害賠償。
```

### 判例要旨拆解
```
「僅對於出賣人有砍伐樹木之權利」
    僅 → 只買到這個；對於出賣人 → 是債權（只能對甲主張）；砍伐 → 權利內容
「未砍伐前未取得所有權」 → 反面：砍了才有 → 誰砍誰的
「不得對於其他購買該樹木而砍伐之第三人主張所有權」 → 不因先買就是你的
```

## 四、「法律另有規定」：§799 區分所有建築物

- 公寓的專有部分其實是整棟建築物的構成部分，但法律讓它有獨立所有權 → 構成部分例外得單獨為物權標的。物權法再講。
