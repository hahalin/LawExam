# 民法14 筆記：純粹經濟上損失（pure economic loss, PEL）導論——挖斷電纜案（案例一）：乙過失挖斷**台電**的電纜致甲營業損失 → 甲**有損害但無權利受侵害**（電纜所有權是台電的；甲無所有權、物權、人格權被侵害）→ 不得依 §184 I 前段；乙僅過失 → 亦不該當 §184 I 後段（故意背於善良風俗）、§184 II（無保護他人之法律被違反）→ 甲對乙**無侵權請求權**，只能依與台電之供電契約（停電折扣）或事先以保險分散風險；台電則得就電纜所有權被侵害對乙請求。理由：**權利保護與行為自由之平衡**，絕對權具**典型公開性**（Publizität），乙能預見的只有電纜本身，電纜背後的營業損失不可預見 → 以絕對權為核心建構 §184 I 前段，其餘由後段、II 補充

## 📖 法條原文速查

> **民法 §184 I**　因故意或過失，不法侵害他人之**權利**者，負損害賠償責任。故意以背於善良風俗之方法，加損害於他人者亦同。
> **民法 §184 II**　違反保護他人之法律，致生損害於他人者，負賠償責任。但能證明其行為無過失者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「乙施工過失挖斷電纜，甲商店停電無法營業，甲得否依 §184 I 前段對乙請求營業損失？」 | **不得**。電纜所有權屬台電，甲無絕對權受侵害，營業損失為**純粹經濟上損失** |
| 「同上，得否依 §184 I 後段或 II？」 | **不得**。後段須**故意**＋背於善良風俗；II 須違反保護他人之法律，過失挖斷不該當 |
| 「純粹經濟上損失定義？」 | 損害**未與絕對權（財產權、人格權等）相結合**，單純的經濟損失（最高法院用語：「此項損害係純粹的，未與其他財產權或人格權等權利相結合」） |
| 「甲怎麼辦？」 | 依與台電之供電契約（停電補償條款）；營業損失巨大者應事先投保；台電得就電纜所有權被侵害依 §184 I 前段對乙求償 |
| 「為何侵權行為法不保護過失造成之純粹經濟上損失？」 | **權利保護 vs 行為自由**之平衡：絕對權有典型公開性，行為人可預見；純粹經濟損失範圍無從預見（高速公路車禍 → 後車誤機、誤簽約……全算在肇事者頭上，無人敢開車）→ 以絕對權為 §184 I 前段核心，過失侵害利益原則不賠 |

## 一、思考順序（本堂所有案例共用）

```
第一步：有無損害？（有損害才有賠償）
第二步：損害背後有無「權利」（絕對權）受侵害？
   有 → §184 I 前段（過失＋不法即可）
   無 → 純粹經濟上損失 → 只能往 §184 I 後段（故意＋背俗）、§184 II（違反保護他人之法律）思考
   皆不該當 → 侵權行為法不保護 → 回契約、保險
```

## 二、案例一：挖斷電纜

| | 內容 |
|---|---|
| 事實 | 甲與台電簽供電契約；乙施工**過失**挖斷電纜；甲下午無法營業 |
| 損害 | 有（營業損失） |
| 權利侵害 | **無**（電纜是台電的；甲無所有權、物權、人格權被侵害） |
| §184 I 前段 | ✗ |
| §184 I 後段 | ✗（僅過失，非故意背俗） |
| §184 II | ✗（無保護他人之法律） |
| 結論 | 甲對乙無侵權請求權；依供電契約（停電幾小時當月電費打折）；台電對乙有 §184 I 前段 |

## 三、為什麼？——典型公開性

- 乙挖斷電纜時能預見的：電纜壞了要賠電纜。電纜背後連接出去有多少營業損失，**難以預料、無典型公開性**。
- 若要求乙對全部結果負責 → 行為自由過度限制（「以後沒有人敢挖電纜」「牽一髮動全身」）。
- 絕對權＝學界認為權利保護與行為自由間最好的中間值 → 以絕對權受侵害為核心建構 §184 I 前段；其餘用 §184 I 後段、II **補充**。
- 侵權行為法找不到兩全其美的方式，只能找平衡點。
