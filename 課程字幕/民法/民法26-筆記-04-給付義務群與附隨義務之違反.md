# 民法26 筆記：給付義務群與附隨義務之違反

## 不合債之本旨，看的是「給付義務群」：
- **主給付義務**：契約明示約定或法律定義性條文所定的核心給付（租賃：出租人交付租賃物、承租人付租金）
- **從給付義務**：為使主給付義務獲得最大滿足，依交易習慣或誠信原則衍生，**可獨立請求**
- **附隨義務**：同樣為使主給付獲得最大滿足而衍生，**不可獨立請求**
- 三者任何一種違反，都構成**不完全給付**

## 王澤鑑的例子：買一匹汗血寶馬（字幕作「血汗寶馬」）
- 主給付：馬本身
- 從給付：**血統證明書**（可以獨立請求交付）
- 附隨義務：告知飼養注意事項、有無遺傳性疾病（不能獨立請求，但違反仍構成不完全給付）

## 附隨義務違反可否解約：
- 原則**不可以**：附隨義務是契約最末端的細節（最後 5%、10%）
- 例外：違反已達**契約目的不達**的程度 → 仍可解約
- 例：買冷氣附安裝（安裝不能獨立請求 → 附隨義務）
  - 沒裝好但冷氣還能吹、可補正 → 不必解約
  - 電沒接好跳電，壓縮機燒掉、冷氣不能用 → 契約目的不達 → 可解約

## 區分越來越模糊：
- 附隨義務違反也可能解約 → 與從給付的差別只剩「能否獨立請求」
- **林誠二**：只分**要素債務**（主給付）與**附隨債務**（從給付＋附隨），不再細分
- 老師舉設計圖的例子說明「能否獨立請求」仍要回到個案約定判斷（此段字幕 00:45:37 ~ 00:46:30 斷續缺漏）

## 考試技巧：枝微末節的事實多半在考附隨義務
- 例：到餐廳點炒飯，在廁所滑倒受傷
  - 主給付是炒飯；提供乾淨的用餐環境是為使主給付獲得最大滿足的延伸義務 → **附隨義務**
  - 廁所濕滑致受傷 → 附隨義務違反 → 依 §227 請求損害賠償
  - 但不能因為廁所髒就解約：食物照樣能吃，契約目的沒有不達
- 與主給付**完全無關**的事，不能解釋成附隨義務
- 答題時要說明：為什麼這個義務屬於從給付或附隨義務、為什麼違反它也構成不完全給付

## 📖 法條原文速查

> **§227 I**　因可歸責於債務人之事由，致為不完全給付者，債權人得依關於給付遲延或給付不能之規定行使其權利。

> **§148 II**　行使權利，履行義務，應依誠實及信用方法。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「違反附隨義務是否構成不完全給付？」 | **是**，主、從、附隨都在給付義務群內 |
| 「從給付與附隨義務的區別？」 | 從給付**可獨立請求**；附隨義務不可 |
| 「買馬未交付血統證明書？」 | 從給付義務違反 |
| 「附隨義務違反可否解約？」 | 原則**不可**；達契約目的不達時例外可以 |
| 「餐廳廁所濕滑顧客跌傷，可否依債務不履行求償？」 | 可，附隨義務違反，依 §227 |

## 給付義務群

```
給付義務群（皆可構成不完全給付）
├── 主給付義務 ── 契約／定義性條文 ── 馬本身
├── 從給付義務 ── 可獨立請求 ────── 血統證明書
└── 附隨義務 ──── 不可獨立請求 ──── 告知遺傳病、安裝冷氣、乾淨廁所
                  └── 原則不得解約，契約目的不達時例外可以
林誠二：要素債務（主給付）／附隨債務（從給付＋附隨）
```
