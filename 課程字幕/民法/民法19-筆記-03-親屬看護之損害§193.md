# 民法19 筆記：親屬看護之損害§193

## 問題：
- 甲被乙開車撞傷，由已退休的母親丙到醫院照顧 3 個月，丙沒有向甲收費
- 甲依 §184 I 前段＋§193 I（增加生活上之需要）請求時，丙的照顧付出能否算進去？

## 否定說：
- 甲沒有支出費用 → 沒有損害 → 沒有賠償

## 實務（88 台上 1827）：肯定
- 親屬看護所付出的勞力**並非不能評價為金錢**
- 基於親情免除被害人的支付義務，這種身分關係的恩惠**不能加惠於加害人**
- 比照僱用職業看護之費用，認被害人受有相當看護費之損害

## 王澤鑑補充：移轉性損失
- 實務理由沒錯，但沒回答「**損害在哪裡**」
- 丙有時間、勞力、交通費等損失，但丙**沒有絕對權受侵害** → 不能自己依 §184 求償
- 甲權利受侵害，卻因丙沒收錢而**沒有損害**
- 損害本應與權利同在甲身上（甲自己請看護會付錢）→ 因丙不收費而偏移到丙
- 以**移轉性損失**把損害移回甲，權利與損害同歸一人 → 甲得依 §193 請求

## 作答：
- 選擇題：選**得請求**
- 申論：先寫實務兩個理由（非不能評價為金錢、非為加惠加害人），再補移轉性損失，論述較完整

> 來源：民法19 課程字幕 00:28:40 ~ 00:36:30（講義 208 頁）；字幕「假扣押了三個月」為語音辨識錯字，依上下文應為照顧甲三個月

---

## 📖 法條原文速查

> **§193 I**　不法侵害他人之身體或健康者，對於被害人因此喪失或減少勞動能力或**增加生活上之需要**時，應負損害賠償責任。

---

## 📋 實務見解速查

> **88 台上 1827**（講義 208 頁）：親屬代為照顧被害人之起居，固係基於親情，但親屬看護所付出之勞力並非不能評價為金錢，雖因二者身分關係而免除被害人之支付義務，惟此種基於身分關係之恩惠，自不能加惠於加害人，應比照僱用職業護士看護情形，認被害人受有相當於看護費之損害。（要旨改寫，原文請對講義）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「被害人由母親無償看護，得否向加害人請求看護費？」 | **得**（88 台上 1827） |
| 「親屬無償看護，故被害人無損害？」 | **錯**，恩惠不能加惠於加害人 |
| 「看護之母親得否自己依 §184 向加害人求償？」 | **否**，母親無絕對權受侵害 |
| 「學說以何理論說明被害人之損害？」 | **移轉性損失**（王澤鑑） |

## 一、權利與損害分離

```
乙撞傷甲
├─ 甲：身體健康權受侵害 ✓／未付費 → 表面上無損害
└─ 丙（母親）：時間、勞力、交通費之損失 ✓／無權利受侵害 ✗
        ↓ 丙不收費，損害偏移到丙
移轉性損失：把丙的損害移回甲
        ↓
甲：權利＋損害 → §184 I 前段＋§193 I ✓
```

## 二、實務與學說的分工

| | 實務（88 台上 1827） | 王澤鑑 |
|---|---|---|
| 結論 | 肯定 | 肯定 |
| 理由 | 非不能評價為金錢；不能加惠加害人 | 移轉性損失 |
| 回答了什麼 | 為何不應讓加害人占便宜 | 甲的損害在哪裡 |
