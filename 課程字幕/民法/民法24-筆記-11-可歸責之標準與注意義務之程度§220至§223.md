# 民法24 筆記：可歸責之標準與注意義務之程度（§220至§223）

## 給付不能的效果，先看可不可歸責：
- 不可歸責於債務人 → 債務人 **§225**；再看債權人：
  - 雙方都不可歸責 → **§266**（免對待給付）
  - 可歸責於債權人 → **§267**（仍須對待給付）
- 可歸責於債務人 → **§226** 損害賠償、**§256** 解除契約
- §266、§267、§256 在雙務契約章節，所以條號會跳到後面

## 責任程度的光譜（原則在中間，往兩邊都是例外）：
| 責任 | 意義 | 例 |
|------|------|-----|
| **不可抗力責任** | 無過失也要負責，連不可抗力都不能免責 | §231 II（遲延中）、§654 旅客**遲到** |
| **通常事變責任** | 無過失也要負責，但可以不可抗力免責 | §654 旅客**傷害**、§606 旅店主人 |
| **抽象輕過失**（原則） | 與**善良管理人**比 | 法條沒特別規定時 |
| **具體輕過失** | 與**處理自己事務**比 | §535、§590 無償委任、寄託 |
| **重大過失** | 與**一般人**比 | §237 受領遲延中 |
| 故意 | 只就故意負責 | 少見 |

## 讀法條看出責任類型（§654）：
- 「對旅客之傷害及遲到應負責任」——沒寫故意過失、沒寫可歸責 → **無過失責任**
- 但書「其**傷害**係因不可抗力所致者，不在此限」——只有傷害能以不可抗力免責
  - 傷害 → 通常事變責任；遲到 → 不可抗力責任
  - §654 II：不可抗力的遲到，以旅客因遲到而**增加支出之必要費用**為限（颱風停飛只給餐券、毛毯）
- §231 II 只是**歸責規定**，不是請求權基礎；請求仍回到 §226 等，用它解釋「可歸責」

## §220 II「從輕酌定」：
- 事件**非予債務人以利益**（無償）→ 從輕酌定
- 「輕」是放寬犯錯空間，反而可能只負**具體輕過失**或**重大過失**，不是「負輕過失」
- 無償大多是具體輕過失；受有報酬就改負善良管理人注意（§535、§590）
  - 林誠二舉例：無償幫人寄信，跟自己的信一樣放包包；收了錢就要特別謹慎保管

## 過失 ≠ 可歸責：
- 先畫線：負重大過失責任 → 故意、重大過失可歸責；具體輕過失、抽象輕過失、無過失都**不可歸責**
- 負不可抗力責任 → 沒過失也可歸責

## §221：無行為能力人、限制行為能力人 → 準用 §187 看**識別能力**
- 陷阱：甲**訂約時**就是無行為能力人 → 契約依 §75 **無效**，沒有債務不履行，走不當得利
- 有效訂約後甲才車禍、受監護宣告 → 才是 §221 的問題；無識別能力 → 不可歸責

## §222、§223：
- 故意或重大過失責任**不得預先免除**（強行規定，違反無效）；**事後**免除可以
- §223：應與處理自己事務為同一注意者，有**重大過失**仍應負責

## 📖 法條原文速查

> **§220**　I 債務人就其故意或過失之行為，應負責任。II 過失之責任，依事件之特性而有輕重，如其事件非予債務人以利益者，應**從輕酌定**。

> **§221**　債務人為無行為能力人或限制行為能力人者，其責任依**第一百八十七條**之規定定之。

> **§222**　故意或重大過失之責任，**不得預先免除**。

> **§223**　應與處理自己事務為同一注意者，如有重大過失，仍應負責。

> **§231 II**　前項債務人，在遲延中，對於因**不可抗力**而生之損害，亦應負責。但債務人證明縱不遲延給付，而仍不免發生損害者，不在此限。

> **§654**　I 旅客運送人對於旅客因運送所受之傷害及運送之遲到應負責任。但因旅客之過失，或其**傷害**係因不可抗力所致者，不在此限。II 運送之遲到係因不可抗力所致者，旅客運送人之責任，除另有交易習慣者外，以旅客因遲到而增加支出之必要費用為限。

> **§606**　旅店或其他供客人住宿為目的之場所主人，對於客人所攜帶物品之毀損、喪失，應負責任。但因不可抗力或因物之性質或因客人自己或其伴侶、隨從或來賓之故意或過失所致者，不在此限。

> **§535**　受任人處理委任事務，應依委任人之指示，並與處理自己事務為同一之注意，其受有報酬者，應以善良管理人之注意為之。

> **§237**　在債權人遲延中，債務人僅就故意或重大過失，負其責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債務人原則上負何種過失責任？」 | **抽象輕過失** |
| 「旅客運送遲到因不可抗力，可否免責？」 | **不可**（不可抗力責任），但賠償以必要費用為限 |
| 「旅客傷害因不可抗力？」 | **可免責**（通常事變責任） |
| 「無償委任之注意義務？」 | **具體輕過失**（與處理自己事務同一注意） |
| 「受領遲延中債務人責任？」 | 僅就**故意或重大過失**（§237） |
| 「預先約定重大過失免責？」 | **無效**（§222）；事後免除可以 |
| 「無行為能力人訂約後不履行，適用 §221？」 | **否**，契約依 §75 無效 |
