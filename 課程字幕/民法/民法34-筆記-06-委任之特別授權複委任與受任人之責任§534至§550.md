# 民法34 筆記：委任之特別授權、複委任與受任人之責任（§534～§550）

## 略過的章節：
- 旅遊、出版、經理人、代辦商：老師跳過
- 委任：§534、§537～§539 選擇題很愛考

## §534 特別授權（考前看一遍六款）：
- 受**概括委任**得為一切行為，但下列須**特別授權**：
  1. 不動產之出賣或設定負擔
  2. 不動產租賃期限**逾二年**
  3. 贈與
  4. 和解
  5. 起訴
  6. 提付仲裁
- 其餘行為可用概括授權

## 複委任（§537～§539）：
- 原則：受任人應**自己處理**
- 例外：經**委任人同意**、另有**習慣**、或有**不得已事由** → 得使第三人代為處理

| | 違法複委任 | 合法複委任 |
|---|---|---|
| 條文 | §538 I | §538 II |
| 受任人責任 | 就第三人之行為與自己之行為**負同一責任** → 丙出事就是乙出事 | 僅就第三人之**選任**及**指示**負責 → 挑對人、指示無誤，丙的過失與乙無關 |
| 委任人對第三人 | — | §539：有**直接請求權** |

- 例：甲委任乙，乙複委任丙

## §541 II：
- 受任人以自己名義為委任人取得之權利，應移轉於委任人
- **借名登記**的返還依據之一（見本講筆記-10）

## §544 是「小損害賠償」：
- 要件：處理委任事務**有過失**，或**逾越權限**
- 前提是**有做但沒做好**
- 完全擺爛不做 → 不是 §544，回到債務不履行
  - 給付仍有實益 → 依**給付遲延**請求履行＋遲延損害（§231）
  - 給付已無實益 → 拒絕給付，請求**不履行**之損害賠償（大損害賠償）

## §546 委任人之償還義務（選擇題愛考）：
- I 必要費用 → 償還並付**自支出時起**之利息
- II 必要債務 → 請求代為清償；未到期可請求提出擔保
- III 因**非可歸責於自己**之事由受損害 → 請求賠償
- 與無因管理 §176 管理人的權利很像
- 例：律師代墊的謄本規費，依法可向當事人請求

## 終止與消滅：
- §549：**雙方**都可隨時終止
- §550：當事人一方**死亡、破產、喪失行為能力** → 委任關係消滅；契約另有訂定或依事務性質不能消滅者除外
- §549、§550 在借名登記很常用（見本講筆記-10）

## 📖 法條原文速查

> **§534**　受任人受概括委任者，得為委任人為一切行為。但為左列行為，須有**特別之授權**：一、不動產之出賣或設定負擔。二、不動產之租賃其期限逾二年者。三、贈與。四、和解。五、起訴。六、提付仲裁。

> **§537**　受任人應**自己處理**委任事務。但經委任人之同意或另有習慣或有不得已之事由者，得使第三人代為處理。

> **§538**
> I　受任人違反前條之規定，使第三人代為處理委任事務者，就該第三人之行為，與就自己之行為，負**同一責任**。
> II　受任人依前條之規定，使第三人代為處理委任事務者，僅就第三人之**選任**及其對於第三人所為之**指示**，負其責任。

> **§539**　受任人使第三人代為處理委任事務者，委任人對於該第三人關於委任事務之履行，有**直接請求權**。

> **§541 II**　受任人以自己之名義，為委任人取得之權利，應移轉於委任人。

> **§544**　受任人因處理委任事務**有過失**，或因**逾越權限**之行為所生之損害，對於委任人應負賠償之責。

> **§546**
> I　受任人因處理委任事務，支出之必要費用，委任人應償還之，並付**自支出時起之利息**。
> II　受任人因處理委任事務，負擔必要債務者，得請求委任人代其清償，未至清償期者，得請求委任人提出相當擔保。
> III　受任人處理委任事務，因非可歸責於自己之事由，致受損害者，得向委任人請求賠償。

> **§549 I**　當事人之任何一方，得**隨時終止**委任契約。

> **§550**　委任關係，因當事人一方**死亡、破產或喪失行為能力**而消滅。但契約另有訂定，或因委任事務之性質不能消滅者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「概括委任可否出租不動產 3 年？」 | **不可**，逾二年須特別授權（§534 ②） |
| 「概括委任可否起訴、和解、贈與？」 | **不可**，均須特別授權 |
| 「受任人未經同意複委任，對第三人過失負責？」 | **負同一責任**（§538 I） |
| 「合法複委任之受任人責任？」 | 僅就**選任及指示**負責（§538 II） |
| 「委任人對複受任人有無直接請求權？」 | **有**（§539） |
| 「受任人完全不處理事務，依 §544 請求？」 | **不是**，依給付遲延或不履行 |
| 「誰得隨時終止委任？」 | **雙方**（§549） |
