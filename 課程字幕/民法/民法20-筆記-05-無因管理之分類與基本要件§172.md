# 民法20 筆記：無因管理之分類與基本要件（§172）

## 分類：
- 標準一：主觀上**為他人**還是**為自己** → 真正／不真正無因管理
- 標準二（真正無因管理內）：是否**利於本人**且**不違反本人明示或可得推知之意思** → 適法／不適法
- 不真正無因管理：**誤信管理**（過失，以為是自己的事）、**不法管理**（明知是他人事務，為自己利益管理）
- 只有**適法無因管理**是債之發生原因（契約、無因管理、不當得利、侵權行為），屬**法定之債**；其他三種原則回到不當得利、侵權行為或特別規定

## 基本要件（§172）：
- **未受委任，並無義務**：這件事本來與你無關
  - 甲撞傷乙後送醫 → 不是無因管理（本來就要負賠償責任）
  - 消防隊救火、父母帶小孩看醫生 → 有法律上義務，不是
- **為他人之意思**：有為他人的意思就夠，不必「純為」他人；**兼為自己**也可以
  - 買便當順便幫朋友買飲料
  - 隔壁失火，怕延燒到自家而去救火 → 兼為自己，仍成立
- **管理事務**：看過程不看結果，火沒撲滅、徒勞無功也成立

## 道路交通之自我犧牲：
- 甲逆向駛來，乙為閃避甲而摔傷
- 一般想到：§184 I 前段、§184 II（違反保護他人之法律）、§191-2
- 隱藏路線：乙閃避是為避免甲被撞受傷 → 為甲管理事務 → 依 **§176** 請求損害賠償
- 實益：侵權行為 2 年時效已過時，§176 適用一般時效 **15 年**（§125）
- 老師：考題出現「侵權行為時效已過，問怎麼辦」，不要忘了無因管理

## 📖 法條原文速查

> **§172**　**未受委任，並無義務**，而為他人管理事務者，其管理應依本人明示或可得推知之意思，以有利於本人之方法為之。

> **§176 I**　管理事務，利於本人，並不違反本人明示或可得推知之意思者，管理人為本人支出必要或有益之費用，或負擔債務，或受損害時，得請求本人償還其費用及自支出時起之利息，或清償其所負擔之債務，或**賠償其損害**。

> **§125**　請求權，因**十五年**間不行使而消滅。但法律所定期間較短者，依其規定。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「肇事者將被害人送醫，成立無因管理？」 | **否**，有法律上義務 |
| 「管理人兼為自己利益，即不成立無因管理？」 | **錯**，有為他人之意思即可 |
| 「救火未能撲滅，不成立無因管理？」 | **錯**，不問結果 |
| 「何種無因管理為債之發生原因？」 | **適法**無因管理（法定之債） |
| 「為閃避逆向車輛而摔傷，得依無因管理請求？」 | **得**，道路交通之自我犧牲，§176 |

## 一、分類樹

```
管理他人事務
├─ 為他人 → 真正無因管理
│   ├─ 利於本人＋不違反本人意思 → 適法（法定之債）
│   └─ 不利於本人或違反本人意思 → 不適法（筆記-10）
└─ 為自己 → 不真正無因管理
    ├─ 過失（以為是自己的事）→ 誤信管理
    └─ 明知是他人事務 → 不法管理（筆記-11）
```

## 二、要件檢驗表

| 要件 | 判斷 | 例 |
|---|---|---|
| 未受委任、並無義務 | 本來與你無關 | 肇事者送醫 ✗ |
| 為他人之意思 | 有即可，可兼為自己 | 救鄰居火怕延燒 ✓ |
| 管理事務 | 不問結果 | 滅火器噴完火仍在 ✓ |
| 利於本人、不違反意思 | 決定適法與否 | 筆記-06 |

## 三、閃避逆向車：請求權基礎

| 基礎 | 時效 |
|---|---|
| §184 I 前段、§184 II、§191-2 | 2 年／10 年（§197） |
| §176 I | 15 年（§125） |
