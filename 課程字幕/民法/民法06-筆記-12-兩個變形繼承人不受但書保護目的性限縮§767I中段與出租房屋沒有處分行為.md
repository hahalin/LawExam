# 民法06 筆記：§87 I 但書的兩個變形——繼承人不受保護（目的性限縮、§767 I 中段塗銷）、出租房屋根本沒有「處分」（下堂續）

> 來源：民法06 課程字幕 02:16:00 ~ 02:31:41（本堂結尾；出租案的「善意第三人」解釋下堂續）

---

## 📖 法條原文速查

> **§87 I 但書**　但不得以其無效對抗善意第三人。
> **§1148 I**　繼承人自繼承開始時，除本法另有規定外，承受被繼承人財產上之**一切權利、義務**。……
> **§759-1 II**　因信賴不動產登記之善意第三人，已**依法律行為**為物權變動之登記者，其變動效力，不因原登記物權之不實而受影響。
> **§767 I**　所有人對於無權占有或侵奪其所有物者，得請求返還之（**前段**）。對於妨害其所有權者，得請求除去之（**中段**）。有妨害其所有權之虞者，得請求防止之（後段）。
> **§118 I**　無權利人就權利標的物所為之**處分**，經有權利人之承認始生效力。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲與乙通謀虛偽將 A 地登記於乙名下，乙死亡，善意繼承人丙辦妥繼承登記，丙取得 A 地？」 | **否**。① §1148 只能繼承乙的權利，乙未取得 A ② §759-1 II 須**依法律行為**，繼承不是 ③ §87 I 但書**目的性限縮**：善意第三人限於**因法律行為**交易安全受影響者，繼承人不在內 |
| 「同上，甲對丙之請求權基礎？」 | **§767 I 中段**（除去妨害 → 塗銷登記），不是前段（丙未占有，土地甲自己在用） |
| 「法律上妨害之意義？」 | 非所有人卻**登記為所有人** → 法律上妨害（事實上妨害：倒垃圾） |
| 「答題標題寫『乙丙間法律行為是否有效』？」 | **錯**（倒扣）。繼承是法律事實，乙丙間沒有法律行為，只寫「丙」 |
| 「甲與乙通謀虛偽移轉並交付 A 屋，乙出租給善意丙並交付，丙可否主張善意取得？」 | **不可**。出租＋交付是**債權契約的履行**，**沒有處分行為** → 無「無權處分」→ 無善意取得可言；租房子不會租成屋主 |
| 「同上，丙如何對抗甲 §767 I 前段？」 | 主張甲乙行為有效、乙是所有人、自己與乙有租約 → 甲可否以通謀無效對抗善意丙 → **「善意第三人」如何解釋**（王澤鑑、陳聰富、林誠二不同）→ 下堂 |

## 一、變形 ①：繼承人

#### 事實
甲與乙通謀虛偽，把 A 地登記在乙名下。乙過世，善意的丙繼承並辦妥繼承登記。甲要把地要回來。

#### 分析（時間順序）
```
【甲乙】通謀虛偽 → 物權行為無效 → 乙未取得 A 地所有權
【丙】不是「乙丙間法律行為」——繼承是【法律事實】，不是法律行為（人死了怎麼過戶？）
    ① §1148 繼承？→ 只能繼承乙的一切權利 → A 不是乙的 → 繼承不到
    ② §759-1 II 善意取得？→ 丙善意 ✓、完成登記 ✓、前手登記不實 ✓ → 但須「依法律行為」✗ → 不能
    ③ §87 I 但書？→ 條文只寫「善意第三人」
        目的性限縮：但書目的是保護【交易安全】→ 第三人須是因【法律行為】交易安全受影響之人
        → 繼承人沒有交易安全要保護 → 不在但書範圍
→ 乙、丙都沒拿到 A → 甲仍是所有人
```

#### 甲的請求權：§767 I 中段，不是前段
```
前段：對無權占有者請求【返還占有】→ 但 A 地是甲自己在用，丙沒有占有 → 用不到
中段：對妨害所有權者請求【除去妨害】
    妨害有兩種：事實上妨害（在我地上倒垃圾）／法律上妨害（不是所有人卻登記為所有人）
    → 丙登記為 A 地所有人 = 法律上妨害 → 甲依 §767 I 中段請求丙【塗銷登記】
```
- 老師：繼承人是 §87 很特別的存在——他取得了登記外觀，卻不能主張任何跟善意有關的保護，因為他沒有交易安全要被保護。

## 二、變形 ②：出租房屋（下堂續）

#### 事實
甲與乙通謀虛偽，把 A 屋過戶給乙**並交付**（做得像一點）。乙把 A 屋出租給善意的丙並交付。甲發現，依 §767 I 前段向丙請求返還占有。

#### 很多人寫得很順、然後錯了
```
✗「乙將房屋交付給丙構成無權處分，丙善意 → 善意取得 → 丙是 A 屋所有人 → 甲不能 §767」
    → 租房子租一租變屋主？從天而降的所有權？交易安全不可能保護到送你房子
錯在第一句：乙丙間根本沒有「處分」
    乙丙做的是【債權契約（租賃）】＋為履行契約而【交付】
    沒有以物權變動為目的的行為 → 沒有處分行為 → 無所謂「無權」處分 → 沒有善意受讓什麼
```

#### 丙真正要做的：抗辯甲不是屋主
```
§767 I 前段要件 ①：甲是 A 屋所有人？
【甲乙】通謀虛偽 → 物權行為無效 → 乙沒拿到所有權（沒問題）
【丙】主張甲乙行為【有效】→ 乙是所有人 → 乙來告我，我用租約對抗；甲不是所有人，告不了我
→ 問題：甲可不可以用「通謀無效」對抗善意的丙？
→ 丙是不是 §87 I 但書的「善意第三人」？（丙不是取得物權的人，只是承租人）
→ 王澤鑑、陳聰富、林誠二見解不同 → 下堂從這裡接
```
