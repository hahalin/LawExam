# 民法10 筆記：§170 狹義無權代理的三面關係——本人與相對人：效力未定，本人有承認權／拒絕權；相對人有催告權（§170 II「相當期限」vs §80「一個月以上」）與撤回權（§171）；相對人與無權代理人：不得請求履行（乙非當事人）、**不能善意取得**（信賴基礎不同：無權處分信賴乙是所有人、有占有的推定力 §943；無權代理只信賴乙有代理權，占有不是授權外觀 → 應循 §107／§169）

> 來源：民法10 課程字幕 02:06:39 ~ 02:17:55

---

## 📖 法條原文速查

> **§170**　I 無代理權人以代理人之名義所為之法律行為，非經本人承認，對於本人不生效力。
> II 前項情形，法律行為之相對人，得定**相當期限**，催告本人確答是否承認，如本人逾期未為確答者，視為拒絕承認。
> **§171**　無代理權人所為之法律行為，其相對人於本人未承認前，得撤回之。但為法律行為時，明知其無代理權者，不在此限。
> **§80**　I 前條契約相對人，得定**一個月以上**期限，催告法定代理人，確答是否承認。II 於前項期限內，法定代理人不為確答者，視為拒絕承認。
> **§943 I**　占有人於占有物上行使之權利，推定其適法有此權利。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「狹義無權代理之三面關係？」 | ① 本人–相對人：§170 效力未定 ② 相對人–無權代理人：§110 損害賠償（筆記 14）③ 本人–無權代理人：內部關係（委任、侵權等） |
| 「本人之權利？」 | **承認權**（有效）／**拒絕承認**（確定不生效力） |
| 「相對人之權利？」 | **催告權**（§170 II，定相當期限，逾期視為拒絕）、**撤回權**（§171，本人未承認前；但為法律行為時明知無代理權者不得撤回） |
| 「§170 II 與 §80 之差別？」 | §80 法定「一個月以上」；§170 II 只說「相當期限」，兩個禮拜法官認為相當也可以 |
| 「相對人得否請求無權代理人履行契約？」 | **不得**。法律行為在甲丙間，乙不是當事人 |
| 「甲借車予乙，乙以甲之代理人名義賣車並交付善意丙，甲拒絕承認，丙得否善意取得？」 | **不得**。無權代理不能善意取得（選擇題常考，好背；要懂理由）。丙的信賴基礎是「乙有代理權」，不是「乙是所有人」；乙占有車的外觀不足以讓人相信乙有代理權，要有 §107／§169 的授權外觀信賴才值得保護 |
| 「無權處分 vs 無權代理的信賴基礎？」 | 無權處分：乙以**自己名義**賣，丙看到乙占有（§943 推定適法有權利）→ 信賴乙是所有人 → 公信 → 善意受讓。無權代理：乙明講「這是甲的車，甲委託我賣」→ 丙最多信賴乙有代理權 → 往代理的保護機制（§107／§169）找，不是 §801＋§948 |

```
            ①本人–相對人：§170 效力未定
   甲（本人）─────────────────────────── 丙（相對人／第三人）
      ╲                                   ╱
  ③內部關係                        ②相對人–無權代理人：
  （委任、侵權…）                   不得請求履行；§110 損害賠償；不能善意取得
        ╲                               ╱
              乙（無權代理人）
```

- 法條有時叫丙「相對人」有時叫「第三人」，只是觀察角度不同。

## 二、本人–相對人：單純法條操作

| 誰 | 權利 | 條文 | 備註 |
|---|---|---|---|
| 本人 | 承認 → 有效；拒絕 → 不生效力 | §170 I | |
| 相對人 | 催告：定**相當期限**，逾期視為拒絕 | §170 II | 跟 §80 長一樣，但 §80 要**一個月以上**（定性規定），這裡不一定 |
| 相對人 | 撤回：本人未承認前 | §171 | 不想等本人就直接撤回；但締約時明知無代理權者不得撤回 |

## 三、相對人–無權代理人

- 不能請求履行：乙不是法律行為當事人。
- 善意相對人：§110 損害賠償（爭點滿滿，筆記 14）。惡意相對人：明知無權代理還做，沒有值得保護之處。

## 四、為什麼無權代理不能善意取得（申論要會論述）

| | 無權處分 | 無權代理 |
|---|---|---|
| 乙用誰的名義 | 自己 | 甲（明講「這是甲的車，甲委託我賣」） |
| 丙看到什麼 | 乙占有 A 車 → §943 推定適法有權利 → 公示外觀 → 公信 | 乙占有 A 車，但乙自己說車是甲的 |
| 丙信賴的是 | **乙是所有人、有處分權** | **乙有代理權** |
| 信賴夠不夠 | 強 → §801＋§948 善意受讓 | 占有不等於授權外觀 → 要 §107／§169 的授權外觀才值得保護 |
| 結論 | 可善意取得 | **不可**：我相信你有代理權 → 應往代理的方向找保護（授權人責任），期待乙把東西處分給我是概念矛盾 |
