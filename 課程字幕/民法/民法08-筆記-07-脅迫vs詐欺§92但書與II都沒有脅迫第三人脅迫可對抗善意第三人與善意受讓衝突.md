# 民法08 筆記：脅迫為什麼不在 §92 I 但書與 §92 II——第三人脅迫善意相對人仍可撤、撤銷可對抗善意第三人；與善意受讓的衝突（王澤鑑 vs 林誠二／鄭冠宇）；§93 脅迫終止後起算

> 來源：民法08 課程字幕 00:43:31 ~ 00:54:37

---

## 📖 法條原文速查

> **§92**
> I 因被詐欺或**被脅迫**而為意思表示者，表意人得撤銷其意思表示。但**詐欺**係由第三人所為者，以相對人明知或可得而知其事實者為限，始得撤銷之。
> II 被**詐欺**而為之意思表示，其撤銷不得以之對抗善意第三人。
> → I 本文有脅迫；I 但書、II 只有詐欺

> **§93**　前條之撤銷，應於發見詐欺或**脅迫終止後**，一年內為之。但自意思表示後，經過十年，不得撤銷。
> **§801＋§948**　善意受讓

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「丙脅迫甲將 A 畫賣予**善意無過失**的乙，甲得否撤銷？」 | **得**。§92 I 但書只限詐欺，第三人**脅迫**不問相對人善惡 |
| 「乙再轉賣善意丁並交付，甲撤銷後得否對丁主張？」 | §92 II 只限詐欺 → 脅迫之撤銷**得對抗善意第三人**（反面解釋）→ 丁不能用 §92 II。丁能否 §801＋§948 善意受讓？**有爭議** |
| 「爭議兩說？」 | **王澤鑑**：善意取得是決定物權歸屬的特別規定，優先 → 丁取得。**林誠二、鄭冠宇**：§92 II 刻意排除脅迫是立法者保護被脅迫表意人的特別目的，「不保護交易安全」才特別 → §92 II 優先 → 丁不能善意取得。**無標準答案，兩說並陳** |
| 「立法者為何區別詐欺與脅迫？」 | 被脅迫者意思自由受侵害程度**遠大於**被詐欺（被騙最終還是自己拿出來的；被脅迫是心不甘情不願）→ 脅迫時表意人保護最優先，相對人與第三人的交易安全可犧牲 |
| 「被脅迫之除斥期間起算？」 | **脅迫終止後**一年（不是發現時——一被脅迫就知道了，要等脅迫停止才敢撤：加害人被關、死亡、中風）；意思表示後十年 |

## 一、條文觀察：脅迫在但書和第二項消失了
```
§92 I 本文：詐欺＋脅迫 → 都可撤
§92 I 但書：只有詐欺 → 第三人詐欺要相對人明知或可得而知
§92 II：只有詐欺 → 詐欺之撤銷不得對抗善意第三人
→ 脅迫：第三人脅迫不管相對人善惡都可撤；撤銷可以對抗善意第三人
→ 立法者有意識：被脅迫太可憐，相對人、第三人的交易安全都可以犧牲
```

| | 被詐欺 | 被脅迫 |
|---|---|---|
| 意思自由受侵害 | 較輕（陷於錯誤後**自己**拿出來） | 較重（心不甘情不願） |
| 第三人為之 | 相對人明知或可得而知才可撤 | 不問相對人 |
| 撤銷對善意第三人 | 不得對抗 | **得**對抗 |

## 二、與善意受讓的正面衝突
```
丙脅迫甲 → 甲賣 A 畫給善意乙 → 乙轉賣善意丁並交付
甲依 §92 撤銷 → 乙丁買賣有效、物權行為無權處分效力未定
丁用 §92 II？✗（脅迫可對抗善意第三人）
丁用 §801＋§948？物權編只問：前手無權處分？是。依法律行為受讓占有？是。善意無重大過失？是 → 取得
→ 民總說保護甲、物權編說保護丁 → 衝突
```

| | 王澤鑑 | 林誠二、鄭冠宇 |
|---|---|---|
| 結論 | 善意取得優先 → 丁取得 | §92 II 優先 → 丁不能善意取得 |
| 理由 | 善意取得是決定物權歸屬的特別規定（從 §87 I 但書到 §92 II 一貫立場） | 民法裡保護交易安全一點都不特別，**不保護**交易安全才特別；§92 II 排除脅迫就是立法者說「這時表意人最重要」，再讓丁善意取得就架空 §92 II |
| 考試 | 兩說並陳，沒有標準答案 | |

### 為什麼會這樣：清末立法把兩套制度都抄進來
- 世界各國保護交易安全有兩種模式：「不得對抗善意第三人」（第三人主張行為有效、限制當事人抗辯）與「善意取得」（直接依法取得）。我國民法兩套都要 → 99% 案件一致，少數情形衝突：債權讓與（只能用不得對抗）、§92 II 脅迫（兩制度目的相反）。

## 三、§93 的起算：脅迫終止後
- 詐欺從「發現」起算；脅迫一被脅迫就發現了，但不敢撤 → 等脅迫**終止**（加害人入獄、死亡、中風、植物人）後一年內；上限意思表示後十年。
