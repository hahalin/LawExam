# 民法27 筆記：降價之亂類推 §245-1 與回復原狀（§213）

## 情境：
- 電信甲公司：上週才辦 **999 元**吃到飽、綁約兩年；這週推出 **499 元**方案、所有人都能辦 → 每月差 500 元，兩年差 12,000 元
- 車商乙公司：上個月以 **300 萬元**買車；一個月後同車款降價 **100 萬元**，業務說是總公司決策
- 剛買的人能主張什麼？

## 消保官常給的兩個建議都不好用（葉啟洲，講義 378 頁）：
- **情事變更（§227-2）**：要件是「**非當時所得預料**」
  - 消費者無法預見，但**企業經營者可以預見**自己要推方案、要降價 → 不符
- **違約金酌減（§252）**：讓消費者以合理違約金解約後重新締約
  - 違約金是否過高，以**締約當時**的狀態判斷，不能因為事後的促銷就說過高 → 也很難

## 葉啟洲：類推 §245-1
- §245-1：締約時**故意隱匿**重要資訊 → 契約**不成立** → 他方受損害
- 降價之亂：締約時**故意隱匿**即將降價的重要資訊 → 契約**成立**（買貴了）→ 消費者受損害
- 兩者都有損害、都有故意隱匿，只差在契約成立與否 → 利益狀態類似，**類推適用**

## 賠償內容不是締約成本，而是回復原狀（§213）：
- **§213 I**：回到契約沒有成立的狀態 → 廢止原契約、**重新締約**（例：還沒交車，把 300 萬元的訂單作廢，改以 200 萬元重訂同一台車）
- **§213 III**：請求回復原狀所必要的費用 → 實質上就是**減價**（300 萬元 → 200 萬元；999 元 → 499 元）

## 老師的評價：
- 理論可以解決問題，但要件不好過：企業經營者對未來促銷到底要揭露到什麼程度？**無須揭露的資訊，就談不上隱匿**
- 價格本來就是商業競爭手段，企業不希望每個人都買最便宜
- 典型適用：業務明說「教材近年不會改版」，一套數萬元賣出後下個月就出新版 → 屬**不實說明**，這套理論走得下去（可減價，或廢止後改買新版）
- 答題時要論述：此情形下企業經營者的**資訊揭露義務**應到什麼程度

## 📖 法條原文速查

> **§245-1 I ①**　契約未成立時，當事人為準備或商議訂立契約而有左列情形之一者，對於非因過失而信契約能成立致受損害之他方當事人，負賠償責任：一、就訂約有重要關係之事項，對他方之詢問，**惡意隱匿或為不實之說明**者。

> **§213**　I 負損害賠償責任者，除法律另有規定或契約另有訂定外，應**回復**他方損害發生前之**原狀**。III 第一項情形，債權人得請求支付回復原狀所必要之費用，以代回復原狀。

> **§227-2 I**　契約成立後，情事變更，**非當時所得預料**，而依其原有效果顯失公平者，當事人得聲請法院增、減其給付或變更其他原有之效果。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「企業突然降價，剛買的消費者可依情事變更請求減價？」 | 難，企業經營者**可預料** |
| 「可否以違約金過高酌減後解約？」 | 難，過高與否以**締約時**判斷 |
| 「葉啟洲的解決路徑？」 | **類推 §245-1**（故意隱匿重要資訊） |
| 「類推後賠償內容？」 | §213 I 廢止重訂；§213 III **減價** |
| 「此說最大困難？」 | 企業經營者有無**揭露義務** |

## 三條路比較

| 路徑 | 卡在哪裡 |
|---|---|
| 情事變更 §227-2 | 企業經營者可預料 |
| 違約金酌減 §252 | 過高與否看締約時 |
| 類推 §245-1 | 資訊揭露義務的範圍 |

```
§245-1 原型：故意隱匿 → 契約不成立 → 受損害
降價之亂：  故意隱匿 → 契約成立（買貴）→ 受損害
                       ↓ 利益狀態類似 → 類推
             損害賠償 = 回復原狀
             ├── §213 I：廢止原約、重新締約
             └── §213 III：請求差額（減價）
```
