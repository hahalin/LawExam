# 民法20 筆記：損害型態與兩年時效之起算點

## 先分「一個行為」還是「行為持續」：
- **一次性**：侵權行為與損害同時發生 → 自損害發生（知悉）時起算，沒有爭議
- **後遺症型**：一個侵害行為，損害陸續冒出 → 自**損害大致底定**時起算（考試最常考）
- **持續不可分**：侵害行為本身持續、從未中斷（無權占有、24 小時排放廢水、持續噪音）→ 自**損害最初發生**時起算，不因侵害持續而延後
- **持續可分**：同類侵害一次又一次（這個月寄騷擾信、下個月再寄）→ 兩說：①當成一件事，自第一次起算 ②**每次獨立、個別起算**（實務傾向）

## 後遺症型為何要等底定：
- 車禍當下只是頭暈，一個月後驗出腦震盪，之後症狀陸續出現
- 若車禍當天就起算，後遺症還在發生，時效已跑了半年 → 對被害人不利
- 損害不再發生、程度「定格」時，才算知有損害

## 持續不可分為何不延後：
- 工廠開始排廢水，一年後才起訴 → 時效已進行一年
- 不能說廢水還在排，時效就一直往後延

## 實務：
- 講義 250 頁註 392：一次加害行為致不斷發生後續損害，該損害不可分或為侵害狀態之延續者，以實際損害程度**底定**、損害顯在化時起算
- 註 393（108 年 778 號判決）：後遺症型依損害底定或侵害行為終止起算；侵權行為持續發生而各損害**各自獨立、可相互區別**者，就各該損害**分別起算**
- 註 394（106 年 187 號判決）：無權占有他人不動產，損害為占有本身，於侵權行為時即已確定，自知悉時起算；**不得因持續占有而謂損害不斷發生**

> 來源：民法20 課程字幕 00:04:14 ~ 00:15:52（講義 250 頁）；判決字號字幕僅唸「108 年 778 號」「106 年 187 號」，法院與字別建議查證

## 📖 法條原文速查

> **§197 I 前段**　因侵權行為所生之損害賠償請求權，自請求權人**知有損害**及賠償義務人時起，二年間不行使而消滅。

## 📋 實務見解速查

> **108 年 778 號判決**（講義註 393）：一次加害致後續損害不斷發生，損害不可分或屬侵害狀態延續者，分別以實際損害程度底定或不法侵害行為終止起算；侵權行為持續發生、各損害各自獨立並可相互區別者，就各該損害分別起算。（要旨改寫）

> **106 年 187 號判決**（講義註 394）：侵奪他人不動產占有，被害人主張之損害為占有本身者，於侵權行為時即已確定，自知悉時起算，不得因加害人持續占有而謂損害不斷發生。（要旨改寫）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「車禍後遺症陸續出現，2 年自車禍時起算？」 | **錯**，自損害**大致底定**時 |
| 「無權占有持續中，時效不進行？」 | **錯**，持續不可分 → 自損害最初發生時起算 |
| 「每月寄一封騷擾信，時效如何起算？」 | 各次可區別 → **個別起算** |
| 「工廠持續排放廢水，時效隨排放延後？」 | **否** |

## 一、四種型態

```
侵害行為 ─────────────── 時間 ──→
一次性      ●＝損害             → 損害發生時
後遺症      ●  ○  ○  ○ ○○ 底定   → 損害大致底定時
持續不可分  ●━━━━━━━━━━━━        → 損害最初發生時
持續可分    ●   ●   ●   ●       → 每一次個別起算（另說：第一次）
```

## 二、判斷順序

| 問題 | 是 | 否 |
|---|---|---|
| 只有一個侵害行為？ | 看損害是否陸續出現 → 後遺症型 | 下一題 |
| 侵害行為中間從未中斷？ | 持續不可分 → 最初發生時 | 持續可分 → 個別起算 |
