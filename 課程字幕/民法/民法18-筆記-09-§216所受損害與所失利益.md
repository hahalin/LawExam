# 民法18 筆記：§216所受損害與所失利益

## 先算總額再殺價：
- 範圍分**一般性規定**（算總額）與**減免性規定**（殺價）
- 先用 §216、§192～§196 算出總額，再談 §216-1 損益相抵、§217 與有過失；順序顛倒邏輯就錯

## §216 與 §192～§196 的體系位置：
- §216 在債編通則「損害賠償之債」→ 債務不履行與侵權行為**都能用**
- §192～§196 **只有侵權行為**能用；債務不履行要用，須有準用規定，例如 **§227-1**（債務不履行侵害人格權，準用 §192～§195、§197）

## 所受損害與所失利益：
- 所受損害＝既有財產**積極減少**；所失利益＝應得而未得，財產**消極不增加**
- 機器遺失：機器價值減少＝所受損害；機器本可創造的獲利＝所失利益
- 所失利益要有**預定計畫**，須說服法官是通常可得的利益，不是想像

## 數字例：
- 房屋被毀損、修復 5 個月；屋主主張本來要出租、月租 2 萬 → 所失利益 **10 萬**
- 證明方式：事故前已在租屋網刊登（10/1 刊登、10/15 受損）→ 可證已有出租計畫

## 📖 法條原文速查

> **§216**　I 損害賠償，除法律另有規定或契約另有訂定外，應以填補債權人所受損害及所失利益為限。II 依通常情形，或依**已定之計劃**、設備或其他特別情事，**可得預期之利益**，視為所失利益。

> **§227-1**　債務人因債務不履行，致債權人之**人格權**受侵害者，**準用**第 192 條至第 195 條及第 197 條之規定，負損害賠償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§192～§196 得否直接適用於債務不履行？」 | **否**，限侵權行為；人格權受侵害時經 **§227-1 準用** §192～§195 |
| 「§216 是否僅適用於侵權行為？」 | **否**，所有損害賠償之債皆適用 |
| 「所失利益之意義？」 | 財產**消極不增加**；依通常情形或已定計劃可得預期之利益 |
| 「計算損害賠償時，應先適用與有過失再計算總額？」 | **錯**，先算總額、再減免 |

## 一、損害賠償範圍兩步驟

```
第一步：計算總額（一般性規定）
├─ §216：所受損害＋所失利益（所有損害賠償之債）
└─ §192～§196：侵權行為特別規定
        ↓
第二步：減免（減免性規定）
├─ §216-1 損益相抵
└─ §217 與有過失（下堂續講）
```

## 二、所受損害 vs 所失利益

| | 所受損害 | 所失利益 |
|---|---|---|
| 性質 | 積極減少 | 消極不增加 |
| 機器遺失 | 機器價值 | 機器可創造之獲利 |
| 房屋毀損 | 房屋價值減損 | 不能出租之租金（須有計畫） |
| 舉證重點 | 財產減少多少 | **預定計畫**（§216 II） |

## 三、適用範圍對照

| 規定 | 侵權行為 | 債務不履行 |
|---|---|---|
| §216 | ✓ | ✓ |
| §192～§195 | ✓ | 侵害人格權時經 §227-1 準用 |
| §196 | ✓ | ✗（無準用） |
