# 民法11 筆記：代理權之消滅——法定代理：§1090 宣告停止親權是「停止」不是消滅，子女成年才真正消滅；意定代理：§108 I 代理權之消滅依其所由授與之法律關係定之（原因關係消滅 → 授權跟著消滅）；§108 II 原因關係存續中得撤回代理權，但依該法律關係之性質不得撤回者除外（律師委任與代理權密不可分）

> 來源：民法11 課程字幕 00:40:30 ~ 00:46:20

---

## 📖 法條原文速查

> **§108**　I 代理權之消滅，依其所由授與之法律關係定之。
> II 代理權，得於其所由授與之法律關係存續中撤回之。但依該法律關係之性質不得撤回者，不在此限。
> **§1090**　父母之一方濫用其對於子女之權利時，法院得依他方、未成年子女、主管機關、社會福利機構或其他利害關係人之請求或依職權，為子女之利益，宣告**停止**其權利之全部或一部。
> **§1086 I**　父母為其未成年子女之法定代理人。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「離婚後約定親權由一方行使，他方之法定代理權消滅？」 | **不消滅**，只是處於**停止**狀態。親權是父母與生俱來的權利，法律不能剝奪，頂多暫停（§1090 濫用親權亦同：宣告停止） |
| 「法定代理權何時真正消滅？」 | **子女成年**等法定事由 |
| 「甲僱用乙並授與代理權，僱傭契約終止，代理權？」 | **隨之消滅**（§108 I：依所由授與之法律關係定之）。原因關係有效時，原因消滅 → 授權消滅 |
| 「僱傭關係繼續中，甲得否單獨撤回對乙之代理權？」 | **得**（§108 II 本文）：事情處理完把代理權收回，僱傭關係繼續 |
| 「當事人委任律師訴訟，得否於委任關係存續中撤回代理權？」 | **不得**（§108 II 但書）：委任律師處理事務必然隱含代理權授與，沒有代理權什麼都做不了 → 委任與代理權**不可分離** |

## 一、法定代理權：停止 vs 消滅

| 事由 | 效果 |
|---|---|
| 離婚後協議由一方行使親權 | 他方親權**停止**，不是消滅 |
| §1090 濫用親權經法院宣告 | **停止**全部或一部 |
| 子女成年 | 法定代理權**消滅** |

- 身分法再細看；民總只要記得 §1090 是停止不是消滅。

## 二、意定代理：§108 兩項

```
有原因關係（僱傭、委任等）的授權
§108 I：原因關係消滅 → 代理權跟著消滅（生命共同體）
§108 II：原因關係還在，能不能單獨撤回代理權？
         原則 → 可以（員工事情辦完，收回代理權、僱傭繼續）
         但書 → 依法律關係之性質不得撤回者除外：律師委任（委任必含代理權授與，拆不開）
```

## 三、下一筆記

- 沒有原因關係、或原因關係無效／不成立時，**還能不能授權**？→ 有因說 vs 無因說（筆記 06）。那不是 §108 在管的問題。
