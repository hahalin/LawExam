# 民法06 筆記：對話 §94 瞭解主義 vs 非對話 §95 到達主義——「到達」的定義、風險分配與誠信原則

> 來源：民法06 課程字幕 00:18:07 ~ 00:30:00

---

## 📖 法條原文速查

> **§94**（對話意思表示之生效）
> 對話人為意思表示者，其意思表示，以相對人**瞭解時**，發生效力。

> **§95**（非對話意思表示之生效）
> I 非對話而為意思表示者，其意思表示，以通知**達到**相對人時，發生效力。但撤回之通知，同時或先時到達者，不在此限。
> II 表意人於發出通知後死亡或喪失行為能力或其行為能力受限制者，其意思表示，不因之失其效力。

> **§440 I**（租金支付遲延之終止）
> 承租人租金支付有遲延者，出租人得定相當期限，**催告**承租人支付租金，如承租人於其期限內不為支付，出租人得終止契約。

> **§148 II**　行使權利，履行義務，應依**誠實及信用方法**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「對話意思表示何時生效？」 | 相對人**瞭解**時（§94 瞭解主義） |
| 「非對話意思表示何時生效？」 | 通知**到達**相對人時（§95 I 到達主義） |
| 「對話與非對話如何區分？」 | **即時性、有無留下紀錄**：面對面、電話、Skype → 對話；信件、Email、LINE 文字、**LINE 語音訊息** → 非對話 |
| 「LINE 語音訊息是對話還是非對話？」 | **非對話**（會留在手機裡，隨時可點開聽） |
| 「『到達』之意義？」 | 置於相對人**隨時可瞭解之地位**（通說、最高法院），不以實際閱讀為必要 |
| 「出租人口頭向聽不懂中文的韓籍承租人催告繳租？」 | 對話 → 相對人未**瞭解** → 催告不生效 → 不得依 §440 終止 |
| 「人事主管將解僱通知偷塞在員工桌上文件夾？」 | 形式上「隨時可瞭解」，但**違反誠信原則** → 不認為到達（陳聰富） |
| 「相對人故意不放傳真紙致未收到？」 | 客觀上未到達，但相對人違反誠信 → **擬制到達**（陳聰富） |

## 一、對話 vs 非對話：看有沒有時間差

| | 對話 §94 | 非對話 §95 |
|---|---|---|
| 特徵 | **即時**、不留紀錄：面對面、電話、Skype 通話 | **有時間差**、會留紀錄：信件、Email、LINE 文字、LINE 語音訊息 |
| 生效 | 相對人**瞭解**時 | 通知**到達**時 |

- 語音訊息是用嘴巴講，但它會「留在對方手機裡隨時可點開」→ 非對話。

### 對話的案例：韓國學生
```
房東路上遇到韓籍房客（中文不好）口頭說「該繳房租了」
→ 對話意思表示 → 他瞭解了嗎？聽不懂 → 不生催告效力
→ §440 的「催告」要件不備 → 不能終止租約
```

## 二、「到達」＝置於相對人隨時可瞭解之地位

### 為什麼不用「瞭解」切，而用「到達」切：風險分配
```
寄出 ──（郵差運送）──→ 到達相對人家門口 ──→ 相對人打開 ──→ 瞭解內容
      表意人承擔：寄不到的風險           相對人承擔：沒看到的風險
                                        （家人丟掉、狗咬爛、沒開信箱）
前提：內容必須是相對人「可瞭解」的 → 寄中文信給看不懂中文的人，到了也沒用
```
- 若像 §94 一樣要相對人瞭解才生效，表意人要承擔「信到你手上你卻看不懂／不看」的所有風險 → 太重 → §95 在**到達**這個時點切開。

## 三、輔助判準：誠信原則（陳聰富）

| 情境 | 客觀上 | 誠信 | 結論 |
|------|------|------|------|
| 人事主管不好意思當面解僱老員工，把解僱通知**偷塞在他桌上某個文件夾** | 「他打開就看得到」→ 似乎隨時可瞭解 | 顯然違反 | **不認為到達** |
| 對方律師說「下午 3 點前沒收到和解條件就破局」，你傳真過去，對方**故意不放紙** | 沒放紙 → 未置於可瞭解地位 | 相對人故意阻撓 | **擬制到達** |

- §95 的到達是客觀判斷，但要**輔以誠信原則**才完整；台大法研所考過。
