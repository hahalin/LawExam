# 民法02 筆記：§16 §17 不得拋棄與人格權 §18、不法性的利益衡量

> 來源：民法02 課程字幕 00:35:33 ~ 01:01:43

---

## 📖 法條原文速查

> **§16**（能力之保護）
> 權利能力及行為能力，**不得拋棄**。

> **§17**（自由之保護）
> I 自由**不得拋棄**。
> II 自由之**限制**，以**不背於公共秩序或善良風俗**者為限。

> **§18**（人格權之保護）
> I 人格權受侵害時，得請求法院**除去**其侵害；有受侵害**之虞**時，得請求**防止**之。
> II 前項情形，以**法律有特別規定**者為限，得請求損害賠償或慰撫金。

> **§195 I 前段**（特別人格權的列舉）
> 不法侵害他人之**身體、健康、名譽、自由、信用、隱私、貞操**，或不法侵害**其他人格法益而情節重大**者，被害人雖非財產上之損害，亦得請求賠償相當之金額。

## 📋 實務見解速查

> **104 年 1383 號判決**（整形診所案，講義註 51；經最高法院維持）：不法性之認定採**利益衡量原則**，就被侵害之法益、加害人之權利及社會公益等，依**比例原則**為判斷；倘衡量結果對加害人之行為不足以正當化，其侵害始具不法性。
> → 建議查閱判決字號全稱

> **112 年台上字第 965 號判決**（米其林案，講義 48 頁註）：餐廳拒絕評鑑屬**契約自由**，米其林評鑑屬**言論自由**；美食資訊流通對社會有益，言論自由優先 → 評鑑**無不法性**，請求撤下評鑑無理由。
> → 建議查閱判決原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲與乙約定甲拋棄行為能力、自願受乙支配？」 | **無效**。§16 強行規定 |
| 「自由可否拋棄？可否限制？」 | **不得拋棄；得限制**，但以不背於公序良俗為限（§17） |
| 「§18 I 請求除去或防止，須加害人有故意過失？」 | **不須**。§18 要件只有三個：人格權受侵害、因果關係、不法性 |
| 「居住安寧權、遺族追思權、肖像權是人格權嗎？」 | **是**，屬**一般人格權**（§195 未列舉，但最高法院承認） |
| 「§18 I 的除去／防止，須區分一般或特別人格權？」 | **不須**，只要是人格權即可。區分只在 §195 慰撫金那一關 |
| 「人格權侵害之不法性如何判斷？」 | **利益衡量**（比例原則）：被侵害法益 vs 加害人權利 vs 社會公益 |
| 「§18 II 損害賠償、慰撫金之請求依據？」 | 要**法律有特別規定**（§184、§195 等），§18 本身不是請求權基礎 |

## 一、§16 §17：為什麼民法要突兀地規定「不得拋棄」

```
羅馬法：人 ─┬─ 自然人（權利主體）
            └─ 奴隸（權利客體，受支配）
      ↓ 天賦人權、人皆生而平等
為了避免奴隸制度復活 → §16 權利能力、行為能力不得拋棄（維護人性尊嚴第一步）
                      → §17 自由不得拋棄
```
- 「我簽約拋棄權利能力、自願受你支配」→ 違反強行規定 → **無效**。
- 自由**可以限制**，但限制不得背於公序良俗 → 怎麼判斷？**利益衡量**。

### 案例：紅衣恐慌症（早期考題、轉學考偏好；近 10~20 年國考少見）
```
甲看到紅色會恐慌發作，同事乙故意天天穿紅色在旁晃
甲請求法院禁止乙「上班時間」穿紅衣

衡量：
  限制乙的法益：只限上班時間穿紅衣的自由（下班隨便）→ 限制不大
  保護甲的法益：身體健康權（不致恐慌發作、能正常工作）→ 保護大
→ 這種限制可能不背於善良風俗 → 個案認定
```

## 二、人格權的概念與分類

- **定義**（考試要會寫）：以**維護人性尊嚴、貫徹人的存在價值**所必要之權利。

```
人格權
├── 特別人格權：法有明文（§195 I 列舉：身體、健康、名譽、自由、信用、隱私、貞操）
└── 一般人格權：法無明文，但維護人性尊嚴所必要，最高法院判決承認
      例：居住安寧權（噪音逾一般人容忍程度）、遺族追思權、肖像權……
```
- 民法找不到 ≠ 不存在。居住安寧不在 §195 列舉，但難道不重要？→ 一般人格權。
- 分類的實益在**慰撫金**那一關（見「人格權損害賠償」筆記）；§18 I 除去／防止**不分**。

## 三、§18 的保護架構：事前 vs 事後

```
人格權受侵害
├── 事前救濟：§18 I 後段 → 損害防止請求權（有受侵害之虞 → 請求防止；「將來不要再做」）
└── 事後救濟
      ├── §18 I 前段 → 除去請求權（「刪文」）
      ├── 損害賠償 → §184 ＋ §195 等（§18 II：須法律有特別規定）
      └── 不當得利 → 人格權具財產價值時（學者見解）
```

### §18 I 的要件：三個，沒有故意過失
```
① 人格權受侵害
② 因果關係（該行為造成侵害）
③ 不法性（隱藏要件：「侵害」一詞本身含負面評價 → 值得非難 → 不法）
```
- 為什麼不要故意過失？人格權保護人性尊嚴，對方沒過失難道你就要被踐踏？
- 最難的是 ③ 不法性 → 通說採**利益衡量**。

## 四、不法性的利益衡量：兩個案例（姚志明老師文章，講義 45 頁）

### 案例一：整形診所案
#### 事實
1. A 整形診所的見證廣告人物，其實就是診所護士乙（自己見證自己）。
2. 甲發現後到診所拍護士照片，PO 文比對、揭露造假。
3. 乙主張：§18 I 前段請求刪文；§184 + §195 請求慰撫金。

#### 分析
```
① 肖像權受侵害：未經同意拍照上網 → 有
② 因果關係：拍照 PO 文行為 → 有
③ 不法性：利益衡量
     乙的損害：肖像被公開
     甲的利益：言論自由 ＋ 公益（醫美資訊封閉、資訊落差大，公開有助大眾選擇）
   → 公開之利益 > 乙之損害 → 行為正當化 → 無不法性
```
#### 結論
- 法院：無不法性，請求無理由。姚志明老師贊同（醫療資訊落差領域，資訊公開更有公益價值）。

### 案例二：米其林案
#### 事實
餐廳不想被米其林評鑑，請求撤下評鑑結果。

#### 分析
| | 法院（高院、最高法院 112 台上 965） | 姚志明老師 |
|---|---|---|
| 餐廳的權利 | 契約自由（選擇締約對象） | 不受評鑑的自由 |
| 米其林的權利 | 言論自由 | — |
| 衡量 | 言論自由 > 契約自由；美食資訊流通對社會有益 → **無不法性** | 應區分：**公益性評鑑**（消防、食安稽查）不能拒絕；**私益評鑑**（好不好吃）與公益無關，契約自由應更受保障 → 可以拒絕 |

- 老師個人傾向姚志明老師的區分說。
- 共同點：都是在做**不法性＝利益衡量**的操作。

## 關鍵法條速查表

| 法條 | 內容 | 與本主題關聯 |
|------|------|------------|
| **§16** | 權利能力、行為能力不得拋棄 | 人性尊嚴、反奴隸 |
| **§17** | 自由不得拋棄；限制不得背於公序良俗 | 利益衡量的第一個場景 |
| **§18 I** | 除去（前段）／防止（後段） | 本筆記核心；要件無故意過失 |

| §195 I | 特別人格權列舉；其他人格法益情節重大 | 一般／特別人格權的分界 |
