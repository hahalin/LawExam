# 民法07 筆記：善意第三人再轉手給惡意的丁——前手有權處分，後手善惡意、有償無償都不問；交易安全不限於有償行為

> 來源：民法07 課程字幕 00:12:00 ~ 00:17:38（講義 164 頁「自善意第三人受讓標的物之惡意第三人」）

---

## 📖 法條原文速查

> **§87 I 但書**　但不得以其無效對抗善意第三人。
> **§801**、**§948**　動產善意受讓（民法06 筆記 11）
> **§761 I**　動產物權之讓與，非將動產交付，不生效力。
> **§767 I 前段**　所有人對於無權占有或侵奪其所有物者，得請求返還之。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲乙通謀虛偽移轉 A 車，乙賣給善意丙，丙再**贈與**明知甲乙通謀的丁並交付，甲得否對丁依 §767 請求返還？」 | **不得**。丙已善意取得（或依 §87 I 但書取得）→ 丙是所有人 → 丙→丁是**有權處分** → 丁取得所有權，**善惡意、有償無償均不問** |
| 「何時才討論後手之善惡意？」 | 只有**前手無權處分**時，為保護後手交易安全才討論；前手有權處分 → 沒有交易安全問題 → 不討論 |
| 「贈與是無償契約，不涉及交易安全？」 | **錯**。交易安全指**法律行為有效性**的安全，所有財產行為（有償、無償、債權、物權）都涉及，只是強弱不同；**身分行為**才無交易安全 |

---

## 一、陷阱題的結構

```
甲 ──通謀虛偽──→ 乙 ──賣給善意丙──→ 丙 ──送給【惡意】丁並交付──→ 丁
甲：丁知道我們通謀，我可以用通謀無效對抗丁，車還我（§767）？
```

## 二、分析：到丙那一手就終局確定了

```
甲乙：通謀虛偽 → 債權、物權行為無效 → 乙未取得
乙丙：買賣有效；物權行為無權處分 → 丙善意 → §801＋§948 善意受讓（或 §87 I 但書）→ 丙【終局取得】A 車所有權
丙丁：丙是所有人 → 丙→丁的債權行為、物權行為都有效 → 【有權處分】
    → 丁取得所有權，跟丁善意惡意一點關係都沒有
→ 甲對丁 §767 ✗（甲早就不是所有人）
```

### 為什麼不能讓丁拿不到
- 若丁因惡意拿不到 → 丁回頭告丙債務不履行 → 丙：這是我的東西，我要移轉卻移轉不過去，就因為他惡意？不合理。
- 既然是丙的東西，要移轉給誰是丙的自由。

## 三、兩個觀念

| 觀念 | 內容 |
|------|------|
| ① 善惡意只在前手無權處分時討論 | 討論後手善惡意的目的是「保護後手的交易安全」，前提是前手無權處分。前手有權處分 → 後手不管善惡、有償無償，都安全取得 |
| ② 交易安全 ≠ 有償 | 「交易」不是狹義的買賣，是**法律行為的有效性**。買賣、租賃、借貸、贈與、所有權移轉、抵押權設定……只要是法律行為都有交易安全介入，有償強一點、無償弱一點，但不會「贈與就沒有交易安全」。沒有交易安全的是**身分行為** |

- 老師改集訓班考卷常見錯誤：「贈與契約是無償契約，並非交易，不涉及交易安全之保護」→ 完全錯誤。
