# 民法08 筆記：第三人利益契約的被詐欺——相對人善意、受益人惡意時能不能撤：我國文義不能，王澤鑑參考德國民法 §123 II 以「真正受益人」為準

> 來源：民法08 課程字幕 00:22:50 ~ 00:27:30（講義 191 頁）

---

## 📖 法條原文速查

> **§92 I 但書**　詐欺係由第三人所為者，以**相對人**明知或可得而知其事實者為限，始得撤銷之。
> **§269 I**（第三人利益契約）以契約訂定向第三人為給付者，要約人得請求債務人向第三人為給付，其第三人對於債務人，亦有直接請求給付之權。
> **德國民法 §123 II**（講義 191 頁）意思表示相對人以外之人，因意思表示而直接取得權利者，以該取得人對於詐欺明知或可得而知者為限，得對之撤銷意思表示。→ 建議查閱講義原文

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「乙詐欺甲使甲誤以為真跡為仿作而低價出售，甲與**善意的丙**訂立第三人利益契約，約定向**明知詐欺的丁**給付，甲得否撤銷？」 | 依我國 §92 I 但書文義：相對人是丙、丙善意 → **不得撤銷** → 丁雖惡意仍取得。**王澤鑑**：參考德國民法 §123 II，應以**真正受有利益之人（丁）**是否明知或可得而知為準 → 丁惡意 → **得撤銷** |
| 「理由？」 | §92 I 但書保護的是相對人的交易安全，相對人通常就是受益人；當相對人未受益、第三人受益時，應問**丁的交易安全有無保護價值** |

---

## 一、案例結構
```
乙詐欺甲（畫是真的，騙他是仿作）
甲 ──買賣，第三人利益契約──→ 丙（相對人，善意、什麼都不知道）
                約定：甲直接對丁給付，丁有直接請求權
丁（受益人）：知道乙詐欺甲
```

## 二、依我國條文解
```
甲的意思表示對象＝丙 → 丙是相對人 → 丙善意 → §92 I 但書 → 甲不能撤
→ 法律行為有效 → 丁即使惡意也取得標的物
→ 畫拿不回來
```

## 三、王澤鑑：看終局受益的人
```
德國民法 §123 II：相對人以外之人因意思表示直接取得權利者，以該取得人明知或可得而知為限，得撤銷
→ 本案終局得利的是丁，不是丙 → 判斷標準應該是丁，不是丙
→ 丁惡意 → 甲可以撤
```
- 立論：§92 I 但書的目的是保護相對人的交易安全，因為相對人通常就是受益人；當相對人（丙）沒有受益、而第三人（丁）受益時，該問的是丁的交易安全有沒有保護價值。
- 老師：這是比較特別的例子，第三人利益契約本身留到債總。
