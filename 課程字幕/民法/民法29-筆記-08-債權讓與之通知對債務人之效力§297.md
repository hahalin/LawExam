# 民法29 筆記：債權讓與之通知對債務人之效力（§297）

## 角色：
- 甲＝讓與人（原債權人）；乙＝債務人；丙＝受讓人
- 老師提示：選擇題**非常喜歡考** §297

## 有通知（或提示讓與字據）：
- 通知可由**讓與人或受讓人**為之；受讓人提示讓與字據，與通知同效（§297 II）
- 對乙而言，債權人已經是**丙**
- 丙向乙請求 → 乙**不得拒絕**
- 甲向乙請求 → 乙**得拒絕**
- 乙仍對甲清償 → **不生清償效力**，債權沒有消滅，丙仍可向乙請求
  - 乙向甲請求返還：**過失**（例：六年前收到銀行讓與給資產管理公司的通知，忘了）→ 可依 §179 請求
  - **故意**（明知無給付義務）→ §180 ③，**不得**請求返還
- 乙對丙清償 → 有效，債之關係消滅

## 沒有通知：
- 「對於債務人不生效力」是**相對**的：只對乙不生效力，甲丙之間仍有效
- 結果是「一個債權、各自表述」：
  - 對乙：債權人還是**甲**
  - 對甲丙：債權人已經是**丙**
- 甲向乙請求、或乙主動對甲清償 → 乙是向「對的人」清償，**債務消滅**
- 丙不能再向乙請求，只能對甲主張 **§179**

## 兩個陷阱（判例）：
- **受讓人直接請求＝兼有通知**：§297 允許受讓人通知，丙找上門向乙請求時，就足以使乙知道讓與事實（22 上 1162）
- **債務人已知情＝等同通知**：通知只是**觀念通知**，目的是讓債務人知道、免得誤向原債權人清償；乙既已知悉，不得以未通知為由拒絕（39 年判例）

## 有無通知的對照：
| 情形 | 有通知 | 沒有通知 |
|---|---|---|
| 丙向乙請求 | 乙不得拒絕 | 原則得拒絕，但請求本身兼有通知 |
| 甲向乙請求 | 乙得拒絕 | 乙給付，債務消滅 |
| 乙對甲清償 | 不生效力，丙仍可請求 | 有效，債務消滅 |
| 不當得利 | 乙 → 甲（故意則 §180 ③ 排除） | 丙 → 甲 |

> 來源：民法29 課程字幕 01:36:28 ~ 01:48:51（39 年判例之字號字幕未提，建議查證）

## 📖 法條原文速查

> **§297**
> I 債權之讓與，非經**讓與人或受讓人通知**債務人，**對於債務人不生效力**。但法律另有規定者，不在此限。
> II 受讓人將讓與人所立之讓與字據**提示**於債務人者，與通知有同一之效力。

> **§180 ③**　因清償債務而為給付，於給付時**明知無給付之義務**者，不得請求返還。

---

## 📋 實務見解速查

> **22 上 1162 判例**（講義 591 頁）：§297 I 之本旨，無非使債務人知有債權讓與之事實。受讓人對債務人主張受讓事實行使債權時，既足使債務人知有債權讓與之事實，即應認為**兼有通知之效力**。

> **39 年判例**（講義 591 頁）：此項通知不過為**觀念通知**，使債務人知有債權移轉之事實，免誤向原債權人清償而已。債務人**既已知**債權讓與之事實，自不得藉口未經通知而拒絕。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「誰可以為債權讓與之通知？」 | **讓與人或受讓人** |
| 「未通知，債權讓與效力？」 | 僅**對債務人**不生效力，讓與人與受讓人間仍有效 |
| 「已通知，債務人仍向原債權人清償？」 | **不生清償效力**，受讓人仍得請求 |
| 「未通知，債務人向原債權人清償？」 | 債務**消滅**；受讓人向讓與人請求不當得利 |
| 「受讓人未通知即直接請求，債務人得否拒絕？」 | **不得**，請求兼有通知效力（22 上 1162） |
| 「債務人已知讓與，但未受通知？」 | 不得以未通知拒絕（39 年判例） |
| 「通知的性質？」 | **觀念通知** |

## 流程圖

```
甲把 A 債權讓與丙
├── 有通知乙（或提示字據、丙直接請求、乙已知情）
│     債權人＝丙
│     乙 → 甲清償：無效 → 丙仍可請求；乙 → 甲 §179（明知則 §180 ③）
└── 未通知乙
      對乙：債權人仍是甲；對甲丙：債權人是丙
      乙 → 甲清償：有效 → 丙 → 甲 §179
```
