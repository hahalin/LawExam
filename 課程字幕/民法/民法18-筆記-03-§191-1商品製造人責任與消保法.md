# 民法18 筆記：§191-1商品製造人責任與消保法

## 三個推定：
- §191-1 但書與 §191 結構相同：生產製造加工設計**無欠缺**（阻卻不法）、損害**非因**欠缺所致（因果不存在）、已盡**相當注意**（無過失）→ 推定不法、因果、過失
- 以**通常使用或消費**為前提：電風扇正常運轉中爆炸算；把手指伸進扇葉不算。使用＝用了物還在（車），消費＝用了就耗盡（保養品）

## 保護對象與純粹經濟上損失：
- 「他人」不限買受人，凡因商品通常使用消費受波及者皆可
- 用語是「所致他人之損害」，不是「權利」：王澤鑑認為只是舉證責任倒置，不得突破 §184 絕對權／純粹經濟上損失之區分；林誠二、孫森焱（參與 89 年增訂）認為是**有意擴大**保護法益，包含純粹經濟上損失
- 考試最愛：洗手檯爆炸（商品自傷）能否依 §191-1 請求——取決於上述爭議

## 責任主體：
- 實質製造人、**形式製造人**（貼牌，如委託代工的保溫瓶印自家 logo）、**輸入業者**（§191-1 IV，水貨）
- **不含經銷商**：民法上不能對經銷商主張 §191-1

## 消保法 §7～§9：
- 前提：被告須為**企業經營者**；私人間買賣無消保法
- §7：**無過失責任**，證明無過失只能**減輕**、不能免除；多數說不含純粹經濟上損失（「財產」解為權利）
- §7 保護「消費者或第三人」：實務要求第三人須企業經營者**可預見**；詹森林認為任何**無辜旁觀者**皆包括（洗選水果機捲入 1 歲半幼童案）
- §8 經銷商：與製造者**連帶**，但屬**推定過失**，證明已盡相當注意即免責
- §9 輸入業者：責任同 §7 製造者

## 📖 法條原文速查

> **§191-1**　I 商品製造人因其商品之**通常使用或消費**所致**他人之損害**，負賠償責任。但其對於商品之生產、製造或加工、設計**並無欠缺**或其損害**非因該項欠缺所致**或於防止損害之發生，**已盡相當之注意**者，不在此限。
> II（要旨）在商品上附加標章或文字符號，足以表彰係其自己所生產製造加工者，**視為**商品製造人。IV（要旨）商品**輸入業者**應與商品製造人負同一之責任。（原文請對六法）

> **消保法 §7**（要旨）　I 設計、生產、製造商品或提供服務之企業經營者，應確保商品或服務符合當時科技或專業水準可合理期待之**安全性**。III 違反致生損害於**消費者或第三人**時，應負連帶賠償責任；但能證明其無過失者，法院**得減輕**其賠償責任。（原文請對六法）

> **消保法 §8 I**（要旨）　從事經銷之企業經營者，就商品或服務所生之損害，與設計、生產、製造商品或提供服務之企業經營者**連帶負賠償責任**；但其對於損害之防免已盡相當之注意，或縱加以相當之注意而仍不免發生損害者，不在此限。（原文請對六法）

> **消保法 §9**（要旨）　輸入商品或服務之企業經營者，視為該商品之設計、生產、製造者或服務之提供者，負本法第七條之製造者責任。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「消費者得否依 §191-1 向經銷商請求？」 | **否**，§191-1 不含經銷商；經銷商責任在**消保法 §8** |
| 「貼牌商品（委託代工、印自家標章），標章業者是否為商品製造人？」 | **是**，形式製造人（§191-1 II 視為） |
| 「平行輸入業者是否負 §191-1 責任？」 | **是**，與製造人負同一責任（§191-1 IV） |
| 「消保法 §7 企業經營者證明無過失，得否免責？」 | **否**，法院僅**得減輕** |
| 「消保法 §8 經銷商證明已盡相當注意，得否免責？」 | **得**，推定過失責任 |
| 「§191-1 之『他人』限於買受人？」 | **否**，任何受波及者 |
| 「私人間出售自製物品致損害，有無消保法 §7？」 | **無**，須企業經營者 |

## 一、§191-1 構成要件拆解

```
商品製造人（實質／形式／輸入業者；不含經銷商）
   ↓ 商品之通常使用或消費
所致他人之損害（他人不限買受人）
   ↓
負賠償責任 ← 但書三推定：不法、因果、過失
```

## 二、純粹經濟上損失爭議（§191-1）

| | 否定說 | 肯定說 |
|---|---|---|
| 代表 | 王澤鑑 | 林誠二、孫森焱 |
| 理由 | §191-1 只是舉證責任倒置，保護法益同 §184；過失之純粹經濟上損失不能求償，故意回 §184 I 後段 | 89 年本土增訂，故意不用「權利」而寫「損害」，意在擴大保護法益 |
| 商品自傷（洗手檯爆炸） | 回契約法處理 | 可依 §191-1 請求 |

- §190、§191 是民國 19 年承襲德國法，用德國概念解釋沒有問題；§191-1～§191-3 是 89 年增訂，背景不同，這是肯定說的切入點

## 三、民法 §191-1 vs 消保法 §7～§9

| 比較 | 民法 §191-1 | 消保法 §7（製造） | 消保法 §8（經銷） | 消保法 §9（輸入） |
|---|---|---|---|---|
| 被告身分 | 不限 | 企業經營者 | 企業經營者 | 企業經營者 |
| 歸責 | 推定過失 | **無過失責任** | 推定過失 | 同 §7 |
| 證明無過失 | 免責 | **僅得減輕** | 免責 | 僅得減輕 |
| 經銷商 | ✗ | — | ✓ 連帶 | — |
| 保護對象 | 他人 | 消費者或第三人 | 同左 | 同左 |

## 四、§7「第三人」範圍：洗選水果機案

#### 事實
1. 農用洗選水果機（邊注水邊攪動分級），父母在旁工作
2. 一歲六個月幼童好奇觸摸，被捲入受傷，請求設計製造者依消保法 §7 負責

#### 爭點與見解
- 企業經營者抗辯：機器設計給農民用，無從預見幼童接觸，不可能為其設計安全機制
- **實務**：第三人須以企業經營者**可預見**為前提 → 幼童非 §7 之第三人
- **詹森林**：貫徹消保法保護消費者及第三人之目的，任何**無辜旁觀者**皆屬之 → 幼童得請求
