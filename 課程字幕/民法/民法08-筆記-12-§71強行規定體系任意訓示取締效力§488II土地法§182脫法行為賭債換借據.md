# 民法08 筆記：§71 強行規定的體系——任意／訓示／取締／效力規定；§488 II 的「得」其實是不得限制；土地法 §182 是任意規定；脫法行為（賭債換借據）與王澤鑑的批評

> 來源：民法08 課程字幕 01:53:52 ~ 02:14:00（講義註 163、165、179）

---

## 📖 法條原文速查

> **§71**　法律行為，違反**強制或禁止**之規定者，無效。但其規定**並不以之為無效**者，不在此限。
> **§488 II**　僱傭未定期限，亦不能依勞務之性質或目的定其期限者，各當事人**得**隨時終止契約。但有利於受僱人之習慣者，從其習慣。
> **§422-1**　租用基地建築房屋者，承租人於契約成立後，**得**請求出租人為地上權之登記。
> **土地法 §102**　租用基地建築房屋，應由出租人與承租人於契約訂立後二個月內，聲請該管直轄市或縣（市）地政機關為地上權之登記。
> **土地法 §182**　土地所有權之移轉為絕賣者，其增值稅向出賣人徵收之；如為繼承或贈與者，其增值稅向繼承人或受贈人徵收之。
> **證券交易法 §60**（證券商不得借貸款項予客戶等）→ 建議查閱
> → 以上條文請對最新六法

## 📋 實務見解速查（字號請對講義）

> 註 163（最高法院 102 年台上字判決）：不定期契約之勞工以單方意思表示終止契約，為形成權之行使，無待對方同意或核准即生效力，此為勞工之權利，**不得以勞僱雙方特約**約定須俟主管核准始生效力加以限制；縱有此特約，亦違反法令而無效。
> 註 165：土地增值稅依土地法 §182 應由出賣人繳納，但此為國家順利課稅之規定；出賣人在公法上有納稅義務，買賣當事人間基於私法自治，就增值稅由何人負擔**不妨另行約定**。
> 註 179（最高法院 44 年台上字判例）：賭博為法令禁止之行為，因該行為所生之債原無請求權可言；縱使雙方同意以新債清償方式變更為負擔他項新債務，**亦屬脫法行為**，不能因之取得請求權。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律規定之分類？」 | **任意規定**（無拘束力，得做得不做）、**訓示規定**（建議性質，違反仍有效）、**取締規定**（有拘束力，違反受罰但行為仍有效，§71 但書）、**效力規定**（違反無效，§71 本文）；強行規定分強制與禁止 |
| 「土地法 §102 二個月內登記地上權？」 | **訓示規定**。§422-1 請求權時效 15 年，§102 只是建議趕快辦 |
| 「證券商違反證交法借錢給客戶，消費借貸效力？」 | **有效**（取締規定），證券商受罰，客戶仍須還錢 |
| 「特約排除 §488 II 之隨時終止權（須主管核准始得離職）？」 | **無效**。§488 II 雖用「得」，通說認其本質是**不得限制** → 禁止規定 |
| 「約定土地增值稅由買受人負擔？」 | **有效**。土地法 §182 為便利課稅之**任意規定**，有人繳即可 |
| 「賭債改簽借據、本票，債權人依消費借貸或票據請求？」 | 實務：**脫法行為**，不能取得請求權（44 年判例）。王澤鑑：這是**法律解釋問題**（債務性質更改著重同一性，原無效債務不因更改而有效），不必另造「脫法行為」理論 |
| 「賭場先借錢給客人再讓他賭？」 | 老師：目前看是單純消費借貸，借錢去賭是你家的事，難認不合法（實務的進化） |

## 一、四種規定
| 類型 | 拘束力 | 違反的效果 | 例 |
|------|------|------|-----|
| 任意規定 | 無 | — | 條文「得……」；土地法 §182 |
| 訓示規定 | 無（建議） | 行為仍有效 | 土地法 §102 二個月內登記 |
| 取締規定 | 有 | 行為**仍有效**，但受罰（§71 但書） | 證交法 §60 證券商借款給客戶 |
| 效力規定 | 有 | 行為**無效**（§71 本文） | 一般強制、禁止規定 |

## 二、兩個考過的條文：字面會騙人
### §488 II「得隨時終止」
```
特約：僱傭無期限，但受僱人不得任意終止／須主管核准才生效
§488 II 寫「得」→ 看起來是任意規定 → 特約排除應該可以？
通說：這個「得」是給受僱人的權利，本質是【不得限制】→ 禁止規定 → 特約違反 → §71 無效
註 163：勞工終止是形成權，不待核准即生效，特約限制無效
```
### 土地法 §182 增值稅向出賣人徵收
```
條文沒有應、得、不得 → 從立法目的解釋
目的：國家順利課稅 → 誰繳都一樣 → 沒約定就向出賣人收
→ 任意規定 → 約定由買受人負擔 → 有效（註 165）
```

## 三、脫法行為
```
甲欠乙賭債 100 萬 → 賭債非債（賭博違反強行規定，請求權無效）→ 乙告不贏
乙：那你簽借據／本票給我，變成借款債務、票據債務 → 請求權基礎變成消費借貸、票據 → 形式上合法
最高法院：用合法行為掩護非法行為、規避法律 → 【脫法行為】→ 新的借款、票據債務也無效（44 年判例）
```

| | 最高法院 | 王澤鑑 |
|---|---|---|
| 結論 | 無效 | 無效（結論相同） |
| 方法 | 另立「脫法行為」理論 | **法律解釋**就夠了：賭債變票據債務是**債務性質更改**，著重債務**同一性** → 原本無效的債務不因更改而變有效。「最高法院不要偷懶，好好解釋法律，不要直接丟脫法行為」 |

### 實務的進化：賭場先借錢
- 現在賭場不把賭債換成借據，而是**先借你 100 萬**（純消費借貸，借了不一定要玩）→ 你拿去賭輸 → 還是要還借款。澳門賭場來台告借款就是這種。老師：就現在的法律解釋看，單純借錢還錢，借錢去玩是你家的事，將來會不會認為不合法另說。
