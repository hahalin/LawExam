# 民法11 筆記：乙無權代理甲與丙締約，效力未定中甲死亡、乙為唯一繼承人——承認權可否繼承：通說可（§1148，承認權非一身專屬）；繼承後可否拒絕承認：身分法多數說（戴東雄等）基於誠信原則（禁反言）不得拒絕 → 契約強制有效、乙負履行義務；林秀雄：可拒絕——法無明文，且強制有效反而剝奪丙 §171 撤回權，乙拒絕時丙仍有 §110

> 來源：民法11 課程字幕 00:59:00 ~ 01:08:00（民總與身分法交界，考試出現過）

---

## 📖 法條原文速查

> **§1148 I**　繼承人自繼承開始時，除本法另有規定外，承受被繼承人財產上之一切權利、義務。但權利、義務專屬於被繼承人本身者，不在此限。
> **§170 I**　無代理權人以代理人之名義所為之法律行為，非經本人承認，對於本人不生效力。
> **§171**　無代理權人所為之法律行為，其相對人於本人未承認前，得撤回之。但為法律行為時，明知其無代理權者，不在此限。
> **§148 II**　行使權利，履行義務，應依誠實及信用方法。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「兒子乙無權代理父甲向丙借款，甲未承認即死亡，乙為唯一繼承人。承認權可否繼承？」 | **可**。承認權只是對法律行為效力予以承認的權利，非一身專屬 → 依 §1148 由乙繼承 |
| 「乙繼承承認權後，得否拒絕承認？」 | **身分法多數說（戴東雄等）：不得**。基於誠信原則（允諾禁反言）：自己無權代理，好不容易有機會讓契約有效，怎可拒絕 → 契約**強制有效** → 乙繼承契約關係，對丙負履行義務。**林秀雄：得**。① 法條沒說不能拒絕 ② 強制有效對丙未必較好：效力未定狀態下丙保有 **§171 撤回權**，甲一死契約強制有效，丙的撤回權就不見了 ③ 乙若拒絕，丙仍有 **§110** 損害賠償 → 讓乙保有拒絕權對丙並無不利，何必為誠信原則強制有效 |
| 「甲承認後死亡、或拒絕後死亡？」 | 效力已確定，無此問題。本題限於**效力未定狀態中**死亡 |

## 一、兩個層次

```
層次一：承認權可否繼承？ → 通說：可（§1148），非一身專屬
層次二：繼承承認權的乙（＝當初的無權代理人）可否拒絕承認？ → 有爭議
```

## 二、層次二兩說

| | 否定說（身分法多數：戴東雄等；字幕提及三位戴姓老師，姓名請對講義） | 肯定說（林秀雄） |
|---|---|---|
| 理由 | 誠信原則、禁反言：你自己無權代理，現在有機會讓它有效，不能拒絕 | 法無明文；不能拒絕對當事人沒有比較好 |
| 效果 | 契約強制有效 → 乙繼承契約 → 對丙負履行義務 | 契約續處效力未定 → 乙可承認（丙可請求履行）或拒絕（丙 §110 求償） |
| 對丙 | 得到有效契約，但失去 §171 撤回權（也許想了一下要撤回，結果甲一死撤不了） | 保有撤回權；乙拒絕時仍有 §110 → 交易安全無損 |
