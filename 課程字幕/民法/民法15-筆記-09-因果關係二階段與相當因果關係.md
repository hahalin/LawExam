# 民法15 筆記：因果關係二階段與相當因果關係

## 兩個階段：
- **責任成立因果關係**：在 §184 檢驗——行為與權利侵害有無關聯，決定**要不要賠**
- **責任範圍因果關係**：在 §216 檢驗——各項損害與侵權責任有無關聯，決定**賠多少**
- 侵權案例中因果關係通常要**檢驗兩次**；先確定題目問的是哪一個層次

## 兩步判斷：
- 第一步 **事實上因果關係**：條件理論，「若無此因，即無此果」，把所有可能原因留下、排除不可能者
- 第二步 **法律上因果關係**：相當因果關係，依一般知識經驗觀察，相同行為**通常**會發生相同結果 → 具相當性；不需「必然發生」

## 老師辦案例：改運費：
- 原住民被害人車禍後花 1 萬元殺豬祭天改運，請求列入賠償
- 條件上：沒車禍就不用改運 ✓；相當性：不是每個車禍的人通常都會去改運 ✗
- 輔具、柺杖、輪椅、醫藥費等直接相關者承認；與車禍無關的單據（本來就在吃的藥）不列入

## 102 或 103 年律師司法官考題（第一小題：責任範圍）：
- 甲超速撞乙，乙提出多項損害；責任成立無爭議，問題在**責任範圍**
- 醫藥費、勞動能力減損：**§193** 法律已明定，不必另證因果
- 住院期間家中遭竊：條件 ✓、相當性 ✗（住院不在家常見，遭竊是極少數）
- 拄柺杖下樓又跌倒：條件 ✓、相當性 ✓（王澤鑑：**初始侵害所造成之結果侵害**，受傷後再受傷機率高）
- 住院檢查發現腦瘤而離職：相當性 ✗；王澤鑑另提**法規目的說**——腦瘤與侵權行為截然無關，不在侵權行為法保護目的內

## 第二小題：國道巴士跳橋案（責任成立）：
- 小客車追撞國道巴士，巴士起火爆炸，乘客慌亂逃出、把橋樑縫隙誤為安全島一躍而下受傷，得否向肇事者請求
- 條件 ✓；相當性：實務**肯定**。老師點出判決中考題沒寫清楚的要素：民國 60 幾年、**深夜**、照明昏暗、伴隨爆炸聲、**一群人**一起逃（群眾無法理性判斷）

## 📖 法條原文速查

> **民法 §184 I 前段**　因故意或過失，不法侵害他人之權利者，負損害賠償責任。

> **民法 §216 I**　損害賠償，除法律另有規定或契約另有訂定外，應以填補債權人所受損害及所失利益為限。

> **民法 §193 I**　不法侵害他人之身體或健康者，對於被害人因此喪失或減少勞動能力或增加生活上之需要時，應負損害賠償責任。

## 📋 實務見解速查

> **國道巴士跳橋案**（最高法院，民國 60 幾年之事實；字號字幕未唸，請對講義）：依當時時空背景（深夜、照明昏暗、爆炸聲、多人一同逃竄），乘客誤將橋樑縫隙當安全島跳下受傷，依一般知識經驗觀察通常可能發生 → 具相當因果關係。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「責任成立與責任範圍因果關係各在何處檢驗？」 | 責任成立 → **§184**（要不要賠）；責任範圍 → **§216**（賠多少） |
| 「事實上因果關係之判斷標準？」 | **條件理論**：若無此因，即無此果 |
| 「相當因果關係之判斷？」 | 依一般知識經驗，相同行為**通常**會發生相同結果；不要求必然發生 |
| 「車禍受傷住院，家中遭竊，得否請求？」 | 條件 ✓、相當性 **✗** → 不在責任範圍 |
| 「拄柺杖跌倒再受傷，得否請求？」 | **得**。初始侵害所造成之結果侵害，具相當性（王澤鑑） |
| 「車禍住院檢查發現腦瘤而離職？」 | 不得。相當性 ✗；王澤鑑另以**法規目的說**排除 |
| 「巴士爆炸乘客誤跳橋縫受傷，肇事者應否負責？」 | 實務**肯定**相當因果關係（深夜、昏暗、爆炸、群體逃竄） |

## 一、判斷流程

```
先問：哪一層次？
├── 責任成立（§184）：行為 → 權利侵害？
└── 責任範圍（§216）：責任 → 各項損害？
          ├── 法律明定者（§193 醫藥費、勞動能力）→ 直接認定
          └── 其餘逐項：
               ① 事實上因果（條件理論）→ ✗ 則排除
               ② 法律上因果（相當性）→ ✗ 則排除
               ③（補充）法規目的說：非侵權法所要處理者 → 排除
```

## 二、五項損害對照（102 或 103 年考題）

| 損害項目 | 條件 | 相當性 | 結論 |
|---|---|---|---|
| 醫藥費 | — | — | §193 法律擬制，✓ |
| 勞動能力減損 | — | — | §193 明定，✓ |
| 住院期間家中遭竊 | ✓ | ✗ | 不賠 |
| 拄柺杖跌倒再受傷 | ✓ | ✓（初始侵害之結果侵害） | 賠 |
| 發現腦瘤而離職 | ✓ | ✗（另：法規目的說） | 不賠 |

- 答題第一段：「侵權行為之因果關係包括責任成立及責任範圍之因果關係；本件甲撞乙，責任成立無爭議，問題在乙主張之損害是否為責任範圍所及。」

## 三、巴士跳橋案的判斷要素

| 要素 | 為何重要 |
|---|---|
| 民國 60 幾年 | 當年高速公路照明遠不如今 |
| 深夜、照明昏暗 | 難辨橋縫與安全島 |
| 起火伴隨爆炸聲 | 逃命心理 |
| 巴士多名乘客一起逃 | 群眾跟隨前人、無法理性判斷 |

- 老師：題目事實寫得不夠清楚；若是白天大太陽，很難認為通常會發生。
