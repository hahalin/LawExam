# 民法33 筆記：承攬瑕疵之解除契約與建築物須拆除重建（§494、§495）

## 解除契約的判斷順序：
```
工作有瑕疵
│
├── 非重要瑕疵 → 不論依哪一條，都不能解約
│
└── 重要瑕疵（影響契約目的：房子不能住、程式不能跑）
    │
    ├── 非建築物、非土地上工作物 → §494 直接解約，不問可歸責
    │
    └── 建築物或土地上工作物
        ├── 可歸責於承攬人 → §495 II 解約（瑕疵重大致不能達使用目的）
        └── 不可歸責於承攬人
            ├── 原則：§494 但書，不得解約
            └── 例外：須拆除重建 → 目的性限縮，可以解約（83 台上 3265）
```

## 卡住的情形：
- 例：建商施工沒有任何過失，但建材有重金屬或是輻射鋼筋，房屋目的不達
- §494 但書：建築物 → 不得解約
- §495 II：要可歸責於承攬人 → 用不上
- 文義上找不到解約依據

## 83 台上 3265 判例：目的性限縮
- §494 但書所謂不得解約，指瑕疵**不至影響建築物結構或安全、無須拆除重建**者
- 瑕疵已達有**倒塌危險**，還要定作人承受，不是立法本意
- 道理：解約對承攬人最大的不利是**回復原狀**（拆屋）；房子本來就要拆，讓定作人解約，承攬人也沒有更不利

## 詹森林：條文位置放錯
- 債編修正草案原本把現行 §495 II 放在 §494 後面
- §494 讀完接著讀 §495 II：「建築物……瑕疵重大致不能達使用之目的者，定作人得解除契約」→ 正好就是 83 年判例的結論
- 立法院把它移到 §495 後面，變成要以「可歸責」為前提 → 原本要解決的問題沒解決，仍要援用判例做目的性限縮

## 📖 法條原文速查

> **§494**　承攬人不於前條第一項所定期限內修補瑕疵，或依前條第三項之規定拒絕修補或其瑕疵不能修補者，定作人得解除契約或請求減少報酬。但**瑕疵非重要**，或所承攬之工作為**建築物或其他土地上之工作物**者，定作人**不得解除契約**。

> **§495 II**　前項情形，所承攬之工作為建築物或其他土地上之工作物，而其**瑕疵重大致不能達使用之目的**者，定作人得解除契約。

---

## 📋 實務見解速查

> **83 台上 3265 判例**（要旨）：§494 但書規定所承攬之工作為建築物或其他土地上之工作物者，定作人不得解除契約，係指承攬人所承攬之建築物，其瑕疵程度尚不致影響建築物之結構或安全，**毋庸拆除重建**者而言。倘瑕疵程度已達建築物有**倒塌之危險**，猶謂定作人仍須承受此項危險，而不得解除契約，要非立法本意所在。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「非重要瑕疵可解除承攬契約？」 | **不可** |
| 「動產工作重要瑕疵，須可歸責才能解約？」 | **不須**，§494 |
| 「建築物重大瑕疵可歸責於承攬人？」 | §495 II **可解約** |
| 「建築物瑕疵不可歸責，但須拆除重建？」 | **可解約**（83 台上 3265 目的性限縮） |
| 「建築物瑕疵不影響結構安全？」 | **不得解約**，只能減少報酬 |
