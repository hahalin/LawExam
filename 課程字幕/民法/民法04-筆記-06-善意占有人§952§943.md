# 民法04 筆記：善意占有人的收取權 §952 ＋ §943

> 來源：民法04 課程字幕 00:43:00 ~ 00:53:25

---

## 📖 法條原文速查

> **§952**（善意占有人之使用收益權）
> 善意占有人於**推定其為適法所有之權利範圍內**，得為占有物之**使用、收益**。
> → 要件：① 善意占有人 ② 受推定保護；效果：使用收益（有「收益」二字）

> **§943**（占有權利之推定）
> I 占有人於占有物上行使之權利，**推定**其適法有此權利。
> II 前項推定，於下列情形不適用之：
> 一、占有**已登記之不動產**而行使**物權**。
> 二、行使所有權以外之權利者，對**使其占有之人**。

> **§759-1 I**（對照：不動產登記之推定）
> 不動產物權經登記者，推定登記權利人適法有此權利。→ 已登記不動產的物權看登記外觀，不看占有

> **§179**（不當得利）→ 甲能否對丙請求不當得利，取決於丙有無收取權

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「甲地被乙無權占有並出租予善意丙，丙所種果實分離後歸誰？」 | **丙**。丙為善意占有人，受 §943 推定，依 §952 有收益權 |
| 「無權占有人乙有無收取權？」 | **無**，找不到依據 |
| 「§943 II ① 之例外是否適用於本例？」 | **否**。丙行使的是**租賃權（債權）**，不是物權 |
| 「§943 II ② 之例外是否適用於本例？」 | **否**。甲不是「使丙占有之人」（使丙占有的是乙） |
| 「丙可收取到何時？」 | 推定被**推翻**為止（甲起訴主張丙非向其承租）；推翻前合法收取 |
| 「甲得否對丙主張不當得利？」 | 丙有收取權 → 有法律上原因 → **不得** |

## 一、案例

#### 事實
甲在山上有一塊土地，長年荒廢。乙見無人管理，圈地據為己有，出租給善意的丙。丙在上面種果實。

#### 分析
```
未分離 → 土地的一部分 → 甲的（沒什麼好考）
已分離 → 誰有收取權？
    原則：原物所有人甲（§766）
    但：有其他收取權人時，輪不到原物所有人 → 先檢驗乙、丙
    乙：無權占有人 → 無租約、無物權 → 沒有收取權依據 → ✗
    丙：「善意」是線索 → §952
```

## 二、§952 要配 §943 一起看

```
§952：善意占有人，在「推定其為適法所有之權利範圍內」，得使用收益
    ↑ 推定從哪來？→ §943 I：占有人於占有物上行使之權利，推定其適法有此權利
    丙占有 A 地、行使租賃權 → 推定丙有合法租賃權 → 有使用收益權 → 可收果實
```

### §943 II 的兩個例外（本例都閃過）

| 例外 | 內容 | 本例 |
|------|------|------|
| ① 占有已登記不動產而行使**物權** | 已登記不動產的物權看**登記**外觀（§759-1 I），跟占有無關 | 丙行使的是**租賃權＝債權** → 不適用 |
| ② 行使所有權以外之權利，對**使其占有之人** | 對讓你占有的那個人，直接看你們的內部原因關係，不需推定 | 使丙占有的是**乙**，不是甲 → 甲不是「使其占有之人」→ 不適用 |

→ 回到原則：丙受推定 → §952 有收益權 → **分離後的果實歸丙**。

## 三、推定可以推翻

- §943 是「推定」→ 甲舉反證（起訴主張「你不是跟我租的」）推翻後，丙不能再收取。
- 推翻**之前**，丙的收取都合法 → 甲對丙的不當得利請求無理由（有法律上原因）。
- 老師：善意占有人有收取權，是容易被忽略的點；§952 在不當得利會再看第二遍。
