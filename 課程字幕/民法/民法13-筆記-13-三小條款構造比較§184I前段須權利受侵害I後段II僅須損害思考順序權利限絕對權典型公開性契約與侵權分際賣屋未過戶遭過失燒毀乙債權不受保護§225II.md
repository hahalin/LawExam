# 民法13 筆記：三小條款的構造比較與「權利」的意義——§184 I 前段：行為、**權利**、損害、因果＋不法＋過失；I 後段：**加損害於他人**（不須權利受侵害）＋故意背於善良風俗；II：加損害於他人＋違反保護他人之法律＋推定過失；思考順序：有無損害 → 有無權利受侵害 → 有則 I 前段，無則 I 後段或 II；「權利」限**絕對權**（通說）：比較法（德民 §823）、**典型公開性**（王澤鑑：看得見才能要求你避免，行為自由的限制才有正當性）、維持契約與侵權的分際；甲賣屋予乙未過戶、丙過失燒毀：甲 I 前段 ✓，乙之債權非絕對權 ✗（後段無故意背俗、II 無違法）→ 乙依 §225 II 向甲請求讓與對丙之賠償請求權

## 📖 法條原文速查

> **§184**　I 因故意或過失，不法侵害他人之**權利**者，負損害賠償責任。故意以背於善良風俗之方法，**加損害於他人**者亦同。II 違反保護他人之法律，致生**損害於他人**者，負賠償責任。但能證明其行為無過失者，不在此限。
> **§225 II**　債務人因前項給付不能之事由，對第三人有損害賠償請求權者，債權人得向債務人請求讓與其損害賠償請求權，或交付其所受領之賠償物。（代償請求權）
> **§348 I**　物之出賣人，負交付其物於買受人，並使其取得該物所有權之義務。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「三小條款構成要件的差異？」 | 第一層（構成要件）：**只有「權利」這個要件不同**——I 前段須權利受侵害；I 後段、II 只須有損害。第二層（歸責）：I 前段不法＋故意過失；I 後段故意＋背於善良風俗；II 違反保護他人之法律＋推定過失（但書舉證免責） |
| 「侵權行為題目的思考順序？」 | ① 先問**有無損害**（沒有損害就沒有賠償，最容易忽略）② 有無**權利**受侵害 → 有 → 涵攝 I 前段；無 → 說明為何不能用前段，改往 I 後段或 II |
| 「§184 I 前段之『權利』？」 | 通說：**絕對權**（物權、人格權等），不含債權 |
| 「為何限絕對權？」 | ① 比較法：源自德民 §823，德國限絕對權（學者批評不能德國說什麼就是什麼）② **典型公開性**（王澤鑑）：侵權行為法是為保護權利而限制行為自由，前提是權利**看得見**——看得見、做得到卻沒避免，要你負責才合理；看不見的東西無從避免，法不強人所難 ③ 隱藏理由：維持**契約與侵權的分際**——若債權也是「權利」，所有債務不履行都變侵權，債編可以刪掉只留一條，無法反映各契約的風險分配個性 |
| 「甲將 A 屋（市價 1000 萬）以 800 萬賣予乙，尚未過戶；丙過失燒毀 A 屋。甲、乙得否對丙請求？」 | **甲**：有損害、所有權（絕對權）受侵害 → **I 前段 ✓**（房子看得見，丙應避免）。**乙**：有損害（§348 債權無法實現），但債權非絕對權 → I 前段 ✗；丙僅過失、無背於善良風俗 → I 後段 ✗；丙未違反保護他人之法律 → II ✗ → 乙對丙**無侵權請求權**。但乙不是沒救：甲不可歸責給付不能 → 乙依 **§225 II 代償請求權**，請求甲讓與其對丙之 §184 損害賠償請求權 |
| 「結果合理？」 | 王澤鑑：合理。丙燒房子時只能預見房子有所有人要賠，無法想像房子背後還有買受人（債權人）→ 預防不了 → 不該負責 → 乙的權利保護在侵權法上退讓，由契約法（§225 II）補位 |

## 一、三小條款比較表

| | §184 I 前段 | §184 I 後段 | §184 II |
|---|---|---|---|
| 行為、損害、因果 | ✓ | ✓ | ✓ |
| **權利受侵害** | **須** | 不須（加損害於他人） | 不須（致生損害於他人） |
| 客觀歸責 | 不法 | 背於善良風俗 | 違反保護他人之法律 |
| 主觀歸責 | 故意或過失 | **故意** | **推定過失**（但書可舉證免責） |

## 二、思考流程

```
有損害？ ✗ → 不賠
   ↓ ✓
權利（絕對權）受侵害？ ✓ → §184 I 前段涵攝
   ↓ ✗
說明不能用前段 → §184 I 後段（故意背俗）？→ §184 II（違反保護他人之法律）？
```

## 三、燒屋案

```
甲 ─買賣 800 萬，未過戶─ 乙      丙過失燒毀 A 屋（市價 1000 萬）
甲：損害 ✓、所有權 ✓（絕對權，典型公開性）→ 丙依 I 前段賠甲
乙：損害 ✓（§348 請求權落空）、權利 ✗（債權相對權）→ 前段 ✗；後段 ✗（無故意背俗）；II ✗（無違法）
    → 乙對丙無侵權請求權 → 乙 → 甲：§225 II 代償請求權（請求讓與甲對丙之 §184 請求權）
```

- 權利保護與行為自由的拔河在此：乙的保護讓位給丙的行為自由（丙看不見債權），但契約法另有機制。
