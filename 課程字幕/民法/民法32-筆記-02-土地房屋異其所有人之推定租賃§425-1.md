# 民法32 筆記：土地房屋異其所有人之推定租賃（§425-1）

## 三個條文的起手式相同：
- 土地與其上房屋**同屬一人所有**，之後變成不同人所有
- 差別在「變成不同人所有」的原因與效果：
  - §425-1：所有人**自己處分**（只賣地、只賣屋、地屋分別賣給不同人）→ **推定租賃關係**
  - §838-1：因**強制執行**拍賣 → **法定地上權**
  - §876：因**實行抵押權**拍賣 → **法定地上權**
- 推定可舉反證推翻，當事人可另行約定坐落關係（例：無償使用 20 年、房屋送你）；被動被拍賣時當事人難以協商，所以直接給物權（地上權）
- 法定地上權存續到建築物不堪使用、滅失為止（細節到物權法再講）

## 推定租賃的期間：
- 在**房屋得使用期限內**有租賃關係；房屋滅失，推定租賃隨之消滅
- 期限不受 §449 I 二十年上限限制

## 爭點一：法院核定租金（§425-1 II）的溯及效力：
- 情境：雙方對租金談不攏（一方主張公告地價、一方主張市價），請求法院定之，判決核定每月 28,000 元
- 甲說：形成訴訟，判決確定後才生效 → 確定前無從請求
- 高院座談會、最高法院（110 台上 3013）：租賃關係在推定成立時已依法發生，法院只是**確認租金數額** → **溯及**至推定租賃關係成立時；判決可命給付起訴前期間的租金
- 例：拖了 3 年才判決 → 3 年租金都可請求

## 爭點二：溯及期間可否請求遲延利息？
- 高院座談會：肯定（既然自始有給付義務）
- 最高法院（113 年度第 766 號判決）：**否定**。給付遲延須可歸責於債務人；租金核定前無從給付，**不可歸責** → 不負遲延責任

## 爭點三：土地共有時有無 §425-1？
- 事實：A 地甲乙丙共有，甲在 A 地上建 B 屋；乙丙依土地法 §34-1 多數決把 A 地賣給丁（或分割由第三人取得）；丁請求甲拆屋還地
- 肯定說（107 台上 1938）：「同屬一人所有」包括土地共有人除房屋所有人外尚有其他共有人的情形 → 目的性擴張，避免房屋被拆
- 否定說（多數說、陳榮傳教授）：甲能蓋屋是基於**分管契約**，應回到共有規定處理（§826-1 分管契約對受讓人效力；共有關係消滅分管契約隨之消滅），不必類推 §425-1
- 細節到物權法再講

## 爭點四：違章建築：
- 違建無所有權，只能讓與**事實上處分權**
- 實務、多數說：為貫徹避免拆屋之目的，仍有 §425-1 適用
- 吳從周教授批評：公法上違建本應拆除，民法卻加以保護，是法秩序衝突；違建無保護必要

## 📖 法條原文速查

> **§425-1**
> I　土地及其土地上之房屋**同屬一人所有**，而僅將土地或僅將房屋所有權讓與他人，或將土地及房屋同時或先後讓與相異之人時，土地受讓人或房屋受讓人與讓與人間或房屋受讓人與土地受讓人間，**推定**在房屋得使用期限內，有**租賃關係**。其期限不受第四百四十九條第一項規定之限制。
> II　前項情形，其租金數額當事人不能協議時，得請求**法院定之**。

> **§838-1 I**（摘要）土地及其上建築物同屬一人所有，因**強制執行之拍賣**，其土地與建築物之拍定人各異時，**視為已有地上權之設定**。→ 建議查閱最新六法原文

> **§876 I**（摘要）設定抵押權時土地及其上建築物同屬一人所有，而僅以土地或僅以建築物為抵押者，於抵押物拍賣時，**視為已有地上權之設定**。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **110 台上 3013**：承租人自租賃關係成立時起即有給付租金義務，§425-1 推定租賃亦然；法院判決得宣示推定租賃成立後之租金並命給付，不以起訴狀繕本送達後為限。

> **113 年度第 766 號判決**：租金核定前，房屋所有人不可歸責，不負遲延責任。→ 字號依講義，建議查證

> **107 台上 1938**：「同屬一人所有」包括土地共有人除與房屋相同之共有人外尚有其他共有人之情形（肯定說）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「地主自己賣地，房屋與土地間的法律關係？」 | **推定租賃**（§425-1），可舉反證推翻 |
| 「房屋被強制執行拍賣、抵押權實行？」 | **法定地上權**（§838-1、§876），不是租賃 |
| 「推定租賃的期間受 20 年限制？」 | **不受**，房屋得使用期限內 |
| 「法院核定租金有無溯及效力？」 | **有**，溯及推定租賃成立時 |
| 「溯及期間的遲延利息？」 | 最高法院：**不得請求**（不可歸責） |
| 「土地共有時有無 §425-1？」 | 肯否二說；多數說**否定**，回到分管契約 |
