# 民法28 筆記：第三人表示享受利益後之變更撤銷與解除（§269 II）

## 丙什麼時候取得權利？
- **甲乙約定時**，丙就取得直接請求權，不需要丙表示意見
- 從 §269 III 反推：表示不要才「**視為自始**未取得」→ 表示前其實已經取得
- 三種狀態：
  - 丙**未表示** → 已有權利，但甲乙可依 §269 II 變更或撤銷
  - 丙**表示不要** → §269 III，視為自始未取得
  - 丙**表示享受** → 甲乙還能不能動？條文沒寫，靠 §269 II **反面解釋**

## §269 II 的變更與撤銷：
- 變更：把丙換成別人
- 撤銷：撤掉第三人約款，利益回到乙身上

## 丙表示享受後，四種權利分開看：
- **任意（合意）變更、撤銷** → **不行**
- **法定撤銷權**（§88 錯誤、§92 詐欺脅迫）→ **可以**，§269 II 沒有排除民法總則
- **約定解除權** → **可以**
  - 林誠二、孫森焱：約定解除權是第三人利益契約的一環，丙在契約框架下受拘束
  - 例：甲乙約定一個月內可任意解約，丙表示享受也不影響
- **法定解除權** → 有爭議
  - 實務（講義 552 頁註 868 判決）：**可以**，法定撤銷權、解除權不受 §269 II 限制
  - 林誠二：**不行**，未得丙同意不得行使

## 法定解除權的爭議案例：
- 甲乙訂買賣契約，約定甲向丙給付，丙有直接請求權，且丙已表示享受
- 乙拒不付價金，甲可否依 §254 解約？
- 實務：可以，解除權是法定權利，不因丙表示享受而受影響
- 林誠二（少數）：不行
  - 丙表示享受後，丙的利益**優先**於當事人
  - 甲拿不到價金的風險，只能向乙要錢；不能解約後就不給丙
  - 第三人利益契約真正要保護的是丙

## 甲乙之間其餘關係（補充）：
- 甲可向乙請求對待給付
- 乙只能請求甲向丙給付，不能請求向自己給付（見民法28-筆記-07）

## 📖 法條原文速查

> **§269**　II 第三人對於前項契約，**未表示享受其利益之意思前**，當事人得**變更**其契約或**撤銷**之。III 第三人對於當事人之一方表示**不欲享受**其契約之利益者，**視為自始未取得**其權利。

> **§254**　契約當事人之一方遲延給付者，他方當事人得定相當期限催告其履行，如於期限內不履行時，得解除其契約。

---

## 📋 實務見解速查

> **最高法院 82 年判決**（講義 552 頁註 868；字號建議查證）：§269 II 係指第三人未為受益之意思表示前，當事人得以**協議**變更契約內容或使契約根本消滅；表示受益後即不得為之。如當事人行使**法定之撤銷權或解除權**，則不受該條規定之限制。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「利益第三人何時取得權利？」 | **契約成立時**，不待表示 |
| 「第三人未表示前，當事人得變更或撤銷？」 | **得**（§269 II） |
| 「第三人表示不欲享受？」 | **視為自始未取得**（§269 III） |
| 「表示享受後，當事人合意撤銷？」 | **不得** |
| 「表示享受後，被詐欺得撤銷？」 | **得**，法定撤銷權不受影響 |
| 「表示享受後，因要約人遲延而解約？」 | 實務**得**；林誠二**不得** |

## 丙表示享受後的權利整理

| 權利 | 結論 | 依據 |
|---|---|---|
| 任意變更、撤銷 | 不得 | §269 II 反面解釋 |
| 法定撤銷（§88、§92） | 得 | 不排除總則 |
| 約定解除權 | 得 | 林誠二、孫森焱 |
| 法定解除權（§254） | 實務得／林誠二不得 | 註 868 判決 |

```
甲乙約定 ──→ 丙取得權利
              ├── 未表示 → 可被變更、撤銷（§269 II）
              ├── 表示不要 → 視為自始未取得（§269 III）
              └── 表示享受 → 任意變更撤銷 ✗；法定撤銷 ✓；
                            約定解除 ✓；法定解除 實務 ✓／林誠二 ✗
```
