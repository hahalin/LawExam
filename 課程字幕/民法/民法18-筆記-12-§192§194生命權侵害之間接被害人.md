# 民法18 筆記：§192§194生命權侵害之間接被害人

## 直接被害人不能請求：
- 甲被乙不法侵害致死，權利能力終於死亡（§6）→ 甲本人無法依 §184 求償
- 我國**不承認餘命損害**

## 間接被害人兩類：
- §192 財產上損害：① 為死者**支出**醫療、增加生活上需要或殯葬**費用**之人；② 死者對其負**法定扶養義務**之人
- §194 非財產上損害（慰撫金）：只有**父、母、子、女、配偶**

## 法定扶養義務須符合 §1114 以下：
- 只有扶養事實、沒有法定扶養義務 → 不能依 §192 II 請求
- 考題：甲父母是退休公務員領退休金、另有房屋出租，生活無虞；甲很孝順，被撞死 → 父母**能維持生活**，甲對其無法定扶養義務 → **無** §192 II

## 移轉性損失與請求權基礎：
- 學理稱**移轉性損失**：把直接被害人生命權受侵害之損害，轉到間接被害人身上
- 里長幫無力辦後事的死者代墊喪葬費 → 可依 §192 請求，但里長**沒有任何權利受侵害**
- 老師：§192 可**直接主張**，不必與 §184 結合（硬套 §184 會卡在「支出費用者何權利受侵害」）；§184 的要件放在「乙侵害甲生命權」這段涵攝
- §194 以一定身分關係為前提 → 可寫 **§184＋§194**

> 來源：民法18 課程字幕 02:27:54 ~ 02:34:34；老師引用父母受扶養要件時唸「1116 條」，「不能維持生活」之要件規定在 §1117，請對六法

## 📖 法條原文速查

> **§192**　I 不法侵害他人致死者，對於支出醫療及增加生活上需要之費用或**殯葬費之人**，亦應負損害賠償責任。II 被害人對於第三人負有**法定扶養義務**者，加害人對於該第三人亦應負損害賠償責任。

> **§194**　不法侵害他人致死者，被害人之**父、母、子、女及配偶**，雖非財產上之損害，亦得請求賠償相當之金額。

> **§6**　人之權利能力，始於出生，終於死亡。

> **§1117 I**（要旨）　受扶養權利者，以**不能維持生活**而無謀生能力者為限；II 無謀生能力之限制，於直系血親尊親屬不適用之。（原文請對六法）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「被害人死亡，其本人之餘命損害得否請求？」 | **否**，我國不承認 |
| 「父母生活無虞，子女被撞死，父母得否依 §192 II 請求扶養費？」 | **否**，父母須**不能維持生活**才有法定扶養權利 |
| 「代墊喪葬費之里長得否請求加害人賠償？」 | **得**，§192 I 支出殯葬費之人 |
| 「得依 §194 請求慰撫金者？」 | **父、母、子、女、配偶**（不含兄弟姊妹、祖父母） |
| 「有扶養事實但無法定扶養義務，得否依 §192 II 請求？」 | **否** |

## 一、致死案件之請求權人

```
乙不法侵害甲致死
├─ 甲（直接被害人）：權利能力消滅 → ✗；不承認餘命損害
└─ 間接被害人
    ├─ 財產上（§192）
    │   ├─ I：支出醫療、增加生活需要、殯葬費之人（例：里長）
    │   └─ II：甲對其負法定扶養義務之人
    └─ 非財產上（§194）：父、母、子、女、配偶
```

## 二、法定扶養義務之判斷（考題）

| 事實 | 判斷 |
|---|---|
| 父母為退休公務員，有退休金 | 能維持生活 |
| 父母有房屋出租，生活無虞 | 能維持生活 |
| 甲孝順、實際扶養父母 | 只是扶養**事實** |
| 結論 | 無法定扶養義務 → **無 §192 II** |

## 三、涵攝寫法

| 請求 | 寫法 | 理由 |
|---|---|---|
| 支出費用（§192 I） | 直接主張 §192 | 支出者無權利受侵害，與 §184 結合不起來 |
| 扶養費（§192 II） | 直接主張 §192（亦可勉強說身分權受侵害） | 同上 |
| 慰撫金（§194） | §184＋§194 | 有身分關係為前提 |
| §184 要件 | 涵攝「乙侵害甲生命權」：故意過失、不法 | 責任成立階段 |

- 對照：王澤鑑認 §192～§196 為範圍規定、不能單獨作請求權基礎（上一份）
