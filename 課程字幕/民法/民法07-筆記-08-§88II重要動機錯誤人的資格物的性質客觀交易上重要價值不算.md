# 民法07 筆記：§88 II 重要的動機錯誤——人的資格、物的性質（客觀要素）＋交易上重要 → 視為內容錯誤；「價值」不算

> 來源：民法07 課程字幕 01:05:30 ~ 01:11:01

---

## 📖 法條原文速查

> **§88 II**　當事人之**資格**或物之**性質**，若**交易上認為重要**者，其錯誤，**視為**意思表示內容之錯誤。
> → 效果是「視為內容錯誤」，不是「得撤銷」；視為後再依 §88 I 撤銷

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§88 II 之要件？」 | ① **人的資格或物的性質**（**客觀**要素，有標準答案）② **交易上認為重要**（影響締約意願或價格） |
| 「誤以為畫作為張大千真跡、誤以為對方有律師執照、買到凶宅、泡水車？」 | 物的性質／人的資格，交易上重要 → §88 II 視為內容錯誤 → 依 §88 I 撤銷 |
| 「誤以為畫作**很值錢**？」 | **價值**是主觀要素 → **不是** §88 II 的性質 → 一般動機錯誤 → 不得撤銷 |
| 「僱用秘書時誤以為其未婚？」 | 已婚未婚雖客觀，但**交易上不重要**（不影響一般人締約意願，也不能拿來當理由）→ 不得撤銷 |
| 「得否直接依 §88 II 撤銷？」 | **不精確**。§88 II 無「撤銷」二字，效果是視為內容錯誤，撤銷仍依 §88 I |

---

## 一、§88 II 的結構：先「視為」再「撤銷」
```
重要動機錯誤 ──§88 II 視為──→ 內容錯誤 ──§88 I──→ 得撤銷（仍須無過失、一年內）
論述時不要寫「依 §88 II 撤銷」，寫「依 §88 II 視為內容錯誤，依 §88 I 撤銷」
```

## 二、要件 ①：客觀要素——有標準答案

| 客觀（資格／性質）✓ | 主觀 ✗ |
|------|------|
| 有沒有律師資格、保母執照、日文 N1 | 法律好不好、日文好不好、會不會顧小孩 |
| 畫是不是真跡、是不是凶宅、是不是泡水車、有沒有前科 | **這個東西值不值錢**（物的價值） |

- 考試最愛問「如果是價值呢」→ 價值是主觀的（我覺得值錢、我覺得還好）→ 不在 §88 II → 不得撤銷。
- **性質 vs 價值**要看清楚。

## 三、要件 ②：交易上認為重要
```
會影響締約意願，或會影響價格 → 重要
已婚未婚：客觀，但不影響一般人的締約意願（就算會也不能講）→ 不重要
```

## 四、典型案例
| 案例 | 要件 ① | 要件 ② | 結果 |
|------|------|------|------|
| 畫作是否為梵谷／張大千真跡 | 物的性質 ✓ | ✓ | §88 II → 可撤銷 |
| 對方有無律師、會計師執照 | 人的資格 ✓ | ✓ | 同上 |
| 凶宅、泡水車 | 物的性質 ✓ | ✓ | 同上 |
| 畫很值錢 | 價值 ✗ | — | 一般動機錯誤 |
| 秘書已婚 | ✓ | ✗ | 不得撤銷 |

- 老師：§88 II 是考試裡最常用到的，重點就在判斷「算不算人的資格或物的性質、交易上重不重要」。
