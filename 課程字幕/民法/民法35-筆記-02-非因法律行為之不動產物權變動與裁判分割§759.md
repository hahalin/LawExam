# 民法35 筆記：非因法律行為之不動產物權變動與裁判分割（§759）

## 核心：先有效果，再登記：
- 非因法律行為＝沒有當事人的意思表示，依**法律規定**或事實自然發生變動
- 效果在登記前就已發生；登記只是讓權利人取得**處分權**
- 這種登記稱**保存登記**、**宣示登記**、**第一次登記**
- 老師的比方：臉書公開「穩定交往中」的前提是先交往，再公開
- 選擇題很愛考 §759

## 類型一：繼承：
- 數字例：甲名下 A 地，甲死亡，乙為唯一繼承人，乙想把 A 地賣給丙
- ① 甲死亡瞬間，乙即取得所有權（§1147、§1148 I），不需任何意思表示，乙不知甲死亡也一樣
- ② 乙辦**繼承登記**（§759）→ 取得處分權；實務須先繳遺產稅，持完稅證明才能辦
- ③ 乙再與丙辦**移轉登記**（§758）→ 丙取得所有權
- 隱瞞死亡、用被繼承人印章直接過戶以規避遺產稅 → 偽造文書、使公務員登載不實（題外話，不考）

## 類型二：徵收：
- 土地徵收條例：**補償費發給完竣**時，原所有人權利終止，政府取得所有權（字幕不確定是第 21 條或第 29 條，建議查證）
- 原所有人拒領 → 依法**提存**，同樣發生移轉
- 不是強迫甲為移轉的意思表示，而是法律直接創造移轉結果

## 類型三：強制執行：
- 數字例：債權人乙聲請拍賣甲的 A 地，丙以 700 萬元拍定
- 拍定時：**尚未**取得
- 繳足價金時：**尚未**取得
- 領得執行法院發給之**權利移轉證書**時：**取得所有權**（強制執行法 §98 I）
- 丙要再賣給丁 → 先辦 §759 登記取得處分權，再移轉登記給丁

## 類型四：法院判決，限形成判決：
- 實務：§759 的法院判決，以**形成判決**為限（給付判決不算）
- 例：甲乙共有 A 地，要分成 A1（甲）、A2（乙）
| | 協議分割 | 裁判分割 |
|---|---|---|
| 性質 | 法律行為 | 法院形成 |
| 一方不履行 | 訴請**履行分割協議** → **給付之訴** | 不能協議才訴請分割（§824）→ **形成之訴** |
| 判決確定時 | **不**發生分割效果 | **直接**發生分割效果 |
| 何時取得 A1、A2 | 持判決單獨辦**分割登記**完成時（§758） | 判決確定時；之後登記屬 §759 |
- 判斷關鍵字不是「分割」，而是「訴請**裁判分割**」還是「訴請**履行分割協議**」

## 類型五：其他非因法律行為：
- §295、§307 抵押權隨同移轉與消滅 → 見民法35-筆記-03
- 房屋原始取得 → 見民法35-筆記-04

## 📖 法條原文速查

> **§759**　因**繼承、強制執行、徵收、法院之判決**或其他非因法律行為，於登記前已取得不動產物權者，應經登記，始得**處分**其物權。

> **§1147**　繼承，因被繼承人死亡而開始。

> **§1148 I 本文**　繼承人自繼承開始時，除本法另有規定外，承受被繼承人財產上之一切權利、義務。

> **強制執行法 §98 I**　拍賣之不動產，買受人自領得執行法院所發給**權利移轉證書**之日起，取得該不動產所有權。→ 建議查閱最新條文

> **§824**（共有物分割方法）分割之方法不能協議決定，或於協議決定後因消滅時效完成經共有人拒絕履行者，法院得因任一共有人之請求，命為分配。→ 摘要，建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「繼承人須辦繼承登記才取得不動產所有權？」 | **否**，死亡時即取得；登記後才能**處分** |
| 「拍賣不動產之拍定人何時取得所有權？」 | 領得**權利移轉證書**時，不是拍定或繳款時 |
| 「徵收何時移轉所有權？」 | 補償費**發給完竣**（含提存）時 |
| 「§759 之法院判決包括給付判決？」 | **不包括**，限**形成判決** |
| 「訴請履行分割協議勝訴確定，判決確定時取得分得部分？」 | **否**，須辦分割登記才生效 |
| 「裁判分割判決確定，未登記前已取得分得部分？」 | **是**，未登記不得處分 |
