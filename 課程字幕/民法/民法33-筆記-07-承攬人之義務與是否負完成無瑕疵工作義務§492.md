# 民法33 筆記：承攬人之義務與是否負完成無瑕疵工作義務（§492）

## 承攬的法律構造：
| 當事人 | 義務 |
|---|---|
| 承攬人 | ① **完成工作**（遲延 → 民法33-筆記-08）② **瑕疵擔保**（民法33-筆記-09 以下） |
| 定作人 | ① **給付報酬**（承攬是有償契約）② **協力義務** |

## 協力義務：
- 有些工作承攬人一個人做不完，例：跑消防執照、建築執照，屋主不配合就辦不下來
- 定作人不協力，是債務不履行還是另有法律效果 → 爭點，下一講續講

## 爭點：「完成工作」要不要到無瑕疵的程度？
| | 實務（否定） | 學說（肯定：陳自強、吳光明） |
|---|---|---|
| 結論 | 做完就是做完 | 有完成**無瑕疵**工作的義務 |
| 有瑕疵時 | 工作已完成，走 **§492～§495 瑕疵擔保**，不再處理債務不履行 | 工作根本沒完成，構成**債務不履行** |
| §492～§495 的定位 | 瑕疵擔保規定 | 只是把 §227 不完全給付明文化的**確認性規定** |

## 學說的文義論證：
- §354（買賣）：出賣人「**應擔保**」其物無瑕疵 → 擔保責任
- §492（承攬）：承攬人完成工作，「**應使**」其具備約定品質、無瑕疵 → 立法者要承攬人負這個**義務**
- 用語不同，可推出承攬人負完成無瑕疵工作之義務

## 老師的寫法：
- 自己寫擬答多採實務：完工和瑕疵切開，論述簡單，也符合條文架構
- 採學說往債務不履行寫也可以，看自己哪種論述順

## 📖 法條原文速查

> **§492**　承攬人完成工作，**應使**其具備約定之品質，及無減少或滅失價值，或不適於通常或約定使用之瑕疵。

> **§354 I**　物之出賣人對於買受人，**應擔保**其物依第三百七十三條之規定危險移轉於買受人時無滅失或減少其價值之瑕疵，亦無滅失或減少其通常效用或契約預定效用之瑕疵。但減少之程度，無關重要者，不得視為瑕疵。

> **§227 I**　因可歸責於債務人之事由，致為不完全給付者，債權人得依關於給付遲延或給付不能之規定行使其權利。

> **§507**（協力義務，要旨）　工作需定作人之行為始能完成，而定作人不為其行為時，承攬人得定相當期限催告定作人為之；逾期不為者，承攬人得解除契約並請求損害賠償。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **85 台上 2280**（要旨，講義註 1184）：承攬人完成之工作應具備約定品質、無瑕疵，為 §492 所明定，此係承攬人瑕疵擔保責任之規定，與承攬工作之完成無涉。工作已完成者，縱有瑕疵，亦不能因此謂工作未完成。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「工作有瑕疵，實務認為工作未完成？」 | **否**，已完成，走瑕疵擔保 |
| 「§492 用語與 §354 的差別？」 | §492「**應使**」、§354「**應擔保**」 |
| 「學說認為 §492～§495 的性質？」 | §227 不完全給付的**確認性規定** |
| 「承攬人的主要義務？」 | 完成工作、瑕疵擔保 |
| 「定作人的主要義務？」 | 給付報酬、協力 |
