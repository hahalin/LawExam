# 民法05 筆記：§84 處分財產的允許與「處分」的三種意義

> 來源：民法05 課程字幕 00:13:37 ~ 00:21:40

---

## 📖 法條原文速查

> **§84**（特定財產處分之允許）
> 法定代理人允許限制行為能力人**處分**之財產，限制行為能力人，就該財產有處分之能力。
> → 廣義處分（債權行為＋物權行為）

> **§118 I**（無權處分）
> 無權利人就權利標的物所為之**處分**，經有權利人之承認始生效力。
> → 狹義處分（物權行為、準物權行為）

> **§68 II**　主物之**處分**，及於從物。→ 廣義處分

> **§765**（所有權之內容）
> 所有人，於法令限制之範圍內，得自由使用、收益、**處分**其所有物，並排除他人之干涉。
> → 最廣義處分（含事實上處分）

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§118 之處分指？」 | **狹義**：物權行為、準物權行為（以權利變動為目的） |
| 「§84、§68 之處分指？」 | **廣義**：法律上處分＝債權行為＋物權行為 |
| 「§765 之處分指？」 | **最廣義**：法律上處分＋事實上處分（使用、消費、毀損） |
| 「父母允許子女處分零用錢，子女以零用錢分期購買 4 萬元 iPhone？」 | **超出父母預見範圍** → 不在允許範圍內 |
| 「子女以零用錢買樂透中 100 萬，對獎金有無處分能力？」 | **無**。中獎超出預見範圍；若中 1,000 元與零用錢相當則仍可 |
| 「父母允許子女賣掉 Switch，是否包含買賣契約？」 | **包含**。§84 的處分是廣義，含債權行為與物權行為 |

---

## 一、「處分」在民法裡不只一個意思

```
最廣義處分（§765）＝ 事實上處分 ＋ 法律上處分
    事實上處分：不發生法律效果的支配 → 騎腳踏車去公園、把車洗乾淨、把東西吃掉
    法律上處分：發生權利義務變動
        廣義處分（§84、§68 II）＝ 債權行為 ＋ 物權行為
            狹義處分（§118）＝ 物權行為、準物權行為（只以權利變動為目的）
```

| 條文 | 處分的意義 | 為什麼 |
|------|-----------|-------|
| **§118** | 狹義：物權行為、準物權行為 | 無權處分講的是權利變動 |
| **§84** | 廣義：債權＋物權行為 | 父母允許小孩「賣」Switch，不可能只允許物權行為、不允許買賣契約 |
| **§68 II** | 廣義 | 把車洗乾淨備胎不會跟著乾淨 → 事實上處分不及於從物 |
| **§765** | 最廣義 | 所有人可以用、可以賣、也可以把它弄壞 |

- 選擇題會問：下列哪個處分是廣義／狹義／最廣義？要從每條的內涵看。

## 二、§84 的關鍵：法代的預見可能性

```
父母允許處分的財產（零用錢）→ 就該財產有處分能力
但處分的「結果」若超出父母預見 → 不在允許範圍
```

| 情形 | 在允許範圍內？ |
|------|------|
| 每週 1,000 元零用錢，買文具、吃飯 | ✓ |
| 用每週 1,000 元零用錢向老闆分 40 期買 4 萬元 iPhone | ✗ 一週給 1,000 卻拿著最新 iPhone，殊難想像 |
| 零用錢買樂透中 100 萬，再處分獎金 | ✗ 超出預見，對獎金無處分能力 |
| 零用錢買樂透中 1,000～1,200 元 | ✓ 與零用錢相當 |
