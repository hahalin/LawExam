# 民法15 筆記：不法性與阻卻違法事由

## 結果不法說（通說）：
- 不法性是**客觀**判斷行為值不值得非難；有責性（故意過失、責任能力）是**主觀**判斷
- §184 I 前段把「故意或過失」與「不法」分開規定 → **過失不法二元論** → 判斷不法時不談過失 → **結果不法說**
- 行為不法說（如日本法，過失不法一元論）會把過失放進不法判斷；老師比喻像刑法階層理論的主客觀混合
- 判斷方法：①有損害結果 ②無阻卻違法事由 → 不法性具備

## §184 I 前段三層結構：
- 要件（行為、權利、損害、因果）→ 不法（客觀非難）→ 有責（主觀非難）
- 經典例：討債集團用老虎鉗拔牙 vs 牙醫拔牙，前四要件都有，差在**有無被害人承諾**

## 阻卻違法事由：
- ①**§149～152**：正當防衛、緊急避難、自助行為；民法自有規定，不必類推刑法
- ②**得被害人承諾**（最常見）：須**有效**——不違反公序良俗、須合法；例：與 15 歲之人發生性行為，縱經同意仍屬無效承諾 → 侵害貞操權；拳擊**生死狀**以生命為承諾，可能因違背善良風俗而無效
- 承諾可**明示**或**默示**：陳聰富書中多為默示——參與活動即默示同意該活動之**合理風險**（觀賽被高爾夫球、棒球界外球打到；籃球卡位碰撞 ✓，但拿拐子打人 ✗）
- ③**行政法規**：最高法院認為**不能**阻卻民法上違法。符合排放標準只代表國家不罰你，不代表不必賠（老師舉六輕；標準可能為發展產業而訂得很低）；民法仍要求善良管理人注意

## 自甘冒險 vs 被害人承諾：
- 分界：對**受傷結果**有無**認識＋同意**
- 被害人承諾：認識且同意結果發生 → **阻卻不法** → 完全不用賠
- 自甘冒險：知道危險仍去做，但**不同意**受傷 → 侵權仍成立 → 以**與有過失（§217）減輕**
- 例：甲明知乙無照、酒駕仍搭乘，車禍受傷 → 自甘冒險 → 乙仍負責，依與有過失減輕

## 📖 法條原文速查

> **民法 §149**　對於現時不法之侵害，為防衛自己或他人之權利所為之行為，不負損害賠償之責。但已逾越必要程度者，仍應負相當賠償之責。

> **民法 §150 I**　因避免自己或他人生命、身體、自由或財產上急迫之危險所為之行為，不負損害賠償之責。但以避免危險所必要，並未逾越危險所能致之損害程度者為限。

> **民法 §151**　自助行為（為保護自己權利，於不及受公權力援助等要件下，對他人自由或財產施以拘束、押收或毀損）。（原文請對六法）

> **民法 §217 I**　損害之發生或擴大，被害人與有過失者，法院得減輕賠償金額，或免除之。

> **民法 §72**　法律行為，有背於公共秩序或善良風俗者，無效。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「我國侵權行為法之不法性採何說？」 | 通說：**結果不法說**（§184 I 前段故意過失與不法分列＝過失不法二元論） |
| 「符合行政法規之排放標準，可否阻卻侵權行為之違法？」 | **不可**（最高法院）。行政法規只決定國家罰不罰，不是民事賠償之阻卻事由 |
| 「與未成年人（15 歲）經其同意發生性行為，可否以被害人承諾阻卻違法？」 | **不可**。承諾無效 → 侵害貞操權 |
| 「觀看棒球賽被界外球擊中，得否求償？」 | 原則不得：參與／觀賽＝**默示承諾**合理風險 → 阻卻違法 |
| 「明知駕駛酒駕仍搭乘而受傷？」 | **自甘冒險**，非被害人承諾 → 侵權成立，依 **§217 與有過失**減輕 |
| 「被害人承諾與自甘冒險之區別？」 | 承諾＝對結果**認識＋同意** → 阻卻不法、全免；自甘冒險＝只認識危險、**不同意**結果 → 成立、減輕 |
| 「拳擊比賽生死狀之效力？」 | 以生命為承諾，可能違背公序良俗而**無效** |

## 一、三層結構

```
§184 I 前段
├── 要件層：行為、權利、損害、因果（客觀上有無侵權）
├── 不法層：客觀上值不值得非難（結果不法：有結果＋無阻卻事由）
└── 有責層：故意過失、責任能力（主觀非難）
```

## 二、阻卻違法事由總表

| 類型 | 內容 | 注意 |
|---|---|---|
| §149 正當防衛 | 對現時不法侵害之防衛 | 逾越必要程度仍負相當責任 |
| §150 緊急避難 | 避免急迫危險 | 不逾越危險所能致之損害程度 |
| §151 自助行為 | 不及受公權力援助時 | 要件嚴格 |
| 被害人承諾（明示） | 手術同意等 | 須有效：合法、不違背公序良俗 |
| 被害人承諾（默示） | 參與運動、觀賽 | 限活動之**合理風險** |
| 行政法規 | — | **✗ 不能阻卻** |

## 三、承諾 vs 自甘冒險

| | 被害人承諾 | 自甘冒險 |
|---|---|---|
| 對危險之認識 | 有 | 有 |
| 對結果之同意 | **有** | **無** |
| 效果 | 阻卻不法 → 侵權不成立 | 侵權成立 |
| 賠償 | 不用賠 | §217 與有過失減輕 |
| 例 | 了解後遺症仍同意手術 | 明知酒駕仍搭車 |
