# 民法24 筆記：種類之債之特定與交付必要行為完結（§200 II、§235）

## 特定是什麼：
- 從「一台筆電」變成「**這台**筆電」
- 特定後，契約標的只剩這一台：
  - 這台滅失 → **給付不能**
  - 這台有瑕疵 → 瑕疵擔保
  - 店裡其他商品與你無關

## 特定的兩個原因（§200 II）：
- **經債權人同意指定**：到門市買手機，店員拿出一支請你檢查，你看過說沒問題 → 特定，爭議少
- **交付必要行為完結**：考試最愛考
  - 注意不是「交付完結」，多了「必要行為」
  - 交付＝**提出＋受領**；債務人只控制得了提出 → 完成**提出**即可，受領與否不問

## 什麼叫提出（§235）：
- **赴償之債**（送到債權人住所或指定地點）→ 須**現實提出**：依約送到，就完結
- **往取之債**（債權人自己來拿）→ **言詞提出**：準備好給付並**通知**債權人，即生提出效力（§235 但書）
  - 字幕作「延遲提出」「王取之債」，依法律用語校正為言詞提出、往取之債

## 考題：水晶燈
1. 甲向乙買水晶燈（種類之債），約定時間地點送到
2. 乙依約送到，甲忘記、不在家，請乙下午再送
3. 乙回程發生車禍，水晶燈滅失，乙**不可歸責**

### 分析
- 乙依約送到甲指定地點那一刻 → 交付必要行為完結 → **標的特定**（§200 II）
- 特定物滅失 → **給付不能**
  - 甲不能再依 §348 請求給付（乙依 §225 I 免給付義務）
  - 甲也不能依 §226 請求賠償（乙不可歸責）
- 乙可否依 §367 請求價金？**可以**
  - 甲受領遲延（§234）；實務與王澤鑑認為**受領遲延本身是可歸責事由**
  - 給付不能可歸責於甲 → §267，甲仍須為對待給付
  - 學理上的不同分析留到受領遲延再講

## 老師提醒：
- 種類之債的考點不在「給中等品質」，而在「**提出到一半東西沒了**」
  - 提出前滅失 → 原則無給付不能，再給一台
  - 已提出（特定）後滅失 → 走給付不能

## 📖 法條原文速查

> **§200 II**（種類之債之特定）　前項情形，債務人**交付其物之必要行為完結**後，或**經債權人之同意**指定其應交付之物時，其物即為特定給付物。

> **§235**（提出之方式）　債務人非依債務本旨實行提出給付者，不生提出之效力。但債權人預示拒絕受領之意思，或給付兼需債權人之行為者，債務人得以準備給付之事情，**通知**債權人，以代提出。

> **§234**（受領遲延）　債權人對於已提出之給付，拒絕受領或不能受領者，自提出時起，負遲延責任。

> **§225 I**　因不可歸責於債務人之事由，致給付不能者，債務人免給付義務。

> **§267**　當事人之一方因可歸責於他方之事由，致不能給付者，得請求對待給付。但其因免給付義務所得之利益或應得之利益，均應由其所得請求之對待給付中扣除之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「種類之債何時特定？」 | **交付必要行為完結**，或**經債權人同意指定** |
| 「交付必要行為完結是否以債權人受領為必要？」 | **否**，完成提出即可 |
| 「赴償之債的提出方式？」 | **現實提出**（送到約定地點） |
| 「往取之債的提出方式？」 | **言詞提出**：準備給付並通知 |
| 「送達後債權人不在，回程不可歸責滅失，買受人可否請求給付？」 | **不可**，已特定 → 給付不能，§225 免給付義務 |
| 「出賣人可否請求價金？」 | **可以**，受領遲延視為可歸責於債權人，§267 |

## 水晶燈案流程

```
訂約（種類之債）
   ↓ 乙依約送到甲指定地點
交付必要行為完結 → 特定（§200 II）＋甲受領遲延（§234）
   ↓ 回程車禍，乙不可歸責
給付不能
   ├─ 甲 → 乙：§348 給付 ✗（§225 I）；§226 賠償 ✗
   └─ 乙 → 甲：§367 價金 ✓（§267，受領遲延視為可歸責於甲）
```
