# 民法25 筆記：選擇之債之給付不能（§211）

## 先定選擇權人：
- 甲乙約定由 A、B、C 三種給付中選一種，甲為債務人、乙為債權人
- 依 **§208**，選擇權原則上屬於**債務人**甲（選擇之債的基本規則見民法24-筆記-08）
- 其中 A 給付不能 → 依 §211 處理，關鍵是「**由誰負責**」

## §211 本文：債之關係僅存於餘存給付
- A 因**可歸責於甲**（選擇權人）而不能 → 甲只能就 **B、C** 選一個給付
- 甲本來就可以從 B、C 選，所以沒有太大問題
- 雙方都不可歸責時，也依本文，存在於餘存給付

## §211 但書：不能事由應由**無選擇權**之當事人負責
- A 因**可歸責於乙**（無選擇權人）而不能 → 不在此限：甲**仍可選擇 A**
- 甲選 A 的效果：
  - 對甲而言是不可歸責、可歸責於乙的給付不能
  - §225 I：甲**免給付義務**，不用交 A
  - §267：乙**仍須為對待給付**
- 也就是說，甲不必交東西，還可以向乙要錢

## 讀法：
- 但書的意思是：有選擇權的人可以選那個已經不能的給付，再依給付不能的規則處理
- 可歸責於自己（選擇權人）→ 不能選不能的那個；可歸責於對方 → 可以選

## 📖 法條原文速查

> **§208**　於數宗給付中得選定其一者，其選擇權屬於**債務人**。但法律另有規定或契約另有訂定者，不在此限。

> **§211**　數宗給付中，有自始不能或嗣後不能給付者，債之關係僅存在於**餘存之給付**。但其不能之事由，應由**無選擇權之當事人負責**者，不在此限。

> **§225 I**　因不可歸責於債務人之事由，致給付不能者，債務人免給付義務。

> **§267**　當事人之一方因可歸責於他方之事由，致不能給付者，得請求對待給付。但其因免給付義務所得之利益或應得之利益，均應由其所得請求之對待給付中扣除之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「選擇之債選擇權原則上屬誰？」 | **債務人**（§208） |
| 「一宗給付因可歸責於選擇權人而不能？」 | 債之關係存於**餘存給付**（§211 本文） |
| 「一宗給付因可歸責於無選擇權人而不能？」 | 選擇權人**仍得選該不能之給付**（§211 但書） |
| 「債務人選擇不能之給付後，效果？」 | §225 I 免給付＋§267 仍得請求對待給付 |

## 案例：ABC 三選一

```
甲（債務人、選擇權人）── A / B / C 選一 ──→ 乙（債權人）
A 給付不能
├── 可歸責於甲（有選擇權）→ §211 本文：甲只能就 B、C 選
├── 雙方不可歸責 → §211 本文：就 B、C 選
└── 可歸責於乙（無選擇權）→ §211 但書：甲可選 A
        → §225 I 甲免給付；§267 乙仍須付款
```

| 不能事由由誰負責 | 甲可否選 A | 結果 |
|---|---|---|
| 甲 | ✗ | 交 B 或 C |
| 乙 | ✓ | 不交東西，仍收對待給付 |
