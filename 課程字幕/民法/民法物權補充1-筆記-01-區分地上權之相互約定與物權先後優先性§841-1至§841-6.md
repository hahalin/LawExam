# 民法物權補充1 筆記：區分地上權之相互約定與物權先後優先性（§841-1至§841-6）

## 什麼是區分地上權（§841-1）
- 把土地的**水平利用**轉為**垂直利用**：在他人土地上下**一定空間範圍**內設定的地上權
- 例：地上 8～12 公尺給高架橋、地下 2～5 公尺給下水道或鐵路
- 本節沒規定的，**準用普通地上權**（§841-6）→ 只要記特別規定

## 區分地上權人之間的約定（§841-2）
- 甲的土地，上層設定給乙、下層設定給丙；乙丙空間可能互相干擾 → 可約定相互間使用收益的限制
- 對**地主**：約定未經土地所有人同意者，使用收益權消滅時，地主**不受拘束**；地主同意則受拘束
- 對**第三人**（受讓人）：約定**經登記**才能對抗

## 延長期間影響第三人（§841-3、§841-4）
- 法院依 §840 IV 定區分地上權期間，足以影響第三人權利者，應**併斟酌**第三人利益（§841-3）
- 依 §840 以時價補償或延長期間，足以影響第三人權利時，應對第三人為**相當補償**；不能協議由法院裁定（§841-4）
- 概念類似相鄰關係：忍受的一方有補償作為對價

## 數個用益物權並存：先來後到（§841-5）
- 同一土地有區分地上權與以使用收益為目的的物權同時存在，**後設定**物權的行使，**不得妨害先設定**的物權
- 例：甲先設定農育權給乙種樹，再設定區分地上權給丙；樹根伸入丙的空間 → 丙不得要求移除，後設定者要禮讓
- **立法理由**（選擇題考過）：區分地上權若經**先存在的用益物權人同意**而設定，後設定的區分地上權**得優先**於先物權行使

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 區分地上權之定義 | 他人土地上下一定空間範圍 |
| 區分地上權人間約定，未經地主同意 | 使用收益權消滅時，地主**不受拘束** |
| 約定對第三人之效力 | **登記**才能對抗 |
| 先設定農育權、後設定區分地上權衝突 | **先設定者優先**（§841-5） |
| 先物權人同意後設定區分地上權 | 後設定者**得優先**（立法理由） |
| 未規定事項 | 準用普通地上權（§841-6） |

---

## 先後優先判斷

```
同一土地：先物權（乙）→ 後設定區分地上權（丙）
   ├─ 乙未同意 → 乙優先，丙不得妨害乙（§841-5）
   └─ 乙同意丙設定 → 丙優先（立法理由）
```
