# 民法11 筆記：§111～§113 無效的法律行為——§111 一部無效原則全部無效（毒品買賣：毒品部分無效，價金部分跟著無效），例外除去該部分亦可成立者其他部分仍有效（僱傭契約附懷孕離職條款）；§112 無效行為之轉換（考點在身分法：無效認領→收養、無效拋棄繼承→特留分拋棄；票據：無效保證→背書）；§113 無效之損害賠償與回復原狀——實務當請求權基礎直接用 vs 王澤鑑：確認性規範（與 §18 II、§100 君子條款同類），應回歸 §179、§767、§91、§184 等

> 來源：民法11 課程字幕 01:25:40 ~ 01:34:40

## 📖 法條原文速查

> **§111**　法律行為之一部分無效者，全部皆為無效。但除去該部分亦可成立者，則其他部分，仍為有效。
> **§112**　無效之法律行為，若具備他法律行為之要件，並因其情形，可認當事人若知其無效，即欲為他法律行為者，其他法律行為，仍為有效。
> **§113**　無效法律行為之當事人，於行為當時知其無效，或可得而知者，應負回復原狀或損害賠償之責任。
> **§18 II**　前項情形，以法律有特別規定者為限，得請求損害賠償或慰撫金。（確認性規範之例）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律行為效力的四種結果？」 | 檢驗完成立要件、一般生效要件（行為能力、意思表示、標的）、特別生效要件（條件期限、處分權、代理權）後，只有四種：**有效、無效、得撤銷、效力未定**。§111～§117 講後三種的效果 |
| 「甲向乙購買毒品，毒品部分違反強行規定無效，價金部分有效？」 | **全部無效**（§111 本文）。不能說毒品不用給、錢還是要付 |
| 「僱傭契約附『懷孕即離職』條款，條款無效，整份契約？」 | **其他部分仍有效**（§111 但書）：除去該條款，僱傭契約不受影響 |
| 「§112 之例？」 | 無效之認領 → 轉換為收養；無效之拋棄繼承 → 轉換為特留分之拋棄；無效之票據保證 → 轉換為背書。財產法上少用，考點在身分法 |
| 「§113 之法律性質？」 | **實務：請求權基礎**，直接依 §113 請求損害賠償或回復原狀。**王澤鑑：確認性規範**——只是重申「法律行為無效時，你可能依 §91、§110、§245-1、§247、§184 負賠償責任，可依 §179、§767 回復原狀」，拿掉也沒差；若直接用 §113，其他要件較嚴格的請求權基礎（不當得利有自己的要件、範圍、效果）會被架空 |
| 「確認性規範的其他例子？」 | **§18 II**（人格權受侵害，法律有特別規定才得請求賠償——沒這條也知道）、**§100**（林誠二：君子條款，條件成否未定前損害相對人期待，條件成就後要賠——不是請求權基礎） |

## 一、§111：一顆老鼠屎壞了一鍋粥，但挖掉後粥沒被汙染就還能喝

| | 例 | 結果 |
|---|---|---|
| 本文：一部無效 → 全部無效 | 毒品買賣：標的「毒品」違法，「價金」本身不違法，但同一法律行為 | 全部無效 |
| 但書：除去該部分亦可成立 | 僱傭契約附懷孕離職條款（違反強行規定無效） | 條款無效，僱傭契約其他部分有效 |

## 二、§112：無效的行為剛好符合另一個法律行為的要件

- 身分法考點：無效認領 → 收養？無效拋棄繼承 → 特留分拋棄？票據法：無效保證 → 背書？
- 財產法上不常用，身分法再講。

## 三、§113：請求權基礎還是確認性規範

| | 實務 | 王澤鑑（學說） |
|---|---|---|
| 性質 | 請求權基礎 | 確認性規範：重申、確認既有規定 |
| 用法 | 直接依 §113 請求損害賠償、回復原狀 | 回復原狀用 §179、§767；損害賠償用 §91、§110、§245-1、§247、§184 |
| 理由 | 不用再找其他請求權基礎 | 直接用 §113 會架空其他要件較嚴的請求權基礎 |

- 老師：解題到現在都沒用過 §113——王澤鑑的書從不把它當請求權基礎。這比較像研究所考的性質問題；實務上找到一個回復原狀的依據操作就夠了。
