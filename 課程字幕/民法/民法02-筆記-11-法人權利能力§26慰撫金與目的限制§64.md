# 民法02 筆記：法人權利能力 §26、法人慰撫金與目的限制 §64

> 來源：民法02 課程字幕 02:04:54 ~ 02:21:36

---

## 📖 法條原文速查

> **§26**（法人之權利能力）
> 法人於**法令限制內**，有享受權利負擔義務之能力。但**專屬於自然人**之權利義務，不在此限。

> **§64**（財團董事行為無效之宣告）
> 財團董事，有**違反捐助章程**之行為時，法院得因主管機關、檢察官或利害關係人之聲請，**宣告其行為為無效**。

> **§195 I 前段**
> 不法侵害他人之身體、健康、名譽、自由、信用、隱私、貞操，或不法侵害其他人格法益而情節重大者，被害人**雖非財產上之損害**，亦得請求賠償相當之金額。
> → 條文寫「非財產上之損害」，沒有寫「精神痛苦」

---

## 📋 實務見解速查

> **62 年台上字第 2806 號判例**（早期）：公司係依法組織之法人，其名譽遭受損害，**無精神上痛苦可言**，登報道歉已足回復其名譽，無依 §195 I 請求精神慰藉金之餘地。

> **112 年度台上大字第 544 號裁定**（大法庭，改採肯定）：§195 I 之慰撫金係針對**非財產上損害**，精神痛苦只是其中一種；法人雖無精神痛苦，若受有其他**無法以金錢衡量**之損害，亦得請求。
> → 建議查閱裁定原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人有無權利能力？」 | **有**，原則與自然人同（§26；法人實在說） |
| 「法人權利能力之限制？」 | ① **法令限制** ② **專屬自然人**之權利義務（繼承、結婚、認領、收養） |
| 「法人得否請求慰撫金？」 | 早期判例**否**（無精神痛苦）→ **112 台上大 544 肯定**：精神痛苦專屬自然人，慰撫金不是 |
| 「社團法人之行為是否受目的限制？」 | **否**。§26 文義無此限制＋保護交易安全（一般人難查知法人目的） |
| 「財團董事違反捐助章程之行為，效力？」 | 法院得**宣告無效**（§64）；實務採**形成訴訟說**：宣告前**仍有效** |
| 「法人擬制說 vs 實在說？」 | 擬制：假裝是人；實在：就是人。我國採**實在說**（§26 全面承認權利能力） |

## 一、法人的權利能力：原則與自然人相同（實在說）

```
擬制說：假裝法人是人（早期）
目的財產說：只在一定目的／財產範圍內是人
實在說：法人就是人 ← 我國（§26：除法令限制外，有享受權利負擔義務之能力）
```
- 不是對立見解，是時代思潮演變。

## 二、限制一：法令限制

- 公司法、保險法、銀行法……很多法人不能做的事。

## 三、限制二：專屬自然人之權利義務

- 繼承權、身分行為（結婚、認領、收養）。「我要嫁給台積電」→ 不行。
- **爭點：慰撫金請求權算不算專屬自然人？**

### 兩個階段

| | 62 台上 2806（早期） | 112 台上大 544（現在） |
|---|---|---|
| 結論 | 法人**不能**請求慰撫金 | 法人**可以**請求慰撫金 |
| 理由 | 慰撫金＝安慰精神痛苦；法人無精神痛苦 → 無慰撫必要 | §195 I 文義是「**非財產上之損害**」＝無法用金錢衡量的損失；精神痛苦只是其中一種，不是唯一 |
| 論述結構 | 精神痛苦專屬自然人 → 慰撫金專屬自然人 | 精神痛苦專屬自然人（合理）→ 但**慰撫金不是**；法人若有精神痛苦以外、無法以金錢衡量的損害 → 得請求 |

### 老師評論
- 路徑開了，但**很難證明**：法人的損害幾乎都能金錢化（捐款從 1000 萬掉到 600 萬＝400 萬財產損害；業績下滑、產量減少都是錢；數額不確定可由民訴法酌定）。
- 要出現「純粹、無法用錢衡量、又不是精神痛苦」的法人損害，實務上還在等案例。

## 四、法人該不該受「目的」限制

### 社團法人：不受目的限制

```
文義：§26 只說「法令限制內」「專屬自然人者不在此限」，沒說「目的範圍外不在此限」
交易安全：A 社團法人（目的：醫療）向甲買一塊地純投資
    → 若受目的限制 → 買賣可能無效
    → 一般人與法人交易不會、也難以查證其目的（你來補習前查過補習班的目的含「教育」嗎？）
    → 為保護交易安全 → 不受目的限制 → 契約有效
```

### 財團法人：因 §64 而受限制

```
捐助章程一定寫捐助目的
    → 董事行為違反目的 ＝ 違反章程
    → §64：法院得宣告其行為無效
    → 財團法人實質上受目的限制
```

### 進階：§64「宣告無效」——宣告**前**有效嗎？

| | 形成訴訟說（實務、王澤鑑） | 確認訴訟說（吳從周） |
|---|---|---|
| 宣告前 | **有效**；沒人聲請、法院沒宣告就一直有效 | **自始無效** |
| 宣告後 | 無效 | 無效（只是確認） |
| 理由 | 最高法院一貫見解 | 用語是「宣告無效」不是「撤銷」。有效變無效的制度叫撤銷；「宣告」＝check 確認它本來就無效 |
| 例 | 王澤鑑：財團法人醫院買地投資，法院未宣告前仍有效 | — |

## 關鍵法條速查表

| 法條 | 內容 | 與本主題關聯 |
|------|------|------------|
| **§26** | 法令限制內有權利能力；專屬自然人者除外 | 本筆記核心 |
| **§64** | 財團董事違反捐助章程 → 法院得宣告無效 | 財團受目的限制的依據 |
| §195 I | 非財產上損害之賠償 | 法人慰撫金的文義依據 |

## 關鍵實務見解速查表

| 實務見解 | 要旨 |
|---------|------|
| 62 台上 2806 | 法人無精神痛苦，不得請求慰撫金（已被大法庭變更） |
| **112 台上大 544** | 法人得請求慰撫金；非財產上損害 ≠ 精神痛苦 |
