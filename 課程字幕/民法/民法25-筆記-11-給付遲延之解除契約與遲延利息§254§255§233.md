# 民法25 筆記：給付遲延之解除契約與遲延利息（§254、§255、§233）

## 先分期限類型：
- **絕對定期**（§255）：期限是契約**不可或缺的要素**，過了就不能達契約目的
  - 例：聖誕節活動的舞台布置，合約壓在 12/21 完成；結婚當天要布置好
  - 遲延 → **不必催告**，直接解除契約；依 §260 不妨礙損害賠償，通常搭配 §232
- **相對定期**（§254）：有期限但只是隨口約定，不是契約要素
  - 例：買家具約「下禮拜二送」，只是剛好那天在家
  - 遲延 → 須**定相當期限催告**，期限內仍不履行才能解約
- **未定期限**（§254）：見下方「催告兩次」

## 解約要不要以可歸責為要件？
- §254、§255 條文只寫「遲延給付」，沒寫可歸責
- 實務（**109 台上 346**，講義註 720）：仍須**可歸責**——體系解釋，這裡的遲延就是 §229、§230 的遲延

## 選擇題陷阱：未定期限要**催告兩次**
- 第一次：**§229 II** 的催告，使債務人陷於遲延（例：命 12/10 前交付）
- 第二次：**§254** 的定期催告，期滿不履行才有解除權（例：12/17 前再不交就解約）
- 解除權在**遲延後**才發生；只發一次「下週不交就解約」的存證信函，解約不生效力

## 定相當期限：催告期限太短也不是無效
- **有約定**（例：約定須定 10 日以上催告）：
  - 符合約定 → 催告有效，期滿不履行即可解約
  - 不合約定（只給 3 天）→ 不是催告無效；自催告時起經過**約定期限**仍不履行，基於誠信原則得解約（**90 台上 1231**，講義註 722）
- **無約定**：所定期間過短，也不認為催告無效；經過**相當期間**後發生效力（講義註 723 引 74 年第 1 次民事庭決議，字號建議查證）
- 理由：相當期間是讓債務人有準備履行的時間，時間給足了仍不履行，就可以解約

## §233 遲延利息（選擇題注意法條）：
- 金錢債務遲延 → 依法定利率（**§203 週年 5%**）計算遲延利息；約定利率較高從約定
- **對於利息，無須支付遲延利息**（例：當月 1 萬元利息沒付，不能就這 1 萬再算遲延利息）
- 證明有其他損害者，並得請求賠償

## 📖 法條原文速查

> **§254**　契約當事人之一方遲延給付者，他方當事人得**定相當期限催告**其履行，如於期限內不履行時，得解除其契約。

> **§255**　依契約之性質或當事人之意思表示，**非於一定時期為給付不能達其契約之目的**，而契約當事人之一方不按照時期給付者，他方當事人得**不為前條之催告**，解除其契約。

> **§233**　I 遲延之債務，以支付金錢為標的者，債權人得請求依**法定利率**計算之遲延利息。但約定利率較高者，仍從其約定利率。II 對於利息，**無須支付遲延利息**。III 前二項情形，債權人證明有其他損害者，並得請求賠償。

> **§203**　應付利息之債務，其利率未經約定，亦無法律可據者，週年利率為**百分之五**。

---

## 📋 實務見解速查

> **90 台上 1231**：當事人約定債務人遲延時，須經債權人定一定期限催告始得解約者，債權人催告所定期限雖較約定為短，但自催告時起已經過該約定期限，債務人仍不履行，基於誠信原則，應解為債權人得解除契約。

> **109 台上 346**：§254 解除權之發生，以債務人陷於可歸責之給付遲延為要件（依老師轉述）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「絕對定期行為遲延，解約須否催告？」 | **不須**（§255） |
| 「相對定期行為遲延？」 | 須**定相當期限催告**（§254） |
| 「未定期限之債，解約須催告幾次？」 | **兩次**（§229 II＋§254） |
| 「催告期限短於約定期限，催告是否無效？」 | **否**，經過約定期限仍不履行得解約 |
| 「§254 解約須否可歸責？」 | 實務：**須** |
| 「利息遲付，可否再計遲延利息？」 | **不可**（§233 II） |
| 「法定利率？」 | 週年 **5%**（§203） |

## 解約路徑

```
給付遲延
├── 絕對定期 → §255：不催告直接解約（＋§232、§260 損賠）
├── 相對定期 → §254：定相當期限催告 → 期滿不履行 → 解約
└── 未定期限 → 第一次催告（§229 II，陷於遲延）
               → 第二次定期催告（§254）→ 期滿不履行 → 解約
```
