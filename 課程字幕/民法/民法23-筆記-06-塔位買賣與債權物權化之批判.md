# 民法23 筆記：塔位買賣與債權物權化之批判

## 案例（講義 358 頁，陳榮傳教授文章）：
- 甲是 A 納骨塔所有人，乙向甲買 **117 個塔位**，尚未交付或登記（老師：一次買 117 個顯然是投資）
- A 建物後來轉賣給丙、丁，又因丁的債權人強制執行，被戊拍定取得
- 乙對戊起訴，確認乙對這些塔位有**永久使用權**

## 一、二、三審：
- **一審**：塔位買賣具混合契約性質，類推 §425 I，使用關係對受讓人繼續存在 → 乙勝訴
- **二審**：§425 I 要求「承租人占有中」，塔位尚未交付、未占有 → 不得類推
- **最高法院**：引用**債權物權化**，但塔位既未交付也未登記，連**公示外觀**都沒有 → 不能物權化，乙之主張無理由

## 實務的債權物權化公式：
- 110 台上 1945：買賣契約只有債之效力，不得對抗契約外第三人；債權物權化至少要具備使第三人知悉該債權存在的**公示外觀**
- 實務等於採：**債權＋公示外觀＝可對抗第三人**

## 陳榮傳的批判：
- **誤會一**：把 §425 I 當成債權物權化 → §425 是把受讓人拉進來成為契約當事人，仍遵守債之相對性（見民法23-筆記-04）
- **誤會二**：「債權＋公示外觀即可對抗第三人」
  - 破壞債之相對性原則
  - 要突破既有原則必須有法律依據，現行法沒有規定
  - → 反對債權物權化理論
- **不能類推 §425 I**：塔位是**永久**使用、買斷權利；租賃是**一時性**，性質不同

## 真正的解套：特別法
- 殯葬管理條例（老師唸作第 33 條，條號建議查證）：骨灰（骸）存放設施應設置登記簿**永久保存**
- 陳榮傳認為：只要有**登記簿記載**（納骨塔內部登記即可，不必像土地登記那麼正式）或**占有外觀**，就有可以對抗納骨塔所有人的永久使用權
- 占有外觀不必放入骨灰罈：實務上在塔位貼紅紙寫「售」，表示已被訂走
- 老師評價：本文對「§425 I 被當成債權物權化」及債權物權化在實務被濫用的反思，很有建設性

## 📖 法條原文速查

> **§425 I**　出租人於租賃物交付後，承租人占有中，縱將其所有權讓與第三人，其租賃契約，對於受讓人仍繼續存在。

> **殯葬管理條例（塔位登記簿）**　公墓、骨灰（骸）存放設施應設置登記簿永久保存，並登載法定事項。→ 建議查閱最新條文原文與條號

---

## 📋 實務見解速查

> **110 台上 1945**：買賣契約僅有債之效力，基於債之相對性原理，不得以之對抗契約以外之第三人；所謂債權物權化而具有對抗第三人之效力，至少須具備使第三人知悉該債權存在之**公示外觀**方法。（依講義註釋整理）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「實務承認債權物權化的最低要件？」 | **公示外觀**（110 台上 1945） |
| 「塔位未交付未登記，買受人可否對抗拍定人？」 | 最高法院：**不可**，欠缺公示外觀 |
| 「塔位買賣可否類推 §425 I？」 | 二審：未占有；陳榮傳：永久 vs 一時，**不可** |
| 「陳榮傳對債權物權化的態度？」 | **反對**：破壞相對性、無法律依據 |
| 「塔位永久使用權的依據？」 | 殯葬管理條例登記簿或占有外觀（條號建議查證） |

## 各審見解對照

| | 理由 | 結果 |
|---|---|---|
| 一審 | 類推 §425 I | 乙勝 |
| 二審 | 未占有，不合 §425 要件 | 乙敗 |
| 三審 | 債權物權化，但欠缺公示外觀 | 乙敗 |
| 陳榮傳 | 兩條路都不對；依殯葬管理條例 | 有登記或占有外觀即可對抗 |
