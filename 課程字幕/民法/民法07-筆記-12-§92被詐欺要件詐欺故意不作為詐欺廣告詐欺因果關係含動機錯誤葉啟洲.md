# 民法07 筆記：§92 被詐欺的要件——詐欺故意、作為／不作為詐欺（告知義務）、廣告詐欺（真實≠誠實）、兩階段因果關係與「錯誤含動機錯誤」（葉啟洲反對）

> 來源：民法07 課程字幕 02:02:17 ~ 02:18:27（本堂結尾；第三人詐欺 §92 I 但書下堂續）

---

## 📖 法條原文速查

> **§92**（被詐欺或被脅迫之意思表示）
> I **因**被詐欺或被脅迫**而**為意思表示者，表意人得撤銷其意思表示。但詐欺係由第三人所為者，以相對人明知或可得而知其事實者為限，始得撤銷之。
> II 被詐欺而為之意思表示，其撤銷不得以之對抗善意第三人。

> **§93**　前條之撤銷，應於發見詐欺或脅迫終止後，一年內為之。但自意思表示後，經過十年，不得撤銷。

> **消費者保護法 §22**　企業經營者應確保廣告內容之**真實**，其對消費者所負之義務不得低於廣告之內容。→ 建議查閱最新條文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§92 被詐欺之要件？」 | ① 詐欺行為（含**故意**）② 兩階段因果關係（因詐欺陷於錯誤、因錯誤為意思表示）③ 第三人詐欺時相對人明知或可得而知（I 但書）④ 除斥期間（§93） |
| 「出賣人過失提供錯誤資訊？」 | **非詐欺**。詐欺須有詐欺**故意**，不小心講錯不算 |
| 「出賣人對車內曾有人自殺隻字未提？」 | 有**告知義務**而故意隱匿重要資訊 → **不作為詐欺**（不講也是一種騙） |
| 「廣告內容不真實即構成詐欺？」 | **否**（陳忠五）。不真實 ≠ 不誠實。廣告詐欺須 ① 客觀上廣告內容可擬制為**契約之一部**（針對契約要素之資訊）② 主觀上足以引起消費者**合理信賴** |
| 「女明星代言建案稱『我決定住在這裡了』，買受人以為可與其為鄰而購屋？」 | 鄰居是誰非契約要素、一般人不會合理信賴 → **非廣告詐欺** → 不得依 §92 撤銷 |
| 「因被詐欺陷於**動機錯誤**而為意思表示，得否撤銷？」 | **通說：得**。§92 不須顧慮相對人（騙人者）的交易安全，錯誤不限 §88 類型。**葉啟洲：否**，須為重要錯誤（參 §88 II），單純動機錯誤不得 |

## 一、體系
```
§92 被詐欺
├── 要件 ① 詐欺行為：作為（積極告知不實）／不作為（有告知義務而故意隱匿）；須有詐欺故意
│         廣告詐欺：真實 ≠ 誠實（陳忠五）
├── 要件 ② 因果關係：因詐欺 → 陷於錯誤 → 因錯誤 → 為意思表示（兩個「因」）
│         錯誤含不含動機錯誤？通說含；葉啟洲限重要錯誤
├── 要件 ③ 第三人詐欺（I 但書）→ 下堂
├── 要件 ④ 除斥期間 §93
└── 效果：撤銷；§92 II 不得對抗善意第三人（脅迫不在此限）
```

## 二、詐欺行為

| 類型 | 內容 | 例 |
|------|------|-----|
| 作為詐欺（積極） | 積極告知不實資訊 | 是凶宅說不是；泡水車說不是；事故車說沒事故 |
| 不作為詐欺（消極） | 對**重要資訊**，有**告知義務**而**故意隱匿** | 車內去年有人自殺，賣車時隻字未提——「我沒騙你，我只是沒講」仍是詐欺 |
| 隱藏要件：故意 | 不小心給錯資料不叫詐欺 | 給錯 ≠ 故意給錯 |

## 三、廣告詐欺（陳忠五）
```
消保法 §22 用「真實」兩個字 → 廣告不真實就是詐欺？
克寧奶粉「像大樹一樣高」沒長高 → 告詐欺？不可能
→ 陳忠五：【不誠實】才叫詐欺，不是【不真實】。廣告本來就浮誇，重點是有沒有誠實告知資訊
廣告詐欺的兩個要件：
  客觀：廣告內容可擬制為契約之一部（針對契約要素：房屋設備、汽車配備……）
  主觀：足以引起消費者的合理信賴
兩者都備＋內容不實 → 廣告詐欺；缺一 → 不是
```

### 台大法研所考題：女明星與退休公務員
```
退休公務員看到女明星代言淡水建案，slogan「我決定住在這裡了，你呢？」→ 以為能跟她當鄰居 → 問房仲（不清楚）→ 買了 → 女明星根本不住那
廣告不實？有。廣告詐欺？
  客觀：買賣契約要擔保鄰居是誰嗎？不用，契約要素是房屋本身；鄰居會搬家 → 不是契約之一部 ✗
  主觀：一般人不會真的相信她住那 → 無合理信賴 ✗
→ 非廣告詐欺 → 不得依 §92 撤銷
```
- 建案廣告「依山傍水、人間仙境」營造意象 ≠ 實況，不引起合理信賴 → 不是詐欺。

## 四、因果關係：兩個「因」
```
§92 I「因被詐欺……而為意思表示」
階段一：因被詐欺 → 陷於錯誤
階段二：因錯誤 → 為意思表示
```

### 這裡的「錯誤」含不含動機錯誤
| | 通說（多數說） | 葉啟洲（講義 193 頁〈愛情保險單與愛情靈骨塔〉） |
|---|---|---|
| 結論 | **含**。不再區分 §88 的類型 | **不含**單純動機錯誤，須重要錯誤 |
| 理由 | §88 是自己的錯，動機非交易要素，要顧相對人交易安全 → 不能撤；§92 是**你騙我**，相對人沒有被保護的必要 → 不管什麼錯誤都能撤 | 參照 §88 II，民法對單純動機錯誤的保護程度較低；不涉人的資格、物的性質者，縱被詐欺亦不得依 §92 撤銷 |

- 下堂：第三人詐欺（§92 I 但書，律師一試萬年考點）。
