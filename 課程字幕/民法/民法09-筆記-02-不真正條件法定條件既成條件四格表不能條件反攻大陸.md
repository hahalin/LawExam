## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「不真正條件之類型？」 | **法定條件、既成條件、不能條件、不法條件** |
| 「以『你承諾契約即成立』為條件？」 | **法定條件**＝法律構成要件，有無約定都一樣，無意義 |
| 「以**已發生**之事實為停止條件？」 | **視為無條件**（契約成立時條件早已成就 → 直接生效） |
| 「以已發生之事實為解除條件？」 | 法律行為**無效**（一成立就該失效） |
| 「以**確定不發生**之事實為停止條件？」 | **無效**（永遠不會生效） |
| 「以確定不發生之事實為解除條件？」 | **視為無條件**（永遠不會失效） |
| 「以客觀不可能之事實（長江北流）為條件？」 | **不能條件**，與確定不發生同處理：停止 → 無效；解除 → 視為無條件 |
| 「租約約定『租至反攻大陸之日』，出租人得否終止？」 | 早年視為**期限**（確定發生）→ 期限未屆至不得收回；近年視為**確定不發生／不能**之解除條件 → 視為無條件 → 不定期租賃 → 得隨時終止 |

## 一、法定條件：廢話條件
- 「如果你承諾，契約就成立」「我解除契約，契約就消滅」→ 把法律規定當條件，沒有意義。

## 二、既成條件：約定時就已經確定了（選擇題最愛）
```
條件應該是「不確定是否發生」；既成條件是約定時就已經確定發生、或確定不發生
→ 用推的，不要背：
```

| | 當**停止條件** | 當**解除條件** |
|---|---|---|
| **已確定發生**（農地早就能申請農舍；你去年就考上律師） | **視為無條件**：契約一成立條件就成就 → 直接生效，條件沒意義 | **無效**：一成立就要失效（租到你考上為止，你去年就考上了 → 不租了） |
| **已確定不發生**（問過 100 家銀行都貸不到八成；不孕症卻約定「懷孕就不租」） | **無效**：永遠不會生效 | **視為無條件**：永遠不會失效（當作沒這條件） |

## 三、不能條件：客觀上不可能
- 「長江北流就送你 1,000 萬」→ 客觀不可能 → 等同確定不發生：停止條件 → 無效；解除條件 → 視為無條件。

### 台灣限定：反攻大陸
```
民國 38 年國防部大量租地租屋安置軍人，租期寫「租到反攻大陸為止」
蔣中正時期：反攻大陸「確定會發生」→ 期限 → 期限未屆至 → 地主不能收回，只能收租
八二三砲戰後：兩岸分治，「不確定是否發生」→ 真正條件
近年判決：確定不發生、甚至客觀不可能 → 以反攻大陸為解除條件 → 視為無條件
→ 變成不定期限、無條件的租賃 → §450 II 隨時可終止 → 地主收回土地、另訂租約
```
- 老師：同一個附款隨時代有不同解釋脈絡，大概只有台灣感受得到。
