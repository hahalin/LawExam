# 民法債權補充2 筆記：經理人、居間與行紀（§554§568§573§578）

## 經理人（§554）
- 對第三人，就商號或其分號或事務之一部，**視為**有為管理上一切必要行為之權（§554 I）
- 有管理權不等於什麼都能做：除有**書面授權**外，對**不動產不得買賣或設定負擔**（§554 II）
- 以**買賣不動產為營業**的商號經理人，不受此限制（§554 III）
- 對照：委任也有須特別授權的事項（§534）

## 居間：報告訂約機會或媒介（仲介）
- 居間人不是被媒介契約的當事人；甲報告乙丙訂約，買賣契約在乙丙之間
- **義務**：就訂約事項據實報告；對顯無履行能力或無訂約能力之人不得媒介（§567 I）；並有調查義務
- **報酬**（§568）：
  - 契約因其報告或媒介而**成立**者為限，始得請求（報酬後付）
  - 被媒介的契約附**停止條件**者，條件成就前不得請求
- **爭點：跳過仲介私下成交**
  - 甲居間，告訴乙「丙有意願」；乙終止居間契約，私下與丙訂約
  - 實務：§568 I 的報酬請求權以「契約因其報告而成立」為**停止條件**；乙以**不正當方法阻止條件成就** → 依 **§101 I** 視為條件已成就 → 甲仍可請求報酬
- **婚姻居間**（§573）：約定報酬者，就其報酬**無請求權**
  - 是「無請求權」不是「無效」：媒人不能請求，但當事人主動給的紅包有法律上原因，**不能依不當得利要回**

## 行紀：代買代賣
- 以**自己名義**，為他人計算，為動產買賣或其他商業交易而受報酬之營業（§576）
- 例：託日本代購業者買東西
- 行紀人為委託人計算所訂立的契約，對相對人**自得權利、自負義務**（§578）→ 委託人不是契約當事人
- 與代理不同：代理效果直接歸本人；行紀的效果不歸委託人
- 相對人不履行債務時，行紀人對委託人**直接負履行**責任；契約另有訂定或習慣者除外（§579）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 經理人可否出賣商號不動產 | 須**書面授權**；以買賣不動產為業者除外 |
| 居間人何時得請求報酬 | 契約因其報告或媒介而**成立** |
| 被媒介契約附停止條件 | 條件成就前不得請求 |
| 委託人跳過仲介私下成交 | §101 視為條件成就，仍得請求 |
| 婚姻居間約定報酬 | **無請求權**（非無效） |
| 行紀契約當事人 | **行紀人**，非委託人 |
