# 民法10 筆記：§107 代理權之限制或撤回（越權代理）——相對人須善意且無過失；歸責事由：事後限制 ✓、自始限制（學說：無創造外觀 → 無 §107；實務：文義解釋包含）、撤回必為事後；學說：須「外部授權、內部限制／撤回」才有外觀；各條善意程度比較（§107 §169 善意無過失／§801 §948 善意無重大過失／§759-1 善意即可）

> 來源：民法10 課程字幕 01:18:21 ~ 01:28:01

---

## 📖 法條原文速查

> **§107**　代理權之限制及撤回，不得以之對抗善意第三人。但第三人因過失而不知其事實者，不在此限。
> **§167**　代理權係以法律行為授與者，其授與應向代理人或向代理人對之為代理行為之第三人，以意思表示為之。（內部授權／外部授權）

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§107 之要件？」 | ① 本人曾授權，其後**限制或撤回**代理權 ② 第三人（＝相對人）**善意且無過失**（但書：因過失而不知者除外） |
| 「『不得對抗善意第三人』之意義？」 | 第三人得要求本人負**授權人責任**（當作有權代理），本人不得以代理權已限制或撤回為抗辯 |
| 「自始限制有無 §107 適用？」 | **學說：無**——一開始就說「底價 30 萬」，本人沒有創造「無限制」的外觀，第一個要件（可歸責）就不成立，回歸 §170 無權代理。**實務：有**——文義「限制」不分自始事後，只要第三人善意無過失即可。學者批評對本人太重 |
| 「撤回有無自始撤回？」 | **無**。撤回一定是事後的（一邊授權一邊撤回，授權幹嘛） |
| 「學說上典型的 §107 情境？」 | **外部授權**（公開委託房仲賣地，大家都知道）→ **內部撤回／限制**（跟房仲吵架私下撤回、私下訂底價，沒跟大家說）→ 第三人誤以為授權還在 → 有可歸責事由。若從頭到尾都是內部授權、內部撤回，根本沒有信賴可言 → 無 §107 |
| 「§107 相對人之善意程度？」 | **善意且無過失**。比較：§801＋§948 善意且無**重大**過失；§759-1 II **善意**即可；§110 通說善意即可（筆記 14） |

## 一、要件與效果

```
歸責事由：代理權之限制 or 撤回
相對人：善意且無過失（但書「因過失而不知」→ 例外可對抗）
效果：本人不得以限制、撤回對抗 → 第三人可請求本人負授權人責任
```

## 二、限制：自始 vs 事後

```
二手車商案
事後限制：授權車商賣車時沒開底價（大家看到「他有代理權賣車」的外觀）
          → 事後打電話說「底價 30 萬」→ 外觀上看不到底價限制 → 典型可歸責 ✓
自始限制：一開始就講清楚「底價 30 萬」→ 根本沒有創造「無底價」的外觀
          學說：無 §107 適用（本人沒創造外觀，是你不知道，為什麼要我負責）
          實務：有 §107 適用（文義解釋：「限制」包含自始與事後）
```

| | 學說 | 實務 |
|---|---|---|
| 自始限制 | ✗ 無 §107，回歸無權代理 | ✓ 只要第三人善意無過失 |
| 事後限制 | ✓ | ✓ |
| 撤回 | ✓（必為事後） | ✓ |

## 三、學說更進一步：外部授權 → 內部限制／撤回

```
考試劇情：甲高調公開「委託某房仲賣地，有興趣找他」（外部授權，§167）
         → 甲與房仲吵架（成數抽太高）→ 低調撤回授權，沒跟大家說（內部撤回）
         → 第三人誤以為授權還在 → 這才叫創造外觀、可歸責
反面：一開始就偷偷內部授權、撤回也偷偷 → 沒人知道發生什麼事 → 沒有值得保護的信賴 → 回歸 §170
→ §107 真正用得到的情形不多：外部授權＋事後內部撤回／限制
```

## 四、各條「善意」的門檻不同（選擇題愛比）

| 法條 | 門檻 |
|---|---|
| **§107、§169** | 善意且**無過失** |
| §801＋§948（動產善意受讓） | 善意且無**重大**過失 |
| §759-1 II（不動產信賴登記） | 善意即可 |
| §110（通說） | 善意即可（筆記 14） |
