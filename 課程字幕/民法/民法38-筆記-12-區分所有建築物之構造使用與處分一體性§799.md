# 民法38 筆記：區分所有建築物之構造使用與處分一體性（§799）

## 為什麼要有區分所有
- 一物一權：一棟房屋一個所有權。高樓大廈若只有一個所有權，幾百戶都是共有人，處分、管理沒有效率
- 法律上把大樓切成**專有部分**（單獨所有）與**共有部分**（全體共有）

## 專有部分 vs. 共有部分（§799 I、II）
- **專有部分**：**構造上**及**使用上**可獨立，且得單獨為所有權標的
  - 構造上獨立：有明確界定的空間
  - 使用上獨立：獨立出入口、獨立水電表，不必經過別人家
- **共有部分**：專有部分以外的其他部分，及不屬專有部分的附屬物
  - 常考：**樓頂平臺**、**外牆**、公設（健身房、管理室、收發室）、社區花園、球場等附屬物
  - 外牆是共有 → 自家外牆掛競選旗幟，要由管委會決定，不是個別住戶
- **地下室**：不可一概而論；有構造及使用上獨立性者可為專有，規劃為防空避難或社區停車場者為共有

## 買一戶公寓移轉三樣（三位一體）
1. 專有部分（單獨所有權）
2. 共有部分應有部分（俗稱小公、公設）
3. **基地**應有部分——基地是土地，不屬於建築物本身

## 應有部分怎麼算（§799 IV）
- 依**專有部分面積 ÷ 專有部分總面積**；另有約定從其約定
- 例：5 戶各 100 坪，專有總面積 500 坪 → 每戶對共有部分與基地各 **1/5**

## 使用：專用與共用的例外（§799 III）
- 專有部分：原則專用；經**其所有人同意**，依規約可約定**共用**（例：一樓做交誼廳、管理中心）
- 共有部分：原則共用；**除法律另有限制外**，依規約可約定由特定所有人**專用**
- 法律限制例：法定避難空間、樓頂平臺不得約定專用（萬一災難，其他住戶沒處避難）→ 細節建議查閱公寓大廈管理條例

## 處分一體性（§799 V）
- 專有部分與所屬共有部分及基地權利，**不得分離**而為移轉或設定負擔
- 衍生考點：**土地登記規則 §98**——專有部分連同基地應有部分一併移轉給同一人時，**不適用土地法 §34-1 IV**
  - 例：甲乙丙丁為區分所有權人，甲把一戶（專有＋共有＋基地）賣給戊；丁不能就基地應有部分主張優先承購
- 歷史：公寓大廈管理條例（84 年）起才有一體性限制，98 年 §799 明文；84 年前分離處分常見，產權混亂、都更困難 → 物權編施行法 §8-5 設優先承買權調整（下一講民法39 筆記-01 接續）

## 📖 法條原文速查

> **§799 V**（處分一體性）專有部分與其所屬之共有部分及其基地之權利，不得分離而為移轉或設定負擔。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 專有部分之要件 | 構造上**及**使用上獨立 |
| 樓頂平臺、外牆屬於 | **共有部分** |
| 地下室屬於 | 個案判斷 |
| 共有部分及基地應有部分如何計算 | 專有部分面積比（§799 IV） |
| 專有部分約定共用之要件 | 所有人同意＋規約 |
| 共有部分約定專用之限制 | 法律另有限制者不得 |
| 專有部分連同基地出賣，他區分所有人可否優先承購基地 | **不可**（土登 §98、§799 V） |

## 構造圖

```
區分所有建築物（買一戶＝三樣）
 ├─ 專有部分：單獨所有權（構造＋使用獨立）
 ├─ 共有部分：全體共有，應有部分按面積比
 │     樓頂平臺、外牆、公設、附屬物
 └─ 基地：土地，全體共有，應有部分按面積比
 ── 三者不得分離處分（§799 V）
```

## 使用的原則與例外

| 部分 | 原則 | 例外 | 例外要件 |
|---|---|---|---|
| 專有 | 專用 | 約定共用 | 所有人同意＋規約 |
| 共有 | 共用 | 約定專用 | 規約，且法律無限制 |
