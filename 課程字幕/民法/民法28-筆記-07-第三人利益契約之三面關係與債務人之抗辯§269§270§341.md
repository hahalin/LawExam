# 民法28 筆記：第三人利益契約之三面關係與債務人之抗辯（§269、§270、§341）

## 構造：
- 甲＝**債務人**；乙＝**要約人兼債權人**；丙＝**利益第三人**
- 甲乙約定：甲向丙為給付，**且丙對甲有直接請求給付之權**
- 有沒有**直接請求權**是關鍵：
  - 有 → 第三人利益契約（§269）
  - 沒有 → 只是**指示給付關係**（也有人稱不真正第三人利益契約）（**96 台上 1105**）
- 老師提示：考試很愛考、能見度高

## 三段關係的名稱（考試會直接問）：
- 從**丙**的角度記：
  - 甲→丙：丙受領給付、可直接請求 → **履行關係**
  - 乙↔丙：丙左手受領給付、右手向乙提出對價 → **對價關係**
  - 甲↔乙：本該丙付給甲的對價跑去乙丙之間，所以乙要補償甲 → **補償關係**
- 常見混淆：對價關係不是「乙提出對價給甲」

## 甲丙之間（履行關係）：
1. 丙可直接請求甲給付
2. 甲**不能**向丙請求對待給付，對待給付只能向乙要
3. 甲債務不履行時：
   - **給付相關**的權利由**丙**行使：例如因瑕疵受傷的損害賠償
   - **對待給付相關**的權利由**乙**行使：例如減價、解約請求返還價金（錢是乙付的）
4. §270：甲得以**甲乙契約（補償關係）**所生的一切抗辯對抗丙
   - 例外：**§341 不得抵銷**
5. 甲**不能**拿**乙丙間（對價關係）**的抗辯對抗丙（債之相對性）
   - 例：乙丙間是贈與，乙有 §416 撤銷權，甲不能拿來用
   - 老師板書一度寫反，已當堂更正

## §341 抵銷禁止：
- 例：乙甲約定買賣價金 100 萬元直接付給丙，丙對甲有 100 萬元直接請求權；甲另對乙有 80 萬元借款債權
- 丙請求 100 萬元，甲能否以對乙的 80 萬元抵銷、只付 20 萬元？→ **不行**
- 理由：不是兩人互負債務的結構；甲丙債務有**獨立性**，是丙自己的直接請求權

## 乙丙之間（對價關係）：
- **可有可無**，不影響第三人利益契約的成立與效力
- 例：乙丙間贈與被撤銷而無效 → 頂多乙對丙主張 §179；甲丙關係不受影響
- 丙不需要證明對價關係存在（講義 549 頁註 861）

## 甲乙之間（補償關係）：
- 乙對甲有請求權，但內容是請求甲**向丙**給付，不能請求向自己給付（§269 I）
- 因此有**兩個**內容一致的請求權：乙→甲（向丙給付）、丙→甲（向自己給付）
- 甲對乙有對待給付請求權

## 📖 法條原文速查

> **§269 I**　以契約訂定向第三人為給付者，要約人得請求債務人**向第三人**為給付，其第三人對於債務人，亦有**直接請求給付之權**。

> **§270**　前條債務人，得以由**契約**所生之一切抗辯，對抗受益之第三人。

> **§341**　約定應向第三人為給付之債務人，**不得**以其債務，與他方當事人對於自己之債務為**抵銷**。

---

## 📋 實務見解速查

> **96 台上 1105**（講義 548 頁註 859）：第三人利益契約，乃當事人一方與他方約定，由他方向第三人為一定之給付，第三人因此取得**直接請求**他方給付權利之契約。倘第三人並未取得直接請求權，僅為指示給付關係，非 §269 之第三人利益契約。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「第三人利益契約與指示給付的區別？」 | 第三人有無**直接請求權** |
| 「債務人與第三人間稱為？」 | **履行關係** |
| 「要約人與第三人間稱為？」 | **對價關係**（可有可無） |
| 「債務人與要約人間稱為？」 | **補償關係** |
| 「標的物有瑕疵，誰得請求減價？」 | **要約人**（對待給付相關） |
| 「債務人得以對要約人之債權與第三人抵銷？」 | **不得**（§341） |
| 「債務人得以對價關係之抗辯對抗第三人？」 | **不得**，§270 只限補償關係 |

## 三面關係圖

```
          補償關係（§270 抗辯來源）
   甲 ═══════════════════════ 乙
（債務人）                  （要約人）
     ＼                       ／
履行關係＼                   ／對價關係
（丙直接請求）＼           ／（可有可無）
              丙（利益第三人）
```

| 權利 | 誰行使 |
|---|---|
| 請求甲向丙給付 | 乙、丙都可以 |
| 對待給付 | 甲向乙請求 |
| 給付相關損害賠償 | 丙 |
| 減價、解約返還價金 | 乙 |
