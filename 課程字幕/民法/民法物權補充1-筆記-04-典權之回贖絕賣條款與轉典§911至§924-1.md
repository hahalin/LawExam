# 民法物權補充1 筆記：典權之回贖絕賣條款與轉典（§911至§924-1）

## 典權的構造（§911）
- 甲需要資金：抵押借款要付利息；改成 → 乙付甲一筆**典價**，甲把不動產交乙**使用收益**
- 甲用錢不付利息，乙用地不付租金，各取所需
- 定義：支付典價，在他人不動產為使用收益，於他人不回贖時，取得該不動產所有權之權
- 標的：土地或房屋都可以（地上權、農育權只能以土地為標的）
- 典期中甲仍是所有人，仍可把不動產賣給第三人

## 期限與回贖
- 典權約定期限**不得逾 30 年**，逾者縮短為 30 年（§912）
- 時間到，甲有兩個選擇：
  - **回贖**：提出原典價 → 塗銷典權，甲回復完整所有權
  - **不回贖**：乙取得典物所有權

## 乙何時取得所有權（例：典價 500 萬、典期 20 年）
| 情形 | 乙取得所有權時點 | 條文 |
|---|---|---|
| 有**絕賣條款**（到期不贖即作絕賣） | 典期屆滿甲未回贖，**即**取得 | §913 II |
| 無絕賣條款、**有定期限** | 典期屆滿後 **2 年**內未回贖 | §923 |
| 無絕賣條款、**未定期限** | 出典後 **30 年**未回贖 | §924 |

- 絕賣條款限制：典期**不滿 15 年**者不得附絕賣條款（§913 I）
- 絕賣條款**非經登記不得對抗第三人**（§913 III）
- 依法律規定取得所有權，屬 §759，辦宣示登記即可

## 轉典與出租（§915）
- 典權存續中，典權人得將典物**轉典或出租**（另有約定或習慣者從之）
- 轉典或租賃期限**不得逾原典期**；原典未定期限者，轉典、租賃不得定期限
- **轉典典價不得超過原典價**
- 土地及其上建物同屬一人並為同一人設定典權者，不得分離轉典或處分

## 轉典後的回贖（§924-1）
- 甲典給乙 **1,000 萬** → 乙轉典給丙 **800 萬** → 丙轉典給丁 **700 萬**
- 甲向乙表示回贖，乙不於相當期間向丙回贖並塗銷 → 甲得於原典價範圍內，以**最後典價**逕向轉典權人回贖
- 計算：甲付丁 **700**；丙可請求差額 **100**；乙可請求差額 **200**；合計仍是 1,000
- 甲可為乙、丙**提存**差額；典權人預示拒絕塗銷或行蹤不明時亦同

## 📖 法條原文速查

> **§913**（絕賣條款）典權之約定期限不滿十五年者，不得附有到期不贖即作絕賣之條款。典權附有絕賣條款者，出典人於典期屆滿不以原典價回贖時，典權人即取得典物所有權。絕賣條款非經登記，不得對抗第三人。

> **§923、§924、§924-1** → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 典期上限 | **30 年** |
| 可附絕賣條款之典期 | **15 年以上** |
| 有絕賣條款，屆期不贖 | 典權人**即**取得所有權 |
| 定期典權，無絕賣條款 | 屆滿後 **2 年**不贖 |
| 未定期典權 | 出典後 **30 年**不贖 |
| 轉典典價、期限 | 不得超過原典價、原典期 |
| 轉典後出典人回贖 | 以**最後典價**向轉典權人回贖，差額給前手或提存 |

## 轉典回贖金流

```
甲 ─典價1000→ 乙 ─800→ 丙 ─700→ 丁（現在使用收益）
回贖：甲 → 丁 700（最後典價）
      甲 → 丙 100（800−700）
      甲 → 乙 200（1000−800）
      合計 1000 → 三個典權全部塗銷
```
