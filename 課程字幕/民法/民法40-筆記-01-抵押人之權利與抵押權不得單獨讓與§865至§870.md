# 民法40 筆記：抵押人之權利與抵押權不得單獨讓與（§865至§870）

## 大原則：抵押人什麼都能做，只要不影響抵押權人
- 甲以 A 地設定抵押權給乙後，甲仍是所有人，可以繼續處分、使用 A 地
- 物權講先來後到（優先性）：後發生的權利不能影響先成立的抵押權
- §866、§867、§868 的共同用語：「抵押權不因此而受影響」

## 抵押人可以做的事
- **再設定抵押權**（§865）：次序依登記先後，乙第一順位，後設定的丙第二順位
- **設定用益物權或出租**（§866 I）：地上權、租賃都可以；§866 是大考點，要搭配 §877 II、強制執行法 §98 II 一起看（見本講筆記-07～09）
- **讓與所有權**（§867）：抵押權有**追及效力**，跟著物走不跟著人走；甲把 A 地賣給丙，乙對丙的 A 地仍有抵押權
- **分割或一部讓與抵押物**（§868）：不可分性，見民法39-筆記-08

## 抵押權人這一端
- 債權分割、一部讓與、債務一部承擔，抵押權不受影響（§869，見民法39-筆記-08）
- **唯一不行的事（§870）**：抵押權不得與債權分離而讓與，也不得為其他債權之擔保
  - 例：乙把 A 債權讓給丁、自己留抵押權 → 不行
  - 例：乙欠丁錢，想把擔保 A 債權的抵押權改拿來擔保丁的 B 債權 → 不行
  - 抵押權只能隨債權讓與而移轉（§295）

## 📖 法條原文速查

> **§865**（抵押權之次序）不動產所有人，因擔保數債權，就同一不動產，設定數抵押權者，其次序依**登記之先後**定之。

> **§866 I**（設定用益物權或租賃）不動產所有人設定抵押權後，於同一不動產上，得設定地上權或其他以使用收益為目的之物權，或成立租賃關係。但其抵押權**不因此而受影響**。

> **§867**（抵押物之讓與）不動產所有人設定抵押權後，得將不動產讓與他人。但其抵押權不因此而受影響。

> **§870**（從屬性）抵押權**不得由債權分離**而為讓與，或為其他債權之擔保。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「抵押人設定抵押權後得否再設定第二順位抵押權？」 | **得**，次序依登記先後（§865） |
| 「抵押人設定抵押權後得否出租抵押物？」 | **得**，但抵押權不受影響（§866 I） |
| 「抵押物讓與第三人後，抵押權是否消滅？」 | **否**，追及效力（§867） |
| 「抵押權人得否保留抵押權而只讓與債權？」 | **否**（§870） |
| 「抵押權人得否以其抵押權為其他債權之擔保？」 | **否**（§870） |

---

## 體系整理

```
抵押權設定後
├─ 抵押人（所有人）── 再設定抵押 §865／設定用益、出租 §866／讓與 §867／分割 §868
│                       → 都可以，抵押權不受影響
└─ 抵押權人 ────────── 債權分割、讓與 §869 → 抵押權不受影響
                        抵押權單獨讓與或擔保他債權 §870 → 不行
```
