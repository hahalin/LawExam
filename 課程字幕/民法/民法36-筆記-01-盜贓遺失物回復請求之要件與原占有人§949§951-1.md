# 民法36 筆記：盜贓遺失物回復請求之要件與原占有人（§949、§951-1）

## 前講補充：指示交付的善意取得時點：
- 占有改定：§948 II 明文，須**受現實交付且交付時善意**（見民法35-筆記-11）
- 指示交付（§761 III）沒有明文，學說分兩說：
  - 史尚寬：我國法沒有德國法那種限制 → **讓與返還請求權時**即可善意取得
  - 王澤鑑：受讓人**向第三人取回標的物時**才真正占有 → 取回時仍善意才受保護
- 數字例：乙把借來的 A 車寄託在丙處，1/2 以指示交付賣給善意的丁，丁 1/10 向丙取回 → 史說 1/2、王說 1/10

## §949 在體系中的位置：
```
無權處分動產
  └─ 原則：§801＋§948 → 善意受讓人取得所有權（保護交易安全）
       └─ 例外：§949 → 原占有人 2 年內可推翻善意取得（本人比受讓人更值得保護）
            └─ 例外的例外：§950 付錢才能回復、§951 不得回復（見本講筆記-03）
```

## 四個要件：
1. 標的物係**非基於原占有人之意思而喪失占有**
2. 主張者是**原占有人**（惡意占有人除外，§951-1）
3. 對象是**善意受讓之現占有人**（轉得人爭議見本講筆記-02）
4. 自喪失占有時起 **2 年**內（除斥期間，見本講筆記-02）

## 要件一：非因己意喪失占有：
- 是：**盜贓、遺失、搶奪、強盜** → 東西「不翼而飛」，不是自己交出去的
- 不是：**被詐欺、被脅迫、錯誤、虛偽意思表示、侵占** → 都還有意思表示，是自己交出去的
- 對照刑法分則：因害怕交出財物（恐嚇）≠ 不能抗拒被拿走（強盜）
  - 被脅迫交出 → 不能用 §949；被強盜 → 可以
- 民總的占有喪失大多基於意思表示，所以民總很少碰到 §949

## 要件二：原占有人（有權、無權都算）：
- 占有是**事實狀態**不是權利；法條只寫「占有人」而沒排除者，有權、無權占有人都包括（§960、§962 也一樣）
- 有權占有人：所有人、**承租人**都可以主張
- 善意無權占有人：也可以（例：向未經輔助人同意的受輔助宣告人買車，買賣與移轉效力未定，買受人不知情）
- **惡意占有人不行**（§951-1）：小偷不值得保護，不能讓他去推翻善意第三人的交易

## 📖 法條原文速查

> **§949**
> I　占有物如係**盜贓、遺失物**或其他**非基於原占有人之意思而喪失其占有**者，原占有人自喪失占有之時起**二年以內**，得向**善意受讓之現占有人**請求回復其物。
> II　依前項規定回復其物者，自喪失其占有時起，**回復其原來之權利**。

> **§951-1**　第九百四十九條及第九百五十條規定，於原占有人為**惡意占有**者，不適用之。

> **§948 II**　動產占有之受讓，係依第七百六十一條第二項規定為之者，以受讓人受現實交付且交付時善意者為限，始受前項規定之保護。

> **§761 III**　讓與動產物權，如其動產由第三人占有時，讓與人得以對於第三人之返還請求權，讓與於受讓人，以代交付。

> **§15-2 I ⑤**　受輔助宣告之人為不動產、船舶、航空器、汽車或其他重要財產之處分、設定負擔、買賣、租賃或借貸，應經輔助人同意。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「被詐欺而交付之動產，得依 §949 請求回復？」 | **不得**，基於己意交付 |
| 「被強盜、搶奪之物，屬非基於己意喪失占有？」 | **是** |
| 「受託人侵占寄託物後出賣，寄託人得依 §949 回復？」 | **不得**，當初是自己交付 |
| 「承租人之租賃物被竊，承租人得主張 §949？」 | **得**，承租人是原占有人 |
| 「小偷之贓物又被他人竊取轉賣，小偷得主張 §949？」 | **不得**，惡意占有人（§951-1） |
| 「善意無權占有人得主張 §949？」 | **得** |
| 「以指示交付受讓，何時善意取得？」 | 史尚寬：讓與時；王澤鑑：取回時 |

## 原占有人四案比較

| 主張者 | 例 | 可否主張 §949 |
|---|---|---|
| 所有人 | 甲的車被偷 | 可 |
| 有權占有人 | 承租人乙租來的車被偷 | 可 |
| 善意無權占有人 | 向受輔助宣告人買車、不知情的乙 | 可 |
| 惡意無權占有人 | 偷甲車的乙，車又被丙偷 | **不可**（§951-1） |
