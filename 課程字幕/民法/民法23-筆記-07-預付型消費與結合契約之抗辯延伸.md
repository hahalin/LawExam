# 民法23 筆記：預付型消費與結合契約之抗辯延伸

## 案例（講義 364 頁）：
- A 健身房（或美語補習班）推出終身會員：先繳 **60 萬**，之後年費只要 1 萬（一般會員年費 6 萬）
- 甲拿不出 60 萬，A 介紹合作的 B 融資公司；甲向 B 借款（**消費借貸**），B 把 60 萬直接撥給 A
- 甲每月還 B 1 萬，分 60 期
- A 前幾年現金大量流入、擴大投資，之後收入只剩年費，撐不住而倒閉
- 甲沒課可上，不想再繳貸款 → 甲對 A 的**同時履行抗辯**（§264），能否延伸對 B 主張？

## 現代版：二手車貸
- 車商帶買受人向合作融資公司辦全額貸款
- 車有瑕疵，買受人依 §359 解除買賣、依 §259 請求回復原狀 → 能否也對融資公司拒絕繳款？
- 融資公司：借貸歸借貸、買賣歸買賣

## 早年實務：債之相對性
- A 與甲、B 與甲是兩個不同法律關係 → A 倒閉，甲只能向 A 求償，對 B 的貸款一塊都不能少
- 風險全由消費者承擔
- 後來政府要求預付型業者**履約保證**（收入一定比例交付履保），此類糾紛變少

## 楊淑文：結合契約之抗辯延伸（關鍵字要背）
- **要件**：A 與 B 之間有合作關係、互蒙其利（A 賣得出、B 借得出）
  - 消費者自己另找銀行貸款 → 沒有合作關係，不適用
- **理由**：
  - 若沒有 B，A 倒閉時甲停止付款即可，不承擔 A 的風險
  - B 加入後，甲卻要繼續繳款 → 合作關係**增加消費者不必要的風險**
  - 異業結盟者應相互承擔風險；得到合作好處的是 A、B，不是甲 → A 倒閉的風險應由 B 承擔
- 承認與債之相對性衝突，但符合風險分配與公平；在立法（履保、定型化契約規範）跟上之前，法院依 §1 法理有可操作的工具
- 實務：地院小額訴訟判決已有採納（講義註 568，新北地院，字號建議查證）

## 謝哲勝：結合契約本質上是一個契約
- A、B 與甲之間不是兩條線，而是**一個法律關係** → 沒有債之相對性問題，抗辯直接對抗，不必「延伸」
- 依據：講義註 567，國際財務報導準則中多個契約合併視為單一契約的概念（建議查證）
- 與楊淑文**結果一致、理論不同**

## 📖 法條原文速查

> **§264 I**　因契約互負債務者，於他方當事人未為對待給付前，得**拒絕自己之給付**。但自己有先為給付之義務者，不在此限。

> **§359**　買賣因物有瑕疵，而出賣人依前五條之規定，應負擔保之責者，買受人得**解除其契約**或請求減少其價金。但依情形，解除契約顯失公平者，買受人僅得請求減少價金。

> **§259**　契約解除時，當事人雙方回復原狀之義務，除法律另有規定或契約另有訂定外，依左列之規定……→ 各款建議查閱最新六法原文

> **§1**　民事，法律所未規定者，依習慣；無習慣者，依法理。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「健身房倒閉，依債之相對性，會員對融資公司？」 | 仍須還款（早年實務） |
| 「結合契約抗辯延伸的關鍵要件？」 | 出賣人與融資者有**合作關係** |
| 「消費者自行找銀行貸款，可否延伸抗辯？」 | **否**，無合作關係 |
| 「楊淑文與謝哲勝的差異？」 | 楊：兩個契約、抗辯延伸；謝：**一個契約** |
| 「延伸的抗辯是什麼？」 | 對 A 的同時履行抗辯（§264）、解除後回復原狀 |

## 三角關係圖

```
        A 健身房／車商 ←──── 合作結盟（互蒙其利）────→ B 融資公司
             ↑                                         ↑
   服務契約（同時履行抗辯 §264）              消費借貸（每月還款）
             └──────────────── 甲 ────────────────────┘

A 倒閉／車有瑕疵：
  債之相對性 → 甲仍須還 B
  楊淑文     → 甲對 A 的抗辯延伸到 B
  謝哲勝     → 三方是一個契約，直接對抗
```
