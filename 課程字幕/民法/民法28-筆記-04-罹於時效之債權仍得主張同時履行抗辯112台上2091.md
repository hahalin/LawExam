# 民法28 筆記：罹於時效之債權仍得主張同時履行抗辯（112台上2091）

## 案例（講義 532 頁，數字簡化）：
- 甲公司向乙承租房屋經營（類似健身房），交付一張**支票**擔保租金
- 租期屆滿，甲沒有回復原狀；乙自行拆除裝潢，花了 **80 萬元**
- 乙可依租賃關係請求甲賠償，但出租人對承租人的賠償請求權時效只有 **2 年**（§456）
- 兩年後，甲起訴請求乙返還支票
- 乙主張：① 甲應賠我 80 萬元 ② 甲不賠，我就不還支票（同時履行抗辯）
- 甲提出時效抗辯 → 80 萬元請求權已罹於時效
- 爭點：乙能不能拿已罹於時效的債權，主張同時履行抗辯？

## 最高法院：**可以**
- §264 只寫「因契約互負債務」，沒有要求該債務未罹於時效
- 同時履行抗辯是為**對抗他方請求權**而設，本質是抗辯，**沒有消滅時效**的問題
- 雙務契約互負債務有履行上的牽連關係；一方請求權罹於時效消滅，同時履行抗辯權仍存在
- 他方請求給付時，仍可行使同時履行抗辯拒絕自己的給付

## 二審：**不可以**
- 80 萬元已罹於時效、甲已為時效抗辯 → 乙就該債權不得請求給付 → 不發生同時履行抗辯
- 最高法院認為二審「所持法律見解已有可疑」而廢棄

## 老師的看法：贊同二審
- 同時履行抗辯是雙方互相履行的公平原則
- 甲本來可以拒絕付 80 萬元，現在為了拿回支票不得不付 → 等於用同時履行抗辯**架空消滅時效**
- 這是兩個制度的衝突；時效維護的法安定性仍應優先
- 老師強調這是個人見解，讓同學自行斟酌

## 📖 法條原文速查

> **§264 I**　因契約互負債務者，於他方當事人未為對待給付前，得拒絕自己之給付。但自己有先為給付之義務者，不在此限。

> **§432**（要旨）　I 承租人應以善良管理人之注意，保管租賃物。II 承租人違反前項義務，致租賃物毀損、滅失者，負損害賠償責任。→ 建議查閱最新六法原文

> **§456 I**（要旨）　出租人就租賃物所受損害對於承租人之賠償請求權，因**二年**間不行使而消滅。→ 建議查閱最新六法原文

> **§144 I**　時效完成後，債務人得**拒絕給付**。

---

## 📋 實務見解速查

> **112 台上 2091 判決**（講義 532 頁）：同時履行抗辯權係為對抗他方之請求權而設，依其規範目的，本身**無消滅時效**之問題。雙務契約當事人互負債務，既有履行上之牽連關係，縱一方之請求權因罹於時效而消滅，其同時履行抗辯權**仍然存在**，他方請求給付時，仍得行使以拒絕自己之給付。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「同時履行抗辯權有無消滅時效？」 | **無**，抗辯不罹於時效 |
| 「己方請求權已罹於時效，仍得主張同時履行抗辯？」 | 最高法院：**仍得**（112 台上 2091） |
| 「反對見解的理由？」 | 架空消滅時效、強迫對方給付 |

## 兩說對照

| | 最高法院 | 二審（老師贊同） |
|---|---|---|
| 結論 | 可主張同時履行抗辯 | 不可主張 |
| 理由 | 抗辯無時效；§264 未限制 | 債權不得請求給付，無對立可言 |
| 效果 | 甲須付 80 萬元才拿回支票 | 甲可直接拿回支票 |
| 價值 | 雙方履行的牽連關係 | 時效制度的法安定性 |

```
乙 ──80 萬元損害賠償（已罹於時效）──→ 甲
甲 ──返還支票──→ 乙
        │
        └─ 乙：你不付 80 萬，我不還支票（§264）
           最高法院：可以；二審：不可以
```
