# 民法29 筆記：債權讓與之限制與從權利之隨同移轉（§294、§295）

## 債之移轉的範圍：
- **債權讓與** §294～§299；**債務承擔** §300～§306（見本講筆記-11）

## 債權讓與的性質：
- 甲對乙有 A 債權，甲把 A 賣給丙 → 甲丙間有兩個法律行為：
  - **買賣契約**：債權行為
  - **債權讓與**（§294）：使債權移轉的**準物權行為**
- 選擇題陷阱：名稱有「債權」，但**不是債權行為**
- 就像買車：買賣契約與移轉汽車所有權是兩個行為

## 不得讓與的債權（§294 I）：
1. **依債權性質不得讓與**：著重當事人資格、與個人綁定
   - 僱傭：雇主不能把員工「賣」給別家公司
   - 租賃：房東挑房客、房客挑房東，實務認為也著重資格
   - 慰撫金請求權：§195 II，原則不得讓與或繼承（已依契約承諾或已起訴者除外）
   - 剩餘財產分配請求權
2. **依當事人特約不得讓與**
3. **禁止扣押的債權**：與生存權有關
   - 強制執行法 §122（社會福利津貼、社會救助等不得強制執行）、勞基法 §61（職災補償不得讓與）
   - 例：每月 8,000 元社會救助金讓給債主去領，就失去社會救助的意義

## 違反禁止讓與特約，第三人惡意時（§294 II）：
- 條文只說「不得以之對抗**善意**第三人」；反面＝可以對抗**惡意**第三人，但「對抗」是什麼意思？
- **物權效力說**：讓與（準物權行為）**無效**，惡意的丙根本沒有取得 A 債權
- **債權效力說**：讓與**有效**，丙取得 A 債權，只是債務人乙**得拒絕**丙的請求
- 一層時結論相同；差別在**再轉讓**：甲 →（惡意）丙 →（善意）丁
  - 物權效力說：丙沒有債權，丙丁讓與是**無權處分、效力未定**；**債權不能善意取得**（§801、§948、§759-1 II 都用不上）→ 善意的丁也拿不到，乙可以拒絕
  - 債權效力說：丙有債權，丙丁讓與**有效**；丁善意 → 乙**不得拒絕**
- 孫森焱：採**債權效力說**，才能把後手的善意第三人都保護進來
- 核心：§294 II 的「善意第三人」是只限甲的**下一手**，還是包含**所有後手**

## §295 從權利隨同移轉：
- 原則：債權的**擔保**及其他**從屬權利**隨同移轉；最典型是**抵押權**（到抵押權、§759 時再談）
- 例外：與讓與人有**不可分離之關係**者不移轉
- 案例：A 畫市價 200 萬元，乙詐欺甲，使甲以為只值 100 萬元而賤賣給乙，畫已交付
  - 甲把 100 萬元價金債權賣給並讓與丙
  - 丙**不能**依 §92 撤銷、再依不當得利請求返還 A 畫
  - 被詐欺的撤銷權取決於甲自己有沒有被詐欺，與甲**不可分離**，丙只買到 100 萬元價金債權
  - 甲若撤銷 → 丙買到**不存在的債權** → 依 §350、§353 權利瑕疵擔保處理
- §295 II：**未支付的利息**，推定隨同原本移轉（可另行約定）
- §296：讓與人應交付證明文件、告知必要情形（附隨義務）

## 📖 法條原文速查

> **§294**
> I 債權人得將債權讓與於第三人。但左列債權，不在此限：一、依債權之**性質**，不得讓與者。二、依當事人之**特約**，不得讓與者。三、債權**禁止扣押**者。
> II 前項第二款不得讓與之特約，**不得以之對抗善意第三人**。

> **§295**
> I 讓與債權時，該債權之**擔保及其他從屬之權利**，隨同移轉於受讓人。但與讓與人有**不可分離之關係**者，不在此限。
> II 未支付之利息，**推定**其隨同原本移轉於受讓人。

> **§296**　讓與人應將證明債權之文件，交付受讓人，並應告以關於主張該債權所必要之一切情形。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「債權讓與之性質？」 | **準物權行為**，非債權行為 |
| 「慰撫金請求權得否讓與？」 | 原則**不得**；已依契約承諾或已起訴者得（§195 II） |
| 「違反禁止讓與特約，讓與給善意第三人？」 | 不得對抗，讓與**有效** |
| 「債權得否善意取得？」 | **不得** |
| 「惡意丙再讓與善意丁，丁得否向債務人請求？」 | 物權效力說：不得；**債權效力說**：得 |
| 「價金債權讓與，被詐欺之撤銷權是否隨同移轉？」 | **否**，與讓與人不可分離 |
| 「未付利息是否隨同移轉？」 | **推定**隨同移轉 |

## 兩說比較（甲 → 惡意丙 → 善意丁）

| | 物權效力說 | 債權效力說 |
|---|---|---|
| 甲丙讓與 | 無效 | 有效，乙得拒絕丙 |
| 丙丁讓與 | 無權處分，效力未定 | 有效 |
| 丁向乙請求 | 乙得拒絕 | 乙不得拒絕 |
| 善意第三人範圍 | 只到甲的下一手 | 包含所有後手 |
