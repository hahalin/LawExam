# 公司法13 筆記：董事資訊權的依據與公司拒絕的舉證責任（§23、§210）

## 考過很多次，答案可以整段背：
- 2015 司法官、2018 司法官、2023 司律（有限公司，講義 17-18）都考過
- 考法固定：董事向公司要財務資料，公司拒絕有沒有理由
- 講義 6-77 第七行的「結論」整段可以當模板背

## 公司法沒有明文：
- 公司法**沒有**董事資訊權的明文
- 有明文的只有**股東資訊權**（§210）與**監察人資訊權**（講義註 141）
- 股份有限公司與有限公司的董事都會討論到這個問題

## 為什麼董事需要資訊：
- 董事執行業務負**忠實義務**與**善良管理人注意義務** → 必須知悉、取得相關資訊
- 例：董事會討論要不要到冰島投資，董事對冰島一無所知，就無法判斷

## 經濟部見解：擴張 §210（只適用股份有限公司）：
- 經濟部多次函釋以 **§210**（股東及債權人查閱抄錄）作為董事請求的依據，一路擴張到股東名簿等資料
- §210 本來規範股東與債權人，跟董事沒有直接關係，但經濟部這樣解釋
- 經濟部函釋只針對**股份有限公司** → 考**有限公司**時不能寫經濟部見解

## 最高法院見解：附隨於受託義務（兩種公司都能用）：
- **110 台上 539**：缺乏資訊就無法做成決策；在執行業務的**合理目的**範圍內得取得相關資訊
- **111 台上 1079**：董事為善盡注意義務當然有資訊請求權，是**附隨的監督權能**，屬當然法理；資訊請求權**附屬於受託義務**而生
- 學者強調：董事資訊權不應與 §210 直接掛鉤，而是從 **§23 受託義務**而來
- 最高法院也指出查閱抄錄範圍**不以 §210 為限**（等於修正經濟部）

## 董事的義務與公司拒絕的要件：
- 董事取得資訊後本於忠實與注意義務，須**合理使用**、負**保密義務**、不得為不利公司的行為
- 公司要拒絕，須由**公司舉證**：①與執行業務**無涉** ②**無必要** ③**無正當目的**
- 否則不得拒絕。關鍵：**公司舉證**

## 獨立董事（證交法）：
- 學者認為 2018 年證交法新增的規定是**獨立董事資訊權**的規範（字幕唸作「§14-2 第三項」，條號建議查證），證交法再學

## 📖 法條原文速查

> **§23 I**　公司負責人應**忠實**執行業務並盡**善良管理人之注意義務**，如有違反致公司受有損害者，負損害賠償責任。

> **§210 II**（摘錄）　前項章程及簿冊，**股東及公司之債權人**得檢具利害關係證明文件，指定範圍，隨時請求查閱、抄錄或複製……（詳見本講筆記-10）

---

## 📋 實務見解速查

> **最高法院 110 年度台上字第 539 號**：董事若缺乏資訊即無從做成決策，基於執行業務之合理目的需要，得於合理範圍內取得相關資訊。→ 原文建議查證

> **最高法院 111 年度台上字第 1079 號**：董事為善盡善良管理人注意義務，當然享有資訊請求權，屬附隨之監督權能，係附屬於受託義務而生；查閱抄錄範圍不以 §210 為限。→ 字幕唸作「111079」，推定為 111 台上 1079，建議查證

> **講義 6-77（取得資訊後的義務與拒絕事由）**：董事取得之資訊應本於忠實及注意義務合理使用、負保密義務；公司須舉證董事之請求與執行業務無涉、無必要或無正當目的，始得拒絕。→ 出處判決課堂未唸字號

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司法有無明文規定董事資訊權？」 | **沒有**；明文的是股東與監察人 |
| 「董事資訊權的依據（最高法院）？」 | 附隨於**受託義務**（§23），不以 §210 為限 |
| 「有限公司董事資訊權可否援引經濟部函釋？」 | **不可**，經濟部函釋只針對股份有限公司 |
| 「公司拒絕提供資訊，誰負舉證責任？」 | **公司** |
| 「公司得拒絕的事由？」 | 與執行業務**無涉**、**無必要**、**無正當目的** |

## 一、兩種依據對照

| | 經濟部 | 最高法院（110 台上 539、111 台上 1079） |
|---|---|---|
| 依據 | §210 擴張 | §23 受託義務，附隨的監督權能 |
| 適用 | 股份有限公司 | 股份有限公司、有限公司 |
| 範圍 | 以 §210 為核心 | 不以 §210 為限 |

## 二、答題模板

```
1. 公司法未明文規定董事資訊權（明文者為股東、監察人）
2. 董事負忠實、善管注意義務（§23 I），須取得資訊始能決策
   → 資訊請求權附隨於受託義務而生（111 台上 1079）
3. 董事應合理使用、保密、不得為不利公司行為
4. 公司舉證：無涉執行業務／無必要／無正當目的 → 才能拒絕
5. 本題公司未能舉證 → 拒絕無理由
```
