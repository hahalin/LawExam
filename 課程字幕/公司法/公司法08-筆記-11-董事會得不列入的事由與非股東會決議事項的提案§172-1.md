# 公司法08 筆記：董事會得不列入的事由與非股東會決議事項的提案（§172-1）

## 原則：董事會「應」列為議案（§172-1 IV）：
- 審查者是**董事會**；原則上股東提什麼都要列入，符合下列各款才可以排除
- 考法：講義 5-30（如提出「B 公司吸收合併 A 公司」的提案）——實質判斷這種議案能不能提

## 第 2～4 款：形式審查，對應前面各項：
- ②提案股東於停止過戶時持股**未達 1%** ← 來自 I
- ③在公告**受理期間外**提出 ← 來自 II（≥ 10 日）
- ④超過 **300 字**，或**提案超過一項** ← 來自 III、I 但書
- 講義 5-26：各款均屬**形式審查**，不應賦予董事會裁量權 → 違反就不列入
- 太簡單，不會考申論，考也是選擇題

## 第 1 款「非股東會所得決議」才是重頭戲：
- 先分：這件事是不是**公司法明文**的股東會決議事項
- **明文事項**（例：講義 5-33 三號提案解任甲乙，§199）→ 董事會**應**列入；通過的決議**合法、有效，且拘束董事會**。這題的考點不在這裡，而在一案兩案（本講筆記-09）
- **非明文事項** → 再分是否為公益或社會責任

## §172-1 V：公益與社會責任的提案（2018 增訂）：
- 為敦促公司**增進公共利益或善盡社會責任**的建議 → 董事會**仍得列入**
- 例：疫情期間提案公司出資購買疫苗捐給受災鄉親、成立慈善基金會
- 講義 5-26（沒考過）：只**放寬內容**，**程序要件**仍要遵守——還是只能提一項、要在受理期間內、300 字

## 非明文、非公益事項：能不能列入（爭點）：
- 例：講義 5-33 一號提案（關於增資股數 100 萬股，字幕不清，建議查證題目原文）
- **否定說**（講義 5-24 ~ 5-25）：即使做成決議，也**不產生決議的效力**，沒有拘束董事會與公司的法律效果；若可列入會有弊病——
  - A **濫行提案**
  - B 董事會**恣意排除**（喜歡的列、不喜歡的不列，例：列幼兒園案、不列公園案）
  - C 成為董事會的**民意基礎**（例：先讓股東會通過赴海外設廠，虧錢時說是股東自己同意的）
- **肯定說（多數）**：①尊重股東意見、良性互動（股東積極主義）②公司社會責任，讓更多議案可以列入 ③實務上**臨時動議幾乎沒有限制**，配套與資訊權更完整的提案權更不應限制
- 可採少數說，但一定要把爭點寫出來
- 縱採肯定說，通過的決議也**只是建議性質，沒有拘束力**

## 合法性 → 有效性 → 拘束性：
- 股東會議案分三步檢驗（第四步「執行」通常不討論），順序與民法相同
- 合法性：通常會過（除非提案進口象牙、買手槍）
- 有效性：通常會過（民法上多用條件、期限限制效力）
- **卡在拘束性**：這件事本來就**不是股東會的權限**，決議對董事會沒有拘束力
- 例：股東會決議「下一任美國總統應該是某人」→ 合法、有效、沒有拘束力，只是意志的展現
- 例：提案「公司應蓋兩座公園給鄉親使用」→ 就算勉強算公益，結果也一樣：合法有效、不拘束董事會

## 📖 法條原文速查

> **§172-1**
> IV 除有下列情事之一者外，股東所提議案，**董事會應列為議案**：
> 一、該議案**非股東會所得決議**。
> 二、提案股東於公司依第一百六十五條第二項或第三項停止股票過戶時，持股**未達百分之一**。
> 三、該議案於公告**受理期間外**提出。
> 四、該議案**超過三百字**或有第一項但書**提案超過一項**之情事。
> V 第一項股東提案係為敦促公司**增進公共利益或善盡社會責任**之建議，董事會**仍得列入**議案。

> **§202**　公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由**董事會**決議行之。（非股東會權限的依據，見本講筆記-12）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股東所提議案，董事會『得』列入？」 | ✕，原則**應**列入 |
| 「§172-1 IV ②～④ 董事會有裁量權？」 | ✕，**形式審查** |
| 「公益提案得同時提三項？」 | ✕，只放寬內容，**程序要件仍適用** |
| 「公益或社會責任提案，董事會應列入？」 | ✕，「**仍得**」列入 |
| 「非股東會決議事項列入並通過，拘束董事會？」 | ✕，**合法有效但無拘束力**，僅建議性質 |
| 「明文股東會決議事項之提案通過？」 | 合法、有效、**拘束董事會** |

## 一、§172-1 IV 第 1 款的判斷流程

```
股東提案
├── 公司法明文的股東會決議事項 → 應列入 → 合法、有效、拘束董事會
└── 非明文
     ├── 公益／社會責任（§172-1 V）→ 仍得列入（程序要件照舊）
     └── 非公益 → 能否列入？
           ├── 否定說：不生決議效力；濫行提案、恣意排除、民意基礎
           └── 肯定說（多數）：股東積極主義、社會責任、臨時動議都不限制
                 ↓ 不論哪一說
           通過也只是建議，不拘束董事會
```

## 二、三步檢驗

| 步驟 | 明文事項 | 非明文事項 |
|---|---|---|
| 合法性 | 過 | 通常過 |
| 有效性 | 過 | 通常過 |
| 拘束性 | **拘束董事會** | **不拘束**（非股東會權限） |
