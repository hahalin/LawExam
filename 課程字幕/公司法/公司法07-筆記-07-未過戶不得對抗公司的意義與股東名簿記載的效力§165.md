# 公司法07 筆記：未過戶不得對抗公司的意義與股東名簿記載的效力（§165）

## 過戶只是對抗要件：
- 依 §165 I，**過戶不是生效要件**，只是對抗要件 → 受讓人即使沒通知公司變更股東名簿，股份轉讓**仍然生效**，只是不能對抗公司
- 「過戶」的白話＝**變更股東名簿記載**

## 「不得對抗公司」的意義（最高法院）：
- 未過戶前，受讓人**不得向公司主張**股息、紅利等股東權利
- 但**不包括請求變更名簿的權利** → 公司**不得拒絕**受讓人辦理過戶
- 講義註 87（老師稱 **96 台上 515**，建議查證字號）：公司以**不正當的消極行為**阻止變更名簿 → **類推適用民法 §101**，視為條件成就

## 股東名簿登載的效果：
- 公司可**據以**讓名簿上的人行使股東權（投票、領股利）
- 但名簿不是百分之百對：
  - **106 台上 283**（字幕辨識不清，建議查證字號）：登記為股東者，若登記係**偽造或不實**，不得僅以該登記認定其對公司的股東權存在 → 可**舉反證推翻**
  - **112 台上 2334**（老師提醒是較新的見解，建議查證字號）：下列三種情形，公司仍以股東名簿認定股東 → **違反誠信原則**
    1. 公司**知悉**股份有變動，卻**不為變更**
    2. 經請求變更，公司**無正當理由拒絕**變更
    3. 公司**知悉不符合**變更要件，仍**逕為變更**
  - 簡單講：明知該改不改、請求了不改、不合法卻幫他改
- 兩則見解的處理不同：96 台上 515 是類推民法 §101 視為條件成就；112 台上 2334 是以違反誠信原則處理

## 王志誠老師見解（看過即可）：
- 未變更股東名簿時，名簿上的讓與人從公司領到的股利不構成不當得利；受讓人只能依雙方**內部關係**向讓與人請求（建議對照講義 4-38 原文）

## 📖 法條原文速查

> **§165 I**
> 股份之轉讓，非將受讓人之姓名或名稱及住所或居所，記載於公司股東名簿，**不得以其轉讓對抗公司**。

> **民法 §101 I**（條件成就之擬制）
> 因條件成就而受不利益之當事人，如以**不正當行為阻其條件之成就**者，**視為條件已成就**。

> **民法 §148 II**　行使權利，履行義務，應依**誠實及信用方法**。

---

## 📋 實務見解速查

> **最高法院**：未過戶不得向公司主張股息紅利等股東權，但不包括請求變更名簿之權利，公司不得拒絕過戶。
> **96 台上 515**（建議查證）：公司以不正當消極行為阻止變更，類推民法 §101 視為條件成就。
> **106 台上 283**（建議查證）：名簿登記偽造或不實者，不得僅以登記認定股東權存在，得舉反證推翻。
> **112 台上 2334**（建議查證）：公司知悉變動而不變更、無正當理由拒絕變更、知悉不符仍逕為變更，仍以名簿認定股東者，違反誠信原則。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「受讓人未過戶，股份轉讓無效？」 | ✕，**仍生效**，只是不得對抗公司 |
| 「受讓人未過戶，公司得拒絕其請求過戶？」 | ✕，不得對抗公司**不包括請求變更名簿的權利** |
| 「公司以不正當方法阻止過戶，效果？」 | **類推民法 §101**，視為條件成就 |
| 「股東名簿記載之人必為股東？」 | ✕，登記偽造不實可**舉反證推翻** |
| 「公司明知股份已變動仍依名簿認定股東？」 | **違反誠信原則**（112 台上 2334） |

## 一、受讓人乙未過戶時

```
乙 ──向公司主張──┬─ 出席投票、領股利 → ✕ 不得對抗公司
                 └─ 請求變更股東名簿 → ○ 公司不得拒絕
                         │
                         └─ 公司以不正當消極行為阻止
                              → 類推民法 §101 視為條件成就
```

## 二、名簿不是絕對的

| 情形 | 處理 |
|---|---|
| 名簿上的登記偽造、不實 | 可舉反證推翻（106 台上 283） |
| 公司知悉變動而不變更 | 違反誠信原則（112 台上 2334） |
| 經請求無正當理由拒絕 | 違反誠信原則 |
| 知悉不符仍逕為變更 | 違反誠信原則 |
