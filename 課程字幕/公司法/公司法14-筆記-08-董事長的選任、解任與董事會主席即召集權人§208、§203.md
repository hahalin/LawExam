# 公司法14 筆記：董事長的選任、解任與董事會主席即召集權人（§208、§203）

## 地位：
- 董事長是股份有限公司**法定必備常設**機關，一定要有

## 選任的時點（§203，召集權見公司法13-筆記-11）：
- 正常改選：新任期開始後，由所得選票代表選舉權最多的董事於 **15 日內**召開第一次董事會選董事長
- 提前改選並決議任滿時解任：董事長、副董事長、常務董事的改選**得於任期屆滿前**為之（§203 II）
- 例：任期到 3/25，2/1 就選出下屆董事 → 這一個多月下屆董事沒事做，法條只讓你先把**下屆董事長**選出來；沒考過

## 選任的方法（§208 I、II，選擇申論都常考）：
- 未設常務董事：**董事會特別決議**（2/3 以上出席、出席過半數）**互選**一人為董事長
- 副董事長：「**得**」依章程以同一方式互選 → **章定任意**
- 設有常務董事：由**常務董事**以特別決議互選（§208 II 後段，見本講筆記-07）
- 第一次董事會出席未達選舉董事長的最低人數（2/3）→ 原召集人 **15 日內繼續召集**，並**得**用 **§206 的決議方法**選舉（§203 III）→ 出席門檻從 2/3 降到過半數；選擇題可考、沒考過

## 解任與辭職：
- 解任：法無明文 → 經濟部、學者多數：**怎麼選就怎麼解**
  - 未設常董 → 董事會特別決議（§208 I）
  - 設有常董 → 常務董事特別決議（§208 II）
  - 選擇申論都可以考
- 董事長可以**單獨辭去董事長**、保留董事身分
- 辭職沒有代理問題——代理以董事長**還在位**為前提（見本講筆記-10）

## 主席（§208 III 前段）：
- 對內為**股東會、董事會、常務董事會**的主席
- 股東會由董事會召集 → 主席依 §208 III → **董事長**（§182-1 I，見公司法08-筆記-12）

## 董事會主席＝召集權人（電腦圖 6-25）：
- 誰是召集權人，誰就是主席；講義 6-103（召集權人）與 6-143（主席）互相註記
- 第一次董事會：所得選票代表選舉權最多的董事為主席（**經濟部見解**，非法條明文）；他沒出席、也沒委託代理 → 出席董事**互選一人**（經濟部）
- 董事長召集 → 董事長為主席（**§208 III 明文**）
- 過半數董事依 §203-1 III 自行召集 → **類推 §182-1**，由過半數董事**互推一人**為主席
- 要分清楚哪些是法條明文、哪些是經濟部見解

## 📖 法條原文速查

> **§208**
> I　董事會未設常務董事者，應由三分之二以上董事之出席，及出席董事過半數之同意，**互選一人為董事長**，並**得依章程規定**，以同一方式互選一人為副董事長。
> II（後段）　董事長或副董事長由**常務董事**依前項選舉方式互選之。
> III（前段）　董事長**對內為股東會、董事會及常務董事會主席**，對外代表公司。

> **§203**
> II　董事係於上屆董事任期屆滿前改選，並經決議自任期屆滿時解任者，其董事長、副董事長、常務董事之改選**得於任期屆滿前**為之，不受前項之限制。
> III　第一次董事會之召集，出席之董事未達選舉常務董事或董事長之最低出席人數時，原召集人應於**十五日內繼續召集**，並得適用**第二百零六條**之決議方法選舉之。

> **§182-1 I**　股東會由董事會召集者，其主席依第二百零八條第三項規定辦理；由董事會以外之其他召集權人召集者，主席由該召集權人擔任之，召集權人有二人以上時，應**互推一人**擔任之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「未設常董時，董事長如何選任？」 | **董事會特別決議**互選 |
| 「副董事長是否必設？」 | **否**，得依章程設置 |
| 「第一次董事會出席不足 2/3，如何選董事長？」 | 15 日內繼續召集，得以 **§206 普通決議**方法選舉 |
| 「董事長如何解任？」 | 法無明文，**怎麼選就怎麼解**（董事會或常董特別決議） |
| 「董事長可否只辭董事長、保留董事？」 | **可以** |
| 「過半數董事自行召集的董事會，主席是誰？」 | 類推 §182-1，**互推一人** |

## 一、董事會主席對照（電腦圖 6-25）

| 召集權人 | 主席 | 依據 |
|---|---|---|
| 董事長（§203-1 I） | 董事長 | §208 III 明文 |
| 第一次董事會：選舉權最多的董事（§203 I） | 該董事；未出席也未委託 → 互選一人 | 經濟部 |
| 過半數董事自行召集（§203-1 III） | 互推一人 | 類推 §182-1 |

## 二、選任與解任

```
有無常務董事？
├── 無 → 董事會特別決議（2/3 出席 × 過半數）選、解董事長、副董事長
└── 有 → 常務董事特別決議選、解董事長、副董事長
         （常務董事本身由董事會特別決議選、解）
```
