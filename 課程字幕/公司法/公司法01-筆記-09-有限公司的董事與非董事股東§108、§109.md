# 公司法01 筆記：有限公司的董事與非董事股東（§108、§109）

## 有限公司股東分成兩群：
- **董事**：法定必備機關（§108 I「**應**至少置董事一人」），執行業務**並**代表公司
- **不執行業務股東**＝**非董事之股東**：行使監察權（§109）
- 有限公司**沒有董事會、沒有股東會**；法律不要求開會，但硬要開會也不違法，只要符合法定要件

## 董事人數與選任要背：
- 最少 **1 人**、最多 **3 人**
- 經**股東表決權三分之二以上**同意，就**有行為能力之股東**中選任 → 經所合一

## 代表公司的人：
- 董事 1 人：就是該董事
- 董事 2～3 人：得以章程置**董事長一人**對外代表公司，董事長經**董事過半數**同意互選
- 未置董事長：各董事**單獨**代表（經濟部見解）
- 章程只能寫「得設董事長」，**不能寫董事長姓名**，否則換人就要改章程，經濟部不准登記

## 業務執行準用無限公司：
- §108 IV 準用 §46：業務執行由**董事過半數**同意；通常事務董事單獨執行，其他董事異議即停止
- §108 IV 準用條文很多，老師說一試出題機率**超高**，幾乎都考過一輪

## 非董事股東的監察權：
- §109 I 準用 §48：**隨時**質詢、查閱
- §109 II：得**代表公司**委託律師、會計師審核 → 費用由公司負擔
- §109 III：規避、妨礙或拒絕者處罰鍰

## 📖 法條原文速查

> **§108**（有限公司董事）
> I　公司**應至少置董事一人**執行業務**並**代表公司，**最多置董事三人**，應經股東表決權**三分之二以上**之同意，就**有行為能力之股東**中選任之。董事有數人時，**得以章程置董事長一人**，對外代表公司；董事長應經董事**過半數**之同意互選之。
> IV　第三十條、**第四十六條**、第四十九條至第五十三條、第五十四條第三項、第五十七條至第五十九條、第二百零八條第三項、第二百零八條之一及第二百十一條至第二百十二條之規定，於董事準用之。→ 建議查閱最新六法原文

> **§109**（不執行業務股東之監察權）
> I　**不執行業務之股東**，均得行使**監察權**；其監察權之行使，準用**第四十八條**之規定。
> II　不執行業務之股東辦理前項事務，得**代表公司委託律師、會計師**審核之。
> III　規避、妨礙或拒絕不執行業務股東行使監察權者，代表公司之董事處罰鍰。→ 罰鍰數額建議查閱最新六法原文

## 📋 實務見解速查

> **經濟部 88.10.21 函**：公司法 §109 所稱「不執行業務股東」，指**非董事之股東**。→ 字號建議查證

> **經濟部見解**：有限公司董事有數人而未置董事長者，各董事均得**單獨**代表公司；章程不得記載董事長姓名。→ 建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有限公司董事人數？」 | **至少 1 人、最多 3 人** |
| 「有限公司董事如何選任？」 | 股東表決權 **2/3 以上**同意，就有行為能力之**股東**中選任 |
| 「有限公司有無董事會？」 | **無**（也沒有股東會） |
| 「有限公司董事長如何產生？」 | **得以章程**置一人，董事**過半數**同意互選 |
| 「有限公司數董事未置董事長，誰代表？」 | 各董事**單獨**代表 |
| 「§109 的不執行業務股東指誰？」 | **非董事之股東**（經濟部函） |
| 「非董事股東委託會計師查帳，費用由誰負擔？」 | 「**代表公司**」委託 → 由**公司**負擔 |

## 一、有限公司機關（電腦圖 1-5）

```
有限公司股東
├── 董事（法定必備，1～3 人；股東表決權 2/3 以上選任）
│     ├ 業務執行：§108 IV 準用 §46 → 董事過半數；通常事務董事單獨，異議停止
│     └ 代表公司：
│         ├ 單一董事 → 該董事
│         └ 2～3 位董事 → 有董事長：董事長
│                         無董事長：各董事單獨代表（經濟部）
└── 非董事之股東（§109）
      ├ 準用 §48：隨時質詢、查閱
      ├ 得代表公司委託律師、會計師
      └ 規避、妨礙、拒絕 → 罰鍰
```

## 二、§108 的「數人」是幾人？

- 董事上限 3 人，所以「董事有數人時」＝ **2～3 人**。

## 三、選擇題小技巧：門檻用語

| 公司法常見門檻 | 通常寫法 |
|---|---|
| 2/3 | 「三分之二**以上**」（含本數） |
| 1/2 | 「**過半數**」（不含本數） |

- 以上、以下含本數；超過、未達不含本數。選擇題會考。

## 四、無限公司 vs 有限公司的變化

| | 無限公司 | 有限公司 |
|---|---|---|
| 執行業務的人 | 執行業務**股東** | **董事** |
| 業務執行 | 股東過半數（§46） | 董事過半數（§108 IV 準用 §46） |
| 監督 | 不執行業務股東（§48） | 非董事股東（§109 準用 §48） |
| 委託律師、會計師 | 無規定 | 得代表公司委託（§109 II） |

- 老師：§109 條文仍寫「不執行業務之股東」，有限公司其實沒有「執行業務股東」的概念，應理解為**非董事之股東**——這是檢驗公司法功力的點。
- 有限公司機關在最後一堂課會再講一次。
