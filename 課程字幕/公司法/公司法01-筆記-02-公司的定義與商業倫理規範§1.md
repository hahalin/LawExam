# 公司法01 筆記：公司的定義與商業倫理規範（§1）

## 公司是營利的社團法人：
- §1 I：以**營利**為目的、依公司法組織登記成立的**社團法人**
- **營利**＝賺到的錢會**分配給股東**，不是「公司一定賺錢」；非營利＝賺的錢不分給成員，拿去做公益
- 是**社團法人**（以人為基礎），不是財團法人

## 應遵守法令與商業倫理規範：
- §1 II 前段用「**應**」：公司經營業務**應**遵守**法令**及**商業倫理規範**
- 選擇題考過「應」與「得」的替換
- 商業倫理規範的內容會隨時代變遷，學者間有爭執；白話說就是「正派經營」

## 得採行公益行為、善盡社會責任：
- §1 II 後段用「**得**」：得採行增進公共利益之行為，以善盡其**社會責任**
- 例：疫情期間企業出資採購疫苗捐贈

## 📖 法條原文速查

> **§1**（公司之定義及社會責任）
> I　本法所稱公司，謂以**營利為目的**，依照本法組織、登記、成立之**社團法人**。
> II　公司經營業務，**應**遵守法令及**商業倫理規範**，**得**採行增進公共利益之行為，以善盡其**社會責任**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司是社團法人或財團法人？」 | **社團法人**，以營利為目的 |
| 「營利的意義？」 | 盈餘**分配給股東**；不是指一定獲利 |
| 「公司經營業務『得』遵守商業倫理規範？」 | **錯**，是「**應**」遵守法令及商業倫理規範 |
| 「公司『應』採行增進公共利益之行為？」 | **錯**，是「**得**」採行，以善盡社會責任 |

---

## 一、§1 的結構

```
§1 I　公司的定義
   ├── 目的：營利（盈餘分配給股東）
   └── 性質：社團法人（以人為本體）

§1 II　公司經營的界線
   ├── 「應」：遵守 法令 ＋ 商業倫理規範   ← 義務
   └── 「得」：增進公共利益 → 社會責任      ← 鼓勵
```

## 二、營利與非營利

| | 營利 | 非營利 |
|---|---|---|
| 賺到的錢 | 分配給股東 | 不分配，用於公益或其他目的 |
| 是否保證獲利 | 否（公司仍可能倒閉） | — |

- §1 是典型選擇題法條，老師估計出申論題的機率在 2% 以下。
