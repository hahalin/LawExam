# 公司法05 筆記：解散後應行清算與清算中視為尚未解散（§24、§25、§26）

## 為什麼公司解散不等於法人格消滅：
- 自然人：死亡 → 人格立即消滅 → 財產債務由**繼承人**處理
- 公司：沒有「死亡」，對應的概念是**解散**；但公司**沒有繼承人**，財產與債務只能自己處理
- 自己處理的程序就是**清算**；清算需要一個權利義務主體 → 解散時**法人格不消滅**，持續到**清算完結**
- 講義：解散只是法人格消滅的**原因**，不是消滅本身

## 原則：解散之公司應行清算（§24）：
- 例外三種不清算：**合併、分割、破產**
- 破產 → 走破產法，不在公司法處理
- 合併、分割 → §319 準用 §73～§75，消滅公司的權利義務由存續或新設公司**概括承受**（§75），債權人找承受公司即可，所以不需要清算，法人格**直接消滅**

## 清算中視為尚未解散（§25）：
- 「視為尚未解散」＝在清算範圍內**仍有法人格**
- 法人格可理解為**權利能力**：仍是權利義務主體
- 清算中仍有**名稱專用權**，他人不能隨便使用其名稱（電腦圖 2-16）

## 清算中得暫時經營業務（§26）：
- 目的限於**了結現務**與**便利清算**（選擇題考點）
- 只能**暫時**經營：不是讓公司趁清算開分公司、拓展海外

## 📖 法條原文速查

> **§24**（解散後之清算）
> 解散之公司除因**合併、分割或破產**而解散外，**應行清算**。

> **§25**（清算中之公司）
> 解散之公司，於**清算範圍內**，**視為尚未解散**。

> **§26**（清算中之營業）
> 前條解散之公司，在清算時期中，得為**了結現務**及**便利清算**之目的，**暫時經營業務**。

> **§319**　第七十三條至第七十五條之規定，於股份有限公司之**合併或分割**準用之。→ 建議查閱最新六法原文

> **§75**　因合併而消滅之公司，其權利義務，應由合併後**存續或另立之公司承受**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司解散後法人格是否立即消滅？」 | **不消滅**；清算範圍內視為尚未解散（§25），**清算完結**才消滅 |
| 「解散後不須清算的情形？」 | **合併、分割、破產**（§24） |
| 「合併、分割為何不須清算？」 | §319 準用 §75，權利義務由存續或新設公司**概括承受** |
| 「清算中公司得否經營業務？」 | 得**暫時**經營，目的限**了結現務、便利清算**（§26） |
| 「清算中公司有無名稱專用權？」 | **有**（仍有法人格） |

## 一、自然人與公司的對照

| | 自然人 | 公司 |
|---|---|---|
| 結束的事由 | 死亡 | 解散 |
| 人格何時消滅 | 死亡時立即 | 清算完結時 |
| 財產債務誰處理 | 繼承人 | 公司自己（清算） |
| 處理期間有無人格 | — | 有（§25） |

## 二、電腦圖 2-16：解散後的三條路

```
解散事由發生
├── 合併、分割 ── §319 準用 §75 概括承受 ── 不清算，法人格直接消滅
├── 破產 ──────── 破產法 ──────────────── 不在公司法處理
└── 其他事由 ──── §24 應行清算
                    └── 清算中有法人格（§25）、得暫時經營（§26）
                         └── 清算完結 → 向法院聲報（§331 IV）→ 法人格消滅

另：撤銷／廢止設立登記 ── §26-1 準用 §24～§26 ── 清算（見本講筆記-01）
```

## 三、合併的例子（電腦圖 2-15）

1. 甲電信公司對債權人張三負 500 萬元債務。
2. 甲電信被乙電信**吸收合併** → 甲電信因合併而解散（§315 I ⑤）。
3. 依 §24，合併屬不清算的例外；依 §319 準用 §75，甲的權利義務由乙**概括承受**。
4. 張三直接向**乙電信**請求 500 萬元即可 → 不需要清算，甲電信的法人格在**合併基準日**直接消滅。
