# 公司法18 筆記：股東清算或破產時按市價收回抵償債務與解釋上的例外（§167）

## §167 I 但書：用股份抵償債務：
- 要件：股東**清算**或受**破產宣告**（喪失清償能力的狀態）
- 效果：公司得**按市價**收回該股東的股份，抵償其於清算或破產宣告**前**結欠公司的債務
- 學界與實務普遍認為可以**直接主張抵銷** → 公司相對於其他債權人**優先**受償
- 清算指**法人**股東；破產則法人、自然人都可能（講義 12-25）

## 立法理由與批評（電腦圖 12-5）：
- 立法理由：股份**很可能被低價出售**，影響其價值
- 學者批評：違反**債權人平等原則**

## 企業併購法的例外：
- 企業併購時，依企併法行使股份收買請求權而由公司收買（企併法 §12；字幕說「第 11 條或第 12 條」→ 建議查證）

## 解釋上的例外（選擇題會考）：
- 限制的目的是**避免資本灌水**；不會違反資本維持原則、不是公司花錢去買的，就不禁止（講義 12-25）
- ① **無償取得**：別人贈與（字幕另提到「拋棄」→ 建議查證）
- ② **概括繼受**：合併、分割而取得（例：甲公司合併乙公司，乙原持有甲的股份，只能一併承受）
- ③ **減資**銷除股份時先取得自己的股份

## 📖 法條原文速查

> **§167 I 但書**　但於股東**清算**或受**破產之宣告**時，得**按市價**收回其股份，**抵償**其於清算或破產宣告**前**結欠公司之債務。

> **§186**、**§316-2**、**§317**　股份收買請求權（反對重大行為／簡易合併／合併分割）→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股東受破產宣告，公司得否收回其股份？」 | **得**，按**市價**收回，抵償破產宣告**前**的債務 |
| 「§167 I 但書的清算指誰？」 | **法人**股東；破產則法人、自然人皆可能 |
| 「§167 I 但書的立法理由？」 | 股份可能被**低價出售** |
| 「§167 I 但書受到的批評？」 | 違反**債權人平等原則** |
| 「公司受贈取得自己股份是否違反 §167 I？」 | **不違反**（無償取得，解釋上例外） |
| 「公司因合併承受被合併公司持有的本公司股份？」 | **不違反**（概括繼受） |

## 一、數字例（電腦圖 12-5）

```
乙公司（上市公司）
  │ 甲公司是乙的股東；乙對甲有債權 100 萬元
  ▼
甲公司 ←── 丙對甲有債權 400 萬元
  │ 借款後解散、進入清算
  ▼
甲公司剩下的財產：市值 100 萬元的乙公司股份
```

| | 沒有 §167 I 但書 | 有 §167 I 但書 |
|---|---|---|
| 分配方式 | 債權比例 1：4 平均分配 | 乙按市價收回 100 萬元股份直接抵銷 |
| 乙受償 | 20 萬元 | **100 萬元** |
| 丙受償 | 80 萬元 | 0 元 |
