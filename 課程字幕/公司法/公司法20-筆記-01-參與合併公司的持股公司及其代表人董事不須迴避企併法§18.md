# 公司法20 筆記：參與合併公司的持股公司及其代表人董事不須迴避（企併法§18）

## 企併法 §18 VI 拆成前提與效果兩塊讀：
- 前提一：公司**持有**其他參加合併公司的**股份**
- 前提二：該公司（§27 I 法人董事）或其**指派代表人**（§27 II）**當選**為其他參加合併公司的**董事**
- 效果：就其他參與合併公司的**合併事項**為決議時，**得行使表決權**＝股東會、董事會**都不必迴避**

## 沒有這條會怎樣：
- 持股公司在合併案有權利義務變動，是**自身利害關係**人 → 原本依 §178（股東會）、§206 IV 準用 §178（董事會）要迴避
- 企併法 §18 VI 是特別規定，把這兩個迴避**排除**

## 立法理由（講義 15-18）：
- 合併通常是**提升體質、強化競爭力**，不至於有害公司利益
- 國內外合併收購實務上**很常見**母公司吸收子公司

## 同時持有兩家參與合併公司股份的股東：
- 臺灣高等法院 96 重上 145：**舉重以明輕**，同時持有兩合併公司股份者，**也不必迴避**
- 這點國考考過；最高法院見解穩定

## 學者評價（講義 15-19，看看即可）：
- 股東會不迴避可以接受；**董事會也不迴避**就有點奇怪，董事是受託人、有領報酬 → 老師也支持這個批評
- 收購、股份轉換等其他企併類型也有類似不迴避規定（講義 15-18 ~ 15-19 三、四，進階）

## 📖 法條原文速查

> **企併法 §18 VI**　公司持有其他參加合併公司之股份，或該公司或其指派代表人當選為其他參加合併公司之董事者，就其他參與合併公司之合併事項為決議時，**得行使表決權**。
> → 釋字 770 審查時為第 5 項，之後項次改為第 6 項，**內容一字未改**。建議查閱最新六法原文

> **§178**　股東對於會議之事項，有自身利害關係致有害於公司利益之虞時，不得加入表決，並不得代理他股東行使其表決權。

> **§206 IV**　第一百七十八條……之規定，於第一項之決議準用之。（董事會決議的迴避）→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「母公司持有子公司股份並指派代表人當選子公司董事，子公司股東會、董事會決議與母公司合併時，母公司及代表人董事應否迴避？」 | **不必迴避**，**得行使表決權**（企併法 §18 VI） |
| 「沒有 §18 VI 時依公司法應否迴避？」 | **應**迴避（§178；董事會 §206 IV 準用 §178） |
| 「同時持有兩家合併公司股份的法人股東應否迴避？」 | **不必**；舉重以明輕（高院 96 重上 145） |
| 「§18 VI 的立法理由？」 | 合併通常提升體質、強化競爭力，不至於有害公司利益 |
| 「學者對 §18 VI 的主要批評？」 | **董事會**層級也不迴避較有疑問 |

## 一、例子（電腦圖 15-2，公司名改稱）

```
甲公司（外國母公司）── 持有 45% ──→ 乙公司（臺灣子公司）
        └─ 指派 3 名代表人 ──當選──→ 乙公司董事

甲吸收合併乙：
  乙董事會決議（§317）：甲的 3 名代表人董事 → 得行使表決權
  乙股東會決議（§316；企併法 §18）：甲的 45% → 得行使表決權

原本：§178、§206 IV 準用 §178 → 應迴避
企併法 §18 VI → 迴避規定打叉
```

## 二、同時是兩家公司股東（電腦圖 15-3）

```
丙公司 ── 持有乙 5.29% ──
       └─ 持有甲 8.5%（假設）
甲、乙合併 → 丙在兩邊投票都會影響另一邊的利益
高院 96 重上 145：§18 VI 連「持股＋當選董事」都不迴避，
                  單純同時持股更不必迴避（舉重以明輕）
```

## 三、與 §206 利害關係迴避的對照

| | 一般董事會決議 | 合併事項決議（企併法 §18 VI） |
|---|---|---|
| 持股公司的股份 | 有利害關係 → 不得加入表決（§178） | 得行使表決權 |
| 持股公司代表人董事 | 有利害關係 → 迴避（§206 IV） | 得行使表決權 |
| 補強 | — | 說明義務（企併法 §5 III，見公司法19-筆記-12） |
