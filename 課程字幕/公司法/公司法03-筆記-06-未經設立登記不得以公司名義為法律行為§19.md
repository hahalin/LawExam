# 公司法03 筆記：未經設立登記不得以公司名義為法律行為（§19）

## 違反 §19 的情形：
- 公司**未經設立登記**（＝尚未成立），卻以**公司名義**經營業務或為其他法律行為
- 例：貓熊公司尚未登記，代表人陳阿貓以「貓熊公司」名義為甲方，和乙公司簽租賃契約
- 合法的做法：簽約名義寫「**貓熊公司籌備處**」→ 選擇題**超級愛考**
- 行為人**不限於發起人**，任何人冒用不存在的公司名稱都可能違反

## 三種責任同時存在：
- **刑事**：行為人處 1 年以下有期徒刑、拘役或科或併科新臺幣 15 萬元以下罰金
- **民事**：行為人**自負民事責任**；行為人 2 人以上者**連帶**
- **行政**：由主管機關**禁止使用**公司名稱

## 違反 §19 不是無效：
- 法條寫「自負民事責任」→ 契約有效，責任停在**行為人**（陳阿貓）身上，公司不負責
- 民法學者覺得奇怪：乙公司想要的履約對象是貓熊公司，結果變成陳阿貓
- **109 台上 2979**：公司設立登記後**承認**該法律行為，使其歸屬於公司，並無不許之理 → 契約可轉回成立後的貓熊公司
- 學者：§19 應限於**自始至終沒有設立公司之意**卻冒用公司名義者

> 來源：公司法03 課程字幕 01:42:15 ~ 01:51:21（講義第 2-43 ~ 2-44 頁）

## 📖 法條原文速查

> **§19**（未登記而以公司名義營業之禁止）
> I　**未經設立登記**，不得以**公司名義**經營業務或為其他法律行為。
> II　違反前項規定者，行為人處**一年以下有期徒刑、拘役或科或併科新臺幣十五萬元以下罰金**，並**自負民事責任**；行為人有二人以上者，**連帶負民事責任**，並由主管機關**禁止其使用公司名稱**。

---

## 📋 實務見解速查

> **最高法院 109 年度台上字第 2979 號判決**：違反 §19 所為之法律行為，公司於設立登記完成後**承認**該法律行為，將其效果歸屬於公司，並以交易主體自居，自無不許之理。→ 原文建議查閱司法院裁判書系統

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「設立中公司對外應以何名義為法律行為？」 | **「某某公司籌備處」** |
| 「違反 §19 所為的契約，效力？」 | **不是無效**，由**行為人自負**民事責任 |
| 「違反 §19 的行為人限於發起人？」 | **不限** |
| 「違反 §19 有哪些責任？」 | **刑事＋民事＋行政**（禁止使用名稱）三者並存 |
| 「行為人二人以上？」 | **連帶**負民事責任 |
| 「公司成立後可否承認違反 §19 的契約？」 | **可以**（109 台上 2979） |

## 一、用情境走一次

```
貓熊公司（未登記）── 代表人陳阿貓 ──簽約──→ 乙公司（出租人）
        │
        ├── 用「貓熊公司」名義 → 違反 §19
        │      ├─ 刑：1 年以下、拘役或科或併科 15 萬以下罰金
        │      ├─ 民：陳阿貓自負（契約有效）
        │      └─ 行政：禁止使用公司名稱
        │      └─ 貓熊公司成立後承認 → 效果轉歸公司（109 台上 2979）
        │
        └── 用「貓熊公司籌備處」名義 → 合法，依同一體說由成立後公司繼受
```

## 二、§19 與同一體說的接點

- 同一體說讓設立中公司的權利義務當然由成立後公司繼受（見 公司法03-筆記-04）
- 但前提是用**籌備處**名義；用公司名義就落入 §19，效果先停在行為人身上

> 字幕校正：字幕「紅海公司」「鴻海公司」為老師舉例的相對人，本筆記改稱乙公司；字幕「10萬罰金」「5萬元以下罰金」為口誤，法條為 15 萬元。
