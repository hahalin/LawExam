# 公司法18 筆記：閉鎖性公司的三大要件與排除式立法（§356-1）

## 三大要件，缺一不可（§356-1 I）：
- ① 股東人數**不超過 50 人**
- ② 章程定有**股份轉讓限制**
- ③ **非公開發行**股票公司
- 50 人上限：中央主管機關**得增加**（§356-1 II），但**目前沒有增加**
- 三個要件要**同時**具備；之後任何一個不符合 → 強制變更（本講筆記-11）

## 排除式立法（電腦圖 13-1）：
- 相對於「完整寫出一整套規範」的立法例；當年由邵慶平老師領軍、趕在 2018 年大修之前推出，採較快的寫法
- 兩種寫法：
  - **直接不適用特定規範**（例：§356-12 III 發行新股不適用 §267）
  - **另訂特別規範**（例：§356-3 V、VII 章程得排除累積投票制）
- **沒有規定的，回歸適用一般股份有限公司的規定**
- 閉鎖性股份有限公司**仍是股份有限公司**；所以各校、補習班都是股份有限公司教完才教閉鎖性

## 老師的例子（律師事務所的董監）：
- 不適用特定規範：大家九點上班，董監不適用，只要上滿時數
- 另訂特別規範：大家打卡，董監刷臉即可
- 沒寫的（辦公室零食能不能吃）→ 回歸一般規定，董監也能吃

## 立法目的與考試方向：
- 股東人數少、彼此有**信賴關係**，維持公司的閉鎖性
- 2018 年修法後許多閉鎖性特色已沿用到一般公司，差異縮小（講義 13-3 註 1，方嘉麟老師整理三點）
- 出題：**大機率出選擇題**；申論只出過一次（講義 13-17）；差異多採**經濟部見解**，記經濟部見解即可
- 立法論批評（講義註 2，邵慶平、劉連煜老師）不考

## 📖 法條原文速查

> **§356-1**
> I　本法所稱閉鎖性股份有限公司，指**股東人數不超過五十人**，並於**章程定有股份轉讓限制**之**非公開發行股票**公司。
> II　前項股東人數，中央主管機關得視社會經濟情況及實際需要**增加**之；其計算方式及認定範圍，由中央主管機關定之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「閉鎖性公司的股東人數上限？」 | **50 人**；主管機關得增加，目前未增加 |
| 「閉鎖性公司得否為公開發行公司？」 | **不得**，必須非公發 |
| 「閉鎖性公司章程得否不限制股份轉讓？」 | **不得**，轉讓限制是要件 |
| 「閉鎖性公司章節未規定的事項？」 | 回歸**股份有限公司**一般規定 |
| 「閉鎖性公司是不是股份有限公司？」 | **是** |

## 一、排除式立法圖（電腦圖 13-1）

```
股份有限公司的一般規定（§128 以下）
        │ 全部適用，除了：
        ▼
閉鎖性股份有限公司（§356-1 ~ §356-14）
├── 不適用特定規範：§356-3 VI（募集設立）、§356-12 III（§267）…
├── 另訂特別規範：§356-3 V、VII（累積投票）、§356-7（特別股）、§356-8 III（無實體股東會）…
└── 沒有規定 → 回歸一般規定
```
