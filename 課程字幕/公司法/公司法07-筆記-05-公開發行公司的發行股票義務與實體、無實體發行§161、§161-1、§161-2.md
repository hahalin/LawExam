# 公司法07 筆記：公開發行公司的發行股票義務與實體、無實體發行（§161、§161-1、§161-2）

## 電腦圖 4-12 的閱讀順序（老師說記憶時很重要）：
- ① 有沒有**發行義務**（法定／任意）→ ② **發行方式**（不發行／實體 §162／無實體 §161-2）→ ③ 發行方式決定**轉讓方式**（見本講筆記-06）

## 股票發行的意義：
- 公司**製作並交付**，或以**帳簿劃撥方式**交付股票的行為
- 製作後實體交付＝實體發行；以帳簿劃撥交付＝無實體發行

## 誰有強制發行股票義務（§161-1）：
- **公開發行公司**「應」於**設立登記或發行新股變更登記後 3 個月內**發行股票 → 法定發行義務
- 負責人違反者處罰鍰（§161-1 II）
- **非公開發行公司**：任意，每次發行新股由**董事會**決定要不要發
  - 章程沒規定時，可能出現「這批有發、那批沒發」；股東不喜歡可以修章規定一律發行
- 易混淆（講義 4-35 對照 4-40）：「有沒有**發行股票的義務**」≠「股票有沒有**公開發行**」（§156-2，見本講筆記-10）

## 3 個月 vs 30 日：
- 公司法 §161-1 是 3 個月；證交法 §34 I 是 **30 日** → 公司法的 3 個月有點問題（小爭點）

## 為什麼要在登記後才發股票（§161）：
- §161 I：非經**設立登記或發行新股變更登記後，不得發行股票**；II：違反者股票**無效**
- 理由：設立登記與變更登記有會計師查核簽證（§7）與主管機關形式審查（§12），相對比較不會有問題（見公司法04-筆記-11、公司法03-筆記-11）

## 發行方式：
- **實體**：§162（印製股票，見本講筆記-02）
- **無實體**：§161-2
  - 發行股票之公司，其發行之股份**得免印製股票**
  - 所有股份有限公司都可以（**公發、非公發皆可**），選擇題會考
  - 未印製股票者，應洽**證券集中保管事業機構**（臺灣集中保管結算所）**登錄**其股份
  - 注意：無實體**也是有發行**股票，只是看不見

## 📖 法條原文速查

> **§161**（發行股票之時期）
> I 公司**非經設立登記或發行新股變更登記後，不得發行股票**。但公開發行股票之公司，證券管理機關另有規定者，不在此限。
> II 違反前項規定發行股票者，其股票**無效**。但持有人得向發行股票人請求損害賠償。

> **§161-1**（公開發行公司之發行股票義務）
> I **公開發行股票之公司**，**應**於設立登記或發行新股變更登記後**三個月內**發行股票。
> II 公司負責人違反前項規定，不發行股票者，除由證券主管機關令其限期發行外，處罰鍰……→ 罰鍰金額建議查閱最新六法原文

> **§161-2**（無實體發行）
> I 發行股票之公司，其發行之股份**得免印製股票**。
> II 依前項規定未印製股票之公司，應洽證券集中保管事業機構**登錄**其發行之股份，並依該機構之規定辦理。
> → III、IV 見本講筆記-06

> **證交法 §34 I**　發行人應於依公司法得發行股票或公司債券之日起**三十日內**，對認股人或應募人憑出資證明交付股票或公司債券……→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「所有股份有限公司均有發行股票之義務？」 | ✕，只有**公開發行公司**（§161-1） |
| 「公開發行公司應於設立登記後幾個月內發行股票？」 | **3 個月**（證交法為 30 日） |
| 「非公開發行公司是否發行股票，由股東會決定？」 | ✕，任意，由**董事會**決定（章程可規定） |
| 「未經設立登記即發行之股票，效力為何？」 | **無效**（§161 II） |
| 「免印製股票限於公開發行公司？」 | ✕，**所有**股份有限公司皆可 |
| 「無實體發行即未發行股票？」 | ✕，無實體**也是發行** |
| 「發行股票義務與公開發行是同一件事？」 | ✕，完全不同（§161-1 vs §156-2） |

## 一、電腦圖 4-12 左半部

```
有沒有發行義務
├── 公開發行公司 → 法定義務（§161-1：登記後 3 個月內）
└── 非公開發行公司 → 任意（每次由董事會決定，章程可統一規定）
        ↓
發行方式
├── 不發行
└── 發行
    ├── 實體：§162（代表董事簽章＋銀行簽證）
    └── 無實體：§161-2（免印製，集保登錄）
```

## 二、兩個容易混淆的問題

| | 發行股票義務 | 公開發行 |
|---|---|---|
| 問的是 | 要不要把股票做出來交付 | 公司要不要受證交法規範、對外募集 |
| 條文 | §161-1 | §156-2 |
| 講義 | 4-35 | 4-40 |
