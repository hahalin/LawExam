# 公司法11 筆記：讓與主要部分營業或財產的判斷標準（§185）

## 爭點：
- §185 I ② 的「**主要部分**」怎麼判斷 → 實務兩說＋劉連煜老師一說，考試**三說都寫**

## 主要財產目錄說（最早期，已不採）：
- 列在公司**主要財產目錄**上的就是主要財產（講義 5-125 倒數第七行）
- 劉連煜老師批評：
  - 主要財產目錄即使有編製，也只是**內部文件**，交易相對人無從判斷
  - 公司法已**刪除**主要財產目錄，沒有明確標準

## 所營事業不能成就說（目前法院多數）：
- 讓與的部分會使公司**原定營業不能成就**（講義 5-126、註 363）
- 劉連煜老師批評：**標準太嚴格，適用困難**
  - 被告常抗辯「公司還剩一兩個員工、幾張桌子，還能經營」→ 除非整間公司賣光，否則都能抗辯

## 質與量雙重判斷法（劉連煜老師，少數實務支持，註 365）：
- **質**：是否導致營業**無法繼續或大幅萎縮**
- **量**：讓與部分的**價值與數量**是否具有相當重要性
- 雖然模糊，劉老師認為比「不能成就」合理

## 經濟部補充：
- 是否為主要財產，**不以是否列名章程為準**，回歸法院判斷標準（講義 5-126 最後兩行）

## 歷屆考題：
- 2017 臺大法研所：品牌與代工兩部門**營業額大致相當**，出售其中一部門 → 討論是否為主要部分
- 2014 律師、司法官：出售**僅有之晶圓廠一座** → 出售主要財產（說成全部財產老師認為太誇張）

## 📖 法條原文速查

> **§185 I ②**　讓與**全部或主要部分**之營業或財產。

## 📋 實務見解速查

> **主要財產目錄說**：字幕唸「97 台上 1707、87 台上 1998」→ 字號建議查證

> **最高法院 81 台上 2696**、**經濟部 69.2.23 函**（字幕「305705」，推定為經商字第 05705 號，建議查證）：係指因其全部或主要部分營業或財產之轉讓，致**影響其原定營業之不能成就**者。

> **註 365**：有實務採質與量雙重判斷。→ 字號建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「目前法院判斷主要部分多採何說？」 | **所營事業不能成就說**（原定營業不能成就） |
| 「主要財產以章程列名為準？」 | ✕（經濟部） |
| 「主要財產目錄說的缺點？」 | 內部文件相對人難以判斷；公司法已**刪除**主要財產目錄 |
| 「質與量雙重判斷的內容？」 | 質：營業無法繼續或**大幅萎縮**；量：價值、數量具**相當重要性** |
| 「出售公司僅有的一座晶圓廠？」 | 讓與**主要部分**財產，適用 §185 |

## 一、三說比較

| 學說 | 標準 | 批評／地位 |
|---|---|---|
| 主要財產目錄說 | 列入主要財產目錄 | 內部文件、已刪除 → **不採** |
| 所營事業不能成就說 | 原定營業不能成就 | 太嚴格、適用困難 → **實務多數** |
| 質與量雙重判斷法 | 質：無法繼續或大幅萎縮；量：價值數量相當重要 | 劉連煜，少數實務 |

## 二、答題架構

```
§185 I ②「主要部分」
├── 1. 主要財產目錄說（早期）→ 批評
├── 2. 所營事業不能成就說（實務多數）→ 批評：太嚴格
├── 3. 質與量雙重判斷法（劉連煜）
└── 4. 經濟部：不以章程列名為準
→ 涵攝：營業額占比、是否僅有的生產設備、出售後營業是否大幅萎縮
```
