# 公司法02 筆記：經營判斷法則的舉證責任與五個推定

## 先講出題機率：
- 國考目前**從未出過**；法研所（政大、北大）考過
- 老師強調：經營判斷法則（Business Judgment Rule，BJR）本質上是**民事訴訟法的舉證責任**問題，不是公司法問題

## 推定董事的決策沒有問題：
- 美國德拉瓦州法：推定董事的經營決策是**充分知情、善意誠實、為公司最佳利益**而作成 → 給董事的保護
- 公司或股東代表公司起訴主張董事違反受任人義務時，先由**原告**舉證推翻推定

## 原告至少推翻五個推定之一：
- 五個推定：**商業決定、無利害關係（及獨立性）、適當注意、善意、無濫用裁量權**
- 口訣「**商利適善濫**」；老師的句子：商場上厲害的人往往都是善意的爛好人
- 考 BJR 背不出這五個，分數就很難拿
- 原告**一個都推翻不了 → 直接敗訴**

## 推翻後舉證責任轉換，不是直接勝訴：
- 推翻成功 → 舉證責任轉由**被告董事**證明交易**整體公平**（entire fairness）
- 整體公平＝**fair dealing**（交易過程沒有利益衝突，或衝突已妥善處理）＋**fair price**（價格合理）
- 董事證明公平 → 原告敗訴；證明不出來 → 原告勝訴

## 我國實務：
- 商業事件審理細則 §37：法院審酌負責人是否忠實執行業務、盡善管注意義務時的具體判斷，實質上接近 BJR（講義註釋 44，屬新的實務見解）
- 我國法院判決常援引此抗辯，但不少用錯，律師實務上仍有操作空間
- 若國考出題：說明 BJR 內容＋我國實務見解（商業事件審理細則有部分引入）

> **§23 I**（公司負責人之義務）
> 公司負責人應忠實執行業務並盡善良管理人之注意義務，如有違反致公司受有損害者，負損害賠償責任。→ BJR 處理的是這條訴訟中的舉證順序

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「經營判斷法則的性質？」 | 對董事經營決策的**推定**，屬**舉證責任**分配 |
| 「BJR 下誰先負舉證責任？」 | **原告**（公司或股東） |
| 「原告須推翻幾個推定？」 | **至少一個** |
| 「推翻推定後董事即須賠償？」 | **否**，轉由董事舉證**整體公平** |
| 「整體公平的內容？」 | **fair dealing ＋ fair price** |

## 一、舉證流程（電腦圖 2-4）

```
公司或股東（代表公司）起訴：董事違反受任人義務
   ↓
推定：董事決策充分知情、善意、為公司最佳利益
   ↓ 原告舉證推翻五個推定之一
   ├── 一個都推翻不了 ──────────────► 原告敗訴
   └── 推翻成功 → 舉證責任轉換
         ↓ 被告董事舉證整體公平（fair dealing＋fair price）
         ├── 證明公平 ──► 原告敗訴
         └── 證明不出 ──► 原告勝訴
```

## 二、五個推定

| 口訣 | 推定 | 原告推翻的例子 |
|---|---|---|
| 商 | 商業決定（business decision） | 根本不是經營決策 |
| 利 | 無利害關係、獨立 | 董事有重大利害關係 |
| 適 | 適當注意（due care） | 資訊不足下決策 |
| 善 | 善意（good faith） | 惡意 |
| 濫 | 無濫用裁量權 | 濫用權限 |

## 三、法研所考法（政大法研所，講義第 26 頁）

- 題目直接寫：董事主張其經營決策受**經營判斷法則**保護，不得事後任意推翻 → 直接考 BJR 的意義與舉證流程。

> 字幕校正：口訣字幕作「商利四散爛」「商利四善爛」「尚力四善爛」，依五個推定的內容推定為「商利適善濫」（「四」為「適」的諧音），建議查證；字幕「interfairness」應為 entire fairness。
