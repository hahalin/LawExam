# 公司法17 筆記：資本三原則的起源與授權資本制下章定股份總數的提高、降低（§156、§129、§266）

## 資本的意義：
- 股東為達成公司目的事業所為財產出資的總額，是一個**不變的計算上金額**，大致就是**實收資本額**
- 變動要經過嚴格程序
- **公司法**已經**沒有最低資本額**；銀行、證券商等特別法仍有（選擇題）

## 資本三原則的出發點：
- 目的是**保護公司債權人**：錢要留在公司，是一套「很節儉」的制度
- 起源德、英都有人主張；老師個人認為來自德國（戰後企業大量向國家貸款，國家要限縮公司的資金運用）
- 美國法幾乎沒有這套原則

## 三個原則各管什麼時點（先寫在講義旁）：
- **資本確定原則**：**設立時**
- **資本維持原則**：**運作中**
- **資本不變原則**：**實收資本額的變動**

## 股份有限公司的立法變遷（選擇題）：
- **法定資本制 → 折衷授權資本制 → 授權資本制**
- 法定資本制：章定資本額設立時全部認足或募足，**章定＝實收**
  - 優點：設立時錢全部到位，債權人保障大
  - 缺點：資本額大時公司**難以成立**、**資金閒置**；每次增資、減資都要**修改章程**（§277 股東會特別決議）
- 折衷制：設立時發行不得低於一定比例，只是過渡（看過即可）
- **授權資本制**：設立時只要在章程確定股份總數、**分次發行**；未發行部分由**董事會**依需要決定發行（2005 年修 §156）

## 授權資本制的條文串接：
- §156 I：資本應分為**股份**
- §129 ③：章程記載**股份總數**（＝章定股份總數、授權股份總數）
- §156 IV：章定股份總數**得分次發行**
- §266 I、II：分次發行新股，由**董事會特別決議**
- 不想授權董事會 → 設立時一次發滿即可

## 增資要不要股東會：
- 在**章定股份總數內**發行新股 → **不必修改章程**，董事會特別決議即可
- **超過**章定股份總數 → 必須先**修改章程**提高股份總數

## 章定股份總數的提高與降低：
- 舊法要求股份總數全數發行後才能增資（舊 §278），2018 年已刪除 → 現在**隨時**可依 §277 股東會特別決議**提高**，沒有上限
- 也可以**降低**，但**不得低於已發行股份總數**
  - 降低＝修改章程**刪除未發行股份**（講義 12-9 ~ 12-10）
  - 只要股東會特別決議修章，**不必**踐行債權人保護等其他程序：只是調整授權額度，不影響債權人

## 📖 法條原文速查

> **§156 I**　股份有限公司之資本，應分為**股份**，擇一採行票面金額股或無票面金額股。
> **§156 IV**　公司章程所定股份總數，得**分次發行**；同次發行之股份，其發行條件相同者，價格應歸一律。……
> → 建議查閱最新六法原文

> **§129 ③**　採行票面金額股者，**股份總數**及每股金額；採行無票面金額股者，**股份總數**。

> **§266**
> I　公司依第一百五十六條第四項分次發行新股，依本節之規定。
> II　公司發行新股時，應由**董事會**以董事三分之二以上之出席，及出席董事過半數同意之決議行之。

> **§277**　I 公司非經股東會決議，不得變更章程。II 前項股東會之決議，應有代表已發行股份總數三分之二以上之股東出席，以出席股東表決權過半數之同意行之。（III、IV 略）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司法有無最低資本額？」 | **沒有**；特別法（銀行、證券商）另有 |
| 「資本三原則的主要目的？」 | **保護債權人** |
| 「我國股份有限公司現採？」 | **授權資本制**（法定 → 折衷 → 授權） |
| 「章定股份總數內發行新股，須否修改章程？」 | **不須**，董事會特別決議（§266 II） |
| 「超過章定股份總數發行新股？」 | 須先**修改章程**（股東會特別決議） |
| 「得否隨時提高章定股份總數？」 | **可以**，2018 年後不必先全數發行 |
| 「降低章定股份總數的限制？」 | **不得低於已發行股份總數** |

## 一、數字例

```
章定股份總數 1,000 萬股（§129 ③）
   ├── 設立時發行 300 萬股（設立時決定，沒有授權問題）
   └── 未發行 700 萬股 → 授權董事會分次發行（§156 IV＋§266 I、II）

提高章定股份總數：1,000 → 1,500 萬股 ✔（隨時、無上限）
降低章定股份總數：1,000 → 800 萬股 ✔（刪除未發行股份）
                  1,000 → 200 萬股 ✘（低於已發行 300 萬股）
```

## 二、法定資本制與授權資本制

| | 法定資本制 | 授權資本制 |
|---|---|---|
| 設立時 | 章定資本全部認足或募足 | 只要確定股份總數，可分次發行 |
| 章定與實收 | 相等 | 可以不相等 |
| 增資 | 修改章程 | 額度內董事會特別決議 |
| 債權人保障 | 大 | 較小 |
| 現行適用 | **有限公司**（本講筆記-06） | **股份有限公司** |
