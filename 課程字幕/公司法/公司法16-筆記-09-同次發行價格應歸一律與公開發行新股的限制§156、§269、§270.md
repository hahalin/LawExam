# 公司法16 筆記：同次發行價格應歸一律與公開發行新股的限制（§156、§269、§270）

## 同次發行、條件相同，價格應歸一律（§156 IV；選擇題）：
- 章程所定股份總數**得分次發行**
- **同次**發行（這一次決議發行的）且**發行條件相同**者，**價格應歸一律**
  - 發行條件相同：例如**都是普通股**或**都是特別股**
  - 同次有普通股也有特別股：可以不同定價
- 效果：**員工、股東、特定人**的認購價格必須一致（講義 10-6）
  - 避免變成**變相報酬**（例如員工比較便宜）
- 公開發行公司：價格決定方法得由證券主管機關另定（§156 IV 但書；講義寫證交法 §28-1 IV，建議查證），原則上也是一律

## 降價要從頭問起：
- 例：原定每股 58 元，員工、股東、特定人都不買
- 大幅降價到 20 元 → 價格要一律，所以要**從員工重新問起**
- 不能降價後直接賣給特定人

## 發行新股的一般限制（講義 10-10，都是複習）：
- **§161**：非經**設立登記**或**發行新股變更登記**後，不得發行股票；違反者股票**無效**
  - 理由：登記時經濟部有基本審查，會計師也有驗資（§7）
- **§161-1**：公開發行公司應於設立登記或發行新股變更登記後**三個月內**發行股票（見公司法07-筆記-05）
- **§140**：**不得折價發行**，發行價格不得低於票面金額（講義 4-29，見公司法07-筆記-03）

## §270：根本不得公開發行新股（比較狠）：
- 判斷核心：公司**體質不佳**
- ① **最近連續二年有虧損**
  - 但書：依事業性質須有較長準備期間，或有健全營業計畫、確能改善營利能力者，不在此限
  - 例：連年虧損的甲手機公司 → 不能公開發行新股，只能改用私募等方式
- ② **資產不足抵償債務**（資不抵債）
- 老師：資不抵債值得限制；連虧兩年但虧不多，限制是否必要不好說，所以有但書

## §269：不得公開發行具有優先權利之特別股：
- 「優先權利」依學者及法院見解，指**股利的優先**（現金或股票股利都算）
- 判斷核心：發不發得出這筆優先股利
- ① 最近三年平均稅後淨利，**不足支付**已發行及擬發行特別股的股息
- ② 已發行特別股約定的股息，**未能按期支付**

## 與公司債的對照：
- §269、§270 對照 §249、§250（本講筆記-04）：都是看公司付不付得出錢
- 老師一試前會把這四條一起翻一遍

## 📖 法條原文速查

> **§156 IV**　公司章程所定股份總數，得**分次發行**；**同次發行**之股份，其**發行條件相同**者，**價格應歸一律**。但公開發行股票之公司，其股票發行價格之決定方法，得由證券主管機關另定之。→ 建議查閱最新六法原文

> **§161**
> I　公司非經**設立登記**或**發行新股變更登記**後，不得發行股票。但公開發行股票之公司，證券管理機關另有規定者，不在此限。
> II　違反前項規定發行股票者，其股票**無效**。但持有人得向發行股票人請求損害賠償。

> **§269**　公司有左列情形之一者，**不得公開發行具有優先權利之特別股**：
> 一、最近三年或開業不及三年之開業年度課稅後之平均淨利，**不足支付已發行及擬發行之特別股股息**者。
> 二、對於已發行之特別股約定股息，**未能按期支付**者。

> **§270**　公司有左列情形之一者，**不得公開發行新股**：
> 一、最近**連續二年有虧損**者。但依其事業性質，須有較長準備期間或具有健全之營業計畫，確能改善營利能力者，不在此限。
> 二、**資產不足抵償債務**者。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「同次發行普通股，員工價格可否低於特定人？」 | **不可以**，價格應歸一律（§156 IV） |
| 「同次發行普通股與特別股，可否不同定價？」 | **可以**，發行條件不同 |
| 「原定價格無人認購，降價後可否直接洽特定人？」 | **不可以**，要從員工重新問起 |
| 「未經發行新股變更登記即發行股票？」 | 股票**無效**（§161 II） |
| 「最近連續二年虧損，可否公開發行新股？」 | 原則**不得**（§270 ①），有但書 |
| 「資產不足抵償債務，可否公開發行新股？」 | **不得**（§270 ②） |
| 「§269 的優先權利指什麼？」 | **股利**優先 |
| 「已發行特別股股息未按期支付，可否公開發行優先特別股？」 | **不得**（§269 ②） |

## 一、價格一律的流程

```
同次發行普通股，每股 58 元
   員工不認 → 股東不認 → 特定人不買
   ↓ 降價為 20 元
   ✗ 直接賣給特定人
   ✓ 從員工 → 股東 → 特定人重新來一次（價格要一律）
```

## 二、四條「付不付得出錢」對照

| | 公司債 | 股份 |
|---|---|---|
| 完全不准 | §250：不得發行公司債（100%、違約繼續中） | §270：不得公開發行新股（連虧兩年、資不抵債） |
| 部分不准 | §249：不得發行無擔保公司債（150%、了結三年內） | §269：不得公開發行優先特別股（股息付不出） |
