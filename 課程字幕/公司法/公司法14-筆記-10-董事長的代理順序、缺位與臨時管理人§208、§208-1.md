# 公司法14 筆記：董事長的代理順序、缺位與臨時管理人（§208、§208-1）

## 代理的前提（講義 6-146）：
- 董事長**尚在位**，只是一時無法行使 → 「**請假**」或「**因故不能行使職權**」（§208 III）
- 因故不能行使職權（最高法院）：去向不明、**羈押**（不論有無禁見）、逃避、重病、與公司訴訟兩造同為一人（字幕作「訴訟兩上同仁」，建議對照講義）、被**假處分**禁止行使職權
- **死亡、辭職、解任** → **缺位**，沒有代理

## 代理順序（§208 III，完全照法條）：
1. **副董事長**：**法定當然代理人**，不能推辭；但副董事長是**章定任意**機關，公司可能沒有
2. 無副董事長，或副董事長也請假、因故不能 → 董事長**指定常務董事一人**；未設常務董事 → **指定董事一人**
3. 董事長未指定 → **常務董事或董事互推一人**：怎麼推都可以，推出時得到過半數同意即可；不知道怎麼推，就開一次普通決議（講義 6-147，沒考過）

## 被假處分時不能走「指定」（選擇題小考點）：
- **指定代理人**本身是董事長的**職權**之一
- 被假處分 → 董事長職權不能行使 → **指定權**也不能行使
- 即使先前已指定好 → 跳過指定，走「副董事長 → 互推」
- 講義另一理由：否則可以先指定好人選，假處分也不怕；老師認為從法條文義就足以說明

## 實例（疫情期間的金控公司，改用代號）：
- 甲金控董事長 A 出國回臺隔離時確診、須治療 → 副董事長 B 當然代理
- B 同時是乙公司董事長，被批評金融機構負責人與一般公司負責人同一人 → B 也**請假**
- 輪到 A 事先**指定**的董事 C 代理，A 康復後回任
- 老師：遇到這種情形，請假就會往後跳一順位

## 缺位的補選：類推適用 §208 III（講義 6-148）：
- 最高法院與經濟部一致：**類推**（不是直接適用）§208 III
- 理由：開董事會要有人召集；董事長死亡或辭職就沒有董事長 → 先依 §208 III 的順序找出一人召集董事會，補選董事長

## 臨時管理人（§208-1，只考選擇題；召集股東會的權限見公司法08-筆記-02）：
- 要件：董事會**不為或不能**行使職權，致公司有**受損害之虞**
- 程序：法院因**利害關係人或檢察官**聲請，選任**一人以上**
- 權限：代行**董事長及董事會**職權——董事會已停擺，需要有人能決議也能對外代表；叫「臨時」，目的是讓公司趕快**恢復正常運作**
- **不得為不利於公司**之行為，例：**撤回抗告**
- 立法目的：仿非訟事件法，防止董事死亡、辭職、解任、羈押、重病、**複數當選名單**等使經營權停擺
- 只是覺得董事做得不好、違反 §23 I → **不能**聲請；須董事會已無法合法合理運作
- 資格：不以股東為限，通常選律師、會計師（律師原則上不得拒絕法院指定的職務）；原則選**自然人**——選法人無從判斷適任，派誰出來也難管控
- 有利害關係的事項仍須**迴避**
- 臨時管理人有數人時如何行使職權：字幕作「合意之和解」，語意不清，建議對照講義 6-157
- 法院應囑託主管機關登記；解任時囑託註銷登記（§208-1 II、III）

## 📖 法條原文速查

> **§208 III（後段）**　董事長**請假或因故不能行使職權**時，由**副董事長**代理之；無副董事長或副董事長亦請假或因故不能行使職權時，由董事長**指定常務董事一人**代理之；其未設常務董事者，**指定董事一人**代理之；董事長未指定代理人者，由常務董事或董事**互推一人**代理之。

> **§208-1**
> I　董事會**不為或不能**行使職權，致公司有**受損害之虞**時，法院因**利害關係人或檢察官**之聲請，得選任一人以上之臨時管理人，代行**董事長及董事會**之職權。但**不得為不利於公司之行為**。
> II　前項臨時管理人，法院應囑託主管機關為之登記。
> III　臨時管理人解任時，法院應囑託主管機關註銷登記。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事長請假，第一順位代理人？」 | **副董事長**（法定當然代理） |
| 「無副董事長、未設常董，董事長指定誰？」 | **董事一人** |
| 「董事長未指定代理人？」 | 常務董事或董事**互推一人** |
| 「董事長死亡，副董事長可否代理？」 | 死亡是**缺位**，無代理；補選時**類推** §208 III |
| 「董事長被假處分，先前指定的代理人可否代理？」 | **不可**，指定權也是職權，跳過指定 |
| 「臨時管理人代行何者職權？」 | **董事長及董事會** |
| 「臨時管理人由誰聲請？」 | **利害關係人或檢察官**；法院選任 |
| 「臨時管理人可否撤回抗告？」 | **不可**，屬不利於公司之行為 |

## 一、代理順序

```
董事長請假／因故不能行使職權（尚在位）
        ↓
① 副董事長（法定當然代理；章定任意，可能沒有）
        ↓ 無，或也請假／不能
② 董事長指定：常務董事一人（未設常董 → 董事一人）
        ↓ 未指定（或董事長被假處分，不能指定）
③ 常務董事或董事互推一人

董事長死亡、辭職、解任 → 缺位 → 類推 §208 III 找人召集董事會補選
董事會整個不能運作 → §208-1 臨時管理人
```

## 二、三種情況對照

| | 代理 | 缺位 | 臨時管理人 |
|---|---|---|---|
| 狀態 | 董事長在位、一時不能 | 董事長已不在 | 董事會不為或不能運作 |
| 依據 | §208 III 直接適用 | **類推** §208 III | §208-1 |
| 誰決定人選 | 法定順序 | 法定順序 | 法院 |
