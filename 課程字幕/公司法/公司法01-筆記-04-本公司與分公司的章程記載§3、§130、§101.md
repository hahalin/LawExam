# 公司法01 筆記：本公司與分公司的章程記載（§3、§130、§101）

## 公司住所固定是本公司所在地：
- §3 I：公司以其**本公司所在地**為住所，不能另選
- 股份有限公司的本公司所在地是章程**絕對必要記載事項**（§129 ④），所以從章程就能知道公司住所

## 本公司與分公司的定義：
- §3 II：**首先設立**、管轄全部組織的總機構＝本公司；受本公司管轄的**分支機構**＝分公司
- 分公司與本公司是同一權利能力（民訴上分公司有當事人能力，對分公司的判決效力及於本公司）
- 生活例：銀行的總行＝本公司，各地分行＝分公司

## 股份有限公司設分公司要先寫進章程：
- 分公司之設立是**相對必要記載事項**（§130 I ①）：非經載明於章程者**不生效力**
- 原本章程沒寫 → 先由股東會決議**變更章程**，再由董事會決議設立分公司

## 有限公司不必寫分公司：
- 有限公司章程應記載事項（§101）沒有「分公司」，也沒有相對記載事項的分類
- 有限公司章程沒寫分公司，照樣可以設立

## 📖 法條原文速查

> **§3**（公司住所、本公司與分公司）
> I　公司以其**本公司所在地**為住所。
> II　本法所稱本公司，為公司依法**首先設立**，以管轄全部組織之總機構；所稱分公司，為受本公司管轄之**分支機構**。

> **§129**（章程絕對必要記載事項）
> 發起人應以**全體之同意**訂立章程，載明下列各款事項，並簽名或蓋章：一、公司名稱。二、所營事業。三、股份總數及每股金額（或無票面金額股之股份總數）。四、**本公司所在地**。五、董事及監察人之人數及任期。六、訂立章程之年、月、日。→ 建議查閱最新六法原文

> **§130 I**（章程相對必要記載事項）
> 下列各款事項，**非經載明於章程者，不生效力**：一、**分公司之設立**。二、解散之事由。三、特別股之種類及其權利義務。四、發起人所得受之特別利益及受益者之姓名。

> **§101 I**（有限公司章程應載明事項）
> 公司名稱、所營事業、股東姓名或名稱、資本總額及各股東出資額、盈餘及虧損分派比例或標準、本公司所在地、董事人數、定有解散事由者其事由、訂立章程之年月日，共九款；**沒有分公司**。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司得以章程另定住所？」 | **不得**，住所＝本公司所在地（§3 I） |
| 「股份有限公司設分公司，只要董事會決議即可？」 | **錯**，分公司須載明於章程（§130 I ①） |
| 「股份有限公司原章程未載分公司，如何設立？」 | 先**股東會決議變更章程**，再**董事會決議**設立 |
| 「有限公司章程未載分公司，設立分公司效力？」 | **有效**，§101 無分公司事項 |
| 「何者為首先設立、管轄全部組織的總機構？」 | **本公司**（§3 II 前段） |

## 一、章程記載事項的兩種

```
股份有限公司章程
├── 絕對必要記載（§129）── 不寫 → 章程無效
│     └ ④ 本公司所在地 → 連到 §3 I 公司住所
└── 相對必要記載（§130）── 不寫 → 該事項不生效力
      └ ① 分公司之設立

有限公司章程（§101）── 只有「應記載」，不分絕對、相對；沒有分公司
```

## 二、2011 年考題（講義第 1-5 頁註釋三）

| 選項 | 判斷 |
|---|---|
| 分公司設立屬公司自治事項，董事會決議即可 | 錯：須載明於章程 |
| 應先由股東會決議修改章程，再由董事會決議設立分公司 | **對** |

## 三、有限公司的陷阱題

- 題目：A **有限公司**於 110 年設立，章程原無分公司規劃，後來設立分公司，效力如何？
- 答：**有效**。要先看清楚是**有限公司**，§101 沒有分公司事項，不必先改章程。
- 老師提醒：把題目中的「有限公司」打星號，這題考的就是把股份有限公司的 §130 錯套到有限公司。
