# 公司法07 筆記：申請公開發行與停止公開發行（§156-2）

## 決議機關不同（§156-2 I）：
- **申請公開發行**：**董事會**決議（普通決議）即可，不必問股東
- **申請停止公開發行**：**股東會特別決議**（2/3 出席、出席表決權過半數同意）
- 出席不足定額時，可用過半數出席、出席表決權 2/3 以上同意（II）；章程可提高（III）
- 本講筆記-01 林國彬老師的推論就是從「申請只要董事會決議」出發

## 為什麼一鬆一嚴：從股東權益保障出發：
- 公開發行後，公司受證交法規範、資訊公開，**股東權益提高** → 由儉入奢易 → 董事會決議即可
- 停止公開發行，**股東權益變少** → 由奢入儉難 → 要股東會特別決議

## 證券主管機關得停止公開發行（§156-2 IV）：
- 公開發行公司 ①**已解散** ②**他遷不明** ③因**不可歸責於公司之事由**
- 致**無法履行證交法**有關公開發行公司的義務 → **證券主管機關（金管會）**得停止其公開發行

## 公營事業（§156-2 V）：
- 公營事業申請公開發行及停止公開發行，應先經該公營事業之主管機關**專案核定**
- 老師：公司法上看到「**公營事業**」四個字，只會考**選擇題**，不會考申論
- 「核定」這是第一次出現，之後還會看到兩次，屆時再整理

## 📖 法條原文速查

> **§156-2**（申請公開發行與停止公開發行）
> I 公司得依**董事會之決議**，向證券主管機關申請辦理公開發行程序；申請**停止公開發行**者，應有代表已發行股份總數**三分之二以上股東出席之股東會**，以出席股東表決權**過半數**之同意行之。
> II 出席股東之股份總數不足前項定額者，得以有代表已發行股份總數過半數股東之出席，出席股東表決權三分之二以上之同意行之。
> III 前二項出席股東股份總數及表決權數，章程有較高之規定者，從其規定。
> IV 公開發行股票之公司已**解散**、**他遷不明**或因**不可歸責於公司之事由**，致無法履行證券交易法規定有關公開發行股票公司之義務時，**證券主管機關得停止其公開發行**。
> V **公營事業**之申請辦理公開發行及停止公開發行，應先經該公營事業之主管機關**專案核定**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「申請公開發行應經股東會特別決議？」 | ✕，**董事會**決議即可 |
| 「申請停止公開發行由董事會決議？」 | ✕，**股東會特別決議** |
| 「公開發行公司他遷不明致無法履行證交法義務，誰得停止其公開發行？」 | **證券主管機關**（金管會） |
| 「公營事業申請停止公開發行，股東會決議即可？」 | ✕，應先經其主管機關**專案核定** |
| 「否決權特別股得否決董事會申請公開發行之決議？」 | ✕，否決權只及股東會事項（但修章可擋，見筆記-01） |

## 一、對照表

| | 申請公開發行 | 停止公開發行 |
|---|---|---|
| 決議機關 | 董事會 | 股東會 |
| 決議方法 | 普通決議 | 特別決議（公發可用 II 的方式） |
| 股東權益 | 提高 | 減少 |
| 記法 | 由儉入奢易 | 由奢入儉難 |
| 公營事業 | 先經主管機關專案核定 | 先經主管機關專案核定 |

## 二、停止公開發行的兩條路

```
公司自己要停 ─── 股東會特別決議（§156-2 I 後段）
主管機關停   ─── 解散／他遷不明／不可歸責事由
                 ＋ 致無法履行證交法義務（§156-2 IV）
```
