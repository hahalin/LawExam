# 公司法04 筆記：許可業務應載明章程與所營事業的記載方式（§18）

## §18 五項的排列：
- I、IV 講**名稱**；II、III 講**所營事業**；V 講名稱與業務都要**事前申請核准**
- 老師：項次排列沒有道理，但要記住哪一項講什麼

## 所營事業依營業項目代碼表登記（§18 III）：
- 所營事業應依中央主管機關所定**營業項目代碼表**登記
- 已設立登記、所營事業為**文字敘述**者，於**變更所營事業時**改依代碼表辦理
- 代碼最後一碼為 **1**，原則上是**許可業務**；為 **0**，原則上非許可業務（例外很少）

## 許可業務應載明章程，其餘不受限制（§18 II）：
- **許可業務**：一定要**載明於章程**，且須先取得目的事業主管機關許可才能經營
- **其餘**＝**非許可業務**：不必載明章程，也**可以經營、完全有效**
- 違反許可規定：由目的事業主管機關處罰，甚至有刑事責任（例：未經交通部許可經營汽車貨運業的外送平台遭裁罰；未經許可販售運動彩券）

## 章程記載方式兩種：
- **限定列舉**：只列出具體營業項目
- **限定列舉＋概括記載**：另加代碼 **ZZ99999**「除許可業務外，得經營法令非禁止或限制之業務」

## 從事章程限定以外的非許可業務：
- 只有**限定列舉**的公司才會有這個爭點
- **對外效力：有效**（非許可業務本來就不必寫在章程）
- **對內效力**：董事會執行業務違反章程，董事依 **§193** 對公司負損害賠償責任
- 國考只考過一次；記不住可以放掉，但上半（許可業務要載明章程）一定要記

## 📖 法條原文速查

> **§18 II**（所營事業）
> 公司所營事業除**許可業務應載明於章程**外，**其餘不受限制**。

> **§18 III**（營業項目代碼表）
> 公司所營事業應依中央主管機關所定**營業項目代碼表**登記。已設立登記之公司，其所營事業為文字敘述者，應於**變更所營事業時**，依代碼表規定辦理。

> **§18 V**（事前核准）
> 公司**名稱及業務**，於公司登記前應**先申請核准**，並**保留一定期間**；其審核準則，由中央主管機關定之。

> **§193**（董事會執行業務之責任）
> I　董事會執行業務，應依照法令章程及股東會之決議。
> II　董事會之決議，違反前項規定，致公司受損害時，參與決議之董事，對於公司負賠償之責；但經表示異議之董事，有紀錄或書面聲明可證者，免其責任。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「許可業務是否須載明於章程？」 | **須**（§18 II） |
| 「非許可業務未載明於章程，得否經營？」 | **得**，對外**有效** |
| 「所營事業應如何登記？」 | 依**營業項目代碼表**（§18 III） |
| 「章程載明某業務外『得經營其他合法事業』，何者不得經營？」 | **許可業務**（例：**存款業務**）未載明者不得經營（註 120） |
| 「限定列舉的公司經營章程以外的非許可業務，董事責任？」 | 對外有效；對內依 **§193** 對公司負賠償責任 |
| 「公司名稱及業務何時申請核准？」 | 登記**前**先申請核准並保留一定期間（§18 V） |

## 一、體系（電腦圖 2-12）

```
§18 II 所營事業
├── 許可業務 → 必須載明章程（並取得許可）
└── 其餘（非許可業務）→ 縱使未經載明 → 對外效力：有效

所營事業的記載方式（§18 III：代碼表）
├── 限定列舉            （例：甲公司章程只列 4 項代碼）
└── 限定列舉＋概括記載    （例：乙公司章程第 85 項 ZZ99999）

從事章程具體限定以外的非許可業務（只在「限定列舉」才有爭點）
├── 對外：有效
└── 對內：違反章程 → §193 董事對公司負賠償責任
```

## 三、例題（講義註 120）

- 天下公司章程記載：電腦遊戲軟體及開發業務外，「**得經營其他合法事業**」→ 已有概括記載
- 問：何者**不得經營**？
- 解：概括記載之下仍不得經營的，只有**未載明的許可業務** → **存款業務**
