# 公司法02 筆記：經理人的形式認定與實質認定（100台上1624）

## 職稱是最不恰當的標準：
- 舊公司法曾規定總經理、副總經理、協理等名稱；修法後**廢除法定名稱**，由公司自行決定
- 所以判斷是否為經理人，**最不適宜的標準就是職稱**（考過的選擇題）
- 老師的例子：名片上寫總經理，結果公司「最低的職員就是總經理」

## 形式認定說（公司法主流）：
- 二擇一：**經主管機關（經濟部）登記**，或**經 §29 程序選任**（股份有限公司＝董事會普通決議）
- 目前律師實務上主要的判斷方式

## 實質認定說：
- 看是否有**對內管理事務、對外代表**的權限
- **證交法**的主流（主管機關函令採此說）；不是公司法主流

## 最高法院：董事會實質決議通過聘任：
- **100 年台上字第 1624 號判決**：公司內控說明書、公告申報書、公開說明書、年報都**載明某人為總經理**，且這些文件**經董事會決議通過** → 視為董事會**實質決議認可**聘任 → 是經理人
- 公式：**文件記載＋董事會通過＝經理人**
- 學者評論：這其實也接近形式認定，只是用董事會通過文件來滿足 §29 的決議要求

## 📖 法條原文速查

> **§29 I ③**
> 股份有限公司應由**董事會**以董事過半數之出席，及出席董事過半數同意之決議行之。（經理人之委任、解任及報酬）

## 📋 實務見解速查

> **最高法院 100 年度台上字第 1624 號判決**：公司所出具之內控說明書、公告申報書、公開說明書及年報，均載明某人為總經理，而上開文件經**董事會決議通過**，可認董事會已**實質決議認可**聘任其為總經理。→ 原文建議查閱司法院裁判書系統

> 老師另提 **102 年度台上字第 306 號判決**採相同方向 → 字號建議查證

> 證交法主管機關函令採**實質認定說**（講義註釋 14）→ 函號建議查證

## 一、三種認定方法（電腦圖 2-1）

```
誰是經理人？
│
├── ✗ 職稱 ─ 最不恰當
│
├── 形式認定說（公司法主流）── 二擇一
│     ├ 經濟部登記
│     └ 依 §29 選任（股份有限公司：董事會普決）
│
├── 最高法院：董事會實質決議通過聘任
│     └ 經董事會通過的文件明確載明其人 → 是經理人（100 台上 1624）
│
└── 實質認定說（證交法主流）
      └ 對內管理事務＋對外代表
```

## 二、考題：同一題考三種認定法（2014 公證人、調查局）

### 事實
1. 非公開發行 A 公司章程定有經理人數人，其中總經理統籌管理、可議價締約
2. 總經理辭職，A 緊急請乙擔任 CEO，**言明職權與總經理同等**；之後對內對外都以 CEO 名義執行
3. A 董事會編造並經會計師查核的營業報告書，因章程沒有 CEO，**記載乙為總經理**
4. 乙稱是基於個人情誼協助；**董事會沒有決議**選任，也**沒有登記**
5. 股東認為乙經營不善致虧損，想請求賠償

### 分析：乙是不是經理人？

| 認定方法 | 依據的事實 | 結論 |
|---|---|---|
| 實質認定說 | 言明職權與總經理同等、對內對外執行 | 是 |
| 最高法院（100 台上 1624） | 董事會編造的營業報告書載明為總經理 | 是 |
| 形式認定說 | 董事會未決議、未登記 | 不是 |

- 是不是經理人，決定乙是否為 §8 II 的公司負責人，進而是否負 §23 的忠實義務、注意義務（見 公司法02-筆記-03、09）。

> 字幕校正：字幕「依登記法第四條向主管機關登記」，講義引用的登記依據條號建議查證；「劉律老師」所指學者建議查證。
