# 公司法11 筆記：肥貓條款與董事報酬不得事後追認（§156-4、§29、§196）

## 肥貓條款（講義 6-16，沒考過，要考是選擇題）：
- 立法論評論：政府紓困屬非常態性規範，其實應**另立法律**
- **§156-4 I**：公司設立後，為**改善財務結構或回復正常營運**，參與**政府專案核定之紓困方案** → 得**發行新股轉讓於政府**，作為接受政府財務協助的對價（就是政府入股）
  - 發行程序**不受本法發行新股規定限制**：公司情況緊急，而且新增股東只有政府
  - 相關辦法由中央主管機關定
- **§156-4 II**：紓困方案達 **10 億元以上** → 專案核定的主管機關會同受紓困公司，向**立法院**報告自救計畫
- **§29 II**：主管機關應要求公司提具**自救計畫**，並得**限制發給經理人報酬**或為其他必要處置
- **§196 II**：§29 II 對**董事**準用；**§227** 再準用 §196 → **監察人**也能限制
- 問題：條文只寫「報酬」，酬勞、業務執行費用怎麼限制 → 以**辦法**限制（講義 6-16 倒數第五行）

## 不得事後追認（§196 I 末句）：
- 立法目的：避免**大股東兼董事**自己幫自己加薪（講義 6-16 最後一行）
- 「事後」＝**就任後、任期中**（講義 6-17）→ 做到一半幫自己加薪，不可以
- 立法論批評：沒什麼意義，可以**事前控制** → 先決議**下一任**董事報酬，再改選董事
- 對照 **105 台上 678**：先議決報酬、後選任董事，沒有利益衝突，不必依 §178 迴避（見公司法10-筆記-03）

> 來源：公司法11 課程字幕 01:47:47 ~ 01:54:28（講義 6-16 ~ 6-17）

## 📖 法條原文速查

> **§156-4**（紓困）
> I　公司設立後，為改善財務結構或回復正常營運，而參與**政府專案核定之紓困方案**時，得發行新股轉讓於政府，作為接受政府財務上協助之對價；其發行程序**不受本法有關發行新股規定之限制**，其相關辦法由中央主管機關定之。
> II　前項紓困方案達中華民國**十億元以上**者，應由專案核定之主管機關會同受紓困之公司，**向立法院報告其自救計畫**。

> **§29 II**　公司有第一百五十六條之四之情形者，專案核定之主管機關應要求參與政府專案紓困方案之公司提具**自救計畫**，並得**限制其發給經理人報酬**或為其他必要之處置或限制；其辦法，由中央主管機關定之。

> **§196**
> I　董事之報酬，未經章程訂明者，應由股東會議定，**不得事後追認**。
> II　第二十九條第二項之規定，對董事準用之。

> **§227**　監察人準用 §196 等規定。→ 準用條號範圍建議查閱最新六法原文（字幕唸成「277」，依文意校正為 §227）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「參與政府紓困方案發行新股給政府，須依一般發行新股程序？」 | ✕，**不受**本法發行新股規定限制 |
| 「紓困方案達多少須向立法院報告自救計畫？」 | **10 億元以上** |
| 「紓困時得限制誰的報酬？」 | 經理人（§29 II）、董事（§196 II）、監察人（§227） |
| 「董事報酬得由股東會事後追認？」 | ✕，**不得事後追認** |
| 「『事後』指什麼時候？」 | **就任後、任期中** |
| 「股東會先決議下一任報酬，再選任董事？」 | 可以，無利益衝突（105 台上 678） |

## 一、紓困限制報酬的準用鏈

```
§29 II 經理人報酬得限制
   ↓ §196 II 準用
董事
   ↓ §227 準用 §196
監察人
（酬勞、業務執行費用 → 以辦法限制）
```

## 二、事後追認與事前控制

| | 時點 | 效力 |
|---|---|---|
| 任期中幫現任董事加薪，事後追認 | 就任後 | **不得**（§196 I） |
| 先決議下一任報酬，再改選 | 選任前 | 可以，事前控制 |
