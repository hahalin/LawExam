# 公司法13 筆記：董事違法的事後求償體系與公司對現任董事起訴（§212、§213）

## 事前預防與事後求償是兩套系統：
- 事前預防：行為還沒做，請求**不作為** → 股東 §194、監察人 §218-2 II（見公司法12-筆記-12）
- 事後求償：行為已經做完，處理的是**賠償**；請求權主體是**公司**，由公司向董事求償
- 事後求償第一個要分的是：被告**現在還是不是董事**。現任與卸任走的程序不同（卸任見本講筆記-05）
- 例：董事把公司搞到虧損後辭職，公司再追究 → 走**卸任董事**那一條

## 對現任董事求償的四塊（板書顏色）：
- 紅：**公司為原告**（§212、§213）→ 本筆記
- 橘：**少數股東代表訴訟**（§214、§215）→ 本講筆記-02、03
- 綠：**投保中心**（投保法 §10-1 I ①）→ 本講筆記-04
- 黃：**監察人沒有主動起訴的權限**，只有兩個折衷方案 → 本講筆記-04

## §212：股東會普通決議是起訴要件，決議後公司有起訴義務：
- 公司要告**現任**董事，必須先有**股東會決議**（沒有特別規定 → **普通決議**）
- 這個決議是**原告資格**的一部分；一般人告董事直接起訴即可，但董事任職的公司要告他，必須先過股東會
- 決議後公司**應**自決議之日起 **30 日內**起訴 → 是**義務**，不能不告
- 講義註 112：劉連煜認為董事長直接代表公司起訴即可，不需股東會或董事會決議；沒有其他學者支持、也沒有法院採納，時間不夠就寫通說

## §213：公司與董事間訴訟由監察人代表公司：
- 原則：**監察人**代表公司
- 例外：**股東會得另選**代表公司為訴訟之人
- 「除法律另有規定外」：學者與法院一致認為指 **§214**，沒有其他增值點
- 立法目的：本來代表公司的是**董事長**（§208 III），為避免董事長**循私或顧念同事情誼**，改由監察人代表
- 經股東會普通決議後，監察人有代表公司**起訴的義務**（§212 接 §213）

## §213 的適用範圍（最高法院）：
- 股份有限公司與董事間的訴訟**一律**適用 §213：
  - 不問公司是**原告或被告**（公司告董事、董事告公司都適用）
  - 不問**原因事實**，即使與董事身分無關也適用
- 董事告公司時，公司的法定代理人：最高法院要求把**全體監察人**都列為法定代理人，再由他們決定誰代表公司

## 📖 法條原文速查

> **§212**（股東會決議對董事提起訴訟）
> 股東會決議，對於董事提起訴訟時，公司應自決議之日起**三十日內**提起之。

> **§213**（公司與董事間訴訟之代表）
> 公司與董事間訴訟，除法律另有規定外，由**監察人**代表公司，**股東會亦得另選**代表公司為訴訟之人。

> **§208 III**（前段）　董事長對內為股東會、董事會及常務董事會主席，對外**代表公司**。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **最高法院（講義 6-59 白色圈圈三）**：股份有限公司與董事間之訴訟，不論公司為原告或被告、不論原因事實為何（即使與董事身分無關），均應依 §213 由監察人代表公司。→ 字幕唸作「大法庭的裁定 109 臺上抗字 11」「96150 臺上 532」，字號無法確認，建議對照講義 6-59 查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司對現任董事起訴，須經何種決議？」 | **股東會普通決議**（§212） |
| 「股東會決議起訴後，公司得否不起訴？」 | **不得**，應於決議之日起 **30 日內**起訴 |
| 「公司與董事間訴訟由誰代表公司？」 | 原則**監察人**；股東會得另選代表訴訟之人（§213） |
| 「董事告公司，是否適用 §213？」 | **適用**，不問公司是原告或被告 |
| 「公司向董事請求與董事職務無關的債務，是否適用 §213？」 | **適用**，不問原因事實 |
| 「§213 由監察人代表的立法理由？」 | 避免董事長**循私或顧念同事情誼** |

## 一、求償體系圖

```
董事違法
├── 事前（行為未完成）→ 請求不作為
│     ├── 股東 §194
│     └── 監察人 §218-2 II
└── 事後（行為已完成）→ 公司向董事求償
      ├── 現任董事
      │     ├── 紅：公司為原告 §212 + §213
      │     ├── 橘：少數股東 §214 + §215
      │     ├── 綠：投保中心 投保法 §10-1 I ①
      │     └── 黃：監察人無主動起訴權（只有折衷方案）
      └── 卸任董事（本講筆記-05）
```

## 二、電腦圖 6-17 的兩個方向

| | 甲公司告董事乙 | 董事丙告甲公司 |
|---|---|---|
| 是否董事與公司間訴訟 | 是 | 是 |
| 先行程序 | §212 股東會普通決議 | — |
| 公司的代表 | 監察人（§213） | 全體監察人列為法定代理人 |

- 延伸例：董事乙到甲公司開的餐廳吃飯沒付 700 元，甲公司起訴請求 → 與董事身分無關，**仍走 §212、§213**。

## 三、§213 的三個例外（講義 6-60）

1. 法律另有規定（考試不會遇到）
2. 股東會另選代表訴訟之人
3. §214 少數股東代表訴訟
