# 公司法19 筆記：控制公司對從屬公司債權不得抵銷與深石原則（§369-7）

## 不得主張抵銷（§369-7 I）：
- 前提：控制公司使從屬公司為非常規交易，依 §369-4 對從屬公司**負有損害賠償責任**
- 控制公司若對從屬公司**另有債權**，在**應負擔的損害賠償限度內**，**不得主張抵銷**
- 理由：若可抵銷，控制公司只要製造一些對從屬公司的債權，就能把 §369-4 請求權抵掉，§369-4 形同虛設
- 不得抵銷的債權：**任何種類**的債權都不行（講義 14-9 倒數第 3 行）
- 對應的債務：損害賠償額度內，**任何債務**都不能抵（講義 14-10 第 2 行）

## 深石原則：債權居次（§369-7 II）：
- 字幕作「誠實原則／生實原則」，即**深石原則**（Deep Rock Doctrine）
- 前項債權，**不論有無別除權或優先權**
- 從屬公司依破產法**破產或和解**，或依公司法**重整或特別清算**時（都是清償能力出問題）
- 控制公司的債權**次於從屬公司其他債權**受清償 → 自動變成劣後債權
- 別除權、優先權記「**抵押權**」就好（質權也算）
- 學者認為：所有債權都要列後

## 立法理由（講義 14-10 倒數第 4 行）：
- 從屬公司財產是**全體債權人的總擔保**
- 避免控制公司利用參加破產分配，壓低從屬公司資本、增加負債，損害其他債權人

## 三重保護：
- 不能和解、不能拋棄（§369-4 IV）、不能抵銷（§369-7 I）→ 對 §369-4 請求權的保護很大
- 老師：§369-7 I、II 與 §369-12 幾乎只會考**選擇題**

## 📖 法條原文速查

> **§369-7**
> I　控制公司直接或間接使從屬公司為不合營業常規或其他不利益之經營者，如控制公司對從屬公司有債權，在控制公司對從屬公司應負擔之**損害賠償限度內**，**不得主張抵銷**。
> II　前項債權無論**有無別除權或優先權**，於從屬公司依破產法之規定為**破產或和解**，或依本法之規定為**重整或特別清算**時，應**次於**從屬公司之其他債權受清償。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「控制公司得否以其對從屬公司的債權，抵銷 §369-4 的賠償債務？」 | **不得**，在損害賠償限度內 |
| 「不得抵銷的債權限於金錢借貸？」 | **不限**，任何債權 |
| 「控制公司債權設有抵押權，從屬公司破產時？」 | 仍**次於**其他債權受清償 |
| 「§369-7 II 適用的程序？」 | 破產、和解（破產法）；重整、特別清算（公司法） |
| 「§369-7 II 學理名稱？」 | **深石原則**（債權居次） |

## 一、不得抵銷（電腦圖 14-6）

```
小夫公司（從屬）──§369-4 請求權 1,000 萬──→ 胖虎公司（控制）
胖虎公司 ──另有借款債權 1,000 萬──→ 小夫公司

胖虎主張兩筆互相抵銷？ → 不得（§369-7 I）
```

## 二、債權居次（電腦圖 14-7）

```
小夫對胖虎：§369-4 請求權 800 萬
胖虎對小夫：債權 800 萬，設有抵押權
        ↓
① 胖虎不得抵銷（§369-7 I）
② 小夫破產／和解／重整／特別清算
   → 胖虎的 800 萬即使有抵押權，也次於其他債權受清償（§369-7 II）
```

## 三、兩項比較

| | §369-7 I | §369-7 II |
|---|---|---|
| 內容 | 不得主張抵銷 | 債權居次 |
| 時點 | 平時 | 從屬公司破產、和解、重整、特別清算 |
| 範圍 | 損害賠償限度內 | 前項債權（不論有無擔保） |
