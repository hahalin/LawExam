# 公司法10 筆記：撤銷判決的溯及效力與決議內容無效的擴張（§189、§191）

## 撤銷判決確定後：溯及無效（講義 5-122）：
- 決議經撤銷判決確定 → **溯及**失其效力
- 已依決議執行的行為：
  - **不涉及第三人** → 原則溯及無效
  - **涉及第三人** → 還有第三人保護問題，要區分情形認定（講義只給概括想法）

## 選任董事的決議被撤銷：
- 被選任的董事在任內代表公司所為的行為怎麼辦，幾乎無法完美解答
- 一說：屬**無權代表**，類推適用無權代理，可由股東會決議**承認**
- 另有學者主張**表見代理**
- 老師：太難考，知道有這個問題即可

## 變更議案順序（講義 5-119，約十年前臺大法研所題目）：
- 依股東會議事規則，變更議案順序**須經股東會決議**；未經決議逕行變更 → 違反
- 有興趣自己看

## §191 決議內容無效，最高法院有擴張（註 355）：
- 條文只說「違反法令或章程」，但最高法院一直以來並沒有限縮解釋
- 違反下列**公司法基本原則**也屬內容違法 → 無效：
  - **股東平等原則**
  - **股東有限責任原則**
  - **股份轉讓自由原則**
  - **侵害股東固有權**
  - **公序良俗**

## 📖 法條原文速查

> **§189**（決議之撤銷）　股東會之召集程序或其決議方法，違反法令或章程時，股東得自決議之日起三十日內，訴請法院撤銷其決議。

> **§191**（決議之無效）　股東會決議之內容，違反**法令或章程**者無效。

---

## 📋 實務見解速查

> **最高法院（註 355）**：§191 所稱違反法令或章程，包括違反股東平等原則、股東有限責任原則、股份轉讓自由原則、侵害股東固有權及違反公序良俗。→ 判決字號與原文建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「撤銷判決確定後，決議效力？」 | **溯及**失效 |
| 「股東會決議違反股東平等原則，效力？」 | **無效**（§191 擴張） |
| 「§191 只限於違反具體法條？」 | ✕，包括公司法**基本原則**與公序良俗 |
| 「選任董事決議被撤銷，該董事所為代表行為？」 | 一說無權代表，類推無權代理，得由股東會承認 |

## 一、§191 的範圍

```
§191 決議內容違反法令或章程 → 無效
├── 具體法令：刑法、槍砲彈藥刀械管制條例、廢棄物清理法……
├── 章程
└── 最高法院擴張（註 355）
    ├── 股東平等原則
    ├── 股東有限責任原則
    ├── 股份轉讓自由原則
    ├── 侵害股東固有權
    └── 公序良俗
```

## 二、撤銷後的處理

| 情形 | 處理 |
|---|---|
| 決議已執行，不涉第三人 | 溯及無效，原則回復 |
| 決議已執行，涉及第三人 | 另考量第三人保護，區分情形 |
| 選任董事決議被撤銷 | 無權代表（類推無權代理，股東會得承認）／表見代理 |
