# 公司法08 筆記：提案的受理程序與300字限制（§172-1）

## 限於董事會召集的股東常會：
- §172-1 I 寫「**股東常會**」議案 → 臨時會不行，理由是避免程序太複雜
- 講義 5-21：限於**董事會**召集的股東常會（§172-1 IV 由董事會審查列入）
- 政府或法人一人股份有限公司不開股東會（§128-1，見公司法02-筆記-01）→ **沒有提案權**

## 公告受理（§172-1 II）：
- 公司應於常會召開前的**停止股票過戶日前**（閉鎖期間，§165，見公司法07-筆記-08）公告受理提案
- 公告內容：**書面或電子**受理方式、受理處所、受理期間
- 受理期間**不得少於 10 日**——選擇題超愛考，理由是讓股東有充分時間提案

## 經濟部見解（講義 5-22，每一個都要記）：
- **到達主義**：提案要在受理期間內**到達**公司（對照召集通知採**發信主義**，見本講筆記-03）
- 提案權是**固有權**（不得以章程或股東會決議剝奪，見公司法06-筆記-02）→ 公司**沒有公告**，股東**仍得行使**（國考考過）

## 300 字（§172-1 III）：
- 股東所提議案以 **300 字**為限，要背
- 學者與經濟部都同意：**包括標點符號**（選擇題考過好幾次）；附件不計（學者建議）
- 300 字是**強制規定**；超過 → 董事會得不列入（IV ④）
- 由來：抄自美國委託書規則的 500 字，立法時認為中文精簡，改為 300 字

## 提案股東應親自或委託出席：
- 提案股東應親自或委託他人出席常會，並參與該議案討論
- **沒有處罰**，只是希望提案人關注自己的議案

## 📖 法條原文速查

> **§172-1**（股東提案權）
> II 公司應於股東常會召開前之**停止股票過戶日前**，公告受理股東之提案、**書面或電子**受理方式、受理處所及受理期間；其受理期間**不得少於十日**。
> III 股東所提議案以**三百字**為限；提案股東應**親自或委託他人出席**股東常會，並參與該項議案討論。

---

## 📋 實務見解速查

> **經濟部**：股東提案採**到達主義**，應於受理期間內送達公司。
> **經濟部**：提案權為**固有權**，公司未公告受理，股東仍得提案。
> **經濟部、學者**：300 字**包括標點符號**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「提案受理期間不得少於幾日？」 | **10 日** |
| 「公告受理的時點？」 | 常會前之**停止過戶日前** |
| 「股東提案以寄出時為準？」 | ✕，**到達主義**（召集通知才是發信主義） |
| 「公司未公告受理提案，股東即不得提案？」 | ✕，**固有權**，仍得行使 |
| 「300 字不含標點符號？」 | ✕，**包括標點** |
| 「提案股東未親自或委託出席，受罰鍰？」 | ✕，**沒有處罰** |
| 「法人一人公司股東有提案權？」 | ✕，不開股東會 |

## 一、受理程序時間線

```
公告受理（書面／電子、處所、期間）
   ↓ 受理期間 ≥ 10 日（提案須「到達」）
停止過戶日（§165 閉鎖期間開始）
   ↓
召集通知日前：通知提案股東處理結果（本講筆記-10）
   ↓
股東常會：提案股東親自或委託出席、參與討論
```

## 二、發信主義 vs 到達主義

| | 召集通知（§172） | 股東提案（§172-1） |
|---|---|---|
| 誰寄給誰 | 公司 → 股東 | 股東 → 公司 |
| 主義 | 發信主義 | 到達主義 |
| 理由 | 股東太多，無法確保送達 | 受理期間內公司要能處理 |
