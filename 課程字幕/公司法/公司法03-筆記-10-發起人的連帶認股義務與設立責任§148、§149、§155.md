# 公司法03 筆記：發起人的連帶認股義務與設立責任（§148、§149、§155）

## 發起人的認股義務：
- 理由：讓公司設立之初有足夠資金
- **發起設立**：發起人認足第一次發行股份（§131）；學理上**每位發起人至少認 1 股**（法條沒寫，選擇題考過）
- **募集設立**：發起人至少認第一次發行股份的 **1/4**（§133 II，選擇題很愛考）

## 設立責任先分「成立」與「不成立」：
- **不成立**：§150 發起人連帶，認股人不負；其他公司依民法 §681（見 公司法03-筆記-05）
- **成立**：再分**對公司**與**對第三人**
- 這就是嚴格準則主義「**加重發起人責任**」的具體內容（見 公司法03-筆記-03）

## 公司成立後，發起人對公司：
- **連帶認繳義務**（§148）：①未認足的第一次發行股份 ②已認而未繳股款 ③已認而撤回 → 發起人**連帶認繳**；**無過失責任**，目的是資本充實
- **損害賠償**（§149）：因 §147（報酬、特別利益、設立費用冒濫、財產估價過高）或 §148 情形致公司受損害 → 公司得向發起人請求賠償
- **怠忽任務**（§155 I）：發起人對公司設立事項怠忽任務致公司受損害 → 對公司負**連帶**賠償責任

## 公司成立後，發起人對第三人：
- **§155 II**：發起人對於公司在**設立登記前**所負債務，在登記後**亦負連帶責任**
- 「設立登記前所負債務」＝**設立中公司**時期的債務
- 能「賠公司」就表示公司**有成立** → §155 要在條文旁寫「公司成立」；§150 寫「公司不成立」

## 📖 法條原文速查

> **§148**（發起人之連帶認繳義務）
> **未認足**之第一次發行股份，及**已認而未繳股款**者，應由發起人**連帶認繳**；其**已認而經撤回**者亦同。

> **§149**（發起人之損害賠償責任）
> 因**第一百四十七條**及**第一百四十八條**情形，公司受有損害時，得向發起人請求賠償。

> **§155**（發起人之責任）
> I　發起人對於公司設立事項，如有**怠忽其任務**致公司受損害時，應**對公司**負連帶賠償責任。
> II　發起人對於公司在**設立登記前所負債務**，在**登記後**亦負連帶責任。

> **§150**（對照：公司不能成立）
> 公司不能成立時，發起人關於公司設立所為之行為，及設立所需之費用，均應負連帶責任，其因冒濫經裁減者亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「認股人已認股後撤回，未認足部分由誰負責？」 | **發起人連帶認繳**（§148） |
| 「§148 連帶認繳責任是否以發起人有過失為必要？」 | **否**，無過失責任 |
| 「發起設立時每位發起人至少認幾股？」 | 學理上至少 **1 股** |
| 「發起人對設立中公司時期的債務，公司成立後還要負責？」 | **要**，§155 II 連帶 |
| 「§150 與 §155 的區別？」 | §150 公司**不成立**；§155 公司**成立** |
| 「誰負發起人責任？」 | **章程上簽名蓋章**之人（形式認定，見 筆記-07） |

## 一、整套責任圖（老師板書收尾）

```
發起人的設立責任
├── 公司不成立 → §150 連帶（股份有限公司）／民法 §681（其他公司）
│                 認股人不負
└── 公司成立
     ├── 對公司
     │    ├── §148 連帶認繳（未認足、已認未繳、已認撤回）—無過失
     │    ├── §149 因 §147、§148 致公司受損 → 賠償
     │    └── §155 I 怠忽任務 → 連帶賠償
     └── 對第三人
          └── §155 II 設立登記前所負債務 → 登記後亦連帶
```

## 二、§155 II 接上設立必要費用與開業準備行為

```
設立中公司的債務（公司已成立）
├── 設立必要費用 → 公司當然承受 → 屬「登記前所負債務」→ §155 II 發起人也連帶
└── 開業準備行為
     ├── 公司承認 → 公司承受 → 屬「登記前所負債務」→ §155 II 發起人也連帶
     └── 公司不承認 → 不是公司的債務 → 不進 §155 II
                       → 發起人依類推民法 §110 自負賠償責任
```

- 老師強調：只有「公司承受」的兩種情形才接到 §155 II（見 公司法03-筆記-08）

## 三、用數字走一次 §148

- A 公司首次發行 400 萬股，發起人甲、乙認 100 萬股，認股人認 300 萬股
- 認股人丙認 50 萬股後未繳款、丁認 30 萬股後撤回、另有 20 萬股始終無人認
- 甲、乙須**連帶認繳** 50 萬＋30 萬＋20 萬＝**100 萬股**；即使甲、乙沒有任何過失也一樣
- A 公司若因此受有損害，另依 §149 向甲、乙請求賠償
