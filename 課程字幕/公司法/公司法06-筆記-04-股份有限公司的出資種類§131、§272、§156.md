# 公司法06 筆記：股份有限公司的出資種類（§131、§272、§156）

## 原則現金，例外現金以外：
- 出資原則是**現金**；現金以外依時點分兩塊：**設立時**（出資人是**發起人**）、**設立後**（出資人是**股東**）
- 本段 15 年來國考只考選擇題

## 設立時：發起人：
- 發起設立：發起人出資除現金外，得以**公司事業所需之財產、技術**抵充（§131 III）
- 募集設立：發起人應向創立會報告以**現金以外之財產、技術**抵繳股款的情形（§145 I ④）
- 法人發起人（§128 III，見 公司法03-筆記-07）：
  - 第 1 款公司或有限合夥：法無明文出資種類 → 回歸 **§131**（現金、財產、技術）
  - 第 2 款：限以**自行研發**之專門技術或智慧財產權作價投資；買的、租的都**不行**（選擇題很愛考）
  - 第 3 款經目的事業主管機關核准（與創設目的相關）：法無明文 → 回歸 §131
- §128 III 是**發起人**的限制，不是股東的限制：財團法人醫院買已上市公司股票，與 §128 III 無關

## 設立後：股東：
- **公開發行**新股：應以**現金**為股款（§272 本文）
- 原有股東認購或特定人協議認購而**不公開發行**：得以**公司事業所需之財產**出資（§272 但書）
- 股東出資除現金外，得以**對公司所有之貨幣債權**、公司事業所需之財產或技術抵充；抵充數額需經**董事會決議**（§156 V，未特別規定 → 普通決議）
- 經濟部：公開發行只能現金，必須維持；非公開發行以 §156 V **補充解釋**，所以也能用貨幣債權、技術；現金任何時候都可以
- 另有**股份交換**（§156-3），見 公司法06-筆記-05

## 對公司所有之貨幣債權：
- 立法目的：**改善公司財務狀況**（降低負債比例）
- 只限對**公司**的債權，不包括對第三人的債權
- 最高法院：先讓公司買下你對第三人的債權、再拿來抵充出資，也**不行**（講義註 13，字號未唸出）

## 財產、技術與勞務的區別：
- **財產**（現物）：動產、不動產、商標權、專利權、出資額；經濟部：不得以**設定地上權**出資，須有**所有權**
- **技術**：範圍比現物廣，例如尚未取得專利的**商品製造程序**（麵包配方、溫度、時間）
- **勞務**：以在公司工作若干年作為對價 → 股份有限公司**不可以**（閉鎖性公司例外，之後學）
- **商譽**出資已刪除

## 📖 法條原文速查

> **§131 III**　發起人之出資，除現金外，得以**公司事業所需之財產、技術**抵充之。

> **§128 III**　政府或法人均得為發起人。但法人為發起人者，以下列情形為限：一、公司或有限合夥。二、以其**自行研發**之專門技術或智慧財產權作價投資之法人。三、經目的事業主管機關認屬與其創設目的相關而予核准之法人。

> **§272**　公司**公開發行**新股時，應以**現金**為股款。但由原有股東認購或由特定人協議認購，而**不公開發行**者，得以公司事業所需之**財產**為出資。

> **§156 V**　股東之出資，除現金外，得以**對公司所有之貨幣債權**、公司事業所需之財產或技術抵充之；其抵充之數額需經**董事會決議**。

> **§145 I ④**　發起人應就以現金以外之財產、技術抵繳股款者之相關事項，報告於創立會。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「發起人出資得以何者抵充？」 | 現金、公司事業所需之**財產、技術**（§131 III）；**沒有**貨幣債權 |
| 「法人發起人以購入的專利權作價投資？」 | **不可**，須**自行研發**（§128 III ②） |
| 「公開發行新股得以財產出資？」 | **不可**，只能現金（§272 本文） |
| 「股東得以對第三人的貨幣債權抵充出資？」 | **不可**，限對**公司**之貨幣債權 |
| 「§156 V 抵充數額由誰決議？」 | **董事會**（普通決議） |
| 「股份有限公司股東得以勞務出資？」 | **不可**（技術可以，勞務不行） |
| 「得以設定地上權出資？」 | **不可**（經濟部：須有所有權） |
| 「得以商譽出資？」 | **不可**，已刪除 |

## 二、為什麼股東多了「對公司貨幣債權」

- 公司要先**成立**，才可能有人對它有貨幣債權 → 發起人（設立時）不會有，股東（設立後）才有。

## 三、對第三人債權繞道抵充（最高法院否定）

1. 甲想當乙公司股東，手上只有對丙公司的 200 萬元債權。
2. 甲以 180 萬元把債權賣給乙公司，乙公司因此欠甲 180 萬元。
3. 甲再以這 180 萬元「對公司債權」抵充出資 → **不行**：公司負債並沒有因此降低，不符立法目的。

## 四、技術出資與勞務出資

| | 技術出資 | 勞務出資 |
|---|---|---|
| 內容 | 製造程序、尚未取得權利的專門技術 | 在公司工作若干年作為對價 |
| 股份有限公司 | 可以 | 不可以（考題：電機博士以在 A 公司工作三年為對價 → 不可） |
