# 公司法07 筆記：實體股票的簽章簽證與廢除無記名股票（§162、§447-1）

## 先複習：股份與股票：
- 股份**必然存在**（§156 I），股票不必然存在；股票最主要的意義是**方便轉讓**（電腦圖 4-1，見公司法06-筆記-07）

## §162 規範的是實體股票：
- 條文寫「**印製**股票者」→ 就是**實體**股票
- 股票「**應**」編號、載明法定事項（不是「得」）
- **由代表公司之董事簽名或蓋章**：只要有代表公司的董事簽章即可，**沒有規定人數**
  - 修法前有人數要求（舊法為董事三人以上，建議查證）
  - 實務上有公司沒修章仍寫多人簽章，經濟部認為也可以，只是可以刪掉
- **銀行簽證**：須經依法得擔任股票發行簽證人之**銀行**簽證後發行
  - 沒有簽證的股票是**廢紙**，不會成為有價證券；公司自己印出來不算
  - 簽證要付簽證費
- 應記載事項：公司名稱、設立或變更登記年月日、票面金額股的股份總數及每股金額（無票面只寫股份總數）、本次發行股數、發起人股票字樣、特別股字樣、發行年月日

## 2018 年刪除無記名股票：
- 現行法下實體股票**一律記名**
- 理由：無記名實體股票像鈔票，**洗錢防制**上難以追蹤流向
- 過渡：§447-1——107 年 7 月 6 日修正施行前已發行的無記名股票，繼續適用施行前規定；但持有人**行使股東權時，公司「應」將其變更為記名式**（應，不是得）→ 無記名股票只會越來越少

> 來源：公司法07 課程字幕 00:27:19 ~ 00:34:42（講義 4-28 頁、電腦圖 4-1）

## 📖 法條原文速查

> **§162 I**（股票之製作）
> 發行股票之公司**印製股票**者，股票應編號，載明下列事項，由**代表公司之董事簽名或蓋章**，並經依法得擔任股票發行簽證人之**銀行簽證**後發行之：
> 一、公司名稱。
> 二、設立登記或發行新股變更登記之年、月、日。
> 三、採行票面金額股者，股份總數及每股金額；採行無票面金額股者，股份總數。
> 四、本次發行股數。
> 五、發起人股票應標明發起人股票之字樣。
> 六、特別股應標明其特別種類之字樣。
> 七、股票發行之年、月、日。
> → 第二項以下建議查閱最新六法原文

> **§447-1**（無記名股票之過渡）
> I 本法中華民國一百零七年七月六日修正之條文施行前，公司已發行之**無記名股票**，繼續適用施行前之規定。
> II 前項股票，於持有人**行使股東權時**，公司**應**將其變更為**記名式**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「實體股票應由董事三人以上簽名或蓋章？」 | ✕，**代表公司之董事**簽名或蓋章即可，無人數規定 |
| 「股票未經銀行簽證，仍為有效之有價證券？」 | ✕，未經簽證不是有價證券 |
| 「股票簽證得由會計師為之？」 | ✕，由依法得擔任簽證人之**銀行** |
| 「現行公司法得發行無記名股票？」 | ✕，2018 年**刪除** |
| 「修法前已發行之無記名股票，持有人行使股東權時，公司『得』變更為記名式？」 | ✕，是「**應**」變更 |
| 「§162 規範的是無實體發行？」 | ✕，「印製」＝**實體**；無實體是 §161-2 |

## 一、實體股票成為有價證券的三個條件

```
公司印製股票（§162）
   ├─ 應編號、載明法定事項
   ├─ 代表公司之董事簽名或蓋章（不問人數）
   └─ 銀行簽證 ★ 缺了就是廢紙
            ↓
      有價證券，可背書轉讓（§164）
```

## 二、無記名股票的處理

| 時點 | 規定 |
|---|---|
| 2018 年修法後 | 不得發行無記名股票，實體股票一律記名 |
| 修法前已發行 | 繼續適用舊法（§447-1 I） |
| 持有人行使股東權時 | 公司**應**變更為記名式（§447-1 II） |
