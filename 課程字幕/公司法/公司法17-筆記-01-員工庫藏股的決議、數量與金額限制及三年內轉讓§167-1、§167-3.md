# 公司法17 筆記：員工庫藏股的決議、數量與金額限制及三年內轉讓（§167-1、§167-3）

## 本講定位：
- 第十一章員工獎勵、第十二章資本三原則都**偏選擇題**，老師上課速度較快
- 五種員工獎勵制度的總表與「董事、監察人不是員工」已在上一講整理（見公司法16-筆記-12），本講逐一講條文

## 適用範圍：
- **上市、上櫃**公司 → 適用**證交法 §28-2**（經濟部見解）
- 其餘公司（非上市、非上櫃）→ 適用 **§167-1**
- §167-1「法律另有規定者外」、§167-3「其他法律」都是指證交法 §28-2

## 決議、數量、金額三個限制：
- 決議：**董事會特別決議**；須在法定額度內表明金額，**不得概括授權董事長**
- 數量：不超過已發行股份總數 **5%**（選擇題考；證交法是 10%）
- 金額：收買總金額不得逾「**保留盈餘＋已實現之資本公積**」
  - 保留盈餘＝法定盈餘公積＋特別盈餘公積＋未分配盈餘
  - 已實現之資本公積＝發行溢價、受領贈與所得（§241 I ①②，見公司法16-筆記-01）
- 在額度內**沒有收買次數限制**，也不必等前一批全部轉讓完才能再買

## 三年內轉讓，每一批分別起算：
- 收買的股份應於 **3 年內**轉讓員工
- 屆期未轉讓 → **視為公司未發行股份，並為變更登記**＝**法定減資**（本講筆記-09）
- 是否逾三年，經濟部個案認定

## 持有期間與轉讓後：
- 庫藏股持有期間**不得享有股東權利**（§167-1 III）；範圍採「修正說」，講義 12-26，下一講才講
- 轉讓給員工時，得限制員工 **2 年內不得轉讓**（§167-3）
- 章程得訂明轉讓對象包括**控制或從屬公司員工**（§167-1 IV）

## 📖 法條原文速查

> **§167-1**
> I　公司除法律另有規定者外，得經**董事會**以董事三分之二以上之出席及出席董事過半數同意之決議，於不超過該公司已發行股份總數**百分之五**之範圍內，收買其股份；收買股份之總金額，不得逾**保留盈餘加已實現之資本公積**之金額。
> II　前項公司收買之股份，應於**三年內**轉讓於員工，屆期未轉讓者，**視為公司未發行股份，並為變更登記**。
> III　公司依第一項規定收買之股份，**不得享有股東權利**。
> IV　章程得訂明第二項轉讓之對象包括符合一定條件之控制或從屬公司員工。
> → 建議查閱最新六法原文

> **§167-3**　公司依第一百六十七條之一或其他法律規定收買自己之股份轉讓於員工者，得限制員工在一定期間內不得轉讓。但其期間最長不得超過**二年**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「上市公司買回庫藏股轉讓員工，依公司法 §167-1？」 | **錯**，上市上櫃適用**證交法 §28-2** |
| 「§167-1 庫藏股的決議機關？」 | **董事會特別決議**；不得概括授權董事長 |
| 「§167-1 收買數量上限？」 | 已發行股份總數 **5%** |
| 「收買總金額上限？」 | **保留盈餘＋已實現之資本公積** |
| 「額度內可否分多次收買？」 | **可以**，無次數限制 |
| 「三年內未轉讓的效果？」 | 視為未發行股份並為變更登記（**法定減資**） |
| 「轉讓員工後得限制轉讓多久？」 | 最長 **2 年**（§167-3） |

## 一、三年期限的計算（電腦圖 11-3）

| 收買日 | 應轉讓期限 |
|---|---|
| 2024/3/5 收買 3 萬股 | 2027/3/4 前 |
| 2024/8/17 再收買一批 | 2027/8/16 前 |

- 每一批**各自**起算 3 年；某一批逾期未轉讓，只有那一批視為未發行股份

## 二、流程

```
董事會特別決議（表明金額）
   ↓ 數量 ≤ 5%，金額 ≤ 保留盈餘＋已實現資本公積
公司收買自己股份（持有期間不得享有股東權利）
   ├── 3 年內轉讓員工 → 得限制員工 2 年內不得轉讓（§167-3）
   └── 逾 3 年未轉讓 → 視為未發行股份，變更登記（法定減資）
```
