# 公司法19 筆記：從屬公司債權人與少數股東的代位求償、和解拋棄不受影響及時效（§369-4、§369-6）

## 為什麼要讓別人代位（講義 14-7 第 3 行）：
- 從屬公司之所以叫從屬，就是**聽話** → 通常不會自己向控制公司求償
- 所以控制公司**未為賠償**時，特許從屬公司的債權人、股東代位行使

## 行使主體（§369-4 III）：
- **從屬公司的債權人**：不論債權**多寡**與**清償期**長短均可行使 → 民法代位權的特別規定（債權 2,000 元、兩年後才到期也可以）
- **繼續一年以上**持有從屬公司已發行**有表決權**股份總數或資本總額 **1%** 以上的股東；持股可以**湊足**（講義 3-4）
- 老師：公司法唯一明文要求「**有表決權**」的少數股東權就是這條
- 立法論批評（講義 14-8，現在幾乎不考）：1% 偏高；無表決權股東一樣受損，要求有表決權不合理

## 行使方式：
- **以自己名義**：自己當原告
- 行使的是「前二項」從屬公司的權利：對控制公司（I）、對控制公司負責人（II）
- 訴之聲明：**請求對從屬公司為給付**（法條明文）

## 和解、拋棄不受影響（§369-4 IV）：
- 從屬公司聽話，很容易就和解或拋棄對控制公司的請求權
- 法律明定：前項權利的行使，**不因從屬公司所為和解或拋棄而受影響**
- 老師：選擇題**很喜歡考**第四項

## 消滅時效（§369-6）：
- 自請求權人**知**控制公司有賠償責任及賠償義務人時起 **2 年**
- 自賠償責任發生時起 **5 年**
- 老師：要記，選擇題很喜歡考

## 📖 法條原文速查

> **§369-4**
> III　控制公司**未為第一項之賠償**，從屬公司之**債權人**或**繼續一年以上**持有從屬公司已發行**有表決權**股份總數或資本總額**百分之一以上**之股東，得**以自己名義**行使前二項從屬公司之權利，請求**對從屬公司為給付**。
> IV　前項權利之行使，**不因從屬公司就該請求賠償權利所為之和解或拋棄而受影響**。

> **§369-6**　前二條規定之損害賠償請求權，自請求權人**知**控制公司有賠償責任及知有賠償義務人時起，**二年**間不行使而消滅。自控制公司賠償責任發生時起，逾**五年**者亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「從屬公司股東代位求償的持股要件？」 | **繼續一年以上**、**有表決權**股份 **1%** 以上，可湊足 |
| 「從屬公司債權人代位，須債權已屆清償期？」 | **不必**，不論多寡、清償期長短 |
| 「代位者請求給付的對象？」 | **從屬公司**，不是自己 |
| 「從屬公司已與控制公司和解，股東還能代位？」 | **能**，和解、拋棄**不受影響**（§369-4 IV） |
| 「§369-4、§369-5 請求權的時效？」 | 知悉起 **2 年**、責任發生起 **5 年** |

## 一、代位求償的結構

```
控制公司（甲）＋負責人 ──應賠償但未賠──→ 從屬公司（乙）不敢要
                                           ↑ 給付對象
從屬公司債權人 或 一年以上有表決權 1% 股東
        └─ 以自己名義起訴，聲明：被告應給付乙公司 ○○ 元
```

## 二、§369-4 請求權的保護

| 保護 | 條文 |
|---|---|
| 從屬公司和解、拋棄不影響代位 | §369-4 IV |
| 控制公司不得以其債權主張抵銷 | §369-7 I（見本講筆記-05） |
| 控制公司債權在從屬公司破產等程序中居次 | §369-7 II（見本講筆記-05） |

- §369-5（受益從屬公司）是否在代位範圍，見本講筆記-04
