# 公司法05 筆記：改派代表人補足原任期與董事長職位的變動（§27）

## §27 III：依職務關係隨時改派、補足原任期：
- **職務關係**：指**法人股東與其代表人**之間的關係
- **隨時**：任期中任何時候都可以
- **補足原任期**：補足的是原**董事（監察人）任期**，例如原任期 3 年剩 1 年，新代表人做滿那 1 年
- 經濟部：改派是**單獨行為**，通知**到達公司**即生效

## 兩條線要分清楚（電腦圖 2-25、2-26）：
- **職務關係**（法人股東 ⇄ 代表人）：**可以切斷**，切斷後可改派補足原任期
  - 例：法人股東改派代表人、代表人向法人股東辭職、代表人本身發生解任事由
- **委任關係**（被投資公司 ⇄ 董事）：**不能用改派處理**，一旦切斷就形成**董事缺位**，不得改派補足任期
  - 例：董事向被投資公司辭職、被投資公司解任董事、董事發生當然解任事由

## §27 與 §128-1 不得併用：
- 經濟部：兩者互相衝突，不可共同使用
- 理由：§27 的董監要經**股東會選任**；§128-1（政府或法人一人股東公司）的董監由法人股東**指派**，沒有選舉（見 公司法02-筆記-01）

## 董事長職位的變動（國考考過三次以上）：
- **§27 I 法人董事長**：法人董事經董事會選為董事長，董事長是**法人**本身
  - 法無明文，但依法理仍須指定自然人代表；且**董事代表人與董事長代表人必須是同一人**
  - 理由：進董事會會場靠董事身分、坐主席位靠董事長身分，兩人不同就無法行使職務；沒有董事代表身分也不能當董事長代表
  - 改派董事代表人 → 法理上**被迫一併改派**董事長代表人 → 董事、董事長**仍是同一法人**，**不需補選**
- **§27 II 代表人董事長**：代表人本人當選董事、再被選為董事長
  - 法人股東依 §27 III 改派 → 原代表人**喪失董事身分** → 董事長必須是董事 → 董事長**當然解任** → **董事長缺位**，須**補選董事長**

## 一句話抓重點：
- §27 I 換的是**代表人**，董事、董事長都還是那個法人
- §27 II 換的是**董事本人**，董事長就要重選

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§27 III 的職務關係是指？」 | **法人股東與代表人**之間的關係 |
| 「改派的代表人任期如何計算？」 | **補足原任期** |
| 「改派何時生效？」 | **單獨行為**，到達公司即生效（經濟部） |
| 「代表人已向被投資公司辭去董事，法人股東得否改派補足？」 | **不得**；委任關係消滅，形成**缺位** |
| 「§27 與 §128-1 得否併用？」 | **不得**（經濟部） |
| 「法人董事長（§27 I）改派代表人，須否補選董事長？」 | **不須**；董事長仍是法人，代表人一併更換 |
| 「代表人董事長（§27 II）被改派，董事長職位如何？」 | **當然解任**、董事長**缺位**，須**補選** |
| 「§27 I 董事代表人與董事長代表人得否不同人？」 | **不得**，必須同一人 |

## 一、職務關係與委任關係（公司名改為甲乙丙）

```
§27 I                                    §27 II
甲公司 ══委任══ 乙公司（董事）            甲公司 ══委任══ B（董事）
                  ⇅ 職務關係                                ⇅ 職務關係
                  A（董事代表人）                          丙公司（法人股東）

⇅ 職務關係 → 可切斷 → 改派補足原任期（§27 III）
══ 委任關係 → 切斷 = 董事缺位 → 不得改派補足
```

| 切斷的是 | 情形 | 可否改派補足 |
|---|---|---|
| 職務關係 | 法人股東改派；代表人向法人股東辭職；代表人自身事由 | **可以** |
| 委任關係 | 董事向公司辭職；公司解任董事；董事當然解任事由 | **不可以**（缺位） |

## 二、董事長的變動（老師黑板）

```
§27 I：法人董事長
  董事＝乙公司　董事長＝乙公司
  董事代表人 A ＝ 董事長代表人 A
  乙改派 A → C：董事代表人換成 C → 董事長代表人也必須換成 C
  結果：董事、董事長仍是乙公司 → 不需補選

§27 II：代表人董事長
  董事＝B　董事長＝B（丙公司派）
  丙改派 B → D：D 成為董事，B 不再是董事
  B 喪失董事身分 → 董事長當然解任 → 董事長缺位 → 補選董事長
```
