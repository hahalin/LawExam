# 公司法07 筆記：票面金額股單向轉換為無票面金額股（§156-1）

## 轉換程序（§156-1 I 前段、II）：
- **股東會特別決議**（2/3 出席、出席表決權過半數同意），將已發行之票面金額股**全數**轉換為無票面金額股
- 章程可以提高出席與表決門檻（II）

## 只能單向轉換（§156-1 VI）：
- 已採無票面金額股者，**不得轉換為票面金額股** → 只能「票面 → 無票面」
- 立法理由（講義註 64）：國外少見兩者自由互轉，自由互轉會造成**資訊混淆**
- 老師：簡單講就是怕大家搞不清楚；他個人認為全部無票面也沒問題

## 轉換的會計效果（§156-1 I 後段）：
- 轉換前依 §241 I ① 提列的資本公積（**發行溢價**）應**全數轉為資本**
- 電腦圖 4-11：票面 10 元、發行價 90 元、100 萬股
  - 轉換前：股本 1,000 萬、發行溢價 8,000 萬
  - 轉換後：股本 **9,000 萬**、發行溢價 **0**（無票面就不會有溢價這個項目）

## 公開發行公司不適用（§156-1 V）：
- 前四項規定**公開發行公司不適用** → 公開發行公司**不得**將票面金額股轉為無票面金額股
- 2018 年立法理由：公開發行公司涉及眾多投資人權益，原則上**續行維持**，避免投資人困擾
- 老師：理由不強，理論上公發公司轉換沒有問題，只是怕股民不懂造成恐慌

## 經濟部見解：非公發的無票面公司可以申請公開發行（選擇題考過）：
- 公司在**非公開發行時就已是無票面**，之後申請成為公開發行公司 → **續行無票面金額股**
- 區分：§156-1 V 禁止的是公發公司「**做轉換的動作**」；原本就無票面、只是**維持狀態**，可以
- 所以公開發行公司**有可能是無票面金額股**
- 成為公開發行公司的方式：公開發行的動作或狀態（證交法 §22、§42，見公司法01-筆記-06）

## 技術性規定（§156-1 III、IV）：
- III：公司**印製股票**者，全數轉換時，已發行股票上的每股金額自轉換基準日起**視為無記載**
- IV：公司應通知股東於轉換基準日起 **6 個月內**換取股票
- 為什麼要換：§162 I ③ 票面金額股的股票要記載每股金額，無票面只記載股份總數 → 股票要改掉票面金額

## 📖 法條原文速查

> **§156-1**（票面金額股轉換為無票面金額股）
> I 公司得經有代表已發行股份總數三分之二以上股東出席之股東會，以出席股東表決權過半數之同意，將已發行之票面金額股**全數轉換**為無票面金額股；其於轉換前依第二百四十一條第一項第一款提列之資本公積，應**全數轉為資本**。
> II 前項出席股東股份總數及表決權數，章程有較高之規定者，從其規定。
> III 公司印製股票者，依第一項規定將已發行之票面金額股全數轉換為無票面金額股時，已發行之票面金額股之每股金額，自轉換基準日起，**視為無記載**。
> IV 前項情形，公司應通知各股東於轉換基準日起**六個月內**換取股票。
> V 前四項規定，於**公開發行股票之公司，不適用之**。
> VI 公司採行無票面金額股者，**不得轉換為票面金額股**。

> **§241 I ①**　超過票面金額發行股票所得之溢額。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「票面金額股轉為無票面金額股，董事會決議即可？」 | ✕，**股東會特別決議** |
| 「公司得將部分票面金額股轉為無票面金額股？」 | ✕，須**全數**轉換 |
| 「無票面金額股得轉換為票面金額股？」 | ✕，**單向**轉換（§156-1 VI） |
| 「公開發行公司得將票面金額股轉為無票面金額股？」 | ✕（§156-1 V） |
| 「採無票面金額股之非公開發行公司，得申請公開發行？」 | **可以**，續行無票面（經濟部） |
| 「轉換前之發行溢價資本公積仍保留為資本公積？」 | ✕，**全數轉為資本** |
| 「轉換後股東應於幾個月內換取股票？」 | 轉換基準日起 **6 個月** |

## 一、轉換前後（電腦圖 4-11）

```
轉換前（票面 10 元、發行價 90 元、100 萬股）
   股本 1,000 萬 ＋ 資本公積（發行溢價）8,000 萬
            │ 股東會特別決議，全數轉換
            ▼
轉換後（無票面）
   股本 9,000 萬 ＋ 發行溢價 0
```

## 二、公開發行公司能不能「是」無票面？

```
情形 A：已是公發公司，原為票面金額股 → 想轉無票面
        → ✕ §156-1 V（禁止的是轉換動作）

情形 B：非公發時已是無票面 → 申請公開發行（證交法 §22 / §42）
        → ○ 續行無票面（經濟部，維持原狀態）
```
