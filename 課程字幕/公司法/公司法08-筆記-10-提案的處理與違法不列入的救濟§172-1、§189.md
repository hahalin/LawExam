# 公司法08 筆記：提案的處理與違法不列入的救濟（§172-1、§189）

## 處理結果的通知（§172-1 VI）：
- 公司應於**股東會召集通知日前**，將處理結果通知提案股東
- 合於規定的議案 → **列於開會通知**
- 未列入的 → 董事會於**股東會**說明未列入的理由
- 老師批評：開會時才說明理由毫無實益；學者主張應在事前通知時就告訴股東理由，但條文沒有這樣規定

## 違反的四種效果（講義 5-27 ~ 5-28）：
- ①**行政罰鍰**（§172-1 VII：違反 II、IV、VI）——罰得不多，不太痛
- ②**訴請撤銷股東會決議**（§189）——有爭議，見下方
- ③**損害賠償**：董事會違反 §172-1 II 或 IV，股東**沒有直接損害賠償請求權**；現行法下只能由**公司**向董事求償（字幕提到「代位」，應指股東代表訴訟，建議查證）——一定要打勾記住
- ④**定暫時狀態處分**（民訴 §538）：請求將議案列入
- 考法：講義 5-33（2018 年國考，字幕作「司法院」，考試別建議查證）——A 公司董事會未將議案列入是否合法、對股東會有何影響、如何救濟或因應
- 陷阱：有考生寫「自行開股東會」——那不是提案未被列入的救濟方法

## 能不能撤銷股東會決議：
- **法院見解**（少見的實際判決，講義 5-28）：一審認為不算瑕疵；臺高院認為縱未符合受理期間 10 日的規定，**瑕疵非重大且於決議無影響**，不達得撤銷的程度 → 這是 §189-1 裁量駁回的問題（講義 5-108 會學）
- 結論：法院對提案未被列入的效果採弱勢立場
- **學者見解**（幾乎一致）：違反 §172-1 II 或 IV ＝**召集程序違法的重大瑕疵**，得依 §189 撤銷
- 但是：只能撤銷**與提案內容相關且受影響**的議案 → 救濟其實有等於無

## 撤銷的範圍（電腦圖 5-5）：
- 股東 5 月合法提出「盈餘分派案」，董事會違法不列入
- 股東會議案：A 選任董事案、B 盈餘分派案、C 變更章程案
- 只能撤銷 **B**（與提案相關）；A、C 與提案無關，**不能撤銷**
- 如果股東會根本**沒有相關議案** → 無從撤銷，股東提案權最弱的地方

## 📖 法條原文速查

> **§172-1**
> VI 公司應於股東會**召集通知日前**，將處理結果通知提案股東，並將合於本條規定之議案**列於開會通知**。對於未列入議案之股東提案，董事會應於**股東會說明**未列入之理由。
> VII 公司負責人違反第二項、第四項或前項規定者，各處**罰鍰**。→ 金額建議查閱最新六法原文

> **§189**（決議之撤銷）　股東會之**召集程序**或其決議方法，違反法令或章程時，股東得自決議之日起**三十日**內，訴請法院撤銷其決議。

> **§189-1**（裁量駁回）　法院對於前條撤銷決議之訴，認為其違反之事實**非屬重大且於決議無影響**者，得駁回其請求。

> **民事訴訟法 §538 I**（定暫時狀態處分）　於爭執之法律關係，為防止發生重大之損害或避免急迫之危險或有其他相類之情形而有必要時，得聲請為定暫時狀態之處分。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **臺高院**（講義 5-28，字號建議查證）：縱有未於受理期間 10 日之瑕疵，瑕疵非重大且於決議無影響，不達得撤銷之程度。
> **學者**：違反 §172-1 II、IV 為召集程序之重大瑕疵，得依 §189 撤銷，但限於與提案內容相關之議案。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「處理結果應於何時通知提案股東？」 | **召集通知日前** |
| 「未列入議案之理由於何時說明？」 | 於**股東會**說明 |
| 「董事會違法不列入，股東得直接向董事請求損害賠償？」 | ✕，**無直接請求權** |
| 「股東得聲請定暫時狀態處分要求列入？」 | **可以**（民訴 §538） |
| 「違法不列入，股東得撤銷股東會全部決議？」 | ✕，學者：限**相關**議案；法院傾向瑕疵非重大 |
| 「違反 §172-1 II、IV、VI 的行政責任？」 | 公司負責人**罰鍰**（VII） |

## 一、處理時間線

```
受理期間（≥ 10 日）
   ↓ 董事會審查（§172-1 IV）
召集通知日前 → 通知提案股東處理結果
   ├─ 合規 → 列於開會通知
   └─ 未列入 → 股東會上說明理由
```

## 二、四種救濟

| 救濟 | 可否 | 說明 |
|---|---|---|
| 罰鍰 | 可 | §172-1 VII，金額不高 |
| 撤銷決議 | 有爭議 | 法院：瑕疵非重大；學者：召集程序違法，但限相關議案 |
| 損害賠償 | 股東不能直接請求 | 由公司向董事求償 |
| 定暫時狀態處分 | 可 | 民訴 §538，請求列入 |

## 三、可撤銷的範圍

```
股東合法提「盈餘分派案」→ 董事會違法不列入
   股東會議案：A 選任董事 ✘ 不能撤銷（無關）
              B 盈餘分派 ✔ 可以撤銷（相關）
              C 變更章程 ✘ 不能撤銷（無關）
   沒有 B 案 → 無從救濟
```
