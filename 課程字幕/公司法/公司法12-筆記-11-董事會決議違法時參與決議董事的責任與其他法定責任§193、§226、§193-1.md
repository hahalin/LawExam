# 公司法12 筆記：董事會決議違法時參與決議董事的責任與其他法定責任（§193、§226、§193-1）

## 意思決定與執行分開看（電腦圖 6-14）：
- 意思決定：**董事會**；執行：董事長、董事或董事會指定的董事
- 執行的人違反忠實義務、善管注意義務致公司受損 → 依 **§23 I** 負賠償責任（見公司法02-筆記-09）
- 執行若是**基於董事會決議**，參與決議的董事也應負責 → **§193**
- §193 的前提：有一個**合法召開並作成決議的董事會**，而且執行者**照著決議**去做

## 沒有 §193 的情形（電腦圖 6-15）：
- **未召開**董事會 → 沒有 §193
- 有召開，但執行者**未依照決議**而為（董事會說投資阿拉斯加，他去投資非洲）→ 沒有 §193
- 有召開，但執行者**逾越權限**（說好在美國開 10 人小工廠，他蓋了上千人的大廠）→ 沒有 §193
- 以上只剩執行者本人依 §23 負責

## §193 的要件與免責：
- 董事會執行業務應依照**法令、章程及股東會決議**（§193 I）
- 決議違反前項致**公司**受損害 → **參與決議**的董事對**公司**負賠償責任（§193 II）
- 免責：**表示異議**，且有**紀錄或書面聲明可證**——要求的是「異議」，不是「反對」；實務上要請求議事錄記名

## 各種董事的責任：
- 出席、參加表決、**同意** → 有責
- 出席、參加表決、**異議**且有紀錄或書面聲明 → 免責
- **未出席**（法無明文，學者多數）：有正當理由 → 無 §193；**無正當理由** → 有 §193（董事有出席義務；出席異議要這麼複雜才能免責，不來就直接免責太誇張）
- **出席但未參加表決**（棄權、離席）：林國全採**肯定說**，仍有 §193；沒有實務見解，申論題考的機率低，但要看得出這個爭點

## 其他法律明定董事應負責的情形（講義 6-53 第五點）：
- 資本不實（§9，見公司法05-筆記-01）
- 違法轉投資（§13，見公司法04-筆記-03）
- 違法貸放資金（§15，見公司法04-筆記-05）
- 違法保證（§16，見公司法04-筆記-06）
- 違反善良管理人注意義務（§23）
- 違反股份收回禁止（講義 12-23，之後講）
- 第七、八項老師說沒考過、可打叉；第九項 §276（講義 10-9，之後講，會考選擇題）

## 董監連帶、責任解除與責任保險（講義 6-57，都沒考過）：
- **§226**：監察人對公司或第三人負損害賠償責任，而董事亦負其責任時，兩者為**連帶債務人**
- **§231**：責任解除，講義 8-3 會詳細講
- **§193-1**：公司得為董事投保**責任保險**；投保或續保後，應將投保金額等重要內容提**最近一次董事會**報告；由公司投保，不必董事自己投保

## 📖 法條原文速查

> **§193**（董事會執行業務之依據與責任）
> I　董事會執行業務，應依照**法令章程及股東會之決議**。
> II　董事會之決議，違反前項規定，致**公司**受損害時，**參與決議**之董事，對於公司負賠償之責；但經**表示異議**之董事，**有紀錄或書面聲明可證**者，免其責任。

> **§193-1**（董事責任保險）
> I　公司得於董事任期內就其執行業務範圍依法應負之賠償責任投保責任保險。
> II　公司為董事投保責任保險或續保後，應將其責任保險之投保金額、承保範圍及保險費率等重要內容，提**最近一次董事會**報告。

> **§226**　監察人對公司或第三人負損害賠償責任，而董事亦負其責任時，該監察人及董事為**連帶債務人**。

> **§231**　各項表冊經股東會決議承認後，視為公司已解除董事及監察人之責任。但董事或監察人有不法行為者，不在此限。→ 建議查閱最新六法原文

> 字幕校正：「股份回籠禁止」推定為「股份收回禁止」，建議查證；第七、八項字幕唸作「1251 跟 259」，條號建議對照講義 6-53。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事會決議違反股東會決議致公司受損，誰負責？」 | **參與決議**的董事對**公司**負責（§193 II） |
| 「出席董事如何免責？」 | **表示異議**，且有**紀錄或書面聲明**可證 |
| 「董事長未經董事會決議擅自投資，適用 §193？」 | **否**，只有執行者依 §23 負責 |
| 「無正當理由未出席的董事？」 | 學者多數：**仍負 §193 責任** |
| 「出席但棄權、離席的董事？」 | 林國全：**仍負責**（無實務見解） |
| 「董事與監察人同負損害賠償責任？」 | **連帶債務人**（§226） |
| 「董事責任保險投保後向誰報告？」 | **最近一次董事會** |

## 一、§193 的判斷（電腦圖 6-15）

```
董事長／董事執行業務致公司受損
 ├── 未召開董事會 ─────────────── 無 §193（執行者 §23）
 └── 有召開董事會
       ├── 未依決議而為／逾越權限 ── 無 §193（執行者 §23）
       └── 依決議而為 → 決議違反法令、章程、股東會決議
              ├── 出席、參加表決
              │     ├── 同意 ─────────────── 有責
              │     └── 異議＋紀錄或書面聲明 ── 免責
              ├── 出席、未參加表決（棄權、離席）── 林國全：有責
              └── 未出席
                    ├── 有正當理由 ── 無責
                    └── 無正當理由 ── 有責（學者多數）
```

## 二、為什麼 §193 很少考

- 題目要先設計「有合法董事會決議 → 執行者照著做」，才輪得到 §193
- 申論題還要特別點出未出席、棄權、離席的董事，又沒有實務見解支撐
