# 公司法20 筆記：有限公司股東同意不拘形式但不得排除股東表示意見（113台上702）

## 有限公司沒有股東會（見公司法01-筆記-09）：
- 法條只寫「經股東表決權過半數／三分之二以上之**同意**」，**怎麼取得同意沒有規範**

## 113 台上 702（近一兩年熱門判決）：
- 表決權如何行使**原則不拘形式**：書面、個別、共同都可以
- 例：星期一到星期五分別一位一位問、分別拿書面同意 → 可以；五人集合一次表決 → 也可以
- 但要以**能確認全體股東對特定議案都有表示意見機會**的合理方式為之；理由：表決權是股東的**固有權**，不得剝奪
- 若**排除少數股東表示異議的機會**，必須同時證明三件事才合法：
  1. **善意**
  2. **正當商業目的**
  3. 符合**比例原則**
- 不符合 → 構成**權利濫用**（民法 §148），**決議無效**
- 老師：這個見解**很硬**，要記得
- → 判決原文用語建議查證

## 2023 年考題（講義 17-25 ~ 17-27）：
- 出題時判決還沒出來，但可以「舊題新解」
- 爭點一：一定要開股東會嗎？
  - 臺南地院：**不需要**，取得法定同意即可
  - 蔡英欣（推測為出題老師）：原則不需要，但有**長期慣行**或**章程明定**開會時就需要；本題「向來遇有重要事項就邀集各股東」＝長期慣行 → 需要
- 爭點二：瑕疵如何救濟？
  - 臺南地院：**得撤銷**
  - 蔡英欣：**決議無效**，不必依民法 §56 撤銷
  - 113 台上 702：故意不問乙，沒有善意 → 民法 §148 權利濫用，**決議無效**

## 📖 法條原文速查

> **民法 §148 I**　權利之行使，不得違反公共利益，或以**損害他人為主要目的**。

> **民法 §56 I**　總會之召集程序或決議方法，違反法令或章程時，社員得於決議後三個月內請求法院撤銷其決議。但出席社員，對召集程序或決議方法，未當場表示異議者，不在此限。

> **§106 I 前段**　公司增資，應經股東表決權**過半數**之同意。

## 📋 實務見解速查

> **113 台上 702**：有限公司股東表決權如何行使，法無明文，原則不拘形式，得以書面、個別或共同方式為之，但須能確認全體股東均有對特定議案表示意見的機會；表決權為股東固有權，排除少數股東表示異議的機會者，須具備善意、正當商業目的並符合比例原則，否則屬權利濫用，決議無效。（依課堂講述整理，原文建議查證）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有限公司股東同意是否須召開股東會？」 | 原則**不拘形式**，書面、個別、共同均可 |
| 「董事得只徵詢部分股東取得過半數同意？」 | 須讓**全體股東**都有表示意見的機會 |
| 「排除少數股東表示意見的合法要件？」 | **善意**＋**正當商業目的**＋**比例原則** |
| 「不符合上述要件的效力？」 | 民法 §148 權利濫用，**決議無效**（113 台上 702） |
| 「長期慣行開會卻未開會？」 | 蔡英欣：需要開會；臺南地院：不需要 |

## 一、2023 考題事實套用

```
A 有限公司：股東甲、乙、丙、丁（各 1 票），甲為董事
慣例：重要事項都邀集全體股東決議
甲想增資，因乙向來反對，只問丙、丁
  → 甲、丙、丁 3/4 已過半數（§106 I），票數夠
  → 但乙被刻意排除
  → 善意？✕（目的就是避開反對者）
  → 113 台上 702：權利濫用，決議無效
```

## 二、三說比較

| | 是否須開股東會 | 瑕疵效果 |
|---|---|---|
| 臺南地院 | 不需要 | 得撤銷 |
| 蔡英欣 | 長期慣行或章程明定時需要 | 無效 |
| 113 台上 702 | 不拘形式，但須給全體表示意見機會 | 權利濫用 → 無效 |
