# 公司法10 筆記：撤銷訴訟原告須當場異議的類推適用、例外與訴權繼受（§189、民法§56）

## 出席股東要當場表示異議（最高法院幾乎一面倒）：
- §189 只寫「股東」，但最高法院**類推適用民法 §56 I 但書**：出席股東對召集程序或決議方法**未當場表示異議**，不得訴請撤銷
- 是**類推適用**，不是直接適用
- 理由：未表示異議的股東事後轉而主張違法，股東任意反覆會影響公司法律秩序的安定（講義 5-106 末四行）→ 一句話就是**禁反言**；老師：理由對，但不夠有力

## 否定說與其他見解（參考）：
- 劉連煜：公司法制定在民法之後卻沒有採，**顯無採用之意**；公司法是特別法
- 邵慶平另有特殊見解（註 312）
- 最高法院已經決定，考試寫最高法院

## 兩個實務小見解（沒考過）：
- 只是**表達不同意**的意見（投反對票），不等於異議（註 314）
- **受託代理人**當場異議，效力歸屬**本人**（註 310）

## 出席未異議的兩個例外（講義 5-107，要畫起來）：
- **沒有充分機會表示異議**：主席因部分股東在場鼓譟，未經決議逕行宣布散會（註 315）
- **瑕疵無法得知**：開會前無權稽核實際出席人數與股份數，無法當場查核報告是否正確（註 316）

## 未出席股東也可以起訴：
- 未出席的股東**無法期待其事前預知**，也**無法當場表示異議**，所以容許提起（講義 5-107 白圈三）
- 老師批評：一開始堅持要異議，後面又一直開例外

## 訴權繼受（講義 5-107 ~ 5-108）：
- 原則：原告在**決議時**與**起訴時**都要有股東身分
  - 起訴時：決定當事人適格
  - 決議時：要在股東會當時取得撤銷訴權
- 例外：前手在決議時是股東，且依民法 §56 **已取得撤銷訴權**（不論是當場異議、例外情形或未出席），**訴權不因股份轉讓而消滅**，由**繼受人**行使
- 最高法院的想法像「包裹」：移轉股份（買賣、贈與都可）時，訴權包在股份裡一起過去
- **原始取得新股**者不能繼受（發行新股不是從前手受讓）

## 📖 法條原文速查

> **§189**（決議之撤銷）　股東會之召集程序或其決議方法，違反法令或章程時，**股東**得自決議之日起三十日內，訴請法院撤銷其決議。

> **民法 §56 I**（總會決議之撤銷）　總會之召集程序或決議方法，違反法令或章程時，社員得於決議後**三個月內**請求法院撤銷其決議。**但出席社員，對召集程序或決議方法，未當場表示異議者，不在此限。**

- 字幕把民法 §56 I 唸成「會後 30 日內」，民法條文是**三個月**，已依六法校正；公司法 §189 才是 30 日。

## 📋 實務見解速查

> **最高法院（多數見解）**：§189 撤銷訴訟，類推適用民法 §56 I 但書，出席股東須當場表示異議。

> **93 台上 123**（註 315，字號依字幕，建議查證）：主席因部分股東鼓譟，未經決議逕行宣布散會，股東無充分機會對選舉結果表示異議 → 仍得起訴。

> **註 316 判決**：開會前無從稽核實際出席人數及股份數，無法當場查核 → 雖未當場異議仍得起訴。→ 字號建議查證

> **註 314 判決**（字幕作「12 台上 2347」，年度建議查證）：僅表達不同意見，不等於表示異議。

> **最高法院（講義 5-108）**：前手已依民法 §56 取得撤銷訴權，訴權不因股份轉讓而消滅，由繼受人行使；原始取得新股者不適用。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「出席股東未當場異議，得依 §189 起訴？」 | 最高法院：**原則不得**（類推民法 §56 I 但書） |
| 「是直接適用還是類推適用民法 §56？」 | **類推適用** |
| 「主席未經決議逕行宣布散會，股東來不及異議？」 | **仍得起訴**（無充分機會） |
| 「未出席股東得否起訴撤銷？」 | **得** |
| 「決議後才受讓股份的股東得否起訴？」 | 前手已取得訴權 → **得（訴權繼受）** |
| 「決議後因發行新股取得股份的股東？」 | ✕，原始取得不繼受 |

## 一、原告資格四格

| 決議時是股東？ | 出席？ | 當場異議？ | 有訴權？ |
|---|---|---|---|
| 是 | 是 | 是 | **有** |
| 是 | 是 | 否 | 原則無；**無充分機會、瑕疵無法得知**例外有 |
| 是 | 否 | — | **有**（無法期待預知） |
| 否 | — | — | 原則無；前手有訴權 → **訴權繼受** |

## 二、訴權繼受（假設日期）

```
6/30 股東會  甲出席並當場異議 → 甲取得訴權
7/10 甲把股份賣給乙 → 訴權隨股份一起移轉
7/20 乙起訴（決議之日起 30 日內） → 合法原告
──
若乙是 7/10 認購公司發行的新股 → 原始取得 → 沒有訴權
```
