# 公司法03 筆記：設立登記生效與登記對抗（§6、§12）

## 公司法只有一種登記是登記生效：
- **登記生效主義**：要登記才發生效力 → 公司法只有 **§6 設立登記**
- 其餘登記一律是**登記對抗主義**：§12
- 依據就在 §12 的文字：「公司**設立登記後**」才開始適用 → 設立登記本身不在其內

## §12 登記對抗：
- 設立登記後，①**應登記而不登記** ②**已登記之事項有變更而不為變更之登記** → **不得以其事項對抗第三人**
- 目的：**對外公示揭露**，讓外界了解公司內部情形，並督促公司儘快登記

## 「第三人」要不要分善意惡意：
- **實務多數：均不得對抗說**，不分善意惡意；理由：使法律關係**合一確定**，並促使公司儘速辦理變更登記
- **劉連煜、邵慶平**：僅不得對抗**善意**第三人，對惡意第三人可以對抗；理由：保護不知情的人，明知登記不實的人不值得保護
- 老師判斷：申論出題機率低，題目要出得很明顯才會考到 §12

## 登記與真正，符合其一即生效：
- 經理人代表公司簽約：**經濟部登記的經理人**或**真正選任的經理人**，符合其一即對公司生效
- 和經理人「形式認定：登記或選任擇一」是同一個邏輯（見 公司法02-筆記-06）

## 📖 法條原文速查

> **§6**（設立登記）
> 公司非在中央主管機關**登記後，不得成立**。→ 登記生效

> **§12**（登記對抗）
> 公司**設立登記後**，有應登記之事項而**不登記**，或已登記之事項有變更而**不為變更之登記**者，**不得以其事項對抗第三人**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司法哪一種登記採登記生效主義？」 | **只有設立登記**（§6） |
| 「變更登記未辦，效力？」 | **不得對抗第三人**（§12，登記對抗） |
| 「§12 的第三人是否限於善意？」 | 實務多數：**不分善惡意**均不得對抗；學者（劉連煜、邵慶平）：限善意 |
| 「公司已改選經理人但未變更登記，原經理人代表公司簽約，公司可否否認？」 | **不可以**，不得以未登記的變更對抗第三人 |
| 「新經理人已選任但尚未登記，代表公司簽約是否生效？」 | **生效**，真正經理人 |

| 9/5 | 甲 | ✓ | ✗ | ✓ **最糟**：公司不改登記，不得對抗 |

- 9/5 這天最能看出登記對抗的厲害：公司早已換人卻拖著不登記，就要承受原經理人的簽約
- 套用兩說：均不得對抗說 → 相對人明知甲已被換掉也一樣生效；善意說 → 相對人知情時公司可以對抗

## 二、兩種主義對照

| | 登記生效 | 登記對抗 |
|---|---|---|
| 條文 | §6 | §12 |
| 範圍 | 設立登記 | 設立登記後的其他登記 |
| 未登記 | 公司不成立 | 不得對抗第三人 |
