# 公司法18 筆記：閉鎖性公司章程限制轉讓的經濟部見解、遺產指定承購與屬性公開（§356-5、§356-2）

## 轉讓限制「應」於章程載明（§356-5 I）：
- 理由：股東間關係緊密、有信賴關係，維持閉鎖性（講義 13-3）
- 是「**應**」不是「得」：一定要寫在章程
- 讓受讓人知道限制：印製股票者，股票上以**明顯文字註記**；不印製者，於交付股東的相關文件中載明（II）；受讓人得請求公司給**章程影本**（III）

## 經濟部見解：限制的內容（講義 13-4 ~ 13-5，考點）：
- 限制必須是**永久**的：章程規定「限制期間屆滿後即可自由轉讓」→ **違法**
- 可能的限制方式：**先買權**條款、**同意**條款
- 適用於**全體股東**，不分普通股、特別股 → 每個人都要受限制
- **不同股東可以有不同限制**（例：A 不得轉讓；B 只能轉讓給乙；C 須經董事會特別決議才能轉讓）
- 但規定**部分股東不受限制 → 不可以**（可寬可緊，但都要限制）
- **分段期間**可以：例「3 年內不得轉讓，3 年後經董事會同意得轉讓」
- 「普通股股東非經同意不得出售、質押、擔保或其他處分」→ 可以（完全禁止也可）

## 股份成為遺產（講義 13-5 註 9）：
- 問題：股東過世、繼承人眾多 → 人數超過 50 人，公司什麼都沒做就違法
- 經濟部：得以章程限制繼承時的處理；限制違反公序良俗或權利濫用者，可以起訴爭執
- **112 台上 1512**：閉鎖性公司股份作為遺產，章程得規定**指定股東承購**，與公序良俗無違（該案由特別股股東指定承購人）→ 要旨建議查證
- 邵慶平老師：這種限制可以，但要注意**特留分**問題

## 閉鎖性屬性的公開（§356-2）：
- 公司應於**章程載明閉鎖性之屬性**，並由中央主管機關**公開於資訊網站**
- 想知道交易對象是不是閉鎖性 → 看**章程**或查**經濟部網站**
- 立法時學者曾想把「閉鎖性」放進公司**名稱**，立委認為有歧視疑慮而作罷

## 📖 法條原文速查

> **§356-5**
> I　公司股份轉讓之限制，**應於章程載明**。
> II　前項股份轉讓之限制，公司印製股票者，應於股票以**明顯文字註記**；不印製股票者，並應於交付股東之相關文件中載明。
> III　前項股份轉讓之受讓人得請求公司給與**章程影本**。

> **§356-2**　公司應於**章程載明閉鎖性之屬性**，並由中央主管機關**公開於其資訊網站**。

## 📋 實務見解速查

> **經濟部見解**：轉讓限制須為**永久**，達限制期間後即可轉讓者違法；適用全體股東、不分普通股特別股；得對不同股東為不同限制，但不得使部分股東不受限制；得分期間限制。

> **112 台上 1512**：閉鎖性公司股份為遺產時，章程得規定由指定之股東承購，不違背公序良俗。→ 建議查證判決原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「閉鎖性公司股份轉讓限制『得』於章程載明？」 | ✕，「**應**」於章程載明 |
| 「章程規定限制 8 個月後即可自由轉讓？」 | **違法**，限制須永久 |
| 「章程只限制普通股、不限制特別股？」 | **不可**，全體股東都要限制 |
| 「對不同股東訂不同限制？」 | **可以** |
| 「3 年內不得轉讓、3 年後經董事會同意得轉讓？」 | **可以** |
| 「股份為遺產時，章程規定指定股東承購？」 | **可以**（112 台上 1512） |
| 「如何得知公司是閉鎖性？」 | 章程載明＋主管機關資訊網站公開；**不在名稱** |

## 一、限制內容判斷

```
章程的轉讓限制
├── 全體股東、全部股份都受限？
│     ├── 否（有人不受限）→ ✘ 違法
│     └── 是 → 各人寬嚴不同可以
└── 限制是永久的？
      ├── 期滿即自由轉讓 → ✘ 違法
      └── 期滿改成另一種限制（如董事會同意）→ ✔
```
