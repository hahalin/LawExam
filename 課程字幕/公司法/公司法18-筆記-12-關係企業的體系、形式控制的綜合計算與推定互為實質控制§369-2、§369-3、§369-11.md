# 公司法18 筆記：關係企業的體系、形式控制的綜合計算與推定互為實質控制（§369-2、§369-3、§369-11）

## 第 14 章 12 個條文分五塊（電腦圖 14-1）：
- ① **定義**：§369-1
- ② **通知義務**：§369-8（持股超過 1/3、1/2 等的通知）
- ③ **控制從屬公司**（重點）：
  - 定義：形式 §369-2 I＋§369-11（持股計算採**實質認定**）；實質 §369-2 II＋§369-3（推定互為控制）
  - 相關規範：§369-4 ~ §369-6（老師電腦圖標為揭開公司面紗）、§369-7 I 控制公司對從屬公司的債權**不得主張抵銷**、§369-7 II **深石原則**、§369-12 關係報告書（限**公開發行**公司）
- ④ **相互投資公司**：定義 §369-9 I、效力 §369-10（見公司法10-筆記-06）
- ⑤ **互為控制從屬**：§369-9 II；形式互為控從另有 §179 II ② 無表決權（不太常考）

## 關係企業的定義（§369-1；講義 14-3）：
- 法律上**人格獨立**，但**經濟上**有控制或投資關聯的公司；要處理的是**控制權**的問題
- 條文說「企業」，實際上指**公司**，原則上不包括自然人
- 兩款：① 有控制與從屬關係的公司 ② 相互投資的公司

## 形式控制從屬（§369-2 I）：
- 持有他公司**有表決權**股份或出資額，**超過半數** → 控制公司；他公司為從屬公司
- 從外觀數字就判斷得出來，所以叫「形式」
- 股份有限公司看**有表決權股份**；有限、兩合公司看**出資額**
- **無限公司不可能是從屬公司**：公司不得為無限責任股東（§13 I），根本不可能成為無限公司的股東

## 持股計算：實質認定法（綜合計算法，§369-11）：
- 重點在**持股目的**與**為誰取得**，不單純看形式（講義 14-4）
- 連同計入：① 公司的**從屬公司**持有的 ② **第三人為該公司**持有的 ③ **第三人為該公司之從屬公司**持有的
- 「為他人持有」怎麼證明是訴訟上舉證的問題（民事訴訟法），公司法只管：認定是 → 就要加進去

## 實質控制從屬（§369-2 II、§369-3）：
- 除前項外（先看形式，不符合再看實質），**直接或間接控制他公司的人事、財務或業務經營** → 控制公司
- 人事、財務、業務**三個只要有一個**就成立
- 直接認定實質控制力很困難 → §369-3 設兩款**推定**：① 執行業務股東或董事有**半數以上相同** ② 有表決權股份或資本總額有**半數以上為相同股東持有或出資**
- 推定的效果是**互為**實質控制從屬（講義 14-4 倒數第 5 行）：可主張甲控制乙，也可反過來主張乙控制甲（電腦圖 14-3）

## 📖 法條原文速查

> **§369-1**　本法所稱關係企業，指獨立存在而相互間具有下列關係之企業：一、有控制與從屬關係之公司。二、相互投資之公司。

> **§369-2**
> I　公司持有他公司**有表決權**之股份或出資額，**超過**他公司已發行有表決權之股份總數或資本總額**半數**者為控制公司，該他公司為從屬公司。
> II　除前項外，公司直接或間接控制他公司之**人事、財務或業務經營**者亦為控制公司，該他公司為從屬公司。

> **§369-3**　有下列情形之一者，**推定**為有控制與從屬關係：一、公司與他公司之執行業務股東或董事有**半數以上相同**者。二、公司與他公司之已發行有表決權之股份總數或資本總額有**半數以上為相同之股東持有或出資**者。

> **§369-11**　計算本章公司所持有他公司之股份或出資額，應連同下列各款之股份或出資額一併計入：一、公司之**從屬公司**所持有他公司之股份或出資額。二、**第三人為該公司**而持有之股份或出資額。三、**第三人為該公司之從屬公司**而持有之股份或出資額。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「關係企業包括自然人？」 | 原則**不包括**，指公司 |
| 「形式控制的標準？」 | 持有**有表決權**股份或出資額**超過半數** |
| 「無限公司得否為從屬公司？」 | **不可能**（§13 I） |
| 「§369-11 的計算方式？」 | **實質認定法**（綜合計算法），三款一併計入 |
| 「實質控制須人事、財務、業務都控制？」 | **不必**，**一項**即可 |
| 「符合 §369-3 的效果？」 | **推定互為**實質控制從屬 |
| 「關係報告書的義務適用於哪些公司？」 | **公開發行**公司（§369-12） |

## 一、§369-11 數字例（電腦圖 14-2）

```
A ──53%──→ B（A 為形式控制公司，B 為形式從屬公司）

對 C 公司的持股：
  A 自己持有                  13%
  B（A 的從屬公司）持有        17%  ← 第 1 款
  甲（為 A 持有）              14%  ← 第 2 款
  乙（為 B 持有）              16%  ← 第 3 款
  ─────────────────────────────
  合併計算 A 持有 C            60% ＞ 50% → C 為 A 的形式從屬公司
```

## 二、推定互為實質控制（電腦圖 14-3）

```
甲公司、乙公司符合 §369-3 第 1 款或第 2 款
        ↓ 推定互為實質控制從屬
主張一：甲＝控制公司，乙＝從屬公司
主張二：乙＝控制公司，甲＝從屬公司   （兩種都可以主張）
```
