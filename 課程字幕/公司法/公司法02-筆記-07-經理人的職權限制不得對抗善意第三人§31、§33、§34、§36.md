# 公司法02 筆記：經理人的職權限制不得對抗善意第三人（§31、§33、§34、§36）

## 經理人有民法上的固有職權：
- 通說：**公司法上經理人＝民法上經理人** → 有民法經理人的**固有職權**（民法 §553 I），可代表公司簽名
- 公司完全沒有限制時，回歸民法
- 老師評估：二試約 20 年以上沒出，選擇題仍要有基本概念

## 可以用章程或契約限制：
- §31：經理人職權除章程規定外，並得依**契約**訂定；在**章程或契約授權範圍內**有為公司管理事務及簽名之權
- 例：公司以契約限制經理人只能簽 **20 萬元以下**的契約 → 可以
- 講義：可以限制，但**不能完全剝奪**（考試不太考）

## 限制不得對抗善意第三人（§36）：
- 公司加在經理人職權上的限制（即 §31 的章程、契約限制），**不得對抗善意第三人**
- 相對人**不知道**有限制 → 契約對公司有效
- 相對人**明知**有限制 → 對公司不生效力

## 經理人的義務與責任：
- **§23 I**：經理人是 §8 II 的職務負責人，負忠實義務、善良管理人注意義務（見 公司法02-筆記-03、09）
- **§33**：不得變更董事、執行業務股東的決定，或股東會、董事會的決議，也不得逾越權限 → 可看出經理人是**輔助業務執行機關**
- **§34**：違反法令、章程或 §33 致公司受損害 → 對**公司**負賠償責任
- §33、§34 是標準選擇題

## 📖 法條原文速查

> **§31**（經理人之職權）
> I　經理人之職權，除**章程**規定外，並得依**契約**之訂定。
> II　經理人在公司章程或契約規定**授權範圍內**，有為公司**管理事務及簽名**之權。

> **§33**（經理人之服從義務）
> 經理人**不得變更**董事或執行業務股東之決定，或股東會或董事會之決議，或**逾越**其規定之權限。

> **§34**（經理人之賠償責任）
> 經理人因違反法令、章程或前條之規定，致公司受損害時，**對於公司**負賠償之責。

> **§36**（經理權限制之效力）
> 公司**不得以**其所加於經理人職權之限制，**對抗善意第三人**。

> **民法 §553 I**（經理人之定義）
> 稱經理人者，謂經商號之授權，為其**管理事務及簽名**之人。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司法上經理人與民法上經理人的關係？」 | 通說：**相同**，有民法上固有職權 |
| 「公司可否以契約限制經理人職權？」 | **可以**，章程或契約均可（§31） |
| 「經理人逾越限制與不知情之第三人簽約，效力？」 | 公司**不得對抗善意第三人** → 對公司有效（§36） |
| 「第三人明知限制？」 | 對公司**不生效力** |
| 「經理人可否變更董事會決議？」 | **不可**（§33） |
| 「經理人違反章程致公司受損，對誰負責？」 | 對**公司**負賠償責任（§34） |

## 一、職權與限制的流程（電腦圖 2-1）

```
經理人阿貓（胖虎公司董事會普決選任）
   │ 公司法經理人＝民法經理人 → 固有職權（民法 §553 I）
   ▼
公司以章程或契約限制（§31）
   例：不得簽訂購買汽車的契約／只能簽 20 萬元以下
   ▼
阿貓仍代表公司簽了購車契約
   ├── 相對人善意（不知限制）→ §36 不得對抗 → 有效
   └── 相對人明知限制 ────────────→ 對公司不生效力
```

## 二、§31 與 §36 的連動

| 條文 | 角色 |
|---|---|
| §31 | 公司**可以**用章程、契約限制經理人職權 |
| §36 | 這個限制**不能拿來對抗**善意第三人 |

- 記法：§36 說的「職權之限制」就是 §31 的章程、契約限制，兩條要寫在一起。

## 三、經理人義務一覽

| 義務 | 條文 | 違反效果 |
|---|---|---|
| 忠實義務、善管注意義務 | §23 I（經理人為 §8 II 負責人） | 損害賠償 |
| 遵守法令、章程、決議；不逾越權限 | §33 | §34 對公司賠償 |
| 兼任禁止、競業禁止 | §32 | 見 公司法02-筆記-08 |
