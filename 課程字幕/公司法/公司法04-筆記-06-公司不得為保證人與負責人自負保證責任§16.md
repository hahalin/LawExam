# 公司法04 筆記：公司不得為保證人與負責人自負保證責任（§16）

## 原則：不得為任何保證人：
- 法條文義指**人保**
- 立法理由：穩定公司財務，避免任意保證

## 兩個例外：
- **其他法律**規定得為保證（例：銀行法），不會考
- **公司章程**規定得為保證 → 章程通常**概括排除**（「本公司得對外保證」）

## 違反效果：負責人自負保證責任：
- 保證契約**不是無效**，而是改由**公司負責人自負保證責任**
- 公司受有損害，負責人另負**賠償責任**
- 銀行因此很在意公司有無違反 §16：保證人會換成負責人個人

## 「保證」的範圍（實務見解，全部要背）：
- **民法上的保證**：算
- **票據上的保證**：算
- **票據背書**：**不算**（背書不是保證；學者有批評，考試以最高法院見解作答）
- 以不動產**為他人債務設定抵押權**（物保）：**仍在禁止之列**
- **債務承擔**：引用保證法理，**也違反 §16**（最高法院 92 年台上字第 914 號）

## 物保的界線：
- 公司以自己的廠房土地為**自己的借款**設定抵押 → 當然合法
- 公司以自己的財產為**別人的債務**設定擔保 → 違反 §16

## 📖 法條原文速查

> **§16**（保證之限制）
> I　公司除依其他法律或**公司章程**規定得為保證者外，**不得為任何保證人**。
> II　公司負責人違反前項規定時，應**自負保證責任**，如公司受有損害時，亦應負**賠償責任**。

---

## 📋 實務見解速查

> **最高法院 92 年台上字第 914 號**：公司為他人**承擔債務**，引用保證法理，亦違反 §16。→ 字號依字幕，原文建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司違反 §16 為他人保證，保證契約效力？」 | 由**公司負責人自負保證責任** |
| 「公司章程得否概括規定公司得為保證？」 | **可以**，章程為例外 |
| 「公司為票據保證，是否違反 §16？」 | **違反**（票據保證也算） |
| 「公司為票據背書，是否違反 §16？」 | **不違反**（背書不是保證） |
| 「公司以不動產為他人債務設定抵押權？」 | **違反**（物保仍在禁止之列） |
| 「公司為他人承擔債務？」 | **違反**（最高法院 92 台上 914） |
| 「公司以自有不動產為自己借款設定抵押？」 | **合法** |

## 一、黑板例：保證契約移到誰身上

```
小富公司（債務人）向丙銀行借款
   ↓ 銀行要求保證人
大方公司同意擔任保證人
   但大方公司章程沒有「得為保證」的規定
   ↓
違反 §16 I
   ↓
§16 II：大方公司負責人張三自負保證責任
   → 保證關係存在於「丙銀行與張三」之間
   → 大方公司若受損害，張三另負賠償責任
```

- 字幕 01:15 ~ 01:18 約 2 分鐘缺漏，板書例中「張三」的身分未錄到；依 §16 II 推定為大方公司的負責人

## 二、保證範圍一覽

| 行為 | 是否違反 §16 | 依據 |
|---|---|---|
| 民法保證 | 違反 | 法條文義（人保） |
| 票據保證 | 違反 | 實務 |
| 票據背書 | **不違反** | 最高法院：背書不是保證 |
| 為他人債務提供不動產抵押 | 違反 | 實務：物保亦禁止 |
| 為自己債務提供不動產抵押 | 合法 | 自己的債務 |
| 債務承擔 | 違反 | 最高法院 92 台上 914 |

- 老師：保證都不行了，直接把別人的債務扛過來，當然更不行。
- 字幕「劉玉玉老師」也批評背書不算的見解，推定為**劉連煜**老師，建議查證。

## 三、§13、§15、§16 的違反效力對照

| 條文 | 違反效力（考試答案） |
|---|---|
| §13 I 無限責任股東 | 無效 |
| §13 II 轉投資超過 40% | 有效（學者多數） |
| §15 資金貸與 | 有效（實務）／無效（學者多數）；借用人與負責人連帶返還 |
| §16 保證 | 負責人自負保證責任 |
