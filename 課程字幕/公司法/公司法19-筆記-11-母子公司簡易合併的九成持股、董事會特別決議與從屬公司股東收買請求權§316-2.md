# 公司法19 筆記：母子公司簡易合併的九成持股、董事會特別決議與從屬公司股東收買請求權（§316-2）

## 要件（§316-2 I；企併法 §19 類似）：
- 控制公司持有從屬公司已發行股份 **90% 以上**（「以上」含本數，選擇題會考）
- 控制公司及從屬公司的**董事會**都以**特別決議**（2/3 以上出席、出席過半數同意）通過
- 合併決議**不適用 §316 I ~ III** 股東會決議 → 兩邊都不必開股東會
- 選擇題、申論題都喜歡考，申論機會較低

## 只能從屬公司併入控制公司（講義 15-12、15-13 國字四）：
- 條文只寫「與其從屬公司合併」，但學者與經濟部**一致**：限於**從屬公司被吸收合併進入控制公司**
- 控制公司併入從屬公司 → 回到一般程序：董事會決議＋**股東會特別決議**

## 為什麼兩邊只要董事會特別決議（電腦圖 15-1）：
- **控制公司**：股東權益早已透過高度持股間接及於從屬公司，合併只是把間接關係轉為直接 → **影響甚小**（從屬公司賺 100 元，控制公司本來就能分到 90 元，合併後變 100 元）
- **從屬公司**：控制公司持股九成，即使其他股東反對也擋不住 → 開股東會**並無實益**

## 股份收買請求權：只有從屬公司股東有：
- 從屬公司董事會決議後，應即通知股東，指定 **30 日以上**期限，股東得書面異議、請求**從屬公司**按當時公平價格收買（§316-2 II）
- 控制公司股東**沒有**：§317 收買請求權的規定於控制公司不適用（§316-2 後段項次建議查證）
- 理由：從屬公司股東**沒有置喙餘地**又**影響甚大** → 給退場機會；控制公司股東影響甚小 → 不給
- 其餘資產負債表、債權人保護、章程修改、合併登記與一般程序相同，不是重點

> 來源：公司法19 課程字幕 02:33:41 ~ 02:46:45（講義 15-12 ~ 15-13、15-17；電腦圖 15-1）

## 📖 法條原文速查

> **§316-2**
> I　控制公司持有從屬公司**百分之九十以上**已發行股份者，得經控制公司及從屬公司之**董事會**以董事三分之二以上出席，及出席董事過半數之決議，與其從屬公司合併。其合併之決議，**不適用第三百十六條第一項至第三項**有關股東會決議之規定。
> II　**從屬公司**董事會為前項決議後，應即通知其股東，並指定**三十日以上**期限，聲明其股東得於期限內提出書面異議，請求從屬公司按當時公平價格，收買其持有之股份。
> （第三項以下：價格協議、請求失效、§317 於**控制公司不適用**、控制公司修章仍依 §277 等）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「簡易合併的持股門檻？」 | 從屬公司已發行股份 **90% 以上**（含 90%） |
| 「簡易合併由誰決議？」 | 控制公司**及**從屬公司的**董事會特別決議** |
| 「控制公司得否以簡易合併併入從屬公司？」 | **不得**，限**從屬併入控制** |
| 「哪一方股東有股份收買請求權？」 | **只有從屬公司**股東 |
| 「控制公司為何不必經股東會？」 | 股東權益已間接及於從屬公司，**影響甚小** |
| 「從屬公司為何不必經股東會？」 | 控制公司持股九成，開會**並無實益** |

## 一、電腦圖 15-1：A 持有 B 92%，B 併入 A

| | A 公司（控制、存續） | B 公司（從屬、消滅） |
|---|---|---|
| 決議 | 董事會特別決議 | 董事會特別決議 |
| 不開股東會的理由 | 對股東權益**影響甚小** | 召開股東會**並無意義** |
| 股東收買請求權 | **無** | **有** |
| 理由 | 影響甚低 | 影響甚大、無從阻止 |

## 二、與一般合併的比較

| | 一般合併 | 簡易合併 |
|---|---|---|
| 持股 | 不限 | 90% 以上 |
| 方向 | 不限 | 從屬併入控制 |
| 決議 | 董事會＋股東會特別決議 | 雙方董事會特別決議 |
| 收買請求權 | 雙方異議股東（§317） | 只有從屬公司股東（§316-2 II） |
