# 公司法02 筆記：當然負責人與職務負責人（§8、§23）

## 公司要靠負責人行為：
- 公司是法人，沒有行為實體，必須設置機關；這些機關的擔任者就是各種**公司負責人**
- 分兩類：**當然負責人**（一有資格就是負責人，§8 I）、**職務負責人**（只在執行職務範圍內才是，§8 II）

## 當然負責人（§8 I）：
- **無限公司、兩合公司**：執行業務或代表公司的股東（執行業務 §45、§46；代表公司 §56，見 公司法01-筆記-08）
- **有限公司、股份有限公司**：**董事** → 重要
- 董事＝負責人是**等號**：只要是董事，任何時候都是負責人，不可能是董事卻不是負責人

## 職務負責人（§8 II）：
- 四種公司都有：**經理人、清算人、臨時管理人** → 口訣「**經清臨**」
- 股份有限公司才有：**發起人、監察人、檢查人、重整人、重整監督人** → 口訣「**發監檢重重**」
- 必須在**執行職務範圍內**才是負責人
- 選擇題非常喜歡考這條

## §8 是定義規定，接到 §23：
- 公司法其他條文出現「**公司負責人**」五個字，就回到 §8 找是誰
- 例：§23 I「公司負責人應忠實執行業務並盡善良管理人之注意義務」→ 把「公司負責人」替換成 §8 I 的董事，董事就是 §23 的義務主體

## 📖 法條原文速查

> **§8**（公司負責人）
> I　本法所稱公司負責人：在無限公司、兩合公司為**執行業務或代表公司之股東**；在有限公司、股份有限公司為**董事**。
> II　公司之**經理人、清算人或臨時管理人**，股份有限公司之**發起人、監察人、檢查人、重整人或重整監督人**，在**執行職務範圍內**，亦為公司負責人。

> **§23 I**（忠實義務與注意義務）
> **公司負責人**應忠實執行業務並盡善良管理人之注意義務，如有違反致公司受有損害者，負損害賠償責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有限公司、股份有限公司之當然負責人？」 | **董事** |
| 「無限公司、兩合公司之當然負責人？」 | **執行業務或代表公司之股東** |
| 「經理人是否任何時候都是公司負責人？」 | **否**，只在**執行職務範圍內**（§8 II） |
| 「監察人、檢查人是哪種公司的負責人？」 | **股份有限公司**的職務負責人 |
| 「下列何者非有限公司之負責人？」 | 發起人、監察人、檢查人、重整人、重整監督人（只屬股份有限公司） |
| 「§23 的公司負責人包括董事嗎？」 | **包括**，§8 I 董事即當然負責人 |

## 一、體系圖

```
公司負責人（§8）
│
├── 當然負責人（§8 I）─ 有資格就是，無時不是
│     ├── 無限、兩合：執行業務或代表公司之股東
│     └── 有限、股份有限：董事
│
└── 職務負責人（§8 II）─ 執行職務範圍內才是
      ├── 四種公司都有：經理人、清算人、臨時管理人（經清臨）
      └── 股份有限公司才有：發起人、監察人、檢查人、重整人、重整監督人（發監檢重重）
                              └ 重整之後會學到：限公開發行公司
```

## 二、「執行職務範圍內」怎麼理解

| 情境 | 誰是負責人 |
|---|---|
| 人事經理處理人事業務 | 人事經理（經理人在職務範圍內） |
| 公司的監察事項出問題 | 監察人；經理人**不會**出來負責 |
| 任何事項 | **董事**永遠是（§8 I） |

## 三、老師補充（考試不考）

- 老師認為「臨時管理人」實際上只有**有限公司與股份有限公司**才有，條文把它和經理人、清算人並列為「四種公司都有」，是條文先天的問題；修法研討會曾提出，未被採納。考試照條文記「經清臨」即可。

> 字幕校正：字幕「金清零」「發監減刑」是口訣的語音辨識，應為「經清臨」「發監檢重重」。
