# 公司法05 筆記：變更組織（§76、§76-1、§106、§126）

## 定義與功能：
- 不影響**法人格**，將公司變更為**他種類**的公司組織（例：有限公司變更為股份有限公司）
- 功能一：**不經解散程序**，直接變更組織
- 功能二：因故欠缺原組織要件、但具備他種公司要件時，以他種組織繼續存在，**維持企業**
- 特色：**人格保持同一性**

## 2018 年修法前就有的（兩組）：
- **無限 ⇄ 兩合**，雙向，須**全體**股東同意
  - 無限 → 兩合：全體同意，以一部股東改為有限責任或另加入有限責任股東（§76 I）
  - 兩合 → 無限：有限責任股東全體退股、無限責任股東 2 人以上，一致同意（§126 II）；或全體同意（§126 III）
- **有限 → 股份有限**，**單向**，股東表決權**過半數**同意（§106 III）

## 2018 年新增：
- **無限、兩合 → 有限或股份有限**，**單向**，股東 **2/3 以上**同意變更章程（§76-1 I、§126 IV）
- 為什麼門檻反而比無限、兩合互換低：鼓勵它們轉出去；全臺無限、兩合公司合計只剩十家左右，修法時本想刪除這兩種公司，最後保留但開門讓它們轉型

## 股份有限公司不能變更組織：
- 理由：股份有限公司被認為是**最完善的組織型態**，所以所有變更都只進不出
- 有限 → 股份有限是單向，原因也在此

## 📖 法條原文速查

> **§76 I**（無限 → 兩合）
> 公司得經**全體股東之同意**，以一部股東改為有限責任或另加入有限責任股東，變更其組織為**兩合公司**。

> **§76-1 I**（無限 → 有限、股份有限）
> 公司得經股東**三分之二以上**之同意變更章程，將其組織變更為**有限公司或股份有限公司**。

> **§106 III**（有限 → 股份有限）
> 公司得經股東表決權**過半數**之同意減資或變更其組織為**股份有限公司**。

> **§126**（兩合公司之變更組織）
> II　前項有限責任股東全體退股時，無限責任股東在二人以上者，得以**一致之同意**變更其組織為**無限公司**。
> III　無限責任股東與有限責任股東，以**全體之同意**，變更其組織為**無限公司**。
> IV　公司得經股東**三分之二以上**之同意變更章程，將其組織變更為**有限公司或股份有限公司**。
> → 建議查閱最新六法原文（字幕在 §126 II 唸成「變更為有限」，依條文校正為變更為**無限公司**）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「變更組織的特色？」 | 不經解散、**法人格同一性**維持 |
| 「無限公司變更為兩合公司的門檻？」 | **全體**股東同意（§76 I） |
| 「有限公司變更為股份有限公司的門檻？」 | 股東表決權**過半數**（§106 III） |
| 「無限、兩合變更為有限或股份有限的門檻？」 | 股東 **2/3** 以上同意（§76-1、§126 IV，2018 新增） |
| 「股份有限公司得否變更為有限公司？」 | **不得**；股份有限公司不能變更組織 |
| 「有限公司得否變更為無限公司？」 | **不得**；有限只能單向變更為股份有限 |

## 一、電腦圖 2-19：變更組織地圖

```
修法前
  無限 ⇄ 兩合 ─────────── 全體同意（§76 I、§126 II III）
  有限 ──→ 股份有限 ───── 過半數（§106 III），單向

2018 新增
  無限 ──→ 有限／股份有限 ── 2/3（§76-1 I），單向
  兩合 ──→ 有限／股份有限 ── 2/3（§126 IV），單向

股份有限 ──→ ✕（不得變更組織：最佳型態）
```

## 二、門檻對照

| 變更方向 | 門檻 | 條文 | 方向 |
|---|---|---|---|
| 無限 → 兩合 | 全體 | §76 I | 雙向之一 |
| 兩合 → 無限 | 全體／一致 | §126 II、III | 雙向之一 |
| 有限 → 股份有限 | 過半數 | §106 III | 單向 |
| 無限 → 有限、股份有限 | 2/3 | §76-1 I | 單向 |
| 兩合 → 有限、股份有限 | 2/3 | §126 IV | 單向 |

- 背法：負無限責任的兩種公司互換，門檻最高（全體）；轉出去變成有限責任的，門檻降到 2/3。
