# 公司法09 筆記：政府或法人股東的代表人與分別行使表決權（§181）

## 代表人不限一人，但只能做一個意思表示（§181 I、II）：
- 政府或法人為股東時，**代表人不限於一人**（I 前段）
- 但表決權的行使仍以所持有的股份**綜合計算**（I 後段）
- 代表人有二人以上時，應**共同為之**（II）→ 立法者怕你看不懂，又寫一次
- 綜合計算、共同為之，結論都是：只能做**單一（同一）意思表示**——全部贊成或全部反對
- 老師：技術性條文，考點偏選擇題

## 為他人持有股份的困境：
- 例（電腦圖 5-13，比例放大）：乙銀行是甲公司的法人股東，持股 35%，背後是替丙（10%）、丁（15%）、戊（10%）等出資者持有
- 丙、丁贊成，戊反對 → 乙銀行只能做一個意思表示，怎麼投都有人不滿
- 若沒有特別規定，現實上只能選擇**不出席或棄權**，進退失據

## 公開發行公司得分別行使（§181 III、IV）：
- **公開發行公司**的股東係**為他人持有股份**時，得主張**分別行使**表決權
- 兩個要件都要有：**公開發行公司**＋**為他人持有**（講義 5-58，學者特別提醒）
- 資格條件、適用範圍、行使方式等由證券主管機關定之（IV）
- 現行主管機關開放的範圍很窄（講義註 168），大致限於三類：
  1. 華僑或外國人投資國內證券的**基金**
  2. 投資國內證券的**國外金融機構**
  3. **海外存託憑證**
- 學者主張應**全面開放**

## 法人股東的代表人能否復委任（講義 5-57，很久沒考）：
- 情境（電腦圖 5-14）：丙公司是乙公司的法人股東，原委託甲出席；開會當天甲出車禍，無法出席
- 最高法院 **91 台上 2496**：有**民法 §537** 的適用 → 甲得**直接委託他人**（復委任）
- 王文宇老師：不行
- 記最高法院見解即可；實務上打電話請法人股東改派就解決了

## 📖 法條原文速查

> **§181**（政府或法人股東之表決權）
> I 政府或法人為股東時，其**代表人不限於一人**。但其表決權之行使，仍以其所持有之股份**綜合計算**。
> II 前項之代表人有二人以上時，其代表人行使表決權應**共同為之**。
> III **公開發行公司**之股東係**為他人持有股份**時，股東得主張**分別行使**表決權。
> IV 前項分別行使表決權之資格條件、適用範圍、行使方式、作業程序及其他應遵行事項之辦法，由證券主管機關定之。

> **民法 §537**（自己處理事務）　受任人應**自己處理**委任事務。但經委任人之同意或另有習慣或有**不得已之事由**者，得使第三人代為處理。

---

## 📋 實務見解速查

> **91 台上 2496**：法人股東之代表人出席股東會，有民法 §537 之適用，得**復委任**他人出席（講義 5-57）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人股東的代表人以一人為限？」 | ✕，**不限於一人** |
| 「法人股東指派三名代表人，得各自依意見投票？」 | ✕，**綜合計算**、**共同為之**，單一意思表示 |
| 「非公開發行公司的股東為他人持有股份，得分別行使表決權？」 | ✕，限**公開發行公司** |
| 「§181 III 分別行使的要件？」 | 公開發行公司＋**為他人持有** |
| 「法人股東代表人臨時不能出席，得復委任？」 | **可以**（91 台上 2496，民法 §537） |

## 一、§181 的結構

```
政府或法人股東
├── I 前段：代表人不限一人
├── I 後段＋II：綜合計算、共同為之 → 單一意思表示
└── III、IV：公開發行公司＋為他人持有 → 得分別行使
              └── 範圍：基金、國外金融機構、海外存託憑證（註 168）
```

## 二、為他人持有的情境（電腦圖 5-13）

| 背後出資者 | 比例 | 意見 |
|---|---|---|
| 丙 | 10% | 贊成 |
| 丁 | 15% | 贊成 |
| 戊 | 10% | 反對 |
| 乙銀行合計 | 35% | 無 III：只能全贊成或全反對（或不出席、棄權）；有 III：25% 贊成、10% 反對 |

## 三、與自然人共有股份對照

| | 共有股份（§160） | 法人股東（§181） |
|---|---|---|
| 行使人數 | 推定**一人** | 代表人**不限一人** |
| 意思表示 | 同一、不可分割 | 單一、共同為之 |
| 例外 | 無 | 公發公司為他人持有得分別行使 |
