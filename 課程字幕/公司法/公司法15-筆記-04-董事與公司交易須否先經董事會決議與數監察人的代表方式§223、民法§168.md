# 公司法15 筆記：董事與公司交易須否先經董事會決議與數監察人的代表方式（§223、民法§168）

## 爭點在哪裡：
- 代表機關沒有爭議：法條明定由**監察人**代表
- 爭的是：監察人代表之前，要不要**先經董事會決議**
- 這個問題只發生在**非公開發行公司**，或公開發行但**沒有設獨立董事、審計委員會**的公司

## 公開發行公司設獨立董事或審計委員會：法有明文，無爭議：
- 董事與公司交易，董事必然有權利義務變動 → 必然屬於**董事自身利害關係**事項
- 證交法 §14-3：設獨立董事者，應提**董事會**決議
- 證交法 §14-5 I：設審計委員會者，**先審計委員會、後董事會**
- 這是證交法的考點，不會在公司法考

## 非公開發行公司：兩派長期各說各話：

### 最高法院 100 年度第 3 次民事庭會議、經濟部：不需要
- 直接由監察人**決定並代表**；決定與代表是同一個監察人動作，不是兩次
- 理由：避免利益衝突——§223 整條都在避免利益衝突，先丟給董事會反而讓利衝回來（講義 7-11）
- 講義另列一說：不需經董事會，由**監察人全體**決定（講義 7-11）

### 學者多數：先董事會提案、後監察人決定
- 性質類似**提出權與決定權**：董事會提案，監察人自己決定要不要做
- 董事會的提案**不拘束**監察人（像行政院提案、立法院決定要不要通過）
- 未經董事會決議 → **類推適用無權代理**，對公司不當然發生效力
- 理由：
  - **§202 分權模式**：業務執行原則由董事會決定，只要監察人決定就違反這個分權
  - 先經**內部評估**，避免監察人職權脫逸董事會、監察人的制衡制度（講義 7-12）
  - **監察人也可能有利益衝突**（講義引邵慶平，其他學者贊同）
  - 參考**證交法**：設獨董、審委會時本來就是先董事會
- 前提限縮（講義 7-10）：須是**業務之執行**（才有 §202），且**非股東會決議事項**（例：§185 重大行為本來就會先經董事會召集股東會）

## 老師舉例：只交給監察人未必安全：
- 董事 X 與監察人 Y 私交很好；公司剛買一輛全新跑車
- X：「我手頭緊，7 萬元賣給我吧。」Y：「老朋友，沒問題。」
- 7 萬元買全新跑車 → 利益衝突明顯；監察人可能與董事勾結

## 監察人有數人時，要共同代表還是單獨代表：
- **100 台上 1026**：代表公司不是「監察權」→ 不適用 §221 單獨行使 → 依**民法 §168**，數代理人應**共同**為之
- **經濟部、學者**：依 §221 **單獨代表**即可
- 劉連煜（講義註 25）的解讀：
  - 這是從「決策機關」的爭議延伸到「代表機關」
  - 最高法院先說只要監察人決定，又發現監察人可能有利衝或事先套好；不便直接改 100 年第 3 次民事庭會議，就用「全體共同」來降低危害
  - 但比較好的彌補是改掉前面的見解；硬說代表權不是監察權也說不通——可以說監察權是上位概念、代表權是下位概念

## 📖 法條原文速查

> **§223**　董事為自己或他人與公司為買賣、借貸或其他法律行為時，由**監察人**為公司之代表。

> **§202**　公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由**董事會**決議行之。

> **§221**　監察人各得**單獨行使**監察權。

> **民法 §168**　代理人有數人者，其代理行為應**共同**為之。但法律另有規定或本人另有意思表示者，不在此限。

> **證交法 §14-3、§14-5 I**　涉及董事自身利害關係之事項，應提董事會決議（設審計委員會者，應經審計委員會全體成員二分之一以上同意，並提董事會決議）。→ 款次與原文建議查閱最新六法原文

## 📋 實務見解速查

> **最高法院 100 年度第 3 次民事庭會議**：董事與公司為法律行為，由監察人代表公司，**無須先經董事會決議**。→ 依課堂講述整理，原文建議查證

> **100 台上 1026**：監察人有數人時，代表公司與董事為法律行為非屬監察權之行使，應依民法 §168 **共同代表**。→ 依課堂講述整理，原文建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「設審計委員會的公開發行公司，董事與公司交易的程序？」 | **先審計委員會、後董事會**，再由代表機關代表（證交法 §14-5） |
| 「非公開發行公司，§223 交易須否先經董事會？實務？」 | **不需要**（100 年第 3 次民事庭會議、經濟部） |
| 「同上，學者多數？」 | **先董事會提案、後監察人決定**；提案不拘束監察人 |
| 「學說下未經董事會決議的效力？」 | **類推無權代理**，不當然對公司生效 |
| 「數監察人代表公司，最高法院？」 | **共同代表**（民法 §168；100 台上 1026） |
| 「同上，經濟部與學者？」 | 依 §221 **單獨代表** |

## 一、黑板體系

```
董事與公司為法律行為（§223）
│
├── 公開發行＋設獨董／審委會（法有明文，證交法考）
│     └── （審委會）→ 董事會 → 代表機關代表
│
└── 非公開發行（或未設獨董、審委會）
      ├── 實務、經濟部：監察人決定＝監察人代表（一次）
      └── 學者多數：董事會提案 → 監察人決定並代表
                    （提案不拘束監察人）
```

| 須否先經董事會 | 不需要 | 不需要 | 多數：需要（提案） |
| 數監察人如何代表 | 共同（民法 §168） | 單獨（§221） | 單獨（§221） |
