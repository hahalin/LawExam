# 公司法04 筆記：舉債不受限制與資金貸與的原則禁止及例外（§14、§15）

## §14 已刪除：舉債不受限制：
- 公司向銀行或他人**私人借貸**（民法消費借貸）不再受限制
- 發行**公司債**仍有公司法的限制，兩者不要混淆

## §15 原則：不得貸與股東或任何他人：
- 公司資金**不得貸與股東或任何他人**；股東被特別點名，也不能借
- 立法目的：**維持資本充實**、**避免變相退股**
- 例：三人各出資 300 萬元成立公司（共 900 萬），其中一人向公司借 500 萬元 → 不但沒出資，還倒拿 200 萬元
- 公司不是銀行或地下錢莊；**自然人原則上不能向公司借錢**

## 例外一：公司間或與行號間有業務往來：
- 「業務往來」認定**寬鬆**：只要**有過交易**即可（例：乙公司的商品在丙便利商店上架）
- 法條沒寫上限 → 經濟部 95 年 5 月 16 日函：**不受淨值 40% 限制**，即**無上限**

## 例外二：公司間或與行號間有短期融通資金之必要：
- 隱含要件：**沒有業務往來**（有業務往來直接用第一款）
- 融資金額**不得超過貸與企業淨值 40%**
- 淨值＝資產總額 − 負債；上限**累計計算**
- 短期：一年或一個營業週期（國考不考）

## 兩個例外的對象：
- 只能借給**公司或行號**；行號＝**獨資或合夥**經營的事業（商業登記法）
- 例外也不能借給自然人

## 經濟部的兩個函釋（選擇題愛考）：
- **預借薪資**、約定從薪資及獎金扣還 → **非屬貸款**，不適用 §15（經濟部 68 年函）
- 可以貸與**有業務往來的法人股東**（公司組織）：股東原則上不能借，但符合例外即可 → **例外破原則**，經濟部認為合法

## 📖 法條原文速查

> **§15 I**（資金貸與之限制）
> 公司之資金，除有下列各款情形外，**不得貸與股東或任何他人**：
> 一、公司間或與行號間有**業務往來**者。
> 二、公司間或與行號間有**短期融通資金之必要**者。融資金額**不得超過貸與企業淨值的百分之四十**。

> **§14**：已刪除。

> **商業登記法 §3**：本法所稱商業，指以營利為目的，以**獨資或合夥**方式經營之事業。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司得否將資金貸與股東？」 | 原則**不得**（§15 I） |
| 「公司間有業務往來，貸與金額有無上限？」 | **無上限**（經濟部 95.5.16 函） |
| 「公司間有短期融通資金必要，貸與上限？」 | 貸與企業**淨值 40%**，累計計算 |
| 「§15 的 40% 與 §13 的 40% 基準是否相同？」 | **不同**：§15 是**淨值**；§13 是**實收股本** |
| 「公司得否貸款給自然人？」 | **不得**；例外對象限**公司或行號** |
| 「員工預借薪資、從薪資扣還，是否違反 §15？」 | **不違反**，非屬貸款 |
| 「公司得否貸與有業務往來之法人股東？」 | **可以**（經濟部：合法） |
| 「§15 的立法目的？」 | 維持**資本充實**、避免**變相退股** |

## 一、體系（電腦圖 2-10）

```
§15 公司資金貸與
原則：不得貸與股東或任何他人
例外：對象限「公司或行號」
├── 有業務往來（第 1 款） → 可以，無上限
└── 沒有業務往來
     ├── 有短期融通資金必要（第 2 款） → 可以，≤ 貸與企業淨值 40%（累計）
     └── 沒有短期融通資金必要 → 不可以
```

## 二、§13 與 §15 的 40% 對照

| | §13 II 轉投資 | §15 I ② 短期融通 |
|---|---|---|
| 主體 | 公開發行公司 | 所有公司 |
| 基準 | 本公司**實收股本** | 貸與企業**淨值** |
| 計算 | 累計 | 累計 |

## 三、法人股東例（電腦圖 2-11）

```
乙公司持有丙公司股份 → 乙是丙的法人股東
   ↓ 原則（藍筆）
丙不得貸與股東 → 不能借給乙
   ↓ 例外（紅筆）
乙、丙之間有業務往來（乙的商品在丙上架）
   ↓
經濟部：合法 → 例外破原則
```
