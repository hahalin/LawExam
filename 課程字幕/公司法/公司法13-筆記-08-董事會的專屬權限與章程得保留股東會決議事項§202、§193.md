# 公司法13 筆記：董事會的專屬權限與章程得保留股東會決議事項（§202、§193）

## 董事會的性質（講義 6-85 概說）：
- 由**全體董事**組成，是**法定、必備、常設**的機關；讓經營效率化、集思廣益
- 必須以**會議體**方式行使職權 → 有董事會時，**單一董事沒有決策權**（老師比喻：像偶像團體，一團一起出來）
- 以多數決決定：一般是董事會普通決議；重大事項提高為**特別決議**（2/3 以上出席、出席過半數同意，見公司法01-筆記-12）
- 董事會是**意思決定機關**，不是代表機關；要透過董事長或董事執行

## 公司法明文的事項：專屬權限，沒有爭議：
- 明定**董事會**：例 §266 發行新股（董事會特別決議）、§29 經理人的委任、解任及報酬
- 明定**股東會**：例 §277 變更章程（股東會特別決議）
- 法院、經濟部、學者一致稱為**專屬權限**，三個效果：
  - ①是**必須的法定程序**：沒經過就不合法
  - ②**不可以章程變更**：法條寫誰就是誰
  - ③**不可以授權**
- ②③都可以從①推出來

## 公司法沒有明文的事項：§202 原則董事會，章程得保留給股東會：
- §202：公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由**董事會**決議行之 → **董事會中心主義**（見公司法01-筆記-10）
- 沒有特別說 → **董事會普通決議**
- 但書的「章程」：只能在**法律沒有明定**的範圍內，以章程規定由股東會決議（經濟部接受）
- 例（講義註 157）：分公司的設立、名稱變更、所在地變更，公司法沒有明定是股東會職權 → 依 §202 由董事會決議；但**章程規定**分公司設立、變更、廢止須經股東會決議，亦無不可
- 若沒有章程規定而股東會自己去決議 → 合法有效，但**不拘束**董事會（本講筆記-09）

## §193 與 §202 的衝突與限縮解釋（國考不太考）：
- §202：業務執行原則由董事會決議
- §193 I：董事會執行業務應依照法令章程及**股東會之決議** → 看起來董事會又要聽股東會
- 解決：把 §193 的「股東會之決議」**限縮解釋**為「依法令（或章程）應由股東會決議者」，兩條就不衝突

## 📖 法條原文速查

> **§202**（董事會職權）
> 公司業務之執行，除**本法或章程**規定應由股東會決議之事項外，均應由**董事會**決議行之。

> **§193 I**　董事會執行業務，應依照法令章程及**股東會之決議**。

> **§266 II**　公司發行新股時，應由董事會以董事**三分之二以上**之出席，及出席董事**過半數**同意之決議行之。

> **§277**（變更章程）
> I　公司非經股東會決議，不得變更章程。
> II　前項股東會之決議，應有代表已發行股份總數**三分之二以上**股東之出席，以出席股東表決權**過半數**之同意行之。

## 📋 實務見解速查

> **經濟部（講義註 157）**：分公司之名稱變更、所在地變更等事項，公司法未明定為股東會職權，依 §202 由董事會決議；如於章程規定分公司之設立、變更、廢止須經股東會決議，亦無不可。→ 原文建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有董事會時，單一董事得否自行決定業務執行？」 | **不得**，須以會議體決議 |
| 「公司法明定為股東會決議的事項，章程得改由董事會決議？」 | **不得**，專屬權限不可變更、不可授權 |
| 「公司法未明定的業務執行事項由誰決定？」 | **董事會**（§202，普通決議） |
| 「章程得否規定分公司的設立變更須經股東會決議？」 | **可以**（經濟部） |
| 「§193 I『股東會之決議』如何解釋？」 | **限縮**為依法令（章程）應由股東會決議者 |

## 一、權限分配圖（板書）

```
業務事項
├── 公司法明定
│     ├── 董事會（§266、§29）──┐
│     └── 股東會（§277）──────┴→ 專屬權限：必須程序／不可章程變更／不可授權
└── 公司法未明定
      ├── 原則：董事會（§202）
      └── 例外：章程規定由股東會決議（例：分公司設立變更）
```

## 二、會吵的只有兩格

| 事項 | 股東會去決議 |
|---|---|
| 法律明定股東會 | 正常，有效有拘束力 |
| 未明定，但章程規定股東會 | 正常，有效有拘束力 |
| **法律明定董事會** | 爭點 → 本講筆記-09 |
| **未明定、章程也沒規定（原則董事會）** | 爭點 → 本講筆記-09 |
