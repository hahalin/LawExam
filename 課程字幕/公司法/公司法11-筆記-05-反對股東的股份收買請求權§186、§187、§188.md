# 公司法11 筆記：反對股東的股份收買請求權（§186、§187、§188）

## 性質（講義 5-128 國字(七)）：
- **自益權、固有權** → **不得以章程剝奪**
- 多數見解認為是**形成權**：股東一行使，就與公司成立股份買賣契約
- 沒有爭議，國家考試沒考過，要考應該是選擇題

## 立法目的：
- 公司發生重大變動時，給反對的股東一個**離開的機會**（老師戲稱像法定離婚事由）
- 例：甲公司原本做晶圓代工，突然把晶圓廠賣光改賣冰淇淋 → 股東可請求公司買走股份

## 公司法上只有兩類情況（講義 5-129 第三行）：
- **§186**：§185 重大行為
- **§317**（合併、分割）、**§316-2**（簡易合併）→ 都屬合併分割，第 15 章再講（講義 15-10、15-12）

## 要件：雙重反對：
- 股東會決議**前**，已**以書面通知**公司反對
- **並且**在股東會上**也反對**
- 為什麼開會前就能書面反對：§185 事項依 **§172 V** 必須在召集事由中列舉說明，不得臨時動議 → 股東事前就知道要決議什麼

## 效果：
- 得請求**公司**以**當時公平價格**收買其所有之股份

## 程序（§187）：
- 自決議日起 **20 日內**，以書面提出請求
- 有協議價格 → 公司自決議日起 **90 日內**支付
- 自決議日起 **60 日內**未達協議 → 股東於期間經過後 **30 日內**聲請法院裁定價格
- 價款支付與股份交付**同時履行**；股份移轉於**價款支付時**生效

## 失效（§188）：
- 公司**取銷** §185 行為時，請求失效
- 股東未在期間內提出請求，也失效

## 📖 法條原文速查

> **§186**（反對股東之收買請求權）　股東於股東會為前條決議前，已以**書面通知**公司反對該項行為之意思表示，並於股東會**已為反對**者，得請求公司以**當時公平價格**，收買其所有之股份。但股東會為前條第一項第二款之決議，同時決議解散時，不在此限。→ 但書建議查閱最新六法原文

> **§187**（收買股份之價格決定）
> I　前條之請求，應自第一百八十五條決議日起**二十日內**，提出記載股份種類及數額之書面為之。
> II　股東與公司間協議決定股份價格者，公司應自決議日起**九十日內**支付價款，自第一百八十五條決議日起**六十日內**未達協議者，股東應於此期間經過後**三十日內**，聲請法院為價格之裁定。
> III　公司對法院裁定之價格，自第二項之期間屆滿日起，應支付法定利息，股份價款之支付，應與股份之交付同時為之，股份之移轉於價款支付時生效。

> **§188**（收買請求權之失效）
> I　第一百八十六條股東之請求，於公司**取銷**第一百八十五條第一項所列之行為時，失其效力。
> II　股東於前條第一項及第二項之期間內，不為同項之請求時亦同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股份收買請求權得以章程剝奪？」 | ✕，**自益權、固有權** |
| 「行使要件？」 | 決議前**書面通知反對**＋股東會上**也反對** |
| 「請求期間？」 | 自決議日起 **20 日內** |
| 「協議價格者，公司何時支付？」 | 自決議日起 **90 日內** |
| 「60 日內未達協議？」 | 期間經過後 **30 日內**聲請法院裁定 |
| 「股份何時移轉？」 | **價款支付時** |
| 「公司取銷 §185 行為？」 | 請求**失效**（§188） |

## 一、期間時間軸

```
決議日 ──20 日──→ 書面請求期限
   │
   ├──60 日──→ 未達協議 ──30 日──→ 聲請法院裁定價格
   │
   └──90 日──→ 有協議：公司支付價款期限
```
