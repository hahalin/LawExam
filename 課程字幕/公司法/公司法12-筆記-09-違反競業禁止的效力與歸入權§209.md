# 公司法12 筆記：違反競業禁止的效力與歸入權（§209）

## 競業行為本身有效：
- 董事未經許可就自己開漢堡店、和第三人交易 → 該行為**完全有效**
- 公司的救濟是 §209 V 的**歸入權**

## 歸入權的發動：
- 股東會「**得**」以決議行使——是「得」不是「應」，不一定要行使
- 行使歸入權的股東會決議是**普通決議**；該董事兼股東須**迴避**
- 沒有股東會決議就**不能歸入**，實務上是蠻困難的要件

## 一條兩個股東會決議：
- 事前許可：**特別決議**（§209 I、II）
- 事後歸入：**普通決議**（§209 V）
- 公司法裡少數一條就有兩種股東會決議、且要件不同的條文

## 「視為公司之所得」的意思：
- 不是錢直接進公司戶頭
- 通說：歸入權性質是**形成權**，形成一個**請求權**；公司仍要向該董事為請求的意思表示，請求把所得交給公司

## 一年除斥期間：
- 自所得產生後**逾一年**者不得歸入，性質是**除斥期間**
- 和 §23 III（忠實義務的歸入權）一樣是一年——選擇題非常喜歡考（見公司法02-筆記-10）

## 📖 法條原文速查

> **§209 V**　董事違反第一項之規定，為自己或他人為該行為時，股東會**得以決議**，將該行為之所得**視為公司之所得**。但自所得產生後**逾一年**者，不在此限。

> **§23 III**　公司負責人對於違反第一項之規定，為自己或他人為該行為時，股東會得以決議，將該行為之所得視為公司之所得。但自所得產生後逾一年者，不在此限。→ 詳見公司法02-筆記-10

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事未經許可所為的競業行為效力？」 | **有效** |
| 「歸入權的行使？」 | 股東會**得**以**普通決議**行使，該董事須迴避 |
| 「事前許可與事後歸入的決議？」 | 許可＝**特別決議**；歸入＝**普通決議** |
| 「歸入權的期間？」 | 所得產生後**一年**，**除斥期間**，同 §23 III |
| 「股東會決議歸入後，所得當然移轉給公司？」 | **否**，形成請求權，仍須請求 |

## 一、違反競業禁止的處理

```
董事未經股東會許可為競業行為
        ↓
競業行為本身有效
        ↓
股東會「得」以普通決議行使歸入權（該董事迴避）
        ↓  所得產生後一年內
形成請求權 → 公司向董事請求交付所得
```

## 二、§209 的兩個決議

| | 事前許可 | 事後歸入 |
|---|---|---|
| 條項 | §209 I、II | §209 V |
| 決議 | 特別決議 | 普通決議 |
| 迴避 | 該董事兼股東迴避 | 該董事兼股東迴避 |
| 期間 | 事前 | 所得產生後一年 |
