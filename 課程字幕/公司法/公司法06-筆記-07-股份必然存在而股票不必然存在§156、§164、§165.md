# 公司法06 筆記：股份必然存在而股票不必然存在（§156、§164、§165）

## 股份：資本應分為股份：
- 股份有限公司之資本，**應**分為股份（§156 I）→ 是「應」不是「得」；叫股份有限公司，所以一定分成股份
- 股份是**出資**的單位，**必然存在**

## 普通股與特別股：
- 公司股份之一部分**得為特別股**，其種類由**章程**定之（§156 III）
- 特別股的內容在 §157（見 公司法06-筆記-08 ～ 12）
- 特別股之種類及其權利義務，**非經載明於章程者不生效力**（§130 I ③）
- 公司成立後要發行特別股，須**變更章程** → 股東會**特別決議**（§277）

## 股票：表彰股份的有價證券，不必然存在：
- 股票只是表彰股份的有價證券，用來**便利轉讓**、提高持股意願
- 即使**沒有股票**，股份也能轉讓
- 股份≠股票；組合只有兩種：**有股份沒股票**、**有股份有股票**，不會「沒有股份」

## 股份轉讓的兩種情形：
- **有股份、沒股票**：生效要件是**意思表示合致**；對抗要件是記載股東名簿（§165）→ 比較麻煩
- **有股份、有股票**（尤其實體股票）：**背書交付**（§164）；對抗公司仍須記載股東名簿（§165）
- 字幕在有股票情形說「生效要件一樣是記載股東名簿」，依 §165 文義應為**對抗要件**
- 詳細內容在講義 4-34 頁之後再講

## 📖 法條原文速查

> **§156**
> I 股份有限公司之資本，**應分為股份**，擇一採行票面金額股或無票面金額股。
> III 公司股份之一部分**得為特別股**；其種類，**由章程定之**。

> **§130 I ③**　下列各款事項，**非經載明於章程者，不生效力**：……三、**特別股之種類及其權利義務**。

> **§164**　股票由股票持有人以**背書**轉讓之，並應將受讓人之姓名或名稱記載於股票。→ 建議查閱最新六法原文

> **§165 I**　股份之轉讓，非將受讓人之姓名或名稱及住所或居所，記載於公司**股東名簿**，**不得以其轉讓對抗公司**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股份有限公司之資本『得』分為股份？」 | **錯**，是「**應**」分為股份 |
| 「公司未發行股票，股份即不得轉讓？」 | **錯**，沒有股票也能轉讓 |
| 「特別股之種類未載明於章程，效力如何？」 | **不生效力**（§130 I ③） |
| 「特別股種類由何者定之？」 | **章程**（§156 III） |
| 「股份轉讓未記載於股東名簿，效力？」 | 轉讓仍生效，但**不得對抗公司**（§165） |


## 二、特別股入章程的連動

```
§156 III 得為特別股，種類由章程定
      ↓
§130 I ③ 未載明章程不生效力
      ↓
成立後才要發 → 變更章程 → §277 股東會特別決議
```
