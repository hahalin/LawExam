# 公司法05 筆記：法人董監與法人代表人董監及股東身分要件（§27、§192）

## §27 I：法人董監（法人自己當選）：
- 政府或法人為股東時，**法人本身**得當選為董事或監察人
- 但須**指定自然人代表行使職務**
- 董事是**法人**；被指定的自然人是「**董事代表人**」，**不是董事**
- 委任契約（民法 §528、§192 V）存在於**被投資公司與法人股東**之間，自然人代表與被投資公司之間**沒有**委任契約
- 法人只有一個法人格 → 依 §27 I 只能當選**一席**，董事或監察人**擇一**

## §27 II：法人代表人董監（代表人自己當選）：
- 政府或法人為股東時，亦得由其**代表人**當選為董事或監察人
- 董事是**代表人（自然人）本人**；委任契約存在於**被投資公司與代表人**之間，法人股東與被投資公司之間沒有
- 代表人有數人時，得**分別當選** → 可以當選**多席**董事或多席監察人
- 實務上最常用的是 §27 II

## 名稱怎麼記：
- §27 I：法人當選董監，再派代表人 → 「**法人董監**（的）代表人」
- §27 II：法人派代表人去當選董監 → 「**法人代表人**董監」

## 法人必須具有股東身分：
- 條文寫「政府或法人**為股東時**」→ 兩項都以法人具**股東身分**為前提
- 對照 §192 I：董事由股東會就「**有行為能力之人**」選任，**不以股東為限**
- 經濟部與學者：§27 是 §192 I 的**特別規定**；講義理由：§27 明定股東要件，明示其一排除其他，且 §27 本身弊端多，加上限制也合理
- 法人股東**出脫全部持股** → 失去股東身分 → 其董監**當然解任**

## 代表人不需具有股東身分：
- 經濟部：§27 II 的**代表人本人不需**具有股東身分
- 需要股東身分的是背後的**法人股東**

## 📖 法條原文速查

> **§27**（法人為董監）
> I　政府或法人**為股東時**，得當選為董事或監察人。但須**指定自然人代表行使職務**。
> II　政府或法人**為股東時**，亦得由其**代表人**當選為董事或監察人。代表人有數人時，得**分別當選**，但不得同時當選或擔任董事及監察人。
> III　第一項及第二項之代表人，得依其職務關係，隨時改派補足原任期。
> IV　對於第一項、第二項代表權所加之限制，不得對抗善意第三人。
> → 建議查閱最新六法原文

> **§192**
> I　公司董事會，設置董事不得少於三人，由股東會就**有行為能力之人**選任之。
> V　董事與公司間之關係，除本法另有規定外，依民法關於**委任**之規定。

> **民法 §528**　稱委任者，謂當事人約定，一方委託他方處理事務，他方允為處理之契約。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「依 §27 I 當選，誰是董事？」 | **法人本身**；自然人只是代表行使職務 |
| 「依 §27 II 當選，誰是董事？」 | **代表人（自然人）本人** |
| 「依 §27 I，法人可當選幾席？」 | **一席**，董事或監察人擇一 |
| 「依 §27 II，代表人有數人時？」 | 得**分別當選**多席 |
| 「法人當選董監是否須具股東身分？」 | **須**；§27 為 §192 I 的**特別規定** |
| 「一般自然人董事是否須具股東身分？」 | **不須**（§192 I：有行為能力之人） |
| 「§27 II 的代表人本人是否須具股東身分？」 | **不須**（經濟部） |
| 「法人股東出脫全部持股，其董監如何？」 | **當然解任** |

## 一、兩種型態的委任關係（老師黑板，公司名改為甲乙丙）

```
§27 I（法人董監）
  甲公司（被投資）══委任══ 乙公司（法人股東，董事）
                              │ 指定
                              自然人 A（董事代表人，不是董事）

§27 II（法人代表人董監）
  甲公司（被投資）══委任══ 自然人 B（董事）、自然人 C（董事）
                              ↑ 派任
                         丙公司（法人股東，本身不是董事）
```

| | §27 I | §27 II |
|---|---|---|
| 誰是董事 | 法人股東 | 代表人 |
| 委任契約當事人 | 被投資公司 × 法人股東 | 被投資公司 × 代表人 |
| 席次 | 一席（董或監擇一） | 可多席 |
| 誰須具股東身分 | 法人股東 | 法人股東（代表人不須） |

## 二、電腦圖 2-24：§192 與 §27

```
§192 I：董事 ← 有行為能力之人 → 不須股東身分
§27  ：主體是政府或法人 → 條文「為股東時」→ 須股東身分
結論：§27 是 §192 I 的特別規定
```
