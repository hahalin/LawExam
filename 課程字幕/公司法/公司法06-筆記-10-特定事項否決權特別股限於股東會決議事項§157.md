# 公司法06 筆記：特定事項否決權特別股限於股東會決議事項（§157）

## 先建立觀念：否決權是「股份」的權利：
- 特別股是股份的一種 → 由**股東**行使 → 在**股東會**行使
- 所以只能否決**股東會**可以決議的事項，不能否決**董事會**的事項

## 經濟部見解（全部要背）：
- ① 否決權限於**股東會決議事項**；依法屬董事會決議事項者（例：經理人的委任、解任及報酬，§29，見 公司法02-筆記-05），**不得**行使否決權
- ② 章程規定特別股股東對「家族成員以外之增資事項」有否決權 → **不可以**：發行新股依 §266 屬**董事會職權**，不是股東會決議事項（講義 10-8 頁再學）
- ③ 為使法律關係早日確定，原則上應於**決議時**行使；縱約定得於會後行使，也須在**合理期間**內（多久法條、經濟部都沒說）
- ④ 可以**不出席**股東會，會後在合理期間內行使
- ⑤ 否決權與**無表決權**可以**並存**
- ⑥ 對**選舉結果**不得行使否決權
- ⑦ 可以發行對「**解任特定董事**議案」有否決權的特別股，但要在特定期間內行使

## 理由：
- ①② 是股東會與董事會**權限分配**下的解釋；劉連煜老師贊同：特別股只是股份，持有人是股東，不應干涉其他機關
- ⑥ 尊重選舉結果：選任若能否決，選一次否決一次，公司永遠沒有董事
- ⑦ 解任時經營者還在，否決解任不會讓公司沒有董事；另參考外國實務，重要決議都可以作為否決權的對象

## 📖 法條原文速查

> **§157 I ④**　複數表決權特別股或**對於特定事項具否決權特別股**。

> **§29 I ③**　股份有限公司經理人之委任、解任及報酬，應由**董事會**以董事過半數之出席，及出席董事過半數同意之決議行之。

> **§266 II**　公司發行新股時，應由**董事會**以董事三分之二以上之出席，及出席董事過半數同意之決議行之。→ 建議查閱最新六法原文

---

## 📋 實務見解速查

> **經濟部**（講義註 11）：特別股股東行使否決權時，以股東會得行使之決議為限；依法屬於董事會決議事項，例如經理人之委任、解任及報酬（§29），則不得行使否決權。

> **經濟部**：對選舉結果不得行使否決權；得發行對解任特定董事議案具否決權之特別股；否決權得與無表決權並存。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「否決權特別股得否決董事會委任經理人的決議？」 | **不得**，限**股東會**決議事項 |
| 「章程規定特別股對家族以外之增資有否決權？」 | **不可**，發行新股屬**董事會**職權（§266） |
| 「否決權只能在股東會當場行使？」 | 原則決議時；約定會後行使須在**合理期間**內 |
| 「未出席股東會的特別股股東可否行使否決權？」 | **可以**，會後合理期間內 |
| 「無表決權特別股可同時具否決權？」 | **可以**並存 |
| 「對董事選舉結果得行使否決權？」 | **不得** |
| 「對解任特定董事議案得行使否決權？」 | **可以**（特定期間內） |

## 一、判斷流程

```
這個事項是誰決議的？
├── 董事會（經理人委任 §29、發行新股 §266）→ ✕ 不得否決
└── 股東會
     ├── 選任董事（選舉結果）→ ✕ 不得否決（避免永遠沒有董事）
     ├── 解任特定董事 → ○ 可以否決（特定期間內）
     └── 其他股東會決議事項 → ○ 可以否決
            ├── 時點：決議時；約定會後 → 合理期間
            └── 可不出席；可與無表決權並存
```

## 二、選任與解任為什麼不同

| | 選任董事 | 解任特定董事 |
|---|---|---|
| 可否否決 | 不可 | 可 |
| 否決後的狀態 | 一直否決 → 公司沒有董事 | 原董事繼續在任，經營者還在 |
| 理由 | 尊重選舉結果 | 不影響公司運作；外國實務亦然 |
