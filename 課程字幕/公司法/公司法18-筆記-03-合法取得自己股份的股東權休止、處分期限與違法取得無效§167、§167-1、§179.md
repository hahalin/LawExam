# 公司法18 筆記：合法取得自己股份的股東權休止、處分期限與違法取得無效（§167、§167-1、§179）

## 合法取得：股東權休止：
- 學者多數說：公司合法持有自己的股份（庫藏股）期間，**所有股東權都休止、不得行使**；轉讓出去後再**回復**（講義 12-26；字幕稱「修正說」「休止說」→ 用語建議查證）
- 條文例：§167-1 III（員工庫藏股**不得享有股東權利**）、§179 II ①（公司依法持有自己之股份**無表決權**）
- 理由：已經是例外允許你取得，權利自然要受限制

## 處分方式：完全依法條（只會考選擇題）：
- 二選一：**再轉讓**或**銷除**（銷除＝法定減資，見公司法17-筆記-09）
- §167 I 但書、§186 收買 → **6 個月內**按市價出售；屆期未出售 → 視為未發行股份，並為變更登記（§167 II）
- §167-1 員工庫藏股 → **3 年內**轉讓員工；屆期未轉讓 → 視為未發行（講義 11-4；公司法17-筆記-01）
- §158 特別股收回 → **法無明文**，但應**銷除**：特別股是股東平等原則的例外，不宜長期存在（講義 4-14）
- §235-1 → 買回庫藏股後以股票方式發放員工（講義 11-9）
- 合併、分割收買的股份 → 企併法 §13（講義註 45，有興趣再看）

## 違法取得：無效：
- 實務固定見解：違反**禁止規定**，**無效**（民法 §71）
- 劉連煜老師：以人頭取得時，為保障交易安全應有效——參考就好

## 📖 法條原文速查

> **§167 II**　公司依前項但書、第一百八十六條規定，收回或收買之股份，應於**六個月內**，按市價將其出售，屆期未經出售者，**視為公司未發行股份**，並為變更登記。

> **§167-1 III**　公司依第一項規定收買之股份，**不得享有股東權利**。

> **§179 II ①**　公司依法持有自己之股份 → **無表決權**。

> **民法 §71**　法律行為，違反強制或禁止之規定者，無效。但其規定並不以之為無效者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司合法持有的自己股份有無表決權？」 | **無**（§179 II ①）；其他股東權也休止 |
| 「依 §186 收買的股份應於多久內出售？」 | **6 個月**，按市價 |
| 「§167 I 但書收回的股份屆期未出售？」 | **視為未發行股份**，變更登記 |
| 「員工庫藏股的轉讓期限？」 | **3 年**（§167-1 II） |
| 「收回的特別股如何處理？」 | 法無明文，應**銷除** |
| 「公司違法取得自己股份的效力？」 | **無效** |

## 一、股份狀態圖

```
股東持有 ──（§167 I 例外）──→ 公司持有＝庫藏股
所有權利都可行使               股東權全部休止（表決權、盈餘分派…）
      ↑                              │
      └──────── 再轉讓 ←─────────────┤
                                     └─→ 銷除（法定減資）
```

## 二、處分方式總表

| 取得原因 | 處分 | 期限／依據 |
|---|---|---|
| §167 I 但書（清算、破產） | 按市價出售 | 6 個月（§167 II） |
| §186（反對重大行為） | 按市價出售 | 6 個月（§167 II） |
| §167-1（員工庫藏股） | 轉讓員工 | 3 年（§167-1 II） |
| §158（特別股收回） | 銷除 | 法無明文 |
| §235-1（員工酬勞） | 發放員工 | 講義 11-9 |
| 合併、分割 | 依企併法 | 企併法 §13 |

- 逾期未處理 → 視為未發行股份＝**法定減資**：不依比例、不經股東會（公司法17-筆記-09）
