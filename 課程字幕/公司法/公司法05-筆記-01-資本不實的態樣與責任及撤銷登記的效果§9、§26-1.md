# 公司法05 筆記：資本不實的態樣與責任及撤銷登記的效果（§9、§26-1）

## 資本不實的兩個態樣：
- **自始不實**（未繳納股款罪）：股東**並未實際繳納**，而以申請文件表明收足（§9 I 前段）
- **事後不實**（發還股款罪）：股東**雖已繳納**，而於登記後將股款**發還**股東或**任由股東收回**（§9 I 後段）
- 名稱「未繳納股款罪」「發還股款罪」是最高法院給的稱呼
- 立法目的：保護**公司債權人**、避免**虛設公司**

## 「股款」的範圍：
- 應收之股款**不限於現金**，現物出資（如土地）該繳沒繳一樣構成自始不實
- 發還也**不限於原物發還**：現金出資卻以廠房或土地發還，一樣違反

## 民事、刑事、行政三種責任：
- 刑事（§9 I）：公司負責人處 **5 年以下**有期徒刑、拘役或科或併科 50 萬～250 萬元罰金 → 老師：公司法**最重**的刑事責任
- 民事（§9 II）：公司負責人應與**各該股東連帶**賠償公司或第三人所受損害 → 股東也要負責，常考
- 行政（§9 III）：**刑事判決有罪確定後**，由中央主管機關撤銷或廢止其登記；**判決確定前已補正**者不在此限

## 撤銷登記後資本怎麼辦：
- 原則：登記被撤銷或廢止 → **回復前一次登記**（像不動產登記張三→李四→王五，王五被塗銷就回到李四）
- **增資時**不實：撤銷增資登記，資本回到上一次登記的數額
- **設立時**不實：沒有「前一次登記」可回復 → 依 **§26-1 準用 §24～§26 清算程序**，清算完結後法人格消滅

## 📖 法條原文速查

> **§9**（資本不實之責任）
> I　公司應收之股款，股東**並未實際繳納**，而以申請文件表明收足，或股東雖已繳納而於登記後將股款**發還**股東，或**任由股東收回**者，公司負責人各處**五年以下有期徒刑**、拘役或科或併科新臺幣五十萬元以上二百五十萬元以下罰金。
> II　有前項情事時，公司負責人應與各該股東**連帶賠償**公司或第三人因此所受之損害。
> III　第一項經法院判決**有罪確定後**，由中央主管機關**撤銷或廢止**其登記。但判決確定前，已為**補正**者，不在此限。
> → 建議查閱最新六法原文

> **§26-1**（撤銷或廢止登記準用清算）
> 公司經中央主管機關**撤銷或廢止登記**者，**準用前三條**之規定。→ 前三條＝§24、§25、§26，即準用清算程序

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股東未實際繳納股款而以文件表明收足，屬何種資本不實？」 | **自始不實**（未繳納股款罪），§9 I 前段 |
| 「登記後將股款發還股東，屬何種資本不實？」 | **事後不實**（發還股款罪），§9 I 後段 |
| 「現物出資未繳、或現金出資以土地發還，是否構成？」 | **構成**；股款不限現金、發還不限原物 |
| 「資本不實時，誰對公司或第三人負連帶賠償責任？」 | **公司負責人與各該股東**連帶（§9 II） |
| 「主管機關何時撤銷或廢止登記？」 | 刑事判決**有罪確定後**；確定前已補正者不撤銷（§9 III） |
| 「增資登記被撤銷，資本回到多少？」 | 回復**前一次登記**的資本額 |
| 「設立登記被撤銷，公司如何處理？」 | §26-1 準用 §24～§26 → **清算** |

## 一、體系

```
§9 資本不實
├── 依違法時點
│   ├── 自始不實（未繳納股款）：沒繳，文件表明收足
│   └── 事後不實（發還股款）：繳了，登記後發還或任由收回
├── 責任
│   ├── 刑事 §9 I：負責人 5 年以下
│   ├── 民事 §9 II：負責人＋各該股東，連帶賠償公司或第三人
│   └── 行政 §9 III：有罪確定後撤銷／廢止登記（確定前補正者除外）
└── 撤銷後的效果（依發生時點）
    ├── 設立後增資時 → 回復前一次登記
    └── 設立時 → 無前次登記 → §26-1 準用清算
```

## 二、增資與設立的對照（老師黑板例）

| | 設立時不實 | 增資時不實 |
|---|---|---|
| 例 | 設立登記資本 1,000 萬元，股款根本沒繳 | 設立 1,000 萬元後，增資 30 億元，增資款不實 |
| 撤銷的登記 | 設立登記 | 增資登記 |
| 效果 | 沒有前一動 → §26-1 → 準用清算，清算完結法人格消滅 | 回復前一次登記 → 資本回到 1,000 萬元 |

- 兩次的資本額都要經**會計師查核簽證**（§7 I 設立、§7 II 增資），見 公司法04-筆記-11。

## 三、§9 III 的讀法

- 法條寫「第一項經法院判決有罪確定後」，第一項就是刑事責任 → 可以在六法旁寫成「第一項**刑事判決**有罪確定後」，比較好記。
- 主管機關**依職權**撤銷或廢止即可，不需要檢察機關通知。
- 補正：不論公司自行補正或主管機關限期補正，時點都必須在**判決確定前**。
- §9 IV（偽造文書罪章辦理登記）已在 公司法04-筆記-12 整理。

## 四、§26-1 的「登記」是哪一種

- 準用清算是「公司要走到結束」的嚴重效果，不是什麼登記被撤銷都要清算。
- 老師結論：§26-1 的登記指**設立登記**。撤銷或廢止設立登記 → 準用 §24～§26 清算。
- 講義 2-70 頁也把經主管機關依 §9 等規定撤銷或廢止登記列為**強制解散事由**；字幕列舉的其他條號辨識不清 → **建議查證**講義原文。
