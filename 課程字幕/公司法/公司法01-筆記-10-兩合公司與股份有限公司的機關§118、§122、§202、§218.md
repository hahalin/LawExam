# 公司法01 筆記：兩合公司與股份有限公司的機關（§118、§122、§202、§218）

## 兩合公司：依股東責任分工：
- **無限責任股東**：準用無限公司規定，執行業務、代表公司
- **有限責任股東**：只有監督權；**不得執行業務、不得對外代表公司**（§122）
- 有限責任股東的查閱權原則上**每會計年度終了**一次；必要時聲請**法院**許可才可隨時檢查（§118）
- 這兩條老師說沒考過，看過即可

## 股份有限公司：由股東會往下選：
- **股東會**選任**董事**與**監察人**
- 董事組成**董事會**，董事會選出**董事長**（§208）；董事長是**法定代表機關**
- 董事會職權範圍：**董事會中心主義**（§202）
- 董事會行使職權要**開會**（§206：過半數出席、出席過半數同意）

## 監察人：隨時、單獨：
- §218：**隨時**調查公司業務及財務狀況、查核簿冊文件，得請求董事會或經理人提出報告
- 得**代表公司**委託律師、會計師（有限公司 §109 II 是後來照抄 §218 II）
- §221：監察人各得**單獨**行使監察權

## 📖 法條原文速查

> **§118 I**（有限責任股東之監察權）
> 有限責任股東，得於**每會計年度終了時**，查閱公司帳目、業務及財產情形；必要時，**法院**得因有限責任股東之聲請，許其**隨時**檢查公司帳目、業務及財產之情形。→ 建議查閱最新六法原文

> **§122**（有限責任股東之限制）
> 有限責任股東，**不得執行公司業務及對外代表公司**。

> **§202**（董事會職權）
> 公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由**董事會**決議行之。

> **§206 I**（董事會普通決議）
> 董事會之決議，除本法另有規定外，應有**過半數董事之出席**，出席董事**過半數**之同意行之。

> **§218**（監察人監督權）
> I　監察人應監督公司業務之執行，並得**隨時**調查公司業務及財務狀況，查核、抄錄或複製簿冊文件，並得請求董事會或經理人提出報告。
> II　監察人辦理前項事務，得**代表公司委託律師、會計師**審核之。
> III、IV　違反者處罰鍰，並得限期改正。→ 建議查閱最新六法原文

> **§221**（單獨行使）
> 監察人各得**單獨**行使監察權。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「兩合公司有限責任股東得否代表公司？」 | **不得**，也不得執行業務（§122） |
| 「兩合公司有限責任股東何時可查閱帳目？」 | **每會計年度終了**；隨時檢查須**法院**許可（§118） |
| 「股份有限公司的董事、監察人由誰選任？」 | **股東會** |
| 「股份有限公司董事長由誰選出？」 | **董事會**（§208） |
| 「股份有限公司業務執行原則由誰決定？」 | **董事會**（§202，董事會中心主義） |
| 「監察人得否單獨行使監察權？」 | **得**（§221） |
| 「監察人委託會計師的費用？」 | 「**代表公司**」委託 → 公司負擔（§218 II） |

## 一、兩合公司（電腦圖 1-8 上半）

```
兩合公司股東
├── 無限責任股東 → 準用無限公司：執行業務、代表公司
└── 有限責任股東
      ├ 監督：每會計年度終了查閱；必要時法院許可隨時檢查（§118）
      └ 不得執行業務、不得對外代表公司（§122）
```

## 二、股份有限公司（電腦圖 1-8 下半）

```
股東會
├── 選任 → 董事 ── 組成 → 董事會
│                          ├ 職權範圍：§202 董事會中心主義
│                          ├ 行使方式：§206 開會（過半數 × 過半數）
│                          └ 選出 → 董事長（§208，法定代表機關）
└── 選任 → 監察人（§216）
             ├ 監督：§218 隨時調查、查核
             └ 方式：§221 各得單獨行使
```

### §202 的讀法

- 初學先把中間「除本法或章程規定應由股東會決議之事項外」括起來，讀成：**公司業務之執行，均應由董事會決議行之** → 董事會中心主義。
- 例外才是法律或章程規定由股東會決定的事項。詳細內容之後再講。

## 三、監督權比較

| 監督者 | 時點 | 委託律師、會計師 | 行使方式 |
|---|---|---|---|
| 無限公司不執行業務股東（§48） | 隨時 | — | — |
| 有限公司非董事股東（§109） | 隨時（準用 §48） | 得代表公司委託 | — |
| 兩合公司有限責任股東（§118） | 年度終了；法院許可才隨時 | — | — |
| 股份有限公司監察人（§218、§221） | 隨時 | 得代表公司委託 | 各得單獨 |
