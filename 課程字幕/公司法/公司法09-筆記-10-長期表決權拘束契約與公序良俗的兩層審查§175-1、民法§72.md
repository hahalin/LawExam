# 公司法09 筆記：長期表決權拘束契約與公序良俗的兩層審查（§175-1、民法§72）

## 解題第一步：先說明「為什麼是表決權拘束契約」：
- 題目通常不會直接寫「表決權拘束契約」，只寫「支持甲提出的候選人當選董事」「支持甲取得兩席、乙一席」
- 不能只答「這是表決權拘束契約」，要說明：讓某人當選董事、保住經營權，**必然需要股東間共同為表決權方向的行使** → 符合 §175-1「約定共同行使表決權之方式」
- 沒寫這一段，這個爭點的分數就不見（老師一堂講了三次）

## 長期的表決權拘束契約：不行：
- 幾年算長：不是固定數字；陳彥良老師提出的大致標準是 **10 年以上**。題目只有三、五年，不能說是長期
- 效果：違反**公序良俗**而**無效**（民法 §72）
- 理由（講義 5-69）：
  1. 表決權拘束本身就是**偏離一股一表決權**的非常態，會形成代理成本；期間越長問題越嚴重（張心悌老師，建議查證）
  2. **經營權長期壟斷**，無法更迭、沒有足夠的制衡機制
  3. 對其他股東、債權人、公眾不利：公司失去內部監控
- 106 台上 2329：審查是否**超過合理範圍**、是否**不利公司治理**

## 有效性的兩層審查（講義 5-70、5-80 ~ 5-81）：
- 第一層：**法律**——是否符合 §175-1 的要件（股東身分、書面、非公開發行公司）
- 第二層：**公序良俗＝公司治理**——**嚴重違反公司治理**即違反公序良俗而無效
- 最高法院沒有單獨討論「長期」，而是用這個等號串起來：長期拘束契約 → 嚴重違反公司治理 → 違反公序良俗 → 無效
- 所以有兩種考法：①直接問 50 年、30 年的契約效力 ②問「是否違反公序良俗／公司治理」，答案要接到「是否屬長期」

## 附解除條件算不算長期（2021 年考題的隱藏爭點，講義 5-82）：
- 約定「在**目前股權結構維持不變**的情形下，日後每次選舉都支持……」→ 這是**解除條件**：結構改變就不再拘束
- 臺高院：有解除條件，**不算長期**
- 學者：**仍屬長期**
  1. 條件與期限本來就不同（民法總則）
  2. 只要條件一直不成就，契約就**無止境延續**
- 看不到這個爭點，分數就不見

## 其他（沒考過）：
- **董事會**的表決權拘束契約（董事間約定選某人為常務董事）：法無明文，最高法院 72 台上 2528 認為**有效**（建議查證）
- 廣義的表決權拘束契約包括**席次分配**的經營權協議（講義 5-70）

## 📖 法條原文速查

> **§175-1 I 前段**　股東得以**書面契約**約定**共同行使股東表決權之方式**。

> **民法 §72**（違反公序良俗）　法律行為，有背於**公共秩序或善良風俗**者，**無效**。

> **民法 §99 II**（解除條件）　附**解除條件**之法律行為，於條件成就時，失其效力。

## 📋 實務見解速查

> **106 台上 2329**：表決權拘束契約是否有效，應審查其約定是否**超過合理範圍**、是否**不利公司治理**；嚴重違反公司治理者，違反公序良俗而無效（講義 5-70、5-81）。

> **臺高院（講義 5-82）**：約定附有「股權結構維持不變」的解除條件者，非屬長期。→ 學者反對；判決字號字幕未唸出

> **72 台上 2528**：董事間的表決權拘束契約有效（講義 5-71）。→ 字號依字幕，建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股東約定未來 50 年均支持甲提名之董事候選人，效力？」 | 長期拘束 → 嚴重違反公司治理 → 違反**公序良俗**無效 |
| 「約定 3 年內支持甲，屬長期？」 | 通常**不屬**；大致以 **10 年以上**為長期 |
| 「表決權拘束契約有效性的審查層次？」 | ①法律要件 ②公序良俗＝公司治理 |
| 「附『股權結構維持不變』解除條件，即非長期？」 | 臺高院：是；學者：**仍屬長期**（條件≠期限） |
| 「董事間約定選任常務董事的拘束契約？」 | 有效（72 台上 2528，建議查證） |

## 一、實例題的寫法

```
① 定性：支持甲當選／甲兩席乙一席
        → 需股東間共同為表決權方向之行使
        → §175-1 表決權拘束契約
② 第一層：法律要件（股東、書面、非公發）
③ 第二層：公序良俗＝公司治理
        → 是否長期？（50 年；或附解除條件 → 學者：仍長期）
        → 經營權無法更迭、欠缺制衡 → 嚴重違反公司治理
④ 結論：民法 §72 無效
```

## 二、兩題考古題

| 題目 | 事實 | 爭點 |
|---|---|---|
| 講義 5-74 Q5 | 董事長甲與大股東乙丙丁約定**未來 50 年**行使表決權支持甲提出的候選人 | 定性＋長期 |
| 講義 5-79（2021 年） | 甲乙約定在**目前股權結構維持不變**下，日後每次選舉支持甲取得兩席、乙一席；問是否有效、有無悖於公序良俗 | 定性＋兩層審查＋解除條件是否長期 |
