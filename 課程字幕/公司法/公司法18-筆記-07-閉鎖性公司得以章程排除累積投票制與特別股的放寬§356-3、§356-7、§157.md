# 公司法18 筆記：閉鎖性公司得以章程排除累積投票制與特別股的放寬（§356-3、§356-7、§157）

## 一般公司：累積投票制強制適用：
- §198：每一股份有與應選出董事人數相同之選舉權，得集中選舉一人或分配選舉數人，由所得選票代表選舉權較多者當選（見公司法11-筆記-10）
- 設立時發起人選任董監：§131 II **準用** §198；設立後股東會選任：直接適用 §198
- §198 **沒有但書、沒有例外**，章程不得排除

## 閉鎖性公司：章程得另定：
- 發起人選任董監：**除章程另有規定外**，準用 §198（§356-3 V）
- 股東會選任董監：**除章程另有規定外**，依 §198（§356-3 VII）
- 兩個情形都可另行規定，只是條項不同（V 與 VII）
- 經濟部：章程可以規定**每股僅有一個選舉權**或**全額連記法**；但**不得規定須經全體同意**（未給理由，老師推測是怕選不出來）

## 票面與無票面（已刪除）：
- 原 §356-6 閉鎖性可發無票面金額股；2018 年修法後一般公司也可以，條文**刪除**（講義 13-7 → 改看 4-28；公司法07-筆記-03）
- 劉連煜老師對排除 §140 的批評：立法論，不考

## 特別股的放寬（講義 13-8）：只記和 §157 不同的地方：
- 其餘與一般特別股相同（講義 4-3；公司法06-筆記-08 ~ 12）；放寬是為了讓閉鎖性公司**更有彈性**
- 記法：一般是 **§157**、閉鎖性是 **§356-7**，尾數都是 7
- 差異 ①：**複數表決權**特別股
  - 一般：選舉**監察人**時不適用，與普通股表決權同（§157 II）→ 理由：保障監察權獨立
  - 閉鎖性：沒有排除規定 → 選董事、監察人**都可以**用複數表決權
- 差異 ②：**當選一定名額**的權利
  - 一般：§157 I ⑤ 寫「當選一定名額**董事**」→ 解釋上**監察人不行**
  - 閉鎖性：§356-7 I ④ 只寫「當選一定名額」→ **董事、監察人都可以**
- 差異 ③：§157 III 公開發行公司不適用部分特別股 → 閉鎖性**必為非公發**，不需要這條（不用討論）

## 📖 法條原文速查

> **§356-3**
> V　發起人選任董事及監察人之方式，**除章程另有規定者外**，準用第一百九十八條規定。
> VII　股東會選任董事及監察人之方式，**除章程另有規定者外**，依第一百九十八條規定。

> **§356-7 I**　公司發行特別股時，應就下列各款於章程中定之：……③ 特別股之股東行使表決權之順序、限制、無表決權、**複數表決權**或對於特定事項之否決權。④ 特別股股東被選舉為董事、監察人之禁止或限制，或**當選一定名額之權利**。……
> → §356-7 是否另有關於 §157 II 的明文排除，建議查閱最新六法原文

> **§157**
> I ④ 複數表決權特別股；⑤ 特別股股東被選舉為董事、監察人之禁止或限制，或**當選一定名額董事**之權利
> II　前項第四款複數表決權特別股股東，於**選舉監察人**時，與普通股股東之表決權同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「一般股份有限公司得以章程排除累積投票制？」 | ✕，**強制**適用 §198 |
| 「閉鎖性公司得以章程排除累積投票制？」 | **可以**（§356-3 V、VII） |
| 「閉鎖性公司章程規定選任董事須全體同意？」 | **不可以**（經濟部） |
| 「閉鎖性公司複數表決權特別股可用於選監察人？」 | **可以**（一般公司不行，§157 II） |
| 「閉鎖性公司特別股可保障當選一定名額監察人？」 | **可以**（§356-7 I ④）；一般公司只限董事 |
| 「閉鎖性公司可否發行無票面金額股？」 | 可以，但現在一般公司也可以，§356-6 已刪 |

## 一、選任董監的方式

| | 一般公司 | 閉鎖性公司 |
|---|---|---|
| 發起人選任 | 準用 §198（§131 II），強制 | 準用 §198，**章程另有規定從其規定**（§356-3 V） |
| 股東會選任 | 依 §198，強制 | 依 §198，**章程另有規定從其規定**（§356-3 VII） |
| 章程可改成 | — | 每股一選舉權、全額連記法；✘ 全體同意 |

## 二、特別股差異表

| 項目 | §157（一般） | §356-7（閉鎖性） |
|---|---|---|
| 複數表決權選董事 | 可 | 可 |
| 複數表決權選監察人 | ✘（§157 II） | ✔ |
| 當選一定名額董事 | ✔ | ✔ |
| 當選一定名額監察人 | ✘（條文只寫董事） | ✔（條文只寫一定名額） |
| 公發公司不適用 | §157 III | 不需要（必為非公發） |
