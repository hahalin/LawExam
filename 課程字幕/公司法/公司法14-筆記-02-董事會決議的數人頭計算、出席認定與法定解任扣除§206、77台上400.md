# 公司法14 筆記：董事會決議的數人頭計算、出席認定與法定解任扣除（§206、77台上400）

## 董事會數人頭，股東會算股份：
- 董事會每位董事**一個表決權**，算**人數**；股東會算**出席股份數**（老師：股東會是「你幾股」，董事會是人多就贏）
- 普通決議（§206 I）：**過半數董事出席**、出席董事**過半數同意**
- 特別決議：**2/3 以上董事出席**、出席董事**過半數同意**，共 11 種；口訣見公司法01-筆記-12（講義 1-12，選擇題會考）

## 置董事二人時怎麼決議（講義 6-112，沒考過）：
- 依據 §192 II、§128-1 II（見公司法02-筆記-02）：章程**不設董事會** → 沒有董事會
- 置董事一人：由該董事行使，沒有開會決議的問題
- 置董事二人：準用董事會規定，但法未明定怎麼決議
  - 普決、特決的差異消失：過半數出席、2/3 出席，都是兩人
  - 同意數：學者與經濟部傾向**兩人都要同意**
  - 老師：若一人同意就夠，當初設一個董事就好

## 「出席」怎麼認定（講義 6-118，沒考過）：
- 公開發行公司：以**簽到簿**為準（議事辦法要求設簽到簿）
- 非公開發行公司：不設簽到簿也不違法，依意思表示**具體認定**
- 邵慶平（字幕作「邵西明」，建議查證）：有設簽到簿時，仍應斟酌簽到簿內容

## 「過半數董事」的分母：法定解任要扣除（選擇題考過）：
- 經濟部：以**依法選任、實際在任、能應召出席**的董事計算 → **法定解任**及辭職等不在任者要扣除
- 學者批評（註 238），但經濟部一直維持
- 老師提醒：電腦圖 6-24 的經濟部見解考試一定要會寫，學者見解當補充

## 簽到後離席：以簽到簿為準（77 台上 400）：
- 最高法院：以**出席簽到簿**為準，**中途離席不影響**出席數
- 臺高院座談會見解不同（註 239），考試採最高法院
- 實際意義：董事簽到後離開仍算出席，不問有沒有參與討論

## 📖 法條原文速查

> **§206 I**　董事會之決議，除本法另有規定外，應有**過半數董事之出席**，出席董事**過半數之同意**行之。

> **§192 II**　公司得依章程規定不設董事會，置董事一人或二人。置董事一人者，以其為董事長，董事會之職權並由該董事行使，不適用本法有關董事會之規定；置董事二人者，**準用**本法有關董事會之規定。

> **§185 IV**　第一項之議案，應由有**三分之二以上董事出席**之董事會，以出席董事**過半數**之決議提出之。（字幕此處唸作「第四項」，與公司法11-筆記-01 一致）

## 📋 實務見解速查

> **最高法院 77 年度台上字第 400 號**：董事會出席人數以**出席簽到簿**為準，簽到後中途離席者仍計入出席。→ 要旨依課堂講述整理，案號與原文建議查證

> **經濟部見解**：董事會出席人數，應以依法選任並**實際在任、能應召出席**之董事為計算基準；法定當然解任者應予扣除。→ 函號建議對照講義 6-118

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事會決議以股份數計算？」 | **否**，數人頭，一人一表決權 |
| 「董事 15 人，3 人辭職，董事會特別決議至少幾人出席？」 | (15−3) × 2/3 = **8 人** |
| 「董事法定解任，是否計入董事總數？」 | **扣除**，以實際在任能出席者計算（經濟部） |
| 「董事簽到後離席，是否計入出席？」 | **計入**，以簽到簿為準（77 台上 400） |
| 「置董事二人時決議方式？」 | 學者、經濟部傾向**兩人均同意** |

## 一、兩個計算例

### 例一：先扣不在任者（註 234）
- 董事 15 人，其中 3 人辭職；董事會要決議提出出租全部營業的議案（§185 IV，董事會特別決議）
```
15 − 3 = 12（實際在任能出席）
12 × 2/3 = 8 → 至少 8 人出席
同意：出席者過半數
```

### 例二：簽到後離席（電腦圖 6-22）
- 董事 A ~ G 共 7 人；11:00 A、B、C、D、E 五人簽到，F、G 沒來；D、E 簽到後就離開
- 11:30 討論股份交換案（§156-3，董事會特別決議）
```
定足數：7 × 2/3 = 4.67 → 至少 5 人
簽到簿：5 人 → 符合（現場只剩 A、B、C 也一樣）
多數決：5 人過半數 = 3 → A、B、C 都同意即通過
```

## 二、股東會與董事會的計算對照

| | 股東會 | 董事會 |
|---|---|---|
| 計算單位 | 股份數 | 人數 |
| 分母 | 已發行股份總數（扣無表決權股，見公司法09-筆記-12） | 實際在任能出席的董事 |
