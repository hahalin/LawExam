# 公司法01 筆記：公開發行公司的動作與狀態（§156-2）

## 只有股份有限公司能公開發行：
- 無限、有限、兩合都不行
- 理由：公司法設計之初，股份有限公司就是為**大型公司**而立法（大公司走大公司的規範）
- 同理，**公司分割**也只有股份有限公司可以（後面課程會講）
- 「大小分流」是立法方向的用語，確定適用時才寫；用錯地方反而顯示觀念不清

## 我國採任意公開發行：
- 要不要公開發行由公司自己決定，法律不強制
- 公開發行公司依股票交易方式分四種：**上市、上櫃、興櫃、非上市櫃（非興櫃）**

## 變成公開發行公司有兩條路：
- **動作**：向不特定人公開招募有價證券，事前向金管會**申報生效**（證交法 §22）；時點可以是設立時（募集設立）或成立後發行新股
- **狀態**：依**董事會普通決議**，向證券主管機關申請辦理公開發行程序（§156-2 I）；未依法發行的股票要上市櫃，先申請**補辦**發行審核程序（證交法 §42）

## §156-2 的「公開發行」是形容詞：
- 「申請辦理公開發行（的）程序」指變成公開發行的**狀態**，不是發行股票的動作
- 對照：§13 II「公開發行股票之公司」也是形容詞；§267 III「得公開發行或洽由特定人認購」是動詞

## 📖 法條原文速查

> **§156-2 I**（申請公開發行）
> 公司**得**依**董事會之決議**，向證券主管機關申請辦理**公開發行程序**；申請停止公開發行者，應有代表已發行股份總數三分之二以上股東出席之股東會，以出席股東表決權過半數之同意行之。→ 建議查閱最新六法原文

> **證交法 §22 I**（申報生效）
> 有價證券之募集及發行，除政府債券或經主管機關核定之其他有價證券外，非向主管機關**申報生效**後，不得為之。

> **證交法 §42 I**（補辦公開發行）
> 對於未依本法發行之股票，擬在證券交易所上市或於證券商營業處所買賣者，應先向主管機關申請**補辦**本法規定之有關發行審核程序。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有限公司得否公開發行股票？」 | **不得**，只有**股份有限公司** |
| 「我國是否強制公司公開發行？」 | **否**，任意公開發行 |
| 「公司申請辦理公開發行程序，須經何種決議？」 | **董事會**決議（未特別規定＝普通決議）（§156-2 I） |
| 「募集有價證券須事前向金管會做什麼？」 | **申報生效**（證交法 §22） |
| 「只有公開發行公司才能聲請的程序？」 | **重整**（另有限於公開發行公司適用的條文） |

## 一、成為公開發行公司（電腦圖 1-2）

```
公開發行公司（任意，不強制）
│
├── 動作：向不特定人公開招募有價證券
│     └ 證交法 §22：事前向金管會「申報生效」
│        ├ 設立時：募集設立（首次發行）
│        │   └ 成立即受證交法規範、成本高；老師說最後一例約在民國 82 年（銀行，依銀行法要求）
│        └ 成立後：發行新股（§266、§267 III）
│            └ 申報後經一定營業日生效（老師說 12 個營業日，建議查證）
│
└── 狀態：把公司股票直接變成公開發行的股票
      ├ §156-2 I：董事會（普通）決議 → 申請辦理公開發行程序
      └ 證交法 §42：擬上市櫃者，先申請「補辦」發行審核程序
```

## 二、公開發行與非公開發行的差異（講義第 1-7 頁）

| 項目 | 公開發行公司 |
|---|---|
| 特別決議門檻 | 出席不足 2/3 時，可用**過半數出席、2/3 以上同意**（見 公司法01-筆記-12） |
| 募資 | 可**公開募集**股份、公司債 |
| 股票 | 有**發行股票義務** |
| 重整 | 只有公開發行公司可以重整 |
| 其他 | 部分條文限於公開發行公司適用 |

## 三、公開發行公司的種類（電腦圖 1-3）

| 種類 | 交易方式 |
|---|---|
| 上市 | 證券交易所集中市場；原則上**應**在集中市場交易（證交法 §150） |
| 上櫃 | 櫃買中心；**得**在櫃檯買賣，也有其他交易方式 |
| 興櫃 | 與**推薦證券商**交易（推薦證券商須持有一定數量股份） |
| 非上市櫃、非興櫃 | 只是公開發行，依公司法規範 |

- 區分標準是**股票交易方式**的不同。
- 這部分屬背景知識，考試不太會問「如何成為公開發行公司」，但不懂會影響後面的理解。

> 字幕校正：「新櫃／新貴」為**興櫃**；「補辦」為證交法 §42 的補辦發行審核程序。
