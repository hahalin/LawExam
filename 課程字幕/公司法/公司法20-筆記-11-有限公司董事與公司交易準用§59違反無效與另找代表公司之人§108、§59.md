# 公司法20 筆記：有限公司董事與公司交易準用§59違反無效與另找代表公司之人（§108、§59）

## 規則（§108 IV 準用 §59）：
- 代表公司的董事，為自己或他人與公司為**買賣、借貸或其他法律行為**時，**不得同時為公司之代表**
- 範圍是**所有法律行為**；法定例外只有**向公司清償債務**
- 經濟部另加一個例外：董事對公司**無償贈與**（沒考過，注意即可）

## 違反的效力：
- 經濟部見解非常嚴格：違反 §59 → **無效**
- 很容易成立：有限公司只有一位董事甲，甲代表公司跟甲自己訂買賣契約 → 違法、無效

## 解決方法：另找代表公司之人，先找其他董事，再找股東（電腦圖 17-6）：
- **董事 2～3 人、未設董事長**：依民法 §27 II 各董事均得代表 → 由**另一位董事**代表公司
- **董事 2～3 人、有設董事長**，董事長是交易相對人：本來只有董事長能代表，但經濟部認為情況特殊，**其他董事**得代表公司
- **只有一位董事**：由**全體股東**同意，另推選**有行為能力的股東**代表公司
- **一人有限公司，唯一股東就是董事**：陷入困境；經濟部見解只能**新增其他股東**才有辦法；學者有批評（講義 17-12 八，自己看）

## 違法執行業務的損害賠償（講義 17-12）：
- §108 IV 準用 §52：董事執行業務應依照**法令、章程及股東之決定**；違反致公司受損害，應負賠償責任

> 來源：公司法20 課程字幕 02:29:47 ~ 02:38:51（講義 17-11 ~ 17-12；電腦圖 17-6）
> 字幕老師一度說「金管會的函令」，前後文皆為經濟部見解，應為口誤。

## 📖 法條原文速查

> **§59**　代表公司之股東，如為自己或他人與公司為買賣、借貸或其他法律行為時，**不得同時為公司之代表**。但**向公司清償債務**時，不在此限。

> **§108 IV**　……第五十二條……第五十七條至**第五十九條**……之規定，於董事準用之。→ 建議查閱最新六法原文

> **民法 §27 II**　董事就法人一切事務，對外代表法人。董事有數人者，除章程另有規定外，**各董事均得代表法人**。

> **§52**　I 股東執行業務，應依照法令、章程及股東之決定。II 違反前項規定，致公司受有損害者，對於公司應負賠償之責。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有限公司董事得否代表公司與自己訂買賣契約？」 | **不得**（§108 IV 準用 §59） |
| 「§59 的法定例外？」 | **向公司清償債務** |
| 「經濟部另承認的例外？」 | 董事對公司**無償贈與** |
| 「違反 §59 的效力？」 | 經濟部：**無效** |
| 「設有董事長，董事長與公司交易由誰代表？」 | **其他董事**（經濟部） |
| 「只有一位董事時？」 | **全體股東**同意推選其他有行為能力股東 |
| 「與股份有限公司的處理有何不同？」 | 股份有限公司由**監察人**代表（§223）；有限公司沒有監察人 |

## 一、四種情形一次看（電腦圖 17-6）

```
董事要跟公司交易 → 自己不能代表公司（§59）
│
├── 有其他董事？
│     ├── 未設董事長 → 另一位董事代表（民法 §27 II）
│     └── 有董事長且董事長是相對人 → 其他董事代表（經濟部）
│
└── 只有一位董事
      ├── 還有其他股東 → 全體股東同意推選其他股東代表
      └── 一人公司（股東＝董事）→ 困境；經濟部：新增股東
```

## 二、與股份有限公司對照

| | 股份有限公司 | 有限公司 |
|---|---|---|
| 條文 | §223 | §108 IV 準用 §59 |
| 誰代表公司 | 監察人（見公司法15-筆記-03） | 其他董事 → 其他股東 |
| 例外 | — | 清償債務；經濟部加無償贈與 |
| 違反效力 | 學說效力未定；100 台上 1627 得許諾或承認（見公司法15-筆記-05） | 經濟部：無效 |
