# 公司法10 筆記：決議不成立的無召集權人召集與出席股份數不足（103年度第11次民事庭會議）

## 為什麼要另外創造「不成立」：
- 例：無召集權人召集甲公司股東會，決議解任董事乙
- 不是 §191：解任董事的**內容**完全合法
- 若只能主張 §189：得撤銷，訴訟期間決議**有效**，乙要先回家，無召集權人反而得逞
- 所以學者提出、實務接受：這種**重大瑕疵**屬決議**不成立**，提**確認之訴**
- 不成立＝無法適用 §191、但嚴重到不適合放在 §189 的情形；公司法**未明文**

## 不成立的定義與例子（講義 5-100）：
- 決議**成立過程顯然重大違法**，未具備決議的成立要件
- 例：開會地點已有效變更仍在原地決議；根本**未為召集通知**；**漏未通知情節重大**；**根本沒有開會**
- **無召集權人召集**：近期最高法院有直接採不成立說；早期 28 上 1911 採**無效說**（註 292），兩種寫法都可以
- 28 上 1911 採無效的背景：當時舊法限一個月內訴請撤銷，法院覺得不夠用而自創無效；屬法制史

## 出席股份數不足：決議不成立（103 年度第 11 次民事庭會議）：
- 法律規定須有一定數額股份出席，這個數額是決議的**成立要件**；決議是多數股東基於**平行協同的意思表示**而成立，欠缺就不成立（講義 5-101）
- 當時案件是 §185 特別決議；解任董事等特別決議同樣解釋
- 為什麼不討論「表決權數不足」：那是**議案未通過**，沒有瑕疵可談

## 統一前的爭議（講義 5-102，看過即可）：
- 得撤銷說、不成立說、折衷說（依特別決議、普通決議區分；早期學者採，字幕作「鄭萬老師」，建議查證）
- 折衷說：區分特決普決的理由不清楚
- 得撤銷說：①有權召集的人可以為所欲為，1%、2% 出席也能決議 ②**少數股東決定公司意思，多數股東反而要起訴**

## 選擇題陷阱：先確認還有沒有退路：
- **公開發行公司特別決議可以退一步**：過半數出席 × 2/3 同意（例 §199 III）
- **普通決議可以假決議**：1/3 以上出席、出席過半數同意（§175，見公司法01-筆記-11）

## 📖 法條原文速查

> **§199**（董事之解任）
> I 董事得由股東會之決議，隨時解任；如於任期中無正當理由將其解任時，董事得向公司請求賠償因此所受之損害。
> II 股東會為前項解任之決議，應有代表已發行股份總數**三分之二以上**股東之出席，以出席股東表決權**過半數**之同意行之。
> III **公開發行股票之公司**，出席股東之股份總數不足前項定額者，得以有代表已發行股份總數**過半數**股東之出席，出席股東表決權**三分之二以上**之同意行之。

> **§175 I**（假決議）　出席股東不足前條定額，而有代表已發行股份總數**三分之一以上**股東出席時，得以出席股東表決權過半數之同意，為**假決議**，並將假決議通知各股東，於一個月內再行召集股東會。

> **§230 I**（財務報表之承認）　董事會應將其所造具之各項表冊，提出於股東常會請求承認。→ 普通決議；第八章（講義 8-4）再學

## 📋 實務見解速查

> **最高法院 103 年度第 11 次民事庭會議決議**：法律規定決議須有一定數額以上股份之股東出席，此為股東會決議之**成立要件**，欠缺即屬**決議不成立**。→ 原文建議查證

> **28 上 1911**（註 292）：無召集權人召集之股東會，所為決議**無效**。→ 早期見解，原文建議查證

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「出席股份數未達定足數所為決議，效力？」 | **不成立**（103 年第 11 次民庭） |
| 「無召集權人召集股東會所為決議，效力？」 | 近期：**不成立**；早期 28 上 1911：無效 |
| 「公開發行公司解任董事，出席 52%、同意 70%？」 | **合法**，可退一步（§199 III），不是不成立 |
| 「普通決議只有 45% 出席承認財報？」（註 298） | 超過 1/3 → 可**假決議**（答 C） |
| 「決議不成立應提何種訴訟？」 | **確認之訴** |
| 「出席表決權數不足，屬決議不成立？」 | ✕，是**議案未通過** |

## 一、解任董事的出席數判斷（公開發行公司）

| 出席 | 同意 | 結果 |
|---|---|---|
| 70%（≥ 2/3） | 過半數 | 通過（§199 II） |
| 52%（過半數） | ≥ 2/3 | 通過（§199 III 退一步） |
| 41% | ≥ 2/3 | 兩種定額都不足 → **不成立** |

- 非公開發行公司沒有 III，出席不足 2/3 就不成立。

## 二、無召集權人召集，為什麼不選 §189

```
無召集權人召集 → 解任董事乙
   │
   ├─ §191？ 內容合法 → 不適用
   ├─ §189？ 得撤銷 → 訴訟中有效 → 乙先失去職位（對乙不利）
   └─ 不成立 → 確認之訴 → 自始不生效力（學說、近期實務）
```
