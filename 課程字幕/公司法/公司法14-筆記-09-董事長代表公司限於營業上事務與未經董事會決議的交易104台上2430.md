# 公司法14 筆記：董事長代表公司限於營業上事務與未經董事會決議的交易（104台上2430）

## 董事長是法定代表人：
- §208 III：董事長**對外代表公司** → 公司法少數明定的公司代表人
- 法條明定是董事長 → 這個權限**不能以章程變更**，也不能授權給別人（講義 6-145 末行）
- §208 V：§57、§58 對「代表公司之董事」準用 → 學者、法院都認為就是**董事長**
- 「業務執行權」（講義 6-144 第三點）帶過

## 限制一：限於營業上事務（準用 §57）：
- 對公司**營業上一切事務**有辦理之權 → 非營業上事務**沒有**代表權，也無法以任何方式變成有效
- 最高法院 109 台上 2027：是否屬營業上事務，看是否與**營業目的之達成**有關
- 例：花店董事長以公司名義買花＝營業上事務；文具店董事長大量買花 → 不是
- 實務上律師吵很兇，國考不考，記得「限營業上事務」即可

## 限制二：法律或章程明定須股東會、董事會決議的事項：
- 法條寫誰就是誰，程序無法閃避、逃脫、變更；未經合法程序不可能有效（第一堂課起一再強調）

## 限制三：對代表權所加的限制，不得對抗善意第三人（準用 §58）：
- 公司內部對董事長代表權另加限制 → 看第三人**知道或不知道**

## 爭點：屬營業上事務，但未經董事會決議（104 台上 2430，沒考過的特殊見解）：
- 前提：已經確定是**營業上事務**、屬董事長權限——不是營業上事務就不用走到這一步
- 例：花店董事長以公司名義買了 100 萬元的花；公司抗辯「這筆沒有經過董事會決議，對公司不生效力」
- 最高法院：董事長的交易有沒有經過董事會決議，交易相對人實際上**無從得知**，與對代表權加以限制相同 → 為保障**交易安全**，**類推適用 §58**，看相對人是否**善意**

## 📖 法條原文速查

> **§208 III（前段）**　董事長對內為股東會、董事會及常務董事會主席，**對外代表公司**。

> **§208 V**　第五十七條及第五十八條對於代表公司之董事準用之。

> **§57**　代表公司之股東，關於公司**營業上一切事務**，有辦理之權。

> **§58**　公司對於股東代表權所加之限制，**不得對抗善意第三人**。

---

## 📋 實務見解速查

> **最高法院 109 年度台上字第 2027 號**：是否屬公司營業上之事務，應以該行為與公司**營業目的之達成**是否有關判斷。→ 要旨依課堂講述整理，建議查證

> **最高法院 104 年度台上字第 2430 號**：董事長所為屬營業上事務之交易，究竟有無經董事會決議，交易相對人實際上無從知悉，與代表權受限制相同；為保障交易安全，應**類推適用公司法第 58 條**，以相對人是否善意定其效力。→ 要旨依課堂講述整理，引用條文建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事長代表公司的範圍？」 | **營業上一切事務**（§208 V 準用 §57） |
| 「非營業上事務，董事長以公司名義為之？」 | **無代表權** |
| 「法律明定須股東會決議的事項，董事長逕行代表？」 | 未經合法程序，**不生效力** |
| 「公司對董事長代表權的內部限制，可否對抗第三人？」 | **不得對抗善意第三人**（準用 §58） |
| 「營業上事務未經董事會決議，效力？」 | 類推 **§58**，看相對人**是否善意**（104 台上 2430） |

## 一、判斷順序

```
董事長以公司名義與丙交易
        ↓
① 是營業上事務嗎？（109 台上 2027：與營業目的之達成有關）
   ├── 否 → 無代表權，不生效力
   └── 是 ↓
② 法律或章程明定須股東會／董事會決議嗎？
   ├── 是，且未決議 → 不生效力（程序不可規避）
   └── 否 ↓
③ 公司內部另有限制，或公司抗辯「這筆沒經董事會決議」？
   └── 準用／類推 §58：丙善意 → 公司不得對抗；丙惡意 → 可對抗
```

## 二、代入練習

| 情形 | 結論 |
|---|---|
| 花店董事長買 100 萬元花，未經董事會決議，賣方不知情 | 類推 §58，賣方善意 → 對公司有效 |
| 同上，賣方明知公司內規須經董事會 | 賣方惡意 → 公司得對抗 |
| 文具店董事長以公司名義大量買花 | 非營業上事務 → 無代表權 |
