# 公司法16 筆記：新股認購權的獨立轉讓、員工承購股份的限制轉讓與控制從屬公司員工（§267）

## 股東的新股認購權得獨立轉讓，員工的不得（§267 IV）：
- 「前三項新股認購權利」＝ I 民營員工、II 公營員工、III 原有股東（電腦圖 10-4：員工用紅筆、股東用藍筆）
- **原則**：得與原有股份**分離而獨立轉讓** → 股東的新股認購權可以轉讓（講義 10-5）
- **例外**：「除保留由員工承購者外」→ 員工的新股認購權**不得轉讓**，民營、公營都一樣（講義 10-4）
- 理由：員工新股認購權是為了**勞資融合**；轉給不是員工的人，就失去給這個權利的意義
- 老師：條文很簡單，但很多人讀不懂，要一個字一個字對照電腦圖

## 員工承購的股份得限制轉讓二年（§267 VI）：
- 公司對員工依 I、II 承購的股份，**得**限制一定期間不得轉讓，**最長二年**
- **兩重限制**（電腦圖 11-1 最下方）：
  - ① 新股認購**權本身**：完全不得轉讓，一定要員工自己行使（§267 IV）
  - ② 認到的**股份**：還可以再限制最長兩年不得轉讓（§267 VI）

## 章程得訂明包括控制或從屬公司員工（§267 VII）：
- 章程**得**訂明：依 I 承購股份的員工，包括符合一定條件的**控制或從屬公司**員工
  - 是「得」不是「應」→ 要寫進章程才可以
- 2018 年**全面開放**：所有員工獎勵制度都可以包括控制、從屬公司員工（講義 11-4 第一行，本講筆記-12）
- 例（電腦圖 11-2，老師用真實集團，公司名改稱）：
  - 甲公司持有乙公司 **78.4%** 股份 → 甲是**控制公司**、乙是**從屬公司**
  - A 是甲的員工，B 是乙的員工
  - 甲給 A：當然可以（本公司員工）
  - 甲給 B：章程訂明後**可以**（從屬公司員工）
  - 乙給 B：當然可以
  - 乙給 A：章程訂明後**也可以**（控制公司員工）→ 控制、從屬**雙向**都可以

## 電腦圖 11-1「新股認購權」欄位（複習用，用手遮住想答案）：
- §267 I、II：民營公司**強制保留 10% ~ 15%**
- §267 IV：員工新股認購權**不得**獨立轉讓
- §267 VI：**可以**限制不得轉讓，上限 **2 年**
- 右上角：**全面開放**，章程訂明可包括控制從屬公司員工

## 📖 法條原文速查

> **§267**
> IV　前三項新股認購權利，**除保留由員工承購者外**，得與原有股份**分離而獨立轉讓**。
> VI　公司對員工依第一項、第二項承購之股份，得限制在一定期間內不得轉讓。但其期間**最長不得超過二年**。
> VII　**章程得訂明**依第一項規定承購股份之員工，包括符合一定條件之**控制或從屬公司**員工。
> → VII 原文建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「原有股東的新股認購權可否獨立轉讓？」 | **可以**（§267 IV） |
| 「員工的新股認購權可否轉讓給配偶？」 | **不可以**，員工的不得轉讓 |
| 「員工承購的新股可否限制轉讓？期間？」 | **可以**，最長 **2 年**（§267 VI） |
| 「公司限制員工承購股份 3 年不得轉讓？」 | **違法**，超過 2 年 |
| 「從屬公司員工可否認購控制公司的員工保留股份？」 | 章程**得**訂明後可以（§267 VII） |
| 「控制公司員工可否認購從屬公司的員工保留股份？」 | **也可以**，控制、從屬雙向皆可 |

## 一、§267 IV 逐字對照（電腦圖 10-4）

```
「前三項新股認購權利」
   ├── I  民營員工 ─┐
   ├── II 公營員工 ─┴→ 「除保留由員工承購者外」→ 不得轉讓（紅）
   └── III 原有股東 ──→ 「得……分離而獨立轉讓」→ 可以轉讓（藍）
```

## 二、員工的兩重限制

```
員工新股認購權 ──（權本身不得轉讓，§267 IV）──→ 員工自己行使
                                                    ↓
                                               認到的股份
                                                    ↓
                                     得限制不得轉讓，最長 2 年（§267 VI）
```
