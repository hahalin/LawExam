# 公司法16 筆記：私募公司債的要件、事後報備與決議機關（§248、§248-1）

## 私募的意義（講義 9-8 ~ 9-9）：
- **私募**（private placement）相對於**公開募集**（public offering）
- 功能：**節省發行成本**、**迅速完成**
- 特色：**洽特定人**；應募人**自行評估風險**，法律不多干涉
- 沿革：2001 年訂 §248 II、III；2018 年修正，**增訂 §248-1**，並在 §248 I ⑫ 加上「私募不在此限」

## 私募不需要受託人（§248 I ⑫ 但書；選擇題）：
- 受託人是國家強制公司另外找人來監督（本講筆記-05）
- 私募原則上自己保護自己 → 2018 年刪掉受託人的要求（講義註 16）
- 私募債權人的保護只剩**債權人會議**

## §248 II、III：幾乎每個字都能考：
- **主體**：私募之發行公司**不以上市、上櫃、公開發行股票之公司為限** → 非公發公司也可以私募公司債
- **客體**：**普通公司債、轉換公司債、附認股權公司債**三種都可以私募
- **排除過去獲利能力的限制**：不受 §249 ②（150%）、§250 ②（100%）限制
  - 理由：過去獲利不代表未來一定獲利
  - 但違約遲延**尚在繼續中**（§250 ①）仍不能發
- **事後報備制**：**發行後 15 日內**，檢附相關資料向**證券主管機關報備**
  - 發行後才報 → 叫「事後」；只是報備，不用申報生效
- **人數**：不得超過 **35 人**；但**金融機構**應募者不在此限
  - 金融機構**不算入人數**：35 個自然人＋100 家銀行也可以
  - 理由：金融機構理論上有自保能力，不需要保護
  - 證交法 §43-6 II 也是 35 人（證交法再學）

## 私募的決議機關（講義 9-10 國字七）：
- **轉換公司債、附認股權公司債**（§248-1 明文）：
  - **董事會特別決議**（依 §246）＋**股東會（普通）決議**
  - 不是報告股東會，而是要股東會決議
  - 理由：轉換或認股會**影響股份數量**，也就影響**股東權益**
  - 公開發行公司另依證券主管機關規定（證交法 §43-6）
- **普通公司債**：**法無明文**
  - 依 §248-1 **立法理由**（講義註 19），參考 §246、證交法 §43-6 III → **董事會特別決議**
  - 老師批評：寫在立法理由不寫進法條
  - 選擇題會考

## 其他（講義 9-10 ~ 9-12）：
- 非公發公司私募總額**無上限**（見本講筆記-04）
- 私募公司債的**流通限制**：公司法**沒有**（學者認為需要）；證交法有（§43-8）
- 發行方式、轉讓方式：實體與無實體，和股票一樣（講義 4-35，見公司法07-筆記-05）；未考過
- 唯一不同：**公司債可以無記名**（股票已廢除無記名，見公司法07-筆記-02）

## 📖 法條原文速查

> **§248**
> I ⑫　公司債權人之受託人名稱及其約定事項。公司債之**私募不在此限**。
> II　普通公司債、轉換公司債或附認股權公司債之私募不受第二百四十九條**第二款**及第二百五十條**第二款**之限制，並於**發行後十五日內**檢附發行相關資料，向證券主管機關**報備**；私募之發行公司**不以上市、上櫃、公開發行股票之公司為限**。
> III　前項私募人數不得超過**三十五人**。但**金融機構**應募者，不在此限。

> **§248-1**　公司依前條第二項私募**轉換公司債或附認股權公司債**時，應經第二百四十六條**董事會之決議**，並經**股東會決議**。但公開發行股票之公司，證券主管機關另有規定者，從其規定。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「私募公司債是否需要受託人？」 | **不需要**（§248 I ⑫ 但書） |
| 「非公開發行公司可否私募公司債？」 | **可以**（§248 II 末段） |
| 「私募公司債是否受過去獲利能力限制？」 | **不受** §249 ②、§250 ② |
| 「私募公司債應於何時向主管機關辦理？」 | **發行後 15 日內報備**（事後報備制） |
| 「私募人數上限？」 | **35 人**；金融機構**不計入** |
| 「35 名自然人＋40 家銀行應募，是否違法？」 | **不違法** |
| 「私募轉換、附認股權公司債的決議？」 | **董事會特別決議＋股東會決議**（§248-1） |
| 「私募普通公司債的決議？」 | 法無明文；依立法理由為**董事會特別決議** |

## 一、公司債發行程序總整理（講義板書）

```
公開發行公司
   ├── 募集（公開發行）→ 董事會特別決議＋報告股東會（§246）＋證交法 §22 申報生效
   └── 私募 → 證交法 §43-6

非公開發行公司（只能私募）
   ├── 普通公司債 → 董事會特別決議（法無明文，§248-1 立法理由）
   └── 轉換、附認股權公司債 → 董事會特別決議＋股東會普通決議（§248-1）
```

## 二、私募與募集的對照

| | 募集 | 私募 |
|---|---|---|
| 對象 | 不特定多數人 | 特定人 |
| 受託人 | 要（§248 I ⑫） | **不要** |
| 獲利能力限制（§249 ②、§250 ②） | 受限 | **不受限** |
| 主管機關 | 事前辦理 | **發行後 15 日內報備** |
| 人數 | — | **35 人**（金融機構不計） |
| 主體 | 公開發行公司 | 不以公開發行公司為限 |
