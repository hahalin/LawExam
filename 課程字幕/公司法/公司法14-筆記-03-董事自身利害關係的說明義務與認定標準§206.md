# 公司法14 筆記：董事自身利害關係的說明義務與認定標準（§206）

## 說明義務（§206 II）：
- 前提：董事對會議事項有**自身利害關係**
- 義務：於**當次**董事會說明自身利害關係的**重要內容**
- 立法理由：**資訊揭露**，讓其他董事做成決議時有**充分資訊**
- 書面、口頭都可以；其他董事詢問時要答覆
- 不論出席與否都有說明義務；有利害關係的董事**仍要通知出席**——不出席就無從說明，不是有利害關係就不用來
- 說明之後，接著是**討論與表決的迴避**（§206 IV，見本講筆記-05）

## 認定標準一：法律上權利義務變動（經濟部、107 台上 649）：
- 董事**本身**有**直接具體的權利義務變動**：取得權利、免除義務、喪失權利、新負義務
- 以董事本人**實質認定**，範圍相當**狹窄**
- 例：甲公司與董事 A 本人簽買賣契約（民法 §345）→ A 權利義務變動 → 有自身利害關係

## 認定標準二：視為有利害關係（2018 年增訂 §206 III）：
- 以**列舉**方式擴張關係人：董事的**配偶**、**二親等內血親**、與董事有**控制從屬關係的公司**
- 關係人就議案有利害關係 → **視為**董事有自身利害關係
- 學者（講義 6-115）：立法意義甚佳，但不能只靠 §206 III，仍要以標準一**實質認定**
- 選擇題：是**血親**，**姻親不算**；老師提到證交法類似規定寫的是「親屬」，範圍較寬

## 操作方式：先用標準一判斷關係人，再歸到董事身上：
- 甲公司與 A 的配偶 B 交易：A 會說「又不是跟我交易」；但 B 依標準一有權利義務變動 → B 的利害關係**視為** A 的利害關係 → A 要在董事會說明
- 甲公司與 A 的兒子 C（直系血親一親等）交易：同理，C 有 → 視為 A 有
- 與董事有控制從屬關係的公司，另見本講筆記-04

> 來源：公司法14 課程字幕 00:32:19 ~ 00:50:31（講義 6-115 ~ 6-117）

## 📖 法條原文速查

> **§206**
> II　董事對於會議之事項，有**自身利害關係**時，應於**當次**董事會**說明**其自身利害關係之**重要內容**。
> III　董事之**配偶**、**二親等內血親**，或與董事具有**控制從屬關係之公司**，就前項會議之事項有利害關係者，**視為**董事就該事項有自身利害關係。

---

## 📋 實務見解速查

> **最高法院 107 年度台上字第 649 號（與經濟部見解同）**：所謂自身利害關係，指因該事項之決議，董事本身之權利義務將有直接具體之變動，取得權利、免除義務，或喪失權利、新負義務。→ 要旨依課堂講述整理，建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事有自身利害關係時，何時說明？」 | **當次**董事會，說明**重要內容** |
| 「有利害關係的董事是否仍應通知出席？」 | **是**，否則無從說明 |
| 「董事的岳父與公司交易，視為董事有利害關係？」 | **否**，§206 III 限**血親**，姻親不算 |
| 「董事的兒子與公司交易？」 | 二親等內血親 → **視為**董事有利害關係 |
| 「自身利害關係的認定標準？」 | 法律上**直接具體權利義務變動**（107 台上 649）＋ §206 III 視為 |

## 一、判斷流程

```
議案的交易相對人是誰？
├── 董事本人 → 標準一：權利義務變動 → 有
├── 配偶、二親等內血親 → 先用標準一判斷該人 → 有 → 視為董事有（§206 III）
├── 與董事有控制從屬關係的公司 → 見本講筆記-04
└── 其他人（例：姻親）→ 不適用 §206 III，回到標準一實質判斷
        ↓
有自身利害關係 → 說明義務（§206 II）→ 迴避（§206 IV，筆記-05）
```

## 二、兩個標準對照

| | 標準一 | 標準二 |
|---|---|---|
| 依據 | 經濟部、107 台上 649 | §206 III（2018 增訂） |
| 判斷對象 | 董事本人 | 配偶、二親等內血親、控制從屬公司 |
| 方法 | 實質認定權利義務變動 | 列舉、**視為** |
| 特色 | 狹窄 | 擴張，但不能取代實質認定 |
