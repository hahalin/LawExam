# 公司法17 筆記：員工酬勞應於章程訂明、董事會特別決議與有限公司準用（§235-1、§110）

## 強制章定（選擇題超愛考）：
- 條文主詞是「公司」→ **公開發行、非公開發行**公司都適用
- 「**應**」於章程訂明，不是「得」→ 強制採用，公司不能說不想用
- 以**當年度**獲利狀況的**定額或比率**分派
  - 定額：固定金額，例如每年 500 萬元
  - 比率（經濟部，考過一次）：得訂**固定數**（2%）、**一定區間**（2%～5%）或**下限**（至少 1%）；**不能只訂上限**
  - 訂區間或下限時，**最終比率由董事會特別決議定之**

## 當年度獲利的計算：
- 以**稅前**利益計算（扣除分派員工酬勞前），不是稅後
- **一年發一次**：每年一個總額；總額內可一次發，也可分次發（例：500 萬元分清明 200 萬、中秋 200 萬、聖誕 100 萬）
- 只看當年度，不累積：賺的年度發、賠的年度不發
- 公司尚有**累積虧損**時，應先**彌補**才能發

## 決議與發放方式：
- 以**股票或現金**為之
- **董事會特別決議**＋**報告股東會**
  - 只要報告、不必股東會決議：分派比例已經寫在章程，股東會在訂章程時已經決定過
- 發股票時，董事會得同次決議以**發行新股**或**收買自己股份**為之
- 發放方式屬**董事會專屬**特別決議事項，**章程不得限制**只能發現金或只能發股票（經濟部不准登記）
- 細節（老師說看過即可）：
  - 以庫藏股發員工酬勞，須**單獨為 §235-1 買回**，不得挪用其他目的買回的股份（經濟部；劉連煜老師認為過嚴）
  - 劉連煜老師：以股份發放的員工酬勞是對過去一年的回報，**不得限制轉讓**（個人見解；字幕作「劉麗玉」，推定為劉連煜，建議查證）
- 章程得訂明對象包括**控制或從屬公司員工**（§235-1 V）

## 公營事業一律連結「核定」：
- 公營事業出現三次，只考選擇題；口訣：**公營事業＝核定**
  - **§235-1 II**：經主管機關核定，才適用員工酬勞
  - **§267 II**：經主管機關核定，得保留新股由員工承購，**不超過 10%**
  - **§156-2 V**：申請公開發行、停止公開發行，應先經主管機關核定

## 有限公司準用：
- §110 III 準用 §235-1 → 有限公司**也有員工酬勞制度**（選擇題）
- 有限公司沒有股份 → **只能發現金**
- 程序：董事造具表冊**分送各股東，請其承認**（§110 I）

## 📖 法條原文速查

> **§235-1**
> I　公司**應**於章程訂明以**當年度獲利狀況**之**定額或比率**，分派員工酬勞。但公司尚有**累積虧損**時，應予彌補。
> II　公營事業除經該公營事業之主管機關專案**核定**者，並於章程訂明員工分派酬勞之定額或比率外，不適用前項之規定。
> III　前二項員工酬勞以**股票或現金**為之，應由**董事會**以董事三分之二以上之出席及出席董事過半數同意之決議行之，並**報告股東會**。
> IV　公司經前項董事會決議以股票之方式發給員工酬勞者，得同次決議以**發行新股**或**收買自己之股份**為之。
> V　章程得訂明前項發給股票或現金之對象包括符合一定條件之控制或從屬公司員工。

> **§110 III**　第二百二十八條之一、第二百三十一條至第二百三十三條、第二百三十五條及**第二百三十五條之一**之規定，於有限公司準用之。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「非公開發行公司是否須於章程訂明員工酬勞？」 | **須**；公發、非公發都「**應**」章定 |
| 「員工酬勞比率得否只訂上限？」 | **不得**；固定數、一定區間或**下限** |
| 「獲利以稅前或稅後計算？」 | **稅前** |
| 「有累積虧損時可否分派員工酬勞？」 | 應**先彌補** |
| 「員工酬勞的決議？」 | **董事會特別決議**＋**報告**股東會 |
| 「章程得否規定員工酬勞只能發現金？」 | **不得**，屬董事會專屬事項 |
| 「有限公司有無員工酬勞？」 | **有**（§110 III 準用），**只能發現金** |
| 「公營事業適用員工酬勞的條件？」 | 經主管機關**核定** |

## 一、比率三種訂法（經濟部）

| 訂法 | 例 | 最終比率 |
|---|---|---|
| 固定數 | 2% | 2% |
| 一定區間 | 2%～5% | 董事會特別決議定之 |
| 下限 | 至少 1% | 董事會特別決議定之 |
| 只訂上限 | 最多 3% | **不可以** |

## 二、流程

```
章程訂明（應章定）定額或比率
   ↓ 當年度稅前獲利，先彌補累積虧損
董事會特別決議（股票或現金；股票得同次決定發新股或庫藏股）
   ↓
報告股東會
```
