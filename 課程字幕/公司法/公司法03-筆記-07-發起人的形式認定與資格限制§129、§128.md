# 公司法03 筆記：發起人的形式認定與資格限制（§129、§128）

## 誰是發起人：形式認定說：
- 發起人是**設立中公司的執行機關與代表機關**
- 多數說與實務採**形式認定說**：在**章程上簽名或蓋章**的人就是發起人
- 依據：§129「發起人應以**全體**之同意訂立章程……並**簽名或蓋章**」→ 每位發起人都要在章程上簽名蓋章
- 這個認定和後面的發起人責任接在一起：要叫某人負發起人責任，先確認他有在章程上簽名（見 公司法03-筆記-10）

## 自然人：要有完全行為能力：
- **無行為能力人、限制行為能力人、受輔助宣告尚未撤銷之人**，不得為發起人（§128 II）
- 受監護宣告者是無行為能力人，當然也不行
- 理由：發起人**責任很重**

## 政府與法人：
- 政府或法人均得為發起人（§128 III）；政府沒有限制
- 法人當發起人**只有三種**，是**列舉**不是例示：
  - **公司或有限合夥**
  - 以其**自行研發**之專門技術或智慧財產權作價投資之法人（買來、租來的不行；例：**工業技術研究院**）
  - 經目的事業主管機關認屬與其創設目的相關而予**核准**之法人（例：**醫院**財團法人申請設公司賣醫療產品）

## 📖 法條原文速查

> **§129**（發起人訂立章程）
> 發起人應以**全體之同意**訂立章程，載明下列各款事項，並**簽名或蓋章**：……（各款建議查閱最新六法原文）

> **§128**（發起人）
> I　股份有限公司應有**二人以上**為發起人。
> II　**無行為能力人、限制行為能力人或受輔助宣告尚未撤銷之人**，不得為發起人。
> III　政府或法人均得為發起人。但法人為發起人者，以下列情形為限：
> 　一、**公司或有限合夥**。
> 　二、以其**自行研發**之專門技術或智慧財產權**作價投資**之法人。
> 　三、經目的事業主管機關認屬與其創設目的相關而予**核准**之法人。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「如何認定發起人？」 | **形式認定**：章程上簽名或蓋章之人 |
| 「受輔助宣告之人可否為發起人？」 | **不可以**（尚未撤銷者） |
| 「財團法人以**購入**的專利作價投資，可否為發起人？」 | **不可以**，限**自行研發** |
| 「§128 III 法人得為發起人的情形是例示？」 | **列舉**，只有三種 |
| 「醫院（財團法人）未經核准，可否買已上市公司的股票？」 | 與 §128 **無關**：§128 限制的是**發起人**，不是股東 |

## 一、資格限制分流

```
誰可以當發起人（§128）
├── 自然人 → 須有完全行為能力（II）
│     ✗ 無行為能力、限制行為能力、受輔助宣告尚未撤銷
├── 政府 → 可以，無限制（III 本文）
└── 法人 → 限三種（III 但書，列舉）
      ├── 公司、有限合夥
      ├── 自行研發技術／智財作價投資（工研院）
      └── 主管機關核准（醫院）
```

## 二、陷阱題：發起人限制 ≠ 股東限制

- 題目：醫院是財團法人，未經許可可否買台積電股票？
- 台積電早已成立，買股票是當**股東**，不是當**發起人** → 跟 §128 一點關係都沒有
- 選擇題看到 §128 的要件，先確認題目問的是不是「發起人」

## 三、第二款的例子為什麼這麼少

- 能自行研發專門技術、智財的法人，通常本身就是**公司**，用第一款就解決
- 不是公司又能自行研發的，老師們舉得出的幾乎只有工研院
