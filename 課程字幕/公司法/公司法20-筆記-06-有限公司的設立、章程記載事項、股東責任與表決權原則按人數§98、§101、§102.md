# 公司法20 筆記：有限公司的設立、章程記載事項、股東責任與表決權原則按人數（§98、§101、§102）

## 有限公司這一章的定位：
- 一直都是**選擇題**的點，近幾年才有申論題（講義 17-18 以後的考題）
- 法條只有約 16 條，寫得不清楚 → 實務上產生很多問題
- 第 18 章重整前面已上過（見公司法05-筆記-06），本章是全課程最後一章

## 設立：
- 股東**一人以上**（§98 I、§2）；人數**無上限**；有限公司制度承襲德國法
- 股東以**全體同意**訂立章程，簽名或蓋章（§98 II）；股份有限公司發起人也是全體同意（§129），沒有特別
- **繳足出資**：資本總額由各股東**全部繳足**，**不得分期**、**不得向外招募**（§100）→ 法定資本制；用語只能寫「**資本總額**」（見公司法17-筆記-06）
- 設立登記（§387）自己看

## 章程絕對必要記載事項（§101 I），注意 ③ ④ ⑥ ⑦：
- ③ 股東姓名或名稱、④ 資本總額及各股東出資額 → 出資轉讓必然要**修章**（本講筆記-08 會用到）
- ⑥ **本公司**所在地 → 選擇題考過：有限公司設分公司**不必**寫進章程
- ⑦ 董事人數 → §108 會用到（本講筆記-10）

## 股東的責任與出資：
- 以**出資額**為限（§99 I）；股份有限公司是以**股份**為限（§2）
- §99 II（2018 新增）揭穿公司面紗，見公司法06-筆記-03
- 出資種類 §99-1：現金、對公司的貨幣債權、公司事業所需財產、技術 → **抄 §156 V**，完全一樣（見公司法06-筆記-06）

## 表決權（§102，選擇題超級愛考）：
- 原則：**不問出資多寡，每一股東一表決權**＝按**人數**
- 但書：得以**章程**訂定按出資多寡比例分配表決權
- 政府或法人為股東，準用 §181（§102 II）
- 經濟部固定見解：有限公司各種同意的比例**不得以章程提高**，除非法條明文；唯一明文是 **§29**（經理人委任、解任、報酬，章程得為較高規定）

## 📖 法條原文速查

> **§98**　I 有限公司由**一人以上**股東所組成。II 股東應以**全體之同意**訂立章程，簽名或蓋章，置於本公司，並每人各執一份。

> **§101 I**　公司章程應載明下列事項：一、公司名稱。二、所營事業。三、股東姓名或名稱。四、**資本總額及各股東出資額**。五、盈餘及虧損分派比例或標準。六、**本公司所在地**。七、**董事人數**。八、定有解散事由者，其事由。九、訂立章程之年、月、日。

> **§100 I**　公司資本總額，應由各股東**全部繳足**，不得分期繳款或向外招募。

> **§99 I**　各股東對於公司之責任，除第二項規定外，以其**出資額**為限。

> **§102**　I 每一股東**不問出資多寡，均有一表決權**。但得以章程訂定按出資多寡比例分配表決權。II 政府或法人為股東時，準用第一百八十一條之規定。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有限公司股東人數？」 | **一人以上**，無上限 |
| 「有限公司設分公司，應否記載於章程？」 | **不必**；§101 只要求**本公司所在地** |
| 「董事人數是否為章程絕對必要記載事項？」 | **是**（§101 I ⑦） |
| 「有限公司股東表決權的原則？」 | **每人一表決權**；章程得改按出資比例 |
| 「有限公司股東的責任？」 | 以**出資額**為限（股份有限公司是以股份為限） |
| 「有限公司資本得否分期繳納？」 | **不得**，全部繳足（§100） |
| 「有限公司章程得提高法定同意比例？」 | 經濟部：**不得**，唯一例外是 §29 經理人 |

## 一、表決權算給你看

```
有限公司股東 A、B、C、D；出資各為 70 萬、10 萬、10 萬、10 萬
章程未另訂 → 每人 1 票，共 4 票：B、C、D 同意＝3/4 過半數
章程訂按出資比例 → A 70%：A 一人反對，B、C、D 只有 30%
```

## 二、有限公司與股份有限公司對照

| | 有限公司 | 股份有限公司 |
|---|---|---|
| 股東人數 | 1 人以上 | 2 人以上或政府、法人 1 人 |
| 責任 | 以出資額為限 | 以所認股份為限 |
| 資本制 | 法定資本制（§100） | 授權資本制 |
| 表決權 | 原則按人數（§102） | 原則一股一權（§179） |
