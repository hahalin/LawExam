# 公司法16 筆記：建設股息與公積發放的比例、項目限制（§234、§241）

## 無盈餘不得分派的例外之一：建設股息：
- 原則：**無盈餘不得分派股息及紅利**（§232 II，見公司法15-筆記-08）
- 例外：**建設股息**（又稱**建業股息**），電腦圖 8-1 正下方「無盈餘」的例外
- 背景：§232 比美國嚴格；需要巨大資本、建設期很長的公司（老師舉興建高速鐵路的公司），開始營業前完全沒有收入，籌資困難 → 特別允許開業前就發股息吸引投資人
- 本質：還沒營業不可能賺錢，所以是把股東先繳的**出資返還一部分**（羊毛出在羊身上）
- 國考目前只剩**選擇題**，名稱不必背，要件要會

## 建設股息的要件（§234）：
- 設立登記**後**，依業務性質需**二年以上**準備才能開始營業
- 經**主管機關許可**＋**章程**規定（選擇題愛考「許可」：只寫在章程不夠）
- 於**開始營業前**分派
- 以**預付股息**列入資產負債表的股東權益項下；開業後每屆分派超過實收資本額 6% 時，以超過部分扣抵沖銷（後段知道即可）

## 公積的來源（講義 8-12 ~ 8-13）：
- **盈餘公積**
  - 法定盈餘公積：§237 I，有盈餘時**應**提 10%，是**法定額度**，不能多提少提；達實收資本額可不提，但要繼續提也可以（講義註 33）
  - 特別盈餘公積：§237 II，**得**以章程訂定或股東會（普通）決議另提；有特定用途，知道即可
- **資本公積**：會計上是股本買賣的價差；法科只記 §241 I 兩款
  - ① **發行溢價**（超過票面金額發行股票所得之溢額）
  - ② **受領贈與之所得**
  - 其他（如庫藏股買賣）不考

## 公積的用途（§239）：
- ① **彌補虧損**：順序是盈餘 → 法定盈餘公積 → 資本公積（見公司法15-筆記-09）
  - 好記的理由：法定盈餘公積本質上就是每年提出來的盈餘；只有資本公積來自股本，所以放最後
- ② **§241**：以公積發給新股或現金

## §241 的前提與特色：
- 前提：**無虧損**＝沒有**累積**虧損，不含本期虧損（講義註 35；詳見公司法15-筆記-09）
- 特色（講義 8-14 第一行）：只要沒有累積虧損，**即使沒有盈餘也能發**，可以把帳上的法盈、資本公積拿來發
  - 例：第一年虧 2 億、第二年賺 2 億，剛好打平，沒有盈餘可分 → 但帳上原有的資本公積、法盈仍可依 §241 發放

## 法盈限比例，資本公積限項目不限比例（電腦圖 8-5）：
- **法定盈餘公積：限比例**（§241 III）
  - 只有**超過實收資本額 25%** 的部分才能發 → 換句話說，必須**保留實收資本額的 25%**
  - 「超過」：剛好 25% 那部分不能發
  - 理由：留一點保障債權人
- **資本公積：限項目、不限比例**（§241 I）
  - 只限發行溢價、受領贈與所得兩項
  - 「**全部或一部**」→ 可以全發

## 📖 法條原文速查

> **§232 II**　公司**無盈餘時**，不得分派股息及紅利。

> **§234**
> I　公司依其業務之性質，自設立登記後，如需**二年以上**之準備，始能開始營業者，經**主管機關之許可**，得依**章程**之規定，於**開始營業前**分派股息。
> II　前項股息之分派，以**預付股息**列入資產負債表之股東權益項下，公司開始營業後，每屆分派股息及紅利超過實收資本額**百分之六**時，應以其超過之金額扣抵沖銷之。

> **§237**
> I　公司於完納一切稅捐後，分派盈餘時，應先提出**百分之十**為法定盈餘公積。但法定盈餘公積，已達實收資本額時，不在此限。
> II　除前項法定盈餘公積外，公司得以章程訂定或經股東會議決，另提特別盈餘公積。

> **§239 I**　法定盈餘公積及資本公積，除**填補公司虧損**外，不得使用之。但第二百四十一條規定之情形，或法律另有規定者，不在此限。

> **§241**
> I　公司**無虧損**者，得依前條第一項至第三項所定股東會決議之方法，將法定盈餘公積及下列資本公積之**全部或一部**，按股東原有股份之比例發給新股或現金：一、超過票面金額發行股票所得之**溢額**。二、**受領贈與**之所得。
> III　以法定盈餘公積發給新股或現金者，以該項公積**超過實收資本額百分之二十五**之部分為限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「無盈餘時可否於開始營業前分派股息？」 | 建設股息：設立登記後需**二年以上**準備＋**主管機關許可**＋**章程**規定（§234 I） |
| 「章程已定建設股息，未經主管機關許可，可否分派？」 | **不可以**，許可是要件 |
| 「建設股息在資產負債表的列法？」 | **預付股息**，列股東權益項下（§234 II） |
| 「法定盈餘公積提列比例可否自訂？」 | **不可以**，法定 10% |
| 「§241 可發放的資本公積？」 | **發行溢價**、**受領贈與所得** |
| 「以法盈發新股或現金的限制？」 | 限**超過實收資本額 25%** 的部分（§241 III） |
| 「實收資本 1,000 萬、法盈 600 萬，法盈最多可發多少？」 | 600 − 250 ＝ **350 萬** |
| 「以資本公積發放有無比例限制？」 | **無**，限項目不限比例，得全部發放 |

## 一、無盈餘時的分派體系

```
§232 II 無盈餘不得分派股息及紅利
   │
   ├── 例外一：建設股息（§234）
   │      設立登記後需 2 年以上準備 ＋ 主管機關許可 ＋ 章程
   │      → 開業前分派；列「預付股息」
   │
   └── 例外二：§241 公積發放
          前提：無累積虧損（沒有盈餘也可以）
          ├── 法定盈餘公積 → 限比例：保留實收資本額 25%
          └── 資本公積（溢價、受贈）→ 限項目、不限比例
```

## 二、法盈發放的算法（電腦圖 8-5 右下角）

| 項目 | 金額 |
|---|---|
| 實收資本額 | 1,000 萬 |
| 法定盈餘公積 | 600 萬 |
| 必須保留（1,000 × 25%） | 250 萬（不能發） |
| 最多可發 | 600 − 250 ＝ **350 萬** |

- 法盈累積到實收資本額（100%）就不必再提；最多只讓你發到剩 1/4，保留給債權人。

## 三、法盈與資本公積的比較

| | 法定盈餘公積 | 資本公積 |
|---|---|---|
| 來源 | 盈餘的 10% | 發行溢價、受領贈與所得（§241 I 兩款） |
| 本質 | 盈餘 | 股本相關 |
| 彌補虧損順序 | 先 | 後（§239 II） |
| §241 發放限制 | **限比例**（超過實收 25%） | **限項目、不限比例**（全部或一部） |
