# 公司法04 筆記：公司名稱不得相同與視為不相同（§18）

## 應使用我國文字：
- 公司名稱應使用**我國文字**（§18 I；公司名稱及業務預查審核準則 §5 亦同）
- 外文名稱另依 §392-1 申請登記（見 公司法04-筆記-10）

## 不得與他公司或有限合夥名稱相同：
- 比較對象只有**公司**與**有限合夥**，**不包括商號**
- 有限合夥依有限合夥法有法人格，也有**名稱專用權**

## 是否相同，只看特取名稱：
- 公司名稱分三塊：**特取名稱**＋**業務種類**＋**公司種類**
- 例：「大雄房屋股份有限公司」→ 大雄＝特取、房屋＝業務種類、股份有限公司＝公司種類
- 「大雄房屋」與「胖虎房屋」特取不同 → 不相同，合法

## 即使對方同意，相同名稱也不能用：
- 理由：消費者會**誤認**；名稱不是兩家公司私下能處分的事

## 類似名稱不禁止：
- 理由：①**減輕行政負擔**，「類似」涉及主觀判斷難期一致；②另有**公平交易法、商標法、民法**作事後審查
- 實務提醒：登記一定會過（形式審查），但**可能被告**

## 視為不相同的兩種方法（§18 I 後段）：
- **標明不同業務種類**：特取名稱可以相同（例：大雄房屋／大雄旅遊）
- **可資區別之文字**：經濟部採**負面表列**；表列的字等於**沒寫**

## 📖 法條原文速查

> **§18 I**（公司名稱）
> 公司名稱，應使用**我國文字**，且**不得與他公司或有限合夥名稱相同**。二公司或公司與有限合夥名稱中標明**不同業務種類**或**可資區別之文字**者，**視為不相同**。

> **公司名稱及業務預查審核準則**：可資區別文字採負面表列（字幕稱「第七條第三項」）→ 條次建議查閱最新法規原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司名稱是否相同，以何者判斷？」 | **特取名稱** |
| 「他公司同意時，可否使用相同名稱？」 | **不可以** |
| 「公司法是否禁止類似名稱？」 | **不禁止**（但可能依公平法、商標法、民法被告） |
| 「特取名稱相同，業務種類不同，是否合法？」 | **合法**，視為不相同 |
| 「在他人特取名稱前加『新』『老』『正港』？」 | **不可資區別**，視為相同 |
| 「業務種類後加『企業』『實業』『工業』？」 | **不可資區別** |
| 「名稱前加地區名（臺灣）？」 | **不可資區別**，地區名等於沒寫 |
| 「公司名稱不得與何者相同？」 | 他**公司**或**有限合夥**（不含商號） |

## 一、體系（電腦圖 2-13）

```
§18 I 公司名稱
├── 應使用我國文字
├── 不得相同（他公司、有限合夥）── 以「特取名稱」判斷
│     └── 即使對方同意也不行
├── 公司法並未禁止「類似名稱」→ 可登記，但可能被告
└── 視為不相同
      ├── 標明不同業務種類 → 特取名稱可以相同
      └── 可資區別之文字 → 經濟部採「負面表列」
```

## 二、不可資區別的文字（講義註 124，等於沒寫）

| 位置 | 不算數的字 |
|---|---|
| 一般 | 組織種類、有限合夥、**地區名**、國名、堂記、行號、社 |
| 特取名稱**前** | **新、好、老、大、小**、真、正、原、純、真正、純正、**正港、正統** |
| 特取名稱與業務種類相同時，業務種類**後** | **企業、實業、展業、興業、產業、工業**、商事、商業、商社、商行、事業 |

- 字幕「展業、新業」辨識不清，「新業」推定為「興業」→ **建議查證**講義註 124 原文
- 白話：寫「新大福餐飲」，經濟部只看得到「大福餐飲」

## 三、老師的例子（改為假名）

| 情形 | 登記 | 風險 |
|---|---|---|
| 特取名稱把兩家知名企業的名字連在一起（如「甲品乙納」） | 會過：特取整段是新的 | 兩家企業都可能提告 |
| 「福堂開發」之後另有人登記「福堂建設」「福堂營造」 | 會過：業務種類不同 | 先登記的公司提告；最高法院判決可以繼續使用名稱，但**不得用於廣告** |

## 四、例題（講義註 121）

- 甲在薩摩亞經商有成，回臺**依我國法設立**觀光旅遊業 → **本國公司**（準據法主義，見 公司法01-筆記-05）
- 已有「臺灣大發觀光」公司（原題特取名稱字幕辨識不清，改用假名）→「臺灣」是地區名，等於沒寫 → 對方特取名稱是「大發」

| 選項 | 可否 | 理由 |
|---|---|---|
| 薩摩亞商大發 | 不可 | 「○○商」只限外國公司在臺分公司；國名不算區別 |
| 新大發 | 不可 | 「新」不可資區別 |
| 大發興業 | 不可 | 「興業」不可資區別 |
| **大發旅遊** | **可** | 改變**業務種類** |
