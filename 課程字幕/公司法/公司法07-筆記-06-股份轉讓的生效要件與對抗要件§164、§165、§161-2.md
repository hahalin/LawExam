# 公司法07 筆記：股份轉讓的生效要件與對抗要件（§164、§165、§161-2）

## 為什麼要分生效要件與對抗要件：
- **生效要件**：處理**股東之間**（讓與人與受讓人）股份轉讓的效力 → 受讓人能不能在法庭上主張自己**合法取得股份**
- **對抗要件**：處理受讓人能不能**對公司**主張自己是股東 → 公司以**股東名簿**判斷（§169 I ①②：姓名或名稱、住所或居所、股數、股票號數）
- 對抗公司的實益：記載名簿後才能向公司**行使股東權**，最基本的是**表決權**與**盈餘分派**
- 老師比喻（健身房會籍）：甲把會籍賣給乙，兩人之間買賣生效是一層；但要讓健身房讓乙使用設施、向乙收費，必須到健身房**變更資料** → 這就是對抗

## 三種情形都要分兩個要件（電腦圖 4-12 右半部）：
- **未發行股票**：
  - 生效要件：法無明文，最高法院——當事人間**轉讓合意**（意思表示合致）即可
  - 對抗要件：變更**股東名簿**記載
  - 電腦圖 4-13：張三把 100 萬股轉給李四時簽了書面契約 → 是**證明文書**，**不是有價證券**，也不是生效要件；李四再轉給阿貓，不簽書面也照樣生效
  - 沒發股票時舉證麻煩 → 這就是發行股票方便轉讓的原因
- **實體股票**：
  - 生效要件：§164 **記名背書＋交付**（背書寫上自己名字，並記載受讓人姓名或名稱）
  - 對抗要件：§165 I 記載股東名簿
- **無實體股票**：
  - 上市、上櫃、興櫃：生效要件為**帳簿劃撥**（證交法 §43 II）；對抗要件為通知公司（證交法 §43 V，建議查證項次）→ 學證交法時再複習
  - 非上市櫃：生效要件為 §161-2 III **向公司辦理**（無法帳簿劃撥）；不適用 §164（沒有股票可背書）；對抗要件仍為 §165 **記載股東名簿**
  - §161-2 IV：公司已印製的股票未繳回者，不適用前項 → 仍依原本實體股票規定

## 空白背書（講義註 83、84，高考考過，國考未考）：
- 法律規定須**記名背書**；絕大多數法院見解：未記名背書不生轉讓效力（臺灣高等法院有少數見解認為有效）
- **105 台上 1223**（建議查證字號）：空白背書可以**授權他人填寫**受讓人姓名；但**填寫前**仍不生效力

## 📖 法條原文速查

> **§164**（記名股票之轉讓）
> 股票由股票持有人以**背書**轉讓之，並應將**受讓人之姓名或名稱記載於股票**。

> **§165 I**（股東名簿記載之效力）
> 股份之轉讓，非將受讓人之姓名或名稱及住所或居所，記載於公司**股東名簿**，**不得以其轉讓對抗公司**。

> **§161-2 III、IV**
> III 經證券集中保管事業機構登錄之股份，其轉讓及設定權利，應**向公司辦理**或以**帳簿劃撥**方式為之，**不適用第一百六十四條及民法第九百零八條**之規定。
> IV 前項情形，於公司已印製之股票未繳回者，不適用之。

> **§169 I ①②**（股東名簿）
> 股東名簿應編號記載下列事項：一、各股東之姓名或名稱、住所或居所。二、各股東之股數；發行股票者，其股票號數。→ 其餘各款建議查閱最新六法原文

> **證交法 §43 II、V**　帳簿劃撥交付、通知公司 → 建議查閱最新六法原文

## 📋 實務見解速查

> **最高法院**：未發行股票之公司，股份轉讓只需當事人間意思表示合致即生效力。
> **多數法院見解**：實體股票須記名背書始生轉讓效力。
> **105 台上 1223**（建議查證）：得授權他人填寫受讓人姓名，未填寫前不生效力。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「未記載股東名簿，股份轉讓不生效力？」 | ✕，股東名簿是**對抗要件**，轉讓仍生效 |
| 「未發行股票之公司，股份轉讓須訂立書面？」 | ✕，**意思表示合致**即可；書面只是證明文書 |
| 「未發行股票時所簽之轉讓書面為有價證券？」 | ✕ |
| 「實體股票之轉讓生效要件？」 | **記名背書＋交付**（§164） |
| 「非上市櫃之無實體股份轉讓，得依 §164 背書？」 | ✕，應**向公司辦理**（§161-2 III） |
| 「無實體股份轉讓後即可對抗公司？」 | ✕，非上市櫃仍須**記載股東名簿**（§165） |
| 「空白背書得授權他人補填？」 | 可以，但**填寫前不生效**（105 台上 1223） |

```
甲（讓與人） ──生效要件──→ 乙（受讓人）
                            │
                            │ 對抗要件：變更股東名簿
                            ▼
                         公司：名簿上寫誰，就讓誰
                               投票、領股利
```
