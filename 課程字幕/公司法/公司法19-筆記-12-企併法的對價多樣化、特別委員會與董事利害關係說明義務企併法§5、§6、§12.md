# 公司法19 筆記：企併法的對價多樣化、特別委員會與董事利害關係說明義務（企併法§5、§6、§12）

## 考試定位：
- 企併法：選擇題考過；申論題目前看起來會**附法條**，選擇題**不附**
- 老師：上課提到的條文看過、有印象即可

## 重點一：併購對價多樣化（講義 15-14）：
- 公司法限於股份；企併法得以股份、其他公司股份、現金或其他財產為對價（見本講筆記-09）

## 重點二：公開發行公司應設特別委員會（企併法 §6，講義 15-15 ~ 15-16）：
- **公開發行**公司於召開董事會決議併購事項**前**，**應**設置特別委員會（「應」不是「得」）
- 職權：就併購計畫與交易的**公平性、合理性**進行審議，將結果**提報**董事會及股東會
- 已設**審計委員會**者，由審計委員會行之
- 審議時應委請**獨立專家**協助，就換股比例或配發股東之現金或其他財產的合理性提供意見
- 只是**諮詢**、提供資訊：**沒有否決權**，也**沒有談判磋商權**
- 立法理由：提供**適當保護機制**，避免不公平、不合理的併購
- 程序變成：（公開發行公司）特別委員會審議 → 董事會決議合併契約 → 股東會特別決議

## 重點三：董事有自身利害關係的兩個義務（企併法 §5 III、IV，講義 15-14 ~ 15-15）：
- **說明義務**（§5 III）：向**董事會及股東會**說明自身利害關係的**重要內容**及**贊成或反對併購決議的理由**
- **敘明義務**（§5 IV）：公司應於**股東會召集事由中**敘明上述內容，並可置於證券主管機關或公司指定的網站，將網址載明於通知
- 兩個義務要說明的內容相同：自身利害關係＋贊成反對理由
- 董事會層級的利害關係說明義務對照公司法 §206 II（見公司法14-筆記-03）

## 重點四：股份收買請求權的技術性規定（企併法 §12，講義 15-16 國字四）：
- 價格未達成協議 → 由**公司**以全體未達成協議的股東為相對人，聲請法院裁定（字幕作「對全體股東提起訴訟」，程序性質建議查證）
- 程序費用、檢查人報酬由**公司負擔**；公平價格的舉證也由公司負擔
- 公司應先支付其認為**無爭議**的公平價格；股東應交存股票
- 併購時這一整塊專用企併法，公司法的程序不再適用；看標題即可

## 📖 法條原文速查

> **企併法 §6 I**　**公開發行股票之公司**於召開董事會決議併購事項前，**應設置特別委員會**，就本次併購計畫與交易之**公平性、合理性**進行審議，並將審議結果提報董事會及股東會。（但書略）
> **企併法 §6 II**　前項規定之特別委員會成員、職權等，由主管機關定之；設有**審計委員會**者，由審計委員會行之。（大意）
> **企併法 §6 III**　特別委員會或審計委員會進行審議時，應委請**獨立專家**協助就換股比例或配發股東之現金或其他財產之合理性提供意見。（大意）

> **企併法 §5 III**　公司進行併購時，公司董事就併購交易有**自身利害關係**時，應向**董事會及股東會說明**其自身利害關係之重要內容及**贊成或反對**併購決議之理由。

> **企併法 §5 IV**　前項情形，公司應於股東會**召集事由中敘明**董事利害關係之重要內容及贊成或反對併購決議之理由，其內容得置於證券主管機關或公司指定之網站，並應將其網址載明於通知。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公開發行公司併購前是否須設特別委員會？」 | **應**設置（企併法 §6） |
| 「特別委員會得否否決併購案？」 | **不得**；只有審議、提報，無否決權、無談判磋商權 |
| 「已設審計委員會者？」 | 由**審計委員會**行之 |
| 「董事有自身利害關係，應向誰說明？」 | **董事會及股東會**（企併法 §5 III） |
| 「說明的內容？」 | 利害關係**重要內容**＋**贊成或反對理由** |
| 「股東會召集通知要記載嗎？」 | **要**，於召集事由中敘明（§5 IV） |

## 一、公開發行公司的合併程序（企併法）

```
特別委員會（或審計委員會）審議公平性、合理性 ── 委請獨立專家
        ↓ 提報（僅供參考，無否決權）
董事會決議合併契約（有利害關係的董事：說明義務 §5 III）
        ↓ 召集事由中敘明利害關係（§5 IV）
股東會特別決議（企併法 §18）
```

## 二、董事利害關係的兩個義務

| | 說明義務 | 敘明義務 |
|---|---|---|
| 條文 | 企併法 §5 III | 企併法 §5 IV |
| 義務人 | 有利害關係的董事 | 公司 |
| 對象／場合 | 董事會、股東會 | 股東會召集事由 |
| 內容 | 利害關係重要內容＋贊成反對理由 | 同左 |
