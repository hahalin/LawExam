# 公司法09 筆記：書面電子投票的效力、撤銷與優先順序（§177-1、§177-2）

## 視為親自出席（§177-1 II 本文）：
- 「**視為**」親自出席 → 股東其實**沒有到場**，法律把他當成有到
- 股東會現場可能有三種案：**原議案**（事先列入）、**修正案**（一定是現場提出）、**臨時動議**（一定是現場提出）
- 人不在現場，後兩者怎麼辦，就是這一段的問題

## 書面電子投票後「未出席」：
- 原議案 → 依其書面電子投票
- 修正案、臨時動議 → **視為棄權**（§177-1 II 但書，明文）
- 經濟部：視為棄權者**計入出席股權數**，但**不計入同意的表決權數** → 實質上**等同反對**，效力很強

## 二日前送達、重複以最先為準（§177-2 I）：
- 書面電子的意思表示應於開會 **2 日前送達**公司
- 後段是另一件事：意思表示**重複**時以**最先送達**者為準，但聲明撤銷前意思表示者除外
- 經濟部（講義 5-52，沒考過）：書面投票若要用公司製發的票，宜在召集通知一併表明

## 投票後想親自出席：二日前以相同方式撤銷（§177-2 II）：
- 應於開會 **2 日前**，以**與行使表決權相同之方式**撤銷（電子投的就電子撤）
- **逾期撤銷** → 合法的書面電子投票仍存在 → 以**書面電子**行使的表決權為準
- 結論：**書面電子 ＞ 親自出席**；多數學者批評（本人反而比電子投票弱），立法是為了避免作業爭議

## 投票後「有出席」但未合法撤銷（經濟部，法無明文）：
- 會有爭議的前提是：**合法電子投票存在**，本人又到場；若已在 2 日前合法撤銷，就跟親自出席一樣，沒有問題
- 原議案 → 依書面電子投票（§177-2 II 明文）
- 修正案 → 自己**不得提出**；他人提出的，**視為棄權**。理由：修正案是**原議案的延長**，已經表示過意見
- 臨時動議 → 自己**得提出**，也**得行使表決權**。理由：沒有表示過意見的議案

## 書面電子＋委託書同時存在：以委託書為準（§177-2 III）：
- 兩者都合法有效時，以**委託代理人**出席行使的表決權為準（其中一個無效就沒有衝突）
- 最後一塊拼圖：**委託書 ＞ 書面電子 ＞ 親自出席**（§177 IV＋§177-2 II、III）

## 📖 法條原文速查

> **§177-1 II**（視為親自出席）　前項以書面或電子方式行使表決權之股東，**視為親自出席**股東會。但就該次股東會之**臨時動議**及原議案之**修正**，**視為棄權**。

> **§177-2**
> I 股東以書面或電子方式行使表決權者，其意思表示應於股東會開會**二日前送達**公司，意思表示有重複時，以**最先送達**者為準。但聲明撤銷前意思表示者，不在此限。
> II 股東以書面或電子方式行使表決權後，欲親自出席股東會者，應於股東會開會**二日前**，以**與行使表決權相同之方式**撤銷前項行使表決權之意思表示；**逾期撤銷**者，以**書面或電子方式**行使之表決權為準。
> III 股東以書面或電子方式行使表決權，**並**以委託書委託代理人出席股東會者，以**委託代理人**出席行使之表決權為準。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「以電子方式行使表決權之股東，法律上地位？」 | **視為親自出席** |
| 「電子投票股東未出席，對臨時動議及修正案？」 | **視為棄權**；計入出席數、不計同意數 → 實質等同反對 |
| 「電子投票意思表示應於幾日前送達？」 | **2 日前** |
| 「電子投票後欲親自出席，應如何撤銷？」 | 2 日前、以**相同方式**撤銷 |
| 「電子投票未撤銷又親自出席，原議案以何者為準？」 | 以**電子投票**為準 |
| 「同上情形，該股東得提出修正案？」 | ✕；他人提出的修正案**視為棄權** |
| 「同上情形，該股東得提出臨時動議並表決？」 | **可以**（經濟部） |
| 「同時電子投票並委託代理人出席，以何者為準？」 | **委託代理人**（§177-2 III） |

## 一、視為棄權的計算（電腦圖 5-8）

- A 公司已發行普通股 100 股；親自出席 60 股，電子投票 40 股（未到場）
- 現場出現修正案：現場 60 股中贊成 40、反對 20；電子 40 股視為棄權

| 算法 | 出席數 | 同意 | 結果 |
|---|---|---|---|
| 經濟部：計入出席、不計同意 | 100 | 40 | 未過半數 → 不通過 |
| 若不計入出席（對照） | 60 | 40 | 過半數 → 通過 |

→ 視為棄權實質上等於投反對票

## 三、三種議案的處理

| 議案 | 電子投票後未出席 | 電子投票後出席、未合法撤銷 |
|---|---|---|
| 原議案 | 依電子投票 | 依電子投票（§177-2 II） |
| 修正案 | 視為棄權（明文） | 自己不得提；他人提出視為棄權（經濟部） |
| 臨時動議 | 視為棄權（明文） | 自己得提、得表決（經濟部） |

## 四、優先順序總圖

```
委託書  ＞  書面電子  ＞  親自出席
  │            │
  │            └── §177-2 II：逾期撤銷以書面電子為準
  ├── §177-2 III：書面電子＋委託書 → 委託書
  └── §177 IV：逾期撤銷委託 → 委託代理人
```
