# 公司法16 筆記：通常發行新股與特殊發行新股的區分實益（§267、§156-3）

## 依發行目的區分（講義 10-6 ~ 10-8；電腦圖 10-1）：
- **通常發行新股**：又稱**現金發行新股**
  - 以**籌集資金**為目的
  - 股東繳錢，公司實質財產增加
- **特殊發行新股**：不是為了錢，而是有**其他事由**
  - 事由很多（股份交換、員工認股權、轉換公司債、附認股權公司債、認股權憑證、員工酬勞……），**不用背**

## 唯一的區分實益：有沒有新股認購權：
- 通常發行新股 → **有**新股認購權（§267 I ~ III，本講筆記-07）
- 特殊發行新股 → **沒有**
- 證交法的強制提撥一定比例對外公開發行，也只有通常發行新股才有；證交法乾脆直接寫「現金發行新股」

## 判斷方法：一個概念貫穿：
- 先問這次發行**有沒有任何特殊目的**
- 有任何目的 → **特殊**發行新股 → 沒有新股認購權
- 沒有特殊目的 → 那就是為了錢 → **通常**發行新股 → 有新股認購權
- 老師：「沒有理由也是一種理由」

## 理論上為什麼特殊發行沒有新股認購權：
- 認股權的例（電腦圖 10-2）：甲持有認股權（員工認股權也好、其他認股權也好），行使後要求乙公司發 **20 萬股** → 這 20 萬股就是為了給甲才發的；再讓員工、股東主張優先認購，理論上**不合**
- 員工酬勞的例（電腦圖 10-3）：乙公司以股份發員工酬勞，給員工丙 **12 萬股** → 這是因為丙是員工才給的；再談新股認購權也**無法融合**

## 法條也明文排除：
- **§156-3** 股份交換：發行新股作為受讓他公司股份的對價，董事會特別決議，**不受 §267 I ~ III 限制**（講義 3-11，見公司法06-筆記-05）
- **§267 V**：以**公積抵充**，核發新股予原有股東（公積轉增資）→ 不適用員工保留（I、II）
- **§267 VIII**：因**合併**他公司、**分割**、公司**重整**，或依 §167-2、§235-1、§262、§268-1 I 增發新股 → 不適用本條
- **§267 IX**：**限制員工權利新股** → 不適用 I ~ VI
- 走理論或走法條都可以，結論都是**沒有新股認購權**

## 📖 法條原文速查

> **§156-3**　公司設立後得發行新股作為受讓他公司股份之對價，需經董事會三分之二以上董事出席，以出席董事過半數決議行之，**不受第二百六十七條第一項至第三項之限制**。

> **§267**
> V　第一項、第二項所定保留員工承購股份之規定，於以**公積抵充**，核發新股予原有股東者，**不適用**之。
> VIII　本條規定，對因**合併**他公司、**分割**、公司**重整**或依第一百六十七條之二、第二百三十五條之一、第二百六十二條、第二百六十八條之一第一項而增發新股者，**不適用**之。
> IX　公司發行**限制員工權利新股**者，不適用第一項至第六項之規定……
> → VIII、IX 原文建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「通常發行新股的別稱？」 | **現金發行新股** |
| 「通常與特殊發行新股的區分實益？」 | **新股認購權**的有無 |
| 「公司以發行新股進行股份交換，員工、股東有無新股認購權？」 | **無**（§156-3） |
| 「轉換公司債轉換為股份時，股東可否主張新股認購權？」 | **不可以**，特殊發行新股 |
| 「以公積轉增資發新股，是否要保留員工承購？」 | **不必**（§267 V） |
| 「因合併增發新股，是否適用 §267？」 | **不適用**（§267 VIII） |
| 「發行限制員工權利新股，是否適用 §267 I ~ VI？」 | **不適用**（§267 IX） |

## 一、判斷流程

```
這次發行新股有沒有特殊目的？
   │
   ├── 有（股份交換、轉換、認股權、員工酬勞、合併、分割、重整、限制員工權利新股……）
   │      → 特殊發行新股 → 沒有新股認購權
   │
   └── 沒有 → 就是為了錢
          → 通常發行新股（現金發行新股）→ 有新股認購權（員工 → 股東 → 特定人）
```

## 二、排除新股認購權的法條

| 情形 | 條文 | 排除範圍 |
|---|---|---|
| 股份交換 | §156-3 | §267 I ~ III |
| 公積抵充發新股予原股東 | §267 V | 員工保留（I、II） |
| 合併、分割、重整、§167-2、§235-1、§262、§268-1 | §267 VIII | 本條全部 |
| 限制員工權利新股 | §267 IX | §267 I ~ VI |
