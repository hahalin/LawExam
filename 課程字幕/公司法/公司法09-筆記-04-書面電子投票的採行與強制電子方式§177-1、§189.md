# 公司法09 筆記：書面電子投票的採行與強制電子方式（§177-1、§189）

## 為什麼 2005 年新增書面電子投票（電腦圖 5-6）：
- 原本只有親自出席或委託書，問題有三：
  1. **受託人難找**：不能挨家挨戶問人能不能代為出席
  2. **場地要大**：所有人不是自己到、就是請人到，場地要容納全部
  3. **集中同一天**：各公司股東會擠在同一天，股東難分身
- 實務上公司不太愛用：股東都上網投完了，**很難徵求委託書**，也**無法在現場與股東溝通**

## 原則：得自由採用，載明於召集通知即可（§177-1 I 本文）：
- 公開發行、非公開發行公司**均得自由採用**
- 採行時，行使方法應**載明於股東會召集通知**
- 選擇題：採行書面電子投票**不需要修改章程**，因為條文只要求載明於召集通知

## 例外：主管機關得強制「電子」方式（§177-1 I 但書）：
- 證券主管機關得視公司規模、股東人數與結構等，命公司將**電子方式**列為表決權行使方式之一
- 選擇題陷阱：但書只有**電子**，**沒有書面**（公開發行公司股東太多，書面不好處理）
- 目前強制對象：**上市、上櫃、興櫃**公司

## 應採電子而未採：召集程序違法，得訴請撤銷（§189）：
- 依修法理由，應採電子方式而未採 → **召集程序違反法令** → 股東得依 §189 於決議之日起 **30 日內**訴請撤銷決議
- 實務上幾乎不會發生（上市櫃興櫃一看就知道，太容易被抓）
- §189 的完整說明在講義 5-103

## 📖 法條原文速查

> **§177-1 I**（書面電子投票）　公司召開股東會時，**得**採行以書面或電子方式行使其表決權；其以書面或電子方式行使表決權時，其行使方法應載明於股東會**召集通知**。但證券主管機關應視公司規模、股東人數與結構及其他必要情況，命其將**電子方式**列為表決權行使方式之一。→ 但書文字建議查閱最新六法原文

> **§189**（決議撤銷之訴）　股東會之**召集程序**或其**決議方法**，違反法令或章程時，股東得自決議之日起**三十日內**，訴請法院**撤銷**其決議。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「非公開發行公司得採行書面電子投票？」 | **可以**，公發、非公發均得自由採用 |
| 「採行書面電子投票須經章程訂定？」 | ✕，**載明於召集通知**即可 |
| 「主管機關得命公開發行公司採書面方式行使表決權？」 | ✕，但書只有**電子方式** |
| 「哪些公司應將電子方式列為表決權行使方式？」 | **上市、上櫃、興櫃**公司 |
| 「應採電子投票而未採，效果？」 | 召集程序違法 → 得依 **§189** 訴請撤銷 |

## 一、§177-1 I 的結構

```
§177-1 I
├── 本文：得採行書面或電子（自由）
│     └── 方法載明於召集通知（不必修章程）
└── 但書：主管機關命列「電子」方式
      ├── 對象：上市、上櫃、興櫃
      └── 違反 → 召集程序違法 → §189 撤銷
```

## 二、新增前後的比較

| | 只有親自＋委託書 | 加上書面電子投票 |
|---|---|---|
| 股東 | 自己去或找人去 | 可以不到場直接投 |
| 場地 | 要容納全部出席者 | 壓力減輕 |
| 公司派 | 可徵求委託書、現場溝通 | 委託書難徵求、無法現場溝通 |
