# 公司法20 筆記：有限公司的監察權、會計表冊視為承認、增減資與變更章程（§109、§110、§112、§106、§113）

## 監察權（§109，第一講已上，見公司法01-筆記-09）：
- **不執行業務股東**＝**非董事**的股東（經濟部），均得行使監察權
- 準用 §48：**隨時**向董事質詢營業情形、查閱財產文件帳簿表冊
- 得**代表公司**委託律師、會計師審核 → 費用由公司負擔；規避、妨礙、拒絕者處罰鍰
- 本講補充：查閱範圍**寬鬆認定**；最高法院甚至認為**取得出資額之前**的資料也可以查閱

## 會計（§110、§112）：
- §110 I：每屆會計年度終了，董事依 §228 造具表冊（營業報告書、財務報表、盈餘分派或虧損撥補議案），**分送各股東請其承認**，承認須股東表決權**過半數**同意
- §110 II：至遲於年度終了後 **6 個月內**分送；分送後**逾 1 個月未提出異議，視為承認** → 最特別的規定
- §110 III 準用季、半年盈餘分派（§228-1）、§231～§233、員工酬勞（§235-1）、§240 等，自己看；§110 IV 準用 §245 I 選派檢查人
- §112 I：先提 **10%** 法定盈餘公積，已達**資本總額**時免提 → 對照 §237 I（股份有限公司是**實收資本額**）
- §112 II：得以章程或股東表決權**三分之二以上**同意另提**特別盈餘公積**
- §112 III 準用 §239（公積用途、先用盈餘公積填補虧損）、§241（公積轉增資或發現金）；§241 原為股東會特別決議，準用後經濟部認為須**三分之二以上**同意

## 資本三原則：
- 資本確定：§100 全部繳足、不得分期或招募（本講筆記-06）
- 資本維持：§110、§112 用股份有限公司的會計程序落實
- 資本不變：§106 增減資

## 增資、減資、變更組織（§106），都只要過半數：
- **增資**：股東表決權**過半數**同意；但同意增資者**沒有**按原出資比例出資的**義務** → 對照 §267 股份有限公司也是新股認購「權」不是義務
- 有前述情形時，得經過半數同意**由新股東參加**
- **減資**、**變更組織**為股份有限公司：也是過半數（變更組織見公司法05-筆記-10）
- **不同意的股東**，對章程因增資、減資、變更組織而修正的部分，**視為同意** → 這三件事修章不必三分之二

## 變更章程、合併、解散（§113）：
- 股東表決權**三分之二以上**同意（選擇題很愛考）
- 變更章程、合併、解散、清算，其餘準用無限公司規定（§113 II）

## 考題（講義 17-18 ~ 17-32，自己看）：
- 2023（17-18）：有限公司股東的資訊權（見講義 6-75）、表決權拘束契約可否類推、變更組織
- 2022（17-29 ~ 17-30）：1970 年設立的公司章程寫修章須**全體同意**（2018 年前 §113 準用無限公司＝全體同意），現行法已改為三分之二 → 依章程還是依現行法？
  - 經濟部、劉連煜：依**現行法**
  - 法院（講義 17-30）：**尊重章程**，須全體同意；邵慶平：章程也可以
  - 可轉化為：現行法下**章程得否提高**修章比例到全體同意 → 經濟部一定說**不行**（本講筆記-06）
- 2014 司法官（17-32）：代位請求權基礎可否類推，自己看

## 📖 法條原文速查

> **§110 I、II**　每屆會計年度終了，董事應依第二百二十八條之規定，造具各項表冊，分送各股東，請其承認；其承認應經股東表決權**過半數**之同意。前項表冊，至遲應於每會計年度終了後**六個月內**分送。分送後**逾一個月未提出異議者，視為承認**。

> **§112 I**　公司於彌補虧損完納一切稅捐後，分派盈餘時，應先提出百分之十為法定盈餘公積。但法定盈餘公積已達**資本總額**時，不在此限。

> **§106**　I 公司增資，應經股東表決權**過半數**之同意。但股東雖同意增資，仍**無按原出資數比例出資之義務**。II 有前項但書情形時，得經股東表決權過半數之同意，由**新股東參加**。III 公司得經股東表決權過半數之同意**減資**或**變更其組織**為股份有限公司。IV 前三項不同意之股東，對章程因增資、減資或變更組織而修正部分，**視為同意**。

> **§113**　I 公司變更章程、合併及解散，應經股東表決權**三分之二以上**之同意。II 除前項規定外，公司變更章程、合併、解散及清算，準用無限公司有關之規定。
> → §112 III 準用 §241 的範圍（款項）建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有限公司會計表冊分送後多久未異議視為承認？」 | **1 個月** |
| 「表冊承認的同意門檻？」 | 股東表決權**過半數** |
| 「有限公司法定盈餘公積提到何時免提？」 | 達**資本總額**（股份有限公司是實收資本額） |
| 「有限公司增資、減資、變更組織的門檻？」 | 都是**過半數** |
| 「同意增資的股東須按比例出資？」 | **不必** |
| 「不同意增資的股東，對修章部分？」 | **視為同意** |
| 「有限公司變更章程、合併、解散？」 | **三分之二以上** |

## 一、門檻總整理（有限公司，以股東表決權計）

| 事項 | 門檻 | 條文 |
|---|---|---|
| 會計表冊承認 | 過半數（1 個月未異議視為承認） | §110 |
| 特別盈餘公積 | 章程或三分之二以上 | §112 II |
| 增資、減資、變更組織 | 過半數（不同意者視為同意修章） | §106 |
| 出資轉讓 | 其他股東過半數（董事三分之二） | §111（本講筆記-08） |
| 董事選任、董事競業許可 | 三分之二以上 | §108 I、III |
| 變更章程、合併、解散 | 三分之二以上 | §113 I |
