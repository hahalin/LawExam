# 公司法16 筆記：員工與原有股東的新股認購權及洽特定人認購（§267）

## 發行新股的利弊（講義 10-3）：
- 實收股本增加 → **股權稀釋**；賺的錢不變時，每股盈餘（EPS）下降 → 公司會慎重考慮
- 好處：拿到錢**不用還**（老師的誇張講法：印股票換鈔票）

## 新股認購權：是權利不是義務：
- 通常發行新股時，**員工**與**股東**有優先於他人認購的權利，稱為**新股認購權**（§267 I ~ III）
- 是**權利**，可以認，也可以不認
- 順序：**員工 → 股東 → 公開發行或洽特定人**
- 只有**通常發行新股**（現金增資）才有；特殊發行新股沒有（本講筆記-11）

## 員工新股認購權（§267 I、II）：
- 立法目的：促進**勞資融合**
- **民營**（§267 I）：**應**保留發行新股總數 **10% ~ 15%** 由員工承購
  - 是「應」不是「得」→ **強制保留**
  - **法定上下限**：不能低於 10%，也不能高於 15%（選擇題）
  - 「除經目的事業中央主管機關專案核定者外」：老師說實務上沒看過核定
- **公營**（§267 II）：經公營事業主管機關**專案核定**，**得**保留，但**不得超過 10%**
  - 公司法提到公營事業只有三處，看到就是選擇題：§156-2 V（見公司法07-筆記-10）、§267 II、§235-1 II
- 經濟部：**不區分普通股、特別股**，要**分別保留**（講義註 2、3）
  - 例：同次發行特別股 60 萬股、普通股 40 萬股，保留 10% → 特別股 6 萬股、普通股 4 萬股
  - 不可以合在一起，全部改給同一種股份（特別股、普通股數字依字幕推定，建議查證講義註 3）

## 原有股東新股認購權（§267 III）：
- 扣除員工保留部分後，**公告及通知**原有股東，按**原有股份比例儘先分認**
  - 現在股票都記名 → 實際上是**通知**；公告用於修法前已發行的無記名股票
- 應聲明**逾期不認購者喪失其權利** → 有一段**認股期間**（本講筆記-10）
- 不足分認一新股：**合併共同認購**（例：0.3 股＋0.7 股合認一股，共有）或**歸併一人認購**（把 0.3 讓給他人去認）
- 性質：經濟部認為是**固有權**，不得剝奪；也不分普通股、特別股
- 員工不論認不認，剩下的都往下流到股東

## 員工、股東都不認：公開發行或洽特定人：
- **公開發行公司**：可以**公開發行**，也可以**洽特定人**
- **非公開發行公司**：只能**洽特定人**（不可能公開發行）
- **特定人**：經濟部認為**沒有身分限制**，不限原有股東及員工，由**董事會**決定（講義 10-6、10-8）
- 實例（老師舉真實案例，公司名改稱）：
  - **甲金控（2010 年）**：須補足資本適足率，只能發新股；正逢金融海嘯，股價下跌，員工認購 0、股東認購 0 → 沒有選擇公開發行（內部都不買，外人更不會買）→ 洽特定人，由公股銀行認購
  - **乙航空公司**：創辦人持股近七成，想引進新股東 → 對員工只能**勸**少認，不能強迫放棄；創辦人自己在股東階段大幅放棄 → 洽特定人（其親屬）認購

## 證交法的插隊：
- 公開發行公司現金增資，另有證交法 §28-1 的**強制提撥 10% 對外公開發行**，位在員工與股東之間（證交法再學）

## 📖 法條原文速查

> **§267**
> I　公司發行新股時，除經目的事業中央主管機關專案核定者外，**應**保留發行新股總數**百分之十至十五**之股份由公司員工承購。
> II　**公營事業**經該公營事業之主管機關**專案核定**者，得保留發行新股由員工承購；其保留股份，**不得超過**發行新股總數**百分之十**。
> III　公司發行新股時，除依前二項保留者外，應**公告及通知原有股東**，按照原有股份比例**儘先分認**，並聲明**逾期不認購者，喪失其權利**；原有股東持有股份按比例不足分認一新股者，得**合併共同認購**或**歸併一人認購**；原有股東未認購者，得**公開發行**或**洽由特定人認購**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「新股認購權是權利或義務？」 | **權利**，可以不認購 |
| 「民營公司保留員工承購比例？」 | **應**保留 **10% ~ 15%**，法定上下限，不得增減 |
| 「民營公司章程定員工保留 20%，效力？」 | **違法**，超過上限 |
| 「公營事業員工承購比例？」 | 專案核定，**不得超過 10%** |
| 「同次發行普通股與特別股，員工保留如何計算？」 | **分別保留**（經濟部） |
| 「原有股東新股認購權的性質？」 | **固有權**（經濟部） |
| 「非公開發行公司員工、股東均未認購？」 | 只能**洽特定人**認購 |
| 「特定人有無身分限制？由誰決定？」 | **無**；由**董事會**決定（經濟部） |

## 一、新股認購的順序

```
通常發行新股（現金增資）
   ↓
① 員工：民營應保留 10%~15%（§267 I）／公營核定 ≤ 10%（§267 II）
   ↓ （公開發行公司另有證交法 §28-1 提撥 10% 對外公開發行）
② 原有股東：按比例儘先分認（§267 III），逾期喪失
   ↓ 未認購
③ 公開發行公司 → 公開發行 或 洽特定人
   非公開發行公司 → 只能洽特定人
```

## 二、員工與股東新股認購權比較

| | 員工 | 原有股東 |
|---|---|---|
| 條文 | §267 I、II | §267 III |
| 比例 | 民營 10% ~ 15%；公營 ≤ 10% | 其餘部分按持股比例 |
| 目的 | 勞資融合 | 維持持股比例（固有權） |
| 普通股、特別股 | 分別保留 | 都適用 |
| 獨立轉讓 | 不得（本講筆記-08） | 得 |

| 實務見解 | 要旨 |
|---------|------|
| **經濟部（講義註 2、3）** | 員工保留不分普通股、特別股，分別保留 |
