# 公司法03 筆記：公司不能成立時發起人負連帶責任（§150、民法§681）

## 股份有限公司：§150：
- 公司**不能成立**時，發起人就①**公司設立所為之行為**②**設立所需之費用**，負**連帶責任**；因冒濫經裁減者亦同
- §150 在 §128 之後 → 只適用於**股份有限公司**
- 只有**發起人**負責，**認股人**被排除 → 保護募集設立的認股人，認股人只就所認股份負責，反而像債權人，可向發起人取回股款

## 無限、有限、兩合公司：民法 §681：
- 沒有 §150 這種條文 → 用**發起人合夥**處理（見 公司法03-筆記-04）
- 合夥財產不足清償合夥債務時，各合夥人對不足之額**連帶**負責
- 設立中公司雖是無權利能力社團，但背後有發起人合夥 → 實務見解同樣由發起人負連帶責任

## 結論一句話：
- 不管哪一種公司，**公司不成立 → 發起人連帶責任**，只是說理不同
- 公司不成立時，**不必區分**設立必要費用與開業準備行為，結果殊途同歸（區分只在公司成立時才有意義，見 公司法03-筆記-08）

## 📖 法條原文速查

> **§150**（公司不能成立時發起人之責任）
> 公司**不能成立**時，**發起人**關於公司設立所為之**行為**，及設立所需之**費用**，均應負**連帶責任**，其因冒濫經裁減者亦同。

> **民法 §681**（合夥人之補充連帶責任）
> 合夥財產不足清償合夥之債務時，各合夥人對於不足之額，**連帶**負其責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股份有限公司不能成立，誰對設立費用負責？」 | **發起人連帶**（§150） |
| 「募集設立的認股人要不要依 §150 負責？」 | **不用**，§150 只規定發起人 |
| 「有限公司不能成立時，依據？」 | 發起人合夥 → **民法 §681** |
| 「公司不能成立時，需否區分設立必要費用與開業準備行為？」 | **不需要**，一律由發起人連帶負責 |
| 「§150 適用於哪一種公司？」 | **股份有限公司**（條號在 §128 之後） |

## 一、依公司種類分流

```
公司不能成立
├── 股份有限公司 → §150：發起人連帶（認股人不負）
└── 無限／有限／兩合 → 發起人合夥 → 民法 §681：發起人連帶
                         ↓
           結論相同：發起人負連帶責任
```

## 二、用數字走一次

- 甲、乙、丙三人發起設立 A 股份有限公司，籌備期間以「A 公司籌備處」名義租辦公室，欠租金 60 萬元；後來 A 公司設立失敗
- 出租人可以向甲、乙、丙**任何一人**請求全部 60 萬元（§150 連帶）
- 若是募集設立，認股人丁已繳股款 30 萬元：丁**不必**分擔租金，還可以向發起人請求返還股款

## 三、條號定位小技巧（公司法01 教過）

- §128 起是股份有限公司章 → §150 必然只適用股份有限公司，選擇題拿來問有限公司時直接排除
