# 公司法03 筆記：發起人合夥、設立中公司與同一體說（§6）

## 設立程序五步：
- **訂立章程**：組織與活動的基本規則
- **確定股東**：發起設立只有發起人（§131）；募集設立有發起人（§132、§133）與認股人（§138、§139）
- **確定資本**：發起設立由發起人認足；募集設立發起人至少 1/4、認股人最多 3/4（見 公司法03-筆記-03）
- **設立機關**：選任董事、監察人（發起設立 §131；募集設立由創立會 §146）
- **設立登記**：公司非在中央主管機關登記後，不得成立（§6）

## 設立登記前後兩個變化：
- 董監事雖已選出，**設立登記後才能執行業務**；登記前由**發起人**執行
- 「發起人」「認股人」只存在於登記前；登記後一律稱為**股東**

## 發起人合夥與設立中公司是兩個東西：
- **發起人合夥**（學說，法條沒有）：訂立章程**之前**，發起人間先締結**合夥契約**，用來說明發起人間的**內部關係**
- **設立中公司**：從**訂立章程**起到**設立登記完成**止
- 兩者開始時點不同，結束時點相同（設立登記完成）
- 登記後：設立中公司 → **成立後公司**，取得法人格；發起人合夥 → **目的達成而解散**
- 關聯：設立中公司的機關是**發起人**；發起人依**合夥契約**行使權限、履行設立義務

## 設立中公司的性質與同一體說：
- 多數說：設立中公司是**無權利能力社團**，發起人是其代表；沒有法人格
- **同一體說**：設立中公司與成立後公司為同一體，**猶如自然人之胎兒**；超越人格之有無，權利義務**無須移轉，當然繼受**
- 理由：①構成員與機關相同（發起人、認股人變股東；董監事延續）②避免公司成立後**不承認**的流弊

## 📖 法條原文速查

> **§6**（設立登記）
> 公司非在中央主管機關**登記**後，不得**成立**。

> **§131 I**（發起設立選任董監）
> 發起人認足第一次應發行之股份時，應即按股繳足股款並**選任董事及監察人**。

> **§146 I**（創立會選任董監）
> 創立會應**選任董事、監察人**。→ 其餘各項建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「設立中公司的性質？」 | 多數說：**無權利能力社團** |
| 「設立中公司的機關？」 | **發起人** |
| 「設立中公司與成立後公司的關係？」 | **同一體說**：權利義務當然繼受，無須移轉 |
| 「發起人合夥與設立中公司是否同一？」 | **不同**；登記後前者解散、後者成為成立後公司 |
| 「設立登記前選出的董事可否執行業務？」 | **不可以**，登記後才能執行；登記前由發起人執行 |
| 「公司何時取得法人格？」 | **設立登記**完成（§6） |

## 一、時間軸（老師板書）

```
發起人合夥 ─────────────────────────┐ 解散（目的達成）
（合夥契約）                         │
     訂立章程 → 確定股東 → 確定資本 → 選董監 → 設立登記（§6）
     └──────────── 設立中公司 ────────────┘ → 成立後公司（有法人格）
                 （無權利能力社團）          發起人、認股人 → 股東
                                              董監事 → 開始執行業務
```

## 二、為什麼要同一體說（小夫公司例）

- 公司設立過程中不可能完全不為法律行為，例如**租辦公室**
- 簽約名義要用「**小夫公司籌備處**」（不用籌備處會違反 §19，見 公司法03-筆記-06）
- 問題：無權利能力社團簽的約，權利義務怎麼「過渡」到成立後有法人格的小夫公司？
- 同一體說：兩者人格上同一，像小時候取得的汽車，長大後當然還是自己的；不必再辦移轉

## 三、為什麼選合夥契約

- 學者要從民法有名契約中挑一個說明發起人間的關係：買賣、委任、合會、居間都不合
- 合夥最貼近「大家一起出資完成共同目的」；且合夥人對合夥債務負**無限責任**（後面公司不能成立時會用到，見 公司法03-筆記-05）

| | 發起人合夥 | 設立中公司 |
|---|---|---|
| 依據 | 學說 | 學說 |
| 開始 | 訂立章程前 | 訂立章程時 |
| 結束 | 設立登記完成 → 解散 | 設立登記完成 → 成為成立後公司 |
| 性質 | 民法合夥 | 無權利能力社團 |
| 功能 | 發起人間內部關係 | 對外法律關係的主體 |
