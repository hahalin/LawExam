# 公司法06 筆記：股東有限責任原則與揭穿公司面紗（§154、§99）

## 股東有限責任原則：
- 股份有限公司股東：對公司責任以**繳清其股份之金額**為限（§154 I）
- 有限公司股東：對公司責任以其**出資額**為限（§99 I）
- 履行出資義務後，對公司**沒有其他義務**
- 學理來源：**公司法人格**。債權人只能向公司求償，債權被法人格擋住，穿不過去向股東求償
- 全世界學者、法院的共識：公司法若只能留一個原則，就是**股東有限責任原則** → 不可輕易推翻

## 例外：揭穿公司面紗（§154 II＝§99 II，文字完全相同）：
- 要件：①股東**濫用公司法人地位** ②致公司負擔**特定債務** ③**清償顯有困難** ④**情節重大而有必要**
- 效果：**該股東**應負清償之責 → 債權人可以**向股東請求公司欠的債**
- 只能向**控制股東**求償：小股東沒有能力濫用法人地位
- 「清償顯有困難」：公司有錢還，就沒有揭穿的必要
- 有限公司、股份有限公司**都有**此規定，選擇題考過兩次以上

## 美國法來源與五要件：
- Piercing the Corporate Veil：veil 指法人格（corporate entity）；符合要件時法人格**虛化**，債權穿過法人格向股東求償
- 公司被當成股東的 **alter ego**（分身）或 **instrumentality**（工具）
- 五要件：**控制**、**形態不遵守**（不開股東會、沒有員工等）、**資本嚴重不足**、**資產混淆**（股東常向公司借錢、挪用公司資產）、**詐欺**（fraud）
- 詐欺不是刑法 §339：指利用公司形態取得自然人本來沒有的**有限責任利益**的惡意
- 美國法院沒說要符合幾個；張心悌老師（字幕「張新毅」，建議查證）觀察：法院較看重**控制**與**詐欺**

## 適用：例外從嚴：
- 堅守**最後手段性**（輔助性）
- 沒有單一決定性因素，綜合個案一切因素判斷
- 三個判準：①§154 II 要件 ②立法理由：**股東人數**、**股權集中程度** ③美國法五要件
- 股東人數**越少**、股權**越集中** → 越容易揭穿（才找得出誰在操控）
- 立法理由另列「新增債務是否源於詐欺行為、資本是否顯不足承擔」，老師認為即美國法判準，不必另背

## 📖 法條原文速查

> **§154**（股份有限公司股東責任）
> I 股東對於公司之責任，除第二項規定外，以**繳清其股份之金額**為限。
> II 股東**濫用公司之法人地位**，致公司負擔**特定債務**且**清償顯有困難**，其**情節重大而有必要**者，該股東應負清償之責。

> **§99**（有限公司股東責任）
> I 各股東對於公司之責任，除第二項規定外，以其**出資額**為限。
> II 股東濫用公司之法人地位，致公司負擔特定債務且清償顯有困難，其情節重大而有必要者，該股東應負清償之責。

## 📋 學說見解速查

> **劉連煜老師**：①法條「特定」二字是多餘的，只要是債務即可（字幕作「最穩」，推定為「贅文」，建議查證）②法人股東須證明有**不法目的** ③自然人股東限於**閉鎖性公司**才適用 ④應多用 §8 III 事實上董事（見 公司法02-筆記-04），不要浮濫使用 §154 II。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「揭穿公司面紗原則只適用於股份有限公司？」 | **錯**，§99 II 有限公司也有，文字與 §154 II 相同 |
| 「揭穿公司面紗的效果？」 | **該股東**對公司的特定債務負清償之責 |
| 「公司資力充足，債權人可主張揭穿公司面紗？」 | **不可**，須**清償顯有困難** |
| 「持股極少的股東也可能被揭穿？」 | 原則否，須能**濫用**法人地位（控制股東） |
| 「立法理由列的審酌因素？」 | **股東人數**、**股權集中程度**（另有詐欺、資本顯不足） |
| 「股東人數越多越容易揭穿？」 | **錯**，人數少、股權集中才容易 |
| 「美國法揭穿公司面紗五要件？」 | 控制、形態不遵守、資本不足、資產混淆、詐欺 |
| 「揭穿公司面紗的適用原則？」 | 例外從嚴、最後手段性、綜合一切因素 |

## 一、法人格與求償路線

```
原則（有限責任）
債權人甲 ──1,000 萬──→ 甲公司（法人格）╳ 擋住 → 股東
                                    （母公司持股 99%、其他股東 1%）

例外（§154 II 要件具備）
債權人甲 ──1,000 萬──→ 甲公司（法人格虛化、出現破洞）
                         └──穿過──→ 控制股東（母公司）負清償之責
                                    其他 1% 股東 ╳ 不負責
```

- 老師舉的是某外商電子公司的公害案件，母公司持股 99%（公司名改稱甲公司、母公司）。

## 二、考題：侵權債權人（講義 3-7 頁，2009 年法研所考題，校名字幕不清，建議查證）

### 事實
1. 甲等七人以**嚴重不足的資本**設立 A 公司等五家公司
2. 五家公司使用**同一營業處所**，員工、股東為同一批人，名片同時印五家公司
3. 各公司間**無息借貸資金**
4. A 公司的侵權行為被害人乙，主張股東也應負賠償責任

### 分析
- 法律依據：§154 II（或 §99 II）
- 對應五要件：資本嚴重不足 ✓、形態不遵守（五家共用處所、人員）✓、資產混淆（無息借貸）✓
- 為何強調**侵權**：契約債權人締約時可以評估對方償債能力；侵權被害人**無法選擇債務人** → 更應容許揭穿
