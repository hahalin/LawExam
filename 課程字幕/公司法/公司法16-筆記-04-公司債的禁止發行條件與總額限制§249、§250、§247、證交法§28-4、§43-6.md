# 公司法16 筆記：公司債的禁止發行條件與總額限制（§249、§250、§247、證交法§28-4、§43-6）

## 有擔保與無擔保的區分實益：
- 有擔保＝有設定擔保物權；無擔保＝沒有（講義 9-6）
- 區分實益兩個：
  - ① **禁止發行條件不同**（§249、§250）
  - ② **總額限制不同**（§247、證交法 §28-4、§43-6）
- 兩者都**只考選擇題**；老師建議一試進考場前翻一下 §249、§250（連同 §269、§270，見本講筆記-09）

## 判斷核心：利息付不付得出來：
- **§250：完全不得發行公司債**（最嚴格）
  - ① 前已發行的公司債或其他債務有違約或遲延支付本息，**尚在繼續中**
  - ② 最近三年平均稅後淨利，未達擬發公司債年息總額的 **100%**；但經**銀行保證**者不受限制
- **§249：不得發行無擔保公司債**（有擔保仍可發）
  - ① 曾有違約或遲延支付本息的事實**已了結**，自**了結之日起三年內**
  - ② 最近三年平均稅後淨利，未達年息總額的 **150%**
- 背法：100%＋繼續中 → 全不准；150%＋了結三年內 → 只准有擔保
- 老師個人見解：§250 ① 有點歧視欠錢的人，但一般人也不願借錢給欠錢不還的人

## 考題（講義 9-7 註 11）：
- 甲公司最近三年平均淨利 **500 萬**，從未發過公司債（沒有違約問題）
- 擬發行總額 **1 億元、年息 3.5%** 的公司債 → 每年利息 **350 萬**
- 500 ÷ 350 ≈ 143% → 達 100%、未達 150%
- → **可以發有擔保**，**不能發無擔保**（答案 B）

## 總額限制的四種情形（電腦圖 9-2）：
- **公開發行公司＋募集（公開發行）** → 證交法 §28-4，**不受 §247 限制**
  - 有擔保、轉換、附認股權：≤ 淨值（全部資產減全部負債）的 **200%**
  - 前款以外的無擔保（只剩**無擔保普通公司債**）：≤ 淨值的 **1/2**
- **公開發行公司＋私募普通公司債** → 證交法 §43-6 III：≤ 淨值的 **400%**，**不受 §247 限制**
- **公開發行公司＋私募轉換、附認股權公司債** → 剩下這兩種才用**公司法 §247**
  - 總額 ≤ 淨值；無擔保 ≤ 淨值的 1/2
  - 理由：§247 明文限**公開發行股票公司**；立法理由也寫明私募轉換、附認股權公司債仍受 §247 限制（講義註 9）
- **非公開發行公司＋私募** → **無總額限制**
  - §247 限公開發行公司，無從適用
  - 閉鎖性公司 §356-11 明文不適用 §247
  - 非閉鎖性的也一樣：立法理由說為便利籌資，私募總額**無限制**（講義註 10）
  - 考題（講義 9-6 註 6）：非公發公司私募普通公司債最多多少？→ **無上限**（答案 D）

## 📖 法條原文速查

> **§249**　公司有下列情形之一者，**不得發行無擔保公司債**：
> 一、對於前已發行之公司債或其他債務，曾有違約或遲延支付本息之事實**已了結**，自了結之日起**三年內**。
> 二、最近三年或開業不及三年之開業年度課稅後之平均淨利，未達原定發行之公司債，應負擔年息總額之**百分之一百五十**。

> **§250**　公司有下列情形之一者，**不得發行公司債**：
> 一、對於前已發行之公司債或其他債務有違約或遲延支付本息之事實，**尚在繼續中**者。
> 二、最近三年或開業不及三年之開業年度課稅後之平均淨利，未達原定發行之公司債應負擔年息總額之**百分之一百**者。但經**銀行保證**發行之公司債不受限制。

> **§247**
> I　**公開發行股票公司**之公司債總額，不得逾公司現有全部資產減去全部負債後之餘額。
> II　**無擔保**公司債之總額，不得逾前項餘額**二分之一**。

> **證交法 §28-4**　已依本法發行股票之公司，募集與發行公司債，其發行總額，除經主管機關徵詢目的事業中央主管機關同意者外，依下列規定辦理，**不受公司法第二百四十七條規定之限制**：
> 一、有擔保公司債、轉換公司債或附認股權公司債，其發行總額，不得逾全部資產減去全部負債餘額之**百分之二百**。
> 二、前款以外之無擔保公司債，其發行總額，不得逾全部資產減去全部負債餘額之**二分之一**。

> **證交法 §43-6 III**　**普通公司債之私募**，其發行總額，除經主管機關徵詢目的事業中央主管機關同意者外，不得逾全部資產減去全部負債餘額之**百分之四百**，不受公司法第二百四十七條規定之限制。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「違約遲延支付本息尚在繼續中，可否發公司債？」 | **完全不得發行**（§250 ①） |
| 「違約已了結兩年，可否發無擔保公司債？」 | **不得**（了結起三年內，§249 ①）；有擔保可以 |
| 「平均淨利達年息 120%，可發何種公司債？」 | 只能發**有擔保**（未達 150%） |
| 「平均淨利未達年息 100%，有銀行保證？」 | **可以發**（§250 ② 但書） |
| 「公開發行公司募集轉換公司債的總額？」 | 淨值 **200%**（證交法 §28-4 ①），不受 §247 |
| 「公開發行公司私募普通公司債的總額？」 | 淨值 **400%**（證交法 §43-6 III） |
| 「公開發行公司私募轉換公司債的總額？」 | 適用**公司法 §247**：淨值；無擔保 1/2 |
| 「非公開發行公司私募公司債的總額？」 | **無限制** |

## 一、禁止發行條件對照

| | §250 不得發行公司債 | §249 不得發行無擔保公司債 |
|---|---|---|
| 違約 | 尚在**繼續中** | 已了結，**三年內** |
| 獲利 | 平均淨利未達年息 **100%** | 未達年息 **150%** |
| 但書 | 銀行保證不受限 | — |
| 效果 | 有擔保、無擔保都不能發 | 有擔保仍可發 |

```
平均淨利 ÷ 年息總額
   < 100%        → 不得發行（§250）
   100% ~ 150%   → 只能發有擔保（§249）
   ≥ 150%        → 有擔保、無擔保都可以
```

## 二、總額限制（電腦圖 9-2 填空版）

| 公司 | 發行方式 | 種類 | 依據 | 總額 |
|---|---|---|---|---|
| 公開發行 | 募集 | 有擔保、轉換、附認股權 | 證交法 §28-4 ① | 淨值 200%（不適用 §247） |
| 公開發行 | 募集 | 無擔保普通公司債 | 證交法 §28-4 ② | 淨值 1/2（不適用 §247） |
| 公開發行 | 私募 | 普通公司債 | 證交法 §43-6 III | 淨值 400%（不適用 §247） |
| 公開發行 | 私募 | 轉換、附認股權 | **公司法 §247** | 淨值；無擔保 1/2 |
| 非公開發行 | 私募 | 三種皆可 | 立法理由、§356-11 | **沒有** |

- 淨值＝全部資產 − 全部負債（＝股東權益）
