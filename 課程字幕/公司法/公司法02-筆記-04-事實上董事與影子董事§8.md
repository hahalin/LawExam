# 公司法02 筆記：事實上董事與影子董事（§8）

## 先分清楚「法律上董事」：
- 法律上董事（de jure）：**依公司法選出的董事**
- 公司法條文寫「董事」兩字，一律指**法律上董事**
- 所以 §8 III 開頭「公司之**非董事**」＝**不是法律上董事**的人；本來就是董事的人不需要 §8 III

## §8 III 抓兩種人：
- **事實上董事（de facto）**：非董事而**實質上執行董事業務**；考試上「董事業務」直接理解為**董事會**——不是董事，卻收到開會通知、出席發言甚至表決
- **影子董事（shadow director）**：非董事而**實質控制**公司之人事、財務或業務經營，並**實質指揮董事**執行業務 → 控制＋指揮
- 最高法院判決不用這兩個名詞，用「**實質董事**」

## 影子董事兩個常見誤會：
- 人事、財務、業務經營是**三者擇一**，不用三個都有
- 指揮董事**一位就夠**，不必指揮過半數或全體

## 效果：
- 與本法董事同負**民事、刑事及行政罰**責任 → 三種都有，不是擇一
- 本法董事＝§8 I 公司負責人 → 接到 §23 I 的損害賠償等責任
- 2012 年增訂，**2018 年擴及所有公司種類**
- 沒有改變「董事」的定義，只是把責任擴大到事實上董事與影子董事
- 國考、法研所都很常出

## 📖 法條原文速查

> **§8 III**（實質董事）
> 公司之**非董事**，而**實質上執行董事業務**或**實質控制**公司之人事、財務或業務經營而**實質指揮董事**執行業務者，與本法董事同負**民事、刑事及行政罰**之責任。但政府為發展經濟、促進社會安定或其他增進公共利益等情形，對**政府指派之董事**所為之指揮，**不適用之**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§8 III 適用於哪些公司？」 | **所有公司**（2018 年修正） |
| 「影子董事須控制人事、財務、業務全部？」 | **否，擇一**即可 |
| 「影子董事須指揮過半數董事？」 | **否，指揮一位**即可 |
| 「實質董事負何種責任？」 | 與董事同負**民事、刑事及行政罰**責任 |
| 「卸任創辦人仍受邀出席董事會、經常提供意見？」 | **事實上董事** |
| 「法人股東指示其代表董事挪用公司資金？」 | 法人股東為**影子董事** |
| 「法人可否為事實上董事？」 | **不可**；法人最多是**影子董事** |
| 「政府指揮其指派之董事，適用 §8 III？」 | **不適用**（但書） |

## 一、三種董事對照

| | 法律上董事 | 事實上董事 | 影子董事 |
|---|---|---|---|
| 拉丁文／英文 | de jure | de facto | shadow director |
| 是否依法選任 | 是 | 否 | 否 |
| 判斷關鍵 | 選任 | 自己**親自**執行董事業務（出席董事會） | **控制**（人事、財務、業務擇一）＋**指揮**董事（一位即可） |
| 主體 | — | 只能是**自然人** | 自然人或法人 |
| 責任 | §23 等 | 與董事同負民、刑、行政罰責任 | 同左 |

## 二、典型案例

### 事實上董事（講義註釋 4）
- 選任有瑕疵、沒有選任（偽造當選）、已被解任，但仍在做董事的事
- 考過的例子：創辦人擔任董事長多年後**不再擔任董事**，仍以創辦人身分**受邀參加董事會、經常提供意見** → 標準的事實上董事

### 影子董事（2013 臺大法研所）
- 公開發行公司由三大法人股東各派代表當選董事；B 公司只派一名代表當選董事丙並兼董事長
- B 公司**指示丙挪用公司資金**供 B 周轉 → B 公司控制＋指揮 → **影子董事**

## 三、效果怎麼接到 §23

```
§8 III 實質董事
   ↓ 與「本法董事」同負責任
本法董事 ＝ §8 I 公司負責人（當然負責人）
   ↓
§23 I 公司負責人違反忠實、注意義務 → 損害賠償（民事）
＋ 刑事責任、行政罰（三者都有）
```

## 四、老師補充（考試不太考）

- **要不要嚴格區分 de facto 與 shadow？** 英國法有區分（shadow 責任較輕）；我國兩者效果相同，分得再清楚也殊途同歸，所以考試不太強調區分。
- **學者見解**：講義引學者（字幕作「劉老師」）認為影子董事應有**經常性、慣常性**要件，只有一次恐難認定；選擇題可能單考這點。
- **但書**：政府為公共利益指揮其指派的董事（例如公營事業），不適用 §8 III → 政府不因此負董事責任。此時政府若要歸類，屬**影子董事**。

> 字幕校正：字幕「隱私董事」「貫常性」應為「影子董事」「慣常性」；「民事刑事行政法」依條文為「民事、刑事及行政罰」。
