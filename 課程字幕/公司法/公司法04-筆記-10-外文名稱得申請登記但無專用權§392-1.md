# 公司法04 筆記：外文名稱得申請登記但無專用權（§392-1）

## 「得」申請，不是「應」：
- 公司**得**向主管機關申請外文名稱登記；也可以不登記
- 外文名稱指**英文**名稱

## 外文名稱要寫在章程：
- 主管機關應依**章程記載**的外文名稱登記
- 要新增或更改外文名稱 → **變更章程** → 股東會**特別決議**（§277，見 公司法01-筆記-12）
- 可以只寫在章程上、不去登記

## 主管機關沒有審查權：
- 「應」依章程記載登記 → **不做事前審查**
- 就算與他公司外文名稱相同，申請照樣通過

## 事後處理：須依申請：
- 登記後有法定情形時，主管機關**得依申請**令其**限期辦理變更登記**；屆期未辦妥 → **撤銷或廢止**外文名稱登記
- 法定情形：①與依貿易法令**登記在先**的出進口廠商外文名稱相同；②經**法院判決確定**不得使用；③與**政府機關、公益團體**的外文名稱相同（政府機關也要自己申請）
- 關鍵字：**依申請**（不是依職權）

## 沒有名稱專用權：
- 沒人申請，就可以**共用**相同的外文名稱
- 學者：外文名稱**沒有公司名稱專用權**

## 📖 法條原文速查

> **§392-1**（外文名稱登記）
> I　公司**得**向主管機關申請公司外文名稱登記，主管機關**應依公司章程記載之外文名稱**登記之。
> II　前項公司外文名稱登記後，有下列情事之一者，主管機關得**依申請**令其限期辦理變更登記；屆期未辦妥變更登記者，**撤銷或廢止**該公司外文名稱登記：
> 一、公司外文名稱與依貿易法令**登記在先**或預查核准在先之他出進口廠商外文名稱相同。……
> 二、公司外文名稱經**法院判決確定**不得使用。
> 三、公司外文名稱與**政府機關、公益團體**之外文名稱相同。
> III　第一項外文名稱之種類，由中央主管機關定之。
> → 第二項各款細節建議查閱最新六法原文

> **§277 I、II**（變更章程）
> 公司非經股東會決議，不得變更章程。前項股東會之決議，應有代表已發行股份總數三分之二以上之股東出席，以出席股東表決權過半數之同意行之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司是否應登記外文名稱？」 | **得**登記，非應登記 |
| 「外文名稱登記的依據？」 | 依**章程記載**的外文名稱 |
| 「主管機關對外文名稱有無事前審查權？」 | **無**，應依章程登記 |
| 「外文名稱與他公司相同，主管機關可否依職權撤銷？」 | **不可**；須**依申請**，並先令限期變更 |
| 「公司外文名稱有無專用權？」 | **無**；未經申請可共用 |
| 「新增外文名稱須經何種決議？」 | 變更章程 → 股東會**特別決議**（§277） |

## 一、黑板例（改為假名）

```
甲咖啡公司 2006 年登記英文名稱「Ｘ Coffee」
   ↓
2026 年乙公司章程也寫「Ｘ Coffee」，申請外文名稱登記
   ↓
經濟部：應依章程記載登記，無審查權 → 照准
   ↓
甲公司
├── 提出申請 → 經濟部令乙限期變更 → 屆期未辦 → 撤銷或廢止
└── 不申請（例如兩家老闆交好） → 兩家共用同一外文名稱
```

## 二、中文名稱與外文名稱對照

| | 中文名稱（§18） | 外文名稱（§392-1） |
|---|---|---|
| 是否必要 | 必要，應使用我國文字 | **得**申請 |
| 審查 | 事前申請核准（§18 V） | **不審查**，依章程登記 |
| 相同名稱 | 不得相同 | 可登記；依申請才處理 |
| 專用權 | 有 | **無** |
