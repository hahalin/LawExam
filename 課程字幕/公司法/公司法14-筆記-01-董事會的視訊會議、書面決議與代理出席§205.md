# 公司法14 筆記：董事會的視訊會議、書面決議與代理出席（§205）

## 董事會的三種開會方式：
- **實體召開**：特定時間、地點開會，時地不要太奇怪即可；不限國內（註 212，不考：曾有公司為了方便派駐大陸的董事，改在香港開）
- **視訊會議**（§205 II）：以視訊參與者**視為親自出席**
- **無實體（書面）董事會**（§205 V ~ VII）：不實際集會，以書面行使表決權

## 視訊會議不必章定：
- §205 II 寫「**如以**」視訊會議為之 → **不用訂明章程**就可以採用（選擇題考過）
- 對照股東會：股東會要用視訊**必須章程訂明**（§172-2）
- 差別理由：董事人數少（三、五、七人），視訊無妨；股東會人數多，純視訊會讓股東出席受限
- 限於**看得到臉**的視訊；**電話、email 不可以**

## 無實體董事會的要件：
- **非公開發行公司**才可以（§205 VII，選擇題很愛考）
- 章程「**得**」訂明 → 有章程規定才能用
- 經**全體董事同意**，而且是**當次**同意 → 每次都要重新取得
- 全體同意的是**開會方式**，不是議案內容：三位董事都同意本次用書面表決，投資案仍可一票贊成、兩票反對
- 效果：視為已召開董事會；書面表決的董事視為親自出席（§205 VI）
- 經濟部：仍須**寄發召集通知**，載明事由及行使方式，通知各董事及監察人
- 方嘉麟（註 214，不考）：書面決議只是意見寄來寄去，沒有討論、無法集思廣益，公司治理上不妥；老師建議用這個理由記「公發公司不適用」

## 董事應親自出席，章定才能代理：
- §205 I 前段「**應**」親自出席 → 董事有**出席義務**（像法官、訴訟律師不能說我不開庭）
- 後段：**章程訂定**得由**其他董事**代理 → 章程沒寫就不能代理
- 章程未定而代理 → 被代理的董事等於**缺席**；代理人還替他投票 → **決議方法違法** → 依董事會瑕疵原則**無效**（見公司法13-筆記-12）
- 代理的三個限制：
  - 只能委託**其他董事**
  - **每次**出具委託書，列舉召集事由的授權範圍（§205 III）→ 不能長期委託同一人；未列舉範圍就等於概括授權
  - 代理人以**受一人委託為限**（§205 IV，非常喜歡考）
- 為什麼限其他董事（不考）：①業務機密不外洩，其他董事本來就會知道 ②平常一起開會好找人，對方本來就要出席

## 股東出席是權利，董事出席是義務：
- 股東會代理：不必章定，只有代理表決權數上限（§177，見公司法09-筆記-01、講義 5-46）
- 董事會代理：必須章定、限其他董事、限受一人委託
- 經濟部（講義 6-110 末行）：三位董事只有一人親自出席，即使另一人委託他代理，仍不符合董事會的基本要件 → 無效；學者有不同見解（註 219，臺大法研所很久以前考過）

## 📖 法條原文速查

> **§205**（董事出席與表決方式）
> I　董事會開會時，董事應**親自出席**。但公司章程訂定得由**其他董事代理**者，不在此限。
> II　董事會開會時，**如以視訊會議為之**，其董事以視訊參與會議者，**視為親自出席**。
> III　董事委託其他董事代理出席董事會時，應於**每次**出具委託書，並列舉召集事由之授權範圍。
> IV　前項代理人，以受**一人**之委託為限。
> V　公司章程**得**訂明經**全體董事同意**，董事就**當次**董事會議案以**書面**方式行使其表決權，而不實際集會。
> VI　前項情形，視為已召開董事會；以書面方式行使表決權之董事，視為親自出席董事會。
> VII　前二項規定，於**公開發行股票之公司，不適用之**。

> **§172-2 I**（股東會視訊）　公司章程**得訂明**股東會開會時，以視訊會議或其他經中央主管機關公告之方式為之。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事會以視訊會議為之，須章程訂明？」 | **不必**（§205 II「如以」）；股東會才須章定 |
| 「董事以電話參與董事會，視為親自出席？」 | **否**，限視訊 |
| 「公開發行公司得以書面方式行使表決權而不實際集會？」 | **不得**（§205 VII） |
| 「無實體董事會的全體董事同意，指同意什麼？」 | 同意**開會方式**，且每次（當次）同意；議案可有不同意見 |
| 「董事得委託非董事代理出席？」 | **不得**，限其他董事，且須章程訂定 |
| 「一董事可同時受兩位董事委託？」 | **不可**，以受一人委託為限 |
| 「章程未定得代理而代理表決，決議效力？」 | 等於缺席，決議方法違法 → **無效** |

## 一、股東會與董事會對照（講義 6-110、6-111 表）

| | 股東會 | 董事會 |
|---|---|---|
| 視訊 | 須章定（§172-2） | **不必章定**（§205 II） |
| 無實體書面 | 限**閉鎖性**公司，當次全體同意（§356-8，第 13 章再講） | 限**非公發**，章定＋當次全體同意（§205 V ~ VII） |
| 代理出席 | 不必章定，有表決權數上限（§177） | **必須章定**、限其他董事、每次委託、受一人委託 |
| 出席性質 | 權利 | **義務** |

## 二、章程未定而代理

```
章程沒有「得由其他董事代理」
        ↓
董事乙委託董事丙出席
        ↓
乙 → 視同缺席
丙代乙投票 → 決議方法違法 → 原則無效（97 台上 925）
```
