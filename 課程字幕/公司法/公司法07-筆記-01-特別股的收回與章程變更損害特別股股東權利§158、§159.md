# 公司法07 筆記：特別股的收回與章程變更損害特別股股東權利（§158、§159）

## 特別股的收回（§158）：
- 條文用「**得**」收回 → 任意收回，法律不強制公司收回
- 2011 年修法**刪除收回財源限制**（舊法只能用特定會計項目，講義註 34 是舊法，不用畫）→ 現在任何來源的資金都可以收回
- 章程可以事先寫明**無償收回**（例：發行滿 3 年無償收回）；合法，只是市場比較不願意買
- 經濟部：**不得以發行普通股收回特別股** → 等於把特別股轉成普通股，就是 §157 I ⑥ 的轉換特別股（見公司法06-筆記-12）；收回只能**付錢**
- 收回後應**消除**，不得再賣出：法無明文，學者與法院一致；§158 是 §167 I 股份回籠禁止的例外，目的在**消除不平等**（講義 12-27「特別股收回之處理，法無明文」對照）
- 但書「不得損害特別股股東按照章程應有之權利」＝**不溯及既往**：已領的股利不能要求返還

## 股份的拋棄（附帶，未考過）：
- 股東可以拋棄股份，須**向公司為之**；拋棄後成為**庫藏股**，公司可以減資

## 章程變更損害特別股股東權利（§159）：
- 為什麼一定牽涉變更章程：特別股的權利**載明於章程**（§130 I ③、§157）
- 何謂「損害特別股股東之權利」：
  - **72 台上 808**（字幕所述，建議查證）：限縮於**優先權利**，也就是比別人好的權利被縮小
  - **劉連煜**老師：包括**所有權利**（法無明文限制，且區分認定麻煩）
- 程序兩關：**股東會特別決議**提出修章案 ＋ **特別股股東會決議**
  - 股東會特別決議其實沒什麼特別：修改章程本來就是特別決議（§277）
  - 公開發行公司出席不足時，可用過半數出席、出席表決權 2/3 同意（§159 II）；章程可提高（§159 III）
- §159 IV「特別股股東會準用關於股東會之規定」：文字沒寫普通或特別決議，學者與法院認為準用後是**特別股股東會的特別決議**
- 特別股股東會不同意 → **從頭再來**，重新提出修章案（例：一股 5 權改 1 權被否決，改提 3 權、4 權，類似妥協）

## 林國彬老師見解：否決權特別股可以實質阻止公開發行：
- 申請公開發行只要**董事會**普通決議（§156-2 I 前段，見本講筆記-10）；否決權只對**股東會**決議事項行使 → 擋不住申請
- 但公開發行公司不得有 §157 III 所列特別股（見公司法06-筆記-12）→ 公司必須**修章**刪除 → 走 §159 或 §277 股東會 → 持有「修改章程否決權」的特別股股東可以否決 → **最終實質上阻止**公開發行

## 📖 法條原文速查

> **§158**（特別股之收回）
> 公司發行之特別股，**得收回**之。但不得損害特別股股東按照章程應有之權利。

> **§159**（特別股股東之保障）
> I 公司已發行特別股者，其**章程之變更**如有**損害特別股股東之權利**時，除應有代表已發行股份總數三分之二以上股東出席之股東會，以出席股東表決權過半數之決議為之外，**並應經特別股股東會之決議**。
> II 公開發行股票之公司，出席股東之股份總數不足前項定額者，得以有代表已發行股份總數過半數股東之出席，出席股東表決權三分之二以上之同意行之，並應經特別股股東會之決議。
> III 前二項出席股東股份總數及表決權數，章程有較高之規定者，從其規定。
> IV 特別股股東會**準用**關於股東會之規定。

> **§167 I**（股份回籠禁止）公司除依第一百五十八條、第一百六十七條之一……規定外，不得自將股份收回、收買或收為質物。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **經濟部**：不得以發行普通股之方式收回特別股（等同轉換特別股）。
> **72 台上 808**（建議查證字號）：§159 所稱特別股股東之權利，限於優先權利。
> **學說與實務**：收回之特別股應予消除，不得再行出售；§159 IV 準用後為特別股股東會之特別決議。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司應收回特別股？」 | ✕，是「**得**」收回 |
| 「收回特別股限以特定財源為之？」 | ✕，2011 年已**刪除財源限制** |
| 「章程得訂定無償收回特別股？」 | **可以** |
| 「公司得發行普通股收回特別股？」 | **不得**（經濟部：等同轉換） |
| 「收回之特別股得再行出售？」 | **不得**，應消除 |
| 「收回特別股時得請求返還已領股利？」 | **不得**（不溯及既往） |
| 「章程變更損害特別股股東權利，只要股東會特別決議即可？」 | ✕，**並應經特別股股東會決議** |
| 「特別股股東會以普通決議為之？」 | ✕，學說實務：準用後為**特別決議** |

## 一、§159 兩關程序（具體數字）

```
已發行 1,000 萬股：普通股 700 萬、特別股 300 萬
擬將一股 5 權的特別股改為一股 1 權（損害優先權利）

第一關：股東會特別決議（全體股份計算）
   出席 ≥ 667 萬股（2/3）→ 同意 > 出席表決權半數
        ↓ 通過修章案
第二關：特別股股東會特別決議（只算特別股）
   出席 ≥ 200 萬股（300 萬 × 2/3）→ 同意 > 出席半數
        ├─ 通過 → 章程變更生效
        └─ 否決 → 重新提出修章案（例如改成一股 3 權）再跑一次
```

## 二、「損害特別股股東權利」的範圍

| 見解 | 範圍 | 一股 5 權降為 1 權 | 其他權利變動 |
|---|---|---|---|
| 72 台上 808 | 限於**優先權利** | 要過 §159 | 非優先權利 → 不必 |
| 劉連煜 | **所有權利** | 要過 §159 | 也要過 §159 |

## 三、林國彬老師的推論

```
申請公開發行 ── 董事會普通決議（§156-2 I）── 否決權特別股擋不住
      ↓
成為公開發行公司前，章程不得留有 §157 III 特別股
      ↓
修章 → 股東會（§159 / §277）── 修章否決權特別股可否決
      ↓
章程改不了 → 實質上無法公開發行
```
