# 公司法17 筆記：股份自由轉讓原則與章程、契約限制轉讓的效力（§163、§356-1、企併法§11）

## 原則（§163 本文）：
- 公司股份之轉讓，除本法另有規定外，**不得以章程禁止或限制**之
- 立法理由（不太考，申論 15 年以上沒考）：
  - ① 保障股東**收回投資**的機會
  - ② **企業所有與經營分離**：參與經營與股東身分無關，股份應可轉讓（見公司法01-筆記-07）
  - ③ **股東有限責任**：誰當股東不那麼重要
- 「除本法另有規定外」→ 例外非常多（本講筆記-12）

## 以章程限制轉讓：
- **閉鎖性股份有限公司**（§356-1）：章程**必須**定有股份轉讓限制 → 合法且必要（第十三章再講）
- **企業併購法 §11**：**非公開發行**公司**得**於章程限制股份轉讓
  - 章程的效力及於**沒有簽契約的人**，所以限於非公開發行公司
- 兩者以外，以章程限制轉讓 → 違反 §163 → 股東會決議內容違反法令，**無效**（§191）；股份轉讓仍**有效**
- 記憶順序：先記閉鎖性（一定要有），再記企業併購法（非公發得訂）

## 以契約限制轉讓：
- 符合企業併購法：可以
- **不符合**企業併購法：最高法院固定見解 → 契約**有效**，但**不得對抗第三人**（選擇題考）
  - 效果有限：違約方要付違約金，但股份轉讓仍有效、可以過戶，達不到「不讓股份轉出去」的目的
  - 劉連煜老師認為這見解雖然緩和了自由轉讓原則，但沒達到最終目的（字幕作「劉德玉」，推定，建議查證）

## 電腦圖 12-4 左下虛線框填空：
- 違反 §163 的章程修改效力：**無效**
- 契約限制轉讓：該契約**有效**，但該契約**不可對抗第三人**

## 📖 法條原文速查

> **§163**　公司股份之轉讓，除本法另有規定外，**不得以章程禁止或限制之**。但非於公司**設立登記後**，不得轉讓。

> **§356-1 I**　閉鎖性股份有限公司，指股東人數不超過五十人，並於**章程定有股份轉讓限制**之非公開發行股票公司。→ 建議查閱最新六法原文

> **企業併購法 §11**　公司進行併購時，股東得以書面契約約定股份轉讓之限制；**非公開發行股票之公司**得於**章程**中記載股份轉讓之限制。→ 內容為摘要，建議查閱最新六法原文

> **§191**　股東會決議之內容，違反法令或章程者**無效**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股份自由轉讓原則的條文？」 | **§163 本文** |
| 「閉鎖性公司得否以章程限制股份轉讓？」 | **必須**限制（§356-1） |
| 「依企業併購法得以章程限制轉讓的公司？」 | **非公開發行**公司 |
| 「一般公司以章程限制股份轉讓？」 | 違反 §163，**無效** |
| 「股東間以契約限制轉讓（不符企併法）？」 | 契約**有效**，但**不得對抗第三人** |
| 「違反限制轉讓契約而轉讓股份？」 | 轉讓**有效**，只負違約責任 |

## 一、限制轉讓的方式與效力（電腦圖 12-4 左下）

```
限制股份轉讓
├── 以法令限制 → 沒有問題（本講筆記-12）
├── 以章程限制
│   ├── 閉鎖性公司（§356-1）→ 合法且必須
│   ├── 企併法 §11（非公開發行）→ 得
│   └── 其他 → 違反 §163，無效（轉讓仍有效）
└── 以契約限制
    ├── 符合企併法 → 可以
    └── 不符合 → 契約有效，但不得對抗第三人
```

## 二、案例：契約約定不得出售

#### 事實
1. A 與 B 約定：B 不得將持有的甲公司股份賣給他人，違約賠 50 萬元
2. 兩天後 B 把股份賣給 C

#### 分析
- 約定**有效** → B 應賠 A 50 萬元
- 不得對抗第三人 → B 與 C 的股份轉讓**有效**，C 可以過戶
- A 的目的（股份不外流）沒有達成
