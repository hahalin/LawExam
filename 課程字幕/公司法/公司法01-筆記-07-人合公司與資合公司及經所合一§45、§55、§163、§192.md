# 公司法01 筆記：人合公司與資合公司及經所合一（§45、§55、§163、§192）

## 學理分類，以對外信用基礎區分：
- 著重**股東個人條件** → **人合公司**，標準類型是**無限公司**
- 著重**公司財產數額** → **資合公司**，標準類型是**股份有限公司**
- **兩合公司**在中間，稱**中間公司**；**有限公司**學者一致認為屬**資合公司**
- 不會出在二試，最多以相關法條出選擇題；但它是理解四種公司的骨架

## 判斷標準是股東對公司債務的責任：
- 股東對公司債務負直接、無限責任 → 人合
- 股東負間接、有限責任 → 資合
- 有限公司股東以**出資額**為限，所以歸資合

## 兩端的三個特色剛好相反：
- 人合：合夥性濃、股東地位移轉**困難**（§55）、**經所合一**（§45）
- 資合：法人性濃、股東地位移轉**容易**（§163）、**經所分離**（§192）
- 根源都是責任不同：要負無限責任，就會在意和誰一起負責、也要能親自經營

## 經所合一與經所分離：
- 全稱：**經營權**與**所有權**合一／分離；所有權＝股東身分
- 經所合一：有股東身分就有經營權
- 經所分離：取得經營權（例如當董事）**不需要**股東身分

## 📖 法條原文速查

> **§55**（無限公司出資轉讓）
> 股東非經**其他股東全體之同意**，不得以自己出資之全部或一部，轉讓於他人。

> **§45 I**（無限公司執行業務）
> **各股東均有執行業務之權利**，而負其義務。但章程中訂定由股東中之一人或數人執行業務者，從其訂定。

> **§163**（股份自由轉讓）
> 公司股份之轉讓，除本法另有規定外，**不得以章程禁止或限制之**。但非於公司設立登記後，不得轉讓。

> **§192 I**（董事之選任）
> 公司董事會，設置董事不得少於**三人**，由股東會就**有行為能力之人**選任之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「人合、資合的區分標準？」 | 公司**對外信用基礎**；實際看**股東對公司債務的責任** |
| 「有限公司屬人合或資合？」 | **資合**（股東以出資額為限） |
| 「兩合公司的定位？」 | **中間公司** |
| 「無限公司股東轉讓出資，須經何種同意？」 | **其他股東全體**同意（§55） |
| 「股份有限公司得以章程禁止股份轉讓？」 | **不得**（§163，除本法另有規定） |
| 「股份有限公司董事須具股東身分？」 | **不須**，有行為能力之人即可（§192 I）→ 經所分離 |

## 一、光譜表（電腦圖 1-4）

```
對外提供的信用基礎
人合 ◄────────────────────────────────► 資合
無限公司          兩合公司          有限公司 / 股份有限公司
（標準人合）      （中間公司）      （學者認為資合）（標準資合）

著重股東個人條件                     著重財產數額
股東負連帶無限責任                   股東以出資額／股份為限
```

## 二、三個相對的特色

| 特色 | 人合（無限公司） | 資合（股份有限公司） |
|---|---|---|
| 性質 | 合夥性濃 | 法人性濃 |
| 股東地位移轉 | 困難：§55 其他股東**全體同意** | 容易：§163 **不得以章程禁止或限制** |
| 經營與所有 | **經所合一**：§45 各股東均有執行業務之權 | **經所分離**：§192 由股東會就**有行為能力之人**選任董事 |

### 推理鏈

```
無限公司：股東負無限責任
   ├→ 誰跟我一起負責很重要 → 地位移轉要全體同意
   └→ 責任這麼重，當然要能親自經營 → 經所合一

股份有限公司：股東只以股份為限
   ├→ 換人當股東無所謂 → 股份自由轉讓
   └→ 誰經營都可以，能賺錢就好 → 董事不必是股東（經所分離）
```

- 讀 §192 要讀出「沒寫的字」：條文只寫「有行為能力之人」，**沒有寫股東**，所以董事不需股東身分。
- 對照：有限公司 §108 I 寫「就有行為能力之**股東**中選任」→ 有限公司的董事是經所合一（見 公司法01-筆記-09）。

> 字幕校正：「金所合一／金鎖分離／金權分離」皆為**經所合一／經所分離**（經營權與所有權）。
