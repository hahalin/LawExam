# 公司法16 筆記：公司籌資的公募私募體系與公司債的種類（§262、§246-1）

## 公司籌措資金的兩種方式（講義 9-3）：
- **發行新股**（增資）→ 第十章
- **借貸資金** → 直接向銀行借，或需要大量資金時發行**公司債** → 第九章
- 第九章近年很少考（最後是 2014、2015 年，偏法條），記住基本法條即可

## 公開發行公司：什麼都可以：
- 股份、公司債都可以**公開發行**或**私募**
- 公開發行依證交法 §22；私募依證交法 §43-6 ~ §43-8（證交法再學）

## 非公開發行公司：一定不能公開發行：
- 名字就叫非公開發行 → **絕對不能公開發行**
  - 想公開發行就先變成公發公司（§156-2，見公司法07-筆記-10）
- **股份不能私募** → 發行新股的對象只能是**員工、股東、特定人**（§267 I ~ III，見本講筆記-07）
- **公司債可以私募** → §248 II、III、§248-1；閉鎖性公司另有 §356-11
- 修法時學者曾討論刪除非公發公司私募公司債；經濟部認為實務有需求而保留

## 公司債的定義與特殊性（講義 9-3 ~ 9-4）：
- 定義：**長期**、**大量**的資金，分割成單位發行債券
- 特殊規範的目的：**保護投資大眾**（公司債的出資人叫**應募人**；股份叫**認股人**）
- 只有**股份有限公司**可以發行
- **到期資金不足時要比例清償**（選擇題）：
  - 例：到期本息共 10 億，公司只湊得出 8 億 → 每位債權人一律受償 **80%**
  - 不可以先對一部分債權人全額清償、其餘的人等下次
  - 理由：還本付息是公司債債權人**最基本的權利**，必須平等

## 轉換公司債（§262 I，電腦圖 9-1 上半）：
- 公司債附**轉換權**，像套餐一起賣（bundle）
- 依轉換辦法的**期間、價格、數量**行使 → 行使後**債權消滅**，身分由債權人轉為**股東**
- 轉換權是**形成權**；公司有核給股份的**義務**，**債權人有選擇權**
- 公司因此發的新股屬**特殊發行新股**（見本講筆記-11）
- 技術性規定（未考過）：§248 VII → 可轉換或可認購股份數加計已發行股份等，超過章定股份總數時，要**先變更章程**增加資本額；發行新股不得超過授權股份數，超過無效（電腦圖 9-3）

## 附認股權公司債（§262 II，電腦圖 9-1 下半）：
- 公司債之外**另享有**認購股份的權利（條件、期間、價格、數量）
- 認購時要**另行支付股款** → 成為股東，但**原債權人身分不變**
- 公司有核給股份的義務，**認股權憑證持有人有選擇權**

## 次順位公司債（§246-1）：
- 發行時約定**受償順序次於其他債權**
- 順序很後面，**幾乎等於股份**；通常單獨出題

## 📖 法條原文速查

> **§246-1**　公司於發行公司債時，得約定其**受償順序次於**公司其他債權。

> **§262**
> I　公司債約定得**轉換股份**者，公司有依其轉換辦法核給股份之**義務**。但公司債債權人有**選擇權**。
> II　公司債**附認股權**者，公司有依其認購辦法核給股份之**義務**。但認股權憑證持有人有**選擇權**。

> **§248 VII**　可轉換股份數額、可認購股份數額加計已發行股份總數等，如超過公司章程所定股份總數時，應**先完成變更章程**增加資本額後，始得為之。→ 條文很長，建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「非公開發行公司可否公開發行股份或公司債？」 | **不可以** |
| 「非公開發行公司可否私募股份？」 | **不可以**；對象限員工、股東、特定人（§267） |
| 「非公開發行公司可否私募公司債？」 | **可以**（§248 II） |
| 「公司債到期資金不足，可否先對部分債權人全額清償？」 | **不可以**，應對全體**比例清償** |
| 「轉換公司債行使轉換權後，債權人身分？」 | **債權消滅**，成為股東 |
| 「附認股權公司債行使認股權後，債權人身分？」 | 另行繳款成為股東，**債權不變** |
| 「轉換或認股，公司與持有人各自的地位？」 | 公司有**核給義務**；持有人有**選擇權**（§262） |
| 「次順位公司債的受償順序？」 | 次於其他債權，**僅優先於股東**（§246-1） |

## 一、籌資體系（講義板書）

```
                股份                    公司債
公開發行公司    公開發行 ✓／私募 ✓      公開發行 ✓／私募 ✓
                （證交法 §22；§43-6～8）

非公開發行公司  公開發行 ✗              公開發行 ✗
                私募 ✗                  私募 ✓
                → 員工、股東、特定人     → §248 II、III、§248-1
                  （§267 I～III）        → 閉鎖性：§356-11
```

## 二、三種公司債的比較

| | 轉換公司債 | 附認股權公司債 | 次順位公司債 |
|---|---|---|---|
| 條文 | §262 I | §262 II | §246-1 |
| 權利 | 債權**換成**股份 | 債權**之外另**認購股份 | 受償順序較後 |
| 是否另繳股款 | 否 | **是** | — |
| 行使後債權 | **消滅** | **不變** | — |

## 三、公司清算時的受償順序

```
① 優先債權（抵押權、質權等擔保物權）
② 普通債權
③ 次順位公司債（§246-1）
④ 股東：賸餘財產分派請求權
```
