# 公司法12 筆記：跨任期解任與跨公司解任（投保法§10-1、§200）

## 跨任期解任——投保法明文：
- 投保法 §10-1 I ②：解任事由**不以起訴時任期內發生者為限** → 可以拿前一任期的事由解任現任職位
- 法院早期採否定說，近期多數與學者採**肯定說**

## 跨任期的兩種情形（電腦圖 6-10、6-11）：
- **情形一：訴訟中連任**——第一任內發生事由並起訴，訴訟進行中任期屆滿、又當選第二任 → 原解任訴訟**可以續行**，解任第二任的職位
- **情形二：連任後才發現**——第一任內發生事由，當時沒人發現，連任第二任後才發現 → 可在第二任**援引第一任事由**提起裁判解任
- 解任效力仍到**該任期屆滿**為止

## 跨公司解任——2025 年投保法修正：
- 增訂事由：證交法 §20 I（證券詐欺）、§20 II（財報不實）、§32 I（公開說明書不實而無免責事由）、§155 I、II（操縱行為）、§157-1（內線交易）、§171 I ②③（不當利益輸送、侵占公司資產等），以及期貨交易法相關規定——考試應會附條文
- 刪除「**執行業務**」字樣，避免爭議
- 立法理由：**經營者的誠信很重要**；有這些情事屬不適合擔任職務，**不論是否在執行所屬公司業務**，均有解任必要 → 在他公司的不法行為，也可以作為現公司的解任事由
- 學者（張心悌）肯定：①文義上不法行為是獨立事由 ②從董事**資格**角度，不適合擔任任何上市櫃公司董事 ③目的解釋：具有**高度公益性**

## 公司法 §200 能不能跨任期——近年國考：
- 投保法有明文，**公司法沒有明文**
- 考題：B 公司股東依公司法訴請法院裁判解任監察人；訴訟進行中任期屆滿後再度當選，可否解任
- 否定說：股東會改選已對過去事項**重新綜合考量**；限制可能侵害**工作權**；屬無法預知的事
- 肯定說：改選時股東**未必知悉**事由；否則會產生**訴訟拖延**（拖到任期屆滿就結束）
- 老師採**肯定說**；下一題可能考公司法上能否**跨公司**解任，同樣可採肯定說

## 📖 法條原文速查

> **投保法 §10-1 I ②**　訴請法院裁判解任公司之董事或監察人，不受公司法第二百條及第二百二十七條準用第二百條之限制，且**解任事由不以起訴時任期內發生者為限**。→ 2025 年修正內容建議查閱最新六法原文

> **公司法 §200**　董事執行業務，有重大損害公司之行為或違反法令或章程之重大事項，股東會未為決議將其解任時，得由持有已發行股份總數百分之三以上股份之股東，於股東會後三十日內，訴請法院裁判之。

> 字幕校正：「投保法11／實之一」＝投保法 §10-1；「張西堤」推定為張心悌，建議查證；「去年國考」的年度建議查證。2025 年修正增訂的證交法條號依字幕整理，建議查閱最新六法原文。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「投保中心可否以前一任期的事由解任現任董事？」 | **可以**，事由不以起訴時任期內發生者為限 |
| 「訴訟中任期屆滿又連任，訴訟可否續行？」 | **可以**續行 |
| 「董事在乙公司的內線交易，可否作為解任其甲公司董事的事由？」 | 投保法 2025 年修正後**可以**（跨公司解任） |
| 「2025 年修正刪除什麼字樣？」 | 「**執行業務**」 |
| 「公司法 §200 有沒有明文可跨任期？」 | **沒有**；學說爭議，老師採肯定說 |

## 一、跨任期兩種情形（第一任 2019/7 ～ 2022/7，第二任 2022/7 ～ 2025/7）

```
情形一（6-10）
2021/10 發生事由 → 2021/12 起訴 → 2022/7 任滿、連任第二任 → 訴訟續行
                                                    → 2024/2 判決確定解任，效力到 2025/7

情形二（6-11）
2021/10 發生事由（無人發現）→ 2022/7 連任第二任 → 2023/2 才發現 → 援引第一任事由起訴
```

## 二、跨任期與跨公司

| | 跨任期 | 跨公司 |
|---|---|---|
| 意思 | 同一公司，前任事由解任現任 | 他公司的不法行為解任本公司職位 |
| 投保法 | 明文可以 | 2025 年修正後可以（立法理由） |
| 公司法 §200 | 無明文，學說爭議 | 無明文，可能是下一個考點 |

## 三、§200 跨任期兩說

| | 否定說 | 肯定說（老師採） |
|---|---|---|
| 理由一 | 改選時已重新綜合考量 | 改選時股東未必知悉 |
| 理由二 | 侵害工作權、無法預知 | 避免訴訟拖延 |
