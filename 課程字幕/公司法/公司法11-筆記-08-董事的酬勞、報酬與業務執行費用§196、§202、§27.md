# 公司法11 筆記：董事的酬勞、報酬與業務執行費用（§196、§202、§27）

## 三分法（目前法院、經濟部與多數學說，講義 6-9）：
- **酬勞**：盈餘分配
- **報酬**：勞務的對價
- **業務執行費用**：執行職務的支出
- 曾宛如老師只分「業務執行費用」與「其他」兩類（字幕「鄭文老師」，人名建議查證），知道即可

## 酬勞：盈餘的一部分，公司法沒有規定：
- 性質：股東**自願讓出**的盈餘權益 → 以年度盈餘一定比例給付，具**成功報酬**性質
- **公司有賺錢才有**，虧損年度就沒有
- 經濟部：只能以**現金**發放，不得以發行新股為之（避免與 §240 盈餘轉增資混淆，這點不會考）
- 決定方式完全依經濟部見解（講義 6-10 ~ 6-11）：
  - 盈餘分派表**不得再列**董事酬勞項目
  - 須**章程**訂明依**定額或比率**分派；章程沒有訂明 → **不得分派**，也不能用股東會決議分派
  - 比率須訂**上限**（例：最高 1.5%），實際比率由**董事會特別決議**決定（建議查證）

## 報酬：勞務的對價，§196 有規定：
- **不論有無盈餘都要支付**，例如薪資、獎金、退休金
- 決定方式：**章程訂明**；未訂明者由**股東會議定**（§196 I）
- **不得概括授權董事會**：
  - 98 台上 935：甲公司修章「董事、監察人之報酬由董事會議定之」，沒有具體規定 → 與法律規定不符（選擇題考過，註 18）
  - 股東會也不能決議把報酬交由董事會**自行決定** → 違反公司治理原則及 §196，決議**無效**
- 合法授權方式：
  - 章程：訂明依**同業通常水準**支給，或訂**總額上限**範圍授權董事會（劉連煜老師也接受同業通常水準）
  - 股東會：決議**全體董事報酬總額**，個別分配委由董事會決議 → 個別董事金額可以不同
- 章程不必「授權股東會」：章程不寫，依 §196 自動由股東會議定

## 業務執行費用：公司法沒有規定：
- 例：交通費、住宿費、餐費
- 回歸 **§202** → **董事會普通決議**
- **沒有迴避問題**：只是實報實銷；要不要出差，在更早決定該業務時就處理了

## 法人代表人董事只能領業務執行費用（講義 6-13，選擇題考過）：
- 依 §27 I（法人董事的代表人）或 §27 II（代表人董事）當選者，只能支領**車馬費**（業務執行費用）
- **酬勞、報酬歸法人股東**：民法 **§541**，代表人＝受任人，法人股東＝委任人（經濟部 63.8.5 函、最高法院 102 台上 1304；多數見解）
- 法人董監見公司法05-筆記-11、12

## 📖 法條原文速查

> **§196 I**（董事報酬）　董事之報酬，**未經章程訂明者，應由股東會議定**，不得事後追認。

> **§202**　公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由**董事會決議**行之。

> **民法 §541 I**　受任人因處理委任事務，所收取之金錢、物品及孳息，應**交付於委任人**。

## 📋 實務見解速查

> **98 台上 935**：章程規定董監報酬由董事會議定，未為具體規定，屬概括授權，與 §196 不符。→ 原文建議查證

> **最高法院 102 台上 1304**、**經濟部 63.8.5 函**：法人股東代表人所得報酬，屬處理委任事務所收取，應交付法人股東。→ 原文建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「章程規定董監報酬由董事會議定，無具體規定？」 | **不合法**，概括授權（98 台上 935） |
| 「股東會決議報酬交由董事會自行決定？」 | **無效** |
| 「股東會決議全體董事報酬總額，個別分配由董事會決定？」 | **可以** |
| 「董事酬勞得以發行新股發放？」 | ✕，經濟部：只能**現金** |
| 「公司虧損，仍須支付董事報酬？」 | **要**，報酬是勞務對價；酬勞才是有盈餘才有 |
| 「代表人董事的報酬歸誰？」 | **法人股東**（民法 §541），代表人只領車馬費 |
| 「業務執行費用由誰決定？」 | **董事會普通決議**（§202），無迴避問題 |

## 一、三分法比較

| | 酬勞 | 報酬 | 業務執行費用 |
|---|---|---|---|
| 性質 | 盈餘分配、成功報酬 | 勞務對價 | 執行職務支出 |
| 虧損時 | 沒有 | 照付 | 照付 |
| 公司法明文 | ✕ | **§196** | ✕ |
| 決定方式 | 章程訂定額或比率上限（經濟部） | 章程，未訂由股東會 | 董事會普通決議（§202） |
| 例 | 年度盈餘 1.5% | 薪資、獎金、退休金 | 高鐵票、住宿、餐費 |
| 代表人董事 | 歸法人股東 | 歸法人股東 | 本人可領 |

## 二、報酬的授權

```
不可：概括授權董事會（章程或股東會都不行）
可以：
├── 章程：同業通常水準／總額上限範圍 → 授權董事會
└── 股東會：議定全體董事報酬總額 → 個別分配委由董事會
    例：總額 2,000 萬，董事會決議董事長 1,500 萬、其餘董事分 500 萬
```
