# 公司法13 筆記：董事會決議瑕疵原則無效與實務的三個例外（97台上925、113台上1491）

## 先對照股東會（見公司法10-筆記-07）：
- 股東會決議瑕疵**有明文**：程序瑕疵 → 得撤銷（§189）；內容瑕疵 → 無效（§191）；另有實務創設的**不成立**
- 董事會決議瑕疵**公司法沒有明文** → 只能看實務與學說

## 原則：違反就無效（97 台上 925）：
- 董事會決議有瑕疵，不論**召集程序**或其他瑕疵，原則上**無效**（實務與學者多數）
- 理由：董事會是公司的**權力中樞**，為確保權力**合法合理運作**、決議內容符合全體利益，應嚴格要求召集程序與決議內容符合法定
- 曾宛如支持：董事會**召開成本低**——執行機關、開會頻繁、人數少（三、五、七人）；瑕疵時重開也只需 3 日，緊急情事還能縮短
- 考律師司法官不能只背到這裡，要再背例外

## 例外一：未遵守通知期間，全體出席且無異議（104 台上 823）：
- §204 要求事先通知，目的是確保**各董事均得出席**參與議決
- 召集雖違反期間規定，但董事**全體出席**，且**無異議**而參與決議 → 瑕疵**補正**，決議有效
- **兩個都要有**：全體出席卻在會上抗議沒收到通知 → 不符合
- 學者多數肯定（曾宛如、劉連煜、王志誠）；講義註 205：沒充分準備就該當場異議，否則事後翻覆等於假程序之名推翻決議
- 邵慶平小批判：①開會時沒發現瑕疵，自然不會異議 ②沒出席但都知情且全體同意，是否還得重開（老師：董事會重開就好，問題不大）

## 通知對象包括監察人，未通知監察人原則無效：
- §204 I：通知各**董事及監察人**（選擇題會考）
- 為什麼要通知監察人：監察人**得列席董事會陳述意見**（§218-2 I），且有**違法制止**權（§218-2 II，見公司法12-筆記-12），不通知他就無從出席與制止
- 最高法院：**未通知監察人** → 決議**無效**

## 例外二：三名董事自行召集，不必書面通知（98 台上 871）：
- 公司董事缺額達 1/3 後只剩三名董事、沒有監察人；三名董事以董事身分召集，互選董事長
- 既是**全部三名董事**自己召集，本來就都知情 → **無須**三日前書面通知

## 例外三：瑕疵輕微不影響決議結果，或全體知悉無異議（113 台上 1491，最新）：
- 董事會決議要讓全體董事有機會參與、充分討論；違反 **§203 ~ §207** 或公開發行公司董事會**議事辦法**者，原則無效
- 例外：**瑕疵輕微、不影響決議結果**，或**全體董事知悉而無異議**
- 老師：113 台上 1491 實際上已涵蓋 104 台上 823

## 第四個例外是學者見解（講義 6-131，下次講）：
- 利害關係衝突時**迴避**的效力；法院例外只有上面三個

## 📖 法條原文速查

> **§204 I**　董事會之召集，應於三日前通知各**董事及監察人**。但章程有較高之規定者，從其規定。

> **§218-2**
> I　監察人得**列席董事會陳述意見**。
> II　董事會或董事執行業務有違反法令、章程或股東會決議之行為者，監察人應即通知董事會或董事停止其行為。

## 📋 實務見解速查

> **最高法院 97 年度台上字第 925 號**：董事會為公司之權力中樞，為確保權力之合法合理運作及決議內容之合法妥當，其召集程序及決議內容均須符合法律規定；違反者原則上無效。→ 原文建議查證

> **最高法院 104 年度台上字第 823 號**：董事會之召集雖違反 §204 通知期間之規定，惟全體董事均出席且無異議而參與決議者，瑕疵即已補正。→ 原文建議查證

> **最高法院 98 年度台上字第 871 號**：三名董事以董事身分自行召集董事會，召集董事即為全部董事，無須三日前書面通知。→ 字幕前後唸作「93」與「98」，採 98，建議查證

> **最高法院 113 年度台上字第 1491 號**：董事會違反 §203 至 §207 或公開發行公司董事會議事辦法者，除瑕疵輕微不影響決議結果，或全體董事知悉而無異議外，原則無效。→ 要旨依課堂講述整理，建議查證

> **最高法院（講義 6-107 ~ 6-108）**：董事會召集未通知監察人，決議無效。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事會召集程序違法，決議效力？」 | 原則**無效**（97 台上 925）；**不是**得撤銷 |
| 「未於期間前通知，但全體董事出席，決議有效？」 | 還要**無異議**，兩者兼具才補正（104 台上 823） |
| 「董事會召集通知的對象？」 | **董事及監察人** |
| 「董事會召集未通知監察人，決議效力？」 | **無效** |
| 「瑕疵輕微不影響決議結果？」 | 例外有效（113 台上 1491） |

## 一、股東會與董事會瑕疵對照

| | 股東會 | 董事會 |
|---|---|---|
| 明文 | 有（§189、§191） | 沒有 |
| 程序瑕疵 | 得撤銷 | 原則**無效** |
| 例外 | 裁量駁回（§189-1） | 104 台上 823、98 台上 871、113 台上 1491 |

## 二、例外整理

```
董事會決議瑕疵 → 原則無效（97 台上 925）
├── 例外一：期間不足，但全體出席＋無異議（104 台上 823）
├── 例外二：全部董事自行召集，不必書面通知（98 台上 871）
├── 例外三：瑕疵輕微不影響結果，或全體知悉無異議（113 台上 1491）
└── 學者第四例外：利害關係迴避（講義 6-131，下次講）
```
