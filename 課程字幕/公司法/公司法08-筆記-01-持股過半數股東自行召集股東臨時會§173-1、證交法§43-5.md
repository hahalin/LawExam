# 公司法08 筆記：持股過半數股東自行召集股東臨時會（§173-1、證交法§43-5）

## 開頭複習（§173，見公司法07-筆記-12）：
- 召集權人體系：①董事會（以會召集，不是以人召集）②監察人（§220 最重要，§245 多為選擇題）③少數股東（§173 I~III、IV）與持股過半數股東（§173-1）④臨時管理人、重整人、清算人（見本講筆記-02）
- §173 I~III 是原則：1 年＋3% → 書面請求董事會 → 15 日不為 → 報經主管機關**許可**；IV 是董事會無法行使職權狀態下的例外
- 經濟部的許可是**實質審查**召集事由，不是看格式

## 要件只有兩個：
- **繼續 3 個月以上**＋持有已發行股份總數**過半數**
- 符合就能**自行召集**股東臨時會：不必請求董事會、不必經主管機關許可、不必說明理由
- 立法理由（講義 5-8）：這類股東對公司經營及股東會有**關鍵性影響**
- 例：甲公司（臺灣便利商店）的日本母公司持股約 50.多%，即屬之

## 持股以股東名簿為準：
- §173-1 II：持股期間與持股數，以 §165 II、III **停止過戶時**的持股為準 → 即以**股東名簿**記載為準（閉鎖期間見公司法07-筆記-08）
- 召集時要讓其他股東知道**是誰**合計過半，不能只說「我們過半」
- 講義註 24：**111 台上 706**——未辦理過戶的股東召集臨時會，縱事實上已過半數，其餘股東無從得知其有無召集權限（判決對決議效力的結論建議查證）
- 過半數可以由數名股東**湊**（見公司法06-筆記-02）

## 無表決權股份算不算（固有爭點）：
- **肯定說（經濟部）**：條文只寫「已發行股份總數過半數」，沒有排除 → 有表決權、無表決權都算（文義解釋）
- **否定說**：違反立法理由——給這項權利是因為股東對公司有影響力，無表決權股份哪來的影響力
- 兩說都可採。經濟部對**所有少數股東權**都採同一立場：無表決權一起算；唯一例外是 **§369-4**（條文明文「有表決權」）

## 📖 法條原文速查

> **§173-1**（持股過半數股東自行召集）
> I 繼續**三個月以上**，持有已發行股份總數**過半數**股份之股東，得**自行召集**股東臨時會。
> II 前項股東持股期間及持股數之計算，以第一百六十五條第二項或第三項**停止股票過戶時**之持股為準。

> **§369-4 I**（從屬公司少數股東代位）　繼續一年以上，持有控制公司已發行**有表決權**股份總數或資本總額百分之一以上之股東，得以書面請求控制公司之監察人為公司對從屬公司提出訴訟。→ 建議查閱最新六法原文

> **證交法 §43-5 IV**（公開收購後的召集）　公開收購人與其關係人於公開收購後，所持有被收購公司已發行股份總數超過該公司已發行股份總數**百分之五十**者，得以書面記明提議事項及理由，**請求董事會**召集股東臨時會，不受公司法第一百七十三條第一項規定之限制。→ 建議查閱最新六法原文

## 📋 實務見解速查

> **111 台上 706**（講義註 24）：股東臨時會由**未辦理過戶**之股東召集，縱事實上持股過半數，其餘股東無從得知其有無召集權限。→ 字號依講義，判決全文建議查證
> **經濟部**：少數股東權之持股計算，有表決權、無表決權股份均計入；§369-4 例外。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「繼續 1 年以上、持股過半數之股東始得依 §173-1 自行召集？」 | ✕，**3 個月**以上 |
| 「依 §173-1 召集須先請求董事會或經主管機關許可？」 | ✕，**直接自行召集** |
| 「§173-1 持股之計算基準？」 | **停止過戶時**之持股（股東名簿） |
| 「數股東合計過半數得依 §173-1 召集？」 | **可以** |
| 「無表決權股份是否計入 §173-1 持股數？」 | 經濟部：**計入**；否定說：違反立法理由 |
| 「公司法少數股東權中，明文限於有表決權股份者？」 | **§369-4** |
| 「§173-1 召集有次數限制？」 | **沒有** |

## 一、§173、§173-1 對照

| | §173 I~III | §173 IV | §173-1 |
|---|---|---|---|
| 持股期間 | 1 年 | 無 | **3 個月** |
| 持股比例 | 3% | 3% | **過半數** |
| 請求董事會 | 要 | 不要 | 不要 |
| 主管機關許可 | 要 | 要 | **不要** |
| 說明理由 | 書面記明 | 報請許可時審查 | 不要 |

## 二、無表決權股份的計算

```
少數股東權的持股比例
├── 經濟部：條文只寫「已發行股份」→ 有、無表決權都算
│     └── 唯一例外：§369-4（明文「有表決權」）
└── §173-1 否定說：立法理由是「關鍵性影響」→ 無表決權不該算
```

## 三、§173-1 與證交法 §43-5 IV（2019 政大法研所考過）

- 問題：公開收購後持股超過 50% 的人，只能用證交法，還是公司法 §173-1 也能用？
- **少數說**：證交法是特別法，**特別法優先**；避免普通法的要件比特別法寬鬆
- **多數說＋主管機關**：兩條**都能用**，只是用法不同——①要件不同 ②立法慣例不同 ③立法理由（內涵本質）不同
- 老師：爭點不能說不重要，但已有固定見解，且實例題不好設計（要讓兩法都能用），出題機率不高
- 兩條的要件差異等上證交法再學
