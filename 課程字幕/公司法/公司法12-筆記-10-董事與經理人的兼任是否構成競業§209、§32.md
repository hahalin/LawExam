# 公司法12 筆記：董事與經理人的兼任是否構成競業（§209、§32）

## 四種兼任，只有一種有明文：
- **經理人兼經理人**：§32 前段明文**原則禁止**，不分是否同類業務都要經 §29 I 方式同意（見公司法02-筆記-08）
- **董事兼董事、董事兼經理人、經理人兼董事**：法條**沒有明文**
- 有明文的通常只考選擇題；沒有明文的三種才有爭議

## 沒有明文時討論什麼：
- 不是討論「是否直接禁止兼任」，而是討論兼任行為**是否構成競業行為**
- 判斷核心：有沒有**業務機密外洩之虞**（利益衝突）→ 兩家公司是否**同類業務**
  - 同類：兩家都是速食業者，或兩家都是晶圓代工 → 有利益衝突
  - 不同類：一家晶圓代工、一家牛排館 → 沒有機密可以外洩

## 依身分適用不同條文（電腦圖 6-13）：
- 董事那一端 → **§209**（股東會特別決議許可）
- 經理人那一端 → **§32 後段**「為他人經營同類之業務」（依 §29 I 方式同意）
- §32 前段的兼任禁止只直接適用於「經理人兼經理人」；董事兼經理人、經理人兼董事不能直接用前段
- 同類的董事兼經理人須**兩次許可**：兩家公司各一次，一個用 §209、一個用 §32，不要混在一起

## 實務例外：
- **百分之百持股的母子公司**、間接持股或關係企業之間兼任，實務認為**不需要 §209 許可**

## 近年考題（講義 6-48 ～ 6-50）：
- 經理人**當選**同類公司的**董事** → 構成競業，需要許可
- 經理人兼任同類公司的**監察人** → 不構成：監察人不執行業務，沒有競業禁止的適用；但仍要注意 §222（監察人不得兼任**本公司**董事、經理人）

## 📖 法條原文速查

> **§32**　經理人**不得兼任其他營利事業之經理人**，並不得**自營或為他人經營同類之業務**。但經依第二十九條第一項規定之方式同意者，不在此限。

> **§29 I ③**　股份有限公司經理人之委任、解任及報酬，應由**董事會**以董事過半數之出席，及出席董事過半數同意之決議行之。→ 其他公司類型的同意方式建議查閱最新六法原文

> **§209 I**　董事為自己或他人為屬於公司營業範圍內之行為，應對股東會說明其行為之重要內容並取得其許可。→ 本講筆記-08

> **§222**　監察人不得兼任公司董事、經理人或其他職員。

> 字幕校正：老師說「有限公司是董事會普通決議」為口誤，依 §29 I 應為**股份有限公司**由董事會決議。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「經理人兼任不同類公司的經理人，須同意？」 | **須**，§32 前段不分是否同類 |
| 「董事兼任不同類公司的董事，須 §209 許可？」 | **不須**，無業務機密外洩之虞 |
| 「董事兼任同類公司的董事？」 | **須** §209 股東會許可 |
| 「甲公司董事兼同類乙公司經理人？」 | 甲依 **§209**、乙依 **§32**，**兩次許可** |
| 「百分之百持股母子公司間兼任董事？」 | 實務：**不需** §209 許可 |
| 「經理人兼任同類公司監察人，構成競業？」 | **不構成**，監察人不執行業務 |

## 一、兼任表（電腦圖 6-13）

| 兼任型態 | 同類業務 | 不同類業務 | 依據 |
|---|---|---|---|
| 經理人兼經理人 | 須同意 | 須同意 | §32 前段（明文禁止） |
| 董事兼董事 | 須許可 | 不須 | §209（是否構成競業） |
| 董事兼經理人（甲董事、乙經理人） | 甲 §209 ＋ 乙 §32 | 都不須 | 兩次許可 |

## 二、判斷流程

```
兼任
 ├── 經理人兼經理人 → §32 前段，原則禁止，經 §29 I 同意
 └── 其他三種（無明文）
        ↓ 是否構成競業行為？
     有無業務機密外洩之虞 → 是否同類業務
        ├── 同類 → 董事端 §209、經理人端 §32 後段
        └── 不同類 → 不須許可
```
