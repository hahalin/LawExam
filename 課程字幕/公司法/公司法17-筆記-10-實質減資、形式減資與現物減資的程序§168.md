# 公司法17 筆記：實質減資、形式減資與現物減資的程序（§168）

## 減資原因分兩種（國考沒考過，避免看不懂）：
- **實質減資**：資本過剩、用不到那麼多資金 → 把錢**真的退還**給股東
- **形式減資**（會計上稱「彌補虧損的減資」）：
  - 公司持續虧損、**累積虧損**升高，淨值低於實收資本額，賺錢也補不完虧損、無法分派盈餘
  - 作法：**降低實收資本額**使其與淨值一致，用實收股本抵銷累積虧損
  - **不退還任何財產**，只是計算上取得平衡
  - 老師舉甲公司（大型軌道運輸公司）的例子：通車營運前買地、鋪軌、買車都在燒錢，累積虧損極高
  - 實質意義：當作那部分**從來沒有出資過**（原本 1,000 萬元只剩 200 萬元，就當作一開始只出 200 萬元）

## 形式減資的兩個效果：
- **每股淨值上升** → 投資人較願意買，市價較有上升動機
- 累積虧損打銷 → **馬上可以分派盈餘**（無虧損才能分派，見公司法15-筆記-09）
- 代價：原出資股東等於**認賠**那部分出資

## 現物減資（§168 II、III）：
- 實質減資時，以**現金以外財產**退還股款
- 退錢沒有爭議；退東西就會吵：甲拿土地、乙拿汽車、丙拿黃金，誰拿什麼、估價對不對都會有爭執
- 要件：
  - **董事會**普通決議召集股東會（§171）
  - 財產價值及抵充數額，董事會應於股東會前送交**會計師查核簽證**（估價難以精確，避免損害股東與債權人）
  - **股東會**決議（普通決議，與 §168 I 同）
  - 經**收受財產股東同意**（避免股東間不平等）
- 順序：**董事會 → 會計師 → 股東會 → 收受財產股東同意**

## 📖 法條原文速查

> **§168**
> II　公司減少資本，得以**現金以外財產**退還股款；其退還之財產及抵充之數額，應經**股東會決議**，並經該**收受財產股東之同意**。
> III　前項財產之價值及抵充之數額，**董事會**應於股東會前，送交**會計師查核簽證**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「形式減資是否退還股東財產？」 | **不退**，只是用實收股本抵銷累積虧損 |
| 「形式減資後每股淨值？」 | **上升** |
| 「實質減資？」 | 資本過剩，**真的退還**股東 |
| 「得否以現金以外財產退還股款？」 | **可以**（現物減資，§168 II） |
| 「現物減資須經誰同意？」 | 股東會決議＋**收受財產股東同意** |
| 「現物減資財產價值由誰查核？」 | 董事會於股東會前送**會計師查核簽證** |

## 一、實質減資（電腦圖 12-2）

```
減資前：資產 現金 900 萬 ＝ 負債 0 ＋ 實收股本 900 萬
減資後：資產 現金 500 萬 ＝ 負債 0 ＋ 實收股本 500 萬
        → 退還股東 400 萬元
```

## 二、形式減資（電腦圖 12-3）

| | 形式減資前 | 形式減資後 |
|---|---|---|
| 股數 | 100 萬股（面額 10 元） | 20 萬股（銷除 80 萬股） |
| 實收股本 | 1,000 萬元 | 200 萬元 |
| 累積虧損 | −800 萬元 | 0 |
| 現金（淨值） | 200 萬元 | 200 萬元（不退錢） |
| 每股淨值 | 2 元 | 10 元 |

- 會計分錄：借 實收股本 800 萬、貸 未分配盈餘（累積虧損）800 萬

## 三、現物減資流程

```
董事會（召集股東會）
   ↓ 財產價值、抵充數額送會計師查核簽證
股東會決議
   ↓
收受財產股東同意（不同意就不要這樣做）
```
