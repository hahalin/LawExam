# 公司法17 筆記：減資的債權人保護程序與換發股票（§281、§73、§74、§279）

## 債權人保護程序（電腦圖 12-1，只考選擇題）：
- §281：§73、§74 於**減少資本準用**之
  - 電腦圖 12-1 標題分兩塊：**減資** → §281 準用 §73、§74；**合併、分割** → §319（之後才講）
- 步驟：
  - ① 編造**資產負債表**及**財產目錄**：讓債權人知道公司現在的狀態
  - ② 決議後**通知及公告**債權人，指定 **30 日以上**期限，聲明債權人得於期限內提出**異議**
  - ③ 對提出異議的債權人**清償**或提供**相當擔保**
- 效果（§74）：
  - 沒有通知公告 → **不得對抗**債權人
  - 有通知公告、債權人**未異議** → 得對抗
  - 有異議、公司**有清償或提供擔保** → 得對抗
  - 有異議、公司**未清償也未提供擔保** → **不得對抗**
- 老師的記法：像跟家人或伴侶商量一件大事（出國一個月）：先告知；對方不高興就要處理；債權人要的是清償或擔保

## 減資的實施、申請減資登記：
- 講義 12-7 這兩段打叉，不重要

## 減資換發股票（§279）：
- 條文是「**換發**」→ 前提是公司**原本已發行股票**（§162 的實體股票）；減資後票面記載已經變更，**一定要換**
- 公司應於**減資登記後**，定 **6 個月以上**期限通知各股東換取，並聲明逾期不換取者**喪失股東權利**
- 期限內不換取 → **喪失股東權利**；公司得將股份**拍賣**，賣得金額給付該股東
- 合併股份時「不適於合併之股份」準用 §279 II（§280）；什麼是不適於合併之股份，老師說目前沒有定論

> 來源：公司法17 課程字幕 01:47:59 ~ 01:56:25（講義 12-7；電腦圖 12-1）
> 字幕中老師說「記名就通知、無記名就公告」；§73 II 條文是「分別通知及公告」，建議以條文為準查證。

## 📖 法條原文速查

> **§281**　第七十三條及第七十四條之規定，於**減少資本準用**之。

> **§73**
> I　公司決議合併時，應即編造**資產負債表**及**財產目錄**。
> II　公司為合併之決議後，應即向各債權人分別**通知及公告**，並指定**三十日以上**期限，聲明債權人得於期限內提出**異議**。

> **§74**　公司不為前條之通知及公告，或對於在指定期限內提出異議之債權人**不為清償**，或**不提供相當之擔保**者，**不得以其合併對抗債權人**。

> **§279**
> I　因減少資本換發新股票時，公司應於**減資登記後**，定**六個月以上**之期限，通知各股東換取，並聲明逾期不換取者，**喪失其股東之權利**。
> II　股東於前項期限內不換取者，即喪失其股東之權利，公司得將其股份**拍賣**，以賣得之金額，給付該股東。
> → III 罰鍰規定建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「減資的債權人保護依據？」 | **§281 準用 §73、§74** |
| 「異議期間？」 | 指定 **30 日以上** |
| 「未通知公告即減資的效果？」 | **不得對抗**債權人（不是無效） |
| 「債權人異議，公司提供相當擔保？」 | **得對抗** |
| 「減資換發股票的通知期限？」 | 減資登記後定 **6 個月以上** |
| 「逾期不換取股票？」 | **喪失股東權利**，公司得**拍賣**並給付賣得金額 |

## 一、債權人保護流程（電腦圖 12-1）

```
減資決議 → 編造資產負債表、財產目錄
   ↓
通知及公告（30 日以上異議期間）
   ├── 未通知公告 ──────────────→ 不得對抗
   └── 已通知公告
         ├── 未異議 ───────────→ 得對抗
         └── 異議
               ├── 清償或提供擔保 → 得對抗
               └── 都沒做 ────────→ 不得對抗
```

## 二、換發股票

```
減資登記 → 定 6 個月以上期限通知換取
   ├── 期限內換取 → 新股票
   └── 逾期不換 → 喪失股東權利 → 公司拍賣，價金給該股東
```
