# 公司法02 筆記：不設董事會、不置監察人與董事最低人數（§128-1、§192、證交法§26-3）

## 得依章程不設董事會，置董事一人或二人：
- §128-1 II 與 §192 II 內容相同：**得依章程規定不設董事會**，置董事**一人或二人**
- 置董事**一人**：該董事就是**董事長**，董事會職權也由他行使
- 置董事**二人**：**準用**本法有關董事會之規定
- 大前提要打星號：**章程規定不設董事會** → 不論一人或二人，公司都**沒有董事會**
- 2018 年修法，為回應企業實務需求，開放**非公開發行公司**（含一人公司）採用

## 只有一人公司可以不置監察人：
- §128-1 III：**第一項公司**（政府或法人股東一人）得依章程規定**不置監察人**
- 理由：只有一個股東，決定權在他，也沒有其他需要保障的股東，由股東自行監督
- 公司法**沒有**開放兩人以上股東的公司不置監察人 → 只有 §128-1 的公司可以

## 董事最低人數：
- **公開發行公司**：至少 **5 人**（證交法 §26-3 I）→ 一試考過兩三次
- **非公開發行公司**：原則至少 **3 人**（§192 I）
- 例外：章程規定**不設董事會** → 董事 1 人或 2 人（§192 II、§128-1 II）

## 📖 法條原文速查

> **§128-1**
> II　前項公司，得依章程規定**不設董事會**，置董事**一人或二人**；置董事一人者，以其為**董事長**，董事會之職權由該董事行使，不適用本法有關董事會之規定；置董事二人者，**準用**本法有關董事會之規定。
> III　第一項公司，得依章程規定**不置監察人**；未置監察人者，不適用本法有關監察人之規定。

> **§192**（董事人數）
> I　公司董事會，設置董事**不得少於三人**，由股東會就有行為能力之人選任之。
> II　公司得依章程規定不設董事會，置董事一人或二人。置董事一人者，以其為董事長，董事會之職權並由該董事行使，不適用本法有關董事會之規定；置董事二人者，準用本法有關董事會之規定。
> → 建議查閱最新六法原文

> **證交法 §26-3 I**
> 已依本法發行股票之公司董事會，設置董事**不得少於五人**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公開發行公司董事最少幾人？」 | **5 人**（證交法 §26-3 I） |
| 「非公開發行公司董事會最少幾人？」 | 原則 **3 人**（§192 I） |
| 「可否只設董事一人？」 | 可以，但須**章程規定不設董事會**（§192 II、§128-1 II）；公開發行公司不行 |
| 「置董事一人時誰是董事長？」 | 該董事即**董事長**，並行使董事會職權 |
| 「置董事二人時，有無董事會？」 | **沒有董事會**，只是**準用**董事會規定 |
| 「股東 2 人以上之股份有限公司可否章定不置監察人？」 | **不可**；只有**政府或法人股東一人**的公司可以（§128-1 III） |

## 一、董事人數體系（電腦圖 1-11）

```
股份有限公司的董事人數
│
├── 公開發行公司 ── 最少 5 人（證交法 §26-3 I）
│
└── 非公開發行公司
     ├── 原則：設董事會，最少 3 人（§192 I）
     └── 例外：章程規定不設董事會（§192 II；一人公司 §128-1 II）
           ├── 董事 1 人 → 即董事長，兼行使董事會職權
           └── 董事 2 人 → 準用董事會規定
```

## 二、一人公司把所有機關集中在一人身上（電腦圖 1-10）

老師的真實例子：鴻海百分之百持股的投資子公司，章程不設董事會、只置董事一人、未置監察人。

| 機關 | 依據 | 由誰擔任 |
|---|---|---|
| 董事 | §128-1 IV 指派 | 那一位董事 |
| 董事長（法定代表機關） | §128-1 II | 同一人 |
| 董事會（業務執行） | §128-1 II | 同一人 |
| 股東會職權 | §128-1 I | 同一人（以董事會身分行使） |
| 監察人 | §128-1 III | **無需設置** |

- 老師的比喻：對方要找董事、董事長、董事會、股東會談，出來的都是同一個人，而且沒有監察人監督他。

## 三、附：公司法的核心思想（老師補充，國考不考）

- **內部監控**：股東會、董事會、監察人三大機關
- **股東有限責任**：學者普遍認為是公司存在的意義
- 公司法條文本質上是三方利益在拉扯：**經營者（董事會）、交易相對人（債權人）、少數股東**
- 近年另有 **ESG**（公司的社會責任）；老師認為主要是大公司議題，國考出題機率低
