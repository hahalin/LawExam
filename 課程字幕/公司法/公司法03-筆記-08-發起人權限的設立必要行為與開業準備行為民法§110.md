# 公司法03 筆記：發起人權限的設立必要行為與開業準備行為（民法§110）

## 權限範圍內的行為才歸屬成立後公司：
- 依同一體說，設立中公司的權利義務原則上都由成立後公司承受（見 公司法03-筆記-04）
- 但發起人雖是設立中公司的執行與代表機關，權限仍有限制；以「是否為設立所必要」區分兩類
- 區分理由（老師說不會考）：①設立中公司**沒有監督機關** ②避免侵害成立後**董事會**的權限（發起人順手在阿拉斯加買 5,000 畝地就不行）

## 設立必要費用：成立後公司承受：
- 以**設立公司為直接目的**的行為：**籌備處的租賃**、**設立人員的僱用**、認股書及公開說明書的印製、訂立章程、募集廣告的刊登
- 記不住至少記前兩個：租籌備處、請籌備人員
- 基於同一體說，由成立後公司負擔

## 開業準備行為：無權代表，類推無權代理：
- 為公司成立後營業所做的準備：**原料的訂購**、**機械的購買**、**廠房土地的訂購**、營業用員工的聘請
- 記不住至少記：**廠房土地**、**機械購買**；簡單說就是「大張旗鼓」的事
- 最高法院：發起人權限**不包括**開業準備行為 → **無權代表**，類推適用**無權代理**
- 公司成立後**承認** → 對公司生效
- 公司成立後**不承認** → 類推**民法 §110**，發起人對**善意相對人**負損害賠償責任

## 公司不能成立時不必分：
- 一律 §150 發起人連帶（其他公司依民法 §681），見 公司法03-筆記-05

## 📖 法條原文速查

> **民法 §110**（無權代理人之責任）
> 無代理權人，以他人之代理人名義所為之法律行為，對於**善意之相對人**，負**損害賠償**之責。

> **民法 §170 I**（無權代理）
> 無代理權人以代理人之名義所為之法律行為，非經本人**承認**，對於本人不生效力。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「發起人租用籌備處辦公室，公司成立後由誰負擔？」 | **成立後公司**（設立必要行為，同一體說） |
| 「發起人購買工廠廠房、土地，公司成立後當然歸屬公司？」 | **否**，開業準備行為，須公司**承認** |
| 「開業準備行為的性質？」 | 發起人**無權代表**，類推**無權代理** |
| 「公司不承認開業準備行為，發起人責任依據？」 | 類推**民法 §110**，對善意相對人負損害賠償 |
| 「公司不能成立，需否區分兩類行為？」 | **不需要**，一律 §150 |
| 「設立人員的僱用 vs. 營業員工的聘請」 | 前者**設立必要**；後者**開業準備** |

## 一、整體分流（老師板書）

```
發起人以設立中公司名義所為的行為
├── 公司不能成立 → 不分 → §150 發起人連帶（見 筆記-05）
└── 公司成立
     ├── 設立必要費用 → 成立後公司當然承受（同一體說）
     └── 開業準備行為 → 無權代表，類推無權代理
            ├── 公司承認 → 對公司生效
            └── 公司不承認 → 類推民法 §110，發起人對善意相對人賠償
```

- 公司成立後，發起人對公司在登記前所負的債務還要負 **§155 II** 連帶責任，接在這張圖的後面，見 公司法03-筆記-10

## 二、兩類行為對照

| | 設立必要費用 | 開業準備行為 |
|---|---|---|
| 目的 | 直接為了**設立**公司 | 為了公司成立後**營業** |
| 例 | 租籌備處、僱設立人員、印認股書與公開說明書、訂章程、刊登募集廣告 | 訂原料、買機械、訂廠房土地、聘營業員工 |
| 發起人權限 | 有 | **無**（最高法院） |
| 公司成立後 | 當然承受 | 承認才生效 |

## 三、選擇題（講義例題）

- 題目：設立過程中涉及**工廠廠房**的交易，問效力歸屬（題幹細節以講義為準）
- 廠房土地不是設立公司所必須 → **開業準備行為**
- 「僅得由當事人負責」✗：等於直接假設公司不承認，但公司可能承認
- 「當然歸屬成立後公司」✗：要承認才歸屬
- 「成立後公司當然與發起人共同負責」✗：同樣要先承認
- 正解：**經成立後公司承認後，才對公司發生效力**
