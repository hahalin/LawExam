# 公司法02 筆記：經理人的兼任禁止與競業禁止（§32）

## 前段：兼任其他營利事業經理人之禁止：
- 經理人**不得兼任其他營利事業之經理人**
- 公司法中**唯一**的「兼任禁止」，而且是經理人獨有
- 「其他營利事業」→ 不問業務種類：麥當勞的經理人不能去當肯德基的經理人，**也不能去當臺積電的經理人**，兩者毫無關係也不行
- 只禁止兼任「**經理人**」
- 老師說今年國考考過

## 後段：競業禁止：
- 不得**自營或為他人經營同類之業務** → 一般的競業禁止
- 不特別：無限公司、有限公司、兩合公司、股份有限公司的相關人員都有類似規定

## 例外：依 §29 I 方式事前同意：
- 但書：經依 **§29 I** 規定之方式同意者，不在此限 → 要**事前許可**
- 所以 §29 實際上管**四件事**：委任、解任、報酬，以及 **§32 的兼任與競業**
- 兼任時，**兩家公司各自同意一次** → 一共兩次

## 違反的效果：
- 行為**仍然有效**，不會變成無效
- 公司可以主張**利益歸入**：公司法沒有明文；學說多數與實務認為類推**民法 §563**（2 個月／1 年）；也有學者主張依 **§23 III**

## 📖 法條原文速查

> **§32**（經理人之兼職與競業禁止）
> 經理人**不得兼任其他營利事業之經理人**，並**不得自營或為他人經營同類之業務**。但經依**第二十九條第一項**規定之方式同意者，不在此限。

> **民法 §563**（經理人、代辦商違反競業禁止之效果）
> I　經理人或代辦商，有違反前條規定之行為時，其商號得請求因其行為所得之利益，作為損害賠償。
> II　前項請求權，自商號知有違反行為時起，經過**二個月**或自行為時起，經過**一年**不行使而消滅。

> **§23 III** → 見 公司法02-筆記-10

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「文具公司經理人兼任半導體公司經理人，不同類業務，可以嗎？」 | **不可以**，兼任禁止不問業務種類 |
| 「§32 前段禁止兼任什麼？」 | 其他營利事業之**經理人**（只限經理人） |
| 「經理人兼任如何合法？」 | 依 **§29 I** 方式**事前同意** |
| 「兼任兩家公司經理人，要誰同意？」 | **兩家公司各同意一次** |
| 「違反 §32 之行為效力？」 | **有效**；公司可主張利益歸入 |
| 「違反 §32 之歸入權依據？」 | 法無明文；多數類推**民法 §563**，另有學者主張 **§23 III** |

## 一、§32 結構

```
§32
├── 前段：不得兼任其他營利事業之經理人 ── 公司法唯一的兼任禁止，不問業務種類
├── 中段：不得自營或為他人經營同類業務 ── 一般競業禁止
└── 但書：依 §29 I 方式事前同意 → 不在此限
          ├ 無限、兩合：全體無限責任股東過半數
          ├ 有限：全體股東表決權過半數
          └ 股份有限：董事會普決
```

## 二、兩次同意（電腦圖 2-2）

| | 臺積電（股份有限公司） | 臺灣優衣庫（有限公司） |
|---|---|---|
| 經理人 | 阿貓 | 阿貓 |
| 同意兼任的方式 | **董事會普通決議** | **全體股東表決權過半數** |
| 次數 | 一次 | 一次 |

→ 兼任一定是**兩次同意**。

## 三、考題（講義註釋 21）

### 事實
1. 生產販賣文具的 A 公司（股份有限公司）選任甲為推廣部經理
2. B 公司（有限公司）想借重甲，經**過半數股東同意**聘甲為業務部經理，並表示甲**不用辭去** A 公司職務
3. 問：兼任是否合法？

### 分析
- 甲同時是 A、B 兩家公司的經理人 → 需要**兩家各自同意**
- 選項「因不是同類業務所以合法」→ 錯，兼任禁止與是否同類無關
- 選項「未經 B 公司全體股東同意」→ 錯，有限公司是過半數，B 已經同意
- 正解：**未經 A 公司董事會決議同意 → 不合法**
