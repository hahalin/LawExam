# 公司法05 筆記：命令解散與裁定解散（§10、§11）

## 命令解散（§10）：
- 主體：**主管機關**（經濟部）；發動：**依職權**或**利害關係人申請**
- 事由**具體明確**，共四款：
  - ①② 6 個月不營業（但書：延展登記、停業登記）→ 見本講筆記-02
  - ③ 名稱經判決確定不得使用，6 個月內未變更，經限期辦理仍未辦妥 → 見 公司法04-筆記-09
  - ④ 資本額查核簽證文件未於設立登記後 30 日內檢送 → 見 公司法04-筆記-11
- 第 ③ 款為何最後只能解散：主管機關無從替公司決定新名稱，公司拒不改名，只能命令解散

## 裁定解散（§11）：
- 主體：**法院**；發動：**股東聲請**（法院不告不理）
- 事由**抽象**：公司之經營有**顯著困難**或**重大損害**
  - 什麼叫顯著困難、重大損害，學說與實務都沒有劃一標準，由法院個案判斷
- 程序：徵詢**主管機關及目的事業中央主管機關**意見，並通知公司**提出答辯**後，才裁定
- 聲請股東資格（股份有限公司）：繼續 **6 個月以上**持有已發行股份總數 **10% 以上** → 一定要背

## 「6 個月 10%」只出現在兩條：
- **§11 II** 裁定解散的聲請股東
- **§282 I ①** 重整的聲請股東（見本講筆記-06）
- 老師：10% 是少數股東權中**要求最高**的比例，在公開發行公司已算超級大股東

## 撤銷廢止登記也是強制解散事由：
- 經主管機關依 §9 等規定撤銷或廢止登記者，講義列為強制解散事由，效果是準用清算（§26-1，見本講筆記-01）

## 防止解散的方法（講義 2-71，只挑考點）：
- §10 各款**但書**：選擇題常考
- **變更組織**：會考，見本講筆記-10
- **重整**（§282 以下）：限公開發行公司，見本講筆記-06
- 章程事由變更、人數不足補人等，老師說沒考過

## 📖 法條原文速查

> **§10**（命令解散）
> 公司有下列情事之一者，**主管機關**得**依職權或利害關係人之申請**，**命令解散**之：
> 一、公司設立登記後**六個月**尚未開始營業。但已辦妥延展登記者，不在此限。
> 二、開始營業後自行停止營業**六個月**以上。但已辦妥停業登記者，不在此限。
> 三、公司名稱經法院判決確定不得使用，公司於判決確定後六個月內尚未辦妥名稱變更登記，並經主管機關令其**限期辦理**仍未辦妥。
> 四、未於第七條第一項所定期限內，檢送經會計師查核簽證之文件者。但於主管機關命令解散前已檢送者，不在此限。

> **§11**（裁定解散）
> I　公司之經營，有**顯著困難**或**重大損害**時，**法院**得據**股東之聲請**，於徵詢主管機關及目的事業中央主管機關意見，並通知公司提出答辯後，**裁定解散**。
> II　前項聲請，在股份有限公司，應有繼續**六個月以上**持有已發行股份總數**百分之十**以上股份之股東提出之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「命令解散的主體與發動方式？」 | **主管機關**；依職權或利害關係人申請（§10） |
| 「裁定解散的主體與發動方式？」 | **法院**；依**股東聲請**（§11 I） |
| 「股份有限公司聲請裁定解散的股東資格？」 | 繼續 **6 個月**以上、持股 **10%** 以上（§11 II） |
| 「裁定解散的事由？」 | 經營有**顯著困難**或**重大損害**（抽象，個案判斷） |
| 「法院裁定解散前應踐行的程序？」 | 徵詢主管機關及目的事業中央主管機關意見、通知公司答辯 |
| 「公司法中哪兩條要求 6 個月 10%？」 | **§11 II**、**§282 I ①** |
| 「命令解散或裁定解散後是否清算？」 | **要清算**（§24） |

## 一、電腦圖 2-17：兩種強制解散對照

| | 命令解散 §10 | 裁定解散 §11 |
|---|---|---|
| 主體 | 主管機關 | 法院 |
| 形式 | 命令 | 裁定 |
| 事由 | 具體明確（四款） | 抽象（顯著困難、重大損害） |
| 發動 | 依職權或利害關係人申請 | 股東聲請（6 個月、10%） |
| 審查程序 | — | 徵詢主管機關意見＋公司答辯 |
| 解散後 | 清算 | 清算 |

## 二、記憶方法

```
主管機關 → 命令 → 具體四款 → 職權也可以
法　　院 → 裁定 → 抽象事由 → 一定要股東聲請（不告不理）
                                   └─ 6 個月 10%（＝ §282 重整聲請股東）
```
