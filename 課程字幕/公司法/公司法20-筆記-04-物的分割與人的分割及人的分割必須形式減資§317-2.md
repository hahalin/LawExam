# 公司法20 筆記：物的分割與人的分割及人的分割必須形式減資（§317-2）

## 區分標準（講義 16-5）：
- 分割對價由**被分割公司**取得 → **物的分割**
- 分割對價由被分割公司的**全體股東**取得 → **人的分割**
- 法律明文承認：§317-2 I ④「**被分割公司或其股東**所取得股份之總數、種類及數量」→ 前半「被分割公司」＝物的分割，後半「其股東」＝人的分割

## 物的分割：
- 把一大塊資產切給新公司，沒有白吃的午餐 → 新公司把對價（通常是股份）交給被分割公司
- 被分割公司資產換資產，資產負債表平衡，**不需減資**

## 人的分割：
- 新公司把對價交給被分割公司的**全體股東**，**依持股比例**分配
- 為什麼可以給股東：公司本質上由股東**按持股比例**持有，公司資產就是股東按比例持有的資產 → 給公司或按比例給全體股東都可以
- 一定要「全體」、一定要「依比例」

## 人的分割必須形式減資：
- 被分割公司資產減少，卻沒有任何資產增加；負債不動
- 資產＝負債＋股東權益 → 只能在股東權益項下調整
- 未分配盈餘、法定盈餘公積、特別盈餘公積、資本公積都不能動 → 只能減**股本（實收資本額）**
- 結論：被分割公司**必須**做**形式減資**，不是可以不做；對應 §317-2 I ⑦ 資本減少有關事項
- 國考選擇題只考過一次

## 📖 法條原文速查

> **§317-2 I**　第三百十七條第一項之分割計畫，應以書面為之，並記載下列事項：
> ③ 承受營業之既存公司發行新股或新設公司發行股份之總數、種類及數量。
> ④ 被分割公司**或其股東**所取得股份之總數、種類及數量。
> ⑦ 被分割公司之**資本減少**時，其資本減少有關事項。
> → 其餘各款見本講筆記-05；建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「物的分割與人的分割的區分標準？」 | 對價由**被分割公司**或其**全體股東**取得 |
| 「人的分割，新公司股份如何分配？」 | 由被分割公司股東**依持股比例**取得 |
| 「人的分割，被分割公司是否須減資？」 | **必須**（形式減資） |
| 「物的分割，被分割公司是否須減資？」 | **不須** |
| 「物的分割不須減資，因此不須通知債權人？」 | **錯**；仍要踐行債權人保護程序（§319 準用 §73、§74） |
| 「公司法上分割的法律依據哪一款承認人的分割？」 | §317-2 I ④「或其股東」 |

## 一、資產負債表算給你看

```
甲公司分割前：資產 100 億 ＝ 負債 60 億 ＋ 股東權益 40 億（其中股本 30 億）
把 20 億的部門分割給乙公司

物的分割：乙的股份給甲
  資產 100 億（部門 −20 億、乙公司股份 +20 億）＝ 負債 60 ＋ 權益 40 → 平衡，不減資

人的分割：乙的股份給甲的全體股東（依比例）
  資產 80 億 ＝ 負債 60 ＋ 權益 ？
  → 權益只能剩 20 億 → 股本減 20 億 → 必須形式減資
```

## 二、考古題（講義 16-5 註釋 6）逐項判斷

| 選項敘述 | 判斷 |
|---|---|
| 先經董事會決議，再經股東會決議 | 正確（§317、§316） |
| 人的分割：新設公司新股由股東依比例取得，被分割公司須減資 | 正確 |
| 分割有助於縮小規模、專業化與效率化 | 正確（功能面的敘述） |
| 物的分割：新股由被分割公司取得，不須減資，**不需通知債權人** | 前兩句正確，**最後一句錯** |
