# 公司法12 筆記：裁判解任的立法目的與先行程序要件（§200）

## 立法目的：法院退居第二線（電腦圖 6-9）：
- 原始設定：董事的選任（§198）與解任（§199）都由**股東會**決定，股東自己內部解決
- 法院是**第二線**：股東會被大股東把持，明明不適任的董事卻不被解任 → 才由法院**矯正不當的股東會決議**
- 作為保護公司與少數股東的救濟

## 要件一：事由（§200 與 §199 的差別）：
- 執行業務有**重大損害公司之行為**，或**違反法令或章程之重大事項**——兩種都要「重大」
- §199 不必講事由，不講只是要賠錢；§200 一定要有兩種事由之一

## 要件二：主體：
- 持有已發行股份總數 **3% 以上**的股東（選擇題會考）

## 要件三：先行程序——「股東會未為決議將其解任」：
- 解釋：**§199 解任議案曾提出於股東會，但未通過**（提出且被否決）
- 不能跳過股東會直接起訴，即使持股達 3% 也不行
- 如何讓議案上股東會：請董事會列入（很難），或用 **§172-1 股東提案權**（見公司法08-筆記-07）
- 議案若通過就直接解任，不必再訴請裁判
- 為什麼這樣解釋：
  - ①若不必先提出議案，這個要件就**形同不存在**
  - ②法院是第二線、矯正不當的股東會決議 → 要先有一個不當的決議
  - ③條文寫「**於股東會後三十日內**」→ 一定有一次股東會，就是否決解任議案的那次

## 要件四：期間：
- **股東會後 30 日內**訴請法院裁判

## 裁判解任的效力範圍：
- 到**該次任期屆滿**為止，下一任不受限制（跨任期問題見本講筆記-07）

## 監察人：
- §227 準用 §200（投保法 §10-1 也同時提到 §227 準用 §200）

## 📖 法條原文速查

> **§200**（裁判解任）
> 董事執行業務，有**重大損害公司之行為**或**違反法令或章程之重大事項**，**股東會未為決議將其解任**時，得由持有已發行股份總數**百分之三以上**股份之股東，於**股東會後三十日內**，訴請法院裁判之。

> **§199 I 前段**　董事得由股東會之決議，隨時解任。→ 本講筆記-03

> **§172-1 I**　持有已發行股份總數百分之一以上股份之股東，得向公司提出股東常會議案。→ 詳見公司法08-筆記-07

> **§227**　第一百九十六條至第二百條……之規定，於監察人準用之。→ 準用條號範圍建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「訴請裁判解任董事的股東持股門檻？」 | **3% 以上** |
| 「起訴期間？」 | **股東會後 30 日內** |
| 「§200 的事由？」 | **重大**損害公司之行為，或違反法令或章程之**重大**事項 |
| 「持股 5% 的股東未經股東會直接訴請裁判解任？」 | **不合法**，須先有解任議案提出於股東會而**未通過** |
| 「§199 解任是否須有事由？」 | **不須**；無正當理由只是要賠償 |
| 「裁判解任的效力及於下一任？」 | **否**，到該次任期屆滿為止 |

## 一、§199 與 §200 對照

| | 決議解任（§199） | 裁判解任（§200） |
|---|---|---|
| 機關 | 股東會（第一線） | 法院（第二線） |
| 事由 | 不需要（無正當理由要賠） | 重大損害公司／違反法令章程重大事項 |
| 主體 | 股東會特別決議 | 持股 3% 以上股東 |
| 程序 | — | 解任議案提出於股東會而未通過 |
| 期間 | 隨時 | 股東會後 30 日內 |

## 二、案例：先行程序

#### 事實
1. 甲公司是上市公司，董事長乙執行業務有重大損害公司之行為
2. 股東丙持股 4%，想讓法院解任乙

#### 分析
1. 丙不能直接起訴，即使持股達 3%
2. 丙可依 §172-1 提出「解任乙」的議案，列入股東常會
3. 股東會否決該議案 → 丙於該次股東會後 30 日內訴請法院裁判解任
4. 股東會通過該議案 → 乙已依 §199 解任，不必再起訴

```
§199 解任議案提出於股東會
     ├── 通過 → 已解任，不必訴請
     └── 否決 → 股東會後 30 日內，持股 3% 以上股東訴請法院裁判解任（§200）
```
