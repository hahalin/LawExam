# 公司法17 筆記：法定減資不依比例、不須股東會決議與債權人保護（§168、§167、§167-1）

## 名稱與依據：
- 法條沒有命名；「法定減資」是**經濟部**給的名稱，學者也接受
- 出處：§168 I **但書**「但本法或其他法律另有規定者，不在此限」
  - 本法另有規定：**§167 II**、**§167-1 II**
  - 其他法律另有規定：**證交法 §28-2 IV**（證交法時再講）

## 辨識句：
- 公司法裡看到「**視為公司未發行股份，並為變更登記**」→ 就是法定減資
  - §167-1 II：員工庫藏股 3 年內未轉讓員工（本講筆記-01）
  - §167 II：依法收回或收買的股份，屆期未出售
- 變更登記是指**經濟部**登記的已發行股份總數與資本額，不是章程

## 法定減資的三個「不需要」（經濟部）：
- **不需要股東會決議**：法律直接規定，**董事會普通決議**即可
- **不需要依持股比例**減少
- **不需要**踐行**債權人保護程序**

## 為什麼不依比例：
- 一般減資：全體股東照比例一起縮小
- 法定減資：只讓**特定那一批股份**變成未發行股份，其他股東持股數不動

> 來源：公司法17 課程字幕 01:56:25 ~ 02:08:04（講義 12-7 ~ 12-8）

## 📖 法條原文速查

> **§168 I**　公司非依股東會決議減少資本，不得銷除其股份；減少資本，應依股東所持股份比例減少之。**但本法或其他法律另有規定者，不在此限。**

> **§167-1 II**　前項公司收買之股份，應於三年內轉讓於員工，屆期未轉讓者，**視為公司未發行股份，並為變更登記**。

> **§167 II**　公司依前項但書、第一百八十六條規定，所收回或收買之股份，應於六個月內，按市價將其出售，屆期未經出售者，**視為公司未發行股份，並為變更登記**。→ 建議查閱最新六法原文

> **證交法 §28-2 IV**　→ 上市上櫃公司買回股份逾期未轉讓，視為未發行股份；條文建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法定減資的法源？」 | **§168 I 但書** |
| 「公司法中哪兩條屬法定減資？」 | **§167 II**、**§167-1 II** |
| 「法定減資須否股東會決議？」 | **不須**，董事會普通決議（經濟部） |
| 「法定減資須否依持股比例？」 | **不須** |
| 「法定減資須否踐行債權人保護程序？」 | **不須** |
| 「條文出現『視為公司未發行股份，並為變更登記』？」 | 就是**法定減資** |

## 一、數字例：一般減資與法定減資

**甲公司已發行 100 萬股**：甲 45 萬股、乙 20 萬股、丙 30 萬股，另有 5 萬股是公司依 §167-1 買回的庫藏股。

```
一般減資（減為 50 萬股）：大家照比例一起縮小

法定減資：5 萬股庫藏股 3 年內未轉讓員工
   ↓ 視為未發行股份，並為變更登記
已發行股份 100 萬 → 95 萬股
甲 45 萬、乙 20 萬、丙 30 萬 → 都不變
```

## 二、一般減資與法定減資

| | 一般減資（§168 I 本文） | 法定減資（§168 I 但書） |
|---|---|---|
| 決議 | 股東會普通決議 | 董事會普通決議 |
| 比例 | 依持股比例 | 不依比例，只消除特定股份 |
| 債權人保護 | 準用 §73、§74 | 不需要 |
| 不得臨時動議 | 有（§172 V） | 不涉及股東會 |
