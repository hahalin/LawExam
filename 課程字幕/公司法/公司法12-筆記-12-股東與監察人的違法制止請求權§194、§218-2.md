# 公司法12 筆記：股東與監察人的違法制止請求權（§194、§218-2）

## 事前預防與事後追訴：
- 小孩走向家裡的花瓶，先叫他離遠一點 → **事前預防**；花瓶已經打破，叫他賠 → **事後追訴**
- 董事要做違法行為前先制止 → 制止請求權；行為已經做完就沒有制止的問題，只剩求償
- 本講只講事前預防（講義 6-58），以選擇題為主；事後追訴下一講從 6-59 開始

## 股東的違法制止請求權（§194）：
- 主體：**繼續一年以上**持有股份的股東——**單獨股東權**，**不需要持股比例**（選擇題超級愛考）
- 對象（法條文字）：**董事會**
- 事項（法條文字）：董事會決議為違反**法令或章程**的行為
- 立法目的：強化股東權益，讓股東能事先預防
- 不一定要起訴；有必要時可聲請**假處分**

## 監察人的違法制止（§218-2 II）：
- 對象：**董事會或董事**
- 事項：違反**法令、章程或股東會決議**
- 目的：強化監察人權限，事先制止
- 老師：§218-2 是寫得最完整、最清楚的一條

## §194 少寫的部分，解釋上補齊：
- **股東會決議**：§193 I 規定董事會應依股東會決議執行業務 → 違反股東會決議也可以制止
- **董事**：①可以及時制止，避免損害發生與擴大 ②**舉重以明輕**：董事會都能制止，董事更可以
- 沒有董事會（例如 §128-1 不設董事會，見公司法02-筆記-02）時沒有董事會決議可言 → 仍可直接對董事行使制止權（學者見解，沒考過）

## 兩者關係：
- **並行不悖**（劉連煜用語）：兩者可以**同時並用、不分先後**，沒有誰要先行使
- 都是**事前預防**，行為已經執行完畢就沒有用武之地

## 📖 法條原文速查

> **§194**（股東之制止請求權）
> **董事會決議**，為違反**法令或章程**之行為時，**繼續一年以上**持有股份之股東，得請求董事會**停止其行為**。

> **§218-2 II**（監察人之制止）
> **董事會或董事**執行業務有違反**法令、章程或股東會決議**之行為者，監察人應即通知董事會或董事**停止其行為**。

> **§193 I**　董事會執行業務，應依照法令章程及股東會之決議。→ 本講筆記-11

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股東行使 §194 制止請求權的要件？」 | **繼續一年以上**持股，**不問持股比例** |
| 「持股 0.5%、已持有兩年的股東可以請求？」 | **可以** |
| 「股東須先請求監察人制止，才能自己請求？」 | **不須**，兩者並行不悖、**不分先後** |
| 「監察人制止的對象與事項？」 | 董事會或董事；違反法令、章程或股東會決議 |
| 「董事會決議已執行完畢，還能請求制止？」 | **不能**，制止是事前預防 |
| 「股東可否制止違反股東會決議的行為、可否對個別董事？」 | 解釋上**都可以** |

## 一、§194 與 §218-2 II 對照（電腦圖 6-16）

| | 股東（§194） | 監察人（§218-2 II） |
|---|---|---|
| 主體要件 | 繼續一年以上持股，不問比例 | 監察人 |
| 對象 | 董事會（解釋上及於董事） | 董事會或董事 |
| 違反事項 | 法令、章程（解釋上及於股東會決議） | 法令、章程、股東會決議 |
| 性質 | 事前預防 | 事前預防 |
| 關係 | 並行不悖、不分先後 | 並行不悖、不分先後 |

## 二、經典選擇題（講義註 110）

- 公司董事會決議違反法令；甲是股東（持股比例不高），乙、丙是監察人
- 「誰可以請求停止該行為？」
  - 以甲持股比例不足為由否定 → ✕（不需要持股比例）
  - 須先由監察人制止，股東才能請求 → ✕（不分先後）
  - **甲、乙、丙都可以單獨請求** → ✔
