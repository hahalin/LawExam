# 憲法02 筆記：用盡審級救濟

## 判斷關鍵：
- 一句話：**你有沒有努力過**（先在一般法院救濟，失敗了才輪到憲法法庭）
- 釋憲是「**不得已**」才走的路，不能直接敲大法官的門

## 算用盡：
- 打到最後一審，定讞在終局裁判 → 可聲請
- 上訴了，但被以**上訴不合法裁定駁回** → 定讞在二審，仍算努力過 → 可聲請（以二審判決為確定終局裁判）

## 不算用盡：
- 可上訴、抗告而**不上訴**
- 上訴**逾期**
- 主動**撤回**上訴
- **未繳裁判費**被駁回
- 跳過一般法院**直接聲請**（反年改陣營，2018 年不受理）

> 來源：憲法02 課程字幕 00:40:48 ~ 00:58:00（講義第 13～15 頁）

## 📖 法條原文速查

> **憲訴 §59 I**　人民於其憲法上所保障之權利遭受**不法侵害**，經依法定程序**用盡審級救濟程序**，對於所受不利確定終局裁判，或該裁判及其所適用之法規範，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> **憲法 §16**（訴訟權）　人民有請願、訴願及訴訟之權。→ 反年改陣營主張「一律要求窮盡審級」限制訴訟權

---

## 📋 釋字／不受理決議速查

> **釋字 745 理由書**（講義第 14 頁註）：最高行政法院以聲請人上訴未具體指摘原判決違背法令、**上訴不合法**為由駁回，本件聲請應以臺北高等行政法院判決為**確定終局判決**。→ 字幕「4745」＝釋字 745；原文建議查閱講義

> **大法官第 1557 次會議不受理決議**（講義第 15 頁）：聲請人雖提起上訴，但因**未繳納裁判費**被駁回 → 未用盡審級救濟，不受理。→ 會次依字幕，建議查閱講義

> **2018/7/13 不受理決議**（反年金改革陣營聲請，字幕稱「1479 不受理決議」）：大法官曾有決議，事實無爭議且具**憲法上原則重要性**者，未經審級救濟亦可例外受理；但後續決議限縮為須已提起訴訟、已有判決並提起上訴的情形。未提起訴訟就直接聲請 → 不受理。→ 決議會次與文字建議查閱講義第 15 頁

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「人民聲請的要件？」 | 人民＋憲法上權利遭不法侵害＋**用盡審級救濟**＋不利確定終局裁判（§59 I） |
| 「上訴最高法院被以上訴不合法駁回，得否以二審判決聲請？」 | **得**：有上訴＝努力過，以二審判決為確定終局裁判（釋字 745 理由書） |
| 「得上訴而未上訴，二審定讞，得否聲請？」 | **不得**：未用盡審級救濟 |
| 「上訴逾期／撤回上訴，得否聲請？」 | **不得** |
| 「上訴但未繳裁判費被駁回，得否聲請？」 | **不得**：不是實質努力（陷阱：表面上有上訴） |
| 「未經訴訟直接聲請憲法法庭？」 | **不受理**（2018 年反年改案） |
| 「依法不得上訴三審的案件，二審定讞？」 | 二審就是**終局**，已用盡審級 → 可聲請 |
| 「『不法侵害』要先證明成立才能聲請？」 | 不必；聲請時**主張**即可，是否不法由憲法法庭實體判斷 |

## 一、「同樣定讞在二審」的四種結局

前提：這個案件**依法可以上訴第三審**。

```
二審判決
├── 上訴 → 三審判決定讞 ──────────────── ✔ 可聲請
├── 上訴 → 以「上訴不合法」裁定駁回 ──── ✔ 可聲請（有努力）
├── 上訴 → 未繳裁判費被駁回 ─────────── ✘ 不可（偷吃步）
├── 上訴逾期／撤回上訴 ──────────────── ✘ 不可
└── 不上訴 ──────────────────────────── ✘ 不可（沒努力）
```

| 情形 | 定讞在哪 | 有沒有努力 | 結論 |
|---|---|---|---|
| 三審判決 | 三審 | 有 | 可 |
| 上訴不合法被駁回 | 二審（非終局審級） | **有** | **可** |
| 不上訴 | 二審 | 沒有 | 不可 |
| 上訴逾期 | 二審 | 沒有（遲交） | 不可 |
| 撤回上訴 | 二審 | 沒有 | 不可 |
| 未繳裁判費 | 二審 | 沒有 | 不可 |

- 老師提醒（實務）：上訴期間、裁判費都是律師最重視的事。當事人拖到期限前幾天才找律師，很容易出事。

## 二、直接聲請：反年金改革陣營的策略

```
主張：法律本身違憲（例：通姦罪、年改條例）
   └→ 一審、二審法官都只能依法判 → 打一二審沒有意義
   └→ 要求一律窮盡審級才能聲請 → 限制訴訟權（憲法 §16）
大法官：未經訴訟直接聲請 → 不受理
        但留下空間：至少打完一個審級、具憲法上原則重要性 → 也許有機會
老師：這個例外空間實際上沒有被用過，打問號
```
