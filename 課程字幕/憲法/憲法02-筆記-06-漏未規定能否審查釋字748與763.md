# 憲法02 筆記：漏未規定能否審查（釋字748與763）

## 問題：
- §59 的審查標的是「裁判」或「所適用之法規範」→ 前提是**有一個不好的規定**
- 如果侵害來自**沒有規定**（漏未規定、立法不作為），終局裁判根本沒有「所適用」的規範可以審
- 例：同性伴侶去登記結婚被拒，原因是民法**沒有**規定同性可以結婚

## 湯德宗大法官的解法（釋字 763 意見書）：
- 法律只寫了**規範錯誤**（不應規定而規定）可以審；**規範不足**（應規定而漏未規定）沒寫
- 規範不足是普遍現象，所以只有漏未規定**顯屬立法上之重大瑕疵**、造成**法規範價值體系之矛盾（衝突）**時，才例外納入審查（源頭：釋字 477）
- 多數意見以「具憲法原則之重要性」「依本院解釋先例」受理，但法律的受理要件沒有這兩個詞 → 理由不夠清楚

## 釋字 748 的處理方式：
- 宣告民法婚姻章未保障同性婚姻**違憲**，限期 **2 年**內修法
- 逾期未修 → 同性二人可**直接依本解釋**辦理結婚登記（不是「定期失效」，因為沒有東西可以失效）
- 結果：2019 年制定**司法院釋字第七四八號解釋施行法**

## 📖 法條原文速查

> **憲訴 §59 I**　人民於其憲法上所保障之權利遭受不法侵害，經依法定程序用盡審級救濟程序，對於所受不利確定終局裁判，或該裁判及**其所適用之法規範**，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> **民法 §972**（婚約）　婚約，應由男女當事人自行訂定。→ 字幕「婚約由男女雙方當事人自行定之」，以原文為準

> **憲法 §7**（平等權）　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律平等。

> **憲法 §22**（概括基本權）　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。

> **土地法 §219**（釋字 763 審查對象）→ 條文較長，建議查閱最新六法原文

## 📋 釋字速查

> **釋字 748**（2017/5/24）：民法親屬編婚姻章規定，未使相同性別二人得為經營共同生活之目的，成立具有親密性及排他性之永久結合關係，於此範圍內，與憲法 §22 保障**婚姻自由**及 §7 保障**平等權**之意旨有違。有關機關應於 **2 年內**完成相關法律之修正或制定；逾期未完成者，相同性別二人得依婚姻章規定，持二人以上證人簽名之書面，向戶政機關辦理結婚登記。

> **釋字 763**（2018）：土地法 §219 **未規定**主管機關應就被徵收土地之後續使用情形，定期通知原土地所有權人或依法公告 → 違憲（立法不作為型的例子）。→ 解釋文字建議查閱原文

> **釋字 763 湯德宗大法官部分協同意見書**：聲請人指摘系爭規定「漏未規定」者，與「確定終局裁判所適用之法律或命令發生有牴觸憲法之疑義」具有本質上的差異：前者為「**規範不足**」（應規定而漏未規定），後者為「**規範錯誤**」（不應規定而規定）。「規範不足」毋寧為法規範普遍存在的「現象」，蓋人類的認知能力有限，任何法規範皆有適用範圍，無法包羅萬有，所謂「掛一漏萬」殆所難免。因此，本院**釋字第 477 號**解釋首度嘗試將「規範不足」納入違憲審查之範圍時，即坦言：系爭規定之漏未規定，須**顯屬立法上之重大瑕疵**，始得為本院審查之標的。換言之，僅於漏未規定造成**法規範價值體系之矛盾（衝突）**時，才能例外地納入違憲審查的範圍。
> → 字幕「444 號解釋首度嘗試」，對照意見書原文為**釋字 477**，已校正；字幕「7623」＝釋字 763

> **釋字 477**：戒嚴時期人民受損權利回復條例 §6 適用對象未包括其他受同等損害者，「**漏未規定，顯屬立法上之重大瑕疵**」，反足以形成人民在法律上之不平等，與憲法 §7 有所牴觸。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律漏未規定，得否成為審查客體？」 | **原則不能**（法律只規定規範錯誤）；**例外**：顯屬立法上之重大瑕疵、造成法規範價值體系矛盾時可以 |
| 「首度將規範不足納入審查的解釋？」 | **釋字 477**（戒嚴時期人民受損權利回復條例） |
| 「規範不足 vs 規範錯誤？」 | 不足＝應規定而漏未規定；錯誤＝不應規定而規定 |
| 「釋字 748 宣告違憲的依據？」 | 憲法 **§22 婚姻自由**＋ **§7 平等權** |
| 「釋字 748 的宣告方式？」 | 限期 2 年修法；**逾期得依本解釋辦理結婚登記**（不是定期失效） |
| 「為何 748 不用定期失效？」 | 違憲的是「**沒有規定**」，沒有條文可以失效；要讓它「有」才合憲 |
| 「民法 §972 文義能否得出一夫一妻？」 | **不能**，要靠**體系解釋**（婚姻章以一夫一妻建構） |

## 一、規範錯誤 vs 規範不足

```
人民不爽 → 權利受損 → 原因是什麼？
├── 爛判決 → 審裁判
├── 爛法律（規範錯誤）→ 審所適用之法規範 ✔ 法律有寫
└── 沒有法律（規範不足）→ 終局裁判沒有可適用的規範
        └→ 原則：法律沒寫可以審
        └→ 例外：顯屬立法上重大瑕疵、造成價值體系矛盾（釋字 477）
```

- 弔詭之處：如果國家明文規定「禁止同性結婚」，程序上反而**沒問題**（那就是所適用之法規範）；正因為「沒有規定」，才卡在受理門檻。

## 二、民法 §972 的文義解釋與體系解釋

| 解釋方法 | 「男女當事人」的結論 |
|---|---|
| 文義解釋 | 一男一女、兩男、兩女、甚至三男兩女都說得通 |
| 體系解釋 | 婚姻章後續條文都以**一夫一妻**建構 → 指一男一女 |

## 三、釋字 748 的效果與後續

| | 一般違憲宣告 | 釋字 748 |
|---|---|---|
| 方式 | 宣告違憲，**定期失效**（例：2 年後失效） | 宣告違憲，限期 2 年**立法** |
| 逾期 | 條文失效 | 同性二人得依本解釋辦理結婚登記 |
| 原因 | 有條文可以讓它消失 | 沒有條文；要讓「沒有」變成「有」 |

- 老師舉期末報告為例：沒有截止日就會無限延宕，大法官等於設了截止日。
- 2019 年立法：**司法院釋字第七四八號解釋施行法**（多處準用民法），沒有直接修民法，也沒叫「同性婚姻法」，減少反彈。
- 老師先用 748 說明受理困境，但 748 沒有回應這個程序問題，所以改用 763 的湯德宗意見書說明。
