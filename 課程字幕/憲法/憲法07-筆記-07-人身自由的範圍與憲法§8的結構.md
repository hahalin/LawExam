# 憲法07 筆記：人身自由的範圍與憲法§8的結構

## 為什麼要讀：
- 2010 年考過、2020 年疫情又考，兩題幾乎一模一樣 → 考點固定，是簡單的單元

## 人身自由＝被關：
- 被拘禁在一定處所、**跑不掉**（§8）
- 一般行動自由：其實跑得掉，只是被限制某條路（§22，如路上盤查）
- 遷徙自由：範圍最廣，典型是禁止出境（§10）
- 限制人身自由**必然**限制遷徙自由；反之不然

## §8 的結構：
- 現行犯：法律另定 → 刑訴 §88：**任何人**都可以逮捕
- 非現行犯：只有**司法或警察機關**可以逮捕拘禁；只有**法院**可以審問處罰
- §8 II 寫「**犯罪嫌疑**」→ 24 小時內移送法院 → 刑事程序規定得很死，留給刑訴考
- §8 I 沒寫犯罪嫌疑 → 非刑事也可能被關（外籍移工收容、傳染病隔離、管收）→ **憲法愛考非刑事**

## 📖 法條原文速查

> **憲法 §8 I**　人民身體之自由應予保障。除**現行犯**之逮捕由法律另定外，非經**司法或警察機關**依法定程序，不得逮捕拘禁。非由**法院**依法定程序，不得審問處罰。非依法定程序之逮捕、拘禁、審問、處罰，得拒絕之。

> **憲法 §8 II**　人民因**犯罪嫌疑**被逮捕拘禁時，其逮捕拘禁機關應將逮捕拘禁原因，以**書面**告知本人及其本人指定之親友，並至遲於**二十四小時**內移送該管法院審問。本人或他人亦得聲請該管法院，於二十四小時內向逮捕之機關**提審**。

> **憲法 §10**　人民有居住及遷徙之自由。

> **憲法 §22**　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。→ 一般行動自由

> **刑事訴訟法 §88 I**　現行犯，**不問何人**得逕行逮捕之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「誰可以逮捕現行犯？」 | **任何人**（§8 I 授權法律另定 → 刑訴 §88） |
| 「誰可以逮捕拘禁非現行犯？」 | **司法或警察機關**（§8 I） |
| 「誰可以審問處罰？」 | **法院**（§8 I） |
| 「因犯罪嫌疑被逮捕，幾小時內移送法院？」 | **24 小時**（§8 II），並書面告知本人及指定親友 |
| 「非犯罪嫌疑者能否被拘禁？」 | **可能**：§8 I 未限於犯罪嫌疑（移工收容、傳染病隔離、管收） |
| 「限制人身自由與遷徙自由的關係？」 | 限制人身自由**必然**限制遷徙自由；限制遷徙不必然限制人身 |
| 「人身自由屬哪一層法律保留？」 | **憲法保留**（§8 直接規定程序） |
| 「警察盤查、遊行時封路限制的是？」 | **一般行動自由**（§22），不是人身自由 |

## 一、同心圓：人身自由最小、最嚴格

```
┌─────────────────────────────── 遷徙自由（§10）例：禁止出境
│  ┌──────────────────── 一般行動自由（§22）例：盤查、封路
│  │  ┌───────── 人身自由（§8）例：拘禁、羈押、隔離
│  │  │ 跑不掉
│  │  └─────────
│  └────────────────────
└───────────────────────────────
```

- 「我覺得被拘禁在臺灣」「被拘禁在學校」是浪漫化的說法，不是人身自由的限制。
- 人身自由：你跑不掉；一般行動自由：你跑得掉，只是不跑或要繞路。

## 二、§8 的拆解

| 行為 | 誰可以 | 依據 |
|---|---|---|
| 逮捕現行犯 | 任何人 | §8 I 授權 → 刑訴 §88 |
| 逮捕拘禁（非現行犯） | 司法或警察機關 | §8 I |
| 審問處罰 | 法院 | §8 I |
| 犯罪嫌疑被捕 → 移送審問 | 24 小時內移送該管法院 | §8 II |

- 有人要逮捕你，你可以請他證明是警察；不是警察就不能逮捕（非現行犯時）。
- §8 II 短短三行，已經包含**正當法律程序**：要書面通知、要讓你有抗辯機會（開羈押庭）。

## 三、刑事 vs. 非刑事：憲法考後者

```
憲法 §8
├── 刑事程序（犯罪嫌疑）
│     抓到 → 24 小時內移送法院 → 法官決定羈押
│     → 規定得很死 → 刑訴考
│
└── 非刑事程序（§8 I 沒寫犯罪嫌疑）
      逃逸移工收容、傳染病隔離、欠稅管收……
      → 憲法沒規定程序要長怎樣 → 靠大法官填補 → 憲法愛考
```

- 疫情問題：衛生主管機關把確診者關在家裡，可以說「你不是司法或警察機關」嗎？→ 見下一份筆記（警察機關廣義解釋）。
- 本單元會教四號非刑事拘禁的解釋：本堂釋字 588（管收），下堂三號（傳染病、外籍移工、大陸地區人民）。
