# 憲法07 筆記：重罪羈押與合憲性解釋（釋字665）

## 羈押的目的：
- 不是處罰，是避免妨礙追訴：**逃亡、滅證、串供**
- 刑訴 §101 I ③「重罪」羈押的邏輯不同：重罪不必然會逃亡、滅證、串供 → 爭議

## 釋字 665（陳水扁聲請）：
- **合憲性解釋**：重罪羈押合憲，但**不能單純因為重罪**就羈押
- 除重罪外，還要有相當理由認為有逃亡、滅證、串供之虞，且具保、責付、限制住居等較小手段都不足以確保程序進行

## 規範與現實的落差：
- 理想：重罪者「逃亡可能性」的門檻可以降低（老師比喻：一般要 90%，重罪 70% 即可）
- 實務：以前勾「重罪」一款，現在多勾一款「逃亡」就好 → 不一定產生質變
- 部分大法官認為這種合憲性解釋本身有問題

## 📖 法條原文速查

> **刑事訴訟法 §101 I**　被告經法官訊問後，認為**犯罪嫌疑重大**，而有下列情形之一，非予羈押，顯難進行追訴、審判或執行者，得羈押之：
> 一、逃亡或有事實足認為有**逃亡**之虞者。
> 二、有事實足認為有**湮滅、偽造、變造證據**或**勾串**共犯或證人之虞者。
> 三、所犯為**死刑、無期徒刑或最輕本刑為五年以上有期徒刑**之罪，有相當理由認為有逃亡、湮滅、偽造、變造證據或勾串共犯或證人之虞者。
> → 第三款後段「有相當理由認為……之虞」是 665 之後修法加入，建議查閱最新六法原文

---

## 📋 釋字速查

> **釋字 665 號**（2009 年）：刑訴 §101 I ③ 於被告犯該款之罪、犯罪嫌疑重大，且**有相當理由認為其有逃亡、湮滅、偽造、變造證據或勾串共犯或證人等之虞**，法院斟酌命具保、責付或限制住居等侵害較小之手段，均不足以確保追訴、審判或執行程序之順利進行，此際予以羈押，方屬正當，於此範圍內與憲法並無牴觸。→ 原文建議查閱司法院網站
> - 同號解釋另處理法院**分案**是否違反法定法官原則（認合憲）→ 訴訟權單元再講。
> - 老師說李震山、許玉秀、許宗力、林子儀大法官認為這樣的合憲性解釋有問題 → 意見書類型與名單建議查閱司法院網站。

> 字號校正：字幕「四至六六五」即**釋字 665**。卡車衝撞總統府事件老師說 2013 年，一般記載為 **2014 年 1 月**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「羈押的目的？」 | 避免**逃亡、滅證、串供**，確保追訴審判執行；不是處罰 |
| 「得否僅因犯重罪即羈押？」 | **不得**（釋字 665）：仍須有相當理由認有逃亡、滅證、串供之虞 |
| 「釋字 665 對重罪羈押的結論？」 | **合憲**，但採**合憲性（限縮）解釋** |
| 「羈押前還要考量什麼？」 | 具保、責付、限制住居等**較小侵害手段**是否足夠 |
| 「重罪的門檻？」 | 死刑、無期徒刑或**最輕本刑五年以上**有期徒刑之罪 |

## 一、§101 I 三款的邏輯

```
羈押的目的：避免破壞追訴
        │
├── ① 逃亡之虞      → 你逃走我怎麼辦案 → 合理
├── ② 滅證、串供之虞 → 追訴變得很麻煩   → 合理
└── ③ 重罪          → 重罪「會」逃亡嗎？不一定 → 爭議
```

- 如果真的覺得重罪者逃亡機率高，用第 ① 款押他就好，不需要獨立的重罪款。

## 二、具體例子：卡車衝撞總統府

- 有人開卡車衝上總統府門口，檢察官以殺人未遂聲請羈押。
- 老師分析：
  - 證據：車子就在現場，很明確 → 無滅證問題。
  - 共犯：初步看來單獨犯罪 → 無串供可能。
  - 逃亡：衝撞後雙腳骨折 → 很難逃亡。
- 當時引起軒然大波，老師記得最後沒有羈押（可能是交保）→ 細節建議查證。
- 現在總統府前白色花台狀的設施，其實是防衝撞的鋼架。

## 三、釋字 665 的背景與效果

| 項目 | 內容 |
|---|---|
| 聲請人 | **陳水扁**（國務機要費案被羈押） |
| 挑戰對象 | 重罪羈押、分案換法官（法定法官原則）等 |
| 結論 | 重罪羈押合憲性解釋：不能單純因重罪羈押 |
| 迴避問題 | 當時 15 位大法官都是陳水扁提名；但大法官全部迴避就沒有人能處理，很多時候沒辦法迴避 |

- 八卦：陳水扁帶進看守所的書包括王兆鵬老師的《刑事訴訟法》；他認為 665 是不好的解釋。

### 規範與現實的落差

```
理想（老師的粗略比喻）
  一般案件：逃亡可能性要達 90% 才押
  重罪案件：逃亡可能性 70% 就可以押

實務（老師詢問刑事律師）
  以前：勾「重罪」
  現在：勾「重罪」＋ 再勾「逃亡」，多寫幾句理由
```
