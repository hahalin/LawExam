# 憲法04 筆記：司法最小主義與Marbury案

## 憲法判決的效力強大但脆弱：
- 憲法法庭沒有軍隊、警察，判決效力靠所有人**承認、配合**而存在
- 一般法院判決不理會 → 強制執行、拘提；憲法判決不理會 → 不會怎麼樣，但效力會一路下降

## 司法最小主義：
- 憲法判決處理問題宜**窄而淺**：解決眼前的小問題，大問題交給具民主正當性的機關
- 處理得越小，大家越會配合；一次處理太大，可能出現不配合

## Marbury v. Madison（1803）：
- 美國違憲審查權的起點：宣告法律違憲、不予適用
- 判決結論對新政府有利、對申請人不利，新總統只能接受 → 確立「大家都聽最高法院」

## 這段的考點：
- 本段多為觀念補充，考點是複習的**自由民主憲政秩序**（釋字 499）：民主共和國、國民主權、基本權保障、權力分立

## 📖 法條原文速查

> **憲法 §1**（民主共和國）　中華民國基於三民主義，為**民有民治民享**之**民主共和國**。

> **憲法 §2**（國民主權）　中華民國之**主權屬於國民全體**。

---

## 📋 釋字／判例速查

> **釋字 499 號**（2000 年）：第五次修憲（國大延任案）違憲。憲法中具有本質重要性而為規範秩序存立之基礎者，修憲亦不得變更：**民主共和國原則、國民主權原則、保障人民權利、權力分立與制衡**，構成**自由民主憲政秩序**。

> **Marbury v. Madison**（美國聯邦最高法院，1803）：首席大法官 Marshall 主筆。確立聯邦最高法院得審查國會法律是否合憲，違憲之法律不予適用。

> 字號校正：字幕「四字499」即釋字 499；「47次748號解釋」即釋字 748。

## 一、司法最小主義

```
眼前的問題（小）  ← 司法解決：窄、淺、小
      │
背後的問題（大）  ← 交給具民主正當性的機關（立法、行政）思辨決定
```

- 老師的例子：釋字 748（2017）同性婚姻；2018 年公投結果多數反對。
- 老師不是評價同性婚姻，而是提出「**時間**」的問題：司法走在社會前面，可能引起反效果。

## 二、Marbury v. Madison 的故事

| 步驟 | 內容 |
|---|---|
| 背景 | 聯邦黨（亞當斯）敗選，民主共和黨（傑佛遜）將上任 |
| 起因 | 亞當斯卸任前趕簽一批法官任命狀，部分**來不及送出**；新政府拒絕交付，Marbury 當不成治安法官 |
| 困境 | 當時最高法院地位低；若判 Marbury 勝訴，新總統可能不理 → 判決形同廢紙 |
| 判決 ① | 任命狀已簽署 → **有效** |
| 判決 ② | 權利受侵害 → 可依法救濟 |
| 判決 ③ | 但 Marbury 依據的法律讓他**直接向最高法院起訴**，最高法院依憲法主要是**上訴管轄** → 該法律**違憲**，不予適用 |
| 結果 | 實體上新政府輸了道理，結論上贏了 → 傑佛遜無可奈何，只能接受；從此大家習慣服從最高法院，**違憲審查權**確立 |

- 老師的重點：違憲審查權不是因為規範寫得清楚而確立，而是在權力鬥爭中靠智慧建立起來的。

## 三、效力從哪裡來

- 例子：高中沒有規定一定要在教室午睡，但大家都在教室睡；離島騎車沒人戴安全帽，只有自己戴。
- 效力來自**大家都承認、都配合**；即便不喜歡，也先配合。
- 美國國情咨文：議員依黨派鼓掌，**將軍與大法官**永遠不起立、不鼓掌 → 他們效忠的是憲法、自由民主憲政秩序，不是某個人。

## 四、複習：自由民主憲政秩序（釋字 499）

```
題目出現「自由民主憲政秩序」
   → 憲法可以成為審查對象（修憲違憲）
   → 修憲有界限
   → 四個原則：
       ├── 民主共和國
       ├── 國民主權
       ├── 基本權保障
       └── 權力分立與制衡
```

- 老師：題目只要出現這六個字，499、修憲有界限、四原則的關鍵字全部寫上去。
