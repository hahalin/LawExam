# 憲法04 筆記：國家最高機關聲請與獨立機關（憲訴§47）

## 能以自己名義聲請的有九個：
- §47 I：**五院＋總統**（六個國家最高機關）
- §47 III 準用 I：**相當二級機關之獨立機關**——中選會、公平會、NCC（三個）

## 下級機關不是不能聲請：
- 衛福部、經濟部等要**報請上級機關**（行政院）聲請，最後以**行政院**名義提出（§47 II）
- 行政院不同意，就不能聲請

## 為什麼獨立機關可以自己聲請：
- 獨立機關的意義＝上級機關**不得指揮監督**；要它報請行政院同意，等於讓行政院指揮它

## 三個要件：
- ① 國家最高機關 ② 因**行使職權** ③ 就**所適用之法規範**認有牴觸憲法

## 📖 法條原文速查

> **憲訴 §47 I**（國家最高機關聲請）　國家最高機關，因本身或下級機關**行使職權**，就**所適用之法規範**，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> **憲訴 §47 II**（下級機關）　下級機關，因行使職權，就所適用之法規範，認有牴觸憲法者，得**報請上級機關**為前項之聲請。

> **憲訴 §47 III**（獨立機關）　中央行政機關組織基準法所定相當**二級機關之獨立機關**，於其獨立行使職權，自主運作範圍內，**準用**第一項規定。→ II、III 文字建議查閱最新六法原文

> **中央行政機關組織基準法 §21 II**（獨立機關成員任命）　……相當二級機關之獨立機關，由一級機關首長**提名經立法院同意**後任命之；其他獨立機關，由一級機關首長任命之。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「衛福部（經濟部、法務部）得否聲請法規範憲法審查？」 | 不能以自己名義；應**報請行政院**，由行政院聲請（§47 II） |
| 「行政院長個人得否聲請？」 | **不得**，以**行政院**名義聲請，院長是代表人 |
| 「總統得否聲請？」 | **得**：總統本身就是憲法機關（憲法未規定總統府） |
| 「NCC 得否以自己名義聲請？」 | **得**：相當二級機關之獨立機關，準用 §47 I（§47 III） |
| 「依 §47 得以自己名義聲請的有幾個？」 | **九個**：五院＋總統（I）＋中選會、公平會、NCC（III） |
| 「三級獨立機關（如運安會）得否準用 §47 I？」 | **不得**，§47 III 限於相當**二級**機關之獨立機關 |

## 一、國家最高機關是誰

```
國家最高機關（6）
├── 總統          ← 總統「本人」就是憲法機關；總統府不是
├── 行政院        ← 以院的名義，院長是代表人
├── 立法院
├── 司法院
├── 考試院
└── 監察院
```

## 二、下級機關：球是部會發的，丟出去的是行政院

```
衛福部（行使職權，認法規範違憲）
   │ 報請（§47 II）
   ▼
行政院 ── 不同意 → 不能聲請
   │ 同意
   ▼
以「行政院」名義聲請（§47 I）
```

- 老師：一試會考「經濟部可不可以聲請」，答案不是單純是非，而是「要報請行政院、以行政院名義聲請」。

## 三、獨立機關

| | 二級獨立機關 | 三級獨立機關 |
|---|---|---|
| 例 | **中選會、公平會、NCC** | 老師舉：運安會、不當黨產處理委員會、核安會 |
| 成員任命 | 行政院長提名，**立法院同意** | 行政院長任命 |
| 憲訴 §47 III | **準用 I，得自己聲請** | 不適用 |

- 「臺灣有幾個獨立機關？」→ 二級 3 個、三級 3 個，共 6 個（三級名單老師說不用特別記）。
- 一級機關＝五院；二級＝部、會；三級＝署、局。

### 為什麼獨立機關可以自己聲請

```
一般行政機關：上級對下級有指揮監督權
   → 處分不服 → 訴願（向上級機關）→ 上級可撤銷（違法或不當）
獨立機關：上級不得指揮監督
   → NCC 的處分不服 → 不經訴願，直接行政訴訟
   → 聲請釋憲也不必經行政院同意
```

- 舊法（司法院大法官審理案件法）時代，獨立機關聲請要經上級機關層轉，很奇怪；2018 年前後爭論很多，憲訴法 §47 III 直接解決。
- 憲訴法：2019 年通過、**2022 年施行**。

## 四、§47 I 的三個要件

| 要件 | 內容 | 審查重點 |
|---|---|---|
| ① 主體 | 國家最高機關 | 通常無爭議 |
| ② 行使職權 | 行使**憲法上**的職權 | 有沒有做該做的事 |
| ③ 適用法規範 | 行使職權時會用到這個法規範 | 法規範阻礙它行使職權 |

- 寫考題：主張可以聲請，就論證三個要件都符合；主張不行，就寫哪一兩個不符合。典型案例見筆記 05（監察院聲請黨產條例）。
