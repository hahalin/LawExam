# 憲法10 筆記：公共論壇理論與巴奈公園抗議案

## 非內容管制再細分：時間、地點、方式
- 現代民主國家多半管**非內容**：時間（投票日不得競選活動）、方式（18 禁、617 的適當隔絕）、地點
- **公共論壇理論**（美國法）：專門細分「**地點**」→ 不同地點，限制言論的正當性不同

## 三種場域（講義第 49 頁表）：
- **傳統公共論壇**：人行道、公園、街道 → 本來就是給人說話的地方，限制正當性**最低**
- **指定（選定）公共論壇**：政府開放供表意的場所
- **非公共論壇**：例如私人住家門口 → 限制正當性較高
- 網路也有分：一般人的臉書可以封鎖人；**總統**的臉書留言區接近公共論壇，不能任意刪留言、封鎖（老師舉川普封鎖網友案）

## 釋字 734 再看一次（言論自由的角度）：
- 臺南市公告把「未經核准設置廣告物」都列為污染環境行為 → **逾越母法**，違反法律保留（憲法06 筆記 01）
- 大法官另提醒：公告雖非為限制言論而設，個案中對廣告物設置時間、地點、方式的審查，可能造成**言論自由**的限制，修正時應通盤考量

## 巴奈公園抗議案（臺北地院行政訴訟庭 109 年度簡字第 4 號）：
- 原住民歌手巴奈等人為原住民**傳統領域**轉型正義訴求，在二二八和平公園放置桌椅、傘架抗議 → 依臺北市公園管理自治條例 §13 ⑥（任意放置桌椅箱櫃板架）裁罰
- 一審：公園是**傳統公共論壇**；原告為社會經濟弱勢的原住民族 → **嚴格審查** → 相關收費規定違憲拒絕適用；抗議放置**不是「任意」**放置，也未妨礙通行或破壞設施 → **撤銷**處分
- 老師：二審翻盤，但一審判決論述非常用心，值得一讀

## 📖 法條原文速查

> **廢棄物清理法 §27**　在指定清除地區內嚴禁有下列行為：……⑪ 其他經主管機關公告之污染環境行為。→ 前十款為具體污染行為；條文建議查閱最新六法原文

> **臺南市公告**（釋字 734 審查標的，老師念出）　本市清除區域內，未經主管機關核准，於道路、牆壁、樑柱、電桿、樹木、橋樑、水溝、池塘或其他土地定著物張貼、懸掛、繫綁、噴漆、粉刷、樹立、釘夾、堆放或以其他方法設置廣告物，為污染環境行為。→ 文字依字幕整理，建議查閱原文

> **臺北市公園管理自治條例 §13 ⑥**　公園內不得有下列行為：……任意放置桌、椅、箱、櫃或板架等。→ 罰則見同條例 §17；建議查閱原文

## 📋 釋字／判決速查

> **釋字 734 號**（2015 年）：臺南市政府公告將未經核准設置廣告物一概認定為污染環境行為，未就設置廣告物是否有礙環境衛生與國民健康、是否已達廢棄物清理法 §27 前十款所定污染程度予以區分，逾越母法授權範圍，與**法律保留原則**有違。系爭公告雖非為限制人民言論自由而設，然於具體個案中可能因主管機關對廣告物設置之時間、地點、方式之審查而否准設置，造成限制人民**言論自由**之結果；主管機關修正公告時，應通盤考量其必要性及適當性。→ 原文建議查閱司法院網站

> **臺北地方法院行政訴訟庭 109 年度簡字第 4 號判決**（2020 年 7 月 27 日）：原告巴奈等人於二二八和平公園放置桌椅、傘架抗爭，經臺北市公園路燈工程管理處依公園管理自治條例 §13 ⑥、§17 裁罰。法院認公園屬**傳統公共論壇**，相關場地使用收費規定雖非針對言論內容，但因原告為社會經濟弱勢之原住民族，採**嚴格審查**，認其違憲而拒絕適用；原告係為表達訴求而駐點，非「任意」放置，且未妨礙公眾通行或破壞環境設施 → 撤銷訴願決定及原處分。→ 二審結果依老師口述「翻盤」，建議查證

> 校正：老師說一審法官是對「自治條例」做違憲審查；查判決，法官拒絕適用的是場地管理辦法、場地使用須知中的**收費規定**，對自治條例 §13 ⑥ 則是認定本案不屬「任意」放置。兩者都是法官在個案中**不適用**低於法律位階的規範，結論方向相同。

> 補充：川普封鎖推特網友案為 Knight First Amendment Institute v. Trump（2019 年第二巡迴上訴法院認定違憲；2021 年聯邦最高法院以川普卸任為由撤銷原判）。→ 老師未唸案名，建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公共論壇理論細分的是哪一種限制？」 | 時間、地點、方式中的**地點** |
| 「典型的傳統公共論壇？」 | **人行道**、公園、街道 |
| 「在傳統公共論壇限制表意，正當性高還是低？」 | **低**，審查從嚴 |
| 「地方法院法官可否對自治條例、行政規則做違憲審查？」 | 可以審查並在**個案不適用**，但不能宣告失效 |
| 「釋字 734 以什麼原則宣告違憲？」 | **法律保留**（逾越母法授權），並提醒言論自由的地點限制 |
| 「限制在平台發言、在公園放置抗議物品，屬何種限制？」 | **非內容（地點）**限制，仍屬言論自由限制 |

## 一、言論限制的分類樹

```
言論自由的限制
├─ 內容限制（不准你講什麼、講了就罰）→ 原則從嚴
└─ 非內容限制
     ├─ 時間：投票日不得競選活動；兒童產品廣告時段限制（老師口述）
     ├─ 方式：18 禁、適當安全隔絕（617）
     └─ 地點 → 公共論壇理論
           ├─ 傳統公共論壇（人行道、公園）→ 限制正當性最低
           ├─ 指定公共論壇
           └─ 非公共論壇（私人住家門口）→ 限制正當性較高
```

## 二、法官的違憲審查權限（法規位階三角形）

```
        憲法          ← 拘束法官
        法律          ← 拘束法官；認違憲只能聲請憲法法庭（§55）
   命令、自治條例、行政規則  ← 不拘束法官；法官可自行審查、個案不適用
```

- 巴奈案就是「小法官」在個案中做違憲審查的例子：可以不適用，但不能宣告失效。

## 三、老師的提醒：差別待遇不是雙標

- 判決出來後，「那我以後也可以在公園放桌椅？」→ 不行。巴奈是為了特定議題、在具政治意義的地點（鄰近總統府）抗議，且是原住民族身分。
- 外觀相似、內涵不同的案件做出**差別待遇**，才是個案判斷；拿同一個標準看所有問題才是問題。
