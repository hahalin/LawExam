# 憲法第二堂課 — 課程筆記

## 一、上堂複習

- 修憲有界限：**自由民主憲政秩序**（四大原則：民主共和國原則、國民主權、基本人權、權力分立）
- 釋憲主體五類：國家最高機關（五院＋總統）、立法委員、法官、地方自治團體、人民
- 釋憲客體：憲法、法律、命令、判例、決議、判決
- 憲法本身可以被宣告違憲

## 二、113 年憲判第 9 號 — 國會擴權法案的立法程序審查

### 背景

- 2024 年國民黨與民眾黨聯合推動**國會調查權**與**藐視國會罪**
- 引發青島東路民眾聚集抗議
- 爭議焦點：**送出委員會後抽換版本**的程序問題

### 立法程序要點

- 立法程序：**一讀 → 二讀 → 三讀**，其中**二讀最重要**
- 立法院採**委員會中心主義**（八個委員會，如司法法制委員會、交通委員會等）
- 立法程序兩大原則（源自**憲法第 2 條國民主權原則**）：
  - **公開透明原則**
  - **討論原則**

### 憲法法庭的立場

- 採**明顯重大瑕疵**標準介入立法程序
- 本案結論：雖有瑕疵，但尚未完全背離公開透明原則與討論原則 → **立法程序不構成違憲**
- 但實體面多條規定被宣告違憲

### 重要觀念

- **司法自制**：政治爭議應優先在政治場域（立法院）解決，憲法法庭為最後手段
- **不同意見書**：雖無法律效力，但留下記錄有重大意義
- 釋字 748 號（同性婚姻）的啟示：立法院通過是最佳方案，釋憲是次優

## 三、人民申請釋憲 — 憲訴法第 59 條

### 3.1 誰是「人民」

| 類型 | 是否為人民 | 說明 |
|------|-----------|------|
| **自然人** | ✅ | 當然是人民 |
| **法人** | ✅ | 依其性質可主張基本權 |
| **外國人** | ✅（部分限制） | 不能主張**參政權**（憲法第 17 條） |
| **大陸地區人民** | ✅（特別規範） | 依**增修條文第 11 條**處理 |
| **政黨** | ✅ | 本質即屬人民，可主張參政權受損 |
| **動物** | ❌ | 非法律上的人 |

#### 法人可否主張基本權？

| 可主張 | 不可主張 |
|--------|----------|
| 財產權、平等權 | 人身自由（憲法第 8 條） |
| 言論自由（如商業廣告） | 秘密通訊自由（憲法第 12 條） |
| 營業自由 | 應考試服公職（憲法第 18 條） |

#### 立法沿革

- **舊法**（司法院大法官審理案件法第 5 條第 1 項第 2 款）：列出「人民、法人、政黨」
- **新法**（憲訴法第 59 條）：僅寫「人民」→ 因法人與政黨本質即為人民

### 3.2 用盡審級救濟途徑

核心判準：**有沒有「努力」**

| 情形 | 可否申請釋憲 | 原因 |
|------|-------------|------|
| 上訴到最高法院**定讞** | ✅ | 正常用盡審級 |
| 上訴被**裁定駁回**（不合法） | ✅ | 有努力，以原審為終局裁判 |
| 可上訴但**未上訴** | ❌ | 沒努力 |
| 上訴**逾期** | ❌ | 遲交 |
| **主動撤回**上訴 | ❌ | 自行放棄 |
| **未繳裁判費** | ❌ | 偷懶 |
| 跳過法院**直接申請釋憲** | ❌（原則） | 但大法官曾有例外 |

#### 相關解釋

| 解釋 | 內容 |
|------|------|
| **釋字 745 號** | 上訴不合法被駁回 → 以高等行政法院判決為終局裁判，可申請釋憲 |
| 大法官第 **1447 號不受理決議** | 反年金改革陣營直接申請釋憲 → 不受理 |

## 四、所適用法規範 — 寬鬆說 vs. 嚴格說

### 📌 函釋（Explanation）

函釋是行政機關對法令的解釋性函文，常見於行政訴訟判決中。行政法院判決往往引用大量函釋作為裁判依據，因此行政訴訟案件中「所適用之法規範」範圍最廣。在申請釋憲時，須判斷哪些函釋才是真正造成判決結果的「關鍵法規範」。

### 兩種見解

| | 寬鬆說（多數意見） | 嚴格說（少數意見，張瓊文大法官） |
|---|---|---|
| 標準 | 判決中出現的**所有法條**皆可作為釋憲標的 | 須符合形式＋實質要件 |
| 形式要件 | — | 判決須**載明**法律名稱、條次或函文編號 |
| 實質要件 | — | 該法令須與裁判主文/結論有**密切關係** |

#### 相關解釋

| 解釋 | 內容 |
|------|------|
| **釋字 756 號** | 受刑人通訊自由案（寬鬆說代表） |
| **釋字 760 號** | 張瓊文大法官意見書提出嚴格適用說 |

## 五、補充專題：受刑人案件（釋字 755、756 號）

### 背景：邱和順案

- 監獄行刑法及施行細則 → 監獄官可**審查、刪除**受刑人信件內容
- 過去受刑人**不能**針對監獄處分提起訴訟
- 邱和順提行政訴訟 → 法院認定無審判權 → **裁定駁回** → 申請大法官解釋

### 程序困境

- 裁定駁回引用的是行政程序法、訴願法等**程序法** → 非邱和順真正要挑戰的**監獄行刑法**
- 嚴格說認為本案不應受理（陳碧玉、黃璽君、張瓊文大法官）

### 解釋結果

| 解釋 | 內容 |
|------|------|
| **釋字 755 號** | 受刑人**可以**對監獄處分提起訴訟 |
| **釋字 756 號** | 受刑人通訊自由受保障，多條管理措施被宣告**違憲** |
| **釋字 785 號** | 消防員權益案（大法官解釋中點擊率最高） |

### 相關法條

- 監獄行刑法及施行細則
- 行政程序法第 92 條第 1 項
- 訴願法第 1 條第 1 項、第 3 條第 1 項

## 六、重要性理論 — 大法官主動擴張審查範圍

### 📌 考試作答技巧（考試會考）

大法官可將當事人**未申請**、甚至終局裁判**未適用**的法規範，以**重要關聯性**為由一併納入審查。

| | 當事人有申請 | 當事人沒申請 |
|---|---|---|
| **終局裁判有適用** | ✅ 當然受理 | ✅ 可拉進來 |
| **終局裁判沒適用** | — | ✅ 可拉進來 |

#### 考試技巧

> 題目若要你扮演大法官，除了處理題目指定的法條外，**主動論述為何有必要將其他相關法規範拉進審查範圍**（受理要件），可拿到額外分數。只要多寫三行說明「為什麼我認為有必要將 B 拉進來」，老師就知道你連程序爭點都掌握了。

#### 相關解釋

| 解釋 | 內容 |
|------|------|
| **釋字 739 號** | 理由書提出「重要關聯性」概念，一併納入審查範圍 |
| **釋字 753 號** | 詹森林大法官部分不同意見書，引用湯德宗大法官意見 |

#### 湯德宗＋詹森林大法官論述

> 「申請人只需主張自己基本權遭受侵害，且主張並非全然無據，即滿足要件。一旦決議受理後，大法官審查範圍**不受申請人主張之拘束**。」

## 七、立法不作為（漏洞規定）可否申請釋憲

### 核心案例：釋字 748 號（同性婚姻）

- **民法第 972 條**：「婚約由**男女**雙方當事人自行定之」
- 文義解釋 + 體系解釋 → 民法建構一夫一妻制 → **無同性婚姻規範**
- 同性戀登記結婚被拒 → 想申請釋憲 → 但「不能結婚」是因為**沒有規範**而非**有錯誤的規範**
- 憲訴法第 59 條要求「所適用之法規範」→ 無規範 = 無適用 = **程序困境**

### 湯德宗大法官的回應（釋字 763 號協同意見）

1. 法律規定的是「規範錯誤」，不是「漏洞規定」
2. **釋字 477 號**首度將「**規範不足**」（立法漏洞）納入審查
3. 結論：僅在漏未規定造成**法體系矛盾衝突**時，才例外納入審查

### 釋字 748 號的特殊效力宣告

| 傳統模式 | 釋字 748 號模式 |
|----------|----------------|
| 定期失效：宣告違憲 → 兩年後法律失效 | 兩年內立法 → 若不立法，以釋字 748 為結婚依據 |
| **有標的**可以失效 | **沒有標的**可以失效 → 需要「新增」規範 |

- 最終立法：**釋字第 748 號解釋施行法**
- 祁家威：本案申請人，臺灣最早公開出櫃者

## 八、憲法判決的效力

### 核心法條

| 法條 | 內容 |
|------|------|
| **憲訴法第 37 條** | 裁判自**宣示或公告之日**發生效力 |
| **憲訴法第 38 條** | 判決有拘束**各級機關及人民**之效力，各機關負有**實現判決內容之義務** |

### 📌 推薦閱讀：Cass Sunstein《剪裁歧見》

- **作者**：Cass Sunstein（凱斯·桑斯坦），美國法哲學教授，曾任歐巴馬政府資訊與法規事務辦公室主任
- **書名**：《剪裁歧見》（*Legal Reasoning and Political Conflict*，臺灣繁體中文譯本）
- **核心主張**：大法官做出的判決效力極強（拘束全國機關與人民） → 因此大法官應**自制**
- **「淺而薄」理論**：大法官在每次爭議中應只解決**一個小問題**，不應對一個問題做出終局性的全面解釋
- **理由**：終局性的廣泛解釋會**壓縮政治空間**，使社會失去透過民主程序自行解決爭議的機會
- **講師補充**：美國理論不必然直接適用於臺灣，但值得作為思考「大法官權力界限」的參考

## 九、時事議題：剴剴案與修法批判

### 📌 考題預測（講師明確指出「一定會變考題」）

### 剴剴條款修法內容與批判

| 修法內容 | 問題/批判 |
|----------|----------|
| 殺害七歲以下兒童 → 加重 1/2 | 兒少法第 112 條**原本就規定**殺害 18 歲以下兒童可加重 1/2 → 修法**重複** |
| 傷害致死 → 可判**死刑** | 傷害致死 = 故意傷害 + **過失**致死 → 與 **113 年憲判第 8 號**（死刑限於「極端殺人」）矛盾 → **違憲** |
| 虐殺兒童 → 死刑或無期徒刑 | 過去本就可判死刑；拿掉「十年以上有期徒刑」→ 壓縮法官裁量權 |

### 113 年憲判第 8 號（死刑限縮案）

- 死刑限於**極端殺人**狀況（如無差別殺人）
- **故意殺人 + 故意致死** → 僅在極端情況才可判死刑
- 傷害致死的「致死」部分屬**過失** → 不符合「極端殺人」標準

### 預期考法與作答方向

> **題目設計**：被告因傷害致死被依修法後條文判處死刑 →
> 1. **判決**可否申請裁判憲法審查？→ 可以，依憲訴法第 59 條「該裁判」
> 2. **條文**可否申請違憲審查？→ 可以，所適用之法規範
> 3. **判準是什麼？** → 113 年憲判第 8 號確立的「極端殺人」標準
> 4. **結論**：傷害致死中的「致死」為過失 → 非故意殺人 → 不符「極端殺人」→ 判死刑**違憲**

### 相關法條

- 刑法第 271 條（殺人罪）、第 277 條第 2 項（傷害致死）
- 兒少法第 112 條
- 113 年憲判第 8 號、憲訴法第 38 條、第 59 條

## 考試重點提示

1. **人民聲請釋憲三要件**：(1) 誰是人民 (2) 用盡審級救濟 (3) 所適用法規範
2. **重要性理論**：大法官可主動將相關法規範拉進審查 → 考試作答時多論述受理要件可加分
3. **立法不作為**（漏洞規定）能否釋憲 → 僅在**法體系矛盾衝突**時例外納入
4. **剴剴條款修法**一定會變考題 → 核心判準是 113 年憲判第 8 號「極端殺人」標準
5. **合併審理**（憲訴法第 24 條）與原因案件的概念
