# 憲法07 筆記：基本權競合、衝突與自由權解題架構

## 競合：一個行為涉及多個基本權，要抓哪一個
- 可能吸收成一個（A），也可能並列（A＋B）
- 性工作被禁止：性自主＋財產權 → 合起來就是「交易」→ 抓**工作權**（§15）
- 集會遊行踩禁制區被驅逐：言論自由被集會自由吸收、宗教只是動機 → 抓**集會自由**（§14）

## 為什麼最重要：
- **基本權抓錯，後面全部都錯**
- 讀書時按單元讀，看言論自由章就理所當然寫言論自由；考試沒有單元，要自己判斷

## 衝突：私人之間各自主張基本權
- 例：天主教徒蛋糕師傅拒做同性婚禮蛋糕 → 宗教自由（§13）vs. 平等權（§7）
- 臺灣憲法判決目前還沒有典型案例

## 自由權解題架構（起手式）：
- 什麼基本權 → 他有沒有享有 → 有無國家公權力侵害 → 審查標準 → 形式合憲性與實質合憲性

## 📖 法條原文速查

> **憲法 §7**　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律平等。

> **憲法 §11**　人民有言論、講學、著作及出版之自由。

> **憲法 §13**　人民有信仰宗教之自由。

> **憲法 §14**　人民有集會及結社之自由。

> **憲法 §15**　人民之生存權、**工作權**及**財產權**，應予保障。

> **憲法 §22**　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。→ 性自主權的依據

---

## 📋 釋字速查

> **釋字 554、791 號**：性自主權屬憲法 §22 保障之基本權（791 宣告通姦罪違憲）。

> **Masterpiece Cakeshop v. Colorado Civil Rights Commission**（美國聯邦最高法院，2018 年）：蛋糕店老闆基於宗教信仰拒絕為同性伴侶製作婚禮蛋糕。→ 老師說師傅是天主教徒；一般報導為基督徒。案名與細節為補充，老師未唸案名。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「全面禁止性工作，主要限制何種基本權？」 | **工作權**（§15）；性自主＋對價合起來是交易，寫性自主就是抓錯 |
| 「集會遊行進入禁制區被驅逐，限制何種基本權？」 | **集會自由**（§14）；言論自由被吸收，宗教只是動機 |
| 「基本權競合的處理？」 | 判斷是否**吸收**為單一基本權，或並列多個 |
| 「基本權衝突的例子？」 | 宗教自由 vs. 平等權（婚禮蛋糕案） |
| 「自由權案件的審查順序？」 | 保護領域 → 主體 → 國家侵害 → 審查基準 → 形式（法律保留、明確性）與實質（比例原則）合憲性 |

## 一、競合：抓對基本權

```
某個行為涉及多個基本權
        │
        ├── 吸收：A + B + C = A
        └── 並列：A + B + C = A + B
```

### 例一：性工作被禁止

```
性行為（性自主 §22）＋ 金錢對價（財產權 §15）
        ↓
       交易
        ↓
   工作權（§15）← 抓這個
```

- 國家沒有禁止大家發生性行為，禁止的是「性行為且有對價」→ 核心是交易，也就是工作。
- 寫「限制性自主權」不能說限制不到，但沒有抓對核心基本權。

### 例二：為宗教迫害上街抗議，踩到禁制區被驅逐

| 涉及的基本權 | 結論 |
|---|---|
| 言論自由（§11） | 集會遊行＝言論觀點＋行動 → 被 §14 **吸收** |
| 宗教自由（§13） | 只是抗議的理由；被驅逐是因為踩到禁制區，不論什麼主題都一樣 |
| **集會自由（§14）** | 真正被限制的基本權 |

- 題目會故意這樣設計，誘導你寫宗教自由。

### 讀書時最容易犯的錯

- 按單元讀解題書：連看三四題都是言論自由，自然不會想「這題限制什麼基本權」。
- 考試沒有單元 → 拿掉單元後，常常不知道在考什麼。抓對基本權是基本權單元最重要的一件事。

## 二、衝突：婚禮蛋糕案

| | 蛋糕師傅 | 同性伴侶 |
|---|---|---|
| 主張 | 宗教自由（§13）：基於信仰無法支持同性婚姻 | 平等權（§7）：為什麼針對我差別待遇 |
| 難題 | 店家能挑消費者，好像沒有不行 | 基於這種理由挑，會產生很大的問題 |

- 臺灣目前還沒發生，但要放在心上。
- 老師：大家都有自由，但自由絕對不會無限上綱；學法律就是學「什麼情況下是合理的自由」。

## 三、自由權解題架構（講義第 20～21 頁）

```
① 什麼基本權？（保護領域、競合）
        ↓
② 他有沒有享有這個基本權？（主體：人權／國民權／公民權）
        ↓
③ 有沒有國家公權力侵害？
        ↓
④ 審查標準：嚴格／中度／寬鬆
        ↓
⑤ 形式合憲性（法律保留、明確性）＋ 實質合憲性（比例原則）
```

- 這是正課，總複習會花更多時間；起題就用這個架構。
