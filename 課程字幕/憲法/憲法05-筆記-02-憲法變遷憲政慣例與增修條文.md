# 憲法05 筆記：憲法變遷：憲政慣例與增修條文

## 憲法變遷有三種：
- **憲政慣例**：憲法沒規定，靠政治運作反覆行使、形成法的確信
- **修憲**：直接修改條文，或另立增修條文（我國走後者）
- **憲法解釋**：不增添文字，透過詮釋讓憲法往前走（見筆記 04）

## 為什麼有增修條文：
- 憲法本文是 1947 年給**整個中國**用的；增修條文是「**國家統一前**」給臺澎金馬暫時用的
- 本文不刪，只**凍結**，等「反攻大陸」後解凍 → 整套體制在形式上是暫時的
- 不是因為以前修憲很難：2005 年以前由國民大會修憲，門檻反而不高

## 📖 法條原文速查

> **增修條文前言**　為因應**國家統一前**之需要，依照憲法第二十七條第一項第三款及第一百七十四條第一款之規定，增修本憲法條文如左：

> **增修 §2 VI**　總統、副總統之任期為**四年**，連選得**連任一次**，不適用憲法第四十七條之規定。

> **憲法 §47**（已不適用）　總統副總統之任期為**六年**，連選得連任一次。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「憲政慣例的成立要件？」 | 憲法**未規定**；經**反覆行使**；形成**法的確信** |
| 「我國修憲採何種方式？」 | 不直接改本文，另立**增修條文**，凍結本文部分條文 |
| 「增修條文前言所稱修憲目的？」 | 「為因應**國家統一前**之需要」 |
| 「總統任期？」 | 本文 6 年（§47）→ 增修 §2 VI 改為 **4 年**，連選得連任一次 |
| 「現行修憲程序是第幾次修憲的產物？」 | **2005 年第七次修憲**（廢國民大會，改由立法院提案、公民複決） |

## 一、三種憲法變遷

```
憲法變遷
├── 憲政慣例 ── 憲法沒寫 → 反覆行使 → 法的確信（我國少見）
├── 修憲
│     ├── 直接修改本文（美國式）
│     └── 增修條文（我國：本文凍結、增修暫時適用）
└── 憲法解釋 ── 文義、體系、目的、歷史、比較；合憲性解釋（筆記 04）
```

## 二、憲政慣例：美國總統任期

| | 美國 | 我國 |
|---|---|---|
| 規定 | 早期憲法未限制任期次數，華盛頓兩任即退，形成慣例；後來明文：最多當選兩次 | 增修 §2 VI：四年一任，連選得連任一次 |
| 結果 | 川普已當兩任，不能再選 | 老師見解：條文只限制「連任」一次，隔一任後再出來選沒有不行 |

- 前提：憲政慣例只在**憲法寫得不夠清楚**時才有空間。

## 三、為什麼是增修條文而不是改本文

```
1947 憲法本文 ── 適用範圍：整個中國
        │ 1949 政府遷臺
        ▼
增修條文 ── 「國家統一前」暫時適用臺澎金馬
        │ 本文不刪，只凍結
        ▼
（若反攻大陸成功）刪除增修條文、本文解凍
```

- 老師的延伸：「中華民國憲法」講的是 1947 年的疆界、1949 年後的臺澎金馬，還是 1911～1949 的歷史概念？說法不完整，國家認同差異因此很大；這類議題是嚴肅、必須公開討論與說服的。
