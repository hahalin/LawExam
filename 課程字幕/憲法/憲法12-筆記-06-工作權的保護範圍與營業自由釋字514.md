# 憲法12 筆記：工作權的保護範圍與營業自由（釋字514）

## 什麼是工作：
- 工作的共同目的是**賺錢**謀生 → 憲法 §15 工作權保障的是**謀生的經濟活動**
- 不賺錢的志工活動，不屬工作權

## 殺手、販毒算不算工作：
- **算**：落入工作權保護範圍，刑法 §271 禁止殺人就是限制殺手的工作權
- 進入審查後當然**合憲** → 結論不變，但審查的路要走
- 若大法官先把某些工作排除在保護範圍外，等於用**道德**決定範圍；應全部放進來，管制交給法律，有爭議再由大法官審查
- 實務依據：釋字 666 許宗力協同意見書

## 工作權的三個面向（釋字 514 黃越欽協同意見書）：
- **職業選擇自由**：能不能從事某職業（例：要考上才能當律師）→ 防禦權
- **營業自由**：已從事該職業，執行上受到的限制（例：律師公會諮詢費下限）→ 防禦權
- **狹義工作權**：國家提供法制讓人民有工作可做（職訓、就業輔導）→ 社會權
- 實務仍統稱 §15 工作權；考點多在防禦權

## 釋字 514：營業自由＝工作權＋財產權
- 營業自由是憲法 §15 **工作權及財產權**保障的內涵
- 自然人多落在職業選擇自由，法人多落在營業自由，大法官的區分目前不太清楚

> 來源：憲法12 課程字幕 01:34:19 ~ 01:53:36（講義第五本第 1～4 頁）

## 📖 法條原文速查

> **憲法 §15**（生存權、工作權、財產權）　人民之**生存權、工作權及財產權**，應予保障。

> **刑法 §271 I**（殺人罪）　殺人者，處死刑、無期徒刑或十年以上有期徒刑。

---

## 📋 釋字速查

> **釋字 514 號**（2000 年）：人民營業之自由為憲法 §15 **工作權及財產權**所保障之內涵。基於工作權，人民得自由選擇從事一定之營業為其職業，而有開業、停業與否及從事營業之時間、地點、對象及方式之自由；基於財產權，人民並有營業活動之自由，例如對其商品之生產、交易或處分均得自由為之。許可營業之條件、營業應遵守之義務及違反義務應受之制裁，均涉及人民工作權及財產權之限制，應以法律定之，或有法律明確授權。→ 原因案件為教育部「遊藝場業輔導管理規則」，原文建議查閱

> **釋字 666 號 許宗力協同意見書**（2009 年）：「憲法第十五條職業自由所稱之職業，原則上只要是人民用以謀生的經濟活動即足當之」→ 提供性服務收取對價亦屬職業。許玉秀部分協同意見書亦認性販售應被承認為一種職業。

> 字號校正：字幕「許宗義」即**許宗力**（已查證 666 意見書）；字幕「黃月清」應為**黃越欽**大法官，意見書種類建議查閱原文；「4至514」「4至666」即釋字 514、666。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「工作權保障的『工作』指什麼？」 | **謀生的經濟活動**；不以合法或符合道德為前提 |
| 「殺手、販毒在不在工作權保護範圍？」 | **在**；限制後經審查**合憲** |
| 「營業自由的憲法依據？」 | 憲法 §15 **工作權＋財產權**（514） |
| 「營業自由包括什麼？」 | 開業、停業、營業**時間、地點、對象、方式**；商品生產、交易、處分 |
| 「許可營業的條件能否以行政命令定之？」 | **不能**，應以法律或法律明確授權（514） |
| 「志工活動受工作權保障？」 | **不受**：非謀生的經濟活動 |

## 一、保護範圍要畫大的理由

```
所有謀生的經濟活動 → 都放進工作權
        ↓
法律決定要不要、怎麼管制
        ↓
有人不服 → 大法官審查（比例原則）
```

- 反面：若說「性工作不是工作」→ 限制性工作的法律不用審查，因為根本沒限制到基本權（另見 憲法07-筆記-04）。

## 二、職業選擇自由與營業自由

| | 職業選擇自由 | 營業自由 |
|---|---|---|
| 問題 | 能不能做這一行 | 做這一行時受到什麼限制 |
| 例 | 沒考上律師不能執業 | 律師諮詢費不得低於公會標準（每小時 5000 元，可往上不可往下，老師口述） |
| 憲法依據 | §15 工作權 | §15 工作權＋財產權（514） |
