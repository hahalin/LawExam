# 憲法11 筆記：大學內部退學規定（釋字563）

## 事實：
- 政大民族學系碩士班研究生，**資格考兩次未通過**，依校內規定被退學
- 他挑戰的是**大學內部規定**，不是國家法令

## 先判斷方向：
- 380、450 的邏輯是「國家不要用法令干涉大學」
- 563 反過來：規定是大學自己訂的 → 屬大學自治 → 直覺就是**合憲**
- 大學內部規定除非本身違法、違憲（老師舉極端例：規定要裸奔才能畢業），否則很難說不對

## 大學自治的六個面向（563）：
- **內部組織、課程設計、研究內容、學力評鑑、考試規則、畢業條件**
- 立法機關不得任意以法律強制大學設置特定單位；行政機關不得以命令干預教學內容
- 教育主管機關對大學只有**適法性監督**

> 來源：憲法11 課程字幕 01:17:10 ~ 01:24:25（講義第四本第 65～66 頁）

## 📖 法條原文速查

> **憲法 §11**（表現自由）　人民有言論、**講學**、著作及出版之自由。→ 大學自治屬講學自由保障範圍

> **大學法**關於學生成績考核、退學之授權規定 → 條號與原文建議查閱最新六法原文

## 📋 釋字速查

> **釋字 563 號**（2003 年）：大學自治為憲法 §11 講學自由之保障範圍；大學對於教學、研究與學習之學術事項，諸如內部組織、課程設計、研究內容、學力評鑑、考試規則及畢業條件等，均享有自治權。大學以章則訂定碩士班研究生於一定期間內未通過資格考核者應予**退學**，屬大學自治範圍，**合憲**。→ 解釋文原文建議查閱司法院網站

> 字號校正：字幕「4至563」即釋字 563。

## 一、大學自治的兩個方向

```
大學自治（§11 講學自由）
├── 對外：擋國家干涉
│     ├── 380：教育部規定共同必修 → 違憲
│     └── 450：法律強制設軍訓室 → 違憲
└── 對內：大學自訂規則
      └── 563：資格考未過退學 → 合憲（除非規定本身明顯違法）
```

## 二、老師補充：大學與選系

- 二一退學、雙二一等制度，各校自訂，原則上不能說不合理。
- 老師感慨：高中階段少有機制幫學生理解各科系在做什麼，導致填志願後才發現不適合。
