# 憲法16 筆記：總統可否不公布法律

## 爭點：
- 立法院通過的法律，總統依法公布（刊登總統府公報）才生效
- 總統認為法律違憲，能不能**故意不公布**？目前學界正在討論，沒有標準答案

## 用制衡機制思考：
- 內閣制：首相與國會僵持 → **解散國會**，交給選民決定
- 我國：行政院不同意法律案 → **覆議**；覆議失敗（立法院 1/2 維持原案）→ 行政院長應接受
- 覆議失敗後總統若還能不公布 → 權力過度偏向行政權 → 老師認為**不行**

## 聲請憲法法庭也走不通：
- 憲訴 §47 三要件：國家最高機關 ✓、行使職權 ✓（公布）、**適用法規範** ✗
- 公布法律不等於適用該法律 → 老師認為這條路走不通

## 老師的思考法：
- 權力分立問題要想「**政權交換後，你能不能接受？**」
- 民主政治就是自作自受：僵局由選民的選擇造成，也由選民承擔

## 📖 法條原文速查

> **憲法 §37**　總統依法**公布法律**，發布命令，須經行政院院長之副署，或行政院院長及有關部會首長之副署。

> **憲法 §72**　立法院法律案通過後，移送總統及行政院，總統應於收到後**十日內公布**之，但總統得依照本憲法第五十七條之規定辦理。→ 老師上課未提，補充；第 57 條已由增修 §3 II 取代

> **增修 §3 II ②**（覆議）　行政院對於立法院決議之法律案、預算案、條約案，如認為有**窒礙難行**時，得經總統之核可，於該決議案送達行政院十日內，移請立法院覆議。立法院對於行政院移請覆議案，應於送達十五日內作成決議。……覆議案逾期未議決者，原決議失效。覆議時，如經全體立法委員**二分之一以上**決議維持原案，行政院院長應即接受該決議。→ 建議查閱最新六法原文

> **憲訴 §47 I**　國家最高機關，因本身或下級機關**行使職權**，就**所適用之法規範**，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律經立法院通過後，總統應於幾日內公布？」 | **十日內**（§72） |
| 「行政院對法律案不同意的憲法機制？」 | **覆議**（增修 §3 II ②），須經總統核可 |
| 「覆議時立法院以多少維持原案，院長須接受？」 | 全體立委**二分之一以上** |
| 「總統得否依 §47 就其應公布之法律聲請違憲審查？」 | 老師：難以成立，公布不等於**適用**法規範 |

## 一、僵局怎麼解：兩種制度的對照

```
內閣制：首相 ←僵局→ 國會
            └→ 解散國會 → 選民決定
                 ├ 首相大勝 → 推行政策
                 └ 首相大敗 → 下臺

我國：行政院 ←不同意→ 立法院通過的法律案
            └→ 覆議 → 立法院重新表決
                 ├ 未達 1/2 維持 → 原決議失效
                 └ 1/2 以上維持 → 院長應接受 → 總統公布？
                                              └ 再不公布 → 行政權過大（老師：不行）
```

## 二、§47 三要件代入

| 要件 | 總統不公布法律的情形 |
|---|---|
| 國家最高機關 | 總統是 ✓ |
| 行使職權 | 公布法令權 ✓ |
| 適用法規範 | 公布法律，總統本身並不會用到那部法律 ✗（同 憲法04-筆記-05 監察院黨產條例案的邏輯） |

## 三、老師的看法

- 結論：總統**不能**不公布違憲的法律。立法院若通過很糟的法律、覆議又失敗，總統可以忍受、可以爭取下一次選舉，但不能用不公布來對抗。
- 檢驗方法：基本權偏向盡可能保障人民；權力分立則要想，換成你不支持的人當總統，他不覆議也不公布，你能不能接受。
