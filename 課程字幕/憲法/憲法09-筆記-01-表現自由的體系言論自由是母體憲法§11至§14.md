# 憲法09 筆記：表現自由的體系：言論自由是母體（憲法§11至§14）

## 表現自由都在「表達」：
- 言論、講學、著作、出版（§11）、秘密通訊（§12）、宗教（§13）、集會結社（§14）全部都在表達觀點
- 講學自由（學術自由、大學自治）也放在 §11

## 公式：言論自由＋特別要素：
- 秘密通訊自由＝言論自由＋**隱私**
- 宗教自由＝言論自由＋**宗教**
- 集會自由＝言論自由＋**行動**（上街）
- 結社自由＝言論自由＋**團體**

## 考試要寫對基本權：
- 考集會自由卻寫言論自由 → 不算錯，但**不精確**：言論自由已被集會自由吸納
- 要寫的是「言論自由沒有、該基本權才有」的那個要素

## 📖 法條原文速查

> **憲法 §11**　人民有**言論、講學、著作及出版**之自由。

> **憲法 §12**　人民有**秘密通訊**之自由。

> **憲法 §13**　人民有**信仰宗教**之自由。

> **憲法 §14**　人民有**集會及結社**之自由。

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「學術自由、大學自治的憲法依據？」 | **§11 講學自由** |
| 「秘密通訊自由與言論自由的關係？」 | 言論自由＋**隱私** |
| 「集會自由與言論自由的關係？」 | 言論自由＋**行動**；言論自由已被吸納 |
| 「結社自由與言論自由的關係？」 | 言論自由＋**團體** |
| 「著作、出版自由要不要另外討論？」 | 通常併入**言論自由**，考試很少單獨考 |

## 一、表現自由的同心圓

```
                 言論自由（§11）＝表達觀點
      ┌──────────────┬──────────────┬──────────────┬──────────────┐
  ＋隱私           ＋宗教          ＋行動          ＋團體
  秘密通訊（§12）   宗教自由（§13）  集會自由（§14）  結社自由（§14）
```

- 宣教為什麼歸宗教自由？它本來也是言論自由的一種，只是多了「宗教」這個要素。
- 每一種都有「與言論自由共同的部分」，也有「言論自由沒有的部分」。

## 二、答題時怎麼用

- 題目考集會遊行 → 主寫**集會自由**；言論自由只在說明「集會是表達觀點的方式」時帶到。
- 題目考社團設立 → 主寫**結社自由**（例：釋字 644，見本堂筆記 08）。
- 寫對基本權是違憲審查第一步，之後的審查基準、審查都建立在這一步上（見筆記 04 的答題架構）。

## 三、§11 內部的分工

| §11 列舉 | 考試處理 |
|---|---|
| 言論 | 主角，最愛考 |
| 講學 | 學術自由、大學自治，另外講 |
| 著作、出版 | 包含在言論自由裡，不另細分 |
