# 憲法03 筆記：法官聲請的主體與客體（憲訴§55）

## 誰能聲請：
- **各法院**：能獨立審判者都可以；獨任制由該法官、合議制由合議庭聲請
- **檢察官不能**依 §55 聲請：不審理案件、不作裁判，不會有「裁判結果」受直接影響

## 法官的「不得已」：
- 法規範違憲與否，對該案件的**裁判結果有直接影響**（通姦罪違憲 → 無罪；合憲 → 有罪）
- 違憲與否不影響判決結果 → 不符 §55

## 能就什麼聲請：
- 只有**法律位階**法規範；命令、判例、決議、函釋不拘束法官 → 法官在個案中**自行不適用**（只有個案效力）
- 爭點：**地方自治條例**——多數意見（大法官第 1509 次會議不受理決議）認為不行；黃虹霞大法官不同意見認為具法律性質者應可聲請

> 來源：憲法03 課程字幕 00:56:42 ~ 01:08:37；01:13:45 ~ 01:15:09（法官「直接影響」要件補充）（講義第 26～28 頁）

## 📖 法條原文速查

> **憲訴 §55**（法官聲請）　**各法院**就其**審理之案件**，對裁判上所應適用之**法律位階法規範**，依其**合理確信**，認有牴觸憲法，且於該案件之**裁判結果有直接影響**者，得聲請憲法法庭為宣告違憲之判決。

> **憲法 §80**　法官須超出黨派以外，**依據法律**獨立審判，不受任何干涉。

> **地方制度法 §25**（自治法規）　直轄市、縣（市）、鄉（鎮、市）得就其自治事項或依法律及上級法規之授權，制定自治法規。自治法規經地方立法機關通過，並由各該行政機關公布者，稱**自治條例**；自治法規由地方行政機關訂定，並發布或下達者，稱**自治規則**。→ 建議查閱最新六法原文

> **憲法 §110**　縣立法並執行之事項（列舉縣教育、衛生、實業、交通等）。→ 條文較長，建議查閱最新六法原文

## 📋 釋字／決議速查

> **釋字 137 號**：法官於審判案件時，對於各機關就其職掌所作有關法規釋示之行政命令，固未可逕行排斥而不用，但仍得依據法律，表示其**合法適當之見解**。

> **釋字 216 號**：法官依據法律獨立審判，各機關就其職掌所作有關法規釋示之行政命令，法官於審判案件時，**並不受其拘束**。→ 要旨建議查閱原文

> **釋字 371 號**：法官於審理案件時，對於應適用之**法律**，依其合理之確信，認為有牴觸憲法之疑義者，各級法院得以之為先決問題裁定停止訴訟程序，並提出客觀上形成確信法律為違憲之具體理由，聲請大法官解釋。（法官聲請的源頭；§55 立法理由引用 137、371）

> **大法官第 1509 次會議不受理決議**（107 年度憲三字第 5 號，花蓮地方法院法官就花蓮縣自治條例聲請）：法官聲請釋憲只能以**立法院通過之法律**為客體，地方自治條例不是法律 → **不受理**。→ 會議次數依老師講述，建議查閱原決議

> **黃虹霞大法官不同意見書**：法律僅指中央法規中由立法院三讀、總統公布者嗎？就憲法 §110 **專屬地方自治事項**、由地方立法機關通過之自治條例，似應認為**具法律性質**，而得為法官聲請釋憲之客體；自治條例也非釋字 137 所稱之行政命令。

> 字號校正：字幕「院四至371」即釋字 371；字幕「方老師」，經查此不同意見書作者為**黃虹霞**大法官。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「檢察官得否依憲訴 §55 聲請憲法法庭判決？」 | **不得**：§55 限「各法院就其審理之案件」，檢察官不審理、不作裁判（曾出現在考題） |
| 「合議庭的案件由誰聲請？」 | **合議庭**；獨任制由該法官 |
| 「法官聲請的客體？」 | **法律位階**法規範（§55） |
| 「法官認某行政命令、函釋違憲，怎麼辦？」 | 個案中**自行不予適用**，只有**個案效力**（上級審仍可能適用）；不得聲請 |
| 「§55『直接影響』是什麼意思？」 | 法規範違憲與否會**改變該案裁判結果** |
| 「法官得否就地方自治條例聲請？」 | 多數意見：**不得**（第 1509 次會議不受理）；黃虹霞不同意見：具法律性質者應可 → **爭點** |

## 一、法官聲請的主體

```
各法院（能獨立審判者）
  ├── 獨任制 → 該法官聲請
  └── 合議制 → 合議庭聲請

檢察官 ✗ → 不審理案件、只能起訴，不會有「裁判結果」
```

## 二、三角柱：憲法、法律、其他

```
        ▲
       ╱ ╲      第一層：憲法
      ╱───╲     第二層：法律（只有立法院三讀、總統公布的）→ 拘束法官 → 可以聲請
     ╱─────╲    第三層：其他（命令、函釋、判例、決議、自治規則、自治條例）
    ╱───────╲            → 不拘束法官 → 自己不適用即可，不能聲請
```

- 法官依**法律**審判（憲法 §80）→ 能拘束法官的只有憲法與法律。
- 讓法官「無異議」適用的規範，必須有足夠的**民主正當性**。

## 三、爭點：自治條例的民主正當性

| 規範 | 制定者 | 民主正當性 |
|---|---|---|
| 行政命令（例：國健署） | 人民選總統 → 總統任命行政院長 → 部會 → 所屬機關 | **很遠、薄弱** |
| 自治規則 | 地方行政機關（如臺北市政府） | 不高 |
| 自治條例 | 人民一人一票選出的**議員**（縣市議會）通過 | **高**，制定過程像法律 |

```
自治條例民主正當性高
     ├── 法官可以直接拒絕適用？→ 那就不能聲請（多數意見的結果）
     └── 法官不能直接拒絕適用？→ 應給法官聲請的空間（黃虹霞不同意見）
```

- 老師：自治條例有**法律的外觀**，但不是法律，也不是行政命令 → 落在**灰色地帶**。多數意見認為不行，但不同意見很有道理，答案沒那麼絕對。考到「法官能否就地方自治條例聲請」要記得這個爭點。
- 位階也不是絕對的上下關係，仍要看事務領域。
