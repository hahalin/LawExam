# 憲法01 筆記：修憲界限與自由民主憲政秩序

## 憲法也可以違憲：
- 修憲**有界限**，界限＝**自由民主憲政秩序**
- 抵觸這個核心價值的修憲條文，就不該是憲法
- 一試、研究所、律師司法官都「非常愛考」

## 自由民主憲政秩序的四個內涵（課堂版）：
- 民主共和國原則
- 國民主權
- 基本權保障
- 權力分立

## 法規範位階先記三層：
- 憲法 → 法律（只有立法院能立）→ 其他（命令、行政規則、函釋、自治條例、自治規則）

> 來源：憲法01 課程字幕 01:10:19 ~ 01:31:52（講義第 5～6 頁）

## 📖 法條原文速查

> **憲法 §22**　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。→ 婚姻自由的依據（釋字 748）

> **憲法 §63**　立法院有議決法律案、預算案、戒嚴案、大赦案、宣戰案、媾和案、條約案及國家其他重要事項之權。

> **憲法增修條文 §4**（立委選舉：區域、原住民、全國不分區及僑居國外國民，政黨比例代表 5% 門檻）→ 條文較長，建議查閱最新六法原文

---

## 📋 釋字原文速查

> **釋字 499 號**（課堂未唸字號，依故事內容對應）：國民大會第五次修憲以**無記名投票**進行，並將國大代表改依立委選舉政黨比例產生、延長任期；大法官認修憲有其界限，**自由民主憲政秩序**為憲法核心價值，牴觸者無效，該次修憲條文失其效力。→ 要旨文字建議查閱原文

> **釋字 721 號**：增修條文 §4 立委選舉「單一選區兩票制」與政黨比例代表 **5% 門檻**，**合憲**（聲請人：綠黨、制憲聯盟等小黨）。

> **釋字 748 號**：民法未使相同性別二人得成立婚姻關係，違反 §22 婚姻自由與 §7 平等權；婚姻具**親密性、排他性、永久性**之結合。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「憲法（修憲條文）得否作為違憲審查客體？」 | **可以**。修憲有界限（釋字 499） |
| 「修憲的界限？」 | **自由民主憲政秩序**（考試直接寫這八個字） |
| 「修憲界限的內涵？」 | 民主共和國原則、國民主權、基本權保障、權力分立 |
| 「單一選區兩票制合憲？」 | **合憲**（釋字 721）→ 小黨挑戰的是**憲法增修條文本身** |
| 「修憲改成婚姻限一夫一妻，有無問題？」 | 可能抵觸**基本權**（婚姻自由，釋字 748 → 憲法 §22）→ 修憲違憲 |
| 「誰能制定法律？」 | **只有立法院**。縣市議會制定的是**自治條例**，不是法律 |
| 「民主國一定是共和國？」 | **不一定**（英國：民主但元首世襲） |

## 一、憲法會違憲？

```
法律違憲：憲法是對的，法律是錯的
憲法違憲：憲法本身也可能錯 → 那它憑什麼審別人？
   └── 大法官的解法：憲法之上還有「核心價值」
          └── 自由民主憲政秩序
```

- 核心價值＝少了它就不是這個東西。憲法的核心任務是**防止獨裁**：再大的官也只有一部分權力（總統不能立法、不能參與判決）。
- 比喻：籃球規則禁止帶球走步；違反規則的人根本不是在打籃球。

## 二、國大修憲的故事（對應釋字 499）

1. 以前修憲由**國民大會**負責（2005 年廢除），現在修憲最後一關是**人民公投**（例：18 歲投票權修憲公投未過）。
2. 國大代表把修憲表決從記名改成**無記名**，並延長自己任期、改成依立委選舉的政黨比例直接產生。
3. 立委聲請釋憲，主張這次修憲違憲 → 大法官以「自由民主憲政秩序」為界限，宣告該次修憲失效。

- 民意代表表決應**記名**：選民要知道他投了什麼，下次才能用選票問責。

## 三、四個內涵

| 內涵 | 白話 | 例 |
|---|---|---|
| 民主共和國原則 | 最高領導者由選舉產生 | 英國是民主國但非共和國 |
| 國民主權 | 人民是國家的主人 | 外國人不能在臺灣投票 |
| 基本權保障 | 有些權利不能被多數拿走 | 修憲限一夫一妻 → 牴觸婚姻自由（釋字 748） |
| 權力分立 | 國家權力切成多份 | 五院＋總統 |

## 四、法規範位階（老師的記法）

```
憲法
 └── 法律（只有立法院）
      └── 其他：命令、行政規則、行政函釋、自治條例（議會）、自治規則（地方行政機關）
```

- 第三層彼此誰大不好比，個案判斷；考試先用三層記。
