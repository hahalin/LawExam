# 憲法02 筆記：合併審理與原因案件（憲訴§24）

## 規則：
- 分別提起的數宗聲請，憲法法庭**得**合併審理、合併裁判
- 聲請審查的**法規範或爭議同一**者，**應**就已受理的聲請案件合併審理
- 合併後一個判決，效力及於全部合併的案件

## 兩個名詞先記住：
- **原因案件**：已經向憲法法庭聲請的那些案件（例：釋字 791 合併的通姦罪聲請案）
- **其他案件**：涉及同一爭議、但仍在一般法院審理中的案件

## 下一講預告：
- 來不及合併怎麼辦？（例：判決宣示前兩天才聲請）→ **§41**
- 接著講法官聲請（較簡單）、立委聲請（講義第 29 頁起，政治爭議最多）

> 來源：憲法02 課程字幕 02:05:13 ~ 02:05:40、02:19:53 ~ 02:25:57（講義第 22 頁）

## 📖 法條原文速查

> **憲訴 §24**
> I　分別提起之數宗聲請，憲法法庭**得**合併審理，並得合併裁判。但其聲請審查之**法規範或爭議同一**者，憲法法庭**應**就已受理之聲請案件合併審理。
> II　聲請人以同一聲請書聲請數事項，憲法法庭得分別審理，並得分別裁判。

> **憲訴 §41**（下一講）　判決效力及於「以同一法規範或爭議聲請而**未及併案審理**之案件」的規定 → 細節下一講整理，建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「數宗聲請，憲法法庭可否合併審理？」 | **得**合併審理、合併裁判（§24 I 本文） |
| 「聲請審查的法規範相同時？」 | **應**就已受理之案件合併審理（§24 I 但書）→ 注意「得」與「應」 |
| 「同一聲請書聲請數事項？」 | 得**分別**審理、分別裁判（§24 II） |
| 「何謂原因案件？」 | 已向憲法法庭聲請、被合併審理的案件 |
| 「判決前來不及合併的聲請案？」 | 依 **§41** 處理（下一講） |

## 一、圖解

```
人民聲請（通姦罪）×N ┐
法官聲請（通姦罪）×M ├─ 爭議同一 → 應合併審理 → 一號解釋／判決
                     ┘                    ↓
                                 效力及於全部合併案件（原因案件）

仍在一般法院審理的通姦案件 → 其他案件（不是原因案件）
```

## 二、為什麼會有「來不及合併」

- 律師手上的案子在憲法法庭宣判前兩天才定讞 → 趕寫聲請書送進去，但憲法法庭隔天就宣判，來不及合併。
- 這種案件會被裁定駁回嗎？→ 下一講 §41。
- 老師：一般法院法官不一定隨時盯著憲法法庭的動態，所以真的可能發生。
