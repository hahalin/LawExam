# 憲法12 筆記：集會遊行法的歷史與三大爭點：許可制、禁制區、首謀

## 集會自由是什麼：
- 集會遊行＝**言論自由＋行動**：上街表達觀點（見 憲法09-筆記-01）
- 老師認為集會自由是最重要的基本權：國家怎麼保障集會自由，是檢驗這個國家多自由的**試金石**

## 沒有法律時怎麼辦：
- 憲法 §14 保障集會自由；法律**同時保障也限制**
- 沒有任何集會遊行的法律時 → 回到憲法，**想怎麼集會遊行都可以**
- 但 1949～1987 年戒嚴，上街抗議可能被以懲治叛亂條例處罰 → 實際上沒有集會自由

## 現行集遊法的來歷：
- 1988 年制定**動員戡亂時期集會遊行法**，目的是限制集會遊行；終止動員戡亂後改名集會遊行法，內容幾乎沒變
- 老師評：至今仍是限制人民的法律，所以「怎麼考都有東西可以寫」

## 三大爭點：
- **許可制**（§8 I）：上街抗議要政府同意；老師認為民主國家應採**報備制**
- **禁制區**（§6）：最值得抗議的機關周邊反而不能抗議，範圍劃得粗糙
- **首謀**（§29）：命令解散不解散，處罰首謀；當代集會遊行常常找不到首謀

## 📖 法條原文速查

> **憲法 §14**（集會結社自由）　人民有**集會及結社**之自由。

> **集會遊行法 §8 I**（許可制）　室外集會、遊行，應向主管機關**申請許可**。但左列各款情形不在此限：一、依法令規定舉行者。二、學術、藝文、旅遊、體育競賽或其他性質相類之活動。三、宗教、民俗、婚、喪、喜、慶活動。

> **集會遊行法 §6 I**（禁制區）　集會、遊行不得在左列地區及其週邊範圍舉行。但經主管機關核准者，不在此限：一、總統府、行政院、司法院、考試院、各級法院及總統、副總統官邸。二、國際機場、港口。三、重要軍事設施地區。四、各國駐華使領館、代表機構、國際組織駐華機構及其館長官邸。→ 各款與週邊範圍建議查閱最新六法原文

> **集會遊行法 §29**（首謀處罰）　集會、遊行經該管主管機關命令解散而不解散，仍繼續舉行經制止而不遵從，**首謀者**處二年以下有期徒刑或拘役。

> 字號校正：老師列舉禁制區時提到**監察院**；現行 §6 I ① 並無監察院（亦無立法院），已於 憲法09-筆記-03 查證。

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「集會自由的憲法依據？」 | **憲法 §14** |
| 「室外集會遊行，現行法採許可制或報備制？」 | **許可制**（集遊法 §8 I），但學術、藝文、宗教、婚喪喜慶等除外 |
| 「禁制區屬於何種言論限制？」 | **非內容限制**（地點），見雙軌理論 |
| 「首謀者處罰的要件？」 | 經**命令解散而不解散**，**經制止而不遵從** → 首謀處二年以下有期徒刑或拘役（§29） |
| 「禁制區包括監察院、立法院嗎？」 | **不包括**；有總統府、行政院、司法院、考試院、各級法院 |
| 「集遊法的前身？」 | 1988 年**動員戡亂時期集會遊行法** |

## 一、為什麼說許可制奇怪

- 上街抗議通常是不滿政府 → 要被抗議的人同意你抗議，邏輯矛盾。
- 報備制下，政府只在特殊情形拒絕，最典型是**同一時間地點已有人使用**。
- 老師說法：許可的比例很高（記得約 98% 以上），但集會自由要保障的是**關鍵時刻**不被拒絕。

## 二、禁制區的問題

| 問題 | 例子 |
|---|---|
| 最值得抗議的地方不能抗議 | 總統府、行政院 |
| 劃法粗糙，連帶劃進無關地點 | 新北地院周邊的停車場、家樂福；總統官邸周邊劃到兩廳院、捷運站一帶 |
| 文字與現況脫節 | 條文只寫「法院」，沒寫地檢署（早期院檢合一，歷史解釋上應包含） |
| 執法尷尬 | 法院前常有聲援、記者會，與集會遊行界線不清，警方不敢辦 |

- 老師的結論：國家可以有禁制區，例如不能跑進總統府（國安），但應限制「不能進入」，而不是周邊幾公尺都不能表達意見。

## 三、首謀的問題

- 傳統集會遊行由有魅力的人號召 → 首謀容易認定，處罰首謀是為了壓制有政治影響力的人。
- 當代集會遊行（同志大遊行、網路號召）：參加的人不是因為某人號召而來 → **誰是首謀**無從認定。
