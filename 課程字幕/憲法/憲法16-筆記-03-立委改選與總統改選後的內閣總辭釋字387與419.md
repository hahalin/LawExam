# 憲法16 筆記：立委改選與總統改選後的內閣總辭（釋字387與419）

## 釋字 387：舊體制下立委改選，內閣應總辭
- 前提：行政院長由總統提名、**經立法院同意** → 立法院的組成**直接**決定行政院長是誰
- 立委改選 → 新民意 → 行政院長應於新立委第一次集會前提出辭職，由總統重新提名、立法院同意

## 修憲後 387 前提不存在：
- 行政院長改由總統任命，不須立法院同意 → 立法院對行政院長人選的影響從**直接**變**間接**
- 解釋所依附的制度大幅改變 → **前提不存在，結論也不存在** → 387 不再適用
- 立委改選後行政院長辭職 → **禮貌性**辭職；新總統就任前辭職 → **義務性**（與總統共進退）

## 2016 年爭議：
- 馬英九主張依 387，立委改選後應由新多數黨組閣；反對說認為 387 已不適用
- 老師：387 的聲請人陳水扁，日後任總統時即主張 387 不適用，退回行政院長張俊雄的總辭

> 來源：憲法16 課程字幕 00:43:30 ~ 00:57:55（講義第 8～9 頁）

## 📖 法條原文速查

> **增修 §3 I**　行政院院長由**總統任命**之。……憲法第五十五條之規定，停止適用。

> **增修 §3 II**　行政院依左列規定，對**立法院負責**，憲法第五十七條之規定，停止適用。→ 建議查閱最新六法原文

## 📋 釋字速查

> **釋字 387 號**（1995 年）：行政院院長既須經立法院同意而任命之，且對立法院負政治責任，基於民意政治與責任政治之原理，立法委員任期屆滿改選後第一次集會前，行政院院長自應向總統提出辭職。行政院副院長、各部會首長及不管部會之政務委員係由行政院院長提請總統任命，應隨同行政院院長一併提出辭職。

> **釋字 419 號**（1996 年）：行政院院長於新任總統就職時提出總辭，係基於尊重國家元首所為之**禮貌性辭職**，並非其憲法上之義務。→ 這號作成時總統仍與立委分開產生；修憲後老師認為新總統就任前的辭職已屬**義務性**

> 字號校正：字幕「四至387」即釋字 387。老師說 387 聲請人為陳水扁（當時為立委），2008 年立委改選後陳總統退回張俊雄的總辭 → 建議查證。

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「依釋字 387，立委改選後行政院長應否總辭？」 | **應**（舊制：院長須立法院同意） |
| 「修憲後 387 是否仍適用？」 | 老師：**不再適用**，院長改由總統任命，前提不存在 |
| 「新總統就職時行政院長辭職，419 怎麼定性？」 | **禮貌性辭職**，非憲法義務 |
| 「現制下新總統就任前，行政院長辭職的性質？」 | 老師：**義務性**（與總統共進退）；立委改選後才是禮貌性 |

## 一、387 的邏輯與它的前提

```
舊制：總統提名 → 立法院同意 → 行政院長
             ↑
     立法院組成「直接」決定院長人選
             ↓
     立委改選 = 新民意 → 院長應辭職 → 重新提名、同意（387）

新制：總統任命 → 行政院長（不須同意）
     立法院組成只能「間接」影響（總統可能被迫提名溫和人選）
     → 387 的前提消失 → 387 不適用
```

- 判斷舊解釋能否適用：先找出解釋所依附的**制度前提**；制度大幅改變，前提不存在，結論就不存在。

## 二、兩種辭職的對照（老師的見解）

| 時點 | 性質 | 理由 |
|---|---|---|
| 立委改選後 | **禮貌性** | 民意改變，讓總統審視是否換人 |
| 新總統就任前 | **義務性** | 院長由總統任命，與總統共進退 |

## 三、2016 年的爭議

| 日期 | 事件 |
|---|---|
| 2016.1.16 | 蔡英文當選，民進黨立委過半 |
| 2016.2.1 | 新立法院就職，民進黨多數 |
| 2016.5.20 | 蔡英文就職，期間總統仍是馬英九 |

- 馬英九主張依 387 由新多數黨組閣；反對說：387 不適用，院長應在新總統就任前下臺。
- 老師：才三個月，應從制度面把總統與立委的就職時間合併處理。這一年 387 成為研究所熱門考題。
