# 憲法03 筆記：憲法判決的變更（憲訴§42）

## 原則不能再聲請：
- 經司法院解釋或憲法法庭判決宣告**不違憲**或作成其他憲法判斷 → 任何人不得就相同法規範或爭議再聲請（§42 I）

## 例外可以聲請變更判決：
- 憲法或相關法規範**修正**，或**相關社會情勢有重大變更**（§42 II；國家最高機關就機關爭議依 §42 III）
- 例：釋字 554（通姦罪合憲）→ 釋字 791（違憲）；釋字 656 → 111 年憲判字第 2 號

## 為什麼「不違憲」可以被翻：
- **違憲必然不合理**；但**合憲不代表合理**，只是還沒到違憲的程度 → 保留重新判斷的空間

## 📖 法條原文速查

> **憲訴 §42 I**（一事不再理）　法規範審查案件或機關爭議案件，經司法院解釋或憲法法庭判決宣告**不違憲**或作成其他憲法判斷者，除有第二項或第三項之情形外，任何人均**不得就相同法規範或爭議聲請判決**。

> **憲訴 §42 II**（聲請變更判決）　各法院、人民或地方自治團體之立法或行政機關，對於經司法院解釋或憲法法庭判決宣告未違憲之法規範，因**憲法或相關法規範修正**，或**相關社會情勢有重大變更**，認有重行認定與判斷之必要者，得分別依第三章或第七章所定程序，聲請憲法法庭為**變更之判決**。

> **憲訴 §42 III**　國家最高機關就機關爭議事項，有前項情形者，得依第四章所定程序，聲請憲法法庭為變更之判決。→ II、III 文字建議查閱最新六法原文

## 📋 釋字／憲判速查

> **釋字 554 號**（2002 年）：刑法通姦罪（舊 §239）**合憲**。

> **釋字 791 號**（2020 年）：刑法 §239 通姦罪**違憲**，自解釋公布之日起失其效力；刑事訴訟法 §239 但書（對配偶撤回告訴效力不及於相姦人）亦違憲。釋字 554 應予**變更**。

> **111 年憲判字第 2 號**：法院以判決命加害人道歉，違反**不表意自由**；釋字 656 應予**變更**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「經宣告不違憲之法規範，得否再就相同法規範聲請？」 | **原則不得**（§42 I） |
| 「什麼情形可聲請變更判決？」 | 憲法或相關法規範**修正**，或**相關社會情勢有重大變更**（§42 II） |
| 「誰可以依 §42 II 聲請變更判決？」 | **各法院、人民、地方自治團體之立法或行政機關**；國家最高機關就機關爭議另依 §42 III |
| 「憲法判決可否被後來的判決推翻？」 | **可以**：554 → 791（通姦罪）、656 → 111 憲判 2（命道歉） |
| 「宣告合憲是否代表該規定合理？」 | **不一定**：違憲必不合理，合憲只是未達違憲程度 |

## 一、§42 的結構

```
司法院解釋／憲法法庭判決宣告「不違憲」或作成其他憲法判斷
        │
        ├── 原則：任何人不得就相同法規範或爭議再聲請（§42 I）
        │
        └── 例外：聲請「變更之判決」
              ├── 事由：憲法或相關法規範修正
              │        或相關社會情勢有重大變更
              ├── 各法院、人民、地方自治團體之立法或行政機關 → §42 II
              └── 國家最高機關（機關爭議）→ §42 III
```

- 老師：條文看起來很複雜，關鍵就是「**社會情勢有重大變更**」。
- §42 I 寫的是「不違憲或作成其他憲法判斷」，「其他憲法判斷」是否包含違憲宣告，老師認為可以細談。

## 二、不合憲與不合理

```
          不合理
   ┌──────────────────────┐
   │   ┌──────────┐       │
   │   │  違憲    │       │   違憲 → 必然不合理
   │   └──────────┘       │   合憲 → 可能仍不合理，只是沒到違憲
   └──────────────────────┘
```

- 大法官宣告違憲 → 這件事一定不對。
- 大法官宣告合憲 → 只是「我沒說它違憲」，不代表百分之百對。
- 所以制度上保留空間：社會變了，可以重新判斷。

## 三、通姦罪：554 → 791

| | 釋字 554（2002） | 釋字 791（2020） |
|---|---|---|
| 結論 | 合憲 | 違憲，變更 554 |
| 背景 | 通姦被視為嚴重錯誤 | 社會觀念改變；統計發現實際上多處罰到**女性** |

- 原本預設保護女性，但傳統家庭中男性多為經濟支柱，妻子常對丈夫**撤回告訴**，丈夫對妻子則告到底 → 最後多處罰女性。
- 社會情勢重大變化 → 有機會重新解讀。
- 老師補充：大法官一定有立場，評價大法官要看**意見書的理由**，不是看立場本身；立場與論述的差異會讓判決隨時間改變。
