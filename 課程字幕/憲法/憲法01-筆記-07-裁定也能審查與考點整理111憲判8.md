# 憲法01 筆記：裁定也能審查與考點整理（111憲判8）

## 判決是句號，裁定是逗號：
- 判決：一個審級結束（一審、二審、三審）
- 裁定：訴訟進行中的中間決定（例：暫時處分「先不要拆」、羈押）
- 裁定不服 → **抗告**、再抗告

## 裁定也算「該裁判」：
- 111 年憲判字第 8 號：暫時處分之裁定，已盡審級救濟，得為裁判憲法審查之客體
- 本案本身還沒結束也可以，只要那個裁定已經不能再救濟

## 第一堂的考試兩大主軸：
- 能不能聲請（主體 × 客體的排列組合）
- 審查的客體有沒有違憲

> 來源：憲法01 課程字幕 02:22:36 ~ 02:32:53（講義第 10 頁）

## 📖 法條原文速查

> **憲訴 §59 I**　人民於其憲法上所保障之權利遭受不法侵害，經依法定程序**用盡審級救濟**程序，對於所受不利確定終局裁判，或**該裁判**及其所適用之法規範，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

---

## 📋 憲法判決速查

> **111 年憲判字第 8 號**（課堂引用段落）：暫時處分之裁定，一經法院為之，就該裁定事項即屬終結審級；因裁定而權利受侵害之關係人如有不服，僅得為抗告、再抗告；經用盡審級救濟之暫時處分裁定，得為**裁判憲法審查**之客體。→ 要旨文字建議查閱原文

> **113 年憲判字第 9 號**：涉及立法院職權相關修法，判決中處理**立法程序**瑕疵能否作為審查對象（下一堂細講）。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§59 的『該裁判』包含裁定？」 | **包含**，終局裁定經用盡審級救濟者亦屬之（111 憲判 8） |
| 「暫時處分裁定，本案尚未終結，可否聲請？」 | **可以**，只要該裁定已用盡審級救濟 |
| 「法官對函釋不滿，可否聲請憲法法庭？」 | **不可以**（§55 限法律位階） |
| 「同一法官可否在個案中宣告該函釋違憲不予適用？」 | **可以**（法官依**法律**審判，不受函釋拘束） |
| 「審查客體有哪些？」 | 憲法、法律、命令、（舊）判例決議、**裁判（判決＋裁定）** |
| 「何時起可以就裁判聲請？」 | **2022 年**憲法訴訟法施行後 |

## 一、判決 vs 裁定

| | 判決 | 裁定 |
|---|---|---|
| 比喻 | 句號 | 逗號 |
| 時點 | 一個審級結束 | 訴訟進行中 |
| 例 | 一審判決、二審判決 | 暫時處分（先不要拆屋）、羈押 |
| 不服 | 上訴 | 抗告、再抗告 |
| 可否成為裁判憲法審查客體 | 確定終局判決 ✓ | 用盡審級救濟的終局裁定 ✓（111 憲判 8） |

## 二、第一堂總整理

```
誰可以不爽（主體）
   國家最高機關｜人民｜立委 1/4｜法官｜地方自治團體
不爽誰（客體）
   憲法 → 法律 → 命令、函釋 → （舊）判例、決議 → 裁判（2022 後）
組合限制
   立委：法律位階以上
   法官：法律位階（命令、函釋自己不適用即可）
   人民：可就裁判聲請（用盡審級）
```

## 三、下一堂預告：程序能不能審

- 立法院一讀、二讀、三讀若有瑕疵，產出的法律內容沒問題，可否主張**程序違憲**？
- 老師的立場：程序設計不嚴謹，會提高結果出錯的風險，所以程序本身值得審查（下一堂結合 113 年憲判字第 9 號細講）。
- 接下來 3～4 堂依序講：人民 → 法官 → 立委 → 國家最高機關 → 地方自治團體。老師認為憲法訴訟法是**考試 CP 值最高**的部分。
