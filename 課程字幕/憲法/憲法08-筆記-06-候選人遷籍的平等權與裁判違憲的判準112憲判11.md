# 憲法08 筆記：候選人遷籍的平等權與裁判違憲的判準（112憲判11）

## 平等權爭點：候選人可以為選舉遷籍，選民不行？
- 候選人要先有該選區的選舉權才能登記參選 → 必然要把戶籍遷過去（「空降」）
- 選民為支持候選人遷籍 → 可能構成刑法 §146 II
- 憲法法庭：**不違反平等權**——候選人遷籍後必然在當地積極從事競選活動，與選區產生連結；選民單純遷籍則未必有連結

## 裁判憲法審查的判準：
- 法院對**基本權意義及保護範圍**理解錯誤，且實質影響個案裁判 → 違憲
- 適用法律（尤其**概括條款**）時，應審酌的基本權重要事項**漏未審酌**，或未辨識出**基本權衝突**、應權衡而未權衡、權衡明顯錯誤 → 違憲
- 112 憲判 11：法院把「實際居住」理解得太窄，影響選舉權的保護範圍 → 判決違憲

## 基本權衝突的例子：
- 公然侮辱（刑法 §309）：言論自由（§11）vs 名譽權（§22）→ 113 憲判 3
- 婚禮蛋糕案：店家的宗教自由、營業自由 vs 同志伴侶的平等權
- 重點不是「能不能拒絕」，而是**基於什麼理由**拒絕

## 📖 法條原文速查

> **憲法 §7**　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律**平等**。

> **刑法 §146 II**　意圖使特定候選人當選，以虛偽遷徙戶籍取得投票權而為投票者，亦同（處五年以下有期徒刑）。

> **刑法 §309 I**（公然侮辱）　公然侮辱人者，處拘役或九千元以下罰金。→ 罰金數額建議查閱最新六法原文

> **憲法 §11**　人民有言論、講學、著作及出版之自由。

> **憲法 §22**　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。→ 名譽權的依據

## 📋 憲判速查

> **112 年憲判字第 11 號**（平等權部分）：候選人須先具選舉權始得登記參選，勢必先將戶籍遷入選區；候選人遷籍後必然在選區積極從事競選相關活動，與為支持特定候選人而虛偽遷籍之選舉人不同 → 刑法 §146 II **不違反平等權**。→ 原文建議查閱憲法法庭網站

> **112 年憲判字第 11 號**（審查基準）：各級法院就法律之解釋、適用，係基於對**基本權意義及其保護範圍之錯誤理解**，且該錯誤將實質影響具體個案之裁判；或於解釋、適用法律於具體個案時，尤其涉及**概括條款**之適用，有應審酌之基本權重要事項而**漏未審酌**，或未能辨識出其間涉及**基本權之衝突**，致發生應權衡而未權衡，或其權衡有**明顯錯誤**之情形，即可認定構成違憲。→ 文字依講義朗讀整理，建議查閱原文

> **113 年憲判字第 3 號**：刑法 §309 I 公然侮辱罪，於限縮解釋範圍內不違憲；法院須權衡表意人的**言論自由**與被害人的**名譽權**。→ 原文建議查閱憲法法庭網站

> **Masterpiece Cakeshop v. Colorado Civil Rights Commission**（美國聯邦最高法院，2018 年，補充）：麵包師以宗教信仰為由拒絕替同性伴侶製作婚禮蛋糕。最高法院判麵包師勝訴，但理由限於州民權委員會對其宗教信仰**欠缺中立**，未就宗教自由與反歧視的一般衝突表態。老師說麵包師是天主教徒，一般報導為基督徒。→ 建議查證

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「候選人得為參選遷籍，選民為支持候選人遷籍卻受處罰，是否違反平等權？」 | **不違反**：候選人遷籍後必然與選區產生連結，選民未必 |
| 「法院對基本權保護範圍理解錯誤並影響裁判，憲法法庭得如何處理？」 | 宣告**裁判違憲**，廢棄發回 |
| 「裁判違憲的判準？」 | 保護範圍理解錯誤；應審酌而漏未審酌；應權衡而未權衡；權衡明顯錯誤 |
| 「公然侮辱涉及哪兩種基本權衝突？」 | **言論自由**（§11）vs **名譽權**（§22）（113 憲判 3） |
| 「雇主因員工懷孕而解僱，問題在哪？」 | 解僱本身可以，問題在**理由**——基於懷孕即構成歧視 |

## 一、平等權：兩種遷籍

| | 候選人 | 選民 |
|---|---|---|
| 為什麼遷 | 要先有選舉權才能登記參選 | 為支持特定候選人 |
| 遷籍後 | 必然在當地從事競選活動 → **與選區產生連結** | 不住、不工作在當地 → **未必有連結** |
| 處罰 | 不罰 | §146 II 處罰 |
| 結論 | 有正當理由的差別待遇 → 不違反平等權 | |

- 老師：空降的縣市長很多（舉張善政、高虹安為例），是不是當地人不一定重要；不在當地長大，不代表不能把當地治理好。

## 二、判決違憲的思考路徑

```
法院怎麼解釋、適用法律
        │
        ├── 基本權保護範圍理解錯誤？（112 憲判 11：實際居住理解太窄）
        ├── 應審酌的基本權漏未審酌？
        └── 有基本權衝突卻沒有權衡，或權衡明顯錯誤？（公然侮辱、婚禮蛋糕）
                │
                └── 任一成立，且實質影響裁判 → 裁判違憲
```

- 老師：我們對基本權內涵的理解，會影響對法律的詮釋——實際居住擴及工作地後，基本權的範圍變大，原本的判決就站不住。

## 三、基本權衝突：重點在理由

- 麵店老闆可以拒絕態度惡劣的客人；但寫「某族群與狗不得進入」，就是**歧視**。
- 同一個行為（拒絕交易、解僱），理由不同，法律評價就完全不同 → 所以需要憲法判決來權衡。
- 婚禮蛋糕案：宗教自由＋營業自由（契約自由）vs 平等權；每個個案的基本權碰撞都不一樣。
