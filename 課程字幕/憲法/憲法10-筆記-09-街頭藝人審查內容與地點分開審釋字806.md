# 憲法10 筆記：街頭藝人審查：內容與地點分開審（釋字806）

## 事實：
- 臺北市街頭藝人在公共空間表演，須先依《臺北市街頭藝人從事藝文活動許可辦法》申請**活動許可證**
- 主管機關得要求在指定場所**解說、操作、示範或表演**，審查通過才發證

## 兩個面向要分開看：
- 誰夠格當街頭藝人、表演好不好 → **不適合由政府（公務員）審查**
- 在哪裡表演、幾點表演、怎麼表演（如丟刀子、火）→ 政府**可以**做一定管制

## 釋字 806 的三層結論：
- **法律保留**：整個許可制只是地方行政機關的自治規則，未經自治條例授權 → 違反
- **藝術表現自由（§11）**：審查表演**內容** → 嚴格審查 → **違憲**；審查是否適合指定空間 → 中度審查 → 合憲
- **職業自由（§15）**：審查**技藝**（主觀條件）→ 違憲；審查地點適合性 → 合憲
- 老師：本講先講言論自由部分，法律保留、工作權部分散在其他單元

> 來源：憲法10 課程字幕 01:47:07 ~ 01:54:15（講義第四本第 46～47 頁）

## 📖 法條原文速查

> **憲法 §11**（表現自由）　人民有言論、講學、著作及出版之自由。→ 806：包括**藝術表現自由**

> **憲法 §15**（工作權）　人民之生存權、工作權及財產權，應予保障。→ 806：職業選擇自由

> **臺北市街頭藝人從事藝文活動許可辦法**
> - §4 I（系爭規定一）：街頭藝人在公共空間從事活動前，須向主管機關申請**活動許可證**。
> - §6 I 前段（系爭規定二）：取得許可證者，得在公共空間從事藝文活動。
> - §5 I（系爭規定三）：主管機關必要時得要求申請人於指定場所**解說、操作、示範或表演**，經審查通過後核發許可證。
> → 條文依解釋摘要整理，建議查閱原文

## 📋 釋字速查

> **釋字 806 號**（2021 年 7 月 30 日）：
> 1. 系爭規定一、二、三合併觀察所形成之審查許可制度，限制人民職業自由與藝術表現自由部分，未經地方立法機關通過，亦未獲自治條例授權，違反**法律保留原則**。
> 2. 對街頭藝人**技藝**之審查，屬選擇職業之主觀條件限制，不符比例原則，違反憲法 §15 **職業選擇自由**；審查藝文活動是否適於在指定公共空間進行，與比例原則無違。
> 3. 涉及審查藝文活動**內容**部分，管制目的難認係追求**特別重要公共利益**，違反憲法 §11 **藝術表現自由**；審查是否適合於指定公共空間表演部分，與比例原則無違。
> → 原文建議查閱司法院網站

> **審查基準**：
> - 時間、地點、方式等**無涉表意內容**的管制 → **中度審查**：目的須為合法公共利益，不得藏有壓抑表意內容之目的，並須留給表意人其他替代途徑。
> - 直接干預演出**內容**（議題、觀點或品質）→ **嚴格審查**：目的須為特別重要公共利益，並採最小侵害手段。

> 字號校正：老師說的「細則規定一、二、三」，解釋原文稱**系爭規定一、二、三**（許可辦法 §4 I、§6 I 前段、§5 I）。字幕「4至806」即**釋字 806**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「街頭藝人表演內容須經政府審查，合憲嗎？」 | **違憲**（806），嚴格審查，違反藝術表現自由 |
| 「審查表演是否適合在指定地點進行？」 | **合憲**，中度審查 |
| 「806 對時間地點方式管制採何基準？」 | **中度審查**（不是一律寬鬆，陷阱） |
| 「審查街頭藝人技藝，限制哪種職業自由？」 | 選擇職業之**主觀條件** → 違憲 |
| 「806 許可制違反法律保留的原因？」 | 只是**自治規則**，未經自治條例授權 |

## 一、同一個許可制，切三刀

```
臺北市街頭藝人許可制（自治規則）
   ├─ 法律保留：未經自治條例授權 → 違反
   ├─ §11 藝術表現自由
   │    ├─ 審查內容（議題、觀點、品質）→ 嚴格審查 → 違憲
   │    └─ 審查地點適合性 → 中度審查 → 合憲
   └─ §15 職業自由
        ├─ 審查技藝（主觀條件）→ 違憲
        └─ 審查地點適合性 → 合憲
```

## 二、為什麼地點可以管

- 西門町捷運出口前空間小，適合畫畫、不適合雜耍；裡面較大的區域才適合。
- 晚上十點、住宅附近 → 時間要管。
- 丟刀子、火焰雜耍 → 方式要管（老師舉道具刀失手飛入觀眾席的影片）。
- 但時間、地點、方式的管制**不能夾帶壓抑內容**的效果，否則仍要回到內容審查。
