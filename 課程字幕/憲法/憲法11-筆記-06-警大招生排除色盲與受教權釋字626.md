# 憲法11 筆記：警大招生排除色盲與受教權（釋字626）

## 事實：
- A 報考**中央警察大學**研究所碩士班，初試通過、複試時體檢發現**色盲**
- 依警大招生簡章，體格檢查不合格 → 不予錄取
- A 主張侵害其**受教育權**，聲請釋憲

## 第一個重點：招生簡章是審查標的
- 傳統上釋憲標的必須是**法規範**
- 626：警大招生簡章是國立大學**對外發布之一般性規範** → 具法規範性質，可以審查

## 第二個重點：警大與一般大學不同
- 一般大學培養什麼人才由各校自定；警大、國防大學負有**執行國家任務**的特殊目的
- 警大隸屬**內政部**（國防大學隸屬國防部，一般大學屬教育部）
- 警大仍享有一定程度的自治權，但受本質功能限制（例：不得設與警政無關的系），應接受**比一般大學更多的國家監督**
- 法律授權內政部訂資格標準、警大據以訂簡章 → **合憲**

## 第三個重點：受教權的兩種憲法依據
- 受**國民教育**之權利 → 憲法 **§21**
- 受**國民教育以外**教育之權利（大學、研究所）→ 憲法 **§22**

## 結論：
- 排除色盲考生**合憲**

## 📖 法條原文速查

> **憲法 §21**（受國民教育之權利義務）　人民有受**國民教育**之權利與義務。

> **憲法 §22**（概括基本權）　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。→ 626：受國民教育以外教育之權利

> **憲法 §7**（平等權）　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律平等。

> **憲法 §159**（教育機會平等）　國民受教育之機會，一律平等。

## 📋 釋字速查

> **釋字 626 號**（2007 年）：中央警察大學 91 學年度研究所碩士班招生簡章，係警大就招生事項所訂定對外發布之**一般性規範**。警大隸屬內政部，負責警察養成教育，與國家警政水準及社會治安息息相關，其組織與任務有特殊性，而與一般大學**未盡相同**；然研究高深學術亦為其設校宗旨，就涉及警察學術之教學、研究與學習事項，包括入學資格條件，享有**一定程度之自治權**。警大自治權之行使應受其本質與功能之限制，例如不得設立與警政無關之系別，並應受**較一般大學更多之國家監督**。招生簡章以色盲為不予錄取之事由，與憲法 §7、§159 平等受教育之意旨**無違**。→ 解釋文原文建議查閱司法院網站

## 一、一般大學與負有國家任務的大學

| | 一般大學 | 警大、國防大學 |
|---|---|---|
| 主管機關 | 教育部 | 內政部、國防部 |
| 培養什麼人才 | 各校自定 | 警察、軍事人才（國家任務） |
| 能否設任意系所 | 可以 | 不得設與本質無關的系（警大不能開音樂系） |
| 國家監督 | 適法性監督 | 比一般大學**更多** |
| 法律授權主管機關訂入學標準 | 違反大學自治（參 380） | 合憲（626） |

## 二、考試怎麼用 626（老師口述）

- 老師說 2018 年律師考試考過類似題型：軍校學生被退學，分別扮演被退學者與軍校寫法律意見書（→ 題目年份與內容建議查證）。
- **軍校方**：主張大學自治。
- **被退學者方**：主張 626「與一般大學未盡相同」→ 不能直接套用一般大學的自治強度，國家監督較多、司法審查也可較密。
- 兩邊寫一樣的答案就失分。

## 三、色盲真的不能當警察嗎（老師的保留）

- 大法官結論合憲；但色盲程度不一，警察職務中是否有適合的角色，可以更細緻討論。
- 若為色盲另設職位，又可能產生其他不合理 → 這就是憲法的難題。
