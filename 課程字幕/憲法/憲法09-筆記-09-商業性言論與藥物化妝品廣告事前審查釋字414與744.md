# 憲法09 筆記：商業性言論與藥物、化妝品廣告事前審查（釋字414與744）

## 商業性言論：
- 定義：提供有助於人民做出**經濟上合理選擇**的資訊
- 考試最愛考（政治性言論結論固定，反而不好考）
- 傳統說法是低價值（414）；老師認為**不一定**：同一瓶水，「成分標示」可以嚴管，「源自雪山、天然純淨」的廣告詞不該嚴管

## 釋字 414（1996 年）：藥物廣告事前審查**合憲**
- 藥物廣告與國民健康有重大關係，「應受**較嚴格之規範**」
- 陷阱：「較嚴格之規範」＝法律可以管得較嚴＝**寬鬆審查**，不是嚴格審查

## 釋字 744（2017 年）：化妝品廣告事前審查**違憲**
- 事前審查原則違憲；例外須防免生命身體健康遭受直接、立即、難以回復的危害
- 化妝品上架前已有其他管制（成分、許可字號等），廣告送審沒有直接及絕對必要關聯

## 老師的兩個反思：
- 用廣告送審保護健康，合理嗎？必要嗎？
- 744 的標準近似**明顯而立即的危險**；若真照此標準，幾乎沒有言論能被限制 → 這個美國法上的傳統標準是否過時？

## 📖 法條原文速查

> **藥事法 §66 I**（藥物廣告事先核准）　藥商刊播藥物廣告時，應於刊播前將所有文字、圖畫或言詞，申請中央或直轄市衛生主管機關**核准**，並向傳播業者送驗核准文件。→ 建議查閱最新六法原文

> **化妝品衛生管理條例 §24 II**（舊）　化妝品之廠商登載或宣播廣告時，應於事前將所有文字、畫面或言詞，申請中央或直轄市衛生主管機關**核准**，並向傳播機構繳驗核准之證明文件。→ 釋字 744 宣告違憲失效

> **化妝品衛生管理條例 §30 I**（舊）　違反 §24 II 者，處新臺幣**五萬元以下**罰鍰。→ 744 一併宣告違憲失效；本條例已於 2018 年全文修正為「化妝品衛生安全管理法」，建議查閱最新六法原文

## 📋 釋字速查

> **釋字 414 號**（1996 年）：藥物廣告係為獲得財產而從事之經濟活動，涉及財產權之保障，並具商業上意見表達之性質，惟因與國民健康有重大關係，基於公共利益之維護，**自應受較嚴格之規範**。……言論自由……包括政治、學術、宗教及商業言論等，並依其性質而有不同之保護範疇及限制之準則。其中**非關公意形成、真理發現或信仰表達之商業言論，尚不能與其他言論自由之保障等量齊觀**。→ 藥事法事先審查規定**合憲**；原文建議查閱司法院網站

> **釋字 744 號**（2017 年 1 月 6 日）：化妝品廣告之事前審查乃對言論自由之重大干預，**原則上應為違憲**。系爭規定之立法資料須足以支持對化妝品廣告之事前審查，係為防免人民生命、身體、健康遭受**直接、立即及難以回復危害**之特別重要之公共利益目的，其與目的達成之間具**直接及絕對必要關聯**，且賦予人民**獲立即司法救濟**之機會，始符合比例原則及保障言論自由之意旨。化妝品衛生管理條例 §24 II、§30 I 相關部分違憲，自解釋公布之日起失其效力。

> 事實（老師口述）：414 的原因案件是 1994 年在《長春》雜誌刊登醫療器材（富士第一治療器）廣告，只有一句「週年慶送臺北—首爾來回機票抵用券 3000 元」未送審。744 的原因案件是 DHC 在奇摩購物中心刊登防曬乳廣告（「能在肌膚表面形成保護膜，預防陽光傷害肌膚……」）未經核准，被罰 3 萬元。

> 補充：「明顯而立即的危險」源自美國 Schenck v. United States（1919，Holmes 大法官，「在戲院裡謊稱失火」的比喻）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「商業性言論的保障程度？」 | 414：非關公意形成、真理發現或信仰表達，**不能與其他言論等量齊觀** |
| 「藥物廣告事前審查？」 | **合憲**（釋字 414） |
| 「414 說『應受較嚴格之規範』，審查基準是？」 | **寬鬆審查**（陷阱：不是嚴格審查） |
| 「化妝品廣告事前審查？」 | **違憲**（釋字 744），事前審查原則違憲 |
| 「744 事前審查例外合憲要件？」 | 直接、立即、難以回復之危害＋直接及絕對必要關聯＋立即司法救濟 |
| 「為何化妝品與藥物結論不同？」 | 化妝品對健康的危害非立即；產品上市前已有其他管制，廣告送審無絕對必要 |

## 一、商業性言論的價值看資訊性質

| 同一瓶水上的資訊 | 性質 | 管制強度 |
|---|---|---|
| 成分、容量、保存期限、水源 | 保障生命身體健康的揭露資訊 | 可以要求較嚴格 |
| 「源自雪山，天然純淨」 | 創意性的廣告詞 | 不應嚴格管制 |

| 產品 | 廣告管制 |
|---|---|
| 水、飲料 | 幾乎不管 |
| 酒 | 可以廣告，要加警語 |
| 菸 | 幾乎等於禁止 |
| 藥物、醫療器材 | 事前送審（414 合憲） |
| 化妝品 | 事前送審（744 違憲） |

## 二、414 與 744 對照

| | 釋字 414（1996） | 釋字 744（2017） |
|---|---|---|
| 法律 | 藥事法 | 化妝品衛生管理條例 |
| 產品 | 藥物、醫療器材 | 化妝品（含保養品） |
| 審查基準 | 寬鬆（「應受較嚴格之規範」） | 嚴格（事前審查原則違憲） |
| 結論 | 合憲 | 違憲，公布日失效 |
| 理由 | 與國民健康有重大關係 | 危害非立即；已有成分、許可字號等管制，廣告送審無直接及絕對必要關聯 |

- 老師的質疑：若擦在身上就要送審，吃下肚的食品廣告豈不更該送審？藥局的藥亂吃可能會死，化妝品亂擦通常不會怎樣（除非肌膚敏感）。
- 背景：化妝品業者長期不滿送審曠日費時又要繳費，DHC 案成為聲請契機。

## 三、明顯而立即危險的反思

```
傳統標準：明顯而立即的危險才能限制（戲院裡喊失火）
      ↓
744 擴寫：防免生命身體健康遭受直接、立即、難以回復的危害
      ↓
反思：真的有言論會造成「立即」危險嗎？
      若照此標準，幾乎什麼言論都不能限制
      → 標準是否太舊？言論自由市場的假設是否太傳統？（筆記 02）
```
