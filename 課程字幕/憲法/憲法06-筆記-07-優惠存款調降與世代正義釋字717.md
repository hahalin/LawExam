# 憲法06 筆記：優惠存款調降與世代正義（釋字717）

## 事實：
- 1960、70 年代為吸引人才擔任公務員，給予退休公教人員 **18% 優惠存款**
- 2006 年後討論國家財政負擔，銓敘部修正相關要點，降低優惠存款額度 → 退休人員聲請解釋

## 定性：繼續性法律關係：
- 優惠存款不是一次給付就結束，而是**持續存在**的法律關係 → **不真正溯及既往**
- 進入不真正溯及既往 → 審查**信賴保護**與過渡措施

## 結論：
- 改革會影響退休人員權益，但為世代公平、減輕財政負擔，且改革**合理、漸進** → **合憲**

## 世代正義：
- 現在的決定影響未來世代；與**氣候訴訟**相連（要求國家作為，類似行政法的課予義務訴訟）

## 一、為什麼優存是不真正溯及

```
一次給付（例如一次退休金已領完）── 已終結 ─→ 事後追回 = 真正溯及
優惠存款（每期都在計息）────────── 持續中 ─→ 嗣後調降 = 不真正溯及
                                                    │
                                              審查信賴保護、過渡措施
```

- 公務員的不滿可以理解：重點不是領多少，是「當初跟我講好的，現在要砍」。
- 老師補充：文官體系穩定是民主發展順利的關鍵因素之一；不要歧視公務人員。

## 二、世代正義與氣候訴訟

| | 典型憲法訴訟 | 氣候訴訟 |
|---|---|---|
| 請求 | 宣告某規範或判決違憲 | 要求國家**做到**一定程度（如減碳） |
| 類比 | 撤銷訴訟（處分我不要） | **課予義務訴訟**（不只不要，還要給我滿意的） |
| 正當性 | 侵害現在的基本權 | 影響 50 年、100 年後世代的基本權 |

- 荷蘭、德國、韓國、美國都有氣候訴訟；臺灣目前較接近的是立法不作為的討論，但不完全一樣。
