# 憲法04 筆記：暫時處分（憲訴§43與釋字599）

## 暫時處分是什麼：
- 一件事做下去損害太大，判決出來前**先暫停**

## 要件（§43）：
- ① 權利或公益遭受**難以回復之重大損害**
- ② 有**急迫必要性**
- ③ **無其他手段**可資防免
- ④ 隱藏要件：**利大於弊**（比較准與不准、判決合憲與違憲四種結果）

## 新舊法對照：
- 舊法沒有暫時處分 → 大法官用**一號解釋**暫停（釋字 599）、再用**一號解釋**宣告違憲（釋字 603）
- 新法：**一個裁定**（113 年憲暫裁字第 1 號）＋**一個判決**（113 年憲判字第 9 號）→ 比較合理

## 考法：
- 法律已規定完整，暫時處分本身較少單獨考；可能考你在實務上會不會想到**先聲請暫時處分**

## 📖 法條原文速查

> **憲訴 §43 I**（暫時處分）　聲請案件繫屬中，憲法法庭為避免憲法所保障之**權利或公益**遭受**難以回復之重大損害**，且有**急迫必要性**，而**無其他手段可資防免**時，得依聲請或依職權，就案件相關之爭議、法規範之適用或原因案件裁判之執行等事項，為**暫時處分**。→ 其餘各項建議查閱最新六法原文

---

## 📋 釋字／憲法法庭裁判速查

> **釋字 599 號**（2005 年）：戶籍法 §8 II、III（換發身分證按捺指紋）於釋字 603 作成前**暫時停止適用**。大法官依職權得為保全處分（暫時處分）。

> **釋字 603 號**（2005 年）：戶籍法 §8 II、III 強制按捺指紋始發身分證違憲，隱私權受憲法 §22 保障。

> **113 年憲暫裁字第 1 號**（2024 年）：立法院職權行使法等國會改革修法（國會調查權、總統國情報告等）部分條文，於本案判決前**暫時停止適用**。

> **113 年憲判字第 9 號**（2024 年）：國會改革修法案本案判決。

> 字號校正：字幕「113年憲判，憲裁之一號」應為 **113 年憲暫裁字第 1 號**；「4至599」「4603」即釋字 599、603。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「憲法法庭為暫時處分的要件？」 | **難以回復之重大損害**＋**急迫必要性**＋**無其他手段**可資防免（§43） |
| 「暫時處分可否依職權為之？」 | **可以**，依聲請或依職權 |
| 「暫時處分以什麼形式作成？」 | **裁定**（非終局判決） |
| 「舊法時代大法官以什麼作成暫時處分？」 | 以**解釋**：釋字 599（按捺指紋）→ 本案釋字 603 |
| 「舊法沒有規定，大法官憑什麼暫時處分？」 | 「**較大的權力必然蘊含較小的權力**」：能宣告違憲失效，就能先凍結 |

## 一、利大於弊：律師考試報名的例子

| | 最後認定**有**資格 | 最後認定**沒**資格 |
|---|---|---|
| **先讓他考** | 很好 | 撤銷考試結果，損害小 |
| **不讓他考** | **重大損失（無法回復）** | 還好 |

- 最怕的是「有資格但不讓他考」→ 所以先讓他考。

## 二、按捺指紋：為什麼要凍結

```
不凍結 → 全臺 2300 萬人指紋都壓下去 → 最後宣告違憲 → 隱私權難以回復
凍結   → 最後違憲：皆大歡喜
       → 最後合憲：再去做就好
```

## 三、新舊法對照

| | 舊法（大審法） | 新法（憲訴法） |
|---|---|---|
| 規定 | 沒有暫時處分 | **§43** 明文 |
| 指紋案／國會改革案 | 釋字 599（解釋）＋ 釋字 603（解釋） | 113 憲暫裁 1（**裁定**）＋ 113 憲判 9（**判決**） |
| 評價 | 用解釋做暫時處分不太對，但當時沒有權力 | 比較合理 |

- 講義第 54 頁補充：釋字 599 旁寫 **603**；113 憲暫裁 1 旁寫 **113 憲判 9**。
