# 憲法03 筆記：想修法要修法未果（釋字603與113憲裁16）

## 為什麼只有「想修法」，沒有「想立法」：
- 聲請標的一定是一部**已存在的法律**；想立法而失敗，沒有東西可以聲請
- 不想修法 → 標的是**新法**；想修法 → 標的是**舊法**

## 兩種失敗不一樣：
- 好好阻擋：對方最後一定走到二讀、三讀表決 → 失敗有紀錄、標準較明確
- 好好修法：對方怎麼擋沒有固定方式 → 怎樣才算「修法失敗」較難判斷

## 兩個案例：
- **釋字 603**：修正草案交付委員會後，院會**兩次**就復議案決議「**另定期處理**」→ **修法未果**，算行使職權 → 受理
- **113 年憲裁字第 16 號**：修正草案**仍在委員會審查中** → 還沒失敗，不符修法未果 → 不受理

> 來源：憲法03 課程字幕 01:57:43 ~ 02:17:31（講義第 31、35 頁）

## 📖 法條原文速查

> **憲訴 §49**　立法委員現有總額四分之一以上，**就其行使職權**，認法律位階法規範牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> **戶籍法 §8 II、III**（舊法，釋字 603 宣告違憲）　II 依前項請領國民身分證，**應捺指紋並錄存**。但未滿十四歲請領者，不予捺指紋，俟年滿十四歲時，應補捺指紋並錄存。III 請領國民身分證，不依前項規定捺指紋者，**不予發給**。→ 建議查閱原文

> **憲法 §22**　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。（隱私權的依據）

---

## 📋 釋字／憲裁速查

> **釋字 603 號**（2005/9/28）：
> - 程序：戶籍法 §8 II、III 修正案經程序委員會提報院會，院會決議交內政及民族、財政兩委員會審查，嗣**兩次就復議案決議另定期處理** → 屬**修法未果**，符合「行使職權」要件而受理。
> - 實體：**隱私權**受憲法 §22 保障（含資訊隱私權）；強制按捺指紋始核發身分證之規定**違憲**，不再適用。→ 實體要旨到隱私權章節細講，建議查閱原文

> **113 年憲裁字第 16 號**（2024/5/24，賴香伶等 31 位立委就勞工保險條例 §13 等規定聲請）：
> 「倘法律公布施行經相當時日，立法委員認有違憲疑義，自應先行提出修正案，並於確定修法未成後，由少數之四分之一以上立法委員聲請法規範憲法審查」；聲請人提出之新增及修正草案「**仍於立法院有關委員會審查中**，不符前述『修法未果』意旨，尚難認與『行使職權』之要件相符」→ **不受理**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「立委想修正某舊法未成，聲請釋憲的要件？」 | 須**修法未果**，才屬「行使職權」 |
| 「修正草案在院會兩次被決議『另定期處理』？」 | 屬**修法未果** → 可聲請（**釋字 603**） |
| 「修正草案仍在委員會審查中即聲請？」 | **不符**修法未果 → 不受理（**113 年憲裁字第 16 號**） |
| 「釋字 603 的聲請人？」 | **立委**（賴清德等），不是人民 |
| 「釋字 603 實體結論？」 | 強制捺指紋始發身分證**違憲**；隱私權受**憲法 §22** 保障 |
| 「立委能否就『想立法但失敗』聲請？」 | **不能**，沒有可聲請的標的 |

## 一、兩種行為樣態對照

| | 不想修法或立法 | 想修法 |
|---|---|---|
| 我方處境 | 對方要通過新法，我方反對 | 我方要修掉舊法，修不掉 |
| 聲請標的 | **新法** | **舊法** |
| 怎樣算失敗 | 對方二讀、三讀通過 | 對方擋住我方的修正案 |
| 要看什麼 | 有沒有**好好阻擋** | 有沒有**修法未果** |
| 代表案例 | 1476 次決議、釋字 781 | 釋字 603、113 憲裁 16 |
| 發生頻率 | **較常見**（現在比較重要） | 較少 |

- 老師：以前先教 603 再教 781；現在倒過來，因為「對方剛做的事我超不開心，立刻聲請」比「修不掉一部有一陣子的法律」常見得多。

## 二、釋字 603 的故事（按捺指紋）

```
1990 年代末  戶籍法 §8 修正：換發新身分證要按捺指紋（老師說約 1998 年）
              → 人權團體反對（隱私權；外包廠商爭議）→ 擱置
2000         政黨輪替，民進黨執政 → 不推動
              → 監察院糾正行政院：法律已規定，為什麼不做？
              → 行政院找立法院（國民黨多數）修法 → 不修
2005         內政部（民進黨政府）改為傾向推動
              ↔ 民進黨立委反對 → 內政部：要不做，你們就去修法
              → 民進黨立委提出戶籍法 §8 修正案
              → 交委員會審查 → 院會兩次「另定期處理」
              → 賴清德等立委聲請釋憲（蔡英文立委出席言詞辯論）
              → 釋字 603：受理，§8 II、III 違憲
```

- 關鍵：有提修正案、有交委員會、被**兩次另定期處理**（連審查都沒開始就一直延後）→ 大法官認為立法院**怠於處理** → 修法未果。

## 三、113 年憲裁字第 16 號：還在委員會審查中

```
提出修正草案 → 交委員會 → 審查中（112/12/29 聲請時仍在審查）
                              ↓
                       還沒失敗 → 不是修法未果 → 不受理
```

| | 釋字 603 | 113 憲裁 16 |
|---|---|---|
| 草案位置 | 委員會 | 委員會 |
| 狀態 | 院會兩次決議另定期處理（**被擱置**） | **審查中**（還在進行） |
| 是否失敗 | 是 | 否 |
| 結果 | 受理 | 不受理 |

## 四、法律的歸納與演繹

- 兩次另定期處理 → 可以。
- 三次 → 應該也可以。
- 一次 → **不知道**。
- 老師：讀法律要學會從案例歸納、再演繹到新情形；更深層要評價的是「**怎樣修法才算失敗**」。
