# 憲法13 筆記：大學教師評鑑與大學自治（111憲判12）

## 案例：
- 臺大法律學院一位副教授，教師評鑑未通過；兩年內複評仍未通過 → 可能不續聘
- 申訴、再申訴、行政訴訟都敗訴 → 主張評鑑施行細則（教學、研究、服務如何評分、70 分門檻）不明確、程序不公，侵害工作權

## 屬於哪一階：主觀條件
- 評鑑未通過 → 可能不續聘、資遣 → 改變**身分**
- 但教師可**透過自己的努力**避免 → **主觀**條件限制（像 584：不犯那些罪就能開計程車）

## 但要調降審查基準：大學自治
- 評鑑規定是大學依大學法 §21 授權、在**大學自治**範圍內訂定
- 尊重大學自治規章的自主權 → **降低審查密度**，採**寬鬆審查** → 合憲

## 答題重點：
- 本案涉及的是教師的**工作權**，不是講學自由；大學自治是另一個面向
- 主觀限制原本審查較嚴，因大學自治而調降 → 這種「排列組合」就是考試要考的

## 服公職是特殊的工作權：
- 服公職是一種工作，但工作不一定是服公職 → **同心圓**
- 限制公職人員的工作 → 審**憲法 §18** 服公職權，不是 §15 工作權

## 📖 法條原文速查

> **憲法 §15**　人民之生存權、**工作權**及財產權，應予保障。

> **憲法 §18**　人民有應考試、**服公職**之權。

> **大學法 §21**　大學應建立**教師評鑑**制度，對於教師之教學、研究、輔導及服務成效進行評鑑，作為教師升等、續聘、長期聘任、停聘、不續聘及獎勵之參考。→ 原文建議查閱最新六法原文

---

## 📋 憲判速查

> **111 年憲判字第 12 號**：審查標的為國立臺灣大學法律學院教師評鑑辦法施行細則 §5～§8。大學教師評鑑未通過，可能涉及不續聘等效果，教師得透過個人努力避免喪失教師身分，屬對大學教師職業自由**主觀條件**的限制；惟為尊重**大學自治**規章訂定的自主權，降低審查密度，適用**寬鬆審查**基準 → 不違憲。另涉及法律明確性、正當法律程序。→ 主文與日期建議查閱憲法法庭網站

> 楊惠欽大法官部分協同、部分不同意見書：贊同寬鬆審查，但理由是評鑑未通過只是無法在原大學繼續任教，並未剝奪教師資格，與一般主觀條件限制有程度差異。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「大學教師評鑑未通過不續聘，限制何種基本權？」 | **工作權**（職業自由），不是講學自由 |
| 「屬哪一階？」 | **主觀**條件（可透過個人努力避免） |
| 「111 憲判 12 採何種審查基準？」 | **寬鬆**：因**大學自治**降低審查密度 |
| 「111 憲判 12 結論？」 | **合憲** |
| 「限制公務員的工作，審哪一條？」 | 憲法 **§18** 服公職權（特殊工作權） |

## 一、審查基準怎麼決定

```
誰？大學教師
什麼權利？工作權（職業自由）
怎麼限制？評鑑未通過 → 不續聘 → 改變身分 → 主觀限制（原應較嚴）
   │
   └── 但：規範出自大學、屬大學自治範圍
          → 調降審查密度 → 寬鬆審查 → 合憲
```

## 二、工作權與服公職權

```
┌──────────── 工作（§15）────────────┐
│                                     │
│        ┌── 服公職（§18）──┐         │
│        └──────────────────┘         │
└─────────────────────────────────────┘
```

- 公務人員因評鑑、考績被淘汰 → 落入特殊工作權，審 §18。
