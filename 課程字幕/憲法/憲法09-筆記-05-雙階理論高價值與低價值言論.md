# 憲法09 筆記：雙階理論：高價值與低價值言論

## 高低價值不是在評價言論好不好：
- 而是**國家限制它的正當性**高低
- 高價值 → 國家限制正當性低 → 審查**從嚴**
- 低價值 → 國家限制正當性高 → 審查**從寬**

## 例子：
- **政治性言論**：高價值，是言論自由的核心
- **色情言論**：低價值（可能涉及兒少保護）→ 真人兒少性影像全面禁止；一般色情限制 18 歲以下

## 商業性言論不一定：
- 依**產品**與**擺放位置**而不同：水、飲料廣告幾乎不管；菸幾乎等於禁止廣告；酒要加警語
- 詳見筆記 09

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「雙階理論區分什麼？」 | **高價值**言論與**低價值**言論 |
| 「高價值言論的意義？」 | 國家限制的**正當性低** → 嚴格審查 |
| 「政治性言論屬於？」 | **高價值**，言論自由的核心 |
| 「商業性言論一律是低價值？」 | **不一定**，依產品與資訊性質而異（傳統見解：414 視為低價值） |
| 「雙軌與雙階的差別？」 | 雙軌看**怎麼限制**（內容／非內容）；雙階看**限制什麼言論**（高／低價值） |

## 一、雙階理論的結構

```
言論的價值（＝國家限制的正當性高低）
│
├── 高價值：政治性言論
│     → 國家管制正當性低 → 嚴格審查
│
├── 低價值：色情言論
│     → 國家管制正當性高 → 寬鬆審查
│     例：真人兒少性影像完全禁止；一般色情 18 歲以下不能看
│
└── 不一定：商業性言論
      菸 → 幾乎等於不能廣告（對身體影響大）
      酒 → 可廣告，但要加警語
      水、飲料 → 幾乎不管
```

- 政治性言論不會規定「18 歲以下不能看」，色情可以 → 這就是價值高低的差別。

## 二、三種分類一起用

| 分類 | 問的問題 | 從嚴 | 從寬 |
|---|---|---|---|
| 雙軌（筆記 03） | 限制內容，還是時間地點方式？ | 內容 | 非內容（但不一律） |
| 雙階（本筆記） | 被限制的是什麼價值的言論？ | 高價值 | 低價值 |
| 事前／事後（筆記 07） | 講之前要審核，還是講了再罰？ | 事前 | 事後 |

- 三種分類都是在決定**審查基準**，是答題架構第二步（筆記 04）。
