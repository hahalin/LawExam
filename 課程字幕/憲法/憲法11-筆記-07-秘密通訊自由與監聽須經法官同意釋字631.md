# 憲法11 筆記：秘密通訊自由與監聽須經法官同意（釋字631）

## 秘密通訊自由是什麼：
- 講**悄悄話**的權利：寫信、講電話、LINE 一對一訊息
- 臉書公開貼文不是悄悄話 → 屬一般言論自由
- 公式：**言論自由＋隱私＝秘密通訊自由**（憲法 §12）

## 監聽為什麼影響特別大：
- 監聽 A，所有跟 A 聯絡的人都被監聽 → 更可能侵害**第三人**
- 被監聽者**不知道** → 無法行使訴訟法上的防禦權利（對照羈押：可請律師、開羈押庭）
- 監聽具**持續性**、不受空間限制

## 釋字 631：
- 舊通保法由**檢察官**自行核發通訊監察書 → **違憲**
- 監聽須經**中立、客觀的法官**審核 → 邏輯與釋字 392（羈押權回歸法官）相同

## 監聽的三層要求：
- **形式**：法律要件具體明確，不可以行政命令為依據
- **程序**：中立客觀的法官事前審核
- **實質**：嚴格審查標準

## 📖 法條原文速查

> **憲法 §12**（秘密通訊自由）　人民有秘密通訊之自由。

> **舊通訊保障及監察法 §5 II**　通訊監察書，偵查中由**檢察官**依司法警察機關聲請或依職權核發。→ 釋字 631 違憲；現行法已改由法官核發，條文建議查閱最新六法原文

---

## 📋 釋字速查

> **釋字 631 號**（2007 年）：憲法 §12 保障人民秘密通訊自由。國家採取限制手段時，除應有法律依據外，限制之要件應具體、明確，不得逾越必要範圍，並踐行**必要之法律程序**。舊通保法 §5 II 未要求通訊監察書原則上應由**客觀、獨立行使職權之法官**核發，而使職司犯罪偵查之檢察官與司法警察機關同時負責通訊監察書之聲請與核發，難謂為合理、正當之程序規範，**違憲**。→ 解釋文原文建議查閱司法院網站

> **釋字 392 號**（1995 年）：檢察官無羈押權，羈押須由法院決定（見 憲法07-筆記-08）。

> 字號校正：字幕「4至631」即釋字 631。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「偵查中由檢察官核發通訊監察書，合憲嗎？」 | **違憲**（631）：應由**法官**核發 |
| 「631 的邏輯與哪號解釋相近？」 | **釋字 392**（羈押權回歸法官） |
| 「監聽能否以行政命令為依據？」 | **不行**，至少要**法律**（法律保留） |
| 「監聽為何比其他強制處分更須嚴謹？」 | 持續性、被監聽者不知情無法防禦、易侵害**第三人** |
| 「LINE 一對一訊息受何種基本權保障？」 | **秘密通訊自由**（§12）；公開貼文則屬言論自由 |

## 一、監聽的審查架構（講義第 73 頁圖）

```
監聽（限制 §12 秘密通訊自由）
├── 形式：法律保留＋要件具體明確（不得以行政命令）
├── 程序：中立客觀法官審核（631）
└── 實質：嚴格審查
       ├── 持續性、不受空間限制
       ├── 被監聽者不知情 → 無法行使訴訟權利
       └── 比其他強制處分更易侵害第三人
```

## 二、老師講的故事

- 曾有立委質詢部長：監聽依據為何？部長答依交通部行政命令，並反問「難道不抓壞人嗎？」→ 從法治角度，回答很糟：監聽至少要有**法律**依據。老師說這兩人後來都當了總統，請同學自己去查。
- 監聽某人時意外聽到其他人的事，曾引發政爭 → 說明監聽對第三人的影響。
- 老師：秘密通訊單元多已成為成熟的法律規定，考試相對少考。
