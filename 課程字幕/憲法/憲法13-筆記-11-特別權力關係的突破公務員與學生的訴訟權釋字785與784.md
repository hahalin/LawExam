# 憲法13 筆記：特別權力關係的突破：公務員與學生的訴訟權（釋字785與784）

## 什麼是特別權力關係：
- 過去預設某些人（公務員、受羈押被告、學生）**不需要完整的訴訟權**
- 現在已全面突破 → 考試價值降低，但要知道演進

## 公務員：243 → 298 → 785
- **243**：**免職**改變公務員身分 → 可以行政訴訟；**記大過**未改變身分 → 不可以
- **298**：足以改變公務員身分或對其有**重大影響**的懲戒處分 → 應有救濟
- **785**：申訴、再申訴之後，也可以依措施性質**提起行政訴訟**；是否違法侵害權利，由法院個案判斷

## 受羈押被告：
- 過去不服看守所處遇只能申訴，不能向法院救濟 → 現在**可以**向法院救濟

## 學生：382 → 684 → 784
- **382**：**退學**等足以改變學生身分的處分 → 可以救濟
- **684**：**大學生**對未改變身分、但侵害受教權或其他基本權的公權力措施 → 也可以救濟
- **784**：**各級學校學生**全面開放 → 侵害權利即可提起行政訴訟

## 📋 釋字速查

> **釋字 243 號**（1989 年）：公務員受**免職**處分，得提起行政訴訟；記大過等未改變公務員身分者，不得提起。→ 建議查閱原文

> **釋字 298 號**（1992 年）：足以改變公務員身分或對於公務員有**重大影響**之懲戒處分，受處分人得請求司法救濟。→ 建議查閱原文

> **釋字 785 號**（2019 年）：公務人員保障法申訴、再申訴程序，並不排除公務人員認其權利受違法侵害或有主張其權利之必要時，原即得按相關措施之性質，依法提起**相應之行政訴訟**請求救濟；是否違法侵害公務人員之權利，則仍應依行政訴訟法或其他相關法律之規定，**個案具體判斷**。→ 建議查閱原文

> **釋字 653 號**（2008 年，補充，老師未唸字號）：羈押法限制受羈押被告不服看守所處遇只能申訴、不得向法院請求救濟，違憲。→ 建議查證

> **釋字 382 號**（1995 年）：學生受**退學**或類此處分，足以改變學生身分並損及受教育之機會，得提起訴願及行政訴訟。

> **釋字 684 號**（2011 年）：**大學**為實現教育目的或維持秩序所為之行政處分或公權力措施，如侵害學生受教權或其他基本權利，即使非屬退學或類此處分，亦得提起行政爭訟。

> **釋字 784 號**（2019 年）：**各級學校**學生認其權利因學校之教育或管理等公權力措施而遭受侵害時，得提起行政爭訟，無特別限制之必要。

> 字號校正：字幕「4至243」即釋字 243；字幕「手機的被告」「開機壓庭」應為「羈押的被告」「羈押」的辨識錯誤。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公務員受記大過，依 243 可否行政訴訟？」 | **不可**（未改變身分）；243 只開放免職 |
| 「公務員申訴、再申訴後可否行政訴訟？」 | **可以**（785），依措施性質提起 |
| 「大學生對非退學的措施可否救濟？」 | **可以**（684），須侵害受教權或其他基本權 |
| 「國高中生對學校管理措施可否救濟？」 | **可以**（784，全面開放） |
| 「382 開放的範圍？」 | 退學或類此**改變學生身分**之處分 |
| 「記憶法？」 | 學生：684 大學生 → 784 各級學校（都是「84」） |

## 一、演進總表

| 對象 | 起點 | 中間 | 全面突破 |
|---|---|---|---|
| 公務員 | 243：免職可訴 | 298：重大影響可訴 | 785：申訴再申訴後亦可行政訴訟 |
| 學生 | 382：退學可訴 | 684：大學生全面 | 784：各級學校全面 |
| 受羈押被告 | 只能申訴 | — | 可向法院救濟（653，補充） |

## 二、公務員的兩條救濟路線

```
公務員不服
   ├── 行政處分（影響身分、權利）→ 復審 → 行政訴訟
   └── 管理措施、工作條件 → 申訴 → 再申訴 → （785 前：到此為止）
                                          → （785 後：可依性質提行政訴訟）
```

- 785 之後：能不能**提起**是一回事，法院**是否受理**、有無違法侵害是另一回事。
