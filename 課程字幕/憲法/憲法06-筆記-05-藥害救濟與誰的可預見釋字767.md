# 憲法06 筆記：藥害救濟與誰的可預見（釋字767）

## 事實：
- 聲請人 2007 年因重病在臺大醫院治療，用藥後病情穩定，但半年後雙耳失聰，確定是藥物副作用
- 申請藥害救濟被拒：藥害救濟法 §13 ⑨「**常見且可預期**之藥物不良反應」不得申請
- 主管機關標準：發生率約 **1% 以上**即屬常見；該藥致聽力喪失的發生率高於此

## 爭點與結論：
- 聲請人主張：一般人不知道「常見」是 1% → 不可預見 → 違反法律明確性
- 大法官：**不違反**法律明確性；病人可透過**醫師告知、藥袋標示、藥物仿單**合理預見
- 藥害救濟是社會政策立法，涉及國家資源分配 → **寬鬆審查**

## 以誰的角度判斷可預見：
- 多數意見：不需要病人自己看得懂，透過醫師、仿單可預見即可
- 黃昭元：專業領域不可能以一般人民的知識判斷；詹森林等：應以受害人角度判斷

## 📋 釋字速查

> **釋字 767 號**（2018 年 7 月 27 日）：藥害救濟法 §13 ⑨ 所稱「常見且可預期之藥物不良反應」，其意義非難以理解，且為受規範者所得預見，並可經由司法審查加以確認，**不違反法律明確性原則**；亦不違反比例原則，與憲法保障生存權、健康權之意旨無違。

> 理由書重點（老師朗讀）：一般受規範者及病人與家屬，縱無法完全確知用藥是否符合藥害救濟要件，唯因可合理期待透過**醫師之告知義務、藥袋上之標示或藥物仿單之記載**，就用藥之不良反應之可預期發生機會及請求藥害救濟之可能性，有一定程度之預見。藥害救濟屬**社會政策立法**，涉及國家資源分配，立法者有較大裁量空間，採**較寬鬆**之審查。

> 補充：本案藥物為 Amikacin（抗生素）；委員會引用國外文獻，耳毒性發生率約 7%～23%（老師口述「10%」）。本號解釋有多位大法官提出意見書，詹森林、黃瑞明、蔡明誠等主張「可預期」應以受害人角度判斷。

> 字號校正：字幕「4767」即**釋字 767**；字幕「張森林」應為**詹森林**大法官。

## 一、藥害救濟制度的目的

```
吃藥一定有副作用風險
        │
若每次副作用都告醫師、藥廠
        │
→ 沒人敢引進新藥 → 藥商賺不到錢、人民吃不到新藥（雙輸）
        │
所以：藥商提撥 → 藥害救濟基金會 → 符合要件直接給付救濟金
```

- 處理的是「**大家都沒有錯，但結果發生了**」的情形；若有人可歸責，就有過失問題，走訴訟有正當性。
- 老師補充：醫師因被告入罪的機率很低，但被告本身就很煩；制度要降低風險與成本。

## 二、§13 ⑨ 的判斷

```
不良反應發生率
├── 約 1% 以上 → 常見且可預期 → 不得申請
└── 低於 1% → 不常見、不可預期 → 可申請
```

- 聲請人律師的論點：「常見且可預期」看得懂字，但一般人不知道門檻是 1% → 無法預見。
- 核心掙扎：讓病人知道副作用，是**法律**的責任，還是**醫師、藥師**的責任？若是後者，法律本身未必有問題。

## 三、誰的可預見

| 立場 | 內容 |
|---|---|
| 多數意見 | 受規範者得預見，不需病人自己看懂；醫師看得懂、能告知即可 |
| 黃昭元（意見書） | 向來以一般人民為標準，但許多專業領域需特定專業知識才能理解，不能只依一般人民的知識判斷 |
| 詹森林等（意見書） | 應以受害人（一般人民）的角度判斷 |

- 老師贊同黃昭元：法律沒有義務讓所有人民一看就懂；遇到法律問題該做的是找律師。
- 法律用語與日常用語的落差：「通謀虛偽意思表示」的「虛偽」不是罵人，一般人卻可能讀成罵人。
- 寬鬆審查的另一層理由：立法者比大法官更接近社會真實的聲音。
