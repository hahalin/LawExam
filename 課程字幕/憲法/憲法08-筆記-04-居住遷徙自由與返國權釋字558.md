# 憲法08 筆記：居住遷徙自由與返國權（釋字558）

## 居住自由為什麼很少討論：
- 法律限制「家」，多半限制的是**所有權** → 放在**財產權**（§15）處理，簡單
- 居住自由若跟所有權脫鉤（租屋、遊民），就變成**給付請求權**：國家要讓人有地方住 → 很難用法律落實
- 大法官多半迴避；適足居住權、日照權只在意見書中出現

## 遷徙自由的三號解釋：
- 釋字 345：限制欠稅人出境 → **合憲**
- 釋字 443：役男出境限制以**未經法律授權**的命令為之 → 違憲（層級化法律保留）
- 釋字 558：國安法規定人民**入出境**須經許可、違者處刑 → 對在臺有戶籍國民違憲

## 558 的背景：黑名單與黃文雄
- 戒嚴時期海外從事民主、臺獨運動者被列**黑名單**，不許入境，未經許可入境還要處刑
- 黃文雄 1970 年在美國刺殺蔣經國未遂，流亡海外；民主化後回臺，被以違反國安法起訴
- 審理的**臺灣高等法院**法官認為荒謬 → 法官聲請解釋

## 📖 法條原文速查

> **憲法 §10**　人民有**居住及遷徙**之自由。

> **憲法 §15**　人民之生存權、工作權及**財產權**，應予保障。→ 住處是自有房屋時，多以財產權處理

> **國家安全法 §3 I**（81 年修正後，558 審查標的）　人民入出境，應向內政部警政署入出境管理局申請**許可**。→ 未經許可入出境者依同法 §6 處刑；文字建議查閱解釋原文

---

## 📋 釋字速查

> **釋字 345 號**（1994 年）：限制欠稅人或欠稅營利事業負責人出境實施辦法，係依稅捐稽徵法授權訂定，為確保稅收、增進公共利益所必要，**與憲法尚無牴觸**。→ 原文建議查閱司法院網站

> **釋字 443 號**（1997 年）：役男出境處理辦法限制役男出境，涉及**遷徙自由**，未經法律授權而以命令限制，違反法律保留。（層級化法律保留，見憲法05-筆記-07）

> **釋字 558 號**（2003 年 4 月 18 日）：
> - 憲法 §10 之**居住遷徙自由**，包括入出國境之權利。人民為構成國家要素之一，**在臺灣地區設有住所而有戶籍之國民**得隨時返回本國，**無待許可**。
> - 入出國境之權利並非不得限制，但須符合 §23 比例原則，並以法律定之。
> - 動員戡亂時期國家安全法 §3 II ②，適用於動員戡亂時期，與憲法尚無牴觸。
> - 81 年修正後國安法 §3 I 未區分國民是否於臺灣地區設有住所而有戶籍，一律非經許可不得入境，並對未經許可入境者，依 §6 予以**刑罰**，違反比例原則，侵害國民得隨時返回本國之自由。
> - 與本解釋意旨不符部分，自立法機關基於裁量權限就入出境所制定之法律相關規定施行時起，**不予適用**。
> - 聲請人：**臺灣高等法院**刑事庭法官，於黃文雄違反國家安全法案件審理中聲請。

> 字號校正：字幕「四至三四五」即**釋字 345**；「四四五八」「4458」即**釋字 558**（老師說約 2003 年，經核對為 92 年 4 月 18 日）。字幕「4732號解釋羅祥報導在4709號講的四族居住權」推測為：**釋字 709、732** 涉及迫遷與居住自由，**羅昌發**大法官意見書論及「**適足居住權**」；「釋字773號還二號解釋，黃虹霞大法官意見書」提到日照權，所指字號無法確認——以上出處建議查閱司法院網站。

|---------|---------|
| 「入出國境之權利受何條保障？」 | **憲法 §10 居住遷徙自由**（釋字 558） |

| 「限制欠稅人出境是否違憲？」 | **合憲**（釋字 345） |
| 「役男出境限制違憲的理由？」 | **未經法律授權**、以命令限制遷徙自由（釋字 443） |
| 「拆遷自有房屋，主要涉及何種基本權？」 | 多以**財產權**（§15）處理；居住自由較少單獨討論 |

## 一、居住自由：防禦權還是給付請求權

| | 有所有權 | 沒有所有權（租屋、遊民） |
|---|---|---|
| 基本權 | 財產權（§15） | 居住自由（§10） |
| 性質 | **防禦權**：法律限制我的房子 → 我挑戰 | 接近**給付請求權**：國家應讓我有地方住 |
| 落實 | 容易 | 困難（需要社會住宅等配套；抽不到） |

- 老師的體會：大學搬出合租處、住進只有 2.5 張雙人床大的小套房，才感受到「有一個自己的小天地」——這就是居住自由想保障的東西，跟有沒有所有權無關。
- 例：臺北市議員曾主張對龍山寺遊民「噴水」驅離——老師認為這不是解決問題，只是把人趕到下一個地方。
- 日照權：日本等國把日照視為重要權利；房間沒有陽光算不算不符居住自由？討論起來會非常複雜，大法官多迴避。

## 二、遷徙自由：出境與入境

```
遷徙自由（§10）
├── 出境
│   ├── 欠稅限制出境 → 合憲（345）
│   └── 役男出境限制 → 未經法律授權，違憲（443）
└── 入境（返國）
      └── 有戶籍國民 → 無待許可（558）
```

- 老師：558 沒有直指核心——它不是說「出入境要許可本身就奇怪」，而是以「**未區分有無戶籍**」為由宣告違憲，是比較迂迴的解釋。
- 老師：這麼威權的規定，到 2000 年後才被宣告違憲，自由民主並不是一直理所當然。

## 三、558 的故事

| 時間 | 事件 |
|---|---|
| 1960 | 雷震案（《自由中國》批評蔣介石，被捕）→ 民主派感到無望 |
| 1970 | 黃文雄在紐約刺殺蔣經國未遂，被捕時高喊「Let me stand up like a Taiwanese!」（滅火器〈Stand Up Like a Taiwanese〉即取自這句），後棄保流亡 |
| 戒嚴時期 | 海外民主、臺獨人士列入黑名單，不許入境；未經許可入境處刑 |
| 民主化後 | 黃文雄回臺召開記者會 → 被以違反國安法起訴 |
| 2003 | 高等法院法官聲請 → 釋字 558 宣告違憲 |

- 老師：不鼓勵任何刺殺，民主社會中絕對不對；但可以回想那個時代為何有人做出這種決定。黃文雄回臺後持續從事人權運動。
