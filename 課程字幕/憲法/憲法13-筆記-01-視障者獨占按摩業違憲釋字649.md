# 憲法13 筆記：視障者獨占按摩業違憲（釋字649）

## 案例：
- 舊身心障礙者保護法 §37 I：**非**視覺障礙者，**不得**從事按摩業 → 違者處罰
- 理髮店員工幫客人洗頭時捏肩、敲背，被社會局依 §37 I 裁罰；行政訴訟敗訴 → 聲請解釋

## 屬於哪一階：客觀條件
- 對**非視障者**而言，不論怎麼努力都不能從事按摩業 → **客觀**條件限制 → 從嚴審查

## 649 的結論：違憲
- 按摩業並非只有視障者才能從事；受相當訓練、經鑑定合格者，都應有從事資格
- 只准視障者從事，未能形成**多元競爭**環境；所欲保障的視障者工作權，與非視障者的就業利益**顯不相當**
- 少數以**客觀限制**宣告違憲的解釋

## 本案也是基本權衝突：
- 一邊保障**視障者**的工作權，一邊限制**非視障者**的工作權 → 比較兩者損益
- 若有其他方法能幫助視障者，就不必以全面排除非視障者為手段

## 📖 法條原文速查

> **舊身心障礙者保護法 §37 I 前段**　非本法所稱視覺障礙者，不得從事按摩業。→ 原文建議查閱司法院解釋原文；現行法名稱為身心障礙者權益保障法

> **憲法 §15**　人民之生存權、**工作權**及財產權，應予保障。

> **憲法 §7**　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律**平等**。

---

## 📋 釋字速查

> **釋字 649 號**（2008 年）：舊身心障礙者保護法 §37 I 前段禁止非視障者從事按摩業，係對非視障者職業選擇自由的**客觀條件**限制；按摩業並非僅得由視障者從事，受相當訓練並經鑑定合格者亦應有從事資格。將按摩業僅允准視障者從事，使有意投身按摩工作的非視障者轉行或失業，未能形成多元競爭環境供消費者選擇，所欲保障之利益與所限制之利益**顯不相當**，與憲法 §7 平等權、§15 工作權之意旨不符，**違憲**，定期失效。→ 解釋文字與失效期限建議查閱司法院網站

> 字號校正：字幕「469號解釋」「69號解釋」即**釋字 649**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「禁止非視障者從事按摩業，屬三階理論哪一階？」 | **客觀**條件（非視障者無法靠自身努力取得） |
| 「649 結論？」 | **違憲**：非視障者經訓練鑑定合格也應可從事 |
| 「649 涉及哪些基本權？」 | **工作權**（§15）、**平等權**（§7） |
| 「本案的結構特色？」 | **基本權衝突**：保障視障者工作權 vs 限制非視障者工作權 |
| 「客觀限制一定違憲？」 | 不一定；但審查最嚴格，649 是少數以客觀限制宣告違憲之例 |

## 一、649 的審查路徑

```
限制：非視障者不得從事按摩業
   │
   ├── 對誰？非視障者 → 怎麼努力都不能做 → 客觀條件
   ├── 審查基準：從嚴
   ├── 目的：保障視障者工作機會（視障者可選職業遠少於一般人）
   └── 手段：全面排除非視障者
          → 打擊過廣、有其他手段 → 損益顯不相當 → 違憲
```

## 二、老師的評論

- 這號解釋的重點不在「要不要保護視障者」，而在「看得見的人全都不能從事按摩業，合不合理」。
- 開放後的現實：合法的視障按摩師須考照，非法業者不用 → 成本差距反而打擊視障按摩業者。
- 老師仍認為結論正確：應以**其他更積極的措施**幫助視障者，而不是透過打擊非視障者來幫助視障者。
