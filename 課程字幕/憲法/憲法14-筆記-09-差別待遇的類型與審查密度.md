# 憲法14 筆記：差別待遇的類型與審查密度

## 非優惠性差別待遇：依分類標準決定審查密度
- **嫌疑分類**（可疑分類）：以**天生不可改變**的特徵分類（種族）→ 正當性低，**提高**審查基準
- 性別：老師認為屬**準嫌疑**分類——男女確有生理差異（懷孕、月經），合理差別待遇較多（例：生理假）
- **權利性質**：自由權（人身、言論）較難容許差別待遇；經濟性權利（財產權）較容易
- **一次性政策**：如 921 地震依戶籍、全倒半倒給不同補助 → 較具合理性，從寬
- **憲法委託**：增修 §11 授權以法律規範兩岸人民關係 → 立法者較可做差別待遇，但仍要看事項本質

## 優惠性差別待遇：多半尊重
- 抓出弱勢族群給予較好對待：**原住民升學優惠**、低收入戶
- 立法要綜合人口、收入、社會資本、文化脈絡 → 大法官多**尊重**
- 例外：過度保障而**不合理擠壓主流族群**時，才適度提高審查基準
- 最後仍要審查手段與目的的關聯性（有學者認為此處就是**比例原則**）

## 📖 法條原文速查

> **憲法 §7**　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律平等。

> **憲法增修條文 §11**（兩岸關係）　自由地區與大陸地區間人民權利義務關係及其他事務之處理，得以**法律**為特別之規定。→ 字幕老師說「憲法第 11 條」，應為增修條文 §11

> **憲法增修條文 §10 XII**　國家應依民族意願，保障原住民族之地位及政治參與，並對其教育文化……予以保障扶助並促其發展。→ 優惠性差別待遇的憲法依據之一

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「以種族等天生不可改變特徵分類，審查密度？」 | **嚴格**（嫌疑分類） |
| 「性別分類？」 | 準嫌疑分類，審查較嚴，但生理差異可構成合理理由 |
| 「涉及自由權 vs 經濟權的差別待遇？」 | 自由權**較嚴**、經濟權**較寬** |
| 「一次性政策（如災後補助）的差別待遇？」 | 較**寬鬆**、尊重 |
| 「兩岸人民的差別待遇？」 | 增修 §11 **憲法委託** → 較寬，但仍看事項本質 |
| 「原住民升學優惠屬於？審查態度？」 | **優惠性差別待遇**，原則**尊重** |

## 一、審查密度的方向

```
審查從嚴 ◀──────────────────────────────▶ 審查從寬
嫌疑分類（種族）                         一次性政策
準嫌疑（性別）                           憲法委託（增修 §11）
涉及自由權                               涉及經濟性權利
                                         優惠性差別待遇（原則）
```

## 二、嫌疑分類：天生不可改變

- 美國法的標準：美國過去的黑白隔離（公車、廁所、學校）→ 很難找到正當理由。
- 我國早期的例子：老師舉公務人員考試依**籍貫**分配名額（以全中國各省為基準），在臺灣造成本省人名額相對較少的排擠效果。

## 三、優惠性差別待遇

| 正面理由 | 爭議 |
|---|---|
| 起跑點本來就不同（教育資本、文化資本、醫療距離） | 保障一個名額，可能排擠一般生第 100 名 |
| 統計上原住民仍屬弱勢 | 「我認識的原住民同學很優秀」→ 老師：這是**倖存者偏差** |

- 立法者有較大形成空間；除非過度擠壓主流族群，才提高審查。
