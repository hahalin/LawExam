# 憲法17 筆記：偵查中卷證不得調閱（釋字729）

## 背景：
- 2013 年政爭期間，特偵組監聽及於立法院電話；立法院司法及法制委員會向最高法院檢察署**調閱偵查卷證**，遭拒
- 最高法院檢察署經法務部層轉行政院聲請解釋

## 釋字 729 的結論：
- **偵查中**的案件 → 立法院**不得調閱**（權力分立、檢察機關獨立行使職權、偵查不公開）
- 偵查終結，**不起訴處分確定**或**未經起訴而以其他方式結案**（如行政簽結）→ **得調閱**，但有條件
- 若調閱有**妨害另案偵查**之虞 → 檢察機關得延至另案偵查終結後再提供

## 為什麼不起訴的案件還能調閱：
- **法律責任**與**政治責任**不同：沒有違法，不代表沒有可追究的政治責任

> 來源：憲法17 課程字幕 01:10:46 ~ 01:16:41（講義第 73～74 頁）

## 📋 釋字速查

> **釋字 729 號**（104 年 5 月 1 日；聲請人：最高法院檢察署）解釋文要旨：
> - 檢察機關代表國家進行犯罪之偵查與追訴，基於權力分立與制衡原則，且為保障檢察機關獨立行使職權，對於**偵查中之案件**，立法院自**不得**向其調閱相關卷證。
> - 立法院向檢察機關調閱已偵查終結而**不起訴處分確定**或**未經起訴而以其他方式結案**之案件卷證，須基於**目的與範圍均屬明確之特定議案**，並與其行使憲法上職權有**重大關聯**，且非屬法律所禁止者為限。
> - 如因調閱而有**妨害另案偵查**之虞，檢察機關得延至該另案偵查終結後，再行提供調閱之卷證資料。
> - 調閱偵查卷證之文件**原本或影本**者，應經立法院**院會**決議；要求提供參考資料者，由**院會或其委員會**決議為之。
> - 因調閱卷證而知悉之資訊，其使用應限於行使憲法上職權所必要，並注意維護關係人之權益（名譽、隱私、營業秘密等）。釋字 325 應予**補充**。

> 字號校正：字幕「729 的主角是柯建銘」係指背景事件涉及之立委；聲請人是**最高法院檢察署**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「立法院得否調閱偵查中案件卷證？」 | **不得**（釋字 729） |
| 「不起訴處分確定的案件卷證可否調閱？」 | **得**，須目的範圍明確的特定議案、與職權有重大關聯、非法律所禁止 |
| 「調閱可能妨害另案偵查時？」 | 檢察機關得**延至另案偵查終結後**提供 |
| 「調閱卷證原本須經何種決議？」 | **院會**決議；參考資料由院會或委員會決議 |
| 「729 與 325 的關係？」 | 729 **補充** 325 |
| 「不起訴就代表沒有責任？」 | 沒有**法律**責任，仍可能有**政治**責任 |

---

## 一、可否調閱的判斷流程

```
立法院要調閱檢察機關卷證
        │
        ├─ 偵查中 ────────────────→ 不得調閱
        │
        └─ 偵查終結
             ├─ 起訴 → 進入法院審判（另受審判獨立保障）
             └─ 不起訴確定／未經起訴而結案（行政簽結）
                  ├─ 特定議案、目的範圍明確、與職權重大關聯、非法律禁止 → 得調閱
                  └─ 有相牽連案件仍在偵查 → 延至該案偵查終結後提供
```

## 二、相牽連案件

- A 案不起訴了，但相牽連的 B、C、D 案還在偵查 → 先給 A 案卷證，可能讓偵查不公開的內容提前公開 → 等相關案件都結束再提供。

## 三、法律責任與政治責任

| | 法律責任 | 政治責任 |
|---|---|---|
| 問什麼 | 有沒有違法 | 做法是否恰當 |
| 追究方式 | 偵查、審判 | 質詢、調閱、輿論、要求下臺 |
| 例 | 不起訴 → 沒有刑事責任 | 仍可能有值得在政治上追究之處 |
