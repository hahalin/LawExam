# 憲法02 筆記：審查範圍擴張與重要關聯性（釋字739）

## 規則：
- 原則：審查標的＝聲請人聲請、且為確定終局裁判所適用的法規範
- 例外：與受理部分**具有重要關聯性**的規定，即使**未經聲請**、甚至**不是終局裁判所適用**，大法官也可以**一併納入審查範圍**（老師稱「重要性理論」）

## 理由：
- 單看 A 條可能合憲，A＋B 一起看才看得出違憲
- 一個法條要碰到聲請、走到憲法法庭的機率很低，受理了就要有效處理
- 詹森林、湯德宗大法官：受理後為有效進行規範控制，審查範圍**不受聲請人主張拘束**

## 考試怎麼用：
- 題目說聲請 A，但你讀完發現 B 也有問題 → 扮演大法官時多寫三行，說明為什麼把 B 拉進來審查

> 來源：憲法02 課程字幕 01:29:17 ~ 01:39:46（講義第 18～19 頁）

## 📖 法條原文速查

> **憲訴 §59 I**　人民於其憲法上所保障之權利遭受不法侵害，經依法定程序用盡審級救濟程序，對於所受不利確定終局裁判，或該裁判及**其所適用之法規範**，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> 釋字 739 審查的是**獎勵土地所有權人辦理市地重劃辦法**（平均地權條例授權訂定）→ 條文內容與本主題無關，不列

---

## 📋 釋字速查

> **釋字 739 理由書**（老師逐字唸的段落）：獎勵重劃辦法 §26 I 規定，為確定終局裁判所適用，但**未經聲請人聲請解釋**；同辦法 §9 第 3 款、第 6 款規定，**未為確定終局裁判所適用，亦未經聲請人聲請解釋**，均與同辦法 §20 規定具有**重要關聯性**，應一併納入審查範圍。→ 條號依字幕，建議查閱原文

> **釋字 753 詹森林大法官部分不同意見書**（引用湯德宗大法官見解）：聲請人只需主張**自己**（而非他人）之基本權遭受侵害，且其主張**並非全然無據**，即滿足要件；一旦決議受理，為有效遂行規範控制，大法官審查範圍即**不受聲請人主張之拘束**。→ 字幕「4至753」＝釋字 753；文字建議查閱講義第 19 頁

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「大法官得否審查聲請人未聲請的規定？」 | **得**，與受理部分具**重要關聯性**者，一併納入審查（釋字 739） |
| 「得否審查非確定終局裁判所適用的規定？」 | **得**，具重要關聯性即可（釋字 739：§9 未適用、未聲請，仍納入） |
| 「聲請人須主張何人的基本權受侵害？」 | **自己**的，不是他人的 |
| 「聲請人主張要到什麼程度才受理？」 | **並非全然無據**即可（雙重否定＝「還說得過去」，不是「講得很好」） |
| 「受理後審查範圍受聲請人主張拘束？」 | **不受拘束**（為有效規範控制） |
| 「重要關聯性理論會不會讓大法官濫權？」 | 老師：不至於，大法官怕被批評、內部意見多元，自有制衡 |

## 一、四格：哪些規定可以被審查

| | 聲請人有聲請 | 聲請人沒聲請 |
|---|---|---|
| **終局裁判有適用** | 當然可以（§59 I） | 具重要關聯性 → **可以**（739：§26 I） |
| **終局裁判沒適用** | 本堂未講 | 具重要關聯性 → **可以**（739：§9 ③⑥） |

## 二、圖解

```
終局裁判提到 A、B、C 三條
聲請人只聲請 A
        ↓
大法官受理 A
        ↓ 再問：只審 A 夠嗎？
A 單獨看合憲，A＋B 一起看可能違憲
        ↓
B（終局裁判適用、未聲請）→ 一併審查
D、E（終局裁判沒提到、也沒聲請）→ 也可一併審查
```

- 白話：受理門檻要過，但過了之後**審什麼由大法官決定**。

## 三、會不會權力失衡？

- 老師的看法：不至於。大法官多半是一路順遂的學者、法官、檢察官、律師，**很怕被罵**；15 位大法官常有很多種意見，內部就有制衡。
