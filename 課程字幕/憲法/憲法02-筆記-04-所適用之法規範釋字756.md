# 憲法02 筆記：所適用之法規範（釋字756）

## 兩種見解：
- **寬鬆說**（多數意見，大法官多半採）：判決裡**出現**的法條，都算「所適用」，都可以聲請
- **嚴格說**（少數意見，張瓊文、陳碧玉等大法官）：必須是**作為裁判基礎、影響裁判結論**的法條；裁判只是提到，不算適用

## 為什麼要這個要件：
- 法院沒有適用那條法律 → 那條法律沒有影響到聲請人 → 欠缺權利保護必要
- §59 I 的結構：「不利確定終局裁判」**或**「該裁判**及**其所適用之法規範」→ 可攻擊的是裁判、法規範兩大類

## 釋字 756 的困境（受刑人書信被刪）：
- 受刑人想挑戰的是**監獄行刑法**（監獄長官檢閱、刪除書信）
- 但當時受刑人不能起訴 → 行政法院以**無審判權、起訴要件不備**駁回 → 裁判用的是程序法，不是監獄行刑法
- 多數大法官仍受理；陳碧玉、黃璽君、張瓊文大法官認為**欠缺所適用之法規範**，不應受理

## 📖 法條原文速查

> **憲訴 §59 I**　人民於其憲法上所保障之權利遭受不法侵害，經依法定程序用盡審級救濟程序，對於所受不利確定終局裁判，**或**該裁判**及其所適用之法規範**，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> **憲法 §11**（表現自由）　人民有言論、講學、著作及出版之自由。

> **憲法 §12**（秘密通訊自由）　人民有秘密通訊之自由。

> **監獄行刑法**（舊法）關於書信檢閱、刪除的規定，以及行政法院駁回時引用的行政訴訟法、訴願法、行政程序法條文 → 字幕條號不清楚（如「行政程序法 107 條」應是行政訴訟法的起訴要件規定），且監獄行刑法已於 2019 年全文修正，建議查閱講義第 17 頁與最新六法原文

## 📋 釋字速查

> **釋字 755**（2017/12/1）：受刑人不服監獄處分或其他管理措施，逾越達成監獄行刑目的所必要之範圍，而**不法侵害其憲法所保障之基本權且非顯屬輕微**時，舊法不許向法院請求救濟，違反憲法 §16 訴訟權 → **受刑人可以訴訟**。→ 解釋文字建議查閱原文

> **釋字 756**（2017/12/1，聲請人包括邱和順）：監獄長官**檢查**書信是否夾帶違禁品，合憲；**閱讀**書信內容未區分書信種類、未斟酌個案，過度限制秘密通訊自由，違憲；**刪除**書信內容應以法律明確規定要件與程序，並符合比例原則。→ 解釋文字建議查閱原文

> **釋字 756 陳碧玉大法官部分不同意見書**：裁判「所適用」之法令，指已納入裁判結果的涵攝過程、作為裁判基礎者；與裁判結果無關者，縱裁判曾經敘及，仍非所適用之法令。確定終局判決以**無審判權、起訴要件不備**駁回，系爭監獄行刑法規定並非其裁判基礎。

> **張瓊文大法官意見書**（講義引用）：所謂適用，須限於確定終局裁判所依據或據以獲致裁判結論、與所引用法令**有密切關係**者，否則裁判僅提及某一法令，亦非所謂適用。→ 老師先說釋字 760，後自更正為 756；出處建議查閱講義第 16 頁

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「何謂確定終局裁判『所適用』之法規範？」 | 寬鬆說：裁判中出現、引用的法規範；嚴格說：作為**裁判基礎**、與結論有密切關係者 |
| 「大法官多數採哪一說？」 | 多半採**寬鬆說** |
| 「法院沒適用的法律，人民能否聲請？」 | 原則不能：沒有影響到聲請人，欠缺權利保護必要 |
| 「受刑人可否就監獄處分提起訴訟？」 | **可以**（釋字 755 後） |
| 「監獄長官閱讀受刑人書信？」 | 未區分書信種類、一概閱讀 → **違憲**（釋字 756，秘密通訊自由） |
| 「受刑人有沒有言論自由、秘密通訊自由？」 | **有**，只是不完整；問題是限制是否**合理** |
| 「釋字 756 的程序爭議？」 | 終局裁判以**無審判權**駁回，用的是程序法 → 少數意見認為欠缺所適用之法規範 |

## 一、寬鬆說 vs 嚴格說

一份判決裡會出現很多法條（行政訴訟最多：法律、命令、函釋一大堆）。

| | 寬鬆說 | 嚴格說 |
|---|---|---|
| 誰採 | 多數意見 | 張瓊文、陳碧玉等少數意見 |
| 標準 | 判決**提到、引用**的法規範 | 作為**裁判基礎**、決定判決結果的那一兩條 |
| 只是順帶提到的法條 | 可以聲請 | 不可以 |

- 老師建議：練習自己看判決。前面多是事實整理，「**經查**」之後才是法院的判斷；關鍵常常只有三四句。

## 二、釋字 756：受刑人書信被刪

```
邱和順（受刑人）寫信 → 監獄長官以妨害監獄紀律為由要求刪除內容
        ↓ 權利受損（表現自由、秘密通訊自由）
受刑人不能訴願、不能訴訟（當時）
        ↓ 提起行政訴訟
行政法院：無審判權、起訴要件不備 → 駁回
        ↓ 確定
聲請釋憲：要挑戰的是監獄行刑法
        ↓
問題：終局裁判「所適用」的是程序法，不是監獄行刑法
```

| | 多數意見 | 少數意見（陳碧玉、黃璽君、張瓊文） |
|---|---|---|
| 是否受理 | **受理** | 不應受理 |
| 理由 | 聲請人要爭的問題合理，限制法院審判權本身就是要挑戰的事 | 終局裁判沒有適用監獄行刑法，**欠缺所適用之法規範** |

- 老師：這個問題「可大可小」。若嚴格適用，法院**沒有審判權**這件事本身反而永遠無法被挑戰。
- 結局：釋字 755 讓受刑人可以訴訟；釋字 756 讓書信限制變得比較合理。
- 讀大法官解釋要看**不同意見書**：了解為什麼有人不同意，才會真正懂多數意見。

## 三、受刑人的權利（背景）

- 受刑人有言論自由、秘密通訊自由，但**不可能完整**；要討論的是**合理的範圍**。
- 受刑人目前**不能投票**：投票採在籍投票，受刑人不在戶籍地。老師的立場：應該讓受刑人投票（不在籍投票議題，軍人、警消也受影響）。
