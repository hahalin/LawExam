# 憲法07 筆記：逮捕拘禁之機關與審問處罰之法院（釋字588與392）

## 「警察機關」廣義解釋（釋字 588）：
- 不限組織法上穿制服的警察；凡法律賦予得使用干預、取締手段者都算
- 例：行政執行處、移民署、衛生主管機關（疫情隔離）
- 理由：1947 年制憲時沒想到移工、新冠肺炎這些狀況

## 「司法機關」廣義解釋（釋字 392）：
- 不限法官，**檢察官**也是（偵查追訴是為了達成司法任務）→ 檢察官可以逮捕

## 「法院」狹義解釋（釋字 392）：
- 審問處罰的「法院」＝**有審判權之法官**所構成的獨任或合議法院
- 檢察官不是法院 → 不得有**羈押權**；羈押要由法官決定

## 為什麼檢察官不能羈押：
- 法官中立；檢察官代表國家打擊犯罪，本來就有立場
- 羈押名義上不是處罰，實際上就是處罰 → 過去濫押嚴重

## 📖 法條原文速查

> **憲法 §8 I**　……除現行犯之逮捕由法律另定外，非經**司法或警察機關**依法定程序，不得逮捕拘禁。非由**法院**依法定程序，不得審問處罰。……

> **憲法 §8 II**　人民因犯罪嫌疑被逮捕拘禁時，……並至遲於二十四小時內**移送該管法院審問**。……→ 392 用 II 的「法院」對照 I 的「法院」，得出只有法官可以羈押

---

## 📋 釋字速查

> **釋字 588 號**（2005 年）：憲法 §8 I 所稱「**警察機關**」，並非僅指組織法上之形式警察，凡法律規定，以維持社會秩序或增進公共利益為目的，賦予其機關或人員得使用干預、取締之手段者均屬之 → 行政執行處執行拘提管收，不違憲。→ 原文建議查閱司法院網站

> **釋字 392 號**（1995 年）：
> - 「**司法機關**」採廣義：代表國家從事偵查、追訴、執行之**檢察官**，其職權目的在達成司法任務，在此範圍內屬廣義司法之一。
> - 「**法院**」採狹義：指有**審判權之法官**所構成之獨任或合議之法院。
> - 刑事訴訟法賦予檢察官羈押被告之權，與憲法 §8 不符，違憲。→ 原文建議查閱司法院網站

> 字號校正：字幕「4588」即**釋字 588**；「4392」即**釋字 392**。字幕「許中立」即**許宗力**（當時為學者，2003 年起任大法官；憲法08 字幕同一人名對得上其經歷）。老師說 392 是史上第二次憲法法庭言詞辯論，建議查證。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§8 I 的警察機關是否限於形式警察？」 | **否**，廣義（釋字 588）；行政執行處、移民署、衛生機關都可以 |
| 「檢察官是否屬 §8 I 的司法機關？」 | **是**，廣義（釋字 392）→ 可逮捕拘禁 |
| 「檢察官是否屬 §8 I 審問處罰的法院？」 | **否**；法院限**有審判權之法官**（釋字 392） |
| 「檢察官得否羈押被告？」 | **不得**（釋字 392 → 羈押權回歸法官） |
| 「三個機關名詞的解釋寬嚴？」 | 警察機關**廣義**、司法機關**廣義**、法院**狹義** |

## 一、三個名詞，三種解釋

```
憲法 §8 I
├── 逮捕拘禁：「司法或警察機關」
│     ├── 警察機關 → 廣義（588）：衛生局、移民署、行政執行處
│     └── 司法機關 → 廣義（392）：法官、檢察官
│
└── 審問處罰：「法院」
      └── 狹義（392）：有審判權的法官 → 只有法官能羈押
```

- 記法：疫情時大家都被關過，關你的不是警察，是衛生主管機關 → 警察機關廣義解釋。
- 老師：這其實是憲法沒立好，但也不能苛責 1947 年的憲法。

## 二、釋字 392：羈押權回到法官手上

| | 支持檢察官有羈押權 | 主張羈押權交給法官 |
|---|---|---|
| 代表 | 時任法務部長**馬英九** | 立委**張俊雄**等（學者許宗力參與辯論） |
| 結果 | 輸，事後開記者會表示遺憾 | 贏 |

- 現在的羈押流程：檢察官聲請 → 法官決定 → 不押的話檢察官可抗告 → 高等法院。
- 老師：30 年後回頭看，羈押權交給法官才合理；若檢察官可以自己押人，政治爭議案件會更可怕。

### 為什麼檢察官不能羈押

| | 法官 | 檢察官 |
|---|---|---|
| 國家任務 | 審判 | 偵查、追訴、打擊犯罪 |
| 態度 | **中立** | 有立場：認為被告有罪 |
| 若有羈押權 | — | 抓到的人都覺得有問題 → **濫押** |

- 羈押名義上是為了避免妨礙偵查，實際上對被押的人就是處罰。
- §8 I 後段「非由法院不得審問處罰」＋ §8 II「移送該管法院審問」→ 兩個「法院」都指有審判權的法院，**檢察官沒有審判權**，這是文義解釋就能得出的結論。
