# 憲法16 筆記：內閣制、總統制、半總統制與我國體制的轉變

## 三種憲政體制看「人民選出什麼」：
- **內閣制**（英國、日本）：人民只選出**國會**，國會產出行政權（首相）→ 行政、立法**合一**、國會中心主義；閣員多由國會議員兼任
- **總統制**（美國）：人民分別選出總統與國會 → 行政、立法**完全分立**，各自對人民負責；沒有質詢，只有國會調查與聽證
- **半總統制**（雙首長制）：人民選總統、選國會，行政院長由總統任命並對立法院負責 → 行政權可替換，彈性較高

## 我國：從偏內閣制走向半總統制
- 憲法本文 §53：行政院為**國家最高行政機關**；總統由國大選出、行政院長經立法院同意
- 修憲後：國大廢除、總統**直選**、行政院長**無須立法院同意** → 規範與現實衝突，實際上總統才是國家領導者
- 釋字 1：立法委員不得兼任官吏 → 我國閣員多為學者、專業人士，與內閣制不同

## 📖 法條原文速查

> **憲法 §53**　行政院為國家**最高行政機關**。

> **憲法 §55 I**（本文，已凍結）　行政院院長由總統提名，經**立法院同意**任命之。→ 增修 §3 I 改為總統任命，不須立法院同意

> **增修 §3 I**　行政院院長由**總統任命**之。行政院院長辭職或出缺時，在總統未任命行政院院長前，由行政院副院長暫行代理。憲法第五十五條之規定，停止適用。

> **增修 §2 I**　總統、副總統由中華民國自由地區全體人民**直接選舉**之，自中華民國八十五年第九任總統、副總統選舉實施。→ 建議查閱最新六法原文

> **憲法 §75**　立法委員不得兼任官吏。

## 📋 釋字速查

> **釋字 1 號**（1949 年）：立法委員依憲法第 75 條之規定，不得兼任官吏；如願就任官吏，即應辭去立法委員。

> 字號校正：字幕「四字一號」即釋字 1。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「內閣制的特色？」 | 行政、立法**合一**；首相由國會產生；國會中心主義 |
| 「總統制的特色？」 | 行政、立法**完全分立**；各自對人民負責；無質詢制度 |
| 「憲法本文規定的國家最高行政機關？」 | **行政院**（§53） |
| 「現行行政院長之任命是否須立法院同意？」 | **不須**，由總統任命（增修 §3 I） |
| 「立法委員得否兼任官吏？」 | **不得**（§75、釋字 1） |

## 一、三種制度的圖像

```
內閣制：  人民 ──選── 國會 ──產生── 首相、內閣（國會議員兼任）
總統制：  人民 ──選── 總統（行政）
          人民 ──選── 國會（立法）       兩邊完全分立
半總統制：人民 ──選── 總統 ──任命── 行政院長 ──負責── 立法院
          人民 ──選── 立法院
```

| | 內閣制 | 總統制 | 半總統制（我國） |
|---|---|---|---|
| 人民選出 | 國會 | 總統＋國會 | 總統＋國會 |
| 行政首長來源 | 國會多數產生 | 人民直選 | 總統任命 |
| 首長下臺 | 國會重選，不必全民改選 | 任期制 | 總統可替換行政院長 |
| 閣員 | 國會議員兼任 | 不得兼任 | 不得兼任（§75） |

- 日本例：石破茂辭職後，自民黨先黨內選出總裁，再由國會選出首相（高市早苗），人民不必重新投票。
- 我國：總統缺位由副總統繼任，不是由立法院重選。
- 美國政黨是**軟性政黨**，黨內派系多，總統要逐一說服議員；我國較偏**剛性政黨**。老師認為政黨內部有派系競爭是健康的。

## 二、半總統制的好處

- 總統、立委一選就是四年；行政院長做不好可以替換 → **滾動式調整**、高度彈性。
- 許多新興民主國家採半總統制。老師認為我國人民已習慣一人一票選總統，改採內閣制在情感上很難。

## 三、我國體制的轉變

```
憲法本文：
  人民 → 國大 → 選總統
  人民 → 地方議會 → 選監察委員
  人民 → 立法院
  總統提名行政院長 → 立法院同意
  → 行政院長看起來是行政權的老大（偏內閣制）

修憲後：
  國大廢除；監察委員改由總統提名、立法院同意
  人民直選總統
  總統任命行政院長，不須立法院同意
  → 半總統制，總統是實質領導者
```

- 憲法本文因戒嚴、動員戡亂，幾乎沒有完整施行過。
