# 憲法13 筆記：隧道穿越土地與請求徵收地上權（釋字747）

## 案例：指南宮與北二高隧道
- 指南宮買地，原規劃蓋靈骨塔、停車場
- 政府在該土地**地下**挖隧道，作為北二高工程 → 土地價值受損、用途受限
- 指南宮要求國道局**徵收**（地上權）並補償，遭拒 → 聲請解釋

## 和 400 的差別：
- 400 處理的是**所有權**（地面整塊被當道路用）
- 747 處理的是土地的**上空或地下**被利用 → 對應**地上權**

## 大法官的論證層次：
- ① 什麼是特別犧牲：財產權損失（所有權喪失、使用收益減損）逾越社會責任應忍受範圍 → 國家應合理補償
- ② 穿越土地上空或地下，也可能構成特別犧牲
- ③ 本案確實達到特別犧牲
- ④ 但沒有補償，法律也沒讓人民**主動請求徵收** → 違憲

## 747 比 400 有牙齒：
- 有關機關應於**一年內**修正土地徵收條例
- 逾期未修法 → 土地所有權人得**直接依本解釋**請求需用土地人申請徵收地上權
- 性質上是**立法不作為**：給期限、給替代的請求權基礎，立法院才有壓力

## 📖 法條原文速查

> **憲法 §15**　人民之生存權、工作權及**財產權**，應予保障。

> **土地徵收條例 §57 I**　需用土地人因興辦第三條規定之事業，需穿越私有土地之**上空或地下**，得就需用之空間範圍協議取得**地上權**，協議不成時，準用徵收規定取得地上權。但應擇其損害最少之處所及方法為之。→ 原文建議查閱最新六法原文（747 後已修法）

> **土地徵收條例 §11**　需用土地人申請徵收土地或土地改良物前，應先與所有人**協議價購**或以其他方式取得。→ 原文建議查閱最新六法原文

## 📋 釋字速查

> **釋字 747 號**（2017 年）：需用土地人因興辦土地徵收條例 §3 之事業，穿越私有土地之上空或地下，致**逾越所有權人社會責任所應忍受範圍**，形成個人之**特別犧牲**，而不依徵收規定向主管機關申請徵收地上權者，土地所有權人**得請求**需用土地人向主管機關申請徵收地上權。土地徵收條例 §11 及 §57 I 未就此有所規定，與上開意旨不符。有關機關應自解釋公布之日起**一年內**修正土地徵收條例；逾期未完成修法，土地所有權人得依本解釋意旨請求。→ 原文與日期建議查閱司法院網站

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「政府在私人土地地下挖隧道，未補償，侵害何權？」 | **財產權**（特別犧牲未補償） |
| 「747 的救濟方式？」 | 土地所有權人得**請求**需用土地人申請**徵收地上權** |
| 「747 是否定期要求修法？」 | **是**，一年內修正土地徵收條例 |
| 「逾期未修法？」 | 得**直接依解釋意旨**請求 |
| 「400 與 747 處理的權利？」 | 400：所有權（既成道路）；747：上空／地下（地上權） |
| 「為何 747 有效、400 效果打折？」 | 747 給**期限**與**替代請求權**；400 只說應逐年辦理 |

## 一、四層論證

```
① 特別犧牲的定義：逾越社會責任應忍受範圍 → 應補償
② 上空、地下被穿越 → 也可能構成特別犧牲
③ 本案（隧道穿越）→ 構成特別犧牲
④ 法律未讓人民請求徵收、也沒有補償 → 違憲
        ↓
   一年內修法；逾期 → 直接依解釋請求
```

## 二、立法作為與立法不作為的處理

| | 立法作為（法律規定違憲） | 立法不作為（漏未規定） |
|---|---|---|
| 大法官的處理 | 宣告失效 | 定期要求修法，必要時給替代的請求權基礎 |
| 例 | — | 747、748 |

- 老師：如果 748 沒有給立法院期限壓力，立法院不會修法 → 747 同樣道理。
