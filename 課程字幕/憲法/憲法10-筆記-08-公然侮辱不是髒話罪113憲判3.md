# 憲法10 筆記：公然侮辱不是髒話罪（113憲判3）

## 一句話記：
- **公然侮辱不是髒話罪**：不是罵髒話就有罪
- 113 憲判 3 對刑法 §309 I 作**合憲性解釋**（合憲，但限縮適用）

## 要區分情緒與侮辱：
- 平靜狀態下突然罵人「白痴」→ 成立機會較高
- 機車擦撞當下脫口「你會不會開車啊」→ 多半是**情緒**，成立機會較低
- 要看是**情緒性**發言、**侮辱性**發言，還是兩者兼有

## 老師說最重要的一段（講義第 43 頁）：
- 被害人**自行引發爭端或自願加入爭端**，表意人以負面語言回擊 → 一般人常見反應，應**從寬**認定
- 為尋求網路聲量而表意的自媒體、大眾媒體人員受到負面評價 → **自招風險**，應自行承擔
- 反之，具**言論市場優勢地位**的網紅、自媒體經營者或公眾人物，透過網路或傳媒故意公開羞辱他人 → 應負**較大**責任

## 📋 憲判速查

> **113 年憲判字第 3 號**（2024 年）：刑法 §309 I 規定所處罰之公然侮辱行為，係指依**個案之表意脈絡**，表意人故意發表公然貶損他人名譽之言論，已**逾越一般人可合理忍受之範圍**；經權衡該言論對他人名譽權之影響，及該言論依其表意脈絡是否有益於公共事務之思辯，或屬文學、藝術之表現形式，或具學術、專業領域等正面價值，於個案足認他人之名譽權應優先於表意人之言論自由而受保障者。於此範圍內，與憲法保障言論自由之意旨尚屬無違。→ 主文文字依記憶整理，建議查閱憲法法庭網站原文

> **判決理由（講義第 43 頁，老師畫線）**：例如被害人自行引發爭端或自願加入爭端，致表意人以負面語言予以回擊，尚屬一般人之常見反應，仍應從寬容忍此等回應言論。又如被害人係為尋求網路聲量而表意之自媒體或大眾媒體人員，或屬媒體節目活動參與者，其受眾之負面評價，可認係自招風險而應自行承擔。反之，具言論市場優勢地位之網紅、自媒體經營者或公眾人物，透過網路或傳媒故意公開羞辱他人，應負較大責任。→ 文字依字幕整理，建議查閱判決原文

> 字號校正：字幕「13憲判3」「113年憲判第三號」即 **113 年憲判字第 3 號**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「刑法 §309 I 公然侮辱罪違憲嗎？」 | **合憲**，但經**合憲性解釋**限縮（113 憲判 3） |
| 「罵髒話一定成立公然侮辱？」 | **不一定**，依表意脈絡判斷 |
| 「被害人先挑起爭端，表意人回罵？」 | 一般人常見反應，應**從寬**認定 |
| 「追求聲量的自媒體受到負評？」 | **自招風險**，應自行承擔 |
| 「網紅、公眾人物公開羞辱他人？」 | 具言論市場**優勢地位**，負**較大**責任 |
| 「誹謗與公然侮辱的區別？」 | 誹謗涉**可證明真假的事實**；公然侮辱是不涉事實的貶抑 |

## 一、成立與否的判斷軸

```
罵人的話
   ├─ 表意脈絡：情緒性？侮辱性？兩者皆有？
   ├─ 被害人：自己挑起爭端？為聲量而表意的自媒體？
   ├─ 表意人：一般人？具優勢地位的網紅、公眾人物？
   └─ 言論價值：有益公共事務思辯？文學藝術？學術專業？
        ↓
   逾越一般人可合理忍受範圍，且名譽權應優先 → 才成立
```

## 二、對照組

| 情境 | 成立機會 |
|---|---|
| 平靜時突然辱罵 | 較高 |
| 擦撞、爭執當下的情緒用語 | 較低 |
| 一般網友在直播留言狂刷三字經 | 偏高（老師親身經驗） |
| 大網紅在節目上公開羞辱特定人 | 比一般人罵同樣的話更高 |

- 老師：這號判決的價值是把日常生活中大家理解的事「**憲法化**」。
- 合憲性解釋之後，未來可能出現針對公然侮辱**裁判**本身的憲法審查（裁判違憲，見憲法08 筆記 06）。
