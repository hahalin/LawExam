# 憲法03 筆記：立委聲請與不得已的失敗（憲訴§49）

## 要件只有兩個：
- 立法委員現有總額**四分之一以上**：113 席 ÷ 4 ＝ 28.25 → **29 席**
- **就其行使職權**：整個單元就在學這四個字

## 2022 年前後：
- 舊大審法 §5 I ③：現有總額**三分之一**（113 席 → 38 席）
- 憲訴法 §49（2022 施行）：**四分之一**

## 不得已的失敗：
- 立委自己就能立法、修法 → 會來聲請的，一定是**失敗者**
- 失敗還必須是**不得已**的失敗，才算「行使職權」
- 兩種行為樣態：**不想修法或立法**（要好好阻擋，筆記 07）、**想修法**（要修法未果，筆記 08）

## 一、為什麼立委聲請最奇怪

- 立委來跟大法官說「這個法律違憲」，大法官最想回：「你們不會自己改嗎？」
- 所以立委聲請的爭議最多、**考試最愛考**；近一年立法院的狀況讓這部分更重要。
- 存在理由：多數不一定正確、少數不一定錯誤 → 立法依多數決，但要給**少數黨**反擊的機會 → 四分之一門檻。

## 二、所有聲請主體都要「不得已」

| 主體 | 什麼叫不得已 | 例 |
|---|---|---|
| 人民（§59） | 用盡審級救濟仍敗訴 | 上訴到最高法院定讞 ✓；上訴被裁定駁回 ✓；**自己不上訴**而確定 ✗ |
| 法官（§55） | 法規範違憲與否**直接影響**裁判結果 | 通姦罪違憲 → 無罪；合憲 → 有罪 ✓；某條違憲與否不影響結果 ✗ |
| 立委（§49） | **不得已的失敗** | 下兩份筆記 |

- 老師：你不聲請會怎樣？會死嗎？會 → 才讓你聲請。

## 三、立委的不得已＝失敗

```
立委能立法、修法
     ↓
勝利者（多數）自己改就好，不需要聲請
     ↓
來聲請的一定是失敗者（loser）
     ↓
還要問：是不是「不得已」的失敗？
     ├── 是 → 算「行使職權」→ 可以聲請
     └── 否 → 不算行使職權 → 不受理
```

- 老師的類比：討論善意取得，前提一定是前手**無權**；討論立委聲請，前提一定是**失敗**。

## 四、兩種行為樣態

```
§49「行使職權」
  ├── 不想修法或立法（對方要通過新法，我方反對）
  │     → 聲請標的：新法
  │     → 要看：有沒有「好好阻擋」（筆記 07：1476 次決議、釋字 781）
  │
  └── 想修法（我方要修掉舊法，修不掉）
        → 聲請標的：舊法
        → 要看：有沒有「修法未果」（筆記 08：釋字 603、113 憲裁 16）
```
