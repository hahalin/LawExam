# 憲法17 筆記：條約審議與兩公約施行法（釋字329）

## 條約要送立法院審議：
- §63：立法院有議決**條約案**之權
- 釋字 329：名稱為條約、公約，或名為協定而附有**批准條款**者，應送立法院審議

## 兩公約：沒簽署，但自願國內法化：
- 我國未被普遍承認為國家，**沒有完成兩公約的批准程序**
- 立法院自行通過**兩公約施行法**，自願遵守 → 兩公約在我國**國內法化**
- 一般國家是簽署批准後國內法化；我國是自己立法說要遵守

## 公約在國內的位階：沒有標準答案
- 施行法是法律；但法律若牴觸兩公約，是否當然無效？公約內容多半空泛，精神上希望**憲法化**
- 例：公政公約 §20 II 要求禁止仇恨言論，但我國沒有立法禁止 → 能否直接援引公約禁止？規範與現實的落差
- 負責推動落實的機關：監察院**國家人權委員會**

## 📖 法條原文速查

> **憲法 §63**　立法院有議決法律案、預算案、戒嚴案、大赦案、宣戰案、媾和案、**條約案**及國家其他重要事項之權。

> **公民與政治權利國際公約 §20 II**　任何鼓吹民族、種族或宗教仇恨之主張，構成煽動歧視、敵視或強暴者，應以法律禁止之。→ 建議查閱施行法所附中文本

## 📋 釋字速查

> **釋字 329 號**：憲法所稱之條約，係指中華民國與其他國家或國際組織所締約之國際書面協定，包括用條約或公約之名稱，或用協定等名稱而其內容直接涉及國家重要事項或人民之權利義務且具有法律上效力者而言。其中名稱為條約或公約或用協定等名稱而附有**批准條款**者，當然應送立法院審議。→ 原文建議查閱司法院網站

> 字號校正：字幕「32,324 是 329」即**釋字 329**。

## 一、條約的國內法化：一般國家與我國

```
一般國家：談判簽署 → 送國會審議批准 → 國內法化

我國（兩公約）：無法完成批准程序
             → 立法院自行制定「兩公約施行法」
             → 自願遵守 → 國內法化
```

- 老師：理論上條約是我們跟國際談完後整包回到立法院審議；兩公約沒有經過這個程序，所以用施行法的方式處理。
- 去年考試考過「國際法在我國有沒有適用」，要小心。

## 二、位階問題

| 問題 | 說明 |
|---|---|
| 施行法的位階 | 法律 |
| 法律牴觸兩公約，是否無效？ | 沒有答案 |
| 能否直接援引公約限制人民（如仇恨言論）？ | 規範與現實的衝突；理想上應立法補足公約要求而我國未做到的部分 |

## 三、老師推薦：監察院的報告

- 監察院的調查報告、糾正案不是判決，寫法較自由，常引用國際公約，可以看到規範如何連結現實。
- 例：區公所沒有無障礙設施 → 身心障礙者權利公約（CRPD）要求 → 監察院對地方政府提出糾正 → 議員據以質詢 → 地方政府提出改善報告。
