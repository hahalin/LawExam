# 憲法10 筆記：菸品標示義務與不表意自由（釋字577）

## 菸是商業性言論最愛考的單元：
- 菸是大家公認最不好的產品，沒有政治人物敢替菸講話 → 打菸**政治正確**，法律管得特別嚴
- 老師提醒：管制越嚴、越沒人敢反對的地方，越要警覺背後是否**不合理**
- 套路：法律管很嚴 → 菸商不服、敗訴 → 聲請釋憲 → 大法官原則上**尊重立法者** → 碰到菸幾乎都合憲

## 釋字 577：強制在菸盒標示尼古丁、焦油含量 → 合憲
- 強制標示＝要求菸商說出它不想說的話 → 涉及**消極不表意自由**（言論自由）
- 大法官：標示有助消費者**正確了解**菸品，並意識吸菸危害、審慎判斷 → 維護國民健康，合憲

## 老師的質疑：
- 「有助正確了解」可以接受（像飲料標示熱量）
- 「讓人意識危害而不抽」不成立：會看尼古丁、焦油的是**已經在抽**的人，用來挑濃淡；沒有吸菸者不知道抽菸不好
- 法律管制的目標應是**風險**（一般攝取不會出事），不是禁止一切「不好」；國家責任與個人責任要平衡

## 📖 法條原文速查

> **憲法 §11**（表現自由）　人民有言論、講學、著作及出版之自由。→ 577：包括**消極不表意自由**

> **菸害防制法 §8 I**（舊，1997 年版）　菸品所含之**尼古丁及焦油含量**，應以中文標示於菸品容器上。→ 釋字 577 合憲；本法已於 2009、2023 年大幅修正，現行條號與內容建議查閱最新六法原文

> **菸害防制法 §21**（舊）　違反 §8 標示規定之罰則。→ 原文與金額建議查閱最新六法原文

---

## 📋 釋字速查

> **釋字 577 號**（2004 年）：憲法 §11 保障人民之表現自由，既保障積極之表意自由，亦保障**消極之不表意自由**。國家為增進公共利益，於符合比例原則之範圍內，非不得以法律課予人民表意之義務。菸害防制法 §8 I 課菸品業者於其商品標示尼古丁及焦油含量之義務，係對菸品業者不表意自由之限制，惟其目的在**提供消費者必要商品資訊與維護國民健康**，手段有助目的達成，對菸品業者之限制尚屬輕微，與比例原則無違，**合憲**。→ 原文建議查閱司法院網站

> 字號校正：字幕「4至577」即**釋字 577**；「菸害防治法」應為**菸害防制法**。老師說「接下來 577 跟 794」，兩號都是菸。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「強制菸品標示尼古丁、焦油含量，限制何種基本權？」 | **消極不表意自由**（言論自由，憲法 §11） |
| 「言論自由是否保障『不說話』的自由？」 | **是**，積極表意＋消極不表意（釋字 577） |
| 「菸品標示義務合憲嗎？」 | **合憲**（釋字 577）：提供必要資訊、維護國民健康，限制輕微 |
| 「國家可否課予人民表意義務？」 | 可以，須以法律為之並符合比例原則 |
| 「涉及菸品的管制，大法官態度？」 | 多半**尊重立法者**，結論多合憲（577、794） |

## 一、為什麼菸常被考

```
菸＝公認最不好的產品
   ↓
沒有政治人物敢替菸講話 → 打菸政治正確
   ↓
法律管得特別嚴（標示、廣告、贊助、吸菸區、年齡 18→20、全面禁電子菸）
   ↓
菸商不服、敗訴 → 聲請釋憲 → 大法官尊重立法者 → 合憲
```

- 老師提醒：當大家都覺得「這個東西管再嚴也沒關係」，往往就是問題所在。
- 各國模式不同：老師舉紐西蘭規定某年以後出生者不得吸菸，但電子菸普及；臺灣相反，提高吸菸年齡、全面禁止電子菸（老師口述，建議查證）。

## 二、577 的論證與老師的拆解

| 大法官的理由 | 老師的評價 |
|---|---|
| 標示有助消費者對菸品**正確了解** | 可以接受，類似飲料標示熱量 |
| 告知成分使消費者**意識並警覺**吸菸危害、審慎判斷 | 假設很怪：看標示的是已在吸菸的人，用來選濃淡，不會因此戒菸 |
| 明顯有助維護國民健康 | 目的正當，但手段與目的的關聯被高估 |

- 後來菸盒警示越來越多（警示圖文、面積比例都有規定），已非 577 當時只標尼古丁、焦油。

## 三、國家責任與個人責任

- 法律管制的合理標準：一般人**正常攝取**不會出事；自己長期大量攝取，是自己的選擇。
- 老師延伸：臺灣人較少自己承擔風險，出事先怪政府 → 國家對接近山、海、湖等自然資源限制多 → 是否有憲法上的「接近使用自然資源」權利、限制過多是否違憲，值得思考（考試較少考）。
- 若「不好就要管」，酒、速食都該管 → 好壞與責任分配要**綜合判斷**、個案判斷。
