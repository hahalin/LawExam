# 憲法17 筆記：質詢與備詢的對象（釋字461與498）

## 質詢與備詢的區分：
- **質詢**：院會中，立委對**行政院院長及各部會首長**（增修 §3 II ①）
- **備詢**：**委員會**邀請政府人員及社會上有關係人員到會（§67 II）
- 本質上都是詢問、檢討官員；憲法用語不同

## 釋字 461：誰不是質詢、備詢對象
- **參謀總長**：是國防部部長的**幕僚長**，不是部會首長 → **不能質詢**，但**應赴委員會備詢**（涉重要國防機密得免答）
- **獨立行使職權**的人員（法官、NCC 委員等）→ **不能被邀備詢**；但具行政官性質者（如 NCC 主委）可以
- **司法、考試、監察三院院長** → 基於五院相互尊重，**不受邀備詢**；三院**秘書長**等非獨立行使職權人員，就其提出的法律案及預算案，仍有備詢義務

## 釋字 498：地方自治團體人員
- 除法律明定應到會者外，地方自治團體行政機關公務員**得自行衡量**是否到會備詢
- 立法院**不得**因其未到會而刪減或擱置中央對地方的**補助款**
- 對照：中央部會被邀拒不到會、逃避監督 → 立法院可以據此刪其預算

## 📖 法條原文速查

> **增修 §3 II ①**　行政院有向立法院提出施政方針及施政報告之責。立法委員在開會時，有向**行政院院長**及**行政院各部會首長**質詢之權。

> **憲法 §67 II**　各種委員會得邀請**政府人員**及**社會上有關係人員**到會**備詢**。

## 📋 釋字速查

> **釋字 461 號**（1998 年 7 月）要旨：
> - 參謀總長為國防部部長之**幕僚長**，不屬憲法所稱部會首長，非立法委員**質詢**之對象。
> - 參謀總長除因執行關係國家安全之軍事業務等正當理由外，**不得拒絕**應邀到委員會**備詢**；詢問內容涉及重要國防機密事項者，得免予答覆。
> - 司法、考試、監察三院**院長**，本於五院間相互尊重之立場，並依循憲政慣例，得**不受**邀請備詢。
> - 三院**非獨立行使職權**而負行政職務之人員，於其提出之法律案及有關預算案涉及之事項，有應邀說明之義務。
> → 原文建議查閱司法院網站

> **釋字 498 號**要旨：地方自治團體行政機關公務員，除法律明定應到會備詢者外，得**衡酌**到會說明之必要性，決定是否到會；立法院不得因其未到會而**刪減或擱置**中央機關對地方自治團體之補助款。→ 原文建議查閱司法院網站

> 字號校正：字幕「4至461和498號」即**釋字 461**、**498**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「下列何者**不是**立委質詢的對象？」 | **參謀總長**（幕僚長，非部會首長） |
| 「參謀總長可否拒絕到委員會備詢？」 | **原則不得**；涉重要國防機密得免答 |
| 「法官可否被邀到立法院備詢？」 | **不可**：獨立行使職權 |
| 「司法院院長應否到立法院備詢？」 | **不必**：三院院長基於五院相互尊重不受邀；**秘書長**仍應就法律案、預算案說明 |
| 「直轄市局長不到立法院備詢，立法院可否刪補助款？」 | **不可**（釋字 498） |
| 「中央部會首長拒不備詢，可否刪其預算？」 | **可以**：逃避監督 |

## 一、對象分類表（老師：律師司法官考試考過這張表，年份建議查證）

| 對象 | 質詢（院會） | 備詢（委員會） |
|---|---|---|
| 行政院院長、各部會首長 | ✓ | ✓ |
| 參謀總長 | ✗ | ✓（國防機密得免答） |
| 法官、NCC 委員等獨立行使職權者 | ✗ | ✗ |
| NCC 主委（行政官性質） | — | ✓ |
| 司法、考試、監察三院院長 | ✗ | ✗（相互尊重） |
| 三院秘書長等行政人員 | ✗ | ✓（就其法律案、預算案） |
| 地方自治團體公務員 | ✗ | 自行衡量（法律明定者除外） |

## 二、地方為什麼可以不來

```
直轄市局長 ── 對市議會負責
中央部會首長 ── 對立法院負責（行政院 ← 立法院監督）

局長不對立法院負責 → 可以自行決定是否到會
        → 立法院不得以刪補助款懲罰（498）
部會首長拒不到會 → 逃避監督 → 立法院可刪其預算
```

## 三、秘書長的角色

- 三院院長不備詢，立法院對三院最高只能詢問到**秘書長**；秘書長的重要任務是**政策辯護**。
- 老師：官員被罵到說不出話，有時是避免把政策變成政治議題的選擇，不宜只用畫面評價。
