# 憲法17 筆記：立法院的預算權：不得增加支出與只刪不改（釋字264與391）

## 立法院不得為增加支出的提議：
- 憲法 §70：立法院對於行政院所提預算案，**不得為增加支出之提議**
- 理由是**責任政治**：行政院做事、花錢；立法院監督。若立法院可以加錢，花太多錢時分不清是誰的責任

## 立法院可以立法，法律必然帶來支出：
- 不是說立法院完全不能讓預算增加：立法院立一部需要經費的法律（例：法庭直播），必然增加預算，這可以
- 不可以的是：**自己提出預算案**，或在行政院已提出的預算上**再往上加**

## 預算案只能刪，不能逐條改：
- 審議法律案可以**逐條逐句增刪修改**；審議預算案原則上只能**刪減**（釋字 391）
- 在款項目節間移動增減，會實質變動施政計畫，**政策成敗無所歸屬、責任政治難以釐清**

## 老師見解：用法律案包裝預算案？
- 法律是**反覆、長久、持續**適用的；預算是**一年一次**
- 用特別條例規定一次性、當年度結束的發放（2025 年普發現金），實質上較接近預算 → 老師認為有違反 §70 之虞，但強調是個人見解、不是絕對違憲

## 📋 釋字速查

> **釋字 264 號**：立法院會議決議請行政院在該年度再加發公教人員年終工作獎金、「其預算再行追加」，係就預算案為**增加支出之提議**，與憲法 §70 牴觸，不生效力。→ 原文建議查閱司法院網站

> **釋字 391 號**：立法院審議預算案，不得比照審議法律案作**逐條逐句之增刪修改**；如僅對各機關所編列預算之數額，在款項目節間**移動增減**並追加或削減原預算之項目，實質上變動施政計畫之內容，造成**政策成敗無所歸屬，責任政治難以釐清**之結果，有違立法權與行政權**權力分立**之憲政原理。→ 原文建議查閱司法院網站

> 字號校正：字幕「4391 跟 294 號解釋」：391 即**釋字 391**；「294」推定為談 §70 的**釋字 264**，建議查證。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「立法院得否對行政院所提預算案為增加支出之提議？」 | **不得**（§70；釋字 264） |
| 「§70 的理論基礎？」 | **責任政治**、權力分立 |
| 「立法院制定需要經費的法律，是否違反 §70？」 | **不違反**；§70 限制的是對行政院所提預算案**增加支出** |
| 「立法院得否在預算的款項目節間移動增減？」 | **不得**（釋字 391） |
| 「預算案審議與法律案審議的差別？」 | 法律案可逐條逐句修改；預算案原則上**只能刪減** |

## 一、為什麼只能監督、不能加錢

```
行政院 ── 執行政策、花錢 ── 對結果負責
   ↑ 監督（刪減、質詢、罵）
立法院

若立法院可以加錢：
   錢花太多 → 是行政院的錯？還是立法院的錯？
   → 責任歸屬混亂 → 違反責任政治
```

- 老師：「監督」是果，「責任政治」是因。答題要抓到責任政治這四個字。

## 二、可以與不可以

| 情形 | 是否違反 §70 |
|---|---|
| 立法院制定新法律，執行上需要經費 | 不違反 |
| 立法院自己提出預算案 | 違反 |
| 在行政院所提預算上增加支出（264：加發年終獎金） | 違反 |
| 在款項目節間移動增減（391） | 違反權力分立 |

## 三、法律案與預算案的本質區別（老師見解）

| | 法律 | 預算 |
|---|---|---|
| 時間 | 長期、反覆、持續（殺人罪不會明年就結束） | 一年一次 |
| 例 | 照顧低收入戶的常態補助 | 一次性、當年度發放 |

- 一次性、當年度結束的給付若由立法院以法律主動規定，實質上是**以法律案包裝預算案**，限制行政權使用預算的權限 → 老師認為有違反 §70 之虞。
- 若由行政院主動編列、立法院審議，就比較沒有問題。
- 老師認為這是近年最值得拿來考的題目，因為直接牽涉憲法法理；並強調這是他目前的個人見解。
