# 憲法15 筆記：三等特考分發警專受訓（釋字760）

## 制度：兩條路通往警官、兩條路通往基層員警
- 警大畢業或訓練合格 → **警官**（可一路升遷）
- 警專畢業或訓練合格 → **基層員警**（警階有天花板）
- 三等特考（大學畢業才能考）→ 原應到**警大**受訓 → 警官
- 四等特考（高中畢業可考）→ 到**警專**受訓 → 基層員警

## 爭議：三等考上，卻被分到警專
- 警政署以警大訓練位置不足為由，把一批三等特考及格者分發到**警專**受訓
- 法律規定警專訓練合格 → 基層員警 → 三等考上的人當不到警官

## 為什麼是間接歧視的例子：
- 「警專畢業或訓練合格者任基層員警」這句話**本身沒有問題**
- 但實際適用到被分發到警專的三等特考及格者 → 產生不公平

## 結論：違反平等權
- 釋字 760：違反憲法 §7 **平等權**；解釋未另外宣告違反 §18 服公職權
- 警政署「訓練位置不足」的理由，與差別待遇之間**欠缺實質關聯**

## 📖 法條原文速查

> **憲法 §7**　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律平等。

> **憲法 §18**　人民有應考試服公職之權。

> **警察人員人事條例 §11 II**（2018 年時）　警察官之任官資格，以警察大學或警官學校畢業或訓練合格者為限之規定（大意）。→ 條文文字建議查閱最新六法原文

## 📋 釋字速查

> **釋字 760 號**（2018 年 1 月 26 日）：警察人員人事條例 §11 II 未明確規範三等特考及格者的訓練機構，致實際上僅分發警專受訓的及格者無從取得警官任官資格，構成**差別待遇**，違反憲法 §7 平等權；主管機關應於一定期間內採取措施除去不平等。→ 主文與期限建議查閱解釋原文

## 一、路徑圖

```
         ┌── 警大（畢業或訓練合格）─→ 警官
高中畢業 ─┤
         └── 警專 ─────────────────→ 基層員警

         ┌── 三等特考 ─→ 原應警大受訓 ─→ 警官
大學畢業 ─┤               └─ 部分被分到警專 ─→ 基層員警  ← 爭議
         └── 四等特考 ─→ 警專受訓 ─────→ 基層員警
```

## 二、老師的比喻

- 停車場看板寫「剩餘車位 10」，開下去發現是 0 → 問題不在有沒有車位，而是**為什麼告訴你有**。
- 考過三等，制度承諾的是警官；因為行政上的訓練位置分配，結果只能當基層員警。
- 老師也提到警大、警專「血統主義」：直接讀警大、警專的是「純正」，特考進來的被看成外來者。

## 三、與 748 的比較（伏筆）

- 760 的當事人**仍然可以當警察**，只是當不成警官 → 服公職沒有被完全剝奪。
- 真正的問題是**分配不平等** → 大法官只用平等權處理。詳見 筆記-04。
