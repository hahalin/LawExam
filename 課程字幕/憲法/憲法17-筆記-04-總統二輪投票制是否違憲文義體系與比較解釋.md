# 憲法17 筆記：總統二輪投票制是否違憲：文義、體系與比較解釋

## 問題：
- 增修 §2 I：總統、副總統候選人聯名登記，「以**得票最多**之一組為當選」
- 若以**法律**把總統選舉改成**二輪投票制**，會不會違憲？學者近來有討論

## 三種解釋角度，答案可能不同：
- **文義解釋**：條文只說「得票最多」，沒說哪一輪 → 改成第二輪得票最多也是得票最多，可能不違憲；反面：第一輪第一名在第二輪落選（法國發生過），似與「得票最多」衝突
- **體系解釋**：憲法凡要提高門檻（例如絕對多數）都會明文；沒寫就是最基本的相對多數 → 以法律改成二輪、提高門檻，可能違憲
- **比較解釋**：法國的二輪投票是**寫在憲法裡** → 二輪投票的正當性應來自憲法明文

## 答題要點：
- 不能只看單一條文的文字，要看整體結構與比較法；角度不同，答案就不同

## 📖 法條原文速查

> **增修 §2 I**　總統、副總統由中華民國自由地區全體人民**直接選舉**之，自中華民國八十五年第九任總統、副總統選舉實施。總統、副總統候選人應**聯名登記**，在選票上同列一組圈選，以**得票最多之一組為當選**。在國外之中華民國自由地區人民返國行使選舉權，以法律定之。

> **民法 §972**　婚約，應由**男女**當事人自行訂定。

## 一、三種解釋方法套在同一題

```
增修 §2 I「以得票最多之一組為當選」
│
├─ 文義解釋 → 沒限定哪一輪 → 二輪的「最多」也算 → 可能合憲
│             但：第一輪第一名在第二輪輸了 → 他不是「得票最多」嗎？
│
├─ 體系解釋 → 提高門檻都要明文（絕對多數、2/3、3/4……）
│             沒寫 = 最基本的相對多數 → 法律加門檻 → 可能違憲
│
└─ 比較解釋 → 法國二輪制規定在憲法 → 二輪需憲法明文 → 可能違憲
```

## 二、同樣的方法看民法有沒有禁止同性婚姻

| 方法 | 看什麼 | 結論 |
|---|---|---|
| 文義解釋 | §972「男女當事人」 | 字面上看不出排除同性（男男、女女也是「男女」） |
| 體系解釋 | 整部民法親屬編 | 整體以**一男一女**的婚姻打造 → 民法沒有開放同性婚姻 |
