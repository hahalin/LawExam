# 憲法05 筆記：法治國與階層化法律保留（釋字443）

## 法治國的意思：
- 不是「有法律就治理」，而是法律**有道理**才治理；法治國要確保我們遵守的規則是合理的

## 事實：
- 1990 年代《役男出境處理辦法》：未服役的役男原則**不得出境**，只有國際比賽等特殊情形可申請
- 該辦法是**行政命令**，兵役法沒有授權 → 大學生申請出國留學被拒，聲請釋憲

## 結論：
- 釋字 443：以命令限制役男出境，**欠缺法律授權**，違反法律保留（憲法 §23），侵害 §10 **遷徙自由**
- 確立**階層化法律保留**：權利越重要、限制越嚴重 → 規範位階要越高

## 📖 法條原文速查

> **憲法 §8 I**（人身自由）　人民身體之自由應予保障。除現行犯之逮捕由法律另定外，非經司法或警察機關依法定程序，不得逮捕拘禁……

> **憲法 §8 II**　人民因犯罪嫌疑被逮捕拘禁時，其逮捕拘禁機關應將逮捕拘禁原因，以書面告知本人及其本人指定之親友，並至遲於**二十四小時**內移送該管法院審問。→ 憲法保留的例子

> **憲法 §10**（居住遷徙自由）　人民有居住及**遷徙**之自由。

> **憲法 §23**（法律保留、比例原則）　以上各條列舉之自由權利，除為防止妨礙他人自由、避免緊急危難、維持社會秩序，或增進公共利益所必要者外，不得以**法律**限制之。

> **中央法規標準法 §2**　法律得定名為**法、律、條例或通則**。

> **中央法規標準法 §5**（應以法律規定之事項）　左列事項應以法律定之：一、憲法或法律有明文規定，應以法律定之者。二、關於人民之**權利、義務**者。三、關於國家各機關之組織者。四、其他重要事項之應以法律定之者。

## 📋 釋字速查

> **釋字 443 號**（1997 年）：役男出境處理辦法限制役男出境，兵役法及兵役法施行法均未授權，違反憲法 §23 法律保留，侵害 §10 遷徙自由。理由書建立**階層化法律保留**：
> - 憲法 §8 人身自由之保障 → **憲法保留**
> - **剝奪人民生命或限制人民身體自由** → 以制定法律方式為之（**絕對法律保留**）
> - 涉及人民其他自由權利之限制 → 法律規定，或以法律**具體明確授權**命令補充（**相對法律保留**）
> - 執行法律之**細節性、技術性次要事項** → 主管機關得發布命令規範（**不需法律保留**）
> - 給付行政：規範密度較寬鬆；但涉及公共利益之重大事項，仍應有法律或法律授權之命令為依據

> 補充（老師未引字號）：**釋字 474 號**——時效制度須**逕由法律明定**，不得授權行政機關以命令訂定。→ 對應老師所說「時效是法律絕對保留」

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「階層化法律保留出自哪一號？」 | **釋字 443**（五顆星） |
| 「警察逮捕後 24 小時內移送法院，屬何種保留？」 | **憲法保留**（§8 II），法律不得改為 48 小時 |
| 「剝奪生命、限制身體自由屬何種保留？」 | **絕對法律保留**（如刑法 §271 死刑須由法律規定） |
| 「時效制度可否授權命令訂定？」 | **不可**，須由法律明定（釋字 474） |
| 「遷徙自由的限制屬何種保留？」 | **相對法律保留**：法律或法律具體明確授權之命令 |
| 「細節性、技術性事項？」 | **不需法律保留**，主管機關得以命令規範 |
| 「行政命令可以處罰人民嗎？」 | 須有**法律授權** |
| 「如何辨識是法律還是命令？」 | 名稱為**法、律、條例、通則**者為法律（中標法 §2）；「辦法」「規則」「細則」是命令 |

## 一、本案：役男出境處理辦法

```
役男：滿 18 歲之翌年 1 月 1 日起
        │
《役男出境處理辦法》（命令）：未服役者原則不得出境
        │ 兵役法沒有授權
        ▼
釋字 443：限制 §10 遷徙自由，須法律或法律具體明確授權 → 違憲
```

- 限制有沒有道理？有，怕役男出國逃兵。問題在於：① 只用一紙命令；② 原則全面禁止，預設所有役男都會逃兵，太誇張。
- 現在役男出國只要上網申請即可。

## 二、階層化法律保留：權利越重要，位階越高

```
限制越嚴重 ▲
          │ 憲法保留 ────── §8 II 24 小時移送（法律也不能改）
          │ 絕對法律保留 ── 剝奪生命（刑法 §271）、限制身體自由、時效
          │ 相對法律保留 ── 其他自由權利（如遷徙）：法律 or 法律授權之命令
          │ 不需法律保留 ── 細節性、技術性事項
限制越輕微 ▼
```

- 貫穿之後所有課程的邏輯：**人民權利被限制的嚴重程度**，決定法規範要多嚴謹。罰 600 元和判 6 年，當然不一樣。
- 為什麼法律比命令嚴謹：立法程序經三讀、成本高；命令由行政機關自行訂定，成本低 → 越重要的權利交給越難制定的規範。
- 生命權不是憲法保留：憲法只會保障人權，不會寫「可以剝奪生命」；死刑寫在刑法 §271 → 絕對法律保留。
- 行政機關專業常高於立法機關 → 立法者定框架、授權行政機關處理細節，是合理分工。
