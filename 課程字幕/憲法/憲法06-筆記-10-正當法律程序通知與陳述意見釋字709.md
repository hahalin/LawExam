# 憲法06 筆記：正當法律程序：通知與陳述意見（釋字709）

## 核心兩件事：
- **通知**：讓當事人知道發生什麼事、違反什麼規定
- **陳述意見**（聽證）：讓當事人有申辯的機會
- 源自美國法，以通知與聽證為核心

## 嚴謹程度依侵害大小：
- 紅燈右轉罰 600：要通知，但不一定事前陳述意見（事後可申訴、行政訴訟）
- 刑事被告：通知、偵查庭陳述、起訴、一審、二審 → 程序非常嚴謹
- 由立法者綜合考量基本權種類、限制強度、公益、機關功能、替代程序與成本，制定相應程序

## 釋字 709（都市更新）：
- 都更涉及**居住自由、財產權** → 應確保利害關係人知悉資訊、適時陳述意見，並舉行**聽證**

## 📖 法條原文速查

> **憲法 §8 I**（人身自由）　人民身體之自由應予保障。除現行犯之逮捕由法律另定外，非經司法或警察機關依**法定程序**，不得逮捕拘禁。非由法院依法定程序，不得審問處罰。→ 正當法律程序的文字依據之一

> **憲法 §10**　人民有居住及遷徙之自由。

> **憲法 §15**　人民之生存權、工作權及**財產權**，應予保障。

---

## 📋 釋字速查

> **釋字 709 號**（2013 年 4 月 26 日）：都市更新條例關於都市更新事業概要及計畫審核程序之規定，未設**適當組織**審議，未確保利害關係人知悉相關資訊及適時陳述意見之機會，計畫核定前未舉行**聽證**，不符憲法要求之正當行政程序，違憲。

> 理由書重點（老師朗讀）：正當行政程序，包括應規定確保利害關係人**知悉相關資訊**之可能性，及許其**適時向主管機關以言詞或書面陳述意見**，以主張或維護其權利；並應公開舉行聽證，使利害關係人得到場以言詞為意見之陳述及論辯，作成聽證紀錄。

> 正當法律程序的一般公式（老師朗讀）：應視所涉基本權之種類、限制之強度及範圍、所欲追求之公共利益、決定機關之**功能合適性**、有無**替代程序**及各項可能程序之**成本**等因素綜合考量，由立法者制定相應之法定程序。

> 字號校正：字幕「四之709」即**釋字 709**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「正當法律程序的核心要素？」 | **通知**與**陳述意見（聽證）** |
| 「正當法律程序是否有固定標準？」 | **沒有**；依限制權利的大小決定程序樣貌 |
| 「決定應踐行何種程序的考量因素？」 | 基本權種類、限制強度與範圍、公益、機關功能合適性、替代程序、成本 |
| 「都市更新計畫核定未舉行聽證？」 | 違反正當行政程序（釋字 709） |
| 「釋字 709 涉及的基本權？」 | **居住自由**與**財產權** |

## 一、兩個例子對照

| | 紅燈右轉罰 600 | 內線交易刑事被告 |
|---|---|---|
| 通知 | 有（開單，告知違反什麼規定） | 有（傳票寫涉嫌內線交易） |
| 陳述意見 | 不一定事前；不服可申訴、行政訴訟 | 一定要：偵查庭陳述、可委任律師 |
| 後續程序 | 繳了就結束 | 起訴、一審、二審 |
| 侵害大小 | 小 | 大（可能被關） |

```
限制權利越大 → 正當法律程序越嚴謹
限制權利越小 → 程序可以簡化
```

## 二、老師的高中故事：沒有通知、沒有申辯

- 上課隔壁同學一直講話，老師罵兩人；老師說要記過。
- 問題一：沒有**通知**到底為什麼記過（上課講話？頂撞師長？）。
- 問題二：沒有給**申辯、陳述意見**的機會。

## 三、本堂總結：所有原則都繞著同一件事

```
法律保留 → 授權明確性 → 法律明確性 → 比例原則
→ 法律不溯及既往 → 信賴保護 → 正當法律程序
            │
對人民權利侵害越大，原則越緊縮；侵害越小，可越寬鬆
```

- 下一堂進入基本權：基本權種類、基本概念，從人性尊嚴、人身自由開始。社會國原則留到財產權再講。
