# 憲法06 筆記：真正與不真正溯及既往（釋字714）

## 兩種溯及既往：
- **真正溯及既往**：新法適用於過去**已終結**的事實 → 原則**違憲**
- **不真正溯及既往**：新法適用於過去開始、**尚未終結**的事實 → 原則**不違憲**，看配套（信賴保護、過渡措施）

## 關鍵是行為有沒有終結：
- 規則本身簡單；考試真正要判斷的是：當事人的行為（或狀態）**終結了沒有**

## 釋字 714：
- 土壤及地下水污染整治法 §48：施行前已發生的污染，污染**持續存在**者，仍可追究污染行為人
- 處理的是**污染狀態的存續**，不是過去的行為 → 不真正溯及既往 → **不違反**法律不溯及既往原則

> 來源：憲法06 課程字幕 01:34:42 ~ 01:43:01（講義第二本第 29～31 頁）

## 📖 法條原文速查

> **土壤及地下水污染整治法 §48**（2000 年制定時，要旨）　本法有關污染行為人責任之規定，「於本法施行前已發生土壤或地下水污染之**污染行為人**適用之」。→ 列舉的條文範圍與現行條號，建議查閱最新六法原文

> **憲法 §15**　人民之生存權、工作權及**財產權**，應予保障。

---

## 📋 釋字速查

> **釋字 714 號**（2013 年 11 月 15 日）：土污法 §48 關於「於本法施行前已發生土壤或地下水污染之污染行為人適用之」，係對本法施行後，其污染狀況**仍繼續存在**之情形而為規範，**尚未違反法律不溯及既往原則**；與憲法 §15 保障工作權、財產權之意旨無違。理由書：施行前終了之污染行為，施行後已無污染狀況者，不在適用範圍；施行前之污染行為本非合法，信賴不值得保護，並非顯失均衡。

> 事實補充：聲請人中石化因吸收合併台灣鹼業而概括承受**安順廠**受污染土地（戴奧辛、重金屬）；臺南市政府要求整治。老師說工廠 1978 年停工，判決記載為 **71 年（1982 年）5 月關廠**。

> 字號校正：
> - 字幕「471」「714717」中講土污法的是**釋字 714**。
> - 字幕「臺灣市政府」應為**臺南市政府**。
> - 老師說真正、不真正溯及既往的圖出自「詹森林大法官 605 號解釋意見書」；釋字 605 作成於 2005 年，詹森林 2016 年才任大法官，字號存疑 → 建議查閱。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「新法適用於施行前已終結之事實？」 | **真正**溯及既往 → 原則違憲 |
| 「新法適用於施行前開始、施行後仍繼續之事實？」 | **不真正**溯及既往 → 原則不違憲，審查信賴保護與過渡措施 |
| 「區分真正與不真正的關鍵？」 | 事實（行為或狀態）是否**已終結** |
| 「土污法 §48 對施行前污染行為人適用，違反不溯及既往？」 | **不違反**：規範的是施行後**仍繼續存在**的污染狀態（釋字 714） |
| 「施行前終了、施行後已無污染者？」 | **不適用** §48 |

## 一、圖解

```
             法律修正（施行日）
                   │
過去開始 ── 已終結 │                → 真正溯及既往：原則違憲
過去開始 ─────────┼──── 尚未終結 → 不真正溯及既往：原則合憲，看配套
                   │
效力原則：向後發生
```

- 真正溯及：「你現在才跟我講」——亂丟垃圾突然改成唯一死刑，追究過去已丟的人。
- 不真正溯及：法律本來就會針對進行中的事改變；若這也不能改，就沒有法律能修了。

## 二、污染：行為與狀態

| | 處罰污染**行為** | 處罰污染造成的**狀態** |
|---|---|---|
| 時間 | 1982 年關廠前已結束 | 到現在仍存在 |
| 定性 | 真正溯及既往 | **不真正**溯及既往 |
| 釋字 714 | — | 採此說，合憲 |

- 殺人沒有危害持續性，殺完就結束；污染有**危害持續性**，持續的危害才是法律處理的對象。
- 老師的保留：當年（1970 年代）一般合理第三人是否已知戴奧辛、重金屬是污染？若當時已知，用持續狀態處理較無問題；若當時不知，定性為真正溯及也有道理。
