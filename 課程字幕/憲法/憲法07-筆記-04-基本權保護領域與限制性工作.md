# 憲法07 筆記：基本權保護領域與限制（性工作）

## 保護領域在處理什麼：
- 某個行為是不是這個基本權保障的範圍
- 放在範圍**外** → 根本沒有基本權受損，案件不用討論（聲請會不受理）
- 放在範圍**內** → 不等於不能限制；接著討論限制是否合理

## 老師的原則：盡可能放進來
- 所有事情都應該被好好討論，而不是單純排除在外
- 殺手：放進工作權範圍也沒關係，刑法 §271 禁止殺人當然合理
- 性工作：先承認是工作權保障範圍，再討論法律限制它是否合理（2017 年司法官考過）

## 性工作在臺灣：
- 法律上：社維法允許地方政府以自治條例規劃性交易區域，區內不罰 → **合法**
- 現實上：全臺沒有任何性交易專區 → 實際上**不合法**

## 📖 法條原文速查

> **憲法 §15**　人民之生存權、**工作權**及財產權，應予保障。

> **憲法 §23**　以上各條列舉之自由權利，除為防止妨礙他人自由、避免緊急危難、維持社會秩序，或增進公共利益所必要者外，不得以法律限制之。→ 基本權可以限制，但須合理

> **刑法 §271 I**　殺人者，處死刑、無期徒刑或十年以上有期徒刑。

> **社會秩序維護法 §80**　有下列各款行為之一者，處新臺幣三萬元以下罰鍰：一、從事性交易。但符合前條之一第一項至第三項之自治條例規定者，不適用之。二、在公共場所或公眾得出入之場所，意圖與人性交易而拉客。→ 建議查閱最新六法原文

> **社會秩序維護法 §91-1 I**　直轄市及縣（市）政府得因地制宜，制定自治條例，規劃得從事性交易之區域及其管理。→ 建議查閱最新六法原文

---

## 📋 釋字速查

> **釋字 666 號**（2009 年，補充，老師未提）：舊社維法 §80 I ① 對「意圖得利與人姦、宿者」處罰，只罰性交易的提供者、不罰相對人，違反**平等原則**，自解釋公布之日起至遲二年失效。→ 之後修法改為現行 §80、§91-1 的專區模式

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「某行為不在基本權保護領域內，結果？」 | **沒有基本權受損** → 不進入違憲審查（不受理） |
| 「某行為在保護領域內，是否就不得限制？」 | **不是**；基本權可依 §23 限制，只要合理 |
| 「性工作是否屬工作權保障範圍？」 | 老師採**肯定**：先放進來，再審查限制是否合理（2017 年司法官考題） |
| 「現行法下性交易是否合法？」 | 法律上專區內不罰（社維法 §80、§91-1）；實際上**無專區** → 仍受罰 |
| 「舊社維法罰娼不罰嫖？」 | 違反平等原則（釋字 666，補充） |

## 一、保護領域的思考邏輯

```
某個行為（例：性工作）
        │
        ├── 放在基本權範圍「外」
        │      → 沒有基本權受損 → 不用討論（不受理）
        │
        └── 放在基本權範圍「內」
               → 有基本權 → 進入下一步：限制是否合理？（§23、比例原則）
```

- 「在範圍內」≠「不能限制」。範圍內只是代表**要好好討論**。

## 二、殺手：極端例子

- 殺手算不算工作權範圍？很多人直覺搖頭。
- 但就算放進來，刑法 §271 禁止殺人 → 沒有人會說這過度剝奪殺手的工作權。
- 結論：放進來不會出事，只是讓思考過程完整。

## 三、性工作：有爭議的例子

| 立場 | 推論 |
|---|---|
| 性工作不是工作 | 排除在工作權外 → 法律禁止不用討論 |
| 性工作是工作（老師） | 進入工作權範圍 → 討論現行限制是否合理 |

- 老師提醒這是很難討論的議題：
  - 「為了減少性犯罪所以要有性工作」的論點，是把女性當工具，很膚淺。
  - 就算有很多合理理由，性工作仍可能帶來**性剝削**、性別不平等。
  - 類似難題：代理孕母、啦啦隊（性客體化、性凝視）。
- 限制是否合理屬於專業議題，需要各領域專業評估，不只是法律人能回答。

### 現行法：合法也對，不合法也對

```
社維法 §91-1：地方政府得以自治條例規劃性交易區域
社維法 §80 ①：從事性交易者罰，但符合自治條例者不罰
        │
        ├── 法律上 → 有合法空間
        └── 現實上 → 全臺沒有任何專區 → 實際上都會被罰
```

- 考題可以問：現行對性工作者的限制，到底是很嚴格還是很寬鬆？
