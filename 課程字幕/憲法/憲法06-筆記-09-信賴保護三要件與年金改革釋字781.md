# 憲法06 筆記：信賴保護三要件與年金改革（釋字781）

## 信賴保護三要件：
- **信賴基礎**：有一個可以信任的標的（舊法、舊制度）
- **信賴表現**：已經依該信賴付出代價、有所作為
- **信賴值得保護**：例如黨產條例中源自威權體制的信賴、污染者的信賴，不值得保護

## 年金改革（釋字 781、782、783）：
- 軍、公、教三號；退休金大幅調降
- 退休金按月給付，屬**繼續性給付** → 不真正溯及既往
- 基於財政、人口結構、世代正義，本來有調整空間；有合理的**過渡機制** → 大部分合憲

## 判準：
- 不真正溯及既往 = 政策不是不能改，而是要改得合理
- 信賴保護的重點判斷：**過渡措施**有沒有做好，有沒有降低改革的衝擊

## 📖 法條原文速查

> **憲法 §15**　人民之生存權、工作權及**財產權**，應予保障。

> **憲法 §18**　人民有應考試、**服公職**之權。

> **憲法訴訟法 §49**　立法委員現有總額四分之一以上，就其行使職權，認法律位階法規範牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。→ 釋字 781 的程序面（立委聲請、行使職權），見憲法03-筆記-07

## 📋 釋字速查

> **釋字 781 號**（2019 年 8 月 23 日）：軍人年金改革（陸海空軍軍官士官服役條例）。退休俸係按月給付之**繼續性法律關係**，新法適用於施行後之給付，**不生溯及既往問題**；基於公益（財政永續、世代正義等）調降，並有過渡安排，未違反**信賴保護原則**與比例原則。少數條文另有違憲宣告 → 建議查閱解釋原文

> **釋字 782 號**（公務人員年改）、**釋字 783 號**（教育人員年改）：同日作成，結構相同。

> **釋字 525 號**（補充，老師未唸字號）：信賴保護原則的要件——信賴基礎、信賴表現、信賴值得保護——常引此號。→ 建議查閱

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「信賴保護原則的三要件？」 | **信賴基礎、信賴表現、信賴值得保護** |
| 「尚未付出任何代價，可否主張信賴保護？」 | **不能**：欠缺信賴表現 |
| 「年金改革調降按月退休給與，是否溯及既往？」 | **不真正**溯及：繼續性給付，適用於施行後之給付 |
| 「不真正溯及既往的審查重點？」 | 信賴保護，尤其**過渡措施**是否合理 |
| 「釋字 781、782、783 分別針對？」 | 軍人、公務人員、教育人員 |

## 一、三要件用律師考試改制說明

| 要件 | 律師考試改制的例子 |
|---|---|
| 信賴基礎 | 舊制度（一次考完；後改一試、二試、選考） |
| 信賴表現 | 已經依舊制度準備、付出代價；3 歲的人說「我以後要考律師」，什麼代價都還沒付 → 無信賴表現 |
| 信賴值得保護 | 黨產條例：源自威權體制 → 不值得；土污法：污染者 → 不值得 |

- 考試制度改變會影響考生：準備方向不同（例如以前一試考古題只有三、四年，現在有十年）。

## 二、年金改革的邏輯

```
退休金按月領 → 每月獨立發生效果 → 不是一次結束
        ↓
不真正溯及既往 → 可以改，但要改得合理
        ↓
看過渡機制：有沒有保障最低合理生活、有沒有漸進
        ↓
有 → 合憲
```

- 公務人員的不滿是真實的：重點不是領多少，是當初講好的被砍；不管改革方或被改革方，這份不滿都得吞。
- 老師認為信賴保護較難出完整考題：題目會給一套制度，要判斷降低衝擊的過渡措施是否合理，很困難。

## 三、複習：釋字 781 的程序面

- 立委聲請要「行使職權」：二讀反對、二讀進三讀反對、三讀退席 → 算行使職權（憲訴 §49）。
