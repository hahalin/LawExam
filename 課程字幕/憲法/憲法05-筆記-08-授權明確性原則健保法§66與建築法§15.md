# 憲法05 筆記：授權明確性原則（健保法§66與建築法§15）

## 和法律保留的分工：
- 法律保留：權利多重要 → 規範**位階**要多高（筆記 07）
- 授權明確性：前提是法律**已經授權**命令 → 檢查授權**寫得夠不夠清楚**

## 判斷方式：
- 命令對人民權利影響越大，法律授權就要寫得越**具體明確**；影響很小，概括授權即可
- 違反授權明確性的是**法律**（授權條款），不是命令

## 為什麼要管：
- 授權寫得太寬鬆＝沒有授權，法律可以把一切丟給命令，**法律保留就被架空**

## 📖 法條原文速查

> **全民健康保險法 §66 I**（特約授權）　醫事服務機構得申請保險人同意**特約**為保險醫事服務機構，得申請特約為保險醫事服務機構之醫事服務機構種類與申請特約之**資格、程序、審查基準、不予特約之條件、違約之處理**及其他有關事項之辦法，由主管機關定之。→ 建議查閱最新六法原文

> **建築法 §15 II**（概括授權）　營造業管理規則，由**內政部**定之。→ 現行條文建議查閱最新六法原文

## 📋 釋字速查（老師未唸字號，以下為補充）

> **釋字 313 號**（1993 年）：對人民違反行政法上義務之行為科處罰鍰，涉及人民權利之限制，其處罰之構成要件及數額，應由法律定之；若法律就其構成要件授權以命令為補充規定者，授權之**內容及範圍應具體明確**，然後據以發布命令，始符憲法 §23 之意旨。→ 授權明確性的基本公式

> **釋字 394 號**（1996 年）：建築法 §15 II 概括授權訂定營造業管理規則，依法律整體解釋可推知授權範圍，就營造業登記、行為準則、考核管理等事項尚無不可；但對營造業者所為**裁罰性處分**涉及人民權利之限制，須有法律或法律**具體明確**授權，營造業管理規則相關處罰規定違憲。→ 老師說建築法這條「後來被宣告違憲」，實際被宣告違憲的是依此概括授權訂定的**處罰規定**

> **釋字 753 號**（2017 年）：全民健保法 §66 I 等授權主管機關訂定特約及管理辦法，授權**明確**，不違反授權明確性原則。→ 對應講義第 19 頁的健保法條文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「授權明確性原則審查的對象？」 | **授權的法律**（授權條款），不是命令本身 |
| 「授權明確性要求什麼？」 | 授權之**目的、內容及範圍**應具體明確（釋字 313） |
| 「授權要多明確？」 | 視命令對人民權利的**影響程度**：影響越大，越要具體明確 |
| 「法律僅寫『○○規則由主管機關定之』可以據以處罰嗎？」 | **不可**：裁罰性規定須具體明確授權（釋字 394） |
| 「授權明確性與法律保留的關係？」 | 授權過於寬鬆 → 等於沒有授權 → **架空法律保留** |
| 「健保法 §66 I 的特約授權是否明確？」 | **明確**：列出資格、程序、審查基準、不予特約條件、違約處理 |

## 一、兩個條文放在一起比

| | 健保法 §66 I | 建築法 §15 II |
|---|---|---|
| 授權給誰 | 主管機關 | 內政部 |
| 授權寫了什麼 | 特約的資格、程序、審查基準、不予特約條件、違約處理…… | 只有「營造業管理規則，由內政部定之」 |
| 對人民的影響 | 特約與否、違約處理對醫事機構影響很大 | 規則中的處罰影響營造業者權利 |
| 結論 | 授權明確 | 概括授權，處罰部分不夠明確 |

## 二、兩層把關

```
第一層：法律保留（筆記 07）
  權利重要性 ──對應──→ 規範位階（憲法／法律／授權命令／命令）
        │
        │ 已決定「由法律授權命令」
        ▼
第二層：授權明確性
  命令對權利的影響大小 ──對應──→ 授權條款的明確程度
```

- 為什麼還要第二層：行政機關比較不可控，每個機關的人、積極程度、能力不同；授權寫得越清楚，命令的差異越小。
- 寫太寬鬆就是「聽君一席話，如聽一席話」：法律把什麼都交給命令，命令什麼都能限制 → 又回到違反法律保留。

## 三、下堂預告：違規停車可以連續處罰嗎

- 情境：機車違停，警察開單；兩小時後車還在，能不能再開第二張？
- 違停是一個**行為**，但造成**持續的違法狀態**；處罰的標的是行為還是狀態？
- 若處罰的是狀態，連續處罰有道理；但間隔兩小時會不會太短？
- 老師說下堂接著講**法律明確性原則**，把講義第二本講完後進入基本權。
