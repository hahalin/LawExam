# 憲法07 筆記：基本權主體與人權、國民權、公民權（增修§11）

## 基本權是什麼：
- 憲法給人民的權利，白話定義就是**對抗國家**（避免國家過度侵害）
- 比例原則、信賴保護、法律明確性都是幫人民對抗國家的工具

## 考試第一步先問「他有沒有這個基本權」：
- 自然人：權利能力原則**始於出生**；胎兒是否為基本權主體是未來的大爭議
- 行為能力：憲法多數基本權沒設年齡；**參政權**有明文年齡門檻
- 外國人：用**人權／國民權／公民權**三分（非常愛考）
- 大陸地區人民：**增修 §11** 允許法律特別規定 → 大法官多採**寬鬆**審查
- 法人：有言論自由、財產權，**沒有人身自由**

## 📖 法條原文速查

> **憲法增修條文 §11**（兩岸人民關係）　自由地區與大陸地區間人民權利義務關係及其他事務之處理，得以法律為**特別之規定**。

> **憲法 §130**（選舉年齡）　中華民國國民年滿**二十歲**者，有依法選舉之權。除本憲法及法律別有規定者外，年滿**二十三歲**者，有依法被選舉之權。

> **憲法 §17**（參政權）　人民有選舉、罷免、創制及複決之權。

> **民法 §6**　人之權利能力，始於出生，終於死亡。

> **民法 §7**　胎兒以將來非死產者為限，關於其個人利益之保護，視為既已出生。

> **民法 §12**　滿十八歲為成年。

> **公民投票法 §7**　中華民國國民，除憲法另有規定外，年滿**十八歲**，除受監護宣告尚未撤銷者外，有公民投票權。→ 建議查閱最新六法原文

> **優生保健法 §9 II**　有配偶者，依前項第六款規定施行人工流產，應得**配偶之同意**。但配偶生死不明或無意識或精神錯亂者，不在此限。→ 建議查閱最新六法原文（本法有修法更名討論）

> 字號校正：老師口誤說「憲法第 11 條」，指的是**憲法增修條文第 11 條**；憲法本文 §11 是言論自由。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「外國人享有選舉權（§17）？」 | **不享有**：參政權屬**公民權**，展現國民主權 |
| 「外國人在臺灣的工作權？」 | **國民權**：本國人優先，外國人須申請許可 |
| 「外國人的生命權、人身自由？」 | **人權**：與本國人相同保障 |
| 「法律對大陸地區人民與外國人差別待遇，違反平等？」 | 增修 **§11** 得為**特別規定** → 立法裁量較大，審查**寬鬆**；對陸人較好或較差都「似乎沒有不行」 |
| 「法人得主張哪些基本權？」 | 依性質：言論自由、財產權可以；**人身自由不行** |
| 「憲法對選舉、被選舉年齡的規定？」 | 選舉 **20 歲**、被選舉 **23 歲**（§130）；公投 18 歲是**法律**規定 |
| 「平等權的核心？」 | **合理的差別待遇**，不是齊頭式平等 |

## 一、基本權的白話定義：對抗國家

```
國家（公權力）
   ▲
   │ 基本權：「太嚴重了！」＝ 主張國家過度侵害
   │
人民
```

- 例：紅燈右轉唯一死刑 → 大家都覺得「太嚴重」，這個「太」就是在對抗國家。
- 民主國家人民可以對抗國家：有道理就勝利，沒道理才可能被處罰；威權國家對抗就會被處罰。
- 老師舉白紙運動：參與者「不知道怎麼抗議」。在臺灣，上街是集會遊行（§14）、舉標語是言論自由（§11）、讓媒體報導是新聞自由，接著還可以投票、倡議，一連串都是基本權在對抗國家。

## 二、自然人：權利能力與行為能力

### （一）權利能力：何時開始可以對抗國家

| | 原則 | 例外／爭議 |
|---|---|---|
| 民法 | 始於出生、終於死亡（§6） | 胎兒以將來非死產為限，個人利益視為既已出生（§7，如繼承） |
| 憲法 | 原則以出生認定 | **胎兒是否為基本權主體**：可能成為未來重大爭議 |

- 胎兒若是基本權主體 → 誰替他決定？母親？父親？
- 現行法：有配偶者依特定事由人工流產，須得配偶同意（優生保健法 §9 II）。
- 老師立場：不應需要男方同意；思考胎兒權利時，必須把**性別議題**一起拉進來，否則忽略女性承擔的懷孕負擔。

### （二）行為能力：幾歲可以行使

| 基本權 | 憲法有無年齡門檻 | 說明 |
|---|---|---|
| 參政權（§17） | **有**（§130） | 選舉 20 歲、被選舉 23 歲；公投 18 歲是公投法規定 |
| 民法完全行為能力 | （民法） | 18 歲成年 |
| 言論自由、集會遊行 | **沒有** | 要個案判斷；例：2015 年反課綱微調，很多高中生上街 |

- 一歲嬰兒的言論自由怎麼保障？哭可能有各種原因，很難判斷，屬於永恆的困境。

## 三、外國人：三分法（非常愛考）

| 類型 | 意義 | 外國人 | 例 |
|---|---|---|---|
| **人權** | 普世價值，不分國籍、種族、性別 | 與本國人**相同** | 生命權、人身自由 |
| **國民權** | 有優先順序：本國人優先 | 須取得資格、許可 | 工作權 |
| **公民權** | 展現政治權利、國民主權 | **絕對不能擁有** | 選舉權、參政權（§17） |

- 考試順序：先判斷某甲是哪國人、**有沒有這個基本權**，有才進入比例原則審查；沒有就不用往下。
- 外國人上街抗議有爭議：簽證有類型限制（觀光簽、工作簽），有些權利在外國人身上會受限制。

## 四、大陸地區人民：增修 §11

```
增修 §11「得以法律為特別之規定」
        │
        ├── 立法院就兩岸人民權利義務有較大形成空間
        │
        └── 大法官 → 尊重立法 → 審查基準傾向「寬鬆」
```

- 平等權的核心是**合理的差別待遇**（例：女廁應該比男廁大才公平）。
- 對中國人比外國人好可不可以？似乎沒有不行。比外國人差可不可以？似乎也沒有不行。理由都是增修 §11 的「**特別**」兩字。
- 體系架構仍用人權／國民權／公民權，只是論述上容許較寬或較嚴的規範。

## 五、法人

- 法人是擬制的人：可以打廣告（**言論自由**）、可以賺錢（**財產權**）。
- 法人不會被關 → 沒有**人身自由**（被關的是法人底下的自然人）。
- 基本權都是以自然人打造的，法人只擁有其中幾個。
- 講義第 4～5 頁公法私法區分（雙階理論、前公後私），考點落在行政法，老師跳過。
