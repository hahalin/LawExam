# 憲法17 筆記：立法院的職權與五院的法律案提案權（釋字3與175）

## 立法權只指狹義的法律：
- 憲法 §62：立法院是國家最高立法機關，代表人民行使**立法權**
- 這裡的「法」是**狹義的法律** → 只有立法院能制定法律
- 縣市議會可以制定**自治條例**，但自治條例不是法律，位階低於法律

## 「議決」不等於「提案」：
- §63：立法院有權**議決**法律案、預算案等 → 最後由立法院決定，但不代表只有立法院能提案
- 法律案：**五院都可以提**，依據不同
  - 行政院、考試院：憲法明文；立法院：本身職權
  - 監察院：**釋字 3**；司法院：**釋字 175**（體系解釋：其他院都可以，我也可以）
  - **總統**：沒有任何規範賦予提案權

## 會期與臨時會：
- 每年兩次常會：**2 月至 5 月底**、**9 月至 12 月底**（§68）；其餘月份休會，但幾乎每年都開臨時會
- 臨時會：**總統咨請**或**立委 1/4 以上請求**（§69）

## 📖 法條原文速查

> **憲法 §62**　立法院為國家**最高立法機關**，由人民選舉之立法委員組織之，代表人民行使**立法權**。

> **憲法 §63**　立法院有**議決**法律案、預算案、戒嚴案、大赦案、宣戰案、媾和案、條約案及國家其他重要事項之權。

> **憲法 §67**　I 立法院得設各種委員會。II 各種委員會得邀請政府人員及社會上有關係人員到會**備詢**。

> **憲法 §68**　立法院會期，每年兩次，自行集會，第一次自**二月至五月底**，第二次自**九月至十二月底**，必要時得延長之。

> **憲法 §69**　立法院遇有左列情事之一時，得開臨時會：一、**總統之咨請**。二、立法委員**四分之一以上**之請求。

> **憲法 §58 II**（行政院提案）、**§87**（考試院提案）→ 條文建議查閱最新六法原文

## 📋 釋字速查

> **釋字 3 號**：監察院關於所掌事項，得向立法院**提出法律案**（依五院體制的體系解釋）。

> **釋字 175 號**：司法院就所掌有關司法機關之組織及司法權行使之事項，得向立法院**提出法律案**。

> → 兩號原文建議查閱司法院網站

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「下列何者**無**法律案提案權？」 | **總統**；五院都有 |
| 「監察院、司法院提法律案的依據？」 | 監察院 **釋字 3**、司法院 **釋字 175**（不是憲法明文） |
| 「立法院常會的期間？」 | **2 月～5 月底**、**9 月～12 月底**（§68） |
| 「立法院臨時會的召開？」 | 總統咨請，或**立委 1/4 以上**請求（§69） |
| 「自治條例是不是法律？」 | **不是**，位階低於法律；制定法律只有立法院 |
| 「委員會邀請政府人員到會叫什麼？」 | **備詢**（§67 II）；院會才叫**質詢**（見 筆記-06） |

## 一、議決與提案

```
法律案的生命週期
提案 ──→ 立法院審議 ──→ 議決（立法院最終決定）
 │
 ├─ 行政院（憲法 §58 II）
 ├─ 考試院（憲法 §87）
 ├─ 立法院（立委本身）
 ├─ 監察院（釋字 3）
 └─ 司法院（釋字 175）
    總統：無
```

- 釋字 3、175 用的是**體系解釋**：五院平行，其他院都能就所掌事項提案，監察院、司法院沒有理由不行。
- 老師：這是一試會考的點。

## 二、委員會與院會

| | 委員會 | 院會 |
|---|---|---|
| 地點 | 小會議室，分組討論法案 | 大議場（2014 年學運佔領的就是這裡） |
| 對官員 | **備詢**（§67 II） | **質詢**（增修 §3 II ①） |

- 老師：本質上都是在詢問、檢討官員，但憲法用語不同；立法院內部也常混稱為質詢。

## 三、休會不等於沒事

- 1 月、6～8 月休會，像寒暑假；但立委仍有地方與中央事務，而且幾乎每年都開臨時會。

## 四、老師提醒：權力分立以法條題為主

- 司法院、考試院、監察院與地方自治本堂沒有細講；這些在一試多以**選擇題、法條題**出現，看法條即可。
- 權力分立近兩年爭議多（國會改革法案、預算），考試重要性可能提高。
