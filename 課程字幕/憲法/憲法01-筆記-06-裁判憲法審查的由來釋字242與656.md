# 憲法01 筆記：裁判憲法審查的由來（釋字242與656）

## 2022 年前後的差別：
- 2022 年前：大法官審理案件法，只能做**抽象法規範審查** → 叫「大法官解釋」
- 2022 年起：憲法訴訟法，可以審查**裁判** → 叫「憲法判決」（例：113 年憲判字第 9 號）
- 人民最常不爽的不是法律，而是**判決**

## 為什麼需要裁判憲法審查：
- 判決＝法律適用＋**事實**
- 法律本身沒問題，加上個案事實後才出問題 → 舊制只能繞路處理
- 憲訴 §59 的核心三個字：「**該裁判**」

## 兩個繞路的舊案：
- 釋字 242：老兵兩岸重婚，民法 §992 本身合憲，但適用在這種情形違憲
- 釋字 656：名義上審 §195「回復名譽之適當處分」，實際上審的是法院「登報道歉」的見解

> 來源：憲法01 課程字幕 01:43:26 ~ 02:22:36（講義第 6～9 頁）

## 📖 法條原文速查

> **憲訴 §59 I**　人民於其憲法上所保障之權利遭受不法侵害，經依法定程序用盡審級救濟程序，對於所受不利確定終局裁判，或**該裁判**及其所適用之法規範，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> **民法 §985 I**　有配偶者，不得重複結婚。

> **民法 §992**（舊法，已刪除）　結婚違反第九百八十五條之規定者，利害關係人得向法院請求撤銷之。但在前婚姻關係消滅後，不得請求撤銷。→ 現行法重婚為**無效**（§988），建議查閱最新六法原文

> **民法 §195 I**　不法侵害他人之身體、健康、名譽、自由、信用、隱私、貞操，或不法侵害其他人格法益而**情節重大**者，被害人雖非財產上之損害，亦得請求賠償相當之金額。其**名譽被侵害者，並得請求回復名譽之適當處分**。

> **憲法 §22**　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。

## 📋 釋字原文速查

> **釋字 242 號**：國家遭遇重大變故，在夫妻隔離、相聚無期，甚或音訊全無、生死莫卜之情況下所發生之重婚事件，有不得已之因素存在，與一般重婚事件究有不同。對於此種有長期實際共同生活事實之後婚姻關係，仍得適用 §992 予以撤銷，嚴重影響其家庭生活及人倫關係，反足以妨害社會秩序，就此而言，與**憲法 §22** 保障人民自由及權利之規定有所牴觸。→ 要旨文字建議查閱原文

> **釋字 656 號**：§195 I 後段「回復名譽之適當處分」，如屬以判決命加害人公開道歉，而**未涉及加害人自我羞辱等損及人性尊嚴**之情事者，即未違背憲法保障不表意自由之意旨（**合憲**）。理由書並稱：確定終局裁判就該規定所表示之見解，非屬聲請解釋之範圍。

> **111 年憲判字第 2 號**：§195 I 後段所稱「適當處分」，**不包括**法院以判決命加害人道歉之情形，否則違反憲法保障人民**不表意自由**之意旨；釋字 656 應予變更。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「憲法訴訟法施行前，人民得否就法院裁判聲請釋憲？」 | **不得**，只能就**法規範**聲請（抽象審查） |
| 「憲法訴訟法如何開放裁判憲法審查？」 | §59 I：不利確定終局裁判，或「**該裁判**」及其所適用之法規範 |
| 「釋字 242 宣告 §992 違憲？」 | **沒有**宣告條文違憲；是**適用於特定情形**（兩岸隔離後的長期後婚）違憲 → 實質上是在審判決 |
| 「釋字 242 侵害的權利？」 | 婚姻自由、家庭生活 → **憲法 §22** |
| 「登報道歉合憲嗎？」 | 釋字 656：**合憲**（限縮）；**111 年憲判字第 2 號：違憲**，變更 656 |
| 「111 憲判 2 認為侵害什麼？」 | **不表意自由**（言論自由的消極面） |
| 「§195 條文有寫登報道歉嗎？」 | **沒有**，只寫「回復名譽之適當處分」；登報道歉是**法院的見解** |

## 一、判決 ＝ 法律 ＋ 事實

| | 抽象法規範審查 | 裁判憲法審查 |
|---|---|---|
| 審什麼 | 條文本身合不合憲 | 法院適用條文到個案的結果 |
| 需不需要事實 | 不需要（通姦罪違憲是因為處罰本身） | **需要**（法律沒問題，加上事實才有問題） |
| 結論 | 條文違憲失效 | 裁判違憲，廢棄發回 |
| 名稱 | 大法官解釋 | 憲法判決 |

## 二、釋字 242：老兵重婚的故事

```
1930s  A 在中國與 B 結婚，生 2 名子女
1940s  國共內戰，A 隨國民黨來臺 → 與 B 音訊全無
       三年、五年、十八年過去 → A 在臺灣與 C 結婚，生 3 名子女
1980s  開放兩岸探親 → B 等了 30 年來臺，發現 A 已再婚
       B 依舊 §992 訴請撤銷 A、C 的後婚 → 法院：整個中國都是中華民國 → 重婚 → 得撤銷
       A 聲請釋憲 → 釋字 242
```

- 問題不在「不得重婚」這條規定，而在**兩岸分治這個事實**。
- 大法官沒宣告 §992 違憲，而是說「這種情形」適用 §992 違憲 → 白話：**A 的判決違憲**。
- 當時批評：大法官只能抽象解釋，242 實質上在審判決；之後類似案件多被不受理。

## 三、釋字 656 → 111 年憲判字第 2 號：登報道歉

```
§195 I 後段：回復名譽之適當處分（條文）
        ＋ 法院見解：命登報道歉（適用）
        ＝ 判決
```

- 舊制下大法官說「裁判的見解不在審查範圍」，但 656 實際上審了登報道歉 → 一下說不能、一下又審，標準不一。
- 憲訴法施行後，111 年憲判字第 2 號正式審查並宣告：命登報道歉違憲（強迫不想道歉的人道歉，侵害**不表意自由**）。
- 老師：真心想道歉的人會當庭道歉，被判登報道歉的人沒有一個是真心的。

| 實務見解 | 要旨 |
