# 憲法11 筆記：大學自治與共同必修、軍訓室（釋字380與450）

## 大學與國中小、高中的差別：
- 國中小、高中依**課綱**上課，目的是培養具基本素養的公民 → 教育部可做**適法性＋適當性**監督
- 大學教授自己決定課程、教材、授課內容 → 教育部只能做**適法性監督**
- 擋在中間的框架：**大學自治**（憲法 §11 講學自由的制度性保障）

## 釋字 380：教育部規定共同必修 → 違憲
- 大學法施行細則規定共同必修科目（國文、歷史、軍訓等）由教育部研訂
- 課程設計、科目訂定屬大學自治範圍；施行細則**未經大學法授權** → 違憲

## 釋字 450：法律強制大學設軍訓室 → 違憲
- 大學法與施行細則規定大學應設軍訓室
- 立法機關不得以法律強制大學設置特定單位 → 侵害大學**內部組織自主權**

## 規範與現實的落差：
- 宣告違憲後，各大學仍多保留國文、歷史共同必修與軍訓室 → 既有人力與勢力不會說斷就斷
- 但國家也**不能立法強迫拿掉** → 一樣侵害大學自治

## 📖 法條原文速查

> **憲法 §11**（表現自由）　人民有言論、**講學**、著作及出版之自由。→ 大學自治屬講學自由之保障範圍

> **舊大學法施行細則 §22 III**　共同必修科目由教育部邀集各大學相關人員共同研訂。→ 釋字 380 違憲；條文原文建議查閱司法院解釋原文

> **舊大學法 §11 I ⑥、施行細則 §9 III**　大學應設**軍訓室**。→ 釋字 450 違憲；條文原文建議查閱司法院解釋原文

## 📋 釋字速查

> **釋字 380 號**（1995 年）：憲法 §11 講學自由賦予大學教學、研究與學習之自由，並於直接關涉者享有**自治權**。大學自治範圍包括研究動機之形成、計畫之提出、研究人員之組成、預算之籌措分配、研究成果之發表，以及**課程設計、科目訂定、講授內容、學力評定、考試規則、學生選擇科系與課程之自由、學生自治**。大學課程訂定應由各大學依大學自治與學術責任原則處理；施行細則關於共同必修科目由教育部研訂之規定，**未經大學法授權**，與憲法意旨不符。

> **釋字 450 號**（1998 年）：大學法及其施行細則強制大學設置軍訓室，與憲法保障大學自治之意旨不符。立法機關不得以法律強制大學設置特定之單位，致侵害大學之**內部組織自主權**。

> 字號校正：老師說 380 大約民國 94 年（2005 年）作成；實際為民國 **84 年**（**1995 年**）。字幕「440至450」應為釋字 450。

## 一、適法性監督與適當性監督

| | 適法性監督 | 適當性監督 |
|---|---|---|
| 意義 | 違法才能糾正 | 不違法、但不妥當也能糾正 |
| 例：訴願機關 vs. 原處分機關 | ✓ | ✓（行政一體） |
| 例：行政法院 vs. 行政機關 | ✓ | ✗（權力分立） |
| 教育部 vs. 國中小、高中 | ✓ | ✓ |
| 教育部 vs. 大學 | ✓ | ✗（大學自治） |

## 二、大學自治為什麼是制度性保障

- 制度性保障：沒有這個制度，就沒有這個權利（例：婚姻制度與婚姻自由，見 憲法07-筆記-02）。
- 大學自治要靠制度**杜絕外來干涉**，才能落實學術自由 → 制度性保障。
- 人身自由不是制度性保障：沒有制度，人身自由本來就在。
- 老師引林佳和教授引述的故事：1948 年艾森豪任哥倫比亞大學校長，就職演說時一位教授起身說：「We are not the employees of Columbia University. We are Columbia University.」→ 教授本身就是大學。

## 三、軍訓室的歷史背景（老師口述）

- 學校設軍訓人員有其威權時期背景：監督校園內師生思想。
- 今日教官的工作與當年不同，但「人很好」不是制度存廢的判準。
