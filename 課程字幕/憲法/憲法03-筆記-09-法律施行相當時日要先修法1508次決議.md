# 憲法03 筆記：法律施行相當時日要先修法（1508次決議）

## 規則：
- 法律公布施行經**相當時日**，立委認有違憲疑義 → 應**先提出修正案**，**修法未果**後才能聲請（大法官第 1508 次會議不受理決議；113 年憲裁字第 16 號沿用）

## 兩條路徑怎麼選：
- **剛通過**的法律 → 路徑一：好好阻擋，失敗後**立刻**聲請（筆記 07）
- **已施行一段時間** → 路徑二：先修法，修法未果再聲請（筆記 08）

## 為什麼：
- 拖很久才聲請 → 代表沒那麼反對 → 不是不得已
- 中間經過改選 → 聲請的人已不是當年反對的那批；若已成多數，自己修法就好

> 來源：憲法03 課程字幕 02:17:31 ~ 02:27:02（講義第 37 頁）

## 📖 法條原文速查

> **憲訴 §49**　立法委員現有總額四分之一以上，**就其行使職權**，認法律位階法規範牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

---

## 📋 決議／憲裁速查

> **大法官第 1508 次會議不受理決議**（2020/8/28）：林為洲等 38 位立委就**農田水利會組織通則 §40**（2018/1/31 修正公布）聲請。「倘法律公布施行經**相當時日**，立法委員認有違憲疑義，自應**先行提出修正案**」，修法未果後始得聲請（與釋字 603「修法未果」意旨相符）；聲請人未先提出修正案，不符「行使職權」要件 → **不受理**。→ 決議文字建議查閱原文

> **113 年憲裁字第 16 號**（2024/5/24）：沿用同一句——法律公布施行經相當時日，應先行提出修正案，並於確定修法未成後，再由四分之一以上立委聲請。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律施行多年後，立委才聲請釋憲，要件？」 | 須**先提出修正案**且**修法未果**（第 1508 次會議） |
| 「當年二讀、三讀都投反對票，兩年後聲請，可以嗎？」 | **不行直接聲請**：已經過相當時日，要走**先修法**的路徑 |
| 「兩條路徑是否衝突？」 | **不衝突**：剛通過 → 立刻聲請；過一段時間 → 先修法 |
| 「判斷立委聲請的解題順序？」 | §49 → 判斷**行為樣態**（阻擋／修法）→ 對照案例 |

## 一、課堂題：B 黨 2025 年聲請

```
2023  A 黨通過 X 法案
      B 黨 40 人：二讀反對、二讀進三讀反對、三讀也反對（反對行為無瑕疵）
        │
        │   中間：立委改選
        │
2025  B 黨提出釋憲聲請
```

- 錯誤答案：B 黨二讀、三讀都投反對票 → 符合釋字 781 → 可以聲請。
- 正確思考：
  1. **時間**：拖了兩年才聲請 → 代表其實沒那麼反對 → 沒有不得已。
  2. **人**：中間改選，2025 年的 B 黨立委和 2023 年反對的 40 人已經不同 → 當事人適格有問題。
  3. 若 B 黨改選後已成多數（例：60 席），自己修法就好，還來聲請是浪費司法資源。
- 結論：應先提出修正案，**修法未果**後，才走路徑二聲請。
- 真實案例對照：第 1508 次會議的農田水利會組織通則，2018 年修正公布、2020 年才聲請，中間也經過立委改選。

## 二、兩條路徑的關係

```
你不滿某部法律
   │
   ├── 剛通過、熱騰騰 → 路徑一：有沒有「好好阻擋」？
   │                    （1476 次決議、釋字 781）→ 立刻聲請
   │
   └── 已施行相當時日 → 路徑二：有沒有「修法未果」？
                        （釋字 603、113 憲裁 16、1508 次決議）
```

- 兩條路**不衝突**：反對失敗後，理論上也可以立刻提修正案、修法失敗再聲請；只是沒必要——已經知道你是真心反對，就不強迫你再提一次修正案。
- 路徑一的重點是「**立刻**」；路徑二是因為「已經過有點久」。
- 共同的核心：**有沒有不得已的失敗**。

## 三、考試解題步驟

1. 看到立委聲請 → 先寫 §49（四分之一、行使職權）。
2. 判斷題目是哪一種**行為樣態**：不想修法（好好阻擋）或想修法（修法未果）；施行已久的，要先修法。
3. 對照題目事實與案例（1476、781、603、113 憲裁 16、1508），畫樹狀圖找最接近的那一支。

- 老師：立委聲請是憲法訴訟最愛考的部分，重要性與日俱增。
- 下一講：講完立委，接著國家最高機關、地方自治團體，把憲法訴訟法講完；之後進入憲法的四大支柱其他部分（憲法原理原則、基本權、權力分立）。
