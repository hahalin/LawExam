# 憲法01 筆記：法律命令與判例決議作為審查客體

## 不是每個主體都能不爽每個客體：
- 法律、命令原則上都能成為審查客體（法律被刪除後，受影響者仍可聲請）
- **立委**只能就**法律位階以上**聲請（§49）：立法院不會訂命令
- **法官**只能就**法律位階**聲請（§55）：命令、函釋自己就能處理

## 法官依法審判的「法」＝法律：
- 釋字 137、216：法官不受行政命令、函釋拘束
- 法官可在個案中認定命令違憲、**不予適用**（只有個案效力）
- 既然自己能處理，就不是「不得已」→ **不得就命令聲請**

## 判例與決議已走入歷史：
- 判例、決議不是法律，卻曾實質拘束下級審
- 人民以前可就判例、決議聲請；法官不行 → 矛盾

## 📖 法條原文速查

> **憲訴 §49**　立法委員現有總額四分之一以上，就其行使職權，認**法律位階法規範**牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> **憲訴 §55**　各法院就其審理之案件，對裁判上所應適用之**法律位階法規範**，依其合理確信，認有牴觸憲法，且於該案件之裁判結果有直接影響者，得聲請憲法法庭為宣告違憲之判決。

> **憲法 §80**　法官須超出黨派以外，依據**法律**獨立審判，不受任何干涉。

---

## 📋 釋字原文速查

> **釋字 137 號**：法官於審判案件時，對於各機關就其職掌所作有關法規釋示之行政命令，固未可逕行排斥而不用，但仍得依據法律，表示其合法適當之見解。

> **釋字 216 號**：法官依據法律獨立審判，各機關所發有關法規釋示之行政命令，法官於審判案件時**不受其拘束**。→ 要旨文字建議查閱原文

> **釋字 154 號**：最高法院及行政法院**判例**，在未變更前有其拘束力，可為各級法院裁判之依據，如有違憲情形，得為聲請解釋之對象。→ 要旨文字建議查閱原文

> **釋字 374 號**：最高法院民刑庭總會**決議**，與命令相當，得為人民聲請解釋之對象。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法律已廢止，仍得聲請法規範憲法審查？」 | **可以**，若權利是在廢止前受該法律影響 |
| 「立委得否就行政命令聲請？」 | **不得**，§49 限**法律位階**法規範 |
| 「法官得否就行政命令或函釋聲請？」 | **不得**，§55 限法律位階；法官可自行在個案不予適用，無「不得已」 |
| 「法官得否在個案中認定命令或函釋違憲而不適用？」 | **可以**（釋字 137、216）；效力只及於**個案**，上訴審仍可能適用 |
| 「大法官宣告命令違憲的效力？」 | 失效，對所有人都不再適用 |
| 「法官依法審判的『法』？」 | **法律**（不含命令、函釋、判例、決議） |
| 「以前人民可否就判例、決議聲請？」 | **可以**（釋字 154、374）；法官**不行** |

## 一、主體 × 客體的組合

| 客體 \ 主體 | 人民 | 立委 1/4 | 法官 |
|---|---|---|---|
| 憲法、法律 | ✓ | ✓ | ✓（法律位階） |
| 命令、函釋 | ✓ | ✗（立法院不訂命令） | ✗（可自行不予適用） |
| 判例、決議（舊制） | ✓ | — | ✗ |

## 二、法官遇到違憲的命令怎麼辦

```
法官認命令／函釋違憲
   ├── 可以在本案拒絕適用（個案效力）
   │      └── 上訴二審：該命令仍存在，二審可能照用
   └── 不可聲請憲法法庭 ← 自己能處理，沒有「不得已」
        （大法官：你自己可以處理，不要來找我）
```

- 對比：大法官宣告命令違憲 → 命令失效、歸零。
- 行政機關最常用的工具是**函釋**；老舊函釋常有問題，是後面課程的重點素材。

## 三、判例與決議的矛盾（舊制）

```
判例／決議 不是法律
   ├── 下級審沒引用 → 可能被撤銷發回（實質上像法律）
   └── 法官想聲請釋憲 → 「不是法律，不能聲請」
```

- 許宗力大法官在意見書中批評；後來法制改革，判例、決議制度走入歷史，重要性下降。
