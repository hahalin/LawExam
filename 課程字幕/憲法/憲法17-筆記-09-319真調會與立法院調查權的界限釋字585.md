# 憲法17 筆記：319真調會與立法院調查權的界限（釋字585）

## 事實：
- 2004 年總統大選前一天發生 319 槍擊案，選舉結果差距極小，落選陣營質疑
- 立法院多數通過「三一九槍擊事件真相調查特別委員會條例」，成立**真調會**，設在**立法權**底下

## 大前提：放在立法權底下，就只能做立法權能做的事
- 立法院調查權是**輔助**立法院行使職權的權力，與**犯罪偵查權、審判權**不同
- 真調會的權限不能超過立法院本身；不能剝奪行政權、司法權、監察權

## 真調會條例被宣告違憲的幾個點（依老師講義）：
- 第 8 條：槍擊案刑事責任案件的**偵查專屬真調會**、真調會行使**檢察官**權限、各機關應移交全部案件 → 逾越立法院調查權範圍
- **借調檢察官**：須經所屬機關**同意**；借調期間**不得行使檢察權**（已不是檢察官）
- 調查結果與法院確定判決**歧異者得為再審理由** → 侵犯法官對再審的判斷
- 要求真調會向**監察院**提出報告 → 混淆兩院不同的調查權
- 行使職權**不受國家機密保護法、營業秘密法、刑事訴訟法**等規定限制 → 不尊重行政權與法治

## 585 肯定的部分：
- 立法院有**調查權**（不限於文件調閱），必要時得經院會決議要求人民或政府人員**陳述證言**，並得以罰鍰為合理強制手段
- 委任**非立委**協助調查（老師稱「外包」）須以**特別法**明定，不能無限擴張

## 📋 釋字速查

> **釋字 585 號**（2004 年 12 月）要旨：
> - 立法院調查權乃立法院行使其憲法職權所必要之**輔助性權力**；與追訴犯罪之偵查權、審判權有別。
> - **獨立行使職權**之國家機關所掌事項，以及行政首長依其行政權固有權能享有之**行政特權**事項，立法院應予適當尊重。
> - 調查方式除調閱文件外，必要時得經院會決議，要求與調查事項相關之人民或政府人員**陳述證言或表示意見**，並得對違反協助調查義務者，於科處**罰鍰**之範圍內施以合理之強制手段 → **補充** 釋字 325。
> - 調查權之發動、組織、範圍、方法及司法救濟等應以**法律**規範；委任**非立法委員**協助調查者，應制定特別法，並遵守權力分立、比例原則等。
> - 真調會條例多條違憲（偵查專屬、檢察官權限、借調檢察官行使檢察權、再審理由、向監察院報告、不受國家機密保護法等規定）。→ 違憲條次與失效時點建議查閱司法院網站

> 字號校正：字幕「4至585」即**釋字 585**；老師說「458 號講到可不可以外包」，推定為 585 本身關於委任非立委協助調查的部分，建議查證。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「立法院調查權的性質？」 | **輔助性權力**，用以行使憲法職權（585） |
| 「立法院調查委員會可否行使檢察官的偵查權？」 | **不可**：調查權與偵查權、審判權有別 |
| 「借調的檢察官在真調會可否行使檢察權？」 | **不可**；且借調須經所屬機關同意 |
| 「調查結果與確定判決歧異得為再審理由？」 | **違憲**：侵犯司法權 |
| 「立法院能否要求人民到場陳述證言？」 | **可以**，經院會決議，並得以罰鍰合理強制（585） |
| 「委任非立委協助調查？」 | 須制定**特別法** |
| 「585 與 325 的關係？」 | 585 **補充** 325：從文件調閱擴及對人調查 |

## 一、真調會侵犯了哪些權

```
真調會（放在立法權底下）
├── 偵查專屬、行使檢察官權限、案件移交 → 侵犯 行政權（檢察）
├── 調查結果歧異得為再審理由 ─────── → 侵犯 司法權
├── 向監察院提出報告 ─────────── → 混淆 監察權
└── 不受國家機密保護法等限制 ─────── → 侵犯 行政權
    （只差考試權沒碰到 —— 老師戲稱「大滿貫」）
```

## 二、借調者的身分

- 借調到真調會的檢察官，在真調會裡是**委員**，不是檢察官 → 不能行使檢察權。
- 類比：曾任法官的立委，現在是立委，不能因為以前是法官就判案。

## 三、再審為什麼由法官決定

- 案件受不受理、上訴是否駁回、是否開啟再審，都由法院依法決定；再審開啟比例很低（老師說約千分之六）。
- 條例讓真調會的結論足以構成再審理由，等於由立法機關決定法院要不要重審。

## 四、課後問答：調查委員會放在哪一權比較好

| 放在 | 優點 | 疑慮 |
|---|---|---|
| 立法權 | 避免球員兼裁判（行政首長本身是調查對象時） | 立法權負責監督，不負責執行 |
| 行政權 | 行政權範圍廣，可作成行政處分（例：黨產會、運安會） | 調查對象若是行政首長，球員兼裁判 |
| 監察院 | 本來就有調查權 | — |

- 老師：真調會最大的問題不是放在哪裡，而是**條例賦予了不合理的權限**；若不剝奪偵查權、審判權，放在立法院也未必不合理。
- 老師另提：調查權分散在行政、立法、監察；若要乾淨，可廢監察院、把調查權回歸國會（北歐國會監察使），但那些國家是內閣制，脈絡不同。
