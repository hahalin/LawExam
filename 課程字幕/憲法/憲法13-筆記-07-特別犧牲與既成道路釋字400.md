# 憲法13 筆記：特別犧牲與既成道路（釋字400）

## 財產權單元的重點：特別犧牲
- 一般犧牲：為公益限制財產權，只要正當就好（紅燈不准右轉 → 不會要求國家補償）
- **特別犧牲**：限制本身不是不合理，但**太超過**了，逾越社會責任應忍受的範圍 → 國家要**補償**
- 要學的是：什麼情況下算「太超過」

## 案例：既成道路
- 私人土地日積月累被當成道路使用，成為社區、村落的**既成道路**
- 政府以公用地役關係為由讓公眾通行，卻**不徵收、不補償**
- 地主：土地已等於國家在用，自己無法使用，又拿不到錢 → 聲請解釋

## 既成道路成立公用地役關係的三要件：
- ① 為**不特定公眾**通行所必要（不是只為了通行便利或省時）
- ② 公眾通行之初，土地所有人**並無阻止**
- ③ 經歷**年代久遠**而未曾中斷

## 400 的結論與問題：
- 既成道路形成特別犧牲 → 國家**應依法辦理徵收、給予補償**
- 但又說：各級政府如因**經費困難**，得**定期籌措財源、逐年辦理**或以他法補償
- 沒說不徵收的後果 → 效力大打折扣（規範與現實的落差）

## 📖 法條原文速查

> **憲法 §15**　人民之生存權、工作權及**財產權**，應予保障。

> **憲法 §23**　以上各條列舉之自由權利，除為防止妨礙他人自由、避免緊急危難、維持社會秩序，或增進公共利益所必要者外，不得以法律限制之。

## 📋 釋字速查

> **釋字 400 號**（1996 年）：既成道路成立公用地役關係，首須為不特定公眾通行所必要，而非僅為通行之便利或省時；其次，於公眾通行之初，土地所有權人並無阻止之情事；其三，須經歷之年代久遠而未曾中斷，所謂年代久遠雖不必限定其期間，但仍應以時日長久，一般人無復記憶其確實之起始為必要。
> 如因公用或其他公益目的之必要，國家機關雖得依法徵收人民之財產，但應給予相當之補償，方符憲法保障財產權之意旨。既成道路符合一定要件而成立公用地役關係者，其所有權人對土地既已無從自由使用收益，形成因公益而**特別犧牲**其財產上之利益，國家自應依法律之規定辦理徵收給予補償；各級政府如因經費困難，不能對上述道路全面徵收補償，有關機關亦應**訂定期限籌措財源逐年辦理**或以他法補償。→ 原文建議查閱司法院網站

> 字號校正：字幕「四至400號」「4400號」即釋字 400；「繼承道路」即「既成道路」。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「什麼是特別犧牲？」 | 為公益限制財產權，**逾越社會責任應忍受範圍** → 應**補償** |
| 「既成道路成立公用地役關係的要件？」 | 不特定公眾通行所**必要**；通行之初所有人**未阻止**；**年代久遠**未中斷 |

| 「既成道路所有人可否請求補償？」 | 國家**應**辦理徵收補償（400） |
| 「政府經費困難怎麼辦？」 | 訂定期限籌措財源**逐年辦理**或以他法補償 |
| 「400 的弱點？」 | 未規定不徵收的效果 → 規範與現實落差（對照 747 要求一年內修法） |

## 一、一般犧牲與特別犧牲

```
為公益限制財產權
   ├── 一般犧牲：在社會責任應忍受範圍內 → 不補償（紅燈不准右轉）
   └── 特別犧牲：逾越應忍受範圍（太超過）→ 應補償（徵收、既成道路）
```

## 二、為什麼政府不想徵收

- 不徵收：不用花錢，道路照樣公用 → 維持現狀對政府最有利。
- 400 之前：國家說無法處理；400 之後：國家知道要徵收，但「不徵收你能怎樣」。
- 訴訟上，地主常要舉證道路公共化的起點（例如用祖父的日記）。

## 三、三號特別犧牲對照（詳見筆記-08、09）

| 釋字 | 被犧牲的是什麼 | 大法官怎麼處理 |
|---|---|---|
| **400** | 土地所有權（既成道路） | 應徵收補償；經費困難可逐年辦理 |
| **747** | 土地上空、地下（隧道穿越） | 一年內修法；未修法前依解釋請求徵收地上權 |
| **813** | 土地上建物被登錄為歷史建築 | 欠缺相當補償，違憲 |
