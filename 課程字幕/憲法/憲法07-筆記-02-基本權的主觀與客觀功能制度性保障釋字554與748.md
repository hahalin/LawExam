# 憲法07 筆記：基本權的主觀與客觀功能、制度性保障（釋字554與748）

## 主觀功能：人民不爽可以請法院救濟
- **防禦權**：國家不要過度侵害我（「你不要這樣做」）→ 大法官解釋、憲法判決 99% 處理這個
- **給付權**：國家不多做一點就侵害我（「你得這樣做」）→ 多出現在行政法，如申請低收入戶被駁回提課予義務訴訟

## 客觀功能：基本權同時拘束國家
- **保護義務**：最常侵害你的是其他人民 → 國家要打造刑法、警察、國家賠償等制度
- **程序保障**：正當法律程序（上堂釋字 709）
- **組織與制度性保障**：有些基本權必須依賴制度才能實現

## 制度性保障的經典轉變：婚姻
- 釋字 554：婚姻與家庭受**制度性保障**，制度（一夫一妻）決定了婚姻自由的長相
- 釋字 748：婚姻自由是建立**親密性、排他性之永久結合關係**，國家應提供制度 → 從制度變成權利

> 來源：憲法07 課程字幕 00:30:31 ~ 00:49:45（講義第三本第 7～11 頁）

## 📖 法條原文速查

> **憲法 §15**　人民之生存權、工作權及財產權，應予保障。

> **憲法 §16**（訴訟權）　人民有請願、訴願及訴訟之權。

> **憲法 §18**（應考試服公職）　人民有應考試服公職之權。

> **刑事訴訟法 §376 I**（不得上訴第三審）　最重本刑為三年以下有期徒刑、拘役或專科罰金之罪，以及竊盜、侵占、詐欺、背信、恐嚇取財、贓物等罪之案件，經第二審判決者，原則不得上訴於第三審法院。→ 各款內容建議查閱最新六法原文

## 📋 釋字速查

> **釋字 554 號**（2002 年）：婚姻與家庭為社會形成與發展之基礎，受憲法**制度性保障**。婚姻係一夫一妻為營永久共同生活，並使雙方人格得以實現與發展之生活共同體；因婚姻而生之永久結合關係，不僅使夫妻在精神上、物質上互相扶持依存，並延伸為家庭與社會之基礎。→ 原文建議查閱司法院網站

> **釋字 748 號**（2017 年）：民法婚姻章未使相同性別二人，得為經營共同生活之目的，成立具有**親密性及排他性之永久結合關係**，於此範圍內，違反憲法 §22 婚姻自由及 §7 平等權。

> 字號校正：字幕「4至55」即**釋字 554**；「4748」即**釋字 748**。

|---------|---------|
| 「基本權的主觀功能？」 | **防禦權**（請國家不要侵害）＋**給付權**（請求國家作為）；可請求法院救濟 |
| 「基本權的客觀功能？」 | **保護義務**、**程序保障**、**組織與制度性保障**；拘束國家 |

| 「釋字 554 對婚姻的定位？」 | 婚姻與家庭受**制度性保障**，一夫一妻 |

| 「大法官解釋多處理哪種功能？」 | **防禦權**；給付權多在行政訴訟處理 |

## 一、基本權功能總覽

```
基本權
├── 主觀公權利（人民可請求法院救濟）
│   ├── 防禦權：國家不要過度侵害 → 例：沒紅燈右轉卻被罰，提起訴訟
│   └── 給付權：國家要積極作為   → 例：低收入戶申請被駁回，課予義務訴願、訴訟（§15 生存權）
│
└── 客觀法規範（拘束國家，人民不一定能直接請求救濟）
    ├── 保護義務：防止人民被其他人民侵害
    ├── 程序保障：正當法律程序
    └── 組織與制度性保障：依賴制度才能實現的基本權
```

- 老師說這是基本權「主要的五個功能」，簡單記即可。
- 給付權比較常出現在行政處分：我想拿但沒拿到 → 行政救濟。

## 二、國家保護義務：威爾康西餐廳

- 臺中威爾康西餐廳大火：逃生走道堆滿雜物，大量顧客無法逃出，死傷慘重（老師說燒死六七十人；一般記載為 1995 年、64 人罹難）。
- 堆雜物是餐廳的錯，但國家沒有把消防安全制度做到位 → **國家保護義務**做得不夠。
- 日常生活中最常侵害你基本權的是**其他人民**，所以國家要打造制度：刑法、警察、國家賠償法。
- 國家保護義務最常在**行政法**考。
- 老師的防災補充：有煙先往下逃，逃不掉就關門躲著，不要往上跑。

## 三、制度性保障：權利的「長相」由制度決定

| | 一般基本權（例：言論自由 §11） | 制度性保障（例：訴訟權、婚姻） |
|---|---|---|
| 先有什麼 | 先有權利，再用制度保護 | 制度決定權利長什麼樣子 |
| 國家什麼都不做 | 照樣可以行使 | 無法實現 |
| 例 | 在這裡發言就是言論自由 | 刑事案件能不能上第三審，由刑訴 §376 決定 |

- 參政權接近制度性保障（要有選舉制度才能選），但不是最典型。
- **應考試服公職**最典型：國家要先設 A、B 公務人員考試，才有應考試的權利。

### 婚姻：從制度到權利

```
釋字 554（2002）                    釋字 748（2017）
既有制度 = 一夫一妻                  婚姻自由 = 親密性 + 排他性 + 永久結合
   ↓                                     ↓
婚姻自由 = 一夫一妻                   國家應打造制度，讓任何性別、性傾向的二人
（制度鎖定權利的長相）                  都能建立這種關係（權利決定制度）
```

- 老師評價：554 把婚姻和家庭綁在一起，預設婚姻是為了延續家庭與社會而存在；但婚姻應是一種選擇。大法官的思潮往前走了。
