# 憲法04 筆記：自治法規函告無效須用盡審級救濟（憲訴§83）

## §83 結構像人民聲請：
- 地方自治團體就法定事項，**依法定程序用盡審級救濟**而受不利確定終局裁判，認損害其地方自治權 → 聲請
- 四種主體中只有人民要先打訴訟；§83 跟人民一樣

## 不爽的對象：
- 不是自己的自治法規（那是自己訂的，當然覺得對）
- 不爽的是監督機關的**函告無效**——這是**行政處分**（行政程序法 §92）→ 先打**行政訴訟**
- 大法官不審函告本身（行政權核心），審的是行政法院的**確定終局裁判**

## 例：萊克多巴胺零檢出
- 食安法授權衛福部訂殘留容許量；臺北市等議會自治條例訂「零檢出」
- 衛福部函告自治條例**無效**（牴觸法律、法律優位）→ 地方要先提行政訴訟，用盡審級後才能依 §83 聲請

## 一句話判斷法：
- 憲法訴訟永遠先問「**誰在不爽誰**」：主體、客體、要經過什麼程序，全部包含在裡面

## 📖 法條原文速查

> **憲訴 §83 I**（地方自治團體聲請裁判憲法審查）　地方自治團體，就下列各款事項，依法定程序**用盡審級救濟**而受之不利**確定終局裁判**，認為損害其受憲法所保障之**地方自治權**者，得聲請憲法法庭為宣告違憲之判決：
> 一、**自治法規**，經監督機關**函告無效**或**函告不予核定**。
> 二、其**立法機關議決之自治事項**，經監督機關函告無效。
> 三、其**行政機關辦理之自治事項**，經監督機關撤銷、變更、廢止或停止其執行。
> → 第二、三款文字建議查閱最新六法原文

> **憲訴 §83 II**　前項聲請，應於確定終局裁判送達後**六個月**之不變期間內為之。→ 建議查閱最新六法原文

> **憲訴 §83 III**　第一項案件，準用第六十條、第六十一條及第六十二條第一項規定。→ 準用範圍依老師口述，建議查閱最新六法原文

> **行政程序法 §92 I**（行政處分）　本法所稱行政處分，係指行政機關就公法上具體事件所為之決定或其他公權力措施而對外直接發生法律效果之**單方行政行為**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「自治條例經監督機關函告無效，地方自治團體得否直接聲請憲法法庭？」 | **不得**：先依法定程序**用盡審級救濟**（行政訴訟），受不利確定終局裁判後才能依 §83 聲請 |
| 「函告無效的法律性質？」 | **行政處分**（行政程序法 §92） |
| 「§83 的審查客體？」 | 行政法院的**確定終局裁判**，不是自治法規本身 |
| 「§83 列了哪三款事項？」 | ① 自治法規函告無效或不予核定 ② 議決自治事項函告無效 ③ 辦理自治事項經撤銷、變更、廢止或停止執行 |
| 「§82 與 §83 怎麼分？」 | §82：不爽**中央法規範**（法規範審查）；§83：不爽監督機關的**函告**（先打訴訟，裁判審查） |
| 「自治條例牴觸法律，監督機關可函告無效的原理？」 | **法律優位原則** |

## 一、自治法規是什麼

| | 自治條例 | 自治規則 |
|---|---|---|
| 制定者 | 地方**立法機關**（縣市議會） | 地方**行政機關**（縣市政府） |
| 民主正當性 | 較高（議員民選） | 較低 |
| 法規範位階 | 都屬「其他」：憲法 > 法律 > 其他（命令、自治條例、自治規則） | |

- 自治法規牴觸法律 → 上級機關可函告無效（**法律優位**）。
- 臺灣各地方差異小（語言、宗教、氣候），地方自治權不像美國各州那麼大，仍要遵守法律。

## 二、萊克多巴胺案（舊法故事，新法對齊）

```
食品安全衛生管理法：殘留容許量由衛福部定之（法律授權）
        │
衛福部訂出容許量 → 低於即可進口（美豬）
        │
臺北市議會等：自治條例訂「零檢出」
        │
衛福部：函告自治條例無效（牴觸法律）
        │
各議會不爽 ──→ §82？ ✗ 它們不爽的不是中央法規範
        │
        └──→ 函告無效＝行政處分 → 行政訴訟 → 用盡審級 → §83 ✓
```

- 2012 年開放含萊克多巴胺美牛，當時民進黨反對；後來民進黨執政延續並開放美豬。
- 函告無效是否違法，是**中央與地方權限劃分**的問題，權力分立單元再講。

## 三、為什麼大法官不直接審函告

- 行政處分有行政權的**判斷餘地**，大法官不宜直接審查（就像大法官不能去改水利署的考卷）。
- 大法官能審的是**司法權**的產物：行政法院就函告所作的確定終局裁判。

## 四、誰在不爽誰：外人

| 主體 | 不爽的對象 | 條文 |
|---|---|---|
| 國家最高機關 | 立法院幫它訂的**法規範** | §47 |
| 立委 | 法律 | §49 |
| 法官 | 法律 | §55 |
| 人民 | 法規範或**裁判** | §59 |
| 地方自治團體 | **中央**法規範 | §82 |
| 地方自治團體 | 監督機關的**函告**（經裁判） | §83 |

- 所有主體不爽的都是「外人」：地方不會不爽自己訂的自治法規，它不爽的是衛福部對它說三道四。
