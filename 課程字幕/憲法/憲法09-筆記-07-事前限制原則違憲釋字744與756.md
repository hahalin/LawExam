# 憲法09 筆記：事前限制原則違憲（釋字744與756）

## 事前限制 vs 事後限制：
- **事前**：原則不能講，經國家許可才能講（例：已廢止的**出版法**——出版品要先經國家審核）
- **事後**：原則都可以講，講了有問題才處罰（例：酒的廣告違規，有人檢舉就可能被罰）

## 事前限制是最嚴重的限制：
- 「你不能自由地講，你就不會自由地想」
- 「籠中出生的鳥，以為飛翔是一種病」
- 民主社會出書看出版社要不要你；戒嚴時期出書看國家准不准

## 大法官的態度：
- **釋字 744**：國家對言論之事前審查，原則上應為違憲
- **釋字 756**：援引 744；但對**受刑人**的事前審查不是原則違憲，仍須重要公益目的、實質關聯
- 現行任何審核機制都有違憲風險：不是百分之百違憲，但違憲機率高

## 📋 釋字速查

> **釋字 744 號**（2017 年）：化妝品廣告之事前審查乃對言論自由之重大干預，**原則上應為違憲**。除非立法資料足以支持：為防免人民生命、身體、健康遭受**直接、立即及難以回復**危害之特別重要公共利益目的，手段與目的達成之間具**直接及絕對必要關聯**，且賦予人民獲立即司法救濟之機會，始符合比例原則及保障言論自由之意旨。→ 詳見筆記 09

> **釋字 756 號**（2017 年 12 月 1 日）：監獄檢查受刑人書信、限制投稿等規定部分違憲。理由書援引 744：「國家對一般人民言論之事前審查，原則上應為違憲」；但對**受刑人**言論之事前審查，並非原則違憲，惟因嚴重限制言論自由，其目的須為**重要公益**，手段與目的間須有**實質關聯**。

> 出處存疑：「你不能自由地講，你就不會自由地想」，老師說是「徐大」講的（可能指某位大法官），建議查證。「籠中出生的鳥，以為飛翔是一種病」一般認為出自智利作家 Alejandro Jodorowsky（補充）。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「事前限制與事後限制，何者對言論自由侵害較大？」 | **事前限制** |
| 「國家對一般人民言論之事前審查？」 | **原則上違憲**（釋字 744） |
| 「事前審查例外合憲的要件？」 | 防免生命身體健康遭受**直接、立即、難以回復**危害＋**直接及絕對必要關聯**＋**立即司法救濟**（744） |
| 「對受刑人言論的事前審查也是原則違憲？」 | **不是**：重要公益＋實質關聯（中度審查，釋字 756） |
| 「出版法現況？」 | **已廢止**（1999 年） |

## 一、事前與事後

```
事前限制：原則不能講 ──（國家許可）──→ 才能講
          例：出版法（已廢）、藥物廣告送審（414）、化妝品廣告送審（744 違憲）

事後限制：原則都能講 ──（有問題）──→ 被檢舉、被處罰
          例：酒類廣告違規、選罷法違規
```

| | 事前限制 | 事後限制 |
|---|---|---|
| 人民的感受 | 很害怕，乾脆不講、不想 | 比較不害怕，不一定被罰 |
| 審查基準 | 原則從嚴，原則違憲（744） | 依其他分類決定 |
| 性質 | 跟**許可制**很像 | 跟**處罰**相同 |

## 二、744 與 756 的差別

| | 釋字 744 | 釋字 756 |
|---|---|---|
| 對象 | 一般人民（化妝品廠商） | 受刑人 |
| 事前審查 | 原則違憲 | 非原則違憲 |
| 審查基準 | 嚴格（特別重要公益、直接及絕對必要關聯） | 中度（重要公益、實質關聯） |
