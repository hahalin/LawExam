# 憲法07 筆記：基本權的垂直效力與第三人效力

## 垂直效力：
- 基本權是人民用來對抗國家的 → 國家在上、人民在下，國家是基本權的**相對人**

## 第三人效力：
- 人與人之間也會發生基本權衝突（例：雇主規定女性懷孕就要離職）
- 因為基本權的相對人是國家，人民之間就稱為「第三人」

## 兩種解決方式：
- **法院**：個案中衡量哪一方的基本權比較重要；契約本身就含有自由的讓渡與妥協
- **法律**：立法事先調和，免得事事上法院 → 例：性別平等工作法、刑法公然侮辱罪

## 📖 法條原文速查

> **憲法 §7**（平等權）　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律平等。

> **憲法 §15**　人民之生存權、**工作權**及財產權，應予保障。

> **憲法 §22**　凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障。→ **契約自由**、營業自由的依據之一

> **性別平等工作法 §11 II**（原名性別工作平等法）　工作規則、勞動契約或團體協約，不得規定或事先約定受僱者有結婚、**懷孕**、分娩或育兒之情事時，應行離職或留職停薪；亦不得以其為解僱之理由。→ 建議查閱最新六法原文

> **刑法 §309 I**（公然侮辱）　公然侮辱人者，處拘役或九千元以下罰金。

## 📋 憲判速查

> **113 年憲判字第 3 號**（補充，老師未唸字號）：刑法 §309 公然侮辱罪**合憲**，但須限縮適用：依個案情節權衡表意人的言論自由與被害人的名譽權，限於故意貶損他人社會名譽或名譽人格，且逾越一般人可合理忍受範圍者，始成立。→ 判決要旨建議查閱憲法法庭網站

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「基本權的相對人是誰？」 | **國家**（垂直效力） |
| 「私人間的基本權衝突稱為？」 | **基本權第三人效力** |
| 「雇主規定女性懷孕即離職，涉及哪些基本權？」 | 雇主：營業自由、**契約自由**（§22）；受僱者：**工作權**（§15）、**平等權**（§7） |
| 「立法如何調和這類衝突？」 | 性別平等工作法 §11 II：不得約定懷孕應離職，也不得以此解僱 |
| 「公然侮辱罪是哪兩種基本權的調和？」 | 表意人**言論自由** vs. 被害人**名譽權**；法院個案權衡（2018 年律師考過） |
| 「同一句髒話罵路人與罵總統，結果可能不同？」 | **可能**：個案權衡，公眾人物須容忍較多批評 |

## 一、垂直效力與第三人效力

```
          國家（基本權的相對人）
            ▲
  垂直效力  │  人民對抗國家
            │
  人民 A ◄──────► 人民 B
        第三人效力
   （私人之間的基本權衝突）
```

## 二、案例：懷孕就要離職

- 老師舉例：1989 年高雄市立圖書館招聘女性服務人員，規定懷孕就要離職。
- 雇主的理由：增加經營成本（要找人代替）→ 營業自由、契約自由（§22）。
- 受僱者的主張：工作應該是做錯事才被解僱，懷孕錯了嗎？→ 工作權（§15）、平等權（§7）。
- 老師：制度規章多以男性為本位打造，男生不會懷孕，這種規定本質上不公平。
- 後來的解決：**性別平等工作法**直接告訴大家，這類情形受僱者的基本權比較重要 → 不得因結婚、懷孕而解僱。

## 三、兩種解決方式

| 方式 | 怎麼做 | 例 |
|---|---|---|
| 法院 | 個案中比較哪一方的基本權比較重要 | 契約糾紛、公然侮辱個案 |
| 法律 | 立法事先決定衝突時誰優先 | 性別平等工作法、刑法 §309 |

- 契約本身就是讓渡與妥協：老師和補習班約好今天上課，不能說補習班限制他的一般行動自由去告補習班。
- 每件事都上法院太痛苦 → 很多法律其實都在做第三人效力的調和。

## 四、公然侮辱：同一句話，結果不同

- 罵人者主張**言論自由**；被罵者主張**名譽權**。
- 隨便罵路人 → 被告很合理，名譽權較重要。
- 罵總統 → 可能可以，言論自由較重要。
- 每個法院都在審酌：本案中誰的基本權比較重要。
