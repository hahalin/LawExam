# 憲法03 筆記：未及併案的案件（憲訴§41）

## 三種聲請案：
- 來得及併案 → **原因案件**（§24），判決直接生效
- 判決宣示或公告**前**已聲請、符合受理要件，但**來不及併案** → 憲法法庭以**裁定**宣告判決效力及於該案（§41 I）
- 裁定不是判決：判決是一個審級的**句號**，裁定是**逗號**

## 人民與地方自治團體（§83）不適用：
- §41 III：前二項規定於 **§59、§83** 之案件不適用
- 理由：只有這兩種聲請要「廢棄確定終局裁判、**發回管轄法院**」，這要用**判決**才做得到，裁定不行
- 所以憲法法庭會**再作一次判決**（理由可以和前一號完全相同），不會放棄這些人

## 其他三種主體為什麼不需要：
- 國家最高機關、立委、法官：大法官講完就結束，沒有確定裁判要發回

## 📖 法條原文速查

> **憲訴 §41 I**（判決效力之擴張）　憲法法庭就第三章、第四章、第七章及第八章聲請案件之判決，應以**裁定**宣告判決效力及於其他以同一法規範或爭議聲請而**未及併案審理**之案件。但該其他案件，以於**判決宣示或公告前**已向憲法法庭聲請，且**符合受理要件**者為限。→ 建議查閱最新六法原文

> **憲訴 §41 III**　前二項規定，於**第五十九條**及**第八十三條**之案件，**不適用**之。

> **憲訴 §62 I**（節錄）　憲法法庭認人民之聲請有理由者，應於**判決主文**宣告該確定終局裁判違憲，並廢棄之，發回管轄法院……

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「來不及併案的聲請案，憲法法庭以何種形式使其受判決效力？」 | **裁定**（§41 I），不是判決 |
| 「§41 I 的『其他案件』有何限制？」 | 須於**判決宣示或公告前**已聲請，且**符合受理要件** |
| 「§41 擴張效力的規定，哪些案件不適用？」 | **§59（人民）**、**§83（地方自治團體）**之案件（§41 III） |
| 「為何人民聲請案不適用 §41？」 | 人民要的是**廢棄確定終局裁判、發回管轄法院**，須以**判決主文**為之（§62 I），裁定做不到 |
| 「來得及併案的案件稱為？」 | **原因案件**，判決對其直接生效 |

## 一、時間軸上的三種聲請案

```
聲請 ── 併案審理 ──────── 判決宣示／公告 ──────────
 │                         │
 ├─ 來得及併案 → 原因案件（§24），判決直接生效
 │
 ├─ 宣示前已聲請、合法，但來不及併案
 │     ├─ 國家最高機關、立委、法官等 → §41 I 以「裁定」擴張判決效力
 │     └─ 人民（§59）、地方自治團體（§83）→ §41 III 排除 → 另作「判決」
 │
 └─ （判決後才聲請：不在 §41 範圍）
```

- 例：當事人的通姦罪案件**昨天**定讞，律師**今天**就寫好聲請書送到司法院，結果**明天**就宣判 → 一定來不及併案。

## 二、為什麼把 §59、§83 排除

| 主體 | 聲請後要什麼 | 需不需要發回 |
|---|---|---|
| 國家最高機關（§47） | 大法官說清楚職權問題 | 不需要 |
| 立委（§49） | 宣告法律違憲 | 不需要 |
| 法官（§55） | 宣告法律違憲後，自己的案件繼續審 | 不需要（案件根本還沒結束） |
| 人民（§59） | **撤銷對自己不利的確定終局裁判** | **需要** → 廢棄發回 |
| 地方自治團體（§83） | 撤銷侵害自治權的確定終局裁判 | **需要** |

- 廢棄發回的前提是**判決**（§62 I「應於判決主文宣告」）。
- 來不及併案 → 沒有被判決 → 無法撤銷發回 → 所以憲法法庭**再作一號判決**宣告這件也違憲。
- 例：40 件通姦罪併案，宣告違憲立即失效；第 41 件來不及併案，下週再作一號判決，理由和前一號一樣。
- 立法理由在講義第 22 頁下方粗體字，有興趣可自行閱讀。
