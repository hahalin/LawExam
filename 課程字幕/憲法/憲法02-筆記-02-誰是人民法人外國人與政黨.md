# 憲法02 筆記：誰是人民（法人外國人與政黨）

## 判斷方法：
- 不要死背名單，從「**不爽 → 權利受損 → 找大法官**」推回來
- 能主張**憲法上基本權**受侵害的主體，就是憲訴 §59 的「人民」
- 憲訴 §59 的核心三個字仍是「**該裁判**」

## 四種「人」：
- 自然人：當然是人民
- 法人：是人民，但只能主張**依其性質**可享有的基本權（財產權、平等權、言論自由；沒有人身自由、應考試服公職權、秘密通訊自由）
- 外國人、大陸地區人民：是人民，但權利範圍可能不同（外國人沒有參政權；大陸地區人民得以法律特別規定，增修 §11）
- 政黨：是人民（例：綠黨挑戰單一選區兩票制，釋字 721）

## 舊法到新法：
- 舊大審法 §5 I ②：「人民、**法人或政黨**」
- 憲訴 §59 刪掉法人與政黨 → 因為它們本來就是人民的一種，不用另外寫

## 📖 法條原文速查

> **憲訴 §59 I**　人民於其憲法上所保障之權利遭受不法侵害，經依法定程序**用盡審級救濟**程序，對於所受不利確定終局裁判，或**該裁判**及其所適用之法規範，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

> **大審法 §5 I ②**（舊法）　人民、**法人或政黨**於其憲法上所保障之權利，遭受不法侵害，經依法定程序提起訴訟，對於確定終局裁判所適用之法律或命令發生有牴觸憲法之疑義者。→ 建議查閱原文

> **憲法 §17**（參政權）　人民有選舉、罷免、創制及複決之權。

> **憲法增修條文 §11**　自由地區與大陸地區間人民權利義務關係及其他事務之處理，得以法律為**特別之規定**。

> **行政訴訟法 §9**（公益訴訟）　人民為維護公益，就無關自己權利及法律上利益之事項，對於行政機關之違法行為，得提起行政訴訟。但以法律有特別規定者為限。→ 字幕說「第八條」，公益訴訟是 **§9**，已校正

> **憲法 §8**（人身自由）、**§12**（秘密通訊自由）、**§18**（應考試服公職）→ 法人依性質不能主張；條文較長，建議查閱最新六法原文

## 📋 釋字速查

> **釋字 721**：小黨（綠黨、制憲聯盟）聲請，主張增修條文的單一選區兩票制與 **5% 政黨門檻**侵害其權利 → 大法官認**合憲**。重點：**政黨可以作為聲請人**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人得否依 §59 聲請？」 | **得**。但只能主張**依其性質**可享有的基本權 |
| 「法人得主張哪些基本權？」 | 財產權、平等權、言論自由（廣告）、營業自由；**不能**主張人身自由（§8）、秘密通訊自由（§12）、應考試服公職（§18） |
| 「外國人得否聲請？」 | **得**（是人民）；但**參政權**（§17）外國人不享有 |
| 「大陸地區人民的權利可否差別對待？」 | 可，**增修 §11** 授權以法律為特別規定（是好是壞交給立法院） |
| 「政黨得否聲請？」 | **得**，例：釋字 721（綠黨等挑戰 5% 門檻） |
| 「憲訴法為何刪除『法人、政黨』？」 | 因為兩者本來就屬於「人民」，不必另列 |
| 「動物得否聲請？」 | **不得**，我國法律不承認動物是權利主體 |

## 一、從「為什麼可以聲請」推回「誰是人民」

```
判決或法規範對我不利（不爽）
        ↓
我的權利受損 → 精確地說是「憲法上的基本權」
        ↓
所以允許我找憲法法庭
        ↓
反推：能主張基本權受損的主體 ＝ 人民
```

- 這跟民事訴訟的**當事人適格**同一個邏輯：A 被 B 欠錢，只有 A 能起訴，C 不能替 A 告。

### 憲法上的權利 vs 法律上的權利

| | 憲法上的權利 | 法律上的權利 |
|---|---|---|
| 來源 | 憲法明定（如言論自由） | 憲法沒寫，法律創設 |
| 例 | §11 言論自由 | 行訴 §9 公益訴訟（與自己無關也能告） |
| §59 聲請 | 以此為基礎 | 不是 §59 所稱「憲法上所保障之權利」 |

## 二、法人：依性質決定

| 基本權 | 法人可否主張 | 例（補習班） |
|---|---|---|
| 財產權（§15） | **可** | 堆放講義違反建築法、消防法被裁罰 |
| 平等權（§7） | **可** | 法規只針對某一家補習班 |
| 言論自由（§11） | **可** | 下廣告 |
| 營業自由 | 可（工作權衍生） | 工作權本身偏向以自然人為主 |
| 名譽 | 有討論空間（商譽） | — |
| 人身自由（§8） | **不可** | 法人不會被關 |
| 應考試服公職（§18） | **不可** | — |
| 秘密通訊自由（§12） | **不可**（老師的說法） | — |

## 三、自然人也分種類

```
自然人
├── 限制行為能力人 → 只是暫時狀態，不是本質差異
├── 本國人
├── 外國人 → 無參政權（§17）
│     例（臺大轉學考）：外國人在臺參加集會遊行，能否聲請？要打問號
└── 大陸地區人民 → 增修 §11：得以法律特別規定
```

## 四、政黨

- 不要只想到執政黨；大部分政黨**沒有取得公權力**，地位跟一般人民團體一樣。
- 政黨常受侵害的是**參政權**。
- 例：增修條文改採單一選區兩票制並立制，政黨票門檻 5%，小黨選不上 → 綠黨等聲請 → 釋字 721。
