# 憲法14 筆記：平等權的啟動：同一系統與可相提並論性

## 先問能不能比：
- 有比較才有不公平；**沒得比，就沒有平等權的討論**
- 啟動平等權審查的兩個前提：① 是否在**同一個系統**下；② 是否具**可相提並論性**

## 講義的圖：兩人在操場上比賽跑步，一人拉著另一人坐的車
- 系統：都在**操場**上
- 可相提並論：都在**同一個起跑點**、都在**比速度**
- 再加上資源不同 → 才產生不公平；換成一人跑步、一人揮棒，就無從比較

## 有差別待遇，不等於不公平：
- 第一步：是否構成**差別待遇**（能比、又被不同對待）
- 第二步：這個差別待遇**是否合理**（例：女廁比男廁大，可能才公平）

## 同性婚姻為什麼是平等權問題：
- 系統：婚姻制度
- 可相提並論：異性戀與同性戀都是**性傾向** → 一方可以結婚、一方不行 → 差別待遇，再審查是否合理

## 📖 法條原文速查

> **憲法 §7**（平等權）　中華民國人民，無分男女、宗教、種族、階級、黨派，在法律上一律**平等**。

---

## 📋 釋字速查

> **釋字 748 號**（2017 年）：民法未使相同性別二人得成立永久結合關係，以**性傾向**作為分類標準形成差別待遇，違反憲法 §7 平等權（及 §22 婚姻自由）。→ 審查基準（較為嚴格）見 筆記-09

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「啟動平等權審查的前提？」 | **同一系統**＋**可相提並論性** |
| 「有差別待遇是否必然違反平等？」 | **不一定**，還要看差別待遇是否**合理** |
| 「公務員退休金與勞工退休金不同，違反平等嗎？」 | 不同系統 → 原則上**無從比較** |
| 「同性婚姻的比較基準？」 | 婚姻制度內，以**性傾向**為分類（釋字 748） |

## 一、兩步驟

```
步驟一：構成差別待遇嗎？
        ├── 同一系統？ ─── 否 → 無從比較，沒有平等問題
        └── 可相提並論？ ── 否 → 無從比較
                │是
                ▼
        有差別待遇
步驟二：差別待遇合理嗎？
        → 依分類標準決定審查密度（筆記-09）
```

## 二、老師的例子

| 例子 | 能不能比 | 理由 |
|---|---|---|
| 王建民 vs 戴資穎誰厲害 | 不能 | 棒球、羽球不同系統 |
| 甲憲法 80 分、乙民法 70 分 | 不能 | 不同科目，分數意義不同 |
| 甲憲法 80 分、乙憲法 70 分 | 能 | 同一系統、同一標準 |
| 歷史 80 分 vs 公民 57 分（公民頂標 52） | 單看數字不能 | 要放回各自的分布才有意義 |

- 老師：平等權的思維，不是單看一個數字或一個人怎樣，而是先問「他們憑什麼能比」。
