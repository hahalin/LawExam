# 憲法08 筆記：軍事審判與戒嚴時期案件的救濟（釋字272）

## 先分清楚：軍事審判是「訴訟」不是「法律」
- 人民除**現役軍人**外，不受軍事審判（§9）
- 現役軍人違反軍法（陸海空軍刑法）→ 現在由檢察官起訴、在**普通法院**審判
- 2013 年洪仲丘事件後修法：**平時**不再軍事審判，只有**戰時**才有
- 替代役是「兵」不是「軍」→ 不是現役軍人

## 為什麼過去的軍事審判不被信任：
- 法庭在**軍營**裡，名為公開，一般人進不去
- 判決要呈**國防部長**（過去是蔣介石）核定，可以批示加重、改判死刑 → 法官會迎合上意
- 對照：地方法院**沒有上級機關**，法官獨立審判；上訴審可以撤銷判決，但不能指揮下級法官

## 釋字 272：解嚴後不能回普通法院上訴
- 戒嚴時期非軍人被軍事審判（叛亂犯），判決確定者，解嚴後**不得上訴、抗告**；有再審或非常上訴原因者，仍得依法聲請（國安法 §9 ②）
- 大法官：**合憲**——案件已確定、事過境遷、事證調查困難，為維持社會秩序與**法安定性**
- 批評：被認為是阻礙臺灣**轉型正義**的重要解釋

## 📖 法條原文速查

> **憲法 §9**　人民除現役軍人外，不受軍事審判。

> **動員戡亂時期國家安全法 §9**（81 年修正前）　戒嚴時期戒嚴地域內，經軍事審判機關審判之非現役軍人刑事案件，於解嚴後依左列規定處理：
> 一、軍事審判程序尚未終結者，偵查中案件移送該管檢察官偵查，審判中案件移送該管法院審判。
> 二、刑事裁判已確定者，**不得向該管法院上訴或抗告**。但有**再審或非常上訴**之原因者，得依法聲請再審或非常上訴。→ 建議查閱解釋原文

> **軍事審判法 §1**（2013 年修正）　現役軍人**戰時**犯陸海空軍刑法或其特別法之罪，依本法追訴、處罰。→ 平時改依刑事訴訟法由普通法院審判；建議查閱最新六法原文

## 📋 釋字速查

> **釋字 272 號**（1991 年）：戒嚴時期非現役軍人經軍事審判之刑事案件，國安法 §9 ② 規定裁判已確定者於解嚴後不得向法院上訴或抗告，係基於長期戒嚴、事過境遷、事證調查困難，為維持**社會秩序**與裁判**安定**而設，且有再審、非常上訴之特別救濟途徑，**與憲法尚無牴觸**。→ 原文建議查閱司法院網站

> **釋字 436 號**（1997 年，補充，老師本講未提）：軍事審判機關所行使者亦屬國家刑罰權之一種，但**平時**經終審軍事審判確定、宣告有期徒刑以上之案件，應許被告直接以判決違背法令為理由，向**普通法院**請求救濟。→ 原文建議查閱司法院網站

> 字號校正：字幕「4至272」即**釋字 272**。老師說清大學生讀史明《臺灣人四百年史》被以叛亂起訴是 1992 年的「末代叛亂犯」，該案一般稱**獨台會案**，發生於 **1991 年 5 月**，建議查證。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「非現役軍人得否受軍事審判？」 | **不得**（§9） |
| 「現役軍人平時犯陸海空軍刑法，由何者審判？」 | **普通法院**（2013 年修法後，戰時才軍事審判） |
| 「替代役男是否為現役軍人？」 | **否**，替代役是兵役的一種，但不是軍人 |
| 「戒嚴時期軍事審判確定之案件，解嚴後得否上訴？」 | **不得**；得聲請**再審、非常上訴**（國安法 §9 ②，釋字 272 合憲） |
| 「釋字 272 的合憲理由？」 | 事過境遷、事證調查困難、維持社會秩序與**法安定性** |
| 「平時軍事審判確定之有期徒刑以上案件，得否向普通法院救濟？」 | **得**，以判決違背法令為由（釋字 436，補充） |

## 一、軍事審判在講什麼

```
現役軍人犯罪
├── 實體法：陸海空軍刑法（軍法）── 照樣適用
└── 程序（審判在哪）
      ├── 平時 → 檢察官起訴 → 普通法院
      └── 戰時 → 軍事審判（軍事檢察官、軍法官）
```

- 軍法官是不是法官？有不同說法；但現在平時沒有軍法官，爭點變得不重要。
- 時事：總統賴清德提出恢復軍事審判。老師認為合理——戰時不可能臨時找出會審判的軍法官，平時就要準備；他的大學老師當年就說「**不能把軍事審判污名化**」：當時的軍事審判有問題，不等於軍事審判有問題。

## 二、戒嚴時期的軍事審判

| 項目 | 內容 |
|---|---|
| 依據 | 懲治叛亂條例 §2 I：犯刑法 §100 I（意圖顛覆政府）→ **唯一死刑** |
| 實際 | 批評政府、組讀書會都可能被當叛亂犯；計程車司機因乘客在車上談臺獨，被以「知匪不報」判刑 |
| 例 | 美麗島事件（軍法審判，後由李登輝特赦）、雷震案 |
| 程序問題 | 法庭在軍營、判決呈核可被加重 → 欠缺權力分立 |

- 學者主張戒嚴時期的國家狀態是**非法**的；民主化後要不要翻轉過去的判決，就是**轉型正義**與**法安定性**的拉扯。

## 三、272 的取捨

```
解嚴後，叛亂犯想洗刷罪名
        │
        ├── 一般救濟（上訴、抗告）→ 不准（國安法 §9 ②）
        └── 特別救濟（再審、非常上訴）→ 可以
                        ↓
        272：合憲（法安定性 > 全面翻案）
                        ↓
        批評：阻礙轉型正義；後來由促轉會撤銷大量判決
```

- 老師：對當事人來說，痛苦不只是坐牢，而是「我爭取自由民主，憑什麼是犯罪者」——他們想消除的是這個標籤。
