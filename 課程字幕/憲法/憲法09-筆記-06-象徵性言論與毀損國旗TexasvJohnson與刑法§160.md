# 憲法09 筆記：象徵性言論與毀損國旗（Texas v. Johnson與刑法§160）

## 什麼是象徵性言論：
- 用**動作**表達意念；表意人主觀上想表達，客觀上他人也看得出在表達什麼
- 比中指 → 有意義，是言論；隨便比一個沒人懂的手勢 → 不是言論

## 同一個動作，基本權可能不同：
- 在行政院前單純裸奔被趕 → **一般行為自由**
- 在行政院前身上寫字裸體抗議被趕 → **集會自由**（表現自由）
- 要個案判斷，不要直接貼標籤

## 燒國旗：
- **Texas v. Johnson**（美國聯邦最高法院，5 比 4）：禁止毀損國旗的規定違憲，燒國旗是表達言論的方式
- 我國**刑法 §160** 仍處罰侮辱性毀損國旗；限制的是**內容**還是**非內容**？關鍵在燒國旗有沒有**可替代**的表達方式
- 老師：沒有標準答案；他個人認為難以替代（傾向內容限制）

## 📖 法條原文速查

> **刑法 §160 I**（侮辱國徽國旗）　意圖侮辱中華民國，而公然損壞、除去或污辱中華民國之**國徽、國旗**者，處一年以下有期徒刑、拘役或九千元以下罰金。→ 罰金數額建議查閱最新六法原文

## 📋 判決速查

> **Texas v. Johnson**（美國聯邦最高法院，1989 年，5 比 4）：Johnson 在 1984 年共和黨全國代表大會期間，於德州達拉斯焚燒美國國旗抗議雷根政府政策，依德州毀損國旗罪被判刑。法院認為焚燒國旗屬受憲法第一修正案保障的表意行為，處罰規定違憲。

> 老師提到：我國有毀損國旗案件聲請釋憲多年未作成判決（老師說他教書第一年就聲請、至今第八年），近期法院擬自行審理 → 案號未唸，建議查證。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「象徵性言論的要件？」 | 主觀上有**表達意念**，客觀上他人能**理解其意念**（有傳達性） |
| 「Texas v. Johnson 的結論？」 | 禁止焚燒國旗**違憲**，焚燒國旗是表意行為（5 比 4） |
| 「我國毀損國旗是否處罰？」 | **刑法 §160**：意圖侮辱而公然損壞、除去或污辱國旗 |
| 「禁止毀損國旗是內容還是非內容限制？」 | **無定論**：看有無可替代的表達方式；無可替代 → 傾向內容限制 |
| 「絕食抗議是否屬象徵性言論？」 | 可能是（老師說 2014 年律師考過）；強制灌食保護生命權，卻可能限制表意 → 無標準答案 |

## 一、象徵性言論的判斷

```
一個動作
│
├── 主觀：表意人想藉此表達意念？
├── 客觀：配合整體環境，他人看得出在表達什麼？
│
├── 兩者皆是 → 象徵性言論（表現自由）
└── 否 → 一般行為自由
```

| 情境 | 涉及的基本權 |
|---|---|
| 行政院前單純裸奔，被驅離 | 一般行為自由 |
| 行政院前身上寫字裸體抗議，被驅離 | 集會自由（表現自由） |

## 二、燒國旗：內容還是非內容？

| 看法 | 理由 | 結果 |
|---|---|---|
| 非內容限制 | 不禁止你抗議國家，只是不准用毀損國旗這種「方式」；還有很多方式可以抗議 | 原則從寬 |
| 內容限制 | 毀損國旗的象徵力量難以用文字取代（例：主張臺澎金馬是新的政治實體，講出來不如當場燒掉中華民國國旗強烈） | 原則從嚴 |

- 判準：**有沒有可替代性**。有 → 偏非內容；沒有 → 偏內容。老師個人認為沒有。
- 我國案例（老師口述）：有人到慈湖抗議剪國旗；有人在國慶時把永和中正橋上的國旗剪破，都被起訴、判刑，但判得很輕。

## 三、絕食抗議

- 絕食抗議可能是象徵性言論。
- 強制灌食：保護**生命權**（有生命才有言論自由），但也可能破壞**表意**的可能性 → 老師也認為沒有答案。
