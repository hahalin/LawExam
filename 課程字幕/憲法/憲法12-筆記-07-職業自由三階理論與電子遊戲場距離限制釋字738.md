# 憲法12 筆記：職業自由三階理論與電子遊戲場距離限制（釋字738）

## 三階理論（源自德國藥房案）：
- **執行**職業自由的限制：已取得工作，對執行的**時間、地點、方式**加以限制 → **寬鬆**審查
- **主觀**條件限制：須具備一定能力或資格才能從事（例：律師考試）→ **中度**審查
- **客觀**條件限制：與個人能力無關，想做也不能做（例：性交易非法、藥房數量管制）→ **嚴格**審查
- 執行限制像言論的非內容限制（時間、地點、方式）

## 釋字 738：
- 電子遊戲場業管理條例 §9 I：距國中小、高中職、醫院 **50 公尺**以上
- 臺北市自治條例 1000 公尺、臺北縣 990 公尺、桃園縣 800 公尺
- 法律保留：50 公尺是**最低標準**，地方可因地制宜拉長 → **不違反**
- 距離是執行地點的限制 → 原則寬鬆；但距離拉長到產生**實質阻絕**效果，就涉及職業選擇自由 → **提高審查基準**

## 考試要學的層次：
- 第一，知道審查基準有哪些類型
- 第二，知道會不會變形、為什麼變形：**表面上寬鬆，實際侵害變大時，就要提高審查基準**

## 📖 法條原文速查

> **電子遊戲場業管理條例 §9 I**（距離限制）　電子遊戲場業之營業場所，應距離國民中、小學、高中、職校、醫院**五十公尺以上**。→ 原文建議查閱最新六法原文

> **臺北市電子遊戲場業設置自治條例 §5 I ②**　限制級電子遊戲場應距離幼稚園、國民中小學、高中、職校、醫院、圖書館 **1000 公尺**以上。→ 原文建議查閱司法院解釋原文

> **憲法 §15**　人民之生存權、工作權及財產權，應予保障。

## 📋 釋字速查

> **釋字 738 號**（2016 年）：電子遊戲場業管理條例 §9 I 有關 50 公尺距離之規定，係法律為保留地方**因地制宜**空間所設之**最低標準**，並未禁止直轄市、縣（市）以自治條例為應保持更長距離之規範，與法律保留原則無違。距離限制屬對工作**地點之執行自由**所為限制；惟各地方自治團體有關距離之規定，如超出法定最低限制較多時，非無可能產生**實質阻絕**之效果，而須受**較為嚴格**之比例原則審查。→ 原文建議查閱司法院解釋原文

> **德國藥房案**（BVerfGE 7, 377；聯邦憲法法院 1958 年）：藥劑師申請在小鎮開設藥房，因當地已足以滿足需求而被拒。法院建立職業自由**三階理論**，認此一「需求審查」屬客觀許可條件，須為防止對極重要公益之明顯、高度危險始得為之，宣告該限制**違憲**。
> 校正：老師說藥劑師 1955 年申請、法院最後認為**合憲**；實際判決作成於 **1958 年**，結論為**違憲** → 建議查證。

|---------|---------|
| 「職業自由三階理論的審查基準？」 | 執行 → **寬**；主觀 → **中**；客觀 → **嚴** |
| 「律師須考試及格才能執業，屬哪一階？」 | **主觀**條件限制 |
| 「營業時間、地點、方式的限制？」 | **執行**職業自由的限制 |

## 一、三階理論對照

| | 執行限制 | 主觀條件 | 客觀條件 |
|---|---|---|---|
| 意義 | 已能從事，對執行方式設限 | 須具備一定能力、資格 | 與個人能力無關，不能從事 |
| 例 | 營業時間、地點、方式 | 律師、醫師考試；前科限制（消極，見 584） | 性交易非法；藥房數量管制 |
| 審查 | 寬鬆 | 中度 | 嚴格 |
| 對比言論 | 像非內容限制 | — | — |

- 三階理論只是**原則**；1955、1958 年的標準不一定完全適用今日，學憲法就是學「分類 → 分類為何不合用 → 看案例怎麼調整」。

## 二、738 的兩個爭點

```
爭點一：法律說 50 公尺，自治條例說 1000 公尺 → 違反法律保留？
  業者：逾越法律範圍；改成 5 萬公尺整個臺北市都不能開？
  機關：立法目的就是「至少 50 公尺」；各地人口密度不同，應能調整
  738：50 公尺是最低標準 → 不違反法律保留

爭點二：距離限制採什麼審查基準？
  形式上：執行地點限制 → 寬鬆
  實質上：距離拉得太長 → 實質阻絕 → 涉及職業選擇自由 → 較嚴格
```

- 老師例：臺東縣人口約為板橋區一半，面積卻大上二三十倍 → 各地調整距離有其道理。

## 三、為什麼審查基準會變形

- 大法官每次宣告違憲，等於說立法者訂了不好的法律，政治上會有壓力；所以以「侵害人民權利的大小」決定審查密度，維持平衡。
- 寫考卷時不能僵硬套分類：表面上寬鬆，實際效果增強 → 應適度提高審查基準。
