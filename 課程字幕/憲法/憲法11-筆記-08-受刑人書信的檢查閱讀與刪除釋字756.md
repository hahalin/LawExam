# 憲法11 筆記：受刑人書信的檢查、閱讀與刪除（釋字756）

## 事實：
- **邱和順**在羈押、服刑期間寫下個人回憶錄（內容指控監所內吸毒），要寄出投稿，被監所禁止
- 依據：舊監獄行刑法 §66 與施行細則 → 監獄長官可**檢閱**書信，認有妨礙監獄紀律之虞者可令**刪除**

## 受刑人有沒有基本權：
- 有。刑罰講好限制的是**人身自由**，附帶限制居住遷徙等
- 秘密通訊、表現自由**原則上與一般人民無異**，仍受保障
- 「有保障」不等於「限制標準跟一般人一樣」→ 限制的正當性可以不同

## 756 的結論（拆成三個動作）：
- **檢查**（看有沒有夾帶違禁品）→ **合憲**
- **閱讀**（看內容）→ 未區分書信種類、個案情形，一律閱讀 → **違憲**
- **刪除** → 限於維護監獄紀律所必要時合憲，且**刪除部分應影印留存，於釋放時發還**

## 老師的重點：
- 錯不在審查本身，而在**一律**審查 → 應類型化，才符合最小侵害
- 現行監獄行刑法已修正、類型化

## 📖 法條原文速查

> **憲法 §12**（秘密通訊自由）　人民有秘密通訊之自由。

> **憲法 §11**（表現自由）　人民有言論、講學、著作及出版之自由。

> **舊監獄行刑法 §66**　發受書信，由監獄長官**檢閱**之。如認為有妨害監獄紀律之虞，受刑人發信者，得述明理由，令其**刪除**後再行發出；受刑人受信者，得述明理由，**逕予刪除**再行收受。→ 依字幕老師朗讀整理；現行監獄行刑法已全面修正，條號與內容建議查閱最新六法原文

## 📋 釋字速查

> **釋字 756 號**（2017 年 12 月 1 日；聲請人邱和順）：
> - 受刑人除人身自由及附帶受限制之居住遷徙自由外，與一般人民所享憲法上權利原則上並無不同；其秘密通訊與表現自由應受保障。
> - 舊監獄行刑法 §66 **檢查**書信是否夾帶違禁品，手段與目的有合理關聯 → 合憲。
> - **閱讀**書信未區分書信種類、未斟酌個案情形，一概許監獄長官閱讀 → 過度限制秘密通訊自由，違憲（至遲 2 年失效）。
> - **刪除**書信內容，應限於維護監獄紀律所必要，並應以**影本**保留，於受刑人**刑滿出獄時發還**。
> - 施行細則 §81 III 限制投稿（「題意正確」「無損監獄信譽」等要件）部分違憲；§82 部分違憲。→ 解釋文原文建議查閱司法院網站

> 對照：本號「事前審查」的審查基準（重要公益＋實質關聯）見 憲法09-筆記-07。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「受刑人是否享有秘密通訊自由？」 | **是**：除人身自由及附帶限制外，原則與一般人民無異（756） |
| 「監獄檢查受刑人書信有無夾帶違禁品？」 | **合憲** |
| 「監獄一律閱讀受刑人書信內容？」 | **違憲**：未區分書信種類與個案情形 |
| 「監獄刪除書信內容？」 | 限於維護紀律所必要；刪除部分應留存、出獄時**發還** |
| 「756 違憲的關鍵字？」 | 「**一律**」「**未區分**」→ 欠缺最小侵害 |

## 一、檢查、閱讀、刪除三分

```
受刑人書信
├── 檢查（有無違禁品）  → 合憲：目的正當、手段合理關聯
├── 閱讀（知悉內容）    → 違憲：一律閱讀，未類型化
└── 刪除（內容）
      ├── 受刑人發信：令其刪除後發出
      └── 受刑人受信：監所逕予刪除 → 受刑人連「知道」都被剝奪，侵害更大
            └── 756：限必要時；影本留存，出獄發還（合憲性解釋）
```

## 二、黃昭元大法官的意見（老師引用）

- 通信雙方都是權利主體。以不太精準的比喻：「好人寫給壞人的信，地位跟壞人寫的信一樣」→ 對受刑人的限制理所當然地擴張到寄信給他的外部人，這有問題。→ 意見書性質（協同或部分不同）建議查閱原文

## 三、老師的補充

- 受刑人是最不受關心的族群：被視為壞人、又不能投票，政治人物沒有誘因。
- 除死刑與無期徒刑外，受刑人終將回歸社會；監所內外落差太大，反而不利復歸。
- 有教監獄學的老師認為確實有人透過書信在獄中指揮犯罪 → 應處理的是**這類人**，而不是一律處理所有人。
- 邱和順是羈押時間極長的冤案爭議當事人；老師說大學時期關注的救援案件中（徐自強、蘇建和、鄭性澤），只剩他尚未獲救。
- 延伸閱讀：白色恐怖期間政治犯遺書無法送達的紀錄（《無法送達的遺書》）。
