# 憲法04 筆記：監察院聲請黨產條例不受理（1482次決議）

## 事實：
- 有人陳情，監察院調查《政黨及其附隨組織不當取得財產處理條例》，調查報告認多條違憲 → 監察院聲請釋憲
- 2018 年司法院首次召開憲法法庭「**說明會**」（尚未受理，討論程序上可否聲請）

## 套 §47 I 三要件：
- ① 國家最高機關：監察院是，無爭議
- ② 行使職權：調查權是為**行使監察權**而存在；監察權（彈劾、糾舉、審計、糾正）都不能對法律做什麼 → 正反說法約五五波
- ③ 適用法規範：黨產條例是黨產會行使職權時適用的法律，不是監察院行使調查權所適用的法律 → **勝負落在這裡**

## 結論：
- 大法官第 **1482** 次會議**不受理**：不符行使職權、不符適用法規範
- 若監察院可以這樣聲請，等於監察院對**所有法律**都能聲請 → 違反「不得已」的設計
- 黨產條例後來由行政法院法官聲請，作成**釋字 793**

## 📖 法條原文速查

> **憲法增修條文 §7 I**（監察院職權）　監察院為國家最高監察機關，行使**彈劾、糾舉及審計**權，不適用憲法第九十條及第九十四條有關**同意權**之規定。

> **憲法 §90**　監察院為國家最高監察機關，行使同意、彈劾、糾舉及審計權。→ 同意權已由增修 §7 I 排除

> **憲法 §95**（調閱權）　監察院**為行使監察權**，得向行政院及其各部會調閱其所發布之命令及各種有關文件。

> **憲法 §96**（調查）　監察院得按行政院及其各部會之工作，分設若干委員會，調查一切設施，注意其是否違法或失職。

> **憲法 §97 I**（糾正）　監察院經各該委員會之審查及決議，得提出**糾正案**，移送行政院及其有關部會，促其注意改善。

> **憲訴 §47 I**　國家最高機關，因本身或下級機關**行使職權**，就**所適用之法規範**，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

## 📋 決議／釋字速查

> **大法官第 1482 次會議不受理決議**（2018 年）：監察院就黨產條例聲請解釋，不受理。理由分兩部分：(1) 不符「行使職權」（用了三段論述）；(2) 不符「**適用法律**」：「聲請人係主張其行使調查權所生之法令違憲疑義，足見其所聲請解釋之系爭條例，並非聲請人行使調查權所**適用之法律**」（僅三行，但是勝負點）。→ 決議原文建議查閱司法院網站
> 另說明：1992 年立法院全面改選前從寬受理監察院聲請，有其**特殊歷史背景**；改選後至 2018 年監察院聲請僅約五件。

> **釋字 793 號**（2020 年）：黨產條例合憲。由行政法院法官聲請。→ 下一講詳述

> **湯德宗大法官**：在 1476 次決議時就想提不同意見書但當時不公開；之後首開大法官就**不受理決議**公開提出不同／協同意見書之例，並在本案提出不同意見書。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「監察院調查後認某法律違憲，得否依 §47 聲請？」 | **不得**：非其行使職權所**適用之法規範**（1482 次決議） |
| 「監察院現行職權？」 | **彈劾、糾舉、審計**（增修 §7 I）＋**糾正**（§97）＋調查（§95、§96，為行使監察權） |
| 「監察院還有同意權嗎？」 | **沒有**，增修 §7 I 排除 |
| 「彈劾、糾舉、糾正、審計各針對什麼？」 | 彈劾、糾舉對**人**；糾正對**事**；審計對**預算決算** |
| 「調查權是獨立職權嗎？」 | 反對說：§95 明定「**為行使監察權**」，調查權是**輔助**手段 |
| 「黨產條例最後如何進入憲法審查？」 | **法官聲請** → 釋字 793（合憲） |

## 一、監察院的職權地圖

```
監察院
├── 監察權（主）
│   ├── 彈劾 ─ 對人，移送懲戒法院（像起訴）── 增修 §7 I
│   ├── 糾舉 ─ 對人（現少用）────────── 增修 §7 I
│   ├── 審計 ─ 對預算決算 ──────────── 增修 §7 I
│   └── 糾正 ─ 對事，促其注意改善 ──────── §97
├── 調查權（輔）── §95 調閱、§96 調查一切設施
└── 同意權 ── 已凍結（增修 §7 I）
```

- 同意權的由來：以前監察委員由地方議會間接選出，大法官由總統提名、監察院同意；修憲後已不存在。
- 糾正沒有法律效果，但政治上會運作（議員拿糾正質詢、新聞報導 → 機關開會檢討）；老師舉京華城案曾被監察院糾正。

## 二、要件 ②「行使職權」：五五波

| 正方（監察院） | 反方（行政院） |
|---|---|
| §95、§96 有調查權，調查黨產條例就是行使職權 | §95 前提是「**為行使監察權**」；監察權四項都不能對法律做什麼，何來調查權 |
| 不先調查，怎麼知道能不能行使監察權？調查先行合理 | §95 調閱的是行政院及部會的命令與文件，§96 調查行政設施；黨產條例是**法律** |
| 調查行政院為何對黨產條例不提覆議 | 提不提覆議是行政權核心，監察院憑什麼調查 |
| 不受理不也是司法院在評價監察院的權力？ | — |

## 三、要件 ③「適用法規範」：九比一

```
§47 文字順序：① 機關 → ② 行使職權 → ③ 適用法規範
實際的邏輯：  ① 機關 → ③ 立法院為它的職權打造的法律 → ② 這法律阻礙它行使職權
                                           （依法行政）
```

- 誰會適用黨產條例？**不當黨產處理委員會**。監察院行使職權適用的是**監察法**。
- 例：司法院大法官行使職權適用憲訴法；若認憲訴法 §30 阻礙其職權而無法開庭，主張「適用法規範」是成立的（是否拘束大法官是另一層次）。
- 行政院的強力論點：如果監察院這樣可以，**每一條法律**它都能「調查後聲請」，監察院不是釋憲機關；各主體設嚴格要件就是為了確保**不得已**。

## 四、歷史背景：為什麼以前寬、現在嚴

| | 1992 年立法院全面改選前 | 改選後 |
|---|---|---|
| 背景 | 戒嚴（1949～1987）、萬年國會（1948 年選出的立委做到 1991/12/31） | 民主化、立法院功能成熟 |
| 法律人 | 律師一年錄取極少；為人權奮鬥的律師（美麗島大審）入獄 | 律師大量增加 |
| 誰在抓違憲 | 監察院（1948 年大陸選出的士紳、讀書人）接受陳情、調查、聲請 | 九成是**人民**聲請，其次法院 |
| 大法官 | 從寬受理監察院聲請 | 1992～2018 年監察院聲請約五件 |

- 鑑定人質疑「以前寬、為何現在嚴」，大法官用法制史回應：以前寬是特殊歷史背景，現在嚴沒有問題。老師認為這段很有說服力。

## 五、考法

- 政大、臺大都考過，政大改成「**考試院**」聲請 → 要先找出考試院的職權，再看該法規範是否為其行使職權所適用。
- 看到國家最高機關聲請，一定想到 **1482 次不受理決議**。
