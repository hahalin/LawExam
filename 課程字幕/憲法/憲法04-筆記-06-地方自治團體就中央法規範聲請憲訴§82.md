# 憲法04 筆記：地方自治團體就中央法規範聲請（憲訴§82）

## §82 跟 §47 I 幾乎一樣：
- 主體換成**地方自治團體之立法或行政機關**（如臺北市議會、臺北市政府）
- 因**行使職權**，認所應適用之**中央法規範**牴觸憲法
- 多一個要件：對其受憲法保障之**地方自治權有造成損害之虞**

## 程序準用分兩組：
- §82 準用法規範憲法審查（§50～§54）→ 與國家最高機關、立委、法官同一組：釋憲完就結束
- §83 準用人民聲請（§60～§62 I）→ 與人民同一組：要用盡審級救濟、廢棄發回

## 例：釋字 748
- 同志伴侶到萬華區戶政登記被拒 → 臺北市政府認為民法有問題，當年（舊法）由臺北市政府聲請
- 以新法看：民法不涉及臺北市的自治權 → 不能依 §82；應由**國家最高機關**依 §47 聲請（老師說法）

## 📖 法條原文速查

> **憲訴 §82 I**（地方自治團體聲請法規範審查）　地方自治團體之**立法或行政機關**，因**行使職權**，認所應適用之**中央法規範**牴觸憲法，對其受憲法所保障之**地方自治權有造成損害之虞**者，得聲請憲法法庭為宣告違憲之判決。

> **憲訴 §82 II**　前項案件，準用第五十條至第五十四條規定。→ 準用範圍依老師口述，建議查閱最新六法原文

> **憲訴 §47 I**（對照）　國家最高機關，因本身或下級機關行使職權，就所適用之法規範，認有牴觸憲法者，得聲請憲法法庭為宣告違憲之判決。

---

## 📋 釋字速查

> **釋字 748 號**（2017 年）：民法婚姻章未使相同性別二人得為經營共同生活之目的，成立具有親密性及排他性之永久結合關係，違反憲法 §22 婚姻自由及 §7 平等權；限期 2 年修法。聲請人：**臺北市政府**、**祁家威**。

> 聲請人校正：釋字 748 實際的聲請人是**臺北市政府**與**祁家威**（舊大審法時代，地方機關得聲請，經上級機關行政院層轉）。老師說「最後是行政院」，是以**新法視角**說明：依憲訴法，臺北市政府不能依 §82 聲請，應由國家最高機關依 §47 聲請。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「地方自治團體依 §82 聲請，客體是什麼？」 | **中央法規範**（含法律、中央命令），不是自己的自治法規 |
| 「§82 比 §47 I 多了什麼要件？」 | 對受憲法保障之**地方自治權有造成損害之虞** |
| 「§82 聲請的主體？」 | 地方自治團體之**立法機關**（議會）或**行政機關**（市政府） |
| 「§82 與 §83 的準用對象？」 | §82 準用 **§50～§54**（法規範審查組）；§83 準用 **§60～§62 I**（人民組） |
| 「臺北市政府認民法未保障同性婚姻違憲，依新法可否依 §82 聲請？」 | 民法未損害其**地方自治權** → 不符 §82；應由國家最高機關依 §47 |

## 一、§82 與 §47 I 的要件對照

| 要件 | §47 I 國家最高機關 | §82 地方自治團體 |
|---|---|---|
| 主體 | 五院＋總統 | 地方自治團體之立法或行政機關 |
| 行使職權 | ✔ | ✔ |
| 客體 | 所適用之法規範 | 所應適用之**中央**法規範 |
| 額外要件 | — | 對**地方自治權**有造成損害之虞 |

- 地方自治權看起來像 power（權力），但被侵害時又像 right（權利），所以地方自治團體分 §82、§83 兩條，比較複雜。

## 二、準用分組：看聲請的目的

```
釋憲完就結束（法規範失效）           要廢棄確定裁判、發回
§53、§54 一組                        §62～§64 一組
├── 國家最高機關 §47                 ├── 人民 §59
├── 立委 §49                         └── 地方自治團體 §83
├── 法官 §55                              （準用 §60、§61、§62 I）
└── 地方自治團體 §82（準用 §50～§54）
```

- 憲訴法第三章（§47～§64）是考試最愛考的地方：§47 國家最高機關、§49 立委、§55 法官、§59 人民。

## 三、釋字 748 的聲請：用新法重看

```
同志伴侶 → 萬華區戶政拒絕結婚登記
                │
臺北市政府：民法沒保障同性婚姻有問題
                │
        §82？民法不涉臺北市自治權 → ✗
                │
        內政部（民法主管）→ 行政院
                │
        行政院行使職權、適用民法 → §47 聲請 ✓
```

- 老師半開玩笑：這筆功勞臺北市（柯文哲）、行政院、總統（蔡英文）都有份；但同婚與政黨沒有絕對關係。
- 另一聲請人祁家威：臺灣第一位在國際媒體公開出櫃的同志，一生爭取同婚合法化。
