# 憲法17 筆記：停建核四與國家重要事項的參與決策權（釋字520）

## 事實：
- 2000 年政黨輪替，新政府要**停建核四**；最簡單的方法是**不執行預算**
- 立法院多數仍支持興建；立法院主張核四屬 §63「**國家其他重要事項**」，立法院有權參與決定
- 行政院會議決議停止執行核四預算 → 與立法院發生適用憲法的爭議 → 行政院聲請（機關爭議）

## 520 把停止執行預算分三種情形：
- ① 維持機關運作的**法定經費**：停止執行致影響機關存續 → **不允許**（不能砍）
- ② 一般性調整、裁減：不涉國家重要政策變更、符合預算法要件 → 依合義務裁量**可以**
- ③ 涉及**施政方針或重要政策變更**（核四）→ 行政院應向立法院**提出報告並備質詢**，尊重立法院的**參與決策權**

## 立法院反對時：
- 行政院可**接受**多數意見、繼續執行；或與朝野黨團**協商**
- 協商不成 → 循**憲法現有機制**處理（院長辭職、不信任案、立法院制定相關法律等）
- 老師簡化：聽話、協商，或破局（有人下臺）

## 學者批評：
- 修憲後總統直選、任命行政院長不需立法院同意，權力應擺向行政權；520 卻以舊體制的思維擴大解釋「國家重要事項」→ 老師引許宗力教授見解：應**限縮**解釋

## 📖 法條原文速查

> **憲法 §63**　立法院有議決法律案、**預算案**、戒嚴案、大赦案、宣戰案、媾和案、條約案及**國家其他重要事項**之權。

> **增修 §3 II ①**　行政院有向立法院提出施政方針及施政報告之責。立法委員在開會時，有向行政院院長及行政院各部會首長質詢之權。

## 📋 釋字速查

> **釋字 520 號**（90 年 1 月 15 日；聲請人：行政院）要旨：
> - 維持法定機關正常運作及其執行法定職務之經費，倘停止執行致**影響機關存續**者，即**非法之所許**。
> - 若非屬國家重要政策之變更且具備預算法所定要件，主管機關依其合義務之裁量，自得裁減經費或變動執行。
> - 涉及施政方針或**重要政策變更**而停止執行法定預算，應由行政院院長或有關部會首長適時向立法院**提出報告並備質詢**；本件應儘速**補行**報告及備詢程序，立法院有聽取義務。
> - 立法院作成反對或其他決議 → 行政院得接受而繼續執行，或與立法院朝野黨團**協商**；協商不成，各有關機關應循**憲法現有機制**為適當之處理。
> - 理由書：立法院的反對決議主要具有**確認法定預算效力**的作用，不等同於可以強制行政院執行。
> → 原文建議查閱司法院網站

> 字號校正：字幕「4520」「4至520」即**釋字 520**；「4632」即**釋字 632**（見 憲法16-筆記-01）。許宗力教授的批評出處，建議查證。

## 一、預算三分法

```
行政院停止執行法定預算
│
├─ ① 維持機關運作的法定經費 → 影響機關存續 → 不允許
│     （對照 632：不審議人事、讓機關停擺，違反憲法忠誠）
│
├─ ② 一般調整、裁減，非重要政策 → 依預算法、合義務裁量 → 可以
│
└─ ③ 重要政策變更（核四）→ 立法院參與決策
        ├─ 行政院向立法院報告、備質詢
        ├─ 立法院支持 → 停止執行
        └─ 立法院反對 → 接受／協商／循憲法現有機制（破局：有人下臺）
```

## 二、為什麼是「國家其他重要事項」

| 主張 | 邏輯 |
|---|---|
| 行政院 | 不編、不執行預算，就沒有預算可議決（有預算案才有議決的問題） |
| 立法院 | 我議決的不只是預算，核四是**國家重要事項**，我有權參與 |

## 三、學者批評：體制變了，解釋也該變

```
修憲前：人民 → 國大 → 總統（間接）；行政院長須立法院同意
        → 立法院權力較大 → §63「國家重要事項」解釋得寬（X）

修憲後：人民 → 總統（直選）；總統任命行政院長，不需立法院同意
        → 權力應擺向行政權 → 「國家重要事項」應限縮（Y）
```

- 520 作成於 2001 年，距總統直選不久；學者認為大法官仍用 X 的方式解釋。
- **監督**是政治，**參與**是法律：立法院原本在政治上監督，520 變成要有絕對的參與機制，等於走回頭路。
- 老師：曾有人以「某任行政院長編列核四預算」批評其立場矛盾；依 520，立法院反對停建後，預算的效力獲得確認，行政院長編列不等於支持核四（具體事實建議查證）。
- 老師：520 以前常考，近年較少；但最近預算爭議多，仍要知道。
