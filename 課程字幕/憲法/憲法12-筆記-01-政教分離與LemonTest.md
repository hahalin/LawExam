# 憲法12 筆記：政教分離與Lemon Test

## 政教分離的核心：
- 政治與宗教**保持距離** → 國家**不偏袒**也**不歧視**任何宗教，確保各宗教平等
- 具體表現：不設國教、不以法律資助特定宗教、公立學校不強制推行宗教教育
- 例：法國總統出席教堂儀式時不參與儀式動作，避免被認為偏袒該宗教

## 美國的審查標準：Lemon Test
- 講義第 91～92 頁，老師沒有展開，只要求記住一點：法規範若有**促進宗教的效果**，就有很高的違憲風險

## 老師的提醒：比較法不能直接畫等號
- 西方有宗教戰爭、宗教與政治立場高度連結的歷史 → 政教分離是大問題
- 臺灣宗教多元但少有宗教爭議：總統拿香拜拜，很少有人認為違反政教分離
- 引用外國標準前，先問「這在臺灣是不是問題」；反過來，美國不是問題的，在臺灣可能是問題

## 📖 法條原文速查

> **憲法 §13**（信仰宗教自由）　人民有信仰宗教之自由。

> **憲法 §7**（平等權）　中華民國人民，無分男女、**宗教**、種族、階級、黨派，在法律上一律平等。→ 國家對各宗教應保持中立

---

## 📋 實務見解速查

> **Lemon v. Kurtzman**（美國聯邦最高法院，1971 年）：審查涉及宗教的法規範，通說整理為三要件：(1) 具有世俗目的；(2) 主要效果**不得促進或抑制宗教**；(3) 不得造成政府與宗教**過度糾纏**。三者有一不符即違反政教分離。→ 年份與三要件為補充，講義原文建議對照

> 對照 **釋字 573**（宗教中立原則，見 憲法11-筆記-09）：國家對宗教應謹守中立及寬容原則，不得對特定宗教加以獎勵或禁制。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「政教分離的核心？」 | 國家對宗教保持**中立**：不偏袒、不歧視，各宗教平等 |
| 「法規範對特定宗教有促進效果？」 | 違憲風險高（Lemon Test 第二要件：不得促進或抑制宗教） |
| 「我國宗教中立的實務依據？」 | **釋字 573**：國家應謹守**宗教中立**及寬容原則 |
| 「政教分離的考試份量？」 | 老師認為臺灣少有爭議，非重點；集會遊行才是本講的考點 |

## 一、西方與臺灣的差異

| | 西方（美、法） | 臺灣 |
|---|---|---|
| 歷史 | 宗教戰爭、宗教相關暴力事件 | 難以想像因宗教起義 |
| 宗教與政治立場 | 高度連結（例：福音派與特定政黨） | 信佛教不能推知支持哪一黨 |
| 宗教與社會議題 | 墮胎、安樂死與信仰（生命屬於神）綁在一起 | 墮胎、安樂死民調支持度高，較務實 |
| 政治人物參與宗教儀式 | 刻意避免 | 總統拿香、政治人物斬雞頭都常見 |

- 弔詭之處：美國總統宣誓時手按**聖經**。

## 二、讀比較法的態度

- 老師說法：教授常舉德國、美國、日本的例子，未必是因為那國制度值得參考，而是因為那是教授會的語言與資料。
- 憲法不能硬把別國的結論搬過來；重點是理解「為什麼在那裡是爭議」，再判斷在臺灣界線怎麼畫。
