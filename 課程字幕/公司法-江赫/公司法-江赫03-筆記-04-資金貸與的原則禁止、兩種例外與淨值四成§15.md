# 公司法-江赫03 筆記：資金貸與的原則禁止、兩種例外與淨值四成（§15）

## 原則（§15 I）：
- 公司的資金**不得貸與股東或任何他人**

## 兩種例外：
- ① 公司間或與行號間有**業務往來** → 可以借，**無上限**（經濟部 93.6.1 函）
- ② 公司間或與行號間有**短期融通資金必要** → 可以借，但融資金額不得超過**貸與企業淨值 40%**
- 短期融通的實務判斷：有沒有**計算利息**

## 計算：
- **淨值**＝資產總額 − 負債總額（資產負債表上的「權益」）
- 融資金額**累積計算**，已清償的不計入（經濟部 95.12.29 函）
- 注意基礎不同：轉投資看**實收股本** 40%，資金貸與看**淨值** 40%

## 違反效果（§15 II）：
- 公司負責人與借用人**連帶負返還責任**；公司受損害時負責人也要賠

## 📖 法條原文速查

> **§15**（資金貸與之限制）
> I　公司之資金，除有左列各款情形外，**不得貸與股東或任何他人**：
> 一、公司間或與行號間有**業務往來**者。
> 二、公司間或與行號間有**短期融通資金之必要**者。融資金額不得超過貸與企業**淨值的百分之四十**。
> II　公司負責人違反第一項規定時，應與借用人**連帶負返還責任**；如公司受有損害者，亦應由其負損害賠償責任。

---

## 📋 實務見解速查

> **經濟部 93.6.1 函**：因 §15 I ① 公司間有業務往來而貸與資金者，**不受**第二款「不得超過貸與企業淨值 40%」的限制。

> **經濟部 95.12.29 函**：計算融資金額是否超過淨值 40% 時，應以融資金額**累計計算**；貸款中已有清償者，不予計入。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司資金得貸與股東？」 | 原則**不得** |
| 「有業務往來的貸與，有金額上限？」 | **沒有**（經濟部 93 年函） |
| 「短期融通資金的上限？」 | 貸與企業**淨值 40%** |
| 「淨值怎麼算？」 | 資產 − 負債 |
| 「融資金額是否累積計算？」 | **是**；已清償者不計 |
| 「違反 §15 的效果？」 | 負責人與借用人連帶返還 |

## 一、課本 22 頁計算題

A 公司：實收資本 1,000 萬；資產 1,200 萬、負債 400 萬 → 淨值 **800 萬** → 40% ＝ **320 萬**

| 問題 | 判斷 | 結論 |
|---|---|---|
| (A) 貸與**無業務往來**的 B 公司 350 萬 | 走短期融通，上限 320 萬 | **不可以** |
| (B) 貸與**有業務往來**的 C 公司 350 萬 | 業務往來無上限 | **可以** |

## 二、資產負債表與淨值

```
資產負債表（balance sheet）
┌──────────┬──────────┐
│ 資產      │ 負債      │
│ 1,200 萬  │ 400 萬    │
│           ├──────────┤
│           │ 權益（淨值）│
│           │ 800 萬    │
└──────────┴──────────┘
會計恆等式：資產 − 負債 ＝ 權益
```

## 三、轉投資 vs 資金貸與

| | 轉投資（§13 II） | 資金貸與（§15） |
|---|---|---|
| 計算基礎 | **實收股本** 40% | **淨值** 40% |
| 適用 | 公開發行公司 | 短期融通（業務往來無上限） |
| 計算方式 | 累積 | 累積 |
