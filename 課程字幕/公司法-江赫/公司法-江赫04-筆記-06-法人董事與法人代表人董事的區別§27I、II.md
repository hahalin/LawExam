# 公司法-江赫04 筆記：法人董事與法人代表人董事的區別（§27 I、II）

## 政府或法人是公司股東時，兩種當選方式（§27，選擇申論都愛考）：
- **§27 I「法人董事代表人」**：以**法人股東本身名義**當選董事或監察人，再指定自然人代表行使職務 → 只能當選**一席**（董事或監察人擇一）
- **§27 II「法人代表人董事」**：以**代表人名義**當選；代表人有數人時可分別當選多席，但**不得同時當選或擔任董事及監察人**
- 實務上法人股東多用 II 項（可以當選多席）

## 兩項只能擇一行使：
- 法人股東只能用 I 項或 II 項，不能同時用（經濟部函）

## 報酬歸誰（101 台上 700）：
- I 項：委任關係在**法人股東**與公司之間 → 報酬給法人股東
- II 項：委任關係在**代表人**與公司之間 → 報酬給代表人

## 📖 法條原文速查

> **§27**（政府或法人股東）
> I　政府或法人為股東時，得當選為董事或監察人。但須指定**自然人代表**行使職務。
> II　政府或法人為股東時，亦得由其**代表人**當選為董事或監察人。代表人有數人時，得**分別當選**，但**不得同時當選或擔任董事及監察人**。
> III　第一項及第二項之代表人，得依其職務關係，**隨時改派**補足原任期。
> IV　對於第一項、第二項代表權所加之限制，不得對抗善意第三人。

---

## 📋 實務見解速查

> **經濟部函（年度請對課本）**：§27 I 與 II 的運作方式不同，法人股東**只能擇一行使**。

> **101 台上 700**：法人股東依 §27 I 當選董事或監察人，委任關係存在於**法人股東與被投資公司**之間；依 §27 II 由代表人當選者，委任關係存在於**代表人與被投資公司**之間，報酬給付對象因而不同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人以自己名義當選董事，依據？」 | §27 I（法人董事代表人） |
| 「§27 I 可當選幾席？」 | **一席**（董事或監察人擇一） |
| 「法人指派多名代表人分別當選董事？」 | 可以（§27 II） |
| 「法人得同時依 I、II 項當選？」 | **不得**，只能擇一 |
| 「依 §27 II 當選，董事報酬給誰？」 | **代表人**（101 台上 700） |

## 一、圖解（B 公司持有 A 公司 40%）

```
§27 I：B 公司（法人）自己當選 A 的董事（或監察人）
         └─ 指定自然人甲代行職務（像職務代理人）
         → 只有一席；報酬給 B

§27 II：B 公司指派 X、Y、Z 為代表人
         └─ X、Y、Z 以自己名義當選 A 的董事
         → 可多席；報酬給 X、Y、Z
         → 但不得「X、Y 當董事、Z 當監察人」（筆記 07）
```

## 二、兩項對照

| | §27 I 法人董事代表人 | §27 II 法人代表人董事 |
|---|---|---|
| 當選名義 | 法人股東 | 代表人 |
| 席次 | 一席 | 可多席 |
| 限制 | 董事或監察人擇一 | 不得同時當選董事及監察人 |
| 委任關係 | 法人股東 ↔ 公司 | 代表人 ↔ 公司 |
| 報酬 | 給法人股東 | 給代表人 |
| 代表人資格 | 法人指定的自然人 | 法人授權者即可（實務要指派同意書），不必是董事長 |
