# 公司法-江赫13 筆記：董事的報酬與酬勞（§196）

## 董事報酬（§196 I，選擇題愛考）：
- 未經章程訂明者，由**股東會議定**（普通決議），**不得事後追認**（不能先斬後奏）
- 目的：避免董事利用經營者地位**索取高額報酬**

## 章程或股東會能否授權董事會決定報酬（分三種）：
- ① **概括授權**（未定總額或比率）→ **不可以**，決議無效、不因事後追認有效（最高法院 98 台上 935）
- ② 訂明**總額或一定比率**再授權董事會分配 → **可以**（最高法院 93 台上 1264；實務常見「稅後盈餘 X%」）
- ③ 授權董事會**依同業通常標準**議定 → **可以**（經濟部函；是否超過同業標準由法院判斷）——學者批評太模糊，但實務多用這種

## 章程、股東會都沒定報酬，董事能否請求：
- 實務（最高法院 94 年判決）：依民法 §547，依習慣或委任性質應給報酬者，受任人仍得請求
- 劉連煜：董事未必是股東，難以想像無償承擔重大經營責任 → **有報酬請求權**（答題採此）
- 訴訟真正爭點是金額：同業通常標準

## 車馬費、交際費算不算報酬：
- 經濟部 93 年函（認為不算）已於 112 年**廢止**
- 現依最高法院 93 台上 532：看是否為**勞務對價**，不拘泥名稱
  - **每月固定支領** → 屬報酬（須章程或股東會決定）
  - **實支實付**（憑單據報銷）→ 只是費用，不屬報酬

## 董事報酬 vs 董事酬勞（經濟部 104 年後區分）：
- **報酬**：服勞務的對價（像月薪）；公司**有無盈餘都要付**；章程或股東會決定；未定仍可請求
- **酬勞**：盈餘分派的分紅；公司**有盈餘才發**；須**章程**訂明定額或比率，**不能用股東會決議代替**（經濟部 104.10.15 函）；章程未規定 → 視為**不發放**，沒有請求權
- 章程訂酬勞比率應以**上限**方式；當年度發放比例經董事會特別決議（經濟部函，少考）

## 📖 法條原文速查

> **§196 I**　董事之報酬，未經章程訂明者，應由**股東會議定**，**不得事後追認**。

> **民法 §547**　報酬縱未約定，如依習慣或依委任事務之性質，應給與報酬者，受任人得請求報酬。

## 📋 實務見解速查

| 來源 | 結論 |
|---|---|
| 最高法院 98 台上 935 | 未定總額或比率而概括授權董事會決定報酬，決議無效 |
| 最高法院 93 台上 1264 | 定有總額或比率者，得授權董事會決定個別董事報酬 |
| 經濟部函（課本 183 頁） | 得授權董事會依同業通常標準議定 |
| 最高法院 93 台上 532 | 每月固定支領的車馬費、研究費屬報酬，不拘泥名稱 |
| 經濟部 104.10.15 函 | 董事酬勞須章程訂明定額或比率，未規定視為不發放 |

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事報酬得由股東會事後追認？」 | **不得** |
| 「章程得概括授權董事會決定報酬？」 | **不得** |
| 「章程授權董事會依同業通常標準決定？」 | **可以** |
| 「每月固定支領的車馬費不屬報酬？」 | **錯**；屬報酬 |
| 「章程未規定董事酬勞，股東會得決議發放？」 | **不得** |

## 一、報酬 vs 酬勞

| | 董事報酬 | 董事酬勞 |
|---|---|---|
| 性質 | 服勞務的對價（月薪） | 盈餘分派（分紅） |
| 公司虧損 | 仍要付 | 不發 |
| 決定 | 章程或股東會 | 只能章程（定額或比率） |
| 未規定 | 仍有請求權 | 視為不發放 |

## 二、課本 199 頁第 4 題

正解：章程規定董監事報酬依**同業通常標準**授權董事會議定。概括授權、未經股東會由董事會自定、股東會概括委託董事會者，均錯。
