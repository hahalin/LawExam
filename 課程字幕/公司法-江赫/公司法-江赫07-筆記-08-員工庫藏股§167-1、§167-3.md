# 公司法-江赫07 筆記：員工庫藏股（§167-1、§167-3）

## 定位：
- 股份回籠禁止原則的例外；**只考選擇題**，背熟就送分
- 立法目的：促進**員工向心力**（買回後轉給員工作為獎勵，例如尾牙配股）

## 五個數字與門檻：
- 決議：**董事會特別決議**（2/3 以上董事出席，出席董事過半數同意）
- 數量：不超過已發行股份總數 **5%**
- 總金額：不得超過**保留盈餘＋已實現資本公積**
- 期限：**3 年內**轉讓給員工
  - 屆期未轉讓 → **視為公司未發行股份**，應辦理變更登記（減資）
- 買回期間：**不得享有股東權利**（例如無表決權）

## 限制員工轉讓（§167-3）：
- 公司得限制員工在一定期間內不得轉讓，最長 **2 年**

## 與證交法庫藏股的陷阱：
- 一試會把公司法與證交法的庫藏股混在選項裡
- 老師提示：證交法庫藏股轉讓員工期限是 **5 年**、數量上限 **10%**，總金額計算也不同（證交法課再統整）

## 📖 法條原文速查

> **§167-1**　I 公司除法律另有規定者外，得經**董事會**以董事三分之二以上之出席及出席董事過半數同意之決議，於不超過該公司已發行股份總數**百分之五**之範圍內，收買其股份；收買股份之總金額，不得逾**保留盈餘加已實現之資本公積**之金額。
> II 前項公司收買之股份，應於**三年內**轉讓於員工，屆期未轉讓者，**視為公司未發行股份**，並應辦理變更登記。
> III 公司依第一項規定收買之股份，**不得享有股東權利**。

> **§167-3**　公司依第一百六十七條之一或其他法律規定收買自己之股份轉讓於員工者，得限制員工在一定期間內不得轉讓。但其期間最長不得超過**二年**。

> 證交法庫藏股（§28-2）→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「員工庫藏股須股東會決議？」 | **錯**；董事會**特別**決議 |
| 「公司法庫藏股上限 10%？」 | **錯**；**5%**（10% 是證交法） |
| 「應於 5 年內轉讓員工？」 | **錯**；**3 年**（5 年是證交法） |
| 「逾期未轉讓，公司得繼續持有？」 | **錯**；視為未發行，辦理變更登記 |
| 「庫藏股在股東會有表決權？」 | **錯**；不得享有股東權利 |
| 「得限制員工 3 年內不得轉讓？」 | **錯**；最長 **2 年** |

## 一、時間軸

```
董事會特決買回（≤5%，金額 ≤ 保留盈餘＋已實現資本公積）
→ 公司持有期間：無股東權利
→ 3 年內轉讓員工 ── 員工取得後，公司可限制 ≤2 年不得轉讓
→ 3 年未轉讓：視為未發行 → 變更登記（減資）
```

## 二、公司法 vs 證交法（老師提示）

| | 公司法 §167-1 | 證交法 |
|---|---|---|
| 數量 | 5% | 10% |
| 轉讓員工期限 | 3 年 | 5 年 |
