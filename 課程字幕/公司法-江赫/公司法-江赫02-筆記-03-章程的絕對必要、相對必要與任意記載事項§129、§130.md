# 公司法-江赫02 筆記：章程的絕對必要、相對必要與任意記載事項（§129、§130）

## 絕對必要記載事項（§129）：
- 沒記載 → **章程無效**（類似票據的絕對必要記載事項）
- 六款：公司名稱、所營事業、股份總數（及每股金額）、本公司所在地、董監**人數及任期**、訂立章程年月日
- 選擇題不能翻法條，要背

## 相對必要記載事項（§130 等）：
- 沒記載章程仍有效，但該事項**不生效力**
- 白話：公司**想做這件事，必須先變更章程**才可以
- 常考：分公司設立、特別股、發起人特別利益、副董事長與經理人、盈餘分派次數增加

## 任意記載事項：
- 公司法沒規定的事項，依契約自由寫進章程（學者稱**章程自治**）
- 界限：不得牴觸法律、公序良俗，牴觸者該條款無效

## 📖 法條原文速查

> **§129**（絕對必要記載事項）　發起人應以全體之同意訂立章程，載明下列各款事項，並簽名或蓋章：
> 一、公司名稱。
> 二、所營事業。
> 三、採行票面金額股者，股份總數及每股金額；採行無票面金額股者，股份總數。
> 四、本公司所在地。
> 五、董事及監察人之**人數及任期**。
> 六、訂立章程之年、月、日。

> **§130 I**（相對必要記載事項）　下列各款事項，**非經載明於章程者，不生效力**：
> 一、分公司之設立。
> 二、解散之事由。
> 三、特別股之種類及其權利義務。
> 四、發起人得受之特別利益及受益者之姓名。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「章程未記載董事姓名，章程無效？」 | **錯**；只要記**人數及任期**，不記姓名 |
| 「章程未記載本公司所在地？」 | 絕對必要記載事項 → **章程無效** |
| 「章程應記載修改章程的年月日？」 | **是**；訂立年月日含歷次修改年月日 |
| 「有限公司章程要記載股份總數、每股金額？」 | **不用**；記載資本總額（出資額）與各股東出資、姓名 |
| 「公司設立分公司須先變更章程？」 | **是**（§130 ①，相對必要） |
| 「公司設副董事長、經理人須章程規定？」 | **是**（§208、§29） |

## 一、絕對必要記載事項（§129）

| 款 | 事項 | 補充 |
|---|---|---|
| ① | 公司名稱 | — |
| ② | 所營事業 | 依營業項目代碼表記載，但所營事業不受代碼限制（江赫01 筆記 09） |
| ③ | 股份總數（＋每股金額） | 票面金額股記兩者；無票面金額股只記股份總數；**有限公司**改記資本總額及各股東出資、姓名 |
| ④ | 本公司所在地 | — |
| ⑤ | 董監人數及任期 | **不記姓名**（董事一任三年常改選） |
| ⑥ | 訂立章程年月日 | 含**修改章程年月日**（最常考） |

## 二、常考的相對必要記載事項（老師整理）

| 事項 | 條文 |
|---|---|
| 分公司的設立 | §130 I ① |
| 特別股的發行 | §130 I ③、§157 |
| 發起人的特別利益 | §130 I ④ |
| 副董事長、經理人的設置 | §208、§29 |
| 盈餘分派次數增加（每季、半年度分派） | §228-1 |

（解散事由也是 §130 的一款，但沒考過。）

## 三、三種記載事項比較

| | 沒記載的效果 | 白話 |
|---|---|---|
| 絕對必要 | 章程**無效** | 每家公司都要寫 |
| 相對必要 | 章程有效，該事項**不生效力** | 想做就先改章程 |
| 任意記載 | — | 章程自治，不得違法、違反公序良俗 |
