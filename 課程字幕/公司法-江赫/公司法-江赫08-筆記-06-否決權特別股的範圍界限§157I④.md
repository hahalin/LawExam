# 公司法-江赫08 筆記：否決權特別股的範圍界限（§157 I ④）

## 是什麼：
- 對**特定事項**具有**否決權**的特別股（俗稱黃金特別股），可推翻公司的特定決定
- 只有**非公開發行公司**能發行（§157 III，大小分流）
- 應在章程中載明特定事項

## 否決權的範圍界限（經濟部 108.1.4 函，★ 可能出申論）：
- 行使否決權，**以股東會得決議的事項為限**
- **董事會**決議的事項 → **不得**行使否決權（例：經理人委任、解任、報酬）
- **董事選舉的結果** → 也**不得**行使否決權

## 先判斷事項屬於誰的權限：
- **股東會專屬**：法律或章程規定由股東會決議（例：減資、變更章程）→ 可以否決
- **董事會專屬**：法律規定由董事會決議（例：經理人委任、員工庫藏股）→ 不可以否決
- **董事會概括**：公司法沒明定交給誰的業務執行，依 §202 由董事會決議 → 不可以否決

## 為什麼這樣劃界（申論要寫）：
- 為了**貫徹企業經營與所有分離原則**（偏向**董事會中心主義**）
- 若特別股股東能否決董事會權限 → 股東凌駕董事會，背離分離原則
- 否決股東會權限 → 都是股東之間的事，不影響董事會與股東會誰比較大
- 寫法要保守：現代公司法「偏向」分離原則，不要寫成分離原則一定對

## 📖 法條原文速查

> **§157 I ④**　複數表決權特別股或對於**特定事項具否決權**特別股。

> **§202**　公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由**董事會**決議行之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「否決權特別股得否決董事會的員工庫藏股決議？」 | **不得**；董事會權限 |
| 「否決權特別股得否決股東會的減資決議？」 | **可以**；股東會權限 |
| 「否決權特別股得否決董事選舉結果？」 | **不得** |
| 「公開發行公司得發行否決權特別股？」 | **不得** |

---

## 一、判斷流程

```
特別股股東想否決某事項
→ 這件事由誰決定？
   ├─ 股東會專屬（減資、變更章程……）→ 可以否決
   ├─ 董事會專屬（經理人、員工庫藏股……）→ 不可以
   ├─ 董事會概括（§202 業務執行）→ 不可以
   └─ 董事選舉結果 → 不可以
```

## 二、權限劃分三分類

| 類型 | 依據 | 例 | 否決權 |
|---|---|---|---|
| 股東會專屬 | 法律或章程 | 減資（§168） | ✔ |
| 董事會專屬 | 法律 | 經理人委任（§29）、員工庫藏股（§167-1） | ✘ |
| 董事會概括 | §202 | 法律沒明定的業務執行 | ✘ |
