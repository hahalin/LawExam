# 公司法-江赫01 筆記：人合公司與資本公司的企業經營所有合一與分離

## 學理分類（劉連煜、柯芳枝等教科書）：
- **人合公司**：經營著重股東個人，信用基礎在股東個人；典型是**無限公司**
- **資本公司**：經營著重公司財產，不看股東個人信用；典型是**股份有限公司**

## 人合公司的特色：
- 合夥色彩濃（雖是公司，偏向合夥商號）
- 股東地位**移轉困難**（無限公司股東轉讓出資要其他股東同意）
- **企業經營所有合一**：經營者就是股東（無限公司執行業務的人必須是股東）

## 資本公司的特色：
- 法人格色彩濃
- 股東地位**移轉容易**（股份自由轉讓）
- **企業經營所有分離**：經營者不一定是股東，股份有限公司的董事**不必**具股東身分

## 為什麼要畫光譜：
- 考點只有一個：**合併只能同性質**（老師：人合跟人合、資合跟資合；不能跨類）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「最典型的人合公司？」 | **無限公司** |
| 「最典型的資本公司？」 | **股份有限公司** |
| 「股份有限公司董事須具股東身分？」 | **不須**；企業經營所有分離 |
| 「無限公司執行業務者須為股東？」 | **是**；企業經營所有合一 |
| 「無限公司得與股份有限公司合併？」 | 老師：**不得**，人合只與人合合併 |

## 一、光譜

```
人合 ←───────────────────────────────→ 資本
無限公司     兩合公司      有限公司        股份有限公司
（最人合）  （有無限股東） （有限責任，    （最資本）
                            但轉讓仍較難）
```

## 二、兩種公司對照

| | 人合公司 | 資本公司 |
|---|---|---|
| 典型 | 無限公司 | 股份有限公司 |
| 信用基礎 | 股東個人 | 公司財產 |
| 性質 | 合夥色彩濃 | 法人格色彩濃 |
| 股東地位移轉 | 困難 | 容易 |
| 經營與所有 | **合一**：經營者＝股東 | **分離**：經營者不必是股東 |

## 三、唯一考點：合併的同類限制（老師說明）

```
人合系：無限公司 ←→ 兩合公司
資合系：有限公司 ←→ 股份有限公司
跨類（例：無限公司併股份有限公司、有限公司併無限公司）→ 不行
```
