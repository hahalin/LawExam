# 公司法-江赫07 筆記：異議股東股份收買請求權（§186、§317、§187）

## 定位：
- 股份回籠禁止原則的例外：反對股東可請求公司以**當時公平價格**買回其股份
- 舊教科書稱「反對股東股份收買請求權」

## 兩種情形：
- ① **§186**：反對 §185 決議（如**讓與全部或主要部分營業或財產**）
  - 例：台積電把 2 奈米製程工廠全部賣掉，股東權益受重大影響
- ② **§317**：反對公司**合併或分割**

## 兩條的差異（一試會考異同）：
- §186：要表示**兩次**反對（會前書面通知公司＋會中反對），**可以投票**（投反對票）
- §317：表示**一次**異議即可（集會前或集會中，書面或口頭經記錄），且須**放棄表決權**
- 實務提醒：保險起見兩次都表示

## 收買流程（§187，會計師考試較常考）：
- 決議日起 **20 日內**，以書面記載股份種類及數額請求
- 協議價格者，公司應自決議日起 **90 日內**支付價款
- 決議日起 **60 日內**未達協議 → 股東應於此期間經過後 **30 日內**聲請**法院裁定價格**
  - 只能在**第 61～90 日**聲請；前 60 日內聲請 → 欠缺權利保護必要被駁回，拿到裁判時通常已過 90 日

## 行使後能否反悔：
- 經濟部 92.12.16 函：股份移轉於**價款交付時**生效
- 公司**已付款** → 不能反悔；**尚未付款** → 可以反悔

## 📖 法條原文速查

> **§186**　股東於股東會為前條決議前，已以**書面通知**公司反對該項行為之意思表示，並於股東會**已為反對**者，得請求公司以當時公平價格，收買其所有之股份。但股東會為前條第一項第二款之決議，同時決議解散時，不在此限。

> **§317 I（節錄）**　公司分割或與他公司合併時，……股東在集會前或集會中，以書面表示異議，或以口頭表示異議經記錄者，得**放棄表決權**，而請求公司按當時公平價格，收買其持有之股份。→ 建議查閱最新六法原文

> **§187**　I 前條之請求，應自第一百八十五條決議日起**二十日內**，提出記載股份種類及數額之書面為之。
> II 股東與公司間協議決定股份價格者，公司應自決議日起**九十日內**支付價款，自第一百八十五條決議日起**六十日內**未達協議者，股東應於此期間經過後**三十日內**，聲請法院為價格之裁定。
> III 公司對法院裁定之價格，自第二項之期間屆滿日起，應支付法定利息，股份價款之支付，應與股票之交付同時為之，**股份之移轉於價款支付時生效**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§186 股東只要會中反對即可？」 | **錯**；會前書面通知＋會中反對 |
| 「§317 股東仍得行使表決權？」 | **錯**；須放棄表決權 |
| 「請求應於決議日起 30 日內提出？」 | **錯**；**20 日** |
| 「股東得於決議後隨時聲請法院裁定價格？」 | **錯**；60 日未達協議後的 30 日內 |
| 「股東行使後一律不得撤回？」 | **錯**；價款交付前可以 |

## 一、§186 與 §317 對照

| | §186 | §317 |
|---|---|---|
| 反對的議案 | §185（讓與主要營業或財產等） | 合併、分割 |
| 表示反對次數 | **兩次** | **一次** |
| 方式 | 會前書面＋會中反對 | 會前或會中，書面或口頭經記錄 |
| 股東會現場投票 | 可以（投反對票） | **放棄表決權** |

## 二、§187 時間軸（決議日 = 第 0 日）

```
第 1～20 日：股東書面請求收買
第 1～60 日：雙方協議價格（不能聲請法院）
第 61～90 日：未達協議 → 聲請法院裁定價格（只有這 30 天）
第 90 日：協議成立者，公司應付款期限
```
