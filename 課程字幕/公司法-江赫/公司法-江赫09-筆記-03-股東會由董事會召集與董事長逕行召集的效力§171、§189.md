# 公司法-江赫09 筆記：股東會由董事會召集與董事長逕行召集的效力（§171、§189）

## 召集權人原則是董事會（§171）：
- 股東會除公司法另有規定外，由**董事會**召集，**不是董事長**
- 正常程序：董事長召集**董事會** → 董事會**決議**召集股東會 → 以董事會名義寄開會通知
- 依據：§171、§203 I（董事會由董事長召集）、§208 III（董事長是董事會主席）；78 台上 1573 判決

## 董事長沒經董事會決議就直接召集股東會：
- 實務（106 台上 1649）：屬**召集程序違反法令** → 股東會決議**得撤銷**（§189）
- 學說（王文宇一派）：董事長不是召集權人 → **無召集權人召集** → 股東會決議**不成立**
- 作答：選擇題用實務；申論題**兩說並陳**再擇一

## 為什麼要分清楚：
- 得撤銷 → 打**形成之訴**（撤銷訴訟，§189 有 30 日期間）
- 不成立 → 打**確認之訴**（要有確認利益）
- 訴訟種類不同，三種瑕疵（得撤銷、不成立、無效）不能混用

## 📖 法條原文速查

> **§171**（股東會之召集權人）　股東會除本法另有規定外，由**董事會**召集之。

> **§203 I 前段**　董事會由**董事長**召集之。→ 建議查閱最新六法原文

> **§208 III 前段**　董事長對內為股東會、董事會及常務董事會**主席**，對外代表公司。→ 建議查閱最新六法原文

> **§189**（決議之撤銷）　股東會之**召集程序**或其**決議方法**，違反法令或章程時，股東得自決議之日起**三十日內**，訴請法院**撤銷**其決議。

---

## 📋 實務見解速查

> **78 台上 1573 判決**：股東會由董事會召集（§171）；董事會由董事長召集，董事長為董事會主席（§203 I、§208 III）→ 股東會的**正常召集程序**是董事長先召集董事會，再由董事會**決議**召集股東會。

> **106 台上 1649 判決**：重申上述正常程序；董事長未依該程序，**逕以董事長名義**召集股東會，屬 §189「召集程序違反法令」得否訴請撤銷的問題，與**無召集權人召集**的股東會不同。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股東會原則上由董事長召集？」 | **錯**；由**董事會**召集（§171） |
| 「股東會的正常召集程序？」 | 董事長召集董事會 → 董事會決議召集股東會 |
| 「董事長未經董事會決議逕行召集股東會，決議效力（實務）？」 | 召集程序違法，決議**得撤銷**（106 台上 1649、§189） |
| 「同上，王文宇一派學說？」 | 無召集權人召集，決議**不成立** |
| 「決議不成立與得撤銷各打什麼訴訟？」 | 不成立 → **確認之訴**；得撤銷 → **形成之訴** |

## 二、董事長逕行召集的兩說

| | 實務（106 台上 1649） | 學說（王文宇一派） |
|---|---|---|
| 定性 | 召集**程序**有瑕疵 | **無召集權人**召集 |
| 效果 | 決議**得撤銷**（§189） | 決議**不成立** |
| 訴訟 | 撤銷之訴（形成之訴），30 日內 | 確認決議不成立之訴（確認之訴） |
| 理由 | 股東會規定偏程序性質 | 召集權人是董事會不是董事長；如同路人自稱召開某公司股東會，根本不是該公司的股東會 |

## 三、作答

- 選擇題：用**實務**（得撤銷）
- 申論題：**兩說並陳**，擇一即可；兩說都有支持者
- 出題背景：臺大邵慶平教授（王文宇老師的學生）可能出題，所以學說要寫
