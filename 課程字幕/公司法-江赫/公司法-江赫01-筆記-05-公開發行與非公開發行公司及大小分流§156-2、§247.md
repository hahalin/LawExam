# 公司法-江赫01 筆記：公開發行與非公開發行公司及大小分流（§156-2、§247）

## 最重要的公司分類：
- 公開發行公司＝取得向**不特定多數人**招募有價證券資格的公司（證交法叫「募集」）
- 非公開發行公司＝沒有這個資格
- 只有**股份有限公司**能經**董事會決議**向證券主管機關申請公開發行（§156-2 I）
- 無限、兩合、有限公司**必然**是非公開發行公司；股份有限公司沒申請也是非公開發行

## 大小分流（107 年修法主軸）：
- 非公開發行公司＝小公司 → **放寬公司自治**
- 公開發行公司＝大公司 → **維持強制規定**
- 公司法約 447 條中，一百多條用公開／非公開區分

## 申論題用法：
- 條文以公開／非公開區分 → 立法目的寫「**貫徹大小分流**，放寬非公開發行公司的公司自治，維持公開發行公司的強制規定」

> §247 只是拿來示範大小分流，條文本身之後公司債再講。

## 📖 法條原文速查

> **§156-2 I 前段**（申請公開發行）　公司得依**董事會之決議**，向證券主管機關申請辦理公開發行程序。→ 建議查閱最新六法原文

> **§247 I**（公司債總額限制）　**公開發行股票公司**之公司債總額，不得逾公司現有全部資產減去全部負債後之餘額。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「有限公司得申請公開發行？」 | **不得**；只有股份有限公司可以 |
| 「股份有限公司申請公開發行由哪個機關決議？」 | **董事會**（§156-2 I） |
| 「未申請公開發行的股份有限公司是何種公司？」 | 非公開發行公司 |
| 「非公開發行公司發行公司債有總額上限？」 | **沒有**；§247 只限制公開發行公司 |
| 「公司法 107 年修法的主軸？」 | **大小分流** |

## 一、分類圖

```
公司
├── 無限、兩合、有限公司 ──→ 必然非公開發行
└── 股份有限公司
     ├── 董事會決議申請公開發行（§156-2 I）──→ 公開發行公司
     └── 未申請 ──→ 非公開發行公司
```

## 二、大小分流

| | 非公開發行公司 | 公開發行公司 |
|---|---|---|
| 定位 | 小公司 | 大公司 |
| 立法方向 | **放寬公司自治** | **維持強制規定** |
| 例：公司債總額 | 無上限 | 不得逾淨值（§247 I） |

## 三、§247 為什麼是典型的大小分流

- 公司債＝公司向人借錢的債券，舉債太多會影響周轉
- §247 只規定**公開發行公司**的上限，找不到限制非公開發行公司的條文
- → 小公司放寬自治（借得到就好），大公司維持強制規定

## 四、作答提醒

- 公司法偏程序性規定，很難像證交法用一個立法目的（彌補資訊不對等）打到底
- 但凡條文用公開／非公開區分，就可寫「貫徹大小分流」
- 公開發行公司與上市櫃的區別在證交法講過，這裡不重複
