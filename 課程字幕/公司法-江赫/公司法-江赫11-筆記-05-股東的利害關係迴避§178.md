# 公司法-江赫11 筆記：股東的利害關係迴避（§178）

## 原則：一股一表決權（§179 I）
- 除本法另有規定外，每股有一表決權；利害關係迴避是例外

## §178：
- 股東對會議事項有**自身利害關係**致**有害公司利益之虞**時，**不得加入表決**，也**不得代理**他股東行使表決權
- 效果：**不得行使表決權** → 自**已出席股東表決權數**扣除（§180 II）
- 逐案判斷：只就有利害關係的那個議案迴避，其他議案照投

## 什麼是自身利害關係：
- **實務**：決議作成會使特定股東**取得或喪失權利、負擔或免除義務**（權利義務發生變動）
  - 例：公司向該股東買土地
- 學說批評：
  - ① 太過**籠統**
  - ② **持股越多越不能保護自己**：例如討論解任身兼大股東的董事，若一律迴避，持股 1% 的人就能年年提案逼大股東迴避
- 劉連煜老師：本條應刪除；未修法前應加上「股東有**公司外部純粹個人**利害關係」要件（解任董事屬內部事項 → 不迴避；賣地給公司屬外部 → 迴避）

## 考試建議記法——兩種有利害關係但**不用迴避**：
- ① **選任董事**：§198 II 明文排除 §178（股東可以投自己）
- ② **解任董事、監察人**：與選任一體兩面，同樣不用迴避
- 除此之外，依一般認知有利害關係（買賣土地、簽約、投資協議）→ 就要迴避

## 📖 法條原文速查

> **§178**　股東對於會議之事項，有**自身利害關係**致有害於公司利益之虞時，**不得加入表決**，並**不得代理**他股東行使其表決權。

> **§179 I**　公司各股東，除本法另有規定外，每股有一表決權。

> **§198 II**　第一百七十八條之規定，對於前項選舉權，不適用之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股東參選董事，不得投票給自己？」 | **錯**；§198 II 排除 §178 |
| 「股東會討論解任身兼股東的董事，該董事應迴避？」 | **不用**（通說） |
| 「有利害關係的股東得代理他股東投票？」 | **不得** |
| 「迴避股份自已發行股份總數扣除？」 | **錯**；自出席表決權數扣除 |

---

## 一、判斷流程

```
議案與某股東有無利害關係？
├─ 無 → 照常投票
└─ 有 → 是選任或解任董監嗎？
         ├─ 是 → 不用迴避
         └─ 否 → 迴避（不得投票、不得代理），第二式扣除
```
