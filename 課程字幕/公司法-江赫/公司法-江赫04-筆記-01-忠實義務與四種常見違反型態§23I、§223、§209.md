# 公司法-江赫04 筆記：忠實義務與四種常見違反型態（§23 I、§223、§209）

## §23 是公司法少數的請求權基礎（申論題考點）：
- §23 I：對**公司**的責任 → 忠實義務、善良管理人注意義務（兩者不同，有學者合稱「受任人義務」）
- §23 II：對**公司以外第三人**的責任（侵權責任，類似民法 §28）→ 筆記 05
- 開庭時法官會先問你用 I 項還是 II 項

## 忠實義務：
- 適用情境：**利害衝突**（負責人利益與公司利益衝突）
- 要求：以公司利益為最大優先，**不得圖謀自己或第三人利益**

## 四種常見型態：
- ① **自我交易**（公司與董事交易）
- ② 共通經營者的兩家公司交易（同一人兼任兩家董事，多見於母子公司）
- ③ **侵吞或利用公司機會**（私下轉單、收回扣）
- ④ **私下兼業**（董事競業、經理人兼業）

## 自我交易、董事兼業不是一律違反：
- 自我交易 → 看有沒有依 **§223** 由**監察人代表公司**，交易過程與結果是否正常
- 董事兼業 → 看有沒有依 **§209** 對股東會說明重要內容並取得**股東會特別決議**許可
- 符合程序就不違反忠實義務；不符合才違反

## 📖 法條原文速查

> **§23 I**（負責人對公司之責任）　公司負責人應**忠實執行業務**並盡**善良管理人之注意義務**，如有違反致公司受有損害者，負損害賠償責任。

> **§223**（董事與公司交易）　董事為自己或他人與公司為買賣、借貸或其他法律行為時，由**監察人**為公司之代表。

> **§209**（董事競業）
> I　董事為自己或他人為屬於公司營業範圍內之行為，應對股東會說明其行為之**重要內容**並取得其**許可**。
> II　股東會為前項許可之決議，應有代表已發行股份總數**三分之二以上**股東之出席，以出席股東表決權**過半數**之同意行之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「忠實義務規範的情境？」 | **利害衝突** |
| 「董事把土地賣給公司，一律違反忠實義務？」 | **不一定**；看是否由監察人代表公司（§223）及交易是否正常 |
| 「董事私下經營與公司同類業務？」 | 未經股東會**特別決議**許可 → 違反忠實義務（§209） |
| 「董事私下轉單、收回扣？」 | 違反忠實義務（侵吞利用公司機會） |

## 一、§23 架構

```
公司負責人的責任（§23）
├── 對公司（I 項）
│     ├── 忠實義務：利害衝突時不得圖利自己 ← 本筆記
│     └── 善良管理人注意義務：不得有應注意而未注意的過失 ← 筆記 02
│     → 違反效果：損害賠償＋利益歸入權（III 項）← 筆記 04
└── 對第三人（II 項）：與公司連帶賠償 ← 筆記 05
```

## 二、四種型態與判斷

| 型態 | 例 | 判斷重點 |
|---|---|---|
| 自我交易 | 董事與公司買賣土地 | 有無走 §223（監察人代表）、價格是否離譜 |
| 共通經營者交易 | 母公司董事兼子公司董事，母子公司交易 | 是否圖利自己 |
| 侵吞利用公司機會 | 私下轉單、收回扣 | 直接違反 |
| 私下兼業 | 賣雞排公司的董事另開雞排店 | 有無經 §209 股東會特別決議許可 |

自我交易不能一竿子打翻一船人：有的董事是為了幫公司度過難關，用低價把土地賣給公司。
