# 公司法-江赫16 筆記：107 律師二試長題的審題拆解

## 審題方法：
- 題目越長，**一邊看一邊審題**，看到可疑資訊先畫起來、旁邊寫可能的法條
- 不要全部看完才回頭找考點
- 下筆前先寫**大綱**，把「一定要涵攝的題目資訊」寫進大綱
- 經驗法則：**題目越長通常越簡單**；只有四行的題目才要小心
- 題目裡每一段資訊都有用意，沒有人會把沒用的資訊寫進題目

## 題目骨架（課本 236 頁第 12 題）：
- A 人壽是公開發行、未上市櫃公司，甲是董事長
- 段落一：甲應乙要求，用 A 的錢買 C 上市公司股票炒股價；投資長丙提醒已規劃投資 D、E，且買 C 可能違反保險業投資限額；甲堅持
- 段落二：A 董事會只聽 **5 分鐘報告**，以高於鑑價 10% 向董事長甲買地 50 億
- 段落三：兩年後以 60 億賣地給 X 公司，X 的董事長丁是**甲的配偶**；獨立董事戊**反對**；買入與賣出兩次董事會，甲都**未迴避**
- 段落四：前十大股東 F 書面請求獨立董事戊對甲、丙起訴

## 四個考點與大綱：
- **考點 1**：投資 C 股 → §23 I 善良管理人注意義務
  - 必須涵攝：保險業投資限額規定、公司內控辦法（超過 5 億須提報投資委員會）
- **考點 2**：向董事長買地 → §23 I ＋ **經營判斷法則**
  - 必須涵攝：只聽 5 分鐘報告 → 資訊不足的決策
- **考點 3**：賣地給配偶擔任董事長的 X 公司 → §206 III **配偶**擴大利害關係
  - 甲不是法人董事，所以**不是**控制從屬關係
  - 甲應說明、應迴避而未迴避 → 董事會決議**無效**
- **考點 4**：獨立董事戊反對 → §193 II **表示異議**的董事免責
  - 一開始不確定是否考點，看到後面股東要告「參與決議的董事」才確定
- 證交法順帶：獨立董事個人不能代表公司起訴，回歸**審計委員會**決定
