# 公司法-江赫09 筆記：說明主要內容與違反§172 V的效果（§172 V、§189）

## 舊爭點已由 107 年修法解決：
- 舊問題：變更章程列在召集事由時，要不要詳列修改的主要內容？
- 107.8.1 修法：明定九款事項要在召集事由中**列舉並說明主要內容**，採傳統學說

## 經濟部 108.1.22 函定調「說明主要內容」：
- 變更章程不能只寫「變更章程」「修改章程」幾個字
- 要寫出**變更第幾條**及**變更內容**

## 依同一邏輯，其他款也要寫出內容：
- 選任董監：改選幾席董事、幾席監察人
- 減資：減多少
- 解散：何時解散；合併、分割：跟誰；§185：讓與什麼主要財產

## 違反 §172 V 的三種態樣（申論題都考過）：
- ① 不得以臨時動議提出，卻以臨時動議提出
- ② 應在召集事由中列舉，卻未列舉
- ③ 有列舉，卻**未說明主要內容**（現在最常考）
- 任一種 → **召集程序違反法令** → 決議**得撤銷**（§189）

## 📖 法條原文速查

> **§172 V**　選任或解任董事、監察人、變更章程、減資、申請停止公開發行、董事競業許可、盈餘轉增資、公積轉增資、公司解散、合併、分割或第一百八十五條第一項各款之事項，應在召集事由中**列舉並說明其主要內容**，不得以臨時動議提出；其主要內容得置於**證券主管機關或公司指定之網站**，並應將其**網址載明於通知**。

> **§189**　股東會之**召集程序**或其決議方法，違反法令或章程時，股東得自決議之日起**三十日內**，訴請法院**撤銷**其決議。

---

## 📋 實務見解速查

> **經濟部 108.1.22 函**：§172 V 所謂「說明主要內容」，以變更章程為例，不得僅在召集事由記載「變更章程」或「修正章程」等字，應說明章程**變更或修正之處**（例如第幾條）**及其內容**（例如將票面金額股轉換為無票面金額股）。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「召集事由只寫『修改章程』，符合 §172 V？」 | **不符合**；要說明修正第幾條及內容（經濟部 108 年函） |
| 「減資議案在通知上只寫『減資』？」 | **不符合**；要說明減多少 |
| 「主要內容一定要印在紙本通知上？」 | 不一定；**得**置於主管機關或公司指定網站，並在通知載明**網址** |
| 「違反 §172 V 的決議效力？」 | 召集程序違法，**得撤銷**（§189） |
| 「以臨時動議改選董事，決議效力？」 | **得撤銷**，不是無效 |

## 一、違反 §172 V 的判斷流程

```
議案屬於 §172 V 九款之一？
   │ 否 → 不適用本項（可臨時動議）
   │ 是
   ↓
① 是否以臨時動議提出？        是 → 違反
② 是否在召集事由中列舉？      否 → 違反
③ 是否說明主要內容？          否 → 違反
   ↓（任一違反）
召集程序違反法令（§189）
   ↓
股東得自決議之日起 30 日內訴請撤銷 → 決議得撤銷
```

## 二、「說明主要內容」要寫到什麼程度

| 事項 | 通知上要說明的內容 |
|---|---|
| 選任、解任董監 | 改選幾席董事、幾席監察人 |
| 變更章程 | 修正第幾條、改成什麼內容 |
| 減資 | 減少多少資本 |
| 解散 | 何時解散、基準日 |
| 合併、分割 | 與哪家公司合併、分割 |
| §185 | 讓與哪些主要財產或營業 |

## 三、申論題提醒

- 公司法規定本身之外，一定要接著寫**違反的法律效果**
- §172 V 跟開會通知期間（筆記 07）一樣是**召集程序**問題 → 回到 §189 得撤銷
- 申論題可能只佔 5～7 分的小題，但三種態樣都要能辨識
