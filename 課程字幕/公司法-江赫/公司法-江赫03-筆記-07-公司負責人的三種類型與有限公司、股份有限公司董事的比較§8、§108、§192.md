# 公司法-江赫03 筆記：公司負責人的三種類型與有限公司、股份有限公司董事的比較（§8、§108、§192）

## 公司負責人的意義：
- 公司雖有法人格，仍要由自然人代為意思表示 → **直接參與或監督公司業務決策**的人

## 三種負責人：
- **當然負責人**（§8 I）：無限、兩合公司是執行業務或代表公司的股東；有限、股份有限公司是**董事**（全體董事，不只董事長）
- **職務負責人**（§8 II）：經理人、清算人、臨時管理人、**股份有限公司的發起人**、監察人、檢查人、重整人、重整監督人，在**執行職務範圍內**
- **實質負責人**（§8 III）：實質董事（影子董事）→ 筆記 08

## 陷阱：
- §8 II 只寫「股份有限公司之發起人」→ 無限、有限、兩合公司的發起人**不是**負責人（選擇題考過）

## 有限公司 vs 股份有限公司的董事（常考）：
- 有限公司（§108 I）：董事 **1～3 人**，須從**有行為能力的股東**中選任 → 偏企業經營所有合一
- 股份有限公司（§192 I）：董事**不得少於 3 人**，就有行為能力之人選任，**不以股東為限** → 企業經營所有分離

## 📖 法條原文速查

> **§8**（公司負責人）
> I　本法所稱公司負責人：在無限公司、兩合公司為執行業務或代表公司之股東；在有限公司、股份有限公司為**董事**。
> II　經理人、清算人或臨時管理人，**股份有限公司之發起人**、監察人、檢查人、重整人或重整監督人，在**執行職務範圍內**，亦為公司負責人。

> **§108 I**（有限公司董事）　公司應至少置董事**一人**執行業務並代表公司，最多置董事**三人**，應經股東表決權三分之二以上之同意，就**有行為能力之股東**中選任之。董事有數人時，得以章程置董事長一人，對外代表公司；董事長應經董事過半數之同意互選之。

> **§192 I**（股份有限公司董事）　公司董事會，設置董事**不得少於三人**，由股東會就**有行為能力之人**選任之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股份有限公司的負責人只有董事長？」 | **錯**；全體**董事**都是 |
| 「監察人是公司負責人？」 | 在執行職務範圍內**是**（§8 II） |
| 「有限公司的發起人是公司負責人？」 | **不是**；§8 II 只列股份有限公司發起人 |
| 「有限公司董事人數？」 | **1～3 人**，須為股東 |
| 「股份有限公司董事須為股東？」 | **不須**；且不得少於 3 人 |

## 一、負責人三類

| 類型 | 依據 | 誰 |
|---|---|---|
| 當然負責人 | §8 I | 無限、兩合：執行業務或代表公司股東；有限、股份有限：董事 |
| 職務負責人 | §8 II | 經理人、清算人、臨時管理人、股份有限公司發起人、監察人、檢查人、重整人、重整監督人（執行職務範圍內） |
| 實質負責人 | §8 III | 實質董事（筆記 08） |

## 二、兩種公司的董事

| | 有限公司（§108） | 股份有限公司（§192） |
|---|---|---|
| 人數 | 1～3 人 | 不得少於 3 人 |
| 身分 | **股東**（有行為能力） | 有行為能力之人，**不必是股東** |
| 選任 | 股東表決權 2/3 以上同意 | 股東會選任 |
| 特色 | 企業經營所有**合一** | 企業經營所有**分離** |
