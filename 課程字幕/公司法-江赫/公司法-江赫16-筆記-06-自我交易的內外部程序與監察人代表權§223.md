# 公司法-江赫16 筆記：自我交易的內外部程序與監察人代表權（§223）

## 自我交易總整理（★ 看到「公司跟董事交易」先判斷考內部還是外部）：
- **內部程序**（§206 II～IV）：董事會決議時，董事**說明**利害關係＋**迴避**投票 → 違反：董事會決議**無效**
- **外部程序**（§223）：簽約時由**監察人**代表公司，不找董事長（避免同事情誼、利害糾葛）
- 兩者不衝突，都是**忠實義務的具體化**；通常分開考

## §223：
- 董事為自己或他人與公司為買賣、借貸或其他法律行為時，由**監察人**為公司之代表
- 外部程序三個爭點常常一起出（課本 249 頁：101 司法官、103 中正法研所第 3 題）

## Q1：違反 §223（不是由監察人代表）效力？
- **無權代表**，類推適用無權代理 → 非經公司承認不生效力（最高法院 100 台上判決，字號以課本註 138 為準）
- 理由：相對人是董事本人，必定知情惡意，**沒有保護交易安全的必要**
- 對照：讓與主要財產未經股東會特決 → 採**相對無效說**（看相對人是否善意）；這裡不能採相對無效說

## Q2：監察人有數人時，如何代表？（兩說都要寫）
- **單獨代表說**（經濟部、劉連煜）：§221 監察人單獨行使 → 一人代表即可
- **共同代表說**（最高法院 100 台上 1026、王文宇）：§221 只講**監察權**，不及於**代表權** → 回歸民法 §168 共同代表
- 結論自選；老師採共同代表說（謹慎、避免利害衝突、貫徹忠實義務）

## Q3：監察人有沒有實質審查權？（例：公司跟董事買 1,000 萬的地，監察人能改成 800 萬嗎）
- **否定說**（王文宇、邵慶平）：
  - 文義推不出審查權
  - 所有與經營分離、董事會中心主義
  - §206 已有利害關係防免機制
- **肯定說**（劉連煜、**最高法院 100 年度第 3 次民事庭決議**，★ 結論採這說）：
  - 為防董事長礙於同事情誼損及公司，監察人代表公司與董事為法律行為，**無需經董事會決議核准**
  - 否則監察人淪為**橡皮圖章**
- 配分重就兩說並陳，配分輕直接寫肯定說

## 還沒考過的變化題（★）：
- 交易對象是**董事的配偶**：
  - 內部程序：§206 III 擴大 → 董事要說明、迴避
  - 外部程序：§223 文義限「董事為自己或他人」（他人指人頭），**沒有擴大**到配偶、二親等血親、控制從屬公司
- 答題建議：依現行法無從適用 §223，但為防利害衝突，**類推適用 §206 III** 視為董事有利害關係，仍由監察人代表

## 📖 法條原文速查

> **§223**　董事為自己或他人與公司為買賣、借貸或其他法律行為時，由監察人為公司之代表。

> **民法 §168**　代理人有數人者，其代理行為應共同為之。但法律另有規定或本人另有意思表示者，不在此限。

## 📋 實務見解速查

| 來源 | 結論 |
|---|---|
| 最高法院 100 年台上判決（課本註 138） | 違反 §223 非當然無效，公司事前許諾或事後承認即生效力 |
| 最高法院 100 台上 1026 | 監察人數人時共同代表 |
| 最高法院 100 年度第 3 次民事庭決議 | 監察人代表公司與董事為法律行為，無需經董事會決議核准 |

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「董事與公司交易，由董事長代表公司？」 | **錯**；監察人 |
| 「違反 §223 之交易當然無效？」 | **錯**；無權代表，得承認 |
| 「監察人代表公司前須經董事會核准？」 | 最高法院**不須** |
| 「董事配偶與公司交易，依 §223 由監察人代表？」 | 文義**不及**；可主張類推 |

| | 內部程序 | 外部程序 |
|---|---|---|
| 條文 | §206 II～IV | §223 |
| 內容 | 說明、迴避 | 監察人代表簽約 |
| 違反 | 董事會決議無效 | 無權代表，得承認 |
| 擴大到配偶等？ | **有**（§206 III） | **沒有** |
