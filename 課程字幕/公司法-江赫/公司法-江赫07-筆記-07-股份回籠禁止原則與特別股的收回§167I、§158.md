# 公司法-江赫07 筆記：股份回籠禁止原則與特別股的收回（§167 I、§158）

## 股份回籠禁止原則（★★★ 一試幾乎每年一題，二試也考）：
- 原則：公司**不得**將自己的股份**收回、收買或收為質物**（§167 I 本文）
- 例外（法條列舉）：§158 特別股收回、§167-1 員工庫藏股、§186 與 §317 異議股東股份收買請求權、§235-1 等
- 與股份有限公司**沒有退股機制**一脈相承

## 立法目的（申論要寫）：
- 貫徹**資本維持原則**：買回股份等於把股款退給股東
- 避免**炒作股價**：公司自己一直買，製造假性需求
- **最主要**：避免現任董監事藉此**鞏固經營權**的弊端
  - 公司買回的股份聽董事會、董事長的 → 股東會選董事時投給自己 → 用公司的錢鞏固經營權

## 例外一：特別股的收回（§158）：
- 公司發行的特別股**得收回**，但不得損害特別股股東依章程應有的權利
- 實務稱「**附買回條件特別股**」（例：約定 5 年後公司可收回），買的人事先知道，沒有保護交易安全的問題
- 收回的**資金來源**（★ 選擇題）：
  - 100 年 6 月修法前：限盈餘或發行新股所得股款
  - 現行：**不受限制**，可舉債、發行海外存託憑證、向金融機構借款

## 📖 法條原文速查

> **§167 I**　公司除依第一百五十八條、第一百六十七條之一、第一百八十六條、第二百三十五條之一及第三百十七條規定外，**不得自將股份收回、收買或收為質物**。但於股東清算或受破產之宣告時，得按市價收回其股份，抵償其於清算或破產宣告前結欠公司之債務。

> **§158**　公司發行之特別股，**得收回之**。但不得損害特別股股東按照章程應有之權利。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司原則上得買回自己股份？」 | **不得**（§167 I） |
| 「股份回籠禁止原則最主要的立法目的？」 | 避免鞏固經營權（另有資本維持、避免炒作股價） |
| 「公司收回特別股限用盈餘或發行新股股款？」 | **錯**；100 年後資金來源不受限制 |
| 「公司得借款收回特別股？」 | **可以** |

## 二、為什麼會鞏固經營權

```
公司用公司的錢買回自己股份
→ 這批股份由董事會、董事長控制
→ 股東會改選時投給現任經營者
→ 長期下來經營權被鎖住
```
