# 公司法-江赫05 筆記：股東有限責任與揭穿公司面紗（§154、§99）

## 原則：股東有限責任（§154 I）：
- 股東對公司的責任，以**繳清其股份之金額**為限
- 公司有法人格：A 公司欠第三人 B 貨款，B **不能**直接向 A 公司背後的股東求償

## 例外：揭穿公司面紗（§154 II，司律愛考，其他類科少考）：
- 防止股東躲在法人格後面規避債務
- 要件（都是不確定法律概念，實務極難成立）：
  - ① 股東**濫用**公司之法人地位
  - ② 致公司負擔**特定債務**且**清償顯有困難**
  - ③ **情節重大**而**有必要**
- 效果：該股東應**直接負清償責任**

## 立法理由的三個審酌要素（申論題要帶到）：
- ① 公司的**股東人數與股權集中程度**（越集中越容易成立）
- ② 系爭債務是否源於該股東的**詐欺行為**
- ③ 公司**資本額是否顯然不足**清償其所營事業可能產生的債務

## 有限公司也適用：
- §99 II 有限公司**明文**規定同樣內容（不是類推適用）
- 不限擔任董事的股東；符合要件的股東都可能負責

## 實務：
- 老師說臺灣實務成功適用的案例極少；考試敢考的是**工廠污染、食安**這類公安案型（RCA 案）

## 📖 法條原文速查

> **§154**　I 股東對於公司之責任，除第二項規定外，以繳清其股份之金額為限。
> II 股東**濫用**公司之法人地位，致公司負擔特定債務且**清償顯有困難**，其**情節重大而有必要**者，該股東應負清償之責。

> **§99 II**　股東濫用公司之法人地位，致公司負擔特定債務且清償顯有困難，其情節重大而有必要者，該股東應負清償之責。→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「揭穿公司面紗只適用股份有限公司，有限公司類推適用？」 | **錯**；有限公司**明文**規定（§99 II） |
| 「有限公司股東一律只負有限責任？」 | **錯**；可能適用揭穿公司面紗 |
| 「揭穿公司面紗只適用擔任董事的股東？」 | **錯**；符合要件的股東都可能 |
| 「股東對公司債務原則上負連帶清償責任？」 | **錯**；原則有限責任 |

## 一、老師設計的成立情境

```
股東甲持股 99%（股權高度集中）
→ A 公司向 B 買貨 3 億元，B 要求財力證明
→ 甲替 A 公司偽造財力證明（債務源於股東詐欺）
→ A 公司資產只剩幾塊錢（資本顯然不足）
→ 三要素都符合 → B 可直接向甲求償
```

## 二、111 年司律選擇題（課本 76 頁第 4 題）

**事實**：A 有限公司，股東甲、乙，甲任董事；A 從事食品加工，違法添加有毒物質致消費者受損；A 無資力，消費者想依揭穿公司面紗向股東求償。

| 選項 | 判斷 |
|---|---|
| (A) 只適用股份有限公司，但可**類推適用**於有限公司 | 錯；有限公司明文規定 |
| (B) 只適用股份有限公司，甲乙只負有限責任 | 錯 |
| (C) 有限公司也有明文，**有可能**向甲乙求償 | **對** ✔ |
| (D) 也適用有限公司，但**只適用擔任董事的股東** | 錯 |
