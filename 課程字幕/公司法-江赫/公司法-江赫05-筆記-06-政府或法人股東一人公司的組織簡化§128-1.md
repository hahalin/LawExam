# 公司法-江赫05 筆記：政府或法人股東一人公司的組織簡化（§128-1）

## 立法目的：
- 股東只有一人，內部組織越簡化越好，避免無謂的遵守成本
- 簡化分兩塊：**組織結構**（沒有股東會）＋**董監人數與選任**

## 組織結構簡化：
- **沒有股東會這個機關**，股東會職權由**董事會**行使（§128-1 I）
- 甚至可以不設監察人 → 三角形只剩董事

## 經濟部函釋（考試愛考）：
- 91.5.17：原屬股東會決議事項（含 §185、§277 等特別決議事項）→ 一律**董事會普通決議**（章程另有規定除外）
  - 理由：條文沒說特決就回歸原則走普決
- 103.12.5：會計年度終了後 **6 個月內**召開**董事會**承認會計表冊（財報）
  - 有學者批評：財報由董事會委任會計師編製，又由董事會自己承認，球員兼裁判；考試記經濟部結論即可

## 董監選任簡化：
- 董事、監察人**不用選舉**，由政府或法人股東**直接指派**（§128-1 IV）
- 是 **§27 II 但書**（不得同時當選或擔任董事及監察人）的**唯一例外**
- 104.5.4 函釋：因股份轉讓才變成單一法人股東公司 → 原董監**非由法人股東指派者**，須**重新指派**，產生**新任期**

## 人數簡化（選擇題愛考數字）：
- 原則：**三董一監**（董事至少 3 人、監察人至少 1 人）
- 例外：章程得規定不設董事會、置董事 1 人或 2 人；得不置監察人 → 最少**一董零監**
  - 董事 1 人：以其為董事長，董事會職權由該董事行使
  - 董事 2 人：準用董事會規定

## 📖 法條原文速查

> **§128-1**　I 政府或法人股東一人所組織之股份有限公司，不受前條第一項之限制。該公司之股東會職權由**董事會**行使，不適用本法有關股東會之規定。
> II 前項公司，得依章程規定不設董事會，置董事一人或二人；置董事一人者，以其為董事長，董事會之職權由該董事行使，不適用本法有關董事會之規定；置董事二人者，準用本法有關董事會之規定。
> III 第一項公司，得依章程規定不置監察人；未置監察人者，不適用本法有關監察人之規定。
> IV 第一項公司之董事、監察人，由政府或法人股東**指派**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「一人公司董事會行使股東會特別決議事項，須董事會特別決議？」 | **錯**；一律董事會**普通**決議 |
| 「一人公司財報由股東承認？」 | **錯**；**董事會**承認 |
| 「一人公司董監須由股東會選任？」 | **錯**；由政府或法人股東**指派** |
| 「一人公司法人股東之代表人不得同時擔任董事及監察人？」 | **錯**；§27 II 但書的唯一例外 |

| 「一人公司董事至少 3 人？」 | **錯**；章程得規定置 1 人或 2 人 |
| 「因股份轉讓成為一人公司，原董監續任至任期屆滿？」 | **錯**；非指派者須重新指派，新任期 |

## 一、人數對照

| | 一般股份有限公司 | 政府或法人股東一人公司 |
|---|---|---|
| 股東會 | 有 | **無**（職權由董事會行使） |
| 董事 | 至少 3 人 | 章程得置 **1 或 2 人** |
| 監察人 | 至少 1 人 | 章程得**不置** |
| 董監產生 | 股東會選任 | 股東**指派** |
| 俗稱 | 三董一監 | 最少一董零監 |

## 二、事後變成一人公司

```
原本：法人股東 X ＋ 自然人股東 Y（董監由股東會選任）
Y 把股份全賣給 X → 只剩法人股東 X
→ 適用 §128-1
→ 原董監不是 X 指派的 → X 重新指派 → 新任期
```
