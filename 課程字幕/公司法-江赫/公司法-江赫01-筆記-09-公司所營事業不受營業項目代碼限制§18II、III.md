# 公司法-江赫01 筆記：公司所營事業不受營業項目代碼限制（§18 II、III）

## 所營事業（§18 II）：
- 原則：公司所營事業**不受限制** → 鼓勵多角化經營
- 例外：**許可業務**（須經政府許可的業務）應**載明於章程**
- 常考的許可業務：**銀行、保險、證券**

## 營業項目代碼（§18 III）：
- 所營事業應依經濟部的**營業項目代碼表**登記（例：J101010、J905010）
- 有學說認為 §18 II（不受限制）與 §18 III（依代碼登記）看似衝突

## 爭點：公司經營章程未記載的代碼業務，是否違法？
- 結論：**不受營業項目代碼限制**
- 理由：代碼只記載於章程；§18 II 規定所營事業不受任何限制，章程不能牴觸法律 → 自然也不受章程記載的代碼限制
- 實務上代碼只是行政管理上的參考，沒有拘束力

## 📖 法條原文速查

> **§18 II**（所營事業）　公司所營事業除**許可業務**應**載明於章程**外，其餘**不受限制**。

> **§18 III**（營業項目代碼）　公司所營事業應依中央主管機關所定**營業項目代碼表**登記。已設立登記之公司，其所營事業為文字敘述者，應於變更所營事業時，依代碼表規定辦理。

## 一、§18 II 的原則與例外

```
公司所營事業
├── 原則：不受限制（賣玩具、賣雞排都可以）
└── 例外：許可業務 → 經政府許可＋載明於章程
         例：銀行（存匯款）、保險、證券
```

## 二、105 年高考三等申論題（課本 7 頁註 4）

### 事實（簡化成三句）
1. C 股份有限公司章程記載的營業項目只有 **J101010 建築物清潔服務業**
2. 董事會（全體董事同意）將公司資金轉向經營 **J905010 民宿業**
3. 結果大幅虧損；股東主張董事經營章程未記載的業務，應負賠償責任；董事主張 §18 II 不受限制

### 分析
1. 爭點：公司所營事業是否受營業項目代碼（章程記載）限制？
2. §18 III 要求依代碼表登記，但代碼只記載於章程
3. §18 II：除許可業務外，所營事業**不受限制**；民宿業不是許可業務
4. 章程不能牴觸法律 → 所營事業不受章程記載的代碼限制

### 結論
- 董事主張**有理由**；經營民宿業不違反公司法
