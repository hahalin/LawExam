# 公司法-江赫18 筆記：董事會特別決議事項總整理

## 口訣：「合庫換董事長，增資、發債、獎員工」
- 意象：合作金庫換了董事長，新官上任三把火 → 發行新股、發公司債、做員工獎勵
- 一試不能翻法條，背了就有分

## 逐項對照：
- **合**：簡易合併 — §316-2 I
- **庫**：買回庫藏股 — §167-1
- **換**：股份交換 — §156-3
- **董事長**：選任（解任同）董事長 — §208
- **增資**：發行新股 — §266 II（要突破章定股份總數 → 先股東會特決變更章程，§277）
- **發債**：
  - 募集公司債 — §246
  - 私募可轉換、附認股權公司債 — §248-1（另加股東會普決）
  - 私募普通公司債 — 類推 §356-11
- **獎員工**：
  - 員工酬勞 — §235-1
  - 員工認股權憑證 — §167-2
  - 員工庫藏股 — §167-1
  - ★ 例外：**限制員工權利新股**（§267 IX）→ **股東會**特決
