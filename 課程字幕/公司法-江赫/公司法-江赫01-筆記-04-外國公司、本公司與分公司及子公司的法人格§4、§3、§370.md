# 公司法-江赫01 筆記：外國公司、本公司與分公司及子公司的法人格（§4、§3、§370）

## 外國公司（§4 I）：
- 以營利為目的，依**外國法律**組織登記的公司
- 107 年修法前：還要經我國**認許**、在我國境內**營業**
- 現行法：**不用認許、不用營業** → 選擇題仍會考修法前後差異
- 要在臺灣營業 → 設立分公司，名稱**譯成中文**並標明種類、國籍（§370）

## 本公司與分公司（§3 II）：
- 本公司＝管轄全部組織的總機構（俗稱總公司）
- 分公司＝受本公司管轄的分支機構，是本公司的「手腳」，**沒有獨立法人格**
- 分公司的行為效力歸屬本公司；債權人可執行本公司及各分公司的全部財產
- 例外：分公司就**業務範圍內**事項有**當事人能力**，可用自己名義起訴、應訴（40 台上 39）
- 公司住所＝**本公司所在地**，不能以分公司所在地為住所（§3 I）

## 控制公司與從屬公司（母子公司）：
- 例：A 持有 B 已發行有表決權股份**超過半數** → A 控制、B 從屬
- 子公司**有獨立法人格**，分公司沒有 → 這是常考的比較

## 📖 法條原文速查

> **§4 I**（外國公司）　本法所稱外國公司，謂以營利為目的，依照**外國法律組織登記**之公司。

> **§3**（本公司、分公司與住所）
> I　公司以其**本公司所在地**為住所。
> II　本法所稱本公司，為公司依法首先設立，以管轄全部組織之總機構；所稱分公司，為受本公司管轄之分支機構。

> **§370**（外國公司在臺分公司名稱）　外國公司在中華民國境內設立分公司者，其名稱應**譯成中文**，並標明其種類及國籍。→ 建議查閱最新六法原文

> **§369-2 I**（控制公司）　公司持有他公司有表決權之股份或出資額，超過他公司已發行有表決權之股份總數或資本總額**半數**者為控制公司，該他公司為從屬公司。→ 建議查閱最新六法原文

> **民事訴訟法 §40 III**　非法人之團體，設有代表人或管理人者，有當事人能力。（老師說民法老師會講這條；字幕唸成「民法第 40 條第三項」）→ 建議查閱最新六法原文

## 📋 實務見解速查

> **40 台上 39**：分公司係由總公司分設之獨立機構，就其**業務範圍內之事項**涉訟時，有**當事人能力**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「現行法外國公司須經我國認許？」 | **不須**（107 年刪除認許） |
| 「外國公司須在我國境內營業才算外國公司？」 | **不須** |
| 「分公司有獨立法人格？」 | **沒有**；效力歸屬本公司 |
| 「分公司得否以自己名義起訴？」 | 就**業務範圍內**事項可以（40 台上 39） |
| 「債權人對某分公司勝訴，可執行哪些財產？」 | 本公司及所有分公司的**全部財產** |
| 「子公司與分公司的差別？」 | 子公司**有**獨立法人格，分公司**沒有** |
| 「公司得以分公司所在地為住所？」 | **不得**；以本公司所在地為住所（§3 I） |

## 二、分公司 vs 子公司

```
本公司（臺北）
 ├── 分公司（高雄）＝本公司的手腳
 │     沒有法人格：不能自己名義簽約、帳戶視為本公司的
 │     例外：業務範圍內事項可起訴、應訴
 └── （不是這條線）

A 公司 ── 持股超過半數 ──→ B 公司（子公司）
                             有法人格：自己簽約、保有自己財產
```

記法：子公司是「小孩」，再小也是一個人；分公司是「手腳」，剁下來不會變成一個人。

## 三、100 年律師選擇題（課本 51 頁第 43 題）

### 事實
- 甲、乙在開曼群島設立 A 股份有限公司，在臺設立臺北分公司營業
- 臺北分公司虧損，債權人丙以「A 股份有限公司臺北分公司」為被告，勝訴 250 萬元確定

### 選項
| 選項 | 敘述要旨 | 結論 |
|---|---|---|
| (A) | 只能執行臺北分公司的財產 | **錯**：分公司是 A 公司的一部分 |
| (B) | 可執行 A 公司本公司、臺北分公司及其他分公司的全部財產 | **對** |
| (C) | A 公司財產不足時，甲乙依出資比例負補充責任 | **錯**：股份有限公司股東負有限責任 |
| (D) | 甲乙與 A 公司負連帶責任 | **錯**：除非是無限公司 |

答案：**(B)**
