# 公司法-江赫15 筆記：董事會的權限劃分與轉授權（§202）

## 董事會中心主義：
- 董事會：全體董事組成的**法定、必備、常設**業務執行機關
- §202：公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由**董事會**決議行之
- 屬董事會權限的事項若由股東會決議 → 決議雖有效，但只有**建議性質**，對董事會沒有拘束力

## 三種權限：
- **股東會專屬權限**：法律規定交給股東會決定的事項
- **董事會專屬權限**：法律明定交給董事會的事項（例：買回庫藏股轉讓員工、經理人委任解任報酬）
- **董事會概括權限**：法律沒規定、透過 §202 解釋歸董事會的事項

## 轉授權三個考點（老考點，已定調）：
- 考點 1：股東會專屬權限能否以章程授權董事會？→ **不可以**
- 考點 2：董事會權限能否以章程授權股東會？→ 專屬權限**不可**；概括權限**可以**
- 考點 3：能否以章程授權董事長？→ 股東會專屬**不可**、董事會專屬**不可**、董事會概括**可以**
- 邏輯一句話：**專屬的不能轉授權，概括的可以**（經濟部 91.4.10 函同旨）

## 📖 法條原文速查

> **§202**　公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由董事會決議行之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「章程得將股東會專屬權限授權董事會？」 | **錯** |
| 「章程得將董事會概括權限交股東會決定？」 | **對** |
| 「章程得將董事會專屬權限授權董事長？」 | **錯** |
| 「股東會決議了屬於董事會權限的事項，董事會須遵守？」 | **錯**；只有建議性質 |

| 董事會專屬 | — | ✗ | ✗ |
| 董事會概括（§202） | — | ✓ | ✓ |
