# 公司法-江赫08 筆記：實質控制的母子公司不適用股份回籠禁止（§369-2、§369-3）

## 兩種母子公司（關係企業專章）：
- **形式控制**（§369-2 I）：持有他公司有表決權股份或出資額**超過半數**
- **實質控制**（§369-2 II）：**直接或間接控制他公司的人事、財務或業務經營**

## 實質控制適用股份回籠禁止嗎？（★ 考試出現機率最高）
- 最高法院 100 台上 1178：§167 III、IV 與 §179 II ②③ 的規範對象，**只限以出資關係形成的控制從屬**（形式控制）
- 法條文字本來就是「被持有……超過半數之從屬公司」
- 結論：實質控制的子公司
  - **可以**買進母公司股份
  - 已買的股份**有效且有表決權**
- 理由：實質控制**難以認定**（控制哪些人事、多少財務、多少營業額？每個法官判斷不同），形式控制看持股比例就知道

## 推定實質控制（§369-3，★ 會被拉來股份回籠考）：
- ① 兩公司**董事有半數以上相同**
- ② 兩公司已發行有表決權股份總數或資本總額**有半數以上為相同股東持有或出資**
- 被推定實質控制 → 同樣**不受**股份回籠禁止

## 「半數以上相同」怎麼算（經濟部 88.9.8 函，★）：
- 以**席次較高**的公司的半數為計算基礎

## 📖 法條原文速查

> **§369-2**　I 公司持有他公司有表決權之股份或出資額，超過他公司已發行有表決權之股份總數或資本總額**半數**者為控制公司，該他公司為從屬公司。
> II 除前項外，公司直接或間接**控制他公司之人事、財務或業務經營**者亦為控制公司，該他公司為從屬公司。

> **§369-3**　有左列情形之一者，**推定**為有控制與從屬關係：
> 一、公司與他公司之執行業務股東或**董事有半數以上相同**者。
> 二、公司與他公司之已發行有表決權之股份總數或資本總額有**半數以上為相同之股東持有或出資**者。

## 一、半數以上相同的計算

**已知**：甲公司董事 A、B、C、D、E（5 席）；乙公司董事 A、B、F（3 席）；相同 2 人。

| 以誰為基礎 | 半數 | 2 席是否達半數 |
|---|---|---|
| 乙（3 席） | 1.5 | 達到（但不採） |
| **甲（5 席，較高）** | 2.5 | **未達** → 不推定 |

要 **3 席以上**相同才推定。

## 二、113 司律選擇題（課本 110 頁第 7 題）

**事實**：A 上市公司持有 B 51%；B 持有 C 49%，並指派代表人當選 C 過半數董事；A 對 C 無持股；C 持有 A、B 各 1%。

| 關係 | 判斷 |
|---|---|
| A–B | 持股 51% → **形式控制** → B 不得買 A，已持有者無表決權 |
| A、B–C | B 持股 49% 未過半，但控制 C 董事會（人事）→ **實質控制** → C 可買 A、B，有效且有表決權 |

| 選項 | 判斷 |
|---|---|
| (A) B 可收買 A 股份 | 錯 |
| (B) C 不可買進 B 股份 | 錯 |
| (C) C 持有 A 1% 股份有表決權 | **對** ✔ |
| (D) C 持有 B 1% 股份無表決權 | 錯 |

解題步驟：畫持股圖 → 從最上層出發判斷是否母子 → 判斷形式或實質。
