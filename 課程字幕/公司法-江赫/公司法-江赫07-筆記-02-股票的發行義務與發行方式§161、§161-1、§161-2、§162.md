# 公司法-江赫07 筆記：股票的發行義務與發行方式（§161、§161-1、§161-2、§162）

## 股份 vs 股票：
- **股份**：權利（股東權）
- **股票**：表彰股份的**有價證券**（證書）
- 答題不要混用

## 股票種類：
- **記名股票**：記載股東姓名，以**背書**轉讓（§164）
- **無記名股票**：107.8.1 修法**刪除**；現在實體發行一律記名

## 發行時點（§161）：
- 設立登記或發行新股變更登記**後**，才能發行股票（公開發行公司證券主管機關另有規定除外）

## 有沒有發行股票的義務（§161-1，★ 選擇題）：
- **公開發行公司**：設立登記或發行新股變更登記後 **3 個月內**強制發行
  - 違反 → 新臺幣 24 萬～240 萬元罰鍰，得按次處罰至發行為止
- **非公開發行公司**：**自由選擇**是否發行（大小分流）

## 發行方式：
- ① **小面額股票**（俗稱獎狀型股票，§162）
  - 應編號、記載法定事項、代表公司的董事簽名或蓋章
  - 須經**銀行簽證**後發行 → 未經簽證，股票**無效**
- ② 單張大面額股票：107.8.1 修法**刪除**
- ③ **無實體發行**（§161-2，★）
  - 107 年修法前：限公開發行公司
  - 現行：**所有股份有限公司**均可，**不再區分**是否公開發行
  - 須洽**證券集中保管事業**登錄；轉讓、設質以**帳簿劃撥**為之（股東拿到的是集保存摺）
  - 上市櫃公司依證交法**強制**無實體發行

## 📖 法條原文速查

> **§161 I**　公司非經設立登記或發行新股變更登記後，不得發行股票。但公開發行股票之公司，證券管理機關另有規定者，不在此限。

> **§161-1 I**　公開發行股票之公司，應於設立登記或發行新股變更登記後**三個月內**發行股票。

> **§161-2**　I 發行股票之公司，其發行之股份得**免印製股票**。
> II 依前項規定未印製股票之公司，應洽證券集中保管事業機構登錄其發行之股份，並依該機構之規定辦理。
> III 經證券集中保管事業機構登錄之股份，其轉讓及設質，應向公司辦理或以**帳簿劃撥**方式為之，不適用第一百六十四條及民法第九百零八條之規定。
> IV 前項情形，於公司已印製之股票未繳回者，不適用之。

> **§162 I（節錄）**　發行股票之公司印製股票者，股票應編號，載明下列事項，由代表公司之董事簽名或蓋章，並經依法得擔任股票發行簽證人之**銀行簽證**後發行之。

> 上市櫃公司強制無實體發行之證交法條號 → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「所有股份有限公司都有發行股票的義務？」 | **錯**；只有公開發行公司 3 個月內強制發行 |
| 「非公開發行公司不得發行股票？」 | **錯**；自由選擇 |
| 「只有公開發行公司得無實體發行？」 | **錯**；107 年後所有股份有限公司都可以 |
| 「印製股票未經銀行簽證仍有效？」 | **錯**；無效 |
| 「現行法得發行無記名股票、單張大面額股票？」 | **錯**；107 年均已刪除 |

## 一、架構圖

```
是否要發行股票？
├─ 公開發行公司：3 個月內強制發行
└─ 非公開發行公司：自由選擇
     │
     ├─ 發行 → 實體（小面額股票，銀行簽證）
     │        → 無實體（集保登錄、帳簿劃撥；不分是否公開發行）
     └─ 不發行 → 讓與合意＋過戶登記（見筆記-03）
```
