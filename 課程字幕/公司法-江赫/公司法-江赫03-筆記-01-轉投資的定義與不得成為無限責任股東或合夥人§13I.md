# 公司法-江赫03 筆記：轉投資的定義與不得成為無限責任股東或合夥人（§13 I）

## 公司能力的三種限制（總則第七章，總則考點集中在這）：
- 轉投資限制（§13）→ 本筆記與筆記 02、03
- 資金貸與限制（§15）→ 筆記 04、05
- 保證限制（§16）→ 筆記 06
- 三者立法目的相同：**穩固公司財務**，希望公司嚴守本業

## 轉投資的意義：
- 公司以出資入股或受讓出資額、股份的方式，**成為他公司股東**
- 不論長期投資或短期買賣獲利都算
- 白話：A 公司買 B 公司的股票

## 不得成為無限責任股東或合夥人（§13 I）：
- A 公司不能成為**無限公司**的股東（＝無限責任股東），也不能成為**合夥事業**的合夥人
- 理由：無限責任的財務槓桿太大，犧牲公司有限責任、法人格的本質
- 經濟部 102.2.4 函：合夥人**包括民法 §703 的隱名合夥人**

## 📖 法條原文速查

> **§13 I**（轉投資限制）　公司不得為他公司**無限責任股東**或**合夥事業之合夥人**。

> **民法 §700、§703**（隱名合夥）　隱名合夥人僅於其出資之限度內，負分擔損失之責任。→ 建議查閱最新六法原文

---

## 📋 實務見解速查

> **經濟部 102.2.4 函**：依 §13 I，公司不得為合夥事業之合夥人，**包含民法 §703 之隱名合夥人**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司得為他公司無限責任股東？」 | **不得**（§13 I） |
| 「公司得為合夥事業的合夥人？」 | **不得** |
| 「公司得為隱名合夥人？」 | **不得**（經濟部 102 年函） |
| 「A 無限公司投資 B 無限公司 300 萬？」 | **不可以**：成為無限責任股東，與金額無關 |
| 「公司投資會計師合夥事務所？」 | **不可以**：成為合夥人 |

## 一、轉投資限制總圖

```
A 公司轉投資
├── 對象負無限責任（無限公司股東、合夥人含隱名合夥人）
│     → 一律不可以（§13 I）
└── 對象負有限責任（有限公司、股份有限公司股東）
      → 可以，再回頭看 A 自己是哪一種公司
         ├── A 是公開發行公司 → 實收股本 40% 上限（§13 II，筆記 02）
         └── A 是非公開發行股份有限公司、無限、兩合、有限公司
               → 無上限（筆記 03）
```

看題目先判斷「投資的對象」，再判斷「自己是誰」。
