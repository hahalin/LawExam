# 公司法-江赫04 筆記：法人股東改派代表人與董事長職位（§27 III）

## 隨時改派（§27 III）：
- §27 I、II 的代表人，法人股東得依職務關係**隨時改派**，補足原任期
- 代表人**死亡、辭職** → 可以改派
- 代表人被股東會**決議解任** → 法人股東**不能**依 §27 III 改派（老師說法）

## 學者批評（法研所考評析）：
- 代表人成了法人股東的「掌上木偶」，不聽話就換掉，沒有獨立性 → 主張刪除
- 不會刪：政府需要控制國營事業派去的董事（§27 I、II 也適用政府）

## 改派的新代表人是否當然接任董事長？（選擇題常考）
- **不會**；只補足**董事**任期
- 由副董事長、常務董事或董事互推一人代行董事長職權，召集董事會，依 §208 **重新選舉董事長**（經濟部 94.5.20 函）

## 📖 法條原文速查

> **§27 III**（改派代表人）　第一項及第二項之代表人，得依其職務關係，**隨時改派補足原任期**。

> **§208 I、II**（董事長之選任）　董事會未設常務董事者，應由三分之二以上董事之出席，及出席董事過半數之同意，互選一人為董事長……設常務董事者，董事長由常務董事依前項選舉方式互選之。→ 建議查閱最新六法原文

---

## 📋 實務見解速查

> **經濟部 94.5.20 函**：依 §27 I 或 II 產生之董事、監察人，得依職務關係隨時改派代表人補足原任期；但原代表人為**董事長**時，改派之新代表人**尚非當然繼任董事長**，應由副董事長、常務董事或董事互推一人代行董事長職權召集董事會，依 §208 I、II 重新選舉董事長。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人股東得隨時改派代表人？」 | **可以**，補足原任期（§27 III） |
| 「原代表人是董事長，改派的新代表人當然接任董事長？」 | **不會**；要重新選舉董事長 |
| 「學者對 §27 III 的批評？」 | 代表人淪為法人股東的木偶，欠缺獨立性 |

## 一、例子

```
B 公司派 X、Y 當選 A 公司董事，X 被選為 A 的董事長
B 公司嫌 X 不聽話 → 改派乙
   乙：接手 X 的董事席次，補足原任期 ✔
   乙：當然成為 A 的董事長？ ✘
   → A 公司董事會依 §208 重新選舉董事長
```
