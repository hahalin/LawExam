# 公司法-江赫09 筆記：監察人召集股東會與補充召集權（§220、§245）

## 監察人召集的兩條路：
- **主動**（§220）：董事會不為召集或不能召集之外，監察人得為公司利益，於必要時召集 → 考試常考
- **被動**（§245 II）：法院看了**檢查人**的報告認為必要，得命**監察人**召集股東會 → 少考，有印象即可

## 爭點：監察人召集是否以「董事會不為召集或不能召集」為前提？
- 否定說（經濟部 93.4.13 函）：90 年修法為強化監察人權限，監察人只要**為公司利益、必要時**即可召集，**不以董事會不作為為前提**
- 肯定說（最高法院 110 台抗 1423、107 台上 2174）：監察人（及審計委員會獨立董事）的召集權是**補充召集權**，須有董事會不能召集、不為召集或相類的必要情形，才可自行召集
- 關鍵字「**補充召集權**」五個字一定要寫

## 作答：
- 申論題兩說並陳，擇一
- 題目特別交代「董事會不想開、不能開」→ 採最高法院
- 題目沒交代，只問監察人可否召集 → 用經濟部函釋即可
- 監察人能否召集與**本身是否持股無關**

## 📖 法條原文速查

> **§220**（監察人召集股東會）　監察人除**董事會不為召集或不能召集**股東會外，得**為公司利益**，於**必要時**，召集股東會。

> **§245 II**（檢查人報告後命監察人召集）　法院對於檢查人之報告認為必要時，得命**監察人**召集股東會。→ 建議查閱最新六法原文

> **證交法 §14-4 IV**　公司法 §220 等監察人規定，對**審計委員會之獨立董事成員**準用之。→ 準用條號清單建議查閱最新六法原文

---

## 📋 實務見解速查

> **經濟部 93.4.13 函**：90.11.12 修正 §220 後，監察人行使召集權有兩種情形：① 董事會不為召集或不能召集；② 為公司利益於必要時。為強化監察人權限，監察人召集**不再限於**董事會不為召集或不能召集時。

> **最高法院 110 台抗 1423 裁定**（經營權之爭鬧雙胞的案件；字號請對課本）：§220 經證交法 §14-4 IV 準用於審計委員會獨立董事；所謂「必要時」，應有不能召開董事會、或董事會因故不召集股東會等**相類必要情形**，若任由獨立董事憑一己主觀隨時行使此**補充召集權**，將影響公司正常營運、有害公司利益。**107 台上 2174** 同旨。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「監察人主動召集股東會的依據？」 | **§220**：除董事會不為或不能召集外，為公司利益於必要時 |
| 「法院依檢查人報告，得命誰召集股東會？」 | **監察人**（§245 II） |
| 「最高法院對監察人召集權的定性？」 | **補充召集權**：須董事會不為、不能召集或相類必要情形 |
| 「經濟部 93 年函釋的見解？」 | 為公司利益必要時即可，**不以**董事會不作為為前提 |
| 「監察人本身沒有持股，不得召集股東臨時會？」 | **錯**；召集權與持股無關（110 年司律選擇題 D 選項） |
| 「審計委員會的獨立董事能否召集股東會？」 | 可，證交法 §14-4 IV 準用 §220，同受補充召集權限制 |

## 一、問題出在 §220 的寫法

```
§220：監察人「除董事會不為召集或不能召集股東會外」，得為公司利益，於必要時，召集股東會

讀法 A（經濟部）：兩種情形擇一
   ① 董事會不為／不能召集 → 監察人可召集
   ② 為公司利益、必要時   → 監察人也可直接召集，不用先問董事會

讀法 B（最高法院）：順位
   第一順位：董事會召集（§171）
          ↓ 董事會不為／不能召集（或相類必要情形）
   第二順位：監察人才可行使「補充召集權」
```

## 二、兩說對照

| | 否定說 | 肯定說 |
|---|---|---|
| 依據 | 經濟部 93.4.13 函 | 最高法院 110 台抗 1423、107 台上 2174 |
| 監察人召集前要不要先看董事會 | 不用 | 要；董事會不作為才輪到監察人 |
| 定性 | 獨立的召集權 | **補充召集權**（次順位） |
| 學者 | 有人支持 | 有人贊同，也有人認為限縮監察人權限 |
| 時期 | 早期多以此作答 | 110 年後最高法院見解 |

## 三、作答提示

- 題目寫「董事會不願召開」「董事會無法召開」→ 暗示要談補充召集權，採最高法院
- 題目只問「監察人得否召集股東會」→ 用經濟部函釋即可，區別實益不存在
- 為什麼這題重要：誰能召集股東會，就能改選董監、**搶經營權**
