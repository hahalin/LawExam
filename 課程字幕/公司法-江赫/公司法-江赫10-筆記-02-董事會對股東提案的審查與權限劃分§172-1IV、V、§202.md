# 公司法-江赫10 筆記：董事會對股東提案的審查與權限劃分（§172-1 IV、V、§202）

## 原則與不列入事由（§172-1 IV，★ 二試考點）：
- 股東提案，董事會**原則應列入**議案；有下列情形之一才不列入：
  - ① 該議案**非股東會所得決議**（★ 考試只考這款）
  - ② 停止過戶時持股**未達 1%**
  - ③ 在**公告受理期間外**提出
  - ④ 超過 300 字或提案超過一項

## 先判斷提案屬於誰的權限（舊考點 + 新考法）：
- §193（董事會應依股東會決議執行業務）與 §202（業務執行除法律或章程規定由股東會決議外，由董事會決議）看似矛盾
- 現行學說：為貫徹**企業經營與所有分離**，以 **§202** 為主
- 三種權限：
  - **股東會專屬**：法律或章程規定由股東會決議 → 股東會可決議
  - **董事會專屬**：法律明定由董事會決議（經理人委任、員工庫藏股、申請公開發行）
  - **董事會概括**：法律沒規定交給誰（慈善捐款、員工調薪）→ 依 §202 由董事會決議

## 提案屬董事會權限（非股東會所得決議）時：
- 107 年以前（**肯定說**，舊法通說）：可以列入，但股東會決議**無拘束力**，董事會自由決定
- **現行法（否定說）**：**不應列入**，避免**徒增議事負擔**
- 但書（§172-1 V，調和式立法）：提案是為**增進公共利益或善盡社會責任**的建議 → 董事會**得**列入（有選擇權）
  - 列入後，股東會決議仍**無拘束力**（回到舊法思考）

## 應列入而不列入的救濟（臺大法研考過）：
- 只有 §172-1 VII 罰鍰（學者批評太輕）
- **不能**訴請撤銷股東會決議：議案根本沒被討論，沒有可撤銷的決議標的
- 只能在股東會前聲請**定暫時狀態假處分**

## 📖 法條原文速查

> **§172-1 IV**　除有下列情事之一者外，股東所提議案，董事會應列為議案：
> 一、該議案**非股東會所得決議**。
> 二、提案股東於公司依第一百六十五條第二項或第三項停止股票過戶時，持股未達百分之一。
> 三、該議案於公告受理期間外提出。
> 四、該議案超過三百字或有第一項但書提案超過一項之情事。

> **§172-1 V**　第一項股東提案係為敦促公司增進**公共利益**或善盡**社會責任**之建議，董事會**仍得**列入議案。

> **§202**　公司業務之執行，除本法或章程規定應由股東會決議之事項外，均應由董事會決議行之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股東提案委任某學者為總經理，應列入？」 | **不列入**；董事會專屬權限，也非公益提案 |
| 「股東提案要求設置太陽能發電，董事會一定不得列入？」 | **錯**；涉社會責任，董事會**得**列入 |
| 「依 §172-1 V 列入並通過，董事會須遵守？」 | **錯**；無拘束力 |
| 「董事會違法不列入，股東得訴請撤銷股東會決議？」 | **錯**；只能假處分 |

## 一、判斷流程

```
股東提案（已符合 1%、一項、300 字、期間）
→ 提案內容屬誰的權限？
   ├─ 股東會專屬 → 應列入
   └─ 董事會專屬／概括（非股東會所得決議）
        ├─ 涉公共利益或社會責任 → 得列入（決議無拘束力）
        └─ 其他 → 不應列入
```

## 二、160 頁第 11 題：哪些應列入？

| 提案 | 判斷 |
|---|---|
| ① 持股 3% 股東甲提一案 | **列入** |
| ② 持股 5% 股東乙提三案 | 不列入（超過一項） |
| ③ 持股 10% 無表決權特別股股東丙提一案 | **列入** |
| ④ 0.3%＋0.3%＋0.5% 三股東共提一案 | **列入**（合計 1.1%） |
| ⑤ 持股 0.1% 股東提一案 | 不列入 |
| ⑥ 不含標點恰為 300 字 | 不列入（含標點超過） |
| ⑦ 提案委任某學者為總經理 | 不列入（董事會專屬） |
| ⑧ 超過公告受理期間 | 不列入 |

答案：3 種（①③④），選 C。

## 三、166 頁第 4 題（107 高考三等）要點

| 小題 | 答案 |
|---|---|
| 甲提案設置太陽能發電（甲持 50 萬股＝1%） | 原則非股東會所得決議，但涉社會責任，**得**列入；決議無拘束力 |
| 提案審查可否授權常務董事會 | **不可以**（法定董事會職權） |
| 310 字，不含標點恰 300 字 | **不列入** |
| 股東乙能否提修正案 | 屬臨時動議，未違反 §172 V 即可提出 |

## 四、112 司律（165 頁第 15 題）

正解 C（股東提案權只限股東常會）。D 錯在「股東會**後**說明未列入理由」，應於股東會**中**說明。
