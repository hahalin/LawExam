# 公司法-江赫01 筆記：公司的定義與公司、商號的區別（§1）

## 公司的定義（§1）：
- 以**營利**為目的，依公司法組織、登記、成立的**社團法人**
- 經營業務應遵守法令及商業倫理規範，**得**採行增進公共利益的行為，善盡社會責任
- 目的是私益（營利），但不妨礙做公益 → 兩項不衝突

## 考點不在「營利」，在「為什麼要開公司不開商號」：
- 商號＝獨資或合夥經營的事業，做**商業登記**
- 最大差別：公司有**獨立法人格**，商號沒有

## 法人格在商業上的白話意義：
- 公司可以用**公司名義**簽約、保有財產；契約關係在公司與相對人之間
- 商號只能用**出資人名義**簽約、開戶（例：「某某堂 張三」）
- 結果：公司股東負**有限**清償責任，公司債務只能執行公司財產；商號出資人負**無限**清償責任，個人財產也要賠

## 📖 法條原文速查

> **§1**（公司之定義）
> I　本法所稱公司，謂以**營利為目的**，依照本法組織、登記、成立之**社團法人**。
> II　公司經營業務，應遵守法令及商業倫理規範，**得**採行增進公共利益之行為，以善盡其社會責任。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司的目的是公益？」 | **錯**；以營利為目的，但**得**採行增進公共利益的行為（§1 II） |
| 「公司與商號最主要的差別？」 | 有無**獨立法人格** |
| 「股份有限公司財產不足清償，債權人得查封股東個人財產？」 | **不得**；股東負有限責任 |
| 「股東已繳足股款，其個人財產是否為公司債務的擔保？」 | **否** |
| 「商號負債，出資人個人財產要不要賠？」 | **要**；出資人負無限清償責任 |

## 一、公司與商號的四個差別

| 比較項目 | 公司 | 商號（獨資、合夥） |
|---|---|---|
| (A) 法人格 | **有** | **無** |
| 締約名義 | 公司 | 出資人 |
| 銀行帳戶 | 公司名義 | 商號名＋出資人名 |
| 出資人責任 | 有限清償責任（無限公司除外） | 無限清償責任 |
| (B) 適用法律 | 公司法 | **商業登記法** |
| (C) 主管機關 | 經濟部或直轄市政府 | 各縣市政府 |
| (D) 統一發票（實務，不考） | 一律要開 | 月營業額未達 20 萬元可申請免用 |

考試只會考 (A)。

## 二、法人格的白話推導

```
A 公司 ──買賣契約── 甲
   法律關係：A 公司 ↔ 甲
   貨款付不出來 → 甲只能執行 A 公司的財產
   → 股東最多賠掉出資，個人財產不受影響（有限清償責任）

張三開「某某堂」（商號）──買賣契約── 甲
   法律關係：張三 ↔ 甲（跟商號名稱無關）
   1,000 萬貨款付不出來 → 甲告張三、執行張三個人財產
   → 出資人無限清償責任
```

回答客戶時不要只說「法人格是權利義務主體」，要講到**股東只負有限責任**。

## 三、精選試題（課本 42 頁第 2 題）

### 事實
- A、B、C 各出資 100 萬元，設立甲股份有限公司
- 甲公司業務員送貨途中撞死人，法院判決甲公司與業務員連帶賠償 1 億元

### 選項
| 選項 | 敘述要旨 | 結論 |
|---|---|---|
| (A) | 業務員沒有其他財產時，債權人可查封 A、B、C 的個人財產 | **錯**：債務在甲公司，只能執行甲公司財產 |
| (B) | A、B、C 已繳足股款，其個人資產不作為甲公司債務的擔保 | **對**：股東負有限責任 |

答案：**(B)**
