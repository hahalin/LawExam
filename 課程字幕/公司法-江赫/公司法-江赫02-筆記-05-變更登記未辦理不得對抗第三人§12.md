# 公司法-江赫02 筆記：變更登記未辦理不得對抗第三人（§12）

## 兩種登記效力：
- **設立登記**：登記**生效**主義（§6），登記完成才取得法人格
- **設立後的變更登記**：登記**對抗**主義（§12）

## §12 的白話：
- 應登記而不登記，或已登記事項有變更而不辦變更登記 → **不得以其事項對抗第三人**
- 對第三人來說，**以原登記事項為準**

## 典型題型：
- 公司撤換總經理，拖了 30 天才辦經理人變更登記
- 這段期間原總經理仍代表公司簽約 → 對第三人以**原登記的總經理**為準 → 契約**有效**

> 來源：公司法-江赫02 課程字幕 01:19:14 ~ 01:25:37（課本 11 頁；100 年高考三等）

---

## 📖 法條原文速查

> **§12**（變更登記之對抗效力）　公司設立登記後，有應登記之事項而不登記，或已登記之事項有變更而**不為變更之登記**者，**不得以其事項對抗第三人**。

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「設立登記的效力？」 | **生效**要件（§6） |
| 「變更登記的效力？」 | **對抗**要件（§12） |
| 「總經理已撤換但未辦變更登記，原總經理代表公司簽的約，公司可否主張無效？」 | **不可**；不得對抗第三人，以原登記為準 |

## 一、100 年高考三等題

### 事實（簡化）
1. 甲原為 A 公司總經理，並已登記
2. 董事會撤換甲、改選乙，但**30 天後**才辦經理人變更登記
3. 撤換後、變更登記前，甲仍代表 A 公司與 C 公司簽約
4. A 公司主張甲已不是總經理，契約對 A 不生效力

### 分析
```
已登記事項（總經理＝甲）有變更（→ 乙）
     ↓ 未辦變更登記
§12：不得以「總經理已換成乙」對抗第三人 C
     ↓
對 C 而言，總經理仍以原登記的甲為準
     ↓
甲代表 A 簽的約，對 A 有效
```

### 結論
- A 公司的主張**無理由**

## 二、生效 vs 對抗

| | 設立登記 | 變更登記 |
|---|---|---|
| 條文 | §6 | §12 |
| 主義 | 登記生效 | 登記對抗 |
| 沒登記的效果 | 公司不成立 | 不得對抗第三人 |
