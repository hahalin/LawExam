# 公司法-江赫03 筆記：實質董事的要件與持股優勢加人事決定權的判斷（§8 III）

## 實質董事（影子董事）：
- 不是董事，但實質上執行董事業務，或實質控制公司人事、財務、業務經營而實質指揮董事 → 與董事**同負民事、刑事及行政罰責任**
- 例外：**政府**為發展經濟等公益，對其指派董事的指揮 → 不適用（臺電、臺水等）
- 申論題約三四年考一次，常搭配其他條文（忠實義務、§369-4 等）

## 要件：
- ① **所有類型的公司**都適用（107 年修法前只限公開發行公司 → 做舊考古題要注意）
- ② **不具董事身分**（榮譽董事、總裁、執行長、執行總裁都可能是）
- ③ **經常性**實質控制或執行董事業務（偶一為之不算）
- 實質董事也可以是**法人**

## 判斷徵兆（兩個同時出現）：
- 某人對公司有**持股優勢**
- 某人對公司有**人事決定權**（例：派的人占董事席次過半）
- 只有持股優勢可能只是大股東，一定要兩個都有

## 📖 法條原文速查

> **§8 III**（實質董事）　公司之**非董事**，而**實質上執行董事業務**或**實質控制公司之人事、財務或業務經營而實質指揮董事執行業務**者，與本法董事同負民事、刑事及行政罰之責任。但政府為發展經濟、促進社會安定或其他增進公共利益等情形，對政府指派之董事所為之指揮，不適用之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「實質董事限於公開發行公司？」 | **錯**；107 年修法後所有公司都適用 |
| 「政府指揮其指派的董事，構成實質董事？」 | **不構成**（§8 III 但書） |
| 「公司的總裁、執行長可能是實質董事？」 | **可能**，看是否經常性實質控制 |
| 「法人可以是實質董事？」 | **可以** |
| 「實質董事的責任？」 | 與董事同負民事、刑事、行政罰責任 |

## 一、93 年司法官申論題（課本 327 頁第 2 題）

### 事實
- A 公司（手機製造）陸續買進 B 公司（軟板基材）股份達 **65%**
- A 的 9 席董事中有 3 人當選 B 的董事，B 共 **5 席**
- 之後 A 向 B 購買基材的價格比市場行情低 5 成，A 市占率提高

### 判斷
```
持股優勢：A 持有 B 65% ✔
人事決定權：A 的人占 B 董事 5 席中 3 席（過半）✔
→ A（法人）是 B 的實質董事
→ B 的小股東可據此追究 A 的責任（另搭配 §369-4，關係企業再講）
```

## 二、107 年臺大法研所題（課本 60 頁第 7 題）

### 事實
- A 公開發行公司（生技），董事 5 席
- B 非公開發行公司（腳踏車）持有 A **30%**，指派甲、乙、丙當選 A 的 **3 席**董事
- B 的子公司 C 財務困難；A 與 C **無業務往來、也無短期融通必要**
- A 董事會在甲乙丙主導下無異議通過借 C 2 億元

### 判斷
```
持股優勢：30%，有一定分量（視公司規模）
人事決定權：A 的 5 席中 3 席 ✔
→ B 是 A 的實質董事
→ 借款不符 §15 兩種例外，且圖利自己的子公司 → 違反忠實義務
```
