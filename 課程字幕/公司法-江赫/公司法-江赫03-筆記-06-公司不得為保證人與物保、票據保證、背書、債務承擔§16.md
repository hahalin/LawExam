# 公司法-江赫03 筆記：公司不得為保證人與物保、票據保證、背書、債務承擔（§16）

## 原則與例外（§16 I）：
- 原則：公司**不得為任何人之保證人**
- 例外：依**其他法律**（銀行法、保險法）或**公司章程**規定得為保證者（章程規定屬任意記載事項）
- 例：百貨公司禮券背面「經某銀行保證支付」

## 只經全體股東同意可以嗎？
- **不可以**；沒有變更章程、法律也沒規定，即使全體股東同意也不得保證（經濟部 81.10.20 函）

## 特殊保證型態（選擇題愛考）：
- **物上保證**（為他人設定抵押權）→ **不可以**（74 台上 703）
- **票據保證** → **不可以**（保證就是保證）
- **票據背書** → **可以**（91 台簡上 30：背書與保證性質不同，不在 §16 禁止範圍）
- **債務承擔** → **不可以**（92 台上 914：責任較重，舉輕明重）
- 有法律或章程規定時，上述都可以

## 違反效果（§16 II）：
- 公司負責人**自負保證責任**；公司受損害時負責人負賠償責任

## 📖 法條原文速查

> **§16**（保證之限制）
> I　公司除依其他**法律**或公司**章程**規定得為保證者外，**不得為任何保證人**。
> II　公司負責人違反第一項規定時，應**自負保證責任**，如公司受有損害時，亦應負賠償責任。

---

## 📋 實務見解速查

> **經濟部 81.10.20 函**：公司除依其他法律或章程規定得為保證外，不得為任何保證人，自**不得僅經全體股東同意**而對外保證。

> **74 台上 703**：公司提供財產為他人設定擔保物權，就公司財務之影響而言，**與為他人保證人之情形無異**，仍在禁止之列。

> **91 台簡上 30**（字號請對課本）：票據背書與民法保證性質不同，公司在票據上背書**不在 §16 禁止範圍**，應依票據法負背書人責任。

> **92 台上 914**：保證既為法律所禁止，依舉輕以明重之法理，**責任較重的債務承擔**，更在禁止之列。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「公司得為保證人？」 | 原則**不得**；法律或章程規定者除外 |
| 「全體股東同意，公司即可對外保證？」 | **不可以** |
| 「公司為他人設定抵押權？」 | **無效**（74 台上 703） |
| 「公司在支票上背書？」 | **有效**（不在 §16 範圍） |
| 「公司做票據保證？」 | **不可以** |
| 「公司為他人承擔債務？」 | **不可以**（92 台上 914） |
| 「違反 §16 的效果？」 | 負責人自負保證責任 |

## 一、票據保證 vs 票據背書（老師補充）

```
發票人甲 ──本票──→ 受款人乙 ──背書轉讓──→ 執票人丁
   │
   保證人丙（票據保證，與甲同一順位）

丁請求付款：先找甲或丙（同順位）→ 都沒錢才找背書人乙
本票裁定可以對票據保證人聲請，不能對背書人聲請
```

公司當丙（保證）→ 不行；公司當乙（背書）→ 可以。學說批評背書實質上也有擔保作用，但選擇題照實務作答。
實務用語：從客戶手上背書轉來的票叫「客票」。

## 二、106 年司律選擇題（課本 52 頁第 50 題）

| 選項 | 敘述要旨 | 結論 |
|---|---|---|
| (A) | 章程有記載得對外保證，公司可為子公司擔任保證人 | **對** |
| (B) | 章程無保證規定，公司為子公司債務承擔有效 | 錯：債務承擔禁止 |
| (C) | 公司在支票上背書，違反 §16 不生效力 | 錯：背書有效 |
| (D) | 公司提供不動產為他人設定抵押權，對公司有效 | 錯：物保禁止 |

答案：**(A)**
