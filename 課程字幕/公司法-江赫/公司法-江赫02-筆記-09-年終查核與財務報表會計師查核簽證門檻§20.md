# 公司法-江赫02 筆記：年終查核與財務報表會計師查核簽證門檻（§20）

## 年終查核（§20 I）：
- 每會計年度終了，營業報告書、財務報表、盈餘分派或虧損撥補議案 → 提請**股東同意或股東常會承認**
- 實務上股東會第一案常是「承認年度財務報表」，依據就是這條

## 財報要不要會計師查核簽證（§20 II，愛考）：
- 資本額達一定數額，或未達但達一定規模 → 財報先經**會計師查核簽證**
- 經濟部 107.11.8 函定門檻：
- **實收資本額 3,000 萬元以上** → 一定要簽證
- 未達 3,000 萬，但**營業收入淨額達 1 億元**或**參加勞保員工達 100 人** → 也要簽證
- 都沒達到 → 不用，自己編即可

## 與證交法的連結：
- 公開發行公司實收資本通常遠超 3,000 萬，所以年度財報一定經會計師查核簽證

## 📖 法條原文速查

> **§20**（年終查核）
> I　公司每屆會計年度終了，應將**營業報告書、財務報表**及**盈餘分派或虧損撥補**之議案，提請股東同意或**股東常會承認**。
> II　公司**資本額達一定數額以上**或**未達一定數額而達一定規模**者，其財務報表，應先經**會計師查核簽證**；其一定數額、規模及簽證之規則，由中央主管機關定之。但公開發行股票之公司，證券主管機關另有規定者，不適用之。

## 📋 實務見解速查

> **經濟部 107.11.8 函**：§20 II 所謂資本額達一定數額，指財務報導期間結束日**實收資本額達新臺幣 3,000 萬元以上**；未達 3,000 萬元而達一定規模，指符合下列之一：① **營業收入淨額達新臺幣 1 億元**以上；② **參加勞工保險員工人數達 100 人**以上。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「實收資本 3,000 萬元的公司，財報要會計師簽證？」 | **要**（含 3,000 萬） |
| 「實收資本 2,000 萬、營收 1.2 億元？」 | **要**（營收達 1 億） |
| 「實收資本 2,000 萬、勞保員工 80 人、營收 5,000 萬？」 | **不用** |
| 「年度財報由何機關承認？」 | **股東常會**（或股東同意） |

---

## 一、判斷流程

```
實收資本額 ≥ 3,000 萬？ ── 是 → 要簽證
        │ 否
營業收入淨額 ≥ 1 億？ ── 是 → 要簽證
        │ 否
參加勞保員工 ≥ 100 人？ ── 是 → 要簽證
        │ 否
不用簽證
```

## 二、注意

- 門檻看的是**實收**資本額，不是章定資本
- 臺灣不是所有公司財報都要簽證，只有一定規模以上的才要
