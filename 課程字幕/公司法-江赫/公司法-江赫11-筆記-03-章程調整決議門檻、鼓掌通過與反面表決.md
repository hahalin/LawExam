# 公司法-江赫11 筆記：章程調整決議門檻、鼓掌通過與反面表決

## 章程能不能調整普決、特決門檻（一試考點）：
- **降低**：一律**不可以**——法定出席數、表決權數是**最低限度強制規定**，降低易讓少數人把持股東會
- **調高**：
  - 舊見解（肯定說）：臺灣高等法院 100 上 776、經濟部 100.2.23 函 → 強制範疇外回歸私法自治，可以調高（甚至 100% 出席、100% 同意）
  - **現行（否定說）**：經濟部 **108.5.8** 函廢止舊函 → 只有公司法**明文**規定「章程有較高規定者從其規定」時才能調高（例：§13、§29、§185 III、§277 IV）
  - 理由：保障交易安全，不能期待股東、債權人都查閱章程；避免企業運作形成僵局
- 假決議門檻：調高、降低都**不可以**（經濟部 104.7.29 函，見筆記-02）

## 鼓掌通過：
- **不可以**（最高法院 91 台上 2496）：無法計算各候選人或議案的贊成、反對票數
- 例：選董監時主席要求鼓掌通過推舉名單 → 違反累積投票制

## 反面表決：
- **不可以**（最高法院 90 台上 671）
- 反面表決 = 只算反對票，沒表示反對就視為同意
- 理由：股東對議案可能**同意、反對、無意見**；沉默不等於默示同意

## 📋 實務見解速查

| 來源 | 結論 |
|---|---|
| 臺灣高等法院 100 上 776 | （舊）章程得採較高標準之決議方法 |
| 經濟部 108.5.8 函 | 限公司法明文允許章程較高規定者，始得調高；廢止 100.2.23 函 |
| 最高法院 91 台上 2496 | 鼓掌通過無法計算票數，違反公司法 |
| 最高法院 90 台上 671 | 只計反對股數、未反對者視為贊成，違反公司法 |

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「章程得降低股東會特別決議門檻？」 | **不得** |
| 「章程得任意提高股東會普通決議門檻？」 | 現行**不得**；限法律明文允許 |
| 「股東會得以鼓掌方式通過議案？」 | **不得** |
| 「股東會得採反面表決？」 | **不得** |
