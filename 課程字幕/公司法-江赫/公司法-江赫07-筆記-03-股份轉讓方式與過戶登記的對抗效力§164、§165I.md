# 公司法-江赫07 筆記：股份轉讓方式與過戶登記的對抗效力（§164、§165 I）

## 股份怎麼轉讓：
- 記名股票（實體）：讓與合意＋**背書**轉讓（§164）
- 無實體發行：**帳簿劃撥**（§161-2 III）
- **未發行股票**（★ 選擇題）：經濟部 60.1.15 函 → 轉讓人、受讓人填具**受讓同意書**（讓與合意），並參考 §165 會同公司辦理**過戶**

## 股東名簿的兩層意涵：
- ① 股東會**開會通知書**寄給誰、寄到哪（寄到名簿以外地址 → 不生送達效力）
- ② **盈餘分派**（股息、紅利）發給誰

## 過戶登記只是對抗要件（§165 I，★ 基本觀念）：
- 股份轉讓，非將受讓人姓名、住居所記載於股東名簿，**不得以其轉讓對抗公司**
- 最高法院 73 台上 3567：過戶登記是**對抗公司的要件**，**不是**股權轉讓的生效要件
- 最高法院 60 台上 817：「不得對抗公司」指未過戶前，不得向公司主張因受讓而享有**開會、分派股息或紅利**的權利

## 效果：
- 股份移轉**仍有效**
- 但對公司而言，以**原股東名簿記載為準** → 開會通知、股利仍給原股東

## 📖 法條原文速查

> **§164**　股票由股票持有人以**背書**轉讓之，並應將受讓人之姓名或名稱記載於股票。

> **§165 I**　股份之轉讓，非將受讓人之姓名或名稱及住所或居所，記載於公司股東名簿，**不得以其轉讓對抗公司**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「股份轉讓未辦過戶登記，轉讓無效？」 | **錯**；轉讓有效，只是不得對抗公司 |
| 「過戶登記是股權轉讓的生效要件？」 | **錯**；**對抗**要件 |
| 「未過戶，公司應將開會通知寄給受讓人？」 | **錯**；寄給**原股東** |
| 「未發行股票的公司，股份如何轉讓？」 | 讓與合意＋過戶登記 |

## 一、例子

```
股東名簿：甲 100 股（臺北市）
甲 → 把 100 股賣給 A，但沒有變更股東名簿
├─ 甲、A 之間：買賣有效，A 取得股份
└─ 對公司：仍以名簿上的甲為準
     ├─ 股東會開會通知 → 寄給甲（寄給 A 反而是寄錯人）
     └─ 股利 → 發給甲
```
