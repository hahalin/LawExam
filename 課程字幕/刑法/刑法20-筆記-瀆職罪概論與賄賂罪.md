# 刑法20 筆記：瀆職罪概論與賄賂罪

> 來源：刑法20 課程字幕 00:00:00 ~ 01:18:00

---

## 📖 法條原文速查

> **§121**（不違背職務之受賄罪）
> I 公務員或仲裁人對於職務上之行為，要求、期約或收受賄賂或其他不正利益者，處七年以下有期徒刑，得併科七十萬元以下罰金。
> II 犯前項之罪者，所收受之賄賂沒收之。如全部或一部不能沒收時，追徵其價額。

> **§122**（違背職務之受賄罪及行賄罪）
> I 公務員或仲裁人對於違背職務之行為，要求、期約或收受賄賂或其他不正利益者，處三年以上十年以下有期徒刑，得併科二百萬元以下罰金。
> II 因而為違背職務之行為者，處無期徒刑或五年以上有期徒刑，得併科四百萬元以下罰金。
> III 對於公務員或仲裁人關於違背職務之行為，行求、期約或交付賄賂或其他不正利益者，處三年以下有期徒刑，得併科三十萬元以下罰金。
> → 建議查閱最新六法原文確認刑度

> **§123**（準受賄罪）
> 於未為公務員或仲裁人時，預以職務上之行為，要求、期約或收受賄賂或其他不正利益，而於為公務員或仲裁人後履行者，以公務員或仲裁人要求、期約或收受賄賂或其他不正利益論。

## 📋 實務見解原文速查

> **最高法院刑事大法庭 108 年度台上大字第 2306 號裁定**：「職務上行為」之認定，採**實質影響力說**，不以法定職權為限，凡與職務具有關連性之行為，皆屬之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「瀆職罪的分類？」 | 分二大類：**貪汙**（§121/§122/§123/§131）與**濫權**（§120/§124-§130） |
| 「受賄三行為態樣（公務員端）？」 | **要求**（單方發起）→ **期約**（雙方合意）→ **收受**（實際取得），不以三階段齊備為必要 |
| 「行賄端的三行為態樣？」 | **行求**（單方發起）→ **期約**（雙方合意）→ **交付**（實際給付），刑法僅§122 III 處罰行賄**違背職務**之行為 |
| 「『職務上行為』採何說？」 | 大法庭裁定採**實質影響力說**，不限法定職權，只要與職務有實質關連即可 |
| 「§121 與 §122 的區別？」 | §121＝**不違背職務**之受賄；§122＝**違背職務**之受賄（刑度較重） |
| 「§122 第二項加重要件？」 | 收賄後**因而為違背職務行為**，需有時序上的因果關係（先收賄→後違背） |
| 「§123 準受賄的成立時點？」 | 要求/期約/收受在**擔任公務員之前**，但須**就任後實際履行**才成立 |
| 「賄賂或不正利益的範圍？」 | **賄賂**＝可以金錢計算者；**不正利益**＝無法以金錢衡量但具價值者（如性招待） |

## 一、刑法分則學習導論

### (一) 總則與分則的差異

- **總則**：概念抽象、體系性強，重在「推理」
- **分則**：內容瑣碎、罪名繁多，重在「記憶」
- 分則特色：各罪要件容易混淆，需靠反覆接觸強化印象

### (二) 分則教學順序

```
分則結構
├── 國家法益犯罪（先教）
│   ├── 瀆職罪章（Ch. 4）
│   ├── 內亂外患罪（Ch. 1-2）
│   └── 妨害國交罪（Ch. 3）等
├── 社會法益犯罪
│   ├── 公共危險罪
│   └── 偽造文書罪 等
└── 個人法益犯罪
    ├── 殺人罪
    ├── 傷害罪
    └── 財產犯罪 等
```

> **教學策略**：先從國家法益犯罪講起，因考試配分相對低但概念獨立，適合建立分則分析的感覺。

## 三、§121 不違背職務之受賄罪

### (一) 構成要件分析

| 要件 | 說明 |
|------|------|
| **主體** | 公務員或仲裁人（身分犯） |
| **客觀行為** | 對於**職務上之行為**，要求、期約或收受 |
| **行為客體** | **賄賂**或**其他不正利益** |
| **對價關係** | 行為與職務之間須有對價關係 |

### (二) 行為態樣：三階段遞進

```
受賄端（公務員）              行賄端（相對人）
要求（單方發起）    ←→     行求（單方發起）
     ↓                         ↓
期約（達成合意）    ←→     期約（達成合意）
     ↓                         ↓
收受（實際取得）    ←→     交付（實際給付）
```

> **注意**：三階段為犯罪行為的**遞進樣態**，不以三階段齊備為必要。「要求」即已成罪，不須對方同意。

### (三) 「賄賂」與「不正利益」

| 類型 | 定義 | 舉例 |
|------|------|------|
| **賄賂** | 可以金錢計算之財物 | 現金、禮券、股票 |
| **不正利益** | 無法以金錢直接衡量，但具有經濟價值或其他利益 | 性招待、公司職位、升遷機會 |

### (四) 「對價關係」

- 賄賂或不正利益須與公務員之**職務上行為**具有對價關係
- 若僅為社交往來、禮貌性餽贈，不具對價關係 → 不成立本罪

### (五) 「職務上行為」的認定：核心爭議

| 學說 | 內涵 | 結論 |
|------|------|------|
| **法定職權說** | 以法令明定之職務範圍為限 | 範圍較窄 |
| **實質影響力說**（大法庭採） | 不限法定職權，凡公務員基於職務地位，對特定事務具有**實質影響力**者均屬之 | 範圍較廣 |

> **大法庭裁定（108台上大2306）**：正式確認採**實質影響力說**。

#### 案例：鮭魚改名事件（課堂舉例）

- 事實：某區公所承辦戶籍登記之公務員，處理民眾改名申請
- 分析：只要民眾給予公務員好處，希望公務員在職務上「幫忙處理」，即可構成§121 的對價關係
- 重點：改名本身雖然合法，但「為合法行為而收受好處」仍該當§121（不違背職務）

### (六) 行賄端的處罰

| 行賄類型 | 處罰規定 | 說明 |
|---------|---------|------|
| 行賄**違背職務**之行為 | §122 III | 處三年以下有期徒刑 |
| 行賄**不違背職務**之行為 | 刑法**無處罰** | 貪汙治罪條例另有規定 |

> **注意**：刑法僅處罰行賄「違背職務」之行為（§122 III），對於行賄「不違背職務」的行為，刑法不罰。

## 四、§122 違背職務之受賄罪

### (一) 與 §121 的區別

- §121：收賄後做的是**依法該做的事**（不違背職務）
- §122：收賄後做的是**不應做或違法的事**（違背職務）
- 刑度差異：§122 顯著高於 §121

### (二) §122 第一項：基本規定

- 要件：對於**違背職務之行為**，要求、期約或收受賄賂
- **違背職務**＝①明確違法 ②與職務有關聯性
- 案例：轄區外賭場案 → 管轄範圍外的事項，仍可能構成（實質影響力說）

### (三) §122 第二項：加重規定

- 要件：受賄後**因而為違背職務之行為**
- 關鍵：需有**時序上的因果關係**
  - 先收賄 → 後違背職務 ✓
  - 先違背職務 → 後收賄（事後酬謝）→ 不構成第二項，僅成立第一項

```
§122 第一項 vs 第二項
│
├── 第一項：要求/期約/收受賄賂（違背職務方面）→ 尚未實際違背
│
└── 第二項：收賄後「因而」為違背職務之行為 → 已實際違背
              加重處罰（無期徒刑或五年以上）
```

## 五、§123 準受賄罪

### (一) 立法目的

- 堵住漏洞：處罰**尚未就任公務員就先收賄**的行為（事前受賄、超前部署）

### (二) 成立要件

| 要件 | 說明 |
|------|------|
| **時點** | 在未為公務員（或仲裁人）時 |
| **行為** | 預以職務上之行為，要求、期約或收受賄賂 |
| **履行** | 須於就任公務員後**實際履行** |

> **注意**：若就任後**未履行**，則不成立§123。這是本罪的特殊要件。

### (三) 性質

- **身分犯**：雖收賄時尚非公務員，但法律擬制其地位
- 處罰以§121（不違背職務受賄）論
