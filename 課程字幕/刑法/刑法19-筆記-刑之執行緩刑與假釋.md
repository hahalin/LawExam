# 刑法19 筆記：刑之執行、緩刑與假釋

> 來源：刑法19 課程字幕 02:07:00 ~ 02:30:00

---

## 📖 法條原文速查

> **§37-2**（羈押抵刑期）
> 裁判確定前之羈押日數，以一日抵有期徒刑或拘役一日。

> **§41**（易科罰金）
> I 犯最重本刑為五年以下有期徒刑以下之刑之罪，而受六月以下有期徒刑或拘役之宣告者，得以新臺幣一千元、二千元或三千元折算一日，易科罰金。
> VIII 第一項至第四項及第七項之規定，於數罪併罰之數罪均得易科罰金或易服社會勞動，其應執行之刑逾六月者，亦適用之。

> **§41**（易服社會勞動）
> II 依前項規定得易科罰金而未聲請易科罰金者，得以提供社會勞動六小時折算一日，易服社會勞動。
> III 受六月以下有期徒刑或拘役之宣告，不符合第一項易科罰金之規定者，得依前項折算規定，易服社會勞動。

> **§51**（數罪併罰）
> 但應執行之刑，其中有得易科罰金或得易服社會勞動者，於定應執行之刑時，分別合併計算之，得為易科罰金或易服社會勞動。

> **§74**（緩刑）
> I 受二年以下有期徒刑、拘役或罰金之宣告，而有下列情形之一，認以暫不執行為適當者，得宣告二年以上五年以下之緩刑，其期間自裁判確定日起算：
> 一、未曾因故意犯罪受有期徒刑以上之宣告者。
> 二、前因故意犯罪受有期徒刑以上之宣告，執行完畢或赦免後，五年以內未曾因故意犯罪受有期徒刑以上之宣告者。

> **§76**（緩刑效力）
> 緩刑期滿，而緩刑之宣告未經撤銷者，其刑之宣告失其效力。

> **§77**（假釋）
> I 受徒刑之執行而有悛悔實據者，無期徒刑逾二十五年，有期徒刑逾二分之一、累犯逾三分之二，由監獄報請法務部，得許假釋出獄。
> III 無期徒刑裁判確定前逾一年部分之羈押日數算入第一項已執行之期間內。

> **§78**（假釋撤銷）
> I 假釋中因故意更犯罪，受有期徒刑以上刑之宣告者，於判決確定後六月以內，撤銷其假釋。但假釋期間內，故意犯罪受六個月以下有期徒刑之宣告，或受緩刑之宣告者，不在此限。

## 📋 釋字/實務見解原文速查

> **住字第67號裁定（羈押折抵保安處分）**
> 監護處分為拘束人身自由之保安處分，自難以其只是保安處分為由，而否定羈押可以折抵保安處分日數之適用。
> → 羈押得折抵監護處分日數。

> **釋字第679號（數罪併罰之易科罰金）**
> 數罪併罰中，部分得易科罰金、部分不得易科罰金之罪，原實務一律不准易科罰金，有違比例原則。
> → 修法後§51但書：得易科罰金者分組定執行刑，仍可易科。

> **釋字第796號（假釋撤銷）**
> 假釋中故意更犯他罪，不分情節一律撤銷假釋，有違比例原則。
> → 修法後§78但書：受六月以下宣告或緩刑者，改為「得撤銷」（裁量撤銷）。

> **113年憲判字第2號（無期徒刑假釋撤銷殘刑）**
> 無期徒刑假釋被撤銷後，殘刑一律25年，有違比例原則。應區分情節，不宜一律25年。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「羈押可否抵保安處分日數？」 | **可以**（住67裁定，監護處分＝拘束人身自由的保安處分） |
| 「易科罰金 vs 易服社會勞動？」 | 易科罰金需**五年以下之罪**＋六月以下宣告；易服社會勞動只需**六月以下宣告**（不管犯什麼罪） |
| 「犯偽證罪被判六月，可否易科罰金？」 | **不可以**（偽證罪7年以下，不符五年以下要件）；但可**易服社會勞動** |
| 「易服社會勞動幾小時折一天？」 | **六小時**折算一日（非八小時） |
| 「數罪併罰，各罪宣告刑未逾六月但執行刑逾六月，可否易科罰金？」 | **可以**（§41 VIII，以**宣告刑**為準） |
| 「數罪併罰中部分得易科、部分不得易科？」 | 得易科者**分組**定執行刑，仍可易科（§51但書/釋679） |
| 「緩刑的要件？」 | ①**兩年以下**宣告 ②未曾因故意犯罪受徒刑宣告（或五年內未再犯） ③**暫緩執行為適當** |
| 「緩刑期滿效力？」 | 刑之宣告**失其效力**＝等於沒判過（可拿良民證） |
| 「假釋無期徒刑的門檻？」 | 執行逾**25年** |
| 「假釋撤銷，義務 vs 裁量？」 | 故意犯罪受**逾六月**宣告→**義務撤銷**；受**六月以下**或**緩刑**→**裁量撤銷**（釋796） |

## 一、羈押抵刑期（§37-2）

### (一) 原則

- 裁判確定前羈押日數，**一日抵有期徒刑或拘役一日**
- 雖然羈押不是處罰，但基於人權考量，讓羈押可以折抵刑期

### (二) 羈押折抵保安處分

- **可以折抵**（住67裁定）
- 理由：監護處分在**法律定性上**為拘束人身自由的保安處分
- 不能以「只是保安處分」為由否定折抵
- 即便監護處分在執行面上不必然拘束人身自由（可能交付親屬），仍以法律定性為準

## 二、易刑制度

### (一) 易刑類型總覽

```
易刑制度
├── 1. 易科罰金（§41 I）──五年以下之罪＋六月以下宣告
├── 2. 易服社會勞動（§41 II, III）──六月以下宣告即可
├── 3. 易服勞役（§42）──罰金無力完納
├── 4. 罰金易服勞役→轉易服社會勞動
└── 5. 易以訓誡（§43）──拘役或罰金，情節輕微
```

### (二) 易科罰金 vs 易服社會勞動

| 比較 | 易科罰金 | 易服社會勞動 |
|------|---------|------------|
| **犯罪限制** | 最重本刑**五年以下**之罪 | **不限**犯罪類型 |
| **宣告刑** | **六月以下**有期徒刑或拘役 | **六月以下**有期徒刑或拘役 |
| **方式** | 以金錢折算 | 提供勞動服務（社區服務等） |
| **是否入監** | 否 | 否（人在社會上） |

### (三) 經典考題：偽證罪

| 項目 | 分析 |
|------|------|
| **偽證罪法定刑** | 七年以下有期徒刑 |
| **宣告刑** | 被判六個月 |
| **可否易科罰金？** | **不可以**（偽證罪是七年以下，不符「五年以下之罪」要件） |
| **可否易服社會勞動？** | **可以**（不管什麼罪，六月以下宣告即可） |

### (四) 易服社會勞動的折算

- **六小時**折算一日（不是八小時）
- 可在地檢署勞動服務或社區打掃等

### (五) 易以訓誡

- 到檢察官那裡接受訓誡（口頭告誡）
- 實務上**極少使用**

## 三、數罪併罰的易刑基準

### (一) 各罪宣告刑均得易科（§41 VIII）

- 甲分別偷了ABC，宣告刑各3月、4月、5月，執行刑定為8月
- 雖然執行刑超過六月，但各罪宣告刑均未逾六月
- 以**宣告刑為準** → 仍可易科罰金

### (二) 部分得易科、部分不得易科（§51但書/釋679）

```
甲偷A（3月）、偷B（4月）、偷C（8月）
│
├── 得易科組：A(3月)＋B(4月) → 合併定執行刑 → 仍可易科
└── 不得易科組：C(8月) → 須入監執行
```

- 釋字679的意旨：原實務一律不准易科 → 違反比例原則
- 修法後§51但書：得易科者**分組**定執行刑，保留易科機會

## 四、緩刑（§74）

### (一) 要件

```
緩刑三要件
├── ① 受「二年以下有期徒刑、拘役或罰金」之宣告
├── ② 未曾因故意犯罪受有期徒刑之宣告
│   └── 或：前因故意犯罪受宣告，執行完畢或赦免後五年內未再犯
└── ③ 認以暫不執行為適當（法院裁量）
```

### (二) 實務運作：和解的重要性

- 有被害人的犯罪 → 實務上須與被害人**全部和解**才會給緩刑
- 法條雖未明文要求，但實務運作如此
- 詐欺案中，被害人眾多 → 全部和解極為困難 → 緩刑不易

### (三) 緩刑期間

- **二年以上五年以下**
- 緩刑期間越長，對行為人越不利（觀察期越久）
- 被告得以緩刑期間過長為由上訴（法律上允許，但實務上不建議）

### (四) 緩刑效力（§76）

- 緩刑期滿，緩刑宣告**未經撤銷**者 → 刑之宣告**失其效力**
- 效果：**等於沒有被宣告過**
- 可以拿到**乾淨的良民證**

### (五) 緩刑的撤銷

- 分為**應撤銷**與**得撤銷**
- 類似假釋撤銷的架構

> **考試連結**：強制性交既遂（3年以上）→ §59酌減至2年以下 → 才有緩刑空間。

## 五、假釋（§77）

### (一) 積極要件

| 刑種 | 假釋門檻 |
|------|---------|
| **無期徒刑** | 執行逾**25年** |
| **有期徒刑** | 執行逾**二分之一** |
| **累犯** | 執行逾**三分之二** |

> 舊法無期徒刑為10年或15年即可假釋，現行法已修正為25年。

### (二) 消極要件（不得假釋）

| 款次 | 不得假釋之情形 | 說明 |
|------|--------------|------|
| 第一款 | 有期徒刑執行**未滿六個月** | 避免短期自由刑弊病 |
| 第二款 | **三振條款**：假釋期間或執行完畢後五年內故意再犯最輕本刑五年以上之罪 | 累犯又再犯的極端情形 |
| 第三款 | 犯**性侵害犯罪**，經鑑定評估再犯危險未顯著降低 | 性犯罪假釋門檻極高 |

### (三) 短期自由刑弊病

- 實證研究顯示：短期監禁（三、四個月）弊大於利
- 在監獄交到壞朋友，出來後變更壞
- 制度配合：六月以下 → 易科罰金/易服社會勞動；真的要關 → 關滿六月

### (四) 假釋期間的計算（§79-1）

- 非數罪併罰的數罪：行為人裁判確定後又故意犯他罪
- 假釋期間的計算有特別規定

### (五) 無期徒刑的羈押折抵（§77 III）

| 項目 | 舊法規定 | 現行見解 |
|------|---------|---------|
| 羈押折抵門檻 | 超過**一年**的羈押才算入已執行期間 | **不論是否滿一年**，羈押均應算入假釋已執行期間 |
| 問題 | 若羈押11個月即白押，不公平 | 基於人權保障，羈押均應折入 |

### (六) 113年憲判字第2號（無期徒刑殘刑）

- **問題**：無期徒刑假釋被撤銷，殘刑一律25年
- **大法官見解**：一律25年有違比例原則，應依個案區分情節
- 例：犯無期徒刑之罪的人，熬25年假釋後再犯罪 → 殘刑又25年 → 實質終身監禁

## 六、假釋的撤銷（§78/釋796）

### (一) 現行法架構

| 再犯情形 | 撤銷類型 |
|---------|---------|
| 故意犯罪受**逾六月**有期徒刑宣告 | **義務撤銷**（應撤銷） |
| 故意犯罪受**六月以下**有期徒刑宣告，或受**緩刑**宣告 | **裁量撤銷**（得撤銷） |

### (二) 釋字第796號的意旨

- 原制度：不分情節，假釋中故意犯罪**一律撤銷** → 違反比例原則
- 修正後：受六月以下宣告或有緩刑者 → 僅在有**執行刑罰必要**時才撤銷
- 理由：另犯之罪若情節輕微（不需入監），不應連帶撤銷原案假釋

### (三) 實務案例

- 大哥前罪槍砲條例（關五六年後假釋），假釋期間施用二級毒品被判四月
- 舊制：一律撤銷假釋 → 回去蹲原罪殘刑
- 新制（釋796後）：四月宣告屬六月以下 → 改為裁量撤銷 → 得主張無執行刑罰必要
