# 刑法18 筆記：想像競合要件與實行行為部分合致

> 來源：刑法18 課程字幕 00:51:37 ~ 01:05:37

## 📖 法條原文速查

> **§55**（想像競合）
> 一行為而觸犯數罪名者，從一重處斷。但不得科以較輕罪名所定最輕本刑以下之刑。

> **§185-3**（危險駕駛罪）
> I 駕駛動力交通工具而有下列情形之一者……→ 建議查閱最新六法原文

> **§277**（傷害罪）
> I 傷害人之身體或健康者，處五年以下有期徒刑、拘役或五十萬元以下罰金。

> **§284**（過失傷害罪）
> 因過失傷害人者，處一年以下有期徒刑、拘役或十萬元以下罰金。

> **§306**（侵入住居罪）
> 無故侵入他人住宅、建築物或附連圍繞之土地或船艦者，處一年以下有期徒刑、拘役或九千元以下罰金。

## 📋 釋字/實務見解原文速查

> **100 臺非 373 號判決**：酒駕（§185-3 I）期間過失輕傷（§284），因兩罪僅時間地點偶然合致，欠缺目的手段的牽連關係，應**數罪併罰**，非想像競合。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「想像競合的前提？」 | 一行為觸犯**保護法益不同**的數罪名 |
| 「§271 與 §273 可否想像競合？」 | **不可以**，兩罪法益相同→法條競合 |
| 「什麼是實行行為部分合致？」 | 兩罪在**時間上有重疊**，且出於**相同犯意** |
| 「為毆打被害人而侵入住宅？」 | 部分合致→**想像競合** |
| 「先侵入住宅，臨時起意傷害？」 | 分別起意→**數罪併罰** |
| 「酒駕期間過失輕傷？」 | **傳統說**：想像競合；**實務（100臺非373）**：數罪併罰 |
| 「酒駕期間過失致死或致重傷？」 | 有 §185-3 II 加重結果犯，直接論加重結果犯，跟本討論無關 |

## 一、想像競合概念

### §55 前段

> 一行為而觸犯數罪名者，從一重處斷。

### 核心要件

1. **一行為**
2. **觸犯數罪名**（保護法益不同的數罪名）

```
純正競合（想像競合）
│
├── 一行為
│   ├── 行為單數（單純/自然/法的行為單數）
│   └── 實行行為部分合致
│
└── 觸犯保護法益不同的數罪名
    ├── 同種想像競合（罪名相同，如兩個毀損）
    └── 異種想像競合（罪名不同，如傷害＋毀損）
```

### 與法條競合的根本區別

| | 法條競合 | 想像競合 |
|------|---------|---------|
| 法益 | 一行為**一法益**數罪名 | 一行為**不同法益**數罪名 |
| 效果 | 只論一罪（最適合的） | 數罪都成立，從一重**處斷**（科刑規則） |

## 二、「一行為」要件

### (一) 行為單數

包括前面已學過的：
- 單純的行為單數
- 自然的行為單數
- 法的行為單數（繼續犯等）

### (二) 實行行為部分合致

兩罪犯罪時間**有所重疊**。

#### 案例：為毆打而侵入住宅

行為人為了毆打被害人 → 侵入住宅 → 持球棒痛打被害人

- §306 侵入住居 + §277 傷害 → 兩罪時間重疊 → **實行行為部分合致** → 想像競合

#### 多數說的要件

實行行為部分合致，需具備：

1. **時間上重疊**
2. **出於相同犯意**（非分別起意）

#### 反例：先侵入，臨時起意傷害

行為人為看模型飛機侵入住宅 → 被發現後吵架 → 臨時起意毆打被害人

- 侵入住宅與傷害是**分別起意** → **不成立**實行行為部分合致 → 數罪併罰

## 三、酒駕期間過失輕傷的競合爭議

### 前提條件

- 討論限於酒駕 + **過失輕傷**
- 若酒駕 + 過失致死/致重傷 → 有 §185-3 II 加重結果犯，直接論之，**無本爭議**

### 甲說（傳統學說）：想像競合

理由：
1. 兩罪時間上重疊 ✓
2. 過失犯不可能是另行起意 ✓
→ 想像競合，從一重處斷

### 乙說（實務，100 臺非 373）：數罪併罰

理由：
- 實行行為部分合致，除了「非另行起意」外，還需**目的手段上的牽連關係**
- 侵入住宅為了毆打 → 手段/目的關係明確 ✓
- 酒駕 + 過失傷害 → 僅時間地點**偶然合致**，無目的手段關係 ✗
→ 數罪併罰

### 考試建議

- **一試選擇題**：實務採數罪併罰（100 臺非 373）
- 此為非常重要的考點，分則再次出現

## 四、考試提醒：國民法感情不是論理依據

老師強調：考卷上決定採某一說時，**不要說**「因為這一說比較能符合人民的法感情」。
- 法院判決沒有義務迎合人民法感情
- 憲法 §80：法官依法審判，不受任何干涉
- 迎合法感情往往導致違反罪刑法定
