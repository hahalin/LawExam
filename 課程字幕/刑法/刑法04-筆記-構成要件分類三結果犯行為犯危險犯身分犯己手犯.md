# 刑法04 筆記：構成要件分類（三）結果犯vs行為犯、危險犯、身分犯與己手犯

> 來源：刑法04 課程字幕 01:50:06 ~ 02:42:31

## 📖 法條原文速查

> **§100**（內亂罪）
> 意圖破壞國體、竊據國土，或以非法之方法變更國憲、顛覆政府，而以強暴或脅迫著手實行者……
> → **著手犯**（著手即既遂）

> **§150**（聚眾施暴罪）
> 公然聚眾，施強暴脅迫者……
> → 近年趨勢以**適格犯**限縮解釋

> **§168**（偽證罪）
> 於執行審判職務之公署審判時或於檢察官偵查時，證人、鑑定人、通譯於案情有重要關係之事項，供前具結，而為虛偽陳述者……
> → 近年趨勢以**適格犯**限縮（「足以影響裁判結果」）

> **§169**（誣告罪）
> 意圖使他人受刑事或懲戒處分，向該管公務員誣告者……
> → 近年趨勢以**適格犯**限縮

> **§173**（放火燒燬現住建築物罪）
> 放火燒燬現供人使用之住宅或現有人所在之建築物……者，處無期徒刑或七年以上有期徒刑。
> → **抽象危險犯**（條文無「致生公共危險」文字）

> **§175**（放火燒燬自己物罪）
> I：放火燒燬前二條以外之他人所有物，**致生公共危險**者……
> II：放火燒燬前二條以外之自己所有物，**致生公共危險**者……
> → **具體危險犯**（須個案證明「致生公共危險」）

> **§230**（血親性交罪）
> 與直系或三親等內旁系血親為性交者……
> → **己手犯**（不能成立間接正犯與共同正犯）

> **§271**（普通殺人罪）
> → 一般犯（無主體限制）、結果犯、實害犯、非定式犯罪

> **§272**（殺直系血親尊親屬罪）
> 殺直系血親尊親屬者……
> → **不純正身分犯**（無身分者回歸§271）

> **§286**（妨害幼童發育罪）
> 對於未滿十八歲之人，施以凌虐或以他法**足以**妨害其身心之健全或發育者……
> → **適格犯**（「足以」＝介於抽象與具體危險犯之間）

> **§309**（公然侮辱罪）
> → 行為犯（不要求具體結果發生）

## 📋 實務見解速查

> **105 年判決——抽象危險犯可否推翻**：認為抽象危險犯在個案中如能**反證**確實沒有危險，可推翻其危險推定。

> **近年趨勢——以適格犯限縮抽象危險犯**：對偽證罪（§168）、誣告罪（§169）、聚眾施暴罪（§150）等，實務傾向要求行為須「**足以**」產生危險，而非一律推定有危險。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「結果犯與行為犯的區別？」 | 結果犯＝要求**結果發生**（殺人、傷害）；行為犯＝**不要求結果**（公然侮辱、偽證） |
| 「行為犯是否完全無結果？」 | 不是。行為犯可能有事實上的結果，但法律**不以結果為要件** |
| 「如何判斷某罪是結果犯或行為犯？」 | ①條文**明文規定結果**→結果犯 ②法益類型：國家/社會/名譽法益→多為行為犯；個人法益→多為結果犯 |
| 「抽象危險犯與具體危險犯的區別？」 | 抽象＝**行為即推定有危險**（§173 無「致生公共危險」）；具體＝**須個案證明危險**（§175 有「致生公共危險」） |
| 「適格犯（適性犯）是什麼？」 | 介於兩者之間，條文出現**「足以」**（§286「足以妨害身心健全發育」） |
| 「抽象危險犯可否個案推翻？」 | 105 年判決認為**可以**；近年趨勢以**適格犯限縮**解釋 |
| 「純正身分犯 vs 不純正身分犯？」 | 純正＝**無身分不成罪**（貪汙罪）；不純正＝**無身分論基本罪**（§272→§271） |
| 「純正身分犯，無身分者參與怎麼辦？」 | **當作有身分**，一起論罪（§31 I） |
| 「不純正身分犯，無身分者參與怎麼辦？」 | **回歸基本構成要件**論罪（§31 II） |
| 「己手犯的特徵？」 | 不能成立**間接正犯**與**共同正犯**，只能論直接正犯或共犯 |
| 「著手犯是什麼？」 | **著手即既遂**（如§100 內亂罪，極罕見） |

## 一、第五組：結果犯 vs 行為犯

### 基本概念

| 比較項目 | 結果犯 | 行為犯 |
|---------|--------|--------|
| **定義** | 構成要件要求**結果發生** | 構成要件**不要求結果** |
| **既遂時點** | 結果發生時 | 行為完成時 |
| **因果歸責** | **須審查**因果關係與客觀歸責 | **不須**審查 |
| **典型例子** | 殺人（§271）、傷害（§277）、毀損（§354） | 公然侮辱（§309）、偽證（§168） |

### 判斷方法

```
某罪是結果犯或行為犯？
├── 條文明文規定結果 → 結果犯
│   例：殺人罪「致人於死」
│
└── 條文未規定結果 → 看法益類型
    ├── 國家法益 → 多為行為犯（偽證、內亂）
    ├── 社會法益 → 多為行為犯（公共危險）
    ├── 名譽法益 → 多為行為犯（公然侮辱）
    └── 個人法益 → 多為結果犯（殺人、傷害、毀損）
```

## 二、第六組：實害犯 vs 危險犯

### 三種危險犯

```
犯罪對法益的危害程度
├── 實害犯：法益「實際受損」才成立（殺人→人死亡）
│
└── 危險犯：法益「有危險」就成立
    ├── 抽象危險犯（≈行為犯）
    │   └── 做了行為 → 立法推定有危險 → 成立
    │       條文特徵：無「致生公共危險」
    │       例：§173 放火燒現住建築物
    │
    ├── 具體危險犯
    │   └── 做了行為 → 須個案證明確實有危險 → 才成立
    │       條文特徵：有「致生公共危險」
    │       例：§175 放火燒自己物致生公共危險
    │
    └── 適格犯（適性犯）
        └── 介於抽象與具體之間
            條文特徵：有「足以」
            例：§286 凌虐「足以」妨害身心健全發育
```

### 放火罪的比較（抽象 vs 具體）

| 條文 | 行為 | 危險犯類型 | 判斷依據 |
|------|------|-----------|---------|
| **§173** | 放火燒**現住建築物** | **抽象危險犯** | 條文**無**「致生公共危險」 |
| **§175** | 放火燒**自己物** | **具體危險犯** | 條文**有**「致生公共危險」 |

### 適格犯（適性犯）的興起

| 適用條文 | 「足以」要件 | 說明 |
|---------|-------------|------|
| **§286** | 足以妨害身心健全發育 | 虐童罪的典型適格犯 |
| **§168**（趨勢） | 足以影響裁判結果 | 近年以適格犯限縮偽證罪 |
| **§169**（趨勢） | 足以影響偵查/審判 | 近年以適格犯限縮誣告罪 |
| **§150**（趨勢） | 足以造成公共危險 | 近年以適格犯限縮聚眾施暴 |

### 抽象危險犯可否推翻？

| 立場 | 結論 |
|------|------|
| **傳統見解** | 不可推翻（立法推定） |
| **105 年判決** | **可以**個案反證推翻 |
| **近年趨勢** | 不直接推翻，而是以**適格犯重新定性**來限縮 |

## 三、第七組：定式犯罪 vs 非定式犯罪

| 比較項目 | 定式犯罪 | 非定式犯罪 |
|---------|----------|-----------|
| **定義** | 構成要件限定**行為方式** | 構成要件**不限**行為方式 |
| **舉例** | 舊§285 傳染花柳病罪（限「姦淫或猥褻」方式） | 殺人罪（任何手段皆可） |
| **因果歸責** | 通常**不須**審查 | 結果犯 → **須審查** |

> **區別實益**：只有**非定式犯罪的結果犯**才需要做因果關係與客觀歸責的審查。定式犯罪或行為犯通常不需要。

## 四、第八組：一般犯、身分犯、己手犯

### 基本分類

```
行為主體有無限制？
├── 一般犯：任何人都可犯（殺人、傷害、竊盜）
│
├── 身分犯：須特定身分
│   ├── 純正身分犯（構成身分犯）
│   │   └── 無身分 → 根本不成罪
│   │       例：貪汙罪的「公務員」身分
│   │
│   └── 不純正身分犯（加減身分犯）
│       └── 無身分 → 仍可論基本罪名
│           例：§272 殺尊親屬 → 無身分論 §271
│
├── 己手犯：不能成立間接正犯與共同正犯
│   └── 例：§230 血親性交罪
│
└── 著手犯：著手即既遂（極罕見）
    └── 例：§100 內亂罪
```

### 純正身分犯 vs 不純正身分犯

| 比較項目 | 純正身分犯 | 不純正身分犯 |
|---------|-----------|-------------|
| **身分的性質** | 成立犯罪不可或缺 | 影響罪名或刑度，但非不可或缺 |
| **無身分者做相同行為** | **不成立任何此類犯罪** | 成立**基本罪名** |
| **典型例子** | 貪汙罪的公務員身分 | §272 的直系血親卑親屬身分 |
| **無身分者參與犯罪** | 當作有身分，一起論罪（§31 I） | 回歸基本構成要件（§31 II） |

### 案例：純正身分犯——貪汙罪

#### 事實
1. 甲為公家機關人事主任（公務員），收紅包安排親屬入職 → **貪汙罪**
2. 乙為私人企業人事主任，做相同事情 → **不成立貪汙罪**（私人無公務員身分）

#### 結論
- 貪汙罪的「公務員」身分 → **純正身分犯**（無身分就不可能論貪汙）

### 案例：不純正身分犯——殺尊親屬

#### 事實
1. 甲殺自己父親 → §272 殺直系血親尊親屬罪
2. 乙（無親屬關係）殺甲的父親 → **不成立§272**，但成立 **§271 普通殺人罪**

#### 結論
- §272 的親屬身分 → **不純正身分犯**（無身分仍可論§271）

### 無身分者參與犯罪時的處理

| 身分犯類型 | 無身分者參與時 | 記憶口訣 |
|-----------|--------------|---------|
| **純正身分犯** | 當作有身分，一起論罪 | 阿扁（公務員）＋阿珍（無身分）→ 阿珍也論貪汙 |
| **不純正身分犯** | 回歸基本構成要件 | 甲（子女）＋乙（陌生人）一起殺甲父 → 甲論§272，乙論§271 |

### 己手犯

| 特徵 | 說明 |
|------|------|
| **定義** | 無法成立**間接正犯**與**共同正犯**的犯罪 |
| **可成立** | 直接正犯、教唆犯、幫助犯 |
| **不可成立** | 間接正犯、共同正犯 |
| **典型例子** | **§230 血親性交罪** |

> **間接正犯**＝欺騙或威脅他人犯罪（被利用者無自由意思）
> **教唆犯**＝唆使有自由意思的人犯罪（被教唆者可自由決定）

### 著手犯

| 特徵 | 說明 |
|------|------|
| **定義** | **著手即既遂**的犯罪 |
| **理由** | 若等到既遂才處罰已無實益（內亂既遂＝改朝換代） |
| **典型例子** | **§100 內亂罪** |
| **罕見程度** | 刑法分則中**極為罕見** |
