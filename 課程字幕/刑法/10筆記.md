# 刑法第十堂課筆記

## 一、考題複習——密醫案（接續上堂課）

- 甲為密醫，經病患同意，以符合醫療常規方式拔牙
- **構成要件該當性**：
  - 傷害說 → 該當
  - 非傷害說 → 不該當
- **違法性**：業務上正當行為（重點是「行為正當」，非「業務正當」）→ 可阻卻違法

## 二、超法規阻卻違法事由——被害人承諾

### （一）被害人允諾侵害的三種效果（三分法）

| 效果 | 說明 | 舉例 |
|------|------|------|
| **轉而成立其他構成要件** | 法益不准被害人處分，即使被害人同意，仍成立他罪 | §275 加工自殺（生命法益）、§282 加工重傷 |
| **阻卻構成要件的同意**（Einverständnis） | 條文本身以「違反被害人意願」為要件 → 被害人同意 → 構成要件不該當 | §221 強制性交罪（核心＝違反意願）；BDSM 案 → 不該當 |
| **阻卻違法的承諾**（Einwilligung） | 條文未以被害人意願為要件 → 仍該當構成要件 → 到違法性階層用承諾阻卻 | §277 傷害罪 |

> **區分標準**：看構成要件的設計——條文有無要求「違反意願」

### （二）同意 vs 承諾的區別實益

- **同意**（阻卻構成要件）：意思表示有瑕疵 → **不影響**效力（事實上法益捨棄即生效）
- **承諾**（阻卻違法性）：意思表示有瑕疵 → **影響**效力

### （三）被害人承諾的要件

#### 1. 法益有處分可能性

- 限於**個人法益**，國家法益、社會法益不可處分
- **誣告罪**（§169）：保護的是國家司法權 → 被害人不能承諾
  - 實務案例：毒品案中，被告想指認願意配合的共犯為毒品來源以換取§17-1 減刑 → 共犯同意被誣告 → 承諾無效（因誣告罪保護國家法益）

#### 2. 被害人有處分權

- **生命法益、重大身體法益**：無處分權
- **毀損罪**：需**全體被害人**同意

#### 3. 承諾能力

- **不以民法行為能力為準**，取決於**辨別事理能力**
- 未成年人有判斷能力 → 可有效承諾
- 成年人不理智之承諾 → 仍可能無效
  - **德國拔牙案**：成年病人對拔牙之承諾出於不理智 → 承諾無效

#### 4. 出於自由意思（無詐欺、脅迫）

- **動機錯誤** → 不影響承諾效力
  - **德國削骨案**：被害人以為削骨後可變漂亮（動機），實際在削的動作認知正確 → 承諾有效

- **行為人欺騙** → 適用**法益關聯性理論**（Rechtsgutbezogenheit）

| 類型 | 定義 | 承諾效力 | 舉例 |
|------|------|----------|------|
| **法益相關欺騙** | 被害人不知道行為人實際上在做什麼（同意 A，行為人做 B） | **無效** | ATM 詐騙案（以為操作退款，實際轉帳）；注射案（以為生理食鹽水，實為鎮定劑） |
| **法益無關欺騙** | 被害人知道行為人在做什麼，但被騙做完後可得什麼利益 | **原則有效** | 捐血送餐券案（知道抽血，但餐券早已沒有）；網購詐騙案（知道交錢，但被騙所得商品） |

- **法益「無關」的欺騙** 
  - 承諾有效 → 不成立該罪，但可能成立詐欺
  - 定義： 你完全知道自己的法益會受到什麼侵害，只是你被騙了「為什麼要這麼做（動機）」或「對價關係」。

- **法益無關欺騙的例外**：嚴重違反一般人道德良知 → 承諾無效
  - **捐腎案**：媽媽同意割腎救兒，醫師卻將腎賣到器官黑市 → 雖屬法益無關欺騙，但嚴重違反道德良知 → 例外無效

#### 5. 承諾須事前為之

- 事後追認不算承諾
- 事後同意頂多是「被害人不願提告」，與承諾無關

#### 6. 承諾不可違反善良風俗

- 來自**德國刑法**規定（我國條文無類似規定）
- 典型情形：
  - 為**詐領保險金**而承諾他人切斷手指
  - 為**逃避兵役**而承諾他人鋸斷手
- **通說**：違反善良風俗之承諾無效
- **反對說**：畫蛇添足——行為人已可論幫助詐欺等罪，再多論傷害罪無意義

### （四）進階問題：同意與承諾要不要區分？

- **傳統通說**：二分（看構成要件設計）
- **少數說**（一元論）：全部在構成要件用同意處理
  - 理由：被害人已捨棄法益 → 無法益侵害 → 構成要件不該當 → 不需到違法性處理

### （五）推測的承諾

- **定義**：被害人事實上**沒有承諾**，但站在一般社會理性成員觀點，會認為被害人**應該會承諾**
- **案例**：車禍傷患意識不清，醫師評估不截肢會死 → 截肢 → 病患醒來反對
- **效力**：合理的推測即有效，**不因被害人事後反對而無效**

### （六）教師懲戒權（？）

- 過去曾有主張：
  - 業務上正當行為
  - 被害人承諾（中小學生在老師權威下無法自由拒絕 → 不成立）
  - 超法規阻卻違法事由（林東茂老師：有限度肯認，須與教育目的有關）
- **現行法**：**教育基本法 §8②** 嚴禁一切體罰
  - 業務上正當行為 → ✗（法律已禁止）
  - 被害人承諾 → ✗（中小學生無法自由拒絕）
  - 超法規阻卻違法事由 → ✗（法秩序統一性：行政法禁止 → 刑法不能說阻卻違法）
- **結論**：教師對學生無懲戒權，體罰行為成立犯罪

## 三、罪責（有責性）

### （一）罪責的基本概念

- 構成要件＋違法性：看「行為人有沒有做壞事」（看事）
- 罪責：看「行為人值不值得被譴責」（看人）

### （二）罪責的本質

| 理論 | 核心主張 | 為何可譴責 |
|------|----------|------------|
| **道義責任論** | 人**有**自由意志 | 你可以選擇不犯罪卻選擇犯罪 → 應受譴責 |
| **社會責任論** | 人**無**自由意志，被基因、環境決定 | 消滅行為人的危險性 |

- 刑法立場：**道義責任論**（假設人有自由意志）

### （三）罪責的理論

| 理論 | 內涵 | 時期 |
|------|------|------|
| **心理責任論** | 罪責 = 故意過失的心理狀態 | 最早（故意過失放在罪責） |
| **規範責任論** | 罪責 = 行為人的**可非難性** | 後來（故意過失移至構成要件後） |
| **預防責任論** | 罪責 = 用刑罰預防犯罪的必要性 | 最新 |

## 四、責任能力

### （一）三種責任能力
> 一試考點

| 類型 | 對象 | 法律效果 |
|------|------|----------|
| **無責任能力** | 未滿 14 歲；嚴重精神障礙或心智缺陷（§19①） | 不罰 |
| **限制責任能力** | 滿 14 未滿 18；滿 80 歲；較輕精神障礙或心智缺陷（§19②）；瘖啞人（§20） | 得減輕 |
| **完全責任能力** | 排除以上：滿 18 未滿 80、無精神障礙、非瘖啞 | 正常處罰 |

- **瘖啞人**認定極嚴格：須**既聾又啞**，且自幼如此

### （二）釋字第 129 號

- 繼續犯（如私行拘禁）橫跨有、無責任能力時期 → 從**有責任能力時期**負刑事責任
- 類推：限制責任能力跨到完全責任能力 → 以完全責任能力論

### （三）精神狀態的判斷（§19）

- 看兩個門檻：
  1. **控制行動的能力**（如思覺失調症可能喪失）
  2. **辨別是非的能力**（如智能障礙可能欠缺）

### （四）精神疾病與責任能力

| 疾病 | 對責任能力之影響 |
|------|------------------|
| **思覺失調症** | 可能導致無責任能力或限制責任能力（最常與刑事司法相關） |
| **憂鬱症** | 可能一定程度影響責任能力，但不至於無責任能力 |
| **反社會人格** | **不影響**責任能力（有辨識能力和控制能力，只是缺乏良知屏障） |
| **智能障礙** | 主要影響**辨識能力**（非控制能力） |

## 五、原因自由行為

### （一）基本概念

- **原則**：責任能力以**行為時**為準
- **問題**：行為人透過可歸責方式（喝酒、吸毒等）讓自己責任能力缺陷，再犯罪
- **案例**：A 為壯膽殺 B，喝一瓶金門高粱 → 喪失識別能力 → 持刀砍死 B

### （二）構成要件模式（前置犯行）

- **核心思維**：殺人罪 = 非定式犯罪 → 用**喝酒行為**當作殺人行為的開始
- 喝酒時有責任能力 → 以喝酒行為成立殺人罪
- **著手時點**：喝酒時（非砍人時）

#### 雙重故意要求

| 自陷責任能力缺陷故意 | 法益侵害故意 | 結論 |
|:---:|:---:|:---:|
| 故意 | 故意 | **故意犯** |
| 故意 | 過失 | **過失犯** |
| 過失 | 故意 | **過失犯** |
| 過失 | 過失 | **過失犯** |
| 故意 | 無故意過失 | **無罪**（麻醉狀態下的情緒不法行為／自醉行為） |

> **雙重故意的來源**：故意與行為同時存在原則 → 喝酒是犯罪行為的開始 → 喝酒時必須有故意

#### 構成要件模式的缺點

- **定式犯罪**（如竊盜、強盜）：有嚴格行為方式限定 → 前置後「喝酒 ≠ 竊取」→ 無法論罪

### （三）例外模式

- **核心思維**：故意讓自己喪失責任能力再犯罪 = **權利濫用** → 不得主張 §19①②
- 例外地**視為有完全責任能力**
- 用**後行為**（砍人）成立犯罪
- **法律依據**：**§19③**「前二項規定，因故意或過失自行招致者，不適用之。」
- **不會提前著手時點**（與構成要件模式之差異）
- **無定式犯罪難題**（如竊盜直接視為有責任能力即可）

### （四）兩模式之比較

| 比較項目 | 構成要件模式 | 例外模式 |
|----------|:---:|:---:|
| 前置犯行 | ✓ | ✗ |
| 成立犯罪的行為 | 前行為（喝酒） | 後行為（砍人） |
| 著手時點 | 喝酒時 | 砍人時 |
| 引用 §19③ | **不可以** | **必須** |
| 定式犯罪難題 | 有 | 無 |
| 雙重故意表格 | 適用 | 適用 |

### （五）重要觀念釐清

1. **§19③ ≠ 原因自由行為的定義**，僅是例外模式的法律明文
2. §19③ 增訂（2006.7.1）後，兩模式**仍可並存**
3. 2006.7.1 前：學界一面倒採構成要件模式（無§19③ → 採例外模式會違反罪刑法定）
4. 2006.7.1 後：構成要件模式與例外模式各半

### （六）題目寫作注意

- **不管哪個模式**，開頭都先檢討**結果階段行為**（砍人）
- **構成要件模式寫法**：
  1. 行為一（砍人）→ TB 該當、違法性 OK → 罪責：無責任能力 → **無罪**
  2. 行為二（喝酒）→ TB 該當（行為、結果、因果、歸責）→ 主觀：雙重故意 → 違法性、罪責 OK → **成立殺人罪**
  3. ⚠️ **不可引用 §19③**
- **例外模式寫法**：
  1. 行為（砍人）→ TB 該當、違法性 OK → 罪責：原因自由行為兩說並列
  2. 採例外模式 → 行為人有雙重故意 → 濫用責任能力欠缺抗辯 → 依 **§19③** → 視為有完全責任能力 → **成立殺人罪**
- **常見錯誤**：聲稱採構成要件模式，卻引 §19③ 說視為有完全責任能力 → **掛羊頭賣狗肉**

### （七）精神病患不服藥的爭議

- **問題**：有藥不吃、有醫不看，放任精神病發作後攻擊他人 → 是否為原因自由行為？
- **結論**：不排斥適用空間，但要件**通常過不去**

#### 構成要件模式之困難

| 關卡 | 困難內容 |
|------|----------|
| **保證人地位** | 病患無吃藥義務（例外：對家人有保護義務） |
| **因果關係** | 藥物對 A 有效未必對 B 有效 → 難證明不服藥與犯行有因果關係 |
| **主觀不法** | 停藥可能是精神病發作的結果 → 欠缺故意過失 |
| **前置犯行有效性** | 停藥時可能已無責任能力 → 前置無用 |
| **期待可能性** | 抗精神病藥物副作用嚴重（發抖、漏尿等）→ 欠缺期待可能性 |

#### 例外模式

- 關卡較少但仍困難
- 三要件：①停藥引起責任能力障礙 ②停藥時有完全責任能力 ③停藥時有雙重故意
- 實務（100 年判決）：精神病患不服藥 → 性質與故意過失自陷不同 → 不算原因自由行為

## 六、不法意識

> - 考選擇題的同學你要注意，因為選擇題喜歡考你這個名詞的區辨。
> - 考選擇題的同學，你要會分什麼禁止錯誤、見面錯誤、包攝錯誤什麼的，那個你要會分。

### （一）定義

- 行為人知不知道自己的行為是**違法**的
- 明明犯法，行為人卻覺得合法 → **不法意識欠缺**
- 常發生在：阻卻違法事由的誤認、附屬刑法、外國人

### （二）不法意識欠缺的類型

| 類型 | 定義 | 舉例 |
|------|------|------|
| **禁止錯誤** | 對刑法分則**禁止規範**的誤認 | 外國人不知在台灣吸大麻違法 |
| **容許錯誤**（＝間接禁止錯誤） | 對**阻卻違法事由**法律界限的誤認 | 以為逮到小偷後可以痛打一頓 |
| **誡命錯誤** | 不作為犯中對**誡命規範**的誤認 | 保姆不知有餵食義務 |
| **包攝錯誤** | 知道法規範存在，但不知自己的行為**該當**該規範 | 放走別人鳥籠的鳥，不知這也算毀損 |

### （三）容許錯誤 vs 容許構成要件錯誤

| | 容許錯誤 | 容許構成要件錯誤 |
|---|---|---|
| 誤認對象 | **法律**（以為法律允許） | **事實**（以為有正當防衛情狀） |
| 舉例 | 抓到真小偷，以為可以打他 | 以為對方是小偷（實非），故踹倒他 |

### （四）法律效果（§16）

- **可避免**的不法意識欠缺 → **減輕**罪責
- **不可避免**的不法意識欠缺 → **阻卻罪責**（極少見）
- 判斷標準：類似有無過失 → 上網查、問 AI、查政府網站
- 除非專家騙他、網站被駭、行為人不識字等極端狀況，否則通常為**可避免**
- 申論題：引 §16「不法意識欠缺」即可，不需細分禁止/容許/誡命/包攝錯誤

### （五）反面的不法意識欠缺

- 行為**無罪**，行為人卻以為有罪
- 舉例：
  - 男大生與滿 16 歲女友合意性交 → 以為犯法而自首 → 實際上滿 16 即可
  - 緊急避難侵入民宅 → 不知有緊急避難 → 以為犯法
- 與**罪責無關**：構成要件不該當或已阻卻違法 → 根本不進入罪責階段

## 七、期待可能性

### （一）概念

- 行為人處於**艱難處境**，在該處境下要求其不犯罪**難以期待**
- 期待可能性降低或欠缺 → 減輕或阻卻罪責
- **法律不強人所難**：法律只要求做一般人，不要求做聖人

### （二）經典案例：癩馬脫韁案（Leinenfänger-Fall）

- 19 世紀德國案例
- 馬車夫發現馬匹有怪癖（用尾巴纏繞韁繩），向僱主反映未果
- 無法辭職（否則失去生計）→ 繼續駕馬 → 馬怪癖犯作 → 造成車禍
- 有過失，但法院判**無罪**（無期待可能性）

### （三）現行法中的體現

| 規定 | 體現之期待可能性思想 |
|------|---------------------|
| **防衛過當、避難過當** | 人在驚慌時難免手足無措、過度反應 → 減免罪責 |
| **親屬間妨害司法犯罪** | 為至親滅證、藏匿 → 人之常情 → 可減免 |
| **§196② 收受偽造貨幣後行使** | 收到假鈔不甘損失而花掉 → 人性使然 → 僅處罰金；且未遂不罰（§196③ 只罰第一項未遂） |

### （四）超法規阻卻罪責事由

- 可否以期待可能性作為超法規阻卻罪責事由？
- **極端個案才可用**（類似民法誠信原則）
- 案例：家庭主婦燙衣服接到先生命危電話 → 衝去醫院 → 忘關熨斗 → 燒掉房子 → 無期待可能性 → 無罪
- 實務：**強制避難**（受強暴脅迫有生命危險）→ 放在罪責處理
