# 刑法01 筆記：三階論概述與構成要件該當性

## 📖 法條原文速查

> **§12**（故意犯與過失犯）
> I 行為非出於故意或過失者，不罰。
> II 過失行為之處罰，以有特別規定者為限。

> **§13**（故意）
> I 行為人對於構成犯罪之事實，明知並有意使其發生者，為故意。
> II 行為人對於構成犯罪之事實，預見其發生而其發生並不違背其本意者，以故意論。

> **§25**（未遂犯）
> I 已著手於犯罪行為之實行而不遂者，為未遂犯。
> II 未遂犯之處罰，以有特別規定者為限，並得按既遂犯之刑減輕之。

> **§271**（殺人罪）
> I 殺人者，處死刑、無期徒刑或十年以上有期徒刑。

> **§309**（公然侮辱罪）
> I 公然侮辱人者，處拘役或九千元以下罰金。

> **§237**（重婚罪）
> 有配偶而重為婚姻或同時與二人以上結婚者，處五年以下有期徒刑。

> **§342**（背信罪）
> I 為他人處理事務，意圖為自己或第三人不法之利益，或損害本人之利益，而為違背其任務之行為，致生損害於本人之財產或其他利益者，處五年以下有期徒刑、拘役或科或併科五十萬元以下罰金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「三階論的順序？」 | **行為**（前提）→ **構成要件該當性** → **違法性** → **罪責**，三階全過＝犯罪 |
| 「行為階層排除什麼？」 | 排除①**非人類所為**（自然力、動物）②**非基於意志**（反射動作、睡覺翻身） |
| 「客觀構成要件六要素？」 | **主體、行為、客體、結果、因果關係、情狀**（所有犯罪必有主體＋行為，其餘視條文而定） |
| 「故意的定義？」 | 行為人對客觀構成要件事實有**認知（知）**且有**意欲（欲）**；動機正不正當是違法性問題 |
| 「客觀✓主觀✗的效果？」 | **阻卻故意**→可能改論**過失**（前提：①該罪有罰過失 ②行為人確實有過失） |
| 「客觀✗主觀✓的效果？」 | **未遂**（前提：該罪有處罰未遂）；未遂不限於結果未發生，**客體不存在**、**主體欠缺**等也是未遂 |
| 「條文說『殺人者』是什麼語態？」 | **假設語態**（如果有人殺人的話）→ 符合條文叫**該當**，不能說「違反」殺人罪 |
| 「過失犯與未遂犯的共通特徵？」 | 都是**例外處罰**，以法有明文規定者為限（§12II、§25II） |

## 一、三階論的基本架構

### (一) 為什麼需要三階論？

刑法分則中有些規定彼此可能「打架」：
- §354 毀損罪：毀損他人財產 → **有罪**
- §18 I：未滿14歲人之行為 → **不罰**（無罪）
- 問題：未滿14歲毀損他人財產，有罪還無罪？→ 需要**排定順序**

同理：
- §271 殺人罪 → 有罪
- §23 正當防衛 → 不罰
- 問題：正當防衛殺人，有罪還無罪？→ 需要三階論排序

### (二) 三階論的結構

```
0 行為（前提）
  └→ 篩選：是人做的？是基於意志的？
1 構成要件該當性
  └→ 客觀：是否符合刑法分則規定？
  └→ 主觀：有無故意？
2 違法性
  └→ 有無阻卻違法事由？（§21-24）
3 罪責
  └→ 值不值得被譴責？（責任能力、不法意識、期待可能性）

→ 1 + 2 + 3 全部通過 ＝ 犯罪成立
```

---

## 二、行為階層（第0階）

### (一) 功能

行為階層是三階論**進入的前提**，篩選掉「不是行為」的事物。

### (二) 排除對象

| 排除類型 | 說明 | 例子 |
|---------|------|------|
| **非人類行為** | 純自然力或動物所為 | 流浪狗喝車子油箱的汽油、天災破壞 |
| **非意志行為** | 雖為人所做但非基於意識 | 睡覺翻身、膝跳反射 |

### (三) 行為的定義

- **人**基於**意識**所做的 → 才叫行為
- 思想永遠無罪，刑法處罰的是**行為**，不是思想

## 三、構成要件該當性（第1階）

### (一) 客觀構成要件

判斷行為有無符合刑法分則的規定，最多可拆解為六個要素：

| 要素 | 定義 | 殺人罪(§271) | 公然侮辱(§309) | 重婚罪(§237) |
|------|------|:----------:|:----------:|:---------:|
| ①主體 | 做行為的人 | ✓ 殺人的人 | ✓ 罵人的人 | ✓ 重婚的人 |
| ②行為 | 這條罪罰什麼行為 | ✓ 殺 | ✓ 侮辱 | ✓ 重婚 |
| ③客體 | 行為攻擊的對象 | ✓ 行為人以外的自然人 | ✓ 被侮辱的人 | ✗ 無 |
| ④結果 | 是否要求特定外界變動 | ✓ 人死亡 | ✗ 不要求 | ✗ 不要求 |
| ⑤因果關係 | 行為與結果的因果聯繫 | ✓ 有結果就有因果 | ✗ 無 | ✗ 無 |
| ⑥情狀 | 是否要求特定情境 | ✗ 無 | ✓ 「公然」 | ✗ 無 |

**規律**：
- 所有犯罪都必有 **①主體 + ②行為**
- ③～⑥ 視各條文規定而定
- **有結果 → 必有因果關係**（兩者連動）
- 有些要件是**啟示而來**（如殺人罪的「死亡」結果，條文未明寫）

> **胎兒不是人**：故意讓孕婦流產，不成立殺人罪（客體不該當），而是墮胎罪（§291）。

### (二) 主觀構成要件：故意

#### 故意的定義

- **知**（認知）：知道自己在做什麼
- **欲**（意欲）：希望或容任結果發生
- 二者皆備 → 故意

#### 故意 ≠ 動機

| 概念 | 內涵 | 所屬階層 |
|------|------|---------|
| 故意 | 知道在做什麼＋想要它發生 | 構成要件該當性（第1階） |
| 動機是否正當 | 行為的理由是否合理 | 違法性（第2階） |

> 法警槍斃死刑犯：有殺人故意（知且欲），但依法令行為可阻卻違法。

### (三) 客觀 × 主觀的排列組合

#### 1. 客觀 ✓ × 主觀 ✓ → **故意既遂**

- 客觀構成要件全部實現 + 行為人主觀上有故意
- 例：開槍瞄準要害，被害人死亡 → 殺人既遂

#### 2. 客觀 ✓ × 主觀 ✗ → **阻卻故意**（可能改論過失）

- 客觀實現但行為人不知或不欲
- 效果：排除故意 → **視情況改論過失**
- 改論過失的兩個前提：  
  ① 該罪有罰過失  
  ② 行為人確實有過失

| 案例 | 客觀 | 主觀 | 結果 |
|------|------|------|------|
| 獵人黃昏打山豬，誤殺另一獵人 | 實現殺人構成要件 | 不知在殺人 | 阻卻故意→殺人罪有罰過失→通常成立過失致死 |
| 誤拿別人雨傘（以為是自己的） | 實現竊盜構成要件 | 不知是他人之物 | 阻卻故意→竊盜罪無罰過失→**無罪** |
| IG 限動誤發公開（本想發摯友） | 實現公然侮辱 | 不知是「公然」 | 阻卻故意→公然侮辱無罰過失→**無罪** |

> **阻卻故意 ≠ 必有過失**：  
> - 獵人案若被害人穿山豬頭套、山豬色衣服、趴在草叢模仿叫聲 → 獵人可能**無過失** → 完全無罪

#### 3. 客觀 ✗ × 主觀 ✓ → **未遂**

- 客觀構成要件有任何一個未實現 + 行為人主觀上有故意
- 未遂**不限於結果未發生**：

| 案例 | 欠缺的客觀要件 | 說明 |
|------|---------------|------|
| 開槍打人但人沒死 | **結果**未發生 | 最常見的未遂類型 |
| 殺人但被害人已先心肌梗塞死亡（砍的是屍體） | **客體**不存在 | 殺人未遂 |
| 偷傘但其實是自己忘在圖書館的傘 | **客體**不該當（非他人之物） | 竊盜未遂 |
| 踹孕婦肚子想致流產，但其實只是變胖 | **客體**不存在（無懷胎婦女） | 墮胎未遂(§291) |
| 被開除的業務經理不知被解僱仍簽出賣公司契約 | **主體**資格欠缺 | 背信未遂(§342) |

> **未遂犯的處罰也是例外**（§25II），有些犯罪不罰未遂：  
> - 傷害罪(§277)不罰未遂 → 揍館長但館長毫髮無傷 → 無罪  
> - 毀損罪(§354)不罰未遂 → 刮手機螢幕但保護貼太強刮不壞 → 無罪
