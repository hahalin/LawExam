# 刑法06 筆記：構成要件錯誤論

> 來源：刑法06 課程字幕 01:52:00 ~ 02:40:30

## 📖 法條原文速查

> **§12**（犯罪之故意與過失）
> 行為非出於故意或過失者，不罰。過失行為之處罰，以有**特別規定者**，為限。

> **§13**（故意）
> I：行為人對於構成犯罪之事實，**明知**並**有意**使其發生者，為故意。
> II：行為人對於構成犯罪之事實，雖**預見**其發生而其發生並不違背其本意者，以故意論。

> **§271**（殺人罪）
> I：殺人者，處死刑、無期徒刑或十年以上有期徒刑。
> II：前項之未遂犯罰之。

> **§276**（過失致死罪）
> 因過失致人於死者，處五年以下有期徒刑、拘役或五十萬元以下罰金。

> **§354**（毀損罪）
> 毀棄、損壞前二條以外之他人之物或致令不堪用，足以生損害於公眾或他人者，處二年以下有期徒刑、拘役或五百元以下罰金。
> → **不罰過失**（§12 II 無特別規定）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「構成要件錯誤之效果為何？」 | **阻卻故意**，可能改論過失（若該罪處罰過失且行為人有過失） |
| 「等價客體錯誤之處理？」 | **不影響故意、不影響既遂**。殺 A 認錯殺 C → 對 C 論殺人既遂，不用對 A 論未遂 |
| 「不等價客體錯誤之處理？」 | 想像對象 → 論**未遂**；實際對象 → **阻卻故意**，改論過失 |
| 「打擊錯誤中，對誤中對象有無故意？」 | **法定符合說**：法律評價等價即有故意→既遂；**具體符合說（通說）**：人別不同→阻卻故意→改論過失 |
| 「打擊錯誤與擇一故意如何區分？」 | 打擊錯誤：行為人**自信不會打到他人**；擇一故意：**管他的，打到誰都無所謂** |
| 「雙重具體化錯誤如何區分客體錯誤與打擊錯誤？」 | **許玉秀因果鏈設定理論**：結果發生方式符合因果鏈設定→客體錯誤；不符合→打擊錯誤 |
| 「阻卻故意後是否一定論過失？」 | **不一定**。行為人可能無過失（如隔壁教室無人案） |
| 「打擊錯誤中對原本對象一定是未遂嗎？」 | **不一定**。可能既遂（子彈貫穿）或因反常因果仍為未遂（心臟病發） |

## 1. 錯誤論總論

### 錯誤的定義

**錯誤 = 主觀認知與客觀事實不一致**

### 構成要件錯誤的效果

```
構成要件錯誤
    ↓
阻卻故意
    ↓
是否改論過失？
├── 該罪有處罰過失 + 行為人有過失 → 論過失犯
└── 該罪不罰過失 or 行為人無過失 → 無罪
```

### 阻卻故意 ≠ 必然有過失

| 案例 | 阻卻故意後 | 過失？ |
|------|----------|--------|
| 獵人穿山豬頭套案 | 阻卻殺人故意 | 可能有過失（應注意辨識） |
| 劇組槍被掉包案 | 阻卻殺人故意 | 可能**無過失**（無法預見被掉包） |

## 2. 客體錯誤（人別誤認 / 物別誤認）

### 等價客體錯誤 vs 不等價客體錯誤

```
客體錯誤（認錯）
├── 等價客體錯誤：想殺 A 認錯殺 C（都是人）
│   → 不影響故意、不影響既遂
│   → 不用對原本對象論未遂
│
└── 不等價客體錯誤：想殺人卻打壞物 / 想毀物卻殺人
    → 想像對象：論未遂
    → 實際對象：阻卻故意，改論過失
```

### 等價客體錯誤

- **結論**：不影響故意，直接對實際被害人論既遂
- **重點**：**不用檢討原本對象**（不用對 A 論殺人預備或未遂）
- **理由**：生命法益等價，人別差異不影響構成要件該當性

### 不等價客體錯誤

#### 版本 1：想殺人卻打壞物

| 對象 | 論罪 |
|------|------|
| 想像中的 B（人） | §271 II **殺人未遂** |
| 實際被害的模特兒（物） | 阻卻毀損故意 → 毀損罪不罰過失 → **無罪** |

#### 版本 2：想毀物卻殺人

| 對象 | 論罪 |
|------|------|
| 想像中的模特兒（物） | 毀損未遂 → 毀損罪不罰未遂 → **不罰** |
| 實際被害的 B（人） | 阻卻殺人故意 → 改論 **§276 過失致死** |

### 案例：海巡考題（不等價客體錯誤）

- **事實**：用獵槍打獵，打到獵人
- **分析**：
  1. §271 殺人罪：客觀上射殺了人，但主觀上無殺人故意 → 阻卻故意
  2. 改論 §276 過失致死 → 應注意能注意未注意 → 成立

## 3. 打擊錯誤（手段偏差）

### 打擊錯誤 vs 客體錯誤

| 比較項目 | 客體錯誤 | 打擊錯誤 |
|---------|---------|---------|
| **本質** | 認錯（認知上的失誤） | 技術差（手段上的失誤） |
| **原因** | 人別/物別誤認 | 槍法不準、手滑、風吹偏 |
| **案例** | 把 C 當 A 殺 | 瞄準 A，打歪打到 C |

### 基本處理模式

#### 對原本想攻擊的對象（B）

通常論 **§271 II 殺人未遂**（瞄準 B 但沒打到）

#### 對實際打中的對象（C）—— 兩說

| 學說 | 理由 | 結論 |
|------|------|------|
| **法定符合說** | B 和 C 都是「人」，法律評價相同 | 對 C 仍有殺人故意 → **§271 I 殺人既遂** |
| **具體符合說（通說）** | B 和 C 是不同人，人別不一致 | **阻卻故意** → 改論 **§276 過失致死** |

```
打擊錯誤典型處理（具體符合說/通說）
├── 對 B（原本目標）→ §271 II 殺人未遂
└── 對 C（誤中者）  → 阻卻殺人故意 → §276 過失致死
※ 兩罪想像競合
```

### 法定符合說 vs 具體符合說對照

| 比較項目 | 法定符合說 | 具體符合說（通說） |
|---------|----------|-----------------|
| **判斷標準** | 法律評價是否相同 | 具體人別/物別是否一致 |
| **對誤中者** | 有故意 → 既遂 | 阻卻故意 → 改論過失 |
| **論罪結果** | 殺人未遂＋殺人既遂（競合） | 殺人未遂＋過失致死（競合） |

## 4. 打擊錯誤的變化版

### 變化 1：對原本對象可能既遂

- **案例**：B、C 前後站立，子彈**貫穿 B** 後又打死 C
- 結果：A 對 B → **殺人既遂**（不是未遂）；A 對 C → 另論

### 變化 2：反常因果歷程

- **案例**：A 對 B 開槍打歪，B 看到這一幕**心臟病發死亡**
- 結果：A 對 B → 仍為**殺人未遂**（反常因果歷程，客觀上不可預測 → 客觀歸責中斷）

### 變化 3：誤中對象不一定有過失

- **案例（隔壁教室無人案）**：向老師開槍打歪，子彈穿牆打到隔壁空教室的不速之客
- 分析：隔壁教室排定無人使用，有人入侵為**不可預見** → 行為人對誤中者**無過失**

### 重要提醒

- 法定符合說 vs 具體符合說 → 放在**對 C（誤中者）**的部分檢討
- 對 B（原本目標）本來就有故意，無需用此二說

## 5. 擇一故意 vs 打擊錯誤

### 前提區分

| 情形 | 行為人心態 | 定性 |
|------|----------|------|
| 行為人自信槍法準，不會打到其他人 | 「我只會打到 B」 | **打擊錯誤** |
| 行為人不在乎打到誰 | 「管他的，打到 C 也無所謂」 | **擇一故意**（不確定故意） |

### 案例：連勝文槍擊案（2010 年）

#### 事實
1. 殺手「馬面」欲殺新北市議員**陳鴻源**
2. 選前之夜造勢晚會，陳鴻源在舞臺上
3. 馬面衝上舞臺時，**連勝文與陳鴻源換了位置**
4. 馬面**認錯人**，對連勝文腦袋行刑式開槍
5. 子彈貫穿連勝文太陽穴、下巴飛出，飛到臺下打死一名**身障民眾**

#### 法律分析

| 對象 | 錯誤類型 | 論罪 |
|------|---------|------|
| 馬面 → 陳鴻源 | — | 殺人未遂（目標未打到） |
| 馬面 → 連勝文 | **等價客體錯誤**（認錯人） | **§271 II 殺人未遂**（連勝文存活） |
| 馬面 → 身障民眾 | **非打擊錯誤，而是不確定故意** | **§271 I 殺人既遂** |

#### 關鍵分析：為何對身障民眾不是打擊錯誤？

- 馬面行刑式開槍，**槍管朝向臺下**
- 子彈貫穿後飛向臺下打死民眾 → **可預見且容忍**
- 實務認定：馬面對此結果有**不確定故意**（間接故意）→ 殺人既遂

## 6. 打擊錯誤＋客體錯誤競合（歪打正著案）

### 事實

1. A 想殺 B
2. A 把 C **認錯**當成 B（客體錯誤）
3. A 對 C 開槍，但**打歪了**（打擊錯誤）
4. 子彈飛到旁邊，剛好把真正的 B 打死了（歪打正著）

### 分析：不可跳躍式認定既遂

```
✗ 錯誤想法：A 想殺 B，最後 B 也死了 → 殺人既遂
  （不可以這樣跳過中間的錯誤歷程）

✓ 正確分析：分兩段處理
├── 第一段：A → C（瞄準的對象）
│   └── 殺人未遂（打歪沒打到 C）
│
└── 第二段：A → B（誤中的對象）
    └── B 雖是 A 原本想殺的人，但 A 在開槍時
        瞄準的是 C，打到 B 是意外
    └── 類似「事後故意」概念：打到 B 後才發現是目標
    └── 具體符合說：阻卻故意 → 改論過失致死
```

### 答題結構

1. A 對**瞄準對象**（C）：論殺人未遂
2. A 對**誤中對象**（B）：阻卻故意，改論過失致死
3. 兩罪**想像競合**

## 7. 雙重具體化錯誤

### 問題意識

在行為人與被害人**沒有面對面**的情況下，客體錯誤與打擊錯誤**極難區分**。

### 案例：毒蛋糕案

#### 事實
1. 行為人想殺 A，在蛋糕中下高劑量氰化物
2. 將毒蛋糕放在 A 家餐桌上
3. A 當天加班未歸
4. 平常很少回來的弟弟 B 回家，看到蛋糕以為是哥哥留的，吃了蛋糕死亡

#### 傳統見解的困境

| 看法 | 理由 |
|------|------|
| **客體錯誤** | 搞錯了來吃蛋糕的人（以為是 A 來吃，結果是 B） |
| **打擊錯誤** | 手段失誤（挑錯日子／應該親手遞給 A 而非放在桌上） |

→ 兩種說法都說得通 → 傳統二分法在此失靈

### 許玉秀老師：因果鏈設定理論（通說）

**判斷標準：結果發生的方式是否符合行為人對因果鏈的設定**

| 符合因果鏈設定 | → **客體錯誤**（等價→不影響故意→既遂） |
|--------------|--------------------------------------|
| 不符合因果鏈設定 | → **打擊錯誤**（具體符合說→阻卻故意→改論過失） |

### 因果鏈設定理論的適用

| 案例 | 行為人設定的因果鏈 | 實際死亡方式 | 是否符合 | 結論 |
|------|-----------------|------------|---------|------|
| **毒蛋糕案** | 來吃蛋糕的人因氰化物中毒而死 | 弟弟吃蛋糕因氰化物中毒而死 | **符合** | **客體錯誤** → 等價 → 殺人既遂 |
| **汽車炸彈案** | A 發動引擎時炸彈爆炸，A 被炸死 | 小朋友撿球碰到炸彈被炸死 | **不符合** | **打擊錯誤** → 對 A 論未遂，對小朋友論過失致死 |

```
因果鏈設定理論判斷流程
│
├── 結果發生方式 ＝ 因果鏈設定
│   → 只是「搞錯了對象」
│   → 客體錯誤
│   → 等價：不影響故意 → 既遂
│
└── 結果發生方式 ≠ 因果鏈設定
    → 手段/方法出了意外
    → 打擊錯誤
    → 對原本對象：未遂
    → 對誤中對象：阻卻故意 → 改論過失
```

## 關鍵實務見解速查表

| 實務見解 | 要旨 |
|---------|------|
| **具體符合說（通說）** | 打擊錯誤中，行為人與實際被害者人別不一致→阻卻故意→改論過失 |
| **法定符合說** | 打擊錯誤中，只要法律評價等價（都是「人」）→不阻卻故意→仍為既遂 |
| **連勝文槍擊案判決** | 行刑式開槍槍管朝下→對臺下民眾有不確定故意→殺人既遂，非打擊錯誤 |
| **許玉秀因果鏈設定理論（通說）** | 雙重具體化錯誤之區分：結果發生方式符合因果鏈設定→客體錯誤；不符合→打擊錯誤 |
