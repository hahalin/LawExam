# 刑法03 筆記：刑法效力範圍—人的效力與時的效力

> 來源：刑法03 課程字幕 00:44:45 ~ 01:33:40

---

## 📖 法條原文速查

> **§1**（罪刑法定主義）
> 行為之處罰，以行為時之法律有明文規定者為限。拘束人身自由之保安處分，亦同。

> **§2 I**（從舊從輕原則）
> 行為後法律有變更者，適用行為時之法律。但行為後之法律有利於行為人者，適用最有利於行為人之法律。

> **§2 III**（裁判確定後法律變更）
> 處罰或保安處分之裁判確定後，未執行或執行未完畢，而法律有變更，不處罰其行為或不施以保安處分者，免其刑或保安處分之執行。

> **§3**（屬地原則）
> 本法於在中華民國領域內犯罪者，適用之。在中華民國領域外之中華民國船艦或航空器內犯罪者，以在中華民國領域內犯罪論。

> **§35**（刑之輕重標準）
> I 主刑之輕重，依第三十三條規定之順序定之。
> II 同種之刑，以最高度較長或較多者為重。最高度相等者，以最低度較長或較多者為重。
> III 刑之輕重，以本刑為準。但有選科主刑者，以**最重主刑**為準。其有加重或減輕者，以加重或減輕後之刑為準。併科主刑者，以較重之刑為準。

> **憲法 §52**（總統刑事豁免權）
> 總統除犯內亂或外患罪外，非經罷免或解職，不受刑事上之訴究。

> **刑事訴訟法 §302 ④**（免訴判決）
> 犯罪後之法律已廢止其刑罰者，應諭知免訴之判決。

---

## 📋 釋字/實務見解原文速查

> **釋字 627 號**：總統之刑事豁免權（憲法 §52）為**程序障礙**，非實體上免責。總統卸任後仍得追訴。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「總統刑事豁免權屬於實體免責還是程序障礙？」 | **程序障礙**（釋字 627）→ 卸任後可追訴 |
| 「立委言論免責權屬於實體免責還是程序障礙？」 | **實體上免責**→ 卸任後亦不可追訴 |
| 「條文用語從頓號改為『或』是否為法律變更？」 | **否**，未影響刑罰權範圍 |
| 「銀元改為新臺幣是否為法律變更？」 | **否**，僅幣值換算 |
| 「§349 將『牙保』改為『媒介』是否為法律變更？」 | **否**，僅修正用語 |
| 「空白刑法的行政命令變更是否為法律變更？」 | **實務（否定說）**→ 選擇題選此；學說多數（肯定說） |
| 「行為後入罪化，是否適用 §2 I？」 | **否**，直接適用 §1 罪刑法定 |
| 「行為後除罪化，適用 §2 I 嗎？」 | 實務**不走 §2 I**，走刑訴 §302④ 判**免訴** |
| 「裁判確定後除罪化，效果為何？」 | §2 III：免其刑之執行（前提：尚未執行或執行未完畢） |
| 「裁判確定後法律效果僅變輕（非除罪化），有無 §2 III 適用？」 | **無**，§2 III 僅適用除罪化 |
| 「比較新舊法刑度輕重，同種之刑先比什麼？」 | 先比**上限**（最高度）；上限同再比**下限** |
| 「得併科 vs 選科，何者較輕？」 | **選科**較輕（有不用進監獄的選項） |
| 「最有利法律一定是裁判時法嗎？」 | **不一定**，法律數次修正時，最有利的可能是**中間法** |

## 一、人的效力範圍

### 基本原則：屬地原則（§3）

- 在中華民國領域內犯罪→適用我國刑法，**不分國籍**

### 例外

```
人的效力範圍
├── 原則：屬地原則（§3）→ 領域內犯罪一律適用
└── 例外
    ├── ① 總統刑事豁免權（憲法 §52）→ 程序障礙
    ├── ② 立委/議員言論免責權 → 實體免責
    └── ③ 國際法例外（外交人員等）→ 考試不重要
```

| 例外類型 | 性質 | 效果 |
|---------|------|------|
| 總統刑事豁免權 | **程序障礙** | 在任期間不受追訴，卸任後可追訴（如陳水扁 2008 年） |
| 立委/議員言論免責權 | **實體免責** | 發言永久免責，卸任後亦不追訴 |

## 二、時的效力範圍（§2 I 從舊從輕）

### (一) 何謂「法律變更」

#### 判斷標準：須影響國家刑罰權範圍大小

```
法律變更 → 影響刑罰權範圍大小 → 適用 §2 I
         → 未影響刑罰權範圍 → 不適用 §2 I（直接用現行法）
```

#### 非法律變更的情形

| 修法情形 | 是否為法律變更 | 理由 |
|---------|--------------|------|
| 頓號改「或」 | ✗ | 僅修文字，處罰範圍不變 |
| 銀元改新臺幣（108年統一修正） | ✗ | 幣值換算，數額實質不變 |
| §349「牙保」改「媒介」 | ✗ | 修正用語，含義不變 |
| 事實變更（舊版貨幣改新版） | ✗ | 事實層面變動，非法律觀念改變 |

### (二) 空白刑法的行政命令變更

#### 案例：臺灣獼猴從保育類除名

- 野生動物保育法 §42 處罰獵捕保育類動物
- 臺灣獼猴原為保育類→後行政命令將其除名
- 問題：是否算「法律變更」？

| 學說 | 結論 | 理由 | 考試 |
|------|------|------|------|
| **實務（否定說）** | 非法律變更 | 「法律」＝處罰規定本身，行政命令不算 | ⭐ **選擇題選此** |
| 學者多數（肯定說） | 算法律變更 | 補充規範與處罰規定合一，共同彰顯處罰範圍 | — |

### (三) §2 I 各種操作情形

#### ① 入罪化（行為時無罪→裁判時有罪）

- **不適用 §2 I**
- 直接適用 §1 罪刑法定主義（憲法位階）
- 行為時無罪→不能因事後立法而處罰

#### ② 除罪化（行為時有罪→裁判時無罪）

```
除罪化的處理
├── 立法者直接刪除處罰規定 → 除罪化
├── 大法官宣告違憲（如通姦罪 2020 年）→ 也算除罪化（大法庭已確認）
│
└── 法律效果：
    ├── 裁判確定前 → 實務走刑訴 §302④ 判【免訴】
    │               （先程序後實體，不走 §2 I）
    └── 裁判確定後 → §2 III 免其刑之執行
```

> ⚠️ §2 I 的適用範圍：行為時與裁判時**都有罪**，只是刑度不同→才走 §2 I 比較新舊法

#### ③ 限時法（日落條款）

- 定義：有施行期限的法律（如武漢肺炎防治條例 2020 制定→2024 失效）
- 問題：法律失效後是否算除罪化？

| 學說 | 結論 | 理由 |
|------|------|------|
| 否定說 | 不算除罪化 | 法律消失非法律觀念改正；不罰會助長僥倖心理 |
| 肯定說 | 算除罪化 | 法律失效後再罰無犯罪預防意義，僅剩報復 |

- 921 震災重建暫行條例：曾明文規定即使法律失效仍處罰（採否定說立法例）
- 武漢肺炎條例：未規定→產生學術爭議

### (四) 裁判確定後的法律變更（§2 III）

#### 適用要件

```
§2 III 適用要件
├── ① 處罰或保安處分之裁判已確定
├── ② 尚未執行 或 執行未完畢
└── ③ 法律變更為「不處罰」或「不施以保安處分」（除罪化）
    → 效果：免其刑或保安處分之執行
```

#### 實例

| 案例 | 說明 |
|------|------|
| **通姦罪違憲**（2020.5） | 大法官宣告 §239 違憲→當日法務部釋放所有因通姦罪服刑且無其他刑罰之人 |
| **強制工作違憲** | 大法官認強制工作本質為刑罰→宣告違憲→原受宣告者免其保安處分執行 |

#### 重要限制

- **僅適用除罪化**：裁判確定後若僅刑罰變輕（非除罪化），§2 III **不適用**
- 例：死刑若廢除→已確定死刑犯依現行制度仍須執行（可能需另立特別法處理過渡期）
- 前提：**處罰尚未執行或執行未完畢**→ 已執行完畢者不適用

### (五) 法律效果加重減輕：新舊法比較（§35）

#### 比較順序

```
新舊法刑度比較（§35）
│
├── 1. 不同種主刑 → 依 §33 順序（死刑＞無期＞有期＞拘役＞罰金）
│
└── 2. 同種主刑
    ├── 先比上限（最高度）→ 上限高者較重
    └── 上限同 → 再比下限（最低度）→ 下限高者較重
```

#### 具體案例

| 案例 | 行為時 | 裁判時 | 何者有利 | 結論 |
|------|--------|--------|---------|------|
| 擄人勒贖（2014修法） | 死刑、無期或7年以上 | 無期或7年以上 | 裁判時（刪除死刑） | **從輕**（用新法） |
| 酒駕 | 1年以下 | 2年以下 | 行為時 | **從舊**（用舊法） |
| 逆衝 | 5年以下 | 6月以上5年以下 | 行為時（無下限較輕） | **從舊**（用舊法） |
| 普悠瑪案（過失致死） | 業務過失致死：5年以下、**得併科**罰金 | 過失致死：5年以下、**或**50萬以下罰金 | 裁判時（選科有利） | **從輕**（用新法） |

#### 得併科 vs 選科

| 類型 | 意涵 | 舉例 |
|------|------|------|
| **得併科** | 徒刑＋罰金（同時） | 舊業務過失致死 |
| **選科（或）** | 徒刑**或**罰金（擇一） | 新過失致死 |

→ **選科較有利**：有單獨罰金的選項，不必進監獄

> ⚠️ 不要被罰金數額騙：舊法 3000 元（銀元，需乘以 30）vs 新法 50 萬→重點是得併科vs選科，非數額

### (六) 法令數次變遷與中間法

#### 案例：強制性交罪

```
時間軸（刑度變遷）：

行為時         第一次修法        第二次修法（裁判時）
3年以上10年以下 → 5年以下        → 1年以上7年以下
（綠色）        （紅色）          （藍色）
```

- §2 I 但書：適用**最有利於行為人**的法律
- 本例中：紅色（5年以下）最有利→適用**中間法**

#### 🔑 關鍵結論

> **最有利的法律不見得是裁判時法，有時候可能是中間法。**
