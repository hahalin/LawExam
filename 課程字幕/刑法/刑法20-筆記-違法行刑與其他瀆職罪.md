# 刑法20 筆記：違法行刑與其他瀆職罪

> 來源：刑法20 課程字幕 02:00:00 ~ 02:12:00

---

## 📖 法條原文速查

> **§127**（違法行刑罪）
> I 有執行刑罰職務之公務員，違法執行或不執行刑罰者，處五年以下有期徒刑。
> II 因過失而執行不應執行之刑罰者，處一年以下有期徒刑、拘役或九千元以下罰金。
> → 建議查閱最新六法原文確認刑度

> **§128**（越權受理訴訟罪）
> 公務員對於訴訟事件，明知不應受理而受理者，處三年以下有期徒刑。
> → 建議查閱最新六法原文

> **§129**（違法徵收罪及抑留剋扣罪）
> I 公務員對於租稅或其他入款，明知不應徵收而徵收者，處一年以上七年以下有期徒刑，得併科七十萬元以下罰金。
> II 公務員對於職務上發給之款項、物品，明知應發給而抑留不發或剋扣者，處一年以上七年以下有期徒刑，得併科七十萬元以下罰金。
> → 建議查閱最新六法原文

> **§130**（廢弛職務釀成災害罪）
> 公務員廢弛職務，釀成災害者，處三年以上十年以下有期徒刑。
> → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§127 第一項是故意犯或過失犯？」 | **第一項＝故意犯**；**第二項＝過失犯**（但僅限「執行不應執行之刑罰」） |
| 「法務部長拒簽死刑執行令，是否構成§127？」 | **不構成**。法務部長有審核權限，拒簽不等於「違法不執行」 |
| 「§129 第一項的『徵收』是否含罰鍰？」 | **不含**。「租稅或其他入款」指稅捐等，罰鍰非此處所指 |
| 「§129 巧立名目徵收是否構成？」 | **構成**。於法無據之徵收＝「明知不應徵收而徵收」 |
| 「§130 的行為類型？」 | **不作為犯**（廢弛職務＝該做不做），而非作為犯 |
| 「§130『釀成災害』的性質？」 | 三說：**故意犯之結果**（通說）/ 過失犯結果 / **客觀處罰條件** |
| 「§130 的『災害』要件？」 | 須具**公共性**（影響不特定多數人）＋**侵害性**（實質損害） |

## 一、§127 違法行刑罪

### (一) 雙層結構

| 項次 | 主觀 | 行為 | 說明 |
|------|------|------|------|
| **第一項** | **故意** | 違法執行或不執行刑罰 | 同時涵蓋作為（違法執行）與不作為（不執行） |
| **第二項** | **過失** | 執行不應執行之刑罰 | 僅限「執行不應執行」，不含「不執行應執行」 |

> **注意**：過失犯（第二項）僅處罰「積極去做了不該做的事」，不處罰「消極不做該做的事」。

### (二) 刑期計算問題

- 何時算「應執行」、何時算「不應執行」→ 取決於**裁判確定的刑期**
- 舉例：判決有期徒刑三年確定，卻執行四年 → 多出的一年即為「執行不應執行之刑罰」

### (三) 法務部長拒簽死刑

- 法務部長拒絕簽署死刑執行令 → **不構成**§127
- 理由：法務部長對死刑執行有**實質審核權限**，拒簽屬於行使職權

---

## 二、§128 越權受理訴訟罪

- **主體**：有受理訴訟職務之公務員（法官）
- **行為**：明知不應受理而受理
- **實務現況**：極少發生，因法院分案制度嚴格
- 考試幾乎不出，了解即可

---

## 三、§129 違法徵收及抑留剋扣罪

### (一) 第一項：違法徵收

| 要件 | 說明 |
|------|------|
| 主體 | 公務員 |
| 客體 | 租稅或其他入款 |
| 行為 | **明知**不應徵收而徵收 |
| 主觀 | 直接故意（明知） |

#### 態樣

- **於法無據**：完全沒有法律依據就向人民徵收
- **巧立名目**：假借其他名義，實質上徵收不應徵收的款項
- 罰鍰**不算**此處的「租稅或其他入款」

#### 案例：廖學廣案（課堂舉例）

- 事實：公務員違法向商家徵收費用
- 爭點：是否同時構成圖利罪？
- 結論：圖利公庫 → **不構成**§131，因§131 要求圖「私人」不法利益

### (二) 第二項：抑留剋扣

| 要件 | 說明 |
|------|------|
| 客體 | 職務上**應發給**之款項、物品 |
| 行為 | 抑留不發 或 剋扣（扣減應發數額） |

#### 案例說明

- 舉例：發放防疫物資時，公務員私自扣留部分物品不發給民眾
- 抑留＝應發不發（全部扣住）；剋扣＝部分扣減

## 四、§130 廢弛職務釀成災害罪

### (一) 基本結構

- **行為類型**：**純正不作為犯**
- 「廢弛職務」＝該做的事不做、怠於執行職務

### (二) 「災害」的要件

| 特徵 | 說明 |
|------|------|
| **公共性** | 須影響**不特定多數人** |
| **侵害性** | 須造成**實質損害**（不只是抽象危險） |

### (三) 核心爭議：「釀成災害」的主觀要件

| 學說 | 主張 | 說明 |
|------|------|------|
| **故意說（通說）** | 「釀成災害」為故意犯的結果 | 廢弛職務＝故意；釀成災害＝故意行為造成的結果 |
| **過失說** | 「釀成災害」為過失造成 | 廢弛職務故意，但對災害結果僅為過失 |
| **客觀處罰條件說** | 「釀成災害」為客觀處罰條件 | 不問故意或過失，只要客觀上發生災害即可處罰（李聖傑教授採此說） |

```
§130 結構分析
│
├── 行為：廢弛職務（故意不作為）
│
└── 結果：釀成災害
    ├── 故意說：行為人對災害結果也有故意
    ├── 過失說：行為人對災害結果僅有過失
    └── 客觀處罰條件說：不問主觀，客觀發生即可
```

> **考題提醒**：地方特考曾出過此題，要求分析三說並表明立場。
