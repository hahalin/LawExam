# 刑法01 筆記：違法性與阻卻違法事由

> 來源：刑法01 課程字幕 01:52:00 ~ 02:20:00

---

## 📖 法條原文速查

> **§21**（依法令之行為）
> I 依法令之行為，不罰。
> II 依所屬上級公務員命令之職務上行為，不罰。但明知命令違法者，不在此限。

> **§22**（業務上之正當行為）
> 業務上之正當行為，不罰。

> **§23**（正當防衛）
> 對於現在不法之侵害，而出於防衛自己或他人權利之行為，不罰。但防衛行為過當者，得減輕或免除其刑。

> **§24**（緊急避難）
> I 因避免自己或他人生命、身體、自由、財產之緊急危難而出於不得已之行為，不罰。但避難行為過當者，得減輕或免除其刑。
> II 前項關於避免自己危難之規定，於公務上或業務上有特別義務者，不適用之。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「構成要件該當產生什麼效果？」 | **推定違法**（經驗上，符合構成要件的行為通常不正當） |
| 「四大阻卻違法事由？」 | §21 依法令行為/公務員依上級命令、§22 業務上正當行為、§23 正當防衛、§24 緊急避難 |
| 「正當防衛與緊急避難對象的區別？」 | 正當防衛→對**攻擊者**（不法侵害者）；緊急避難→通常犧牲**無辜第三人** |
| 「阻卻違法事由的三大要件？」 | ①**前提事實**具備 ②**手段適當** ③主觀上有**防衛/避難認知** |
| 「防衛過當的效果？」 | **不能阻卻違法**（仍有罪），但得**減輕或免除其刑**（§23但書） |
| 「§21、§22 會不會過當？」 | **會**，所有阻卻違法事由都會過當；只是§21/§22過當無減免其刑的明文規定 |
| 「容許構成要件錯誤？」 | ＝**誤想系列**（客觀上無阻卻事由前提，行為人主觀誤以為有）→通說改論**過失** |
| 「反面容許構成要件錯誤？」 | ＝**偶然系列**（客觀上有阻卻事由前提，行為人主觀不知）→通說**無效果**，原罪成立 |
| 「超法規阻卻違法事由？」 | §21-24以外，學理上承認的阻卻違法事由，如**被害人承諾** |

## 一、違法性的基本概念

### (一) 違法性看什麼？

- 這個已該當構成要件的行為，背後是**正當**或**不正當**
- 構成要件該當 → **推定違法**（經驗法則：殺人通常不正當）
- 推定可被推翻：如果有阻卻違法事由 → 阻卻違法 → 不成立犯罪

### (二) 違法性 vs 構成要件該當性

| 構成要件該當性 | 違法性 |
|--------------|-------|
| 看行為有無符合分則規定 | 看行為正當或不正當 |
| 判斷「故意」（知與欲） | 判斷「阻卻違法事由」 |
| 動機不在此階段討論 | 動機正不正當在此階段判斷 |

## 二、五大阻卻違法事由

### (一) §21 I：依法令行為

- 例：法警依法執行槍斃死刑犯
  - 該當故意殺人罪的構成要件 ✓
  - 但依法令行為 → 阻卻違法 → 不成立犯罪
- 法警**當然有殺人故意**（知道在殺人、也希望死刑犯死亡），但有正當理由

### (二) §21 II：公務員依上級命令

- 例：建管機關拆除違章建築
  - 該當毀損罪 ✓
  - 但公務員依上級命令的職務行為 → 阻卻違法
- 但書：**明知命令違法者，不在此限**

### (三) §22：業務上正當行為

- 例：新聞記者為揭發黑心食品工廠，進入臥底並以密錄器拍攝
  - 該當竊錄罪(§315-1) ✓
  - 但記者採訪行為屬業務上正當行為 → 阻卻違法

### (四) §23：正當防衛

- **前提**：對於**現在不法之侵害**
- **對象**：針對**攻擊者**（不法侵害者）本人
- **精神**：合法無需向不法低頭
- 例：被歹徒強吻，踹歹徒致其腿部瘀傷
  - 該當傷害罪 ✓
  - 正當防衛 → 阻卻違法

### (五) §24：緊急避難

- **前提**：避免自己或他人之**緊急危難**
- **對象**：通常犧牲**無辜第三人**的利益（大多數情況）
- 例：被山豬追趕，翻牆進鄰居庭院躲避
  - 該當侵入住居罪(§306) ✓
  - 緊急避難 → 阻卻違法

### (六) 超法規阻卻違法事由

- §21-24以外，學理上承認的阻卻違法事由
- **被害人承諾**：例如去刺青，刺青師在你身上刺圖案
  - 該當傷害罪 ✓
  - 被害人明確承諾身體法益可捨棄 → 阻卻違法

## 三、阻卻違法事由的構造

所有阻卻違法事由（包括法定與超法規）都有相同的三大格子：

```
阻卻違法 ＝ ① 前提事實具備 ＋ ② 手段適當 ＋ ③ 主觀上有認知
          三格全✓ → 阻卻違法 → 不成立犯罪
          任一格✗ → 不能阻卻違法
```

---

## 四、三格排列組合

### (一) 前提 ✓ 手段 ✓ 主觀 ✓ → **阻卻違法**

- 正常的正當防衛、緊急避難等
- 三要件全部具備，阻卻違法，不成立犯罪

### (二) 前提 ✓ 手段 ✗ 主觀 ✓ → **過當**

| 過當類型 | 案例 |
|---------|------|
| **防衛過當** | 被強吻 → 拿刀捅對方下體致重傷（明明踹倒即可） |
| **防衛過當** | 老人拿拐杖攻擊 → 一刀捅死（踹倒即可） |
| **避難過當** | 被山豬追 → 抓無辜小孩餵山豬（明明可翻牆躲避） |

**效果**：
- **不能阻卻違法**（仍有罪）
- 但§23但書/§24但書：得**減輕或免除其刑**

**重要觀念**：
- **所有阻卻違法事由都會過當**（不限§23/§24）
- §21 依法令行為也會過當（如拆違建用炸藥，連合法部分都炸毀）
- §22 業務上正當行為也會過當（如記者臥底順便偷拍老闆娘洗澡）
- 差別：§23/§24 有明文減免其刑（緊急情況值得同情），§21/§22 無明文

### (三) 前提 ✗ 主觀 ✓ → **誤想**（容許構成要件錯誤）

- 客觀上**無**阻卻違法前提事實，行為人主觀上**誤以為有**

| 誤想類型 | 案例 |
|---------|------|
| **誤想防衛** | 路人揮手想打招呼，行為人誤以為要襲胸而踹人 |
| **誤想被害人承諾** | 外國人比著臉喊 Taiwan number one，刺青師誤以為要在臉上刺字 |

**效果（通說）**：改論**過失犯**
- 誤想被害人承諾的刺青師 → 過失傷害

> **名詞解釋**：
> - 容許構成要件 ＝ 阻卻違法事由（德文翻譯）
> - 禁止構成要件 ＝ 刑法分則的各罪規定
> - 容許構成要件錯誤 ＝ 誤想阻卻違法事由存在

### (四) 前提 ✓ 主觀 ✗ → **偶然**（反面容許構成要件錯誤）

- 客觀上**有**阻卻違法前提事實，行為人主觀上**完全不知道**

| 偶然類型 | 案例 |
|---------|------|
| **偶然避難** | 基於毀損故意砸仇人家窗戶，結果剛好救了瓦斯漏氣的仇人一命 |
| **偶然避難** | 司馬光若是屁孩砸水缸（不知有人溺水），卻意外救出小朋友 |

**效果（通說）**：**無效果**，原本論什麼罪就論什麼罪
- 偶然避難不能阻卻違法 → 仍成立毀損罪
