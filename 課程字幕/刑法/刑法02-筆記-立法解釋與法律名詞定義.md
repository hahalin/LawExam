## 📖 法條原文速查

> **§10 I**（以上、以下、以內）
> 稱以上、以下、以內者，俱連本數或本刑計算。
> → 「超過」「未滿」則**不含**本數

> **§10 II**（公務員）
> 稱公務員者，謂下列人員：
> 一、依法令服務於國家、地方自治團體所屬機關而具有**法定職務權限**，以及其他依法令從事於公共事務，而具有法定職務權限者。（**身分公務員**）
> 二、受國家、地方自治團體所屬機關依法委託，從事與委託機關權限有關之公共事務者。（**授權公務員**）
> → 第三類「委託公務員」為學說整理，實務上以前二款為主

> **§10 IV**（重傷）
> 稱重傷者，謂下列傷害：
> 一、毀敗或嚴重減損一目或二目之視能。
> 二、毀敗或嚴重減損一耳或二耳之聽能。
> 三、毀敗或嚴重減損語能、味能或嗅能。
> 四、毀敗或嚴重減損一肢以上之機能。
> 五、毀敗或嚴重減損生殖之機能。
> 六、其他於身體或健康，有重大不治或難治之傷害。

> **§10 V**（性交）
> 稱性交者，謂非基於正當目的所為之下列性侵入行為：
> 一、以性器進入他人之性器、肛門或口腔，或使之接合之行為。
> 二、以性器以外之其他身體部位或器物進入他人之性器、肛門，或使之接合之行為。
> → 第二款**不含口腔**

> **§230**（血親性交罪）
> 與直系或**三親等內**旁系血親為性交者，處五年以下有期徒刑。
> → 「以內」含本數，故三親等亦包含在內

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「以上、以下、以內是否包含本數？」 | **包含**（§10I） |
| 「超過、未滿是否包含本數？」 | **不包含** |
| 「骨折是否為重傷？」 | 原則上**否**（可接回、非不治難治）→ 重傷需**事後判斷**，看最終恢復情形 |
| 「重傷的六款記憶口訣？」 | 佩佩豬：①**視**能②**聽**能③**語味嗅**能④**四肢**⑤**生殖**⑥**概括**（重大不治難治） |
| 「§10V 第一款與第二款的差別？」 | 第一款含**口腔**（性器進入口腔＝性交）；第二款**不含口腔**（身體部位/器物不論） |
| 「強迫被害人自慰是否為性交？」 | **否**，為猥褻（非「進入」或「接合」） |
| 「舔陰部是否構成性交？」 | **是**（舌頭＝身體部位→進入陰唇內側＝進入性器→§10V 第二款） |
| 「飛機杯套在被害人性器上是否為性交？」 | **是**（器物與性器接合→§10V 第二款） |
| 「公立學校教師收賄，是否以公務員論？」 | **否**，公立學校教師**非身分公務員**（不具公權力行使性質）→ 頂多以授權公務員論 |
| 「約僱人員是否可能是身分公務員？」 | **可**，只要具有**法定職務權限**且非從事機械性事務 |

## 二、重傷（§10 IV）

### (一) 佩佩豬記憶法（六款）

```
重傷六款（佩佩豬教學法）
│
├── ① 毀敗/嚴重減損 一目或二目之「視」能
├── ② 毀敗/嚴重減損 一耳或二耳之「聽」能
├── ③ 毀敗/嚴重減損 「語」能、「味」能或「嗅」能
├── ④ 毀敗/嚴重減損 一「肢」以上之機能
├── ⑤ 毀敗/嚴重減損 「生殖」之機能
└── ⑥ 概括條款：其他於身體或健康有「重大不治或難治」之傷害
```

### (二) 重傷判斷原則

| 原則 | 說明 |
|------|------|
| **事後判斷** | 重傷以**最終結果**認定，非行為當下判斷 |
| **毀敗** | 功能完全喪失 |
| **嚴重減損** | 功能嚴重衰退（未完全喪失但已大幅減損） |
| **不治或難治** | 終局性的結果，無法回復或極難回復 |

> **例**：被打到骨折 → 骨折可接回 → 非不治或難治 → **不算重傷**
> **例**：被打到脾臟破裂須摘除 → 功能永久喪失 → 概括條款 → **重傷**

## 三、性交（§10 V）

### (一) 前提要件：非基於正當目的

- 2006 年增修，排除醫療行為等正當目的
- 老師觀點：此要件**多餘**，因§22 業務上正當行為本有阻卻違法

### (二) 第一款 vs 第二款

| 比較項目 | 第一款 | 第二款 |
|---------|--------|--------|
| **行為工具** | 性器 | 性器以外之**身體部位**或**器物** |
| **進入/接合部位** | 他人性器、肛門、**口腔** | 他人性器、肛門（**不含口腔**） |
| **方向** | 含主動進入＋被動使之接合 | 同左 |

### (三) 重要案例

#### 案例一：舔陰部

- 舌頭＝身體部位（非性器）→ 適用**第二款**
- 進入陰唇內側＝進入性器
- 結論：構成**性交**

#### 案例二：飛機杯套在被害人性器

- 飛機杯＝器物
- 器物與被害人性器接合
- 結論：構成**性交**（§10V 第二款「使之接合」）

#### 案例三：逼迫被害人自慰

- 被害人自行碰觸自己性器 → 無「進入」或「接合」行為
- 結論：**不構成性交**，僅為**猥褻**

## 四、公務員（§10 II）

### (一) 三類公務員體系圖

```
刑法公務員（§10 II）
│
├── 第一類：身分公務員（§10 II 第1款前段）
│   ├── 要件①：依法令服務於國家/地方自治團體所屬「機關」
│   ├── 要件②：具有「法定職務權限」（排除機械性事務）
│   └── 不分產生方式：政務官、事務官、約僱人員均可
│
├── 第二類：授權公務員（§10 II 第1款後段）
│   └──（本堂未講，下次說明）
│
└── 第三類：委託公務員（§10 II 第2款）
    └──（本堂未講，下次說明）
```

### (二) 身分公務員的要件

| 要件 | 說明 |
|------|------|
| **服務於國家/地方自治團體所屬「機關」** | 須為組織法上的機關；公立學校、公立醫院、公營事業**非機關** |
| **法定職務權限** | 依法令享有判斷空間或公權力的職務權限 |
| **排除：機械性事務** | 僅從事機械性、肉體性勞務→不具法定職務權限→非身分公務員 |

### (三) 非身分公務員的排除對象

| 排除對象 | 理由 |
|---------|------|
| **公立學校教師** | 公立學校非機關，教學非公權力行使 |
| **公立醫院醫師** | 公立醫院非機關，醫療非公權力行使 |
| **公營事業員工** | 公營事業非機關 |

- **例外**：三軍總醫院（三總）的軍醫官 → 因具**軍官身分**（軍官＝公務員）→ 以軍官身分成為**身分公務員**，與醫師身分無關

### (四) 身分公務員不分產生方式

| 身分種類 | 公務員？ | 說明 |
|---------|---------|------|
| 政務官（部長、立委） | ✔ | 最典型的身分公務員 |
| 事務官（高普考錄取） | ✔ | 一般國家文官 |
| 約僱人員 | ✔（有條件） | 須具法定職務權限，非機械性事務 |

### (五) 經典案例：基隆殯葬所約僱人員（103年判決）

#### 事實
1. 基隆殯葬所兩名約僱人員負責管理火葬爐
2. **行為一**：收殯葬業者紅包，協助安排火化好時辰
3. **行為二**：收民眾紅包，利用公家火葬爐火化寵物（貓狗）遺體

#### 分析
- 火化撿骨之職務＝直接隸屬殯葬所協助人民處理喪葬事宜
- **非單純機械性肉體勞務** → 具法定職務權限
- 結論：約僱人員仍為**身分公務員**

#### 法律效果
- 收紅包安排火化＋火化寵物遺體 → 構成**違背職務受賄**（貪汙治罪條例）
- 公務員身分使刑責大幅加重
