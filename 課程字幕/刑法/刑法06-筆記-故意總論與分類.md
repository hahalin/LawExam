# 刑法06 筆記：故意總論與分類

> 來源：刑法06 課程字幕 00:00:00 ~ 01:03:00

## 📖 法條原文速查

> **§13**（故意）
> I：行為人對於構成犯罪之事實，**明知**並**有意**使其發生者，為故意。→ **直接故意**
> II：行為人對於構成犯罪之事實，雖**預見**其發生而其發生並不違背其本意者，以故意論。→ **間接故意**

> **§14**（過失）
> I：行為人雖非故意，但按其情節**應注意，並能注意，而不注意**者，為過失。→ **無認識過失**
> II：行為人對於構成犯罪之事實，雖**預見**其能發生而確信其不發生者，以過失論。→ **有認識過失**

> **§131**（圖利罪）
> I：公務員對於主管或監督之事務，**明知**違背法令，直接或間接圖自己或其他私人不法利益，因而獲得利益者，處一年以上七年以下有期徒刑，得併科一百萬元以下罰金。
> → 需「明知」，即**直接故意**始可成立

> **§213**（公文書登載不實罪）
> 公務員**明知**為不實之事項，而登載於職務上所掌之公文書，足以生損害於公眾或他人者，處一年以上七年以下有期徒刑。
> → 需「明知」，即**直接故意**

> **§275**（加工自殺罪）
> I：受他人囑託或得其承諾而殺之者，處一年以上七年以下有期徒刑。
> → 行為人須認知「被害人有求死意願」（對情狀有認知），如看護不知遺書內容→無故意

> **野生動物保育法 §40**
> 有下列情形之一，處六月以上五年以下有期徒刑，得併科新臺幣三十萬元以上一百五十萬元以下罰金：…違反第十八條第一項第一款…。
> → **空白刑法**：需搭配保育類野生動物名錄認定

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「故意的認識內容包括哪些？」 | 須認識**所有客觀構成要件事實**（主體、客體、行為、結果、因果歸責、行為情狀） |
| 「故意是否須認識行為的法律評價？」 | **不須**，法律評價之認知屬**不法意識**問題（§16），非故意範疇 |
| 「故意是否須認識行為之不法性？」 | **不須**，不法性認知屬禁止錯誤問題 |
| 「空白刑法中對補充規範之認識錯誤，效果為何？」 | **通說（連讀理論）**：禁止錯誤（§16）；**蔡聖偉**：構成要件錯誤→阻卻故意 |
| 「直接故意與間接故意之區別實益？」 | ①死刑限直接故意；②法條明文「明知」者限直接故意（§131、§213） |
| 「擇一故意中，未實現的客體應如何論罪？」 | 有爭議：少數說論未遂，多數說認為不需另論未遂 |
| 「事前故意是否成立故意？」 | **否**，故意須存在於**行為時**；事前的殺意在行為時未實現≠故意 |
| 「犯罪動機是否影響故意之成立？」 | **不影響**，動機與故意無關；惟實務論證常交代動機 |

## 1. 客觀構成要件回顧：行為情狀

行為情狀為**客觀構成要件六格的最後一格**，提供犯罪行為的脈絡條件。

```
客觀構成要件六格
├── ① 主體（行為人資格）
├── ② 客體（行為對象）
├── ③ 行為（作為/不作為）
├── ④ 結果
├── ⑤ 因果關係與客觀歸責
└── ⑥ 行為情狀（犯罪的脈絡條件）
```

行為情狀的範例：
- §321 加重竊盜「攜帶兇器」→ 兇器為行為情狀
- §275 加工自殺「受囑託或得其承諾」→ 被害人求死意願為情狀
- 公然猥褻罪「公然」→ 不特定人得以共見共聞為情狀

## 2. 故意概論：知＋欲

故意 = **認知（知）**＋ **意欲（欲）**

行為人必須對**所有客觀構成要件事實**都有認知：

| 欠缺認知的要件 | 案例 | 效果 |
|--------------|------|------|
| 客體無認知 | 獵山豬案：以為是山豬實為獵人 | 阻卻殺人故意 |
| 結果無認知 | 刺傷案：只想刺傷卻致死 | 阻卻殺人故意（仍有傷害故意） |
| 情狀無認知 | IG摯友限動案：不知是摯友限動 | 可能阻卻妨害秘密故意 |
| 情狀無認知 | 撿發票案：以為是無主物實為脫離物 | 阻卻侵占脫離物故意 |
| 情狀無認知 | 小孩偷放刀案：不知背包有刀 | 阻卻加重竊盜，僅論普通竊盜 |
| 情狀無認知 | 看護案：不知遺書中之求死意願 | 阻卻加工自殺故意 |

## 3. 故意認識對象的層次

```
故意須認知的內容
├── 自然事實（物理性質） → 須認知
├── 社會意義（文化脈絡） → 須認知
└── 法律評價（法律概念） → 不須認知（屬不法意識問題）
```

### 關鍵區分

| 層次 | 說明 | 無認知時效果 |
|------|------|------------|
| **自然事實** | 物理上的客觀事實（人、物、動作） | **阻卻故意** |
| **社會意義** | 文化脈絡賦予的意涵（猥褻性、侮辱性等） | **阻卻故意** |
| **法律評價** | 法律概念的涵攝歸類 | **不影響故意**（→ §16 禁止錯誤） |

### 案例：德國啤酒杯墊案（輔大轉學考）

- **事實**：在啤酒杯墊上記帳的法律性質為何？
- **自然事實無認知**（不知墊子上有字跡）→ 阻卻故意
- **社會意義無認知**（不知在墊子上記帳有記帳功能）→ 阻卻故意
- **法律評價無認知**（不知這算「文書」）→ 不影響故意，僅為不法意識問題

### 案例：中指案

- 比中指 → **社會意義**為侮辱（文化共識），須認知
- 手語中的「兄弟」手勢 → 外觀類似比中指但社會意義不同

### 案例：公然猥褻案

- 非洲部落女性裸露上身 → 在該文化中無性慾暗示之**社會意義**
- 若不知在台灣裸露乳房有猥褻之社會意義 → 可能阻卻故意

### 法律評價不須認知的補充

- 德國 §211 謀殺罪之「卑劣」→ 屬法律評價，行為人不須認知自己的動機「卑劣」
- 在台灣貼裸照不知算「猥褻」→ 屬法律評價，不影響故意

## 4. 空白刑法補充規範之認知

### 問題：行為人對空白刑法所引用的補充規範（如保育類名錄）是否須認知？

### 案例：河馬案

- **事實**：行為人飼養河馬，不知河馬為保育類動物
- **法律結構**：野生動物保育法 §40 → 引用「保育類野生動物名錄」→ 河馬列名

### 兩說對照

| 學說 | 立場 | 理由 | 效果 |
|------|------|------|------|
| **連讀理論**（通說、實務） | 禁止錯誤（§16） | 將名錄中的具體物種名稱帶入條文一起讀，行為人對「飼養動物」此事實有認知即可 | 故意不受影響；有減輕可能（§16 但書） |
| **構成要件錯誤說**（蔡聖偉） | 阻卻故意 | 忠於法條文義，「保育類野生動物」本身就是構成要件要素，行為人須認知客體屬保育類 | 阻卻故意，可能改論過失 |

## 5. 故意分類

### 基本分類：直接故意 vs 間接故意

| 類型 | 法條 | 認知要素 | 意欲要素 |
|------|------|---------|---------|
| **直接故意** | §13 I | **明知**（確定認知） | **有意使其發生**（希望） |
| **間接故意** | §13 II | **預見**（可能性認知） | **不違背本意**（容忍） |

### 進階分類：確定故意 vs 不確定故意

```
故意
├── 確定故意（明確知道誰會受害）
│   ├── 直接故意（希望）
│   └── 間接故意（容忍）
│
└── 不確定故意（不確定誰會受害）
    ├── 擇一故意：一發子彈射入人群，不確定打到誰
    │   → 實際打到者：故意既遂
    │   → 未打到者：是否論未遂？有爭議
    │
    └── 累積故意：手榴彈丟入人群 / 開車衝撞人群
        → 對所有可能受害者均有故意
```

### 區別實益

| 實益 | 說明 |
|------|------|
| **死刑的主觀要件** | 死刑僅限**直接故意**，間接故意不得判死 |
| **法條明文「明知」** | §131 圖利罪、§213 登載不實 → 限**直接故意**（明知） |
| **舊 §285 花柳病罪**（已刪除） | 「明知」自己有花柳病而傳染 → 限直接故意 |

### 案例：§131 圖利罪之「明知」

- 需「明知違背法令」→ 直接故意
- 公務員若僅「大概知道可能違法」→ 僅為間接故意 → 不成立 §131

## 6. 意欲要素的三種態度

```
意欲（欲）的光譜
├── 希望（積極追求）→ 直接故意
├── 容忍（不在乎、管他的）→ 間接故意
└── 單純願望（心裡希望但無法掌控）→ 非故意
```

### 案例：單純願望 ≠ 故意

| 案例 | 分析 | 結論 |
|------|------|------|
| **飛機空難案**：A 替 B 買機票，心想飛機最好掉下來 | 機率極低、行為人無法掌控結果 | 單純願望，**非故意** |
| **果凍噎死案**：A 餵小孩吃果凍，心想最好噎死 | 通常不會噎死，除非小孩有吞嚥障礙 | 一般情況為單純願望，**非故意**；若明知有吞嚥障礙則不同 |

## 7. 故意的時間要件：須存在於行為時

```
行為前 ──── 行為時 ──── 行為後
  ✗          ✓          ✗
事前故意    故意成立    事後故意
（非故意）  （唯一時點）（非故意）
```

### 事後故意 ≠ 故意

- **案例**：開車不小心撞到惡鄰居，事後覺得「撞得真棒」
- 分析：撞擊行為時無故意，事後的開心**不等於故意**

### 事前故意 ≠ 故意

- **案例**：A 計畫殺鄰居，保養手槍時不慎走火射殺鄰居
- 分析：保養手槍時尚未「著手」殺人行為，走火為**過失**而非故意
- 重點：故意須存在於**著手行為時**，事前的計畫不等同行為時的故意

## 8. 犯罪動機 ≠ 故意

- **原則**：犯罪動機不影響故意成立
- **實務注意**：論證時仍常交代動機（如詐騙帳戶案：行為人為何提供帳戶→動機為賺錢，但不影響幫助詐欺故意之認定）

## 關鍵實務見解速查表

| 實務見解 | 要旨 |
|---------|------|
| **連讀理論（通說、實務）** | 空白刑法中補充規範不屬構成要件事實，不認知僅為禁止錯誤 |
| **蔡聖偉（構成要件錯誤說）** | 空白刑法之補充規範仍為構成要件要素，不認知應阻卻故意 |
