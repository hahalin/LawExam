## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「常態關聯性與相當因果關係的相當性有何關係？」 | **本質相同**，都是剔除顯然超出一般人經驗預期的反常因果歷程 |
| 「醫院案/救護車案中，行為人對死亡結果是否可歸責？」 | **不可歸責**（風險未實現：原本是刀傷/槍傷風險→變成火災/車禍風險＝A變B） |
| 「血友病患特殊體質案的通說見解？」 | **不具常態性**＝反常因果歷程（旁觀者角度，一般人看不出血友病）→ 未遂犯 |
| 「結果的不可避免性（義務違反關聯性）是什麼？」 | 行為人做錯事，但就算沒做錯事結果**也會發生** → 風險未實現 |
| 「規範保護目的不相關是什麼意思？」 | 行為人違反的規範目的是A，但實際結果是與A**無關的B** |
| 「被害人自我負責的前提？」 | ①被害人清楚知道風險 ②精神/年齡狀態正常 ③**自由地**選擇承擔 |
| 「既遂犯與未遂犯的審查順序？」 | 既遂犯**先客觀**（氣碎飯先客）；未遂犯**先主觀**（未碎飯先主） |

## 一、第二層：風險實現

> 核心問題：行為人製造的A風險→結果發生方式是否仍基於A？還是已變成B？

### 子原則 1：常態關聯性

> ＝ 相當因果關係的「相當性」。用反面方式剔除顯然超出一般人經驗預期的反常因果歷程。

**案例：醫院案/救護車車禍案**

| 步驟 | 醫院案 | 救護車案 |
|------|--------|---------|
| 原本製造的風險 | 槍傷/刀傷致死（A風險） | 刀傷致死（A風險） |
| 實際死因 | 醫院火災/醫療疏失（B風險） | 救護車翻車（B風險） |
| 風險A是否實現？ | **否**（A→B） | **否**（A→B） |
| 結論 | **反常因果歷程** → 不可歸責 | **反常因果歷程** → 不可歸責 |

### 解題示範：救護車車禍案

> 老師以此案為例示範完整的刑法實例題寫作架構。

#### 標題的五個成分

```
標題 = ① 行為人 + ② 行為 + ③ 成立/不成立 + ④ 罪名 + ⑤ 法條依據
```

**範例**：甲持刀砍乙的行為，不成立殺人罪的既遂犯（§271 I）。

> **注意**：
> - 行為要**具體特定**（不能只寫「甲的行為」）
> - 罪名區分：殺人罪的**既遂犯** / 殺人罪的**未遂犯** / 殺人罪的**教唆犯** / 殺人罪的**共同正犯**
> - **不要**寫「殺人未遂罪」「教唆殺人罪」「共同殺人罪」→ 未遂、教唆、共同正犯是罪名的**實現方式**，不是罪本身

#### 既遂犯審查順序（氣碎飯先客）

```
（一）甲持刀砍乙，不成立殺人罪既遂犯（§271 I）

    1. 客觀構成要件
       ├── 行為主體、行為、結果 → 宣稱式帶過
       ├── 條件因果關係 → 有（不砍就不會送醫）
       └── 客觀歸責
           ├── 製造法所不容許的風險 → 有
           └── 風險實現 → 無（反常因果歷程）
    
    → 客觀構成要件不該當（客觀不可歸責）
    → 不成立既遂犯（到此即停，不進入主觀）
```

#### 未遂犯審查順序（未碎飯先主）

```
（二）甲成立殺人罪未遂犯（§271 II）

    1. 主觀 → 有殺人故意（不用定義什麼是故意）
    2. 客觀 → 有著手（未遂犯客觀只有著手，不會有因果歸責）
    3. 違法性、罪責 → 無阻卻事由 → 甲違法且有責
    
    → 成立殺人罪未遂犯
```

> **重要**：因果與歸責只出現在**既遂犯**的標題下。未遂犯的客觀只有**著手**。

### 子原則 1 補充：血友病患特殊體質

| 學說 | 結論 | 理由 |
|------|------|------|
| **通說** | **不具常態性**（反常因果） | 客觀歸責是**旁觀者角度**（行為當下判斷），一般人看不出被害人有血友病；不存在特殊認知 |
| **少數說**（許澤天） | 具常態性（可歸責） | 援引民法蛋殼腦殼理論：法規範對身心特別虛弱的被害人應提供更有效保護，不應從機率角度排除 |

**老師立場（支持通說）**：
- 蛋殼腦殼理論在民法合理→肯認因果→被害人**獲得賠償**（保護被害人）
- 但在刑法→肯認歸責→行為人成立**更重的犯罪**→被害人沒有獲得任何好處
- 刑法不是為了滿足被害人的報復心

> **注意**：許澤天老師的看法**僅限**被害人「特殊體質」的情形，並非要把整個客觀歸責變成事後判斷。

### 子原則 2：結果的不可避免性（義務違反關聯性）

> 行為人做錯事，但就算沒做錯事，結果也還是會發生 → 風險未實現。

**案例一：山羊毛案**
1. 皮革工廠男員工未消毒山羊毛就交給女工加工
2. 女工感染細菌死亡
3. **事後證實**：該細菌非常頑強，即使按SOP消毒也殺不死

| 審查步驟 | 分析 |
|---------|------|
| 行為應挑哪一段？ | **交付有細菌的羊毛**（不是「沒有消毒」→ 那是義務違反，不是行為本身） |
| 條件因果？ | **有**（不交付就不會感染） |
| 製造法所不容許的風險？ | **有**（未消毒就交付） |
| 風險實現？ | **無**（就算消毒也殺不死→結果不具避免可能性） |

> **過失犯行為要挑對**：不能挑「義務違反」（沒消毒）作為評價對象，否則過失犯永遠變成不作為犯。應挑「交付有細菌的羊毛」這個作為。

**案例二：兒童安全座椅案**
- 家長載幼童未使用安全座椅→途中落石砸死幼童
- 有安全座椅→落石一樣砸死
- 結論：結果不具避免可能性

### 子原則 3：規範保護目的

> 行為人違反規範，但最終結果與立法者制定該規範的目的**無關**。

**案例一：德國腳踏車車燈案**
- A、B晚上騎腳踏車一前一後，都沒開車燈
- 對向卡車司機甲看不到A，跨越雙黃線撞死A
- 有人主張：如果B有開車燈→B的燈會照到A→甲就會看到A→不會撞上
- 結論：B**不負責**

| 規範目的分析 | 說明 |
|-------------|------|
| 要求B開車燈的目的 | **照亮自己**，讓別人不要撞到B |
| 規範目的不是 | 照亮前面的A，保護A不被撞 |
| → 規範保護目的不相關 | B不為A的死亡負責 |

**案例二：紅線違停案（107年律師考試改編）**
- 甲在紅線違停，下車離開
- 腳踏車騎士乙經過甲車旁→自己重心不穩往右摔→頭撞甲車後車廂→顱內出血死亡
- 禁止紅線停車的目的：確保往來者的**通行安全**（如閃車造成事故）
- 而非防止：有人自己摔倒頭撞到車體
- 結論：規範保護目的不相關→甲不負責

**案例三：花蓮颱風人行道違停案（真實事件）**
- 甲颱風天違停在人行道上
- 隔壁公寓頂樓違法磚牆被風吹倒→砸到車後座→老婆被打死
- 禁止人行道停車的目的：確保**行人安全**（行人不用與車爭道）
- 而非防止：車上乘客被墜落物砸死
- 結論：規範保護目的不相關→甲不負責

## 二、第三層：構成要件效力範圍

### （一）被害人自我負責

> 被害人清楚知道危險、精神年齡狀態正常、**自由地**選擇承擔→ 該危險由被害人自己承擔，不歸責給行為人。

**案例**：

| 案例 | 說明 | 結論 |
|------|------|------|
| HIV 案 | 女友明知男友感染HIV，仍進行無套性交 | 被害人自我負責 |
| 計程車案 | 乘客趕時間叫司機開快車，出車禍受傷 | 被害人自我負責 |
| 拒絕輸血案 | 特定教派信徒受傷後拒絕輸血致死 | 被害人自我負責 |

### （二）被害人自我負責的限制

自我負責**不成立**的三種情形：

```
被害人自我負責的前提
│
├── ① 被害人身心狀態正常
│   ├── 非幼童
│   ├── 精神狀況良好
│   └── 心智無缺陷
│   → 反例：家長酒駕載幼兒→幼兒無法自我負責
│
├── ② 被害人清楚認知風險
│   → 反例：叫司機開快車，但司機未告知輪胎胎紋已磨平→乘客不知額外風險
│
└── ③ 被害人自由選擇承擔
    → 反例：被追打→闖平交道→被火車撞死→不是自由選擇
```

**案例：平交道闖車（國考題）**
- 行為人追打被害人→被害人前有火車、後有追打者→冒險闖平交道→被火車撞死
- 被害人闖平交道不是自由選擇，是被逼的
- 結論：**不能**自我負責，行為人仍應負責

### （三）專業人員的負責

> 專業人員（消防員、警察）因執行職務死傷時，結果不歸責給原因行為人。

**案例一：消防員火災殉職**
- 失火→消防員前往滅火→不幸葬身火窟
- 能否歸責給失火的人？→ **不可**

**理由**：
1. 這些專業人員**自由選擇**該職業，且有危險津貼
2. **政策考量**：若消防員死傷歸咎失火者→失火者不敢報案求救→自己滅火→更糟糕

**案例二：警察追通緝犯**
- 通緝犯逃脫→警察追的過程中自己摔死
- 能否歸責給通緝犯？→ **不可**
- 專業人員的負責

## 三、解題實用整理

### 既遂犯 vs 未遂犯的審查順序口訣

| 類型 | 口訣 | 順序 | 原因 |
|------|------|------|------|
| **既遂犯** | 「氣碎飯先客」 | 先客觀、後主觀 | 刑法罰的是壞行為（客觀），不是壞想法 |
| **未遂犯** | 「未碎飯先主」 | 先主觀、後客觀 | 客觀上沒有實現→先討論客觀無意義→先看主觀有無故意 |

### 反常因果歷程案件的結論模式

```
1. 既遂犯標題（結論：不成立）
   → 客觀：有因果、有製造風險、但風險未實現（反常因果）
   → 客觀不可歸責 → 不成立既遂犯

2. 未遂犯標題（結論：成立）
   → 主觀：有故意
   → 客觀：有著手
   → 違法且有責 → 成立未遂犯
```

### 寫題注意事項

1. 標題要**具體特定行為**（不能只寫「甲的行為」）
2. 顯然無爭議的要件→**一句話帶過**（「甲違法且有責」）
3. **不要抄法條**到考卷上（刑法考點通常不是法條本身）
4. 法條引用寫**阿拉伯數字**（不要寫國字）
