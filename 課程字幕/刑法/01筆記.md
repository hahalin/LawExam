# 01 筆記：刑法體系與三階論

## 第一章 刑事法的架構

### 實體法與程序法

- **實體法**：規範犯罪成立要件的法律
- **程序法**：規範追訴程序的法律

### 普通法與特別法

- **普通法**：中華民國刑法（刑法典本身）
- **特別刑法**：毒品危害防制條例、貪汙治罪條例、槍砲彈藥刀械管制條例等
- 考試重點：刑法國考**不用寫特別法**
    - 頂多涉及貪汙治罪條例與刑法有交集的幾個條文（分則會講）
    - 毒品、槍砲、詐欺犯罪防治條例等不考

### 特別刑法 vs 附屬刑法

| | 特別刑法 | 附屬刑法 |
|---|---|---|
| 本質 | 本質是刑法 | 本質非刑法（如商法、保險法） |
| 與普通刑法關係 | 規範事項大多在刑法典中已有規定，再做加強 | 犯罪類型在刑法典中幾乎看不到 |
| 反社會性 | 具有強烈反社會性、反道德性 | 通常不具有強烈反社會性 |
| 不法意識 | 行為人很難主張不知法律 | 行為人有可能真的不知道是犯法的 |
| 例子 | 貪汙治罪條例 | 證券交易法（內線交易）、保險法、民用航空法 |

- 區別的實益：附屬刑法的犯罪類型較容易發生「欠缺不法意識」的情況（與罪責階層的禁止錯誤有關）

## 第二節 刑法的最後手段性

- 又稱：**刑法的謙抑思想**
- 核心概念：不要動不動就用刑罰處罰一切看不慣的社會現象
- 適用層面：**刑事立法**，而非法律解釋

### 刑罰非萬能

- 很多社會現象背後有複雜原因，光加重刑罰沒有用，甚至可能有反效果
    - 例：職業駕駛肇事率高 → 背後原因是疲勞駕駛 → 缺工 → 少子化
    - 加重刑責 → 原本繳罰金的變成要入獄 → 行業人力更少 → 反效果
- 例外：新時代犯罪入罪化或加重有助於建立守法意識（如電腦犯罪）
- **治亂世用重典不可信**：
    1. 現代社會根本不是亂世
    2. 即便是亂世，根本原因也不是刑罰太輕

### 考試注意

- 寫考卷時一般不會用到「刑法最後手段性」
- ❌ 不能說「基於刑法最後手段性，所以採對行為人有利的學說」
    - 法院在法律見解選擇上，沒有義務一定選對行為人最有利的
    - **罪疑惟輕是指事實**不明時對被告有利認定，不適用於法律適用
- ✅ 可以說「採某說會導致處罰範圍不當擴張，基於最後手段性不可採」

## 第三節 刑法總則的意義

- 總則 = 共通的原理原則
- 刑法總則分為四大單元：

| 單元 | 內容 | 重要性 |
|---|---|---|
| 法例 | 整部刑法的操作規則（§1-12） | 如同產品使用說明書 |
| **犯罪論** | 犯罪的成立要件（三階論） | **核心重點**，課程主要內容 |
| 競合論 | 多數犯罪是否都要論罪 | 重要 |
| 刑罰論 | 刑的種類與執行（§32-49, §57-99） | 條文最多，但考試重要性最低 |

- 刑罰論多為法條記憶（易科罰金、假釋、緩刑撤銷等），主要考在**一試選擇題**，且通常不超過三題

---

## 第四節 三階論的操作

> 三階論是整部刑法的骨幹與精髓。

### 三階論架構總覽

```
0. 行為（前提）
1. 構成要件該當性
2. 違法性
3. 罪責
→ 1 + 2 + 3 全部通過 = 犯罪行為
```

### 為什麼需要三階論？

- 刑法中有些規定會「打架」：
    - §354 毀損 → 有罪 vs §18① 未滿14歲 → 不罰
    - §271 殺人 → 有罪 vs §23 正當防衛 → 不罰
- 三階論的功能：為這些有罪/無罪的規定**排出適用順序**

---

### 階層零：行為

- 全名：**刑法上有意義的行為**
- 刑法處罰的是人的行為，不是思想（思想永遠無罪）
- 排除兩類情況：
    1. **非人類行為**：自然力、動物攻擊（例：流浪狗喝掉車中汽油）
    2. **非基於意志的行為**：睡覺翻身、膝蓋反射
- 結論：**人基於意識所做的** → 才叫行為

---

### 階層一：構成要件該當性

- 判斷行為有沒有符合刑法分則的規定

#### 客觀構成要件（最多六格）

| 要素 | 說明 | 例（殺人罪） |
|---|---|---|
| 1. 主體 | 做行為的人 | 殺人的人 |
| 2. 行為 | 該條罪處罰的動作 | 殺 |
| 3. 客體 | 行為攻擊的對象 | 行為人以外的自然人 |
| 4. 結果 | 是否要求特定外界變動 | 人死亡 |
| 5. 因果關係 | 行為與結果之間的聯繫 | 死亡是否由殺的行為造成 |
| 6. 情狀 | 犯罪成立的特定情境 | 殺人罪無此要求 |

- 所有犯罪一定有的：**主體 + 行為**
- 有結果 → 一定有因果關係；無結果 → 無因果關係
- 客觀要件有些是條文明文規定，有些是學理解釋（啟示）而來

#### 條文示例

| 條文 | 客觀要素 | 備註 |
|---|---|---|
| §271 殺人罪 | 主體、行為、客體、結果、因果 | 無情狀 |
| §309 公然侮辱 | 主體、行為、客體、情狀（公然） | 無結果、無因果 |
| §237 重婚罪 | 主體、行為 | 僅有前兩格 |

#### 重要觀念

- 刑法分則各罪都是**假設語態**：「殺人者」= 如果有人殺人的話
- 正確用語：「該當」殺人罪、「成立」殺人罪、「構成」殺人罪
- ❌ 不能說「違反」殺人罪（違反殺人罪 = 沒有殺人）
- **胎兒不是人**：故意使孕婦流產 → 不該當殺人罪（客體欠缺），該當墮胎罪（§291）

#### 主觀構成要件：故意

- **故意 = 認知 + 意欲**
    - 行為人對客觀上所做的事有認知（知道自己在幹嘛）
    - 行為人對客觀上所做的事有意欲（想要它發生）
- 動機正不正當 → 與故意無關，是**違法性**的問題

#### 客觀 × 主觀 排列組合

| 客觀 | 主觀 | 效果 | 說明 |
|---|---|---|---|
| ✓ | ✓ | **故意既遂** | 客觀全實現 + 有故意 |
| ✓ | ✗ | **阻卻故意** → 可能改論過失 | 客觀實現但無故意（如誤拿他人雨傘、獵山豬打到人） |
| ✗ | ✓ | **未遂** | 客觀未全實現但有故意（如殺人未死、偷東西被制止） |

##### 阻卻故意後改論過失的前提

1. 該條罪有罰過失
2. 行為人確實有過失

> 例：誤拿他人雨傘 → 過失竊盜 → 竊盜罪不罰過失 → 無罪
> 例：獵山豬打到戴山豬頭套的人 → 行為人可能無過失 → 無罪

##### 未遂犯的觀念澄清

- **未遂 ≠ 僅限結果未發生**
- 客觀構成要件有**任何一個**未實現 + 行為人主觀以為應全部實現 → 都是未遂
- 未遂的類型：
    1. 結果未發生（殺人但人沒死）
    2. 客體不存在（砍已死之人的屍體 → 殺人未遂）
    3. 客體根本不存在（拿東西以為是別人的其實是自己的 → 竊盜未遂）
    4. 主體欠缺（已被開除之業務經理簽出賣公司的契約 → 背信未遂）
    5. 情狀欠缺（踹女子肚子想使其流產，該女其實未懷孕 → 墮胎未遂）
- 未遂犯的處罰也是例外，須法有明文
    - 傷害罪不罰未遂、毀損罪不罰未遂 → 構成未遂但無罪

---

### 階層二：違法性

- 構成要件該當 → **推定違法**（經驗上符合刑法規定的行為通常不正當）
- 違法性看的是：這個行為**正當或不正當**

#### 阻卻違法事由（四大條文 + 超法規）

| 條文 | 名稱 | 例子 |
|---|---|---|
| §21① | 依法令行為 | 法警依法槍斃死刑犯 |
| §21② | 公務員依上級命令行為 | 建管機關拆除違章建築 |
| §22 | 業務上正當行為 | 記者臥底黑心食品工廠用密錄器 |
| §23 | 正當防衛 | 被歹徒攻擊而反擊 |
| §24 | 緊急避難 | 被山豬追趕而翻牆進入他人庭院 |
| 超法規 | 被害人承諾 | 同意刺青（承諾傷害） |

- 正當防衛：對**攻擊者**（合法無需向不法低頭）
- 緊急避難：通常對**無辜的人**（犧牲無辜者利益以保全自己或他人）

#### 阻卻違法事由的結構

- 三大要件：
    1. **前提事實**（如正當防衛：現在不法之侵害）
    2. **手段適當**
    3. **主觀認知**（行為人知道自己在防衛/避難）
- 三者都符合 → 阻卻違法

#### 阻卻違法的排列組合

| 前提事實 | 手段 | 主觀認知 | 效果 | 名稱 |
|---|---|---|---|---|
| ✓ | 適當 | ✓ | 阻卻違法 | 正當防衛/緊急避難等 |
| ✓ | **不適當** | ✓ | **不阻卻違法**，可減免刑 | **過當**（防衛過當/避難過當） |
| **✗** | - | ✓ | 通說改論過失 | **容許構成要件錯誤**（誤想系列） |
| ✓ | 適當 | **✗** | 不阻卻違法，原罪論處 | **反面容許構成要件錯誤**（偶然系列） |

##### 過當

- **所有阻卻違法事由都會過當**，不只§23、§24
- §23、§24 有明文規定過當可減免其刑（因屬緊急情況，值得同情）
- §21、§22 過當無特別減免規定（非緊急情況，不值得同情）

##### 容許構成要件錯誤（誤想系列）

- 客觀上不存在阻卻違法前提事實，行為人主觀上誤以為存在
- 例：以為對方要襲胸而先踹一腳，實際對方只想打招呼
- 例：刺青師誤以為外國人要刺Taiwan number one在臉上
- 通說效果：**改論過失犯**
- 名詞解釋：容許構成要件 = 阻卻違法事由（德文翻譯）；禁止構成要件 = 刑法分則各罪

##### 反面容許構成要件錯誤（偶然系列）

- 客觀上存在阻卻違法前提事實，行為人主觀上不知道
- 例：出於毀損故意砸仇人窗戶，意外救了瓦斯漏氣的仇人（偶然避難）
- 例：司馬光可能只是想打破水缸，不知道裡面有溺水的小朋友
- 通說效果：**無效果，原罪論處**

---

### 階層三：罪責

- 看這個人**值不值得被譴責**
- 構成要件 + 違法性 = 對**事**（有沒有做錯事）
- 罪責 = 對**人**（做錯事的人壞不壞）
- 做壞事 ≠ 這個人很壞（二者是可分的）

#### 阻卻/減免罪責事由

| 事由 | 說明 | 例子 |
|---|---|---|
| 責任能力欠缺 | 未滿14歲、精神障礙、心智缺陷 | 思覺失調症患者毀損他人財物 |
| 欠缺不法意識 | 不知道是犯法的 | 附屬刑法的犯罪（如非保險業經營類似保險） |
| 欠缺期待可能性 | 面臨艱難處境，幾乎別無選擇 | 癩馬脫韁案（馬車夫明知馬有問題但無法辭職） |
| 其他罪責要素 | 防衛過當/避難過當的減免其刑 | 與期待可能性有關（緊急狀態下心理混亂） |

> **期待可能性**：法律不可能要求行為人去做聖人。若行為人面臨的處境使他幾乎別無選擇，則否定罪責。

---

### 三階論的效果總結

| 通過的階層 | 稱呼 | 說明 |
|---|---|---|
| 1 + 2 + 3 | **犯罪行為** | 構成要件該當、違法且有責 |
| 1 + 2 | **違法行為** | 如精神病患、幼童損壞財產 |
| 僅 1 | **構成要件該當行為** | 如正當防衛殺人（該當但阻卻違法） |

### 考試審查注意

- 三階論是**逐階審查**的：
    - 構成要件不該當 → 不用再寫違法性與罪責
    - 違法性阻卻 → 不用再寫罪責
- 犯罪 ≠ 違法（刑法中犯罪必須 1+2+3；違法只需 1+2）
