## 📋 實務見解速查

> **99年第5次刑事庭決議**（接續犯定義）：行為人主觀上基於單一犯意，以數個舉動接續進行，侵害同一法益，在時空上具有密切關係，依社會健全觀念難以強行分開者，視為一行為，論以一罪。

> **99年第5次決議**（投票行賄罪數）：多次投票行賄，符合接續犯要件者論一罪，不符合則數罪併罰。實務不採集合犯說。

> **106年判決**（231相續幫助犯）：馬伕於引誘容留媒介既遂後、性交易終了前加入，基於幫助犯意接送應召女，成立幫助犯。實務對相續幫助犯採**肯定說**。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「競合論處理哪兩大問題？」 | ①**論罪**（哪些罪要論、哪些可不論）②**科刑**（數罪刑罰如何結合） |
| 「想像競合從一重處斷＝只論重罪？」 | **錯**！想像競合是純正競合，**數罪都要論**，只是用重罪刑度科刑 |
| 「不純正競合（假性競合）的效果？」 | 只論**其中一罪**，其餘不論（但不一定是最重的罪） |
| 「行為數認定的關鍵基準？」 | **主觀犯意個數**為關鍵；複數犯意→百分百數行為 |
| 「鄭捷案（自然行為單數 vs 高度專屬法益）？」 | 侵害生命法益→例外認定**數行為**（但許澤天認為宣示＞實質） |
| 「接續犯 vs 自然行為單數差在哪？」 | 接續犯多要求**侵害同一法益** |
| 「偽造貨幣是不是集合犯？」 | **是**（反覆施行為常態，且無常業犯加重規定） |
| 「竊盜/強制性交是不是集合犯？」 | **不是**（反覆犯是行為人心理問題，非犯罪本質） |
| 「投票行賄如何論罪？」 | 學說：集合犯→一罪；實務：接續犯→符合要件一罪/不符合數罪併罰 |
| 「231引誘容留媒介是集合犯嗎？」 | 學說（許澤天）：是；**實務：不是**（曾有常業犯規定→立法者不認為反覆施行） |
| 「選擇題出現牽連犯/連續犯/常業犯？」 | **絕對不選**！三者均已於2006年7月1日刪除 |
| 「繼續犯短暫中斷，行為數是否中斷？」 | **不中斷**（犯意未消滅→仍同一行為） |
| 「哪兩類犯罪最容易考競合？」 | **交通犯罪**（酒駕肇逃）＋**偽造文書犯罪**（偽造→行使→詐欺） |

## 正文

### 一、競合論概述

#### 1. 競合論處理的兩大問題

```
競合論
│
├── ① 論罪層次：哪些罪要論？哪些可以捨棄？
│   ├── 禁止重複評價（一隻豬不能剝兩層皮）
│   │   └── 例：殺人既遂 → 不再另論傷害既遂/重傷既遂
│   └── 禁止評價不足（不該丟的罪不可以亂丟）
│       └── 例：行使偽造私文書＋詐欺 → 兩罪都要論
│
└── ② 科刑層次：數罪刑罰如何結合？
    ├── 不能單純累加（偷100次竊盜＝600月＝50年→比殺人還重）
    └── 也不能全部執行（死刑＋無期→怎麼一起執行？）
```

#### 2. 競合論體系圖

```
                     競合論
                       │
          ┌────────────┴────────────┐
     不純正競合                  純正競合
    （假性競合）              （數罪都要論）
   只論其中一罪               每條都要論
          │                        │
    ┌─────┼─────┐            ┌─────┴─────┐
  法條   不法   不法        想像        實質
  競合   前行為 後行為      競合        競合
                          §55        §50
                       從一重處斷    數罪併罰
```

#### 3. 純正 vs 不純正競合

| 比較項目 | 不純正競合（假性競合） | 純正競合 |
|---------|-------------------|---------|
| 定義 | 數罪同時成立是假象，只論其中一罪 | 數罪都要論，無可捨棄 |
| 最後論罪 | **一罪** | **數罪** |
| 選哪一罪 | 不一定是最重的（無「重罪優於輕罪」法理） | 每條都論 |
| 類型 | 法條競合、不法前行為、不法後行為 | 想像競合、實質競合 |
| 科刑 | 以該一罪科刑 | 想像競合→從一重處斷；實質競合→數罪併罰 |

> ⚠️ **重要提醒**：想像競合「從一重處斷」≠只論重罪！考試寫「因想像競合從一重處斷，因此只論較重之某某罪」→**錯誤**！多寫反而扣分。

> ⚠️ **實務批判**：實務說不純正競合「論最重的」、掰出「重罪優於輕罪」法理→學理上不存在此法理。刑法考試以學者見解為準。

### 二、行為數認定

#### 1. 判斷基準

```
行為數認定
│
├── 客觀基準：動作數量 ＋ 時空密接性
│   └── 但客觀切割永遠沒完沒了（向後轉＝一個or三個動作？）
│
└── 主觀基準：犯意個數 ← ★關鍵基準★
    ├── 一個犯意 → 不見得一行為（還要看客觀）
    └── 複數犯意 → 百分百數行為（無例外）
```

> **黃榮堅老師見解**：行為數一定從主觀犯意去切，不可能從客觀動作數認定。因為客觀動作永遠可以無限切割。

#### 2. 行為單數的類型

```
行為單數
│
├── (1) 單純行為單數：一犯意＋一動作（丟手榴彈炸死兩人）
│
├── (2) 自然行為單數：一犯意＋數動作＋時空密接
│   ├── 反覆性：重複做同一件事（一分鐘揍5拳→一次攻擊）
│   ├── 相續性：拆分成多次做（每天下毒→一個殺人行為）
│   └── ⚠️ 例外：高度專屬法益（生命）→ 變數行為
│       └── 鄭捷案：單一犯意時空密接但侵害生命→數行為
│
├── (3) 法的行為單數（法律擬制為一行為）
│   ├── 複行為犯：強盜＝強取＋竊盜（§328＝§304＋§320）
│   ├── 繼續犯：既遂後法益侵害持續（私行拘禁/酒駕/持有犯罪）
│   │   └── 短暫中斷不切斷行為（酒駕中途下車上廁所→仍同一行為）
│   ├── 構成要件選擇要素：實現多個選擇要素→仍一行為
│   │   └── 例：恐嚇身體＋自由＋名譽＋財產→仍一個恐嚇行為
│   └── ★ 集合犯（最重要）
│
└── (4) 特殊犯罪的行為單數
    ├── 過失犯：看有無機會再次履行注意義務
    └── 不作為犯：看作為誡命出現幾次
```

### 三、接續犯（實務概念）

#### 接續犯 vs 自然行為單數

| 要件 | 自然行為單數 | 接續犯 |
|------|------------|--------|
| 單一犯意 | ✓ | ✓ |
| 數個身體動作 | ✓ | ✓ |
| 時空密接 | ✓ | ✓ |
| 侵害同一法益 | × 不要求 | ✓ **要求** |

> **結論**：接續犯 ≈ 自然行為單數（高度類似但不完全一樣）

#### 差異案例：夜市小偷

- 30秒內先偷小販A的錢→再偷觀光客B的皮夾
- **自然行為單數**→一行為（單一犯意＋時空密接）
- **接續犯**→不是（侵害兩個人的法益，不符合「同一法益」）
- 但最後論罪結論差不多

### 四、集合犯（行為數中最重要）

#### 1. 定義

犯罪類型**本質上**以反覆施行為常態→數次行為視為一行為

> ⚠️ 區別：犯罪本質反覆（集合犯）≠ 行為人犯罪癖好（非集合犯）

#### 2. 典型集合犯

| 犯罪類型 | 為何是集合犯 |
|---------|------------|
| 蒐集犯罪（蒐集國防秘密） | 蒐集本身就是反覆歸於己有 |
| **偽造貨幣** | 設備昂貴，不會只做一次（且無常業犯規定） |
| 使人為奴隸 | 囚禁他人持續奴役→反覆性 |
| 散佈犯罪 | 散佈＝反覆向多數人發放 |

#### 3. 非集合犯（行為人癖好≠犯罪本質）

| 犯罪類型 | 理由 |
|---------|------|
| 竊盜（內衣大盜） | 竊盜本質非反覆施行，是行為人心理問題 |
| 強制性交/猥褻（某某之狼） | 性犯罪非反覆施行為常態 |

#### 4. 判斷技巧：常業犯反推法

```
某罪曾有「常業犯」加重規定
    ↓
代表立法者不認為此罪以反覆施行為常態
    ↓
→ 不是集合犯

某罪從無「常業犯」加重規定
    ↓
可能因為犯罪本質就是反覆
    ↓
→ 可能是集合犯（如偽造貨幣）
```

#### 5. 爭議類型

##### (1) 投票行賄

| 見解 | 結論 | 理由 |
|------|------|------|
| **學說** | 集合犯→一罪 | 買票本質就是反覆做 |
| **實務**（99年第5次決議） | 接續犯 | 不採集合犯說 |

> **兩說差異有限**：
> - 一天跟20人買票→兩說均論**一罪**
> - 分別起意各買一票→兩說均論**數罪**
> - 唯一差異：單一犯意但時空不密接→集合犯一罪/接續犯數罪（但此案例實際上不太會發生）

##### (2) 吸毒

- **學說**：應為集合犯（毒品成癮→反覆施行）
- **實務**：接續犯（一晚用兩次→一罪；時空不密接→數罪併罰）

##### (3) §231 引誘容留媒介性交猥褻

| 見解 | 結論 | 理由 |
|------|------|------|
| 學說（許澤天） | 集合犯 | 營利犯罪本質反覆 |
| **實務** | **非集合犯** | 曾有常業犯規定→立法者認為非反覆施行為常態 |

> ⚠️ **選擇題地雷**：牽連犯、連續犯、常業犯三者均於 2006/7/1 刪除→**絕對不選**

### 五、特殊犯罪的行為單數

#### 1. 過失犯

```
過失犯行為數
│
├── 結果只出現一次 → 一行為
│
└── 結果出現多次
    ├── 行為人無法再履行注意義務（車子失控）→ 仍一行為
    │   例：超速打滑先撞A再撞B → 一行為
    └── 行為人有機會再履行注意義務 → 第二個行為
        例：車回正後緊張逃跑又撞C → 第二行為
```

#### 2. 不作為犯：看作為誡命出現次數

**案例：醫師不作為詐欺**
- 醫師簽名表示不外開業→每月領不開業獎金3萬
- 實際上已在外兼職一年（12個月）
- 每月發獎金前都有機會告知但未告知→**12個作為誡命→12罪**（數罪併罰）

### 六、§231 相續幫助犯（馬伕案）

```
231 犯罪時間軸
│
├── 應召站散播訊息 → 男客上鉤 → 談妥性交易契約
│   └── 此時 §231 已「既遂」（引誘容留媒介完成）
│
├── 馬伕加入（既遂後、終了前）
│   └── 接送應召女往返旅館
│   └── → 相續幫助犯（肯定說）
│
└── 完成性交易並取得對價  → 犯罪「終了」
```

> **實務見解**：馬伕於既遂後終了前加入，基於幫助犯意參與構成要件以外行為（接送），成立**幫助犯**，不是事後幫助。
