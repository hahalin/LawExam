## 📖 法條原文速查

> **§55**（想像競合）
> 一行為而觸犯數罪名者，從一重處斷。但不得科以較輕罪名所定最輕本刑以下之刑。

> **§51 第五款**（數罪併罰之執行刑）
> 宣告多數有期徒刑者，於各刑中之最長期以上，各刑合併之刑期以下，定其刑期。但不得逾三十年。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「什麼是夾結效果？」 | 繼續犯上疊兩個以上**時間不重疊**的狀態犯，用繼續犯把它們夾在一起→想像競合 |
| 「夾結 vs 部分合致？」 | 部分合致：兩罪時間重疊；夾結：兩狀態犯時間**不重疊**，靠繼續犯串聯 |
| 「繼續犯上疊兩個時間重疊的狀態犯？」 | 那是**部分合致**，不是夾結！（如侵入住宅期間同時性交+傷害） |
| 「可否用輕罪去夾重罪？」 | **不可以**（否則多犯輕罪反而讓重罪享想像競合優待） |
| 「不能夾怎麼辦？」 | **去夾結**問題，有甲乙丙丁四說 |
| 「實務採去夾結哪一說？」 | **乙說**：第一次狀態犯+繼續犯想像競合，再與其餘數罪併罰 |

## 一、夾結效果

### 定義

一個**繼續犯**上面，有兩個以上**時間沒有重疊**的狀態犯。這些狀態犯各自與繼續犯有實行行為部分合致的關係，因此可被繼續犯「夾」在一起，全部想像競合。

### 圖示

```
持槍（繼續犯）───────────────────────→
        │              │
    毀損A車          毀損B鐵門
   （狀態犯①）       （狀態犯②）
   
→ 毀損①②時間不重疊，但都跟持槍重疊
→ 用持槍把兩個毀損「夾」起來
→ 三罪想像競合，從一重處斷
```

### 夾結 vs 部分合致 的區別

| | 部分合致 | 夾結 |
|------|---------|------|
| 繼續犯上的狀態犯 | 1 個，或多個但**時間重疊** | 2 個以上且**時間不重疊** |
| 例 | 侵入住宅期間同時性交+傳染性病 | 持槍期間先毀A車再毀B門 |

### 易錯辨識

**題目（69 頁第 10 題）**：侵入住居 + 趁機性交 + 故意傳染性病

- 繼續犯（侵入住居）上疊兩個狀態犯（性交、傷害）
- 但性交與傷害的**時間完全重疊** → **部分合致**，不是夾結！
- 不要機械記憶「疊兩個＝夾結」

### 精確定義

夾結 = 一個繼續犯上疊的兩個以上**時間沒有重疊**的狀態犯

## 二、去夾結

### 前提：不能用輕罪夾重罪

```
持槍（繼續犯，較輕）───────────────→
        │              │
    殺人A            殺人B
   （狀態犯，重罪）    （狀態犯，重罪）
   
→ 原本兩個殺人要數罪併罰
→ 若用持槍夾起來→三罪想像競合→反而更輕？
→ 不合理！多犯一個輕罪反而獲得優待
→ 不能用輕罪夾重罪
```

### 去夾結 = 不能夾時怎麼競合

典型案例：**詐騙集團車手**
- 參與犯罪組織（繼續犯，較輕）
- 取款 8 次 = 8 個加重詐欺罪（狀態犯，較重）
- 不能用參與犯罪組織去夾 8 個詐欺

### 四種學說

#### 甲說：分級理論（傳統學說通說）

**做法**：切八段

```
參與犯罪組織────────────────────→
 ┆  ┆  ┆  ┆  ┆  ┆  ┆  ┆
詐①詐②詐③詐④詐⑤詐⑥詐⑦詐⑧

→ 每段：參與犯罪組織片段 + 詐欺 → 想像競合
→ 8 個想像競合結果 → 數罪併罰定執行刑
```

**缺點**：繼續犯只有一個，卻被評價了 **8 次**（過度評價）

#### 乙說：實務見解（目前實務採此說）

**做法**：第一次 + 繼續犯想像競合，其餘數罪併罰

```
參與犯罪組織────────────────────→
 ┆
詐① ← 跟繼續犯想像競合
   詐②詐③詐④詐⑤詐⑥詐⑦詐⑧ ← 與前者數罪併罰
```

**優點**：避免繼續犯被重複評價
**質疑**：第 2～8 次詐欺也跟繼續犯有部分合致關係，為何不能想像競合？

#### 丙說：雅各布斯教授（蔡聖偉老師支持）

**做法**：先定狀態犯的執行刑範圍，再用該範圍與繼續犯想像競合

```
步驟一：8 個加重詐欺 → §51 定執行刑範圍
   各罪宣告刑都是 1 年 → 範圍：1 年以上 ~ 8 年以下

步驟二：把此範圍視為「虛擬罪名」
   → 與參與犯罪組織罪想像競合，從一重處斷
```

**優點**：規避甲乙兩說的缺點，兼顧公平

#### 丁說：無需去夾結（許澤天老師）

**做法**：就讓它夾，不當優待的問題用**量刑加重**解決

- 殺人本來就可以判死刑/無期，用何種競合方式結論差不多
- 不需要那麼複雜的去夾結操作

### 考試建議

- **一試選擇題**：選**乙說**（實務見解）
- **二試申論**：可寫乙說（實務）後，附帶提丙說作為有力學說

## 三、數罪併罰基本概念（附帶說明）

### 三個刑的概念

| 概念 | 說明 | 例子 |
|------|------|------|
| **法定刑** | 條文直接規定的法律效果 | 殺人罪：死刑/無期/10 年以上 |
| **宣告刑** | 法院在個案中所為的刑之宣告 | 殺人罪處有期徒刑 15 年 |
| **執行刑** | 被告最後實際受執行的刑 | 經 §51 定出的刑 |

- 單純一罪：宣告刑 = 執行刑
- 數罪：各罪分別宣告刑 → §51 定執行刑

### §51 第五款的操作

多數有期徒刑：**最長期以上** ~ **合併刑期以下**（上限 30 年）

```
偷A：3月  偷B：4月  偷C：5月
→ 執行刑範圍：5月以上 ~ 12月以下
→ 法院定刑如 8 月 → 合法
```

### 重要觀念

- 各罪有各自獨立的刑罰權
- 不能因為犯數罪就直接重判 → 要各罪分別宣告後再定執行刑
- 「殺三個人就該判死刑」→ 法律上不是這樣認定的，要各罪分別論
