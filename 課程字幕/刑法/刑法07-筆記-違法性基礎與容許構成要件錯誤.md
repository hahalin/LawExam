## 📖 法條原文速查

> **§16**（法律之不知）
> 除有正當理由而**無法避免**者外，不得因**不知法律**而免除刑事責任。但按其情節，得減輕其刑。

> **§23**（正當防衛）
> 對於現在不法之侵害，而出於防衛自己或他人權利之行為，不罰。但防衛行為過當者，得減輕或免除其刑。

> **§24**（緊急避難）
> 因避免自己或他人生命、身體、自由、財產之緊急危難而出於不得已之行為，不罰。但避難行為過當者，得減輕或免除其刑。

> **§55**（想像競合）
> 一行為而觸犯數罪名者，從一重處斷。

> **民法 §151**（自助行為）
> 為保護自己權利，對於他人之自由或財產施以拘束、押收或毀損者，不負損害賠償之責。但以不及受法院或其他有關機關援助，並非於其時為之，則請求權不得實行或其實行顯有困難者為限。

## 📋 實務見解速查

> **74 臺上 4225 判例**：關於「實質違法性」之論述。實際內容論述的是可罰的違法性概念（行為輕微 + 法益侵害輕微），但用語為「欠缺實質違法性」而非「欠缺可罰的違法性」→ 掛羊頭賣狗肉。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「欠缺可罰違法性需具備哪些條件？」 | **兩個都要輕**：①行為本身輕微 ②法益侵害結果輕微 |
| 「拿刀威脅取得一張白紙，可否主張欠缺可罰違法性？」 | **不可以**：行為（加重強盜）不輕微，不符合要件 |
| 「可罰違法性與實質違法性有何不同？」 | 實質違法性＝行為本身不違反社會通念；可罰違法性＝行為不OK但法益侵害量太少 |
| 「違法與不法有何區別？」（德國學說立場） | **違法**＝有跟沒有（二分法）；**不法**＝有程度高低（民事→行政→刑事） |
| 「超法規阻卻違法事由是否違反罪刑法定？」 | **不違反**：多一種阻卻違法事由 = 多一條無罪空間，對行為人有利 |
| 「容許構成要件錯誤的通說效果？」 | 多數說：**阻卻故意，視情況改論過失犯**；僅嚴格罪責理論用§16處理 |
| 「誤想防衛是否為不法意識的欠缺？」 | **否**（限制法律效果罪責理論/二階論）：行為人是**對事實誤認**，非對法規範誤解，不符§16 |
| 「對應原理在違法性是否適用？」 | **不適用**（蔡聖偉採累加理論）：阻卻違法事由無需主客觀對應 |

## 一、違法性基礎概念

### 推定違法

- 構成要件該當 → **推定違法**
- 理由：經驗上，符合刑法分則構成要件的行為，絕大多數為不正當行為（100件中僅1~2件正當）

### 阻卻違法事由的來源

```
阻卻違法事由
│
├── 法規阻卻違法事由（法律明文規定）
│   例：§23 正當防衛、§24 緊急避難、§21 依法令行為
│
└── 超法規阻卻違法事由（法律未規定，事理上承認）
    → 不違反罪刑法定（對行為人有利）
```

### 阻卻違法事由的三格審查

```
┌───────────┬───────────┬───────────┐
│ 前提事實   │ 手段適當   │ 主觀認知   │
│（客觀）    │（客觀）    │（主觀）    │
├───────────┼───────────┼───────────┤
│ ✓ 有      │ ✓ 適當    │ ✓ 有認知   │ → 阻卻違法
│ 任一 ✗    │           │           │ → 不阻卻違法
└───────────┴───────────┴───────────┘
```

## 二、可罰的違法性

### 爭議核心：違法性有無程度高低？

#### （一）日本學說：肯定（欠缺可罰的違法性）

**兩個條件都要輕微**：
1. **行為本身**輕微（與社會相當的程度）
2. **法益侵害結果**輕微

→ 兩者皆輕 → 欠缺可罰的違法性 → **不成立犯罪**

| 案例 | 行為輕微？ | 法益侵害輕微？ | 可罰違法性？ |
|------|-----------|--------------|------------|
| 偷吃一顆荔枝 | ✓ | ✓ | 欠缺 → 無罪 |
| 偷用一點水洗手 | ✓ | ✓ | 欠缺 → 無罪 |
| 亮刀威脅取一張白紙 | ✗（加重強盜） | ✓ | **不可主張** |

> 東吳轉學考考題：甲未經同意從機車行水龍頭取水，用一小撮洗衣粉洗手 → 欠缺可罰的違法性

#### （二）德國學說 / 林山田立場：否定

- **違法**：有跟沒有的問題（二分法），不存在「有一點違法」
- **不法**：才有程度高低（民事不法 < 行政不法 < 刑事不法）
- 可罰違法性理論**混淆了違法與不法**的概念
- 法益侵害量低的行為 → 犯罪仍成立，但量刑/程序處理（罰金、緩起訴）

#### 實務問題

- 74 臺上 4225 判例使用「實質違法性」用語
- 實際內容 = 可罰的違法性
- 學者批評：**掛羊頭賣狗肉**（實質違法性 ≠ 可罰違法性）

## 三、阻卻違法事由的主客觀合致

### 客觀欠缺 + 主觀具備 → 容許構成要件錯誤（誤想防衛）

- 例：以為路人要猥褻我，踹了一腳 → 實際路人只是提醒揹包拉鏈
- 客觀：無現在不法侵害 ✗ / 主觀：以為有侵害 ✓

### 客觀具備 + 主觀欠缺 → 偶然避難（反面容許構成要件錯誤）

- 例：基於報復砸仇人窗戶 → 實際仇人家瓦斯漏氣，砸窗反而救命
- 客觀：生命危險確實存在 ✓ / 主觀：對危險一無所知 ✗

## 四、對應原理在違法性的適用

### 問題

客觀實現 A 阻卻違法事由，主觀出於 B 阻卻違法事由，可否阻卻違法？

### 案例（蔡聖偉文章 / 北大刑法組考題）

- A 從國外帶回新型手機，在圖書館被偷
- 數天後見到 B 拿同樣手機，誤以為是自己的手機
- A 上前攔住 B（客觀：§23 正當防衛的前提可能存在；主觀：以為在做民法§151 自助行為）

### 兩說

| 學說 | 立場 | 結論 |
|------|------|------|
| **連接理論** | 需要對應 | A客觀 + B主觀 → 不可阻卻違法 |
| **累加理論** ✅（蔡聖偉） | 不需要對應 | A客觀 + B主觀 → 可以阻卻違法 |

### 理由（黑咖啡哲學例子）

- 在無阻卻違法事由時，行為人只需認知「行為不正當」即可
- 不可能要求行為人認知到**什麼樣的「沒有」**→ 如同黑咖啡不加鮮奶油 vs 不加熱牛奶→意思相同
- 違法性判斷的本質 = 反面判斷 → 不適用對應原理

## 五、容許構成要件錯誤五說

### 總覽

| 學說 | 搭配體系 | 核心主張 | 效果 |
|------|---------|---------|------|
| ① **故意理論** | 古典犯罪體系 | 欠缺不法意識 → 阻卻故意 | 阻卻故意 |
| ② **嚴格罪責理論** | 現代三階論 | 欠缺不法意識 → 依§16處理 | 可避免→減輕；不可避免→無罪 |
| ③ **限制罪責理論** | 現代三階論（德國） | 類推適用構成要件錯誤（德§16 I） | 阻卻故意 |
| ④ **限制法律效果罪責理論** ✅ | 現代三階論（我國通說） | 欠缺罪責故意（良知非難） | 阻卻故意 |
| ⑤ **二階論/負面構成要件理論** | 二階犯罪體系 | 不法故意未完整認識 | 阻卻故意 |

### （一）故意理論（古典犯罪體系）

**背景**：100年前的三階論中，故意在**罪責**層判斷，且故意須認識**不法意識**

```
古典三階論：           現代三階論：
構成要件（全客觀）     構成要件（客觀+主觀＝故意）
違法性（全客觀）       違法性（客觀+主觀）
罪責（故意+不法意識）   罪責（責任能力+不法意識+期待可能）
```

- 誤想防衛 → 行為人以為行為合法 → 欠缺不法意識 → 阻卻故意 → 無故意犯罪

### （二）嚴格罪責理論

- 同樣認為是**不法意識欠缺**
- 但在現代三階論下，不法意識是純粹的罪責要素（§16），不再能阻卻故意
- 效果：依§16處理 → 可避免：減輕其刑 / 不可避免：免除刑事責任

> ⚠️ 嚴格罪責理論是五說中**唯一不阻卻故意**的學說

### （三）限制罪責理論（德國流行，我國水土不服）

- 容許構成要件錯誤 = 對**事實**的誤認（非法規範誤解）
- 與構成要件錯誤很像 → **類推適用**構成要件錯誤 → 阻卻故意
- **問題**：類推適用的對象是**德國刑法§16 I**，我國無對應法條
- 我國講構成要件錯誤阻卻故意時，並未援引特定法條 → **類推適用什麼？**→ 水土不服

### （四）限制法律效果的罪責理論（我國通說）✅

提出**罪責故意**概念：

```
罪責故意 = 良知非難
       = 行為人有沒有想跟法律敵對的意思

一般案例：無故揍人 → 構成要件故意 ✓ + 罪責故意 ✓
誤想防衛：以為在防衛 → 構成要件故意 ✓ + 罪責故意 ✗（良知不值得被譴責）
→ 欠缺罪責故意 → 阻卻故意 → 視情況改論過失犯
```

> 批評：罪責故意是為容許構成要件錯誤**量身打造**的概念，無其他適用場景

### （五）二階論 / 負面構成要件理論

**二階論基本架構**：構成要件 + 違法性 = 合併為同一階「不法」

```
二階論的故意須認識：
① 正面不法事實（行為、結果、因果、歸責）
② 無阻卻違法事由（負面不法事實）

誤想防衛：
客觀正面不法 ✓ / 客觀負面不法 ✓（確實無正當防衛情境）
主觀正面認識 ✓ / 主觀負面認識 ✗（以為在防衛）
→ 主觀不完整 → 阻卻故意
```

- **優勢**：不需要額外發明學說，體系內即可得出正確結論
- 代表學者：黃榮堅老師

### 解題記憶口訣

- **多數說**：阻卻故意，視情況改論過失犯
- **唯一例外**：嚴格罪責理論 → 用§16處理（可避免減輕/不可避免免除）

### 誤想防衛過當

- 通說：可類推適用/適用防衛過當（§23但書）、避難過當（§24但書）之減免規定

## 六、§16 之正確適用

### 不法意識欠缺 vs 事實誤認

| | 不法意識欠缺（§16） | 容許構成要件錯誤 |
|---|---|---|
| 誤認對象 | **法規範** | **事實** |
| 例子 | 外國人不知台灣禁止吸毒 | 以為路人要攻擊我 |
| 行為人認知 | 不知行為違法 | 知道行為是什麼，但誤認情境 |
| 適用法條 | §16 | 非§16（對事實誤認，非不知法律） |
