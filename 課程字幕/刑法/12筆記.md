# 刑法第十二講筆記

## 不能未遂考題練習

### §225 趁機性交罪案例

- 案例：甲發現被害人倒臥路旁，上前欲性交，但其實**被害人已經死亡**
- 分析：
  - 甲的行為屬於**客體不能**（對屍體無法成立性交罪）
  - 不能未遂放在**三階之外**（通說）→ 不罰
- 三說操作練習：
  - **客觀危險說**：事後以科學因果法則判斷，對屍體不可能完成性交罪 → 不能未遂 → 不罰
  - **具體危險說**：以行為時一般人觀點，倒臥路旁者有可能未死 → 可能有危險 → 普通未遂
  - **重大無知說**：一般人能否辨認？看具體情況判斷

### 不能未遂操作重點

- 只有在**各說結論不同**時，才需要並列各說討論
- 如果各說結論一致，擇一說操作即可
- 重點在於正確判斷是「**客體不能**」還是「**手段不能**」

### 花生牛奶案（警特四等）

- 案例：甲教唆乙用花生牛奶毒殺丙（以為丙對花生過敏），但丙其實不會過敏
- 正犯乙 → **不能未遂**（手段不能，花生牛奶無法毒殺）
- **共犯問題**：
  - 不能未遂放三階之外 → 正犯行為至少「該當且違法」→ 共犯**可以從屬**
  - 但即使可從屬，仍需檢驗**共犯自身的行為是否也構成不能未遂**
  - 共犯（教唆犯）自己的行為也是基於「花生牛奶能殺人」的錯誤認知 → 共犯行為本身也是不能未遂 → **共犯仍然無罪**
- 結論：正犯不能未遂 + 共犯自身行為也是不能未遂 → 全部不罰

### 隔離犯著手三說複習

| 學說 | 著手時點 | 說明 |
|------|----------|------|
| 嚴格個別理論 | 行為人完成自己行為時 | 寄出毒藥即著手 |
| 修正個別理論 | 中間媒介到達被害人支配領域時 | 毒藥到達被害人處 |
| 整體理論 | 被害人法益受直接危險時 | 被害人實際接觸毒藥 |

## 中止未遂（§27）

### 基本定位

- 中止未遂嚴格來講屬於**刑罰論**，而非犯罪論
- 放在**三階之外**，不是罪責層次的問題
- 效果：**必減免**其刑（非「得」減免）

### 要件一：符合未遂犯一般要件

- 必須先符合普通未遂的成立要件，才有中止未遂的適用空間
- **無法適用中止未遂的情形**：
  - **過失犯**：過失行為結果發生就用最終結果論罪，無中止可言
  - **既遂犯**：犯罪已完成，不能類推適用中止未遂
  - **不罰未遂的犯罪**：如肇事逃逸等行為犯，未遂本身就不處罰，無從中止

### 預備犯中止三說

| 學說 | 結論 | 代表 |
|------|------|------|
| 不成立犯罪說 | 中止預備行為即不成立犯罪 | 林山田、司法院 |
| 成立預備犯說 | 中止後仍成立預備犯 | 最高法院（實務） |
| 類推適用中止未遂說 | 類推適用§27減免其刑 | 多數學說（非實務） |

> **考試重點**：選擇題常考「哪一說不是實務見解」→ 類推適用說（學說多數但非實務）

### 要件二：非失敗未遂（排除要件）

- 失敗未遂 = 行為人發現自己無法達成犯罪目的而放棄
- **通說兩種類型**：
  1. **發現客觀構成要件無法實現**：如搜索後發現屋內空無一物（竊盜）
  2. **發現犯罪利益不存在**：如發現財物不值錢、想要的東西不在
- **典型考題**：欠人3萬元，搶劫後發現被害人只有500元 → 失敗未遂（犯罪利益不存在）→ 不成立中止未遂

#### 許恆達老師不同見解

- 只有第一種（客觀構成要件無法實現）才算**失敗未遂**
- 第二種（犯罪利益不存在）不算失敗未遂，但也**不符合因己意的要件**
- 最終結論相同：兩種情形都不成立中止未遂，只是理論路徑不同

### 要件三：中止意思

- 中止意思 = **終局放棄** + **因己意**

#### 因己意的判斷標準

| 學說 | 內容 | 採用情形 |
|------|------|----------|
| **主觀說／法蘭克公式**（通說＋實務） | 得為而不欲為 = 因己意；欲為而不得為 = 非因己意 | 最主流 |
| 限定主觀說 | 主觀說 + 倫理自我要求（自律vs他律） | 林東茂老師，少人採 |
| 客觀說 | 以一般人標準判斷 | 73年決議，不好操作 |

#### 具體情境判斷

| 情境 | 因己意？ | 說明 |
|------|----------|------|
| 被路人勸阻後放棄 | ✅ 因己意 | 行為人仍有選擇空間，是自己決定不做 |
| 誤認有危險而放棄（如誤以為警察來了） | ❌ 非因己意 | 雖然客觀無危險，但行為人主觀認為「不得不放棄」 |
| 發現監視器 | ✅ 因己意 | 監視器不影響犯罪的完成可能性，行為人仍可繼續 |
| 發現被害人是國中同學 | ✅ 因己意 | 基於個人情感自主決定放棄 |

### 要件四：中止行為／防果行為

#### 既了未遂 vs 未了未遂

| 類型 | 定義 | 中止方式 |
|------|------|----------|
| **未了未遂** | 行為人認為行為尚未完成 | **消極放棄**即可（停手不做） |
| **既了未遂** | 行為人認為行為已經完成 | 必須**積極防果**（採取防止結果發生的行為） |

- 既了 / 未了的判斷以**行為人主觀認知**為準（通說）
- **不要求行為人親力親為**：法律不要求人民履行無效的義務，可以叫他人幫忙（如叫女友打119）

> **手推車比喻**：推手推車下坡 → 還在推（未了，放手即可）→ 已經放手車自己滾（既了，要追上去把車拉住）

#### 因果關係遮斷說（謝玉偉老師）

- 不區分既了 / 未了，而是看**客觀法益危險狀態**
- 如果客觀上法益危險已經存在 → 需要積極遮斷因果關係
- 如果客觀上法益危險尚未存在 → 消極放棄即可

### 要件五：結果不發生

- 行為人的中止行為必須使犯罪結果確實未發生
- **既遂犯不能類推適用中止未遂**

### 準中止未遂（§27 後段）

- **定義**：行為人有防果行為 + 結果確實未發生，但防果行為與結果不發生之間**無因果關係**
- 例：投毒後送醫，但其實毒藥劑量本來就不致死

#### 真摯性要求

- 黃榮堅老師：以**反面排除**的方式判斷 → 排除「顯然不可靠的中止行為」
- 馬克杯案：打傷被害人後叫女友打119送醫 → 成立準中止（中止行為可靠）
- 傳簡訊案：砍傷被害人後只傳簡訊通知被害人友人 → **不成立**準中止（不可靠）

### 不能未遂的中止（§26 + §27 同時出現）

- 當行為同時符合§26（不能未遂）與§27（中止未遂）
- 處理順序：**先§26再§27**
- 理由：§26 效果為「不罰」（無罪），§27 效果為「必減免」→ **無罪優先於減免**

### 犯罪既遂但法律評價未遂時的中止

- 情境：結果客觀上發生了，但因欠缺客觀歸責而法律上評價為未遂
- 例：甲砍傷乙後送醫，但乙因醫療過失死亡（反常因果歷程）→ 死亡結果不可歸責於甲 → 法律上評價為殺人未遂

| 學說 | 處理方式 | 說明 |
|------|----------|------|
| 傳統說（類推適用） | 類推適用§27 | 認為立法者用語不精確，「結果不發生」應包含此情形 |
| 蔡聖偉老師（直接適用） | 直接適用§27 | §27的「結果」=行為人法律上負責的結果，既然法律上結果未發生即可適用 |

- **變化版**：甲下毒（劑量不足以致死）+ 醫療過失致死 → 適用§27後段（準中止未遂）

### 中止未遂效果

- **必減免**其刑（區別於「得減免」）
- **個人性**：中止未遂的效果不及於其他共犯（各共犯獨立判斷）

### 等價客體錯誤與失敗未遂

- 等價客體錯誤不影響故意 → 不會因為打錯目標就變成失敗未遂
- 要區分：「打錯人」（等價客體錯誤，既遂）vs「發現打不到」（失敗未遂）

## 犯罪參與論（第八章）

### 基本概念

#### 行為人概念

| 概念 | 說明 |
|------|------|
| **緊縮的行為人概念** | 只有親自實現構成要件的人才是正犯，其餘為共犯 → 區分制基礎 |
| **擴張的行為人概念** | 所有對犯罪有因果貢獻的人都是正犯 → 單一制基礎 |

#### 區分制 vs 單一制

| 制度 | 說明 | 採用 |
|------|------|------|
| **區分制** | 區分正犯與共犯，不同角色不同法律效果 | 我國現行刑法 |
| **單一制** | 不區分正犯共犯，所有參與者都是行為人 | 奧地利、我國行政罰法 |

### 正犯與共犯的種類

- **正犯**：
  - 直接正犯（單獨正犯）：親自實現構成要件
  - 間接正犯：利用他人（工具人）實現構成要件
  - 共同正犯：數人共同實現構成要件
- **共犯**：
  - 教唆犯：唆使他人犯罪
  - 幫助犯：幫助他人犯罪
- **注意**：絕不可能全體都是共犯（至少要有一個正犯）

### 正犯共犯區分學說

#### 第一說：主觀說（利益理論）

- 以行為人主觀上是為自己利益還是他人利益判斷
- 為自己利益 → 正犯；為他人利益 → 共犯
- **浴盆案**：母親叫姐姐把嬰兒溺死在浴盆中 → 依主觀說，姐姐為母親利益而做 → 姐姐只是幫助犯（荒謬）
- 已被淘汰

#### 第二說：形式客觀說

- 親自實現構成要件行為 → 正犯；否則 → 共犯
- 歷史學說，過於僵硬

#### 第三說：實質客觀說

- 以對犯罪的實質貢獻程度區分
- 歷史學說

#### 第四說：犯罪支配論（學說主流）

| 支配類型 | 對應正犯 | 說明 |
|----------|----------|------|
| **行為支配** | 直接正犯 | 親自實行犯罪行為 |
| **意思支配** | 間接正犯 | 支配工具人的意思決定 |
| **功能性犯罪支配** | 共同正犯 | 分工合作，各自掌控部分不可或缺的角色 |

##### 犯罪支配論的例外

- **己手犯**：如重婚罪（67年決議），只能成立直接正犯或共犯，不能成立間接正犯或共同正犯
- **純正身分犯**：須具備特定身分
- **義務犯**：以違反特定義務為核心

#### 第五說：主客觀擇一標準說（實務見解）

- 實務操作 = **主觀說 + 形式客觀說**，擇一符合即為正犯
- **主觀上**有共同犯意 → 正犯
- **客觀上**親自做構成要件行為 → 正犯
- 兩者**都不符合** → 幫助犯
- **竊盜把風案例**：
  - 有分贓（共同犯意）→ 共同正犯
  - 純粹還人情幫忙把風（無共同犯意、未做竊盜行為）→ 幫助犯

### 共犯處罰根據

#### 責任共犯說（已無人採）

- 甲教唆乙犯罪 → 甲「製造了犯罪人」→ 以製造犯罪人為處罰根據
- 批評：乙是共同侵害法益的人，不是被害人，不能把製造犯罪人當作處罰理由

#### 因果共犯論（惹因說／照因說）（通說）

- 罰甲的理由跟罰乙一樣
- 罰乙：因為乙侵害了被害人A
- 罰甲：因為甲**透過乙**侵害了被害人A
- 各種不同版本的照因說（許澤天老師碩士論文主題）→ 太學理，國考不需深究

### 共犯從屬性

#### 定義

- **共犯的成立以正犯的行為存在為前提**
- 共犯（教唆、幫助）無法獨立存在
- 理由：如果只有共犯行為而無正犯行為 → 沒有法益侵害的危險 → 不值得處罰
- 例：叫人殺人但對方不理 → 不成立教唆犯

#### 三大面向

##### 1. 實行的從屬

- 正犯必須**著手**，共犯才成立
- 正犯未著手 → 共犯不成立
- 例：教唆偷竊，但正犯在翻牆時就被抓（尚未著手竊盜行為）→ 教唆犯不成立

##### 2. 要素的從屬

- 正犯必須符合一定的犯罪成立要件，共犯才能成立

| 從屬程度 | 正犯須符合 | 說明 |
|----------|------------|------|
| 誇張從屬 | 該當＋違法＋有責＋刑罰 | 最嚴格 |
| 嚴格從屬 | 該當＋違法＋有責 | 2006年前採用 |
| **限制從屬** | **該當＋違法** | **現行法採用** |
| 最小從屬 | 該當 | 最寬鬆 |

- **小學生縱火案例**：
  - 小學生買不到汽油 → 甲給小學生一桶汽油 → 小學生成功縱火
  - 嚴格從屬：小學生無罪責 → 無法從屬 → 甲無罪（法律漏洞）
  - **限制從屬**：小學生該當且違法 → 可以從屬 → 甲成立幫助犯 ✅

- **與不能未遂的連結**：
  - 不能未遂放三階之外 → 正犯至少該當且違法 → 滿足限制從屬 → 共犯可成立
  - 不能未遂放構成要件不該當 → 連該當都不滿足 → 共犯無法從屬

- **教唆合法行為**不成立教唆犯：
  - 例：勸懷孕友人依優生保健法進行合法人工流產 → 正犯行為合法（不違法）→ 教唆犯不成立

##### 3. 罪名的從屬

- 正犯與共犯的**罪名必須一致**

### 間接正犯概說

#### 基本結構

- 甲（背後利用人）利用乙（被利用人/工具人）去犯罪
- 最常見兩類手段：**欺騙**、**脅迫**

#### 稱呼

| 角色 | 別稱 |
|------|------|
| 背後利用的人（甲） | 間接正犯、利用人 |
| 被利用的人（乙） | 直接正犯、被利用人、工具人 |

#### 論罪方式

- 看**甲（間接正犯）出於什麼故意** + **乙實際做了什麼事（造成什麼結果）**
- 間接正犯是**正犯**，沒有從屬性問題
- 例：甲把毒飲料交給不知情的乙轉交給A → A喝了死亡 → 甲成立殺人罪的間接正犯

#### 間接正犯 vs 教唆犯的區別

| | 間接正犯 | 教唆犯 |
|--|----------|--------|
| 被利用人的認知 | 被騙或被脅迫，**不知真相或無法自由選擇** | 知道真相，**有充分自由決定空間** |
| 背後之人的地位 | **正犯**（掌控全局） | **共犯**（僅促成） |
| 從屬性問題 | 無 | 有（須滿足從屬性） |

- 威脅案例：甲拿刀威脅乙「不殺A就殺你全家」→ 乙無選擇 → 甲是**間接正犯**
- 教唆案例：甲告知乙飲料有毒並請乙拿去給A喝，乙知情同意 → 乙可自由決定 → 甲是**教唆犯**

## 本講重點摘要

1. **不能未遂考題**：三說只在結論不同時才需並列討論；共犯自身行為也可能構成不能未遂
2. **中止未遂五要件**：①符合未遂犯一般要件 → ②非失敗未遂 → ③中止意思（因己意，法蘭克公式）→ ④中止行為（未了消極/既了積極）→ ⑤結果不發生
3. **準中止未遂**：防果行為存在 + 結果未發生 + 兩者無因果關係；須具真摯性
4. **§26+§27並存**：先§26（無罪）後§27（減免），無罪優先
5. **犯罪參與論**：區分制（正犯 vs 共犯）；犯罪支配論（學說主流）vs 主客觀擇一標準說（實務）
6. **共犯從屬性**：現行法採**限制從屬**（正犯該當＋違法即可）；三面向＝實行從屬＋要素從屬＋罪名從屬
7. **間接正犯**：利用欺騙/脅迫使工具人犯罪，工具人無自主決定空間，間接正犯是正犯而非共犯
