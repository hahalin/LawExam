# 刑法09 筆記：防禦型緊急避難與可罰違法性

> 來源：刑法09 課程字幕 01:24:00 ~ 01:44:00

## 📖 法條原文速查

> **§24**（緊急避難）
> I：因避免自己或他人生命、身體、自由、財產之緊急危難而出於不得已之行為，不罰。但避難行為過當者，得減輕或免除其刑。

> **§320**（竊盜罪）
> I：意圖為自己或第三人不法之所有，而竊取他人之動產者，處五年以下有期徒刑、拘役或五十萬元以下罰金。
> → 建議查閱最新六法原文

> **§321**（加重竊盜罪）
> I：犯前條第一項、第二項之罪而有下列情形之一者，處六月以上五年以下有期徒刑，得併科五十萬元以下罰金：
> 二、**毀越門窗、牆垣**或其他安全設備而犯之。
> → 龍眼長在牆外 = 普通竊盜；伸手過牆摘 = 加重竊盜（§321 I②）

> **§277**（傷害罪）
> I：傷害人之身體或健康者，處五年以下有期徒刑、拘役或五十萬元以下罰金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「防禦型與攻擊型緊急避難之差異？」 | 攻擊型犧牲**無辜法益**→衡平性嚴格；防禦型犧牲**危難來源**→衡平性放寬（非顯然不相當即可） |
| 「保全與犧牲同屬一人時如何處理？」 | 現多數說：用**客觀歸責**（降低風險/替代性風險）解決，不需跑緊急避難 |
| 「降低風險 vs 替代性風險之差異？」 | 降低風險 = 拯救**成功**但人受傷；替代性風險 = 拯救**失敗**人死亡且不拯救也幾乎必死 |
| 「對正當防衛可否正當防衛？」 | **不可**。四種交錯排列組合結論均為不可 |
| 「為保護財產犧牲他人身體，可否緊急避難？」 | **不可**。身體高於財產，即使納入法益總量觀點，多處挫傷仍非微不足道 |
| 「偷一顆龍眼，可否論罪？」 | 爭議：**可罰的違法性**欠缺 → 微罪不舉 |

## 一、防禦型緊急避難

### 攻擊型 vs 防禦型

| 比較項目 | 攻擊型緊急避難 | 防禦型緊急避難 |
|---------|--------------|--------------|
| 被犧牲者性質 | **無辜**（與危難無關） | **非無辜**（= 危難來源 / 始作俑者） |
| 衡平性要求 | **嚴格**：保全利益須明顯優於犧牲利益 | **寬鬆**：**非顯然不相當**即可通過 |
| 自主決定權 | 須考慮被犧牲者的自主決定 | **不需**考慮（危難來源應自我承受） |
| 考試頻率 | 常考 | 較少考 |

### （一）對物防禦

#### 案例：登山者殺河馬案

- 登山者無端遭河馬攻擊，為保命將河馬殺死
- 衡平性：河馬生命 vs 人的生命 → **非顯然不相當** → 通過
- 防禦型不需精密比較，只要不是明顯失衡就給過

### （二）對人防禦

#### 案例：精神病患砸車案

##### 事實
1. 精神病患 A 每到半夜就去樓下砸鄰居機車
2. A 的家人在食物中摻入安眠藥，讓 A 半夜好好睡

##### 分析

**能否主張正當防衛？**
- 通說：**不能**。A 的攻擊非「現在」侵害，而是「將來」的侵害
- （類似家暴殺夫案的爭議）

**能否主張緊急避難？**
- 通說：**可以**（防禦型）
- A 就是危難來源 → 不無辜 → 衡平性放寬
- 不能以「犧牲身體＋自由 > 財產」為由否定
  - 原因：這是**防禦型**，A 是始作俑者，應自我承受
  - 通說允許通過

## 二、保全與犧牲同屬一人

### 核心概念
- 保全的法益與犧牲的法益屬於**同一人**
- 歷史上曾用緊急避難處理，現多數說用**客觀歸責**解決

### 案例：山豬案 / 卡車案

| 案例 | 事實 | 結果 | 處理方式 |
|------|------|------|---------|
| 山豬案 | A 為救 B 射殺追擊山豬，卻誤殺 B | 拯救失敗 | **替代性風險** |
| 卡車案 | 卡車衝向站牌，你抓小朋友跑，小朋友頭撞電線桿死亡 | 拯救失敗 | **替代性風險** |
| 拯救成功但受傷 | 拯救被害人成功，但被害人受了小傷 | 拯救成功 | **降低風險** |

### 降低風險 vs 替代性風險

```
客觀歸責處理保全犧牲同屬一人
│
├── 降低風險（Risikoverringerung）
│   ├── 拯救成功
│   ├── 被害人僅受輕傷
│   └── 結果：不可歸責（不成立犯罪）
│
└── 替代性風險（Risikoersetzung）
    ├── 拯救失敗，人死亡
    ├── 但不拯救幾乎也必死
    └── 結果：不可歸責（不成立犯罪）
```

> **重點**：現在多數說以客觀歸責解決，不跑緊急避難。緊急避難只在不採客觀歸責理論或不承認替代性風險概念時，才會用到。此為「歷史的遺跡」。

## 三、緊急避難與正當防衛的交錯

### 四種排列組合

| 情境 | 結論 | 理由 |
|------|------|------|
| 對正當防衛 → 正當防衛？ | **不可** | 正當防衛 = 合法 → 無「不法侵害」可言 |
| 對正當防衛 → 緊急避難？ | **不可** | 緊急避難之危難不包括合法行為 |
| 對緊急避難 → 正當防衛？ | **不可** | 緊急避難 = 合法 → 無「不法侵害」可言 |
| 對緊急避難 → 緊急避難？ | **不可** | 同上，合法行為不構成危難 |

> **結論**：四種排列組合全部不行。正當防衛與緊急避難均為合法行為，合法行為的相對人只能忍受。

## 四、百萬重機案（法益侵害總量）

### 案例

甲車太重即將倒下，甲急忙將乙推倒在地防止重機摔落，乙多處挫傷。

### 分析
- 甲該當傷害罪（§277）
- 甲面臨的危難：百萬重機倒下 → **財產法益**
- 甲犧牲的法益：乙的身體
- 為財產犧牲身體 → **原則不衡平**
- 即使納入法益侵害的**總量觀點**（百萬重機很貴）：
  - 多處挫傷 ≠ 顯然輕微 → 不是「微不足道」的身體傷害
  - 結論：**必然過當**

## 五、可罰的違法性

### 案例：偷龍眼案

#### 事實
- 甲偷摘乙家龍眼（長出牆外）一顆來吃
- 該當普通竊盜罪（§320；長在牆外 → 非§321 加重竊盜）

#### 寫作順序提醒
- 涉及正當防衛的考題，同時問防衛者與侵害者 → **先寫侵害者**
- 原因：須先確認侵害人行為的不法性，防衛者的論述才寫得下去

#### 可罰的違法性爭議
- 龍眼一顆 → 價值極微
- 「可罰的違法性」欠缺 → 微罪不舉
- 雖是80年代的爭議，但**現在考試仍會出**

> **考試技巧**：看到「偷極微小價值之物」的題型 → 想到可罰的違法性欠缺
