# 刑法13 筆記：共謀共同正犯與特殊問題

> 來源：刑法13 課程字幕 02:10:00 ~ 02:39:00

## 📖 法條原文速查

> **§28**（共同正犯）
> 二人以上共同**實行**犯罪之行為者，皆為正犯。
> → 94年修法將「實施」改為「實行」，排除陰謀預備階段的共同正犯

> **§271**（殺人罪）
> I：殺人者，處死刑、無期徒刑或十年以上有期徒刑。

> **§302**（私行拘禁罪）
> I：私行拘禁或以其他非法方法，剝奪人之行動自由者，處五年以下有期徒刑、拘役或九千元以下罰金。

> **§328**（強盜罪）
> I：意圖為自己或第三人不法之所有，以強暴、脅迫、藥劑、催眠術或他法，至使不能抗拒，而取他人之物或使其交付者，為強盜罪，處五年以上有期徒刑。

## 📋 釋字/實務見解速查

> **釋字 109 號**
> 以自己共同犯罪意思，參與實施構成要件以外之行為，或以自己共同犯罪之意思，事前同謀，而由其中一部分人實行犯罪之行為者，均為**共同正犯**。
> → 前段＝構成要件以外行為（如開車接應）；後段＝共謀共同正犯

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「全體均在預備階段，可否成立共同正犯？」 | **不可以**（§28「實行」＝須有人著手） |
| 「共謀者行為當下不在場，可否為共同正犯？」 | 實務（釋字109）：**可以**；嚴格說：**否定**（頂多教唆犯）；溫和說：**有條件承認** |
| 「嚴格犯罪支配論的最低限度？」 | 行為當下用**通訊方式即時掌握現場**才可能論共正 |
| 「溫和犯罪支配論承認共謀共正的條件？」 | 共謀者須為**核心首腦**，共同行作犯罪計畫或組織犯行 |
| 「過失犯可否成立共同正犯？」 | 傳統：**不可以**；新說：**可以**（法條未明禁＋可解決因果不明問題） |
| 「擇一共同正犯中事後無用的人，是否共正？」 | 許恆達：**否**（事後無貢獻者非共正，但可論精神幫助犯）；德國多數說：**是** |
| 「為殺人而先壓制被害人（§302），如何處理？」 | §302 被殺人罪**吸收**，不另論 |

## 一、過失的共同正犯

### 問題提出：瑞士滾石案

**事實**：甲乙在山坡上推大石頭，路人被其中一顆砸死，無法查明是甲推的還是乙推的。

### 學說爭議

```
過失可否成立共同正犯？
│
├── 傳統說（否定）
│   └── 共同正犯需犯意聯絡 → 過失不可能犯意聯絡
│       → 批評：只回答問題的表面，沒回答本質
│           （支持者可以說：把犯意聯絡要件換掉就好了）
│
└── 新說（肯定，越來越多學者支持）
    ├── 理由①：法條沒有明確反對（§28 只說「二人以上共同」，沒說故意或過失）
    └── 理由②：承認有實益
        └── 交互歸責 = 罪疑惟輕的例外
            → 多人過失造成結果但不能證明是誰
            → 肯認過失共同正犯 → 全體一起負責
```

### 實益示範：瑞士滾石案的結論差異

| 採否定說 | 採肯定說 |
|---------|---------|
| 甲：你沒證據證明是我推的 → 罪疑惟輕 → 無罪 | 甲乙為共同體 → 交互歸責 |
| 乙：你沒證據證明是我推的 → 罪疑惟輕 → 無罪 | → 全體為結果負責 |
| **結果：兩人都無罪（不合理）** | **結果：兩人均有罪** |

## 二、行為分擔

### 三種行為分擔的模式

```
共同正犯的行為分擔
│
├── ① 全體都做構成要件行為
│   └── 如：甲乙各持刀砍被害人
│
├── ② 有人做構成要件行為＋有人做構成要件以外行為
│   └── 如：甲架住被害人（非構成要件）、乙持刀刺（構成要件）
│
└── ③ 每人都只做部分構成要件行為
    └── 如搶銀行：
        甲開車接應（非構成要件）
        乙持槍威嚇（只有強制）
        丙跳入櫃檯取財（只有竊取）
        → 無人完整做 §328，但全體為共同正犯
```

**結論**：行為分擔**不要求**每人都做完整的構成要件行為。

## 三、陰謀與預備的共同正犯

### 結論：不能成立

**法律依據**：§28 修法將「實施」改為「**實行**」

```
§28 的「實行」
│
├── 實行 = 著手的同義詞（有著手才有實行）
│
└── 效果：排除全體均在陰謀或預備階段的共同正犯
    ├── 修法前（寫「實施」）→ 全體陰謀/預備可以成立共正
    └── 修法後（寫「實行」）→ 至少要有一人著手
```

## 四、共謀共同正犯

### 問題提出

共謀者＝有犯意聯絡、甚至是核心首腦，但**行為當下不在場**、沒有行為分擔。

#### 案例
- 甲乙丙丁相約搶銀行
- 甲負責計畫安排人力
- 乙開車接應、丙丁去銀行行搶
- 行搶當天，**甲在家中睡覺**
- 甲 = 共謀共同正犯？

### 三說比較

| 學說 | 立場 | 說明 |
|------|------|------|
| **實務（釋字109）** | 無條件肯定 | 事前同謀＋其中一部分人實行 → 均為共正 |
| **嚴格犯罪支配論** | 否定（除非以通訊即時掌握現場） | 不在場 → 不可能支配犯罪 → 頂多教唆犯 |
| **溫和犯罪支配論** | 有條件承認 | 共謀者須為**核心首腦**（共同行作犯罪計畫/組織犯行） |

### 釋字 109 號的兩段

```
釋字 109 號
│
├── 前段：以自己共同犯罪意思，參與構成要件以外行為
│   └── 例：開車接應的乙（有到場，只是做構成要件外行為）
│   └── 這「不是」共謀共同正犯
│
└── 後段：以自己共同犯罪意思，事前同謀，由一部分人實行
    └── 例：甲在家睡覺
    └── 這才是共謀共同正犯的定義
```

### 三說的實際差異

#### 案例：小弟阿悟
- 阿悟是強盜集團新人
- 行前會議都有參加，但沒提出建設性意見
- 搶劫當天也在家睡覺
- 事後參與分贓

| 學說 | 阿悟是否為共同正犯？ |
|------|-------------------|
| 實務 | **是**（無條件承認共謀共正） |
| 溫和犯罪支配論 | **否**（阿悟非核心人物，未達共同行作犯罪計畫/組織犯行） |
| 嚴格犯罪支配論 | **否**（當下不在場也沒通訊掌握） |

→ **嚴格說對行為人最有利**

## 五、擇一共同正犯

### 問題提出

**事實**：
- 甲乙要殺A
- A的豪宅有前門、後門
- 甲埋伏前門、乙埋伏後門
- A從後門離家 → **乙殺死A**
- 甲完全沒用（事後證明）

→ 甲還是共同正犯嗎？

### 學說爭議

| 學說 | 結論 | 理由 |
|------|------|------|
| **假說（推論實務見解）** | 肯定 | 實務連共謀共正（無行為分擔）都無條件肯定，擇一共正（有分擔但事後無效）更不可能否定 |
| **許恆達（乙說）** | 否定 | 行為分擔應從**事後**角度認定，事後無貢獻者 ≠ 行為分擔 |
| **德國多數說（丙說）** | 肯定 | 行為分擔包括「非典型貢獻」，只要**事前預期**有貢獻即可 |

### 許恆達老師的否定說補充

- 甲雖然不成立共同正犯
- 但甲埋伏前門讓乙更安心 → 甲可成立**精神幫助犯**
- 否定擇一共正 ≠ 全無刑責

## 六、考題演練：默示犯意聯絡與殺人共正

### 案例：圍毆致死案（警特四等）

**事實**：
1. 甲乙沒有事前溝通
2. 一前一後包夾被害人
3. 其中一人用雙手抓住被害人
4. 兩人拳打腳踢，被害人死亡

**分析**：

1. **犯意聯絡**：雖無明示，但動作眼神配合 → **默示犯意聯絡**
2. **私行拘禁（§302）**：甲乙包夾壓制 → §302 共同正犯
3. **殺人罪（§271）**：拳打腳踢致死 → 論§271 共同正犯
   - 為何不是傷害致死？→ 加重結果犯的共正是另一考點，警特四等不會考那麼難
4. **競合**：為殺人而壓制被害人 → §302 被§271 **吸收**，不另論
5. **結論**：甲乙論**殺人既遂罪的共同正犯**
