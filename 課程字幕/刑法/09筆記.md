# 09 筆記：緊急避難（續）、依法令行為、業務上正當行為

## 考題複習

### 一、公務員認定複習

| 案例 | 身分 | 理由 |
|------|------|------|
| 公立學校老師做政府採購 | **授權公務員** | 受國家委託行使公權力 → §132 洩密 ＋ §131 圖利 |
| 約僱人員在戶政事務所 | **身分公務員** | 非機械性事務，具公權力性質 |
| 民間拖吊業者 | **行政助手**（非公務員） | 僅協助行政機關執行 |

### 二、空間效力寫作格式

- **寫作順序**：先判斷空間效力（§5–§8）**再**進入三階層分析
  - §5–§8 的判斷方式 = 「**假設屬實**」→ 不需先審完實體再看管轄
- **時間線索出現 → 考修法**
  - 例：§5⑪ 於 2016 年增訂 → 2014 年行為不適用 → **法律不溯及既往**
  - §5–§8 看似程序性規定，但涉及**國家刑罰權空間效力範圍** → 有實體法成分 → 不可溯及既往

### 三、客觀歸責與因果關係複習

- **雙重具體化錯誤**：牛奶案／沐浴乳案 → 結果作用方式符合因果鏈設定 → **客體錯誤**
- **擇一因果（雙重因果）**：兩個獨立條件各自足以致結果
- **可罰的違法性**：沐浴乳兩坨 → 財產犯罪價值趨近於零 → 肯定說 vs 否定說之爭
- **因果歷程偏離**（110 年律師高考放火案）：
  - 客觀：風險實現（逃生失敗死亡不反常）
  - 主觀：細節性偏差不影響故意

### 四、違法性考題複習

- **對無責任能力人攻擊** → 三階段防衛 → 未做到 1-2-3 → **防衛過當**
- **偶然防衛**複習
- **非意圖式挑唆防衛** → 三階段防衛 → 未做 → 防衛過當
  - 寫法：先確認一般適當性必要性 → 再論社會倫理限制 → 再論 1-2-3 缺失

## 緊急避難的法益衡量（續）

### 一、生命法益的最高位階性

- **生命 vs 國家社會法益** → 生命勝
  - 肇事逃逸案：為保全自己生命而逃離 → 犧牲國家社會法益 → 法益衡平過得去

### 二、香蕉船案

- **事實**：香蕉船翻覆，甲為求生而將乙推離浮板，乙溺斃
- **分析**：
  - 危難 = 海上載浮載沉的**生命危險**（非船翻本身）
  - **過失自招**：甲有過失造成危難 → 不影響主張緊急避難，但法益衡量更嚴格
  - **生命 vs 生命** → 衡平性**過不去** → 不能阻卻違法

| 學說 | 處理方式 | 結論 |
|------|----------|------|
| **傳統說**（通說） | §24①但書 → **避難過當** | 有罪（得減輕或免除） |
| **少數說**（黃榮堅／許澤天） | 免除罪責的緊急避難 | **無罪** |

### 三、德國刑法 §34 vs §35

| | 德國 §34 | 德國 §35 |
|---|----------|----------|
| 性質 | **阻卻違法**緊急避難 | **免除罪責**緊急避難 |
| 法益衡量 | 有 | 無（限生命、身體、自由） |
| 對應我國條文 | §24 前段 | **無對應條文** |

- 少數說主張：擴大解釋我國 §24 → 隱含兩種避難（阻卻違法 ＋ 免除罪責）

### 四、強制抽血案（個人自主決定權）

- **事實**：A 急需罕見血型輸血，醫院志工 C 有此血型但拒絕捐血，醫師強制拘束 C 抽血
- **爭議**：侵害 C 什麼法益？

| 學說 | 侵害法益 | 法益衡平 | 結論 |
|------|----------|----------|------|
| **少數說** | 純粹身體 ＋ 些許自由 | 生命 vs 身體＋自由 → **過得去** | 阻卻違法 |
| **多數說** | **人性尊嚴**（不把人當人看，當供血機器） | 生命 vs 人性尊嚴 → **過不去** | 避難過當 |

### 五、法益損害的強度（總量觀點）

- 法益排序：**生命 > 身體 > 自由 > 財產**
- 生命不可量化比較；但**生命以外的法益可以加入「總量」觀點**
- 短暫自由 vs 巨額財產 → 未必自由較大

> **珠寶店鎖門案**：停電 30 秒，鑽石失竊，店長反鎖大門通知警方
> - 對**真正小偷** → 正當防衛／現行犯逮捕
> - 對**無辜被關客人** → 緊急避難
> - 十幾分鐘自由 vs 上千萬財產 → 法益衡平**過得去** → 阻卻違法

### 六、法益遭受危險的大小（抽象 vs 具體危險）

- **典型考題**：為拯救危急傷患而**冒險酒後駕車**
- 犧牲法益 = 公共安全（不特定人生命身體）
- 保全法益 = 傷患的生命身體

| 情境 | 犧牲方危險程度 | 法益衡平 |
|------|----------------|----------|
| 意識清醒、路上零星車輛 | **抽象危險** | 過得去 → 阻卻違法 |
| 意識模糊、車輛多、幾度差點追撞 | **具體危險** | 過不去 → 避難過當 |

- **關鍵判斷**：行為人所犧牲的公共安全是「抽象危險」還是「具體危險」

## 強制性緊急避難（Genötigter Notstand）

### 一、定義

- 緊急避難的行為人**同時也是強制罪的被害人**
- 例：甲脅迫乙「你去砸丙的車，不然我就捅你」→ 乙砸丙的車

### 二、三說

| 學說 | 效果 | 理由 |
|------|------|------|
| **阻卻違法說**（傳統通說） | 阻卻違法 | §24 未區分危難來源，不分人為或自然力 |
| **免除罪責說**（寬恕罪責說） | 免除罪責（避難過當） | 乙並非全然無辜，乙「利於不法的一方」，與甲是一夥的 |
| **折衷說** | 區分情況 | 被強制者有生命身體重大危險 ＋ 避難手段不犧牲他人生命身體自由 → 阻卻違法；否則 → 免除罪責 |

### 三、區別實益

1. **正當防衛問題**：
   - 阻卻違法說 → 乙合法 → 丙**不能**對乙正當防衛
   - 免除罪責說 → 乙不法 → 丙**可以**對乙正當防衛

2. **共犯從屬問題**：
   - 甲逼迫乙犯罪 → 甲除強制罪外，還可能成立該罪的**間接正犯**
   - 教唆犯需正犯行為**該當且違法** → 乙是否阻卻違法影響甲能否成立教唆犯
   - 偽證罪（純正身分犯＋己手犯）→ 不能成立間接正犯 → 只能考慮教唆犯

## 攻擊型 vs 防禦型緊急避難

### 一、定義比較

| | 攻擊型 | 防禦型 |
|---|--------|--------|
| 被犧牲法益 | **無辜**的法益（危難與其無關） | **危難來源**本身 |
| 法益衡平標準 | **嚴格**（保全 > 犧牲） | **放寬**（非顯然不相當即可） |

### 二、防禦型緊急避難的案例

#### 對物防禦
- 登山者遭河馬攻擊 → 殺死河馬 → 防禦型 → 法益衡平放寬 → **阻卻違法**

#### 對人防禦
- 不需考慮被犧牲者的自主決定權（因其為危難來源）

| 案例 | 分析 |
|------|------|
| 精神病患 A 半夜砸鄰居機車 → 家人在食物摻安眠藥 | 侵害非現在 → 不能正當防衛；防禦型避難 → 法益衡平**過得去** |
| A、B 登山以扣環相連 → B 失足 → A 解開扣環 B 摔死 | A 危險源自 B → 防禦型（非香蕉船的攻擊型）→ 法益衡平**過得去** |

### 三、保全與犧牲法益同屬一人所有

- 保護 A 的過程反而犧牲了 A
- **多數說**：客觀歸責理論即可解決，不需走緊急避難
  - 拯救成功但受傷 → **降低風險**（客觀歸責不成立）
  - 拯救失敗人死亡 → **替代性風險**（不作為也會死 → 客觀歸責不成立）
- 緊急避難處理此類型 = **歷史遺跡**（不採客觀歸責時才用）

## 緊急避難與正當防衛的交錯關係

| 對 ＼ 的行為 | 正當防衛 | 緊急避難 |
|:---:|:---:|:---:|
| **正當防衛** | ✘（合法行為，無不法侵害） | ✘（合法行為，非危難） |
| **緊急避難** | ✘（合法行為，無不法侵害） | ✘（合法行為，非危難） |

- 四種排列組合皆**不可**

### 考題應用

> **百萬重機案**：甲重機傾倒 → 推倒乙（多處挫傷）→ 保全財產犧牲身體 → 即使加入總量觀點仍不衡平 → **避難過當**

> **龍眼案**：
> - 甲偷摘牆外龍眼 → 普通竊盜（非加重）→ 可罰的違法性問題（一顆龍眼價值趨近於零）
> - 乙追打甲 → 傷害罪該當 → ✘正當防衛（理由①甲若欠缺可罰違法性則行為合法；理由②甲已吃完離去 = 過去侵害非現在侵害）
> - **寫作順序**：涉及正當防衛題目，同時問防衛者與侵害者 → **先寫侵害者**

## 依法令行為（§21 I）

### 一、自助行為（民法 §151）

- **原則**：權利禁止自力救濟（避免叢林法則 ＋ 球員兼裁判）
- **例外**：不及受法院或機關援助 ＋ 非於即時為之則請求權不得實行

> **案例**：老人騎電動代步車撞壞你的車 → 肇事要逃 → 拔掉代步車鑰匙通知警方
> - 電動代步車**無車牌** → 當下不攔住日後無從追償
> - 拔鑰匙行為該當剝奪行動自由 → 依自助行為**阻卻違法**
> - 對比：有車牌的汽機車 → 記車牌報警即可 → 無須自助行為

### 二、父母親權與懲戒權（民法 §1084、§1085）

- §1084②：父母對**未成年**子女有保護教養之權利義務
- §1085：父母得於必要範圍內懲戒**子女**（條文未寫「未成年」）
- **刑法學者**：懲戒權應限於**未成年**子女 → 對成年子女無法「合理不過當」
- 手段不能過當（§21 無過當減免規定，不像 §23、§24 有緊急性質值得同情）

### 三、現行犯逮捕（刑訴 §88）

#### （一）定義

| 類型 | 說明 |
|------|------|
| **現行犯** | 犯罪在實施中或實施後**即時發覺**者 |
| **準現行犯** | ①被追呼為犯人；②持有兇器、贓物或身體衣服有犯罪痕跡 |

- 追呼為犯人：不論「追＋呼」並存或擇一 → 重點在一般情境下**是否讓人相信他是現行犯**

#### （二）贓物認定差異

| | 刑法 §349 | 刑訴 §88 |
|---|-----------|----------|
| 範圍 | 專指**財產犯罪**所得 | 泛指**一切犯罪**所得 |
| 例 | 挖墳陪葬品 → ✘贓物 | 貪汙賄款 → ✔贓物 |

#### （三）兩個動作缺一不可

1. **逮捕**
2. **解送**檢警機關

- 逮到人但未解送（例：踹露鳥俠後就走）→ 不能阻卻違法

#### （四）現行犯逮捕 vs 正當防衛重疊

- 擇一成立即阻卻違法 → **看題目線索**：
  - 題目有「解送檢警」→ 寫**現行犯逮捕**
  - 題目無「解送檢警」→ 寫**正當防衛**

#### （五）抓錯人的處理

| 學說 | 判斷標準 | 結論 |
|------|----------|------|
| **通說** | **情勢判斷**：當下外觀看起來像現行犯即可 | 合法逮捕（事後發現無罪不影響合法性） |
| 少數說（李東茂） | 要真的抓對人 | 否則違法 |

- 現行犯逮捕 = **強制處分** → 形式上判斷（同刑訴搜索概念）
- 通說下，現行犯逮捕**很難**變誤想（容許構成要件錯誤），但**不是永遠不會**
  - 客觀上根本不像現行犯卻誤認 → 仍可能構成誤想

#### （六）被合法逮捕者的反擊

- 合法逮捕 → 相對人**不能正當防衛、不能緊急避難**（合法行為的相對人要忍受）
- 若被逮捕者自認無辜而反擊 → **非誤想防衛**（非事實誤認）→ 是 §16 **法律意識欠缺**（不知法律）

## 人工流產（優生保健法）

### 一、六款事由

| 類型 | 款次 | 說明 |
|------|------|------|
| 胎兒有缺陷或可能有缺陷 | 1、2、4 | 基因異常、畸形等 |
| 母體問題 | 3 | 懷孕或分娩危害母體健康 |
| 孕婦心理不適合 | 5、6 | ⑤被性侵；⑥影響心理健康或家庭生活 |

- **第六款**範圍極寬 → 幾乎架空墮胎罪 → 墮胎罪**名存實亡**
- 所有人工流產情境中胎兒一定都是無辜的 → 「胎兒是無辜的」不足以否定人工流產正當性

### 二、現行法限制及學者批評

| 限制 | 內容 | 學者評論 |
|------|------|----------|
| **24 週** | 超過 24 週不得人工流產 | 尚屬合理（母體危險 ＋ 胎兒漸具人形） |
| **成年** | 未成年需法代同意 | **不合理**：反而增加未成年人風險（密醫、墮胎藥、拖到生產） |
| **配偶同意** | 已婚者用第六款需配偶同意 | **極不合理**：侵害女性身體自主權 → 2025 年惡法仍存 |

## 公務員依上級命令行為（§21 II）

- 條文：依所屬上級公務員命令行為不罰，但**明知違法者**不在此限

### 要件

1. 命令具有拘束力（上下級事務範圍內）
2. 命令具備法定程序
3. 未逾越授權範圍
4. **不能明知命令違法**

### 「明知違法」之範圍

| 學說 | 範圍 | 理由 |
|------|------|------|
| **學者** | 僅限**形式**合法性 | 不能要求下級審查上級命令之實質合法性（違反行政倫理） |
| **實務** | 形式 ＋ **實質**皆含 | 只要明知違法，不管形式或實質，皆不能阻卻違法 |

## 業務上正當行為（§22）

### 一、事實業務說

- 重點是**行為正當**，非業務正當（業務上**的**正當行為）
- 「業務」= **事實業務**（不要求合法執照）
- **密醫案例**：無照但處置符合醫療常規 → 可阻卻違法（無照行醫是其他法律問題）

### 二、行為正當的判斷

- 最低限度：不能抵觸其他法領域的規定
  - 密醫為病患拔牙 → 無其他法律禁止拔牙行為本身 → 行為正當 ✔
  - 警察刑求被告 → 刑訴禁止 → 行為不正當 ✘

### 三、醫療行為

#### 要件
1. 出於**醫療目的**
2. **告知後同意**（Informed Consent）
3. 符合**醫療常規**
4. 以緩解疼痛、緩解疾病為目的

#### 特殊情況

| 情況 | 說明 | 效果 |
|------|------|------|
| 無事前同意 | 頂多成立**推測的承諾** | 可能阻卻 |
| **專斷醫療** | 違反病患明示意思 | 原則上**不能阻卻違法** |

#### 醫療行為傷害說 vs 非傷害說

| 學說 | 對成功醫療行為之評價 | 理由 |
|------|----------------------|------|
| **傷害說**（傳統） | 該當傷害罪 → 以阻卻違法事由排除 | 拔牙 = 少一顆牙 ＋ 出血 = 身體完整性受侵害 |
| **非傷害說**（漸成主流） | **不該當**傷害罪 | 醫療行為應看**整體**，不應糾結一刀一針一線；病患從不健康→健康 = 未侵害身體法益 |

### 四、業務上正當行為的實際適用空間

- 真正「只能」用業務上正當行為的情況**不多**
  - 公務員執法 → 可能同時有 §21
  - 醫療行為 → 可能同時有被害人同意、緊急避難
- **記者臥底採訪案**：為揭發黑心食品工廠喬裝臥底、密錄 → 找不到其他阻卻事由 → 只能用業務上正當行為
