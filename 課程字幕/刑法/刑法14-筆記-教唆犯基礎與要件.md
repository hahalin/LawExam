# 刑法14 筆記：教唆犯基礎與要件

> 來源：刑法14 課程字幕 00:00:00 ~ 00:50:00（含共同正犯逾越與重結果引言）

---

## 📖 法條原文速查

> **§29**（教唆犯）
> I：教唆他人使之**實行**犯罪行為者，為教唆犯。
> II：教唆犯之處罰，依其所教唆之罪處罰之。

> **§30**（幫助犯）
> I：幫助他人實行犯罪行為者，為幫助犯。雖他人不知幫助之情者，亦同。
> II：幫助犯之處罰，得按正犯之刑減輕之。
> → I 後段「雖他人不知幫助之情者，亦同」= 承認**片面幫助犯**

> **§153**（煽惑他人犯罪或違背法令罪）
> 以文字、圖畫、演說或他法，公然為下列行為之一者，處二年以下有期徒刑、拘役或三萬元以下罰金：
> 一、煽惑他人犯罪者。
> 二、煽惑他人違背法令，或抗拒合法之命令者。
> → **行為犯 / 抽象危險犯**，不以有人被煽動為必要

> **§277**（傷害罪）
> I：傷害人之身體或健康者，處五年以下有期徒刑、拘役或五十萬元以下罰金。

> **§276**（過失致死罪）
> 因過失致人於死者，處五年以下有期徒刑、拘役或五十萬元以下罰金。

> **§286**（凌虐幼童罪）
> → 建議查閱最新六法原文（近年多次修正）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「教唆對象不特定時，應論何罪？」 | 不成立教唆犯，改論 **§153 煽惑罪**（公然為之） |
| 「教唆之罪名不特定時，行為人如何論罪？」 | **無罪**（教唆犯要求罪名特定） |
| 「教唆犯之處罰如何？」 | **依其所教唆之罪處罰**（§29 II），非獨立罪名 |
| 「教唆犯是否需要與被教唆人有心理接觸？」 | **通說肯定**（溝通理論）；無接觸者改論**精神幫助犯** |
| 「片面教唆是否成立？」 | **不成立**（§29 無§30 I 後段之規定→體系解釋） |
| 「勸阻教唆是否成立教唆犯？」 | **不成立**，屬降低風險行為，非製造風險 |
| 「被教唆的正犯僅達預備階段，教唆人可否論罪？」 | **通說否定**（實行從屬：正犯須著手，§29「實行」） |
| 「陷害教唆是否成立教唆犯？」 | **不成立**（欠缺正犯既遂故意＝無法益侵害意思） |
| 「欠缺教唆故意（玩笑話被當真）如何論罪？」 | 不成立教唆犯，但可能成立**過失犯正犯** |

## 正文

### 一、共同正犯的逾越與重結果（前導）

#### （一）過剩行為（共同正犯的逾越）

共同正犯成員做出**超出犯意聯絡範圍**之行為→該逾越部分其他人不負責。

- 越界與否是**事實認定**問題（如約定「教訓」是否涵蓋重傷？）

#### （二）加重結果犯的共同正犯

```
學說（通說）：否定
├── 理由：加重結果犯 = 故意 + 過失
│        過失犯無共同正犯
│        → 加重結果犯無共同正犯
└── 結論：只能個別認定，各自論罪

實務：肯定
├── 標準：客觀預見可能性
└── 結論：有客觀預見可能性者 → 全體負責
```

- 老師評價：近年考試重要性低

---

### 二、教唆犯的定義

> 唆使**原無犯意**者產生犯意 → 教唆犯
> 對方**已有犯意** → 精神幫助犯（非教唆犯）

#### 成立兩要件

| 要件 | 意義 | 不符合時 |
|------|------|---------|
| **對象特定** | 教唆特定之人 | 對象不特定 → §153 煽惑罪 |
| **罪名特定** | 教唆犯特定之罪 | 罪名不特定 → **無罪** |

---

### 三、煽惑罪（§153）

- **性質**：行為犯 / 抽象危險犯
- 不以有人被煽動為必要，只要**公然**為之即成立
- 三種態樣：煽惑犯罪、違背法令、抗拒合法命令

---

### 四、教唆行為

- **無方式限制**：言語、動作、暗示等均可

#### 勸阻教唆

> 勸說行為人實施**較低度**的犯罪（例如：原欲殺人，勸其改為傷害）

- 結論：**不算教唆**（屬降低風險，非製造風險）
- 考過 106 年海巡署考題（肇事逃逸案）

---

### 五、心理接觸（近年考 2 次以上！）

```
教唆犯是否需與被教唆人有心理接觸？
│
├── 噪音理論（少數說）
│   └── 只要引發犯意即可，不需心理接觸
│
└── 溝通理論（通說）
    ├── 教唆需心理接觸
    ├── 理由 ①：「教唆」語意→預設雙方溝通
    ├── 理由 ②：§30 I 後段有片面幫助規定
    │          §29 無類似規定 → 體系解釋不承認片面教唆
    └── 無心理接觸時 → 改論**精神幫助犯**（非無罪）
```

#### 經典考題：狗屎陷害案

- 考過：司三、警特四等
- 甲有意害乙被處罰，在乙門口放狗屎，乙果然因踩到而怒打路人
- 甲與乙無心理接觸 → 不成立教唆犯
- 甲非間接正犯（利用**動機錯誤**非間接正犯）
- 結論：改論精神幫助犯

### 六、加重構成要件的教唆

> 乙已有竊盜犯意，甲叫乙攜帶刀械去偷（§321 加重竊盜）

| 學說 | 結論 | 理由 |
|------|------|------|
| 教唆說（德國實務） | 甲成立 §321 教唆犯 | 甲引發加重要件的犯意 |
| **幫助說（多數說）** | 甲成立 §320 幫助犯 | 主要不法內涵在竊盜，乙原有竊盜犯意 |

### 七、共犯從屬性與正犯行為階段

#### （一）共犯從屬性

- 正犯須有**故意不法主行為**（限制從屬：該當＋違法＋故意犯）
- **過失犯不能被教唆**

#### （二）從屬性的兩面向

| 面向 | 內涵 |
|------|------|
| **要素從屬** | 正犯行為須該當且違法 |
| **實行從屬**（多數說） | 正犯須**著手**（§29「實行」→ 著手才有實行） |

#### （三）正犯行為階段對教唆犯的影響

```
時間軸：教唆 → 正犯產生犯意 → 陰謀/預備 → 著手 → 未遂 → 既遂
                                                │
                               ← 未遂教唆 →    ← 教唆未遂 →  ← 教唆既遂 →
```

| 正犯進度 | 教唆犯地位 | 結論 |
|---------|-----------|------|
| **既遂** | 教唆既遂 | 無爭議，依教唆之罪論 |
| **著手未既遂** | 教唆未遂 | 該罪罰未遂→可論；不罰未遂→教唆無罪 |
| **未著手（預備/陰謀/放棄）** | 未遂教唆 | 見下方三類分析 |

---

### 八、未遂教唆（被教唆人未著手的三種情況）

```
未遂教唆
├── 🔴 紅色：正犯未產生犯意／放棄
│   └── 不可罰（無爭議）
│
├── 🟡 黃色：正犯達陰謀/預備階段
│   ├── 該罪不罰預備 → 教唆無罪（無爭議）
│   └── 該罪有罰預備 → 爭議
│       ├── 肯定說（高金桂）：預備罪已該當違法 → 可從屬
│       └── 否定說（通說＋實務）：
│           ├── 共犯從屬性有「實行從屬」面向
│           ├── 正犯未著手 → 不滿足實行從屬
│           └── §29「實行犯罪行為」→ 要著手才有實行
│
└── 🟢 綠色：正犯已著手
    └── → 回歸「教唆未遂」處理（非未遂教唆）
```

#### 關鍵：肯定說 vs 否定說的爭議核心

- 肯定說：只看**要素從屬**（該當＋違法→可成立教唆犯）
- **否定說**：除要素從屬外，還要**實行從屬**（正犯須著手）→ 通說＋實務

---

### 九、教唆犯的主觀要件——雙重故意

所有共犯均要求雙重故意：

| 故意 | 內涵 |
|------|------|
| **教唆故意** | 行為人真的希望別人犯罪（不是講幹話） |
| **正犯既遂故意** | 希望正犯可以達於既遂 |

兩者缺一不可。

#### 陷害教唆（欠缺正犯既遂故意）

> 甲明知對面是空屋，叫乙去偷，再報警抓乙

- 形式理由：缺第二故意（正犯既遂故意）
- 實質理由：甲認知到法益侵害不可能 → 無法益侵害意思 → 不罰

#### 經典考題：法律系教授的玩笑話（虐童案）

**事實**：法律系教授甲面帶嚴肅對鄰居乙（公務員）說「把屁孩打爆沒關係，不要打死就好」，乙當真並傷害小孩

**分析**：
1. **正犯乙**：§277 傷害罪 + §286 凌虐幼童罪 → 想像競合
   - 乙的不法意識：可避免（公務員有基本法律常識）
2. **甲**：
   - 不成立傷害/凌虐教唆犯 → 甲無教唆故意（玩笑話、深感愧疚）
   - 成立 **§276 過失傷害罪的正犯**
   - 理由：法律系教授＋面帶嚴肅→可預見幹話被當真→有過失
   - 注意：過失犯**論正犯**（過失犯不區分正犯共犯）
