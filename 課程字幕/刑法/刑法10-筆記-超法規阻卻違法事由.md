## 📖 法條原文速查

> **§221**（強制性交罪）
> 對於男女以強暴、脅迫、恐嚇、催眠術或其他**違反其意願**之方法而為性交者，處三年以上十年以下有期徒刑。
> → 「違反意願」為核心要素 → 被害人同意（阻卻構成要件的同意）

> **§275**（加工自殺罪）
> I 受他人囑託或得其承諾而殺之者，處一年以上七年以下有期徒刑。
> → 被害人允諾侵害的第一類：轉而成立其他構成要件

> **§277**（傷害罪）
> I 傷害人之身體或健康者，處五年以下有期徒刑、拘役或五十萬元以下罰金。
> → 身體法益可處分 → 被害人承諾（阻卻違法的承諾）典型適用場景

> **§169**（誣告罪）
> I 意圖他人受刑事或懲戒處分，向該管公務員誣告者，處七年以下有期徒刑。
> → 保護國家法益＋個人法益 → 法益不許處分 → 承諾無效

> **毒品危害防制條例 §17 I**
> 犯第四條至第八條、第十條或第十一條之罪，供出毒品**來源**，因而查獲其他正犯或共犯者，減輕或免除其刑。
> → 供出上游案例 → 誣告罪法益不可處分之實務案例

> **教育基本法 §8 II**
> 學生之學習權、受教育權、身體自主權及人格發展權，國家應予保障，並使學生不受任何**體罰**，造成身心之侵害。
> → 教師懲戒權不成立阻卻違法事由之法律依據

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「被害人同意對§221 強制性交罪之效果？」 | **阻卻構成要件該當性**（同意 ≠ 承諾），因「違反意願」是構成要件要素 |
| 「被害人承諾傷害，是否阻卻違法？」 | **原則阻卻違法**（§277 身體法益可處分），但須符合六要件 |
| 「被害人承諾殺害自己的效果？」 | **不阻卻違法**，轉為成立 §275 加工自殺罪 |
| 「同意與承諾區別的實益？」 | **意思表示瑕疵效力不同**：同意有瑕疵→仍有效（構成要件不該當）；承諾有瑕疵→無效（仍構成犯罪） |
| 「法益關聯性理論：與法益無關的欺騙→承諾效力？」 | **原則有效**（捐血送餐券案）；**例外無效**（嚴重違反道德良知，如媽媽捐腎案） |
| 「被害人承諾能力是否以民法行為能力為準？」 | **否**，以具備「辨別事理能力」為準 → 成年不理智者無效、未成年有辨別力者有效 |
| 「推測的承諾之效力？」 | 合理推測被害人會同意即有效，**不因事後拒絕而無效** |
| 「教師懲戒權可否作為阻卻違法事由？」 | **不可**，教育基本法 §8 II 嚴禁體罰，業務正當行為、被害人承諾、超法規阻卻違法均不適用 |

## 一、超法規阻卻違法事由概論

超法規阻卻違法事由＝法律沒有明文規定，但學理上承認可以阻卻違法之事由。

核心代表：**被害人允諾侵害**

---

## 二、被害人允諾侵害的三分法

```
被害人允諾侵害
│
├── ① 轉而成立其他構成要件
│   └── 例：被害人同意被殺 → 不成立 §271 殺人 → 但成立 §275 加工自殺
│
├── ② 影響構成要件該當性 → 阻卻構成要件的「同意」
│   └── 例：§221 強制性交 →「違反意願」是構成要件核心
│         被害人同意 → 構成要件不該當 → 不成立犯罪
│
└── ③ 阻卻違法的「承諾」
    └── 例：§277 傷害罪 → 身體法益可處分
          被害人承諾被打 → 阻卻違法 → 不成立犯罪
```

---

## 三、同意 vs 承諾的區別

### （一）區別標準：構成要件的設計方式

| 比較項目 | 阻卻構成要件的同意 | 阻卻違法的承諾 |
|---------|------------------|---------------|
| 作用層次 | 構成要件該當性 | 違法性 |
| 適用場域 | 構成要件以「違反被害人意願」為核心要素的犯罪（如 §221） | 構成要件不以被害人意願為要素的犯罪（如 §277） |
| 判斷方式 | 有同意→構成要件不該當 | 有承諾→阻卻違法 |

### （二）區別實益：意思表示瑕疵的效力

| 瑕疵情形 | 阻卻構成要件的同意 | 阻卻違法的承諾 |
|---------|------------------|---------------|
| 有瑕疵時 | **仍有效**（構成要件不該當） | **無效**（仍構成犯罪） |
| 理由 | 即使被騙而同意，事實上仍「沒有違反意願」 | 承諾須出於自由意思，瑕疵影響其效力 |

#### §221 正確讀法

> 「違反其意願」＝核心要素。強制性交罪保護的不是「性的交往決定自由」（從舊法「致使不能抗拒」修改而來），而是「性自主權」。核心在於：被害人有沒有不同意？

## 四、被害人承諾的六大要件

### 要件一：法益有處分可能性

- 該法益必須是**被害人個人可處分**的法益
- **不可處分之例**：誣告罪（§169）→ 同時保護國家司法公正＋個人法益 → 因含國家法益，個人無法處分

#### 毒品案例（毒品 §17 I 供出上游）

甲被抓到持有毒品，想減刑，但他真的不知道上游是誰。他的朋友乙說：「你講我的名字，說我是上游，我被查到頂多毒品前科再加一條。」甲照做，供稱乙是上游，然後乙承認。

→ 甲成立 §169 誣告罪？乙的承諾有效嗎？
→ **無效**。誣告罪的保護法益包含國家司法權的正確行使（公正審判、偵查資源），不是純粹個人法益，個人不能處分。

### 要件二：處分權（生命、重大身體法益不可處分）

- **生命法益**：不可處分 → 承諾殺害轉為 §275
- **重大身體法益**：不可處分 → 如承諾截肢等重大傷害

### 要件三：承諾能力

- **不以民法行為能力為必要**
- 標準：有無「辨別事理的能力」
- **成年但不理智者**：承諾無效（如精神障礙者）
- **未成年但有辨別力者**：承諾有效（如 15 歲少年了解手術風險並同意）

### 要件四：出於自由意思（法益關聯性理論）

```
欺騙被害人而取得承諾
│
├── 法益「相關」的欺騙 → 承諾無效
│   ├── 定義：欺騙的內容涉及法益本身的品質、範圍、危險性
│   ├── 例：ATM 詐騙案（騙稱操作退款→實際盜轉帳戶）→ 財產法益直接被騙
│   ├── 例：注射鎮定劑案（護理師騙說打維他命→實際注射鎮定劑）→ 身體法益直接被騙
│   └── 結論：承諾無效 → 成立犯罪
│
└── 法益「無關」的欺騙 → 承諾原則有效
    ├── 定義：欺騙與法益本身無關，只涉及動機或目的
    ├── 例：捐血送餐券案（騙說餐券→實際沒有）→ 動機被騙，但身體法益沒有被騙
    ├── 結論：承諾仍有效 → 不成立犯罪
    │
    └── 例外：嚴重違反道德良知 → 承諾無效
        └── 例：媽媽捐腎案（兒子騙媽媽說自己腎衰竭→媽媽捐腎→實際兒子要賣腎賺錢）
             → 雖是法益無關欺騙（身體法益沒被騙），但嚴重違反道德良知 → 例外無效
```

### 要件五：承諾須事前為之

- 事後追認（事後同意）**不算**有效承諾
- 承諾必須在行為前或行為時存在

### 要件六：不違反善良風俗

- **通說**（肯定說）：承諾違反善良風俗者無效
  - 例：為詐領保險金而請人打斷自己的腿 → 承諾無效
  - 例：為逃避兵役而請人弄瞎自己的眼 → 承諾無效
- **反對說**：善良風俗要件畫蛇添足
  - 理由：上述案例可直接論行為人幫助詐欺等，不需要在承諾層次否定

### 少數說：不區分同意與承諾

- 主張：全部在構成要件層次處理
- 邏輯：被害人放棄法益 = 法益已捨棄 = 無法益侵害 = 構成要件不該當
- 結論：沒有違法性層次承諾的問題

## 五、推測的承諾

### 概念

- 被害人**無法表示意見**（昏迷、不在場等），但依客觀情況**合理推測**其會同意

### 案例：截肢案

#### 事實
1. 病患因手術中發現腿部壞死範圍超出預期
2. 當下無法詢問病患意見（全身麻醉中）
3. 醫師判斷不截肢會有生命危險，決定截肢

#### 分析
- 合理推測被害人會同意截肢（保命優先）
- **推測的承諾有效** → 阻卻違法
- **不因事後病患醒來拒絕而無效**（以行為時客觀判斷為準）

## 六、教師懲戒權

### 結論：現行法不承認教師懲戒權為阻卻違法事由

### 分析各種可能路徑

| 阻卻違法事由 | 能否適用 | 理由 |
|------------|---------|------|
| 業務正當行為 | ❌ | 教育基本法 §8 II 嚴禁體罰 → 體罰不是「正當」業務行為 |
| 被害人承諾 | ❌ | 學生（未成年人）難以有效承諾被體罰；且家長代為承諾亦有疑義 |
| 超法規阻卻違法 | ❌ | 法律明文禁止體罰 → 無超法規空間 |
| 林東茂老師有限度肯認說 | ❌ | 主張合理管教仍可阻卻 → 但與教育基本法 §8 II 嚴禁體罰之明文牴觸 |

> ⚠️ 校園霸凌處理與教師懲戒權是**不同議題**，不應混淆。
