# 刑法09 筆記：緊急避難法益衡量與強制性避難

> 來源：刑法09 課程字幕 00:36:00 ~ 01:24:00

## 📖 法條原文速查

> **§24**（緊急避難）
> I：因避免自己或他人生命、身體、自由、財產之緊急危難而出於不得已之行為，不罰。但避難行為過當者，得減輕或免除其刑。
> II：前項關於避免自己危難之規定，於公務上或業務上有特別義務者，不適用之。

> **§185-3**（不能安全駕駛罪）
> 駕駛動力交通工具而有下列情形之一者，處三年以下有期徒刑，得併科三十萬元以下罰金：
> 一、吐氣所含酒精濃度達每公升零點二五毫克或血液中酒精濃度達百分之零點零五以上。
> → 建議查閱最新六法原文

> **§185-4**（肇事逃逸罪）
> → 建議查閱最新六法原文（需注意憲法法庭判決後修正版本）

> **德國刑法 §34**（阻卻違法的緊急避難）
> 為排除他人生命、身體、自由、名譽、財產或其他法益的現實危險，出於不得已之行為，其**所保護利益明顯超過所侵害利益**時，該行為不違法。

> **德國刑法 §35**（免除罪責的緊急避難）
> 為排除自己、親屬或其他親近之人的**生命、身體、自由**之現實危險，所為不得已之行為，**無罪責**。
> → 注意：**無法益衡量要件**，且保護法益限於生命、身體、自由（不含財產）

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「為救傷患酒駕，可否主張緊急避難？」 | **看犧牲端的具體危險程度**：僅抽象危險→可避難；已達具體危險→不可 |
| 「生命對生命，法益衡量能否通過？」 | **不能**，生命不可量化比較，所有生命等價 |
| 「香蕉船案行為人之法律效果？」 | 通說：**避難過當**（§24 I 但書）；少數說（黃榮堅/許澤天）：免除罪責的緊急避難而**無罪** |
| 「我國§24是否隱含兩種避難？」 | 通說：否，僅阻卻違法一種；少數說：是，含阻卻違法＋免除罪責 |
| 「強制抽血救人可否緊急避難？」 | 多數說：**不可**，侵害人性尊嚴，非單純身體法益；少數說：可，僅身體＋自由 |
| 「強制性緊急避難之法律效果？」 | 阻卻違法說（通說）/ 免除罪責說 / 折衷說（區分情況） |
| 「法益侵害的總量如何影響衡平性？」 | 短暫自由 vs 巨額財產 → 量的因素可能翻轉結論 |

## 一、肇事逃逸與緊急避難

### 案例：肇事後被司機持刀追殺

#### 事實
1. 甲過失撞傷人，該當過失傷害罪
2. 被害方司機持開山刀追殺甲
3. 甲肇事逃逸（§185-4）

#### 分析
- 甲保全的法益：**生命**（面臨被砍殺的危險）
- 甲犧牲的法益：肇事逃逸保護的**國家社會法益**
- 生命 vs 國家社會法益 → **生命當然優先**
- 結論：可主張緊急避難阻卻違法

> **關鍵**：生命法益是最高價值，其他法益（含國家社會法益）對上生命，均應讓步。

## 二、免除罪責的緊急避難（德國 §34 vs §35）

### 核心問題：我國§24 只有一條，德國分兩條

```
德國刑法的緊急避難
│
├── §34 阻卻違法的緊急避難
│   ├── 有法益衡量要件（保全 > 犧牲）
│   ├── 效果：不違法（阻卻違法）
│   └── 對應我國 §24 前段
│
└── §35 免除罪責的緊急避難
    ├── 無法益衡量要件
    ├── 保護法益限於：生命、身體、自由
    ├── 對象限於：自己、親屬、親近之人
    ├── 效果：無罪責（免除罪責）
    └── 我國無對應條文 → 爭議所在
```

### 案例：香蕉船案

#### 事實
1. 甲乙駕駛香蕉船至海中，船翻覆
2. 兩人落海僅有一塊浮板
3. 甲搶走乙的浮板，乙因此溺斃
4. 甲該當殺人罪（§271 I）

#### 分析

##### （一）自招危難
- 甲不穿救生衣 → **過失自招**（注意：危難不是「船翻覆」本身，而是「船翻覆後甲在海上載浮載沉的生命危險狀態」→ 甲不穿救生衣有過失）
- 過失自招可否緊急避難？有可否兩說

##### （二）法益衡平性
- 生命 vs 生命 → **不可量化比較** → 衡平性不通過
- 結論：不能主張§24 I 前段阻卻違法

##### （三）罪責階段的效果

| 學說 | 效果 | 理由 |
|------|------|------|
| **通說** | §24 I 但書**避難過當**（有罪，得減免其刑） | 我國無類似德國§35之規定 |
| **少數說**（黃榮堅/許澤天） | **免除罪責的緊急避難而無罪** | §24隱含兩種避難，通不過法益衡量但符合§35要件者→免除罪責 |

##### （四）少數說的邏輯

```
§24 的兩種效果（少數說）
│
├── 通過法益衡量 → 阻卻違法而不罰
│
└── 通不過法益衡量
    └── 但符合德國§35要件（生命/身體/自由之危難）
        → 免除罪責而不罰
```

> **Entschuldigender Notstand**（免除/寬恕罪責的緊急避難）
> - 德文字源與 Entschuldigung（對不起）相近
> - 又譯「寬恕罪責」
> - 在德國法上 = 無罪；傳統我國學者移植後 = 避難過當（有罪）
> - 少數說主張：不能因為法律規定不好就讓行為人有罪

## 三、個人自主決定權

### 案例：強制抽血案

#### 事實
1. A 車禍失血過多，血型罕見，醫院缺乏該血型
2. 醫師得知義工 C 為該血型，要求 C 捐血，C 拒絕
3. 醫師強制拘束 C 身體並抽取血液

#### 爭點：法益衡平性能否通過？

| 學說 | 結論 | 理由 |
|------|------|------|
| **肯定說（少數）** | 可阻卻違法 | 犧牲端僅身體＋短暫自由；保全端為生命 → 衡平 |
| **否定說（多數）** | 避難過當 | 強制抽血 = 否定人格尊嚴，將人當成「供血機器」→ 侵害上升至**人性尊嚴**層次 |

> **重點**：多數說認為將人壓在地上抽血，已完全藐視其作為人的基本尊嚴，不僅是身體法益的問題。人性尊嚴 vs 生命 → 不可衡量。

## 四、法益損害的強度（法益總量觀點）

### 核心概念
- 生命不可量化比較 → 確定
- 但**生命以外的其他法益**，可考量「損害的強度」（法益侵害的總量）

### 酒駕緊急避難的判斷

#### 案例：為救傷患而酒駕

- 保全端：傷患的**生命**
- 犧牲端：公共安全（185之3 保護法益）
- 表面上：生命 > 公共安全 → 可避難

#### 關鍵判斷：犧牲端的危險程度

```
酒駕避難的法益衡量
│
├── 犧牲端僅抽象危險
│   （神智清醒＋途中零星車輛）
│   → 法益衡平通過 → 可主張緊急避難
│
└── 犧牲端已達具體危險
    （意識模糊＋車輛多＋數度差點追撞）
    → 法益衡平不通過 → 避難不成立
```

> **答題關鍵**：看行為人所犧牲的公共安全，究竟是**僅有抽象危險**，還是**已達具體危險**程度。

## 五、強制性緊急避難

### 定義
緊急避難的行為人**同時身兼強制罪的被害人**，即叫做強制性緊急避難。

### 案例

甲脅迫乙：「去砸丙的車，否則我持刀捅你。」
乙因恐懼而砸毀丙的車。

→ 乙 = 緊急避難行為人＋強制罪被害人

### 三說對照

| 學說 | 效果 | 核心理由 |
|------|------|---------|
| **阻卻違法說（通說）** | 乙阻卻違法 | §24未區分危難來源，不論危難是自然力或他人犯罪 |
| **免除罪責說** | 乙僅免除罪責 | 乙「利於不法之一方」＝與甲是一夥的，並非全然無辜 |
| **折衷說** | 區分情況 | 被脅迫者遭生命身體自由重大危險＋避難手段不傷害他人生命身體自由 → 阻卻違法；否則 → 僅免除罪責 |

### 區別實益

#### 1. 正當防衛──丙可否對乙正當防衛？

| 學說 | 丙能否對乙正當防衛？ | 理由 |
|------|---------------------|------|
| 阻卻違法說 | **不能** | 乙的行為合法 |
| 免除罪責說 | **能** | 乙的行為不法（僅免除罪責） |
| 折衷說 | 視情況 | 區分阻卻違法或免除罪責 |

#### 2. 共犯從屬──甲的論罪

- 甲脅迫乙犯罪 → 甲成立**強制罪**＋被脅迫罪名的**間接正犯**（強制支配）
- 若間接正犯不成立（如偽證罪為純正身分犯＋既遂犯 → 無法間接正犯）→ 考慮**教唆犯**
- 教唆犯需**共犯從屬**（正犯行為須該當且違法）
- 若乙阻卻違法 → 甲無從成立教唆犯
- 若乙僅免除罪責 → 乙行為仍違法 → 甲可成立教唆犯

### 退除役官轉任考/臺大法研所考題

- 甲脅迫乙作偽證 → 乙的偽證罪效果？
- 折衷說：乙未犧牲他人生命身體自由 → 可阻卻違法
