## 📖 法條原文速查

> **§10 IV**（重傷定義）
> 稱重傷者，謂下列傷害：一、毀敗或嚴重減損一目或二目之視能。二、毀敗或嚴重減損一耳或二耳之聽能。三、毀敗或嚴重減損語能、味能或嗅能。四、毀敗或嚴重減損一肢以上之機能。五、毀敗或嚴重減損生殖之機能。六、其他於身體或健康，有重大不治或難治之傷害。

> **§173 I**（放火燒燬現有人所在之建築物罪）
> 放火燒燬**現供人使用**之住宅或**現有人所在**之建築物、礦坑、火車、電車或其他供水、陸、空公眾運輸之舟、車、航空機者，處**無期徒刑或七年以上有期徒刑**。

> **§174 I**（放火燒燬現非有人所在之建築物罪）
> 放火燒燬**現未有人所在**之他人所有建築物、礦坑、火車、電車或其他供水、陸、空公眾運輸之舟、車、航空機者，處**三年以上十年以下有期徒刑**。

> **§195**（偽造貨幣罪）
> 意圖供行使之用，而偽造、變造**通用之貨幣、紙幣、銀行券**者，處五年以上有期徒刑，得併科五千元以下罰金。

> **§227 I**（對未滿十四歲之人為性交罪）
> 對於未滿十四歲之男女為性交者，處**三年以上十年以下有期徒刑**。

> **§227 III**（對十四歲以上未滿十六歲之人為性交罪）
> 對於十四歲以上未滿十六歲之男女為性交者，處**七年以下有期徒刑**。

> **§271 I**（殺人罪）
> 殺人者，處死刑、無期徒刑或十年以上有期徒刑。

> **§289**（加工墮胎罪）
> 受懷胎婦女之囑託或得其承諾，而使之墮胎者，處二年以下有期徒刑。

> **§291**（未受囑託墮胎罪）
> 未受懷胎婦女之囑託或未得其承諾，而使之墮胎者，處一年以上七年以下有期徒刑。

> **§306 I**（侵入住居罪）
> 無故侵入他人住宅、建築物或附連圍繞之土地或船艦者，處一年以下有期徒刑、拘役或九千元以下罰金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「構成要件選擇要素之間的錯誤是否影響故意？」 | **語言困難型不影響**（法律評價相同），**立法經濟型須依一般錯誤論處理**（法律評價不等） |
| 「甲以為燒的是無人建築（§174），實際有人（§173），如何論罪？」 | 採**P/非P解釋法**：§174為基本、§173為加重→至少成立§174既遂 |
| 「教唆對15歲性交（§227 III），正犯對13歲性交（§227 I），教唆犯之罪責？」 | 採包含關係解釋：§227 III為基本、§227 I為加重→教唆犯至少成立§227 III之教唆犯 |
| 「所知所犯原則是否為現代通說？」 | **否**，唐律公式已不採用，違反三階論體系 |
| 「§289（受囑託墮胎）與§291（未受囑託墮胎）是否為互斥構成要件？」 | **是**，但可用P/非P解釋為包含關係：§289為基本、§291為加重 |
| 「客體錯誤說與打擊錯誤說對雙重具體化錯誤的結論差異？」 | **客體錯誤說**（主流/許玉秀）：依因果鏈設定理論判斷→來發動車的人=故意既遂；**打擊錯誤說**→分論未遂+過失 |

## 一、雙重具體化錯誤（續）—政大轉學考汽車炸彈案

### 案例事實

1. 甲想殺 A，在 A 的車底裝設炸彈
2. 因果鏈設定：發動引擎 → 炸彈爆炸 → A 死亡
3. A 沒有開車，將鑰匙交給 B
4. A 自己坐在旁邊大樓頂樓女兒牆上眺望
5. B 發動車輛 → 炸彈引爆 → B 炸死
6. 爆炸震波 → A 從女兒牆墜落 → A 頭撞引擎蓋死亡

### 分析（許玉秀因果鏈設定理論）

```
甲對 B：
  B 的死亡方式 → 來發動車的人被炸死 → 符合因果鏈設定
  → 認定為「客體錯誤」 → 殺人既遂（§271 I）

甲對 A：
  A 的死亡方式 → 非發動車被炸死，而是震波墜樓
  → 不符合因果鏈設定
  → 認定為「打擊錯誤」 → 頂多論過失致死
```

### 三種學說

| 學說 | 代表/地位 | 甲對B | 甲對A |
|------|----------|-------|-------|
| **客體錯誤說** | 主流（許玉秀） | 殺人既遂 | 過失致死 |
| **打擊錯誤說** | 德國少數說 | — | — |
| **不區分說** | 不建議採 | — | — |

> ⚠️ 補充案例：維安人員擋子彈案 → 德國打擊錯誤說的論據

## 二、構成要件選擇要素

### 定義

條文中多個要素以「或」連接，符合**任一**即構成要件該當。

### 兩種類型

```
構成要件選擇要素
│
├── 語言困難型（法律評價相同）
│   ├── §306：住宅／建築物／附連圍繞土地／船艦
│   │   （四者無共同上位概念，純屬語言困難才分列）
│   └── §195：貨幣／紙幣／銀行券
│
│   ► 錯誤效果：不影響故意 → 仍論既遂
│
└── 立法經濟型（法律評價不等）
    └── §10 IV 重傷：各款事由之間（眼/鼻/嘴/四肢/生殖器）
        └── 不同身體部位的價值評價可能不同

    ► 錯誤效果：回歸一般錯誤論
      → 想像中的 → 論未遂
      → 實際發生的 → 阻卻故意改論過失
```

### 案例：菊島之星案（澎湖）

- **事實**：菊島之星外觀像遊輪，實為水泥建築物。侵入者以為侵入**船艦**，實際侵入**建築物**
- **分析**：§306 的船艦與建築物屬**語言困難型**選擇要素 → 法律評價相同 → 錯誤不影響故意 → 仍論§306既遂

## 三、排他互斥構成要件錯誤

> 參考文獻：蔡聖偉（2010）

### 定義

兩個條文的構成要件以**互斥排他**的要素區分（P vs 非P），行為人對此要素認識錯誤。

### 三大問題（許玉秀整理）

```
排他互斥構成要件
│
├── ① 構成要件錯誤
│     甲以為§174（無人）→ 實為§173（有人）
│
├── ② 共犯逾越
│     教唆§227 III → 正犯犯§227 I
│
└── ③ 事實不明
      無法證明流浪漢在廠內或廠外
```

### 問題一：構成要件錯誤

**案例：廢棄工廠放火案**
- 甲以為廢棄工廠無人（§174），放火後流浪漢逃出（實為§173）
- 若視為互斥 → §173 無故意（不知有人）、§174 無客觀要件（實際有人）→ 行為人兩罪皆不成立？→ 不合理

### 問題二：共犯逾越

**一般共犯逾越規則**：教唆犯與正犯所犯罪的**包含部分**成立共犯

| 案例 | 教唆內容 | 正犯實行 | 教唆犯罪責 |
|------|---------|---------|-----------|
| 一般案例 | 殺人 | 傷害 | 傷害教唆犯（殺人包含傷害） |
| 一般案例 | 傷害 | 性騷擾 | 無罪（無包含關係） |
| **互斥問題** | §227 III（對15歲性交） | §227 I（對13歲性交） | 若互斥→無包含→教唆犯無罪？→ **不合理** |

### 問題三：事實不明

- 放火燒廢棄工廠 + 流浪漢逃竄
- 無法證明流浪漢在放火當時**在廠內或廠外**
- §173 不能用（無法證明有人）+ §174 也不能用（無法證明沒人）
- → 行為人無罪？→ **罪疑惟輕的困境**

## 四、P/非P 解釋法（解決互斥構成要件問題）

### 核心思路

將互斥要素區分為：
- **P** = 建構不法的要素（增加不法內涵的要素）
- **非P** = 非建構不法的要素（在犯罪審查時可以不看）

**效果**：刪除「非P」後，兩罪變成**包含關係**（基本構成要件 + 加重構成要件）

### 應用

#### §173 / §174（放火罪）

```
P = 有人（建構不法要素：侵害生命安全）
非P = 沒有人（§174的「現非有人」→ 不看）

§174 只看 ABC（放火 + 燒毀 + 建築物）→ 基本構成要件
§173 看 ABC + P（放火 + 燒毀 + 建築物 + 有人）→ 加重構成要件

→ §174 為基本，§173 為加重
→ 以為§174實為§173 → 至少成立§174既遂
```

#### §289 / §291（墮胎罪）

```
P = 未受囑託/未得承諾（建構不法要素：侵害身體自主權）
非P = 受囑託/得承諾（§289的「受囑託」→ 不看）

§289 只看 AB（使懷胎婦女 + 墮胎）→ 基本構成要件
§291 看 AB + P（使懷胎婦女 + 墮胎 + 未受囑託）→ 加重構成要件

→ §289 為基本，§291 為加重
```

**東吳法律所考題**：以為孕婦同意（§289），實際不同意（§291）→ §291 無故意 → 至少論§289既遂

#### §227（與未成年人性交罪）

```
§227 III（14歲以上未滿16歲）→ 基本構成要件
§227 I（未滿14歲）→ 加重構成要件

→ 教唆§227 III，正犯犯§227 I → 教唆犯至少成立§227 III 教唆犯
```

## 五、「所知所犯」批判

- 「所知所犯」為**唐律公式**，現已不被採用
- 問題：違反三階論的犯罪審查體系
- 現代做法：依構成要件錯誤理論處理，而非以「所知所犯」簡化
