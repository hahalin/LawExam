# 刑法08 筆記：正當防衛—前提事實（現在不法侵害）

> 來源：刑法08 課程字幕 00:20:43 ~ 01:07:47

## 📖 法條原文速查

> **§23**（正當防衛）
> 對於現在不法之侵害，而出於防衛自己或他人權利之行為，不罰。但防衛行為過當者，得減輕或免除其刑。

> **§26**（不能未遂）
> 行為不能發生犯罪之結果，又無危險者，減輕或免除其刑。

> **§302**（私行拘禁罪）
> 私行拘禁或以其他非法方法，剝奪人之行動自由者，處五年以下有期徒刑、拘役或九千元以下罰金。

> **§315-1**（妨害秘密罪）
> 有下列行為之一者，處三年以下有期徒刑、拘役或三十萬元以下罰金：
> 一、無故利用**工具或設備**窺視、竊聽他人非公開之活動、言論、談話或身體隱私部位者。
> → 純肉眼偷窺不該當本罪

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「現在侵害與將來侵害之界線，有何學說？」 | ①著手標準說 ②有效防衛說（最寬） ③**預備最後階段說**（實務採） |
| 「家暴殺夫案（趁熟睡殺夫），各說能否正當防衛？」 | 著手標準說✗、預備最後階段說✗、**有效防衛說✓**（此為唯一能算現在侵害者） |
| 「預先設置防衛設備，是否對將來侵害之防衛？」 | **否**，無礙於現在侵害認定（看設備**何時起作用**，非何時設置） |
| 「現在侵害與過去侵害之區分標準？」 | **行為的終了**（法益侵害結束），非既遂、非完成 |
| 「繼續犯（如私行拘禁）既遂後，能否正當防衛？」 | **能**，繼續犯既遂≠終了，被害人被放出才終了，終了前都可防衛 |
| 「竊盜既遂後追逐中，能否正當防衛？」 | **能**，持有改變＝既遂，但持有穩固＝終了，追逐過程中持有未穩固 |
| 「不法侵害之不法，是否須具備罪責？」 | **不需要**（形式不法＝該當＋違法即可），對無罪責者可防衛但權限受限 |
| 「純民事不法可否正當防衛？」 | **多數說可以**（法秩序一體性）；少數說不可（刑法侵犯其他法領域） |
| 「純動物攻擊可否正當防衛？」 | **不可**（人的行為才有不法）；但動物背後有人為故意過失→可防衛 |
| 「不能未遂之侵害，屬正當防衛或誤想防衛？」 | 不能未遂＝**假侵害**，不是防衛對象；誤認為真→**誤想防衛** |

## 一、正當防衛的基本架構

```
正當防衛（§23）
│
├── 1. 前提事實：現在不法侵害
│   ├── 侵害要具有「現在性」
│   ├── 侵害要具有「不法性」
│   └── 必須是「人」所為的侵害
│
├── 2. 防衛行為：手段適當（不過當）
│
└── 3. 主觀要件：防衛意識
```

**基本想法**：面對不法侵害，被害人無義務向侵害者低頭 → 不用先躲避、不用先報警 → 有權直接打回去

## 二、現在侵害的認定

### 反面剔除法

```
將來侵害    →    現在侵害    →    過去侵害
           ↑                    ↑
       綠線（三說）          紅線（行為終了）

不是將來、不是過去 ＝ 現在侵害
```

### （一）將來 vs 現在的界線：三種學說

| 學說 | 標準 | 寬鬆度 | 備註 |
|------|------|--------|------|
| **著手標準說** | 侵害者行為已達未遂犯的著手階段 | 最嚴格 | 預備階段不可防衛 |
| **有效防衛說** | 錯過此時點，防衛將變困難或不切實際 | **最寬鬆** | 完全不問時空密接性 |
| **預備最後階段說** | 侵害者準備到「下一步就要動手」的最後一步 | 中間 | **實務採此說** |
| 具體危險說 | 遲延防衛會讓防衛不成功或承擔更大風險 | 接近有效防衛說 | 徐志人老師個人見解，少數說 |

### 案例演練

#### 案例一：平底鍋案

> 家暴父親在家中找人（找到就要打孩子），大兒子先下手為強，用平底鍋重擊爸爸後腦勺。

| 學說 | 結論 | 理由 |
|------|------|------|
| 著手標準說 | ✗ 非現在侵害 | 爸爸還在找人，未著手 |
| 有效防衛說 | ✓ 現在侵害 | 等找到就被打了 |
| 預備最後階段說 | ✓ 現在侵害 | 找人是動手前最後一步 |

#### 案例二：家暴殺夫案

> 嬌小妻子（150cm/40kg）長期遭受館長體型丈夫家暴，趁丈夫喝醉熟睡時持刀刺殺。

| 學說 | 結論 | 理由 |
|------|------|------|
| 著手標準說 | ✗ | 丈夫在睡覺 |
| 有效防衛說 | **✓** | 丈夫醒來後妻子毫無勝算，熟睡時是唯一有效時點 |
| 預備最後階段說 | ✗ | 丈夫仍在睡覺，不算最後準備階段 |

> ⚠️ 歷久不衰考點，近年仍有轉學考出題

#### 案例三：KTV持槍案（101年國考經典題）

> 持槍歹徒進入KTV在走廊找包廂，服務生先發制人將歹徒打倒。

| 學說 | 結論 | 理由 |
|------|------|------|
| 著手標準說 | ✗ | 還在找包廂，未著手 |
| 有效防衛說 | ✓ | 找到包廂就開槍了 |
| 預備最後階段說 | ✓ | 找包廂是動手前最後一步 |

### （二）預先設置防衛設備

- **結論**：無礙於現在侵害的認定（**無爭議**）
- **理由**：不看設備何時設置，**看設備何時起作用**
- 例：圍牆通電蛇籠20年前設置 → 小偷來爬牆時起作用 → 至少已著手入侵住宅
- ⚠️ 僅現在性過得了，防衛手段是否過當要另行判斷（家用電OK，高壓電過當）

### （三）現在 vs 過去的界線：行為的終了

| 概念 | 定義 | 區分意義 |
|------|------|---------|
| **既遂** | 構成要件實現 | 大多數狀態犯：既遂＝終了 |
| **終了** | **法益侵害的結束** | 正當防衛的最後時點 |
| **完成** | 行為人主觀計畫完成 | ≠ 終了（相續共同正犯的認定會用到） |

```
既遂 ≠ 終了 的犯罪類型
│
├── 繼續犯（如 §302 私行拘禁）
│   ├── 既遂：鎖進倉庫的瞬間
│   └── 終了：被放出來的時候
│   → 既遂後、終了前仍可正當防衛
│
└── 財產犯罪（如竊盜）
    ├── 既遂：持有關係改變（手機拿到手上）
    └── 終了：持有穩固（跳上計程車離開）
    → 追逐過程中持有未穩固，仍可正當防衛
```

## 三、不法侵害的認定

### （一）形式不法：該當＋違法即可

- 通說：**不需要罪責**（法條寫「不法侵害」，非「犯罪行為」）
- 對無罪責者（如精神病患）：**可以防衛，但防衛權受限**（社會倫理限制）

### （二）純民事不法

| 立場 | 結論 | 理由 |
|------|------|------|
| **多數說** | **可以**正當防衛 | **法秩序一體性**：民法可防衛（§149），刑法不讓防衛會矛盾 |
| 少數說 | 不可以 | 刑法侵犯其他法領域：刑事庭須偷偷判斷民事侵權是否成立 |

**常見純民事不法案例**：
- 用肉眼偷窺（§315-1 要求「工具或設備」）
- 使用竊盜（偷騎別人腳踏車）
- 在耳邊低聲罵人（未達公然侮辱）

### （三）人的行為才有不法

```
攻擊來源
├── 純動物攻擊 / 自然力 → 無不法 → ✗ 不可正當防衛（可論緊急避難）
└── 動物背後有人為故意過失
    ├── 故意放狗咬人 → ✓ 可正當防衛
    └── 過失未繫狗鍊致狗咬人 → ✓ 可正當防衛
```

### （四）假侵害（不能未遂）

- 侵害行為根本**自始不存在威脅性** → 假侵害 → **不是正當防衛的對象**
- 若誤認假侵害為真 → **誤想防衛**（容許構成要件錯誤）
- 案例：拿水槍討債（109年調工組考題），被害人太太誤以為是真槍而捅死對方 → 誤想防衛

### （五）純國家社會法益犯罪

- **不可正當防衛**
- 理由（林山田）：維護國家社會秩序是**警察的任務**，一般平民不應自行執法
- 例：看到有人公然猥褻、擺攤賣違禁品 → 報警即可，不可動手

### （六）為第三人防衛（緊急救助）

- 正當防衛**可以為第三人為之**
- 最低限度：**第三人不能明確反對**
- 例：看到屁孩欺負流浪漢 → 可為流浪漢防衛 → 但若流浪漢說「不要管我」→ 防衛權消滅
- 學術名詞：**緊急救助**（周揚儀老師用語）
