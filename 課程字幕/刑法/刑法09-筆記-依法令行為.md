# 刑法09 筆記：依法令行為

> 來源：刑法09 課程字幕 01:44:00 ~ 02:26:00

## 📖 法條原文速查

> **§21**（依法令之行為）
> I：依法令之行為，不罰。
> II：依所屬上級公務員命令之行為，不罰。但明知命令違法者，不在此限。

> **民法 §151**（自助行為）
> 為保護自己權利，對於他人之自由或財產施以拘束、押收或毀損者，不負損害賠償之責。但以不及受法院或其他有關機關之援助，並非於其時為之，則請求權不得實行或其實行顯有困難者為限。

> **民法 §1084**（父母之保護教養義務）
> II：父母對於**未成年**之子女，有保護及教養之權利義務。

> **民法 §1085**（父母之懲戒權）
> 父母得於必要範圍內，懲戒其**子女**。
> → 注意：條文僅寫「其子女」而非「未成年子女」→ 爭議

> **刑訴 §88**（現行犯之逮捕）
> I：現行犯，不問何人得逕行逮捕之。
> II：犯罪在實施中或實施後即時發覺者，為**現行犯**。
> III：有左列情形之一者，以現行犯論（**準現行犯**）：
> 一、被追呼為犯罪人者。
> 二、因持有**兇器、贓物**或其他物件、或於身體、衣服等處露有犯罪痕跡，顯可疑為犯罪人者。

> **優生保健法 §9**（人工流產之事由）
> → 六款事由：①②④胎兒有缺陷或有事實足疑、③母體有問題、⑤被性侵、⑥影響心理健康或家庭生活
> → 第六款幾乎架空墮胎罪

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「民法§151自助行為之要件？」 | **不及受官署援助**＋非於其時為之則請求權不得實行 → 例外允許自力救濟 |
| 「父母懲戒權可否及於成年子女？」 | 刑法學說：**僅限未成年子女**（§1085僅寫「其子女」但§1084限縮為「未成年子女」） |
| 「現行犯 vs 準現行犯之區別？」 | 現行犯 = 實施中或實施後即時發覺；準現行犯 = 被追呼 / 持有兇器贓物等 |
| 「被追呼之『追呼』是擇一或並存？」 | 通說：**擇一**即可（被追或被呼均可成立準現行犯） |
| 「現行犯逮捕抓錯人，是否合法？」 | 通說：**合法**（程序情勢判斷：外觀上像現行犯即可，不因事後發現未犯罪而違法） |
| 「現行犯逮捕會不會變誤想？」 | **很難**但非不可能。外觀上根本不像現行犯卻被逮捕 → 才會變容許構成要件錯誤 |
| 「現行犯逮捕與正當防衛競合時寫哪個？」 | 看題目線索：有「解送檢警」→ **寫現行犯逮捕**；無解送 → **寫正當防衛** |
| 「被逮捕者自認無辜而反擊，是誤想防衛嗎？」 | **不是**。那是§16 法律意識的欠缺（對法律的誤認），非對事實的誤認 |
| 「人工流產第六款的效果？」 | 幾乎使墮胎罪**名存實亡**，絕大多數要人工流產的情況均可通過 |

## 一、自助行為（民法 §151）

### 核心要件
- 為保護**自己的權利**
- **不及受法院或其他有關機關之援助**
- 非於其時為之，則請求權**不得實行或實行有困難**

### 法理基礎
權利原則上禁止自力救濟，原因：
1. 避免回到叢林法則（拳頭大就贏）
2. 避免球員兼裁判（寬鬆判斷要件）

自助行為 = 禁止自力救濟之**例外**

### 案例：老人電動代步車肇事逃逸

#### 事實
1. 你的車停在白色停車格
2. 一位老人騎電動代步車撞壞你的車門和保險桿
3. 老人撞完騎車要跑
4. 你衝上前拔掉電動代步車鑰匙，通知警方處理

#### 分析
- 你可能該當**剝奪行動自由罪**
- 但可主張**自助行為**阻卻違法
- 關鍵：電動代步車**沒有車牌** → 老人跑了就找不到 → 當下不攔住，日後無從求償

> **為何不用一般肇事逃逸舉例？**
> 一般機車/汽車有**車牌**→ 記下車牌報警即可 → 無「不及受官署援助」之急迫性 → 不符自助行為要件。

## 二、父母懲戒權（§1084 / §1085）

### 行使限制

| 限制 | 說明 |
|------|------|
| 手段不能過當 | 所有阻卻違法事由之共通要求 |
| **僅限未成年子女** | §1084 II 明寫「未成年子女」→ 限縮§1085之「其子女」 |

### 條文爭議

```
§1084 II：父母對於「未成年」子女有保護教養之權利義務
          ↓
§1085：父母得懲戒「其子女」（未寫「未成年」）
          ↓
文義上：似乎可懲戒成年子女？
          ↓
刑法學說：不可。對成年子女無法想像何為「合理不過當」的懲戒
```

- 有親屬法學者認為：父母可懲戒成年子女
- **刑法學者（通說）**：僅限未成年子女。德國學說亦同。

## 三、現行犯逮捕（刑訴 §88）

### （一）基本架構

```
現行犯逮捕 §88
│
├── 現行犯（§88 II）
│   └── 犯罪在實施中 or 實施後即時發覺
│
├── 準現行犯（§88 III）
│   ├── 一、被追呼為犯罪人（追 or 呼，擇一即可）
│   └── 二、持有兇器、贓物或其他物件，或身體衣服有犯罪痕跡
│
└── 效果：不問何人得逕行逮捕
    └── 逮捕 = 逮捕行為 ＋ 解送檢警機關（二者缺一不可）
```

### （二）贓物的定義差異

| 法領域 | 贓物定義 | 範圍 |
|--------|---------|------|
| **刑訴（準現行犯）** | **一切犯罪所得** | 較廣 |
| **刑法 §349（贓物罪）** | **財產犯罪所得** | 較窄（僅限竊盜、詐欺等財產犯罪之所得） |

### （三）逮捕 vs 正當防衛的競合

| 題目線索 | 優先採用 | 理由 |
|---------|---------|------|
| 有「解送檢警機關」 | **現行犯逮捕** | 逮捕要件完整（逮捕＋解送） |
| 無「解送檢警」描述 | **正當防衛** | 未解送→逮捕要件不全，寫正當防衛更安全 |

> 兩者可擇一成立即阻卻違法，看題目給什麼線索往有利方向寫。

### （四）抓錯人──程序情勢判斷

#### 通說（多數說）
現行犯逮捕屬**強制處分**→ **形式上判斷**：
- 逮捕當下，該人**外觀上像是現行犯** → 合法逮捕
- 不因事後發現未犯罪而改變逮捕的合法性

#### 案例：剪腳踏車鎖

- 晚上10點多，拿老虎鉗在捷運站旁邊剪自己腳踏車的車鎖
- 外觀上 = 竊盜犯
- 若被路人扭送警局 → **合法逮捕**（通說）

#### 會不會變誤想（容許構成要件錯誤）？

```
現行犯逮捕與誤想
│
├── 通常不會 → 程序情勢判斷，外觀像就合法
│
└── 極少數例外：客觀上根本不像現行犯卻被逮捕
    └── 例：下課後戴墨鏡穿花襯衫走路被認為猥褻犯
        → 這才可能構成違法逮捕 = 容許構成要件錯誤
```

> **結論**：現行犯逮捕只是**很難**變誤想，**不是永遠不會**。

### （五）被合法逮捕者的反擊

- 合法行為的相對人**要忍受** → 不能正當防衛、不能緊急避難
- 若被逮捕者自認無辜而反擊 → **不是誤想防衛**（非對事實的誤認）
- 而是 **§16 法律意識的欠缺**（對法律的誤認）

### （六）考試寫作順序

> 涉及正當防衛的考題，同時問到防衛者與侵害者時 → **先寫侵害者**
> 須先確認侵害者行為不具不法性，防衛者的論述才寫得下去。

## 四、人工流產與墮胎罪

### 優生保健法 §9 六款事由分類

```
人工流產事由
│
├── 胎兒有問題：第1、2、4款
│   └── 胎兒有缺陷或有事實足以懷疑
│
├── 母體有問題：第3款
│   └── 母體身體健康有問題
│
└── 孕婦心理不適合：第5、6款
    ├── 第5款：被性侵而懷孕
    └── 第6款：懷孕或生產影響心理健康或家庭生活
         └── → 幾乎可涵蓋所有不想懷孕的情況
```

### 第六款的效果
- 「影響心理健康或家庭生活」→ 範圍極廣
- 一般女性想人工流產幾乎都符合第六款
- 結果：**墮胎罪幾乎名存實亡**

### 人工流產的法律限制

| 限制 | 學者批評 |
|------|---------|
| 24週以內 | 一般認為合理（孕婦安全＋胎兒漸有人形） |
| 未成年人需法代同意 | **不合理**：反而增加未成年人風險（找密醫、買黑市藥、拖到生下來） |
| 受監護/輔助宣告者之限制 | --- |
| 有配偶者需**配偶同意** | **極不合理**（王皇玉老師批評）：子宮是太太的，配偶同意權侵害身體自主權 |

### 人工流產 = 阻卻違法事由
- 性質：**權利**，不是「看你可憐不罰你」
- 是一種依法令行為（§21 I）的阻卻違法
