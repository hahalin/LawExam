# 刑法14 筆記：連鎖共犯與身分共犯

> 來源：刑法14 課程字幕 01:58:00 ~ 02:37:09

---

## 📖 法條原文速查

> **§28**（共同正犯）
> 二人以上共同實行犯罪之行為者，皆為正犯。

> **§29**（教唆犯）
> I：教唆他人使之實行犯罪行為者，為教唆犯。
> II：教唆犯之處罰，依其所教唆之罪處罰之。

> **§30**（幫助犯）
> I：幫助他人實行犯罪行為者，為幫助犯。雖他人不知幫助之情者，亦同。
> II：幫助犯之處罰，得按正犯之刑減輕之。

> **§31**（身分犯之共犯）
> I：因身分或其他特定關係成立之罪，其共同實行、教唆或幫助者，雖無特定關係，仍以**正犯或共犯**論。但得減輕其刑。
> II：因身分或其他特定關係致刑有重輕或免除者，其無特定關係之人，科以**通常之刑**。

> **§271**（普通殺人罪）
> I：殺人者，處死刑、無期徒刑或十年以上有期徒刑。

> **§272**（殺直系血親尊親屬罪）
> 殺直系血親尊親屬者，處死刑或無期徒刑。
> → 不純正身分犯（加重型態）

> **§274**（生母殺嬰罪）
> → 不純正身分犯（減輕型態）→ 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「教唆教唆應如何論罪？」 | **教唆犯**（實務＋學說一致） |
| 「教唆幫助應如何論罪？」 | 實務：**幫助犯**；許玉秀說：**幫助犯**（結論同） |
| 「幫助教唆應如何論罪？」 | 實務：**幫助犯**；許玉秀說：**教唆犯**（結論不同！） |
| 「幫助幫助應如何論罪？」 | **幫助犯**（實務＋學說一致） |
| 「無身分者參與純正身分犯，如何論罪？」 | §31 I：以身分論→**仍成立該罪正犯或共犯** |
| 「無身分者參與不純正身分犯，如何論罪？」 | §31 II：**科以通常之刑**（打回原形→論基本罪） |
| 「§31 II 共同正犯應如何書寫？」 | **先基本再變體**：先兩人成立基本罪共正→再有身分者獨自成立變體 |
| 「兩人一同勸說正犯犯罪，是否為幫助教唆？」 | **不是**，兩人均為教唆犯（各自論教唆） |

## 正文

### 一、連鎖共犯

> 行為人的行為**不是直接作用在正犯身上**，而是作用在另一個共犯身上

#### 四種類型

| 類型 | 範例 |
|------|------|
| **教唆教唆** | A 告訴 B：請 B 委託 C 殺 D |
| **教唆幫助** | A 知道 C 要殺 D、苦無工具，叫 B 給 C 手槍 |
| **幫助教唆** | B 想唆使 C 殺 D 但不知如何說起，A 提供說服技巧 |
| **幫助幫助** | C 要殺 D，B 想給 C 槍但不知去哪買，A 介紹買槍管道 |

#### 兩種學說

```
連鎖共犯如何論罪？
│
├── 實務說（林鈺雄老師補理由）
│   ├── 教唆教唆 → 論教唆
│   ├── 教唆幫助 → 論幫助
│   ├── 幫助教唆 → 論幫助
│   └── 幫助幫助 → 論幫助
│   理由：教唆＞幫助（不法內涵）→ 取包含部分
│
└── 許玉秀說（依正犯所得助力決定）
    ├── 教唆教唆 → 論教唆（正犯得到教唆）
    ├── 教唆幫助 → 論幫助（正犯得到幫助）
    ├── 幫助教唆 → 論教唆（正犯得到教唆）★
    └── 幫助幫助 → 論幫助（正犯得到幫助）
```

| 類型 | 實務說 | 許玉秀說 | 差異 |
|------|--------|---------|------|
| 教唆教唆 | 教唆 | 教唆 | 同 |
| 教唆幫助 | 幫助 | 幫助 | 同 |
| **幫助教唆** | **幫助** | **教唆** | **不同** |
| 幫助幫助 | 幫助 | 幫助 | 同 |

#### ⚠️ 常見陷阱：「幫助教唆」的認定

兩人一起幫腔勸說正犯犯罪 → **不是**幫助教唆 → 是兩人**各自論教唆犯**

真正的幫助教唆範例：
- 提供說服技巧（讓教唆更容易）
- 勸被教唆者留下來聽教唆犯講話
- 撮合教唆犯與正犯認識

兩個以上的人一起做共犯行為 → **無「共同共犯」**（§28 僅規範共同正犯）→ 各自獨立論罪

### 二、身分犯的基本概念

#### 純正身分犯 vs 不純正身分犯

```
身分犯
├── 純正身分犯
│   ├── 定義：身分是犯罪成立的**不可或缺要素**
│   ├── 無身分 → 無法成立該犯罪（本質上不可能）
│   ├── 範例：貪汙犯罪中的「公務員」身分
│   └── 適用 §31 I
│
└── 不純正身分犯
    ├── 定義：身分僅影響犯罪的**輕重**，不影響成立
    ├── 無身分 → 回歸基本構成要件
    ├── 範例：§272 殺直系血親尊親屬（加重）
    │        §274 生母殺嬰（減輕）
    └── 適用 §31 II
```

---

### 三、§31 I 純正身分犯的參與

#### （一）共同正犯

> 無身分者 + 有身分者 → §31 I：無身分者**仍以正犯論**

- 經典記憶：**阿扁與阿珍**
  - 阿扁（公務員）收賄 → 貪汙罪
  - 阿珍（家庭主婦，無公務員身分）與阿扁一同收賄
  - → §31 I 以身分論 → 阿珍仍為共同正犯

- 學說有反對意見（犯罪支配論例外說→無身分者只能論幫助犯），但§31 I 明文「仍以正犯或共犯論」→ 立法論建議，非解釋論

#### （二）間接正犯

```
情境一：有身分者利用無身分者
├── 範例：公務員（阿扁）騙太太去收取「禮品」（實為賄賂）
└── 結論：公務員成立間接正犯（無爭議，有身分者本就可犯）

情境二：無身分者利用有身分者（有爭議！）
├── 範例：太太騙公務員丈夫去收賄，丈夫不知情
├── 學說：否定
│   ├── 無身分就是無身分
│   └── 不因利用他人而取得身分
└── 實務：肯定
    └── 可成立間接正犯（直接下結論，未附理由）
```

#### （三）教唆犯 / 幫助犯

- 非公務員教唆公務員收賄 → 非公務員論收賄罪教唆犯（§31 I）（無爭議）
- 公務員教唆非公務員收賄 → 學說認為非公務員只能論幫助犯，公務員論間接正犯（較特殊）

### 四、§31 II 不純正身分犯的參與

#### 基本原則：**先基本再變體**

⚠️ §31 II 的文義（「無特定關係之人，科以通常之刑」）容易讓人操作錯誤

#### ❌ 錯誤操作（先變體再退回）

1. 甲（有身分＝生母）＋ 乙（無身分）共同棄嬰
2. → 兩人成立 §274 生母殺嬰共同正犯
3. → 乙無身分，依 §31 II 退回 §271 普通殺人
- ❌ 邏輯顛倒：先論變體再退基本

#### ✅ 正確操作（先基本再變體）

1. **第一標**：甲乙共同棄嬰行為 → 成立 **§271 普通殺人未遂的共同正犯**
2. **第二標**：甲（生母）另成立 **§274 生母殺嬰罪未遂**
3. **競合**：甲同時成立 §271 與 §274 → **法條競合特別關係** → 論 §274

```
§31 II 的正確書寫流程
│
├── Step 1：所有人成立基本構成要件的共同正犯（如 §271）
├── Step 2：有身分者另獨自成立變體構成要件（如 §274）
└── Step 3：有身分者以法條競合處理（特別關係→論變體）
```

### 五、教唆犯與身分犯

| 情境 | 教唆人 | 正犯 | 教唆人論罪 |
|------|--------|------|-----------|
| 有身分教唆無身分 | 甲（子女）叫乙殺甲父 | 乙：§271 | 甲：**§272 教唆犯** |
| 無身分教唆有身分 | 乙叫甲殺甲父 | 甲：§272 | 乙：**§271 教唆犯** |

- 有身分者論有身分之罪，無身分者論無身分之罪，各論各的

#### 考題陷阱：「共謀」≠共同正犯

- 題目出現「共謀」二字 → **不等於共謀共同正犯**
- 「共謀」是日常用語，指兩人有討論
- 教唆犯與正犯當然也會交流討論
- 要看**行為分擔**才能決定是共正還是教唆

#### 考題陷阱：「分手威脅」≠間接正犯（強制支配）

- 強制支配要求被威脅者有成立**緊急避難**的空間
- 用「分手威脅」叫人殺母 → 一般人不會因此殺人、無緊急避難空間
- → 不成立間接正犯，仍論**教唆犯**
