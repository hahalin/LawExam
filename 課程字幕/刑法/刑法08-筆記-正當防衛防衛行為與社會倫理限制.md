# 刑法08 筆記：正當防衛—防衛行為、社會倫理限制與防衛過當

> 來源：刑法08 課程字幕 01:07:48 ~ 01:56:10

## 📖 法條原文速查

> **§23**（正當防衛）
> 對於現在不法之侵害，而出於防衛自己或他人權利之行為，不罰。但防衛行為過當者，得**減輕或免除**其刑。

> **德國刑法§33**（免除罪責的防衛過當）
> 出於慌亂、恐懼、驚嚇而超越防衛行為的尺度者，不罰。

> **§16**（法律上之錯誤 / 禁止錯誤）
> 除有正當理由而無法避免者外，不得因不知法律而免除刑事責任。但按其情節，得減輕其刑。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「正當防衛之防衛手段，是否適用比例原則？」 | **否**，正當防衛只看**適當性＋必要性**，**不做衡平性判斷** |
| 「防衛失敗是否仍可成立正當防衛？」 | **可以**，有效＝客觀上有可能消滅侵害，不需實際成功 |
| 「正當防衛必要性判斷是否包括逃跑報警？」 | **否**，逃跑報警不列入考量，正當防衛賦予直接反擊權 |
| 「正當防衛的社會倫理限制有哪些類型？」 | ①極端失衡 ②對無責任能力者攻擊 ③家庭成員間攻擊 ④挑唆防衛 |
| 「哪些社會倫理限制會直接否定防衛權？」 | **極端失衡**＋**意圖式挑唆防衛**（最嚴重兩種） |
| 「哪些社會倫理限制改採三階段防衛？」 | 對無責任能力者攻擊、家庭成員攻擊、**非意圖式**挑唆防衛 |
| 「延展型防衛過當之定義？」 | 防衛**時間不適當**（侵害已結束後繼續防衛），又稱擴張型 |
| 「延展型防衛過當的適用前提？」 | ①僅限侵害**開始後** ②**局勢底定不適用** |
| 「免除罪責的防衛過當要件？」 | 客觀過當＋主觀出於**軟弱情緒**（慌亂、恐懼、驚嚇）→ 無罪 |
| 「打架互毆不能證明誰先動手，能否正當防衛？」 | 舊實務：雙方**都不準**（違反罪疑惟輕）；學說：**雙方都可以**防衛 |
| 「防衛行為犧牲無辜第三人之物，對第三人論何罪？」 | 對第三人只能論**緊急避難**（正當防衛只能對不法侵害者主張） |

## 一、防衛行為的要件

### 適當性＋必要性（無衡平性）

```
防衛手段判斷
├── 適當性：防衛行為必須有效（客觀上有可能消滅侵害）
│   ├── 不需實際成功 → 防衛失敗仍可認正當防衛
│   └── 無效手段 ✗（如刺破輪胎使車更開不走 → 報復非防衛）
│
├── 必要性：所有有效手段中損害最小
│   ├── ≠ 純粹損害最小（逃跑報警不列入考量）
│   └── 參酌雙方年齡、性別、體力、有無武器
│
└── ✗ 不做衡平性判斷
    ├── 正當防衛 ≠ 比例原則（比例原則 = 適當＋必要＋衡平）
    └── 為奪回財產而使小偷受傷 → 可以正當防衛
```

> ⚠️ 考試不能寫「正當防衛的判斷就是比例原則」，因為正當防衛不做衡量性判斷

## 二、正當防衛的社會倫理限制（權利濫用禁止）

### 四種類型與效果總覽

| 類型 | 效果 | 記憶口訣 |
|------|------|---------|
| ①**極端失衡** | **否定防衛權** | 最嚴重之一 |
| ②對無責任能力者的攻擊 | **三階段防衛** | — |
| ③家庭成員間的攻擊 | **三階段防衛** | 有反對意見 |
| ④**意圖式挑唆防衛** | **否定防衛權** | 最嚴重之二 |
| ④非意圖式挑唆防衛 | **三階段防衛** | — |

> 記法：**最嚴重兩種**（極端失衡＋意圖式挑唆）→ 否定防衛權；**其餘** → 三階段防衛

### （一）極端失衡 → 否定防衛權

- 為保護**微小利益**而犧牲對方**嚴重法益**
- 例：為奪回喝剩不到一半的礦泉水，將小偷絆倒從七樓滾到六樓致腦震盪
- ⚠️ 不是一般違反衡平性（一般不看衡平性），而是**極端**失衡

### （二）對無責任能力者的攻擊 → 三階段防衛

```
三階段防衛（限攻擊性行為）
│
├── 第一步：迴避（先試著逃跑）
│
├── 第二步：保護性防禦（用後背包等抵擋）
│
└── 第三步：攻擊性防衛（不得已才可反擊）
```

- 對象：小孩、精神病患、智能障礙者等
- **僅限攻擊性行為**才有三階段防衛的適用
  - 小學生搶手機 → 不需先逃跑（無攻擊性）
  - 小學生揮拳攻擊 → 要做三階段

### （三）家庭成員間的攻擊 → 三階段防衛

- 同樣適用三階段防衛
- **反對意見**（許志仁、周揚儀老師）：
  1. **助長家暴**：被家暴者不應被要求先忍受
  2. **無法選擇家庭成員**：原生家庭非本人意志可決定，為何要多承擔義務？

### （四）挑唆防衛

| 類型 | 定義 | 效果 |
|------|------|------|
| **意圖式** | 假借防衛之名，行攻擊之實（故意設局激怒對方） | **否定防衛權** |
| **非意圖式** | 言語尖酸但非故意設局（講話不好聽激怒對方） | **三階段防衛** |

### 罪刑法定問題

- 社會倫理限制是**法無明文**的限制
- 在無罪規定（§23）上添加法律沒有的限制 → 使行為人更難獲判無罪
- 正當化論證：權利濫用禁止是**所有法律的共同原則**，可上溯至憲法層次

## 三、防衛過當（§23 但書）

### 效果定位：放在罪責（非違法性）

```
正當防衛 → 阻卻違法（§23 本文）
防衛過當 → 不阻卻違法，在罪責減輕或免除（§23 但書）
```

### （一）強度型防衛過當

- 違反**適當性**：選擇無效手段
- 違反**必要性**：非損害最小的有效手段
- 違反社會倫理限制（非否定防衛權類型）：該做三階段而未做

### （二）延展型（擴張型）防衛過當

- **定義**：防衛的**時間不適當**（侵害已結束後繼續防衛）
- **來源**：許恆達老師2012年文章引入，德國刑法本有此概念
- **學界態度**：中生代學者普遍支持（許玉秀、林書楷、許澤天等均介紹）

```
案例：歹徒性侵 → 我拿石頭丟歹徒 → 歹徒倒地（侵害結束）
                                          ↓
         傳統見解：區分事實錯誤（誤想防衛）/ 法律錯誤（§16禁止錯誤）
                                          ↓
         延展型防衛過當：後段整體視為防衛過當 → 可減輕或免除（更有利）
```

**適用前提**：
| 限制 | 說明 |
|------|------|
| ①僅限侵害**開始後** | 侵害開始前的防衛（如打詐騙集團）不適用 |
| ②**局勢底定不適用** | 歹徒當場昏迷喪失意識 → 防衛者處於絕對優勢 → 不再適用 |

### （三）免除罪責的防衛過當（德國刑法§33）

| 要件 | 內容 |
|------|------|
| **客觀** | 防衛過當（強度型或延展型均可） |
| **主觀** | 出於**軟弱情緒**（慌亂、恐懼、驚嚇） |
| **效果** | **無罪**（免除罪責，無期待可能性） |

```
情緒類型
├── 軟弱情緒：慌亂、恐懼、驚嚇 → 免除罪責的防衛過當 → 無罪
└── 強勢情緒：憤怒、想攻擊 → 一般防衛過當 → 僅得減輕或免除
```

## 四、正當防衛的主觀要件

- **防衛意思 ＝ 認知即可**
- **不需要防衛意欲**（不需真心想保護權利）

案例：在仇人車下裝炸彈，發現小偷要偷車，為保存炸彈而與小偷扭打
→ 動機不良善（不是為保護車主）→ 但有認知到侵害存在 → **仍可正當防衛**

## 五、打架互毆與正當防衛

| 情形 | 舊實務見解 | 學說見解 |
|------|-----------|---------|
| 能證明誰先動手 | 先動手方不可防衛 | 同（合理） |
| **不能證明誰先動手** | 雙方**都不準**防衛 | 依**罪疑惟輕**，雙方**都可以**防衛 |

- 舊實務的問題：不能證明 → 兩方都不準 → 等於**罪疑為重**，違反刑事訴訟基本原則

## 六、防衛行為與第三人

- 正當防衛 → **只能對不法侵害者主張**
- 緊急避難 → **無此限制**
- 結論：為防衛而犧牲無辜第三人之物 → 對第三人只能論**緊急避難**
