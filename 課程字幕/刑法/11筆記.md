# 刑法11——不法與罪責之外的可罰性要件 ＆ 未遂犯

---

## 一、不法與罪責之外的可罰性要件（第六章）

- 位於三階論（該當→違法→有責）之後的「第四階段」
- 在罪責審查結束後才討論的要件

---

### （一）客觀處罰條件

#### 1. 概念

- **無關不法**（與法益侵害無關）
- **無關罪責**（與期待可能性無關）
- 國家純粹基於**刑事政策考量**所設置的可罰性條件

#### 2. 最大特色

- **故意不用對它有認知**
- 只要客觀上該條件存在，即認為條件成就
- 也是**罪疑惟輕的例外**（不適用有利被告的推定）

#### 3. 功能：限縮刑罰事由

| 錯誤理解 | 正確理解 |
|---|---|
| 把難以證明行為人認知的東西都歸為客觀處罰條件 → 擴張刑罰權 | 多加一個要件 → 讓犯罪成立多一道篩選門檻 → **限縮刑罰** |

- 不能將客觀處罰條件當作擴張刑罰的工具，否則違反刑法§12「行為非出於故意或過失不罰」

#### 4. 判斷公式

> 把疑似是客觀處罰條件的部分**遮住**，看法益侵害是否仍然存在：
> - 遮住後法益侵害**不存在** → 百分之百是**構成要件要素**
> - 遮住後法益侵害**仍存在** → 有可能是**客觀處罰條件**

#### 5. 案例分析

| 條文 | 項目 | 遮住後 | 是否為客觀處罰條件 |
|---|---|---|---|
| §238 詐術締婚罪 | 「因而致婚姻無效或撤銷裁判確定」 | 光以詐術締結無效婚姻 → 已侵害婚姻秩序 | ✅ 是（無爭議） |
| §227 與未滿14歲人性交 | 被害人年齡 | 單純與人性交 → 無法益侵害 | ❌ 不是（年齡是構成要件要素） |
| §283 聚眾鬥毆致死傷 | 致人於死或重傷 | 多數說認為是客觀處罰條件（分則再詳述） | ✅ 多數說 |
| §185-3 酒駕罪 | 酒測值數字 | 喝酒本身不是客觀處罰條件，**酒測值數字**才是 | ✅ 酒測值是 |
| §130 廢弛職務釀成災害 | 釀成災害 | 有爭議（柯耀成老師過去主張，現已少人支持） | 爭議 |
| §185-4 肇事逃逸（2021修法後） | 致人死傷 | 法定刑範圍由死傷狀況決定 → 與不法高度相關 | ❌ 修法後不可採 |

- **酒駕罪補充**：行為人不需知道具體酒測值，但必須意識到自己有喝酒且不適合開車
  - 被害人飲料被人摻入酒精而不自知 → 不成立§185-3（連喝酒都不知道）

### （二）個人阻卻刑罰事由 & 解除刑罰事由

#### 1. 個人阻卻刑罰事由（行為時即存在）

- **§288第三項**（墮胎罪）：因疾病或防止生命危險必要而犯罪 → 免除其刑
  - 現無適用空間：孕婦為避免生命危險而人工流產，可依優生保健法阻卻違法
  - 個人看法：比較像緊急避難的除外規定
- **§275第四項**（加工自殺罪）：約為同死而犯前三項之罪 → **得**免除其刑
  - 理由：相約自殺活下來的人也是想死的人，對其論罪科刑反而不利生命保護
  - **自殺不是犯罪的理由**：
    - 本質論：自己是生命的主人，處分自己生命未傷害他人
    - 技術面：既遂→被告死亡無法罰；未遂→罰反而不利生命保護

#### 2. 解除（減免）刑罰事由（犯罪後才發生）

- 代表：**中止未遂**
- 臺灣用語問題：德國中止未遂是無罪（所以叫「解除」），我國中止未遂仍有罪 → 蔡聖偉老師認為應叫**「減免刑罰事由」**

## 二、未遂犯

---

### （一）犯罪的行為階段

```
決意 → 陰謀 → 預備 → 著手 → 完成 → 既遂 → 終了
```

| 階段 | 意義 | 說明 |
|---|---|---|
| **決意** | 腦中浮現犯罪想法 | 刑法不罰思想，決意不可能成立犯罪 |
| **陰謀** | 兩人以上共同謀議 | 僅內亂外患等國家存在犯罪有罰 |
| **預備** | 犯罪準備階段 | 少數犯罪才處罰 |
| **著手** | 開始做構成要件行為 | 著手 = 未遂的起點 |
| **完成** | 行為做完 | 行為層面結束 |
| **既遂** | 構成要件完全實現 | 犯罪成立 |
| **終了** | 法益侵害結束 | 非所有犯罪都有（狀態犯既遂即終了） |

- **完成 ≠ 終了**：完成是行為結束，終了是法益侵害結束
- **既遂後至終了前**的區間僅存在於**繼續犯**、**財產犯罪**等少數犯罪

#### 思想犯的條文注意

- **§348-1 準擄人勒贖罪**：「擄人後意圖勒贖者」→ 條文字面無行為要件，須加上勒贖行為才不淪為思想犯
- **§335 侵佔罪**：傳統說「易持有為所有」= 主觀想法改變瞬間 → 亦須有外在行為

---

### （二）預備犯

#### 1. 形式預備犯（條文直接寫「預備」）

> **口訣：內外放火殺強人 + 一架飛機**（蔡聖偉老師原創圖，飛機為老師自加）

| 口訣 | 犯罪 | 條文 |
|---|---|---|
| 內 | 內亂罪 | §100 等 |
| 外 | 外患罪 | §103 等 |
| 放火 | 放火罪 | §173 |
| 殺 | 殺人罪 | §271③ |
| 強 | 強盜罪 | §328③⑤ |
| 人 | 擄人勒贖罪 | §347 |
| 飛機 | 劫持民用航空器罪 | §185-1 |

#### 2. 實質預備犯（本質為預備但條文未寫「預備」）

- **§199**：意圖偽造貨幣而收集器械原料 → 實質上是§195的預備
- **§187**：意圖供犯罪之用而持有軍用槍砲子彈
  - 「軍用」= 性能上可供軍事使用（手槍即算）
  - 考試有拿槍的題目，不要忘記§187

#### 3. 形式預備犯的正當性爭議

- 批評：「準備行為」範圍太廣（買刀、比價、調查行蹤……都算準備），不符法律明確性
- 回應：預備行為須限於**重要的準備行為**才算

---

### （三）未遂犯的處罰根據

| 學說 | 核心主張 | 支持者 |
|---|---|---|
| **客觀未遂論** | 未遂行為有法益侵害的**危險** | 留日老師居多 |
| **主觀未遂論** | 未遂犯與既遂犯一樣壞（法敵對意思） | 歷史說法，幾乎無人採 |
| **主客觀混合理論（印象理論）**（德國通說） | 行為人透過行為展現法敵對意思 → 一般人產生**法律秩序被動搖的印象** | 留德老師居多 |

- 印象理論本質上是主觀理論，但加上客觀行為的展現作為限制

---

### （四）未遂犯的四大要件

1. **故意**
2. **著手**
3. **不遂**（客觀構成要件未完全實現）
4. **法律明文**（須有處罰未遂的規定）

- **§277 普通傷害罪沒有罰未遂**，考試不要寫「傷害未遂」
- 「不遂」不只是結果未發生，客觀構成要件六要素（主體、客體、行為、結果、因果關係、情狀）任一未實現都是未遂

---

### （五）著手的認定

#### 1. 四種學說

| 學說 | 主張 | 評價 |
|---|---|---|
| **形式客觀說** | 開始做嚴格意義的構成要件行為 | 歷史說法，標準太嚴格 |
| **實質客觀說（行為危險說）** | 行為對法益產生**迫切危險** | 留日老師多採 |
| **主觀說** | 行為人覺得開始做的時點 | 歷史說法，技術上難判斷 |
| **主客觀混合說**（通說） | 判斷對象：行為人犯罪計畫（主觀）；判斷標準：一般人標準有無迫切危險（客觀） | 目前通說 |

- **實質客觀說 vs 主客觀混合說的核心差別**：判斷對象不同
  - 客觀說 → 純客觀事實
  - 混合說 → 行為人腦中的犯罪計畫
- 差別最大之處：**不能未遂案例**（如花蓮開槍案）

#### 2. 著手認定的各種案例

##### （1）已做構成要件行為 → 原則上著手

- 實務案例：男生套上保險套，距女生陰道約三公分 → 已著手（104年判決）

##### （2）隔離犯的著手（行為完成到犯罪實現間有時間/空間/需被害人配合的間隔）

| 學說 | 主張 | 嚴格程度 |
|---|---|---|
| **嚴格個別理論**（實務） | 做完行為即著手 | 最寬鬆 |
| **修正個別理論** | 損害流程失控、行為人想挽回也來不及時 | 中間 |
| **整體理論**（許恆達老師） | 被害人端也進入損害攻擊範圍時 | 最嚴格 |

- 隔離犯著手理論 = 間接正犯的著手理論

##### （3）尚未進行構成要件行為

- 進入客廳物色財物 → 主客觀混合說：著手；實質客觀說：不一定

##### （4）結果提前發生案例

- 行為人計畫用安眠藥迷昏再持刀殺，誤拿毒藥致中毒
  - 實質客觀說 → 著手（客觀上就是毒藥）
  - 主客觀混合說 → 未著手（犯罪計畫中用安眠藥→離殺人還遠）

##### （5）加重構成要件的著手

- **一律回歸基本構成要件認定**，不以加重事由判斷著手
- 範例：加重竊盜（§321）侵入住宅 → 著手是因為已開始搜尋財物（§320的基本構成要件），非因§321
- §222第四款以藥劑犯姦 → 下藥即著手，因為下藥本質是§221的強暴行為

### （六）普通未遂的法律效果

- §25：**得減輕其刑**（可減可不減，通常會減）
- 傳統稱「障礙未遂」（日語用語），現多稱「普通未遂」

---

### （七）不能未遂（§26）

#### 1. 條文與要件

> §26：行為**不能發生犯罪之結果**，又**無危險**者，**不罰**。

| 要件 | 說明 |
|---|---|
| 不能發生犯罪結果 | 篩選意義不大，幾乎所有未遂都套得出來 |
| **無危險** | 判斷關鍵 |

- 2006年修法後改為不罰（之前有罪）
- 不能未遂在預備階段 → 舉重明輕，當然也不罰

#### 2. 不能發生犯罪結果的三種類型

| 類型 | 說明 | 例子 |
|---|---|---|
| **主體不能** | 因誤認**事實**而以為自己是主體 | 業務經理不知被開除，仍出去簽約背信 |
| **客體不能** | 行為客體不存在 | 對已死之人開槍、被害人不在家時掃射 |
| **手段不能** | 手段無法遂行犯罪 | 槍枝射程不夠、毒藥劑量不足 |

- **主體不能的正確理解**：指事實誤認（不知已被開除），非法律評價的誤認（保全不知自己非公務員 → 非主體不能）

#### 3. 無危險的判斷（三說）

| 學說 | 判斷視角 | 標準 | 評價 |
|---|---|---|---|
| **客觀危險說** | 事後判斷 | 自始不能=無危險（絕對不能）；偶然因素=有危險（相對不能） | 歷史說法，貫徹則所有未遂都變不能未遂 |
| **具體危險說（新客觀說）** | 事前一般理性第三人 | 該領域旁觀者是否會覺得有危險 | 通說／多數說 |
| **重大無知說** | 日常生活知識 | 行為人出於日常生活知識的重大無知 → 無危險 | 留日老師多採 |

##### 客觀危險說的批評

- 事後（上帝視角）來看，將來發生什麼都已知道 → 幾乎所有未遂都「無危險」
- 比喻：恐怖片看第二遍不會恐怖

##### 具體危險說的特色

- 危險不是事實，是**價值判斷**、是**感受**
- 旁觀者在專業領域須為具有專門知識的人
  - 製毒案 → 懂製毒的旁觀者判斷
  - 但販毒 → 不需要專業旁觀者（販毒不需專業）

##### 重大無知說的案例

| 重大無知（不罰） | 非重大無知（有罰） |
|---|---|
| 用彈弓射民航機 | 誤算槍枝射程 |
| 給孕婦喝菊花茶使其流產 | 算錯毒品提煉方式 |
| 給糖尿病患喝全糖飲料致死 | 算錯毒藥劑量 |
| 以為田徑裁判起跑槍是真槍 | 誤拿腸胃藥當毒藥 |

##### 三說比較案例

| 案例 | 客觀危險說 | 具體危險說 | 重大無知說 |
|---|---|---|---|
| 乙已被甲射殺，丙不知乙死再刺兩刀 | 無危險 | 有危險 | 有危險 |
| 搶警察配槍但沒裝子彈即開槍 | 無危險 | 有危險 | 有危險 |
| 把腸胃藥誤認為毒藥拿去毒人 | 無危險 | **有危險** | **無危險**（非重大無知但…） |
| 拿不存在面額的外幣去銀行兌換 | 無危險 | 無危險 | 無危險 |

- 具體危險說與重大無知說結論大多相同，差異案例：搞錯容器內裝物（非日常知識的重大無知，但旁觀者看不出）

#### 4. 迷信犯

- 定義：透過自然科學無法驗證的方式實現犯罪（如扎稻草人）
- **不具規範上的意義**，只是現象描述
- 須先確認有無故意：
  - 半信半疑、單純願望 → 無故意
  - 真的確信 → 有故意 → 不能未遂（手段不能＋無危險）→ 不罰
- 考試不用特別提「迷信犯」概念

#### 5. 不能未遂在三階論的定位

| 定位 | 說明 | 支持者 |
|---|---|---|
| **構成要件不該當**（紅色線） | 不能未遂無著手（客觀著手理論下） | 留日老師 |
| **三階外的阻卻刑罰事由**（黃色線） | 該當違法有責，但基於刑事政策不罰（事理上的阻卻刑罰事由） | 蔡聖偉老師（學理主流） |

- 蔡聖偉老師的論理：
  - 罰未遂犯的目的 = 維護行為規範的效力
  - 不能未遂行為即使不罰，也不會有人想模仿 → 不會破壞行為規範效力 → 無處罰必要

#### 6. 區別實益

##### 主要實益：共犯（教唆犯 / 幫助犯）

- 共犯成立前提 = 正犯須**該當且違法**（共犯從屬性）

| 定位 | 正犯（不能未遂行為人） | 共犯能否成立 |
|---|---|---|
| 構成要件不該當（紅色線） | 連構成要件都不該當 | ❌ 不能成立共犯 |
| 三階外（黃色線） | 該當＋違法＋有責，僅三階外不罰 | ✅ 可能成立共犯 |

- 範例：確信扎稻草人可殺人，跟神壇師父要稻草人 → 師父是否成立幫助犯？取決於定位

##### 正當防衛

- **通說：不能對不能未遂正當防衛**
  - 構成要件不該當說 → 無不法，無從防衛
  - 三階外說 → 雖有不法，但不能未遂對法益無危險 → 不構成「侵害」
  - 連結前面：假性侵害的概念（P147）

### 本堂課重點回顧

1. **客觀處罰條件**：無關不法罪責、故意不用認知、限縮刑罰事由、遮住公式判斷
2. **犯罪行為階段**：決意→陰謀→預備→著手→完成→既遂→終了
3. **有罰預備的犯罪**：內外放火殺強人＋飛機
4. **未遂犯處罰根據**：印象理論（通說）
5. **著手認定**：主客觀混合說（通說）—以犯罪計畫為判斷對象，一般人標準判斷迫切危險
6. **隔離犯著手**：嚴格個別理論（實務）vs 整體理論（許恆達老師）
7. **加重構成要件著手**：一律回歸基本構成要件
8. **不能未遂§26**：不能發生結果＋無危險→不罰
9. **無危險判斷**：具體危險說（多數說）、重大無知說
10. **不能未遂定位**：三階外阻卻刑罰事由（學理主流），主要區別實益在共犯
