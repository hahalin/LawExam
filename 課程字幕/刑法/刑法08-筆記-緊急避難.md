# 刑法08 筆記：緊急避難

> 來源：刑法08 課程字幕 01:56:11 ~ 02:40:54

## 📖 法條原文速查

> **§24**（緊急避難）
> I 因避免自己或他人**生命、身體、自由、財產**之緊急危難而出於不得已之行為，不罰。但避難行為過當者，得減輕或免除其刑。
> II 前項關於避免自己危難之規定，於公務上或業務上有特別義務者，不適用之。

> **§23**（正當防衛）
> 對於現在不法之侵害，而出於防衛自己或他人**權利**之行為，不罰。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「緊急避難的法理基礎為何？」 | **社會連帶**：社會成員互助，犧牲小利益救助他人 |
| 「§24 所列法益是例示或列舉？」 | 爭議。講師支持**列舉說**（體系解釋：§23 僅寫「權利」，§24 特別列四種→有意限縮） |
| 「緊急避難與正當防衛在必要性判斷上的差異？」 | 正當防衛**不需**考慮逃跑報警；緊急避難須**不得已＝除此手段別無他法** |
| 「家暴殺夫案能否主張緊急避難？」 | 前提事實可能成立（**持續性危險**→急迫危難）；但**避難手段往往過不去**（可逃跑報警） |
| 「合法行為的相對人能否主張緊急避難？」 | **不能**（否則法律秩序矛盾）；合法行為非危難 |
| 「故意自招危難能否緊急避難？」 | **不可以**（嚴重權利濫用，無爭議） |
| 「過失自招危難能否緊急避難？」 | **學說多數：可以**（白目但非嚴重權利濫用）；**實務：不可以** |
| 「攻擊型緊急避難的衡平性要求？」 | 保全法益必須**大於**犧牲法益（等於不可） |
| 「為救五人犧牲一人，可否緊急避難？」 | **不可以**。生命不可量化比較，刑法採**康德義務論** |
| 「公務業務上有特別義務者可否緊急避難？」 | 原則不可（§24 II）；例外：**法律不要求履行無效義務** |

## 一、緊急避難的法理基礎：社會連帶

- 被犧牲者通常無辜（與正當防衛不同）
- 為何無辜者要被犧牲？→ **社會連帶**
  - 社會成員非原子式存在，應發揮互助精神
  - 別人遇到危險時，犧牲一點利益去幫助他 → 對整體更好

## 二、攻擊型 vs 防禦型

```
緊急避難
├── 攻擊型：犧牲無辜第三人（考試九成考這種）
│   例：被豬追 → 跳入鄰居庭院（鄰居無辜）
│
└── 防禦型：犧牲對象 = 危難來源本身（非無辜）
    例：被臺灣黑熊攻擊 → 打死黑熊（黑熊是危難來源）
```

> ⚠️ 不要記「緊急避難就是正對正」→ 防禦型是對危難來源，不一定正對正

## 三、避難前提：急迫危難

### （一）法益範圍：生命、身體、自由、財產

| 學說 | 範圍 | 理由 |
|------|------|------|
| **例示說** | 不以此四種為限，名譽、隱私、國家社會法益均可 | 保護範圍不應過窄 |
| **列舉說**（講師採） | 僅此四種 | 體系解釋：§23 寫「權利」，§24 特別列四種→立法者有意限縮，因緊急避難犧牲無辜，不宜擴大社會連帶 |

### （二）急迫危難的兩種型態

| 型態 | 定義 | 例子 |
|------|------|------|
| **迫在眼前的危險** | 危險正在發生 | 黑熊朝你衝來 |
| **持續性的危險** | 未爆彈，何時爆不知道，但高度可能變成實害 | 地震傾斜的房屋；長期家暴的配偶 |

#### 家暴殺夫案的緊急避難分析

```
正當防衛 ✗ → 先生熟睡中無「現在侵害」（通說）
         ↓
緊急避難 → 持續性的危險 → 急迫危難 ✓
         ↓
但手段：不得已？ → 可逃跑、報警 → 手段往往過不去 ✗
```

### （三）合法行為不是避難對象

- 合法行為之相對人 → 不能正當防衛 + **也不能緊急避難**
- 理由：否則法律秩序產生矛盾（警察合法逮捕→犯人對警察緊急避難？不可能）

## 四、避難行為：必要性（不得已）

### 不得已 ＝ 除此手段，別無他法

| 項目 | 正當防衛 | 緊急避難 |
|------|---------|---------|
| 逃跑報警 | 不列入考量 | **須考慮** |
| 嚴格程度 | 有效手段中損害最小 | **除此手段別無他法** |
| 結論 | 較寬鬆 | **較嚴格** |

不得已的案例分析：

| 案例 | 可否緊急避難 | 理由 |
|------|------------|------|
| 傷患送醫→搶路人汽車 | ✗ | 可打119 |
| 被暴力討債→侵佔公款 | ✗ | 可報警、逃跑、另借錢 |
| 被狗攻擊→拿C古董花瓶反擊（而非B的傘） | ✗ | 有其他手段可用 |

> **能用正當防衛就優先用**：比特犬攻擊案（主人有不法→正當防衛）若改用緊急避難，必須證明不得已（旁邊有樹可爬→過不了手段要件）

## 五、避難限制

### （一）公務或業務上有特別義務者（§24 II）

- 適用對象：**警消、保全**（最常見）
- 效果：不得主張緊急避難（避免自己危難部分不適用）

| 案例 | 可否緊急避難 |
|------|------------|
| 第一天上班的員警遇槍戰→躲進民宅 | ✗（公務上有特別義務） |
| 銀樓保全發現小偷有刀→放任小偷離開 | ✗（業務上有特別義務） |

### （二）例外：法律不要求履行無效義務

- 手術房火災案例：全麻手術進行中→火勢猛烈→醫護留下也救不了人
- 結論：醫護**可以離開**（留下來只是大家一起死＝無效義務）

## 六、自招危難

### 故意自招 vs 過失自招

| 區分 | 定義 | 能否緊急避難 |
|------|------|------------|
| **故意自招** | 假借避難之名，行損害他人之實（有設局意圖） | **不可以**（無爭議） |
| **過失自招** | 白目但無設局意圖 | 學說多數：**可以**；實務：**不可以** |

```
案例：逗山豬
├── 過失自招：看到告示牌「山豬兇猛」仍去逗 → 白目但無意圖
│   → 學說：可緊急避難 / 實務：不可
│
└── 故意自招：為了吃松阪豬肉而設局激怒山豬 → 假借避難之名
    → 不可緊急避難（嚴重權利濫用）
```

> 實務否定過失自招的理由：做錯事在先→引發的危難應自己承擔，不應找無辜第三人扛

## 七、攻擊型緊急避難的衡平性

### 保全法益 > 犧牲法益（大於才可以）

```
法益位階排序（由高到低）
生命 ＞ 身體 ＞ 自由 ＞ 財產

✓ 保全生命 → 犧牲居住自由（跳入別人庭院躲避）
✗ 保全生命 → 犧牲他人生命（抓小孩去餵山豬）→ 等於不可以
```

### 生命法益的最高位階性

- 任何法益碰到生命都居下風
- 生命 vs 國家法益 → **生命重要**（生命是一切價值的根本）
- 生命 vs 社會法益 → **生命重要**

### 生命不可量化比較

- 多數人的生命 **≠** 優於少數人的生命
- 不能為拯救五人而犧牲一人
- 不能為拯救天才而犧牲智能障礙者
- **每一條命都等價**

#### 電車難題

| 版本 | 大眾道德直覺 | 刑法立場 |
|------|------------|---------|
| 轉轍器版（搬動讓車撞死1人救5人） | 多數說「要搬」 | **不可以** |
| 胖子版（把胖子推下天橋擋車救5人） | 多數說「不推」 | **不可以** |

- 刑法採**康德義務論**（非功利主義）：犧牲少數救多數 → 不可以
