# 刑法07 筆記：因果歷程偏離與結果時序錯誤

> 來源：刑法07 課程字幕 00:56:00 ~ 01:44:00

---

## 📖 法條原文速查

> **§13 I**（直接故意）
> 行為人對於構成犯罪之事實，**明知並有意使其發生**者，為故意。

> **§13 II**（間接故意）
> 行為人對於構成犯罪之事實，**預見其發生**而其發生並**不違背其本意**者，以故意論。

> **§55**（想像競合）
> 一行為而觸犯數罪名者，從一重處斷。但不得科以較輕罪名所定最輕本刑以下之刑。

> **§247**（侵害屍體罪）
> 損壞、遺棄或盜取屍體者，處六月以上五年以下有期徒刑。

> **§271 I**（殺人罪）
> 殺人者，處死刑、無期徒刑或十年以上有期徒刑。

> **§276**（過失致死罪）
> 因過失致人於死者，處五年以下有期徒刑、拘役或五十萬元以下罰金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「因果歷程偏離是否一律阻卻故意？」 | **否**：細節性不重要偏差（刺胸→脖、毒肝→腎）不算偏離，仍可論故意既遂 |
| 「行為人想毒死人，蘑菇非有毒而是腐敗致死，如何論罪？」 | 風險認識說：未認知客觀風險→阻卻故意→**分論未遂（想像毒死）+過失致死（腐敗致死）→§55** |
| 「結果提前發生的通說標準？」 | **著手標準說**：著手前結果實現→過失犯；著手後結果實現→故意既遂 |
| 「結果延後發生的通說處理？」 | **第一行為關鍵說**：死因偏差為不重要偏差→故意殺人既遂 |
| 「結果延後發生放在三階論何處討論？」 | **客觀歸責（風險實現）**；結果提前發生放在**主觀（故意）** |
| 「概括故意說為何被批評？」 | 混淆了**故意**與**犯罪計畫**的概念，棄屍階段行為人無殺人故意 |

## 一、因果歷程偏離

### 定義

行為人意圖實施犯罪且結果確實發生，但**實現結果的過程**與行為人的想像不同。

### 類型區分

```
因果歷程偏離
│
├── 細節性不重要偏差 → 不算「偏離」→ 仍論故意既遂
│   例：刺胸→刺脖 / 毒肝→毒腎 / 放火→逃生墜樓死
│
└── 一般偏離（反常因果歷程）→ 客觀歸責處理
    例：被害人送醫後死於救護車車禍
    → 風險未實現 → 論未遂犯
```

### 故意對因果歷程認知的三說

| 學說 | 代表 | 核心主張 |
|------|------|---------|
| **重要性理論** | 早期學說 | 偏離「重要」則阻卻故意，但標準模糊 |
| **否定說** | 少數說 | 因果歷程非故意認識對象 |
| **風險認識說** ✅ | 蔡聖偉、許玉秀 | 行為人對**客觀上所製造的風險**有認知 → 有故意 |

### 案例：蘑菇案（北大法律所考題）

#### 事實
1. 甲以為蘑菇有毒，將腐敗蘑菇給乙食用
2. 蘑菇其實無毒，但因腐敗導致乙食物中毒死亡

#### 風險認識說分析

```
客觀風險：蘑菇腐敗 → 食物中毒致死
甲的認知：蘑菇有毒 → 中毒致死

甲認知的風險 ≠ 客觀實現的風險
→ 甲未認知客觀風險 → 阻卻故意

分論：
① 殺人未遂（想像中毒死，未實現）
② 過失致死（實際腐敗致死，甲有注意義務違反）
→ §55 想像競合，從一重處斷
```

### 110年律師高考案例：放火逃生案

- 甲放火燒住宅，被害人**未燒死**而是逃生墜樓死亡
- 通說：死因偏差為**細節性不重要偏差** → 故意殺人既遂

## 二、結果提前發生

### 定義

犯罪結果**比行為人預想的時間更早**實現。

### 與「事前故意非故意」的關聯

- 結果在著手前發生 → 行為人想殺人的想法尚非刑法上的殺人故意 → 事前故意非故意 → 過失犯

### 學說比較

#### （一）著手標準說（德國通說）✅

```
結果實現時點
│
├── 著手前 → 事前故意非故意 → 論過失犯
│
└── 著手後 → 已在故意行為階段 → 論故意既遂
```

**案例3：瞄準走火案**
- 甲瞄準乙，尚未扣扳機，槍枝走火擊中乙死亡
- 瞄準 = 著手 → 著手後結果實現 → **故意殺人既遂**

**案例4：分次下毒案**
- 甲計畫分5次下毒，第2次乙即死亡
- 開始下毒 = 著手 → 著手後結果實現 → **故意殺人既遂**

#### （二）計畫完成標準說 / 主觀決定說（少數說，兩說近似）

- 行為人須在主觀上出現「該做的都做完了，剩下聽天由命，想回頭也來不及了」的想法
- 有此想法 + 結果提前發生 → 故意既遂
- 無此想法 → 即使著手後，仍只能分論**未遂 + 過失**

| | 案例3（走火） | 案例4（下毒） |
|---|---|---|
| 著手標準說 | 故意既遂 | 故意既遂 |
| 計畫完成/主觀決定說 | **分論未遂+過失**（可放下槍） | **分論未遂+過失**（第2次而已） |

> 少數說的故意既遂案例：甲給乙吃毒藥，照認知2小時才發作，但乙體質特殊半小時就死了→行為人已完成毒殺行為、回頭不及 → 故意既遂

#### （三）典型構成要件行為標準說（許恆達老師，臺大法研所考點）

審查兩面向：
1. **客觀面**：行為人是否已做到**典型構成要件行為**的階段？
2. **主觀面**：行為人對提早實現的結果是否已有**未必故意**（預認）？

| | 案例3（走火） | 案例4（下毒） |
|---|---|---|
| 典型構成要件行為？ | 瞄準 ≠ 典型殺人行為 → **否** | 下毒 = 典型殺人行為 → **是** |
| 結論 | **分論未遂+過失** | **故意既遂** |

> 三說嚴格程度排序：計畫完成/主觀決定說（最嚴格）> 典型構成要件行為標準說 > 著手標準說（最寬鬆）

## 三、結果延後發生

### 定義

犯罪結果**比行為人預想的時間更晚**實現。行為人以為被害人已死（實際只是昏迷），後續處置行為才導致真正死亡。

### 案例：電影《告白》改編版

#### 事實
1. 高中生在兔子玩偶中設置電機機關
2. 將玩偶交給女班導的幼女
3. 幼女觸電倒地 → 高中生以為已電死
4. 高中生將「屍體」丟入游泳池
5. 法醫發現：幼女被電暈未死，死因為**溺水**

### 三說比較

#### （一）第一行為關鍵說（通說）✅

- 被害人到底是電死還是溺斃 → **不重要的偏差**
- 結論：前面的殺人行為風險已實現 → **殺人故意既遂**

#### （二）區分處理說 / 數罪併罰說

- 人怎麼死的很重要：電死 ≠ 溺斃 → 風險未實現
- 結論：

```
前段：殺人行為 → 風險未實現 → 殺人未遂
                                    ↓ 數罪併罰
後段：棄屍行為 → 一行為觸犯二罪名
  ├── 棄屍未遂（§247）：丟的不是屍體而是活人
  └── 過失致死（§276）：稍加注意即可發現尚未死亡
  → §55 想像競合，從一重處斷
```

#### （三）概括故意說（歷史說法，現已無人採）

- 前後行為在同一故意下進行 → 論殺人既遂
- **批判**：混淆**故意**與**犯罪計畫**。後段棄屍時行為人以為是屍體，根本無殺人故意

### 解題定位

| 結果時序錯誤 | 爭點核心 | 三階論位置 |
|------------|---------|-----------|
| **結果提前發生** | 行為人有沒有故意 | **主觀構成要件（故意）** |
| **結果延後發生** | 風險有沒有實現 | **客觀歸責（風險實現）** |
