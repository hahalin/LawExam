# 刑法10 筆記：原因自由行為

> 來源：刑法10 課程字幕 01:21:00 ~ 02:28:00

---

## 📖 法條原文速查

> **§19**（精神狀態與責任能力）
> I 行為時因精神障礙或其他心智缺陷，致**不能辨識**其行為違法或欠缺依其辨識而行為之能力者，不罰。
> II 行為時因前項之原因，致其辨識行為違法或依其辨識而行為之能力，**顯著減低**者，得減輕其刑。
> III 前二項規定，於因**故意或過失自行招致**者，不適用之。
> → §19 III 是**例外模式**的法律明文，不是原因自由行為的定義

---

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§19 III 是否為原因自由行為的定義？」 | **否**，§19 III 僅是**例外模式**的法律明文依據，不是原因自由行為的定義 |
| 「原因自由行為有幾種模式？」 | 兩種：**構成要件模式**（前置犯行）與**例外模式**（§19 III） |
| 「構成要件模式能否引用 §19 III？」 | **不可以**。構成要件模式不涉及責任能力調整，引用 §19 III 是掛羊頭賣狗肉 |
| 「構成要件模式的『雙重故意』是什麼？」 | ①自陷責任能力缺陷的故意 ②法益侵害的故意。兩者都有＝故意犯，缺一＝過失犯 |
| 「自醉行為（麻醉狀態下情緒不法行為）之效果？」 | **無罪**。行為人喝酒無自陷故意、亦無法益侵害故意，非原因自由行為 |
| 「定式犯罪在構成要件模式下的問題？」 | 定式犯罪（如竊盜）要求特定行為方式（竊取），喝酒≠竊取 → 前置犯行行不通 |
| 「§19 III 何時增訂？」 | **2006 年 7 月 1 日**。之前無此規定，一面倒構成要件模式；之後兩說並存 |
| 「兩模式的著手時點差異？」 | 構成要件模式＝**喝酒時**（前置行為）；例外模式＝**砍人時**（後行為） |
| 「精神病患不服藥是否為原因自由行為？」 | 理論上**不排除**，但要件通常**過不去**（保證人地位、因果關係、故意過失、期待可能性等障礙） |

## 一、原因自由行為的基本概念

### 問題的起源

```
責任能力以「行為時」判斷
     ↓
行為人在有完全責任能力時，故意使自己陷入責任能力缺陷
     ↓
在無/限制責任能力狀態下侵害法益
     ↓
若純依行為時判斷 → 無罪或減刑（不合理）
     ↓
原因自由行為理論 → 例外讓行為人負完全責任
```

---

## 二、兩大模式

### 模式總覽

| 比較項目 | 構成要件模式（前置犯行） | 例外模式（§19 III） |
|---------|----------------------|-------------------|
| 核心思維 | 用**前行為**（喝酒）論罪 | 用**後行為**（砍人）論罪，§19 III 排除減免 |
| 法律依據 | 不需要 §19 III | **需要** §19 III |
| 犯罪行為 | 前行為（喝酒＝殺人行為） | 後行為（砍人＝殺人行為） |
| 著手時點 | **喝酒時**（故可能成立未遂） | **砍人時**（無殺人未遂空間） |
| 責任能力 | 前行為時有完全責任能力（不需調整） | 後行為時無責任能力 → §19 III 視為完全 |
| 定式犯罪 | **有困難**（喝酒≠竊取→無法前置） | **無此困難** |
| 歷史 | §19 III 增訂前（2006 前）一面倒 | §19 III 增訂後（2006 後）始有明文 |

## 三、構成要件模式詳解

### （一）前置犯行的邏輯

```
甲計畫殺乙 → 故意灌醉自己 → 醉後持刀砍殺乙
              （前行為）           （後行為）

構成要件模式：
① 後行為（砍人）→ 無責任能力 → 不成立犯罪
② 前行為（喝酒）→ 有完全責任能力 → 用此行為論殺人罪
```

- 殺人罪是**非定式犯罪**（行為方式不限）→ 喝酒可以是殺人的行為方式 ✅
- 竊盜罪是**定式犯罪**（必須「竊取」）→ 喝酒不是竊取 ❌

### （二）雙重故意要求

```
故意與行為同時存在原則
     ↓
用前行為（喝酒）論罪
     ↓
喝酒當時必須有：
  ① 自陷責任能力缺陷的故意（知道喝酒會醉）
  ② 法益侵害的故意（喝酒時就打算殺人）
     ↓
兩者都有 → 故意犯
缺一 → 過失犯
兩者都無 → 非原因自由行為
```

### （三）雙重故意的五種組合

| 組合 | 自陷故意 | 法益侵害故意 | 結論 |
|------|---------|-------------|------|
| ① | 故意 | 故意 | **故意犯**（故意殺人） |
| ② | 故意 | 過失 | **過失犯**（過失致死） |
| ③ | 過失 | 故意 | **過失犯**（理論上可能性低） |
| ④ | 過失 | 過失 | **過失犯**（過失致死） |
| ⑤ | 無 | 無 | **無罪**（自醉行為） |

### （四）自醉行為（第⑤種）

- 行為人單純喝酒，無自陷故意、也無法益侵害故意
- 醉後因情緒失控而傷人
- 結論：**無罪**（麻醉狀態下的情緒不法行為）
- 這不是原因自由行為

### （五）定式犯罪的困難

| 犯罪類型 | 行為方式 | 前置犯行可否 |
|---------|---------|------------|
| 殺人（非定式） | 不限 | ✅ 喝酒可以是殺人方式 |
| 竊盜（定式） | 必須「竊取」 | ❌ 喝酒不是竊取 |
| 己手犯 | 必須親自為之 | ❌ 前置行為無法親自實現 |

### （六）構成要件模式的寫法重點

> ⚠️ 採構成要件模式時，**絕對不可以引用 §19 III**！
> - §19 III 是例外模式的規定
> - 構成要件模式不涉及責任能力的調整
> - 前行為時本來就有責任能力，不需要 §19 III

## 四、例外模式詳解

### （一）§19 III 的運作

```
甲計畫殺乙 → 故意灌醉自己 → 醉後持刀砍殺乙
                               （用此行為論罪）

例外模式：
① 後行為（砍人）→ 構成要件該當、違法
② 罪責：原本 §19 I/II 可免罰或減輕
③ 但 §19 III：因故意或過失自行招致 → 不適用 §19 I/II
④ 結論：視為完全責任能力 → 成立犯罪
```

### （二）§19 III 的性質

- §19 III **不是**原因自由行為的定義
- §19 III **只是**例外模式的法律明文
- 沒有 §19 III → 例外模式無法律依據 → 違反罪刑法定原則
- 有 §19 III → 例外模式有明文支撐

### （三）例外模式也要看雙重故意

| 組合 | 自陷故意/過失 | 法益侵害故意/過失 | §19 III 適用 |
|------|-------------|-----------------|-------------|
| 故意＋故意 | 故意自陷 | 故意侵害 | ✅ 適用，成立故意犯 |
| 故意＋過失 | 故意自陷 | 過失侵害 | ✅ 適用，成立過失犯 |
| 過失＋故意 | 過失自陷 | 故意侵害 | ✅ 適用，成立過失犯 |
| 過失＋過失 | 過失自陷 | 過失侵害 | ✅ 適用，成立過失犯 |
| 無＋無 | 無故意過失 | 無故意過失 | ❌ 不適用，無罪 |

## 五、考題寫作示範

### 典型題目：甲計畫殺乙，喝醉後持刀砍殺乙致死

#### 版本一：構成要件模式

```
一、甲持刀砍殺乙的行為（後行為）
  （一）構成要件：客觀→行為、結果、因果、歸責 ✅
                  主觀→故意 ✅（醉後仍有認知與決意）
  （二）違法性：無阻卻事由
  （三）罪責：涉及原因自由行為
       → 兩說並列（構成要件模式 vs 例外模式）
       → 採構成要件模式
       → 後行為無責任能力 → 不成立犯罪

二、甲喝酒的行為（前行為）
  （一）構成要件：客觀→行為（喝酒）、結果（乙死）、因果、歸責 ✅
                  主觀→雙重故意 ✅（自陷故意＋殺人故意）
  （二）違法性：無阻卻事由
  （三）罪責：喝酒時有完全責任能力 ✅
  → 成立 §271 殺人罪

⚠️ 不可引用 §19 III！
```

#### 版本二：例外模式

```
一、甲持刀砍殺乙的行為
  （一）構成要件：客觀 ✅、主觀 ✅
  （二）違法性：無阻卻事由
  （三）罪責：涉及原因自由行為
       → 兩說並列
       → 採例外模式
       → 甲具雙重故意（自陷故意＋殺人故意）
       → 依 §19 III，前二項不適用
       → 視為完全責任能力
  → 成立 §271 殺人罪
```

### 常見錯誤：掛羊頭賣狗肉

> 聲稱採構成要件模式，卻在罪責中引用 §19 III 說「視為完全責任能力」
> → 這其實是**例外模式**的寫法！
> → 要不就改稱例外模式，要不就拿掉 §19 III 做前置犯行

## 六、精神病患不服藥的問題

### 問題

精神病患有處方藥，但自行停藥，放任精神病發作後侵害他人法益，是否為原因自由行為？

### 結論

學說與實務：**不排除適用原因自由行為，但要件通常過不去**

### 構成要件模式的障礙

| 關卡 | 問題 |
|------|------|
| ① 保證人地位 | 精神病患**沒有吃藥的義務**（吃藥是權利非義務），前置犯行是不作為→欠缺作為義務。例外：對特定人有保護義務（如不服藥後攻擊自己的小孩→有義務），但很罕見 |
| ② 因果關係 | 抗精神病藥物對每人效果不同，無法證明「服藥就不會犯罪」 |
| ③ 主觀不法 | 停藥可能就是精神病的結果（病人覺得自己好了→無自陷故意過失） |
| ④ 罪責 | 前置到停藥時，病患可能**已經發病**→前置也無責任能力 |
| ⑤ 期待可能性 | 部分藥物副作用嚴重（發抖、失禁、喪失人性尊嚴）→ 期待服藥可能性有疑問 |

### 例外模式的障礙

- 要求：①停藥引起結果行為時責任能力障礙 ②停藥時有完全責任能力 ③停藥時有雙重故意/過失
- 大多數個案：停藥時**已因精神病作用而無完全責任能力** → 過不去

### 實務見解

> 100 年判決：精神病患未依醫囑服藥或定期回診，其於精神狀態正常時故意、過失自陷責任能力欠缺之情況有所不同，很難說是原因自由行為。
