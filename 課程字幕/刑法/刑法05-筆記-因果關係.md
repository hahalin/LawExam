# 刑法05 筆記：因果關係

> 來源：刑法05 課程字幕 00:14:00 ~ 01:06:00

## 📖 法條原文速查

> **§271**（殺人罪）
> I：殺人者，處死刑、無期徒刑或十年以上有期徒刑。
> II：前項之未遂犯罰之。
> III：預備犯第一項之罪者，處二年以下有期徒刑。

> **§277**（傷害罪）
> I：傷害人之身體或健康者，處五年以下有期徒刑、拘役或五十萬元以下罰金。
> → 建議查閱最新條文

> **§354**（毀損罪）
> 毀棄、損壞前二條以外之他人之物或致令不堪用，足以生損害於公眾或他人者，處二年以下有期徒刑、拘役或一萬五千元以下罰金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「因果關係與歸責有何不同？」 | **因果**＝純粹事實判斷（有沒有關）；**歸責**＝價值判斷（要不要負責）。有因果不必然歸責，但歸責前提必有因果 |
| 「哪些犯罪需審查因果關係與歸責？」 | 正面表列三類：**殺人、傷害、毀損**。其他結果犯（如竊盜、圖利）不需要 |
| 「條件理論（非P則非Q）是否分主要原因與次要原因？」 | **否**，條件理論不區分主要與次要原因，所有條件等價（反對「單一謬誤」） |
| 「超越因果關係的結論？」 | 先行行為**無因果**（甲下毒→藥效未發→乙車撞死A→甲無因果） |
| 「擇一因果關係如何處理？」 | 嚴格用非P則非Q會得出雙方都無因果→荒謬→**通說修正公式例外肯定因果** |
| 「事實不明時如何處理？」 | **罪疑惟輕**，但只有題目明示事實不明才能適用 |
| 「相當因果關係說在考試中是否建議使用？」 | **不建議**，考試固定組合＝條件因果＋客觀歸責 |

## 一、因果關係 vs 歸責的概念區分

```
因果關係（事實判斷）           歸責（價值判斷）
  ↓                            ↓
「這件事跟他有沒有關？」     「要不要讓他負責？」
  ↓                            ↓
因果＝歸責的前提              有因果 → 不必然歸責
                               無因果 → 不可能歸責
```

### 需審查因果歸責的犯罪（正面表列）

| 犯罪類型 | 說明 |
|---------|------|
| **殺人罪**（§271） | 行為→死亡結果 |
| **傷害罪**（§277） | 行為→傷害結果 |
| **毀損罪**（§354） | 行為→毀損結果 |

> 其他結果犯（如竊盜、圖利）不需要審查因果歸責。

## 二、條件理論（非P則非Q）

### 公式

> 若無前者（行為），即無後者（結果）→ 行為是結果「不可想像其不存在的條件」→ **有因果關係**

### 特性

- **非常寬鬆**：可以扯很遠（C介紹→A殺B→連A父母生育都有因果）
- 扯遠不是否定理由→後面有**歸責理論**把關
- **目前主流**理論

## 三、條件理論的補充

### 補充①：假設因果流程不影響

> 不能用假設的後續結果否定已存在的因果。

**案例：空難案**
- 殺手在飛機起飛前3小時殺死乘客A
- 3小時後飛機墜毀，全員罹難
- 能否主張「反正A 3小時後也會死」？→ **不能**
- 殺人罪禁止提早結束生命，不論提早多久

### 補充②：行為是共同條件之一即可

> 結果由多數原因造成時，條件論**不區分主要原因與次要原因**，所有原因都等價。

- 反對「**單一謬誤**」思維：不能因為有其他原因就否定自己的行為是條件

### 補充③：累積因果關係

**案例**：甲下毒6克、乙下毒6克（致死量10克），A吃了12克死亡
- 甲乙**各自的量都不足致死**
- 但合計超過致死量→A死亡
- 結論：甲乙**都有因果關係**
- 注意：僅肯定因果，歸責不一定（可能太罕見的巧合）

### 補充④：被害人異常因素 / 曲折離奇不影響

> 因果歷程再怎麼曲折離奇，只要符合非P則非Q，因果關係仍然成立。

**案例一：醫院案**
- 甲開槍打中乙→乙送醫→醫院火災/醫療疏失→乙死
- 因果關係：**有**（不打乙就不會送醫院，不送醫院就不會在火災中死亡）

**案例二：救護車車禍案**
- 甲砍傷乙→乙搭救護車→救護車被撞翻→乙死
- 因果關係：**有**（不砍乙就不會搭救護車）

### 補充⑤：超越因果關係

> 先行為的效果**尚未發揮**，被後行為「超越」取代。

**案例**：甲下毒（藥效未發作）→乙車失控撞死A
- 甲有沒有因果？→ **無因果**
- 就算甲不下毒，A也會被乙撞死
- 下毒行為被車禍**超越**

### 補充⑥：擇一因果關係（雙重因果關係）

**案例**：甲下毒12克、乙下毒12克（致死量10克），A吃了24克死亡

嚴格適用非P則非Q：
- 甲：「我不下毒，乙的12克也足以致死」→ 甲無因果？
- 乙：「我不下毒，甲的12克也足以致死」→ 乙無因果？
- 兩人都無因果 → **荒謬**

> **通說修正**：擇一因果關係中，例外肯定雙方都有因果。這是**條件因果的唯一例外**。

### 比較：累積因果 vs 擇一因果

| 比較項目 | 累積因果關係 | 擇一因果關係 |
|---------|------------|------------|
| 個人劑量 | 各自不足致死（各6克/致死10克） | 各自足以致死（各12克/致死10克） |
| 合計效果 | 合計超過致死量 | 合計遠超致死量 |
| 非P則非Q | 正常適用→都有因果 | 嚴格適用會荒謬→**修正例外** |
| 結論 | 都有因果（正常判斷） | 都有因果（例外肯定） |

### 補充⑦：事實不明 → 罪疑惟輕

**案例：醉漢被三車碾過**
- A、B、C三輛車先後碾過醉漢，不知何車致死
- 結論：A至少過失傷害；B、C可能無罪

**案例：兩人同時開槍**
- 不知誰的子彈先命中 → 兩人都論**未遂**

> **重要提醒**：只有題目**明示事實不明**才能用罪疑惟輕，不可自行假設事實不明。

## 四、相當因果關係說（歷史理論）

### 發展背景

早年為限縮條件理論（太寬鬆）而生，要把**罕見、偶然、例外**的因果歷程剔除。

### 三種學說

| 學說 | 判斷角度 | 血友病案結論 |
|------|---------|------------|
| **主觀說** | 行為人視角 | 不相當（行為人不知道） |
| **客觀說** | 事後上帝視角（早期實務76臺上192） | **相當**（事後看什麼都相當） |
| **折衷說** | 旁觀者認知＋行為人特殊認知 | 不相當（一般人看不出血友病） |

### 血友病案

甲用刀片割傷乙（輕傷），但乙是血友病患者，因凝血功能障礙而死亡。
- 主觀說：甲不知乙有血友病 → **不相當**
- 客觀說：事後知道乙有血友病 → **相當**
- 折衷說：一般旁觀者不知乙有血友病 → **不相當**

### 為何考試不建議使用

1. 客觀說飽受批評（事後諸葛，事後看什麼都相當→沒意義）
2. 本質上處理的是**歸責問題**而非純因果
3. 現在學者幾乎不採
4. **考試固定組合＝條件因果＋客觀歸責**

### 相當性誤用案例

垃圾車清潔隊員摔落案→法院正面判斷「統計上罕見→不相當」→**錯誤**（過失犯永遠不會相當，因為過失犯的結果本身就是罕見的意外）
