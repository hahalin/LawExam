## 📖 法條原文速查

> **§15**（不作為犯）
> I 對於犯罪結果之發生，法律上有防止之義務，能防止而不防止者，與因積極行為發生結果者同。
> II 因自己行為致有發生犯罪結果之危險者，負防止其發生之義務。

> **§24**（緊急避難）
> 因避免自己或他人生命、身體、自由、財產之緊急危難而出於不得已之行為，不罰。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「什麼是義務衝突？」 | **作為義務 vs 作為義務**的衝突（不作為犯專屬的阻卻違法事由） |
| 「女朋友跟媽媽同時落水是義務衝突？」 | **否**，對女朋友無保證人地位 → 非義務衝突 |
| 「義務衝突可用緊急避難處理嗎？」 | **不行**，因為犧牲無辜且法益等值 → 攻擊型緊急避難的法益衡量過不去 |
| 「義務衝突的效果？」 | **阻卻違法**（超法規阻卻違法事由） |
| 「不作為犯何時著手？三說？」 | ①第一救助機會 ②最後救助機會 ③**區分說**（法益已入危險→著手/未入→看行為人反應） |
| 「不作為犯中止未遂適用推車過山坡圖？」 | **不適用**。不作為犯中止必須**積極作為**（放棄＝繼續不作為，非中止） |
| 「間接正犯可否以不作為實現？」 | **不可以**（優越意思支配與不作為矛盾）→ 改論直接正犯 |

| 「有保證人地位者不阻止他人故意犯罪，論正犯還是幫助犯？」 | **實務**：有犯意聯絡→共同正犯/無→幫助犯。**學說五說**各有不同 |

## 正文

### 一、不作為犯的違法性：義務衝突

#### 義務衝突的三種可能類型

```
義務衝突的概念整理
│
├── ① 不作為義務 vs 不作為義務 → ✗ 不是義務衝突
│   └ 理由：不做壞事的義務不會互相衝突
│
├── ② 作為義務 vs 不作為義務 → ✗ 用緊急避難解決即可
│   └ 例：救女兒（作為義務）vs 不毀損他人財物（不作為義務）
│
└── ③ 作為義務 vs 作為義務 → ✓ 真正的義務衝突
    └ 例：媽媽帶兩小孩玩水，兩孩同時溺水，只能救一個
    └ 為何不能用緊急避難？→ 攻擊型避難需法益「大於」，但生命等值
    └ → 只好另創「超法規阻卻違法事由」
```

#### 義務衝突四大要件

| 要件 | 內容 | 反面案例 |
|------|------|---------|
| **①數個作為義務同時存在** | 行為人同時負有多個救助義務 | 女友＋媽媽落水 → ✗（對女友無保證人地位） |
| **②義務間有排斥關係** | 只能履行其一 | 媽媽救完第一個孩子後腳抽筋 |
| **③履行部分的法益 ≧ 未履行部分** | 不可棄重就輕 | 先救狗不救人 → ✗ |
| **④局面非可歸責於行為人** | 不可自己製造衝突 | 媽媽怒將兩小孩丟入湖中 → ✗（自己造成的） |

**效果**：四要件均符合 → **阻卻違法**，不成立犯罪

#### 進階案例：酒駕抓通緝犯

- 民眾酒駕追通緝犯 → 律師主張義務衝突
- 法院：**不成立義務衝突**
  - 不酒駕＝義務；抓通緝犯＝**權利**（非義務）
- 也不能主張緊急避難（國家司法權非緊急避難可保護的法益）
- 頂多走 §16 **容許錯誤**（行為人誤認酒駕可被允許）

### 二、不作為犯的未遂

#### 著手時點三說

```
不作為犯的著手
│
├── 第一救助機會理論
│   └→ 錯過第一個救助機會 ＝ 著手
│
├── 最後救助機會理論
│   └→ 錯過最後的拯救機會 ＝ 著手
│
└── 區分說（法益危險理論/直接危險理論）
    ├→ 法益已進入危險狀態 → 著手
    └→ 法益尚未進入危險狀態
        ├→ 行為人隨時可介入作為 → 等危險接近才著手
        └→ 行為人轉身離開 → 離開時即著手
```

> **平交道管理員案**：醉漢倒在鐵軌上
> - 火車半小時後才來＋管理員在旁邊 → 等火車逼近才著手
> - 火車半小時後才來＋管理員轉身離開 → **離開時即著手**

#### 中止未遂

- 不作為犯的中止未遂 **不適用**「推手推車過山坡」的圖
- 理由：不作為犯的中止行為必須是**積極作為**（放棄＝繼續不作為，不是中止）

```
作為犯中止：            不作為犯中止：
未了 → 放棄即可         ✗ 放棄 ＝ 繼續不作為
既了 → 積極拯救         ✓ 中止必須積極作為
```

#### 經典考題：小黑狼狗案

```
甲牽狼狗小黑散步 → 小黑掙脫 → 撕咬乙 → 乙說「做鬼也不會放過你」→ 甲叫小黑停止＋打119

分析三步驟：

1. 小黑掙脫狗繩（第一個不作為）
   → 不成立犯罪（無作為可能性：狼狗發瘋力氣比人大）

2. 小黑撕咬乙，甲不阻止（第二個不作為）
   → 有作為可能性 → 討論著手問題
   → 三說分析各有不同結論

3. 中止未遂（甲最終阻止＋打119）
   → 己意性？（被害人威脅「做鬼也不放過你」）
   → 主觀說（法蘭克公式）：得為而不為 → ✓ 己意
   → 限定主觀說：倫理自我要求 → ✗ 可能不算
   → 準中止犯（被路人送醫，因果偏離）
```

### 三、不作為犯的參與形態

```
參與形態 × 不作為
│
├── 間接正犯 → ✗ 不可以
│   └ 理由：優越意思支配 ≠ 不作為（概念矛盾）
│   └ 出現疑似不作為間接正犯 → 改論直接正犯
│
├── 共同正犯 → ✓ 可以
│   └ 例：父母合謀餓死嬰兒 → 不作為殺人共同正犯
│
├── 教唆犯 → ✗ 不可以
│   └ 理由：不作為教唆他人犯罪 → 概念上衝突
│
└── 幫助犯 → ✓ 可以
    └ 例：警衛故意不設保全 → 不作為幫助竊盜
```

#### 搬家筆電案（間接正犯 × 不作為）

```
甲畢業搬家 → 朋友誤將室友筆電裝箱 → 甲知情但不阻止

分析層次：
① 間接正犯？→ ✗（不作為不能成立間接正犯）
② 直接正犯？→ ✗（甲對室友財產無保證人地位：無保護義務＋無監督義務）
③ 結論：無罪
```

### 四、★ 核心爭點：不作為正犯 vs 不作為幫助犯的區分

#### 前提辨明

```
有保證人地位者不阻止他人犯罪
│
├── 他人犯「過失」犯罪 → 保證人論【直接正犯】（無爭議）
│   └ 理由：過失行為不能論幫助犯
│   └ 例：護校生注射錯藥＋指導護理師不阻止 → 護理師論故意殺人正犯
│
└── 他人犯「故意」犯罪 → 保證人論正犯還是幫助犯？（★核心爭點）
    └ 例：人學老爸案（兒子被流氓打，爸爸不阻止）
```

#### 六說比較總覽

| 學說 | 區分標準 | 人學老爸案結論 | 代表學者 |
|------|---------|--------------|---------|
| **實務見解** | 有無犯意聯絡 | 有→共同正犯/無→**幫助犯** | 實務 |
| **①犯罪支配論** | 保證人能否獨自阻止犯罪 | 分三種情況（見下） | 德國學說 |
| **②主觀理論** | 為誰的利益不作為 | 為己→正犯/為他人→幫助犯 | 德國學說 |
| **③正犯理論** | 違反義務＝正犯（原則） | **正犯**（除三例外） | 許澤天 |
| **④幫助犯理論** | 擺爛者永遠非主角 | **幫助犯**（無例外） | 蕭宏義 |
| **⑤區別理論** | 違反保護義務→正犯/違反監督義務→幫助犯 | 依義務類型判斷 | 林書楷 |

> **重要**：學說所講的「正犯」＝**單獨正犯**（非共同正犯），因通常保證人與作為犯之間無犯意聯絡

#### ①犯罪支配論（三種情況）

| 情況 | 說明 | 結論 | 人學老爸案舉例 |
|------|------|------|--------------|
| 有作為也沒用 | 結果不可避免 | **不罰** | 爸爸像老師體型 vs 流氓像館長＋荒郊野外 |
| 無法獨自阻止但可求助 | 可透過第三方阻止 | **幫助犯** | 爸爸像老師體型 vs 流氓像館長＋但在熱鬧市區 |
| 自己就能阻止 | 有能力中止卻不中止 | **正犯** | 爸爸像館長體型 vs 流氓像老師體型 |

#### ③正犯理論的三個例外

正犯理論原則：不作為犯**原則上都是正犯**，但三個例外改論幫助犯：

| 例外 | 說明 |
|------|------|
| **純正身分犯** | 行為人不具身分 → 不能論正犯 |
| **己手犯** | 如血親性交罪（爸爸放任兄妹性交 → 不能論血親性交正犯 → 論幫助犯） |
| **意圖犯而欠缺意圖** | 要有特定意圖才能成立的犯罪，行為人欠缺該意圖 → 論幫助犯 |

#### ⑤區別理論

```
不作為的行為人違反何種義務？
│
├── 違反「保護義務」→ 離法益近 → 正犯
│   例：被霸凌學生的父親不阻止 → 正犯（對兒子有保護義務）
│
└── 違反「監督義務」→ 離法益遠 → 幫助犯
    例：班導師不阻止霸凌 → 幫助犯（對霸凌者有監督義務）
```

#### ★ 經典考題：警衛丙案（105年警特）

```
甲欲偷乙家古董花瓶 → 對警衛丙說：我代班 → 丙知情且對花瓶有興趣 → 配合甲的計畫

丙的刑事責任（六說分析）：

實務：丙與甲無犯意聯絡 → 幫助犯
①犯罪支配論：丙上班就能阻止 → 正犯（單獨）
②主觀理論：丙為自己利益（想要花瓶）→ 正犯
③正犯理論：違反義務→原則正犯（須檢查三例外，竊盜非身分犯/己手犯/有不法所有意圖→無例外→正犯）
④幫助犯理論：一律幫助犯
⑤區別理論：丙違反對住戶財產的保護義務 → 正犯

結論：除實務＋幫助犯理論外，其餘學說均論正犯
```
