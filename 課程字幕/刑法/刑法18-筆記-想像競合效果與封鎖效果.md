# 刑法18 筆記：想像競合效果與封鎖效果

> 一行為而觸犯數罪名者，從一重處斷。但不得科以較輕罪名所定最輕本刑以下之刑。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「從一重處斷」的意義 | 是**科刑規則**，不是論罪規則 → 各罪名都要寫在判決主文 |
| 「只論重罪？」 | **不是**！各罪都成立，只是刑度從重罪 |
| 「§55 但書的封鎖效果」 | 不得科以較輕罪名之最輕本刑以下之刑（封鎖下限） |
| 「想像競合的刑度區間」 | 取重罪上限 + 取輕重罪中最高的下限 |
| 「想像競合 vs 法條競合」 | 法條競合只論一罪；想像競合各罪都成立（釐清作用寬） |
| 「輕罪專屬法律效果？」 | 爭議：**保安處分、強制治療**在從重罪處斷時可否宣告 |

## 一、從一重處斷 ≠ 只論重罪

### 核心觀念

- 想像競合是「**科刑規則**」（Strafzumessungsregel），不是「論罪規則」
- 各罪名**都成立**，都要寫在判決主文
- 只是在量刑時，以重罪的法定刑為基礎處斷

### 釐清作用

想像競合的「釐清作用」比法條競合更寬：

| | 法條競合 | 想像競合 |
|------|---------|---------|
| 成立罪名 | 只論一罪 | **各罪都成立** |
| 判決主文 | 只寫一罪 | **寫出所有罪名** |
| 刑度 | 依該一罪 | 從重罪處斷，但有封鎖效果 |
| 意義 | 排斥關係 | 科刑規則，充分評價各法益侵害 |

## 二、從一重處斷的具體操作

### 結合原則

想像競合在確定刑度時，採「結合原則」（而非單純吸收原則）：

```
A 罪：法定刑 1 年以上 7 年以下
B 罪：法定刑 2 年以上 5 年以下

從 A 罪（重罪）處斷：
├── 上限：取重罪 → 7 年（A 的上限）
└── 下限：取兩罪中最高下限 → 2 年（B 的下限，§55 但書封鎖）

→ 處斷刑範圍：2 年以上 7 年以下
```

### 與吸收原則的差異

- **吸收原則**（舊見解）：完全以重罪刑度為準 → 1 年以上 7 年以下
- **結合原則**（現行通說）：上限取重罪，下限取輕重罪中最高者 → 2 年以上 7 年以下

差異在**下限被拉高**，這就是封鎖效果。

## 三、§55 但書：封鎖效果

### 條文

> 但不得科以較輕罪名所定**最輕本刑**以下之刑。

### 意義

- 輕罪的最低法定刑，成為整體處斷刑的**下限**
- 防止從重罪處斷時反而判得比輕罪最低刑還輕

### 範例

```
甲罪（重罪）：6月以上 5年以下
乙罪（輕罪）：2年以上 10年以下 ← 但下限高

若無封鎖效果：從甲罪處斷 → 最低可判 6 月
有封鎖效果：最低不得低於乙罪下限 2 年

→ 處斷刑範圍：2 年以上 5 年以下
```

## 四、輕罪專屬法律效果

### 問題意識

從一重處斷時，輕罪附帶的**專屬法律效果**（如保安處分、強制治療、特定沒收規定）可否宣告？

### 典型案例

用藥劑性侵案：

```
行為：對被害人下藥（毒品）後性侵
成立：
  A. 加重強制性交罪（§222）→ 性犯罪 → 可宣告強制治療
  B. 以藥劑使人施用毒品罪 → 毒品犯罪

比較法定刑 → B 罪較重 → 從 B 罪處斷

問題：B 罪（毒品罪）無強制治療規定
     A 罪（性犯罪）才有強制治療
     → 從毒品罪處斷時，可否宣告性犯罪的強制治療？
```

### 爭議

| 立場 | 理由 |
|------|------|
| **肯定說** | 各罪都成立（想像競合是科刑規則），輕罪的法律效果應保留 |
| **否定說** | 從一重處斷的結果，應以重罪的法律效果為準 |

### 考試注意

- 此爭議在**一試選擇題**中可能出現
- 記住問題意識即可：想像競合從重罪處斷時，輕罪附帶的保安處分等效果是否一併適用
