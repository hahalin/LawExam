# 刑法16 筆記：加重結果犯（結果加重犯）

> 來源：刑法16 課程字幕 00:00:00 ~ 01:00:00（約）

---

## 📖 法條原文速查

> **§17**（加重結果犯）
> 因犯罪致發生一定之結果，而有加重其刑之規定者，如行為人不能預見其發生時，不適用之。

> **§277**（傷害罪）
> I 傷害人之身體或健康者，處五年以下有期徒刑、拘役或五十萬元以下罰金。
> II 犯前項之罪，因而**致人於死**者，處無期徒刑或七年以上有期徒刑；致**重傷**者，處三年以上十年以下有期徒刑。

> **§226**（妨害性自主罪之加重結果）
> I 犯第 221 條、第 222 條、…之罪，因而致**被害人**於死者，處無期徒刑或十年以上有期徒刑；致重傷者，處十年以上有期徒刑。
> II 犯第 221 條、…之罪，因而致**被害人羞忿自殺**或意圖自殺而致重傷者，處十年以上有期徒刑。

> **§55**（想像競合）
> 一行為而觸犯數罪名者，從一重處斷。

> **§12**（故意與過失之處罰原則）
> 行為非出於故意或過失者，不罰。
> 過失行為之處罰，以有特別規定者為限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「加重結果犯的結構為何？」 | 故意基礎行為 ＋ **過失**重結果 ＋ **特殊危險關係** → 加重處罰 |
| 「哪些犯罪有加重結果犯？」 | **暴力犯罪**（傷害、強盜、私行拘禁）、**酒駕** ✓；詐欺、誹謗、放火 ✗ |
| 「基礎犯罪未遂＋重結果發生，成立加重結果犯？」 | 看**行為續生**（如強盜→不需既遂）或**結果續生**（如傷害→需既遂），三說結論不同 |
| 「被害人拒絕就醫後死亡，行為人成立加重結果犯？」 | **否**，被害人自我負責原則 → 行為人無過失 |
| 「故意致死與加重結果犯如何區分？」 | 有殺人故意 → 不是加重結果犯 → 以**想像競合**（§55）處理 |
| 「傷害致死的特殊危險關係，狹義說與廣義說的差異？」 | **狹義說**：僅傷重不治 / **廣義說**：加上逃跑反抗中死亡 |
| 「加重結果的被害人一定是基礎犯罪的被害人？」 | **一般條文不限同一人**；但 §226 I 性犯罪須**同一被害人**（「致被害人」文字） |
| 「同夥參與者可否為加重結果的被害人？」 | **不可以**（交互歸責荒謬＋被害人自我負責） |
| 「§226 II 性侵致羞忿自殺是加重結果犯？」 | **否**，通說認為是「特殊結果責任」，非過失犯結構，學者普遍主張應**刪除** |
| 「無加重結果犯法律明文時如何處理？」 | 回歸 **§55 想像競合**從一重處斷 |

## 正文

### 一、加重結果犯的基本結構

```
加重結果犯 ＝ 故意A罪 ＋ 過失B罪（死亡/重傷）→ 更重的C罪
              ↓
         重刑化思考的產物
         （原本應以想像競合處理，立法者特設加重規定）
```

- **核心概念**：行為人出於故意實施基礎犯罪，過失造成加重結果（死亡或重傷），且基礎行為與加重結果間有「特殊危險關係」
- **重刑化思考**：加重結果犯是把原本故意＋過失的想像競合，以法定加重刑度處理，刑度會**比想像競合更重**

### 二、哪些犯罪有加重結果犯？

| 有加重結果犯 | 無加重結果犯 |
|------------|------------|
| 傷害罪（§277 II） | 詐欺罪 |
| 強盜罪 | 誹謗罪 |
| 私行拘禁罪 | **放火罪**（例外） |
| 妨害性自主罪（§226 I） | |
| 酒駕（§185-3） | |

> **放火罪例外**：放火罪雖然是暴力犯罪，但**無加重結果犯**的規定 → 放火致死以 §55 想像競合處理

### 三、加重結果犯的五大要件

#### 要件一：基礎行為出於故意

基礎犯罪必須是**故意**犯。

##### 爭點：基礎犯罪未遂＋重結果發生

```
三說對照：

┌─ 實務：看基礎犯罪有無罰未遂
│   └→ 有罰未遂 → 可成立加重結果犯未遂
│   └→ 無罰未遂 → 不成立
│
├─ 通說（行為續生 vs 結果續生）
│   ├→ 行為續生（如強盜）→ 不需基礎犯罪既遂 → 可成立
│   └→ 結果續生（如傷害）→ 需基礎犯罪既遂 → 未遂不成立
│
└─ 黃榮堅：按條文編排順序
    └→ 加重結果在前、未遂在後 → 需既遂
    └→ 加重結果在後、未遂在前 → 不需既遂
```

**行為續生 vs 結果續生的區分**：

| 類型 | 定義 | 代表犯罪 | 是否需基礎犯罪既遂 |
|------|------|---------|------------------|
| **行為續生** | 基礎行為本身持續進行中可導致重結果 | 強盜 | **不需** |
| **結果續生** | 基礎犯罪的結果才可能續發重結果 | 傷害 | **需要** |

> **考題：搶奪未遂＋被害人死亡**
> - 搶奪 ＝ **行為續生**（搶奪行為本身就可能致死）
> - 三說結論比較：實務看有無罰未遂 / 通說(行為續生)可成立 / 黃說看條文編排

#### 要件二：重結果出於過失

重結果（死亡/重傷）必須成立**完整的過失犯**，涵蓋：
- 注意義務違反
- 預見可能性
- 因果關係（客觀歸責）

##### 重要案例：被害人拒絕就醫

- 行為人傷害被害人後，被害人**自行拒絕就醫**而死亡
- 結論：**被害人自我負責** → 行為人無過失 → 不成立加重結果犯

##### 考題陷阱：故意致死 ≠ 加重結果犯

- 地特法廉考題：妨害公務中**故意**致人於死
- 分析：既然有殺人故意 → 不適用加重結果犯 → 以妨害公務罪與殺人罪**想像競合**

#### 要件三：特殊危險關係（典型危險）

基礎行為與加重結果之間必須有**典型的危險關聯**。

##### 判斷方式：由行為續生/結果續生推論典型危險

| 犯罪類型 | 典型危險來源 | 舉例 |
|---------|------------|------|
| **強盜罪** | 行為危險（暴力本身致死） | 暴力致死 ✓；財產被奪致死 ✗ |
| **私行拘禁** | 斷絕生存補給 / 逃跑過程中死亡 | 除非被害人以**顯然不合理方式**逃跑 |
| **傷害罪** | 【狹義說 vs 廣義說】 | 見下方分析 |

##### 傷害罪的狹義說 vs 廣義說（王皇玉文章）

| | 狹義說 | 廣義說 |
|---|--------|--------|
| **範圍** | 僅限**傷重不治** | 傷重不治 ＋ **逃跑反抗中死亡** |
| **適用範圍** | 僅適用於「傷害罪」的特殊危險 | 同左 |

> **西瓜刀案**（107年考題）：被害人手部受傷 → 倒地顱內出血死亡
> - 狹義說：手傷非致命傷 → ✗ 非傷重不治
> - 廣義說：倒地過程中死亡 → ✓ 可成立

##### 槍託敲頭走火案

- 行為人用槍托敲被害人頭部，槍枝走火致死
- 分析：走火與敲頭行為之間**無特殊危險關係** → 不成立加重結果犯

#### 要件四：加重結果的被害人

```
加重結果的被害人
├── 一般條文 → 不限同一人（但仍須滿足其他要件）
│   └ 例：假車禍真搶盜，嬰兒（第三人）死亡 → 可成立
│
├── §226 I 性犯罪 → 須同一被害人（「致被害人」文字限制）
│
└── 同夥參與者 → 不包括
    ├ 理由①：交互歸責 → 荒謬（A打B致C死，C也打A致B死…）
    └ 理由②：被害人自我負責（同夥自願參與危險行為）
```

> **飆車案例**：同夥飆車中重傷 → 不論加重結果犯（被害人自我負責）

#### 要件五：法律加重其刑之明文

- 必須有**法律明文**規定加重結果犯
- 無明文規定 → 回歸 **§55 想像競合**從一重處斷
- 例：放火罪無加重結果犯 → 放火致死以想像競合處理

### 四、§226 II 特殊結果責任

#### 性質辨析

```
§226 II（性侵致被害人羞忿自殺）
│
├── 通說＋實務：不是加重結果犯
│   └→ 是「特殊結果責任」（無過失責任性質）
│
└── 學者普遍主張：應予刪除
    ├ 理由①：違反 §12 原則（過失行為之處罰以有特別規定者為限）
    ├ 理由②：具有**貞操思想**色彩（父權浪漫主義思維）
    ├ 理由③：犯罪預防無意義 → 純粹報復
    └ 理由④：違憲疑慮（責任原則）
```

#### 為何不是加重結果犯？

- 被害人自殺是**自主決定**，行為人對此**無過失可言**
- 無法滿足「重結果出於過失」要件
- 本條是將被害人的自殺歸責於行為人 → 結果責任

#### 貞操思想批判

- 預設性侵被害人「應該」羞忿自殺 → 父權浪漫主義
- 隱含「失去貞操等於失去生命意義」的預設
- 與現代性別平權觀念衝突
- 學者結論：十個學者九個主張刪除
