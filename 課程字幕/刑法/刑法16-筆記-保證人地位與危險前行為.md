## 📖 法條原文速查

> **§15**（不作為犯）
> I 對於犯罪結果之發生，法律上有防止之義務，能防止而不防止者，與因積極行為發生結果者同。
> II 因自己行為致有發生犯罪結果之危險者，負防止其發生之義務。

> **§23**（正當防衛）
> 對於現在不法之侵害，而出於防衛自己或他人權利之行為，不罰。但防衛行為過當者，得減輕或免除其刑。

> **§24**（緊急避難）
> 因避免自己或他人生命、身體、自由、財產之緊急危難而出於不得已之行為，不罰。但避難行為過當者，得減輕或免除其刑。

> **§16**（法律錯誤/禁止錯誤）
> 除有正當理由而無法避免者外，不得因不知法律而免除刑事責任。但按其情節，得減輕其刑。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「保證人地位分為哪兩大類？」 | **保護型**（保護法益）vs **監督型**（監督危險源） |
| 「父母對未成年子女有何義務？」 | **兩種都有**：保護義務＋監督義務 |
| 「同居情侶有保證人地位嗎？」 | **有**（生活共同體：精神扶持關係） |
| 「室友/一夜情對象有保證人地位嗎？」 | **無**（非生活共同體） |
| 「違法活動的共同參與者有危險共同體的保證人地位？」 | **無**（危險共同體限**合法活動**） |
| 「事實上承擔保護義務需要契約嗎？」 | **不需要**契約，但須**現實控管風險**＋**客觀合理信賴** |
| 「外傭對老人有保證人地位嗎？」 | **有**（事實上承擔保護義務），但雇主對外傭**無**保證人地位 |
| 「危險前行為的通說？」 | **違背義務前行為**（有過錯才有救助義務） |
| 「正當防衛後須救助歹徒嗎？」 | 通說（違背義務前行為）：**不需要**；少數說（因果前行為＋無期待可能性） |
| 「緊急避難後須救助被犧牲者嗎？」 | 通說：**需要**（開例外，因犧牲者的損害由避難者導致） |

## 正文

### 一、保證人地位總覽

```
保證人地位
│
├── 保護型（保護特定法益免受危險）
│   ├── ① 法律規定
│   ├── ② 生活共同體 / 危險共同體
│   └── ③ 自願承擔保護義務（事實上承擔）
│
└── 監督型（監督危險源不侵害他人）
    ├── ① 危險源的監督
    ├── ② 商品製造人責任
    └── ③ 危險前行為（§15 II）← 唯一有法律明文
```

> **罪刑法定疑慮**：除危險前行為外，其他保證人地位**均無法律明文**，通說以「法理上承認」正當化。此問題被稱為「房間裡的大象」——學者質疑但通說視而不見。

---

### 二、保護型保證人

#### （一）法律規定

- **父母對未成年子女**：法律明文的保護義務
- 範圍：以法律有明確規定者為限

#### （二）生活共同體與危險共同體

##### 生活共同體

**判斷標準**：是否有**精神扶持**關係

| 關係 | 有無保證人地位 | 說明 |
|------|--------------|------|
| 家人 | ✓ | 典型生活共同體 |
| 同居情侶 | ✓ | 有精神扶持關係 |
| 室友 | ✗ | 僅共用空間，無精神扶持 |
| 一夜情對象 | ✗ | 偶然關係 |
| 獄友 | ✗ | 非自願共同生活 |
| 外傭與雇主 | ✗ | 服務方便非家人關係 |

> **注意方向**：外傭對老人有「事實上承擔」的保證人地位，但**非**生活共同體

##### 危險共同體

- 限於**合法活動**的共同參與
- 違法活動的共同參與 → **不算**危險共同體

#### （三）自願承擔保護義務（事實上承擔）

**三大要件**：

```
自願承擔保護義務
│
├── ① 須現實控管風險（非僅口頭承諾）
│   └ 保姆＋鑰匙案：交付鑰匙＝現實控管 ✓
│   └ 僅口頭答應照顧 ✗
│
├── ② 不以契約關係為必要
│   └ 事實上承擔即可（契約可能無效仍有保證人地位）
│
└── ③ 須有客觀合理的信賴基礎
    └ 被保護者合理信賴行為人已接手保護
```

> **深山登山客案**：獨居深山者對登山客被蛇咬無保證人地位（無任何關聯性）→ 保證人地位的功能在於建立**特定關聯性**，並非「能救而不救就有罪」

---

### 三、監督型保證人

#### （一）危險源的監督

- **人的危險源**：精神病院管理者對有攻擊性的病患（龍發堂案例）
- **物的危險源**：須為人或物「本身」所帶來的危險

**重要限制：物偶然成為犯罪工具 → 無監督義務**

```
危險源監督
├── 物本身的危險 → 有監督義務
│   例：精神病患的攻擊行為
│
└── 物偶然成為犯罪工具 → 無監督義務
    例：牆壁被噴漆（誹謗內容）→ 屋主無刪除義務
    例：部落格被留言（誹謗內容）→ 版主無刪除義務
```

> **父母對小孩**：兩種義務都有（保護＋監督）→ 恐龍家長不能只承認保護義務而否認監督義務

#### （二）商品製造人責任

- 製造的商品有加害他人危險 → 出賣人負有**收回義務**
- 例：食安疑慮、車輛暴衝、電腦爆炸

#### （三）危險前行為（§15 II）

##### 基本概念

- **唯一有法律明文**的保證人地位
- 核心思想：**誰製造危險，誰就有控管義務**

> 實務案例：把槍借人玩（走火致死）、池塘邊追人（對方落水不救）、飯鍋下毒（B誤食死亡）

##### 學說爭議：因果前行為 vs 違背義務前行為

| | 因果前行為 | 違背義務前行為（**通說**） |
|---|----------|----------------------|
| **定義** | 一切造成法益危險的行為 | 僅**有過錯**引發法益危險的行為 |
| **設限** | 不設限 | 有設限（須有義務違反） |
| **代表** | 黃榮堅 | 通說多數學者 |

##### 三大區別實益

| 情境 | 因果前行為 | 違背義務前行為（通說） |
|------|----------|-------------------|
| **①無過失造成危險**（騎車撞屁孩） | 有救助義務 | **無**救助義務 |
| **②正當防衛後救歹徒**（★最常考） | 有救助義務 → 但搭配**無期待可能性** → 不罰 | **無**救助義務（合法行為＝無過錯） |
| **③緊急避難後救被犧牲者** | 有救助義務（當然有） | 原則無 → 但通說**開例外**（犧牲者損害由避難者導致） |

##### 正當防衛後的救助義務（★考試重點）

```
正當防衛 → 打傷歹徒 → 不救 → 歹徒死亡

分析架構：
┌── 前段：防衛行為
│   └→ §277 I 傷害罪 → 正當防衛阻卻違法 → 不成立
│
└── 後段：不救助歹徒
    └→ 過失致死的不作為犯？
        ├ 通說（違背義務前行為）→ 無保證人地位 → 不成立
        └ 少數說（因果前行為）→ 有保證人地位
          └→ 但：無期待可能性 → 罪責阻卻 → 不成立
```

**注意**：此類題目必須**前後分段論**，不能直接論傷害致死（§277 II），因為前段有阻卻違法事由，後段沒有，無法合併評價。

##### 緊急避難後的救助義務

- 通說本採違背義務前行為 → 緊急避難是合法行為 → 原則無救助義務
- 但通說覺得法感不對 → **開例外**：被犧牲者的損害是避難者導致 → 例外要救
- 黃榮堅老師採因果前行為 → 不需開例外，本來就有救助義務 → 邏輯一貫
