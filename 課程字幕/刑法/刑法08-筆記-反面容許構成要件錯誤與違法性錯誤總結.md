# 刑法08 筆記：反面容許構成要件錯誤與違法性錯誤總結

> 來源：刑法08 課程字幕 00:00:01 ~ 00:20:35

## 📖 法條原文速查

> **§23**（正當防衛）
> 對於現在不法之侵害，而出於防衛自己或他人權利之行為，不罰。但防衛行為過當者，得減輕或免除其刑。

> **§24**（緊急避難）
> I：因避免自己或他人生命、身體、自由、財產之緊急危難而出於不得已之行為，不罰。但避難行為過當者，得減輕或免除其刑。
> II：前項關於避免自己危難之規定，於公務上或業務上有特別義務者，不適用之。

> **§21**（依法令之行為／上級命令）
> I：依法令之行為，不罰。
> II：依所屬上級公務員命令之職務上行為，不罰。但明知命令違法者，不在此限。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「反面容許構成要件錯誤之法律效果為何？」 | 計罪說（多數）：**無任何效果**，原本論什麼罪就論什麼罪；未遂說：結果不法之抵銷→**未遂犯** |
| 「何謂反面容許構成要件錯誤？」 | 客觀上**有**阻卻違法前提事實存在，行為人主觀上**不知道** → 偶然系列 |
| 「二階論如何處理反面容許構成要件錯誤？」 | 客觀不法打叉（負面不法不存在）＋主觀故意打勾 → **本來就得出未遂結論**，不需另套學說 |
| 「容許構成要件錯誤（正面/反面）的寫作位置？」 | 統一放在**違法性**（因為是違法性的錯誤） |
| 「誤想防衛中阻卻故意後的過失判斷基準為何？」 | 看行為人對「**發生誤想**」有無過失，**非**對構成要件結果有無過失 |
| 「反面容許構成要件錯誤的出題趨勢？」 | 近年出題機率**高於**正面的誤想系列（後者已被考爛） |

## 一、反面容許構成要件錯誤（偶然系列）

### 定義

```
客觀上有阻卻違法的前提事實 ＋ 行為人主觀上不知道
= 反面容許構成要件錯誤（偶然系列）
```

**經典案例**：砸破仇人窗戶（純報復心態），結果仇人家瓦斯漏氣，反而救了一命 → 偶然避難

### 三種學說比較

| 學說 | 體系歸屬 | 推導方式 | 結論 | 備註 |
|------|---------|---------|------|------|
| 古典犯罪體系 | 違法性純客觀 | 客觀有阻卻違法事由即阻卻 | **直接阻卻違法** | 現已無人採 |
| **三階論計罪說**（多數說） | 三階論 | 偶然之好事不影響法敵對意志 | **無任何法律效果** | 原本論什麼罪就論什麼罪 |
| **三階論未遂說** | 三階論 | 結果不法之抵銷 | **未遂犯** | 關鍵字：結果不法的抵銷 |
| 二階論 | 二階論 | 客觀不法打叉＋主觀故意打勾 | **未遂犯** | 直接得出，不需另套學說 |

### 三階論未遂說的推導過程（結果不法之抵銷）

```
行為不法 ＋ 結果不法 → 既遂犯（完整不法）
                │
偶然存在的阻卻違法事實 → 抵銷結果不法
                │
僅剩行為不法（無結果不法）→ 未遂犯
```

- 客觀上消滅了危難 → 好的結果抵銷壞的結果（結果不法被抵銷）
- 只剩行為不法 → 類比未遂犯（未遂犯也是只有行為不法、無結果不法）

### 二階論的推導

```
正面不法（構成要件）：✓ 存在
負面不法（阻卻違法）：客觀上有避難情狀 → 負面不法不存在
                      ↓
         客觀不法 = ✗（打叉）
         主觀故意 = ✓（打勾）→ 整體結果：未遂
```

### 考試寫作方式

1. 列**計罪說**（多數說）：反面容許構成要件錯誤無任何法律效果
2. 列**未遂說**：結果不法之抵銷 → 論未遂犯
3. 括號補充：「若採二階論，本來就會得出未遂犯之結論」

> ⚠️ 中間推導過程很難寫、考試不建議展開，直接寫結論即可

## 二、誤想的依法令行為 / 公務員上級命令（§21）

### 案例

- 公務員接命令拆違建，結果**搞錯對象**，拆的根本不是違建
- 客觀上：對實際被拆建築物**無上級命令**存在
- 主觀上：行為人**誤認有合法命令**
- 法律評價：**誤想的上級命令**（容許構成要件錯誤的一種）

### 重要觀念：所有阻卻違法事由都有誤想 / 偶然系列

```
阻卻違法事由
├── 正當防衛（§23） → 誤想防衛 / 偶然防衛
├── 緊急避難（§24） → 誤想避難 / 偶然避難
├── 依法令行為（§21 I） → 誤想的依法令行為
├── 上級命令（§21 II） → 誤想的上級命令
├── 業務上正當行為（§22） → 誤想的業務正當行為
└── 超法規（被害人承諾等） → 誤想的被害人承諾
```

## 三、誤想系列的過失判斷

### 重要提醒

誤想防衛中，阻卻故意後論「過失犯」時：

| 過失的判斷基準 | 內容 |
|--------------|------|
| ✗ 不是看 | 行為人對構成要件結果有無過失（已有故意，當然有過失，問這個無意義） |
| **✓ 是看** | 行為人對「**發生誤想這件事**」有無過失 |

- 例：行為人若稍加注意就能查明沒有侵害 → 對發生誤想有過失 → 過失犯成立
- 例：行為人已盡合理注意仍發生誤想 → 對發生誤想無過失 → 無罪
