## 📋 實務見解速查

> **113年法律座談會**（夾娃娃機案）：夾娃娃機店內數臺機器雖分屬不同臺主所有，但外觀上看起來同一持有狀態，小偷偷數臺機器零錢→侵害**一個**財產法益。

> **實務見解**（放火罪法益數）：放火罪法益為公共安全，不考慮被焚毀的家數。燒毀一整排連棟透天→仍為一個法益。

> **實務見解**（先誣告後偽證）：誣告與偽證成立想像競合。（但理由與結論不對應→學者批評）

> **實務見解**（偽造文書/有價證券罪數）：偽造文書及偽造有價證券罪數以**被冒名者人數**計算，非以文書/證券張數計算。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「區分純正/不純正競合用什麼標準？」 | 多數說：**法益數**；少數說（許澤天、陳志輝）：不純正競合類型 |
| 「專屬法益如何計算法益數？」 | **數人頭**（生命、身體、自由、名譽、隱私） |
| 「數行為侵害同一人專屬法益，一個還數個法益？」 | **永遠數法益**（先打一拳再踹一腳→兩個法益/數罪） |
| 「財產法益數如何認定？」 | 看**持有個數**（非所有權人數） |
| 「超個人法益（國家/社會法益）法益數？」 | 原則**單一認定**，不考慮被害人數 |
| 「放火燒一排透天，幾個法益？」 | **一個**（公共安全→社會法益→單一認定） |
| 「發掘夫妻合葬墳墓兩具棺木，幾個法益？」 | **一個**（善良風俗→社會法益→單一認定） |
| 「一狀誣告數人，幾個法益？」 | **一個**（國家法益→單一認定） |
| 「偽證罪，同案件不同審級虛偽陳述幾個法益？」 | **一個**（以訴訟件數為準） |
| 「分別向偵查與懲戒機關誣告公務員？」 | **兩個**法益（兩套不同司法系統→例外） |
| 「偽造文書/有價證券的法益數怎麼算？」 | **例外**以被冒名者人數計算（唯一考慮被害人數的超個人法益犯罪） |
| 「偽造三張同一人簽發本票？」 | **一個**法益（同一人被冒名） |
| 「偽造三張不同人借據？」 | **三個**法益（三人被冒名） |
| 「偽造多數外國貨幣（如人民幣）？」 | **一個**法益（人民幣＝有價證券，發行機關只有中國人民銀行一個） |
| 「殺人未遂＋被害人有受傷，如何競合？」 | **想像競合**（殺人未遂＋傷害既遂→從一重處斷） |
| 「先誣告後偽證怎麼競合？」 | 實務：**想像競合**（但理由被批評牛頭不對馬嘴） |
| 「攝錄兩人性行為的性影像，幾個法益？」 | **兩個**（兩人各有隱私法益→想像競合） |

## 正文

### 一、純正 vs 不純正競合的區分標準

```
區分標準爭議
│
├── 多數說（本課採用）：用「法益數」區分
│   ├── 侵害一個法益 → 不純正競合
│   └── 侵害數個法益 → 純正競合
│
└── 少數說（許澤天、陳志輝、早期林山田）：
    └── 用「不純正競合的類型」區分
        └── 先檢查有無符合法條競合/吸收關係等
        └── 符合→不純正競合；不符合→純正競合
```

#### 兩說差異案例：殺人而毀損衣服

| 比較項目 | 法益數說（多數說） | 不純正競合類型說 |
|---------|-----------------|---------------|
| 分析 | 生命＋財產＝兩個法益 | 殺人常伴隨毀損衣物→吸收關係 |
| 結論 | **想像競合** | **法條競合**（只論殺人） |

> **實際差異案例很少**：殺人毀損衣服、偽造文書行使與詐欺的競合等。以法益數說為主流且較好學。

### 二、法益數認定

#### （一）專屬法益：數人頭

##### 適用法益類型
- 生命、身體、自由、名譽、**隱私**

> ⚠️ 隱私≠名譽（不希望別人知道住址→不是覺得住那邊可恥→隱私獨立於名譽）

##### 核心規則

```
專屬法益
│
├── 一行為侵害數人 → 數法益（想像競合）
│   例：打擊錯誤→要打A沒打到打死B→兩個生命法益
│
├── 數行為侵害同一人 → 永遠數法益
│   例：早上揍一拳＋晚上踹一腳＋隔天又揍一拳→三個法益
│
└── 實際應用
    ├── 攝錄兩人性行為 → 兩個隱私法益 → 想像競合
    ├── 廁所裝針孔偷拍同一人多次 → 每次一個法益
    └── 數次性侵同一人 → 每次一個法益（不因同一被害人而為一法益）
```

> ⚠️ **一試近年熱門考點**：攝錄性影像（§319-1），只要有相對人的性行為（非自慰/裸體），一定有想像競合問題。

##### 考題應用：犯意升高（434/444頁）

- 先趁機性交（§225）→後升高為強制性交（§221）
- 重點**不在**§221 vs §225法益是否相同
- 重點在：**數行為侵害專屬法益→永遠數法益→數罪併罰**

---

#### （二）財產法益：看持有個數

```
財產法益數
│
├── 看的是「持有狀態」→ 非所有權人數
│
├── 例1：我家被偷（含借用的iPad）→ 一個持有狀態 → 一個法益
│   （iPad雖屬金榜函授所有，但外觀上由我持有監督）
│
└── 例2：夾娃娃機店內偷數臺零錢（不同臺主）
    → 外觀上同一持有狀態 → 一個法益
    （113年法律座談會）
```

---

#### （三）超個人法益：原則單一認定

##### 核心原則
- 超個人法益＝無被害人→不以被害人數計算法益數
- **原則**：單一認定

##### 各類型整理

| 犯罪類型 | 法益數認定 | 說明 |
|---------|----------|------|
| **放火罪** | 一個 | 不考慮被焚毀家數（公共安全） |
| **發掘墳墓** | 一個 | 夫妻合葬兩棺木→仍一個（善良風俗） |
| **縱放脫逃** | 一個 | 一次縱放多名人犯→一個（國家司法權） |
| **偽證罪** | 以訴訟件數計 | 同案不同審級虛偽陳述→一個；不同案件→數個 |
| **誣告罪** | 見下表 | 原則一個，但有例外 |
| **偽造文書/有價證券** | ⚠️ **例外：以被冒名者人數計** | 唯一考慮被害人數的超個人法益犯罪 |

##### 偽證罪法益數

```
偽證罪
├── 陷害數人 → 一個法益
├── 同案件不同審級虛偽陳述 → 一個法益
│   └── 理由：偽證者一路做到底（偵查→一審→二審），犯意同一
└── 不同訴訟件數 → 數個法益
```

##### 誣告罪法益數

```
誣告罪
├── 一狀誣告數人 → 一個法益
├── 對同一人誣告數個犯罪事實 → 一個法益
├── 同一事向數個機關誣告 → 一個法益
│   （派出所/分局/地檢署/高檢署/法院/總統府→最後都到地檢署）
└── ⚠️ 例外：分別向「偵查」＋「懲戒」機關誣告
    → 兩個法益（兩套不同司法系統）
```

##### 先誣告後偽證

| 見解 | 結論 | 理由 |
|------|------|------|
| **實務** | 想像競合 | 「誣告者為證明確有其事，通常會偽證，難以期待反於誣告之證詞」 |
| **學者批評** | 理由推導出的應是法條競合（吸收） | 實務理由→偽證是誣告附隨行為→應只論誣告；結論卻說想像競合→牛頭不對馬嘴 |

> ⚠️ **一試近年熱門考點**：先誣告後偽證，結論採想像競合。

---

##### 偽造文書/有價證券：唯一例外

```
偽造文書/有價證券的法益數
│
├── 以「被冒名者人數」計算（非文書/證券張數）
│
├── 例1：偽造三張伊谷的本票 → 一個法益（一人被冒名）
├── 例2：偽造三人的借據 → 三個法益（三人被冒名）
│
└── 特殊：偽造多數人民幣
    ├── 人民幣＝有價證券（通說）
    ├── 發行機關＝中國人民銀行（一個機關）
    └── → 一個法益
```

### 三、重罪未遂與輕罪既遂的競合

#### 核心規則

```
重罪未遂 ＋ 輕罪既遂
│
├── 重罪既遂（如殺人既遂）→ 輕罪（傷害）不用另論（法條競合吸收）
│
└── 重罪未遂（如殺人未遂）＋ 輕罪既遂（傷害既遂）
    ├── 被害人無受傷 → 純殺人未遂
    ├── 被害人有受傷 → 殺人未遂＋傷害既遂 → ★想像競合★
    └── 理由：兩種殺人未遂（無傷vs有傷/重傷）不法內涵明顯不同
         → 必須完整評價輕罪既遂的不法
```

#### 適用範圍
- 殺人未遂＋傷害/重傷既遂
- 強制性交未遂＋猥褻既遂
- 其他保護法益相同的重罪未遂＋輕罪既遂組合

#### 考試寫法

| 寫法 | 操作方式 | 適用場合 |
|------|---------|---------|
| **正常寫法** | 開標殺人未遂 ＋ 開標傷害既遂 → 競合處寫想像競合 | 三等考試（時間充裕） |
| **偷懶寫法** | 只開標殺人未遂 → 到競合處才提及傷害既遂並說明想像競合 | 司律二試（時間緊迫） |

> ⚠️ **再次提醒**：想像競合從一重處斷，**不可寫**「只論殺人未遂」→正確寫法是「殺人未遂與傷害既遂想像競合，從一重處斷」。
