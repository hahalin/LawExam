# 刑法11 筆記：未遂犯概論與犯罪行為階段

> 來源：刑法11 課程字幕 00:30:00 ~ 01:01:00

---

## 📖 法條原文速查

> **§25**（未遂犯）
> I：已著手於犯罪行為之實行而不遂者，為未遂犯。
> II：未遂犯之處罰，以有特別規定者為限，並**得按既遂犯之刑減輕之**。

> **§271 III**（預備殺人）
> 預備犯第一項之罪者，處二年以下有期徒刑。
> → **形式預備犯**

> **§328 V**（預備強盜）
> 預備犯強盜罪者…
> → **形式預備犯**

> **§347**（擄人勒贖罪）
> 意圖勒贖而擄人者…
> → 一開始就有勒贖意圖而擄人

> **§348-1**（準擄人勒贖罪）
> 擄人後意圖勒贖者…
> → 條文無「行為」→ 需加上勒索行為才不會是思想犯

> **§335**（侵占罪）
> → 傳統「易持有為所有」→ 若無外在行為即屬思想犯→ 學說要求需有客觀行為

> **§199**（偽造貨幣器械罪）
> → **實質預備犯**

> **§187**（加重持有危險物品罪）
> 意圖犯罪而持有軍用槍砲、子彈…
> → **實質預備犯**

> **§185-1**（劫持民用航空器罪）
> → 形式預備犯口訣中「飛機」所指（蔡聖偉老師自加）

> **§277**（普通傷害罪）
> → **沒有罰未遂**，考試不可寫「傷害未遂」

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「犯罪行為階段的正確順序為何？」 | 決意→陰謀→預備→**著手**→完成→既遂→終了 |
| 「著手與未遂的關係？」 | **一體兩面**：有著手必然進入未遂階段 |
| 「完成與終了有何不同？」 | 完成＝**行為做完**；終了＝**法益侵害結束** |
| 「哪些犯罪有既遂後到終了的階段？」 | 僅少數犯罪：**繼續犯**、**財產犯罪**（如竊盜）。殺人傷害等狀態犯既遂同時終了 |
| 「陰謀犯處罰範圍？」 | 僅**內亂罪**與**外患罪**處罰陰謀 |
| 「背誦形式預備犯的口訣？」 | **內外放火殺強人＋一架飛機**（內亂、外患、放火、殺人、強盜、擄人勒贖＋劫持民航器） |
| 「§277 普通傷害有無處罰未遂？」 | **無**。不可寫「傷害未遂」 |
| 「未遂犯處罰根據通說？」 | 留德老師多採**印象理論**（主客觀混合），留日老師多採**客觀未遂論** |

## 正文

### 一、犯罪行為階段

```
決意 → 陰謀 → 預備 → 著手 → 完成 → 既遂 → 終了
                       ▲
                   未遂起點
                 （著手＝未遂）
```

| 階段 | 意義 | 說明 |
|------|------|------|
| 決意 | 內心產生犯罪想法 | 刑法不罰單純思想 |
| 陰謀 | 二人以上共同謀議 | 僅罰**內亂罪、外患罪** |
| 預備 | 為犯罪做準備行為 | 大部分犯罪不罰預備 |
| **著手** | **開始實行犯罪** | **有著手才叫未遂** |
| 完成 | 行為做完 | 刑法上較不具重要性 |
| 既遂 | 構成要件完全實現 | 如：被害人死亡 |
| 終了 | 法益侵害結束 | 非每個犯罪都有此階段 |

#### 完成 vs. 終了

| 比較 | 完成 | 終了 |
|------|------|------|
| 定義 | 行為做完 | 法益侵害結束 |
| 殺人罪 | 砍完、被害人倒下 | 被害人死亡（既遂即終了） |
| 竊盜罪 | 竊取行為完畢 | 持有贓物狀態結束（有紅色區段） |
| 重要性 | 事實描述 | 影響**相續共同正犯**的認定 |

> ⚠️ 殺人、傷害等**狀態犯**→ 既遂同時即終了（無「既遂後終了前」階段）
> ⚠️ 竊盜等**財產犯罪**、**繼續犯** → 既遂後至終了前有一段時間

### 二、刑法不罰思想（思想犯問題）

#### §348-1 準擄人勒贖罪
- 條文：「擄人**後**意圖勒贖」
- 問題：條文只有「意圖」，無描述外在行為 → 若照字面是思想犯
- 解決：需加上**勒索行為**才成立本罪
- 與§347的區別：§347是「**意圖勒贖而擄人**」→ 一開始就有勒索意圖

| 比較 | §347 擄人勒贖 | §348-1 準擄人勒贖 |
|------|-------------|-----------------|
| 犯罪意圖 | 自始即有勒贖意圖 | 擄人後才生勒贖意圖 |
| 構造 | 意圖→行為 | 行為在先→意圖在後 |
| 解釋重點 | — | 需補充勒索行為要件 |

#### §335 侵占罪
- 傳統解釋「易持有為所有」→ 若無外在行為即是思想犯
- 學說要求：需有**客觀可識別的行為**才成立

### 三、預備犯

#### 形式預備犯 vs. 實質預備犯

| 比較 | 形式預備犯 | 實質預備犯 |
|------|-----------|-----------|
| 定義 | 總則有預備犯之一般規定 | 分則個別罪名自行規定 |
| 條文結構 | 「預備犯第X條之罪者」 | 獨立構成要件 |
| 討論空間 | 「預備」定義太廣泛，有正當性疑慮 | 分則解釋問題，較無爭議 |
| 例子 | §271 III 預備殺人、§328 V 預備強盜 | §199 偽造貨幣器械、§187 持有軍用槍砲 |

#### 形式預備犯口訣（蔡聖偉老師）

> **「內外放火殺強人＋一架飛機」**

| 口訣 | 對應罪名 |
|------|---------|
| 內 | 內亂罪 |
| 外 | 外患罪 |
| 放火 | 放火罪 |
| 殺 | 殺人罪（§271 III） |
| 強 | 強盜罪（§328 V） |
| 人 | 擄人勒贖罪 |
| 飛機 | 劫持民用航空器罪（§185-1）→ 蔡聖偉老師自加 |

#### 形式預備犯的正當性疑慮

- 批評：「預備行為」定義太廣 → 買刀、比價、調查行蹤都是「準備」→ 不符法律明確性
- 回應：限縮解釋 → 唯有**重要的準備行為**才算預備（如拿刀埋伏）

### 四、未遂犯的處罰根據

| 學說 | 核心主張 | 採用者 |
|------|---------|--------|
| **客觀未遂論** | 未遂犯有**法益侵害的危險** | 留日老師（甘添貴等） |
| 主觀未遂論 | 未遂犯與既遂犯**一樣壞**（法敵對意思） | 幾乎無人採（歷史說法） |
| **印象理論**（主客觀混合） | 未遂犯透過客觀行為展現法敵對意思，讓人民產生**法律威信被動搖的印象** | 留德老師、德國通說 |

> **印象理論白話版**：接到詐騙電話雖沒被騙，但會覺得「這國家治安怎麼這麼差」→ 法律秩序受動搖的印象 → 所以未遂犯值得處罰

---

### 五、未遂犯的四大要件

```
未遂犯成立
├── 1. 故意
├── 2. 著手（有著手才叫未遂）
├── 3. 不遂（客觀構成要件未完全實現）
└── 4. 法律有處罰的明文規定
```

- **故意**：未遂犯必須出於故意（過失無未遂）
- **著手**：著手前僅為預備或陰謀
- **不遂**：客觀構成要件六格（主體、客體、行為、結果、因果關係、情狀）任一未實現
- **明文**：未遂犯之處罰以有特別規定者為限（注意 **§277 傷害罪無罰未遂**）

#### 普通未遂的法律效果

- 符合四大要件 → 成立**普通未遂**（舊稱「障礙未遂」，日語用法）
- 效果：**得減**（可減可不減，通常會減，但情節惡劣者實務不給減）
