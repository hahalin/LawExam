# 刑法03 筆記

## 一、公務員（續）

### （一）授權公務員

- **定義**：其他依法律從事**公共事務**，而具有**法定職務權限**的人（§10 II）
- 與身分公務員差異：不需要「服務於國家或地方自治團體所屬機關」（不需在公家機關上班）

#### 1. 公立學校／公立醫院／公營事業人員

- 原則上**不是身分公務員**（手上基本上沒有公權力）
- 但在辦理**政府採購案件**時 → 轉變為**授權公務員**
  - 例：公立國小校長、總務主任依政府採購法蓋操場 → 洩漏底標 → 貪汙犯罪
- **注意**：一般行政機關做採購的人 → 本來就是**身分公務員**，不需論授權

> **雙階理論與刑法的關係**
> - 行政法上：前階段（決定締約對象）= 公法行政處分 → 行政法院；後階段（履約）= 私法關係 → 民事法院
> - **刑法上不適用雙階理論**：不管前階段或後階段，只要碰到政府採購案件，**通通都是授權公務員**
> - 理由：政府採購案件公權力屬性很強，就算後階段是私法關係，公權力介入程度依然很深

#### 2. 公立醫院藥委會委員 → **不是**刑法上公務員

- 藥委會：院長＋各科主任組成，決定醫院買什麼藥、買多少
- 案例：省立屏東醫院精神科主任兼藥委會委員，收廠商錢建議買特定藥
- 關鍵：藥委會做成決定後，**適用政府採購法的主體是醫院總務室**，不是藥委會委員
- 結論：藥委會委員非刑法上公務員

#### 3. 大學教授擔任政府環評委員 → **是**授權公務員

- 理由：處理公共事務＋有**獨立判斷空間**＋法定職務權限
- 不管公私立大學教授，擔任政府環評委員時 → 授權公務員

#### 4. 大學教授核銷國科會經費 → **不是**刑法上公務員

- 過去曾有實務認為是，但**後來不採此說**
- 理由：
  1. 做研究計畫**不是公共事務**
  2. 適用政府採購法的是**學校總務單位**，不是教授本人
- 不實核銷 → 論業務上登載不實、詐欺等罪，**不論貪汙犯罪**

### （二）委託公務員

- **定義**：受國家或地方自治團體所屬機關依法委託，從事與委託機關權限有關之公共事務者
- 對應行政法概念：**行政受託人**（行政程序法§16 I）

#### 1. 典型案例

| 案例 | 是否委託公務員 | 理由 |
|------|:-:|------|
| 海基會驗證中國大陸文書 | ✓ | 受委託行使審查文書的公權力 |
| 民間代驗場驗車 | ✓ | 有**獨立判斷空間**，無監理機關人員在旁監督 |
| 機車行做廢氣排放檢驗 | ✓ | 同上理 |

#### 2. 行政受託人 vs 行政助手

| 比較項目 | 行政受託人（委託公務員） | 行政助手（非公務員） |
|----------|:-:|:-:|
| 自主決定空間 | **有**，本於自己判斷 | **無**，完全聽命行事 |
| 旁邊有無監督 | 無行政機關人員在旁 | 有行政機關人員指揮 |
| 刑法上地位 | 委託公務員 | 非刑法上公務員 |

#### 3. 行政助手案例

- **違規拖吊民間業者**：完全聽命警察指揮，車要拖或放由警察決定 → 行政助手
- **自來水公司／臺電做斷水斷電**任務 → 行政助手
- **受地檢署委託驗尿的民間生技公司**：照程序跑，無裁量空間 → 行政助手
- **里長處理易服社會勞動登記**：結案由**檢察官**決定，里長只是助手 → 行政助手（頂多業務上登載不實）

### （三）公務員爭議類型

#### A. 視具體情況決定

| 類型 | 公務員？ | 說明 |
|------|:-:|------|
| 替代役男 — 警察役 | ✓ 授權公務員 | 與公權力有關 |
| 替代役男 — 社會服務等 | ✗ | 照護弱勢、資源回收等與公權力無關 |
| 士兵 | 視情況 | 依法行公務符合§10 II 時 → 可能是公務員 |
| 清潔隊員 — 掃地 | ✗ | 機械性勞動，無法定職務權限 |
| 清潔隊員 — 稽查、開單 | ✓ | 有判斷廢棄物屬性、告發的權限 |

#### B. 法律上有爭議

**1. 義交（含義警、義消）**

| 見解 | 結論 | 理由 |
|------|------|------|
| **多數說** | 行政助手，**非**公務員 | 行政法通說認定 |
| **少數說**（吳耀宗） | **授權公務員** | 雖非委託公務員，但指揮交通有法定權限＋屬公共事務，符合§10 II 後段 |

**2. 代收稅款銀行行員**

| 見解 | 結論 | 理由 |
|------|------|------|
| **多數說** | 行政助手，**非**公務員 | 照單全收，無裁量空間；稅額爭議找國稅局不是找銀行 |
| 近年少數實務 | 是公務員 | 收稅是公權力行使＋行員以自己名義做成收據 |

## 二、刑法效力範圍

### （一）人的效力範圍

- **屬地原則**（§3）：發生在我國領域內的犯罪 → **不問行為人/被害人國籍** → 我國刑法適用
  - 例：越南移工宿舍內竊盜 → 我國法院審理

#### 例外：雖在我國領域但無刑法適用

| 例外類型 | 內容 | 性質 |
|----------|------|------|
| 總統刑事豁免權（憲法§52） | 除內亂外患罪外，非經罷免或解職不受刑事訴究 | **程序障礙**（非實體免責），卸任後即可追訴 |
| 立法委員／縣市議員言論免責權 | 行使職權之言論免責 | **實體免責** |
| 國際法例外 | 外交人員、使節等 | 國際法問題，刑法不考 |

### （二）時間效力範圍（§2 I）

- **從舊從輕原則**：原則適用**行為時法**，例外適用**最有利於行為人之法律**

#### 1. 法律變更之認定

- **法律變更** = 修正影響**國家刑罰權範圍**（有罪⇔無罪、刑度改變、處罰範圍改變）

| 情形 | 是否法律變更 | 說明 |
|------|:-:|------|
| 頓號 → 或 | ✗ | 意思相同，可罰性未變 |
| 銀元 → 新臺幣（108年統一幣值） | ✗ | 刑罰權範圍未變，僅換算 |
| 贓物罪「牙保」→「媒介」 | ✗ | 文言文 → 白話文，意思相同 |
| 偽造舊版貨幣後新版發行（事實變更） | ✗ | 事實變更非法律變更 |

#### 2. 空白刑法補充規範變更

- 問題：補充空白刑法的**行政命令**變更（如臺灣獼猴從保育類除名），算法律變更嗎？

| 見解 | 結論 | 理由 |
|------|------|------|
| **實務（否定說）** | **不算** | §2 I「法律」專指處罰規定本身，不含背後補充規範 |
| **學說（肯定說）** | 算 | 空白刑法＋補充規範合一才彰顯處罰範圍，補充規範變更 → 處罰範圍改變 |

> **選擇題選「不算」（實務見解）**

#### 3. §2 I 各種情形操作

| 情形 | 處理方式 | 依據 |
|------|----------|------|
| **入罪化**（行為時無罪→裁判時有罪） | 直接適用**§1 罪刑法定**，行為無罪 | 法律不溯及既往（§1 位階高於§2） |
| **除罪化**（行為時有罪→裁判時無罪） | 實務：**刑訴§302 第4款判免訴**（先程序後實體） | 不走§2 I |
| **行為時有罪＋裁判時有罪**（刑度變更） | **§2 I 從舊從輕**操作 | 比較行為時法與裁判時法 |

- **除罪化**包含：立法者主動刪除 ＋ **大法官宣告違憲**（如通姦罪791號解釋）
- **限時法失效**是否算除罪化：
  - 否定說：法律消失，非法律觀念改正
  - 肯定說：法已失效，處罰無犯罪預防意義

#### 4. 裁判確定後之除罪化（§2 III）

- **處罰或保安處分裁判確定後**，未執行或執行未完畢，法律變更為不處罰 → **免其刑或保安處分之執行**
- 案例：
  - 通姦罪違憲當天 → 法務部午夜12點前釋放所有因通姦服刑之人
  - 強制工作違憲 → 原被宣告者轉執行刑罰或釋放
- **限制**：
  - 前提：處罰尚**未執行或執行未完畢**（已執行完畢無效果）
  - 僅限**除罪化**，不含裁判確定後刑罰減輕

#### 5. 法律效果輕重比較（§35）

- **同種之刑**：先比**上限**，上限相同再比**下限**
- **併科 vs 選科**：選科較有利（有單獨罰金選項，可能不用關）
  - 例：舊業務過失致死（得**併**科罰金）vs 新過失致死（**或**罰金）→ 新法有利

#### 6. 法令數次變遷 — 中間法

- 法律多次修正時，**最有利的法律不一定是裁判時法**，可能是**中間法**
- 例：強制性交罪 行為時3-10年 → 中間修為5年以下 → 裁判時修回1-7年 → 適用中間法（5年以下）

### （三）空間效力範圍

#### 1. 領域概念

| 分類 | 內容 |
|------|------|
| **真實領域** | 領土、領空、領海 |
| **想像領域** | 我國籍船艦／航空器（看**註冊編號**，非所有權人或航空公司）、駐外使館 |

- 我國籍航空器：註冊編號**B開頭＋五個數字**
  - 中國：B＋四個字；香港澳門：B＋三個英文字
  - 若掛美國N編號 → 美國籍航空器（即使外觀是華航）
- **駐外使館**：需駐在國**同意放棄管轄權** → 才算我國領域

> **中國大陸是否為我國領域？**
> - **實務**：是（現行憲法及法律框架未將大陸當外國）
> - **學說**：有反對意見（實際無管轄權）
> - **考試建議**：採實務見解（後續較好作答）

#### 2. 境內犯罪

- 全部發生在我國領域（含想像領域）→ 有我國刑法適用
- **外國籍航空器降落我國機場** → 我國法院對上面犯罪有管轄權

**隔地犯（§4）**：

- **行為地**或**結果地**任一在我國領域內 → 視為**境內犯罪**
- 結果地**不需實際發生結果**，預期中可能發生的結果也算
- 跨國正犯與共犯：正犯在臺犯罪，共犯在國外教唆/幫助 → 隔地犯

> **網路隔地犯的限縮**（李聖傑老師）：
> - 不能因為我國看得到某網站內容就認定為隔地犯
> - 除非：違反人類社會普遍價值（種族屠殺、人口買賣、兒童性剝削）或確實侵害我國利益

#### 3. 境外犯罪 — 三大原則

| 原則 | 條文 | 重點 | 適用對象 / 罪名 |
|------|------|------|------|
| **屬人** | §6 | 我國**公務員**境外犯特定罪 | 貪瀆、§163縱放人犯、§213偽造公文書、§336侵佔 |
| **屬人** | §7 | 我國**人民**境外犯**最輕本刑三年以上**之罪（犯罪地亦須處罰） | 殺人✓、竊盜✗、傷害✗ |
| **屬人** | §5⑪ | 我國人境外犯**加重詐欺**（§339-4） | 2016年肯亞詐騙案催生 |
| **保護** | §5①②③⑤⑥⑦ | 保護**國家社會** | 內亂/外患/妨害公務/偽造貨幣/偽造有價證券（含§201-1）/偽造文書 |
| **保護** | §8 | 我國人在外國**被害**，加害之外國人犯最輕三年以上之罪 | 持刀搶劫✓、竊盜✗ |
| **世界** | §5④⑧⑨⑩ | **萬國公罪**，不問與我國利益有無關係 | 劫機/毒品（施用持有除外）/奴役買賣人口/海盜 |

**§5⑪歸類爭議**：

| 見解 | 理由 |
|------|------|
| **屬人**（許澤天，較佳） | 立法目的在讓**境外詐騙的國人**返國後可追訴，重行為人國籍 |
| 保護 | 保護被害人（部分學者） |
| 世界 | 詐騙為萬國公罪（少數見解） |

**本刑之認定**（實務）：

- **不含**刑法**總則**加重減輕（如未遂得減）
- **含**刑法**分則**加重減輕
- 學理：無「未遂罪」之概念，只有「某罪之未遂犯」→ 犯的罪仍是本罪

> **答題注意**：刑法空間效力範圍應在**進入三階論之前**檢討，非三階之後

#### 4. 外國裁判效力（§9）

- **前提**：該行為有我國刑法適用
- **本文**：同一行為雖經外國裁判，**仍得依我國法處斷**（各國司法主權獨立）
- **但書**：在外國已受全部或一部**執行**者 → **得**免其刑全部或一部執行
  - 「得」= 法院有裁量權，可全免、部分免、甚至不免（如查明外國實際未真正執行）

## 三、刑法上的行為概念

- 進入**三階論之前**的初步篩選：排除在刑法上不具意義的行為

### 非刑法上行為

| 類型 | 舉例 | 說明 |
|------|------|------|
| 非人類所為 | 動物攻擊、自然災害 | 但背後有**人力支配**則算（驅使比特犬咬人、違法開墾致土石流） |
| 非基於意識所為 | 睡覺翻身、夢遊 | 無意識成分 |
| 神經反射 | 膝跳反射、碰燙縮手 | 不經大腦 |
| 受直接強制 | 被踹倒壓碎瓷器、被硬抓去打人 | 完全無法控制 |

### 仍屬刑法上行為

| 類型 | 舉例 | 說明 |
|------|------|------|
| 經大腦的本能反應 | 撥蟲、受驚狂奔 | 雖不經思考但經過大腦 |
| 間接強制 | 脅迫你去砸東西（不做就殺全家） | 仍有意思自由（緊急避難問題） |
