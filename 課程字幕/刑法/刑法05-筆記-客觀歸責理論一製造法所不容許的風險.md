## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「客觀歸責理論有幾個層次？」 | **三層**：①製造法所不容許的風險 ②風險實現 ③構成要件效力範圍 |
| 「買機票希望仇人死於空難，結果飛機真的墜毀，有無製造法所不容許的風險？」 | **無**，搭飛機空難屬「法律上不重要的風險」，機率低到可忽略 |
| 「降低風險的行為是否成立犯罪？」 | **不成立**，降低風險＝沒有製造法所不容許的風險 |
| 「降低風險與替代性風險的區別？」 | **降低風險**＝拯救成功但人有受傷；**替代性風險**＝拯救失敗人還是死了 |
| 「替代性風險是否排除客觀歸責？」 | **爭議**：否定說→放在緊急避難處理；肯定說（新進）→排除客觀歸責（拯救本身是好事，不因失敗變壞事） |
| 「容許風險的判斷標準？」 | **利益衡量**：做這件事的好處 > 壞處 → 容許風險 → 沒有製造法所不容許的風險 |
| 「行為人對風險有特殊認知時如何處理？」 | **例外**納入判斷，肯定有製造法所不容許的風險（如知道飛機裝了炸彈仍買票） |

## 一、客觀歸責理論三大層次概述

```
客觀歸責理論
│
├── 第一層：製造法所不容許的風險
│   → 行為人有沒有「做錯事」？
│
├── 第二層：風險實現
│   → 行為人製造的風險A → 結果是否仍與A有關？（還是變成B？）
│
└── 第三層：構成要件效力範圍
    → 結果真的要行為人負責？（被害人自己的錯？第三人負責？）
```

## 二、第一層：製造法所不容許的風險

> 核心問題：行為人有沒有「做錯事」？

### 子原則 1：法律上不重要的風險

> 風險機率低到可以忽略，法律上視為不重要。

**案例：買機票空難案**
- 甲希望仇人死於空難，買了一張機票送仇人
- 仇人搭上飛機，飛機真的墜毀，仇人死亡
- 有無製造法所不容許的風險？→ **無**
- 搭飛機死於空難的機率極低＝法律上不重要的風險

> **老師強調**：人類的風險直覺不可靠，應看數據而非直覺。搭飛機是最安全的交通工具。

### 子原則 2：降低風險的行為

> 讓原本嚴重的結果變得更輕微，雖仍有損害，但整體法益侵害減少。降低風險＝**沒有**製造法所不容許的風險。

**案例：公車站搶救小學生**
- 失控砂石車衝向公車站，你拉著小學生逃走
- 逃走過程中小學生腿部擦傷

| 審查步驟 | 結論 |
|---------|------|
| 條件因果？ | **有**（不拉就不會受傷） |
| 製造法所不容許的風險？ | **無**（降低風險：不拉→死亡；拉→輕傷） |
| 結論 | **不成立**過失傷害 |

**降低風險也適用於共犯**：
- 朋友想殺人 → 你勸他「打傷就好」→ 降低風險
- 朋友想偷一萬 → 你勸他「偷五千就好」→ 降低風險

### 降低風險 vs 替代性風險

```
拯救行為的結果
│
├── 拯救成功＋人有受傷 → 降低風險（百分百排除客觀歸責）
│
├── 拯救成功＋毫髮無傷 → 皆大歡喜（不進入刑法討論）
│
└── 拯救失敗＋人還是死了 → 替代性風險（有爭議）
```

### 替代性風險（爭議）

**案例一：公車站搶救失敗**
- 拉小學生逃走→小學生頭撞電線桿→顱內出血死亡
- 不拉→小學生也會被砂石車撞死
- 結果：不拉也死，拉了也死（只是換一種方式死）

**案例二：火災丟嬰兒**
- 高樓失火，夫妻把嬰兒從窗戶丟下→消防員手滑沒接到→嬰兒死亡
- 不丟→嬰兒也會被燒死

| 學說 | 結論 | 理由 |
|------|------|------|
| **否定說**（傳統） | 替代性風險**不能**排除客觀歸責 | 法益將來必然受損，不代表喪失保護價值。構成要件審查的是法益侵害，不考慮「反正也會死」→ 放在**緊急避難**處理 |
| **肯定說**（新進） | 替代性風險**可以**排除客觀歸責 | 製造法所不容許的風險看「有沒有做錯事」→ 拯救是**好事** → 不因失敗就變壞事 → 成敗都應肯定其無過錯 |

> **結論**：越來越多學者採肯定說，認為替代性風險可排除客觀歸責。

### 子原則 3：容許風險

> 日常生活不存在零風險。法規或社會規範為每件事劃設一道容許界線。在界線以內＝容許風險＝沒有製造法所不容許的風險。

**本質**：利益衡量——做這件事的好處 > 壞處 → 容許風險。

**案例一：運動比賽**
- 棒球投出觸身球→機率低，整體好處 > 壞處→容許風險
- 籃球搶籃板撞傷→容許風險

**案例二：食品添加物**
- 種類與劑量未超過國家標準→容許風險
- 毒物學之父：「萬物皆有毒，凡是有劑量來決定」
- 跳脫劑量談毒物沒有意義（水喝太多也會中毒）
- 消費者以不理性方式食用（三餐吃同款泡麵一個月→腎壞掉）→泡麵公司無刑責→容許風險

**案例三：疫苗接種**
- 國家核准的疫苗（AZ、莫德納、BNT）
- 打疫苗產生不良反應→對醫師或製造商而言→容許風險
- 整體好處 > 壞處

### 例外：行為人對風險有特殊認知

> 客觀歸責原則上是**客觀判斷**（旁觀者角度），但行為人有特殊認知時，例外納入判斷。

**案例一：恐怖分子飛機**
- 一般情況：買機票給別人→法律上不重要的風險
- 特殊認知：你知道飛機被裝了炸彈→仍買票→**有**製造法所不容許的風險

**案例二：AZ疫苗（東吳轉學考）**
- 一般情況：打AZ疫苗→國家核准→容許風險
- 特殊認知：醫師已知病患體質特殊不適合打AZ（血栓風險高），病患再三拜託仍幫他打→**有**製造法所不容許的風險
- 教訓：容許風險的判斷要考慮特殊認知

```
客觀歸責的「客觀」
│
├── 原則：旁觀者角度（行為當下判斷，非事後上帝視角）
│
└── 例外：行為人有特殊認知 → 納入判斷
    ├── 恐怖分子飛機案 → 知道有炸彈
    └── AZ疫苗案 → 知道病患不適合
```

### 天燈案（容許風險＋風險實現的預告）

**事實**：參加地方政府主辦的天燈祈福活動→天燈飄到高速公路→正中擋風玻璃→駕駛重傷

**分析**：
1. 條件因果？有（不放天燈就不會車禍）
2. 製造法所不容許的風險？→ **無**（政府主辦活動＝容許風險）
3. 退一步，即使有→風險實現？→ **無**（天燈飄到高速公路撞擋風玻璃＝反常因果歷程）

> **考試思維**：放天燈是意外，不可能有故意犯的空間，直接寫過失犯即可。
