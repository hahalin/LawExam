# 刑法02 筆記

## 一、刑法的功能 — 保護法益

### （一）法益的概念

- **法益**：重要的社會生活利益，值得或必須用刑法保護的利益
  - 生命、身體、自由、財產 → 重要到一旦沒有就活不下去 → 法益
  - 並非所有利益都是法益（如不受廣告騷擾、不被噪音干擾等 → 程度不夠嚴重，無需刑法介入）

### （二）道德與法益的關係

- 犯罪行為大多也是嚴重的悖德行為，但**純粹不道德的行為不應以刑法處罰**
- 不道德行為的三種層次：

| 類型 | 有無具體傷害 | 刑法是否介入 | 舉例 |
|------|-------------|-------------|------|
| 不道德＋有損害＋程度不嚴重 | 有（輕微） | 否 | 捷運看影片不戴耳機、不讓座 |
| 不道德＋有損害＋判斷困難 | 有 | 否 | 博愛座（可能有隱形需求） |
| 不道德＋無具體傷害 | 無 | 否 | 血親性交（§230）、侮辱屍體 |

- **血親性交罪（§230）**：雙方成年合意＋安全措施，實際上無人受害，只是情感上過意不去 → 學者認為應刪除
- **侮辱屍體**：無繼承人的遊民屍體被利用 → 找不到保護法益
- **動物保護法**（附屬刑法）：只保護貓狗而不保護其他動物 → 實為保護愛貓愛狗人士的情感，非真正法益

### （三）法益的實務意義

- 確認保護法益 → 影響**構成要件的解釋**及**與他罪的競合關係**
- 例：肇事逃逸罪（§185-4）→ 保護法益不同，構成要件解釋就不同（給名片留聯絡方式是否仍成立）

### （四）刑法不保護被害人的報復心

- 處罰加害人 ≠ 保護被害人權益（被害人的損失不會因加害人受罰而恢復）
- **刑法的功能是預防犯罪**，不是滿足報復心

## 二、罪刑法定原則

### （一）基本概念

- **§1**：行為之處罰，以行為時之法律有明文規定者為限
- 核心精神：讓人民對自己行為是否成罪有**可預見性**
- 罪刑法定可能造成不正義（壞人被輕判或無罪），但罪刑不法定更糟糕（無辜者受罰）
  > 寧可讓有錯的人未受應有懲罰，也不要讓無辜的人受到懲罰

### （二）五大子原則

#### 1. 法律保留

- 只有**法律**（立法院通過、總統公布）才能規定犯罪與刑罰
- 自治條例：可科行政罰 ✓，不可科刑罰 ✗
- **空白刑法**：立法院制定法律，但將部分構成要件**授權行政機關以命令補充**
  - 例：§251 囤積生活必需用品 → 行政院命令指定「醫療用口罩」為生活必需用品（2020年）
  - 不違反罪刑法定（法律本體仍由立法院制定）

#### 2. 禁止習慣法

- 習慣法不得作為刑事判決的依據

#### 3. 明確性原則

- **構成要件明確**：人民要能事先知道什麼行為是犯罪
  - 反例：唐律「諸不應得為而為之者，笞四十」→ 概括條款，現代刑法絕不允許
- **法律效果明確**：每條罪需有刑度上下限
  - §32：有期徒刑最低為**兩個月**（未寫下限時的補充）
  - 不可寫「應給予適當處罰」這種無範圍的規定

#### 4. 禁止類推適用

- **類推適用（比附援引）**：法律禁止A，行為人做了跟A很像的事，裁判者說「反正跟A差不多，一樣不行」
- 如果允許類推 → 罪刑法定形同虛設
- 反面教材：
  - §202 偽造郵票罪 — 拼接兩張舊郵票使用，法院判「塗抹註銷符號」→ 違反罪刑法定
  - §185-4 肇事逃逸 — 現場擺爛不離開 ≠ 逃逸（若認定相同即為類推）
- **例外：有利於行為人的類推適用可以**
  - 例：§27 中止未遂（需已著手）→ 預備階段中止，類推適用§27使行為人獲減免 → 對行為人有利，可以

#### 5. 禁止溯及既往

- 不得用**事後公布的法律**處罰**先前已完成的行為**
- 例：§319-3（性影像罪）2023年公布 → 2022年偷存裸照的行為不可追訴
- 刑法空間效力規定也禁止溯及：§5第11款（加重詐欺管轄）2016年增訂 → 不可追溯在此之前的海外詐騙
- **例外①**：行為後法律對行為人有利 → 可溯及（§2第1項但書 — 從新從輕）
- **例外②**：非拘束人身自由的保安處分、沒收 → 適用裁判時法（§2第2項）

---

### （三）刑事法律效果三大類

| 類型 | 性質 | 目的 | 罪刑法定適用 |
|------|------|------|-------------|
| **刑罰** | 有期徒刑、無期徒刑、拘役、罰金 | 懲罰＋矯正 | ✓ |
| **保安處分（拘束）** | 感化教育、監護、禁戒、強制治療 | 純矯正（把人關起來） | ✓（§1後段） |
| **保安處分（非拘束）** | 保護管束、驅逐出境 | 純矯正（不關人） | ✗（§2第2項，適用裁判時法） |
| **沒收** | 準不當得利，剝奪犯罪物/犯罪利得 | 非處罰 | ✗（§2第2項，適用裁判時法） |

> **注意**：非拘束保安處分和沒收雖無罪刑法定適用，但仍受**憲法基本原則**（法律保留等）約束，不可在毫無法律明文下為之

## 三、刑法的解釋

### （一）文義解釋

- 查字典，看中文字面意思
- 例：喝醉酒「牽」機車 ≠ 駕駛 → 不成立§185-3
- **侷限**：同一個字在不同條文中意義可能不同（如「人」在殺人罪只指自然人，在妨害信用罪可含法人）

### （二）歷史解釋

- 查閱當年**立法紀錄**，看立法者原意
- 例：§222第9款後段「散佈播送該影像聲音電子紀錄」→ 文義像事後流出，但查立法資料原寫「直播」→ 實為**直播或類似直播**
- **侷限**：立法者當年想法不一定現在合理
  - 例：1935年墮胎罪採「早產說」（當時醫療不發達＋需要人口），現在不合理

### （三）目的解釋

- 從法律規範的**精神與目的**來解釋
- 例：私自找零（拿走4個10元＋2個5元，放入1個50元）→ 文義上竊盜，但目的上交易價值相同 → 不成立竊盜
- **擴張解釋**：法條適用範圍比文義基本意義更廣，但仍在文義範圍內
  - 例：§321「住宅」→ 包括公寓樓梯間
- **限縮解釋**：法條適用範圍比文義基本意義更窄
  - 例：§315-1「工具設備」→ 限於能**強化視覺感官**之物（非一切人造物）

#### 法律概念的相對性

- 同一概念在不同條文中解釋不同：

| 概念 | 條文A | 條文B | 差異 |
|------|-------|-------|------|
| 動產 | 民法定義 | 刑法竊盜（偷整棵果樹） | 可能不同認定 |
| 共犯 | 刑法（教唆＋幫助） | 刑訴（所有多人犯罪） | 範圍不同 |
| 猥褻 | 性犯罪（含強制親吻） | 風化犯罪§234/235（不含親吻） | 門檻不同 |

### （四）體系解釋

- 從**法條之間的體系關係**推論
- 例①：人的起點 → §274 生母殺嬰罪寫「生產時」→ 屬殺人罪章 → 立法者認為分娩開始即為人 → 採**分娩開始說**
- 例②：§293 遺棄 → 對比§294（遺棄＋不為生存必要之扶助養育保護）→ §293的遺棄專指**作為**（不含見死不救的不作為）

### （五）合憲性解釋

- 非獨立方法，而是在多種解釋結果中，選擇**較符合憲法意旨**的解釋
- 例：§235 散佈猥褻物品 → 用QRcode賣A片（外觀無裸露） → 文義解釋會成罪，但目的解釋（保護不喜歡色情者免於干擾）不成罪 → 後者更符合憲法 → 選後者

## 四、立法解釋（法律名詞定義）

### （一）以上、以下、以內

- **以上、以下、以內**：包含本數
- **超過、未滿**：不含本數

### （二）重傷（§10第4項）

- 六款事由（佩佩豬口訣）：

| 款次 | 部位 | 內容 |
|------|------|------|
| 第一款 | 眼 | 毀敗或嚴重減損一目或二目之視能 |
| 第二款 | 耳 | 毀敗或嚴重減損一耳或二耳之聽能 |
| 第三款 | 鼻口舌 | 毀敗或嚴重減損語能、味能或嗅能 |
| 第四款 | 四肢 | 毀敗或嚴重減損一肢以上之機能 |
| 第五款 | 生殖器 | 毀敗或嚴重減損生殖之機能 |
| 第六款 | 概括 | 其他身體或健康有重大不治或難治之傷害 |

- **重傷須事後判斷**（區別於一般犯罪從行為當下判斷）
  - 用語為「毀敗」「嚴重減損」「不治」「難治」→ 均指**終局性結果**
  - **骨折不算重傷**（可接回復原）

### （三）性交（§10第5項）

- 「非基於正當目的」為**多餘要件**（醫療行為以阻卻違法處理即可）
- **第一款**：以**性器**進入他人之性器、肛門或口腔，或使之結合
  - 涵蓋：陰道性交、肛交、口交
  - 「使之結合」→ 讓女性也能成為性交主體
- **第二款**：以性器以外之**身體部位或器物**進入他人之性器、肛門，或使之結合
  - **不含口腔**（否則塞衛生紙入口也變性交，不合理）
  - 舔陰唇內側 = 身體部位進入他人性器 = 性交（實務見解）
  - 飛機杯套弄 = 器物結合他人性器 = 性交

> 條文寫「他人」→ 逼迫被害人自慰（自己手指進入自己性器）≠ 性交，僅為猥褻

### （四）公務員（§10第2項）— 三大類

#### 1. 身分公務員

- 依法服務於**國家或地方自治團體所屬機關**＋具有**法定職務權限**
- 法定職務權限 = 排除「只從事**機械性事務**」的人
- 包含：政務官、事務官、約僱人員（只要有法定職務權限）
- **排除**：公立學校、公立醫院、公營事業中無公權力者 → 可能成為授權公務員
  - 例外：三軍總醫院軍醫官因**軍官身分**而為身分公務員
- 案例：基隆殯葬所火葬爐約僱人員 → 管理火化事務（非機械性勞務）→ 身分公務員 → 收賄變貪汙
