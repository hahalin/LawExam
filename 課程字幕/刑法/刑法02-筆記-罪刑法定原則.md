# 刑法02 筆記：罪刑法定原則

> 來源：刑法02 課程字幕 00:24:00 ~ 01:20:00

---

## 📖 法條原文速查

> **§1**（罪刑法定主義）
> 行為之處罰，以行為時之法律有明文規定者為限。**拘束人身自由之保安處分**，亦同。

> **§2**（法律變更之適用）
> I 行為後法律有變更者，適用行為時之法律。但行為後之法律有利於行為人者，適用最有利於行為人之法律。
> II 非拘束人身自由之保安處分適用裁判時之法律。
> III 處罰或保安處分之裁判確定後，未執行或執行未完畢，而法律有變更，不處罰其行為或不施以保安處分者，免其刑或保安處分之執行。

> **§27**（中止未遂）
> I 已著手於犯罪行為之實行，而因己意中止或防止其結果之發生者，減輕或免除其刑。
> II 前項規定，於正犯或共犯中之一人或數人，因己意防止犯罪結果之發生，或結果之不發生，非防止行為所致，而行為人已盡力為防止行為者，亦適用之。
> → 有利類推：預備階段因己意中止，類推適用§27 減免其刑

> **§251**（妨害農工商罪之空白授權）
> 以強暴、脅迫或詐術，使人不為生活必需品之交易者…
> → 空白刑法：「生活必需品」由行政命令補充認定

> **§319-3**（未經同意攝錄性影像罪）
> → 2023年2月公布施行；不得溯及適用於施行前之行為

## 📋 釋字/實務見解原文速查

> **司法院釋字第 443 號**（層級化保留體系）
> 涉及人身自由之限制，應以法律定之。→ 刑罰須由立法院通過之法律定之，不得以行政命令創設刑罰

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「罪刑法定主義的意涵？」 | §1 前段：行為之處罰以**行為時之法律有明文規定者**為限（法無明文不罰） |
| 「地方自治條例可否科處刑罰？」 | **不可**，僅能科行政罰（罰鍰等）；刑罰須由**立法院通過＋總統公布** |
| 「空白刑法是否違反罪刑法定？」 | **不違反**，因構成要件仍由法律定之，行政命令僅**補充技術性細節**（如「生活必需品」的認定） |
| 「類推適用是否一律禁止？」 | **不利行為人**之類推禁止；**有利行為人**之類推**容許**（如§27中止未遂類推至預備階段中止） |
| 「行為後法律變更如何適用？」 | §2I：原則**從舊**（適用行為時法）；例外**從新從輕**（行為後法律有利時適用新法） |
| 「非拘束人身自由保安處分適用何時之法？」 | §2II：適用**裁判時**之法律（非行為時法） |
| 「沒收適用何時之法？」 | 適用**裁判時**之法律（與非拘束保安處分相同） |
| 「§1後段『拘束人身自由之保安處分亦同』的意涵？」 | 拘束人身自由的保安處分**亦受罪刑法定拘束**，須法律明文 |

## 一、罪刑法定原則的基本概念

### (一) 定義

- §1 前段：「行為之處罰，以行為時之法律有明文規定者為限」
- 白話：**法無明文規定不罰**（nulla poena sine lege）

### (二) 背後精神

- 寧可讓有罪之人輕判，也不可讓無辜之人受罰（in dubio pro reo 的立法面向）
- 國家刑罰權的自我限制

### (三) 經典案例

#### 案例一：偷襲式觸摸

```
偷襲式觸摸（背後搓胸）
     ↓
§224 強制猥褻？→ 須「違反意願」→ 偷襲時無從表達意願 → ✗
     ↓
§225 趁機猥褻？→ 須「精神或身體障礙」→ 正常人被偷摸不符合 → ✗
     ↓
性騷擾防治法？→ 行為時尚未立法 → ✗
     ↓
結論：罪刑法定 → 無罪
```

- 後來修法：§224 改為「違反其意願**或未經其同意**」

#### 案例二：華航 CI611 空難

- 2002 年華航 CI611（澎湖空難），200 多人罹難
- 業務過失致死罪，法定刑上限僅**五年**
- 即使有 200 條人命，基於罪刑法定，法院不能判超過五年
- 對照：日航 JL123 空難（1985），520 人死亡

## 二、罪刑法定的五大子原則

### 體系圖

```
罪刑法定原則
│
├── ① 法律保留原則
│   └── 刑罰須以「法律」定之（立法院通過＋總統公布）
│
├── ② 習慣法禁止
│   └── 不得以習慣法作為科刑依據
│
├── ③ 明確性原則
│   ├── 構成要件明確
│   └── 法律效果明確
│
├── ④ 禁止類推適用
│   └── 不利行為人之類推禁止；有利行為人之類推容許
│
└── ⑤ 禁止溯及既往
    └── 原則不溯及；例外：行為後法律有利（§2I 但書）
```

### (一) 法律保留原則

| 項目 | 說明 |
|------|------|
| **「法律」之意** | 立法院三讀通過＋總統公布之法律 |
| **地方自治條例** | 僅可科**行政罰**（罰鍰），**不可科刑罰** |
| **行政命令** | 不可直接創設刑罰，但可作為空白刑法的技術性補充 |

#### 空白刑法

- 構成要件的一部分由行政命令填補
- **例**：§251「生活必需品」→ 2020 年疫情期間，行政院以命令將「口罩」列入生活必需品，嗣後囤積口罩始有§251 之適用
- **不違反罪刑法定**：因法律已定框架，行政命令僅補充技術性事實

### (二) 習慣法禁止

- 習慣法不得作為刑事判決之依據
- 例外情形極少，幾乎為絕對禁止

### (三) 明確性原則

#### 構成要件明確

- 構成要件不能使用**過度概括**的規定
- 反面教材：唐律「諸不應得為而為之者」→ 概括犯罪條款 → 違反明確性

#### 法律效果明確

- 刑罰須有明確的**上限與下限**
- §32：有期徒刑最低為**二月**，最高為**十五年**（加重最高二十年）

### (四) 禁止類推適用

#### 什麼是類推？

- 類推＝**比附援引**：將法律未明文的情形，比照法律已明文的情形處理
- 與「解釋」不同：解釋是在文義範圍內，類推是在文義範圍外

#### 不利行為人之類推（禁止）

| 案例 | 說明 |
|------|------|
| §185 妨害公眾往來 | 將「寵物」類推為「經濟動物」→ 超出文義→ **類推禁止** |
| §202 郵票拼合案 | 將兩張半面郵票拼成一張使用，類推為偽造有價證券 → 實務過去曾判有罪 → 學者批評為**負面教材** |
| 肇事逃逸「停留現場但不報警」 | 是否等於逃逸？→ 超出「逃逸」文義 → 類推禁止 → 不構成 |

#### 有利行為人之類推（容許）

- §27 中止未遂係規定於「已著手」後的中止
- 在**預備階段**因己意中止 → 法律未規定這一塊
- 類推適用§27 → 減免其刑 → **有利行為人** → 容許

### (五) 禁止溯及既往

#### 核心概念

- 行為時不違法的行為，不能因事後立法而被追訴

#### 重要案例

| 案例 | 說明 |
|------|------|
| §319-3 性影像罪 | 2023/2 公布施行 → 2022 年偷存裸照 → 行為時無此罪 → 不可溯及 |
| §5 第11款 加重詐欺 | 2016/11 施行 → 在此之前去緬甸從事電信詐騙 → 不可回溯追訴 |
| 附帶說明 | 刑法**空間效力**（§3~§8）屬**實體法**→ 亦有溯及既往禁止之適用；非程序法 |

#### 例外：行為後法律有利

- §2I 但書：行為後法律變更，**有利於行為人→ 從新從輕**
- 白話：如果新法對被告比較好，就用新法

## 三、刑事法律效果的三大分類

### 體系圖

```
刑事法律效果
│
├── 刑罰（懲罰＋矯正）
│   ├── 主刑：死刑、無期徒刑、有期徒刑、拘役、罰金
│   └── 從刑：褫奪公權
│
├── 保安處分（純矯正）
│   ├── 拘束人身自由 → 感化教育、監護處分、禁戒處分、強制治療
│   └── 非拘束人身自由 → 保護管束、驅逐出境
│
└── 沒收（準不當得利）
    └── 剝奪犯罪所得
```

### 各類與罪刑法定的關係

| 類別 | 罪刑法定適用？ | 適用何時法律？ | 法律依據 |
|------|---------------|---------------|---------|
| **刑罰** | ✔ 完全適用 | 行為時法（從舊從輕） | §1 前段、§2I |
| **拘束人身自由保安處分** | ✔ 適用 | 行為時法 | §1 後段 |
| **非拘束人身自由保安處分** | ✗ 不適用罪刑法定（但仍受憲法法律保留拘束） | **裁判時法** | §2II |
| **沒收** | ✗ 不適用罪刑法定 | **裁判時法** | §2II（類推適用） |

> **重點**：§2II 讓非拘束保安處分和沒收可以「溯及既往」，因其不具懲罰性質，目的在於矯正（保安處分）或不當得利之返還（沒收）。
