## 📖 法條原文速查

> **§9**（公司法：轉嫁責任制範例）
> 公司應收之股款，股東並未實際繳納，而以申請文件表明收足……公司負責人各處五年以下有期徒刑、拘役或科或併科新臺幣五十萬元以上二百五十萬元以下罰金。
> → 違法主體是公司（法人），但處罰負責人（轉嫁責任制範例）→ 建議查閱最新條文

> **職業安全衛生法相關條文**（兩罰責任制範例）
> 法人之代表人、法人或自然人之代理人、受僱人或其他從業人員，因執行業務違反本法規定，除處罰其行為人外，對該法人或自然人亦科以各該條之罰金。
> → 法人＋負責人一起罰（兩罰責任制）→ 建議查閱最新條文

> **§230**（血親性交罪）
> 與直系或三親等內旁系血親為性交者，處五年以下有期徒刑。
> → 老師以此為例說明「是否有保護法益」的爭議

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「法人可否為普通刑法的犯罪主體？」 | **原則不可**，因為無法對法人判自由刑；但**附屬刑法**有轉嫁責任制與兩罰責任制 |
| 「轉嫁責任制與兩罰責任制的區別？」 | **轉嫁**＝違法主體是法人→只罰負責人；**兩罰**＝法人（科罰金）＋負責人都罰 |
| 「行為客體與法益的區別？」 | **行為客體**＝具體攻擊對象（人/物）；**法益**＝抽象保護利益。行為客體不一定每罪都有，但法益一定有 |
| 「是否每個犯罪都有行為客體？」 | **否**，如重婚罪（§237）無具體行為客體，但有法益（一對一配偶關係） |
| 「結果犯與行為犯的區別？」 | **結果犯**有結果要求（含實害犯＋具體危險犯）；**行為犯**無結果要求 |

## 一、客觀不法構成要件六格

老師將客觀構成要件整理為六個審查項目：

```
客觀不法構成要件（六格）
│
├── ① 行為主體
├── ② 行為
├── ③ 行為客體
├── ④ 結果
├── ⑤ 因果關係
└── ⑥ 客觀歸責
```

> **重點**：⑤因果關係 ＋ ⑥客觀歸責 是本堂課（及後續）的核心重點。

## 二、行為主體：自然人 vs 法人

### （一）自然人

自然人當然可以作為犯罪主體，無特別說明。

### （二）法人犯罪

**普通刑法**：法人不能成為犯罪主體，因為無法對法人判自由刑。

**附屬刑法**：有兩種處理法人犯罪的方式——

| 比較項目 | 轉嫁責任制 | 兩罰責任制 |
|---------|-----------|-----------|
| 違法主體 | 法人 | 法人＋負責人 |
| 處罰對象 | 僅罰負責人 | 法人（科罰金）＋負責人 |
| 範例 | 公司法 §9 | 職業安全衛生法 |
| 處罰邏輯 | 法人犯錯→轉嫁處罰其負責人 | 法人＋負責人一起承擔 |

## 三、行為客體 vs 法益

| 比較項目 | 行為客體 | 法益 |
|---------|---------|------|
| 性質 | **具體攻擊對象**（人或物） | **抽象保護利益** |
| 每罪是否都有 | **不一定**（有些犯罪無行為客體） | **一定有**（無法益→違憲疑慮） |
| 例：殺人罪 | 被害人（人） | 生命法益 |
| 例：竊盜罪 | 動產（物） | 財產法益 |
| 例：重婚罪 §237 | **無**具體行為客體 | 一對一配偶關係 |

### 重要觀念：無法益 → 立法正當性疑慮

老師舉 **§230 血親性交罪** 為例：有學者質疑此罪究竟保護什麼法益？如果找不到明確法益，立法正當性就有問題，甚至可能違憲。

> **一試要點**：每個犯罪一定有法益，但不一定有行為客體。無法益的立法可能有違憲疑慮。

## 四、結果

```
結果的分類
│
├── 結果犯（有結果要求）
│   ├── 實害犯 → 需要實際法益侵害結果
│   └── 具體危險犯 → 需要具體危險結果
│
└── 行為犯（無結果要求）
    └── 行為完成即成立犯罪
```

> 本堂課主要聚焦的是：**結果犯**中的因果關係與客觀歸責問題（→ 見筆記2、3、4）。
