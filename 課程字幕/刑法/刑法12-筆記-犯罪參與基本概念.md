## 📖 法條原文速查

> **§28**（共同正犯）
> 二人以上共同實行犯罪之行為者，皆為正犯。

> **§29**（教唆犯）
> I 教唆他人使之實行犯罪行為者，為教唆犯。
> II 教唆犯之處罰，依其所教唆之罪處罰之。

> **§30**（幫助犯）
> I 幫助他人實行犯罪行為者，為幫助犯。雖他人不知幫助之情者，亦同。
> II 幫助犯之處罰，得按正犯之刑減輕之。

> **§31**（身分犯之共犯）
> I 因身分或其他特定關係成立之罪，其共同實行、教唆或幫助者，雖無特定關係，仍以正犯或共犯論。但得減輕其刑。
> II 因身分或其他特定關係致刑有重輕或免除者，其無特定關係之人，科以通常之刑。

## 📋 釋字/實務見解原文速查

> **67 年台上字第 2662 號判例**（己手犯）
> 重婚罪之重婚行為，必須本人親自為之，他人不能代為實行，故不能成立共同正犯或間接正犯。
> → 己手犯概念之代表實務見解。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「我國刑法採區分制或單一制？」 | **區分制**：正犯與共犯有不同的構成要件與法律效果 |
| 「犯罪支配論的三種支配」 | ①**行為支配**→直接正犯；②**意思支配**→間接正犯；③**功能性犯罪支配**→共同正犯 |
| 「己手犯的特徵？」 | 只能由本人親自實行，**不能成立共同正犯或間接正犯**（如重婚罪） |
| 「實務區分正犯與共犯的標準？」 | **主客觀擇一標準說**：主觀有共同犯意 OR 客觀有構成要件行為 → 正犯；兩者皆無 → 幫助犯 |
| 「共犯的處罰根據？」 | **因果共犯論（惹因說）**：共犯透過正犯間接侵害法益，須有因果關係 |
| 「現行法採何種從屬性？」 | **限制從屬**：正犯行為須**該當＋違法**，共犯即可成立（不要求有責） |
| 「2006 年前後共犯從屬性的變化？」 | 2006 年前**嚴格從屬**（該當＋違法＋有責）→ 修法後改為**限制從屬**（該當＋違法） |
| 「間接正犯與教唆犯的區別？」 | 間接正犯：被利用人**無自主決定空間**（被騙/被脅迫）；教唆犯：被教唆人**有自主決定空間** |
| 「間接正犯有無從屬性問題？」 | **無**，間接正犯是正犯，直接以自己的故意＋被利用人的行為論罪 |

## 正文

### 一、犯罪參與的基本架構

#### （一）緊縮的行為人概念 vs 擴張的行為人概念

```
行為人概念
│
├── 緊縮的行為人概念（我國採用）
│   ├── 只有親自實行構成要件行為的人才是正犯
│   ├── 教唆、幫助是共犯 → 須透過從屬性連結到正犯
│   └── 正犯與共犯有不同的構成要件與法律效果
│
└── 擴張的行為人概念
    ├── 所有對結果有因果貢獻的人都是行為人
    └── 教唆、幫助只是減輕事由
```

#### （二）區分制 vs 單一制

| 比較項目 | 區分制（我國） | 單一制 |
|---------|------------|--------|
| 正犯與共犯 | **嚴格區分** | 不區分 |
| 共犯成立 | 須符合從屬性 | 各自獨立判斷 |
| 法律效果 | 正犯＞共犯（原則） | 所有參與人相同基礎 |
| 代表國家 | 台灣、德國 | 奧地利 |

---

### 二、正犯與共犯的五種類型

```
犯罪參與類型
│
├── 正犯
│   ├── 直接正犯（單獨正犯）：自己親手實行構成要件行為
│   ├── 間接正犯：利用他人（工具人）實行犯罪
│   └── 共同正犯（§28）：二人以上共同實行
│
└── 共犯
    ├── 教唆犯（§29）：唆使他人產生犯意
    └── 幫助犯（§30）：對正犯提供物質或精神上的助力
```

---

### 三、犯罪支配論

#### 犯罪支配的三種形態

```
犯罪支配論
│
├── 行為支配 → 直接正犯
│   └── 自己親手掌控犯罪實行
│
├── 意思支配 → 間接正犯
│   └── 透過欺騙或脅迫控制被利用人的意思
│   └── 被利用人無自主決定空間
│
└── 功能性犯罪支配 → 共同正犯
    └── 在犯罪計畫中擔任不可或缺的角色
    └── 若抽掉此人，犯罪計畫即無法實現
```

#### 例外：己手犯

- **定義**：只能由本人親自實行的犯罪，他人無法代為
- **效果**：不能成立**共同正犯**或**間接正犯**（但可成立教唆犯或幫助犯）
- **典型例子**：重婚罪（67 年判例）

### 四、正犯與共犯區分的五種學說

| 學說 | 內容 | 標準 | 問題 |
|------|------|------|------|
| **主觀說（利益理論）** | 為自己利益 → 正犯；為他人利益 → 共犯 | 行為人主觀的犯罪利益歸屬 | **浴盆案**：保母溺死嬰兒替母親擋罪→保母只是幫助犯？不合理 |
| **形式客觀說** | 有實行構成要件行為 → 正犯 | 是否親手做了構成要件行為 | 無法處理間接正犯（自己沒動手） |
| **實質客觀說** | 對結果有重要因果貢獻 → 正犯 | 實質貢獻度 | 標準模糊，不易操作 |
| **犯罪支配論（學說通說）** | 掌控犯罪是否發生與如何發生 → 正犯 | 行為支配/意思支配/功能性支配 | 理論完整，但實務未完全採用 |
| **主客觀擇一標準說（實務）** | 主觀有共同犯意 OR 客觀有構成要件行為 → 正犯 | 兩擇一 | 把太多人論為正犯（標準太寬） |

#### 實務：主客觀擇一標準說詳解

```
主客觀擇一標準說（實務見解）
│
├── 主觀條件：有共同犯罪的意思 ─┐
│                              ├── 任一成立 → 正犯
├── 客觀條件：有實行構成要件行為 ─┘
│
└── 兩者皆無 → 幫助犯
```

#### 案例：把風

##### 事實
- 甲負責把風，乙入室行竊
- 甲沒有親手做竊盜的構成要件行為

##### 分析

| 學說 | 甲的定位 | 理由 |
|------|---------|------|
| 犯罪支配論 | **共同正犯** | 甲在犯罪計畫中不可或缺（功能性犯罪支配） |
| 主客觀擇一 | **共同正犯** | 甲主觀上有共同犯意 → 成立正犯 |
| 形式客觀說 | **幫助犯** | 甲沒有親手實行竊盜構成要件行為 |

> 實務以主客觀擇一標準 → 甲為共同正犯。此說被學說批評為**標準太寬**，把風這類輔助角色不應直接論為正犯。

### 五、共犯處罰根據

```
共犯處罰根據的演變
│
├── 責任共犯說（已廢棄）
│   └── 共犯使正犯「墮落」→ 共犯的不法在於讓正犯陷入犯罪
│   └── 問題：把正犯當作被害人？不合理
│
└── 因果共犯論 / 惹因說（通說）
    ├── 共犯透過正犯間接侵害法益
    ├── 共犯的不法來源＝共犯行為與法益侵害之間的因果關係
    └── 重點：共犯必須對法益侵害有因果貢獻
```

### 六、共犯從屬性

#### 三個面向

```
共犯從屬性
│
├── 一、實行從屬性
│   └── 正犯須已「著手」實行，共犯才成立
│   └── 若正犯尚在預備階段 → 共犯不成立
│
├── 二、要素從屬性（最重要）
│   ├── 正犯的行為須達到什麼程度，共犯才可從屬？
│   │
│   ├── 擴張從屬：只要正犯有行為即可 → 範圍最大
│   ├── 嚴格從屬：該當＋違法＋有責 → 2006 年前我國立場
│   ├── 限制從屬：該當＋違法 → 2006 年後我國現行法
│   └── 最小從屬：該當即可 → 範圍最小
│
└── 三、罪名從屬性
    └── 共犯的罪名是否須與正犯相同？
    └── 原則：是（教唆殺人 → 依殺人罪論）
```

#### 要素從屬性四說比較

| 從屬程度 | 正犯須具備 | 特點 |
|---------|-----------|------|
| 擴張從屬 | 有行為 | 太寬 |
| **嚴格從屬** | 該當＋違法＋**有責** | 2006 年前我國（正犯須有責任能力共犯才成立） |
| **限制從屬（現行法）** | 該當＋違法 | 2006 年後我國（正犯不需有責任能力，共犯仍可成立） |
| 最小從屬 | 該當 | 太寬 |

> 💡 限制從屬的重要實益：教唆 14 歲少年殺人（少年無責任能力），在嚴格從屬下教唆犯不成立；在限制從屬下教唆犯**成立**（少年的行為已該當＋違法）。

#### 不能未遂與從屬性的關聯

| §26 不能未遂的體系定位 | 對共犯從屬性的影響 |
|---|---|
| **構成要件不該當** | 正犯行為不該當 → 限制從屬下共犯**無法成立** |
| **三階層以外（獨立事由）** | 正犯行為仍然該當＋違法 → 共犯**可以從屬成立** |

### 七、間接正犯

#### （一）基本結構

```
間接正犯
│
├── 幕後操控者（甲）＝間接正犯
│   └── 出於犯罪故意，利用他人實行犯罪
│
├── 被利用人（乙）＝工具人
│   ├── 類型一：被欺騙 → 不知道自己在犯罪
│   │   └── 例：甲把毒飲料交給乙，乙不知有毒，轉交給 A
│   └── 類型二：被脅迫 → 被迫犯罪
│       └── 例：甲威脅乙「不殺 A 就殺你全家」
│
└── 論罪方式
    ├── 行為：看**乙的行為**（乙做了什麼事實行為）
    ├── 故意：看**甲的故意**（甲想達成什麼犯罪）
    └── 結果：甲以間接正犯論罪，乙視情況可能無罪或減免
```

#### （二）間接正犯 vs 教唆犯

| 比較項目 | 間接正犯 | 教唆犯 |
|---------|---------|--------|
| 被利用人的自主性 | **無**自主決定空間（被騙/被脅迫） | **有**自主決定空間 |
| 幕後者的地位 | **正犯**（掌控犯罪全局） | **共犯**（促成他人犯罪） |
| 從屬性問題 | **無**（正犯獨立判斷） | **有**（須從屬於正犯行為） |
| 犯罪支配 | 意思支配 | 無犯罪支配 |

#### （三）關鍵區辨

- **乙知道真相且自由選擇** → 甲是**教唆犯**
  - 例：甲告訴乙「這是氰化物，你拿去毒 A」，乙同意 → 乙有自主決定 → 甲是教唆
- **乙不知真相或被迫** → 甲是**間接正犯**
  - 例：甲把毒飲料說成果汁給乙 → 乙被騙 → 甲是間接正犯

> 📌 間接正犯是「正犯」，不是共犯，因此**沒有從屬性的問題**。間接正犯的論罪直接看「甲的故意＋最終結果」。
