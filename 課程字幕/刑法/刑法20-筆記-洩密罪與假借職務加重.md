## 📖 法條原文速查

> **§132**（洩漏國防以外秘密罪）
> I 公務員洩漏或交付關於中華民國國防以外應秘密之文書、圖畫、消息或物品者，處三年以下有期徒刑。
> II 因過失犯前項之罪者，處一年以下有期徒刑、拘役或九千元以下罰金。
> III 非公務員因職務或業務知悉或持有第一項之文書、圖畫、消息或物品，而洩漏或交付之者，處一年以下有期徒刑、拘役或九千元以下罰金。
> → 建議查閱最新六法原文確認刑度

> **§109**（洩漏國防秘密罪）
> 洩漏或交付關於中華民國國防應秘密之文書、圖畫、消息或物品者，處一年以上七年以下有期徒刑。
> → 建議查閱最新六法原文

> **§111**（刺探或蒐集國防秘密罪）
> 刺探或蒐集第一百零九條第一項之文書、圖畫、消息或物品者，處五年以下有期徒刑。
> → 建議查閱最新六法原文

> **§134**（公務員假借職務犯罪加重）
> 公務員假借職務上之權力、機會或方法，以故意犯本章以外之罪者，加重其刑至二分之一。但因公務員之身分已特別規定其刑者，不在此限。
> → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§132 國防以外秘密的定義？」 | 國家持有的秘密，但與**國家抵抗外敵無關**者（如偵查中卷宗、戶政/稅籍資料） |
| 「§132 有無處罰過失？」 | **有**，第二項處罰**公務員過失**洩密 |
| 「§132 第三項非公務員的身分限制？」 | 須因**職務或業務**知悉或持有，一般民眾偶然得知不算 |
| 「選舉時亮票是否構成§132？」 | **不構成**。無記名投票是**保密的權利**，非保密的義務；且一般人民投票亦不具職務或業務身分 |
| 「§132 是否為對象犯？」 | **是**。立法者僅罰洩漏/交付方，**不罰**蒐集/刺探方（區別於國防秘密 §109+§111 兩端均罰） |
| 「§134 可否獨立開標？」 | **不可以**。§134 須**附隨於其他犯罪**之後，作為加重事由 |
| 「§134 的『本章以外之罪』是否含特別刑法？」 | **不含**。「本章以外之罪」僅限**普通刑法**之犯罪，不及於特別刑法或附屬刑法 |

## 一、秘密犯罪體系總覽

```
秘密犯罪體系
│
├── 私人秘密 → 妨害秘密罪章（§315 以下）
│
└── 國家秘密
    │
    ├── 國防秘密（與國家抵抗外敵有關）
    │   ├── 洩漏/交付 → §109
    │   └── 刺探/蒐集 → §111
    │
    └── 國防以外秘密（國家持有但與國防無關）
        └── 洩漏/交付 → §132
            ※ 不處罰蒐集/刺探方（對象犯）
```

### 國防秘密 vs 國防以外秘密

| 比較項目 | 國防秘密 | 國防以外秘密 |
|---------|---------|------------|
| 定義 | 與國家**抵抗外敵**直接相關 | 國家持有但與國防**無關** |
| 洩漏處罰 | §109（較重） | §132（較輕） |
| 蒐集處罰 | §111（有罰） | **無** |
| 舉例 | 軍事設施位置、密道、武器部署 | 偵查中卷宗、戶政/稅籍資料 |
| 對象犯與否 | 非對象犯（兩端均罰） | **對象犯**（僅罰洩漏方） |

## 二、§132 洩漏國防以外秘密罪

### (一) 三項結構

| 項次 | 主體 | 主觀 | 行為 | 特殊要件 |
|------|------|------|------|---------|
| **第一項** | 公務員 | 故意 | 洩漏或交付 | 無須因公務知悉 |
| **第二項** | 公務員 | **過失** | 洩漏或交付 | 瀆職罪章少數有罰過失之規定 |
| **第三項** | **非公務員** | 故意 | 洩漏或交付 | 須因**職務或業務**知悉或持有 |

### (二) 行為態樣

| 態樣 | 定義 | 區別 |
|------|------|------|
| **洩漏** | 口頭告知或電子傳輸 | 無實體交接 |
| **交付** | 實體遞交秘密文書/物品 | 有實體交接 |

### (三) 公務員 vs 非公務員的保密義務差異

| 比較 | 公務員（§132 I/II） | 非公務員（§132 III） |
|------|-------------------|-------------------|
| 知悉來源限制 | **無限制** — 公務員對國家秘密負**絕對保密義務** | 須因**職務或業務**知悉或持有 |
| 偶然知悉 | 仍構成 | **不構成** |
| 有罰過失 | **有**（第二項） | **無** |

#### 案例：律師洩密（§132 III 典型案例）

- 事實：律師在偵查中的羈押審查程序中閱卷，將卷中內容洩露給同案未到案的共犯
- 分析：律師因**業務**閱卷而知悉偵查秘密 → 該當§132 III「因職務或業務知悉而洩漏」
- 結論：成立§132 第三項

#### 案例：法官過失洩密（§132 II）

- 事實：羈押審查程序中，法官當庭提示卷宗給辯護人閱覽，疏忽未遮蔽檢察官指定不公開的部分
- 分析：法官**過失**讓辯護人看到不應揭露的內容
- 結論：成立§132 第二項過失洩密

### (四) 保密的「權利」≠ 保密的「義務」

#### 爭議：議會選舉亮票

- **過去做法**：議會無記名投票時代，議員亮票被判§132（洩漏國防以外秘密）
- **學者批評**：無記名投票是國家對投票者的**保護**（權利），權利人自願捨棄不等於違反保密**義務**
- **後續發展**：學界放棄舊見解 → 隨後修法改為**記名投票** → 問題不再存在

> **一般人民投票亮票**：更不可能構成§132。①非公務員；②第三項要求「因職務或業務知悉」，一般人民投票不具此身分。但選罷法另有處罰規定。

### (五) 對象犯性質

```
國防秘密的對向結構（非對象犯，兩端均罰）
├── §109：洩漏/交付方 → 有罪
└── §111：蒐集/刺探方 → 有罪

國防以外秘密的對向結構（對象犯，僅罰一端）
├── §132：洩漏/交付方 → 有罪
└── 蒐集/刺探方 → ✗ 無處罰規定
```

- 因§132 為**對象犯**，蒐集或刺探國防以外秘密的相對人**不成立共犯**
- 案例：律師拜託書記官翻拍偵查卷宗 → 書記官成立§132 公務員洩密；律師（蒐集方）**不成立**教唆犯或共犯

## 三、§134 公務員假借職務犯罪加重

### (一) 性質

- **加重事由**，不是獨立罪名
- 必須**附隨於其他犯罪**之後，不可獨立開標
- 功能：公務員利用職務之便犯其他罪 → 加重其刑至二分之一

### (二) 構成要件

| 要件 | 說明 |
|------|------|
| 主體 | 公務員 |
| 假借方式 | 職務上之**權力**、**機會**或**方法**（三擇一） |
| 犯罪類型 | **故意**犯「本章以外之罪」 |
| 加重幅度 | 加重其刑至**二分之一** |

### (三) 「本章以外之罪」的範圍

| 包含 | 不包含 |
|------|--------|
| **普通刑法**的其他章犯罪 | 瀆職罪章本身的犯罪 |
| | **特別刑法**的犯罪（如證交法、毒品條例） |
| | **附屬刑法**的犯罪 |

> **案例**：金管會公務員因職務知悉上市公司內線消息而進行內線交易 → 所犯為證交法（特別刑法），**不適用**§134 加重。

### (四) 但書排除

- 若其他法律已因公務員身分**特別規定其刑** → 不再依§134 加重（避免雙重加重）

## 四、對象犯的外部關係（白手套問題）

### (一) 問題意識

- 行賄與受賄為對向犯，中間人（居間介紹者）算哪一邊的共犯？

### (二) 判斷標準

```
        行賄端                 居間人（白手套）              受賄端
        ┌────┐               ┌──────────┐               ┌────┐
        │ 行賄 │←────────────→│  居間介紹  │←────────────→│ 受賄 │
        └────┘               └──────────┘               └────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ↓                               ↓
            站在行賄方：                     站在受賄方：
            → 行賄的共同正犯               → 受賄的共同正犯
              或幫助犯                       或幫助犯
```

- 由**事實認定**決定：居間人是站在哪一方的立場參與犯罪？
- 若與公務員共享所得 → 受賄方的共犯
- 若為行賄者牽線 → 行賄方的共犯

### (三) 類似情境：毒品犯罪

| 情境 | 居間人的定位 |
|------|------------|
| 幫毒販找買家 | 販賣毒品的共犯（幫助犯或共同正犯） |
| 幫毒蟲找賣家 | 施用毒品的幫助犯 |

> **刑度差異極大**：販毒（可處死刑/無期徒刑）vs 施用（輕罪）→ 居間人站哪一方的認定至關重要。
