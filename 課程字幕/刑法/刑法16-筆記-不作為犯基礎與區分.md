# 刑法16 筆記：不作為犯基礎與作為不作為區分

> 來源：刑法16 課程字幕 01:00:00 ~ 01:30:00（約）

---

## 📖 法條原文速查

> **§15**（不作為犯）
> I 對於犯罪結果之發生，法律上有防止之義務，能防止而不防止者，與因積極行為發生結果者同。
> II 因自己行為致有發生犯罪結果之危險者，負防止其發生之義務。

> **§135**（妨害公務罪）
> 對於公務員依法執行職務時，施**強暴脅迫**者，處三年以下有期徒刑、拘役或三十萬元以下罰金。

> **§213**（公文書不實登載罪）
> 從事業務之人，明知為不實之事項，而登載於其業務上作成之文書，足以生損害於公眾或他人者，處三年以下有期徒刑、拘役或一萬五千元以下罰金。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「純正不作為犯與不純正不作為犯的區別？」 | **純正**：法條本身以不作為為構成要件（如遺棄罪）/ **不純正**：以作為犯條文論不作為 |
| 「哪些犯罪僅限作為犯？」 | ①妨害公務§135（**強暴脅迫**）②公文書登載不實§213 ③公務員包庇 |
| 「作為與不作為如何區分？通說？」 | 通說：**評價重點說**；有力說：**風險關係說**（製造風險＝作為/放任風險＝不作為） |
| 「山羊毛案是作為還是不作為？」 | **作為**（將有毒山羊毛交給工人→製造風險） |
| 「不開車燈案是作為還是不作為？」 | **作為**（以危險方式駕駛→製造風險） |
| 「急診醫生不治療是作為還是不作為？」 | **不作為**（放任既有風險擴大） |
| 「發現仇人落水，抽回繩索是作為還是不作為？」 | 繩索**已抓到再放回**＝**作為**；繩索**未抓到就抽起**＝**不作為** |
| 「不純正不作為犯的因果關係是什麼性質？」 | **擬制/假設/準因果關係**，不需百分百確定，盡可能確定即可 |
| 「作為可能性與期待可能性有何不同？」 | **作為可能性**＝純事實判斷（能不能做）；**期待可能性**＝規範判斷（該不該要求做） |

## 正文

### 一、不作為犯的分類

```
不作為犯
├── 純正不作為犯
│   └→ 法條本身以不作為為構成要件
│   └→ 如：遺棄罪（§293、§294）
│
└── 不純正不作為犯（刑總重點）
    └→ 以作為犯的條文處罰不作為
    └→ 需具備保證人地位
    └→ 核心條文：§15
```

### 二、不純正不作為犯的成立界線

- **原則**：各罪均可以不作為方式實現
- **例外**：僅限作為的犯罪

| 僅限作為的犯罪 | 理由 |
|--------------|------|
| **妨害公務 §135** | 構成要件要求「強暴脅迫」→ 必須積極行為 |
| **公文書登載不實 §213** | 「登載」行為本身僅限作為 |
| **公務員包庇** | 包庇只能以積極作為實現 |

### 三、作為與不作為的區分

#### 學說演進

```
能量說（身體動作）
  ↓ 批評：過於形式化
修正版能量啟助說（謝玉偉）
  │ 法益惡化 ＝ 作為
  │ 不讓好轉 ＝ 不作為
  ↓ 批評：仍有不足
評價重點說（通說）
  │ 看行為整體的評價重點
  ↓ 批評：循環論證（用「重點」判斷→但何為重點？）
風險關係說（有力說）
  ├→ 製造風險 ＝ 作為
  └→ 放任風險擴大 ＝ 不作為
```

#### 經典案例對照

| 案例 | 作為/不作為 | 風險關係說分析 |
|------|-----------|--------------|
| **山羊毛案**（交付有毒原料） | **作為** | 製造新風險 |
| **不開車燈案** | **作為** | 以危險方式駕駛＝製造風險 |
| **急診醫生不治療** | **不作為** | 放任既有疾病風險擴大 |

### 四、發現仇人案（近年熱門考點）

四個變體，關鍵在於**救助條件是否已啟動**：

```
發現仇人案
│
├── 案例①：看到仇人落水，直接離開
│   └→ 不作為（救助條件未啟動）
│
├── 案例②：丟繩索但仇人未抓到，將繩索抽起
│   └→ 不作為（救助條件未成功啟動）
│
├── 案例③：拉起仇人後發現是仇人，再放回水中
│   └→ ★ 作為 ★（救助條件已啟動 → 中斷已啟動的救助＝製造新風險）
│
└── 案例④：搶走第三人正在施救的繩索
    └→ 不作為（對生命法益而言＝阻斷他人救助）
```

**核心區分準則**：
- 救助條件**已啟動**後中斷 → **作為**（製造風險）
- 救助條件**未啟動**時消滅 → **不作為**（放任風險）

> **補充**：打昏救護員、刺破救護車輪胎 → 對生命法益而言仍是**不作為**（阻斷的是他人的救助能力）

### 五、不純正不作為犯的構成要件

```
不純正不作為犯構成要件
│
├── 1. 成文 ＋ 不成文構成要素
│
├── 2. 作為可能性
│   ├→ 純事實認定（物理上能不能做到）
│   ├→ ≠ 期待可能性（規範上該不該要求）
│   └→ 八掌溪事件：工人受困河中，消防員有無作為可能性？
│
├── 3. 因果關係
│   ├→ 擬制因果關係（假設因果關係/準因果關係）
│   ├→ 假設：「如果行為人作為，結果是否不發生？」
│   └→ 不需百分百確定 → 盡可能確定即可
│
├── 4. 客觀歸責
│   └→ 放任法所不允許的風險（非製造風險）
│
├── 5. 等價條款（§15 I「與因積極行為發生結果者同」）
│   └→ 展現在詐欺罪等犯罪
│
└── 6. 保證人地位（→ 見下一份筆記）
```
