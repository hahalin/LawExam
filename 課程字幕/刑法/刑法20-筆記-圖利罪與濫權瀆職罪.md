## 📖 法條原文速查

> **§131**（圖利罪）
> I 公務員對於主管或監督之事務，明知違背法令，直接或間接圖自己或其他私人不法利益，因而獲得利益者，處一年以上七年以下有期徒刑，得併科一百萬元以下罰金。
> → 建議查閱最新六法原文確認刑度

> **§120**（委棄守地罪）
> 公務員不盡其應盡之責，而委棄守地者，處死刑、無期徒刑或十年以上有期徒刑。
> → 建議查閱最新六法原文

> **§124**（枉法裁判或仲裁罪）
> 有審判職務之公務員或仲裁人，為枉法之裁判或仲裁者，處一年以上七年以下有期徒刑。

> **§125**（濫權追訴處罰罪）
> I 有追訴或處罰犯罪職務之公務員，為左列行為之一者，處一年以上七年以下有期徒刑：一、濫用職權為逮捕或羈押者。二、意圖取供而施強暴脅迫者。三、明知為無罪之人，而使其受追訴或處罰，或明知為有罪之人，而無故不使其受追訴或處罰者。
> → 建議查閱最新六法原文

> **§126**（凌虐人犯罪）
> I 有管收、解送或拘禁人犯職務之公務員，對於人犯施以凌虐者，處一年以上七年以下有期徒刑。
> → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§131 圖利罪的主觀要件？」 | 須**明知**違背法令（**直接故意**），間接故意不夠 |
| 「圖利罪是行為犯還是結果犯？」 | **結果犯**，須「因而獲得利益」，未獲利不成立既遂 |
| 「圖利公庫是否構成§131？」 | **不構成**，須圖「自己或其他**私人**」不法利益 |
| 「被圖利者可否成立§131共犯？」 | **可以**，§131 非對向犯（區別於§121 賄賂罪的對向犯結構） |
| 「§131 與 §121/§122 的關係？」 | §131 為 §121/§122 的**補充規定**（無法構成賄賂罪時才論圖利） |
| 「§124 枉法裁判為何實務上難成立？」 | 依**義務理論**，法官依確信審判時所為之裁判，即便結果錯誤，主觀上也難認有枉法故意 |
| 「§125 的主體是否包含警察？」 | 有爭議。肯定說認警察有犯罪偵查職務；否定說認「追訴」專指**檢察官** |
| 「§125 第三款與 §124 的關係？」 | §125 III 是「明知無罪使其受追訴」，§124 是「枉法裁判」；前者針對**追訴者**，後者針對**審判者** |

## 一、§131 圖利罪

### (一) 本罪定位

- 功能：處罰公務員違法圖利的**概括性規定**
- 與賄賂罪的關係：§131 為 §121/§122 的**補充規定**
  - 無法證明受賄 → 退而求其次論圖利
  - 能論賄賂罪時不論圖利罪

### (二) 構成要件分析

| 要件 | 內容 | 說明 |
|------|------|------|
| **主體** | 公務員 | 身分犯 |
| **客觀要件** | 對主管/監督事務 | 須為該公務員主管或監督的事務 |
| **行為** | 違背法令，圖不法利益 | 直接或間接圖利均可 |
| **結果** | 因而獲得利益 | **結果犯**，未獲利不成立既遂 |
| **主觀要件** | **明知**違背法令 | 僅限**直接故意**（間接故意不符） |

### (三) 重要特點

#### 1. 結果犯

- 須實際「因而獲得利益」
- 如果違法行為尚未使人獲利 → 不成立既遂

#### 2. 利益的認定：採「淨利」

- 獲得的利益以**淨利**認定（扣除成本）

#### 3. 圖利公庫不算

- 必須圖「自己或其他**私人**」不法利益
- 圖利國庫/公庫 → 不構成本罪

#### 4. 非對向犯

- §131 **不是**對向犯
- 被圖利的人**可以**成立本罪的共犯
- 區別：§121/§122 賄賂罪是對向犯，行賄端原則不以共犯論（除§122 III 獨立處罰）

```
對向犯與否的區別
│
├── §121/§122 賄賂罪 → 「對向犯」
│   └── 行賄端原則不論共犯（另有§122 III 獨立處罰）
│
└── §131 圖利罪 → 「非對向犯」
    └── 被圖利者可成立共犯（教唆、幫助均可）
```

## 二、濫權型瀆職罪

### (一) §120 委棄守地罪

- **性質**：極冷門，戰時或非常時期才有適用
- **主體**：負守衛國土責任之公務員
- **行為**：不盡責而委棄守地
- 考試幾乎不考，了解即可

### (二) §124 枉法裁判罪

- **主體**：有審判職務之公務員（法官）或仲裁人
- **行為**：為「枉法」之裁判或仲裁
- **實務困境**：依**義務理論**，法官基於確信所為之裁判，縱使事後認定有誤，也難認主觀上有「枉法」故意

> **注意**：§124 在實務上極難成立，因法官享有審判獨立的保障，判斷是否「枉法」的標準非常嚴格。

### (三) §125 濫權追訴處罰罪

#### 三款行為態樣

| 款次 | 行為 | 說明 |
|------|------|------|
| **第一款** | 濫用職權為逮捕或羈押 | 無合法事由而強制處分 |
| **第二款** | 意圖取供而施強暴脅迫 | 刑求（較少直接考） |
| **第三款** | 明知無罪而追訴/明知有罪而不追訴 | 包含「故入人罪」與「故縱犯人」 |

#### 主體爭議：警察是否為§125之主體？

| 見解 | 理由 |
|------|------|
| **肯定說** | 警察有協助偵查犯罪之職務，屬「有追訴犯罪職務之公務員」 |
| **否定說** | 「追訴」專指**檢察官**之職權，警察僅為偵查輔助機關 |

#### §125 第三款 vs §124 的區別

| 比較 | §125 第三款 | §124 |
|------|-----------|------|
| 主體 | 追訴/處罰犯罪之公務員（檢察官） | 審判職務之公務員（法官） |
| 行為 | 明知無罪而追訴 | 枉法裁判 |
| 階段 | 偵查/追訴階段 | 審判階段 |

### (四) §126 凌虐人犯罪

- **主體**：有管收、解送或拘禁人犯職務之公務員
- **行為**：對人犯施以「凌虐」
- **凌虐**：超過法律容許範圍的不人道待遇
- 典型案例：監獄管理員毆打受刑人
