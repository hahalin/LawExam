# 刑法09 筆記：上級命令與醫療行為

> 來源：刑法09 課程字幕 02:26:00 ~ 02:38:23

## 📖 法條原文速查

> **§21 II**（上級命令之行為）
> 依所屬上級公務員命令之行為，不罰。但明知命令違法者，不在此限。

> **§22**（業務上正當行為）
> 業務上之正當行為，不罰。

## 📘 釋字／實務見解速查

> 實務見解：§21 II「明知命令違法」→ 不分形式或實質合法性，只要明知違法即不能阻卻違法。

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「§21 II 上級命令四要件？」 | ①具有拘束力之命令（事務範圍內）②命令具備法定程序③不逾越授權範圍④不能明知違法 |
| 「明知命令違法，何種合法性？」 | **學說**：僅限形式合法性 vs **實務**：形式＋實質都算 |
| 「業務上正當行為採何說？」 | **事實業務說**：重點是行為正當，非業務正當 |
| 「密醫拔牙，可否阻卻違法？」 | **可以**（事實業務說→行為符合醫療常規→正當→阻卻違法；無照行醫另論） |
| 「醫療行為是否該當傷害罪？」 | **傷害說**：該當→阻卻違法 vs **非傷害說**：根本不該當傷害 |
| 「非傷害說之要件？」 | ①醫療目的②告知後同意③符合醫療常規④緩解疼痛疾病 |
| 「專斷醫療可否阻卻違法？」 | **原則不行**（違反病患意思→欠缺同意基礎） |

## 一、§21 II 上級命令

### 四要件

```
上級命令阻卻違法 §21 II
│
├── ① 具有拘束力的命令
│   └── 上下級公務員的事務範圍之內
│   └── ✗ 上級叫下級跟蹤他老婆 → 超出事務範圍 → 不適用
│
├── ② 命令具備法定程序
│   └── 書面等形式要件均須符合
│
├── ③ 不逾越授權範圍
│   └── 超越原本授權 → 不能阻卻違法
│
└── ④ 不能明知命令違法
    └── 爭議：何種「合法性」？
```

### 明知命令違法之爭議

| 立場 | 內容 | 理由 |
|------|------|------|
| **學說** | 僅限知悉**形式合法性**違反 | 不能要求下級審查上級命令之實質合法性（違反行政倫理） |
| **實務** | 形式＋實質**都算** | 只要明知命令違法，不分形式或實質，均不能阻卻違法 |

## 二、業務上正當行為（§22）

### 事實業務說

```
§22 業務上之「正當行為」
       ↓
重點：「行為」正當 ≠ 「業務」正當
       ↓
業務不合法（如密醫）→ 只要行為本身正當 → 仍可阻卻違法
```

### 「行為正當」之最低限度
- 行為本身**不能抵觸其他法領域**

| 案例 | 行為正當？ | 理由 |
|------|-----------|------|
| 密醫（齒模師）幫病患拔牙 | ✅ | 拔牙行為符合醫療常規，沒有法律禁止「拔牙行為本身」；無照行醫另依其他法律處理 |
| 警察刑求被告 | ✗ | 刑事訴訟法**禁止**刑求 → 行為抵觸其他法領域 → 不正當 |

### 真正只能用業務正當行為的情況

- 其實**不多**，很多情況可走其他阻卻違法事由替代
- 公務員執法 → 可走§21
- 醫療行為 → 可走被害人同意、緊急避難
- **記者臥底採訪** → 唯一只能用業務上正當行為的典型案例
  - 例：記者喬裝成工廠員工臥底，用密錄器拍下黑心食品工廠運作
  - 找不到其他阻卻違法事由 → 只能用§22

## 三、被害人同意與專斷醫療

### 醫療行為需同意

| 情況 | 法律效果 |
|------|---------|
| 患者/家屬**事前同意** | 可阻卻違法（被害人承諾） |
| **未取得**事前同意 | 頂多主張**推測的承諾**（超法規阻卻違法事由） |
| **違反**病患意思（專斷醫療） | **原則不能阻卻違法** |

> 不管怎麼樣，你要經過人家同意；對方有病不想醫，你不能強迫。

## 四、醫療行為論罪：傷害說 vs 非傷害說

### 比較

| | 傷害說（傳統說） | 非傷害說（漸成主流） |
|---|---|---|
| 構成要件該當 | 醫療行為**該當**傷害罪 | 醫療行為**不該當**傷害罪 |
| 不罰理由 | 有阻卻違法事由（業務正當/被害人承諾） | 根本不符合傷害罪構成要件 |
| 觀察方式 | 聚焦一刀一針一線 | 看**整體**醫療行為 |
| 論理 | 拔牙 → 少一顆牙＋出血 → 傷害 | 原本不健康 → 治療後更健康 → 整體非傷害 |

### 非傷害說四要件

```
醫療行為不該當傷害（非傷害說）
│
├── ① 出於醫療目的
├── ② 告知後同意
├── ③ 符合醫療常規
└── ④ 以緩解疼痛、緩解疾病為目的
```

### 拔智齒案例分析

```
智齒長歪 → 壓迫臼齒 → 牙齦經常發炎
         ↓
    口腔處於「不健康」狀態
         ↓
    醫師拔除長歪智齒
         ↓
    少一顆牙＋過程出血
         ↓
  ┌──────────────────────────┐
  │ 傷害說 → 該當傷害 → 阻卻違法    │
  │ 非傷害說 → 整體觀之更健康 → 不該當│
  └──────────────────────────┘
```

### 考試提醒
- 醫療刑法**通常考研究所**（王皇玉老師、曾淑偉老師）
- 國考偶爾出現（109年曾有一試考題涉及）
- 一試出題 → 記住兩說及非傷害說四要件即可
