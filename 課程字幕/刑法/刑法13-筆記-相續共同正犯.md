# 刑法13 筆記：相續共同正犯

> 來源：刑法13 課程字幕 01:40:00 ~ 02:10:00

## 📖 法條原文速查

> **§28**（共同正犯）
> 二人以上共同**實行**犯罪之行為者，皆為正犯。

> **§302**（私行拘禁罪）
> I：私行拘禁或以其他非法方法，剝奪人之行動自由者，處五年以下有期徒刑、拘役或九千元以下罰金。

> **§320**（竊盜罪）
> I：意圖為自己或第三人不法之所有，而竊取他人之動產者，為竊盜罪，處五年以下有期徒刑、拘役或五十萬元以下罰金。

> **§328**（強盜罪）
> I：意圖為自己或第三人不法之所有，以強暴、脅迫、藥劑、催眠術或他法，至使不能抗拒，而取他人之物或使其交付者，為強盜罪，處五年以上有期徒刑。
> → 結構 = 強制（§304）+ 竊盜（§320）

> **§195**（偽造貨幣罪）
> I：意圖供行使之用，而偽造、變造通用之貨幣、紙幣、銀行券者，處五年以上有期徒刑，得併科五千元以下罰金。
> → 建議查閱最新六法原文

## 🎯 一試重點提示

| 常見考法 | 答題關鍵 |
|---------|---------|
| 「著手後既遂前加入者，可否成立相續共同正犯？」 | **較無爭議，原則可以**（但雙行為犯如強盜有例外爭議） |
| 「既遂後形式終了前加入的相續，有無爭議？」 | **較無爭議**，因加入者也在實現構成要件（如繼續犯、集合犯） |
| 「既遂後實質終了前加入者，可否成立共同正犯？」 | **最有爭議**（實務肯定、學說有否定見解） |
| 「實質終了後才加入者？」 | **不可能**成立共同正犯，只能論**後行犯**（如贓物罪、湮滅證據） |
| 「乙在甲強制後才加入取財，可否成立強盜罪共同正犯？」 | 肯定說：利用先前強制狀態；否定說：乙沒做強制 → 竊盜罪共正/強盜罪幫助犯 |
| 「繼續犯（如私行拘禁）途中加入看守者？」 | **可以**成立共同正犯（加入者也在實現構成要件） |

## 一、相續共同正犯概說

相續共同正犯＝在犯罪已經開始之後（著手後），才加入犯意聯絡的共同正犯。

### 核心問題：個人責任原則

> 每個人都只為自己做過的事情負責。沒有做過的事，不干我的事。
> 就算跟做錯事的人有相同血緣、隸屬同一團體，也一樣。

相續共同正犯之所以有爭議，正是因為它可能與個人責任原則衝突——後加入的人，是否要為他加入前的行為負責？

## 二、犯罪時間軸

```
犯罪行為的時間軸
│
├─ 🟢 著手前 ─── 一般共同正犯（無爭議）
│
├─ 🔵 著手後～既遂前 ─── 較無爭議（除雙行為犯外）
│
├─ 🟠 既遂後～形式終了前 ─── 較無爭議
│   （繼續犯/接續犯/集合犯 → 加入者也在做構成要件）
│
├─ 🟡 既遂後～實質終了前 ─── 最有爭議（僅存在於財產犯罪）
│   （贓物持有尚未穩固 → 法益侵害仍在延續）
│
└─ 🔴 實質終了後 ─── 不可能共同（只能論後行犯）
    （如贓物罪、湮滅證據罪）
```

### 形式終了 vs 實質終了

| 概念 | 意義 | 舉例 |
|------|------|------|
| **既遂** | 構成要件客觀實現 | 竊盜：持有關係改變 |
| **形式終了** | 行為人尚未放棄，持續做同一犯罪 | 偷了第一趟又偷第二、第三趟 |
| **實質終了** | 法益侵害結束，持有穩固 | 竊盜犯逃離現場，被害人追不到 |

### 三種「既遂後～形式終了前」的犯罪型態

| 犯罪型態 | 說明 | 舉例 |
|---------|------|------|
| **繼續犯** | 犯罪狀態持續中 | 私行拘禁（§302）：被害人一直被關著 |
| **接續犯** | 同一犯意下反覆做同一行為 | 進入鄰居家偷第一趟、第二趟、第三趟 |
| **集合犯** | 犯罪性質上預設反覆實施 | 偽造貨幣（§195）：做一張就不會停 |

### 竊盜罪貫穿時間軸的例子
1. **著手**：進入鄰居家開始物色財物
2. **既遂**：第一趟裝好帆布袋放上車
3. **形式終了**：又偷第二趟、第三趟，全部偷完
4. **實質終了前（黃色段）**：正要開車離開，被鄰居發現追捕
5. **實質終了**：加速逃逸，鄰居追不上

## 三、各階段的相續分析

### 🟢 著手前加入 → 一般共同正犯（無爭議）

### 🔵 著手後～既遂前加入 → 較無爭議

#### 案例：強盜罪的相續（去年高考考過）

**事實**：
1. 甲乙計劃入室盜竊，找丙把風
2. 甲乙翻牆進入，開始搜尋財物
3. 屋主AB突然出現，甲進廚房拿菜刀威脅交出財物
4. 乙在旁未作聲（沒有參與強制行為）
5. AB不得已交出珠寶和20萬現金給乙
6. 乙將財物放入背包

**分析**：

```
強盜罪（§328）結構 = 強制 + 竊盜
│
├── 甲：做了強制 ✓ + 取財 ✓ → 加重強盜（侵入住宅+攜帶兇器）
│
└── 乙：強制 ✗ + 取財 ✓ → 相續共同正犯的爭議
    ├── 否定說
    │   ├── 乙沒做強制 → 不該為沒做的事負責
    │   ├── 方案A：乙只成立**竊盜罪的共同正犯**
    │   └── 方案B：乙成立**強盜罪的相續幫助犯**（許澤天）
    │       └── 理由：幫助犯不法內涵較低，構成要件要求可放寬
    │
    └── 肯定說（傳統學說+實務+陳子平）
        └── 乙雖沒做強制，但乙的取財是在**利用甲造成的強制狀態**
            → 前行為效果仍在持續中
            → 後行為人利用持續中的效果
            → 應為整體行為負責
```

### 🟠 既遂後～形式終了前加入 → 較無爭議

#### 繼續犯案例：看守被拘禁之人
- 甲將路人鎖在後陽台（§302 既遂）
- 甲要出門，請鄰居幫忙看守 → 鄰居加入
- 鄰居**也在實現302的構成要件** → 成立共同正犯，無爭議

#### 集合犯案例：加入偽鈔製造
- 甲一人偽造貨幣（§195 既遂後持續製造）
- 鄰居加入一起製造 → 也在**做195的構成要件** → 共同正犯，無爭議

### 🟡 既遂後～實質終了前加入 → 最有爭議

#### 案例：搶皮包接應案（許澤天老師）

**事實**：
1. 甲搶到乙的皮包，乙緊追不捨
2. 甲以手機聯絡丙出來營救
3. 甲在指定地點把皮包拋給丙
4. 丙支開追趕的乙
5. 甲最終擺脫，取回皮包，分現金給丙

**爭議**：

| 學說 | 結論 | 理由 |
|------|------|------|
| **肯定說**（實務/德國實務） | 丙可成立強盜罪共同正犯 | 丙加入**加深被害人法益侵害**，沒有丙則被害人可能奪回皮包 |
| **否定說** | 丙不能成立共同正犯 | 甲拿著贓物逃跑的行為**本身不在實現任何構成要件**，丙在共同什麼？ |

### 🔴 實質終了後加入 → 不可能共同

- 殺人完畢請人清洗現場 → **湮滅證據罪**（非殺人共正）
- 偷到東西請鄰居收藏 → **寄藏贓物罪**（非竊盜共正）
- 這類人稱為**後行犯**（只能成立其他獨立犯罪）

## 四、實務立場

> 實務對相續共同正犯的立場**幾乎都持肯定態度**。
> 只要有「相互利用補充關係」，都可以成立。
> 除了紅色段（實質終了後）不可能外，其餘段落實務都肯定。

## 關鍵法條速查表

| 法條 | 內容 | 與本主題關聯 |
|------|------|------------|
| **§28** | 共同正犯 | 相續共同正犯的法律依據 |
| **§328** | 強盜罪 | 相續共正最典型考題（強制+取財的拆分） |
| **§320** | 竊盜罪 | 否定說下乙改論竊盜共正 |
| **§302** | 私行拘禁 | 繼續犯的相續（無爭議） |
| **§195** | 偽造貨幣 | 集合犯的相續（無爭議） |

## 關鍵概念速查表

| 概念 | 要旨 |
|------|------|
| **個人責任原則** | 每人只為自己做的事負責，相續共同正犯可能與此衝突 |
| **形式終了** | 行為人尚未放棄，仍在實現構成要件 |
| **實質終了** | 法益侵害結束（如贓物持有穩固） |
| **後行犯** | 實質終了後才加入者，只能論其他犯罪（贓物罪、湮滅證據） |
| **肯定說理由** | 後加入者利用先行為人造成的狀態，應為整體負責 |
| **否定說理由** | 沒做的事就不該負責，違反個人責任原則 |
