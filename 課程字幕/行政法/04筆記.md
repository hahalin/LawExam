# 行政法 第四堂 筆記

## 本堂主題

法律優位考題（續）、法律保留原則（定義 / 組織法 vs 行為法 / 範圍劃定 / 重要性理論 / 功能最適理論）、層級化法律保留（絕對 / 相對 / 無須）、授權明確性原則

## 一、法律優位原則考題（續）

### 經典考題：廢清法公告逾越母法授權案

| 項目 | 內容 |
|------|------|
| **母法** | 廢棄物清理法 §27 第 11 款 |
| **授權範圍** | 「汙染環境行為」 |
| **公告內容** | 擴及「市容」→ 與汙染無關 |
| **爭點** | 公告是否逾越母法授權範圍？ |
| **結論** | ❌ 逾越授權 → 公告違法 → 後續處分亦違法 |

### 二試答題架構

```
步驟一：點出母法授權範圍（廢清法 §27 第 11 款 → 汙染環境）
    ↓
步驟二：論證公告如何逾越（公告擴及「市容」→ 非汙染範疇）
    ↓
步驟三：因公告逾越 → 依此公告作成之處分亦違法
```

> 📌 本題為釋字 734 改編題

## 二、法律保留原則

### （一）定義與意義

| 項目 | 說明 |
|------|------|
| **定義** | 特定領域的國家事務，應保留給立法者以法律規定（釋字 614） |
| **目的** | 分工合作 — 憲法等級的權限分配 |
| **核心** | 立法者與行政機關之間「誰來做」的問題 |

### （二）組織法 vs 行為法（作用法）

| 比較項目 | 組織法 | 行為法（作用法） |
|----------|--------|-----------------|
| **功能** | 抽象分配管轄權 | 具體規範行為的依據 |
| **舉例** | 警察法「維護治安」 | 警察職權行使法 §6 以下 |
| **能否作為限制人民權利之依據** | ❌ 不夠 | ✅ 可以 |

> ⚠️ **考點**：機關拿組織法當依據限制人民 → 不滿足法律保留

### 經典案例：釋字 535 臨檢案（社子島散步案）

| 項目 | 內容 |
|------|------|
| **事實** | 民眾在社子島散步被警察臨檢 |
| **爭點** | 臨檢的法律依據為何？ |
| **問題** | 警察僅有組織法依據，欠缺行為法授權 |
| **結果** | 臨檢欠缺行為法依據 → 促成**警察職權行使法**修正 |

---

### （三）法律保留的範圍劃定（分配標準）

| 學說 | 內容 | 評價 |
|------|------|------|
| **干預保留說** | 只有侵害人民權利才需法律依據 | ❌ 太窄（給付行政也需標準） |
| **全面保留說** | 所有國家事務都要法律 | ❌ 太寬（立法者負荷不了） |
| **重要性理論（通說）** | 重要事項才保留給立法者 | ✅ 折衷，為通說 |

> 📌 **釋字 443** 引進重要性理論（解釋理由書：「視規範對象內容法益本身所限制之輕重而容許合理之差異」）

---

### （四）功能最適理論（釋字 613）

| 項目 | 說明 |
|------|------|
| **核心概念** | 把事情交給「對的人」來做 |
| **參數一：組成** | 立法（多元代表）vs 行政（單一首長） |
| **參數二：程序** | 立法（三讀嚴謹）vs 行政（命令簡便） |
| **結論** | 立法者在組成和程序上更適合規範重要事項 |

## 三、層級化法律保留

> 從釋字 443 重要性理論發展出三個層次

```
重要性理論分配：
┌─────────────────┐
│  絕對法律保留    │ ← 超重要 → 只能立法者做
├─────────────────┤
│  相對法律保留    │ ← 普通重要 → 立法者做 or 授權行政命令
├─────────────────┤
│  無須法律保留    │ ← 不重要 → 行政機關可自行決定
└─────────────────┘
```

### 考試三拍子

> **事物** + **釋字** + **層次**
> - 一試：考釋字歸類敘述的正確與否
> - 二試：考具體事實是否取得足夠的法律依據

---

### （一）絕對法律保留

> 超重要事項 → 只能以法律直接規定，不得授權以命令代替

| 事物 | 釋字 | 要點 |
|------|------|------|
| **時效制度** | 474 | 「逕由法律明定，自不得授權以命令」 |
| **刑罰主要構成部分** | 522 | 犯罪定型 ＋ 刑名 ＝ 絕對；補充細節可授權 |
| **行政罰構成要件＋效果** | 402 | 裁罰性處分之要件及效果應以法律定之 |
| **公務員免職構成要件** | 491 | 免職 ＝ 實質懲戒 → 要件應依法律 |
| **國家收集個資之目的** | 603 | 收集目的須明確法定（ETC 案：過路費 → 罰單，目的轉換無法律依據） |
| **徵收土地移轉第三人開發之要件** | 743 | 捷運聯合開發案 → 徵收土地從 A 目的（蓋捷運）轉為 B 目的（私人聯合開發），須有法律明確規定 |

#### 租稅法律保留的特殊性

| 釋字 | 內容 | 層次歸屬 |
|------|------|----------|
| **413** | 早期：納稅主體、稅目、稅率等應以法律明定 → 看似絕對 | 模糊化 |
| **750** | 後期：不明確劃歸絕對或相對，保留行政機關呼吸空間 | 模糊化 |
| **700** | 課稅的**技術性細節**可由行政命令為之，不違反租稅法律原則 | 無須法律保留 |

> ⚠️ **考點（曾直接考過）**：用函釋解釋租稅法構成要件 → 技術性事項 → 無須法律保留 → 可直接以職權作成

### （二）相對法律保留

> 普通重要事項 → 立法者自己做可以，也可以授權機關以命令補充（但一定要授權）

#### 1. 生命或身體自由「以外」之自由權益的限制

| 釋字 | 內容 |
|------|------|
| **443** | 限制生命＋身體的處罰 → **絕對**法律保留；生命身體**以外**的權利限制 → **相對**法律保留 |

> ⚠️ **注意**：非生命身體的限制不必然永遠是相對法律保留 → 如釋字 743（財產權限制被劃歸為絕對法律保留）

#### 2. 重大公益給付行政

| 釋字 | 內容 |
|------|------|
| **614**（引 443） | 給付行政如未限制人民自由權利，難謂違反 §23 之法律保留；**但**涉及公共利益之**重大**事項 → 應有法律或法律明確授權 |

> 📌 **關鍵字歸類**：重大公益 ＋ 給付行政 → **相對法律保留**（釋字 614 / 443）

| 事例 | 性質 | 釋字 | 層次 |
|------|------|------|------|
| **三倍券** | 重大公益給付行政 | 614 / 443 | 相對法律保留 |
| **普發一萬** | 重大公益給付行政 | 614 / 443 | 相對法律保留 |
| **要求佩戴口罩** | 生命身體以外的權利限制 | 443 | （起碼）相對法律保留 |

### 閃電命中考法

```
題目pattern：某一「非限制生命身體」或「重大公益給付」的行政行為，
            是否依照對應的釋字取得該有的法令依據？

答題步驟：
  1. 判斷行政行為的屬性（事物）
  2. 點出對應釋字（如 443 / 614）
  3. 確定哪個層級化法律保留層次
  4. 對比事實 → 是否滿足該層次的依據要求
  5. 得出結論：有無違反法律保留
```

### （三）無須法律保留（非屬法律保留範圍）

#### 1. 技術性、細節性的干預行政

> 雖干預人民，但屬雞毛蒜皮 → 不重要 → 無須法律依據

- **例**：戶政事務所要求抽號碼牌 → 影響一般行動自由，但不需要「抽號碼牌條例」

#### 2. 非重大公益的給付行政（釋字 614 反面推論）

> 重大公益給付行政 → 相對法律保留；反面 → **非**重大公益的給付行政 → 無須法律保留

- **例**：各縣市跨年演唱會 → 給付行政但預算僅數千萬，非重大公益 → 無須專行條例

#### 3. 大學自治事項（釋字 563）

| 項目 | 說明 |
|------|------|
| **核心概念** | 大學自治 ＝ 自我管理 → 法律＝他律 → 排除他律介入 |
| **結論** | 大學自治範疇內 → 不生法律保留（§23）的問題 → 大學可自行訂定退學規定 |
| **原因** | 非因「不重要」，而是因為大學自治排除他律 |
| **配套** | 正當程序原則 → 退學規定的訂定與執行都須經正當程序 |

> 📌 釋字 563 兩件事：
> 1. 基於大學自治排除他律 → 不生法律保留問題
> 2. 配套：對師生的干預措施須經**正當程序**（訂定 ＋ 執行）

### 層級化法律保留練習題

| 題目 | 事物屬性 | 釋字 | 層次 | 是否合法 |
|------|----------|------|------|----------|
| 本於職權發布身心障礙宣傳社會教育辦法（全國性發放錢） | 重大公益給付行政 | 443 / 614 | 相對法律保留 | ❌ 出於職權，無法律授權 → 違反法律保留 |
| 要求佩戴口罩 | 生命身體以外權利限制 | 443 | 起碼相對法律保留 | 需有法律或授權依據 |
| 發放三倍券 | 重大公益給付行政 | 614 / 443 | 相對法律保留 | 需有法律或授權依據 |

### 三段論證範本（重大公益給付行政）

```
大前提：依釋字 443 / 614，重大公益給付行政屬相對法律保留，
        須有法律或法律明確授權之依據。
    ↓
小前提：該辦法係出於職權訂定，未取得法律或法律明確之授權。
    ↓
結  論：違反法律保留原則。
```

## 四、授權明確性原則

### （一）為何需要授權明確性？

> 在**相對法律保留**的前提下，立法者可授權行政機關制定命令 → 但授權不得**概括授權**

### （二）歷史典故：納粹德國教訓

| 時間 | 事件 |
|------|------|
| **1933 年** | 納粹控制國會，制定「人民與國家緊急解決法」 |
| **概括授權** | 該法概括授權內閣得制定任何行政命令，甚至可牴觸憲法 → 立法者被架空 |
| **戰後反思** | 西德基本法 §80 第 1 項 → 要求授權之**目的、內容、範圍**應以法律定之 |

### （三）我國繼受

> 留德學者（如翁嶽生等）將德國基本法的授權明確要求引入釋字 → 目的、內容、範圍三要素

### （四）授權明確性三要素

| 要素 | 說明 |
|------|------|
| **授權目的** | 為什麼授權？ |
| **授權內容** | 授權什麼？ |
| **授權範圍** | 授權到什麼界限？ |

> 📌 出自德國基本法 §80 第 1 項，由釋字引介至我國

---

### （五）授權明確性的審查 ⭐

> 本章節最會考的地方

#### 審查密度：依釋字 522「權利影響相稱」原則分軌

```
授權出去的內容 → 影響人民程度？
       │
       ├── 裁罰性 → 嚴格審查
       │
       └── 非裁罰性 → 寬鬆審查
```

#### 1. 裁罰性事項 → 嚴格審查標準

| 要件 | 內容 |
|------|------|
| **三要素明示** | 目的、內容、範圍皆應**明示於授權條款本身** |
| **可罰預見性** | 人民自授權條款即可**預見其行為可罰** |

> ⚠️ 不可令人民必須看到行政命令才知道什麼會被罰 → 必須在**母法授權條款**即可預見

##### 經典案例：釋字 522（證券交易法）

| 項目 | 內容 |
|------|------|
| **事實** | 證券交易法授權制定命令處罰特定交易行為 |
| **問題** | 授權條款僅寫「得制定命令」，未明示處罰之目的、內容、範圍 |
| **大法官認定** | 有授權不明確，須從行政命令中始能確知可罰行為 → **違憲** |

#### 2. 非裁罰性事項 → 寬鬆審查標準

| 要件 | 內容 |
|------|------|
| **三要素無須明示** | 目的、內容、範圍**皆無庸明示於授權條款** |
| **推知即可** | 機關可從**整體法律意旨**推知授權目的即為已足 |

> 📌 寬鬆到：授權條款本身什麼都不用寫，只要整部法律讓機關能推知即可

##### 經典案例：釋字 538（建築法）

| 項目 | 內容 |
|------|------|
| **授權條款** | 建築法 §15：「營造業之管理規則由內政部定之」 |
| **問題** | 未規定授權之目的、內容、範圍 |
| **大法官認定** | 依法律**整體解釋**可推知立法者有意授權 → **合憲** |

---

### 裁罰性 vs 非裁罰性 對照表

| 比較項目 | 裁罰性（嚴格） | 非裁罰性（寬鬆） |
|----------|----------------|-------------------|
| **三要素** | 目的、內容、範圍須**明示**於授權條款 | 目的、內容、範圍**無須明示** |
| **預見性** | 人民自授權條款預見行為**可罰** | 不要求人民預見 |
| **判斷來源** | 授權條款**本身** | 授權條款所依附之**法律整體** |
| **代表釋字** | 522 | 538 |

## 五、綜合考古題演練

### 題目一：身心障礙宣傳辦法 — 授權明確性

| 項目 | 分析 |
|------|------|
| **授權方式** | 施行細則（授權條款：「○○施行細則由○○部定之」） |
| **事物屬性** | 非裁罰性（發放補助） |
| **審查標準** | 寬鬆 → 目的內容範圍無須明示於授權條款，從法律整體推知即可 |
| **法律整體** | 身心障礙者權益保障法 §5 → 可推知補助之授權目的 |
| **結論** | ✅ **未違反**授權明確性原則 |

### 題目二：國民旅遊卡方案 — 法律保留

| 項目 | 分析 |
|------|------|
| **事實** | 行政院以職權推動國民旅遊卡方案，要求持卡於特約商店消費方可請領休假補助 |
| **隱藏爭點** | 此方案以職權訂定 → 有無違反法律保留？ |
| **大前提** | 443 / 614：重大公益給付行政 → 相對法律保留；非重大 → 無須法律保留 |
| **小前提** | 此方案依循既有公務員請假規則（法律規定），僅屬**細節性、技術性**執行事項 |
| **結論** | ✅ 無須法律保留 → 以職權訂定**不違法**（最高行 99 年判決） |

> ⚠️ **考試陷阱**：題目未明示此方案為職權訂定，推定考生知道 → 需具備生活常識與時事敏感度

### 題目二附帶：平等原則

| 項目 | 分析 |
|------|------|
| **差別待遇** | 限定特定商店 ＋ 特定銀行 → B 商店、B 銀行被排除 |
| **正當理由** | 選定特定地區與行業以均衡刺激旅遊 → 未違反事物本質之區別 |
| **結論** | ✅ 未違反平等原則 |

## 本堂總整理

```
法律保留原則
├── 意義：特定事務交給立法者做
├── 目的：分工合作
├── 分配標準：重要性理論（釋字 443）
├── 層級化法律保留
│   ├── 絕對法律保留（474/522/402/491/603/743）
│   ├── 相對法律保留（443/614）
│   └── 無須法律保留（技術性細節/非重大公益給付/大學自治563）
└── 授權明確性（相對法律保留之延伸）
    ├── 來源：納粹教訓 → 德國基本法 §80 → 我國釋字繼受
    ├── 三要素：目的、內容、範圍
    └── 審查標準（釋字 522：權利影響相稱）
        ├── 裁罰性 → 嚴格（明示＋預見可罰）
        └── 非裁罰性 → 寬鬆（整體法律推知即可）
```
