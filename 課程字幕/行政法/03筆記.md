# 行政法 第三堂 筆記

## 本堂主題

不當連結禁止原則、正當法律程序原則、私法填補行政法漏洞、法源位階、法規生效與失效、法律不溯及既往原則（真正溯及 / 不真正溯及）、依法行政（法律優位）

## 一、不當連結禁止原則

### 情境辨識

> 人民要「A」，國家趁機要求人民給「B」 → A 與 B 之間的連結是否正當？

### 三步驟判斷架構

```
步驟一：確認法規體系（A 在哪個體系中？）
    ↓
步驟二：確認制度目的（A 制度的目的為何？）
    ↓
步驟三：國家要的 B 是否能貫徹 A 的制度目的？
    → 有正當關聯 → 合法
    → 無正當關聯 → 不當連結
```

### 經典案例

| 案例 | A（人民想要的） | B（國家要求的） | 制度目的 | 結論 |
|------|-----------------|-----------------|----------|------|
| **罰鍰換照案** | 換行照 | 繳罰鍰 | 交通安全 | ❌ 繳罰鍰與交通安全無正當關聯 → **不當連結** |
| **NCC 電視執照案** | 換電視執照 | 繳錢給中小學 | 節目品質 | ❌ 繳錢與節目品質無正當關聯 → **不當連結** |

### 不當連結在行政程序法的三個實踐

| 法條 | 制度 | 不當連結的表現 |
|------|------|----------------|
| **§10 裁量** | 裁量權行使 | 應符合法規**授權之目的** |
| **§94 附款** | 行政處分附款 | 附款應與處分之目的具**正當合理關聯** |
| **§137 雙務契約** | 行政契約 | 人民給付與機關給付應有**正當合理之連結** |

> 📌 三個條文都在防止國家藉由行政作用「夾帶私貨」

## 二、正當法律程序原則（Due Process）

### 定位

- 介於**憲法**與**行政法**之間的原則
- 不成文但有共識的法律原則

### 定義（釋字 610 協同意見書）

> 關涉人民權利之公權力運作，應設合理正當法律程序，保障人民**參與**及**表達意見**

### 「程序」的兩個階段

| 階段 | 內容 | 說明 |
|------|------|------|
| **事前參與** | 行政處分作成前 | 給予人民陳述意見機會（行程法 §102） |
| **事後救濟** | 處分作成後 | 提起訴願、行政訴訟等 |

### 區別實益

> 就算結果實體上符合構成要件，**程序不對一樣撤銷**

- **案例**：拒絕酒測案 → 程序出錯 → 判決免罰（程序影響實體結果）

### 憲法依據（集合體）

| 來源 | 內容 |
|------|------|
| **憲法 §16** | 訴訟救濟程序 |
| **憲法 §8** | 人身自由特別程序 |
| **各該基本權的程序保障功能** | 基本權客觀面向 → 國家有義務建構適當程序 |

### 行程法 §102：陳述意見

- 處分前給予相對人陳述意見機會
- 是程序保障功能的**具體實踐**

### 正當法律程序的功能

| 功能面向 | 內容 | 說明 |
|----------|------|------|
| **消極面向** | 減少錯誤 | 透過程序減少政府錯誤行為 |
| **積極面向** | 主動營造程序 | 政府建立適合基本權實踐的環境 |

- **積極面向案例**（釋字 364）：廣電頻率分配 — 頻率有限，須透過公平程序分配
- 類推：疫苗分配、停車位分配等稀缺資源

## 三、私法作為行政法法源 — 立法漏洞填補

### 問題意識

> 行政法（公法）有漏洞時，可否用**私法（民法）**來補？→ **可以**

### 兩個填補路徑

| 路徑 | 定義 | 舉例 |
|------|------|------|
| **準用** | 法律**明文規定**可準用私法 | 行程法 §149：行政契約準用民法（如準用民法 §92 撤銷詐欺意思表示） |
| **類推適用** | 法律**未明文**，找最接近的條文填補 | 稅款加計利息案（稅捐稽徵法 §28 漏洞 → 類推民法 §182 等） |

### 類推適用的原則：先公後私

> **釋字 474**：先找公法規定，公法沒有才類推民法

```
發現漏洞
    ↓
先找公法中有無可類推的規定
    ↓
公法也沒有 → 才類推民法規定
```

### 學習建議

- 培養**體系感**：背目錄 → 知道問題在講義哪一頁 → 快速定位

## 四、法源位階

### 為何需要位階？

> 兩個法源強碰時，誰大？→ 需要有排序規則

---

### （一）水平位階（同一公法人內）

#### 基本排序

```
憲法 ＞ 法律 ＞ 命令
```

| 依據 | 規定 |
|------|------|
| **憲法 §171** | 法律牴觸憲法者**無效** |
| **憲法 §172** | 命令牴觸憲法或法律者**無效** |

#### 命令之間的位階

| 情形 | 原則 | 例外 |
|------|------|------|
| **授權命令 vs 職權命令** | 授權命令 ＞ 職權命令（有立法者加持） | 創設性職權命令可與法規命令平起平坐（≈） |
| **上級命令 vs 下級命令** | 上級命令 ＞ 下級命令 | 法律直接授權下級機關 → 下級命令有法律撐腰 → 例外較大 |

---

### （二）垂直位階（不同公法人間）

#### 基本排序

```
中央法規 ＞ 地方法規（自治條例 ＞ 自治規則）
```

| 依據 | 規定 |
|------|------|
| **憲法 §116 / §125** | 省法規 / 縣規章不得牴觸國家法律 |
| **地方制度法 §30** | 自治條例不得牴觸中央法規 |

> ⚠️ 不能**只用**地制法 §30（套套邏輯：兩人吵架，一人自立為王），須**回歸憲法**

#### 案例

| 案例 | 爭點 | 結論 |
|------|------|------|
| **萊豬案** | 中央命令開放 vs 地方自治條例零檢出 | 中央 ＞ 地方 |
| **電子遊戲場距離案** | 地方比中央嚴格 | 例外容許（詳見第四章行政組織） |

---

### （三）同位階法令

| 原則 | 依據 | 說明 |
|------|------|------|
| **特別法優於普通法** | 中標法 §16 | 特別規定排除普通規定 |
| **後法優於前法** | 中標法 §17 | 新規定取代舊規定 |

> 📌 **中央法規標準法** = 萬法之法

---

### （四）不成文法源位階

| 法源類型 | 位階 | 說明 |
|----------|------|------|
| **習慣法** | ≦ 法律 | 不能大於法律 |
| **一般法律原則**（明確性 / 平等 / 比例 / 信賴保護） | **憲法位階** | 都是從憲法推導出的 |
| **大法官解釋 / 憲法判決** | **依規範內容而定** | 見下表 |

#### 大法官解釋的位階判斷

| 解釋類型 | 位階 | 案例 |
|----------|------|------|
| 解釋**憲法疑義** | 憲法位階 | 釋字 748（同性婚姻） |
| 統一解釋**法律 / 命令** | 法律 / 命令位階 | — |

## 五、法規生效與失效

### 考情提示

> 一試很少直接考，但實務重要（不知生效日 → 無法主張權利）

---

### （一）法規生效

| 類型 | 規定 | 說明 |
|------|------|------|
| **明定公佈日施行** | 中標法 §13 | 公佈日起算第 **3 日**生效（如 17 日公佈 → 19 日生效） |
| **明定特定日期** | 如行程法 §175 | 「本法自 90 年 1 月 1 日施行」→ 以該日為準 |
| **自動施行** | 地制法 §32 | 地方政府逾期未公佈 → 期限屆滿起算第 3 日**自動生效**，由地方機關代為發布 |

---

### （二）法規失效

| 類型 | 說明 | 舉例 |
|------|------|------|
| **期間經過** | 限時法到期 | 肺炎條例 |
| **未依法更正廢止 → 自動失效** | 立法院審查法規命令，送還後逾 2 個月未更正即失效 | 立法院職權行使法 §62 |
| **修法廢止** | 整部法被廢止 | 懲治叛亂條例 |

## 六、法律不溯及既往原則

### 體系定位

> 先理解生效 → 再理解失效 → 再理解能否**溯及生效**

### 溯及的定義（釋字 577）

> 把**新法的法律效果**用在**過去已發生之構成要件事實**上 → 即為溯及

- 「已發生之構成要件事實」= 已終結的事件（釋字 793 用語）

---

### （一）真正溯及既往

#### 定義

> 新法法律效果適用於**構成要件已全部實現**且**已引發法效**（已終結）的事件

#### 效果

| | 內容 |
|---|------|
| **原則** | ❌ 不允許（法安定性 + 信賴保護） |
| **例外** | ✅ 允許 → 公益 ＞ 私益 |

#### 例外允許的判斷（不需死背，理解公私益衡量即可）

| 情形 | 為何例外允許 |
|------|-------------|
| 現行法本身不清晰 | 人民無信賴基礎 → 私益微薄 |
| 人民得預見法律有變更 | 已預見 → 私益較小 |
| 損害輕微 | 私益 ＜ 公益 |
| 涉及**憲法重大公共利益** | 公益極大 → 壓過私益 |

#### 經典案例：釋字 793（黨產條例案）

> 迄今**唯一**被大法官承認的真正溯及合憲案例

| 項目 | 內容 |
|------|------|
| **背景** | 威權時期 KMT 取得之不當黨產，數額達 800 多億 |
| **新法** | 黨產條例 → 授權黨產委員會以行政處分追討不當黨產 |
| **溯及爭點** | 過去被認為 OK 的黨產 → 新法事後評價為不 OK → 改變法律效果 |
| **KMT 主張** | 黨產條例違反法律不溯及既往 → 違憲 |
| **大法官結論** | 涉及**憲法重大公共利益** → 例外允許溯及 |
| **關鍵公益** | **政黨公平競爭**：不當黨產導致宣傳資源不對等 → 影響民主機制基礎 |

```
黨產條例溯及 → 原則不允許
    ↓
但涉及「政黨公平競爭」此一憲法重大公益
    ↓
公益 ＞ 私益 → 例外合憲
```

#### 大法庭裁定：性平調查小組案

| 項目 | 內容 |
|------|------|
| **舊法** | 調查小組 = 內部 + 外部委員 |
| **新法** | 調查小組 = **全部外聘** |
| **時序** | 決定已作成（事件已終結）→ 新法才修正 |
| **爭點** | 新法得否溯及適用於已終結的調查？ |
| **結論** | 已終結 → 真正溯及 → **原則不允許** → 違反信賴保護及禁止溯及原則 |

---

### （二）不真正溯及既往

#### 定義

> 新法法律效果適用於**構成要件僅部分實現**、事件**尚未終結**的狀態

#### 與真正溯及的區別

| | 真正溯及 | 不真正溯及 |
|---|---------|-----------|
| **構成要件** | 全部實現 | 僅部分實現 |
| **事件狀態** | 已終結 | 尚未終結 |
| **原則** | ❌ 不允許 | ✅ 允許 |
| **例外** | 公益＞私益 → 允許 | 私益＞公益 → 不允許 |

#### 案例說明

> 二審判決前修法提高上訴門檻 → 案件尚未終結 → 構成要件僅部分實現 → **不真正溯及**

---

### （三）中央法規標準法 §18：不真正溯及的特別規定

#### 適用情境

> ⚡ **許可審理中** + **法規變更** → 必引 §18

#### 規則

```
原則：許可審理中法規變更 → 適用新法
    ↓
例外：舊法有利 + 新法未禁止 → 適用舊法
```

> 📌 口訣：**從新從優**（原則用新，例外擇優）

#### 考古題

| 案例 | 審理中？ | 新 / 舊法哪個有利？ | 新法是否禁止？ | 結論 |
|------|---------|-------------------|---------------|------|
| **電子遊戲場案**（警特） | ✅ 申請營業執照中 | 舊法有利（舊法允許） | ✅ 新法**一律禁止** | 用**新法** → 拒絕申請 |
| **養雞場案（一）**（不真正溯及） | ✅ 申請許可中 | 舊法有利（不需說明會） | ❌ 新法未禁止 | 用**舊法** → 不可否準 |
| **養雞場案（二）**（真正溯及） | ❌ 已取得許可 | — | — | 已終結 → 真正溯及 → **原則不允許撤銷** |
| **土石採取法決議** | ✅ 申請執照中 | 舊法有利（不需繳環境維護費） | ✅ 立法理由禁止 | 用**新法** → 需繳費 |

#### 考試寫作邏輯

```
大前提：中標法 §18
    ↓
小前提：判斷新舊法何者有利 + 新法有無禁止
    ↓
結論：適用新法或舊法 → 得出具體法律效果
```

## 七、依法行政 — 法律優位原則

### 體系定位

> 前面學的：行政是什麼、行政法是什麼、法源有哪些
> 現在要問：行政與法律之間的關係 → **依法行政**

### 依法行政的憲法依據

- 憲法**未明定**「依法行政」
- 但從憲法第三章至第九章可歸納：**憲法機關彼此互動 + 權力分立制衡** → 推導出依法行政

### 依法行政的兩大指標

| 指標 | 核心內容 | 本堂進度 |
|------|----------|----------|
| **法律優位** | 法律 ＞ 行政，行政不得違反法律 | ✅ 本堂講授 |
| **法律保留** | 特定事項須有法律授權始得為之 | ⏳ 下堂講授 |

### 法律優位原則

#### 定義

> 任何行政行為都**不能違反現行法律**，行政行為不得偏離法律

#### 經典考法

```
題目出現：某行政行為 + 參考法條
    ↓
檢視：該行政行為是否違反參考法條？
    ↓
常見模式：母法授權機關制定子法 → 子法或執法是否超出授權範圍？
```

> 📌 答題步驟：**先點出母法授權範圍** → 再論證行政行為是否逾越 → 收尾

#### 考古題：帶病投保案

| 項目 | 內容 |
|------|------|
| **事實** | 甲帶病投保勞保 → 病發請求傷病給付 |
| **參考法條** | 社會保險法規：符合給付事由即應給付（不因帶病投保而排除） |
| **行政行為** | 勞保局依勞委會**函釋**拒絕給付 |
| **爭點** | 函釋（行政行為）是否牴觸法律意旨？ |
| **結論** | 函釋牴觸母法 → 違反**法律優位原則** |

#### 寫作架構

```
一、點出法律意旨（母法規定）
二、論證行政行為（函釋）牴觸法律意旨
三、結論：違反法律優位原則
```

## 重點整理與考試提醒

### 高頻考點

| 主題 | 考試重點 | 關鍵法條 / 釋字 |
|------|----------|----------------|
| 不當連結 | 情境辨識 + 三步驟判斷 | 行程法 §10、§94、§137 |
| 正當法律程序 | 程序影響實體結果 | 釋字 610、行程法 §102 |
| 法源位階 | 垂直位階 + 同位階 | 憲法 §171/§172、地制法 §30、中標法 §16/§17 |
| 真正溯及 | 原則不允許、唯一例外 | **釋字 793**（黨產條例）、釋字 577 |
| 不真正溯及 | 許可審理中 + 法規變更 | **中標法 §18**（從新從優） |
| 法律優位 | 行政行為是否牴觸法律 | 依個案參考法條 |

### 口訣速記

| 主題 | 口訣 |
|------|------|
| 不當連結三條文 | **裁量（§10）→ 附款（§94）→ 契約（§137）** |
| 正當法律程序兩階段 | **事前參與 + 事後救濟** |
| 類推適用順序 | **先公後私**（釋字 474） |
| 法源水平位階 | **憲＞法＞令** |
| 溯及判斷 | **已終結 = 真正溯及（原則不許）；未終結 = 不真正溯及（原則允許）** |
| 中標法 §18 | **從新從優**（原則用新，例外擇優） |
