## 一、授權明確性考題演練（續）

### 考題 1：懲治走私條例案（釋字 680）

| 項目 | 內容 |
|------|------|
| **事實** | 甲乙丙走私，依懲治走私條例 §2 及行政院公告處罰 |
| **爭點** | §2 授權行政院公告管制物品項目及數額 → 授權是否明確？ |
| **軌道選擇** | 懲治走私 ＝ 裁罰性 → 嚴格審查標準 |
| **大前提** | 釋字 522：目的 / 內容 / 範圍需**明示**於授權條款 ＋ 人民可**預見**行為可罰 |
| **涵攝** | §2 全部委由行政院公告，未規定目的、未就管制物品應考量因素規定，須從公告始能知悉可罰範圍 |
| **結論** | ❌ 授權不明確 → 違憲 |

### 考題 2：人民團體法 §58（105 年高考法制）

| 項目 | 內容 |
|------|------|
| **事實** | 人民團體法 §58 授權主管機關「停止理監事職權」 |
| **關鍵** | 需先獨立判斷「停止職權」是否具裁罰性 → 再選軌道 |
| **授權條款辨識** | 「違反法令」即隱含授權規定（非典型格式，需自行辨別） |

### 授權明確性答題三步驟

```
第一洞：判斷授權規範是否具裁罰性
    ↓
第二洞：選軌道（裁罰性 → 嚴格 / 非裁罰性 → 寬鬆）
    ↓
第三洞：用釋字 522 大前提，比對授權條款是否明確
```

> 📌 記得用**釋字 522**帶出雙軌大前提

## 二、行政裁量

### （一）為何接在依法行政之後教

| 邏輯脈絡 | 說明 |
|----------|------|
| 依法行政 | 法律控制行政 |
| 法律有時而窮 | 不可能規範行政每個面向 |
| 需給機關自主空間 | 配合個案做出最佳決定 |

> 行政機關的兩個自主空間：
> 1. **法律效果的選擇** → 裁量空間
> 2. **涵攝的判斷** → 判斷餘地

### （二）行政裁量的定義

| 項目 | 說明 |
|------|------|
| **定義** | 機關在該當構成要件後，針對「是否發生法律效果」＋「發生何種法律效果」的思考空間 |
| **本質** | 法律效果的選擇 |
| **辨識關鍵字** | 「得」→ 選擇（裁量）；「應」→ 必須（羈束） |
| **注意** | 無「得」字也可能有裁量空間（如罰鍰範圍 600–1800） |

---

### （三）裁量瑕疵（三種）⭐ 重要考點

> ⚠️ 裁量瑕疵 ＝ 違法 → 可撤銷

| 瑕疵類型 | 定義 | 特徵關鍵字 | 舉例 |
|----------|------|-----------|------|
| **裁量逾越** | 超越法定裁量範圍（含法律原則界限） | 超出範圍、違反比例原則 | 罰鍰 700–900，卻開 1000；不分情節一律最高額（違反比例原則） |
| **裁量怠惰** | 有裁量權卻不行使，想都不想 | **凡**、**一律** | 不論違規程度，凡查獲一律處最高額 |
| **裁量濫用** | 行使裁量權但參雜法定**外**之動機 | 法外目的、報仇、政治考量 | 交通開單目的應為安全，卻為報仇而開 |

### 口訣速記

```
逾越 → 太超過（法條或比例原則的界限）
怠惰 → 不用腦（凡、一律）
濫用 → 用錯心（法外目的）
```

#### 題 1：兒少福利法虐童案（209 頁）

|------|------|
| **法條** | 兒少權益保障法 §49 + §97（6 萬–30 萬） |
| **事實** | A 市因虐童事件頻傳、觀感不佳 → 下令**凡**虐待經查證屬實，**一律**處最高額並公布姓名 |

### （四）裁量縮減（裁量收縮至零）

#### 基本概念

| 項目 | 說明 |
|------|------|
| **定義** | 裁量空間因個案發展，選項配合**適合性**篩選而減少 |
| **裁量縮減至零** | 選項縮減到只剩一個 → 機關「得」變成「應」 |
| **法律效果** | 機關有做出特定行為之義務；人民有請求權 |
| **法條依據** | 行政訴訟法 §200 第 3 款 vs 第 4 款 |

#### 行政訴訟法 §200 對照

| 款別 | 情形 | 效果 |
|------|------|------|
| **第 3 款** | 事證明確 → 機關無選擇空間（裁量縮減至零） | 法院可判命機關作成**特定內容**之處分 |
| **第 4 款** | 涉及行政裁量（仍有選擇空間） | 人民不能要求特定內容 |

#### 縮減原因 ＝ 適合性

```
裁量為何縮減？
    ↓
因為部分選項在個案中不適合（適合性原則）
    ↓
配合個案事實，刪除不適合選項
    ↓
可能縮減至零
```

#### 經典例子：土壤汙染整治法 §15（八個選項）

- 命停止、調查汙染、提供飲水、設立告示、會同調查、**疏散民眾**、移除汙染物、其他
- 當汙染嚴重危及人命 → 只有「疏散民眾」適合 → 裁量縮減至零

#### 判斷縮減標準 — 釋字 469 ⭐

| 參數 | 內容 | 說明 |
|------|------|------|
| **危害迫切程度** | 人民權益所受侵害的危險有多迫切 | 越迫切 → 能選的越少 |
| **可預見性** | 公務員對損害發生是否可得預見 | 越能預見 → 越應介入 |
| **仰賴公權力** | 侵害防止是否須仰賴公權力 | 非個人可排除 → 機關不可迴避 |
| **可達成性** | 是否可達成目的 | 目的無法以個人努力避免 |

> 📌 考試寫到裁量是否縮減時，**一定要引用釋字 469** 的參數描述事實

#### 灰狗咬人案（李建良文獻，216 頁）

| 項目 | 內容 |
|------|------|
| **事實** | 甲被**路人**飼養的灰狗咬傷，申請沒入該狗，經拒絕 |
| **法條** | 動物保護法 §32 第 1 項第 3 款：「**得**」沒入 → 要 / 不要兩種選項 |
| **分析** | 路人 ＝ 再也不會碰面 → 危害程度低 → 無法讓裁量縮減至零 |
| **結論** | 否准沒入並非違法（裁量空間未縮減） |

#### 判斷流程（李建良學者）

```
步驟一：確認機關有裁量權限 ＋ 案件合乎構成要件
    ↓
步驟二：探求規範授權目的 → 哪個手段配合目的（適合性）
    ↓
步驟三：有無長久慣行 → 行政自我拘束原則
    ↓
步驟四：法律不能或事實不能 → 排除不可行選項
```

### （五）裁量目的與裁量基準

#### 裁量的目的：個案正義

| 概念 | 說明 |
|------|------|
| **個案正義** | 讓機關配合個案做出最佳選擇 |
| **問題** | 各員警認知不同 → 因人設事 → 違反平等原則 |
| **解決** | 上級機關制定**裁量基準**（行政規則）控制裁量 |

#### 個案裁量 vs 一般裁量

| 比較 | 個案裁量 | 一般裁量（裁量基準） |
|------|----------|---------------------|
| **主體** | 個別承辦員警 / 機關 | 上級機關 |
| **目的** | 實現個案正義 | 確保公平一致 |
| **性質** | 法律效果的個案選擇 | 行政規則（裁量基準） |

#### 原則與例外

```
原則：遵守裁量基準（一般裁量優先）
    ↓
例外：裁量基準違法 → 個案裁量優於一般裁量
    → 同時不違反自我拘束原則（違法慣例不值得遵守）
```

> ⚠️ **選擇題常考**：個案裁量 vs 一般裁量的優先順序

#### 考古題：大客車違規處罰標準案（215 頁）

| 項目 | 內容 |
|------|------|
| **事實** | 甲未依法申請經營大客車運輸，二次違規 |
| **裁量基準** | 處罰標準規定：凡第二次起，每次處最高額 15 萬元 |
| **參考法條** | 公路法 §77 第 2 項：5 萬–15 萬 |
| **問題本質** | 表面問「處分是否合法」→ 實質問裁量基準是否違法 |
| **分析** | 裁量基準「凡第二次起處最高額」→ 未通盤考量情節 → 違反比例原則 → 裁量基準違法 |
| **結論** | 應回歸個案判斷 → 個案裁量優於一般裁量 → 15 萬處分違法 |

### 裁量總結

```
裁量＝法律效果的選擇
    ├─ 考點一：裁量瑕疵（逾越 / 怠惰 / 濫用）
    ├─ 考點二：裁量縮減至零（釋字 469 參數）
    └─ 考點三：裁量基準違法 → 個案裁量優先
```

## 三、判斷餘地

### （一）定義與概說

| 項目 | 說明 |
|------|------|
| **定義** | 機關將法令**適用**於具體事件之際（涵攝），法院基於功能最適原則，例外尊重機關判斷的空間 |
| **位置** | 表現在**涵攝**（事實套用到法律）的環節上 |
| **與裁量之區別** | 裁量 ＝ 法律效果選擇 ≠ 判斷餘地 ＝ 涵攝判斷 |
| **性質** | 例外狀態（原則上法院可全面審查） |

#### 原則 vs 例外

| | 說明 |
|---|------|
| **原則** | 法院對機關決定做事後且**全面**審查（事實認定 / 法律解釋 / 涵攝 / 效果選擇） |
| **例外** | 涵攝涉及高度專業 → 法院尊重機關判斷 → 判斷餘地 |

### （二）判斷餘地的由來

| 理由 | 說明 |
|------|------|
| **功能最適** | 把對的事交給對的人（專業的涵攝由專業機關判斷） |
| **能力限制** | 法院對某些專業領域缺乏充分確認能力 |
| **舉例** | 建築物是否有危害公安？電影是否危害青少年？→ 太專業 |

### （三）考試的兩種問法

| 問法 | 翻譯 |
|------|------|
| 「對此涵攝有無**判斷餘地**？」 | 直接問 → 有無判斷餘地 |
| 「法院對此案件的**審查密度**為何？」 | 間接問 → 有判斷餘地＝放寬；無判斷餘地＝從嚴（正常） |

> 📌 看到「審查密度」→ 背後就在問判斷餘地

### 考題對照

| 年度 / 出處 | 問法 | 涵攝內容 |
|-------------|------|----------|
| 102 年司特 | 「行政法院應尊重其判斷餘地」 | 大陸配偶說詞有無重大瑕疵 |
| 104 年律師 | 「其審查密度為何」 | 房屋標準價格的涵攝 |
| 藥害救濟案 | 「其享有判斷餘地」 | 常見可預期的藥物不良反應 |

### （四）判斷標準 — 釋字 553 ⭐⭐ 核心

> 📌 怎麼判斷有沒有判斷餘地？→ **釋字 553**
>
> 553 提出的是「參數」（非構成要件），需**個案判斷**

#### 參數一：事件性質

| 方向 | 情形 | 效果 |
|------|------|------|
| ⬇ 傾向無判斷餘地 | 侵害人民基本權越重 | 越嚴格審查 |
| ⬆ 傾向有判斷餘地 | 涉及科技、環保、醫藥、能力測驗等**專業**事項 | 尊重機關 |

#### 參數二：決定結構

| 結構 | 判斷餘地傾向 | 說明 |
|------|-------------|------|
| **獨任制**（機關首長單獨決定） | ⬇ 較低 | 一人智慧 ≦ 三法官，無需特別尊重 |
| **合議制**（委員會） | ⬆ 較高 | 人選多元、想法齊全 |
| **獨立機關**（如 NCC） | ⬆ 最高 | 更應尊重 |

#### 553 的兩大部分

```
釋字 553
├── 第一部分（括號 1~2）：判斷餘地是否存在
│   ├── 事件性質（侵權程度 vs 專業程度）
│   └── 決定結構（獨任制 vs 合議制 vs 獨立機關）
│
└── 第二部分（括號 3~6）：判斷瑕疵的審查標準
    ├── 3. 法律程序是否踐行
    ├── 4. 涵攝有無錯誤（事實是否存在）
    ├── 5. 法律概念解釋有無違背解釋法則
    └── 6. 其他概括規定
```

### （五）判斷瑕疵（≠ 裁量瑕疵）

| 比較 | 裁量瑕疵 | 判斷瑕疵 |
|------|----------|----------|
| **位置** | 法律效果的選擇 | 涵攝以外的部分 |
| **意涵** | 選錯效果 | 有判斷餘地，但其他地方違法 |
| **例如** | 逾越 / 怠惰 / 濫用 | 程序違法 / 事實不存在 / 法律解釋錯誤 |

#### 判斷瑕疵的兩大類

| 類別 | 內容 |
|------|------|
| **程序合法性瑕疵** | 應遵守的法律程序未踐行 |
| **實體合法性瑕疵** | 事實不存在、法律解釋違背解釋法則 |

> ⚠️ 就算有判斷餘地，法院仍應審查：  
> ① 大前提（法規解釋）是否正確  
> ② 小前提（事實）是否存在  
> → 只有中間的**涵攝**才不審

### （六）常見有判斷餘地的情形（實務與學說整理）

#### 1. 多元組成的判斷

| 項目 | 說明 |
|------|------|
| **代表** | 教師升等（釋字 462） |
| **流程** | 學者專家先行審查 → 報請教師評審委員會 → 除非有專業理由推翻 → 應尊重其判斷 |
| **理由** | 合議制結構 ＋ 專業判斷 → 符合 553 兩個參數 |

#### 2. 屬人性的判斷（很吃判斷者個人屬性）

| 類型 | 說明 | 依據 |
|------|------|------|
| **考試決定** | 閱卷委員評分 → 尊重其學術判斷 | 釋字 319 |
| **但書** | 申論題有判斷餘地 ≠ 簡答題（有標準答案 → 可審查） | 北高行 101 年判字 732 號 |
| **人事考評** | 長官對部屬的能力績效判斷 → 高度主觀性 → 尊重 | 最高行 94 年判字 |
| **地方自治事項** | 里長延選是否有「特殊事故」→ 地方專業 → 尊重 | 釋字 553 本身 |

> ⚠️ **不確定法律概念 ≠ 一定有判斷餘地**  
> 553 自己說要看事件性質，不是看法條用語

#### 3. 專業預測

| 項目 | 說明 |
|------|------|
| **代表** | 環境影響評估 |
| **特色** | 對未來的預測，人類預見能力有限 → 法院傾向尊重 |
| **但書** | 仍可能有**判斷瑕疵** → 事實未調查就做結論 → 違法 |

#### 環評判斷瑕疵案（高等行政法院 92 年訴更字 35 號）

| 項目 | 內容 |
|------|------|
| **事實** | 開發計畫距淨水場僅 1 公里，但機關未與水利署聯繫、未現場勘查 |
| **結果** | 環評雖有判斷餘地，但建立在虛假事實上 → 判斷瑕疵 → 違法 |
| **教訓** | 有判斷餘地 ≠ 吃無敵星星；事實不存在仍可撤銷 |

### （七）考古題演練

#### 題 1：104 年律師 — 房屋標準價格（228 頁）

| 項目 | 內容 |
|------|------|
| **問題** | 法院對不動產評價委員會所定標準價格之審查密度為何？ |
| **553 分析** | |
| 事件性質 | 課稅 → 侵害不顯著 ✗；房屋評定涉專業（地段、景觀等）✓ |
| 決定結構 | 不動產**審議委員會** → 合議制 ✓ |
| **結論** | 傾向有判斷餘地 → 審查密度放寬 |
| **注意事項** | 縱有判斷餘地，仍須審查判斷瑕疵（程序 + 實體） |

#### 題 2：102 年司特 — 大陸配偶居留案（227 頁）

| 項目 | 內容 |
|------|------|
| **事實** | 大陸配偶甲經面談，認定雙方不同居、說詞有重大瑕疵 → 廢止居留 |
| **問題** | 內政部主張「說詞有重大瑕疵」涵攝有判斷餘地？ |
| **553 分析** | |
| 事件性質 | 涉及婚姻 / 家庭權 → 侵害嚴重 ⬇；說詞有無瑕疵不涉專業 ⬇ |
| 決定結構 | 內政部移民署 → 獨任制 ⬇ |
| **結論** | ❌ 無判斷餘地 → 內政部主張無理由 |

#### 題 3：藥害救濟案（230 頁）

| 項目 | 內容 |
|------|------|
| **問題** | 「常見可預期之藥物不良反應」的涵攝有無判斷餘地？ |
| **553 分析** | |
| 事件性質 | 救命錢 → 侵害不低 ⬇；藥物反應判斷 → 涉及醫藥專業 ⬆ |
| 決定結構 | 題目未點明 → 比較模糊 |
| **結論** | 傾向有判斷餘地（專業性較高；食物趨勢傾向尊重機關） |

## 四、本堂體系總整理

```
行政法總論
├── 依法行政（法律控制行政）
│   ├── 法律優位
│   ├── 法律保留
│   └── 授權明確性（釋字 522 雙軌）
│
└── 行政自主空間（法律有時而窮）
    ├── 裁量（法律效果的選擇）
    │   ├── 裁量瑕疵（逾越 / 怠惰 / 濫用）→ 違法可撤銷
    │   ├── 裁量縮減至零（釋字 469）→ 得 → 應
    │   └── 裁量基準
    │       原則：一般裁量（裁量基準）優先
    │       例外：裁量基準違法 → 個案裁量優先
    │
    └── 判斷餘地（涵攝的判斷）
        ├── 判斷標準：釋字 553
        │   ├── 括號 1~2：判斷餘地是否存在
        │   │   ├── 事件性質（侵權 ⬇ / 專業 ⬆）
        │   │   └── 決定結構（獨任 ⬇ / 合議 ⬆ / 獨立機關 ⬆⬆）
        │   └── 括號 3~6：判斷瑕疵審查
        │       ├── 程序合法性
        │       └── 實體合法性
        └── 常見有判斷餘地的情形
            ├── 多元組成判斷（教師升等，釋字 462）
            ├── 屬人性判斷（考試 319 / 人事考評）
            └── 專業預測（環評）
```

## 五、必背釋字速查表

| 釋字 | 主題 | 核心內容 |
|------|------|----------|
| **319** | 考試決定判斷餘地 | 閱卷委員評分應予尊重（除顯然錯誤外） |
| **462** | 教師升等判斷餘地 | 學者專家先行審查 → 應尊重（多元組成） |
| **469** | 裁量縮減參數 | 危害迫切 / 可預見 / 仰賴公權力 / 可達成 → 以致縮減 |
| **522** | 授權明確性雙軌 | 裁罰性 → 嚴格（目的 / 內容 / 範圍須明示） |
| **553** | 判斷餘地判準 | 事件性質 + 決定結構 → 判斷餘地 vs 判斷瑕疵 |
| **680** | 懲治走私條例 | 授權不明確 → 違憲 |

## 六、考試實戰提醒

1. **裁量瑕疵辨別**：看到「凡」「一律」→ 怠惰；看到「最高額」→ 可能逾越；看到「為了 X 目的」→ 可能濫用
2. **裁量縮減**：一定要引用**釋字 469** 參數描述個案事實
3. **判斷餘地**：一定要用**釋字 553** 開頭 → 跑兩大部分（判斷餘地 + 判斷瑕疵）
4. **審查密度 ＝ 判斷餘地問題**：題目問審查密度 → 背後就在問有無判斷餘地
5. **看參考法條**：行政法考題常出現陌生法條，務必耐心看完再作答
6. **篇幅分配**：按配分寫，不要為小題寫長篇大論
