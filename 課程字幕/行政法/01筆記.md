## 三、成文法體系

### （一）憲法
- 最高位階法源，行政行為不得牴觸

### （二）法律
- 經立法院三讀通過、總統公布
- 具有**法律保留**的拘束力

### （三）行政命令

#### 1. 緊急命令（釋字543）

| 項目 | 內容 |
|------|------|
| 依據 | 憲法增修條文 §2 III |
| 發布者 | 總統 |
| 時機 | 為避免國家或人民遭遇緊急危難或應付財政經濟上重大變故 |
| 程序 | 經行政院會議決議，發布後 10 日內提交立法院追認 |
| 性質 | 具有**暫時替代或變更法律**的效力 |

**釋字543 重點：**
- 緊急命令是**總統的非常措施權**
- 具有**暫時替代法律**的效力
- 可以牴觸法律，但**不能牴觸憲法**
- 為因應緊急情勢的需要，執行機關得依緊急命令**再發布具體執行命令**（概括授權）
- 執行命令的內容不得超越緊急命令的範圍

> ✅ 考點：緊急命令可暫時替代法律 → 效力高於法律  
> ✅ 考點：緊急命令不能牴觸憲法  
> ✅ 考點：釋字543承認執行機關可依緊急命令再發布執行命令

#### 2. 法規命令

| 項目 | 內容 |
|------|------|
| 定義 | 行政程序法 §150：行政機關基於**法律授權**，對多數不特定人民就一般事項所作抽象之對外發生法律效果之規定 |
| 要件 | 須有**法律明確授權** |
| 位階 | 低於法律，不得牴觸法律 |

#### 3. 行政規則

| 項目 | 內容 |
|------|------|
| 定義 | 行政程序法 §159：上級機關對下級機關，或長官對屬官，依其權限或職權為規範機關內部秩序及運作 |
| 性質 | **對內**效力為原則，原則上不直接對外拘束人民 |
| 例外 | 解釋性行政規則、裁量基準 → 可能透過**間接適用**對人民產生影響 |

#### 4. 職權命令（釋字570）

- **爭議**：行政程序法施行後，行政機關能否在無法律授權下，以職權訂定具有外部效力的命令？
- **釋字570 立場**：
  - 原則上：行政程序法施行後，外部性職權命令缺乏法律授權，應有疑慮
  - 例外：針對**細節性、技術性事項**的職權命令，仍有存在空間

> ✅ 考點：職權命令 vs 法規命令的差異在於有無**法律授權**  
> ✅ 考點：釋字570 — 細節性技術性事項的職權命令仍有存續空間

### （四）自治規章
- 地方自治團體依法制定的法規
- 包含自治條例、自治規則等

### （五）條約

#### 釋字329：條約的定義
- **廣義條約**：凡國際間的書面協定，不論名稱為何（公約、協定、議定書等），均屬之
- **內容涉及人民權利義務**者 → 應送立法院審議
- 經立法院審議通過 → 具有**國內法律**的效力

#### 條約的內國法化
- 條約在國際法上生效 ≠ 在國內法上直接適用
- 須經過**內國法化**程序（如立法院審議）才具國內法效力
- 直接適用（self-executing）的條約：條文本身夠明確，可直接作為國內法適用

#### 兩岸協議
- 兩岸人民關係條例的規範
- 非屬傳統國際法上的「條約」
- 但可能涉及人民權利義務 → 仍有送立法院審議的問題

> ✅ 考點：釋字329 — 條約的定義與送審標準  
> ✅ 考點：內國法化程序的必要性

## 四、不成文法體系

### （一）習慣法

#### 釋字400：公用地役權（既成道路）

| 項目 | 內容 |
|------|------|
| 背景 | 私有土地長期供公眾通行，形成既成道路 |
| 要件 | ① 不特定公眾通行所必要 ② 非僅為特定人之便利 ③ 經歷年代久遠而未曾中斷 |
| 效果 | 形成**公用地役關係**，土地所有權人不得任意排除公眾通行 |
| 補償 | 國家應依法辦理徵收並給予補償，否則構成**特別犧牲** |

> ✅ 考點：釋字400 是臺灣行政法中習慣法的唯一典型案例  
> ✅ 考點：既成道路三要件 — 公眾通行必要、非特定人便利、年代久遠未中斷

### （二）法官法

#### 1. 判例制度 → 已廢除
- 舊制：最高法院選編判例，具有拘束力
- 問題：判例脫離原判決事實，僅留下抽象法律見解，侵害**審判獨立**
- 現狀：判例制度已廢除，舊判例不再具有拘束力，僅作為參考

#### 2. 決議制度 → 已廢除
- 舊制：最高法院庭長法官聯席會議作成決議，統一法律見解
- 問題：同樣有侵害**審判獨立**的疑慮
- 現狀：已被大法庭制度取代

#### 3. 大法庭制度（取代判例 + 決議）
- 法院組織法規定
- 當各庭間對法律見解有歧異時 → 交由**大法庭**統一見解
- 大法庭裁定具有拘束**提案庭**的效力
- 比判例、決議更符合正當程序

#### 4. 院解字
- 司法院的統一解釋
- 性質：統一解釋，但**不具有直接拘束法官**的效力
- 法官可以**拒絕適用**院解字

> ✅ 考點：判例、決議已廢除 → 因違反審判獨立  
> ✅ 考點：大法庭制度取代判例與決議，拘束提案庭  
> ✅ 考點：院解字不直接拘束法官

### （三）大法官解釋 / 憲法裁判
- 司法院大法官作成
- 具有拘束全國各機關的效力
- 憲法訴訟法施行後 → 改為**憲法法庭裁判**

### （四）一般法律原則
- 作為法源的最後一層
- 包含多種原則（明確性、比例原則、信賴保護等）

## 五、一般法律原則 — 規範模式

### 規則 vs 原則

| 比較項目 | 規則（Rule） | 原則（Principle） |
|----------|-------------|-------------------|
| 結構 | 條件句：「若 A 則 B」 | 最佳化要求：「盡可能實現」 |
| 適用方式 | 全有全無（all or nothing） | 程度化實現（可衡量、可讓步） |
| 衝突處理 | 一方無效 | 個案衡量，較重者優先 |
| 舉例 | 紅燈停、綠燈行 | 比例原則、明確性原則 |

> 💡 原則是一種「盡可能的要求」（optimization requirement），不是絕對的命令，而是在法律與事實條件許可下，盡最大可能實現的規範。

## 六、明確性原則

### （一）釋字432 — 明確性原則 1.0

#### 三要件（判準）

| 要件 | 內容 |
|------|------|
| **理解可能性** | 受規範者能夠**理解**法律規定的意涵 |
| **預見可能性** | 受規範者能夠**預見**其行為是否符合法律構成要件 |
| **審查可能性** | 法院能夠透過**司法審查**加以確認 |

- 三要件為**同時滿足**的要求
- 法律規定必須讓人民**當下**就能理解、預見

> ✅ 考點：釋字432 — 理解、預見、審查三要件  
> ✅ 考點：80% 的明確性原則考題用釋字432 即可處理

### （二）釋字767 — 明確性原則 2.0

#### 背景事實
- **藥害救濟法 §13 第9款**：「常見且可預期之藥物不良反應」不予救濟
- 人民主張：「常見且可預期」文字過於抽象，違反明確性原則

#### 大法官見解

| 項目 | 內容 |
|------|------|
| 結論 | **合憲** — 不違反明確性原則 |
| 關鍵理由 | 修正了「預見」的**時間點** |
| 論述 | 雖然人民**當下**無法完全理解「常見且可預期」的意涵，但透過**有告知義務之人**（醫師、藥師）事後告知，人民仍可有**合理程度的預見** |

#### 432 vs 767 比較

| 比較項目 | 釋字432（1.0） | 釋字767（2.0） |
|----------|---------------|---------------|
| 嚴格度 | 較嚴格 | 較寬鬆 |
| 理解/預見時點 | **當下**就要能理解、預見 | 可以延後到**事後**（經告知後） |
| 前提條件 | 法律條文本身須夠清楚 | 須有**有告知義務之人**存在 |
| 適用場景 | 一般情形（80%的題目） | 有「有義務之人」可事後告知的特殊情形 |

#### 答題要領

```
題目出現明確性原則 →
  ├── 一般情形 → 套釋字432（理解、預見、審查）
  └── 題目有「有告知義務之人」存在 → 套釋字767
       └── 雖當下無法預見，但事後經告知可預見 → 仍算明確
```

> ✅ 考點：釋字767 — 有義務之人的事後告知使預見時點延後  
> ✅ 考點：不能亂用767 — 必須題目中有「有告知義務之人」存在才能適用  
> ❌ 易錯：藥害救濟法的題目若只套432，無法得出「事後預見」的結論 → 會掉分

## 七、本堂課重點回顧

1. **法源體系**：成文法（憲法、法律、行政命令、自治規章、條約）＋ 不成文法（習慣法、法官法、大法官解釋、一般法律原則）
2. **緊急命令**：釋字543 — 可暫時替代法律、可再發布執行命令、不得牴觸憲法
3. **職權命令**：釋字570 — 細節性技術性事項仍有存續空間
4. **條約**：釋字329 — 定義與內國法化
5. **習慣法**：釋字400 — 既成道路公用地役權（臺灣唯一案例）
6. **法官法**：判例與決議已廢、大法庭制度取代、院解字不拘束法官
7. **明確性原則**：
   - **釋字432**（1.0）：理解、預見、審查 → 一般適用
   - **釋字767**（2.0）：有告知義務之人事後告知也算明確 → 特殊適用
